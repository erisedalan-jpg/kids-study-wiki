# 考点命名规则

> 真题 frontmatter `考点` 字段是全真题管线的中枢词表：考点 → 反链（按 alias 匹配概念词条）→ weight → 吉林冲刺索引 / 学生 HTML / 题位脑图。词表脏（同义多写法）会污染频次、打断概念图链接、扰乱权重。本规则统一考点命名，**保守归并纯写法变体、保留有意义粒度**。

## 🚫 红线（防复发硬约束，一字不动）

- **新真题录入考点必查 canonical 清单**：`考点` 只能用规范名；遇旧/异写，先查 `00-元/scripts/canonical_考点_数学.yaml` 是否已有映射。
- **只并纯写法变体，绝不并语义不同项**：`复数乘法` / `复数除法` / `复数运算` 各自保留；`正弦定理` ≠ `余弦定理`；`线面平行` ≠ `线面垂直`。误并会改反链 → 改 weight。
- **加新考点走映射表**：确需新写法时，在 `canonical_考点_数学.yaml` 加 `新变体: 规范名`（或确立新规范名映射到自身），不得在真题里另造同义异写。

## 命名 6 规则

1. **去冗余「的」连接词**（不改义的结构助词）
   `函数的奇偶性 → 函数奇偶性`；`导数的几何意义 → 导数几何意义`；`椭圆的标准方程 → 椭圆标准方程`。

2. **操作词归一为「运算」**（表"对某对象做运算/求解"）
   `交集` / `交集及其运算` / `集合交集` / `集合的交集` / `集合的交集运算` → `交集运算`；
   `并集` / `并集运算` → `并集运算`；`集合的运算` → `集合运算`。

3. **「图象」统一**（数学课标用字，不用「图像」）
   `三角函数的图像与性质` / `三角函数图象与性质` / `三角函数的图象与性质` → `三角函数图象与性质`。

4. **去题型 / 赘尾**（不改义的 `问题` / `判断` / `与应用` / `及应用` / `的解法` 等）
   `命题的真假判断` / `命题的真假判断与应用` → `命题真假判断`；`绝对值不等式的解法` → `绝对值不等式`。

5. **不并语义不同项**（保留真粒度）—— 见红线第 2 条。

6. **受控词表**：canonical 规范名清单即 `canonical_考点_数学.yaml` 的值集合（去重）。新真题考点须落在清单内；扩词走映射表。

## 纯变体硬标准（判定能否归并）

> 两个 tag，**去掉结构性词**（的 / 及其 / 运算 / 计算 / 问题 / 判断 / 应用 / 解法）**与图象-图像异写后字面同义** → 为"纯写法变体"，可并到同一规范名；否则**保留**。逐条入映射表前须满足此标准；拿不准的**不并**（保守 pass-through，原样保留）。

## 如何加新考点（维护流程）

1. 新真题录入时，考点优先从现有 canonical 规范名（`canonical_考点_数学.yaml` 值集合）中选。
2. 若出现旧/异写但语义已有规范名 → 在 `canonical_考点_数学.yaml` 加一行 `异写: 规范名`，跑迁移脚本归并。
3. 若是真正新考点（无现成规范名）→ 直接用规范、简洁的名字（遵守 6 规则），并在映射表加 `新名: 新名`（指向自身）以纳入受控清单。
4. 改动考点后，按下游链重算：
   ```
   python 00-元/scripts/normalize_kaodian_source.py            # dry-run 过 diff
   python 00-元/scripts/normalize_kaodian_source.py --apply    # 写盘（需 git 干净）
   python 00-元/scripts/exam_index.py --province 吉林 --subject 数学
   python 00-元/scripts/compute_weight.py --subject 数学 --apply
   python 00-元/scripts/gen_html.py --apply
   python 00-元/scripts/gen_exam_blueprint.py --apply
   ```
   并对比 weight 漂移（应小且可解释）。
