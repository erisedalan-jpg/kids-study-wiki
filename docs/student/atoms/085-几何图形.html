几何图形

权重4吉林命中0路径1学段[初中, 高中]主题[几何, 七上, 几何初步]

aliases: 几何图形, geometric figure, 几何形状

课本一句话定义

从现实世界中抽象出来的各种图形（点、线、面、体）统称为几何图形；几何图形分为立体图形（占有一定空间）和平面图形（各部分在同一平面内）。

📚 给 6-12 岁（小学高年级回溯版）

生活中到处都有几何图形： - 足球是球体（立体图形） - 课本的封面是长方形（平面图形） - 牛奶盒是长方体（立体图形） - 硬币是圆形（平面图形）

几何图形分两大类： - 立体图形：有"厚度"，占空间（正方体、球、圆柱……） - 平面图形："平的"，在纸上画的（三角形、圆形、正方形……）

几何这门学问，就是研究这些图形的形状、大小和位置关系的数学分支。

🎓 给 12+（进阶版）

几何图形的分类

几何图形
├── 立体图形（三维）
│   ├── 多面体（面都是平面）
│   │   ├── 棱柱（三棱柱、四棱柱=长方体/正方体……）
│   │   ├── 棱锥（三棱锥=四面体、四棱锥……）
│   │   └── 棱台
│   └── 旋转体（曲面）
│       ├── 圆柱
│       ├── 圆锥
│       └── 球
└── 平面图形（二维）
    ├── 直线形（三角形、多边形……）
    └── 曲线形（圆、椭圆……）

几何基本元素

元素 描述 维度
点（point） 无大小，只有位置 0 维
线（line） 无宽度，只有长度（和方向） 1 维
面（surface/plane） 无厚度，只有面积 2 维
体（solid） 有长、宽、高，占空间 3 维

点动成线，线动成面，面动成体——维度的递推规律。

立体图形的展开（平面展开图）

立体图形可以沿棱剪开展平为展开图（net）： - 正方体展开图有 11 种 - 圆柱展开图 = 两个圆 + 一个长方形 - 圆锥展开图 = 一个圆 + 一个扇形

典型例题

例 1：列举身边 3 种立体图形和 3 种平面图形。

解：立体：饮料罐（圆柱）、金字塔形纪念品（四棱锥）、排球（球体）；平面：硬币正面（圆）、地图（平面图）、书封面（长方形）。

例 2：下列图形中，哪些是平面图形？圆柱、三角形、球、正方形、圆锥。

解：三角形、正方形是平面图形；圆柱、球、圆锥是立体图形。

易错点

  1. 圆是平面图形，球是立体图形：圆（circle）在平面内；球（sphere）占三维空间。
  2. 平面图形是截面图或展开图：圆柱的截面是圆（平面图形）。
  3. 几何是抽象的：几何中的点没有大小，线没有宽度，与实物不同。

知识联系

  • 前置：小学平面图形（三角形、圆形、长方形等）
  • 后续：立体图形（各部分定义）→ 点线面体 → 线段射线直线 → 角
  • 高中拓展：空间几何（立体几何）、解析几何（坐标法）
