单项式

权重4吉林命中0路径1学段[初中, 高中]主题[代数, 七上, 整式]

aliases: 单项式, monomial, 单项

课本一句话定义

单项式是数与字母的积（包括单独的一个数或一个字母），没有加减运算；单项式中所有字母指数的和叫做这个单项式的次数，数字因数叫做它的系数。

📚 给 6-12 岁（小学高年级回溯版）

你已经认识了数字，现在数学里出现了字母（代表未知数）。

单项式就是数字和字母"粘在一起"（相乘）的式子，没有加号和减号：

  • $3x$：3 乘以 $x$，是单项式 ✅
  • $-5ab$：$-5$ 乘以 $a$ 乘以 $b$，是单项式 ✅
  • $7$：单独的数，是单项式 ✅（只不过没有字母）
  • $x + 3$：有加号，不是单项式 ❌

单项式的两个关键： - 系数：前面的数字（$3x$ 的系数是 $3$） - 次数：所有字母的指数加起来（$3x^2y$ 的次数是 $2 + 1 = 3$）

🎓 给 12+（进阶版）

严格定义

单项式（monomial）是数、字母或数与字母的积。

系数（coefficient）：单项式中的数字因数。若系数为 1 或 -1，通常省略 1（但保留符号）。

次数（degree）：单项式中所有字母的指数之和。 - 纯数字（非零常数）的次数为 0 - $0$ 的次数没有意义（通常不讨论）

关键性质

单项式 系数 次数 说明
$3x^2y$ $3$ $3$ $2+1=3$
$-ab^2c$ $-1$ $4$ $1+2+1=4$
$\dfrac{1}{2}x$ $\dfrac{1}{2}$ $1$
$-5$ $-5$ $0$ 常数项
$x$ $1$（省略） $1$

典型例题

例 1：指出 $-\dfrac{3}{4}x^2yz^3$ 的系数和次数。

解：系数为 $-\dfrac{3}{4}$；次数为 $2 + 1 + 3 = 6$。

例 2：下列哪些是单项式？$3a$、$x + y$、$-7$、$\dfrac{a}{3}$、$\dfrac{3}{a}$

解： - $3a$：数与字母的积，✅ 单项式 - $x + y$：含加号，❌ 不是单项式（是多项式） - $-7$：单独的数，✅ 单项式（0 次） - $\dfrac{a}{3} = \dfrac{1}{3}a$：数与字母的积，✅ 单项式 - $\dfrac{3}{a} = 3a^{-1}$：字母在分母（指数为 -1），❌ 七年级范围内不算单项式（负指数超出范围）

例 3：若单项式 $3x^m y$ 的次数为 5，求 $m$。

解：$m + 1 = 5$，$m = 4$。

易错点

  1. 字母在分母不是单项式：$\dfrac{1}{x}$ 不是七年级意义上的单项式。
  2. 系数为 1 时别忘了：$x^2$ 的系数是 $1$，不是 $0$。
  3. 负号属于系数：$-3x$ 的系数是 $-3$，不是 $3$。

知识联系

  • 前置：有理数四则运算、字母表示数
  • 后续：多项式 → 整式 → 合并同类项 → 整式加减
  • 高中拓展：多项式（高次）→ 因式分解 → 函数表达式
