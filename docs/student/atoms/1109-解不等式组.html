解不等式组

一句话：不等式组是由若干个不等式联立构成的整体，其解集是各个不等式解集的交集。 English: The solution set of a system of inequalities is the intersection of the solution sets of all individual inequalities in the system.

🎓 考点精讲

定义与原理 设不等式组为 $\begin{cases} f_1(x) > 0 \ f_2(x) \geq 0 \ \cdots \ f_n(x) < 0 \end{cases}$，则该不等式组的解集为 $S = S_1 \cap S_2 \cap \cdots \cap S_n$，其中 $S_i$ 是第 $i$ 个不等式的解集。常见类型包括：一元一次不等式组、一元二次不等式组、含分式或绝对值的不等式组。

关键解法步骤 1. 分别求解：将不等式组中的每个不等式独立解出，得到各自的解集。 2. 在数轴上表示：将各不等式的解集画在同一数轴上，用空心圈表示严格不等号（$<$ 或 $>$），实心点表示含等号（$\leq$ 或 $\geq$）。 3. 取公共部分：数轴上所有线条重叠的区域即为不等式组的解集，通常用区间表示。

以一元一次不等式组 $\begin{cases} 2x - 1 > 3 \ x + 2 \leq 5 \end{cases}$ 为例： - 由 $2x - 1 > 3$ 得 $2x > 4$，即 $x > 2$。 - 由 $x + 2 \leq 5$ 得 $x \leq 3$。 - 数轴上取交集，得解集 $(2, 3]$。

对含二次的不等式组如 $\begin{cases} x^2 - x - 6 < 0 \ x - 1 > 0 \end{cases}$： - 解 $x^2 - x - 6 < 0$ 得 $-2 < x < 3$。 - 解 $x - 1 > 0$ 得 $x > 1$。 - 取交集得 $1 < x < 3$，即 $(1, 3)$。

典型高考应用 - 集合运算题：以不等式组的形式给出集合，求交集或参数范围。 - 函数定义域：求使解析式各部分同时有意义的自变量的取值范围，本质是解不等式组。 - 线性规划：可行域由一组线性不等式联立构成，其边界交点需解相应的等式组确定。

⚠️ 高频易错点

  • 交集与并集混淆：不等式组取交集（各个不等式同时成立），而分类讨论中不同情况的解集取并集，学生常将两者用反。
  • 端点取舍不清：数轴上重叠部分端点的开闭必须严格对照各不等式的等号是否成立。若任一不等式在该点不取等号，则最终解集在该点必须为开区间。
  • 符号变向错误：解不等式两边同乘或除以负数时忘记改变不等号方向，导致单个不等式解集错误，进而使交集结果错误。
  • 分式不等式直接去分母：如 $\frac{x-1}{x+2} > 0$ 不可直接乘 $x+2$ （符号未知），应转为等价整式不等式组 $(x-1)(x+2) > 0$ 求解。
