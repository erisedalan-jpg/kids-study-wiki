商数关系

一句话：同角三角函数的基本商数关系为 $\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha}$（$\cos\alpha \neq 0$）及 $\cot\alpha = \dfrac{\cos\alpha}{\sin\alpha}$（$\sin\alpha \neq 0$）。 English: The quotient identities state that $\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha}$ and $\cot\alpha = \dfrac{\cos\alpha}{\sin\alpha}$.

🎓 考点精讲

定义/原理
商数关系是同角三角函数基本关系之一，将正切、余切直接定义为正弦与余弦的比值： $$\tan\alpha = \frac{\sin\alpha}{\cos\alpha},\quad \cot\alpha = \frac{\cos\alpha}{\sin\alpha} = \frac{1}{\tan\alpha}.$$ 该关系来源于任意角三角函数定义：设角 $\alpha$ 终边上一点 $P(x,y)$，$r=\sqrt{x^2+y^2}$，则 $\sin\alpha=y/r$，$\cos\alpha=x/r$，于是 $y/x = \sin\alpha/\cos\alpha$，当 $x\neq0$ 时即为 $\tan\alpha$。

关键方法
在高考中，商数关系极少单独使用，须与 平方关系 $\sin^2\alpha+\cos^2\alpha=1$ 联立，构成弦切互化的完整工具链。标准解题步骤： 1. 定象限：根据所给角所在的象限，判断 $\sin\alpha,\cos\alpha$ 的符号，决定开方后正负号。 2. 求值联动：已知 $\sin\alpha$（或 $\cos\alpha$）求 $\tan\alpha$ 时，先用平方关系求另一弦值，再代入商数关系；已知 $\tan\alpha$ 求 $\sin\alpha,\cos\alpha$ 时，构造方程组 $\begin{cases} \sin\alpha = \tan\alpha\cdot\cos\alpha \ \sin^2\alpha+\cos^2\alpha=1 \end{cases}$，解出 $\cos\alpha$ 后人回代。 3. 化简与证明：遇到正余切与正余弦混合的表达式，优先将 $\tan\alpha,\cot\alpha$ 化为 $\sin\alpha/\cos\alpha$，再通分、约分。

典型应用
- 给值求值：如“已知 $\sin\alpha = \frac{3}{5}$，且 $\alpha$ 为第二象限角，求 $\tan\alpha$。” 先用平方关系得 $\cos\alpha = -\frac{4}{5}$，再由商数关系得 $\tan\alpha = - \frac{3}{4}$。
- 弦切互换化简：化简 $\frac{1}{\tan\alpha+ \cot\alpha}$，化为 $\frac{1}{\frac{\sin\alpha}{\cos\alpha}+\frac{\cos\alpha}{\sin\alpha}} = \frac{\sin\alpha\cos\alpha}{\sin^2\alpha+\cos^2\alpha}=\sin\alpha\cos\alpha$。
- 条件求值：已知 $\tan\alpha = 2$，求 $\frac{\sin\alpha+\cos\alpha}{\sin\alpha-\cos\alpha}$。分子分母同除以 $\cos\alpha$，化为 $\frac{\tan\alpha+1}{\tan\alpha-1}$，代入即得。

⚠️ 高频易错点

  • 忽略象限符号：用平方关系开方时未根据象限确定 $\sin\alpha$ 或 $\cos\alpha$ 的正负，导致 $\tan\alpha$ 符号错误。
  • 分母为零约束遗漏：使用 $\tan\alpha = \sin\alpha/\cos\alpha$ 时未注明 $\cos\alpha \neq 0$，解方程时可能产生增根（如 $\alpha = \frac{\pi}{2}+k\pi$）。
  • 混淆倒数关系与商数关系：误认为 $\tan\alpha \cdot \cot\alpha = 1$ 属于商数关系，实为倒数关系；商数关系专指弦与切之间的表达式。
  • 弦化切时代换不彻底：已知 $\tan\alpha$ 求齐次分式时，忘记分子分母需同时除以 $\cos\alpha$（或 $\cos^2\alpha$）才能统一为 $\tan$ 的表达式。
