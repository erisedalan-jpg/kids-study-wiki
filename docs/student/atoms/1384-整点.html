整点

一句话：坐标均为整数的点称为整点（格点），是处理离散几何、整数解及线性规划中整数最优解的基础概念。 English: A point whose coordinates are all integers is called an integer point (lattice point).

🎓 考点精讲

定义：在平面直角坐标系中，若点 $P(x,y)$ 满足 $x \in \mathbb{Z}$ 且 $y \in \mathbb{Z}$，则称 $P$ 为整点（或格点）。该定义可自然推广至三维及高维空间。

核心原理与考查方式：高考中整点问题主要围绕“给定区域（直线围成、圆、曲线）内的整点个数”和“线性规划整点最优解”展开。常见题型有： - 通过解整数不等式组计数区域内的整点。例如，求满足 $\begin{cases} x \ge 0 \ y \ge 0 \ 2x + 3y \le 12 \end{cases}$ 的整点个数。 - 在线性约束条件下，求目标函数取最值且变量为整数的生产安排问题。 - 作为信息题引入皮克定理：格点多边形面积 $A = I + \frac{B}{2} - 1$（$I$ 为内部格点数，$B$ 为边界格点数），用于快速解决特定填空题或选择题。

关键方法： 1. 逐行（列）整点扫描法：画出区域，固定一个整数的自变量（如 $x$ 从最小到最大整数值），根据边界关系确定另一坐标的整数取值范围，累加计数。 2. 整数解代数分析：将边界方程转化为不定方程或不等式，利用整数的整除性、同余性质讨论参数取值并枚举。 3. 整点最优解平移法：对于线性规划整点问题，先求普通最优解。若最优解不是整点，在附近网格点搜索，比较目标函数值，确定最优整点。禁止直接对非整点顶点取整。

典型应用场景： - 计数问题：“不等式组 $\begin{cases} x^2 + y^2 \le 4 \ x \ge 0 \end{cases}$ 所表示区域内的整点有多少个？”需结合圆的方程，在 $x=0,1,2$ 时分别求对应 $y$ 的整数取值。 - 线性规划应用题：某厂生产A、B产品，工时、原料限制为整数，利润函数已知，求最大利润的整数生产方案——必须给出整数解。

⚠️ 高频易错点

  • 边界是否包含：题目中“区域内部（不含边界）”、“区域内部及边界”整点个数，实线/虚线边界理解错误，导致包含/排除边界整点出错。
  • 线性规划结果非整点处理失误：直接将最优解顶点坐标四舍五入或就近取整，得到的可能不在可行域内或不是最优整点，必须验证。
  • 对称区域整点重复或遗漏：处理圆、正方形等对称区域时，未单独考虑坐标轴上的点或中心点，按象限简单乘以倍数导致错误。
  • 参数解未限制整数范围：在求直线 $ax + by = c$ 上的整点时，解出通解 $x = x_0 + bt$, $y = y_0 - at$ 但忘记限定 $t \in \mathbb{Z}$ 及区域约束，导致超出范围的无效整点被计入。
