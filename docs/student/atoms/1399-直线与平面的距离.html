直线与平面的距离

权重6吉林命中2路径0学段[高中]主题[立体几何]

aliases: 直线与平面的距离, distance between a line and a plane

直线与平面的距离

一句话：当直线与平面平行时，直线上任意一点到该平面的垂线段长度，称为直线与平面的距离。 English: The distance between a line and a plane, when the line is parallel to the plane, is the length of the perpendicular segment from any point on the line to the plane.

🎓 考点精讲

定义：在三维空间中，若直线 $l$ 与平面 $\alpha$ 平行（即 $l \parallel \alpha$ 或 $l \subset \alpha$），则 $l$ 到 $\alpha$ 的距离定义为 $l$ 上任意一点 $P$ 到平面 $\alpha$ 的距离 $d$。若直线与平面相交，则距离视为 $0$。距离公式依托点到平面的距离公式：设平面方程为 $Ax + By + Cz + D = 0$，直线上取点 $P(x_0, y_0, z_0)$，则 $$ d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}} $$ 核心前提：直线方向向量与平面法向量垂直（即 $\vec{v} \cdot \vec{n} = 0$），且直线上至少一点不在平面内。

关键方法： 1. 验证平行条件：计算直线方向向量 $\vec{v}$ 与平面法向量 $\vec{n}$ 的点积是否为 $0$；若为 $0$，则直线平行于平面或在平面内。 2. 取点代入公式：在直线上任取一便于计算的点（常令参数为 $0$ 或联立坐标），代入点到平面距离公式。 3. 参数方程处理：若直线以参数方程给出 $\begin{cases}x = x_0 + at \ y = y_0 + bt \ z = z_0 + ct\end{cases}$，平面为一般式，可将参数坐标代入平面方程，利用距离为定值（不依赖于 $t$）进行化简计算。

典型应用：高考常见设问包括： - 直接求距离：给出具体直线方程与平面方程，求直线到平面的距离。如“已知直线 $l: \frac{x-1}{2} = \frac{y+2}{-1} = \frac{z}{3}$，平面 $\alpha: x - 2y + 2z - 5 = 0$，求 $l$ 到 $\alpha$ 的距离”。解题步骤：验证平行（方向向量 $(2,-1,3)$ 与法向量 $(1,-2,2)$ 点积 $= 2 + 2 + 6 = 10 \neq 0$，则相交，距离为 $0$；若点积为 $0$，取线上点代入公式）。 - 结合最近距离求参数：题目给出直线与平面平行，用距离反求平面方程或直线参数中的待定系数。

⚠️ 高频易错点

  • 忽视平行前提：未验证直线与平面是否平行就直接代入距离公式，误将相交时 $d = 0$ 漏判。
  • 法向量未约分：计算平面法向量时，若方程系数存在公因子，应优先化简，避免代入距离公式时分母计算繁琐导致错误。
  • 取点不当致计算复杂：在直线上随意取点未选最优坐标（如参数为 $0$ 的交点），导致绝对值内代数式冗长，增加出错概率。
  • 混淆线面距与异面直线距：线面距离仅适用于线面平行情形；若直线与平面不平行（且不在面内），题目通常转为求异面直线间的距离或直线上固定点到平面距离的函数最值，切勿混用公式。
