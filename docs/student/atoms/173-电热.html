电热

权重3吉林命中0路径0学段[初中, 高中]主题[九年级全一, 第十八章电功率]

aliases: 电热, joule heating, 焦耳热, 电阻发热

电热

一句话：电流通过导体时，因电阻的存在而产生的热量叫电热（焦耳热），Q=I²Rt，是电能转化为热能的过程。 English: Joule heating is the heat generated when electric current passes through a resistor; Q=I²Rt; it represents conversion of electrical energy to thermal energy.

📚 给 6-12 岁（自读版）

你有没有摸过长时间使用后的手机充电器？它很热！这就是电热。

电热是怎么产生的？ 导线不是完美的导体，有电阻。电流通过电阻时，就像水在有摩擦的管子里流动——会产生"热量"。

电热的公式：

$$Q_{热} = I^2 Rt$$

电热有时有用，有时有害：

有用的电热： - 电热水壶（电热丝加热水） - 电饭锅（利用电热煮饭） - 暖气（电暖器） - 电热毯（冬天取暖） - 保险丝（过热时熔断，保护电路）

有害的电热： - 输电线路损耗（电热浪费电） - 电子芯片发热（需要散热） - 电机线圈发热（降低效率）

🎓 给 12+（进阶版）

电热的本质

微观解释： - 自由电子在电场中加速 - 与金属晶格（正离子）碰撞，将动能转移给晶格 - 晶格振动加剧 → 温度升高 → 热量产生

这个过程本质上是有序动能（定向运动）→ 无序热运动的转化。

焦耳定律

$$Q = I^2Rt$$

在纯电阻电路中，电热等于电功：$Q = W = UIt = Pt$

电热与功率

热功率（即电热产生速率）：

$$P_{热} = \frac{Q}{t} = I^2 R$$

对于纯电阻，热功率 = 电功率（$P_{热} = P = I^2R = UI = U^2/R$）

串并联电路中的电热分配

串联（相同电流）：

$$\frac{Q_1}{Q_2} = \frac{I^2R_1t}{I^2R_2t} = \frac{R_1}{R_2}$$

串联：电热正比于电阻（大阻值产生更多热量）

并联（相同电压）：

$$\frac{Q_1}{Q_2} = \frac{U^2t/R_1}{U^2t/R_2} = \frac{R_2}{R_1}$$

并联：电热反比于电阻（小阻值产生更多热量）

减少有害电热的方法

  1. 选用低电阻材料（如铜、铝导线）
  2. 增大导线截面积（减小电阻）
  3. 高压输电（减小电流，$Q \propto I^2$，效果显著）
  4. 散热设计（CPU散热片、风冷水冷）

典型例题

例：一台电动机铭牌"220V, 500W"，线圈电阻 $R = 2$ Ω。满功率工作时，求电流和电动机每分钟产生的电热。

解：

$$I = \frac{P}{U} = \frac{500}{220} \approx 2.27 \text{ A}$$

$$Q_{热} = I^2Rt = (2.27)^2 \times 2 \times 60 \approx 619 \text{ J}$$

（注意：电动机的电功 $W = Pt = 500 \times 60 = 30000$ J，其中绝大部分转化为机械能，只有约 619 J 转化为电热。$Q < W$ 的差值 = 转化为机械能的部分。）

易错点： - 含电动机时，$W = UIt$（总电功）而 $Q_{热} = I^2Rt$（仅电热），$W > Q_{热}$ - 仅纯电阻时，$W = Q_{热}$ - 电热一旦产生就散发到环境，难以回收利用
