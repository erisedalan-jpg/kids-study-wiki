二次根式加减

一句话：只有"同类根式"（被开方数相同）才能合并，系数相加减，根号部分不变——就像合并同类项。 English: Only "like radicals" (same radicand) can be combined by adding or subtracting their coefficients.

📚 6-12 岁回溯版

什么是同类根式？

同类根式：被开方数完全相同的根式，例如 $3\sqrt{2}$ 和 $5\sqrt{2}$ 都含 $\sqrt{2}$，是同类根式。

类比同类项：$3x + 5x = 8x$ → $3\sqrt{2}+5\sqrt{2}=8\sqrt{2}$

不同类不能合并：$\sqrt{2}+\sqrt{3}$ 无法化简（就像 $x+y$ 不能合并）。

加减步骤

  1. 先化简：把每个根式化为最简根式（利用二次根式化简）
  2. 找同类根式：对比被开方数
  3. 合并：系数加减，根号不变

例：计算 $\sqrt{12} + 2\sqrt{3} - \sqrt{27}$

$$\sqrt{12} = 2\sqrt{3}, \quad \sqrt{27} = 3\sqrt{3}$$ $$= 2\sqrt{3} + 2\sqrt{3} - 3\sqrt{3} = (2+2-3)\sqrt{3} = \sqrt{3}$$

🎓 12+ 进阶版

严格步骤

第一步：化简每个根式为最简根式（被开方数不含完全平方因数）。

第二步：识别同类根式（被开方数相同 → 系数合并）。

第三步：合并，写出结果。

典型例题

例 1：计算 $3\sqrt{50} - 2\sqrt{18} + \sqrt{8}$

$$3\sqrt{50} = 3\cdot5\sqrt{2} = 15\sqrt{2}$$ $$2\sqrt{18} = 2\cdot3\sqrt{2} = 6\sqrt{2}$$ $$\sqrt{8} = 2\sqrt{2}$$ $$= 15\sqrt{2} - 6\sqrt{2} + 2\sqrt{2} = 11\sqrt{2}$$

例 2：化简 $\sqrt{3+2\sqrt{2}} + \sqrt{3-2\sqrt{2}}$

注意 $3+2\sqrt{2}=(\sqrt{2}+1)^2$，$3-2\sqrt{2}=(\sqrt{2}-1)^2$，故 $$= |\sqrt{2}+1| + |\sqrt{2}-1| = (\sqrt{2}+1)+(\sqrt{2}-1) = 2\sqrt{2}$$

易错点

  • ❌ 未先化简就直接合并，导致漏掉同类根式（如 $\sqrt{12}$ 未化为 $2\sqrt{3}$）
  • ❌ 认为 $\sqrt{2}+\sqrt{2}=\sqrt{4}=2$（应为 $2\sqrt{2}$）
  • ❌ 把加法分配到根号下：$\sqrt{a+b}\neq\sqrt{a}+\sqrt{b}$

知识联系

先化简（→二次根式化简），再合并（类似合并同类项）；综合题常与二次根式乘除混合；含字母时须讨论范围（→不等式）。
