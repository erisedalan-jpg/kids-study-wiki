电阻测量-伏安法

一句话：伏安法用电流表和电压表同时测量待测电阻两端的电压和通过的电流，再由R=U/I计算电阻。 English: The volt-ammeter method measures voltage across and current through a resistor simultaneously, then calculates resistance using R=U/I.

📚 给 6-12 岁（自读版）

如何测量一个未知电阻的阻值？

用伏安法：同时用电压表和电流表测量，再用欧姆定律计算！

实验步骤： 1. 按电路图连接：待测电阻 $R_x$ 串联电流表，两端并联电压表，再串联滑动变阻器和开关 2. 闭合开关，调节滑动变阻器，读取电压表和电流表的示数（多次测量） 3. 用公式计算：$R_x = U/I$ 4. 多次测量取平均值，减小误差

为什么要多次测量？ 减少测量误差，结果更准确。

🎓 给 12+（进阶版）

实验原理

$$R_x = \frac{U}{I}$$

通过测量 $R_x$ 两端电压 $U$ 和通过电流 $I$，由欧姆定律求 $R_x$。

实验电路（两种接法）

安培表外接法（适合大电阻）： - 电流表在电压表外侧 - 电压表测的是 $R_x$ 两端的真实电压 - 电流表测的是 $R_x$ 和电压表的总电流（偏大） - 测量值：$R_{测} = U / I_{总} < R_x$（偏小） - 适用于 $R_x >> R_V$ 的情况（$R_V$ 为电压表内阻）

安培表内接法（适合小电阻）： - 电流表在电压表内侧 - 电流表测的是 $R_x$ 的真实电流 - 电压表测的是 $R_x$ 和电流表的总电压（偏大） - 测量值：$R_{测} = U_{总} / I > R_x$（偏大） - 适用于 $R_x << R_A$ 的情况（$R_A$ 为电流表内阻）

接法选择口诀： - $R_x > \sqrt{R_A R_V}$：外接法（大电阻外接） - $R_x < \sqrt{R_A R_V}$：内接法（小电阻内接）

初中阶段通常用外接法，定性了解误差来源即可。

实验器材

  • 待测电阻 $R_x$
  • 电流表（安培表）
  • 电压表（伏特表）
  • 滑动变阻器（用于调节电压）
  • 电源（电池组）
  • 开关
  • 导线

实验步骤

  1. 按电路图连接，开关断开，滑动变阻器调到最大阻值
  2. 检查接线（尤其是电流表和电压表的正负极）
  3. 闭合开关，调节滑动变阻器，记录多组（$U, I$）数据
  4. 计算各次 $R = U/I$，取平均值
  5. 作 $U$-$I$ 图像，图线斜率 = $R$（更准确）

数据处理

逐次计算：$R_i = U_i / I_i$，再取平均 $\bar{R} = \frac{1}{n}\sum R_i$

图像法：在坐标纸上画 $I$-$U$ 图像（或 $U$-$I$ 图像），拟合直线： - $I$-$U$ 图：斜率 = $1/R$ - $U$-$I$ 图：斜率 = $R$

典型例题

例：用伏安法测量电阻，得到如下数据：

次数 U（V） I（A） R（Ω）
1 2.0 0.20 10.0
2 3.0 0.29 10.3
3 4.0 0.40 10.0

$$\bar{R} = \frac{10.0 + 10.3 + 10.0}{3} \approx 10.1 \text{ Ω}$$

易错点： - 电流表必须串联，电压表必须并联（接法绝对不能弄反） - 实验开始前滑动变阻器要调到最大阻值（保护电路） - 读数要在指针稳定后再读，记录数据要加单位

词汇

伏安法 volt-ammeter method n. The volt-ammeter method measures both voltage and current.
外接法 external connection n. Use external connection for large resistances.
