氯气

权重7吉林命中0路径2学段[高中]主题[必修一, 第二章]

aliases: 氯气, chlorine, Cl₂, 氯

氯气

一句话：黄绿色有毒气体，强氧化性，与水、碱、金属发生多种重要反应，是重要的工业原料。 English: A yellow-green toxic gas with strong oxidizing ability; reacts with water, bases, and metals in many important ways; a key industrial material.

🎓 高中进阶

基本信息

属性 数据
化学式 Cl₂
颜色气味 黄绿色，有强烈刺激性气味
毒性 有毒（吸入高浓度Cl₂有生命危险）
密度 3.214 g/L（比空气重，约空气密度2.5倍）
溶解性 能溶于水（1体积水约溶1体积Cl₂）
化合价 0价（单质）

物理性质

  • 黄绿色气体，有毒，强刺激性
  • 密度大于空气（故收集时可向下排气）
  • 常温常压下为气体，加压可液化为液氯（黄绿色液体）

化学性质

1. 与H₂反应（合成HCl）： $$\text{Cl}_2 + \text{H}_2 \xrightarrow{\text{点燃}} 2\text{HCl}$$

2. 与金属反应（强氧化性）： $$2\text{Fe} + 3\text{Cl}_2 \xrightarrow{\text{点燃}} 2\text{FeCl}_3$$（铁被氧化为+3价，而不是+2价） $$2\text{Na} + \text{Cl}_2 \xrightarrow{\text{点燃}} 2\text{NaCl}$$ $$\text{Cu} + \text{Cl}_2 \xrightarrow{\text{点燃}} \text{CuCl}_2$$

3. 与水反应（氯水的成分）： $$\text{Cl}_2 + \text{H}_2\text{O} \rightleftharpoons \text{HCl} + \text{HClO}$$

4. 与NaOH反应（制漂白粉原理）： $$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$$

5. 与Ca(OH)₂反应（制漂白粉）： $$2\text{Cl}_2 + 2\text{Ca(OH)}_2 \rightarrow \text{Ca(ClO)}_2 + \text{CaCl}_2 + 2\text{H}_2\text{O}$$

氧化性强弱

$$\text{Cl}_2 > \text{Br}_2 > \text{I}_2$$（卤素从上到下氧化性减弱）

Cl₂能将Br⁻氧化为Br₂：$\text{Cl}_2 + 2\text{KBr} \rightarrow 2\text{KCl} + \text{Br}_2$ Cl₂能将I⁻氧化为I₂：$\text{Cl}_2 + 2\text{KI} \rightarrow 2\text{KCl} + \text{I}_2$

尾气处理

Cl₂有毒，实验后尾气必须用NaOH溶液吸收： $$\text{Cl}_2 + 2\text{NaOH} \rightarrow \text{NaCl} + \text{NaClO} + \text{H}_2\text{O}$$

典型例题

例1：Cl₂通入NaBr溶液，发生什么反应？

$$\text{Cl}_2 + 2\text{NaBr} \rightarrow 2\text{NaCl} + \text{Br}_2$$

现象：溶液变橙黄色（Br₂）；Cl₂强氧化性将Br⁻氧化为Br₂。

例2：铁在氯气中燃烧，为什么生成FeCl₃而不是FeCl₂？

分析：Cl₂是强氧化剂，能将Fe氧化到最高化合价+3价，故生成FeCl₃。

易错点 / 拓展

  • 铁与盐酸（HCl）→ FeCl₂（Fe过量时，H⁺氧化性弱）
  • 铁与Cl₂（足量）→ FeCl₃（Cl₂氧化性强）
  • Cl₂不稳定，光照加速分解（HClO分解）：2HClO →(光) 2HCl + O₂
  • Cl₂泄漏处理：用湿布（含Na₂CO₃）捂住口鼻，向上风方向撤离
