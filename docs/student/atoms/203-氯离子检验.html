氯离子检验

一句话：用AgNO₃溶液检验Cl⁻，生成白色AgCl沉淀（不溶于稀硝酸），是鉴定Cl⁻的标准方法。 English: Cl⁻ is detected using AgNO₃ solution, forming a white AgCl precipitate insoluble in dilute nitric acid.

🎓 高中进阶

检验原理

$$\text{Ag}^+ + \text{Cl}^- \rightarrow \text{AgCl}\downarrow$$

AgCl是白色沉淀，不溶于稀硝酸（即使加入稀HNO₃也不溶解），这是关键鉴别特征。

标准操作步骤

  1. 取少量待测溶液于试管中
  2. 加入足量稀硝酸（HNO₃）酸化（排除CO₃²⁻、SO₃²⁻等干扰）
  3. 加入适量AgNO₃溶液
  4. 观察：若出现白色沉淀且加稀HNO₃不溶解 → 证明含有Cl⁻

为什么先加稀硝酸？ - 排除CO₃²⁻（Ag₂CO₃白色沉淀，溶于稀HNO₃） - 排除SO₄²⁻（BaSO₄白色沉淀，但SO₄²⁻不与Ag⁺沉淀；此处主要排除CO₃²⁻） - 排除OH⁻（AgOH沉淀，溶于HNO₃）

不用盐酸或稀硫酸酸化，因为会引入Cl⁻或SO₄²⁻干扰。

AgCl vs 其他卤化银

沉淀 颜色 溶于稀HNO₃ 溶于NH₃·H₂O
AgCl 白色 不溶 溶
AgBr 淡黄色 不溶 微溶
AgI 黄色 不溶 不溶
Ag₂CO₃ 白色 溶（放CO₂） —

典型例题

例1：检验盐酸中的Cl⁻，应如何操作？

分析：取盐酸溶液，先加稀HNO₃（盐酸本身是酸，已足够酸性，可直接加AgNO₃），再加AgNO₃溶液，出现白色沉淀（AgCl）且不溶于稀HNO₃，证明含Cl⁻。

注意：若直接加AgNO₃，不加稀HNO₃酸化，则结果也可（盐酸已是酸性），但标准步骤要加稀HNO₃。

例2：检验NaCl固体中是否混有Na₂CO₃？

分析： 方法一：取样溶于水，加稀HNO₃酸化后加AgNO₃，若有白色沉淀→Cl⁻（NaCl）；另取样加稀盐酸，若冒气泡→CO₃²⁻（Na₂CO₃）。 方法二：向样品中加稀HCl，若有气泡→含Na₂CO₃。

易错点

  • 加AgNO₃前必须先用稀HNO₃（不能用稀HCl或稀H₂SO₄）酸化
  • AgCl不溶于稀HNO₃，溶于浓氨水（形成[Ag(NH₃)₂]⁺）
  • Ag₂CO₃也是白色沉淀，加稀HNO₃溶解（区别于AgCl）
  • 氯水中的Cl⁻来自HCl（Cl₂+H₂O→HCl+HClO），也能被AgNO₃检出
