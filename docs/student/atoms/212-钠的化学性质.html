钠的化学性质

一句话：钠是最活泼的金属之一，能与O₂、H₂O、酸、非金属等多种物质发生剧烈反应。 English: Sodium is one of the most reactive metals, reacting vigorously with oxygen, water, acids, and many nonmetals.

核心化学性质总览

反应对象 条件 产物 方程式
O₂（常温） 空气中 Na₂O（白色） 4Na + O₂ → 2Na₂O
O₂（点燃） 点燃 Na₂O₂（淡黄色） 2Na + O₂ →(点燃) Na₂O₂
H₂O 常温 NaOH + H₂↑ 2Na + 2H₂O → 2NaOH + H₂↑
盐酸 常温 NaCl + H₂↑ 2Na + 2HCl → 2NaCl + H₂↑
Cl₂ 点燃 NaCl 2Na + Cl₂ →(点燃) 2NaCl
S 研磨 Na₂S（剧烈） 2Na + S → Na₂S
乙醇 常温 C₂H₅ONa + H₂↑ 2Na + 2C₂H₅OH → 2C₂H₅ONa + H₂↑

与O₂反应的特殊性

条件 产物 颜色
常温暴露空气 Na₂O（再继续→Na₂CO₃） 白色
点燃 Na₂O₂ 淡黄色

Na在空气中的变化过程： $$\text{Na} \xrightarrow{\text{常温}} \text{Na}_2\text{O} \xrightarrow{\text{H}_2\text{O}} \text{NaOH} \xrightarrow{\text{CO}_2} \text{Na}_2\text{CO}_3 \cdot n\text{H}_2\text{O} \xrightarrow{\text{失水}} \text{Na}_2\text{CO}_3$$

Na加入盐溶液

Na与盐溶液（如CuSO₄）反应：Na先与水反应，不能直接置换金属。

$$2\text{Na} + 2\text{H}_2\text{O} \rightarrow 2\text{NaOH} + \text{H}_2\uparrow$$ $$2\text{NaOH} + \text{CuSO}_4 \rightarrow \text{Cu(OH)}_2\downarrow + \text{Na}_2\text{SO}_4$$

现象：钠浮在液面、熔化为小球、游动、有气泡，最终出现蓝色沉淀。

典型例题

例1：钠在空气中久置后，最终变成什么？

分析：Na → Na₂O → NaOH → Na₂CO₃（最终稳定产物）。若空气潮湿，Na₂CO₃可能潮解为Na₂CO₃溶液。

例2：0.1 mol Na放入足量水中，收集到H₂多少mL（标准状况）？

$$2\text{Na} + 2\text{H}_2\text{O} \rightarrow 2\text{NaOH} + \text{H}_2\uparrow$$ 0.1 mol Na → 0.05 mol H₂ → V = 0.05 × 22400 = 1120 mL

易错点

  • Na与酸反应比与水反应更剧烈（H⁺浓度更大）
  • Na加入FeCl₃：不是置换Fe，而是先与水反应后与FeCl₃沉淀
  • Na₂O₂中氧为-1价，不是普通氧化物（-2价）
  • Na在S上会燃烧爆炸（研磨Na与S时危险）
