硝酸

权重5吉林命中0路径1学段[高中]主题[必修一, 第四章]

aliases: 硝酸, nitric acid, HNO₃, 亚硝酸盐

硝酸

一句话：强酸，具有强氧化性，与大多数金属（除Pt、Au）和非金属反应，浓HNO₃氧化性比稀HNO₃强，Fe/Al在冷浓HNO₃中钝化。 English: A strong acid with strong oxidizing properties; reacts with most metals (except Pt and Au) and nonmetals; concentrated HNO₃ is more oxidizing than dilute; Fe and Al are passivated in cold concentrated HNO₃.

🎓 高中进阶

基本信息

属性 稀HNO₃ 浓HNO₃
浓度 < 65% ≥ 65%
颜色 无色 淡黄色（含溶解NO₂）
特点 强酸通性+强氧化性 极强氧化性，挥发性强
与Cu 3Cu + 8HNO₃(稀) → Cu(NO₃)₂ + 2NO↑ Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂↑
产生气体 NO（无色） NO₂（红棕色）

化学性质

1. 酸性（强酸，完全电离）： $$\text{HNO}_3 \rightarrow \text{H}^+ + \text{NO}_3^-$$

2. 强氧化性（与金属）： 稀HNO₃与铜： $$3\text{Cu} + 8\text{HNO}_3(\text{稀}) \rightarrow 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$$

浓HNO₃与铜： $$\text{Cu} + 4\text{HNO}_3(\text{浓}) \rightarrow \text{Cu(NO}_3)_2 + 2\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$

3. 与非金属反应（强氧化性）： $$\text{C} + 4\text{HNO}_3(\text{浓}) \xrightarrow{\Delta} \text{CO}_2\uparrow + 4\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$ $$\text{S} + 6\text{HNO}_3(\text{浓}) \xrightarrow{\Delta} \text{H}_2\text{SO}_4 + 6\text{NO}_2\uparrow + 2\text{H}_2\text{O}$$

4. 与Fe/Al（钝化）： Fe和Al在冷浓HNO₃中钝化（形成致密氧化膜），不继续反应。

与稀HNO₃（铁）： $$\text{Fe} + 4\text{HNO}_3(\text{稀}) \rightarrow \text{Fe(NO}_3)_3 + \text{NO}\uparrow + 2\text{H}_2\text{O}$$ （Fe被氧化到+3价，因HNO₃氧化性强）

王水（aqua regia）

王水：浓HNO₃和浓HCl的混合物（体积比1:3）。能溶解金（Au）和铂（Pt）： $$\text{Au} + \text{HNO}_3 + 3\text{HCl} \rightarrow \text{AuCl}_3 + \text{NO}\uparrow + 2\text{H}_2\text{O}$$

光照分解

HNO₃在光照下分解： $$4\text{HNO}_3 \xrightarrow{\text{光}} 4\text{NO}_2\uparrow + \text{O}_2\uparrow + 2\text{H}_2\text{O}$$

（浓HNO₃久置变黄：产生NO₂溶于HNO₃使之变黄）→ HNO₃应棕色瓶避光保存

典型例题

例1：足量铁与足量稀HNO₃反应，产物是Fe(NO₃)₂还是Fe(NO₃)₃？

分析： - 稀HNO₃氧化性强，将Fe氧化到Fe³⁺（+3价） - 但若Fe过量，多余Fe与Fe³⁺反应：Fe + 2Fe³⁺ → 3Fe²⁺ - 足量铁时，最终Fe³⁺全部转化为Fe²⁺，产物为Fe(NO₃)₂

例2：1 mol Cu与过量稀HNO₃反应，产生多少mol NO？

$$3\text{Cu} + 8\text{HNO}_3(\text{稀}) \rightarrow 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$$ 1 mol Cu → 2/3 mol NO = 0.667 mol NO

易错点

  • 铁与稀HNO₃：产物Fe³⁺（不是Fe²⁺，HNO₃强氧化性）
  • 铁与稀盐酸：产物Fe²⁺
  • Fe在冷浓HNO₃中钝化，不溶解
  • 浓HNO₃产生NO₂（红棕色气体），稀HNO₃产生NO（无色气体）

中文 English
铜与稀硝酸反应生成无色的一氧化氮气体。 Copper reacts with dilute nitric acid to produce colorless nitric oxide gas.
