硫酸（高中）

一句话：强酸，稀H₂SO₄具有酸的通性，浓H₂SO₄具有吸水性、脱水性和强氧化性，是重要工业化工原料。 English: A strong acid; dilute H₂SO₄ has typical acid properties, while concentrated H₂SO₄ has hygroscopic, dehydrating, and strongly oxidizing properties; an important industrial chemical.

稀H₂SO₄的性质（酸的通性）

$$\text{Zn} + \text{H}_2\text{SO}_4 \rightarrow \text{ZnSO}_4 + \text{H}_2\uparrow$$ $$\text{Fe}_2\text{O}_3 + 3\text{H}_2\text{SO}_4 \rightarrow \text{Fe}_2(\text{SO}_4)_3 + 3\text{H}_2\text{O}$$ $$\text{H}_2\text{SO}_4 + 2\text{NaOH} \rightarrow \text{Na}_2\text{SO}_4 + 2\text{H}_2\text{O}$$

浓H₂SO₄的特殊性质

1. 吸水性（用作干燥剂）： - 能吸收气体中的水蒸气，用于干燥大多数气体（除碱性气体NH₃，不能干燥Br₂、HI、H₂S等） - 稀释时大量放热：酸入水，水入酸会爆炸（应将浓H₂SO₄沿壁缓慢倒入水中并搅拌）

2. 脱水性（使有机物碳化）： $$\text{C}{12}\text{H})$$}\text{O}_{11} \xrightarrow{\text{浓H}_2\text{SO}_4} 12\text{C} + 11\text{H}_2\text{O}\quad(\text{蔗糖变黑碳化

浓H₂SO₄按氢氧原子2:1比例脱去有机物中的H和O，使之碳化。

3. 强氧化性（加热时与金属/非金属反应）： $$\text{Cu} + 2\text{H}_2\text{SO}_4(\text{浓}) \xrightarrow{\Delta} \text{CuSO}_4 + \text{SO}_2\uparrow + 2\text{H}_2\text{O}$$ $$\text{C} + 2\text{H}_2\text{SO}_4(\text{浓}) \xrightarrow{\Delta} \text{CO}_2\uparrow + 2\text{SO}_2\uparrow + 2\text{H}_2\text{O}$$ $$\text{S} + 2\text{H}_2\text{SO}_4(\text{浓}) \xrightarrow{\Delta} 3\text{SO}_2\uparrow + 2\text{H}_2\text{O}$$

Fe和Al在冷浓H₂SO₄中钝化（生成致密氧化膜，停止反应）→可用铁罐或铝罐运输浓H₂SO₄

检验SO₄²⁻

方法：加稀盐酸酸化（排除CO₃²⁻干扰），再加BaCl₂溶液： $$\text{Ba}^{2+} + \text{SO}_4^{2-} \rightarrow \text{BaSO}_4\downarrow\quad(\text{白色沉淀，不溶于稀HNO₃})$$

典型例题

例1：如何将浓H₂SO₄稀释为稀H₂SO₄？

分析：将浓H₂SO₄缓慢沿壁倒入水中，同时用玻璃棒搅拌散热。（切勿将水倒入浓H₂SO₄，会局部沸腾飞溅，危险）

例2：Cu与浓H₂SO₄加热，停止反应后能否用冷却方法继续反应？

分析：不能。Cu溶解后，浓H₂SO₄变稀（稀H₂SO₄不能氧化Cu），反应会停止；加热虽然促进，但随着浓度降低，最终停止。

易错点

  • 稀释浓H₂SO₄：酸入水（不能水入酸）
  • 浓H₂SO₄使蔗糖变黑是脱水碳化，不是氧化反应
  • Fe在冷浓H₂SO₄中钝化（不反应），在稀H₂SO₄中反应生成FeSO₄
  • 干燥HBr、HI、H₂S不能用浓H₂SO₄（会氧化这些气体）
