总览数学物理化学生物

烃

权重4吉林命中0路径1学段[高中]主题[必修二, 第七章]

aliases: 烃, hydrocarbon, 碳氢化合物

烃

一句话：烃是只含碳（C）和氢（H）两种元素的有机化合物，是有机化学的基础，分为烷烃、烯烃、炔烃、芳香烃等类型。 English: A hydrocarbon is an organic compound containing only carbon (C) and hydrogen (H) atoms, forming the foundation of organic chemistry, classified into alkanes, alkenes, alkynes, and aromatic hydrocarbons.

🎓 高中进阶

定义

烃（hydrocarbon）：组成元素只有碳（C）和氢（H）的有机化合物。

$$\text{通式：} C_n H_m \quad (m \leq 2n+2)$$

烃的分类

按碳骨架分：

类型 特征 举例
链烃（脂肪烃） 碳原子连接成链状 CH₄、C₂H₄、C₂H₂
环烃 碳原子连接成环状 环己烷、苯

按饱和度分：

类型 碳键特征 通式（链状） 举例
烷烃 全为C-C单键（饱和） CₙH₂ₙ₊₂ CH₄、C₂H₆
烯烃 含C=C双键 CₙH₂ₙ C₂H₄（乙烯）
炔烃 含C≡C三键 CₙH₂ₙ₋₂ C₂H₂（乙炔）
芳香烃 含苯环 — C₆H₆（苯）

烃的通性

性质 说明
物理性质 碳链越长，沸点越高；C1-C4气态，C5-C17液态，C18+固态
溶解性 不溶于水，溶于有机溶剂（"相似相溶"）
密度 液态烃密度小于水（浮在水面）
可燃性 几乎所有烃都能燃烧
化学反应 烷烃：取代反应；烯烃：加成反应；芳烃：取代、加成

烃的燃烧通式

$$C_nH_m + (n + \frac{m}{4})O_2 \rightarrow nCO_2 + \frac{m}{2}H_2O$$

烷烃燃烧（通式）：

$$C_nH_{2n+2} + \frac{3n+1}{2}O_2 \rightarrow nCO_2 + (n+1)H_2O$$

烃燃烧产物的判断： - n(CO₂)/n(H₂O) > 1：烃中C比H多（可能含苯环或炔键） - n(CO₂)/n(H₂O) = 1：烯烃通式（CₙH₂ₙ） - n(CO₂)/n(H₂O) < 1：烷烃（CₙH₂ₙ₊₂）

各类烃的代表物

烃类 代表物 化学式 主要来源
烷烃 甲烷 CH₄ 天然气
烯烃 乙烯 C₂H₄ 石油裂解
炔烃 乙炔 C₂H₂ 电石与水反应
芳烃 苯 C₆H₆ 煤焦油

典型例题

例1：某烃完全燃烧，生成CO₂和H₂O的物质的量之比为1:2，该烃的通式是什么？

分析： 设烃为CₙHₘ，燃烧：CₙHₘ + O₂ → nCO₂ + m/2 H₂O n(CO₂):n(H₂O) = n : m/2 = 1 : 2 → n : m/2 = 1 : 2 → m = 4n 通式：CₙH₄ₙ（即m = 4n）

若为链状：烯烃通式 CₙH₂ₙ不满足（需m=4n，即 2n=4n，不成立） 实际若 n(CO₂)/n(H₂O) = 1/2 < 1，说明H比C多，符合烷烃规律，但需具体验证。 （建议学生验证：CH₄：n(CO₂)/n(H₂O) = 1/2，满足）

例2：苯（C₆H₆）是饱和烃还是不饱和烃？

分析：从分子式 C₆H₆ 看，饱和烷烃 C₆H₁₄，H少得多，似乎是不饱和的。但苯不是简单的含双键/三键的烃，而是有特殊的苯环结构（共轭体系），性质介于饱和与不饱和之间。通常将苯归类为芳香烃而非简单不饱和烃。

易错点

  • 烃只含C和H，含其他元素（如O）的是烃的衍生物
  • 苯不是普通烯烃，不能用一般烯烃加成规律
  • 液态烃浮在水面（密度<水），不溶于水
