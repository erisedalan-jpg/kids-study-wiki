分子的极性

分子的极性

一句话：分子的极性由分子的空间结构决定：若分子中各极性键的偶极矩向量之和不为零，则为极性分子；否则为非极性分子。 English: Molecular polarity is determined by molecular geometry: if the vector sum of bond dipoles is nonzero, the molecule is polar; otherwise it is nonpolar.

🎓 高中进阶

定义

类型 定义 判断标准
极性分子 分子中正负电荷中心不重合 偶极矩 ≠ 0
非极性分子 分子中正负电荷中心重合 偶极矩 = 0

关键：分子极性 = 键的极性 + 分子空间构型

判断方法

法1：对称性法 - 分子结构完全对称（相同原子对称分布）→ 非极性分子 - 分子结构不对称 → 极性分子

法2：中心原子是否有孤对电子 - 有孤对电子 → 结构不对称 → 通常为极性分子 - 无孤对电子（且所有端原子相同）→ 通常为非极性分子

常见分子极性判断

分子 空间构型 极性 原因
H₂ 线型（相同原子） 非极性 无极性键
HCl 线型 极性 不对称
CO₂ 直线型（对称） 非极性 C=O键向量抵消
H₂O V形（有孤对电子） 极性 O-H向量不抵消
NH₃ 三角锥形（N有孤对） 极性 N-H向量不抵消
CH₄ 正四面体（对称） 非极性 C-H键向量抵消
CCl₄ 正四面体（对称） 非极性 C-Cl向量抵消
CHCl₃ 四面体（不对称） 极性 不对称

极性与溶解性（相似相溶原理）

溶质 溶剂 溶解性
极性分子（HCl、NH₃） 极性溶剂（H₂O） 溶（极溶极）
非极性分子（I₂、苯） 非极性溶剂（CCl₄、苯） 溶（非溶非）
非极性分子（I₂） 极性溶剂（H₂O） 难溶

典型例题

例1：CO₂含有极性键（C=O），为什么CO₂是非极性分子？

分析： - CO₂分子为直线型：O=C=O - 两个C=O极性键的偶极矩大小相等，方向相反（180°），向量和为零 - 正负电荷中心重合 → 非极性分子

例2：比较H₂O和CO₂在水中的溶解性，用极性解释。

分析： - H₂O（极性溶剂）可以溶解极性分子 - H₂O为极性分子（偶极矩≠0）→ 易溶于水（同极相溶） - CO₂为非极性分子 → 在水中溶解度较小 - 实验：CO₂溶于水生成H₂CO₃，发生化学反应，实际溶解度较非极性溶剂中大

易错点

  • 含极性键 ≠ 极性分子（CO₂、CCl₄含极性键但是非极性分子）
  • 只含非极性键 ≠ 一定是非极性分子（但非极性单质分子如H₂确实是非极性的）
  • 极性的判断必须结合空间构型
