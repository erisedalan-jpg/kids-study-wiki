周期

一句话：周期是元素周期表中的横行，同一周期元素的电子层数相同，从左到右原子序数递增，性质呈规律性变化。 English: A period is a horizontal row in the periodic table; elements in the same period have the same number of electron shells, with atomic numbers increasing from left to right.

🎓 高中进阶

定义

元素周期表共有7个周期，每个周期对应一个电子层。同一周期的元素，最外层电子从1个增加到8个（第1周期从1增到2），体现从活泼金属到稀有气体的完整过渡。

各周期概览

第1周期 2 短周期 1 H、He
第2周期 8 短周期 2 Li→Ne
第3周期 8 短周期 3 Na→Ar
第4周期 18 长周期 4 K→Kr（含3d过渡金属）
第5周期 18 长周期 5 Rb→Xe
第6周期 32 长周期 6 Cs→Rn（含镧系14种）

典型例题

例1：已知某元素位于第3周期，其原子最外层有3个电子，判断该元素名称及其氧化物的性质。

分析：第3周期最外层3个电子 → 第ⅢA族 → Al（铝） - Al₂O₃为两性氧化物，既与酸反应也与碱反应： - Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O - Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O

例2：第2周期和第3周期的元素各有多少种，为什么数量不同？

分析： - 第2周期：填充2s²2p⁶，共8种（Li到Ne） - 第3周期：填充3s²3p⁶，共8种（Na到Ar） - 第4周期：增加了3d轨道（10个电子），共18种 - 元素数量 = 该周期可容纳的电子数

易错点

  • 周期数 = 电子层数（不是族序数）
  • 第6、7周期的镧系、锕系元素分别单独列出，不计入主表列数
  • "短周期"特指第1、2、3周期，"长周期"是第4、5、6、7周期
