带电粒子在电场中偏转

权重3吉林命中0路径0学段[高中]主题[必修三, 静电场深化]

aliases: 带电粒子在电场中偏转, deflection of charged particle in electric field, 电场偏转, 带电粒子在电场中的偏转

🎓 带电粒子在电场中偏转

物理模型

带电粒子以初速度 $v_0$（水平方向）进入匀强电场，电场方向垂直于初速度。粒子做类平抛运动：水平方向匀速，竖直方向（沿电场力方向）匀加速。

运动分析

设极板长度为 $L$，极板间距为 $d$，极板间电压为 $U$，粒子质量 $m$，电荷量 $q$。

水平方向（匀速）：

$$x = v_0 t \Rightarrow t = \frac{L}{v_0}$$

竖直方向（匀加速）：

加速度：

$$a = \frac{qE}{m} = \frac{qU}{md}$$

偏转位移（在极板内）：

$$y_1 = \frac{1}{2}at^2 = \frac{qUL^2}{4mdv_0^2}$$

离开极板时竖直速度：

$$v_y = at = \frac{qUL}{mdv_0}$$

偏转角（离开极板时）：

$$\tan\theta = \frac{v_y}{v_0} = \frac{qUL}{mdv_0^2}$$

屏上偏移量

设离开极板后再飞行距离 $l$ 到达荧光屏：

$$y_2 = l\tan\theta = \frac{qULl}{mdv_0^2}$$

总偏移：

$$y = y_1 + y_2 = \frac{qUL^2}{4mdv_0^2} + \frac{qULl}{mdv_0^2}$$

与类平抛运动对比

量 类平抛（重力场） 电场偏转
水平加速度 0 0
竖直加速度 $g$ $qU/(md)$
轨迹 抛物线 抛物线

典型例题

例：示波管偏转板长 $L = 4\,\text{cm}$，板间距 $d = 1\,\text{cm}$，电压 $U = 200\,\text{V}$，电子以 $v_0 = 10^7\,\text{m/s}$ 水平射入，求极板内偏转位移 $y_1$。

$$a = \frac{eU}{md} = \frac{1.6\times10^{-19}\times200}{9.1\times10^{-31}\times0.01} \approx 3.52\times10^{15}\,\text{m/s}^2$$

$$t = \frac{L}{v_0} = \frac{0.04}{10^7} = 4\times10^{-9}\,\text{s}$$

$$y_1 = \frac{1}{2}at^2 = \frac{1}{2}\times3.52\times10^{15}\times(4\times10^{-9})^2 \approx 0.028\,\text{m} = 2.8\,\text{cm}$$

（注：此值已接近 $d/2$，实际需验证粒子不打到极板上）

易错点

  • 电场偏转是类平抛，水平方向速度不变，竖直方向匀加速，两方向运动相互独立。
  • 偏转角公式 $\tan\theta = v_y/v_0$，注意分析的是离开电场时的速度方向。
  • 粒子必须从两极板正中间射入时才不会打到板上（需验证 $y_1 < d/2$）。

与必修二衔接

必修二学习了抛体运动（分运动合成）；本节将重力替换为电场力，模型完全相同，是力学运动学在电学中的典型应用。

🎓 考点精讲

定义/原理
带电粒子（质量 $m$、电量 $q$，不计重力）以初速度 $v_0$ 垂直射入匀强电场 $E$（两极板间电压 $U$，板长 $l$，板间距 $d$），粒子受恒定电场力 $F=qE=\frac{qU}{d}$，沿电场方向产生恒定的加速度 $a=\frac{qU}{md}$。运动可分解为：垂直电场方向匀速直线运动 $x=v_0 t$；沿电场方向初速为零的匀加速直线运动 $y=\frac{1}{2}at^2$。
联立得偏转位移公式：$y=\frac{qU}{2md v_0^2}x^2$（抛物线），射出电场瞬间偏移量 $y_1=\frac{qUl^2}{2md v_0^2}$，出射速度偏转角 $\tan\theta=\frac{v_y}{v_0}=\frac{qUl}{md v_0^2}$。

关键方法
采用类平抛运动处理：正交分解为匀速和匀变速两个独立分量；抓住时间桥梁 $t=\frac{l}{v_0}$；求解偏转量、偏转角常结合几何关系（如离开电场后匀速直线打到屏上，利用“速度反向延长线交水平位移中点”）。题目中若粒子从静止经加速电压 $U_1$ 再进入偏转电场 $U_2$，常代入 $v_0=\sqrt{\frac{2qU_1}{m}}$，得 $y_1=\frac{U_2 l^2}{4dU_1}$，$\tan\theta=\frac{U_2 l}{2dU_1}$，与粒子比荷无关（常用于示波管等）。

典型应用
高考常考：示波管模型中电子束偏转并打在荧光屏上的位移；带电粒子能否飞离极板（临界问题：$y_1\le\frac{d}{2}$）；多个粒子（不同比荷、不同初速）偏转轨迹比较；交变电场中的偏转（需判断运动过程中电场是否恒定或视为瞬时偏转）。解题常结合动能定理与类平抛运动规律。

⚠️ 高频易错点

  • 未判断是否计重力：带电粒子无特殊说明不计重力，带电微粒（如油滴、小球）一般需考虑重力，错用类平抛将导致方程缺失重力项。
  • 混淆偏转位移与偏转角：直接从 $y_1$ 和 $\theta$ 的表达式错误约分或代入几何关系求屏上位移时用错相似比，忽略粒子出场后匀速直线运动的延长线规律。
  • 忽略临界条件：将板长或板间距混淆，求“能否飞出”时误用偏转位移大于板长等错误判断；正确应比较 $y_1$ 与 $\frac{d}{2}$。
  • 交变电场中误当恒定：未分析电压变化周期与粒子穿行时间的关系，直接套用恒定偏转公式；解决时应先比较 $t$ 与周期，再分段或取平均。
