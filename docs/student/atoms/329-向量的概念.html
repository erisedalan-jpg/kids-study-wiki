🎓 向量的概念

定义

向量（vector）是既有大小又有方向的量。

  • 只有大小没有方向的量称为标量（scalar），如温度、质量、时间
  • 向量用有向线段 $\overrightarrow{AB}$ 表示，$A$ 为起点，$B$ 为终点
  • 向量也可记作粗体字母 $\boldsymbol{a}$ 或 $\vec{a}$

向量的大小（模）

向量 $\overrightarrow{AB}$ 的大小称为该向量的模，记作 $|\overrightarrow{AB}|$ 或 $|\boldsymbol{a}|$。

  • 零向量：模为 0 的向量，记作 $\boldsymbol{0}$；零向量的方向任意
  • 单位向量：模为 1 的向量

向量相等

若两个向量 $\boldsymbol{a}$ 和 $\boldsymbol{b}$ 的大小相等且方向相同，则称 $\boldsymbol{a} = \boldsymbol{b}$。

注意：向量相等与起点无关，可以平移。这样的向量称为自由向量。

共线向量（平行向量）

方向相同或相反的向量称为共线向量，也叫平行向量，记作 $\boldsymbol{a} \parallel \boldsymbol{b}$。

规定：零向量与任意向量平行。

典型例题

例1：判断下列说法是否正确：
（1）模相等的向量一定相等；（2）起点相同、终点相同的向量一定相等。

解：
（1）错误。模相等但方向不同的两向量不相等（如 $\overrightarrow{AB}$ 与 $\overrightarrow{BA}$）。
（2）正确。起点终点均相同，大小方向均相同，故相等。

例2：下列哪些是向量？哪些是标量？
速度（vector）、路程（scalar）、位移（vector）、时间（scalar）、力（vector）。

易错点

  • 向量"相等"强调方向相同（不是反向），而"共线"允许反向
  • 零向量的方向不定，但与任意向量平行
  • 向量与位移一样可以平移，不依附于特定起点

与初中衔接

初中学习了有理数的正负表示相反方向的量（如路程正负），高中向量将"方向"推广到平面任意方向，是向量代数的起点。
