🎓 复数的几何意义

复平面

建立平面直角坐标系，将复数 $z = a + b\text{i}$ 对应平面上的点 $Z(a, b)$：

  • $x$ 轴称为实轴（real axis）：表示实部
  • $y$ 轴称为虚轴（imaginary axis）：表示虚部
  • 此坐标平面称为复平面（complex plane），又称高斯平面

对应关系： $$z = a + b\text{i} \longleftrightarrow Z(a, b) \longleftrightarrow \overrightarrow{OZ}$$

每个复数对应复平面上唯一一个点，也对应从原点出发的唯一一个向量。

复数的模

复数 $z = a + b\text{i}$ 的模（绝对值）：

$$|z| = |a + b\text{i}| = \sqrt{a^2 + b^2}$$

几何意义：点 $Z(a, b)$ 到原点的距离。

共轭复数

$z = a + b\text{i}$ 的共轭复数：

$$\bar{z} = a - b\text{i}$$

几何意义：$Z$ 关于实轴的对称点。

性质： $$z + \bar{z} = 2a \in \mathbb{R}, \quad z \cdot \bar{z} = a^2 + b^2 = |z|^2$$

复数的辐角

向量 $\overrightarrow{OZ}$ 与正实轴正方向的夹角 $\theta$ 称为复数 $z$ 的辐角（argument）：

$$\cos\theta = \frac{a}{|z|}, \quad \sin\theta = \frac{b}{|z|}$$

辐角不唯一（相差 $2k\pi$），主辐角范围 $(-\pi, \pi]$。

两复数对应点的距离

$z_1 = a_1 + b_1\text{i}$，$z_2 = a_2 + b_2\text{i}$ 对应点 $Z_1, Z_2$ 的距离：

$$|z_1 - z_2| = \sqrt{(a_1-a_2)^2 + (b_1-b_2)^2}$$

典型例题

例1：在复平面内画出 $z_1 = 2 + 3\text{i}$，$z_2 = -1 - \text{i}$ 对应的点，并求两点距离。

解：$Z_1(2, 3)$，$Z_2(-1, -1)$，$|z_1 - z_2| = \sqrt{9 + 16} = 5$

例2：复数 $z = 1 - \sqrt{3}\text{i}$ 的模和辐角。

解：$|z| = \sqrt{1 + 3} = 2$，$\cos\theta = \frac{1}{2}$，$\sin\theta = -\frac{\sqrt{3}}{2}$，$\theta = -60°$（即 $300°$）。

例3：满足 $|z - 1| = 2$ 的复数 $z$ 对应的点的轨迹。

解：以 $Z_0(1, 0)$ 为圆心，$2$ 为半径的圆。

易错点

  • 虚轴上的点（$a=0, b \neq 0$）表示纯虚数，实轴上的点表示实数
  • 模是非负实数，$|z| \geq 0$
  • 共轭复数 $\bar{z}$ 与 $z$ 关于实轴对称（不是虚轴）

🎓 考点精讲

复数几何意义的核心是将复数与平面向量、点的坐标统一起来，使代数问题可视化，几何问题代数化。

定义与原理： - 复平面：用 $x$ 轴表示实部，$y$ 轴表示虚部，复数 $z=a+bi$ 对应点 $Z(a,b)$，也对应向量 $\overrightarrow{OZ}=(a,b)$。 - 模：$|z|=\sqrt{a^2+b^2}$，几何意义是点 $Z$ 到原点的距离，也等于对应向量的长度。 - 辐角：以 $x$ 轴正半轴为始边，$\overrightarrow{OZ}$ 为终边的角 $\theta$ 称为辐角，记作 $\operatorname{Arg}z$。满足 $-\pi<\theta\le\pi$ 的辐角称为辐角主值 $\arg z$。 - 共轭复数：$\overline{z}=a-bi$，对应点关于实轴对称。 - 加减法：$z_1\pm z_2$ 对应向量的三角形法则或平行四边形法则。 - 乘法与除法：若 $z_1=r_1(\cos\theta_1+i\sin\theta_1)$，$z_2=r_2(\cos\theta_2+i\sin\theta_2)$，则 $z_1z_2=r_1r_2[\cos(\theta_1+\theta_2)+i\sin(\theta_1+\theta_2)]$，$\frac{z_1}{z_2}=\frac{r_1}{r_2}[\cos(\theta_1-\theta_2)+i\sin(\theta_1-\theta_2)]$。几何意义是模相乘（除）、辐角相加（减），即旋转加伸缩。 - 复数的几何表示：$|z-z_0|=r$ 表示以 $z_0$ 对应点为圆心、$r$ 为半径的圆；$|z-z_1|=|z-z_2|$ 表示线段 $Z_1Z_2$ 的垂直平分线；$|z-z_1|+|z-z_2|=2a$（$2a>|Z_1Z_2|$）表示椭圆等。

关键方法： 1. 坐标化：将复数条件转化为点的坐标关系，利用解析几何或向量方法求解。 2. 三角形式与旋转：将乘法、除法、乘方、开方转化为模的运算与辐角的旋转，常用于求轨迹、最值或特定复数。 3. 模与距离的转化：$|z_1-z_2|$ 理解为两点间距离，利用几何图形性质（如三角形不等式 $||z_1|-|z_2||\le|z_1+z_2|\le|z_1|+|z_2|$）求范围。

典型应用： - 已知复数满足 $|z-(1+i)|=2$，求 $|z|$ 的取值范围。将条件转化为点 $Z$ 在以 $(1,1)$ 为圆心、$2$ 为半径的圆上，则 $|z|$ 表示点到原点的距离，结合圆心到原点距离 $\sqrt{2}$，可得 $|z|\in[2-\sqrt{2},2+\sqrt{2}]$。 - 若 $z$ 满足 $\left|\frac{z-1}{z+1}\right|=1$，求对应点的轨迹。由模为 $1$ 得 $|z-1|=|z+1|$，表示到点 $(1,0)$ 和 $(-1,0)$ 距离相等，轨迹为虚轴（即直线 $x=0$），但需扣除 $z=-1$ 点。

⚠️ 高频易错点

  • 混淆复数的模与绝对值：模的非负性及 $|z|^2=z\cdot\overline{z}$ 常用于计算，不可直接脱去模号随意平方。
  • 辐角主值范围记错或忽略多值性：$\arg z$ 默认在 $(-\pi,\pi]$，而 $\operatorname{Arg}z=\arg z+2k\pi$，在乘除与乘方运算中容易遗漏 $2k\pi$ 导致漏解。
  • 将复数的旋转变换方向弄反：$z\cdot i$ 表示将向量逆时针旋转 $90^\circ$，$z\cdot(\cos\theta+i\sin\theta)$ 逆时针旋转 $\theta$，常误为顺时针。
  • 误用实数运算律：复数不能直接比较大小，仅模可比较；$|z_1+z_2|=|z_1|+|z_2|$ 仅当 $z_1$ 与 $z_2$ 同向时成立，一般只能使用三角不等式。
