🎓 等比数列前 $n$ 项和

公式推导

设等比数列首项 $a_1$，公比 $q$，前 $n$ 项和 $S_n$：

当 $q \neq 1$ 时（错位相减法）：

$$S_n = a_1 + a_1 q + a_1 q^2 + \cdots + a_1 q^{n-1}$$

$$qS_n = a_1 q + a_1 q^2 + \cdots + a_1 q^{n-1} + a_1 q^n$$

两式相减：$(1-q)S_n = a_1(1 - q^n)$

$$\boxed{S_n = \frac{a_1(1-q^n)}{1-q} = \frac{a_1(q^n-1)}{q-1}} \quad (q \neq 1)$$

当 $q = 1$ 时（等差，公差为 0）：

$$S_n = na_1$$

公式的等价形式

$$S_n = \frac{a_1 - a_n q}{1-q} = \frac{a_n q - a_1}{q-1} \quad (q \neq 1)$$

（利用 $a_n = a_1 q^{n-1}$，即 $a_1 q^n = a_n q$）

重要性质

性质（等比分段）：$S_n, S_{2n} - S_n, S_{3n} - S_{2n}$ 成等比数列（$q \neq 1$ 时）

$$\frac{S_{2n} - S_n}{S_n} = \frac{S_{3n} - S_{2n}}{S_{2n} - S_n} = q^n$$

无穷等比级数（$|q| < 1$）

当 $|q| < 1$ 时，$q^n \to 0$（$n \to \infty$），无穷项之和：

$$S = \frac{a_1}{1-q} \quad (|q| < 1)$$

应用：循环小数化分数——$0.\overline{3} = 0.3 + 0.03 + \cdots = \dfrac{0.3}{1-0.1} = \dfrac{1}{3}$

典型例题

例1：$a_1 = 1$，$q = 2$，求 $S_{10}$。

解：$S_{10} = \dfrac{1 \times (2^{10}-1)}{2-1} = 2^{10} - 1 = 1023$

例2：$a_1 = 8$，$q = \dfrac{1}{2}$，求 $S_n$ 趋近的极限。

解：$|q| = \dfrac{1}{2} < 1$，$S = \dfrac{8}{1-\frac{1}{2}} = 16$

例3：等比数列 $a_1 = 3$，$S_3 = 21$，求公比 $q$。

解：$S_3 = 3(1 + q + q^2) = 21$，$1 + q + q^2 = 7$，$q^2 + q - 6 = 0$，$(q+3)(q-2) = 0$，$q = 2$ 或 $q = -3$

例4：已知 $S_n = 3^n - 1$，求 $a_n$。

解：$n \geq 2$：$a_n = S_n - S_{n-1} = (3^n-1) - (3^{n-1}-1) = 3^n - 3^{n-1} = 2 \times 3^{n-1}$

$n = 1$：$a_1 = S_1 = 2 = 2 \times 3^0$ ✓，故 $a_n = 2 \times 3^{n-1}$（等比，$q = 3$）

易错点

  • $q = 1$ 时必须单独讨论（$q \neq 1$ 的公式在 $q=1$ 时分母为 0）
  • $S_n - S_{n-1} = a_n$ 仅对 $n \geq 2$ 成立，$n=1$ 时要单独验证
  • 错位相减后要检验 $q \neq 1$ 的前提

🎓 考点精讲

定义与公式推导

对于一个等比数列 ${a_n}$，已知首项 $a_1$，公比 $q$，其前 $n$ 项和记为 $S_n = a_1 + a_2 + \dots + a_n$。

情形一：公比 $q = 1$ 此时数列为常数列 $a_1, a_1, a_1, \dots$，每一项都等于首项，因此 $S_n = n a_1$。

情形二：公比 $q \neq 1$ 采用 错位相减法 推导： $$ \begin{aligned} S_n &= a_1 + a_1 q + a_1 q^2 + \dots + a_1 q^{n-1} \quad \text{(1)} \ q S_n &= a_1 q + a_1 q^2 + a_1 q^3 + \dots + a_1 q^n \quad \text{(2)} \end{aligned} $$ 用 (1) 式减去 (2) 式： $$ (1 - q) S_n = a_1 - a_1 q^n $$ 当 $q \neq 1$ 时，两边同时除以 $(1-q)$，得到核心公式： $$ S_n = \frac{a_1(1 - q^n)}{1 - q} $$ 该公式也可等价变形为 $S_n = \frac{a_1 - a_n q}{1 - q}$（代入通项 $a_n = a_1 q^{n-1}$ 即得），在已知末项 $a_n$ 时使用更便捷。

关键方法

解决等比数列求和问题的标准步骤： 1. 确定首项 $a_1$ 与公比 $q$：从已知条件（递推关系、特定项的值）中解出。 2. 判断公比是否为 1：若 $q=1$，直接使用 $S_n = n a_1$；若 $q \neq 1$，代入公式 $S_n = \frac{a_1(1 - q^n)}{1 - q}$。 3. 执行计算：注意指数运算与符号处理，尤其是 $q$ 为负数或分数时。

判定等比数列求和的成立条件：必须验证公比 $q \neq 1$ 且数列各项均满足等比定义（即 $\frac{a_{k+1}}{a_k} = q$ 为常数），避免在非等比数列中误用公式。

典型应用

高考常见设问与场景： - 直接求值：给定等比数列的首项、公比与项数，求 $S_n$。如“已知 $a_1=3$，$q=2$，求前6项和”。 - 已知和反求参数：给出 $S_n$、$a_1$、$n$ 或 $q$ 中的部分量，解方程求未知数。例如“等比数列前3项和为 $26$，公比为 $3$，求首项”。 - 与错位相减法结合的综合题：形如 ${n \cdot 2^n}$ 的数列求和，需先用错位相减法化为等比部分再套用本公式，是高考解答题的常客。

⚠️ 高频易错点

  • 忽略 $q=1$ 的分类讨论：使用公式 $S_n = \frac{a_1(1-q^n)}{1-q}$ 时，分母含 $1-q$，必须先确认 $q \neq 1$。若题目未明确公比范围而直接套用，将导致漏解或错误。
  • 项数 $n$ 混淆：在复杂递推或实际情境（如年增长率问题）中，容易算错总项数。注意从首项起第 1 项指数为 $q^0$，第 $n$ 项指数为 $q^{n-1}$，求和时指数最高到 $q^{n-1}$，公式分子是 $q^n$。
  • 符号计算失误：当公比 $q$ 为负数时，$(1-q)$ 和 $(1-q^n)$ 的符号尤其需要小心代值，避免正负颠倒。
  • 误用于非等比数列：必须验证后项与前项的比值为常数方可使用本公式。对混合数列求和（如等差加减等比），只能对等比部分单独求和，不能整体直接代公式。
