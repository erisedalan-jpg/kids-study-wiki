原子晶体

权重4吉林命中0路径1学段[高中]主题[选必二, 第三章]

aliases: 原子晶体, covalent network solid, atomic crystal

原子晶体

一句话：原子通过共价键连接成无限三维网状结构的晶体，熔点极高、硬度最大、不导电，代表为金刚石和SiO₂。 English: A crystal in which atoms are bonded by covalent bonds into an infinite three-dimensional network; extremely high melting point, greatest hardness, non-conducting; exemplified by diamond and SiO₂.

🎓 高中进阶

定义

原子晶体（Covalent Network Solid / Atomic Crystal）：结构微粒为原子，原子间通过共价键形成无限延伸的三维网状结构。

  • 整个晶体视为一个"巨型分子"（macromolecule）
  • 不存在独立的小分子单元（无 SiO₂ 分子、无 C 分子）

原子晶体的通性

性质 特征 原因
熔点 极高（>1000°C，多数） 需断裂大量共价键
硬度 最高（金刚石最硬） 共价键强且方向性强
导电性 一般不导电 无自由电子（纯共价）
溶解性 难溶于任何溶剂 破坏共价键需大能量
延展性 无（脆） 晶体破裂而非变形

例外：石墨（原子晶体的特例） - 石墨同样是 C 形成的，但层内为 sp² 杂化形成大 π 键 → 导电 - 层间为弱分子间力 → 硬度低、可滑动（润滑剂） - 石墨是混合型晶体（层内共价键，层间范德华力）

典型原子晶体

物质 化学键 熔点 特点
金刚石（C） sp³ C−C 3550°C 最硬天然物质
Si（硅） sp³ Si−Si 1414°C 半导体
SiO₂ Si−O 1710°C 光导纤维材料
SiC（金刚砂） Si−C 2730°C 研磨材料
BN（六方） B−N（类石墨） 2730°C 超硬材料

影响原子晶体熔点的因素

  1. 键能越大，熔点越高：C−C(348 kJ/mol) > Si−Si(222 kJ/mol) → 金刚石熔点 > Si
  2. 键长越短，键能越大，熔点越高

典型例题

题：比较金刚石和 SiC 的熔点高低，并解释。 解：金刚石（3550°C）> SiC（2730°C） 键能：C−C(348 kJ/mol) > Si−C(435 kJ/mol)？ 实际上 Si−C 键能（435 kJ/mol）> C−C（348 kJ/mol），但金刚石熔点更高，原因是 C−C 键长（154 pm）< Si−C 键长（194 pm），综合密度更高的 C−C 键网络，金刚石整体熔点更高。（注：实际熔点数据比较复杂，高中按键能比较即可）

易错点

  • SiO₂ 没有分子式意义上的"分子"，化学式 SiO₂ 只是 Si:O = 1:2 的比例式
  • 石墨不是纯粹的原子晶体，而是混合型晶体
  • Si 是原子晶体（半导体），不是金属晶体
