醇

一句话：醇是含有醇羟基（—OH 连在饱和碳上）的有机化合物，可发生与钠反应、氧化、酯化和脱水等多种反应，乙醇是最典型的代表。 English: Alcohols contain a hydroxyl group (—OH bonded to a saturated carbon) and undergo reactions with sodium, oxidation, esterification, and dehydration; ethanol is the most representative alcohol.

🎓 高中进阶

定义 / 结构特征

醇（alcohol）：含醇羟基（—OH，连在饱和 sp³ 碳上）的有机物。

分类：

分类 类型 举例
羟基数目 一元醇、二元醇、多元醇 乙醇、乙二醇、丙三醇
碳的类型 伯醇（1°）、仲醇（2°）、叔醇（3°） 正丙醇、2-丙醇、叔丁醇
饱和度 饱和醇、不饱和醇 乙醇、丙烯醇

醇羟基的结构： - O 原子 sp³ 杂化，O—H 键可断（与 Na 反应，或酯化） - C—O 键可断（消去反应，或与 HX 反应） - 与酚羟基（O 连苯环 sp² 碳）不同：醇酸性更弱，无法与 Na₂CO₃ 反应

物理性质（以乙醇为例）： - 低级醇（C₁-C₃）：无色液体，可与水任意比互溶（—OH 与水形成氢键） - 沸点比对应烷烃高（分子间氢键） - 密度一般 < 水

性质 / 反应

反应类型 试剂/条件 方程式示例
与 Na 反应 Na，常温 2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑
催化氧化 O₂，Cu 催化 2CH₃CH₂OH + O₂ →(Cu,△) 2CH₃CHO + 2H₂O
酯化（与酸） 浓 H₂SO₄，加热 CH₃CH₂OH + CH₃COOH ⇌ CH₃COOC₂H₅ + H₂O
分子间脱水 浓 H₂SO₄，140°C 2C₂H₅OH → C₂H₅OC₂H₅ + H₂O（乙醚）
分子内脱水（消去） 浓 H₂SO₄，170°C C₂H₅OH → CH₂=CH₂↑ + H₂O
与 HX 取代 HBr（浓），加热 C₂H₅OH + HBr → C₂H₅Br + H₂O

氧化程度（伯醇）：醇 →（氧化）醛 →（再氧化）羧酸

典型例题

例：如何区分乙醇和乙酸？

解：加 Na₂CO₃ 溶液：乙酸产生气泡（CO₂），乙醇无现象。或加石蕊：乙酸变红，乙醇不变。

例：乙醇脱水的两种产物和条件。

解： - 140°C + 浓 H₂SO₄：分子间脱水 → 乙醚（CH₃CH₂OCH₂CH₃） - 170°C + 浓 H₂SO₄：分子内脱水 → 乙烯（CH₂=CH₂）

易错点

  • 醇羟基（连 sp³ 碳）的酸性远弱于酚羟基（连苯环）和羧酸
  • 叔醇（R₃COH）无法被催化氧化为醛/酮（因 α-C 无 H）
  • 酯化反应是可逆反应（用浓 H₂SO₄ 作催化剂和脱水剂，使平衡正移）
