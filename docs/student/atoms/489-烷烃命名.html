烷烃命名

权重6吉林命中0路径2学段[高中]主题[选必三, 第二章]

aliases: 烷烃命名, alkane nomenclature, IUPAC alkane naming

烷烃命名

一句话：烷烃按 IUPAC 规则命名：选最长碳链为主链，从离取代基最近端编号，以"几-取代基名+烷"格式命名。 English: Alkanes are named by IUPAC rules: select the longest carbon chain as parent, number from the end nearest a substituent, and name as "position-substituent name + ane".

🎓 高中进阶

定义 / 结构特征

烷烃 IUPAC 命名步骤：

  1. 选主链：含碳数最多的连续碳链（若等长，选取代基最多的链）
  2. 编号：从离取代基最近的链端开始，编 C₁、C₂……（使各取代基位次之和最小）
  3. 列取代基：按字母顺序（英文）或笔画（中文）列出，格式：位次-取代基名
  4. 命名主链：C₁=甲、C₂=乙……（见下表）
  5. 组合：取代基名（含位次）+ 烷

碳数与词根：

碳数 中文词根 英文

2 乙 eth-

常见烷基（取代基）名称：

烷基 结构 名称

—CH(CH₃)₂ isopropyl 异丙基
—C(CH₃)₃ tert-butyl 叔丁基

性质 / 反应

命名规则用于准确描述结构，不直接影响反应，但位次信息对预测产物有帮助： - 位次低的碳（如伯碳）与高的碳（叔碳）在卤代反应中活性不同（叔 H > 仲 H > 伯 H）

典型例题

例1：命名下列化合物：CH₃CH(CH₃)CH₂CH₂CH₃

解： - 最长链从 C₁ 至 C₅（5 碳，戊烷母体） - C₂ 连有甲基 - 从靠近甲基端编号：位次 2 - 命名：2-甲基戊烷

例2：命名 CH₃C(CH₃)₂CH₂CH₃

解： - 最长链选含 C(CH₃)₂ 的链：C₁-C₂-C₃-C₄ = 4 碳（丁烷） - C₂ 连有两个甲基（二甲基） - 命名：2,2-二甲基丁烷

例3：写出 3-乙基-2-甲基戊烷的结构简式。

解：主链 5 碳（戊烷），C₂ 甲基，C₃ 乙基： CH₃CH(CH₃)CH(C₂H₅)CH₂CH₃

易错点

  • 主链必须包含取代基所在碳，且是最长的连续链
  • 同一取代基出现多次，用二、三（di-、tri-）前缀，每次均需注明位次
  • 编号使所有取代基位次之和最小（不是最小的单个位次）

  • The parent chain must be the longest continuous carbon chain in the molecule.
  • Substituents are listed in alphabetical order (IUPAC) in the name.
