全反射临界角

一句话：光从光密介质射向光疏介质时，使折射角恰好等于90°的入射角，称为临界角。 English: The critical angle is the angle of incidence for which the angle of refraction is exactly 90° when light passes from an optically denser medium to a less dense medium.

🎓 考点精讲

  • 定义/原理：当光从折射率为 $n_1$ 的光密介质射入折射率为 $n_2$ 的光疏介质（$n_1 > n_2$）时，折射角大于入射角。若逐渐增大入射角，折射角也会随之增大。当折射角达到 90° 时，对应的入射角就是临界角 $C$。根据折射定律 $n_1 \sin C = n_2 \sin 90^\circ$，可得 $\sin C = \dfrac{n_2}{n_1}$。若光疏介质为真空（或空气，$n_2 \approx 1$），则临界角公式简化为 $\sin C = \dfrac{1}{n}$（$n$ 为光密介质的绝对折射率）。当入射角大于或等于临界角，且光从光密介质射向光疏介质时，折射光消失，入射光全部反射回光密介质，此即全反射。

  • 关键方法：判断是否发生全反射，必须同时满足两个条件：① 光从光密介质射向光疏介质；② 入射角 $i \ge$ 临界角 $C$。解题时先由折射率求出 $\sin C$，再比较给定入射角与 $C$ 的关系。若涉及光在介质与空气界面往返的图形题，常需画出光路并利用几何关系（如三角形内角、圆的切线）确定入射角。

  • 典型应用：高考常以光导纤维（内芯折射率大于外套折射率，光在内芯与外套界面上发生全反射传输）和全反射棱镜（等腰直角三角形棱镜，利用玻璃与空气界面的两次全反射改变光路）为情境设问，要求计算最小折射率或最大入射角。也常结合水面下的点光源、圆形亮斑（视场）问题，让考生分析刚好发生全反射的边界光线。

⚠️ 高频易错点

  • 误认为只要光从光密介质射向光疏介质就一定发生全反射，忘记了还必须满足入射角大于或等于临界角。
  • 计算临界角时代错折射率：直接用绝对折射率代入 $\sin C = n$ 或把相对折射率的分母分子颠倒，正确关系为 $\sin C = n_{\text{疏}} / n_{\text{密}}$。
  • 光线从一种介质进入另一种介质后，再射向空气时，忘记重新计算在新的光密介质中的临界角，直接沿用原临界角导致误判。
  • 混淆“全反射时能量全部返回”的含义，误认为光在界面没有能量损耗；实际上全反射仍有倏逝波透入光疏介质，但平均能流为零，高考阶段只需理解反射光强等于入射光强。
