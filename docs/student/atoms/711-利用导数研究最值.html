利用导数研究最值

一句话：利用导数求解函数在给定区间上的最大值与最小值，其核心依据是可导函数的极值点必为驻点，且最值在极值点或区间端点处取得。 English: Using derivatives to find a function’s maximum and minimum values on a given interval, based on the principle that local extrema of differentiable functions occur at critical points, with global extrema attained at these critical points or interval endpoints.

🎓 考点精讲

定义/原理：对于闭区间 $[a, b]$ 上的连续函数 $f(x)$，其最大值与最小值必然存在。若 $f(x)$ 在 $(a, b)$ 内可导，则最值点只可能出现在两种位置： 1. 驻点（即 $f'(x)=0$ 的点）或不可导点（高中阶段以驻点为主）； 2. 区间的端点 $x=a$ 或 $x=b$。 此为求解最值问题的理论基石。极值刻画局部性质，最值描述整体性质，极值未必是最值，反之亦然。

关键方法：标准解题步骤为—— 1. 确定定义域：明确自变量的允许范围（尤其是含参函数或实际问题）。 2. 求导数：计算 $f'(x)$ 并通分/因式分解，化为易于判号的形式。 3. 找临界点：令 $f'(x)=0$，解方程求出区间内的所有实根，并判断有无导数不存在的点。 4. 列表比较：将区间端点及各临界点对应的函数值 $f(x)$ 全部算出，其最大者即为最大值，最小者即为最小值。
若先判断单调性再求最值，需注意：若 $f(x)$ 在 $[a, b]$ 上单调递增，则最小值在 $x=a$ 处，最大值在 $x=b$ 处。

典型应用：高考常以两种形态考查—— - 显函数最值：如“求函数 $f(x)=x^3-3x^2-9x+5$ 在 $[-2,4]$ 上的最大值与最小值”，直接套用上述步骤即可求解。 - 实际问题建模：如“用长为 $L$ 的铁丝围成矩形，求最大面积”，需先建立目标函数（如 $S=x(\frac{L}{2}-x)$），再利用导数求开区间内唯一驻点，并结合实际意义判定该点即为最值点。

⚠️ 高频易错点

  • 忽视定义域与区间端点：仅令 $f'(x)=0$ 求出驻点后，直接认定该点函数值即为最值，忘记计算区间端点处的函数值进行比较，是失分重灾区。
  • 混淆极值与最值：在开区间 $(a,b)$ 内唯一的极大值不一定是最大值，必须验证函数在区间两端的变化趋势（如 $x \to a^+$ 或 $x \to b^-$ 时 $f(x)$ 是否趋于更大的值）。
  • 解 $f'(x)=0$ 后不判号：求出驻点后未通过导数的正负判断单调性（或直接列表计算），导致无法确定该驻点是极大值点、极小值点还是非极值驻点，从而错判最值。
  • 导数运算不过关：通分、因式分解常出错，导致临界点遗漏或求错，后续步骤全部无效。

🌐 中英对照（术语表）

中文 English 说明
最值 Global Extremum (Maximum/Minimum) 函数在整个定义域或给定区间上的最大值或最小值
极值 Local Extremum 函数在局部邻域内的最大值或最小值
驻点 Stationary Point / Critical Point 导数为零的点，即满足 $f'(x)=0$ 的点
端点 Endpoint 闭区间的边界点 $a$ 或 $b$
