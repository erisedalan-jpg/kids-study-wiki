动点轨迹

一句话：动点轨迹是满足给定几何条件的点在平面上运动所形成的图形，常通过求轨迹方程进行研究。 English: The locus of a moving point is the set of all points satisfying given geometric conditions, usually described by an equation.

🎓 考点精讲

动点轨迹的本质是曲线与方程思想的体现：曲线是满足条件的点的集合，方程是该集合的代数描述。高考中轨迹问题主要分为两类：一是直接给出几何条件求轨迹方程，二是由参数化的动点变化过程确定定点或定曲线。

求轨迹方程的一般步骤： 1. 建系设点：建立合适的坐标系，设动点坐标为 $(x, y)$，将题目中的定点、定直线等要素坐标化； 2. 列式翻译：将几何条件（如距离、斜率、向量平行垂直、面积等）用坐标间的代数等式翻译出来； 3. 化简整理：通过代数恒等变形得到 $F(x,y)=0$，并注明定义域限制（即纯粹性验证，排除不满足几何意义的点）； 4. 检验完备性：有时需讨论特殊位置是否满足方程，并依题意补充范围。

常见轨迹类型与条件： - 到两定点距离之和为常数（大于两定点距离）→ 椭圆； - 到两定点距离之差的绝对值为常数（小于两定点距离）→ 双曲线； - 到一定点与定直线距离相等 → 抛物线； - 到两定点连线所张角为定角（非零或平角）→ 两段圆弧（阿波罗尼奥斯圆）。 - 更一般情形需利用参数法或相关点法：如动点 $P$ 随另一曲线上动点 $Q$ 运动，可设 $Q(u,v)$ 满足已知曲线方程 $f(u,v)=0$，再用中点、定比分点等关系写出 $u,v$ 关于 $x,y$ 的表达式，代入消参得轨迹方程。

高考常见设问： - 直接求动点的轨迹方程（多出现在解答题第一问）； - 存在性探究：是否存在满足条件的点使得某图形为特殊形状（如等腰直角三角形）； - 范围与最值：求动点到某定点距离或面积的最大/最小值，需借助轨迹方程计算。

⚠️ 高频易错点

  • 忽视定义域限制：轨迹方程化简易忽略分母不为零、根号非负等条件，导致把不在原几何条件内的点误算成轨迹，如圆方程 $x^2+y^2=1$ 中若不剔除某些象限的点会扩大轨迹范围。
  • 混淆轨迹与轨迹方程：轨迹是图形，轨迹方程是等式。当题目要求“轨迹”时，可能需要描述曲线形状并说明范围，而不仅仅是给出方程。
  • 建系不合理带来复杂计算：若坐标系选择不当（如不利用对称性），会使方程复杂化，增加出错概率。应尽量把定点、定直线放在坐标轴或原点。
  • 相关点代入时方向搞反：用相关点法时，要分清主动点与被动点的关系，列式时移项符号错误，导致最终方程错误。
