歧化反应

一句话：同一元素在反应中发生自身氧化还原，一部分原子化合价升高、另一部分原子化合价降低，同时生成两种不同价态产物的反应。 English: A disproportionation reaction is a redox reaction in which an element in a single oxidation state is simultaneously oxidized and reduced to form two different products.

🎓 考点精讲

定义/原理：歧化反应的本质是同种元素的自身氧化还原。反应物中某元素处于中间价态，在特定条件下发生电子转移：一部分该元素的原子失去电子被氧化（化合价升高），另一部分原子得到电子被还原（化合价降低），最终生成该元素的高价态与低价态两种产物。电子转移全部发生在同种元素之间，氧化剂与还原剂是同一物质。

判断依据——化合价"居中可歧化"规律： - 画出含该元素的常见价态线，若反应物中元素的化合价既不是最高价也不是最低价，则理论上可以发生歧化。 - 常见可歧化价态举例（待家长核对）：Cl₂中Cl为0价（-1与+1之间）、H₂O₂中O为-1价（-2与0之间）、NO₂中N为+4价（+3与+5之间）。

典型反应方程式（高考高频）：

  1. 氯气与碱反应（常温）： $$ \text{Cl}_2 + 2\text{NaOH} = \text{NaCl} + \text{NaClO} + \text{H}_2\text{O} $$ Cl从0价 → NaCl中-1价（还原）+ NaClO中+1价（氧化）

  2. 过氧化氢分解： $$ 2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2\uparrow $$ O从-1价 → H₂O中-2价（还原）+ O₂中0价（氧化）

高考考查方式： - 氧化还原方程式的配平：歧化反应中氧化产物与还原产物的系数比由化合价升降数的最小公倍数确定。 - 电子转移数目计算：标明单线桥或双线桥，注意一个分子内电子得失的方向与数目。 - 实验与流程题：书写尾气吸收（如Cl₂通入NaOH溶液）或物质制备过程中的歧化方程式。

⚠️ 高频易错点

  • 歧化反应与归中反应的混淆：歧化是"中间价→高价+低价"（一分二），归中是"高价+低价→中间价"（二合一）。判断时先标化合价，看电子转移方向是分散还是集中。
  • 氧化剂与还原剂的判定错误：歧化反应中氧化剂和还原剂是同一种物质，不可再拆分成两个独立角色。计算电子转移时要以一个分子为单位标明"得"与"失"的双向转移。
  • 歧化反应是否一定需要水或碱参与：并非绝对。Cl₂的歧化需碱液驱动平衡；而H₂O₂分解可在MnO₂催化下直接发生，无需额外试剂。审题时关注反应条件即可。
  • 化合价"居中"判断笼统化：必须结合该元素在给定体系中的稳定价态谱来判断。例如Fe²⁺在+2价，理论上+2介于0与+3之间，但Fe²⁺在水中一般不发生歧化，因为Fe不是该环境下的稳定价态组合。
