打点计时器

一句话：打点计时器是利用交流电的周期性变化在纸带上等时打点来记录物体运动位移‑时间信息的计时仪器。 English: A dot timer is a timing instrument that records an object's displacement over time by making equally spaced dots on a paper tape using the periodic variation of AC power.

🎓 考点精讲

定义与原理：打点计时器分为电磁打点计时器（工作电压约 8 V 交流）和电火花计时器（工作电压 220 V 交流）。两者均利用交流电频率 $f = 50\ \mathrm{Hz}$，打点周期 $T = \frac{1}{f} = 0.02\ \mathrm{s}$，即相邻两点间的时间间隔为 0.02 s。纸带上的点迹记录了物体在相等时间内的位移，通过对点迹的测量可求得物体的速度和加速度。

关键方法（纸带数据处理）： 1. 判断运动性质：若连续相等时间内的位移差 $\Delta x = x_{n+1} - x_n$ 为恒量，则物体做匀变速直线运动。 2. 求瞬时速度（如求打 $n$ 点时的速度）：$v_n = \frac{x_n + x_{n+1}}{2T}$（中间时刻速度等于平均速度）。 3. 求加速度： - 逐差法：$a = \frac{(x_4+x_5+x_6) - (x_1+x_2+x_3)}{9T^2}$（6 段位移标准处理）； - 图像法：作出 $v-t$ 图线，斜率即加速度； - 基本公式：$a = \frac{\Delta x}{T^2}$（适用于相邻段）。 4. 注意单位换算：纸带测量值通常以 cm 或 mm 给出，计算时必须换算为国际单位 m。

典型高考考查方式： - 设问角度：给定纸带点迹数据，求某点的瞬时速度；求物体运动的加速度；判断物体是否做匀变速运动；计算纸带中某计数点间的平均速度。 - 真实情境：（1）利用重物拖着纸带下落的打点纸带计算重力加速度 $g$，需验证 $\Delta x$ 是否恒定，再代入逐差法求 $a$。（2）探究小车在倾斜导轨上匀加速运动的纸带，已知打点周期和若干段位移，直接计算 $a$ 和某点瞬时速度，并画 $v-t$ 图验证。

⚠️ 高频易错点

  • 周期与频率混淆：误将 50 Hz 对应周期写成 0.2 s 而非 0.02 s，单位换算时常将 mm/cm 直接代入公式而未化为 m。
  • “点”与“计数点”不分：题目常每隔 4 个点取一个计数点（即 $T = 0.1\ \mathrm{s}$），学生未看清题设直接使用 $T = 0.02\ \mathrm{s}$ 计算。
  • 逐差法位移下标错位：将 $x_4+x_5+x_6$ 与 $x_1+x_2+x_3$ 的差值写反，或误用位移段数直接除以段数 $n$ 来计算加速度，而忘记除以 $nT^2$。
  • 电火花与电磁打点计时器混淆：电火花使用墨粉纸盘和 220 V 交流电，打点阻力小；电磁打点使用复写纸和低压交流电，打点阻力较大，实验误差来源不同，混淆电压和结构会导致实验题失分。
