SO2制备

考点SO2制备权重6真题数1学科化学父主题元素化合物

考点定位

  • 父主题：元素化合物
  • 权重 weight：6
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择9
  • 难度分布：易1

知识精要

  • 实验室制备原理：亚硫酸钠与浓硫酸反应，无加热或微热。化学方程式：
    $$\text{Na}_2\text{SO}_3 + \text{H}_2\text{SO}_4(\text{浓}) = \text{Na}_2\text{SO}_4 + \text{SO}_2\uparrow + \text{H}_2\text{O}$$
  • 发生装置：固体（$\text{Na}_2\text{SO}_3$）与液体（浓$\text{H}_2\text{SO}_4$）不加热制气，选用简易启普发生器或其替代装置（如蒸馏烧瓶、圆底烧瓶配分液漏斗）。本题使用蒸馏烧瓶。
  • 收集方法：向上排空气法（密度大于空气）；不可用排水集气法（$\text{SO}_2$易溶于水，且与水反应）。
  • 尾气处理：$\text{SO}_2$是酸性氧化物、有毒，用$\text{NaOH}$溶液吸收，防止污染空气。
  • 核心性质（真题考查）：
  • 还原性：可使酸性$\text{KMnO}_4$溶液褪色。$$\text{5SO}_2 + 2\text{MnO}_4^- + 2\text{H}_2\text{O} = 2\text{Mn}^{2+} + 5\text{SO}_4^{2-} + 4\text{H}^+$$
  • 氧化性：与$\text{S}^{2-}$反应生成硫单质，溶液中出现黄色浑浊。$$\text{SO}_2 + 2\text{S}^{2-} + 2\text{H}^+ \rightarrow 3\text{S}\downarrow + 2\text{H}_2\text{O}$$ 或$$\text{SO}_2 + 2\text{Na}_2\text{S} + 2\text{H}_2\text{O} = 3\text{S}\downarrow + 4\text{NaOH}$$
  • 漂白性（可逆）：$\text{SO}_2$与品红化合成不稳定无色物质，加热后颜色恢复红色。（$\text{SO}_2$漂白具有选择性，不能漂白石蕊等指示剂）
  • 注意事项：
  • 浓硫酸的浓度不能太低，否则生成$\text{SO}_2$溶解损失多。
  • 不能用$\text{HNO}_3$、浓$\text{HCl}$代替浓$\text{H}_2\text{SO}_4$（$\text{HNO}_3$有强氧化性；浓$\text{HCl}$挥发出$\text{HCl}$杂质气体）。

解题方法与套路

  1. 仪器识别与作用：看清图形，确认蒸馏烧瓶、分液漏斗、洗气瓶、酒精灯等常见仪器，名称书写规范（如“蒸馏烧瓶”不能写“圆底烧瓶”、“分液漏斗”不能漏字）。
  2. 化学方程式书写：找准反应物、生成物，配平并标注“$\uparrow$”“$\downarrow$”及反应条件。浓硫酸与亚硫酸钠不加热，不要乱加“$\triangle$”。
  3. 性质推断与现象描述：
  4. 现象要写完整（颜色变化、沉淀、气泡等），如“溶液由紫红色变为无色”“出现淡黄色浑浊”。
  5. 对应性质：褪色若因氧化还原→还原性/氧化性；品红褪色可逆→漂白性。
  6. 可逆性验证操作：先使品红褪色，再通过加热恢复颜色。描述实验操作时，注意“关闭分液漏斗活塞”、“点燃酒精灯加热”等完整步骤及现象对比。
  7. 尾气处理方法：酸性有毒气体选用碱液（$\text{NaOH}$）吸收，回答“$\text{NaOH}$溶液”即可，一般不用$\text{Ca(OH)}_2$溶液（$\text{Ca(OH)}_2$微溶，吸收效率低）。

高频易错

  • 仪器名称写错：蒸馏烧瓶写成“烧瓶”、“圆底烧瓶”；分液漏斗写成“长颈漏斗”或“滴液漏斗”。
  • 化学方程式错漏：漏写“$\uparrow$”或“$\triangle$”；将浓硫酸写成稀硫酸；产物$\text{Na}_2\text{SO}_4$写成$\text{NaHSO}_4$。
  • 离子方程式书写：酸性高锰酸钾与$\text{SO}_2$反应，忘记电荷守恒和氧原子配平；错将$\text{SO}_2$拆开。
  • 现象描述不准确：$\text{SO}_2$氧化$\text{S}^{2-}$生成的硫沉淀是“黄色”或“淡黄色”，不能写成“白色”；高锰酸钾褪色写成“褪为无色”而不是“褪成单色”等。
  • 可逆性验证操作遗漏要点：只写“加热”，未说明“停止通$\text{SO}_2$”或“关闭活塞”，导致现象无法实现（继续通入$\text{SO}_2$会不断褪色）。
  • 尾气溶液选择：吸收$\text{SO}_2$普遍用$\text{NaOH}$溶液，若填写“水”或“石灰水”，未理解$\text{SO}_2$在水中溶解度虽大但吸收不完全且易逸出；石灰水浓度低效果差。

代表题精讲

题目
某化学兴趣小组为探究$\text{SO}_2$的性质，按图所示装置实验，连接顺序为A（制备）→ B（酸性$\text{KMnO}_4$溶液）→ C（$\text{Na}_2\text{S}$溶液）→ D（品红溶液，可加热）。回答：(1) A中仪器名称、反应方程式；(2) B、C现象及体现性质，B中离子方程式；(3) D验证$\text{SO}_2$与品红作用可逆性的操作及现象；(4) 尾气吸收所用溶液。

思路
根据装置流程，由A固液不加热制$\text{SO}_2$，结合试剂推断：B检验还原性，C检验氧化性，D检验漂白性及可逆性。最后尾气用碱液吸收。书写方程式需配平并注明状态；描述操作需体现“停止通入$\text{SO}_2$后加热恢复原色”的核心逻辑。

步骤
1. A中盛放亚硫酸钠的仪器为蒸馏烧瓶，反应：$\text{Na}_2\text{SO}_3 + \text{H}_2\text{SO}_4(\text{浓}) = \text{Na}_2\text{SO}_4 + \text{SO}_2\uparrow + \text{H}_2\text{O}$。
2. B中酸性$\text{KMnO}_4$溶液褪色（紫红色变无色），说明$\text{SO}_2$具有还原性；离子方程式：$5\text{SO}_2 + 2\text{MnO}_4^- + 2\text{H}_2\text{O} = 2\text{Mn}^{2+} + 5\text{SO}_4^{2-} + 4\text{H}^+$。
C中$\text{Na}_2\text{S}$溶液出现黄色浑浊，说明$\text{SO}_2$具有氧化性。
3. D探究可逆性：待品红溶液褪色后，关闭分液漏斗的旋塞停止通$\text{SO}_2$，点燃酒精灯加热，溶液恢复红色。
4. 尾气用$\text{NaOH}$溶液吸收。

点评/变式
- 此题全面覆盖$\text{SO}_2$三大核心性质，是元素化合物实验探究的经典模板。复习时应做到“一装置多性质”串联，熟悉常见检验试剂及对应现象。
- 变式：若将C中换成$\text{BaCl}_2$溶液，再加氧化剂（如$\text{H}_2\text{O}_2$）会产生白色沉淀（$\text{BaSO}_4$），用于检验$\text{SO}_2$的还原性及$\text{SO}_4^{2-}$的生成；若将D改为溴水或碘水，褪色体现还原性而非漂白性，注意区分。解答实验操作题要特别注意“对照思维”和“变量控制”，如验证可逆性必须停止通$\text{SO}_2$后再加热。
