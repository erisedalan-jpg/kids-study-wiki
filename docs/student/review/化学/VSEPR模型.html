VSEPR模型

考点VSEPR模型权重6真题数1学科化学父主题化学键与分子结构

考点定位

  • 父主题：化学键与分子结构
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择2
  • 难度分布：易1

知识精要

VSEPR模型（价层电子对互斥理论）用于预测简单分子或离子的空间构型，核心是“电子对之间排斥最小”。

  • 价层电子对数计算
    对 $AB_m^{\,n\pm}$ 型微粒，中心原子A的价层电子对数 $n$ 为： $$n = \frac{a + m - n_{\pm}}{2}$$ 其中：$a$ 为中心原子最外层电子数；$m$ 为σ键结合的配体数（H相当1个电子，卤素相当7个电子）；$n_{\pm}$ 为电荷数（负电荷时加，正电荷时减）。若结果不为整数，直接进1取整（因单电子也占轨道）。

  • 杂化方式判别

  • $n=2$ → $sp$ 杂化
  • $n=3$ → $sp^2$ 杂化
  • $n=4$ → $sp^3$ 杂化
  • $n=5$ → $sp^3d$ 杂化

  • $n=6$ → $sp^3d^2$ 杂化

  • 空间构型判断
    先由 $n$ 确定电子对理想几何（$n=2$直线形，$n=3$平面三角形，$n=4$正四面体，$n=5$三角双锥，$n=6$正八面体）。再根据孤电子对数（$n - 成键电子对数$）得出真实空间构型：

  • $sp^3$杂化：孤电子对0→正四面体（如$CH_4$）；1→三角锥形（如$NH_3$）；2→V形（如$H_2O$）。
  • $sp^2$杂化：孤电子对0→平面三角形（如$BF_3$）；1→V形（如$SO_2$）。

  • $sp$杂化：均为直线形。

  • 成键σ键与孤电子对确定
    配体数即为σ键数目（不考虑π键），孤电子对占据轨道，故实际分子形状会因孤电子对的排斥而偏离理想几何。

  • 适用条件
    ① 主族元素形成的简单分子或离子；② 中心原子无空d轨道时适用经典VSEPR（如P、S等可用$sp^3d$等）；③ 考虑多重键（双/三键）只算一个σ键，但电子云斥力更大，可影响键角。

解题方法与套路

  1. 定中心原子与配体分子式：明确中心原子A及配体数m，分析电荷。
  2. 算价层电子对数
    $$n = \frac{价电子数 + 配体提供电子数 \pm 电荷数}{2}$$
    （配体H/卤素各提供1，O族提供0，但计算氧族作配体时按提供0电子处理。）
  3. 判断杂化类型：电子对数2~6分别对应$sp, sp^2, sp^3, sp^3d, sp^3d^2$。
  4. 数孤电子对数：$l = n - 配体数$。若成键含多重键仍只计1个σ配体。
  5. 确定空间构型：在电子对理想几何中去掉孤电子对后即得分子实际构型。牢记$sp^3$的0/1/2孤对对应正四面体/三角锥/V形；$sp^2$对应平面三角形/V形；$sp$对应直线形。
  6. 验证键角：孤电子对排斥大，使成键电子对之间夹角变小，如$NH_3$键角<109.5°。

高频易错

  • 忽略孤电子对直接以配体数判断形状：如将$PCl_3$误作平面三角形，实际中心P有1对孤电子，实为三角锥形。
  • 电子对几何构型与分子几何构型混淆：考题要求的是“分子的空间结构”，必须剔除孤电子对，切忌答成电子对理想构型。
  • 配体提供电子数计算错误：H与卤素各算1个电子，氧族（$O,S$等）作配体时提供0个电子（因需形成双键，满足八隅体），而非6个。例如$SO_3$中S的价层电子对数 = $(6+0)/2=3$。
  • 负电荷/正电荷计算反号：负离子应加电荷数，正离子减。如在$NH_4^+$中，N价层电子对数 = $(5+4-1)/2=4$。
  • 多重键算错配位数：双键或三键仍只提供1个σ配位数，但斥力大于单键，会导致键角偏离标准值。
  • 误用杂化方式推构型：只知杂化不知孤电子对数无法准确判断真实形状，如$sp^3$杂化可能是正四面体、三角锥或V形。
  • 忽视中心原子是否满足扩展八隅体：第二周期元素（如N,O）最大配位数4，不出现$sp^3d$；第三周期及以下（如P,S）可超过8电子，可用$sp^3d$等杂化。

代表题精讲

代表题1：2024-辽宁-02（选项D）

题目
判断$PCl_3$的空间结构表述“平面三角形”是否正确。

思路
中心原子P的最外层电子数为5，3个Cl各提供1个电子，无电荷。由VSEPR计算价层电子对数，判定杂化与孤电子对数，得到真实空间构型。

步骤
1. 价层电子对数 $n = \dfrac{5+3}{2} = \dfrac{8}{2} = 4$。
2. 4对电子对应$sp^3$杂化，理想构型为正四面体。
3. 成键配体有3个，故孤电子对数 $l = 4 - 3 = 1$。
4. $sp^3$且有1对孤电子对，分子构型为三角锥形（与$NH_3$类似），绝非平面三角形。
因此题干中“平面三角形”表述错误，正确构型应为三角锥形。

点评/变式
典型陷阱：直观看到三个P—Cl键就误认为平面三角形，忽略了孤电子对的立体化学效应。类似情形：$NH_3$、$NF_3$、$PH_3$均为三角锥形；$H_2O$为V形（2对孤电子）。凡中心原子采用$sp^3$杂化且含孤电子对者，均不能是理想的平面或正四面体，必须根据孤电子对数减键角、改形状。
