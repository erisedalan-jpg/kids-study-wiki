知识精要

  • 水的离子积： $K_w = c(\mathrm{H}^+) \cdot c(\mathrm{OH}^-)$ 。 $K_w$ 只受温度影响，温度升高， $K_w$ 增大。常温（25℃）下 $K_w = 1.0\times 10^{-14}$ 。

解题方法与套路

  1. 定性判断先行，锁定溶液性质：
  2. 分析混合反应后的溶质组成，判断溶液是单一溶质还是混合溶质，显酸性、碱性还是中性。尤其注意酸、碱的强弱及是否完全反应。
  3. 选择核心计算公式，严守适用条件：
  4. 中性条件：明确温度，用 $c(\mathrm{H}^+) = c(\mathrm{OH}^-) = \sqrt{K_w}$ 判断。
  5. 酸性条件：优先求 $c(\mathrm{H}^+)$ 。
  6. 碱性条件：优先求 $c(\mathrm{OH}^-)$ ，再由 $K_w$ 换算求 $c(\mathrm{H}^+)$ 和pH。
  7. 含有难溶电解质：直接建立 $K_{sp}$ 与离子浓度的代数关系，解出 $c(\mathrm{OH}^-)$ 或 $c(\mathrm{H}^+)$。
  8. 代数表达式简化，避免复杂计算：
  9. 遇到字母型计算，直接列式化简，最终结果往往是对数形式。如由 $K_{sp} = b \cdot c^2(\mathrm{OH}^-)$ 导出 $c(\mathrm{OH}^-)= (\frac{a}{b})^{\frac{1}{2}}$ ，再代入 $K_w$ 求 $c(\mathrm{H}^+)$ 和pH。
  10. 极端情况验证：
  11. 混合后剩余离子浓度计算务必除以总体积。对于极稀溶液或涉及电离度很小的弱电解质，不能忽略水的电离。

高频易错

  • 混淆中性判据：将“ ${\rm pH}=7$ ”与“溶液呈中性”无条件等同。必须铭记：只有在常温（25℃）下，两者才等价。根本判据是 $c(\mathrm{H}^+) = c(\mathrm{OH}^-)$ 。
  • 酸碱混合计算时忽略过量体积：计算混合后过量的 $c(\mathrm{H}^+)$ 或 $c(\mathrm{OH}^-)$ 时，忘记分母为总体积（ $V_1+V_2$ ），或直接用物质的量差值替代浓度。
  • 强酸/碱混合向弱电解质的错误迁移：当酸碱恰好完全反应时，若一方为弱电解质，溶液并非中性，必须考虑盐的水解。例如，一元强酸与一元弱碱等浓度等体积混合，恰好反应生成强酸弱碱盐，溶液呈酸性。
  • 弱酸特殊行为的认知缺失：对于特定形式的弱酸问题（如膜平衡问题），未准确理解自由扩散组分（分子形态）与不能扩散组分（离子形态）的浓度关系，导致无法建立正确的平衡表达式。
  • 指示剂选择失误：不理解指示剂变色范围与滴定突跃范围的匹配原则，误选石蕊作中和滴定指示剂，或对强碱滴定弱酸（酚酞）和强酸滴定弱碱（甲基橙）的选择规则记忆混淆。
  • 有效数字和对数运算失分：在求解对数形式的pH表达式时，对 $\lg(\frac{K_w}{\sqrt{K_{sp}}})$ 等复杂表达式的代数变换出错，或忘记 $\lg 1 = 0, \lg 10^x = x$ 等基本运算。

代表题 2: 2012-新课标-05

  • 题目：温度为 $T$ 时 $K_w$ 已知。将浓度为 $a \, {\rm mol \cdot L^{-1}}$ 的一元酸HA与 $b \, {\rm mol \cdot L^{-1}}$ 的一元碱BOH等体积混合，判断溶液呈中性的依据。
  • 思路：核心陷阱在于酸碱性判断的根本法则和温度对pH的影响。需要逐一审视每个选项是否在任何条件下都必然推出 $c(\mathrm{H}^+) = c(\mathrm{OH}^-)$ 。
  • 步骤：
  • A项分析： $a=b$ 且等体积混合，只能说明酸碱物质的量相等，即恰好完全反应。若HA、BOH均为强电解质，则呈中性；若有一方为弱电解质，盐会水解，必不呈中性。故A不能作为充要依据。
  • B项分析： ${\rm pH}=7$ 只在常温（ $K_w=10^{-14}$ ）下才指示中性。温度为 $T$ 时 $K_w$ 未知， ${\rm pH}=7$ 时 $c(\mathrm{H}^+)=10^{-7}{\rm mol\cdot L^{-1}}$ ，但 $c(\mathrm{OH}^-)$ 不确定，所以无法判定是中性。故B错。
  • C项分析：由 $K_w = c(\mathrm{H}^+) \cdot c(\mathrm{OH}^-)$ 可知，当 $c(\mathrm{H}^+) = \sqrt{K_w}$ 时，必然有 $c(\mathrm{OH}^-) = \frac{K_w}{\sqrt{K_w}} = \sqrt{K_w}$ ，即 $c(\mathrm{H}^+) = c(\mathrm{OH}^-)$ 。这是一个与温度无关的、恒成立的中性判据。故C正确。
  • D项分析： $c(\mathrm{H}^+) + c(\mathrm{B}^+) = c(\mathrm{OH}^-) + c(\mathrm{A}^-)$ 是溶液中永远成立的电荷守恒式，与酸碱性完全无关。故D错。
  • 点评/变式：此题极具典型性，揭示了溶液中性判断的两大核心：①根本判据是 $c(\mathrm{H}^+)=c(\mathrm{OH}^-)$；② $K_w$ 是温度的函数。变式训练可关注不同温度下， pH与pOH的加和不再等于14，以及如何用 pOH 来便捷描述碱性溶液。

代表题 3: 2022-全国乙-07

  • 题目：体系中，一元弱酸HA的 $K_a=1.0\times 10^{-3}$ 。 $\mathrm{H^+}$ 与 $\mathrm{A^-}$ 无法穿透隔膜，未电离的HA可自由穿过膜两侧并达到平衡。
  • 思路：解题关键在于理解膜平衡的本质：当未电离的HA自由穿过并在膜两侧达到溶解平衡时，膜两侧溶液中HA分子的浓度必然相等。以此为桥梁，结合各自侧溶液内的电离平衡，可以关联两侧的离子浓度。
  • 步骤：
  • 假设膜左侧溶液（低pH侧，如含强酸）中HA浓度为 $c(\mathrm{HA}){\text{左}}$ ，右侧溶液（通常为纯水或缓冲液）中HA浓度为 $c(\mathrm{HA}))}}$ 。达平衡时， $c(\mathrm{HA{\text{左}} = c(\mathrm{HA})$ 。}
  • 对任一侧HA的电离平衡均有： $K_a = \frac{c(\mathrm{H}^+) \cdot c(\mathrm{A}^-)}{c(\mathrm{HA})}$ 。
  • 因此， $c(\mathrm{A}^-) = K_a \cdot \frac{c(\mathrm{HA})}{c(\mathrm{H}^+)}$ 。由于 $c(\mathrm{HA})$ 在两侧相等， $\frac{c(\mathrm{A}^-){\text{左}}}{c(\mathrm{A}^-)^+)}}} = \frac{c(\mathrm{H{\text{右}}}{c(\mathrm{H}^+)$ 。}}
  • 此式揭示了膜两侧 $c(\mathrm{A}^-)$ 的巨大差异源于 $\mathrm{H^+}$ 浓度差异。高酸度一侧（ $c(\mathrm{H}^+)$ 大） $c(\mathrm{A}^-)$ 被抑制至极低；低酸度一侧 $c(\mathrm{A}^-)$ 则相对较高。
  • 点评/变式：本题是电离平衡在新型情景下的迁移应用，不涉及具体数值计算，重在考察对“平衡时分子浓度一致”这一点的逻辑推导。易错点是误以为膜两侧离子也达到浓度相等，或无法找到HA浓度相等这一关键纽带。
