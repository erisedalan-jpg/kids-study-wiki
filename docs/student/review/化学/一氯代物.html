一氯代物

考点一氯代物权重7真题数1学科化学父主题反应类型与基本反应

考点定位

  • 父主题：反应类型与基本反应
  • 权重 weight：7
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 一氯代物：有机物分子中的一个氢原子被氯原子取代所生成的产物，属于取代反应。
  • 同分异构体数目：一氯代物的种类数等于分子中不同化学环境的氢原子（等效氢）的种类数。
  • 等效氢判断原则：
  • 同一碳原子上的氢原子等效。
  • 同一碳原子上所连相同取代基上的氢原子等效（如连有两个相同的甲基，则两个甲基上的氢等效）。
  • 处于分子对称性对应位置上的氢原子等效（镜面对称、轴对称或中心对称）。
  • 常见对称性操作：旋转对称、轴对称、中心对称。优先找对称面/对称轴，将分子分成对称的片段，处于对称位置的氢原子等效。

解题方法与套路

  1. 看清结构：给出结构简式或键线式，先准确写出或想象出完整的分子骨架，特别注意苯环的连接方式和取代基位置。
  2. 找对称性：画出分子的所有对称轴（或对称面），利用对称性将分子中的氢原子分区。对称位置上的氢原子属于同一种等效氢。
  3. 逐类标注/计数：沿着碳骨架，对不能通过对称性互相重合的氢原子分类编号。注意：
  4. 同一个碳上的氢一般等效（若无手性）。
  5. 连在同一个碳上的相同基团，其对应位置的氢等效。
  6. 苯环上处于邻、间、对等位置，需结合整体对称性判断。
  7. 数种数：等效氢有几类，一氯代物就有几种。必要时可以画出几种一氯代产物的结构验证是否重复。

高频易错

  • 对称轴找不全：多苯环联苯类分子（如联苯、三联苯、四联苯）存在多条对称轴，需同时考虑“穿过中心键的轴”和“垂直于中心键的轴”，只考虑一条容易漏数等效氢种类。
  • 忽略旋转对称：某些分子存在旋转轴，看似不同的位置经旋转后可重合，应视为等效。
  • 误将同一苯环上的不同位置都当作不等效：若分子有整体对称性，不同苯环上的对应位置可能等效。如四联苯中两端的苯环通过中心对称或轴对称等效。
  • 计数不完整：在纸上标注时，遗漏某些碳上的氢，特别是有氢的碳原子较多时，应逐一定位，标号核对。
  • 与二氯代物混淆：本题只判断一氯代物，不需要考虑第二个取代基的位置，不可用定位法复杂化。

代表题精讲

代表题1：2014-新课标Ⅱ-02（四联苯的一氯代物）

题目：四联苯（四个苯环直接相连成直链状）的一氯代物有几种？

思路：四联苯结构为苯－苯－苯－苯直连，分子具有轴对称性和中心对称性。先画出结构，找到所有对称关系，然后将所有氢原子按“是否可以通过对称操作互换”进行分类，一氯代物种数等于等效氢种类数。

步骤： - 画出四联苯骨架：从左到右依次为苯环A（端基）、B、C、D（端基）。苯环A与B以单键相连，B与C、C与D同样以单键相连。 - 确定对称元素：该分子沿中间键的垂直平分面具有镜面对称，即整个分子左右对称。具体而言，苯环A与D完全对称，苯环B与C完全对称。同时，分子沿长轴方向也有垂直于纸面的对称面，每个苯环自身还有对称性。 - 分类计数氢原子（以代表题解析的编号为例）： - 苯环A上：1、2、3、4位（其中1位是对位，2是邻位，3是间位）。由于苯环A内部没有进一步的对称使其1、2、3、4位等效，因此它们不同。但考虑到整个分子的对称性，苯环D上的对应位置与A等效。 - 苯环B上：与C对称等效。B环上的氢位置有类似A环的区分。 - 具体等效关系：解析中提到的1、9、10、18等效（端基苯环的对位氢），2、8、11、17等效（端基苯环邻位且靠近外侧位置），3、7、12、16等效（间位），4、6、13、15等效（另一邻位），5、14等效（中间两个苯环的对位氢？这里5和14是B环和C环上对称的位置）。 - 最终得到5种等效氢。 - 结论：一氯代物有5种，选C。

点评/变式：联苯类分子的一氯代物种数主要考查对称分析能力。变式训练：三联苯的一氯代物有几种？（答案：4种，中间苯环对称轴明显）。还可以改变连接方式，如带有侧链或多支链的联苯，需要综合考虑侧链的对称性和苯环上氢的等效关系。关键还是“等效氢三原则”的综合运用。
