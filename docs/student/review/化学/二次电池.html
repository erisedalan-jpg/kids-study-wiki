二次电池

考点二次电池权重9真题数1学科化学父主题化学反应原理

考点定位

  • 父主题：化学反应原理
  • 权重 weight：9
  • 真题数：1；年份跨度：2013–2013
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 二次电池（可充电电池）：放电时自发进行氧化还原反应，将化学能转化为电能（原电池）；充电时在外接电源作用下逆向反应，电能转化为化学能（电解池）。
  • 电极判断与反应：
  • 放电：负极发生氧化反应（活泼金属失电子），正极发生还原反应（得电子）。
  • 充电：阴极发生还原反应（得电子，与外接电源负极相连）；阳极发生氧化反应（失电子，与外接电源正极相连）。充电时，原来的负极变为阴极，原来的正极变为阳极。
  • 离子移动：
  • 放电时：阳离子移向正极，阴离子移向负极；
  • 充电时：阳离子移向阴极，阴离子移向阳极。若为离子导体（如固体电解质、隔膜），对应的导离子（如$Na^+$）可在两区间定向迁移以平衡电荷。
  • 典型二次电池反应书写：
  • 总反应应满足可逆：$氧化剂+还原剂 \underset{充电}{\stackrel{放电}{\rightleftharpoons}} 氧化产物+还原产物$
  • “ZEBRA”蓄电池（钠-氯化镍电池）：
    • 放电总反应：$2Na + NiCl_2 = 2NaCl + Ni$
    • 充电总反应：$2NaCl + Ni = 2Na + NiCl_2$
    • 放电负极：$Na - e^- = Na^+$
    • 放电正极：$NiCl_2 + 2e^- = Ni + 2Cl^-$
  • 固体电解质（钠离子导体陶瓷管）只允许$Na^+$通过，充放电时$Na^+$在正负极室之间双向迁移。

解题方法与套路

  1. 快速判断原电池/电解池：看题干描述——“蓄电池”“可充电电池”意味着放电为原电池，充电为电解池；结构图若显示外接电源则为充电过程，否则默认为放电过程。
  2. 电极反应式的书写步骤（可逆电池）：
  3. 首先写出总反应（已知或自行推断）。总反应可由活性物质与产物判断，如金属钠与金属氯化物生成氯化钠和该金属。
  4. 负极（放电）确定：活泼金属失电子，对应充电时为阴极得电子。
  5. 正极（放电）确定：由总反应减去负极反应，注意电荷守恒与物料守恒，配平。
  6. 充电反应直接倒推，正极变阳极，负极变阴极，电极反应式把电子写在反向即可。
  7. 离子导体/离子交换膜的移动方向：
  8. 放电时，阳离子向正极移动；充电时，阳离子向阴极移动（即原电池的负极）。电池电解质中携带电荷的离子必须与电极反应消耗或生成的离子种类相匹配。
  9. 分析选项常见考点：
  10. 写出总反应并判断生成物；
  11. 判断电极反应式书写是否正确（电荷守恒、介质条件）；
  12. 判断离子迁移方向（结合电场与反应区离子浓度变化）；
  13. 充电时的电极名称与连接（“正接正，负接负”——原电池负极放电后充电时与外电源负极相连成为电解池阴极）。

高频易错

  • 误判电池总反应：题干给出复杂材料时，没抓住氧化剂、还原剂核心。ZEBRA电池中钠是还原剂，被氧化的产物是$NaCl$（与$Cl^-$结合），而不是直接还原陶瓷管中的其他元素。若出现“钠还原铝的化合物”之类描述，必为错误。
  • 电极反应式配平忽略介质：熔融盐或固体电解质中，电极反应式的$Na^+$与$Cl^-$并不都以自由离子形式大量存在，但需保证两侧电荷与元素守恒。常见错误是正极反应写成$Ni^{2+} + 2e^- = Ni$，而题干实际参与反应的是$NiCl_2$。
  • 离子移动方向混淆：放电时$Na^+$通过钠离子导体向正极移动，补充正极区消耗的$Na^+$（正极生成$Cl^-$，与迁移来的$Na^+$形成$NaCl$）。充电时$Na^+$向阴极（原负极）移动，方向恰好相反。选项常设计为“放电时钠离子向负极移动”或“充电时钠离子向正极移动”等错误表述。
  • 电极名称张冠李戴：放电时负极（$Na$），充电时成为阴极，题目可能叫“充电时与电源负极相连的一极”或“放电时负极在充电时作为阳极”这类叙述，需看清文字陷阱。
  • 忽略陶瓷管的作用：陶瓷管为钠离子导体，只允许$Na^+$通过，隔绝其他物质，防止钠与正极材料直接接触发生危险。若选项说“电子通过陶瓷管”或“$Cl^-$通过陶瓷管”则错误。

代表题精讲

代表题 2013-新课标Ⅱ-05

题目：“ZEBRA”蓄电池的结构如图，电极材料为多孔$Ni/NiCl_2$和金属钠，之间由钠离子导体制作的陶瓷管相隔。下列关于该电池的叙述错误的是： A. 电池反应中有$NaCl$生成；
B. 电池的总反应是金属钠还原三价铝的化合物；
C. 正极反应为：$NiCl_2 + 2e^- = Ni + 2Cl^-$；
D. 钠离子通过钠离子导体在两电极间移动。

思路：这是一道典型的二次电池选择题，需结合蓄电池结构，确定放电时的氧化剂与还原剂、电极反应及离子移动。放电时钠为负极，镍从$+2$价被还原到$0$价，生成$NaCl$；陶瓷管为钠离子导体，$Na^+$可迁移；选项B中“三价铝”与题干材料无关，应直接锁定。

步骤： 1. 确定放电总反应：负极$Na$被氧化为$Na^+$，正极$NiCl_2$中$Ni^{2+}$被还原为$Ni$，$Cl^-$与$Na^+$结合生成$NaCl$。总反应为$2Na + NiCl_2 = 2NaCl + Ni$。可见产物有$NaCl$，A正确。 2. 检查B：总反应涉及的是$Ni^{2+}$被还原，并非铝的化合物，B错。该题选错误的叙述，故B为答案。 3. 验证C：正极为$NiCl_2$得电子，还原为$Ni$，同时释放$Cl^-$，正确反应为$NiCl_2 + 2e^- = Ni + 2Cl^-$，C正确。 4. 验证D：钠离子导体允许$Na^+$穿越陶瓷管，放电时$Na^+$由负极区向正极区移动，充电时反向，D正确。

点评/变式：该题以钠基二次电池为载体，考查电化学基础知识的灵活迁移。失分点主要在：① 看到陌生结构图便慌乱，不能快速列出氧化剂、还原剂；② 忽视题干暗示的离子导体，错误判断离子移动；③ 对“还原三价铝”这类明显与物质成分无关联的描述失去警惕。变式训练可更换为锂离子电池、钠硫电池等，同样抓总反应、电极反应、隔膜导离子类型即可迎刃而解。解题核心口诀：放电负氧化，正还原；充电反向接，阴阳倒。总反应用减法，离子移动看电场。
