知识精要

  • 短周期元素：前18号元素（H→Ar），原子序数1–18；前20号元素包含K（19）、Ca（20）。推断时需熟练记忆1–20号元素的原子结构、电子排布与常见化合价。
  • 电子排布与结构：
  • “空间运动状态数”= 占据的原子轨道数（不是电子数）。如N的$1s^22s^22p^3$占用5个轨道（1s, 2s, $2p_x,2p_y,2p_z$），故有5种空间运动状态。
  • 未成对电子数：由轨道排布图快速判断。如O的$2p^4$有2个未成对电子，S的$3p^4$也有2个。C（$2p^2$）和Si（$3p^2$）同样有2个未成对电子。
  • 成键与杂化：根据价层电子对互斥理论（VSEPR）判断分子构型与键角。孤电子对数越多，对成键电子对的排斥越大，键角通常越小。如$\mathrm{NH_3}$（1对孤电子对，三角锥形，键角约$107^\circ$）> $\mathrm{H_2O}$（2对孤电子对，V形，键角约$105^\circ$）。
  • 元素周期律与性质比较：
  • 原子半径：同周期从左到右逐渐减小，同主族从上到下逐渐增大。电子层数越多，半径越大。
  • 单质沸点：晶体类型主导。一般：原子晶体 > 离子晶体 > 分子晶体。分子晶体中，相对分子质量越大，范德华力越大，沸点越高（如$\mathrm{H_2}$与$\mathrm{O_2}$）。固态非金属单质（如S）沸点高于常见气体单质。
  • 氢化物键角：比较中心原子的杂化方式及孤电子对数。
  • 导电性：金属单质（如Al）为导体，导电性强于半导体（如Si）。
  • 特征离子与配合物：
  • 常见阴离子团：$\mathrm{SO_4^{2-}}$、$\mathrm{CO_3^{2-}}$、$\mathrm{NO_3^-}$等。能与过渡金属离子形成稳定化合物。
  • 配合物：由中心离子（或原子）与配体通过配位键结合形成。配位原子是提供孤电子对直接与中心原子成键的原子。如$\mathrm{[Cu(NH_3)_4]SO_4}$中，配位原子是N，而不是O。
  • 焰色试验：绿色→$\mathrm{Cu^{2+}}$；黄色→$\mathrm{Na^+}$；紫色（透过蓝色钴玻璃）→$\mathrm{K^+}$。
  • ds区元素：包括ⅠB族（Cu、Ag、Au）和ⅡB族（Zn、Cd、Hg）。

解题方法与套路

  1. 锁定特征信息，建立突破口：从最鲜明、最独特的性质入手。
    • 焰色反应：可直接确定金属元素（如绿色→Cu）。
    • 电子运动状态/未成对电子数：反推原子序数范围。常见情况要烂熟于心：2个未成对电子（ⅣA族或ⅥA族），3个未成对电子（ⅤA族），1个未成对电子（ⅠA、ⅢA、ⅦA族）。
    • 分子总电子数、结构式：如$\mathrm{YW_4X_8Z \cdot 4W_2Z}$可拆解为$\mathrm{W_4X_8Z_4Y}$和结晶水，联想常见硫酸盐复盐或配合物形式。
    • 特殊位置关系：“同周期相邻”、“与Ar电子数相等”、“低价氧化物与单质电子总数相等”等，快速缩窄范围。
  2. 利用数学关系，建立方程组：将文字条件转化为关于原子序数（或核外电子数、最外层电子数）的等式或不等式。如“原子序数依次增加，且加和为21”，结合其他定性关系可大幅减少试错成本。
  3. 结合化学常识，筛选验证：推断出的元素必须能形成题干给出的化合物，并符合所有描述的化学行为。
    • 观察化合物形式，推测常见化合价与基团。例如，看到$\mathrm{QZY_4}$形式，应联想$\mathrm{CuSO_4}$、$\mathrm{CaSO_4}$等，再结合Q为$\mathrm{Cu}$（焰色），Y、Z必为O、S。
    • 将候选元素代入反应流程：“逐渐通入至过量”→涉及沉淀生成与溶解，立即联想$\mathrm{CuSO_4}$溶液与氨水的反应（生成蓝色$\mathrm{Cu(OH)_2}$沉淀，后溶解得深蓝色溶液）。
  4. 逐项分析选项，精准判断：元素完全确定后，每个选项都要严谨地用化学原理验证，切勿凭感觉。
    • 看状态比沸点：先看常温状态（固/液/气），再比微粒间作用力。
    • 算杂化比键角：写出中心原子的VSEPR模型，比较孤电子对数。
    • 辨类型断键性：活泼金属与活泼非金属间通常为离子键。
    • 抓定义析配合物：分清组成原子与配位原子，配位原子必须直接提供孤电子对成键。

高频易错

  • 状态与构型混淆：比较沸点时，不能只看分子间作用力，要先看常温状态。例如，单质S为固体，其沸点天然高于气体$\mathrm{O_2}$和$\mathrm{H_2}$。误用分子间作用力规律直接比较S和$\mathrm{O_2}$会出错。
  • 导电性异常：非金属单质的导电性通常弱于金属单质，不能想当然地认为“原子序数大，单质性能就强”。如Al为导体，Si为半导体，导电性Al > Si。
  • 键角比较漏洞：忘记比较孤电子对的影响。$\mathrm{NH_3}$和$\mathrm{H_2O}$虽均为$sp^3$杂化，但$\mathrm{H_2O}$有2对孤电子对，对成键电子对压缩更强，键角（≈$105^\circ$）小于$\mathrm{NH_3}$（≈$107^\circ$）。
  • 配合物配位原子误判：在$\mathrm{[Cu(NH_3)_4]SO_4}$中，与中心离子$\mathrm{Cu^{2+}}$直接配位的是$\mathrm{NH_3}$中的N原子，而不是外界$\mathrm{SO_4^{2-}}$中的O原子。试题常设陷阱，将外界离子中的O设为配位原子。
  • 酸性强弱对比绝对化：“最高价”氧化物的水化物酸性才有规律性递变。如题干只说“Z的氧化物的水化物”，则包括$\mathrm{H_2SiO_3}$（弱酸）等，不能直接应用“高价酸酸性强”的规律与碳酸对比。
  • 推断顺序混乱：不从明确的“题眼”（如焰色、空间运动状态）入手，反而在模糊的位置关系上纠结，导致耗时过长或推断中断。必须由确定性信息向外辐射推理。

题目：2024-辽宁-11（节选）W、X、Y、Z为原子序数依次增大的短周期元素。基态X原子核外电子有5种空间运动状态，基态Y、Z原子有两个未成对电子，Q是ds区元素，焰色试验呈绿色。反应涉及物质$\mathrm{3XW_4}$和$\mathrm{QZY_4}$等。下列说法错误的是：A. 单质沸点 Z>Y>W； B. 简单氢化物键角 X>Y； C. 反应过程中有蓝色沉淀产生； D. $\mathrm{QZX_4Y_4W_{12}}$是配合物，配位原子是Y。

思路： 1. 从焰色反应“绿色”确定Q为Cu元素。 2. 从“空间运动状态5种”推断X为第二周期N/O/F之一。 3. 从“两个未成对电子”推断Y、Z为ⅣA或ⅥA族。结合原子序数依次增大和形成$\mathrm{CuZY_4}$，推断出合理解是$\mathrm{SO_4^{2-}}$，故Y为O、Z为S，倒推出X必为N。 4. 由$\mathrm{XW_3}$ (即$\mathrm{NH_3}$)推断W为H。 5. 代入选项逐一验证。

点评/变式：本题综合性强，结合了原子结构、元素周期律、分子构型、配合物和元素化学性质。关键突破口是“空间运动状态”和“焰色反应”这两个专有名词的理解。变式训练可关注将“空间运动状态”替换为“电子云伸展方向”或“不同能级”，将配合物变为其他多组分物质，考查学生信息迁移和结构分析能力。

题目：2021-全国乙-05（节选）短周期元素W、X、Y、Z，原子序数依次增大，最外层电子数之和为15。X、Y、Z为同周期相邻元素，且均不与W同族。判断下列叙述正确的是：A. 原子半径 W>X>Y>Z； B. 化合物XW中的化学键为离子键； C. Y单质导电性弱于Z单质； D. Z的氧化物的水化物酸性强于碳酸。

思路： 1. 利用“同周期相邻”、“最外层电子数和为15”及“均不与W同族”建立等式，推断W最外层电子数。 2. 根据短周期元素限制，确定W所在族，再推出具体元素。 3. 依据元素周期律和单质导电性常识，分析每个选项。

步骤： 1. 推断过程：设W最外层电子数为a。X、Y、Z同周期相邻，且最外层电子数加和为15。因三者相邻，其最外层电子数可设为b, b+1, b+2。则a + b + (b+1) + (b+2) = 15 → a + 3b = 12。 2. 讨论可能的a值。W为短周期元素且原子序数最小，均不与X、Y、Z同族，意味着a不等于b, b+1, b+2中的任何一个。 - 若a=6 (ⅥA族)，则b=2。X、Y、Z最外层电子数分别为2, 3, 4。它们为同周期相邻元素，不与ⅥA族的W同族，且位于W之后。推断W=O，X=Mg, Y=Al, Z=Si。符合所有条件。 - 若a=3 (ⅢA族)，则b=3，与“均不与W同族”矛盾，舍去。 3. 元素确定：W=O, X=Mg, Y=Al, Z=Si。 4. 选项分析： - A：原子半径，同周期Mg>Al>Si，W(O)电子层为2层，半径小于均为3层的三者。故半径顺序为 Mg>Al>Si>O，即X>Y>Z>W，A错误。 - B：化合物XW为MgO，由活泼金属与活泼非金属形成，是离子化合物，键为离子键。B正确，符合题意。 - C：Y（Al）为金属铝，是电的良导体；Z（Si）为半导体硅，其导电性介于导体
