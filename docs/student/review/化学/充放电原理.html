充放电原理

考点充放电原理权重5真题数1学科化学父主题化学反应原理

考点定位

  • 父主题：化学反应原理
  • 权重 weight：5
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 二次电池与充放电本质：放电时自发进行氧化还原反应，化学能转化为电能；充电时借助外加电源（或光能等）使反应逆向进行，电能转化为化学能。
  • 电极判断与极性转换：
  • 放电：负极发生氧化反应，正极发生还原反应。
  • 充电：阴极发生还原反应（与外电源负极相连），阳极发生氧化反应（与外电源正极相连）。
  • 同一电极对应关系：放电时的负极在充电时变为阴极；放电时的正极在充电时变为阳极。
  • 电极反应式书写关键（以本题 $2Li-O_2$ 电池为例）：
  • 光照充电体系：光催化电极吸收光能产生电子（$e^-$）和空穴（$h^+$）。电子和空穴分别驱动两极反应，替代传统外电路电流。
  • 阴极反应（还原）：$Li^+ + e^- = Li$（锂离子得电子，发生还原反应，沉积金属锂）。
  • 阳极反应（氧化）：$Li_2O_2 + 2h^+ = 2Li^+ + O_2 \uparrow$（过氧化锂失去电子给空穴，发生氧化反应，释放锂离子和氧气）。
  • 粒子流向：
  • 外电路（或光生载流子）：$e^-$ 流向阴极（进行还原反应）；$h^+$ 流向阳极（进行氧化反应）。
  • 内电路（电解质）：阳离子（$Li^+$）移向阴极，阴离子移向阳极。

解题方法与套路

  1. 判装置，定题型：识别题目是新型二次电池，区分放电过程与充电过程。
  2. 析信息，标价态：
  3. 对于充电过程，抓住“光催化电极产生 $e^-$ 和 $h^+$ 驱动”这一关键信息。
  4. 标注关键元素价态变化：$Li$（$0$ 价）与 $Li^+$（$+1$ 价）；$O$ 在 $Li_2O_2$ 中为 $-1$ 价，在 $O_2$ 中为 $0$ 价。
  5. 定极性与反应类型：
  6. 得电子（$e^-$）的一极为阴极，发生还原反应。
  7. 失电子（与 $h^+$ 结合）的一极为阳极，发生氧化反应。
  8. 口诀：阳氧阴还（充电时阳极氧化，阴极还原）。
  9. 逐项验，避陷阱：
  10. 检查电极反应式是否满足电荷守恒与元素守恒。
  11. 核对电极名称（阴极/阳极 vs 负极/正极）是否与过程（充电/放电）匹配。
  12. 判断离子迁移方向时，紧扣“异性相吸”：阳离子移向得电子的阴极。

高频易错

  • 混淆放电与充电的电极称谓：直接将充电时的“阴极”称为“负极”，或将“阳极”称为“正极”。必须明确：负极/正极是针对放电（原电池）而言；阴极/阳极是针对充电（电解池）而言。
  • 不理解光生空穴（$h^+$）的角色：误认为 $h^+$ 是阳离子，向阴极移动。$h^+$ 本质是电子空位，具有很强的得电子能力（氧化性），在电场作用下移向阳极，相当于阳极“失电子”的一种途径。
  • 对 $Li_2O_2$ 中氧元素价态误判：误认为氧是 $-2$ 价，导致无法正确分析阳极反应。在过氧化物中，氧为 $-1$ 价，其被空穴氧化生成 $O_2$（$0$ 价）。
  • 电子与离子流向混淆：误认为在内电路中电子由阴极流向阳极，或误认为 $Li^+$ 移向阳极。内电路靠离子导电，阳离子移向阴极，阴离子移向阳极。

代表题精讲

题目：（2022-全国乙-06）$2Li-O_2$ 电池光照充电时，光催化电极产生电子和空穴，驱动阴极反应（$Li^+ + e^- = Li$）和阳极反应（$Li_2O_2+2h^+=2Li^++O_2$）。判断相关叙述的正误。

思路： 此题为新型充电电池分析题。关键是读懂“光催化电极产生电子和空穴驱动”这一新情境，将其类比为外接电源。电子给出的极区发生还原反应，为阴极；空穴接受的极区发生氧化反应，为阳极。结合题给的两个电极反应式，分析各种表述。

步骤： 1. 辨析电极反应与名称：题给反应 $Li^+ + e^- = Li$ 是得电子（利用 $e^-$）的还原反应，故此极为阴极。另一反应 $Li_2O_2+2h^+=2Li^++O_2$ 是失电子（利用 $h^+$ 移除电子）的氧化反应，故此极为阳极。这是充电过程。 2. 推导放电过程：充电时的阴极在放电时作负极，反应为 $Li - e^- = Li^+$；充电时的阳极在放电时作正极，反应为 $2Li^+ + O_2 + 2e^- = Li_2O_2$。 3. 分析粒子迁移：充电时，内电路中 $Li^+$ 向发生还原反应（消耗 $Li^+$ 得电子）的阴极移动。 4. 判断选项正误（基于常见命题点）： - 若称“该极为负极”或“该极发生氧化反应”，因描述的是充电过程且对应阴极，必错误。 - 若称“光催化电极产生空穴移向阴极”，必错误，$h^+$ 移向阳极。 - 充电时 $Li^+$ 向阴极迁移的叙述正确。 - 放电时正极反应为 $O_2$ 得电子与 $Li^+$ 结合生成 $Li_2O_2$ 的叙述正确。

点评/变式： - 点评：本题核心陷阱是利用全新“光催化充电”情境考查电解池最基础的极性判断与电极反应原理。考生需剥离新颖情境，紧扣“电子—还原—阴极，空穴—氧化—阳极”这一不变规律。 - 变式：若题给电极改为“光催化电极产生电子和空穴驱动放电”，则产生电子的极区发生氧化反应，为负极；驱动空穴的极区发生还原反应，为正极。情境一变，原理不变。
