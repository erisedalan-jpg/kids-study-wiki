知识精要

分子空间构型的核心判断依据是价层电子对互斥理论（VSEPR）与杂化轨道理论。
- VSEPR模型：中心原子周围的价层电子对（成键电子对+孤电子对）因排斥而尽量远离，由此决定电子对的空间排布，略去孤电子对后即得分子构型。
- 孤电子对数公式：$孤电子对数 = \frac{1}{2}(a - x b)$
$a$——中心原子价电子数（主族元素等于最外层电子数）；
$x$——与中心原子结合的原子数；
$b$——每个配位原子达到稳定结构所需电子数（H为1，其他原子通常为$8-$该原子最外层电子数）；
对于离子，$a$ 需相应加减离子电荷数。
- 价层电子对数 $= \sigma$ 键电子对数 $+$ 孤电子对数。
- 杂化轨道类型：由价层电子对数直接推出（2对→$sp$，3对→$sp^2$，4对→$sp^3$，5对→$sp^3d$，6对→$sp^3d^2$），构型与VSEPR模型一致。
- 键角：受孤电子对排斥力（孤对-孤对 $>$ 孤对-成键 $>$ 成键-成键）及配位原子电负性影响。无孤电子对时，键角为标准值（如 $sp^2$ 杂化平面三角形 $120^\circ$，$sp^3$ 杂化正四面体 $109.5^\circ$）。
- 常见构型：$sp$→直线形（$180^\circ$），$sp^2$→平面三角形（$120^\circ$）或V形（有孤对），$sp^3$→正四面体形、三角锥形或V形等。
- 考点常结合等电子体原理（如 $BF_3$ 与 $CO_3^{2-}$、$NO_3^-$ 互为等电子体，构型相似）进行拓展。

解题方法与套路

  1. 锁定中心原子：通常是化合价绝对值最大或电负性较小的原子（H、F除外）。
  2. 计算价层电子对数：
  3. $\sigma$ 键电子对数 = 与中心原子直接相连的原子数（即单键、双键、三键各计为一对）。
  4. 孤电子对数 = $\frac{1}{2}(中心原子价电子数 + 离子电荷数调整 - 配位原子达稳定所需电子总数)$。
  5. 总电子对数 = $\sigma$ 键电子对数 + 孤电子对数。
  6. 确定VSEPR模型：总电子对数 $n$ → 电子对空间构型（2直线、3平面三角、4正四面体等）。
  7. 判断分子空间构型：去掉孤电子对占据的位置，只看配位原子空间排布。
  8. 得出杂化方式与键角：杂化类型 $sp^{n-1}$（$n$ 为总电子对数），根据构型及孤对影响确定键角范围。
  9. 交叉验证：利用等电子体、化学键极性、分子对称性等检查合理性。

高频易错

  • 中心原子价电子数取错：对于阳离子少算电子，阴离子多算电子（如 $BF_4^-$ 中 B 价电子数需 $3+1=4$）。
  • 双键/三键仍计为一对$\sigma$成键电子，误将 $\pi$ 键计入价层电子对数导致错误。
  • 混淆VSEPR模型与分子构型：计算时只写总电子对构型，未略去孤对，导致错判（如 $NH_3$ 电子对四面体而分子为三角锥形）。
  • 孤电子对数目公式用错：配位原子为氢与卤素时稳定所需电子数不同，H需2，卤素需1（因其已有7个电子，需1个成键）；氧、硫等需2。
  • 直接记构型不看价态：同一元素不同价态或不同配位原子个数会导致构型变化（如 $BCl_3$ 与 $BF_4^-$）。
  • 误判杂化：如看到 $BF_3$ 就认为B与三个F成键是 $sp^3$，未算孤对导致错误（无孤对应为 $sp^2$）。
  • 键角比较时忽略孤对斥力或配位原子电负性：如 $NH_3$ 键角 $107^\circ < 109.5^\circ$，而 $NF_3$ 键角比 $NH_3$ 更小。

代表题精讲

代表题（2011·新课标，12题节选）

题目
判断 $BF_3$ 分子的 $F-B-F$ 键角、B原子杂化类型，以及 $BF_4^-$ 的立体结构。

思路
用VSEPR理论先求价层电子对数 → 确定电子对构型与杂化 → 根据有无孤对得到分子/离子构型和键角。

步骤
1. $BF_3$ 分析
- B最外层电子3个，为 $\sigma$ 键电子对数 $=3$（连3个F）。
- 孤电子对数 $= \frac{1}{2}(3 - 3\times 1)=0$（每个F需1个电子成键）。总电子对 $=3$。
- VSEPR模型为平面三角形，杂化 $sp^2$，无孤对，所以分子构型即为平面三角形，键角 $=120^\circ$。

  1. $BF_4^-$ 分析
  2. 阴离子，中心B价电子数调整为 $3 + 1=4$。
  3. $\sigma$ 键电子对 $=4$，孤电子对 $= \frac{1}{2}(4 - 4\times 1)=0$，总电子对 $=4$。
  4. 电子对构型为正四面体，无孤对，离子构型为正四面体形，B杂化 $sp^3$。

点评/变式
- 等电子体联想：$BF_3$ 与 $CO_3^{2-}$、$NO_3^-$ 互为等电子体，同样为平面三角形、$sp^2$ 杂化；$BF_4^-$ 与 $CCl_4$、$SiF_4$、$NH_4^+$ 均属正四面体、$sp^3$ 杂化。
- 变式：若将 $B$ 换为同族 $Al$，如 $AlCl_3$（气态）也为 $sp^2$ 平面三角形；但 $AlF_6^{3-}$ 则为 $sp^3d^2$ 八面体。通过改变中心原子半径及价层可扩展。
- 注意该题后续还涉及六方氮化硼层内 $B-N$ 共价键（$sp^2$ 杂化解释平面层）和层间分子间作用力，表明杂化理论不仅适于孤立的分子，也可用于分析原子晶体的局部结构，需灵活迁移。
