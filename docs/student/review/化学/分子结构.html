分子结构

考点分子结构权重0真题数1学科化学父主题化学键与分子结构

考点定位

  • 父主题：化学键与分子结构
  • 权重 weight：0
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：选择3
  • 难度分布：易1

知识精要

  • ⅣA族元素成键特性：碳、硅以共价键为主；锗、锡、铅可形成共价键、离子键或金属键（取决于化合物与晶型）。
  • 共价键：原子间通过共用电子对形成的相互作用。非金属与氧形成的化合物中通常为极性共价键（电负性差 $\Delta\chi < 1.7$）。
  • $SiO_2$ 的结构与键型：每个 $Si$ 与 $4$ 个 $O$ 以 $sp^3$ 杂化形成共价键，构成空间网状原子晶体；不存在独立的 $SiO_2$ 分子，化学式仅代表原子个数比。$Si-O$ 键为强极性共价键。
  • $CO_2$ 的结构与键型：线型分子，$C$ 以 $sp$ 杂化与 $O$ 形成 $C=O$ 双键（σ键+π键），属共价键。固态（干冰）为分子晶体，分子间以范德华力维系。
  • 原子晶体与分子晶体的判断：
  • 典型原子晶体：$SiO_2$、$SiC$、金刚石、晶体硅。
  • 典型分子晶体：多数非金属氧化物（如 $CO_2$、$SO_2$）、卤素单质、稀有气体晶体。
  • 判断依据：看构成微粒是原子还是分子，以及微粒间作用力是共价键还是分子间作用力。

解题方法与套路

  1. 先判键型，再定晶体
  2. 根据元素的电负性差大致判断键的离子性/共价性；
  3. 结合典型结构记忆：$SiO_2$、金刚石等为原子晶体，$CO_2$、$H_2O$ 等为分子晶体。
  4. 紧扣构成微粒
  5. 描述中若出现“$SiO_2$ 分子”“干冰由原子构成”之类说法，必为错误。
  6. 对于氧化物，微观看是原子直接结合还是以分子单元存在。
  7. ⅣA族的递变线索
  8. 碳、硅：典型非金属，几乎全为共价键。
  9. 铅：金属性较强，部分化合物显离子性（如 $PbF_2$）。
  10. 利用周期律预判：同族从上到下，共价键极性增强、离子性倾向增大（与电负性变化一致）。
  11. 选择题快速排除法
  12. 遇到“都是”“全部”等绝对化表述，往往错误；
  13. 熟记反例：$SiO_2$ 不是分子晶体，$CO_2$ 不是原子晶体。

高频易错

  • 错点1：认为 $SiO_2$ 是由 $SiO_2$ 分子构成的分子晶体。
    → 正：$SiO_2$ 为原子晶体，晶体中最小环为 $12$ 元环（$6$ 个 $Si$、$6$ 个 $O$），不存在单个分子。
  • 错点2：误以为 $CO_2$ 中 $C$ 与 $O$ 不是共价键，或写成 $C-O$ 单键。
    → 正：$CO_2$ 结构式为 $O=C=O$，是 $C=O$ 双键（共价键），分子间作用力不是化学键。
  • 错点3：混淆化学键与分子间作用力。
    → $CO_2$ 分子内为共价键，分子间是范德华力（有时有氢键）。选择题中常将此作为混淆选项。
  • 错点4：认为同族元素化合物键型完全相同。
    → ⅣA族中 $SiO_2$ 为原子晶体，$SnO_2$、$PbO_2$ 则可能显现一定离子性或金属性，键型并不完全一致。
  • 错点5：忽略同素异形体或晶型差异（如碳可形成金刚石、石墨，前者原子晶体，后者混合键型层状结构），但针对本题，碳的氧化物皆为分子晶体。

代表题精讲

题目（2008年全国Ⅱ卷第3题）
对于ⅣA族元素，判断下列叙述的正误（节选关键选项）：

$SiO_2$ 和 $CO_2$ 中，$Si$ 和 $O$、$C$ 和 $O$ 之间都是共价键。

思路
确认 $SiO_2$ 与 $CO_2$ 的微观结构及键型。只要两者均存在共用电子对，即为共价键。注意区分分子内化学键与分子间作用力。

步骤
1. 分析 $SiO_2$：属原子晶体，每个 $Si$ 与周围 $4$ 个 $O$ 以 $Si-O$ 极性共价键结合，形成 $Si-O$ 单键。因此 $Si$ 与 $O$ 之间确为共价键。
2. 分析 $CO_2$：$CO_2$ 分子内 $C$ 与 $O$ 通过 $C=O$ 双键结合，既有 σ 键又有 π 键，均属于共价键。尽管 $CO_2$ 固体是分子晶体，但分子内化学键的性质仍为共价键。
3. 结论：该叙述正确。原题要求选出“不正确”的叙述，故本选项不是答案。

点评/变式
- 本题的核心迷惑点在于将“$SiO_2$ 没有单个分子”与“$Si-O$ 不是共价键”相混淆。只要抓住原子之间通过共用电子对成键就是共价键，与是否形成分子晶体无关。
- 变式1：“$SiO_2$ 是由 $SiO_2$ 分子构成的”为错误说法。
- 变式2：“干冰（$CO_2$）中碳氧原子间以离子键结合”为错误，干冰分子内仍为共价键，升华只破坏分子间作用力。
- 应试策略：遇到同族元素氧化物比较键型时，优先从晶体类型和电负性差入手，避免因晶体类型不同而否定共价键的存在。
