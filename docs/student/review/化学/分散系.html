分散系

考点分散系权重7真题数1学科化学父主题基本概念与物理量

考点定位

  • 父主题：基本概念与物理量
  • 权重 weight：7
  • 真题数：1；年份跨度：2018–2018
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 分散系：把一种（或多种）物质分散在另一种（或多种）物质中所得到的体系。其中被分散的物质称为分散质，容纳分散质的物质称为分散剂。
  • 分类依据：按分散质粒子直径（$d$）大小：
  • 溶液：$d < 1\,\text{nm}$，均一、稳定，分散质以分子或离子形式存在。
  • 胶体：$1\,\text{nm} \leqslant d \leqslant 100\,\text{nm}$，相对稳定，具有丁达尔效应等特性。
  • 浊液：$d > 100\,\text{nm}$，不均一、不稳定，易沉降或分层。
  • 胶体重要性质：
  • 丁达尔效应：光束通过胶体时形成光路，可用于区分胶体与溶液。
  • 电泳：胶粒带电在电场中定向移动。
  • 聚沉：加热、加电解质、加带相反电荷胶粒的胶体可使胶体沉淀。
  • 气溶胶：分散剂为气体的胶体，如雾、云、烟、霾等。雾和霾的分散剂均为空气（分散质为小液滴或固体颗粒）。
  • 概念辨析：雾（液态分散质）与霾（固态分散质）的分散剂相同，均为空气，均属于气溶胶。

解题方法与套路

  1. 锁定分散系三要素：审题时立刻判断题目所涉及体系的分散质、分散剂、所属类别（溶液/胶体/浊液/气溶胶）。
  2. 粒子直径定类别：若给出直径数据，直接与 $1\,\text{nm}$ 和 $100\,\text{nm}$ 比较，确定属于哪类分散系。
  3. 关键性质对应：
  4. 检验胶体 → 丁达尔效应；
  5. 胶体聚沉方法 → 加热、加电解质、混合相反电荷胶体；
  6. 雾、霾 → 气溶胶，分散剂为空气。
  7. 跨学科情境剥离：遇见环境、生活背景题（如雾霾、PM2.5、氮肥等），提取与分散系直接相关的选项，优先利用分散系基本概念判断正误，不被无关化学过程迷惑。

高频易错

  • 雾和霾的分散剂不同：误认为雾分散剂是水、霾分散剂是空气。实际上二者分散剂均为空气，雾的分散质是小液滴，霾的分散质是固体微粒。
  • 胶体与溶液外观混淆：认为所有均一透明的就是溶液，忽略胶体也可能澄清透明（如 Fe(OH)₃ 胶体），必须用丁达尔效应区分。
  • 粒径范围记混：把胶体粒径上限定为 $100\,\text{nm}$ 记成 $50\,\text{nm}$ 或 $200\,\text{nm}$，导致分类错误。
  • PM2.5 非胶体：PM2.5（直径 $\leqslant 2.5\,\mu\text{m} = 2500\,\text{nm}$）从粒子尺寸看属于粗分散系（大于 $100\,\text{nm}$），不是胶体。部分颗粒落入胶体范围，但不能一概而论说 PM2.5 全为胶体。
  • 催化剂概念混用：题目中用氨参与反应生成铵盐而称其为“催化剂”，实则 NH₃ 作为反应物被消耗，不符合催化剂定义。需注意分散系相关判断常与基本概念（催化剂的“一变两不变”）结合出题。

代表题精讲

题目（2018·新课标Ⅱ卷 第2题）

研究表明，氮氧化物和二氧化硫在形成雾霾时与大气中的氨有关（如流程图所示）。下列叙述错误的是 A．雾和霾的分散剂相同
B．雾霾中含有硝酸铵和硫酸铵
C．NH₃ 是形成无机颗粒物的催化剂
D．雾霾的形成与过度施用氮肥有关

思路
本题以雾霾成因的环境问题为情境，由流程图可知 NH₃ 与 NO₂、SO₂ 转化产物反应生成铵盐。选项交叉考查分散系、元素化合物及催化剂基本概念。重点：选项 A 直接关联分散系考点——雾和霾的分散剂；结合分散系知识可直接判断，无需分析完整化学过程。

步骤
- A 选项：雾（液态水微粒分散在空气中）和霾（固体颗粒分散在空气中）的分散剂均为空气，属于气溶胶。故 A 正确。
- B 选项：由图可知 NH₃ 参与反应生成 NH₄NO₃ 和 (NH₄)₂SO₄，成为无机颗粒物成分，故 B 正确。
- C 选项：图中 NH₃ 最终转化为铵盐，氮元素进入颗粒物，NH₃ 是反应物而并非催化剂（没有恢复原状、未改变反应路径但自身消耗），故 C 错误。
- D 选项：过度施用氮肥会释放较多 NH₃（含氮物质），进而促进雾霾中铵盐生成，故 D 正确。
答案选 C。

点评/变式
- 本题最直接的分散系考查落在 A 项，需牢记“气溶胶”的概念，明确雾和霾的分散剂同为空气，分散质状态不同导致现象差异。
- 变式：将选项改为“雾的分散剂是水蒸气，霾的分散剂是空气”，需判断正误——错误，分散剂不是分散质本身。
- 催化剂概念的混用在此类题目中常见，凡是反应中消耗掉的物质，一定不是催化剂。
- 环境背景题常跨多个考点，解题时可“先辨分散系，再析反应物”，保证基础概念不失分。
