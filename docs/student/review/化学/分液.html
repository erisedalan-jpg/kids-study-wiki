分液

  • 父主题：化学实验

  • 真题数：1；年份跨度：2013–2013
  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 分液原理：利用两种互不相溶的液体密度的差异，在分液漏斗中静置分层后，通过下口或上口分离。
  • 适用条件：混合物中至少有两种互不相溶的液体（如有机层与水层）。萃取常与分液联用，溶质在两相间分配后分层分离。
  • 主要仪器：分液漏斗（梨形或球形）、铁架台（或铁圈）、烧杯。
  • 操作要点：
  • 检漏：使用前检查分液漏斗活塞和上口塞是否漏水。
  • 混合与放气：装入液体后盖好上口塞，倒转分液漏斗，振荡使两相充分接触；振荡过程中不断打开活塞放出因振摇产生的气体，防止内部压力过大。
  • 静置分层：将分液漏斗置于铁圈上静置，待明显分层。
  • 分液：打开上口塞（或使塞凹槽对准漏斗上的小孔），使内外气压相等；下层液体从下口放出，上层液体从上口倒出，不可经下口放出以避免污染。
  • 相关应用：在有机合成实验中，反应后分离有机相与水相；洗涤有机相除去杂质；干燥前分离干燥剂等。

解题方法与套路

  1. 识别分液场景：分析题目中混合物组成，判断是否存在不相溶液层，常见如“分离水层与有机层”“将馏出物倒入分液漏斗中分去水层”。
  2. 联系操作步骤：按“检漏→加液→振荡→放气→静置→分液”顺序检索题目所考环节。
  3. 规范表述：回答操作类填空题时，注意要点完整。如“分去水层”应指明从下口放出还是上口倒出；若有机物密度比水小，油层在上，分液时应先放出下层水，然后从上口倒出有机层。
  4. 注意隐含条件：题干给的密度、溶解性数据可用于判断哪一层在上、哪一层在下，以及能否发生乳化等。
  5. 结合物质性质防错：如有强酸/强氧化剂参与，分液时需考虑漏斗材质（玻璃活塞是否需涂凡士林，是否耐腐蚀）；若产物易挥发或易燃，操作环境与干燥方法的选择也常关联。

高频易错

  • 上下口搞反：不放上口塞（未与大气相通），导致下层液体放不出来；上层液体也从下口放出，使上层沾污下口管壁，引入杂质。
  • 忘记放气：尤其是用碳酸钠溶液洗酸或反应产生气体时，直接振荡不按时放气，可能冲开塞子、损失产物甚至引发安全事故。
  • 未检漏：直接使用漏液的分液漏斗，导致液体洒漏，分离失败。
  • 混淆分液与蒸馏/过滤：见到“收集某温度范围馏分”误作分液，其实蒸馏是分离沸点不同的互溶液体；分液专用于分离不互溶液体。
  • 干燥步骤顺序错误：分液所得液体常含少量水，先分液后干燥再进行蒸馏，若顺序颠倒或未干燥彻底即蒸馏，可能导致沸点偏差、产品纯度下降、暴沸等。
  • 忽视密度数据：密度用来判断有机层在上还是在下；常见有机溶剂（如醚、酯、烃）多比水轻，卤代烃常比水重，但正丁醛密度 0.8017 g·cm⁻³ 比水小，分液时应从下口放出水层，从上口倒出正丁醛层。

代表题精讲

题目（2013·新课标Ⅱ·8节选）正丁醛合成实验中，将 Na₂Cr₂O₇ 氧化正丁醇所得混合蒸气冷凝馏出物倒入分液漏斗，分去水层，有机层干燥后蒸馏收集 75～77℃ 馏分，产量 2.0 g。题目还考查了沸石作用及浓硫酸稀释操作，并间接关联分液与干燥。

思路
围绕分液漏斗在有机合成后处理中的应用，考察了分液操作的原理、上下层判断及与干燥、蒸馏的衔接。结合正丁醛（密度 0.8017 g·cm⁻³）微溶于水、正丁醇与水的密度差异，判断有机层在上，水层在下；由微溶可知两相仍有一定互溶，需经干燥除水再蒸馏。

步骤
1. 分离目标：馏出物含水层（含少量未反应醇、无机盐）和有机层（主产物正丁醛及少量正丁醇）。倒入分液漏斗静置分层。
2. 分层判断：正丁醛密度 0.8017 g·cm⁻³ 小于水，有机层在上层，水层在下层。
3. 分液操作：打开分液漏斗上口塞，从下口慢慢放出下层水层；待界面降至活塞处时关闭活塞；将上层正丁醛层从上口倒入干燥锥形瓶。
4. 后续处理：有机层加无水干燥剂（如无水硫酸钠）干燥，过滤除去干燥剂，蒸馏收集 75～77℃ 馏分得纯正丁醛。

点评/变式
本题通过完整工艺流程串联多个考点。分开设问虽未直接要求填“分液”，但对分液过程的理解决定了能否正确判断分层、解释干燥必要性。变式：若同样实验改用密度大于水的有机溶剂（如二氯甲烷），有机层在下层，分液时放出下层有机层，水层从上口倒出，此时若仍从上口倒有机层则失误。复习时应灵活运用密度数据，牢记“下下上上”原则——下层由下口出，上层由上口出。
