分液与干燥

知识精要

  • 分液
  • 定义：分离两种互不相溶的液体混合物的操作。
  • 主要仪器：分液漏斗、铁架台（带铁圈）、烧杯。
  • 适用条件：两种液体互不相溶且密度不同，形成清晰界面。
  • 操作要点：“验漏—加液—振荡—放气—静置—分液”。
    • 验漏：使用前检查分液漏斗上口玻璃塞和活塞是否漏水。
    • 振荡：双手托住分液漏斗，倒转，使液体充分接触后放气，重复数次。
    • 静置：将分液漏斗置于铁圈上，使液层充分分层。
    • 分液：下层液体从下口放出，上层液体从上口倒出。
  • 干燥
  • 目的：除去液体有机物中残留的少量水分。
  • 常用干燥剂选择原则：
    • 不与待干燥物发生反应；
    • 不溶于待干燥物；
    • 吸水性好，干燥速度快。
  • 常见干燥剂及适用范围：
    • 无水氯化钙（CaCl₂）：适用于烃类、卤代烃、醚类，不能干燥醇、胺、氨（会形成配合物）。
    • 无水硫酸镁/硫酸钠：中性，适用范围广，干燥速度较氯化钙慢。
    • 碱石灰/NaOH：适用于干燥碱性或中性气体，不能干燥酸性气体或酯。
    • 浓硫酸：用于酸性或中性气体的干燥。
  • 液态有机物干燥一般操作：向分液后的液体中加入适量固体干燥剂，振荡、静置，待液体澄清后过滤或倾析。

解题方法与套路

  1. 明确分离对象：判断待分离混合物中各组分的物理性质（溶解性、密度、沸点、酸碱性），确定需要进行的单元操作（萃取、洗涤、分液、蒸馏、干燥）。
  2. 确定洗涤与分液顺序：
  3. 有水溶性杂质时，先用水洗，以除去大部分水溶性物质。
  4. 有酸性或碱性杂质时，依次用碱液（如NaOH、Na₂CO₃溶液）和酸液（如稀HCl）洗涤，将杂质转化为盐进入水层。
  5. 每步洗涤后均需充分振荡、放气、静置，然后分液，弃去水层，保留有机层。
  6. 最后再用水洗一次，以除去残留的酸或碱。
  7. 选择干燥剂并干燥：
  8. 根据有机物的性质（是否含活泼氢、是否与干燥剂反应）选择合适干燥剂。
  9. 加入干燥剂至不再结块（块状干燥剂）或液体澄清透明，静置后过滤或直接倾析得到干燥液体。
  10. 常见答题模板：
  11. “NaOH溶液洗涤的作用”：除去……（如未反应的Br₂、酸性物质）。
  12. “加入无水CaCl₂的目的”：干燥（除去有机层中残留的水）。
  13. 分离顺序填空：水洗→碱洗→水洗→干燥→蒸馏（或其他后续操作）。

高频易错

  • 分液漏斗使用：忘记验漏；振荡时未及时放气导致漏斗内气压过大而冲塞；分液时将上层液体也从下口放出，造成污染。分液操作中“下流上倒”原则混淆。
  • 洗涤时保留相判断错误：不清楚有机层在上在下，应根据密度判断。如溴苯密度（1.50 g·cm⁻³）大于水，有机层在下；苯密度（0.88 g·cm⁻³）小于水，有机层在上。洗涤后分液时务必保留目标产物所在相。
  • 干燥剂选择不当：
  • 对含—OH、—NH₂的有机物使用氯化钙，会形成配合物损失产物；
  • 用无水CaO干燥醇、酸等，可能反应；
  • 气体干燥时，选错酸性/碱性干燥剂导致反应。
  • 干燥操作疏漏：干燥后未过滤或倾析，直接将干燥剂与液体一起加热蒸馏，可能引起暴沸或干燥剂分解。
  • 实验步骤术语混淆：把“洗涤”和“萃取”混淆，把“分液”和“蒸馏”适用条件搞混，在不需要蒸馏时贸然加热。

代表题精讲

题目（2012新课标卷节选）：实验室制备溴苯，反应后混合物经水洗过滤除铁屑，滤液依次用10 mL水、8 mL 10% NaOH溶液、10 mL水洗涤，分液后向有机相中加入无水氯化钙，静置过滤。回答洗涤与干燥相关问题。

思路：
- 反应为苯与溴在铁催化下生成溴苯和HBr，同时残余Br₂。
- 水洗初步除去水溶性HBr；碱洗（NaOH溶液）与Br₂、残留HBr反应，生成溶于水的NaBr、NaBrO等；最后水洗除去残留的NaOH。
- 分液后粗溴苯中含微量水，加入无水氯化钙与之结合，干燥后过滤除去吸水后的氯化钙。

步骤：
1. 识别杂质：HBr（气体，溶于水）、未反应的液溴（Br₂）、少量水。
2. 第一次水洗：溶解HBr和部分Br₂，分液弃水层（有机层因密度大在下层，保留）。
3. NaOH溶液洗：$2\mathrm{NaOH}+\mathrm{Br_2} \rightarrow \mathrm{NaBr}+\mathrm{NaBrO}+\mathrm{H_2O}$，$\mathrm{NaOH}+\mathrm{HBr}\rightarrow\mathrm{NaBr}+\mathrm{H_2O}$，使溴和HBr转入水层，分液弃去。
4. 第二次水洗：洗去可能残留的NaOH，分液弃水层。
5. 干燥：向有机相（溴苯）中加入无水氯化钙，振荡静置，无水氯化钙吸收水分。
6. 过滤：滤去氯化钙水合物等固体，得到干燥溴苯。

点评/变式：
- 本流程是“洗涤—分液—干燥”的经典模板，常用于液态有机物的初步纯化。
- 若题目问“能否用NaOH溶液代替Na₂CO₃溶液洗涤？”，需考虑苯酚等杂质的去除效果或乳化风险，但本题中NaOH即可。
- 变式：若产物为硝基苯（密度>1），分液时保留下层；若为乙酸乙酯（密度<1），则保留上层。干燥剂常用无水硫酸钠代替氯化钙，尤其当产物为酯时，避免氯化钙与酯结合。干燥后精制常需进一步蒸馏。
