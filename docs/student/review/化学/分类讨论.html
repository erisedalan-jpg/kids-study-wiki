知识精要

有机反应类型本质是官能团转化与化学键断裂/生成的规律体现。高中阶段必须精准区分四大基础反应类型：

  • 取代反应：有机物分子里的某些原子或原子团被其他原子或原子团所替代。特征：“一上一下，有进有出”，即断一个键、成一个键。常见：烷烃卤代、苯的卤代/硝化/磺化、醇与氢卤酸取代、酯化反应、水解反应（卤代烃、酯、糖、蛋白质）。
  • 加成反应：有机物分子中不饱和键（双键、三键、苯环等）断裂，与其它原子或原子团直接结合生成较饱和的化合物。特征：“断一加二，只上不下”。常见：烯/炔与 $X_2$、$H_2$、$HX$、$H_2O$ 加成，苯与 $H_2$ 加成，醛/酮与 $H_2$ 加成。
  • 消去反应：有机物分子中脱去小分子（如 $H_2O$、$HX$）生成不饱和键。特征：“一分子内脱下两个原子/原子团，形成不饱和键”。常见：醇（浓 $H_2SO_4$、加热）和卤代烃（NaOH醇溶液、加热）的消去。
  • 氧化/还原反应：在有机中，加氧去氢为氧化，加氢去氧为还原。常见：醇→醛→酸、烯/炔被酸性 $KMnO_4$ 氧化、醛的银镜反应等。

守恒与定量计算背景下“分类讨论”的要点：通过对反应前后原子种类、数目及价键变化的分析，准确归类，为后续配平、产率计算奠定基础。

解题方法与套路

跨真题归纳的通用判断步骤：

  1. 标官能团与不饱和键：快速识别反应物中是否含 $\ce{C=C}$、$\ce{-OH}$、$\ce{-COOH}$、苯环等特征结构。
  2. 对比产物骨架与官能团：看产物分子骨架碳数是否增加、官能团种类变化、小分子是否生成。
  3. 若产物中出现两种有机物分子碎片结合（如酸+醇→酯），极可能为取代。
  4. 若反应物有不饱和键而产物饱和（无小分子脱去）→加成。
  5. 若反应物为一分子饱和物，产物出现了不饱和键并脱去小分子（$H_2O$、$HX$）→消去。
  6. 原子/原子团“替换”判断：对于苯环上的反应，若苯环上一个 $H$ 被其他原子团替换（如 $\ce{-NO2}$、$\ce{-Br}$），即为取代。
  7. 排除干扰型：酯化反应（$RCOOH + R'OH \rightleftharpoons RCOOR' + H_2O$）本质是羧酸中 $-OH$ 被烷氧基取代，属取代反应；硝化、磺化同理。

高频易错

  • 加成与取代混淆：烯烃与 $Br_2$ 反应，若为加成（$\ce{CH2=CH2 + Br2 -> CH2Br-CH2Br}$），双键断裂；若在光照或高温下烷烃与 $Br_2$ 反应，则为取代。真题①即为典型加成，误判为取代者极多。
  • 误认为酯化反应是加成或其它类型：酯化产生 $H_2O$，结构变化为酸断 $C-O$ 键、醇断 $O-H$ 键，是取代。③为酯化，属于取代。
  • 忽略消去反应的特征：见 $H_2O$ 小分子脱去便以为是取代，但应看是否形成不饱和键。②乙醇分子内脱水生成 $\ce{CH2=CH2}$，为消去。
  • 苯环上的反应类型模糊：苯与 $HNO_3$ 生成硝基苯，苯环上一个 $H$ 被 $-NO_2$ 替代，是取代；若审题不仔细误记为加成（苯与 $H_2$ 加成才是环己烷）。
  • “守恒”暗示被忽略：分类讨论时可通过原子守恒快速排查选项——加成后所有原子均进入产物，取代则生成两种化合物。

代表题精讲

代表题：2011-新课标-03

题目：下列反应中，属于取代反应的是
① $\ce{CH3CH=CH2 + Br2 -> CH3CHBrCH2Br}$
② $\ce{CH3CH2OH -> CH2=CH2 + H2O}$
③ $\ce{CH3COOH + CH3CH2OH -> CH3COOCH2CH3 + H2O}$
④ $\ce{C6H6 + HNO3 -> C6H5NO2 + H2O}$

思路：逐项分析官能团变化与原子替换关系。①为丙烯与溴反应，双键被加成饱和；②乙醇脱去一分子水生成乙烯，出现不饱和键；③酸与醇生成酯和水；④苯与硝酸生成硝基苯和水。重点判断是否有“原子/原子团被替换”。

步骤： 1. 反应①：$\ce{CH3CH=CH2}$ 含碳碳双键，与 $Br_2$ 作用后双键打开，两个 $Br$ 原子分别加到两个碳上，所有原子均进入产物，属于加成反应。 2. 反应②：反应物乙醇为饱和化合物，产物乙烯含碳碳双键并脱去一分子 $H_2O$，属于消去反应。 3. 反应③：乙酸中 $\ce{-OH}$ 被 $\ce{-OCH2CH3}$ 替代，乙醇中羟基 $H$ 被乙酰基替代，同时生成 $H_2O$，符合“有进有出”，属于取代反应（酯化）。 4. 反应④：苯环上一个 $H$ 原子被 $\ce{-NO2}$ 替代，生成 $H_2O$，亦为取代反应（硝化）。 综上，属于取代反应的是 ③④。

点评/变式：本题以经典反应直接考查类型判定，失分点往往在①误判为取代（受烷烃卤代影响）和③误认为不是取代。变式训练可给出新情景反应，如“$\ce{CH3CH2Br + NaOH ->[\text{水}] CH3CH2OH + NaBr}$”让学生通过“基团替换”特征判断为取代（水解），从而固化“取代必有进有出”的模型。在守恒与定量计算中，锁定反应类型是正确配平与列物质关系式的前提。
