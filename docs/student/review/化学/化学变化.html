化学变化

考点定位

  • 父主题：反应类型与基本反应
  • 权重 weight：0
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 定义：化学变化（化学反应）的本质是有新物质生成，而物理变化则没有新物质生成。二者区分的唯一标准是变化前后物质的分子组成（或原子结合方式）是否发生改变。
  • 微观本质：旧化学键断裂与新化学键形成。
  • 宏观特征：常伴随发光、放热、变色、生成气体或沉淀等现象，但这不是判断的金标准。
  • 常见物理变化：升华、蒸发、凝固、液化、吸附（活性炭）、萃取、分液、蒸馏、升华、盐析。
  • 常见化学变化：燃烧、金属锈蚀、食物腐败、呼吸作用、光合作用、电解质电离、水解、氧化、老化、硫化、硝化等。
  • 同位素间转化（核反应）不属于化学变化，属于核物理变化。

解题方法与套路

  1. 审题与锚定核心概念 立即圈出题干设问关键词：“化学变化”或“物理变化”。判断标准有且仅有一个——有无新物质生成。
  2. 逐项拆解过程机理 对每个选项描述的现象，必须进行过程还原，明确是物理作用还是化学反应在主导：
    • 吸附类：多利用表面微孔或静电作用截留物质，本质是物理作用力。代表：活性炭除味、硅胶吸水。
    • 去油污类：需分辨机理。碱液去油污利用了酯的碱性水解，为化学变化；而汽油、洗涤剂去油污主要利用溶解或乳化，为物理变化。
    • 保鲜抗氧化类：常包含多步化学作用。如高锰酸钾除乙烯（氧化还原）、铁粉除氧气（氧化还原）、生石灰吸水（化合反应）。注意区分并存的物理过程。
    • 吸附干燥类：硅胶、分子筛吸水多为物理变化。
  3. 精炼排除法 迅速找到选项中“明显无新物质生成”（如纯粹粒子扩散、相变或物理吸附）的选项；或锁定“绝对有键的断裂与形成”的选项（如从反应物生成结构完全不同的产物）。
  4. 总结规律 生活情境题本质都是对核心概念的包装。只要抓住“是否生成新物质”这一把钥匙，所有场景都能迎刃而解。

高频易错

  • 误判油脂去污的原理：只用热水或用洗洁精洗涤油污，是利用热使油脂流动性增强（物理变化）或乳化作用（物理变化）；但热碱水去油污，是因为油脂在碱性条件下发生了不可逆的彻底水解（皂化反应），是化学变化。
  • 混淆不同干燥剂的原理：硅胶干燥是单纯的物理吸附；生石灰干燥是发生化合反应变为熟石灰，属于化学变化。
  • 忽视复杂体系中的化学主因：选项 D “硅胶、铁粉”组合，铁粉氧化放热消耗氧气（双重防氧化），虽有硅胶物理吸水，但整个体系的关键保鲜动因靠的是铁粉的化学反应，整体发生化学变化。
  • 概念不清：误认为有能量变化或状态变化就一定是化学变化（如灯泡发光为物理变化）。
  • 特殊物质变化：电解质溶液的导电过程发生了电解，是化学变化；而金属导电仅仅是电子定向移动，是物理变化。

代表题精讲

题目：（2014·新课标Ⅱ）判断“用含硅胶、铁粉的透气小袋与食品一起密封包装”等过程，哪一个未发生化学变化。 思路：紧扣定义“未有新物质生成即物理变化”。对每个选项，问自己：进去的物质和出来的物质在分子层面上是否改变了？ 步骤： - A项：活性炭依靠疏松多孔的结构吸附异味分子，异味分子本身未被破坏，活性炭也未与它反应。这是一个纯粹的分子表面输运与驻留过程，无新物质，属物理变化。 - B项：炊具上油污高级脂肪酸甘油酯在碱性条件和加热催化下，酯基断裂，生成可溶于水的高级脂肪酸盐和甘油。产物结构截然不同，是彻底的化学变化。 - C项：水果释放植物催熟激素乙烯（$ \text{C}_2\text{H}_4 $），高锰酸钾具强氧化性，与之发生氧化还原反应破坏其碳碳双键，生成新物质。属化学变化。 - D项：铁粉是双吸剂核心。它与密封环境中的氧气反应生成三氧化二铁，作为核心保鲜机制，必发生化学变化；硅胶部分是物理吸附。整体过程有化学反应主导。 点评/变式： 本题示范了如何在生活情境中剥离表象看本质。此类题变式常在“油污去除”上设陷阱。例如将 B 项换成“用汽油擦拭衣物上的油渍”，则变为物理溶解（物理变化）；若换成“用洗洁精洗碗”，则是乳化作用（物理变化）。
