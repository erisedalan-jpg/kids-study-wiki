知识精要

  • 常用玻璃仪器及用途：三颈烧瓶（三口烧瓶）用于多口反应体系；滴液漏斗用于控制液体滴加速率；球形冷凝管用于回流，直形冷凝管用于蒸馏；分液漏斗用于分液；容量瓶用于配制一定物质的量浓度的溶液。
  • 实验基本操作与条件控制
  • 加料顺序：固体试剂常分批缓慢加入，以控制反应速率、避免温度剧升。
  • 温度控制：冰水浴用于强放热反应或低温反应；水浴适用于沸点以下且不与水反应的体系，温度上限约 $98^\circ \text{C}$；油浴用于需加热至 $100^\circ \text{C}$ 以上或体系不能接触水蒸气的反应。
  • 沉淀的洗涤与检验：向洗出液中加入特征试剂（如 $\text{BaCl}_2$ 检验 $\text{SO}_4^{2-}$），若无明显现象则洗涤完全；洗涤含酸的沉淀时，可用 $\text{pH}$ 试纸检测洗出液接近中性，间接证明酸（及对应的阴离子如 $\text{Cl}^-$）已洗净。
  • 重要无机反应
  • $\text{Cu(OH)}_2$ 受热分解生成黑色 $\text{CuO}$：$\text{Cu(OH)}_2 \xrightarrow{\Delta} \text{CuO} + \text{H}_2\text{O}$。
  • 酸性 $\text{KMnO}_4$ 与 $\text{H}_2\text{O}_2$ 的氧化还原反应：
    $$2\text{MnO}_4^- + 5\text{H}_2\text{O}_2 + 6\text{H}^+ = 2\text{Mn}^{2+} + 5\text{O}_2\uparrow + 8\text{H}_2\text{O}$$
  • 结晶水合物的性质：$\text{CuSO}_4\cdot5\text{H}_2\text{O}$ 在空气中易风化，部分或全部失去结晶水变为白色无水 $\text{CuSO}_4$。

解题方法与套路

  1. 仪器识别与选择：熟记教材中每种玻璃仪器的外观及功能，结合实验目的（配制溶液、蒸馏、回流、分液等）快速排除无关仪器。
  2. 试剂作用与反应条件分析：从题干中提取反应物状态、控温要求、加入顺序等信息，联系放热反应、温度对副反应的影响、反应速率控制等原理作答。
  3. 陌生氧化还原离子方程式的书写：先根据现象判断氧化剂与还原剂的产物（如紫色 $\text{MnO}_4^-$ → $\text{Mn}^{2+}$，$\text{H}_2\text{O}_2$ → $\text{O}_2$），再用化合价升降守恒、电荷守恒和质量守恒配平，注意酸性介质中不要漏掉 $\text{H}^+$。
  4. 离子洗涤终点的检验：明确目标杂质离子，选用特征沉淀试剂（如 $\text{Ba}^{2+}$ 检 $\text{SO}_4^{2-}$、$\text{Ag}^+$ 检 $\text{Cl}^-$）或 $\text{pH}$ 试纸间接检验（酸洗净），倒推取样、滴加试剂、描述现象与结论。
  5. 结晶与分离操作表述：加热浓缩、冷却结晶、过滤、洗涤、干燥的完整流程，理解趁热过滤与冷却过滤的适用差异。

高频易错

  • 仪器名称：三颈烧瓶误写为“三颈圆底烧瓶”“三口瓶”等不规范名称（标准名称“三颈烧瓶”）；球形冷凝管与直形冷凝管混淆进出水口（下进上出）；滴液漏斗写成“分液漏斗”（二者外形相似，滴液漏斗有活塞可调节滴速，用于加液）。
  • 条件控制理由：只答“防止反应过快”而忽略“反应放热”或“避免副反应”“防止液体暴沸飞溅”等核心原理；使用油浴而非水浴时，未点明“反应温度高于水的沸点”或“体系禁水”。
  • 离子方程式：缺写 $\text{H}^+$（如酸性 $\text{KMnO}_4$ 氧化 $\text{H}_2\text{O}_2$ 时没有补 $\text{H}^+$ 和 $\text{H}_2\text{O}$），或未配平电子转移与电荷，产物误写为 $\text{MnO}_2$。
  • 洗涤检验表述：直接写“加入 $\text{BaCl}_2$ 溶液”，遗漏“取少量最后一次洗出液于试管中”“先加稀盐酸酸化”等规范步骤；用 $\text{pH}$ 试纸检验 $\text{Cl}^-$ 时，理由未从“含 $\text{HCl}$ 的洗涤液呈酸性”逻辑推导。

代表题精讲

题目：2022-全国乙-09·二草酸合铜(Ⅱ)酸钾的制备

思路：本题以无机合成为载体，考查溶液配制仪器选择、结晶水合物的风化现象、沉淀转化及实验流程分析。解题需紧扣配制溶液所需的定量仪器、$\text{CuSO}_4\cdot5\text{H}_2\text{O}$ 风化失水变白、$\text{Cu(OH)}_2$ 受热分解生成 $\text{CuO}$ 等基础知识点，直接作答。
步骤
（1）由 $\text{CuSO}_4\cdot5\text{H}_2\text{O}$ 固体配制已知浓度的 $\text{CuSO}_4$ 溶液，通常需托盘天平、药匙、量筒、烧杯、玻璃棒、容量瓶、胶头滴管等，不需要分液漏斗、冷凝管等分离或回流仪器，故填“分液漏斗”。
（2）$\text{CuSO}_4\cdot5\text{H}_2\text{O}$ 在空气中部分失去结晶水，生成白色无水硫酸铜。
（3）$\text{CuSO}_4$ 与 $\text{NaOH}$ 溶液反应先产生 $\text{Cu(OH)}_2$ 浅蓝色沉淀，加热后 $\text{Cu(OH)}_2$ 分解为黑色 $\text{CuO}$。
点评/变式：制备型实验常隐含物质检验与基本操作，需理解每步转化的化学原理。变式可问“如何检验沉淀是否洗净 $\text{SO}_4^{2-}$”或“浓缩结晶后的一系列操作具体指什么”，需迁移洗涤检验和结晶过滤知识。

题目：2021-全国乙-09·氧化石墨烯的制备

思路：以新型材料制备为情境，考查仪器名称、控温原因、氧化还原反应用途及洗涤终点检验。需根据装置图辨识仪器，结合反应条件（冰水浴→油浴→98℃加热）分析控温目的，由颜色变化（紫色→土黄色）书写氧化还原方程式，并按规范步骤表述 $\text{SO}_4^{2-}$ 和 $\text{Cl}^-$ 的检验。
步骤
（1）仪器 a 为滴液漏斗，c 为三颈烧瓶；冷凝管 b 中冷却水应从下口 d 进、上口出。
（2）步骤Ⅰ反应强放热，分批缓慢加入 $\text{KMnO}_4$ 并冰水浴冷却，可防止因温度过高导致反应过快、副反应增多甚至液体飞溅。
（3）步骤Ⅱ需升温至 $98^\circ \text{C}$，水浴加热达不到该温度（水的沸点仅 $100^\circ \text{C}$，长时间加热不稳定），故用油浴。
（4）紫色悬浊液含过量 $\text{KMnO}_4$，滴加 $\text{H}_2\text{O}_2$ 将 $\text{MnO}_4^-$ 还原为无色 $\text{Mn}^{2+}$：
$$2\text{MnO}_4^- + 5\text{H}_2\text{O}_2 + 6\text{H}^+ = 2\text{Mn}^{2+} + 5\text{O}_2\uparrow + 8\text{H}_2\text{O}$$
（5）检测洗出液中是否存在 $\text{SO}_4^{2-}$：取少量最后一次洗出液于试管中，滴加稀盐酸至无明显现象，再滴入 $\text{BaCl}_2$ 溶液，若无白色沉淀生成，证明已洗净。
（6）$\text{HCl}$ 易溶于水，洗涤时 $\text{H}^+$ 与 $\text{Cl}^-$ 一并进入洗出液。用 $\text{pH}$ 试纸检测洗出液，若呈中性，说明 $\text{HCl}$ 已洗净，则 $\text{Cl}^-$ 亦洗净。
点评/变式：升华点在于用 $\text{pH}$ 试纸间接检验可溶性氯化物洗涤终点，减少了使用 $\text{AgNO}_3$ 的步骤，体现了“性质检验”的灵活思维。变式可替换试剂考查，如用 $\text{NaOH}$ 洗涤酸性杂质，同样可用 $\text{pH}$ 试纸检验洗涤完成。
