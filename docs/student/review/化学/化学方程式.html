知识精要

  • 化学方程式：用化学式表示化学反应的式子，必须遵循质量守恒定律（原子种类、数目不变），需注明必要的反应条件（如高温、催化剂、加热$\Delta$等），并正确标注物质状态（常见$g$气体$\uparrow$，沉淀$\downarrow$）。
  • 书写核心步骤：写反应物与生成物→配平化学计量数（先复杂物质后简单物质，奇数配偶法、氧化还原化合价升降法等）→注条件、标状态。
  • 焰色反应：部分金属或金属离子在灼烧时使火焰呈现特征颜色，属于物理变化，用于离子检验。钡离子—黄绿色（考题标答：绿色）。
  • 可溶性硫化物的性质：碱金属、碱土金属（除Be）硫化物如BaS易溶于水，但易水解，在潮湿空气中可被CO₂和H₂O作用生成碳酸盐沉淀，并放出H₂S气体（臭鸡蛋气味）。
  • 水煤气变换反应：$CO + H_2O \xrightarrow{催化剂} CO_2 + H_2$，用于除去有毒CO并制备清洁能源H₂。

解题方法与套路

  1. 读题－明确反应体系：从流程或叙述中提取反应物（含杂质、过量信息）和主要生成物，注意“还原”“焙烧”“潮湿空气”等关键词暗示的转化方向。
  2. 推断核心产物：
  3. 对题干给出化学式的产品（如立德粉$ZnS·BaSO_4$）、中级产物（如可溶性硫化钡）进行逆向推导；
  4. 利用氧化还原原理判断变价元素（如$BaSO_4$中+6价S被C还原为-2价S，C→CO）；
  5. 结合信息中“臭鸡蛋气味”定H₂S，“清洁能源气体”定H₂，“水溶性变差”定生成难溶物如BaCO₃。
  6. 配平与检查：优先配平金属→非金属（S、C）→H、O，最后用观察法调平气体和水。注意焦炭过量时生成CO而非CO₂。
  7. 规范书写：无遗漏条件（高温、催化剂、水蒸气）；有毒气体尾气CO需转化，清洁能源对应H₂，立刻联想到水煤气变换反应。
  8. 同类拓展：熟悉常见工业转化链——$BaSO_4 \xrightarrow{C} BaS \xrightarrow{潮湿空气} BaCO_3+H_2S$，可用于方程式书写和原因解释。

高频易错

  • 碳热还原硫酸盐产物误判：$BaSO_4$与过量C反应生成$BaS$，而非$BaO$；碳自身氧化产物为$CO$（不是$CO_2$），条件写高温或加强热。
  • 漏标气体和沉淀符号：$H_2S$是气体需标$\uparrow$，$BaCO_3$水溶性差实为沉淀需标$\downarrow$；$CO+H_2O$反应生成$CO_2$和$H_2$，均无毒，都不要气体符号（反应物中H₂O为气态则不标）。
  • 焰色反应描述混淆：Na—黄，K—紫（透过蓝色钴玻璃），Ca—砖红，Cu—绿，Ba—黄绿（常简记绿色），Sr—洋红。钡焰色易错选成黄或红。
  • “水溶性变差”原因解释不全：只写生成BaCO₃沉淀，漏写H₂S气体逸出或反应方程式不配平。
  • 条件遗漏：潮湿空气中必须强调$CO_2$和$H_2O$共同参与，只写与水反应不能完全符合事实。

代表题精讲

题目：2019·新课标Ⅱ·08节选

立德粉$ZnS·BaSO_4$的工业生产中，以重晶石（$BaSO_4$）为原料，在回转炉中被过量焦炭还原为可溶性硫化钡，写出化学方程式；并写出尾气中有毒气体通过水蒸气变换反应转化为CO₂和清洁能源气体的方程式。在潮湿空气中长期放置的“还原料”（BaS）会逸出臭鸡蛋气味气体且水溶性变差，解释原因。

思路：抓住还原过程“$BaSO_4$→$BaS$”，硫由+6价降至-2价，焦炭过量氧化产物为CO；尾气CO有毒，利用$CO+H_2O→CO_2+H_2$；还原料BaS在潮湿空气中，$CO_2$和$H_2O$与之反应生成不溶性$BaCO_3$和气体$H_2S$。

步骤：
- 第一个方程式：反应物BaSO₄与C，还原为BaS，C→CO，根据化合价升降配平$BaSO_4 + 4C \xrightarrow{\text{高温}} BaS + 4CO↑$。
- 第二个方程式：CO与水蒸气转化，生成CO₂和清洁能源H₂，原子守恒即得$CO + H_2O \xrightarrow{\text{催化剂}} CO_2 + H_2$。
- 原因解释：$BaS$在潮湿空气中与二氧化碳和水反应：$BaS + CO_2 + H_2O = BaCO_3↓ + H_2S↑$，难溶的$BaCO_3$生成导致水溶性变差，$H_2S$有臭鸡蛋气味逸出。

点评/变式：此题完美串联了氧化还原反应方程式的书写、尾气处理中的变换反应和对反应现象的解释。变式可延伸为“用还原料制备立德粉”时，加入ZnSO₄发生复分解反应$BaS + ZnSO_4 = ZnS↓ + BaSO_4↓$（共沉淀得立德粉），要求书写离子方程式，注意生成物均为沉淀，书写为$Ba^{2+} + S^{2-} + Zn^{2+} + SO_4^{2-} = ZnS↓ + BaSO_4↓$，易错漏写沉淀符号。
