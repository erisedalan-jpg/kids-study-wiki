化学方程式书写

考点化学方程式书写权重18真题数4学科化学父主题基本概念与物理量

考点定位

  • 父主题：基本概念与物理量
  • 权重 weight：18
  • 真题数：4；年份跨度：2012–2021
  • 出现题位：选择5 选择8 选择10 选择11
  • 难度分布：中4

知识精要

  • 化学方程式的定义：用化学式表示化学反应的式子，需遵循客观事实与质量守恒定律。
  • 书写核心原则
    • 符合客观事实：反应物、生成物种类及转化关系必须真实。如 $Na_2O_2$ 在空气中变质主要与 $CO_2$、$H_2O$ 反应，并非自身分解。
    • 质量守恒：原子种类与数目在反应前后不变，必须配平。
    • 条件与状态标注：方程式中标明必要的反应条件（如“高温”“焙烧”），生成物若有沉淀“$\downarrow$”或气体“$\uparrow$”需正确标注。
  • 书写依据与信息源
    • 定性信息：题干中的“主要成分”“转化为”“析出”等描述，直接指明反应物和核心产物。
    • 定量信息：工艺流程题中的金属离子沉淀pH范围，可判断复分解反应进行的趋势和产物的具体形态。
    • 类比迁移：如碱性氧化物、两性氧化物与酸或铵盐的反应规律具有相似性。

解题方法与套路

  1. 锁定反应物与核心产物 通读题干，圈画“xx与xx反应生成xx”“xx转化为xx”等关键句，明确参与反应的主要物质和最终含核心元素的产品。对于流程题，要结合前后工序确定进入和离开某步骤的物质。
  2. 推断缺失的产物 根据元素守恒和化合物常见价态，补全反应体系中存在的、但题干未显式列出的物质。在高温焙烧或煅烧反应中，常见副产物为 $CO_2$、$H_2O$、$NH_3$、$SO_2$ 等挥发性气体。
  3. 化合价分析定产物形态 对于有变价金属参与的氧化还原反应，需结合题干条件（如“低价硫化物”“低价氧化物”）判断其化合价变化，确定产物的具体化学式。
  4. 守恒配平与符号检查 使用观察法或化合价升降法配平化学方程式。最后一步通查：反应条件、气体“$\uparrow$”或沉淀“$\downarrow$”符号是否遗漏，溶液中的反应是否需写成离子方程式。

高频易错

  • 反应产物臆断，不符事实：典型错误如认为 $Na_2O_2$ 在空气中直接分解为 $Na_2O$ 和 $O_2$。实际上，$Na_2O_2$ 优先与 $CO_2$、$H_2O$ 反应生成 $Na_2CO_3$ 和 $NaOH$。
  • 忽视题干约束条件：
    • 给定“低价”，却将产物错写为高价氧化物或硫化物。
    • 给定“焙烧”温度和铵盐参与，却遗漏了铵盐分解产生的 $NH_3$ 气体。
    • 给定沉淀转化，只用化学方程式而忽略了难溶电解质的书写规范。
  • 方程式配平与符号缺失：
    • 原子个数未配平，特别是氧、氢原子。
    • 反应条件如“高温”“通电”“催化剂”遗漏。
    • 水溶液中反应生成的难溶物漏标“$\downarrow$”，生成的气体漏标“$\uparrow$”。
  • 离子方程式书写陷阱：
    • 错把难溶物、弱电解质、气体等拆写成离子形式。
    • 沉淀转化反应的方程式两边均有不溶物，易出现原理性判断失误。

代表题精讲

题目（2021全国乙卷节选）磁选炼铁高钛炉渣含 $Al_2O_3$、$TiO_2$ 等。焙烧中 $Al_2O_3$ 转化为 $NH_4Al(SO_4)_2$，写出该化学方程式。 思路锁定核心转化“$Al_2O_3 \rightarrow NH_4Al(SO_4)_2$”。从元素守恒看，反应物必含提供 $NH_4^+$ 和 $SO_4^{2-}$ 的物质。结合题干“硫酸盐”暗示及后续“水浸”操作，可知另一反应物为 $(NH_4)_2SO_4$ 且为固相高温环境。缺氢元素，需由硫酸铵的氢生成水，水高温成气态。 步骤 1. 写出核心骨架：$Al_2O_3 + (NH_4)_2SO_4 \rightarrow NH_4Al(SO_4)_2$ 2. 根据原子守恒推断另一产物：反应物含H，生成物含 $NH_4^+$ 后H过量，必生成 $H_2O$。 3. 按Al、S、H、O顺序试配平：$Al_2O_3 + 4(NH_4)_2SO_4 \buildrel{\text{焙烧}}\over{=} 2NH_4Al(SO_4)_2 + 6NH_3\uparrow + 3H_2O\uparrow$（注：铵盐高温分解出氨气放亦常见）。 4. 检查条件与状态：标明“焙烧”条件及气体符号。 点评/变式 此题信息隐蔽，需打破“只有酸根转化”的思维定式。变式训练：写 $Fe_2O_3$ 在类似条件下转化为 $NH_4Fe(SO_4)_2$ 的方程式。

题目（2019全国Ⅱ卷）判断何项反应方程未能正确表达颜色变化。 思路逐一分析每个选项的原理。A是置换反应，B是酸性氧化物与碱的反应，C是过氧化物变质的原理，D是沉淀转化的原理。结合知识精要中“符合客观事实”原则排查。 步骤 1. A项：$Zn$ 活泼性强于 $Cu$，置换出铜单质使蓝色消失。反应与现象对应，正确。 2. B项：$Ca(OH)_2$ 吸收空气中 $CO_2$，生成白色 $CaCO_3$ 沉淀。反应与现象对应，正确。 3. C项：$Na_2O_2$ 淡黄色，在空气中放置，先与水气反应最终生成白色 $NaOH$（及吸收 $CO_2$ 后的 $Na_2CO_3$），并非分解为白色的 $Na_2O$。方程式本身错误，不符合事实。该方程不能表达此变化。 4. D项：$Fe(OH)_3$ 溶解度远小于 $Mg(OH)_2$，可实现沉淀的转化，生成红褐色 $Fe(OH)_3$。反应与现象对应，正确。 点评/变式 颜色变化是“结果”，须找准根本“原因反应”。此类题的干扰项常构造看似守恒但违背热力学或动力学常理的“假反应”。

题目（2018全国Ⅱ卷节选）写出显色反应方程式：$FeC_2O_4$ 与 $K_3[Fe(CN)_6]$ 反应生成蓝色沉淀 $Fe_3[Fe(CN)_6]_2$。 思路题干已给出主要反应物和一种产物沉淀。锁定核心转化：$FeC_2O_4 + K_3[Fe(CN)_6] \rightarrow Fe_3[Fe(CN)_6]_2 \downarrow$。这是亚铁盐与铁氰化钾生成滕氏蓝的经典反应。需根据原子守恒补全另一产物，应为可溶的草酸钾。 步骤 1. 写出反应物和唯一给出的生成物：$FeC_2O_4 + K_3[Fe(CN)_6] \rightarrow Fe_3[Fe(CN)_6]_2 \downarrow$ 2. 观察有K和 $C_2O_4^{2-}$ 离子剩余，它们将结合成另一产物 $K_2C_2O_4$。 3. 利用观察法配平：观察Fe原子，左边需凑出3个，故 $FeC_2O_4$ 系数为3。此时K原子左边为3个，右边应生成3个 $K_2C_2O_4$，但K数为6，故 $K_3[Fe(CN)_6]$ 系数应调整为2，则K守恒。全部配平：$3FeC_2O_4 + 2K_3[Fe(CN)_6] = Fe_3[Fe(CN)_6]_2 \downarrow + 3K_2C_2O_4$。 4. 标明沉淀符号，反应在水溶液中进行，无需标注气体。 点评/变式 给定大部分物质的方程式书写，本质是原子守恒的推演。核心是根据目标产物中阴、阳离子团的比例，去反推反应物配比。
