知识精要

化学计量数推断的核心依据是反应中物质的量变化量之比等于化学计量数之比。对于反应 $a\,\mathrm{A} + b\,\mathrm{B} \rightleftharpoons c\,\mathrm{C} + d\,\mathrm{D}$，必满足： $$|\Delta n(\mathrm{A})| : |\Delta n(\mathrm{B})| : \Delta n(\mathrm{C}) : \Delta n(\mathrm{D}) = a : b : c : d$$ 其中 $\Delta n(\mathrm{A})$、$\Delta n(\mathrm{B})$ 取减少量的绝对值，$\Delta n(\mathrm{C})$、$\Delta n(\mathrm{D})$ 取增加量。

适用条件： - 恒温、恒容（或恒压）密闭容器中的气态或溶液反应； - 已知至少两个时刻各物质的物质的量（或浓度）； - 变化量必须由同一时间段内的数据计算； - 推断出的计量数为最简整数比，若出现 $0.5$ 等需倍乘处理。

关键公式：
取某时段数据，计算 $\Delta n_i$ → 求比值 → 化为最简正整数比 → 写出化学方程式（注明可逆号“$\rightleftharpoons$”）。

解题方法与套路

  1. 确认为变化量数据：从表格或描述中锁定至少两个时间点（一般为初始状态和某反应状态/平衡状态），分别记录 X、Y、Z 等各物质的物质的量。
  2. 计算变化量：
  3. 减少量：$\Delta n_{\text{减}} = n_{\text{初}} - n_{\text{末}}$（反应物）；
  4. 增加量：$\Delta n_{\text{增}} = n_{\text{末}} - n_{\text{初}}$（生成物）。
  5. 求比值：将各物质的变化量列比例式 $\Delta n_{\mathrm{X}} : \Delta n_{\mathrm{Y}} : \Delta n_{\mathrm{Z}}$，约分为最简整数比。
  6. 确定反应物与生成物：减小的为反应物，增加的为生成物，计量数即比值中的对应整数。
  7. 写出化学方程式：按“反应物 → 生成物”形式，配上系数，若反应未进行到底（各物质最终不为零）需使用可逆号“$\rightleftharpoons$”。

高频易错

  • 直接用终点物质的量比当作化学计量数比：必须用变化量（$\Delta n$）之比，而非平衡时物质的量之比。
  • 忽略起始量含生成物的情况：若起始 $n(\text{生成物}) \neq 0$，变化量仍应计算增量，不能直接用末态值。
  • 未约分或约分错误：得到比值如 $0.45:0.90:0.90$，需同时除以 $0.45$ 得 $1:2:2$，切勿留小数或非最简比。
  • 误判反应方向：未根据 $n$ 增减区分反应物与生成物，导致方程式计量数反向。
  • 混用不同时间段的数据：必须取同一时间间隔（如 $0\sim t$）的变化量，不能跨段计算。

代表题精讲

题目（2009·全国Ⅱ·09 改编）：
某温度下，在 2 L 密闭容器中加入 1.00 mol X 和 1.00 mol Y，发生反应生成 Z。不同时间测得各物质的物质的量如下（节选 0 min 与 9 min 数据）：

t/min X/mol Y/mol Z/mol
0 1.00 1.00 0.00
9 0.55 0.10 0.90

后续保持 0.55、0.10、0.90 不变。推断该反应的化学方程式。

思路：
变化量之比等于化学计量数之比。取 0 min 和 9 min 数据计算 $\Delta n$，X、Y 减少，Z 增加，确定反应物与生成物，再约分得最简整数比，注意反应最终达平衡，用可逆号。

步骤：
1. 计算变化量：
$\Delta n(\mathrm{X}) = 1.00 - 0.55 = 0.45\ \mathrm{mol}$（减少）
$\Delta n(\mathrm{Y}) = 1.00 - 0.10 = 0.90\ \mathrm{mol}$（减少）
$\Delta n(\mathrm{Z}) = 0.90 - 0.00 = 0.90\ \mathrm{mol}$（增加）
2. 求比：
$|\Delta n(\mathrm{X})| : |\Delta n(\mathrm{Y})| : \Delta n(\mathrm{Z}) = 0.45 : 0.90 : 0.90 = 1 : 2 : 2$
3. 判定角色与系数：X、Y 减少为反应物，Z 增加为生成物，计量数依次为 1、2、2。
4. 反应方程式：
$$\mathrm{X} + 2\mathrm{Y} \rightleftharpoons 2\mathrm{Z}$$
因 9 min 后各物质不再变化且均不为零，故为可逆反应。

点评/变式：
- 若表格中出现 $n(\mathrm{Z})$ 初值不为零，变化量仍用“末减初”。
- 变式：由浓度变化推断时，注意 $c = n/V$，但比例关系不变，可直接用浓度变化量之比代替。
- 若数据为 $0.60,0.20,0.80$（末态），变化量 $0.40,0.80,0.80$ 同样得 $1:2:2$，说明平衡移动不影响初始计量数推断。
