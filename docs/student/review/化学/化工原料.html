知识精要

  • 联氨（肼）的结构：分子式 $N_2H_4$，电子式为 $H:\underset{\cdot\cdot}{\overset{\cdot\cdot}{N}}(H):\underset{\cdot\cdot}{\overset{\cdot\cdot}{N}}(H):H$，结构式为 。氮原子采用 $sp^3$ 杂化，分子具有极性，常温下为无色液体。
  • 联氨的物理性质与用途：因分子间存在氢键，沸点较高（113.5℃）。能溶于水，是重要的火箭燃料，燃烧产物为 $N_2$ 和 $H_2O$，清洁无污染。
  • 联氨的化学性质：
    • 弱碱性：联氨是二元弱碱，在水中分步电离，其碱性弱于氨。可结合质子显示碱性：$N_2H_4 + H^+ \rightleftharpoons N_2H_5^+$，$N_2H_5^+ + H^+ \rightleftharpoons N_2H_6^{2+}$。
    • 强还原性：联氨中氮元素化合价为 $-2$ 价，兼具氧化性与强还原性，但主要体现强还原性，能被氧气、卤素、高价金属氧化物等氧化。
      • 与氧气反应：$N_2H_4 + O_2 \xrightarrow{点燃} N_2 + 2H_2O$（火箭燃料原理）。
      • 还原性体现：在碱性环境中还原性更强，常利用其失电子生成 $N_2$ 的性质。
  • 联氨的制备：实验室常用 $NaClO$ 和 $NH_3$ 反应制得：$NaClO + 2NH_3 = N_2H_4 + NaCl + H_2O$。

解题方法与套路

  • 化合价分析法定性：对于含氮化合物，首先标出其化合价。$N_2H_4$ 中 $N$ 为 $-2$ 价，处于中间价态，故既有氧化性又有还原性。结合具体环境（如燃烧、与氧化剂反应）判断其表现性质。
  • 电子式与结构式书写：书写共价型分子电子式时，先确定各原子最外层电子数，确保每个原子达到稳定结构。$N$ 需形成 3 对共用电子，$H$ 需形成 1 对。联氨的电子式要注意 $N-N$ 单键的形成及孤对电子的分布。
  • 热化学与键能计算：利用反应热 $ΔH =$ 反应物总键能 - 生成物总键能，计算联氨参与反应的热效应。计算时需正确书写反应物和生成物的结构式，准确找出各类化学键的数目。
  • 共轭酸碱对分析：联氨的弱碱性源于氮原子上的孤对电子能与质子结合。其结合一个质子形成 $N_2H_5^+$（类似于 $NH_4^+$），结合两个质子形成 $N_2H_6^{2+}$。遇到酸过量的情况，要判断是否生成正盐或酸式盐。

高频易错

  • 氮原子共面问题：受单键可旋转及 $sp^3$ 杂化影响，联氨分子中四个原子不共面，整个分子是极性分子。切忌因书写习惯误判为平面分子或非极性分子。
  • 廉价碱写入离子方程式错误：联氨是弱碱，在离子方程式中应保留分子式，不能拆写成离子形式。例如：$N_2H_4 + H^+ = N_2H_5^+$ 是正确的。
  • 氧化还原产物判断错误：联氨作为强还原剂时，在无特殊说明时，其氧化产物常被认为是无污染的 $N_2$，而不是氮的氧化物或氨，这一点在书写工业除氧或火箭燃烧方程式时尤其关键。
  • 电子式与结构式混淆：书写电子式时，易遗漏氮原子上的孤对电子，或将 $N-N$ 单键误写成双键。必须明确 $N_2H_4$ 中氮成键数为 3（其中 2 个 $N-H$ 键，1 个 $N-N$ 键），还有 1 对孤对电子。
  • 键能计算断键数目错误：用键能计算 $N_2H_4$ 燃烧热时，切勿漏算 $N-N$ 单键，并注意 $N_2$ 分子中含有的是氮氮三键（$N \equiv N$）。

代表题精讲

题目：（2016·新课标Ⅱ）联氨（又称肼，$N_2H_4$，无色液体）是一种应用广泛的化工原料，可用作火箭燃料。回答下列问题： （1）联氨分子的电子式为__。 （2）联氨是一种常用的还原剂。向装有少量 $AgBr$ 的试管中加入联氨溶液，观察到的现象是_。联氨可用于处理高压锅炉水中的氧，防止锅炉被腐蚀。理论上 $1\ kg$ 联氨可除去水中溶解的 $O2$_$kg$。 （3）联氨为二元弱碱，在水中的电离方式与氨相似。联氨第一步电离的方程式为：___。

思路：本题全方位考查联氨的结构、性质及定量计算。第（1）问根据核外电子排布和共用电子对理论书写电子式。第（2）问利用化合价变化判断反应可能，并结合化学方程式进行计算。第（3）问类比氨的电离方程式书写即可。

步骤： （1）电子式书写：氮原子最外层有 5 个电子，需形成 3 对共用电子对达 8 电子稳定结构。2 个氮原子之间形成一个 $N-N$ 单键，每个氮再分别与 2 个氢原子形成 2 个 $N-H$ 键。此时每个氮还有 2 个未成键电子，即一对孤对电子。因此，电子式为 $H:\underset{\cdot\cdot}{\overset{\cdot\cdot}{N}}(H):\underset{\cdot\cdot}{\overset{\cdot\cdot}{N}}(H):H$。 （2）现象与计算：$N_2H_4$ 有强还原性，能将 $Ag^+$ 还原为单质银。可观察到有银白色固体析出，并可能有气泡产生（生成氮气）。处理溶解氧的反应为：$N_2H_4 + O_2 = N_2 + 2H_2O$。设 $1\ kg$ 联氨可除去 $O_2$ 的质量为 $x\ kg$，则： $$ \frac{1}{32} = \frac{x}{32} $$ 解得：$x = 1\ kg$。 （3）电离方程式：氨的电离是结合水中的氢离子。类比氨，联氨的第一步电离是结合水中一个质子，生成带一个正电荷的阳离子：$N_2H_4 + H_2O \rightleftharpoons N_2H_5^+ + OH^-$。

点评/变式：本题以“肼”为载体，将物质结构、氧化还原反应、化学用语、化学计算融为一体，是典型的元素化合物综合题。电子式的书写不能死记硬背，要理解共价键的本质。氧化还原产物推断中，“无污染”往往暗示生成氮气。变式思考：若将联氨加入酸性高锰酸钾溶液中，联氨的氧化产物为 $N_2$，高锰酸钾被还原为 $Mn^{2+}$，书写方程式时需注意强弱电解质的存在形态及电荷守恒。
