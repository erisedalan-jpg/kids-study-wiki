知识精要

原子守恒是化学反应最基本的定量关系，依据质量守恒定律：化学反应前后，原子的种类和数目均保持不变。它适用于一切化学反应，尤其在复杂反应、有机物推断、多步反应、氧化还原计算中非常关键。
- 核心表达：对于任意元素 $X$，有 $\sum \left( n_{\text{反应物}} \times \text{化学式中}X\text{的原子数} \right) = \sum \left( n_{\text{生成物}} \times \text{化学式中}X\text{的原子数} \right)$。
- 衍生应用：与电子守恒（氧化还原中转移电子数相等）、电荷守恒（离子反应中净电荷不变）结合，可快速求解被氧化/被还原的物质的量、未知分子式等。
- 常见命题点：
① 酯、酰胺等水解反应中利用原子守恒求羧酸、醇或胺的分子式（注意 $ H_2O $ 的参与）。
② 硝酸与金属反应中被还原的酸（承担氧化剂）与未被还原的酸（承担酸性生成盐）的物质的量比。
③ 多步连续反应中根据初始和最终物质，用原子守恒直接建立等量关系，绕过中间产物计算。

解题方法与套路

  1. 明确化学过程，列出转化关系
    写出“已知物 → 未知物”的变化表达式，有化学方程式的写方程式，无方程式的根据信息写出原子转移的核心关系。特别关注小分子（$ H_2O $、$ O_2 $ 等）的得失。

  2. 标出已知物质的量（或比例）
    将题干给出的物质的量、分子式、原子数目等信息代入关系式。对于氧化还原反应，可先标出元素化合价变化。

  3. 分元素应用原子守恒
    对于有机物分子式推断：$C$、$H$、$O$ 等分别列守恒式。
    对于溶液中离子反应：除原子守恒外，必要时结合电荷守恒。
    对于氧化还原酸的反应：被还原的元素单独守恒计算，未被还原的按照盐的组成计算。

  4. 结合电子守恒求解关键比值
    在氧化还原反应中，先由得失电子总数相等求出被还原（或被氧化）的物质的量，再由总酸中减去这部分即得未被还原的酸，直接求比。

高频易错

  • 忽视“隐形”小分子
    酯水解时需外加 $ H_2O $ 分子，计算羧酸或醇的分子式时容易漏掉水分子带来的 $H$、$O$ 原子，导致碳氢氧个数错误。
  • 混淆硝酸的两种角色
    与金属反应时，硝酸既作氧化剂（被还原成 $NO_2$、$NO$、$N_2O$、$NH_4^+$ 等）又作酸（生成硝酸盐）。常误把化学方程式中硝酸总计量当做被还原量，导致比例算反或算错。
  • 盲目套用方程式系数
    题干未直接给出方程式，或给出的物质的量比例并非方程式系数时，强行用系数比会导致错误。必须回归原子与电子守恒。
  • 原子归属不清
    例如 $ N $ 原子一部分存在于 $ Zn(NO_3)_2 $（未被还原），一部分存在于 $ N_2O $（被还原），计算时忽略任一出口都会出错。
  • 电子守恒与原子守恒错配
    使用电子守恒求得被还原硝酸的物质的量后，直接将其作为总硝酸量，未把起酸作用的硝酸加上，是典型失误。

代表题精讲

题目 2015·新课标Ⅱ·第2题

某羧酸酯分子式 $ C_{18}H_{26}O_5 $，1 mol该酯完全水解得1 mol羧酸和2 mol乙醇，求该羧酸的分子式。
思路 酯水解反应为“酯 + 水 → 羧酸 + 醇”。根据原子守恒，羧酸的分子式 =（酯的原子总数）+（参加反应的水的原子总数）−（生成的醇的原子总数）。已知乙醇分子式 $ C_2H_6O $。
步骤
1. 水解方程式框架：$ C_{18}H_{26}O_5 + 2H_2O \rightarrow 羧酸 + 2C_2H_5OH $。
2. 分别计算各元素原子数：
- 反应物总量：$ C:18, H:26+4=30, O:5+2=7 $
- 2 mol乙醇：$ C:4, H:12, O:2 $
3. 羧酸原子数 = 总量 − 乙醇：$ C:18-4=14, H:30-12=18, O:7-2=5 $
得分子式 $ C_{14}H_{18}O_5 $，对应选项A。
点评/变式
本题直接用原子守恒避开了推断酯的具体结构，适合所有“给定水解产物求另一产物”的题型。易错点为忘加水分子，误选 $ C_{14}H_{14}O_3 $ 之类。变式：“某酯水解生成等物质的量的羧酸和醇，已知酯和醇的分子式，求羧酸分子式”同理。

题目 2009·全国Ⅱ·第1题

物质的量比为2:5的锌与稀硝酸反应，还原产物为 $ N_2O $，锌无剩余，求被还原的硝酸与未被还原的硝酸的物质的量之比。
思路 硝酸同时起酸和氧化剂作用。用电子守恒求被还原的 $ HNO_3 $ 量，再通过生成的盐 $ Zn(NO_3)_2 $ 求未被还原的硝酸量，两者作比。
步骤
1. $ Zn $ 从0升至+2，2 mol $ Zn $ 共失 $ 2\times2=4 $ mol 电子。
2. $ HNO_3 $ 被还原为 $ N_2O $，$ N $ 从+5降至+1，每个 $ N $ 得4个电子。设被还原的硝酸为 $ x $ mol，提供 $ x $ mol $ N $ 原子，生成 $ x/2 $ mol $ N_2O $，共得 $ (x/2)\times8=4x $ mol 电子？
注意：1 mol $ HNO_3 $ 被还原只提供1 mol $ N $，若全部生成 $ N_2O $，则0.5 mol $ N_2O $ 得电子 $ 0.5\times2\times4=4 $ mol。实际上得失电子相等，若锌失4 mol电子，则被还原的硝酸量 $ x $ 满足：每 mol $ HNO_3 $ 还原得电子4 mol（$ N^{+5}\rightarrow N^{+1} $ 在$ N_2O $ 中每个N得4e，但1 mol $ HNO_3 $ 只含1 mol N，生成0.5 mol $ N_2O $ 得4 mol e），因此4 mol e 对应 $ x=1 $ mol。
3. 2 mol $ Zn^{2+} $ 结合 $ NO_3^- $ 生成 $ Zn(NO_3)_2 $，需 $ 2\times2=4 $ mol $ NO_3^- $，即未被还原的硝酸为4 mol。
4. 被还原硝酸：未被还原硝酸 = 1:4，选A。
点评/变式
本题不需完整配平即可用守恒快速解题。易错点是将总酸量5 mol 直接按电子转移分配算错，或混淆求比的分母。变式训练：若还原产物为 $ NO $ 或 $ NH_4NO_3 $，调整化合价变化值即可，方法不变。
