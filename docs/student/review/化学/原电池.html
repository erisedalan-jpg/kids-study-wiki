知识精要

  • 原电池原理：将自发的氧化还原反应释放的化学能转化为电能。负极发生氧化反应，失去电子；正极发生还原反应，得到电子。电子经外电路由负极流向正极；在电解质溶液中，阳离子移向正极，阴离子移向负极。
  • 电极判断依据：活泼性较强的金属（或燃料）作负极；化合价升高的物质在负极反应；化合价降低的物质在正极反应。二次电池放电时负极相当于充电时的阴极，放电时正极相当于充电时的阳极。
  • 电极反应书写：
  • 确定正、负极及其得失电子数目；
  • 结合电解质环境（酸性、碱性、熔融盐或有机电解液）选择参与反应的离子；
  • 遵循电荷守恒与元素守恒，补齐介质微粒（$H^+$、$OH^-$、$H_2O$、$O^{2-}$等）；
  • 可充电电池写成可逆反应形式，标注充、放电方向。
  • 离子迁移与电流方向：电流由正极流向负极（外电路）；阳离子移向正极，阴离子移向负极。
  • 典型电池模型：
  • “可呼吸”电池：$3CO_2+4Na \rightleftharpoons 2Na_2CO_3+C$，放电吸收 $CO_2$，充电释放 $CO_2$。
  • 铁镍蓄电池：$Fe+Ni_2O_3+3H_2O=Fe(OH)_2+2Ni(OH)_2$，碱性电解液。
  • 锌钒电池：$Zn$ 负极，$V_2O_5$ 正极，$Zn(CF_3SO_3)_2$ 水溶液为电解液。

解题方法与套路

  1. 定反应：从总反应（或题目信息）找出氧化剂、还原剂，标出变价元素，确定电子转移数目。
  2. 判电极：还原剂所在电极为负极，氧化剂所在电极为正极；二次电池结合“放电原电池，充电电解池”判断电极名称与极性。
  3. 写反应式：
  4. 负极：还原剂$-ne^- \to$ 氧化产物（注意介质，如碱性条件下 $Fe+2OH^--2e^-=Fe(OH)_2$）；
  5. 正极：氧化剂$+ne^- \to$ 还原产物（如 $3CO_2+4e^-=2CO_3^{2-}+C$）。
  6. 检查电荷与原子守恒，若含氧，酸性用 $H^+$ 和 $H_2O$ 调平，碱性用 $OH^-$ 和 $H_2O$ 调平。
  7. 析迁移：阳离子向正极移动，阴离子向负极移动；电子只在导线中流动，离子只在溶液中移动。
  8. 判选项：逐一核实电极名称、反应物与产物、pH变化、气体参与等，特别注意充电时“正极”说法实指阳极。

高频易错

  • 充放电电极名称混淆：充电时“正极”连接电源正极，实为电解池的阳极，发生氧化反应，而非还原。例如充电时 $Na^++e^-\to Na$ 发生在阴极，若说“充电时正极反应为 $Na^++e^-=Na$”即错。
  • 忽视介质酸碱性：碱性电池中负极氧化产物常与 $OH^-$ 结合生成氢氧化物，不能随意写 $M^{n+}$。如铁镍电池负极生成 $Fe(OH)_2$ 而非 $Fe^{2+}$。
  • 离子移动方向记反：误以为阴离子向正极移动。牢记“正正负负”谐音——“正离子去正极，负离子去负极”。
  • 可充电电池的逆反应书写不当：充电阳极反应是放电正极反应的逆过程，需将电子写在正确一侧，且不能简单反向箭头。
  • 只改变电子数不看总体反应：如 $Na-CO_2$ 电池充电时 $C$ 被氧化为 $CO_2$，同时消耗 $CO_3^{2-}$，若仅写 $C-4e^-=CO_2$ 会丢介质。
  • 混淆电解质中离子作用：有机电解液如 $NaClO_4$ 中 $Na^+$ 参与电极反应，$ClO_4^-$ 只起导电和电荷平衡作用，在选项分析中要区分。

代表题精讲

2018-新课标Ⅱ-06 可呼吸 $Na-CO_2$ 二次电池

题目：室温下的 $Na-CO_2$ 二次电池，电解液为 $NaClO_4$ 有机溶液，钠和负载碳纳米管的镍网分别为电极，总反应：$3CO_2+4Na \rightleftharpoons 2Na_2CO_3+C$。找出错误的说法。

思路：先明确放电过程的电极与反应：$Na$ 失电子作负极，$CO_2$ 在正极（镍网）得电子被还原。由总反应得电子转移数为4。放电时阴离子 $ClO_4^-$ 移向负极。充电时反应逆向，原负极（$Na$）得电子成为阴极，原正极（$C$）失电子成为阳极。

步骤： 1. 放电负极：$Na-e^-=Na^+$（或 $4Na-4e^-=4Na^+$）； 放电正极：$3CO_2+4e^-=2CO_3^{2-}+C$。 2. 离子移动：放电时 $Na^+$ 向正极迁移与 $CO_3^{2-}$ 结合，$ClO_4^-$ 向负极移动，A项正确。 3. 气体参与：放电吸收 $CO_2$，充电释放 $CO_2$，B项正确。 4. 选项C给出的正极反应为 $3CO_2+4e^-=2CO_3^{2-}+C$，正确。 5. 充电时，原正极（镍网）变为阳极，失去电子：$C+2CO_3^{2-}-4e^-=3CO_2$；原负极变为阴极：$Na^++e^-=Na$。选项D“充电时，正极反应为 $Na^++e^-=Na$”将阴极反应错安在正极，错误。

点评/变式：新型二次电池常设陷阱，如混淆充放电电极名称，或错写充电电极反应。应试时抓住总反应，用“负氧化，正还原；充电阴还原，阳氧化”定位。

2011-新课标-05 铁镍蓄电池

题目：铁镍蓄电池放电总反应 $Fe+Ni_2O_3+3H_2O=Fe(OH)_2+2Ni(OH)_2$，选出不正确的说法。

思路：反应产物为氢氧化物，故电解液为碱性。$Fe$ 化合价升高作负极，$Ni_2O_3$ 中 $Ni$ 降价作正极。书写电极反应需用 $OH^-$ 配平。充电时阴极得电子，阳极失电子，分析pH变化。

步骤： 1. 电极判断：$Fe$ 负极，$Ni_2O_3$ 正极，A正确。 2. 负极反应：$Fe+2OH^--2e^-=Fe(OH)_2$，B正确。 3. 充电时阴极：$Fe(OH)_2+2e^-=Fe+2OH^-$，生成 $OH^-$，碱性增强（pH升高），C项说“碱性减弱”错误。 4. 充电阳极：$2Ni(OH)_2+2OH^--2e^-=Ni_2O_3+3H_2O$，D正确。故选C。

点评/变式：碱性介质中电极反应必含 $OH^-$，二次电池充电时阴极附近变碱。常将pH变化方向颠倒作为干扰项。
