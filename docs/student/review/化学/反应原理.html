知识精要

  • 焙烧反应原理：闪锌矿中ZnS等在高温下被O₂氧化，生成金属氧化物与SO₂。
  • 主反应：$2ZnS + 3O_2 \xrightarrow{\Delta} 2ZnO + 2SO_2$
  • 杂质硫化物同时氧化：$4FeS + 7O_2 \rightarrow 2Fe_2O_3 + 4SO_2$，CdS、PbS类似生成CdO、PbO。
  • 酸浸与沉淀：酸浸时金属氧化物与稀H₂SO₄反应生成可溶性硫酸盐；PbSO₄难溶，与不溶性SiO₂一起成为滤渣。
  • $PbO + H_2SO_4 = PbSO_4 \downarrow + H_2O$
  • 水解沉淀除铁：$Fe^{3+}$在pH≈3时可完全水解为$Fe(OH)_3$沉淀，而$Zn^{2+}$在pH≈6以上才沉淀。加入ZnO（或ZnCO₃等）消耗H⁺，调节pH使$Fe^{3+}$水解沉淀，不引入新杂质。
  • 原理：$Fe^{3+} + 3H_2O \rightleftharpoons Fe(OH)_3 \downarrow + 3H^+$，加入ZnO：$ZnO + 2H^+ = Zn^{2+} + H_2O$，促进水解。
  • 置换反应除杂：利用金属活动性差异，用Zn粉将比Zn不活泼的Cd²⁺、Pb²⁺等置换为金属单质沉淀滤去。
  • $Zn + Cd^{2+} = Zn^{2+} + Cd$，$Zn + Pb^{2+} = Zn^{2+} + Pb$
  • 沉淀转化与掩蔽：进一步可加KF等试剂，使残余Pb²⁺、Ca²⁺等转化为难溶氟化物，利用溶度积差异净化。
  • 电解原理：最后$ZnSO_4$溶液电解，阴极上$Zn^{2+}$得电子析出金属锌：阴极 $Zn^{2+} + 2e^- = Zn$；阳极（惰性）$2H_2O - 4e^- = O_2 \uparrow + 4H^+$。

解题方法与套路

  1. 流程整体审视：快速划出原料、中间产物、最终产品，判断每一步操作的目的（除哪种杂质、富集何物质）。
  2. 价态分析定反应：标出关键元素化合价变化，判断氧化还原步骤（如焙烧、置换）与复分解/水解步骤（如酸浸、调pH）。
  3. 滤渣与滤液成分推理：
  4. 结合已知物质溶解性（$SiO_2$不溶，$PbSO_4$、$Fe(OH)_3$等难溶）和加入的试剂，确定沉淀物。
  5. 反向检查：滤液中需保留的目标离子是否流失。
  6. 条件控制答原因：遇到“调pH”等同温度、浓度、酸碱度控制，从速率、转化率、选择性、不引入杂质等角度作答。
  7. 常见角度：提高浸出率（研磨、加热、搅拌）；促进水解沉淀；防止副反应；抑制/促进电离；沉淀完全条件（pH范围计算）。
  8. 方程式书写规范：
  9. 焙烧：硫化物→氧化物+$SO_2$，注意配平，条件高温。
  10. 调pH除铁：写离子方程式，$Fe^{3+} + 3H_2O \rightleftharpoons Fe(OH)_3 \downarrow + 3H^+$，配合所用试剂（如ZnO消耗H⁺）。
  11. 置换：$Zn + M^{2+} = Zn^{2+} + M$。
  12. 分离提纯的化学原理串联：每步涉及的化学反应原理（沉淀溶解平衡、氧化还原、水解平衡）要能准确对应考点，回答时先答原理再结合流程。

高频易错

  • 滤渣成分判断遗漏：酸浸后滤渣①常见误漏$PbSO_4$或$SiO_2$，要注意酸性条件下$Pb^{2+}$也能与$SO_4^{2-}$生成难溶盐。
  • 除铁试剂选择错误：随意写NaOH、氨水等会引新杂质离子，必须添加含目标金属的难溶物（如ZnO、ZnCO₃、Zn(OH)₂）或对应金属单质。
  • 调pH范围表述不当：只说“使Fe³⁺沉淀”而不提保证$Zn^{2+}$不沉淀，缺乏严谨的定量pH范围分析。
  • 置换顺序不清：加Zn粉的顺序要结合流程和金属活动性，先除Cd²⁺（或同时除Pb²⁺），不能先加入KP等沉淀剂使后续置换困难。
  • 电解条件记混：电解$ZnSO_4$溶液应使用惰性阳极，阳极放电的是$OH^-$而不是$SO_4^{2-}$，阴极$Zn^{2+}$放电。误写阳极生成$O_2$的方程式时配平与介质弄错。
  • 陌生方程式无条件：写焙烧方程式常漏写高温条件或反应物O₂，另外杂质FeS焙烧产物写成$FeO$、$SO_3$等不符合实际。

代表题精讲

题目：2018-新课标Ⅱ-08

以闪锌矿（ZnS，含SiO₂和少量FeS、CdS、PbS杂质）为原料制备金属锌的流程：焙烧→酸浸→调pH→加Zn粉→……→电解。设问涉及：焙烧主要方程式、滤渣成分、调pH所用试剂及优点、置换原理、电解方程式等。

思路
先分析各步反应类型与杂质去向：焙烧属氧化，杂质硫化物也一并氧化；酸浸利用溶解性差异分离PbSO₄和SiO₂；调pH利用$Fe^{3+}$与$Zn^{2+}$水解pH的不同，加ZnO不引入杂质；加Zn粉置换出Cd、Pb等；最后电解得金属锌。

步骤
1. 焙烧主反应：$2ZnS + 3O_2 \xrightarrow{\Delta} 2ZnO + 2SO_2$。杂质$FeS$焙烧生成$Fe_2O_3$，$PbS$、$CdS$生成对应氧化物。
2. 稀硫酸酸浸后，$PbO$转化为难溶$PbSO_4$，与$SiO_2$共同进入滤渣①；滤液含$Zn^{2+}$、$Fe^{3+}$、$Cd^{2+}$等。
3. 用ZnO调pH，消耗$H^+$提高pH，使$Fe^{3+}$水解生成$Fe(OH)_3$沉淀滤去（滤渣②），$Zn^{2+}$保留。
- 选择ZnO的原因：消耗$H^+$且不引入新杂质，最终转化成$Zn^{2+}$。
4. 向滤液加Zn粉，利用$Zn$比$Cd$、$Pb$活泼，将其从溶液中置换为单质沉淀，滤渣③含Cd和过量Zn。
5. 净化液电解，阴极$Zn^{2+} + 2e^- = Zn$；阳极用惰性电极，$2H_2O - 4e^- = O_2 \uparrow + 4H^+$。

点评/变式
- 本题集中考查“除杂不引杂”原则、水解沉淀的pH控制、以及金属活动性置换，是“反应原理”在工业流程中的典型投影。
- 常考变式：调pH试剂换为ZnCO₃或Zn(OH)₂，比较优缺点（产生CO₂不影响）。加Zn粉前若先用$H_2O_2$把$Fe^{2+}$氧化为$Fe^{3+}$，再调pH更易除铁。沉淀转化法除Pb²⁺：加$Na_2S$或$KF$生成更难溶的$PbS$、$PbF_2$。备考需熟练书写水解与氧化还原的离子方程式并阐明每一步滤渣成分的理据。
