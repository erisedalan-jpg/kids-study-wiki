反应规律

考点反应规律权重5真题数1学科化学父主题化学反应原理

考点定位

  • 父主题：化学反应原理
  • 权重 weight：5
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 离子方程式评价型判断的核心：既需判断离子方程式本身是否符合化学事实、拆分规则、守恒规律及定量关系，又需判断题目所给“评价”是否正确。
  • 物质拆分规则：易溶且易电离的物质（强酸、强碱、可溶盐）拆成离子；单质、氧化物、难溶物、弱电解质、气体等用化学式。如碳酸镁($\mathrm{MgCO_3}$)微溶，不能拆成 $\mathrm{CO_3^{2-}}$。
  • 氧化还原反应的事实与顺序：
  • 硝酸参与的反应：$\mathrm{NO_3^-}$在酸性条件下表现强氧化性，产物为 $\mathrm{NO}$ 或 $\mathrm{NO_2}$，不能生成 $\mathrm{H_2}$。
  • 多种还原性微粒与同一氧化剂反应时，遵循还原性强者优先的顺序。如 $\mathrm{Fe^{2+}}$ 的还原性强于 $\mathrm{Br^-}$，向 $\mathrm{FeBr_2}$ 溶液中通入等物质的量 $\mathrm{Cl_2}$ 时，$\mathrm{Fe^{2+}}$ 先被全部氧化，$\mathrm{Br^-}$ 部分被氧化。
  • 离子方程式的完整性：涉及铵盐与碱溶液的反应，必须同时写出生成沉淀与生成弱碱（或氨气）的离子，不能漏写。如硫酸铵与氢氧化钡反应，漏写 $\mathrm{NH_4^+}$ 与 $\mathrm{OH^-}$ 的反应。
  • 电子守恒与电荷守恒：离子方程式必须满足电子得失总数相等、两边净电荷数相等。

解题方法与套路

  1. 审题定位：明确题干要求是判断“离子方程式正误”还是“评价是否合理”，避免思维定势。
  2. 逐项双检：对每一个选项，先独立判断离子方程式是否正确，再评价题目给出的“评价”是否与事实相符，两步缺一不可。
  3. 检查化学事实：反应能否发生？产物是否符合实际？特别注意硝酸、浓硫酸等的特性。
  4. 检查拆分规范：依据溶解性表判断物质是否应拆成离子。
  5. 检查守恒关系：原子、电荷、电子得失是否守恒。
  6. 检查定量关系：若涉及“等物质的量”、“过量”等条件，需根据反应的先后顺序确定正确的化学计量数比。
  7. 排除与确认：将“离子方程式错误+评价正确”、“离子方程式正确+评价错误”或两者皆错的选项排除，确定评价合理的选项。
  8. 复查易混点：快速重审微溶物、氧化还原顺序、铵盐反应完整性等高频陷阱。

高频易错

  • 硝酸反应误判：见到 $\mathrm{Fe_3O_4}$ 与酸反应就写置换出 $\mathrm{H_2}$，忽略 $\mathrm{HNO_3}$ 的氧化性。
  • 微溶物拆分混淆：$\mathrm{MgCO_3}$ 常被误当做可溶碳酸盐拆成离子形式。
  • 离子方程式缺项：见到生成沉淀就停止分析，忽略体系中同时发生的其他离子反应，如 $\mathrm{NH_4^+}$ 与 $\mathrm{OH^-}$。
  • 反应顺序应用错误：在 $\mathrm{FeBr_2}$ 与 $\mathrm{Cl_2}$ 等物质的量反应中，误认为 $\mathrm{Fe^{2+}}$ 与 $\mathrm{Br^-}$ 按化学式组成比(1:2)消耗，未考虑还原性强弱顺序导致的先后反应，从而错判离子方程式为正或错判评价。
  • 评价的双重否命题：题干给出正确的离子方程式但配以“错误”的评价，或因非主流考点将正确离子方程式判定为错误，极易诱使考生选错。

代表题精讲

题目：2010全国新课标第7题——表中评价合理的是( )

选项 化学反应及其离子方程式 评价
A $\mathrm{Fe_3O_4}$ 与稀硝酸反应：$2\mathrm{Fe_3O_4} + 18\mathrm{H^+} = 6\mathrm{Fe^{3+}} + \mathrm{H_2 \uparrow} + 8\mathrm{H_2O}$ 正确
B 向碳酸镁中加入稀盐酸：$\mathrm{CO_3^{2-}} + 2\mathrm{H^+} = \mathrm{CO_2 \uparrow} + \mathrm{H_2O}$ 错误，碳酸镁不应写成离子形式
C 向硫酸铵溶液中加入氢氧化钡溶液：$\mathrm{Ba^{2+}} + \mathrm{SO_4^{2-}} = \mathrm{BaSO_4 \downarrow}$ 正确
D $\mathrm{FeBr_2}$ 溶液与等物质的量的 $\mathrm{Cl_2}$ 反应：$2\mathrm{Fe^{2+}} + 2\mathrm{Br^-} + 2\mathrm{Cl_2} = 2\mathrm{Fe^{3+}} + 4\mathrm{Cl^-} + \mathrm{Br_2}$ 错误，$\mathrm{Fe^{2+}}$ 与 $\mathrm{Br^-}$ 的化学计量数之比应为1:2

思路：先独立判断各离子方程式的正误，再比照评价，最终确定评价合理的一项。

步骤： 1. A项：稀硝酸具有强氧化性，该反应中氧化剂为 $\mathrm{HNO_3}$，不会生成 $\mathrm{H_2}$，正确产物应为 $\mathrm{Fe(NO_3)_3}$、$\mathrm{NO}$ 和 $\mathrm{H_2O}$。离子方程式错误，但评价为“正确”。故评价不合理。 2. B项：碳酸镁($\mathrm{MgCO_3}$)为微溶物，书写离子方程式时应保留化学式，不能拆开。所给离子方程式错误。评价指出“碳酸镁不应写成离子形式”，评价正确。故评价合理。 3. C项：硫酸铵与氢氧化钡溶液反应，除生成 $\mathrm{BaSO_4}$ 沉淀外，$\mathrm{NH_4^+}$ 与 $\mathrm{OH^-}$ 还会生成 $\mathrm{NH_3·H_2O}$。所给离子方程式漏写了氨水的生成，不完整，错误。评价为“正确”，故评价不合理。 4. D项：还原性强弱顺序为 $\mathrm{Fe^{2+}} > \mathrm{Br^-}$。等物质的量反应时，$1\,\mathrm{mol\,Cl_2}$ 先氧化 $2\,\mathrm{mol\,Fe^{2+}}$（需 $1\,\mathrm{mol\,Cl_2}$），反应完全；剩下的 $\mathrm{Cl_2}$ 不足，无法使所有 $\mathrm{Br^-}$ 被氧化，因此 $\mathrm{Fe^{2+}}$ 与 $\mathrm{Br^-}$ 的化学计量数之比确为2:2即1:1，离子方程式正确。评价却认为应为1:2，评价错误。故评价不合理。

点评/变式：本题实质是离子方程式正误判断与评价合理性判断的复合题型。核心考点涵盖硝酸的氧化性、微溶物拆分、铵盐反应完整性及竞争反应的顺序问题。变式训练：可将评价栏改为“正误原因分析”，要求考生找出分析错误的选项，强化对双重判断逻辑的掌握。
