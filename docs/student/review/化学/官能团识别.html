官能团识别

考点官能团识别权重6真题数1学科化学父主题有机化学

考点定位

  • 父主题：有机化学
  • 权重 weight：6
  • 真题数：1；年份跨度：2018–2018
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • 官能团定义：决定有机化合物特殊性质的原子或原子团。烃分子中的氢原子被其他原子或原子团取代后，产物分子中出现的特征基团即为官能团。
  • 常见含氧官能团及其结构（重点）：
  • 羟基（—OH）：连在烃基上为醇，连在苯环上为酚。代表物：乙醇、山梨醇、苯酚。
  • 醛基（—CHO）：羰基$C!=!O$一端连有$H$。代表物：乙醛、葡萄糖。
  • 羧基（—COOH）：羰基与羟基相连。代表物：乙酸。
  • 酯基（—COO—）：由羧基与羟基脱水形成。代表物：乙酸乙酯。
  • 醚键（$C!-!O!-!C$）：氧原子连接两个烃基。代表物：乙醚、异山梨醇（含醚键和羟基）。
  • 官能团与典型性质：
  • 羟基：可与$Na$反应，可被氧化（生成醛/酮/酸），可发生酯化反应。
  • 羧基：酸性，使石蕊变红，与$NaHCO_3$反应放出$CO_2$。
  • 醛基：可发生银镜反应，与新制$Cu(OH)_2$悬浊液生成砖红色沉淀。
  • 识别依据：通过结构简式中的原子连接方式、反应条件（如“与饱和$NaHCO_3$反应放出气体”表明含羧基）、分子式与不饱和度分析等可判定官能团种类。
  • 适用条件：本考点贯穿有机化学所有推断与合成任务，须熟练掌握各类官能团的结构、名称及特征反应。命名时优先识别优先级最高的官能团。

解题方法与套路

  1. 直接观察法（结构简式或键线式中识别）
    给出有机物结构简式，直接找出特征原子团：如$—OH$为羟基，$—CHO$为醛基，$—COOH$为羧基，$—COO—$为酯基，$>!C!=!O$为羰基等。注意辨别醚键与酯基、醛与酮。
  2. 名称推演法
    由有机物的习惯名或系统名反推官能团。如“山梨醇”中含“醇”字，必含羟基；“异山梨醇”名称中虽带“醇”，但从合成路线可知其为两分子山梨醇脱水形成的含醚键和羟基的双环化合物，需结合反应推断。
  3. 反应特征推断法
  4. 与$NaHCO_3$反应生成$CO_2$ $\rightarrow$ 分子中含羧基。
  5. 银镜反应或与$Cu(OH)_2$加热产生砖红色沉淀 $\rightarrow$ 醛基（或含醛基物质如葡萄糖）。
  6. 催化加氢（$H_2$/Ni）使碳碳双键、碳氧双键（醛基、酮基）加成；从葡萄糖制山梨醇，是醛基→羟基的转化，可逆推反应物含醛基。
  7. 计算辅助推断法
    根据同位素、质谱、燃烧数据或定量化学反应计算官能团数目。例如7.30 g $F$与足量饱和$NaHCO_3$反应放出2.24 L $CO_2$（标况），可得$n(CO_2)=0.1\ \text{mol}$，由$—COOH \sim CO_2$知$F$中$n(—COOH)=0.1\ \text{mol}$，再由质量与摩尔质量关系推算出分子结构，实质上先确定了$F$含有一个羧基。
  8. 比对已知反应路线
    沿着题目给出的合成路线，分析反应类型（取代、加成、消去、酯化、氧化、还原等），定位官能团的转化。如$B \to C$为酯化反应，则$B$中必有羟基或羧基；根据$C$的结构和乙酸酐反应，明确酯基生成。

高频易错

  • 官能团名称书写不规范：误写为“醇基”“酚基”等，正确应为“羟基”；羧基不能写成“羧酸基”；酯基不能写成“—COO—基”（填空要求写汉字名称，不能写结构简式）。
  • 混淆类似基团：羟基（—OH）与氢氧根（$OH^-$）符号相近但意义完全不同；醚键（$C!-!O!-!C$）不是官能团名称，答题应描述为“醚键”或“醚基”，但常见填空题中识别时通常直接回答“醚键”或“碳碳双键”等，需依据题设语境。若题目问“官能团名称”，则只答羟基、羧基等。
  • 忽略隐藏官能团：在环状结构中，醚键、酯基可能因书写简略而被遗漏。如山梨醇的官能团仅为羟基，异山梨醇（$B$）除羟基外还含有醚键，若仅答“羟基”则丢分。
  • 多官能团判断失误：葡萄糖为多羟基醛，既含羟基也含醛基；催化加氢后醛基变为羟基，得到山梨醇（己六醇），只含羟基。部分考生可能惯性认为醇由醛还原而来而误写醛基。
  • 依据化学性质推断时反应量比关系判断错误：$F$与$NaHCO_3$反应，计算得$n(—COOH)=0.1\ \text{mol}$，结合摩尔质量可确定含1个羧基，如果忽略计算直接猜2个或3个羧基，后续同分异构体数目必然错误。

代表题精讲

2018-新课标Ⅱ-12 节选 — 官能团识别与性质推断

题目
以葡萄糖为原料制得山梨醇（A）和异山梨醇（B），合成治疗心绞痛药物E，部分问题如下：
（2）A中含有的官能团的名称为_。
（6）F是B的同分异构体，7.30 g F与足量饱和碳酸氢钠反应可释放出2.24 L二氧化碳（标准状况），F的可能结构共有__种；其中核磁共振氢谱为三组峰，峰面积比为3:1:1的结构简式为_。

思路
（2）由合成路线“葡萄糖 $\xrightarrow{H_2/Ni}$ A”，葡萄糖为多羟基醛，加氢将醛基还原成羟基，A为山梨醇（己六醇），结构简式：$HOCH_2(CHOH)_4CH_2OH$，其中所有特征原子团都是羟基。
（6）F与$NaHCO_3$反应生成$CO_2$，指示F分子中含有羧基。利用气体物质的量计算羧基个数，然后结合B的分子式和不饱和度，推断F的碳骨架和官能团位置异构，最后根据核磁共振氢谱确定对称结构。

步骤
- 问（2）：写出葡萄糖加氢产物A的结构特征：六个碳原子每个连一个羟基（伯羟基和仲羟基），不再有醛基。故官能团只写“羟基”。不能写“醇羟基”，因题目要求写官能团名称，“羟基”即为标准答案。
- 问（6）：
- 定量判断：$n(CO_2)=2.24\ L / 22.4\ L\cdot mol^{-1}=0.1\ mol$。由$R-COOH + NaHCO_3 \to R-COONa + CO_2!\uparrow + H_2O$，知$n(—COOH)=0.1\ mol$。
- 由B（异山梨醇，分子式$C_6H_{10}O_4$）可知F的同分异构体分子式也为$C_6H_{10}O_4$，其不饱和度为$\frac{2\times6+2-10}{2}=2$。已有一个羧基（含一个不饱和度），剩余一个不饱和度可能为碳碳双键或环。
- 通过摩尔质量计算：若含1个羧基，剩余部分式量为$7.30g / 0.1mol - 45 = 28$，查化学式可推知$C_6H_{10}O_4$除$COOH$外含$C_5H_9O_2$，据不饱和度和结构要求写出可能的碳骨架异构体，共9种。
- 峰面积比3:1:1，对应3个化学环境相同的氢（$CH_3$），1个和1个其他氢，匹配高度对称的分子结构，最后简写为$(CH_3)_2C(COOH)_2$的二甲基丙二酸或另一种高度对称的烯酸结构（根据核磁共振结果具体确认，答案略）。

点评/变式
本题从简单官能团名称填空到复杂异构体推断，始终以官能团识别为核心线索。复习时要特别注意：
（1）官能团名称要填写汉字且规范；
（2）利用典型反应（与$Na$、$NaHCO_3$、银氨溶液等）锁定特定官能团及数目；
（3）结合定量计算确定官能团数目是常见考法，如给出与$Na$反应生成$H_2$的量可判断活泼氢（羟基、羧基）数目，与溴水反应耗溴量可判断碳碳双键的数目等。
变式：若题中改为F能与$Na$反应放出$H_2$，则需通过气体量计算羟基与羧基的活泼氢总数，再结合其他信息逐一排除。
