知识精要

  • 常见阴离子的检验方法
  • $CO_3^{2-}$：加酸产生无色无味且能使澄清石灰水变浑浊的气体（$CO_2$）。
  • $SO_3^{2-}$：加酸产生有刺激性气味且能使品红褪色的气体（$SO_2$）；其与 $Ba^{2+}$ 生成的 $BaSO_3$ 白色沉淀可溶于盐酸。
  • $SO_4^{2-}$：与 $Ba^{2+}$ 生成不溶于盐酸的白色沉淀 $BaSO_4$。
  • $Cl^-$、$Br^-$、$I^-$：用 $AgNO_3$ 检验时需先用稀 $HNO_3$ 排除 $CO_3^{2-}$ 等干扰；$AgX$ 沉淀颜色：$AgCl$ 白、$AgBr$ 浅黄、$AgI$ 黄。
  • $Br^-$、$I^-$：也可用氯水—$CCl_4$ 萃取法，$CCl_4$ 层显橙红色表明含 $Br^-$，显紫色表明含 $I^-$。

  • $NO_3^-$：在本题环境下未设特殊检验，仅通过排除法推断。

  • 离子检验中的水解与酸碱性
    $CO_3^{2-}$、$SO_3^{2-}$ 等弱酸根水解呈碱性，但碱性只指示可能存在，不能唯一确定具体离子。

  • 实验推理核心原则

  • 现象→离子性质：每种试剂或操作只针对特定的离子产生特征现象。
  • 肯定与排除：根据特征现象肯定某些离子存在，同时根据无特征现象或干扰排除另一些离子。
  • 顺序与互斥：注意实验步骤的先后对结论的影响，以及离子间的共存矛盾（如氧化还原、沉淀反应等）。

解题方法与套路

  1. 逐项分析，建立逻辑链
    对每个实验步骤，先明确加入的试剂和操作针对的可能离子，再对照现象得出结论。结论分为三类：肯定存在、肯定不存在、可能存在。

  2. 紧扣“特征反应”定肯定

  3. 产生 $CO_2$（无色无味使石灰水浑浊）→ 必有 $CO_3^{2-}$；
  4. 沉淀不溶于盐酸 → 必有 $SO_4^{2-}$；
  5. 加 $CCl_4$ 后氯水振荡无颜色 → 必无 $Br^-$ 和 $I^-$；

  6. 加 $HNO_3$ 和 $AgNO_3$ 产生白色沉淀 → 必有 $Cl^-$（此时 $Ag_2CO_3$、$Ag_2SO_3$ 等被酸化破坏，不干扰）。

  7. 利用“无现象”作排除

  8. 无刺激性气味气体 → 排除 $SO_3^{2-}$；
  9. $CCl_4$ 层无色 → 排除 $Br^-$、$I^-$；

  10. 后续若需，也可结合电荷守恒与共存限制判断 $NO_3^-$ 等是否存在。

  11. 沉淀溶解差异鉴别 $SO_4^{2-}$ 与 $SO_3^{2-}$
    加 $BaCl_2$ 得白色沉淀，再向沉淀加盐酸：

  12. 全溶且无气体 → 均为 $BaCO_3$，无 $SO_4^{2-}$、无 $SO_3^{2-}$；
  13. 全溶且有刺激性气体 → 有 $BaSO_3$，无 $SO_4^{2-}$；

  14. 不溶或部分不溶 → 存在 $BaSO_4$，肯定有 $SO_4^{2-}$；部分溶解可能同时有 $BaCO_3$ 或 $BaSO_3$。

  15. 整合结论，注意文字规范
    结论应按“实验 X 的结论与理由”格式书写，理由必须对应现象与离子性质的因果关系。

高频易错

  • $CO_3^{2-}$ 与 $SO_3^{2-}$ 混淆
    两者的加酸产物均为酸性气体，但 $CO_2$ 无色无味，$SO_2$ 有刺激性气味。仅凭石灰水浑浊不能区分，必须结合气体气味或后续品红实验。

  • $SO_4^{2-}$ 与 $SO_3^{2-}$ 在钡盐沉淀中的误判
    若只加 $BaCl_2$ 得白色沉淀便认定 $SO_4^{2-}$，忽略了 $BaSO_3$、$BaCO_3$ 也是白色沉淀。必须加盐酸区分：$BaSO_4$ 不溶，其余可溶。

  • 卤素离子的检验忽略干扰

  • 用 $AgNO_3$ 检验 $Cl^-$ 前必须用稀 $HNO_3$ 酸化，否则 $CO_3^{2-}$、$SO_3^{2-}$ 等会生成白色沉淀干扰。

  • 用氯水—$CCl_4$ 法检验 $Br^-$、$I^-$ 时，若溶液中同时存在 $SO_3^{2-}$，氯水先氧化 $SO_3^{2-}$ 使 $Br^-$、$I^-$ 不被氧化，导致 $CCl_4$ 层颜色不明显，但本题中 $SO_3^{2-}$ 已提前排除。

  • “可能存在”结论的滥用
    不能将无特征现象等同于可能存在，例如 $NO_3^-$ 若未做任何检验，则结论只能是“不能确定是否存在”，或根据电荷守恒推断。在本题每个实验的结论只针对该实验所能鉴定的离子，最终的综合推断才容许“可能存在”。

  • 忽视试剂引入的离子
    如实验④加入 $BaCl_2$ 引入了 $Cl^-$，后续检验 $Cl^-$ 时若不再取原溶液则会干扰。本题中各实验分别取少量溶液，所以不存在此问题；但若同一份溶液连续操作，需注意试剂递进引入的离子。

代表题精讲

题目（2008·全国Ⅱ·11）
某钠盐溶液可能含 $NO_3^-$、$CO_3^{2-}$、$SO_3^{2-}$、$SO_4^{2-}$、$Cl^-$、$Br^-$、$I^-$。通过五个独立实验进行鉴别，要求根据现象写出每个实验鉴定离子的结论及理由。

思路
本题为经典的无机阴离子推理题，每个实验独立取样，结论不互相依赖。解题时紧扣“所用试剂—可能被检验的离子—现象对应的特征反应”链条，逐项得出肯定或否定的结论。
- ①：测酸碱性 → 水解呈碱性的离子可能有 $CO_3^{2-}$、$SO_3^{2-}$。
- ②：加 HCl 生成气体，使石灰水浑浊且无色无味 → 必有 $CO_3^{2-}$，无 $SO_3^{2-}$。
- ③：$CCl_4$ + 氯水，$CCl_4$ 层未变色 → 无 $Br^-$、$I^-$。
- ④：加 $BaCl_2$ 产生白色沉淀，沉淀加盐酸不能全溶 → 肯定 $SO_4^{2-}$（$BaSO_4$ 不溶）。
- ⑤：$HNO_3$ 酸化后加过量 $AgNO_3$ 出白色沉淀 → 必有 $Cl^-$。

步骤
1. 实验①
结论：$CO_3^{2-}$ 和 $SO_3^{2-}$ 可能存在，因为它们水解呈碱性。
理由：$CO_3^{2-} + H_2O \rightleftharpoons HCO_3^- + OH^-$，$SO_3^{2-} + H_2O \rightleftharpoons HSO_3^- + OH^-$，均使溶液显碱性，仅凭碱性不能确定具体是哪一种离子。

  1. 实验②
    结论：$CO_3^{2-}$ 肯定存在，因为产生的气体是 $CO_2$；$SO_3^{2-}$ 肯定不存在，因为没有刺激性气味的气体产生。
    理由：$CO_3^{2-} + 2H^+ = CO_2\uparrow + H_2O$，$CO_2$ 无色无味，遇饱和石灰水生成 $CaCO_3$ 沉淀使溶液变浑浊。若存在 $SO_3^{2-}$，则生成有刺激性气味的 $SO_2$，实际无刺激性气味，故排除 $SO_3^{2-}$。

  2. 实验③
    结论：$Br^-$、$I^-$ 肯定不存在，因为没有溴和碘的颜色出现。
    理由：加入氯水将 $Br^-$ 氧化为 $Br_2$、$I^-$ 氧化为 $I_2$，二者均易溶入 $CCl_4$，分别呈现橙红色和紫色。现 $CCl_4$ 层无色，说明无 $Br_2$ 和 $I_2$生成，故原溶液无 $Br^-$、$I^-$。

  3. 实验④
    结论：$SO_4^{2-}$ 肯定存在，因为 $BaSO_4$ 不溶于盐酸。
    理由：加 $BaCl_2$ 产生的白色沉淀可能为 $BaCO_3$、$BaSO_3$、$BaSO_4$ 等，加入足量盐酸后，$BaCO_3$ 和 $BaSO_3$ 均溶解（后者伴 $SO_2$ 气体），唯 $BaSO_4$ 不溶。沉淀不能完全溶解，说明有 $BaSO_4$，从而确证 $SO_4^{2-}$ 存在。

  4. 实验⑤
    结论：$Cl^-$ 肯定存在，因为生成白色沉淀 $AgCl$。
    理由：加 $HNO_3$ 酸化排除了 $CO_3^{2-}$、$SO_3^{2-}$ 等离子的干扰，再加过量 $AgNO_3$ 产生的白色沉淀 $AgCl$ 不溶于稀硝酸，故可确认 $Cl^-$。

点评/变式
- 本题得分关键词：特征气味、“不溶于盐酸”的沉淀、“CCl4层未变色”、酸化排干扰。
- 易错点：实验④若忽略“不能完全溶解”而只写白色沉淀，易漏掉 $SO_4^{2-}$ 的判断。
- 变式拓展：若实验④中沉淀加盐酸后全溶，且产生刺激性气味气体，则判定 $SO_3^{2-}$ 存在而 $SO_4^{2-}$ 不存在；若无气体只全溶，则只含 $CO_3^{2-}$。若实验③ $CCl_4$ 层先变紫后褪色，还需考虑 $I_2$ 被过量氯水进一步氧化的可能。这些变化均体现“实验推理”题型对试剂用量与步骤逻辑的严格考查。
