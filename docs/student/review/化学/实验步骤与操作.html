知识精要

  • 实验操作的完整流程通常遵循“气密性检查 → 药品装入 → 发生/除杂/干燥 → 主体反应 → 收集 → 尾气处理 → 撤装置”的主线。
  • 气体制备与性质实验中，防爆炸、防倒吸、防污染是步骤设计的核心安全目标。
  • 排尽装置内空气：可燃性气体（如 $H_2$）与空气混合受热易爆炸，反应前必须用产生的气体将系统内空气排尽。
  • 验纯：点燃或加热可燃性气体前，必须收集气体并检验纯度，确认无爆鸣声后方可进行后续操作。
  • 先撤导管后停加热（防倒吸）：在有加热的反应中，停止加热前要先将导管移出液面或停止吸收，防止因降温导致系统内压强减小而引发倒吸。
  • 先通气体后加热，先停加热后停气：对需要持续通气的反应，开始时先通气排空气再加热，结束时先停止加热，待冷却后再停止通气。
  • 冷凝收集与冷却：对高温反应后的固体产物，需在停止加热后继续通气，直至冷却到常温再取出，防止高温下与空气接触反应或发生危险。

解题方法与套路

  1. 明确实验目的与装置角色
    先通过题给信息确定目标反应、气体流向以及各装置的功能（发生、净化、干燥、主体反应、收集、尾气处理等）。
  2. 按气流方向确定接口连接顺序
  3. 发生装置出气口→净化→干燥→主体反应→（必要时收集）→尾气处理。
  4. 接口遵循“长进短出”“大口进小口出”的原则（洗气瓶、干燥管等）。
  5. 拆解步骤选项，分割“开始→反应→结束”三阶段
  6. 开始阶段：检查气密性 → 加药品 → 打开分液漏斗活塞（产生气体）→ 排尽空气 → 验纯。
  7. 反应阶段：先通气体 → 点燃或加热 → 反应进行。
  8. 结束阶段：停止加热 → 继续通气至冷却 → 停气 → 拆卸装置。
    将题中给出的操作选项代入三阶段排序。
  9. 利用关键动词锁定前后顺序
    “检验纯度”必在“加热”前；“停止加热”必在“停止通气体”之前；“装入药品”必在“打开活塞”之前。注意“排尽空气”这一步常隐含在“产生气体”和“加热”之间完成。
  10. 验证逻辑：检查每一步是否满足安全、不引入杂质、不损失目标产物的要求。

高频易错

  • 漏掉验纯步骤：只要涉及可燃性气体加热或点燃，就必须先验纯，否则直接给可燃气体加热会爆炸。
  • 加热与通气的先后颠倒：反应管加热前必须通一段时间的原料气排尽空气；反应结束时，先停加热，继续通气冷却，否则高温产物被空气氧化或倒吸。
  • 未区分“产生气体”与“加热反应”的先后：产生气体后应先用氢气排尽装置内空气，并在加热前检验纯度，而不是立刻加热反应管。
  • 忘记防倒吸操作：对有气体参与或有液体吸收的反应，停止加热后装置内压力下降，若未先撤导管易倒吸。
  • 装药品顺序出错：一般先放固体，再加入液体（如分液漏斗中酸液），且都在气密性检查之后。装药品后再查验气密性是错误顺序。

代表题精讲

代表题 2011-新课标-10

题目：制备氢化钙需要将净化干燥后的 $H_2$ 在加热条件下与金属钙反应。实验装置包含气体发生（锌粒加盐酸）、除杂干燥和主体反应管。请连接装置接口并排出实验步骤顺序。

思路
气路方向：发生装置→除 $HCl$ →干燥 $H_2$ →反应管→尾气。步骤排序需抓住“气密性→装药→通$H_2$排空→验纯→加热反应→停热冷却→停气”的主线，并结合选项字母对应操作。

步骤 1. 接口连接
$i$（从发生瓶出气口）接 $e$；$f$ 接 $d$（洗气瓶或干燥管“长进短出”）；$c$ 接 $j$；$k$ 接 $a$。顺序：$i \to e, f \to d, c \to j, k \to a$。
2. 步骤排序（选项：B—打开分液漏斗活塞产生氢气，A—加热反应管并收集检验纯度，D—停止加热，C—收集气体检验氢气纯度）
- 检查装置气密性、装入药品后，先 B 打开分液漏斗活塞产生 $H_2$。
- 氢气将系统内空气排尽，此时需要 C 收集气体检验氢气纯度（验纯），确认空气已被排尽且氢气纯净。
- 验纯合格后 A 加热反应管，使 $H_2$ 与 $Ca$ 反应。
- 反应完毕先 D 停止加热，继续通 $H_2$ 冷却至室温，防止高温氢化钙与空气反应，也防止倒吸。
最终顺序：BADC。

点评/变式
本题典型体现了“可燃气体参与加热反应”的完整安全操作逻辑：排空气→验纯→加热→先停热后停气。易错点在于混淆 A 与 C 的顺序——题目中 A 选项包含“收集气体并检验纯度”，但若把 A 放在 C 前，相当于直接加热了未排尽空气的体系，极易爆炸。实际验纯应在加热之前单独完成。变式可出现在 $CO$ 还原氧化铁、$H_2$ 还原氧化铜等实验中，核心套路完全一致。
