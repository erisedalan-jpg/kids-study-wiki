知识精要

实验现象的准确描述与匹配是化学实验考查的核心。核心要求：基于反应原理，从“色、态、味、光、热、分层、沉淀、气体”等角度完整记录，并关注试剂过量、环境干扰等隐藏因素。

  • 常见现象表述规范
  • 颜色变化：需明确反应前后物质颜色，如紫色褪去、黄色消失、棕黄色变浅绿色等。
  • 沉淀生成：注明颜色与状态，如“白色沉淀”“红褐色沉淀”。
  • 气体产生：指明色、味与检验特征，如“有刺激性气味气体”“使带火星木条复燃”。
  • 分层与溶解：有机反应后需关注水相与有机相的分离；固体溶解或残留。

  • 烟、雾、气区分：烟是固体小颗粒（如MgO与C浓烟），雾是液滴，气为无色无味气体。

  • 常见实验操作中的必记现象

  • 酸性KMnO₄与不饱和烃：紫色褪去，但产物（CO₂、Mn²⁺盐）无色，静置不分层。
  • Mg在CO₂中燃烧：剧烈燃烧，生成白色MgO与黑色C，产生浓烟并有黑色颗粒。
  • Na₂S₂O₃与酸：S₂O₃²⁻+2H⁺=S↓+SO₂↑+H₂O，产生有刺激性气味气体，溶液变浑浊（淡黄色硫）。
  • Fe³⁺与Fe：Fe+2Fe³⁺=3Fe²⁺，黄色消失，加KSCN不变红。
  • 甲烷与Cl₂光照：黄绿色变浅，试管内壁出现油状液滴（氯代烃），试管内液面上升（HCl溶入饱和食盐水）。

解题方法与套路

  1. 先判原理，再对现象
    对于任何“操作—现象”匹配题，先写出核心化学方程式，明确产物组成、颜色、状态和溶解性，再与选项描述逐项比对。

  2. 逐项排除
    若题目要求选“不匹配”，则优先排查明显违背化学常识的现象描述，如：易溶气体生成却写“分层”、反应后溶液颜色与产物不符等。

  3. 注意过量与残留
    当试剂足量或过量时，思考是否会将中间产物进一步转化（如通入足量乙烯使KMnO₄褪色但不会分层），或残留固体造成颜色干扰（如Mg在CO₂中生成黑色C颗粒）。

  4. 串联装置与体系分析
    对于气体参与的光照反应（如CH₄与Cl₂），结合压强、溶解度、反应产物分析试管内液面变化和油状物产生，不能遗漏物理现象。

  5. 控制变量思想
    在影响速率、现象对比的实验设计中（如2010年锌与酸），抓住唯一变量，分析其对形成原电池、反应接触面积等的影响，进而解释现象变化（如金属颜色、气泡快慢）。

高频易错

  • 酸性KMnO₄与乙烯褪色后，误认为溶液分层。产物均为可溶性无机盐，静置不分层。
  • 将Mg在CO₂中燃烧的“浓烟”等同于“白雾”。此处浓烟是MgO和C的固体微粒，不是液滴。
  • Na₂S₂O₃与稀盐酸产生的浑浊叙述不够精确，易写成“白色浑浊”，应明确为“淡黄色或乳黄色硫单质”。
  • FeCl₃加过量铁粉后溶液呈浅绿色，但加入KSCN应不变红，如果忘记铁粉过量导致Fe³⁺完全反应，会错判现象。
  • 甲烷取代反应易漏答“液面上升”，或错误写成“试管内液面下降”。生成HCl溶于水造成压强减小，液面上升。
  • 原电池加快H₂生成速率实验中，忽略过量CuSO₄导致铜覆盖锌表面过多，减少锌与酸接触面积，速率反而下降。
  • 白色粉末鉴别时，忽视“足量酸”与“过量碱”等字眼，容易混淆沉淀溶解与气体产生的先后顺序。

代表题精讲

代表题1：2019-新课标Ⅱ-04

题目
下列实验现象与实验操作不相匹配的是哪一项？选项涉及酸性KMnO₄与足量乙烯、镁条在CO₂中燃烧、Na₂S₂O₃与稀盐酸、FeCl₃与过量铁粉后加KSCN。

思路
分别写出各反应的化学方程式，确定最终产物的颜色、状态、溶解性，与描述的现象逐条对照，指出矛盾点。

步骤
1. 操作A：酸性KMnO₄氧化乙烯生成CO₂、K₂SO₄、MnSO₄，均为可溶性无色物质。紫色褪去正确，但静置后不会分层，因为无有机层或不溶物。现象中“静置后溶液分层”不匹配。
2. 操作B：2Mg + CO₂ 点燃→ 2MgO + C，MgO白烟与黑色碳颗粒形成“浓烟并有黑色颗粒”，现象匹配。
3. 操作C：Na₂S₂O₃ + 2HCl = 2NaCl + S↓ + SO₂↑ + H₂O，有刺激性气味SO₂和淡黄色硫浑浊，现象匹配。
4. 操作D：Fe + 2FeCl₃ = 3FeCl₂，黄色Fe³⁺消失，加KSCN不变红，现象匹配。
故不匹配的是A。

点评/变式
此题的陷阱在于乙烯被氧化后是否有分层。若将乙烯换成苯乙烯或长链烯烃，可能会有不溶性二元醇产生，需具体分析。另外，注意“足量”二字确保KMnO₄完全反应，否则残留紫色也会误导。变式：向酸性KMnO₄中通入足量乙烯，再加入CCl₄萃取——此时会分层，但描述中未涉及萃取，不可额外加戏。

代表题2：2018-新课标Ⅱ-03

题目
实验室用如图所示装置进行甲烷与氯气在光照下反应，试描述预期现象。

思路
从反应物消耗、产物状态和溶解性、体系压强变化三方面入手。甲烷与氯气取代生成氯代烃（二氯甲烷、三氯甲烷、四氯甲烷为油状液体）和HCl，HCl易溶于饱和食盐水，导致试管内气压降低。

步骤
1. 光照后，黄绿色Cl₂被消耗，气体颜色逐渐变浅。
2. 生成的氯代烃沸点较高，试管内壁附着无色油状液滴。
3. HCl气体不断溶入水槽中的饱和食盐水，试管内气体分子数减少，压强减小，水槽液面上方大气压将液体压入试管，试管内液面缓慢上升。
4. 若有NaCl晶体析出属于同离子效应，但非教材必答现象，靠题设回答即可。

点评/变式
该实验常误认为液面下降（若答HCl不溶或认为生成气体增加）。务必牢记：取代反应生成的HCl极易溶于水，是其典型特征。变式：若水槽内为稀NaOH溶液，则油状液滴会因氯代烃部分水解而减少，液面上升更明显。

代表题3：2016-新课标Ⅱ-06

题目
某白色粉末由两种物质组成，为鉴别其成分进行如下实验：
①取少量样品加足量水仍有部分固体未溶解；
②再加入足量稀盐酸，有气泡产生，固体全部溶解；
③取少量样品加入足量稀硫酸有气泡产生，振荡后仍有固体存在。
则该粉末可能为哪组物质？

思路
从白色固体、加水部分溶解、加盐酸全溶且有气体、加稀硫酸有气体且留有固体等矛盾点切入，利用离子共存和沉淀转化进行分析。加硫酸仍有固体，暗示有难溶性硫酸盐或沉淀生成。

步骤
1. 实验①：粉末加水部分不溶，排除全溶组合（如NaHCO₃和Al(OH)₃不能加水产生不溶固体？Al(OH)₃难溶，NaHCO₃可溶，所以可以是难溶+可溶）。
2. 实验②：加足量稀盐酸，固体全部溶解有气体，说明不溶于水的物质能与酸反应放出气体（如碳酸盐、亚硫酸盐）且不产生难溶性氯化物。
3. 实验③：加足量稀硫酸有气体，振荡后仍有固体，说明有气体放出（CO₂或SO₂），且生成了难溶于硫酸的沉淀（如BaSO₄、PbSO₄等）。结合白色粉末组合，BaCO₃与Na₂SO₃或Na₂CO₃与BaCl₂等。
4. 验证选项：C项Na₂SO₃、BaCO₃：加水，BaCO₃难溶，Na₂SO₃可溶，有固体剩余；加足量盐酸，BaCO₃与Na₂SO₃均反应放出气体（CO₂和SO₂），且生成BaCl₂可溶，固体全溶；加足量稀硫酸，BaCO₃转化为BaSO₄不溶且放出CO₂，Na₂SO₃转化为Na₂SO₄并放出SO₂，振荡后BaSO₄固体不消失，与实验符合。其他选项或无不溶物，或加盐酸后仍有不溶物（如AgCl），或加硫酸后无固体。故C符合。

点评/变式
这类鉴别题的关键是“双线索”：气体+沉淀的变化。注意“足量”酸能否完全溶解不溶物；“振荡后仍有固体”提示该固体并非气泡包裹，而是真实难溶。变式可改为检验操作顺序或使用BaCl₂而非硫酸，会改变现象。
