平衡常数

考点平衡常数权重39真题数3学科化学父主题化学反应原理

考点定位

  • 父主题：化学反应原理
  • 权重 weight：39
  • 真题数：3；年份跨度：2020–2023
  • 出现题位：选择7 选择10
  • 难度分布：中3

知识精要

  • 平衡常数定义：对于任意可逆反应 $a\mathrm{A}+b\mathrm{B} \rightleftharpoons c\mathrm{C}+d\mathrm{D}$，在一定温度下达到平衡时，浓度平衡常数 $K_c = \dfrac{c^c(\mathrm{C})\cdot c^d(\mathrm{D})}{c^a(\mathrm{A})\cdot c^b(\mathrm{B})}$。若用平衡分压表示，则压力平衡常数 $K_p = \dfrac{p^c(\mathrm{C})\cdot p^d(\mathrm{D})}{p^a(\mathrm{A})\cdot p^b(\mathrm{B})}$。
  • 适用范围：纯固体、纯液体及稀溶液中的溶剂（如水）不写入表达式；$K$ 只受温度影响，与浓度、压强、催化剂无关。
  • 多重平衡规则：若反应③=反应①+反应②，则 $K_3 = K_1 \times K_2$；若反应③=反应①−反应②，则 $K_3 = K_1 / K_2$。该规则适用于耦合的沉淀溶解平衡、配位平衡、酸碱平衡和氧化还原平衡。
  • $K_p$ 的计算要点：$p_i = p_{\text{总}} \times \phi_i$（$\phi_i$ 为物质的量分数）；$K_p$ 表达式中压强需用平衡时的实际分压代入；$K_p$ 与 $K_c$ 的关系：$K_p = K_c(RT)^{\Delta n}$。
  • 平衡常数与转化率：$K$ 越大，正向反应进行程度越大；同一反应，温度变化时 $K$ 变化，进而引起转化率改变。对于吸热反应，升温 $K$ 增大；放热反应，升温 $K$ 减小。

解题方法与套路

  1. “三段式”法求平衡常数
  2. 写出配平的化学方程式，列出起始浓度（或物质的量）、转化量、平衡量。
  3. 代入平衡常数表达式，注意固体、纯液体不列入。

  4. 涉及 $K_p$ 时，先求出平衡时各气体的物质的量分数，再结合总压求分压，代入 $K_p$。

  5. 图像题处理平衡常数

  6. 对于 $\lg c$ 型坐标，抓住特殊点：当两种离子浓度相等时，$\lg c_1 = \lg c_2$，对应横坐标已知，可快速解出相关平衡常数。

  7. 利用多重平衡关系，将溶度积常数与配位平衡常数耦合，解出复杂体系中各物种浓度。

  8. 多重平衡体系 $K$ 的计算

  9. 将体系中同时存在的反应逐一列出，利用已知的平衡常数建立方程。
  10. 通过元素守恒、电荷守恒等补充方程，联立求解未知分压或浓度。

  11. 若需计算压强，善用道尔顿分压定律，通过总压变化推知反应进度。

  12. 以转化率 $\alpha$ 表达 $K_p$

  13. 假设初始物质的量为 $n_0$，列出转化率 $\alpha$ 下的平衡物质的量。
  14. 计算物质的量分数，乘以总压得到分压，代入 $K_p$ 表达式化简，最终得到含 $\alpha$ 和 $p$ 的代数式。

高频易错

  • 忽略固体或纯液体的处理：$K_c$、$K_p$ 表达式中绝不写入固体或纯液体；若反应体系中存在固体，其浓度视为常数1。
  • 混淆 $K$ 的影响因素：误以为改变浓度或压强的平衡移动会改变 $K$ 值；实际上只有温度才会改变平衡常数。
  • $K_p$ 表达式中错误使用总压：直接用总压代入计算，未按物质的量分数求分压，或者将分压错误地等同于初始分压。
  • 多重平衡耦合时的符号方向：当总反应由分反应相加减得到时，平衡常数计算中的乘除关系容易颠倒；务必写明方程组合，再对应常数关系。
  • 对数坐标图的数据读取：$\lg c$ 型图中交点对应的浓度绝对值判断失误，导致数量级计算错误（如 $K_{sp}=10^{-9.75}$ 需准确读出交点坐标）。
  • 压强计算中的单位转换：有的题目给出 $K_p$ 单位为 $\mathrm{Pa}$ 或其平方，计算时若总压用 $\mathrm{kPa}$ 必须统一单位，否则数量级出错。

代表题精讲

题目1 （2023·新课标）

向 $\mathrm{AgCl}$ 饱和溶液（有足量 $\mathrm{AgCl}$ 固体）中滴加氨水，存在平衡 $\mathrm{Ag}^+ + \mathrm{NH_3} \rightleftharpoons \mathrm{Ag(NH_3)^+}$ 和 $\mathrm{Ag(NH_3)^+} + \mathrm{NH_3} \rightleftharpoons \mathrm{Ag(NH_3)2^+}$，$\lg c(\mathrm{M})$ 与 $\lg c(\mathrm{NH_3})$ 关系如图。判断选项正误，涉及 $K$ 与配合反应 $K$ 的计算。

思路：
利用图中曲线交点（离子浓度相等的点）结合多重平衡关系计算 $K_{sp}$ 和配合平衡常数。

步骤
1. 由图，当 $\lg c(\mathrm{Ag^+})$ 与 $\lg c(\mathrm{Cl^-})$ 相等时（曲线交点），$\lg c(\mathrm{NH_3})$ 极小，此时几乎无配位反应，该点对应 $c(\mathrm{Ag^+}) = c(\mathrm{Cl^-}) = 10^{-4.875} \ \mathrm{mol\cdot L^{-1}}$，因此 $K_{sp} = (10^{-4.875})^2 = 10^{-9.75}$。
2. 第二段配位平衡 $\mathrm{Ag(NH_3)^+} + \mathrm{NH_3} \rightleftharpoons \mathrm{Ag(NH_3)_2^+}$ 的平衡常数 $K = \dfrac{c(\mathrm{Ag(NH_3)_2^+})}{c(\mathrm{Ag(NH_3)^+})\cdot c(\mathrm{NH_3})}$。当 $c(\mathrm{Ag(NH_3)_2^+}) = c(\mathrm{Ag(NH_3)^+})$ 时，$\lg\dfrac{\cdots}{\cdots} = 0$，由图中交点可以读出此时 $\lg c(\mathrm{NH_3}) \approx -3.81$，即 $c(\mathrm{NH_3}) = 10^{-3.81}$，故 $K = 1 / c(\mathrm{NH_3}) = 10^{3.81}$。
3. 综合判断各选项，曲线Ⅰ表示 $\mathrm{Ag^+}$ 浓度的变化而非 $\mathrm{AgCl}$ 溶解度变化（溶解度应包含所有含银物种），故A错。

点评/变式：此类图像题的关键在于利用离子浓度相等的交点直接求常数；若变式涉及 $\mathrm{Cu(NH_3)_4^{2+}}$ 等分步配位体系，方法相同，注意各级配位平衡的耦合。

题目2 （2021·全国乙）

在 $376.8\ \mathrm{^\circ C}$，$\mathrm{BaPtCl_6}$ 部分分解反应 $K_p' = 1.0 \times 10^4\ \mathrm{Pa}^4$。通入碘蒸气初始压强 $20.0\ \mathrm{kPa}$，平衡总压 $32.5\ \mathrm{kPa}$。求 $\mathrm{ICl}$ 分压及反应 $2\mathrm{ICl(g)} \rightleftharpoons \mathrm{Cl_2(g)} + \mathrm{I_2(g)}$ 的平衡常数 $K$。

思路：
联立两个反应，通过总压变化解出各气体分压，再代入目标反应的 $K$ 表达式。

步骤
1. 体系同时存在两个反应：
① $\mathrm{BaPtCl_6(s) \rightleftharpoons BaCl_2(s) + Pt(s) + 2Cl_2(g)}$，已知 $K_p' = p_{\mathrm{Cl_2}}^2 = 1.0\times10^4\ \mathrm{Pa}^4$，解得平衡时 $p_{\mathrm{Cl_2}} = 100\ \mathrm{Pa} = 0.1\ \mathrm{kPa}$。
2. 反应②： $\mathrm{I_2(g) + Cl_2(g) \rightleftharpoons 2ICl(g)}$（实际上题干给出 $2\mathrm{ICl} \rightleftharpoons \mathrm{Cl_2 + I_2}$，可先求逆反应常数再换算）。设初始碘蒸气压 $20.0\ \mathrm{kPa}$，$\mathrm{Cl_2}$ 初始为 $0$。平衡时 $p_{\mathrm{Cl_2}} = 0.1\ \mathrm{kPa}$，设 $p_{\mathrm{I_2}}$ 为 $x\ \mathrm{kPa}$，$p_{\mathrm{ICl}}$ 为 $y\ \mathrm{kPa}$。
3. 由总压：$p_{\mathrm{Cl_2}} + p_{\mathrm{I_2}} + p_{\mathrm{ICl}} = 0.1 + x + y = 32.5\ \mathrm{kPa}$。
4. 由碘元素守恒：初始碘都被转化为 $\mathrm{I_2}$ 和 $\mathrm{ICl}$，即 $20.0 = x + \dfrac{1}{2}y$。
5. 解方程组得 $x = 7.6\ \mathrm{kPa}$，$y = 24.8\ \mathrm{kPa}$，故 $p_{\mathrm{ICl}} = 24.8\ \mathrm{kPa}$。
6. 反应 $2\mathrm{ICl} \rightleftharpoons \mathrm{Cl_2 + I_2}$ 的 $K = \dfrac{p_{\mathrm{Cl_2}}\cdot p_{\mathrm{I_2}}}{p_{\mathrm{ICl}}^2} = \dfrac{0.1\times7.6}{24.8^2}$，列出计算式即可。

点评/变式：多重平衡体系中，常利用一个反应平衡常数恒定得到某一气体分压，再结合总压和物料守恒求解。若条件给出 $K_c$，同样可用浓度进行类似计算，注意单位统一。

题目3 （2020·新课标Ⅱ）

乙烷脱氢反应 $\mathrm{C_2H_6(g) \rightleftharpoons C_2H_4(g) + H_2(g)}$，等压 $p$，转化率 $\alpha$，求 $K_p$。

思路：
用三段式表达平衡时各物质的量，写出分压，代入 $K_p$ 表达式并化简。

步骤
1. 设初始乙烷和氢气各为 $1\ \mathrm{mol}$，则初始总量 $2\ \mathrm{mol}$。平衡时：$n_{\mathrm{C_2H_6}} = 1-\alpha$，$n_{\mathrm{C_2H_4}} = \alpha$，$n_{\mathrm{H_2}} = 1+\alpha$。平衡总物质的量 $n_{\text{总}} = 2+\alpha$。
2. 各气体分压：
$p_{\mathrm{C_2H_6}} = \dfrac{1-\alpha}{2+\alpha}\cdot p$，
$p_{\mathrm{C_2H_4}} = \dfrac{\alpha}{2+\alpha}\cdot p$，
$p_{\mathrm{H_2}} = \dfrac{1+\alpha}{2+\alpha}\cdot p$。
3. $K_p = \dfrac{p_{\mathrm{C_2H_4}}\cdot p_{\mathrm{H_2}}}{p_{\mathrm{C_2H_6}}} = \dfrac{\dfrac{\alpha}{2+\alpha}\cdot p \cdot \dfrac{1+\alpha}{2+\alpha}\cdot p}{\dfrac{1-\alpha}{2+\alpha}\cdot p} = \dfrac{\alpha(1+\alpha)}{(1-\alpha)(2+\alpha)}\cdot p$。

点评/变式：此类推导常见于压强大题，关键在于正确表示总物质的量以及各组分分压。变式可能给出体积比或总压变化，同样用三段式结合分压定义求解。
