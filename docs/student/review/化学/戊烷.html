戊烷

考点戊烷权重0真题数1学科化学父主题有机化学

考点定位

  • 父主题：有机化学
  • 权重 weight：0
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 戊烷的同分异构体：分子式 $C_5H_{12}$ 的烷烃有三种碳骨架：
  • 正戊烷（直链）：$CH_3CH_2CH_2CH_2CH_3$
  • 异戊烷（2-甲基丁烷）：$(CH_3)_2CHCH_2CH_3$
  • 新戊烷（2,2-二甲基丙烷）：$C(CH_3)_4$
  • 一元取代物数目 = 等效氢种类数：烃分子中位置等价的一组氢原子称为等效氢。判断等效氢的三种情况：
  • 同一碳原子上的氢等效；
  • 连在同一个碳原子上的甲基氢等效（如新戊烷的四个甲基氢全等效）；
  • 处于镜面对称位置上的氢等效。
  • 戊醇的同分异构：分子式 $C_5H_{12}O$，能与金属钠反应放 $H_2$ 说明含 $-OH$，属于饱和一元醇。将 $-OH$ 看作戊烷的一取代基，其异构体数 = 戊烷所有等效氢的种数。正戊烷有 3 种等效氢，异戊烷有 4 种，新戊烷有 1 种，共 $3+4+1=8$ 种（不考虑立体异构）。
  • 同分异构体书写原则：有序思维——“碳链异构 → 官能团位置异构 → 官能团类别异构”。本题官能团固定为 $-OH$，只需考虑碳链异构和羟基在碳链上的位置异构。

解题方法与套路

  1. 确认官能团与限制条件：由“与金属钠反应放氢气”判定为醇或羧酸，结合分子式 $C_5H_{12}O$ 不饱和度为0，确定为饱和一元醇 $C_5H_{11}-OH$。
  2. 写出所有碳骨架：列出戊烷的所有碳链异构体（正、异、新）。
  3. 判断等效氢并编号：
  4. 正戊烷：碳原子对称，$C_1$ 与 $C_5$、$C_2$ 与 $C_4$ 等效，共 3 种氢（$C_1、C_2、C_3$）。
  5. 异戊烷：有 4 种不同化学环境的氢（支链甲基、$C_2$、$C_3$、$C_4$ 上的氢各不相同）。
  6. 新戊烷：中心碳无氢，四个甲基完全相同，共 1 种氢。
  7. 取代定位：将 $-OH$ 逐一放到每种不同位置上，每种位置对应一种一元醇。总数相加即为异构体数。
  8. 复查：检查是否漏写碳链，是否误将相同位置重复计数；确认不考虑立体异构（手性碳造成的对映体不计数）。

高频易错

  • 忽略新戊烷的对称性：新戊烷分子高度对称，四个甲基完全等价，一羟代物只有 1 种。考生常误以为甲基上氢不等价或遗漏新戊烷本身，造成少算。
  • 将醚类异构体计入：$C_5H_{12}O$ 还包括饱和醚。但醚不与钠反应，不符合“放出氢气”的条件。必须严格按官能团限制筛选。
  • 等效氢判断失误：例如异戊烷中，1 个甲基连在 $C_2$ 上，该甲基三个H等效，但与主链端甲基环境不同，属于不同种氢。未仔细分析对称性易多计或少计。
  • 数位置异构与碳链异构混淆：先扩充碳链再编号，避免直接在戊烷上瞎画而导致重复。一定要先完整写出三种碳骨架。
  • 忽略题目“不考虑立体异构”：若擅自计入光学异构体，会选超过 8 种的答案。务必遵守题目明确给出的前提。

代表题精讲

题目（2012新课标）分子式为 $C_5H_{12}O$ 且可与金属钠反应放出氢气的有机物有（不考虑立体异构）
A. 5种 B. 6种 C. 7种 D. 8种

思路
与钠反应放氢气必定含羟基（$-OH$），即为戊醇。戊醇可看作戊烷分子中的一个氢原子被羟基取代的产物。戊醇的异构体数 = 戊烷的一羟代物数目 = 戊烷中等效氢的种数。先写出戊烷碳链异构体，再分别判断各类氢的数目并求和。

步骤
1. 写出戊烷 $C_5H_{12}$ 的三种碳链异构体：正戊烷、异戊烷、新戊烷。
2. 正戊烷：碳骨架对称，有 3 种不同位置的氢，可得到 3 种一元醇。
3. 异戊烷（2-甲基丁烷）：等效氢共有 4 种，对应 4 种位置异构的醇。
4. 新戊烷（2,2-二甲基丙烷）：四个甲基完全等价，只有 1 种氢，生出 1 种醇。
5. 总异构体数 $= 3+4+1 = 8$。答案选 D。

点评/变式
该题以“与钠反应”限制官能团，实质上考察烷烃基的异构。若将条件改为“能与 $NaHCO_3$ 反应”，则为羧酸，$C_5H_{12}O$ 含两个氧才能有羧基，分子式须强化。变式：分子式 $C_5H_{11}Cl$ 的同分异构体数同样可用此等效氢法解决，数目也是 8。掌握“碳骨架异构→等效氢判断”的流程，可快速解决一卤代物、一醇、一醛、一酸等异构体数问题。
