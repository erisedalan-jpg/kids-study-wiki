晶体结构与密度计算

考点晶体结构与密度计算权重6真题数1学科化学父主题晶体结构

考点定位

  • 父主题：晶体结构
  • 权重 weight：6
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择11
  • 难度分布：中1

知识精要

  • 电负性递变规律：同周期主族元素自左向右电负性增大；金属元素电负性通常较小。常见元素电负性大小：$\mathrm{O} > \mathrm{Ti} > \mathrm{Ca}$。
  • 晶体类型与熔点：离子晶体的熔点通常显著高于分子晶体。对于组成和结构相似的分子晶体，相对分子质量越大，范德华力越强，熔点越高（如 $\mathrm{TiCl_4} < \mathrm{TiBr_4} < \mathrm{TiI_4}$）。
  • 配位数：离子晶体中，某离子周围最近且等距离的异电性离子的数目。在 $\mathrm{CaTiO_3}$ 晶胞中，顶点 $\mathrm{Ca^{2+}}$ 的配位数为 12（被棱上的 $\mathrm{O^{2-}}$ 包围）。
  • 晶体密度计算通式： $$\rho = \frac{z M}{N_A a^3}$$ 其中，$\rho$ 为密度（单位：$\mathrm{g \cdot cm^{-3}}$），$z$ 为晶胞中结构基元或“分子”的数目，$M$ 为晶胞内含物质的总摩尔质量（单位：$\mathrm{g \cdot mol^{-1}}$），$N_A$ 为阿伏加德罗常数，$a$ 为晶胞参数（单位：$\mathrm{cm}$ 或换算为 $\mathrm{cm}$）。
  • 关于杂化：$\mathrm{CH_3NH_3^+}$ 中 N 原子形成 4 个 $\sigma$ 键，无孤电子对，为 $\mathrm{sp^3}$ 杂化。

解题方法与套路

  1. 快速确定晶胞内粒子的种类与个数（$z$ 值）：
  2. 顶点粒子算 $\frac{1}{8}$，棱上粒子算 $\frac{1}{4}$，面心粒子算 $\frac{1}{2}$，体心粒子算 $1$。求出整个晶胞内每种原子的净数目。
  3. 判断粒子对位关系：比较不同晶胞中离子的坐标参数。若占据同类型顶点或体心位置，则空间位置相同。
  4. 密度计算核心三步：
  5. 算总质量：根据化学式摩尔质量 $M$，晶胞若含 $z$ 个化学式单元，则总质量 $m_\text{cell} = zM/N_A$。
  6. 求晶胞体积：立方晶胞 $V = a^3$，注意单位换算：$1\ \mathrm{nm} = 10^{-7}\ \mathrm{cm}$，即 $a\ (\mathrm{nm}) \times 10^{-7}$ 才得到 $\mathrm{cm}$。
  7. 代入公式：$\rho = m_\text{cell} / V$，整理得分式表达式，不要求算出最终数值时保留运算形式即可。

高频易错

  • 熔点解释的两极分化：不能见到卤素就断定全是分子晶体。$\mathrm{TiF_4}$ 为离子晶体，离子键强导致熔点极高；其余三种为分子晶体，按范德华力解释。丢弃这一区分会严重失分。
  • 配位数数错：在三角形或钙钛矿构型中，顶点离子配位数常误数为 6（只看上下左右前后），实际若顶角与面心/棱心等距，配位数应为 12。
  • 单位陷阱：晶胞参数常给 $\mathrm{nm}$ 或 $\mathrm{pm}$，计算密度时体积必须化为 $\mathrm{cm^3}$。$1\ \mathrm{pm}=10^{-10}\ \mathrm{cm}$，$1\ \mathrm{nm}=10^{-7}\ \mathrm{cm}$。遗忘单位换算致使数量级全错。
  • 粒子承位置对应混淆：$\mathrm{CaTiO_3}$ 中 $\mathrm{Ti^{4+}}$ 占据体心，与 $\mathrm{Pb^{2+}}$ 占据八面体空隙中心类似，要注意离子电荷不同不代表位置不同，只要坐标类型一致即可认为位置相同。

代表题精讲

代表题：2020-新课标Ⅱ-11(4)

题目简述：给出组成为 $\mathrm{Pb^{2+}}$、$\mathrm{I^-}$ 和 $\mathrm{CH_3NH_3^+}$ 的立方钙钛矿晶胞，要求指出 $\mathrm{Pb^{2+}}$ 与 $\mathrm{CaTiO_3}$ 晶胞中何种离子空间位置相同、N原子杂化方式、以及用给定晶胞参数 $a\ \mathrm{nm}$ 列出晶体密度计算式。

思路： - 晶胞构型对应：先根据晶胞图示确定离子占据的位置（顶点、体心、面心），再与 $\mathrm{CaTiO_3}$ 中 $\mathrm{Ca^{2+}}$（顶点）、$\mathrm{Ti^{4+}}$（体心）、$\mathrm{O^{2-}}$（面心）的占位模式相比对。 - 杂化判定：$\mathrm{CH_3NH_3^+}$ 中心原子 N 价层电子对 = 4 对成键 + 0 孤 = 4，对应 $\mathrm{sp^3}$。 - 密度推导：$z=1$（1个 $\mathrm{CH_3NH_3PbI_3}$ 单元），体积换算为 $\mathrm{cm^3}$，代入公式即可。

步骤： 1. 观察 $\mathrm{Pb^{2+}}$ 处于晶胞体心（或与卤素八面体配位的中心），与图 (a) 中位于体心的 $\mathrm{Ti^{4+}}$ 空间位置完全相同，故填 Ti$^{4+}$。 2. $\mathrm{N}$ 原子在 $\mathrm{CH_3NH_3^+}$ 中连接 4 个原子，杂化类型为 $\mathrm{sp^3}$。 3. 晶胞内粒子数：$\mathrm{CH_3NH_3^+}$ 1个（顶点），$\mathrm{Pb^{2+}}$ 1个（体心），$\mathrm{I^-}$ 3个（面心 $\times\frac12 = 3$）。化学式为 $\mathrm{CH_3NH_3PbI_3}$，摩尔质量 $M = 620\ \mathrm{g\cdot mol^{-1}}$。 4. $a\ \mathrm{nm} = a \times 10^{-7}\ \mathrm{cm}$，晶胞体积 $V = (a\times10^{-7})^3 = a^3 \times 10^{-21}\ \mathrm{cm^3}$。 5. 密度表达式： $$\rho = \frac{\frac{620}{N_A}\ \mathrm{g}}{a^3 \times 10^{-21}\ \mathrm{cm^3}} = \frac{620}{N_A \cdot a^3} \times 10^{21}\ \mathrm{g\cdot cm^{-3}}$$

点评/变式：此题几乎为晶体结构与密度计算的经典模板。关键点在于：①必须正确识别离子位置对应；②体积单位换算极易出错，许多考生写到 $a^3$ 后就停止；③密度式常以乘 $10^{21}$ 形式出现，要求保持 $N_A$、$a$ 符号而不带入数值。变式中可能会改变离子，或要求晶胞参数以 $\mathrm{pm}$ 给出，务必注意 $10^{-10}\ \mathrm{cm}$ 换算。
