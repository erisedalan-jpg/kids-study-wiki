有机高分子化合物

考点定位

  • 父主题：有机化学
  • 权重 weight：0
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 有机高分子化合物：相对分子质量很大（通常 $10^4$ 以上），由许多重复结构单元（链节）通过共价键连接而成的有机化合物。
  • 常见天然高分子：淀粉、纤维素、蛋白质、天然橡胶等。注意：油脂不是高分子，它是高级脂肪酸甘油酯，相对分子质量一般在 $10^3$ 以下。
  • 常见合成高分子：合成纤维（如涤纶、锦纶）、合成橡胶（如丁苯橡胶）、塑料（如聚乙烯、聚氯乙烯）。合成纤维属于有机高分子材料，不是无机非金属材料。
  • 易混淆物质：光导纤维的主要成分是 $SiO_2$，属于新型无机非金属材料，不是有机高分子。硅单质是良好的半导体材料，可将太阳能转化为电能，用于太阳能电池。
  • 必备常识：医用酒精的浓度（体积分数）是75%，杀菌消毒效果最佳，而非 95%。

解题方法与套路

  1. 绝对化说法警惕法：题干出现“都是”“通常是”“均是”等字眼时，逐项审视有无反例。如“淀粉、纤维素和油脂都属于天然高分子化合物”极易出现非高分子混入高分子的情况。
  2. 物质分类快速检索：面对物质类别选项，立即回想：
  3. 是否为高分子？相对分子质量是否足够大？是否由重复单元构成？
  4. 是天然还是合成？是有机材料还是无机非金属材料？
  5. 常见数据记忆法：对于常识性数据（如医用酒精浓度 75%、太阳能电池材料为晶体硅、光导纤维成分为 $SiO_2$）需准确记忆，勿张冠李戴。
  6. 逐项排除法：先攻克明显错误的选项，缩小选择范围，提高正确率。

高频易错

  • ✘ 误认为油脂是高分子化合物：油脂是甘油三酯，分子量仅几百，不属于高分子。天然高分子只包括淀粉、纤维素、蛋白质等。
  • ✘ 混淆合成纤维与光导纤维：合成纤维是有机高分子（如尼龙、涤纶），光导纤维是无机非金属材料（$SiO_2$），两者材质截然不同。
  • ✘ 医用酒精浓度记错：常用消毒酒精为 75%（体积分数），95% 浓度过高，反而使细菌表面蛋白质迅速凝固形成保护膜，杀菌效果下降。
  • ✘ 硅的用途误区：单质硅常用于太阳能电池（光能→电能），光导纤维利用的是二氧化硅的全反射性质，不能混为一谈；且硅属于半导体材料，不是新型无机非金属材料（该类别常指结构陶瓷、功能陶瓷等，但光导纤维可算作新型无机非金属材料，注意区分单质与化合物）。

代表题精讲

题目（2012·新课标）

判断下列说法是否正确： A．医用酒精的浓度通常是 95%
B．单质硅是将太阳能转化为电能的常用材料
C．淀粉、纤维素和油脂都属于天然高分子化合物
D．合成纤维和光导纤维都是新型无机非金属材料

思路
本题以常见物质的成分、分类及用途为载体，重点考查有机高分子化合物的判断及相关易混概念。可采用逐项分析法，调用记忆中的准确数据与物质类别定义，甄别每个选项的真伪。

步骤
- 选项 A：记忆回顾——医用酒精的消毒最佳浓度为 75%，95% 酒精多用于擦拭紫外线灯或作为燃料。故 A 错。
- 选项 B：硅是半导体，可制成太阳能电池板，实现光电转换，属于常用材料。故 B 正确。
- 选项 C：淀粉和纤维素是天然高分子，但油脂是甘油三酯，分子量不足 1000，不属于高分子化合物。故 C 错。
- 选项 D：合成纤维（如涤纶）属于有机高分子材料；光导纤维主要成分是 $SiO_2$，为新型无机非金属材料。两者性质不同，“都是”一说错误。故 D 错。
综上，正确选项为 B。

点评/变式
本题 3 个错误选项恰好覆盖有机高分子化合物的三大易混点：油脂能否归入高分子（不能）、合成纤维是有机还是无机（有机）、常见浓度记忆（75% 非 95%）。
变式训练：将选项 C 改为“淀粉、纤维素和蛋白质都属于天然高分子化合物”则正确；将 D 改为“光导纤维和石英玻璃的主要成分相同”则正确（都是 $SiO_2$）。考生要善于在做题中归纳“天然高分子家族”，并牢记特例。
