未成对电子数

考点未成对电子数权重6真题数1学科化学父主题物质结构与原子结构

考点定位

  • 父主题：物质结构与原子结构
  • 权重 weight：6
  • 真题数：1；年份跨度：2023–2023
  • 出现题位：选择3
  • 难度分布：中1

知识精要

  • 定义：基态原子中，根据洪特规则（电子在能量相同的轨道上尽可能分占不同轨道且自旋平行），未与其他电子配对的电子称为未成对电子（单电子），其数目即为未成对电子数。
  • 判断依据：写出基态原子（或简单离子）的电子排布式，重点画出价层轨道表示式（轨道框），按洪特规则填充电子，统计自旋平行的单电子数。
  • 主族元素规律（以第二周期为例）：
  • $Li(2s^1)$ → 1 个未成对电子；$Be(2s^2)$ → 0；$B(2s^2 2p^1)$ → 1；$C(2s^2 2p^2)$ → 2；$N(2s^2 2p^3)$ → 3；$O(2s^2 2p^4)$ → 2；$F(2s^2 2p^5)$ → 1；$Ne(2s^2 2p^6)$ → 0。
  • 规律：同一周期，未成对电子数先增后减，$N$ 族（ⅤA）达到最大（$p$ 轨道半充满，3 个单电子）；碳族与氧族未成对电子数均为 2。
  • 过渡元素特点：需考虑 $(n-1)d$ 和 $ns$ 能级，注意 $Cr$（$3d^5 4s^1$）、$Cu$（$3d^{10} 4s^1$）等洪特规则特例，其未成对电子数分别为 6 和 1。
  • 关联考点：未成对电子数常与第一电离能、电负性、杂化方式、磁性等一起出现在比较类选择题中。

解题方法与套路

  1. 写排布：对题目给出的每种原子，写出基态电子排布式（或直接看原子序数，熟悉前四周期即可）。
  2. 画轨道：只画最外层或价层的轨道表示式（主族画 $ns$、$np$ 轨道；过渡元素画 $(n-1)d$、$ns$ 轨道）。
  3. 填电子：按照洪特规则将电子填入等能量轨道，确保尽多分占且自旋平行。
  4. 数单电子：统计轨道中只有一个电子的轨道数目（注意：一个轨道两个电子已配对，不计入）。
  5. 比大小：将各原子的未成对电子数列出，按题目要求排序判断正误。
  6. 跨知识整合：若选项涉及第一电离能、杂化等，结合未成对电子数与稳定结构（半满、全满）快速排除错误选项。

高频易错

  • 氧原子的未成对电子数误判：$O$ 的 $2p$ 轨道有 4 个电子，按洪特规则，三轨道先各占 1 个电子（3 个单电子），第 4 个电子与其中一个配对，最终单电子数为 2，而非 3 或 0。学生常与 $N(3个)$混淆，误以为 $O$ 更多。
  • 忽略同周期“双峰”规律：$C$ 和 $O$ 的未成对电子数均为 2，大小关系为 $B(1)<C(2)=O(2)<N(3)$，错写成 $B<C<O<N$ 就会失分。
  • 特殊电子构型干扰：$N$ 的 $2p^3$ 半充满结构稳定，第一电离能反常（$C<O<N$），但其未成对电子数依然按照排布规则为 3，即电离能顺序与未成对电子数顺序并非完全同步。
  • 离子与原子混淆：命题可能给出离子（如 $Fe^{2+}$ 与 $Fe^{3+}$），判断未成对电子数需先重新写离子排布（$Fe^{2+}$：$3d^6$，未成对电子数 4；$Fe^{3+}$：$3d^5$，未成对电子数 5）。
  • 过渡元素 3d 与 4s 排布次序：书写电子排布式时，$4s$ 先填但失电子时先失去 $4s$ 电子，判断未成对电子数时应以基态中性原子的正确排布为准。

代表题精讲

题目：2023·新课标卷·第3题（选项C为未成对电子数比较）

一种吸附材料的化学式为 $[(C(NH_2)_3)_2][B(OCH_3)_4]Cl$，部分晶体结构如图（略）。选项为： A. 晶体中存在 $N-H\cdots O$ 氢键
B. 基态原子第一电离能：$C<N<O$
C. 基态原子未成对电子数：$B<C<O<N$
D. 晶体中 B、N、O 原子轨道的杂化类型相同

思路：

聚焦选项 C，快速写出 B、C、O、N 四种原子的基态价层电子排布，画出 $2p$ 轨道框，填入电子，数出未成对电子数，再与选项顺序比对。

步骤：

  1. $B$：$1s^2 2s^2 2p^1$ → $2p$ 轨道上有 1 个单电子 → 未成对电子数=1。
  2. $C$：$1s^2 2s^2 2p^2$ → $2p$ 三轨道先分占两个（2 个单电子） → 未成对电子数=2。
  3. $N$：$1s^2 2s^2 2p^3$ → $2p$ 三轨道各占一个（3 个单电子） → 未成对电子数=3。
  4. $O$：$1s^2 2s^2 2p^4$ → $2p$ 三轨道先各占 1 个（3 个单电子），第 4 个电子与其中一个配对，剩下 2 个单电子 → 未成对电子数=2。
  5. 比较大小：$B(1) < C(2)=O(2) < N(3)$，而选项写的是 $B<C<O<N$，错误。因 $C$ 与 $O$ 相等，严格大小关系不成立。

点评/变式：

  • 陷阱：命题人故意将 $O$ 放在 $C$ 和 $N$ 之间，形似递增，实则 $C$ 和 $O$ 数目相等。仅凭通常的“非金属性增强”或“原子序数增大”的直觉容易误判。
  • 变式一：比较 $F$、$Ne$ 加入后的顺序：$F$ 为 1，$Ne$ 为 0。则完整顺序为 $Ne<B=F<C=O<N$。
  • 变式二：结合第一电离能，该题 B 项表述 $C<N<O$ 实为 $C<O<N$，亦考查半充满稳定性，两处均是高频对比点。复习时应将同周期未成对电子数与第一电离能做捆绑对比记忆。
