知识精要

  • 基态原子核外电子排布规则
    能量最低原理、泡利不相容原理、洪特规则（电子在等价轨道上分布时，总是尽可能分占不同轨道且自旋平行）。

  • 电子排布式的书写
    按构造原理填充电子，但书写时仍按电子层顺序排列。例如 $\mathrm{Fe}$（原子序数 $26$）：$1s^{2}2s^{2}2p^{6}3s^{2}3p^{6}3d^{6}4s^{2}$ 或 $[\mathrm{Ar}]3d^{6}4s^{2}$。
    价电子排布式（价层电子排布）指参与化学反应的电子，对主族元素为最外层电子，对过渡元素一般包括最外层 $s$ 电子和次外层 $d$ 电子。
    轨道表示式（电子排布图）需用方框或圆圈表示轨道，用 $\uparrow$、$\downarrow$ 表示电子自旋。如基态 $\mathrm{Fe}$ 原子价层轨道表示式：
    3d：$\boxed{\uparrow\downarrow}\,\boxed{\uparrow}\,\boxed{\uparrow}\,\boxed{\uparrow}\,\boxed{\uparrow}$，4s：$\boxed{\uparrow\downarrow}$。

  • 能级与能量
    多电子原子中，$E_{ns}<E_{np}<E_{nd}<E_{nf}$，但出现能级交错（如 $E_{4s}<E_{3d}$，填充时先填 $4s$ 后填 $3d$）。注意：填充电子时 $4s$ 能量低于 $3d$，而失去电子时 $4s$ 能级上的电子优先于 $3d$ 失去（形成离子时，如 $\mathrm{Fe}^{2+}$：$[\mathrm{Ar}]3d^{6}$）。
    最高能级指电子最后填充的能级，如基态 $\mathrm{S}$ 原子电子排布 $1s^{2}2s^{2}2p^{6}3s^{2}3p^{4}$，最高能级为 $3p$，电子云轮廓图为哑铃形。

  • 电负性与原子对键合电子的吸引力
    电负性越大，原子吸引键合电子的能力越强。同周期从左到右电负性增大（${19}\mathrm{K} < $），电离能总体增大但具波动性。}\mathrm{Cr

  • 原子结构与元素推断
    依据核外电子层结构（如内层电子数、价电子数）推断短周期元素位置。 阴离子核外电子数与相邻原子的内层电子数相等，可用于锁定元素。例如 $W^-$ 电子数为 2，则 $W$ 为氢，X、Y、Z 内层电子数为 2（均为第二周期元素）。同位素在考古中的应用（$^{14}\mathrm{C}$）可推断 X 为碳。

  • 原子半径与金属原子空间占有率
    金属晶体中原子的空间占有率 = （晶胞内原子总体积）/ 晶胞体积 × 100%。体心四方结构：体心原子和顶角原子种类需根据半径信息或原子个数比确定。

解题方法与套路

  1. 核外电子排布的书写步骤
  2. 由原子序数确定电子总数，依据能量最低原理按 $1s, 2s, 2p, 3s, 3p, 4s, 3d, 4p$ 顺序填充。
  3. 检查全满、半满稳定结构，写出正确的电子排布式，再按层序改写为简化形式。
  4. 书写价层电子时，主族取最外层 $s、p$ 电子，副族及Ⅷ族取 $(n-1)d$ 与 $ns$ 电子。

  5. 画轨道表示式时必须体现洪特规则（分占且同向自旋）。

  6. 比较微粒结构或性质的常见角度

  7. 电子能量与运动区域：不同能级的电子能量不同，但电子云无明确分界，“离核更远”仅对应概率分布，不可绝对化。
  8. 电负性、电离能大小：同周期从左到右增大，同族从上到下减小，注意特殊情况（如 ${\mathrm{N}} > {$ 因半充满稳定）。 }}

  9. 熔沸点比较：分子晶体主要看相对分子质量和分子间作用力（含氢键时优先考虑氢键）。

  10. 由电子排布推断元素的方法

  11. 根据内层电子数、电子排布特征（如“最外层电子数”“p 轨道电子数”等）列式推算。
  12. 结合原子序数递增、原子半径变化、常见同位素用途等锁定元素。

  13. 写出电子排布式或轨道表示式进行验证。

  14. 晶胞空间占有率的计算套路

  15. 确定晶胞类型及所含原子个数（如体心四方：顶点原子 ×1/8 + 体心原子 ×1）。
  16. 列出原子体积总和（$N \times \frac{4}{3}\pi r^3$）和晶胞体积（由晶胞参数或原子半径关系表达）。
  17. 代入公式求百分率，注意单位统一，结果保留表达式或计算值。

高频易错

  • 忽略半满/全满稳定结构：如 $\mathrm{Cr}$、$\mathrm{Cu}$ 的排布易写成 $3d^{4}4s^{2}$、$3d^{9}4s^{2}$，应强化特例记忆。
  • 混淆填充与失电子顺序：原子中电子填充时 $4s$ 先于 $3d$，而失去电子时 $4s$ 上的电子比 $3d$ 上的电子更易失去。
  • 轨道表示式中违反洪特规则：在 $p$、$d$ 轨道上画电子对前未先分占各轨道，或自旋方向不一致。
  • 不能准确识别“最高能级”：基态S原子最后填充在 $3p$，最高能级为 $3p$，而非 $3s$ 或 $2p$，电子云轮廓图要对应其轨道形状。
  • 电负性与原子得电子能力混淆：电负性高表示吸引键合电子能力大，而非简单得电子能力强，需注意语境。
  • 元素推断中对内层电子数理解错误：内层电子数指原子核外除最外层外的电子总数，不能与离子的电子层结构混淆。
  • 晶胞空间占有率计算中原子位置判断失误：顶点与体心位置需结合化学式、原子个数比或原子半径特征分析，不能想当然。

思路
(1) 基态 $\mathrm{Cr}$ 电子排布用洪特规则特例；从电子云概念判断运动区域；用电负性比较与钾的差异。(2) 配位键形成原子需有孤电子对；配位数是中心离子周围配位原子的总数。(3) 根据 $\mathrm{PH}_3$ 成键和孤电子对数目判断杂化；沸点比较考虑氢键；键角差异考虑孤电子对−成键电子对排斥。(4) 根据晶胞顶点和体心原子个数与化学式关系推断原子种类；空间占有率以晶胞原子总体积除以晶胞体积。
