知识精要

气体制备是化学实验的核心内容之一，其装置设计遵循 “发生 → 净化 → 收集 → 尾气处理” 的基本流程。
- 发生装置：依据反应物状态与反应条件选择。
- 固+固加热（如 $O_2$：$KClO_3$/ $MnO_2$、$KMnO_4$）：大试管口略向下倾斜，防止冷凝水回流炸裂。
- 固+液不加热（如 $H_2$、$CO_2$、$H_2S$）：启普发生器或其简易替代装置，可控制反应启停；用长颈漏斗时下端必须液封。
- 固+液或液+液加热（如 $Cl_2$、$HCl$、$C_2H_4$）：烧瓶+分液漏斗，温度计位置（液面下或支管口）视反应而定。
- 净化（除杂）与干燥：先除杂后干燥，杂质分析要结合反应原理。常见洗气瓶、干燥管，液态干燥剂（浓 $H_2SO_4$→酸性、氧化性气体）、固态干燥剂（$CaCl_2$→中性、不可干燥 $NH_3$；碱石灰→干燥碱性气体）、固体干燥管“大进小出”。
- 收集方法：
- 排水法：气体不溶于水且不与水反应（如 $H_2$、$O_2$、$CH_4$）。
- 向上排空气法：密度大于空气（如 $Cl_2$、$CO_2$）。
- 向下排空气法：密度小于空气（如 $NH_3$、$H_2$）。
- 排饱和溶液法：如 $Cl_2$（排饱和食盐水）、$CO_2$（排饱和 $NaHCO_3$）。
- 尾气处理：有毒、有害气体必须处理。易溶液体吸收（$HCl$、$NH_3$→水，但须防倒吸，如倒置漏斗、安全瓶）；可燃气体可点燃；氧化性或酸性气体可用碱液吸收。
- 气密性检查：核心是形成封闭体系，改变压强观察现象（微热法、液差法）。

解题方法与套路

  1. 明确目标气体→依据反应原理确定反应物状态、条件，选出发生装置。
  2. 分析气体所含杂质→由反应物会挥发、副反应或反应不充分产生，制定除杂方案（注意除杂顺序，如先除 $HCl$ 再干燥），并选对试剂和装置（洗气瓶“长进短出”，干燥管“粗进细出”）。
  3. 根据气体性质→选择收集方法及验满方法。
  4. 尾气判断→有毒性或污染性气体必须处理，设计对应处理装置并防倒吸。
  5. 仪器连接顺序：发生→净化→干燥→主体反应（如有）→产物收集或保护装置→尾气处理。整体检验气密性。
  6. 装置评价：从反应控制、安全（防堵塞、防倒吸）、环保、产率、纯度等角度对比改进。

每道装置题均按“杂质—净化—收集—尾气”四步逻辑链快速拆解。

高频易错

  • 长颈漏斗下端未插入液面以下→气体逸出，需液封。
  • 排水法收集气体时，未待气泡连续均匀冒出再收集→混入空气，导致纯度低。
  • 干燥管方向装反→气流走向“粗进细出”，装反可能导致粉末堵塞或干燥失控。
  • 气体除杂顺序错误→如 $CO_2$ 中混有 $HCl$ 和水蒸气，应先除 $HCl$ 后除水，除 $HCl$ 用饱和 $NaHCO_3$，不可用 $Na_2CO_3$（会与 $CO_2$ 反应）。
  • 尾气处理装置未考虑防倒吸→直接将导管插入液面下，溶液易倒吸入反应装置；需加安全瓶或倒置漏斗。
  • 制取并用排水法收集 $H_2$ 或 $O_2$ 时，实验结束先撤酒精灯后移导管→冷水倒吸，试管炸裂。
  • 除杂试剂选择导致新杂质→如干燥 $NH_3$ 用浓 $H_2SO_4$ 会反应，只能用碱石灰；$Cl_2$ 用碱石灰干燥会反应，应用浓硫酸。
  • 装置连接导管直接插入液体吸收尾气，忽视防倒吸。

代表题精讲

题目（2021全国乙卷类典型装置题模拟）：实验室用 $MnO_2$ 与浓盐酸加热制备纯净干燥的 $Cl_2$，并验证其氧化性。请连接仪器装置。

思路：
先分析杂质：浓盐酸会挥发 $HCl$，且气体带水蒸气。需依次用饱和食盐水除 $HCl$、浓硫酸干燥。收集用向上排空气法，尾气用 $NaOH$ 溶液吸收，并考虑防倒吸。

步骤：
发生装置（烧瓶+分液漏斗+酒精灯）→饱和食盐水洗气瓶（长进短出）→浓硫酸洗气瓶→主体反应管→向上排空气法集气瓶（导管伸入集气瓶底部）→尾气用倒置漏斗接入 $NaOH$ 溶液。

点评/变式：
若验证漂白性，则需先干燥后通过干布条再湿布条。常见变式：改用 $KMnO_4$ 与浓盐酸不加热制备 $Cl_2$，则发生装置变为固液不加热，简化控制。装置连接的核心是明确每一步的作用并牢记“长进短出”的洗气瓶规则。
