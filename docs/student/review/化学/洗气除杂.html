知识精要

洗气除杂是利用气体混合物中各组分与液体吸收剂（或固体吸收剂）反应或溶解能力的差异，在洗气装置中将杂质气体吸收，从而获得纯净目标气体的操作方法。核心装置为洗气瓶（广口瓶配双孔塞），也可用U形管、干燥管等。

1. 装置结构
- 洗气瓶：导气管“长进短出”（进气导管长，伸入液面以下；出气导管短，刚露出塞下沿即可）。
- 若用干燥管或U形管装固体吸收剂，气流方向为“大进小出”以避免堵塞。

2. 吸收剂选择原则
- 吸收剂只能与杂质气体反应，不能与目标气体反应，也不能引入新气体杂质。
- 溶解度较大的气体常用水或溶液吸收；酸性气体用碱液或碱石灰等；还原性气体用氧化性溶液（如 $SO_2$ 可用酸性 $KMnO_4$ 溶液）；水蒸气用浓硫酸、氯化钙、碱石灰等干燥剂。

3. 常见除杂实例
- 除去 $CO$ 中的 $CO_2$：用 $NaOH$ 溶液，洗气瓶长进短出。
- 除去 $CO_2$ 中的 $HCl$：用饱和 $NaHCO_3$ 溶液，不可用 $Na_2CO_3$（会吸收 $CO_2$）。
- 除去 $Cl_2$ 中的 $HCl$：用饱和食盐水。
- 气体干燥：酸性干燥剂（浓 $H_2SO_4$、$P_2O_5$）不可干燥碱性气体 $NH_3$；碱性干燥剂（碱石灰）不可干燥酸性气体 $CO_2$、$SO_2$、$Cl_2$ 等。

4. 使用条件与注意
- 洗气瓶内液体量不超过容积的 $\frac{2}{3}$，进气需先经过除杂再干燥，最后收集。
- 加热条件下某些反应可提高吸收效率，但需注意装置末端可能需加防倒吸措施。

解题方法与套路

评价洗气除杂装置正误的通用步骤

  1. 看装置连接
  2. 检查导气管方向：洗气瓶必须是“长进短出”，进气导管插入液面下，出气导管不接触液体。

  3. 若为固体吸收，干燥管、U形管需注意大管口进气。

  4. 看吸收剂选择

  5. 判断目标气体与杂质气体的化学性质，所选吸收剂必须能与杂质反应（或溶解），且不与目标气体反应。

  6. 特别注意可能产生的二次杂质（如用挥发性酸吸收可能引入酸蒸气）。

  7. 看装置的适用性

  8. 若杂质与目标气体常温不反应，洗气法适用；若需加热反应，应选择硬质玻璃管或U形管配合加热装置，而非普通洗气瓶。

  9. 考虑是否会造成气体滞留、倒吸或爆炸隐患。

  10. 综合判断

  11. 将以上检查结果对照选项描述，判断装置图或操作是否正确。排除明显错误（如导管接反、溶液错误、加热方向错等）后确定答案。

高频易错

  • 导管长短不分：洗气瓶进气与出气接反，气体会将液体压出或无法有效吸收。
  • 吸收剂错误：
  • 除去 $CO_2$ 中的 $HCl$ 误用 $NaOH$ 溶液，导致目标气体也被吸收。
  • 干燥 $NH_3$ 误用浓硫酸或氯化钙（会反应）。
  • 忽略气体先后顺序：洗气与干燥同时进行时，干燥装置应放在最后，否则干燥后气体流经水溶液又会带出水蒸气。
  • 洗气瓶代替其他装置：洗气瓶不能用于加热条件下的气-固除杂反应，也不适用于冷凝回流。
  • 固体吸收剂方向：球形干燥管、U形管装固体颗粒时，气流应从大口进、小口出，接反易堵塞或压差过大。

代表题精讲

题目：2014年新课标Ⅱ卷理综第4题C选项——除去CO气体中的CO2气体（装置示意图：洗气瓶内装NaOH溶液，导气管长进短出）。判断图示实验是否正确。

思路
该装置为典型的洗气除杂，需从吸收剂选择和导管连接方式两方面审查。CO为中性难溶性气体，不与NaOH反应；CO2为酸性气体，可与NaOH溶液反应生成碳酸钠而被吸收。进气导管长管伸入液面下，出气导管短管位于液面上方，符合长进短出原则，能够实现“杂质气体被溶液吸收，目标气体逸出”的效果。

步骤
1. 分析目标气体与杂质：要除去CO中的CO2。
2. 原理可行性：$CO_2 + 2NaOH = Na_2CO_3 + H_2O$，CO不反应，可被除去。
3. 装置验证：洗气瓶结构正确，导管长进短出，液体量适中，无加热需求，装置简单可行。
4. 结论：该操作正确。

点评/变式
此题中D选项是乙酸乙酯制备演示实验，导管末端误插入了饱和碳酸钠溶液液面以下，会引起倒吸。E选项类似陷阱可将洗气瓶与防倒吸装置结合考查。常见变式：除去CO2中的CO通常不用洗气法，需将混合气通过灼热CuO粉末，这体现了除杂方法的选择与物质性质直接相关。学习中务必牢记“气体除杂四要素”：不消耗主气、不引入新杂、装置得当、顺序合理。
