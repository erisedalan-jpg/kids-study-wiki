消去反应

考点消去反应权重11真题数2学科化学父主题反应类型与基本反应

考点定位

  • 父主题：反应类型与基本反应
  • 权重 weight：11
  • 真题数：2；年份跨度：2010–2020
  • 出现题位：选择3 选择4
  • 难度分布：中1 易1

知识精要

消去反应是指有机化合物分子中脱去小分子（如 $\ce{H2O}$、$\ce{HX}$ 等）并生成不饱和键（碳碳双键或碳碳三键）的反应。本质是从相邻的两个碳原子上分别脱去原子或原子团，形成 $\pi$ 键。

主要类型与条件 - 卤代烃消去：强碱的醇溶液共热，脱 $\ce{HX}$，生成烯烃或炔烃。
$$\ce{R-CH2-CH2-X + NaOH ->[\text{醇}][\Delta] R-CH=CH2 + NaX + H2O}$$ - 醇消去（分子内脱水）：浓硫酸作催化剂和脱水剂，加热至一定温度（如乙醇在 $170\ \mathrm{^\circ C}$ 下分子内脱水生成乙烯）。
$$\ce{CH3CH2OH ->[\text{浓硫酸}][170\ \mathrm{^\circ C}] CH2=CH2 ^ + H2O}$$

适用条件与规律 - 与羟基或卤原子相连的碳为 $\alpha\text{-C}$，相邻碳为 $\beta\text{-C}$。发生消去反应必须存在 $\beta\text{-H}$。 - 若分子中存在多个 $\beta\text{-H}$，消去反应有取向（遵循扎依采夫规则，主产物为双键碳上取代基较多的烯烃）。 - 不同温度下路径不同：例如乙醇在浓硫酸、$140\ \mathrm{^\circ C}$ 时发生取代生成乙醚，在 $170\ \mathrm{^\circ C}$ 时发生消去生成乙烯。

解题方法与套路

  1. 官能团变化识别法
    观察反应物与产物：若反应物含羟基（$\ce{-OH}$）或卤素（$\ce{-X}$），产物中出现碳碳双键或三键，且同时少了 $\ce{H2O}$ 或 $\ce{HX}$，则通常为消去反应。
  2. 反应条件关联法
  3. 条件为“$\ce{NaOH}$ 醇溶液，加热”→ 卤代烃消去。
  4. 条件为“浓 $\ce{H2SO4}$，加热（$170\ \mathrm{^\circ C}$）”→ 醇消去。
  5. 对比：若为“$\ce{NaOH}$ 水溶液，加热”→ 卤代烃水解（取代）；醇与浓硫酸在 $140\ \mathrm{^\circ C}$ → 酯化或成醚（取代）。
  6. 排除陷阱法
  7. 检查是否有 $\beta\text{-H}$，没有则不能消去（如 $\ce{CH3OH}$ 不能发生消去）。
  8. 区分“消去”与“加成”“取代”：加成是不饱和键变饱和，取代是官能团互换但碳骨架不饱和度不变。
  9. 选项对比筛选法
    面对类似“同系物”“同分异构体”“反应类型”的判断，先锁定目标反应，用前述方法判定其类型，再与选项逐一比对，快速排除错误项（如2020年真题先确定 VPy 合成中反应②是醇消去，直接断定D正确）。

高频易错

  • 消去与取代的混淆
    卤代烃在 $\ce{NaOH}$ 水溶液中水解（取代），在醇溶液中消去。醇在浓硫酸、不同温度下路径不同。考题常将两者条件颠倒作为干扰项。
  • 忽视 $\beta\text{-H}$ 的存在
    不是所有醇或卤代烃都能消去。如 $\ce{CH3Cl}$、$\ce{CH3OH}$ 无 $\beta\text{-H}$，不能发生消去反应。判断反应能否发生是隐含考点。
  • 误判同系物与同分异构体
    含杂原子（如N）或环状结构的有机物，易被错误类比为同系物。如2020年题中 VPy 含氮杂环，与乙烯结构不相似，不是同系物。
  • 共面问题与消去反应判断混淆
    消去产物常含碳碳双键，双键碳为平面结构，但若分子中有饱和碳（四面体构型），则所有原子不可能共面，需区分局部共面与整体共面。
  • 漏看消去反应产物中的小分子
    书写消去反应时忘记生成的小分子（如 $\ce{H2O}$、$\ce{HBr}$）或配平，导致后续类型判断错误。

代表题精讲

1. 2020-新课标Ⅱ-04

题目
合成 2-乙烯基吡啶（VPy）的路线中，给出了 MPy、EPy 等中间体，要求选择正确叙述。

思路
从结构简式看，EPy 含有醇羟基（侧链有 $\ce{-CH(OH)-}$ 结构），VPy 侧链出现碳碳双键（$\ce{-CH=CH2}$），反应②是 EPy → VPy，脱去一分子水，符合醇消去特征。同时利用已知信息快速判断其他选项的正误。

步骤
1. 锁定反应②：反应物 EPy 含 $\ce{-OH}$，产物 VPy 含 $\ce{C=C}$，且反应条件隐含脱水，判定为消去反应，故 D 正确。
2. 验证 A：MPy 的芳香同分异构体可写出邻、间、对甲基吡啶以及氨基苯等，超过两种，A 错。
3. 验证 B：EPy 侧链有两个饱和碳原子，四面体结构导致所有原子不可能共面，B 错。
4. 验证 C：VPy 含有吡啶环和 $\ce{-CH=CH2}$，与乙烯（$\ce{C2H4}$）结构通式不同，且含 N 原子，不是同系物，C 错。

点评/变式
本题将消去反应识别隐藏在合成路线中，要求基于官能团变化快速判断。易错点在于误以为含双键的分子全部原子共面，或忽略杂原子导致同系物错误。变式可改为判断反应①或反应③的类型，或要求设计其他消去路线。

2. 2010-新课标-03

题目
判断下列各组化学反应是否属于同一反应类型：
A. 溴丙烷水解制丙醇；丙烯与水制丙醇
B. 甲苯硝化制对硝基甲苯；甲苯氧化制苯甲酸
C. 氯代环己烷消去制环己烯；丙烯加溴制1,2-二溴丙烷
D. 乙酸和乙醇制乙酸乙酯；苯甲酸乙酯水解制苯甲酸和乙醇

思路
逐一判定每个反应的类型，关注官能团变化与反应条件。消去反应典型特征是生成不饱和键并脱去小分子。

步骤
1. A 组：溴丙烷水解是取代（卤代烃水解）；丙烯与水加成是加成反应。类型不同。
2. B 组：甲苯硝化是取代（苯环上的亲电取代）；氧化制苯甲酸是氧化反应。类型不同。
3. C 组：氯代环己烷消去生成环己烯，是消去反应；丙烯加溴生成二溴丙烷，是加成反应。类型不同。
4. D 组：酯化反应和酯的水解反应，均属于取代反应。类型相同，故选 D。

点评/变式
本题横向对比了消去、加成、取代、氧化等基本反应类型。消去反应出现在 C 组第一反应，典型特征为卤代烃在强碱醇溶液中脱 $\ce{HCl}$。易错点在于将消去与加成混淆，或对酯化与水解归为同一大类取代反应认识不清。变式可给出更复杂的有机分子，要求学生判断类似多步转化中是否有消去步骤。
