温室气体

考点温室气体权重5真题数1学科化学父主题工艺流程

考点定位

  • 父主题：工艺流程
  • 权重 weight：5
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 温室气体：能吸收地面长波辐射并重新向地面发射，导致温室效应的气体。主要包括 $\mathrm{CO_2}$（最主要）、$\mathrm{CH_4}$、$\mathrm{N_2O}$、$\mathrm{O_3}$、氯氟烃及水蒸气等。$\mathrm{CO_2}$ 来源于化石燃料（煤、石油、天然气）的燃烧、动植物呼吸、火山喷发等。
  • 化石燃料燃烧的环境影响：
  • 完全燃烧：碳→$\mathrm{CO_2}$，氢→$\mathrm{H_2O}$。但即使完全燃烧，若燃料含硫、氮等杂质，仍会产生 $\mathrm{SO_2}$、$\mathrm{NO}_x$ 等有毒有害气体，排放颗粒物（灰尘），造成酸雨、雾霾等大气污染。
  • 不完全燃烧：生成 $\mathrm{CO}$（有毒气体）和炭黑颗粒，$\mathrm{CO}$ 是大气污染物之一，能与血液中血红蛋白结合导致人体中毒。
  • 清洁燃料与替代能源：
  • 液化石油气（LPG）主要成分为丙烷、丁烷等低碳烃，含硫、氮等杂质少，燃烧更充分，污染物（$\mathrm{CO}$、$\mathrm{SO}_2$ 等）排放量较低，可减少大气污染。
  • 以气体燃料或低硫轻质油代替重油、煤炭，是减少污染的措施之一。

解题方法与套路

  1. 逐项甄别法：针对“说法错误（或正确）”的单选题，逐一阅读选项，标记“绝对化”用语（如“完全”“一定”），思考是否存在反例。
  2. 精准关联考点：见到 $\mathrm{CO_2}$ 立即关联“温室效应气体”；见到 $\mathrm{CO}$ 关联“有毒大气污染物”“不完全燃烧产物”；见到“化石燃料完全燃烧无污染”立即检索杂质（S、N等）转化的知识。
  3. 对比选项，锁定正误：常见陷阱是将“减少污染”曲解为“无污染”，或将“主要产物 $\mathrm{CO_2}$”默认无污染。需明确：完全燃烧≠零污染。
  4. 正向验证 + 反向排除：对每个选项的结论给出化学理由，若一项明显与常识或课本结论相悖，即为答案；同时确认其他选项均有确切依据，确保不误判。

高频易错

  • “完全燃烧就不会造成大气污染”：错误根源在于忽略化石燃料中的杂质（如硫、重金属、氮化物），燃烧会生成 $\mathrm{SO_2}$、$\mathrm{NO}_x$ 及飞灰，造成酸雨和颗粒物污染。$\mathrm{CO_2}$ 虽无毒，但过量排放引发温室效应，也属全球性环境问题。
  • 混淆 $\mathrm{CO_2}$ 与 $\mathrm{CO}$ 的性质：$\mathrm{CO_2}$ 无毒但不是大气污染物中的有毒气体，而 $\mathrm{CO}$ 是剧毒大气污染物。不要看到“碳的氧化物”就一概而论。
  • 对“减少污染”和“无污染”区分不清：液化石油气代替燃油可“减少”$\mathrm{CO}$、$\mathrm{SO_2}$ 的排放，但并不意味着零排放。题干中若出现“减少大气污染”等谨慎表述，通常为正确选项。
  • 概念标签辨析：环境问题术语（温室效应、酸雨、光化学烟雾）与对应气体要一一对应，不能张冠李戴。

代表题精讲

题目（2016·新课标Ⅱ）
下列关于燃料的说法错误的是
A．燃料燃烧产物 $\mathrm{CO_2}$ 是温室气体之一
B．化石燃料完全燃烧不会造成大气污染
C．以液化石油气代替燃油可减少大气污染
D．燃料不完全燃烧排放的 $\mathrm{CO}$ 是大气污染物之一

思路
本题为典型的“化学与环境”选择题，需用燃料燃烧产物及污染物的基础知识逐项判断。关键在于识别B选项的绝对化表述“完全燃烧不会造成大气污染”是否成立。从化石燃料的组成（含S、N等）出发，即便完全燃烧也会生成 $\mathrm{SO_2}$ 等污染物；其余三个选项均为教材明确结论，据此可快速锁定错误选项。

步骤
1. 审查A项：$\mathrm{CO_2}$ 是公认的温室气体，A正确。
2. 审查B项：化石燃料除C、H外通常含S、N等杂质，完全燃烧会生成 $\mathrm{SO_2}$、$\mathrm{NO}_x$，还会产生灰尘，这些仍会造成大气污染（如酸雨、雾霾），因此“不会造成大气污染”说法错误。
3. 审查C项：液化石油气杂质少、燃烧效率高，尾气中有害成分（尤其是CO和硫氧化物）含量低于普通燃油，可减少大气污染，C正确。
4. 审查D项：$\mathrm{CO}$ 是燃料不完全燃烧的典型产物，有剧毒，属于大气污染物，D正确。
5. 综合判断：错误选项为B。

点评/变式
该题看似简单，实则集中考查了学生容易混淆的两个观念：①完全燃烧与污染的关系；②不同碳氧化物的环境角色。考试中可将“完全燃烧”偷换为“充分燃烧”或“高效燃烧”，同样需注意杂质问题。变式训练：如将选项改为“使用清洁能源（如氢气）可实现零碳排放”（×，氢气本身无碳，但制氢过程可能有碳排放），或“乙醇汽油燃烧不产生 $\mathrm{CO}$”（×，任何碳氢燃料不完全燃烧都可能产生 $\mathrm{CO}$），可继续考察对燃烧本质与环境影响的理解。
