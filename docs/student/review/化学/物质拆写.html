物质拆写

考点定位

  • 父主题：基本概念与物理量
  • 权重 weight：5
  • 真题数：1；年份跨度：2013–2013
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 拆写原则：书写离子方程式时，只有同时满足“易溶”与“完全电离”的物质才拆成离子形式，其余一律保留化学式。
  • 必拆物质
  • 强酸：$HCl, H_{2}SO_{4}（稀）, HNO_{3}, HBr, HI, HClO_{4}$
  • 强碱：$NaOH, KOH, Ca(OH){2}$（澄清石灰水时拆，石灰乳/悬浊液不拆）、$Ba(OH)$
  • 可溶性盐：绝大多数钾盐、钠盐、铵盐、硝酸盐及不生成沉淀的常见盐。
  • 不可拆物质
  • 弱电解质：弱酸（$HF, CH_{3}COOH, H_{2}CO_{3}, H_{2}SO_{3}, HClO$等）、弱碱（$NH_{3}\cdot H_{2}O$）、水
  • 难溶物：沉淀（$CaCO_{3}, BaSO_{4}, AgCl, Fe(OH){3}, Cu(OH)$等）
  • 气体：$CO_{2}, SO_{2}, NH_{3}, H_{2}S$ 等
  • 单质与氧化物：$Fe, Cu, Na, Fe_{2}O_{3}, CO_{2}$ 等
  • 特殊情形
  • 微溶物：作为反应物，若为澄清溶液则拆（如澄清石灰水写 $Ca^{2+}$ + $2OH^{-}$），若为浑浊则写化学式 $Ca(OH)_{2}$；作为生成物一律写化学式并标“↓”。
  • 浓硫酸：不拆，写分子式 $H_{2}SO_{4}$。
  • 酸式盐：强酸的酸式盐完全电离并拆成阳离子、$H^{+}$ 和酸根离子（如 $NaHSO_{4}$ 拆为 $Na^{+}$ + $H^{+}$ + $SO_{4}^{2-}$）；弱酸的酸式盐中酸式酸根离子不拆（如 $NaHCO_{3}$ 拆为 $Na^{+}$ + $HCO_{3}^{-}$）。

解题方法与套路

  1. 明确反应实质与环境：审题确定反应物在何种条件下反应（溶液、熔融、浓/稀酸），写出正确的化学方程式。
  2. 标出各物质状态与类别：将化学方程式中每种物质判断为“可溶强电解质”“难溶物”“弱电解质”“气体”“氧化物/单质”等。
  3. 拆写可溶强电解质：强酸、强碱、可溶性盐拆成自由离子。微溶物视溶液状况决定是否拆。
  4. 保留其余物质：弱酸、弱碱、水、沉淀、气体、单质、氧化物及浓硫酸等保留分子式。
  5. 删去不参与反应的离子：即划掉方程式两边完全相同的离子，确保只剩下实际发生变化的微粒。
  6. 三守恒检查：
  7. 质量守恒（原子种类与个数）
  8. 电荷守恒（两边净电荷代数和相等）
  9. 电子守恒（氧化还原反应中电子转移数匹配）
  10. 最后确认：生成物是否漏标“↓”“↑”，沉淀是否为难溶物质，气体是否合理。

高频易错

  • 醋酸/氨水乱拆：$CH_{3}COOH$、$NH_{3}\cdot H_{2}O$ 是弱电解质，必须写分子式，不能拆成 $H^{+}$+$CH_{3}COO^{-}$ 或 $NH_{4}^{+}$+$OH^{-}$。
  • 石灰石/大理石等碳酸钙拆错：$CaCO_{3}$ 是难溶盐，与酸反应必须保留 $CaCO_{3}$。
  • 碳酸氢根随意拆成 $CO_{3}^{2-}$：$HCO_{3}^{-}$ 是弱酸酸式根，不可再拆，只能整体保留或与 $H^{+}$ 作用。
  • 浓硫酸当作稀酸拆：浓硫酸中硫酸主要以分子存在，写 $H_{2}SO_{4}$；而浓盐酸、浓硝酸仍为强酸，应拆写。
  • 生成物微溶物缺失沉淀符号：如生成 $CaSO_{4}$、$Ag_{2}SO_{4}$ 或 $MgCO_{3}$ 等微溶物，当浓度较大时会沉淀，须标“↓”。
  • 铁与稀盐酸/稀硫酸产物错误：生成 $Fe^{2+}$ 而非 $Fe^{3+}$，离子式应为 $Fe + 2H^{+} = Fe^{2+} + H_{2}\uparrow$。
  • 钠投入盐溶液忽略与水反应：$Na$ 先与 $H_{2}O$ 反应生成 $NaOH$ 和 $H_{2}$，再考虑盐与 $NaOH$ 的反应，不可直接写 $Na$ 置换金属。

代表题精讲

代表题1：2013-新课标Ⅱ-04

题目
能正确表示下列反应的离子方程式是（ ）
A. 浓盐酸与铁屑反应：$2Fe + 6H^{+} = 2Fe^{3+} + 3H_{2}\uparrow$
B. 钠与硫酸铜溶液反应：$2Na + Cu^{2+} = Cu\downarrow + 2Na^{+}$
C. $NaHCO_{3}$ 溶液与稀 $H_{2}SO_{4}$ 反应：$CO_{3}^{2-} + 2H^{+} = H_{2}O + CO_{2}\uparrow$
D. 向 $FeCl_{3}$ 溶液中加入 $Mg(OH){2}$：$3Mg(OH)$} + 2Fe^{3+} = 2Fe(OH)_{3} + 3Mg^{2+

思路
逐项分析物质拆写是否符合规则，并验证反应产物的合理性与守恒关系。

步骤
- A选项：铁与非氧化性酸反应生成 $Fe^{2+}$，且盐酸中 $H^{+}$ 拆写无误，但产物应为 $Fe^{2+}$。错误。
- B选项：$Na$ 投入水溶液中优先与水反应，生成 $NaOH$ 和 $H_{2}$，$NaOH$ 再与 $CuSO_{4}$ 生成 $Cu(OH){2}$ 沉淀，方程式实为 $2Na + Cu^{2+} + 2HO = Cu(OH){2}\downarrow + 2Na^{+} + H\uparrow$。不能直接置换出单质铜。错误。
- C选项：$NaHCO_{3}$ 为弱酸酸式盐，酸式根 $HCO_{3}^{-}$ 不能拆成 $CO_{3}^{2-}$，正确写法为 $HCO_{3}^{-} + H^{+} = H_{2}O + CO_{2}\uparrow$。错误。
- D选项：$Mg(OH){2}$ 为难溶碱，保留化学式；$Fe^{3+}$ 可拆；生成物 $Fe(OH)$ 子拆写。方程式电荷守恒（左边+6，右边+6），原子守恒，沉淀转化趋势成立。正确。}$ 更难溶，写成沉淀，$Mg^{2+

点评/变式
- 陷阱本质：本题选项横跨“产物判断”“反应顺序”“酸式根拆写”和“沉淀转化”，这些均为常见失分点。
- 变式训练：若将 C 选项改为 $NaHCO_{3}$ 与澄清石灰水反应，少量与过量情况生成不同产物，拆写时 $HCO_{3}^{-}$ 均不能拆分，考查量与产物的关系。D 选项可变形为 $FeCl_{3}$ 与 $Mg(OH)_{2}$ 的转化平衡，进一步体会沉淀溶解平衡原理。
