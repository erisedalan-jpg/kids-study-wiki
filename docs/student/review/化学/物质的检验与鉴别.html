知识精要

  • 常见离子的检验方法
  • $I^-$ 本身无色，检验时需先氧化成 $I_2$（在 $CCl_4$ 中显紫色）或使用 $AgNO_3$（淡黄色 $AgI$ 沉淀，不溶于稀 $HNO_3$）。
  • $Ag^+$ 与 $Cl^-$ 产生白色 $AgCl$ 沉淀，不溶于稀 $HNO_3$；注意 $SO_4^{2-}$ 干扰——$BaSO_4$ 也是不溶于稀酸的白色沉淀。
  • 检验 $SO_4^{2-}$ 应加盐酸酸化，除去 $Ag^+,CO_3^{2-}$ 等干扰，再加 $BaCl_2$ 溶液，生成不溶于盐酸的白色沉淀。
  • 物质特性与保存
  • 液溴（$Br_2$）易挥发、有毒，密度比水大，通常用水封保存。
  • 能使湿润淀粉‑KI试纸变蓝的物质是具有氧化性的物质（如 $Cl_2,Br_2,NO_2,O_3,HNO_3(浓)$ 等），不能唯一确定是 $Cl_2$。
  • 萃取与颜色鉴别
  • $I_2$ 在有机溶剂（$CCl_4$、苯）中显紫色，$I^-$ 不溶于有机溶剂且无色。若 $CCl_4$ 层显紫色，证明存在 $I_2$，而非 $I^-$。

解题方法与套路

  1. 沉淀鉴别的干扰排除
    向溶液中加入 $BaCl_2$ 得白色沉淀，遇稀 $HNO_3$ 不溶，可能为 $AgCl$ 或 $BaSO_4$。必须结合其他信息（如是否使用盐酸酸化、溶液酸碱性等）区分。通常检验 $SO_4^{2-}$ 时，先加稀盐酸无沉淀，再加 $BaCl_2$ 出现白色沉淀，才能证明。
  2. 氧化性试纸变色判断
    湿润淀粉‑KI试纸变蓝，说明试样能将 $I^-$ 氧化成 $I_2$，属于氧化性气体检验，不能限定为 $Cl_2$。答题时谨记：能氧化 $I^-$ 的气体均可导致现象。
  3. 萃取显色的陷阱
    $CCl_4$ 层显紫色，说明存在单质碘，而不是碘离子。若要检验 $I^-$，必须先加氧化剂（如氯水、$H_2O_2$）再萃取出 $I_2$，或通过其他特征反应（如 $AgNO_3$ 等）确认。
  4. 逐项排除法
    面对“一定”“都是”等绝对化表述时，优先怀疑；结合典型反例快速排除错误选项。

高频易错

  • “能使淀粉‑KI试纸变蓝的物质一定是 $Cl_2$”：错误！常见氧化性气体如 $NO_2$、$O_3$、$Br_2$ 蒸气等同样有此现象。
  • “$CCl_4$ 层显紫色证明原溶液含有 $I^-$”：错误！只能证明存在 $I_2$，$I^-$ 在有机层中无色，且不加氧化剂时 $I^-$ 不会变色。
  • “不溶于稀 $HNO_3$ 的白色沉淀仅由 $Ag^+$ 产生”：错误！$BaSO_4$ 同样符合。应结合所用沉淀剂是 $BaCl_2$ 还是盐酸酸化后的 $BaCl_2$ 等信息判断。
  • 实际操作顺序错误：检验 $SO_4^{2-}$ 时直接加 $BaCl_2$ 而不先用盐酸排除 $Ag^+$、$CO_3^{2-}$、$SO_3^{2-}$ 干扰，导致误判。

代表题精讲

代表题：2012‑新课标‑01

题目
下列叙述中正确的是（ ）
A．液溴易挥发，在存放液溴的试剂瓶中应加水封
B．能使润湿的淀粉‑KI试纸变成蓝色的物质一定是 $Cl_2$
C．某溶液中加入 $CCl_4$，$CCl_4$ 层显紫色，证明原溶液中存在 $I^-$
D．某溶液中加入 $BaCl_2$ 溶液，产生不溶于稀硝酸的白色沉淀，该溶液一定含有 $Ag^+$

思路
逐项检查知识陷阱：A项考查液溴保存特性；B项氧化性气体干扰；C项 $I_2$ 与 $I^-$ 混淆；D项 $AgCl$ 与 $BaSO_4$ 沉淀的干扰。

步骤
- A：液溴密度大于水，易挥发，常水封保存。正确。
- B：使湿润淀粉‑KI试纸变蓝需要有氧化性物质将 $I^-$ 氧化为 $I_2$，除 $Cl_2$ 外，$NO_2$、$O_3$、$Br_2$ 等均可行。表述绝对化，错误。
- C：$CCl_4$ 层显紫色说明 $I_2$ 存在于有机层，$I^-$ 本身无色且不易溶于 $CCl_4$，无法直接得出原溶液含 $I^-$ 的结论。错误。
- D：$BaCl_2$ 引入 $Ba^{2+}$ 和 $Cl^-$，生成不溶于稀 $HNO_3$ 的白色沉淀可能是 $AgCl$，也可能是 $BaSO_4$，因此不一定含 $Ag^+$。错误。

正确答案：A。

点评/变式
- 本题集中考查“绝对化表述”的常见错误，是离子检验题的典型典范。
- 变式训练：若将B项改为“能使湿润淀粉‑KI试纸变蓝的气体一定是氧化性气体”，则正确；若将C项改为“某溶液加氯水后再加 $CCl_4$，有机层显紫色，则原溶液含 $I^-$”，则正确。
- 提醒：应试中务必区分单质与离子、试剂添加顺序对沉淀判断的影响。
