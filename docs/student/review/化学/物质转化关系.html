物质转化关系

考点物质转化关系权重5真题数1学科化学父主题元素化合物

考点定位

  • 父主题：元素化合物
  • 权重 weight：5
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择3
  • 难度分布：易1

知识精要

  • 物质转化中的固体质量变化：分析反应前后固体物质的种类与质量时，需准确写出化学方程式，判断反应物与生成物中哪些为固态。
  • 常见增重/减重规律
  • ${\rm Na_2O_2}$ 与 ${\rm CO_2}$ 反应：$2{\rm Na_2O_2}+2{\rm CO_2}\rightarrow 2{\rm Na_2CO_3}+{\rm O_2}$，固体由 ${\rm Na_2O_2}$ 变为 ${\rm Na_2CO_3}$，可看作固体增重部分为 ${\rm CO}$，故反应后固体质量增大。
  • 氢气还原 ${\rm CuO}$：${\rm H_2+CuO}\xrightarrow{\Delta}{\rm Cu+H_2O}$，固体由 ${\rm CuO}$ 变为 ${\rm Cu}$，失去氧元素，固体质量减小。
  • 铝热反应：$2{\rm Al+Fe_2O_3}\xrightarrow{\text{高温}}{\rm Al_2O_3+2Fe}$，反应物铝和氧化铁均为固体，生成物氧化铝和铁均为固体，根据质量守恒定律，固体总质量不变。
  • 锌与 ${\rm Cu(NO_3)_2}$ 溶液反应：${\rm Zn+Cu(NO_3)_2\rightarrow Zn(NO_3)_2+Cu}$，固体由 ${\rm Zn}$ 变为 ${\rm Cu}$，相对原子质量 ${\rm Zn(65)>Cu(64)}$，固体质量减小。
  • 差量法原理：${\rm \Delta m=}$ 生成固体的总质量 $-$ 反应前固体的总质量。 $\Delta m>0$ 增重；$\Delta m<0$ 减重；$\Delta m=0$ 不变。

解题方法与套路

  1. 写方程：完整书写题目涉及的化学方程式，注明各物质状态（${\rm s}$、${\rm l}$、${\rm g}$、${\rm aq}$）。
  2. 定固体：找出反应物和生成物中所有固体物质，确认是否气体/液体参与或生成。
  3. 比质量：比较固体部分前后质量或利用差量法计算。固体增重的常见模式是气体中某些成分固定到固体中（如 ${\rm CO_2}$ 中的 ${\rm CO}$ 进入 ${\rm Na_2O_2}$），减重多为固体失去氧或因置换反应相对原子质量减小。
  4. 注意全固态反应：若反应物和生成物均为固体，且无气体逸出或进入，根据质量守恒，固体总质量保持不变。
  5. 定量判断：对有气体参与或生成的，可以用 $1\ {\rm mol}$ 反应为标准计算固体质量差，快速判断。

高频易错

  • 误判 ${\rm Na_2O_2}$ 与 ${\rm CO_2}$ 反应：容易忽略气体变成固体带来的质量增加，误认为生成 ${\rm O_2}$ 会使固体减重。实际增重相当于 ${\rm CO}$ 组分被固体吸收。
  • 铝热反应的质量变化：铝热反应的反应物和生成物全是固体，且无气体参加或消失，封闭体系中固体总质量不变，常被误认为减重或增重。
  • 置换反应中原子量判断错误：锌置换铜，${\rm Zn}$ 的摩尔质量大于 ${\rm Cu}$，故固体质量减小；若为铁置换铜（${\rm Fe+Cu^{2+}\rightarrow Fe^{2+}+Cu}$，$56<64$）则固体质量增大。盲目记规律易出错，必须比较相对原子质量。
  • 忽视状态：如 ${\rm H_2}$ 还原 ${\rm CuO}$ 时，产物 ${\rm H_2O}$ 通常以水蒸气逸出，不属于固体，因此固体仅考虑 ${\rm CuO}$ 变 ${\rm Cu}$ 的失氧减重。

代表题精讲

题目
下列反应中，反应后固体物质增重的是（　）
A．氢气通过灼热的 ${\rm CuO}$ 粉末
B．二氧化碳通过 ${\rm Na_2O_2}$ 粉末
C．铝与 ${\rm Fe_2O_3}$ 发生铝热反应
D．将锌粒投入 ${\rm Cu(NO_3)_2}$ 溶液

思路
分别写出各反应的化学方程式，标记固体，计算固体质量的变化。注意铝热反应反应物、生成物全是固体，质量守恒；其他反应有气体参与或生成，用差量分析。

步骤
- A 选项：${\rm H_2+CuO\xrightarrow{\Delta}Cu+H_2O}$，固体 ${\rm CuO}$（80 g/mol）→ ${\rm Cu}$（64 g/mol），固体减重，不符合。
- B 选项：$2{\rm Na_2O_2+2CO_2\rightarrow 2Na_2CO_3+O_2}$。$2\ {\rm mol}\ {\rm Na_2O_2}$（$2\times78=156\ {\rm g}$）变为 $2\ {\rm mol}\ {\rm Na_2CO_3}$（$2\times106=212\ {\rm g}$），固体增重 $56\ {\rm g}$，相当于吸收了 $2\ {\rm mol}$ 的 ${\rm CO}$ 质量，符合增重。
- C 选项：$2{\rm Al+Fe_2O_3\xrightarrow{\text{高温}}Al_2O_3+2Fe}$，固体反应物和固体生成物总质量相等，固体质量不变，不符合。
- D 选项：${\rm Zn+Cu(NO_3)_2\rightarrow Zn(NO_3)_2+Cu}$，固体 ${\rm Zn}$（65 g/mol）→ ${\rm Cu}$（64 g/mol），固体减重，不符合。

故固体增重的为 B。

点评/变式
- 此题集中考查差量法在物质转化中的应用，核心是厘清固体成分变化与摩尔质量。
- 变式：如果将 ${\rm CO_2}$ 通入 ${\rm Na_2O_2}$ 改为 ${\rm H_2O}$ 蒸气与 ${\rm Na_2O_2}$ 反应（$2{\rm Na_2O_2+2H_2O\rightarrow 4NaOH+O_2}$），固体增重增加的是 ${\rm H_2}$ 的质量，依然增重。
- 掌握“气体→固体固定部分成分”的增重本质，可快速判断类似 ${\rm Na_2O_2}$ 与 ${\rm CO_2}$、${\rm H_2O}$、${\rm Na}$ 与 ${\rm O_2}$ 等反应的质量变化。
