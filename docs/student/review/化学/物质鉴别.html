知识精要

物质鉴别以离子反应为基础，核心是依据特征现象（沉淀、气体、颜色变化）确定离子种类，并排除干扰。

  • 常见离子的特征反应与干扰
  • $SO_4^{2-}$：遇 $Ba^{2+}$ 产生白色沉淀 $BaSO_4$，不溶于酸。$SO_3^{2-}$、$CO_3^{2-}$ 也会与 $Ba^{2+}$ 产生白色沉淀，但 $BaSO_3$、$BaCO_3$ 溶于酸。
  • $SO_3^{2-}$、$CO_3^{2-}$、$HCO_3^-$、$S_2O_3^{2-}$、$HSO_3^-$ 等：遇强酸可生成具有明显气味的气体（$SO_2$、$CO_2$、$H_2S$）。$S_2O_3^{2-}$ 遇酸既有气体（$SO_2$）又有沉淀（$S$），且其气体与其他含硫气体气味类似，形成干扰。
  • $S_2O_3^{2-}$ 的独特反应：$S_2O_3^{2-} + 2H^+ = S \downarrow + SO_2 \uparrow + H_2O$。溶液变浑浊并产生刺激性气味气体，可同时覆盖 $SO_3^{2-}$ 遇酸产生的 $SO_2$ 和 $CO_3^{2-}$ 产生的 $CO_2$ 现象。

  • 沉淀转化：$BaCO_3$、$BaSO_3$ 等难溶盐在加入硫酸时可转化为更难溶的 $BaSO_4$，导致固体溶解再生成新沉淀的表观现象。

  • 鉴别实验设计原则
    试剂选择应逐个确认干扰已排除；观察现象需全面，涵盖颜色、状态、气味；分步检验时必须优先采用互不干扰或可消除干扰的流程（如先酸后钡盐区分 $SO_4^{2-}$ 与 $SO_3^{2-}/CO_3^{2-}$）。

解题方法与套路

  1. 粗判共存与溶解性
    根据样品溶于水是否透明，判断各组分间是否发生反应（如产生气体、沉淀），以及是否含有难溶物。
  2. 加酸——捕捉特征现象
    加入过量强酸（$HCl$ 或 $H_2SO_4$），观察有无气泡、沉淀、颜色变化和气味。
  3. 有浑浊+刺激性气体 → 必含 $S_2O_3^{2-}$（$Na_2S_2O_3$）。
  4. 仅有无味气体（$CO_2$） → 可能含 $CO_3^{2-}/HCO_3^-$。
  5. 仅有刺激性气体无浑浊 → 可能含 $SO_3^{2-}/HSO_3^-$。

  8. 若加入硫酸并观察沉淀变化：产生不溶于后续酸的白色沉淀 → 原混合物中可能存在能与硫酸生成难溶盐的离子（$Ba^{2+}$ 等），并注意沉淀转化。
  9. 判断“确定”与“可能”
    若某离子的特征现象被另一个必存在的离子所覆盖（如 $S_2O_3^{2-}$ 的刺激气体和浑浊将 $SO_3^{2-}$ 的 $SO_2$ 和 $S$ 的生成现象掩盖），则不能依据被覆盖的现象获得确证，只能归为可能存在。符合条件的选项需仅包含“确定”存在的物质。

高频易错

  • 忽视过量盐酸的排蔽作用
    向含 $S_2O_3^{2-}$ 的溶液中加盐酸后，再滴 $BaCl_2$ 得沉淀，易漏判 $SO_4^{2-}$，误以为沉淀可能由 $BaSO_3$ 被氧化形成。实际上过量盐酸已溶解 $BaSO_3$，沉淀只能是 $BaSO_4$。
  • 混淆现象覆盖导致错误排除
    由 $Na_2S_2O_3$ 遇酸生成的 $S$ 和 $SO_2$，会覆盖 $Na_2SO_3$ 产生的 $SO_2$ 和 $Na_2CO_3$ 产生的 $CO_2$，不能因未闻到另一种气味就断然排除 $Na_2SO_3$ 或 $Na_2CO_3$，但同样不能确认其存在。
  • 忽略沉淀转化（加硫酸后的固体）
    混合物加稀硫酸产生气泡且仍有固体，若只考虑酸跟碳酸盐等反应而不考虑生成更难溶的 $BaSO_4$，易错选。需想到 $BaCO_3$ 遇硫酸会转化为 $BaSO_4$ 沉淀。
  • 溶解性与反应性混淆
    部分物质溶于水后可能相互反应生成新沉淀（如 $Na_2CO_3$ 与 $CuSO_4$ 生成碱式碳酸铜），并非本身难溶，此时加水不溶不等于原物质不溶；加入酸后完全溶解并放气，结合加水现象综合分析。

代表题精讲

代表题1：2022全国乙卷-03

题目
某白色粉末可能含 $Na_2SO_4$、$Na_2SO_3$、$Na_2S_2O_3$ 和 $Na_2CO_3$。取少量样品：①溶于水，得无色透明溶液；②向溶液滴加过量稀盐酸，溶液变浑浊，有刺激性气体逸出；离心分离；③取上层清液，滴加 $BaCl_2$ 溶液，有沉淀生成。确定存在的成分是什么？

思路
用“过量盐酸先分辨含硫含碳离子，再钡盐锁死硫酸根”的套路。浑浊+刺激性气体直接指向 $S_2O_3^{2-}$；上层清液加 $BaCl_2$ 产生沉淀，结合过量盐酸条件可推断必含 $SO_4^{2-}$；同时被覆盖现象的 $SO_3^{2-}$ 和 $CO_3^{2-}$ 无法确证。

步骤
1. ①步：全溶得无色透明液 → 组分间不反应，无水解沉淀。
2. ②步：加过量 $HCl$ 后溶液变浑浊并放出刺激性气体 → 发生 $S_2O_3^{2-} + 2H^+ = S\downarrow + SO_2\uparrow + H_2O$，确定存在 $Na_2S_2O_3$。$SO_2$ 的气味和 $S$ 的浑浊将可能存在的 $Na_2SO_3$（出 $SO_2$）和 $Na_2CO_3$（出 $CO_2$）现象完全覆盖，无法据此确认或排除。
3. ③步：离心后清液加 $BaCl_2$ 生成沉淀。过量盐酸已使 $SO_3^{2-}$、$CO_3^{2-}$ 以气体形式脱离或转为弱酸，生成的沉淀只能是 $BaSO_4$ → 确定存在 $Na_2SO_4$。
4. 综合得出确有的物质：$Na_2SO_4$、$Na_2S_2O_3$，对应选项A。

点评/变式
干扰离子的“隐身”是高频陷阱。变式可增加 $Na_2SO_3$ 和 $Na_2CO_3$ 组合，若用先加足量 $BaCl_2$ 再加酸检验，现象就会交叉干扰，需严格遵循酸排蔽顺序。

代表题2：2016新课标Ⅱ卷-06

题目
某白色粉末由两种物质组成。实验：①取少量加足量水仍有部分未溶，再加入足量稀盐酸，有气泡产生，固体完全溶解；②另取少量加足量稀硫酸，有气泡产生，振荡后仍有固体存在。该粉末可能为哪组？

思路
水中残留难溶物 + 盐酸可全溶放气 → 有一组分溶于盐酸产气，另一组分难溶于水但溶于盐酸且不遗留沉淀；稀硫酸处理后残留固体 → 新生成更难溶的硫酸盐（$BaSO_4$ 等），不难联想到 $Ba^{2+}$ 的碳酸盐或亚硫酸盐组合。

步骤
1. 根据①：加水不溶→混合物中含难溶物质。加足量盐酸后全溶并冒气泡→难溶物必与盐酸反应生成可溶物及气体（如 $BaCO_3$、$BaSO_3$ 或 $Al(OH)_3$ 配合产气组分），无剩余沉淀→难溶组分不含 $Cl^-$ 不溶的 $AgCl$ 等。
2. 根据②：加足量稀硫酸，有气泡 → 必有能在酸性环境下产生气体的组分（$CO_3^{2-}$ 或 $SO_3^{2-}$ 等）；振荡后仍有固体 → 生成不溶于酸的钡盐 $BaSO_4$，故原混合物一定含有 $Ba^{2+}$ 的可酸溶盐（如 $BaCO_3$ 或 $BaSO_3$），另有阴离子部分转化为气体。结合选项C：$Na_2SO_3$、$BaCO_3$ 符合。
