甲烷的取代反应

考点甲烷的取代反应权重9真题数1学科化学父主题反应类型与基本反应

考点定位

  • 父主题：反应类型与基本反应
  • 权重 weight：9
  • 真题数：1；年份跨度：2018–2018
  • 出现题位：选择3
  • 难度分布：中1

知识精要

  • 反应类型：取代反应，特征是“一换一”（有机物分子中原子或原子团被其他原子或原子团替代）。
  • 反应物：甲烷（$CH_4$）与纯氯气（$Cl_2$），物质的量之比通常为1:1，但实际反应中氯气常过量以保证反应发生。
  • 反应条件：光照（紫外线或散射光），不可用加热代替，光照提供自由基反应所需能量。
  • 反应机理：自由基链式反应，分链引发（$Cl_2 \xrightarrow{h\nu} 2Cl\cdot$）、链增长（$Cl\cdot + CH_4 \rightarrow HCl + \cdot CH_3$，$\cdot CH_3 + Cl_2 \rightarrow CH_3Cl + Cl\cdot$ 等）、链终止（自由基两两结合）。
  • 反应产物：氯代甲烷混合物（一氯甲烷$CH_3Cl$直至四氯化碳$CCl_4$），以及氯化氢$HCl$。产物是多种取代产物的混合物，不可能只得到纯净的一氯甲烷。
  • 重要性质：
  • $CH_3Cl$在常温下为气体，其余氯代烃（$CH_2Cl_2$、$CHCl_3$、$CCl_4$）均为油状液体。
  • $HCl$极易溶于水，形成盐酸，试管内压强减小，液面上升。
  • 实验现象：黄绿色逐渐变浅（氯气消耗），试管内壁出现油状液滴（液态氯代烃），试管内液面上升（$HCl$溶于水引起压强降低）。

解题方法与套路

  1. 判断反应条件是否满足：明确光照（或更高能量条件如紫外线）为该取代反应的必要条件，加热不能替代。
  2. 判断有机产物状态：常温下，只一氯甲烷为气体，其他为油状液体；若题目中提及试管内壁有油状液滴，应联系多氯代物生成。
  3. 分析压强与液面变化：反应前后气体分子数减少（每取代一个氢，消耗1分子$Cl_2$，生成1分子$HCl$，气体总物质的量不变；但$HCl$溶于水，导致气体总物质的量减小，压强降低），引起液面上升。
  4. 注意试剂用量及产物分布：若氯气足量，产物以多氯代物为主；若甲烷过量，一氯甲烷比例较高，但仍是混合物。
  5. 结合典型实验装置：常见装置为试管倒扣于饱和食盐水（或水）中，光照后观察颜色、油状液滴、液面，通过现象反推反应本质。

高频易错

  • 误认为加热可引发取代：甲烷卤代必须是光照自由基反应，加热无法有效产生大量氯自由基，易与热裂解混淆。
  • 混淆现象原因：液面上升是因为生成的$HCl$溶解于水，而非氯气消耗本身；若忽略$HCl$的溶解性，会误判压强不变。
  • 误认为产物为纯净物：取代反应进行时，多种取代产物共存，即使按理论配比反应，产物仍为混合物。
  • 油状液滴成分判断错误：常温下液态的为$CH_2Cl_2$、$CHCl_3$、$CCl_4$，而$CH_3Cl$为气态；只见到油状液滴不能推理出只有这些多氯代物，但可以确定生成了液态卤代烃。
  • 忽视过量问题：光照下若氯气极少量，反应不易进行完全；常见习题中往往氯气充足，现象明显，但需注意题目是否有“甲烷过量”的描述。
  • 与加成反应混淆：甲烷是饱和烃，不能发生加成，只能取代。若试题出现“褪色”“无油状物”等表述，应先排除反应类型为取代。

代表题精讲

题目 2018-新课标Ⅱ-03

实验室用如图所示装置进行甲烷与氯气在光照下的反应。将盛有混合气体的试管倒扣在饱和食盐水中，经光照反应一段时间后，能正确反映实验现象的装置示意图是（选项示意图略，正解：试管内气体颜色变浅，内壁附着油状液滴，试管内液面上升）。

思路
本题通过装置现象考查取代反应的特征及产物性质。解题起点在于明确光照下甲烷与氯气发生取代反应，并分析气态反应物与生成物的状态、溶解性差异，进而推断压强变化与液面变化。

步骤 1. 抓住反应本质：光照条件下，$CH_4$与$Cl_2$发生取代反应，生成$HCl$和多种氯代甲烷（$CH_3Cl$、$CH_2Cl_2$、$CHCl_3$、$CCl_4$），黄绿色的$Cl_2$被消耗，气体颜色变浅。 2. 判断产物状态：常温下，$CH_3Cl$为气体，$CH_2Cl_2$、$CHCl_3$、$CCl_4$为油状液体，所以试管内壁会出现油状液滴。 3. 分析气体压强变化：反应前后气体分子总数理论不变（每$CH_4 + Cl_2 \rightarrow CH_3Cl + HCl$，气体分子数2→2）；但生成的$HCl$极易溶于水（饱和食盐水可降低$Cl_2$的溶解度，但$HCl$仍溶解），导致试管内气体总物质的量减少，压强降低，外界大气压将水（食盐水）压入试管，液面上升。 4. 排除干扰：液面上升不是因$Cl_2$溶解（饱和食盐水抑制$Cl_2$溶解），也不是生成了液态产物导致气体体积收缩（液滴体积相对于气体可忽略），根本原因是$HCl$的溶解。

点评/变式 - 此题以实验装置为载体，考核“宏观现象—微观变化—物质性质”的关联能力。典型易错是误选油状液滴出现但液面不变或下降的选项，考生往往漏掉$HCl$溶解导致的压强差。 - 变式：若将饱和食盐水改为水，则$Cl_2$也会部分溶解，现象更加复杂（绿色更快褪去，液面上升更显著），但仍可用上述思路分析。 - 延伸：可进一步考查如何验证生成物中有$HCl$（蘸有浓氨水的玻璃棒靠近管口产生白烟，或AgNO₃溶液检验氯离子等）。
