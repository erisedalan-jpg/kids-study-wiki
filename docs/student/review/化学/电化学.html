知识精要

原电池与电解池的本质区别在于能量转化形式：原电池将化学能转化为电能（自发氧化还原），电解池将电能转化为化学能（非自发氧化还原）。判断装置类型的关键依据是无外加电源时为原电池，有外加电源或强制电子流向时为电解池。二次电池（可充电电池）放电时是原电池，充电时是电解池，阴极、阳极的命名仅在电解池/充电过程中使用：阴极连接电源负极，发生还原反应；阳极连接电源正极，发生氧化反应。

电极判断的核心逻辑：电势较高的电极为正极（原电池）或阳极（电解池）。电子经外电路从负极→正极（原电池）、从电源负极→阴极（电解池）。溶液中离子迁移遵循“阴阳相吸”规律：阳离子移向阴极或正极（得电子侧），阴离子移向阳极或负极（失电子侧）。注意阴/阳离子交换膜的选择性透过：仅允许对应离子通过，用以平衡电荷、隔离产物或维持酸碱环境。

电极反应式的书写必须满足三大守恒：电子守恒（转移电子数匹配化合价变化）、电荷守恒（根据介质用 $H^+$、$OH^-$ 或其他离子平衡电荷）、原子守恒。介质酸碱性的影响不可忽视：酸性条件下可添加 $H^+$ 和 $H_2O$，碱性条件下用 $OH^-$ 和 $H_2O$，熔融盐体系用对应离子。书写时可分四步——确定反应物/产物并配平变价元素、根据化合物中 ${H}$ 和${O}$的数目在缺氢侧加$H^+$或$H_2O$/在缺氧侧加$OH^-$或$H_2O$、用电荷守恒补电子、最后检查原子与电荷。

电化学计算的通用桥梁是电子守恒：各电极转移电子数相等，即 $n(e^-) = \frac{I \times t}{F}$（$F = 96500\ C \cdot mol^{-1}$）。由此可建立电极产物与电量之间的定量关系。

电极电势与反应竞争：阳极上失电子能力强者优先放电（金属活泼性顺序中活泼金属阳极优先溶解，惰性电极时阴离子放电顺序为 $S^{2-} > I^- > Br^- > Cl^- > OH^- >$ 含氧酸根）；阴极上得电子能力强者优先放电（$Ag^+ > Cu^{2+} > H^+ > Fe^{2+} > Zn^{2+}$ 等，注意浓度影响）。

解题时须敏锐辨识隐藏条件，如酸性锌锰干电池中 $NH_4Cl$ 水解呈酸性，书写电极反应应有 $H^+$ 参与；铝—空气电池在碱性介质中 $Al$ 转化为 $Al(OH)_4^-$ 而非 $Al^{3+}$。

解题方法与套路

  1. 装置识别与电极命名判定
  2. 有外加直流电源（或光照/充电标记）→ 电解池；无外加电源、依靠自发性氧化还原 → 原电池。

  3. 可逆电池的充/放电过程：书写电极反应须明确当前状态。放电时负极发生氧化反应，正极发生还原反应；充电时阴极与负极对应（得电子还原），阳极与正极对应（失电子氧化）。

  4. 电极反应式书写的标准流程

  5. 步骤一：确定电极反应物与主产物，根据元素化合价变化确定变价元素。
  6. 步骤二：先配平变价元素，并按化合价变化数目标注得/失电子数 $e^-$。
  7. 步骤三：根据环境（酸性/碱性/中性）和原子守恒，用 $H^+、OH^-、H_2O$ 调整非金属元素尤其是氧、氢的个数。
  8. 步骤四：依据电荷守恒复核，确保反应前后净电荷数相等。

  9. 总反应核对：两电极反应相加得总反应式，电子必须抵消。

  10. 电子守恒法的应用框架

  11. 串联电路中通过各电极的电量相等：$n(e^-)=\frac{Q}{F}=\frac{I \cdot t}{96500}$（电流 $I$ 单位 $A$，时间 $t$ 单位 $s$）。
  12. 建立物质的量与电子的关系式，如 $Zn - 2e^- = Zn^{2+}$，或 $2H_2O - 4e^- = O_2 + 4H^+$。利用比例关系直接求解产物质量、气体体积等。

  13. 在涉及产量比较时（如 $H_2$ 产量），要分别列出两电极或两体系的总反应，对比每摩尔电子转移所得目标产物的物质的量。

  14. 离子交换膜的功能定位与分析

  15. 弄清膜两侧电极反应：某电极若消耗 $OH^-$，则为了维持反应持续，需要阴离子交换膜允许 $OH^-$ 从另一侧迁移补充；或者若电极产生 $H^+$，需阳离子交换膜允许 $H^+$ 迁移至另一侧以维持电中性。
  16. 记忆口诀：“阳离往阴（阴极），阴离往阳（阳极）”，务必结合具体反应判断是否需要交换膜以及膜的类型。

高频易错

  • 充放电电极反应的书写混淆：充放电虽是互逆反应，但条件是给定的——放电是自发的总反应，充电是外加电压下的分解/合成反应。电极名称一旦写反，导致选项判断全盘皆错。
  • 电极产物与介质发生后续反应：在单一电极反应式中必须写出介质参与的直接产物，比如在碱性条件下 $Al$ 生成 $Al(OH)_4^-$ 而不是 $Al^{3+}$，$CO_2$ 最终可能生成 $CO_3^{2-}$，要结合溶液整体环境判断。
  • 离子移动方向与膜的类型不匹配：阴离子通过阴离子交换膜，阳离子通过阳离子交换膜。若题目设定阴离子交换膜，但选项说“$H^+$ 通过某膜”则必定错误；反之亦然。必须检查膜的名称与通过它的离子种类。
  • 电子守恒计算中计量关系错误：最容易出错的是将转移电子数与主产物物质的量的系数关系搞反。例如“转移2mol电子消耗多少锌”，需确认电极反应式中锌与电子的系数比（$Zn \sim 2e^-$）。当比较理论产量时，应在相同转移电子数的前提下进行。
  • 放电顺序易忽略浓度与超电势：如用惰性电极电解 $CuSO_4$ 溶液，阴极 $Cu^{2+}$ 先放电，析出铜，但当 $Cu^{2+}$ 浓度极低时 $H^+$ 也可能放电。阴离子在阳极的放电顺序 $Cl^- > OH^-$ 也需牢记，且注意 $Cl^-$ 浓度较大时优先于 $OH^-$ 放电。
  • 电极判断误用“正负”与“阴阳”：原电池里无阴阳极之说法（只有正负极），电解池或充电时才有阴阳极。常设置在二次电池充电过程中，将其误当作原电池来命名电极。

代表题精讲

题目1·2024-辽宁-12

思路 该题是电解池的创新应用。装置目的为耦合 $HCHO$ 的高效氧化以降低阳极析氧过电位，从而提高阴极产氢效率。首先依据图中物质转化判断电极：b极处 $HCHO$ 失去电子被氧化为 $HCOO^-$，故 b 为阳极；a 极则为阴极。随后写出两极的半反应，并结合题目给出的反应机理分析总反应。选项涉及产量比较、半反应式正误及离子迁移方向。

步骤 1. 定电极与过程：b 极 $HCHO \rightarrow HCOO^-$，属氧化反应，b 为阳极；a 极水得电子，放出氢气，a 为阴极。 2. 写半反应： - 阳极多步耦合机理简化为：$2HCHO - 2e^- + 4OH^- \longrightarrow 2HCOO^- + H_2\uparrow + 2H_2O$。 - 阴极：$2H_2O + 2e^- \longrightarrow H_2\uparrow + 2OH^-$。 3. 分析选项： - A：转移 $2\ mol\ e^-$，本体系阳极产 $1\ mol\ H_2$，阴极产 $1\ mol\ H_2$，共 $2\ mol\ H_2$。传统电解水：$2H_2O \xrightarrow{电解} 2H_2 + O_2$，$4\ mol\ e^-$ 产生 $2\ mol\ H_2$，即 $2\ mol\ e^-$ 产生 $1\ mol\ H_2$，因此本体系产量是传统电解水的 $2$ 倍，A 错误（题干称“1.5倍”）。 - B：阴极反应正确。 - C：b极（阳极）消耗 $OH^-$，阴极生成 $OH^-$，$OH^-$ 通过阴离子交换膜向 b 极迁移以补充，表述正确。 - D：阳极总反应正确。 4. 得出答案：错误的是 A。

点评/变式 新情境下要善用总法：转移等电量比较法永远是电化学产量的金标准。当遇到耦合有机物氧化制氢时，关键在于认清耦合反应导致阳极提供的电子部分用于产 $H_2$ 而不是析出 $O_2$，从而成倍提高阴极电流的产氢效率。

题目2·2022-全国乙-06

思路 这是一道光助充电 $Li-O_2$ 电池题。题目给出了充电时阴阳极的反应式，需要识别电极功能和在充/放电两个工况下对应的物质变化。充电是电解池，光照辅助产生空穴（$h^+$，氧化性，驱动阳极反应）和电子（$e^-$，还原性，驱动阴极反应）。放电为自发的原电池过程，$Li$ 作负极。

步骤 $\bullet$ 充电时：阴极 $Li^+ + e^- = Li$（$Li^+$ 被还原）；阳极 $Li_2O_2 + 2h^+ = 2Li^+ + O_2$（氧被氧化为 $O_2$）。 $\bullet$ 放电时：负极为 $Li$：$Li - e^- = Li^+$；正极为 $O_2$ 参与构建 $Li_2O_2$：$2Li^+ + O_2 + 2e^- = Li_2O_2$。 $\bullet$ 总反应：$2Li + O_2 \rightleftharpoons Li_2O_2$。 $\bullet$ 根据各选项描述逐一检查，尤其警惕“光催化电极在放电时充当阴极/阳极”这类迷惑性表述——因放电整个电池是原电池，只有正负极，只有在充电/电解时才说阴、阳极。

点评/变式 此类“光充电”题虽形式新颖，但落脚点依然是电极反应方向的识别。务必抓牢“得电子是还原，失电子是氧化”这一基本逻辑。光提供高能量的电子-空穴对以驱动非自发反应，放电则为常规化学能转电能过程。对本类题，比较充电与放电的电极反应是核心突破口。

题目3·2015-新课标Ⅱ-08（部分）

思路 从给定化学式中提取化合价变化，结合介质信息书写正极和总反应。第（2）问是典型的电子守恒定量计算。第（3）问属分离提纯，依据不同物质溶解度随温度变化差异——冷却热饱和溶液法（降温结晶）。

步骤 1. 正极反应式：一次电池放电，正极 $MnO_2$ 得电子。生成物含 $MnOOH$，说明每摩尔 $MnO_2$ 得 $1\ mol\ e^-$，且环境中因 $NH_4Cl$ 水解呈酸性，需要 $H^+$ 平衡 O 和 H。反应为 $MnO_2 + H^+ + e^- = MnOOH$。负极：外壳锌失电子生成 $Zn^{2+}$。 2. 总反应离子式：正极 $\times 2$ + 负极，得 $2MnO_2 + Zn + 2H^+ = 2MnOOH + Zn^{2+}$。 3. 计算消耗锌： - 电量 $Q = I t = 0.5\ A \times 5 \times 60\ s = 150\ C$。 - 转移电子物质的量 $n(e^-) = 150\ C \div 96500\ C \cdot mol^{-1} \approx 1.554 \times 10^{-3}\ mol$。 - $Zn \sim 2e^-$，$n(Zn) = 0.5 \times n(e^-) = 7.77 \times 10^{-4}\ mol$。 - $m(Zn) = 7.77 \times 10^{-4}\ mol \times 65\ g \cdot mol^{-1} \approx 0.05\ g$。 4. 分离 $ZnCl_2$ 与 $NH_4Cl$：由表可知，$NH_4Cl$ 的溶解度随温度升高而显著增大，$ZnCl_2$ 溶解度虽然也增大但本身极大，将混合溶液加热浓缩后冷却结晶，主要析出 $NH_4Cl$，趁热过滤可初步分离；亦可利用两者溶解度的绝对差异多次递归纯化。

点评/变式 本题综合性强，将电化学与实验操作结合。酸式锌锰电池 “$H^+$ 参与反应” 是书写电极式的关键陷阱；电量计算注意统一单位（时间换成秒）。分离方法依据为：溶解度受温度影响大→冷却热饱和溶液（降温结晶）；影响小→蒸发溶剂（蒸发结晶）。此处 $NH_4Cl$ 适合前法。
