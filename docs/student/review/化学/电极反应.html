知识精要

电极反应是电化学的核心，涵盖原电池（化学能→电能）与电解池（电能→化学能）中电极上发生的氧化/还原半反应。

  • 电极判定与反应类型
  • 原电池：负极发生氧化反应（电子流出），正极发生还原反应（电子流入）。

  • 电解池：阳极发生氧化反应（阴离子、失电子能力强），阴极发生还原反应（阳离子、得电子能力强）。外电路中电子由阳极流向阴极，内电路由离子定向移动完成电荷传递。

  • 电极反应式的书写规则

  • 价态分析：确定核心元素反应前后的化合价变化。
  • 物料守恒：利用 $H_2O/H^+/OH^-$ 配平非$O$、$H$外的原子（常见于含氧酸根、有机物氧化等）。
  • 电荷守恒：在电极方程一侧添加电子 $e^-$ 使两侧净电荷相等。注意电子带负电。

  • 环境适配：根据电解质酸碱性修正产物。

    • 酸性环境：用 $H^+$ 和 $H_2O$ 配平，不出现 $OH^-$。
    • 碱性环境：用 $OH^-$ 和 $H_2O$ 配平，不出现 $H^+$。
    • 熔融盐/固体电解质：只出现相应离子，不补水/酸碱。

  • 离子交换膜与微粒迁移

  • 阳离子交换膜：仅 $H^+, Li^+, Na^+$ 等阳离子通过，从阳极→阴极迁移（电解池）/负极→正极迁移（原电池）。
  • 阴离子交换膜：仅 $Cl^-, SO_4^{2-}, OH^-$ 等阴离子通过，迁移方向相反。

  • 规律：内电路离子迁移目的为平衡电极电中性（阳极区正电荷过剩引阴离子迁入；阴极区负电荷过剩引阳离子迁入）。

  • 二次电池（可充电电池）

  • 放电：负极（氧化）⇌充电：阴极（还原）；放电：正极（还原）⇌充电：阳极（氧化）。
  • 电极判断“正正负负”：放电正极对应充电阳极，放电负极对应充电阴极。

解题方法与套路

  1. 题型速判 标明“电池/原电池/放电”按原电池分析；“电解/充电”按电解池分析；“二次电池/可充电时”按题干描述锁定当前方向。

  2. 电极确认两步法

  3. 化合价升降：失电子（化合价升高）→原电池负极/电解池阳极；得电子（化合价降低）→原电池正极/电解池阴极。

  4. 微粒流向互推：电子由负→正（外电路），阴离子由正→负（内电路）；阳离子反向。

  5. 电极反应式书写流程

  6. 写出原始物→产物，标化合价，配电子数 $e^-$。
  7. 若介质含 $H^+/OH^-$，先配电荷（加 $H^+$ 或 $OH^-$），再补水配原子。

  8. 检查三守恒（电子、物料、电荷）。双膜装置需分清两侧酸碱或浓度差异。

  9. 选项验证与计算

  10. 微粒迁移说法：核验离子类型、膜类型、方向（符合同性相斥、电极电性吸引）。

  11. 理论产气量/电量关系：利用 $n(e^-)$ 守恒，比较反应计量系数。转移相同电量时产物物质的量取决于转移电子数差异。

  12. 图像/信息整合

  13. 箭头判流向：电子从低电位到高电位（外电路逆电流方向），离子通过膜迁移。催化电极关注“空穴$h^+$”视为强氧化剂、“电子$e^-$”为还原剂。

高频易错

  • 电极命名混淆：二次电池中“充电时正极” 错误说成还原反应。正确是阳极（氧化）。简单记：充放电同极对调（正→阳，负→阴）。
  • 反应物/产物与介质不匹配：碱性锌锰电池$MnO_2$得电子生成$MnOOH(\text{或}Mn(OH)_2)$，在碱性环境直接写成$Mn^{2+}$会错。酸性$H^+$ 参与的反应误写 $OH^-$。
  • 有机物氧化电极反应式配平：仅关注$C$化合价变化切不可忽略$H/O$数的平衡，必须添加$H_2O/OH^-$等保证原子守恒（如HCHO氧化为$HCOO^-$时需补$OH^- + H_2O$）。
  • 膜通透性与离子迁移方向：阴离子交换膜不准阳离子穿过，若题干误称$Na^+$经过阴膜则为错误项；多室电解中离子迁移终点常为学生盲区，需要分清是电极区还是中间室浓度变化。
  • 充放电产物计算谬误： “相同电量下” H₂产量对比，忽略$\frac{1\text{ mol e}^-}{\text{生成H}_2的系数}$是关键。转移相同电子数，系数越大产量越少。不可只看化学方程式系数。

代表题精讲

题目 （2024-辽宁-12） 结合耦合HCHO制氢，图示电解装置阴阳极反应，判断说法正误。
思路 先按照HCHO→HCOO⁻是氧化反应判定b极为阳极、a极为阴极；结合机理推导阳极副产H₂，阴极水放电产H₂；选项A属理论产量对比，用电子守恒解。
步骤
- 电极判定：HCHO中C(0)→HCOO⁻中C(+2) 失电子，氧化 → 阳极(b极)。a极得电子产生OH⁻为阴极。
- 阴阳极主反应：阴极 $2H_2O + 2e^- = H_2↑ + 2OH^-$。阳极总反应由机理推导：$HCHO - 2e^- + 4OH^- = 2HCOO^- + 2H_2O + H_2↑$。
- 电量对比：传统电解水：转移 $2e^-$，阴极产1 H₂（阳极无H₂）。耦合方案：转移 $2e^-$，阴、阳两极各产1 H₂共2 H₂。相同电量产量为传统2倍（非1.5倍），A错。
- 离子迁移：电解时OH⁻生成在阴极(a)，经阴离子交换膜迁往阳极(b)方向以中和阳极OH⁻消耗，C正确。
点评/变式 此类“耦合电解”实质是阳极用易氧化物质替代析氧，既降电压又多产H₂。变式可改变阳极有机物（如乙醇、甘油），判断产物及理论产量提升倍数（计算时关键比电子数）。

题目 （2022-全国乙-06) 光照充电$Li\text{-}O_2$二次电池，原理判断错误选项。
思路 区分“光照充电”属电解池，光催化电极产生电子/空穴，驱阴、阳极反应；放电为原电池自动进行。
步骤
- 充电时期判定：“光照…驱动阴极反应$Li^+ + e^- = Li$”→ 得电子为阴极（还原），光电极另一侧发生 $Li_2O_2 + 2h^+ = 2Li^+ + O_2$ 是阳极(空穴夺取电子氧化$O^{2-}$)。
- 离子迁移方向：充电时阳离子 $Li^+$ 经电解质移向阴极（得电子沉积Li）；充电阳极生成$O_2$，$Li^+$脱离。
- 综合反应方向：充电总反应$Li_2O_2 = 2Li + O_2$，放电相反。选项中若说“充电时金属Li在光催化电极处生成”应正确；若说“放电时$O_2$在光电极还原”则应按原电池逻辑核对。
- 易错：把光生空穴$h^+$的作用当还原剂、误判阴极产物等。
点评/变式 光辅助二次电池常将光电极作为充放电极，注意区分电化学与光电化学耦合过程。变式为“光催化分解水制氢”类装置，同样用电子/空穴分析两极。
