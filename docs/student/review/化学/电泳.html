电泳

考点电泳权重6真题数1学科化学父主题基本概念与物理量

考点定位

  • 父主题：基本概念与物理量
  • 权重 weight：6
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 电泳定义：在外加电场作用下，胶体粒子在分散剂中向某一电极做定向移动的现象称为电泳。该性质证明胶粒带电。
  • 胶粒带电原因：胶体粒子比表面积大，有选择性吸附离子的倾向（如 $Fe(OH)_3$ 胶粒优先吸附 $FeO^+$ 带正电；$As_2S_3$ 胶粒优先吸附 $HS^-$ 带负电）；或胶粒表面分子电离导致带电。
  • 胶体整体电中性：胶体分散系呈电中性，胶粒带电，但分散剂中存在等量相反电荷的离子（反离子），整体不带电。切忌说“胶体带电”。
  • 电泳的应用：电泳分离（如蛋白质、核酸分离）、电泳涂漆等；证明胶粒带电。
  • 与溶液导电的区分：溶液导电是因溶质电离出的自由离子在电场下定向移动（某些非电解质的分子不移动）；电泳是带电的较大胶粒在分散介质中的定向移动。

解题方法与套路

  1. 审清对象：明确题目讨论的是溶液、浊液还是胶体，是整体还是分散质粒子。
  2. 区分整体与粒子：胶体整体（包括胶粒和分散剂）呈电中性，带电的只是某些胶粒；溶液整体也电中性。
  3. 判断粒子是否定向移动：通电时，只有带电微粒（离子、带电胶粒）才会定向移动；不带电分子或中性胶粒不移动。
  4. 区分布朗运动与规律运动：胶体中分散质粒子的布朗运动是无规则热运动，溶液中分子运动同样无规则，不存在“有规律”。
  5. 丁达尔效应：可以用来快速区分胶体与溶液，这是必记的光学性质。

高频易错

  • “胶体带电”的说法：胶体呈电中性，带电的仅仅是胶粒。误将胶粒带电等同于胶体带电是典型错误。
  • “溶液中的溶质粒子都向两极移动”：只有电解质电离的自由离子通电时才定向移动，非电解质分子不导电、不移动。
  • “溶液中分子运动有规律”：所有微粒（分子、离子、胶粒）在液体中的热运动都是无规则的，布朗运动就是微粒无规则运动的体现。
  • 忽略胶粒不都带电的事实：并非所有胶体的胶粒都带电，如蛋白质胶体在某pH下可能不带电。但中学阶段常以 $Fe(OH)_3$、$AgI$ 等带电胶粒为例讨论电泳。
  • 混淆导电原理：溶液导电是离子移动，胶体导电可能来自带电胶粒和介质中的反离子，不可混为一谈。

代表题精讲

题目（2009全国Ⅱ-02）：判断下列关于溶液和胶体的叙述正确的是哪个选项（见原题）。

思路：本题对比溶液与胶体的性质，涉及电性、通电时移动、粒子运动、丁达尔效应。需一一辨析选项，抓住四个字“胶体带电”“溶液溶质都移动”“有规律”“明显光带”。

步骤： - A 项：溶液电中性，胶体也电中性，只是胶粒可能带电。故“胶体是带电的”错误。 - B 项：溶液导电时，必须是电解质电离的离子才会定向移动，若溶质为非电解质则无离子移动；胶体中只有带电胶粒才在通电时定向移动（电泳）。选项说“溶液中的溶质粒子分别向两极移动”以偏概全，错误。 - C 项：溶液中分子热运动也是无规则的，胶体中的布朗运动正是分子无规则撞击的体现，两者均无规律，错误。 - D 项：胶体产生丁达尔效应（光带），溶液没有，正确。

点评/变式： - 这道题暴露考生两个弱点：一是对“胶体带电”和“胶粒带电”概念不清；二是对溶液中粒子运动的本质理解不到位。变式可以考：“为什么江河入海口易形成三角洲？”（胶粒遇电解质聚沉，与电泳不一定直接相关）或“电泳现象说明什么？”（证明胶粒带电）。解题关键是牢记胶体整体电中性，胶粒带电需要吸附离子或电离。
