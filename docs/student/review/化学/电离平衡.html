  • 父主题：化学反应原理
  • 权重 weight：31
  • 真题数：3；年份跨度：2008–2021
  • 出现题位：选择3 选择4 选择7
  • 难度分布：中2 易1

知识精要

  • 电离平衡：弱电解质在水溶液中部分电离，存在电离平衡常数（$K_a$ 或 $K_b$），只与温度有关。对一元弱酸 HA：$K_a = \frac{c(\mathrm{H}^+) \cdot c(\mathrm{A}^-)}{c(\mathrm{HA})}$，同理弱碱 BOH：$K_b = \frac{c(\mathrm{B}^+) \cdot c(\mathrm{OH}^-)}{c(\mathrm{BOH})}$。弱电解质越弱，$K$ 越小。
  • 水的离子积：$K_w = c(\mathrm{H}^+) \cdot c(\mathrm{OH}^-)$，25 ℃ 时 $K_w = 1.0 \times 10^{-14}$。纯水、酸、碱、盐溶液中均适用。
  • pH 与 pOH：$pH = -\lg c(\mathrm{H}^+)$，$pOH = -\lg c(\mathrm{OH}^-)$，25 ℃ 时 $pH + pOH = 14$。强酸、强碱溶液直接计算；弱酸、弱碱需代入 $K_a$ 或 $K_b$ 近似计算。酸碱混合优先判断过量、求剩余 $c(\mathrm{H}^+)$ 或 $c(\mathrm{OH}^-)$。
  • 沉淀溶解平衡：难溶电解质 $A_m B_n(s) \rightleftharpoons m A^{n+}(aq) + n B^{m-}(aq)$ 的溶度积 $K_{sp} = c^m(A^{n+}) \cdot c^n(B^{m-})$。$K_{sp}$ 只与温度有关。某离子浓度幂乘积 $Q_c > K_{sp}$ 时生成沉淀。
  • 多平衡综合（电离+沉淀+水解）：需联立质量守恒（物料守恒）、电荷守恒、各平衡常数式。如难溶弱酸盐 MA 在酸中的溶解：$MA(s) \rightleftharpoons M^+ + A^-$，$A^- + H^+ \rightleftharpoons HA$，有 $K_{sp} = [M^+][A^-]$，$K_a = \frac{[H^+][A^-]}{[HA]}$，物料守恒 $[M^+] = [A^-] + [HA]$，可导出线性关系 $[M^+]^2 = K_{sp} + \frac{K_{sp}}{K_a}[H^+]$。反应中若某些离子不水解（如 $M^+$），则其总浓度只受沉淀溶解平衡与酸效应控制。

高频易错

  • 忽略溶液混合体积变化：直接使用原浓度计算，不除以总体积导致离子浓度错误。混合后各离子浓度须按稀释后计算。
  • 过量判断失误：酸碱中和滴定计算时，简单的 $pH=12$ 意味着 $c(\mathrm{OH}^-)=0.01$ mol/L，需用剩余碱的物质的量除以总体积，而非初始碱体积。
  • 乱用近似条件：$c/K_a < 500$ 时仍用最简式 $\sqrt{K_a c}$ 会导致较大误差，必须解二次方程。
  • 多步电离随意忽略第二步：对多元弱酸如 $H_2CO_3$，在海水酸化分析时，$H^+$ 主要影响 $CO_3^{2-}$ 与 $HCO_3^-$ 的平衡，不能错误认为 $CO_2$ 直接与 $H_2O$ 反应产生 $CO_3^{2-}$。酸化的根本是 $CO_2 + H_2O \rightleftharpoons H_2CO_3 \rightleftharpoons H^+ + HCO_3^-$，$H^+$ 再与 $CO_3^{2-}$ 结合。
  • 物料守恒写错：难溶盐溶解体系中，若阳离子不水解，$c(M^+)$ 等于溶液中含 A 元素所有物种浓度之和（即 $[A^-]+[HA]$）。易漏掉 $HA$ 项，误认为 $c(M^+) = [A^-]$。
  • 混淆 $K_{sp}$ 与溶解度：$K_{sp}$ 严格由离子浓度幂乘积定义，受同离子效应影响溶解度减小，但 $K_{sp}$ 本身不变。计算溶解的离子浓度时，若不考虑其他平衡（如酸效应）会出错。

代表题精讲

题目1 (2021全国乙-07)

HA 为一元弱酸，难溶盐 MA 的饱和溶液中 $c(\mathrm{M}^+)$ 随 $c(\mathrm{H}^+)$ 变化，$\mathrm{M}^+$ 不发生水解。298 K 时 $c^2(\mathrm{M}^+)-c(\mathrm{H}^+)$ 为线性关系，如图实线所示。 思路：写出沉淀溶解平衡和酸效应下的电离平衡，联立找出 $c^2(\mathrm{M}^+)$ 与 $c(\mathrm{H}^+)$ 的关系式，从图像斜率、截距获取 $K_{sp}$ 与 $K_a$。
步骤：
1. $MA(s) \rightleftharpoons M^+ + A^-$，$K_{sp} = [M^+][A^-]$。
2. $A^- + H^+ \rightleftharpoons HA$，$K_a = \frac{[H^+][A^-]}{[HA]}$。
3. 物料守恒：阳离子仅源于 MA 溶解，且不水解，故 $c(M^+) = [A^-] + [HA]$。
4. 由物料守恒和 $K_a$ 得 $[A^-] = \frac{c(M^+)}{1 + [H^+]/K_a}$。代入 $K_{sp}$：$K_{sp} = [M^+] \cdot \frac{c(M^+)}{1 + [H^+]/K_a}$。注意 $[M^+] = c(M^+)$。
5. 整理得 $c^2(M^+) = K_{sp} + \frac{K_{sp}}{K_a} [H^+]$。线性关系 $y = kx + b$，斜率 $k = \frac{K_{sp}}{K_a}$，截距 $b = K_{sp}$。
6. 由图像读取截距即 $K_{sp}$，斜率结合截距求 $K_a$。
点评/变式：该题巧用线性化处理多平衡体系，核心是写出正确的物料守恒。变式可替换为 $M^+$ 水解或多元酸，关系更为复杂，但方法一致：列平衡→写常数→用守恒消元。

题目2 (2020新课标Ⅱ-03)

二氧化碳过量排放对海洋生物生存环境的影响，图示海水酸化过程。判断错误叙述。 思路：分析海洋中碳酸平衡及碳酸钙溶解平衡的移动，综合判断各选项。
步骤：
- 海水酸化：$CO_2$ 溶入海水，$CO_2 + H_2O \rightleftharpoons H_2CO_3$，$H_2CO_3$ 电离出 $H^+$ 和 $HCO_3^-$。$H^+$ 浓度增大，使 $HCO_3^- \rightleftharpoons H^+ + CO_3^{2-}$ 逆向移动，$CO_3^{2-}$ 浓度减小，$HCO_3^-$ 浓度增大。（A 正确）
- CaCO₃ 溶解：$CaCO_3(s) \rightleftharpoons Ca^{2+} + CO_3^{2-}$，由于 $CO_3^{2-}$ 被 $H^+$ 结合，平衡正向移动，促进珊瑚礁溶解。（B 正确）
- 海水酸化原理：主要是 $CO_2$ 与水生成碳酸并电离出 $H^+$，并非 $HCO_3^-$ 电离出 $H^+$ 和 $CO_3^{2-}$ 为主因，C 项将主因倒置，错误。
- 用新能源减少 $CO_2$ 排放，减缓酸化，保护珊瑚，D 正确。
故错误叙述为 C。
点评/变式：本题结合环境问题考查电离平衡与沉淀溶解平衡移动，易错点在于把“酸化的原理”归结为 $HCO_3^-$ 电离，实际上碳酸的第一步电离才是 $H^+$ 主要来源。变式可联系“钙化”与“脱钙”的双向过程。
