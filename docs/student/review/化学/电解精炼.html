知识精要

  • 定义：电解精炼是利用电解原理，将不纯金属作阳极、纯金属作阴极，含该金属离子的溶液作电解质，通过控制电位使活泼性不同的金属在阳极分步溶解、在阴极选择性析出，从而提纯金属的方法。
  • 装置四要素
    阳极：粗金属（如粗铜）；阴极：纯金属（如精铜）；
    电解质溶液：含该金属阳离子的盐溶液（如 CuSO₄ 溶液，常加 H₂SO₄ 抑制水解）；
    电源：外接直流电源，阳极接正极，阴极接负极。
  • 电极反应（以精炼铜为例）
    阳极（氧化）：$ \mathrm{Cu - 2e^- = Cu^{2+}} $（主要）；杂质中比 Cu 活泼的 Zn、Fe、Ni 等也放电：$ \mathrm{Zn - 2e^- = Zn^{2+}} $ 等；比 Cu 不活泼的 Au、Ag、Pt 等不放电，沉降至阳极泥。
    阴极（还原）：$ \mathrm{Cu^{2+} + 2e^- = Cu} $（溶液中 Cu²⁺ 得电子优先于 Zn²⁺ 等，因氧化性 Cu²⁺ 更强）。
  • 电解质溶液变化
    精炼过程中，阳极溶解的 Cu 与阴极析出的 Cu 等量，故 $ c(\mathrm{Cu^{2+}}) $ 理论上不变；但活泼杂质（Zn、Fe 等）溶解进入溶液，其阳离子浓度增大，Cu²⁺ 会因水解等因素略微变化；阳极泥富集贵金属。
  • 适用范围
    适用于粗铜、粗银、粗镍等金属的提纯，本质是牺牲阳极杂质，在阴极获得高纯金属。

高频易错

  • 阳极材料判断：切记阳极为粗金属，自身参与反应，不是惰性电极，不能误写溶液阴离子放电。
  • 阴极产物错写：阴极得电子的是目标金属离子，而非活泼杂质离子。如精炼铜中阴极不产生 Zn，即使溶液中有 Zn²⁺。
  • 电解质浓度误判：常有考生认为 $ c(\mathrm{Cu^{2+}}) $ 减小，实际上因阳极溶解与阴极析出差额平衡，浓度基本不变；但酸度、杂质离子浓度会改变。
  • 阳极泥成分遗漏：Au、Ag 等不放电，以单质形式沉积，要联想到工业回收贵金属。
  • 计算顺序错误：当多杂质共存时，阳极放电的总电子数等于阴极得电子数，混淆元素失去电子数会导致质量计算错误。

代表题精讲

代表题：2010 全国新课标·08（节选精炼部分）

题目：物质 A～G 有转化关系，A 为某金属矿主要成分，经过一系列反应得 B 和 C；单质 C 可与 E 的浓溶液反应，G 为砖红色沉淀。流程中涉及电解精炼获得纯金属 C。（设问要求书写精炼的电极反应、分析电解质变化、计算阳极泥等）

思路：由砖红色沉淀 G 常为 Cu₂O，结合矿石主要成分及与浓溶液反应等特征，可推知 C 为 Cu，A 可能为黄铜矿（CuFeS₂）或辉铜矿（Cu₂S）。粗铜经电解精炼得到精铜 C。
步骤：
1. 明确精炼体系：阳极——粗铜（含 Zn、Fe、Ag、Au 等）；阴极——精铜；电解液——CuSO₄ 溶液。
2. 书写反应：
阳极：$ \mathrm{Cu - 2e^- = Cu^{2+}} $（主反应），$ \mathrm{Zn - 2e^- = Zn^{2+}} $，$ \mathrm{Fe - 2e^- = Fe^{2+}} $，Ag、Au 不反应，沉入阳极泥；
阴极：$ \mathrm{Cu^{2+} + 2e^- = Cu} $。
3. 分析溶液中离子浓度：$ c(\mathrm{Cu^{2+}}) $ 基本不变，$ c(\mathrm{Zn^{2+}}) $、$ c(\mathrm{Fe^{2+}}) $ 增大。
4. 定量问题：若已知粗铜质量、杂质含量及电流量，可用电子守恒求出阴极增重或阳极泥质量。

点评/变式：该题将元素推断与电解精炼结合，抓住特征物质（Cu₂O）和典型反应（Cu+浓硫酸）是突破口。变式可换为精炼银（阳极泥含 Au 等），放电顺序与电解质选择需相应调整。
