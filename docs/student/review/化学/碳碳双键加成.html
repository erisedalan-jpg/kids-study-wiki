碳碳双键加成

知识精要

碳碳双键($\ce{C=C}$)是有机物中典型的不饱和键，其加成反应是高考必考点。核心知识如下： - 定义：试剂与双键两端的碳原子结合，碳碳双键中的$\pi$键断裂，形成两个新的$\sigma$键，原子利用率可达100%。 - 常见加成反应： - 与$\ce{H2}$加成（催化加氢）：$\ce{-CH=CH- + H2 ->[催化剂][\Delta] -CH2-CH2-}$。苯环可在更苛刻条件下加氢。 - 与卤素加成：$\ce{-CH=CH2 + Br2/CCl4 -> -CHBr-CH2Br}$，溴水或溴的四氯化碳溶液褪色，用于鉴别。 - 与卤化氢加成：$\ce{-CH=CH2 + HX -> -CHX-CH3}$（马氏规则：氢加在氢多的碳上，但有过氧化物效应时反马）。 - 与水加成：$\ce{-CH=CH2 + H2O ->[催化剂] -CHOH-CH3}$（工业制醇）。 - 与苯环加成的区别：苯环虽可加成，但条件更苛刻（较高温、压），而碳碳双键较活泼，易加成。若分子中同时含双键和苯环，双键优先发生加成。 - 适用条件：主要针对烯烃、炔烃、二烯烃等含有碳碳不饱和键的有机物；苯乙烯等既含双键又含苯环，选择合适的条件可实现选择性加成。

解题方法与套路

此类题多为判断有机物性质的正误，可用下列步骤快速锁定答案： 1. 识别官能团与反应位点：明确分子中含哪些键（碳碳双键、苯环、烷基侧链等），分别对应什么特征反应。 2. 匹配条件与产物： - 碳碳双键的加成：通常用$\ce{Ni}$催化加氢、常温下与卤素/卤化氢加成。 - 苯环的取代与加成：苯环易取代难加成；侧链烷基在光照下发生自由基取代（如$\ce{Cl2/光照}$取代$\alpha$-H）。 - 区分“条件”陷阱：甲苯与氯气在光照条件下反应发生在侧链甲基（碳氢键均裂），而在$\ce{FeCl3}$催化下才在苯环上取代。 3. 逐项检验：对每个选项，写出反应式或关键中间过程，检查官能团转化是否符合规律。 4. 注意“主要产物”：题目强调主要产物时，必须按照反应选择性判断。若出现“主要生成2,4-二氯甲苯”之类违反区域选择性的叙述，可直接判定错误。

高频易错

  • 混淆加成与取代条件：甲苯在光照下是侧链烷基的氢被氯取代，不是苯环氢被取代，误选D项正确是本题典型失分点。
  • 忽略苯环的加成能力：误以为苯环不能加成，导致认为B项错误。实际上苯环与碳碳双键均能催化加氢，苯乙烯加氢可生成乙基环己烷。
  • 反应试剂与现象对应不清：乙烯使溴水褪色是加成，使酸性$\ce{KMnO4}$褪色是氧化，不可混用。
  • 马氏规则误用：不对称烯烃与$\ce{HX}$加成时，氢加在含氢多的双键碳上，产物为主；但有过氧化物存在时反马加成，需注意条件。
  • 审题漏看“错误”：题干要求选“错误的”，但经常有考生看到A正确就选A，导致无谓失分。

代表题精讲

题目（2013新课标Ⅱ-02）下列叙述中，错误的是
A．苯与浓硝酸、浓硫酸共热并保持55～60℃反应生成硝基苯
B．苯乙烯在合适条件下催化加氢可生成乙基环己烷
C．乙烯和溴的四氯化碳溶液反应生成1,2-二溴乙烷
D．甲苯与氯气在光照下反应主要生成2,4-二氯甲苯

思路
本题核心考查碳碳双键加成与苯及其同系物反应的选择性。通过逐一分析每个选项中的反应类型、条件和主要产物，找出与有机反应规律不符的叙述。

步骤
- A项：苯的硝化反应是亲电取代，条件正确，产物硝基苯，正确。
- B项：苯乙烯含碳碳双键和苯环。催化加氢时，双键先被加成为乙基苯，苯环继续加氢得乙基环己烷，合理，正确。
- C项：乙烯与溴发生亲电加成，得到1,2-二溴乙烷，正确。
- D项：甲苯在光照下发生侧链甲基上的自由基取代反应，主要产物为苄基氯（一氯甲基苯），继续取代可得侧链多氯代物，而苯环上的氯代（生成2,4-二氯甲苯）需$\ce{FeCl3}$催化。故D项叙述错误。

点评/变式
本题D项陷阱极为典型——考查“光照条件”与“催化剂条件”的本质区别。变式训练：判断“甲苯与氯气在氯化铁存在下反应主要生成苄基氯”是否正确？答案：错误，此种条件得邻、对位苯环氯代产物。解题时务必看清反应位点是侧链还是苯环，抓住条件与反应类型的内在联系。碳碳双键加成的温和性和苯环取代的条件依赖性，是有机选择题的重要分水岭。
