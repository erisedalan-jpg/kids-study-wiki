碳酸氢钠性质

考点碳酸氢钠性质权重7真题数1学科化学父主题元素化合物

考点定位

  • 父主题：元素化合物
  • 权重 weight：7
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 化学式与俗称：碳酸氢钠（$NaHCO_3$），俗称小苏打，白色细小晶体，易溶于水，溶液呈弱碱性。
  • 热不稳定性：$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2!\uparrow$。受热分解产生 $CO_2$ 是其在食品加工中作膨松剂的核心原理。
  • 与酸反应：$NaHCO_3 + H^+ \rightarrow Na^+ + H_2O + CO_2!\uparrow$，反应剧烈程度弱于 $Na_2CO_3$，常用于治疗胃酸过多、泡沫灭火器。
  • 用途体系
  • 食品工业：发酵粉（膨松剂），面食加工时中和有机酸并受热产气，使面团松软多孔。
  • 医药：口服缓解胃酸过多（须注意产气副作用）。
  • 消防：与硫酸铝混合生成泡沫灭火剂。
  • 对比易混物
  • 纯碱（$Na_2CO_3$）：热稳定性强，不分解，需与酸或酸性物质配合才能产气。
  • 铅笔芯成分是石墨与黏土，不是铅或二氧化铅。
  • 合金（青铜、黄铜）属于混合物，不是单质。
  • 钠元素的焰色反应为黄色，钾元素为紫色（透过蓝色钴玻璃），红色焰火多来源于锶（$Sr$）或锂（$Li$）盐。

  1. 物质用途溯源法：直接回忆该物质核心化学性质，将这些性质与用途“搭桥”。如 $NaHCO_3$ 的“受热产气”直接对应“膨松剂”。
  2. 化学常识秒杀法：高考试题中常见生活化学陷阱，熟记下列高频点可快速排除：
  3. 铅笔芯→石墨，不是铅；水银→汞，不是银；纯碱→$Na_2CO_3$，不是碱；干冰→$CO_2$，不是冰。
  4. 合金、溶液、矿石等均属混合物，叙述为“单质”或“纯净物”时立刻排除。
  5. 焰色反应颜色记忆锚点：$Na$ 黄、$K$ 紫（蓝钴玻璃）、$Ca$ 砖红、$Cu$ 绿、$Sr$ 洋红。选项中出现“红色来自钠”可直接判错。
  6. 二步拆解选择题：第一步，挑出自己绝对肯定的选项（如本题的 $NaHCO_3$ 作膨松剂）；第二步，若时间紧迫直接锁定，若有时间再对其他选项做“成分/类别/原理”核对，保证正确率。

高频易错

  • 铅笔芯不是铅：主成分为石墨，误写成“二氧化铅”或“金属铅”必错。
  • 合金是混合物：青铜（$Cu!-!Sn$ 为主）、黄铜（$Cu!-!Zn$ 为主）等均为混合物，描述为“单质铜”或“有固定组成的纯净物”直接判错。
  • 焰色反应颜色张冠李戴：$Na$ ∉ 红色，$Na$ 为黄色。红色焰火常来自 $Sr^{2+}$（洋红）或 $Li^+$（紫红），切勿将“钠盐”与“红色”绑定。
  • $NaHCO_3$ 与 $Na_2CO_3$ 热稳定性混淆：$NaHCO_3$ 受热易分解，$Na_2CO_3$ 受热不分解。若题干要求“直接加热产气体”只能选碳酸氢钠或碳酸氢铵等不稳定盐。
  • 膨松剂原理理解不全：碳酸氢钠产气有两路——与酸性物质（如乳酸、柠檬酸）反应产气＋受热自身分解产气，两者协同使面团蓬松。

代表题精讲

代表题：2022·全国乙卷·第1题

题目
判断下列说法是否正确：A．$HB$ 铅笔芯成分为二氧化铅；B．碳酸氢钠可做食品膨松剂；C．青铜和黄铜是不同结构的单质铜；D．焰火中红色来源于钠盐灼烧。

思路
这是一道以生活为载体考查元素化合物基础知识的“送分题”。应逐一核对选项所涉物质的真实成分、类别和性质，利用热稳定性、合金概念、焰色反应等核心知识点快速排除错误选项，锁定正确答案。

步骤
1. 审选项 A：铅笔芯的主要成分是石墨和黏土，不含铅或二氧化铅 ($PbO_2$)。$Pb$ 有毒，不会用于文具。A 错误。
2. 审选项 B：$NaHCO_3$ 不稳定，受热分解：$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + H_2O + CO_2!\uparrow$，产生的 $CO_2$ 气体使面团膨胀松软，还可在加工时与有机酸反应，双重起发。符合膨松剂原理，B 正确。
3. 审选项 C：青铜（$Cu!-!Sn$ 合金）和黄铜（$Cu!-!Zn$ 合金）均是混合物，不是铜的单质，更谈不上“不同结构的单质”。C 错误。
4. 审选项 D：$Na$ 的焰色为黄色，不是红色。常考红色焰火是锶 ($Sr$) 或锂 ($Li$) 盐。D 错误。
5. 结论：只有 B 正确，故选 B。

点评/变式
此题核心陷阱在于“生活常识模糊化”。考生常因铅笔名中带“铅”误判 A，因“钠盐”定式思维误选 D。
- 变式预测：可改为“做发酵粉、治疗胃酸过多均利用同一种盐的何种性质”，考查 $NaHCO_3$ 与酸反应、热分解的多用途统一性。
- 延伸注意：若题干将碳酸氢钠换为碳酸钠，应意识到 $Na_2CO_3$ 热稳定性强，直接加热不产气，只能通过与酸反应产气，一般不单独用作膨松剂。
