离子方程式

考点离子方程式权重21真题数3学科化学父主题离子反应

考点定位

  • 父主题：离子反应
  • 权重 weight：21
  • 真题数：3；年份跨度：2010–2021
  • 出现题位：选择3 选择7 选择11
  • 难度分布：中3

知识精要

  1. 离子方程式：用实际参加反应的离子符号表示化学反应的式子。可拆写成离子的物质包括：强酸、强碱、可溶性盐（需满足“一溶二电离”）。不可拆分的物质包括：弱电解质（弱酸、弱碱、水）、沉淀、气体、氧化物、非电解质、单质。
  2. 核心书写规则：
  3. 客观事实：必须符合化学反应原理，不能主观臆造产物。特别注意：氧化还原反应中，硝酸的氧化性由 $NO_3^-$ 在酸性环境下体现，而非 $H^+$。
  4. 质量守恒与电荷守恒：方程式两边各元素原子总数相等，且总电荷数必须相等。
  5. 定量配比：反应物中阴阳离子的配比必须符合其化学式组成，且当涉及“少量/过量/等物质的量”反应时，需严格依据离子反应的先后顺序和定量关系书写。
  6. 特殊反应原理：
  7. 盐类水解：如明矾（$KAl(SO_4)_2·12H_2O$）中的 $Al^{3+}$ 水解显酸性，方程式为 $Al^{3+} + 3H_2O \rightleftharpoons Al(OH)_3 + 3H^+$。
  8. 沉淀转化：如 $CaSO_4$ 水垢处理，其原理是用 $CO_3^{2-}$ 将微溶的 $CaSO_4$ 转化为更难溶的 $CaCO_3$，离子方程式为 $CaSO_4(s) + CO_3^{2-}(aq) \rightleftharpoons CaCO_3(s) + SO_4^{2-}(aq)$。注意：$CaSO_4$ 作为微溶物在反应物中写化学式，$CaCO_3$ 是难溶物也在生成物中写化学式。

解题方法与套路

  1. 审“拆”法：快速扫描反应物与生成物的化学式，确认物质状态与溶解性。
  2. 拆错必错：如难溶的碳酸镁（$MgCO_3$）写成 $CO_3^{2-}$，该选项直接判定为错误。
  3. 原理“三查”法：
  4. 一查反应能否发生：是否违背强制弱（如强酸制弱酸）、高沸点酸制低沸点酸、氧化还原强弱规律。
  5. 二查产物是否正确：特别是涉及氧化性酸（如 $HNO_3$）时，金属与硝酸反应不生成 $H_2$，而是生成氮氧化物；铁与卤素、硝酸等强氧化剂反应产物是 $Fe^{3+}$，而非 $Fe^{2+}$。
  6. 三查离子配比与数量：反应物电离出的离子数目比必须符合化学式。
  7. 定量“先强后弱”法：对于氧化还原反应（如 $FeBr_2$ 与 $Cl_2$），遵循还原性强的离子先反应原则（还原性：$Fe^{2+} > Br^-$）。等物质的量反应时，离子方程式中的化学计量数必须严格按实际参与反应的离子比例书写。
  8. 守恒验证法：最后一步必须同时验证元素守恒和电荷守恒。漏写参与非氧化还原核心反应的离子（如 $NH_4^+$ 与 $SO_4^{2-}$ 反应体系中遗漏 $Ba^{2+}$ 与氨水），会导致方程式不完整。

高频易错

  • 产物臆造陷阱：典型错例为 $Fe_3O_4$ 或活泼金属与稀硝酸反应误写为置换出 $H_2$。稀硝酸的氧化性源于 $NO_3^-$ 在酸性条件下的强氧化性，应还原为 $NO$。
  • 拆分原则误判：
  • 微溶物处理：作为反应物且为澄清态可拆，若为浑浊态（如石灰乳）或作为生成物（如 $CaSO_4$、$CaCO_3$）均不可拆，须写化学式。
  • 难溶物：如 $MgCO_3$、$BaSO_4$、$AgCl$ 等无论出现在反应物还是生成物侧，一律不可拆。
  • 复杂配比失误：
  • 离子方程式只写一半。例如，$Ba(OH)_2$ 与 $(NH_4)_2SO_4$ 反应，不仅是 $Ba^{2+}$ 与 $SO_4^{2-}$ 反应，碱与铵盐还会产生 $NH_3·H_2O$（加热写 $NH_3$），离子方程式必须完整反映所有实际发生的离子组合。
  • $FeBr_2$ 与等物质的量 $Cl_2$ 反应，只氧化了 $Fe^{2+}$ 和一半的 $Br^-$。错例为将化学计量数写成 $1:2$ 或认为 $Br^-$ 完全未被氧化。
  • 水解与电离混淆：明矾水溶液显酸性是因 $Al^{3+}$ 水解，而非直接电离出 $H^+$，且水解极其微弱，须用可逆号“$\rightleftharpoons$”，不写“$\downarrow$”或“$\uparrow$”。

代表题精讲

题目：（2010全国新课标）下表中评价合理的是……（考查 $Fe_3O_4$ 与硝酸、碳酸镁与盐酸、硫酸铵与氢氧化钡、$FeBr_2$ 与等量 $Cl_2$ 反应的离子方程式正误判断） 思路：利用“原理三查法”，依次排查氧化还原合理性、物质拆分准确性、离子反应完整性及定量配比的正确性。 步骤： 1. A项：$Fe_3O_4$ 含 $+2$ 价铁，稀硝酸将其氧化的同时自身被还原为 $NO$，而非 $H_2$。评价“正确”错误。 2. B项：$MgCO_3$ 为难溶性碳酸盐，在离子方程式中不能拆写成 $CO_3^{2-}$ 形式。评价“错误”，且评价理由表述完全符合事实，该项合理。 3. C项：$Ba(OH)_2$ 与 $(NH_4)_2SO_4$ 反应，除生成 $BaSO_4$ 沉淀外，$OH^-$ 与 $NH_4^+$ 也会反应生成弱电解质 $NH_3·H_2O$，离子方程式遗漏了该反应。评价“正确”错误。 4. D项：还原性强弱顺序为 $Fe^{2+} > Br^-$。$Cl_2$ 先氧化 $Fe^{2+}$。$1~mol$ $FeBr_2$ 电离出 $1~mol~Fe^{2+}$ 和 $2~mol~Br^-$，与等物质的量的 $1~mol~Cl_2$ 反应，$Cl_2$ 恰好得 $2~mol$ 电子，将 $1~mol~Fe^{2+}$ 氧化需消耗 $0.5~mol~Cl_2$，剩余 $0.5~mol~Cl_2$ 将氧化 $1~mol~Br^-$。离子方程式 $2Fe^{2+}+2Br^-+2Cl_2 = 2Fe^{3+}+4Cl^-+Br_2$ 完全正确。评价“错误”错。 点评/变式：本题利用表格评价形式，综合考查离子方程式的多个核心判断维度。变式训练可设计为对错例的完整纠正书写，如正确书写 A、C 项离子方程式，以强化“硝酸还原产物”和“复杂体系离子反应完整性”的意识。

题目：（2021-全国乙）判断“用碳酸钠溶液处理水垢中的硫酸钙”的离子方程式正误。 思路：本题属于“沉淀转化”原理的直接应用，考查微溶物与难溶物的书写规则。 步骤： 1. 分析原理：除水垢利用沉淀转化的原理，即由微溶的硫酸钙（$CaSO_4$）转化为更难溶的碳酸钙（$CaCO_3$）。 2. 审析拆分：$CaSO_4$ 尽管是盐且以固体形式附着在水垢中，但其作为微溶物，在反应物一侧须写化学式；碳酸钠可溶，拆写为 $CO_3^{2-}$；生成的 $CaCO_3$ 难溶，写化学式且加沉淀符号；$SO_4^{2-}$ 可溶拆写。题干离子方程式 $CaSO_4 + CO_3^{2-} = CaCO_3 + SO_4^{2-}$ 客观严谨地反映该原理，选项正确。 点评/变式：本题的核心陷阱在于诱导考生将微溶物 $CaSO_4$ 错拆为离子（“钙离子+硫酸根”），从而强行将其判定为错误。复习中务必明确规则：绝大多数微溶物在反应物中的状态决定了它通常作为“浊液或固体书写化学式”，仅在“澄清溶液”的特殊语境中才可拆。
