离子方程式书写

考点离子方程式书写权重23真题数5学科化学父主题离子反应

考点定位

  • 父主题：离子反应
  • 权重 weight：23
  • 真题数：5；年份跨度：2009–2024
  • 出现题位：解答16 选择6 选择8
  • 难度分布：中4 难1

知识精要

  • 定义：用实际参加反应的离子符号表示离子反应的式子。
  • 书写原则：
  • 客观事实原则：符合反应实际，不能凭空臆造产物或反应物（如浓 $H_2SO_4$ 与金属反应不生成 $H_2$）。
  • 质量守恒：反应前后原子种类、数目不变。
  • 电荷守恒：离子方程式两边总电荷相等。
  • 电子得失守恒（氧化还原反应）：还原剂失电子总数等于氧化剂得电子总数。
  • 拆分规则：
  • 可拆为离子：强酸（$HCl、HNO_3、H_2SO_4$ 等）、强碱（$NaOH、KOH、Ba(OH)_2$ 等）、可溶性盐。
  • 不可拆（写化学式）：单质、氧化物、弱电解质（$H_2O$、弱酸、弱碱）、难溶物（沉淀）、气体、浓硫酸（一般写化学式）。
  • 定量离子反应：
  • 遵循“少量”与“过量”规则：一种反应物过量时，产物按量少的物质计量完全反应确定。
  • 多重反应顺序（如氧化还原）：强氧化剂/还原剂优先反应。例如还原性 $Fe^{2+} > Br^-$，通入 $Cl_2$ 时 $Fe^{2+}$ 先被氧化。
  • 条件对产物的影响：
  • 酸碱性条件：高价金属含氧酸盐的生成需强碱条件（如 $FeO_4^{2-}$ 由 $Fe^{3+}$ 在浓碱中氧化制得）。
  • 氧化性酸与还原性物质反应，硝酸将 $FeS$ 氧化为 $Fe^{3+}$、$SO_4^{2-}$ 等，不生成 $Fe^{2+}$ 和 $H_2S$。
  • 配平技巧：对于氧化还原离子方程式，常在酸性介质中补 $H^+$（生成 $H_2O$），碱性介质中补 $OH^-$（生成 $H_2O$）。

解题方法与套路

  1. 判断反应类型：是非氧化还原（复分解/沉淀/水解/配合）还是氧化还原。非氧化还原优先关注沉淀、气体、弱电解质生成；氧化还原关注化合价变化及反应条件。
  2. 分析介质与用量：
  3. 酸碱性环境决定 $H^+$ 或 $OH^-$ 的参与及产物的形态（如 $FeO_4^{2-}$ 需强碱）。
  4. “少量/过量”决定产物种类：如少量 $SO_2$ 通入苯酚钠生成 $SO_3^{2-}$，过量生成 $HSO_3^-$（题中少量 $SO_2$ 却错写为 $HSO_3^-$）。
  5. 氧化还原顺序：多种还原剂与氧化剂反应时，强还原剂优先反应（如 $Fe^{2+}>Br^-$），按比例逐步书写并配平。
  6. 拆分检查：将可溶性强电解质拆成离子，其余保留化学式。特别注意醋酸等弱酸应写分子。
  7. 三守恒验证：
  8. 原子守恒：逐一核对各元素。
  9. 电荷守恒：左右总电荷必须相等。
  10. 电子守恒（氧化还原）：可通过标化合价确认电子转移数目。
  11. 结合化学计算推导化学式：通过滴定数据找出离子物质的量之比，再写出对应离子方程式（如由 $n(Cl^-):n(Fe)$ 确定 $FeCl_x$ 组成，进而书写相关反应）。

高频易错

  • 弱电解质误拆：醋酸、次氯酸、$NH_3·H_2O$ 等必须写分子式，不能拆成离子。
  • 浓酸处理错：浓 $H_2SO_4$ 一般不拆，浓 $HCl$、浓 $HNO_3$ 参与反应时要看实际情况，一般浓 $HNO_3$ 还原产物为 $NO_2$，但浓 $H_2SO_4$ 分子形式参与反应。
  • 忽略氧化性酸的特殊性：稀/浓 $HNO_3$、浓 $H_2SO_4$ 与还原性物质（如 $FeS$、$FeO$、$HI$）发生氧化还原，不能写成简单的酸溶解反应。例如 $FeS$ 遇稀 $HNO_3$ 被氧化成 $Fe^{3+}$、$S$ 或 $SO_4^{2-}$，并非 $Fe^{2+}$ 和 $H_2S$。
  • 遗漏离子反应：多元弱酸的酸式盐与碱反应时，若碱过量，$NH_4^+$、$HCO_3^-$ 都参与反应，不能只写 $HCO_3^-$。
  • 过量问题产物错误：少量 $SO_2$ 与苯酚钠生成 $SO_3^{2-}$ 而不是 $HSO_3^-$，且不能忽视苯酚的弱酸性。
  • 氧化还原顺序搞错：$FeBr_2$ 溶液通入 $Cl_2$，必须遵循 $Fe^{2+}>Br^-$ 的还原性顺序；若先写 $Br^-$ 氧化为 $Br_2$，则与实际相悖。
  • 电荷或电子不守恒：忘记在酸性条件下加 $H^+$，碱性条件下加 $OH^-$，导致方程式两边电荷不相等。

代表题精讲

代表题一：2011-新课标-06（离子方程式正误判断）

题目：判断四个选项的离子方程式正误，涉及 $FeS$ 与稀硝酸、$NH_4HCO_3$ 与过量 $NaOH$、少量 $SO_2$ 通入苯酚钠、大理石与醋酸。

思路：逐一审查是否违背拆分规则、反应事实、量的关系及反应环境。 步骤： - A项：$FeS$ 被稀 $HNO_3$ 氧化，应生成 $Fe^{3+}$、$S$ 或 $SO_4^{2-}$ 和 $NO$，不能简单写成置换出 $H_2S$，错误。 - B项：$NH_4HCO_3$ 过量 $NaOH$，$NH_4^+$ 也会反应生成 $NH_3·H_2O$，方程式漏写该反应，错误。 - C项：少量 $SO_2$ 通入苯酚钠，应生成 $SO_3^{2-}$，不是 $HSO_3^-$，错误。 - D项：$CaCO_3$ 难溶、$CH_3COOH$ 弱酸保留化学式，产物 $Ca^{2+}$、$CH_3COO^-$、$CO_2$、$H_2O$ 拆分正确，守恒，正确。 点评/变式：正误判断需重点突破“量少定产物”和“氧化性酸不按常规出牌”。变式：将 $FeS$ 换成 $FeO$ 与稀硝酸，离子方程式应为 $3FeO + 10H^+ + NO_3^- = 3Fe^{3+} + NO↑ + 5H_2O$。

代表题二：2012-新课标-08（含计算的离子方程式书写）

题目：通过离子交换滴定测定 $FeCl_x$ 中 $x$ 值，书写 $FeCl_3$ 与 $HI$ 的反应、$FeCl_3$ 在强碱性下被 $KClO$ 氧化成 $K_2FeO_4$ 的离子方程式，以及碱性 $K_2FeO_4-Zn$ 电池的正极和总反应离子方程式。

思路：由计量关系确定反应物配比，再将反应物拆写为离子，结合介质条件配平。 步骤： - 由滴定得 $n(Cl^-)=0.010 mol$，$m(Fe)=0.54-0.010×35.5=0.185g$，$n(Fe)=0.0033 mol$，$n(Fe):n(Cl) ≈ 1:3$，得 $x=3$，即物质为 $FeCl_3$。 - $FeCl_3$ 与 $HI$ 氧化还原：$Fe^{3+} + I^- → Fe^{2+} + I_2$，配平：$2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$。 - $FeCl_3$ 与 $KClO$ 碱性反应生成 $FeO_4^{2-}$：碱性环境应补 $OH^-$ 平衡电荷和原子。$Fe^{3+} → FeO_4^{2-}$ 升3，$ClO^- → Cl^-$ 降2，取最小公倍数6，故 $2Fe^{3+} + 3ClO^-$，右边补 $10OH^-$ 生成 $5H_2O$，得：$2Fe^{3+} + 3ClO^- + 10OH^- = 2FeO_4^{2-} + 3Cl^- + 5H_2O$。 - 电池：正极 $FeO_4^{2-}$ 在碱性水环境中得电子生成 $Fe(OH)_3$ 并放出 $OH^-$：$FeO_4^{2-} + 3e^- + 4H_2O = Fe(OH)_3 + 5OH^-$；负极 $Zn$ 失电子在碱性下生成 $Zn(OH)_2$：$Zn - 2e^- + 2OH^- = Zn(OH)_2$；总反应叠加得 $3Zn + 2FeO_4^{2-} + 8H_2O = 3Zn(OH)_2 + 2Fe(OH)_3 + 4OH^-$。 点评/变式：此类题将离子方程式融入计算和电化学，关键是抓住化合价升降配平并视介质补 $H_2O$ 和 $H^+$/$OH^-$。变式：$K_2FeO_4$ 在酸性下得电子产物为 $Fe^{3+}$，电极反应变为 $FeO_4^{2-} + 8H^+ + 3e^- = Fe^{3+} + 4H_2O$。

代表题三：2024-辽宁-16（流程中的离子方程式）

题目：细菌冶金处理载金硫化矿粉（含 $FeS$、$FeAsS$ 包裹金），通过“细菌氧化”使金属硫化物转化为硫酸盐，提高金的浸出率，冶炼金。需写出核心氧化反应的离子方程式。

思路：根据细菌氧化将硫化物转化为硫酸盐，硫元素被氧化为 $SO_4^{2-}$，$Fe$ 通常被氧化为 $Fe^{3+}$，反应环境在酸性溶液（硫杆菌代谢产物提供酸）中进行。 步骤： - $FeS$ 氧化：$FeS$ 中 $Fe(+2)$ → $Fe^{3+}$，升1，$S(-2)$ → $SO_4^{2-}$（+6），升8，总共升9；$O_2$ 作氧化剂，1个 $O_2$ 降4。为配平电子，需 $4FeS + 9O_2$ 参与，酸性条件补 $H^+$、生成水。总反应：$4FeS + 9O_2 + 4H^+ \xrightarrow{细菌} 4Fe^{3+} + 4SO_4^{2-} + 2H_2O$。但细菌氧化通常为水溶液中的氧气参与，方程需配平，常见离子方程式为 $4Fe^{2+} + O_2 + 4H^+ \xrightarrow{细菌} 4Fe^{3+} + 2H_2O$（若先溶解），然而题干指明硫化物转化为硫酸盐，故一步氧化可写为 $2FeS + 9O_2 + 4H^+ \xrightarrow{细菌} 2Fe^{3+} + 2SO_4^{2-} + 2H_2O$（应检查：2FeS提供$2Fe(+2)$→+6失去2电子? 失电子：Fe +2→+3失1×2，S -2→+6失8×2，总失18e；9O2得36e，不等。正确配平：$4FeS + 9O_2 + 4H^+ → 4Fe^{3+} + 4SO_4^{2-} + 2H_2O$，O2得36e，FeS失（1+8）×4=36e）。 - $FeAsS$ 氧化：$Fe$ +2→+3，$As$ -1→+5 失6e（常见产物 $H_3AsO_4$ 或 $AsO_4^{3-}$），$S$ -2→+6失8e，总失电子14+? 需查As常见价态，假设生成 $H_3AsO_4$，每个 $FeAsS$ 失电子：$Fe$ 升1，$As$ 升4（若产物为+5），$S$ 升8，共13e；O2得4e，配平可用适当系数。具体结合实际流程，可写成：$4FeAsS + 13O_2 + 6H_2O \xrightarrow{细菌} 4Fe^{3+} + 4H_3AsO_4 + 4SO_4^{2-}$ （电荷与原子配平）。 点评/变式：信息型离子方程式书写关键是从题干提取反应物、产物及介质，利用化合价升降守恒和原子守恒配平。生物氧化往往有 $O_2$ 参与，$H_2O$ 和 $H^+$ 作为介质补充。变式：若在碱性菌液中氧化，可能生成 $Fe(OH)_3$ 和 $SO_4^{2-}$，需相应调整。
