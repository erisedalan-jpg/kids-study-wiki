离子方程式书写

  • 父主题：离子反应
  • 权重 weight：23
  • 真题数：5；年份跨度：2009–2024
  • 出现题位：解答16 选择6 选择8
  • 难度分布：中4 难1

知识精要

  1. 书写规则：
  2. 拆写原则：强酸、强碱、可溶性盐拆成离子；弱电解质（弱酸、弱碱、水）、难溶物、气体、氧化物、单质均保留化学式。如醋酸（CH₃COOH）、碳酸钙（CaCO₃）、CO₂、Fe₂O₃、Cl₂等必须写化学式。
  3. 守恒原则：必须同时满足原子守恒、电荷守恒和得失电子守恒（若为氧化还原反应）。

  4. 客观事实：必须符合反应的实际产物。例如铁与稀硝酸反应不生成H₂，而是生成NO、Fe³⁺（或Fe²⁺，由量决定）。

  5. 氧化还原离子方程式的配平：

  6. 熟记常见氧化剂/还原剂对应产物：$ \text{MnO}_4^- \rightarrow \text{Mn}^{2+}\ (\text{酸性}) $，$ \text{ClO}^- \rightarrow \text{Cl}^- $，$ \text{Fe}^{3+} \rightarrow \text{Fe}^{2+} $，$ \text{I}^- \rightarrow \text{I}_2 $，$ \text{SO}_2 \rightarrow \text{SO}_4^{2-} $等。

  7. 使用电子守恒先配氧化剂、还原剂及其变价产物的系数，再加介质（H⁺/OH⁻/H₂O）配平电荷与质量。

  8. 与量有关的离子方程式：

  9. 少定多变：少量物质系数设为1，其参加反应的离子按组成比例参与；过量物质按需取用。
  10. 氧化还原顺序：多种还原剂与一种氧化剂反应，还原性强的优先反应（如 $ \text{Fe}^{2+} > \text{Br}^- $）。按比例分段书写。

  11. 酸碱反应顺序：如NH₄HCO₃与NaOH反应，OH⁻先与HCO₃⁻反应，再与NH₄⁺反应；过量时两者均反应。

  12. 依据氧化还原方向判断方程式正误：

  13. 自发进行的氧化还原反应满足“强制弱”规律：氧化性氧化剂 > 氧化产物，还原性还原剂 > 还原产物。否则不能自发进行。

解题方法与套路

  1. 离子方程式正误判断通用步骤：
  2. ① 看是否违背客观事实（产物是否合理，如硝酸参与是否生成NO而非H₂）。
  3. ② 看拆写是否正确（该拆不拆、不该拆拆了均为错）。
  4. ③ 看是否满足三守恒（电荷守恒最易忽略）。

  5. ④ 看“量”条件是否吻合（“少量”“过量”“等物质的量”等），检查反应先后顺序和产物比例。

  6. 氧化还原离子方程式书写步骤：

  7. ① 找变价元素，标化合价，确定氧化剂、还原剂及对应产物。
  8. ② 用电子守恒配平变价物质的系数。
  9. ③ 根据环境（酸性/碱性）添加H⁺或OH⁻配平电荷；不能在酸性环境添OH⁻，碱性环境添H⁺。

  10. ④ 最后用H₂O配平氢、氧原子。

  11. 涉及先后顺序的与量有关离子方程式写法：

  12. 先写分步反应，再按用量比例加和。
  13. 若为氧化还原，先标出全部还原剂的顺序和物质的量，用Cl₂等氧化剂按比例“吃”完一个再“吃”下一个，中间用量区间需写出正确叠加式。

高频易错

  1. 硝酸根离子在酸性条件下才会表现强氧化性。但“稀硝酸”或“硝酸”整体写入方程式时，HNO₃拆为H⁺和NO₃⁻，氧化性由HNO₃体现。忽视这一性质易将氧化还原反应错写为复分解反应（如FeS + H⁺ → Fe²⁺ + H₂S↑ 在硝酸中错误）。
  2. 铵根离子（NH₄⁺）与碱的反应易被漏写。例如NH₄HCO₃与过量NaOH，漏掉NH₄⁺ + OH⁻ → NH₃·H₂O会导致错误。
  3. 弱酸与弱酸盐反应产物的“酸根”形态取决于相对强弱和用量。如SO₂通入苯酚钠溶液：酸性：H₂SO₃ > 苯酚 > HSO₃⁻，因此无论少量还是过量SO₂，产物均为SO₃²⁻（或HSO₃⁻？实际上苯酚不能置换出HSO₃⁻中的H⁺，少量时生成SO₃²⁻，过量时生成HSO₃⁻。而题目中若写成HSO₃⁻在少量时正确与否要依据酸性比较，常见陷阱是忽略苯酚酸性比HCO₃⁻还弱的事实）。
  4. 氧化还原顺序导致“分段”方程式。如FeBr₂溶液通Cl₂，x=0.6a时只写Br⁻被氧化而漏写Fe²⁺被氧化，直接选B出错率极高。必须掌握：还原性Fe²⁺ > Br⁻，Cl₂先氧化全部Fe²⁺后才开始氧化Br⁻。
  5. 碱性介质中生成高价含氧酸盐的配平：易忘加OH⁻配平电荷，或加水配平氢氧时出错。如Fe³⁺与ClO⁻在强碱性生成FeO₄²⁻，碱性下ClO⁻还原产物是Cl⁻，必须添OH⁻平衡电荷。写成酸性条件下的H⁺是常见错误。
  6. 置换反应方向的判断：不能自发进行的反应（如Ag + Cd²⁺ → Ag⁺ + Cd）在离子方程式正误题中常设置错误选项，需结合金属活动性顺序或氧化还原方向识别。

代表题精讲

题目（2011-新课标-06）

能正确表示下列反应的离子方程式为
A．硫化亚铁溶于稀硝酸中：$ \text{FeS} + 2\text{H}^+ = \text{Fe}^{2+} + \text{H}_2\text{S} \uparrow $
B．NH₄HCO₃溶于过量的NaOH溶液中：$ \text{HCO}_3^- + \text{OH}^- = \text{CO}_3^{2-} + \text{H}_2\text{O} $
C．少量SO₂通入苯酚钠溶液中：$ \text{C}_6\text{H}_5\text{O}^- + \text{SO}_2 + \text{H}_2\text{O} = \text{C}_6\text{H}_5\text{OH} + \text{HSO}_3^- $
D．大理石溶于醋酸中：$ \text{CaCO}_3 + 2\text{CH}_3\text{COOH} = \text{Ca}^{2+} + 2\text{CH}_3\text{COO}^- + \text{CO}_2 \uparrow + \text{H}_2\text{O} $

思路：逐项用“客观事实→拆写→守恒→量”四步法判断。A硝酸有强氧化性，产物不符；B忽略NH₄⁺与碱反应；C量少应生成SO₃²⁻而非HSO₃⁻；D醋酸弱酸不拆，碳酸钙难溶，守恒正确。

步骤： - A选项：稀硝酸氧化性，FeS被氧化为Fe³⁺、SO₄²⁻（或S），不可能简单复分解出H₂S，错误。 - B选项：NaOH过量，NH₄⁺与OH⁻反应生成NH₃·H₂O，离子方程式漏写该反应，错误。 - C选项：少量SO₂，苯酚酸性远弱于H₂SO₃，但不能将SO₃²⁻转化为HSO₃⁻；正确产物应是SO₃²⁻：$ 2\text{C}_6\text{H}_5\text{O}^- + \text{SO}_2 + \text{H}_2\text{O} \rightarrow 2\text{C}_6\text{H}_5\text{OH} + \text{SO}_3^{2-} $，写成HSO₃⁻错误。 - D选项：醋酸弱酸写化学式，碳酸钙难溶写化学式，产物拆写正确，电荷及原子守恒，正确。

点评/变式：判断正误时“漏写”和“强制弱”氧化还原错误频率最高。变式：若将B改为“过量NaOH与NH₄HCO₃”，正确写法为 $ \text{NH}_4^+ + \text{HCO}_3^- + 2\text{OH}^- = \text{NH}_3 \cdot \text{H}_2\text{O} + \text{CO}_3^{2-} + \text{H}_2\text{O} $。

题目（2012-新课标-08节选）

(3) FeCl₃与氢碘酸反应生成棕色物质，写出离子方程式。
(4) FeCl₃和KClO在强碱性条件下反应生成K₂FeO₄，写出离子方程式。

思路：两问均为氧化还原离子方程式书写。(3)中Fe³⁺氧化I⁻生成I₂（棕色）和Fe²⁺，介质为酸性，不需额外添H⁺或OH⁻配平，只需按电子守恒配平即可。(4)中Fe³⁺被ClO⁻在强碱性条件下氧化为FeO₄²⁻，ClO⁻还原为Cl⁻，碱性介质要用OH⁻配平电荷，再用水配氢、氧。

步骤： - (3) 电子守恒：Fe³⁺得1e⁻→Fe²⁺，2I⁻失2e⁻→I₂，最小公倍数2，故Fe³⁺系数2，I⁻系数2，I₂系数1。检查电荷：左边总电荷 +4(2Fe³⁺) -2(2I⁻)=+2，右边+2(2Fe²⁺)，守恒。原子守恒。离子方程式：$ 2\text{Fe}^{3+} + 2\text{I}^- = 2\text{Fe}^{2+} + \text{I}_2 $。 - (4) 变价：Fe³⁺→FeO₄²⁻，铁化合价由+3升到+6，升3；ClO⁻→Cl⁻，氯由+1降到-1，降2。电子最小公倍数6，故Fe³⁺系数2，ClO⁻系数3。暂写：$ 2\text{Fe}^{3+} + 3\text{ClO}^- \rightarrow 2\text{FeO}_4^{2-} + 3\text{Cl}^- $。碱性条件，右边电荷总和 -4(2×-2) -3 = -7，左边 +6(2×+3) -3 = +3，相差10个负
