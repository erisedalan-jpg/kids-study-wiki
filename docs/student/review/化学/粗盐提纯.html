粗盐提纯

知识精要

  1. 粗盐成分：主要含 NaCl，另含不溶性泥沙及可溶性杂质离子 $\mathrm{Ca^{2+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{SO_4^{2-}}$。
  2. 除杂原理：不溶性杂质通过溶解、过滤除去；可溶性杂质采用化学沉淀法转化为难溶物后过滤，再通过调 pH、蒸发结晶获得精制 NaCl。
  3. 除杂试剂及顺序（核心）：
  4. 先加过量 $\mathrm{BaCl_2}$ 除 $\mathrm{SO_4^{2-}}$：$\mathrm{Ba^{2+} + SO_4^{2-} \rightarrow BaSO_4\downarrow}$
  5. 再加过量 $\mathrm{NaOH}$ 除 $\mathrm{Mg^{2+}}$：$\mathrm{Mg^{2+} + 2OH^- \rightarrow Mg(OH)_2\downarrow}$
  6. 再加过量 $\mathrm{Na_2CO_3}$ 除 $\mathrm{Ca^{2+}}$ 及上步引入的过量 $\mathrm{Ba^{2+}}$：
    $\mathrm{Ca^{2+} + CO_3^{2-} \rightarrow CaCO_3\downarrow}$，$\mathrm{Ba^{2+} + CO_3^{2-} \rightarrow BaCO_3\downarrow}$
  7. 顺序要求：$\mathrm{Na_2CO_3}$ 必须在 $\mathrm{BaCl_2}$ 之后加入，确保 $\mathrm{Ba^{2+}}$ 被除去；过滤后再向滤液加适量盐酸中和过量 $\mathrm{OH^-}$ 与 $\mathrm{CO_3^{2-}}$，调至中性（或微酸性）。
  8. 生产实际：工业上常用生石灰 (CaO) ** 或石灰乳作沉淀剂，更经济；提纯最终步骤常包含重结晶**以提高纯度。
  9. 相关海水利用：苦卤中通 $\mathrm{Cl_2}$ 提取 $\mathrm{Br_2}$，富集溴可采用空气吹出后用 $\mathrm{SO_2}$ 还原吸收（$\mathrm{SO_2 + Br_2 + 2H_2O \rightarrow H_2SO_4 + 2HBr}$）。

解题方法与套路

  1. 锁定杂质种类：审题时标出粗盐中的 $\mathrm{Ca^{2+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{SO_4^{2-}}$ 及不溶物。
  2. 对应沉淀剂选择：
  3. $\mathrm{SO_4^{2-}}$ → 可溶性钡盐（$\mathrm{BaCl_2}$，忌用 $\mathrm{Ba(NO_3)_2}$ 引入新杂质 $\mathrm{NO_3^-}$）
  4. $\mathrm{Mg^{2+}}$ → 强碱（$\mathrm{NaOH}$ 或石灰乳）
  5. $\mathrm{Ca^{2+}}$ → 可溶性碳酸盐（$\mathrm{Na_2CO_3}$），同时兼除过量的 $\mathrm{Ba^{2+}}$
  6. 排序策略：只要满足 “$\mathrm{Na_2CO_3}$ 加在 $\mathrm{BaCl_2}$ 之后，过滤前加完”，其他顺序可灵活（如 $\mathrm{BaCl_2} \rightarrow \mathrm{NaOH} \rightarrow \mathrm{Na_2CO_3}$ 或 $\mathrm{NaOH} \rightarrow \mathrm{BaCl_2} \rightarrow \mathrm{Na_2CO_3}$ 均可）。
  7. 滤后酸化：过滤向滤液中滴加稀盐酸，除去过量 $\mathrm{NaOH}$ 和 $\mathrm{Na_2CO_3}$，调 pH 呈中性，防止引入新杂质。
  8. 结晶选择：若需高纯 NaCl，通常经过蒸发结晶、重结晶；若题目中只要求“得到精盐”，重结晶可进一步提升纯度。
  9. 判断正误时，注意工业实际与实验室试剂的区别：工业沉淀剂多用廉价石灰，不宜直接选用价格较高的 NaOH。

高频易错

  • 除杂顺序颠倒：误以为先除 $\mathrm{Ca^{2+}}$ 或先加 $\mathrm{Na_2CO_3}$ 均可，实则 $\mathrm{Na_2CO_3}$ 若加在 $\mathrm{BaCl_2}$ 前，则后续加的 $\mathrm{BaCl_2}$ 会引入新 $\mathrm{Ba^{2+}}$ 无法除去。
  • 忽略过量试剂的去除：忘记对引入的过量 $\mathrm{Ba^{2+}}$、$\mathrm{OH^-}$、$\mathrm{CO_3^{2-}}$ 进行处理，直接蒸发导致产品不纯。
  • 酸化时机错误：向沉淀与溶液混合物中加入盐酸后再过滤，导致部分沉淀（$\mathrm{Mg(OH)_2}$、$\mathrm{CaCO_3}$ 等）重新溶解，除杂失败。必须先过滤，后向滤液加盐酸。
  • 沉淀剂选择不当：用 $\mathrm{Ba(NO_3)_2}$ 除 $\mathrm{SO_4^{2-}}$ 会引入 $\mathrm{NO_3^-}$；用 $\mathrm{KOH}$ 除 $\mathrm{Mg^{2+}}$ 引入 $\mathrm{K^+}$ 等，违背“不增”原则。
  • 工业沉淀剂误判：试题常将 “工业选用 NaOH 作沉淀剂” 设为错误选项，需明确工业生产优先使用生石灰或石灰乳。
  • 混淆富集溴的方法：误以为吹出后直接得到溴产品，忽略 $\mathrm{SO_2}$ 还原吸收再氧化的富集步骤。

代表题精讲

题目 2015·新课标Ⅱ·06　海水开发利用的部分过程如图所示。下列说法错误的是
A．向苦卤中通入 $\mathrm{Cl_2}$ 是为了提取溴
B．粗盐可采用除杂和重结晶等过程提纯
C．工业生产常选用 $\mathrm{NaOH}$ 作为沉淀剂
D．富集溴一般先用空气和水蒸气吹出单质溴，再用 $\mathrm{SO_2}$ 将其还原吸收

思路
依流程图及海水综合利用常识，逐一比对选项与工业实际：A 涉及海水提溴第一步氧化；B 涉及粗盐提纯的常规步骤；C 考工业沉淀剂的选择；D 考溴的富集方法。题目要求选错误的，需找出明显违背事实或原理的选项。

步骤
1. 分析 A：苦卤中含 $\mathrm{Br^-}$，通入 $\mathrm{Cl_2}$ 将其氧化为 $\mathrm{Br_2}$，即 $\mathrm{2Br^- + Cl_2 \rightarrow 2Cl^- + Br_2}$，用于提取溴，正确。
2. 分析 B：粗盐含 $\mathrm{Ca^{2+}}$、$\mathrm{Mg^{2+}}$、$\mathrm{SO_4^{2-}}$ 等，依次用过量 $\mathrm{BaCl_2}$、$\mathrm{NaOH}$、$\mathrm{Na_2CO_3}$ 沉淀，过滤后调 pH，蒸发结晶并重结晶提纯，真实可行，正确。
3. 分析 C：工业生产中出于成本考虑，常用**生石灰 (CaO) ** 或石灰乳作为沉淀 $\mathrm{Mg^{2+}}$ 的碱性试剂，而非价格较高的 $\mathrm{NaOH}$，故该说法错误，C 为答案。
4. 分析 D：吹出单质溴后用 $\mathrm{SO_2}$ 还原吸收富集（$\mathrm{Br_2 + SO_2 + 2H_2O \rightarrow 2HBr + H_2SO_4}$），后续再用 $\mathrm{Cl_2}$ 氧化得纯 $\mathrm{Br_2}$，正确。

点评/变式
本题将粗盐提纯置于海水综合利用大背景下考查，易错点正是工业试剂与经济性。变式常考：试剂添加顺序判断；酸化时机；除杂后溶液中溶质成分；或更改流程图要求选择正确操作。记住核心原则：$\mathrm{BaCl_2}$ 除 $\mathrm{SO_4^{2-}}$ → $\mathrm{Na_2CO_3}$ 除 $\mathrm{Ca^{2+}}$ 和过量 $\mathrm{Ba^{2+}}$ → 过滤 → 滤液加盐酸调中性 → 蒸发结晶。
