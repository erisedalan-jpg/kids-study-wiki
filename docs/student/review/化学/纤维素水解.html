知识精要

  • 纤维素组成与结构：天然高分子，由葡萄糖单元通过 $\beta$‑1,4‑糖苷键连接而成，通式可简写为 $(C_6H_{10}O_5)_n$。
  • 酸性水解反应： $$(C_6H_{10}O_5)n + nH_2O \xrightarrow{H^+} n\,C_6H)$$ 酸催化下糖苷键断裂，长链降解，纸张强度下降，宏观表现为变脆、破损。}O_6 \quad(\text{葡萄糖
  • 明矾的酸性来源：明矾主要成分为 $KAl(SO_4)_2\cdot12H_2O$，溶于水后 $Al^{3+}$ 水解： $$Al^{3+} + 3H_2O \rightleftharpoons Al(OH)_3 + 3H^+$$ 使体系呈酸性，成为纸张酸性腐蚀的根源。
  • 碳酸钙的防酸原理：加入 $CaCO_3$ 作为缓冲剂，中和 $H^+$，消耗酸性物质，抑制纤维素水解： $$CaCO_3 + 2H^+ = Ca^{2+} + CO_2\uparrow + H_2O$$

解题方法与套路

  1. 拆解工艺，定位核心反应：从原料（明矾）出发，分析其在水中的行为（水解→$H^+$），再结合纸张成分（纤维素）推断发生的变质反应（酸性水解）。
  2. 从现象反推化学本质：“变脆、破损” → 高分子链断裂 → 水解反应；能阻止这一现象的添加剂（$CaCO_3$）必然与引起水解的 $H^+$ 反应。

  4. 区分可逆与不可逆：盐类水解用“$\rightleftharpoons$”，强酸制弱酸、难溶物与 $H^+$ 反应通常用“$=$”。
  5. 注意状态符号：$CO_2$ 标“$\uparrow$”，沉淀视微溶/难溶情形决定，本题无需标出。
  6. 电荷守恒和原子守恒必须满足。
  7. 表述规范：化学原理回答须同时点明“酸性环境来源”和“纤维素水解断链”两层因果关系，体现逻辑链完整性。

高频易错

  • 混淆水解条件：纤维素、淀粉酸性水解才符合本题情景，不要在明矾体系写成酶催化或碱性水解。
  • 遗漏水解可逆符号：$Al^{3+}$ 水解写“$=$”导致失分，但 $CaCO_3$ 与 $H^+$ 反应写“$\rightleftharpoons$”同样错误。
  • 明矾成分辨识不清：将明矾误认为明胶或只起物理填充作用，忽视 $Al^{3+}$ 的酸性水解。
  • 题目要求的是“离子方程式”却写化学方程式，或反过来；看清“化学（离子）方程式”提示，优先写离子方程式。
  • 添加 $CaCO_3$ 的后果：注意生成 $CO_2$，可能引起纸张表面微小气泡，但题目只要求写工艺原理，不必过度解释。（若题目追问可能带来的新问题才需补充）

代表题精讲

题目（2011 新课标·选修2 第11题第(1)问）
普通纸张的主要成分是纤维素。早期造纸在表面涂敷明矾以防止墨迹扩散，但纸张后发生酸性腐蚀而变脆、破损。经分析，腐蚀与明矾有关。
① 解释其中的化学原理。
② 为防止酸性腐蚀，可在纸浆中加入碳酸钙，写出该工艺原理的化学（离子）方程式。

思路
分析“涂敷明矾”进入纸张后的变化：明矾在水中提供 $Al^{3+}$，水解出 $H^+$，形成酸性微环境；纤维素在 $H^+$ 催化下水解，长链断裂，导致纸张力学性能下降。加入 $CaCO_3$ 可与 $H^+$ 反应，消耗酸性物质，阻止或减缓水解。答题时应先指出酸性来自明矾水解，再说纤维素酸催化降解，最后写离子方程式。

步骤
1. 明矾水解：$Al^{3+} + 3H_2O \rightleftharpoons Al(OH)_3 + 3H^+$，使纸张呈酸性。
2. 纤维素水解：在酸作用下，高分子链中的糖苷键断裂，纤维素降解为小分子（或单糖），宏观上纸张变脆。
3. 碳酸钙的保护作用：$CaCO_3 + 2H^+ = Ca^{2+} + CO_2\uparrow + H_2O$，中和酸，从而抑制纤维素水解。
（答案按题目要求，直接写离子方程式即可，原理部分文字说明。）

点评/变式
本题将盐类水解、多糖水解与文物保护综合在一起，属于“化学与技术”典型命题。明矾的酸性水解是常见考点，也曾出现在净水原理中（$Al^{3+}$ 水解生成 $Al(OH)_3$ 胶体）。变式可延伸到：用 $Mg(HCO_3)_2$ 溶液脱酸、纸张脱酸剂的评价（是否产生气体、引入新杂质等）、淀粉类文物老化原理等。作答时抓住“酸来源→高分子降解→碱性脱酸”主线，即可应对大部分同类问题。
