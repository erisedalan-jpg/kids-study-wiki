结晶

知识精要

  • 结晶概念：溶质从溶液中以晶体形式析出的过程，是分离提纯固体物质的常用方法。
  • 结晶核心原理：通过改变条件（温度、溶剂等），使溶液达到过饱和状态，固体溶质自发形成晶核并长大析出。
  • 两种主要方式：
  • 蒸发结晶（浓缩结晶）：加热蒸发溶剂，使溶液浓缩至饱和后继续蒸发，溶质析出。适用于溶解度随温度变化不大的物质（如 NaCl）。
  • 冷却结晶（降温结晶）：加热溶解制成热饱和溶液，然后冷却，因溶解度下降而析出晶体。适用于溶解度随温度升高明显增大的物质（如 KNO₃、CuSO₄·5H₂O）。
  • 结晶水合物：许多盐从水溶液中结晶时，会结合一定数目的水分子形成结晶水合物，如胆矾（CuSO₄·5H₂O）、绿矾（FeSO₄·7H₂O）、明矾等。结晶水合物的化学式必须标明结晶水数目。
  • 相关操作：蒸发浓缩、冷却结晶、过滤、洗涤、干燥。在制备实验中，常通过“蒸发浓缩、冷却结晶、过滤”得到晶体产品。

解题方法与套路

  1. 抓关键词定位原理：题干中出现“熬之则成胆矾”“蒸发”“浓缩”等词，直接对应蒸发结晶。出现“冷却”“降温”等词，对应冷却结晶。
  2. 结晶与物质性质关联：判断物质是否含结晶水，正确书写化学式。胆矾是 CuSO₄·5H₂O，不是 CuSO₄。类似地，注意区分无水物与结晶水合物。
  3. 结晶与其他反应结合：结晶过程往往是物理变化，但仍可与其他反应串联。例如“熬胆矾铁釜”涉及 Fe 与 CuSO₄ 置换反应，提炼铜单质，结晶是前期获取原料的过程。
  4. 综合信息解读：古籍记载类题目，需先翻译古语，将其转写成现代化学术语（如“苦泉”含 CuSO₄，“熬”即蒸发浓缩），再结合化学原理作答。

高频易错

  • 结晶水合物化学式误写：最常见失分点，如 CuSO₄ 与 CuSO₄·5H₂O 混淆。复习时需要记忆常见晶体的化学式。
  • 蒸发结晶与冷却结晶选取原则不清：对溶解度曲线不敏感，选错结晶方法。记得“斜率大用冷却，斜率小用蒸发”。
  • 结晶与蒸发分不清：结晶是得到晶体的过程，蒸发一般指去除溶剂，但蒸发到有大量晶体析出时就是蒸发结晶。题目“熬之则成胆矾”就是蒸发结晶，不能认为只是简单蒸发。
  • 晶体析出后操作遗漏：涉及分离提纯的题目中，常考查后续过滤、洗涤、干燥等步骤，或母液循环利用。
  • 对古籍描述望文生义：不理解“熬”“烹”等词的化学含义，导致错误判断。

代表题精讲

题目（2020·新课标Ⅱ）沈括《梦溪笔谈》记载：“信州铅山有苦泉，流以为涧。挹其水熬之则成胆矾，烹胆矾则成铜。熬胆矾铁釜，久之亦化为铜”。判断有关叙述错误的是（选项略，其中 A 项胆矾化学式 CuSO₄ 错误，应为 CuSO₄·5H₂O）。

思路：将文言文逐句转化为现代化学场景：苦泉含硫酸铜溶液，“熬”为蒸发浓缩，“成胆矾”为结晶得到硫酸铜晶体，“烹胆矾”可能涉及加热分解或继续反应，“铁釜”引入铁与硫酸铜的置换。据此逐项排查各选项化学原理的正误。

步骤： 1. 明确“胆矾”是硫酸铜晶体，正确化学式为 CuSO₄·5H₂O，A 项书写即为错误。 2. “熬之则成胆矾”是蒸发溶剂使硫酸铜溶液变为过饱和而析出晶体，属于浓缩结晶，C 项正确。 3. 胆矾可提供 CuSO₄，与铁发生 Fe + CuSO₄ = Cu + FeSO₄，属湿法冶铜，B 项正确。 4. “熬胆矾铁釜，久之亦化为铜”正是铁置换铜的置换反应，D 项正确。 故错误选项为 A。

点评/变式：本题以古籍记载切入，考点覆盖结晶操作、结晶水合物化学式以及金属置换反应，属于基础综合题。复习时要归纳常见结晶水合物的名称与化学式，训练从文言描述中提取化学信息的能力。可变式考查绿矾（FeSO₄·7H₂O）的制备与性质，或结合溶解度曲线选择合适结晶方法。
