知识精要

  • 维生素的定义与分类
    维生素是维持人体正常生命活动所必需的一类小分子有机化合物，多数不能在体内合成或合成量不足，必须从食物中摄取。按溶解性分为：
  • 脂溶性维生素：维生素A、D、E、K。溶于脂肪及有机溶剂，体内排泄慢，过量易中毒。

  • 水溶性维生素：维生素B族（B₁、B₂、B₆、B₁₂等）和维生素C。易溶于水，多余部分随尿液排出，需每日补充。

  • 重要维生素的生理功能与缺乏症（高考高频）

  • 维生素A：构成视紫红质，缺乏→夜盲症、干眼症。
  • 维生素C（抗坏血酸）：抗氧化、促进胶原合成，缺乏→坏血病。
  • 维生素D：促进钙、磷吸收，调节骨代谢，缺乏→佝偻病（儿童）、骨软化症（成人）。可由皮肤经紫外线照射合成。
  • 维生素E：抗氧化，保护生物膜。

  • 维生素K：参与凝血因子合成，缺乏易出血。

  • 典型题关联知识
    从真题选项可延伸：

  • 糖类通式 $C_n(H_2O)m$，故称碳水化合物（注：并非所有糖都严格符合此式，如鼠李糖 $C_6HO_5$）。
  • 蛋白质一定含C、H、O、N，多数含S，有的含P、Fe等，仅由C、H、O不可能构成蛋白质。
  • 微量元素（如Se、I、Fe、Zn等）必需但摄入量有安全范围，过量有害。

解题方法与套路

  1. 锁定核心概念：面对维生素类选择题，先快速回忆常见维生素的溶解性、主要功能和典型缺乏症，将选项与记忆库比对。
  2. 排除绝对化表述：对于“仅”“只”“一定”等绝对词要高度警惕，如“仅由碳、氢、氧”，立即联想反例（蛋白质含氮）。
  3. 生活常识辅助：维生素D可促进钙吸收、维生素C可防坏血病等属于生活/生物常识，结合已有知识可快速判断。
  4. 关注细节陷阱：如“维生素D可促进钙吸收”表述虽简略但正确；“碳水化合物”是糖类的别名，正确；微量元素“不宜摄入过多”也符合科学事实。
  5. 跨学科联想：必要时联系生物课所学的物质代谢、无机盐功能，做到理综互通。

高频易错

  • 混淆脂溶性与水溶性维生素：不清楚维生素D是脂溶性，会与维生素C水溶性相混，导致过量中毒或排泄机制判断错误。
  • 错记维生素功能：将维生素D促进钙吸收误归为维生素A或维生素C；将维生素C的抗氧化与维生素E混淆。
  • 忽略蛋白质的基本元素组成：误以为蛋白质只含C、H、O，不知一定含N，常因此选项失分。
  • 对“碳水化合物”片面理解：认为所有糖都严格符合通式 $C_n(H_2O)_m$，实则通式为历史俗名，少数糖不符合；但在中学阶段该说法通常视为正确。
  • 微量元素认知误区：以为“必需”就等于“多多益善”，忽略“微量”的关键限定。

代表题精讲

题目

（2017·新课标Ⅱ，1）下列说法错误的是（　　）
A．糖类化合物也可称为碳水化合物
B．维生素D可促进人体对钙的吸收
C．蛋白质是仅由碳、氢、氧元素组成的物质
D．硒是人体必需的微量元素，但不宜摄入过多

思路
逐选项排查：①糖类多数符合 $C_n(H_2O)_m$，史称碳水化合物，A对；②维生素D典型功能是促钙吸收，B对；③蛋白质含C、H、O、N等，并非仅由C、H、O，C错；④硒是必需微量元素，过量有毒性，D对。选错误项C。

步骤
1. 分析A：糖类旧称碳水化合物，高中教材认可，正确。
2. 分析B：维生素D促进肠道对钙、磷的吸收及骨钙沉积，正确。
3. 分析C：蛋白质基本组成元素为C、H、O、N，部分含S、P等，故“仅由C、H、O”错误。
4. 分析D：硒属人体必需微量元素，但安全范围窄，过量致硒中毒，D正确。
5. 判定错误项为C。

点评/变式
该题在有机与生物交叉点命题，属于基础正误判断。变式可改为：“下列说法正确的是”，选项设为维生素C治疗夜盲症、所有糖都符合碳水化合物通式等，训练学生对常见错误表述的敏感度。复习时务必把营养素的元素组成、核心功能与限定词精准对应。
