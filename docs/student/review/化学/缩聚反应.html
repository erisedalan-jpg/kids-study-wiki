缩聚反应

考点缩聚反应权重10真题数1学科化学父主题反应类型与基本反应

考点定位

  • 父主题：反应类型与基本反应
  • 权重 weight：10
  • 真题数：1；年份跨度：2023–2023
  • 出现题位：选择2
  • 难度分布：中1

知识精要

  • 缩聚反应：由含两个或两个以上官能团的单体，通过分子间官能团多次缩合，脱去小分子（如 $\ce{H2O}$、$\ce{CH3OH}$、$\ce{HCl}$ 等），形成高分子化合物的反应。其本质是逐步聚合。
  • 缩聚物的结构特点：主链上一般留有特征基团（如酯基 $\ce{-COO-}$、酰胺基 $\ce{-CONH-}$），单体与聚合物的组成不同（原子不全部进入大分子）。
  • 聚碳酸酯型缩聚：一般由二元酚（或多元醇）与碳酸酯（如碳酸二甲酯）通过酯交换反应缩聚而成，脱去小分子醇（如甲醇）。典型反应式可简记为： $$n\,\ce{HO-R-OH} + n\,\ce{CH3O-CO-OCH3} \xrightarrow[催化剂]{\Delta} \ce{[O-R-O-CO]}_n + 2n\,\ce{CH3OH}$$
  • 手性碳判断：连接四个互不相同的原子或基团的饱和碳原子。分子内对称轴上的碳不是手性碳；环上桥头碳若不满足四个不同基团，不属手性碳。
  • 聚碳酸酯可降解性：主链含酯基，可水解或生物降解成为小分子，是环境友好材料的重要特征。

解题方法与套路

  1. 识别聚合反应类型
  2. 看反应物官能度：若有两种或以上两官能度（或更高）单体 → 可缩聚。
  3. 看产物特征：有高聚物+小分子脱去（如 $\ce{CH3OH}$、$\ce{H2O}$）→ 必为缩聚反应；无小分子生成，原子全部进入聚合物 → 加聚反应。
  4. 缩聚单体与链节推断
  5. 由高分子片段和脱去的小分子推导单体：沿主链将特征基团（酯基、酰胺基等）断键补加小分子得到单体。
  6. 对于交换缩聚：醇提供 $\ce{-OH}$，酸（或碳酸酯）提供 $\ce{-OR}$，脱去小分子醇。
  7. 手性碳计数法
  8. 步骤：① 找出所有饱和碳（不含双键、三键的碳）；② 逐个检查四个相连基团是否互不相同；③ 排除分子内对称位置上的重复计数；④ 特别注意环上的碳，需仔细分辨对称性。
  9. 选择题综合判断
  10. 对每一个选项逐句验证：可降解性（看是否有易水解基团）、手性碳个数、小分子副产物、反应类型，利用已知信息快速排除错误选项。

高频易错

  • 手性碳数目数错：异山梨醇看似有对称因素，易遗漏或误判桥环上的碳，需逐一检验四个取代基是否不同。
  • 把小分子副产物误判为水：酯交换缩聚（碳酸二甲酯+醇）脱去的是醇（如甲醇），而不是水；只有羧酸与醇缩聚才脱去水。
  • 混淆缩聚与加聚：看到生成高聚物就认为缩聚，但加聚没有小分子脱去，单体结构完整保留在聚合物中，缩聚必有小分子生成。
  • 用习惯思维判断可降解：误以为所有高分子都难降解，实质主链含有酯基等可水解基团时，多可降解，需具体分析。

代表题精讲

题目（2023新课标卷）光学性能优良的高分子材料聚碳酸异山梨醇酯可由如下反应制备。
反应略：异山梨醇与碳酸二甲酯缩聚，生成聚合物和化合物 X。
问：下列说法错误的是 A. 该高分子材料可降解；B. 异山梨醇分子中有3个手性碳；C. 反应式中化合物X为甲醇；D. 该聚合反应为缩聚反应。

思路
从反应式可知，醇和碳酸酯通过酯交换脱去甲醇生成聚碳酸酯，属于缩聚；主链含酯基，可降解；需对异山梨醇的手性碳逐个分析，注意桥环碳的对称性。找出与典型结构不符的选项。

步骤
1. 反应类型：异山梨醇提供两个羟基，碳酸二甲酯相当于两个甲酯，缩合脱去 $\ce{CH3OH}$ 分子，生成聚碳酸酯，符合缩聚定义 → D 正确。
2. 化合物 X：观察官能团变化，碳酸二甲酯的甲氧基与异山梨醇的羟基结合，脱去的是甲醇 $\ce{CH3OH}$ → C 正确。
3. 可降解性：高聚物主链含有反复出现的碳酸酯基 $\ce{-O-CO-O-}$，易水解断裂 → A 正确。
4. 手性碳计数：画出异山梨醇结构（并环双五元环，含两个醚桥），逐一检查饱和碳。分子中不存在对称面使手性碳重复。实际含有 4 个手性碳，而非 3 个 → B 错误，符合题意。

点评/变式
此类“给定新物质转化关系”的选择题，需立足反应机理与结构特征，切忌凭感觉判断手性碳。可将异山梨醇替换为其他双官能度醇类（如双酚 A）与光气或碳酸二甲酯缩聚，变式考查聚碳酸酯的合成、降解和结构解析。熟练掌握“缩聚必脱小分子、有酯基多可降解、手性碳逐一验四邻”三大原则，可快速拿分。
