羧基

考点羧基权重6真题数1学科化学父主题有机化学

考点定位

  • 父主题：有机化学
  • 权重 weight：6
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择7
  • 难度分布：难1

知识精要

  • 羧基：官能团 $—COOH$，由羰基和羟基组成，具有酸性。
  • 酸性：羧酸在水中可电离出 $H^+$，能与 $NaOH$、$Na_2CO_3$、$NaHCO_3$ 等碱反应。$1 \ \mathrm{mol} \ —COOH \sim 1 \ \mathrm{mol} \ NaOH$。
  • 酯的水解：酯基 $—COO—$ 在酸性或碱性条件下水解。碱性水解时，$1 \ \mathrm{mol}$ 酯基消耗 $1 \ \mathrm{mol} \ NaOH$，生成羧酸钠和醇（或酚钠）。
  • 酚羟基：酚 $—OH$ 具有弱酸性，能与 $NaOH$ 反应生成酚钠，$1 \ \mathrm{mol}$ 酚羟基 $\sim 1 \ \mathrm{mol} \ NaOH$。醇羟基不与 $NaOH$ 反应。
  • 分析分子内直接存在的基团与水解后新生成的基团是计算耗碱量的关键。

解题方法与套路

  1. 定官能团：标出分子中所有能与 $NaOH$ 直接反应的官能团（羧基、酚羟基等），以及能水解生成酸性基团的官能团（酯基、卤代烃等）。
  2. 判水解：写出碱性水解产物，重点找出新生成的羧基和酚羟基（常来自酯基中的醇部分若为酚，则生成酚羟基）。
  3. 算总量：将原始分子与水解产物中的羧基、酚羟基总数相加，即为消耗 $NaOH$ 的总物质的量（一般情况下，$1 \ \mathrm{mol}$ 酸性基团消耗 $1 \ \mathrm{mol} \ NaOH$）。特别注意：若水解生成酚羟基，其必然消耗 $NaOH$。

高频易错

  • 忽略酚羟基的酸性：醇 $—OH$ 不与 $NaOH$ 反应，但酚 $—OH$ 会反应。需判断连接在苯环上的羟基。
  • 水解产物的遗漏：酯水解生成的醇若连在苯环上（酚酯），则生成酚羟基，会额外消耗 $NaOH$；仅注意直接连接的羧基而漏掉水解生成的羧基。
  • 错算酯基耗碱比：认为 $1 \ \mathrm{mol}$ 酯基只消耗 $1 \ \mathrm{mol} \ NaOH$（实际水解需 $1 \ \mathrm{mol}$，但生成的酸或酚会再消耗碱）。正确思路：直接计算水解后体系内所有酸性基团总量。

代表题精讲

题目：$1 \ \mathrm{mol}$ 有机物 与足量 $NaOH$ 溶液充分反应，消耗的 $NaOH$ 的物质的量为（ ）

A．$5 \ \mathrm{mol}$　B．$4 \ \mathrm{mol}$　C．$3 \ \mathrm{mol}$　D．$2 \ \mathrm{mol}$

（注：题给结构含一个酯基，且醇部分来自酚，分子内已有酯基和水解后潜在的酚羟基与羧基）

思路：该有机物分子中含有酯基，在足量 $NaOH$ 溶液中发生水解。先分析水解产物结构，再统计产物中所有呈酸性的基团（酚羟基和羧基），每 $1 \ \mathrm{mol}$ 消耗 $1 \ \mathrm{mol} \ NaOH$。

步骤： 1. 原分子中存在一个 $—COO—$（酯基），它与苯环直接相连（酚酯）。碱性水解后，酯基断开，生成 $—COONa$ 和酚羟基（$—OH$ 连在苯环上）。 2. 观察水解产物，分子中原有的取代基结合水解新生成的基团，总共得到 $3 \ \mathrm{mol}$ 酚羟基、$2 \ \mathrm{mol}$ 羧基。其中部分羧基可能是原分子（或水解片段）本身携带。 3. 酚羟基和羧基各消耗 $1 \ \mathrm{mol} \ NaOH$，总计需要 $3+2=5 \ \mathrm{mol} \ NaOH$。

点评/变式：此题典型考查酚酯耗碱的特殊性。若酯基醇部分为普通醇，则水解只生成醇羟基，不与 $NaOH$ 反应，耗碱量会减少。变式训练时，可尝试改变芳香环上取代基位置或换为脂肪族酯，体会官能团酸性判断的核心逻辑。
