胶体

考点胶体权重11真题数1学科化学父主题基本概念与物理量

考点定位

  • 父主题：基本概念与物理量
  • 权重 weight：11
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 胶体定义：分散质粒子直径在 $1\sim100\,\text{nm}$ 之间的分散系。
  • 本质特征：分散质粒子直径大小，决定其性质介于溶液（$<1\,\text{nm}$）与浊液（$>100\,\text{nm}$）之间。
  • 核心性质与鉴别：
    • 丁达尔效应：可见光束通过胶体时出现一条光亮的“通路”，溶液无此现象。这是鉴别胶体与溶液的常用物理方法。
    • 电泳：胶体粒子带有电荷（因吸附离子），在通电时向与自身电荷相反的电极定向移动。胶体整体仍呈电中性。
    • 聚沉：加热、加入电解质或带相反电荷的胶体，均能破坏胶体的稳定结构，使分散质粒子聚集成大颗粒而沉降。
    • 布朗运动：胶体粒子受到分散剂分子不平衡撞击而产生的无规则运动，不是胶体特有，悬浊液中也有。
  • 溶液相关对比：溶质粒子（分子或离子）直径极小，呈均一、稳定、透明状态，能透过滤纸和半透膜；胶体粒子透过滤纸但不能透过半透膜。

解题方法与套路

  1. 快速锁定鉴别现象：题干若比较溶液与胶体，优先看选项是否涉及丁达尔效应——有光路是胶体，无光路是溶液。
  2. 辨析“体系电性”与“粒子电性”：整个胶体电中性，带电的是胶粒；溶液中的溶质若是电解质，电离出的离子分别带正负电，整体仍电中性。
  3. 抓准运动性质的描述：胶体粒子与溶液中分子、离子都在做无规则热运动；选项出现“有规律运动”必错。
  4. 通电移动分析：胶粒带电可向某一极移动（电泳）；溶液中的离子会分别向两极移动，但分子不移动。对“分别向两极移动”的说法需结合溶质具体分析，笼统说“溶质粒子分别向两极移动”不准确。

高频易错

  • “胶体带电”：胶体整体是电中性的，带电的是胶粒。看到“胶体是带电的”直接判错。
  • 夸大电泳现象：认为通电时所有溶液中的粒子都分别向两极移动。实际非电解质分子不带电，不移动。
  • 运动“有规律”陷阱：溶液中的分子、离子热运动并无宏观规律，布朗运动也是无规则，认为溶液运动有规律、胶体无规律的是易错点。
  • 丁达尔效应专属性：丁达尔效应可区分胶体与溶液，但不可区分胶体与浊液（浊液也可能有散射，但通常透光性差）。
  • 概念混淆：认为胶粒能通过滤纸就不能通过半透膜，混淆“过滤”与“渗析”；胶体聚沉后不一定澄清，可能形成沉淀。

代表题精讲

题目

2009·全国Ⅱ·2：下列关于溶液和胶体的叙述，正确的是 A．溶液是电中性的，胶体是带电的 B．通电时，溶液中的溶质粒子分别向两极移动，胶体中的分散质粒子向某一极移动 C．溶液中溶质分子的运动有规律，胶体中分散质粒子的运动无规律，即布朗运动 D．一束光线分别通过溶液和胶体时，后者会出现明显的光带，前者则没有

思路

逐项排查：A项带电主体判断；B项通电时粒子移动情况，看是否所有溶质粒子都移动；C项运动是否有规律；D项利用胶体丁达尔效应鉴别。

步骤

  1. A项：整个分散系均是电中性的，但胶体中胶粒因吸附离子而带电，故“胶体是带电的”错误。
  2. B项：溶液中的溶质若为非电解质（如蔗糖分子），通电时不移动；电解质电离出的离子确实分别向两极移动。胶体中胶粒带电，会向某一极移动，盐析等不带电分散质不移动。叙述以偏概全，错误。
  3. C项：溶液中分子、离子与胶体粒子一样，都在不停做无规则热运动，无“有规律”之说，错误。
  4. D项：一束光通过胶体发生散射，产生光亮的“通路”（丁达尔效应）；溶液不发生明显散射，无此现象，正确。

点评/变式

该题以对比形式考查胶体与溶液的核心差异，选项覆盖丁达尔效应、电泳、布朗运动、电中性，是对胶体专题的经典覆盖。变式可改为：“下列说法中，可用于区分溶液和胶体的是”，答案仍是丁达尔效应。注意，胶体聚沉、渗析也是考查方向，例如“除去淀粉胶体中的少量NaNO₃应用过滤还是渗析？”，渗析是正确方法。
