胶体制备

考点定位

  • 父主题：基本概念与物理量
  • 权重 weight：5
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择7
  • 难度分布：易1

知识精要

  • 胶体定义：分散质粒子直径在 $10^{-9} \text{m} \sim 10^{-7} \text{m}$ ( $1 \text{nm} \sim 100 \text{nm}$ ) 的分散系。这是区别于溶液( $ < 1\text{nm} $ )和浊液( $ > 100\text{nm} $ )的本质特征。
  • $\text{Fe(OH)}_3$ 胶体制备要点：
    • 原理：利用铁盐水解。化学方程式为：$\text{FeCl}_3 + 3\text{H}_2\text{O} \stackrel{\triangle}{=} \text{Fe(OH)}_3 (\text{胶体}) + 3\text{HCl}$。
    • 关键操作：向沸腾的蒸馏水中逐滴加入饱和 $\text{FeCl}_3$ 溶液，继续加热至液体呈透明的红褐色即停止加热。
    • 绝对不能用 $\text{NaOH}$ 等碱与铁盐反应，否则直接生成 $\text{Fe(OH)}_3$ 悬浊液（沉淀）。
    • 绝对不能长时间加热或持续沸腾，否则胶体粒子因碰撞聚沉，形成沉淀。
  • 胶体性质：丁达尔效应是区分胶体与溶液最简便的物理方法。胶体粒子带电（$\text{Fe(OH)}_3$ 胶粒带正电），但整个分散系呈电中性。

解题方法与套路

  1. 咬死“粒子尺寸”：凡是题目提到“透明”、“均一”，且涉及 $1 \text{nm} \sim 100 \text{nm}$ 尺寸范围的，优先联想胶体。
  2. 制备题四步排除法：
    • 一看试剂：试剂是否为“沉淀剂”（如碱、盐溶液直接混合）？若是硬加碱，一定不是胶体制备，只能得到悬浊液。
    • 二看介质：是否明确要求将反应物滴入沸水或热水？若直接混合冷液，需谨慎。
    • 三看滴加顺序与浓度：稀溶液滴入浓溶液？还是浓溶液滴入水？制备 $\text{Fe(OH)}_3$ 胶体必须是饱和溶液滴入沸水。
    • 四看加热时间：是“长时间加热/蒸干”还是“继续加热片刻”？蒸干、持续沸腾必导致聚沉，胶体被破坏。
  3. 综合实验题辨析：遇到“蒸发结晶制备固体”与“制备胶体”混编时，头脑必须清醒——蒸发结晶追求沉淀析出，胶体制备追求稳定的纳米粒子分散，两者操作目的截然相反。

高频易错

  • 错加沉淀剂：直接将 $\text{NaOH}$ 溶液滴入 $\text{FeCl}_3$ 溶液中。前者生成红褐色沉淀，无法得到胶体。
  • 加热失控：长时间煮沸胶体或将其加热蒸干。胶粒热运动加剧碰撞，破坏胶体结构，导致聚沉。
  • 忽视条件细节：题干中“饱和”、“沸水”、“红褐色”等关键词常作为命题信号。将溶液呈红褐色视为标准终点，忽略观察颜色停止加热这一操作。
  • 混淆胶体与其他分散系：误认为“纳米材料”一定是胶体。只有当该材料作为分散质分散在分散剂中并形成稳定体系时，才构成胶体。
  • 错误类比：用制备 $\text{Fe(OH)}_3$ 胶体的思路去制备所有胶体。不同胶体体系的稳定机制不同，必须依据该物质的具体化学性质（如碘化银胶体、金溶胶等制备条件完全不同）。

代表题精讲

题目：（2016-新课标Ⅱ-07）判断“将 $\text{NaOH}$ 浓溶液滴加到饱和 $\text{FeCl}_3$ 溶液中制备 $\text{Fe(OH)}_3$ 胶体”是否能达成实验目的。 思路：本题直击胶体制备的试剂选择易错点。看到 $\text{NaOH}$，要立刻意识到它是强碱沉淀剂，其与铁盐发生的是复分解反应，直接生成颗粒尺寸远超 $100\text{nm}$ 的沉淀，而非胶体。 步骤： 1. 审操作：将 $\text{NaOH}$ 浓溶液滴入饱和 $\text{FeCl}_3$ 溶液。 2. 断反应：反应式为 $\text{FeCl}_3 + 3\text{NaOH} = \text{Fe(OH)}_3 \downarrow + 3\text{NaCl}$。这是典型的沉淀反应，生成物标注是“$\downarrow$”。 3. 判结果：产物为 $\text{Fe(OH)}_3$ 沉淀（悬浊液），分散质粒子尺寸 $ > 100\text{nm}$。而胶体要求粒子尺寸在 $1 \text{nm} \sim 100 \text{nm}$ 之间。该操作产物不符合胶体定义。 4. 定结论：实验操作无法达到制备 $\text{Fe(OH)}_3$ 胶体的目的。 点评/变式：本题是极经典的干扰项设计。制备 $\text{Fe(OH)}_3$ 胶体的唯一正确路径是促进 $\text{Fe}^{3+}$ 的水解，必须提供高温水环境，绝不能引入碱。变式问法：若将操作改为“将 $1 \text{mol/L FeCl}_3$ 溶液滴入冷水中”，依然错误，因为水解程度不够且温度低。再若改为“向沸水中滴加 $\text{FeCl}_3$ 溶液，并长时间煮沸”，则因聚沉而失败。考生务必死记“沸水+饱和溶液+片刻加热至红褐色”这组核心条件链。
