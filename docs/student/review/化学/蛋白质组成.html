蛋白质组成

考点蛋白质组成权重5真题数1学科化学父主题有机化学

考点定位

  • 父主题：有机化学
  • 权重 weight：5
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：选择1
  • 难度分布：中1

知识精要

  • 蛋白质是一类天然有机高分子，其基本组成元素为 碳、氢、氧、氮，大多数还含有 硫，少数含有磷、铁、铜、锌等微量元素。
  • 蛋白质水解的最终产物是 $\alpha$-氨基酸，通式为 $\mathrm{H_2N!-!CHR!-!COOH}$，分子中同时含有氨基（$-\mathrm{NH_2}$）和羧基（$-\mathrm{COOH}$）。
  • 糖类、油脂的元素组成仅为 C、H、O 三种元素；蛋白质因含氨基而必定含 N 元素，这是与糖、油脂在元素组成上的根本区别。
  • 常见有机物元素组成对比：
  • 糖类、油脂：C、H、O
  • 蛋白质：C、H、O、N（多数还含 S）
  • 核酸：C、H、O、N、P
  • 人体必需微量元素（如 Se）需适量摄入，过量或缺乏都会危害健康。维生素 D 可促进人体对钙的吸收。

高频易错

  • 蛋白质元素组成的缺失：最易遗忘蛋白质中的 N 元素，误将蛋白质与糖类、油脂的元素组成等同，认为仅由 C、H、O 组成。
  • 名称干扰：糖类俗称“碳水化合物”，易误以为糖类含碳和水分子，实则只是通式近似为 $(\mathrm{C})_n(\mathrm{H_2O})_m$，本质仍只含 C、H、O，不可类推到蛋白质。
  • 微量元素与维生素功能混淆：注意维生素 D 促进钙吸收，而非直接补钙；硒是必需微量元素但过量有毒。平时需将教材中必需微量元素（Fe、Zn、Se、I 等）与常量元素（C、H、O、N 等）区分清楚。
  • 忽视“仅”字的绝对化陷阱：选项中若出现“仅由……组成”“全部是……”等绝对化字眼，要高度警惕，多数为错误说法。

代表题精讲

题目（2017 新课标Ⅱ·1）
下列说法错误的是
A．糖类化合物也可称为碳水化合物
B．维生素 D 可促进人体对钙的吸收
C．蛋白质是仅由碳、氢、氧元素组成的物质
D．硒是人体必需的微量元素，但不宜摄入过多

思路
本题为典型的“挑错题”，考点覆盖常见有机物的组成与人体健康知识。解题关键在于快速提取各选项对应的核心知识点，并着重关注选项 C 中“仅由碳、氢、氧”这一绝对化描述，联想蛋白质必含 N 元素的知识点即可锁死错误项。

步骤
1. 审题干，明确要找 错误 说法。
2. 逐项判断：
- A 项：糖类的通式为 $C_n(H_2O)_m$，故有碳水化合物之称，描述正确。
- B 项：维生素 D 可促进钙、磷吸收，符合教材表述，正确。
- C 项：蛋白质的基本组成元素必有 C、H、O、N，常含 S 等，因此“仅由碳、氢、氧”错误。
- D 项：硒是人体必需微量元素，摄入过多会中毒，描述正确。
3. 对比后选定 C 为答案。

点评/变式
- 点评：此题选项 C 的陷阱在于利用“仅由”二字制造绝对化错误，是生物学与化学交叉知识中考查“元素组成”的典型考法。考生需注意，即便是同属有机物的蛋白质，其元素种类也与糖、油脂有本质区别——氮元素的存在是蛋白质的标志。
- 变式：若将 C 项改为“蛋白质的主要组成元素有碳、氢、氧、氮”，则为正确说法；若改为“所有蛋白质都含有硫”，则错误（有些不含硫）。提醒考生平时复习应有意识地对比“一定含有”“可能含有”“主要含有”等限定词的细微差异。
