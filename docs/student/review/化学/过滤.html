知识精要

过滤是分离不溶性固体与液体的基本操作方法，常用于粗盐提纯、沉淀分离等实验。
- 主要仪器：漏斗、玻璃棒、烧杯、铁架台（带铁圈）、滤纸。
- 操作关键——“一贴、二低、三靠”
- 一贴：滤纸用水润湿后紧贴漏斗内壁，中间不留气泡。
- 二低：滤纸边缘略低于漏斗边缘，过滤时漏斗内液面始终低于滤纸边缘。
- 三靠：烧杯嘴紧靠玻璃棒引流；玻璃棒末端轻轻斜靠三层滤纸一侧；漏斗下端尖嘴紧靠下方烧杯内壁，使滤液沿烧杯壁流下，防止飞溅。
- 沉淀洗涤：向漏斗中注入少量蒸馏水，刚好浸没沉淀，待水自然流下，重复2～3次。
- 洗涤效果检验：取少量最后一次洗涤液，检测可能存在于原滤液中的离子（如粗盐过滤后取洗涤液检验 $\mathrm{SO_4^{2-}}$ 或 $\mathrm{Cl^-}$），若无相应现象则沉淀已洗净。

解题方法与套路

过滤及固液分离装置正误判断题的通用步骤：
1. 锁定关键点：观察漏斗下端是否紧靠烧杯内壁；玻璃棒末端是否轻触三层滤纸处；是否用玻璃棒引流。
2. 逐条对照“一贴二低三靠”：先看滤纸是否贴合漏斗；再看液面高度与滤纸边缘关系；最后逐一核对“三靠”部位。
3. 排除典型错误：漏斗下端悬空、玻璃棒戳在单层滤纸上、未用玻璃棒直接倾倒液体、液面高过滤纸边缘等，直接判错。
4. 结合其他实验要求：若题目为混搭实验图示，还需独立判断其他装置（如加热固体试管口方向、洗气瓶进气导管长短、防倒吸设置等），最终选择唯一正确选项。

高频易错

  • 漏斗下端悬空：学生常忽略漏斗尖端应紧贴烧杯内壁，悬空会导致液体飞溅、流速不稳定，图示题极易错判。
  • 玻璃棒位置错误：玻璃棒直接顶在单层滤纸上，导致滤纸戳破，失去过滤作用。
  • 忘记引流：倾倒浊液时烧杯嘴未接触玻璃棒，直接倾入漏斗，易冲破滤纸或液体溢出。
  • 液面超过滤纸边缘：滤液从滤纸与漏斗间隙通过，造成滤液仍浑浊。
  • 滤纸边缘高于漏斗：使滤纸无法完全贴壁，起不到有效过滤作用，装置图常以此设错。
  • 加热固体时试管口方向混淆：与过滤无关，但在混合图示题中易忽略试管口略向下倾斜而误判。

代表题精讲

题目（2014·新课标Ⅱ第4题）
给出四个实验装置示意图：A.除去粗盐溶液中不溶物；B.碳酸氢钠受热分解；C.除去CO气体中的CO₂气体；D.乙酸乙酯的制备演示实验，要求选出正确的一项。

思路
逐一用各实验的操作要点核验图示。过滤重点查“三靠”，固体加热重点看试管口方向，洗气除杂看导管“长进短出”，酯制备看防倒吸。

步骤
- A项（过滤）：装置中漏斗下端尖嘴未紧靠烧杯内壁，玻璃棒也未靠在三层滤纸一侧，错误。
- B项（碳酸氢钠受热分解）：试管口向上倾斜，产生的水蒸气在管口冷凝会倒流炸裂试管，正确做法应管口略向下倾斜，错误。
- C项（洗气除杂）：除CO₂应使混合气体通过洗气瓶中的碱液，进气导管应伸入液面下（长进），出气导管稍露出胶塞（短出）。图示为短进长出，气体无法有效洗气，错误。
- D项（乙酸乙酯制备）：乙醇、乙酸、浓硫酸混合液加热，导管末端靠近饱和碳酸钠溶液液面，可防倒吸且不插入液面以下，正确。
因此选D。

点评/变式
过滤虽是基础操作，但在选择题中常通过漏斗下端位置、玻璃棒接触点设坑。变式训练可追问：若过滤后发现滤液仍浑浊，可能有哪些原因？如何洗涤滤渣并检验是否洗净？这些均源于“一贴二低三靠”及沉淀洗涤的深化理解。
