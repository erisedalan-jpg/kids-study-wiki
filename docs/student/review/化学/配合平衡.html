知识精要

配位平衡：中心离子（金属离子）与配体（如 NH₃、CN⁻、Cl⁻）结合生成配离子的可逆反应，存在动态平衡。例如 $Ag^+ + 2NH_3 \rightleftharpoons [Ag(NH_3)_2]^+$。

配合物稳定常数 $K_稳$（生成常数 $K_f$）：表征配离子稳定程度。对 $Ag^+ + 2NH_3 \rightleftharpoons [Ag(NH_3)_2]^+$，$K_稳=\dfrac{c([Ag(NH_3)_2]^+)}{c(Ag^+)\cdot c^2(NH_3)}$。$K_稳$ 越大，配离子越稳定，越不易解离。逐级配位时有逐级稳定常数 $K_1$、$K_2$，总稳定常数 $K_稳=K_1\cdot K_2$。

解离常数 $K_不稳$：$K_不稳=1/K_稳$，描述配离子解离倾向。

与溶度积的耦合：难溶盐（如 AgCl）遇配体可能因生成配离子而溶解。$AgCl(s) \rightleftharpoons Ag^+ + Cl^-$（$K_{sp}=c(Ag^+)\cdot c(Cl^-)$）与配位平衡叠加，总反应 $AgCl(s)+2NH_3 \rightleftharpoons [Ag(NH_3)2]^+ + Cl^-$ 的平衡常数 $K=K\cdot K_稳$。

对数图像：常以 $\lg c(M)$ 对 $\lg c(NH_3)$ 作图。各组分（$Ag^+$、$[Ag(NH_3)_1]^+$、$[Ag(NH_3)_2]^+$ 等）呈直线，斜率等于该物种相对 $Ag^+$ 多结合的 NH₃ 个数：$Ag^+$ 斜率 0，一氨配离子斜率 +1，二氨配离子斜率 +2。

影响因素：增大配体浓度使配位平衡正移、$K_稳$ 大的配体可置换 $K_稳$ 小的配体；加酸消耗 NH₃ 等配体使配离子解离；$K_稳$ 只随温度变化。

解题方法与套路

  1. 识图定物种：按各曲线斜率判断对应何种物种。斜率 0 为游离金属离子，斜率每增 1 多结合一个配体；$Cl^-$ 随 NH₃ 增大而增大（AgCl 溶解增多），单独成线。
  2. 由图取点读 $K_{sp}$：找 $Ag^+$ 与 $Cl^-$ 曲线交点（或在 AgCl 饱和段），$\lg K_{sp}=\lg c(Ag^+)+\lg c(Cl^-)$，两对数相加即得。
  3. 逐级求 $K$：相邻两物种曲线满足 $\dfrac{c(\text{高配})}{c(\text{低配})}=K_i\cdot c(NH_3)$，取 $c(NH_3)$ 已知点代入对数关系求逐级 $K_i$。
  4. 算目标反应 $K$：将目标方程拆成已知平衡（$K_{sp}$、逐级 $K_稳$）的组合，平衡常数对应相乘（逆向取倒数）。
  5. 判断溶解性/移动方向：比较 $Q$ 与 $K$，或看增大配体浓度后平衡移向，结合 $K_稳$ 大小判断配体能否置换。

高频易错

  • 斜率与物种对应错：把高级配离子（斜率大）当成游离离子，或反之。牢记斜率 = 比 $Ag^+$ 多结合的配体数。
  • $K_{sp}$、$K_稳$、$K_不稳$ 混用：$K_稳$ 是生成方向，$K_不稳=1/K_稳$；溶度积是固液平衡，三者表达式与方向务必分清。
  • 对数运算出错：$\lg(K_{sp})=\lg c(Ag^+)+\lg c(Cl^-)$ 是相加；求总 $K=K_{sp}\cdot K_稳$ 对数则相加，切勿相乘对数。
  • 配体浓度计入错误：稳定常数表达式中配体浓度带相应指数（如 $c^2(NH_3)$），逐级常数只带一次方。
  • 混淆逐级常数与累积常数：$K_稳(总)=K_1\cdot K_2$，读图所得相邻物种比值对应的是逐级常数 $K_i$。
