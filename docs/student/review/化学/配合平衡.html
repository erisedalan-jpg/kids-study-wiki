知识精要

配合平衡描述中心原子（多为金属离子）与配体通过配位键形成配合物的可逆过程，核心概念包括： - 逐级稳定常数 $K_n$：如 $Ag^+ + NH_3 \rightleftharpoons [Ag(NH_3)]^+$，$K_1 = \frac{[[Ag(NH_3)]^+]}{[Ag^+][NH_3]}$；
$[Ag(NH_3)]^+ + NH_3 \rightleftharpoons [Ag(NH_3)2]^+$，$K_2 = \frac{[[Ag(NH_3)_2]^+]}{[[Ag(NH_3)]^+][NH_3]}$。
- 累积稳定常数 $\beta_n = K_1 \cdot K_2 \cdots K_n$，如 $\beta_2 = \frac{[[Ag(NH_3)_2]^+]}{[Ag^+][NH_3]^2}$。
- 与沉淀溶解平衡的耦合：难溶电解质 $M_mA_n$ 在有配体存在时，可通过配合反应溶解。例如 $AgCl(s) \rightleftharpoons Ag^+ + Cl^-$，$K=[Ag^+][Cl^-]$；加入 $NH_3$ 后，$Ag^+$ 被配合，平衡总反应为
$$AgCl(s) + 2NH_3 \rightleftharpoons [Ag(NH_3)2]^+ + Cl^-$$
其平衡常数 $K = K \cdot \beta_2$。溶解后溶液中 $c(Cl^-) = [Ag^+] + [[Ag(NH_3)]^+] + [[Ag(NH_3)_2]^+]$（物料守恒）。
- 对数浓度图中的特征：随配体浓度增加，游离金属离子浓度单调下降；中间级配合离子浓度先增后减，出现极大值；最高级配合离子浓度单调上升；阴离子浓度由溶解总量决定，单调上升且与总金属离子浓度相等（当阴离子不参与配位时）。

解题方法与套路

处理配合平衡与沉淀溶解平衡组合图像题的通用步骤： 1. 识别物料守恒关系：先写出与沉淀相关的阴离子浓度与金属总浓度的等量关系（若阴离子不配位），以此确定代表 $Cl^-$ 的曲线，该曲线必然随配体浓度增加而增加，且在起始无配体时与 $[M^+]$ 相等。
2. 确定剩余离子的曲线归属：游离金属离子浓度随配体增加迅速下降，其 $-\lg c$ 单调上升；配位数最高的配合离子单调上升（$-\lg c$ 单调下降）；中间配合离子先升后降，存在拐点。
3. 计算平衡常数：
- $K_{sp}$ 利用起始无配体时的点：$[M^+]=[A^-]=\sqrt{K_{sp}}$，对应 $-\lg c(M^+)=-\lg c(A^-)= \frac{1}{2}pK_{sp}$。
- 逐级稳定常数 $K_n$ 找两种相邻配合离子浓度相等的点，此时 $K_n = \frac{1}{[L]}$（$[L]$ 为该点配体平衡浓度），利用横坐标读数。
- 总反应平衡常数可由 $K_{sp} \cdot \beta_n$ 或图中合适点直接求算。
4. 评价选项：按上述分析逐一验证，注意物理量取对数后的变化趋势，勿混淆曲线。

高频易错

  • 混淆离子的种类识别：误将 $-\lg c$ 最大值当作浓度最大，忽略 $-\lg c$ 越大浓度越小。
  • 不利用物料守恒：未意识到 $c(Cl^-) = c(Ag)_{总}$，从而导致阴离子曲线判断错误。
  • 起始点未重合：无配体时，饱和溶液中阳离子与阴离子浓度相等，两条曲线的 $-\lg c$ 必在右端点重叠，忘记此约束导致误判。
  • 稳定常数计算取点错误：取浓度相等点求 $K$ 时忽略了此时 $[L]$ 不是加入的总浓度，而是平衡浓度（图中已给出平衡浓度时可用）。
  • 误把各级配合物浓度变化规律套用于所有体系：若配体也能与阴离子作用，需重新列出守恒关系，但高考常考阴离子不配位的体系，可套用经典变化趋势。
