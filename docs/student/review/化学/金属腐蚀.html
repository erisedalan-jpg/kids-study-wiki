金属腐蚀

考点金属腐蚀权重6真题数1学科化学父主题化学反应原理

考点定位

  • 父主题：化学反应原理
  • 权重 weight：6
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 金属腐蚀的本质是金属原子失电子被氧化：$M-ne^- \rightarrow M^{n+}$。电化学腐蚀是最普遍的形式，需形成原电池（正极、负极、电解质、闭合回路）。
  • 判断原电池正负极：活泼金属作负极（发生氧化反应），较不活泼的导体或氧化剂作正极（发生还原反应）。如 $Mg-AgCl$ 电池中，$Mg$ 为负极，$AgCl$ 为正极活性物质。
  • 电极反应书写规则：负极失电子生成相应阳离子；正极得电子，注意实际氧化态物质的存在形式。难溶物（如 $AgCl$）写化学式，不能拆成离子。电解质环境（如海水）可能参与副反应。
  • 离子迁移方向：阴离子向负极移动，阳离子向正极移动。放电时，负极生成阳离子，正极消耗阳离子或生成阴离子，盐桥或溶液中离子定向迁移以保持电荷守恒。
  • 活泼金属（如 $Mg$、$Al$ 等）在水溶液中可能直接与水发生副反应：$Mg + 2H_2O = Mg(OH)_2 + H_2 \uparrow$，需结合金属活性进行判断。

解题方法与套路

  1. 拆解装置，定位角色：根据题目信息确定谁是负极、谁是正极。一般活泼金属为负极；特殊电池（如 $Mg-AgCl$）中 $AgCl$ 为正极活性物质，通过得电子生成 $Ag$ 和 $Cl^-$。
  2. 紧扣物质写电极反应：
  3. 负极：金属失电子，简单离子直接写 $M-ne^- = M^{n+}$（注意电荷守恒、质量守恒），若为碱性介质注意后续反应；
  4. 正极：考虑氧化态物质实际存在形式。若为不溶性盐（如 $AgCl$、$PbSO_4$），电极反应写其化学式，得电子生成金属和阴离子，如 $2AgCl + 2e^- = 2Ag + 2Cl^-$。
  5. 判断离子移动：牢记“阴离子走向负极，阳离子走向正极”。特别是当正极产生阴离子时，该阴离子会向负极运动，如 $Cl^-$ 在正极界面上生成后，由正极区域向负极迁移。
  6. 注意活泼金属的副反应：若负极金属能与电解质溶液（尤其是水）直接反应，会存在腐蚀副反应，影响电池效率，需识别并书写正确方程式。
  7. 逐项验证选项：对照以上分析，对每个选项进行正误判断。尤其注意电极反应书写的细节（能否拆成离子）、物质的存在形态。

高频易错

  • 正极反应错写为简单离子放电：见到“$AgCl$”直接写成 $Ag^+ + e^- = Ag$，忽略了 $AgCl$ 为难溶盐，应以化学式整体出现在电极反应中。正确为 $2AgCl + 2e^- = 2Ag + 2Cl^-$。
  • 离子迁移方向混乱：常见错误是认为 $Cl^-$ 向正极移动。实际上，原电池工作时，阴离子移向负极。本题中 $Cl^-$ 在正极生成，随后向负极迁移，方向判断易出错。
  • 忽略副反应：以为负极金属只发生电极反应，忘记活泼金属（如镁）在水中可直接与水发生氧化还原反应析氢，导致负极腐蚀加剧，消耗活性物质。
  • 电荷守恒与质量守恒失误：配平电极反应时电子数与离子电荷数不匹配，或漏写水、氢氧根等介质粒子。

代表题精讲

题目（2016全国新课标Ⅱ卷·05） $Mg-AgCl$ 电池是一种以海水为电解质溶液的水激活电池。判断下列叙述错误的是哪项？
选项：A. 负极反应 $Mg-2e^-=Mg^{2+}$；B. 正极反应 $Ag^+ + e^- = Ag$；C. 放电时 $Cl^-$ 由正极向负极迁移；D. 负极会发生副反应 $Mg+2H_2O=Mg(OH)_2+H_2 \uparrow$。

思路
- $Mg-AgCl$ 电池：$Mg$ 比 $Ag$ 活泼，作负极，$AgCl$ 作正极活性材料。海水作电解质，含大量 $Cl^-$、水等。
- 逐一检查电极反应、离子迁移、副反应。注意 $AgCl$ 难溶，正极反应需用 $AgCl$ 书写。

步骤
1. 分析负极：$Mg$ 失电子生成 $Mg^{2+}$，反应 $Mg-2e^-=Mg^{2+}$，A 正确。
2. 分析正极：$AgCl$ 得电子被还原成 $Ag$ 并释放 $Cl^-$，反应应为 $2AgCl+2e^- = 2Ag+2Cl^-$，而 B 选项写 $Ag^+ + e^- = Ag$，误将难溶 $AgCl$ 当作 $Ag^+$ 反应，B 错误。
3. 离子迁移：原电池中阴离子移向负极。正极产生 $Cl^-$，它会向负极移动，维持电中性，C 正确。
4. 副反应：$Mg$ 是活泼金属，在常温下能与水反应，海水为中性水溶液，发生 $Mg+2H_2O=Mg(OH)_2+H_2 \uparrow$，D 正确。
5. 综上，错误的是 B。

点评/变式
- 本题易错点为忽略难溶物在电极反应中的书写规则。变式训练：若将 $AgCl$ 换成 $PbSO_4$ 或 $Ag_2O$，正极反应均须写化学式，不可拆开；若介质为碱性溶液，负极的 $Mg^{2+}$ 会进一步与 $OH^-$ 结合，反应写为 $Mg+2OH^- -2e^- = Mg(OH)_2$。
- 水激活电池中的副反应暗示了金属腐蚀与电池反应的关联——负极金属在电解质溶液中发生的不只是电极反应，还有自腐蚀，这是实际应用需注意的问题。
