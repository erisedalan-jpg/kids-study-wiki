铁的化合物

知识精要

  • 铁的常见化合物：氯化物（$FeCl_2$、$FeCl_3$）、氧化物（$FeO$、$Fe_2O_3$、$Fe_3O_4$）、氢氧化物、高铁酸盐（如 $K_2FeO_4$）等。$Fe^{2+}$ 呈浅绿色，具有还原性；$Fe^{3+}$ 呈棕黄色，具有氧化性。
  • $FeCl_x$ 化学式的确定：利用离子交换法将 $Cl^-$ 完全置换为 $OH^-$，再用酸滴定 $OH^-$，由 $n(OH^-)=n(Cl^-)$ 和样品质量确定 $x$。
  • $FeCl_2$ 与 $FeCl_3$ 的制备：$FeCl_2$ 可用铁粉与盐酸反应；$FeCl_3$ 需用铁粉与氯气直接化合（不能用盐酸，因生成 $FeCl_2$）。
  • $Fe^{3+}$ 与 $I^-$ 的反应：$2Fe^{3+} + 2I^- = 2Fe^{2+} + I_2$，生成棕色碘单质，体现了 $Fe^{3+}$ 的氧化性。
  • 高铁酸钾（$K_2FeO_4$）：
  • 制备：$FeCl_3$ 与 $KClO$ 在强碱性条件下反应，$2Fe^{3+} + 3ClO^- + 10OH^- = 2FeO_4^{2-} + 3Cl^- + 5H_2O$，利用 $ClO^-$ 在碱性介质中的氧化性。
  • 电池应用：$K_2FeO_4$–$Zn$ 碱性电池中，$FeO_4^{2-}$ 作正极材料，正极反应为 $FeO_4^{2-} + 3e^- + 4H_2O = Fe(OH)_3 + 5OH^-$；总反应为 $3Zn + 2FeO_4^{2-} + 8H_2O = 3Zn(OH)_2 + 2Fe(OH)_3 + 4OH^-$。
  • 混合物中组分质量分数的求算：已知平均 $n(Fe):n(Cl)$，设 $FeCl_2$ 和 $FeCl_3$ 物质的量，建立物质的量关系式求解。

解题方法与套路

  1. 离子交换–滴定法确定卤化物组成
  2. 步骤 ① 写出交换关系：$Cl^- \rightarrow OH^-$，确保 $n(Cl^-)=n(OH^-)$。
  3. ② 滴定：$OH^- + H^+ = H_2O$，故 $n(OH^-)=c(HCl) \times V(HCl)$。
  4. ③ 求出 $n(Cl)$，结合样品质量求出 $n(Fe)$，基于 $FeCl_x$ 中 $n(Cl)=x \cdot n(Fe)$ 解得 $x$。
  5. 平均组成求混合物物质的量分数
  6. 设 $FeCl_2$ 物质的量为 $a$，$FeCl_3$ 物质的量为 $b$。
  7. 由 $\frac{2a+3b}{a+b}=2.1$ (平均氯铁比)，解出 $a/b$ 关系，再求 $FeCl_3$ 的物质的量分数 $=\frac{b}{a+b}$。
  8. 离子方程式的书写与配平
  9. 氧化还原反应：先根据化合价升降守恒配电子转移，再用电荷守恒和质量守恒补全 $H^+ /OH^-/H_2O$。介质碱性用 $OH^-$ 和 $H_2O$ 调平，酸性用 $H^+$ 和 $H_2O$。
  10. 例如 $Fe^{3+}+I^-$ 反应：$Fe^{3+} \rightarrow Fe^{2+}$，$I^- \rightarrow I_2$，配平得到 $2Fe^{3+}+2I^- = 2Fe^{2+}+I_2$。
  11. 碱性电池电极反应式的书写
  12. 正极：$FeO_4^{2-}$ 在碱性条件下得电子被还原生成 $Fe(OH)_3$，写出 $FeO_4^{2-} + 3e^- \rightarrow Fe(OH)_3$，再根据电荷守恒左侧补 $4H_2O$，右侧补 $5OH^-$ 得完全式。
  13. 总反应：正极 + 负极（$Zn \rightarrow Zn(OH)_2$）叠加，消去电子。
  14. 注意碱性介质产物为 $Zn(OH)_2$ 和 $Fe(OH)_3$。

高频易错

  • 离子交换中等量关系错误：$n(Cl^-)=n(OH^-)$ 而非物质的量浓度的直接交换，切忌漏掉溶液体积与浓度的换算。
  • $FeCl_3$ 与氢碘酸反应产物判断失误：认为生成 $FeI_3$，实际 $Fe^{3+}$ 可将 $I^-$ 氧化为 $I_2$，自身被还原为 $Fe^{2+}$。氧化性强弱：$Fe^{3+} > I_2$。
  • 高铁酸钾制备与电池反应中介质条件忽略：题目明确指出 “强碱性条件”“碱性电池”，配平时必须用 $OH^-$ 和 $H_2O$ 补平电荷与质量，不可出现 $H^+$。
  • 电极反应式书写时电荷不守恒：$FeO_4^{2-}$ 还原为 $Fe(OH)_3$，由电荷 -2 到 0 得 3 个电子，注意需加 $4H_2O$ 与 $5OH^-$ 满足氧原子和电荷守恒。
  • 混合物物质的量分数计算混淆：题目问的是物质的量分数（$n(FeCl_3)/n_总$），不要误算为质量分数。
  • $FeCl_2$ 与 $FeCl_3$ 的制备方法混淆：$Fe+2HCl \rightarrow FeCl_2+H_2\uparrow$；$2Fe+3Cl_2 \xrightarrow{\Delta} 2FeCl_3$。铁与盐酸不能得到 $FeCl_3$。

代表题精讲

题目简述（2012 新课标–08）
一道综合考查铁化合物化学式确定、混合物计算、氧化还原方程式书写及高铁酸钾电化学应用的试题。共 4 小问，包含滴定计算、定量分析、离子方程式书写和电极反应式。

（1）确定 $FeCl_x$ 的 $x$ 值
- 思路：阳离子交换后 $Cl^-$ 被 $OH^-$ 等物质的量置换，盐酸滴定流出液中的 $OH^-$ 得到 $n(OH^-)$，即为 $n(Cl^-)$；由样品质量与 $n(Cl^-)$ 计算 $n(Fe)$，利用化学式 $FeCl_x$ 求 $x$。
- 步骤
① $n(OH^-)=n(HCl)=0.40\ mol·L^{-1} \times 0.0250\ L = 0.010\ mol$。
② 则 $n(Cl^-)=0.010\ mol$。
③ 样品质量 $0.54\ g$，$m(Fe)=0.54\ g - 0.010\ mol \times 35.5\ g·mol^{-1} = 0.185\ g$。
④ $n(Fe)=0.185\ g / 56\ g·mol^{-1} \approx 0.00330\ mol$（精确计算：$0.54-0.355=0.185$, $0.185/56 \approx 0.00330$）。因 $n(Cl)=3n(Fe)$，得 $x=3$。
简便关系：$n(Cl)=0.010\ mol$，$x=0.010 / n(Fe)$，但更严谨是用 $n(Cl^-)=0.010$，$n(Fe)=(0.54-0.010\times 35.5)/56=0.010/3$，故 $x=3$。
- 点评/变式：离子交换滴定法的核心是等量代换。可变形为测定其他金属氯化物（如 $AlCl_x$）的组成，或使用阳离子交换柱先交换出 $H^+$ 再用碱滴定，原理类似。

（2）$FeCl_2$ 和 $FeCl_3$ 混合物中 $FeCl_3$ 的物质的量分数及制备
- 思路：设 $n(FeCl_2)=a\ mol$，$n(FeCl_3)=b\ mol$，利用平均氯铁比建立方程求解；再由铁与酸或氯气的反应规律回答制备方法。
- 步骤
① 方程：$\frac{2a+3b}{a+b}=2.1$ → $2a+3b=2.1a+2.1b$ → $0.9b=0.1a$ → $a=9b$。
② 物质的量分数 $=\frac{b}{a+b}=\frac{b}{10b}=0.10=10\%$。
③ 制备：$FeCl_2$ 用铁粉与盐酸；$FeCl_3$ 用铁粉与氯气。
- 点评/变式：平均值法在混合物计算中广谱适用。若题目给出质量比等其他条件，可转化为物质的量比再联立。

（3）$FeCl_3$ 与氢碘酸反应
- 思路：$Fe^{3+}$ 遇 $I^-$ 发生氧化还原反应，注意产物为 $Fe^{2+}$ 和 $I_2$，直接根据电子守恒配平。
- 步骤：$Fe^{3+}+e^- \rightarrow Fe^{2+}$，$2I^- -2e^- \rightarrow I_2$，最小公倍数后得 $2Fe^{3+}+2I^- = 2Fe^{2+}+I_2$。
- 点评/变式：该反应常用于 $Fe^{3+}$ 的检验（淀粉碘化钾试纸变蓝）或定量滴定。注意酸性条件下 $NO_3^-$ 等与 $I^-$ 反应也类似。

（4）高铁酸钾制备与碱性电池
- 思路：制备反应利用 $ClO^-$ 在碱性介质中将 $Fe^{3+}$ 氧化为 $FeO_4^{2-}$，依据化合价变化配平。电池部分，由总反应推导正极反应时，先写出负极 $Zn+2OH^- -2e^- = Zn(OH)_2$，再用总反应减去负极得到正极反应，或直接根据碱性条件书写 $FeO_4^{2-}$ 还原产物为 $Fe(OH)_3$。
- 步骤
① 制备离子方程式：$Fe^{3+} \rightarrow FeO_4^{2-}$ 化合价升 3，$ClO^- \rightarrow Cl^-$ 降 2，配系数后得 $2Fe^{3+}+3ClO^-+10OH^- = 2FeO_4^{2-}+3Cl^-+5H_2O$。
② 正极反应：$FeO_4^{2-} + 3e^- \rightarrow Fe(OH)_3$，在碱性条件下来源电荷守恒需补 $4H_2O$ 和 $5OH^-$，得 $FeO_4^{2-} + 3e^- + 4H_2O = Fe(OH)_3 + 5OH^-$。
③ 总反应：$3Zn + 2FeO_4^{2-} + 8H_2O = 3Zn(OH)_2 + 2Fe(OH)_3 + 4OH^-$。
- 点评/变式：碱性锌–高铁酸盐电池是新型环保电池的典型代表，书写电极反应时务必明确产物形态和介质参与。可变形为 $Li-FePO_4$ 等电极反应书写。
