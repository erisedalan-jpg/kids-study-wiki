知识精要

阿伏加德罗常数（$N_A$） 是连接宏观物理量与微观粒子数的桥梁，其数值约为 $6.02 \times 10^{23} \text{mol}^{-1}$。高考考查的核心在于判断特定宏观量所对应的微观粒子数是否等于给定数值。

  • 核心公式：$N = n \cdot N_A$，其中物质的量 $n = \frac{m}{M} = \frac{V}{V_m} = c \cdot V_{aq}$。
  • 气体摩尔体积（$V_m$）：仅适用于气体，且在标准状况（$0^\circ\text{C}$，$101\text{kPa}$）下，$V_m \approx 22.4 \, \text{L/mol}$。注意：$\text{SO}_2$、$\text{CH}_4$、$\text{C}_2\text{H}_4$ 等在标况下为气体，而 $\text{H}_2\text{O}$、$\text{SO}_3$、$\text{NO}_2$ 等不是。
  • 物质结构：
  • 白磷（$\text{P}_4$）：正四面体，1 个 $\text{P}_4$ 分子含 6 个 $\text{P}-\text{P}$ 键。
  • 石墨烯：六元环结构，每个碳原子被 3 个环共用，1 个六元环平均含 $6 \times \frac{1}{3} = 2$ 个碳原子。
  • 烷烃：1 个 $\text{C}n\text{H}$ 键，共}$ 分子含 $(n-1)$ 个 $\text{C}-\text{C}$ 键和 $(2n+2)$ 个 $\text{C}-\text{H价键总数为 $3n+1$。对于混合物且具有相同最简式（如正丁烷与异丁烷均为 $\text{C}4\text{H}$），可用极值法或直接按任意物质计算。
  • 溶液中的粒子行为：
  • 弱电解质电离/弱离子水解：$\text{Fe}^{3+}$、$\text{NH}_4^+$、$\text{SO}_3^{2-}$、$\text{PO}_4^{3-}$、$\text{HCO}_3^-$ 等均会发生水解或电离，导致其数目小于理论值。
  • 物料守恒：$c(\text{NaHCO}_3)=0.1\text{mol/L}$ 时，$n(\text{H}_2\text{CO}_3) + n(\text{HCO}_3^-) + n(\text{CO}_3^{2-}) = 0.1 N_A$（1L 溶液），而非仅 $\text{HCO}_3^-$ 与 $\text{CO}_3^{2-}$ 之和。同理，$1.0\text{L} \, \text{NaAlO}_2$ 溶液中氧原子数包含溶剂水，远大于 $2N_A$。
  • 氧化还原反应与电子转移：
  • 电子转移数 = 变价原子个数 × 单位原子化合价变化值 × 物质的量。计算时无需区分是否为可逆反应，因为化学反应速率不改变反应计量学中的转移电子能力。对于完全反应的部分，电子转移是确定值。如 $1\text{mol} \, \text{K}_2\text{Cr}_2\text{O}_7 \rightarrow \text{Cr}^{3+}$，2 个 $\text{Cr}$ 化合价从 +6 降至 +3，共转移 $6\text{mol} \, e^-$。
  • 可逆反应：对于反应前后气体分子总数不变的反应（如 $\text{H}_2 + \text{I}_2 \rightleftharpoons 2\text{HI}$），无论转化率如何，总物质的量恒定。若分子总数改变（如 $2\text{SO}_2 + \text{O}_2 \rightleftharpoons 2\text{SO}_3$），则不能直接用初始量计算反应后的分子总数，且转移电子数小于按完全反应计算值。
  • 混合物极值/最简式法：
  • 同最简式（如 $\text{NO}_2$ 与 $\text{N}_2\text{O}_4$ 均为 $\text{NO}_2$）的混合物，可按该最简式计算原子数。
  • 同质量分数元素的混合物（如乙烯 $\text{C}_2\text{H}_4$ 与环丁烷 $\text{C}_4\text{H}_8$，最简式均为 $\text{CH}_2$），碳原子或氢原子数可直接按质量除以最简式摩尔质量求得。

解题方法与套路

  1. 审题定类：通读选项，迅速将其归类。常考的 5 大类陷阱：气体摩尔体积适用条件、物质结构/化学键计算、溶液水解/电离平衡、电子转移数、可逆反应。
  2. 抓取关键条件：
    • 看状态与环境：看到“标准状况”且为气体，立刻联想 $22.4\text{L/mol}$；若是“常温常压”或非气体（$\text{H}_2\text{O}, \text{SO}_3, \text{HF}$ 等），此条件无效。
    • 看组成与结构：熟悉特例。看到 $\text{P}_4$ 想 6 个键，看到石墨想 2 个碳成 1 个环，看到烷烃算氢原子用最简式法更快。
    • 看溶液中的粒子：看到弱碱阳离子（$\text{NH}_4^+$）、弱酸阴离子（$\text{CO}_3^{2-}, \text{SO}_3^{2-}, \text{PO}_4^{3-}$），立即标记水解/电离，粒子数必小于直接乘积。看到无体积的 pH 选项，直接判错。
    • 看反应类型：是氧化还原还是非氧化还原反应，是否可逆。可逆反应中，反应物无法全耗尽，生成物量小于理论最大值。
  3. 精算与估算：
    • 计算物质的量 $n$：用 $n = \frac{m}{M}$ 或 $n = \frac{V}{V_m}$ 或 $n = cV$。
    • 计算目标粒子数 $N$：$N = n \times \text{粒子个数/每基本单元}$。粒子个数指原子、离子、质子、中子、电子或化学键。
    • 电子转移：固定公式 $N(e^-) = n(\text{变价元素})\times\Delta\text{化合价}$。
  4. 混合物处理：遇到混合物，先找最简式是否相同。若不相同但数据特殊，试极值法假设全为 A 或全为 B，看结果是否一致。若一致，则该值为确定值。

高频易错

  • 气体标况陷阱：忽视“标准状况”适用范围。如 $\text{SO}_3$ 标况下为固体、$\text{HF}$ 为液体、$\text{NO}_2$ 因自身缔合体积不准确。见“常温常压”不能使用 $22.4\text{L/mol}$。
  • 水解/电离忽略：只进行简单乘法计算，忘记 $\text{NH}_4^+$、$\text{Fe}^{3+}$、$\text{SO}_3^{2-}$、$\text{PO}_4^{3-}$ 等在水中会因水解/电离而减少。
  • 物质结构误判：
  • $\text{P}_4$ 误认为含 4 个 $\text{P}-\text{P}$ 键，实为 6 个。
  • 石墨烯/石墨误认为 1mol 碳对应 1mol 六元环，实为 $1\text{mol}$ 碳对应 $0.5\text{mol}$ 六元环。
  • 混淆羟基（$-OH$）和氢氧根离子（$OH^-$）：前者电子数为 $8+1=9$，后者为 $10$。
  • 物料守恒混淆：计算含碳弱酸盐溶液时，直接令所有含碳粒子数之和等于初始投入量，忽略了碳元素守恒包含所有形态（包括弱酸分子）。
  • 可逆反应分子数误算：$\text{SO}_2$ 与 $\text{O}_2$ 反应、$\text{N}_2$ 与 $\text{H}_2$ 反应是体积缩小的可逆反应，反应后分子总数不等同于初始投入量的加和绝对值。错误地用初始投料代替平衡态组成。
  • 溶剂水忽视：水溶液中的氧原子、氢原子计算，必须加上溶剂 $H_2O$ 贡献。

代表题 1：2018-新课标Ⅱ-05

题目：下列有关 $N_A$ 说法正确的是：A. 124g $\text{P}_4$ 含 $\text{P}-\text{P}$ 键 $4N_A$；B. 100mL $1\text{mol/L} \, \text{FeCl}_3$ 中含 $\text{Fe}^{3+}$ $0.1N_A$；C. 标况下 11.2L 甲烷和乙烯混合物含氢原子 $2N_A$；D. 密闭容器中 2mol $\text{SO}_2$ 和 1mol $\text{O}_2$ 催化反应后分子总数为 $2N_A$。 思路：分别运用物质结构、盐类水解、混合物分析和可逆反应原理进行判断。 步骤： - A 项：$n(\text{P}_4) = 124\text{g} / 124 \text{g/mol} = 1\text{mol}$。1 个 $\text{P}_4$ 含 6 个 $\text{P}-\text{P}$ 键，故键数为 $6N_A$。该项错。 - B 项：$n(\text{FeCl}_3) = 0.1\text{L} \times 1\text{mol/L} = 0.1\text{mol}$。由于 $\text{Fe}^{3+}$ 水解，实际 $\text{Fe}^{3+}$ 数目 $< 0.1N_A$。该项错。 - C 项：$n(\text{混合气}) = 11.2\text{L} / 22.4\text{L/mol} = 0.5\text{mol}$。无论甲烷 $\text{CH}_4$ 还是乙烯 $\text{C}_2\text{H}_4$，每摩尔气体均含 4mol 氢原子，故氢原子数为 $0.5 \times 4N_A = 2N_A$。该项正确。 - D 项：反应 $2\text{SO}_2 + \text{O}_2 \rightleftharpoons 2\text{SO}_3$ 为可逆反应且分子数减少。若完全反应，分子总数为 2mol；但反应不能彻底，故分子总数 $> 2N_A$ 且 $< 3N_A$。该项错。 点评/变式：C 项展示了混合物原子计算的捷径：若各组分含有相同数目的某原子，则可整体计算。变式：若为甲烷和乙烷混合物，则无法直接得出氢原子数。

代表题 2：2019-新课标Ⅱ-02

题目：下列说法错误的是：A. 3g $^3\text{He}$ 含中子数 $1N_A$；B. 1L $0.1\text{mol/L}$ 磷酸钠溶液含 $\text{PO}4^{3-}$ $0.1N_A$；C. 1mol $\text{K}_2\text{Cr}_2\text{O}_7$ 被还原为 $\text{Cr}^{3+}$ 转移电子 $6N_A$；D. 48g 正丁烷和 10g 异丁烷混合物中共价键为 $13N_A$。 思路：考查内容全面，需结合原子结构、电离理论、电子转移和有机分子结构进行辨析。 步骤： - A 项：$^3\text{He}$ 质量数为 3，中子数 = $3-2=1$。$n(^3\text{He})=3\text{g}/3\text{g/mol}=1\text{mol}$，故中子数为 $1N_A$。该项正确。 - B 项：$\text{Na}_3\text{PO}_4$ 是强电解质，但 $\text{PO}_4^{3-}$ 是弱酸根，水中发生水解：$\text{PO}_4^{3-} + \text{H}_2\text{O} \rightleftharpoons \text{HPO}_4^{2-} + \text{OH}^-$，故 $\text{PO}_4^{3-}$ 数目 $< 0.1N_A$。该项错误。 - C 项：$\text{K}_2\text{Cr}_2\text{O}_7$ 中 Cr 为 +6 价，产物 $\text{Cr}^{3+}$ 中为 +3 价，1mol 该物质含 2mol Cr，化合价降 6 价，转移 $6N_A$ 电子。该项正确。 - D 项：正丁烷和异丁烷互为同分异构体，化学式均为 $\text{C}_4\text{H}}$。总质量 = $58\text{g}$，总物质的量 = $58\text{g} / 58\text{g/mol} = 1\text{mol}$。每个 $\text{C4\text{H}$ 分子含 $3\times4+1=13$ 个共价键，故共价键总数为 $13N_A$。该项正确。 点评/变式：D 项运用了同分异构体混合物计算的“整合法”，当混合物成分互为同分异构体时，可视为一种纯净物计算。
