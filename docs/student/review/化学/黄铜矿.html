黄铜矿

考点定位

  • 父主题：元素化合物
  • 权重 weight：1
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择11
  • 难度分布：中1

知识精要

  • 黄铜矿：主要成分 $\mathrm{CuFeS_2}$，是炼铜最重要的矿物原料。
  • 火法炼铜核心阶段：
    • 造锍熔炼（反射炉）：$\mathrm{CuFeS_2}$ 与空气在 $1000\ ^\circ\mathrm{C}$ 左右反应，生成 $\mathrm{Cu_2S}$、$\mathrm{FeS}$ 以及 $\mathrm{FeO}$。加入石英砂（$\mathrm{SiO_2}$）造渣：$\mathrm{FeO + SiO_2 \xlongequal{\Delta} FeSiO_3}$（炉渣）。
    • 吹炼（转炉）：将冰铜（主要成分为 $\mathrm{Cu_2S}$ 和 $\mathrm{FeS}$）鼓入空气，先生成 $\mathrm{Cu_2O}$，随后 $\mathrm{Cu_2O}$ 与未反应的 $\mathrm{Cu_2S}$ 发生反应生成泡铜（粗铜）。
    • 电解精炼：粗铜作阳极，纯铜作阴极，$\mathrm{CuSO_4}$ 溶液作电解液。阳极主要反应：$\mathrm{Cu - 2e^- = Cu^{2+}}$；比铜活泼的金属（如 $\mathrm{Fe}$、$\mathrm{Zn}$ 等）也溶解进入溶液，不如铜活泼的金属（如 $\mathrm{Ag}$、$\mathrm{Au}$ 等）形成阳极泥。

解题方法与套路

  1. 抓住流程主线：原料→预处理→核心反应→产品分离→精制。本题反射炉（造锍与造渣）→转炉（吹炼成泡铜）→电解精炼（得精铜）。
  2. 方程式书写要点：
  3. 依据题给信息“生成低价硫化物/氧化物”确定产物价态：$\mathrm{Cu}$ 为 $\mathrm{Cu_2S}$（$\mathrm{Cu}$ 为 $+1$ 价），$\mathrm{Fe}$ 为 $\mathrm{FeS}$（$\mathrm{Fe}$ 为 $+2$ 价）和 $\mathrm{FeO}$。
  4. 配平遵循得失电子守恒、元素守恒，注意空气中 $\mathrm{O_2}$ 参与，常伴有 $\mathrm{SO_2}$ 生成。
  5. 物质成分推断：按“进出”原则，由加入物和已知产物反向推断中间产物的主要成分。
  6. 电化学问题：分清阴阳极及电极材料，阳极泥成分由金属活动性顺序推断。

高频易错

  • 铁的低价氧化物混淆：黄铜矿氧化过程中，$\mathrm{Fe}$ 的“低价氧化物”是 $\mathrm{FeO}$（+2价），不是 $\mathrm{Fe_2O_3}$ 或 $\mathrm{Fe_3O_4}$，书写方程式时易出错。
  • 炉渣成分：造渣反应产物为 $\mathrm{FeSiO_3}$（偏硅酸亚铁），易错写为 $\mathrm{Fe_2SiO_4}$。
  • 冰铜成分：冰铜是 $\mathrm{Cu_2S}$ 和 $\mathrm{FeS}$ 的熔融混合物，并非纯 $\mathrm{Cu_2S}$。
  • 泡铜生成的两个关联反应：吹炼时先生成 $\mathrm{Cu_2O}$，再与 $\mathrm{Cu_2S}$ 反应，易丢第一步或忽略 $\mathrm{Cu_2O}$ 的作用。
  • 电解精炼的阳极判断：粗铜作阳极发生氧化反应，纯铜作阴极，不可颠倒；阳极泥中的 $\mathrm{Ag}$、$\mathrm{Au}$ 等不放电，形成固体沉积。

代表题精讲

题目 （2012·新课标·11 节选重组）
黄铜矿（$\mathrm{CuFeS_2}$）炼制精铜的工艺：精矿砂与石英砂混合在反射炉中加热至 $1000\ ^\circ\mathrm{C}$ 左右通空气，生成铜和铁的低价硫化物，且部分 $\mathrm{Fe}$ 的硫化物转变为低价氧化物；随后在转炉中吹炼得泡铜，最后电解精炼得精铜。回答： (1) 反射炉中两个主要反应的化学方程式； (2) 转炉中产生泡铜的化学原理（用方程式表示）； (3) 电解精炼时，阳极主要电极反应式和阳极泥中主要富集的金属。

思路
(1) 由信息“低价硫化物”定 $\mathrm{Cu_2S}$、$\mathrm{FeS}$，“低价氧化物”为 $\mathrm{FeO}$，结合空气 $\mathrm{O_2}$ 氧化并生成 $\mathrm{SO_2}$，分别写 $\mathrm{CuFeS_2}$ 氧化和 $\mathrm{FeS}$ 氧化。(2) 吹炼利用 $\mathrm{Cu_2S}$ 先部分氧化成 $\mathrm{Cu_2O}$，$\mathrm{Cu_2O}$ 再与余下的 $\mathrm{Cu_2S}$ 反应得 $\mathrm{Cu}$。(3) 粗铜阳极失去电子得 $\mathrm{Cu^{2+}}$，比 $\mathrm{Cu}$ 不活泼的金属 $\mathrm{Ag}$、$\mathrm{Au}$ 不放电形成阳极泥。

步骤 1. 反射炉反应：
$$\begin{aligned} &2\mathrm{CuFeS_2 + O_2 \xlongequal{\Delta} Cu_2S + 2FeS + SO_2} \ &2\mathrm{FeS + 3O_2 \xlongequal{\Delta} 2FeO + 2SO_2} \end{aligned}$$ $\mathrm{FeO}$ 随后与石英砂反应：$\mathrm{FeO + SiO_2 \xlongequal{\Delta} FeSiO_3}$，形成炉渣除去。 2. 转炉吹炼泡铜：
$$\begin{aligned} &2\mathrm{Cu_2S + 3O_2 \xlongequal{\Delta} 2Cu_2O + 2SO_2} \ &2\mathrm{Cu_2O + Cu_2S \xlongequal{\Delta} 6Cu + SO_2} \end{aligned}$$ 总效果为 $\mathrm{Cu_2S + O_2 \xlongequal{\Delta} 2Cu + SO_2}$。 3. 电解精炼：阳极主要反应 $\mathrm{Cu - 2e^- = Cu^{2+}}$；阳极泥中主要富集 $\mathrm{Ag}$、$\mathrm{Au}$ 等贵金属。

点评/变式
本题以黄铜矿火法炼铜流程为载体，综合考察氧化还原方程式书写与电解原理。关键是从“低价”信息锁定 $\mathrm{Cu(+1)}$、$\mathrm{Fe(+2)}$ 物种。变式可延伸至湿法炼铜（$\mathrm{CuFeS_2}$ 与 $\mathrm{FeCl_3}$ 溶液等反应）或分析炉渣成分对环境的影响。
