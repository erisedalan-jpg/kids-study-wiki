三角函数值符号

考点三角函数值符号权重2真题数3学科数学父主题三角函数

考点定位

  • 父主题：三角函数
  • 权重 weight：2
  • 真题数：3；年份跨度：2013–2020
  • 出现题位：填空15 选择2 选择11
  • 难度分布：易1 中2

知识精要

  • 任意角 $\alpha$ 的三角函数在各象限的符号：
  • 第一象限：$\sin\alpha>0$，$\cos\alpha>0$，$\tan\alpha>0$
  • 第二象限：$\sin\alpha>0$，$\cos\alpha<0$，$\tan\alpha<0$
  • 第三象限：$\sin\alpha<0$，$\cos\alpha<0$，$\tan\alpha>0$
  • 第四象限：$\sin\alpha<0$，$\cos\alpha>0$，$\tan\alpha<0$
  • 二倍角公式：
    $\sin2\alpha = 2\sin\alpha\cos\alpha$，$\cos2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$
    据此可由 $\alpha$ 所在象限推断 $2\alpha$ 的符号。
  • 同角三角函数基本关系：
    $\sin^2\alpha + \cos^2\alpha = 1$，$\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha}$。用于“知一求二”或联立方程。
  • 两角和的正切公式：
    $\tan(\alpha + \beta) = \dfrac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$，特别地 $\tan\left(\alpha+\dfrac{\pi}{4}\right) = \dfrac{\tan\alpha + 1}{1 - \tan\alpha}$

解题方法与套路

  1. 定号先定象限：看到“第几象限角”，立刻写出该象限内 $\sin\alpha$ 和 $\cos\alpha$ 的符号，可用“一全正、二正弦、三双切、四余弦”速记。
  2. 二倍角符号判断：$\sin2\alpha$ 的符号只取决于 $\sin\alpha$ 与 $\cos\alpha$ 是否同号；$\cos2\alpha$ 的符号需要比较 $\cos^2\alpha$ 与 $\sin^2\alpha$ 的大小，不可直接由象限推定。
  3. 统一函数名称：给条件式含不同倍角时，先用倍角公式将 $2\alpha$ 化为 $\alpha$ 的函数，得到关于 $\sin\alpha,\cos\alpha$ 的方程。
  4. 联立平方关系求值：结合 $\sin^2\alpha + \cos^2\alpha = 1$，配合已知角的范围确定符号，解出具体数值。
  5. 利用和角公式求 $\tan\alpha$：给出 $\tan(\alpha+\frac{\pi}{4})$ 等条件时，先求 $\tan\alpha$，再由 $\tan\alpha$ 求 $\sin\alpha,\cos\alpha$，最后计算式子。

高频易错

  • 第四象限角 $\alpha$，$\sin\alpha<0,\cos\alpha>0$，但 $\cos2\alpha = \cos^2\alpha - \sin^2\alpha$ 符号不定，不能凭感觉选“$\cos2\alpha>0$”。
  • 解方程 $2\sin\alpha = \cos\alpha$ 时，未考虑角的范围就直接除以 $\cos\alpha$，可能漏掉 $\cos\alpha=0$ 的情况（题中给范围排除了即可）。
  • 由 $\tan\alpha$ 求 $\sin\alpha,\cos\alpha$ 时，忘记利用象限确定符号，导致最后结果符号错误。
  • 已知 $\sin\alpha+\cos\alpha$ 等，直接两边平方时忽略符号，解出两值后未根据象限取舍。
  • 混淆 $\sin2\alpha$ 与 $\cos2\alpha$ 的倍角展开形式，尤其在条件中是 $\cos2\alpha+1=2\cos^2\alpha$ 等变形。

代表题精讲

例1（2020·全国Ⅱ理）

题目：若 $\alpha$ 为第四象限角，则 $\cos2\alpha$ 与 $\sin2\alpha$ 的符号判断。
思路：由第四象限符号代入 $\sin2\alpha$ 的公式即可判定；$\cos2\alpha$ 需要比较平方差。
步骤：
1. $\alpha$ 在第四象限 $\Rightarrow \sin\alpha<0,\ \cos\alpha>0$。
2. $\sin2\alpha = 2\sin\alpha\cos\alpha$：一负一正相乘为负，故 $\sin2\alpha<0$，选项 D 正确。
3. $\cos2\alpha = \cos^2\alpha - \sin^2\alpha$：平方相减，符号需视绝对值大小而定，无法直接确定（可取特例验证 A、B 均可能）。
点评：双角符号题关键在原始象限符号，不可跳步猜结论。

例2（2019·全国Ⅰ文）

题目：已知 $\alpha \in (0,\frac{\pi}{2})$，$2\sin2\alpha = \cos2\alpha + 1$，求 $\sin\alpha$。
思路：用倍角公式化为同角，联立平方关系求解。
步骤：
1. 左边：$2\sin2\alpha = 4\sin\alpha\cos\alpha$；右边：$\cos2\alpha+1 = 2\cos^2\alpha$。
2. 方程化为 $4\sin\alpha\cos\alpha = 2\cos^2\alpha$。由 $\alpha\in(0,\frac{\pi}{2})$ 知 $\cos\alpha>0$，两边同除以 $2\cos\alpha$ 得 $2\sin\alpha = \cos\alpha$，即 $\tan\alpha=\frac{1}{2}$。
3. 构造直角三角形，得 $\sin\alpha = \frac{1}{\sqrt{1+2^2}} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$。
点评：本题注意到 $\cos\alpha>0$ 方可约分。由正切求正弦用“$\sin\alpha = \frac{\tan\alpha}{\sqrt{1+\tan^2\alpha}}$”更严谨。

例3（2013·全国Ⅰ理）

题目：设 $\theta$ 为第二象限角，若 $\tan\left(\theta+\frac{\pi}{4}\right)=\frac12$，求 $\sin\theta+\cos\theta$。
思路：先由两角和正切公式求 $\tan\theta$，再由同角关系及象限符号解出 $\sin\theta$ 和 $\cos\theta$。
步骤：
1. $\tan\left(\theta+\frac{\pi}{4}\right) = \frac{\tan\theta + 1}{1 - \tan\theta} = \frac12$，解得 $\tan\theta = -\frac13$。
2. 由 $\tan\theta = \frac{\sin\theta}{\cos\theta} = -\frac13$ 及 $\sin^2\theta+\cos^2\theta=1$，且 $\theta$ 在第二象限（$\sin\theta>0,\cos\theta<0$），联立得 $\cos\theta = -\frac{3}{\sqrt{10}}$，$\sin\theta = \frac{1}{\sqrt{10}}$。
3. 求和：$\sin\theta+\cos\theta = \frac{1-3}{\sqrt{10}} = -\frac{2}{\sqrt{10}} = -\frac{\sqrt{10}}{5}$。
点评：由 $\tan\theta$ 求正余弦时，务必用象限锁定符号，防止双解漏判。
