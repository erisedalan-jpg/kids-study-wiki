三角函数最值

知识精要

  1. 辅助角公式（合一变形） 对于 $y = a\sin x + b\cos x$，可化为： $$ y = \sqrt{a^2+b^2} \sin(x + \varphi) \quad \text{或} \quad y = \sqrt{a^2+b^2} \cos(x - \theta) $$ 其中 $\tan\varphi = \frac{b}{a}$，$\tan\theta = \frac{a}{b}$。

    • 最值：最大值为 $\sqrt{a^2+b^2}$，最小值为 $-\sqrt{a^2+b^2}$。
    • 成立条件：$x \in \mathbb{R}$；若 $x$ 有限制区间，需结合单调性求最值。

  2. 二次函数型 型如 $y = a\sin^2 x + b\sin x + c$ 或 $y = a\cos^2 x + b\cos x + c$，可利用 $\sin^2 x + \cos^2 x = 1$ 将函数统一为同名三角函数，然后换元：

    • 令 $t = \sin x$（或 $t = \cos x$），则 $t \in [-1, 1]$（注意题设区间对 $t$ 范围的进一步限制）。
    • 化为 $y = at^2 + bt + c$，在 $t$ 的闭区间上利用二次函数单调性或配方法求最值。

  3. 和差角公式化简 利用两角和与差的正弦、余弦公式将复杂表达式直接展开、合并，得出形如 $A\sin(x+\varphi)$ 或 $A\cos(x+\varphi)$ 的简单形式。

    • 常用公式：$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$ $\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$
    • 化简目标：化归为 $y = M\sin(\omega x + \varphi) + N$ 或 $y = M\cos(\omega x + \varphi) + N$，利用有界性（$|\sin| \le 1$，$|\cos| \le 1$）求最值。

  4. 图像距离型 形如 $|f(x) - g(x)|$ 的最值，可先利用三角恒等式将差化积或化为单一三角函数，再用有界性求解。 典型：$|\sin x - \cos x| = \sqrt{2}\left|\sin\left(x - \frac{\pi}{4}\right)\right|$，最大值为 $\sqrt{2}$。

  5. 三角形背景下的综合最值

    • 利用正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ 将边的线性组合转化为角的正弦组合，再利用三角恒等变换求最值。
    • 或利用余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ 建立边的关系，通过设变量构造二次方程，利用判别式 $\Delta \ge 0$ 求解最值范围。

解题方法与套路

  1. 观察结构，选择化简方向

    • 若为 $a\sin x + b\cos x$ 型或可化为该型 → 辅助角公式。
    • 若含 $\sin^2 x$，$\cos^2 x$，$\sin x\cos x$ 等 → 降幂或统一函数名，换元化为二次函数。
    • 若为和差角或结构可通过和差公式抵消 → 直接展开重组。
    • 含绝对值且为差的形式 → 先不处理绝对值，内部化一角一函数，再加绝对值。
    • 三角形边角混合 → 利用正、余弦定理统一为角（或边）。

  2. 统一变量与函数名 利用同角三角关系（$\sin^2 \theta + \cos^2 \theta = 1$）、二倍角公式（$\cos2\theta = 1 - 2\sin^2\theta = 2\cos^2\theta - 1$）等，将表达式转化为仅含 $\sin x$（或 $\cos x$）的多项式。

  3. 明确变量范围（关键步骤）

    • 若 $x \in \mathbb{R}$：$\sin x, \cos x$ 的范围为 $[-1, 1]$。
    • 若 $x$ 有限制区间（如 $[0, \frac{\pi}{2}]$）：必须求出整体的角 $\omega x + \varphi$ 的范围，再结合图像或单位圆确定 $\sin(\omega x + \varphi)$ 的范围；换元时也需相应限定新元 $t$ 的范围，不能简单取 $[-1,1]$。

  4. 求解最值

    • 对于 $y = A\sin(\omega x + \varphi) + k$：当 $\sin(\omega x + \varphi) = 1$ 时取最大值 $A + k$（$A>0$），当 $\sin(\omega x + \varphi) = -1$ 时取最小值 $-A + k$；若 $A<0$ 则相反。
    • 对于 $y = at^2 + bt + c$：配方得 $y = a\left(t + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a}$，结合 $t$ 范围及抛物线开口方向确定最值（可能在对称轴或边界取得）。

  5. 三角形背景的独特处理

    • 角化边：利用正弦定理，同时注意三角形内角限制（$A, B, C \in (0, \pi)$ 且 $A+B+C=\pi$）消元，转化为一个角的正弦型函数。
    • 边化角：利用余弦定理构造边的关系，进而转化为二次方程有解问题，由判别式 $\Delta \ge 0$ 求最值范围。

高频易错

  • 换元后忽略定义域限制：如 $x \in [0, \frac{\pi}{2}]$，令 $t = \cos x$，则 $t \in [0, 1]$，而不是 $[-1, 1]$，错误扩大范围会导致最值出错。
  • 辅助角公式中 $\varphi$ 的确定及符号错误：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi = \frac{b}{a}$，不注意 $a, b$ 的符号可能选错象限。
  • 二次函数配方与对称轴计算错误：系数提取、符号弄反，或直接在给定区间上错误判断单调性。
  • 绝对值处理不当：如求 $|\sin x - \cos x|$ 最值，忘记先化积再加绝对值，直接拆分可能无法比较。
  • 正弦型函数在定区间上最值不看端点：当对称轴不在区间内时，最值一定在端点取得，盲目认为最大值就是 $A$ 或最小值就是 $-A$ 而忽略区间。
  • 三角形中边角转化的等价性：由正弦定理得到的角的关系注意是否满足三角形内角和与边角大小关系（大边对大角），以及最终结果是否需要检验存在性。
  • 计算粗心：和差角展开时正负号漏写、恒等变形中少乘项等。

代表题精讲

题目 2017-文-13

求函数 $f(x) = 2\cos x + \sin x$ 的最大值。

思路：形如 $a\sin x + b\cos x$，直接用辅助角公式合成一个正弦（或余弦）函数，利用正弦函数的有界性得最大值。

步骤： $$ f(x) = \sin x + 2\cos x = \sqrt{1^2 + 2^2} \left( \frac{1}{\sqrt{5}}\sin x + \frac{2}{\sqrt{5}}\cos x \right) $$ 令 $\cos \varphi = \frac{1}{\sqrt{5}}$，$\sin \varphi = \frac{2}{\sqrt{5}}$（或取 $\varphi$ 满足 $\tan\varphi = 2$），则 $$ f(x) = \sqrt{5} (\sin x \cos \varphi + \cos x \sin \varphi) = \sqrt{5} \sin(x + \varphi). $$ 由于 $\sin(x + \varphi) \le 1$，所以 $f(x)_{\max} = \sqrt{5}$.

点评/变式：辅助角公式是最基本的三角函数最值模型，务必记牢 $\sqrt{a^2+b^2}$。变式：若求 $f(x) = \sin x - 2\cos x$ 的最大值，结果相同，角度 $\varphi$ 不同。

题目 2017-理-14

求函数 $f(x) = \sin^2 x + \cos x - \frac{3}{4}$，$x \in \left[0, \frac{\pi}{2}\right]$ 的最大值。

思路：含 $\sin^2 x$ 和 $\cos x$，利用 $\sin^2 x = 1 - \cos^2 x$ 统一为关于 $\cos x$ 的二次式；注意到 $x$ 范围限制，确定 $\cos x$ 的取值范围，换元后配方求最值。

步骤： 由 $\sin^2 x = 1 - \cos^2 x$ 得 $$ f(x) = 1 - \cos^2 x + \cos x - \frac{3}{4} = -\cos^2 x + \cos x + \frac{1}{4}. $$ 令 $t = \cos x$，由 $x \in \left[0, \frac{\pi}{2}\right]$ 知 $t \in [0, 1]$，则 $$ y = -t^2 + t + \frac{1}{4} = -\left(t - \frac{1}{2}\right)^2 + \frac{1}{2} + \frac{1}{4} = -\left(t - \frac{1}{2}\right)^2 + 1. $$ 当 $t = \frac{1}{2} \in [0, 1]$ 时，$y_{\max} = 1$，即 $f(x)_{\max} = 1$.

点评/变式：此题典型错误是换元后将 $t$ 范围误设为 $[-1,1]$，从而可能得到相同最大值（本题对称轴恰在 $[0,1]$ 内），但最小值就会算错。变式：求 $f(x) = \cos^2 x + \sin x$ 在 $x \in [0, \pi]$ 上的最值，需令 $t = \sin x \in [0,1]$。

题目 2016-文-11

求函数 $f(x) = \cos 2x + 6\cos\left(\frac{\pi}{2} - x\right)$ 的最大值。

思路：利用二倍角公式 $\cos 2x = 1 - 2\sin^2 x$，诱导公式 $\cos\left(\frac{\pi}{2} - x\right) = \sin x$，将函数化为关于 $\sin x$ 的二次函数，换元配方求最值。

步骤： $$ f(x) = (1 - 2\sin^2 x) + 6\sin x = -2\sin^2 x + 6\sin x + 1. $$ 令 $t = \sin x$，则 $t \in [-1, 1]$， $$ y = -2t^2 + 6t + 1 = -2\left(t^2 - 3t\right) + 1 = -2\left(t - \frac{3}{2}\right)^2 + \frac{11}{2} + 1? $$ 仔细配方： $$ -2\left(t^2 - 3t\right) + 1 = -2\left[\left(t - \frac{3}{2}\right)^2 - \frac{9}{4}\right] + 1 = -2\left(t - \frac{3}{2}\right)^2 + \frac{9}{2} + 1 = -2\left(t - \frac{3}{2}\right)^2 + \frac{11}{2}. $$ 对称轴 $t = \frac{3}{2} > 1$，故函数在 $[-1, 1]$ 上单调递增，当 $t=1$ 时 $y$ 最大： $y_{\max} = -2 + 6 + 1 = 5$. 所以最大值为 5.

点评/变式：本题极易因为不判断对称轴位置而直接将 $\frac{11}{2}$ 作为最大值，导致错误。必须注意二次函数在限定区间上的最值必须看对称轴与区间的关系。变式：$f(x) = -\cos 2x + 4\sin x$ 最值，仍化为 $\sin x$ 二次型，注意开口方向和区间。
