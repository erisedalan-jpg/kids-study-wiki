两点间距离公式

  • 真题数：7；年份跨度：2013–2022

知识精要

  • 两点间距离公式：点 $A(x_1,y_1)$, $B(x_2,y_2)$，则 $|AB| = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$。
  • 坐标形式扩展：
    • 若点在一维直线上，如与坐标轴交点，则距离为坐标差的绝对值。
    • 参数方程下的距离：将参数坐标代入距离公式，转化为关于参数的函数。
    • 极坐标下的距离：利用极径与极角关系，结合余弦定理或化为直角坐标求解。
  • 几何性质结合：
    • 抛物线定义：抛物线上点到焦点的距离等于到准线的距离。
    • 椭圆定义：椭圆上点到两焦点的距离之和为常数，但在求到定点距离时，通常化为二次函数或三角函数最值问题。
    • 圆的弦长：直线与圆相交，弦长常用几何法（弦心距、半径、半弦长构成的直角三角形）或代数法（代入后利用根与系数的关系）。
  • 相关变形式：
    • 中点坐标公式：$M(x_m, y_m)$，$x_m = \frac{x_1+x_2}{2}$，$y_m = \frac{y_1+y_2}{2}$。
    • 点到坐标原点的距离：$d = \sqrt{x^2 + y^2}$。

解题方法与套路

  1. 直接代入法：已知两点坐标或可轻易设出坐标，直接套用公式 $\sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$ 计算。
  2. 定义转化法：在抛物线、椭圆、双曲线等圆锥曲线背景中，充分利用曲线的几何定义，将到某点的距离等价转化为到定直线或定点的距离，简化计算。
  3. 参数方程法：当点在曲线上且需表达距离时，将坐标设为参数方程形式（如椭圆上点可设为 $(a\cos\theta, b\sin\theta)$，圆上点可设为 $(r\cos\theta, r\sin\theta)$），将距离问题转化为单一变量的三角函数或二次函数最值问题。
  4. 函数与方程思想：求距离最值时，通过已知条件建立距离关于某变量（坐标、参数、角度）的函数关系式，利用函数求值域方法（配方、三角函数有界性、导数等）求最值。
  5. 几何图形法：在求圆的弦长或与圆相关的距离时，优先画出图形，利用垂径定理、勾股定理、圆心距等几何关系，将代数计算转化为几何求值，减少计算量。

高频易错

  • 忽视定义域：用参数方程设点坐标时，参数的取值范围直接影响距离函数的值域。如参数 $\theta$ 的取值范围是否完整，角 $\alpha$ 是否有特殊限制（题中 $0 \le \alpha \le \pi$）。
  • 点到准线的距离计算：抛物线 $y^2=2px$ 的准线是 $x = -\frac{p}{2}$，点到准线的距离是横坐标之差的绝对值。容易忘记符号或直接写错坐标。
  • 混淆弦长公式：在直线与圆锥曲线相交求弦长时，公式 $|AB| = \sqrt{1+k^2}|x_1-x_2|$ 中的 $|x_1-x_2|$ 必须由 $\sqrt{(x_1+x_2)^2-4x_1x_2}$ 得出，切勿漏算开方。
  • 极坐标与直角坐标互化错误：转化时，$x=\rho\cos\theta$, $y=\rho\sin\theta$, $\rho^2=x^2+y^2$。交点坐标应统一化为直角坐标后求解或表达，避免在极坐标下混淆长度和角度。
  • 开方遗漏正负：解完方程求距离时，坐标差可能有多解，需结合几何位置判断符号或直接取绝对值，不能随意舍去负半轴的点。
  • 代数变形错误：在求最值配方法时，如由 $\sin^2\theta$ 和 $\sin\theta$ 构成二次函数，换元后忽略新元的范围 $[-1,1]$，导致最值求错。

代表题精讲

2022-理-05

题目：设 $F$ 为抛物线 $C: y^2=4x$ 的焦点，点 $A$ 在 $C$ 上，点 $B(3,0)$，若 $|AF|=|BF|$，则 $|AB|$ 等于多少。

思路：由抛物线方程求焦点 $F$ 坐标，进而计算出 $|BF|$ 的长度。利用 $|AF|=|BF|$，结合抛物线定义，将 $|AF|$ 转化为点 $A$ 到准线的距离，从而快速求出点 $A$ 的横坐标，再代入抛物线方程得到纵坐标，最后用两点间距离公式求 $|AB|$。

步骤： 1. 由 $y^2=4x$ 得 $p=2$，焦点 $F(1,0)$。 2. $B(3,0)$，则 $|BF| = \sqrt{(3-1)^2 + (0-0)^2} = 2$。 3. 由 $|AF|=|BF|=2$。根据抛物线定义，点 $A$ 到焦点 $F$ 的距离等于点 $A$ 到准线 $x=-1$ 的距离。 4. 设 $A(x_A, y_A)$，则 $x_A + 1 = 2$，解得 $x_A = 1$。 5. 点 $A$ 在抛物线上，代入得 $y_A^2 = 4 \times 1$，解得 $y_A = \pm 2$。 6. 利用两点间距离公式求 $|AB|$： $$|AB| = \sqrt{(1-3)^2 + (\pm 2 - 0)^2} = \sqrt{(-2)^2 + 4} = \sqrt{8} = 2\sqrt{2}$$。

点评/变式：此题核心是利用抛物线定义绕开解复杂方程组。若变式为椭圆或双曲线，应将定义转化为对应形式，或设出点坐标直接代入距离公式求解。

2021-文-11

题目：设 $B$ 是椭圆 $C: \frac{x^2}{5} + y^2 = 1$ 的上顶点，点 $P$ 在 $C$ 上，则 $|PB|$ 的最大值为多少。

思路：理解椭圆上顶点坐标，并设出动点 $P$ 的参数坐标（利用椭圆的参数方程），将 $|PB|$ 表示为参数 $\theta$ 的三角函数，最后通过二次函数配方式求该表达式的最大值。

步骤： 1. 求上顶点 $B$ 坐标：椭圆方程为 $\frac{x^2}{5} + y^2 = 1$，令 $x=0$，得 $y=1$，所以 $B(0,1)$。 2. 设点 $P$ 坐标：椭圆的参数方程为 $x = \sqrt{5}\cos\theta, \; y = \sin\theta$ （$\theta \in \mathbb{R}$），则 $P(\sqrt{5}\cos\theta, \sin\theta)$。 3. 表达 $|PB|^2$，便于求最值： $$|PB|^2 = (\sqrt{5}\cos\theta - 0)^2 + (\sin\theta - 1)^2$$ $$= 5\cos^2\theta + \sin^2\theta - 2\sin\theta + 1$$ 用 $\cos^2\theta = 1 - \sin^2\theta$ 代入： $$= 5(1 - \sin^2\theta) + \sin^2\theta - 2\sin\theta + 1$$ $$= -4\sin^2\theta - 2\sin\theta + 6$$ 4. 令 $t = \sin t \in [-1, 1]$，则 $|PB|^2 = -4t^2 - 2t + 6$。 这是开口向下的二次函数，对称轴为 $t = \frac{2}{2 \times (-4)} = -\frac{1}{4}$。 因为 $-\frac{1}{4} \in [-1,1]$，所以当 $t = -\frac{1}{4}$ 时，$|PB|^2$ 取最大值。 5. 计算最大值： $$|PB|^2_{\text{max}} = -4\left(-\frac{1}{4}\right)^2 - 2\left(-\frac{1}{4}\right) + 6 = -\frac{1}{4} + \frac{1}{2} + 6 = \frac{25}{4}$$ 所以 $|PB|_{\text{max}} = \frac{5}{2}$。

点评/变式：本题将几何最值化为二次函数最值，是典型方法。换元时务必注意新元的范围是由三角函数的有界性决定的。若点 $B$ 非顶点，坐标变化后配方形式不同但思路一致。

2021-理-11

题目：设 $B$ 是椭圆 $C: \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 (a>b>0)$ 的上顶点，若 $C$ 上的任意一点 $P$ 都满足 $|PB| \le 2b$，求 $C$ 的离心率的取值范围。

思路：本题是恒成立问题。同样设参数方程表达距离，将距离最大值不超过 $2b$ 的条件转化为关于参数 $\theta$ 的函数最值问题。通过二次函数在闭区间上的最大值与椭圆参数关系，解出 $a$、$b$ 满足的不等式，进而求出 $e$ 的范围。

步骤： 1. 求上顶点 $B(0, b)$。 2. 设点 $P(a\cos\theta, b\sin\theta)$，则 $$|PB|^2 = (a\cos\theta)^2 + (b\sin\theta - b)^2$$ $$= a^2\cos^2\theta + b^2\sin^2\theta - 2b^2\sin\theta + b^2$$ 代入 $\cos^2\theta = 1 - \sin^2\theta$： $$= a^2(1-\sin^2\theta) + b^2\sin^2\theta - 2b^2\sin\theta + b^2$$ $$= (b^2 - a^2)\sin^2\theta - 2b^2\sin\theta + a^2 + b^2$$ 3. 令 $t = \sin\theta \in [-1, 1]$，则 $f(t) = (b^2 - a^2)t^2 - 2b^2 t + a^2 + b^2$。因为 $a>b>0$，故 $b^2 - a^2 < 0$，这是一个开口向下的二次函数。 4. 要使任意 $t \in [-1,1]$ 都有 $f(t) \le (2b)^2 = 4b^2$，只需 $f(t)$ 在 $[-1,1]$ 上的最大值 $\le 4b^2$。 对称轴为 $t = \frac{2b^2}{2(b^2 - a^2)} = \frac{b^2}{b^2-a^2} < 0$。 比较对称轴与 $-1$ 的关系： - 若 $\frac{b^2}{b^2-a^2} \le -1$，即 $b^2 \ge a^2 - b^2 \Rightarrow a^2 \le 2b^2$。此时最大值在 $t=-1$ 处取得。 $f(-1) = (b^2-a^2) + 2b^2 + a^2 + b^2 = 4b^2$。符合条件 $f(t) \le 4b^2$。（恰好等于 $4b^2$） - 若 $\frac{b^2}{b^2-a^2} > -1$，即 $a^2 > 2b^2$。此时最大值在对称轴顶点处取得，函数值会大于 $f(-1)=4b^2$，与对所有 $P$ 满足条件矛盾。 5. 故必须有 $a^2 \le 2b^2$。由 $b^2 = a^2 - c^2$ 代入得： $$a^2 \le 2(a^2 - c^2) \Rightarrow a^2 \le 2a^2 - 2c^2 \Rightarrow 2c^2 \le a^2 \Rightarrow \frac{c^2}{a^2} \le \frac{1}{2}$$ 6. 离心率 $e = \frac{c}{a}$，所以 $e^2 \le \frac{1}{2}$，又因为椭圆 $0 < e < 1$，所以 $0 < e \le \frac{\sqrt{2}}{2}$。离心率的取值范围是 $\left(0, \frac{\sqrt{2}}{2}\right]$。

点评/变式：这是一道将距离条件转化为二次函数闭区间最值问题的经典题。关键在于分析二次项系数的正负，确定对称轴的位置，从而判定最大值点的位置。不要遗漏对称轴在定义域内或外的讨论，这是含参二次函数问题的核心陷阱。
