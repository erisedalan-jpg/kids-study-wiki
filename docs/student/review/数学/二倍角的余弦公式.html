二倍角的余弦公式

考点二倍角的余弦公式权重2真题数2学科数学父主题三角函数

考点定位

  • 父主题：三角函数
  • 权重 weight：2
  • 真题数：2；年份跨度：2013–2020
  • 出现题位：填空13 选择6
  • 难度分布：易2

知识精要

  • 二倍角的余弦公式（核心三形式） $$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha$$ $$\cos 2\alpha = 2\cos^2 \alpha - 1$$ $$\cos 2\alpha = 1 - 2\sin^2 \alpha$$ 以上公式对任意 $\alpha \in \mathbf{R}$ 均成立。
  • 升幂公式与降幂公式 由二倍角的后两个形式反向得到： $$1 + \cos 2\alpha = 2\cos^2 \alpha \quad\Rightarrow\quad \cos^2 \alpha = \frac{1 + \cos 2\alpha}{2}$$ $$1 - \cos 2\alpha = 2\sin^2 \alpha \quad\Rightarrow\quad \sin^2 \alpha = \frac{1 - \cos 2\alpha}{2}$$ 这两个公式是实现三角恒等变形中“降次”与“升角”的核心工具。
  • 适用条件 公式无需限定角的具体范围，但若涉及开方或符号选取（如 $\cos \alpha$ 从 $\cos^2 \alpha$ 开方），必须结合给定角的象限确定符号。

解题方法与套路

  1. 已知单角的弦值求二倍角的余弦值
    若已知 $\sin \alpha$，优先选用 $\cos 2\alpha = 1 - 2\sin^2 \alpha$；
    若已知 $\cos \alpha$，优先选用 $\cos 2\alpha = 2\cos^2 \alpha - 1$。
    这样可以一次代入直接得值，无需先求其他函数值。
  2. 已知二倍角弦值求单角余弦平方或相关组合
    利用降幂公式将 $\cos^2 \theta$ 或 $\sin^2 \theta$ 转化为含 $\cos 2\theta$ 的表达式，再代入已知量。
  3. 角度不一致时的配凑思路
    首先观察“所求角”与“已知角”的倍数关系或代数和关系。常用技巧：
  4. 所求角的一半或两倍与已知角有直接联系，优先使用二倍角或降幂公式。
  5. 结合诱导公式将 $2\alpha \pm \frac{\pi}{2}$、$\frac{\pi}{2} \pm \alpha$ 转化为已知单角或多倍角的弦值。 典型链路：$\cos^2(\alpha + \frac{\pi}{4}) = \frac{1 + \cos(2\alpha + \frac{\pi}{2})}{2} = \frac{1 - \sin 2\alpha}{2}$。
  6. 运算回路
    若遇到平方、四次方等高次项，反复使用降幂公式或 $\sin^2 \alpha + \cos^2 \alpha = 1$ 降次，直到出现可直接代入的已知条件。

高频易错

  • 公式选择错误
    将 $\sin^2 \alpha = \frac{1 - \cos 2\alpha}{2}$ 与 $\cos^2 \alpha$ 的降幂形式混淆，导致分子符号颠倒。务必记住：$\sin^2$ 前为“减”，$\cos^2$ 前为“加”。
  • 系数与分母遗漏
    降幂公式时忘记除以 $2$，或在代入 $\cos 2\alpha = 1 - 2\sin^2 \alpha$ 时漏掉系数 $2$。
  • 诱导公式误用
    $\cos(2\alpha + \frac{\pi}{2}) = -\sin 2\alpha$，容易少掉负号或误记为 $+\sin 2\alpha$。建议结合函数名变化与象限符号双重验证。
  • 忽略开方时的符号
    由 $\cos^2 \theta = a$ 求 $\cos \theta$ 时，若题目没有给出角的象限，则 $\cos \theta = \pm \sqrt{a}$，不可直接舍去负号。
  • 对标准形式的变形不敏感
    比如见到 $1 + \cos 2\alpha$ 要立即联想到 $2\cos^2 \alpha$，见到 $1 - \cos 2\alpha$ 要联想到 $2\sin^2 \alpha$，避免在简单题上绕远路。

代表题精讲

题目1（2020年文数）

题目 已知 $\sin x = -\dfrac{2}{3}$，求 $\cos 2x$。
思路 已知 $\sin x$ 直接求 $\cos 2x$，首选 $\cos 2x = 1 - 2\sin^2 x$，避免涉及 $\cos x$ 的符号讨论。
步骤
$$\cos 2x = 1 - 2\sin^2 x = 1 - 2 \times \left(-\frac{2}{3}\right)^2 = 1 - 2 \times \frac{4}{9} = 1 - \frac{8}{9} = \frac{1}{9}$$ 点评/变式 本题为基础题，体现“公式选择决定运算量”的思想。若先用 $\cos^2 x = 1 - \sin^2 x$ 再代 $\cos 2x = 2\cos^2 x - 1$，也能得解，但多一步求 $\cos^2 x$ 且易在正负号上犹豫。变式训练：若改为已知 $\cos x = \frac{1}{3}$，则优先用 $\cos 2x = 2\cos^2 x - 1$。

题目2（2013年文数）

题目 已知 $\sin 2\alpha = \dfrac{2}{3}$，求 $\cos^2\left(\alpha + \dfrac{\pi}{4}\right)$。
思路 所求式子为余弦的平方，且角度为 $\alpha + \frac{\pi}{4}$，自然想到降幂公式 $\cos^2 \theta = \frac{1 + \cos 2\theta}{2}$，此时新角 $2\left(\alpha + \frac{\pi}{4}\right) = 2\alpha + \frac{\pi}{2}$，利用诱导公式 $\cos\left(2\alpha + \frac{\pi}{2}\right) = -\sin 2\alpha$ 即可与已知挂钩。
步骤
$$ \begin{aligned} \cos^2\left(\alpha + \frac{\pi}{4}\right) &= \frac{1 + \cos\left[2\left(\alpha + \frac{\pi}{4}\right)\right]}{2} \ &= \frac{1 + \cos\left(2\alpha + \frac{\pi}{2}\right)}{2} \ &= \frac{1 - \sin 2\alpha}{2} \ &= \frac{1 - \frac{2}{3}}{2} = \frac{\frac{1}{3}}{2} = \frac{1}{6} \end{aligned} $$ 点评/变式 此题核心是“观察角之间的关系”：所求角的两倍与已知角差一个 $\frac{\pi}{2}$。诱导公式 $\cos\left(\theta + \frac{\pi}{2}\right) = -\sin \theta$ 是高频考点。变式：若已知 $\cos 2\alpha = \frac{1}{3}$，求 $\sin^2\left(\alpha - \frac{\pi}{4}\right)$，可用类似思路：$\sin^2\left(\alpha - \frac{\pi}{4}\right) = \frac{1 - \cos\left(2\alpha - \frac{\pi}{2}\right)}{2} = \frac{1 - \sin 2\alpha}{2}$，需由 $\cos 2\alpha$ 先求 $\sin 2\alpha$（注意符号），进一步增加难度。
