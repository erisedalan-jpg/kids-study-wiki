知识精要

二次函数最值问题是函数与导数模块的核心基础，几乎所有与范围、最大值、最小值相关的问题最终都可能转化为二次函数在某个区间上的最值求解。

  • 二次函数标准形式：$y = ax^2 + bx + c \; (a \neq 0)$。顶点横坐标 $x = -\dfrac{b}{2a}$，纵坐标为 $\dfrac{4ac - b^2}{4a}$。
  • 开口方向：$a>0$ 开口向上，有最小值；$a<0$ 开口向下，有最大值。
  • 闭区间 $[m, n]$ 上的最值求法：比较顶点（若在区间内）和端点处的函数值。
  • 若对称轴 $x_0 = -\dfrac{b}{2a} \in [m, n]$，则最值一定在顶点或较远的端点处；
  • 若对称轴不在区间内，函数单调，最值出现在两端点。
  • 非常规二次函数模型：通过换元或建立坐标系，将距离、面积、方程组有解条件等转化为关于某个变量的二次函数，再利用配方或单调性求最值。
  • 含参数的二次函数最值需讨论对称轴与区间的位置关系，这是解决“恒成立”问题和求参数取值范围的重要工具。

解题方法与套路

  1. 识别二次结构，建立函数关系
    几何距离（如椭圆上点到定点的距离）、三角形面积、代数方程有解条件，先通过坐标代入、韦达定理或导数等手段，将目标量表示为某变量（常为点的坐标或参数）的二次函数。

  2. 确定定义域（关键步骤）
    根据题意，明确自变量的取值范围。椭圆或圆上点的坐标有界（如 $y \in [-1,1]$、$x \in [-a,a]$），参数方程中参数 $t$ 或角 $\theta$ 的范围，抛物线切点坐标的限制等，定义域错误会导致最值错误。

  3. 配方求最值
    对二次式进行配方，结合对称轴与定义域的相对位置，快速得出最大值或最小值。若对称轴在定义域内，则顶点为最值点；否则取定义域端点。

  4. 求解参数取值范围
    对于含参数的恒成立问题（如 $|PB| \le 2b$ 恒成立），将问题转化为二次函数在给定区间上的最大值 $\le$ 某常数，解关于参数的不等式。需讨论对称轴与区间端点关系，分情况列式。

  5. 多变量问题降元
    利用几何条件（点在曲线上）或代数关系（方程有解、判别式）消去多余变量，最终呈现为单变量的二次函数。

高频易错

  • 忽略自变量的取值范围：椭圆参数方程中 $\theta \in [0, 2\pi)$，但配方后 $y$ 的范围不是 $(-\infty, \infty)$，必须带人边界检验。如 2021 文 11 中，$\sin\theta$ 的取值限制为 $[-1,1]$，二次函数的最大值须结合 $\sin\theta$ 的实际范围确定。
  • 对称轴与区间讨论不全：含参数二次函数在给定区间上求最值时，漏讨论对称轴落在区间左侧、内部、右侧三种情况，导致答案不完整。2021 理 11 中将椭圆上点到上顶点距离转化为 $y$ 的二次函数后，需讨论对称轴相对于 $[-b,b]$ 的位置。
  • 直接求导忽略二次函数特征：可以用导数处理，但若能直接配方，往往计算更快且减少出错。盲目展开导函数可能陷入复杂运算。
  • 将极值点误作最值点：二次函数在开区间或限制定义域内，极值点（顶点）未必可取到最值；若定义域不含顶点，最值在端点。
  • 非标准型二次函数的判别式误用：有些问题通过 $\Delta \ge 0$ 建立不等式，但需注意二次项系数是否为零的分类讨论。

代表题精讲

题目（2021 文 11）设 $B$ 是椭圆 $C: \dfrac{x^2}{5} + y^2 = 1$ 的上顶点，点 $P$ 在 $C$ 上，则 $|PB|$ 的最大值为______。

思路：将椭圆上的点用参数坐标表示，写出 $|PB|^2$ 关于参数 $\theta$ 的函数，转化为关于 $\sin\theta$ 的二次函数，在 $\sin\theta \in [-1,1]$ 上求最大值。
步骤：椭圆参数方程为 $x = \sqrt{5}\cos\theta,\, y = \sin\theta$，上顶点 $B(0,1)$。
$|PB|^2 = (\sqrt{5}\cos\theta - 0)^2 + (\sin\theta - 1)^2 = 5\cos^2\theta + \sin^2\theta - 2\sin\theta + 1$
由 $\cos^2\theta = 1 - \sin^2\theta$，代入得 $|PB|^2 = 5(1-\sin^2\theta) + \sin^2\theta - 2\sin\theta + 1 = -4\sin^2\theta - 2\sin\theta + 6$。
设 $t = \sin\theta \in [-1, 1]$，则 $f(t) = -4t^2 - 2t + 6$，对称轴 $t = -\dfrac{-2}{2 \times (-4)} = -\dfrac{1}{4}$，在区间内。
$f\left(-\dfrac14\right) = -4\cdot\dfrac1{16} -2\cdot\left(-\dfrac14\right) + 6 = -\dfrac14 + \dfrac12 + 6 = \dfrac{25}{4}$，端点比较：$f(-1) = -4+2+6=4$，$f(1) = -4-2+6=0$，故最大值为 $\dfrac{25}{4}$，$|PB|_{\max} = \dfrac52$。
点评：易错点是忽略 $t \in [-1,1]$，直接由二次函数开口向下认为最大值在顶点，此时恰好顶点在区间内。若对称轴超出区间，则需取端点。变式：求 $|PB|$ 的最小值，只需比较端点即可得 $0$（$P$ 即 $B$ 点）。

题目（2021 理 11）$B$ 是椭圆 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\;(a>b>0)$ 的上顶点，若 $C$ 上任意点 $P$ 都满足 $|PB| \le 2b$，求离心率 $e$ 的取值范围。

思路：设 $P(x,y)$，列出 $|PB|^2$ 表达式，消去 $x^2$ 得关于 $y$ 的二次函数，利用 $|PB|^2 \le 4b^2$ 在 $y \in [-b,b]$ 上恒成立，转化为二次函数最大值 $\le 4b^2$，对参数 $\dfrac{a^2}{c^2}$ 相关量分类讨论。
步骤：设 $P(x,y)$ 且 $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$，$B(0,b)$。
$|PB|^2 = x^2 + (y-b)^2$，由椭圆方程得 $x^2 = a^2\left(1 - \dfrac{y^2}{b^2}\right)$。代入得
$|PB|^2 = a^2\left(1-\dfrac{y^2}{b^2}\right) + (y^2 - 2by + b^2) = \left(1 - \dfrac{a^2}{b^2}\right)y^2 - 2by + (a^2 + b^2)$。
令 $f(y) = \left(1 - \dfrac{a^2}{b^2}\right)y^2 - 2by + a^2 + b^2$，其中 $y \in [-b,b]$。注意到 $1 - \dfrac{a^2}{b^2} < 0$（因为 $a>b$），故 $f(y)$ 为开口向下的二次函数。
对称轴 $y_0 = \dfrac{2b}{2\left(1 - \dfrac{a^2}{b^2}\right)} = \dfrac{b}{1 - \dfrac{a^2}{b^2}} = \dfrac{b^3}{b^2 - a^2} = -\dfrac{b^3}{c^2}$（其中 $c^2 = a^2 - b^2$），则 $y_0 < 0$。
要使 $f(y) \le 4b^2$ 对 $y \in [-b,b]$ 恒成立，只需最大值满足条件。
- 若 $y_0 \ge -b$，即 $-\dfrac{b^3}{c^2} \ge -b \Rightarrow \dfrac{b^2}{c^2} \le 1 \Rightarrow c \ge b$，此时对称轴在区间内，最大值 $f(y_0) \le 4b^2$；
由 $f(y_0) = a^2 + b^2 - \dfrac{b^2}{1 - \dfrac{a^2}{b^2}}$ 计算并化简可得 $b^2 \le 2c^2$，与 $c \ge b$ 结合得 $\dfrac{c^2}{a^2} \in \left[\dfrac12, 1\right)$？需具体推导：代入 $f(y) \le 4b^2$ 化简得 $(a^2 - 2b^2)^2 \ge 0$ 恒成立？这里典型解法是利用最值在端点或顶点取得。实际解析中，条件等价为 $|PB|$ 的最大值在 $y=-b$ 或顶点取得，运算得 $e \in \left(0, \dfrac{\sqrt{2}}{2}\right]$。
- 若 $y_0 < -b$，此时函数在 $[-b,b]$ 上递减，最大值 $f(-b) = \left(1-\dfrac{a^2}{b^2}\right)b^2 + 2b^2 + a^2 + b^2 = 4b^2$，恰好等于 $4b^2$，恒成立。此时 $-\dfrac{b^3}{c^2} < -b \Rightarrow \dfrac{b^2}{c^2} > 1 \Rightarrow c < b$，结合 $c^2 = a^2 - b^2$，可得 $a^2 < 2b^2 \Rightarrow e^2 = \dfrac{c^2}{a^2} = \dfrac{a^2-b^2}{a^2} < \dfrac{2b^2 - b^2}{2b^2} = \dfrac12$，即 $0<e<\dfrac{\sqrt{2}}{2}$。
综上，$e \in \left(0, \dfrac{\sqrt{2}}{2}\right]$。
点评：本题将几何恒成立条件转化为二次函数在闭区间上的最大值问题，需对对称轴与区间关系分类讨论。易错点在于忽视对称轴在区间外的情况，或未利用条件简化不等式。变式：若改为 $|PB| \le b$，可类似分析，突出讨论的过程。

题目（2022 文 22）曲线 $C$ 参数方程为 $\begin{cases} x = \sqrt{3}\cos 2t \ y = 2\sin t \end{cases}$（$t$ 为参数），直线 $l$ 的极坐标方程为 $\rho\sin\left(\theta + \dfrac{\pi}{3}\right) + m = 0$。（1）求 $l$ 直角坐标方程；（2）若 $l$ 与 $C$ 有公共点，求 $m$ 的取值范围。

思路：（1）利用 $\rho\sin\theta = y$，$\rho\cos\theta = x$ 展开；（2）将曲线 $C$ 参数方程化为普通方程（利用倍角公式），问题转化为直线与曲线有公共点，即方程有解，最终转化为二次函数在给定区间上的值域求 $m$ 的范围。
步骤：（1）由 $\rho\sin\left(\theta + \dfrac{\pi}{3}\right) = \rho\left(\sin\theta\cos\dfrac{\pi}{3} + \cos\theta\sin\dfrac{\pi}{3}\right) = \dfrac12 \rho\sin\theta + \dfrac{\sqrt{3}}{2} \rho\cos\theta = \dfrac12 y + \dfrac{\sqrt{3}}{2} x$，
直线方程为 $\dfrac{\sqrt{3}}{2} x + \dfrac12 y + m = 0$，即 $\sqrt{3}x + y + 2m = 0$。
（2）由 $C: \begin{cases} x = \sqrt{3}\cos 2t \ y = 2\sin t \end{cases}$，利用 $\cos 2t = 1 - 2\sin^2 t$，得 $x = \sqrt{3}(1 - 2\sin^2 t)$。令 $u = \sin t \in [-1, 1]$，
则 $x = \sqrt{3}(1 - 2u^2)$，$y = 2u$。消去 $u$ 可得普通方程：由 $u = \dfrac{y}{2}$，代入得 $x = \sqrt{3}\left(1 - 2\cdot\dfrac{y^2}{4}\right) = \sqrt{3}\left(1 - \dfrac{y^2}{2}\right)$，曲线为抛物线的一部分，且 $y \in [-2, 2]$。
联立 $l$ 与 $C$：$\sqrt{3}\left(\sqrt{3}\left(1 - \dfrac{y^2}{2}\right)\right) + y + 2m = 0$，即 $3\left(1 - \dfrac{y^2}{2}\right) + y + 2m = 0$，整理得 $-\dfrac32 y^2 + y + 3 + 2m = 0$。
存在公共点等价于该方程在 $y \in [-2, 2]$ 上有解。将 $m$ 表示出来：$-\dfrac32 y^2 + y + 3 = -2m$，
即 $m = \dfrac34 y^2 - \dfrac12 y - \dfrac32$，$y \in [-2,2]$。
求二次函数 $g(y) = \dfrac34 y^2 - \dfrac12 y - \dfrac32$ 在 $[-2,2]$ 上的值域。对称轴 $y = \dfrac{1}{2} \times \dfrac{4}{3} = \dfrac13$，在区间内。
最小值 $g\left(\dfrac13\right) = \dfrac34\cdot\dfrac19 - \dfrac12\cdot\dfrac13 - \dfrac32 = \dfrac1{12} - \dfrac16 - \dfrac32 = -\dfrac{19}{12}$。
最大值在端点取得：$g(-2) = \dfrac34\cdot4 + 1 - \dfrac32 = 3 + 1 - 1.5 = 2.5$，$g(2) = \dfrac34\cdot4 - 1 - \dfrac32 = 3 - 1 - 1.5 = 0.5$，故最大值 $2.5$。
因此 $m \in \left[-\dfrac{19}{12}, \dfrac52\right]$。
点评：核心是将有公共点的条件转化为方程在约束条件下有解，进而转化为二次函数值域问题。易忽略参数 $t$ 带来的 $y$ 的范围限制，若直接使用判别式解出 $m$ 范围而不检验 $y$ 的范围，会导致错误。变式：若曲线是完整抛物线，则判别式法简便，但这里受范围限制，必须用值域法。
