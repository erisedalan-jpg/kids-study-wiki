知识精要

  • 复数模的计算：若复数 $z = a + bi$（$a, b \in \mathbf{R}$），则其模长 $|z| = \sqrt{a^2 + b^2}$。此为代数运算中复数领域的基础核心。
  • 函数值的代入运算：若函数 $f(x)$ 的定义明确，求参数或函数值时，将已知点坐标或变量值直接代入解析式中，转化为方程（组）求解。这是函数与方程思想的直接体现。
  • 实数运算的根本：涉及幂运算、四则运算时，务必遵循先乘方、再乘除、后加减的顺序，并注意符号的准确性。代数运算的根基在于对算理的精确执行。

解题方法与套路

  1. 明确运算对象的结构：遇到复数先分离实部与虚部；遇到函数先看解析式的构成（如多项式、分式等）。
  2. 代入已知条件：将题目给定的数值（如实部、虚部，或函数过的点）直接代入相应的公式或解析式中。
  3. 建立等量关系：通过代入，将题目的文字或几何条件转化为纯粹的代数方程。
  4. 精确化简求解：严格按照运算规则进行计算。如计算 $|1-i|$ 时，先平方再开方：$\sqrt{1^2 + (-1)^2}$；解方程 $-a+2=4$ 时，注意移项变号。

高频易错

  • 复数模与绝对值的混淆：切莫将 $|z|$ 等同于实数绝对值去直接去掉符号。必须牢记 $|z| = \sqrt{a^2 + b^2}$，结果是实数。
  • 代入时的符号错误：如将形如 $f(-1)$ 代入 $-2x$ 时，极易因负号丢失或叠加错误，导致正负性反转。
  • 运算跳步导致失分：求解如 $4 = a(-1)^3 - 2(-1)$ 此类算式时，建议分步计算幂次和乘法，再整理方程，避免一步到位产生的计算事故。
  • 忽略定义域：虽然真题层面较简单，但在涉及根式、分式等复杂函数的代入时，需潜意识验证结果的合法性。

代表题精讲

2024-新课标Ⅱ-01

  • 题目：已知 $z = 1 - i$，求 $|z|$ 的值。
  • 思路：直接应用复数模长的定义公式，找出实部与虚部进行代数运算。
  • 步骤：
  • 识别复数：$z = 1 - i$，实部 $a=1$，虚部 $b=-1$。
  • 套用模长公式：$|z| = \sqrt{a^2 + b^2}$。
  • 代入计算：$|z| = \sqrt{1^2 + (-1)^2} = \sqrt{1+1} = \sqrt{2}$。
  • 点评/变式： 本题是对复数代数运算最直接的考查。核心在于公式记忆的准确度与平方运算的速度。变式训练可关注分子或分母含复数的模长计算，如 $\left|\dfrac{1+i}{1-i}\right|$，需先化简再求模。

2015-文-13

  • 题目：已知函数 $f(x) = ax^3 - 2x$ 的图象过点 $(-1, 4)$，求实数 $a$ 的值。
  • 思路：利用点在函数图象上的几何性质，将点的横纵坐标对应代入解析式，构建关于 $a$ 的方程求解。
  • 步骤：
  • 依题意，点 $(-1, 4)$ 满足函数关系，即当 $x=-1$ 时，$f(-1)=4$。
  • 将 $x=-1$ 代入函数式：$f(-1) = a(-1)^3 - 2(-1)$。
  • 计算代数式：$a(-1) + 2 = -a + 2$。
  • 建立并解方程：$-a + 2 = 4$，得 $-a = 2$，故 $a = -2$。
  • 点评/变式： 核心在于代入后的指数运算与去括号法则。该题型常作为复杂函数或导数应用题的基元步骤出现。变式可引入奇偶性，如已知 $f(x) + g(x) = x^3$，其中 $f(x)$ 为奇函数，$g(x)$ 为偶函数，让考生通过赋值（如代入 $x=-1$）构造方程解出参数。
