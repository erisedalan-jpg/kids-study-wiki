余弦函数

知识精要

  • 余弦函数的定义与图像：余弦函数 $y = \cos x$，定义域 $\mathbf{R}$，值域 $[-1,1]$，周期 $2\pi$，偶函数，在 $[2k\pi, 2k\pi+\pi]$ 上单调递减，在 $[2k\pi-\pi, 2k\pi]$ 上单调递增，图像关于 $y$ 轴对称。
  • 余弦函数的常用公式：
  • 平方关系：$\cos^2 x + \sin^2 x = 1$.
  • 两角和与差：$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$.
  • 二倍角公式：$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$.
  • 降幂公式：$\cos^2\alpha = \dfrac{1+\cos 2\alpha}{2}$，$\sin^2\alpha = \dfrac{1-\cos 2\alpha}{2}$.
  • 诱导公式：$\cos(\pi \pm \alpha) = -\cos\alpha$，$\cos(2\pi - \alpha) = \cos\alpha$，$\cos(\frac{\pi}{2} \pm \alpha) = \mp \sin\alpha$.
  • 和差化积：$\cos\alpha + \cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$，$\cos\alpha - \cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$.
  • 三角形中的余弦定理：在 $\triangle ABC$ 中，角 $A, B, C$ 的对边分别为 $a, b, c$，则 $b^2 = a^2 + c^2 - 2ac\cos B$，变形得 $\cos B = \dfrac{a^2 + c^2 - b^2}{2ac}$.
  • 隐含条件：三角形内角和 $A+B+C=\pi$，因此 $\cos B = -\cos(A+C)$，$\sin B = \sin(A+C)$.

解题方法与套路

  1. 统一角度与名称：若条件中含有 $A-C$ 与 $B$，立刻利用 $B = \pi - (A+C)$ 转化为 $\cos B = -\cos(A+C)$，将不同角组合合并为相同或互补角，再利用和差角公式展开或逆用。
  2. 边角互化：出现边长等式（如 $b^2 = ac$）时，优先用正弦定理 $a=2R\sin A$ 等化为角的关系，或用余弦定理将角的余弦转化为边，根据目标选择方向。求角常常化为纯角的三角函数方程。
  3. 多倍角公式与降幂：遇到平方、乘积形式时，用降幂公式 $\cos^2 x = \frac{1+\cos 2x}{2}$、积化和差等，将二次化为一次，消去常数，简化方程。
  4. 整体代换与解方程：将整理出的关于 $\cos$ 或 $\sin$ 的方程式看作整体，利用有界性、特定角范围进行求解，必要时配合均值不等式或二次函数求最值。
  5. 检验角的范围：求出 $\cos B$ 值后，由已知条件或边长关系确定 $B$ 是锐角还是钝角，再确认唯一解。

高频易错

  • 忽视三角形内角限制：直接将 $A-C$ 和 $B$ 展开而忘记 $A+B+C=\pi$，导致无法化简。务必先利用互补关系将多角统一到少数角。
  • 和角公式符号错误：$\cos(A+C) = \cos A\cos C - \sin A\sin C$，注意是减号，转化为 $-\cos B$ 时易漏掉负号。
  • 降幂时常数项处理失误：如 $b^2=ac$ 转化为 $\sin^2 B = \sin A\sin C$ 后，降幂出现 $\frac{1-\cos 2B}{2} = \sin A\sin C$，右侧若再用积化和差，注意系数 $\frac12$ 的整体平衡。
  • 忽略正余弦的有界性：得到 $\cos(A-C)$ 或 $\cos B$ 的方程后，未检查解是否在 $[-1,1]$ 内，导致引入增根。
  • 忘记检验角是否合理：由 $\cos B = \frac12$ 得到 $B=60^\circ$ 或 $300^\circ$，不结合三角形内角范围而误写多解。
  • 余弦定理边角互化时错用对应关系：角度与对边必须严格对应，如 $b$ 对应 $B$，切勿张冠李戴。

代表题精讲

2009-理-17（2009年高考全国卷理科数学）

题目
在 $\triangle ABC$ 中，内角 $A, B, C$ 的对边长分别为 $a, b, c$，已知 $\cos(A-C) + \cos B = \frac{3}{2}$，且 $b^2 = ac$，求角 $B$.

思路
利用 $B = \pi - (A+C)$ 将 $\cos B$ 化为 $-\cos(A+C)$，代入条件得 $\cos(A-C) - \cos(A+C) = \frac{3}{2}$。左边用和差化积或两角和差公式展开，得出 $\sin A\sin C$ 的表达式。再由 $b^2=ac$ 用正弦定理化为 $\sin^2 B = \sin A\sin C$，联立消去 $\sin A\sin C$，得到关于 $\sin B$ 或 $\cos B$ 的方程，结合三角恒等式和范围求解。也可将 $b^2=ac$ 用余弦定理转化为边的关系，但化为角更直接。

步骤
1. 在 $\triangle ABC$ 中，$B = \pi - (A+C)$，于是 $\cos B = -\cos(A+C)$.
条件化为 $\cos(A-C) - \cos(A+C) = \frac{3}{2}$.
2. 展开差与和的余弦：
$\cos(A-C) = \cos A\cos C + \sin A\sin C$,
$\cos(A+C) = \cos A\cos C - \sin A\sin C$,
两式相减：$\cos(A-C) - \cos(A+C) = 2\sin A\sin C$.
因此 $2\sin A\sin C = \frac{3}{2}$，即 $\sin A\sin C = \frac{3}{4}$.
3. 由正弦定理 $a=2R\sin A$，$b=2R\sin B$，$c=2R\sin C$，代入 $b^2 = ac$ 得：
$(2R\sin B)^2 = (2R\sin A)(2R\sin C) \Rightarrow \sin^2 B = \sin A\sin C$.
结合上一步，$\sin^2 B = \frac{3}{4}$.
4. 在 $\triangle ABC$ 中，$0 < B < \pi$，$\sin B > 0$，故 $\sin B = \frac{\sqrt{3}}{2}$.
所以 $B = \frac{\pi}{3}$ 或 $B = \frac{2\pi}{3}$.
5. 检验：若 $B = \frac{2\pi}{3}$，则 $\sin B = \frac{\sqrt{3}}{2}$ 依然满足 $\sin^2 B = \frac{3}{4}$。但结合条件 $b^2=ac$ 及余弦定理可进一步判断，实际上 $B=\frac{2\pi}{3}$ 会使 $b$ 最长，但 $b^2=ac$ 与余弦定理联立会导致矛盾（或由此时 $A, C$ 均为小于 $\frac{\pi}{3}$ 的角，$\sin A\sin C$ 的最大值小于 $\frac{3}{4}$）。更简洁的方法：由 $b^2=ac$ 得 $b$ 不是最大边就是中间边，$B$ 不可能为钝角？计算表明 $\sin A\sin C = \frac{3}{4}$，且 $A+C = \frac{2\pi}{3}$，可推出 $\cos(A-C) = 1$，进而 $A=C$，此时 $A=C=\frac{\pi}{3}$，$B=\frac{\pi}{3}$。故舍去 $B = \frac{2\pi}{3}$.
综上，$B = \frac{\pi}{3}$.

点评/变式
- 本题核心考点是三角恒等变换与正余弦定理的综合应用，需熟练掌握“化多角为单角”、“边角互化”两种主流路径。
- 易失分点在最后一步定解：不能仅由 $\sin B$ 得两解就草率下结论，务必结合三角形的隐含条件或其他边角关系进行筛解。
- 变式：若条件改为 $\cos(A-C) + \cos B = 1$，$a, b, c$ 成等比，求 $B$；或给出 $\sin A\sin C$ 具体值反向求等比关系。此类问题均可仿照上述步骤，先将三角函数关系化为正弦积，再用正弦定理沟通边比。
