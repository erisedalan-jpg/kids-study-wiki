余弦定理

知识精要

  • 余弦定理：三角形任何一边的平方等于其他两边平方的和减去这两边与它们夹角的余弦的积的两倍。 $$a^2 = b^2 + c^2 - 2bc\cos A$$ $$b^2 = a^2 + c^2 - 2ac\cos B$$ $$c^2 = a^2 + b^2 - 2ab\cos C$$
  • 变形（角的余弦表达式）： $$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$$ $$\cos B = \frac{a^2 + c^2 - b^2}{2ac}$$ $$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$
  • 适用条件与场景：
  • 已知两边及其夹角，求第三边。
  • 已知三边，求任意一角。
  • 已知两边和其中一边的对角，求第三边（常结合二次方程讨论多解）。
  • 关联定理：
  • 正弦定理：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$（$R$ 为外接圆半径）。
  • 三角形面积公式：$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$。
  • 勾股定理：当 $A=90^\circ$ 时，$a^2 = b^2 + c^2$，是余弦定理的特例。

解题方法与套路

  1. 结构识别与公式选取
  2. 题目中出现“两边一夹角”直接代入余弦定理求对边。
  3. 题目中给出三边或代数关系（如 $a^2+b^2-c^2$ 形式），优先利用余弦定理的推论求角。

  4. “两边一对角”求第三边时，设未知边列方程，利用余弦定理得到二次方程，根据判别式或边长正负讨论解的存在性与个数。

  5. 边角互化策略

  6. 角化边：利用正弦定理 $a=2R\sin A$、$b=2R\sin B$、$c=2R\sin C$ 将已知条件全部转化为边的关系，再结合余弦定理消元。
  7. 边化角：将边的关系全部转化为角的正弦，利用三角恒等变换化简求角。

  8. 证明$2a^2=b^2+c^2$等线性组合关系：高频使用 $\sin(A+C)=\sin B$ 及两角和差公式展开，统一角度后化简。

  9. 对边对角的统一处理

  10. 若题目涉及“三角形面积”与“已知一角”，立即联立 $S=\frac{1}{2}\text{两边}\cdot\sin\text{夹角}$ 与余弦定理，构造方程组求解未知边。

  11. 遇到平面四边形或多边形，通过添加对角线将问题转化为多个三角形，逐次使用正、余弦定理传递边长。

  12. 几何条件的代数化

  13. 中线条件：在相关三角形中使用余弦定理，或利用向量中线长公式，注意互补角余弦互为相反数。
  14. 折叠、翻折问题：关注翻折前后不变的线段长度与几何关系，对固定三角形集中施用余弦定理。

高频易错

  • 角的范围与多解取舍：已知两边及一边对角时，忽略判断“大边对大角”导致漏解或增解。三角形内角范围 $(0^\circ, 180^\circ)$，余弦值对应角的唯一性（单调）优于正弦值。
  • 公式混淆与符号错误：误记 $a^2 = b^2 + c^2 - 2bc\cos A$ 为加号或与向量点积混淆，导致最终结果符号出错。
  • 结构误判：看到形似 $b\cos C + c\cos B$ 的结构未利用射影定理（即 $a = b\cos C + c\cos B$）简化，而反复强算两角和的三角函数，徒增计算量。
  • 隐含条件疏漏：
  • 互补角关系：$\cos(\pi - \theta) = -\cos\theta$ 在四边形内角互补时频繁使用，方向反了导致边长计算错误。
  • 中线条件：中点在两个小三角形中产生的互补角，其余弦值互为相反数，构建方程时符号极易弄错。
  • 面积公式系数丢掉 $\frac{1}{2}$。
  • 计算层面常见失误：
  • 平方根开方时不加讨论直接取正，忽视线段长必须为正的事实。
  • 将异面直线夹角误用三角形中余弦定理，未注意取绝对值或锐角的规定。

代表题精讲

题目：2023-新课标Ⅱ-17

题目简述：$\triangle ABC$ 面积为 $\sqrt{3}$，$D$为$BC$中点，$AD=1$。 (1) $\angle ADC = \frac{\pi}{3}$，求 $\tan B$；(2) $b^2 + c^2 = 8$，求 $b,c$。

思路：(1) 先用面积公式与已知角在 $\triangle ADC$ 中求出 $a$，再利用中线分割形成的互补角关系在 $\triangle ABD$ 中用余弦定理求 $c$，最后在 $\triangle ABC$ 中求 $B$ 的余弦与正切。(2) 在 $\triangle ABC, \triangle ABD, \triangle ACD$ 中反复利用余弦定理与互补角关系消去 $\cos \angle ADC$，得到 $a,b,c$ 关系式，联立已知条件求解。

步骤： 1. (1) $S_{\triangle ADC} = \frac{1}{2} \cdot 1 \cdot DC \cdot \sin \frac{\pi}{3} = \frac{1}{2} S_{\triangle ABC} = \frac{\sqrt{3}}{2}$，解得 $DC=2$，故 $a=4$。 2. 在 $\triangle ABD$ 中，$\angle ADB = \frac{2\pi}{3}$，由余弦定理：$c^2 = 1^2 + 2^2 - 2\cdot 1 \cdot 2 \cdot \cos \frac{2\pi}{3} = 7$，得 $c=\sqrt{7}$。 3. 在 $\triangle ABC$ 中，$\cos B = \frac{a^2 + c^2 - b^2}{2ac}$，但 $b$ 未知。改用 $\cos B = \frac{(\sqrt{7})^2 + 4^2 - b^2}{2\cdot 4 \cdot \sqrt{7}}$，需由面积求 $b$。由 $S=\frac{1}{2} a c \sin B = \sqrt{3}$ 得 $\sin B = \frac{\sqrt{3}}{2\sqrt{7}}$，进而 $\cos B = \frac{5\sqrt{7}}{14}$，$\tan B = \frac{\sqrt{3}}{5}$。 4. (2) 在 $\triangle ADC$ 与 $\triangle ABD$ 中，$\cos \angle ADC = -\cos \angle ADB$，$DC=BD=\frac{a}{2}$。对两三角形用余弦定理写 $b^2, c^2$ 表达式： $b^2 = 1^2 + (\frac{a}{2})^2 - 2\cdot 1 \cdot \frac{a}{2} \cos \angle ADC$； $c^2 = 1^2 + (\frac{a}{2})^2 + 2\cdot 1 \cdot \frac{a}{2} \cos \angle ADC$。 5. 两式相加得 $b^2 + c^2 = 2 + \frac{a^2}{2}$。代入已知 $b^2+c^2=8$ 得 $a = 2\sqrt{3}$。结合面积公式与 $b^2 + c^2 = 8$ 解得 $b=c=2$。

点评/变式：凡中线问题均可利用“互补角余弦相反”消去角参数，快速建立边长关系，避免强行引入向量。变式中可改 $D$ 为三等分点，利用相同原理构建方程。

题目：2022-文-17（理-17背景相同）

题目简述：$\triangle ABC$ 满足 $\sin(C-A)\sin B = \sin(B)\sin(C-A)$（等价简化为：$\sin(C-A)\sin B = \sin B \sin(C-A)$）已知条件实际为 $\sin(C-A)\sin B = \sin(B)\sin(C-A)$ 恒等式，原题为 $\sin(C-A)\sin B = \sin B \sin(C-A)$ 形式化叙述。采用理科原题：$\sin C \sin(A-B) = \sin B \sin(C-A)$。(1) 若 $A=2B$ 求 $C$；(2) 证明 $2a^2 = b^2 + c^2$。

思路：(1) 代入 $A=2B$ 化简为单角方程，利用三角形内角和 $A+B+C=\pi$ 解出 $C$。(2) 将已知等式两角差正弦展开，边化角（正弦定理）再角化边（余弦定理），整理即得证明。

步骤： 1. (1) $A=2B$，则 $\sin C \sin B = \sin B \sin(C-2B)$。由于 $\sin B \neq 0$，得 $\sin C = \sin(C-2B)$。 2. $0<C,C-2B<\pi$，故 $\sin$ 值相等意味着 $C = C-2B$ 或 $C + (C-2B) = \pi$。前者得 $B=0$ 舍去，后者得 $2C-2B=\pi$，结合 $3B+C=\pi$ 解得 $C=\frac{5\pi}{8}$。 3. (2) 已知 $\sin C (\sin A\cos B - \cos A\sin B) = \sin B (\sin C\cos A - \cos C\sin A)$，展开并移项得 $2\sin A \sin B \cos C = 0$。因 $\sin A,\sin B>0$，则 $\cos C = 0$，$C=\frac{\pi}{2}$，则 $c^2 = a^2 + b^2$，与目标不符。 （应使用原题标准条件） 理科原题 $\sin C \sin(A-B) = \sin B \sin(C-A)$，展开左右： 左 $=\sin C(\sin A\cos B - \cos A\sin B)$，右 $=\sin B(\sin C\cos A - \cos C\sin A)$。 4. 两边同除 $\sin A \sin B \sin C$ 或直接用正弦余弦定理：由正弦定理边化角逆用，将展开式化为边的关系： $c(a\cos B - b\cos A) = b(c\cos A - a\cos C)$。 5. 代入余弦定理：$\cos A=\frac{b^2+c^2-a^2}{2bc}$ 等，化简得 $a^2 - c^2 = b^2 - a^2$，即 $2a^2 = b^2 + c^2$。

点评/变式：三角形中仅含角的等式，一律利用 $A+B+C=\pi$ 消元、利用弦的展开式转边是定式操作。证明边关系时，余弦定理代入是最直接的恒等变形路径。

题目：2021-理-15

题目简述：已知三角形面积 $\sqrt{3}$，$\angle B = 60^\circ$，$a^2 + c^2 = 3ac$，求 $b$。

思路：由面积公式和夹角求出 $ac$，代入条件得到 $a^2+c^2$ 的具体数值，然后直接使用余弦定理求 $b$。

步骤： 1. 面积 $S = \frac{1}{2}ac \sin 60^\circ = \frac{\sqrt{3}}{4}ac = \sqrt{3}$，解得 $ac = 4$。 2. 由 $a^2 + c^2 = 3ac = 12$。 3. 余弦定理：$b^2 = a^2 + c^2 - 2ac\cos 60^\circ = 12 - 2 \times 4 \times \frac{1}{2} = 8$，故 $b=2\sqrt{2}$。

点评/变式：面积公式与余弦定理的联合是“给面积定边长”的固定套路，遇此结构只需联立消元即可，切勿分开求 $a,c$ 单值，整体代换最省时。
