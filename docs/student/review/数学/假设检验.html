知识精要

  • 假设检验是一种根据样本信息推断总体特征的统计推断方法，其核心依据是小概率事件原理：概率很小的事件在一次试验中几乎不可能发生。若在原假设成立的前提下，样本观测结果属于小概率事件，则有理由怀疑原假设，从而拒绝它。
  • 检验两个总体均值是否有显著差异（或有无提高）时，常用步骤：
  • 提出原假设 $H_0$（通常为“无差异”或“无提高”）与备择假设 $H_1$（“有差异”或“有提高”）；单侧检验时，若问“有无提高”，设 $H_0:\mu_{\text{新}} \le \mu_{\text{旧}}$，$H_1:\mu_{\text{新}} > \mu_{\text{旧}}$。
  • 选择适当的检验统计量（如两样本均值差），确定其分布。
  • 由样本计算统计量的观测值。
  • 根据给定的显著性水平 $\alpha$（通常取 $0.05$）确定拒绝域，或直接依据样本均值差与标准差的关系进行直观判断。
  • 作出决策：若观测值落入拒绝域（或概率小于 $\alpha$），则拒绝 $H_0$，认为有显著提高；否则，不拒绝 $H_0$。
  • 在高考中，常简化处理：直接分别计算两组样本的均值 $\bar{x}_1,\bar{x}_2$ 和样本方差 $s_1^2,s_2^2$（用 $n-1$ 作为分母），比较均值大小并结合方差波动进行推断。若新设备样本均值明显高于旧设备，且两者方差无巨大差异，则可认为新设备生产产品的该项指标有显著提高。

$H_0$：新设备指标无提高（或 $\mu_{\text{新}} \le \mu_{\text{旧}}$）；$H_1$：新设备指标有提高（$\mu_{\text{新}} > \mu_{\text{旧}}$）。 3. 对比均值与波动：
直观上看，$\bar{x}{\text{新}}$ 是否显著大于 $\bar{x}}}$。一般若 $\bar{x{\text{新}} - \bar{x}$），则出现如此大的样本均值差的概率非常小，从而拒绝原假设。 4. }}$ 大于 $2$ 倍左右的共同标准差 $\sqrt{\frac{s_{\text{旧}}^2+s_{\text{新}}^2}{2}}$ 时，可认为差异显著。高考允许直接利用小概率原理陈述：假定新设备无提高（即 $\mu_{\text{新}} = \mu_{\text{旧}规范表达结论：

高频易错

  • 假设方向错误：将“有无提高”设成双侧检验，或原假设设反（如 $H_0:\mu_{\text{新}} > \mu_{\text{旧}}$），导致逻辑混乱。
  • 方差算错：样本方差分母误用 $n$ 而非 $n-1$，题目中若要求计算“样本方差”，应一律除以 $n-1$。
  • 忽略波动的影响：仅看均值大小就下结论，未考虑方差较大时样本均值差可能纯粹由抽样误差引起。
  • 结论表述绝对化：忘记假设检验本质是概率判断，不能说“新设备指标一定提高了”，而应说“有显著提高”或“在显著性水平 $0.05$ 下认为有提高”。
  • 计算粗心：均值、方差的手算极易出错，差值带平方，要仔细核对每次代入。

代表题精讲

2021年·全国乙卷·文科·第17题

题目：某厂研制了一种生产高精产品的设备，为检验新设备生产产品的某项指标有无提高，用一台旧设备和一台新设备各生产了 $10$ 件产品，得到指标数据如下： 旧设备：$9.8, 10.3, 10.0, 10.2, 9.9, 9.8, 10.0, 10.1, 10.2, 9.7$；
新设备：$10.1, 10.4, 10.1, 10.0, 10.1, 10.3, 10.6, 10.5, 10.4, 10.5$。
问：能否认为新设备生产产品的该项指标有显著提高？（$\alpha=0.05$，可能用到的数据略）

思路：分别算两组均值、方差；提出单侧假设 $H_0:\mu_{\text{新}} \le \mu_{\text{旧}}$，$H_1:\mu_{\text{新}} > \mu_{\text{旧}}$；利用均值差相对于波动的程度作判断。

步骤： 1. 计算样本均值：
旧设备 $\bar{x}{\text{旧}} = \frac{9.8+10.3+\dots+9.7}{10} = \frac{100.0}{10} = 10.0$，
新设备 $\bar{x} = 10.3$。 2. 计算样本方差：}} = \frac{10.1+10.4+\dots+10.5}{10} = \frac{103.0}{10
旧设备 $s_{\text{旧}}^2 = \frac{1}{9}\sum (x_i - 10.0)^2$
$= \frac{( -0.2)^2+0.3^2+0^2+0.2^2+(-0.1)^2+(-0.2)^2+0^2+0.1^2+0.2^2+(-0.3)^2}{9}$
$= \frac{0.04+0.09+0+0.04+0.01+0.04+0+0.01+0.04+0.09}{9} = \frac{0.36}{9}=0.04$；
新设备 $s_{\text{新}}^2 = \frac{1}{9}\sum (y_i - 10.3)^2$
$= \frac{(-0.2)^2+0.1^2+(-0.2)^2+(-0.3)^2+(-0.2)^2+0^2+0.3^2+0.2^2+0.1^2+0.2^2}{9}$
$= \frac{0.04+0.01+0.04+0.09+0.04+0+0.09+0.04+0.01+0.04}{9} = \frac{0.40}{9} \approx 0.044$。 3. 形成判断：
新设备样本均值 $10.3$，旧设备样本均值 $10.0$，样本均值差为 $0.3$。两组样本方差均在 $0.04$ 左右，标准差约 $0.2$。若假定新设备无提高，两总体均值相等，出现均值差达到 $0.3$ 这样大的样本差异，对应的统计量观测值（$t$ 值）约为 $\frac{0.3}{\sqrt{(0.04+0.044)/10}} \approx \frac{0.3}{0.092} \approx 3.26$，远大于一般临界值，属于小概率事件，因此拒绝 $H_0$。 4. 结论：可以认为新设备生产产品的该项指标有显著提高。

点评/变式：
- 本题是单侧检验的典型代表，核心是围绕“提高”合理设定原假设。
- 高考文科不必硬背 $t$ 分布表，重在写出逻辑清晰的定量分析过程：先算统计量，再结合“小概率原理”给出结论。
- 变式：若问题改为“新设备与旧设备指标有无显著差异”，则变为双侧检验，$H_0:\mu_{\text{新}}=\mu_{\text{旧}}$，$H_1:\mu_{\text{新}}\neq\mu_{\text{旧}}$，拒绝域会分在两侧，结论可能变为“有显著差异（提高或降低）”，需注意方向性表述。
