公差

考点公差权重40真题数1学科数学父主题数列

考点定位

  • 父主题：数列
  • 权重 weight：40
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：填空13
  • 难度分布：易1

知识精要

  • 等差数列定义：从第二项起，每一项与前一项的差等于同一个常数，即 $a_{n+1} - a_n = d$（$n \in \mathbb{N}^$），常数 $d$ 称为公差*。
  • 通项公式：$a_n = a_1 + (n-1)d$ （$a_1$ 为首项）。
  • 前 $n$ 项和公式（必记双形式）： $$ S_n = \frac{n(a_1 + a_n)}{2} = n a_1 + \frac{n(n-1)}{2}d $$ 适用条件：已知首项和公差（或末项）时灵活选用。
  • 公差 $d$ 的几何意义：在 $a_n$ 关于 $n$ 的一次函数关系 $a_n = dn + (a_1 - d)$ 中，$d$ 是斜率；在 $S_n$ 关于 $n$ 的二次函数关系 $S_n = \frac{d}{2}n^2 + (a_1 - \frac{d}{2})n$ 中，二次项系数为 $\frac{d}{2}$，常数项为 $0$。

解题方法与套路

  1. 设基本量：将已知条件中的各项或前 $n$ 项和统一转化为只含 $a_1$ 和 $d$（或 $a_1$ 与某一项）的表达式。
  2. 若出现 $S_n$，优先代入 $S_n = n a_1 + \frac{n(n-1)}{2}d$，避免引入中间项 $a_n$。
  3. 列方程（组）：利用题设等式等价转化为关于 $d$（或 $a_1$ 与 $d$）的方程。
  4. 解方程求公差：化简时注意合并同类项，避免计算失误。若方程中 $a_1$ 被消去，则直接得 $d$；若仍含 $a_1$，需结合其他条件联立求解。
  5. 验算（可选）：将求得的 $d$ 代回原式，确认等式成立，尤其注意符号。

高频易错

  • 前 $n$ 项和公式选错致计算复杂：对 $S_2, S_3$ 等小下标，直接用 $S_2 = a_1 + a_2 = 2a_1 + d$，$S_3 = 3a_1 + 3d$ 最简。切勿生搬硬套末项公式而多设 $a_2, a_3$。
  • 下标与系数混淆：$S_3 = 3a_1 + 3d$ 中 $d$ 的系数是 $C_3^2 = 3$（来自 $\frac{3 \times 2}{2}$），不要误写成 $2d$ 或 $6d$。
  • 移项变号错误：由 $6a_1 + 3d = 6a_1 + 6d + 6$ 得 $3d - 6d = 6$，最后 $d = -2$。常见失分点为把 $-3d = 6$ 解成 $d = 2$。
  • 忽略 $d$ 可为负：习惯性以为公差为正，漏掉负解。实际等式中系数关系决定符号，负公差完全成立。

代表题精讲

题目（2022-文-13）
记 $S_n$ 为等差数列 ${a_n}$ 的前 $n$ 项和．若 $3S_2 = 2S_3 + 6$，则公差 $d = ______$．

思路
将 $S_2$ 和 $S_3$ 用首项 $a_1$ 和公差 $d$ 表示，代入等式消去 $a_1$ 直接求出 $d$。选用 $S_n = na_1 + \frac{n(n-1)}{2}d$ 最直接。

步骤
1. 写出 $S_2$ 与 $S_3$： $$ S_2 = 2a_1 + \frac{2 \times 1}{2}d = 2a_1 + d $$ $$ S_3 = 3a_1 + \frac{3 \times 2}{2}d = 3a_1 + 3d $$ 2. 代入条件 $3S_2 = 2S_3 + 6$： $$ 3(2a_1 + d) = 2(3a_1 + 3d) + 6 $$ 3. 展开并化简： $$ 6a_1 + 3d = 6a_1 + 6d + 6 $$ 约去 $6a_1$，得： $$ 3d = 6d + 6 $$ $$ -3d = 6 $$ $$ d = -2 $$ 4. 得公差 $d = -2$。

点评/变式
此题只含一个方程，却能求出唯一 $d$，关键在于 $a_1$ 被完美消去，说明条件与首项无关。
变式训练：若将条件改为 $S_3 = 3S_2 + 6$，则 $3a_1 + 3d = 3(2a_1 + d) + 6$ $\Rightarrow$ $3a_1 + 3d = 6a_1 + 3d + 6$ $\Rightarrow$ $-3a_1 = 6$，此时只能求出 $a_1 = -2$，而 $d$ 无法确定。对比可见，不同系数结构决定了未知量能否分离，解题时先预判消元对象可事半功倍。
