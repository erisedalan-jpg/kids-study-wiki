共线条件

考点共线条件权重1真题数1学科数学父主题平面向量

考点定位

  • 父主题：平面向量
  • 权重 weight：1
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：填空13
  • 难度分布：易1

知识精要

  • 共线（平行）向量定义：方向相同或相反的非零向量叫做平行向量，零向量与任意向量平行。
  • 坐标表示：设 $\vec{a}=(x_1,y_1)$，$\vec{b}=(x_2,y_2)$（$\vec{a},\vec{b}$ 为非零向量），则 $$\vec{a}\parallel\vec{b}\iff x_1y_2-x_2y_1=0$$ 即“交叉相乘相减为零”。该充要条件可推广至任意向量，包括零向量，此时方程恒成立。
  • 适用条件：仅适用于平面向量坐标已知的情形；若向量坐标含参数，可直接列方程求解参数，无需分类讨论分母是否为 $0$，避免漏解。
  • 本质：向量共线的本质是存在实数 $k$ 使得 $\vec{a}=k\vec{b}$，坐标形式即为分量成比例，但 交叉相乘 形式能安全处理含有 $0$ 分量的情形。

解题方法与套路

  1. 坐标化：将所有涉及向量用坐标表示（若题干未给出坐标，则选基底进行坐标运算）；计算线性组合后的向量坐标，如 $ \lambda\vec{a}+\vec{b}$。
  2. 列共线方程：对目标向量 $\vec{p}=(x_p,y_p)$ 与 $\vec{q}=(x_q,y_q)$，直接代入
    $$x_py_q-x_qy_p=0$$
  3. 解方程：整理为关于参数的一元一次（或简单）方程，求出参数值。
  4. 检验（可选）：确认所得参数不导致向量退化为零向量产生歧义（高中解题一般直接作答，若题目有范围限制则需回代）。

高频易错

  • 交叉相乘符号写反：小心 $(x_1,y_1)$ 与 $(x_2,y_2)$ 的对应，避免写成 $x_1y_1-x_2y_2=0$ 之类。
  • 移项错误：如 $-7(\lambda+2)+4(2\lambda+3)=0$ 展开时漏掉负号，或把加号误写为减号。
  • 混淆垂直与平行的坐标条件：垂直条件为 $x_1x_2+y_1y_2=0$，与平行条件 $x_1y_2-x_2y_1=0$ 易混。
  • 错误使用比例式：忌用 $\frac{x_1}{x_2}=\frac{y_1}{y_2}$，当 $x_2$ 或 $y_2$ 为零时分式无意义，容易丢解，统一使用乘积式最安全。
  • 忽略运算顺序：进行线性组合如 $\lambda\mathbf{a}+\mathbf{b}$ 时，未将 $\lambda$ 乘到向量分量导致坐标错误。

代表题精讲

题目（2008-文-13）：设向量 $\mathbf{a}=(1,2)$，$\mathbf{b}=(2,3)$，$\mathbf{c}=(-4,-7)$，若向量 $\lambda\mathbf{a}+\mathbf{b}$ 与 $\mathbf{c}$ 共线，求 $\lambda$。
思路：先写出 $\lambda\mathbf{a}+\mathbf{b}$ 的坐标，再利用向量共线的坐标充要条件 $x_1y_2 - x_2y_1=0$ 直接列出关于 $\lambda$ 的方程，求解即得。
步骤： 1. 计算 $\lambda\mathbf{a}+\mathbf{b} = \lambda(1,2)+(2,3)=(\lambda+2,\, 2\lambda+3)$。 2. 由 $(\lambda+2,\, 2\lambda+3)$ 与 $(-4,-7)$ 共线，得： $$(\lambda+2)\times(-7) - (-4)\times(2\lambda+3)=0$$ 即 $-7(\lambda+2)+4(2\lambda+3)=0$。 3. 展开并合并：$-7\lambda-14+8\lambda+12=0 \Rightarrow \lambda-2=0$，解得 $\lambda=2$。 点评/变式：本题为共线条件的直接应用，方程一次即解。变式可改为“若向量 $\lambda\mathbf{a}+\mathbf{b}$ 与 $\mathbf{c}$ 垂直”，则只需将条件换为 $(\lambda+2)\cdot(-4)+(2\lambda+3)\cdot(-7)=0$，考查点立即切换，条件公式必须精准记忆。
