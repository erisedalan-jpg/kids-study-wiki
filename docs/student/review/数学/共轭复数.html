共轭复数

知识精要

  • 共轭复数定义：若 $z=a+bi\ (a,b\in\mathbb{R})$，则其共轭复数 $\overline{z}=a-bi$。实部相同，虚部互为相反数。
  • 核心性质：
  • $z\cdot\overline{z}=|z|^2=a^2+b^2$（实数）。
  • $z+\overline{z}=2a$（实数），$z-\overline{z}=2bi$（纯虚数，当 $b\neq0$ 时）。
  • $\overline{z_1\pm z_2}=\overline{z_1}\pm\overline{z_2}$，$\overline{z_1\cdot z_2}=\overline{z_1}\cdot\overline{z_2}$，$\overline{\left(\frac{z_1}{z_2}\right)}=\frac{\overline{z_1}}{\overline{z_2}}\ (z_2\neq 0)$。
  • $\overline{\overline{z}}=z$。
  • 复数相等的充要条件：$a+bi=c+di\iff a=c$ 且 $b=d$（其中 $a,b,c,d\in\mathbb{R}$）。
  • 复平面中的点：$z=a+bi$ 对应点 $(a,b)$，$\overline{z}$ 对应点 $(a,-b)$，两点关于实轴对称。
  • 复数代数形式的运算：
  • 加减法：实部与实部相加减，虚部与虚部相加减。
  • 乘法：按多项式乘法展开，利用 $i^2=-1$ 合并。
  • 除法：分子分母同乘以分母的共轭复数，化为 $a+bi$ 的标准形式。

解题方法与套路

  1. 设标准形式法：当题目涉及 $z$ 与 $\overline{z}$ 的混合运算且不易直接化简时，设 $z=a+bi\ (a,b\in\mathbb{R})$，写出 $\overline{z}=a-bi$，代入等式中利用复数相等的充要条件列方程组求解 $a,b$。
  2. 整体化简法：对于仅含 $z$ 的运算（如求 $\overline{z}$、$|z|$ 等），先对 $z$ 的表达式进行四则运算化为 $a+bi$ 的标准形，然后直接写出共轭复数或进行后续计算。
  3. 性质直用：遇到 $z+\overline{z}$、$z-\overline{z}$、$z\cdot\overline{z}$ 等对称结构时，直接套用性质转化为实数或纯虚数，大幅简化解题过程，避免设未知数。
  4. 分母实数化：复数除法运算中，分子分母同乘以分母的共轭复数，使分母变为实数，再分离实部与虚部。

高频易错

  • 共轭复数符号搞反：$\overline{z}$ 是虚部变号，而非实部变号。如 $z=1-2i$ 的共轭是 $1+2i$，误记为 $-1+2i$ 会导致全题失分。
  • 漏掉虚数单位 $i$：在计算 $z-\overline{z}$ 时，结果为 $2bi$，部分考生只写 $2b$ 而忽略 $i$，使得方程无法匹配。
  • 复数相等条件未分离实虚部：遇到含 $z$ 和 $\overline{z}$ 的方程时，若不能正确将式子整理为“实数+虚数”的形式，会列错方程组。
  • 共轭复数运算误用：比如误认为 $z\cdot\overline{z}=a^2-b^2$（实际为 $a^2+b^2$），或认为 $\overline{z_1+z_2}=\overline{z_1}-\overline{z_2}$ 等。
  • 复平面点坐标颠倒：$\overline{z}$ 的对应点是 $(a,-b)$，而不是 $(-a,b)$ 或 $(-a,-b)$；命题中常以象限判断考查，需画出草图确认。
  • 虚部概念混淆：复数 $a+bi$ 的虚部是实数 $b$，而不是 $bi$。例如 $z=-1-i$ 的虚部是 $-1$，而非 $-i$。此类辨析常在命题判断中出现。

代表题精讲

代表题1（2022·理·02）

题目：已知 $z=1-2i$，且 $z+a\overline{z}+b=0$，其中 $a,b$ 为实数，求 $a,b$ 的值。
思路：先求出 $\overline{z}=1+2i$，代入方程整理成“实部 $+$ 虚部$\times i$”的形式，再利用复数相等的充要条件列出关于 $a,b$ 的实数方程组求解。
步骤：
由 $z=1-2i$ 得 $\overline{z}=1+2i$。
代入方程：
$$(1-2i)+a(1+2i)+b=0$$ 展开并合并实部与虚部：
$$(1+a+b)+(2a-2)i=0$$
因为 $a,b\in\mathbb{R}$，根据复数相等的条件得：
$$\begin{cases} 1+a+b=0 \ 2a-2=0 \end{cases}$$
解方程组：由第二式得 $a=1$，代入第一式得 $b=-2$。
故选A（$a=1,b=-2$）。
点评/变式：本题核心是“标准化——分离实虚部——列方程组”。若题目改为已知 $a,b$ 求 $z$，则需设 $z=x+yi$ 反向求解，思想一致。注意务必先准确写出 $\overline{z}$。

因此，代表题2的题目简述为：已知 $2(z+\overline{z})+3(z-\overline{z})=4+6i$，求复数 $z$。
步骤：设 $z=a+bi\ (a,b\in\mathbb{R})$，则 $\overline{z}=a-bi$。
$z+\overline{z}=2a$，$z-\overline{z}=2bi$。
代入得：$2(2a)+3(2bi)=4a+6bi = 4+6i$。
根据复数相等得 $4a=4,\ 6b=6$，解得 $a=1,\ b=1$，故 $z=1+i$。选C。
点评/变式：本题巧妙利用 $z\pm\overline{z}$ 的化简，避免了直接展开的繁琐。若等式复杂，也可设标准形式硬展开，但利用对称结构能显著提速。变式：若改为含 $z\cdot\overline{z}$ 的方程，则可利用 $|z|^2$ 整体求模。

代表题3（2019·文·02）

题目：设 $z=i(2+i)$，求 $\overline{z}$。
思路：先计算 $z$，化成 $a+bi$ 的标准形式，然后直接写出共轭复数。
步骤：
$z=i(2+i)=2i+i^2=2i-1=-1+2i$。
所以 $\overline{z}=-1-2i$。故选D。
点评/变式：本题为最基本的共轭复数运算，易错点在于乘法运算漏项或 $i^2$ 处理错误。务必先算准 $z$ 再取共轭。变式：求 $|z|$ 或 $\frac{1}{z}$ 时，同样先化简为标准形式再运算。
