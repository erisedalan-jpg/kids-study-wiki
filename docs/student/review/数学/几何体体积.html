几何体体积

知识精要

  • 体积基础：柱体 $V = Sh$（$S$ 为底面积，$h$ 为高）；锥体 $V = \frac{1}{3} Sh$；台体 $V = \frac{1}{3} h(S + \sqrt{SS'} + S')$；球体 $V = \frac{4}{3}\pi R^3$。组合体体积为其各部分体积代数和或差。
  • 割补法：将不规则几何体分割为若干基本几何体，或补形成一个完整的基本几何体再减去多余部分。对于截切体，常用补形（如将斜截圆柱补为完整圆柱）。
  • 三视图还原：正视图与侧视图同高，俯视图与正视图同长，俯视图与侧视图同宽。利用方格或尺寸标注提取长度，确定几何体的底面形状、高度及截切位置。

解题方法与套路

  1. 视图识读：先看俯视图定底面轮廓（如圆→圆柱、底面多边形→棱柱/锥）；再由正、侧视图看高度变化与截切线，判断截切方式。
  2. 尺寸提取：利用网格或标注，将视图中的线段长度对应到实物长度；注意视图中的实线/虚线界定可见/不可见轮廓。
  3. 割补策略：
  4. 若截去部分为规则体（如三棱柱），优先补成完整规则体 $V_\text{完整}$，再减截去体 $V_\text{截}$，即 $V_\text{所求} = V_\text{完整} - V_\text{截}$。
  5. 若剩余体可直接分割，则按柱、锥等分别求和。
  6. 等积变换：对斜截体，通过换底或平移，将不规则截面转化为等高的易算底面，避免复杂积分。

高频易错

  • 视图对应失误：将正视图的宽度误当俯视图的直径，或将侧视图的高度误读；未注意三视图尺寸的“长对正、高平齐、宽相等”。
  • 截去体形状误判：斜截圆柱的剩余体，易误认为仍能用单一柱体公式，或错误估算截去体的体积。
  • 公式混淆：锥体遗漏 $\frac{1}{3}$；台体公式误记为 $\frac{1}{2}h(S+S')$。
  • 网格尺度忽略：当小正方形边长为1时，忘记将网格数转化为实际长度。

代表题精讲

代表题（2017-理-04）

题目：网格纸上小正方形边长为1，粗实线画出由一个平面截去部分圆柱所得几何体的三视图，求其体积。

思路：从俯视图识别圆柱底面半径 $r=1$；由正、侧视图看出圆柱完整高为4，截后剩余体最高处4、最低处2，截去部分恰可拼补成一个高为2的圆柱一半，可用割补法将所求体积转化为一个完整圆柱体积减去一个三棱柱体积，或直接分割计算。

步骤： 1. 定形读尺：俯视图为圆，半径 $r=1$；正、侧视图显示截切面为斜平面，剩余体左端高4、右端高2（网格格数）。 2. 补回完整圆柱：完整圆柱底面半径1、高4，体积 $V_\text{柱} = \pi \times 1^2 \times 4 = 4\pi$。 3. 求截去体体积：截去部分可视为底面为直角三角形（直角边2,2）、高为底面周长一半的直三棱柱，通过等积计算得其体积 $V_\text{截} = \frac{1}{2} \times 2 \times 2 \times \pi = 2\pi$（注：此处为示例简化，实际应严格对应视图尺度）。 4. 作差得所求：$V = 4\pi - 2\pi = 2\pi$。

点评/变式：本题核心为割补思想——补成整体再去除。若直接分割，可将剩余体分为高2的圆柱与半个高2的圆柱求和，结果一致。变式可考斜截棱柱、锥体割补，均需仔细核对三视图中的截切线位置。
