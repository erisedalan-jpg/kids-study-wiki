知识精要

几何体体积计算的核心是熟记基本体积公式并灵活运用分割、补形、做差三大策略。

  • 基本体积公式：
  • 长方体 / 正方体：$V=abc$（$a,b,c$ 为长宽高）。
  • 柱体（棱柱、圆柱）：$V=S_{底}\cdot h$。
  • 锥体（棱锥、圆锥）：$V=\dfrac{1}{3}S_{底}\cdot h$。
  • 台体：$V=\dfrac{1}{3}h\left(S_{上}+S_{下}+\sqrt{S_{上}S_{下}}\right)$。
  • 球：$V=\dfrac{4}{3}\pi r^3$。
  • 直棱柱体积：底面积乘以高。当截面把柱体切成"前后两个直棱柱"时，可分别按"底面（截面方向的梯形 / 三角形）× 棱长"计算。
  • 分割法：把不规则几何体拆成若干已知体积的基本体。
  • 补形法：把缺角的体补成完整长方体 / 棱柱，再减去补上的部分。
  • 做差法：大体积减去被截去 / 挖去部分的体积。
  • 体积比与等积转化：求两部分体积之比时，可用公共的底或高约去，化简比值；锥体等底等高则等积。

解题方法与套路

  1. 看清切割方式：平面截多面体后，判断两部分各是什么几何体（直棱柱、棱锥、不规则体）。
  2. 优选直棱柱视角：若截面平行于某组侧棱方向，可把两部分都看作"以截面方向多边形为底、以该棱长为高"的直棱柱，体积 = 该多边形面积 × 棱长。
  3. 梯形底面积：截面切出的侧面常为梯形，用 $S_{梯}=\dfrac{(a+b)h}{2}$ 算底面积。
  4. 作差验证：算出一部分体积后，用总体积减去它得另一部分，比值 = 部分 ∶（总 − 部分）。
  5. 化简比值：体积比中公共因子（如相同的"高"或"棱长"）可直接约掉，只比底面积。

高频易错

  • 把切出的两部分都当成棱锥：实际多为直棱柱（底为梯形 / 三角形），体积公式不含 $\dfrac13$。
  • 底面积与高对应错：直棱柱的"高"应是垂直于所取底面的棱长，取错方向导致结果错误。
  • 梯形上下底取反或漏算：$\dfrac{(a+b)h}{2}$ 中 $a,b$ 是两平行边，$h$ 是它们间的距离。
  • 比值未约简或方向写反：题目问"两部分体积比"，注意先后顺序与是否需写成最简整数比。
  • 总体积算错：长方体 $V=abc$，单位与数据须核对。

代表题精讲

代表题（2015·文·19 第Ⅱ问，平面分割长方体求体积比）

题目：长方体 $ABCD\text{-}A_1B_1C_1D_1$ 中 $AB=16$，$BC=10$，$AA_1=8$；$E,F$ 在 $A_1B_1,D_1C_1$ 上，$A_1E=D_1F=4$。过 $E,F$ 的平面 $\alpha$（截出正方形截面 $EFHG$）把长方体分成两部分，求两部分体积之比。

思路：截面 $\alpha$ 沿 $BC$ 方向（即 $A_1D_1$ 方向，长 $10$）平移不变，故两部分都是以 $BC=10$ 为公共"长度"（柱高）的直棱柱，底面分别是侧面 $ABB_1A_1$ 内被截线 $GE$ 分出的两个梯形。只需算两个梯形面积之比，柱高 $10$ 可约去。

步骤： 1. 由第Ⅰ问，$E$ 在 $A_1B_1$ 上 $A_1E=4$；$G$ 在 $AB$ 上。由正方形边 $|EG|=10$ 及高 $AA_1=8$，水平投影差为 $6$，故 $AG=A_1E+6=4+6=10$（即 $BG=16-10=6$）。 2. 截面把侧面矩形 $ABB_1A_1$（$16\times8$）分成两个直角梯形： - 含顶点 $A,A_1$ 一侧的梯形，平行边为 $A_1E=4$ 与 $AG=10$，高（即 $AA_1$ 方向距离）为 $8$，面积 $S_1=\dfrac{(4+10)\times8}{2}=56$。 - 含顶点 $B,B_1$ 一侧的梯形，平行边为 $B_1E=16-4=12$ 与 $BG=16-10=6$，高 $8$，面积 $S_2=\dfrac{(12+6)\times8}{2}=72$。 3. 两部分均为以对应梯形为底、$BC=10$ 为高的直棱柱，故 $$V_1=56\times10=560,\qquad V_2=72\times10=720.$$ 4. 体积比 $V_1:V_2=560:720=7:9$。

点评：本题关键是识别"截面沿 $BC$ 方向平移不变"，从而两部分都是直棱柱，把三维体积比化简为二维梯形面积比，柱高约去。校验：$560+720=1280=16\times10\times8$，恰为长方体总体积，无误。变式：若截面不平行于任何棱，则两部分可能是棱锥或不规则体，需用分割 / 补形分别求体积。
