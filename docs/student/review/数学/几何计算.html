知识精要

  • 余弦定理（任意三角形）： $$a^2=b^2+c^2-2bc\cos A$$ 用于已知两边及夹角求第三边，或已知三边求角。变形：$\displaystyle\cos A=\frac{b^2+c^2-a^2}{2bc}$。
  • 互补角的余弦关系：若 $\alpha+\beta=180^\circ$，则 $\cos\beta=-\cos\alpha$。
    常用特例：$\cos135^\circ=-\dfrac{\sqrt2}{2}$，$\cos45^\circ=\dfrac{\sqrt2}{2}$，两者互为相反数。
  • 线段比例关系：若 $BC=3BD$，则 $CD=BC-BD=2BD$。在选取三角形运用余弦定理时，需将各边统一用同一未知数表示。
  • 方程思想：在含多个三角形的图形中，通过余弦定理建立边长关系，联立等式消去中间量（如 $AB$），转化为一元方程求解。

解题方法与套路

  1. 标已知，设未知：将题中的已知边长、角度标注在图上，设所求线段为未知数（如 $BD=x$），并用该未知数表达其他相关线段（如 $CD=2x$）。
  2. 选择三角形用余弦定理：找出包含已知角和所求边的三角形。若存在互补角（如 $135^\circ$ 与 $45^\circ$），分别在两个三角形中写出余弦定理表达式，注意余弦值的符号。
  3. 整理表达式：将已知数值（如 $AD=\sqrt2$，即 $AD^2=2$）代入，化简得到用 $x$ 表示的 $AB^2$、$AC^2$ 等式。
  4. 利用附加条件建立等式：如 $AC=\sqrt2\,AB$，则 $AC^2=2AB^2$，代入刚才得到的关系式。
  5. 联立消元求解：将不同三角形得到的等式联立，消去中间边（如 $AB$），得到关于 $x$ 的方程。解方程并根据实际意义取舍根。
  6. 检验：将解代回原题，检查是否符合几何条件（如边长为正、两边之和大于第三边等）。

高频易错

  • 互补角余弦弄错符号：$\triangle ABD$ 中用 $\angle ADB=135^\circ$，$\triangle ACD$ 中用 $\angle ADC=45^\circ$，$-2\cdot AD\cdot BD\cos135^\circ$ 实际为 $-!2\cdot AD\cdot BD\cdot(-\frac{\sqrt2}{2})=+\sqrt2\,AD\cdot BD$；另一三角形中对应项为 $-\sqrt2\,AD\cdot CD$。符号一错全盘皆输。
  • 线段关系代换遗漏：题干给出 $BC=3BD$，隐含 $CD=2BD$，易误写为 $CD=3BD$ 或 $CD=BD$，导致后续方程错误。
  • 已知边长遗忘或代错：本题 $AD=\sqrt2$（原始题干可能排版遗漏），实际计算中 $AD^2=2$，$AD\cos135^\circ=-\frac{\sqrt2}{2}\cdot\sqrt2=-1$ 等细节不可弄混。
  • 方程变形失误：消去 $AB$ 时需将 $AC^2=2AB^2$ 与两个表达式联立，相减时注意系数和常数项的正确运算，避免出现 $BD^2-4BD-1=0$ 解成 $BD=2-\sqrt5$（负根应舍去）。
  • 不检验解的合理性：解得 $BD=2+\sqrt5$，需验证 $BD>0$ 且与原题其他边长构成合理的三角形（尤其压轴题若有多解需讨论取舍）。

代表题精讲

题目：$\triangle ABC$ 中，$D$ 为 $BC$ 边上一点，$BC=3BD$，$AD=\sqrt2$，$\angle ADB=135^\circ$．若 $AC=\sqrt2\,AB$，求 $BD$．

思路：
分别在 $\triangle ABD$ 与 $\triangle ACD$ 中利用余弦定理表示 $AB^2$ 与 $AC^2$，用 $BD$ 表达各边，利用 $AC=\sqrt2\,AB$ 得到等式，联立消 $AB$ 得关于 $BD$ 的方程求解。

步骤：
1. 设 $BD=x\;(x>0)$，由 $BC=3BD$ 得 $CD=2x$。将 $AD=\sqrt2$ 及角度补角关系代入余弦定理。
2. 在 $\triangle ABD$ 中：
$$AB^2=BD^2+AD^2-2\cdot BD\cdot AD\cdot\cos135^\circ$$
$$=x^2+2-2\cdot x\cdot\sqrt2\cdot\left(-\frac{\sqrt2}{2}\right)=x^2+2+2x \quad\text{①}$$
3. 在 $\triangle ACD$ 中，$\angle ADC=180^\circ-135^\circ=45^\circ$：
$$AC^2=CD^2+AD^2-2\cdot CD\cdot AD\cdot\cos45^\circ$$
$$=(2x)^2+2-2\cdot 2x\cdot\sqrt2\cdot\frac{\sqrt2}{2}=4x^2+2-4x \quad\text{②}$$
4. 由条件 $AC=\sqrt2\,AB$ 得 $AC^2=2AB^2$，将①、②代入：
$$4x^2+2-4x = 2(x^2+2+2x)$$
化简：$4x^2+2-4x=2x^2+4+4x$
整理得：$2x^2-8x-2=0$，即 $x^2-4x-1=0$。
5. 解方程：$x=\dfrac{4\pm\sqrt{16+4}}{2}=2\pm\sqrt5$，舍去负根 $2-\sqrt5$（负值），得 $BD=2+\sqrt5$。

点评/变式：
- 本题核心是双三角形配合补角关系，利用余弦定理搭建方程。补角的余弦互为相反数直接导致两式中一次项系数符号相反（$+2x$ 与 $-4x$），最终消元降次。
- 变式：若将 $\angle ADB$ 改为 $120^\circ$，$AC$ 与 $AB$ 的关系改为 $AC=\sqrt3\,AB$，照样可用相同策略，核心为化简出关于 $BD$ 的二次方程。
- 注意：若图形中有特殊角，可配合正弦定理或面积法，但本题中余弦定理直接转化为边的关系最为直接。
