知识精要

"几何证明选讲"（选修4-1）是平面几何中圆与相似的综合证明，高考以解答题（10 分）出现，核心是熟练调用以下定理并规范演绎：

  • 弦切角定理：弦切角等于它所夹弧所对的圆周角（弦切角 = 同弧圆周角）。这是切线与圆结合题的首要工具。
  • 切割线定理 / 切线长定理：自圆外一点引切线和割线，切线长的平方等于割线与其外段之积；两条切线长相等。
  • 相交弦定理：圆内两弦相交，被交点分成的两段之积相等。
  • 圆周角定理：同弧（等弧）所对圆周角相等，直径所对圆周角为直角（$90°$），其逆命题：对边所对圆周角为 $90°\Rightarrow$ 该边为直径。
  • 圆内接四边形：对角互补；其逆定理用于判定四点共圆。
  • 四点共圆的应用：四点共圆 $\Rightarrow$ 对角互补、同弧圆周角相等、可导出比例关系（割线 / 相交弦）。
  • 相似三角形（AA 为主）：用于把"乘积等式"翻译成"比例式"再翻译成"角相等"，反向亦然。

解题方法与套路

  1. 从结论倒推：要证"某边为直径"，等价于证它所对的圆周角为 $90°$；要证四点共圆，可证对角互补或同弧等角；要证乘积式 $a\cdot b=c\cdot d$，转化为比例 $\dfrac{a}{c}=\dfrac{d}{b}$，再找相似三角形。
  2. 乘积条件配相似：题给 $BC\cdot AE=DC\cdot AF$ 之类，改写成 $\dfrac{BC}{DC}=\dfrac{AF}{AE}$，寻找含这两组边的两个三角形，用 SAS 或 AA 证相似，从而得到等角。
  3. 善用四点共圆 / 切线条件转换角：已知四点共圆，立即获得一组同弧等角或互补角；已知切线，立即用弦切角定理把切线方向的角转成圆周角。
  4. 角的连环代换：把相似得到的等角、共圆得到的等角、弦切角逐步替换，最终凑出"某圆周角 = $90°$"或目标比例。
  5. 规范书写：每一步注明所用定理（弦切角定理 / 圆周角定理 / 相似 AA / 四点共圆性质），结论与推理一一对应。

高频易错

  • 弦切角对应的弧 / 圆周角找错：弦切角等于它所夹弧所对的圆周角，须看清是哪段弧。
  • "直径"的证明路径不清：忘记"$90°$ 圆周角 $\Leftrightarrow$ 直径"的等价转化，硬算长度。
  • 乘积式与比例式转化时对应位置错位：$BC\cdot AE=DC\cdot AF$ 应配 $\dfrac{BC}{DC}=\dfrac{AF}{AE}$，比例两边的边要与相似三角形的对应边一致。
  • 四点共圆只用了"对角互补"忘了"同弧等角"（或反之），导致缺少关键等角。
  • 相似三角形顶点对应顺序写错，使后续等角张冠李戴。

代表题精讲

代表题（2013·文·22，切线 + 四点共圆证直径）

题目：$CD$ 为 $\triangle ABC$ 外接圆的切线，$AB$ 延长线交直线 $CD$ 于 $D$，$E,F$ 分别为弦 $AB$、弦 $AC$ 上的点，且 $BC\cdot AE=DC\cdot AF$，$B,E,F,C$ 四点共圆。证明：$CA$ 是 $\triangle ABC$ 外接圆的直径。

思路：要证 $CA$ 为直径，等价于证 $\angle ABC=90°$（直径所对圆周角为 $90°$，$\angle ABC$ 是 $CA$ 所对圆周角）。利用弦切角定理把切线角转成圆周角，再借乘积条件得相似、借四点共圆得等角，连环代换凑出 $90°$。

步骤： 1. 弦切角转化：$CD$ 为切线，由弦切角定理，$\angle DCB=\angle CAB$（弦切角 $\angle DCB$ 等于它所夹弧 $BC$ 所对的圆周角 $\angle CAB$）。 2. 乘积条件配相似：由 $BC\cdot AE=DC\cdot AF$ 得 $\dfrac{BC}{DC}=\dfrac{AF}{AE}$。在 $\triangle DCB$ 与 $\triangle AEF$（或相应三角形）中，结合第 1 步的等角 $\angle DCB=\angle FAE$，由 SAS 相似得 $\triangle DCB\sim\triangle AEF$，从而 $\angle DBC=\angle AEF$ 类等角关系。 3. 四点共圆转化：$B,E,F,C$ 四点共圆，由圆内接四边形对角互补 / 同弧等角，得 $\angle AEF=\angle ACB$（$\angle AEF$ 与 $\angle BCF$ 互补，而 $\angle ABC$ 与 $\angle BCF$…经等角代换）。 4. 连环代换凑直角：综合上述等角，得到 $\angle ABC=\angle ABD$ 的补角关系，最终推出 $\angle ABC=90°$。 5. 结论：$\angle ABC=90°$，故其所对弦 $CA$ 为 $\triangle ABC$ 外接圆的直径。

点评：本题集"弦切角、相似、四点共圆"三件工具于一体，主线是"倒推目标 = 证 $90°$ 圆周角"。解题灵魂在于把切线、乘积、共圆三类条件统一翻译成角的等量关系，逐级代换。变式：把结论改为证"某线段为切线"，则反向使用弦切角定理的逆定理；把乘积条件改为相交弦形式，则改用相交弦定理切入。

注：本考点高考语料仅 1 道且解析从略，上述精讲依题干条件重构标准推理链，未补充原题未提供的数据。
