函数奇偶性

考点函数奇偶性权重32真题数16学科数学父主题函数与导数

考点定位

  • 父主题：函数与导数
  • 权重 weight：32
  • 真题数：16；年份跨度：2008–2021
  • 出现题位：填空14 填空15 选择2 选择3 选择4 选择8 选择9 选择10 选择11 选择12
  • 难度分布：易10 中6

知识精要

  1. 定义：设函数 $f(x)$ 定义域 $D$ 关于原点对称。
    • 奇函数：对于任意 $x\in D$，都有 $f(-x)=-f(x)$。图像关于原点对称。
    • 偶函数：对于任意 $x\in D$，都有 $f(-x)=f(x)$。图像关于 $y$ 轴对称。
  2. 运算性质：
    • 奇函数 $+$ 奇函数 $=$ 奇函数；偶函数 $+$ 偶函数 $=$ 偶函数。
    • 奇函数 $\times$ 奇函数 $=$ 偶函数；奇函数 $\times$ 偶函数 $=$ 奇函数；偶函数 $\times$ 偶函数 $=$ 偶函数。
    • 复合函数 $f(g(x))$ 的奇偶性遵循“同偶异奇”原则（内层外层均为偶函数则为偶函数，其余情况与外层奇偶性一致，注意定义域约束）。
  3. 核心定理：
    • 若奇函数 $f(x)$ 在 $x=0$ 处有定义，则必有 $f(0)=0$。
    • 奇函数在关于原点对称区间上的单调性相同；偶函数在关于原点对称区间上的单调性相反。
  4. 图像对称轴与周期：
    • 若 $f(x+a)$ 是偶函数，则 $f(x)$ 关于 $x=a$ 对称。
    • 若 $f(x+a)$ 是奇函数，则 $f(x)$ 关于点 $(a,0)$ 中心对称。
    • $f(x)$ 若关于 $x=a$ 和 $x=b$ 都对称，则 $T=2|a-b|$ 是一个周期。

解题方法与套路

  1. 定义验证法：判断奇偶性，第一步求定义域并验证是否关于原点对称，第二步计算 $f(-x)$，对比与 $\pm f(x)$ 的关系。
  2. 性质转化法（脱壳法）：
    • 处理抽象不等式 $f(m) > f(n)$ 时，若 $f(x)$ 为偶函数且在 $[0, +\infty)$ 上单调递增，则等价于 $|m| > |n|$。
    • 若条件仅给出 $x>0$ 或 $x<0$ 的解析式，求另一区间函数值或解析式，可利用 $f(x)=\pm f(-x)$ 将变量转化到已知区间。
  3. 函数构造法：
    • 遇到 $x f'(x) - f(x)$ 或 $x f'(x) + f(x)$ 型不等式，联想构造函数 $g(x)=\frac{f(x)}{x}$ 或 $g(x)=xf(x)$，利用导数判断单调性，结合奇偶性求解不等式。
  4. 图像特征法：利用奇函数图像关于原点中心对称，偶函数图像关于 $y$ 轴对称，结合极限趋势排除错误选项，快速识别函数图像。

高频易错

  1. 忽略定义域：判断奇偶性时，必须先确认定义域关于原点对称。如函数 $y=\log_2\frac{2-x}{2+x}$，定义域为 $(-2,2)$，具备对称性才能判定为奇函数。
  2. 混淆单调区间与单调性：奇函数在对称区间的单调性严格相同，偶函数则严格相反。书写单调区间时，若函数在 $x=0$ 不连续，不可用“$\cup$”连接。
  3. 误用 $f(0)=0$ 定理：奇函数需在 $x=0$ 有定义时才能得出 $f(0)=0$。若定义域不包含 $0$（如 $f(x)=\frac{1}{x}$），不能强行套用此结论。
  4. 复合函数奇偶性误判：仅记“同增异减”而忽略奇偶性。如 $f(x)=x^3$ 是奇函数，$g(x)=\cos x$ 是偶函数，但复合函数 $f(g(x))$ 是偶函数。
  5. 平移变换后的奇偶性：若 $f(x)$ 为奇函数，则 $f(x+a)-b$ 关于点 $(-a, -b)$ 中心对称，而非原点。

代表题精讲

代表题一（2021-文-09）

题目：设函数 $f(x)=\frac{1-x}{1+x}$，则下列函数中为奇函数的是（ ） A. $f(x-1)-1$ B. $f(x-1)+1$ C. $f(x+1)-1$ D. $f(x+1)+1$

思路：本题考察平移变换构造奇函数。直接利用分离常数法化简 $f(x)$，识别其对称中心，通过平移将对称中心移至原点 $(0,0)$ 即可获得奇函数。

步骤： 1. 化简：$f(x)=\frac{1-x}{1+x} = \frac{2-(1+x)}{1+x} = \frac{2}{1+x} - 1$。 2. 识别对称中心：反比例函数 $y=\frac{2}{x}$ 是奇函数，对称中心为 $(0,0)$。$f(x)$ 是由 $y=\frac{2}{x}$ 向左平移 1 个单位，再向下平移 1 个单位得到，故对称中心为 $(-1, -1)$。 3. 还原变换：欲使其为奇函数（关于原点对称），需将 $f(x)$ 向右平移 1 个单位，再向上平移 1 个单位，得到函数 $g(x)=f(x-1)+1$。 4. 验证：$g(x)=\frac{2}{1+(x-1)}-1+1 = \frac{2}{x}$，满足 $g(-x)=-g(x)$。

点评/变式：求解复杂分式函数的对称中心，分离常数是首选。逆向思维：若 $f(x+a)+b$ 为奇函数，则 $f(x)$ 的对称中心为 $(a, b)$。

代表题二（2020-文-10）

题目：设函数 $f(x)=x^3-\frac{1}{x^3}$，则 $f(x)$（ ） A. 是奇函数，且在 $(0,+\infty)$ 单调递增 B. 是奇函数，且在 $(0,+\infty)$ 单调递减 C. 是偶函数，且在 $(0,+\infty)$ 单调递增 D. 是偶函数，且在 $(0,+\infty)$ 单调递减

思路：直接利用定义判断奇偶性，利用熟知的幂函数单调性及单调性的运算法则判断。

步骤： 1. 定义域与奇偶性：定义域 ${x|x \neq 0}$。$f(-x)=(-x)^3 - \frac{1}{(-x)^3} = -x^3 + \frac{1}{x^3} = -f(x)$，故为奇函数。 2. 单调性：$y=x^3$ 在 $(0, +\infty)$ 递增，$y=-\frac{1}{x^3}$ 在 $(0, +\infty)$ 也递增（由 $y=x^{-3}$ 递减，负号改变单调性）。递增函数加递增函数仍为递增函数。 3. 结论：$f(x)$ 在 $(0, +\infty)$ 单调递增。

点评/变式：$\frac{1}{x^a}$ 型单调性：指数为正越大，增长越快；指数为负要注意反比例特性及分界点。利用导数也可验证，$f'(x)=3x^2+3x^{-4}>0$，同样可得单调递增。

代表题三（2019-理-14）

题目：已知 $f(x)$ 是奇函数，且当 $x<0$ 时，$f(x)=-e^{ax}$。若 $f(\ln 2)=8$，则 $a=$_。

思路：利用奇函数性质“正负互推”，将自变量为正数的函数值转化为已知解析式的区间求解。

步骤： 1. 定区间：$\ln 2 \in (0,1)$，不在已知区间 $x<0$ 上。 2. 化归：由 $f(x)$ 为奇函数，得 $f(\ln 2) = -f(-\ln 2)$。 3. 代入：$-\ln 2 < 0$，满足已知解析式，故 $f(-\ln 2) = -e^{a(-\ln 2)} = -e^{-a\ln 2}$。 4. 联立求解：$f(\ln 2) = -(-e^{-a\ln 2}) = e^{-a\ln 2} = 8$。 两边同时取自然对数：$-a\ln 2 = \ln 8 = 3\ln 2$。 由 $\ln 2 \neq 0$，解得 $a=-3$。

点评/变式：本题核心是“$f(x)=-f(-x)$”这个符号转换。注意指数运算：$e^{-a\ln 2} = (e^{\ln 2})^{-a} = 2^{-a}=8$，可得 $-a=3$，更快捷。
