分式不等式

考点分式不等式权重6真题数1学科数学父主题不等式

考点定位

  • 父主题：不等式
  • 权重 weight：6
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 分式不等式标准形式：$\frac{f(x)}{g(x)}>0$ 或 $\frac{f(x)}{g(x)}<0$（含 $\ge,\le$）。
  • 等价转化：
  • $\frac{f(x)}{g(x)}>0 \iff f(x)g(x)>0$（分母不为零自动满足）
  • $\frac{f(x)}{g(x)}<0 \iff f(x)g(x)<0$
  • $\frac{f(x)}{g(x)}\ge0 \iff \begin{cases} f(x)g(x)\ge0 \ g(x)\neq0 \end{cases}$
  • $\frac{f(x)}{g(x)}\le0 \iff \begin{cases} f(x)g(x)\le0 \ g(x)\neq0 \end{cases}$
  • 常见可化为分式不等式的情形：移项通分，化为 $\frac{A(x)}{B(x)}>0$ 形式，切不可随意去分母。
  • 结合绝对值不等式的解集：$|x|>a \ (a>0) \iff x>a \text{ 或 } x<-a$；$|x|<a \iff -a<x<a$。

解题方法与套路

  1. 化简每个不等式为最简形式
  2. 对于绝对值不等式，直接写解集；对于分式不等式，移项使右边为 $0$，分子分母统一化为乘积形式。
  3. 分式化整式
  4. 将 $\frac{f(x)}{g(x)}>0$（$<0$）转化为 $f(x)g(x)>0$（$<0$）；若带等号，需附加分母不为零。
  5. 解整式不等式
  6. 求对应方程根，用数轴穿根法或二次函数图像得解集。
  7. 求交集（或并集，依题意）
  8. 画数轴，确定公共部分，注意端点取舍（分母限制与定义域）。
  9. 检验与作答
  10. 验证端点是否符合条件，尤其分母为零的点必须剔除。

高频易错

  • 去分母错误：直接两边同乘分母（未知正负），导致不等号方向不确定。正确做法是移项通分。
  • 解分式不等式忽略分母不为零：在 $\ge0$ 或 $\le0$ 时易把使分母为零的 $x$ 纳入解集，需额外剔除。
  • 绝对值不等式方向混淆：$|x|>3$ 表示到原点距离大于 $3$，是“两根之外”；$|x|<a$ 是“两根之内”。
  • 求交集时忽视端点：例如集合 $A$ 是开区间，集合 $B$ 是开区间，交集端点应为开，但习惯性写成闭区间。
  • 数轴穿根法奇穿偶不穿误用：在含有 $(x-a)^n$ 因子时注意奇次幂穿过、偶次幂反弹。

代表题精讲

题目：（2009 理科）设集合 $A={x \mid |x|>3}$，$B=\left{x \mid \frac{x-1}{x-4}<0\right}$，求 $A\cap B$。

思路：先分别解出 $A$ 和 $B$ 中不等式的解集，然后利用数轴求两集合的交集。

步骤：
1. 解 $|x|>3$：由绝对值不等式得 $x>3$ 或 $x<-3$，故 $A=(-\infty,-3)\cup(3,+\infty)$。
2. 解 $\frac{x-1}{x-4}<0$：等价于 $(x-1)(x-4)<0$，解得 $1<x<4$，且分母 $x-4\neq0$ 自然满足，故 $B=(1,4)$。
3. 求 $A\cap B$：数轴上 $A$ 是 $(-\infty,-3)\cup(3,+\infty)$，$B$ 是 $(1,4)$，公共部分为 $(3,4)$。
4. 对应选项 B。

点评/变式：本题为基础分式不等式与绝对值不等式结合求交集的题型。陷阱点在于考生可能在解分式不等式时错误去分母，或忽略分母不为零导致区间端点误判。
- 变式：若 $B=\left{x \mid \frac{x-1}{x-4}\le0\right}$，则解集为 $[1,4)$，注意 $4$ 取不到。若求 $A\cap B$，结果为 $[1,4)$ 与 $(-\infty,-3)\cup(3,+\infty)$ 的交集 $(3,4)$，进一步考察端点取值。
