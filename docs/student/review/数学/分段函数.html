知识精要

  • 分段函数：在定义域的不同子集上，对应法则用不同解析式表示的函数。
  • 核心要素：
  • 定义域拆分：关键是确定分段点，将定义域划分为若干不相交的子区间。
  • 对应法则：每个子区间对应一个具体的函数解析式。
  • 整体性：分段函数是一个函数，而非多个函数。其值域为各段值域的并集。
  • 常见题型：
  • 求值：判断自变量所属区间，代入相应解析式。注意层层嵌套的递推求值。
  • 求解析式：利用奇偶性、周期性等函数性质，或应用题中的等量关系，分段求出对应区间上的解析式。
  • 图像与性质：分段作出函数图像，利用图像研究单调性、最值、零点、不等式等问题。
  • 实际应用：根据背景（如利润、医学检测）中不同条件，建立分段函数模型，并求解最值或概率。

解题方法与套路

  1. 分段点与区间划分：
  2. 数学题：从绝对值、二次根式等“天然”分段点划分；对于应用题，找出使问题情境发生质变的数量界限（如成本、临界值、需求量）。

  3. 示例：|x+a|的零点 $x=-a$；利润公式随需求量 $X$ 与进货量 $130$ 的大小关系而变。

  4. 逐段求解并检验：

  5. 在每一段定义域区间内，独立地解方程、不等式或求最值。

  6. 关键一步：将每段求得的结果与该段的定义域区间取交集，作为最终该段的解集。所有段解集的并集即为全题答案。

  7. 含参分段函数的最值：

  8. 明确参数所在分段。
  9. 分别求出每段上的最小值（可能为常数或含参表达式）。

  10. 比较各段最小值，结合参数范围，确定整个分段函数的最小值（通常在各段最小值相等或分段点处取得）。

  11. 数形结合：

  12. 对于研究函数性质、解不等式、求参数取值范围等问题，准确画出分段函数的图象是核心策略。
  13. 观察图象的走势、关键点、交点，将代数问题几何化，往往能快速找到解题突破口。

高频易错

  • 忽视定义域检验：解出的方程根或不等式解集，必须代入相应的分段区间进行验证，超出区间的要舍弃。这是最常见的失分点。
  • 分段点归属不清：将分段点随意划归某一区间，可能导致解析式重复或缺漏。通常按“不重不漏”原则处理，写成 $x \lt a, a \le x \lt b, x \ge b$ 等形式即可。
  • 奇偶性求解析式时符号错误：设 $x<0$，则 $-x>0$，利用 $f(x)=\pm f(-x)$ 求解时，务必注意 $f(-x)$ 需代入已知区间的完整解析式，且整体符号不要遗漏。
  • 应用题建模时单位与关系错误：混淆“需求量”与“供应量”的大小关系，导致利润或成本的表达式列反或遗漏某项（如亏本部分）。应逐项理清事件发生的条件与相应损益的计算公式。

代表题精讲

题目1（2023-新课标Ⅱ-19）：本题为医学检测问题。以频率分布直方图为背景，需通过漏诊率 $p(c)=0.5\%$ 确定临界值 $c$ 及误诊率 $q(c)$。并构建 $f(c)=p(c)+q(c)$ 在 $[95,105]$ 上的解析式，求其最小值。

  • 思路：利用直方图中的面积（频率）代表概率，建立关于 $c$ 的方程求临界值。分段函数 $f(c)$ 的分段点由直方图区间端点确定，应逐段写出 $p(c), q(c)$ 的线性表达式，再求和得到 $f(c)$。最后利用一次函数单调性求各段最小值，比较得全局最小值。

  • 步骤：

  • 求临界值 $c$：由患病者直方图，区间 $[95,100)$ 频率为 $0.03$。漏诊率 $p(c)=0.5\%=0.005$。设 $c \in [95,100)$，则 $(c-95) \times 0.002 = 0.005$，解得 $c=97.5$。误诊率 $q(c)$ 为未患病者直方图中 $[-100,105]$ 区间内大于 $c$ 的面积。算得 $q(97.5)=(100-97.5)\times 0.01 + 0.002 = 0.035 = 3.5\%$。
  • 求 $f(c)$ 解析式：当 $c \in [95,100)$ 时， $p(c) = (c-95)\times 0.002 = 0.002c - 0.19$。 $q(c) = (100-c)\times 0.01 + 0.002 = -0.01c + 1.002$。 从而 $f(c) = p(c)+q(c) = -0.008c + 0.812$。 当 $c \in [100,105]$ 时， $p(c) = 0.005 + (c-100)\times 0.012 = 0.012c - 1.195$。(注意此处 $p(c)$ 累计) $q(c) = (105-c)\times 0.002 = -0.002c + 0.21$。 从而 $f(c) = p(c)+q(c) = 0.01c - 0.985$。

  • 求最小值：$f(c)$ 在 $[95,100)$ 单调递减，最小值为 $f(100)=-0.8+0.812=0.012$。在 $[100,105]$ 单调递增，最小值为 $f(100)=1-0.985=0.015$。比较得 $f(c)$ 在区间 $[95,105]$ 上的最小值为 $f(100)=0.012$。（注：本题答案有特定表述，此处展示了标准的逐段最值求解过程。）

  • 点评/变式：作为新情境题，关键在于提取数学模型。 $p(c), q(c)$ 的构建是典型的“面积累积”过程，分界点为直方图区间端点。变式可改为求期望、方差等，但核心仍是分段建模。

题目2（2019-文-06）：已知 $f(x)$ 为奇函数，且当 $x \ge 0$ 时，$f(x)=1-e^x$，求 $x \lt 0$ 时的解析式。

  • 思路：利用奇函数性质 $f(x)=-f(-x)$。设 $x \lt 0$，则 $-x \gt 0$，将 $-x$ 代入已知的正半轴解析式，再整体加负号。

  • 步骤：

  • 设 $x \lt 0$，则 $-x \gt 0$。
  • 代入已知解析式：$f(-x) = 1 - e^{-x}$。
  • 利用奇函数性质：$f(x) = -f(-x) = -(1 - e^{-x}) = e^{-x} - 1$。

  • $x \lt 0$ 时，$f(x)=e^{-x}-1$，对比选项得D。

  • 点评/变式：此题陷阱在于符号运算。务必牢记奇函数的定义式 $f(x) = -f(-x)$，代入计算时括号要紧随。变式为偶函数求解析式，则用 $f(x)=f(-x)$，直接代入即可，无负号变化。

题目3（2018-理-23）：已知函数 $f(x)=5-|x+a|-|x-2|$。当 $a=1$ 时，解不等式 $f(x) \ge 0$；若 $f(x) \le 1$ 恒成立，求 $a$ 的取值范围。

  • 思路：第一问将 $f(x)$ 去绝对值，化为分段函数，再分段解不等式。第二问分离参数或转化为最值问题 [$f(x) \le 1$ 即 $|x+a|+|x-2| \ge 4$]，利用绝对值的几何意义求最小值。

  • 步骤：

  • (1) $a=1$ 时，$f(x)=5-|x+1|-|x-2|$。 分类讨论去绝对值： 当 $x \le -1$ 时，$f(x)=5-(-x-1)-(2-x)=2x+4$。 令 $2x+4 \ge 0$，得 $x \ge -2$，结合前提得 $-2 \le x \le -1$。 当 $-1 \lt x \lt 2$ 时，$f(x)=5-(x+1)-(2-x)=2 \ge 0$ 恒成立，得 $-1 \lt x \lt 2$。 当 $x \ge 2$ 时，$f(x)=5-(x+1)-(x-2)=-2x+6$。 令 $-2x+6 \ge 0$，得 $x \le 3$，结合前提得 $2 \le x \le 3$。 综上，解集为 $[-2, 3]$。

  • (2) $f(x) \le 1 \Rightarrow 5-|x+a|-|x-2| \le 1 \Rightarrow |x+a|+|x-2| \ge 4$。 由绝对值三角不等式或几何意义（数轴上点 $x$ 到 $-a$ 与 $2$ 的距离之和）： 其最小值为 $|(-a)-2| = |a+2|$。 故原问题等价于 $|a+2| \ge 4$。 解得 $a+2 \ge 4$ 或 $a+2 \le -4$，即 $a \ge 2$ 或 $a \le -6$。

  • 点评/变式：绝对值的分段处理是核心基本功。第二问巧妙利用“恒成立问题转化为最值问题”的思想，结合绝对值的几何意义，避免了再次分类讨论，极大简化了求解过程。这是处理含参绝对值不等式最值的绝佳套路。
