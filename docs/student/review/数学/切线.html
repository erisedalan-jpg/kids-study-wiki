知识精要

  • 导数的几何意义：函数 $y=f(x)$ 在点 $x_0$ 处的导数 $f'(x_0)$ 即为曲线在该点 $(x_0, f(x_0))$ 处切线的斜率 $k$。
  • 切线方程：曲线 $y=f(x)$ 在点 $(x_0, y_0)$ 处的切线方程为 $y - y_0 = f'(x_0)(x - x_0)$。其中 $(x_0, y_0)$ 为切点。
  • 圆锥曲线的切线：
    • 抛物线 $x^2 = 2py$：点 $(x_0, y_0)$ 处的切线斜率为 $k = \frac{x_0}{p}$（可由求导或联立判别式为零求得）。切线方程为 $y - y_0 = \frac{x_0}{p}(x - x_0)$，化简即 $x_0x = p(y + y_0)$。
    • 抛物线 $y^2 = 2px$：点 $(x_0, y_0)$ 处的切线方程为 $y_0y = p(x + x_0)$。
  • 切点弦方程：过曲线外一点 $P(x_0, y_0)$ 作曲线的两条切线，切点为 $A, B$。若曲线为抛物线 $x^2=2py$，则切点弦 $AB$ 所在的直线方程为 $x_0x = p(y + y_0)$。其推导本质是利用两切点均满足同一直线方程。
  • 公切线问题：证明一条直线同时是两个函数图像的切线，需分别找出两函数图像上的切点，并验证两切点处的切线方程完全一致（斜率相等、截距相等）。
  • 平行与垂直关系：两直线平行，斜率相等（$k_1=k_2$）；两直线垂直，斜率乘积为 $-1$（$k_1k_2=-1$）。此关系常用于求参数或切点坐标。

解题方法与套路

  1. 已知切点求切线方程：
    • 步骤一：求导，得到导函数 $f'(x)$。
    • 步骤二：将切点横坐标 $x_0$ 代入导函数，计算切线斜率 $k = f'(x_0)$。
    • 步骤三：利用点斜式写出切线方程 $y - f(x_0) = k(x - x_0)$，并化简。
  2. 已知切线斜率或切线过某点求参数/切点：
    • 情况A：已知斜率 $k$。令导数 $f'(x_0) = k$，解出切点横坐标 $x_0$，进而求出纵坐标或参数。
    • 情况B：已知切线过非切点 $P(m, n)$。设切点坐标为 $(x_0, f(x_0))$，写出含参切线方程 $y - f(x_0) = f'(x_0)(x - x_0)$。将点 $P(m, n)$ 代入，解出 $x_0$，再确定切线方程。
  3. 求圆锥曲线切点弦方程及面积最值：
    • 步骤一：设曲线外一点 $P(x_0, y_0)$ 及曲线上两切点 $A(x_1,y_1), B(x_2,y_2)$。
    • 步骤二：写出以 $A, B$ 为切点的切线方程。
    • 步骤三：利用点 $P$ 在两切线上，得到 $A, B$ 坐标满足同一直线方程，即切点弦 $AB$ 方程。
    • 步骤四：联立切点弦方程与曲线方程，利用韦达定理和弦长公式求弦长 $|AB|$。
    • 步骤五：利用点到直线距离公式求点 $P$ 到弦 $AB$ 的距离 $d$。
    • 步骤六：将三角形面积 $S = \frac{1}{2}|AB|d$ 表达为目标变量的函数，借助二次函数或不等式求最值。
  4. 证明公切线问题：
    • 步骤一：求出第一条曲线在给定切点 $A$ 处的切线方程 $l$。
    • 步骤二：设第二条曲线上的切点 $B$，写出其在 $B$ 处的切线方程 $l'$（含参）。
    • 步骤三：令 $l'$ 与 $l$ 重合，即斜率相等、截距相等，建立方程组。
    • 步骤四：通过方程变形或解方程，证明 $B$ 存在且满足条件。

高频易错

  • 弄错切点：在“过某点”的切线问题中，该点不一定是切点。必须设出切点坐标进行求解，否则极易漏解或出错。
  • 混淆导数公式：
    • $(\ln x)' = \frac{1}{x}$，特别注意复合函数求导，如 $\ln\frac{x-1}{x+1} = \ln(x-1) - \ln(x+1)$ 可简化求导。
    • 分式求导要仔细，分子是“上导下不导减去下导上不导”。
  • 忽略定义域：讨论函数单调性或写切线方程时，需确保自变量取值在函数定义域内。例如，$f(x) = \ln x$ 的定义域为 $(0, +\infty)$。
  • 弦长公式使用错误：弦长公式 $|AB| = \sqrt{1+k^2}|x_1 - x_2| = \sqrt{1+k^2}\frac{\sqrt{\Delta}}{|a|}$（$a$为联立后二次项系数）中，$\Delta$ 须为正，且 $|x_1-x_2| = \frac{\sqrt{\Delta}}{|a|}$，计算时勿忘绝对值。
  • 面积最值漏考虑变量范围：用坐标表示三角形面积后求最值，务必根据点所在曲线方程求出坐标的取值范围（如圆的纵坐标范围 $y \in [-3,-5]$），不结合范围直接用基本不等式或二次函数对称轴求解易出错。

代表题精讲

代表题 1：2008-文-07（导数基础应用）

  • 题目：已知曲线 $y=ax^2$ 在点 $(1, a)$ 处的切线与直线 $2x - y - 6 = 0$ 平行，求 $a$ 的值。
  • 思路：利用导数求出曲线在给定点处的切线斜率，再利用两直线平行斜率相等的条件，建立关于 $a$ 的方程求解。
  • 步骤：
    1. 求导：对 $y=ax^2$ 求导得 $y' = 2ax$。
    2. 求斜率：在点 $(1, a)$ 处，切线斜率 $k = y'|_{x=1} = 2a$。
    3. 已知直线斜率：直线 $2x - y - 6 = 0$ 可化为 $y = 2x - 6$，其斜率为 $2$。
    4. 列方程：因为两条直线平行，所以斜率相等，即 $2a = 2$。
    5. 求解：解得 $a = 1$。
  • 点评/变式：本题是导数几何意义最直接的考察，属于送分题。关键点在于：1. 求导公式要准确；2. 切点横坐标必须代入导函数求斜率；3. 理解平行即斜率相等。变式：若两直线垂直，则条件变为 $2a \times 2 = -1$。
