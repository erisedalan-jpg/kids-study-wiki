切线方程

知识精要

  • 切线定义：对于曲线 $y=f(x)$，若函数在 $x_0$ 处可导，则曲线在点 $P(x_0, f(x_0))$ 处的切线是经过 $P$ 且斜率为 $f'(x_0)$ 的直线；$f'(x_0)$ 即为曲线在该点处的切线斜率。
  • 切线方程公式：点斜式 $y - f(x_0) = f'(x_0)(x - x_0)$。
  • “在点”与“过点”的区别：
  • 在点 $(x_0, y_0)$ 处的切线：该点一定是切点，直接求导得斜率。
  • 过点 $(a, b)$ 的切线：该点未必是切点，需设切点 $(x_0, f(x_0))$，由切线方程 $y - f(x_0) = f'(x_0)(x - x_0)$ 过 $(a,b)$ 以及切点在曲线上，列方程组解出 $x_0$。
  • 导数的几何意义：函数 $y=f(x)$ 在 $x=x_0$ 处的导数 $f'(x_0)$ 等于曲线在 $(x_0,f(x_0))$ 处切线的斜率。
  • 参数方程与极坐标下的切线：
  • 参数方程 $\begin{cases} x = x(t) \ y = y(t) \end{cases}$ 在某点 $(x(t_0), y(t_0))$ 处的切线斜率 $k = \frac{y'(t_0)}{x'(t_0)}$（$x'(t_0)\neq0$）。
  • 圆或一般曲线的切线可用几何法（圆心到直线距离 $d=r$）或隐函数求导，在极坐标系下，通常先求得直角坐标切线方程，再化为极坐标方程 $\rho\cos\theta,\rho\sin\theta$。
  • 公切线问题：两条曲线 $y=f(x)$ 与 $y=g(x)$ 的公切线，需分别设切点，利用切线斜率和切线方程（或截距）相等建立关系。

解题方法与套路

  1. 求曲线在某点处的切线
  2. 求导得 $f'(x)$，代入横坐标得斜率 $k=f'(x_0)$；
  3. 写出切点 $(x_0, f(x_0))$；
  4. 点斜式写出方程，必要时化为一般式或斜截式。
  5. 求曲线过某点的切线
  6. 设切点 $(t, f(t))$；
  7. 计算斜率 $k=f'(t)$，写出切线方程 $y-f(t)=f'(t)(x-t)$；
  8. 代入给定的点坐标，解出 $t$；
  9. 代回得到切线方程。若解出多个 $t$，则有多个切线。
  10. 已知切线方程求参数
  11. 若是“在点”的切线，利用该点导数等于切线斜率；同时切点满足切线方程。
  12. 若切线未知，利用条件列关于参数的方程求解。
  13. 两曲线相切或公切线问题
  14. 对 $y=f(x)$ 与 $y=g(x)$ 的公切线：
    设切点分别为 $(x_1,f(x_1))$ 和 $(x_2,g(x_2))$，切线斜率相等 $f'(x_1)=g'(x_2)$，且两切点处的切线方程相同（一般可由截距相等得到关系），联立求解。
  15. 若一直线与一曲线相切，可通过联立方程，利用判别式 $\Delta=0$ 求解参数（判别式法常用于二次曲线）。
  16. 圆的切线问题
  17. 几何法：设切线方程为 $y-y_0=k(x-x_0)$，利用圆心到直线距离等于半径 $d=r$ 求解 $k$。注意斜率不存在的情况单独检验。
  18. 极坐标切线：先求出直角坐标方程，再利用 $x=\rho\cos\theta, y=\rho\sin\theta$ 化为极坐标方程。
  19. 切线与曲线公共点问题
  20. 求出切线方程后，联立曲线方程与切线方程求解，切点处通常为二重根（相切），另可能有其他交点。

高频易错

  • 混淆“在点处的切线”与“过点的切线”：当点不在曲线上时，必须设切点；即使点在曲线上，求“过该点的切线”也不等同于求“在该点处的切线”，该点可能并非切点。
  • 忽视定义域：涉及 $\ln x$ 等函数，求导前确认 $x>0$，求出的切点横坐标必须在定义域内。
  • 漏解斜率不存在的情况：过一点作圆的切线，若设斜率 $k$，必须讨论直线垂直于 $x$ 轴的情形，避免遗漏竖直切线。
  • 求导错误：基本导数公式记混，尤其是复合函数求导法则（如 $y=\ln(x+1)$ 的导数是 $\frac{1}{x+1}$，而非 $\frac{1}{x}$）。
  • 将切线方程代入曲线方程后，忽略重根含义：相切时判别式 $\Delta=0$ 只对二次方程有效，高次方程需保证至少有一个重根，可通过因式分解验证。
  • 参数方程求切线时，未验证 $x'(t_0) \neq 0$，或误用 $y'(t_0)$ 直接作为斜率。
  • 极坐标转化时，$\rho, \theta$ 与原直角坐标关系不清，导致方程化简出错。

代表题精讲

1. 2021年全国卷文科第21题（2）

题目：已知 $f(x)=x^3 - x^2 + ax +1$，求曲线 $y=f(x)$ 过坐标原点的切线与曲线的公共点坐标。
思路：通过“过原点的切线”设切点，利用切点在曲线上和切线过原点，解出切点坐标，得到切线方程，再联立曲线求所有公共点。
步骤：
- 设切点为 $(t, t^3 - t^2 + at +1)$，导数 $f'(t)=3t^2 - 2t + a$，切线斜率 $k=f'(t)$。
- 切线方程：$y - (t^3 - t^2 + at +1) = (3t^2 - 2t + a)(x - t)$。
- 切线过原点 $(0,0)$，代入化简得 $-t^3 + t^2 - at -1 = -3t^3 + 2t^2 - at$，整理得 $2t^3 - t^2 -1 = 0$，因式分解得 $(t-1)(2t^2 + t + 1)=0$，实数解 $t=1$。
- 切点为 $(1, a+1)$，斜率 $k = 3 - 2 + a = a+1$，切线方程 $y = (a+1)x$。
- 联立 $y = (a+1)x$ 与 $y = x^3 - x^2 + ax +1$，消 $y$ 得 $x^3 - x^2 + ax +1 = (a+1)x$，即 $x^3 - x^2 - x +1 = 0$。因式分解 $(x-1)^2(x+1)=0$。
- 解的 $x=1$（切点，二重根）或 $x=-1$，代入得公共点 $(1, a+1)$ 和 $(-1, -a-1)$。
点评/变式：本题典型地考察“过点”而非“在点”的切线，设切点是关键。公共点除了切点外，还有另一交点，说明切线与曲线可以再相交。变式：若改为“曲线在原点处的切线”则需检查原点是否在曲线上（$f(0)=1$，并不在），从而需重新设切点。

2. 2021年全国卷文科第22题

题目：圆心 $C(2,1)$，半径 $1$ 的圆。（1）写参数方程；（2）过点 $F(4,1)$ 作圆的两条切线，求极坐标方程。
思路：（1）圆参数方程直接写出；（2）先求直角坐标切线方程，讨论斜率不存在情况，再用点到直线距离公式求斜率，最后化为极坐标。
步骤：
- （1）参数方程：$\begin{cases} x = 2 + \cos\theta \ y = 1 + \sin\theta \end{cases}$（$\theta$ 为参数）。
- （2）圆直角坐标方程 $(x-2)^2 + (y-1)^2 = 1$。
① 过 $F(4,1)$ 的直线若斜率不存在，$x=4$，圆心到直线距离 $|4-2|=2>1$，舍去。
② 设切线 $y-1=k(x-4)$，即 $kx - y + 1 - 4k = 0$。圆心 $(2,1)$ 到该直线距离 $d = \frac{|2k - 1 + 1 - 4k|}{\sqrt{k^2+1}} = \frac{|-2k|}{\sqrt{k^2+1}} = 1$。
化简得 $4k^2 = k^2+1$，解得 $k = \pm \frac{\sqrt{3}}{3}$。
切线方程：$y-1 = \pm \frac{\sqrt{3}}{3}(x-4)$，整理为 $x - \sqrt{3}y - 4 + \sqrt{3} = 0$ 和 $x + \sqrt{3}y - 4 - \sqrt{3} = 0$。
- 化为极坐标：将 $x=\rho\cos\theta, y=\rho\sin\theta$ 代入，得 $\rho\cos\theta - \sqrt{3}\rho\sin\theta = 4 - \sqrt{3}$，即 $\rho = \frac{4-\sqrt{3}}{\cos\theta - \sqrt{3}\sin\theta}$，或进一步化为 $\rho\sin(\frac{\pi}{6} - \theta) = \cdots$ 等形式（根据题目答案格式可保留合理形式）。题中给出 $\rho\cos\theta - \sqrt{3}\rho\sin\theta = 4 - \sqrt{3}$ 等均为正确。
点评/变式：圆的切线问题优先考虑几何法（圆心到直线距离）避开了求导。必须检验斜率不存在的情形。极坐标转化只需代入关系式，不必强行合并为单一三角函数。变式：若求圆的切线方程且切点未知，也可利用圆心与切点连线垂直于切线，利用向量求解。

3. 2019年全国卷文科第10题

题目：曲线 $y=2\sin x + \cos x$ 在点 $(\pi, -1)$ 处的切线方程为（选项略）。
思路：求在给定点处的切线，直接求导得斜率，点斜式写方程。
步骤：
- 求导：$y' = 2\cos x - \sin x$。
- 在 $x=\pi$ 处，$k = 2\cos\pi - \sin\pi = -2$。
- 切点 $(\pi, -1)$，切线方程：$y + 1 = -2(x - \pi)$，即 $y = -2x + 2\pi - 1$，一般式 $2x + y - 2\pi + 1 = 0$。
- 对照选项，C选项 $2x + y - 2\pi + 1 = 0$ 正确。
点评/变式：本题极基础，关键是正确求导与代入。注意三角函数的导数值不要算错，$\cos\pi = -1, \sin\pi = 0$。变式：若问“过点 $(\pi,-1)$”的切线，则需设切点重新计算，此处恰好在曲线上，可直接验证是否只有一条切线。
