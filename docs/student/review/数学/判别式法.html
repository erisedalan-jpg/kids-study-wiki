判别式法

考点定位

  • 父主题：数学思想方法
  • 权重 weight：5
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：填空16
  • 难度分布：难1

知识精要

  • 判别式法的核心思想：将问题转化为关于某个变量的二次方程（或可化为二次型），利用该方程有实数解时判别式 $\Delta \ge 0$ 建立不等式，求得目标式的取值范围或最值。
  • 适用条件：能在题目几何或代数关系中，找到约束条件，并将目标量（如线段和、面积、距离等）设为参数，代入约束条件后整理成关于某主元的二次方程（或二次函数形式）。常用于解三角形、解析几何、函数最值等。
  • 关键理论依据：
  • 实系数一元二次方程 $ax^2+bx+c=0$ 有实数根 $\Leftrightarrow \Delta = b^2-4ac \ge 0$（需注意二次项系数 $a \ne 0$ 或单独讨论）。
  • 若方程的定义域为全体实数且参数均为实数，则判别式非负是实根存在的充要条件。
  • 在本题中的体现：由余弦定理得出 $a^2 + c^2 - ac = 3$，设 $AB+2BC = c+2a = m$，消去 $c$ 得到关于 $a$ 的二次方程，利用 $\Delta \ge 0$ 求出 $m$ 的最大值。

解题方法与套路

  1. 定约束关系：根据题目条件（如余弦定理、勾股定理、椭圆定义等）建立含未知边、角或坐标的等式。
  2. 设参表示目标：将待求最值的表达式设为参数 $m$，并用题目中的主要变量表达（例如设 $c+2a=m$）。
  3. 消元代换成二次型：通过代入消元，把约束等式转化为关于某一主元的二次方程（通常整理成 $Ax^2+Bx+C=0$ 形式，系数含 $m$）。
  4. 判别式建不等式：确保主元有实数解（如边长、坐标等默认为实数），令 $\Delta = B^2 - 4AC \ge 0$，解出 $m$ 的范围。
  5. 验证等号条件：将临界 $m$ 值代回检验对应的主元取值是否满足题设（如边长非负、角范围等），从而确定最值是否可取。

高频易错

  • 忽略二次项系数为零的情况：若整理出的方程二次项系数含参数，需先讨论 $A=0$ 时方程退化为一次的情形，否则误用判别式会导致漏解或错解。
  • 未验证等号成立的条件：判别式 $\Delta \ge 0$ 仅保证方程有实根，但该实根是否在题目限制范围内（如线段长度大于0、角度范围等）必须检验，否则可能得到不可取的最值。
  • 消元方向选择不当：若消元后表达式过于复杂或无法化为二次方程，应考虑换元或采用其他方法（如本题另解的正弦定理+辅助角），不可强行使用判别式。
  • 混淆主元与参数：判别式法的前提是主元为实数，若将目标参数误作主元，则推导无效。

代表题精讲

题目 （2011·理·16）在 $\triangle ABC$ 中，$B=60^\circ$，$AC=\sqrt{3}$，则 $AB+2BC$ 的最大值为______。

思路
法一（判别式法）：设三边，用余弦定理建立等式，将目标式设为参数，消去一个边后得到关于另一边长的二次方程，利用判别式求参数范围。
法二（三角法）：用正弦定理将边化角，转化为单一角的三角函数，用辅助角公式求最值。

步骤（法一 判别式法详解） 1. 设 $AB=c$，$BC=a$，$AC=b=\sqrt{3}$，$B=60^\circ$。 2. 由余弦定理：$b^2 = a^2+c^2-2ac\cos B$，代入得 $3 = a^2+c^2 - ac$。 3. 令 $AB+2BC = c+2a = m$，则 $c = m-2a$。 4. 将 $c$ 代入余弦定理式：$a^2 + (m-2a)^2 - a(m-2a) = 3$。
展开整理：$a^2 + m^2 -4am +4a^2 - am +2a^2 = 3$，即 $7a^2 -5am + m^2-3 = 0$。 5. 视 $a$ 为实数，上述关于 $a$ 的二次方程有实数解，故判别式 $\Delta = (-5m)^2 -4 \cdot 7 \cdot (m^2-3) \ge 0$。
计算得 $25m^2 -28m^2 +84 = -3m^2+84 \ge 0$，解得 $m^2 \le 28$，即 $m \le 2\sqrt{7}$？
⚠️ 解析中原计算为 $\Delta = 84-3m^2 \ge 0$ 得 $m \le 2\sqrt{7}$？但题干给答案为 $2\sqrt{7}$。原文解析中 $\Delta=84-3m^2\ge0$ 得 $m\le 2\sqrt{7}$？解析写的是 $m\le 2\sqrt{7}$？原文中写的是“故m≤2”，但答案给的是2√7。仔细看：解析中写“△=84﹣3m2≥0 故m≤2”，而题干给的最大值为2√7，这里有矛盾。从正确推导看：$25m^2-28m^2+84=-3m^2+84\ge 0 \Rightarrow m^2\le 28 \Rightarrow m\le 2\sqrt{7}$。考题答案应是 $2\sqrt{7}$。重新审视：原题答案显示“2 ”，但后面有空白，可能是2√7。我们按正确数学推导输出 $m\le 2\sqrt{7}$，且等号成立时 $a=\frac{5\sqrt{7}}{7}, c=\frac{4\sqrt{7}}{7}$ 满足条件，最大值 $2\sqrt{7}$。 更正：计算判别式 $\Delta = 25m^2 - 28(m^2-3) = -3m^2+84 \ge 0$，得 $m^2 \le 28$，故 $m \le 2\sqrt{7}$。 6. 当 $m=2\sqrt{7}$ 时，代入方程得 $7a^2 -10\sqrt{7}a + (28-3)=0$，即 $7a^2 -10\sqrt{7}a +25=0$，解得 $a=\frac{5\sqrt{7}}{7}$，对应 $c = 2\sqrt{7} - \frac{10\sqrt{7}}{7} = \frac{4\sqrt{7}}{7}$，均为正数，符合题意。
因此 $AB+2BC$ 的最大值为 $2\sqrt{7}$。

点评/变式
- 判别式法的关键在于将约束条件转化为二次方程，注意主元为边长，天然实数；构建方程时需检查系数是否为零。
- 若题目改为求 $AB+BC$ 或 $AB+3BC$ 的最值，同样可设参数，但消元后可能不是二次型，此时可考虑三角换元。
- 另解正弦定理：$AB=2\sin C$，$BC=2\sin A$，$A+C=120^\circ$，化为 $2\sin(120^\circ-A)+4\sin A = \cos A +5\sin A = 2\sqrt{7}\sin(A+\varphi)$，最大值为 $2\sqrt{7}$，可作为验证。
