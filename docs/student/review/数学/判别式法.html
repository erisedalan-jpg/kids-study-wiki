判别式法

考点定位

  • 父主题：数学思想方法
  • 权重 weight：5
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：填空16
  • 难度分布：难1

知识精要

  • 判别式法的核心：将多变量问题通过代换转化为一个变量的一元二次方程，利用方程有实数解的充要条件（判别式 $\Delta\ge 0$）构造不等式，从而确定目标变量的取值范围或最值。
  • 适用条件：问题存在可转化为“关于某变量的二次方程”的结构，且该变量在方程中有实数解（通常为长度、角度等实数变量，需满足隐含的实际限制）。
  • 典型步骤框架：设目标变量为参数→代入已知等式消元→整理成关于主元的二次方程→令 $\Delta\ge 0$ 解出参数范围→验证等号成立的条件是否符合题意。
  • 常见关联考点：余弦定理、正弦定理、二次函数、圆锥曲线中的最值、不等式恒成立等。

解题方法与套路

  1. 选定主元与参数：根据题目所求（如 $AB+2BC$），设目标式为参数 $m$，并结合已知条件设定合适的变量（如边长 $a,c$）作为主元。
  2. 构建等式：利用几何或代数条件（如余弦定理 $a^2+c^2-ac=b^2$）建立变量间的约束关系。
  3. 代入消元：将目标式改写为 $c=m-2a$（或解出其他线性关系），代入约束等式，化简得到关于主元 $a$ 的一元二次方程。
  4. 利用判别式限制：因 $a$ 有实数解，令二次方程的判别式 $\Delta \ge 0$，得到关于 $m$ 的不等式，解出 $m$ 的范围。
  5. 验证最值可取得：将临界 $m$ 值代回方程，求出对应的变量值，验证是否满足实际条件（如边长为正、三角形构成等），确认最值成立。

高频易错

  • 忽略等号成立验证：判别式 $\ge 0$ 只保证二次方程有实数根，但解出的根必须符合原问题的实际意义（如三角形边长>0、角度在 $(0,\pi)$ 等），若不验证可能导致“假最值”或漏解。
  • 转化过程不等价：代入消元时若平方或去分母，可能扩大解的范围，需保证等价变形，或事后检验增根。
  • 主元选取不当：若主元的选择导致二次项系数为零（失去二次性），判别式法无法直接使用，需换元或分类讨论。
  • 混淆判别式法与函数最值：判别式法是基于“存在实数 $x$ 满足 $f(x)=0$”的整体性技巧，不能简单等同于二次函数的最大/最小值，需理解其本质是隐式的约束条件。

代表题精讲

代表题1：2011年全国卷理科第16题

题目：在 $\triangle ABC$ 中，$B=60^\circ$，$AC=\sqrt{3}$，求 $AB+2BC$ 的最大值。

思路： - 设 $BC=a$，$AB=c$，已知 $b=AC=\sqrt{3}$，$B=60^\circ$，用余弦定理得约束 $a^2+c^2-ac=3$。 - 令目标 $m = c+2a$，化为 $c = m-2a$，代入约束式，整理成关于 $a$ 的二次方程。 - 利用 $a$ 为实数，其判别式 $\Delta \ge 0$，解出 $m \le 2$，得到最大值 $2\sqrt{7}？$ 注意原题答案为 $2\sqrt{7}$？不对，解析写 $m\le 2$，最大值2。但答案可能为 $2\sqrt{7}$？重新看一下：原题写“最大值为 2 ”，之后有空格。解析中得出 $m\le 2$，故最大值为2。但单位？原题“AC=”，可能不是√3，而是根号3？b^2=3，所以AC=√3，那么m最大值是2？但代入验证：m=2时，7a^2-10a+1=0，a为正，三角形合理。最终最大值为2。但常见这类题答案可能是2√7？这里按解析结果是2。实际原题是2011重庆理16？我记得有题是AC=√3，求AB+2BC最大值是2√7。等等，检查：解析说“cosB=... 所以a2+c2﹣ac=b2=3”，b=AC=√3，b2=3。设c+2a=m，代入得7a^2﹣5am+m^2﹣3=0，△=84﹣3m2≥0，m2≤28，m≤2√7才对！因为84-3m^2≥0 => m^2 ≤ 28 => m ≤ 2√7。解析却写“△=84﹣3m2≥0 故m≤2”，这明显是笔误。最终答案应该是2√7。而且后面另解中也得到2√7？另解得到2√7 sin(A+φ)，最大值2√7。所以正确答案是2√7。原文本中“最大值为 2　 ”可能漏了根号7。在代表题精讲中，我会按正确答案2√7来讲解，并指出解析笔误，强调判别式得出28。

步骤： - 设 $BC=a$，$AB=c$，$AC=b=\sqrt{3}$。由余弦定理：$b^2=a^2+c^2-2ac\cos 60^\circ$，即 $a^2+c^2-ac=3$。 - 令 $c+2a=m$，则 $c=m-2a$，代入上式：$a^2+(m-2a)^2-a(m-2a)=3$。 - 展开：$a^2 + m^2 -4ma +4a^2 -ma +2a^2 = 3$。 - 合并：$7a^2 -5ma + m^2 -3 =0$。 - 视该方程为关于 $a$ 的一元二次方程，因 $a$ 为实数，故 $\Delta = (-5m)^2 -4\times7\times(m^2-3) \ge 0$。 - 计算：$\Delta = 25m^2 -28m^2 +84 = 84-3m^2 \ge 0$，得 $m^2 \le 28$，故 $m \le 2\sqrt{7}$。 - 当 $m=2\sqrt{7}$ 时，方程化为 $7a^2 - 10\sqrt{7}a +25=0$，解得 $a=\frac{5\sqrt{7}}{7}$，此时 $c=m-2a = \frac{4\sqrt{7}}{7}$，满足三角形两边和大于第三边、边长为正，可取。 - 所以 $AB+2BC$ 的最大值为 $2\sqrt{7}$。

点评/变式： - 判别式法成功将在余弦定理约束下的线性组合最值问题代数化，避免使用三角恒等变换，体现“设参——消元——判别式”的通用思想。 - 易错点：若展开合并计算粗心，或未验证 $m=2\sqrt{7}$ 时对应的 $a,c$ 是否满足三角形条件，会误判最大值的可及性。 - 变式：可改为 $2AB+BC$、$AB+BC$ 等其他线性组合；也可将 $B=60^\circ$ 换成其他特殊角，余弦定理所得约束式相应变化，判别式法依然有效。

另解拓展（正弦定理辅助角法）

因本考点为判别式法，另解仅展示思路：用正弦定理得 $a=2\sin A, c=2\sin C$，由 $A+C=120^\circ$ 将 $m=2\sin C+4\sin A$ 化为 $2\sqrt{7}\sin(A+\varphi)$，直接得最大值 $2\sqrt{7}$。此方法沟通了判别式法与三角函数最值的关联。
