到角公式

考点定位

  • 父主题：解析几何
  • 权重 weight：5
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：选择11
  • 难度分布：难1

知识精要

  • 到角公式
    设直线 $l_1$ 的斜率为 $k_1$，$l_2$ 的斜率为 $k_2$，则 $l_1$ 到 $l_2$ 的角 $\theta$（从 $l_1$ 绕交点逆时针旋转到与 $l_2$ 重合所转过的角）满足
    $$\tan\theta = \frac{k_2 - k_1}{1 + k_1 k_2} \quad (1 + k_1 k_2 \neq 0).$$
  • 方向性：分子为“终边斜率 $-$ 始边斜率”，分母中 $k_1$、$k_2$ 的顺序与分子保持一致。

  • 垂直限制：$1 + k_1 k_2 = 0$ 时两直线垂直，到角为 $90^\circ$，公式失效。

  • 夹角公式（对比）
    两直线夹角 $\alpha$（不大于 $90^\circ$）满足
    $$\tan\alpha = \left|\frac{k_2 - k_1}{1 + k_1 k_2}\right| \quad (1 + k_1 k_2 \neq 0).$$ 夹 角没有方向，结果总取正值。在等腰三角形问题中，若仅使用夹角公式会得到两个可能的斜率值，必须结合几何位置进一步筛选。

  • 适用条件
    两直线斜率均存在且不垂直。一般用于已知（或可设）两直线斜率，求与角有关的等量关系，从而建立方程。

解题方法与套路

  1. 设出目标直线方程
    若直线过原点，直接设 $y = kx$；若不过原点，设斜截式或点斜式。

  2. 转化“角相等”的几何条件

  3. 等腰三角形底边与两腰所成的角相等 → 可利用到角公式表达“一条直线到另一条的角”。

  4. 明确角的旋转方向：反复观察图形，标出“哪条直线转到哪条直线”，写出对应的到角正切。

  5. 列方程求解

  6. 写出两个到角的正切表达式，令它们相等（或根据其他等量关系列出方程）。

  7. 解得斜率的候选值。

  8. 检验与取舍

  9. 限制条件：如“原点在底边上”“斜率存在”“分母不为零”等。
  10. 图形验证：利用倾斜角的范围或画草图排除误根（例如底边应位于两腰之间，或不满足交点位置等）。

高频易错

  • 到角方向弄反
    记错“始边 → 终边”与公式的对应，导致分子、分母符号错误。正确记忆：$\tan\theta = \dfrac{k_{\text{终}} - k_{\text{始}}}{1 + k_{\text{始}} k_{\text{终}}}$。

  • 混淆到角与夹角
    夹角公式取了绝对值，会丢失方向信息。当题目需要区分“到角”或“有向角”时，使用夹角公式会产生多解，增加后续排除成本。

  • 忽视分母为零的情况
    由 $1 + k_1 k_2 = 0$ 引起的无定义情形未单独讨论，导致漏解或误判。

  • 解出斜率后未筛根
    仅靠代数方程得到的根不一定满足几何实际（如原点在底边上、三角形存在性、倾斜角范围等）。本题中 $k=-\frac{1}{3}$ 虽满足方程，但原点不在实际底边线段上，必须结合图形舍去。

代表题精讲

题目

等腰三角形两腰所在直线的方程分别为 $l_1: x + y - 2 = 0$ 与 $l_2: x - 7y - 4 = 0$，原点在等腰三角形的底边上，则底边所在直线的斜率为（ ）
A. 3　　B. 2　　C. $\frac{1}{3}$　　D. $-\frac{1}{3}$

思路

利用 “原点在底边上” 可设底边 $l_3: y = kx$。等腰三角形的底边与两腰的“到角”相等，根据图形选定旋转方向：$l_3$ 到 $l_1$ 的角等于 $l_2$ 到 $l_3$ 的角。由此列出到角方程，解出 $k$，再结合原点位置排除增根。

步骤

  1. 求两腰斜率
    $l_1: y = -x + 2 \Rightarrow k_1 = -1$；
    $l_2: y = \frac{1}{7}x - \frac{4}{7} \Rightarrow k_2 = \frac{1}{7}$。

  2. 设底边方程
    由原点在底边上，设 $l_3: y = kx$（斜率 $k$ 存在）。

  3. 写出到角正切表达式

  4. $l_3$ 到 $l_1$ 的角：$\tan\theta_1 = \dfrac{k_1 - k}{1 + k k_1} = \dfrac{-1 - k}{1 - k}$；

  5. $l_2$ 到 $l_3$ 的角：$\tan\theta_2 = \dfrac{k - k_2}{1 + k_2 k} = \dfrac{k - \frac{1}{7}}{1 + \frac{k}{7}}$。

  6. 列方程
    $\dfrac{-1 - k}{1 - k} = \dfrac{k - \frac{1}{7}}{1 + \frac{k}{7}}$，
    化简得 $\dfrac{k+1}{k-1} = \dfrac{7k-1}{k+7}$（注意符号处理），交叉相乘：
    $(k+1)(k+7) = (k-1)(7k-1)$，
    展开得 $k^2 + 8k + 7 = 7k^2 - 8k + 1$，整理得 $6k^2 - 16k - 6 = 0$，即 $3k^2 - 8k - 3 = 0$。
    解得 $k = 3$ 或 $k = -\frac{1}{3}$。

  7. 验根
    由草图可知，两腰交点可求得，底边应在两腰“内侧”，使原点落在线段内部。$k = -\frac{1}{3}$ 时，底边过于平缓，原点不在底边线段上，舍去。故仅有 $k=3$ 满足。

点评与变式

  • 点评：本题关键是把等腰三角形的“等角”转化为有向的到角相等，而不能用夹角直接列式。列方程时严格遵照“始边 → 终边”的顺序，是避免符号错误的核心。最后的筛根要结合图形或倾斜角的顺序，切勿直接双选。
  • 变式：若题中“原点在底边所在直线上”改为“底边过原点且不经过第三象限”，也会影响斜率取舍；或改为求底边方程，过程不变，最后写出 $y=3x$。到角思想还可用于光线反射、三角形角平分线等问题——本质都是等角关系的斜率表达。
