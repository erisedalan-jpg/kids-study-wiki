前n项和与积

考点前n项和与积权重6真题数1学科数学父主题数列

考点定位

  • 父主题：数列
  • 权重 weight：6
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：解答19
  • 难度分布：中1

知识精要

  • 数列 ${a_n}$ 的前 $n$ 项和：$S_n = a_1 + a_2 + \cdots + a_n$，满足 $a_n = \begin{cases} S_1, & n=1 \ S_n - S_{n-1}, & n\ge 2 \end{cases}$
  • 数列 ${S_n}$ 的前 $n$ 项积：记 $b_n = S_1 \cdot S_2 \cdots S_n$，满足 $b_1 = S_1$，且当 $n\ge 2$ 时 $S_n = \dfrac{b_n}{b_{n-1}}\ (b_{n-1}\neq 0)$。
  • 等差数列的判定与通项：$b_n - b_{n-1} = d$（常数）对 $n\ge 2$ 恒成立；通项 $b_n = b_1 + (n-1)d$。
  • 由 $S_n$ 求 $a_n$ 必须分段：先求 $a_1 = S_1$，再求 $n\ge 2$ 时 $a_n = S_n - S_{n-1}$，最后验证 $n=1$ 是否可合并，若不能则分段给出。

解题方法与套路

  1. 统一变量：将条件中出现的 $S_n$ 与 $b_n$ 利用关系 $S_n = \dfrac{b_n}{b_{n-1}}\ (n\ge 2)$ 转化为只含 $b_n$ 的递推式。
  2. 处理首项：单独检验 $n=1$ 时条件是否与递推结果一致（或直接代条件求 $b_1$）。
  3. 证明等差/等比：通过化简得到 $b_n - b_{n-1} = \text{常数}$（等差）或 $\dfrac{b_n}{b_{n-1}} = \text{常数}$（等比），指明首项与公差/公比。
  4. 写出 $b_n$ 通项：利用等差（或等比）数列的通项公式。
  5. 回代求 $S_n$：由 $S_n = \dfrac{b_n}{b_{n-1}}\ (n\ge 2)$ 及 $S_1 = b_1$ 得出统一的分段（或合并）表达式。
  6. 求 $a_n$ 通项：利用 $a_n = S_n - S_{n-1}\,(n\ge 2)$，并单独写出 $a_1 = S_1$；务必检验 $n=1$ 是否可并入通式，不能则分段写。

高频易错

  • 忽略 $b_{n-1}\neq 0$ 的隐含条件：若 $b_{n-1}=0$，则 $S_n = \dfrac{b_n}{b_{n-1}}$ 无意义，需先确认各项非零（通常可由条件推出）。
  • 未对 $n=1$ 单独处理：直接用 $S_n = \dfrac{b_n}{b_{n-1}}$ 求 $S_1$ 会导致分母出现 $b_0$ 而错误。
  • 通项合并错误：由 $S_n$ 求出的 $a_n$ 表达式在 $n=1$ 时可能不成立，必须验证，否则会丢失 $a_1$ 的正确值。
  • 递推推导中误用下标范围：将 $n\ge 2$ 得到的递推公式错误应用于 $n=1$，导致等差数列的首项或公差出错。
  • 计算失误：分式化简时符号或通分错误，尤其在差分化简 $S_n - S_{n-1}$ 时容易出错。

代表题精讲

题目（2021·理·19）$S_n$ 为 ${a_n}$ 前 $n$ 项和，$b_n$ 为 ${S_n}$ 前 $n$ 项积，已知 $\dfrac{2}{S_n} + \dfrac{1}{b_n} = 2$。 (1) 证明 ${b_n}$ 是等差数列； (2) 求 ${a_n}$ 的通项公式。

思路 利用 $b_n$ 的定义将 $S_n$ 用 $b_n, b_{n-1}$ 替换，代入条件得到 $b_n$ 的递推关系，化简证明其为等差数列。再求出 $b_n$ 通项，反推 $S_n$，最后用 $S_n$ 与 $a_n$ 的关系求通项，注意分段。

步骤 (1) 当 $n=1$ 时，$S_1 = b_1$。由已知 $\dfrac{2}{S_1} + \dfrac{1}{b_1} = 2 \Rightarrow \dfrac{3}{b_1} = 2 \Rightarrow b_1 = \dfrac{3}{2}$。 当 $n\ge 2$ 时，$S_n = \dfrac{b_n}{b_{n-1}}$。代入条件： $$\dfrac{2}{\frac{b_n}{b_{n-1}}} + \dfrac{1}{b_n} = 2 \quad\Rightarrow\quad \dfrac{2b_{n-1}}{b_n} + \dfrac{1}{b_n} = \dfrac{2b_{n-1}+1}{b_n} = 2$$ 所以 $b_n = b_{n-1} + \dfrac{1}{2}$，即 $b_n - b_{n-1} = \dfrac{1}{2}$（常数）。 综上，数列 ${b_n}$ 是首项 $b_1 = \dfrac{3}{2}$，公差 $d = \dfrac{1}{2}$ 的等差数列。

(2) 由(1)得 $b_n = \dfrac{3}{2} + (n-1)\cdot\dfrac{1}{2} = \dfrac{n+2}{2}$。 当 $n=1$ 时，$S_1 = b_1 = \dfrac{3}{2}$； 当 $n\ge 2$ 时，$S_n = \dfrac{b_n}{b_{n-1}} = \dfrac{\frac{n+2}{2}}{\frac{n+1}{2}} = \dfrac{n+2}{n+1}$。 验证 $n=1$ 时 $\dfrac{1+2}{1+1} = \dfrac{3}{2}$ 也成立，故 $S_n = \dfrac{n+2}{n+1}\ (n\ge 1)$。 于是 $a_1 = S_1 = \dfrac{3}{2}$； 当 $n\ge 2$ 时， $$a_n = S_n - S_{n-1} = \dfrac{n+2}{n+1} - \dfrac{n+1}{n} = \dfrac{n(n+2) - (n+1)^2}{n(n+1)} = \dfrac{-1}{n(n+1)}$$ 该表达式在 $n=1$ 时值为 $-\dfrac{1}{2} \neq \dfrac{3}{2}$，故需分段： $$ a_n = \begin{cases} \dfrac{3}{2}, & n=1 \ -\dfrac{1}{n(n+1)}, & n \ge 2 \end{cases} $$

点评/变式 - 关键纽带：$S_n = \dfrac{b_n}{b_{n-1}}$（$n\ge 2$）实现了 $S_n$ 与 $b_n$ 的互化，是破题核心。 - 易错警示：许多考生直接将 $S_n$ 代入条件时忘记对 $n=1$ 单独讨论，或由 $S_n$ 求 $a_n$ 后未检验 $n=1$，导致漏掉分段。 - 变式思考：若条件变为 “$S_n$ 的前 $n$ 项积 $b_n$ 满足 $\lambda S_n + \mu / b_n = C$”，可用完全相同方法设出递推；若求 ${b_n}$ 的通项或判断等差/等比，核心均是消去 $S_n$。
