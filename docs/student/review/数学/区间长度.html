知识精要

  • 几何概型定义：若随机试验的可能结果无限多且每个结果发生的可能性相等，通常借助几何度量（长度、面积、体积）来定义概率，称为几何概型。
  • 核心公式：$P(A) = \frac{\mu(A)}{\mu(\Omega)}$，其中 $\mu$ 表示对应区域的几何度量。
  • 区间长度概率模型：在一维区间内等可能取点，概率等于事件对应子区间的长度与总区间长度之比，即 $P = \frac{L_{\text{事件}}}{L_{\text{总}}}$。
  • 适用条件：试验结果无限且等可能，概率与位置无关，仅与几何度量占比有关。

解题方法与套路

  1. 识别模型：题干中出现“在区间……随机取数”等描述，立即锁定为一维几何概型（长度型）。
  2. 确定总长度：根据给定区间端点计算总长度 $L_{\text{总}}$。
  3. 确定事件长度：根据事件条件（如“取到的数小于某值”）确定对应子区间的长度 $L_{\text{事件}}$。
  4. 套用公式：概率 $P = \frac{L_{\text{事件}}}{L_{\text{总}}}$，计算结果后约分为最简分数。
  5. 作答验证：检查概率值是否在 $0$ 和 $1$ 之间，核对区间端点是否考虑开闭（一般不影响概率）。

高频易错

  • 忽略区间长度计算：将区间端点误作长度直接代入公式，例如把 $(0,\frac12)$ 的总长度误认为是 $\frac12 - 0$ 但计算错误。
  • 分子分母颠倒：将“总长度”作为分子导致概率 $>1$。
  • 开闭区间混淆（不影响概率）：开区间或闭区间的单点概率为 $0$，因此是否包含端点不影响连续型区间长度概率的计算结果。
  • 数轴单位误读：如将 $\frac13$ 理解为在总区间为 $\frac12$ 中的绝对坐标，未正确折算长度。

代表题精讲

2021-文-07

题目：在区间 $(0, \frac12)$ 随机取 $1$ 个数，求取到的数小于 $\frac13$ 的概率。

思路：识别为几何概型，总区间长度 $L_{\text{总}} = \frac12$，事件“小于 $\frac13$”对应子区间 $(0, \frac13)$，长度 $L_{\text{事件}} = \frac13$，概率为两者之比。

步骤： - 总长度：$L_{\text{总}} = \frac12 - 0 = \frac12$。 - 事件长度：$L_{\text{事件}} = \frac13$（在区间 $(0, \frac12)$ 内，$\frac13 < \frac12$ 成立，因此完整包含子区间）。 - 概率计算：$P = \frac{\frac13}{\frac12} = \frac13 \times \frac21 = \frac23$。 - 对照选项，选 $\frac23$。

点评/变式：此题极简，但易错点在于看到 $\frac12$ 和 $\frac13$ 直接相减或相乘。变式可将总区间改为 $(0,1)$ 或事件改为“大于某个数”，或引入分段区间，解题步骤完全一致，只需准确求出子区间长度。注意当事件子区间超出总区间范围时，应取交集长度。
