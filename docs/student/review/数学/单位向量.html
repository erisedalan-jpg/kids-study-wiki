单位向量

  • 父主题：平面向量
  • 权重 weight：1

  • 出现题位：填空13
  • 难度分布：易1

知识精要

  1. 单位向量定义：长度（模）等于 1 的向量，记作 $\vec{e}$。满足 $|\vec{e}| = 1 \iff \vec{e}^2 = 1$。
  2. 向量垂直充要条件：$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0$。
  3. 核心运算律：数量积满足分配律 $(\vec{a}+\vec{b})\cdot(\vec{c}+\vec{d}) = \vec{a}\cdot\vec{c} + \vec{a}\cdot\vec{d} + \vec{b}\cdot\vec{c} + \vec{b}\cdot\vec{d}$。
  4. 模与数量积关系：$|\vec{a}|^2 = \vec{a} \cdot \vec{a} = \vec{a}^2$。

解题方法与套路

  1. 设基底/参数：利用已知垂直关系，常设单位正交基底 $\vec{i},\vec{j}$ 或直接设两垂直单位向量 $\vec{a},\vec{b}$，其满足 $\vec{a}^2 = \vec{b}^2 = 1$，且 $\vec{a} \cdot \vec{b} = 0$。
  2. 向量条件代数化：将题中所有"垂直""单位"等几何条件，严格转化为数量积的方程。
  3. 垂直：数量积等于零。
  4. 模长：直接平方转化为向量的平方。
  5. 展开化简：利用数量积的分配律展开算式，代入已知基底的数量积关系，消去交叉项，化简为关于待求参数 $k$ 的代数方程。
  6. 解方程求值：解出参数值，注意实数范围内是否符合题意（若无其他限制则保留根）。

高频易错

  1. 忽略"单位"条件：做题时只用了 $\vec{a} \perp \vec{b}$，却忘了 $|\vec{a}| = |\vec{b}| = 1$ 这一关键条件，导致化简时无法消去模长。
  2. 数量积展开错误：错误套用多项式乘法，丢掉交叉项。记牢 $(\vec{a}+\vec{b})\cdot(\vec{c}-\vec{d}) = \vec{a}\cdot\vec{c} - \vec{a}\cdot\vec{d} + \vec{b}\cdot\vec{c} - \vec{b}\cdot\vec{d}$。
  3. 混淆数量积与实数乘法：写出 $\vec{a} \cdot \vec{a} = 1$ 之后，在方程中又错误地写成 $|\vec{a}|$ 或丢掉平方，导致方程错误。
  4. 忽略实数解验根：解出 $k$ 值后没有代回原式检验是否满足初始的垂直条件。

代表题精讲

题目：已知 $\vec{a}$ 与 $\vec{b}$ 为两个垂直的单位向量，$k$ 为实数，若向量 $\vec{a}+\vec{b}$ 与 $k\vec{a} - \vec{b}$ 垂直，求 $k$ 的值。

思路：直接利用向量垂直的充要条件建立数量积方程。由单位向量和垂直关系可知 $\vec{a}^2 = \vec{b}^2 = 1$ 且 $\vec{a} \cdot \vec{b} = 0$。列出 $(\vec{a}+\vec{b})\cdot(k\vec{a} - \vec{b})=0$，展开后代入已知条件即得关于 $k$ 的一元一次方程。

步骤：
1. 依题意写出已知数量关系：
$\vec{a}^2 = 1,\quad \vec{b}^2 = 1,\quad \vec{a}\cdot\vec{b}=0$。
2. 由题设两向量垂直得：
$(\vec{a}+\vec{b})\cdot(k\vec{a} - \vec{b}) = 0$。
3. 展开左边：
$= k(\vec{a}\cdot\vec{a}) - \vec{a}\cdot\vec{b} + k(\vec{b}\cdot\vec{a}) - \vec{b}\cdot\vec{b}$。
4. 代入已知条件化简：
$= k\cdot 1 - 0 + k\cdot 0 - 1 = k - 1$。
5. 令 $k - 1 = 0$，解得 $k = 1$。

点评/变式：本题为基础题型，核心仅考察一个转化：将几何垂直关系正确翻译为代数方程。
变式思考：若条件改为 $\vec{a}+\vec{b}$ 与 $k\vec{a}+\vec{b}$ 的夹角为锐角，则应建立数量积 $>0$ 的不等式求解。
