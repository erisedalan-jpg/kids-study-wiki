知识精要

  • 参数方程与普通方程互化
    • 消参方法：代入消参（由一式解出参数代入另一式）；三角恒等变换消参（如利用 $\sin^2 \theta + \cos^2 \theta = 1$）；代数变换消参（如已知 $x=t+\frac{1}{t}, y=t-\frac{1}{t}$，则 $x^2 - y^2 = 4$）。
    • 特别注意：参数方程化为普通方程时，必须注明 $x, y$ 的取值范围（即参数对坐标的限制，如 $x \ge 0$，或 $0 \le y \le 1$），否则不是等价变形。
  • 极坐标与直角坐标互化公式
    • 互化前提：极点与原点重合，极轴与 $x$ 轴正半轴重合。
    • 核心公式：$$x = \rho \cos\theta,\quad y = \rho \sin\theta,\quad \rho^2 = x^2 + y^2,\quad \tan\theta = \frac{y}{x}\ (x \neq 0)$$
    • 常见变形：$\rho = 2a\cos\theta \implies (x-a)^2 + y^2 = a^2$（圆心在 $x$ 轴且过极点的圆）。
    • 三角展开：$\rho \sin(\theta \pm \frac{\pi}{3}) = \frac{1}{2}\rho \sin\theta \pm \frac{\sqrt{3}}{2}\rho \cos\theta$。
  • 直线参数方程标准式
    • 标准式：$\begin{cases} x = x_0 + t\cos\alpha \ y = y_0 + t\sin\alpha \end{cases}$（$t$ 为参数，$\alpha$ 为倾斜角）。
    • 参数 $t$ 的几何意义：$|t|$ 表示直线上动点到定点 $(x_0, y_0)$ 的距离。
  • 常见曲线
    • 圆 $(x-a)^2+(y-b)^2=r^2$ 的参数方程：$\begin{cases} x = a + r\cos\theta \ y = b + r\sin\theta \end{cases}$（$\theta$ 为参数）。
    • 椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 的参数方程：$\begin{cases} x = a\cos t \ y = b\sin t \end{cases}$（$t$ 为参数）。

解题方法与套路

  1. 极坐标转直角坐标
  2. 遇到含 $\rho, \theta$ 的三角和差公式，先展开（如 $\rho\sin(\theta + \frac{\pi}{3})$），再利用 $x = \rho\cos\theta, y = \rho\sin\theta$ 整体代换，最后化简得到 $Ax+By+C=0$ 形式。
  3. 参数方程求交点
  4. 将曲线参数方程直接代入直线直角坐标方程（或另一曲线方程），转化为关于参数 $t$（或 $\theta$）的三角函数方程。
  5. 核心技巧：辅助角公式 处理 $a\sin t + b\cos t$，或利用 $\sin t, \cos t$ 的有界性建立不等式求参数范围。
  6. 若涉及二次项，可利用 $\sin^2 t + \cos^2 t = 1$ 转化为二次函数或判别式问题。
  7. 处理动点轨迹与距离
  8. 向量法：若 $\overrightarrow{OP} = 2\overrightarrow{OM}$，且 $M$ 在已知曲线上，设参数表达 $M$ 后，$P$ 点坐标直接成比例扩大，消参即得轨迹。
  9. 中点公式：$M$ 为 $PQ$ 中点，直接用参数表示 $P, Q$ 坐标后，利用中点坐标公式构建 $M$ 的参数方程。
  10. 距离最值：通常用两点间距离公式化为 $\alpha$ 的三角函数求值域，或利用极坐标下 $\rho$ 的函数求极值（$|AB| = |\rho_1 - \rho_2|$）。
  11. 求极坐标轨迹方程
    • 先求出普通方程中的 $x,y$ 关系，再利用互化公式反推 $\rho$ 关于 $\theta$ 的表达式。
    • 关键要注意 $\theta$ 的限制范围（如线段、射线或半圆的限制）。

高频易错

  • 消参不完全导致 $x,y$ 范围扩大：如半圆极坐标 $\rho=2\cos\theta, \theta\in[0,\frac{\pi}{2}]$ 化为普通方程应为 $(x-1)^2+y^2=1$ 且 $0\le y\le 1$。漏写 $y\ge 0$ 会作为错误处理。
  • 忽视隐含条件：参数方程 $\begin{cases} x = t + \frac{1}{t} \ y = t - \frac{1}{t} \end{cases}$ 隐含 $|x| \ge 2$。此类隐含范围是易扣分点。
  • 极坐标方程与直线垂直混淆：求切线或垂线时，容易混淆直线斜率和极径斜率。如极坐标方程中，若切线与已知直线垂直，应先转化为直角坐标下的垂直关系（斜率乘积为 $-1$）。
  • 角度范围忽略：在极坐标方程求交点或轨迹时，未讨论 $\theta$ 与 $\rho$ 同号的情况，导致出现不在线段上的多余点。
  • 参数 $t$ 的意义错用：非标准直线的参数方程（$t$ 的系数平方和不为 1），$|t|$ 不表示长度。只有标准式才有几何意义。

代表题精讲

代表题 1：2022-文-22/理-22

  • 题目：曲线 $C: \begin{cases} x = \sqrt{3}\cos 2t \ y = 2\sin t \end{cases}$，直线 $l$ 极坐标方程为 $\rho\sin(\theta+\frac{\pi}{3})+m=0$。（1）求 $l$ 的直角坐标方程；（2）若 $l$ 与 $C$ 有公共点，求 $m$ 范围。
  • 思路：极坐标方程核心在于“展开-代换”四字诀。对于公共点问题，需将参数方程代入直角坐标方程，利用三角函数有界性或二次函数值域求解。
  • 步骤
    1. 化直：$\rho\sin(\theta+\frac{\pi}{3}) = \rho(\frac{1}{2}\sin\theta+\frac{\sqrt{3}}{2}\cos\theta) = \frac{1}{2}y + \frac{\sqrt{3}}{2}x$。得 $l: \sqrt{3}x + y + 2m = 0$。
    2. 联立：代入 $C$，得 $\sqrt{3}(\sqrt{3}\cos 2t) + 2\sin t + 2m = 0$。化简为 $3(1-2\sin^2 t) + 2\sin t + 2m = 0$。
    3. 换元：令 $u = \sin t \in [-1, 1]$，问题转化为二次函数 $2m = 6u^2 - 2u - 3$ 在 $[-1,1]$ 有解。
    4. 求值域：对称轴 $u=\frac{1}{6}$，最小值在 $u=\frac{1}{6}$ 处取 $-\frac{19}{6}$；最大值在 $u=-1$ 处取 $5$。故 $-19 \le 2m \le \frac{19}{3}$，即 $m \in [-\frac{19}{12}, \frac{5}{2}]$。
  • 点评/变式：此题典型陷阱在于 $C$ 方程中 $x$ 是关于 $2t$ 的余弦，需化为 $x=\sqrt{3}(1-2\sin^2 t)$ 实现变量统一。若无法统一参数角度，此题无法解出。

代表题 2：2020-理-22

  • 题目：$C_1: \begin{cases} x = 4\cos^2\theta \ y = 4\sin^2\theta \end{cases}$，$C_2: \begin{cases} x = t+\frac{1}{t} \ y = t-\frac{1}{t} \end{cases}$。（1）化为普通方程；（2）求经过极点和 $C_1, C_2$ 交点 $P$ 且圆心在极轴上的圆的极坐标方程。
  • 思路：消参时注意取值范围限制。对于过极点的圆，其极坐标方程必为 $\rho = 2R\cos\theta$，求出 $P$ 点坐标即可解得 $R$。
  • 步骤
    1. 化普：$C_1$ 两式相加即得 $x+y=4$，但注意到 $\cos^2\theta, \sin^2\theta \in [0,1]$，故 $x,y \in [0,4]$。
    2. $C_2$ 利用平方差得 $x^2-y^2=(t+\frac{1}{t})^2 - (t-\frac{1}{t})^2 = 4$，即 $\frac{x^2}{4} - \frac{y^2}{4} = 1$。注意 $|x| \ge 2$。
    3. 求交点：联立 $\begin{cases} x+y=4 \ x^2-y^2=4 \end{cases}$，解得 $x-y=1$，进而得 $P(\frac{5}{2}, \frac{3}{2})$。
    4. 求极坐标：设圆极坐标方程 $\rho = 2R\cos\theta$。$P$ 点极径 $\rho_P = \sqrt{(\frac{5}{2})^2+(\frac{3}{2})^2} = \frac{\sqrt{34}}{2}$，极角 $\cos\theta_P = \frac{5/2}{\rho_P}$。代入 $\rho_P = 2R\cos\theta_P$ 得 $2R = \frac{\rho_P}{\cos\theta_P} = \frac{34}{10} = \frac{17}{5}$。故极坐标方程为 $\rho = \frac{17}{5}\cos\theta$。
  • 点评/变式：本题考查了消参的两种基本方法（加减消元与平方差消元）。求圆的极坐标方程，若能识破“过极点+圆心在极轴”即 $\rho = a\cos\theta$ 的结论，计算量将极大简化。
