台体体积

考点台体体积权重8真题数1学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：8
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 台体体积公式：设上、下底面积分别为 $S_1,S_2$，高为 $h$，则台体体积 $$V=\frac{1}{3}h\left(S_1+S_2+\sqrt{S_1S_2}\right).$$ 适用于棱台、圆台，注意中间项 $\sqrt{S_1S_2}$ 不可遗漏。
  • 正棱台结构特征：上下底面平行且为相似正多边形，各侧棱延长后交于一点（可补形成正棱锥）；上下底面中心连线垂直于底面，长度为台体高；顶点在底面的投影落在这条中心连线上，但与底面中心一般不重合。
  • 线面角定义：平面的一条斜线与它在平面内的射影所成的锐角，即 $\sin\theta=\frac{\text{垂线段长}}{\text{斜线段长}}$，$\tan\theta=\frac{\text{垂线段长}}{\text{射影长}}$。求角的关键是准确找到垂足和射影。
  • 正三角形面积：边长为 $a$ 的正三角形面积 $S=\frac{\sqrt3}{4}a^2$；正三角形中线（高）长 $h_{\triangle}=\frac{\sqrt3}{2}a$；中心到顶点距离为 $\frac{2}{3}h_{\triangle}=\frac{\sqrt3}{3}a$，中心到边距离为 $\frac{1}{3}h_{\triangle}$。

解题方法与套路

  1. 直接法（体积对接法）
  2. 由已知边长得上下底面面积 $S_1,S_2$；
  3. 代入台体体积公式解出高 $h$；
  4. 画截面图，取底面中心及对应顶点，利用“上底面顶点在下底面的投影位于中心连线上”这一正棱台性质确定射影点位置；
  5. 计算射影线段长（通常为中心到顶点距离之差）；
  6. 在直角三角形中用 $\tan\theta = \dfrac{h}{\text{射影长}}$ 求线面角正切。
  7. 补形法（锥体转化法）
  8. 将正棱台补形为以原下底面为底面的正棱锥；
  9. 利用棱台高及底面边长比例，得到台体与锥体体积关系（或比例），求出锥体体积；
  10. 由锥体体积及底面积得锥高，即为补出的小锥高与台高之和；
  11. 所求侧棱与底面的夹角即原锥侧棱与底面的夹角，在锥中应用正切定义求解。

高频易错

  • 体积公式记错：漏掉 $\sqrt{S_1S_2}$ 或写成 $\frac{S_1+S_2}{2}$，导致高算错。
  • 射影位置混淆：误将台体顶点在底面的射影当作底面中心，直接使用中心到顶点的距离作为射影长，导致 $\tan\theta=\frac{h}{AO}$（错误）。正三棱台顶点的射影是上底面对应顶点沿 $h$ 方向正投影到底面的点，与中心 $O$ 有一小段距离。
  • 长度计算粗心：正三角形底边中线与中心距边长关系的比例易错，中心到顶点距离是 $\frac{2}{3}$ 中线，利用时须细心。
  • 角度定义偏差：线面角是斜线与射影的夹角，正切须用垂线长比射影长，不可用斜线长作分母。

代表题精讲

题目（2024·新课标Ⅱ·7）
正三棱台 $A B C - A_1 B_1 C_1$ 的体积为 $\dfrac{52}{3}$，$AB = 6$，$A_1B_1 = 2$，$A_1A$ 与底面 $ABC$ 所成角的正切值为？

思路
给定台体上下底边长，先求两底面积，利用台体体积公式反求高。再结合正三棱台的投影特征，找到 $A_1$ 在底面射影 $M$ 的位置，构成直角三角形 $A_1 M A$，用高及射影长求正切。

步骤
1. 计算两底面积：
$S_{ABC} = \frac{\sqrt3}{4} \times 6^2 = 9\sqrt3$，
$S_{A_1B_1C_1} = \frac{\sqrt3}{4} \times 2^2 = \sqrt3$。
2. 代入台体体积公式求高 $h$：
$V = \frac13 h\left(9\sqrt3 + \sqrt3 + \sqrt{9\sqrt3 \cdot \sqrt3}\right) = \frac13 h\left(10\sqrt3 + 3\sqrt3\right) = \frac{13\sqrt3}{3}h$，
由 $\frac{13\sqrt3}{3}h = \frac{52}{3}$，得 $h = \frac{4}{\sqrt3} = \frac{4\sqrt3}{3}$。
3. 寻找线面角：
取底面正三角形中心 $O$，上底中心 $O_1$，则 $O_1O \perp$ 底面且 $O_1O = h$。因为正三棱台侧棱延长交于一点，$A_1,O_1,O,A$ 共线。$A_1$ 在底面的射影 $M$ 在直线 $OA$ 上，且 $O_1A_1 \parallel OM$，$OM = O_1A_1$。
底面中心到顶点距离 $OA = \frac23 \times \frac{\sqrt3}{2} \times 6 = 2\sqrt3$，
上底中心到顶点距离 $O_1A_1 = \frac23 \times \frac{\sqrt3}{2} \times 2 = \frac{2\sqrt3}{3}$。
故射影长 $AM = OA - OM = 2\sqrt3 - \frac{2\sqrt3}{3} = \frac{4\sqrt3}{3}$。
4. 求正切：
$A_1M = h = \frac{4\sqrt3}{3}$，则 $\tan\theta = \frac{A_1M}{AM} = 1$。

点评与变式
本题亦可直接补形为正三棱锥 $P-ABC$，由比例求得锥体积 $V_{P-ABC} = 18$，再得锥高，进而求出侧棱与底面夹角，正切值同样为 $1$。补形法能绕过复杂的投影长度计算，但需熟练掌握锥台比例关系。若底面不是正三角形而换作正方形（正四棱台），投影分析方法完全一致，始终抓住“顶点、中心共线”及“平行投影相等”两条。
