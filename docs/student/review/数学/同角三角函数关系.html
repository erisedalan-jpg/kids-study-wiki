知识精要

同角三角函数的基本关系是三角函数恒等变换与求值的基石，其核心内容如下：

  1. 平方关系：$\sin^2\alpha + \cos^2\alpha = 1$。
    • 适用条件：$\alpha$ 为任意角。
    • 衍生变形：$(\sin\alpha \pm \cos\alpha)^2 = 1 \pm 2\sin\alpha\cos\alpha$ （与二倍角公式 $\sin2\alpha = 2\sin\alpha\cos\alpha$ 紧密联系）。
  2. 商数关系：$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$。
    • 适用条件：$\alpha$ 满足 $\cos\alpha \neq 0$，即 $\alpha \neq \frac{\pi}{2} + k\pi, k \in \mathbb{Z}$。
    • 衍生变形：$\sin\alpha = \tan\alpha \cdot \cos\alpha$。
  3. 核心思想：“知一求二”。在已知一个三角函数值及角所在象限（或能够判定符号）的前提下，可通过上述两组关系求出该角的其他三角函数值。其本质是利用方程思想求解。
  4. 与其它公式的联系：
    • 与诱导公式：实现各象限角的三角函数值向锐角三角函数的转化。
    • 与两角和差公式：在同角关系求值后，代入 $\sin(\alpha \pm \beta), \cos(\alpha \pm \beta), \tan(\alpha \pm \beta)$ 等公式进行综合计算。
    • 与二倍角公式：二倍角公式（如 $\sin2\alpha = 2\sin\alpha\cos\alpha$, $\cos2\alpha = \cos^2\alpha - \sin^2\alpha$）本身就是同角关系的直接应用和延伸，常与平方关系结合进行化简求值。

解题方法与套路

在高考真题中，本考点很少单独出现，多作为解题链的中间环节。通用解法可归纳为以下几个步骤：

  1. 看角定号：拿到题目，首先确定目标角或已知角的范围（象限）。这是杜绝符号错误的根本。若角所在象限未明确给出，必须分类讨论或通过已知函数值的隐含信息判定。
  2. 选公式定目标：分析已知条件与需要求解的量之间的联系，选择合适的公式。
    • 已知 $\tan\alpha$ 求 $\sin\alpha, \cos\alpha$ 的齐次式：利用商数关系 $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$ 并结合平方关系，构造分式或方程组求解。
    • 已知 $\sin\alpha \pm \cos\alpha$ 的值：优先对该式进行平方，利用平方关系转化为求 $2\sin\alpha\cos\alpha$（即 $\sin2\alpha$），再通过配方等手段求 $\sin\alpha \mp \cos\alpha$，最后由方程组解出 $\sin\alpha$ 和 $\cos\alpha$。
    • 一般求值问题：直接运用平方关系 $\sin^2\alpha + \cos^2\alpha = 1$ 进行弦切互化或已知一个值求另一个值。
  3. 方程求解：将第一步确定的符号，代入第二步选择的公式，构建方程或方程组。在利用平方关系开方求解 $\sin\alpha$ 或 $\cos\alpha$ 时，务必根据第一步的符号进行取舍。
  4. 整体代换：若问题不要求单独求出 $\sin\alpha$ 或 $\cos\alpha$，而是求某个组合式的值（如 $\sin\alpha + \cos\alpha$，$\sin\alpha\cos\alpha$），应优先考虑整体思想，通过完全平方公式或韦达定理等建立联系，避免复杂的分情况讨论和求值。

高频易错

这些真题暴露的典型失分点，需要高度警惕：

  • 符号判定错误：这是最高频错误。在利用平方关系开方时，忽略了角所在的象限，导致三角函数值的正负号判断失误。例如，2013理15题，明确 $\theta$ 为第二象限角，求出的正弦为正、余弦为负，才能正确计算和与积。2009文/理04题，由 $\cot A$ 为负值，可判断 $A$ 为钝角，从而排除 $\cos A$ 为正的选项。
  • 公式适用条件忽视：使用商数关系 $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$ 及其变形时，未确保分母不为零（即角 $\alpha$ 的终边不在 $y$ 轴上）。若题目中隐含有条件限制了角的范围，需仔细甄别。
  • 混淆平方关系与二倍角：在处理 $(\sin\alpha - \cos\alpha)^2 = 1 - \sin2\alpha$ 或解方程 $2\sin\alpha = \cos\alpha$ 时，部分学生容易在利用 $\sin^2\alpha + \cos^2\alpha = 1$ 消元时出现符号或系数错误。
  • 三角与二次函数结合型问题的值域忽视：如2017理14题，将 $\sin^2x$ 转化为 $1-\cos^2x$ 后，转化为关于 $\cos x$ 的二次函数，此时必须严格根据 $x$ 的范围确定中间变量 $t = \cos x$ 的取值范围，然后在此范围内求二次函数的最值。学生常常忽略定义域（这里是三角函数的值域）限制，直接对二次函数取全局最值。
  • 对“第一象限角”的过度联想：第一象限角的三角函数值不一定都为最简单的正数。比如2024新课标Ⅱ-13题给出了具体的数值关系，是一个计算题，而不是简单的符号判断题。

代表题精讲

题目 2023-新课标Ⅱ-07：已知 $\alpha$ 为锐角，$\cos\alpha = \frac{1+\sqrt{5}}{4}$，则 $\sin\frac{\alpha}{2} =$ ( )。 思路 本题要求半角的正弦值，核心思路是利用二倍角公式（或半角公式）搭建已知角 $\alpha$ 的余弦与待求角 $\frac{\alpha}{2}$ 正弦之间的关系。通过设定一个完全平方的形式，可巧妙避开直接开方时的正负号讨论。 步骤 1. 建立关系：由余弦的二倍角公式 $\cos\alpha = 1 - 2\sin^2\frac{\alpha}{2}$，得 $2\sin^2\frac{\alpha}{2} = 1 - \cos\alpha$。 2. 代入求值：将 $\cos\alpha = \frac{1+\sqrt{5}}{4}$ 代入，得 $1 - \cos\alpha = 1 - \frac{1+\sqrt{5}}{4} = \frac{3-\sqrt{5}}{4}$。 3. 构造完全平方：将 $\frac{3-\sqrt{5}}{4}$ 分子分母同乘以2，得 $\frac{6-2\sqrt{5}}{8} = \frac{(\sqrt{5}-1)^2}{8}$。 4. 开方定号：$\sin\frac{\alpha}{2}$ 的表达式为 $\sin\frac{\alpha}{2} = \sqrt{\frac{(\sqrt{5}-1)^2}{16}}$。因为 $\alpha$ 为锐角，则 $\frac{\alpha}{2}$ 也是锐角，其正弦值为正，故 $\sin\frac{\alpha}{2} = \frac{\sqrt{5}-1}{4}$。 点评/变式 本题的难点在于数值计算和配方技巧。常规思路是半角公式 $\sin\frac{\alpha}{2} = \sqrt{\frac{1-\cos\alpha}{2}}$，直接带入 $\cos\alpha$ 的值会产生复合二次根式，需要配出完全平方式才能化简。这提醒考生在备考中需积累常见的根式化简技巧，如 $(\sqrt{5}-1)^2 = 6-2\sqrt{5}$。

题目 2024-新课标Ⅱ-15（节选关键步骤）：记 $\triangle ABC$ 的内角 $A,B,C$ 的对边分别为 $a,b,c$，已知 $\sin A + \sqrt{3}\cos A = 2$。(1) 求 $A$。 思路 这是一道典型的“同角关系+辅助角公式”综合题。通过辅助角公式将已知等式左边合并为单一三角函数形式，再利用同角三角函数的基本关系与特殊角的三角函数值求解 $A$。 步骤 1. 辅助角公式合并：将 $\sin A + \sqrt{3}\cos A$ 合并为 $2\sin\left(A+\frac{\pi}{3}\right)$。原等式即 $2\sin\left(A+\frac{\pi}{3}\right) = 2$。 2. 化简求解：得到 $\sin\left(A+\frac{\pi}{3}\right) = 1$。 3. 同角关系定角：因为 $A$ 为三角形内角，$A \in (0,\pi)$。那么 $A+\frac{\pi}{3} \in \left(\frac{\pi}{3}, \frac{4\pi}{3}\right)$。在此区间内，使得正弦值为1的角只有 $\frac{\pi}{2}$。 4. 得出结论：所以 $A+\frac{\pi}{3} = \frac{\pi}{2}$，解得 $A = \frac{\pi}{6}$。 点评/变式 本题将常规的“给值求角”问题嵌入到解三角形的情境中，并综合考查了辅助角公式。角范围的判定是本题的易错点，必须明确角 $A$ 是三角形内角这一隐含条件，并将合并后的角 $A+\frac{\pi}{3}$ 作为一个整体来研究其范围，最后根据特定区间内的正弦值确定唯一的角。该方法可推广至所有形如 $a\sin x + b\cos x = c$ 且已知角范围的问题。
