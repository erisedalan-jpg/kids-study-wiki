考点定位

  • 父主题：平面向量
  • 权重 weight：10
  • 真题数：2；年份跨度：2008–2008
  • 出现题位：填空13 解答22
  • 难度分布：易1 难1

知识精要

  • 向量的坐标运算：若 $\vec{a}=(x_1,y_1)$，$\vec{b}=(x_2,y_2)$，则 $\vec{a}+\vec{b}=(x_1+x_2, y_1+y_2)$，$\lambda \vec{a}=(\lambda x_1, \lambda y_1)$。
  • 向量共线（平行）的充要条件：
    • 几何形式：存在实数 $\lambda$，使得 $\vec{a} = \lambda \vec{b}$（$\vec{b} \neq \vec{0}$）。
    • 坐标形式（核心工具）：若 $\vec{a}=(x_1,y_1)$，$\vec{b}=(x_2,y_2)$，则 $\vec{a} \parallel \vec{b} \iff x_1y_2 - x_2y_1 = 0$。该条件源自向量夹角公式中 $\sin \theta = 0$ 的退化，等价于“交叉相乘差为零”。
  • 三点共线的向量推论：若 $\vec{AB} \parallel \vec{AC}$，则 $A,B,C$ 三点共线，其坐标满足 $(x_B-x_A)(y_C-y_A) - (x_C-x_A)(y_B-y_A)=0$。

解题方法与套路

处理向量共线问题的标准流程： 1. 向量坐标化：将题目中的向量关系转化为坐标运算。若已知点坐标，直接写出；若涉及未知参数，将其代入坐标表达式。 2. 线性运算化简：对含参向量进行加、减、数乘运算，整理成标准坐标形式 $(x,y)$。如已知 $\lambda \vec{a} + \vec{b}$，先分别计算坐标分量再合并。 3. 套用共线条件列方程：利用 $x_1y_2 - x_2y_1 = 0$ 建立关于参数 $\lambda$ 的方程。注意区分两个向量的横纵坐标，避免交叉相乘时错位。 4. 解方程求参：解一次方程得出参数值，若题目限定参数范围（如 $k>0$），需检验取舍。 5. 几何问题代数化（解析几何综合）：若共线条件隐含在直线与曲线交点中（如点 $D$ 在 $AB$ 上），设出直线方程并联立，利用韦达定理或向量关系建立坐标等式，最终转化为共线或坐标运算求解。

高频易错

  • 坐标加减错位：计算 $\lambda \vec{a}+\vec{b}$ 时，误将 $\vec{a}$ 的横纵坐标与 $\vec{b}$ 混淆，导致组合错误。应对：严格按“横+横、纵+纵”对齐书写。
  • 共线公式记忆混淆：
  • 错误写法：$x_1x_2 - y_1y_2 = 0$（此为垂直条件）或 $x_1y_1 - x_2y_2 = 0$。
  • 正确写法：$x_1y_2 - x_2y_1 = 0$。记忆口诀：“交叉相乘再相减，顺序别反符号对”。
  • 遗漏向量非零的隐含前提：使用几何形式 $a = \lambda b$ 时，必须注意分母向量不能为零向量。坐标形式 $x_1y_2 - x_2y_1 = 0$ 则无此限制，可大胆使用。
  • 解析几何中运算目标偏离：在椭圆等综合问题里，列出众多坐标方程后，未紧扣“向量共线”这一核心条件建立联系，转化为简单的坐标比例或乘积等式，导致复杂运算无果。

代表题精讲

题目1（2008-文-13）

设向量 $\vec{a}=(1,2)$，$\vec{b}=(2,3)$，若向量 $\lambda\vec{a}+\vec{b}$ 与向量 $\vec{c}=(-4,-7)$ 共线，则 $\lambda=$

思路：
本题给定向量的核心参数 $\lambda$，目标是利用“两向量共线则坐标交叉相乘相等”这一充要条件建立方程。解题路径清晰：先计算含参向量的坐标，再代入共线公式。

步骤：
1. 计算目标向量：
$\lambda\vec{a} + \vec{b} = \lambda(1,2) + (2,3)$
横坐标：$\lambda \times 1 + 2 = \lambda + 2$。
纵坐标：$\lambda \times 2 + 3 = 2\lambda + 3$。
所以新向量坐标为 $(\lambda+2, 2\lambda+3)$。 2. 利用共线条件列式：
与 $\vec{c}=(-4,-7)$ 共线，代入公式 $x_1y_2 - x_2y_1 = 0$：
$(\lambda+2)\times(-7) - (-4)\times(2\lambda+3) = 0$。 3. 解方程：
化简得 $-7\lambda -14 + 8\lambda +12 = 0$，即 $\lambda - 2 = 0$，解得 $\lambda=2$。

点评/变式：
这是向量共线最基础的考法，务必保证代数运算零失误。变式可改为“已知 $\vec{a}+\lambda\vec{b}$ 与 $\vec{c}$ 共线”，或与三点共线结合（如 $A,B,C$ 坐标含参，利用 $\vec{AB} \parallel \vec{AC}$ 求参），解题逻辑完全一致。

题目2（2008-文-22）

椭圆中心在原点，$A(2,0), B(0,1)$ 为顶点，直线 $y=kx(k>0)$ 与 $AB$ 交于 $D$，与椭圆交于 $E,F$。需结合向量关系求相关量或证明。

思路：
这是一道解析几何与向量结合的综合题。核心突破口在“$D$ 在 $AB$ 上”与“$A,B,D$ 共线”，可用向量共线定理建立 $D$ 点坐标的关系。同时 $D$ 也在 $y=kx$ 上，联立可解出 $D$ 坐标。进一步处理与椭圆交点 $E,F$ 时，可联立椭圆方程与直线方程，利用韦达定理得到两点坐标关系，再结合题目给定的向量条件（如 $AE, AF$ 的关系或 $ED, DF$ 的关系）列出方程，求解目标参数。

步骤： 1. 求 $D$ 点坐标：
直线 $AB$ 方程：$\frac{x}{2}+y=1$。点 $D$ 在 $y=kx$ 上，可设 $D(x_D, kx_D)$。
利用 $A,B,D$ 共线：$\vec{AD} = (x_D-2, kx_D)$，$\vec{AB}=(-2,1)$，由 $ \vec{AD} \parallel \vec{AB} $ 得：
$(x_D-2)\times 1 - (-2)\times kx_D = 0 \implies x_D - 2 + 2kx_D = 0$，解得 $x_D = \frac{2}{1+2k}$。
故 $D(\frac{2}{1+2k}, \frac{2k}{1+2k})$。 2. 处理椭圆与直线关系：
椭圆由顶点得 $a=2, b=1$，方程为 $\frac{x^2}{4} + y^2 = 1$。
联立 $\frac{x^2}{4} + (kx)^2 = 1$，可得交点 $E(x_1, kx_1), F(x_2, kx_2)$。
由韦达定理：$x_1+x_2 = 0$，$x_1x_2 = -\frac{4}{1+4k^2}$。 3. 应用向量条件转化：
根据题目具体设问（如求证某比例、求 $k$ 值等），将几何关系转化为 $x_1, x_2, x_D$ 的等式。例如，若涉及长度比，利用共线的横纵坐标比相等，化为坐标的线性关系求解或证明。

点评/变式：
本题将向量共线作为解析几何中“设点、消参、列等式”的关键桥梁，避免了直接使用两点距离公式的复杂运算。精髓在于：几何位置关系 $\rightarrow$ 向量平行/共线 $\rightarrow$ 坐标的一次方程。变式常表现为求直线斜率、定点坐标或证明定值，反复操练“共线条件”与“韦达定理”的联合应用是破局关键。
