知识精要

  • 向量加法的坐标运算：若 $\vec{a}=(x_1, y_1)$，$\vec{b}=(x_2, y_2)$，则 $\vec{a}+\vec{b}=(x_1+x_2, y_1+y_2)$。
    适用条件：向量以坐标形式给出，直接对应分量相加。
  • 数乘向量的坐标运算：若 $\lambda \in \mathbb{R}$，则 $\lambda \vec{a} = (\lambda x_1, \lambda y_1)$。
  • 数量积的坐标运算：$\vec{a} \cdot \vec{b} = x_1 x_2 + y_1 y_2$，其结果是一个实数。
  • 混合运算顺序：先做数乘和加法（属于线性运算），再算数量积。若有括号，优先括号内的向量和、差。

  5. 验证与估算
    对于选择题，算出具体数值后快速检查符号和量级，避免低级计算错误。

高频易错

  • 混淆向量加法和数量积的坐标公式：向量加法是横坐标相加、纵坐标相加，数量积是横坐标乘积加纵坐标乘积，两者不可记混。
  • 忽略 $\lambda=0$ 或负数的细节：数乘时符号变化导致方向反转，坐标对应成倍变化。
  • 计算粗心：先求 $2\vec{a}+\vec{b}$ 时，忘记数量积是两个向量点乘，错误地将中间过程的坐标直接作为最终答案（如误认为结果还是向量）。
  • 坐标对应错位：尤其当向量含负数时，容易写错 $x_1 x_2 + y_1 y_2$ 的正负号。

代表题精讲

题目（2015·文·04）
已知向量 $\vec{a}=(1, -1)$，$\vec{b}=(-1, 2)$，求 $(2\vec{a}+\vec{b})\cdot\vec{a}$ 的值。

思路
本题是坐标形式下向量线性运算与数量积的混合。先根据向量的数乘与加法公式，求出 $2\vec{a}+\vec{b}$ 的具体坐标，得到一个新的向量，再将其与 $\vec{a}$ 作数量积。由于所有运算皆在整数坐标范围内，直接计算最为稳妥。

步骤
1. 计算 $2\vec{a}$：
$$2\vec{a} = 2(1, -1) = (2, -2)$$ 2. 计算 $2\vec{a}+\vec{b}$：
$$(2, -2) + (-1, 2) = (2+(-1), -2+2) = (1, 0)$$ 3. 计算 $(2\vec{a}+\vec{b})\cdot\vec{a}$：
$$(1, 0) \cdot (1, -1) = 1\times1 + 0\times(-1) = 1$$ 4. 对应选项，选 C。

点评/变式
- 点评：本题属于基础题，考查向量坐标运算的两条基本路线：线性组合（加、数乘）与数量积。先组合再点乘的流程清晰，务必分步书写，减少跳步出错。
- 变式一（交换点乘对象）：若把问题改成 $(2\vec{a}+\vec{b})\cdot\vec{b}$，则结果为 $(1,0)\cdot(-1,2)=-1$，体会同一线性组合与不同向量点积导致结果符号相反。
- 变式二（加入实数倍）：求 $(3\vec{a}-2\vec{b})\cdot(\vec{a}+\vec{b})$，也应先分别求出两个括号内向量的坐标，再作数量积，方法完全一致。
- 变式三（抽象化）：若已知 $|\vec{a}+\vec{b}|$ 和 $|\vec{a}|,|\vec{b}|$ 及夹角，展开 $(2\vec{a}+\vec{b})\cdot\vec{a} = 2\vec{a}^2 + \vec{a}\cdot\vec{b}$，用模长与夹角代入计算，可体会坐标法与基底展开法的联系。
