向量法求空间角

知识精要

  • 异面直线所成角：过空间一点作两条异面直线的平行线，所成的锐角或直角。范围 $\theta \in \left(0,\frac{\pi}{2}\right]$。
  • 向量法求角：
  • 设两异面直线的方向向量分别为 $\boldsymbol{a}, \boldsymbol{b}$，则异面直线所成角 $\theta$ 满足 $$\cos\theta = |\cos\langle\boldsymbol{a}, \boldsymbol{b}\rangle| = \frac{|\boldsymbol{a}\cdot\boldsymbol{b}|}{|\boldsymbol{a}||\boldsymbol{b}|}.$$
  • 由 $\sin\theta = \sqrt{1-\cos^2\theta}$ 可求正弦，$\tan\theta = \frac{\sin\theta}{\cos\theta}$ 可求正切。
  • 建系原则：优先选择三条两两垂直的棱作为坐标轴，如正方体、长方体中有直角的顶点为原点。用坐标表示关键点，写出方向向量。

解题方法与套路

  1. 合理建系：找出（或作）空间中的两两垂直直线，以交点为原点建立空间直角坐标系。几何体棱长可设具体值（如2）或1。
  2. 写出点的坐标：根据几何条件，求出每条异面直线上两个不重合点的坐标，端点通常取已知顶点。
  3. 求方向向量：利用终点减起点坐标，得到两异面直线的方向向量。
  4. 套用夹角公式：计算 $\cos\theta = \frac{|\boldsymbol{a}\cdot\boldsymbol{b}|}{|\boldsymbol{a}||\boldsymbol{b}|}$，注意绝对值保证锐角。
  5. 求目标三角函数：按题意需求计算 $\sin\theta$ 或 $\tan\theta$。常用 $\sin\theta = \sqrt{1-\cos^2\theta}$，$\tan\theta = \frac{\sin\theta}{\cos\theta}$。

高频易错

  • 忽略线线角范围：直接用向量夹角可能得到钝角余弦，忘记取绝对值，导致余弦为负。
  • 坐标符号与长度设值错误：建系后点的坐标易写反或漏写 $z$ 坐标，设棱长不统一。
  • 方向向量终点选取不当：异面直线 $AE$ 与 $CD$，$AE$ 方向向量应为 $\overrightarrow{AE}$ 或 $\overrightarrow{EA}$，$CD$ 方向向量 $\overrightarrow{CD}$ 或 $\overrightarrow{DC}$，不要混用端点导致反向含混（但取绝对值影响不大，但仍需小心）。
  • 正切求法跳步：直接由 $\cos\theta$ 心算 $\tan\theta$ 时易出错，务必先求 $\sin\theta$ 再用比值，或使用 $\tan\theta = \frac{\sqrt{|\boldsymbol{a}|^2|\boldsymbol{b}|^2 - (\boldsymbol{a}\cdot\boldsymbol{b})^2}}{|\boldsymbol{a}\cdot\boldsymbol{b}|}$ 直接计算。

代表题精讲

题目
在正方体 $ABCD-A_1B_1C_1D_1$ 中，$E$ 为棱 $CC_1$ 的中点，求异面直线 $AE$ 与 $CD$ 所成角的正切值。

思路
正方体天然具备三垂直条件，以 $D$ 为原点，$DA$, $DC$, $DD_1$ 分别为 $x$, $y$, $z$ 轴建系。设棱长为2方便计算中点坐标。求方向向量 $\overrightarrow{AE}$ 与 $\overrightarrow{CD}$，使用异面直线夹角余弦公式，得 $\cos\theta$，再求 $\sin\theta$ 和 $\tan\theta$。

步骤
1. 以 $D$ 为原点，$DA$ 为 $x$ 轴，$DC$ 为 $y$ 轴，$DD_1$ 为 $z$ 轴建立空间直角坐标系。
2. 设正方体棱长为 $2$，得 $A(2,0,0)$, $C(0,2,0)$, $D(0,0,0)$, $C_1(0,2,2)$，则 $E$ 为 $CC_1$ 中点：$E(0,2,1)$。
3. $\overrightarrow{AE} = (-2, 2, 1)$；$\overrightarrow{CD} = (0, -2, 0)$（或 $\overrightarrow{DC} = (0,2,0)$，取绝对值后无影响）。
4. 计算数量积：$\overrightarrow{AE}\cdot\overrightarrow{CD} = (-2)\times0 + 2\times(-2) + 1\times0 = -4$，$|\overrightarrow{AE}| = \sqrt{(-2)^2+2^2+1^2}=3$，$|\overrightarrow{CD}|=2$。
5. $\cos\theta = \frac{|-4|}{3\times2} = \frac{2}{3}$，$\sin\theta = \sqrt{1-\left(\frac{2}{3}\right)^2} = \frac{\sqrt{5}}{3}$。
6. $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{\sqrt{5}/3}{2/3} = \frac{\sqrt{5}}{2}$。

点评/变式
本题是向量法求基本空间角的典型模式，关键步骤为建系设点→方向向量→夹角公式→三角转化。若题干改为求 $AE$ 与 $CD$ 所成角的正弦值，则直接给出 $\frac{\sqrt{5}}{3}$。若几何体变为长方体或棱柱时，只要存在三垂直，同样可用此法。注意在非正方体中棱长需设不同参数，计算稍复杂但套路不变。
