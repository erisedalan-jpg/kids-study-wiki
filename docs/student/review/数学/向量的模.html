向量的模

  • 权重 weight：7

知识精要

  • 向量的模：向量 $\vec{a}$ 的长度，记为 $|\vec{a}|$. 若 $\vec{a}=(x,y)$，则 $|\vec{a}|=\sqrt{x^2+y^2}$.
  • 模的平方：$|\vec{a}|^2=\vec{a}\cdot\vec{a}=\vec{a}^2$.
  • 数量积与模的关系：
  • $|\vec{a}\pm\vec{b}|^2=|\vec{a}|^2\pm 2\vec{a}\cdot\vec{b}+|\vec{b}|^2$（模长平方公式）.
  • $\vec{a}\cdot\vec{b}=\frac{1}{2}(|\vec{a}+\vec{b}|^2-|\vec{a}|^2-|\vec{b}|^2)$.
  • 垂直与模：若 $\vec{a}\perp\vec{b}$，则 $\vec{a}\cdot\vec{b}=0$，且 $|\vec{a}+\vec{b}|^2=|\vec{a}|^2+|\vec{b}|^2=|\vec{a}-\vec{b}|^2$.
  • 模相等与垂直：非零向量 $\vec{a},\vec{b}$ 满足 $|\vec{a}+\vec{b}|=|\vec{a}-\vec{b}| \Leftrightarrow \vec{a}\perp\vec{b}$.
  • 模的非负性：$|\vec{a}|\ge 0$，且 $|\vec{a}|=0 \Leftrightarrow \vec{a}=\vec{0}$.

解题方法与套路

  1. 平方转化法：求向量的模或数量积时，首选对等式两边平方，将模转化为数量积运算，利用 $\vec{a}^2=|\vec{a}|^2$ 建立方程。
  2. 垂直条件的利用：出现 $(\vec{b}-2\vec{a})\perp\vec{b}$ 等条件，立即转化为 $(\vec{b}-2\vec{a})\cdot\vec{b}=0$，展开得到模与数量积的关系。
  3. 已知和差模求数量积：若已知 $|\vec{a}+\vec{b}|$ 和 $|\vec{a}-\vec{b}|$，可分别平方后相加或相减，直接求出 $|\vec{a}|^2+|\vec{b}|^2$ 或 $\vec{a}\cdot\vec{b}$。
  4. 向量换元法：设 $\vec{c}=\vec{a}-\vec{b}$，将原条件用 $\vec{c}$ 和另一个向量表示，利用 $\vec{c}$ 的模已知，简化运算（如2023新课标Ⅱ法二）。
  5. 坐标代入法：已知向量的坐标时，直接计算线性运算后的向量坐标，再用 $\sqrt{x^2+y^2}$ 求模。
  6. 整体代换：在 $|\vec{a}+\vec{b}|$ 的平方式中，将 $\vec{a}\cdot\vec{b}$ 用已知的模或关系式整体代入，不解出每个量，直接求目标模。

高频易错

  • 平方展开漏项：$|\vec{a}\pm\vec{b}|^2=|\vec{a}|^2\pm 2\vec{a}\cdot\vec{b}+|\vec{b}|^2$，容易漏掉中间的 $\pm 2\vec{a}\cdot\vec{b}$，或符号写错。
  • 垂直与模长关系混淆：$|\vec{a}+\vec{b}|=|\vec{a}-\vec{b}|$ 等价于 $\vec{a}\perp\vec{b}$，但反过来 $\vec{a}\perp\vec{b}$ 时不仅模相等，还有勾股关系 $|\vec{a}\pm\vec{b}|^2=|\vec{a}|^2+|\vec{b}|^2$，不可随意给无垂直时使用。
  • 数量积与模平方运算混乱：把 $\vec{a}\cdot\vec{b}$ 和 $|\vec{a}||\vec{b}|$ 混同，错写 $|\vec{a}\cdot\vec{b}|$ 等等。数量积为实数，其自身的平方不等于模的平方。
  • 换元后忘记还原：使用 $\vec{c}=\vec{a}-\vec{b}$ 等方法求出 $|\vec{c}|$ 后，忘记代回原题要求，答非所问。
  • 坐标计算的算术错误：向量坐标加减时符号出错，或开方时忽略算术平方根，导致模计算出错。
  • 忽略非零向量的条件：垂直判定的推导中，必须在 $\vec{a},\vec{b}$ 为非零向量的前提下，否则 $\vec{a}\cdot\vec{b}=0$ 无法推出几何垂直。

代表题精讲

题目（2024新课标Ⅱ-03）

已知 $|\vec{a}|=1$，$|\vec{a}+2\vec{b}|=2$，且 $(\vec{b}-2\vec{a})\perp\vec{b}$，求 $|\vec{b}|$.

思路
由垂直得数量积方程，把 $\vec{a}\cdot\vec{b}$ 用 $|\vec{b}|^2$ 表示；再将 $|\vec{a}+2\vec{b}|=2$ 两边平方，代入 $|\vec{a}|$ 和 $\vec{a}\cdot\vec{b}$ 的表达式，解出 $|\vec{b}|^2$。

步骤
1. 由垂直：$(\vec{b}-2\vec{a})\cdot\vec{b}=0 \Rightarrow \vec{b}^2 - 2\vec{a}\cdot\vec{b}=0$，即 $2\vec{a}\cdot\vec{b}=|\vec{b}|^2$.
2. 将 $|\vec{a}+2\vec{b}|=2$ 平方：$|\vec{a}|^2 + 4\vec{a}\cdot\vec{b} + 4|\vec{b}|^2 = 4$.
3. 代入 $|\vec{a}|=1$ 和 $4\vec{a}\cdot\vec{b}=2\cdot(2\vec{a}\cdot\vec{b})=2|\vec{b}|^2$：
$1 + 2|\vec{b}|^2 + 4|\vec{b}|^2 = 4 \Rightarrow 6|\vec{b}|^2 = 3 \Rightarrow |\vec{b}|^2 = \frac{1}{2}$.
4. 故 $|\vec{b}|=\frac{\sqrt{2}}{2}$.

点评/变式
该题核心是将垂直条件数量积化，然后整体代入模平方公式，不需求出 $\vec{a}\cdot\vec{b}$ 的具体值。变式：把垂直改为已知 $\vec{a},\vec{b}$ 的夹角为 $60^\circ$，其他不变，同样方法可求 $|\vec{b}|$。

题目（2023新课标Ⅱ-13）

已知 $|\vec{a}-\vec{b}|=\sqrt{3}$，$|\vec{a}+\vec{b}|=|2\vec{a}-\vec{b}|$，求 $|\vec{b}|$.

思路
方法一：将第二个等式两边平方，化简得 $\vec{a}$ 与 $\vec{b}$ 的关系；再对第一个模条件平方，整体消元求 $|\vec{b}|$.
方法二：设 $\vec{c}=\vec{a}-\vec{b}$，用 $\vec{c}$ 表达 $\vec{a}+\vec{b}$ 和 $2\vec{a}-\vec{b}$，由模相等平方得到 $|\vec{c}|=|\vec{b}|$，直接得解。

步骤
法一
1. $|\vec{a}+\vec{b}|=|2\vec{a}-\vec{b}|$ 平方得：$|\vec{a}|^2+2\vec{a}\cdot\vec{b}+|\vec{b}|^2 = 4|\vec{a}|^2-4\vec{a}\cdot\vec{b}+|\vec{b}|^2$，
化简：$2\vec{a}\cdot\vec{b}=3|\vec{a}|^2-4\vec{a}\cdot\vec{b} \Rightarrow 6\vec{a}\cdot\vec{b}=3|\vec{a}|^2 \Rightarrow 2\vec{a}\cdot\vec{b}=|\vec{a}|^2$.
2. 对 $|\vec{a}-\vec{b}|=\sqrt{3}$ 平方：$|\vec{a}|^2 - 2\vec{a}\cdot\vec{b} + |\vec{b}|^2 = 3$.
代入 $2\vec{a}\cdot\vec{b}=|\vec{a}|^2$：$|\vec{a}|^2 - |\vec{a}|^2 + |\vec{b}|^2 = 3 \Rightarrow |\vec{b}|^2=3 \Rightarrow |\vec{b}|=\sqrt{3}$.

法二
1. 令 $\vec{c}=\vec{a}-\vec{b}$，则 $|\vec{c}|=\sqrt{3}$.
那么 $\vec{a}+\vec{b}=(\vec{a}-\vec{b})+2\vec{b}=\vec{c}+2\vec{b}$，
$2\vec{a}-\vec{b}=2(\vec{a}-\vec{b})+\vec{b}=2\vec{c}+\vec{b}$.
2. 条件 $|\vec{a}+\vec{b}|=|2\vec{a}-\vec{b}|$ 化为 $|\vec{c}+2\vec{b}|=|2\vec{c}+\vec{b}|$，平方：
$|\vec{c}|^2+4\vec{c}\cdot\vec{b}+4|\vec{b}|^2 = 4|\vec{c}|^2+4\vec{c}\cdot\vec{b}+|\vec{b}|^2$，
消去 $4\vec{c}\cdot\vec{b}$ 得 $3|\vec{b}|^2=3|\vec{c}|^2$，即 $|\vec{b}|=|\vec{c}|=\sqrt{3}$.

点评/变式
两种方法本质都是通过平方消去数量积，法二换元更简洁，避免了求 $\vec{a}\cdot\vec{b}$ 的过程。变式：把条件改为 $|\vec{a}+\vec{b}|=2|\vec{a}-\vec{b}|$ 和 $|\vec{a}|=2$，则可类似求出 $|\vec{b}|$ 与夹角的关系。
