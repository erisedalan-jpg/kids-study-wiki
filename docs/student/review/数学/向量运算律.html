向量运算律

考点向量运算律权重7真题数1学科数学父主题平面向量

考点定位

  • 父主题：平面向量
  • 权重 weight：7
  • 真题数：1；年份跨度：2023–2023
  • 出现题位：填空13
  • 难度分布：中1

知识精要

  • 向量运算律
  • 加法与减法：$\vec{a}+\vec{b}=\vec{b}+\vec{a}$（交换律），$(\vec{a}+\vec{b})+\vec{c}=\vec{a}+(\vec{b}+\vec{c})$（结合律），$\vec{a}-\vec{b}=\vec{a}+(-\vec{b})$.
  • 数乘：$\lambda(\mu \vec{a})=(\lambda\mu)\vec{a}$，$(\lambda+\mu)\vec{a}=\lambda\vec{a}+\mu\vec{a}$，$\lambda(\vec{a}+\vec{b})=\lambda\vec{a}+\lambda\vec{b}$.
  • 数量积：$\vec{a}\cdot\vec{b}=\vec{b}\cdot\vec{a}$（交换律），$(\lambda\vec{a})\cdot\vec{b}=\lambda(\vec{a}\cdot\vec{b})$，$(\vec{a}+\vec{b})\cdot\vec{c}=\vec{a}\cdot\vec{c}+\vec{b}\cdot\vec{c}$（分配律）.
  • 模与数量积的关系：$|\vec{a}|^2=\vec{a}^2=\vec{a}\cdot\vec{a}$，$|\vec{a}\pm\vec{b}|^2=|\vec{a}|^2\pm 2\vec{a}\cdot\vec{b}+|\vec{b}|^2$.
  • 适用条件：凡涉及向量模的等式或不等式，平方去掉模号，转化为数量积运算，是核心转化手段.

解题方法与套路

  1. 遇模则平方：从条件（或目标）中的模等式出发，两边同时平方，得 $|\cdot|^2 = (\cdot)^2$，将几何量转化为代数方程.
  2. 展开与化简：利用完全平方公式展开 $|\vec{a}\pm\vec{b}|^2$，移项合并，消去相同项，得到 $\vec{a}\cdot\vec{b}$ 或 $|\vec{a}|$ 与 $|\vec{b}|$ 的关系.
  3. 联立方程组：若题目给两个独立条件，分别平方后形成方程组，消去 $\vec{a}\cdot\vec{b}$ 或某一模，解出目标模.
  4. 换元简化（高阶）：当表达式中向量多次出现线性组合时，可设基底向量或构造新向量（如 $\vec{c}=\vec{a}-\vec{b}$），将条件转化为关于新向量的简洁关系，减少计算量.

高频易错

  • 平方漏项：误把 $|\vec{a}\pm\vec{b}|^2$ 写成 $|\vec{a}|^2+|\vec{b}|^2$，遗漏交叉项 $\pm 2\vec{a}\cdot\vec{b}$；或展开 $(m\vec{a}\pm n\vec{b})^2$ 时系数漏平方.
  • 符号错乱：移项或展开时忘记括号外负号导致计算结果反号，特别是在 $\vec{a}-\vec{b}$ 与 $\vec{b}-\vec{a}$ 切换时.
  • 向量与模混用：把 $|\vec{a}|$ 直接当作 $\vec{a}$ 参与数量积运算，或者将 $\vec{a}^2$ 误写成 $|\vec{a}|$（丢失平方）.
  • 换元不等价：引入新向量 $\vec{c}=p\vec{a}+q\vec{b}$ 后，未能正确反解原条件，导致关系式变形错误.
  • 结果忽略算术根：由 $\vec{b}^2=3$ 得出 $|\vec{b}|=\pm\sqrt{3}$，忘记模的非负性.

代表题精讲

题目
已知向量 $\vec{a}, \vec{b}$ 满足 $|\vec{a}-\vec{b}|=\sqrt{3}$，$|\vec{a}+\vec{b}|=|2\vec{a}-\vec{b}|$，则 $|\vec{b}|=$ ______.

思路
条件给出两组模的关系，直接套用“遇模则平方”策略，消去 $\vec{a}\cdot\vec{b}$ 即可求出 $|\vec{b}|$。也可通过设 $\vec{c}=\vec{a}-\vec{b}$ 将两个向量不等式重组为对称形式，减少变量.

步骤
法一（直接平方）
由 $|\vec{a}+\vec{b}|=|2\vec{a}-\vec{b}|$ 两边平方： $$(\vec{a}+\vec{b})^2 = (2\vec{a}-\vec{b})^2$$ $$\vec{a}^2+2\vec{a}\cdot\vec{b}+\vec{b}^2 = 4\vec{a}^2-4\vec{a}\cdot\vec{b}+\vec{b}^2$$ 移项得 $3\vec{a}^2 - 6\vec{a}\cdot\vec{b}=0$，即
$$\vec{a}^2 = 2\vec{a}\cdot\vec{b}$$
对 $|\vec{a}-\vec{b}|=\sqrt{3}$ 两边平方：
$$(\vec{a}-\vec{b})^2 = 3 \implies \vec{a}^2 - 2\vec{a}\cdot\vec{b} + \vec{b}^2 = 3$$
将 $\vec{a}^2 = 2\vec{a}\cdot\vec{b}$ 代入，得 $\vec{b}^2 = 3$，故 $|\vec{b}|=\sqrt{3}$.

法二（换元）
令 $\vec{c} = \vec{a} - \vec{b}$，则 $\vec{a}+\vec{b} = \vec{c}+2\vec{b}$，$2\vec{a}-\vec{b} = 2\vec{c}+\vec{b}$.
已知条件化为 $|\vec{c}+2\vec{b}| = |2\vec{c}+\vec{b}|$，且 $|\vec{c}|=\sqrt{3}$.
对模等式平方：
$$(\vec{c}+2\vec{b})^2 = (2\vec{c}+\vec{b})^2$$ $$\vec{c}^2 + 4\vec{c}\cdot\vec{b} + 4\vec{b}^2 = 4\vec{c}^2 + 4\vec{c}\cdot\vec{b} + \vec{b}^2$$ $$\vec{c}^2 + 4\vec{b}^2 = 4\vec{c}^2 + \vec{b}^2 \implies 3\vec{b}^2 = 3\vec{c}^2 \implies |\vec{b}|^2 = |\vec{c}|^2$$ 于是 $|\vec{b}| = |\vec{c}| = \sqrt{3}$.

点评/变式
本题核心为“模平方”的熟练运用，法二通过换元将原式变化为完全对称的形式，避免解方程组，计算量更小。注意两点：平方展开后常数项不能忘，模开方只得正值。
变式：将条件改为 $|\vec{a}+\vec{b}|=|\vec{a}-\vec{b}|$，则推出 $\vec{a}\perp\vec{b}$；若已知 $|\vec{a}|=1$，$|\vec{b}|=2$，$|\vec{a}+\vec{b}|=\sqrt{7}$，则可反求 $\vec{a}\cdot\vec{b}$ 或夹角——方法同理。
