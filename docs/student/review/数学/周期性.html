周期性

考点周期性权重6真题数5学科数学父主题函数与导数

考点定位

  • 父主题：函数与导数
  • 权重 weight：6
  • 真题数：5；年份跨度：2014–2022
  • 出现题位：填空15 选择9 选择11 选择12
  • 难度分布：中4 易1

知识精要

  • 周期定义：若存在非零常数 $T$，使 $f(x+T)=f(x)$ 对定义域内任意 $x$ 恒成立，则 $T$ 为 $f(x)$ 的周期。最小正周期是其中最小的正数。
  • 三角函数周期：
  • $y=A\sin(\omega x+\varphi)+B$ 及 $y=A\cos(\omega x+\varphi)+B$ 的最小正周期 $T=\frac{2\pi}{|\omega|}$（$\omega \neq 0$）。
  • $y=|\sin(\omega x+\varphi)|$ 及 $y=|\cos(\omega x+\varphi)|$ 的周期变为原周期的一半，即 $T=\frac{\pi}{|\omega|}$。$$y=\cos|x|=\cos x$$，周期仍为 $2\pi$ ；$y=\sin|x|$ 不是周期函数。
  • 抽象函数对称性与周期性（设 $f(x)$ 定义域为 $\mathbb{R}$）：
  • 双对称推周期：
    • 若 $f(x)$ 关于两条直线 $x=a$ 与 $x=b$ 对称 ($a \neq b$)，则 $T=2|a-b|$。
    • 若 $f(x)$ 关于点 $(a,0)$ 与直线 $x=b$ 对称 ($a \neq b$)，则 $T=4|a-b|$。
  • 一个等式推周期：
    • 若 $f(x+a)=f(x+b)$，则 $T=|a-b|$。
    • 若 $f(x+a)=-f(x)$ 或 $f(x+a)=\frac{1}{f(x)}$ 或 $f(x+a)=-\frac{1}{f(x)}$，则 $T=2a$。
  • 奇偶性与对称性结合推周期：
    • $f(x)$ 为奇函数且关于 $x=a$ 对称 $\Rightarrow$ $T=4a$。
    • $f(x)$ 为偶函数且关于 $x=a$ 对称 $\Rightarrow$ $T=2a$。

解题方法与套路

  1. 三角型周期显式求解法：
  2. 将已知函数化为标准三角函数型或带绝对值的三角函数型。
  3. 代入条件（如函数值、零点）建立关于 $\omega$ 的方程，结合 $\omega$ 的范围求最值或取值。注意 $\omega$ 与周期的关系 $T=\frac{2\pi}{\omega}$。
  4. 数形结合辨识法（适用于选择填空题快速判断）：
  5. 对于含绝对值的三角函数，可用几何画板或草图勾勒图像趋势。
  6. 直接观察重复单元宽度锁定周期，对照选项验证给定区间单调性。
  7. 抽象函数递推求值法（适用于构造周期性求和）：
  8. 第一步：利用给出的对称性或奇偶性等式，进行迭代代换。常用手段：将 $x$ 替换为 $x+1$、$x-1$ 等，消去中间项，推出 $f(x+T)=f(x)$ 的形式，求出周期 $T$。
  9. 第二步：利用奇偶性，计算一个周期内各整数点的函数值（常利用 $f(0)=0$ 或对称轴函数值）。
  10. 第三步：将所求长数列和拆分成若干个完整周期加余项，利用周期性化简求和。

高频易错

  • 三角参数范围易漏：涉及 $f(x)=A\cos(\omega x+\varphi)$ 求 $\omega$ 最小值时，零点表达式 $\omega x + \varphi = \frac{\pi}{2}+k\pi$ 中 $k \in \mathbb{Z}$ 不可遗漏或写错；求出的 $\omega$ 表达式如 $\omega=3+9k$ 需取满足 $\omega>0$ 的最小正值。
  • 混淆 $f(1-x)=f(1+x)$ 的双重性质：该式不仅表明函数关于 $x=1$ 轴对称，更关键的是结合奇偶性可导出 $f(x+2)=-f(x)$ 进而得到 $T=4$。切勿直接误判周期为 $2$。
  • 绝对值的贸然应用：
  • $y=\sin|x|$ 和 $y=\cos|x|$ 的性质差异巨大。$\cos|x| = \cos x$ 仍是周期函数；$\sin|x|$ 破坏了奇变规律，不再是周期函数，不可强行套用绝对值对原周期减半的结论。
  • $y=|\sin x|$ 与 $y=\sin|x|$ 分属不同概念，注意绝对值加在变量 $x$ 上还是整体函数值上。
  • 求和时忽略头尾：计算 $f(1)+f(2)+...+f(50)$ 这种非完整周期个数的和时，别忘记处理余项（例如前 $48$ 项是周期组合，最后单独加工第 $49$ 和第 $50$ 项）。

代表题精讲

题目 2018-理-11：已知 $f(x)$ 是定义在 $\mathbb{R}$ 上的奇函数，满足 $f(1-x)=f(1+x)$，若 $f(1)=2$，求 $f(1)+f(2)+...+f(50)$ 的值。 思路 先由等式推出 $f(x+2)=-f(x)$，得周期 $T=4$。再由奇函数求出一个周期内各整数点函数值，最后分组求和。 步骤 1. 因为 $f(x)$ 是奇函数，且 $f(1-x)=f(1+x)$，所以 $f(1+x) = f(1-x) = -f(x-1)$。 2. 令 $t=x+1$，则 $x-1=t-2$，上式变为 $f(t) = -f(t-2)$，即 $f(x+2)=-f(x)$。 3. 由 $f(x+2) = -f(x)$ 得 $f(x+4) = -f(x+2) = f(x)$，故周期 $T=4$。 4. 计算一个周期内的值：$f(1)=2$，$f(2)=f(0)=0$，$f(3)=f(1-2)=f(-1)=-f(1)=-2$，$f(4)=f(0)=0$。 5. 求和：前 $48$ 项为 $12$ 个完整周期，和为 $0$。总合 $=0 + f(49) + f(50) = f(1) + f(2) = 2+0 = 2$。 点评/变式 抽象函数求值必抓“周期性”和“整数点函数值”两步。变式：若条件改为 $f(x)$ 为偶函数，$f(1+x)=f(1-x)$，则可推出 $T=2$，结果将截然不同。

题目 2022-理-15：已知 $f(x)=\cos(\omega x+\varphi)$，$\omega>0, 0<\varphi<\pi$，最小正周期 $T$，$f(T)=\frac{\sqrt{3}}{2}$，$x=\frac{\pi}{9}$ 为零点，求 $\omega$ 最小值。 思路 直接使用 $T=\frac{2\pi}{\omega}$ 代入函数值方程求 $\varphi$，再用零点方程求 $\omega$ 的通式，结合限制条件取最小正值。 步骤 1. 周期 $T=\frac{2\pi}{\omega}$，则 $f(T)=\cos(2\pi+\varphi)=\cos\varphi=\frac{\sqrt{3}}{2}$。 2. 由 $0<\varphi<\pi$ 得 $\varphi=\frac{\pi}{6}$。 3. $x=\frac{\pi}{9}$ 是零点 $\Rightarrow \cos(\frac{\pi}{9}\omega + \frac{\pi}{6}) = 0$。则 $\frac{\pi}{9}\omega + \frac{\pi}{6} = \frac{\pi}{2} + k\pi$ ($k \in \mathbb{Z}$)。 4. 解得 $\omega = 3 + 9k$。因为 $\omega>0$，当 $k=0$ 时取最小正数 $\omega=3$。 点评/变式 三角函数含参求最值，本质是解三角方程。易错点在于零点方程写作 $\frac{\pi}{2} + 2k\pi$ 漏解。同时务必检验求出的参数是否满足周期的定义范围。

题目 2019-理-09：下列以 $\frac{\pi}{2}$ 为周期且在 $(\frac{\pi}{4}, \frac{\pi}{2})$ 上单调递增的是：A. $|\cos 2x|$ B. $|\sin 2x|$ C. $\cos|x|$ D. $\sin|x|$ 思路 逐项分析周期后锁定 A 或 B（CD周期不合格或非周期函数），再代入区间验证 A、B的单调性。 步骤 1. D项 $\sin|x|$ 不是周期函数，排除。 2. C项 $\cos|x| = \cos x$，周期 $T=2\pi$，排除。 3. A项 $f(x)=|\cos 2x|$，$\omega=2$，周期 $T=\frac{\pi}{2}$。$x \in (\frac{\pi}{4}, \frac{\pi}{2})$ 时 $2x \in (\frac{\pi}{2}, \pi)$，此区间 $\cos 2x<0$，故 $|\cos 2x| = -\cos 2x$。$-\cos 2x$ 在 $(\frac{\pi}{2}, \pi)$ 上单调递增，故 A 正确。 4. B项 $f(x)=|\sin 2x|$，周期也是 $\frac{\pi}{2}$，但 $x \in (\frac{\pi}{4}, \frac{\pi}{2})$ 时，$\sin 2x$ 从极大值点向零点递减，单调性不合，排除。 点评/变式 此类题应优先扫除“绝对假周期”选项，过长的周期或不周期项直接排除，缩小包围圈，最后用区间单调性一锤定音。熟记 $y=|\sin \omega x|$ 与 $y=|\cos \omega x|$ 的翻折图像是关键。
