周期数列

考点周期数列权重12真题数1学科数学父主题数列

考点定位

  • 父主题：数列
  • 权重 weight：12
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：填空16
  • 难度分布：易1

知识精要

  • 周期数列：对于数列 ${a_n}$，若存在正整数 $T$ 使得对任意 $n \in \mathbb{N}^$ 都有 $a_{n+T}=a_n$ 恒成立，则称 ${a_n}$ 为周期数列，$T$ 为一个周期。能使上式成立的最小正整数称为最小正周期*（本文简称为周期）。
  • 递推产生周期的常见形式：
  • 分式递推 $a_{n+1} = \frac{A a_n + B}{C a_n + D}$（$AD - BC \neq 0$），在一定条件下经过若干次迭代后可回到初始值，形成周期性。特别地，型如 $a_{n+1} = \frac{1 + a_n}{1 - a_n}$，周期 $T=3$；$a_{n+1} = -\frac{1}{a_n}$ 或 $a_{n+1} = \frac{1}{1 - a_n}$ 等也常见 3 周期或 2 周期。
  • 分段递推中，取倒数、取负等操作也可能诱导短周期。
  • 差分方程或函数不变性引发的周期现象。
  • 判定与求值依据：
  • 若由递推关系能推出 $a_{n+T}=a_n$，则数列是周期的，可利用周期性将远距离下标“拉回”已知范围内的项。
  • 对于具体项的计算，先利用给定的某一项（或前几项）和递推式依次计算前后项，直到出现重复值（首次与前面某一项相等），即可确定周期长度和循环节，再通过带余除法求出任意项的值。
  • 注意周期的起点不一定从 $a_1$ 开始，有时需从已知项逆推至目标项。

解题方法与套路

处理“给定复杂递推式，给出某项求远方项”问题，标准流程：

  1. 代入具体值求连续项：从已知项出发，反复利用递推式计算相邻若干项，通常求 $6 \sim 10$ 项即可看出重复模式。计算时注意每一步的代数化简，避免繁分式错误。
  2. 观察找出循环节：当出现 $a_{m}=a_{k}$（$m > k$）时，可确定从 $k$ 项起开始循环，一个周期内的项依次列出。确定周期 $T = m - k$ 以及循环节内容（如 $2, \frac12, -1$）。
  3. 利用带余除法定位：欲求 $a_n$，若循环从 $a_p$ 开始，周期为 $T$，则先计算 $n - p$，除以 $T$，余数 $r$ 决定 $a_n$ 对应循环节中的位置：$a_n = a_{p + r}$（当 $r=0$ 时取 $a_{p+T-1}$ 或按节末处理）。若已知项在循环节内部（即下标跨度不足一圈），可直接反向递推或依循环节顺推。
  4. 逆推技巧：若已知项在目标项之后，可将递推关系反解为 $a_n = f^{-1}(a_{n+1})$，然后逆向代入。对于分式递推，反解往往容易。若发现周期结构，亦可依周期“平移”回目标项，避免逐一代入。

通用口诀：连续算、找重复、定周期、带余除。

高频易错

  • 递推式中的下标理解混乱：题目给出 $a_{n+1}=g(a_n)$，代入 $n$ 的具体数值时应严格：$a_8=g(a_7)$，$a_7=g(a_6)$，顺序不能颠倒。容易出现“已知 $a_8$ 去求 $a_7$”时不会反解递推式，或者直接用正递推公式代入此时 $n=8$ 错误计算出 $a_9$。
  • 周期起点的误判：并非所有数列都从 $a_1$ 进入周期，若根据已知项求出的循环是从 $a_3$ 开始的，则 $a_1,a_2$ 可能不在稳定循环节内，这时认为周期对任意项都成立就会犯错。必须验证从第几项起进入周期，或从已知项向回推验证。
  • 代数化简失误：分式递推 $a_{n+1} = \frac{1+a_n}{1-a_n}$ 这类形式，计算时若忘记将带分数转化为假分数、符号错误或约分失误，会导致后续项全部错误，从而找不到正确周期。应分步计算并保留最简有理数或根式。
  • 余数分界点错误：设循环节为 $b_1,b_2,\dots,b_T$，若 $a_k$ 对应 $b_1$，则 $a_{k+m}$ 对应 $b_{1+(m \bmod T)}$（当余数为 $0$ 时对应 $b_T$）。常见错法是周期3下的余数对应错误，如 $8 \div 3 = 2 \cdots 2$ 时，误将余数2对应循环节中的第2项，但首项下标可能不匹配。需根据实际算出的项标对应关系，不可死记公式。
  • 递推式定义域疏忽：分式分母不能为零，因此某些项可能使递推式无定义。即使计算中未碰到禁止值，也应在得到结果后回头检查数列各项是否均有意义（本题中 $a_n \neq 1$ 恒成立，无需额外排除）。

代表题精讲

题目

（2014·全国卷文科第16题）已知数列 ${a_n}$ 满足 $a_{n+1} = \frac{1 + a_n}{1 - a_n}$，且 $a_8 = 2$，求 $a_1$ 的值。

思路

本题给出分式递推和较远的第8项，直接正向求 $a_1$ 需要逆向递推7次，计算量大且易错。可尝试从已知项逆推几步并寻找规律，观察是否出现周期性，然后借助周期将下标为1的项与已知项建立联系，快速求解。

步骤

  1. 反解递推关系
    由 $a_{n+1} = \frac{1 + a_n}{1 - a_n}$，反解 $a_n$ 得： $$ a_n = \frac{a_{n+1} - 1}{a_{n+1} + 1}. $$
  2. 逆向计算连续项
    已知 $a_8 = 2$，
  3. $n = 8$ 反推 $a_7$：$a_7 = \frac{a_8 - 1}{a_8 + 1} = \frac{2 - 1}{2 + 1} = \frac13$;
  4. $n = 7$ 反推 $a_6$：$a_6 = \frac{a_7 - 1}{a_7 + 1} = \frac{\frac13 - 1}{\frac13 + 1} = \frac{-\frac23}{\frac43} = -\frac12$;
  5. $n = 6$ 反推 $a_5$：$a_5 = \frac{a_6 - 1}{a_6 + 1} = \frac{-\frac12 - 1}{-\frac12 + 1} = \frac{-\frac32}{\frac12} = -3$;
    继续反推：
  6. $a_4 = \frac{a_5 - 1}{a_5 + 1} = \frac{-3 - 1}{-3 + 1} = \frac{-4}{-2} = 2$。
  7. 发现周期
    算得 $a_4 = 2$，与 $a_8 = 2$ 相同，且下标差 $8 - 4 = 4$？进一步检查连续值变化：从 $a_4=2$ 起，正向递推：$a_5 = \frac{1+2}{1-2} = -3$（与反推结果一致），$a_6 = \frac{1-3}{1+3} = -\frac12$，$a_7 = \frac{1-\frac12}{1+\frac12} = \frac13$，$a_8 = \frac{1+\frac13}{1-\frac13} = 2$。可见从 $a_4$ 开始，数列呈现 $2, -3, -\frac12, \frac13, 2, \dots$ 的循环？但题设周期常判定为 $2, \frac13, -\frac12$ 出现？实际上反推时得到了 $a_7=\frac13$，而正向从 $a_5=-3$ 得到 $a_6=-\frac12$, $a_7=\frac13$, $a_8=2$。若将 $a_5, a_6, a_7, a_8$ 列出：$-3, -\frac12, \frac13, 2$，这与 $2, \frac13, -\frac12$ 不同？重新审视代数运算：
