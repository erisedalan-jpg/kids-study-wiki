商数关系

知识精要

同角三角函数的基本关系中，商数关系为核心纽带：

  • $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$（$\alpha \neq \frac{\pi}{2}+k\pi, k\in\mathbb{Z}$）
  • $\cot\alpha = \frac{\cos\alpha}{\sin\alpha}$（$\alpha \neq k\pi, k\in\mathbb{Z}$）

上述关系直接建立正弦与余弦的比值，与平方关系 $\sin^2\alpha+\cos^2\alpha=1$ 联合，可由比值求具体三角函数值。由商数关系可得 $\sin\alpha = \tan\alpha \cdot \cos\alpha$，或设比例因子：若 $\frac{\sin\alpha}{\cos\alpha}= \frac{a}{b}$，可令 $\sin\alpha = ak$，$\cos\alpha = bk$，代入平方关系解 $k$，再根据象限定符号。特别注意：三角形内角范围为 $(0,\pi)$，锐角三角函数值全正，钝角余弦为负、正弦为正，结合商数符号可定角类型。

解题方法与套路

  1. 定号：根据已知商数值的正负及角度范围，锁定目标三角函数的符号（可直接排除选择题中的干扰项）。
  2. 列比例：将条件给出的 $\tan\alpha$ 或 $\cot\alpha$ 写成 $\frac{\sin\alpha}{\cos\alpha}$ 的形式，知一求一联用。
  3. 设参或直代：
  4. 方法一：设 $\sin\alpha = ak$，$\cos\alpha = bk$（其中 $\frac{a}{b}$ 为已知比值的最简形式，含符号），代入 $\sin^2\alpha+\cos^2\alpha=1$ 求 $k$，回代得值。
  5. 方法二：直接利用恒等式 $\cos^2\alpha = \frac{1}{1+\tan^2\alpha}$ 或 $\sin^2\alpha = \frac{\tan^2\alpha}{1+\tan^2\alpha}$（余切同理），开方后配符号。
  6. 检验：将结果代回原式或平方关系，确认无运算错误。

高频易错

  • 忽略角范围致符号错：如条件给出 $\cot A<0$ 且 $A\in(0,\pi)$，未推出 $A$ 为钝角，导致 $\cos A$ 取正号。
  • 比例设参时忘记携带符号：$\cot A=-\frac{12}{5}$ 应设 $\cos A = -12k$，$\sin A = 5k$（$k>0$），若漏写负号会得正值错解。
  • 商数关系倒置：混淆 $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$ 和 $\cot\alpha = \frac{\cos\alpha}{\sin\alpha}$，代值时分子分母颠倒。
  • 开方忘记加绝对值：由 $\cos^2\alpha = \frac{1}{1+\tan^2\alpha}$ 开方得 $|\cos\alpha|$，必须结合象限去绝对值符号。
  • 三角形限制条件遗漏：在 $\triangle ABC$ 中角度范围 $0^\circ<A<180^\circ$，但某些学生误用锐角三角函数处理所有内角。

代表题精讲

代表题 2009-理-03

题目：已知 $\triangle ABC$ 中，$\cot A = -\frac{12}{5}$，则 $\cos A =$ ( )
A. $\frac{12}{13}$　B. $\frac{5}{13}$　C. $-\frac{5}{13}$　D. $-\frac{12}{13}$

思路：由 $\cot A$ 负号知 $A$ 为钝角，$\cos A<0$，可直接排除 A、B 两正选项。再将商数关系与平方关系联立，设比例系数或直接利用恒等式求值。

步骤：
1. 因 $A\in(0,\pi)$ 且 $\cot A = \frac{\cos A}{\sin A} = -\frac{12}{5}<0$，说明 $\cos A$ 与 $\sin A$ 异号，又 $\sin A>0$，故 $\cos A<0$，排除 A、B。
2. 由商数关系得 $\frac{\cos A}{\sin A} = -\frac{12}{5}$，设 $\cos A = -12k$，$\sin A = 5k$（$k>0$）。
3. 代入平方关系：$(-12k)^2 + (5k)^2 = 1 \Rightarrow 144k^2 + 25k^2 = 169k^2 = 1$，解得 $k = \frac{1}{13}$。
4. 则 $\cos A = -12 \times \frac{1}{13} = -\frac{12}{13}$，选出 D。

点评/变式：此题巧用符号排除缩小选择范围。设比例系数 $k$ 可避免分式运算，是处理“已知比值求值”的通用高效方法。
变式：若已知 $\tan\alpha = -\frac{3}{4}$ 且 $\alpha$ 为第二象限角，求 $\sin\alpha$ 与 $\cos\alpha$ 的值。（提示：设 $\sin\alpha = 3k,\ \cos\alpha = -4k$，注意符号与象限匹配。）
