知识精要

  • 四点共圆的判定定理（常考核心）
  • 对角互补：若四边形一组对角之和为 $180^\circ$，则四点共圆。
  • 外角等于内对角：若四边形的一个外角等于它的内对角，则四点共圆。
  • 同侧张角相等：若两个点在一条线段同侧，且对该线段所张的角相等，则这两点与线段两端点四点共圆（圆周角定理逆定理）。
  • 圆幂定理的逆用：若两线段交于一点，满足 $PA\cdot PB=PC\cdot PD$（相交弦逆定理）或割线比例关系，可证四点共圆（多在综合性推理中作为桥梁）。
  • 四点共圆的性质（常用于求解）
  • 共圆后所有圆周角性质成立：同弧所对圆周角相等，弦切角等于所夹弧对的圆周角。
  • 圆内接四边形对角互补、外角等于内对角。
  • 可用于构造直角三角形（直径所对圆周角为 $90^\circ$），转化长度与面积。

解题方法与套路

  1. 观察图形，锁定目标四边形：明确要证明的是哪四个点共圆，为后续角度或比例推理确定方向。
  2. 首选“对角互补”路径：在正方形、直角三角形等垂直关系丰富的图形中，优先证明一组对角均为 $90^\circ$（或互补）。常用于：
  3. 利用已知垂直（如 $DF \perp CE$）得出某个角为 $90^\circ$；
  4. 通过相似三角形传递角的相等关系，转化为另一角为 $90^\circ$，从而证互补。
  5. 灵活运用相似三角形搭桥：当直角或已知角不够直接时，通过比例关系 $\frac{DE}{DC}=\frac{DF}{CF}$ 等发现相似，再利用相似得到对应角相等，最终转化为共圆条件（如 $\angle GDF = \angle BCF$ 推出 $\triangle GDF \sim \triangle BCF$，从而得到角相等，进而证 $\angle GFB = 90^\circ$）。
  6. 已知共圆反推性质求值：当题目后续要求面积、长度时，立刻利用共圆所得性质：如直角、等角、圆幂、直角三角形斜边中线等，再结合全等或割补法完成计算。

高频易错

  • 对角找错：证明对角互补时，所找的“对角”不是目标四边形的真正对角，导致推理无效。务必核实四边形顶点的对应关系。
  • 相似三角形对应边比例写错：如将 $\frac{DF}{CF}$ 误写为 $\frac{CF}{DF}$，导致后续比例无法传递，影响角相等证明。
  • 弦切角定理使用条件不清：弦切角等于所夹弧对的圆周角，必须满足一边与圆相切、另一边是弦，且离开切点的角才是弦切角。
  • 误将比例关系直接当共圆条件：仅凭线段成比例不能直接得到四点共圆，必须结合夹角相等等条件，转化为圆幂逆定理或相似角关系。
  • 计算面积时忽略“共圆带来的直角三角形”：如证明 $\angle GFB = 90^\circ$ 后，$GF$ 与 $BF$ 垂直，却仍用一般四边形面积公式，而未拆分为两个直角三角形求解。

代表题精讲

代表题一：2016 年正方形中的四点共圆

题目：在正方形 $ABCD$ 中，$E$、$G$ 分别在 $DA$、$DC$ 上，$DE=DG$，过 $D$ 作 $DF \perp CE$ 于 $F$。
（Ⅰ）证明 $B，C，G，F$ 四点共圆；
（Ⅱ）若 $AB=1$，$E$ 为 $DA$ 的中点，求四边形 $BCGF$ 的面积。

思路：
- 对（Ⅰ）可优先考虑对角互补：已有 $\angle BCD=90^\circ$，若证 $\angle GFB=90^\circ$ 即可。
- 通过 $DF \perp CE$ 得 $\angle DFC=90^\circ$，结合 $DE=DG$ 和正方形边长相等等条件，构造相似三角形 $\triangle GDF \sim \triangle BCF$，进行角度传递，最终得到 $\angle GFB = \angle DFC = 90^\circ$。
- 对（Ⅱ），利用（Ⅰ）结论得到 $\angle GFB=90^\circ$，再结合 $GF=GC$（可由直角三角形斜边中线或全等得出），将四边形分割为全等三角形求面积。

步骤：
（Ⅰ）由正方形得 $DC=BC$，$DE=DG$。
由 $DF \perp CE$ 得 $\angle DFC=90^\circ$，$\text{Rt}\triangle DFC \sim \text{Rt}\triangle EDC$，有 $\frac{DF}{CF}=\frac{ED}{DC}=\frac{DG}{BC}$。
又 $\angle GDF = 90^\circ - \angle FDC = \angle FCD$，而 $\angle BCF = 90^\circ - \angle FCD$，注意此处需要更精确的关系：由相似得 $\angle GDF = \angle BCF$，于是 $\triangle GDF \sim \triangle BCF$。
所以 $\angle CFB = \angle DFG$，
则 $\angle GFB = \angle GFC + \angle CFB = \angle GFC + \angle DFG = \angle DFC = 90^\circ$。
又 $\angle BCD=90^\circ$，故 $\angle BCD + \angle GFB = 180^\circ$，所以 $B，C，G，F$ 四点共圆。

（Ⅱ）$AB=1$，$E$ 为 $DA$ 中点，则 $DE=\frac12$，$DG=\frac12$，$GC=\frac12$。
在 $\text{Rt}\triangle DFC$ 中，$F$ 为斜边中点吗？需注意：由 $\triangle GDF \sim \triangle BCF$ 可得 $\frac{GF}{BF}=\frac{GD}{BC}=\frac12$，且可证明 $GF=GC$。实际上，连接 $GF$，由 $\angle GFB=90^\circ$ 及 $GC=GD$，可证 $\triangle GFB \cong \triangle GCB$（$GF=GC$，公共边 $GB$，直角），故 $S_{\triangle GFB}=S_{\triangle GCB}$。
由 $AB=1$，$BC=1$，$CG=\frac12$，$S_{\triangle BCG}=\frac12 \times 1 \times \frac12=\frac14$。
因此 $S_{BCGF}=2S_{\triangle BCG}=\frac12$。

点评/变式：本题以正方形为载体，核心是“直角 + 相似三角形”推导共圆，典型的“对角互补”判定法。变式中可将 $E$ 位置一般化，或换为矩形背景，但方法相通。

代表题二：2013 年弦切线与四点共圆

题目：$CD$ 为 $\triangle ABC$ 外接圆的切线，$AB$ 延长线交 $CD$ 于 $D$，$E$、$F$ 分别在弦 $AB$、$AC$ 上，满足 $BC \cdot AE = DC \cdot AF$，且 $B，E，F，C$ 四点共圆。
（1）证明：$CA$ 是 $\triangle ABC$ 外接圆的直径；
（2）若 $DB=BE=EA$，求过 $B，E，F，C$ 四点的圆的面积与 $\triangle ABC$ 外接圆面积的比值。（本题只要求掌握共圆部分，重点在（1））

思路：
- 题设直接给出了 $B，E，F，C$ 四点共圆，利用它的性质 $\angle CFE = \angle CBE$。
- 切线 $CD$ 给出弦切角：$\angle DCB = \angle A$。
- 将比例条件 $BC \cdot AE = DC \cdot AF$ 改写成 $\frac{BC}{DC}=\frac{AF}{AE}$，结合弦切角等，可证 $\triangle CDB \sim \triangle AEF$，得 $\angle CBD = \angle AFE$。
- 由共圆性质得 $\angle CFE = \angle CBE$，于是 $\angle CFE = \angle AFE$，且 $A$、$F$、$C$ 共线，故两角和为平角，各为 $90^\circ$，即 $\angle AFC=90^\circ$，所以 $CA$ 为直径。

步骤：
（1）由 $CD$ 是 $\triangle ABC$ 外接圆的切线，得 $\angle DCB = \angle A$。
由 $BC \cdot AE = DC \cdot AF$ 得 $\frac{BC}{DC} = \frac{AF}{AE}$。
所以 $\triangle BCD \sim \triangle FAE$（两边成比例且夹角相等，夹角为 $\angle DCB$ 和 $\angle A$），于是 $\angle CBD = \angle AFE$。
又 $B，E，F，C$ 四点共圆 $\Rightarrow \angle CFE = \angle CBE$（同弧 $\widehat{CE}$ 所对圆周角）。
所以 $\angle CFE = \angle AFE$。
因为 $A，F，C$ 三点共线，故 $\angle CFE + \angle AFE = 180^\circ$，从而 $\angle CFE = \angle AFE = 90^\circ$，即 $\angle AFC = 90^\circ$，所以 $CA$ 是 $\triangle ABC$ 外接圆的直径。

点评/变式：本题训练“已知共圆”如何输出角相等等关键性质，同时结合切线带来的弦切角，对比例条件进行相似转化。直径证明常落脚在“圆周角为 $90^\circ$”。若将四点共圆条件换成其他形式（如圆幂等式），可类比推理。
