圆内接四边形性质

考点圆内接四边形性质权重1真题数1学科数学父主题平面几何

考点定位

  • 父主题：平面几何
  • 权重 weight：1
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：解答22
  • 难度分布：中1

知识精要

  • 圆内接四边形的性质：圆内接四边形对角互补，即 $\angle A + \angle C = 180^\circ$，$\angle B + \angle D = 180^\circ$；任一外角等于其内对角。
  • 核心推论：在同圆或等圆中，同弧或等弧所对的圆周角相等。反之，相等的圆周角所对的弧也相等。
  • 平行线与圆周角：若一条弦与一条切线或另一弦平行，则它们所夹的弧相等，从而对应的圆周角或弦相等。本题关键：$CF \parallel AB \implies \widehat{AC} = \widehat{BF}$。
  • 中位线定理：三角形两边中点的连线平行于第三边且等于第三边的一半。即 $DE \parallel BC$，$DE = \frac{1}{2}BC$。

解题方法与套路

  1. 平行条件转化法：看到圆周上出现平行弦（如 $CF \parallel AB$），立即导出弧相等（$\widehat{AC} = \widehat{BF}$），再推出弦相等或角相等（$BC=AF$，$\angle BDC = \angle BCD$ 等）。
  2. 中点连环处理：条件给出多个中点，不仅使用中位线定理得出平行与线段关系，还可结合平行四边形（如 $D$ 为中点且 $CF \parallel BD$，可构造平行四边形 $BDCF$）证明线段相等。
  3. 四点共圆的判定与应用：
  4. 判定：若四边形一组对角互补或外角等于内对角，则四点共圆。本题中由平行四边形性质可得 $A$、$B$、$C$、$F$ 及 $D$、$B$、$C$、$F$ 两组四点共圆。
  5. 应用：利用四点共圆的性质转化角相等，为三角形相似提供角条件。
  6. 相似证明五步法：①找两对角对应相等；②若只有一对，利用线段比；③关键角优先考虑圆内接四边形外角、平行线同位角/内错角；④利用公共角或对顶角；⑤最终写出相似判定结论。

高频易错

  • 圆周角定理逆用错误：在圆中，由弧相等可得圆周角相等，但必须确保所对的弧是同一段或相等的弧。
  • 平行弦所夹弧相等混淆：$CF \parallel AB$ 推出的是 $\widehat{AF} = \widehat{BC}$ 或 $\widehat{AC} = \widehat{BF}$，具体需根据平行线位置判断。错用结论会导致后续角相等链条断裂。
  • 四点共圆的忽视：当图形出现圆内接三角形外加平行线时，容易忽略图形中其他天然的圆内接四边形（如本题的四边形 $DBCF$），导致找不到关键的角相等关系。
  • 中位线性质用错：中位线 $DE$ 平行于 $BC$，易误写为 $DE \parallel AC$ 或 $DE=\frac{1}{2}AB$。
  • 相似证明对应点错位：$\triangle BCD \sim \triangle GBD$ 中，顶点对应关系是 $B \leftrightarrow G$, $C \leftrightarrow B$, $D \leftrightarrow D$，若找错对应角（如误证 $\angle BDC = \angle GBD$）会导致全盘皆输。

代表题精讲

题目：如图，$D$，$E$ 分别为 $\triangle ABC$ 边 $AB$，$AC$ 的中点，直线 $DE$ 交 $\triangle ABC$ 的外接圆于 $F$，$G$ 两点，若 $CF \parallel AB$，证明： （1）$CD=BC$； （2）$\triangle BCD \sim \triangle GBD$。

思路： （1）证 $CD = BC$，观察 $BC$ 与 $CD$ 所在的三角形，可考虑证四边形 $BDCF$ 为平行四边形，得对边相等；或连接 $AF$，利用平行弦 $CF \parallel AB$ 推弧等进而得 $BC=AF$，再通过中位线和平行证明 $AD \parallel CF$，最终得到平行四边形。 （2）证相似，目标是找两对角相等。利用（1）中平行四边形的结论，发现 $D, B, C, F$ 四点共圆，结合圆内接四边形外角等于内对角及平行弦性质转化角。

步骤： （1）证明 $CD=BC$ - 由 $D$ 为 $AB$ 中点，$CF \parallel AB$，得 $CF \parallel BD$。 - $\because D$ 为 $AB$ 中点，$\therefore BD=DA$。又 $CF \parallel AD$（因 $CF \parallel AB$ 整体）。 - 由 $CF \parallel AB \implies \widehat{AC} = \widehat{BF} \implies AF = BC$。 - $\because D, E$ 为中点，$\therefore DE \parallel BC$，即 $DG \parallel BC$。 - 则 $\angle ADE = \angle ABC$，$\angle AED = \angle ACB$。 - 又 $A, B, C, F$ 四点共圆，$\angle CFE = \angle ABC$。 - $\therefore \angle ADE = \angle CFE \implies AD \parallel CF$。 - $\because AD = DB, AD \parallel CF, DB \parallel CF$，$\therefore$ 四边形 $BDCF$ 为平行四边形，$\therefore CD = BC$。

（2）证明 $\triangle BCD \sim \triangle GBD$ - 由（1）知四边形 $BDCF$ 为平行四边形，$\therefore \angle BDC = \angle BFC$。 - $D, B, C, F$ 四点共圆，$\therefore \angle BFC = \angle BDC$（其实互为补角或相等，此处平行四边形得对边平行，故$BCFD$为等腰梯形，四点共圆）。 - 由圆内接四边形 $DBCF$ 性质：$\angle GBD = \angle GBC$（同角），$\angle GDB = \angle FCB$（外角等于内对角）。 - 在 $\triangle BCD$ 与 $\triangle GBD$ 中， $\angle BDC = \angle BCD$（由（1）$CD=BC$ 得）+ 圆内接四边形导角，核心找公共角 $\angle D$。 更直接：$\because BC = CD$，$\therefore \angle 1 = \angle 2$。 又 $\angle 1 = \angle G$（圆内接四边形外角），$\angle 2 = \angle GBC$。 $\therefore \angle G = \angle GBC$。 在 $\triangle BCD$ 和 $\triangle GBD$ 中， $\angle BDC = \angle GBD$（平行线内错角及圆的角转化）， $\angle BCD = \angle GDB \implies \triangle BCD \sim \triangle GBD$。

点评/变式 - 核心桥梁：平行弦性质是打通全题的关键，它将中位线与圆周角定理串联，是高考圆问题的高频切入点。 - 经典变形：若取消中点条件，直接给 $CF \parallel AB$ 且 $CF=BD$，能证出什么结论？本质仍是构造平行四边形和四点共圆。 - 避坑指南：证明相似时，角的推导必须基于严格的四点共圆或平行线性质，不能“看着像”就写。建议每一步角相等都标注依据（如“平行弦所夹弧等”“外角等于内对角”），防止被扣过程分。
