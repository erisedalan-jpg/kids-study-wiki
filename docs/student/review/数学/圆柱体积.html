圆柱体积

考点圆柱体积权重1真题数1学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：1
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 圆柱体积公式：底面半径为 $r$，高为 $h$ 的圆柱体积 $$V = \pi r^2 h.$$
  • 切削削问题中，被切削掉部分的体积 $V_{\text{削}} = V_{\text{毛坯}} - V_{\text{零件}}$.
  • 三视图与几何体的关系：长对正、高平齐、宽相等。由正视图、侧视图得到几何体的高度与宽（长）度，由俯视图得到上下底面的形状与大小，特别注意实线、虚线的含义（可见棱与不可见棱）。
  • 组合体体积：若几何体由若干基本体（柱、锥、台、球等）组合而成，其体积为各部分体积的代数和（本题中为上、下两个圆柱的叠加）。

解题方法与套路

  1. 读图、标数：根据三视图及网格标注（或题目给出的尺寸），确定各视图中的关键尺寸。注意区分圆的直径与半径。
  2. 还原几何体：将三视图“拉伸”成立体图形。常用方法是以俯视图为底，配合正、侧视图的高度，把平面图形竖直拉起，想象切割、叠加关系。
  3. 分块计算体积：若几何体为组合体，拆分为基本几何体分别套用体积公式，求和得零件体积 $V_{\text{零件}}$。
  4. 求毛坯体积：看清毛坯形状（常为圆柱、长方体等），由条件求出其体积 $V_{\text{毛坯}}$。
  5. 计算比值：切削掉部分的体积 $V_{\text{削}} = V_{\text{毛坯}} - V_{\text{零件}}$，所求比值为 $\dfrac{V_{\text{削}}}{V_{\text{毛坯}}}$（或根据题目要求写成最简分数）。

高频易错

  • 半径与直径混淆：三视图中给出的圆形尺寸往往是直径，但体积公式用半径。若直接将直径代入 $\pi r^2 h$ 会致错。
  • 三视图对应关系出错：未能正确对齐“宽相等”，导致底面尺寸代入错误（例如将侧视图的宽误作俯视图的长）。
  • 遗漏不可见轮廓：若零件从毛坯中切割产生内部空腔，三视图中会以虚线表示，忽略虚线会遗漏材料去除量，导致零件体积算大。
  • 忘记基本公式：圆柱体积错用为 $\pi d^2 h$、$\frac{1}{3}\pi r^2 h$ 等。
  • 比值未约分或答反：求成 $V_{\text{零件}}/V_{\text{毛坯}}$，忽视题目问的是“切削掉部分”的占比。

代表题精讲

题目（2014年全国Ⅰ卷理-06）：网格纸上正方形小格边长为1cm，粗线画出某零件的三视图。该零件由一个底面半径3cm、高6cm的圆柱体毛坯切削得到，则切削掉部分的体积与原来毛坯体积的比值为（　　）

思路
首先由三视图还原出零件的实际形状：从网格数出尺寸，知零件由下、上两个同轴圆柱叠加而成（下大上小，阶梯轴状）。分别计算两个圆柱的体积，求和得到零件体积。毛坯即为完整的半径为3、高为6的圆柱体。用毛坯体积减去零件体积即得切削掉部分体积，再求比值并约分。

步骤 1. 读三视图（尺寸来源：网格小格边长=1）。 - 正视图、侧视图均显示：下部矩形高 $2$，宽 $6$（对应大圆柱）；上部矩形高 $4$，宽 $4$（对应小圆柱）。 - 俯视图为两个同心圆，大圆直径 $6$，小圆直径 $4$。 2. 还原零件几何体： - 下部大圆柱：半径 $r_1 = 3$，高 $h_1 = 2$。 - 上部小圆柱：半径 $r_2 = 2$，高 $h_2 = 4$。 零件总高 $2+4=6$，与毛坯高度一致。 3. 计算零件体积： $$V_{\text{零件}} = \pi r_1^2 h_1 + \pi r_2^2 h_2 = \pi \times 3^2 \times 2 + \pi \times 2^2 \times 4 = 18\pi + 16\pi = 34\pi \, (\text{cm}^3).$$ 4. 计算毛坯体积： $$V_{\text{毛坯}} = \pi \times 3^2 \times 6 = 54\pi \, (\text{cm}^3).$$ 5. 切削掉部分体积： $$V_{\text{削}} = V_{\text{毛坯}} - V_{\text{零件}} = 54\pi - 34\pi = 20\pi.$$ 所求比值： $$\frac{V_{\text{削}}}{V_{\text{毛坯}}} = \frac{20\pi}{54\pi} = \frac{10}{27}.$$ 对应选项 C。

点评与变式
本题将三视图与圆柱体积公式结合，核心障碍在于正确提取三视图中的尺寸并还原阶梯轴几何体。易错点是把小圆柱的直径 $4$ 直接当作半径代入，导致零件体积算成 $\pi\times 4^2\times 4$ 等错误。
变式训练：若毛坯改为棱柱，或零件带有圆台、球缺等，思路不变——先还原、再分块求体积、最后作差求比值，注意牢记各类几何体体积公式。
