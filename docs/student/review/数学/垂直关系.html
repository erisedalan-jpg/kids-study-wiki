知识精要

  • 垂直的判定与转化
    在解析几何中，两直线 $l_1$、$l_2$ 垂直（$l_1 \perp l_2$）常通过下列方式转化为代数关系：
  • 斜率之积：$k_1 \cdot k_2 = -1$（注意斜率不存在时单独讨论）。
  • 向量点积：若直线方向向量分别为 $\vec{v}_1$、$\vec{v}_2$，则 $\vec{v}_1 \cdot \vec{v}_2 = 0$；对于以点 $P$ 为顶点的直角，可用 $\overrightarrow{PA} \cdot \overrightarrow{PB}=0$。
  • 勾股定理：在 $\triangle ABC$ 中，若 $AB \perp AC$，则 $|BC|^2 = |AB|^2 + |AC|^2$。
  • 椭圆中的焦点三角形
    设椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1 \ (a>b>0)$ 的两焦点为 $F_1(-c,0)$、$F_2(c,0)$，点 $P$ 在椭圆上，则 $\triangle PF_1F_2$ 满足：
  • $|PF_1|+|PF_2|=2a$，$|F_1F_2|=2c$，$b^2=a^2-c^2$。
  • 若 $\angle F_1PF_2 = 90^\circ$，则 $|PF_1|^2+|PF_2|^2 = 4c^2$。
  • 离心率的求解通法
    $e=\frac{c}{a}$，需通过几何关系或点的坐标代入椭圆方程建立关于 $a,c$ 的齐次方程，结合 $e \in (0,1)$ 解得。

解题方法与套路

处理圆锥曲线中“垂直关系”的通用步骤： 1. 设焦点与坐标：根据对称性建立坐标系，写出焦点坐标，必要时设出动点坐标。 2. 将垂直条件代数化：借助直角三角形边角关系、勾股定理、两直线垂直的斜率关系或向量垂直，求出关键点的坐标或边长。 3. 利用曲线定义或方程：将点的坐标代入曲线标准方程，或利用定义中的长度关系，得到关于 $a,b,c$ 的方程。 4. 消元求离心率：利用 $b^2=a^2-c^2$（椭圆）或 $b^2=c^2-a^2$（双曲线）消去 $b$，建立 $a,c$ 的齐次方程，解出 $e=\frac{c}{a}$，并根据离心率范围取舍。 5. 选择题可灵活运用：等腰直角三角形、含 $30^\circ$（或 $60^\circ$）的直角三角形等特殊三角形，可直接推得边长比例，快速得到关于 $a,c$ 的关系。

高频易错

  • 坐标与线段长度的符号：焦点在 $x$ 轴时，$F_2(c,0)$，向量 $\overrightarrow{F_2P}$ 的坐标容易写反；计算 $P$ 的坐标时，要注意方向与角度所在的象限。
  • 误用垂足点：本题中直角为 $\angle F_1PF_2$ 还是 $\angle PF_2F_1$？需仔细区分垂直关系的位置，不同位置的直角对应不同的边长计算。
  • 椭圆离心率的范围：求得 $e$ 的方程后可能有多解，务必用 $0<e<1$ 检验并舍去超出范围的根。
  • 混淆椭圆与双曲线的焦点三角形性质：椭圆中 $|PF_1|+|PF_2|=2a$，双曲线中 $||PF_1|-|PF_2||=2a$；将垂直关系与和（或差）联立时不可混用。

代表题精讲

2018·全国卷·文·11（椭圆离心率）

题目
已知 $F_1$，$F_2$ 是椭圆 $C$ 的两个焦点，$P$ 是 $C$ 上的一点，若 $PF_1 \perp PF_2$，且 $\angle PF_2F_1=60^\circ$，则 $C$ 的离心率为 $\ (\ \ )$
A. $1-\frac{\sqrt{3}}{2}$　B. $2-\sqrt{3}$　C. $\frac{\sqrt{3}-1}{2}$　D. $\sqrt{3}-1$

思路
由垂直和 $60^\circ$ 角确定 $\triangle PF_1F_2$ 的形状，用已知边 $|F_1F_2|=2c$ 表示出 $P$ 的坐标，代入椭圆方程建立关于 $a,c$ 的方程，化简求 $e$。

步骤
1. 设椭圆方程为 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1 \ (a>b>0)$，焦点 $F_1(-c,0)$，$F_2(c,0)$。
2. 在 $\triangle PF_1F_2$ 中，$PF_1 \perp PF_2$ 且 $\angle PF_2F_1=60^\circ$，则 $\triangle PF_1F_2$ 为直角三角形，斜边 $|F_1F_2|=2c$。
$|PF_2| = |F_1F_2|\cos 60^\circ = 2c \times \frac{1}{2}=c$，
$|PF_1| = |F_1F_2|\sin 60^\circ = 2c \times \frac{\sqrt{3}}{2}=\sqrt{3}c$。
3. 由 $F_2(c,0)$ 出发，$P$ 在 $x$ 轴上方，$\angle PF_2F_1=60^\circ$ 表明 $\overrightarrow{F_2P}$ 与 $x$ 轴负方向夹角 $60^\circ$，故
$$P!\left(c - |PF_2|\cos 60^\circ,\ |PF_2|\sin 60^\circ\right) = \left(c - \frac{c}{2},\ \frac{\sqrt{3}c}{2}\right) = \left(\frac{c}{2},\ \frac{\sqrt{3}c}{2}\right).$$
4. 将 $P$ 代入椭圆方程：
$$\frac{(c/2)^2}{a^2} + \frac{(\sqrt{3}c/2)^2}{b^2}=1 \quad\Rightarrow\quad \frac{c^2}{4a^2} + \frac{3c^2}{4b^2}=1.$$
5. 利用 $b^2 = a^2-c^2$ 消去 $b$：
$$\frac{c^2}{4a^2} + \frac{3c^2}{4(a^2-c^2)}=1.$$
两边同乘 $4a^2(a^2-c^2)$：
$$c^2(a^2-c^2) + 3c^2a^2 = 4a^2(a^2-c^2).$$
整理得 $4a^4 - 8a^2c^2 + 4c^4=0$，除以 $4$ 并用 $e=\frac{c}{a}$ 代入：
$$a^4 - 2a^2c^2 + c^4=0 \ \Rightarrow\ 1 - 2e^2 + e^4=0 \ \Rightarrow\ (e^2-1)^2=0 \quad(\text{但此题应为 } e^4-8e^2+4=0).$$
重新审慎推导：从 $\frac{c^2}{4a^2} + \frac{3c^2}{4(a^2-c^2)}=1$ 出发，设 $e^2=\frac{c^2}{a^2}$，则
$$\frac{e^2}{4} + \frac{3e^2}{4(1-e^2)}=1 \ \Rightarrow\ e^2(1-e^2) + 3e^2 = 4(1-e^2).$$
即 $e^2 - e^4 + 3e^2 = 4 - 4e^2 \ \Rightarrow\ -e^4 + 8e^2 - 4 = 0$，即 $e^4 - 8e^2 + 4 = 0$。
6. 解二次方程 $t^2 - 8t + 4=0$（令 $t=e^2$），得 $t=4 \pm 2\sqrt{3}$。
因 $e \in (0,1)$，$t<1$，故 $t=4-2\sqrt{3}=\left(\sqrt{3}-1\right)^2$，于是
$$e = \sqrt{t} = \sqrt{3}-1.$$
对应选项 D。

点评
本题充分体现了垂直条件与直角三角形边角关系的结合，利用三角比直接求得 $P$ 坐标，再代入标准方程是通法。变式：若条件改为 $\angle F_1PF_2=60^\circ$ 且 $PF_1 \perp x$ 轴等，同样通过直角三角形的边或坐标入手，建立齐次方程求离心率。注意求解过程中对齐次方程的化简要细致，避免符号错误。
