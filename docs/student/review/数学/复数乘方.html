知识精要

  • 复数代数形式的乘方：设 $z=a+bi\ (a,b\in\mathbb{R})$，则 $z^n = (a+bi)^n$。当 $n$ 较小时，可直接按二项式定理展开，并结合 $i^2=-1$、$i^3=-i$、$i^4=1$ 化简。
  • 复数乘方的三角形式（棣莫弗定理）：若 $z=r(\cos\theta+i\sin\theta)$，则 $z^n = r^n(\cos n\theta + i\sin n\theta),\ n\in\mathbb{N}^*$。特别地，当模 $r=1$ 时，$(\cos\theta+i\sin\theta)^n = \cos n\theta + i\sin n\theta$。
  • 常用简化技巧：对于 $(1\pm i)^2$ 等特殊复数的平方结果应熟记：$(1+i)^2=2i$，$(1-i)^2=-2i$。由此可快速递推更高次幂。
  • 适用条件：代数形式或三角形式均可处理复数乘方，需注意指数为正整数。当次数较高且角度易于表达时，优先使用三角形式。

解题方法与套路

  1. 观察底数特征：先看复数是否为 $1\pm i$、$\sqrt{3}\pm i$ 等特殊形式，它们的平方或低次幂结果简洁，可借以减少计算量。
  2. 低次直接乘方：若次数 $n\le 4$，可直接逐步平方或展开。如 $(a+bi)^2 = a^2 - b^2 + 2abi$，再结合 $i^2=-1$。
  3. 高次借助三角形式：当 $n$ 较大且辐角为特殊角时，将复数化为 $r(\cos\theta+i\sin\theta)$，利用棣莫弗定理一步到位。
  4. 二项展开法：对 $(a+bi)^n$ 用二项式定理展开，整理实部与虚部，注意 $i$ 的幂周期为 4。
  5. 验算与选项匹配：计算结束后，注意结果的实部与虚部正负号，对照选项快速排除。

高频易错

  • $i$ 的幂次混淆：$i^2=-1$，$i^3=-i$，$i^4=1$，在多次相乘时符号易错，可先合并所有 $i$ 的因子次数再统一处理。
  • 平方展开漏项或符号错误：如误算 $(1-i)^2=1-2i-i^2$ 后忘记 $-i^2$ 应为 $+1$，得到 $2-2i$ 而非正确结果 $-2i$。
  • 直接四次方展开易漏乘：若直接用二项式定理展开 $(1-i)^4$，组合系数和符号运算量大，容易在虚部系数处出错。
  • 混淆 $1-i$ 与 $i-1$：题目中通常是 $1-i$，平方得 $-2i$；若顺手写成 $(i-1)^2$ 则结果为 $-1+2i-i^2=2i$，符号相反。
  • 忘记复数乘方结果的实虚性：计算中间可能得到纯虚数，再平方后变回实数；需要注意结果的最终形式是纯实数、纯虚数还是普通复数，防止选项误读。

代表题精讲

题目（2020-文-02）
计算 $(1-\mathrm{i})^4 =$ （选择题，选项：A. $-4$　B. $4$　C. $-4\mathrm{i}$　D. $4\mathrm{i}$）

思路
注意到底数为 $1-\mathrm{i}$，先计算 $(1-\mathrm{i})^2$，再将结果平方得到四次方，可避免直接四次方展开的繁琐。同时关注 $i^2=-1$ 的使用。

步骤
1. 计算 $(1-\mathrm{i})^2$：
$$(1-\mathrm{i})^2 = 1^2 - 2\cdot 1\cdot \mathrm{i} + (\mathrm{i})^2 = 1 - 2\mathrm{i} - 1 = -2\mathrm{i}.$$ 2. 将上步结果平方得到四次方：
$$(1-\mathrm{i})^4 = [(-2\mathrm{i})]^2 = (-2)^2 \cdot \mathrm{i}^2 = 4 \times (-1) = -4.$$ 3. 对照选项，$-4$ 对应 A。

点评/变式
- 分步平方是处理 $(1\pm i)$ 偶次方的高效手段，可大幅降低出错率。
- 若题目改为 $(1+\mathrm{i})^4$，则 $(1+\mathrm{i})^2=2\mathrm{i}$，四次方为 $(2\mathrm{i})^2=-4$，结果仍为 $-4$。
- 变式：计算 $(1+\sqrt{3}\mathrm{i})^3$。提示：模为 $2$，辐角 $60^\circ$，用三角形式 $[2(\cos 60^\circ+i\sin 60^\circ)]^3=8(\cos 180^\circ+i\sin 180^\circ)=-8$，更快。
- 此题易错点在于由 $-2\mathrm{i}$ 平方时忘记 $\mathrm{i}^2=-1$ 而误得 $4\mathrm{i}$ 或 $4$，需强化虚数单位平方的符号意识。
