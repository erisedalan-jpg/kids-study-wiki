复数乘法

考点复数乘法权重18真题数5学科数学父主题复数

考点定位

  • 父主题：复数
  • 权重 weight：18
  • 真题数：5；年份跨度：2015–2023
  • 出现题位：选择1 选择2
  • 难度分布：易5

知识精要

  • 复数的代数形式：$z = a + bi$，其中 $a,b\in\mathbb{R}$，$i$ 为虚数单位，满足 $i^2 = -1$。
  • 复数乘法法则：设 $z_1 = a+bi$，$z_2 = c+di$，则
    $$z_1 z_2 = (a+bi)(c+di) = ac + adi + bci + bdi^2 = (ac-bd) + (ad+bc)i.$$
    运算实质：多项式乘法展开，合并实部与虚部，注意 $i^2$ 化为 $-1$。
  • 共轭复数：$z=a+bi$ 的共轭复数 $\overline{z}=a-bi$。若已知 $z$ 为某两复数乘积，求 $\overline{z}$ 时常先算出乘积再取共轭。
  • 复数相等的条件：$a+bi = c+di \iff a=c \text{ 且 } b=d$（$a,b,c,d\in\mathbb{R}$）。含参数等式常用此法列方程求解。
  • 复数的几何意义：复数 $a+bi$ 对应复平面内的点 $(a,b)$，由此可判断乘积所在象限。

解题方法与套路

  1. 直接展开，逐项相乘：将两个复数看作二项式相乘，使用分配律展开，注意带上虚数单位 $i$。
  2. 合并 $i^2$，分离实虚：遇到 $i^2$ 立即化为 $-1$；整理后写成 $(\text{实部}) + (\text{虚部})i$ 的标准代数形式。
  3. 求共轭莫跳步：若先求 $z$ 的乘积再求 $\overline{z}$，严格按照“先乘后取共轭”的顺序，不要漏掉虚部符号变化。
  4. 含参问题用复数相等：若等式两侧均为复数代数形式，利用实部、虚部分别相等列出实数方程组，求解参数。
  5. 判断点所在象限：求出乘积的实部 $x$ 和虚部 $y$，根据 $(x,y)$ 的符号确定象限（第一象限：$x>0,y>0$；第二象限：$x<0,y>0$；第三象限：$x<0,y<0$；第四象限：$x>0,y<0$）。

高频易错

  • 忘记 $i^2=-1$ 或符号错乱：展开时常因疏忽将 $bdi^2$ 写成 $+bd$ 而非 $-bd$，导致实部符号错误。
  • 实部虚部归并不彻底：展开后出现 $i^2$ 项、$i$ 项、常数项混在一起，没有将不含 $i$ 的项全部合并为实部，含 $i$ 的一次项全部合并为虚部。
  • 共轭对象搞错：题目要求 $\overline{z}$ 但直接对两个相乘的复数先分别取共轭再乘，或不根据最终乘积直接求共轭，或只改了虚部的符号而忘记实部不变。
  • 复数相等时虚部系数看漏：等式两边含 $i$ 项系数比较时，误将虚部与实部交叉相等，或参数对应不准确导致方程列错。
  • 象限判断只看实部或虚部：未完整判断 $(x,y)$ 的符号组合，或误以为虚部 $y$ 为 $bi$ 中的 $b$ 即为坐标纵轴（确实如此，但有时考生搞混）。

代表题精讲

1. 2023新课标Ⅱ卷

题目：在复平面内，$(1+3i)(3-i)$ 对应的点位于哪个象限？
思路：先按乘法展开，化简为 $a+bi$ 形式，根据实部、虚部正负确定象限。
步骤： 1. 展开：$(1+3i)(3-i) = 3 - i + 9i - 3i^2$。 2. 合并 $i^2$：$-3i^2 = -3(-1) = 3$。 3. 合并实部与虚部：实部 $3+3=6$，虚部 $(-1+9)i = 8i$，即 $6+8i$。 4. 对应点 $(6,8)$，实虚皆正，位于第一象限。
点评/变式：本题核心是乘法后的象限判断。若改成 $(1-3i)(-3+i)$，结果实虚部符号将变化，点可能落在第四或第二象限，需重新计算确认。务必在化简后看清实虚部符号。

2. 2019全国卷文科

题目：设 $z = i(2+i)$，则 $\overline{z}=$？
思路：先计算 $z$，再求共轭。注意 $i$ 在前，直接用分配律展开。
步骤： 1. 计算 $z$：$z = i(2+i) = 2i + i^2 = 2i - 1$。 2. 写成标准形式：$z = -1 + 2i$。 3. 取共轭：$\overline{z} = -1 - 2i$，对应选项 D. $-1-2i$。
点评/变式：此题易错点在于展开后误将 $-1+2i$ 的共轭写成 $1-2i$ 或 $1+2i$，应对“实部不变，虚部变号”刻入肌肉记忆。若题目改为 $\overline{i(2-i)}$，先算 $z=2i - i^2 = 2i+1 = 1+2i$，共轭为 $1-2i$。

3. 2018全国卷文科

题目：$i(2+3i) =$？
思路：直接用乘法法则，$i$ 乘以括号内每一项，合并实虚。
步骤： 1. 分配：$i(2+3i) = 2i + 3i^2$。 2. $i^2 = -1$，得 $2i + 3(-1) = -3 + 2i$。 3. 对应选项 D. $-3+2i$。
点评/变式：本题为基础到不能再基础的纯运算。训练时将系数从 $i$ 换成 $-i$ 练习，如 $(-i)(2+3i) = -2i -3i^2 = 3-2i$，巩固符号处理。
