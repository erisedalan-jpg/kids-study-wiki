知识精要

  • 复数的代数形式：$z = a + bi\ (a,b \in \mathbb{R})$，$a$ 为实部，$b$ 为虚部（虚部是实数）。
  • 复数相等：$a+bi = c+di \iff a = c$ 且 $b = d$。
  • 复数的模：$|z| = \sqrt{a^2 + b^2}$，表示复平面内点 $(a,b)$ 到原点的距离。 性质：$|z_1z_2| = |z_1||z_2|$，$|z_1/z_2| = |z_1|/|z_2|\,(z_2 \neq 0)$，$|z^n| = |z|^n$。
  • 共轭复数：$\overline{z} = a - bi$，满足 $z\overline{z} = |z|^2$，$|\overline{z}| = |z|$。
  • 四则运算： 加减：实部与实部相加减，虚部与虚部相加减。 乘法：$(a+bi)(c+di) = (ac-bd) + (ad+bc)i$。 除法：$\frac{a+bi}{c+di} = \frac{(a+bi)(c-di)}{c^2+d^2}\,(c+di \neq 0)$。
  • 虚数单位 $i$：$i^2 = -1$，$i^{4k}=1,\ i^{4k+1}=i,\ i^{4k+2}=-1,\ i^{4k+3}=-i$。
  • 几何意义：复数 $z=a+bi$ 对应复平面上的点 $(a,b)$ 或向量，对称性与坐标变换联系紧密（如关于虚轴对称：$(a,b) \to (-a,b)$，对应 $z$ 变为 $-\overline{z}$ 的特殊情形）。

解题方法与套路

  1. 统一形式：将题中复数均化成 $a+bi$ 的标准代数形式，特别是除法与乘方运算后。
  2. 复数相等列方程组：若等式两侧均为复数且含未知实数，令实部、虚部分别相等，转化为实数方程组求解。
  3. 模长计算策略：
  4. 先化简复数再代入 $|z| = \sqrt{a^2+b^2}$。
  5. 遇乘积、商或乘方的模，优先用模的性质简算。
  6. 对于含多个复数的模长条件，可设三角形式（如 $z=2\cos\theta+2i\sin\theta$）简化运算。
  7. 共轭与除法：分母含虚数时，分子分母同乘分母的共轭复数，分母化为实数。
  8. 几何对称题：抓住点坐标的对称关系（关于虚轴、实轴、原点），直接写出对应复数再计算。
  9. 含 $z$ 与 $\overline{z}$ 的方程：可设 $z=a+bi$，将方程化为一对实方程求解。

高频易错

  • 混淆虚部与虚数单位：虚部是 $b$，不是 $bi$。如 $z=3-4i$ 的虚部是 $-4$，共轭复数的虚部变号，实部不变。
  • 除法时漏乘或错用：分子、分母同乘共轭复数后，分母应为 $c^2+d^2$（无 $i$），切忌忘记同时乘分子。
  • 模长计算变实数平方：$|a+bi|=\sqrt{a^2+b^2}$，不是 $a^2+b^2$，开方不能少。
  • 乘方运算中 $i^2=-1$ 符号失误：如 $(2i)^2 = -4$，$(1+i)^2=2i$，注意含 $i$ 项的符号变化。
  • 复数相等忽略限制条件：题目常隐含 $a,b\in\mathbb{R}$，务必确认实部、虚部均为实数，否则不可直接对应相等。
  • 共轭复数误解：共轭仅虚部变号，若将 $a+bi$ 误认为共轭为 $-a+bi$ 或 $a-bi$ 混淆方向。

代表题精讲

题目1（2022-文-02）

设 $(1+2i)a + b = 2i$，其中 $a,b$ 为实数，则（　　） A. $a=1, b=-1$ 　B. $a=1, b=1$　C. $a=-1, b=1$　D. $a=-1, b=-1$

思路：将等式左侧整理成 $A+Bi$ 的形式，再利用复数相等（实部、虚部分别相等）列出关于 $a,b$ 的方程组。

步骤： 左侧 $= a + 2ai + b = (a+b) + 2ai$，右侧 $= 0 + 2i$。 由复数相等得： $$ \begin{cases} a + b = 0 \ 2a = 2 \end{cases} $$ 解得 $a = 1$，代入得 $b = -1$，故选 A。

点评/变式：该题考查复数乘法及相等条件的直接应用。注意不要漏乘 $2i \cdot a$ 中的 $i$，且须把不含 $i$ 的项全部归入实部。变式中可将 $2i$ 换成其他复数，或改为含 $\overline{z}$ 的方程，解法相同。

题目2（2022-理-02）

已知 $z = 1 - 2i$，且 $z + a\overline{z} + b = 0$，其中 $a,b$ 为实数，则（　　） A. $a=1, b=-2$　B. $a=-1, b=2$　C. $a=1, b=2$　D. $a=-1, b=-2$

思路：先写出 $\overline{z}$，代入方程，把左侧整理为 $A+Bi$ 形式，利用复数等于零等价于实部、虚部均为零，列方程组。

步骤： $\overline{z} = 1 + 2i$，代入： $1 - 2i + a(1+2i) + b = (1 + a + b) + (-2 + 2a)i = 0$。 则 $$ \begin{cases} 1 + a + b = 0 \ -2 + 2a = 0 \end{cases} $$ 由第二式得 $a = 1$，代入第一式得 $b = -2$，故选 A。

点评/变式：题目涉及共轭复数与方程，核心仍是“化为 $a+bi$ 后实虚部分别为零”。常见变式：将等式改为 $z^2 + az + b = 0$，需先计算 $z^2$ 再合并。

题目3（2021-文-02）

设 $z = \frac{4+3i}{i}$，则 $\overline{z} =$（　　） A. $3-4i$　B. $-3+4i$　C. $3-4i$　D. $3+4i$

（原题选项有重复，答案应为 $3-4i$）

思路：先通过复数除法化简 $z$，再取共轭得 $\overline{z}$。

步骤： $z = \frac{4+3i}{i}$。分子分母同乘 $-i$（或同乘 $i$ 的共轭 $-i$）： $z = \frac{(4+3i)(-i)}{i(-i)} = \frac{-4i -3i^2}{1} = -4i + 3 = 3 - 4i$。 因此 $\overline{z} = 3 + 4i$。 但观察选项应为 $3-4i$ 才正确？重新审视： $z = \frac{4+3i}{i}$，分子分母乘 $-i$：分母 $i \cdot (-i) = -i^2 = 1$，分子 $(4+3i)(-i) = -4i -3i^2 = -4i +3 = 3-4i$，所以 $z=3-4i$，共轭为 $3+4i$。选项 D 为 $3+4i$，原卷答案选 C 有误，应以正确推导为准：此题原解析答案给出 C（$3-4i$）可能是直接取 $z$ 的虚部变号误解，实际 $z=3-4i$ 的共轭是 $3+4i$ 。根据题目要求，我们按正确处理：$z=3-4i$，$\overline{z}=3+4i$。

点评/变式：除法化简是关键，切记分母实数化。共轭复数变换务必只变虚部符号。变式：$\frac{3+4i}{1-i}$，需分母实数化后取共轭。
