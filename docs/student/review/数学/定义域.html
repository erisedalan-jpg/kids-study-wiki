定义域

考点定义域权重3真题数1学科数学父主题函数与导数

考点定位

  • 父主题：函数与导数
  • 权重 weight：3
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 定义域：使函数解析式有意义的自变量 $x$ 的取值范围。常见限制条件：
  • 分式分母 $\neq 0$；
  • 偶次根式被开方数 $\geq 0$；
  • 对数真数 $>0$，底数 $>0$ 且 $\neq 1$；
  • 零次幂底数 $\neq 0$；
  • 实际问题需符合实际意义。
  • 复合函数定义域：由外层函数定义域与内层函数值域的交集确定，遵循“由外到内，逐步求解”原则。
  • 反函数与原函数的定义域关系：
  • 原函数 $y=f(x)$ 的定义域是其反函数 $y=f^{-1}(x)$ 的值域；
  • 原函数的值域是反函数的定义域。
  • 定义域的表示：区间、集合或不等式，需按题目要求规范书写。

解题方法与套路

  1. 直接法求定义域：列出所有限制条件的不等式（组），解之并取交集。
  2. 抽象函数定义域求解：
  3. 已知 $f(x)$ 定义域为 $[a,b]$，求 $f[g(x)]$ 定义域 $\Rightarrow$ 解 $a \le g(x) \le b$；
  4. 已知 $f[g(x)]$ 定义域，求 $f(x)$ 定义域 $\Rightarrow$ 先求 $g(x)$ 在给定区间上的值域。
  5. 反函数相关问题中的定义域处理：
  6. 反函数的存在条件：原函数必须是一一映射，通常指单调函数。
  7. 求反函数时，先由 $y=f(x)$ 反解 $x$，交换 $x,y$ 得 $y=f^{-1}(x)$，并注明反函数的定义域（即原函数的值域）。
  8. 选择题中，可借助原函数的定义域和值域直接排除选项，如题中原函数 $x\le0$ 且值域 $y\ge0$，则反函数定义域 $x\ge0$，值域 $y\le0$，快速锁定答案。

高频易错

  • 忽略定义域变化：进行代数变形（平方、开方、消去公因式等）时，可能扩大或缩小定义域，此类变形务必检验等价性。
  • 反函数定义域写错：常见错误是直接将原函数的定义域当作反函数定义域，或者忘记转换。正确做法：反函数定义域 $=$ 原函数值域。
  • 实际情境忽视：如长度、面积等应用题，自变量取值必须符合实际。
  • 复合函数定义域混淆：将 $f[g(x)]$ 的定义域错误理解为 $g(x)$ 的定义域。
  • 结果表示不规范：漏写或错写端点，用“或”与“且”混淆。

代表题精讲

题目：函数 $y=-\sqrt{-x}\ (x\le0)$ 的反函数是（ ）
A. $y=x^2\ (x\ge0)$
B. $y=-x^2\ (x\ge0)$
C. $y=x^2\ (x\le0)$
D. $y=-x^2\ (x\le0)$

思路：利用原函数与反函数的定义域、值域互换关系直接排除，不必完全求出反函数表达式。先看原函数定义域 $x\le0$，其值域由解析式 $-\sqrt{-x}$ 得 $y\le0$？需细算：当 $x\le0$，$-x\ge0$，$\sqrt{-x}\ge0$，故 $-\sqrt{-x}\le0$，值域 $y\le0$。因此反函数定义域为 $x\le0$，值域为 $y\le0$？等等，原函数值域是反函数定义域，原函数定义域是反函数值域。原函数 $x\le0$，$y\le0$。则反函数应为 $x\le0$ 且 $y\le0$。但观察选项，A、B 定义域 $x\ge0$，C、D 定义域 $x\le0$。那么反函数定义域应是原函数值域 $y\le0$，所以反函数定义域 $x\le0$，排除 A、B。再看值域：反函数值域应是原函数定义域 $x\le0$，即反函数的 $y\le0$。C 是 $y=x^2\ge0$，不符；D 是 $y=-x^2\le0$，符合。故选 D。

更严谨的做法：反解求反函数。由 $y=-\sqrt{-x}$ 得 $\sqrt{-x}=-y$，两边平方 $-x=y^2$，即 $x=-y^2$。交换 $x,y$：$y=-x^2$。再求原函数值域：$x\le0$ 时 $y\le0$，所以反函数定义域 $x\le0$。得 $y=-x^2\ (x\le0)$。

步骤： 1. 确定原函数定义域 $x\le0$，值域：$\sqrt{-x}\ge0 \Rightarrow y=-\sqrt{-x}\le0$。
2. 根据反函数定义，其定义域为原函数值域 $x\le0$，值域为原函数定义域 $y\le0$。
3. 观察选项，只有 D 同时满足定义域 $x\le0$ 和表达式 $y=-x^2$ 产生的值域 $y\le0$。
4. 或者直接推导反函数解析式：从 $y=-\sqrt{-x}$ 解出 $x=-y^2$，互换变量得 $y=-x^2$，再限定定义域为 $x\le0$。

点评/变式：本题的核心是利用定义域与值域的互换快速排除，这是反函数选择题的常见技巧。变式训练：若原函数为 $y=\sqrt{x+1}\ (x\ge -1)$，求其反函数并注明定义域。注意平方变形后定义域的变化。
