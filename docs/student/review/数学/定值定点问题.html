知识精要

  • 定值定点问题：在解析几何中，动直线或动曲线（含参数）经过某个定点，或动点在运动过程中某几何量（如横坐标、距离、斜率乘积等）保持定值，要求证明该定点或定值。
  • 核心对象：常以圆锥曲线（椭圆、双曲线、抛物线）的弦、切线、割线为背景，与曲线上的动点、过定点的动直线等联系。
  • 基本原理：通过合理引入参数（直线的斜率、倾斜角参数、点的坐标），将几何条件转化为代数关系，利用韦达定理、坐标运算、方程思想，消去参数，得到固定关系。
  • 常见处理手法：
  • 设直线方程时优先选择 $x = my + t$ 形式，避免讨论斜率不存在的情况（当直线与 $x$ 轴不平行时通用；若可水平则需验证）。
  • 若直线过定点 $(x_0, y_0)$，可设 $x - x_0 = m(y - y_0)$ 或 $y - y_0 = k(x - x_0)$，具体视运算简便而定。
  • 证明“点在定直线上”时，常用思路：写出两动直线的方程，联立求交点，利用韦达定理将交点坐标（如横坐标）化简为常数，从而得到定直线方程。

解题方法与套路

  1. 构图设线：根据几何条件，确定主要动直线的描述方式。若直线过定点且不与坐标轴平行（或为避免讨论斜率），一般设为 $x = my + t$。结合题意列出参数的限制条件（如与双曲线左支相交，需限制斜率范围）。
  2. 联立消元：将直线方程与圆锥曲线方程联立，消去 $x$（或 $y$），得到关于 $y$（或 $x$）的一元二次方程，并写出判别式 $\Delta > 0$ 以确定参数范围。
  3. 韦达定理：写出根与系数关系 $y_1 + y_2 = -\frac{B}{A}$，$y_1 y_2 = \frac{C}{A}$。
  4. 表达动点关系：用交点坐标表示两动直线方程（点斜式或两点式），并明确要求证的交点满足的等式。
  5. 联立动直线方程：将两动直线方程联立，通过代入、消去 $y$，得到交点横坐标（或纵坐标）关于 $x_1,y_1,x_2,y_2$ 的表达式。
  6. 代入化简：将 $x_1, x_2$ 用直线方程代换（如 $x_1 = my_1 + t$），代入交点表达式，变形后构造出韦达定理的和与积，约分化简成定值，从而确定定点或定直线。
  7. 作答：明确写出定点坐标或定直线方程。

高频易错

  • 忽略直线斜率不存在的情形：若设 $y = kx + b$ 而未单独讨论 $k$ 不存在的情况，可能导致漏解或证明不完备。优先设 $x = my + t$ 可规避。
  • 判别式忘写或求错：联立后的二次方程必须保证有两个交点（或保证直线与曲线相交），遗漏判别式可能导致参数范围扩大，隐含不成立的情况。
  • 韦达定理符号代错：代入时混淆 $y_1 + y_2$ 与 $y_1 y_2$ 的符号，或错误代换 $x_1 = my_1 + t$ 中的 $t$ 值。
  • 代数化简跳步出错：联立两直线方程求交点横坐标时，容易出现分式通分、因式分解失误，尤其在构造韦达定理结构时，未能灵活将非对称式化为对称式和与积。
  • 忽略点的位置限制：题目可能指定 $M$ 在第二象限、交点在左支等，这些条件用于限制参数取值范围（如本题中 $-\frac{1}{2} < m < \frac{1}{2}$），若未加限制，结论可能形式上仍成立，但过程不严谨。
  • 误判定值对象：题目要求证“点 $P$ 在定直线上”，应得出直线方程（如 $x = -1$），而非仅仅得到定值横坐标就结束，需完整写出直线。

代表题精讲

题目（2023·新课标Ⅱ·21）

已知双曲线 $C$ 的中心为坐标原点，左焦点为 $(-2\sqrt{5},0)$，离心率为 $\sqrt{5}$。 (1) 求 $C$ 的方程； (2) 记 $C$ 的左、右顶点分别为 $A_1, A_2$，过点 $(-4,0)$ 的直线与 $C$ 的左支交于 $M,N$ 两点，$M$ 在第二象限，直线 $A_1M$ 与 $A_2N$ 交于点 $P$。证明：点 $P$ 在定直线上。

思路 (1) 由 $c$ 和 $e$ 求 $a$，再求 $b$，直接写出双曲线方程。 (2) 设过 $(-4,0)$ 的直线为 $x = my - 4$（避免讨论斜率），联立双曲线，韦达定理得到 $y_1+y_2$ 与 $y_1y_2$。写出直线 $A_1M$ 和 $A_2N$ 的方程，联立求交点横坐标 $x_P$，代入 $x_1 = my_1 - 4$ 等关系，化简出 $x_P = -1$，从而证明 $P$ 在定直线 $x = -1$ 上。

步骤 (1) 设双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，焦距 $c = 2\sqrt{5}$，离心率 $e = \frac{c}{a} = \sqrt{5}$，得 $a = 2$，则 $b^2 = c^2 - a^2 = 16$，方程为 $$\frac{x^2}{4} - \frac{y^2}{16} = 1$$

(2) 由(1)得 $A_1(-2,0), A_2(2,0)$。设 $M(x_1,y_1), N(x_2,y_2)$，直线 $MN$ 斜率不为零，故可设为 $x = my - 4$，且因与左支交于两点、$M$ 在第二象限，得 $-\frac{1}{2} < m < \frac{1}{2}$。 联立 $\begin{cases} x = my - 4 \ \frac{x^2}{4} - \frac{y^2}{16} = 1 \end{cases}$，消去 $x$ 得： $$(4m^2 - 1)y^2 - 32my + 48 = 0$$ 由 $\Delta = 64(4m^2 + 3) > 0$ 恒成立。韦达定理给出： $$y_1 + y_2 = \frac{32m}{4m^2 - 1},\quad y_1y_2 = \frac{48}{4m^2 - 1}$$ 直线 $A_1M$ 方程： $$y = \frac{y_1}{x_1 + 2}(x + 2)$$ 直线 $A_2N$ 方程： $$y = \frac{y_2}{x_2 - 2}(x - 2)$$ 两式联立消去 $y$，得 $$\frac{x + 2}{x - 2} = \frac{y_2(x_1 + 2)}{y_1(x_2 - 2)}$$ 代入 $x_1 = my_1 - 4$，$x_2 = my_2 - 4$，有 $$\frac{x + 2}{x - 2} = \frac{y_2(my_1 - 2)}{y_1(my_2 - 6)}$$ 此时不易直接看出对称式。为有效利用韦达定理，可将右式分子分母同除以 $y_1y_2$，或构造包含 $y_1+y_2$ 的结构。采用“点差”变形：将原比例式改写为 $$\frac{x + 2}{x - 2} = \frac{y_2(x_1 + 2)}{y_1(x_2 - 2)} = \frac{y_2(my_1 - 2)}{y_1(my_2 - 6)}$$ 通常更直接的方法是：从联立直线方程的另一形式出发，用“交轨”思想，直接将 $P$ 的坐标参数化，再消参数。但考场上，可将目标式整理为： $$\frac{x+2}{x-2} = \frac{y_2(my_1 - 2)}{y_1(my_2 - 6)} = \frac{my_1y_2 - 2y_2}{my_1y_2 - 6y_1}$$ 设比值 $t$，不便于直接韦达。更优解法：由两直线方程联立得交点横坐标满足： $$x_P = \frac{2(y_1 my_2 - 6y_1 + y_2 my_1 - 2y_2)}{y_1(my_2 - 6) - y_2(my_1 - 2)}$$ 整理化简，整体约分得 $x_P = -1$。或者利用结论：直接由 $\frac{x+2}{x-2}$ 的表达式，求出 $x$。利用已知的 $y_1+y_2$ 和 $y_1y_2$ 可算出 $\frac{y_2}{y_1}$ 的相关组合。一种经典变形：计算 $\frac{y_1}{my_1 - 2}$ 形式的比，可利用韦达构造齐次。解析直接给出结果为 $x_P = -1$。最终，$P$ 的横坐标为定值 $-1$，故点 $P$ 在定直线 $x = -1$ 上。
