实轴长

知识精要

  • 双曲线的实轴：双曲线与实轴所在直线相交所得两个顶点间的线段称为实轴，长度记为 $2a$；$a$ 为实半轴长。
  • 等轴双曲线：实轴长与虚轴长相等的双曲线。中心在原点、焦点在 $x$ 轴上的标准方程为
    $$x^2 - y^2 = a^2 \quad (a>0)$$
    此时实轴在 $x$ 轴上，实轴长 $2a$，虚轴长也为 $2a$。
  • 抛物线的准线：对抛物线 $y^2 = 2px\ (p>0)$，准线方程为 $x = -\frac{p}{2}$。
    本题 $y^2 = 16x$ 中 $2p=16 \Rightarrow p=8$，准线为 $x=-4$。
  • 对称交点与弦长：若直线 $x = x_0$ 与等轴双曲线交于 $A(x_0, y_0)$，$B(x_0, -y_0)$，则 $|AB| = 2|y_0|$。

解题方法与套路

利用抛物线、等轴双曲线方程求实轴长的通用步骤： 1. 定型设参：根据焦点位置设等轴双曲线方程。焦点在 $x$ 轴设 $x^2 - y^2 = a^2$，焦点在 $y$ 轴设 $y^2 - x^2 = a^2$。 2. 求相关直线：求出已知抛物线（或其它曲线）的准线、渐近线等直线方程，一般可得垂直于坐标轴的直线 $x = m$ 或 $y = n$。 3. 联立求交点（含参）：将直线方程代入双曲线方程，解出交点坐标（用 $a$ 表示纵/横坐标的绝对值）。 4. 利用弦长列方程：根据条件中的弦长（如 $|AB|=l$），建立关系 $2|y_0| = l$ 或 $2|x_0| = l$，解出交点坐标的具体值。 5. 回代求 $a$ 及 $2a$：将坐标代入双曲线方程，求出 $a^2$，进而得到实轴长 $2a$。

高频易错

  • 混淆 $a$ 与 $2a$：求出 $a$ 后忘记题目问的是实轴长 $2a$，导致误选半轴长的选项。
  • 准线方程错记：$y^2 = 2px$ 的准线是 $x = -\frac{p}{2}$，而非 $x = \frac{p}{2}$ 或 $x = -p$。需先正确写出 $p$ 再代入。
  • 等轴双曲线方程设错：看到“焦点在 $x$ 轴”就设为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，忘记等轴条件 $a = b$，应直接设 $x^2 - y^2 = a^2$，减少参数。
  • 坐标代入计算错误：将 $A(m, y_0)$ 代入 $x^2 - y^2 = a^2$ 时，误算为 $m^2 - y_0^2$ 的符号或数值，建议先平方再相减。
  • 弦长理解偏差：若 $A, B$ 关于 $x$ 轴对称且横坐标相同，$|AB|$ 为两点纵坐标之差的绝对值 $2|y_0|$，不要误用横坐标之差。

代表题精讲

代表题1（2012 全国大纲卷 文10）
题目：等轴双曲线 $C$ 的中心在原点，焦点在 $x$ 轴上，$C$ 与抛物线 $y^2 = 16x$ 的准线交于 $A, B$ 两点，$|AB| = 4\sqrt{3}$，求 $C$ 的实轴长。

思路：设出等轴双曲线标准方程；写出抛物线准线；利用对称性表达 $A, B$ 坐标；由弦长得纵坐标，代入双曲线求 $a$，最后得 $2a$。

步骤： 1. 设等轴双曲线为 $x^2 - y^2 = a^2\ (a>0)$。
2. 抛物线 $y^2 = 16x$ 的准线为 $x = -4$。
3. 由对称性，可设 $A(-4, y_0),\; B(-4, -y_0)$，则 $|AB| = 2|y_0| = 4\sqrt{3} \Rightarrow |y_0| = 2\sqrt{3}$，取 $y_0 = 2\sqrt{3}$。
4. 将 $A(-4, 2\sqrt{3})$ 代入双曲线：
$$(-4)^2 - (2\sqrt{3})^2 = a^2 \ \Rightarrow\ 16 - 12 = a^2\ \Rightarrow\ a^2 = 4.$$
得 $a = 2$（$a>0$）。
5. 实轴长 $= 2a = 4$。

点评/变式： - 本题关键是把“等轴”转化为 $a = b$，直接用单参数方程，避免 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的复杂形式。 - 变式训练：若焦点在 $y$ 轴，设 $y^2 - x^2 = a^2$；若与抛物线的焦点弦相交，同样利用坐标对称性列方程，策略一致。 - 易错提醒：常有同学求出 $a=2$ 即选 A，忽略了实轴长是 $2a$；另有同学将准线错写为 $x=4$，导致整题错误。牢记抛物线标准形式与 $p$ 的几何意义。
