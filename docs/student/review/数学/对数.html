对数

考点对数权重7真题数2学科数学父主题函数与导数

考点定位

  • 父主题：函数与导数
  • 权重 weight：7
  • 真题数：2；年份跨度：2008–2013
  • 出现题位：选择5 选择8
  • 难度分布：易1 中1

知识精要

  • 定义：若 $a^b=N$（$a>0, a \neq 1$），则 $b=\log_a N$。特别地，$\log_a 1=0$，$\log_a a=1$。
  • 运算性质（$a>0, a \neq 1, M,N>0$）：
    • $\log_a(MN)=\log_a M + \log_a N$
    • $\log_a\frac{M}{N}=\log_a M - \log_a N$
    • $\log_a M^n = n\log_a M$
  • 换底公式：$\log_a b = \frac{\log_c b}{\log_c a}$（$a,b,c>0，a,c \neq 1$）。常用推论：$\log_a b = \frac{1}{\log_b a}$；$\log_{a^n} b^m = \frac{m}{n}\log_a b$。
  • 单调性：当 $a>1$ 时，$y=\log_a x$ 在 $(0, +\infty)$ 上单调递增；当 $0<a<1$ 时，$y=\log_a x$ 单调递减。
  • 数值比较关键点：对数符号由底数与真数是否大于 1 决定。$\log_a b>0$ 当且仅当 $(a-1)(b-1)>0$；$\log_a b<0$ 当且仅当 $(a-1)(b-1)<0$。常借助中间值 $0$ 和 $1$ 进行过渡比较。

解题方法与套路

  1. 化同底统一标准：比较底数不同的对数大小时，首选换底公式将所有对数转化为同底（常取 $10$ 或 $e$），再用函数单调性求解。
  2. 寻找中间值“0”与“1”：当对数无法直接化为同底时，判断各自与 $0$ 或 $1$ 的大小关系。$\log_a b$ 与 $1$ 的比较相当于直接比较真数 $b$ 与底数 $a$ 的大小。
  3. 换底收放法：利用换底公式将目标对数拆解为乘积或分式，再结合已知条件进行分别比较。
  4. 作差/作商法：对于结构相似的对数表达式，可尝试作差并化为积商形式的对数，或因式分解后判断符号；作商时结合换底公式与不等号方向推理。
  5. 中间值桥接法（放大缩小）：将复杂对数通过换底或运算写成已知范围值的组合，应用于链条式不等关系的判断。

高频易错

  • 忽略底数范围致单调性误用：未先判别底数 $a>1$ 还是 $0<a<1$ 就直接套用单调性，导致比较方向完全相反。
  • 直接比较真数大小：误以为“真数大则对数大”，忘记了底数的影响。必须是同底且底数大于 $1$ 时才成立。
  • 对数自身正负性质混淆：（$\log_3 2$ 是小于 $1$ 的正数，$\log_5 2$ 也是正数）同真数不同底数时，误以为底数越大值越大。实则若 $\log_a 2 > \log_b 2 > 0$，可推出 $b>a>1$ 或 $0<a<b<1$。
  • 忽视定义域要求：做换底或变形时未注意真数必须恒大于 $0$，以及在变量 $x$ 处于不同区间时，对数值符号及幂次变形的方向会受影响（如 $x \in (0,1)$ 时，$\ln x <0$，此时 $2\ln x < \ln x$，$\ln^3 x$ 的符号与大小需结合负值仔细分析）。

代表题精讲

代表题1：2013-文-08

题目：已知 $a=\log_3 2$，$b=\log_5 2$，$c=\log_2 3$，比较 $a,b,c$ 的大小。 思路：$c$ 明显大于 $1$，$a$ 和 $b$ 均属于 $(0,1)$。问题的核心在于比较 $a$ 与 $b$ 的大小。由于真数相同而底数不同，可采用换底公式化为同底分数的倒数来比较，或转换为同底对数。 步骤： 1. 粗分离：$c=\log_2 3 > \log_2 2 = 1$；$0<a<1$，$0<b<1$。故 $c$ 最大。 2. 细比较：比较 $a$ 与 $b$。 法一（换底倒数法）：$a = \frac{1}{\log_2 3}$，$b = \frac{1}{\log_2 5}$。因 $y=\log_2 x$ 单调递增，$\log_2 3 < \log_2 5$，取倒数得 $\frac{1}{\log_2 3} > \frac{1}{\log_2 5}$，即 $a>b$。 法二（换底相同真数法）：$a=\frac{\lg 2}{\lg 3}$，$b=\frac{\lg 2}{\lg 5}$。分子相同，分母 $\lg 3 < \lg 5$，故 $a>b$。 3. 结论：$c>a>b$。选 D。 点评/变式：同真数对数比较通用方法化为倒数再比，切记当 $a,b>1$ 时结论依然成立，即 $\log_3 2 > \log_5 2$。推广：若 $p>q>1, m>1$，则 $\log_p m < \log_q m$。

代表题2：2008-文-05

题目：设 $x \in (e^{-1}, 1)$，$a=\ln x$，$b=2\ln x$，$c=\ln^3 x$，比较 $a,b,c$ 的大小。 思路：先由 $x$ 的取值范围确定 $\ln x$ 的符号及大致范围，再定性判断各表达式经过乘除运算后的数值大小变化。 步骤： 1. 定基调：由 $e^{-1} < x < 1$ 得 $-1 < \ln x < 0$，即 $\ln x$ 是介于 -1 和 0 的负数。 2. 析差值：$b-a = (2\ln x) - (\ln x) = \ln x < 0$，故 $b < a$。 3. 析乘方：$c=\ln^3 x = (\ln x)^3$。由于 $\ln x \in (-1, 0)$，其三次方绝对值小于一次方，且仍为负数。 计算 $c-a = \ln^3 x - \ln x = \ln x(\ln^2 x - 1)$。 因为 $-1<\ln x<0$，$\ln x$ 为负； $\ln^2 x \in (0,1)$，故 $(\ln^2 x - 1)$ 为负。负乘负得正，故 $c-a > 0 \implies c > a$。 4. 结论：$c > a > b$。选 C。 点评/变式：处理 0 到 1 区间的变量幂次极易出错。牢记口诀“大零小一，越乘越小”。负值区间内绝对值与大小是相反的：$-0.2 > -0.8$，平方后 $0.04 < 0.64$。此类题可用特值法快速验证，取 $x=e^{-0.5}$，则 $a=-0.5, b=-1, c=-0.125$ 直接得解。
