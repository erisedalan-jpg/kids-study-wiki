平方关系

考点平方关系权重7真题数1学科数学父主题三角函数

考点定位

  • 父主题：三角函数
  • 权重 weight：7
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择3
  • 难度分布：易1

知识精要

  • 平方关系：$\sin^2\alpha + \cos^2\alpha =1$
    变形：$\sin^2\alpha = 1-\cos^2\alpha$，$\cos^2\alpha = 1-\sin^2\alpha$
    可导出 $1+\tan^2\alpha = \sec^2\alpha$，$1+\cot^2\alpha = \csc^2\alpha$（要求角使函数有意义）
  • 商数关系：$\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha}$，$\cot\alpha = \dfrac{\cos\alpha}{\sin\alpha}$
  • 符号规则：由角所在象限决定 $\sin\alpha,\cos\alpha$ 正负。
    如 $\cot A<0$ 且 $A\in(0,\pi)$，则 $A$ 为钝角，$\cos A<0,\sin A>0$。

解题方法与套路

  1. 定象限，判符号：根据已知三角函数值的正负及角的范围，确定目标函数值的符号。
  2. 化弦为切或化切为弦：利用商数关系将 $\cot A$（或 $\tan A$）表为 $\dfrac{\cos A}{\sin A}$，得到 $\sin A$ 与 $\cos A$ 的比例式。
  3. 联立平方关系：设 $\sin A = k\cdot\text{比例}$，$\cos A = k\cdot\text{比例}$，代入 $\sin^2 A+\cos^2 A=1$ 求 $k^2$。
  4. 定值取舍：结合第1步的符号，对开方结果取正确的值。
  5. 特殊公式速解（选用）：若熟练 $1+\cot^2 A=\csc^2 A$，可先求 $\csc A$（带符号），再求 $\sin A$，最后得 $\cos A = \cot A \cdot \sin A$。

高频易错

  • 忽略角范围导致符号错误：看到 $\cot A$ 为负，直接推 $\cos A$ 与 $\sin A$ 异号，但三角形内角 $A\in(0,\pi)$，$\sin A>0$ 恒成立，只能 $\cos A<0$。不判断直接开方正值会误选 A、B。
  • 开方忘加正负号：由 $\sin^2 A+\cos^2 A=1$ 求值时，开方应写 $|\cos A|$，未结合象限去绝对值则漏掉负号。
  • 商数关系倒置：$\cot A = \dfrac{\cos A}{\sin A}$，警惕误写为 $\dfrac{\sin A}{\cos A}$。
  • 联立时运算失误：将 $\sin A = -\dfrac{5}{12}\cos A$（比例）代入平方关系时系数平方容易算错，建议分步计算。

代表题精讲

题目：已知 $\triangle ABC$ 中，$\cot A = -\dfrac{12}{5}$，则 $\cos A =$（　）
A. $\dfrac{12}{13}$　B. $\dfrac{5}{13}$　C. $-\dfrac{5}{13}$　D. $-\dfrac{12}{13}$

思路：先由 $\cot A<0$ 及三角形内角范围确定 $A$ 为钝角，得 $\cos A<0$，排除 A、B。再由 $\cot A = \frac{\cos A}{\sin A}$ 得 $\sin A$ 与 $\cos A$ 的比例，联立平方关系解出 $\cos A$。

步骤：
1. $\because A\in(0,\pi),\cot A=-\frac{12}{5}<0 \Rightarrow A\in(\frac{\pi}{2},\pi)$，于是 $\cos A<0$，排除 A、B。
2. 由 $\cot A=\frac{\cos A}{\sin A}=-\frac{12}{5}$，得 $\sin A = -\frac{5}{12}\cos A$。
3. 代入 $\sin^2 A+\cos^2 A=1$：
$$\left(-\frac{5}{12}\cos A\right)^2 + \cos^2 A =1 \Rightarrow \frac{25}{144}\cos^2 A + \cos^2 A =1$$
$$\frac{169}{144}\cos^2 A =1 \Rightarrow \cos^2 A = \frac{144}{169}$$
4. 开方得 $|\cos A| = \frac{12}{13}$，结合 $\cos A<0$，得 $\cos A = -\frac{12}{13}$。
故选 D。

点评/变式
- 也可用 $1+\cot^2 A=\csc^2 A$：$\csc^2 A = 1+\frac{144}{25}=\frac{169}{25}$，由 $A$ 为钝角，$\sin A>0$，故 $\csc A = \frac{13}{5}$，得 $\sin A = \frac{5}{13}$，进而 $\cos A = \cot A \cdot \sin A = -\frac{12}{5}\times\frac{5}{13}=-\frac{12}{13}$。
- 变式：若题设给出 $\tan A = \frac{3}{4}$ 且 $A$ 为第三象限角，求 $\cos A$。思路一致：判符号为负，再由 $\sin A = \frac{3}{4}\cos A$ 代入平方关系。
