平方运算

  • 出现题位：填空15
  • 难度分布：中1

知识精要

  • 同角平方关系：对任意角 $\theta$，恒有 $\sin^2\theta + \cos^2\theta = 1$。
  • 两角和与差的正弦公式： $$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta.$$
  • 平方运算的适用条件：当已知两个含 $\sin$ 和 $\cos$ 的线性等式，且需要求 $\sin(\alpha\pm\beta)$ 或 $\cos(\alpha\pm\beta)$ 的值时，可将等式两边分别平方，通过交叉项构造和差公式，并利用平方和关系消元。

解题方法与套路

  1. 识别结构：题目给出形如“$A\sin\alpha + B\cos\beta = C$”与“$D\cos\alpha + E\sin\beta = F$”的两个等式，所求为 $\sin(\alpha\pm\beta)$ 或 $\cos(\alpha\pm\beta)$。
  2. 两边平方：将两个等式分别两边平方，得到两个新等式，保留所有交叉项（如 $2\sin\alpha\cos\beta$、$2\cos\alpha\sin\beta$）。
  3. 式子相加（或相减）：通过相加（或相减）使 $\sin^2\alpha + \cos^2\alpha$ 及 $\cos^2\beta + \sin^2\beta$ 合并为常数，并让交叉项组合成两角和差公式的整体形式。
  4. 代公式求值：将交叉项组合用 $\sin(\alpha\pm\beta)$ 或 $\cos(\alpha\pm\beta)$ 表示，整理即得所求值。

高频易错

  • 漏乘交叉项系数：平方展开时漏掉 $2ab$ 项，导致无法构造和差公式。
  • 混淆平方和：误以为 $\sin^2\alpha + \sin^2\beta = 1$ 或错误处理不同角的平方和，必须各自配对为 1。
  • 符号错误：两等式相加或相减时，交叉项前的符号要与公式匹配；尤其当题目为 $A\sin\alpha - B\cos\beta$ 等含负号时，注意交叉项正负。
  • 忽略角的一致性：所求角为 $\alpha+\beta$ 时，交叉项必须恰好为 $\sin\alpha\cos\beta \pm \cos\alpha\sin\beta$ 的形式，需确认哪个式子提供哪一项。

代表题精讲

题目：已知 $\sin\alpha + \cos\beta = 1$，$\cos\alpha + \sin\beta = 0$，求 $\sin(\alpha + \beta)$。

思路：两个等式均含异名三角函数，可直接平方后相加，利用 $\sin^2\theta+\cos^2\theta=1$ 消去平方项，留下的交叉项恰好为 $\sin(\alpha+\beta)$ 的展开式。

步骤： 1. 将 $\sin\alpha + \cos\beta = 1$ 两边平方： $$\sin^2\alpha + 2\sin\alpha\cos\beta + \cos^2\beta = 1 \quad ①$$ 2. 将 $\cos\alpha + \sin\beta = 0$ 两边平方： $$\cos^2\alpha + 2\cos\alpha\sin\beta + \sin^2\beta = 0 \quad ②$$ 3. ① + ② 得： $$(\sin^2\alpha + \cos^2\alpha) + (\cos^2\beta + \sin^2\beta) + 2(\sin\alpha\cos\beta + \cos\alpha\sin\beta) = 1$$ 由平方关系得： $$1 + 1 + 2\sin(\alpha+\beta) = 1$$ 4. 化简：$2 + 2\sin(\alpha+\beta) = 1$，即 $\sin(\alpha+\beta) = -\dfrac12$。

点评/变式：本题典型地展示了“平方相加”构造和角公式的套路。若所求为 $\cos(\alpha-\beta)$，则可将交叉项组合为 $\cos\alpha\cos\beta + \sin\alpha\sin\beta$，灵活选用加减。注意平方前须观察交叉项的组合方向，必要时可在平方前将等式移项或换序，以匹配所求角参数。
