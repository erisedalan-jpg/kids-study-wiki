知识精要

平移法是求解异面直线所成角的通法，核心是通过直线平移将空间角转化为平面相交直线的角，从而在三角形中计算。其依据是等角定理：空间中如果两个角的两边分别对应平行，且方向相同，则这两个角相等或互补。对于给定两条异面直线 $a$ 与 $b$，常用步骤为取一条直线（或两条）平移至某点，使得两条直线相交，所成锐角（或直角）即为异面直线所成的角，范围是 $\left(0, \frac{\pi}{2}\right]$。若平移后得到的角为钝角，则取其补角作为异面直线夹角。正方体中常利用对面平行、中位线以及特殊点的连线实现平移，如 $AD_1\parallel BC_1$，$B_1D_1\parallel BD$ 等。

解题方法与套路

  1. 选择平移基准点：观察两条异面直线，抓住其中一条直线的端点或中点，结合几何体的特征（如正方体棱平行关系），寻找一条与其中一条异面直线平行的、且与另一条异面直线能构成三角形边的连线。
  2. 作出平移辅助线，明确所求角：将目标线平移到合适位置，使两条直线交于一点。明确平移后形成的角（或其补角）即为所求异面直线所成的角。
  3. 证明垂直或利用长度关系简化：对于含有垂直关系的几何体（如正方体），优先证明平移后构成的三角形中是否存在直角三角形，可利用线面垂直定理（如正方体中体对角线、面对角线间的垂直关系）。
  4. 设棱长（或关键长度）并计算：设棱长为具体数值（如 $2$），便于计算各线段长度。若三角形可解，通过余弦定理或锐角三角函数（如正弦、正切）求角。若为直角三角形可直接利用边长比求角。
  5. 下结论：根据范围写出角的大小。

高频易错

  • 混淆角与补角：平移后得到的两条相交直线所成的角可能为异面直线所成角的补角，必须确认取锐角或直角。尤其在正方体等常见模型中，应验证三角形内角的范围。
  • 平移选择不当导致难以计算：不加选择地平移可能导致角度所在的三角形边太难求，优先平移到规则图形的特殊点（如中点、顶点）。
  • 棱长设定不当：设棱长为 $1$ 可能产生大量分数与根号，增加计算出错风险；设棱长为 $2$ 或 $2$ 的整数倍可使中点、对角线等长度保持整齐，减少计算压力。
  • 忽视垂直关系的证明：在正方体中用肉眼观察得出 $PC\perp PB$ 而未给出严谨推导（如利用线面垂直），可能失分。务必先证垂直再解直角三角形。
  • 漏用正方体结构性质：记错面对角线长与体对角线长，如将 $B_1D_1$ 的长度记错。

代表题精讲

题目 2021年理科数学第5题：在正方体 $ABCD{-}A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 的中点，求直线 $PB$ 与 $AD_1$ 所成的角。

思路
将 $AD_1$ 平移到与 $PB$ 相交的位置，利用 $AD_1 \parallel BC_1$，则 $\angle PBC_1$（或其补角）即为所求。连接 $PC_1$，通过证明 $PC_1\perp PB$ 得到直角三角形，进而利用三角函数求角。

步骤
1. 连接 $BC_1$，因为 $AD_1 \parallel BC_1$，所以 $PB$ 与 $AD_1$ 所成角等于 $PB$ 与 $BC_1$ 所成角，即 $\angle PBC_1$ 或其补角。
2. 连接 $PC_1$，在正方体中 $BB_1 \perp$ 平面 $A_1B_1C_1D_1$，$PC_1 \subset$ 平面 $A_1B_1C_1D_1$，所以 $BB_1 \perp PC_1$；又 $P$ 为 $B_1D_1$ 中点，在正方形 $A_1B_1C_1D_1$ 中，$PC_1 \perp B_1D_1$，且 $B_1D_1\cap BB_1=B_1$，故 $PC_1 \perp$ 平面 $PBB_1$，于是 $PC_1 \perp PB$。
3. 设正方体棱长为 $2$，则 $BC_1 = 2\sqrt{2}$，$PC_1 = \frac{1}{2}\,B_1D_1 = \sqrt{2}$。
4. 在 $\text{Rt}\triangle PBC_1$ 中，$\sin \angle PBC_1 = \dfrac{PC_1}{BC_1} = \dfrac{\sqrt{2}}{2\sqrt{2}} = \dfrac{1}{2}$，又 $\angle PBC_1$ 为锐角，得 $\angle PBC_1 = \dfrac{\pi}{6}$。
5. 故直线 $PB$ 与 $AD_1$ 所成角为 $\dfrac{\pi}{6}$。

点评/变式
本题为已知正方体中点和线关系求异面直线成角的典型题，平移法是首选。解题时棱长设为 $2$ 使计算更整，避免了分数。证明 $PC_1 \perp PB$ 是关键跳板，体现了“先垂直、后计算”的安全模式。变式可将中点移至面对角线其他等分点，或改为求 $PB$ 与 $A_1C_1$ 所成角，平移策略类似，此时可能需构造一般三角形用余弦定理求解，注意异面直线角的范围为 $\left(0,\frac{\pi}{2}\right]$。
