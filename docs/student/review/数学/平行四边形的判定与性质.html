平行四边形的判定与性质

考点平行四边形的判定与性质权重5真题数1学科数学父主题平面几何

考点定位

  • 父主题：平面几何
  • 权重 weight：5
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：解答22
  • 难度分布：中1

知识精要

  • 平行四边形的定义：两组对边分别平行的四边形叫做平行四边形。
  • 平行四边形的性质：
  • 对边平行且相等：$AB \parallel CD$，$AD \parallel BC$；$AB = CD$，$AD = BC$。
  • 对角相等、邻角互补：$\angle A = \angle C$，$\angle B = \angle D$；$\angle A + \angle B = 180^\circ$。
  • 对角线互相平分：$OA = OC$，$OB = OD$。
  • 平行四边形是中心对称图形，对称中心是对角线的交点。
  • 平行四边形的判定（5种，任一组均可独立判定）：
  • 两组对边分别平行的四边形（定义判定）。
  • 两组对边分别相等的四边形。
  • 一组对边平行且相等的四边形。
  • 两组对角分别相等的四边形。
  • 对角线互相平分的四边形。
  • 中位线定理：三角形的中位线平行于第三边且等于第三边的一半。本题中 $DE \parallel BC$ 且 $DE = \frac 12 BC$，可推出 $DF \parallel BC$，为证平行四边形提供平行条件。
  • 圆中平行弦的性质：圆中两条平行弦所夹的弧相等。若 $CF \parallel AB$，则 $\overparen{AF} = \overparen{BC}$，从而弦 $AF = BC$，圆周角 $\angle BDC = \angle GBD$ 等，为相似三角形提供角的条件。

解题方法与套路

  1. 由平行逐步构造平行四边形：出现一组对边平行时，寻找另一组对边平行或平行且相等的关系。如利用三角形中位线得 $DF \parallel BC$，结合已知 $CF \parallel AB$ 直接判定四边形 $BDFC$ 是平行四边形，快速得到对边相等。
  2. 借助平行四边形转移线段关系：由平行四边形对边平行且相等，可将线段进行等量代换。如 $CF \parallel BD$ 且 $CF = BD$，结合 $AD = BD$ 得 $CF \parallel AD$ 且 $CF = AD$，顺势判定另一平行四边形 $ADCF$，将目标边 $CD$ 转化为 $AF$，再利用圆的性质与已知等弧联系。
  3. 证明线段相等优先构造平行四边形：当条件给出多组平行线时，可将所证线段置于平行四边形中，利用性质直接得等量。若需证 $CD = BC$，而 $BC$ 在圆中可与弧挂勾，便通过构造平行四边形将 $CD$ 转移到与圆相关的弦 $AF$ 上。
  4. 相似三角形的证明紧扣平行四边形带来的角相等：利用平行四边形的对边平行得内错角、同位角相等；利用圆中平行弦得等弧进而得等角（如 $\angle GBD = \angle BDC$），再结合平行线的同旁内角、对顶角等推理出两角对应相等，证得相似。

高频易错

  • 中位线应用不完整：仅由中点想中位线，却忽略需要“两个中点”才能得平行及倍半关系。本题 $D$、$E$ 分别为 $AB$、$AC$ 的中点，得 $DE \parallel BC$，进而 $DF \parallel BC$，如果搞混端点或错误使用“过一边中点平行另一边”的推论，容易丢失关键平行条件。
  • 平行四边形的判定条件混淆：仅有 $CF \parallel AB$ 和 $DF \parallel BC$ 时，错判为平行四边形 $BDFC$ 但忽略检查边是否对应。事实上 $DF$ 与 $BC$ 平行但 $DF$ 包含 $DE$，需要确认 $BDFC$ 的两组对边确实是 $BD$ 与 $CF$，$DF$ 与 $BC$。常犯错误是把 $DE \parallel BC$ 直接当作 $BD \parallel FC$ 的充分条件，缺一步推导。
  • 圆中平行弦性质提取角时漏掉等弧的“中间桥梁”：由 $CF \parallel AB$ 得到 $\overparen{AF} = \overparen{BC}$，若直接写 $\angle ACF = \angle BAC$ 而不通过等弧，可能用错角度。需要明确：平行弦所夹弧相等 → 所对圆周角相等。部分学生跳步导致角对应错误。
  • 证明相似时角对应乱序：第三小题中的 $\triangle BCD \sim \triangle GBD$，容易把 $\angle CDB$ 与 $\angle GBD$ 错配。应按照“等弧对等角”以及平行性质，厘清 $\angle BDC$ 与 $\angle GBD$ 的关系，按顶点对应写出相似。

代表题精讲

题目（2012 理 22）
如图，$D$、$E$ 分别为 $\triangle ABC$ 边 $AB$、$AC$ 的中点，直线 $DE$ 交 $\triangle ABC$ 的外接圆于 $F$、$G$ 两点，若 $CF \parallel AB$，证明：（1）$CD = BC$；（2）$\triangle BCD \sim \triangle GBD$。

思路
（1）中位线给出 $DF \parallel BC$，加上已知 $CF \parallel AB$ 可证四边形 $BDFC$ 为平行四边形，得到 $CF = BD$；又 $D$ 为中点得 $AD = BD$，故 $CF \parallel AD$ 且 $CF = AD$，判定 $ADCF$ 为平行四边形，得 $CD = AF$。再利用 $CF \parallel AB$ 得到圆中平行弦所夹弧相等 $\overparen{AF} = \overparen{BC}$，从而弦 $AF = BC$，最终得到 $CD = BC$。
（2）在第（1）问基础上，因为 $CD = BC$，所以 $\angle BDC = \angle DBC$；由 $CF \parallel AB$ 推得 $\overparen{AF} = \overparen{BC}$，这时 $\overparen{AF} = \overparen{BC} = \overparen{?}$ 需要结合图形，得到 $\angle GBD = \angle BDC$；再由 $BC = CD$ 得 $\angle CBD = \angle CDB$，进一步结合外角或对顶角找 $\angle BCD = \angle GDB$，即可对应相似。

步骤
（1）证明
- ∵ $D$、$E$ 分别为 $AB$、$AC$ 中点
$\therefore DE \parallel BC$，即 $DF \parallel BC$，且 $AD = DB$。
- 已知 $CF \parallel AB$，在四边形 $BDFC$ 中：
$DF \parallel BC$，$CF \parallel BD$（因为 $AB$ 包含 $BD$），
$\therefore$ 四边形 $BDFC$ 是平行四边形。
$\therefore CF = BD$。
- 又 $AD = DB$，故 $CF = AD$；同时 $CF \parallel AD$（均平行于 $AB$）。
- 在四边形 $ADCF$ 中，$CF \parallel AD$ 且 $CF = AD$，
$\therefore$ 四边形 $ADCF$ 是平行四边形。
$\therefore CD = AF$。
- 在圆中，$CF \parallel AB$，
$\therefore \overparen{AF} = \overparen{BC}$（平行弦所夹的弧相等）。
$\therefore AF = BC$。
- 综上，$CD = AF = BC$，即 $CD = BC$。

（2）证明
- 由 $CF \parallel AB$ 得 $\overparen{AF} = \overparen{BC}$，
则 $\angle GBD = \angle BDC$（$\angle GBD$ 是 $\overparen{AF}$ 所对圆周角？注意点 $G$ 的位置：$DE$ 交圆于 $F$、$G$，$G$ 在 $F$ 另一侧。实际上 $\overparen{BG}$ 等，但我们从等弧出发：$\overparen{AF} = \overparen{BC}$，可得 $\angle ADF = \angle BDC$？更简洁：在圆内接四边形或直接找对应角。常见解法：因为 $\overparen{AF} = \overparen{BC}$，所以 $\angle ACF = \angle BAC$，但我们需要联系 $\triangle BCD$ 与 $\triangle GBD$。观察图形，$\angle GBD$ 是弧 $GD$ 所对的圆周角？这里用标准答案路径：由（1）知 $CD = BC$，所以 $\angle BDC = \angle DBC$。又由 $CF \parallel AB$ 得 $\overparen{AF} = \overparen{BC}$，从而 $\angle GBD = \angle BDC$。因此 $\angle GBD = \angle BDC = \angle CBD$。还需再找一对等角：因为 $DE \parallel BC$，所以 $\angle GDB = \angle DBC$（内错角），而 $\angle DBC = \angle BDC$，即 $\angle GDB = \angle BDC$，这表明点 $G$、$D$、$C$ 构成圆上某关系，但我们要证 $\triangle BCD \sim \triangle GBD$。已得 $\angle GBD = \angle BDC$，$\angle GDB = \angle DBC$，满足两组角对应相等，故相似。具体： - 由 $DE \parallel BC$ 得 $\angle GDB = \angle DBC$。
- 由 $CF \parallel AB$ 和圆性质得 $\angle GBD = \angle BDC$。
$\therefore \triangle BCD \sim \triangle GBD$。

点评/变式
- 本题核心是“连环平行四边形”：先判定 $BDFC$，再利用中点等量转移到 $ADCF$，两次运用“一组对边平行且相等”，将看似无关的线段 $CD$ 与 $BC$ 联系起来。
- 圆中平行弦的等弧性质是跨模块考查的重点，常与相似、全等结合。变式训练可尝试：将中点改为三等分点，条件 $CF \parallel AB$ 变为 $CF$ 与 $AB$ 成特定角度，探究是否仍有类似结论。
- 证明相似时，特别注意角的寻找策略：先找已知线段相等带来的等腰三角形底角相等，再借助平行线、圆内接四边形补全另一组等角，避免错误对应顶点。
