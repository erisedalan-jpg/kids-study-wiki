  • 难度分布：中1

知识精要

  • 正方体的截面与表面展开：当半正多面体的所有顶点都在正方体表面上时，可在正方体的一个面或对角面上作出含所求棱长的平面图形，从而将空间关系转化为平面几何问题。
  • 等腰直角三角形：若直角边长为 $a$，则斜边长为 $\sqrt{2}a$；反之，若斜边长为 $c$，则直角边长为 $\frac{\sqrt{2}}{2}c$。本题中 $BG=GE$ 且 $\angle BGE=90^\circ$，直接应用于正方体表面的八边形转角处。
  • 对称性与相等关系：半正多面体具有高度对称性，正方体表面的截口图形关于正方体面对角线对称，由此得出线段相等的关键条件（如 $BG=GE=CH$），避免额外设元。
  • 方程建模：利用正方体棱长等于组成棱的几段线段之和（如 $CH+HG+CH=1$），结合几何关系列出关于未知棱长 $x$ 的方程，最终解出 $x=\sqrt{2}-1$。

解题方法与套路

  1. 识图并分层计数：对于多面体的面数，按特征层（如上、中、下）分别统计正多边形的个数，注意对称性以避免重复或遗漏。
  2. 空间定位，锁定关键截面：抓住“所有顶点都在正方体表面上”这一条件，将半正多面体的棱映射到正方体的面上，找到能同时包含正方体棱和所求棱长的平面图形。
  3. 抽象线段，设未知数：把半正多面体的棱长设为 $x$，在截面图中标出与 $x$ 相关的线段。
  4. 化归平面几何模型：通过做延长线、连接关键点，构造典型的平面图形（如等腰直角三角形、矩形），利用对称性得出线段相等关系和角度信息。
  5. 建立方程求解：用 $x$ 表示正方体棱长，根据“正方体棱长=1”列出等式，求解并化简（如分母有理化得到 $\sqrt{2}-1$）。
  6. 答案回代验证：检查所得棱长是否符合图形实际（正值且小于正方体棱长），并确认与面数无矛盾。

高频易错

  • 面数漏数或重数：未注意分层结构，错把同一层旋转对称的面算作同一面，或忽略中层侧面的正多边形。
  • 未能正确分离平面图形：空间想象不足，没有从正视、俯视或侧视角度提取出有效截面，误以为必须使用立体几何公式。
  • 等腰直角三角形的直角边与斜边混淆：把 $BE=x$ 当作直角边，导致 $BG$ 错误表示为 $\sqrt{2}x$；正确应为 $BG=GE=\frac{\sqrt{2}}{2}x$。
  • 忽略正方体棱上截口的对称分布：未能推出 $CH=BG$，漏掉一端或两端对称的截去部分，从而在列方程“正方体棱长=1”时丢项。
  • 只知公式不会迁移：对“$1= \sqrt{2}x + x$”这类线段和等式感到陌生，根源在于缺乏将多面体棱长与正方体棱长通过平面图形搭桥的意识。

代表题精讲

题目 2019-文-16

半正多面体由两种或以上的正多边形围成，图2中的半正多面体棱数为48，所有顶点都在棱长为1的正方体表面上。求该半正多面体共有多少个面，及其棱长。

思路

  • 面数：由对称性分层计数（上下层+中间层）。
  • 棱长：把半正多面体棱投射到正方体表面，构造等腰直角三角形，利用正方体棱长等于截断的各段之和列出方程。

步骤

  1. 计算面数
    观察图形对称性：第一层与第三层各有9个面（含正三角形与正八边形），共18个面；第二层（侧面一圈）共有8个面，总计 $18+8=26$ 个面。

  2. 几何情景转化
    在正方体的一个面上，半正多面体的顶点和棱形成正八边形。设半正多面体的棱长为 $x$，正方体棱长为 $1$。
    如图，延长线段 $BC$ 与 $FE$ 交于 $G$，延长 $BC$ 交正方体棱于点 $H$。由对称性知 $\triangle BGE$ 为等腰直角三角形，且 $AB=BE=x$，$BG=GE=CH$。

  3. 求关键线段长
    在 $\triangle BGE$ 中，斜边 $BE=x$，直角边 $BG=GE=\frac{\sqrt{2}}{2}x$，故 $CH=\frac{\sqrt{2}}{2}x$。
    又正八边形的边长等于半正多面体的棱长，即 $HG=x$。

  4. 建立并解方程
    正方体棱长由三部分组成：$CH+HG+CH=1$，即 $$\frac{\sqrt{2}}{2}x + x + \frac{\sqrt{2}}{2}x = 1$$ 合并得 $(\sqrt{2}+1)x=1$，解得 $$x=\frac{1}{\sqrt{2}+1}=\sqrt{2}-1$$

  5. 答案
    共 $26$ 个面，棱长为 $\sqrt{2}-1$。

点评/变式

  • 本题核心在于将看似复杂的半正多面体结构“降维”到正方体表面的平面图形，运用等腰直角三角形和线段和建立方程。这种“空间问题平面化”是高考立体几何与平面几何交汇的经典考法。
  • 变式训练：若将正方体棱长改为 $a$，该半正多面体棱长如何表示？（答案：$(\sqrt{2}-1)a$）若将半正多面体改为由正方形和正三角形围成的另一类半正多面体（如截角立方体），同样的方法是否适用？需关注对称性和截面正多边形的种类变化。
