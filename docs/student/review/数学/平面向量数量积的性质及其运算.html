平面向量数量积的性质及其运算

考点平面向量数量积的性质及其运算权重0真题数1学科数学父主题平面向量

考点定位

  • 父主题：平面向量
  • 权重 weight：0
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 数量积定义：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$（$\theta$ 为 $\vec{a},\vec{b}$ 的夹角）。
  • 模与数量积的关系：$|\vec{a}|^2=\vec{a}\cdot\vec{a}=\vec{a}^2$；同理 $|\vec{b}|^2=\vec{b}^2$。
  • 和差的模的平方： $$|\vec{a}\pm\vec{b}|^2 = (\vec{a}\pm\vec{b})^2 = |\vec{a}|^2 \pm 2\,\vec{a}\cdot\vec{b} + |\vec{b}|^2.$$ 这是解决由向量模长反求数量积的核心工具。
  • 适用条件：已知 $|\vec{a}\pm\vec{b}|$ 与 $|\vec{a}|,|\vec{b}|$ 中的部分信息，求数量积 $\vec{a}\cdot\vec{b}$，或利用该关系建立方程。

解题方法与套路

  1. 见到模的和差先平方
    将形如 $|\vec{a}\pm\vec{b}|=k$ 的式子两边同时平方，得到 $|\vec{a}|^2 \pm 2\vec{a}\cdot\vec{b} + |\vec{b}|^2 = k^2$。
  2. 构造方程组消元
    若题目同时给出 $|\vec{a}+\vec{b}|$ 与 $|\vec{a}-\vec{b}|$，则写出两个平方等式，通过相加或相减直接消去 $|\vec{a}|^2+|\vec{b}|^2$，解出 $\vec{a}\cdot\vec{b}$。
    常用同构式： $$|\vec{a}+\vec{b}|^2 + |\vec{a}-\vec{b}|^2 = 2(|\vec{a}|^2+|\vec{b}|^2),$$ $$|\vec{a}+\vec{b}|^2 - |\vec{a}-\vec{b}|^2 = 4\,\vec{a}\cdot\vec{b}.$$ 直接使用第二个公式可一步得到数量积。
  3. 注意符号对应
    展开时 $\pm$ 号的二倍项与平方结果严格对应，切勿混淆。

高频易错

  • 误将 $|\vec{a}\pm\vec{b}|$ 当成 $|\vec{a}|\pm|\vec{b}|$，二者不等，必须整体平方。
  • 展开时忘记中间项系数 $2$，写成 $|\vec{a}|^2 \pm \vec{a}\cdot\vec{b} + |\vec{b}|^2$，导致结果错误。
  • 已知 $\vec{a}\cdot\vec{b}$ 时反求 $|\vec{a}\pm\vec{b}|$ 忘记开方：$|\vec{a}\pm\vec{b}| = \sqrt{|\vec{a}|^2 \pm 2\vec{a}\cdot\vec{b} + |\vec{b}|^2}$。
  • 数量积 $\vec{a}\cdot\vec{b}$ 可为负数，若只在正数范围内思考，易漏解。

代表题精讲

题目
设向量 $\vec{a},\vec{b}$ 满足 $|\vec{a}+\vec{b}|=\sqrt{10}$，$|\vec{a}-\vec{b}|=\sqrt{6}$，则 $\vec{a}\cdot\vec{b}=$（ ）
A. 1　B. 2　C. 3　D. 5

思路
同时出现 $|\vec{a}+\vec{b}|$ 和 $|\vec{a}-\vec{b}|$，宜直接利用恒等式 $|\vec{a}+\vec{b}|^2 - |\vec{a}-\vec{b}|^2 = 4\vec{a}\cdot\vec{b}$ 求解。

步骤
分别平方： $$|\vec{a}+\vec{b}|^2 = 10,\quad |\vec{a}-\vec{b}|^2 = 6.$$ 两式相减： $$|\vec{a}+\vec{b}|^2 - |\vec{a}-\vec{b}|^2 = 10 - 6 = 4.$$ 又 $$|\vec{a}+\vec{b}|^2 - |\vec{a}-\vec{b}|^2 = \left(|\vec{a}|^2+2\vec{a}\cdot\vec{b}+|\vec{b}|^2\right) - \left(|\vec{a}|^2-2\vec{a}\cdot\vec{b}+|\vec{b}|^2\right) = 4\vec{a}\cdot\vec{b}.$$ 因此 $4\vec{a}\cdot\vec{b}=4$，得 $\vec{a}\cdot\vec{b}=1$，选 A。

点评/变式
- 直接使用 $4\vec{a}\cdot\vec{b}=|\vec{a}+\vec{b}|^2-|\vec{a}-\vec{b}|^2$ 可避免展开后重复消元，大幅提高速度。 - 变式：若已知 $|\vec{a}+\vec{b}|$ 和 $|\vec{a}-\vec{b}|$ 之一，以及 $|\vec{a}|,|\vec{b}|$，则用平方和公式 $2(|\vec{a}|^2+|\vec{b}|^2)=|\vec{a}+\vec{b}|^2+|\vec{a}-\vec{b}|^2$ 求另一模长，再求数量积。 - 训练中应牢记这两个恒等式，在选填题中实现“秒杀”。
