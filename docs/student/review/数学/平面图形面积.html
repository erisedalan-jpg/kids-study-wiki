知识精要

  • 定积分与面积：由连续曲线 $y=f(x)$（$f(x)\ge 0$）、直线 $x=a,x=b$ 及 $x$ 轴围成的曲边梯形面积 $S=\int_a^b f(x)\,\mathrm{d}x$。
  • 上下相减型：由两条连续曲线 $y=f(x),y=g(x)$ 与直线 $x=a,x=b$ 围成的图形面积 $S=\int_a^b |f(x)-g(x)|\,\mathrm{d}x$，通常需判断区间内上下位置。
  • 选 $y$ 为积分变量：若图形更方便用 $y$ 表示左、右边界，可由曲线 $x=\varphi(y),\ x=\psi(y)$ 及直线 $y=c,y=d$ 围成，面积 $S=\int_c^d |\varphi(y)-\psi(y)|\,\mathrm{d}y$。
  • 分段处理：当图形边界函数在不同区间发生变化或交点在区间内部时，需以交点为界分段积分求和。
  • 适用条件：边界函数在积分区间上连续，且积分存在；用牛顿-莱布尼茨公式计算时需找到原函数。

解题方法与套路

  1. 画图定区：在同一坐标系中画出所有给定曲线的草图，标出交点坐标，明确所求封闭图形的边界构成。
  2. 选变量与方向：
  3. 优先选择使被积函数简单、无需分段或少分段的方向（$x$ 型或 $y$ 型）。
  4. 本题中曲线 $x=\sqrt{y}$（即 $y=\sqrt{x}$ 的反形式）与 $x=y+2$ 均易表达为 $x$ 关于 $y$ 的函数，故选 $y$ 为积分变量。
  5. 求交点定限：解方程组求边界曲线的交点坐标，确定积分下限与上限。若选 $y$ 为变量，交点纵坐标即为积分限。
  6. 列式去绝对值：在同一区间内确定“左”“右”或“上”“下”曲线。$x$ 型：$S=\int_a^b [上曲线 - 下曲线]\,\mathrm{d}x$；$y$ 型：$S=\int_c^d [右曲线 - 左曲线]\,\mathrm{d}y$。
  7. 计算定积分：求原函数，代入牛顿-莱布尼茨公式。
  8. 检验：结果大于零，且与图形直观大小匹配。

高频易错

  • 盲目用 $x$ 型积分：若 $y=\sqrt{x}$ 与 $y=x-2$ 用 $x$ 积分，需从交点处分成两段：一段为 $x$ 在 $[0,1]$ 时上下为 $y=\sqrt{x}$ 和 $y=0$，另一段 $[1,4]$ 时上下为 $y=\sqrt{x}$ 和 $y=x-2$。分解不当易算错。
  • 忽视 $y$ 轴边界：题目明确“及 $y$ 轴围成”，$y$ 轴即 $x=0$，必须作为边界之一。若只算 $y=\sqrt{x}$ 与 $y=x-2$ 的封闭区域会遗漏。
  • 交点求错：$y=\sqrt{x}$ 与 $y=x-2$ 平方后求解注意增根，必须代入原方程检验。
  • 上下限颠倒或积分变量混乱：选 $y$ 为变量时，积分上下限是 $y$ 值，被积函数是 $x$ 的表达式，切勿写成 $y$ 的取值范围对应 $x$ 的积分。
  • 忘记原函数符号或常数：$\sqrt{y}$ 的原函数是 $\frac{2}{3}y^{3/2}$，计算时系数易错。

题目（2011·全国新课标理·9）

求由曲线 $y=\sqrt{x}$，直线 $y=x-2$ 及 $y$ 轴所围成图形的面积。

思路
所求区域左边界为 $y$ 轴（$x=0$），下方为直线和曲线的一部分。由于边界涉及 $y$ 轴且 $y=\sqrt{x}$ 与 $y=x-2$ 的交点处函数关系简单，将曲线改写为 $x=y^2$（$y\ge 0$），直线改写为 $x=y+2$，选 $y$ 为积分变量，可一次积分完成。

步骤
1. 改写方程并求交点：
$y=\sqrt{x} \Rightarrow x=y^2\ (y\ge 0)$；$y=x-2 \Rightarrow x=y+2$。
求交点：$y^2 = y+2 \Rightarrow y^2-y-2=0 \Rightarrow (y-2)(y+1)=0$，得 $y=2$ 或 $y=-1$（舍去，因 $y\ge 0$）。交点坐标为 $(4,2)$。
又 $y$ 轴为 $x=0$，与两曲线的相对位置：
当 $y=0$ 时，曲线 $x=0$，直线 $x=2$；当 $y=2$ 时，曲线 $x=4$，直线 $x=4$。
2. 确定积分区间与左右边界：
$y$ 从 $0$ 到 $2$。在任意 $y\in[0,2]$ 上，$x=y^2$ 与 $x=y+2$ 比较大小：$y+2 - y^2 = -(y^2 - y -2)=-(y-2)(y+1)\ge 0$ 在 $[0,2]$ 上成立，故右边界为 $x=y+2$，左边界为 $x=y^2$。
3. 列面积积分式：
$$S=\int_0^2 [ (y+2) - y^2 ]\,\mathrm{d}y = \int_0^2 (-y^2 + y + 2)\,\mathrm{d}y.$$
4. 计算：
