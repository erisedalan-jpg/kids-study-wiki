知识精要

并集是由所有属于集合 $A$ 或属于集合 $B$ 的元素构成的集合，记作 $A \cup B$，即
$$A \cup B = {x \mid x \in A \text{ 或 } x \in B}.$$ 核心性质：$A \cup A = A$，$A \cup \varnothing = A$，$A \cup B = B \cup A$；若 $A \subseteq B$，则 $A \cup B = B$。
含补集的混合运算：$\complement_U(A \cup B) = (\complement_U A) \cap (\complement_U B)$（德摩根律）。当全集 $U$ 给定，求并集的补集时，可先求并集再取补集，亦可先对各集合取补集再求交集，依据题目结构选择较简路径。

解题方法与套路

  1. 明确运算顺序：有括号先算括号内；若为 $\complement_U(M \cup N)$ 形式，通常先求 $M \cup N$，再用全集减去该并集得到补集。
  2. 离散数集的并集：直接列出两个集合的全部元素，合并后去除重复元素，写成列举法形式（元素之间无序、互异）。
  3. 连续数集（区间）的并集：在数轴上画出每个集合对应的区间，所有被覆盖的部分即为并集，并用区间或不等式正确表示（特别注意端点的开闭）。
  4. 描述法集合先化简：若集合以描述法给出（如不等式、方程的解），先求出具体元素或最简形式，再进行并集运算。
  5. 巧用德摩根律：当 $\complement_U A$ 与 $\complement_U B$ 容易直接写出时，可用 $\complement_U(A \cup B)=\complement_U A \cap \complement_U B$ 替代先并后补，减少出错。
  6. 结果检验：检查元素是否满足互异性、区间端点是否正确、全集范围内的元素有无遗漏。

高频易错

  • 混淆并集与交集：把 $A \cup B$ 错写成公共部分（如 ${1,2}$ 与 ${2,3}$ 错取 ${2}$）。
  • 并集元素重复书写：合并时忘记互异性，写成 ${1,2,2,3}$ 之类的错误。
  • 忽略全集范围：求 $\complement_U(M \cup N)$ 时，全集中某些既不在 $M$ 也不在 $N$ 的元素容易被遗漏，应明确列出全集所有元素后再剔除。
  • 区间并集端点处理不当：例如 $A=(-1,2)$，$B=[2,3)$，并集应表示为 $(-1,3)$ 错误（实际上 $(-1,3)$ 不含 $2$，正确的并集应为 $(-1,3)$ 还是 $(-1,2)\cup[2,3)$ ，需仔细核对端点开闭；注意，若 $2$ 处左开右闭，并集在 $2$ 处有定义，不可用单一开区间涵盖）。通常直接用数轴观察，端点开闭情况逐点确定。
  • 未化简描述法集合：如 $B={x \mid (x+1)(x-2)<0, x\in \mathbb Z}$ 应求得整数集 ${0,1}$ 再做运算，若误当作连续区间则致错。
