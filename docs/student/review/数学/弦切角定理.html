弦切角定理

知识精要

  • 弦切角定理：顶点在圆上，一边和圆相交、另一边和圆相切的角叫做弦切角。弦切角等于它所夹的弧所对的圆周角。如图，若 $CD$ 切 $\odot O$ 于 $C$，$CA$ 为弦，则 $\angle DCA = \angle B$（$B$ 为弧 $CA$ 所对圆周角）。
  • 切割线定理：从圆外一点引圆的切线和割线，切线长是这点到割线与圆交点的两条线段长的比例中项。即若 $DE$ 切圆于 $C$，$DAB$ 为割线，则 $DC^2 = DA \cdot DB$。
  • 弦切角定理的逆定理：若一个角满足一边与圆相交，且其角度等于它所夹弧对的圆周角，则另一边与圆相切。
  • 四点共圆的性质与判定：圆内接四边形的对角互补，外角等于内对角；若两个点在同侧所张的角相等，则四点共圆。
  • 相关性质：同弧或等弧所对的圆周角相等；直径所对的圆周角为直角；相似三角形的比例关系可导出线段乘积式。

解题方法与套路

  1. 识别弦切角并转化：遇切线优先找弦切角，利用弦切角定理将切线与弦的夹角转化为其所夹弧对的圆周角，实现角关系的传递。
  2. 利用等弧/比例条件构造相似：题干给出线段乘积式（如 $BC \cdot AE = DC \cdot AF$）时，改写为比例式 $\frac{BC}{DC} = \frac{AF}{AE}$，结合已转化的角相等，证明三角形相似，进而得到对应角相等或边成比例。
  3. 四点共圆的介入：当题目出现“$B,E,F,C$ 四点共圆”，立刻使用圆内接四边形的对角互补、外角等于内对角等性质，将不同位置的角转移集中，配合弦切角导出直角或等角，证明直径等特殊结论。
  4. 切割线定理搭桥求长度比或面积比：涉及线段长度、面积比值计算时，优先考虑切割线定理将切线长与割线段联系起来，结合所设小量（如 $DB=BE=EA=x$），把关键线段都用同一参数表示，再用勾股定理、相似比等建立方程求解比值。
  5. 面积比的转化：圆的面积比等于半径平方比，也等于直径平方比；在与圆有关的面积问题中，可以通过找出两圆的直径，转化为对应线段平方的比值进行计算。

高频易错

  • 弦切角所夹弧找不准：弦切角的两边中，切线一边与弦一边所夹的弧是圆弧被弦与切线所夹的部分，很多同学误认为是别的弧，导致圆周角代错。注意弦切角的顶点是切点，夹的弧是弦与切线之间的弧。
  • 切割线定理套用错误：切线长是割线上从圆外点到两个交点的线段的比例中项，必须是外点到两交点的线段长度，而不是点到圆上任意点的距离；同时要确保切线是从那个外点引出的同一条。
  • 四点共圆性质用反：外角等于内对角，往往搞错“外角”是哪个角，正确的是四边形一个外角等于与它不相邻的内对角。
  • 乘积式直接当比例式：$a \cdot b = c \cdot d$ 推出 $\frac{a}{c} = \frac{d}{b}$ 等多种写法，需结合要证明的相似三角形对应边选取正确比例，选错会导致无法构成相似。
  • 只证不计算，忽略隐含数据：如 $DB=BE=EA$ 这类条件，没有及时设为未知数并表达其余线段，导致面积比或长度比的计算卡住。

代表题精讲

（2013·理·22）

题目：如图，$CD$ 为 $\triangle ABC$ 外接圆的切线，$AB$ 的延长线交直线 $CD$ 于 $D$，$E$、$F$ 分别在弦 $AB$、$AC$ 上，且 $BC \cdot AE = DC \cdot AF$，$B,E,F,C$ 四点共圆。
（1）证明 $CA$ 是 $\triangle ABC$ 外接圆的直径；
（2）若 $DB=BE=EA$，求过 $B,E,F,C$ 四点的圆的面积与 $\triangle ABC$ 外接圆面积的比值。

思路：
（1）由 $CD$ 是切线得 $\angle DCB = \angle A$，结合乘积式比例证 $\triangle CDB \sim \triangle AEF$，得 $\angle CBD = \angle AFE$；再由 $B,E,F,C$ 四点共圆得 $\angle CFE = \angle CBE$，进而推出 $\angle CFA = 90^\circ$，故 $CA$ 为直径。
（2）设 $DB=x$，得各边用 $x$ 表示，利用切割线定理求 $DC$，用勾股定理求 $CA$，再找出两圆直径 $CE$ 与 $CA$ 的平方比即面积比。

步骤：
（1）证明直径：
∵ $CD$ 是切线 ⇒ $\angle DCB = \angle A$（弦切角定理）。
由 $BC \cdot AE = DC \cdot AF$ 得 $\displaystyle\frac{BC}{DC} = \frac{AF}{AE}$， ∴ $\triangle CDB \sim \triangle AEF$ ⇒ $\angle CBD = \angle AFE$。
又 $B,E,F,C$ 共圆 ⇒ $\angle CFE = \angle CBE$（同弧所对圆周角相等），且 $\angle CBE = \angle CBD$。
故 $\angle AFE = \angle CFE$，而 $A,F,C$ 共线，所以 $\angle AFE + \angle CFE = 180^\circ$，推得 $\angle AFE = \angle CFE = 90^\circ$。
即 $CF \perp AB$，但 $CF$ 是弦 $AC$ 上的一部分，所以 $CA$ 垂直于 $AB$？需正确：点 $F$ 在 $AC$ 上，$A、F、C$ 共线，$\angle AFE=90^\circ$ 意味着 $EF \perp AC$，但我们要证 $CA$ 是直径。由 $\triangle CDB \sim \triangle AEF$ 有 $\angle CBD = \angle AFE = 90^\circ$，即 $\angle CBA = 90^\circ$。因为 $B,E,A$ 共线，$\angle CBA = \angle CBE = 90^\circ$，所以 $CA$ 是 $\triangle ABC$ 外接圆的直径（直径所对圆周角为直角的逆用）。
（2）求面积比：
设 $DB = BE = EA = x$，则 $AB = 3x$，$DA = DB + BA = 4x$。
由切割线定理：$DC^2 = DB \cdot DA = x \cdot 4x = 4x^2$ ⇒ $DC = 2x$。
在 $Rt\triangle ABC$ 中，$\angle CBA = 90^\circ$，由（1）知 $CA$ 为直径，$BC$ 需求。
连接 $CE$，$B,E,F,C$ 四点共圆，该圆直径显然为 $CE$（因为 $\angle CBE = 90^\circ$ 对直径 $CE$）。
欲求 $CE$：在 $\triangle CBE$ 中，$CB$ 未知。由 $\triangle ABC$，$CB$ 可通过 $\triangle DBC$ 或相似求。由 $DC=2x$，$DB=x$，且 $\angle DCB = \angle A$，可用勾股：$\triangle ABC$ 中 $AB=3x$，设 $BC = a$，则 $CA^2 = a^2 + 9x^2$。
由 $\triangle CDB \sim \triangle ADC$？不一定。用切割线定理前已导出 $DC=2x$，在 $\triangle DBC$ 中，$DB=x$，$DC=2x$，$\angle BDC$ 为公共角，且 $\angle DCB = \angle A$。过 $C$ 作切线，由弦切角定理，$\angle DCB = \angle A$，而 $\angle D$ 公用 ⇒ $\triangle DCB \sim \triangle DAC$，则 $\frac{DC}{DA} = \frac{BC}{AC} = \frac{DB}{DC}$。
代入：$\frac{2x}{4x} = \frac{BC}{AC} = \frac{x}{2x}$ ⇒ $\frac{BC}{AC} = \frac{1}{2}$。
设 $BC = y$，则 $AC = 2y$，又 $AB=3x$，$BC^2 + AB^2 = AC^2$ ⇒ $y^2 + 9x^2 = 4y^2$ ⇒ $3y^2 = 9x^2$ ⇒ $y = \sqrt{3}x$。
故 $AC = 2\sqrt{3}x$，$BC = \sqrt{3}x$。
在 $Rt\triangle CBE$ 中，$BE = x$，$BC = \sqrt{3}x$ ⇒ $CE^2 = x^2 + 3x^2 = 4x^2$ ⇒ $CE = 2x$。
所以两圆直径：大圆 $AC = 2\sqrt{3}x$，小圆 $CE = 2x$。面积比为直径平方比：$\frac{(2x)^2}{(2\sqrt{3}x)^2} = \frac{4x^2}{12x^2} = \frac{1}{3}$。

点评/变式：本题综合弦切角、相似、四点共圆、切割线定理，是典型的几何证明与计算结合题。关键在通过弦切角打开角相等的突破口，再利用共圆把角集中到同一直线上推得直角。比值计算中，“设而不求”的参数 $x$ 消去，得到定值。变式可改变条件（如 $DB=BE=EC$）或目标（求线段比），方法不变。
