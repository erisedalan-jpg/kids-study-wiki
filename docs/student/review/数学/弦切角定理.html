知识精要

弦切角定理是圆中证明角相等与比例关系的核心工具： - 定义：顶点在圆上，一边与圆相交（弦），另一边与圆相切（切线）的角，叫弦切角。 - 定理内容：弦切角等于它所夹的弧所对的圆周角。即：若 $EC$ 为切线，$C$ 为切点，则 $\angle ACE = \angle CBA$（所夹弧为 $\widehat{AC}$）。 - 常用推论： - 等弧对的弦切角相等，等弧对的圆周角也相等，两者可互化。 - 若两个弦切角所夹的弧相等，则这两个弦切角相等。 - 弦切角定理可直接导出切割线定理：从圆外一点引切线和割线，切线长是这点到割线与圆交点的两条线段长的比例中项。 - 适用条件：题目中出现“切线”“切点”关键字，且需找与圆有关的角相等关系，优先考虑弦切角定理。它常与“圆周角定理”“相似三角形”“四点共圆”联合命制综合题。

解题方法与套路

  1. 识别弦切角
    切线一端为切点，另一条边为过切点的弦，所构成的角就是弦切角。立刻写出其等于所夹弧的圆周角。
  2. 角度转化链
    结合已知弧相等、同弧所对圆周角相等，或四点共圆得到的外角等于内对角，进行多步等角代换，最终证明目标角相等。
  3. 构造相似三角形
    将弦切角与圆周角相等作为一对等角，再结合公共角或另一对弦切角/圆周角相等，凑出两三角形相似。常见相似结构：
  4. 切线 $CD$，切点 $C$，割线 $DBA$，则 $\triangle DCB \sim \triangle DAC$（基于 $\angle DCB = \angle A$，$\angle D$ 公共）。
  5. 有多个切点和相交弦时，多次使用弦切角定理构建两对等角，证明相似。
  6. 将乘积式转为比例式
    当问题要求证形如 $a^2 = b \cdot c$ 时，可转化为 $\dfrac{a}{b} = \dfrac{c}{a}$，然后寻找比例线段所在的相似三角形，用弦切角定理提供角相等依据。
  7. 与四点共圆联动
    若出现 B、E、F、C 四点共圆，可迅速得出 $\angle CFE = \angle CBE$，$\angle BEF = \angle BCF$ 等，再与弦切角、圆周角串联，解决角相等和直径判定问题。

高频易错

  • 错判弦切角所夹的弧：弦切角所夹的弧是切点与弦的另一端点之间的弧，与圆周角的对应关系不能弄反。建议用“弧端点—切点”对应弦切角的两边来记忆。
  • 误用圆周角定理位置：弦切角等于圆周角时，圆周角的顶点必须在所夹弧的异侧圆周上，部分图形需画出准确的圆周角顶点。
  • 相似三角形对应边写反：用弦切角得出 $\angle DCB = \angle A$ 后，$\triangle DCB \sim \triangle DAC$ 的对应边为 $DC:DA = DB:DC = CB:AC$。如果点顺序写错，比例会颠倒，导致 $DC^2 = DB \cdot DA$ 推不出来。
  • 忽视切线还有另一侧弦切角：过同一切点的切线，两侧都形成弦切角，分别等于各自所夹弧的圆周角，证明全面角相等时可能需用到另一侧。
  • 遗漏切割线定理的直接应用：已知切线和割线时，直接引用切割线定理能省去一次相似证明，但必须确保定理条件满足（共点、一割线一切线）。

代表题精讲

代表题1 2013·理·22

题目
$CD$ 为 $\triangle ABC$ 外接圆的切线，$AB$ 延长线交 $CD$ 于 $D$，$E,F$ 分别在弦 $AB,AC$ 上，且 $BC \cdot AE = DC \cdot AF$，$B,E,F,C$ 四点共圆。
(1) 证明 $CA$ 是 $\triangle ABC$ 外接圆的直径；
(2) 若 $DB = BE = EA$，求过 $B,E,F,C$ 四点的圆的面积与 $\triangle ABC$ 外接圆面积的比值。

思路
(1) 利用弦切角定理得出等角，结合条件比例式证明 $\triangle CDB \sim \triangle AEF$，再利用四点共圆进行等角传递，证明 $\angle CFA = 90^\circ$ 得出直径。
(2) 利用 $DB = BE = EA$ 表示各线段，由切割线定理和勾股定理用同一参数表示两圆直径，最后计算面积比。

步骤
(1) 直径证明
由弦切角定理：$\angle DCB = \angle A$。
条件 $BC \cdot AE = DC \cdot AF$ 化为 $\dfrac{BC}{DC} = \dfrac{AF}{AE}$。
又 $\angle DCB = \angle A$，因此 $\triangle CDB \sim \triangle AEF$（两边对应成比例且夹角相等）。
所以 $\angle CBD = \angle AFE$。
由 $B,E,F,C$ 四点共圆得 $\angle CFE = \angle CBD$（外角等于内对角）。
于是 $\angle CFE = \angle AFE$。
而 $\angle CFE + \angle AFE = 180^\circ$，所以 $\angle CFE = \angle AFE = 90^\circ$。
故 $\angle CFA = 90^\circ$，因此 $CA$ 是 $\triangle ABC$ 外接圆的直径。

(2) 面积比值
设 $DB = BE = EA = a$，则 $AB = 3a$。
过 $B,E,F,C$ 四点的圆的直径为 $CE$（因为 $\angle CFE = 90^\circ$，该圆以 $CE$ 为直径）。
由 $DB = BE$ 及 $DC$ 为切线，$DBA$ 为割线，切割线定理：$DC^2 = DB \cdot DA = a \cdot 4a = 4a^2$，得 $DC = 2a$。
在 $\triangle DBC$ 中，$\angle DBC = 180^\circ - \angle ABC$，而 $CA$ 为直径得 $\angle CBA = 90^\circ$，所以 $\angle DBC = 90^\circ$，故 $DC$ 为 $\triangle DBC$ 斜边，
由勾股定理 $CB^2 + BD^2 = DC^2$，即 $CB^2 + a^2 = (2a)^2$，$CB = \sqrt{3}a$。
同理在 $\triangle ABC$ 中，$AB = 3a$，$CB = \sqrt{3}a$，$\angle CBA = 90^\circ$，
直径 $CA = \sqrt{AB^2 + CB^2} = \sqrt{9a^2 + 3a^2} = 2\sqrt{3}a$。
过 $B,E,F,C$ 的圆直径 $CE$：在 $\triangle CBE$ 中，$BE = a$，$CB = \sqrt{3}a$，$\angle CBE = 180^\circ - 90^\circ = 90^\circ$？
注意 $\angle CBA = 90^\circ$ 且 $E$ 在 $AB$ 上，则 $\angle CBE = \angle CBA = 90^\circ$，
故 $CE = \sqrt{CB^2 + BE^2} = \sqrt{3a^2 + a^2} = 2a$。
两圆直径比为 $CE : CA = 2a : 2\sqrt{3}a = 1 : \sqrt{3}$，
面积比为直径平方比 $(1^2):(\sqrt{3})^2 = 1:3$，
所求比值为 $\dfrac{1}{3}$。

点评/变式
本题两次用到弦切角定理（第(1)问开头，以及潜在地配合切割线定理），并结合四点共圆和比例相似。核心是将弦切角得出的等角作为相似依据。变式可把条件改为弧相等等，仍然用弦切角搭建等角关系。

代表题2 2010·理·22

题目
已知圆上 $\widehat{AC} = \widehat{BD}$，过 $C$ 点的圆的切线与 $BA$ 的延长线交于 $E$ 点。
证明：(Ⅰ) $\angle ACE = \angle BCD$；
(Ⅱ) $BC^2 = BE \cdot CD$。

思路
(Ⅰ) 由弦切角定理将 $\angle ACE$ 转化为 $\widehat{AC}$ 所对圆周角，再利用已知弧等转化为 $\angle BCD$。
(Ⅱ) 乘积式转化为比例，寻找 $\triangle BCE$ 与 $\triangle DCB$ 相似。利用弦切角定理提供两次等角，完成相似证明。

步骤
(Ⅰ)
因为 $CE$ 是切线，$C$ 为切点，由弦切角定理得
$$\angle ACE = \angle CBA \quad (\text{弦切角等于所夹弧 } \widehat{AC} \text{ 的圆周角})$$
已知 $\widehat{AC} = \widehat{BD}$，根据等弧对等圆周角，得
$$\angle CBA = \angle BCD$$
于是 $\angle ACE = \angle BCD$。

(Ⅱ)
要证 $BC^2 = BE \cdot CD$，即证 $\dfrac{BC}{BE} = \dfrac{CD}{BC}$。
在 $\triangle BCE$ 和 $\triangle DCB$ 中：
由弦切角定理，$\angle BCE$ 夹弧 $\widehat{BC}$，其等于 $\widehat{BC}$ 所对的圆周角 $\angle BAC$。
而 $\widehat{BC}$ 也对应另一圆周角 $\angle BDC$（同弧），故
$$\angle BCE = \angle BDC$$
又由 (Ⅰ) 知 $\angle ACE = \angle BCD$，而 $\angle ACB$ 公共？需注意 $\angle CBE$：
$\angle CBE$ 是 $\widehat{AC}$ 所对的圆周角（$B$ 为顶点），由弧等得 $\angle CBE = \angle BCD$。
因此 $\triangle BCE \sim \triangle DCB$（有两对角对应相等：$\angle BCE = \angle BDC$，$\angle CBE = \angle BCD$）。
由相似得对应边成比例：
$$\dfrac{BC}{DC} = \dfrac{BE}{BC}$$
即 $BC^2 = BE \cdot CD$。

点评/变式
本题是弦切角定理与弧相等联合运用的典范，两次定理调用连得两组等角，直接建立相似。第二问也可用切割线定理配合圆内相似，但直接两次弦切角更直接。变式可将条件换成垂径或圆心角等，仍以弦切角为桥梁。
