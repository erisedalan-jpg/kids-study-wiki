知识精要

  • 循环结构基本概念：在条件满足时反复执行同一段代码（循环体）。程序框图（流程图）中由判断框与流程线构成循环回路。高考常考两种模式：
    当型循环：先判断条件，满足则执行循环体，否则退出（“先判断后执行”）；
    直到型循环：先执行一次循环体，然后判断条件，不满足则继续循环，满足则退出（“先执行后判断”）。框图识别依据：循环回路中判断框的位置与流程线走向。
  • 循环三要素：
  • 循环变量初值（输入或直接赋值，如 $n=1$, $S=0$）；
  • 循环体的操作（赋值与运算，注意执行顺序）；
  • 循环终止条件（判断框中的不等式，超出临界则跳出）。
  • 常见循环算法模型：
  • 累加求和：$S=S+a_n$ 型；累乘求积：$p=p \times k$ 型；
  • 秦九韶算法（多项式求值）：$S=S \cdot x + a$，从内向外迭代；
  • 更相减损术：大数减小数，直至两数相等，输出最大公约数；
  • 迭代逼近：如用 $\left| \frac{b^2}{a^2}-2 \right|<\varepsilon$ 控制近似值。
  • 框图规范：
    起止框（圆角矩形/椭圆）、输入输出框（平行四边形）、处理框（矩形）、判断框（菱形）。算法不必陷入程序代码，重在流程逻辑推理。

解题方法与套路

  1. 明确初值与输出：标出循环开始前各变量数值，确认最终输出哪个变量（可能是循环变量，也可能是过程量）。
  2. 逐次模拟执行：按判断框条件，逐轮列出变量更新情况。每次完整执行循环体后，再返回判断条件。关键操作必须按顺序记录，如 $b=b+2a$ 后立即 $a=b-a$，不能颠倒。
  3. 找准终止边界：注意最后一次进入循环体后、再次判断条件时不满足才跳出。循环执行次数由条件边界决定，常设“临界点”陷阱。
  4. 归纳规律：若循环次数多，可寻找变量变化的规律（等差、等比、递推），避免逐轮机械罗列。例如累加公式 $\sum\limits_{k=1}^N \frac{1}{k(k+1)}$ 可用裂项求和验证。
  5. 补全框图类：根据输出结果反推缺失的步长或条件。观察累加项的特点（如正负交替、步长间隔）确定应填入的赋值语句或判断条件。
  6. 检验特例：对边界值（如 $N=2$、初始条件正好满足跳出）做快速验证，防止粗心失分。

高频易错

  • 循环次数多算或少算：最后一次执行循环体后，判断条件不成立时立即退出，此时若误把“条件刚成立”的那次也算入，会多输出一轮。正确做法是：循环直到条件不满足才停止。
  • 变量更新顺序混淆：循环体中含有多个赋值，后一表达式可能用到刚更新的变量。务必按照框图箭头的先后顺序处理，否则数值会错位。
  • 输出对象看错：题目要求输出的可能是 $k$ 或 $n$（循环次数），也可能是 $S$ 或其他中间量，不要默认输出循环变量。
  • 当型与直到型混淆：当型循环“先判断后执行”，如果初始条件不满足则一次都不执行；直到型循环“先执行后判断”，至少执行一次。高考常将两种形态转换设问。
  • 补全框图时步长判断失误：若累加项符号交替或分母跳变（如 $1,-\frac12,\frac13$），步长往往是关键。比如正负交错下的 $i=i+1$ 还是 $i=i+2$，要观察相邻两项下标的差。
  • 忽略累加器初值：累加变量初值常设为 $0$，累乘变量初值设为 $1$，否则结果会整体错位。
  • 算法背景的“翻译”偏差：如秦九韶算法中变量 $s$ 与输入的 $a$ 的关系，要理解 $s=s\cdot x + a$ 的递推含义，不盲目套公式。

代表题精讲

题目1 （2022年文科第7题）

执行程序框图，初始 $a=1,b=2,n=1$。循环：$b=b+2a$，$a=b-a$，$n=n+1$，当 $\left|\frac{b^2}{a^2}-2\right| < 0.01$ 时输出 $n$，否则继续循环。求输出的 $n$。

思路
这是典型的迭代逼近问题，通过 $b$ 与 $a$ 的比值平方接近 $2$ 来控制精度。逐轮模拟变量更新，当不等式成立时立即停止，此时 $n$ 即为循环执行的累计次数。

步骤
1. 初始值：$a=1$，$b=2$，$n=1$（尚未进入循环体）。
2. 第一次循环：
$b\leftarrow 2+2\times1=4$；
$a\leftarrow 4-1=3$；
$n\leftarrow 1+1=2$。
计算 $\frac{4^2}{3^2}-2=\frac{16}{9}-2\approx1.78-2=-0.22$，取绝对值 $0.22>0.01$，继续。
3. 第二次循环：
$b\leftarrow 4+2\times3=10$；
$a\leftarrow 10-3=7$；
$n\leftarrow 2+1=3$。
$\frac{100}{49}-2\approx2.04-2=0.04$，$0.04>0.01$，继续。
4. 第三次循环：
$b\leftarrow 10+2\times7=24$；
$a\leftarrow 24-7=17$；
$n\leftarrow 3+1=4$。
$\frac{576}{289}-2\approx1.993-2=-0.007$，$0.007<0.01$，条件满足，退出循环。
5. 输出 $n=4$，对应选项 B。

点评/变式
本题关键在顺序：必须先用旧 $a$ 更新 $b$，再用新 $b$ 更新 $a$，顺序颠倒会得到完全不同的数列。变式中可改变不等式中的常数，如逼近 $\sqrt{3}$ 时用 $\left|\frac{b^2}{a^2}-3\right|$，训练迭代执行能力。

题目2 （2020年文科第7题）

执行程序框图，输入 $k=0$，$a=0$。循环：$a=2a+1$，$k=k+1$；若 $a>10$ 则输出 $k$，否则返回继续循环。求输出的 $k$。

思路
框图采用“先执行后判断”结构，每次让 $a$ 变为 $2a+1$，同步 $k$ 加 1。当 $a$ 首次大于 $10$ 时，输出此时的 $k$。逐轮计算 $a$ 值即可。

步骤
1. 初始值：$k=0$，$a=0$。
2. 第1轮：$a\leftarrow 2\times0+1=1$，$k\leftarrow 0+1=1$；判断 $a>10$？否，继续。
3. 第2轮：$a\leftarrow 2\times1+1=3$，$k\leftarrow 1+1=2$；$3>10$？否。
4. 第3轮：$a\leftarrow 2\times3+1=7$，$k\leftarrow 2+1=3$；$7>10$？否。
5. 第4轮：$a\leftarrow 2\times7+1=15$，$k\leftarrow 3+1=4$；$15>10$，是，跳出循环。
6. 输出 $k=4$，对应选项 C。

点评/变式
本题是直到型循环的典型：第一次执行循环体后 $k$ 变 1，此后每次循环 $k$ 同步加 1。注意点：若将终止条件改为 $a\le 10$ 继续循环，则输出时机恰好相反，极易混淆。变式可将递推式换成 $a=3a-1$，或输出 $a$ 而非 $k$，训练区分输出目标的能力。
