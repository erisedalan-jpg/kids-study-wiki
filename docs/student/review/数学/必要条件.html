知识精要

  • 充分条件与必要条件：若“$p \Rightarrow q$”，称 $p$ 是 $q$ 的充分条件，$q$ 是 $p$ 的必要条件。
  • 充要条件：若“$p \Rightarrow q$”且“$q \Rightarrow p$”（即 $p \Leftrightarrow q$），则 $p$ 与 $q$ 互为充要条件。
  • 充要条件的证明：必须分两步走——
    （1）证明充分性（$p \Rightarrow q$）；
    （2）证明必要性（$q \Rightarrow p$）。
    每一步都要明确当前假设与目标，选用合适的定理、公式进行推导。
  • 与不等式结合的常用工具：
  • 正数运算保持不等号；
  • 平方比较法：对非负数 $A,B$，$A > B \iff A^2 > B^2$；
  • $(\sqrt{a}+\sqrt{b})^2 = a+b+2\sqrt{ab}$；
  • $|a-b| = \sqrt{(a-b)^2} = \sqrt{(a+b)^2-4ab}$（结合和与积的转化）。
  • 关键恒等式与条件转化：
    已知 $a+b=c+d$ 时，
    $$(\sqrt{a}+\sqrt{b})^2 - (\sqrt{c}+\sqrt{d})^2 = 2(\sqrt{ab}-\sqrt{cd}),$$ $$|a-b|^2 - |c-d|^2 = (a+b)^2-4ab - [(c+d)^2-4cd] = 4(cd-ab).$$
    因此 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d} \iff ab > cd$，
    且 $|a-b| < |c-d| \iff ab > cd$（结合 $a+b=c+d$ 与正数条件）。这是本题充要性的核心代数链。

解题方法与套路

  1. 审题，分清条件与结论
    对于充要性证明，明确“$p$：$\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$”，“$q$：$|a-b| < |c-d|$”，并画出双向箭头图。
  2. 充分性证明（$\Rightarrow$）
    假设 $p$ 成立，利用平方化去根号，结合已知恒等式 $a+b=c+d$，推出 $ab>cd$。再由 $|a-b|^2 = (a+b)^2-4ab$ 将 $ab>cd$ 转化为 $|a-b| < |c-d|$。
  3. 必要性证明（$\Leftarrow$）
    假设 $q$ 成立，反向推得 $ab>cd$，再利用 $(\sqrt{a}+\sqrt{b})^2 = a+b+2\sqrt{ab}$ 推出 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$。
  4. 书写规范
  5. 每一步标明“充分性”“必要性”；
  6. 所有变形必须说明依据（正数可平方，结合已知等式）；
  7. 平方展开要完整，避免跳步；
  8. 最后给出“综上所述，……是……的充要条件”的总结。
  9. 条件挖掘技巧
    当题设给出正数与和相等时，迅速联想到平方差、乘积比较、绝对值放缩等链路，建立“根号和—乘积—绝对值”三者之间的等价关系。

高频易错

  • 双向缺一：只证了充分性或必要性，遗漏另一方向，导致“充要条件”证明不完整。
  • 条件使用不全：忘记使用“正数”条件就直接平方，忽略平方要求非负；未使用 $a+b=c+d$，导致无法化简，陷入复杂运算。
  • 等价变形失误：误认为 $ab>cd$ 与 $|a-b| > |c-d|$ 等价，实则在 $a+b=c+d$ 且正数下应为反向关系。
  • 符号混淆：从 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$ 两边平方时，忘记交叉项 $2\sqrt{ab}$，或错误约去 $a+b$ 与 $c+d$ 后直接比较根号乘积而漏乘2。
  • 逻辑链脱节：由 $ab>cd$ 推出 $\sqrt{ab}>\sqrt{cd}$ 时，未说明正数保证单调性；从 $ab>cd$ 到 $|a-b|^2 < |c-d|^2$ 时，忽略 $a+b=c+d$ 的替换，导致写不出 $4(cd-ab)<0$ 的简洁形式。

代表题精讲

2015年新课标卷文/理 第24题

题目：设 $a,b,c,d$ 均为正数，且 $a+b=c+d$。证明：
（1）若 $ab > cd$，则 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$；
（2）$\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$ 是 $|a-b| < |c-d|$ 的充要条件。

思路：
第（1）问直接比较平方差，利用已知和相等消去 $a+b$ 与 $c+d$，凸显乘积与根式的关系。第（2）问是典型的充要条件证明，需要双向推理。注意到条件和结论分别联系着 $\sqrt{ab}$ 和 $ab$，而题设的和相等提供了乘积与绝对值差的等价转化，因此整个证明实际围绕着 $ab>cd$ 这一核心不等式展开。

步骤：
（1）
$a,b,c,d >0$，
$(\sqrt{a}+\sqrt{b})^2 = a+b+2\sqrt{ab}$，
$(\sqrt{c}+\sqrt{d})^2 = c+d+2\sqrt{cd}$。
由 $a+b=c+d$，两式相减得差为 $2(\sqrt{ab}-\sqrt{cd})$。
已知 $ab > cd$，且正数保证 $\sqrt{ab} > \sqrt{cd}$，故
$(\sqrt{a}+\sqrt{b})^2 > (\sqrt{c}+\sqrt{d})^2$。
两边开方（函数单调），得 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$。

（2）
充分性（若 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$，则 $|a-b| < |c-d|$）：
由假设平方得 $a+b+2\sqrt{ab} > c+d+2\sqrt{cd}$，用 $a+b=c+d$ 约去，推出 $\sqrt{ab} > \sqrt{cd}$，故 $ab > cd$。
又 $|a-b|^2 = (a+b)^2-4ab$，$|c-d|^2 = (c+d)^2-4cd$，
结合 $a+b=c+d$ 得 $|a-b|^2 - |c-d|^2 = -4(ab-cd) < 0$。
因此 $|a-b|^2 < |c-d|^2$，由非负性开方得 $|a-b| < |c-d|$。
必要性（若 $|a-b| < |c-d|$，则 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$）：
由假设得 $|a-b|^2 < |c-d|^2$，代入平方展开式得到$-4ab < -4cd$，即 $ab > cd$。
由 $ab > cd$ 及第（1）问结论，立即得到 $\sqrt{a}+\sqrt{b} > \sqrt{c}+\sqrt{d}$。
综上所述，二者互为充要条件。

点评/变式：
该题为代数推理与简易逻辑结合的经典模型。核心技巧在于利用“两数和相等”消去复杂项，将目标不等式统一归结为乘积 $ab$ 与 $cd$ 的大小比较。变式训练：将“$a+b=c+d$”改为“$a^2+b^2=c^2+d^2$”，$a,b,c,d>0$，证明 $\sqrt{a}+\sqrt{b}>\sqrt{c}+\sqrt{d}$ 是 $|a-b|<|c-d|$ 的充要条件，所用方法类似。（提示：平方后需利用平方和相等化简）
