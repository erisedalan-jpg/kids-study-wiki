截面圆性质

考点截面圆性质权重5真题数2学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：5
  • 真题数：2；年份跨度：2009–2012
  • 出现题位：填空16 选择11
  • 难度分布：中2

知识精要

  • 球的基本要素：设球心为 $O$，球半径为 $R$。
  • 截面圆性质（核心）：
  • 用一个平面去截球，截面是圆面。截面圆的圆心 $O_1$ 是球心 $O$ 在截面上的投影。
  • 球心与截面圆圆心的连线 $OO_1$ 垂直于截面（即 $OO_1 \perp$ 平面）。
  • 设截面圆半径为 $r$，球心到截面的距离 $d = OO_1$，则必满足勾股关系：$$R^2 = r^2 + d^2$$
  • 特殊截面（大圆）：当截面过球心 $O$ 时，$d=0$，此时截面圆半径最大 $(r=R)$，称为大圆。
  • 几何体关联：
  • 球内接正三棱锥/正三角形：常需求解三角形外接圆半径作为 $r$。
  • 球的直径端点性质：若 $SC$ 为球的直径，则 $SC$ 的中点即为球心 $O$；连接直径一端点 $S$ 与球心 $O$ 并延长交球面于另一点 $C$，利用平行或比例关系可求几何体高。

解题方法与套路

涉及球与截面圆的定量计算，通常按以下步骤操作：

  1. 定球心、圈截面：画出轴截面图或关键截面图，明确标注球心 $O$、截面圆圆心 $O_1$ 及球半径 $R$、截面圆半径 $r$。
  2. 用勾股串半径：在 $\triangle OO_1A$（$A$ 为截面圆与球的公共点）中，利用 $R^2 = r^2 + d^2$ 建立方程。
  3. 求距离（核心桥梁）：根据其它几何条件求出 $r$ 或 $d$。
  4. 若截面过某线段中点或与某直线成固定夹角，常通过解三角形确定 $d$。
  5. 若截面为内接三角形的外接圆，利用正弦定理 $a/\sin A = 2r$ 计算 $r$。
  6. 解算目标量：
  7. 求球的表面积/体积：先求 $R$。
  8. 求内接几何体的体积/高：利用球心到截面的距离 $d$ 及直径性质推导几何体的高线长度。例如：若 $SC$ 为直径，且 $C$ 在过截面圆且垂直于截面的直线上，则几何体的高 $h = 2d$。

高频易错

  • 对 $d$ 的几何意义理解错：误将球心到截面圆上某点的距离当作 $d$。必须牢记 $d$ 是球心到截面圆圆心的垂线段长。
  • 混淆 $R$、$r$、$d$ 的对应关系：在 $R^2 = r^2 + d^2$ 中，$R$ 必为斜边。若题目已知球的直径，需先除以 2 得到半径 $R$ 再代入，常出现直接以直径为边计算的错误。
  • 无法将空间角转化为平面距离：如给定“过某点且与某直线成 $\theta$ 角的平面截球”，常需将此线面角正确放置在一个直角三角形中求出 $d$。典型错误是找错夹角的对边或邻边，导致 $d$ 算反。
  • 多面体高与 $d$ 的关系搞反：对于顶点在球心正上方且截面对称的情况，几何体的高未必等于 $d$。若顶点与截面圆在球心异侧且连线过球心，高可能是 $R+d$ 或 $R-d$；若利用直径端点性质，高甚至可能是 $2d$，务必画图确认比例关系。

代表题精讲

题目1（2012 理 11·锥体体积）

已知三棱锥 $S-ABC$ 顶点均在球 $O$ 表面，$\triangle ABC$ 是边长为 1 的正三角形，$SC$ 是球 $O$ 的直径且 $SC=2$，求三棱锥体积。

  • 思路：利用 $SC$ 为直径推导线面关系，将三棱锥高转化为球心到截面距离的两倍，通过直角三角形链计算 $d$ 与体积。
  • 步骤：
  • 依题意：球半径 $R=1$。
  • 求截面圆半径 $r$：底面 $\triangle ABC$ 为正三角形，其外接圆即为截面圆，由正弦定理 $ \frac{1}{\sin 60^\circ} = 2r \Rightarrow r = \frac{\sqrt{3}}{3} $。
  • 求球心到截面距离 $d$：在直角 $\triangle OO_1A$ 中，$d = OO_1 = \sqrt{R^2 - r^2} = \sqrt{1 - \frac{1}{3}} = \frac{\sqrt{6}}{3}$。
  • 推导几何体的高：$SC$ 为直径，则 $O$ 为 $SC$ 中点；延长 $CO_1$ 交球面于 $D$。由 $OO_1 \perp$ 平面 $ABC$，得 $SD \perp$ 平面 $ABC$，且 $SD = 2OO_1 = \frac{2\sqrt{6}}{3}$。
  • 计算体积：$S_{\triangle ABC} = \frac{\sqrt{3}}{4}$，体积 $V = \frac{1}{3} \times \frac{\sqrt{3}}{4} \times \frac{2\sqrt{6}}{3} = \frac{\sqrt{2}}{6}$。
  • 点评/变式： 关键是把 $SC$ 为直径转化为“球心 $O$ 为中点”及平行比例关系。若直径端点直接作射影，往往高度就是 $2d$ 或 $R+d$，切忌臆测而忽略推导。此模型可推广至任意圆内接三角形作为底面的棱锥。

题目2（2009 文 16·球表面积）

设 $OA$ 是球 $O$ 的半径，$M$ 是 $OA$ 中点，过 $M$ 且与 $OA$ 成 $45^\circ$ 角的平面截球得圆 $C$。若圆 $C$ 面积为 $\frac{7\pi}{4}$，求球 $O$ 的表面积。

  • 思路：以 $M$ 的特殊位置和给定夹角在轴截面内构建含 $d$ 的直角三角形，列方程解出球半径 $R$。
  • 步骤：
  • 设球半径为 $R$，截面圆 $C$ 的半径为 $r$。由面积得 $\pi r^2 = \frac{7\pi}{4} \Rightarrow r^2 = \frac{7}{4}$。
  • 画出轴截面：图示包含球心 $O$、截面圆圆心 $O_1$（即 $C$）、$M$ 点。由平面与 $OA$ 成 $45^\circ$ 角知，在含 $OO_1$ 与 $OA$ 的三角形中，$\angle OMO_1 = 45^\circ$。因为 $M$ 是 $OA$ 中点，$OM = \frac{R}{2}$。
  • 在 $\triangle OMO_1$ 中，球心到截面距离 $d = OO_1 = OM \cdot \sin 45^\circ = \frac{R}{2} \times \frac{\sqrt{2}}{2} = \frac{\sqrt{2}R}{4}$。
  • 代入核心公式：$R^2 = r^2 + d^2 = \frac{7}{4} + (\frac{\sqrt{2}R}{4})^2 = \frac{7}{4} + \frac{R^2}{8}$。
  • 解得 $\frac{7}{8}R^2 = \frac{7}{4} \Rightarrow R^2 = 2$，故球表面积 $S = 4\pi R^2 = 8\pi$。
  • 点评/变式： “过定点且与某直线成定角”的截面关键是要想到定点、线、角都在轴截面内，立刻能把空间角转化为平面直角三角形中的边长关系。本类题失分点常在误认为 $M$ 就是截面圆圆心上，务必区分弦中点与圆心的差异。
