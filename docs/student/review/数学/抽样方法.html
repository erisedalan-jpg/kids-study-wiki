知识精要

  • 简单随机抽样：从总体中逐个不放回等可能抽取个体，每个个体被抽中的概率相等。适用于总体内个体差异不大、分布均匀的情形。
  • 分层抽样：将总体按某种特征分成互不交叉的若干层，再从各层中按比例（或非比例）独立抽取样本。当层内差异小、层间差异大时，可显著提高样本的代表性。
  • 总体参数的估计：
  • 总体总量 $N$ 的估计：$\hat{N} = \bar{x} \cdot M$，其中 $\bar{x}$ 为样本均值，$M$ 为总体单位总数。
  • 总体均值 $\mu$ 的估计：$\hat{\mu} = \bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$。
  • 样本相关系数（衡量两个变量的线性相关程度）： $$ r = \frac{ \sum_{i=1}^{n} (x_i-\bar{x})(y_i-\bar{y}) }{ \sqrt{ \sum_{i=1}^{n} (x_i-\bar{x})^2 } \sqrt{ \sum_{i=1}^{n} (y_i-\bar{y})^2 } } $$ $|r| \le 1$，$|r|$ 越接近 $1$，线性相关越强。

解题方法与套路

  1. 抽样方法的选择：当已知总体内部差异（如“各地块间植物覆盖面积差异很大”）时，优先考虑分层抽样，并说明分层的依据（按影响研究变量的主要因素分层）及好处（提高样本代表性，使估计更准确）。
  2. 估计量的计算：
  3. 从样本数据求和得到 $\sum x_i$ 与样本容量 $n$，计算样本均值 $\bar{x} = \frac{1}{n}\sum x_i$。
  4. 根据问题背景合理换算总量（如乘以总地块数、总面积等）。
  5. 相关系数的快速计算：
  6. 直接利用题目给出的三个平方和与交叉乘积和：$L_{xx}=\sum(x_i-\bar{x})^2$，$L_{yy}=\sum(y_i-\bar{y})^2$，$L_{xy}=\sum(x_i-\bar{x})(y_i-\bar{y})$。
  7. 代入 $r = \frac{L_{xy}}{\sqrt{L_{xx}\,L_{yy}}}$。注意结果按要求精确到 $0.01$，并参考提供的 $\sqrt{2}$ 等近似值。
  8. 数据分析与文字表述：分层抽样的理由要结合具体数据背景，不要只写“分层抽样”，需指出分层变量（如植物覆盖面积）。

高频易错

  • 混淆抽样方法适用条件：简单随机抽样忽视总体内部差异大时会使样本代表性不足，应改用分层抽样；若写成系统抽样或整群抽样且无合理依据则不得分。
  • 估计总量时忘记乘以总体单位数：如本题中“野生动物数量的估计值 = 样区平均数 × 200”，漏乘200会导致结果错误。
  • 相关系数公式记忆不清：分子分母混淆，或忘记分母是两个平方和的平方根之积，误用为算术平方根的整体。
  • 计算错误：对 $L_{xx}, L_{yy}, L_{xy}$ 的使用张冠李戴；开方时未利用给定近似值（如 $\sqrt{2}\approx1.414$），导致精度偏差。
  • 审题不清：题目要求给出“更合理的抽样方法并说明理由”，只写方法名称不解释原因会扣分。

代表题精讲

题目（2020·全国卷·文/理18）
某沙漠地区200个地块，用简单随机抽样抽取20个样区，调查植物覆盖面积 $x_i$（公顷）和野生动物数量 $y_i$。已知 $\sum x_i=60$，$\sum y_i=1200$，$\sum (x_i-\bar{x})^2=80$，$\sum (y_i-\bar{y})^2=9000$，$\sum (x_i-\bar{x})(y_i-\bar{y})=800$。
（1）求该地区野生动物数量的估计值（估计值=样区平均数×200）；
（2）求样本的相关系数（精确到0.01）；
（3）已知各地块植物覆盖面积差异很大，为提高估计准确性，请给出更合理的抽样方法并说明理由。

思路
（1）先求样区野生动物数量的平均数 $\bar{y}$，再乘以总地块数200。
（2）直接使用相关系数公式 $r = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2}\sqrt{\sum(y_i-\bar{y})^2}}$ 代入数据计算。
（3）植物覆盖面积差异大且可能影响野生动物数量，因此采用分层抽样，以覆盖面积为分层依据，各层内抽取样本，使样本结构更接近总体，提高代表性。

步骤
（1）由 $\sum_{i=1}^{20} y_i = 1200$，得 $\bar{y} = \frac{1200}{20} = 60$。
估计值 $= 60 \times 200 = 12000$。
（2）已知 $L_{xy}=800$，$L_{xx}=80$，$L_{yy}=9000$。
$r = \frac{800}{\sqrt{80}\sqrt{9000}} = \frac{800}{\sqrt{80 \times 9000}} = \frac{800}{\sqrt{720000}}$。
$\sqrt{720000} = \sqrt{72 \times 10000} = 100\sqrt{72} = 100 \times \sqrt{36 \times 2} = 100 \times 6\sqrt{2} \approx 600 \times 1.414 = 848.4$。
$r = \frac{800}{848.4} \approx 0.943$，精确到 $0.01$ 得 $0.94$。
（3）抽样方法：分层抽样。理由：地块间植物覆盖面积差异很大，而且植物覆盖面积与野生动物数量存在相关性（由相关系数 $0.94$ 可知高度正相关）。按植物覆盖面积将地块分成若干层，各层内动物数量差异相对较小，再从各层按适当比例抽取样区，能使样本对各层均有代表性，从而获得更精确的野生动物数量估计。

点评/变式
本题考查了统计中“抽样—估计—相关分析”的完整链条。第（3）问的思维要点在于：不能只答方法名称，必须结合题目数据（覆盖面积差异大、与野生动物数量相关性强）给出分层理由。类似问题可变形为：提供总量估计残差等信息，要求判断现有抽样方案的不足并设计新方案。
