知识精要

  • 正整数指数幂：$a^n = \underbrace{a \cdot a \cdot \ldots \cdot a}_{n \text{ 个}}$（$a\in\mathbb{R},\ a\in\mathbb{C}$ 均可）。
  • 负整数指数幂：$a^{-n} = \frac{1}{a^n}\ (a\neq 0)$。
  • 零指数幂：$a^0 = 1\ (a\neq 0)$。
  • 分数指数幂：$a^{\frac{m}{n}} = \sqrt[n]{a^m}$（$a>0$ 时定义方便；若 $a<0$ 需分奇偶讨论）。
  • 复数域中，幂运算遵循同样的代数法则：乘法可先用完全平方、二项式定理或化为三角形式用棣美弗定理：$[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$。
  • 虚数单位 $i$ 的周期性：$i^1=i,\ i^2=-1,\ i^3=-i,\ i^4=1$，周期为4。

解题方法与套路

  1. 识别指数结构：看清底数与指数，判断是实数幂还是复数幂，指数大小。
  2. 选择化简路径：
  3. 若底数为复数 $a+bi$ 且指数较小，优先采用逐步平方或二项式展开（用完全平方公式与 $i^2=-1$ 化简）。
  4. 若指数较大或底数辐角特殊，化三角形式用棣美弗定理效率更高。
  5. 严格执行代数法则：
  6. 展开时注意符号，每步单独处理实部与虚部。
  7. 利用 $i$ 的幂周期消去高次项。
  8. 结果标准化：将结果写成 $a+bi$ 的代数形式，确认实部与虚部无误。

高频易错

  • 忽略 $i^2=-1$：展开过程中容易将 $i^2$ 误写成 $1$ 或不处理，导致实部虚部混淆。
  • 符号错误：复数减法底数如 $(1-i)$，平方时交叉项为 $-2i$，极易漏掉负号。
  • 偶次幂忘加括号：计算 $(a+bi)^2$ 时直接写成 $a^2 + b^2 i^2$，丢失中间项 $2abi$。
  • 混淆 $i$ 的周期：如 $i^3$ 错记为 $1$ 或 $i$，导致结果不对。
  • 误用分数指数幂的底数限制：对负实数开偶次根或复数开方时，直接套用实数的根式性质而出错。

代表题精讲

题目（2020全国卷文科第2题）：$(1-i)^4 = $（ ）
A. $-4$　B. $4$　C. $-4i$　D. $4i$

思路
指数为4，可“先平方再平方”逐步化简；也可直接使用二项式定理展开，再合并同类项。

步骤
解法一（逐步平方）： $$(1-i)^2 = 1^2 -2\cdot 1\cdot i + (i)^2 = 1 -2i -1 = -2i$$ $$(1-i)^4 = [(1-i)^2]^2 = (-2i)^2 = 4i^2 = 4\cdot (-1) = -4$$

解法二（二项式展开）： $$(1-i)^4 = \sum_{k=0}^4 \binom{4}{k} 1^{4-k}(-i)^k = 1 -4i +6(-i)^2 -4(-i)^3 +(-i)^4$$ 各项： - $k=0$: $1$ - $k=1$: $-4i$ - $k=2$: $6\cdot (-1) = -6$ - $k=3$: $-4\cdot (-i)^3 = -4\cdot [(-i)^2\cdot (-i)] = -4\cdot [(-1)\cdot (-i)] = -4\cdot i = -4i$ （或用 $(-i)^3 = -i^3 = -(-i)=i$，则 $-4\times i = -4i$） - $k=4$: $(-i)^4 = i^4 = 1$ 求和：$1 -4i -6 -4i +1 = (1-6+1) + (-4i-4i) = -4 -8i$？此处有矛盾，需要重新仔细计算二项式展开符号。

纠正二项式展开的计算： $(1-i)^4$，用二项式定理 $(a+b)^n$，令 $a=1,\ b=-i$。 $$\begin{aligned} (1-i)^4 &= \binom{4}{0}1^4(-i)^0 + \binom{4}{1}1^3(-i)^1 + \binom{4}{2}1^2(-i)^2 + \binom{4}{3}1^1(-i)^3 + \binom{4}{4}(-i)^4 \ &= 1 + 4(-i) + 6(-i)^2 + 4(-i)^3 + (-i)^4 \ &= 1 -4i + 6(i^2) + 4(-i^3) + i^4 \ &= 1 -4i + 6(-1) + 4(-(-i)) + 1 \ &= 1 -4i -6 + 4i + 1 \ &= (1-6+1) + (-4i+4i) = -4 + 0i = -4 \end{aligned}$$ 原来之前错误在于 $(-i)^3$ 的系数符号处理。修后无误，结果 $-4$，选 A。

点评与变式
- 逐步平方法更快捷且不易错，推荐小题优先使用。 - 二项式展开需格外注意系数与 $i$ 幂的符号，适合指数不超过4的情形。 - 变式1：$(1+i)^4$ 同样可得 $-4$（对称性）。 - 变式2：$(1-i)^6$ 可先平方得 $-2i$，再三次方：$(-2i)^3 = -8i^3 = -8(-i)=8i$，也可化为三角式验证。
