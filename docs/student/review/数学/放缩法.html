知识精要

放缩法是通过有目的地将不等式的一边（或其中的某些项）放大或缩小，借助不等式的传递性，将难以直接处理的结构转化为易求和、易比较的“过渡量”的一项核心证明与估值方法。 - 基本原理：若 $A \le B$ 且 $B \le C$，则 $A \le C$。关键在于构造合适的中间量 $B$，使得 $B$ 易于求和或易于判定。 - 常见放缩方向： - 求和型不等式证明：通常将通项放大（证小于号）或缩小（证大于号），使其变为等比数列、可裂项分式等。 - 分式放缩：分子固定时，缩小分母则分式变大；放大分母则分式变小。 - 函数值域判断：对函数表达式进行适度放大或缩小，获得一个“易判断”的范围，用于排除选项。 - 常用放缩技巧： - $a_n = 3^n - 1 \ge 3^n - 3^{n-1} = 2\cdot 3^{n-1}$（$n\ge2$），从而 $\frac{1}{3^n-1} \le \frac{1}{2\cdot 3^{n-1}}$。 - $\frac{2|x|}{x^2+1} \le 1$ （由基本不等式 $x^2+1 \ge 2|x|$）。 - 三角函数有界性放缩：$|\sin x| \le 1, |\cos x| \le 1$。 - 适用条件：数列求和不等式证明、复杂函数值域或最值的粗略估计、选择题中通过范围排除错误选项。

解题方法与套路

  1. 明确目标不等式方向：确定要证的是“和 $<$ 某常数”还是“和 $>$ 某常数”，决定是将通项放大还是缩小。
  2. 拆项观察结构：写下待求和的通项，寻找它与等比数列、可裂项分式之间的“距离”。优先考虑保留前几项不动，对后面的项进行放缩，以保证精度。
  3. 构造等比或裂过渡量：
  4. 等比型：将分母缩小（或放大）成一个等比数列的通项，使放缩后的通项能构成无穷递缩等比数列。
  5. 裂项型：将通项放大（或缩小）为可裂项相消的差式，如 $\frac{1}{n^2} < \frac{1}{n(n-1)} = \frac{1}{n-1} - \frac{1}{n}$。
  6. 求和并比较：对放缩后的数列求和，得到中间和 $S'$，验证 $S \le S' < \text{目标}$ 或 $S \ge S' > \text{目标}$。
  7. 检查“等号”与起始项：
  8. 确认所证为严格不等式时，是否通过“保留前几项精确值，从某项开始放缩”的方式避免了等号成立。
  9. 检查不等号方向是否因放缩而反转。

高频易错

  • 放缩过度：将不等式的一边放得“太大”或“太小”，导致求和后越过了目标常数，证明失败。对策：尝试保留前1项或前2项精确值，从 $n\ge2$ 或 $n\ge3$ 开始放缩，并适当调整放缩的松紧度。
  • 不等号方向反转：在将分母扩大（分式变小）时，误用了缩小，导致方向错误。务必始终牢记“分母小则分式大”的原则。
  • 忽略首项条件：等比放缩时，公比必须满足绝对值小于1，且要验证放缩不等式对起始$n$成立。例如 $n=1$ 时 $3^1-1=2$，若强行用 $3^n-1\ge 2\cdot 3^{n-1}$，等号恰好成立，需确认不破坏整体严格性。
  • 裂项残留：构造裂项放缩时，未检验裂项求和后的剩余项，导致残留部分无法处理或不等式方向错误。
  • 选择题中的误用：利用放缩得到函数的上界或下界，但忽略了等号成立的条件，可能错失正确选项。例如 $|f(x)|\le 1$ 只能说明值域包含于 $[-1,1]$，不能说明函数图像一定在这个范围内达到边界。

代表题精讲

代表题1（2022-文-08，函数图像选择题）

题目：如图是区间 $[-3,3]$ 上某个函数的大致图像，判断该函数为
A. $y=\frac{x^3-3x}{x^2+1}$
B. $y=\frac{x^3-x}{x^2+1}$
C. $y=\frac{2x\cos x}{x^2+1}$
D. $y=\frac{2\sin x}{x^2+1}$
（图像特征：过原点，奇函数，局部有正有负，最大值约大于1）

思路：通过奇偶性、特殊点排除部分选项，对剩余可选项利用放缩法快速判断值域上界，与图像极值对比完成排除。

步骤：
1. 四个函数均为奇函数，图像关于原点对称，均过原点，无法直接排除。
2. 代入 $x=1$：A. $\frac{1-3}{2}=-1$；B. $\frac{1-1}{2}=0$；C. $\frac{2\cos1}{2}=\cos1>0$；D. $\frac{2\sin1}{2}=\sin1>0$。若图像在 $x=1$ 附近为负值，则排除C、D。
3. 利用放缩判断C的值域：$|y|=\frac{|2x\cos x|}{x^2+1}\le \frac{|2x|}{x^2+1}\le 1$ （因为 $x^2+1\ge2|x|$），所以 $y\in[-1,1]$。观察图像若存在函数值绝对值明显大于1的点，则C必排除。
4. 同理判断D：$|y|=\frac{|2\sin x|}{x^2+1}\le \frac{2}{x^2+1}\le 2$，上界较宽松，无法直接由值域排除。进一步结合零点（$\sin x=0$处为0）等特性可排除D。最终确认为A。

点评/变式：选择题中放缩法常用于“值域放大排除”，其核心是获得一个容易验证的上下界。变式训练：证明 $y=\frac{2x}{x^2+4}$ 的值域为 $[- \frac12, \frac12]$——可直接用基本不等式放缩。

代表题2（2014-理-17，数列不等式证明）

题目：已知数列 ${a_n}$ 满足 $a_1=1$，$a_{n+1}=3a_n+1$。
（Ⅰ）证明 ${a_n+\frac12}$ 是等比数列，并求 ${a_n}$ 的通项公式；
（Ⅱ）证明：$\frac1{a_1}+\frac1{a_2}+\cdots+\frac1{a_n} < \frac32$。

思路：（Ⅰ）构造等比数列，待定系数法求得常数项为 $\frac12$；（Ⅱ）求得通项 $a_n=\frac{3^n-1}{2}$，则 $\frac1{a_n}=\frac2{3^n-1}$。直接求和无法完成，需对分母进行放缩，将其变成等比数列求和。

步骤：
（Ⅰ）设 $a_{n+1}+\lambda = 3(a_n+\lambda)$，代入 $a_{n+1}=3a_n+1$ 得 $\lambda=\frac12$。故 ${a_n+\frac12}$ 是首项 $a_1+\frac12=\frac32$，公比 $3$ 的等比数列。
$a_n+\frac12 = \frac32\cdot 3^{n-1} = \frac{3^n}{2}$，通项 $a_n = \frac{3^n-1}{2}$。

（Ⅱ）由（Ⅰ）得 $\frac1{a_n}=\frac{2}{3^n-1}$。
当 $n=1$ 时，$\frac1{a_1}=1 < \frac32$，成立。
当 $n\ge2$ 时，放缩分母：$3^n-1 = 3^n-1 \ge 3^n - 3^{n-1} = 2\cdot 3^{n-1}$。
于是 $\frac{2}{3^n-1} \le \frac{2}{2\cdot 3^{n-1}} = \frac1{3^{n-1}}$。
因此求和：
$$ \sum_{k=1}^n \frac1{a_k} = 1 + \frac2{3^2-1} + \cdots + \frac2{3^n-1} \le 1 + \frac13 + \frac1{3^2} + \cdots + \frac1{3^{n-1}} $$ 右侧为等比数列求和：$1\times\frac{1-(\frac13)^n}{1-\frac13} = \frac32\left(1-\frac1{3^n}\right) < \frac32$。
综上，对一切正整数 $n$，原不等式成立。

点评/变式：本题的放缩核心是将 $3^n-1$ 缩小为 $2\cdot 3^{n-1}$，保留了等比结构。常犯错误是放缩为 $3^n-1 > 3^{n-1}$，此时放缩后的和为调和型，无法求和。若题目改为证 $< \frac54$，则需保留前两项精确值，从第三项放缩。变式：已知 $b_n=2^n-1$，证明 $\sum_{k=1}^n \frac1{b_k} < 2$。
