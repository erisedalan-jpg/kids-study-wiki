数值计算

考点定位

  • 父主题：其他
  • 权重 weight：1
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：选择7
  • 难度分布：易1

知识精要

  • 程序框图的构成：起止框、输入/输出框、处理框、判断框、流程线。循环结构由判断框控制循环的继续或终止。
  • 循环结构的两种类型：
  • 当型循环：先判断条件，条件成立时执行循环体，否则退出（满足条件则循环）。
  • 直到型循环：先执行循环体，再判断条件，条件不成立时继续循环，成立时退出（满足条件则跳出）。
  • 变量赋值与迭代：每次循环中，变量的值按框图中的运算公式更新。同一变量在不同循环轮次中会连续变化，需逐次追踪。
  • 循环变量的作用：通常有计数变量（如 $n=n+1$）和累加（积）变量，二者初始值及更新顺序直接影响结果。

解题方法与套路

  1. 读懂框图，确定结构
    明确起止框、输入输出框；识别循环体范围；看清判断框的条件，并区分当型/直到型。
  2. 列出关键变量，标出初始值
    在草稿纸上列出所有会被赋值的变量，按框图标注它们的初始值。
  3. 逐次模拟循环，表格化记录
    按循环次数顺序执行每一步，将每个变量在该次循环结束时的值填入表格。每一次判断条件后，决定是否继续或跳出。
  4. 留意边界，防止多一次或少一次
    当条件处于临界时，要特别小心是否在执行循环体后才判断、还是判断后执行循环体。可在草稿表格中标注“第k次进入”“第k次判断”。
  5. 归纳规律，简化计算（仅当循环次数多时）
    若循环次数较多，可从迭代关系发现数列规律（如等差、等比、斐波那契等），利用通项公式直接计算，避免机械运行数十次。

高频易错

  • 混淆当型与直到型循环：当型是“真则循环”，直到型是“真则跳出”。不明确结构会导致执行次序判断错误。
  • 初始值未正确设置：多数程序框图的变量初始值在框图开始处给定，容易遗漏，导致首轮计算即出错。
  • 赋值顺序错误：循环体内多条赋值语句若顺序不同，结果可能天差地别。必须严格按框图从上到下依次执行，不能随意调换。
  • 多算或少算一次循环：尤其是判断条件和循环体先后顺序不同时，临界值常造成输出值偏差 ±1。建议在边界手动测试：假设循环变量刚好取到判断条件值，模拟一遍确认。
  • 忘记更新计数变量：部分框图中计数变量 $n$ 的更新可能位于循环体末尾，容易忽略，导致输出值始终为初值。

代表题精讲

题目（2022 全国乙卷文科第 7 题）

执行所给的程序框图（框图略，主要逻辑为：初始 $b=2,\ a=1,\ n=1$；循环体依次执行 $b=b+a$，$a=b-a$，$n=n+1$；当满足某条件时输出 $n$），输出的 $n=$（ ）
A. 3  B. 4  C. 5  D. 6

思路
该题为典型的循环结构程序框图求输出值，循环体内涉及两个变量 $a,b$ 的迭代赋值，$n$ 为计数变量。由于循环次数不多，利用列表法逐步模拟运行即可。关键要抓住 $b=b+a$ 与 $a=b-a$ 这一对赋值的实际效果：一次更新后，$(a,b)$ 的新值相当于前两个值之和构成的新数对，本质是生成斐波那契数列的变体。

步骤
1. 列出初始值：$b=2,\ a=1,\ n=1$。
2. 第一次循环：
$b = b+a = 2+1 = 3$，
$a = b-a = 3-1 = 2$，
$n = n+1 = 2$。
此时 $(a,b)=(2,3)$，$n=2$。
3. 第二次循环：
$b = 3+2 = 5$，
$a = 5-2 = 3$，
$n = 2+1 = 3$。
此时 $(a,b)=(3,5)$，$n=3$。
4. 第三次循环：
$b = 5+3 = 8$，
$a = 8-3 = 5$，
$n = 3+1 = 4$。
此时 $(a,b)=(5,8)$，$n=4$。
5. 达到循环终止条件（框图通常判断 $b$ 是否超过某个阈值或满足特定不等式），跳出循环，输出 $n=4$。

点评/变式
本题核心是准确追踪赋值顺序，切忌将 $a=b-a$ 误认为是 $a=b-a_{\text{旧}}$。赋值语句中的右手边所有变量均取语句执行前的当前值。易错点在于判断循环何时停止，如条件为 $b>7$ 时跳出，则第三次循环后 $b=8>7$ 满足，输出 $n=4$；若条件写成 $b \geq 8$，可能在 $b=8$ 时多循环一次导致输出 $5$。
变式训练：更复杂的迭代如 $t=a,\ a=b,\ b=t+b$（斐波那契标准形式）或带条件判断的内层分支，均可用同一表格跟踪法解决。建议考生在草稿纸上清晰列出“步号—a—b—n—条件判断”五列，可有效避免少算或多算。
