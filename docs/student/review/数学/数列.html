知识精要

  • 等差数列
    • 定义：$a_{n+1} - a_n = d$（常数）。
    • 通项公式：$a_n = a_1 + (n-1)d$。
    • 前 $n$ 项和公式：$S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$。
    • 重要性质：若 $m+n=p+q$，则 $a_m + a_n = a_p + a_q$。
  • 等比数列
    • 定义：$\frac{a_{n+1}}{a_n} = q$（常数，$q \neq 0$）。
    • 通项公式：$a_n = a_1 q^{n-1}$。
    • 前 $n$ 项和公式：当 $q=1$ 时 $S_n = na_1$；当 $q \neq 1$ 时 $S_n = \frac{a_1(1-q^n)}{1-q}$。
    • 等比中项性质：若 $a, b, c$ 成等比，则 $b^2 = ac$。注意：此项常作为核心条件用于列方程。
  • 数列递推与构造
    • 线性组合构造：通过将已知递推关系式进行加减等线性运算，构造出新的等差或等比数列，是求解通项的关键方法。
    • 方程组思想：由新构造数列的通项公式与原数列通项的关系，建立方程组，解出所求通项。

解题方法与套路

  1. 定义与性质转化法 将题目中的等差或等比条件，直接转化为关于首项 $a_1$ 和公差 $d$（或公比 $q$）的方程。如利用“三项成等比数列”列出 $a_3 a_{10} = a_6^2$ 的关系式，求解基本量。
  2. 递推关系线性运算法（构造法） 对于形如 $\begin{cases} a_{n+1} = f(a_n, b_n) \ b_{n+1} = g(a_n, b_n) \end{cases}$ 的数列组，常对两式作和、差或倍数运算，以消去交叉项，构造出仅含 $a_n+b_n$ 或 $a_n-b_n$ 的新数列，并证明其为等差或等比数列。
  3. 通项公式反求法 先求出构造数列（如 ${a_n+b_n}$ 和 ${a_n-b_n}$）的通项公式，再将其视为关于 $a_n$ 和 $b_n$ 的二元一次方程组，通过解方程组直接反解出单个数列的通项公式。

高频易错

  • 等比数列条件的多解性：在利用等比中项 $b^2 = ac$ 列方程求解公差 $d$ 时，得到的方程通常是一元二次方程，会产生两个解。必须回代检验所有解是否符合题意（如是否导致等比数列某项为零），防止漏解。
  • 基本量运用混乱：在设基本量后，用 $a_1, d$（或 $a_1, q$）表示特定项（如 $a_3, a_6, a_{10}$）时，极易因项数推算错误导致方程列错。建议统一用 $a_n = a_m + (n-m)d$ 的形式从已知项出发，减少失误。
  • 构造后首项的计算遗漏：在证明新构造数列 ${a_n+b_n}$ 为等差或等比时，不仅要证明递推关系，还必须明确写出新数列的首项（如 $a_1+b_1$），否则后续的通项公式将无法正确写出。

代表题精讲

题目：已知 ${a_n}$ 和 ${b_n}$ 满足 $a_1=1, b_1=0, a_{n+1} = 4a_n - 3b_n - 4, b_{n+1} = 4b_n - 3a_n - 4$。证明 ${a_n+b_n}$ 是等比数列，${a_n-b_n}$ 是等差数列，并求 ${a_n}$ 和 ${b_n}$ 的通项公式。 思路：目标是证明两个构造数列的等差/等比性质。直接对给出的 $a_{n+1}$ 和 $b_{n+1}$ 的递推式分别进行相加和相减运算，观察结果是否符合定义。 步骤： 1. 运算构造： - 两式相加：$a_{n+1} + b_{n+1} = (4a_n - 3b_n - 4) + (4b_n - 3a_n - 4) = (a_n + b_n) - 8$。 - 两式相减：$a_{n+1} - b_{n+1} = (4a_n - 3b_n - 4) - (4b_n - 3a_n - 4) = 7(a_n - b_n)$。 2. 判定性质： - 由和式可得 $(a_{n+1}+b_{n+1}) - (a_n+b_n) = -8$，且首项 $a_1+b_1=1$。故 ${a_n+b_n}$ 是首项为1，公差为 $-8$ 的等差数列。 - 由差式可得 $\frac{a_{n+1}-b_{n+1}}{a_n-b_n} = 7$，且首项 $a_1-b_1=1$。故 ${a_n-b_n}$ 是首项为1，公比为 $7$ 的等比数列。 3. 求通项： - 由等差数列通项公式：$a_n + b_n = 1 + (n-1)(-8) = 9 - 8n$。 - 由等比数列通项公式：$a_n - b_n = 1 \times 7^{n-1} = 7^{n-1}$。 - 联立两式：$\begin{cases} a_n + b_n = 9-8n \ a_n - b_n = 7^{n-1} \end{cases}$，解得 $a_n = \frac{7^{n-1} - 8n + 9}{2}$，$b_n = \frac{9 - 8n - 7^{n-1}}{2}$。 点评/变式：本题的核心是“通过线性运算构造新数列”。注意最终证明需指明首项与公差/公比。变式训练：若递推关系变为系数不等的线性组合，如 $a_{n+1} = 2a_n + b_n, b_{n+1} = a_n + 2b_n$，则通常寻找待定系数进行组合，令 $a_{n+1} + \lambda b_{n+1} = k(a_n + \lambda b_n)$，转化为等比数列问题。

题目：等差数列 ${a_n}$ 中，$a_4=10$，且 $a_3, a_6, a_{10}$ 成等比数列，求 ${a_n}$ 前 20 项的和 $S_{20}$。 思路：利用已知项 $a_4$ 和公差 $d$ 表示出 $a_3, a_6, a_{10}$，代入等比中项条件 $a_3 \cdot a_{10} = a_6^2$，解出 $d$，进而求出 $a_1$ 和 $S_{20}$。 步骤： 1. 设基本量并表示目标项： 设公差为 $d$，由 $a_4=10$ 可得： $a_3 = a_4 - d = 10 - d$， $a_6 = a_4 + 2d = 10 + 2d$， $a_{10} = a_4 + 6d = 10 + 6d$。 2. 列方程求公差： 由等比中项性质有 $(10-d)(10+6d) = (10+2d)^2$。 展开得：$100 + 60d - 10d - 6d^2 = 100 + 40d + 4d^2$。 化简为：$10d^2 - 10d = 0$，即 $10d(d-1)=0$。 解得 $d=0$ 或 $d=1$。 3. 分类讨论求 $S_{20}$： - 当 $d=0$ 时，数列为常数列，$a_1 = a_4 = 10$。$S_{20} = 20 \times 10 = 200$。 - 当 $d=1$ 时，$a_1 = a_4 - 3d = 10 - 3 = 7$。$S_{20} = 20 \times 7 + \frac{20 \times 19}{2} \times 1 = 140 + 190 = 330$。 点评/变式：“等比中项”是方程的来源，“等差数列通项”是表达项的规则。本题极易漏掉 $d=0$ 的解而失分。无论题目是否明确“公差不为0”，只要方程解出零值，都必须保留并讨论。常数列既是等差数列又是公比为1的等比数列，满足“成等比”的条件。
