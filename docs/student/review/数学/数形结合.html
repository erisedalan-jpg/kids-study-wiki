知识精要

“数形结合”是高考核心数学思想，指将抽象的代数关系与直观的几何图形相互转化、相互补充，从而快速寻找解题思路。

  1. 以形助数（核心应用）

    • 函数与方程/不等式：利用函数图像研究方程根（零点）的个数、不等式解集。关键操作是绘制图像、寻找交点，尤其关注复杂函数、分段函数、含绝对值函数。
    • 线性规划：将约束条件表示为平面区域，将目标函数（如 $z = ax + by$）视为一组平行直线，通过平移直线在可行域边界上寻找最优解。截距型 $z = ax + by$ 最为常见。
    • 解析几何：将几何条件（如三角形形状、距离关系）代数化，建立方程求解；或将代数结果（如直线与圆锥曲线交点）对应回几何图形，理解其位置关系。
    • 立体几何：从三视图复原几何体，或直接依据题意建立空间直角坐标系，将空间角、距离等度量问题转化为向量坐标运算。

  2. 以数解形（精确计算）

    • 对几何图形建立坐标系，赋予几何元素坐标与方程，通过精确的代数计算证明几何性质或求解度量问题。如求椭圆离心率、异面直线夹角等。
    • 函数的性质（单调性、奇偶性、周期性、对称性）决定其图像特征，反之，从图像可以读出函数的性质。

  3. 关键结合点

    • 对称性：函数图像关于直线 $x=a$ 对称 $\Leftrightarrow f(a+x) = f(a-x)$；关于点 $(a, b)$ 中心对称 $\Leftrightarrow f(a+x) + f(a-x) = 2b$。交点也常常因此具有对称分布的特性。
    • 几何意义：绝对值 $|x-a|$ 表示数轴上点到点 $a$ 的距离；分式 $\frac{f(x)}{x}$ 的结构常与过原点或定点的连线斜率关联。

解题方法与套路

  1. 构图解题五步法（针对大多数压轴题）

    • 第一步：代数化归。 将题目条件转化为函数、方程或不等式。如判断零点个数，构造函数 $h(x) = f(x) - g(x)$，或变形为 $F(x) = G(x)$ 的形式。
    • 第二步：分析特征。 快速识别基本函数类型（幂、指、对、三角、二次函数等）及其图像特征，特别是对称性、周期性、渐近线、特殊定点等。
    • 第三步：精准绘图。 在坐标系中画出草图，标注关键点（零点、极值点、交点、区间端点）。对于分段函数，应分段作图。
    • 第四步：数形互助。 观察图形，寻找临界状态。如“恰有一个交点”通常对应直线与曲线相切、或过端点等临界情况。利用几何关系列方程。
    • 第五步：精细计算，写解答。 将临界条件转化为代数方程求解，并结合图形得出最终结果或范围。

  2. 线性规划标准解法

    • 第一步：画可行域。 将约束条件中的每条直线画出，通过取特殊点法确定不等式表示的区域，并取交集。
    • 第二步：目标函数几何化。 将 $z = ax+by$ 变形为 $y = -\frac{a}{b}x + \frac{z}{b}$，理解 $z$ 与直线在 $y$ 轴上截距的线性关系。
    • 第三步：平移找最优解。 依 $- \frac{a}{b}$ 方向平移直线，使截距取最大或最小值。最优解通常在可行域的顶点处取得。
    • 第四步：解方程组求顶点坐标，代入目标函数求值。

  3. 利用对称性处理多交点求和问题

    • 第一步：判断对称性。 判断所涉函数的图像是否具有同一对称轴或对称中心。
    • 第二步：分析交点分布。 根据对称性，所有交点的横坐标（或纵坐标）必定关于对称轴对称，或所有交点成对出现且关于对称中心中心对称。
    • 第三步：整体求和。 若对称轴为 $x=m$，则两两对称交点的横坐标之和为 $2m$，所有交点横坐标之和等于 $m \times \text{交点个数}$。若对称中心为 $(a,b)$，则成对交点的坐标之和为 $(2a, 2b)$。

高频易错

  1. 作图不准，忽略定义域。 绘制函数图像时，不关注定义域边界、渐近线、关键点的函数值，导致对交点个数的误判。特别是绘制二次函数在闭区间上的图像时，易忽略区间端点。
  2. 混淆代数推演与几何特征。 例如，将“函数 $f(x)$ 有极大值点 $a$”直接等同于“ $f'(a)=0$ 且 $f'(x)$ 在 $a$ 两侧变号”，而不结合 $f(x)$ 含有两个零点时，极大值点处的函数图象特征（即“穿而不变”的零点 $x=a$ 与“变号”的零点 $x=b$ 之间的关系）。
  3. 线性规划最优点判断错误。 对目标函数 $z=ax+by$，不分析 $b$ 的符号对截距与 $z$ 关系的影响，导致极大值与极小值错误。同时，易忽略斜率比较，将最优点取在了非最优的顶点上。
  4. 对称性应用失误。 对于 $f(x)$ 与 $g(x)$ 均关于直线 $x=a$ 对称，错误地认为它们的交点关于点 $(a,0)$ 对称。实际上，交点是关于直线 $x=a$ 对称的点的集合，成对交点的横坐标之和为 $2a$，纵坐标相等。
  5. 忽视参数对图形的影响。 对于含参数的函数（如 $y=a(x-3)$ 表示过定点 $(3,0)$ 的直线），在利用图形分析问题时，不讨论参数在不同范围时图形的动态变化，导致丢失临界情况。

代表题精讲

题目1 （2021-理-10）：设 $a \neq 0$，若 $a$ 为函数 $f(x)=a(x-a)^2 (x-b)$ 的极大值点，则（ ） 思路：首先，$a$ 是 $f(x)$ 的一个零点。根据“极大值点”的几何意义，函数在 $x=a$ 两侧的值都小于 $f(a)=0$。由于 $(x-a)^2$ 在 $x=a$ 处不变号，因此 $f(x)$ 在 $x=a$ 附近的符号完全由 $a(x-b)$ 决定。要使 $x=a$ 处取得极大值0，函数图像必须在 $a$ 的左右附近都位于 $x$ 轴下方（即 $f(x) \le 0$）。由此分析 $a$ 和 $b$ 的关系，并画出满足条件的函数草图。 步骤： 1. 零点分析：函数 $f(x)$ 的零点为 $x=a$ (为二重根) 和 $x=b$ (为一重根)。由于 $a \neq 0$ 且 $a$ 是极大值点，故 $a \neq b$，否则 $f(x)=a(x-a)^3$ 是单调函数，无极值。 2. 符号分析：在 $x=a$ 附近，$(x-a)^2 > 0$，因此 $f(x)$ 的符号与 $h(x)=a(x-b)$ 相同。 3. 画图分析：为使 $x=a$ 是极大值点，$f(x)$ 在 $x=a$ 左右附近的函数值应均小于 $f(a)=0$，即 $h(x)=a(x-b) < 0$ 在 $x=a$ 的一个去心邻域内恒成立。 4. 求解条件：一次函数 $h(x)$ 要在 $x=a$ 附近恒为负，其图像必须是过点 $(b,0)$ 且在该邻域位于 $x$ 轴下方的直线。这要求 $a$ 和 $b$ 满足特定关系。具体地，$h(a) = a(a-b) < 0$，必须 $a$ 与 $(a-b)$ 异号。将此不等式展开即得 $a^2 - ab < 0$，即 $ab > a^2$。对照选项为 $ab > a^2$。 点评/变式：本题核心是“以形助数”，将抽象的极值点概念转化为函数模型的零点和符号问题，再通过绘制符号草图快速建立不等式。避免了对三次函数求导后的复杂讨论。变式：若 $a$ 变为极小值点，则结论将变为 $ab < a^2$。

题目2 （2021-理-23）：已知函数 $f(x) = |x-a| + |x+3|$。（1）当 $a=1$ 时，求不等式 $f(x) \ge 6$ 的解集；（2）若 $f(x) > -a$，求 $a$ 的取值范围。 思路：（1）利用绝对值的几何意义：$|x-1| + |x+3|$ 表示数轴上动点 $x$ 到定点 $1$ 和 $-3$ 的距离之和。求距离之和不小于6的点的范围，直接在数轴上找临界点。（2）利用绝对值三角不等式 $|x-a| + |x+3| \ge |(x-a) - (x+3)| = |a+3|$，将恒成立问题转化为最值问题。 步骤： 1. （1）几何意义法：当 $a=1$ 时，$f(x) = |x-1| + |x+3|$。定点 $1$ 和 $-3$ 的距离为 $|1-(-3)| = 4$。 2. 设 $f(x)=6$，表示动点 $x$ 到两点距离之和为 $6$。由于 $6 > 4$，动点应在两点构成线段的外部。设该点到右端或左端距离为 $d$，则 $(4-d)+d + d = 6$，（或直接计算）求出临界点坐标。和式的几何意义表明，从线段中点向两侧，每远离1个单位，距离之和增加2。要使和为6，需从线段端点向外延长1个单位。故临界点为 $-3-1=-4$ 和 $1+1=2$。 3. 因此，满足 $f(x) \ge 6$ 的解集为 $(-\infty, -4] \cup [2, +\infty)$。 4. （2）最值转化法：由绝对值三角不等式，$f(x) = |x-a| + |x+3| \ge |(a-x)+(x+3)| = |a+3|$。当 $(x-a)(x+3) \le 0$ 时取等号，即最小值 $f(x){\min} = |a+3|$。 5. 要使 $f(x) > -a$ 恒成立，必须 $f(x) > -a$，即 $|a+3| > -a$。 6. 解绝对值不等式：等价于 $a+3 > -a$ 或 $a+3 < a$。前者解得 $a > -\frac{3}{2}$，后者无解。故 $a$ 的取值范围是 $(-\frac{3}{2}, +\infty)$。 点评/变式：本题是“以数解形”和“以形助数”的结合。第（1）问直接用绝对值的几何意义秒杀，第（2）问则利用代数恒等变形（绝对值不等式）找到几何最值，再解代数不等式。变式：若问题改为 $f(x)$ 的图像与直线 $y=k$ 有两个交点求 $k$ 的范围，则必须准确画出 $f(x)$ 的“V”形或平底梯形图像来分析。
