知识精要

数形结合是把抽象的代数关系与直观的几何图形相互转化的思想：用"形"辅助分析"数"（看图找关系），用"数"精确刻画"形"（建系算坐标）。高考中它不是独立题型，而是渗透在以下五类高频场景：

  • 线性规划（最高频）：约束条件 $\begin{cases}\cdots\end{cases}$ 表示平面可行域，目标函数 $z=ax+by$ 化为 $y=-\dfrac{a}{b}x+\dfrac{z}{b}$，$\dfrac{z}{b}$ 是直线在 $y$ 轴上的截距。平移直线，当 $b>0$ 时截距与 $z$ 同向（截距最大则 $z$ 最大）；当 $b<0$ 时相反。最优解一般在可行域顶点取得。
  • 方程根 / 函数交点：方程 $f(x)=g(x)$ 的根，等价于曲线 $y=f(x)$ 与 $y=g(x)$ 交点的横坐标。交点个数、横（纵）坐标之和常借助图象对称性：若两图象都关于直线 $x=a$ 对称，则交点成对出现，横坐标之和 $\sum x_i=ma$（$m$ 为交点个数）；若都关于点 $(a,b)$ 中心对称，则 $\sum x_i=ma$，$\sum y_i=mb$。
  • 绝对值的几何意义：$|x-x_1|+|x-x_2|$ 表示数轴上点 $x$ 到 $x_1,x_2$ 两点的距离之和（最小值为 $|x_1-x_2|$）；$|x-x_1|-|x-x_2|$ 为距离之差。集合的交并用数轴直观求解。
  • 解析几何中的几何性质：圆锥曲线求离心率时，把焦点、顶点、特殊角（如等腰三角形、垂直）画成图，利用对称性与几何关系（圆的直径所对圆周角为直角、弦心距等）直接读出点坐标，再代入方程，可大幅减少计算。
  • 导数 / 构造函数：含 $xf'(x)\pm f(x)$ 形式的条件，构造 $g(x)=\dfrac{f(x)}{x}$ 或 $g(x)=xf(x)$，由 $g'(x)$ 符号判断单调性，结合奇偶性"模拟"出图象草图，再读出不等式的解集。

核心口诀：代数定方向、几何看趋势、交点即根、对称配对、顶点取最值。

解题方法与套路

  1. 识别可数形结合的信号：出现"约束条件求最值""方程根的个数""图象交点坐标之和""含绝对值不等式""求离心率""$f'(x)$ 与 $f(x)$ 的组合不等式"等字眼，优先考虑作图。
  2. 线性规划五步法：① 把每个不等式画成边界直线并定半平面，交出可行域（注意虚实线、是否含边界）；② 将 $z=ax+by$ 改写为斜率为 $-\dfrac{a}{b}$ 的直线族；③ 平移该直线，由 $b$ 的正负判断 $z$ 随截距增减的方向；④ 找到使 $z$ 最优的顶点（多为两边界直线交点），联立解出坐标；⑤ 代回 $z$ 求值。
  3. 交点 / 根问题：① 把方程拆成两条已熟悉的曲线 $y=f(x)$、$y=g(x)$；② 在同一坐标系画草图，数交点个数；③ 利用对称性求坐标和——找出公共对称轴 $x=a$ 或对称中心 $(a,b)$，按 $\sum x_i=ma$ 直接得结果，不必逐根求解。
  4. 绝对值问题：把 $|x-x_1|+|x-x_2|$ 翻译为数轴上的距离之和，画出分段折线图（V 形），用临界点（绝对值零点）分区讨论，几何上找满足条件的区间端点。
  5. 构造函数判断不等式：见 $xf'(x)-f(x)<0$ 即 $\left(\dfrac{f(x)}{x}\right)'<0$，构造 $g(x)=\dfrac{f(x)}{x}$；由单调性、奇偶性（$f$ 奇 $\Rightarrow g$ 偶）和已知零点画 $g$ 的示意图象，把目标不等式（如 $f(x)>0\Leftrightarrow x\cdot g(x)>0$）转成图象的正负区间求解。
  6. 解析几何几何法：先按题意精确作图，标出焦点、顶点、对称点；利用对称性写出关键点坐标（含 $a,b,c$），代入曲线方程得到 $a,b,c$ 的等式，再求 $e=\dfrac{c}{a}$。

高频易错

  • 线性规划截距方向判错：当目标函数为 $z=2x+y$（$b>0$）时，截距最大 $z$ 最大；但若 $z=2x-y$（$b<0$），化为 $y=2x-z$，此时 $z$ 是截距的相反数，截距最小才 $z$ 最大，方向极易搞反。
  • 可行域边界虚实、开闭判断不清：不等式带等号画实线（含边界），不带等号画虚线（不含），最优点落在虚线上时该值取不到。
  • 求交点坐标和却去硬解每个根：忽视对称性导致计算量爆炸甚至无法求解，应先找对称轴 / 对称中心用 $\sum x_i=ma$。
  • 绝对值距离的几何含义记错：把"距离之和"当成"距离之差"，或临界点取错。
  • 构造函数选错形式：把 $xf'(x)-f(x)$ 误配成 $g(x)=x f(x)$（其导数是 $f+xf'$），应配 $g(x)=\dfrac{f(x)}{x}$（其导数分子恰为 $xf'(x)-f(x)$）。
  • 图象画得不准导致交点数误判：分段函数、对数函数、含绝对值函数要标清关键点（零点、对称轴、渐近线、端点取值），尤其端点开闭。
  • 离心率几何法漏掉范围限制 / 多解取舍：解出 $e$ 后须验证 $e>1$（双曲线）或 $0<e<1$（椭圆）。

代表题精讲

代表题一（2021·理·10，三次函数极值点与参数）

题目：设 $a\neq0$，若 $a$ 为函数 $f(x)=a(x-a)^2(x-b)$ 的极大值点，判断 $a,b$ 的大小关系（答案 $ab^2>a^3$，即选 D）。

思路：$f(x)$ 以 $x=a$ 为二重零点、$x=b$ 为单零点。画出三次函数图象——$x=a$ 处图象与 $x$ 轴相切（不变号），$x=b$ 处穿过（变号）。要使 $x=a$ 为极大值点，需结合首项系数 $a$ 的正负与零点位置，用图象判断 $a$ 与 $b$ 的相对大小。

步骤： 1. 由 $a\neq b$（否则 $f$ 单调无极值），$f$ 有二重根 $a$ 和单根 $b$，在 $x=a$ 附近不变号、$x=b$ 附近变号。 2. 分 $a>0$、$a<0$ 两类，结合"切点 $a$ 为极大值"画图：当 $a>0$ 时图象先升后切再降，要求 $b<a$；当 $a<0$ 时要求 $b>a$。 3. 两种情形统一写成 $a(a-b)>0$，即 $a^2>ab$，两边乘 $a$（按 $a$ 符号同向）整理得 $a^3a^3$，选 D。

点评：本题是"数（导数符号、根的重数）"与"形（三次曲线切 / 穿 $x$ 轴）"结合的范例。关键在于把"二重根处相切不变号"翻译成图象语言。变式：把"极大值点"改为"极小值点"，结论方向反转。

代表题二（2016·理·12 / 文·12，对称性求交点坐标和）

题目：函数 $f(x)$ 满足 $f(2-x)=f(x)$，$y=|x^2-2x-3|$ 与 $y=f(x)$ 的图象交点为 $(x_1,y_1),\cdots,(x_m,y_m)$，求 $\sum x_i$（答案：$m$，选 B）。

思路：两函数图象都关于直线 $x=1$ 对称，交点必关于 $x=1$ 成对出现，横坐标可两两配对求和。

步骤： 1. 由 $f(2-x)=f(x)$ 知 $f$ 的图象关于直线 $x=1$ 对称。 2. $y=|x^2-2x-3|=|(x-1)^2-4|$ 的图象也关于 $x=1$ 对称。 3. 两对称图象的交点关于 $x=1$ 对称，每对交点横坐标之和为 $2$。设共 $m$ 个交点（$m$ 对里每对和为 $2$，即 $\dfrac{m}{2}$ 对），故 $\sum x_i=\dfrac{m}{2}\times2=m$，选 B。

点评：抓住"公共对称轴"是此类题的命脉，根本不需要解方程。变式：若改为中心对称 $f(-x)=2-f(x)$（图象关于 $(0,1)$ 对称），则 $\sum(x_i+y_i)=m$（2016·理·12 即此型），方法完全平行。

代表题三（2020·文·15，线性规划求最值）

题目：$x,y$ 满足 $\begin{cases}x+y\ge-1\x-2y\le-1\x-y\le1\end{cases}$，求 $z=2x+y$ 的最大值（答案：$8$）。

思路：画可行域，把 $z=2x+y$ 化为 $y=-2x+z$，截距 $z$ 最大时 $z$ 最大，平移直线到可行域最右上顶点。

步骤： 1. 三条边界直线围出可行域（一个有界三角形区域）。 2. 目标函数化为 $y=-2x+z$，斜率 $-2$，截距即 $z$；$b=1>0$，截距最大则 $z$ 最大。 3. 平移直线 $y=-2x+z$ 至与可行域相切于右上顶点 $A$，$A$ 为 $x-2y=-1$ 与 $x-y=1$ 的交点，联立解得 $A(3,2)$。 4. 代入 $z=2\times3+2=8$。

点评：线性规划得分关键是"画准可行域 + 判对截距方向 + 顶点联立"。变式：把目标改为 $z=2x-y$（如 2014·理·9），则化为 $y=2x-z$，需让截距最小才使 $z$ 最大，方向相反，是最常见的失分陷阱。
