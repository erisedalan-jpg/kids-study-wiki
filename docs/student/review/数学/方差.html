知识精要

  • 方差的定义与计算：
  • 对于一组数据 $x_1, x_2, ..., x_n$，其方差 $s^2 = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})^2$。
  • 简化计算公式：$s^2 = \frac{1}{n} \sum_{i=1}^{n} x_i^2 - \bar{x}^2$。
  • 方差描述数据的离散程度或波动大小。方差越小，数据越集中稳定；方差越大，数据越分散。
  • 离散型随机变量的方差：
  • 若随机变量 $X$ 的分布列为 $P(X=x_i)=p_i$，期望 $E(X)=\mu$，则方差 $D(X) = \sum_{i=1}^{n} (x_i - \mu)^2 p_i$。
  • 重要计算公式：$D(X) = E(X^2) - [E(X)]^2$。
  • 性质：$D(aX+b) = a^2 D(X)$。
  • 常见分布模型：
  • 二项分布：若 $X \sim B(n, p)$，则期望 $E(X)=np$，方差 $D(X)=np(1-p)$。
  • 超几何分布：若 $X \sim H(N, M, n)$，期望 $E(X)=n \cdot \frac{M}{N}$，方差计算较复杂，可依据定义或公式 $D(X)=\frac{nM(N-M)(N-n)}{N^2(N-1)}$。
  • 数据特征稳健性：
  • 一组数据经过去掉极端值等处理后，平均数、方差、极差易受极端值影响而变化，而中位数通常保持稳定（不变量）。

解题方法与套路

  1. 样本数据特征的快速判断法：
  2. 特值法/极端化思想：直接代入简单的数字（如较为对称或不对称的数据列），观察去掉最大值和最小值前后各统计量的变化。这是解决选择题的高效杀手锏。
  3. 定义分析法：明确中位数只取决于中间位置的数据；方差、极差取决于所有数据或两端极值；平均数取决于全体数据之和。
  4. 离散型随机变量方差求解“三步走”：
  5. 第一步（定型）：识别随机变量服从何种分布。若为二项分布、超几何分布等常见模型，直接套用对应的期望、方差公式，极大简化计算。
  6. 第二步（列表）：若为一般的离散变量，先根据题意求出 $X$ 的所有可能取值，并逐一准确计算对应的概率，列出分布列（务必验证概率和是否为1）。
  7. 第三步（计算）：选择最优方法求 $D(X)$。一般优先使用公式 $D(X)=E(X^2)-[E(X)]^2$，分别求出 $E(X)$ 与 $E(X^2)$ 再相减，此法常比直接用定义计算更简便。
  8. 决策型问题通用策略：
  9. 比较两个方案的优劣，不能仅比较期望（平均水平），必须综合比较期望与方差。
  10. 若期望相同或接近，选择方差较小的方案（风险小、收益稳定）。
  11. 若期望差异大，需结合实际背景权衡收益与风险。

高频易错

  • 方差与数据变换的关系：容易记错删除或增加数据对方差的影响。切记，去掉一个最高分和一个最低分，数据的波动范围极大概率会变小，因此方差通常会改变（变小），而非不变。
  • 二项分布与超几何分布的模型混淆：
  • 二项分布：应用于有放回抽取或总体数量极大几乎不影响概率的场合。
  • 超几何分布：应用于无放回抽取且总体数量明确的场合。若判断错分布类型，方差公式会完全用错。
  • 期望、方差计算失误：在分布列的计算中，务必将 $X$ 的取值（如收益 $X$）与概率准确对应。千万不要把变量值直接代入公式时抄错，尤其在分段函数型（如利润函数）背景下，需先由条件确定 $X$ 在不同区间对应的值。
  • 对方差单位的忽视：方差计算结果的单位是原始数据单位的平方，仅在比较相对波动大小时使用，无具体实际单位的比较意义。
  • 中位数的“不变”特性理解：中位数只与中间位置的一个或两个数据有关，与两端的极值无关，这一根本特征决定了去掉两端值后中位数不变。

代表题精讲

代表题一：2019-理-05

  • 题目：9位评委的原始评分去掉1个最高分和1个最低分后得到7个有效评分，判断哪一数字特征保持不变。
  • 思路：本题属概念辨析题，最优解法为利用数据的统计特征定义并结合特殊数值进行排除。
  • 步骤：
  • 设9个原始评分从小到大排序为 $x_1 \le x_2 \le ... \le x_9$。
  • 原始中位数为 $x_5$；去掉 $x_1$ 与 $x_9$ 后7个数据中位数为 $x_5$，故中位数不变。
  • 极差由 $x_9-x_1$ 变为 $x_8-x_2$，一般情况下缩小，极差改变。
  • 由于去掉了分值，总分必然改变，平均数 $ \bar{x} $ 随之改变，故平均数改变。
  • 平均数改变，多数数据到平均数的距离改变，方差通常会改变（变小）。
  • 点评/变式：此题考“不变”，中位数是最稳健的特征量。变式可变为问“一定变小的是”，则答案为方差或极差。应牢记：在数据去掉极端值后，方差通常反映更集中的样本波动，会变小。

代表题二：2012-理-18

  • 题目：花店每日购进16/17枝花，售价10元，进价5元，未售出则作垃圾处理。基于100天需求记录计算利润的期望与方差，并决策购进数量。
  • 思路：本题为典型的经济决策应用题，核心是先建立利润关于需求量的分段函数，在需求频率已知的基础上求离散随机变量（利润）的分布列、期望及方差，最后用期望和方差做双重评判。
  • 步骤：
  • 建模：设日需求量 $n$，进16枝。当 $n \ge 16$ 时，利润 $y=80$ 元；当 $n \le 15$ 时，利润 $y=10n-80$ 元。
  • 求分布列：以频率代替概率。$X$ 的可能取值为 $60, 70, 80$。 $P(X=60)=P(n=14)=0.1$； $P(X=70)=P(n=15)=0.2$； $P(X=80)=P(n \ge 16)=0.16+0.16+0.15+0.13+0.10=0.7$。
  • 求期望：$E(X)=60 \times 0.1 + 70 \times 0.2 + 80 \times 0.7 = 76$。
  • 求方差：先求 $E(X^2)=60^2 \times 0.1 + 70^2 \times 0.2 + 80^2 \times 0.7 = 5820$，则 $D(X)=E(X^2)-[E(X)]^2 = 5820 - 76^2 = 5820 - 5776 = 44$。
  • 决策：同理计算购进17枝时的利润 $Y$ 的期望 $E(Y)=76.4$，方差 $D(Y)=142.64$。购进17枝时期望稍增但方差剧增，即利润波动风险显著加大。若倾向稳定经营，选16枝；若追求略高收益且可承担风险，选17枝。答案不唯一，理由充分即可。
  • 点评/变式：该题是方差应用的“母题”。在独立重复的二项分布模型下，方差公式可极大简化计算。如2017年代表题，产品抽取满足二项分布 $X \sim B(100, 0.02)$，直接得 $D(X)=np(1-p)=100 \times 0.02 \times 0.98 = 1.96$，避免复杂列表，务必熟练掌握。
