显著性检验

考点定位

  • 父主题：概率统计
  • 权重 weight：6
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：解答17
  • 难度分布：易1

知识精要

  • 显著性检验的基本目的：利用样本数据推断总体参数（如均值）之间是否存在显著差异，或某项指标是否有显著提高/降低。本题为两个独立样本均值差异的单侧检验。
  • 关键统计量：
  • 样本均值：$\bar{x} = \dfrac{1}{n}\sum_{i=1}^{n} x_i$，反映数据的集中趋势。
  • 样本方差：$s^2 = \dfrac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$ （注意题目规定分母为 $n$，不是 $n-1$），反映数据离散程度。
  • 本题给定的判断规则（简化版检验准则）：
    若 $\bar{y} - \bar{x} \ge \sqrt{\dfrac{s_1^2 + s_2^2}{10} \times 2}$，则认为新设备均值较旧设备有显著提高，否则无显著提高。
    这相当于用样本差值与基于合并方差构建的“临界差”进行比较。
  • 适用条件：两独立样本，样本量相等（均为 $n=10$），方差未知但通过样本方差估计，判断规则由题目直接给出，无需查表。

解题方法与套路

  1. 整理数据：分别列出旧设备、新设备的10个数据，防止抄错。
  2. 计算样本均值：
    $\bar{x} = \dfrac{\text{旧数据总和}}{10}, \quad \bar{y} = \dfrac{\text{新数据总和}}{10}$。
    计算时可用对应均值简化方差计算。
  3. 计算样本方差（分母用 $n$，本题 $n=10$）：
    $s^2 = \dfrac{1}{10}\sum_{i=1}^{10}(x_i - \bar{x})^2$，即先求各数据与均值之差的平方，再求平均。新、旧设备方差分别计算。
  4. 构造并计算比较量：
    依据题目公式，计算
    $\text{门槛值} = \sqrt{\dfrac{s_1^2 + s_2^2}{10} \times 2}$，
    再计算 $\bar{y} - \bar{x}$。
  5. 作判断：
    若 $\bar{y} - \bar{x} \ge \text{门槛值}$，则回答“有显著提高”；否则回答“无显著提高”。
  6. 规范结论：需用题目原话明确给出判断结果。

高频易错

  • 方差分母误用 $n-1$：题目未说明时，默认样本方差分母用 $n$，尤其根据真题解析，直接除以10。用 $n-1$ 会导致方差略大，门槛值变化，可能影响判断。
  • 计算错误：数字较多，减法、平方、求和易出错。建议列表计算差值再平方，逐项核对；也可用计算器二次检验。
  • 均值代入错误：$\bar{y} - \bar{x}$ 与方差对应关系混乱，注意新设备均值 $\bar{y}$ 减旧设备均值 $\bar{x}$，顺序不可颠倒。
  • 误读判断规则：把 $\sqrt{\dfrac{s_1^2 + s_2^2}{10} \times 2}$ 根号下漏掉 $2$ 或错放位置；或者把“≥”当成“>”严格不等。
  • 单位与精度：结果通常保留合适的小数位，均值与方差计算要与题目数据精度匹配，本题均值保留一位或两位，方差保留三位小数。
  • 直接描述偏差：要求准确表达“有显著提高”而不是“有提高”或“明显提高”，与题目设问一致。

代表题精讲

题目

某厂用新、旧设备各生产10件产品，得到产品某项指标数据（已给）。记旧设备样本均值为 $\bar{x}$，方差为 $s_1^2$；新设备样本均值为 $\bar{y}$，方差为 $s_2^2$。
（1）求 $\bar{x},\bar{y},s_1^2,s_2^2$；
（2）若 $\bar{y} - \bar{x} \ge \sqrt{\dfrac{s_1^2+s_2^2}{10}\times 2}$，认为新设备指标均值较旧设备有显著提高，否则无显著提高。据此判断。

思路

题目已给出全部数据及判断标准，直接按“均值→方差→差值→门槛→比较”的流程求解。注意计算细心，可用性质 $\sum (x_i-\bar{x})^2 = \sum x_i^2 - n\bar{x}^2$ 辅助检验，但直接逐项减平方更直观。

步骤

  1. 计算均值：
    $\bar{x} = \dfrac{9.8+10.3+10.0+10.2+9.9+9.8+10.0+10.1+10.2+9.7}{10} = \dfrac{100}{10}=10$；
    $\bar{y} = \dfrac{10.1+10.4+10.1+10.0+10.1+10.3+10.6+10.5+10.4+10.5}{10} = \dfrac{103}{10}=10.3$。

  2. 计算旧设备方差 $s_1^2$：
    各数据减10：$-0.2, 0.3, 0, 0.2, -0.1, -0.2, 0, 0.1, 0.2, -0.3$；
    平方：$0.04,0.09,0,0.04,0.01,0.04,0,0.01,0.04,0.09$；
    和 $=0.36$，故 $s_1^2 = \dfrac{0.36}{10}=0.036$。

  3. 计算新设备方差 $s_2^2$：
    各数据减10.3：$-0.2, 0.1, -0.2, -0.3, -0.2, 0, 0.3, 0.2, 0.1, 0.2$；
    平方：$0.04,0.01,0.04,0.09,0.04,0,0.09,0.04,0.01,0.04$；
    和 $=0.40$，故 $s_2^2 = \dfrac{0.40}{10}=0.04$。

  4. 构造门槛并比较：
    $\sqrt{\dfrac{s_1^2+s_2^2}{10}\times 2} = \sqrt{\dfrac{0.036+0.04}{10}\times 2} = \sqrt{0.0076\times 2} = \sqrt{0.0152} \approx 0.1233$；
    $\bar{y}-\bar{x}=10.3-10=0.3$；
    显然 $0.3 \ge 0.1233$，故满足条件。

  5. 结论：新设备生产产品的该项指标均值较旧设备有显著提高。

点评/变式

  • 本题属于“给出判别式”的显著性检验，重点考查统计量的规范计算与认真程度；只要方差分母用 $10$、根号内正确代入，便是送分题。
  • 变式一：若标准改为 $\bar{y} - \bar{x} \ge \sqrt{\dfrac{2(s_1^2+s_2^2)}{10}}$ ，或要求“是否显著降低”，只需调整比较方向。
  • 变式二：样本量不相等时，可能会给出类似 $ \sqrt{\dfrac{s_1^2}{n_1}+\dfrac{s_2^2}{n_2}}$ 的门槛，需根据实际 $n$ 灵活代入。
  • 延伸思考：本题简化了检验过程（不查表、不算精确显著性水平），旨在体会“用样本推断总体差异”的思想。若标准门槛变大（如临界值更严格），可能得到“无显著提高”的结论，提示“显著”依赖于标准设定。
