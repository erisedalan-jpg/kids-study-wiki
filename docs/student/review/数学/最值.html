知识精要

函数的最值问题是函数与导数模块的核心，贯穿整个高中数学。核心知识点如下： - 基本初等函数的最值： - 二次函数 $f(x)=ax^2+bx+c$ 在 $\mathbb{R}$ 上：$a>0$ 有最小值 $\frac{4ac-b^2}{4a}$，无最大值；$a<0$ 有最大值，无最小值。闭区间 $[m,n]$ 上：在端点及对称轴 $x=-\frac{b}{2a}$ 处取最值。 - 三角函数：$y=A\sin(\omega x+\varphi)+B$ 或 $y=A\cos(\omega x+\varphi)+B$ 的最值为 $|A|+B$ 或 $-|A|+B$。$y=a\sin x+b\cos x$ 可化为 $\sqrt{a^2+b^2}\sin(x+\varphi)$ 求最值。 - 指数/对数函数：利用单调性求最值，特别注意复合函数定义域。 - 导数法求最值： - 对于可导函数 $f(x)$，在闭区间 $[a,b]$ 上的最值求解步骤：第一步，求导函数 $f'(x)$；第二步，解方程 $f'(x)=0$ 及不可导点，得到区间内所有极值可疑点；第三步，比较所有极值可疑点函数值与端点值 $f(a),f(b)$，最大者为最大值，最小者为最小值。 - 对于开区间 $(a,b)$ 或无穷区间，通过判断单调性及区间端点/无穷远处的极限趋势来确认最值的存在性。 - 不等式法求最值： - 基本不等式：$a,b>0$ 时，$a+b \ge 2\sqrt{ab}$（和定积最大），$ab \le \left(\frac{a+b}{2}\right)^2$（积定和最小）。需严格遵守“一正二定三相等”。 - 绝对值不等式：$|a|-|b| \le |a \pm b| \le |a|+|b|$。常用于求 $|x-a|+|x-b|$ 型函数的最小值（图像法或几何意义更佳）。 - 其他模型中的最值： - 线性规划：$z=ax+by$ 型目标函数，在约束条件的可行域顶点处取得最值。 - 向量中的数量积 $\vec{a}\cdot\vec{b}$ 的最值，常转化为坐标运算或利用 $|\vec{a}\cdot\vec{b}| \le |\vec{a}||\vec{b}|$。 - 立体几何中体积/面积最值，先建立目标函数（如设为高 $h$ 或角 $\theta$ 的函数），再利用导数或不等式求解。 - 解析几何中的距离、面积最值常转化为函数问题或利用几何性质（如对称性、定义）求解。

解题方法与套路

  1. 明确目标函数与定义域： 仔细审题，将所求最值的量（面积、长度、表达式值）表示为某个变量（设为 $x$，或点的坐标）的函数 $f(x)$。定义域是生命线，必须根据题意明确写出自变量的取值范围。
  2. 选择最优方法：
    • 初等函数型：若函数为熟悉的二次、三角、对勾函数等类型，优先采用配方法、三角恒等变换、图像法或单调性法直接求最值。
    • 复杂函数型：若函数较为复杂（如超越函数积、商、指对混合），必须求导。令导数等于零求出极值可疑点，再结合端点值比较。
    • 和、积、倒数和结构型：若表达式可化为“和定”或“积定”的形式，且变量为正，优先尝试基本不等式及变形（如 $a+b+c \ge 3\sqrt[3]{abc}$）。
    • 两点距离、线段和差型：优先考虑几何意义，如将 $\sqrt{(x-a)^2+(0-b)^2}$ 看作点 $(x,0)$ 到 $(a,b)$ 的距离，将 $|x-a|+|x-b|$ 看作数轴上点到两点距离之和。线性规划问题用几何法求截距、斜率、距离的最值。
    • 多元变量型：利用题设条件（如等式关系 $g(x,y)=0$）进行消元，将多元函数化为一元函数。若消元困难或表达式对称，可考虑利用不等式（如 $\sqrt{ab} \le \frac{a+b}{2}$）整体构造或换元。
  3. 验证取等条件与极值点： 利用基本不等式必须验证等号能否成立，这是填空题和解答题的得分关键。利用导数，需列表确认函数在极值可疑点两侧的单调性变化，并比较所有极值点与端点的函数值。若为开区间，需判断函数在该区间的最大值/最小值趋势。

高频易错

  • 混淆三角函数性质：如误将 $y=\sin 2x$ 和 $y=\sin(2x-\frac{\pi}{4})$ 的对称轴、零点看作相同。通过令相位整体等于标准值可避免混淆。
  • 基本不等式忽略“正”和“定”：看到 $a+b$ 就想用 $2\sqrt{ab}$，却忽略 $a,b$ 可能为负。“和定”与“积定”是前提，不能随意构造。
  • 定义域/参数范围判断失误：
    • 求分段函数或带参数的最值时，忽略了分段区间的断点或参数变动对定义域的影响。
    • 如真题中根据 $f(x) \ge -\frac{8}{9}$ 求参数 $m$，需准确平移区间并分段解析，容易遗漏右端点。
  • 导数与端点值比较遗漏：导数等于零的点不一定是整个区间的最值点，必须与区间端点函数值比较。这是解答题扣分的重灾区。
  • 几何最值建模错误：
    • 立体几何中建系或设变量后，函数关系列错，如将高与底面半径的关系误写为和的关系。
    • 解析几何中面积公式忘写系数 $\frac{1}{2}$，或最值点对应的几何位置不存在。
  • 线性规划区域判断错误：将虚线与实线混淆，导致可行域边界取否判断错误，进而使最值点选错。

代表题精讲

2024-新课标Ⅱ-14

  • 题目：在 $4\times4$ 方格表选4个方格，每行每列恰选一个，求选法总数及选中4个数之和的最大值。
  • 思路：这是一个排列组合与最值的综合题。第一空是经典错位排列模型：逐行选列，列号不重复，为 $4!$ 种。第二空，需理解所有 $4!$ 种选法中，每种选法对应一个和。直接求所有和的最大值，数据固定，可穷举或分析。最优策略是优先将每行的最大值选出，但需兼顾列限制。由于方格表数据未知，此题核心实为理解模型后列举或逻辑推理。
  • 步骤：
    1. 求选法总数：第一行可在4列中选一个，有4种；第二行只能选剩余3列，有3种；以此类推，共 $4 \times 3 \times 2 \times 1 = 24$ 种。
    2. 分析最大和：要使和最大，应尽量选每行最大的数。但若某列的最大数在多行出现，则产生冲突。
    3. 求最大值：观察表格（原题有数据），将每行的最大两个数找出，尝试组合，使每列只占一个。通过简单列举最优组合，即可得到最大和。（此题因表格数据缺失，仅演示方法）
  • 点评/变式：此题将“排列数”与“最值筛选”结合，新高考趋势。关键在于理解两种约束：模型约束（每行每列恰一个）与数据约束（数值大小）。变式：“在一个 $n \times n$ 矩阵中，求此模型下的最大值/最小值”。

2024-新课标Ⅱ-09

  • 题目：对于函数 $f(x)=\sin 2x$ 和 $g(x)=\sin(2x-\frac{\pi}{4})$，判断零点、最大值、最小正周期和对称轴是否相同。（多选）
  • 思路：逐一验证四个选项。涉及三角函数的基本性质，直接利用相应公式和结论分别求出两个函数各自的属性，再进行比较。
  • 步骤：
    1. 验证零点（A选项）：令 $f(x)=0$，得 $2x=k\pi \Rightarrow x=\frac{k\pi}{2}$。令 $g(x)=0$，得 $2x-\frac{\pi}{4}=k\pi \Rightarrow x=\frac{k\pi}{2}+\frac{\pi}{8}$。零点集不同，A错误。
    2. 验证最大值（B选项）：两者最大振幅均为1，故最大值均为1，B正确。
    3. 验证最小正周期（C选项）：$T_f=\frac{2\pi}{2}=\pi$，$T_g=\frac{2\pi}{2}=\pi$，C正确。
    4. 验证对称轴（D选项）：$f(x)$ 对称轴方程 $2x=\frac{\pi}{2}+k\pi \Rightarrow x=\frac{\pi}{4}+\frac{k\pi}{2}$。$g(x)$ 对称轴方程 $2x-\frac{\pi}{4}=\frac{\pi}{2}+k\pi \Rightarrow x=\frac{3\pi}{8}+\frac{k\pi}{2}$。对称轴不同，D错误。 故选：BC
  • 点评/变式：本题属基础题，考查三角函数基本通性通法。易错点在于平移变换后，误以为所有性质都不变。变式：“判断 $f(x)=\cos 2x$ 与 $g(x)=\sin(2x+\frac{\pi}{3})$ 的上述性质异同”。

2022-文-11

  • 题目：函数 $f(x)=\cos x + (x+1)\sin x + 1$ 在区间 $[0,2\pi]$ 的最小值、最大值分别为多少。
  • 思路：函数形式较复杂，非标准三角函数，直接求最值的最佳方案是对 $f(x)$ 求导，通过研究其单调性，找到区间内的极值点，再与端点值比较得出最值。
  • 步骤：
    1. 求导：$f'(x) = -\sin x + \sin x + (x+1)\cos x = (x+1)\cos x$。
    2. 求极值可疑点：令 $f'(x)=0$，在 $[0,2\pi]$ 上，得 $x+1=0$（无解），或 $\cos x=0$。解得 $x_1=\frac{\pi}{2}$，$x_2=\frac{3\pi}{2}$。
    3. 比较函数值：计算极值可疑点和端点的函数值。
      • $f(0) = \cos 0 + (0+1)\times 0 + 1 = 2$。
      • $f(\frac{\pi}{2}) = 0 + (\frac{\pi}{2}+1) \times 1 + 1 = \frac{\pi}{2}+2$。
      • $f(\frac{3\pi}{2}) = 0 + (\frac{3\pi}{2}+1) \times (-1) + 1 = -\frac{3\pi}{2} - 1 + 1 = -\frac{3\pi}{2}$。
      • $f(2\pi) = \cos 2\pi + (2\pi+1)\sin 2\pi + 1 = 2$。
    4. 定结论：比较四个值 $2, \frac{\pi}{2}+2, -\frac{3\pi}{2}, 2$，最大值为 $\frac{\pi}{2}+2$，最小值为 $-\frac{3\pi}{2}$。
  • 点评/变式：利用导数求超越函数最值的标准范例。注意：求导后能分解因式是极大简化运算的关键。本题极值点恰好在区间内，直接比较端点即可。易错点为代值计算错误及漏算端点值。变式：“求 $f(x)=\cos x + (x+2)\sin x + 1$ 在 $[0,2\pi]$ 上的最值”。
