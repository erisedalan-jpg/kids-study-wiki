知识精要

  • 二元一次不等式组与可行域：由若干个关于 $x,y$ 的一次不等式组成的约束条件，所有满足约束条件的点 $(x,y)$ 构成的平面区域称为可行域。每一个不等式对应一条直线分出的半平面，可行域是这些半平面的交集（通常为凸多边形）。
  • 线性目标函数的最值：对于形如 $z=ax+by$（$b \neq 0$）的线性目标函数，可改写为 $y=-\dfrac{a}{b}x+\dfrac{z}{b}$，即将 $z$ 看作直线在 $y$ 轴上的截距的 $b$ 倍（当 $b>0$ 时，截距越大 $z$ 越大；$b<0$ 时截距越大 $z$ 越小）。
  • 最值点存在定理：若可行域非空且有界，线性目标函数的最大（小）值必在可行域的某个顶点处取得；若可行域无界，可能无最值，但若存在最值，也可在顶点处取得或通过边界趋势判断。

解题方法与套路

  1. 写出约束条件并确定直线：将不等式组中的每个不等号改为等号，得到对应的边界直线方程，明确各直线的斜率和截距。
  2. 画出可行域：逐一直线作图，利用特殊点（如原点）检验不等式方向，用阴影正确标出可行域（注意虚实线：含等于为实线，不含为虚线）。
  3. 求出可行域顶点坐标：通过联立边界直线方程，求出所有相邻边界交点的坐标，并根据是否满足所有约束条件确认是否为可行域顶点。
  4. 平移目标函数直线：将目标函数 $z=ax+by$ 变形为 $y=-\frac{a}{b}x+\frac{z}{b}$，画出初始直线 $y=-\frac{a}{b}x$，在可行域内沿纵截距增大（$b>0$ 求最大）或减小（$b>0$ 求最小）方向平移，找出“最后接触”可行域的点就是最优解。
  5. 代顶点比较：若可行域为封闭凸多边形，直接将所有顶点坐标代入 $z$ 表达式求值，比较大小即得最值；若边界平行于目标函数直线，可能出现无穷多最优解（一条线段上的点均是）。
  6. 得结论：写出取得最值时对应的点的坐标和 $z$ 的最大（小）值。

高频易错

  • 不等式方向与区域混淆：将 $y \ge kx+b$ 误判为直线下方，实际为直线上方；检验时选用不在边界上的点（通常为原点）最保险。
  • 忽视整数解或隐含条件：若题目暗示 $x,y$ 为整数，求最值后必须验证坐标是否为整数点，否则需要调整到附近整点再比较。
  • 误判斜率与最优解：当目标函数直线的斜率与某条边界直线斜率相等时，可能存在整条线段上的点都是最优解，此时最大（小）值唯一但最优解不唯一。
  • 实线与虚线处理不当：约束条件含等号边界可用实线表示该线上的点可取；不含等号用虚线，线上的点不满足约束，代入要排除。
  • 目标函数变形后的符号：若 $b<0$，$z$ 与截距 $\frac{z}{b}$ 的变化方向相反，即截距越大 $z$ 越小（因为除以负数），此时必须小心平移方向，避免最值搞反。

代表题精讲

代表题 1：2015-理-14（2015全国卷II理科14题）

题目
若 $x$，$y$ 满足约束条件 $\begin{cases} x-y+1 \ge 0,\ x-2y \le 0,\ x+2y-2 \le 0, \end{cases}$ 则 $z=x+y$ 的最大值为____。

思路
本题是标准线性规划求最大值问题。目标函数为 $z=x+y$，系数均为正，可改写为 $y=-x+z$，$z$ 即为直线的纵截距，截距越大 $z$ 越大。画出三条边界直线围成的可行域，计算顶点坐标并代入比较，即可得最大值。

步骤
1. 边界直线为：
$l_1: x-y+1=0$，即 $y=x+1$；
$l_2: x-2y=0$，即 $y=\frac{1}{2}x$；
$l_3: x+2y-2=0$，即 $y=1-\frac{1}{2}x$。
2. 确定可行域：代原点 $(0,0)$ 检验：$0-0+1\ge0$ 成立，故原点在 $l_1$ 的下方区域；$0-0\le0$ 成立，故原点在 $l_2$ 的下方（含线上方？注意 $x-2y\le0$ 即 $y\ge \frac{1}{2}x$，取直线上方）；$0+0-2\le0$ 成立，原点在 $l_3$ 的下方。可行域是三条直线围成的三角形区域（包含边界）。
3. 求顶点：
联立 $\begin{cases} x-y+1=0 \ x-2y=0 \end{cases}$，解得 $x=-2,y=-1$，得点 $A(-2,-1)$；
联立 $\begin{cases} x-y+1=0 \ x+2y-2=0 \end{cases}$，两式相减 $(-3y+3=0)\Rightarrow y=1, x=0$，得点 $B(0,1)$；
联立 $\begin{cases} x-2y=0 \ x+2y-2=0 \end{cases}$，两式相加 $2x-2=0\Rightarrow x=1, y=\frac12$，得点 $C(1,\frac12)$。
4. 代入 $z=x+y$：
$A: -2+(-1)=-3$；
$B: 0+1=1$；
$C: 1+\frac12 = \frac32$。
最大值 $\frac32$ 在点 $C$ 处取得。

点评/变式
本题可行域三个顶点均为两直线直接交点，无多余约束，简单直接。目标函数 $z=x+y$ 的直线斜率为 $-1$，恰好介于 $l_2$ 斜率 $\frac12$ 和 $l_3$ 斜率 $-\frac12$ 之间，因此最优解唯一。若将目标函数变为 $z=2x+y$，则需重新比较斜率判定平移方向；若约束中某个不等号改为“≥”，变化可行域形状可能导致最值点不同。此外，实际考试中若可行域复杂，可先把顶点求全再代入，安全高效。
