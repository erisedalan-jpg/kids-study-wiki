最小二乘法

考点最小二乘法权重5真题数1学科数学父主题概率统计

考点定位

  • 父主题：概率统计
  • 权重 weight：5
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：解答19
  • 难度分布：中1

知识精要

  • 线性回归方程：研究两个具有线性相关关系的变量 $x$ 与 $y$，方程形如 $\hat{y}=\hat{b}x+\hat{a}$。
  • 最小二乘法原理：使所有样本点到回归直线的竖直距离的平方和最小，以此估计 $\hat{b}$ 和 $\hat{a}$。
  • 参数估计公式（样本数据 $(x_i,y_i), i=1,2,\dots,n$，均值为 $\bar{x},\bar{y}$）： $$\hat{b} = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{\sum_{i=1}^{n}(x_i-\bar{x})^2} = \frac{\sum_{i=1}^{n}x_i y_i - n\bar{x}\bar{y}}{\sum_{i=1}^{n}x_i^2 - n\bar{x}^2}$$ $$\hat{a} = \bar{y} - \hat{b}\bar{x}$$
  • 重要性质：回归直线必过样本中心点 $(\bar{x},\bar{y})$；回归直线用于预测时，代入的自变量值不宜离样本范围太远。
  • 适用条件：两变量呈近似的线性相关（通常先考察散点图或相关系数；高考题一般直接给出数据要求计算，默认可建立线性回归方程）。

解题方法与套路

  1. 变量转换与准备
    若题干给出的自变量不是直接可加的序号（如年份），应将其转化为等差数列编号（如 $t=1,2,\dots$），使计算简化。明确样本容量 $n$。

  2. 计算基本统计量（按公式所需）

  3. 均值 $\bar{x},\bar{y}$。
  4. 求和项：$\sum x_i$、$\sum y_i$、$\sum x_i y_i$、$\sum x_i^2$。
  5. 或使用离差形式：$\sum(x_i-\bar{x})^2$、$\sum(x_i-\bar{x})(y_i-\bar{y})$。

  6. 列表格辅助计算，防止数据错漏。

  7. 代入公式求系数
    先求 $\hat{b}$（斜率），再代入 $\hat{a} = \bar{y} - \hat{b}\bar{x}$ 求截距。结果按要求保留小数（通常精确到 0.1 或 0.01）。

  8. 回归分析与应用

  9. 分析变化：由 $\hat{b}$ 的正负说明增长或下降，由 $\hat{b}$ 的绝对值说明变化速率（“平均每增加一个单位 $x$，$y$ 增加 $\hat{b}$ 个单位”）。
  10. 预测：将目标自变量 $x_0$ 代入回归方程计算 $\hat{y}_0$，注意解释预测值（慎用过远外推）。

高频易错

  • 未对年份进行简化处理：直接用 2007~2013 作 $x$ 导致 $\sum x_i$、$\sum x_i^2$ 巨大，极易算错且浪费时间。务必转换为 $t=1,2,3,\dots$
  • 混淆 $\hat{b}$ 的分子分母：记牢 $\hat{b}=\frac{\sum (x_i-\bar{x})(y_i-\bar{y})}{\sum (x_i-\bar{x})^2}$，分母是自变量的离差平方和，千万不可颠倒。
  • $\hat{a}$ 错写成 $\bar{y}-\hat{b}x_i$：截距必须用均值 $\bar{y}-\hat{b}\bar{x}$ 计算，不能用某个样本点代入。
  • 忘记回归直线过样本中心：可用 $(\bar{x},\bar{y})$ 快速检验所求方程是否合理。
  • 预测时自变量编号对应错误：如预测 2015 年，$t$ 应取 9（按 2007 年 $t=1$ 推得），若误用 8 则全部失分。
  • 单位与小数位数不按要求：题干单位（千元）、附表中的数据精度是扣分高发区。

代表题精讲

题目
（2014 全国理·19）给出 2007—2013 年农村居民人均纯收入 $y$ 与年份代号 $t$（$t=1,\dots,7$）的数据表，要求（Ⅰ）求 $y$ 关于 $t$ 的线性回归方程；（Ⅱ）利用回归方程分析收入变化情况，并预测 2015 年的人均纯收入。附斜率和截距的最小二乘估计公式。

思路
- 先将年份转化成的 $t$ 已给出，直接使用。样本容量 $n=7$。
- 计算 $\bar{t},\bar{y}$ 以及所需的 $\sum t_i y_i$、$\sum t_i^2$。可列表累加。
- 代入公式求出 $\hat{b},\hat{a}$，写出回归方程。
- 第（Ⅱ）问依赖第（Ⅰ）问结果：先由斜率解释“平均每年增加…千元”，再把 2015 年对应 $t=9$ 代入方程得预测值。

步骤
第（Ⅰ）问： - 计算均值：$\bar{t}=\frac{1+2+\dots+7}{7}=4$，$\bar{y}=\frac{2.9+3.3+3.6+4.4+4.8+5.2+5.9}{7}=\frac{30.1}{7}=4.3$。 - 计算 $\sum t_i y_i = 1\times2.9 + 2\times3.3 + \cdots + 7\times5.9 = 134.4$（列式算得）。
$\sum t_i^2 = 1^2+2^2+\dots+7^2 = 140$。 - 代入公式：
$\hat{b} = \frac{\sum t_i y_i - n\bar{t}\bar{y}}{\sum t_i^2 - n\bar{t}^2} = \frac{134.4 - 7\times4\times4.3}{140 - 7\times4^2} = \frac{134.4 - 120.4}{140 - 112} = \frac{14}{28} = 0.5$
$\hat{a} = \bar{y} - \hat{b}\bar{t} = 4.3 - 0.5\times4 = 2.3$ - 回归方程：$\hat{y} = 0.5t + 2.3$。

第（Ⅱ）问： - 分析变化：斜率 $\hat{b}=0.5>0$，说明 2007—2013 年该地区农村居民人均纯收入逐年增长，平均每年增加约 0.5 千元。 - 预测：2015 年对应 $t=9$，代入得 $\hat{y} = 0.5\times9 + 2.3 = 6.8$（千元）。
故预测该地区 2015 年农村居民人均纯收入为 6.8 千元。

点评/变式
- 本题为“最小二乘法”的模板题，关键在于列表计算不出错，并牢记 $\hat{a}$ 必须用均值计算。
- 若遇到非线性趋势（如指数增长），可能给换元提示（例如 $y=c e^{dx}$ 两边取对数），本质仍转化为线性回归。
- 变式训练：将年份编号改为 $t=2007,2008,\dots$ 直接计算，体会运算量的巨大差异，强化“先编号”的意识。
- 预测时注意题目是否要求合理评价：例如不能无限制外推，可说明“基于近年增长趋势的估计，实际收入会受到多种因素影响”。
