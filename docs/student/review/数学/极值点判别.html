极值点判别

考点极值点判别权重5真题数1学科数学父主题函数与导数

考点定位

  • 父主题：函数与导数
  • 权重 weight：5
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：填空16
  • 难度分布：难1

知识精要

  • 极值点定义：设函数 $f(x)$ 在 $x_0$ 附近有定义，若对附近任一 $x\neq x_0$ 恒有 $f(x)>f(x_0)$（或 $f(x)<f(x_0)$），则 $x_0$ 为极小（大）值点。极值点是函数单调性改变的分界点。
  • 一阶判别法：$f'(x_0)=0$ 且在 $x_0$ 左右导数 异号（左正右负为极大，左负右正为极小）。仅有 $f'(x_0)=0$ 不保证是极值点。
  • 二阶判别法：若 $f'(x_0)=0$ 且 $f''(x_0)\neq0$，则 $f''(x_0)>0$ 时 $x_0$ 为极小值点，$f''(x_0)<0$ 时 $x_0$ 为极大值点。当 $f''(x_0)=0$ 时失效，需回到一阶判别。
  • 含参极值点问题转化：极值点分布条件常转化为导函数 $f'(x)$ 变号零点的个数与位置问题。进一步可分参或构造两个函数，转化为两函数图象交点的条件（交点横坐标对应零点）。
  • 指数函数求导：$(a^x)'=a^x\ln a$（$a>0$且 $a\neq1$）；特别注意 $0<a<1$ 时 $\ln a<0$，导数符号反转，函数递减。

解题方法与套路

  1. 求导定号：写出 $f'(x)$，令 $f'(x)=0$ 并化为便于分析的形式（常将非零因子分离）。
  2. 方程分参：把方程 $f'(x)=0$ 拆成 $g(x)=h(x)$ 的形式，使得 $g(x)$ 和 $h(x)$ 的图象容易画出（如一线一曲线，或一条过原点的直线与一条指数/对数型曲线）。
  3. 图象定参：
  4. 画图讨论参数对 $g(x)$ 或 $h(x)$ 的影响（如底数 $a$ 对指数函数陡峭程度的影响）；
  5. 结合原函数的极大、极小值点的顺序（如 $x_1<x_2$ 分别为极小、极大值点），确定 $f'(x)$ 的符号变化规律（哪段正、哪段负），从而确定两函数图象的上下关系。
  6. 临界求界：找到满足条件的参数临界状态——通常是两函数图象相切（此时导函数零点重合，无极值点或为拐点）。利用切点处的函数值相等、导数值相等，解出参数临界值。
  7. 范围验证：结合单调性分析及图象上下关系，在临界值划分的区间内取特殊值检验，确定最终参数的取值范围。

高频易错

  • 忽视导数变号：误以为 $f'(x_0)=0$ 就是极值点。必须验证 $x_0$ 两侧 $f'(x)$ 异号。尤其在参数讨论中，导函数零点可能为“不穿过”的零点（重根或切线碰零点），此时并非极值点。
  • 忽视底数对单调性的影响：$a^x$ 及 $\ln a$ 的符号在 $a>1$ 和 $0<a<1$ 时相反。不分类讨论直接画图极易搞错导函数符号，导致极大极小位置颠倒。
  • 混淆极大值与极小值点的顺序条件：题干给出 $x_1<x_2$ 且指定谁是极小、谁是极大，这直接决定 $f'(x)$ 在区间上的正负号。必须将代数式与图象的上下关系严格对应，否则会解出反向的不等式。
  • 处理“过原点的切线”时的疏漏：设切点求斜率，往往利用切点既在曲线上又在切线上，切点处导数等于切线斜率。对抽象函数如 $g(x)=a^x\ln a$，求导时要小心 $(\ln a)^2$ 等表达式。
  • 边界取舍错误：临界值（如切线斜率与直线斜率相等时）通常需舍去，因为此时两图象相切，零点为二重根，导数不变号，无两个不同极值点。

代表题精讲

题目：已知 $x=x_1$ 和 $x=x_2$ 分别是函数 $f(x)=2a^x - ex^2$（$a>0$ 且 $a\neq1$）的极小值点和极大值点。若 $x_1<x_2$，求 $a$ 的取值范围。

思路：求导得 $f'(x)=2(a^x\ln a - ex)$。极值点对应 $f'(x)$ 的变号零点，即方程 $a^x\ln a = ex$ 有两根 $x_1,x_2$。由极值点性质知，当 $x<x_1$ 时 $f'(x)<0$，$x_10$，$x>x_2$ 时 $f'(x)<0$。这等价于曲线 $y=a^x\ln a$ 与直线 $y=ex$ 的图象有两个交点，且先交处曲线在直线下方，后交处曲线上穿再下穿。分 $a>1$、$0<a<1$ 画图，可知只有 $0<a<1$ 才可能满足符号变化。进一步，当 $a$ 变小时指数曲线变陡，临界为直线 $y=ex$ 与 $y=a^x\ln a$ 相切于某点，利用切点条件求出临界 $a$，再由图象上下关系确定 $a$ 的范围。

步骤： 1. 求导：$f'(x)=2a^x\ln a - 2ex = 2(a^x\ln a - ex)$。 2. $f'(x)$ 的正负取决于 $g(x)=a^x\ln a$ 与直线 $h(x)=ex$ 的大小关系：$f'(x)>0 \iff a^x\ln a > ex$（注意 $\ln a$ 符号，下文分情况）。 3. 因 $x_1$ 极小，$x_2$ 极大且 $x_1<x_2$，可得 $f'(x)$ 的符号： $$x<x_1: f'(x)<0;\quad x_10;\quad x>x_2: f'(x)<0.$$ 即 $g(x)$ 与 $h(x)$ 图象的关系：$(-\infty,x_1)$ 上 $g(x)ex$；$(x_2,+\infty)$ 上 $g(x)1$，则 $\ln a>0$，$g(x)=a^x\ln a$ 为下凸增函数且恒正。直线 $y=ex$ 过原点，二者至多有一个交点（或相切），无法产生上述要求的两交点且符合符号变化，故 $a>1$ 不成立。 5. 因此 $0<a<1$，此时 $\ln a<0$，$g(x)=a^x\ln a$ 恒负，且 $a^x$ 递减，$g(x)$ 单调递增（因为负值减少）。画出草图：指数型曲线在 $x$ 轴下方，从左向右上升趋于0；直线 $y=ex$ 过原点。二者可有两个交点，第一个交点附近曲线从下方穿越到上方？需结合 $f'(x)$ 的符号：在 $x$ 趋于 $-\infty$ 时 $a^x\ln a$ 负无穷（？）实际上 $a^x \to +\infty$，乘以负的 $\ln a$ 得 $-\infty$，而 $ex\to -\infty$，比较需要极限。为确保有两交点和正确的符号变化，需要直线与曲线相交情况为：在较小交点的左邻域 $g(x)ex$，右邻域 $g(x)<ex$。对于 $0<a<1$，曲线 $g(x)$ 是递增且上凸（？需要二阶导验证），但可通过几何条件分析。 6. 临界情形：直线 $y=ex$ 与 $y=a^x\ln a$ 相切。设切点为 $(x_0, a^{x_0}\ln a)$，则切线斜率满足 $g'(x_0)=a^{x_0}(\ln a)^2 = e$，且切线过原点：$a^{x_0}\ln a - 0 = e(x_0-0) \Rightarrow a^{x_0}\ln a = ex_0$。联立得： $$\begin{cases} a^{x_0}(\ln a)^2 = e \ a^{x_0}\ln a = ex_0 \end{cases}$$ 两式相除得 $\ln a = \frac{1}{x_0}$，即 $x_0 = \frac{1}{\ln a}$。代入第一式得 $a^{1/\ln a}(\ln a)^2 = e$。由于 $a^{1/\ln a} = e^{\frac{\ln a}{\ln a}} = e$，故 $e(\ln a)^2 = e \Rightarrow (\ln a)^2=1 \Rightarrow \ln a = -1$（因 $0<a<1$ 舍去正1）。得 $a = e^{-1} = \frac{1}{e}$。 7. 当 $a=1/e$ 时，直线与曲线相切，导函数只有一个二重零点，无极值点，不满足题意。要得到两个不同极值点且符号正确，需直线斜率 $e$ 小于曲线在原点附近某点的变化率使得有两个交点。结合图象分析，当 $a$ 越接近0时，曲线越陡。实际当 $a>1/e$ 且 $a<1$ 时，可满足条件。所以范围为 $\frac{1}{e} < a < 1$。答案写成 $(\frac{1}{e}, 1)$。

点评与变式：本题典型地体现“极值点→导函数变号零点→两图象交点”的转化链。过原点的切线提供绝佳的临界情形，利用切点双重条件求出参数界限是高频技巧。变式可改为极大值点极小值点反过来，或更换为对数型函数，核心思想一致。务必注意底数范围分讨论和导数符号与图象上下关系的精确对应。
