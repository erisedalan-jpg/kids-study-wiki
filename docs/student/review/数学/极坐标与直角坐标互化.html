极坐标与直角坐标互化

知识精要

  • 互化公式：极坐标 $(\rho, \theta)$ 化为直角坐标 $(x,y)$： $$x = \rho \cos \theta,\quad y = \rho \sin \theta$$ 直角坐标 $(x,y)$ 化为极坐标 $(\rho, \theta)$： $$\rho = \sqrt{x^2+y^2},\quad \tan \theta = \frac{y}{x}\ (x \neq 0)$$ 其中 $\rho \ge 0$，$\theta$ 通常由点所在象限及 $\tan \theta$ 共同确定，一般取 $\theta \in [0, 2\pi)$ 或指定范围。

  • 常见曲线方程形式：

    • 直线：极坐标方程常见形式如 $\rho \cos\theta = a$（垂直于极轴的直线）、$\rho \sin\theta = b$（平行于极轴的直线）；一般式 $A\rho \cos\theta + B\rho \sin\theta + C = 0$ 可直接化为 $Ax + By + C = 0$。
    • 圆：圆心在极点半径为 $r$ 时方程为 $\rho = r$；圆心在极轴上常见 $\rho = 2a\cos\theta$（过极点，圆心 $(a,0)$），$\rho = 2a\sin\theta$（过极点，圆心 $(0,a)$）。
    • 曲线方程互化时，若极坐标方程中出现 $\sin(\theta \pm \varphi)$ 或 $\cos(\theta \pm \varphi)$，应先用和差角公式展开，再代入 $x, y$ 化简。

  • 参数方程：

    • 圆 $(x-a)^2 + (y-b)^2 = r^2$ 的参数方程：$x = a + r\cos t,\ y = b + r\sin t$（$t$ 为参数）。
    • 椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 的参数方程：$x = a\cos t,\ y = b\sin t$。
    • 参数方程化为普通方程的核心是消参，常用方法：代入消元、利用恒等式（如 $\sin^2 t + \cos^2 t = 1$）。

解题方法与套路

  1. 极坐标方程化为直角坐标方程（通用步骤）

    • 构造 $\rho\cos\theta$ 与 $\rho\sin\theta$：将方程整理成包含 $\rho\cos\theta$、$\rho\sin\theta$ 或 $\rho^2$ 的形式。若出现单独 $\sin\theta$ 或 $\cos\theta$，通常需要两边同乘 $\rho$ 以构造 $\rho$ 与三角函数的乘积。
    • 展开三角结构：方程中若有 $\sin(\theta + \theta_0)$ 或 $\cos(\theta + \theta_0)$，先用两角和差公式 $\sin(\alpha \pm \beta)$，$\cos(\alpha \pm \beta)$ 展开。
    • 整体代换：将 $\rho\cos\theta$ 换为 $x$，$\rho\sin\theta$ 换为 $y$，$\rho^2$ 换为 $x^2+y^2$。
    • 化简整理：得到直角坐标系下的直线或曲线方程，注意是否需要附加变量的取值范围限制。

  2. 直角坐标方程化为极坐标方程

    • 代入：直接令 $x = \rho\cos\theta,\ y = \rho\sin\theta$ 代入方程。
    • 三角化简：整理后往往可提取 $\rho$ 或利用三角恒等式化简为 $\rho = f(\theta)$ 或 $F(\rho, \theta) = 0$ 的形式。

  3. 参数方程化为普通方程

    • 方法一（代入法）：由其中一个方程解出参数，代入另一个方程。
    • 方法二（三角恒等式法）：若参数以三角函数形式出现（如 $x = a\cos t, y = b\sin t$），利用 $\sin^2 t + \cos^2 t = 1$ 消参，得到 $\left(\frac{x}{a}\right)^2 + \left(\frac{y}{b}\right)^2 = 1$。
    • 注意消参后普通方程中变量 $x, y$ 的取值范围应与参数方程定义域对应。

  4. 涉及交点、轨迹与最值问题的处理策略

    • 交点：将曲线方程化成同一种坐标系（通常选直角坐标），联立求解。
    • 轨迹：设出动点坐标，利用几何关系或条件等式，建立轨迹方程。若求极坐标轨迹，可先建直角坐标方程再转化，或直接寻找 $\rho$ 与 $\theta$ 的关系。务必结合动点实际运动范围确定变量的限制区间。
    • 最值：若点在参数曲线上（如椭圆），可将目标表达式设为参数 $t$ 的函数，利用三角函数有界性或二次函数性质求解最值。

高频易错

  • $\rho$ 的符号与边界问题：互化公式中默认 $\rho \ge 0$，但有些极坐标方程允许 $\rho < 0$（视为反向延长线上的点）。实际考题中，利用 $x = \rho\cos\theta, y = \rho\sin\theta$ 变形时通常不涉及负 $\rho$，但由直角坐标反求 $\rho$ 时必有 $\rho \ge 0$。轨迹问题中容易忽略 $\rho$ 非负对 $\theta$ 范围的压缩，导致轨迹不闭合或多余。
  • 角度 $\theta$ 的多值性：由 $\tan\theta = y/x$ 求 $\theta$ 时，必须结合 $(x,y)$ 所在象限确定唯一角度，不能仅写 $\theta = \arctan(y/x)$。
  • 方程变形中的增根或失根：
    • 极坐标方程两边同乘 $\rho$ 时，会引入 $\rho=0$（即极点）这个点。若原方程中极点本就不满足条件，检验后应舍去或说明；若极点本身适题意，则保留。
    • 参数方程消参时，若参数范围有限制（如 $0 \le t \le \pi$），消参后普通方程必须标注 $x, y$ 的相应范围，仅给出方程而忽略范围是常见失分点。
  • 题目坐标系混用：参数方程通常是基于直角坐标系的表达，不要误当成极坐标。审题时务必看清题目是在何种坐标系下描述曲线，尤其注意条件中同时出现直角坐标参数方程与极坐标方程时，需统一坐标系后再处理。
  • 直线极坐标方程化简：$\rho\sin(\theta+\frac{\pi}{3}) + m = 0$ 类方程展开时，$\sin(\theta+\frac{\pi}{3})$ 系数计算易出错。展开后务必重新检查 $\sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}, \cos\frac{\pi}{3} = \frac{1}{2}$ 的代入。

代表题精讲

代表题一：2022·文/理·22

题目：给定直线 $l$ 的极坐标方程 $\rho\sin(\theta+\frac{\pi}{3})+m=0$，曲线 $C$ 的参数方程为 $x=\sqrt{3}\cos 2t,\ y=2\sin t$（$t$ 为参数）。求 $l$ 的直角坐标方程；若 $l$ 与 $C$ 有公共点，求 $m$ 的取值范围。

思路： （1）利用两角和正弦公式展开极坐标方程，构造 $\rho\cos\theta, \rho\sin\theta$，代换为 $x, y$ 即得直角坐标方程。 （2）$C$ 为参数方程，需先转化为普通方程或直接代入。注意到 $x$ 中参数为 $2t$，可用二倍角公式化为关于 $\sin t$ 的表达式，与 $y$ 建立联系消参。再将直线方程与曲线方程联立，化为关于 $\sin t$ 的二次方程。由 $l$ 与 $C$ 有公共点，即方程在 $\sin t \in [-1,1]$ 内有解，转化为二次函数或二次方程在闭区间上的根分布问题求 $m$ 范围。

步骤： 1. 化 $l$ 为直角坐标： 展开 $\rho(\sin\theta\cos\frac{\pi}{3} + \cos\theta\sin\frac{\pi}{3}) + m = \frac{1}{2}\rho\sin\theta + \frac{\sqrt{3}}{2}\rho\cos\theta + m = 0$。 代换得 $\frac{1}{2}y + \frac{\sqrt{3}}{2}x + m = 0$，整理为 $\sqrt{3}x + y + 2m = 0$。

  1. 化 $C$ 为普通方程： $x = \sqrt{3}\cos 2t = \sqrt{3}(1-2\sin^2 t)$，已知 $y = 2\sin t$，即 $\sin t = \frac{y}{2}$。 代入得 $x = \sqrt{3}\left(1 - 2\cdot\frac{y^2}{4}\right) = \sqrt{3} - \frac{\sqrt{3}}{2}y^2$。 由于 $t$ 任意，$\sin t \in [-1,1]$，故 $y \in [-2, 2]$；$x = \sqrt{3}(1-2\sin^2 t)$ 在 $\sin t \in [-1,1]$ 时范围是 $[-\sqrt{3}, \sqrt{3}]$。 整理普通方程为 $\frac{\sqrt{3}}{2}y^2 + x - \sqrt{3} = 0 \ \Rightarrow \ x = \sqrt{3} - \frac{\sqrt{3}}{2}y^2$（$y \in [-2,2]$）。

  2. 联立求交点条件： 将 $x$ 代入直线方程：$\sqrt{3}\left(\sqrt{3} - \frac{\sqrt{3}}{2}y^2\right) + y + 2m = 0 \ \Rightarrow \ 3 - \frac{3}{2}y^2 + y + 2m = 0$。 整理得 $\frac{3}{2}y^2 - y - (2m+3) = 0 \ \Rightarrow \ 3y^2 - 2y - 2(2m+3) = 0$。

  3. 转化为方程在 $[-2,2]$ 有解求 $m$： 令 $f(y) = 3y^2 - 2y - 4m - 6$，问题等价于 $f(y)=0$ 在 $y \in [-2,2]$ 上有根。 二次函数开口向上，对称轴 $y = \frac{1}{3} \in [-2,2]$。故需满足最小值非正且端点值非负： $\Delta = 4 + 12(4m+6) \ge 0 \Rightarrow m \ge -\frac{19}{12}$（保证实根）； 区间内有根等价于 $f(-2)\cdot f(2) \le 0$ 或端点值异号及最小值点验证等。由于对称轴在区间内，更严谨为： $f\left(\frac{1}{3}\right) \le 0$ 且 $\max{f(-2), f(2)} \ge 0$。 计算 $f(-2) = 12+4-4m-6=10-4m \ge 0 \Rightarrow m \le \frac{5}{2}$； $f(2) = 12-4-4m-6=2-4m$； $f(\frac{1}{3}) = \frac{1}{3} - \frac{2}{3} - 4m -6 = -\frac{1}{3}-4m-6 = -4m - \frac{19}{3} \le 0 \Rightarrow m \ge -\frac{19}{12}$。 综合得 $-\frac{19}{12} \le m \le \frac{5}{2}$。

点评/变式： 本题将参数方程、极坐标方程交汇，核心是统一为直角坐标后利用参数的范围转化为函数有界性问题。易错点在于消参后忽略 $y \in [-2,2]$，直接使用判别式 $\Delta \ge 0$ 会导致范围扩大。变式可考直线与曲线相交弦长、或改为直线与下半部分椭圆有公共点等。
