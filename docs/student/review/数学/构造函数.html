知识精要

构造函数是导数应用中的核心思想，主要用于解不等式、比大小和求参数范围。其理论根基是导数与单调性的关系：若 $F'(x) > 0$，则 $F(x)$ 单调递增；若 $F'(x) < 0$，则 $F(x)$ 单调递减。结合特殊点的函数值（如 $F(0)=0$），可将抽象不等式转化为自变量的比较。

常见构造函数模型（必须牢记导数形式，逆向联想原函数）： 1. 和差型：由 $f'(x) \pm g'(x) > 0$ 构造 $F(x) = f(x) \pm g(x)$。 2. 积商型： - $xf'(x) + f(x) \rightarrow [x f(x)]'$； - $xf'(x) - f(x) \rightarrow \left[\frac{f(x)}{x}\right]'$； - $f'(x) + f(x) \rightarrow [\mathrm{e}^x f(x)]'$； - $f'(x) - f(x) \rightarrow \left[\frac{f(x)}{\mathrm{e}^x}\right]'$； - $f'(x)g(x) + f(x)g'(x) \rightarrow [f(x)g(x)]'$； - $f'(x)g(x) - f(x)g'(x) \rightarrow \left[\frac{f(x)}{g(x)}\right]'$（常见 $g(x)=x^n,\ \mathrm{e}^x$ 等）。 3. 比大小模型：通过将待比较的式子变形为同一函数在不同点处的值，利用单调性判定。例如比较 $2\ln1.01$ 与 $\sqrt{1.04}-1$，设 $x=0.01$，构造 $F(x)=2\ln(1+x)-\sqrt{1+4x}+1$。 4. 奇偶性平移：若 $f(x)$ 为奇函数，则 $\frac{f(x)}{x}$ 一般为偶函数；结合单调性可快速画草图，解 $f(x)>0$ 等价于 $x\cdot\frac{f(x)}{x}>0$，用数形结合。

适用条件：题目出现抽象函数导数不等式（如 $xf'(x) < f(x)$）、含参不等式恒成立、超越式大小比较等，优先考虑构造函数。

解题方法与套路

  1. 观察结构，联想导数：将条件中的 $f'(x)$ 与 $f(x)$ 的组合与上述常见模型的导数形式对照，确定构造函数 $F(x)$。必要时两边同乘正因子（如 $x$，$\mathrm{e}^x$）。
  2. 确定新函数及定义域：写出 $F(x)$，特别关注使分母为零的点、对数真数定义域等，这些是后期解不等式的分段点。
  3. 判断单调性与奇偶性：求 $F'(x)$，利用已知不等式判断其符号，得出单调区间。若涉及奇偶性，计算 $F(-x)$ 进行验证。
  4. 利用特殊点求值：代入如 $F(0), F(1), F(-1)$ 等已知值，作为解不等式的临界点。
  5. 转化原问题：
  6. 解抽象不等式：将 $f(x) > 0$ 等变形为 $F(x) > 0$ 或 $x\cdot F(x) > 0$ 等形式，结合单调性与特殊点列不等式组。
  7. 比较大小：将数转化为同一函数的不同函数值，由自变量大小及单调性推出结果。
  8. 求参数范围：按单调性求出含参最值，构建关于参数的不等式，再构造函数求解。
  9. 写出答案，务必回验定义域。

高频易错

  • 忽略定义域：如构造函数 $F(x)=\frac{f(x)}{x}$ 时漏掉 $x \neq 0$，解不等式时讨论不全，导致解集错误。
  • 导数符号与单调性混淆：$F'(x) < 0$ 是减函数，自变量增大函数值反而减小，处理不等式时方向易反。
  • 奇偶性判断失误：误把 $\frac{f(x)}{x}$（$f$ 奇）当成奇函数，实际上它是偶函数，画错草图会直接选错。
  • 构造时漏乘因子：如看到 $f'(x) + 2f(x)$ 应联想 $\mathrm{e}^{2x}f(x)$，漏掉指数系数导致无法整合。
  • 不等式传递不当：在解复合不等式时，忽略中间变量的符号，盲目乘除导致不等号方向错误。例如由 $x<y$ 推 $\ln|x-y|$ 的正负，需讨论绝对值。
  • 比大小选模失误：未将常数合理参数化（设 $x$），导致函数复杂难以求导，或没有统一为相同自变量的函数值。

题目1（2021·理·12）

已知 $a = 2\ln1.01$，$b = \ln1.02$，$c = \sqrt{1.04} - 1$，比较 $a, b, c$ 的大小。

思路 $a = \ln(1.01^2) = \ln1.0201$，直接与 $b=\ln1.02$ 比较可得 $a>b$。难点在 $a$ 与 $c$、$b$ 与 $c$。引入参数 $x=0.01$，则 $a = 2\ln(1+x)$，$b = \ln(1+2x)$，$c = \sqrt{1+4x} - 1$。通过构造函数，利用导数和单调性比较大小。

步骤 1. 比较 $a$ 与 $b$：$a=\ln1.0201 > \ln1.02 = b$，所以 $a>b$。 2. 比较 $a$ 与 $c$：令 $F(x) = 2\ln(1+x) - (\sqrt{1+4x} - 1)$，$x>0$。 求导：$F'(x) = \frac{2}{1+x} - \frac{2}{\sqrt{1+4x}} = 2\frac{\sqrt{1+4x} - (1+x)}{(1+x)\sqrt{1+4x}}$。 因 $\sqrt{1+4x} > 1+x$（平方即可验证），故 $F'(x) > 0$，$F(x)$ 在 $(0, +\infty)$ 单调递增。 又 $F(0)=0$，所以 $F(0.01) > 0 \Rightarrow 2\ln1.01 > \sqrt{1.04} - 1$，即 $a > c$。 3. 比较 $b$ 与 $c$：令 $G(x) = \ln(1+2x) - (\sqrt{1+4x} - 1)$，$x>0$。 $G'(x) = \frac{2}{1+2x} - \frac{2}{\sqrt{1+4x}} = 2\frac{\sqrt{1+4x} - (1+2x)}{(1+2x)\sqrt{1+4x}}$。 因 $\sqrt{1+4x} < 1+2x$（$ (1+2x)^2 = 1+4x+4x^2 > 1+4x $），故 $G'(x) < 0$，$G(x)$ 在 $(0, +\infty)$ 单调递减。 又 $G(0)=0$，所以 $G(0.01) < 0 \Rightarrow \ln1.02 < \sqrt{1.04} - 1$，即 $b < c$。 4. 综上，$b < c < a$，选B。

点评/变式 比较大小的核心是把常数“变活”，设为变量后再构造函数，统一在同一自变量的函数值下比较。变式：比较 $2\ln1.02$ 与 $\sqrt{1.08}-1$ 等，方法完全一致。
