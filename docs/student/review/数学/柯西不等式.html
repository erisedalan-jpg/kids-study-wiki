柯西不等式

知识精要

柯西不等式是证明不等式和求最值的有力工具，其标准形式为：对任意实数 $a_1,a_2,\cdots,a_n$ 和 $b_1,b_2,\cdots,b_n$，有
$$(a_1^2+a_2^2+\cdots+a_n^2)(b_1^2+b_2^2+\cdots+b_n^2) \geq (a_1b_1+a_2b_2+\cdots+a_nb_n)^2.$$ 取等条件为 $\frac{a_1}{b_1}=\frac{a_2}{b_2}=\cdots=\frac{a_n}{b_n}$（当某个分母为零时，对应分子也为零）。二维形式 $n=2$ 最为常用，即 $(a^2+b^2)(c^2+d^2)\ge(ac+bd)^2$。

此外，柯西不等式还有变体形式，如“权方和”不等式：若 $x_i>0$，则
$$\frac{y_1^2}{x_1}+\frac{y_2^2}{x_2}+\cdots+\frac{y_n^2}{x_n} \ge \frac{(y_1+y_2+\cdots+y_n)^2}{x_1+x_2+\cdots+x_n}.$$
使用柯西不等式时，关键是将待证式子配凑成“平方和的乘积”或“分式平方和”的结构，并注意方向“ ≥ ”不可用反。高考中常与均值不等式、立方和公式等结合，用以证明对称结构的不等式或求最值。

解题方法与套路

  1. 结构识别与直接套用
    观察是否具备 $(\sum A_i^2)(\sum B_i^2) \ge (\sum A_iB_i)^2$ 的形式。例如 $(a+b)(a^5+b^5)$ 可视为 $[(\sqrt{a})^2+(\sqrt{b})^2][(\sqrt{a^5})^2+(\sqrt{b^5})^2]$。
  2. 引入常数项或条件配凑
    当已知 $a+b+c$ 或和为定值时，通过乘上 $(a+b+c)$ 构造分母以使分式符合柯西形式，如证明 $\frac{a^2}{b}+\frac{b^2}{c}+\frac{c^2}{a} \ge a+b+c$，可写为 $\left(\frac{a^2}{b}+\frac{b^2}{c}+\frac{c^2}{a}\right)(b+c+a) \ge (a+b+c)^2$。
  3. 联合均值不等式转化条件
    带有高次项的条件（如 $a^3+b^3=2$）常通过因式分解或代换转化为低次和 $a+b$ 与积 $ab$ 的关系，再由均值不等式 $ab \le (\frac{a+b}{2})^2$ 构造关于 $a+b$ 的不等式求解。
  4. 逆用或变形运用
    将目标式转化为平方和除以线性项的形式，利用 $\frac{x_1^2}{y_1}+\cdots+\frac{x_n^2}{y_n} \ge \frac{(x_1+\cdots+x_n)^2}{y_1+\cdots+y_n}$，直接得到下界。

高频易错

  • 方向颠倒：柯西不等式左边乘积大于等于右边平方和，不可将“≥”误用作“≤”；权方和公式同样如此，证毕时需确认不等号方向。
  • 忽略取等条件：高考证明题必须验证等号成立时的变量取值（通常各数对应成比例），缺乏取等条件会被扣过程分。
  • 配凑系数失误：构造平方和时要注意系数的均衡，如将 $a+b$ 视为 $(\frac{a}{\sqrt{k}})^2+(\frac{b}{\sqrt{m}})^2$ 等，需保证展开后与原式一致，否则放缩失真。
  • 滥用条件范围：权方和形式要求分母严格为正，若题目未明确正数，不能随意用分式柯西。在 $a,b,c$ 均为正数的前提下才可安全使用 $ \sum \frac{x^2}{y} \ge \frac{(\sum x)^2}{\sum y}$。
  • 混淆均值与柯西：均值不等式常用于产生“积→和”的缩放，柯西用于“和与平方和”的链接，在综合题中需分清每一步所运用的工具及其前提。

代表题精讲

2017理23

题目：已知 $a>0,b>0$，且 $a^3+b^3=2$，证明：
(1) $(a+b)(a^5+b^5) \ge 4$；
(2) $a+b \le 2$。

思路：(1) 注意到 $a+b = (\sqrt{a})^2+(\sqrt{b})^2$，$a^5+b^5 = (\sqrt{a^5})^2+(\sqrt{b^5})^2$，直接应用柯西不等式。
(2) 条件 $a^3+b^3=2$ 可变形出 $a+b$ 与 $ab$ 的关系，然后由均值不等式将 $ab$ 缩放为 $a+b$
