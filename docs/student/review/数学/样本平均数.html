样本平均数

知识精要

  • 样本平均数(样本均值)定义：对于一组样本数据 $x_1, x_2, \cdots, x_n$，其样本平均数 $$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$ 它是总体均值的最小方差无偏估计，反映样本数据的集中趋势。

  • 加权平均数：若数据 $x_i$ 出现频数为 $f_i$，则 $\bar{x} = \frac{\sum x_i f_i}{\sum f_i}$。在实际计算中，当已知总和时可直接用总量除以个数。

  • 线性变换性质：若 $y_i = kx_i$（$k$ 为常数），则 $\bar{y} = k\bar{x}$。该性质是解决“由样本均值推算总体总量”类问题的核心依据。

  • 样本平均数与估计：在简单随机抽样下，样本平均数可作为总体平均数的估计值；当已知总体规模 $N$ 时，总体总量的估计量 $\hat{T} = N \cdot \bar{x}$。

  • 区分两组概念：

  • $\bar{x}$（样本平均数）vs $\mu$（总体平均数）
  • 样本总和 $\sum x_i = n\bar{x}$，直接用于质量检查与后续计算
  • 样本平均数是计算样本方差、相关系数等后续统计量的基础中间量

解题方法与套路

  1. 直接公式法
    当已知所有样本数据时，直接求和除以样本容量。若题目已给出总和，则直接用总和计算，避免逐项累加出错。

  2. 对称结构与补全法
    若数据呈现某种重复或对称，可先统计频数再加权求和，减少计算量。

  3. “总和–平均数”互推套路
    题型特征：给出样本平均数，求样本总和；或给出样本总和，求平均数。
    核心关系：$\sum x_i = n\bar{x}$。这一步往往是相关系数计算、回归分析等大题的第一步。

  4. 比例估计与总量推算套路
    适用场景：由样本平均数推断总体总量，且总体规模已知或可测。
    步骤：

  5. 计算样本平均数 $\bar{x}$
  6. 确定总体单位数 $N$

  7. 估计总体总量 $\hat{T} = N \bar{x}$
    当存在线性关系 $y = kx$ 时，先估计系数 $k = \bar{y} / \bar{x}$，再代入总体自变量总量求目标总量。

  8. 利用样本平均数简化复杂公式代入
    在相关系数 $r$、回归系数等公式中，需要 $\bar{x}, \bar{y}$。正确求出平均数是后续计算正确的前提。一般先列出 $\bar{x}, \bar{y}$ 的值，再代入。

高频易错

  • 总量与平均数的混淆：题目给出的是“总和”还是“平均数”需仔细辨别。本题中表格给出每棵树的横截面积与材积量，最后一行“总和”是直接给出的，可直接用总和求平均，勿再累加一遍。

  • 单位与量纲错误：根部横截面积单位为 $\text{m}^2$，材积量为 $\text{m}^3$，平均数带有相同单位。答题时必须写明单位，否则失分。

  • 计算精度丢失：求平均数时若除不尽，应根据题意保留适当小数位数，或先以分数形式保留，在后续乘法运算中再统一近似，避免累积误差。本题第(1)问计算简单，第(3)问利用比例推算时要保持精度一致。

  • 误用总体平均数与样本平均数：已知总体根部横截面积总和为 $186\text{m}^2$，并非所有树的横截面积平均，需结合样本信息估计材积量。不能直接套用样本材积量平均数乘以树的总数，而必须先确定两者比例关系。

  • 忽略等比关系的条件验证：题目明确“材积量与其根部横截面积近似成正比”，这是使用比例估计的前提。若条件不成立则不能直接使用，需改用回归等其他方法。

代表题精讲

题目（2022 全国甲卷文科第19题）

为估计林区某种树木的总材积量，随机选取10棵，测量根部横截面积 $x_i$ 与材积量 $y_i$，数据如表。已知 $\sum x_i=0.6$，$\sum y_i=3.9$。
（1）估计平均一棵树的根部横截面积与平均材积量；
（2）求根部横截面积与材积量的样本相关系数（精确到0.01）；
（3）已知该林区所有树木根部横截面积总和为 $186\text{m}^2$，树木材积量与其根部横截面积近似成正比，利用数据给出总材积量的估计值。

思路

（1）直接使用样本平均数公式 $\bar{x}=\frac{1}{n}\sum x_i$，$\bar{y}=\frac{1}{n}\sum y_i$，已知总和，直接除以10即可。
（3）利用第（1）问求出的 $\bar{x}$ 与 $\bar{y}$，确定比例系数 $\hat{k}=\bar{y}/\bar{x}$，再用总体根部横截面积总和 $S_x = 186$ 乘以该系数，即得总材积量估计 $\hat{T}_y = \hat{k} \cdot S_x$。注意此处利用的是“成正比”条件，而非直接使用 $\bar{y}$ 乘以树木总数。

步骤

第（1）问
样本容量 $n=10$，由题意总和已给出：
$\sum x_i = 0.6$，$\sum y_i = 3.9$。
平均根部横截面积
$$\bar{x} = \frac{0.6}{10} = 0.06 \; (\text{m}^2)$$
平均材积量
$$\bar{y} = \frac{3.9}{10} = 0.39 \; (\text{m}^3)$$

第（3）问
由“材积量 $y$ 与根部横截面积 $x$ 近似成正比”，设 $y = kx$。
利用样本平均数估计比例系数：
$$\hat{k} = \frac{\bar{y}}{\bar{x}} = \frac{0.39}{0.06} = 6.5$$
已知林区所有树木根部横截面积总和为 $186\text{m}^2$，因此总材积量估计值为
$$\hat{T}_y = \hat{k} \times 186 = 6.5 \times 186 = 1209 \; (\text{m}^3)$$

点评与变式

本题以样本平均数为起点，贯穿了统计估计的基本逻辑链：样本均值→比例系数→总体总量估计。第（1）问虽简单，却是全题的基础；一旦求错，后续分数全丢。
变式1：若没有直接给出总和，而只给原始数据表，则需先计算 $\sum x_i$ 和 $\sum y_i$ 再求平均。
变式2：若不成正比而是线性关系 $y = a + bx$，则需先用最小二乘法求回归系数，再用总体横截面积均值或总和进行预测，此时不能简单用比例。
警示：第（3）问易错点为直接用平均材积量乘以树木棵数，但树木棵数未知，必须借助“成正比”这一关键条件，通过根部横截面积总量转换。这说明在应用题中挖掘隐含比例关系是解题的突破口。
