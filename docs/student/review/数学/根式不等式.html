根式不等式

  • 父主题：不等式

  • 出现题位：选择1

知识精要

  • 根式不等式定义：含未知数在根号内的不等式，通常形如 $\sqrt{f(x)} \ge g(x)$ 或 $\sqrt{f(x)} \le g(x)$（$f(x) \ge 0$）。
  • 基础原理：
  • 偶次根号下被开方式必须 非负：$f(x) \ge 0$。
  • 不等号两边平方时，必须保证 两边同号 方可保持等价。
  • 标准解法拆分：
  • 类型 $\sqrt{f(x)} \le g(x)$ 等价于不等式组： $$\begin{cases} f(x) \ge 0, \ g(x) \ge 0, \ f(x) \le [g(x)]^2 \end{cases}$$ 要点：$g(x)$ 必须非负，否则不等式无解（根式非负，不可能 $\le$ 负数）。
  • 类型 $\sqrt{f(x)} \ge g(x)$ 等价于以下两个不等式组的并集： $$\begin{cases} g(x) \ge 0, \ f(x) \ge [g(x)]^2 \end{cases} \quad \text{或} \quad \begin{cases} g(x) < 0, \ f(x) \ge 0 \end{cases}$$ 要点：当 $g(x)$ 为负时，只要根式有意义，恒成立。
  • 常见特例：$\sqrt{x} \le a$（$a \ge 0$）直接化归为 $0 \le x \le a^2$。本题中 $\sqrt{x} \le 4, x \in \mathbb{Z}$ 即求满足 $0 \le x \le 16$ 的整数。

解题方法与套路

  1. 定类型，建模型：认清是“根式 ≤ 常数/函数”还是“根式 ≥ 常数/函数”，决定后续套路。
  2. 列约束，写等价组：
  3. 被开方式 $\ge 0$ 必须写出。
  4. 若为 $\le$ 型，右侧必须 $\ge 0$ 并与平方不等式联立。
  5. 若为 $\ge$ 型，按右侧正负分类讨论，最后取并集。
  6. 解不等式组：
  7. 解普通不等式（二次、一次）时，注意区间端点取舍。
  8. 若题目涉及整数解，最后一步将连续范围取交集后筛选整数。
  9. 检验与取并（交）：
  10. 分类讨论得到的解集应取并集。
  11. 多个条件应取交集。
  12. 特殊情形如 $x \in \mathbb{Z}$ 或有其他限制，需在最后一步落实。

高频易错

  • 忘记定义域：直接平方得到 $x \le 16$ 而遗漏 $x \ge 0$，导致范围扩大。
  • 忽略平方条件：对 $\sqrt{f(x)} \le g(x)$ 未检查 $g(x) \ge 0$，在 $g(x)$ 可能为负时错误保留无解部分。
  • 混淆并集与交集：$\ge$ 型分类讨论后未取并集，$\le$ 型三个条件未取交集。
  • 端点处理失当：根式不等式平方后常可包含等号（需满足定义域），但若一端严格不等式，需格外注意。
  • 审题不清：题目附加 $x \in \mathbb{Z}$ 或 $x \in \mathbb{N}$ 时，忘记将解集转化为具体整数，导致误选选项（如本题选区间而漏掉整数）。

代表题精讲

题目 （2010 全国卷文）已知集合 $A={x \mid |x| \le 2, x \in \mathbb{R}}$，$B={x \mid \sqrt{x} \le 4, x \in \mathbb{Z}}$，则 $A \cap B =$（ ）
A. $(0,2)$　B. $[0,2]$　C. ${0,2}$　D. ${0,1,2}$

思路
分别化简集合 $A$ 和 $B$。$A$ 是绝对值不等式，易解。$B$ 是根式不等式结合整数限制。最后求交集，注意元素必须是整数。

步骤
1. 化简 $A$：$|x| \le 2 \Leftrightarrow -2 \le x \le 2$，故 $A = [-2, 2]$。
2. 化简 $B$：$\sqrt{x} \le 4$，需 $\begin{cases} x \ge 0 \ \sqrt{x} \le 4 \end{cases} \Rightarrow 0 \le x \le 16$。又 $x \in \mathbb{Z}$，所以 $B = {0, 1, 2, \dots, 16}$。
3. 求交集：$A \cap B = {x \mid -2 \le x \le 2 \text{ 且 } x \in B} = {0, 1, 2}$。
4. 对选项：只有 D 符合，故选 D。

点评/变式
- 本题属于集合与简单不等式交汇的基础题，核心陷阱在于 $B$ 的整数性，许多考生忽略 $x \in \mathbb{Z}$ 而误选 B（区间 $[0,2]$）。
- 变式1：若 $B = {x \mid \sqrt{x-1} \le 2}$，则需注意定义域 $x-1 \ge 0$，再平方求解。
- 变式2：遇到 $\sqrt{x+3} \ge x-1$ 型，需讨论右侧正负，分两类取并集，不可直接平方。
- 策略：根式不等式解题务必画“定义域—平方条件—取交集”三步流程图，养成严谨习惯，避免低级失误。
