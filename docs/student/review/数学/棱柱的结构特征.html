棱柱的结构特征

考点棱柱的结构特征权重17真题数2学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：17
  • 真题数：2；年份跨度：2008–2009
  • 出现题位：填空16 解答18
  • 难度分布：中2

知识精要

  • 棱柱的定义：有两个面（底面）互相平行，其余各面都是四边形，并且每相邻两个四边形的公共边（侧棱）都互相平行，由这些面所围成的多面体叫做棱柱。底面是全等的多边形，侧面都是平行四边形，侧棱平行且相等。
  • 直棱柱：侧棱垂直于底面的棱柱。侧棱长等于高，侧面均为矩形。
  • 平行六面体：底面是平行四边形的四棱柱。它的六个面都是平行四边形，相对的两个面互相平行且全等，四条体对角线交于一点且在该点互相平分。
  • 充要条件（对应平行六面体）：
  • 空间四棱柱为平行六面体 $\Leftrightarrow$ 三组对面分别平行（六个面都是平行四边形）。
  • 空间四棱柱为平行六面体 $\Leftrightarrow$ 体对角线交于一点，且在交点处互相平分。
  • 直三棱柱的常见特征：底面为三角形，侧棱垂直底面，因此侧棱垂直底面内任意一条直线。若底面有垂直关系（如 $AB \perp AC$），则可直接用于建立空间直角坐标系，利用向量或几何法证明平行、垂直或求角。

解题方法与套路

  1. 棱柱问题建系法
  2. 当题目中出现直棱柱或正棱柱，且底面有垂直关系（如 $AB \perp AC$），常以底面某一顶点为原点，以该顶点出发的两条互相垂直的棱所在直线为 $x,y$ 轴，以平行于侧棱的方向为 $z$ 轴建立空间直角坐标系。

  3. 将几何条件转化为向量坐标，利用向量垂直（数量积为零）或平行（向量共线）来证明或计算。

  4. 类比推理在空间几何中的应用

  5. 从平面到空间的类比：如将平面四边形的性质（平行四边形两组对边分别平行、对角线互相平分）推广到空间四棱柱，得到平行六面体的充要条件。

  6. 注意维度提升后概念的变化：平行四边形的“对边平行”对应平行六面体的“对面平行”；“对角线”对应“体对角线”；“互相平分”在空间中仍成立，但需明确是所有体对角线交于同一点并互相平分。

  7. 证明线面垂直的套路（针对直棱柱）

  8. 利用“直线与平面内两条相交直线垂直”的判定定理。
  9. 直棱柱中侧棱与底面垂直，因此侧棱垂直底面内所有直线，优先利用这一条件。
  10. 善用中点构造中位线、平行四边形，将待证垂直关系转化为已知垂直关系或通过向量数量积为零证明。

高频易错

  • 概念混淆：四棱柱、平行六面体、直平行六面体、长方体的包含关系经常考。平行六面体要求底面是平行四边形；直平行六面体是侧棱垂直于底面的平行六面体；长方体是底面为矩形的直平行六面体。必须逐层区分，不能拿到侧棱垂直就说底面是矩形。
  • 类比不当：将平行四边形的性质直接照搬到一般四棱柱上。例如“对角线互相平分”只是平行六面体的充要条件，普通四棱柱的体对角线不一定交于一点，更不一定互相平分。
  • 忽视垂直传递的条件：在直棱柱中，侧棱垂直于底面，所以侧棱垂直于底面内所有直线，但侧面内的线不一定垂直于底面。证明时容易误以为侧面上的中线或连线自动垂直于底面内某直线，必须回到线面垂直的本质判定。
  • 用向量法时坐标系建立不严谨：未证明三轴两两垂直就默认坐标轴互相垂直，或点的坐标写错（尤其涉及中点、比例分点）。直三棱柱中一定要确认底面有直角，否则不能直接建系。

代表题精讲

代表题 1（2009-理-18）

题目：如图，在直三棱柱 $ABC-A_1B_1C_1$ 中，$AB \perp AC$，$D$ 为 $AA_1$ 中点，$E$ 为 $B_1C$ 中点，且 $DE \perp$ 平面 $BCC_1$。求证：$AB = AC$。

思路：利用直三棱柱 $AB \perp AC$ 的条件，以 $A$ 为原点建系，设 $AB=a$，$AC=b$，$AA_1=c$，写出各点坐标。将条件 $DE \perp$ 平面 $BCC_1$ 转化为向量 $\overrightarrow{DE}$ 与平面 $BCC_1$ 的法向量 $\boldsymbol{n}$ 平行，即 $\overrightarrow{DE} \parallel \boldsymbol{n}$，从而推导出参数 $a=b$。

步骤： 1. 以 $A$ 为原点，$AB$ 为 $x$ 轴正半轴，$AC$ 为 $y$ 轴正半轴，$AA_1$ 为 $z$ 轴正半轴。则 $A(0,0,0),\,B(a,0,0),\,C(0,b,0),\,A_1(0,0,c),\,B_1(a,0,c),\,C_1(0,b,c)$。 2. 中点 $D$ 为 $AA_1$ 中点：$D(0,0,\frac c2)$；$E$ 为 $B_1C$ 中点： $$E\Big(\frac{a}{2},\frac{b}{2},\frac c2\Big)$$ 3. 计算 $\overrightarrow{DE} = \Big(\frac a2,\frac b2,0\Big)$。 4. 平面 $BCC_1$ 的法向量可取 $\overrightarrow{BC}=(-a,b,0)$ 与 $\overrightarrow{CC_1}=(0,0,c)$ 的叉积：$\boldsymbol{n} = (bc,ac,0)$（也可取 $\boldsymbol{n}=(b,a,0)$，因为平面内向量可简化）。 注：$\overrightarrow{BC}\times \overrightarrow{CC_1} = (b\cdot c - 0\cdot 0,\, 0\cdot 0 - (-a)\cdot c,\, (-a)\cdot 0 - b\cdot 0) = (bc, ac, 0)$。 5. 条件 $DE \perp$ 平面 $BCC_1$ 等价于 $\overrightarrow{DE} \parallel \boldsymbol{n}$，即存在 $\lambda \neq 0$ 使得 $(\frac a2,\frac b2,0)=\lambda (bc,ac,0)$。 6. 由第三分量均为 $0$ 自动满足；比较前两分量得： $$\frac a2 = \lambda bc,\quad \frac b2 = \lambda ac$$ 若 $a,b,c$ 均不为 $0$，两式相除得 $\frac{a}{b}=\frac{bc}{ac}=\frac{b}{a}$，即 $a^2=b^2$，故 $a=b$。因此 $AB=AC$。

点评/变式：本题巧妙利用直三棱柱底面垂直的特性建系，将线面垂直转化为向量平行，避免了复杂的几何辅助线。若题目改为求二面角或线面角，该建系方法同样有效，只需进一步求出相关平面法向量的夹角。

代表题 2（2008-理-16）

题目：平面内的一个四边形为平行四边形的充要条件有多个，如两组对边分别平行。类似地，写出空间中的一个四棱柱为平行六面体的两个充要条件。

思路：由平面到空间的类比推理，抓住平行四边形的本质特征——对边平行、对角线互相平分，将其推广到空间中的四棱柱，注意将“边”替换为“面”，“对角线”替换为“体对角线”。

步骤： 1. 类比“两组对边分别平行”： 平面中两组对边分别平行 $\implies$ 空间三组对面分别平行。因为四棱柱有上下底面和三个方向的侧面，平行六面体的六个面都是平行四边形，即三组对面分别平行。 充要条件①：三组对面分别平行的四棱柱为平行六面体。 2. 类比“两条对角线互相平分”： 平面中平行四边形的对角线交于一点且互相平分。推广到空间，平行六面体的四条体对角线交于一点，并在交点处互相平分。 充要条件②：平行六面体的对角线交于一点，并且在交点处互相平分。 （也可写：底面是平行四边形且侧棱平行且相等，但标准答案如题述。）

点评/变式：本题为压轴填空，考查类比推理能力与棱柱结构特征。易错点在于直接写“底面为平行四边形且侧棱不垂直”之类含混不清的条件，或忽略“充要”二字。平时应多总结平面与空间的对偶性质，如三角形→三棱锥（三角形内心到三边等距→三棱锥内心到四侧面等距），培养类比思维。
