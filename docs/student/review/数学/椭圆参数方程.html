椭圆参数方程

知识精要

  • 椭圆的参数方程（中心在原点）
  • 焦点在 $x$ 轴：椭圆 $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1(a>b>0)$ 的参数方程为 $\begin{cases} x=a\cos\varphi \ y=b\sin\varphi \end{cases}$（$\varphi$ 为参数）。
  • 焦点在 $y$ 轴：椭圆 $\frac{y^{2}}{a^{2}}+\frac{x^{2}}{b^{2}}=1(a>b>0)$ 的参数方程为 $\begin{cases} x=b\cos\varphi \ y=a\sin\varphi \end{cases}$（$\varphi$ 为参数）。
  • 参数 $\varphi$ 的几何意义：离心角（并非旋转角），通常取 $\varphi\in[0,2\pi)$。
  • 核心价值：将椭圆上的动点坐标用单参数 $\varphi$ 表示，从而把几何最值、范围问题转化为三角函数或二次函数在有限区间上的最值问题。
  • 常用转化公式：
  • $\cos^2\varphi = 1-\sin^2\varphi$，$\sin^2\varphi = 1-\cos^2\varphi$。
  • 距离平方可化为关于 $\sin\varphi$ 或 $\cos\varphi$ 的二次式，如 $A\sin^2\varphi+B\sin\varphi+C$，其中 $\sin\varphi\in[-1,1]$。

解题方法与套路

  1. 写参数方程：根据给定的椭圆标准方程，识别焦点位置，写出对应参数方程（$x$ 与 $a\cos\varphi$ 或 $b\cos\varphi$ 对应，$y$ 与 $b\sin\varphi$ 或 $a\sin\varphi$ 对应）。
  2. 设动点坐标：设椭圆上动点 $P$ 的坐标为 $(x(\varphi), y(\varphi))$，明确参数 $\varphi$ 的取值范围（通常为 $[0,2\pi)$）。
  3. 建立目标函数：将所求的距离、距离平方和、斜率、面积等表示为关于 $\varphi$ 的表达式。若遇到多个平方和，充分利用 $\cos^2\varphi+\sin^2\varphi=1$ 化简。
  4. 化归为三角函数/二次函数最值：
  5. 若化为 $f(\sin\varphi)$ 或 $f(\cos\varphi)$，令 $t=\sin\varphi\in[-1,1]$，转化为闭区间上二次函数求最值。
  6. 若化为 $A\sin(\varphi+\theta)+B$ 或 $A\cos(\varphi+\theta)+B$，直接利用有界性求范围。
  7. 注意定义域：求二次函数最值时，必须结合 $t\in[-1,1]$ 的区间限制，判断对称轴是否在区间内，必要时计算区间端点值。

高频易错

  • 混淆参数方程形式：焦点在 $y$ 轴时，仍机械地套用 $x=a\cos\varphi,y=b\sin\varphi$，导致 $a,b$ 错位。
  • 忽略参数的约束：求解目标函数后，忘记 $\sin\varphi$ 和 $\cos\varphi$ 的有界性 $[-1,1]$，错误使用二次函数在 $\mathbb{R}$ 上的最值。
  • 参数 $\varphi$ 与倾斜角混淆：误将参数方程中的 $\varphi$ 当作点与原点连线的倾斜角，用于斜率或夹角计算时出错。
  • 距离平方展开失误：计算如 $(a\cos\varphi)^2$ 时漏掉平方或系数，或者在配方、整理过程中出现符号错误。
  • 极坐标与直角坐标互化错误：综合题中，点的极坐标化直角坐标时出错（$x=\rho\cos\theta, y=\rho\sin\theta$），导致后续目标函数建立错误。

代表题精讲

1. 2021年全国乙卷文科第11题

  • 题目：设 $B$ 是椭圆 $C:\frac{x^{2}}{5}+y^{2}=1$ 的上顶点，点 $P$ 在 $C$ 上，则 $|PB|$ 的最大值为？
  • 思路：椭圆焦点在 $x$ 轴，写出参数方程；设 $P$ 坐标，表示 $|PB|^2$，化为关于 $\sin\varphi$ 的二次函数，利用二次函数在 $[-1,1]$ 上求最大值。
  • 步骤：
  • 椭圆 $C:\frac{x^{2}}{5}+y^{2}=1$ 的上顶点为 $B(0,1)$。
  • 参数方程：$\begin{cases} x=\sqrt{5}\cos\varphi \ y=\sin\varphi \end{cases}$，设 $P(\sqrt{5}\cos\varphi,\sin\varphi)$。
  • 计算距离平方： $$|PB|^{2}=(\sqrt{5}\cos\varphi-0)^{2}+(\sin\varphi-1)^{2}=5\cos^{2}\varphi+\sin^{2}\varphi-2\sin\varphi+1$$ 利用 $\cos^{2}\varphi=1-\sin^{2}\varphi$，得： $$|PB|^{2}=5(1-\sin^{2}\varphi)+\sin^{2}\varphi-2\sin\varphi+1=-4\sin^{2}\varphi-2\sin\varphi+6$$
  • 令 $t=\sin\varphi,\ t\in[-1,1]$，则 $f(t)=-4t^{2}-2t+6$，开口向下，对称轴 $t=-\frac{1}{4}\in[-1,1]$。 因此最大值在 $t=-\frac{1}{4}$ 处取得： $$f_{\max}= -4\left(-\frac{1}{4}\right)^{2}-2\left(-\frac{1}{4}\right)+6 = -\frac{1}{4}+\frac{1}{2}+6=\frac{25}{4}$$
  • 故 $|PB|_{\max}=\frac{5}{2}$，选 A。
  • 点评/变式：本题关键是化为二次函数并注意 $t$ 的限制。变式：若点 $B$ 为左顶点或其他定点，方法一致；若求 $|PB|$ 的最小值，则比较对称轴与区间端点。

2. 2012年课标卷选修4-4（文23/理23）

  • 题目：已知曲线 $C_{1}$ 参数方程 $\begin{cases} x=2\cos\varphi \ y=3\sin\varphi \end{cases}$（$\varphi$ 为参数），曲线 $C_{2}$ 为 $\rho=2$ 的圆，正方形 $ABCD$ 顶点均在 $C_{2}$ 上，$A$ 极坐标为 $(2,\frac{\pi}{3})$。（1）求 $A,B,C,D$ 直角坐标；（2）$P$ 为 $C_{1}$ 上任意一点，求 $|PA|^{2}+|PB|^{2}+|PC|^{2}+|PD|^{2}$ 的取值范围。
  • 思路：（1）极坐标化直角坐标，结合正方形对称性求四点坐标。（2）设 $P$ 参数坐标，利用平方和表达式化简，转化为 $\sin^{2}\varphi$ 的一次式求范围。
  • 步骤： （1）由 $C_{2}:\rho=2$ 且正方形逆时针排列，$A(2,\frac{\pi}{3})$，得 $B(2,\frac{5\pi}{6}),C(2,\frac{4\pi}{3}),D(2,\frac{11\pi}{6})$。直角坐标：$A(1,\sqrt{3}),B(-\sqrt{3},1),C(-1,-\sqrt{3}),D(\sqrt{3},-1)$。 （2）设 $P(2\cos\varphi,3\sin\varphi)$，则 $$t=|PA|^{2}+|PB|^{2}+|PC|^{2}+|PD|^{2}$$ 利用对称性与坐标代入化简（或利用正方形中心在原点，四点坐标平方和为定值关系），可得： $$t=4x_{0}^{2}+4y_{0}^{2}+16 = 4(4\cos^{2}\varphi)+4(9\sin^{2}\varphi)+16 = 16\cos^{2}\varphi+36\sin^{2}\varphi+16$$ $$=16(1-\sin^{2}\varphi)+36\sin^{2}\varphi+16 = 32+20\sin^{2}\varphi$$ 因为 $\sin^{2}\varphi\in[0,1]$，所以 $t\in[32,52]$。
  • 点评/变式：多个距离平方和常可利用椭圆参数方程及对称性整体化简，避免逐个展开；求取值范围时注意 $\sin^{2}\varphi$ 的值域。变式：若正方形中心非原点，需先平移坐标或直接计算。
