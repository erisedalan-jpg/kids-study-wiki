正三棱柱

考点正三棱柱权重6真题数1学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：6
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 正三棱柱的定义：底面为正三角形，侧棱垂直于底面的直棱柱。当所有棱长相等时，底面边长等于侧棱长，即高 $h=a$。
  • 外接球的核心要素：
  • 球心位置：上下底面外接圆圆心（正三角形的中心）连线的中点。
  • 外接球半径 $R$ 的构成：以半高 $\frac{h}{2}$ 和底面外接圆半径 $r$ 为两条直角边，$R$ 为斜边，满足 $R^2 = r^2 + \left(\frac{h}{2}\right)^2$。
  • 相关计算公式：
  • 边长为 $a$ 的正三角形外接圆半径：$r=\frac{\sqrt{3}}{3}a$（区别于内切圆半径 $\frac{\sqrt{3}}{6}a$ 及高 $\frac{\sqrt{3}}{2}a$）。
  • 球的表面积：$S=4\pi R^2$。
  • 适用条件：所有直棱柱（侧棱垂直于底面）的外接球球心均为上下底面外心连线的中点，此法可迁移至正四棱柱、正六棱柱等。

解题方法与套路

  1. 识别模型：判断几何体为“侧棱垂直底面且底面为正多边形”的直棱柱。本题为所有棱长相等的正三棱柱。
  2. 定位球心：找到上底面外心 $O_1$、下底面外心 $O_2$，外接球球心 $O$ 为 $O_1O_2$ 的中点。
  3. 构造直角三角形：连接球心 $O$、底面外心 $O_2$、底面一个顶点 $B$，得到 $\text{Rt}\triangle OO_2B$，其中 $O O_2 = \frac{h}{2}$，$O_2B = r$（底面外接圆半径），$OB=R$（外接球半径）。
  4. 分层计算：
  5. 计算底面外接圆半径 $r$（正三角形 $r=\frac{\sqrt{3}}{3}a$）；
  6. 确定柱体高 $h$ 和半高 $\frac{h}{2}$；
  7. 利用勾股定理求 $R^2 = r^2 + \left(\frac{h}{2}\right)^2$。
  8. 回代公式：将 $R^2$ 代入目标公式（如表面积 $S=4\pi R^2$ 或体积 $V=\frac{4}{3}\pi R^3$）得出最终结果。

高频易错

  • 混淆底面正三角形的三类半径/线段：外接圆半径 $r=\frac{\sqrt{3}}{3}a$，高 $h_{\triangle}=\frac{\sqrt{3}}{2}a$，内切圆半径 $r_{\text{内}}=\frac{\sqrt{3}}{6}a$。计算 $R$ 时必须使用外接圆半径。
  • 球心定位错误：误将球心定在底面的外心、重心或侧棱中点。对于直棱柱，球心必在上下底面中心连线的中点，而非表面上的某点。
  • 高与棱长关系误判：所有棱长都为 $a$，意味着侧棱也是 $a$，即柱高 $h=a$。若题目条件变更为“底面边长 $a$，侧棱长 $b$”，则 $h=b$，需避免机械代入 $h=a$。
  • 计算细节失分：求 $R^2$ 时通分出错（如 $\frac{1}{3}+\frac{1}{4}=\frac{7}{12}$ 算成 $\frac{5}{12}$ 或 $\frac{2}{7}$），表面积漏乘 4 或误用 $S=\pi R^2$。

代表题精讲

题目（2010·理·10）：设三棱柱的侧棱垂直于底面，所有棱长都为 $a$，顶点都在一个球面上，则该球的表面积为（　　）
A．$\pi a^2$ 　 B．$\frac{7}{3}\pi a^2$ 　 C．$\frac{11}{3}\pi a^2$ 　 D．$5\pi a^2$

思路：这是正三棱柱的外接球问题，所有棱长相等提供了高与底面边长的数量关系。通过“球心在几何中心”模型，利用直角三角形求出外接球半径 $R$，再算表面积。

步骤：
1. 由题意知，底面为正三角形，边长 $a$，侧棱长 $=a$，所以柱高 $h=a$。
2. 底面外接圆半径 $r=\frac{\sqrt{3}}{3}a$。
3. 球心 $O$ 到上、下底面中心的距离为 $d=\frac{h}{2}=\frac{a}{2}$。
4. 在由球心、底面外心、底面顶点构成的直角三角形中，$R^2= r^2+d^2 = \left(\frac{\sqrt{3}}{3}a\right)^2 + \left(\frac{a}{2}\right)^2 = \frac{a^2}{3}+\frac{a^2}{4} = \frac{7a^2}{12}$。
5. 球的表面积 $S=4\pi R^2 = 4\pi \cdot \frac{7a^2}{12} = \frac{7}{3}\pi a^2$。故选B。

点评/变式
- 本模型的关键组合永远是“底面外接圆半径”和“半高”。若底面变为正方形（正四棱柱），$r=\frac{\sqrt{2}}{2}a$；若为正六棱柱，$r=a$。
- 变式：若三棱柱侧棱垂直于底面，底面边长 $a$，侧棱长 $2a$，则 $R^2 = \left(\frac{\sqrt{3}}{3}a\right)^2 + a^2 = \frac{4}{3}a^2$，表面积为 $\frac{16}{3}\pi a^2$。
- 注意题目中“所有棱长都为 $a$”是一个特殊条件，由此确定 $h=a$；若题目只给出“底面边长和高分别为不同数值”，务必代入对应的 $h$，而非直接使用 $a$。
