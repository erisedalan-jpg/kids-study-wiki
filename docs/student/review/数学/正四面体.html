正四面体

  • 父主题：立体几何
  • 权重 weight：1
  • 真题数：1；年份跨度：2013–2013
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 正四面体的定义：四个面都是全等的正三角形的四面体，所有棱长相等。
  • 与正方体的关系：正四面体可内接于正方体，其顶点为正方体的四个互不共面的顶点，棱长为正方体面对角线。若正方体棱长为 $a$，则正四面体棱长 $l=\sqrt{2}a$，体积 $V=\frac{1}{3}a^3$，高 $h=\frac{\sqrt{6}}{3}l=\frac{2\sqrt{3}}{3}a$。
  • 常见度量公式（设棱长为 $a$）：
  • 表面积 $S=\sqrt{3}a^2$，体积 $V=\frac{\sqrt{2}}{12}a^3$，高 $h=\frac{\sqrt{6}}{3}a$；
  • 外接球半径 $R=\frac{\sqrt{6}}{4}a$，内切球半径 $r=\frac{\sqrt{6}}{12}a$；
  • 对棱距离 $d=\frac{\sqrt{2}}{2}a$（对棱互相垂直）。
  • 三视图投影原理：正视图将空间图形向后投射到坐标平面（如 $zOx$ 平面），投影时仅保留垂直于投影面的坐标（$y$ 坐标舍去），被遮挡的线用虚线表示。

解题方法与套路

  1. 坐标还原几何体：给出一组空间直角坐标，先观察是否具有“一个原点+三个两点共一面”特征，联想正方体顶点（坐标只含 $0$ 和 $1$），补形成正方体，再取其四个顶点即得正四面体。
  2. 确定投影平面上的二维点：去掉投影方向所对应的坐标（如以 $zOx$ 为投影面，去掉 $y$），得到各顶点在投影面上的二维坐标。
  3. 恢复棱的连线：按原四面体的棱连接对应的投影点，画全六条棱的投影线段。
  4. 虚实线判断：根据与投影面垂直的坐标轴（此处为 $y$ 轴）的大小判断前后位置。坐标大的点更靠近观察者，若两线段交叉，则靠前的线段画实线，被遮挡的线段画虚线；重合于外围轮廓的线画实线。

高频易错

  • 投影点遗漏或错连：直接凭感觉画图，未按原四面体所有棱一一投影，导致漏画内部对角线。
  • 虚实线混淆：不加区分地将所有投影线段画成实线，或记错前后方向。应以投影面法线方向判断遮挡关系——坐标值大的在前，实线；被完全遮挡的线段画虚线。
  • 误判形状为三角形：将正四面体的投影想当然看作正三角形，忽略投影方向变化时可能得到带对角线的正方形。
  • 坐标马虎：丢弃坐标时保留错误变量，或未考虑某些点因坐标特殊而投影重合。

代表题精讲

题目（2013·全国理·7）
一个四面体的顶点在空间直角坐标系 $O!-!xyz$ 中的坐标分别是 $(1,0,1)$，$(1,1,0)$，$(0,1,1)$，$(0,0,0)$，画该四面体三视图中的正视图时，以 $zOx$ 平面为投影面，则得到的正视图可以为（　　）

思路
四个点均只含 $0$ 和 $1$，可还原为棱长为 $1$ 的正方体的四个顶点。以 $zOx$ 为投影面，即沿 $y$ 轴方向投射，去掉 $y$ 坐标得四个投影点；再连接原四面体的全部棱，并根据 $y$ 坐标大小判别虚实。

步骤
1. 记 $O(0,0,0)$，$A(1,0,1)$，$B(1,1,0)$，$C(0,1,1)$，此四点构成棱长为 $\sqrt{2}$ 的正四面体。
2. 向 $zOx$ 平面投影（去掉 $y$）：
$O\to(0,0)$，$A\to(1,1)$，$B\to(1,0)$，$C\to(0,1)$。
四个投影点恰好是边长为 $1$ 的正方形的四个顶点。
3. 连原四面体的六条棱：
$OA$：$(0,0)!-!(1,1)$（左下到右上对角线）
$OB$：$(0,0)!-!(1,0)$（底边）
$OC$：$(0,0)!-!(0,1)$（左边）
$AB$：$(1,1)!-!(1,0)$（右边）
$AC$：$(1,1)!-!(0,1)$（顶边）
$BC$：$(1,0)!-!(0,1)$（右下到左上对角线）
4. 判断可见性：沿 $y$ 轴方向看，$y$ 坐标大的靠近观察者。$B,C$ 的 $y=1$，在最前；$O,A$ 的 $y=0$，在后方。
- 正方形边框由 $OB,OC,AB,AC$ 投影组成，虽然有前后，但处于轮廓位置，均画实线。
- 对角线 $BC$（$y=1$ 在前）画实线；对角线 $OA$（$y=0$ 在后）与 $BC$ 投影交叉，被遮挡，画虚线。
故正视图为正方形加一条内部实对角线（$BC$）和一条虚对角线（$OA$）。

点评与变式
- 本题核心是“正方体模型+投影坐标剥离+虚实遮挡判断”。在选择题中，抓住正方体补形可快速画出直观图。
- 变式：若以 $xOy$ 平面为投影面，正视图将是边长 $\sqrt{2}$ 的正三角形，需注意投影方向不同导致图形迥异，务必厘清坐标轴与投影面的对应关系。
