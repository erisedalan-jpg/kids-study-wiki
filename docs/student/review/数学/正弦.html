知识精要

  • 任意角正弦：在平面直角坐标系中，设角 $\alpha$ 终边上任意一点 $P(x,y)$ 到原点的距离 $r=\sqrt{x^2+y^2}>0$，则 $\sin\alpha=\dfrac{y}{r}$。在单位圆中，$\sin\alpha$ 等于终边与单位圆交点的纵坐标。
  • 同角基本关系（核心）：
  • 平方关系：$\sin^2\alpha+\cos^2\alpha=1$（恒成立）。
  • 商数关系：$\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}$，$\cot\alpha=\dfrac{\cos\alpha}{\sin\alpha}$（$\alpha\neq k\pi$ 且分母不为零）。
  • 符号规则：$\sin\alpha$ 在第一、二象限为正，三、四象限为负。若已知 $\cot\alpha<0$，则 $\sin\alpha$ 与 $\cos\alpha$ 异号；结合 $\alpha$ 所在三角形内角范围（$0<\alpha<\pi$），可进一步确定 $\sin\alpha$ 必为正、$\cos\alpha$ 为负。
  • 关系变形：由商数关系得 $\cos\alpha = \cot\alpha\cdot\sin\alpha$，代入平方关系即可消元求解。若只涉及正弦、余弦，优先平方关系联立。

解题方法与套路

  1. 定号（象限判断）：根据已知三角比的符号和角的固有范围，明确所求正弦（或余弦）的符号。例如在 $\triangle ABC$ 中，内角 $A\in(0,\pi)$，$\cot A<0\Rightarrow A$ 为钝角，$\sin A>0$，$\cos A<0$。
  2. 建方程（化弦为切或统一函数）：利用商数关系 $\cot A = \dfrac{\cos A}{\sin A}$ 将已知等量转化为正、余弦的一次关系式，如 $\cos A = k\sin A$（$k$ 为己知常数）。
  3. 联立平方关系：将上述关系式代入 $\sin^2 A+\cos^2 A=1$，得到仅含 $\sin A$（或 $\cos A$）的二次方程。
  4. 求解并取舍：解方程并结合第1步的符号判断，排除增根，得到唯一解。

高频易错

  • 忽略符号判断导致双解：直接由 $\sin^2A+\cos^2A=1$ 解出正负两个值，却没有利用 $\cot A$ 的符号或角的范围进行取舍，造成答案多选或错选。
  • 定义域不明确：误认为 $\cot A=\dfrac{\cos A}{\sin A}$ 中 $\sin A\neq0$ 自然满足，但在实际运算中忘记检查，虽然此题不涉及分母为零。
  • 切化弦时代数恒等变形失误：如由 $\cot A=-\dfrac{12}{5}$ 错误写成 $\cos A = -\dfrac{12}{5}\sin A$，符号漏乘或系数颠倒。
  • 忽视三角形内角限制：盲目套用任意角结论，忘了在 $\triangle ABC$ 中 $0<A<\pi$，这正是定号的关键依据。

代表题精讲

题目（2009全国卷·文·4）：已知 $\triangle ABC$ 中，$\cot A = -\dfrac{12}{5}$，则 $\cos A =$（ ）

A. $\dfrac{12}{13}$　B. $\dfrac{5}{13}$　C. $-\dfrac{5}{13}$　D. $-\dfrac{12}{13}$

思路
$\cot A$ 已知，且 $A$ 是三角形内角。先用 $\cot A<0$ 推出 $A$ 为钝角，从而 $\cos A<0$，排除 A、B。再将余切化为弦，联立平方关系直接解出 $\cos A$ 的值。

步骤
1. 因为 $0<A<\pi$，$\cot A = -\dfrac{12}{5}<0$，所以 $A$ 为钝角，$\sin A>0$，$\cos A<0$。
2. 由商数关系得 $\cot A = \dfrac{\cos A}{\sin A} = -\dfrac{12}{5}$，即 $\cos A = -\dfrac{12}{5}\sin A$。
3. 代入平方关系：$\sin^2 A + \left(-\dfrac{12}{5}\sin A\right)^2 = 1$
$\Rightarrow \sin^2 A + \dfrac{144}{25}\sin^2 A = 1$
$\Rightarrow \dfrac{169}{25}\sin^2 A = 1$
$\Rightarrow \sin^2 A = \dfrac{25}{169}$
4. 由 $\sin A>0$ 得 $\sin A = \dfrac{5}{13}$。
5. 回代求 $\cos A$：$\cos A = -\dfrac{12}{5} \times \dfrac{5}{13} = -\dfrac{12}{13}$。
或直接由平方关系：$\cos^2 A = 1 - \sin^2 A = \dfrac{144}{169}$，结合 $\cos A<0$ 得 $\cos A = -\dfrac{12}{13}$。

点评/变式
本题核心是同角三角函数基本关系的熟练运用，关键步骤是“定号”。若题目改为求 $\sin A$，同样流程可解。变式：已知 $\triangle ABC$ 中，$\sin A = \dfrac{4}{5}$，求 $\cos A$ 和 $\tan A$——此时必须分 $A$ 为锐角或钝角讨论，体现符号分类的重要性。
