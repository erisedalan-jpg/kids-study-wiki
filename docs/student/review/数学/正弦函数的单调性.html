知识精要

  1. 正弦函数的单调性
    标准正弦函数 $y = \sin x$ 在一个周期内的单调区间为：
  2. 单调递增区间：$[-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi], k \in \mathbb{Z}$
  3. 单调递减区间：$[\frac{\pi}{2} + 2k\pi, \frac{3\pi}{2} + 2k\pi], k \in \mathbb{Z}$

此性质是求解复合正弦型函数 $y = A\sin(\omega x + \varphi)$（其中 $A \neq 0, \omega > 0$）单调性的基础。

  1. 复合正弦函数的单调区间求解
    对于 $y = A\sin(\omega x + \varphi)$（设 $A > 0, \omega > 0$），先写出 $u = \omega x + \varphi$，再套用 $y = \sin u$ 的单调性条件，最后解出 $x$ 的范围。

  2. 求增区间：令 $-\frac{\pi}{2} + 2k\pi \le \omega x + \varphi \le \frac{\pi}{2} + 2k\pi, k \in \mathbb{Z}$

  3. 求减区间：令 $\frac{\pi}{2} + 2k\pi \le \omega x + \varphi \le \frac{3\pi}{2} + 2k\pi, k \in \mathbb{Z}$

若 $A < 0$，函数单调性与 $A > 0$ 时相反。此时可先用诱导公式将负号化到相位中，或直接反向套用不等式。

  1. 引入 $\cos x$ 的辅助角公式
    形如 $a\sin x + b\cos x$ 的函数，必须统一函数名才能使用单调性。化简公式为：
    $$a\sin\alpha \pm b\cos\alpha = \sqrt{a^2+b^2}\sin(\alpha \pm \varphi)$$
    其中 $\tan\varphi = \frac{b}{a}$，$\varphi$ 所在象限由 $a, b$ 的符号确定。这是真题中最高频的前置化简动作。

解题方法与套路

  1. 函数名与结构统一
    若函数含 $\sin$ 和 $\cos$ 的线性组合，优先用辅助角公式合并为 $A\sin(\omega x + \varphi)$ 或 $A\cos(\omega x + \varphi)$ 的标准形式。若形式为 $\cos x - \sin x$，常提取负号化为 $-\sin(x - \frac{\pi}{4})$ 处理。

  2. 整体代换求区间
    将括号内的角整体视为 $u$，利用标准正弦函数的单调区间建立不等式，再解出 $x$ 的范围。这一步务必指定整数 $k$，并理解所得的是一系列互不重叠的单调区间族。

  3. 给定子区间的含参处理
    若已知函数在某个具体区间 $[m, n]$ 上单调，则该区间必须是求出的理论单调区间的子集。通过比较区间端点的大小关系，建立关于参数（通常为 $\omega$ 或 $a$）的不等式，求其最大值或取值范围。

  4. 特殊值排除法
    遇到求参数范围的复杂选择题时，可在参数允许范围内选取特殊值（如 $\omega = 1, 2$）代入检验单调性，快速排除错误选项。此法在真题的"压轴题"解法中直接出现。

高频易错

  • 忽视 $\omega$ 的影响
    在求 $\sin(\omega x + \varphi)$ 的单调区间时，解出 $x$ 时不等式两边要同时除以 $\omega$ 并变号（若 $\omega < 0$）。常犯错误是忘记变换不等号方向或忘记除以 $\omega$。

  • 辅助角化简符号错乱
    化简 $\cos x - \sin x$ 时易直接写成 $\sin(x - \frac{\pi}{4})$，漏掉整体负号。正确应为 $-\sin(x - \frac{\pi}{4})$ 或 $\sqrt{2}\cos(x + \frac{\pi}{4})$，符号错误将导致单调性完全相反。

  • 混淆复合函数的单调性
    $y = A\sin(\omega x + \varphi)$ 中，当 $A < 0$ 时，增区间和减区间对调。许多学生强行记忆“正弦增减”而忽略振幅符号，导致整题方向性错误。

  • 忽略周期性带来的多区间选择
    由 $k \in \mathbb{Z}$ 求出的单调区间有无数个。在限定定义域（如 $[0, a]$）时，必须选择能与给定区间重叠或包含它的那个特定 $k$ 值（常为 $k = 0$），取错 $k$ 值会得到错误参数范围。

  • 开闭区间不敏感
    单调性在闭区间讨论，平移后端点包含与否可能影响参数的“最大值”是否能取等号。如真题求 $a$ 的最大值，关键就是判断 $a \le \frac{3\pi}{4}$ 能否取等。

代表题精讲

题目 (2018-文-10)：若 $f(x) = \cos x - \sin x$ 在 $[0, a]$ 上为减函数，求 $a$ 的最大值。
思路
本题目标是为有限区间 $[0, a]$ 匹配单调性。首先将函数化为单一正弦型，然后求出该函数全局的单调递减区间族，最后让已知区间 $[0, a]$ 成为其中某个减区间的子集，进而锁定 $a$ 的边界。
步骤
1. 化简函数：
$$f(x) = \cos x - \sin x = -(\sin x - \cos x) = -\sqrt{2}\sin(x - \frac{\pi}{4})$$
可以写成 $f(x) = \sqrt{2}\sin(x + \frac{3\pi}{4})$，但负号形式更易处理单调性。由于系数为负，$f(x)$ 的减区间对应 $\sin(x - \frac{\pi}{4})$ 的增区间。
2. 令 $-\frac{\pi}{2} + 2k\pi \le x - \frac{\pi}{4} \le \frac{\pi}{2} + 2k\pi, k \in \mathbb{Z}$
3. 解得 $-\frac{\pi}{4} + 2k\pi \le x \le \frac{3\pi}{4} + 2k\pi$。
4. 取 $k=0$，得距原点最近的减区间为 $[-\frac{\pi}{4}, \frac{3\pi}{4}]$。
5. 为使 $[0, a]$ 单调递减，必须有 $[0, a] \subseteq [-\frac{\pi}{4}, \frac{3\pi}{4}]$。据此得到 $a \le \frac{3\pi}{4}$，故 $a$ 的最大值为 $\frac{3\pi}{4}$。
点评/变式
本题是固定区间反求参数的典型。注意“$a$ 的最大值”能够取到等号，因为当 $a = \frac{3\pi}{4}$ 时，$[0, a]$ 确为原函数减区间的子区间。若题目换为求 $a$ 的取值范围，同样不能遗漏这个等号。

题目 (2018-理-10)：若 $f(x) = \cos x - \sin x$ 在 $[-a, a]$ 上为减函数，求 $a$ 的最大值。
思路
与文科题解法完全一致，区别仅为已知区间变为对称区间 $[-a, a]$。同样需先化简函数、求全局减区间，再让区间包含在减区间内。由于区间是对称的，求出的 $a$ 值会相应变化。
步骤
1. 同文科题，$f(x) = -\sqrt{2}\sin(x - \frac{\pi}{4})$，其减区间族为 $[-\frac{\pi}{4} + 2k\pi, \frac{3\pi}{4} + 2k\pi], k \in \mathbb{Z}$。
2. 取 $k=0$，减区间为 $[-\frac{\pi}{4}, \frac{3\pi}{4}]$。
3. 现在需要 $[-a, a] \subseteq [-\frac{\pi}{4}, \frac{3\pi}{4}]$。
4. 为同时满足 $-a \ge -\frac{\pi}{4}$ 且 $a \le \frac{3\pi}{4}$，得到 $a \le \frac{\pi}{4}$。
5. 故 $a$ 的最大值为 $\frac{\pi}{4}$。
点评/变式
此题将文科题的端点 $0$ 变为了可移动的 $-a$，对思维习惯有所挑战。必须让整个对称区间完全落在减区间内，是由两端点共同约束得出的更紧致的结果。属于同类题的小幅变式，考查更细致。

题目 (2012-理-09)：已知 $\omega > 0$，函数 $f(x) = \sin(\omega x + \frac{\pi}{4})$ 在 $[\frac{\pi}{2}, \pi]$ 上单调递减，求 $\omega$ 的取值范围。
思路
此时区间固定，参数 $\omega$ 在角频率位置。可利用“整体代入”思想写出函数单调减区间的通式，由题意区间必须是某一减区间的一部分，由此列出不等式组并借助整数 $k$ 确定参数范围。真题中另有特值排除法可选。
步骤
1. 要求 $f(x)$ 递减，即需 $\frac{\pi}{2} + 2k\pi \le \omega x + \frac{\pi}{4} \le \frac{3\pi}{2} + 2k\pi$。
2. 解出 $x$ 的范围：$\frac{\frac{\pi}{4} + 2k\pi}{\omega} \le x \le \frac{\frac{5\pi}{4} + 2k\pi}{\omega}$。
3. 使 $[\frac{\pi}{2}, \pi]$ 为其子区间，必有：
$\frac{\frac{\pi}{4} + 2k\pi}{\omega} \le \frac{\pi}{2}$ 且 $\pi \le \frac{\frac{5\pi}{4} + 2k\pi}{\omega}$
4. 解上述不等式，并结合 $\omega > 0$ 及选择合理整数 $k$（通常取 $k=0$ 或邻近值试算），可得 $\omega \in [\frac{1}{2}, \frac{5}{4}]$。
点评/变式
这是典型的由区间单调求参数 $\omega$ 范围的问题。待定系数在相位内部，必须同时处理两个端点的不等式。掌握特值排除法能快速在考场上验证选项、抢分，但完整推导更能应对填空题或变式。
