正方体性质

考点正方体性质权重1真题数1学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：1
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 正方体是侧棱与底面垂直且底面为正方形的直平行六面体，所有棱长相等，各面均为全等的正方形。
  • 核心线段长度（设棱长为 $a$）：
  • 面对角线长 $\sqrt{2}a$；体对角线长 $\sqrt{3}a$。
  • 核心位置关系：
  • 相邻棱垂直；相邻面对角线夹角为 $\frac{\pi}{2}$ 或 $\frac{\pi}{3}$（等边三角形）。
  • 体对角线与面对角线、棱的夹角固定。
  • 中点性质：底面对角线中点即底面中心，到各顶点距离 $=\frac{\sqrt{2}}{2}a$；与侧棱端点连线形成直角三角形。
  • 异面直线所成角：
  • 定义：过空间任一点作两异面直线的平行线，所成的锐角或直角。
  • 范围：$(0, \frac{\pi}{2}]$。
  • 平移法原理：利用平行关系将两直线平移到同一个三角形中求解。

解题方法与套路

  • 平移—解三角形法（求异面直线所成角的核心套路）
  • 找平行：观察图形中已有的平行关系（如正方体中 $AD_1 \parallel BC_1$，$A_1B \parallel D_1C$ 等），将其中一条异面直线平移至与另一条相交，通常优先选择端点或中点。
  • 定三角形：连接相关点构造包含平移后两相交直线的三角形。
  • 算边长：利用正方体棱长及勾股定理，计算三角形的三边长度。
  • 求角：用余弦定理 $\cos\theta = \frac{a^2+b^2-c^2}{2ab}$ 求夹角的余弦值，注意 $\theta \in (0,\frac{\pi}{2}]$，若余弦为负则取其补角。
  • 坐标法（备用方案）：建立空间直角坐标系，写出方向向量，用 $\cos\theta = \frac{|\vec{u} \cdot \vec{v}|}{|\vec{u}||\vec{v}|}$ 直接求解。

高频易错

  • 平移方向搞错：误把异面直线平移到延长线的反向延长线上，导致构造出的角是补角而非原角。注意平移时方向要一致。
  • 忽略角的范围：异面直线所成角一定是锐角或直角，用余弦定理算出钝角余弦值时必须取补角，或直接用绝对值处理。
  • 边长计算粗心：正方体中涉及中点时，忘记利用等腰三角形性质（如 $B_1D_1$ 中点 $P$ 与 $C_1$ 连线 $C_1P \perp B_1D_1$），把直角三角形边写错。建议画出分离图形，标注棱长与面对角线、半面对角线的准确长度。
  • 平移选择不当：随意平移导致三角形较难计算，应优先利用正方体已有的平行棱或平行面对角线。

代表题精讲

题目：在正方体 $ABCD-A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 的中点，则直线 $PB$ 与 $AD_1$ 所成的角为（） A. $\frac{\pi}{2}$　B. $\frac{\pi}{3}$　C. $\frac{\pi}{4}$　D. $\frac{\pi}{6}$

思路：注意到 $AD_1 \parallel BC_1$，可将异面直线 $PB$ 与 $AD_1$ 所成角转化为相交直线 $PB$ 与 $BC_1$ 的夹角 $\angle PBC_1$，再解 $\triangle PBC_1$。

步骤： - 连接 $BC_1$，在正方体侧面 $BCC_1B_1$ 中，$AD_1 \parallel BC_1$，故所求角等于 $\angle PBC_1$。 - 连接 $PC_1$。在底面 $A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 中点，而 $C_1B_1 = C_1D_1$，所以 $C_1P \perp B_1D_1$，且 $C_1P = \frac{\sqrt{2}}{2}a$（设棱长为 $a$）。 - 计算三边： - $BC_1 = \sqrt{2}a$； - $BP = \sqrt{BB_1^2 + B_1P^2} = \sqrt{a^2 + \left(\frac{\sqrt{2}}{2}a\right)^2} = \frac{\sqrt{6}}{2}a$； - $PC_1 = \sqrt{C_1B_1^2 - B_1P^2} = \sqrt{a^2 - \left(\frac{\sqrt{2}}{2}a\right)^2} = \frac{\sqrt{2}}{2}a$。 - 在 $\triangle PBC_1$ 中，由余弦定理： $$\cos\angle PBC_1 = \frac{BP^2 + BC_1^2 - PC_1^2}{2 \cdot BP \cdot BC_1} = \frac{\frac{3}{2}a^2 + 2a^2 - \frac{1}{2}a^2}{2 \cdot \frac{\sqrt{6}}{2}a \cdot \sqrt{2}a} = \frac{3a^2}{\sqrt{12}a^2} = \frac{\sqrt{3}}{2}$$ - 故 $\angle PBC_1 = \frac{\pi}{6}$，选 D。

点评/变式： - 本题典型地展示了“平移—解三角形”的完整流程，抓住 $AD_1 \parallel BC_1$ 是破题关键。 - 变式：若求 $PB$ 与 $A_1C_1$ 的夹角，可将 $A_1C_1$ 平移至 $AC$，或连接 $B_1D_1$ 利用中点 $P$ 的性质构造三角形。核心思路不变，熟练后可直接用向量坐标法验证。
