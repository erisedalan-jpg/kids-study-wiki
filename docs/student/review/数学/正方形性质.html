知识精要

  • 正方形核心性质
    四条边等长，四个角均为直角；对角线相等且互相垂直平分；既是中心对称也是轴对称图形（4条对称轴）。
    常用坐标系：将正方形置于坐标轴，可利用垂直、等长关系简化计算。

  • 四点共圆的判定方法

  • 对角互补：若四边形中 $\angle A + \angle C = 180^\circ$，则四点共圆。
  • 张角相等：同一线段所对的两个张角相等，则四点共圆。

  • 直径所对圆周角：若 $\angle ABC = 90^\circ$ 且 $AC$ 为直径，则 $A,B,C$ 共圆；若再证 $\angle AOC = 90^\circ$ 或 $O$ 到四点等距，可得共圆。
    本题中，由正方形性质 $\angle BCG = 90^\circ$，只需证 $\angle BFG = 90^\circ$ 即可推得 $B,C,G,F$ 四点共圆，此时 $BG$ 为直径。

  • 垂直与垂足坐标计算
    直线 $l_1 \perp l_2$ 时斜率满足 $k_1 k_2 = -1$。
    已知点 $D$ 和直线 $CE$，作垂线 $DF$，联立两直线方程可求得垂足 $F$ 坐标。

  • 不规则四边形面积
    可用拆分法：$S_{BCGF} = S_{\triangle BCG} + S_{\triangle BFG}$，利用直角三角形的面积公式 $\frac{1}{2}ab$，或用向量叉乘的坐标公式计算。

解题方法与套路

  1. 建立合适坐标系
    以正方形顶点 $D$ 为原点，$DC$、$DA$ 所在直线为坐标轴，设边长为 $1$（或 $a$），由条件 $DE=DG$ 得到 $E,G$ 坐标均为参数 $t$，减少变量。

  2. 用代数手段证共圆

  3. 求出关键点 $F$（垂足）坐标（解垂线方程组）。

  4. 通过向量内积或斜率判断 $\angle BFG = 90^\circ$，结合已知直角 $\angle BCG$ 得出四点共圆（或直接证 $BF \perp FG$）。

  5. 面积分块计算

  6. 将四边形分解为共边或共顶点的多个直角三角形。

  7. 利用点的坐标直接计算各边长或用三角形面积坐标公式 $S=\frac{1}{2}|x_1y_2 - x_2y_1|$ 求和。

  8. 几何法备选
    也可用旋转、相似变换：例如将 $\triangle DCF$ 绕 $D$ 旋转 $90^\circ$ 到 $\triangle DAH$，通过边角关系证明直角，但坐标法在正方形问题中更通用、不易失误。

高频易错

  • 坐标建系的顶点顺序错乱
    务必将正方形按 $D(0,0), C(a,0), B(a,a), A(0,a)$ 的顺序放置，确保 $DA$ 在 $y$ 轴，$DC$ 在 $x$ 轴，否则点的坐标关系易错。

  • 垂足坐标求错
    $DF \perp CE$，斜率取负倒数时漏写负号，或解方程时移项出错，导致 $F$ 点坐标错误，后续全盘皆输。建议带入检验是否满足 $DF \cdot CE = 0$。

  • 四点共圆时对角判断混淆
    必须确定谁是对角：$B,C,G,F$ 中，若连接顺序为 $B\to C\to G\to F$，对角为 $\angle BCG$ 与 $\angle BFG$，非 $\angle CBG$ 与 $\angle CFG$。一定画图确认。

  • 面积拆分遗漏或重复
    多边形面积拆分要确保无重叠无遗漏，本例中 $\triangle BCG$ 为直角三角形（直角在 $C$），$\triangle BFG$ 为直角三角形（直角在 $F$），若误认为 $\triangle BCF$ 等会得出错误结果。

  • 参数 $e= \frac{1}{2}$ 时代入粗心
    $e=\frac{1}{2}$ 时，$e^2+1=\frac{5}{4}$，坐标化简需细致，常见错误是把 $x_F$ 算成 $\frac{1}{3}$ 之类。
