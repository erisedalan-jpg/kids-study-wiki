  • 出现题位：选择9
  • 难度分布：中1

知识精要

  • 比例线段：若四条线段 $a,b,c,d$ 满足 $a:b=c:d$，则称其为成比例线段。
  • 平行线分线段成比例：两条直线被一组平行线所截，截得的对应线段成比例。
  • 三角形相似判定：
  • 两角对应相等的两个三角形相似（AA）；
  • 平行于三角形一边的直线截其他两边（或延长线），所得三角形与原三角形相似。
  • 相似三角形的性质：对应边成比例，对应高、中线、角平分线的比等于相似比。
  • “重差法”测高原理：利用两次不同位置的表杆，构造两组相似三角形，通过两次影长（或视线截距）的差消除不可直接测量的量，从而求得远距离或高度。核心公式实质为比例关系的代数变形。

解题方法与套路

  1. 抽象几何图：将文字描述转化为标准的平面几何图形，标出已知垂线段（表高）、水平距离（表距、表目距）以及待求高度。
  2. 找相似三角形：利用“垂直于水平面的标杆”与“海岛”均垂直于地面，得到平行线，从而识别出包含目标高度和已知高度的相似三角形。
  3. 列双重比例式：分别针对两个不同观测点，写出包含目标高度的比例式（通常用“物高与目高差之比”等于对应水平距离之比）。
  4. 引入中间变量，消元求解：设出不可测的过渡线段（如岛面到前表的水平距离），利用两个比例式相减，消去该变量。
  5. 化简为目标表达式：将比例等式变形，整理出目标高度的表达式，注意区分“表距”与“表目距的差”的代数结构。

高频易错

  • 混淆线段端点：容易将“表目距”GC 与 EH 的顺序搞反，导致对应线段错位。应严格按观测点与表杆顶点的连线来对应三角形。
  • 忽视“表高”：最终表达式里需叠加表高（或通过比例式直接求得全高），许多考生在化简到最后一步时漏加表高，导致错选。
  • 无法正确处理“差”：题目给出“表目距的差”是一个整体量，若直接记成 $d = GC - EH$，却在列式时代入错误符号，会推导出错误选项。
  • 误用平行条件：标杆与海岛均垂直于水平面，得到的是 $AB \parallel DE \parallel FG$，而非斜线平行，将斜视线当作相似三角形的边时，需看清哪一段是平行线间的截线段。

代表题精讲

题目（2021-理-09）

刘徽《海岛算经》测海岛高：点 $E,H,G$ 在水平线 $AC$ 上，$DE,FG$ 为两等高标杆（表高），$EG$ 为表距，$GC$ 与 $EH$ 为表目距，两者的差称为表目距的差。求海岛 $AB$ 的高。

思路：设表高为 $h$，表距为 $d$，前表目距 $EH = a$，后表目距 $GC = b$，则表目距的差为 $b - a$。由 $DE \parallel AB$ 得 $\triangle ABH \sim \triangle DEH$，由 $FG \parallel AB$ 得 $\triangle ABC \sim \triangle FGC$。分别列出比例式，消去包含 $AH$ 或 $BH$ 中的未知水平距离，解出 $AB$。

步骤： 1. 设 $AB = H$，表高 $DE = FG = h$，$EH = a$，$GC = b$，表距 $EG = d$。前表到岛脚的水平距离 $AH$ 为 $x$（未知）。 2. 由 $\triangle ABH \sim \triangle DEH$（$AB \parallel DE$），得 $$\frac{H}{h} = \frac{AH}{EH} = \frac{x}{a}.$$ 3. 由 $\triangle ABC \sim \triangle FGC$（$AB \parallel FG$），注意到 $AC = AH + HG + GC$？需仔细对应：实际图景中，海岛 $A$ 是岛顶在水平面的投影？依据《海岛算经》原图，$A$ 为岛脚（或水岸点），$H$ 为后表脚点，$G$ 为前表脚点，$C$ 为前表目距点。观察点从后表 $D$ 望岛顶 $B$，视线经过后表顶 $D$ 与岛顶 $B$ 交地面于 $H$。更准确的几何模型为：后表 $DE$，从 $D$ 望岛顶 $B$，视线交地面于 $H$；前表 $FG$，从 $F$ 望岛顶 $B$，视线交地面于 $C$。则水平面 $AC$ 上有：自岛脚 $A$ 向右，依次为后表脚 $E$、前表脚 $G$、后视线落点 $H$？原题“E，H，G在水平线AC上”的次序为 $A$、$E$、$H$、$G$、$C$？需要依《海岛算经》原文：后表立于 $E$，前表立于 $G$，从后表望岛顶，视线过地表 $H$；从前表望岛顶，视线过地表 $C$。则顺序为 $A$（岛脚）-- $E$（后表）-- $H$（后视线足）-- $G$（前表）-- $C$（前视线足）。如此，$EH = a$，$GC = b$，$EG = d$。 由此，$AB \parallel DE \parallel FG$，$\triangle ABH \sim \triangle DEH$，得 $\frac{AB}{DE} = \frac{AH}{EH}$，设 $AH = y$（岛脚到后视线足的距离？实际相似：$AB:DE = AH:EH$，注意 $H$ 是后视线足，$A$ 为岛脚）。再对前表：$AB:FG = AC:GC$？但 $C$ 为前视线足，三角形 $ABC$ 中 $C$ 是前足点吗？通常模型：岛顶 $B$，岛脚 $A$，后表 $DE$，从 $D$ 望 $B$，视线交地面于 $H$；前表 $FG$，从 $F$ 望 $B$，视线交地面于 $C$。则 $\triangle ABH \sim \triangle DEH$，$\triangle ABC \sim \triangle FGC$。此时，$AH$ 是岛脚到后足的距离，$AC$ 是岛脚到前足的距离。那么 $AC = AH + HC$，而 $HC = ?$ 点排列：$A$--$E$--$H$--$G$--$C$。所以 $HC$ 包含 $HG$ 和 $GC$？顺序为 $A,E,H,G,C$。所以 $AC = AH + HE + EG + GC$？不，$A,E,H,G,C$ 同一线，$AH = AE + EH$；$AC = AH + HG + GC$。但 $HG = ?$ 实际上 $H$ 到 $G$ 的距离为 $HG = EG - EH$？因为 $E,H,G$ 顺序为 $E$--$H$--$G$，所以 $HG = EG - EH$。则 $AC = AH + (EG - EH) + GC$。 相似比： $\frac{AB}{h} = \frac{AH}{EH} \Rightarrow AH = \frac{AB}{h} \cdot EH$， $\frac{AB}{h} = \frac{AC}{GC} \Rightarrow AC = \frac{AB}{h} \cdot GC$。 两式相减：$AC - AH = \frac{AB}{h}(GC - EH)$。 而 $AC - AH = HC = HG + GC = (EG - EH) + GC$。但 $GC - EH$ 正是表目距的差。原题表达式需得出最终 $AB = \frac{\text{表高} \times \text{表距}}{\text{表目距的差}} + \text{表高}$。验证选项。此处详细算式可按《海岛算经》原解： 由 $\triangle ABH \sim \triangle DEH$，$\frac{AB}{DE} = \frac{AH}{EH}$；由 $\triangle ABC \sim \triangle FGC$，$\frac{AB}{FG} = \frac{AC}{GC}$。因为 $DE = FG = h$，所以 $\frac{AH}{EH} = \frac{AC}{GC}$。设 $EH=a, GC=b$，则 $AH = \frac{a}{b} AC$。又 $AC - AH = HC = HG + GC = (d - a) + b$。代入可解 $AC$，再得 $AB = \frac{h}{b} AC$。运算得 $AB = \frac{h \cdot d}{b - a} + h$。故选项 A 正确：$\frac{\text{表高} \times \text{表距}}{\text{表目距的差}} + \text{表高}$。

点评/变式： 该题取自中国古代数学经典，考查相似三角形对应边的比例关系与代数变换的结合。关键在于从“表目距的差”这个差值结构中，通过两次比例式相减消去不可测的过渡段。变式训练可尝试改变标杆高度不等、或标杆不在同一水平线等情况，强化对“重差法”通法的理解。考场上若示意图不清晰，可快速自画标准横轴点列，严格按照视线与标杆、目标物构成的“A字型”相似写出比例式，避免因对应边错乱丢分。
