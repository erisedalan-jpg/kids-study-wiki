比较大小

考点比较大小权重2真题数6学科数学父主题函数与导数

考点定位

  • 父主题：函数与导数
  • 权重 weight：2
  • 真题数：6；年份跨度：2009–2022
  • 出现题位：选择4 选择7 选择8 选择10 选择11 选择12
  • 难度分布：中4 易2

知识精要

  • 比较大小的本质：转化为函数单调性问题或中间值插入问题。
  • 函数单调性法：若待比较的两数可化为同一函数的不同自变量值，则构造该函数，判断其在所涉区间上的单调性（增则自变量大函数值大，减则反）。
  • 中间值法（搭桥法）：常用中间值 $0$ 或 $1$（如 $\log_a b$ 与 $0$ 或 $1$ 比较）。将各数与中间值比较，再间接推出大小关系。
  • 作差/作商法：欲比较 $A$ 与 $B$，可取差 $A-B$ 判符号，或商 $\frac{A}{B}$ 与 $1$ 比大小（注意 $B$ 的正负）。
  • 同构变形与单调性：将条件不等式变形为 $f(x) < f(y)$ 的形式，通过 $f$ 的单调性推 $x$ 与 $y$ 的大小。
  • 对数换底公式：$\log_a b = \frac{\ln b}{\ln a}$ 或 $\frac{\log_c b}{\log_c a}$，便于统一底数比较。
  • 数列单调性与不等式传递：利用递推关系推导各项的单调性或直接比较相邻项、隔项大小。
  • 概率比较中的差式分析：不同策略下的概率表达式相减，通过因式分解、符号判定分析优劣。
  • 特值法（适用选择/填空题）：在参数可任意选取时（满足给定范围），取特殊值代入快速判断。

解题方法与套路

  1. 审题定法：一看能否同构函数；二看有无现成单调表达式；三看能否取中间量；四看是否需要作差或作商。
  2. 同构函数法步骤
  3. 将已知不等式恒等变形，使左右两边结构相同；
  4. 构造函数 $f(x)$，并指明其定义域及单调性（注意增减运算：增+增=增，增−减=增等）；
  5. 由单调性推出自变量的大小关系；
  6. 根据结论判定选项中的对数、绝对值等范围。
  7. 中间值法步骤
  8. 判断每个数的正负或与 $0$、$1$ 的关系（如 $\log_a b$，$a>1$ 时 $b>1$ 则正且 $>1$ 等）；
  9. 无法直接比较两数时，插入中间量（如 $\frac{1}{2}$，$2$ 等）分而比之。
  10. 作差/作商法步骤（用于概率或复杂数列）
  11. 列出要比较的两个量 $P$、$Q$ 的表达式；
  12. 计算 $P - Q$，提取公因式或配方判断符号；
  13. 若概率表达式中含多个变量，利用已知大小关系简化。
  14. 数列比较的迭代与放缩
  15. 利用递推关系连续迭代，得到前几项具体形式；
  16. 通过 $a_k$ 的范围放缩或传递不等号方向。
  17. 选择题技巧
  18. 优先使用特值法：给参数 $p_1,p_2,p_3$ 等满足条件的简单值（如 $0.9,0.8,0.7$）代入检验；
  19. 选项互斥时，排除明显错误项。

高频易错

  • 忽略单调性严格成立的条件：如用 $f(x)=2^x-3^{-x}$ 单调增，必须分别确认 $2^x$ 增、$-3^{-x}$ 增（即 $3^{-x}$ 减），缺一不可。
  • 对数比较时忽略底数与真数的范围：如 $\log_3 2$ 在 $(0,1)$ 内，$\log_5 2$ 也在 $(0,1)$ 内，仅看底数大真数小需换底或利用函数 $y=\frac{\ln 2}{\ln x}$ 单调性判断。
  • 不等号传递方向弄反：如 $a< b$ 且 $b< c$ 得 $a< c$，但在分式或负号运算中容易混淆。
  • 作商法忘记分母符号：$\frac{A}{B}>1$ 且 $B>0$ 才能推 $A>B$；若 $B<0$ 符号相反。
  • 概率问题中漏乘组合系数：如第二盘定对手后，另两盘顺序有两种等可能情形，忘记乘以 $\frac12$ 或误以为只有一种顺序。
  • 构造的函数与变量不匹配：变形后必需使函数式子完全一样，例如 $2^x-3^{-x}$ 与 $2^y-3^{-y}$ 对应，而不能一侧有常数。
  • 误用绝对值或对数定义域：$\ln|x-y|>0$ 要求 $|x-y|>1$；$\ln(y-x+1)>0$ 要求 $y-x+1>1$ 即 $y-x>0$，要注意前提推导。

代表题精讲

代表题1（2022-理-04）

题目：已知 $a_k \in \mathbb{N}^*$, $k=1,2,\dots$, 定义数列 $b_n$: $b_1 = a_1 + \frac{1}{a_1}$, $b_2 = a_1 + \frac{1}{a_2 + \frac{1}{a_2}}$, $b_3 = a_1 + \frac{1}{a_2 + \frac{1}{a_3 + \frac{1}{a_3}}}$, 依此类推。判断大小关系：A. $b_1< b_5$ B. $b_3< b_8$ C. $b_6< b_2$ D. $b_4< b_7$。

思路：由递推写出 $b_n$ 与 $b_{n+1}$ 的关系，利用 $a_k$ 为正整数放缩，判断序列的单调性和间隔项的大小规律。

步骤： - 依定义，记连分式结构：$b_n$ 最内层表现为 $a_n+ \frac1{a_n}$；而 $b_{n+1}$ 将该层替换为 $a_n + \frac1{a_{n+1}+ \frac1{a_{n+1}}}$。 - 注意到 $a_{n} \ge 1$, 有 $a_{n} + \frac1{a_{n+1}+ \frac1{a_{n+1}}} < a_{n} + 1$，同时大于 $a_n$，经过多层嵌套后，可推出 $b_1 > b_2$（因第一层 $a_1+\frac1{a_1} > a_1+\frac1{a_2+\frac1{a_2}}$），且下标奇数项与偶数项分别具有单调性。 - 实质比较结论：$b_1 > b_3 > b_5 > \dots$, $b_2 < b_4 < b_6 < \dots$，且所有偶数项均小于所有奇数项，所以 $b_4 < b_7$ 正确。即 A错 $b_1>b_5$；B错 $b_3>b_8$；C错 $b_6>b_2$；D正确。

点评/变式：本题核心是连分式结构的单调性分析，大可不必逐项算出具体值。变式可将 $a_k$ 范围改为 $a_k \ge 2$ 等，单调方向可能变化，需重新判定。

代表题2（2022-理-10）

题目：某棋手与甲、乙、丙各赛一盘，相互独立。对甲的胜率 $p_1$，乙 $p_2$，丙 $p_3$，且 $p_3 > p_2 > p_1 > 0$。记 p 为该棋手连胜两盘的概率，问 p 与比赛次序的关系。

思路：连胜两盘意味着第二盘必须获胜，且另两盘中恰好再赢一盘。列出不同次序的 p 表达式，作差比较。

步骤： - 第二盘与甲比赛时，有两种顺序：（乙,甲,丙）或（丙,甲,乙），p甲 = $\frac12[(1-p_2)p_1 p_3 + p_2 p_1 (1-p_3) + (1-p_3)p_1 p_2 + p_3 p_1 (1-p_2)] = p_1(p_2+p_3) - 2p_1 p_2 p_3$。 - 同理，第二盘与乙比赛：p乙 = $p_2(p_1+p_3) - 2p_1 p_2 p_3$；第二盘与丙：p丙 = $p_3(p_1+p_2) - 2p_1 p_2 p_3$。 - 比较：p丙 - p乙 = $(p_3-p_2)(p_1+p_2+p_3-2p_1 p_2 p_3 通过化简为$(p_3-p_2)(p_1(1-p_2)+p_3(1-p_1))$，显然正数，故 p丙 > p乙。类似可得 p丙 > p甲，所以第二盘与丙比赛 p 最大。答案选D。

点评/变式：概率比较问题考查学生把文字转化为数学表达并作差分析的能力，注意组合系数一定加对。变式可推广至 $n$ 名对手的最优排列。

代表题3（2020-文-12）

题目：若 $2^{x} - 3^{-x} < 2^{y} - 3^{-y}$，则（ ）
A. $\ln(y-x+1) > 0$ B. $\ln(y-x+1) < 0$ C. $\ln|x-y| > 0$ D. $\ln|x-y| < 0$

思路：构造函数 $f(t)=2^t-3^{-t}$，由其单调性得到 $x<y$，代入选项判断对数真数与1的大小。

步骤： - 由已知 $2^{x} - 3^{-x} < 2^{y} - 3^{-y}$，设 $f(t)=2^t - 3^{-t}$。 - $2^t$ 是 $\mathbb{R}$ 上增函数，$3^{-t}=(\frac13)^t$ 是减函数，则 $-3^{-t}$ 是增函数，故 $f(t)$ 为增函数。 - 由 $f(x) < f(y)$ 得 $x < y$ ⇒ $y - x > 0$。 - 对于选项 A：真数 $y - x + 1 > 1$，故 $\ln(y-x+1) > 0$，A正确；B误。 - C、D中 $\ln|x-y|$ 真数为 $|x-y| = y-x$，无法确定是否 $>1$，故不一定。

点评/变式：构造同构函数是高考比较大小的杀手锏，关键是识别并正确判断单调性。变式可将 $2,3$ 互换或改为其他底数，甚至在不等式侧加上常数项，仍可同构解决。
