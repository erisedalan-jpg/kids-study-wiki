知识精要

  • 法向量定义：如果向量 $\vec{n} \neq \vec{0}$ 所在的直线与平面 $\alpha$ 垂直，则称 $\vec{n}$ 为平面 $\alpha$ 的一个法向量。
  • 核心性质：平面 $\alpha$ 的法向量与平面内任意两个不共线向量均垂直，即数量积为 $0$。
  • 求法（代数法）：
    1. 设平面法向量 $\vec{n}=(x,y,z)$。
    2. 在平面内找两个不共线向量 $\vec{a}, \vec{b}$。
    3. 列方程组 $\begin{cases} \vec{n} \cdot \vec{a} = 0 \ \vec{n} \cdot \vec{b} = 0 \end{cases}$。
    4. 赋值解出法向量（通常取整数解，或某个坐标为 $1$，注意避开无解赋值）。
  • 空间角应用（核心公式）：
    • 线面角：设直线方向向量为 $\vec{l}$，平面法向量为 $\vec{n}$，则 $\sin\theta = |\cos\langle\vec{l},\vec{n}\rangle| = \dfrac{|\vec{l} \cdot \vec{n}|}{|\vec{l}||\vec{n}|}$（范围 $0^\circ \le \theta \le 90^\circ$）。
    • 二面角：设两平面法向量分别为 $\vec{n_1}, \vec{n_2}$，则 $|\cos\theta| = \dfrac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|}$。二面角正弦值 $\sin\theta = \sqrt{1-\cos^2\theta}$。需根据图形判断二面角是锐角还是钝角，决定余弦值正负。
  • 建系前提：寻找或证明三条两两垂直的直线作为坐标轴（如长方体一角、线面垂直条件）。

解题方法与套路

  1. 建系与坐标化：
  2. 利用题目中的垂直条件（如 $PD \perp \text{底面}$、 长方体结构）建立空间直角坐标系。
  3. 准确写出关键点坐标，设出未知长度参数。
  4. 转化垂直关系：
  5. 将几何垂直（如 $PB \perp AM$）转化为向量数量积为 $0$，列方程求解参数，确定几何体完整形状。
  6. 求法向量（解方程组法）：
  7. 针对目标平面，选取两个已知的不共线向量。
  8. 联立数量积为 $0$ 的方程组，通过赋值求出一组法向量坐标。
  9. 计算空间角：
  10. 线面角：直接用 $\sin\theta = |\cos\langle\text{方向向量},\text{法向量}\rangle|$ 计算。
  11. 二面角：
    • 分别求两个平面的法向量。
    • 算余弦绝对值 $|\cos\langle\vec{n_1},\vec{n_2}\rangle|$。
    • 若求正弦值，用 $\sqrt{1-\cos^2\langle\vec{n_1},\vec{n_2}\rangle}$ 直接得出。
    • （注意：涉及二面角余弦值符号时，需观察图形判断锐/钝角）。
  12. 建系策略选择：
  13. 优先选择底面垂直、线面垂直等天然垂直关系为 $z$ 轴。
  14. 底面矩形直接取两边为 $x,y$ 轴。

高频易错

  • 法向量赋值陷阱：解方程组 $\begin{cases} a_1x+b_1y+c_1z=0 \ a_2x+b_2y+c_2z=0 \end{cases}$ 时，赋值不当可能导致无解或增加计算量。建议先消元，再对自由变量取简单值（常令 $z=1$，若 $z$ 前系数异常则换其他变量）。
  • 线面角公式混淆：线面角公式是 $\sin$ 值，不是 $\cos$ 值。错用 $\cos$ 会导致答案倒置。
  • 二面角与法向量夹角关系不清：法向量夹角 $\langle\vec{n_1},\vec{n_2}\rangle$ 与二面角可能相等或互补。求正弦值时虽然符号恒正，但若题目求余弦值，不判断锐钝直接取绝对值会失分。
  • 建系缺乏严格垂直前提：只在直观感觉“看起来垂直”的地方建系，未利用题干给出或证明的垂直关系（如 $PD \perp \text{底面}$），导致坐标运算无效。
  • 坐标计算粗心：中点坐标或含参坐标计算错误，导致后续全错。务必回头检查关键点坐标。

代表题精讲

2021-理-18

题目：在四棱锥 $P-ABCD$ 中，底面 $ABCD$ 是矩形，$PD \perp$ 底面 $ABCD$，$PD=DC=1$，$M$ 为 $BC$ 中点，且 $PB \perp AM$。 （1）求 $BC$ 长；（2）求二面角 $A-PM-B$ 的正弦值。

思路：利用 $PD \perp$ 底面矩形建立空间直角坐标系。将 $BC$ 设为参数，通过 $PB \perp AM$ 的向量数量积为 $0$ 求出参数。再用方程组分别求平面 $PAM$ 与平面 $PMB$ 的法向量，计算法向量夹角余弦绝对值，进而得二面角正弦值。

步骤： 1. 建系：以 $D$ 为原点，$\overrightarrow{DA},\overrightarrow{DC},\overrightarrow{DP}$ 方向分别为 $x,y,z$ 轴正方向。 设 $BC = 2a\ (a>0)$，则各点坐标为 $D(0,0,0), A(2a,0,0), B(2a,1,0), M(a,1,0), P(0,0,1)$。 2. 求参数：$\overrightarrow{PB} = (2a,1,-1)$，$\overrightarrow{AM} = (-a,1,0)$。 由 $\overrightarrow{PB} \cdot \overrightarrow{AM} = -2a^2+1=0$，解得 $a = \frac{\sqrt{2}}{2}$。故 $BC = 2a = \sqrt{2}$。 3. 求法向量 $\vec{m}$（平面 $PAM$）： $\overrightarrow{PA} = (\sqrt{2},0,-1)$，$\overrightarrow{AM} = (-\frac{\sqrt{2}}{2},1,0)$。 由 $\begin{cases} \vec{m} \cdot \overrightarrow{PA} = \sqrt{2}x - z = 0 \ \vec{m} \cdot \overrightarrow{AM} = -\frac{\sqrt{2}}{2}x + y = 0 \end{cases}$，取 $x=\sqrt{2}$，得 $y=1, z=2$。$\vec{m}=(\sqrt{2},1,2)$。 4. 求法向量 $\vec{n}$（平面 $PMB$）： $\overrightarrow{PM} = (\frac{\sqrt{2}}{2},1,-1)$，$\overrightarrow{PB} = (\sqrt{2},1,-1)$。 由 $\begin{cases} \vec{n} \cdot \overrightarrow{PM} = \frac{\sqrt{2}}{2}x + y - z = 0 \ \vec{n} \cdot \overrightarrow{PB} = \sqrt{2}x + y - z = 0 \end{cases}$，两式相减得 $\frac{\sqrt{2}}{2}x=0 \Rightarrow x=0$。代入得 $y=z$，取 $y=1,z=1$。$\vec{n}=(0,1,1)$。 5. 计算二面角正弦值： $\cos\langle\vec{m},\vec{n}\rangle = \frac{|\vec{m}\cdot\vec{n}|}{|\vec{m}||\vec{n}|} = \frac{3}{\sqrt{7}\cdot\sqrt{2}} = \frac{3}{\sqrt{14}}$。 二面角正弦值 $\sin\theta = \sqrt{1 - (\frac{3}{\sqrt{14}})^2} = \frac{\sqrt{70}}{14}$。

点评/变式：核心在于通过正交条件确定几何体形状。建系后，所有二面角问题化为纯代数运算，无需作辅助线找平面角。

2015-理-19

题目：在长方体 $ABCD-A_1B_1C_1D_1$ 中，$AB=16, BC=10, AA_1=8$，点 $E,F$ 分别在 $A_1B_1, D_1C_1$ 上且 $A_1E=D_1F=4$，过 $E,F$ 的平面 $\alpha$ 与长方体的面交成正方形。 （1）画出正方形；（2）求直线 $AF$ 与平面 $\alpha$ 所成角的正弦值。

思路：由长方体天然垂直关系直接建系。根据交线为正方形确定截面位置。求 $AF$ 方向向量与平面 $\alpha$ 法向量，代入线面角正弦公式。

步骤： 1. 建系：以 $D$ 为原点，射线 $DA,DC,DD_1$ 分别为 $x,y,z$ 轴正半轴。 可得 $A(10,0,0), A_1(10,0,8), F(0,4,8)$。 2. 分析正方形：平面 $\alpha$ 过 $EF$ 作截面，交线正方形边长等于 $EF$ 在平行平面间距离，结合尺寸知正方形边长为 $10$。可确定截面与棱交点为 $G(10,6,0), H(0,10,0)$ 等（实际作图为矩形 $EFGH$，其中 $E(10,4,8), F(0,4,8)$）。 3. 求平面 $\alpha$（即 $EFGH$）的法向量 $\vec{n}$： $\overrightarrow{EF} = (-10,0,0)$，$\overrightarrow{EH} = (-10,6,-8)$。 由 $\begin{cases} \vec{n} \cdot \overrightarrow{EF} = -10x = 0 \ \vec{n} \cdot \overrightarrow{EH} = -10x+6y-8z = 0 \end{cases}$，得 $x=0$。取 $y=4$，则 $z=3$。$\vec{n}=(0,4,3)$。 4. 求线面角： 方向向量 $\overrightarrow{AF} = (-10,4,8)$。 $\sin\theta = \frac{|\overrightarrow{AF} \cdot \vec{n}|}{|\overrightarrow{AF}||\vec{n}|} = \frac{|0+16+24|}{\sqrt{100+16+64} \cdot \sqrt{16+9}} = \frac{40}{\sqrt{180}\cdot 5} = \frac{4\sqrt{5}}{15}$。

点评/变式：截面位置分析是此类题的难点，但一旦画出或确定关键点坐标，就转化为常规的求法向量和线面角问题。建系时利用现成的墙角模型最为直接。
