知识精要

  • 点到平面距离定义：由空间一点向平面作垂线，垂线段的长即为该点到该平面的距离。
  • 核心方法——等体积法（体积桥）：
    若 $P$ 为平面 $\alpha$ 外一点，$A,B,C$ 为 $\alpha$ 上不共线三点，则点 $P$ 到 $\alpha$ 的距离
    $$d = \frac{3V_{P-ABC}}{S_{\triangle ABC}}.$$ 通过选择便于计算体积的顶点与底面（常利用已知线面垂直或可求高的三棱锥）求出 $V_{P-ABC}$，再求出 $\triangle ABC$ 的面积，即可解得 $d$。
  • 向量法求距离（新高考常备）：
    若平面 $\alpha$ 的法向量为 $\boldsymbol n$，定点 $P$ 到平面 $\alpha$ 的距离
    $$d = \frac{|\overrightarrow{AP}\cdot \boldsymbol n|}{|\boldsymbol n|},$$
    其中 $A$ 为 $\alpha$ 内任意一点。向量法无需构造三棱锥，适用于可方便建系的图形。
  • 适用条件：能以已知垂直关系或坐标运算得到三棱锥体积与底面面积；向量法需能准确求出平面法向量。

解题方法与套路

  1. 定位目标三棱锥
    确定哪个点是待求距离的“顶”，哪个平面是“底”，将该点与平面上的三个点构成三棱锥。
  2. 换顶点求体积
    选取另一个便于求高的顶点（常为已有线面垂直或能直接求高的一点），计算同一三棱锥的体积 $V$。常用公式：$V = \frac13 S_{\text{底}} \cdot h_{\text{已知}}$。注意变换不会改变体积大小。
  3. 求目标底面面积
    结合已知长度、角度以及垂直关系（如线线垂直、线面垂直），准确计算出待求距离所对的底面三角形的面积。优先寻找直接直角，若无直角可解三角形。
  4. 用体积反求距离
    利用 $d = \dfrac{3V}{S_{\text{底面}}}$ 得出点到平面的距离。可代入数值，注意分母和分子的单位与运算。
  5. （向量法备选）
    建系 $\rightarrow$ 求平面法向量 $\rightarrow$ 利用点法距公式求解。需明确坐标、准确计算叉积或法向量。

高频易错

  • 忘记证明关键垂直：直接用某线段作为高，却未证明它与底面垂直（如 $PO\perp$ 平面 $ABC$、$BC\perp PB$ 等），会在立体几何证明题中失去步骤分。
  • 等体积变换选错顶点：若所选新顶点到新底面的距离未知，则无法求出体积。应选择有明确线面垂直或已给长度的顶点。
  • 平面面积计算失误：误用斜边当高、将平行四边形面积直接当作三角形面积、忽略正弦定理中角度的匹配、漏乘 $\frac12$ 等。
  • 体积公式疏忽：忘记乘 $\frac13$ 或将 $V=Sh$ 当成三棱锥体积。
  • 数据代入粗心：求 $d=\frac{3V}{S}$ 时，将 $V$ 与 $S$ 的对应关系弄错，混淆不同平面的面积与体积。

代表题精讲

题目1（2018全国Ⅱ文19(2)）

在三棱锥 $P-ABC$ 中，$AB=BC=2\sqrt{2}$，$PA=PB=PC=AC=4$，$O$ 为 $AC$ 中点。已证 $PO\perp$ 平面 $ABC$。点 $M$ 在棱 $BC$ 上，且 $MC=2MB$，求点 $C$ 到平面 $POM$ 的距离。
思路：能利用已证的 $PO\perp$ 平面 $ABC$，将三棱锥 $C-POM$ 的体积转化为以 $P$ 为顶点的 $P-COM$ 的体积。
步骤
1. 计算 $V_{C-POM}=V_{P-COM}$。$PO\perp$ 底面 $ABC$，故 $P-COM$ 的高 $PO$ 可求：在正 $\triangle PAC$ 中，$PO=2\sqrt{3}$。
2. 求 $S_{\triangle COM}$：由 $BC=2\sqrt{2}$，$MC=2MB$ 得 $MC=\frac{4\sqrt{2}}3$；$\triangle ABC$ 为等腰直角三角形（$AB=BC=2\sqrt{2}$，$\angle B=90^\circ$），$\angle C=45^\circ$，$OC=2$。
$$S_{\triangle COM}=\frac12\cdot OC\cdot CM\cdot\sin45^\circ = \frac12\times 2\times\frac{4\sqrt{2}}3\times\frac{\sqrt{2}}2 = \frac43.$$
3. 得 $V_{P-COM}= \frac13 S_{\triangle COM}\cdot PO = \frac13\times\frac43\times2\sqrt{3}= \frac{8\sqrt{3}}9.$
4. 求 $S_{\triangle POM}$：$PO\perp OM$，先求 $OM$。在 $\triangle COM$ 中用余弦定理：
$OM^2=OC^2+CM^2-2\cdot OC\cdot CM\cos45^\circ = 4+\frac{32}{9} - 2\times2\times\frac{4\sqrt{2}}3\times\frac{\sqrt{2}}2 = \frac{20}{9}$，$OM=\frac{2\sqrt5}3$。
$S_{\triangle POM}= \frac12\cdot PO\cdot OM = \frac12\times 2\sqrt{3}\times\frac{2\sqrt{5}}3= \frac{2\sqrt{15}}3.$
5. 由 $d=\frac{3V}{S}$ 得点 $C$ 到平面 $POM$ 的距离 $d = \dfrac{3\times\frac{8\sqrt{3}}9}{\frac{2\sqrt{15}}3} = \frac{\frac{8\sqrt{3}}3}{\frac{2\sqrt{15}}3} = \frac{8\sqrt{3}}{2\sqrt{15}} = \frac{4\sqrt{5}}5.$
点评/变式：等体积法在此题中两次受益于第(1)问证明的线面垂直，考前务必养成“先证后算”的习惯。若将条件改为正棱锥或建系，亦可使用向量法。
