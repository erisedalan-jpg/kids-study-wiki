点斜式

知识精要

  • 点斜式方程：若直线过定点 $P(x_0,\,y_0)$ 且斜率为 $k$，则其方程为
    $$y-y_0=k(x-x_0)$$
  • 适用条件：必须已知直线上一点和直线的斜率；当直线斜率不存在（倾斜角为 $90^\circ$）时，方程应写为 $x=x_0$，不能用点斜式。
  • 求切线斜率：函数 $y=f(x)$ 在 $x=x_0$ 处的导数 $f'(x_0)$ 即为曲线在该点处切线的斜率。
  • 切点与切线：若点 $(x_0,y_0)$ 在曲线 $y=f(x)$ 上，则切线方程为 $y-y_0=f'(x_0)(x-x_0)$。

解题方法与套路

  1. 确认点的位置：验证给定点是否在曲线上。若在，即为切点；若不在，需设切点再列方程。
  2. 求斜率：对函数求导，将切点横坐标代入导函数，得到切线斜率 $k$。
  3. 对多项式函数，用 $(x^n)'=nx^{n-1}$ 逐项求导。
  4. 套用点斜式：将切点坐标 $(x_0,y_0)$ 与斜率 $k$ 代入 $y-y_0=k(x-x_0)$。
  5. 化简方程：通常化为斜截式 $y=kx+b$ 或一般式，以便匹配选项或按要求作答。
  6. 检查特殊情况：若导数不存在，检查是否为竖直线情况（$x=x_0$）；若斜率为 $0$，切线为水平线 $y=y_0$。

高频易错

  • 导函数求错：误记幂函数导数公式，如将 $(x^3)'$ 错算为 $3x^2$ 忘记系数，或常数项遗漏。务必逐项求导。
  • 混淆点斜式与斜截式：直接将点代入 $y=kx+b$ 求 $b$ 时，斜率算错或计算失误导致方程错误。点斜式可直接代入，更不容易出错。
  • 忽略点不在曲线上：题目所给点如果不在曲线上，不能直接求导得斜率，必须设切点坐标联立方程，否则解答全错。
  • 代值错误：求导后将 $x$ 的值代入导函数时，正负号或运算差错，导致斜率错误。建议代入后二次检验。
  • 切线方程不化简：部分题目要求选出正确的直线方程，若不化简为选项中的形式，容易误判。

代表题精讲

题目
曲线 $y=x^3-2x+1$ 在点 $(1,0)$ 处的切线方程为（ ）
A．$y=x-1$ 　B．$y=-x+1$ 　C．$y=2x-2$ 　D．$y=-2x+2$

思路
先验证点 $(1,0)$ 是否在曲线上，确认其为切点；对函数求导得到斜率函数，代入 $x=1$ 得切线斜率；利用点斜式写出切线方程并化简，对比选项。

步骤
1. 验证切点：将 $x=1$ 代入原函数 $y=1^3-2\times1+1=0$，故点 $(1,0)$ 在曲线上，即为切点。
2. 求斜率：对 $y=x^3-2x+1$ 求导，得 $y'=3x^2-2$。
当 $x=1$ 时，斜率 $k=3\times1^2-2=1$。
3. 点斜式：过 $(1,0)$ 且斜率为 $1$ 的直线方程为 $y-0=1\cdot(x-1)$，即 $y=x-1$。
4. 结合选项，对应 A。

点评/变式
此题是导数几何意义与点斜式的直接结合，难度较低。关键步骤是准确求导和代入横坐标得斜率。若题目改为“过点 $(0,1)$ 作曲线 $y=x^3-2x+1$ 的切线”，则该点不在曲线上，需设切点 $(t,t^3-2t+1)$，写出切线方程 $y-(t^3-2t+1)=(3t^2-2)(x-t)$，再将 $(0,1)$ 代入解出 $t$，最后回代得切线方程，此时要警惕思维定式，不能直接对 $(0,1)$ 求导。
