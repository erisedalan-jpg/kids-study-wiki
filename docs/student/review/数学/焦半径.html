焦半径

考点定位

  • 父主题：解析几何
  • 权重 weight：1
  • 真题数：3；年份跨度：2013–2022
  • 出现题位：填空16 选择6 选择11
  • 难度分布：中2 难1

知识精要

  1. 定义与核心定理：连接抛物线上一点与焦点的线段称为抛物线的焦半径。核心依据是抛物线定义：平面内到一个定点（焦点）和一条定直线（准线）距离相等的点的轨迹。设抛物线上点为 $M$，焦点为 $F$，则 $|MF|$ 等于点 $M$ 到准线的距离 $d$。利用该定义可将焦半径长度转化为坐标运算，是解决此类问题的根本。
  2. 不同标准方程下的焦半径公式（重要推论）：
    • 对于抛物线 $y^2 = 2px \ (p>0)$，焦点 $F(\frac{p}{2},0)$，准线 $x = -\frac{p}{2}$。若点 $M(x_0,y_0)$ 在抛物线上，则 $|MF| = x_0 + \frac{p}{2}$。
    • 对于抛物线 $y^2 = -2px$，$|MF| = -x_0 + \frac{p}{2}$（此时 $x_0 \le 0$）。
    • 对于抛物线 $x^2 = 2py$，$|MF| = y_0 + \frac{p}{2}$；$x^2 = -2py$，$|MF| = -y_0 + \frac{p}{2}$。
    • 适用条件：必须先确认抛物线的标准方程类型与焦点位置。公式直接给出焦半径与点坐标的线性关系，避免复杂的距离公式。
  3. 焦点弦相关性质（拓展）：过焦点的弦为焦点弦。此专题真题常结合焦点弦的中点、延长线等几何条件，但解题突破口往往仍是焦半径公式本身。

解题方法与套路

  1. 第一步：明确方程与焦点。快速将抛物线方程化为标准形式，确定 $p$ 值，写出焦点坐标和准线方程。这是所有计算的基础。
  2. 第二步：坐标设点与表示。根据点在抛物线上的位置，灵活设出一点坐标。若仅涉及一个独立点，通常设横坐标为参数。例如对 $y^2=2px$，常设 $M(\frac{y_0^2}{2p}, y_0)$。
  3. 第三步：翻译几何条件为代数方程。
    • 距离相等条件：若给出 $|MF| = d$，优先使用焦半径公式转化为 $x_0 + \frac{p}{2} = d$ 或类似形式，解出坐标。
    • 直径与圆的条件：“以 $MF$ 为直径的圆过点 $A$” $\Leftrightarrow$ $AF \perp AM$ $\Leftrightarrow$ $\overrightarrow{FA} \cdot \overrightarrow{MA} = 0$ 或利用 “直径所对圆周角为直角”。
    • 中点条件：利用中点坐标公式，用已知点表示未知点坐标。
  4. 第四步：联立方程与代换。将第三步得到的代数方程与点在抛物线上的方程联立。通常未知数个数等于方程个数，可解。注意开方时可能有多个解，对应多种可能情况（如2013题出现两解）。

高频易错

  1. 混淆焦准距与焦点坐标：$y^2=2px$ 中，焦点是 $(\frac{p}{2}, 0)$，焦准距是 $p$。经常误将 $p$ 当焦点横坐标代入计算，导致错误。
  2. 点坐标的符号选取不当：设点坐标时，若仅给出距离而未说所在象限，其纵坐标可取正负。例如 $x=1$ 时，$y$ 可取 $\pm 2\sqrt{2}$，不可遗漏。但有时求的是长度，最终结果不受符号影响，需先保留符号计算以确定几何形状。
  3. 错误套用焦半径公式：盲目记成 $x_0+\frac{p}{2}$，而不管抛物线开口方向。左开口时准线为 $x=\frac{p}{2}$，焦半径实为 $\frac{p}{2}-x_0$。最稳妥的方法是用定义推导：$|MF| = x_0\ \text{到准线的距离}$。
  4. 几何条件翻译偏差：对“以AB为直径的圆过点P”理解不完全。它同时意味着：(1) P在以AB中点为圆心半径的圆上；(2) $\angle APB=90^\circ$。后者（向量点积为0）往往是更简洁的代数转化路径。2013-理-11题若直接计算圆心坐标和半径会非常繁琐，而用垂直关系可快速建立等式。

代表题精讲

2022-文-06

  • 题目：设 $F$ 为抛物线 $C:y^2=4x$ 的焦点，点 $A$ 在 $C$ 上，点 $B(3,0)$，若 $|AF|=|BF|$，求 $|AB|$。
  • 思路：由抛物线方程得焦点坐标和 $p$ 值，求出 $|BF|$，即为 $|AF|$。利用焦半径公式将 $|AF|$ 转化为点 $A$ 的横坐标 $x_A$，代入抛物线方程求出 $A$ 的全坐标，最后用两点间距离公式求 $|AB|$。
  • 步骤：
    1. 由 $y^2=4x$ 知 $p=2$，焦点 $F(1,0)$。
    2. $B(3,0)$，则 $|BF|=|3-1|=2$，故 $|AF|=2$。
    3. 设 $A(x_A,y_A)$，由焦半径公式 $|AF| = x_A+\frac{p}{2} = x_A+1=2$，解得 $x_A=1$。
    4. $A$ 在抛物线上，代入 $x_A=1$ 得 $y_A^2=4 \times 1=4$，解得 $y_A=\pm 2$。不妨取点坐标不影响长度，设 $A(1,2)$。
    5. 计算 $|AB| = \sqrt{(1-3)^2+(2-0)^2} = \sqrt{4+4} = 2\sqrt{2}$。
  • 点评：此题是焦半径公式的直接应用，步骤简洁，是基础分必拿题型。关键在于迅速转化距离为横坐标。若不用焦半径公式而设 $A(x,y)$，用 $\sqrt{(x-1)^2+y^2}=2$ 联立 $y^2=4x$ 也能解出 $x$，但计算量稍大，足见熟练使用推论公式的必要性。

2017-理-16

  • 题目：已知 $F$ 是抛物线 $C:y^2=8x$ 的焦点，$M$ 是 $C$ 上一点，$FM$ 的延长线交 $y$ 轴于点 $N$。若 $M$ 为 $FN$ 的中点，求 $|FN|$。
  • 思路：利用中点关系，将 $N$ 点纵坐标用 $M$ 点坐标表示，并结合 $N$ 在 $y$ 轴上（横坐标为0）这一特征求出 $M$ 的横坐标。再用焦半径公式求出 $|FM|$，$|FN|$ 即为其两倍。
  • 步骤：
    1. 由 $y^2=8x$ 得 $p=4$，焦点 $F(2,0)$。设 $N(0, y_N)$。
    2. $M$ 为 $FN$ 中点，由中点公式得 $M(\frac{2+0}{2}, \frac{0+y_N}{2})$，即 $M(1, \frac{y_N}{2})$。
    3. $M$ 在抛物线上，代入坐标：$(\frac{y_N}{2})^2 = 8 \times 1$，解得 $y_N = \pm 4\sqrt{2}$。
    4. $M$ 的横坐标 $x_M=1$，由焦半径公式 $|FM| = x_M + \frac{p}{2} = 1+2=3$。
    5. 因为 $M$ 是 $FN$ 中点，所以 $|FN|=2|FM|=6$。
  • 点评：本题巧妙结合中点和焦半径，未直接给出 $M$ 坐标，但通过中点性质精确定位了其横坐标。关键一步是发现 $M$ 横坐标必为 $F$ 和 $N$ 横坐标平均数，即 $1$。后续计算水到渠成，考查了转化思想与运算准确性。

2013-理-11

  • 题目：设抛物线 $C:y^2=2px(p>0)$ 的焦点为 $F$，点 $M$ 在 $C$ 上，$|MF|=5$，若以 $MF$ 为直径的圆过点 $(0,2)$，求 $C$ 的方程。
  • 思路：设出焦点 $F$ 和点 $M$。利用 $|MF|=5$ 结合焦半径公式得出 $M$ 的横坐标（含 $p$）。设 $A(0,2)$，利用圆的条件转化为直角三角形 $MAF$ 中 $\angle MAF=90^\circ$，即勾股定理 $|AM|^2+|AF|^2=|MF|^2$。将所有长度用 $p$ 表示，解方程求 $p$。
  • 步骤：
    1. 焦点 $F(\frac{p}{2}, 0)$，设 $M(x_M, y_M)$。
    2. 由 $|MF|=5$ 及焦半径公式：$x_M + \frac{p}{2} = 5 \Rightarrow x_M = 5 - \frac{p}{2}$。代入抛物线 $y_M^2 = 2p(5 - \frac{p}{2})$。
    3. 设 $A(0,2)$，由题知 $\angle MAF=90^\circ$，故 $|AM|^2+|AF|^2=|MF|^2$。
    4. 计算各长度平方： $|MF|^2=25$ $|AF|^2 = (\frac{p}{2}-0)^2+(0-2)^2 = \frac{p^2}{4}+4$ $|AM|^2 = (x_M-0)^2+(y_M-2)^2 = x_M^2+y_M^2-4y_M+4$
    5. 代入 3 中等式：$(x_M^2+y_M^2-4y_M+4) + (\frac{p^2}{4}+4) = 25$ $\Rightarrow [ (5-\frac{p}{2})^2 + 2p(5-\frac{p}{2}) ] -4y_M + 4 + \frac{p^2}{4}+4 = 25$ $\Rightarrow 25 -5p + \frac{p^2}{4} + 10p -p^2 -4y_M + 8 + \frac{p^2}{4} = 25$ $\Rightarrow -\frac{p^2}{2} +5p -4y_M + 8 = 0$ $(1)$
    6. 需另寻方程消去 $y_M$。再考虑 $AF \perp AM$，即 $k_{AF} \cdot k_{AM} = -1$，或向量点积为零。 $\overrightarrow{FA} = (-\frac{p}{2}, 2)$，$\overrightarrow{MA} = (-x_M, 2-y_M)$。 由 $\overrightarrow{FA} \cdot \overrightarrow{MA} = 0$ 得：$(-\frac{p}{2})(-x_M) + 2(2-y_M) = 0$ $\Rightarrow \frac{p}{2}x_M + 4 -2y_M = 0$ $\Rightarrow 2y_M = \frac{p}{2}(5-\frac{p}{2})+4$ $(2)$
    7. 将 $(2)$ 代入 $(1)$ 消去 $y_M$： $-\frac{p^2}{2}+5p -2[\frac{p}{2}(5-\frac{p}{2})+4] + 8 = 0$ $-\frac{p^2}{2}+5p -5p + \frac{p^2}{2} -8 + 8 = 0$ 发现代入后恒为 $0=0$，说明只用直角不足以确定 $p$，需利用 $M$ 在抛物线上的条件更充分。实际上，直接展开 $|AM|^2+|AF|^2=|MF|^2$ 并将 $y_M^2=2p x_M$ 代入，得： $x_M^2 + 2p x_M -4y_M+4 + \frac{p^2}{4}+4 = 25$ 将 $x_M=5-\frac{p}{2}$ 代入，得 $10p-\frac{p^2}{2} -4y_M +8=0$，结合向量点积 $2y_M = \frac{5p}{2} - \frac{p^2}{4} + 4$，代入得： $10p -\frac{p^2}{2} -2( \frac{5p}{2} - \frac{p^2}{4} +4) +8=0 \Rightarrow p^2 -10p +16=0$，解得 $p=2$ 或 $p=8$。
    8. 抛物线方程为 $y^2=4x$ 或 $y^2=16x$。
  • 点评：本题是压轴题，难度在于几何条件与代数转化的复合。解题核心仍紧扣抛物线定义（焦半径）得出 $M$ 横坐标。破解圆的条件时，“直径对直角”巧妙避开了圆心半径的复杂计算。计算过程中需注意保留 $y_M$ 一次项到最终消元。若直接设 $M$ 点利用距离求解，运算量会激增。
