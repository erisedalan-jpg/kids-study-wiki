球心到平面的距离

考点球心到平面的距离权重1真题数1学科数学父主题立体几何

考点定位

  • 父主题：立体几何
  • 权重 weight：1
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 球的表面积公式：$S=4\pi R^2$，$R$为球半径。
  • 球心到截面圆距离公式：$d=\sqrt{R^2-r^2}$，其中$r$为截面圆半径，且球心与截面圆圆心的连线垂直于该截面。
  • 等边三角形面积公式：$S_{\triangle}=\frac{\sqrt3}{4}a^2$（$a$为边长）。
  • 等边三角形外接圆半径：$r=\frac{a}{\sqrt3}$；内切圆半径：$r_{\text{内}}=\frac{a}{2\sqrt3}$（勿混淆）。
  • 适用条件：三角形顶点均在球面上，则该三角形的外接圆即为球的一个截面圆，上述距离公式直接适用。

解题方法与套路

  1. 由面积反求边长：对等边三角形，利用 $S=\frac{\sqrt3}{4}a^2$ 解得边长 $a$。
  2. 求三角形外接圆半径：用 $r=\frac{a}{\sqrt3}$ 计算截面圆半径。
  3. 由球的表面积求球半径：由 $S_{\text{球}}=4\pi R^2$ 解出 $R$。
  4. 代入距离公式：$d=\sqrt{R^2-r^2}$ 即得球心到平面的距离。
  5. 检验垂直关系：确认球心与截面圆心连线垂直于平面，通常题设“顶点都在球面上”已保证此关系。

高频易错

  • 混淆等边三角形的外接圆半径与内切圆半径，误将 $r_{\text{内}}=\frac{a}{2\sqrt3}$ 当作截面圆半径，导致距离计算错误。
  • 面积公式记忆不准：$S=\frac{\sqrt3}{4}a^2$ 记成 $S=\frac{\sqrt3}{2}a^2$ 或 $S=\frac{1}{2}a^2\sin60^\circ$ 但忘记化简。
  • 球表面积公式混用 $S=4\pi R^2$ 与 $S=\pi D^2$ 导致半径计算出错。
  • 忽略球心到平面距离为 $\sqrt{R^2-r^2}$ 的前提是球心到截面圆心连线垂直截面，实际解题时需有意识验证，但若题目明确“顶点在球面上且三角形为等边”可大胆使用。
  • 计算草率：开方、平方时符号或数值错误，如 $\sqrt{4-3}$ 算出 $\sqrt{7}$。

代表题精讲

题目（2020·理科全国卷） 已知 $\triangle ABC$ 是面积为 $\dfrac{9\sqrt3}{4}$ 的等边三角形，且其顶点都在球 $O$ 的球面上。若球 $O$ 的表面积为 $16\pi$，则 $O$ 到平面 $ABC$ 的距离为（ ）
A. $\sqrt3$　B. $\dfrac32$　C. $1$　D. $\dfrac{\sqrt3}{2}$

思路
先由等边三角形面积求出边长 $a$，进而得截面圆半径 $r$；再由球的表面积求出球半径 $R$；最后利用距离公式 $d=\sqrt{R^2-r^2}$ 求解。

步骤
设等边三角形边长为 $a$，则
$$\frac{\sqrt3}{4}a^2 = \frac{9\sqrt3}{4} \quad\Rightarrow\quad a^2=9 \quad\Rightarrow\quad a=3.$$
等边三角形外接圆半径
$$r = \frac{a}{\sqrt3} = \frac{3}{\sqrt3} = \sqrt3.$$
球 $O$ 表面积 $S=4\pi R^2 = 16\pi$，得
$$R^2 = 4 \quad\Rightarrow\quad R = 2.$$
球心 $O$ 到平面 $ABC$ 的距离
$$d = \sqrt{R^2 - r^2} = \sqrt{4 - 3} = 1.$$
故答案为 C。

点评/变式
- 本题是球心到截面距离的经典模型，难度较低，但必须准确记忆等边三角形的外接圆半径公式。若将 $r$ 误取为 $\frac{a}{2\sqrt3}=\frac{\sqrt3}{2}$，会错选 $d=\frac{\sqrt{13}}{2}$ 等。 - 变式：若题目给出的是任意三角形的面积和外接圆半径，仍需先求外接圆半径，再结合球半径求距离。核心始终是 $d=\sqrt{R^2-r^2}$，关键在于准确从条件中提取 $r$ 和 $R$。 - 延伸：当截面为直角三角形时，外接圆半径 $r$ 等于斜边的一半；正 $n$ 边形外接圆半径也有固定公式，答题要注意公式适用条件。
