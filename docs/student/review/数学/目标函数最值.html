目标函数最值

知识精要

本考点聚焦在线性约束条件下求解线性目标函数的最值，即简单的线性规划问题。核心框架如下：

  1. 可行域：由二元一次不等式组构成的约束条件，在平面直角坐标系中表示为各不等式解集的交集，通常是凸多边形区域（含边界）。
  2. 目标函数：形如 $z = ax + by$ 的函数。求 $z$ 最值的关键在于将其变形为直线的斜截式：$y = -\frac{a}{b}x + \frac{z}{b}$（设 $b ≠ 0$）。此时，$\frac{z}{b}$ 代表该直线在 $y$ 轴上的截距。
  3. 最值定理：线性目标函数的最优解必然在可行域的某个顶点处取得。若顶点处未得最值，则目标函数可能无界。
  4. 核心步骤：“画、移、求、算”，即精确画出可行域，再通过平移目标函数等值线族找到最优解对应的顶点，联立方程求出该点坐标，并回代目标函数算出最值。

解题方法与套路

针对线性规划的填空题与选择题，总结通法步骤如下：

  1. 精确画域：在坐标系中，将每个约束条件取等号视为直线方程。
    • 对于不等式 $Ax + By + C ≥ 0$ (或 $≤ 0$)，可用选点法（如原点 $(0,0)$）检验可行域在半平面的哪一侧。
    • 注意虚实线：包含“=”（如$≥,≤$）画实线，不包含（如 $>,<$）画虚线。
  2. 目标函数变形：将 $z = ax + by$ 改写为 $y = -\frac{a}{b}x + \frac{z}{b}$，指明 $z$ 的几何意义与直线在 $y$ 轴截距 $\frac{z}{b}$ 成正比或相反。
  3. 平移寻优：先过原点（或易画的点）画出斜率为 $-\frac{a}{b}$ 的一族平行线中的一条。保持斜率不变，沿着截距增大或减小的方向平移该直线，使其首次或最后一次接触可行域的顶点。
    • 若 $b>0$，则直线在 $y$ 轴截距最大时 $z$ 最大，截距最小时 $z$ 最小。
    • 若 $b<0$，则结论相反。
  4. 求解算值：联立构成该最优顶点的两相交直线方程，得到精确坐标 $(x_0, y_0)$。将该坐标代入原目标函数 $z = ax + by$ 中算出最终结果。

高频易错

从历年真题暴露的失分点来看，务必注意以下几点：

  • 画域方向颠倒：选点代入检验不等式时符号弄错，导致整个可行域画反。务必用简单点（如 $(0,0)$）谨慎检验。
  • 混淆截距与目标值：例如，对于 $z = x - 2y$，变形为 $y = \frac{1}{2}x - \frac{z}{2}$。目标 $z$ 越大，截距 $-\frac{z}{2}$ 反而越小。切忌不假思索地认为“截距最大时 $z$ 最大”。
  • 顶点求解草率：求解最优解坐标时，联立直线方程计算错误，或者将点坐标代入目标函数时出现运算失误，导致功亏一篑。
  • 忽略边界等号：未看清约束条件是“$≥$”还是“$>$”，导致画线虚实错误，可能丢失边界上的最优解。
  • 斜率比较失败：目标函数直线斜率未取准，或因可行域极不规则而凭感觉平移，导致选错顶点。关键是看初始等值线的倾斜程度。

代表题精讲

2022-文-05

  • 题目：约束条件为 $x+y \ge 2$，$x+2y \le 4$，$y \ge 0$，求 $z = 2x - y$ 的最大值。
  • 思路：先作出三条直线围成的可行域，将目标函数变形为 $y = 2x - z$，明确 $z$ 最大等价于直线在 $y$ 轴上的截距 $-z$ 最小。平移斜率为 $2$ 的直线寻找最优解。
  • 步骤：
    1. 画出直线 $x+y=2$，$x+2y=4$，$y=0$。经检验点 $(0,0)$ 不满足第一个不等式 $x+y \ge 2$，故可行域为三线所围成的开口向右上的三角形区域。
    2. 目标函数 $z = 2x - y$，化为 $y = 2x - z$。该直线斜率 $k=2$，纵截距为 $-z$。
    3. 绘制一条斜率为 $2$ 的初始直线。向下（纵截距减小方向）平移该直线，使其纵截距 $-z$ 最小，从而使得 $z$ 最大。
    4. 观察图像，当直线平移到经过约束边界 $x+2y=4$ 与 $y=0$ 的交点 $C(4,0)$ 时，截距最小。
    5. 将 $x=4, y=0$ 代入目标函数，得 $z_{\text{max}} = 2 \times 4 - 0 = 8$。
  • 点评/变式：目标函数 $z = 2x - y$ 中 $y$ 的系数为负，是截距与目标函数值增减性相反的典型案例。务必转化为 $-z$ 来观察。变式可将 $y$ 系数的负号换位置，如 $z = x + 2y$，则结论反之。

2019-文-13

  • 题目：变量 $x, y$ 满足 $2x + 3y - 6 \ge 0$，$x + y - 3 \le 0$，$y - 2 \le 0$，求 $z = 3x - y$ 的最大值。
  • 思路：先行定域，再化 $z$ 为 $y = 3x - z$，明确 $z$ 与纵截距 $-z$ 成反比。平移斜率为 $3$ 的直线，使截距最小。
  • 步骤：
    1. 作出三条界线的图象。能看出可行域是一个以 $(0,2)$、$(1,2)$ 和 $(3,0)$ 为顶点的三角形区域。
    2. 将 $z = 3x - y$ 变形为 $y = 3x - z$，其中 $-z$ 是该直线的纵截距。
    3. 要令 $z$ 最大，即令纵截距 $-z$ 最小。因此，需将直线向下平移。
    4. 在向下平移过程中，直线最后接触的可行域顶点是 $(3,0)$。
    5. 代入计算，$z_{\text{max}} = 3 \times 3 - 0 = 9$。
  • 点评/变式：此题顶点 $(3,0)$ 由 $x+y-3=0$ 与 $y=0$ 联立得出。注意第三个条件 $y-2\le 0$ 在本题中是可行域的“上边界”，并非最优解所在处。若将目标函数换为取最小值，则最优解通常下移。

2018-理-14

  • 题目：变量 $x, y$ 满足约束条件 $\begin{cases} x-2y+2 \ge 0 \ x+y-1 \ge 0 \ 2x-y-4 \le 0 \end{cases}$，求 $z = x + y$ 的最大值。
  • 思路：本题目标函数 $z = x+y$ 中 $y$ 系数为正，直接平移即可。画出约束域，将目标函数化为 $y = -x + z$，寻找纵截距最大的顶点。
  • 步骤：
    1. 画出三条直线对应的区域并取交集，得到一个不规则四边形区域。
    2. 目标函数化为 $y = -x + z$，斜率为 $-1$，纵截距为 $z$。
    3. 此时 $z$ 最大等价于纵截距最大。故将斜率为 $-1$ 的直线系向上平移。
    4. 观察可行域，该直线向上平移到最后接触的点是边界 $x-2y+2=0$ 与 $2x-y-4=0$ 的交点。联立解得该点坐标为 $(2, 2)$。
    5. 代入目标函数，得最大值 $z_{\text{max}} = 2 + 2 = 4$。
  • 点评/变式：本题属于 $b>0$ 的常规情形，直接“上移取大、下移取小”。需注意最优解未必由最靠边的直线相交得到，应养成联立检验顶点坐标的习惯。
