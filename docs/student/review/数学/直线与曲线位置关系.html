直线与曲线位置关系

  • 真题数：1；年份跨度：2018–2018
  • 出现题位：解答22
  • 难度分布：中1

知识精要

  • 圆锥曲线的参数方程与互化：椭圆 $\frac{x^{2}}{a^{2}}+\frac{y^{2}}{b^{2}}=1$ 的参数方程为 $\begin{cases} x=a\cos\theta \ y=b\sin\theta \end{cases}$（$\theta$ 为离心角）；直线的标准参数方程为 $\begin{cases} x=x_0+t\cos\alpha \ y=y_0+t\sin\alpha \end{cases}$（$t$ 为参数，$\alpha$ 为倾斜角），$|t|$ 表示直线上动点到定点 $(x_0,y_0)$ 的距离。
  • 直线与二次曲线相交弦中点问题的两条核心途径：
  • 点差法：设弦端点 $A(x_1,y_1),B(x_2,y_2)$，代入曲线方程作差，利用中点坐标与斜率关系直接得斜率，适用条件：中点坐标已知。
  • 参数 $t$ 的几何意义：将标准参数方程代入曲线，交点对应 $t_1,t_2$，弦中点满足 $t_1+t_2=0$，由此求倾斜角或斜率。
  • 中点坐标公式：$x_1+x_2=2x_0,\;y_1+y_2=2y_0$（$(x_0,y_0)$ 为中点）。
  • 直线与椭圆相交弦存在的前提是中点在椭圆内部（需验证$\frac{x_0^2}{a^2}+\frac{y_0^2}{b^2}<1$）。

解题方法与套路

  1. 参数方程化普通方程：三角参数多用 $\cos^2\theta+\sin^2\theta=1$ 消参；直线参数直接消 $t$ 得点斜式 $y-y_0=\tan\alpha(x-x_0)$ 或一般式。
  2. 已知弦中点求弦所在直线斜率（点差法）：
  3. 设弦端点 $(x_1,y_1),(x_2,y_2)$，代入椭圆（或双曲线、抛物线）标准方程；
  4. 两式相减，左边因式分解产生 $(x_1+x_2)(x_1-x_2)$ 与 $(y_1+y_2)(y_1-y_2)$；
  5. 代入中点坐标，整理得 $\frac{y_1-y_2}{x_1-x_2}$，即为所求斜率。
  6. 利用直线参数方程处理中点问题：
  7. 写出直线的标准参数方程 $\begin{cases} x=x_0+t\cos\alpha \ y=y_0+t\sin\alpha \end{cases}$；
  8. 代入二次曲线方程，整理成关于 $t$ 的一元二次方程 $At^2+Bt+C=0$；
  9. 弦中点对应 $t_1+t_2=0$ ⇒ $B=0$，解出 $\tan\alpha$（斜率）。
  10. 通法备用：若不想用参数 $t$，可直接设点斜式 $y-y_0=k(x-x_0)$，联立方程，利用韦达定理由中点条件 $\frac{x_1+x_2}{2}=x_0$ 解 $k$。

高频易错

  • 参数方程消参时忽略参数的取值范围，导致普通方程表示的曲线多于或少于原曲线（本题 $\theta$ 为任意实数，无限制；若有限制，必须注明）。
  • 直线参数方程 $\begin{cases} x=x_0+at \ y=y_0+bt \end{cases}$ 中，只有当 $a^2+b^2=1$ 且 $b\ge0$（或准确对应三角函数）时，$t$ 才具有标准距离意义，否则不能直接使用 $t_1+t_2=0$ 得中点的结论。
  • 使用点差法求出斜率后，未验证判别式 $\Delta>0$ 而直接写直线方程，可能产生不存在弦的情况（本题中点 $(1,2)$ 在椭圆 $\frac{x^2}{4}+\frac{y^2}{16}=1$ 内部，天然满足）。
  • 将中点坐标 $(1,2)$ 误代入椭圆方程求斜率，例如误认为中点满足直线与椭圆联立后韦达定理的对称中心，未分清点差法与代入法的区别。

代表题精讲

题目：（2018·理22）在直角坐标系 $xOy$ 中，曲线 $C$ 的参数方程为 $\begin{cases} x=2\cos\theta \ y=4\sin\theta \end{cases}$（$\theta$ 为参数），直线 $l$ 的参数方程为 $\begin{cases} x=1+t\cos\alpha \ y=2+t\sin\alpha \end{cases}$（$t$ 为参数）。 （1）求 $C$ 和 $l$ 的直角坐标方程； （2）若曲线 $C$ 截直线 $l$ 所得线段的中点坐标为 $(1,2)$，求 $l$ 的斜率。

思路： (1) 椭圆 $C$ 用平方和消参；直线 $l$ 消 $t$ 得点斜式或一般式。 (2) 已知弦中点即直线所过定点 $(1,2)$，可用点差法或参数 $t$ 的几何意义高效求解斜率，避开繁杂的联立韦达算法。

步骤： (1) 由 $\begin{cases} x=2\cos\theta \ y=4\sin\theta \end{cases}$，利用 $\cos^2\theta+\sin^2\theta=1$，得 $$\frac{x^2}{4}+\frac{y^2}{16}=1.$$ 这就是 $C$ 的直角坐标方程（椭圆）。
由 $\begin{cases} x=1+t\cos\alpha \ y=2+t\sin\alpha \end{cases}$，消去 $t$ 得 $y-2=\tan\alpha\,(x-1)$，或化为一般式 $x\sin\alpha - y\cos\alpha + 2\cos\alpha - \sin\alpha = 0$。

(2) 方法一（点差法）
设直线 $l$ 与椭圆 $C$ 的交点为 $A(x_1,y_1),\;B(x_2,y_2)$，则
$$\frac{x_1^2}{4}+\frac{y_1^2}{16}=1,\qquad \frac{x_2^2}{4}+\frac{y_2^2}{16}=1.$$
两式相减得 $$\frac{(x_1+x_2)(x_1-x_2)}{4} + \frac{(y_1+y_2)(y_1-y_2)}{16} = 0.$$
因为线段 $AB$ 的中点坐标为 $(1,2)$，所以 $x_1+x_2 = 2$, $y_1+y_2 = 4$，代入上式：
$$\frac{2(x_1-x_2)}{4} + \frac{4(y_1-y_2)}{16} = 0 \;\Rightarrow\; \frac{x_1-x_2}{2} + \frac{y_1-y_2}{4} = 0.$$
两边乘 $4$：$2(x_1-x_2) + (y_1-y_2) = 0$，因此斜率
$$k = \frac{y_1-y_2}{x_1-x_2} = -2.$$

方法二（参数 $t$ 的几何意义）
将直线参数式代入椭圆方程：
$$\frac{(1+t\cos\alpha)^2}{4} + \frac{(2+t\sin\alpha)^2}{16} = 1.$$
展开并整理成关于 $t$ 的二次方程：
$$\left(\frac{\cos^2\alpha}{4}+\frac{\sin^2\alpha}{16}\right)t^2 + \left(\frac{\cos\alpha}{2}+\frac{\sin\alpha}{4}\right)t + \left(\frac{1}{4}+\frac{4}{16}-1\right) = 0.$$
常数项为零（因为点 $(1,2)$ 在椭圆内部，检验即知），方程形式为 $At^2 + Bt = 0$。
设两个交点对应参数为 $t_1,t_2$，由韦达定理 $t_1+t_2 = -\frac{B}{A}$。中点对应 $t_1+t_2 = 0$，故 $B=0$：
$$\frac{\cos\alpha}{2} + \frac{\sin\alpha}{4} = 0 \;\Rightarrow\; 2\cos\alpha + \sin\alpha = 0 \;\Rightarrow\; \tan\alpha = -2.$$
因此 $l$ 的斜率为 $-2$。

点评/变式： 点差法在已知弦中点时，可以“秒杀”斜率，无需联立方程和繁琐的代数运算，是解答小题和简化大题步骤的首选。参数 $t$ 的方法本质上与联立法等价，但利用了中点 $(x_0,y_0)$ 恰好是直线所过定点的特性，直接由一次项系数为零得出结果，同样简洁。
变式训练：若直线 $l$ 过点 $(1,2)$ 且被椭圆截得的弦长被该点平分，还能求出弦长；或者把中点换为 $(0,1)$，先验证是否在椭圆内，再求斜率。点差法对双曲线、抛物线同样适用，注意双曲线中点弦存在性要求中点不在渐近线上等条件。
