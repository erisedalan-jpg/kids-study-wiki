直线参数方程

知识精要

  • 坐标互化公式
    直角坐标 $(x,y)$ 与极坐标 $(\rho,\theta)$ 满足：
    $$\rho^2 = x^2 + y^2,\quad x = \rho\cos\theta,\quad y = \rho\sin\theta.$$

  • 圆的方程
    圆的标准方程 $(x - a)^2 + (y - b)^2 = r^2$，圆心 $(a, b)$，半径 $r$；
    一般方程 $x^2 + y^2 + Dx + Ey + F = 0$，化为标准式后可求圆心、半径。

  • 直线的参数方程（坐标式）
    过点 $P_0(x_0,y_0)$，倾斜角为 $\alpha$ 的直线参数方程为：
    $$\begin{cases} x = x_0 + t\cos\alpha \ y = y_0 + t\sin\alpha \end{cases} \quad (t\ \text{为参数})$$
    其中 $|t|$ 表示直线上动点 $P$ 到 $P_0$ 的距离。当 $t > 0$ 时，$\overrightarrow{P_0P}$ 方向与 $\alpha$ 一致；$t < 0$ 方向相反。

  • 直线参数方程化为普通方程
    消去参数 $t$：当 $\cos\alpha \neq 0$ 时，斜率 $k = \tan\alpha = \dfrac{\sin\alpha}{\cos\alpha}$，
    普通方程为 $y - y_0 = \tan\alpha \cdot (x - x_0)$。

  • 直线与圆相交的弦长
    若圆心到直线的距离为 $d$，圆半径为 $r$，则弦长
    $$|AB| = 2\sqrt{r^2 - d^2}.$$

解题方法与套路

  1. 圆的极坐标方程求法
    先将圆的一般方程写出（若给出标准方程则展开），再将 $x^2+y^2$ 换为 $\rho^2$，$x$ 换为 $\rho\cos\theta$，$y$ 换为 $\rho\sin\theta$，整理即得极坐标方程。

  2. 已知直线参数方程，求普通方程与斜率
    识别参数方程是否为标准形式 $(x = x_0 + t\cos\alpha,\ y = y_0 + t\sin\alpha)$。
    若是，直接得斜率 $k = \tan\alpha$；若 $x$ 与 $t$ 关系不含 $\cos\alpha$，需利用恒等变形消 $t$。

  3. 已知弦长求直线斜率
    利用弦长公式 $|AB| = 2\sqrt{r^2 - d^2}$ 反解圆心到直线的距离 $d$。
    再结合点到直线距离公式 $d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2+B^2}}$ 建立关于斜率 $k$ 的方程，求解即得。

  4. 参数方程中介入弦长问题的标准流程

  5. 化参数方程为普通方程（含参斜率）；
  6. 求圆心坐标与半径；
  7. 列出圆心到直线距离表达式（含斜率）；
  8. 代入弦长公式解出斜率。

高频易错

  • 混淆一般式与标准式参数方程：只有当 $t$ 的系数为 $\cos\alpha,\sin\alpha$ 且 $\cos^2\alpha+\sin^2\alpha=1$ 时，$t$ 才具有几何距离意义。若题目给出 $x = at,\ y = bt$，则不是标准形式，需消参求斜率。
  • 弦长公式误用：只适用于直线与圆相交时，圆心到直线距离 $d < r$，且必须保证计算 $d$ 时使用普通方程。
  • 解斜率时丢解：由 $d$ 的表达式得出关于 $|k|$ 的方程，开方后应得两个互为相反数的解（斜率为正负），勿漏。
  • 极坐标方程漏项：展开圆标准方程时，常数项遗漏导致 $\rho^2$ 与常数项的转换错误。

代表题精讲

题目：2016-文-23

在直角坐标系 $xOy$ 中，圆 $C$ 的方程为 $(x+6)^2+y^2=25$。
（Ⅰ）以坐标原点为极点，$x$ 轴正半轴为极轴建立极坐标系，求 $C$ 的极坐标方程；
（Ⅱ）直线 $l$ 的参数方程是 $\begin{cases} x = t\cos\alpha \ y = t\sin\alpha \end{cases}$（$t$ 为参数），$l$ 与 $C$ 交于 $A,B$ 两点，$|AB|= \sqrt{10}$，求 $l$ 的斜率。

思路
（Ⅰ）从圆的标准方程展开得到一般方程，利用直角坐标与极坐标互化公式直接代换。
（Ⅱ）从直线参数方程知它过原点，倾斜角为 $\alpha$，普通方程为 $y = (\tan\alpha)x$。利用弦长和半径求出圆心到直线的距离，再由距离公式建立关于斜率 $k=\tan\alpha$ 的方程求解。

步骤
（Ⅰ）将 $(x+6)^2 + y^2 = 25$ 展开：
$x^2 + 12x + 36 + y^2 = 25 \implies x^2 + y^2 + 12x + 11 = 0$.
代入 $\rho^2 = x^2 + y^2,\ x = \rho\cos\theta$，得极坐标方程
$$\rho^2 + 12\rho\cos\theta + 11 = 0.$$

（Ⅱ）由参数方程消参，直线的普通方程为 $y = (\tan\alpha)x$，即 $kx - y = 0$，其中 $k = \tan\alpha$。
圆 $C$ 圆心 $(-6,0)$，半径 $r = 5$。
圆心到直线的距离
$$d = \frac{|-6k - 0|}{\sqrt{k^2 + 1}} = \frac{6|k|}{\sqrt{k^2+1}}.$$
由弦长公式 $|AB| = 2\sqrt{r^2 - d^2}$，代入 $|AB|=\sqrt{10}$，得
$$\sqrt{10} = 2\sqrt{25 - d^2} \implies 10 = 4(25 - d^2) \implies d^2 = 25 - \frac{5}{2} = \frac{45}{2}.$$
又 $d^2 = \dfrac{36k^2}{k^2+1}$，所以
$$\frac{36k^2}{k^2+1} = \frac{45}{2} \implies 72k^2 = 45(k^2+1) \implies 27k^2 = 45 \implies k^2 = \frac{5}{3}.$$
因此 $k = \pm\dfrac{\sqrt{15}}{3}$，即直线 $l$ 的斜率为 $\dfrac{\sqrt{15}}{3}$ 或 $-\dfrac{\sqrt{15}}{3}$。

点评/变式
本题综合了圆的普通方程、极坐标方程和直线参数方程的转化，以及直线与圆相交的弦长计算。
- 牢记标准参数方程 $ (t\cos\alpha, t\sin\alpha) $ 中的参数 $t$ 的正余弦系数直接对应倾斜角。
- 变式：若给出一般参数方程 $ \begin{cases} x = -6 + t\cos\alpha \ y = t\sin\alpha \end{cases} $，则直线过 $(-6,0)$，求弦长同样思路；或给出非标准参数方程如 $ \begin{cases} x = 2t \ y = 3t \end{cases} $，应先消参求斜率再套用公式。
