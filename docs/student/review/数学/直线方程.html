知识精要

  • 直线的倾斜角与斜率
    倾斜角 $\alpha \in [0,\pi)$，斜率 $k = \tan\alpha$（$\alpha \neq \frac{\pi}{2}$）。两点 $P_1(x_1,y_1), P_2(x_2,y_2)$ 决定的斜率 $k = \frac{y_2 - y_1}{x_2 - x_1}$（$x_1 \neq x_2$）。
  • 直线方程的五种形式
    点斜式：$y - y_0 = k(x - x_0)$；斜截式：$y = kx + b$；两点式：$\frac{y - y_1}{y_2 - y_1} = \frac{x - x_1}{x_2 - x_1}$；截距式：$\frac{x}{a} + \frac{y}{b} = 1$（$a,b \neq 0$）；一般式：$Ax + By + C = 0$（$A,B$不同时为 $0$）。
    注意：截距是坐标，可取负值；点斜式与斜截式要求斜率存在；两点式要求 $x_1 \neq x_2$ 且 $y_1 \neq y_2$。
  • 两直线的位置关系
    平行 $\iff k_1 = k_2$ 且 $b_1 \neq b_2$，或 $A_1B_2 - A_2B_1 = 0$ 且 $A_1C_2 - A_2C_1 \neq 0$。
    垂直 $\iff k_1k_2 = -1$，或 $A_1A_2 + B_1B_2 = 0$。
  • 到角公式与对称
    $l_1$ 到 $l_2$ 的角 $\theta$ 满足 $\tan\theta = \frac{k_2 - k_1}{1 + k_1k_2}$（$1+k_1k_2 \neq 0$）。
    点关于直线对称：垂直+中点在直线上。直线关于直线对称：常用来解决角平分线或等腰三角形底边所在直线问题。
  • 距离公式
    两点距 $|P_1P_2| = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$；
    点 $(x_0, y_0)$ 到直线 $Ax+By+C=0$ 的距离 $d = \frac{|Ax_0+B y_0+C|}{\sqrt{A^2+B^2}}$；
    平行线 $Ax+By+C_1=0$ 与 $Ax+By+C_2=0$ 间距 $d = \frac{|C_1 - C_2|}{\sqrt{A^2+B^2}}$。
  • 解析几何中的直线策略
    在椭圆、双曲线、抛物线中，直线方程常设为点斜式（需讨论斜率不存在），通过联立方程、韦达定理、几何条件坐标化求解。

解题方法与套路

  1. 选设直线方程
    已知一点选点斜式，已知纵截距选斜截式；过 $x$ 轴上定点可设 $x = my + t$（避免讨论斜率不存在）；与圆锥曲线相交时，优先设简单形式。
  2. 利用几何条件坐标化
    等腰三角形底边所在直线与两腰等角 → 用到角公式建立等式；对称点 → 中点在对称轴上且连线垂直；腰三角形、焦点三角形等，把长度、角度转化为顶点坐标关系。
  3. 求交点与代点
    直线与曲线相交，联立方程求出交点坐标（或利用韦达定理表达关系）。将已知点坐标代入直线方程解出参数。注意双曲线、抛物线的特殊几何性质可简化计算。
  4. 求斜率/离心率/距离的通用路径
    设点 → 抓住几何约束（如等腰、直角、对称）写出直线方程 → 代入另一条件（点坐标、距离等） → 解方程得出所求参数。
  5. 检验与取舍
    结合图形排除增根（如斜率取值、原点位置、焦点所在侧等）。用选项反代验证是选择题的高效策略。

高频易错

  • 忽视斜率不存在的情形：设点斜式 $y-y_0=k(x-x_0)$ 前要判断直线垂不垂直于 $x$ 轴；若过 $F(c,0)$ 的直线可设为 $x=my+c$ 避免讨论。
  • 到角公式顺序反置：$l_1$ 到 $l_2$ 的角是 $l_1$ 逆时针旋转到 $l_2$ 的角，计算时 $k_1$、$k_2$ 代入 $\tan\theta = \frac{k_2 - k_1}{1+k_1k_2}$ 位置不可颠倒。等腰三角形底边到两腰的角相等，需根据图形判定位角方向。
  • 截距式滥用：截距式要求横、纵截距均不为零。过原点或与坐标轴平行的直线不能用截距式。
  • 交点坐标代入遗忘条件：如“点 $P$ 在过 $A$ 且斜率为某值的直线上”意味着 $P$ 坐标满足该直线方程，必须完整写出并代入。
  • 离心率与斜率混淆：离心率 $e = \frac{c}{a}$，斜率 $k = \frac{\Delta y}{\Delta x}$，不可直接将 $k$ 当作 $e$ 或 $c/a$，需通过几何条件转化。
  • 双曲线左支/右支限定：涉及双曲线分支时，联立后交点横坐标的符号需符合“左支”或“右支”要求，否则会多解或错解。

代表题精讲

2024-新课标Ⅱ-19

  • 题目：双曲线 $C: x^2 - y^2 = m\ (m>0)$，点 $P_1(5,4)$ 在 $C$ 上，常数 $k \in (0,1)$。过 $P_{n-1}$ 作斜率为 $k$ 的直线与 $C$ 的左支交于 $Q_{n-1}$，$P_n$ 为 $Q_{n-1}$ 关于 $y$ 轴的对称点，依次构造 $n=2,3,\dots$。
  • 思路：利用 $P_1$ 求 $m$；设 $P_{n-1}$，写出直线方程，联立双曲线求出 $Q_{n-1}$；利用对称得 $P_n$ 坐标，寻找 $P_n(y_n)$ 的递推关系，最终证明数列性质或求极限。
  • 步骤：
  • 代 $P_1$ 入 $C$：$25-16 = m \Rightarrow m = 9$，双曲线为 $x^2 - y^2 = 9$。
  • 设 $P_{n-1}(x_{n-1}, y_{n-1})$，过其且斜率为 $k$ 的直线：$y - y_{n-1} = k(x - x_{n-1})$。
  • 与 $C$ 联立，消 $y$ 得 $x^2 - [k(x - x_{n-1}) + y_{n-1}]^2 = 9$。解出异于 $P_{n-1}$ 的另一交点 $Q_{n-1}$（在左支，取负根）。
  • 对称得 $P_n$：若 $Q_{n-1}(x_Q, y_Q)$，则 $P_n(-x_Q, y_Q)$。
  • 观察 $P_n$ 的坐标递推，利用 $k$ 的范围与几何性质证明序列收敛或求出特定项。
  • 点评／变式：本题以直线和对称构造点列，本质是迭代映射的坐标表达。解答时勿漏“左支”导致选错交点；利用 $y$ 轴对称为换号，可将双曲线上的点映射到右支，方便后续讨论。类似题可变为关于 $x$ 轴对称或其他斜率的旋转对称。

2018-理-12

  • 题目：已知 $F_1,F_2$ 是椭圆 $C:\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1(a>b>0)$ 的左右焦点，$A$ 为左顶点，$P$ 在过 $A$ 且斜率为 $\frac{\sqrt{3}}{6}$ 的直线上，$\triangle PF_1F_2$ 为等腰三角形，$\angle F_1F_2P = 120^{\circ}$，求离心率。
  • 思路：将等腰与角度转化为 $P$ 点坐标，代 $P$ 入直线 $AP$ 方程得到 $a,c$ 关系。
  • 步骤：
  • 定坐标：$A(-a,0), F_1(-c,0), F_2(c,0)$。直线 $AP: y = \frac{\sqrt{3}}{6}(x + a)$。
  • 等腰 $\triangle PF_1F_2$ 中 $\angle F_1F_2P = 120^{\circ}$，底边可能为 $PF_1$ 或 $F_1F_2$。由 $|PF_2| = |F_1F_2| = 2c$，且 $\angle PF_2F_1 = 120^{\circ}$，可求 $P$ 坐标：作垂线或旋转，得 $P(2c, \sqrt{3}c)$。
  • $P$ 在直线 $AP$ 上：$\sqrt{3}c = \frac{\sqrt{3}}{6}(2c + a) \Rightarrow a = 4c$。
  • 离心率 $e = \frac{c}{a} = \frac{1}{4}$。
  • 点评／变式：解析几何中常把焦点三角形条件直接坐标化；注意等腰三角形直角与120°的坐标推算。本题亦可用 $PF_1$ 为底边等其他情形检验，舍去不符合题意的解。变式可将直线斜率或角度更换，训练条件翻译能力。

2017-文-12

  • 题目：过抛物线 $C: y^2 = 4x$ 的焦点 $F$，且斜率为 $\sqrt{3}$ 的直线交 $C$ 于点 $M$（$M$ 在 $x$ 轴上方），$l$ 为 $C$ 的准线，点 $N$ 在 $l$ 上且 $MN \perp l$，求 $M$ 到直线 $NF$ 的距离。
  • 思路：求 $M$ 坐标，由 $MN \perp l$ 得 $N$，写出 $NF$ 方程，计算点 $M$ 到直线距离。
  • 步骤：
  • 焦点 $F(1,0)$，准线 $l: x = -1$；直线 $MF: y = \sqrt{3}(x - 1)$。
  • 联立 $y^2 = 4x$：$3(x-1)^2 = 4x \Rightarrow 3x^2 -10x +3 =0 \Rightarrow x = 3$ 或 $x = \frac{1}{3}$。$M$ 在 $x$ 轴上方且对应较大 $x$，取 $x=3$，$y = 2\sqrt{3}$，即 $M(3, 2\sqrt{3})$。
  • $MN \perp l$ 且 $N$ 在 $l$ 上，故 $N(-1, 2\sqrt{3})$。直线 $NF$：过 $N(-1, 2\sqrt{3})$ 和 $F(1,0)$，斜率 $k_{NF} = \frac{2\sqrt{3} - 0}{-1-1} = -\sqrt{3}$，方程 $\sqrt{3}x + y - \sqrt{3} = 0$。
  • 点 $M$ 到直线 $NF$ 的距离 $d = \frac{|\sqrt{3} \cdot 3 + 2\sqrt{3} - \sqrt{3}|}{\sqrt{(\sqrt{3})^2 + 1^2}} = \frac{|4\sqrt{3}|}{2} = 2\sqrt{3}$。
  • 点评／变式：涉及抛物线时，充分利用定义（如 $|MF|$ 等于 $M$ 到准线距离）和几何性质可简化。本题 $MN \perp l$ 揭示 $M,N$ 纵坐标相同，大幅减少运算。此类距离问题常结合点到直线距离公式与几何关系直接求值。
