直线的截距

  • 难度分布：难1

知识精要

  • 直线的截距：直线与 $x$ 轴交点的横坐标称为横截距（$a$），与 $y$ 轴交点的纵坐标称为纵截距（$b$）。截距是实数，可为正、负或零。
  • 截距式方程：若直线在 $x$、$y$ 轴上的截距分别为 $a$、$b$（$a \neq 0, b \neq 0$），则直线方程为 $\displaystyle\frac{x}{a}+\frac{y}{b}=1$。
    过原点的直线不能用截距式表示（截距均为 $0$）。
  • 由一般式或点斜式求截距：将直线方程 $Ax+By+C=0$ 化为截距式时，令 $y=0$ 得 $x=-\frac{C}{A}$（横截距），令 $x=0$ 得 $y=-\frac{C}{B}$（纵截距）。
  • 直线与坐标轴围成的三角形面积：$S = \frac{1}{2}|a||b|$，其中 $a$、$b$ 为直线在两轴上的截距。注意取绝对值以保证面积非负。
  • 切线相关（本题背景）：圆 $x^2+y^2=r^2$ 上一点 $(x_0,y_0)$ 处的切线方程为 $x_0 x + y_0 y = r^2$；若用点斜式，切线斜率 $k$ 与圆心和切点连线的斜率乘积为 $-1$。

解题方法与套路

  1. 判断点与圆的位置关系：将点代入圆方程，若满足则点在圆上；若不满足且需切线，要分情况讨论（设斜率、判别式等）。
  2. 求切线方程（点在圆上）：
  3. 法一：利用切线垂直过切点的半径，求出斜率 $k=-\frac{x_0}{y_0}$（$y_0 \neq 0$），再点斜式写出方程；
  4. 法二：直接代切线公式 $x_0 x + y_0 y = r^2$。
  5. 计算截距：将所得直线方程整理为一般式，分别令 $x=0$、$y=0$，求出纵截距 $b$ 和横截距 $a$。
  6. 求三角形面积：$S=\frac{1}{2}|ab|$，直接代入计算。若截距已为正值，可去掉绝对值。
  7. 化简与作答：注意计算结果是否为最简分数或整数，面积须带单位（本题无单位）。

高频易错

  • 截距与距离混淆：截距是坐标值（可正可负），求面积时务必加绝对值；距离是长度，本身就非负。
  • 忽略截距为零的情形：当直线过原点时，截距均为 $0$，此时与坐标轴围不成三角形（除非要说面积为 $0$），不可盲目套用 $\frac{1}{2}|ab|$。
  • 求切线斜率时忘记垂直关系：点在圆上时，切点与圆心连线的斜率 $k_1$ 与切线斜率 $k_2$ 满足 $k_1 k_2 = -1$，计算易取倒数而忘负号。
  • 方程系数符号错误：点斜式展开或化简一般式时，移项符号疏忽导致截距计算错误。例如 $y-2=-\frac{1}{2}(x-1)$ 化为 $x+2y-5=0$ 时，常数项符号要仔细。
  • 忽视斜率不存在的情况：若点在圆的上、下顶点，切线水平，斜率为 $0$；在左、右顶点，切线竖直，斜率不存在。本题无此情况，但其他题目需警惕分类讨论。

代表题精讲

题目（2009-文-15）：已知圆 $O: x^2+y^2=5$ 和点 $A(1,2)$，则过 $A$ 且与圆 $O$ 相切的直线与两坐标轴围成的三角形的面积等于___。

思路
先验证 $A$ 在圆上，利用切线与半径垂直求出斜率，点斜式写出切线方程，再分别求出横、纵截距，最后用面积公式 $S=\frac{1}{2}|ab|$ 计算。

步骤
1. 验证：$1^2+2^2=5$，点 $A$ 在圆上。
2. 圆心 $O(0,0)$ 与 $A$ 连线的斜率 $k_{OA} = \frac{2-0}{1-0}=2$，故切线斜率 $k = -\frac{1}{2}$。
3. 切线方程：$y-2 = -\frac{1}{2}(x-1)$，化简得 $x+2y-5=0$。
4. 求截距：令 $y=0$ 得 $x=5$（横截距 $a=5$）；令 $x=0$ 得 $y=\frac{5}{2}$（纵截距 $b=\frac{5}{2}$）。
5. 面积：$S = \frac{1}{2} \times 5 \times \frac{5}{2} = \frac{25}{4}$。

点评/变式
- 本题直接给出点在圆上，无需讨论点在圆外用判别式。若点改为 $(3,1)$（在圆外），则需设点斜式，利用圆心到直线距离等于半径求斜率，可能有两解，截距与面积计算更复杂。
- 注意截距可正可负，本题截距皆为正，面积可直接求。若截距一正一负，面积仍为其绝对值乘积的一半。
- 变式训练：求过点 $(-2,1)$ 且与圆 $x^2+y^2=5$ 相切的直线在两轴上的截距之和（或面积），需先判断点位置再计算。
