直观图

考点定位

  • 父主题：立体几何
  • 权重 weight：12
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：选择6
  • 难度分布：易1

知识精要

  • 三视图投影规律：主视图与俯视图 长对正；主视图与左视图 高平齐；俯视图与左视图 宽相等。三个视图均从垂直于相应投影面的方向观察得到，反映物体的真实长度、高度和宽度。
  • 简单组合体的三视图：由柱、锥、台、球等基本几何体经过叠加或切割形成的组合体，其三视图是各基本体三视图的叠加或截减，要注意各部分之间交界处的线条（实线可见，虚线不可见）以及切点、交线的表示。
  • 由三视图还原直观图：以俯视图为基础，结合主视、左视中的高度信息推断几何体的形状与位置，常用“拉伸法”（将二维视图沿垂直方向拉伸）或“拆分组合法”（将组合体拆成基本体分别还原）。
  • 空间想象与检验：根据已知两视图推断第三视图，关键是抓住几何体的结构特征及在不同投影方向上的可见轮廓，必要时借助坐标系及长方体框辅助定位。

解题方法与套路

  1. 由给定的两个视图确定几何体的结构：从投影规律入手，根据主视图与俯视图的“长对正”关系，判断几何体在水平面上的底面形状及前方、后方、左右位置；根据主视图的高度信息判断各部分的高度。
  2. 逐部分还原组合体：若为拼接型组合体，先在俯视图中划分各基本体的底面投影区域，再结合主视图的高度逐一还原柱、锥、台、球等；若为切割型，先想象完整的简单体，再通过视图中的缺角和线条判断切除部分。
  3. 确定第三视图的可见轮廓与不可见轮廓：根据“高平齐、宽相等”绘制左视图（侧视图）的外框，然后将还原出的几何体上各顶点、棱线向侧立投影面投影。注意对称中心线、相贯线、截交线等，特别分清哪部分在前（可见画实线）、哪部分在后（不可见画虚线）。
  4. 对照选项验证：将作出的左视图草图与选择题选项比对，确认关键棱线的实虚、倾斜方向及交点位置是否符合题目给出的正视图和俯视图。

高频易错

  • 分不清叠加体交界处的实虚线：两个基本体相接，若表面平齐则中间不应有线；若高低错落或相交，则应有交线。常在组合处漏画或多画线。
  • 视图中倾斜线的投影误判：俯视图中的斜线可能是倾斜平面的投影，也可能是曲面转向轮廓线。需结合另一视图判断，否则还原的几何体会出错。
  • 忽略不可见轮廓线的虚线：简单的锥体或棱柱被遮挡的棱线在侧视图中应为虚线，考生容易漏画。
  • 混淆圆锥与半圆锥、棱锥与棱柱：半圆锥在俯视图中表现为圆的一半加上三角形边界，若误判为三棱锥或半圆柱，会导致侧视图选择错误。
  • 宽相等度量错误：俯视图与左视图的宽度对应关系搞反，特别是在组合体前后不对称时，容易选错侧视图的左右位置。

代表题精讲

题目（2011年理科数学全国卷第6题）

已知一个几何体的正视图和俯视图（如图，正视图为等腰三角形内含一条从顶点到底边中点的竖线；俯视图由一矩形与一半圆拼接，矩形邻接半圆直径边，且内部有连线），则相应的侧视图可以为四个选项之一。要求选出正确的侧视图。

思路： 由俯视图的矩形加半圆可推断底面由一个长方形和半圆组合而成，应为棱柱与半圆锥（或半圆柱）构成的组合体。结合正视图为等腰三角形且内有竖线，说明组合体前方或后方存在斜面或棱线，需具体还原几何体再确定其向右投影的侧视图。

步骤： 1. 分析俯视图结构：将俯视图分为矩形区域和半圆区域两部分。矩形部分对应棱柱（或底面为矩形的直棱柱），半圆部分对应半圆锥或半圆柱。半圆的直径与矩形的一边重合，说明两部分前后紧密贴合。 2. 结合正视图确定高度：正视图外轮廓为等腰三角形，表明从正面看组合体最高点在中间，两侧逐渐降低。这种情况通常对应一个三棱锥（或半圆锥）与一个三棱柱的组合，使得交线形成三角形轮廓。正视图内部的竖线是从顶点到底边中点的可见棱线，说明该处有面与面的交线，且交线正对观察者。 3. 还原直观图：想象底面在水平面上，矩形部分在后（或前），半圆部分在另一侧贴合成整体。由正视图三角形轮廓可判断：半圆部分是一个半圆锥（底面直径与矩形等宽，且轴线垂直于底面），矩形部分可能是躺倒的三棱柱（其一个侧面与半圆锥的底面共面）。最终几何体为：后面是一个底面为直角三角形的直三棱柱（三角形面朝向前方），前面紧贴一个底面为半圆的半圆锥，两者高度相同且共用一条母线。 4. 绘制侧视图（从左向右看）：左侧（原俯视图中对应矩形一端）看到三棱柱的侧面，为矩形；右侧看到半圆锥的侧面，其轮廓为直角三角形（因为从侧面看圆锥，轮廓是三角形，半圆锥则显示为直角三角形与半圆底线）。注意两者叠加部分在侧视图中应画出交线——可见的竖线将矩形与三角形分开。因此侧视图整体外框为一矩形，内部有一条竖直分界线，且右侧三角形区域的斜边反映半圆锥的母线，呈倾斜状。该特征与选项中的图形匹配，选出正确答案（一般为类似矩形中间有竖线，上半部为直角三角形斜边的选项）。 5. 验证：用“高平齐”检查，侧视图高度等于正视图的三角形高度；用“宽相等”检查，侧视图总宽度等于俯视图矩形加半圆的总宽度，分界线位置对应矩形与半圆的分界，符合几何投影关系。

点评/变式： 本题核心障碍是从俯视图的半圆加矩形与正视图的三角形结合，正确还原为三棱柱与半圆锥的组合，而非全圆柱或半球。变式训练可尝试：将俯视图改为圆与矩形组合，正视图改为梯形，辨析侧视图；或给出侧视图与正视图，反选俯视图，强化组合体三视图的对应关系及“长对正、高平齐、宽相等”的应用。
