秦九韶算法

知识精要

  • 秦九韶算法：中国古代计算一元$n$次多项式值的优秀算法，西方称霍纳(Horner)算法。它将求值运算转化为一种递推关系，只需$n$次乘法和$n$次加法，远少于直接计算。
  • 基本公式：设多项式 $f(x)=a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0$，秦九韶算法通过从内层多次提取公因数改写为 $f(x)=((\cdots((a_nx+a_{n-1})x+a_{n-2})x+\cdots +a_1)x+a_0)$。
  • 递推步骤：令 $v_0=a_n$，对于 $k=1,2,\dots,n$，执行 $v_k=v_{k-1}\cdot x+a_{n-k}$，最终 $v_n=f(x)$。
  • 程序框图特征：通常采用循环结构——初始值可为 $S=0$ 或 $S=a_n$，然后循环 $n$ 次（或$n+1$次），每次输入下一个系数 $a$，执行 $S=S\times x + a$。输入系数的顺序必须从最高次项系数到常数项。
  • 核心理解：算法只做两种运算：“乘 $x$” 和 “加下一个系数”，反复进行。

解题方法与套路

  1. 读懂框图，确定变量角色：明确哪个变量存放当前累加值（通常为 $S$ 或 $v$），哪个是循环变量（如 $k$），以及循环终止条件。
  2. 确定初始状态与循环次数：注意 $S$ 的初值（可能为 $0$ 或直接输入第一个系数）。多项式次数为 $n$ 时，一般需要输入 $n+1$ 个系数，因此循环体执行 $n+1$ 次。
  3. 按顺序手工模拟：根据框图流程，严格按照“输入$a$ $\to$ 计算 $S=S\times x +a$ $\to$ 循环变量加1 $\to$ 检查条件”的顺序，一步步写出每一步的变量值。
  4. 系数与次数对应：输入的数字序列 $a$ 必须与多项式的系数顺序对应。若题干未明确，可根据算法特点推断：秦九韶算法总是从高次到低次（即 $a_n, a_{n-1}, \dots, a_0$）。
  5. 最后检查输出节点：确认循环退出后输出的变量是否正确，注意是否在更新后退出。

高频易错

  • 系数顺序颠倒：误以为输入顺序是常数项→一次项→高次项，导致代入错误。牢记秦九韶公式内部提取因子的顺序决定了系数必须从高位向低位输入。
  • 循环次数搞错：混淆次数 $n$ 与系数个数 $n+1$。如 $n=2$ 时系数有 3 个，循环应执行 3 次。若框图中初值为 $S=0$，则第一次输入的是最高次系数，循环次数为 $n+1$。
  • 初始值错误：框图可能将 $S$ 初始化为 0 或直接读取第一个系数，需结合程序结构判断，不可想当然。
  • 计算中途失误：模拟算式时直接跳步或乘加顺序颠倒（如误算成 $S=(S+a)\times x$），一定要严格按照 $S=S\times x+a$ 的正确递推式。
  • 忽略退出条件的判断时机：有的框图先计算，后判断 $k>n$ 退出；有的先判断。特别注意最后一步是否有效。本题是计算后 $k$ 自增，再判断，所以最后有效一步算完才退出。

代表题精讲

代表题 1：2016 年文科数学全国卷（理 8 同题）

题目：执行如图秦九韶算法程序框图，输入 $x=2$，$n=2$，依次输入的 $a$ 为 $2,2,5$，求输出的 $S$。

思路：首先识别这是典型的秦九韶递推，$n=2$ 表示多项式次数为 2，共有 3 个系数 $a_2,a_1,a_0$。初始 $S$ 很可能为 $0$，然后循环 $k$ 从 $1$ 到 $3$，每次读入一个系数，执行 $S=S\times x +a$，最终输出 $S$。

步骤： 1. 输入 $x=2$，$n=2$，设 $S=0$，$k=1$。 2. 第 1 次输入 $a=2$，$S=0\times 2 + 2 = 2$，$k=1$ 不满足退出条件。 3. 第 2 次输入 $a=2$，$S=2\times 2 + 2 = 6$，$k=2$ 不满足退出条件。 4. 第 3 次输入 $a=5$，$S=6\times 2 + 5 = 17$，$k=3$ 满足退出条件（$k>2$）。 5. 输出 $S=17$。

点评/变式：该题完美诠释了秦九韶算法的过程，多项式为 $f(x)=2x^2+2x+5$，当 $x=2$ 时代入得 17。变式：若框图初始 $S$ 为第一个输入的 $a$，则循环次数应少一次，计算顺序仍同。文理同题说明此考点考查频率虽低但一经出现便是经典，务必掌握模拟流程的严谨性。
