知识精要

  • 球的截面性质：球心到截面的距离 $d$、球半径 $R$ 与截面圆半径 $r$ 满足 $d^2+r^2=R^2$。
  • 两平面垂直时的几何结构：若两个平面 $\alpha \perp \beta$，球心 $O$ 向两平面作垂线，垂足分别为两截面圆的圆心 $O_1,O_2$，则有 $OO_1 \perp \alpha$，$OO_2 \perp \beta$，进而 $OO_1 \perp OO_2$。
  • 公共弦的中点性质：两截面圆的公共弦 $AB$ 的中点 $E$ 满足 $O_1E \perp AB$、$O_2E \perp AB$，且 $OE \perp AB$；当 $\alpha \perp \beta$ 时，$O_1E \perp O_2E$，可构成矩形 $OO_1EO_2$，其对角线 $O_1O_2 = OE$。
  • 距离计算：球心到公共弦中点的距离 $OE=\sqrt{R^2-\left(\dfrac{AB}{2}\right)^2}$；再利用矩形对角线相等求得两圆圆心距 $O_1O_2$。

解题方法与套路

  1. 定球心与截面圆圆心：对于球与平面的交线问题，首先确定球心 $O$，并由垂径定理找到截面圆圆心（球心在截面上的射影）。
  2. 抓住“垂直”构建平面图形：若涉及两垂直平面，必有球心到两平面的垂线相互垂直；公共弦中点与两圆心的连线也相互垂直，从而形成矩形或直角三角形。
  3. 把空间距离转化为平面线段计算：利用直角三角形（常用 $R$、$d$、$r$ 组成的直角三角形）或矩形对角线，通过勾股定理计算目标距离。
  4. 优先画关键截面图：画出过球心、截面圆圆心及公共弦中点的平面截图，可清晰展现各线段的垂直与相等关系。

高频易错

  • 直接套用两圆位置关系公式，忽略球心到两截面的垂线长度不一定相等，且两截面平面垂直时，圆心的几何关系由球心位置决定。
  • 误认为两截面圆的圆心距等于球心到两平面垂足的距离之和，忽略公共弦中点起到的连接作用（应为矩形对角线）。
  • 在计算 $OE$ 时忘记弦长的一半是 $1$，或误用球半径 $2$ 直接作为 $OE$。
  • 没正确建立矩形 $OO_1EO_2$：必须验证 $OO_1 \parallel O_2E$ 且 $OO_2 \parallel O_1E$，否则无法使用对角线相等的结论。

代表题精讲

题目

已知球半径 $R=2$，两个相互垂直的平面分别截球面得到两个圆，若两圆的公共弦长为 $2$，求两圆的圆心距。

思路

由球截面性质，球心到两平面的射影即为两圆的圆心 $O_1,O_2$。两平面垂直 $\Rightarrow$ $OO_1 \perp OO_2$。公共弦 $AB$ 中点 $E$，有 $O_1E \perp AB$，$O_2E \perp AB$，又平面垂直可推得 $O_1E \perp O_2E$，从而 $OO_1EO_2$ 为矩形。目标 $O_1O_2 = OE$，而 $OE$ 可在 $Rt\triangle OEA$ 中用勾股定理求得。

步骤

  1. 设球心为 $O$，两截面圆圆心分别为 $O_1,O_2$，公共弦为 $AB$，$E$ 为 $AB$ 中点。
  2. 因为 $OO_1 \perp$ 平面 $O_1AB$，$OO_2 \perp$ 平面 $O_2AB$，且两平面垂直，故 $OO_1 \perp OO_2$。
  3. 又 $O_1E \perp AB$，$O_2E \perp AB$，由平面垂直性质知 $O_1E \perp O_2E$，且 $O_1E \parallel OO_2$，$O_2E \parallel OO_1$，所以四边形 $OO_1EO_2$ 为矩形。
  4. 于是两圆圆心距 $O_1O_2 = OE$。
  5. 连接 $OA$，在 $Rt\triangle OEA$ 中，$OA=R=2$，$AE=\dfrac{AB}{2}=1$，由勾股定理：$OE = \sqrt{OA^2 - AE^2} = \sqrt{2^2 - 1^2} = \sqrt{3}$。
  6. 故 $O_1O_2 = \sqrt{3}$，对应选项 C。

点评/变式

本题以球与两垂直平面的截面为背景，考查空间想象与距离转化能力。核心在于将三维关系降维到一个矩形对角线上。变式：若两平面不垂直，给出其夹角，则 $OO_1$ 与 $OO_2$ 的夹角随之改变，$O_1O_2$ 需用余弦定理或异面直线上两点距离公式求解，但公共弦中点的性质仍有重要桥梁作用。
