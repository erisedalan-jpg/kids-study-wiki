空间几何体体积

考点定位

  • 父主题：立体几何
  • 权重 weight：1
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 正方体截角后的体积计算：正方体被平面沿三个面对角线截下一个三棱锥（即切去一个角），该三棱锥为直角三棱锥，底面是等腰直角三角形，侧棱垂直底面，体积为正方体体积的 $\frac{1}{6}$。
  • 空间几何体体积的求法：直接公式法（柱、锥、台、球），间接法（割补法、等体积法），以及利用三视图还原几何体再求体积。
  • 三视图规则：主视图与俯视图长对正，主视图与侧视图高平齐，俯视图与侧视图宽相等。三视图中的实线表示可见轮廓，虚线表示不可见轮廓。
  • 正方体面对角线、体对角线与截面的特征：与正方体顶点相关的截面往往形成正三角形、正方形、正六边形等，掌握其面积与体积比例。

解题方法与套路

  1. 还原几何体：根据三视图，先判断基本几何体（如正方体、长方体），再根据内部线条判断被截去部分的形状。本题主、俯、侧视图均是正方形且有一条对角线，可还原为正方体被平面沿三个面对角线切去一个三棱锥，剩余部分为三视图所示。
  2. 标注顶点与棱长：设正方体棱长为 $a$，明确截去部分是由三条共顶点的棱构成的直角三棱锥，其三条直角棱长均为 $a$。
  3. 计算体积比值：截去三棱锥体积 $V_{\text{截}}=\frac{1}{3}\times\left(\frac{1}{2}a^2\right)\times a = \frac{a^3}{6}$，剩余体积 $V_{\text{剩}}=a^3-\frac{a^3}{6}=\frac{5a^3}{6}$，二者比值 $\frac{V_{\text{截}}}{V_{\text{剩}}}=\frac{1}{5}$。
  4. 归一化处理：比值与棱长无关，可直接设 $a=1$ 简化计算，避免符号干扰。

高频易错

  • 三视图内对角线虚实不分：若对角线为虚线，则截去的部分可能位于不同方位，导致体积比变化。务必确认图中线型为实线。
  • 误将截去部分当成四棱锥或其它几何体：本题三视图的三个对角线均连通于同一顶点，由此判断截去的是一个三棱锥，若判断错误，体积公式将用错。
  • 体积比值分子分母颠倒：题目问“截去部分体积与剩余部分体积的比值”，务必看清谁比谁，避免写成 $5$ 或 $\frac{5}{1}$。
  • 忽略正方体切割后的剩余形状：剩余部分不是规则几何体，不能直接求积，用总体积减去截去部分体积为通法，但需确保截去部分计算无误。

代表题精讲

题目（2015-文-06）
一个正方体被一个平面截去一部分后，剩余部分的三视图如图，则截去部分体积与剩余部分体积的比值为多少？
（三视图特征：三个视图均为正方形，且每个正方形内有一条对角线，对角线从同一顶点出发。）

思路
由三视图“三个同向对角线”可判定截去部分为从正方体同一顶点出发的三条棱构成的三棱锥，体积为正方体的六分之一，进而求比值。

步骤
1. 设正方体棱长为 $1$，则体积 $V_{\text{正方体}}=1$。
2. 截去的三棱锥底面为边长为 $1$ 的等腰直角三角形，面积为 $\frac{1}{2}$，高为 $1$，故体积 $V_{\text{截}}=\frac{1}{3}\times\frac{1}{2}\times1=\frac{1}{6}$。
3. 剩余体积 $V_{\text{剩}}=1-\frac{1}{6}=\frac{5}{6}$。
4. 所求比值 $\frac{V_{\text{截}}}{V_{\text{剩}}}=\frac{1/6}{5/6}=\frac{1}{5}$。

点评/变式
该题是“割补法”的经典应用，关键是通过三视图还原切割方式。变式可改为截去两个角或多个角，或换成被一平面截去一个三棱柱等，核心仍是先还原再作差。此外，若三视图中的对角线方向变化或部分为虚线，对应的截去位置随之改变，但体积比可能依然不变，需结合空间想象灵活分析。
