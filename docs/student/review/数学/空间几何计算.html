考点定位

  • 父主题：立体几何
  • 权重 weight：2
  • 真题数：3；年份跨度：2009–2018
  • 出现题位：填空15 填空16
  • 难度分布：中3

知识精要

  • 旋转体（圆锥）
    母线 $l$、底面半径 $r$、高 $h$ 满足 $l^2 = r^2 + h^2$。
    母线与底面所成角 $\theta$：$\cos\theta = \dfrac{r}{l}$，$\sin\theta = \dfrac{h}{l}$。
    侧面积 $S_{\text{侧}} = \pi r l$，体积 $V = \dfrac{1}{3}\pi r^2 h$。
    轴截面等腰三角形底边 $2r$，腰 $l$，可集中反映母线、半径、角的关系。
  • 多面体（正四棱锥）
    底面正方形边长 $a$，高 $h$，斜高 $h'$，侧棱长 $l$。
    体积 $V = \dfrac{1}{3}a^2 h$。
    侧棱长 $l = \sqrt{h^2 + \left(\dfrac{\sqrt{2}}{2}a\right)^2}$，斜高 $h' = \sqrt{h^2 + \left(\dfrac{a}{2}\right)^2}$。
    外接球球心常在高线或延长线上，利用棱长与球半径关系列方程。
  • 球的截面与切线
    球半径 $R$，截面圆半径 $r$，球心到截面距离 $d$ 满足 $r^2 = R^2 - d^2$。
    过球内一点 $M$ 且与已知直线成 $\theta$ 角的平面，$d$ 可由点 $M$ 到球心的距离与 $\theta$ 的关系求得。
    球表面积 $S = 4\pi R^2$，体积 $V = \dfrac{4}{3}\pi R^3$。
  • 空间角的转化
    直线与平面所成角 → 直线与其在平面内射影的夹角。
    圆截面与直线成角 → 先定截面位置（与已知直线的夹角），再求球心到截面距离。

解题方法与套路

  1. 画关键截面
    圆锥问题常画轴截面（含高、母线、底面直径）；棱锥问题常画过顶点和底面中心的纵截面；球的截面问题画出过球心且与截面垂直的大圆，标出距离 $d$。
  2. 将空间角转化为平面线段比
    利用直角三角形中三角函数的定义，把母线与底面所成角、平面与直线所成角等转化为长度关系。例如圆锥中 $\sin\theta = h/l$，$\cos\theta = r/l$。
  3. 利用面积或体积条件建立方程
    如母线夹角已知，利用三角形面积 $S_{\triangle SAB} = \dfrac{1}{2} l^2 \sin\angle ASB$ 求母线 $l$；正四棱锥体积已知时，由 $V = \frac{1}{3}a^2h$ 求 $h$，再结合底面边长求侧棱。
  4. 球与截面问题列勾股方程
    抓住直角三角形 $R^2 = r^2 + d^2$。$d$ 的求解是难点，通常通过球心到截面所在平面的垂线段构造，再结合点 $M$ 的位置与给定夹角求 $d$。
  5. 代入公式计算结果
    得母线长、半径、高等基本量后，代入侧面积、表面积、体积公式，注意检查单位与运算。

高频易错

  • 错把母线与底面夹角当成母线与高线的夹角：母线与底面成角 $\theta$，则 $h = l\sin\theta$，$r = l\cos\theta$，不可颠倒。
  • 三角形面积公式误用：$S_{\triangle SAB} = \frac12\cdot SA\cdot SB\cdot\sin\angle ASB$，若 $SA=SB=l$，则为 $\frac12l^2\sin\angle ASB$。已知余弦时需先求正弦，避免符号错误。
  • 正四棱锥的侧棱与半对角线关系不清：底面正方形边长 $a$，半对角线为 $\frac{\sqrt{2}}{2}a$，侧棱长 $l = \sqrt{h^2 + (\frac{\sqrt{2}}{2}a)^2}$，不要误用为 $\frac{a}{2}$。
  • 球的截面距离计算错误：若截面过点 $M$ 且与直线 $OA$ 成 $\theta$ 角，$M$ 到球心距离 $OM$，$d = OM\cdot\sin\theta$ 还是 $\cos\theta$ 需画图确认。直线与平面所成角为直线与它在该平面内射影的夹角，因此 $d$ 是 $OM$ 在平面法向上的投影，通常 $d = OM\sin\theta$。
  • 面积与表面积混淆：圆锥侧面积 $\pi rl$，表面积 $\pi r(l+r)$；球的表面积 $4\pi R^2$。审题看清求“侧面积”还是“表面积”。
  • 单位与计算精度：涉及根号时常需保留根号形式或准确计算，避免过早近似导致答案错误。

代表题精讲

题目（2018·理·16）

圆锥顶点 $S$，母线 $SA,SB$ 所成角的余弦值为 $\dfrac78$，$SA$ 与底面成 $45^\circ$，$\triangle SAB$ 的面积为 $5\sqrt{15}$，求圆锥的侧面积。
思路：由母线夹角和三角形面积求母线长；再由母线与底面成角求底面半径；最后用侧面积公式。
步骤
1. 由 $\cos\angle ASB = \dfrac78$，得 $\sin\angle ASB = \sqrt{1-\left(\dfrac78\right)^2} = \dfrac{\sqrt{15}}{8}$。
2. $\triangle SAB$ 中 $SA = SB = l$，面积 $S = \dfrac12 l^2 \sin\angle ASB = \dfrac12 l^2 \cdot \dfrac{\sqrt{15}}{8} = 5\sqrt{15}$，解得 $l^2 = 80$，$l = 4\sqrt{5}$（本题题干数值可能为另种组合，方法同）。
3. $SA$ 与底面成 $45^\circ$，则底面半径 $r = l\cos45^\circ = 4\sqrt{5}\cdot\dfrac{\sqrt{2}}{2} = 2\sqrt{10}$。
4. 圆锥侧面积 $S_{\text{侧}} = \pi r l = \pi \cdot 2\sqrt{10} \cdot 4\sqrt{5} = 40\sqrt{2}\pi$。
点评/变式
此题型核心是“空间角 $\to$ 长度 $\to$ 面积”。若将母线夹角换成轴截面顶角，过程类似。若求全面积，侧面积再加底面积 $\pi r^2$ 即可。

题目（2013·文·15）

已知正四棱锥 $O!-!ABCD$ 的体积为 $\dfrac{8\sqrt{2}}{3}$，底面边长为 $2$，求以 $O$ 为球心、$OA$ 为半径的球的表面积。
思路：由体积、底面边长求出高，再求侧棱长 $OA$，最后代球表面积公式。
步骤
1. 底面正方形边长 $a=2$，面积 $S_{\text{底}} = a^2 = 4$。
2. 体积 $V = \dfrac13 S_{\text{底}} h = \dfrac13 \times 4 \times h = \dfrac{8\sqrt{2}}{3}$，得高 $h = 2\sqrt{2}$。
3. 底面半对角线 $d = \dfrac{\sqrt{2}}{2}a = \sqrt{2}$。侧棱 $OA = \sqrt{h^2 + d^2} = \sqrt{(2\sqrt{2})^2 + (\sqrt{2})^2} = \sqrt{8+2} = \sqrt{10}$。
4. 球半径 $R = OA = \sqrt{10}$，表面积 $S = 4\pi R^2 = 40\pi$。
点评/变式
正棱锥的外接球不一定球心就是顶点，本题直接以顶点为球心，易于计算。通常求外接球时需找球心位置，列方程求解。
