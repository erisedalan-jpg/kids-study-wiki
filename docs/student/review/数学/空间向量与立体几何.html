空间向量与立体几何

知识精要

  • 异面直线所成角
    已知两条异面直线 $l_1,l_2$，经过空间任一点 $O$ 分别作 $l_1'\parallel l_1$，$l_2'\parallel l_2$，则 $l_1'$ 与 $l_2'$ 所成的锐角（或直角）称为异面直线 $l_1$ 与 $l_2$ 所成的角，其范围是 $(0,\frac{\pi}{2}]$。
  • 向量法求异面直线所成角
    若异面直线 $l_1,l_2$ 的方向向量分别为 $\vec{a},\vec{b}$，则
    $$\cos\theta = |\cos\langle\vec{a},\vec{b}\rangle| = \frac{|\vec{a}\cdot\vec{b}|}{|\vec{a}||\vec{b}|}.$$ $\theta$ 为 $l_1,l_2$ 所成的角。
    适用条件：可建立空间直角坐标系，或已知向量的坐标（模与夹角）。
  • 几何法（平移法）
    利用中位线、平行四边形等将其中一条直线平移到与另一条相交，构造三角形，再用余弦定理求解。
  • 空间向量的坐标运算
    若 $\vec{a}=(x_1,y_1,z_1)$，$\vec{b}=(x_2,y_2,z_2)$，则
    $\vec{a}\cdot\vec{b}=x_1x_2+y_1y_2+z_1z_2$，$|\vec{a}|=\sqrt{x_1^2+y_1^2+z_1^2}$。

解题方法与套路

  1. 建系与坐标化
    找出三线两两垂直的公共点作为原点，建立空间直角坐标系。当题设出现“直棱柱”“直角”“侧棱垂直底面”等时，优先将直角顶点置为原点。
  2. 确定关键点坐标
    设出线段长度（常赋便于计算的值，如 $BC=CA=CC_1=2$），写出所有相关点的坐标。
  3. 求方向向量
    用终点减起点得到两异面直线的方向向量。
  4. 代入公式
    利用 $\cos\theta = \frac{|\vec{a}\cdot\vec{b}|}{|\vec{a}||\vec{b}|}$ 计算，结果即为所求角的余弦值。
  5. 若用平移法：选取适当的点作平行线，形成三角形，用余弦定理 $\cos\angle A = \frac{b^2+c^2-a^2}{2bc}$ 求夹角。
  6. 检验
    检查是否加了绝对值，结果是否为正值且不超过 $1$。

高频易错

  • 忘加绝对值：向量夹角可能为钝角，异面直线所成角只能是锐角或直角，因此余弦值必须取绝对值。
  • 建系错误：没有严格证明三线两两垂直就直接建系，或在斜棱柱中强行建立直角坐标系。
  • 坐标抄错：中点坐标求错（$\frac{x_1+x_2}{2}$ 搞混分量），或方向向量减错顺序。
  • 模长计算遗漏分量：算模时漏掉其中一个坐标的平方。
  • 平移后角找错：几何法中，平移后对应的角不是异面直线所成角，而误认为其补角。
  • 混淆线线角与线面角公式：线线角用余弦，线面角用正弦，两者公式不同。

代表题精讲

题目
直三棱柱 $ABC-A_1B_1C_1$ 中，$\angle BCA=90^\circ$，$M,N$ 分别是 $A_1B_1,A_1C_1$ 的中点，$BC=CA=CC_1$，求 $BM$ 与 $AN$ 所成角的余弦值。

思路
可以建立空间直角坐标系，也可平移转化。向量法更直接：以 $C$ 为原点，$CA,CB,CC_1$ 所在直线分别为 $x,y,z$ 轴建系。设 $BC=CA=CC_1=2$，写出各点坐标，得到方向向量 $\overrightarrow{BM}$ 和 $\overrightarrow{AN}$，套用夹角公式。平移法则取 $BC$ 中点 $O$，连接 $ON$，证明 $BM\parallel NO$，在 $\triangle ANO$ 中用余弦定理。

步骤
（解法一：向量法）
如图，以 $C$ 为原点，$CA$ 为 $x$ 轴，$CB$ 为 $y$ 轴，$CC_1$ 为 $z$ 轴建立空间直角坐标系。设 $BC=CA=CC_1=2$，
则 $A(2,0,0)$，$B(0,2,0)$，$C_1(0,0,2)$，$A_1(2,0,2)$，$B_1(0,2,2)$。
$M$ 是 $A_1B_1$ 中点 $\Rightarrow M\left(\frac{2+0}{2},\frac{0+2}{2},\frac{2+2}{2}\right) = (1,1,2)$。
$N$ 是 $A_1C_1$ 中点 $\Rightarrow N\left(\frac{2+0}{2},\frac{0+0}{2},\frac{2+2}{2}\right) = (1,0,2)$。
方向向量 $\overrightarrow{BM} = M-B = (1,-1,2)$，$\overrightarrow{AN} = N-A = (-1,0,2)$。
$$\cos\theta = \frac{|\overrightarrow{BM}\cdot\overrightarrow{AN}|}{|\overrightarrow{BM}||\overrightarrow{AN}|} = \frac{|1\times(-1)+(-1)\times0+2\times2|}{\sqrt{1^2+(-1)^2+2^2}\,\sqrt{(-1)^2+0^2+2^2}} = \frac{3}{\sqrt{6}\cdot\sqrt{5}} = \frac{3}{\sqrt{30}} = \frac{\sqrt{30}}{10}.$$
因此 $BM$ 与 $AN$ 所成角的余弦值为 $\frac{\sqrt{30}}{10}$。

（解法二：平移法）
取 $BC$ 中点 $O$，连接 $ON$、$AO$。由题可得 $MN\parallel B_1C_1\parallel BC$ 且 $MN=\frac12 B_1C_1$，$OB= \frac12 BC$，故 $MN\parallel OB$ 且 $MN=OB$，四边形 $MNOB$ 为平行四边形，$BM\parallel NO$。于是 $BM$ 与 $AN$ 所成角即为 $\angle ANO$。
设 $BC=CA=CC_1=2$，求得 $AN = \sqrt{5}$，$NO = BM = \sqrt{6}$，$AO = \sqrt{5}$。
在 $\triangle ANO$ 中，$\cos\angle ANO = \frac{AN^2+NO^2-AO^2}{2\cdot AN\cdot NO} = \frac{5+6-5}{2\cdot \sqrt{5}\cdot\sqrt{6}} = \frac{6}{2\sqrt{30}} = \frac{\sqrt{30}}{10}$。

点评/变式
- 两种方法皆为通法，向量法思维量小、计算固定，适合坐标系易建的情形；平移法在不易坐标化的难题中更显巧思。
- 变式：若将条件“$M,N$ 是中点”改为“$M,N$ 满足 $A_1M = \frac13 A_1B_1$，$A_1N = \frac13 A_1C_1$”，向量法只需调整坐标，几何法平移构造将更复杂，体现向量法的优越性。
