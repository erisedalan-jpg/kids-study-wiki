知识精要

等差数列是高考核心考点，以下要点需精准掌握。

  • 定义：$a_{n+1} - a_n = d$（$d$ 为常数，$n \in \mathbb{N}^*$）。
  • 通项公式：$a_n = a_1 + (n-1)d$。
  • 可推广为 $a_n = a_m + (n-m)d$。
  • 前 $n$ 项和公式： $$S_n = \frac{n(a_1+a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$$ $S_n$ 在公差 $d \ne 0$ 时是关于 $n$ 的二次函数（常数项为 $0$）。
  • 核心性质：
  • 等差中项：$2a_n = a_{n-1} + a_{n+1}$（$n \ge 2$）。更一般地，若 $m+n = p+q$，则 $a_m + a_n = a_p + a_q$。
  • 奇偶项和性质：$S_{2n-1} = (2n-1)a_n$（用中间项表示）；在含 $2n$ 项的等差数列中，$S_{\text{偶}} - S_{\text{奇}} = nd$，$\dfrac{S_{\text{偶}}}{S_{\text{奇}}} = \dfrac{a_{n+1}}{a_n}$。
  • 片段和性质：$S_n, S_{2n}-S_n, S_{3n}-S_{2n}$ 仍成等差数列（公差为 $n^2 d$）。
  • 判定与条件：
  • 定义法；等差中项法；通项为一次型 $a_n = pn+q$；前 $n$ 项和为无常数项的二次型 $S_n = An^2 + Bn$。
  • 与其它知识的综合：结合等比中项、取整函数、对数运算、利用导数求最值等。

解题方法与套路

从历年真题可提炼出以下通法：

  1. 基本量法：设出首项 $a_1$ 和公差 $d$，利用条件列方程组求解。适合给出若干项或和的具体关系时使用。
  2. 性质巧用简化法：当条件涉及下标和相等或奇数项和时，优先利用 $a_m + a_n = a_p + a_q$ 或 $S_{2n-1} = (2n-1)a_n$ 直接得到中间项，避免解方程组。
  3. 化成函数处理最值：求 $S_n$ 或 $nS_n$ 的最值，写出 $S_n$ 关于 $n$ 的二次函数（或 $nS_n$ 为三次型），利用二次函数单调性、对称轴（考虑 $n$ 为正整数取附近值）或求导解决。
  4. 裂项相消求和：若 $S_n$ 为等差数列的前 $n$ 项和，求 $\sum \frac{1}{S_k}$ 时，将 $\frac{1}{S_n}$ 裂成两项差（如 $\frac{2}{n(n+1)} = 2(\frac{1}{n} - \frac{1}{n+1})$）即可抵消。
  5. 新定义分段处理法：遇到 $b_n = [a_n]$（取整函数）或 $b_n = [\lg a_n]$ 等，先求出通项 $a_n$，再按照取整规则分段确定 $b_n$ 的取值，然后分段求和（常需找规律）。
  6. 等比中项转化法：等差数列中某些项成等比数列，利用 $(a_{k+m})^2 = a_k \cdot a_{k+2m}$ 建立方程，结合公差求解。

高频易错

  1. 混淆公式与下标：$a_n$ 和 $S_n$ 公式中公差系数记错（如 $S_n = na_1 + \frac{n(n+1)}{2}d$ 错写为 $\frac{n(n-1)}{2}d$）；误用 $S_{2n-1} = (2n-1)a_{n}$ 时，中间项 $a_n$ 下标算错。
  2. 忽略 $n$ 的正整数约束：用二次函数求 $S_n$ 最值，对称轴为小数时未比较相邻整数对应的函数值，直接取整导致错误（如 2013 年理 16）。
  3. 裂项时系数漏乘：裂 $\frac{1}{S_n}$ 时，若 $S_n = \frac{n(n+k)}{2}$ 型，提取系数容易出错，需用待定系数法验证。
  4. 新定义取整边界不清：由 $a_n$ 到 $[a_n]$ 或 $[\lg a_n]$ 分段时，未严格按 $[x]$ 定义确定每段的起止项数，导致漏项或重复。
  5. 等比中项符号忽略：在等差数列中利用 $a_4^2 = a_2 \cdot a_8$ 建立方程时，解出 $a_4$ 后未注意公差符号是否唯一，但在给定条件明确时可确定。

代表题精讲

题目（2017·理·15）

等差数列 ${a_n}$ 前 $n$ 项和为 $S_n$，$a_3=3$，$S_4=10$，求 $\displaystyle \sum_{k=1}^{n} \frac{1}{S_k}$。

思路：先由基本量求出 $a_1$ 和 $d$，写出 $S_n$ 表达式，再将 $\frac{1}{S_n}$ 裂项求和。

步骤： 设公差为 $d$，由 $a_3 = a_1 + 2d = 3$，$S_4 = 4a_1 + 6d = 10$，解得 $a_1 = 1$，$d = 1$。 $\Rightarrow a_n = n$，$S_n = \frac{n(n+1)}{2}$。 因此 $\frac{1}{S_k} = \frac{2}{k(k+1)} = 2\left(\frac{1}{k} - \frac{1}{k+1}\right)$。 求和： $$ \sum_{k=1}^{n} \frac{1}{S_k} = 2\left[ \left(1-\frac{1}{2}\right) + \left(\frac{1}{2}-\frac{1}{3}\right) + \cdots + \left(\frac{1}{n}-\frac{1}{n+1}\right) \right] = 2\left(1-\frac{1}{n+1}\right) = \frac{2n}{n+1}. $$

点评/变式：裂项是处理等差数列倒数和的典型手段。若 $S_n$ 为 $n(n+2)$ 型，则 $\frac{1}{S_n} = \frac{1}{2}\left(\frac{1}{n} - \frac{1}{n+2}\right)$，系数与间隔需注意。
