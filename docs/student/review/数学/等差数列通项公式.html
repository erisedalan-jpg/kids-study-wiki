等差数列通项公式

考点等差数列通项公式权重7真题数6学科数学父主题数列

考点定位

  • 父主题：数列
  • 权重 weight：7
  • 真题数：6；年份跨度：2009–2024
  • 出现题位：填空12 填空14 解答17
  • 难度分布：易4 中2

知识精要

  • 定义：从第二项起，每一项与前一项的差等于同一个常数 $d$，即 $a_{n+1}-a_n=d$（常数）。
  • 通项公式：$a_n = a_1 + (n-1)d$；推广形式：$a_n = a_m + (n-m)d$。
  • 等差中项：若 $a,A,b$ 成等差数列，则 $A=\dfrac{a+b}{2}$，即 $2A=a+b$。
  • 前 $n$ 项和公式： $$S_n = \frac{n(a_1+a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$$ 其中已知 $a_n$ 时优先用第一个，已知 $d$ 时优先用第二个。
  • 重要性质：若 ${a_n}$ 为等差数列，且 $m+n = p+q$（均为正整数），则 $$a_m + a_n = a_p + a_q$$ 特别地，$a_1+a_n = a_2+a_{n-1} = \cdots$。
  • 公差与单调性：$d>0 \Rightarrow$ 递增；$d<0 \Rightarrow$ 递减；$d=0 \Rightarrow$ 常数列。涉及 $S_n$ 最值时，常借助二次函数或 $a_n$ 的正负转折项求解。

以上基础源自考纲要求，真题中通项公式常与求和结合，本质是“基本量 $a_1, d$”的方程思想。

解题方法与套路

  1. 基本量法（首选）
    将所有条件通过通项公式 $a_n = a_1 + (n-1)d$ 和前 $n$ 项和公式统一转化为关于 $a_1$ 与 $d$ 的方程（组），解出 $a_1,d$，再代入所求。
  2. 若给出若干项的和，如 $a_3+a_4=7,a_2+a_5=5$，直接写：
    $$(a_1+2d)+(a_1+3d)=7,\quad (a_1+d)+(a_1+4d)=5$$

  3. 若给出 $S_n$，例如 $S_3=-15$，用 $S_3 = 3a_1 + 3d$ 列方程。

  4. 利用性质简化（检验用）
    当条件中有“两两和”且下标满足 $m+n=p+q$ 时，可直接使用 $a_m+a_n = a_p+a_q$ 验证或快速求解。但注意：若题目所给数值与性质矛盾（如错题数据），必须回到基本量法，不可硬套性质。

  5. 求通项后解决衍生问题

  6. 求 $S_n$ 的最值：
    方法一：将 $S_n$ 写成 $n$ 的二次函数 $S_n = An^2 + Bn$，结合 $n \in \mathbb{N}^*$ 和对称轴求最值。
    方法二：解 $a_n \ge 0$（或 $\le 0$）找到正负转折项。

  7. 构造新数列（如取整函数）：先求出 ${a_n}$ 通项，逐项计算新数列的前几项，再求和。

  8. 含参数的等比条件
    若等差数列 ${a_n}$ 的某三项成等比，则用等比中项列式：$a_{11}^2 = a_1 \cdot a_{13}$，全部转化为 $a_1,d$ 的方程，注意 $d \neq 0$ 等隐含条件。

通用流程：设 $a_1,d$ → 译条件为方程 → 解方程 → 回代目标 → 作答。

高频易错

  • 方程组列式、计算错误：通项公式中的 $n-1$ 易误写为 $n$，如把 $a_5$ 写成 $a_1+5d$；解二元一次方程组时正负号、倍数关系易错。务必用 $a_1+(n-1)d$ 仔细核对每一项。
  • 求和公式混淆：
    $$S_n = na_1 + \frac{n(n-1)}{2}d \quad\text{中}\quad \frac{n(n-1)}{2}d \ \text{不是}\ nd$$ 尤其是计算 $S_{10}=10a_1+\frac{10\times 9}{2}d$，注意系数为 $45$，而非 $55$ 或 $10$。
  • 忽略 $n$ 为正整数：求 $S_n$ 最值时，二次函数的对称轴可能不是整数，需取最接近的整数 $n$ 计算比较。
  • 滥用下标和性质：只有在确定是等差数列时，$m+n=p+q \Rightarrow a_m+a_n=a_p+a_q$ 才成立。若题目故意构造多解（如 $a_3a_7=-16, a_4+a_6=0$），直接用性质可得 $a_4+a_6 = a_3+a_7 = 0$，简化运算，但要注意此时仍需求解方程组，而不是只靠性质得所有项。
  • 遗漏多解情况：由 $a_3a_7=-16, a_3+a_7=0$ 可解得 $a_3=4, a_7=-4$ 或 $a_3=-4, a_7=4$，导致两个不同的等差数列，需全部写出。凡涉及乘积条件时，应考虑正负两种情况。
  • 忽视公差为零：若无特殊说明，等差数列的公差 $d$ 可为零。当条件出现“等比”或明确 $d \neq 0$ 时，方可排除零公差。通项公式中 $d=0$ 为常数列，仍满足等差定义。
