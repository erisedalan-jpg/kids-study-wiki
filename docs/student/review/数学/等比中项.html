等比中项

知识精要

  • 等比中项定义：若三个数 $a,G,b$ 成等比数列，则称 $G$ 为 $a$ 与 $b$ 的等比中项，满足 $G^2 = ab$（$ab>0$）。正负取法与数列实际项的正负一致。
  • 等比数列中的推广：对等比数列 ${a_n}$，若 $m+n=p+q$，则 $a_m a_n = a_p a_q$。特别地，若 $2n=p+q$，则 $a_n^2 = a_p a_q$，即 $a_n$ 是 $a_p$ 与 $a_q$ 的等比中项。
  • 片段和成等比性质：设等比数列 ${a_n}$ 前 $n$ 项和为 $S_n$，公比为 $q$。若 $q \neq -1$ 且 $S_k \neq 0$，则 $S_k,\; S_{2k}-S_k,\; S_{3k}-S_{2k},\;\dots$ 成等比数列，公比为 $q^k$。该性质可直接用于由某几个片段和求其他片段和，避免大量基本量运算。
  • 等差数列中的等比关系：若等差数列 ${a_n}$ 满足 $a_m,a_k,a_n$ 成等比，可直接列出方程 $a_k^2 = a_m a_n$，代入通项 $a_k = a_1+(k-1)d$ 转化为 $a_1$ 与 $d$ 的方程求解。

解题方法与套路

  1. 利用片段和性质解决等比数列前 $n$ 项和问题
  2. 检查题目条件，确认 $q \neq -1$ 且相关片段和非零。
  3. 取合适的 $k$，构造片段和 $S_k, S_{2k}-S_k, S_{3k}-S_{2k}$ 成等比的新数列。
  4. 利用等比中项或等比数列通项公式，先求出缺失的片段和，再组合求出目标 $S_n$。
  5. 必要时也结合 $S_n$ 的基本量公式 $S_n = \dfrac{a_1(1-q^n)}{1-q}$（$q\neq 1$）进行验证或替代计算。
  6. 等差数列中“三项成等比”的核心步骤
  7. 设等差数列首项 $a_1$，公差 $d$（或先用某中间项表示其余两项）。
  8. 由等比中项 $a_k^2 = a_m a_n$ 列方程。
  9. 代入等差数列通项公式，消元化简，求解 $d$ 或 $a_1$。
  10. 回代求通项、特定项或求和公式 $S_n = n a_1 + \dfrac{n(n-1)}{2}d$。
  11. 等差数列的隔项求和问题
  12. 识别下标构成等差数列的子列，例如 $a_1,a_4,a_7,\dots$，其公差为原公差的 $3$ 倍。
  13. 确定新数列首项、公差和项数，直接用等差数列求和公式计算。

高频易错

  • 忽略等比数列求和公式的分段条件：使用 $S_n = \dfrac{a_1(1-q^n)}{1-q}$ 时，必须先排除 $q=1$ 的情况，否则分母为零产生漏解或错误。
  • 片段和性质的适用条件不清：只有在 $q \neq -1$ 且 $S_k \neq 0$ 时，片段和才成等比数列。若 $q=-1$ 时可能出现 $S_k=0$ 使性质失效，需单独讨论或转化方法。
  • 等比中项的正负号选取随意：等比数列各项符号规律性强（同号或正负交替），等比中项 $G=\pm\sqrt{ab}$ 须与数列中该位置的符号一致。切勿只取正值或忘记检验。
  • 方程化简粗心导致增根或丢解：在等差数列成等比的问题中，列出二次方程后可能产生零解（如 $d=0$），需结合题目条件（如“公差不等于零”）舍去或讨论。
  • 片段和的新数列公比错误：片段和 $S_{k}, S_{2k}-S_{k}, S_{3k}-S_{2k}$ 的公比是 $q^k$，而非 $q$，计算目标项时要正确使用指数。

代表题精讲

代表题1（2023·新课标Ⅱ·08）

题目：等比数列 ${a_n}$ 前 $n$ 项和为 $S_n$，$S_4 = -5$，$S_6 = 21 S_2$，求 $S_8$。
思路：利用片段和性质或基本量法。由 $S_4=-5\neq 0$ 且 $S_6=21S_2$ 可知 $q \neq -1$，从而 $S_2, S_4-S_2, S_6-S_4, S_8-S_6$ 成等比数列，先求出 $S_2$，再依次推出其余片段和，最终得到 $S_8$。
步骤：
1. 由片段和性质，$S_2$, $S_4-S_2$, $S_6-S_4$ 成等比。设 $S_2 = x$，则 $S_4-S_2 = -5-x$，$S_6 = 21x$，$S_6-S_4 = 21x +5$。
2. 由等比中项得 $(-5-x)^2 = x(21x+5)$。展开：$x^2+10x+25 = 21x^2+5x \Rightarrow 20x^2 -5x -25 =0 \Rightarrow 4x^2 -x -5 =0$。
3. 解得 $x = -1$ 或 $x = \frac{5}{4}$。结合 $S_4=-5$ 及 $q^2>0$ 可知 $x$ 应为负，取 $x=S_2=-1$。
4. 片段和新数列公比 $q^2 = \frac{S_4-S_2}{S_2} = \frac{-5-(-1)}{-1} = 4$。则 $S_6-S_4 = (S_4-S_2)\cdot 4 = -16$，$S_8 = S_4 + (S_6-S_4) + (S_8-S_6) = -5 + (-16) + (-16)\times 4 = -85$。
点评/变式：利用片段和性质可大幅化简运算。关键在于判断 $q \neq -1$，并正确设出等比数列。若公比为正，还可快速由 $S_{4}$ 与 $q^4$ 直接求 $S_8 = S_4(1+q^4)$，此处 $q^2=4$，得 $S_8 = -5\times(1+16) = -85$，亦殊途同归。
