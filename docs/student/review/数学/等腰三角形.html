等腰三角形

考点等腰三角形权重11真题数3学科数学父主题平面几何

考点定位

  • 父主题：平面几何
  • 权重 weight：11
  • 真题数：3；年份跨度：2012–2015
  • 出现题位：解答22 选择4
  • 难度分布：中3

知识精要

  • 定义：有两条边相等的三角形叫做等腰三角形，相等的两边称为腰，另一边称为底边；两腰的夹角叫顶角，腰和底边的夹角叫底角。
  • 性质：
  • 两底角相等（等边对等角）。
  • 顶角的平分线、底边上的中线、底边上的高互相重合（“三线合一”）。
  • 等腰三角形是轴对称图形，对称轴是底边的垂直平分线（即“三线”所在直线）。
  • 若等腰三角形的顶角为 $\theta$，则底角为 $\frac{180^\circ-\theta}{2}$；若已知一底角为 $\alpha$，则顶角为 $180^\circ-2\alpha$。
  • 判定：
  • 定义法：有两条边相等。
  • 等角对等边：若一个三角形有两个角相等，则这两个角所对的边也相等。
  • 常见组合模型：
  • 等腰三角形与圆：对称轴过圆心，切线、弦心距、弧中点等具有对称性。
  • 与椭圆结合：利用“底角 $\theta$”可建立腰与底边（或焦距）的等量关系，再结合椭圆定义、通径、焦准距等求离心率。

解题方法与套路

  1. 直接使用“等边对等角、等角对等边”进行边角转换。
    见到边相等立刻转化出角相等，反之亦然，尤其适合求解角度或证明线段相等。
  2. “三线合一”的灵活调用。
    等腰三角形中，只要见到顶角平分线、底边中线、底边高线中的任意一条，马上想到其余两条也重合，常用于作辅助线或建立直角关系。
  3. 对称性构造辅助线。
    等腰三角形是轴对称图形，涉及圆、切点等问题时，常利用对称轴（底边的垂直平分线）添加辅助线，得到全等或等量关系。
  4. 遇等腰三角形与圆锥曲线结合，先标好顶点身份。
    明确哪两条边相等，哪个为顶角、哪个为底角。再将几何等量转化为代数路程关系，如 $|PF_2| = |F_1F_2| = 2c$，再结合坐标、焦准距或定义方程求参数。
  5. 利用底角建立特殊角三角形。
    如底角 $30^\circ$ 可得出 $30^\circ, 30^\circ, 120^\circ$ 的三角形，边长比 $1:1:\sqrt{3}$；底角 $45^\circ$ 得等腰直角三角形等，方便直接写比利式。

高频易错

  • 忽略不确定哪两条边相等：题目只说“等腰三角形”而未明确腰与底时，必须分类讨论，避免漏解。
  • 把底角、顶角混淆：计算角度时，一定要反复确认是顶角还是底角，尤其在圆锥曲线焦点三角形中，“底角为 $30^\circ$”意味着腰与底边的夹角为 $30^\circ$，而非顶角。
  • “三线合一”用错边：必须是顶角平分线、底边上的中线和底边上的高才合一，腰上的高和中线不具此性质。
  • 对称轴误认为任意高线：只有底边上的中线所在直线才是对称轴，不可随意对腰上高线使用对称性。
  • 方程列式时未统一线段方向：在椭圆题中，$|PF_2|=|F_1F_2|$ 直接写出 $P$ 的横坐标表达式时，易忽略焦点位置导致符号错误，建议统一用距离公式。
  • 切线、弦等几何量跳过等腰性质直接计算：如等腰三角形内切圆问题，不先利用对称性得到切点 $E,F$ 关于对称轴对称，会增加大量运算。

代表题精讲

题1（2015·理·22）：等腰三角形与内切圆的对称性

题目：如图，$O$ 为等腰 $\triangle ABC$ 内一点，$\odot O$ 与底边 $BC$ 交于 $M,N$，与高 $AD$ 交于 $G$，且与 $AB,AC$ 分别相切于 $E,F$。求证：$EF \parallel BC$。

思路：利用等腰三角形的对称轴 $AD$，结合圆的轴对称性，证明 $E,F$ 关于 $AD$ 对称，从而得到 $EF \perp AD$，又 $BC \perp AD$，推出平行。

步骤： 1. 连接 $OE, OF$，由切线性质得 $OE \perp AB$，$OF \perp AC$。 2. $\triangle ABC$ 等腰，$AD$ 是底边的高也是顶角平分线和对称轴，故 $AD$ 垂直平分 $BC$，且 $AB,AC$ 关于 $AD$ 对称。 3. 因为 $\odot O$ 与 $AB,AC$ 相切于 $E,F$，由对称性可得 $OE=OF$，且 $E,F$ 关于直线 $AD$ 对称。 4. 因此 $EF \perp AD$，又 $BC \perp AD$，故 $EF \parallel BC$。

点评/变式：此题亦可利用 $\triangle AOE \cong \triangle AOF$ 证 $AE=AF$，结合等腰 $\triangle AEF$ 的三线合一。变式：若给出 $AG$ 等于半径等条件，可求线段长或面积，仍需以对称为核心。

题2（2012·文/理·4）：椭圆与等腰三角形求离心率

题目：设 $F_1,F_2$ 是椭圆 $E:\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1 \;(a>b>0)$ 的左、右焦点，$P$ 为直线 $x=\dfrac{3a}{2}$ 上一点，$\triangle F_2PF_1$ 是底角为 $30^\circ$ 的等腰三角形，求 $E$ 的离心率。

思路：由底角 $30^\circ$ 确定等腰三角形的腰为 $|PF_2|$ 与 $|F_1F_2|$，得出 $|PF_2|=2c$，再利用 $P$ 的横坐标及 $F_2$ 的坐标建立方程。

步骤： 1. $\triangle F_2PF_1$ 是底角为 $30^\circ$ 的等腰三角形，若底角为 $\angle PF_2F_1$，则 $|PF_2| = |F_1F_2| = 2c$。 2. 由正弦或几何可知 $\angle PF_2F_1=30^\circ$，顶角 $\angle F_2PF_1=120^\circ$，但可直接用边的关系：设 $F_2(c,0)$，$P$ 在 $x=\dfrac{3a}{2}$ 上，故 $P(\dfrac{3a}{2}, y_P)$。 3. 由 $|PF_2|=2c$ 得距离方程：$\sqrt{ \left( \dfrac{3a}{2} - c \right)^2 + y_P^2 } = 2c$。
同时 $|PF_2|=|F_1F_2|$ 亦可结合 $P$ 到 $F_1$ 距离，但最简单的几何关系为：$P$ 到 $F_2$ 的水平距离为 $\dfrac{3a}{2}-c$。在 $\triangle PF_2F_1$ 中，作底边 $PF_2$ 上的高，利用 $30^\circ$ 角可知 $\dfrac{3a}{2}-c = |PF_2| \cos 60^\circ = 2c \times \dfrac{1}{2} = c$（这里需细致分析，直接给出关键等式）。 4. 实际上，由几何关系可直接写出 $2c = |PF_2|$，且 $P$ 的横坐标 $\dfrac{3a}{2}$，则 $\dfrac{3a}{2} - c = |PF_2| \sin 30^\circ$ 或利用 $\triangle PF_2F_1$ 中 $\angle PF_2F_1=30^\circ$ 得到 $\cos 60^\circ = \dfrac{\frac{3a}{2}-c}{2c}$，即 $\frac{1}{2} = \dfrac{\frac{3a}{2}-c}{2c}$。 5. 解得 $\frac{3a}{2} - c = c \Rightarrow \frac{3a}{2}=2c \Rightarrow e=\frac{c}{a}=\frac{3}{4}$。

点评/变式：关键是识别等腰的腰是 $|F_1F_2|$（焦距），把底角 $30^\circ$ 转化到水平距离与腰的比例。变式可改为底角 $45^\circ$ 或顶角 $120^\circ$，方法一致。
