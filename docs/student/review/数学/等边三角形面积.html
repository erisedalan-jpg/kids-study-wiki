等边三角形面积

考点等边三角形面积权重1真题数2学科数学父主题平面几何

考点定位

  • 父主题：平面几何
  • 权重 weight：1
  • 真题数：2；年份跨度：2020–2020
  • 出现题位：选择10 选择11
  • 难度分布：中2

知识精要

  • 等边三角形面积公式：若边长为 $a$，则面积 $S = \frac{\sqrt{3}}{4}a^2$。该公式可变形为边长 $a = \sqrt{\frac{4S}{\sqrt{3}}} = 2\sqrt{\frac{S}{\sqrt{3}}}$，用于由面积反求边长。
  • 等边三角形的外接圆半径：边长为 $a$ 的等边三角形，其外接圆半径 $r = \frac{\sqrt{3}}{3}a$（即 $r = \frac{a}{\sqrt{3}}$，注意不同于内切圆半径 $\frac{\sqrt{3}}{6}a$）。解题时可通过 $S$ 求 $a$，再求 $r$，实现“面积 $\to$ 边长 $\to$ 外接圆半径”的链条。
  • 球的表面积与半径：球表面积 $S_{\text{球}} = 4\pi R^2$，已知表面积可求得球半径 $R = \sqrt{\frac{S_{\text{球}}}{4\pi}}$。
  • 球截面性质：若球的半径为 $R$，球心到截面圆平面的距离为 $d$，截面圆半径为 $r$，则满足 $R^2 = d^2 + r^2$，即 $d = \sqrt{R^2 - r^2}$。本题中等边三角形所在平面截球得圆，该圆即为三角形的外接圆，因此 $r$ 即为上述外接圆半径。

解题方法与套路

  1. 翻译面积条件：由等边三角形面积 $S$，利用 $S = \frac{\sqrt{3}}{4}a^2$ 解出边长 $a$。
  2. 计算外接圆半径：利用 $r = \frac{\sqrt{3}}{3}a$ 求出截面圆半径（等边三角形的外接圆半径）。
  3. 求球半径：根据球的表面积 $S_{\text{球}} = 4\pi R^2$ 解出 $R$。
  4. 建立勾股关系：球心到平面 $ABC$ 的距离 $d$、球半径 $R$、截面圆半径 $r$ 构成直角三角形，套用 $d = \sqrt{R^2 - r^2}$ 得出距离。
  5. （变式）若已知球半径和球心距，求三角形面积：逆用过程，先由 $r = \sqrt{R^2 - d^2}$ 得外接圆半径，再反求边长与面积。

高频易错

  • 面积公式混淆：误将等边三角形面积记为 $\frac{\sqrt{3}}{2}a^2$ 或 $\frac{1}{2}a^2\sin60^\circ$ 计算时漏掉平方。牢记标准式 $S = \frac{\sqrt{3}}{4}a^2$。
  • 内外接圆半径混淆：等边三角形外接圆半径是 $r = \frac{\sqrt{3}}{3}a$，内切圆半径是 $r_{\text{内}} = \frac{\sqrt{3}}{6}a$。遇截面问题要用外接圆半径，不可错用内切圆半径。
  • 面积数值处理失误：如给出面积 $\frac{9\sqrt{3}}{4}$，解 $a^2 = 9$ 得 $a=3$ 后，外接圆半径应为 $\sqrt{3}$，但常有学生平方计算错误或忘记开方。
  • 球的截面公式记错：错误使用 $d = \sqrt{r^2 - R^2}$ 或 $d = R - r$，必须强化垂直关系的勾股定理 $R^2 = d^2 + r^2$。
  • 忽视单位或选项形式：计算得 $d=1$ 后直接选 A 或 B 中的近似值。应检验最终结果与选项一致。

代表题精讲

代表题1 （2020·全国·文11 / 理10）

题目：已知 $\triangle ABC$ 是面积为 $\frac{9\sqrt{3}}{4}$ 的等边三角形，且其顶点都在球 $O$ 的球面上。若球 $O$ 的表面积为 $16\pi$，则 $O$ 到平面 $ABC$ 的距离为（ ）
A. $\sqrt{3}$　B. $\frac{3}{2}$　C. $1$　D. $\frac{\sqrt{3}}{2}$

思路：利用等边三角形面积求边长，进而求得三角形外接圆半径；由球的表面积求球半径；最后通过球心到截面的距离公式求解。

步骤： 1. 设等边三角形边长为 $a$，由面积公式得 $\frac{\sqrt{3}}{4}a^2 = \frac{9\sqrt{3}}{4}$，解得 $a^2 = 9$，即 $a = 3$。 2. 等边三角形的外接圆半径 $r = \frac{\sqrt{3}}{3}a = \frac{\sqrt{3}}{3} \times 3 = \sqrt{3}$。 3. 设球的半径为 $R$，由球的表面积 $4\pi R^2 = 16\pi$，得 $R^2 = 4$，故 $R = 2$。 4. 球心 $O$ 到平面 $ABC$ 的距离 $d$ 满足 $R^2 = d^2 + r^2$，即 $2^2 = d^2 + (\sqrt{3})^2$，得 $d^2 = 4 - 3 = 1$，所以 $d = 1$。
对应选项 C。

点评/变式：
本题是等边三角形面积与球的截面性质结合的典型送分题，文科、理科同题，体现基础运算能力。变式可改为已知球心到平面的距离和球半径，反求等边三角形的面积；或者将等边三角形换成直角三角形或一般三角形，需先求外接圆半径再用同一截面关系。核心不变：抓住面积与外接圆半径的转化、球的截面直角三角形。
