系数和

考点定位

  • 父主题：计数原理
  • 权重 weight：6
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：填空15
  • 难度分布：中1

知识精要

  • 赋值法求系数和：设多项式展开式为 $f(x)$。
  • 各项系数之和：$f(1)$。
  • 各项系数交错和（奇偶项相减）：$f(-1)$。
  • 奇数项系数之和：$\frac{f(1)-f(-1)}{2}$。
  • 偶数项系数之和：$\frac{f(1)+f(-1)}{2}$。
  • 适用条件：展开式中含有参数或需要求某一类指数（如奇数、偶数、倍数项）的系数之和时，通过给 $x$ 赋特定值（常用 $1,-1$）构造方程。
  • 核心依据：二项式定理的恒等变形，赋值后等式仍成立，从而建立系数与参数之间的联系。

解题方法与套路

  1. 设函数：将含参的展开式整体视为关于 $x$ 的函数 $f(x)$。
  2. 赋特值：
  3. 令 $x=1$，得所有项系数和 $f(1)$。
  4. 令 $x=-1$，得奇偶项系数交错和 $f(-1)$。
  5. 组合计算：根据题目所求的“奇数次幂项系数之和”或“偶数次幂项系数之和”，套用公式：
  6. 奇数次幂项系数和 $S_{\text{奇}} = \frac{f(1)-f(-1)}{2}$。
  7. 偶数次幂项系数和 $S_{\text{偶}} = \frac{f(1)+f(-1)}{2}$。
  8. 解方程：令上述结果等于已知数值，解出待定参数（如 $a$）。
  9. 检验：必要时回代验证，确保赋值过程未遗漏常数项或零次项的影响。

高频易错

  • 混淆奇偶公式：容易将奇数项系数和误记为 $\frac{f(1)+f(-1)}{2}$，务必通过特例（如 $f(x)=a_0+a_1x$）验证记忆。
  • 无中生有的“常数项”处理：当 $x$ 的奇数次幂包含 $x^1$ 时，常数项 $a_0$ 为偶数次幂项（$x^0$）。使用 $\frac{f(1)-f(-1)}{2}$ 时已自动消去常数项，不必单独扣除。
  • 忽略括号前系数：形如 $(a+x)(1+x)^n$ 的乘积，赋值时 $a$ 也会参与运算，不可只对二项式部分赋值。
  • $f(-1)$ 符号错误：当 $f(x)$ 中含 $(1+x)^4$ 时，代入 $x=-1$ 得 $0^4=0$，容易当成 $2^4$ 计算。
  • 公式适用范围：上述奇偶项公式仅适用于按 $x$ 的升幂或降幂排列的标准多项式。若展开式含有负指数或分式，需先化为标准形式再赋值。

代表题精讲

题目：（a+x）（1+x）⁴ 的展开式中 x 的奇数次幂项的系数之和为 32，求 a。

思路：展开式复杂，不直接展开，利用赋值法整体求解。令 $f(x)=(a+x)(1+x)^4$，利用 $f(1)$ 与 $f(-1)$ 组合出奇数次幂项系数和，建立关于 $a$ 的方程。

步骤： 1. 设 $f(x) = (a+x)(1+x)^4$。 2. 求 $f(1) = (a+1)(1+1)^4 = (a+1) \cdot 16$。 3. 求 $f(-1) = (a-1)(1-1)^4 = (a-1) \cdot 0 = 0$。 4. 根据公式，奇数次幂项系数之和为 $\frac{f(1) - f(-1)}{2} = \frac{16(a+1) - 0}{2} = 8(a+1)$。 5. 由题意知 $8(a+1) = 32$，解得 $a = 3$。

点评/变式：此题核心在于识别“系数和”与赋值法的对应关系。变式可能要求偶数次幂项系数和，或改为求所有二项式系数的和。注意 $f(-1)$ 的计算因 $(1-1)^4=0$ 而高度简化，若展开式改为 $(2+x)^4$ 或 $(a-x)(1+x)^4$，$f(-1)$ 不再为 0，需重新计算，但整体框架不变。
