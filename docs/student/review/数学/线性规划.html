知识精要

线性规划是研究目标函数在约束条件下的最值问题的数学方法，核心是数形结合。其基本要素包括： - 约束条件：关于变量 $x,y$ 的一次不等式组（或等式），构成可行域（平面区域）。 - 目标函数：形如 $z=ax+by$（$a,b$ 为常数）的线性函数，求其最大值或最小值。 - 可行域与最优解：可行域是约束条件对应的平面点集；使目标函数取得最值的可行解即为最优解（通常位于可行域的顶点）。 - 几何意义：将目标函数变形为 $y=-\frac{a}{b}x+\frac{z}{b}$（$b \neq 0$），则 $z$ 的几何意义与直线在 $y$ 轴上的截距密切相关：当 $b>0$ 时，$z$ 最大对应截距最大；当 $b<0$ 时，$z$ 最大对应截距最小。 - 含参问题：当目标函数或约束条件含参数时，需根据最优解的唯一性或临界情况，结合图形确定参数值。

解题方法与套路

线性规划问题的通用解题步骤可归纳为“画”、“移”、“求”、“代”四步： 1. 画可行域：将约束条件中的不等式转化为等式，画出每条直线；通过“直线定界、特殊点定域”的方法（如代入 $(0,0)$ 检验）确定各不等式表示的区域，最终标出可行域（常为凸多边形）。 2. 目标函数直线化：将目标函数 $z=ax+by$ 改写为斜截式 $y=-\frac{a}{b}x+\frac{z}{b}$，明确该直线的截距随 $z$ 的变化关系，即确定平移方向。 3. 平移找极值点：在可行域内，沿目标函数直线的法线方向平移该直线，直至可行域边界的最远点。若 $b>0$，平移至截距最大处 $z$ 最大；若 $b<0$，平移至截距最小处 $z$ 最大。最优解通常在可行域的顶点（角点）处取得。 4. 求交点、代值计算：若最优解在两条边界直线的交点处，联立这两条直线的方程，解方程组求得该点坐标，并代入目标函数计算出最值。若可行域包含多条边界，亦可先求出所有顶点坐标，分别代入目标函数比较大小，以确定最值。

高频易错

  • 方向判断失误：变形目标函数时，混淆 $z$ 与截距的正负关系。例如，对于 $z=2x-y$，化为 $y=2x-z$，$z$ 最大等价于 $-z$ 最小，即直线截距最小，这是最常见的失分点。
  • 区域定错：在画可行域时，将不等式 $>$ 或 $\ge$ 的区域方向弄反。务必使用“选取原点或其他易算点代入”的方法进行校验。
  • 临界点识别错误：平移直线时，未能准确找到使截距达到极值的最远边界点，尤其是当可行域开放或边界斜率与目标函数斜率相同时（此时可能有无穷多最优解或需考察线段端点）。
  • 计算疏忽：解边界直线交点方程组时计算错误，或因图形绘制不精确导致对交点坐标的误判。建议求得交点后，将该点坐标代入所有约束条件进行快速验证。
  • 审题遗漏：忽略题设中变量为整数（整点问题）的特殊要求，直接使用顶点坐标，导致所求最优解并非真正可行的整数点。本题集内虽未出现，但为常见陷阱。

代表题精讲

代表题一：2022-文-05

  • 题目：若 $x,y$ 满足 $\begin{cases} x+2y \ge 2, \ x+2y \le 4, \ y \ge 0, \end{cases}$，求 $z=2x-y$ 的最大值。
  • 思路：本题为常规线性规划。首先画出三条直线围成的可行域，然后将目标函数变形，明确 $z$ 最大对应截距最小，通过平移找到最优顶点，最后求解坐标并代入。
  • 步骤：
    1. 画可行域：画出三条直线 $x+2y=2$，$x+2y=4$，$y=0$。可行域为两平行直线间的带状区域在 $x$ 轴上方的部分，是一个平行四边形。
    2. 变形目标函数：$z=2x-y \implies y=2x-z$。可见，$-z$ 表示该直线在 $y$ 轴上的截距。求 $z$ 的最大值，等价于求截距 $-z$ 的最小值，即直线 $y=2x-z$ 需向下平移至可行域最远的边界点。
    3. 平移找点：保持斜率 $2$，向下平移直线 $y=2x$，在可行域内经过的最远点是平行四边形的右下顶点。该点是直线 $x+2y=4$ 与 $y=0$ 的交点。
    4. 求交点、代值：联立方程组 $\begin{cases} x+2y=4 \ y=0 \end{cases}$，解得交点坐标为 $(4,0)$。代入目标函数得 $z_{\max}=2\times4-0=8$。
  • 点评/变式：本题的关键在于理解目标函数斜率为正，而待求截距系数为负时的几何转换。若目标函数改为 $z=2x+y$，则 $z$ 最大等价于截距 $z$ 最大，最优解将变为直线 $x+2y=4$ 与 $y$ 轴的交点 $(0,2)$，此时 $z_{\max}=2$。考生需熟练掌握“截距异号”时的画图平移方向判断。

代表题二：2021-文-05

  • 题目：若 $x,y$ 满足 $\begin{cases} y \le 2, \ x+3y \ge 4, \ 3x-y \le 4, \end{cases}$，求 $z=3x+y$ 的最小值。
  • 思路：这是一道求最小值的题。目标函数变形后，$z$ 的值与截距正相关，因此平移直线找最小截距即可。从图形上看，可行域为一个三角形，最优解在三角形的顶点取得。
  • 步骤：
    1. 画可行域：画出三条直线 $y=2$，$x+3y=4$，$3x-y=4$。确定区域可得一个三角形区域。
    2. 变形目标函数：$z=3x+y \implies y=-3x+z$。$z$ 即为直线在 $y$ 轴上的截距。求 $z$ 的最小值，即求截距的最小值，需将直线 $y=-3x$ 向下平移至可行域最边缘。
    3. 平移找点：向下平移直线 $y=-3x$，在可行域内最后接触的点是直线 $x+3y=4$ 与 $3x-y=4$ 的交点。
    4. 求交点、代值：联立方程组 $\begin{cases} x+3y=4 \ 3x-y=4 \end{cases}$，解得交点坐标为 $(1,3)$。代入目标函数得 $z_{\min}=3\times1+3=6$。
  • 点评/变式：本题展示了在可行域形状简单时，直接寻找所有顶点并代入计算是简洁且不易出错的方法。该三角形的另外两个顶点分别是 $(0.8, 2)$ 和 $(2,2)$，代入 $z=3x+y$ 计算比较，亦可快速锁定最小值在点 $(1,3)$ 处取得。对于含参数的最值问题，通常会给出最值反求参数，其本质仍是先写出含参的顶点坐标，再通过最值建立方程求解。
