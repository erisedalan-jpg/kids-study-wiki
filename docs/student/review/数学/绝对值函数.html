绝对值函数

知识精要

  • 绝对值定义：$|x|=\begin{cases} x, & x\geq 0 \ -x, & x<0 \end{cases}$，本质是数轴上点到原点的距离。
  • 去绝对值基本方法：零点分段讨论、平方法（需保证非负）、图象翻折。
  • 绝对值函数图象变换：
    • $y=f(x)\to y=|f(x)|$：将$x$轴下方部分沿$x$轴翻折到上方；
    • $y=f(x)\to y=f(|x|)$：保留$y$轴右侧图象，去掉左侧，再将右侧对称到左侧。
  • 含绝对值的和差函数：形如$f(x)=|x-a|\pm|x-b|$，零点分段画出分段一次函数图象，其最小值（或最大值）出现在零点之间。
  • 绝对值不等式：
    • $|x|0)\iff -a<xa\iff x<-a\text{ 或 }x>a$；
    • $||a|-|b||\leq |a\pm b|\leq |a|+|b|$（三角不等式），用于求最值或放缩；
    • 含多个绝对值的不等式常采用零点分段法化为不等式组求解。
  • 对称性与奇偶性：
    • 偶函数满足$f(x)=f(|x|)$，可将$x<0$的部分转化为正数处理（如2010理08）；
    • 若$f(x)=f(2a-x)$，则$f(x)$图象关于直线$x=a$对称；
    • 若两个函数图象均关于同一直线$x=a$对称，则其交点也关于该直线对称，横坐标之和可批量计算（如2016文12）。

解题方法与套路

  1. 零点分段法：针对$f(x)=|x-a|+|x-b|$或$g(x)=\sum k_i|x-a_i|$型函数，找出各绝对值的零点，将数轴分段，每段内去绝对值化为一次（或多项式）函数，可解不等式、求最值或画图象。
  2. 几何意义转化：$|x-a|$表示数轴上$x$到$a$的距离。求$|x-a|+|x-b|$的最小值即找$x$到$a,b$距离和的最小点，常为闭区间$[a,b]$内任意点（若系数不等则需加权）。用于快速判断参数范围。
  3. 图象变换法：由基本初等函数图象经过平移、翻折得到绝对值函数图象。如$y=|x^2-2x-3|$由抛物线保留$x$轴上方的部分，下方翻折得到，其对称轴仍为$x=1$。
  4. 性质转化：遇到$f(|x|)$或需处理偶函数时，利用$f(x)=f(|x|)$将变量限制在$[0,+\infty)$，转化为正数绝对值求解，简化不等式。
  5. 对称性求和：若两个函数图象的交点具有公共对称轴，则所有交点的横坐标之和为$m\times x_{\text{对称轴}}$（$m$为交点个数），省去逐个求解。

高频易错

  • 分段讨论不等价：零点分段解不等式时，每一段所得解必须与该段前提范围求交集，最后取并集，易漏掉交集导致解集扩大。
  • 图象翻折忽视定义域：$y=f(|x|)$的变换中，需去掉原$x<0$的部分，再将右侧对称过去，若原函数在$x<0$处有定义，直接去绝对值而不删图会导致错误。
  • 平方法随意使用：不等式两边平方必须先保证非负，如$|x-2|>x$，平方会继承原不等号，但$x$的符号不确定，直接平方可能引入增解，应分类处理。
  • 最值点误判：对于$|x-a|+|x-b|$，当$x$在$a,b$之间时取得最小值$|a-b|$，但在系数不同（如$2|x-a|+|x-b|$）时，最小值点可能改变，不能直接套用中点。
  • 对称性忽视交点个数：利用对称性求和时，必须确认所有交点成对出现关于对称轴对称，若对称轴上单独有一个交点，则其横坐标恰好为对称轴，求和时需单独加上。
  • 偶函数$f(x)=f(|x|)$的前提：该式对定义域为全体实数的偶函数才恒成立，若定义域不对称，不可随意使用。

代表题精讲

题目（2016文12）

已知$f(x)=f(2-x)$，函数$y=|x^2-2x-3|$与$y=f(x)$图象的交点为$(x_1,y_1),(x_2,y_2),\dots,(x_m,y_m)$，则$\sum_{i=1}^m x_i=$（ ） A. 0 B. m C. 2m D. 4m

思路：由$f(x)=f(2-x)$得$f(x)$关于直线$x=1$对称；再证明$y=|x^2-2x-3|$也关于$x=1$对称，从而所有交点成对地关于$x=1$对称，横坐标之和可由对称性求出。

步骤： 1. 由$f(x)=f(2-x)$可令$t=1-x$，则$f(1+t)=f(1-t)$，故$f(x)$图象关于直线$x=1$对称。 2. 对$y=|x^2-2x-3|$，内部二次函数$y=x^2-2x-3$的对称轴为$x=1$。取绝对值是将$x$轴下方翻折，不改变对称轴，因此$y=|x^2-2x-3|$的图象也关于直线$x=1$对称。 3. 两条曲线均关于$x=1$对称，则它们的交点要么在对称轴上（$x=1$），要么成对地对称分布在两侧，且每对交点的横坐标之和为$2\times1=2$。 4. 设交点总数为$m$。若对称轴上无交点，$m$为偶数，所有交点的横坐标之和为$\frac{m}{2}\times2=m$。若对称轴上有一个交点（横坐标为1），剩余$m-1$个成偶数对，横坐标之和为$1+\frac{m-1}{2}\times2=m$。因此对任意正整数$m$，$\sum_{i=1}^m x_i = m$。 5. 选B。

点评/变式：抓住两函数的公共对称轴是解题关键。变式：将$y=|x^2-2x-3|$换成$y=|\ln|x-1||$等仍关于$x=1$对称的曲线，方法相同。注意验证对称轴上是否有交点，若题目明确过对称轴的某点，需单独考虑。

题目（2012文24）

已知函数$f(x)=|x+a|+|x-2|$。 （Ⅰ）当$a=-3$时，求不等式$f(x)\geq 3$的解集； （Ⅱ）若$f(x)\leq |x-4|$的解集包含$[1,2]$，求$a$的取值范围。

思路：（Ⅰ）代入$a$后利用零点分段法化为不等式组求解；（Ⅱ）利用解集包含区间，意味着在$[1,2]$上不等式恒成立，可转化成在该区间上去绝对值，转化为含参数的不等式，利用最值求参数范围。

步骤： （Ⅰ）$a=-3$时，$f(x)=|x-3|+|x-2|$。零点为$2,3$。 - 当$x<2$时，$f(x)=3-x+2-x=5-2x\geq3\Rightarrow x\leq1$，结合$x<2$得$x\leq1$。 - 当$2\leq x\leq3$时，$f(x)=3-x+x-2=1\geq3$，无解。 - 当$x>3$时，$f(x)=x-3+x-2=2x-5\geq3\Rightarrow x\geq4$，结合$x>3$得$x\geq4$。 综上，解集为${x|x\leq1\text{ 或 }x\geq4}$。 （Ⅱ）$f(x)\leq |x-4|$解集包含$[1,2]$，即当$x\in[1,2]$时，$|x+a|+|x-2|\leq |x-4|$恒成立。 在$[1,2]$上，$x-2\leq0$，$x-4<0$，故$|x-2|=2-x$，$|x-4|=4-x$，不等式化为$|x+a|+2-x\leq4-x$，即$|x+a|\leq2$。 在$x\in[1,2]$上，$|x+a|\leq2$恒成立等价于$-2\leq x+a\leq2$，即$-x-2\leq a\leq -x+2$在该区间恒成立。需$a$大于等于左边最大值，小于等于右边最小值。 设$g(x)=-x-2$，在$[1,2]$上递减，最大值为$g(1)=-3$；$h(x)=-x+2$，递减，最小值为$h(2)=0$。 故$-3\leq a\leq0$。

点评/变式：第（Ⅱ）问典型地利用子集条件转化为恒成立问题，然后通过去绝对值得出参数范围。注意去绝对值时要根据给定区间的$x$范围判断内部符号，切忌盲目讨论。变式可将条件改为“存在$x\in[1,2]$使得不等式成立”，则转化为存在性问题，需用最大值或最小值不同侧。

题目（2018文23）

设函数$f(x)=5-|x+a|-|x-2|$。 （Ⅰ）当$a=1$时，求不等式$f(x)\geq0$的解集； （Ⅱ）若$f(x)\leq1$恒成立，求$a$的取值范围。

思路：（Ⅰ）代入$a$，移项得$|x+1|+|x-2|\leq5$，用零点分段或几何意义解；（Ⅱ）$f(x)\leq1$恒成立等价于$|x+a|+|x-2|\geq4$恒成立，左侧下界由绝对值和的几何意义或绝对值不等式求得，建立关于$a$的不等式。

步骤： （Ⅰ）$a=1$时，$f(x)\geq0\iff 5-|x+1|-|x-2|\geq0\iff |x+1|+|x-2|\leq5$。 几何意义：数轴上的点$x$到$-1$与$2$的距离之和不超过$5$。$-1$与$2$的距离为$3$，因此$x$向左最多可延伸$\frac{5-3}{2}=1$到$-1-1=-2$，向右对称可到$2+1=3$。故解集为$[-2,3]$。 或零点分段：$x<-1$时，$-(x+1)-(x-2)\leq5\implies x\geq-2$，得$-2\leq x<-1$；$-1\leq x<2$时，$x+1-(x-2)=3\leq5$恒成立；$x\geq2$时，$x+1+x-2\leq5\implies x\leq3$，得$2\leq x\leq3$。并集为$[-2,3]$。 （Ⅱ）$f(x)\leq1$恒成立$\iff 5-|x+a|-|x-2|\leq1\iff |x+a|+|x-2|\geq4$恒成立。 由绝对值的三角不等式：$|x+a|+|x-2|\geq |(x+a)-(x-2)|=|a+2|$。当$(x+a)(x-2)\leq0$时取等（需存在$x$使得等号成立）。要使$|x+a|+|x-2|\geq4$对一切$x$成立，只需最小值$|a+2|\geq4$即可。 故$|a+2|\geq4\Rightarrow a+2\leq-4$或$a+2\geq4$，解得$a\leq-6$或$a\geq2$。 所以$a$的范围是$(-\infty,-6]\cup[2,+\infty)$。

点评/变式：该类“绝对值之和”型函数的最值问题，利用$|x-a|+|x-b|\geq|a-b|$可迅速得到最小值，省去分段讨论。注意等号成立的条件是$x$位于$a,b$
