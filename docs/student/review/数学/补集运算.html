补集运算

考点补集运算权重8真题数4学科数学父主题集合

考点定位

  • 父主题：集合
  • 权重 weight：8
  • 真题数：4；年份跨度：2009–2022
  • 出现题位：选择1
  • 难度分布：易4

知识精要

  • 全集 $U$：在研究集合关系与运算时，所涉及的全部元素的集合。
  • 补集：设 $U$ 为全集，$A\subseteq U$，由 $U$ 中所有不属于 $A$ 的元素组成的集合称为 $A$ 的补集，记作 $\complement_U A$，即 $\complement_U A = {x \mid x\in U, x\notin A}$。
  • 并集：$A\cup B = {x \mid x\in A \text{ 或 } x\in B}$。
  • 交集：$A\cap B = {x \mid x\in A \text{ 且 } x\in B}$。
  • 混合运算：补集运算可以结合并、交进行，注意运算顺序——有括号先算括号内，或利用德摩根律转化。
  • 德摩根律：$\complement_U(A\cup B) = (\complement_U A)\cap (\complement_U B)$，$\complement_U(A\cap B) = (\complement_U A)\cup (\complement_U B)$。在仅涉及补集与并/交的混合运算中，可简化计算。
  • 适用条件：补集定义的前提是明确全集 $U$，且讨论的集合都是 $U$ 的子集。

解题方法与套路

  1. 明确全集与目标集合：首先从题干中提取出全集 $U$ 以及所涉及的所有集合 $A, B, M, N$ 等。
  2. 处理括号内运算：若求 $\complement_U(M\cup N)$ 或 $\complement_U(M\cap N)$，先算括号内的并集或交集，得到中间集合 $T$。
  3. 执行补集运算：在全集 $U$ 中剔除中间集合 $T$ 的元素，得到 $\complement_U T$。即 $\complement_U T = U \setminus T$。
  4. 验证选项（选择题必用）：将求得的集合与选项逐一比对；也可从选项出发，判断元素与集合的关系，如考查“是否属于”等特点。
  5. 双向核对：利用德摩根律，可将 $\complement_U(M\cup N)$ 转为 $(\complement_U M)\cap (\complement_U N)$ 进行验算，确保无误。

高频易错

  • 忽略全集：补集 $\complement_U A$ 与全集 $U$ 有关，全集不同结果不同。读题时必须圈出全集范围。
  • 并集与补集顺序混乱：混淆 $(\complement_U M)\cup N$ 与 $\complement_U(M\cup N)$，前者需先取补集再并，后者先并后取补集。一定要看清括号位置。
  • 元素遗漏或重复：并集列举元素时易漏掉交集部分，补集列举时易将不属于 $U$ 的元素误写入答案。
  • 符号误读：题目若以 $\complement_U M = {1,3}$ 的形式给出条件，应熟练反推 $M = U \setminus {1,3}$，避免正向推导出错。
  • 德摩根律误用：$\complement_U(A\cup B) \neq (\complement_U A)\cup(\complement_U B)$，混淆与负负得正的情况。

代表题精讲

代表题 2022-理-01

题目：设全集 $U={1,2,3,4,5}$，集合 $M$ 满足 $\complement_U M={1,3}$，则（ ）
A. $2\in M$　 B. $3\in M$　 C. $4\notin M$　 D. $5\notin M$

思路
由补集定义反推出 $M$ 的具体元素，然后判断选项给出的元素与 $M$ 的隶属关系。
步骤
1. $\complement_U M = {1,3}$，意味着在 $U$ 中去掉 $1$ 和 $3$ 后的剩余元素构成 $M$。因此 $M = U \setminus {1,3} = {2,4,5}$。
2. 检查各选项：A 项 $2\in M$ 正确；B 项 $3\in M$ 错误；C 项 $4\notin M$ 错误；D 项 $5\notin M$ 错误。
点评/变式
本题是补集定义最直接的应用。变式：给出 $\complement_U M$ 及部分元素关系，求全集或求未知元素。

代表题 2021-文-01

题目：已知全集 $U={1,2,3,4,5}$，$M={1,2}$，$N={3,4}$，则 $\complement_U(M\cup N)=$（　）
A. ${5}$　 B. ${1,2}$　 C. ${3,4}$　 D. ${1,2,3,4}$

思路
先求 $M$ 与 $N$ 的并集，再在全集 $U$ 中取补集。
步骤
1. 计算 $M\cup N = {1,2}\cup {3,4} = {1,2,3,4}$。
2. $\complement_U(M\cup N) = U \setminus {1,2,3,4} = {5}$。
3. 匹配选项，A 正确。
点评/变式
可用德摩根律验证：$\complement_U(M\cup N) = (\complement_U M)\cap (\complement_U N) = {3,4,5}\cap {1,2,5} = {5}$。变式可改为求 $\complement_U(M\cap N)$ 或加入空集情况。

代表题 2020-理-01

题目：已知集合 $U={-2,-1,0,1,2,3}$，$A={-1,0,1}$，$B={1,2}$，则 $\complement_U(A\cup B)=$（ ）
A. ${-2,3}$　 B. ${-2,2,3}$　 C. ${-2,-1,0,3}$　 D. ${-2,-1,0,2,3}$

思路
先合并 $A$ 与 $B$，再求补集；注意集合中含有负数、零和正数，罗列时要细心避免遗漏。
步骤
1. $A\cup B = {-1,0,1} \cup {1,2} = {-1,0,1,2}$（注意元素 $1$ 不重复）。
2. $\complement_U(A\cup B) = U \setminus {-1,0,1,2} = {-2,3}$。
3. 对比选项，A 正确。
点评/变式
补集的结果恰好是 $U$ 中“最边沿”的两个元素。可变形为给出补集结果反推 $A$ 或 $B$ 的元素，强化逆向思维能力。
