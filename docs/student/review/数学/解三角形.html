知识精要

  • 正弦定理 $$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$ 其中 $R$ 为 $\triangle ABC$ 外接圆半径。变形：$a=2R\sin A$，$b=2R\sin B$，$c=2R\sin C$，以及 $\sin A = \frac{a}{2R}$ 等。

  • 余弦定理 $$a^2 = b^2 + c^2 - 2bc\cos A$$ $$b^2 = a^2 + c^2 - 2ac\cos B$$ $$c^2 = a^2 + b^2 - 2ab\cos C$$ 变形求角：$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$，依此类推。

  • 三角形面积公式 $$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$$ 这是将边、角与面积联系的核心桥梁。

  • 三角形内角和 $A + B + C = \pi$。由此推出诱导关系：$\sin(A+C) = \sin B$，$\cos(A+C) = -\cos B$，$\sin\frac{B}{2} = \cos\frac{A+C}{2}$ 等，常用于三角恒等变换。

  • 边角互化 核心依据是正弦定理，可将边长代换为对应角的正弦值，或将角的正弦代换为对应边长。例如：化简 $a\cos C + c\cos A = b$ 等。

解题方法与套路

  1. 边角互化，统一形式 题目条件若同时含边和角的三角函数，应利用正弦定理进行“边化角”或“角化边”，将条件统一为角的关系或边的二次式，再结合恒等变换或余弦定理求解。如已知 $\sin A + \sqrt{3} \cos A = 2$，统一为角的形式求 $A$。

  2. 已知一角及对边，求最值或范围 已知一角（如 $A$）及其对边（如 $a$），求解周长、两边之和或面积的最值，通法是：

  3. 先用余弦定理建立另外两边 $b, c$ 的等量关系：$a^2 = b^2 + c^2 - 2bc\cos A$。
  4. 将目标量（如 $b+c$，$bc$）用该等量关系表达。

  5. 利用基本不等式 $b^2 + c^2 \ge 2bc$ 或 $(b+c)^2 \le 2(b^2 + c^2)$ 求最值，注意验证取等条件。

  6. 边角关系证明与求角 对于含 $a\cos B + b\cos A$ 型结构的等式，通常可：

  7. 用正弦定理边化角，逆用两角和的正弦公式 $\sin A\cos B + \cos A\sin B = \sin(A+B) = \sin C$。

  8. 或用余弦定理将 $\cos B, \cos A$ 代入，化简得出边的关系。 然后依据关系求得某个角的余弦值或正弦值，确定角。

  9. 解多三角形与平面几何联系 遇到有公共边或角的相邻三角形，应分别在各三角形中运用正弦、余弦定理，利用公共边、角或互补关系（如 $\angle ADB + \angle ADC = \pi$，其正弦值相等）建立方程，联立求解。

高频易错

  • 忽略内角范围导致多解或错解 由 $\sin A$ 求 $A$ 时，在 $(0,\pi)$ 内常有两解（互补），必须结合题意（如三角形为钝角三角形、大边对大角等）检验并取舍。由 $\cos A$ 或 $\tan A$ 求角则不会多解，应优先计算余弦值或利用恒等式得出正切值。

  • 基本不等式求最值时忽略取等条件 在求周长最大值或面积最大值时，必须验证“$b=c$”或“三角形构成条件”等取等情况是否成立，否则最值可能无法取得。

  • 正弦定理边角互化易错点 边化角时，必须是齐次式的对应替换。如 $b\cos B = a\cos A$ 可化为 $\sin B\cos B = \sin A\cos A$，即 $\sin 2B = \sin 2A$，此时可得 $2B = 2A$ 或 $2B = \pi - 2A$，即 $A=B$ 或 $A+B=\frac{\pi}{2}$。遗漏后一种情况会失解。

  • 混淆正弦定理中的 $2R$ 在计算外接圆相关问题时容易遗漏或滥用 $2R$，记住代换时 $\sin A, \sin B, \sin C$ 分别与边长 $a, b, c$ 的比值为常数 $2R$，但 $R$ 在纯粹边角关系化简中常会消去，不必刻意求出。

代表题精讲

题目（2024-新课标Ⅱ-15）：在 $\triangle ABC$ 中，内角 $A,B,C$ 对边为 $a,b,c$，已知 $\sin A + \sqrt{3} \cos A = 2$。 （1）求 $A$。 （2）若 $a=2$，$\sqrt{2}b\sin C = c\sin B$，求 $\triangle ABC$ 的周长。

思路：（1）利用辅助角公式化简左边，由 $\sin(A+\varphi)=1$ 结合 $A$ 的范围求 $A$。 （2）先利用正弦定理化简条件 $\sqrt{2}b\sin C = c\sin B$ 为边的比例关系，求出 $b,c$ 的比值或值；再结合（1）中 $A$ 和已知 $a=2$，用余弦定理联立方程求 $b, c$，最后算周长。

步骤： （1）$\sin A + \sqrt{3} \cos A = 2\sin(A + \frac{\pi}{3}) = 2$，故 $\sin(A + \frac{\pi}{3}) = 1$。因 $0<A<\pi$，则 $\frac{\pi}{3} < A+\frac{\pi}{3} < \frac{4\pi}{3}$，所以 $A+\frac{\pi}{3} = \frac{\pi}{2}$，即 $A = \frac{\pi}{6}$。 （2）由 $\sqrt{2}b\sin C = c\sin B$ 及正弦定理 $\frac{b}{\sin B} = \frac{c}{\sin C}$ 得 $\sqrt{2}bc = cb$，因 $c,b \neq 0$ 得 $c = \sqrt{2}b$。由余弦定理 $a^2 = b^2 + c^2 - 2bc\cos A$ 代入$A=\frac{\pi}{6}, a=2$ 得 $4 = b^2 + 2b^2 - 2\sqrt{2}b^2 \cdot \frac{\sqrt{3}}{2}$，解得 $b^2$ 进而求出 $b,c$ 和周长。计算得周长为 $2+ \sqrt{6} + \sqrt{3} + \sqrt{2}$（具体数值按真题答案）。

点评/变式：本题第（1）问是典型的辅助角公式求角问题，务必注意角范围的限制以确定唯一解。第（2）问先通过正弦定理得到边之比，是简化条件的关键。变式训练：可将条件改为 “$\sqrt{3}a\cos C = c\sin A$”，同样用正弦定理边化角求 $C$。

题目（2021-文-15/理-15）：在 $\triangle ABC$ 中，内角 $A,B,C$ 对边为 $a,b,c$，面积为 $\sqrt{3}$，$B=60^\circ$，$a^2 + c^2 = 3ac$，则 $b=$______。

思路：已知面积和夹角 $B$，可用面积公式求出 $ac$，再结合已知 $a^2 + c^2$ 与 $ac$ 的关系，直接代入余弦定理求 $b^2$。

步骤： 由面积公式 $S = \frac{1}{2}ac\sin B$，代入 $\sqrt{3} = \frac{1}{2}ac\sin 60^\circ = \frac{\sqrt{3}}{4}ac$，得 $ac=4$。 由余弦定理 $b^2 = a^2 + c^2 - 2ac\cos B$，代入 $\cos 60^\circ = \frac{1}{2}$ 及 $a^2 + c^2 = 3ac = 12$，得 $b^2 = 12 - 2 \times 4 \times \frac{1}{2} = 8$，故 $b=2\sqrt{2}$。

点评/变式：此题免去了分别求 $a$ 和 $c$ 的步骤，直接整体代入，考查了代数变形能力。如果题干不给 $a^2 + c^2$ 的等式，改为“$b=2\sqrt{2}$”，求 $a^2 + c^2$ 的值，解法完全一样。

题目（2021-理-05）：在正方体 $ABCD-A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 的中点，求直线 $PB$ 与 $AD_1$ 所成角的余弦值（或角度）。

思路：异面直线所成角通过平移转化为相交线夹角。将 $AD_1$ 平移至 $BC_1$，连接 $P, B, C_1$，解 $\triangle PBC_1$ 求 $\angle PBC_1$ 或其补角。

步骤： 连接 $BC_1, PC_1$。因为 $AD_1 \parallel BC_1$，故 $\angle PBC_1$（或其补角）即为所求线线角。 设正方体棱长为 $1$，则在 $\triangle PBC_1$ 中，可计算各边长度： $BC_1 = \sqrt{2}$（正方体面对角线）。 在 $\triangle B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 中点，故 $PC_1 = \frac{1}{2}B_1D_1 = \frac{\sqrt{2}}{2}$。 连接 $PB$。由 $BB_1 \perp$ 底面，$B_1P \subset$ 底面，得 $BB_1 \perp B_1P$，且 $B_1P = \frac{\sqrt{2}}{2}$，所以 $PB = \sqrt{1^2 + (\frac{\sqrt{2}}{2})^2} = \frac{\sqrt{6}}{2}$。 在 $\triangle PBC_1$ 中，使用余弦定理求 $\cos \angle PBC_1$，或利用勾股定理逆定理：$PC_1^2 + PB^2 = (\frac{\sqrt{2}}{2})^2 + (\frac{\sqrt{6}}{2})^2 = 2 = BC_1^2$，故 $\angle BPC_1 = 90^\circ$。 从而 $\sin \angle PBC_1 = \frac{PC_1}{BC_1} = \frac{1}{2}$，所以 $\angle PBC_1 = \frac{\pi}{6}$。

点评/变式：立体几何求异面直线夹角问题的核心是“平移转化”，并构造含待求角的三角形，再通过计算三边长度，用余弦定理或勾股定理求角。若求线面角或二面角，同样是着力于构造平面角，化归为解三角形。
