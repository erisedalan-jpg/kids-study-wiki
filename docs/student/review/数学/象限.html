知识精要

  • 象限角定义：将角的顶点与原点重合，始边与 $x$ 轴非负半轴重合，终边落在第几象限即为第几象限角。终边在坐标轴上的角不属于任何象限。
  • 三角函数在各象限的符号规律（核心）：
函数 第一象限 第二象限 第三象限 第四象限
$\sin\alpha$ $+$ $+$ $-$ $-$
$\cos\alpha$ $+$ $-$ $-$ $+$
$\tan\alpha$ $+$ $-$ $+$ $-$
  • 符号记忆口诀：“一全正，二正弦，三正切，四余弦”。意为：第一象限所有三角函数值为正；第二象限仅正弦（及余割）为正；第三象限仅正切（及余切）为正；第四象限仅余弦（及正割）为正。

解题方法与套路

  1. 条件翻译：将已知的三角不等式 $ \sin\alpha \lessgtr 0 $、$ \cos\alpha \lessgtr 0 $、$ \tan\alpha \lessgtr 0 $ 分别翻译为角 $\alpha$ 所在的可能象限集合。
  2. 分别限制：
  3. 由 $ \sin\alpha > 0 $ 得 $\alpha$ 在一、二象限；由 $ \sin\alpha < 0 $ 得 $\alpha$ 在三、四象限。
  4. 由 $ \cos\alpha > 0 $ 得 $\alpha$ 在一、四象限；由 $ \cos\alpha < 0 $ 得 $\alpha$ 在二、三象限。
  5. 由 $ \tan\alpha > 0 $ 得 $\alpha$ 在一、三象限；由 $ \tan\alpha < 0 $ 得 $\alpha$ 在二、四象限。
  6. 取交集锁定：求各条件所得象限集合的交集。若交集唯一，即为答案；若需进一步讨论，常结合特殊角或角的范围进行排除。
  7. 终结检查：终边落在坐标轴上的情况不满足任意两个条件同时成立，可直接排除。

高频易错

  • 混淆符号位置：误将 $\sin\alpha$ 的正负与余弦象限对应，或记错 $\tan\alpha$ 在二、四象限的符号。务必反复强化记忆口诀。
  • 单一条件误判：仅凭一个条件（如 $\sin\alpha<0$）就误选三或四象限，忽略了另一个条件（$\tan\alpha>0$）对答案的联合约束。求解此类问题必须同时满足所有条件。
  • 忽略坐标轴角：默认所有角度都存在象限。对于 $\tan\alpha$，务必注意当 $\alpha$ 终边在 $y$ 轴上时（如 $\alpha=\frac{\pi}{2}+k\pi$）$\tan\alpha$ 无定义，不存在正负。虽然本题未涉及，但此类逻辑漏洞常出现在多选或判断中。

代表题精讲

题目：若 $\sin\alpha < 0$ 且 $\tan\alpha > 0$，则 $\alpha$ 是第几象限角？

思路： 本题为典型的“由三角函数值的符号反推角所在象限”问题。核心思路是将两个条件分别转化为角所在的象限范围，然后求两个象限集合的交集。该交集必须同时满足正弦为负和正切为正。

步骤： 1. 解 $ \sin\alpha < 0 $： 正弦值在第三、第四象限为负。 $$ \Rightarrow \alpha \in { \text{第三象限角} } \cup { \text{第四象限角} } $$

  1. 解 $ \tan\alpha > 0 $： 正切值在第一、第三象限为正。 $$ \Rightarrow \alpha \in { \text{第一象限角} } \cup { \text{第三象限角} } $$

  2. 求交集： $$ { \text{三} , \text{四} } \cap { \text{一} , \text{三} } = { \text{三} } $$ 只有第三象限同时满足两个条件。

  3. 结论：$\alpha$ 是第三象限角。故选C。

点评/变式： - 点评：本题为基础送分题，牢牢掌握“一全二正三切四余”口诀是关键。解题时要养成“双条件制导”的习惯，避免看一眼一个条件就匆忙下结论。 - 变式：若将条件改为“$\sin\alpha \cdot \cos\alpha > 0$ 且 $\tan\alpha < 0$”，如何判断？首先 $ \sin\alpha \cdot \cos\alpha > 0 $ 等价于 $ \tan\alpha > 0 $，这表明 $\alpha$ 在一、三象限。但后续条件又要求 $ \tan\alpha < 0 $，二者产生矛盾，则这样的角 $\alpha$ 不存在。这提醒我们注意题目条件间的逻辑一致性。
