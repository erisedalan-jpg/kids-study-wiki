象限坐标符号

考点定位

  • 父主题：三角函数
  • 权重 weight：5
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 复平面的坐标表示：复数 $z = a + bi\ (a,b \in \mathbb{R})$ 在复平面内对应点 $Z(a, b)$，其中实部 $a$ 为横坐标，虚部 $b$ 为纵坐标。
  • 各象限内点的坐标符号特征：
    • 第一象限：$a > 0,\ b > 0$
    • 第二象限：$a < 0,\ b > 0$
    • 第三象限：$a < 0,\ b < 0$
    • 第四象限：$a > 0,\ b < 0$
  • 坐标轴上的点：不在任何象限。若 $a=0, b\neq0$，点在虚轴上；若 $a\neq0, b=0$，点在实轴上；$a=b=0$ 为原点。

解题方法与套路

已知复数（或点）所在象限求参数取值范围的通用步骤： 1. 写出点坐标：将复数化为标准代数形式 $z = a + bi$，明确实部 $a$ 与虚部 $b$ 的表达式（含参数）。 2. 依据象限列不等式组：根据点所在象限，写出实部与虚部应满足的符号条件（严格不等式，不含等号）。 - 第四象限 → $a>0$ 且 $b<0$； - 第一象限 → $a>0$ 且 $b>0$； - 第二象限 → $a<0$ 且 $b>0$； - 第三象限 → $a<0$ 且 $b<0$。 3. 解不等式组：分别求解每一个不等式，再取交集，得到参数的取值范围。 4. 检验边界：若题目涉及“在某象限内”，等号不可取；若求点在某半轴或轴上的情况，应单独列出等式条件。

高频易错

  • 象限符号记忆混乱：常将第四象限的纵坐标符号误记为正，导致 $b<0$ 写成 $b>0$。建议记忆口诀：“一全正，二正弦，三正切，四余弦”对应三角函数符号，结合坐标横纵的符号进行联想。
  • 忽略 “在象限内” 隐含的严格不等号：将 $a>0, b<0$ 误写成 $a \ge 0, b \le 0$，错误包含了坐标轴上的点。题目明确说“在第四象限”，一定不能取等。
  • 混淆实部与虚部：将 $m+3$ 当成虚部，$m-1$ 当成实部，导致不等式方向完全反置。应始终牢记 $z = a+bi$ 的对应顺序。
  • 解不等式组时取并集：误把同时满足的条件当成“或”的关系，取了并集，导致范围扩大。

代表题精讲

题目：已知 $z = (m+3) + (m-1)i$ 在复平面内对应的点在第四象限，求实数 $m$ 的取值范围。

思路：由复数的几何意义，点坐标为 $(m+3, m-1)$。第四象限需要横坐标为正、纵坐标为负，列出关于 $m$ 的不等式组，解出 $m$ 的范围。

步骤： 1. 实部 $a = m+3$，虚部 $b = m-1$。 2. 点在第四象限 $\Rightarrow a>0$ 且 $b<0$。 3. 列不等式组： $$\begin{cases} m+3 > 0 \ m-1 < 0 \end{cases}$$ 4. 解之得 $m > -3$ 且 $m < 1$，即 $-3 < m < 1$。 5. 对照选项，取值范围为 $(-3, 1)$，选项 A。

点评/变式： - 本题属于“已知象限求参数”的基础题型，核心是建立实部与虚部的符号不等式。 - 变式1：若点在第二象限，则条件变为 $m+3<0$ 且 $m-1>0$，此时不等式组无解，即不存在 $m$ 使点在第二象限。 - 变式2：若点位于直线 $y=x$ 上（虚部等于实部），则列出 $m-1 = m+3$，解得无解；若在虚轴上（实部为0），则 $m+3=0$，此时 $m=-3$，虚部为 $-4$，点在虚轴负半轴上，不属于任何象限。 - 此类题可进一步与复数的模、共轭复数、复数运算的几何意义结合，但核心仍是坐标与象限的符号关系。
