知识精要

  • 赋值是算法中的基本操作，用“$=$”表示，意义是将右边表达式的值计算后赋给左边的变量，如 $S = S + M$ 表示把当前 $S$ 与 $M$ 的和作为 $S$ 的新值。
  • 在程序框图中，赋值操作发生在处理框（矩形框）内，每执行一次赋值，变量的旧值被新值覆盖，后续运算均使用最新值。
  • 累加变量通常初始化为 $0$，累乘变量初始化为 $1$，并按照循环结构在每次迭代中更新：$S = S + a_k$ 或 $M = M \cdot q$ 等形式。
  • 赋值过程中的变量更新必须严格按框图从上到下、从左到右的顺序模拟，同一轮循环中各赋值语句的先后顺序直接影响最终结果。

解题方法与套路

  1. 明初始：列出程序开始前所有输入变量及赋初值的变量的初始值，如 $x=2, t=2, M=1, S=3, k=1$。
  2. 判条件：检查进入循环的条件（如 $k \le t$），若满足则进入循环体，否则直接输出结果。
  3. 逐句执行：按循环体内语句顺序依次更新变量值，建议列表演示每个变量在每步的变化。
  4. 记更新：每次循环结束后，循环变量必须按框图指示自增（如 $k = k+1$），再回到判断条件。
  5. 定终值：当循环条件不再满足时，输出的变量值即为所求结果。
  6. 对于嵌套循环或条件分支，同样按“深度优先”方式逐层模拟，防止跳步。

高频易错

  • 混淆“$=$”的数学意义与赋值意义：$S = S + M$ 在数学上不成立，但作为赋值语句合法，理解错误会导致模拟卡死。
  • 初始值记错：如累加变量只看框图初始框，不要遗漏已给的初值（本题 $S$ 初值为 $3$，而非 $0$）。
  • 循环终止条件边界误判：当 $k=t$ 时仍会执行一次循环体，执行后 $k$ 自增，才跳出。极易漏掉最后一次循环。
  • 赋值顺序颠倒：先更新 $S$ 还是先更新 $M$，必须与框图一致。若交换顺序，结果完全不同。
  • 变量覆盖后未使用新值：某变量在循环初被赋值，之后其值被其他变量引用，必须是本轮更新后的值。

代表题精讲

题目（2014 理-07）
执行如图所示的程序框图，若输入的 $x$，$t$ 均为 $2$，则输出的 $S=$（　）

思路
初始值明确，循环条件 $k \le t$，循环体内先计算 $M = M \times \dfrac{x}{k}$，再累加 $S = S + M$，然后 $k$ 自增 $1$。逐次模拟即可。

步骤
- 初值：$x=2$，$t=2$，$M=1$，$S=3$，$k=1$ - 第 1 次循环：$k=1 \le t$ $M = 1 \times \dfrac{2}{1} = 2$ $S = 3 + 2 = 5$ $k = 1+1=2$ - 第 2 次循环：$k=2 \le t$ $M = 2 \times \dfrac{2}{2} = 2$ $S = 5 + 2 = 7$ $k = 2+1=3$ - 判断 $k=3 \le t$？否，跳出循环，输出 $S=7$。

点评/变式
本题核心是赋值顺序和循环边界的模拟。注意 $M$ 的计算含有除法，$x,k$ 均为整数时结果仍可能为整数，不会因小数出现而复杂化。变式常将 $t$ 改为更大的数，或改变初始 $S,M$ 的值，解题方法完全一致。考生训练时可自行改变循环条件（如 $k < t$），体验边界差异。
