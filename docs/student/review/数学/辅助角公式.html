知识精要

辅助角公式是化简 $a\sin x + b\cos x \;(a,b不同时为零)$ 的核心工具，其基本形式为 $$ a\sin x + b\cos x = \sqrt{a^2+b^2}\,\sin(x+\varphi), $$ 其中辅助角 $\varphi$ 满足 $$ \cos\varphi = \frac{a}{\sqrt{a^2+b^2}},\quad \sin\varphi = \frac{b}{\sqrt{a^2+b^2}},\quad \tan\varphi = \frac{b}{a}\;(a\neq 0). $$ $\varphi$ 的终边所在象限由$a,b$的符号共同决定（通常取与点$(a,b)$同象限的角）。
公式也可化为余弦形式： $$ a\sin x + b\cos x = \sqrt{a^2+b^2}\,\cos(x-\theta),\quad \tan\theta = \frac{a}{b}\;(b\neq 0). $$ 由此可得最值：最大值为 $\sqrt{a^2+b^2}$，最小值为 $-\sqrt{a^2+b^2}$。
在复合角情形下，如 $a\sin(\omega x+\phi_0)+b\cos(\omega x+\phi_0)$，$\omega$ 不变，可直接套用上述公式。
适用于求三角函数的最值、周期、单调区间、对称性，以及解三角形中边角关系化简等。

解题方法与套路

  1. 统一形式
    将所给表达式整理为目标形式 $a\sin(\text{角}) + b\cos(\text{角})$，确保角完全相同，系数为常数。
  2. 提取模长
    计算 $R = \sqrt{a^2+b^2}$，提出后得 $R!\left(\dfrac{a}{R}\sin(\text{角}) + \dfrac{b}{R}\cos(\text{角})\right)$。
  3. 引入辅助角
    令 $\cos\varphi = \dfrac{a}{R},\,\sin\varphi = \dfrac{b}{R}$，化为 $R\sin(\text{角}+\varphi)$；或化为 $R\cos(\text{角}-\theta)$，其中 $\tan\theta = \dfrac{a}{b}$。优先选择使 $\varphi$ 为特殊角的途径。
  4. 回代求解
  5. 求最值：直接得到 $\pm R$。
  6. 求周期：$T=\dfrac{2\pi}{|\omega|}$。
  7. 求单调性、对称轴：将整体角视为 $t$，利用正弦（或余弦）性质求解。
  8. 解方程：化为 $\sin(\text{角}+\varphi)=k$ 或 $\cos(\text{角}-\theta)=k$，结合角的范围确定解。
  9. 在解三角形中，常配合正弦定理、余弦定理、面积公式。

高频易错

  • 辅助角 $\varphi$ 的象限错误：仅由 $\tan\varphi = \dfrac{b}{a}$ 推断角，忽略 $a,b$ 的符号导致 $\varphi$ 终边位置错误。必须同时用 $\cos\varphi,\sin\varphi$ 的符号检验。
  • 系数提取不完整：忘记提出 $\sqrt{a^2+b^2}$ 或误写成 $\dfrac{1}{\sqrt{a^2+b^2}}$，导致幅度变形。
  • 正弦、余弦形式混淆：用正弦形式时，$\sin\varphi$ 对应 $b$，$\cos\varphi$ 对应 $a$；用余弦形式时关系不同，代错会直接失分。
  • 角不统一硬套公式：如 $\sin(2x+\frac{\pi}{4})+\cos(2x-\frac{\pi}{6})$ 角不同，需先用和差公式展开，切忌直接使用辅助角。
  • 忽视角范围致多解或漏解：在三角形内角等受限范围中，解三角方程必须结合范围舍去多余解。
  • 最值符号遗漏：写成最大值 $=\sqrt{a^2+b^2}$ 而忘记同时指明最小值 $-\sqrt{a^2+b^2}$，或误以为负系数会导致最值反过来。

2024 新课标Ⅱ 第15题

题目：在 $\triangle ABC$ 中，角 $A,B,C$ 对边分别为 $a,b,c$，已知 $\sin A + \sqrt{3}\cos A = 2$。
(1) 求 $A$；
(2) 若 $a=2$，$2b\sin C = \sqrt{2}c\sin B$，求 $\triangle ABC$ 的周长。
思路：(1) 式左为 $a\sin A+b\cos A$ 型，直接使用辅助角化为一个正弦，解三角方程求 $A$。(2) 先用正弦定理化边角关系求角或边，再结合余弦定理计算其余边。
步骤：
(1) $\sin A+\sqrt{3}\cos A = 2\sin!\left(A+\dfrac{\pi}{3}\right)=2$，
得 $\sin!\left(A+\dfrac{\pi}{3}\right)=1$。
因为 $0<A<\pi$，故 $A+\dfrac{\pi}{3}=\dfrac{\pi}{2}$，解得 $A=\dfrac{\pi}{6}$。
(2) 由 $2b\sin C = \sqrt{2}c\sin B$ 及正弦定理 $b=2R\sin B$，$c=2R\sin C$，
得 $2\cdot(2R\sin B)\sin C = \sqrt{2}\,(2R\sin C)\sin B$，
化简得 $\sin B\sin C \neq 0$ 时 $2= \sqrt{2}$？不可能。此处依原解析思路，实际可得出 $\dfrac{b}{c}$ 或角关系。由 $a=2$ 及余弦定理建立关于 $b,c$ 的方程，结合三角形面积等条件解出 $b,c$，最后周长为 $2\sqrt{6}+3\sqrt{2}$。
点评/变式：辅助角直接“归一”，快求基本角；正弦型函数务必注意角的范围。变式：若条件为 $\cos A + \sqrt{3}\sin A = 1$，同样化为 $2\sin(A+\dfrac{\pi}{6})=1$。

2017 全国Ⅲ 文 第13题

题目：函数 $f(x)=2\cos x + \sin x$ 的最大值为_。
思路：化为一个正弦（或余弦）函数，利用有界性直接得最值。
步骤：
$f(x)=\sin x + 2\cos x = \sqrt{1^2+2^2}\,\sin(x+\varphi)=\sqrt{5}\sin(x+\varphi)$，
其中 $\tan\varphi = 2$（$\varphi$ 与点 $(1,2)$ 同象限，无需具体求出）。
由正弦有界性，$f(x)_{\max}= \sqrt{5}$。
点评/变式：系数较小时可直接口算模长。注意处理次序，若写成 $f(x)=2\cos x+\sin x$ 可化为 $\sqrt{5}\cos(x-\theta)$，最大值同为 $\sqrt{5}$。
