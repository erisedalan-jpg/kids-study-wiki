知识精要

向量数量积的运算律是代数化处理几何问题的基础，务必熟练： - 交换律：$\vec{a}\cdot\vec{b}=\vec{b}\cdot\vec{a}$。 - 数乘结合律：$(\lambda\vec{a})\cdot\vec{b}=\lambda(\vec{a}\cdot\vec{b})=\vec{a}\cdot(\lambda\vec{b})$（$\lambda\in\mathbb{R}$）。 - 分配律：$\vec{a}\cdot(\vec{b}\pm\vec{c})=\vec{a}\cdot\vec{b}\pm\vec{a}\cdot\vec{c}$，也可逆向合并。 - 模长关系：$\vec{a}\cdot\vec{a}=|\vec{a}|^{2}$，这是将模长转化为数量积的核心桥梁。 - 核心公式：$|\vec{a}\pm\vec{b}|^{2}=|\vec{a}|^{2}\pm 2\vec{a}\cdot\vec{b}+|\vec{b}|^{2}$，是向量模长运算的万能工具。 - 条件：以上运算律对所有维度的向量均成立，无需考虑夹角。注意数量积结果是一个实数，因此只能进行线性运算，绝无结合律。

解题方法与套路

  1. 目标消去未知向量：遇到形如 $\vec{a}\cdot (m\vec{a}+n\vec{b})$ 的式子，第一步立即用分配律展开，化为只含 $\vec{a}\cdot\vec{a}$ 或 $\vec{a}\cdot\vec{b}$ 的项。
  2. 数乘提取系数：展开过程中，将数乘系数提到点乘前面，例如 $m\vec{a}\cdot\vec{b}$，避免混淆。
  3. 模长平方代换：见到 $\vec{a}\cdot\vec{a}$ 果断写成 $|\vec{a}|^{2}$，这是命题人给出的直接已知条件。
  4. 整体代入求值：将已知的单向量模长、两向量点乘值整体代入化简后的式子，口算即得答案。
  5. 若条件不足：题目若只给模长不给点乘，很可能需要构造模长公式 $|\vec{a}\pm\vec{b}|^{2}$ 并解出 $\vec{a}\cdot\vec{b}$，再回头代入目标式。

高频易错

  • 误用结合律：$(\vec{a}\cdot\vec{b})\cdot\vec{c}$ 与 $\vec{a}\cdot(\vec{b}\cdot\vec{c})$ 写法本身就不规范，前者是数乘向量，后者是向量点乘向量？极易混淆。牢记：数量积的结果是数，不能与第三个向量直接再点乘，除非有标量乘法。但 $( \vec{a}\cdot\vec{b} )\vec{c}$ 是向量的数乘，与 $\vec{a}(\vec{b}\cdot\vec{c})$ 方向未必相同，绝不相等。
  • 符号遗漏：展开 $\vec{a}\cdot(2\vec{a}-\vec{b})$ 时，注意 $-\vec{a}\cdot\vec{b}$ 的负号。若已知 $\vec{a}\cdot\vec{b}=-1$，代入后变为 $-(-1)$，需双重符号细心。
  • 混淆模与点乘：$|\vec{a}|=1$ 不能直接用于 $\vec{a}\cdot\vec{b}$，必须通过模长平方得到 $\vec{a}\cdot\vec{a}=1$。把 $|\vec{a}|$ 与 $\vec{a}$ 混为一谈，极可能导致无法展开。
  • 分配律方向错误：$(\vec{a}+\vec{b})\cdot(\vec{c}+\vec{d})$ 应两两分配得到四项，切忌少项。虽然本题不涉及，但稍复杂题常在此失分。

代表题精讲

题目（2018·全国卷·文4）已知向量 $\vec{a},\vec{b}$ 满足 $|\vec{a}|=1$，$\vec{a}\cdot\vec{b}=-1$，则 $\vec{a}\cdot(2\vec{a}-\vec{b})=(\quad)$
A. 4　　B. 3　　C. 2　　D. 0

思路
目标式含有未知向量 $\vec{b}$，但已知 $\vec{a}\cdot\vec{b}$，利用分配律将目标式展开，消去 $\vec{b}$ 并引入 $|\vec{a}|^{2}$，即可完全用已知量表示。

步骤
1. 展开：$\vec{a}\cdot(2\vec{a}-\vec{b})=2\vec{a}\cdot\vec{a}-\vec{a}\cdot\vec{b}$（分配律与数乘结合律）。
2. 转化模长：$2\vec{a}\cdot\vec{a}=2|\vec{a}|^{2}=2\times1^{2}=2$。
3. 代入已知：$-\vec{a}\cdot\vec{b}=-(-1)=1$。
4. 求和：$2+1=3$，故选B。

点评/变式
此题完全依赖向量数量积的线性运算律，属于“秒杀”级别的基础题。若条件改为 $|\vec{a}|=2$，$|\vec{b}|=3$，$\vec{a}$ 与 $\vec{b}$ 的夹角为 $\frac{\pi}{3}$，求 $\vec{b}\cdot(3\vec{a}+\vec{b})$。需先用夹角公式算出 $\vec{a}\cdot\vec{b}=3$，再分配展开：$3\vec{a}\cdot\vec{b}+|\vec{b}|^{2}=3\times3+9=18$。无论条件如何包装，掌握“分配→模长/点乘代换→求值”的三板斧，即可稳定拿分。
