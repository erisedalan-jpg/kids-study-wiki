知识精要

逻辑推理题在高考中主要考查合情推理与演绎推理能力，题目通常以文字叙述给出若干条件和限制，要求推断出确定结论。核心知识包含：

1. 命题真假与逻辑联结 - 每个陈述句可视为一个命题，具有唯一的真值（真/假）。 - “只有一人预测正确”等条件意味着命题集合中有且仅有一个真命题，其余为假。 - 掌握矛盾关系：若 $A$ 说“$p$ 成立”，而事实上 $p$ 不成立，则 $A$ 说假话。当两人的断言不可同真或不可同假时，构成推理突破口。

2. 排列与对应关系 - 成绩排序、卡片分配等本质是元素与位置的对应。常用方法：穷举有限可能性，利用条件逐一排除。 - 互异性条件：如“三人成绩互不相同”、“2位优秀，2位良好”、“三张卡片各不相同”等，用于限定解空间。

3. 信息知情权与推理链 - 部分题目中不同人掌握不同信息（如看到他人成绩），其言行（“我不知道”“我知道”）本身就是推理依据。 - “我不知道”意味着：根据该人目前所知，存在多种可能情况，无法唯一确定目标事实。 - 通过模拟每个人的视角逐步推演，可将分散信息聚合成全局信息。

解题方法与套路

1. 假设归谬法（核心方法） - 步骤：依次假设某人的陈述为真（或假设某元素处于某位置），检查是否与其他条件或陈述产生矛盾。 - 若推出矛盾，则假设不成立，原命题的否定为真。 - 常用于“只有一人说真话”类型的问题。

2. 列表穷举与打表法 - 当可能性较少（如排列数 $\le 6$）时，直接列出所有可能情况，用条件逐条筛选。 - 优势：直观、不易遗漏，适合检验。

3. 分步推理与角色代入法 - 针对“某人知道某信息后说……”的类型： - 第一步：从公开言论（如“我不知道”）反向推导该人看到的信息结构。 - 第二步：站在另一个人视角，利用第一步结论推导他本该知道什么、实际能否知道。 - 关键点：严格区分“当事人知道的信息”与“我们作为解题者知道的信息”，逐步扩散公共知识。

4. 找矛盾点优先突破 - 寻找多个命题中互斥的断言（如两人对同一事实的说法相反），或与恒真条件（如总数、互异性）冲突的断言，作为突破口。

高频易错

  • 混淆“只有一人正确”与“至多一人正确”：前者意味恰好一真两假，后者允许全假。务必确认题干用词。
  • 误将“乙的话”当作已知事实：在假设归谬时，必须先假设某句为真，再以此为临时事实推演，不可先入为主认定某句为真。
  • 忽略“不知”传递的信息：甲说“不知道自己的成绩”，结合他知道的局部信息，必然推出他看到的两人成绩为一优一良。忽略此点会导致完全无法推进。
  • 循环假设未穷尽：若假设甲正确得出矛盾，应继续检验乙正确、丙正确是否均矛盾，避免过程中半途而废。
  • 忽视互异性条件：如“三人成绩互不相同”、“三张卡片上数字不同”，推演中若产生两人同分或同卡，必须立即判定该分支无效。

代表题精讲

1. 2019-文-05（三人成绩预测）

题目：甲、乙、丙三人成绩互不相同，各作一预测。甲：甲 $\gt$ 乙；乙：丙 $\gt$ 甲且丙 $\gt$ 乙；丙：丙 $\gt$ 乙。只有一人预测正确，求成绩排序。 思路：只有一人正确 → 用假设归谬法，分别假设甲、乙、丙预测正确，看哪种情况不矛盾。 步骤： - 若甲正确：甲 $\gt$ 乙；乙错 $\Rightarrow$ 并非（丙 $\gt$ 甲且丙 $\gt$ 乙） $\Rightarrow$ 丙 $\le$ 甲或丙 $\le$ 乙；丙错 $\Rightarrow$ 丙 $\le$ 乙。结合互异得丙 $\lt$ 乙 $\lt$ 甲，与假设无矛盾，排序为甲、乙、丙。 - 若乙正确：丙 $\gt$ 甲，丙 $\gt$ 乙；此时丙必说“丙 $\gt$ 乙”亦为真，违背“只有一人正确”，矛盾，排除。 - 若丙正确：丙 $\gt$ 乙；甲错 $\Rightarrow$ 甲 $\le$ 乙；结合得甲 $\le$ 乙 $\lt$ 丙。此时乙说“丙 $\gt$ 甲且丙 $\gt$ 乙”成立，乙亦真，矛盾，排除。 - 综上，唯一可能是甲正确，排序为甲、乙、丙，选A。 点评：本题为典型的“唯一真话”逻辑题，关键是假设后严格检验其他话真假，及时识别矛盾点。变式可改为“只有一人错误”，方法对称。

2. 2017-理-07 / 文-09（看成绩推理）

题目：四人中2优2良。老师给甲看乙、丙成绩；给乙看丙成绩；给丁看甲成绩。甲看后说“我不知道自己的成绩”。以下正确的是？ 思路：以甲的话为突破口，推出乙丙成绩结构，再分角色代入推导乙、丁能知道什么。 步骤： - 甲看到乙、丙成绩后仍不知自己成绩 ⇒ 乙、丙必然一优一良（若同优则甲为良可推知，若同良则甲为优可推知）。 - 乙看到丙成绩，且从甲公开言论可推知乙、丙为一优一良（乙完全能做出以上推理）。若丙为优，则乙知自己为良；若丙为良，则乙知自己为优。因此乙能知道自己的成绩。 - 丁看到甲成绩，同时能从甲言论推出甲丁也必为一优一良（因乙丙已占一优一良，剩余成绩中甲丁也是同样结构）。因此丁见甲后，当知自己成绩为另一档。丁也能知道自己的成绩。 - 乙知道自己的成绩但只看到丙，看不到甲丁，故不知甲、丁分别成绩（从而不知四人全部）。丁同理。但乙、丁均知自己，选项D正确。 点评/变式：核心是“我不知道”这一公开陈述让所有人（含我们）推导出隐藏结构，进而推进推理。这类题要求代入角色分步推演，注意区分“他知道”与“他不知道”。

3. 2016-文-16（三张卡片猜数字）

题目：三卡片分别写有 $1$ 和 $2$，$1$ 和 $3$，$2$ 和 $3$。甲、乙、丙各取一张。甲看乙卡后说“我与乙相同数字不是 $2$”；乙看丙卡后说“我与丙相同数字不是 $1$”；丙说“我卡片上数字之和不是 $5$”。求甲卡片上的数字。 思路：从丙的确定陈述入手分类讨论，结合甲、乙的话排除矛盾。 步骤： - 丙：和不是 $5$ ⇒ 丙的卡不是 $2$ 和 $3$ ⇒ 丙卡为 $1$ 和 $2$ 或 $1$ 和 $3$。 - 分类讨论： - 若丙卡为 $1$ 和 $2$：乙看丙卡后说相同数字非 $1$，说明乙、丙共同数字只能是 $2$（即乙的卡片必有 $2$）。另一数字不能是 $1$（否则与丙同为 $1$ 与 $2$，矛盾于乙话），故乙卡为 $2$ 和 $3$。此时甲看乙卡后说相同数字非 $2$，则甲不能有 $2$。剩余卡片为 $1$ 和 $3$，甲恰好取之，且与乙（$2$ 和 $3$）相同数字为 $3$（非 $2$），符合。得出甲卡为 $1$ 和 $3$。 - 若丙卡为 $1$ 和 $3$：乙看后说相同数字非 $1$，则乙丙共同数字只能为 $3$，乙卡必含 $3$。另一数字非 $1$（否则有 $1$ 与丙相同），故乙卡为 $2$ 和 $3$。此时甲看乙卡后说相同数字非 $2$，则甲卡不能有 $2$，只能为 $1$ 和 $3$。但丙已持 $1$ 和 $3$（矛盾，卡片互异）。故此情况无解。 - 综上，甲卡片上的数字是 $1$ 和 $3$。 点评：本题以确定性陈述为起点，进行穷举分类，核心是时刻检查互异性与各人陈述的逻辑一致性。变式常置换数字或条件，本质依旧是“逐句过滤”的思路。
