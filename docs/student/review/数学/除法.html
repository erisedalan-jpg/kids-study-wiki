知识精要

  1. 复数的除法定义 复数 $z_1=a+bi$ 除以 $z_2=c+di$（$z_2\neq0$）的商仍是一个复数，记作 $z_1\div z_2$ 或 $\frac{z_1}{z_2}$。

  2. 除法运算法则 进行复数除法运算时，通常将分子与分母同乘以分母的共轭复数，从而使分母实数化，转化为乘法运算： $$\frac{a+bi}{c+di} = \frac{(a+bi)(c-di)}{(c+di)(c-di)} = \frac{(ac+bd)+(bc-ad)i}{c^2+d^2} \quad (c+di\neq0)$$ 运算结果需写成代数形式 $x+yi$（$x,y\in\mathbb{R}$）。

解题方法与套路

  1. “分母实数化”步骤
  2. 分式结构：将除法写成 $\frac{a+bi}{c+di}$ 的分式形式。
  3. 找共轭：准确写出分母 $c+di$ 的共轭复数 $c-di$。
  4. 同乘共轭：分子与分母同时乘以 $c-di$。
  5. 化简分子：按多项式乘法展开分子，注意 $i^2=-1$ 进行合并，得到新复数的实部与虚部。
  6. 化简分母：分母化为实数 $c^2+d^2$。
  7. 书写结果：将实部与虚部分别除以分母实数，写成 $x+yi$ 的标准形式。

高频易错

  1. 共轭复数找错：误将分母 $c+di$ 的共轭写成 $-c+di$ 或 $c+di$。共轭复数仅改变虚部符号，即 $c-di$。
  2. 分母计算错误：忽略 $(c+di)(c-di) = c^2+d^2$，误算为 $c^2-d^2$ 或忘记虚部符号变化导致结果错误。
  3. 结果未拆开：正确计算出 $\frac{ac+bd}{c^2+d^2} + \frac{bc-ad}{c^2+d^2}i$ 后，必须将实部和虚部彻底分开书写，且虚部漏乘 $i$ 是常见失分点。

代表题精讲

【代表题】2018-理-01

  • 题目：计算复数 $\frac{1+2i}{1-2i}$。
  • 思路：该题为典型的复数除法。分母为 $1-2i$，其共轭复数为 $1+2i$。采用“分母实数化”策略，分子分母同乘分母的共轭复数，展开化简即可。
  • 步骤： $$\frac{1+2i}{1-2i} = \frac{(1+2i)(1+2i)}{(1-2i)(1+2i)}$$ $$= \frac{1+4i+4i^2}{1-4i^2}$$ 代入 $i^2=-1$ 化简： $$= \frac{1+4i-4}{1+4} = \frac{-3+4i}{5}$$ 写成标准代数形式： $$= -\frac{3}{5} + \frac{4}{5}i$$
  • 点评/变式：此题为基础题，核心在于熟练运用分母实数化。运算中需特别注意正负号。
  • 变式：若计算 $\frac{1-2i}{1+2i}$，结果则为 $-\frac{3}{5} - \frac{4}{5}i$，可对比记忆互为倒数的两复数实虚部符号关系。
