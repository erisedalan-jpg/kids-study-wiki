面积最值

考点面积最值权重6真题数2学科数学父主题解析几何

考点定位

  • 父主题：解析几何
  • 权重 weight：6
  • 真题数：2；年份跨度：2008–2013
  • 出现题位：解答20 解答21
  • 难度分布：难2

知识精要

  • 椭圆标准方程与性质：中心在原点的椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1 (a>b>0)$，焦点在$x$轴上，右焦点$(c,0)$，满足 $a^2=b^2+c^2$。
  • 点差法求中点弦斜率：弦两端点满足椭圆方程，作差后利用平方差公式变形，可得弦中点与原点连线斜率与弦斜率之积为定值 $-\frac{b^2}{a^2}$（焦点在$x$轴）。
  • 弦长公式：弦$AB$所在直线与椭圆方程联立，得一元二次方程。弦长 $|AB|=\sqrt{1+k^2}|x_1-x_2|=\sqrt{1+k^2}\frac{\sqrt{\Delta}}{|a_间|}$。对于焦点在$x$轴的椭圆，与直线$y=kx+m$联立后，弦长也常用纵坐标差表示：$|AB|=\sqrt{1+\frac{1}{k^2}}|y_1-y_2|$。
  • 对角线垂直的四边形的面积：对角线长度分别为$d_1,d_2$且垂直，面积 $S=\frac{1}{2}d_1 d_2$。
  • 函数最值求法：面积表达式常为分式二次型，即关于某变量（常为直线截距或斜率）的函数，可整体换元，利用基本不等式 $\sqrt{ab}\le\frac{a+b}{2}$ 或二次函数配方法求极值。特别注意换元后变量范围的确定（由判别式$\Delta>0$得出）。

解题方法与套路

  1. 定曲线，设直线：根据题意，从未知的目标弦入手，设定其直线方程（形式要利于优化计算，如已知斜率时设斜截式 $y=kx+m$ 或 $x=\frac{1}{k}y+n$）。
  2. 联立得方程：将直线方程与椭圆方程联立，消去其中一个变量，得到关于另一个变量的一元二次方程。计算判别式 $\Delta$，得到参数的取值范围（定义域）。
  3. 利用弦长公式表示目标量：结合韦达定理 $x_1+x_2,x_1x_2$，用弦长公式写出弦的长度。此时长度通常表示为参数的函数。
  4. 处理另一条直线：利用题设几何关系（垂直、对称、中点、交点等），求出另一条目标直线的方程。有时需先求出其弦长（若同为对角线），有时需转化为点到直线的距离（若为平行线间图形的高）。
  5. 构建面积函数：将图形面积用上述所得的弦长、距离等几何量表示，统一为同一个参数（如截距$m$、斜率$k$或某个点的坐标）的函数。
  6. 求最值：分析面积函数的结构（常为关于参数二次的齐次分式型），通过换元（设 $t=参数m$ 或 $t=函数整体$）、配方或利用基本不等式求出最大值，并需验证等号成立时参数值落在定义域内。

高频易错

  1. 忽视判别式求定义域：在设定含参直线并与椭圆联立后，未通过 $\Delta>0$ 计算参数的取值范围，导致所求最值对应的参数值不可取，造成最值错误。
  2. 弦长公式记忆错误：混淆 $\sqrt{1+k^2}\frac{\sqrt{\Delta}}{|A|}$ 中 $A$ 是联立后所得一元二次方程的二次项系数。对于横纵坐标的选择，公式混淆致错。
  3. 面积转化出错：四边形面积公式误用。如对角线不垂直时乱用 $\frac{1}{2}d_1d_2$。又如，对于平行四边形，未能善用同底等高转化面积。
  4. 换元求最值时忽略等号条件验证：利用基本不等式求最值时，未写“当且仅当…”的等号条件，或虽写但是该条件对应的参数值超出定义域，导致步骤不严密或答案错误。
  5. 点差法结论泛化：牢记点差法结论 $k_{OP}\cdot k_{AB}=-\frac{b^2}{a^2}$ 仅适用于原点是中心的情况，并注意这里的$P$是弦的中点。

代表题精讲

题目：2013-理-20

已知椭圆 $M$ 右焦点在直线 $x+y-\sqrt{3}=0$ 上，过该焦点的该直线交 $M$ 于 $A,B$，且 $AB$ 中点与原点连线斜率为 $\frac{1}{2}$，$C,D$ 为 $M$ 上点，对角线 $CD\perp AB$，求四边形 $ACBD$ 面积最大值。 思路 先用点差法与焦点坐标求出椭圆方程，再利用两对角线垂直且均过同一点（焦点）的特性，将四边形面积表示为两对角线乘积的一半，分别用弦长公式表示两条弦长，最后构造单变量函数求最值。 步骤 1. 由右焦点$(c,0)$在直线$x+y-\sqrt{3}=0$上，得$c=\sqrt{3}$。 2. 设$A(x_1,y_1),B(x_2,y_2)$，中点$P(x_0,y_0)$。点差法得：$\frac{y_0}{x_0} \cdot k_{AB} = -\frac{b^2}{a^2}$。已知$k_{AB}=-1$，中点斜率$\frac{y_0}{x_0}=\frac{1}{2}$，代入解得 $a^2=2b^2$。结合 $a^2=b^2+c^2$ 与 $c^2=3$，得 $b^2=3, a^2=6$，椭圆方程 $\frac{x^2}{6}+\frac{y^2}{3}=1$。 3. 直线$CD\perp AB$，则$k_{CD}=1$，设$CD$方程为 $y=x+m$。将$y=x+m$代入椭圆方程，得 $3x^2+4mx+2m^2-6=0$。弦长 $|CD|=\sqrt{2}\sqrt{(x_1+x_2)^2-4x_1x_2} = \frac{2\sqrt{2}}{3}\sqrt{18-2m^2}$。由$\Delta>0$得$-3<m<3$。 4. 直线$AB:x+y-\sqrt{3}=0$ 过焦点，即$m_{AB}=-\sqrt{3}$。直接求弦长，或由$CD\perp AB$且交于一点知四边形对角线为$AB,CD$。弦长$|AB|$固定，求得 $|AB|=\frac{4\sqrt{6}}{3}$。 5. 面积 $S=\frac{1}{2}|AB||CD| = \frac{4\sqrt{3}}{9}\sqrt{36-4m^2}$，当$m=0\in(-3,3)$时，$S_{max}=\frac{8\sqrt{3}}{3}$。 点评/变式 本题是典型的“对角线垂直的四边形”面积最值问题。核心在于将面积转为求两弦长。如果四边形未明确对角线交于一点，需先证明。变式：若条件变为“四边形ACBD为平行四边形且CD⊥AB”，面积最大值的求法雷同，或通过分割为三角形求解。

题目：2008-理-21

椭圆顶点为 $A(2,0),B(0,1)$。直线 $y=kx (k>0)$ 交 $AB$ 于 $D$，交椭圆于 $E,F$。求四边形 $AEBF$ 面积的最大值。 思路 四边形四个顶点分列两直线与椭圆上，需将其面积分割或转化。注意到$E,F$关于原点对称，$A,B$在坐标轴上，可利用坐标写出四个三角形面积之和，进而构造关于$k$的函数求最值。 步骤 1. 椭圆方程 $\frac{x^2}{4}+y^2=1$。直线$AB: x+2y-2=0$。 2. 联立 $y=kx$ 与椭圆，设 $E(x_1,kx_1),F(x_2,kx_2)$，解得 $x_{1,2}=\pm\frac{2}{\sqrt{1+4k^2}}$。由对称性，设$x_1>0$。 3. 因A、B在坐标轴，四边形$AEBF$面积 $S=S_{\triangle AEF}+S_{\triangle BEF}=\frac{1}{2}|EF|(d_{A\to EF}+d_{B\to EF})$。EF过原点，方程$kx-y=0$，则 $d_{A\to EF}+d_{B\to EF} = \frac{|2k-0|}{\sqrt{1+k^2}}+\frac{|0-1|}{\sqrt{1+k^2}} = \frac{2k+1}{\sqrt{1+k^2}}$。 4. 弦长 $|EF|=\sqrt{1+k^2}|x_1-x_2| = 2\sqrt{1+k^2}\cdot\frac{2}{\sqrt{1+4k^2}}$。 5. 面积 $S = \frac{1}{2}\cdot\frac{4\sqrt{1+k^2}}{\sqrt{1+4k^2}}\cdot\frac{2k+1}{\sqrt{1+k^2}} = \frac{4k+2}{\sqrt{1+4k^2}}$。 6. 令 $S^2=\frac{(4k+2)^2}{1+4k^2}$，整理为关于$k$的二次方程用判别式求最值；或分子分母同除以$k$换元，利用不等式。求导易得 $k=\frac{1}{2}$ 时，面积取得最大值 $S_{max}=2\sqrt{2}$。 点评/变式 本题关键在于不拘泥于对角线公式，灵活分割四边形。利用原点为椭圆的对称中心，简化了距离表达。处理形如 $\frac{ak+b}{\sqrt{ck^2+d}}$ 的分式函数最值，平方后转化为二次型是通法。变式：若将直线$y=kx$ 更换为过原点的一般弦，求三角形或四边形面积最值，此法完全适用。
