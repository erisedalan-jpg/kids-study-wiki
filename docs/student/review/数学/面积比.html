知识精要

  • 几何概型（面积比）：若试验的所有可能结果构成的区域 $\Omega$ 的面积为 $S_\Omega$，且每个结果出现的可能性相等，则事件 $A$（对应区域面积为 $S_A$）发生的概率 $$P(A) = \frac{S_A}{S_\Omega}.$$
  • 适用条件：
  • 样本空间 $\Omega$ 为一个可度量的几何区域（长度、面积、体积）；
  • 每个基本事件的发生是等可能的（均匀分布）；
  • 事件 $A$ 对应的子区域可度量。
  • 随机模拟与频率估计概率：当试验次数 $n$ 很大时，事件 $A$ 发生的频率 $\frac{m}{n}$ 稳定于其概率 $P(A)$，即 $$\frac{m}{n} \approx P(A).$$ 利用该关系可由已知的面积比反过来推算未知量（如圆周率 $\pi$）。

解题方法与套路

  1. 定区域：将实际问题中的变量取值范围转化为平面区域（或空间区域）。明确总区域 $\Omega$ 与事件 $A$ 对应的区域。
  2. 算面积：分别计算 $S_\Omega$ 与 $S_A$。注意坐标的取值范围（如仅在第一象限，只取四分之一圆等）。
  3. 列等式：
  4. 若直接求概率：$P(A) = \dfrac{S_A}{S_\Omega}$；
  5. 若是随机模拟求未知参数：由频率近似概率，得 $\dfrac{m}{n} \approx \dfrac{S_A}{S_\Omega}$，解出所求量。
  6. 作答：注意单位统一、近似值的化简。

高频易错

  • 错用整个圆的面积：题中 $x,y$ 常限制在 $[0,1]$ 或 $[-1,1]$ 等区间，满足 $x^2+y^2<1$ 的区域可能是 $\frac14$ 圆（第一象限）或半圆等，而总面积是正方形（或矩形），不能直接用整圆的面积。
  • 混淆距离与平方和：“平方和小于 $1$”对应区域是单位圆内部（半径 $1$），而不是“平方和的算术平方根小于 $1$”，两者一致，但有时题目会改写表述，需准确识别。
  • 忽略等可能性假设：几何概型要求点在该区域内均匀分布。若抽取方式非均匀（如非独立、非均匀），不可直接使用面积比。
  • 频率与概率的近似方向弄反：随机模拟中，$\frac{m}{n} \approx P(A)$ 而非 $\frac{n}{m}$。建立方程时要小心。

代表题精讲

题目（2016·理·10）
从区间 $[0,1]$ 均匀随机抽取 $2n$ 个数，构成 $n$ 个数对 $(x_1,y_1), (x_2,y_2),\dots,(x_n,y_n)$。其中满足 $x^2+y^2<1$ 的数对共有 $m$ 个，则用随机模拟的方法得到的圆周率 $\pi$ 的近似值为（选项略）。

思路
每个数对 $(x,y)$ 看作平面上的点，所有可能结果构成的区域 $\Omega$ 是边长为 $1$ 的正方形 $[0,1]\times[0,1]$。满足 $x^2+y^2<1$ 的点落在单位圆的第一象限部分（四分之一圆）。由几何概型，该事件概率为四分之一圆面积与正方形面积之比。再通过随机模拟的频率近似概率，建立方程解出 $\pi$。

步骤
1. 总样本空间 $\Omega = { (x,y) \mid 0\le x\le 1, 0\le y\le 1}$，面积 $S_\Omega = 1 \times 1 = 1$。
2. 事件 $A = { (x,y) \mid x^2+y^2 < 1,\; 0\le x,y\le 1}$，区域为四分之一单位圆，面积
$$S_A = \frac{1}{4}\pi \cdot 1^2 = \frac{\pi}{4}.$$
3. 由几何概型，$P(A) = \dfrac{S_A}{S_\Omega} = \dfrac{\pi}{4}$。
4. 随机模拟中，用频率 $\dfrac{m}{n}$ 估计概率 $P(A)$，因此
$$\frac{m}{n} \approx \frac{\pi}{4},$$
解得 $\pi \approx \dfrac{4m}{n}$。

点评/变式
- 该题本质立足“面积比”与“频率估计概率”的双向应用：正向已知面积比得概率，反向通过模拟频率求面积比中的未知参数。
- 变式1：若 $x,y$ 均从 $[-1,1]$ 均匀抽取，则总区域为边长 $2$ 的正方形，面积 $4$；事件区域为单位圆（整个圆），面积 $\pi$。则 $\dfrac{m}{n} \approx \dfrac{\pi}{4}$，仍得 $\pi \approx \dfrac{4m}{n}$。
- 变式2：用此法可求任意不规则图形的面积。若已知总区域面积和事件区域的形状但面积未知，可进行随机模拟，由点落入事件区域的频率估算其面积。
