知识精要

韦达定理是沟通方程系数与根之间关系的核心工具，在解析几何中主要用于“设而不求”策略。 - 一元二次方程：对于方程 $ax^2+bx+c=0\ (a\ne0)$，若其判别式 $\Delta \ge 0$，两根 $x_1,x_2$ 满足 $$x_1+x_2=-\frac{b}{a},\quad x_1x_2=\frac{c}{a}.$$ - 两根的代数恒等变形（常考）： $$|x_1-x_2|=\sqrt{(x_1+x_2)^2-4x_1x_2}=\frac{\sqrt{\Delta}}{|a|}.$$ $$x_1^2+x_2^2=(x_1+x_2)^2-2x_1x_2.$$ - 以 $y$ 为主元的方程：当联立方程消去 $x$ 得到 $ay^2+by+c=0$ 时，对应 $y_1+y_2=-\frac{b}{a}$，$y_1y_2=\frac{c}{a}$，切勿混淆符号。 - 适用条件：必须保证二次项系数 $a\neq0$ 且 $\Delta>0$（若要求两个不同实根，含直线与二次曲线交于两点等问题）。 - 解析几何中的典型载体： - 弦长：$|AB|=\sqrt{1+k^2}\,|x_1-x_2|$ 或 $|AB|=\sqrt{1+\frac{1}{k^2}}\,|y_1-y_2|$。 - 向量垂直/共线、斜率关系、中点、面积等均可转化为两根和与积的表达式。

解题方法与套路

通用步骤——设而不求+韦达定理 1. 设点与设线：设出交点坐标 $A(x_1,y_1),B(x_2,y_2)$ 和直线方程（一般设为 $y=kx+m$ 或 $x=my+t$，注意优先避开斜率不存在的讨论）。 2. 联立方程：将直线方程代入二次曲线方程，消元得到一元二次方程（该步必须整理成标准形式）。 3. 判别式控制：写出 $\Delta>0$ 保证相交于两点（在定值定点问题中常作为隐含条件列出，不一定要解出范围）。 4. 写出韦达定理：明确写出 $x_1+x_2$ 与 $x_1x_2$（或 $y_1+y_2$ 与 $y_1y_2$）。 5. 转化题意条件：将几何条件（弦长、面积、垂直/共线/共点、分点比等）用坐标表示，代入韦达定理的结果，消去坐标，得到关于直线参数的方程或恒等式。 6. 求解或证明：解出参数，或发现所得表达式与坐标系中某些量抵消，从而得到定值、定点或定直线。

特别地：对于一元二次方程根与系数的选用（如极值点个数问题），则直接根据两根符号、大小关系等条件列不等式组，利用韦达定理将根的性质转化为系数的约束。

高频易错

  1. 忽略二次项系数与判别式：联立后得到的方程，当二次项系数含参数时，必须保证其非零且 $\Delta>0$，否则交点个数不符合题意。
  2. 韦达定理符号记错：$x_1+x_2=-\frac{b}{a}$，负号极易被遗漏，尤其是消 $y$ 后方程整理不规范时。
  3. 混淆横纵坐标的韦达：设直线 $x=my+t$ 消去 $x$ 得关于 $y$ 的二次方程，此时 $y_1+y_2=-\frac{B}{A}$，万不可套用到 $x_1+x_2$ 上。
  4. 弦长公式用错：用 $|AB|=\sqrt{1+k^2}|x_1-x_2|$ 时，$k$ 必须是直线斜率；若直线为 $x=my+t$，则弦长公式为 $\sqrt{1+m^2}|y_1-y_2|$，注意对应关系。
  5. 面积计算遗漏系数：如 $\triangle OAB$ 面积 $S=\frac12 |OF| \cdot |y_1-y_2|$，焦点到准线的距离等几何量容易算错。
  6. 向量条件转化错误：$OA\perp OB \Rightarrow x_1x_2+y_1y_2=0$，不要漏掉 $y_1y_2$，且必须先用直线方程统一变量再代入韦达定理。

代表题精讲

代表题1：2023-新课标Ⅱ-11

题目：函数 $f(x)=a\ln x+\frac{b}{x}+\frac{c}{x^2}\ (a\neq0)$ 既有极大值也有极小值，判断各选项正误。

思路：极值存在必要条件为导数在 $(0,+\infty)$ 上有两个变号零点，转化为导数的分子二次方程有两个不等的正根，利用韦达定理建立 $a,b,c$ 的不等式关系。

步骤： 1. 求导：$f'(x)=\frac{a}{x}-\frac{b}{x^2}-\frac{2c}{x^3}=\frac{ax^2-bx-2c}{x^3}$。 2. $f(x)$ 既有极大值也有极小值 $\Leftrightarrow f'(x)$ 在 $(0,+\infty)$ 有两个变号零点 $\Leftrightarrow$ 方程 $ax^2-bx-2c=0$ 有两个不等的正根 $x_1,x_2$。 3. 条件：$\Delta=b^2+8ac>0$，且 $x_1+x_2=\frac{b}{a}>0$，$x_1x_2=-\frac{2c}{a}>0$。 4. 由 $x_1x_2>0$ 得 $-\frac{2c}{a}>0\Rightarrow ac<0$，故 D 正确。 由 $\Delta>0$ 得 $b^2+8ac>0$，故 C 正确。 由 $x_1+x_2>0$ 且 $x_1x_2>0$ 无法直接推出 $ab>0$ 或 $bc>0$ 若干，进一步分析：$x_1+x_2>0\Rightarrow \frac{b}{a}>0$，又 $ac<0$，得 $ab>0$，结合 $ac<0$ 得 $bc<0$。故 B 正确，A 错误。

点评：极值点个数转化为二次方程正根个数是典型考法，韦达定理沟通了根的性质与系数符号，题目不需解出根，直接判别系数符合即可。

代表题2：2023-新课标Ⅱ-21

题目：双曲线 $\frac{x^2}{4}-\frac{y^2}{16}=1$，过 $(-4,0)$ 的直线交左支于 $M,N$，$M$ 在第二象限，直线 $MA_1$ 与 $NA_2$ 交于点 $P$，证明 $P$ 在定直线上。

思路：设直线 $MN$ 为 $x=my-4$ 避开斜率讨论，联立利用韦达定理表示 $M,N$ 坐标关系；写出两条直线方程并联立求出 $P$ 点横坐标，代入韦达定理化简得定值。

步骤： 1. 由已知得 $A_1(-2,0),A_2(2,0)$，设 $MN: x=my-4$，与双曲线联立消 $x$ 得 $(4m^2-1)y^2-32my+48=0$，$\Delta=64(4m^2+3)>0$ 恒成立。 2. 由韦达定理：$y_1+y_2=\frac{32m}{4m^2-1}$，$y_1y_2=\frac{48}{4m^2-1}$。 3. 直线 $MA_1: y=\frac{y_1}{x_1+2}(x+2)$，直线 $NA_2: y=\frac{y_2}{x_2-2}(x-2)$。 联立求交点：令两方程 $y$ 相等并利用 $x_1=my_1-4,\ x_2=my_2-4$ 代入化简，可得 $$\frac{y_1}{my_1-2}(x+2)=\frac{y_2}{my_2-6}(x-2).$$ 4. 整理得到关于 $x$ 的方程，利用 $y_1+y_2$ 与 $y_1y_2$ 代入，注意保留形式对称。最终解得 $x=-1$，即 $P$ 在定直线 $x=-1$ 上。

点评：典型的设而不求、韦达代换证明定点定直线问题。关键是用 $x=my+t$ 简化运算，交点横纵坐标的转化要熟练，最后代入韦达定理消去参数。

代表题3：2014-文-10

题目：抛物线 $y^2=3x$，焦点为 $F$，过 $F$ 倾斜角为 $30^\circ$ 的直线交于 $A,B$，求 $|AB|$。

思路：写出焦点坐标及直线方程，联立利用韦达定理结合抛物线定义或弦长公式直接计算。

步骤： 1. 焦点 $F(\frac34,0)$，直线方程 $y=\frac{\sqrt3}{3}(x-\frac34)$。 2. 联立 $\begin{cases} y^2=3x \ y=\frac{\sqrt3}{3}(x-\frac34) \end{cases}$，消去 $y$ 得 $16x^2-168x+9=0$。 3. 韦达定理：$x_1+x_2=\frac{168}{16}=\frac{21}{2}$。 4. 由抛物线定义 $|AB|=x_1+x_2+p = x_1+x_2+\frac32 = \frac{21}{2}+\frac{3}{2}=12$。

变式：可将焦点弦长问题转化为 $x_1+x_2$ 的直接求解，无须单独求交点，简洁高效。
