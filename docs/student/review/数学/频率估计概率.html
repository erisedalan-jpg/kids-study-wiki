频率估计概率

考点定位

  • 父主题：概率统计
  • 权重 weight：2
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：解答18
  • 难度分布：易1

知识精要

  • 频率估计概率：在相同条件下进行大量重复试验，事件 $A$ 发生的频率 $\frac{m}{n}$（$n$ 为试验次数，$m$ 为 $A$ 发生的频数）会稳定在某个常数附近，称该常数为事件 $A$ 的概率 $P(A)$。当样本容量足够大且抽样随机时，可用频率作为概率的估计值，即 $P(A)\approx \frac{\text{频数}}{\text{样本容量}}$。
  • 频率分布表与平均值估计：若已知样本取值为 $x_i$ 的频数 $f_i$（或频率 $p_i = f_i/n$），则样本平均数 $\bar{x} = \frac{\sum x_i f_i}{n} = \sum x_i p_i$。当以样本均值估计总体均值时，就是加权平均。
  • 适用条件：随机抽样、样本容量较大、数据分布能代表总体。

解题方法与套路

  1. 审题标量：明确随机事件对应的数据条件（如“不高于”“高于…但不高于…”），在表格或数据中准确圈定符合条件的取值。
  2. 计数求和：从频数分布表中累加符合条件的频数。
  3. 计算频率：频率 $= \frac{\text{满足条件的频数之和}}{\text{总频数}}$，结果可写成分数或小数，作为对应概率的估计值。
  4. 求平均值：将每个取值 $x_i$ 与其频数 $f_i$ 乘积求和，再除以总频数，即 $\bar{x} = \frac{\sum x_i f_i}{\sum f_i}$。结果需带上实际单位或系数（如保费中的 $a$）。
  5. 检验合理性：检查所用频数是否全覆盖条件，有无重复或遗漏。

高频易错

  • 频数≠频率：直接拿频数当概率估计值是典型错误。必须除以总数。
  • 条件区间误判：注意“不高于”含等号，“高于…但不高于…”为左开右闭区间。需把每种取值翻译成保费值再筛选，不可凭印象。
  • 平均保费漏乘系数：保费多以 $a$ 的倍数给出，计算平均保费时先算出倍数平均值，最后乘上 $a$。忘记写 $a$ 会丢失物理意义或单位。
  • 混淆保费与出险次数：保费是由出险次数决定的映射，题目表格中有出险次数与保费的对应关系。求概率时条件针对保费，计算时应以保费数值为准绳去匹配出险次数（进而匹配频数）。
  • 样本量不足：频率估计概率要求 $n$ 足够大，本题给出 $n=200$ 适用，但考生需意识到小样本下频率波动很大，不宜估计概率。

代表题精讲

题目：某险种基本保费为 $a$，续保人本年度保费与上年度出险次数关系如表。随机调查 200 名续保人一年内出险次数，得到频数分布表。
(Ⅰ) 求事件 $A$：“一续保人本年度的保费不高于基本保费”的概率估计值；
(Ⅱ) 求事件 $B$：“保费高于基本保费但不高于基本保费的 160%”的概率估计值；
(Ⅲ) 求续保人本年度的平均保费估计值。

思路：
- 将“保费条件”转化为“出险次数”：
不高于 $a$ → 0 次（$0.85a$）或 1 次（$a$）；
高于 $a$ 但不高于 $1.6a$ → 2 次（$1.25a$）或 3 次（$1.5a$），4 次及以上已超出。
- 从频数表中提取对应频数求和，除以 200 得到频率。
- 平均保费直接用加权平均公式：$\frac{\sum (\text{保费}\times\text{频数})}{200}$。

步骤：
1. 事件 $A$ 对应出险次数为 0,1，频数 $60+50=110$，$P(A)\approx \frac{110}{200}=0.55$。
2. 事件 $B$ 对应出险次数为 2,3，频数 $30+30=60$，$P(B)\approx \frac{60}{200}=0.3$。
3. 各出险次数对应的保费分别为：$0.85a, a, 1.25a, 1.5a, 1.75a, 2a$；频数为 $60,50,30,30,20,10$。
平均保费 $= \frac{0.85a\times60 + a\times50 + 1.25a\times30 + 1.5a\times30 + 1.75a\times20 + 2a\times10}{200}$
$= \frac{a(0.85\times60 + 50 + 1.25\times30 + 1.5\times30 + 1.75\times20 + 2\times10)}{200}$
计算分子：$51 + 50 + 37.5 + 45 + 35 + 20 = 238.5$，
故平均保费 $= \frac{238.5a}{200}=1.1925a$。

点评/变式：
- 本题核心是用样本频率估计概率，切勿写出 $P(A)=0.55$ 的等号（可用“估计值为”或“$\approx$”），但高考评卷通常不苛责符号，稳妥可用 $P(A)$ 的估计值为 $0.55$。
- 平均保费本质是期望的样本估计，若给的是频率而非频数，必须先还原频数或直接用频率加权，避免漏乘总数。
- 变式：可能将出险次数改为连续区间，需用组中值代替；或者将保费调整为分段函数，需精准解读“160%”这样的倍数关系。
