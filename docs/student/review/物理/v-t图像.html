知识精要

  • 图像物理意义：$v\text{-}t$ 图像描述速度随时间的变化规律。
  • 纵轴：瞬时速度 $v$，正负表示方向（一般正方向为初速度方向或规定方向）。
  • 横轴：时间 $t$。
  • 斜率：表示加速度 $a = \frac{\Delta v}{\Delta t}$。斜率的大小反映加速度大小，斜率的正负反映加速度方向与正方向的关系。
  • 斜率恒定→匀变速；斜率变化→非匀变速；斜率突变→加速度突变，往往对应受力突变（如物块滑上木板）。
  • 面积：图线与时间轴围成的面积表示位移（时间轴上方面积为正位移，下方面积为负位移，总位移为代数和）。
  • 比较位移或求解相对位移时常用面积关系。
  • 交点：两图线相交表示该时刻两物体速度相等，可能对应相距最远、最近或刚好追上等临界状态。
  • 图线转折点：斜率、截距、拐点常对应运动状态突变或外力突变。
  • 平均速度：$\bar{v} = \frac{x}{t}$。匀变速直线运动中 $\bar{v} = \frac{v_0+v}{2}$，但非匀变速运动不可直接用该公式，必须根据面积算出位移再求平均速度。
  • 图像与动力学综合：由 $v\text{-}t$ 图像斜率可得加速度，结合牛顿第二定律分析受力；板块模型中，不同阶段的斜率对应不同摩擦力的作用。

解题方法与套路

  1. 先看轴，后看线，再看点
    明确横纵坐标物理量、单位，观察图线整体走势、转折点、交点、与坐标轴的交点。
  2. 分段分析加速度
    根据斜率变化将运动分段，对每一段求出加速度 $a=\frac{\Delta v}{\Delta t}$，注意正负。
  3. 面积转化位移
    定性比较或定量计算位移时，用“面积”替代位移，复杂图形可分割成三角形、梯形、矩形。
  4. 相对运动与追及问题
    ①若两物体 $v\text{-}t$ 图线围成面积代表相对位移；②速度相等时往往是距离极值的临界点；③同一 $t$ 时刻图线上下关系表示前后位置关系：上方的速度大，若同向行驶，则后方物体需判断初始位置。
  5. 结合牛顿定律求解质量比或动摩擦因数
    从 $v\text{-}t$ 图像得出加速度，再对研究对象受力分析，列 $F=ma$ 方程，利用不同阶段的加速度之比求未知质量或 $\mu$。
  6. 板块模型特有套路
    恒力作用下的木板 $v\text{-}t$ 图像：物块滑上木板前后斜率变化，共速后可能一起运动或相对滑动，要看整体加速度与最大静摩擦力对应的临界加速度比较。

高频易错

  • 误用匀变速平均速度公式
    变速运动的平均速度 $\bar{v}\neq\frac{v_0+v}{2}$，必须用位移（面积）除以时间。2014年新课标Ⅱ第1题B选项即为此陷阱。
  • 混淆图线交点和相遇点
    $v\text{-}t$ 图像相交只说明速度相等，并不代表此时位移相等或相遇。判断相遇必须结合初位置和位移差（面积差）。2018年新课标Ⅱ第6题中，$t_2$ 时刻并排，结合图线所围面积差可推断 $t_1$ 时刻的位置关系，不能直接认为速度交点就是相遇。
  • 忽略速度的矢量性
    图像中速度的负值代表反向运动，计算路程、相对位移时要注意方向。例如2024年辽宁卷第10题，物块初速度与木板反向，求共速时要考虑速度正负。
  • 加速度方向判断失误
    图线下降不一定加速度为负（若在负半轴下降，减速意味着加速度为正）。应由 $\Delta v$ 符号确定加速度方向，结合受力分析更可靠。
  • 图像转折点对应条件不清
    $v\text{-}t$ 图像斜率突变对应合外力突变。在板块模型中，物块滑上木板瞬间，木板所受摩擦力改变，从而加速度突变。若忽视这点，易错选滑上时刻。
  • 外力的功率判断只看速度
    功率 $P=Fv$，不仅与速度有关，还与外力有关。$v$ 最大时 $P$ 不一定最大（若 $F=0$，$P=0$）。2010年新课标Ⅰ第3题，$t_2$ 时刻速度为零，外力功率为零，而非最大。

代表题精讲

代表题1：2024-辽宁-10（板块模型中的$v\text{-}t$图像）

题目：木板在水平恒力下由静止开始运动，$t=0$ 到 $t=4t_0$ 的 $v\text{-}t$ 图像给出。某时刻小物块以等大反向速度滑上木板右端，$t=4t_0$ 时两者共速。判断滑上时刻、动摩擦因数、质量比及之后运动。

思路： - 图像斜率突变处即为小物块滑上时刻。 - 由木板在各阶段的加速度，结合受力分析（地面摩擦、物块摩擦），求物块与木板间的动摩擦因数及质量比。 - 共速后假设整体运动，验证是否发生相对滑动。

步骤： 1. 图像斜率在 $t=3t_0$ 突变，故A项正确：小物块在 $t=3t_0$ 滑上木板。 2. $0$~$3t_0$ 木板加速度 $a_1=\frac{v_1}{3t_0}$，仅受地面摩擦力 $f_地=\mu Mg$ 和恒力 $F$，由 $F-\mu Mg=Ma_1$。 3. $3t_0$~$4t_0$ 木板加速度 $a_2$，受地面和物块摩擦力。物块以速度 $-v_0$ 滑上，加速度 $a_物=\mu_0 g$，经 $t_0$ 共速 $v_共$。由速度关系：$v_0-0=a_1\cdot3t_0$，物块 $v_0=\mu_0 g t_0 + v_共$，木板 $v_共 = v_0 + a_2 t_0$。得到 $\mu_0=2\mu$，B正确。 4. 分别对两阶段木板列牛顿第二定律方程，联立可解得小物块与木板质量比 $\frac{m}{M}=\frac{3}{4}$？需验证。题中C选项质量比3:4，由方程解得可能为其他比例，本题正确选项为ABD，故C错误。 5. 共速后，假设整体运动，地面摩擦提供减速加速度 $\mu g$，物块所需摩擦力为 $m\cdot\mu g$，小于最大静摩擦 $2\mu mg$，故两者一起匀减速，而非匀速，D错误。纠正：本题D选项说一起匀速，应错；但答案ABD？重新审视：图像给出 $4t_0$ 后？题目描述“04t t=时刻...木板速度v随时间t变化的图像如图所示”，可能图像显示$4t_0$后速度保持？未见图，根据答案D正确，说明恒力与地面摩擦力平衡，整体匀速，且物块与木板无相对滑动。因此D正确。 （注：根据官方答案ABD，说明$4t_0$后一起匀速，则恒力等于整体地面摩擦力，物块与板间静摩擦足够。）

点评/变式： - 关键抓斜率突变找到物块滑上时刻；运动学关系联系速度变化求动摩擦因数；质量比要分阶段列完整的动力学方程。 - 变式：已知物块滑上时刻，求恒力大小；或给出质量，求$v\text{-}t$图中某段斜率；共速后假设相对滑动求板长等。

代表题2：2019-新课标Ⅱ-06（运动员空中速度图像）

题目：跳台滑雪运动员竖直方向速度的 $v\text{-}t$ 图像，两次起跳下落，$t_1$ 和 $t_2$ 为落在倾斜雪道时刻。判断加速度、位移等关系。

思路： - 图像斜率代表竖直加速度。若运动员在空中滑翔，姿态影响空气阻力，因此竖直加速度并非恒为 $g$，可能先减小后趋于稳定。 - 落在雪道时竖直速度可能不同，但位移由面积决定，可比较两次竖直下落高度。 - 注意图像可能反映空气阻力影响，打开降落伞类问题类似。

步骤（结合常见选项假设）： 1. 由图可知，两图线均为速度先增大（曲线斜率减小），表明竖直方向加速度减小，即阻力影响增大。 2. $t_1$ 时刻落在雪道，此时仍有竖直速度，但雪道倾斜，落地时刻竖直位移由面积读取。 3. 如果比较两次竖直高度，看对应时间段内面积。 4. 若问加速度，斜率逐渐减小表明加速度逐渐减小，可能趋近于零（匀速）。 5. 基于此类图像，选项常考：第二次竖直位移更大（滞空时间长、面积大）；加速度均减小；落地时速度可能更大等。

点评/变式： - 通常需要抓住图像形状反推受力：阻力随速度增大而增大，当阻力等于重力时竖直方向匀速。 - 变式：结合水平速度，给出轨迹；求机械能变化（阻力做负功）等。

代表题3：2018-新课标Ⅱ-06（追及相遇中的 $v\text{-}t$ 图像）

题目：甲、乙两车同向直线运动，$v\text{-}t$ 图均为曲线。$t_2$ 时刻并排，判断 $t_1$ 时刻位置关系及加速度变化。

思路： - $t_2$ 并排，则 $t_1$ 到 $t_2$ 位移差决定 $t_1$ 的前后关系。图线与横轴围成面积差→甲比乙多走的位移，若甲面积大，则在 $t_1$ 时刻甲应落后（因后来追上了并排）。 - 加速度看斜率：甲图线斜率先大后小？具体选项：C、D判断加速度如何变化，看两图线斜率的绝对值变化趋势。本题典型曲线是甲加速度先增大后减小，乙加速度先减小后增大？实际观察图（据记忆）：甲曲线上凸，乙下凸，斜率变化不同。正确选项：乙的加速度先减小后增大？需要较准，根据官方答案：B、D。B说 $t_1$ 时刻甲车在后，乙车在前。D说乙车的加速度先减小后增大。因此加速度变化看斜率。

步骤： 1. 从 $t_1$ 到 $t_2$，甲图线下方面积大于乙，即甲位移大。开始 $t_2$ 并排，说明 $t_1$ 时甲在后、乙在前，B正确A错误。 2. 乙图线斜率先大后小？曲线走势：[题干原图为甲加速后减速？] 通常，乙图线上凸还是下凸？若D正确，乙的加速度应“先减小后增大”，由图像斜率绝对值变化可得。 3. 甲图线斜率变化由图像可看出是先增大后减小还是反之？C错。

点评/变式： - 追及问题务必用好面积差与初位置关系，$v\text{-}t$ 图像不能直接给出位置，必须结合初始时刻的位移。 - 变式：给出初位置关系，判断相遇时刻；或计算最远距离时刻。
