万有引力定律

知识精要

  • 万有引力定律：$F=G\frac{m_1m_2}{r^2}$，适用于质点或均匀球体（此时 $r$ 为两球心距离）。
  • 重力与万有引力的关系：
    1. 两极（无自转）：$mg_0 = G\frac{Mm}{R^2}$。
    2. 赤道（考虑自转）：$G\frac{Mm}{R^2} - mg = m\omega^2 R = m\frac{4\pi^2}{T^2}R$。
    3. 一般位置：重力是万有引力的一个分力，另一个分力提供随地球自转的向心力。
    4. 天体表面（忽略自转）：$mg = G\frac{Mm}{R^2} \Rightarrow GM=gR^2$（黄金代换）。
  • 天体运动核心方程：$G\frac{Mm}{r^2} = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2}r = ma_n$。
  • 开普勒定律：
    1. 轨道定律：轨道为椭圆，太阳位于焦点。
    2. 面积定律：$v_P > v_Q$，$t_{近\to远} > t_{远\to近}$，引力做功改变速率，机械能守恒。
    3. 周期定律：$\frac{a^3}{T^2} = k$ （$a$ 为半长轴，中心天体决定 $k$）。
  • 天体密度推导：
    • 近地卫星：$\rho = \frac{3\pi}{GT^2}$。
    • 稳定自转不瓦解的临界条件：$G\frac{Mm}{R^2} = m\frac{4\pi^2}{T^2}R$，结合 $\rho = \frac{M}{\frac{4}{3}\pi R^3}$，得最小密度 $\rho = \frac{3\pi}{GT^2}$。
    • 地表重力加速度法求密度：$g_0 = G\frac{M}{R^2}$，结合体积公式。
  • 引力势能：相对无穷远为负值，随距离增大而增大。引力做正功，势能减小；引力做负功，势能增大。
  • 同步卫星：周期等于地球自转周期，轨道半径约 $4.2 \times 10^4$ km（距地面约36000 km），角速度等于地球自转角速度。
  • 质量均匀球壳：对壳内物体引力为零。

解题方法与套路

  1. 天体质量密度求解：
  2. “地表法”：利用 $mg = G\frac{Mm}{R^2}$，得 $M=\frac{gR^2}{G}$，再由 $\rho=\frac{M}{V}$ 求密度。
  3. “环绕法”：利用 $G\frac{Mm}{r^2} = m\frac{4\pi^2}{T^2}r$，得 $M=\frac{4\pi^2 r^3}{GT^2}$，结合体积求密度。若为近地（$r\approx R$），则 $\rho=\frac{3\pi}{GT^2}$。
  4. “临界自转法”：处于“瓦解”临界时，赤道物体引力全部提供向心力，联立 $G\frac{Mm}{R^2}=m\frac{4\pi^2}{T^2}R$ 与密度公式求极值。

  5. 常用比例：由 $g = G\frac{M}{R^2}$ 和 $\rho = \frac{M}{\frac{4}{3}\pi R^3}$，得 $g \propto \rho R$。

  6. 轨道参量比较与运算：

  7. 牢记“越高越慢”原则：轨道半径 $r$ 越大，$v$ 越小，$\omega$ 越小，$a_n$ 越小，$T$ 越大。
  8. 宇宙速度：$v_1=7.9$ km/s（最大环绕/最小发射），$v_2=11.2$ km/s，$v_3=16.7$ km/s。
  9. 赤道物体、近地、同步卫星区分：轨道半径排序 $r_{赤道物体}=R_{地} < r_{近地} \ll r_{同步}$。

  10. 利用开普勒第三定律进行周期/半径的比例计算，注意是同一天体系统。

  11. 变轨与能量问题：

  12. 椭变圆：在远日点（远地点）加速变高轨圆，在近日点（近地点）减速变低轨圆。
  13. $E_{机械能} = E_k + E_p$，高轨道总机械能更大（$E_p$ 增大超过 $E_k$ 减小）。

  14. 稀薄大气阻力使卫星 $r$ 缓慢减小，引力做正功导致动能增加（速度变大），但机械能减少。

  15. 特殊物理模型处理：

  16. 弹簧振子结合：注意简谐运动的平衡位置在受力平衡点（弹簧弹力=重力），而不是弹簧原长。利用对称性（$k\Delta x = mg$ 等）分析加速度、形变量。
  17. 星体遮挡信号：化为几何问题，利用切线、圆心角、弧长，结合运动周期求解时间。

高频易错

  • 混淆“距离”与“半径”：万有引力公式 $F=G\frac{Mm}{r^2}$ 中的 $r$ 是球心距。若题干给的是距地面高度 $h$，必须用 $r=R+h$ 代入，切忌直接代入 $h$。
  • 误判“完全失重”为“不受引力”：空间站中的物体完全失重，是指引力全部提供向心力，$F_引 = m\omega^2 r$，引力本身并不为零，且远大于地面上的向心力。
  • 地表与高空引力大小比较：同一物体，$F_引 \propto \frac{1}{r^2}$，地表离地心近，所受引力大于高轨道处引力。
  • 卫星受阻力动态误区：大气阻力使卫星减速，并非直接导致动能减小。因为阻力做负功，轨道半径变小，引力势能转化为动能，结果动能反而增大，但总机械能减小。
  • 质量不随位置改变：经典力学中，质量是物体的固有属性，不随重力加速度变化。
  • 同步卫星高度估算：同步卫星轨道半径约 4.2 万公里，是地球半径（6400 km）的约 6.6 倍，地月距离（38 万公里）约为其半径的 9 倍，可据此比例进行快速估算。
  • 开普勒定律误用：椭-圆轨道混合命题中，$Q\to N$ 运动是先远离近日点，速率减小，引力做负功，经历的时间与速率有关，不能简单认为是四分之一周期。

代表题精讲

代表题1：2024-辽宁-07（弹簧振子测密度）

题目：将小球从弹簧原长处由静止释放，分别在地球与某天体表面简谐运动。图像显示平衡位置弹簧伸长量关系。地球半径是天体半径的 n 倍，求二者平均密度之比 $r_1/r_2$。

思路：核心在于建立简谐运动平衡位置与表面重力加速度的关系，再由 $g$ 引入天体密度。根据图像信息找到两星球下平衡位置弹簧伸长量的数量关系，结合黄金代换 $GM=gR^2$ 和密度定义求解。

步骤： 1. 设地球表面重力加速度为 $g$，天体表面为 $g'$。根据简谐运动受力平衡，有 $k x_0 = mg$，故 $\frac{g}{g'} = \frac{x_0}{x_0'}$。 2. 由黄金代换 $GM = gR^2$，代入 $M = \rho \cdot \frac{4}{3}\pi R^3$ 得： $G\rho \cdot \frac{4}{3}\pi R^3 = g R^2 \Rightarrow g \propto \rho R$。 3. 因此有：$\frac{g}{g'} = \frac{r_1 R}{r_2 R'} = \frac{r_1}{r_2} \cdot n$。 4. 联立两式：$\frac{r_1}{r_2} \cdot n = \frac{x_0}{x_0'}$。 由题干图像（a）可知，弹簧原长时释放，地球表面振幅 $A = 4dx_1$，平衡位置形变量 $x_0=2dx_1$；天体表面振幅 $A'=2dx_2$，平衡位置形变量 $x_0'=dx_2$。 根据图像纵坐标比例可推得 $dx_1$ 与 $dx_2$ 的关系，或直接由图读出 $x_0$ 与 $x_0'$ 的比例。关键信息：图像显示天平平衡伸长量为地球的 1/2，即 $x_0 / x_0' = 2$。 5. 所以 $\frac{r_1}{r_2} \cdot n = 2 \Rightarrow \frac{r_1}{r_2} = \frac{2}{n}$。

点评：此题巧妙结合力学与天体，关键是平衡位置对应重力，勿混淆原长。变式可考察双星系统、不同行星表面弹簧振子周期之比。

代表题2：2023-新课标-04（近地轨道物资）

题目：天舟六号携带物资对接空间站后，轨道高度约400 km（小于同步卫星高度），物资与静止地面时对比： A.质量；B.合力；C.引力；D.角速度。

思路：逐个选项物理本质分析。质量是标量；合力看状态（地面静止合力为0，太空做圆周运动合力为向心力）；引力由位置决定；角速度可用高低轨道的运动参量比较。

步骤： 1. A错：质量在低速宏观下不变。 2. B错：地面合力为零；太空受引力全部作为向心力，合力不为零且不为小（$F_{合} = \frac{GMm}{(R+h)^2}$）。 3. C错：由 $F_{引}=G\frac{Mm}{r^2}$，$r_{地} < r_{太空}$，故地面引力大于太空引力。 4. D对：由 $G\frac{Mm}{r^2}=m\omega^2 r \Rightarrow \omega = \sqrt{\frac{GM}{r^3}}$，太空轨道 $r$ 小于同步卫星轨道 $r_{同}$，则 $\omega_{太空} > \omega_{同} = \omega_{自转}$。

点评：本题针对考生“认为失重就是不受力”的典型迷思精准打击。牢记完全失重是指视重为零，合力（万有引力）不为零。

代表题3：2022-全国乙-01（空间站漂浮）

题目：近地圆轨道空间站中，航天员自由漂浮，表明（ ） A.引力近似为零；B.飞船作用力平衡引力；C.引力约等于向心力；D.地面引力小于太空向心力。

思路：考察完全失重的动力成因。空间站及内部物体均只受引力，且完全用于提供绕地飞行的向心力。$F_{引} = m a_n$，故相互挤压的作用力消失。

步骤： 1. A错：航天员在空间站受地球引力（设该处重力加速度 $g'$），$F_{引}=mg'$，不可忽略。 2. B错：飞船对航天员作用力（弹力）几乎为零，不是平衡引力的合力。 3. C对：引力全部提供向心力，二者大小相等。 4. D错：地面引力 $F_1=\frac{GMm}{R^2}$，太空向心力 $F_2=\frac{GMm}{(R+h)^2}$，有 $F_2 < F_1$。

点评：完全失重环境的第一特征就是 $F_{引}=F_{向}$，其余接触力为零。注意区分地面与高空引力大小。
