中心天体质量

考点中心天体质量权重5真题数1学科物理父主题万有引力 与 天体

考点定位

  • 父主题：万有引力 与 天体
  • 权重 weight：5
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 中心天体质量求解依据
    环绕天体在中心天体的万有引力作用下做匀速圆周运动（或椭圆运动），由牛顿第二定律与万有引力定律结合开普勒第三定律可求中心天体质量。
    圆周运动：$G\frac{Mm}{r^2}=m\frac{4\pi^2}{T^2}r \;\Rightarrow\; M=\frac{4\pi^2 r^3}{GT^2}$
    椭圆轨道（开普勒第三定律）：$\frac{a^3}{T^2}=\frac{GM}{4\pi^2}$，其中$a$为半长轴。

  • 比值法（地日系统参照）
    当题目不直接给出$G$值，而是与太阳质量$M_\odot$、地球公转轨道（$a_\oplus=1\,\text{AU}$，$T_\oplus=1\,\text{年}$）比较时，利用开普勒第三定律比例式：
    $$\frac{M}{M_\odot} = \frac{a^3/T^2}{a_\oplus^3/T_\oplus^2} = \left(\frac{a}{1\,\text{AU}}\right)^3 \left(\frac{1\,\text{年}}{T}\right)^2$$ 只需获取环绕天体的半长轴$a$和公转周期$T$即可快速估算中心天体质量。

  • 适用条件
    仅考虑中心天体引力（忽略其它天体作用）；环绕天体质量远小于中心天体质量；已知环绕天体的轨道参数（$a$、$T$或等效信息）。

解题方法与套路

  1. 明确环绕系统和参考系
    认准研究对象（某星体绕某黑洞/恒星），看题中是否给出地-日系统作为参考（$1\,\text{AU}$，$1\,\text{年}$），若给出直接选用比值法。

  2. 提取或推断轨道参量

  3. 半长轴$a$：题中可能直接给出数值及单位（如$\text{AU}$）。

  4. 周期$T$：常通过轨迹图、时间跨度与位置变化推断。注意区分一个完整周期与时间段的关系——如图中从某位置出发回到同位置为$1$个周期，从一端到对面为半个周期。

  5. 代入开普勒第三定律比值公式
    $$\frac{M}{M_\odot} = \frac{a^3/T^2}{1^3/1^2} = \frac{a^3}{T^2}$$ 其中$a$单位为$\text{AU}$，$T$单位为年。算出倍数后根据选项确定数量级。

  6. 计算与检验
    快速估算数量级（如$a=10^3$，$a^3=10^9$，若$T\approx 16$年，$T^2\approx 256$，比值为$4\times10^6$）。结合选项排除数量级偏差。

高频易错

  • 周期判断错误
    给定轨迹图往往只展示一段时间内的部分轨道，易将半个周期或不足一个周期的时间当成完整周期。务必根据位置对称性判断已完成圈数。真题中1994~2002年约8年，轨迹显示恰好走过半个椭圆，周期$T\approx 16$年。

  • 单位混用
    比值法中必须统一：半长轴用$\text{AU}$，周期用年，与地日系统一致；若用米、秒则须代入$G$值计算。

  • 错选公式形式
    开普勒第三定律的正确形式为$\frac{a^3}{T^2}=\frac{GM}{4\pi^2}$，比例时系数约掉，但部分同学误写成$T^2\propto a^3$后漏掉质量因子或忘记比值对象。

  • 计算粗心
    数量级乘除错误，特别是$10^9$除以几百时，数量级容易少或多一个零，须细心比对选项。

  • 误用环绕天体质量
    中心天体质量由轨道参数唯一确定，与环绕天体自身质量无关。题目给出太阳质量仅作参照。

代表题精讲

题目

2021全国乙卷·第5题：科学家对银河系中心恒星S2持续观测，1994~2002年间的轨迹为半长轴约$1000\,\text{AU}$的椭圆，推测其受银河系中心大质量黑洞引力作用。已知太阳质量为$M$，估算该黑洞质量约为（　　）

思路

将S2绕黑洞椭圆运动与地球绕太阳圆周运动对比，利用开普勒第三定律比例关系。关键是从“1994到2002年”及椭圆轨迹图推断S2的公转周期（图呈半椭圆，历时约8年，故周期约16年）。半长轴已知为$1000\,\text{AU}$。由比例式直接求黑洞质量相对于太阳质量的倍数。

步骤

  1. 确定轨道参数：
    半长轴 $a_{\text{S2}} = 1000\,\text{AU}$；
    图中1994~2002年经历半椭圆，即半个周期 $\Delta t = 8\,\text{年}$，故周期 $T_{\text{S2}} = 16\,\text{年}$。

  2. 开普勒第三定律比值：
    地球：$a_\oplus=1\,\text{AU}$，$T_\oplus=1\,\text{年}$，中心天体太阳质量$M_\odot = M$。
    S2系统：中心天体黑洞质量 $M_{\text{BH}}$，满足
    $$\frac{a_{\text{S2}}^3}{T_{\text{S2}}^2} \propto M_{\text{BH}} ,\quad \frac{a_\oplus^3}{T_\oplus^2} \propto M_\odot$$
    因此
    $$\frac{M_{\text{BH}}}{M} = \frac{a_{\text{S2}}^3 / T_{\text{S2}}^2}{1^3 / 1^2} = \frac{1000^3}{16^2} = \frac{10^9}{256} \approx 3.9 \times 10^6$$

  3. 对照选项：约为$4\times10^6\,M$，选择相应选项。

点评与变式

本题核心是“看图定周期”和“比例法”，若考生误将8年当周期，则得$M_{\text{BH}}/M = 10^9/64 \approx 1.6\times10^7$，数量级偏差可能被选项区分。
变式：若S2半长轴变为$5000\,\text{AU}$，周期为$200$年，则黑洞质量约为多少倍太阳质量？
由比例式：$5000^3 / 200^2 = (1.25\times10^{11}) / (4\times10^4) = 3.125\times10^6$，仍为百万倍量级。熟练掌握比值法可快速应对任何给定轨道参数的估测问题。
