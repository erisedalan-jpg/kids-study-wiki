知识精要

临界条件是高考物理的高频考点，贯穿力学、电学、光学等板块，其核心为“恰好发生”或“恰好不发生”的转折状态。解决临界问题本质上就是把物理现象从“量变”推向“质变”的瞬间用方程锁定。

  • 基本定义：当某一物理量（如速度、角度、力、位移等）达到某一特定值时，物理过程发生突变（如相对滑动、脱离、全反射、刚好追不上等），此特定值即为临界值，该状态为临界状态。
  • 临界条件的常见表达：
  • “刚好不脱离”——弹力（支持力）恰为零或速度恰为共速。
  • “刚好相对滑动”——两物体间静摩擦力达到最大静摩擦力，且加速度仍相同。
  • “刚好发生全反射”——入射角等于临界角 $C$，满足 $\sin C = \frac{1}{n}$。
  • “刚好穿出（或打不到）”——粒子运动轨迹与边界相切。
  • “刚好追上（或追不上）”——两者速度相等时恰处于同一位置（或后者的速度仍不大于前者）。
  • “最小推力”“最短距离”——将临界条件反向代入物理规律求极值。
  • 常用定理/公式适用条件：
  • 牛顿第二定律：$F_\text{合}=ma$，受力分析找临界力（如最大静摩擦力 $f_\text{max}=\mu N$）。
  • 动量守恒定律：合外力为零或某一方向外力为零，注意速度的矢量性（正方向选取）。
  • 能量守恒/动能定理：用于与速度、高度相关的临界值（如刚好滑到最高点）。
  • 平抛运动规律：水平 $x=v_0 t$，竖直 $v_y=gt$（或 $v_y^2=2gh$），速度偏向角 $\tan\phi=\frac{v_y}{v_0}$。
  • 全反射条件：光密到光疏，入射角 $\ge$ 临界角。
  • 适用条件提炼（真题指向）：临界问题贯穿运动过程分析，必须分清“临界”前后的物理规律差异（如摩擦力性质突变、动量守恒的系统选择），并在临界点建立等量或不等量关系，再结合几何关系求极值。

解题方法与套路

临界问题的解答遵循“识临界、列方程、转极值”三步，以下为跨真题提炼的通用解法：

  1. 审视“题眼”，锁定临界状态
    圈出“最小”“最大”“刚好”“至少”“不能”等字眼，明确题中所求临界量对应的物理情景。如“抛出速度最小”对应石子接触水面时速度方向与水面的夹角恰好等于 $\theta$；“反弹的物块不能再追上”对应第8次推出后运动员速度恰大于等于物块速度。

  2. 分析临界瞬间的物理关系
    找到临界状态下的特殊条件：

  3. 动力学临界：两物体加速度相等且摩擦力达到极值。
  4. 动量临界：某次作用后二者的速度满足恰好追上/分离的条件。
  5. 轨迹临界：粒子运动圆弧与边界相切，利用几何关系找半径 $R$ 与边界尺寸的关系。

  6. 光学临界：折射光刚好掠过界面（折射角 $90^\circ$）或发生全反射。

  7. 建立临界方程，转不等式为等式
    将临界条件写入物理规律：

  8. 运动学：如 $\tan\theta = \frac{v_y}{v_{0\min}}$。
  9. 动量守恒：如第 $n$ 次推出后 $v_n = \frac{(2n-1)mv}{M}$，再根据 $v_7<v \le v_8$ 列不等式求解 $M$ 范围。
  10. 几何关系：磁场中轨迹相切时，利用弦长、半径与磁场宽度的几何勾连。

  11. 光学：从点光源发出的光在表面刚好全反射，计算镀膜的最小面积等于满足全反射条件的球冠面积。

  12. 求解并验证范围
    由方程求出临界值的表达式或数值。若涉及区间，注意临界点归属（“能不能”的边界是否包括等号），依据题意规定最终范围。

  13. 归纳法与周期性过程的处理（特例）
    对多次重复的临界问题（如多次推物块），通过写出前几次过程的递推关系，用数学归纳法导出通项公式，再将临界次数代入不等式求解。

高频易错

  • 混淆“临界摩擦力”性质：临界状态下静摩擦力达到 $\mu_s N$，其后变成滑动摩擦力 $\mu_k N$，若题中明示 $\mu_s=\mu_k$ 则可统一用 $\mu$，但必须注意相对滑动瞬间摩擦力的方向仍为阻碍相对运动。
  • 平抛速度方向与水面夹角的误认：速度方向与水平夹角 $\alpha$ 和与水面（即竖直方向？——水面是水平面，夹角是速度与水面即水平面的夹角）注意 $\tan\theta = v_y/v_x$，并非其余弦或正弦，容易错把 $\theta$ 当成与竖直方向的角。
  • 动量守恒的速度方向选取：多次推物块时，每次推之前物块与人的速度方向可能相反，不可随意忽视正方向规定，所有速度代入时必须保证矢量性，否则符号错乱导致归纳错误。
  • 全反射镀膜面积：点光源在立方体中心，镀膜区域应是球面对应立体角在立方体表面的投影。易错将“最小面积”理解为整个面镀满，或忘记光源在中心导致各方向对称，几何关系复杂。
  • 磁场临界“相切”的几何盲区：粒子恰好穿过y轴正半轴，并非轨迹与x轴相切，而是轨迹与y轴相切或恰好从边界点出来，需仔细画图。对于磁场方向判断，洛伦兹力提供向心力，偏转方向决定磁场方向，漏判会导致临界条件丢失。
  • 板块模型临界力F的突变：在图（c）中木板加速度突变时刻对应物块与木板刚好发生相对滑动，此时拉力 $F$ 满足 $F-\mu_2 m_2 g = m_2 a$ 与整体方程联立，易只分析单一物体而漏掉加速度相等的临界关系。
  • “刚好不能追上”为速度相等时仍追不上：冰块与斜面体分离后，判断能否追上小孩，需计算分离后冰块的速度，若其不大于小孩的速度则不能追上，不能想当然认为质量小的就能追上。

代表题精讲

题目（2023-新课标-11）

从距水面高度 $h$ 处水平抛出扁平石子，要产生“水漂”效果，石子接触水面时的速度方向与水面的夹角不能大于 $\theta$，不计空气阻力，求抛出速度的最小值。

思路
临界状态对应石子落至水面瞬间，速度方向与水面的夹角恰好等于 $\theta$。平抛运动竖直速度为 $v_y=\sqrt{2gh}$，水平速度即所求最小抛出速度 $v_{0\min}$。由速度矢量图得 $\tan\theta = \frac{v_y}{v_{0\min}}$，解出 $v_{0\min}$。

步骤
1. 石子做平抛运动，下落高度 $h$，竖直分速度满足 $v_y^2 = 2gh$，故 $v_y = \sqrt{2gh}$。
2. 接触水面时速度方向与水面的夹角为 $\theta$，即 $\tan\theta = \frac{v_y}{v_x}$，其中 $v_x = v_{0\min}$。
3. 当夹角恰为临界值 $\theta$ 时，抛出速度最小，代入得 $\tan\theta = \frac{\sqrt{2gh}}{v_{0\min}}$。
4. 解得 $v_{0\min} = \frac{\sqrt{2gh}}{\tan\theta}$。若用余切可写为 $\sqrt{2gh}\,\cot\theta$。
5. 故抛出速度的最小值为 $\frac{\sqrt{2gh}}{\tan\theta}$。

点评/变式
此题将临界条件隐藏在生活情景“水漂”中，实质是平抛运动速度偏向角的极值。变式可改为“抛出速度固定，求最大高度”或“限定抛出角度，求落水时夹角”，解法核心均为建立速度矢量三角形与临界角度等式。

题目（2020-新课标Ⅱ-08）

质量为 $M$ 的运动员静止在冰面，将质量 $m=4.0\,\text{kg}$ 的物块以 $v=5.0\,\text{m/s}$ 推向竖直挡板，物块弹回后运动员再次以同大小速度推出。不计摩擦，经过8次推出后运动员退行速度大于 $5.0\,\text{m/s}$ 且物块不能再追上，求运动员质量可能值（选项 $48\text{kg},53\text{kg},58\text{kg},63\text{kg}$）。

思路
每次推的过程动量守恒，且物块与挡板弹性碰撞后速度反向。取人运动方向为正，利用数学归纳法导出第 $n$ 次推出后运动员速度 $v_n = \frac{(2n-1)mv}{M}$。根据“第7次推出后还能再推（即 $v_7 < v$），第8次推出后不能再推（即 $v_8 \ge v$）”列出不等式，解出 $M$ 范围。

步骤
1. 规定人退行方向为正。第一次推出：$0 = Mv_1 - mv$，得 $v_1 = \frac{mv}{M}$。
2. 第二次推出前，人已具有 $v_1$，物块以速度 $(-v)$ 反弹后被接住，人、物块共同速度变为 $v_1$（接住过程动量守恒可不计，因只关心每次推出的瞬间）。推出过程：$Mv_1 + mv = Mv_2 - mv$，解得 $v_2 = \frac{3mv}{M}$。
3. 依此类推，第 $n$ 次推出满足 $Mv_{n-1} + mv = Mv_n - mv$，整理得 $v_n = v_{n-1} + \frac{2mv}{M}$，结合首项得 $v_n = \frac{(2n-1)mv}{M}$。
4. 第7次推出后还能再推，要求 $v_7 < v$（否则物块追不上人，无法进行下一次），即 $\frac{(2\times7-1)mv}{M} < v \;\Rightarrow\; \frac{13mv}{M} < v \;\Rightarrow\; M > 13m = 52\,\text{kg}$。
5. 第8次推出后物块不能再追上，要求 $v_8 \ge v$，即 $\frac{(2\times8-1)mv}{M} \ge v \;\Rightarrow\; \frac{15mv}{M} \ge v \;\Rightarrow\; M \le 15m = 60\,\text{kg}$。
6. 综上 $52\,\text{kg} < M \le 60\,\text{kg}$，对照选项，B（53kg）和C（58kg）在此范围内，A、D错误。

点评/变式
本题是典型的多次作用临界问题，关键在于正确递推和读懂“不能追上”的临界条件（人、物块速度相等时物块刚好无法再次接触）。变式可改为“物块质量未知”“给定质量求最多能推几次”，解法思路相同，需注意数学归纳法的符号和取等。
