二极管正向电阻

考点二极管正向电阻权重5真题数1学科物理父主题恒定电流

考点定位

  • 父主题：恒定电流
  • 权重 weight：5
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 二极管正向电阻特性：硅二极管在正向导通时，其电阻并非定值，会随温度升高而明显减小（负温度系数）。
  • 恒定电流控制：在二极管所在支路串联一个已知阻值的定值电阻 $R_0$。调节回路电压（如滑动变阻器），使 $R_0$ 两端电压 $U_0 = I_0 R_0$（$I_0$ 为目标恒定电流），即可保证流过二极管的电流恒为 $I_0$。
  • 正向电压‑温度关系：在恒定正向电流下，硅二极管两端的正向电压 $U$ 随温度 $t$ 线性减小，表达式可记为 $U = U_0 – k(t-t_0)$，其中 $k = \left|\frac{\Delta U}{\Delta t}\right|$ 为测温灵敏度。
  • 测温灵敏度：$$S = \left|\frac{\Delta U}{\Delta t}\right| = \frac{|U_2 – U_1|}{|t_2 – t_1|}$$ 单位一般为 $\text{V/℃}$ 或 $\text{mV/℃}$，计算时注意有效数字。

解题方法与套路

  1. 识别电压表作用：根据电路串并联关系，明确各电压表测量对象（常为一个测定值电阻 $R_0$ 获取电流信号，另一个测二极管正向电压 $U$）。
  2. 应用欧姆定律求控制电压：利用 $U_0 = I_0 R_0$ 算出目标电压，调节滑动变阻器使该电压表达到示数即可。
  3. 分析电阻变化对电路的影响（滑动变阻器未动时）：
  4. 二极管正向电阻变小 → 总电阻变小 → 干路电流变大 → $R_0$ 两端电压 $U_0$ 变大。
  5. 二极管正向电压 $U_D$ = 电源路端电压 - $U_R$ - $U_0$，结合数据判断变化。
  6. 恒定电流的恢复操作：
  7. 若 $U_0$ 变大，需减小电流以恢复原值，应使滑动变阻器接入电阻增大（滑片向有效阻值增大的方向移动）；若 $U_0$ 变小，则减小接入电阻。
  8. 可根据滑动变阻器的接线方式，判断滑片向哪端移动才能增大或减小电阻。
  9. 读取图象求灵敏度：在 $U\text{-}t$ 图线上取较远的两点，计算斜率绝对值：$\left|\frac{\Delta U}{\Delta t}\right| = \frac{U_{\text{高}} - U_{\text{低}}}{t_{\text{高}} - t_{\text{低}}}$，结果保留两位有效数字或按题目要求。

高频易错

  • 混淆两个电压表的示数变化：误认为二极管正向电压表在温度升高时也会“增大”。实际正向电阻变小，若电流恒定，其电压一定减小；若未恒定，需结合电路整体分析。
  • 滑动变阻器滑片移动方向判断错误：不画简化电路分析，凭感觉选 A 或 B。应明确：要增大电阻，滑片需远离下接线柱（或向电阻丝变长的方向移动）。
  • 误把正向电阻当作普通定值电阻：二极管的正向电阻随温度升高而减小，与金属热电阻的 PTC 特性相反。
  • 灵敏度有效数字错误：图象读取数据时，用粗糙估读，导致结果只有 1 位有效数字或与要求不符。应按题目有效数字位数保留。
  • 电路调节顺序理解错位：认为“温度升高→二极管电阻变小→直接调节 R 使电流恒定”而忽略中间过程电压表示数先发生变化的事实。

代表题精讲

代表题：2019‑新课标Ⅱ‑10

题目：某小组研究硅二极管在恒定电流 $50.0\,\mu\text{A}$ 下的正向电压 $U$ 与温度 $t$ 的关系。电路如图，$R$ 为滑动变阻器，$R_0=100\,\Omega$ 为定值电阻，两理想电压表分别测 $R_0$ 和二极管两端电压。图（b）为 $U\text{-}t$ 关系曲线。回答：（1）为使电流恒为 $50.0\,\mu\text{A}$，电压表 $V_1$ 的示数应为多少？升温时二极管正向电阻如何变？另一电压表示数如何变？为保持 $V_1$ 示数不变，滑片向哪端移？（2）求测温灵敏度（保留两位有效数字）。

思路：本题核心是用串联定值电阻监控电流。先由欧姆定律求控制电压 $U_1$；从图象得出温度升高 $U$ 减小，结合恒定电流知正向电阻 $R_D=U/I$ 减小；温度升高瞬间未调 $R$，总电阻减小→电流增大→$V_1$ 示数增大，为了使 $U_1$ 回到 $5.00\,\text{mV}$ 需增大 $R$，判断接线确定滑片移动方向；灵敏度从图线上取两点计算斜率绝对值。

步骤： 1. 求 $V_1$ 示数：$I = 50.0\,\mu\text{A} = 5.00 \times 10^{-5}\,\text{A}$，$U_1 = I R_0 = 5.00 \times 10^{-5} \times 100 = 5.00 \times 10^{-3}\,\text{V} = 5.00\,\text{mV}$。 2. 由图（b）知 $U$ 随 $t$ 升高而减小，因 $I$ 恒定，$R_D = U/I$，故正向电阻变小。 3. 升温瞬间（未调 $R$）：$R_D$ 减小→回路总电阻减小→电流 $I$ 增大→$R_0$ 两端电压 $U_1$ 增大。 4. 要恢复 $U_1 = 5.00\,\text{mV}$ 需减小电流，应增大滑动变阻器接入阻值。若滑片向 $B$ 端移动时电阻变大，则滑片移向 $B$（具体需对照电路接线，本题答案为 B）。 5. 求灵敏度：取图线上两点，如 $(t_1, U_1) = (0\,^\circ\text{C}, 0.44\,\text{V})$ 和 $(t_2, U_2) = (80\,^\circ\text{C}, 0.22\,\text{V})$，则斜率绝对值 $$S = \frac{0.44-0.22}{80-0} = \frac{0.22}{80} = 0.00275\,\text{V/℃} = 2.8 \times 10^{-3}\,\text{V/℃}$$ 保留两位有效数字得 $2.8 \times 10^{-3}\,\text{V/℃}$。

点评/变式：此题融合了电学实验与传感器原理。关键模型是“恒流源”的替代——用电压表和定值电阻构成的电流反馈。类似变式：研究二极管的恒定正向电流下 $U\text{-}t$ 关系，可将二极管换为热敏电阻（NTC/PTC）、铂热电阻等，分析方法一致。若考查光电二极管、反向饱和电流等，注意区分。计算灵敏度时，务必从图线读取准确坐标，减少估算误差
