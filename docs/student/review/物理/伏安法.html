伏安法

考点伏安法权重8真题数1学科物理父主题实验 与 测量

考点定位

  • 父主题：实验 与 测量
  • 权重 weight：8
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 伏安法原理：用电压表测两端电压 $U$，电流表测通过电流 $I$，由部分电路欧姆定律 $R = \frac{U}{I}$ 求待测电阻。属于间接测量。
  • 测量电路的选择
  • 电流表内接法：电流表在电压表测量回路内，$R_{\text{测}} = R_x + R_A$，测量值偏大，适用于 $R_x \gg R_A$（大电阻）。
  • 电流表外接法：电压表直接并联在待测电阻两端，电流表在干路，$R_{\text{测}} = \frac{R_xR_V}{R_x+R_V}$，测量值偏小，适用于 $R_x \ll R_V$（小电阻）。
  • 试触法：改变电流表接法，观察两只电表示数变化的显著程度，变化大的外接或内接选择对应待测电阻与电表内阻的相对关系，从而确定接法。
  • 滑动变阻器接法
  • 限流式：串联在回路中，调节范围较小，节能，适合无需从零开始的场景。
  • 分压式：与电源并联，电压从零开始连续可调，适合要求电压调节范围宽、小电阻控制大电流等。
  • 实物连线规则：先串联主干回路（电源→开关→滑动变阻器→电流表→待测电阻），再并联电压表；注意电表正负接线柱（电流“正入负出”）和量程；连线不得交叉；滑动变阻器“一上一下”接入。
  • 数据处理
  • 计算法：多次测量取 $R = \frac{U}{I}$ 平均值，或利用 $U$-$I$ 图像斜率求电阻。
  • 图像法处理非线性关系：本题验证 $R_L$ 与 $t$ 近似线性，作 $R_L$-$t$ 图，通过各点是否落在一条直线附近判断。

解题方法与套路

  1. 明确待测对象与电路结构：理清电路图中哪一部分是待测等效电阻（如本题虚线框内的 $R_L$），分清电表所测的电压、电流是否直接对应待测电阻。
  2. 确定伏安法接法：从题干关键信息（如“电压表内阻很大”）判断应选择电流表外接法以减小系统误差；若给出电表内阻的准确值或需更精确测量，也可考虑内接法并进行计算修正。
  3. 实物图连线
  4. 由电路图出发，先连串联的主干路：电源、开关、滑动变阻器、电流表、待测电阻（虚线框）。
  5. 再连电压表，注意电压表必须并联在待测电阻两端。
  6. 检查接线柱极性，滑动变阻器限流/分压接线是否正确。
  7. 数据记录与作图
  8. 根据表格数据建立坐标系，横、纵坐标轴标出物理量和单位，选择合理分度，使图线占据大部分坐标纸。
  9. 准确描点，用“×”或“·”标记。
  10. 观察趋势，用平滑直线（或曲线）拟合；若为探究线性关系，应使数据点均匀分布在直线两侧（个别偏差大的点可舍弃）。
  11. 得出结论：由拟合直线的形状和走向判断近似线性关系，并可进一步得出变化规律（如 $R_L$ 随温度升高而减小）。

高频易错

  • 内外接混淆：看到“电压表内阻很大”就随意接线，误将电压表并联在电流表和待测电阻串联的两端（内接法），导致测量值偏大，且未能利用“电压表分流可忽略”的条件。
  • 实物连线操作性错误：滑动变阻器连接三根线（一上两下）或全接在固定端，无法变阻；电表正负接线柱反接；导线交叉缠绕；忘记开关断开状态。
  • 作图不规范：坐标轴不写物理量符号与单位；分度值选取不合理（如取值过小使点挤在一起，或过大使点过于分散）；将数据点简单用折线连接，而不是用平滑直线拟合；拟合线未穿过多数点的中心。
  • 线性关系误判：只要有少许离散点就认为不是线性关系，忽略测量误差允许的波动；或将 $R_L$ 与 $t$ 的关系直接写为正比，忽略“近似为线性”的表述。

代表题精讲

题目

2010年新课标Ⅰ卷第10题：利用对温度敏感的半导体热敏电阻 $R_T$ 与固定电阻 $R_1$、$R_2$ 组成虚线框电路，使等效电阻 $R_L$ 随温度近似线性变化。用伏安法测量不同温度下的 $R_L$，电压表内阻很大，测量结果列表给出。要求：（1）按电路图连实物图；（2）作 $R_L\text{-}t$ 图线并判断线性关系。

思路

由“电压表内阻很大”可直接判定采用电流表外接法——电压表直接并联在虚线框两端（测 $R_L$ 两端电压），电流表串在干路。实物连线先连主回路，后并电压表。数据处理时用描点法作 $R_L\text{-}t$ 图像，观察数据点分布是否近似在一条直线上。

步骤

  1. 连线
  2. 从电源正极出发，依次连接开关、滑动变阻器（限流式，一端接固定端，一端接滑片）、电流表正接线柱 → 负接线柱 → 虚线框代表 $R_L$ 的一端，虚线框另一端接回电源负极，完成主干路。
  3. 电压表并联在虚线框两端：电压表正接线柱接靠近电源正极一侧，负接线柱接靠近电源负极一侧。检查滑动变阻器是否“一上一下”联接。
  4. 作 $R_L\text{-}t$ 图
  5. 横轴为温度 $t\,(\degree\text{C})$，范围 $30.0\sim90.0$，纵轴为 $R_L\,(\Omega)$，范围 $34.7\sim54.3$。
  6. 按表格数据描出 7 个点，建议用“×”标记。
  7. 用直尺作一条直线，使多数点落在线上或均匀分布在线两侧。结果可见点大致沿一条向下倾斜的直线分布。
  8. 判断线性关系：由于各数据点与所画直线偏差很小，可认定在给定温度范围内 $R_L$ 随 $t$ 变化近似为线性关系（负相关）。

点评/变式

  • 本题核心是用伏安法测电阻与“化曲为直”思想，通过电路拓扑设计将非线性的热敏电阻特性转化为近似线性的等效电阻，简化后续处理和显示。实测中的关键扣分点常出现在实物连线内外接和作图细节。
  • 变式1：若题干未明确电表内阻信息，需先通过比较 $R_x$ 与 $\sqrt{R_AR_V}$ 或试触决定内、外接。
  • 变式2：若已知电流表内阻 $R_A$，可利用内接法测得 $R_{\text{测}}=R_x+R_A$，通过计算修正获得精确 $R_x$。此类题会考查系统误差分析及修正公式。
