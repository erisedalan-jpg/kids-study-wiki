知识精要

  • 位移的定义：从初位置指向末位置的有向线段，矢量；用 $\Delta x = x_2 - x_1$ 表示。
  • 位移与路程：位移只取决于始末位置，路程为路径长度；单向直线运动中位移大小等于路程，但两者概念不同，不可混淆。
  • 匀变速直线运动的位移公式：
    $$x = v_0 t + \frac{1}{2}at^2$$
    速度与位移关系：$v^2 - v_0^2 = 2ax$
  • $v!-!t$ 图象中的位移：图象与时间轴围成的“面积”表示位移大小（时间轴上方为正位移，下方为负位移），适用于一切直线运动。
  • 平均速度：$\overline{v} = \dfrac{x}{t}$，是位移与时间的比值，矢量；仅当物体做匀变速直线运动时才有 $\overline{v} = \dfrac{v_0 + v}{2}$（即初末速度的算术平均），非匀变速运动不可直接套用。
  • 加速度变化时的位移：若 $a$ 不是恒量，应利用 $v!-!t$ 图象面积、分段求位移或积分思想求解，不能用匀变速公式一步到位。

解题方法与套路

  1. 图象法求位移
  2. 识别 $v!-!t$ 图中图线与时间轴围成的面积，即对应时间内的位移。
  3. 比较不同物体位移时，直接在图中比较面积大小；若涉及方向，则需考虑正负。

  4. 平均速度可直接用面积（位移）除以时间得到。

  5. 公式法求位移

  6. 匀变速运动优先使用 $x = v_0t + \frac{1}{2}at^2$ 或 $v^2 - v_0^2 = 2ax$。

  7. 非匀变速运动若加速度分段恒定，则分段计算位移后求和；若加速度连续变化，常用图象法。

  8. 多阶段运动的位移处理

  9. 画出运动过程分段示意图，标注各阶段的初速度、加速度、时间。
  10. 逐段计算位移，必要时利用速度关系（如最大速度、衔接速度）列方程。

  11. 对于“由静止开始加速、后匀速”等典型模型，设加速时间与最大速度，利用总位移和时间列方程组求解。

  12. 平均速度的比较与计算

  13. 在相同时间内，位移大的平均速度大；位移计算优先看 $v!-!t$ 图象面积。
  14. 非匀变速运动切忌用 $\frac{v_0+v}{2}$ 算平均速度，必须严格用 $\overline{v} = x/t$。

高频易错

  • 混淆位移与路程：题中求“位移”时用了路径长度，或将该带方向的矢量当成标量处理。
  • $v!-!t$ 图象面积理解错误：误把面积当路程（折返运动中位移与路程不同），或忽略横轴下方的负面积。
  • 非匀变速运动误用匀变速公式：如看到“加速大小不变”便直接用 $x=\frac{1}{2}at^2$，但加速度方向或大小变化时不适用。
  • 平均速度公式滥用：只有匀变速直线运动才有 $\overline{v} = \frac{v_0+v}{2}$，对变加速运动、变减速运动均不成立，必须用定义式 $\overline{v}=x/t$。
  • 图象斜率与面积混淆：斜率反映加速度，面积反映位移，二者不可相互替代。题目可能同时考查加速度变化趋势与位移大小，需区分。
  • 忽略反应时间或初始条件：如起跑反应时间、初速度为零等条件未纳入位移计算，导致分段错误。

代表题精讲

代表题1（2014·新课标Ⅱ·01）

题目：甲乙两车在同一平直公路同向行驶，$t=0$ 到 $t=t_1$ 的 $v!-!t$ 图象如图所示。根据图象判断正确的是（　）
A．甲的平均速度比乙大
B．乙的平均速度等于 $\frac{v_1+v_2}{2}$
C．甲乙两车位移相同
D．甲的加速度逐渐减小，乙的加速度逐渐增大

思路：利用 $v!-!t$ 图象面积比较位移，再由 $x$ 和 $t$ 得出平均速度；由斜率变化判断加速度变化趋势。

步骤：
1. 观察图象，甲图线上凸，乙图线下凹，甲乙所围面积不同；在相同时间 $t_1$ 内，甲图线与 $t$ 轴围成的面积明显大于乙的面积。
2. 由 $x = \text{面积}$ 知 $x_{\text{甲}} > x_{\text{乙}}$，选项C错误。
3. 平均速度 $\overline{v} = x/t$，时间相同，故 $\overline{v}{\text{甲}} > \overline{v}$，A正确。}
4. 乙做变减速运动（速率减小且图线弯曲），不是匀变速，$\overline{v} \neq \frac{v_0+v}{2}$，B错误。
5. 看斜率：甲的切线斜率逐渐减小，即加速度大小减小；乙的切线斜率绝对值逐渐增大，即加速度大小增大，D正确（若原题是单选，可能只选A；但本着题目本意，这里可能存在双选，具体以原题解析为准：仅A正确，D是否对需根据原图象，题目说明甲加速度减小，乙加速度增大，解析中没否定D，但最终答案给出的是A，此处我们以解析为准：答案为A）。

点评/变式：本题核心是通过面积理解位移，进而比较平均速度，同时警示非匀变速运动中 $\frac{v_0+v}{2}$ 的误用。变式可换为给出 $a!-!t$ 图或 $x!-!t$ 图分析位移。

代表题2（2011·新课标·11）

题目：甲乙两车由静止出发做加速直线运动，加速度方向始终不变。第一段时间 $t$ 内，甲的加速度为 $a$，乙的加速度为 $2a$；接下来相同时间 $t$ 内，甲的加速度变为 $2a$，乙的加速度变为 $a$。求两车在这两段时间内总位移之比。

思路：分段用匀变速位移公式，分别计算两车两段位移，求和后求比值。

步骤：
1. 设第一段时间为 $t$，第二段时间也为 $t$。
2. 甲车：第一段位移 $x_{1} = \frac{1}{2}at^2$，末速度 $v_1 = at$；第二段以 $v_1$ 为初速、加速度 $2a$，位移 $x_{2} = v_1 t + \frac{1}{2}(2a)t^2 = at^2 + at^2 = 2at^2$；总位移 $x_{\text{甲}} = \frac{1}{2}at^2 + 2at^2 = \frac{5}{2}at^2$。
3. 乙车：第一段位移 $x_{1}' = \frac{1}{2}(2a)t^2 = at^2$，末速度 $v_1' = 2at$；第二段位移 $x_{2}' = v_1' t + \frac{1}{2}at^2 = 2at^2 + \frac{1}{2}at^2 = \frac{5}{2}at^2$；总位移 $x_{\text{乙}} = at^2 + \frac{5}{2}at^2 = \frac{7}{2}at^2$。
4. 位移比 $x_{\text{甲}} : x_{\text{乙}} = \frac{5}{2} : \frac{7}{2} = 5:7$。

点评/变式：典型的分段匀变速位移叠加，关键要画好过程图，分清初速与加速度。可进一步考查两车在哪段时间内速度相等、何时相遇等。

代表题3（2010·新课标Ⅰ·11）

题目：博尔特100m和200m世界纪录分别为9.69s、19.30s。100m时反应时间0.15s，起跑后匀加速到最大速率后匀速跑完。200m时反应及加速阶段同100m，但之后平均速率仅为最大速率的96%。求：(1)加速时间 $t$ 和最大速率 $v_m$；(2)匀加速阶段的加速度 $a$。

思路：建立匀加速+匀速的分段位移模型，利用总位移和总时间列方程组，注意200m中后段平均速率打折，仍保持加速段相同。

步骤：
1. 100m：加速阶段位移 $x_1 = \frac{v_m}{2}t$（因初速0、匀加速），匀速阶段位移 $x_2 = v_m(9.69 - 0.15 - t)$，总位移 $x_1+x_2=100$。
2. 200m：加速阶段参数同100m，加速结束后的路程用打折后的平均速率。设最大速率 $v_m$，则后段平均速率为 $0.96v_m$，后段时间为总时间减反应时间再减加速时间： $(19.30-0.15-t)$，后段位移为 $0.96v_m(19.30 - 0.15 - t)$，加上加速位移 $\frac{v_m}{2}t$ 等于200。
3. 列方程组：
- 100m： $\frac{v_m}{2}t + v_m(9.54 - t) = 100$
- 200m： $\frac{v_m}{2}t + 0.96v_m(19.15 - t) = 200$
4. 解方程组得 $t \approx 0.96\,\text{s}$，$v_m \approx 11.24\,\text{m/s}$。
5. 加速度 $a = v_m/t \approx 11.24/0.96 \approx 11.7\,\text{m/s}^2$。

点评/变式：本题将位移分解为加速段与匀速段，巧妙利用两层条件联立求解未知量。常见错误是忘记扣除反应时间，或200m中误将打折前最大速率直接用于后段。变式可将加速段改为先匀加速再匀减速等。
