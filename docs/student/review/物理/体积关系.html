体积关系

考点体积关系权重6真题数1学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：6
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：填空14
  • 难度分布：中1

知识精要

  • 玻意耳定律：一定质量的气体，在温度不变时，压强与体积成反比。 $p_1V_1 = p_2V_2$。连通器中，等温变化是核心适用条件。
  • 连通器压强关系：在静止的同一连续液体内，等高处压强相等。液面下深度 $h$ 处压强 $p = p_{\text{液面}} + \rho g h$（水银柱常用 cmHg 直接表示）。
  • 体积关系：对于粗细均匀的竖直玻璃管，气体体积正比于气柱长度 $l$。初始体积对应管长减去水银柱初始高度，末态同理。若初态水银面恰在管口下端齐平，初始气体长度即管长。
  • 隐含条件：缓慢过程视为等温；开口端气体压强即为大气压 $p_0$；底部水平连通器内各管下端压强相等。

解题方法与套路

  1. 选研究对象：分别取各段封闭气体为研究对象，明确初、末状态参量（$p$、$V$，可用气柱长度 $l$ 代替体积）。
  2. 建立压强关系：从开口端（已知 $p_0$）出发，利用连通器原理，沿液面走向列出下端等高处压强等式。得出各管内气体压强与水银柱高度、$p_0$ 的函数关系。
  3. 设未知数列方程：通常设水银柱高度（或高度差）为未知量。由末态气柱长度 $l' = l_0 - h_{\text{Hg}}$，再用玻意耳定律对每段气体列方程。
  4. 联立求解：根据压强关系消去多余未知数，解方程时注意舍去超出管长或不符合物理意义的解。
  5. 结果表达：最终所求通常为两管水银柱高度差，直接作差得出。

高频易错

  • 初始状态误判：未看清装置初始液面是否齐平，误将初始气体压强当作非 $p_0$。若无特殊说明，初态下端齐平、开口与大气相通，则各封闭气体初压为 $p_0$。
  • 水银面高度起算点混乱：所有水银柱高度必须从同一水平参考面（如下端连通水平面）起算，不可混用管口或其他位置。
  • 体积与长度转换漏掉横截面积：由于各管粗细均匀且相同，$S$ 可以约去，直接用气柱长度表示体积，但忽视变化量对应的水银柱高度差。
  • 解方程忘舍根：二次方程常出现大于管长的无效解，须根据管长约束舍去。
  • 混淆 $p = p_0 + h$ 的正负号：若管内液面低于开口液面，压强应相加；若高于，则相减。判断时一律写成 “下端压强 = 气体压强 + 水银柱高度” 的形式，避免符号错误。

代表题精讲

题目

如图，一玻璃装置放在水平桌面上，竖直玻璃管 A、B、C 粗细均匀，A、B 两管的上端封闭，C 管上端开口，三管的下端在同一水平面内且相互连通。A、B 两管的长度分别为 $l_1 = 13.5\,\text{cm}$，$l_2 = 32\,\text{cm}$。将水银从 C 管缓慢注入，直至 B、C 两管内水银柱的高度差 $h = 5\,\text{cm}$。已知外界大气压 $p_0 = 75\,\text{cmHg}$。求 A、B 两管内水银柱的高度差。

思路

初态三管下端连通、C 开口，A、B 内气体压强等于大气压 $p_0$，气柱长即为管长。缓慢注水银为等温过程，分别对 A、B 内气体使用玻意耳定律。利用连通器原理，以下端为参考面，建立 C、B、A 的下端压强等式，求出 B 末态压强，再推 A 的末态压强，结合气柱长度变化解出水银柱高度，最后作差。

步骤

  1. 初始状态：
    初态 A、B 内气柱长分别为 $l_1 = 13.5\,\text{cm}$、$l_2 = 32\,\text{cm}$，压强均为 $p_0 = 75\,\text{cmHg}$。
  2. 末态压强关系：
    设末态 A、B、C 各管水银柱高度（从下端水平面起算）分别为 $h_A$、$h_B$、$h_C$。
    下端正强 $p_{\text{底}} = p_0 + h_C = p_B + h_B = p_A + h_A$。
    已知 B、C 水银柱高度差 $h_C - h_B = 5\,\text{cm}$，代入得 $p_B = p_0 + 5 = 80\,\text{cmHg}$。
  3. 对 B 气体用玻意耳定律：
    $p_0 l_2 = p_B (l_2 - h_B)$ $\Rightarrow 75 \times 32 = 80 (32 - h_B)$
    解得 $h_B = 2\,\text{cm}$。
    则 $h_C = h_B + 5 = 7\,\text{cm}$。
  4. 对 A 气体列式：
    末态 A 压强 $p_A = p_0 + h_C - h_A = 82 - h_A$（cmHg），
    气柱长 $l_A' = l_1 - h_A = 13.5 - h_A$。
    由 $p_0 l_1 = p_A (l_1 - h_A)$：
    $75 \times 13.5 = (82 - h_A)(13.5 - h_A)$。
    化简得 $h_A^2 - 95.5h_A + 94.5 = 0$，解得 $h_A = 1\,\text{cm}$（另一解 $94.5\,\text{cm} > 13.5\,\text{cm}$ 舍去）。
  5. 高度差：
    A、B 水银柱高度差 $\Delta h = h_B - h_A = 2\,\text{cm} - 1\,\text{cm} = 1\,\text{cm}$。

点评与变式

此题经典呈现了“连通器 + 玻意耳定律”的综合应用，关键是建立起以下端为参考的压强等式。变式可改为：① 将 A、B 管长度互换或改变初始水银量；② 注入水银使得某管水银面达到管口；③ 求注入的水银总体积。核心思路不变，始终从开口端压强出发，逐段列等式，结合气态方程求解。
