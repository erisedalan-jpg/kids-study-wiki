知识精要

  • 余弦定理：任意三角形 $ABC$ 中，边 $a,b,c$ 对角 $A,B,C$ ，有 $$a^2 = b^2 + c^2 - 2bc\cos A$$ $$b^2 = a^2 + c^2 - 2ac\cos B$$ $$c^2 = a^2 + b^2 - 2ab\cos C$$
  • 变形求角：$\cos A = \frac{b^2+c^2-a^2}{2bc}$ ，其余类推。
  • 适用条件：已知两边及其夹角求第三边；已知三边求角。
  • 在物理矢量合成中的角色：当合矢量与两个分矢量构成封闭三角形时，已知其中两边及其夹角（两分矢量首尾相接时的夹角，或合矢量与一分矢量的夹角），可求第三边的大小，或求方向角。本质是矢量三角形（或平行四边形的一半）的几何计算。

解题方法与套路

  • 矢量三角形作图法：
  • 明确合矢量与分矢量的矢量关系：$\vec{v}=\vec{v}_1+\vec{v}_2$（平行四边形法则），将其画为首尾相接的三角形。
  • 在三角形中标出已知量：两边的长度（速率）、它们之间的夹角（注意：两分矢量首尾相接时夹角为 $\theta$，平行四边形中则是 $180^\circ-\theta$，需根据题意确定）。
  • 选取含有所求量的边（未知第三边），写出余弦定理表达式：$v_2^2 = v^2 + v_1^2 - 2 v v_1 \cos\alpha$，其中 $\alpha$ 是合矢量与已知分矢量 $v_1$ 的夹角。
  • 计算数值并依据几何关系判定方向（结合方位形容词如东偏南、西偏北等）。
  • 方向判定搭配：若还需求方向角，可用正弦定理 $\frac{v_2}{\sin\alpha} = \frac{v_1}{\sin\beta}$ 求未知角，或直接根据三角形边角大小定性判断。

高频易错

  • 夹角代错：矢量三角形的夹角与平行四边形中两分矢量间夹角不同。若分矢量间夹角为 $\varphi$，则矢量三角形中对应角为 $180^\circ-\varphi$，代入公式时容易直接用 $\varphi$ 导致符号反。
  • 余弦定理符号：公式 $a^2 = b^2 + c^2 - 2bc\cos A$ 中，当 $A>90^\circ$ 时 $\cos A<0$，项变为加；死记“减”会错。
  • 混淆已知边与未知边：例如题目给出合速度与一分速度，求另一分速度，误用 $v_2 = \sqrt{v^2 + v_1^2}$（勾股定理）而忽略夹角。
  • 方向表述不规范：判断“东偏南”“西偏北”等方位时未对应好几何角的起始方向。
  • 单位换算遗漏：题目给的数值常带数量级 $10^3\,\text{m/s}$，提取公因数再计算可减少计算错误。

代表题精讲

题目（2015·新课标Ⅱ·03）

同步卫星转移轨道与同步轨道夹角 $30^\circ$，同步轨道环绕速度约 $3.1\times10^3\,\text{m/s}$，卫星飞经赤道上空时速度 $1.55\times10^3\,\text{m/s}$，高度与同步轨道相同。求发动机附加速度的方向和大小。

思路：卫星由转移轨道进入同步轨道，发动机点火提供附加速度 $\vec{v}_2$，使合速度变成同步轨道速度 $\vec{v}$。已知合速度大小 $v=3.1\times10^3\,\text{m/s}$，一分速度 $v_1=1.55\times10^3\,\text{m/s}$，$\vec{v}$ 与 $\vec{v}_1$ 夹角 $30^\circ$。矢量关系 $\vec{v} = \vec{v}_1 + \vec{v}_2$，作封闭三角形，利用余弦定理求 $v_2$，再由几何关系判方向。

步骤： 1. 作矢量三角形：从 $\vec{v}_1$ 末端画 $\vec{v}_2$，使首尾相接得到合矢量 $\vec{v}$，标注已知：$v_1$、$v$，夹角 $\alpha=30^\circ$（为 $\vec{v}$ 与 $\vec{v}_1$ 的夹角）。 2. 由余弦定理：$v_2^2 = v^2 + v_1^2 - 2 v v_1 \cos30^\circ$。 - 提公因子 $(1\times10^3)^2$，代入：$v_2^2 = 3.1^2 + 1.55^2 - 2\times3.1\times1.55\times\frac{\sqrt{3}}{2}$ - $3.1^2=9.61$，$1.55^2\approx2.4025$，乘积项：$2\times3.1\times1.55\times0.866\approx2\times3.1\times1.3423\approx8.322$。 - $v_2^2 \approx 9.61+2.40-8.32 = 3.69$，$v_2 \approx 1.92 \times 10^3\,\text{m/s}$，接近 $1.9\times10^3\,\text{m/s}$。 3. 方向判断：$\vec{v}$ 为同步轨道速度（向东），$\vec{v}_1$ 在转移轨道，夹角 $30^\circ$ 在赤道平面内；由平行四边形可知 $\vec{v}_2$ 大致偏向东南方向（东偏南）。

点评/变式：本题是余弦定理在矢量合成中的典型应用，关键在于正确构建速度三角形并识别夹角。变式：若已知两分速度及其夹角，求合速度大小，同样用余弦定理（此时夹角用两分矢量夹角，注意首尾相接的补角关系）。注意数量级提取简化计算，避免繁琐小数运算。
