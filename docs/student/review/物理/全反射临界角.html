全反射临界角

考点全反射临界角权重6真题数1学科物理父主题几何光学 与 物理光学

考点定位

  • 父主题：几何光学 与 物理光学
  • 权重 weight：6
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：解答16
  • 难度分布：中1

知识精要

  • 全反射现象：光从光密介质射向光疏介质时，折射光线消失、全部反射回光密介质的现象。
  • 发生条件（缺一不可）：
  • 光从光密介质进入光疏介质（折射率 $n_1 > n_2$）。
  • 入射角 $\theta \ge$ 临界角 $C$。
  • 临界角公式：光从折射率为 $n$ 的介质射向真空（或空气，$n \approx 1$）时，临界角 $C$ 满足 $$\sin C = \frac{1}{n}$$ 若光从介质 $n_1$ 射入介质 $n_2$（$n_1 > n_2$），则 $$\sin C = \frac{n_2}{n_1}$$
  • 折射定律（斯涅耳定律）：$n_1 \sin \theta_1 = n_2 \sin \theta_2$，几何光学计算的基础。
  • 光路可逆性：在反射和折射中普遍成立，可用于简化角度分析。
  • 常见介质临界角：$n=1.5$ 时，$C = \arcsin\frac{2}{3} \approx 41.8^\circ$；$n=\sqrt{2}$ 时，$C=45^\circ$；$n=2$ 时，$C=30^\circ$。熟记可快速判断。

解题方法与套路

  1. 规范画光路图
  2. 按比例画出界面与法线，标出入射角、折射角、反射角。

  3. 光线经过多个界面时，依次画出折射线或反射线，注意虚实线区分。

  4. 逐面应用折射定律与反射定律

  5. 在已知入射角、折射率的界面，用 $n_1\sin\theta_1=n_2\sin\theta_2$ 求出折射角（或反射角）。

  6. 未知入射角时，利用几何关系（三角形内角和、平行线、垂线等）求出。

  7. 全反射判断三步骤

  8. 定疏密：明确光线射向的介质是光疏还是光密。
  9. 算临界角：根据 $n$ 求出 $\sin C$ 或 $C$。

  10. 比角度：计算该面上的入射角，若 $\theta_{\text{入}} \ge C$ 且从光密到光疏，则发生全反射。

  11. 角度传递的几何技巧

  12. 利用“法线与界面垂直”“三角形外角等于不相邻两内角和”“平行线性质”等将已知角传递到未知面。

  13. 经常需要把折射角、入射角与界面的夹角转化为三角形的内角。

  14. 求射出光线与入射光线夹角

  15. 通常通过多次折射、反射的光路，最终出射角可由首末两根光线方向的几何关系获得，可结合光路可逆性简化。
  16. 注意区分“偏向角”（入射光与出射光的夹角）和“折射角”。

高频易错

  • 错用临界角公式：只有光从介质射向真空（空气）时公式才是 $\sin C = 1/n$，当光射入另一种介质时，必须使用 $\sin C = n_2/n_1$。
  • 分不清光密光疏：折射率大的为光密，折射率小的为光疏，与密度无关。常误以为从空气进入介质也能发生全反射，实际上全反射只能发生在光密进入光疏的过程中。
  • 入射角找错：入射角是光线与法线的夹角，不是与界面的夹角。在三角形或平行线情境中容易混淆，凡遇角度均应补画法线确认。
  • 忽略反射次数限定：题干中“不考虑多次反射”意味着只按第一次到达某界面的光路处理，不可自行添加二次、三次反射路径。
  • 几何关系推导失误：在30°-60°-90°的直角棱镜中，边角关系与光线方向密切相关，一处错往往导致全盘角度错误。建议在图上清晰标注所有角度。
  • 混淆出射光与入射光夹角的求解：部分考生误以为是求某个界面的折射角，实际上该夹角可通过平行线、三角形外角等几何关系转化为某个已知角。

代表题精讲

题目 （2020新课标Ⅱ-16）直角棱镜折射率 $n=1.5$，横截面为 $\triangle ABC$，其中 $\angle C=90^\circ$，$\angle A=30^\circ$。一细束与 $BC$ 边平行的光线从 $AB$ 边上的 $D$ 点射入，经折射后射到 $BC$ 边上。
（i）判断光线在 $BC$ 边上是否发生全反射，并说明理由；
（ii）不考虑多次反射，求从 $AC$ 边射出的光线与最初的入射光线夹角的正弦值。

思路
首先根据折射率和三角形角度，计算临界角；画光路图，利用平行关系和三角形角度求出 $AB$ 面的入射角，再由折射定律得折射角；通过角度传递求出光线到达 $BC$ 面的入射角，与临界角比较判断全反射；然后依题意只考虑一次反射，画出反射后射向 $AC$ 边的光路，求出射点处的入射角，再次用折射定律求得 $AC$ 边出射角；最后根据几何关系找出出射光线与原始入射光线的夹角，并求其正弦值。

步骤
1. 计算临界角
棱镜折射率 $n=1.5$，空气折射率 $n_0 \approx 1$，光从棱镜射向空气时的临界角 $C$ 满足
$$\sin C = \frac{1}{n}= \frac{2}{3}, \quad C = \arcsin\frac{2}{3} \approx 41.8^\circ$$

  1. $AB$ 面折射
    $\triangle ABC$ 中 $\angle C=90^\circ,\angle A=30^\circ \Rightarrow \angle B=60^\circ$。
    光线平行于 $BC$，因此与 $AB$ 边的夹角为 $60^\circ$（内错角）。过 $D$ 作 $AB$ 的法线，入射角 $i$ 为光线与法线的夹角：
    $$i = 90^\circ - 60^\circ = 30^\circ$$
    由折射定律：$1 \cdot \sin 30^\circ = 1.5 \cdot \sin r$，得
    $$\sin r = \frac{1}{3}, \quad r = \arcsin\frac{1}{3}$$

  2. 判断 $BC$ 面上的全反射
    光线折射后射入棱镜，到达 $BC$ 边上的 $E$ 点。在 $\triangle DBE$ 中，$\angle B=60^\circ$，$AB$ 的法线与 $BC$ 的几何关系可推得：射到 $BC$ 面时的入射角 $\theta = 90^\circ - (\angle B - r)$？更直接的推导：
    折射光线与 $AB$ 法线的夹角为 $r$，$AB$ 法线与 $AB$ 垂直，$AB$ 与 $BC$ 的夹角为 $60^\circ$，可得折射光线与 $BC$ 边法线的夹角（即入射角）$\theta$ 满足：
    $$\theta = 60^\circ + r$$
    因为 $r = \arcsin(1/3) \approx 19.47^\circ$，所以 $\theta \approx 79.47^\circ$。
    也可精确计算：$\sin\theta = \sin(60^\circ + r)$ 是否大于 $\sin C$ 即可判断。
    $\sin\theta = \sin 60^\circ \cos r + \cos 60^\circ \sin r = \frac{\sqrt{3}}{2}\cdot\frac{2\sqrt{2}}{3} + \frac{1}{2}\cdot\frac{1}{3} = \frac{\sqrt{6}}{3} + \frac{1}{6}$。
    由于 $\sqrt{6} \approx 2.449$，$\sin\theta \approx 0.816 + 0.167 = 0.983$，远大于 $\frac{2}{3}$，因此 $\theta > C$，且光从棱镜射向空气满足光密到光疏，发生全反射。

  3. $AC$ 面出射
    全反射后光线射向 $AC$ 边。根据反射定律与三角形角度，反射光线到达 $AC$ 面时的入射角 $i'$ 可由几何求出：在 $\triangle BEC$ 等中推导可得 $i' = 30^\circ - r$。
    由折射定律：$1.5 \cdot \sin i' = 1 \cdot \sin \alpha$，其中 $\alpha$ 是出射角。代入 $\sin i' = \sin(30^\circ - r)$，计算得
    $$\sin \alpha = 1.5 \cdot \sin(30^\circ - r)$$
    利用 $\sin r = 1/3$，$\cos r = \frac{2\sqrt{2}}{3}$，
    $$\sin(30^\circ - r) = \sin 30^\circ\cos r - \cos 30^\circ\sin r = \frac{1}{2}\cdot\frac{2\sqrt{2}}{3} - \frac{\sqrt{3}}{2}\cdot\frac{1}{3} = \frac{\sqrt{2}}{3} - \frac{\sqrt{3}}{6}$$
    故 $\sin \alpha = \frac{3}{2} \left( \frac{\sqrt{2}}{3} - \frac{\sqrt{3}}{6} \right) = \frac{\sqrt{2}}{2} - \frac{\sqrt{3}}{4} = \frac{2\sqrt{2} - \sqrt{3}}{4}$。

  4. 求夹角的正弦值
    通过光路几何（延长入射光线、利用平行与法线关系）可知，从 $AC$ 边出射的光线与最初的入射光线（与 $BC$ 平行）之间的夹角正好等于出射角 $\alpha$。因此，所求正弦值为
    $$\sin \alpha = \frac{2\sqrt{2} - \sqrt{3}}{4}$$

点评/变式
- 本题核心是考查全反射条件的应用和几何光学中的角度递推。许多考生在判断 $BC$ 边全反射时仅比较数值，忽略了必须明确“光密射向光疏”这一前提，表述时一定要点明。 - 常见变式：（1）改变折射率使临界角变化，从而改变全反射结果；（2）光线从 $AC$ 边入射、问从 $AB$ 或 $BC$ 边出射的情况；（3）增加“考虑色散”要求分析不同色光的出射方向。
- 备考建议：对30°-60°-90°棱镜中的平行光线入射问题，总结典型角度关系，熟练以后可以快速口算出射角，节省画图推演时间。
