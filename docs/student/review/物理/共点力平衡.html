共点力平衡

考点共点力平衡权重37真题数10学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：37
  • 真题数：10；年份跨度：2008–2023
  • 出现题位：填空12 选择1 选择2 选择3 选择5 选择10 选择11
  • 难度分布：中7 易2 难1

知识精要

  • 共点力平衡条件：物体所受合外力为零，即 $F_{\text{合}}=0$。
  • 正交分解形式：$\sum F_x = 0$，$\sum F_y = 0$。
  • 静态平衡：物体保持静止或匀速直线运动状态，速度恒为零或恒定。
  • 动态平衡：物体缓慢移动，过程中各时刻均可视为平衡状态，通常借助矢量三角形或相似三角形定性/定量分析力的变化。
  • 受力分析顺序：重力 → 弹力 → 摩擦力 → 其他力（电场力、安培力等）。
  • 摩擦力方向与大小：
  • 滑动摩擦力：$f = \mu N$，方向与相对运动方向相反。
  • 静摩擦力：随外力和运动趋势变化，存在最大值 $f_{\text{max}}$。
  • 正交分解坐标轴选取原则：让尽可能多的力落在坐标轴上，或沿运动趋势方向及垂直方向建立坐标轴。
  • 整体法与隔离法：分析系统与外界的作用力时优先用整体法，分析系统内部各物体间相互作用时必须用隔离法。

解题方法与套路

  1. 明确研究对象：
  2. 单个物体或结点（隔离法）——如 2022 全国乙卷绳连小球问题。
  3. 多物体系统（整体法）——如 2008 全国Ⅱ两滑块匀速下滑问题。
  4. 受力分析并画示意图：
  5. 按重力、弹力、摩擦力、其他力的顺序逐一画出，不遗漏。
  6. 准确标注各力方向及已知/未知符号。
  7. 构建平衡方程：
  8. 对于三力平衡，优先采用合成法（构造力三角形）或图解分析；尤其动态平衡问题，直观判断各力变化。
  9. 对于多力（≥4力）平衡，常采用正交分解法，沿平衡方向或垂直斜面方向建立坐标系，列 $\sum F_x=0$、$\sum F_y=0$ 方程。
  10. 代入几何关系与临界条件求解：
  11. 若涉及最大/最小力问题（如 2013 新课标Ⅱ），直接列出静摩擦力最大时的临界方程。
  12. 若涉及“不论推力多大都不动”的临界角分析（如 2012 新课标拖把问题），利用不等式 $F_{\text{推水平}} \leq \lambda N$ 推导临界条件。
  13. 检验结果：检查量纲、力的方向是否合理，矢量符号是否落实。

高频易错

  • 受力多/漏/错：尤其容易忽略轻绳张力处处相等、静摩擦力方向与相对运动趋势相反而不是与运动方向相反。
  • 动态平衡中误判变化趋势：没有正确选取矢量三角形，混淆旋转过程中边长代表的力的大小变化。
  • 摩擦力方向在临界状态反转：如 2013 年斜面外力范围问题，最大静摩擦方向可沿斜面向上或向下，须分情况列方程。
  • 正交分解角度错误：斜面问题中重力沿斜面和垂直斜面分量应为 $mg\sin\theta$、$mg\cos\theta$，混淆 $\sin$ 与 $\cos$。
  • 整体法/隔离法混用不当：若求系统内部作用力，必须先整体后隔离，不能直接整体法得出内部力。

代表题精讲

代表题一：2019-新课标Ⅱ-03

题目：物块在平行斜面的轻绳拉动下沿倾角 $30^\circ$ 斜面匀速上升，动摩擦因数 $\mu = \frac{\sqrt{3}}{3}$，轻绳最大张力 $1500\text{N}$，求最大质量。

思路：物体匀速运动，满足沿斜面平衡。当拉力最大时质量最大，直接对物块受力分析，沿斜面方向列平衡方程。

步骤： 1. 画受力分析图：重力 $mg$ 竖直向下，支持力 $N$ 垂直斜面向上，摩擦力 $f$ 沿斜面向下（物块向上运动），绳拉力 $F$ 平行斜面向上。 2. 正交分解，沿斜面方向：$F = mg\sin30^\circ + f$； 垂直斜面方向：$N = mg\cos30^\circ$。 3. 利用滑动摩擦力公式 $f = \mu N = \mu mg\cos30^\circ$ 代入平衡方程：
$$F = mg(\sin30^\circ + \mu\cos30^\circ)$$ 4. 代入 $\mu = \frac{\sqrt{3}}{3}$、$\sin30^\circ = 0.5$、$\cos30^\circ = \frac{\sqrt{3}}{2}$，计算括号内数值：
$$0.5 + \frac{\sqrt{3}}{3} \cdot \frac{\sqrt{3}}{2} = 0.5 + 0.5 = 1$$ 5. 解得 $m = \frac{F}{g} = \frac{1500}{10} = 150\text{kg}$。

点评/变式：本题属于直线运动中的平衡问题，关键是正确判断摩擦力方向。若物块沿斜面减速或静止趋势，摩擦力方向就可能改变，需根据运动状态具体分析。

代表题二：2016-新课标Ⅱ-01

题目：质量 $m$ 的物体用轻绳悬挂，水平力 $F$ 缓慢拉动绳中点 $O$ 左移，判断 $F$ 与绳 $OA$ 段的拉力 $T$ 变化。

思路：结点 $O$ 受三段绳拉力作用，其中悬挂物绳的拉力恒为 $mg$。用图解法，构建力三角形，观察随角度增大时各边变化。

步骤： 1. 取结点 $O$ 为研究对象，受三个力：向下恒力 $mg$、水平向左 $F$、沿 $OA$ 斜向上的拉力 $T$。 2. 因缓慢移动，$O$ 始终处于三力平衡，平移力构成闭合三角形。 3. 向量三角形中，$mg$ 固定（竖直线段），$F$ 可由水平线表示，$T$ 由斜边表示。当 $O$ 左移，绳与竖直方向夹角 $\theta$ 增大。 4. 三角形中对应 $\theta$ 的对边 $F$ 与斜边 $T$ 均随 $\theta$ 增大而增大。 5. 结论：$F$ 逐渐变大，$T$ 逐渐变大。

点评/变式：动态平衡典型题。若悬挂点不是缓慢移动而是加速，则不能用平衡处理。若力改为斜向上拉，图解三角形形状会变，但仍可定性分析。

代表题三：2013-新课标Ⅱ-02

题目：固定斜面上物块受平行斜面外力 $F$ 作用，已知保持静止时 $F$ 的最大值 $F_1$ 和最小值 $F_2$，问由此可求出什么物理量。

思路：静止状态下静摩擦力可沿斜面向上或向下。$F$ 最大时静摩擦力沿斜面向下，$F$ 最小时静摩擦力沿斜面向上，联立方程消去 $mg\sin\theta$ 即可求出最大静摩擦力。

步骤： 1. 受力分析：重力 $mg$、支持力 $N$、外力 $F$、静摩擦力 $f$（$f \leq f_{\text{max}}$）。 2. 沿斜面列平衡方程： - 当 $F=F_1$（最大），静摩擦力沿斜面向下达到最大 $f_{\text{max}}$：$F_1 - mg\sin\theta - f_{\text{max}} = 0$； - 当 $F=F_2$（最小），静摩擦力沿斜面向上达到最大 $f_{\text{max}}$：$F_2 + f_{\text{max}} - mg\sin\theta = 0$。 3. 两式相减：$F_1 - F_2 - 2f_{\text{max}} = 0$，即 $f_{\text{max}} = \frac{F_1 - F_2}{2}$。 4. 可见由 $F_1$、$F_2$ 可直接求出最大静摩擦力；$mg\sin\theta = \frac{F_1+F_2}{2}$ 虽可求，但 $m$ 和 $\theta$ 各自未知，无法单独求出 $m$ 或 $\theta$ 以及正压力。

点评/变式：本题考察临界条件的灵活应用，不求具体值而求可求的量，是选择题常见考法。核心在于识别最大静摩擦力方向会随外力方向改变而反转。
