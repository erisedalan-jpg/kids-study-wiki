知识精要

  • 螺旋测微器（千分尺）原理
    精密测量长度的仪器，精度为 $0.01\ \text{mm}$，读数由固定刻度与可动刻度组成。
    读数公式：
    $$L = \text{固定刻度(主尺)读数} + \text{可动刻度副尺格数} \times 0.01\ \text{mm}$$ 固定刻度先看半毫米线是否露出，露出则加 $0.5\ \text{mm}$；可动刻度需估读到 $0.001\ \text{mm}$ 位。

  • 零误差（系统误差）
    螺旋测微器校零时，若主尺零点与副尺零点未对齐，会出现“零点误差”。
    校零读数 $d_0$ 可正可负（差动方向不同），测量读数 $d_1$，则真实厚度为： $$D = d_1 - d_0$$ 此即物理实验中的减法修正，消除固定的系统误差。

  • 适用条件
    系统误差是定值或线性误差时，可用减法（或更一般的代数相减）消除。螺旋测微器零误差属于典型的固定系统误差，减法运算得到真值。

解题方法与套路

  1. 先读校零示数 $d_0$
    判断零刻度线位置：若可动刻度零线在主尺基准线的上方或下方，按读数规则读出带有符号的 $d_0$（常见为正值，记为 $+0.010\ \text{mm}$ 等）。注意读数的正负号需由实物图约定，本题中直接给出为 $0.010\ \text{mm}$。

  2. 再读测量示数 $d_1$
    对被测物进行同样刻度的读数，得到包含系统误差在内的测量值。固定刻度半毫米线、可动刻度格数和估读均需仔细。

  3. 相减得真值
    $$D = d_1 - d_0$$ 直接套用公式，注意单位统一（均为 $\text{mm}$）。若 $d_0$ 为负值，则变为加绝对值。

  4. 结果保留合理位数
    螺旋测微器读数至 $0.001\ \text{mm}$ 位（千分位），结果也保留到 $0.001\ \text{mm}$。注意末尾处理，不要丢失有效数字或四舍五入错误。

高频易错

  • 零点读数方向弄错
    若校零时副尺零线在主尺基准线上方，零点读数为正值；下方则为负值。易误判正负号导致修正错误。本题直接给出示数，可规避此坑，但需理解原理。

  • 忘减零点误差
    测量读数直接当作厚度，导致结果偏大或偏小一个固定值。高考常直接考查“厚度 = 测量读数 - 校零读数”。

  • 半毫米线判断失误
    固定刻度上，半毫米刻线是否已露出常被忽略，造成 $0.5\ \text{mm}$ 的粗大偏差。读数时应以副尺零线为参照，若副尺零线已过半毫米线但未到下一毫米线，须加 $0.500\ \text{mm}$。

  • 估读不到位
    可动刻度一格代表 $0.01\ \text{mm}$，应估读到下一位 $0.001\ \text{mm}$。例如本题图(b)读数为 $6.870\ \text{mm}$，末位“0”不可省略。

  • 有效数字与单位
    结果需保留三位小数（$0.001\ \text{mm}$ 位），且与读数的有效数位对应。有时会要求以 $\text{cm}$ 或 $\text{m}$ 表示，注意单位换算时的零的个数。

代表题精讲

2012-新课标-09

题目
某同学利用螺旋测微器测量一金属板的厚度。该螺旋测微器校零时的示数如图（a）所示，测量金属板厚度时的示数如图（b）所示。图（a）所示读数为 $0.010\ \text{mm}$，图（b）所示读数为 $6.870\ \text{mm}$，所测金属板的厚度为 $6.860\ \text{mm}$。

思路
本题已知校零读数和测量读数，直接利用减法消除系统误差：真实厚度 $D = d_1 - d_0$。不需要自己从图中读取，但需理解读数来源与有效数字。

步骤
1. 明确已知：$d_0 = 0.010\ \text{mm}$，$d_1 = 6.870\ \text{mm}$。
2. 相减：$D = 6.870\ \text{mm} - 0.010\ \text{mm} = 6.860\ \text{mm}$。
3. 结果保留三位小数，与读数一致，单位为 $\text{mm}$。

点评/变式
- 此题为基础送分题，核心是减法修正零误差的思想。若将零点读数给为负值（如 $-0.010\ \text{mm}$），则厚度变为 $6.880\ \text{mm}$，考查正负号处理。
- 变式：不直接给出读数，要求考生从螺旋测微器示意图中读取 $d_0$ 和 $d_1$，再相减。此时要特别注意固定刻度半毫米线、可动刻度对齐情况以及估读，强化读数基本功。
- 也可引申到其他需要消除系统误差的实验，如电表机械调零后的“零差”、米尺端部磨损采用两端读数相减等，逻辑一致。
