知识精要

分压接法是指滑动变阻器采用分压式连线，使其作为分压器向负载提供可调电压。基本连接方式为：滑动变阻器两个固定端接电源两极，滑片和一个固定端接负载。负载两端电压 $U_{\text{load}}$ 与滑片位置有关，忽略电源内阻时有： $$U_{\text{load}} = \frac{R_{\text{并}}}{R_{\text{ab}}} \cdot E$$ 其中 $R_{\text{ab}}$ 为变阻器总电阻，$R_{\text{并}}$ 为滑片与一固定端之间的电阻与负载并联后的等效电阻。该接法的电压调节范围大，可从零连续调到路端电压（接近电源电动势 $E$）。
适用条件：需要电压从零开始调节；负载电阻远大于变阻器全部电阻时，电压调节的线性度更优。在测量电表内阻等实验中常配合“恒压输出固定滑片”的思想，通过先后两次电压读数与串联电阻的变化间接计算未知电阻。

解题方法与套路

  1. 识别电路——观察滑动变阻器的三个接线端：若一固定端与滑片作为输出接负载，另一固定端接电源，则为分压接法。
  2. 初始安全位置——闭合开关前，滑片应滑至使负载两端电压为零的位置（通常是将负载短路的那一端）。
  3. 分步操作——先调节滑片使负载获得目标电压（如满偏），然后保持滑片位置不变，改变负载回路中的元件（如串联电阻箱）并读取新读数。
  4. 恒压假设——滑片位置固定后，分压器输出端电压 $U_o$ 视为不变，这是建立方程的关键前提。
  5. 列式求解——利用串联分压（或并联分流）及欧姆定律，写出两次状态下的关系式，消去中间量并解出待求电阻。

高频易错

  • 混淆分压与限流接法：限流接法的负载电压最小值不是零，而是 $\frac{R_L}{R_L+R_{\text{变}}}E$；分压接法则可从零起调。
  • 滑片初始位置错误：分压接法中，闭合开关前滑片应使负载两端被短路，不是使变阻器总阻值最大。
  • 滑片固定后误认为路端电压恒定：滑片固定仅保证分压器输出的空载电压恒定，若有电源内阻或线路变化，该电压仍可能变动。
  • 物理量代换不清：满偏电压 $U_0$、调节后的电压 $U$、串联电阻箱阻值 $R$ 以及待测内阻 $R_V$ 带入公式时，易混淆分子分母关系。

代表题精讲

代表题 2016-新课标Ⅱ-10

题目
利用图（a）所示分压电路测量量程为2.5 V的电压表内阻（约数千欧），可选择电阻箱（最大99999.9 Ω）、滑动变阻器 $R_1$（50 Ω）、$R_2$（5 kΩ）、3 V直流电源等。主要步骤：①连接电路；②将电阻箱调0，滑片移至最左端，闭合开关；③调节滑片使电压表满偏；④保持滑片不动，调节电阻箱使电压表示数为2.00 V，记下电阻箱阻值 $R$。

思路
滑动变阻器构成分压器；滑片位置固定后，其输出电压 $U_o$ 保持恒定。第一次电压表满偏时 $U_o=2.5$ V；第二次电压表与电阻箱串联接于同一输出端，利用串联分压关系建立方程，即可算出电压表内阻 $R_V$。

步骤
1. 按原理图连线，电阻箱先置零，滑片移至最左端（输出电压为零）。
2. 闭合开关，缓慢调节滑片，使电压表指针刚好指在满偏刻度（2.5 V），此时分压器输出电压 $U_o=2.5$ V。
3. 保持滑片绝对不动，向电压表支路串联电阻箱，增大其阻值 $R$，直至电压表示数降为2.00 V。
4. 对此时回路列串联方程：流过电压表与电阻箱的电流相等
$$\frac{U}{R_V} = \frac{U_o - U}{R}$$
其中 $U=2.00$ V，$U_o=2.50$ V。解得
$$R_V = \frac{U}{U_o - U}R = \frac{2.00}{0.50}R = 4R$$
5. 将记录的电阻箱阻值 $R$ 代入，即得电压表内阻。

点评/变式
本题最大陷阱在于辨析分压与限流——若误用限流思路，会错认为滑片位置改变后总电压仍不变。分压接法配合“恒压点”可巧妙避开直接测电流的困难，广泛适用于高内阻电表的测量。变式1：将电阻箱与电压表并联，需用到分流关系 $R_V = \frac{U}{I_g - I}$。变式2：若电源有不可忽略的内阻，可在滑片固定后测量两次负载电压，利用闭合电路欧姆定律求解电表内阻。
