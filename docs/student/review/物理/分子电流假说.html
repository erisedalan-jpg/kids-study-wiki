分子电流假说

考点分子电流假说权重6真题数1学科物理父主题磁场 与 安培力洛伦兹力

考点定位

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：6
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 分子电流假说（安培假说）：在原子、分子等微粒内部存在一种环形电流（分子电流），每个分子电流都相当于一个微小磁体。当这些分子电流取向大致一致时，宏观上便呈现出磁性。安培假说成功解释了磁现象的电本质。
  • 地磁场分布：地磁的南极位于地理北极附近（并不完全重合），地磁的北极位于地理南极附近。地球表面外部的磁感线方向从地理南极（地磁北极）出发，弯曲指向地理北极（地磁南极）。
  • 安培定则（右手螺旋定则）判断环形电流磁场：右手拇指指向环形电流中心轴线上的磁场方向（即 $N$ 极方向），四指弯曲的方向表示环形电流的环绕方向。
  • 适用条件：环形电流、螺线管产生的磁场方向判断必须严格使用安培定则；地磁场方向的常识是解题隐含条件。

解题方法与套路

  1. 明确磁场方向与地理对应关系
    先确定地磁场的方向：在地球外部，磁场线从地理南极附近（地磁 $N$ 极）指向地理北极附近（地磁 $S$ 极）。
  2. 将地理方位转化为拇指指向
    安培定则要求拇指指 $N$ 极，地磁 $N$ 极在地理南极附近，故拇指应指向地理南方。
  3. 由安培定则反推电流方向
    右手拇指指向南方（竖直页面视情况而定），四指自然弯曲，从北极上空俯视，四指弯曲方向即是所需环形电流的流向。
  4. 结合选项图示匹配结论
    根据推得的电流环绕方向（顺/逆时针、东西方向等）筛选对应图示。

高频易错

  • 混淆地磁极与地理极：误以为地理北极就是磁北极，没有记住地磁南极在地理北极附近，导致安培定则拇指指向反向。
  • 安培定则手势使用不熟练：右手拇指指向中心轴磁场方向时，四指的环绕方向判断颠倒，把“电流方向”和“磁场方向”的因果搞错。
  • 俯视方向与三维空间混淆：默认从北极上空俯视（常见选项视角），未根据题目图示按要求转化为特定视角下的电流顺逆时针，导致错选。
  • 忽视隐含条件：不清楚“地磁场的磁感线在地球内部从北指向南、外部从南指向北”这一基本图像，无法建立安培假说中环形电流与地球整体磁场的对应。

代表题精讲

题目（2011新课标-01）

安培为解释地球的磁性提出假说：地球磁场由绕过地心的环形电流 $I$ 引起。选项中给出了不同的环形电流方向示意图，要求选出正确的方向图。

思路

地球磁场的 $N$ 极在地理南极附近，故地心环形电流产生的磁场方向应指向地理南极；运用安培定则，拇指指向地理南极（磁场 $N$ 极），四个手指弯曲方向即为环形电流方向；再根据图示视角得出正确电流环绕方式。

步骤

  1. 设定地球模型：地理北极在上，地理南极在下。地磁场的外部磁感线由地理南极指向地理北极，即地磁 $N$ 极在地理南极附近。
  2. 安培假说中的环形电流相当于一个超级大螺线管，其中心轴向为地轴方向，拇指需指向地磁 $N$ 极（地理南极附近）。
  3. 右手拇指指向地理南极（通常情况下理解为竖直向下），四指自然弯曲：从北极上方俯视，四指弯曲方向为逆时针，对应地球自西向东转动时从北极看到的逆时针电流。
  4. 题中图示若为从北极俯视，则电流应为逆时针（或四指方向向西/自东向西流动）；比对选项，确定四指方向整体为“西向”或逆时针的图即为正确答案C。

点评/变式

  • 此题核心是地磁极方位记忆＋安培定则的熟练运用。即使考点为“分子电流假说”，实际并未要求复述假说内容，而是考核运用假说模型解释实际现象的能力。
  • 变式题常改为判断地球内部环形电流位置（如“赤道面内由西向东的环形电流”“沿经线平面的环形电流”），解法不变：先找地磁 $N$ 极，再用安培定则确定电流方向。
  • 另一个易混淆点是“地理象限与立体方向”：平时记住地磁场磁感线从南向北，此处反推电流时要注意手势不变，只需把拇指方向调至真实地理南即可。
