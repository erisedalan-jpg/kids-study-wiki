考点力学权重16真题数3学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：16
  • 真题数：3；年份跨度：2017–2017
  • 出现题位：填空14 选择3 选择4
  • 难度分布：中2 难1

知识精要

  • 牛顿第一定律（惯性定律）：物体在不受外力或所受合外力为零时，总保持匀速直线运动状态或静止状态。
    匀速直线运动 $\iff$ 合外力 $\sum \vec{F}=0$。

  • 牛顿第二定律：$\sum \vec{F}=m\vec{a}$。力是产生加速度的原因，加速度与合外力同向、瞬时对应。

  • 牛顿第三定律：作用力与反作用力总是大小相等、方向相反，作用在同一直线、不同物体上。

  • 共点力平衡：物体静止或匀速直线运动时 $\sum F_x=0$，$\sum F_y=0$。常用正交分解法、矢量三角形法。

  • 向心力：做匀速圆周运动的物体所受的指向圆心的合外力 $F_向=m\frac{v^2}{R}=m\omega^2R$。向心力是效果力，由实际力（如重力、弹力、摩擦力）的合力提供。非匀速圆周运动时，向心力公式仍可用于法线方向。

  • 受力分析基本步骤：选定研究对象→画重力→找接触力（弹力、摩擦力）→分析其他场力（如电场力、浮力）→检查是否漏力、多力。

  • 浮力：$F_浮=\rho_外 g V_排$，其中 $\rho_外$ 为外界流体的密度。气体浮力同样适用阿基米德原理。

  • 平衡条件与匀速运动结合：水平桌面上的匀速运动，水平方向拉力等于滑动摩擦力 $F=\mu F_N$，竖直方向 $F_N=mg$（无其他竖直力时）。

解题方法与套路

  1. 对象·过程·状态三清原则
    明确研究对象（单个物体还是整体），划分运动过程（匀速、加速、圆周等），抓住关键状态（平衡态、圆周最低最高点、脱离点等）。

  2. 受力分析“两画一查”
    先画重力，再画接触力（弹力方向垂直于接触面，绳子张力沿绳，摩擦力沿接触面），后补场力（浮力等）。每画一个力都要明确施力物体，避免凭空添加。

  3. 建立坐标系与分解

  4. 平衡问题：让尽量多的力落在坐标轴上，列 $\sum F_x=0$，$\sum F_y=0$。
  5. 非平衡直线运动：沿加速度方向建 $x$ 轴，$\sum F_x=ma$，垂直方向 $\sum F_y=0$。

  6. 圆周运动：沿半径方向（向心方向）列 $F_向=m\frac{v^2}{R}$，切线方向列 $\sum F_切=ma_切$。

  7. 寻找补充方程
    摩擦力 $f=\mu F_N$，弹簧弹力 $F=kx$，浮力 $F_浮=\rho g V_排$。几何关系（绳长不变、角度相等）、运动学关系（速度、位移与半径关联）常被遗漏。

  8. 整体法与隔离法灵活切换
    求系统外力优先用整体法，求系统内力必须用隔离法。整体法条件：各部分加速度相同。

  9. 临界状态挖掘
    “恰好”“刚好”“最大”等词暗示临界：如轨道顶点的最小速度 $v_{min}=\sqrt{gR}$（杆模型 $v_{min}=0$），刚好脱离时弹力为零，绳刚好松弛时张力为零。

高频易错

  • 把“匀速直线运动”等同于“不受力”：实际上是合外力为零，摩擦力与拉力平衡，而不是没有摩擦力。漏掉摩擦力导致受力分析残缺。

  • 向心力来源分析不清：误以为向心力是单独施加上去的特殊力。光滑轨道的内壁弹力、外壁弹力、绳拉力、重力分量都可以充当向心力。轨道外侧运动时，注意弹力方向垂直接触面指向圆心；内侧运动时指向背离圆心。

  • 浮力计算中密度用错：热气球所受浮力应按气球外部冷空气密度计算，而非内部热空气密度。气球内部气体重力用内部密度。

  • 平衡问题中漏掉某个方向的分量：斜面或曲面上的平衡，重力沿斜面分量易遗漏，或正交分解时角度对应错误。

  • 牛顿第三定律应用不当：将作用力与反作用力误认为平衡力而错误抵消。例如人对地面的压力和地面对人的支持力是作用反作用，不能在一个物体上平衡。

  • 忽略状态突变时的瞬时加速度：绳断或弹簧释放瞬间，加速度可能突变，需重新受力分析，之前平衡的结论不再适用。

代表题精讲

代表题一：2017-新课标Ⅱ-03（水平拉力下物块匀速运动）

  • 题目：一物块在水平拉力 $F$ 作用下沿水平桌面做匀速直线运动。判断相关力的大小关系或做功情况（原题考查摩擦力与平衡）。
  • 思路：匀速直线运动→合外力为零。水平方向：$F = f$；竖直方向：$F_N = mg$，且 $f = \mu F_N$。若涉及做功，拉力做正功，摩擦力做负功，合力做功为零，动能不变。
  • 步骤：
  • 画受力分析图：竖直向下的重力 $mg$，竖直向上的支持力 $F_N$，水平向前的拉力 $F$，水平向后的滑动摩擦力 $f$。
  • 列平衡方程：$F - f = 0$，$F_N - mg = 0$。
  • 补充 $f = \mu F_N$，得出 $F = \mu mg$。
  • 根据问题判断选项，如力的大小、做功正负。注意滑动摩擦力与速度方向相反，做负功。
  • 点评/变式：此类匀速直线运动常结合 $F$ 方向改变（如斜向上拉）或接触面粗糙程度变化。若拉力斜向上，则需分解拉力，支持力变为 $mg - F\sin\theta$，摩擦力变为 $\mu(mg - F\sin\theta)$，平衡表达式改变，可求最省力角度 $\tan\theta = \mu$。

代表题二：2017-新课标Ⅱ-04（半圆形光滑轨道）

  • 题目：半圆形光滑轨道固定在水平地面，直径与地面垂直。让小球从不同位置由静止释放，分析运动过程中受力、速度、压力、脱离等。
  • 思路：光滑轨道，无摩擦，机械能守恒。轨道为圆形，最低点与最高点向心力由重力和弹力的合力提供。最高点临界速度 $v_{min}=\sqrt{gR}$，低于此速未到最高点即脱离轨道做斜抛。
  • 步骤：
  • 取最低点为零势能面，设释放点与圆心连线与竖直方向夹角为 $\theta$，由机械能守恒：$mgR(1-\cos\theta) = \frac{1}{2}mv^2_{低}$ 或至任意点。
  • 对轨道任意点受力分析：径向：$F_N \pm mg\cos\alpha = m\frac{v^2}{R}$（$\alpha$ 为与竖直方向夹角，弹力方向视内侧或外侧而定）。切向：$mg\sin\alpha = ma_切$。
  • 最高点处：若从等高处释放（$\theta=90^\circ$），到达最高点时速度为 $0$，所需向心力 $0$，此时若轨道是外侧，小球会提前脱离；若是内侧（类似于翻滚过山车），到达最高点速度至少 $\sqrt{gR}$。
  • 判脱离：当弹力 $F_N=0$ 时为脱离临界，结合机械能守恒可求脱离角 $cos\alpha = 2/3$（常见小球从内轨顶部稍下滚动的脱离点）。
  • 点评/变式：该模型是圆周运动与机械能守恒的综合。常考脱离瞬间的速度、脱离后的斜抛最值。注意区分“绳模型”与“杆模型”最高点临界速度差异；轨道内侧与外侧弹力方向的差异。
