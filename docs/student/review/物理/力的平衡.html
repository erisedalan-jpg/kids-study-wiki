知识精要

  • 共点力平衡条件：物体所受合力为零，即 $\sum \vec{F}=0$。正交分解形式：$\sum F_x=0$，$\sum F_y=0$。
  • 受力分析基本步骤：明确研究对象→按重力、弹力、摩擦力、电场力、磁场力等顺序分析→画受力示意图。
  • 连接体平衡：整体法（分析系统外力）与隔离法（分析内力）结合。利用“刚性杆连接”带来的几何约束，列写位移或体积关系。
  • 常见力的平衡表达：
  • 压强问题中 $F=pS$，注意面积不同时力也不同。
  • 库仑力 $F=k\frac{q_1 q_2}{r^2}$，方向沿连线。
  • 电场力 $F=qE$，大小 $E$ 不变时仅方向随电场变化。
  • 滑动摩擦力 $f=\mu N$，静摩擦力依平衡条件计算。
  • 准静态过程平衡：如缓慢抽气，每一步仍可视为平衡态，外力变化缓慢，可用平衡方程联系初始与末态。

解题方法与套路

  1. 确定研究对象：单物体或系统。若涉及内力且已知外力足够，优先整体法；需解内力时隔离分析。
  2. 规范受力分析：画出每个力的方向、作用点。注意施力物体，避免多力或漏力。
  3. 建立平衡方程：
  4. 若三力平衡，优先用合成法或拉密定理，构成闭合矢量三角形。
  5. 多力平衡，建立直角坐标系，将力分解到坐标轴上，列 $\sum F_x=0$、$\sum F_y=0$。
  6. 关联补充方程：库仑力合成、几何约束（如刚性杆连接导致体积变化量之比等于截面积反比）、胡克定律等。
  7. 求解并检验：注意物理量的对应关系，结果合理性（如压强、体积非负）。

高频易错

  • 受力分析对象错误：如活塞平衡问题中，误将整个容器作为研究对象，无法得到内力(压强差)。
  • 面积与力的匹配：活塞两侧气体压强乘各自侧面积才是力，常错写成 $p_1 = p_2$ 而忽略面积因子。
  • 电场旋转后力的变化：带电微粒在平行板电容器中，板转过角度后场强大小不变，仅方向跟随旋转；易错认为电场力大小变化或方向保持原状。
  • 库仑力方向与叠加：同号相斥、异号相吸，求合力时易弄错方向；三个电荷平衡时，要同时满足每个电荷合力为零。
  • 实验中的平衡转化：测动摩擦因数时，木块“相对桌面静止”是为了使弹簧秤示数等于滑动摩擦力；若木块与木板同步运动则会引入静摩擦或运动不一致，导致读数不是真实滑动摩擦力。
  • 几何关系疏忽：如两汽缸活塞刚性连接，移动距离比等于截面积反比，未找出体积变化关系导致无法求解。

代表题精讲

代表题1：2019年新课标Ⅱ-14（活塞连接体平衡与气体定律）

题目
横截面积分别为 $2S$ 和 $S$ 的汽缸连通，刚性杆连接的两活塞将容器分为氢气、空气、氮气三部分。初始平衡时，氮气压强 $p_0$、体积 $V_0$，氢气体积 $2V_0$，空气压强 $p$。缓慢抽走空气，温度不变，活塞未达连接处。求：(i) 抽气前氢气压强；(ii) 抽气后氢气压强和体积。

思路
(i) 抽气前活塞平衡：选取两活塞整体（或分别对两活塞）分析受力，水平方向受到两侧气体压力，列平衡方程求解氢气压强。
(ii) 抽气后空气压强为零，活塞新平衡；对氢气、氮气分别应用玻意耳定律，结合刚性杆几何约束（两活塞移动距离关系）列方程组求解。

步骤
(1) 抽气前，对活塞和刚性杆整体水平方向：氢气压力向右 $p_{\text{氢}}\cdot 2S$，空气向左 $p\cdot 2S$，氮气向左 $p_0 S$，空气向右 $p S$（右侧活塞空气部分），合力为零：
$(p_{\text{氢}} - p)\cdot 2S = (p_0 - p)S \;\Rightarrow\; p_{\text{氢}} = \frac{1}{2}(p_0 + p)$。
(2) 抽气后，中间空气压强为零。设氢气压强与体积为 $p_1, V_1$，氮气压强与体积为 $p_2, V_2$。活塞平衡：$p_2 S = p_1 \cdot 2S$，即 $p_2 = 2p_1$。
(3) 等温变化：氢气 $p_1 V_1 = p_{\text{氢}}\cdot 2V_0$；氮气 $p_2 V_2 = p_0 V_0$。
(4) 刚性杆几何关系：氢气体积增加量等于氮气体积减少量的两倍（因活塞面积与移动距离的关系），即 $V_1 - 2V_0 = 2(V_0 - V_2)$。
(5) 联立解得 $p_1 = \frac{1}{2}p_0 + \frac{1}{4}p$，$V_1 = \frac{4V_0(p_0 + p)}{2p_0 + p}$（具体表达式依计算）。

点评/变式
本题是受力平衡、气体实验定律与几何约束的综合。关键：(a) 区分“压强”和“压力”，$F = pS$；(b) 刚性杆连接使两活塞位移关联，体积变化量呈固定比例。变式可改为不同截面积比或加入弹簧等。

代表题2：2018年新课标Ⅱ-10（利用平衡测动摩擦因数）

题目
用图(a)装置测量木块与木板间动摩擦因数。跨过光滑定滑轮的细线两端分别连接木块和弹簧秤，木块上方可放砝码。缓慢向左拉动木板，木块和砝码相对桌面静止时，弹簧秤示数即为滑动摩擦力大小$f$。实验记录砝码质量$m$与对应$f$数据，$f_4$从图(b)读出。求动摩擦因数。

思路
木块静止→水平方向二力平衡：弹簧拉力$F$（即弹簧秤示数）等于滑动摩擦力$f$。竖直方向：$N=(M+m)g$，$f=\mu N$，因此$f=\mu (M+m)g$。由多组$(m, f)$数据通过作图或线性拟合求斜率可得$\mu$。

步骤
(1) 图(b)读出$f_4$（如2.75N等，依图）。
(2) 列出$f$—$(M+m)g$的关系：$f = \mu (M+m)g$，即$f$与$m$呈线性。
(3) 由数据计算$\mu$：可用$\mu = \frac{\Delta f}{g \Delta m}$（逐差法）或图像斜率÷$g$得到。

点评/变式
巧妙处在于将动摩擦转化为静力学测量，克服了直接测运动摩擦的困难。关键在于木块始终保持静止（相对桌面），确保弹簧秤示数等于滑动摩擦力。若木板加速拉动，只要木块静止，示数仍为滑动摩擦力，因为滑动摩擦力仅与正压力和动摩擦因数有关，与相对速度大小无关（低速时）。

代表题3：2017年新课标Ⅱ-03（水平匀速直线运动中的平衡）

题目
一物块在水平拉力$F$的作用下沿水平桌面做匀速直线运动。已知物块质量$m$，重力加速度$g$，求动摩擦因数（或拉力$F$）。

思路
物块匀速→合力为零。水平方向：$F=f$；竖直方向：$N=mg$。滑动摩擦力$f=\mu N$，联立得$F=\mu mg$。

步骤
(1) 画受力图：重力$mg$向下，支持力$N$向上，拉力$F$沿水平运动方向，摩擦力$f$反向。
(2) 竖直平衡：$N=mg$；水平平衡：$F=f$。
(3) 由$f=\mu N$得$F=\mu mg$，若已知$F, m$可解$\mu$；反之亦然。

点评/变式
本题为最基础的共点力平衡。易错点：误认为拉力倾斜或忽略摩擦力方向的判断。变式可将桌面倾斜，考查斜面平衡问题，需正交分解。
