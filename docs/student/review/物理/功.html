知识精要

  • 功的定义：力对物体做的功等于力的大小、位移大小、力与位移夹角余弦的乘积。公式：$W = Fl\cos\theta$。
  • $\theta \in [0, \frac{\pi}{2})$，力做正功。
  • $\theta = \frac{\pi}{2}$，力不做功。
  • $\theta \in (\frac{\pi}{2}, \pi]$，力做负功，也称物体克服此力做功。
  • 恒力功计算：直接利用 $W = Fl\cos\theta$ 或 $W = Fx$（当力与位移同向时）。
  • 变力功计算：
  • 利用动能定理：$W_{\text{合}} = \Delta E_k$。
  • 利用 $W - x$ 图像的面积求功。
  • 微元法或能量守恒（高考中多以前两者为主）。
  • 功率：
  • 平均功率：$\bar{P} = \frac{W}{t}$ 或 $\bar{P} = F\bar{v}\cos\theta$。
  • 瞬时功率：$P = Fv\cos\theta$。
  • 一对相互作用力的功：作用力与反作用力做功的代数和不一定为零，其正负取决于两物体的相对位移方向。

解题方法与套路

  1. 明确研究对象与过程：准确选取单个物体或系统，确定运动的初、末位置和经历的过程。
  2. 受力分析求总功：
  3. 分析各力是否做功、做正功还是负功。
  4. 恒力总功优先使用 $W_{\text{合}} = F_{\text{合}}l \cos\theta$；变力或曲线运动中，常先求各力做的功再求代数和，或直接使用动能定理。
  5. 动能定理是利器：在涉及变力做功（如空气阻力、拉力等）、多过程复杂运动或仅需知道初末速度变化时，优先选用 $W_{\text{总}} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$ 来架起力与运动的桥梁。
  6. 分析功率变化：判断某力瞬时功率的变化，需紧扣 $P = Fv$，分析 $F$ 或 $v$ 是否恒定，以及它们的变化趋势。
  7. 巧用图像法：遇到 $W-x$ 图，图线的斜率代表力 $F$，图线与 $x$ 轴围成的面积代表该段位移内拉力所做的功。
  8. 系统机械能守恒与功的关系：在只有系统内重力或弹力做功的条件下，系统内一个物体机械能的减少量，等于另一个物体机械能的增加量。杆、绳等连接体问题中，弹力可能对单个物体做功，但其对系统做的总功为零。

高频易错

  • 摩擦力做功的重复计算：不要将滑动摩擦力产生的热量 $Q = f \cdot s_{\text{相对}}$ 与摩擦力对单个物体的做功 $W_f = f \cdot s_{\text{对地}}$ 混淆。2014年真题明确展示了 $W_f$ 正比于对地位移，与动能定理结合求解其他力做功的套路。
  • 错误判断弹力不做功的情形：光滑面、不可伸长的绳、刚性杆对物体做的功虽总功为零，但对单个物体可以做正功或负功。如2015年真题，杆对 $b$ 先做正功后做负功；2017年真题，圆环弹力始终垂直速度方向不做功。
  • 误认为“速度为0时合力必为0”：在物体运动的瞬时静止点（如单摆最高点），速度为零但加速度不为零，合力不为零。2015年真题 $a$ 落地前瞬间加速度大小可以大于 $g$，并非始终不大于 $g$。
  • 错误使用功率公式：求瞬时功率，必须用该时刻的瞬时速度和该时刻作用力的乘积。求平均功率，用功除以时间。由 $F-t$ 图或 $v-t$ 图求功率时，要注意对应时刻的点对点关系。
  • 混淆“克服某力做功”与“该力做功”：克服阻力做功等于阻力做功的负值，即正值。在动能定理方程中，若设克服阻力做功为 $W$，则表达式为 $W_{\text{其他}} - W = \Delta E_k$。

代表题精讲

代表题一：2023-新课标-02

  • 题目：雨滴以恒定速率竖直下落 $h$ 高度，求克服空气阻力做的功（已知质量 $m$、重力加速度 $g$）。
  • 思路：核心信息是“恒定速率”下落，隐含雨滴处于二力平衡状态，且动能不变。可直接应用动能定理或将功与能的变化联系起来。
  • 步骤：
  • 明确过程：雨滴下落高度 $h$，初末速度均为 $v$，故 $\Delta E_k = 0$。
  • 受力分析并应用动能定理：该过程有重力做正功 $mgh$，空气阻力做负功，设其做功为 $W_f$。则 $mgh + W_f = 0$。
  • 求解：解得 $W_f = -mgh$。故克服空气阻力做功为 $mgh$。
  • 点评/变式： “匀速”是动能定理的快捷键，直接给出总功为零。变式中，若下落时受恒定水平风力，问题变为求合外力或某个变力做功，此时用动能定理分析复杂路径上合力做功依然是首选。

代表题二：2021-全国乙-11

  • 题目：篮球从 $h_1$ 自由下落反弹至 $h_2$，已知碰撞前后动能比值恒定。现从 $h_3$ 下落，要求反弹同为 $h_3$，需在开始下落时向下拍球，作用时间 $t$ 恒定。求(1)拍球做功；(2)拍球作用力大小。
  • 思路：利用自由下落和反弹高度求出篮球与地面碰撞过程的动能损耗比例。第二次下落过程包含“人拍球”和“重力做功”两部分使球获得初始动能，利用该比例建立方程求解功。
  • 步骤：
  • 求动能比值：设碰前动能为 $E_k$，碰后动能为 $E_k'$。第一次过程有 $E_k = mgh_1$，$E_k' = mgh_2$。则比值 $k = \frac{E_k}{E_k'} = \frac{mgh_1}{mgh_2} = \frac{1.8}{1.2}= 1.5$。即每次碰撞后动能变为碰前的 $\frac{1}{1.5} = \frac{2}{3}$。
  • 求拍球做功 $W$：第二次，设球刚脱离手时的动能为 $E_{k0}$。下落碰地前动能 $E_{k1} = mgh_3 + E_{k0}$。碰后动能 $E_{k2} = \frac{2}{3}E_{k1}$。反弹至 $h_3$ 高处，由动能定理 $-mgh_3 = 0 - E_{k2}$，得 $\frac{2}{3}(mgh_3 + E_{k0}) = mgh_3$。代入数据解得 $E_{k0} = \frac{1}{2}mgh_3 = 4.5 \text{J}$。即人拍球做功 $W = 4.5\text{J}$。
  • 求作用力 $F$：拍球过程，球在恒力 $F$ 和重力 $mg$ 作用下向下加速，由动能定理 $(F+mg)x = W = \frac{1}{2}mv^2$。再结合动量定理 $(F+mg)t = mv$，或由匀变速规律 $\frac{v}{2}t = x$，联立求解。由 $W = \bar{F}x$ 和动量定理 $(F+mg)t = m v$，且 $W = \frac{1}{2}mv^2$，可得 $(F+mg)t = \sqrt{2mW}$ 。代入数据解得 $F = 9\text{N}$。
  • 点评/变式： 连接多过程的桥梁是“碰撞前后动能比值不变”，这是功能关系中的典型条件。求功时，动能定理比牛顿定律更直接。求作用力时，需联合动量定理或运动学公式。
