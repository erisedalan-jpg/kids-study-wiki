功率

知识精要

功率是描述力对物体做功快慢的物理量，是标量。核心公式为定义式 $P=\frac{W}{t}$ 与计算式 $P=Fv\cos\alpha$（$\alpha$ 为力 $F$ 与速度 $v$ 的夹角）。在高考中需要重点掌握平均功率 $\bar{P}=\frac{W}{t}$ 与瞬时功率 $P=Fv$ 的区分与计算。当力的方向与速度方向同向时，公式简化为 $P=Fv$，此式是分析机车启动问题的关键。

机车启动模型是考查重点。两种典型启动方式：一是以恒定功率 $P_0$ 启动，由 $F=\frac{P_0}{v}$ 知牵引力随速度增大而减小，加速度随之减小，汽车做加速度减小的加速运动，当 $F=f$ 时达到最大速度 $v_m=\frac{P_0}{f}$，其$v\text{-}t$图像为斜率逐渐减小的曲线。二是以恒定加速度启动，牵引力 $F$ 恒定，由 $P=Fv$ 知功率随时间均匀增大，当功率达到额定功率后，开始做功率恒定的变加速运动，直至匀速。两组约束关系 $F-f=ma$ 与 $P=Fv$ 是解题核心。

同时需掌握功率与功能关系的结合，如利用动能定理计算变力做功从而实现功率转化，或结合法拉第电磁感应定律计算安培力功率等综合问题。

解题方法与套路

  1. 明确求什么功率：先审题确定目标是某段时间内的平均功率还是某一时刻的瞬时功率。平均功率优先用 $\bar{P}=\frac{W}{t}$ 或 $\bar{P}=F\bar{v}$（适用于恒力）。瞬时功率必须用 $P=Fv$，其中的 $v$ 为该时刻的瞬时速度。
  2. 分析运动与受力：对于非匀速运动，必须进行受力分析和运动分析，通常需结合牛顿第二定律 $F_{\text{合}}=ma$ 或平衡方程。这是通过速度变化反推力，或通过力变化推速度的基础。尤其是处理图像问题时，要能根据功率/功的图像斜率或面积获取力的信息。
  3. 机车启动的图像转化：遇到功率 $P$ 随时间 $t$ 变化的图像，要能推导出速度 $v$ 随时间 $t$ 变化的图像。核心是通过 $F=\frac{P}{v}$ 和 $F-f=ma$ 得到 $a=\frac{P/v - f}{m}$，确定加速度的变化趋势，从而勾勒出速度图线的凹凸性。
  4. 综合问题的功率拆解：当涉及多个力做功时，若求总功率，可采用 $P_{\text{总}} = F_{\text{合}}v$（矢量形式）或分别求各力功率代数和。在电磁感应中，外力的功率常转化为焦耳热功率和摩擦生热功率，利用能量守恒求外力的功率是高效解法。

高频易错

  • 混淆平均功率与瞬时功率：本题集中频繁出现利用$v\text{-}t$图像或$W\text{-}x$图像判断功率大小与正负的题目。务必注意，$P=\frac{W}{t}$求的是$t$时间内的平均功率，$P=Fv$在$v$为瞬时速度时才是瞬时功率。切忌将功的正负变化与瞬时功率的大小变化直接等同。
  • 误判“功率最大”位置：在变加速运动中，随着速度增大，若牵引力减小，它们的乘积 $Fv$（即瞬时功率）不一定在速度最大时最大。如恒定功率启动中，功率始终为额定功率；在匀加速+恒定功率组合中，匀加速阶段结束时功率才达到并维持最大，但速度此时并非最大。
  • 忽视“外力”构成：计算外力的功率时，必须明确“外力”指的是所有作用力还是一个特定力。例如在电磁感应杆模型中，$F$ 外力的功率除克服安培力做功外，还需克服摩擦力、重力做功，若考虑不全会导致动能定理建立等式错误。
  • 功$W$与位移$x$图像的斜率：$W\text{-}x$ 图像的斜率 $k=\frac{\Delta W}{\Delta x}$ 在恒力作用下数值上等于该力的大小。如果物体受变力，则图像切线斜率反映该时刻的力。误判斜率物理意义会导致无法正确提取力或加速度信息。

代表题精讲

2023-新课标-07

题目：一水平面上的物体在水平拉力和摩擦力作用下滑动，给出拉力做功$W$随位移$x$的变化图像，要求根据已知的质量与摩擦因数判断相关说法。 思路：先利用动摩擦因数求出恒定的摩擦力大小 $f=\mu mg$。重点关注 $W\text{-}x$ 图像：图像的斜率代表拉力 $F$ 的大小。分段求出拉力作用的区间和大小，然后通过受力分析求出各阶段的加速度，利用运动学公式分析速度变化，最后将外力功率拆解为拉力的功率与摩擦力功率之和进行检验。 步骤： 1. 计算摩擦力大小 $f=0.4\times1\times10\,\text{N}=4\,\text{N}$。 2. 由 $W\text{-}x$ 图读取斜率：前段（如 $0$~$2\,\text{m}$）斜率恒定，拉力 $F_1=…\,\text{N}$（可求得）；后段拉力 $F_2=…\,\text{N}$。比较各阶段拉力与摩擦力大小，明确物体分别做匀加速、匀减速或匀速。 3. 分段求加速度 $a=\frac{F-f}{m}$，据 $v_t^2 - v_0^2 = 2ax$ 求出关键位置的速度。 4. 各时刻拉力的瞬时功率 $P_F = Fv$，摩擦力的瞬时功率 $P_f = -fv$，合外力功率为二者代数和，或按 $P_{\text{总}}=(F-f)v$ 计算。对标选项得解。 点评/变式：此题核心是“图像斜率即力”。凡是给出力做的功随位移变化的线性图，默认该过程受恒力作用。易错点在于没有计入摩擦力做功，或在求“外力”功率时忘记摩擦力也是外力。

2015-新课标Ⅱ-04

题目：给出汽车功率 $P$ 随时间 $t$ 变化的图线，在 $0$~$t_1$ 内功率与时间成正比，$t_1$ 后功率恒定。阻力恒为 $f$，判断可能的 $v\text{-}t$ 图线。 思路：这是“先恒定加速度后恒定功率”启动模型的图像逆向判断。$0$~$t_1$ 内 $P=kt$，由 $P=Fv$ 及 $F-f=ma$ 可推出，只有牵引力 $F$ 恒定且速度 $v$ 均匀增大（匀加速），功率才会随时间线性增大。$t_1$ 时刻功率达额定值，之后保持功率不变，机车做加速度减小的加速运动。速度图线应为先直线上升，后上凸曲线上升到最大值。 步骤： 1. 分析 $0$~$t_1$：$P \propto t$。若做匀加速 $v=at$，且 $F$ 恒定，则 $P=Fv=Fat \propto t$，符合题意。故此段 $v\text{-}t$ 图为过原点倾斜直线。 2. 分析 $t_1$~$t_2$：$P=P_0$（恒定值）。由 $F=\frac{P_0}{v}$ 知 $v$ 增则 $F$ 减，结合 $a=\frac{F-f}{m}$ 知加速度减小。故此段 $v\text{-}t$ 图线斜率持续减小，呈上凸形状至 $v$ 达最大匀速。 3. 观察选项找到先直线后上凸曲线、且没有斜率突变点的图线。 点评/变式：关键是把功率图转换为受力图。典型的易错选项是画出“下凸”曲线，混淆了加速度减小与速度变化率减小的区别。只要紧抓 $a \to 0$ 时速度趋于匀速，图像必为“上凸”。

2014-新课标Ⅱ-12

题目：在匀强磁场中，直导体棒绕一端以角速度 $\omega$ 在同心圆导轨上匀速转动，已知各物理量，求感应电流方向与大小及外力的功率。 思路：转动切割磁感线产生了感应电动势，先用右手定则求电流方向，用法拉第电磁感应定律计算感应电动势 $E= \frac{1}{2}B\omega( (2r)^2 - r^2)$ 得电流大小。求外力功率，由于棒匀速转动，外力矩功率等于安培力阻力矩功率与摩擦力阻力矩功率之和。 步骤： 1. 用右手定则判断切割方向得出电流方向。 2. 计算电动势：$E = \frac{1}{2}B\omega (L_2^2 - L_1^2) = \frac{3}{2}B\omega r^2$，故 $I=\frac{E}{R}$。 3. 计算安培力的功率。棒上各处线速度不同，直接用能量守恒：电能转化为热 $P_{\text{电}}=I^2 R$，$P_{\text{电}} = \frac{9B^2\omega^2 r^4}{4R}$。 4. 计算克服摩擦力的功率。棒转动时，各处速度不同，需取质心或中点等效，或积分求总摩擦力功率。最终外力功率 $P_{\text{外}}=P_{\text{电}} + P_{\text{摩擦}}$。 点评/变式：求变力功率时，能量守恒是首选。对于匀速转动杆，外力做功全部转化为焦耳热和摩擦热。难点在于摩擦功率的计算，必须考虑速度的线性分布采用等效法或微元法。
