加速度

  • 真题数：4；年份跨度：2011–2018
  • 出现题位：选择1 选择6 选择7 选择11

知识精要

  • 加速度定义：加速度 $a = \frac{\Delta v}{\Delta t}$，是矢量，方向与速度变化量 $\Delta v$ 的方向相同。加速度描述速度变化的快慢，与速度大小、速度变化大小无必然联系。
  • 匀变速直线运动：加速度恒定不变的运动。速度公式 $v = v_0 + at$，位移公式 $x = v_0t + \frac{1}{2}at^2$，速度与位移关系 $v^2 - v_0^2 = 2ax$。适用条件：加速度矢量恒定（大小、方向均不变）。
  • 加速度与速度的关系：加速度方向与速度方向相同时，物体做加速运动；方向相反时，做减速运动。速率增大或减小仅由加速度与速度的夹角决定，与加速度大小变化无关。
  • $v-t$ 图像中的加速度：斜率 $k=\tan\theta$ 表示加速度。斜率大小代表加速度大小，斜率正负代表加速度方向（通常规定正方向）。图像与时间轴围成的面积表示位移，面积差可以比较两物体在同一时段内的相对位移。
  • 曲线运动中的加速度：加速度（合外力）方向指向轨迹的凹侧。速率变化取决于加速度切向分量：切向加速度与速度同向，速率增大；反向，速率减小。法向加速度只改变速度方向。

解题方法与套路

  1. $v-t$ 图像问题通用步骤
  2. 明确横轴、纵轴物理量及正方向规定。
  3. 斜率：切线的斜率代表瞬时加速度，斜率绝对值的变化趋势对应加速度大小的变化（斜率变陡→加速度增大，斜率变缓→加速度减小）。
  4. 面积：图像与 $t$ 轴围成的面积表示位移，不同图线在同一时间段内的面积差表示相对位移，用于判断前后、并排、相遇等问题。
  5. 交点：两图线交点表示该时刻速度相等，不一定相遇，结合初始位置才能判断位置关系。
  6. 判断加速度大小变化的方法
    在 $v-t$ 图中观察切线斜率的绝对值变化：若曲线越来越平缓，斜率绝对值减小，加速度大小减小；若曲线越来越陡直，斜率绝对值增大，加速度大小增大。注意区分“大小”和“方向”，描述时应明确。
  7. 前后车或并排问题
  8. 先找准已知时刻的位置关系（如“$t_2$ 时刻并排”）。
  9. 比较从参考时刻到 $t_2$ 的位移差（面积差），反推其他时刻的位置。若 $t_1$ 到 $t_2$ 内甲位移大于乙位移，且 $t_2$ 时并排，则 $t_1$ 时甲在后乙在前。
  10. 常用口诀：“并排看面积累差，前车追后车看位移增量”。
  11. 电场中曲线运动的速率与加速度方向判断
  12. 步骤一：在轨迹上选点（如 $b$ 点），画出速度方向（沿切线）。
  13. 步骤二：根据速率递减确定合力（加速度）方向与速度方向夹角为钝角（$>90^\circ$）。
  14. 步骤三：合力方向必须指向轨迹凹侧，确定大致合力方向。
  15. 步骤四：若牵扯电场力，必用场强方向与电荷正负：正电荷受力与 $E$ 同向，负电荷受力与 $E$ 反向。结合电场方向推得正确选项。

高频易错

  • 平均速度公式错用：$\overline{v} = \frac{v_0+v}{2}$ 仅适用于匀变速直线运动。非匀变速（如加速度变化的变加速运动）不可套用，必须使用 $\overline{v} = \frac{x}{t}$ 计算。
  • $v-t$ 图像中面积和位移的混淆：面积有正负，若图像在 $t$ 轴下方，面积代表负位移。比较两车位置关系时，务必计及全部面积（位移），而非只看速度大小。
  • 斜率大小判断被图像弯向迷惑：有时曲线向上弯（斜率逐渐增大）并不代表加速度大小一定增大，还要考虑坐标轴标度及正方向。切线的陡峭程度才是唯一判据。
  • 并排问题忽略初始位置：并排指位置坐标相同，$v-t$ 图只能得到相对位移变化，必须结合某个时刻的确定位置信息（如“$t_2$ 时刻并排”）反推其它时刻。
  • 曲线运动中误判加速度方向：正确方法是加速度指向轨迹凹侧，同时满足速率变化与夹角关系。尤其注意带负电粒子受力与电场强度方向相反，容易仅画出受力方向就直接选电场方向，未做反向导致错误。
  • 加速度大小变化与速度变化混淆：加速度减小只说明速度增加（或减小）得越来越慢，但速度仍可能继续增加。不要一见加速度减小就认为速度随之减小。

代表题精讲

代表题1：2018-新课标Ⅱ-06

题目：甲、乙两汽车同向运动，$v-t$ 图线为两条曲线，$t_2$ 时刻两车并排行驶。判断 $t_1$ 时刻位置关系及两车加速度大小的变化情况。选项：A. 两车在 $t_1$ 时刻也并排行驶；B. 在 $t_1$ 时刻甲车在后，乙车在前；C. 甲车加速度大小先增大后减小；D. 乙车加速度大小先减小后增大。
思路：运用 $v-t$ 图像面积表位移，斜率表加速度。从 $t_2$ 并排出发，比较 $t_1$ 到 $t_2$ 内两车位移差，确定 $t_1$ 前后位置。观察图线弯曲趋势，判断切线斜率绝对值变化，从而确定加速度大小的变化。
步骤：
1. 从 $t_1$ 到 $t_2$，甲图线与 $t$ 轴围成的面积大于乙的面积，说明甲在此段时间内的位移大于乙的位移。
2. $t_2$ 时刻两车并排（位置相同），则 $t_1$ 时刻甲的位置应比乙靠后，即甲在后、乙在前，故 A 错 B 对。
3. 观察甲图线，斜率（由曲线切线可见）先较平后变陡再变平，斜率绝对值是先小后大又变小？实际图像甲为类凸曲线，切线斜率绝对值逐渐减小，故甲车加速度大小一直减小，C 错。
4. 乙图线在上凸与下凹间有拐点，切线斜率绝对值先减小后增大，故乙车加速度大小先减小后增大，D 对。
点评/变式：本题核心是 $v-t$ 图像的面积法和斜率法。变式可让两车多次相遇，或改为 $x-t$ 图像，亦可引入加速度图像。注意加速度大小只看斜率绝对值，不要凭曲线“上下”主观臆断。

代表题2：2014-新课标Ⅱ-01

题目：甲乙两车 $t=0$ 到 $t=t_1$ 内 $v-t$ 图如图所示，判断平均速度、位移和加速度变化。选项：A. 汽车甲的平均速度比乙的大；B. 乙的平均速度 $\overline{v} = \frac{v_1+v_2}{2}$；C. 甲乙位移相同；D. 甲加速度大小逐渐减小，乙加速度大小逐渐增大。
思路：直接比较面积得位移，进而比较平均速度。确认乙车并非匀变速，不能用匀变速平均速度公式。看切线斜率变化判断加速度大小增减。
步骤：
1. 甲图线与 $t$ 轴围成面积显著大于乙，故甲的位移大于乙的位移，时间相同，则 $\overline{v}_甲=\frac{x_甲}{t_1} > \overline{v}_乙=\frac{x_乙}{t_1}$，A 正确，C 错误。
2. 乙做变减速运动，加速度不恒定，$\overline{v} = \frac{v_1+v_2}{2}$ 仅对匀变速成立，此处不适用，B 错误。
3. 甲曲线上各点切线的斜率绝对值逐渐减小，故加速度大小逐渐减小；乙曲线斜率绝对值逐渐增大，故加速度大小逐渐增大，D 正确。
点评/变式：平均速度公式使用条件必须牢记。此题可与追击相遇、功率变化综合，也可变为给出 $a-t$ 图像推 $v-t$ 特征，考查逆向思维。

代表题3：2011-新课标-07

题目：一带负电荷的质点，在电场力作用下沿曲线 $abc$ 从 $a$ 运动到 $c$，速率递减。判断 $b$ 点电场强度 $E$ 的方向。
思路：质点速率递减 → 合力（电场力）与速度夹角为钝角。曲线运动合力指向凹侧。由质点带负电，电场力方向与 $E$ 方向相反，由此确定 $E$ 正确指向。
步骤：
1. 在 $b$ 点画出速度方向沿切线（虚线给出）。因速率减小，合力方向与速度夹角必大于 $90^\circ$。
2. 合力又必须指向轨迹凹侧，结合这两条，可确定电场力的大致方向。
3. 质点带负电，电场力 $F = -eE$，即受力方向与场强方向相反。将电场力方向反转，即得电场强度 $E$ 的方向。
4. 对照各个选项图，选择满足：$E$ 的反向（受力）指向凹侧且与切向速度成钝角的选项。
点评/变式：处理曲线运动中的受力与场强方向，常用口诀：“凹侧受力，钝角减速；正电同向，负电反向”。变式可把轨迹曲线换成圆弧，讨论速率变化时法向加速度和切向加速度，或引入磁场与洛伦兹力等。
