动力学

考点动力学权重6真题数1学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：6
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：选择11
  • 难度分布：难1

知识精要

  • 匀变速直线运动基本公式：
    速度公式 $v = v_0 + at$
    位移公式 $x = v_0t + \frac{1}{2}at^2$
    速度–位移关系 $v^2 - v_0^2 = 2ax$
    适用条件：加速度恒定、直线运动。

  • 牛顿第二定律：$F = ma$，矢量式。独立分量式：$F_x = ma_x$，$F_y = ma_y$。
    应用步骤：明确研究对象→受力分析→正交分解→列方程求解。

  • 滑动摩擦力：大小 $f = \mu F_N$。
    计算动摩擦因数 $\mu$ 时，通常利用 $f$ 与 $F_N$ 的比值，且注意 $F_N$ 的求解必须根据竖直方向受力平衡或牛顿第二定律确定，不可盲目写成 $mg$。

  • 两类动力学问题：
    ① 已知受力情况求运动（利用牛顿第二定律求加速度，再结合运动学公式）；
    ② 已知运动情况求受力（由运动学公式逆向求加速度，再用牛顿第二定律求力）。

  • 多对象问题的处理：划分明确的研究对象，分别列方程。若两物体之间存在时间、位移、速度的关联，需寻找运动等时性、位移关系等约束条件。

解题方法与套路

  1. 拆解对象，独立分析
    将题目中的各个物体（如冰球、运动员）分开，每个物体单独进行受力分析与运动分析。

  2. 受力分析求加速度（力→运动）

  3. 画出受力示意图，标出所有力。
  4. 根据运动过程确定加速度方向，建立坐标系。
  5. 列牛顿第二定律方程 $F_\text{合} = ma$，尤其注意滑动摩擦力 $f = \mu F_N$ 的处理。

  6. 当竖直方向平衡时，$F_N = mg$。

  7. 运动过程建模（运动→力）

  8. 明确已知物理量（初速度、末速度、位移等），选用合适的运动学公式：
    已知 $v_0$、$v$、$x$ 且不涉及时间时，优先使用 $v^2 - v_0^2 = 2ax$ 求加速度。

  9. 利用加速度建立物理量与力之间的桥梁。

  10. 挖掘隐含的等时性与约束条件
    分析题目中“同时开始”“到达”“至少”等关键词：“当冰球到达挡板时，运动员至少到达小旗处”意味着冰球运动的时间与运动员运动的时间相等，且运动员的位移至少为 $s_1$。由此构建时间相等关系，联立方程求解未知量。

  11. 检查结果的合理性
    加速度、动摩擦因数等是否为正，是否符合物理情境；答案是否包含必要的文字说明和单位。

高频易错

  • 误将冰面的支持力等同于重力：此题冰球在水平冰面运动，竖直方向合力为零，$F_N = mg$，正确。但若题目中有其他竖直方向的力或斜面，切不可直接默认 $F_N = mg$，必须验证竖直方向的平衡或加速度。

  • 运动学公式方向与符号混乱：冰球做匀减速直线运动，末速度 $v_1$ 小于初速度 $v_0$，加速度应取负值（以初速度方向为正）。使用 $v_1^2 - v_0^2 = 2a s_0$ 时，注意 $a$ 为负值，配合摩擦力方向分析，避免符号错误导致 $\mu$ 为负。

  • 混淆不同研究对象的位移和时间：冰球的位移是 $s_0$（起跑线到挡板），运动员的位移至少是 $s_1$（起跑线到小旗），两者经历的时间相等。误将位移混用或弄错比例关系是常见失分点。

  • 遗漏“最小加速度”的临界条件：“至少到达”意味着运动员的位移恰好为 $s_1$ 时对应的加速度即为满足训练要求的最小值，有些考生错误地将此理解为范围而不会建立等式。

  • 单位或重力加速度符号：题目给定重力加速度为 $g$，在表达动摩擦因数或加速度时，结果中若出现 $g$，无需代入 $9.8\text{m/s}^2$ 或 $10\text{m/s}^2$，保留符号即可，切忌无中生有。

代表题精讲

题目（2017·新课标Ⅱ·11）

冰球以速度 $v_0$ 从起跑线沿垂直于起跑线方向滑向挡板，挡板距起跑线 $s_0$；同时运动员从静止起跑，垂直于起跑线匀加速滑向距起跑线 $s_1$（$s_1 < s_0$）的小旗。要求冰球到达挡板时，运动员至少到达小旗处。冰球到达挡板时速度为 $v_1$，重力加速度 $g$。求：
(1)冰球与冰面之间的动摩擦因数；
(2)满足训练要求的运动员的最小加速度。

思路
冰球做匀减速直线运动，已知 $v_0, v_1, s_0$，用速度–位移公式可直接求出加速度大小，再结合冰球在冰面上只受滑动摩擦力、竖直方向平衡，利用牛顿第二定律求 $\mu$。运动员由静止匀加速，运动时间与冰球相同，位移至少为 $s_1$，由时间相等和位移公式求最小加速度。

步骤
(1) 对冰球：设其加速度大小为 $a_b$，以初速度方向为正方向，则
$$v_1^2 - v_0^2 = -2a_b s_0 \quad\Rightarrow\quad a_b = \frac{v_0^2 - v_1^2}{2 s_0}.$$
冰球水平方向只受滑动摩擦力 $f = \mu mg$，由牛顿第二定律：
$$f = ma_b \quad\Rightarrow\quad \mu mg = m \frac{v_0^2 - v_1^2}{2 s_0},$$
解得 $$\mu = \frac{v_0^2 - v_1^2}{2 g s_0}.$$

(2) 冰球的运动时间 $t$：由 $v_1 = v_0 - a_b t$ 得
$$t = \frac{v_0 - v_1}{a_b} = \frac{v_0 - v_1}{(v_0^2 - v_1^2)/(2 s_0)} = \frac{2 s_0}{v_0 + v_1}.$$
运动员在相同时间 $t$ 内，由静止匀加速，加速度设为 $a_m$，位移至少为 $s_1$：
$$s_1 = \frac{1}{2} a_m t^2,$$
代入 $t$ 解得最小加速度：
$$a_m = \frac{2 s_1}{t^2} = \frac{2 s_1}{\left( \frac{2 s_0}{v_0 + v_1} \right)^2} = \frac{s_1 (v_0 + v_1)^2}{2 s_0^2}.$$

点评/变式
本题是典型的“牛顿运动定律+匀变速直线运动”小综合，明确了两类分析（冰球减速、运动员加速）并通过时间相等建立关联。变式可延伸为：将冰球换为在传送带上的滑块，或同时考虑摩擦力方向变化；亦可改变“至少”条件为“恰好相遇”进而求速度关系。核心方法不变：隔离对象，运动学搭桥，牛顿第二定律求力或运动。考生应熟练运用不涉及时间的速度–位移公式，减少计算环节，提升准确率。
