动能与半径关系

考点动能与半径关系权重5真题数1学科物理父主题万有引力 与 天体

考点定位

  • 父主题：万有引力 与 天体
  • 权重 weight：5
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 带电粒子在匀强磁场中的圆周运动半径
    $$r = \frac{mv}{qB}$$
    其中 $m$ 为粒子质量，$v$ 为速度，$q$ 为电荷量大小，$B$ 为磁感应强度。
    推导依据：洛伦兹力提供向心力 $qvB = m\dfrac{v^{2}}{r}$。
  • 半径与动能的关系
    动能 $E_{k} = \dfrac{1}{2}mv^{2}$，得 $v = \sqrt{\dfrac{2E_{k}}{m}}$，代入半径公式：
    $$r = \frac{\sqrt{2mE_{k}}}{qB}$$
    对同一磁场 $B$，粒子的轨道半径由 质量、电荷量、动能 共同决定。
  • 偏转方向判断
    使用左手定则：磁感线穿掌心，四指指向正电荷运动方向（或负电荷运动的反方向），拇指即洛伦兹力方向。电子与正电子带异号电荷，以相同方向射入磁场时偏转方向一定相反。

解题方法与套路

  1. 先定性判方向
    明确入射粒子的电性，正电荷四指同速度方向，负电荷四指反速度方向，用左手定则比划出洛伦兹力，确定偏转圆弧的弯曲方向。
  2. 再定量比半径
  3. 写半径通式 $r = \dfrac{mv}{qB}$ 或用动能形式 $r = \dfrac{\sqrt{2mE_{k}}}{qB}$。
  4. 若比不同粒子：固定 $B$，比较 $\dfrac{\sqrt{m}}{q}$ 或 $\dfrac{mv}{q}$。
  5. 若比同一粒子不同动能：动能 $E_k \uparrow$，则 $v \uparrow$，故 $r \uparrow$；动能越大半径越大，反之越小。
  6. 结合选项逐一验证
    重点关注“一定”“相同”“无法判断”等绝对化表述，需检查是否有未给定条件（如速度、动能是否相等）。

高频易错

  • 把正电子当负电子：正电子带正电，电子带负电，偏转方向必然相反，记错电性直接选错。
  • 忽略速度或动能条件：选项说“电子与正电子半径一定相同”，忘记半径还与速度有关，若无“速度相等”前提则无法确定半径相等，落入绝对化陷阱。
  • 混淆动能与半径的增减关系：由 $r = \dfrac{mv}{qB}$ 知 $r \propto v$，又 $E_{k} \propto v^{2}$，所以动能越大，$v$ 越大，半径越大，而非越小。
  • 仅凭轨迹判断粒子种类：当场中存在质子（$+e$）与正电子（$+e$）时，若未给出动能或速度关系，仅靠偏转半径无法区分二者，因为半径还取决于质量和动能。

代表题精讲

题目 （2014·新课标Ⅱ·07 改编）
磁谱仪永磁铁提供匀强磁场，硅微条探测器记录粒子轨迹。宇宙射线中的电子、正电子和质子从上部垂直进入磁场，问下列说法正确的是（多选）：
A. 电子与正电子的偏转方向一定不同
B. 电子与正电子在磁场中运动轨迹的半径一定相同
C. 仅依据粒子运动轨迹无法判断该粒子是质子还是正电子
D. 粒子的动能越大，它在磁场中的运动轨迹半径越小

思路
先根据电性用左手定则判断偏转方向，排除方向选项；再利用半径公式的动能表达式分析半径与各因素的关系，逐一核对剩余选项。

步骤
1. 分析A选项：电子带负电，正电子带正电，都以相同方向射入磁场时，洛伦兹力方向相反，偏转方向一定不同。A正确。
2. 分析B选项：半径 $r = \dfrac{\sqrt{2mE_{k}}}{qB}$，电子与正电子质量相等、电荷量大小相等，但未告知动能是否相等，速度可能不同，半径未必相同，“一定相同”错误。B错误。
3. 分析C选项：质子和正电子均带 $+e$，但质子质量远大于正电子质量，由 $r = \dfrac{\sqrt{2mE_{k}}}{qB}$，若仅凭轨迹半径，无法唯一确定粒子种类，因为可能通过不同动能组合得到相同半径，所以单凭轨迹无法可靠区分。C正确。
4. 分析D选项：动能 $E_{k} \uparrow \Rightarrow v \uparrow$，$r = \dfrac{mv}{qB} \uparrow$，半径变大而非变小，D错误。
综上，正确选项为A、C。

点评/变式
- 本题考查对带电粒子在匀强磁场中运动半径和偏转的灵活理解。关键是把动能关系代入半径公式，切忌死记“半径与速度成正比”却忘反向对应动能。
- 变式：若将质子换成α粒子，要求比较相同动能下α粒子与质子的半径比，可由 $r \propto \sqrt{m}/q$ 计算：α粒子 $m_\alpha=4m_p$，$q_\alpha=2e$，则半径比 $r_\alpha/r_p = (\sqrt{4}/2) / (\sqrt{1}/1) =1$，即相同动能时半径相等，适于设置“一定相同”陷阱。
