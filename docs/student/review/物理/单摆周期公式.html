单摆周期公式

考点单摆周期公式权重16真题数3学科物理父主题机械振动 与 机械波

考点定位

  • 父主题：机械振动 与 机械波
  • 权重 weight：16
  • 真题数：3；年份跨度：2019–2023
  • 出现题位：解答15 选择10
  • 难度分布：中2 易1

知识精要

  • 单摆模型：一根不可伸长、质量可忽略的细线，一端固定，另一端悬挂一个体积小、质量大（可视为质点）的摆球。摆角 $\theta < 5^\circ$ 时，其运动可近似为简谐运动。
  • 周期公式：单摆的周期 $T$ 与摆长 $l$ 和当地重力加速度 $g$ 的关系为 $$T = 2\pi \sqrt{\frac{l}{g}}$$ 由此可得重力加速度的测量公式： $$g = \frac{4\pi^2 l}{T^2}$$
  • 等效摆长：摆长 $l$ 指从悬挂点到摆球重心的距离。若悬挂点下方有钉子等障碍物，摆球运动到不同阶段对应的摆长会发生变化，周期需分段计算。复合摆的完整周期为各段半周期之和：$T = \frac{1}{2}(T_1 + T_2)$。
  • 小角度近似：当摆角很小时，摆球偏离平衡位置的位移 $x$ 与时间 $t$ 满足正弦或余弦关系，位移 $x$ 的大小近似等于摆球沿圆弧移动的弧长 $s = l\theta$。

解题方法与套路

  1. 明确摆长与等效摆长：严格区分悬线长度 $l_线$ 与摆长 $l$（$l = l_线 + \frac{d}{2}$）。遇到复合摆（有钉子），需分段确定摆长：碰钉前摆长为原摆长，碰钉后摆长变为从钉子到球心的距离。
  2. 处理周期与时间关系：利用 $T = \frac{t}{n}$ 计算周期，特别注意“第1次到第N次经过某点”对应的全振动次数。经过平衡位置每两次为一个全振动，次数 $n = \frac{N-1}{2}$。
  3. 比例法求新摆摆长：由 $T \propto \sqrt{l}$ 推导出 $l_2 = \left( \frac{T_2}{T_1} \right)^2 l_1$。注意将题设的“10个周期时间等于11个周期时间”等条件转化为周期之比。
  4. 图像问题分析：明确位移的参考点是平衡位置，且规定了正方向。碰钉前后，周期与振幅（最大位移）均会突变，据此结合振动方程 $x = A\sin(\omega t + \varphi)$ 或 $x = A\cos(\omega t + \varphi)$ 判断图线形状与对应时间。

  6. 螺旋测微器：先检查是否存在零误差（零点未对齐），若存在，需记为系统误差并在测量值中加以修正。最终直径 = 测量读数 - 零点读数。
  7. 刻度尺：读数需估读到分度值的下一位。
  8. 角度盘：注意悬挂点偏移对角度测量造成的误差，悬挂点偏高，指示角度大于实际角度。

高频易错

  • 忽略零点误差：螺旋测微器校零时，若可动刻度零线没过固定刻度横线，其读数（零点误差读数）可能是负值（注意“倒读”），计算直径时务必减去此值。
  • 摆长计算错误：摆长必须从悬挂点算至球心，忘加摆球半径是常见错误。若悬线长 $L$、球径 $d$，则摆长 $l = L + \frac{d}{2}$。
  • 周期计数失误：混淆“经过最低点的次数”与“全振动次数”。单摆从第一次过最低点开始计时，到第 $N$ 次过最低点，经历的周期数为 $\frac{N-1}{2}$。
  • 小角度近似滥用：在计算摆球被拉开的最大距离时，注意区分水平位移 $x$ 和圆弧弧长 $s$。小角度下 $x \approx s$，但物理意义不同。命题中常要求使用弧长近似弦长来求解。
  • 摆长突变时周期理解片面：碰到钉子后，新单摆周期仅取决于新摆长，且新运动只是原大周期运动的一部分。一个完整周期是由两个不同摆长的半周期的合周期构成的。误以为周期不变或全程按某一段摆长计算会导致错解。

代表题精讲

2023-新课标-10

题目：用单摆测重力加速度。涉及螺旋测微器读数（含零误差修正）、角度盘固定位置对摆角测量的影响、根据摆线长和摆球直径计算摆长、由多次经过最低点的时间求周期并算 $g$。 思路： 1. 读零点误差和球径测量值，作差求实际直径。 2. 分析角度盘悬挂点偏移后，指针转动半径与刻度弧的相对几何关系，判断示数误差。 3. 由摆线长和球半径求摆长，由经过最低点的次数算全振动次数，求出周期，代入 $g = \frac{4\pi^2 l}{T^2}$ 计算。 步骤： 1. 零误差修正：零点示数为正（或负），读取数值。测量物体时读数为另一示数。直径 $d =$ 测量值 $-$ 零点值。 2. 摆角判断：角度盘固定在 $O$ 点上方，摆线指针的旋转中心偏离角度盘圆心，相对同一摆角，指针在刻度盘上划过的角度变小，故示数 $5^\circ$ 小于实际摆角。 3. 数据处理：摆长 $l = 81.50\text{cm} + \frac{d}{2}\text{cm}$。第1次到第61次过最低点共60个半周期，即30个全振动周期。周期 $T = \frac{54.60\text{s}}{30}$。计算 $g = \frac{4\pi^2 l}{T^2}$。 点评/变式：本题高度仿真常规实验操作，暴露出考生在仪器调零、有效摆长计算、计数求周期等细节上的易错点。变式可考察游标卡尺测小球直径，或要求分析角度盘固定在 $O$ 点下方时的系统误差。

2020-新课标Ⅱ-15

题目：原摆摆长 $80.0\text{cm}$，求拉开不超过 $5^\circ$ 时的最大拉离距离；设计新摆，使其摆10个周期的时间等于原摆摆11个周期的时间，求新摆摆长。 思路： 1. 由小角度近似，拉离距离近似等于弧长 $s = l\theta$（$\theta$ 用弧度制）。 2. 由时间相等建立周期关系 $10T_2 = 11T_1$，得到 $\frac{T_2}{T_1} = \frac{11}{10}$。 3. 利用周期公式 $T \propto \sqrt{l}$，导出 $\frac{l_2}{l_1} = \left( \frac{T_2}{T_1} \right)^2$，代入已知数据求解新摆长。 步骤： 1. 计算最大距离：$5^\circ = 5 \times \frac{\pi}{180} \text{rad} \approx 0.0873 \text{rad}$。弧长 $s = l\theta = 80.0\text{cm} \times 0.0873 \approx 6.98\text{cm} \approx 6.9\text{cm}$。 2. 计算新摆摆长：由 $T_2/T_1 = 11/10$，得 $l_2 = l_1 \times \left( \frac{11}{10} \right)^2 = 80.0\text{cm} \times 1.21 = 96.8\text{cm}$。 点评/变式：此题不需实验数据，直接考查单摆公式的定性理解与定量计算。角度转弧度的近似计算是易错点。变式中可将时间关系改为“新摆摆动 $N$ 次的时间与原摆摆动 $M$ 次的时间相等”，或要求通过改变摆长来校准走时不准的摆钟。

2019-新课标Ⅱ-15

题目：绳长 $l$，正下方 $\frac{3}{4}l$ 处有铁钉。将小球拉至小角度释放，求一个完整周期内 $x-t$ 图像。 思路： 1. 分析运动分段：碰钉前摆长为 $l$，周期长；碰钉后摆长为 $\frac{1}{4}l$，周期短。 2. 确定位移参考点：平衡位置（最低点）为 $x=0$，向右为正。 3. 描述运动：从右侧最大位移处释放，$t=0$ 时 $x$ 正最大。先按长周期摆动，回到最低点碰钉，再按短周期向左摆动。 4. 推导图像特征：碰钉后周期变短，故图线在横轴上更密；碰钉前后振幅（最大位移）相同，均为原释放点位移，但碰钉后至左侧最大位移时，摆角会增大。 步骤： 1. 分段：碰钉前，$T_1 = 2\pi\sqrt{l/g}$；碰钉后，$T_2 = 2\pi\sqrt{l/(4g)} = T_1/2$。 2. 初态：$t=0$ 时，在右侧最大位移 $x = A$，振动方程为 $x = A\cos(\omega_1 t)$。 3. 碰钉时刻：经过 $\frac{T_1}{4}$，$x=0$，速度方向向左，在该点碰钉，摆长突变。 4. 碰钉后运动：此后，以 $\omega_2 = \frac{2\pi}{T_2} = 2\omega_1$ 向左振动，位移由0变为左侧负最大，由 $-A\sin(\omega_2 t')$ 描述。在 $x-t$ 图中，后段曲线频率是前段的两倍，形成一个完整周期内前疏后密的图线。 点评/变式：本题核心在于“摆长突变”导致的“周期突变”，要求根据各段的初位移与初速度衔接图像。正确选项的图像特点是第一段和第三段（碰钉前和碰钉后向右摆）曲线形态疏密不同，且位移始终关于平衡位置 $x=0$ 反对称或对称。变式可考察铁钉在不同位置时，对图像周期、对称性及完整周期时长的影响。
