压强

考点压强权重13真题数2学科物理父主题物理方法 与 通用

考点定位

  • 父主题：物理方法 与 通用
  • 权重 weight：13
  • 真题数：2；年份跨度：2009–2013
  • 出现题位：填空14 选择3
  • 难度分布：中2

知识精要

  • 压强定义与计算：压强 $p = \frac{F}{S}$，气体压强由大量分子无规则碰撞器壁产生。液体压强 $p = \rho g h$，同种液体静止时等深处压强相等。
  • 气体压强的确定方法：灵活选取“液片”或活塞为研究对象，根据力的平衡或牛顿第二定律列式。常见参考压强：开口端与大气相连处压强为 $p_0$；液柱两侧压强差 $\Delta p = \rho g \Delta h$（$\Delta h$ 为竖直高度差）。
  • 理想气体状态方程：$\frac{pV}{T} = C$（质量一定时）。常用三个实验定律：
  • 玻意耳定律（等温变化）：$p_1 V_1 = p_2 V_2$
  • 查理定律（等容变化）：$\frac{p_1}{T_1} = \frac{p_2}{T_2}$
  • 盖–吕萨克定律（等压变化）：$\frac{V_1}{T_1} = \frac{V_2}{T_2}$
  • 适用条件：气体质量不变，温度不太低、压强不太大（一般视为理想气体）。处理变质量问题时可利用克拉珀龙方程 $pV = nRT$ 或转换为质量不变的情形。
  • 关联量分析：多部分气体时，需找关联——总体积不变、压强差等于液柱或活塞重力产生的压强、容器为U形管或气缸时隔板移动引起的体积变化关联等。

解题方法与套路

  1. 选对象、分过程：明确要研究的部分气体，画出初、末状态示意图，标出已知量（$p、V、T$）。
  2. 分析压强关系：对液柱、活塞等受力分析，利用平衡（或牛顿第二定律）导出两部分气体间的压强关系。常见模型：水银柱平衡时 $p_{\text{下}} = p_{\text{上}} + \rho g h$；活塞无质量无摩擦时两侧压强相等。
  3. 挖掘体积关联：几何条件给出各段气柱长度变化与水银柱/活塞移动距离的关系。如玻璃管问题，气柱长度之和与玻璃管总长、水银柱长度之间的关系。
  4. 列气体方程：对每一部分质量不变的气体列出相应的实验定律或理想气体状态方程。优先判断过程特点（等温、等容、等压）以简化计算。
  5. 联立求解：将压强、体积、温度关系方程联立，统一单位（常用 cmHg 或 Pa），解出待求量，并判断解的合理性。
  6. 能量与热力学结合（如有）：若涉及绝热或热传递，需结合热力学第一定律 $\Delta U = W + Q$，分析内能、温度变化。

高频易错

  • 漏掉大气压强：在计算封闭气体压强时，忘记加上开口端的大气压强 $p_0$，或液柱平衡时将液柱产生的压强方向弄反。
  • 体积与长度混淆：气体体积 $V$ 正比于气柱长度 $l$（横截面积不变时），但直接代入方程时常忘记横截面积可约去，误将长度差当作体积差。
  • 液柱移动方向判断错误：认为活塞下推水银柱必然下降，未通过压强变化准确判断液柱的上下移动，导致体积关联式列错。
  • 研究对象不统一：对同一部分气体使用不同的质量或漏掉过程量；用状态方程时未保证质量不变就列比例式。
  • 多过程、多部分气体关联失误：各部分气体的初、末状态参量下标混乱；没有写出明确的几何关联（如总长度恒定条件），导致方程数不足。
  • 单位换算：cmHg 与 Pa 换算时出错（1 cmHg = $\frac{1}{76} \times 1.013 \times 10^5$ Pa），或与非国际单位制混用时忘记统一。

代表题精讲

【代表题1】2013·新课标Ⅱ·14

题目：如图，上端开口、下端封闭玻璃管竖直放置，下部空气柱 $l_1=25.0\,\text{cm}$，中间水银柱 $l_2=25.0\,\text{cm}$，上部空气柱 $l_3=40.0\,\text{cm}$。活塞从开口处缓慢下推，使下部空气柱长度变为 $l_1'=20.0\,\text{cm}$。无漏气，$p_0=75.0\,\text{cmHg}$。求：（1）最后下部分气体的压强；（2）活塞下推的距离。 思路：两段空气柱均经历等温变化（缓慢推动），使用玻意耳定律。分析水银柱平衡得出上下压强关系，再用体积（长度）的几何关联求出活塞位移。 步骤： 1. 初态压强：下部空气柱 $p_1 = p_0 + l_2 = 100\,\text{cmHg}$；上部空气柱 $p_3 = p_0 = 75\,\text{cmHg}$。 2. （1）下部空气柱等温变化：$p_1 l_1 = p_1' l_1'$，得 $p_1' = \frac{100 \times 25}{20} = 125\,\text{cmHg}$。 3. 水银柱平衡：$p_1' = p_3' + l_2$，解得 $p_3' = 125 - 25 = 100\,\text{cmHg}$。 4. 上部空气柱等温变化：$p_3 l_3 = p_3' l_3'$，得 $l_3' = \frac{75\times 40}{100} = 30\,\text{cm}$。 5. 几何关联：下部空气柱缩短 $\Delta l_1 = 5\,\text{cm}$，水银柱长度不变，故水银柱上升 $5\,\text{cm}$（上表面上升 $5\,\text{cm}$）。上部空气柱缩短 $10\,\text{cm}$，设活塞下推距离为 $d$，则 $d + 5\,\text{cm} = 10\,\text{cm}$，得 $d = 5\,\text{cm}$。 点评/变式：活塞类问题的关键是液柱和活塞的联动几何关系。变式：将活塞固定而缓慢加热某段气体，需结合查理定律与液柱平衡，同样需要找出体积变化与水银柱位移的关联。

【代表题2】2009·全国Ⅱ·03

题目：水平放置的密封气缸内，竖直绝热隔板分为左右两部分，右侧气体内有电热丝。气缸壁与隔板均绝热。初始时隔板静止，左右温度相等。给电热丝通电后切断，当缸内气体再次平衡时，与初始状态相比的判断。 思路：右侧气体吸热升温，压强增大→推动隔板左移→左侧气体被绝热压缩→左侧温度、压强均升高；右侧气体最终与左侧压强相等，同时体积增大。 步骤： 1. 初态：$T_{\text{左0}} = T_{\text{右0}}$，未说明压强和体积具体初值，隔板静止说明 $p_{\text{左0}} = p_{\text{右0}}$。 2. 过程分析：通电后右侧气体 $Q>0$，$T$ 升高到 $T'$，$p$ 增大；活塞左移，左侧绝热压缩，$W_{\text{左}}>0$，$\Delta U_{\text{左}}>0$，故 $T_{\text{左}}$ 升高，$p_{\text{左}}$ 增大。 3. 终态再平衡：隔板再次静止，$p_{\text{左}} = p_{\text{右}}$。右侧气体经历吸热和对外做功过程，其最终温度可能高于初态（通常仍比左侧高或相等？因两侧压强相等，且右侧最初主动升温）。由理想气体状态方程或热力学定律可推知：左侧因压缩温度必升高，右侧因吸热内能增加，即使对外做功，终态温度也高于初态。 4. 常见正确选项：左侧气体温度升高、压强增大；右侧气体温度也升高、压强增大；隔板移动使左侧体积减小，右侧体积增大。 点评/变式：本题考查热力学第一定律与气体状态变化的综合。绝热意味着 $Q=0$，但做功会改变内能。变式：若隔板导热，最终两侧温度相等，但压强关系仍由平衡决定，可结合克拉珀龙方程分析体积分配。
