双缝干涉条纹间距

考点双缝干涉条纹间距权重6真题数1学科物理父主题几何光学 与 物理光学

考点定位

  • 父主题：几何光学 与 物理光学
  • 权重 weight：6
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：解答15
  • 难度分布：中1

知识精要

  • 双缝干涉条纹间距公式：$\Delta x = \dfrac{L}{d}\lambda$
  • $L$：双缝到屏的距离；$d$：双缝间距；$\lambda$：光在真空（或空气）中的波长。
  • 对同一实验装置，$L$、$d$ 不变，$\Delta x \propto \lambda$，波长越长，条纹间距越大。
  • 光的颜色、频率、波长的对应关系
  • 不同色光频率 $\nu$ 不同，真空中波长为 $\lambda_0 = \dfrac{c}{\nu}$，频率越高，真空中波长越短。
  • 同一介质中光速 $v = \dfrac{c}{n}$，波长 $\lambda = \dfrac{v}{\nu} = \dfrac{\lambda_0}{n}$，介质中波长比真空中短。双缝干涉实验通常在空气中进行，可直接用真空中波长比较。
  • 折射率与光速、频率、波长的联系
  • 折射率 $n = \dfrac{c}{v}$，$n$ 越大，介质中光速越小。
  • 对于同种介质，频率越高的光折射率越大（正常色散）。因此 $n$ 大 $\rightarrow$ 频率高 $\rightarrow$ 真空波长小。
  • 全反射临界条件：$\sin C = \dfrac{1}{n}$，折射率越大的光临界角越小，越易发生全反射。

解题方法与套路

  1. 对比不同色光性质的通用步骤
    （1）由折射现象（偏向角大小）或折射率直接比较确定两光的 $n$ 大小。
    （2）由 $n=\dfrac{c}{v}$ 判断介质中光速 $v$ 大小。
    （3）根据“同种介质，$n$ 越大频率越高”确定频率 $\nu$ 高低，进而由 $\lambda_0 = c/\nu$ 比较真空中波长。
    （4）若题目涉及干涉条纹，直接调用 $\Delta x \propto \lambda_0$：波长较长的光，干涉条纹间距较大。
    （5）若涉及全反射，由 $\sin C = 1/n$ 得出折射率大的光临界角小，先消失。
  2. 双缝干涉选项的快速判定
  3. 只要比较出两光真空中波长大小，即可判断条纹间距相对大小，无需计算。
  4. 特别注意：有些题目给出的是“同一双缝干涉装置”，强调 $L$、$d$ 相同，结论唯一取决于波长。

高频易错

  • 混淆介质中波长与真空中波长：干涉条纹间距由光在实验环境（通常为空气或真空）中的波长决定，不是介质中的波长。从玻璃砖射出的光回到空气中后，波长恢复为真空波长，直接用真空波长比较。
  • 误认为折射率大的光干涉条纹间距大：折射率大 $\rightarrow$ 频率高 $\rightarrow$ 波长小 $\rightarrow$ 条纹间距小，记住“紫光折射率大但条纹密”。
  • 全反射与干涉结论混淆：同一束光，折射率大者更易全反射（先消失），但其干涉条纹间距更小，两结论方向相反，选择题常同时出现，需逐一严谨判断。
  • 忽略实验装置是否相同：$\Delta x$ 比较的前提是 $L$、$d$ 相同，若题目更换装置，则不能直接由波长得出结论。

代表题精讲

2015·新课标Ⅱ·15（多选）

题目：一束光沿半径方向射向半圆柱形玻璃砖，底面入射角为 $\theta$，折射后射出 $a$、$b$ 两束光线。下列判断正确的是（ ）。
A. 在玻璃中，$a$ 光的传播速度小于 $b$ 光
B. 在真空中，$a$ 光的波长小于 $b$ 光
C. 玻璃砖对 $a$ 光的折射率小于对 $b$ 光的折射率
D. 若增大 $\theta$ 角，折射光线 $a$ 首先消失
E. 分别用 $a$、$b$ 光做双缝干涉实验，$a$ 光干涉条纹间距大于 $b$ 光

思路：由光路图（入射角相同，介质到空气）看出 $a$ 光折射角更小，说明 $a$ 偏折更厉害 $\rightarrow$ $n_a > n_b$。进而推出介质中 $v_a < v_b$，频率 $\nu_a > \nu_b$，真空中波长 $\lambda_a < \lambda_b$，全反射临界角 $C_a < C_b$，双缝干涉条纹间距 $\Delta x_a < \Delta x_b$。

步骤：
1. 比较折射率：两光从玻璃射向空气，入射角相同，$a$ 光折射角较小，由折射定律 $n = \frac{\sin r}{\sin i}$（此处 $i$ 为折射角，$r$ 为入射角）知 $a$ 光折射角小则 $\sin r$ 小，故 $n_a > n_b$，C 错。
2. 比较介质中光速：$v = c/n$，$n$ 大则 $v$ 小，$v_a < v_b$，A 对。
3. 比较频率与波长：同种介质折射率越大光频越高，$\nu_a > \nu_b$；真空中 $\lambda = c/\nu$，所以 $\lambda_a < \lambda_b$，B 对。
4. 比较全反射：$\sin C = 1/n$，$n_a > n_b$ $\rightarrow$ $C_a < C_b$，增大入射角 $\theta$ 时，折射角先达到 $90^\circ$ 的是临界角小的 $a$ 光，故 $a$ 先全反射消失，D 对。
5. 比较双缝干涉条纹间距：同一装置，$\Delta x \propto \lambda$，$\lambda_a < \lambda_b$ $\rightarrow$ $\Delta x_a < \Delta x_b$，E 错。

点评/变式：
本题以折射为背景，综合考查了光速、波长、全反射和干涉条纹间距的关系，几乎覆盖几何光学与物理光学中光的色散全部结论链。解题核心是“因偏折判 $n$，再由 $n$ 推出频率、波长及一切后续结论”。变式训练中可将玻璃砖换成三棱镜，或把双缝干涉换为薄膜干涉，同样遵循 $n$ 大 $\rightarrow$ $\lambda_0$ 小 $\rightarrow$ 条纹间距小的规律。牢记“大折射率对应小波长、小速度、小临界角、高频率”，可一次性锁定多选项正误。
