变压器

考点变压器权重10真题数1学科物理父主题交流电 与 变压器

考点定位

  • 父主题：交流电 与 变压器
  • 权重 weight：10
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择11
  • 难度分布：难1

知识精要

  • 正弦交变电流的有效值与峰值：$U = \frac{U_m}{\sqrt{2}}$，$I = \frac{I_m}{\sqrt{2}}$（仅适用于正弦式交变电流）。计算功率、热量时必须用有效值。
  • 理想变压器的基本规律：
  • 电压与匝数关系：$\frac{U_1}{U_2} = \frac{n_1}{n_2}$（一个副线圈）；
  • 输入功率等于输出功率：$P_1 = P_2$，即 $U_1 I_1 = U_2 I_2$；
  • 副线圈可视为一个内阻为零的交流电源，其负载功率 $P_2 = \frac{U_2^2}{R}$（纯电阻）。
  • 理想气体实验定律——查理定律：一定质量的理想气体在体积不变时，压强与热力学温度成正比：$\frac{p_1}{T_1} = \frac{p_2}{T_2}$。
  • 热力学第一定律与电热：电热丝产生的热量 $Q = Pt$（纯电阻且不计其他能量损耗），若全部被气体吸收，则 $Q = C \Delta T$。

解题方法与套路

  1. 变压器输出功率计算的三步走：
  2. ① 由原线圈电压峰值 $U_m$ 求出有效值 $U_1 = \frac{U_m}{\sqrt{2}}$；
  3. ② 利用匝数比 $\frac{U_1}{U_2} = \frac{n_1}{n_2}$ 求出副线圈电压 $U_2$；

  4. ③ 在纯电阻回路中，$P = P_2 = \frac{U_2^2}{R}$。

  5. 变压器与热学综合的时间求解套路：

  6. ① 明确气体变化过程特征（如“绝热容器”“密封”常暗示等容过程），由初末状态关系结合气体定律（如查理定律）求出温度变化量 $\Delta T$；
  7. ② 由题给吸热关系 $Q = C\Delta T$ 得出所需总热量；

  8. ③ 利用能量守恒 $Q = Pt$（产生的热量全部吸收），代入已求出的输出功率 $P$，解出时间 $t$。

  9. 关键桥梁：能量守恒与功率定义——电热丝功率等于变压器输出功率，且 $Q = Pt$。

高频易错

  • 有效值与峰值混淆：直接用峰值 $U_m$ 代替有效值代入功率或电压比公式，导致结果错误。计算任何涉及能量/功率的交流电问题必须先用峰值除以 $\sqrt{2}$。
  • 忽略理想变压器的功率等量关系：误认为原线圈输入功率不等于副线圈输出功率，或试图直接从原线圈回路求功率而绕了弯路。记住 $P_1 = P_2$，一般先求出 $U_2$ 再算 $P_2$ 最直接。
  • 气体状态变化过程判断失误：容器“密封”且无活塞移动的暗示通常表示等容变化，需选用查理定律。若误用等压或等温变化公式会导致 $\Delta T$ 求错。
  • 比例系数误用：二极管、电容器等元件不改变电压有效值的理想变压关系，但本题无此陷阱。需注意能量传递效率是否为100%（本题为“全部被气体吸收”）。

代表题精讲

代表题：2024-辽宁-11

题目：理想变压器匝数比 $n_1 : n_2 = 5 : 1$，原线圈接电压峰值为 $U_m$ 的正弦交流电源，副线圈接阻值为 $R$ 的电热丝，电热丝密封于绝热容器中加热理想气体。加热前气体温度为 $T_0$。已知气体吸收的热量 $Q = C\Delta T$，电热丝产生的热量全部被气体吸收。求：（1）变压器输出功率 $P$；（2）使容器内气体压强变为加热前2倍所需的通电时间 $t$。

思路：本题分两部分。第一部分为纯变压器计算，按“原线圈有效值→副线圈电压→输出功率”递推；第二部分需通过查理定律找到末态温度，从而得到 $\Delta T$，再利用吸热公式和能量守恒求出时间。

步骤： （1）变压器原线圈输入电压有效值： $$U_1 = \frac{U_m}{\sqrt{2}}$$ 由理想变压器电压比： $$\frac{U_1}{U_2} = \frac{n_1}{n_2} \Rightarrow U_2 = \frac{n_2}{n_1} U_1 = \frac{1}{5} \cdot \frac{U_m}{\sqrt{2}} = \frac{U_m}{5\sqrt{2}}$$ 输出功率 $P$ 等于负载电阻 $R$ 上的功率： $$P = \frac{U_2^2}{R} = \frac{\left(\frac{U_m}{5\sqrt{2}}\right)^2}{R} = \frac{U_m^2}{50R}$$

（2）气体做等容变化，由查理定律： $$\frac{p_0}{T_0} = \frac{2p_0}{T_2} \Rightarrow T_2 = 2T_0$$ 温度变化量： $$\Delta T = T_2 - T_0 = T_0$$ 气体吸收的热量： $$Q = C\Delta T = C T_0$$ 电热丝在时间 $t$ 内产生的热量： $$Q = Pt = \frac{U_m^2}{50R} t$$ 由能量守恒： $$\frac{U_m^2}{50R} t = C T_0 \Rightarrow t = \frac{50 C T_0 R}{U_m^2}$$

点评/变式： - 本题是典型的“电—热”综合题，关键在于区分交流电的峰值与有效值，且需准确识别气体的等容变化条件。 - 若将加热对象改为有摩擦活塞的容器（等压变化），则需改用盖-吕萨克定律，但本题压强变为2倍，体积不变，适合用查理定律。 - 变式中电热丝热量若只有部分被吸收（效率 $\eta$），则 $Q = \eta Pt$，相应调整即可。 - 当原线圈含内阻或副线圈有二极管时，不能直接套用匝数比，需注意只有理想变压器才能使用上述公式。
