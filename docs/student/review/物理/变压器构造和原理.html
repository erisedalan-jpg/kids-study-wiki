变压器构造和原理

考点变压器构造和原理权重12真题数2学科物理父主题交流电 与 变压器

考点定位

  • 父主题：交流电 与 变压器
  • 权重 weight：12
  • 真题数：2；年份跨度：2011–2014
  • 出现题位：选择4 选择8
  • 难度分布：中1 易1

知识精要

  • 理想变压器模型：无能量损耗，原副线圈功率相等 $P_1 = P_2$。
  • 电压关系：$\frac{U_1}{U_2} = \frac{n_1}{n_2}$（适用于一个原线圈对应一个副线圈，且电压指交流有效值或最大值，瞬时值也满足匝数比）。
  • 电流关系：仅有一个副线圈时，$\frac{I_1}{I_2} = \frac{n_2}{n_1}$；多个副线圈时，由 $U_1I_1 = U_2I_2 + U_3I_3 + \cdots$ 和各组匝数比求解。
  • 制约关系：副线圈电压 $U_2$ 由原线圈电压 $U_1$ 和匝数比决定，与负载无关；原线圈电流 $I_1$ 由副线圈电流 $I_2$（即副线圈输出功率）决定；输入功率由输出功率决定。
  • 二极管的影响：半波整流使负载上只有半个周期有电流，电压波形非正弦。负载电阻 $R$ 上电压的有效值 $U_{cd}$ 不是副线圈两端正弦电压的有效值 $U_2$，而是满足 $U_{cd} = \frac{U_2}{\sqrt{2}}$（当二极管串联且正向电阻为零时）。计算功率要用有效值：$P = \frac{U_{cd}^2}{R}$。
  • 交流电表的读数：所有交流电压表、电流表的示数均为有效值。

解题方法与套路

  1. 确定原副线圈电压：先由已知电源或原线圈电压及匝数比，算出副线圈两端正弦交流电压的有效值 $U_2$（不考虑二极管、负载变化，$U_2$ 由匝数比唯一确定）。
  2. 分析非线性元件（如二极管）的影响：若存在二极管，需明确负载一个周期内实际通电时间。对于理想二极管半波整流，负载电压的有效值 $U_{cd} = \frac{U_2}{\sqrt{2}}$，功率 $P_{cd} = \frac{U_2^2}{2R}$。注意 $U_2$ 本身由匝数比决定，不随负载改变。
  3. 分析负载变化引起的功率、电流变化：利用 $P_2 = \frac{U_{cd}^2}{R}$（或全波时 $P_2 = \frac{U_2^2}{R}$）判断功率随 $R$ 的变化，再由 $P_1 = P_2$ 确定原线圈功率，由 $P_1 = U_1 I_1$ 求原线圈电流表读数 $I_1$。
  4. 处理“短路二极管”“去掉二极管”类变化：对比有无二极管时副线圈输出功率的变化。二极管短路后变为全波整流，功率加倍（若负载电阻不变），从而原线圈输入功率、电流均加倍。
  5. 紧扣能量守恒：当副线圈有多个回路或非纯电阻时，始终以 $P_1 = P_2$ 和 $U_1I_1 = P_2$ 为核心列方程。

高频易错

  • 混淆 $U_2$ 与二极管后负载电压 $U_{cd}$：误认为 $U_{ab}:U_{cd} = n_1:n_2$ 总是成立。实际上，若副线圈接二极管半波整流，$U_{cd}$ 不再是变压器副线圈两端电压 $U_2$，此时电压比关系对 $U_{cd}$ 不直接成立，正确的是 $U_{ab}:U_2 = n_1:n_2$。
  • 误用有效值关系：变压器电压比适用于原副线圈两端正弦交流电的有效值，含二极管的负载电压 $U_{cd}$ 已经是非正弦量，不能直接用匝数比计算 $U_{cd}$，必须先求 $U_2$ 再计算整流后的有效值。
  • 误以为负载变化影响副线圈电压：理想变压器中，副线圈电压 $U_2$ 只取决于 $U_1$ 和匝数比，与 $R$ 大小无关。负载电阻 $R$ 变化时，$U_2$ 不变，$U_{cd}$ 也不变（只要二极管状态不变），变化的是功率和电流。
  • 二极管反向电阻无穷大时的功率计算错误：直接使用 $\frac{U_2^2}{R}$ 而非 $\frac{U_2^2}{2R}$，错在忘记只工作半个周期。有效值计算必须考虑热量等效：$\frac{U_2^2}{R}\cdot\frac{T}{2} = \frac{U_{cd}^2}{R}T$。
  • 电流表示数判断失误：增大 $R$ 时，输出功率减小，因为输入功率等于输出功率，所以原线圈电流表的读数应减小，不能想当然认为 $R$ 增大电流也增大。

代表题精讲

题1：2014新课标Ⅱ-08

题目：理想变压器原副线圈匝数 $n_1$、$n_2$，原线圈接正弦交流电源和理想电流表，副线圈串联理想二极管和负载电阻 $R$，交流电压表测 $a,b$ 端（原线圈端）和 $c,d$ 端（负载两端），得 $U_{ab}$、$U_{cd}$。判断各选项正误。

思路：先明确 $U_{ab}$ 为原线圈电压有效值，副线圈电压有效值 $U_2 = \frac{n_2}{n_1}U_{ab}$。二极管的作用使得 $R$ 上电压为半波正弦，其有效值 $U_{cd} = \frac{U_2}{\sqrt{2}}$。负载功率 $P_{cd} = \frac{U_{cd}^2}{R}$，由能量关系求电流表读数变化。对比短路二极管前后功率加倍。

步骤： - A项：因 $U_{cd} = \frac{U_2}{\sqrt{2}} = \frac{n_2 U_{ab}}{\sqrt{2}n_1}$，故 $U_{ab}:U_{cd} = \sqrt{2}n_1:n_2 \neq n_1:n_2$，A错。 - B项：$R$ 增大 → $P_{cd} = \frac{U_{cd}^2}{R}$ 减小，输入功率减小，原线圈电压 $U_{ab}$ 由电源决定不变，则电流表读数 $I_1 = \frac{P_1}{U_{ab}}$ 减小，B对。 - C项：$U_{cd}$ 由匝数比和原线圈电压决定，与 $R$ 无关，C错。 - D项：二极管短路后，变为全波整流，$R$ 上电压有效值变为 $U_2$，功率变为 $\frac{U_2^2}{R}$，是短路前功率 $\frac{U_2^2}{2R}$ 的两倍，所以输入功率和原线圈电流均加倍，D对。 答案：BD

点评/变式：本题核心在于二极管的半波整流效应，一定要分两步走：先算的副线圈电压有效值 $U_2$，再根据有效值定义得出负载电压 $U_{cd}$。切忌直接用 $U_{ab}:U_{cd}=n_1:n_2$。若二极管与电阻并联，或变为电感、电容，分析方法类似，均需从波形和有效值定义出发。

题2：2011新课标-04

题目：理想变压器，原副线圈匝数比1:2，副线圈接额定电压220V、额定功率22W的灯泡，灯泡正常发光。求此时原线圈上电压表和电流表的读数 $U$、$I$。

思路：灯泡正常发光，意味着副线圈电压恰为220V。根据匝数比，原线圈电压 $U = \frac{n_1}{n_2} \times 220V$。再由理想变压器功率相等，灯泡功率22W即变压器输出功率，原线圈输入功率也为22W，根据 $P = UI$ 求原线圈电流。

步骤： - 由 $\frac{U_1}{U_2}=\frac{n_1}{n_2}$，得原线圈电压 $U = \frac{1}{2} \times 220V = 110V$。 - 副线圈输出功率 $P_2 = 22W$，因理想变压器 $P_1 = P_2$，原线圈功率也为22W。 - 原线圈电流 $I = \frac{P_1}{U} = \frac{22}{110}A = 0.2A$。 答案：A

点评/变式：此题是变压器的直给型基础题，考查电压比和功率相等。易错在电流比直接套用 $\frac{I_1}{I_2}=\frac{n_2}{n_1}$ 而不注意只有一个副线圈可以，尽管如此仍需确认。灯泡额定值直接给出副线圈电压，简化了分析。变式可能改为灯泡未正常发光，或负载为非线性元件，此时需结合欧姆定律或功率式计算实际电压电流。
