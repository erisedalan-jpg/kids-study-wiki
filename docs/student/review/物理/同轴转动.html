同轴转动

考点同轴转动权重6真题数1学科物理父主题曲线运动 与 抛体

考点定位

  • 父主题：曲线运动 与 抛体
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 同轴转动：绕同一固定转轴转动的物体（如门、车轮、传送带同轴轮、指尖篮球等），其上各点角速度 $\omega$ 恒相等，且周期 $T$、转速 $n$ 均相同。
  • 线速度：$v = \omega r$，在 $\omega$ 相同时，$v \propto r$（半径越大线速度越大）。
  • 向心加速度：$a = \omega^2 r = \frac{v^2}{r}$，在 $\omega$ 相同时，$a \propto r$；若结合 $v$ 讨论，一般用 $a=\omega^2 r$ 更为直接。
  • 适用条件：物体绕同一轴转动且各点无相对滑动（刚体转动或稳定同轴转动情景）。

解题方法与套路

  1. 快速识别“同轴”情景：题干出现“绕轴转动”“同一个转轴”“同一个轮子/盘/球”等关键词，优先锁定同轴转动关系。
  2. 确立角速度相等：同轴转动各点 $\omega$ 相同，是后续计算的唯一桥梁。
  3. 分析半径关系：从题目示意或描述中找出比较点的转动半径大小关系。
  4. 利用公式逐项判断：
  5. 比较线速度：用 $v = \omega r$，$\omega$ 不变时按半径大小比较。
  6. 比较向心加速度：用 $a = \omega^2 r$，同样按半径大小比较。
  7. 若涉及周期/频率：由 $T = \frac{2\pi}{\omega}$ 直接判断所有点相等。
  8. 区分传动模型：若为皮带、链条、齿轮啮合（边缘线速度大小相等），不可误用同轴角速度相等。

高频易错

  • 误将同轴当作线速度相等：同轴转动是 $\omega$ 相等，不是 $v$ 相等。半径不同时 $v$ 一定不同。
  • 半径判断失误：转动中心到该点的距离才是圆周运动半径，不能想当然视为“到球心”或“到某点”的直线距离，应以转轴为基准。
  • 向心加速度随便代公式：同轴比较首选 $a = \omega^2 r$，避免用 $a = \frac{v^2}{r}$ 因 $v$ 与 $r$ 都在变而犯错。
  • 混淆同轴与同带传动：同轴是 $\omega$ 同，同带是 $v$ 同（边缘点），涉及轮盘组合时务必分开判断。

代表题精讲

代表题 2024-辽宁-02

题目：篮球在指尖上绕轴转动，球面上 P、Q 两点做圆周运动，比较半径、线速度大小、向心加速度大小、角速度大小。

思路：篮球绕通过指尖的竖直轴转动，P、Q 为球面上不同点，转动轴相同 → 同轴转动 → 角速度 $\omega$ 相等。再根据各自到转轴的距离（圆周半径）比较线速度和向心加速度。

步骤： 1. 确定模型：篮球整体绕同一竖直轴转动，P、Q 两点随球一起转动，属同轴转动，因此 $\omega_P = \omega_Q$。选项 D 正确。 2. 判断半径：由图可知 P 点离转轴较近，Q 点离转轴较远，故 $r_P < r_Q$。选项 A 错误。 3. 比较线速度：由 $v = \omega r$，$\omega$ 相等时 $v \propto r$，则 $v_P < v_Q$。选项 B 错误。 4. 比较向心加速度：由 $a = \omega^2 r$，$\omega$ 相等时 $a \propto r$，则 $a_P < a_Q$。选项 C 错误。

点评/变式：本题核心是“同轴转动角速度相等”这一结论的直接应用。常见变式：将篮球换为绕竖直轴转动的圆盘、雨伞边缘水滴、旋转的餐桌等，均属同一模型。若将题改为比较周期、频率或转速，正确答案依然是所有点均相等。务必与“皮带传动边缘线速度相等”进行对比记忆。
