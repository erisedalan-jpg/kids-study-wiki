知识精要

  • 圆周运动的描述
    线速度 $v = \frac{\Delta s}{\Delta t}$，角速度 $\omega = \frac{\Delta \theta}{\Delta t}$，周期 $T = \frac{2\pi r}{v} = \frac{2\pi}{\omega}$，频率 $f = \frac{1}{T}$。
    向心加速度 $a_n = \frac{v^2}{r} = \omega^2 r = \frac{4\pi^2}{T^2}r$，方向始终指向圆心。

  • 向心力
    效果力，来源为物体所受合力在指向圆心方向的分量。匀速圆周运动合力全部提供向心力：
    $$F_n = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2}r。$$
    变速圆周运动中，径向合力 $F_n$ 仍满足上述关系（此时 $v$ 为瞬时速率），切向合力改变速度大小。

  • 万有引力与天体运动
    万有引力定律 $F = G\frac{Mm}{r^2}$ 。
    天体圆轨道运动：$G\frac{Mm}{r^2} = m\frac{v^2}{r} = m\omega^2 r = m\frac{4\pi^2}{T^2}r$。
    开普勒第三定律：$\frac{a^3}{T^2} = \frac{GM}{4\pi^2}$（$a$为半长轴，$M$为中心天体质量）。
    近地轨道上物体处于完全失重状态，所受引力全部提供向心力，并非不受引力。

  • 带电粒子在匀强磁场中的圆周运动
    洛伦兹力提供向心力：$qvB = m\frac{v^2}{r}$，得 $r = \frac{mv}{qB}$，周期 $T = \frac{2\pi m}{qB}$（与速度无关）。
    确定圆心方法：两速度垂线交点，或入射点、出射点连线的中垂线与速度垂线的交点。

  • 典型圆周运动模型

  • 水平面内转弯：静摩擦力或路面支持力与重力的合力提供向心力。车速 $v = \sqrt{gr\tan\theta}$（无侧滑趋势临界速度）。
  • 竖直面内光滑圆环/轨道：机械能守恒，最高点临界速度 $v_{\min} = \sqrt{gr}$（轻杆/管内可为零），最低点受力最大。
  • 光滑大圆环上小环下滑：除重力外弹力不做功，速率满足 $v = \sqrt{2gh}$。

解题方法与套路

  1. 明确研究对象与运动平面：确定圆周运动的轨道面、圆心和半径。对于天体问题，明确轨道半径与天体半径的区别；对于磁场问题，画出轨迹并利用几何关系求半径。
  2. 受力分析与向心力来源：分析物体所受的实际力（重力、弹力、摩擦力、万有引力、洛伦兹力等），找出指向圆心方向的合力，令其等于 $m\frac{v^2}{r}$ 或相应的向心力表达式。
  3. 运动学量与动力学方程结合：遇周期、转速等需求，灵活选用 $v$、$\omega$、$T$ 之间的关系与向心力公式联立。
  4. 能量与圆周结合：变速率圆周运动（如竖直面内无支撑下滑），优先使用机械能守恒或动能定理求出速率，再代入向心力方程求解某处弹力或压力。
  5. 临界条件判断：
  6. 恰好通过最高点：轻绳/轨道，$v_{\min}=\sqrt{gr}$；杆/管，$v_{\min}=0$。
  7. 恰好无滑动趋势：转弯时重力与支持力的合力恰提供向心力，$v_c = \sqrt{gr\tan\theta}$。
  8. 恰好飞离或相对滑动：实际所需向心力超过可能的最大静摩擦力或约束力时发生。
  9. 开普勒定律处理天体椭圆运动：给出半长轴和周期，用 $\frac{a^3}{T^2} = \frac{GM}{4\pi^2}$ 对比已知系统（如地球绕太阳）求中心天体质量比。
  10. 带电粒子圆周磁场问题：先画轨迹，定圆心、求半径、画角度，用 $qvB = m\frac{v^2}{r}$ 和几何关系求解 $B$、偏移量或时间。时间可用 $t = \frac{\theta}{2\pi}T$。

高频易错

  • 误将“完全失重”当“不受引力”：航天员漂浮是因为引力全部用于提供向心力，飞船对人的支持力为零，引力依然存在且等于 $G\frac{Mm}{r^2}$。
  • 向心力参与受力分析：向心力是效果力，列方程时不能写成“$G + F_n = \cdots$”，应在等号左边写实际力，右边写 $m\frac{v^2}{r}$。
  • 轨道半径与星球半径混淆：近地卫星轨道半径 $r \approx R_{地}$，但高空卫星 $r = R_{地} + h$。计算引力或向心力时务必用轨道半径。
  • 转弯时误认为车速低于临界速度就会立刻向内滑：只要横向摩擦力未达最大静摩擦，车辆仍能维持原有半径，只有所需向心力小于沿斜面向下的合力分力时，才有向内滑的趋势，且通常由静摩擦平衡，不一定滑动。
  • 竖直面圆周运动最高点速度随意认为是零：绳模型和光滑环的最高点必须有最小速度 $\sqrt{gr}$，否则物体会提前脱离轨道。
  • 开普勒第三定律使用不准确：$\frac{a^3}{T^2} = k$，系数 $k$ 只与中心天体质量有关；绕不同中心天体的系统不能直接等比，需通过牛顿定律推导质量比。
  • 磁场圆周运动半径错误使用直径：几何关系找半径时，经常混淆弦长、半径与偏转角，正确定圆心是根本。

代表题精讲

题目（2022·全国乙卷·1）：天宫二号绕地飞行，航天员自由漂浮，分析所受引力与向心力关系。

思路：航天员随空间站做匀速圆周运动，合力提供向心力。无其他作用力时，引力全部充当向心力，飞船对人作用力为零，人处于完全失重。
步骤
1. 航天员与飞船一起绕地球做圆周运动，受到地球引力 $F_{引} = G\frac{Mm}{r^2}$。
2. 设飞船对人的作用力为 $N$，由向心力方程：$F_{引} + N = m\frac{v^2}{r}$（指向地心为正）。
3. 因引力恰好提供全体所需向心力，$F_{引} = m\frac{v^2}{r}$，故 $N = 0$，人只受引力。
4. 地面所受引力 $F_{表} = G\frac{Mm}{R^2}$，因 $r > R$，$F_{表} > F_{引} = m\frac{v^2}{r}$。因此只有C正确。
点评/变式：完全失重决非无引力，而是引力全部用于产生加速度。变式：若飞船在椭圆轨道远地点，加速度与向心加速度关系如何？

题目（2022·全国乙卷·3）：固定光滑大圆环上小环从顶端P由静止自由下滑，求速率正比于何量。

思路：光滑约束，弹力始终垂直运动方向不做功，只有重力做功，机械能守恒。速率与下降高度的平方根成正比。
步骤
1. 设大圆环半径为 $R$，小环从P点下滑，下降竖直高度为 $h$。
2. 由机械能守恒：$mgh = \frac{1}{2}mv^2$，得 $v = \sqrt{2gh}$。
3. 所以 $v \propto \sqrt{h}$，即正比于下降高度的平方根（若选项有“$\sqrt{h}$”或其表述，即为答案）。
点评/变式：常见误选“正比于下滑弧长”或“正比于高度”，注意几何与能量关系。变式：求小环对大圆环的压力变化，需结合径向动力学方程 $mg\cos\theta - N = m\frac{v^2}{R}$。

题目（2021·全国乙卷·5）：根据恒星S2的椭圆轨道半长轴（约1000 AU）及多年观测位置，推测银河系中心黑洞质量。

思路：利用开普勒第三定律，对比地球绕太阳的规律，得出黑洞质量与太阳质量之比。
步骤
1. 设黑洞质量为 $M_{BH}$，S2的轨道半长轴 $a = 1000\,\text{AU}$，周期 $T$ 可由图中1994—2002年位置变化估算（一般约16年，但此处可设 $T$）。
2. 对S2：$\frac{a^3}{T^2} = \frac{GM_{BH}}{4\pi^2}$；对地球：$\frac{(1\,\text{AU})^3}{(1\,\text{年})^2} = \frac{GM_{\odot}}{4\pi^2}$。
3. 两式相比得 $\frac{M_{BH}}{M_{\odot}} = \left(\frac{a}{1\,\text{AU}}\right)^3 \left(\frac{1\,\text{年}}{T}\right)^2$，代入数值和观测周期即可得数量级约为 $4\times10^6 M_{\odot}$。
点评/变式：此类问题核心是将未知系统与已知系统（地-日）作比，消去常数。若题目未直接给出周期，需通过观测图中的位矢角度变化推算。变式：已知卫星绕月周期、轨道半径和月球半径，求月球质量——同样用开普勒定律或万有引力提供向心力。
