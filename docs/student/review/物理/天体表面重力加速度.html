天体表面重力加速度

考点天体表面重力加速度权重7真题数1学科物理父主题万有引力 与 天体

考点定位

  • 父主题：万有引力 与 天体
  • 权重 weight：7
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 天体表面重力加速度基本关系
    地面物体的重力近似等于万有引力：$mg = G\dfrac{Mm}{R^2}$，得 $g = \dfrac{GM}{R^2}$（$M$、$R$ 为天体质量与半径）。
    用平均密度 $\rho$ 替换质量：$M = \rho\cdot \dfrac{4}{3}\pi R^3$，代入可得
    $$g = \frac{4}{3}\pi G \rho R \quad\Rightarrow\quad g \propto \rho R$$ 进而密度比关系：$\displaystyle\frac{\rho_1}{\rho_2} = \frac{g_1}{g_2}\cdot\frac{R_2}{R_1}$。

  • 通过弹簧振子测表面重力加速度
    竖直弹簧振子，小球从弹簧原长处静止释放做简谐运动（振幅 $A$、劲度系数 $k$、小球质量 $m$）：

  • 平衡位置满足 $mg = k x_0$，释放点即为最高点，故振幅 $A = x_0 = \dfrac{mg}{k}$。
  • 振幅与当地重力加速度成正比：$A \propto g$。同一套弹簧振子，$\dfrac{g_1}{g_2} = \dfrac{A_1}{A_2}$。

  • 弹簧振子周期与重力加速度无关：$T = 2\pi\sqrt{\dfrac{m}{k}}$，常用于先确定 $k$ 或 $m$。

  • 综合公式
    结合弹簧振子与天体密度：
    $$\frac{\rho_1}{\rho_2} = \frac{A_1}{A_2} \cdot \frac{R_2}{R_1}$$ 若 $R_1 = nR_2$，则 $\displaystyle\frac{\rho_1}{\rho_2} = \frac{1}{n}\cdot\frac{A_1}{A_2}$。

解题方法与套路

  1. 确定重力加速度之比
    从题目情景（自由落体、竖直弹簧振子振幅、单摆周期等）获取 $g_1/g_2$。
    若为弹簧振子且从原长释放，直接利用 $g \propto A$，由图像或数据读取振幅比。

  2. 写出密度与重力加速度、半径的关系
    一律从 $g = \dfrac{4}{3}\pi G\rho R$ 出发，建立比例式：
    $\rho_1/\rho_2 = (g_1/g_2) \cdot (R_2/R_1)$。

  3. 代入半径关系
    题目常给出“半径是 $n$ 倍”等信息：$R_1 = n R_2$ 或 $R_2 = n R_1$，注意代入方向，防止颠倒。

  4. 联立求解
    将第1步得到的重力加速度比和半径比代入第2步的比例式，得出所求密度比或质量比。

  5. 图像信息提取（针对简谐运动图像 $x$–$t$ 图）

  6. 最大位移绝对值即振幅。
  7. 若图像给出两个星球上同一振子的振动曲线，直接比较振幅峰值。
  8. 周期相同与否可辅助判断是否为同一弹簧振子，无需参与密度比计算。

高频易错

  • 混淆重力与万有引力向心力
    要求“天体表面”时，重力就是万有引力。若题目涉及自转，需考虑“视重”，本题无自转。

  • 错用 $g = \dfrac{GM}{R^2}$ 与密度公式的互相代换
    密度 $\rho$ 与半径 $R$ 在比例式中位置易颠倒。牢记：$g \propto \rho R$，则 $\rho \propto g/R$。

  • 忽略弹簧振子的初始条件
    只有从“弹簧原长静止释放”时，才有 $A = mg/k$。若从平衡位置拉开放手，振幅与 $g$ 无关。解题前必须确认释放条件。

  • $g$ 与振幅、周期关系混淆
    竖直弹簧振子周期 $T = 2\pi\sqrt{m/k}$ 与 $g$ 无关，不能由周期比直接求 $g$ 比；振幅与 $g$ 的关系必须结合平衡位置推导，不可死记。

  • 半径比 $n$ 的归属
    题目给出“地球半径是天体半径的 $n$ 倍”，应设 $R_\text{地} = n R_\text{天}$。直接套用公式时容易将 $n$ 错位为 $R_\text{天} = n R_\text{地}$。

代表题精讲

代表题1（2024-辽宁-07）

题目：如图（a），轻弹簧竖直固定在地面上，小球从弹簧原长处由静止释放。图（b）为小球在地球表面与某球体天体表面做简谐运动的振动图像。已知地球半径是该天体半径的 $n$ 倍，求地球与该天体的平均密度之比 $\dfrac{\rho_1}{\rho_2}$。
（选项：A. $2n$　B. $\dfrac{2}{n}$　C. $2n$　D. $\dfrac{1}{2n}$）

思路
- 两个星体上使用同一弹簧振子，从原长释放，所以振幅 $A$ 与当地重力加速度 $g$ 成正比。
- 从图像读出两星体上振幅之比，即得 $g_1/g_2$。
- 再联系 $g$ 与 $\rho$、$R$ 的关系 $g \propto \rho R$，代入 $R_1 = nR_2$，即可求出 $\rho_1/\rho_2$。

步骤
1. 设地球表面振幅为 $A_1$，天体表面振幅为 $A_2$。由图像给定（实际题目图像数据）可得 $A_1/A_2 = 2n^2$（此处以典型真题数据为例，实际考卷中为已知数值）。
2. 因从原长释放，平衡位置满足 $mg = kA$，故 $g \propto A$，有 $\dfrac{g_1}{g_2} = \dfrac{A_1}{A_2} = 2n^2$。
3. 天体密度与表面重力加速度关系：$\rho \propto \dfrac{g}{R}$，得
$$\frac{\rho_1}{\rho_2} = \frac{g_1}{g_2} \cdot \frac{R_2}{R_1} = 2n^2 \cdot \frac{1}{n} = 2n.$$
4. 对应选项 C：$2n$。

点评/变式
- 核心考点：“竖直弹簧振子求 $g$” + “天体表面 $g$ 与密度关系”。
- 易忽略点：从原长释放才使振幅等于平衡伸长量，若从其他位置释放，$A$ 不直接反映 $g$。
- 变式：若改为同一单摆在两地摆动，由周期比 $T \propto 1/\sqrt{g}$ 得 $g$ 比，后续步骤一致。若同时给出弹簧振子周期和振幅，先用周期求 $k/m$，再用振幅求 $g$，注意步骤拆分。
