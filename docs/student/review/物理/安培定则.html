安培定则

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：10
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 安培定则（右手螺旋定则）
  • 直线电流：右手握住导线，拇指指向电流方向，弯曲四指所指方向为磁感线环绕方向。
  • 环形电流（含螺线管）：右手弯曲四指与电流方向一致，拇指所指一端为内部磁场 $N$ 极（即内部磁感线方向）。
  • 适用于恒定电流，常用于判断电流与磁场间的方向关系。
  • 地磁场基本特点
  • 地磁 $S$ 极在地理北极附近，地磁 $N$ 极在地理南极附近。
  • 地球外部磁感线从地磁 $N$ 极（地理南极）指向地磁 $S$ 极（地理北极），内部由 $S$ 指向 $N$（即从地理北极指向地理南极）。
  • 安培分子电流假说
  • 物质内部存在绕原子核运动的环形电流，此微观电流是磁现象的本质根源。
  • 地球磁性也可等效为内部有绕地轴的宏观环形电流，由运动电荷产生磁场。

解题方法与套路

利用安培定则处理环形电流与磁场方向关系题目的通用步骤：
1. 确定目标磁场方向：根据题意或已知情境（如地磁场分布、同名磁极排斥、异名相吸等）明确环形电流产生的内部磁场方向。
2. 选用定则版本：螺线管或环形电流用弯曲四指表电流、拇指表内部磁场方向。
3. 手掌定向：将右手指向匹配目标磁场方向：
- 若已知磁场求电流，则拇指指向内部磁场方向，四指自然弯曲所示方向即电流环绕方向。
- 若已知电流求磁场，四指跟随电流方向，拇指指出 $N$ 极或内部磁场方向。
4. 结合视角判断：注意题目给的图是平面俯视、正视还是侧视，将四指弯曲方向与实际图示对应，判断电流是顺时针/逆时针或东/西/南/北走向。

高频易错

  • 地理南北极与地磁南北极混淆：地磁 $S$ 极在地理北极附近，导致地球内部磁场方向常被弄反。切记磁场内部由 $S$ 指向 $N$，即从地理北极附近指向地理南极附近。
  • 拇指与四指对应功能混淆：环形电流中，拇指永远指内部磁场（$N$ 极），四指永远指电流绕行方向，不可颠倒。
  • 电流方向与电子运动方向：题目若给的是电子束或离子流，须先转换为常规电流方向再应用安培定则。
  • 只记忆“外部磁感线从北到南”：在环形电流内部或螺线管内部，磁感线与外部相反，必须按内部磁场方向应用定则。
  • 空间方向误判：在立体图上，易将“向西”的电流方向观察成“向东”或顺/逆时针含混不清，需掌握右手投影与方位对应。

代表题精讲

代表题 1：2011 新课标 · 01

题目
要求选出能正确表示安培假设下地球内部环形电流方向的示意图。安培认为地球磁场由绕地轴的环形电流引起。

思路
已知地磁场的实际南北极位置，从而确定地球内部磁场方向；再依据安培定则，用拇指指向内部磁场方向推导四指（电流）绕行方向。

步骤
1. 根据地磁场规律：地磁 $S$ 极在地理北极附近，地磁 $N$ 极在地理南极附近。地球内部磁感线方向由 $S$ 指向 $N$，即从地理北极附近指向地理南极附近。
2. 设定右手拇指指向：内部磁场方向为地球内部磁感线方向，因此拇指应指向南方（地理南极方向）。
3. 右手四指自然弯曲表示电流绕行方向，与拇指方向垂直接近。当拇指指向南方时，四指弯曲指向西方（由右手定则严格判断）。
4. 对照四个选项，选出电流方向（即四指弯曲方向）向西的图，选项 C 正确。

点评/变式
- 核心考查点是安培定则与地磁场分布的整合。类似题目可能直接将地磁场换成通电螺线管或电磁铁，要求判断电流方向或磁极。
- 变式注意：若题干给出的是电子沿环形轨道运动，需先根据电子运动反方向确定等效电流方向，再使用安培定则。
- 灵活掌握“拇指指内部磁场，四指指电流”的单一定向逻辑，就可在此类题中快速选定正确示意图。
