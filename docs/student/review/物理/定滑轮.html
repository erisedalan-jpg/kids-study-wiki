定滑轮

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：0
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 定滑轮模型：轻绳跨过光滑定滑轮，绳与轮无相对滑动，绳不可伸长。
  • 绳上张力处处相等（滑轮光滑不计转动惯量）。
  • 连接体沿绳方向的速度、加速度大小始终相等。
  • 机械能守恒定律（系统）：若只有重力或弹力做功，系统机械能守恒。
    对本题系统（a 球、b 球、地球）：
    $$\Delta E_k + \Delta E_p = 0$$
    或
    $$E_{初} = E_{末}$$
  • 运动分段分析：当一侧物体触地或碰撞后，绳可能松弛，需分过程求解。
  • 阶段一：绳绷紧，两球共同运动，系统机械能守恒（或联合牛顿第二定律+运动学）。
  • 阶段二：绳松后，剩余物体独立运动（如竖直上抛），可用机械能守恒或运动学公式。

解题方法与套路

处理定滑轮连接体问题的标准流程：

  1. 确界过程：判断物体接触地面、绳松紧变化等临界点，把运动划分为不同阶段。
  2. 速度关联：同一根不可伸长的绳连接的两个物体，沿绳方向速度大小始终相等（此处滑轮光滑，两球速度大小相等）。
  3. 阶段一求解（绳拉紧且有共同运动）：
  4. 方法一：对系统用机械能守恒（无摩擦、无外力做功）。
    列式：系统减少的重力势能 = 系统增加的动能 + 系统增加的重力势能（若某一物体升高）。
  5. 方法二：隔离法用牛顿第二定律求加速度，再结合运动学求末速度。
  6. 阶段二求解（绳松后）：
  7. 绳松弛瞬间，物体仅受重力，以此为初速度做竖直上抛或自由落体，可用机械能守恒或运动学公式求上升高度。
  8. 叠加高度：总高度 = 阶段一位移 + 阶段二竖直上抛最大位移。

高频易错

  • 忘记分段：认为 b 球落地瞬间 a 球立即停止，忽略 a 球仍具有速度继续上升，错选 A（h）或仅算出上升至 h 的位移。
  • 机械能守恒写错：
  • 漏算 a 球重力势能增加（如写 $3mgh = \frac12 (3m+m)v^2$，没减 $mgh$）。
  • 动能项质量计算错误：系统总动能应为 $\frac12 (m+M)v^2$，不能只写单个物体动能。
  • 速度关联错误：误认为 a、b 速度不同，或加速度不同。
  • 能量范围混淆：b 落地时认为动能完全转化为 a 的重力势能，即 $\frac12 m v^2 = mgh_2$，但忽略了 b 落地阶段系统动能与势能转化的整体性（阶段一系统动能是二者共有，阶段二才是 a 单独动能转化）。
  • 符号与高度基准混淆：未明确参考面，导致势能计算差符号。

代表题精讲

2008-全国Ⅱ-05

题目：如图，光滑定滑轮，柔软不可伸长细绳，a 球质量 $m$ 静置于地面，b 球质量 $3m$ 用手托住高度 $h$，绳刚好拉紧。释放 b 后，a 可能到达的最大高度是？

思路：分两阶段。阶段一：b 从 $h$ 高处下落至地面，绳拉紧带动 a 上升，系统机械能守恒求 b 落地瞬间二者共同速度 $v$。阶段二：b 落地绳松弛，a 以速度 $v$ 做竖直上抛，机械能守恒求再上升高度 $h'$。总高度 $H = h + h'$。

步骤：
1. 选地面为零势能面。
2. 阶段一系统机械能守恒：
$$3mgh = mgh + \frac12 (m+3m)v^2$$
$$\Rightarrow 2mgh = 2m v^2 \Rightarrow v^2 = gh$$
3. 阶段二 a 球竖直上抛，机械能守恒（或运动学）：
$$\frac12 m v^2 = mg h'$$
$$h' = \frac{v^2}{2g} = \frac{gh}{2g} = 0.5h$$
4. 最大高度：$H = h + h' = 1.5h$，故选 B。

点评/变式：
- 典型“绳连体+临界脱离”问题，核心在于 b 触地后绳松，a 不是立即停而是继续上抛。
- 若将 b 质量改为 $m$，则 $v=0$，$a$ 不上升，$H=h$？但 $a$ 本来在地面，初始无法释放？需不平衡。
- 若 b 质量小于 $m$，则 a 下沉，b 上升，考察另一侧脱离。务必找准系统与过程的边界。
