知识精要

  • 欧姆定律（部分电路）：$U = IR$，适用于纯电阻元件或已知恒定电流的回路。在实验中，若保持通过某元件的电流恒定，其两端电压的变化直接反映其电阻变化：$R = \frac{U}{I}$，$I$ 一定时，$U \propto R$。
  • 线性关系的处理：若两个物理量成线性关系，图像为一条倾斜直线，斜率（或斜率的绝对值）常代表特定物理量。在分析传感器特性时，灵敏度通常定义为 $|k| = \left| \frac{\Delta y}{\Delta x} \right|$ (输出量对输入量的变化率)。
  • 图像数据的读取与计算：从图线上取点计算斜率时，应选取尽量远且便于读数的两点，利用 $k = \frac{y_2 - y_1}{x_2 - x_1}$ 求解，注意有效数字的保留规则。
  • 电路动态调节：在分压或限流电路中，为保证某支路电流恒定，当负载电阻变化时，需反向调节滑动变阻器。判断滑动变阻器滑片移动方向的关键：分析总电阻变化对电压分配的影响，使目标电压或电流恢复原值。

解题方法与套路

  1. 恒定电流电路的分析：首先明确“恒定电流”是控制条件，利用 $U = I R$ 将元件两端电压与电阻直接关联。例如已知电流 $I_0$ 和定值电阻 $R_0$，则 $R_0$ 上的电压 $U_1 = I_0 R_0$ 必须恒定，以此作为调节目标。
  2. 图像判断电阻/电压趋势：题干给出 $U!-!t$ 图线，若电流恒定，电阻 $R = U/I$ 的变化趋势与 $U$ 一致。温度升高时从图线看出电压 $U$ 减小，则电阻减小。
  3. 动态调节滑片方向的推理：外围元件电阻变化 → 导致总电流或电压重新分配 → 需要调节滑片改变电路电阻，使待稳量恢复。例如负载电阻减小、两端电压下降时，若要从滑变重新获得目标电压，通常需减小串联部分电阻（或增大并联部分的分压），据此判断滑片向哪端移动。
  4. 灵敏度/斜率的计算：在 $U!-!t$ 线性图像上，任选两点 $(t_1, U_1)$、$(t_2, U_2)$，计算斜率绝对值 $|\Delta U / \Delta t|$。单位用 $\text{V/}^\circ\text{C}$，结果按题目要求的有效数字保留（如保留2位有效数字）。

高频易错

  • 错把图像斜率当作电阻变化率：题目中灵敏度定义是 $|\Delta U / \Delta t|$，而不是 $\Delta R / \Delta t$。由于电流恒定，两者仅差常数倍 $I$，但需按题目明确指出的定义计算。
  • 读数与有效数字处理不当：从坐标纸上读取点的坐标时，容易估读错误或计算斜率后有效数字保留错误。必须注意题目要求“保留2位有效数字”，并检查计算器结果。
  • 滑片移动方向判断逻辑混乱：未分清电路结构（分压式还是限流式），误将“要使 $U_1$ 恢复原值”等同于“增大总电压”或“减小总电阻”，没有结合具体电路节点电位变化分析。
  • 忘记温度升高电压减小的深层含义：误认为二极管正向电阻随温度变化是“变大”，或因看到电压减小而错误判断电阻不变。实际上恒定电流下 $U \propto R$，必须结合图线走势判断。
  • 单位转换遗漏：题中电压单位 $\text{mV}$ 与 $\text{V}$ 的换算易被忽略，导致结果差1000倍。计算灵敏度时，务必统一单位（通常最终用 $\text{V}$），并注意毫伏与伏的转换。

步骤
- 第（1）问
$R_0=100\,\Omega$，$I=50.0\,\mu\text{A} = 5.00\times10^{-5}\,\text{A}$。
由 $U_1 = I R_0 = 5.00\times10^{-5} \times 100 = 5.00\times10^{-3}\,\text{V} = 5.00\,\text{mV}$。
从 $U!-!t$ 图线看，温度升高时 $U$（二极管正向电压）减小。因为 $I$ 恒定，由 $R_{\text{D}} = U/I$ 知正向电阻变小；二极管电压减小导致支路总电压下降，要保持 $U_1$ 不变，需提高加在 $R_0$ 上的分压比例。结合电路，滑片向 $B$ 端移动可使与二极管串联部分的电阻减小，从而提升 $U_1$ 使其恢复原值。
答案：$5.00$；变小；增大；$B$。
- 第（2）问
在 $U!-!t$ 图线上选点：$t_1=10\,^\circ\text{C}$ 时 $U_1\approx 0.43\,\text{V}$，$t_2=60\,^\circ\text{C}$ 时 $U_2\approx 0.29\,\text{V}$。
斜率绝对值 $|\Delta U / \Delta t| = |0.29-0.43| / |60-10| = 0.14 / 50 = 2.8\times10^{-3}\,\text{V/}^\circ\text{C}$。
保留2位有效数字：$2.8\times10^{-3}$。

点评/变式
- 本题核心是理解“恒定电流”下电压表读数与电阻的等价性。
- 滑片移动方向是常见失分点，可简记：当二极管电阻减小、其分压减小时，若要维持定值电阻电压不变（即电流不变），应让滑变额外给予更多分压，通常需将滑片向使与二极管串联电阻减小的方向调节。
- 灵敏度计算实质是求斜率，注意坐标读出时无须从零开始，只需差值准确。类似题可变换为热敏电阻的 $R!-!t$ 线性关系，并计算 $|\Delta R / \Delta t|$。
