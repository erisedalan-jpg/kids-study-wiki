考点定位

  • 父主题：实验 与 测量
  • 权重 weight：6
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择9
  • 难度分布：易1

知识精要

  • 实验原理
  • 运动学测加速度：物体从静止开始匀加速直线运动，位移与时间满足 $h = \frac{1}{2} a t^2$，即 $a = \frac{2h}{t^2}$。实验中常测量某段下落高度与所用时间。
  • 动力学理论加速度：对跨过轻滑轮的两小球整体，由牛顿第二定律 $m_B g - m_A g = (m_A + m_B) a'$，得理论值 $a' = \frac{m_B - m_A}{m_A + m_B} g$。
  • 误差来源
  • 系统误差：滑轮有质量、存在摩擦阻力、细绳有质量、空气阻力、释放时初速度不为零等，这些会使测量加速度普遍偏小或偏大。
  • 偶然误差：长度、时间、质量的测量读数误差。
  • 有效数字：计算过程中保留的位数应与题目给出的测量值有效数字位数匹配，最终结果按要求保留一定位数，运算时采用四舍五入。

解题方法与套路

  1. 明确实验目的与原理
    先判断是单纯用运动学公式测加速度，还是同时需用牛顿第二定律算理论值。大多数此类题两部分都要处理。
  2. 选择合适的运动学公式
    若从静止释放，已知时间 $T$ 和下落距离 $s$，直接用 $s = \frac{1}{2} a T^2$ 求 $a$；若给出了多个距离和时间，可考虑用逐差法。
  3. 代入数据计算
    注意单位统一（通常用国际单位：m、s、kg），将 $h$ 看作下落的总高度差，而非某单一高度。计算时先写公式，再代入数据，最后得出结果并按要求保留有效数字。
  4. 理论加速度的推导
    应用整体法列牛顿第二定律，注意两物体用轻绳连接，加速度大小相等。列式时重力差为合外力，总质量是两物体质量之和。
  5. 误差对比与原因分析
    比较实验值 $a$ 与理论值 $a'$ 的大小关系（通常 $a < a'$），从装置并非理想入手，具体指出：滑轮摩擦、空气阻力未计，或滑轮、绳有质量等。表述要具体，避免“测量误差”等空洞说法。

高频易错

  • 位移代入错误：题目给出释放时高度 $h_0$ 和末高度 $h$，下落高度应为 $s = h_0 - h$，误用 $h_0$ 或 $h$ 直接代入 $h = \frac{1}{2} a t^2$。
  • 有效数字出错：题中原始数据多为三位有效数字，结果也常要求保留三位，计算时注意不要擅自多保留或少保留。例如 $1.60$ 不能写成 $1.6$。
  • 整体法列式时质量搞错：理论加速度表达式往往易写成 $a' = \frac{m_B - m_A}{m_B} g$ 或漏掉滑轮质量（若滑轮有质量并非轻滑轮则要考虑转动惯量，但高中阶段大多只要求指出影响）。
  • 误差原因表述笼统：失分点常在于只写“有误差”或“读数不准”，应明确指出系统误差来源：“滑轮存在摩擦”“空气阻力”“细绳有质量”等。

代表题精讲

题目 （2020·新课标Ⅱ·09）
用跨过定滑轮的两小球 A、B 测量加速度。释放后测出小球 B 下落高度变化 $h_0 - h = 0.590 m - 0.100 m = 0.490 m$，用时 $T = 0.730 s$。A、 B 质量分别为 $100.0 g$ 和 $150.0 g$，$g = 9.80 m/s^2$。求实测加速度 $a$、理论加速度 $a'$（保留3位有效数字），并分析差异的主要原因。

思路
实测加速度通过匀加速位移公式求得；理论加速度由轻绳连接体的牛顿第二定律得出；比较两者大小，从非理想条件找出具体原因。

步骤 1. 下落高度 $s = h_0 - h = 0.490 m$，由 $s = \frac{1}{2} a T^2$ 得
$$a = \frac{2s}{T^2} = \frac{2 \times 0.490}{0.730^2} \approx 1.84 m/s^2$$ 保留三位有效数字为 $1.84 m/s^2$。
2. 理论加速度：对整体 $m_B g - m_A g = (m_A + m_B) a'$
$$a' = \frac{m_B - m_A}{m_A + m_B} g = \frac{0.1500 - 0.1000}{0.1500 + 0.1000} \times 9.80 = \frac{0.0500}{0.2500} \times 9.80 = 1.96 m/s^2$$ 保留三位有效数字为 $1.96 m/s^2$。
3. 对比发现实测 $a < a'$，系统误差主要原因：滑轮与轴之间存在摩擦、细绳与滑轮之间有摩擦、空气阻力、滑轮有质量使一部分力用于使其转动等，写出其中一条即可。

点评/变式
- 数据计算需细心，先查高度变化量，再代公式。
- 理论值推导务必用整体法，避免隔离法出错。
- 误差分析是此类实验题的必考点，回答时需从“理想条件忽略的因素”切入，如绳重、滑轮质量、各种阻力，切忌只说“人为误差”或“仪器不准”。变式可改为用光电门测瞬时速度计算加速度，原理类似。
