对数函数

考点定位

  • 父主题：物理方法 与 通用
  • 权重 weight：0
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 对数运算核心公式（$a>0, b>0, c>0$）：
  • $\lg(ab) = \lg a + \lg b$，$\lg\frac{a}{b} = \lg a - \lg b$
  • $\lg a^n = n\lg a$（$n$为任意实数）
  • $\lg 1 = 0$，$\lg 10 = 1$
  • 物理量间的幂函数关系可通过取对数转化为线性关系： 若 $y = k x^\alpha$（$k>0, x>0$），则 $\lg y = \alpha \lg x + \lg k$。 图像为一条直线，斜率 $=\alpha$，截距 $=\lg k$。
  • 适用条件：所有变量必须取正值，否则不能直接取对数；常选用相同量纲的比值作为对数的真数以消除量纲（即无量纲化），如 $\lg(\frac{T}{T_0})$。
  • 常见物理规律的对数形式：
  • 开普勒第三定律 $R^3 / T^2 = k$ $\Rightarrow$ $3\lg R - 2\lg T = \lg k$
  • 对同一天体系统，不同行星满足 $3\lg(R/R_0) = 2\lg(T/T_0)$，即 $\lg(R/R_0) = \frac{2}{3}\lg(T/T_0)$ 或 $\lg(T/T_0) = \frac{3}{2}\lg(R/R_0)$。

解题方法与套路

  1. 写出原始物理规律，找出相关物理量间的幂函数关系式（通常为比例式 $y \propto x^n$）。
  2. 无量纲化：引入恰当的参考量（如题目给定的 $T_0, R_0$），将各物理量写成比值形式，确保对数的真数为纯数。
  3. 两边取常用对数（或自然对数，视题目坐标系底数而定），利用对数运算法则展开。
  4. 整理成 $Y = mX + b$ 的线性形式，明确哪个量作纵坐标、哪个作横坐标。
  5. 由斜率 $m$、截距 $b$ 及是否过原点，匹配图像特征（如斜率正负、数值大小、有无截距等）。
  6. 若选项为图像选择题，可直接通过特殊点验证（取 $T=T_0$ 时 $R=R_0$ 对应点）辅助判断。

高频易错

  • 对数运算法则混淆：误以为 $\lg(a+b)$ 可拆开，或记错 $\lg a^n = (\lg a)^n$。牢记仅乘除运算与幂运算可拆。
  • 忽略真数为正的条件：物理量（周期、半径等）均大于零，但若坐标轴直接标以 $\lg T$ 而非 $\lg(T/T_0)$，需警惕 $T$ 的数值可能因单位选取而小于 1 导致对数为负，但仍成立。
  • 比例系数 $k$ 处理不当：取对数时容易丢掉 $\lg k$，导致误以为图线必过原点。只有经过合适比值变换（如 $R/R_0, T/T_0$）且常数抵消时，图线才过原点。
  • 斜率的倒数关系：横纵坐标互换时斜率互为倒数。例如 $y= \frac{2}{3}x$ 与 $x= \frac{3}{2}y$ 对应不同图像，需严格按题目给定的坐标轴判断。
  • 误把指数当斜率：对 $R^3 \propto T^2$，直接写成 $\lg R = \frac{3}{2}\lg T$ 是错误的；正确为 $3\lg R = 2\lg T + \text{const}$，若横轴为 $\lg T$、纵轴为 $\lg R$，则斜率为 $2/3$，而非 $3/2$。

代表题精讲

2010-新课标Ⅰ-07（6分）

题目：太阳系八大行星的轨道均可近似为圆轨道。用 $T$ 和 $R$ 分别表示行星绕太阳运行的周期和轨道半径，$T_0$ 和 $R_0$ 分别是水星绕太阳运行的周期和轨道半径。下列4幅图中，横轴为 $\lg(T/T_0)$，纵轴为 $\lg(R/R_0)$，正确的是（ ）

思路：由开普勒第三定律建立 $R$ 与 $T$ 的关系，将比值代入后取对数，导出 $\lg(R/R_0)$ 关于 $\lg(T/T_0)$ 的表达式，根据斜率和截距选择图像。

步骤： 1. 行星绕太阳做圆周运动，开普勒第三定律：$\frac{R^3}{T^2} = k$，其中 $k$ 对同一中心天体为常数。
2. 对水星同样有 $\frac{R_0^3}{T_0^2} = k$，两式相除得： $$\frac{R^3}{R_0^3} = \frac{T^2}{T_0^2} \quad \Rightarrow \quad \left(\frac{R}{R_0}\right)^3 = \left(\frac{T}{T_0}\right)^2$$ 3. 两边取常用对数： $$3\lg\left(\frac{R}{R_0}\right) = 2\lg\left(\frac{T}{T_0}\right)$$ 4. 整理为纵轴关于横轴的函数： $$\lg\left(\frac{R}{R_0}\right) = \frac{2}{3}\lg\left(\frac{T}{T_0}\right)$$ 5. 这是一条过原点的直线，斜率 $= \frac{2}{3} > 0$，故选相应的过原点且斜率为正、小于1的直线图像。

点评/变式： - 本质是将幂函数关系 $y \propto x^{n}$ 经取对数后线性化。本题利用比值消去常数 $k$，使得图像必过原点。 - 若横纵坐标互换（横轴 $\lg(R/R_0)$，纵轴 $\lg(T/T_0)$），则关系变为 $\lg(T/T_0) = \frac{3}{2}\lg(R/R_0)$，斜率为 $1.5$，图像仍过原点但“更陡”。 - 应试时，快速验证特殊点：当 $T=T_0$ 时 $R=R_0$，则横纵坐标均为 $\lg 1 = 0$，图像必过 $(0,0)$，排除不过原点的选项；再结合斜率大小即可锁定答案。
