封闭气体压强

考点封闭气体压强权重1真题数1学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：1
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：填空14
  • 难度分布：中1

知识精要

  • 封闭气体压强的确定
  • 液柱平衡法：在U形管或液柱连接的容器中，同一水平液面处压强相等。压强差由液柱高度差产生：$\Delta p = \rho g h$。用水银柱时，压强差常用“mmHg”直接表示，$1\,\text{mmHg}$ 即 $1\,\text{mm}$ 高水银柱产生的压强。
  • 真空参考：若某空间为真空（$p=0$），与之连接的气体压强等于液柱高度差对应的压强。
  • 理想气体状态方程
  • 一般形式：$pV = nRT$，对一定质量的理想气体，常用比例式 $\dfrac{p_1V_1}{T_1} = \dfrac{p_2V_2}{T_2}$。
  • 气体实验定律（适用条件：质量一定）
  • 玻意耳定律（等温变化）：$p_1V_1 = p_2V_2$。
  • 查理定律（等容变化）：$\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$，其中 $T$ 必须用热力学温度，$T = t + 273\,\text{K}$。
  • 关联气体与体积分配
  • 多个容器连通前后，气体总质量不变，各自状态量通过总体积约束、压强平衡关系关联。
  • 本题特例：$A$ 初始为真空，打开阀门后 $A$ 与 $B$ 连通，气体充满总体积，属于等温膨胀。

解题方法与套路

  1. 选对象：明确研究哪部分气体（通常是经历状态变化且质量不变的那部分），必要时分研究对象处理（如 $B$ 中气体、$C$ 中气体）。
  2. 拆状态：针对每一过程，分清初态和末态，并标出各状态的参量 $(p, V, T)$。
  3. 列压强关系：利用液柱高度差或连通器原理写出各部分气体压强与已知量的关系。常用写法：$p_{\text{气}} = p_0 \pm \rho g \Delta h$。
  4. 写体积关系：利用题目给出的容积比例、总体积守恒等条件将各体积用同一未知量或已知量表示。
  5. 套定律：根据过程特征选择对应的气体实验定律或状态方程列方程。等温过程直接用玻意耳定律，体积不变直接用查理定律。
  6. 解算：联立方程求解，注意单位一致性（压强用mmHg时体积单位可任意，只需前后一致；温度必须用开尔文）。

高频易错

  • 忽略“细管体积远小于玻璃泡容积”的条件：此条件允许在体积计算时不计入U形管和细管内气体的体积，否则体积关系复杂且无法求解。
  • 温度未换算为开尔文：气体定律中的 $T$ 是热力学温度，用 $t+273$ 代入，尤其在第二步加热过程中容易直接使用摄氏温度列式。
  • 压强基准混淆：未分清是高“于”还是低“于”大气压，导致 $\Delta p$ 的加减号出错。建议始终以某一水平面为参考，写出 $p_{\text{左}} = p_{\text{右}} + \rho g \Delta h$ 形式的等式。
  • 真空区域压强处理错误：真空 $p=0$，不能当成 $p_0$。
  • 对象混淆：打开阀门后 $A$ 与 $B$ 连通，气体为原 $B$ 中的气体，$C$ 中气体未参与此过程，加热时只加热了 $C$ 所在水槽，需区分清楚哪部分气体经历什么变化。

代表题精讲

2012-新课标-14

题目
如图，用U形管和细管连接的玻璃泡 $A$、$B$、$C$ 浸在 $0^\circ\text{C}$ 水槽中，$B$ 的容积是 $A$ 的 $3$ 倍。阀门 $S$ 隔开 $A$ 和 $B$，$A$ 内为真空，$B$ 和 $C$ 内充有气体。初始U形管内左边水银柱比右边低 $60\,\text{mm}$。打开阀门 $S$，系统稳定后U形管内左右水银柱高度相等。细管和U形管内气体体积远小于玻璃泡容积。
（1）求玻璃泡 $C$ 中气体的压强（以 $\text{mmHg}$ 为单位）；
（2）将右侧水槽的水从 $0^\circ\text{C}$ 加热到一定温度时，U形管内左边水银柱比右边高 $60\,\text{mm}$，求加热后右侧水槽的水温。

思路
- 第一步为等温变化过程，以原 $B$ 内气体为研究对象，打开 $S$ 后它膨胀到 $A+B$。利用初末态压强关系与体积关系，列玻意耳定律求出末态压强，结合U形管水银柱高度变化（最后相平）反推出 $C$ 中气体的压强。
- 第二步为 $C$ 内气体的等容变化（$C$ 的玻璃泡容积不变），初态压强即第一步所求，末态压强根据水银柱高 $60\,\text{mm}$ 的新平衡关系求得，再利用查理定律求末温。

步骤
1. （1）求 $p_C$
- 设 $A$ 的容积为 $V$，则 $B$ 的容积为 $3V$。初始时 $B$ 内气体压强记为 $p_{B1}$，$C$ 内气体压强记为 $p_C$。
- 初始U形管中左边水银柱比右边低 $60\,\text{mm}$，则有 $p_C = p_{B1} + 60\,\text{mmHg}$。
- 打开阀门 $S$ 稳定后，$A$、$B$ 连通，水银柱相平，说明此时 $B$ 侧气体压强等于 $p_C$，记 $p_{B2} = p_C$。该过程为等温变化，对 $B$ 中原气体使用玻意耳定律：$p_{B1} \cdot 3V = p_{B2} \cdot (3V + V) = p_C \cdot 4V$。
- 联立 $p_C = p_{B1} + 60$ 和 $p_{B1} \cdot 3V = p_C \cdot 4V$，消去体积得 $3p_{B1} = 4p_C$。
- 将 $p_{B1} = \frac{4}{3}p_C$ 代入 $p_C = \frac{4}{3}p_C + 60$，解得 $\frac{1}{3}p_C = 60$，即 $p_C = 180\,\text{mmHg}$。

  1. （2）求加热后水温
  2. $C$ 中气体体积不变（等容变化）。初态：$T_1 = 273\,\text{K}$，$p_1 = 180\,\text{mmHg}$。
  3. 加热后右侧水槽升温，U形管左边水银柱比右边高 $60\,\text{mm}$。此时 $C$ 内压强 $p_2$ 满足：$p_2 = p_{B}' + 60$，且此时 $A$、$B$ 侧气体仍为原 $B$ 内气体，其体积、温度未变（仍浸在 $0^\circ\text{C}$ 水槽中），故 $p_{B}' = p_{B2} = p_C = 180\,\text{mmHg}$。因此 $p_2 = 180 + 60 = 240\,\text{mmHg}$。
  4. 对 $C$ 中气体用查理定律：$\frac{p_1}{T_1} = \frac{p_2}{T_2}$，代入得 $\frac{180}{273} = \frac{240}{T_2}$。
  5. 解得 $T_2 = \frac{240 \times 273}{180} = 364\,\text{K}$，对应摄氏温度 $t_2 = 364 - 273 = 91^\circ\text{C}$。

点评/变式
- 抓住“细管体积忽略”使体积关系极简，只与玻璃泡容积比有关，是破解复杂装置的关键。
- 第二问中容易误认为 $B$ 侧气体也升温，需细审题意（只有右侧水槽加热，$C$ 单独升温，$A$、$B$ 仍在 $0^\circ\text{C}$ 水槽中）。
- 变式：若初始U形管两边高度差方向相反，或加热对象改为左侧，则压强平衡关系须重新建立，但分析框架不变——先定压强关系，再根据对象状态变化选定律。
