布朗运动

考点布朗运动权重17真题数1学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：17
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：填空13
  • 难度分布：易1

知识精要

  • 布朗运动：悬浮在液体或气体中的微小固体颗粒（如花粉、碳粒）所做的不停息的无规则运动。
  • 产生原因：液体（或气体）分子对固体颗粒撞击的不平衡性。
  • 特点：颗粒越小、温度越高，布朗运动越剧烈；运动轨迹无规则，永不停止。
  • 本质：布朗运动不是液体分子的热运动，而是液体分子无规则热运动的间接反映；不能反映固体颗粒自身分子的热运动（固体颗粒由大量分子组成，内部运动不直接表现为布朗运动）。
  • 表面张力：液体表面具有收缩至最小面积的趋势，使液面呈紧绷的弹性膜状。表现为：小液滴（如小雨滴）呈球形、水黾在水面行走等。
  • 液晶：介于液体与晶体之间的物质状态。既有液体的流动性，又在光学性质上具有晶体的各向异性（可随电场等条件变化），常用于显示器。
  • 沸点与气压：饱和蒸气压等于外界气压时的温度称为沸点。高原地区气压低，沸点降低，而非温度低所致。
  • 蒸发吸热：液体蒸发时从周围吸热，导致自身或邻近物体温度降低。干湿泡温度计湿泡因纱布中的水蒸发吸热，示数低于干泡。

解题方法与套路

该类选择题通常考查热学基本概念辨析，采用“逐项判断正误+选项组合”的解法： 1. 逐项分析因果关系：对每个选项，先锁定核心物理知识点，再核对叙述的因果链条是否成立。 - 如：布朗运动反映“液体分子热运动”√，反映“花粉分子热运动”×。 - 如：雨滴球形是“表面张力”的结果√；高原沸点低是“气压低”的结果√，是“温度低”的结果×。 2. 警惕偷换主语/对象：布朗运动、分子力等描述中，主体混淆是常见设错方式。 3. 关联实际现象与物理原理：液晶显示器利用了各向异性；干湿泡温度差利用蒸发吸热。平时积累典型应用，直接匹配即可。 4. 多选排除法：若为多项选择题（本题实为选正确项，可多选），先确认绝对错误的选项，再对存疑项用原理反推，避免漏选。

高频易错

  • 布朗运动主体的张冠李戴：易误认为布朗运动反映了花粉分子或固体颗粒分子的热运动。正确表述：反映液体（气体）分子的无规则运动。
  • 沸点与气压的关系混淆：高原沸点低常被误归因于“高原温度低”，实质是气压低导致沸点降低。
  • 液晶性质的片面理解：液晶兼具流动性和各向异性，不要误以为液晶像普通晶体一样所有性质均各向异性，或忽略其光学各向异性的应用。
  • 表面张力与浸润/不浸润区分：小雨滴球形是表面张力起主导，而非重力缺失或大气压作用。
  • 蒸发吸热对象错位：干湿泡温度计湿泡示数低是因为水蒸发吸热使湿泡自身降温，不是环境温度低。

代表题精讲

题目（2014·新课标Ⅱ·13）

下列说法正确的是（多选题）
A. 悬浮在水中的花粉的布朗运动反映了花粉分子的热运动
B. 空气的小雨滴呈球形是水的表面张力作用的结果
C. 彩色液晶显示器利用了液晶的光学性质具有各向异性的特点
D. 高原地区水的沸点较低，这是高原地区温度较低的缘故
E. 干湿泡温度计的湿泡显示的温度低于干泡显示的温度，这是湿泡外纱布中的水蒸发吸热的结果

思路：本题涉及布朗运动、表面张力、液晶、沸点与气压、蒸发吸热五个独立的热学知识点，逐一调用对应原理进行因果辨析，判定正确选项。

步骤： 1. 选项A：布朗运动是花粉颗粒的运动，花粉颗粒包含大量分子，其运动反映的是水分子的无规则热运动，而非花粉分子的热运动。错误。 2. 选项B：液体表面层分子间距较大，分子力表现为引力，使液面有收缩到最小面积的趋势，小水滴在无其他外力显著影响时呈球形。正确。 3. 选项C：液晶分子的排列存在某种取向序，导致其光学性质（如折射率）沿不同方向不同，彩色液晶显示器正是利用此各向异性，通过电场控制液晶取向改变光学特性。正确。 4. 选项D：沸腾条件是饱和蒸气压等于外界压强。高原气压低，饱和蒸气压达到外界气压所需的温度较低，故沸点低；并非高原气温低所致。错误。 5. 选项E：湿泡温度计的纱布保持湿润，水蒸发需吸收热量，使湿泡及邻近水银感温球温度下降，故示数低于干泡。正确。

正确选项：B、C、E。

点评/变式：本题为热学组合式正误判断，覆盖多个二级考点，难度适中。常见的变式是更换部分选项的场景（如将小雨滴改为水黾浮于水面、液晶改为各向同性表述、高原沸点改为高压锅原理），要求考生仍用“原理→现象”的对应关系快速锁定。备考时需将各知识点的“因果关系”牢记，尤其防范主体偷换。
