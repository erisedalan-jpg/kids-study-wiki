带电粒子在匀强电场中的偏转

考点带电粒子在匀强电场中的偏转权重0真题数1学科物理父主题静电场

考点定位

  • 父主题：静电场
  • 权重 weight：0
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 基本模型：不计重力的带电粒子以初速度 $v_0$ 垂直射入匀强电场（电场方向与 $v_0$ 垂直），在电场力作用下做匀变速曲线运动，轨迹为抛物线，属于类平抛运动。
  • 运动分解
  • 沿初速度方向（设为 $x$ 轴）：匀速直线运动，$x = v_0 t$。
  • 沿电场力方向（设为 $y$ 轴）：初速为零的匀加速直线运动，加速度 $a = \dfrac{F}{m} = \dfrac{qE}{m}$（$E$ 为电场强度大小，$q$ 含正负）。
  • 核心公式
  • 偏转位移：$y = \dfrac{1}{2}at^2 = \dfrac{1}{2}\dfrac{qE}{m}\left(\dfrac{x}{v_0}\right)^2$。
  • 轨迹方程：$y = \dfrac{qE}{2mv_0^2}x^2$，轨迹为过原点的抛物线，开口由 $\dfrac{qE}{m}$ 的符号与大小决定。
  • 速度偏转角 $\theta$ 满足：$\tan\theta = \dfrac{v_y}{v_x} = \dfrac{at}{v_0} = \dfrac{qE}{mv_0}\cdot\dfrac{x}{v_0} = \dfrac{qEx}{mv_0^2}$。
  • 位移偏转角 $\phi$ 满足：$\tan\phi = \dfrac{y}{x} = \dfrac{qEx}{2mv_0^2}$，且有 $\tan\theta = 2\tan\phi$。
  • 适用条件：匀强电场，粒子不受重力或其他外力，初速度垂直于电场方向。

解题方法与套路

  1. 定坐标：以入射点为原点，初速度方向为 $x$ 轴正方向，与电场方向平行的方向为 $y$ 轴（注意电场方向可能有两种取向，需分情况讨论）。
  2. 判偏转方向：根据电荷正负与电场方向确定加速度 $a = \dfrac{qE}{m}$ 的方向。正电荷加速度与电场方向相同，负电荷相反；若电场方向未知，需保留两种可能性（如 $+y$ 或 $-y$）。
  3. 写轨迹方程：利用 $y = \dfrac{qE}{2mv_0^2}x^2$，将不同粒子的比荷 $\dfrac{q}{m}$ 代入，比较抛物线开口大小（二次项系数绝对值越大，开口越窄）和开口方向（同号同向，异号反向）。
  4. 比轨迹特征：同一坐标下，$x$ 相同时 $y \propto \dfrac{q}{m}$；若电场强度 $E$ 和 $v_0$ 均相同，可直接比较各粒子轨迹形状与相对位置，排除明显矛盾选项。
  5. 校验选项：在定性判断中，可结合“速度相同、电场相同”时，偏转位移与比荷成正比，且正负电荷轨迹关于 $x$ 轴对称（若电场方向唯一确定则不对称，但题目常隐藏电场方向而要求选“可能”图像）。

高频易错

  • 忘记电场方向未知性：题干若只给出“电场方向与 $y$ 轴平行”而未指明正负，则存在 $+y$ 与 $-y$ 两种可能，图像可能上下对称，只考虑一种方向会漏选。
  • 将比荷混淆为电荷量：偏转位移取决于比荷 $\dfrac{q}{m}$ ，而非单纯的 $q$ 或 $m$。粒子电荷量加倍但质量不变时，偏转加倍；若质量同时成比例增加，偏转可能不变。
  • 忽略负电荷轨迹反向：负电荷加速度与正电荷相反，轨迹在 $x$ 轴另一侧，容易错判为相同侧。
  • 开口大小判断失误：误认为 $q$ 越大开口越小，忘记除以质量。应直接比较 $\dfrac{q}{m}$ 的绝对值：绝对值越大，开口越“窄”（相同 $x$ 时 $|y|$ 越大，看起来更贴近 $y$ 轴）。
  • 轨迹对称性误用：对质量不同、电荷不同的粒子，勿随意套用“正负粒子轨迹对称”，对称性仅当电场方向确定且比荷绝对值相同时成立；若比荷绝对值不同，则两抛物线开口大小不同不构成对称。

代表题精讲

代表题 2021-全国乙-07

题目：四个带电粒子的电荷量和质量分别为 $(+q, m)$、$(+2q, m)$、$(+3q, 3m)$、$(-q, m)$，先后以相同的速度从坐标原点沿 $x$ 轴正方向射入一匀强电场，电场方向与 $y$ 轴平行，不计重力。下列描绘四个粒子运动轨迹的图像中，可能正确的是（）

思路：四个粒子初速相同、电场相同，但比荷不同且正负有别，电场方向未知。轨迹为抛物线，表达式 $y=\dfrac{qE}{2mv_0^2}x^2$。为方便比较，令 $k=\dfrac{q}{m}$（带符号），则轨迹为 $y=\dfrac{kE}{2v_0^2}x^2$。四个粒子的 $k$ 值分别为：$+k_1=+\dfrac{q}{m}$，$+k_2=+\dfrac{2q}{m}$，$+k_3=+\dfrac{3q}{3m}=+\dfrac{q}{m}$，$+k_4=-\dfrac{q}{m}$。可见粒子1与粒子3的比荷相同，轨迹全同；粒子2比荷是粒子1的两倍，其抛物线开口更窄（$|k|$更大）；粒子4与粒子1比荷绝对值相等但符号相反，若电场方向确定，轨迹应关于 $x$ 轴对称开口大小相同，但电场方向可有两种取向，因此粒子1与粒子4的轨迹可能关于 $x$ 轴对称，也可能粒子1在上、粒子4在下，反之亦然。结合选项图像需同时满足：两轨迹重合（1和3）、一轨迹开口更窄且同侧（2）、一轨迹开口与重合者相同但反向（4），且允许上下翻转。

步骤： 1. 计算比荷：粒子1: $\dfrac{q}{m}$；粒子2: $\dfrac{2q}{m}$；粒子3: $\dfrac{3q}{3m}=\dfrac{q}{m}$，与粒子1相同；粒子4: $-\dfrac{q}{m}$。 2. 粒子1、3轨迹完全相同，在图像中应为同一曲线。 3. 粒子2比荷绝对值是粒子1的2倍，相同 $x$ 下 $|y|$ 是粒子1的2倍，即轨迹更靠近 $y$ 轴，且与粒子1同侧（同为正）。 4. 粒子4与粒子1比荷大小相等、符号相反，轨迹应在 $x$ 轴另一侧，且与粒子1轨迹关于 $x$ 轴对称。 5. 由于电场方向可能为 $+y$ 或 $-y$，整个图形可能上下颠倒，只要相对关系满足即可。A、D选项满足上述相对关系（包含曲线重合、开口差异、正负分两侧），B、C不满足（如混淆了比荷大小或方向）。

点评/变式：本题关键点在于——相同速度与相同电场下，粒子偏转仅由比荷 $q/m$ 决定；电场方向的不确定性使得图像存在上下对称的可能，审题时看到“可能正确的是”要主动思考多解情形。变式：若将“电场方向与 $y$ 轴平行”改为“电场方向沿 $y$ 轴正方向”，则电场方向唯一，轨迹相对位置固定，此时粒子4必然偏向下侧，若图像只给出一种取向则须严格匹配。
