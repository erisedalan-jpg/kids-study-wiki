带电粒子在复合场中的运动

考点带电粒子在复合场中的运动权重2真题数1学科物理父主题磁场 与 安培力洛伦兹力

考点定位

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：2
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  1. 复合场定义：重力场、电场、磁场三者同时存在，或其中任意两场并存的空间区域。
  2. 核心分析方法：以带电粒子为研究对象，按序进行受力分析（重力是否考虑视情景而定，电场力、洛伦兹力注意方向），明确合力，结合初速度条件确定运动性质与轨迹。
  3. 直线运动的微宏条件
  4. 匀速直线：合外力为零（平衡态）。
  5. 匀变速直线：合外力恒定，且方向与速度共线。
  6. 常见功能关系
  7. 动能变化看合外力做功；重力做功改变重力势能；电场力做功改变电势能（$W_电 = -\Delta E_p$）；除重力外其他力做功等于机械能变化。
  8. 匀强电场中 $U=Ed$（推导电势能时方便）。
  9. 本题模型提炼：平行板电容器倾斜放置，内部为匀强电场，方向垂直极板；带电粒子受重力恒向下，电场力恒沿电场线。粒子能沿水平直线运动，则竖直方向合力为零（$F_y = mg$），水平方向合力恒定且与速度方向共线，粒子做匀变速直线运动，动能减小、电势能增加。
  10. 易忽视点：题设中“平行板电容器的两个极板与水平地面成一角度”直接提示重力必须纳入分析，不可因“带电粒子”而盲目忽略重力。

解题方法与套路

  1. 定对象、析力源：明确带电粒子，标出重力（常在题干图中隐含）、电场力（由极板正负及粒子电性判断，方向恒垂直于极板）、若存在磁场再加洛伦兹力。
  2. 运动条件反推合力方向：若粒子沿直线运动，则合力必沿该直线方向（匀速）=或合力为零）。对本题倾斜极板，水平直线运动⇒合力必水平向左或右。
  3. 正交分解列式：沿垂直于速度（竖直）和沿速度（水平）方向分解电场力与重力。由竖直方向合力为零求出电场力的竖直分量，进而确定电场力大小及水平分量，得合力大小。
  4. 判定运动类型：合力是否为零？若不为零且恒定，则为匀变速直线运动。结合速度方向知加速或减速。
  5. 能量变化“三步判”
  6. 电场力做正功→电势能减少；做负功→电势能增加。
  7. 合力做正功→动能增加；反之减小。
  8. 除重力外其他力（电场力）做功等于机械能增量。
  9. 应对电性未知：若电荷正负未给定，则可假设电场力某一方向（如垂直极板向上），由平衡需要反推电性，结论如无矛盾即为合理，多数选择题利用选项约束可唯一锁定。

高频易错

  • 惯性误判“直线=匀速”：看到水平直线即认为受力平衡，直接选“重力与电场力平衡”，忽略合力不为零但方向与速度共线的匀变速情形。
  • 错判电场方向：将倾斜电容器电场视为水平或竖直，未抓住“匀强电场方向垂直于极板”这一关键。
  • 重力漏判：题目画有地面或给出“与水平成角度”时，重力必须考虑。未画出重力箭头不代表重力可忽略。
  • 电势能变化推导反向：误认为电场力方向与极板垂直就做正功，实则需看位移与电场力夹角：粒子水平运动，电场力斜向上，若正电荷受力斜向上，位移水平向左/右可能导致夹角大于90°，做负功，电势能增加。
  • 混淆洛伦兹力特性：若题目叠加磁场，粒子做直线运动只能匀速（因为洛伦兹力随速度变），无法做匀变速直线，此题未涉及磁，易在变式中混淆。

代表题精讲

代表题1（2012·新课标·05）

题目：平行板电容器的两极板与水平地面成一倾角，接直流电源。一带电粒子恰能沿图示水平直线通过电容器，分析此过程粒子的能量及运动性质。

思路：粒子受竖直向下的重力 $mg$ 和垂直于极板的电场力 $F$。要水平直线运动，竖直方向必平衡，水平方向合力恒定。由此推出电场力斜向上，合力水平向左（或右），粒子做匀减速直线运动，电场力做负功，电势能增加。

步骤
1. 设极板与水平地面夹角 $\theta$，电场力 $F$ 垂直极板斜向上（可由平衡反推）。
2. 正交分解：
$$F_y = F\cos\theta = mg \quad\text{(竖直合力零)}$$ 水平合力：$F_x = F\sin\theta = mg\tan\theta$，恒定。
3. 因 $F_x$ 与速度方向相反（若粒子向右运动，合力向左），粒子匀减速，动能逐渐减少，C错。
4. 电场力与位移夹角为钝角，做负功，电势能逐渐增加，B对。
5. 合力恒定且与速度共线，粒子做匀变速直线运动，D对。
6. 重力与电场力明显不共线反向，A错。
答案：BD

点评/变式
- 点评：本题属于“电场+重力场”直线运动的典例，考查用力的分解和运动条件推理的能力。关键抓牢“直线运动⇒合力共线”，避免平衡思维的定势。
- 变式：若将电容器改为水平放置，并外加垂直纸面的匀强磁场，粒子做匀速直线运动，则需满足 $qvB = qE$ 且重力被支持力抵消或其他处理，可迁移到“速度选择器”模型。
