平均速度

  • 父主题：运动学
  • 权重 weight：21
  • 真题数：3；年份跨度：2008–2017

知识精要

  • 定义：在变速直线运动中，物体发生的位移 $\Delta x$ 与发生这段位移所用时间 $\Delta t$ 的比值，称为平均速度。它是描述物体位置变化快慢的矢量，方向与位移方向相同。
  • 定义式：$\bar{v} = \frac{\Delta x}{\Delta t}$。这是求解平均速度的通式，适用于一切运动形式。
  • 匀变速直线运动推论：仅当物体做匀变速直线运动时，平均速度才等于该过程初、末瞬时速度的算术平均值，即 $\bar{v} = \frac{v_0 + v}{2}$。其成立的核心条件是加速度恒定。
  • 图像关联：在 $v-t$ 图像中，图线与时间轴所围的面积代表位移。因此，在比较不同运动过程的平均速度时，本质是转化为了“相同时间内比较面积大小（位移大小）”的问题。

解题方法与套路

  1. 直接定义法
    • 适用场景：给定或隐含地给出了过程的总位移和总时间，或涉及非匀变速运动（如变加速、变减速）的平均速度计算。
    • 操作步骤：无需判断运动性质，直接锁定总位移 $\Delta x$ 和总时间 $\Delta t$，代入 $\bar{v} = \frac{\Delta x}{\Delta t}$ 求解或比较。
  2. 推论简化法
    • 适用场景：明确已知物体做匀变速直线运动，且已知初、末速度。
    • 操作步骤：核对运动是否满足“加速度恒定”这一关键前提。确认后，直接应用 $\bar{v} = \frac{v_0 + v}{2}$ 快速计算。此公式在与电磁感应、动力学综合的匀减速问题中，是连接运动学与能量/电路问题的桥梁。
  3. 图像面积法
    • 适用场景：题目给出 $v-t$ 图像，需要比较不同物体的平均速度。
    • 操作步骤：在 $v-t$ 图上，针对相同时间段，直观比较图线与时间轴所围面积的大小。面积大的位移大，由 $\bar{v} = \frac{x}{t}$ 可知，时间相同时，位移大的平均速度大。对于非匀变速曲线，此法是避免公式误用的根本方法。

高频易错

  • 公式滥用：盲目地将 $\bar{v} = \frac{v_0 + v}{2}$ 用于一切运动，这是最高频的错误。务必牢记，该公式仅对匀变速直线运动成立。对于加速度变化的运动，此式算出的仅是算术平均值，而非由位移定义的平均速度。
  • 矢量性遗忘：在涉及往复运动或方向变化的问题中，直接将路程作为代入定义式的时间，或直接用速度大小算术求和。平均速度是矢量，必须用总位移（不能是路程）除以总时间。
  • 图像概念混淆：在 $v-t$ 图像问题中，误将图线某时刻的切线斜率变化（加速度减小）等同于速度减小，或算平均速度时与瞬时速度混淆。

代表题精讲

代表题一：2014-新课标Ⅱ-01

  • 题目：两汽车在同一 $v-t$ 图像中，甲为变加速运动且加速度渐小，乙为变减速运动且加速度渐大，比较 $t_1$ 时间内的平均速度、位移等。
  • 思路：本题的核心是“同等时间，比较位移”。平均速度的比较必须回归定义式 $\bar{v} = \frac{x}{t}$。在 $v-t$ 图中，位移即面积，直接目测甲、乙两图线与时间轴所围面积的大小关系即可。
  • 步骤：
    1. 锁定时间：研究的都是 $0$ 到 $t_1$ 这段时间。
    2. 比较位移（面积）：观察图像，甲图线下方的面积（甲位移）明显大于乙图线下方的面积（乙位移），即 $x_{\text{甲}} > x_{\text{乙}}$。
    3. 判平均速度：由 $\bar{v} = \frac{x}{t}$，时间 $t$ 相同，故 $\bar{v}{\text{甲}} > \bar{v}$。选项A正确，C错误。}
    4. 分析易错点：乙车做变减速运动，不满足匀变速条件，其平均速度不能用算术平均值 $\frac{v_0+v}{2}$，选项B错误。加速度变化看切线斜率，甲斜率渐小，加速度渐小；乙斜率渐大，加速度渐大，选项D正确。
  • 点评/变式：本题是典型的图像+概念题。变式可改为甲、乙图线互换，或问某时间段内平均速度与算术平均值的大小关系。应考原则是：凡遇非匀变，必回定义式。

代表题二：2008-全国Ⅱ-12

  • 题目：导体棒在恒定安培力作用下，做匀减速运动，速度从 $v_0$ 减至 $v_1$。保持棒中电流 $I$ 恒定，求此过程平均感应电动势和负载消耗的平均功率。
  • 思路：本题是运动学推论在电磁感应综合题中的应用。题干中“电流强度 $I$ 保持恒定”导致安培力 $F=BIl$ 恒定，这是核心里程碑——它确立了导体棒做匀减速直线运动的性质。由此，才能用匀变速运动的平均速度公式求解平均电动势。
  • 步骤：
    1. 判运动性质：由 $F=BIl$ 恒定，得加速度恒定，棒做匀减速运动。
    2. 求平均速度：直接使用推论 $\bar{v} = \frac{v_0 + v_1}{2}$。
    3. 求平均感应电动势：由 $E=Blv$ 可知，感应电动势与速度成正比，因此平均感应电动势 $\overline{E} = Bl\bar{v} = Bl \cdot \frac{v_0+v_1}{2}$。
    4. 能量核算平均功率：电源总平均功率 $P_{\text{总}} = \overline{E}I$。负载消耗的平均功率等于总平均功率减去导体棒内阻消耗的热功率，即 $\overline{P} = \overline{E}I - I^2r$。
  • 点评/变式：本题的命门是“恒流→恒安培力→匀减速→可用算术平均速度”。若题目改为“电阻恒定”，则棒做加速度减小的减速运动，那段过程的平均电动势就无法用初末速度的算术平均值来求，只能从电量或能量角度突破。
