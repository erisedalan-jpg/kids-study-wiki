平行四边形定则

考点平行四边形定则权重9真题数1学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：9
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：选择3
  • 难度分布：中1

知识精要

  • 矢量与标量：既有大小又有方向的物理量为矢量（如力、速度、位移），其运算遵从平行四边形定则（或三角形定则）。只有大小的量为标量，按代数和运算。
  • 平行四边形定则：求两个互成角度的共点矢量 $F_1$、$F_2$ 的合矢量时，以 $F_1$、$F_2$ 为邻边作平行四边形，过作用点的对角线即合矢量 $F$。若已知合矢量与一个分矢量，可用同样的定则求另一个分矢量。
  • 三角形定则：将两个矢量首尾相接，从第一个矢量始端指向第二个矢量末端的矢量即合矢量。与平行四边形定则实质相同，更便于解三角形。
  • 矢量关系定量计算：
  • 两个分矢量大小 $F_1$、$F_2$，夹角 $\theta$，合力 $F = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$，方向用正弦定理或余弦定理确定。
  • 已知合矢量 $F$、一个分矢量 $F_1$ 及其与 $F$ 的夹角 $\alpha$ 时，另一个分矢量 $F_2 = \sqrt{F^2 + F_1^2 - 2FF_1\cos\alpha}$（由三角形余弦定理得出），方向由题图中几何关系判定。
  • 合力范围：$|F_1 - F_2| \le F \le F_1 + F_2$，分力夹角增大时合力减小。
  • 适用条件：一切矢量的加减运算，包含力、速度、加速度、位移、电场强度、磁感应强度等。

解题方法与套路

  1. 明确研究对象与矢量环境：确定哪一个矢量为合矢量，哪几个为分矢量。在运动学速度合成中，常以实际运动速度（相对地面）为合速度，其他速度为分速度。
  2. 画矢量合成图：按已知条件画出平行四边形或三角形。标注已知矢量的大小、方向及夹角，未知矢量方向用方位描述（如东偏南、西偏北等）。
  3. 选择解三角形工具：若已知两边及其夹角或三边关系，优先使用余弦定理；若已知两角及一边，用正弦定理。注意夹角是两矢量方向之间的夹角，而非补角。
  4. 定量计算：代入数据，注意单位统一（如 m/s, km/h 等），结果保留合理有效数字。判断矢量方向时，需结合图示与地理方位（东、西、南、北及其偏角）。
  5. 检验合理性：检查结果是否在理论范围内，大小是否合理，方向是否符合题设运动趋势。

高频易错

  • 错误理解矢量夹角：余弦定理中夹角必须取两矢量方向间的夹角。当已知合速度与一分速度夹角 $\alpha$、求另一分速度时，应用 $v_2 = \sqrt{v^2+v_1^2-2vv_1\cos\alpha}$，而非加上余弦项。若误套 $v = \sqrt{v_1^2+v_2^2+2v_1v_2\cos\theta}$ 会导致结果错误。
  • 方向判定混乱：速度合成的方向需结合地理方位和实际运动图像判断。例如同步轨道自西向东，故合速度向东；附加速度方向需按平行四边形补齐后，观察指向东偏南还是西偏北。容易不看图盲目猜方向。
  • 忽略矢量性，直接代数加减：当两个分速度不共线时，不能简单相加或相减，必须按平行四边形定则合成。
  • 余弦定理边长对应错误：在矢量三角形中，务必厘清已知边与所求边的关系，避免用错公式形式（如把 $v_2^2 = v_1^2+v^2-2v_1v\cos\alpha$ 写成 $v^2 = v_1^2+v_2^2-2v_1v_2\cos\alpha$）。
  • 有效数字与数量级疏忽：题给数据常带数量级（如$10^3\,\text{m/s}$），计算时宜先提取数量级，最后恢复，防止漏乘或错位。

代表题精讲

【代表题】2015-新课标Ⅱ-03

题目：卫星从转移轨道飞经赤道上空时，速度为 $v_1 = 1.55 \times 10^3\,\text{m/s}$，此时高度与同步轨道相同，转移轨道与同步轨道夹角为 $30^\circ$。发动机点火给一附加速度 $v_2$，使卫星进入同步轨道，同步轨道环绕速度 $v = 3.1 \times 10^3\,\text{m/s}$。求 $v_2$ 的大小和方向。

思路：本题属于速度的矢量合成。卫星最终沿同步轨道运行，其线速度 $v$ 即为合速度；转移轨道速度 $v_1$ 是一个分速度；发动机提供的附加速度 $v_2$ 是另一个分速度。已知 $v$、$v_1$ 及二者夹角 $30^\circ$，可由平行四边形定则画图，移为三角形后用余弦定理求 $v_2$ 大小；方向结合同步轨道自西向东（向东）及夹角关系判断为东偏南。

步骤： 1. 确定合速度为同步轨道速度 $v = 3.1\times 10^3\,\text{m/s}$，方向向东。 2. 一个分速度 $v_1 = 1.55\times 10^3\,\text{m/s}$，方向与同步轨道夹角 $30^\circ$（由题图知为东偏北 $30^\circ$）。 3. 画矢量三角形：以 $v_1$ 末端连向 $v$ 末端，该有向线段即 $v_2$。由余弦定理： $$v_2 = \sqrt{v^2 + v_1^2 - 2vv_1\cos 30^\circ}$$ 代入： $$v_2 = 10^3 \times \sqrt{3.1^2 + 1.55^2 - 2\times 3.1\times 1.55\times\frac{\sqrt{3}}{2}}$$ 计算 $3.1^2=9.61$，$1.55^2=2.4025$，$2\times 3.1\times 1.55\times 0.866 \approx 8.332$， 则 $v_2 \approx 10^3 \times \sqrt{9.61+2.4025-8.332} = 10^3 \times \sqrt{3.6805} \approx 1.92 \times 10^3 \,\text{m/s}$，取 $1.9 \times 10^3\,\text{m/s}$。 4. 方向：由几何关系，$v_2$ 需填补 $v_1$ 与向东方向的夹角，最终使合速度向东，从图可得 $v_2$ 方向为东偏南。故选项 B 正确。

点评/变式：此题用速度的平行四边形定则替代常见力的合成，本质上仍是矢量运算法则。考生易错点在于余弦定理的符号（减号而非加号）以及东西南北的偏角判断。变式训练：若将转移轨道速度改为与同步轨道垂直（$90^\circ$），则附加速度的大小变为 $\sqrt{v^2 + v_1^2}$，方向可通过 $\tan\theta = \frac{v_1}{v}$ 求出偏角，强化矢量正交分解思想。
