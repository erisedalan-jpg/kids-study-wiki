平衡力

考点平衡力权重6真题数1学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择3
  • 难度分布：易1

知识精要

  • 二力平衡：作用在同一物体上的两个力，大小相等、方向相反、且作用在同一直线上，这两个力就彼此平衡。平衡力作用下的物体处于静止或匀速直线运动状态。
  • 相互作用力（牛顿第三定律）：两个物体之间的作用力与反作用力总是大小相等、方向相反、作用在同一条直线上，但作用在两个不同的物体上。
  • 平衡力与相互作用力的核心区别：平衡力“同体”，相互作用力“异体”。
  • 滑动摩擦力方向：与接触面间相对运动的方向相反。注意“相对”二字——摩擦力的方向不一定与物体的实际运动方向相反。
  • 受力分析要点：选择研究对象（隔离法或整体法），按重力→弹力→摩擦力的顺序画出全部力，利用平衡方程或牛顿第二定律列式。

解题方法与套路

  1. 定对象：明确要分析受力的是哪一个物体（例如砚台）。如果涉及多个物体，通常先从受力简单或已知运动的物体入手。
  2. 判状态：根据题干判断该物体处于静止、匀速还是加速状态。若静止或匀速，则合力为零（平衡状态）。
  3. 找摩擦方向：找出接触面间的相对运动方向或相对运动趋势方向，滑动（或静）摩擦力的方向与之相反。注意区分“相对地面”的运动方向。
  4. 受力分析画图：按顺序画出重力、弹力（支持力、压力）、摩擦力，标在作用点上。
  5. 辨平衡与相互作用：
  6. 一看作用对象：两个力是否作用在同一物体上？是 → 可能为平衡力；否 → 一定是相互作用力。
  7. 二看大小来源：平衡力由运动状态（合力为零）决定大小关系；相互作用力由牛顿第三定律天生等大。
  8. 列式判断：对平衡状态，在水平和竖直方向分别列出合力为零的方程，比较各力大小，检验选项。

高频易错

  • 平衡力与相互作用力混淆：见到等大反向的力就认为是平衡力，忽略“同体”条件。如桌面对砚台的支持力与墨条对砚台的压力虽然都作用在砚台上，但大小不等，故不是平衡力。
  • 摩擦力方向判断想当然：误以为摩擦力方向总与物体的运动方向相反，忽略了“相对运动”这一关键。墨条向左运动，相对砚台向左，故砚台对墨条的摩擦力向右，而非向左。
  • 竖直方向压力与支持力等大误解：在水平面上，支持力未必等于物体的重力，更不等于其上其他物体对它的压力。砚台在竖直方向受重力 $G$、桌面支持力 $F_N$、墨条的压力 $F_{压}$，平衡时 $F_N = G + F_{压}$，显然 $F_N > F_{压}$。
  • 研究对象混乱：将不同物体上的力放在一起当作平衡力。例如把桌面对砚台的摩擦力和墨条对砚台的摩擦力当作相互作用力，实际上它们都作用在砚台上，是平衡力；相互作用力应在砚台与桌面之间、墨条与砚台之间分别成对出现。

代表题精讲

题目
（2024 辽宁）利用砚台将墨条磨成墨汁，墨条速度方向水平向左时，下列说法正确的是：
A. 砚台对墨条的摩擦力方向水平向左
B. 桌面对砚台的摩擦力方向水平向左
C. 桌面和墨条对砚台的摩擦力是一对平衡力
D. 桌面对砚台的支持力与墨条对砚台的压力是一对平衡力

思路
先分析墨条与砚台间的相对运动，得出砚台对墨条的摩擦力方向；再以砚台为研究对象，根据其静止状态进行水平和竖直方向的受力分析，逐一判断各选项的正误。

步骤
1. 墨条水平向左运动，相对于砚台向左运动，故砚台对墨条的滑动摩擦力方向水平向右（与相对运动方向相反）。选项 A 错误。
2. 由牛顿第三定律，墨条对砚台的摩擦力 $f_{条→砚}$ 方向水平向左。砚台处于静止状态，水平方向合力为零，因此桌面必须给砚台一个水平向右的静摩擦力 $f_{桌→砚}$ 来平衡。选项 B 错误。
3. 砚台在水平方向只受 $f_{条→砚}$（向左）和 $f_{桌→砚}$（向右），二力等大、反向、共线且作用在同一物体（砚台）上，是一对平衡力。选项 C 正确。
4. 竖直方向，砚台受重力 $G$、桌面支持力 $F_N$ 和墨条的压力 $F_{压}$。由平衡条件 $F_N = G + F_{压}$，得 $F_N > F_{压}$。虽然二力都作用在砚台上，但大小不相等，不是平衡力。选项 D 错误。

点评/变式
本题以传统文化情境考查“平衡力与相互作用力”的辨析，极易混淆。解题关键：
- 摩擦力方向必须严格根据“相对运动”来判断；
- 平衡力必须满足“等大、反向、共线、同体”，仅同体而大小不等（如 D）也不叫平衡力；
- 变式可拓展为“若墨条加速向左，则砚台水平方向受力是否仍平衡？摩擦力如何变？”，此时需结合牛顿第二定律分析，平衡力概念不再适用，但相互作用力仍然成立。
