弹性碰撞

  • 父主题：动量

  • 出现题位：填空12 解答15

知识精要

  • 弹性碰撞特征：碰撞过程中系统机械能不损失，同时满足动量守恒与动能守恒。恢复系数 $e=1$，分离速度等于接近速度。
  • 核心公式（一维动碰静）：质量 $m_1$ 的球以 $v_0$ 碰静止的 $m_2$，碰后速度 $$v_1' = \frac{m_1-m_2}{m_1+m_2}v_0,\quad v_2' = \frac{2m_1}{m_1+m_2}v_0$$ 等质量时速度交换；$m_1 \ll m_2$ 时 $v_1' \approx -v_0$，$v_2' \approx 0$。
  • 弹性碰撞的等效处理：碰撞时间极短，内力远大于外力（重力、摩擦力等），该过程中外力冲量可忽略，可直接应用动量守恒和动能守恒求碰后速度。
  • 与“板–块”、传送带等综合时，碰后两物体可能具有不同速度，进入摩擦力作用阶段，此时需结合牛顿第二定律 $a = \frac{F_\text{合}}{m}$、运动学公式 $v_t^2-v_0^2=2ax$ 或动能定理、动量定理分段处理，直至共速或再次碰撞。
  • 碰撞后相对滑动的能量关系：摩擦生热 $Q = \mu N \cdot \Delta s$，其中 $\Delta s$ 为相对路程；对系统用能量守恒：初动能 = 末动能 + 摩擦生热。

解题方法与套路

  1. 画过程草图，分阶段：明确碰撞前、碰撞瞬间、碰撞后三个阶段；碰撞瞬间只用动量守恒（和动能守恒）求速度，不计位移。
  2. 碰撞方程的规范书写： 动量守恒 $m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$，动能守恒 $\frac12 m_1v_1^2 + \frac12 m_2v_2^2 = \frac12 m_1v_1'^2 + \frac12 m_2v_2'^2$；或利用恢复系数 $v_1' - v_2' = -(v_1 - v_2)$ 简化计算。

  5. 碰后摩擦力阶段：对两物体分别受力分析→求加速度→画 $v-t$ 草图判断运动过程（何时同速、谁先减速到零）。
  6. 求解目标：用运动学公式求各自位移，用动能定理或能量守恒求相对位移（划痕或板长条件）。
  7. 多次碰撞的临界条件：提取每次碰后初速的规律，寻找共速点；临界条件往往是相对位移恰好等于某个长度，或某物体速度恰为零等。
  8. 叠加法求相对位移：$a_\text{相} = a_1 - a_2$，$v_\text{相初}$ 已知，利用 $v_\text{相末}^2 - v_\text{相初}^2 = 2a_\text{相} x_\text{相}$ 快速得相对位移。

高频易错

  • 碰撞瞬间误加摩擦力或重力冲量。题目若强调“碰撞时间极短”且内力巨大，必须完全忽略其他常力的冲量，只由动量守恒和动能守恒求解碰后速度。
  • 弹性碰撞动能方程漏写 $\frac12$，或混淆弹性与完全非弹性（后者动能损失最大，碰后共速）。
  • 板碰墙后速度反向，但物块速度仍维持原方向，两者初速度方向相反，摩擦力方向常判断错误（摩擦力阻碍相对运动）。
  • 用牛顿定律和运动学公式时，正值方向选取混乱，导致加速度正负号出错；建议统一以某一初速度方向为正。
  • 求相对位移时忘记摩擦生热对应的是相对路程，而非对地位移之差，若全程摩擦力方向不变，相对位移可取绝对值；若有往复，需分段求相对路程。
  • 多过程问题中忽略了“共速后最大静摩擦力能否提供加速度”的判断，直接认为共速后一起匀速，导致后续运动分析错误。
