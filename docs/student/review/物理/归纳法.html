归纳法

考点定位

  • 父主题：物理方法 与 通用
  • 权重 weight：5
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 物理归纳法的核心思想：对多次重复的同类物理过程，从初始条件出发，运用同一物理规律写出前几步方程，观察规律，归纳出第 $n$ 次过程的通项表达式。
  • 适用场景
    • 物体间发生多次碰撞、多次推拉等重复性相互作用。
    • 过程具有明确的递推关系，相邻两次过程仅下标变化，结构相同。
  • 核心工具——动量守恒定律（本类问题主要依托）
    • 条件：系统所受合外力为零（如本题“不计冰面摩擦力”）。
    • 一维表达式：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$（注意规定正方向，速度带符号）。
  • 归纳法建模流程（以推物块问题为例） 设第 $n$ 次推物块前瞬间人的速度为 $v_{n-1}$，推后瞬间人的速度为 $v_n$，物块被推出的速度恒为 $v$（相对挡板或对地）。每次推的过程满足： $$M v_{n-1} + m (\text{本次接住物块时物的速度}) = M v_n - m v$$ 结合“接住物块”至“推出物块”间的运动约束（如本题中物块碰挡板后原速反向），建立 $v_{n-1}$ 与 $v_n$ 的递推关系。
  • 常见通项形式：通过累加或迭代可得 $v_n$ 关于 $n$ 的线性表达式，如 $M v_n = (2n-1)mv$。

解题方法与套路

  1. 明确系统与守恒量
    梳理研究对象（运动员、物块），判断守恒条件（合外力为零），选定正方向（常以人运动方向为正），确保各速度符号统一。
  2. 写出前几步的具体方程
    按事件顺序，依次列出第一次、第二次……的守恒方程，使用具体物理量符号（物体质量 $M, m$，速度 $v, v_1, v_2, \ldots$），避免过早代入数字。
  3. 寻找递推规律
    对比各次方程，找出从第 $n-1$ 次到第 $n$ 次的统一递推形式，将多个方程联立或累加，消去中间量。
  4. 归纳第 $n$ 次的通项公式
    利用累加法或数学归纳法，写出 $v_n$ 与 $n$、已知量的解析关系。
  5. 代入临界条件解不等式
    根据题意（如第 7 次后能追上，第 8 次后追不上），列出关于 $v_n$ 与某一阈值（如 $v$）的不等式，解出待求质量 $M$ 的范围。

高频易错

  • 速度方向与正负号混乱
    人、物块对地速度需依据所设正方向严格标注正负。物块碰挡板后方向反转，方程中 $+mv$ 与 $-mv$ 极易写错，建议画过程草图逐一核对。
  • 递推起点混淆
    初态（人、物均静止）是 $v_0=0$；但第一次推后人的速度是 $v_1$，第一次方程是 $0 = Mv_1 - mv$，并非 $Mv_0+mv$。
  • 接住物块时速度的处理
    运动员接住物块前瞬间，物块速度与人速度方向、大小关系需根据“追上”条件判断，接住过程为完全非弹性碰撞，总动量守恒；而推出为主动分离，方程形式不同，不要整体当成一次碰撞处理。
  • 通项累加时的指标错位
    从 $n=1$ 到 $n=N$ 累加时，务必核实等式数量及左、右两侧的剩余项，避免漏项或多出项。
  • 不等号取等错误
    “大于 5.0 m/s，反弹的物块不能再追上”即 $v_8 \geq v$；第 7 次推后还能追上意味着 $v_7 < v$。取等与否直接影响质量范围的闭、开区间，需逐字推敲题意。

代表题精讲

代表题 2020-新课标Ⅱ-08

题目
运动员（质量 $M$）与物块（质量 $m=4.0\,\text{kg}$）静止在冰面上。运动员将物块以 $v=5.0\,\text{m/s}$ 推向竖直挡板，物块与挡板弹性碰撞后反向，等运动员追上物块再次推出，且每次推出后物块速度大小均为 $5.0\,\text{m/s}$。共推 8 次后，运动员速度 $>5.0\,\text{m/s}$，物块不再能追上。不计摩擦，求 $M$ 的可能值（选项：48、53、58、63 kg）。

思路
每次“推”的过程满足动量守恒；物块碰挡板后速度反向，大小不变，前后两次推之间人追上物块意味着此时人和物块速度相等。从第一次开始，列出动量守恒方程，发现递推规律并累加得到第 $n$ 次推出后人的速度通项 $v_n$，再分别代入 $n=7$（第 7 次推出后还能被追上）和 $n=8$（第 8 次推出后不再被追上）建立不等式，解出 $M$ 的范围。

步骤 1. 设人运动方向为正。推出瞬间物块速度为 $-v$。 2. 第一次推出：$0 = Mv_1 - mv$ → $Mv_1 = mv$。
第二次推出：$Mv_1 + mv = Mv_2 - mv$ → $Mv_2 = Mv_1 + 2mv$。
第三次推出：$Mv_2 + mv = Mv_3 - mv$ → $Mv_3 = Mv_2 + 2mv$。
…… 3. 递推：$Mv_n = Mv_{n-1} + 2mv$。累加得
$$Mv_n = mv + 2mv(n-1) = (2n-1)mv.$$ （按题干解析的常用形式，也可等价写为 $v_n = \frac{(2n-1)mv}{M}$。） 4. 第 7 次推出后，物块还能追上人：$v_7 < v$。
$$\frac{(2\times7-1)mv}{M} < v \quad\Rightarrow\quad \frac{13m}{M} < 1 \quad\Rightarrow\quad M > 13m = 52\,\text{kg}.$$ 5. 第 8 次推出后，物块不再能追上人：$v_8 \geq v$。
$$\frac{(2\times8-1)mv}{M} \geq v \quad\Rightarrow\quad \frac{15m}{M} \geq 1 \quad\Rightarrow\quad M \leq 15m = 60\,\text{kg}.$$ 6. 综上：$52\,\text{kg} < M \leq 60\,\text{kg}$，对应 B、C 选项。

点评 / 变式 - 本题核心是将“多次推”转化为等差数列递推，通过累加规避逐次代换繁琐运算。考查动量守恒与归纳思维。 - 若命题改为“每次推出物块相对运动员的速度大小为 $u$”，则递推关系将涉及转换参考系，需构造关于相对速度的守恒方程，再转化到地面速度进行归纳。这种变式在高考中也有出现，本质方法不变：写出前两项，找公差，得通项，解不等式。
