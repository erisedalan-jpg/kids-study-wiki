形变量

考点形变量权重7真题数1学科物理父主题运动学

考点定位

  • 父主题：运动学
  • 权重 weight：7
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 形变量：物体受力后长度的变化量，即 $x = |l - l_0|$，其中 $l_0$ 为原长，$l$ 为形变后的长度。
  • 胡克定律：在弹性限度内，弹簧的弹力 $F$ 与形变量 $x$ 成正比。
    公式：$F = kx$
    方向：弹力方向与形变方向相反（指向恢复原长的方向）。
  • 适用条件：弹性限度内，轻质弹簧（不计质量），仅考虑一维拉伸或压缩。
  • 关键区分：弹簧长度 ≠ 形变量。压缩时 $x = l_0 - l$；拉伸时 $x = l - l_0$。
  • 由真题提炼：已知两次不同力（压和拉）及对应弹簧长度，可联立方程求劲度系数 $k$ 或原长 $l_0$。

解题方法与套路

  1. 设未知原长：弹簧原长 $l_0$ 是连接不同受力状态的桥梁，必设。
  2. 写形变量表达式：
  3. 压缩：$x_1 = l_0 - l_1$
  4. 拉伸：$x_2 = l_2 - l_0$
    （注意 $l_1$、$l_2$ 是实验测得的长度）
  5. 列胡克定律方程：
    $F_1 = k(l_0 - l_1)$
    $F_2 = k(l_2 - l_0)$
  6. 联立消元：消去 $l_0$（或先求 $l_0$），解得 $k = \frac{F_1 + F_2}{l_2 - l_1}$。
  7. 验证结果：检查量纲，确认 $l_2 > l_1$ 且 $k>0$。

高频易错

  • 将弹簧长度直接当作形变量：不设原长，直接用 $F_1 = k l_1$ 等导致错误。
  • 正负号混乱：弹力公式 $F = kx$ 中 $x$ 为绝对值，但建立方程时常通过几何关系确定 $x$，丢负号或大小关系错位。
  • 混淆弹力与外力：题干给的是施加在弹簧上的外力，平衡时外力大小等于弹力，方向无关，直接用绝对值列式即可。
  • 未注意到“轻质弹簧”：轻质意味着弹簧两端受力相等，可直接用胡克定律，不考虑质量惯性。

代表题精讲

2010-新课标Ⅰ-02

题目
一根轻质弹簧一端固定，用 $F_1$ 的力压弹簧另一端，平衡时长 $l_1$；改用 $F_2$ 的力拉弹簧，平衡时长 $l_2$。在弹性限度内，求弹簧劲度系数。

思路
两次受力下弹簧的长度已知，但原长未知，属于典型的“知力知长求 $k$”模型。通过设原长，分别用压缩和拉伸的形变量表达胡克定律，联立消去原长即得 $k$。

步骤
设原长为 $l_0$。
压缩状态：形变量 $x_1 = l_0 - l_1$，由胡克定律 $F_1 = k (l_0 - l_1)$　　……①
拉伸状态：形变量 $x_2 = l_2 - l_0$，由胡克定律 $F_2 = k (l_2 - l_0)$　　……②
①+②得 $F_1 + F_2 = k (l_2 - l_1)$
解得 $$\displaystyle k = \frac{F_1 + F_2}{l_2 - l_1}$$

点评/变式
- 本题陷阱在于直接用 $l_1$ 或 $l_2$ 当作形变量，错误得到 $k = F_1/l_1$ 或类似结果。必须牢记：弹簧长度本身不是形变量。
- 若题目变为已知 $k$ 和一次受力长度，求原长或另一长度，解法同理，用 $l_0 = \frac{F_1 l_2 + F_2 l_1}{F_1 + F_2}$ 可直接写出。
- 变式：若两次均是拉伸（或均是压缩），则形变量为同向差值，表达式变为 $k = \frac{|F_2 - F_1|}{|l_2 - l_1|}$，需结合物理情景分析。
