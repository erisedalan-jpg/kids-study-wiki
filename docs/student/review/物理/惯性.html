惯性

考点惯性权重5真题数1学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：5
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 惯性：一切物体都有保持原来运动状态不变的性质，称为惯性。它表现为物体抵抗运动状态变化的“顽固性”，是物体的固有属性。
  • 惯性定律（牛顿第一定律）：一切物体在没有受到外力作用时，总保持匀速直线运动状态或静止状态，直到有外力迫使它改变这种状态为止。
  • 惯性的唯一量度：质量。质量越大，惯性越大；与物体是否受力、速度大小、运动方向均无关。
  • 运动状态的改变：速度（大小、方向）发生变化，即存在加速度，本质是力作用的效果。匀速直线运动与静止均是运动状态不变的状态。
  • 适用条件：牛顿第一定律只适用于惯性参考系（相对地面匀速或静止的参考系可近似视为惯性系）。

解题方法与套路

  1. 紧扣定义法：直接判断选项是否与“保持原来运动状态”“抵抗运动状态变化”一致。凡是说“惯性是力”“惯性随速度变化”均错。
  2. 状态判断法：分析物体是否处于平衡态（静止或匀速直线运动）。若速度变化（大小或方向），则运动状态改变，该过程不可能由惯性单独维持。
  3. 题肢排除法：
  4. 选项中包含“没有力，只能静止”“速度大惯性大”“圆周运动体现惯性”等典型错误表述，可直接排除。
  5. 多选题中常设干扰项，将“不受力时的运动”与“日常经验”混淆，需严格按照牛顿第一定律正本清源。
  6. 关键词锁定：“抵抗运动状态变化”“保持原来运动状态”“一切物体”“质量是唯一量度”是惯性的核心表达，见到即锁定正确选项。

高频易错

  • 混淆惯性与力：误以为惯性是一种力，或认为“克服惯性”“惯性作用”。惯性是性质，不是力。
  • 将“不受力”等同于“只能静止”：不受力时物体可能做匀速直线运动，日常经验中物体停下的原因是受到阻力。
  • 误认为曲线（匀速率圆周）运动体现惯性：方向改变即速度改变，运动状态已变，不属于“保持原来运动状态”。
  • 惯性大小与速度挂钩：速度大小不影响惯性，只与质量有关。同样质量，速度大的物体停下来难，是因为速度变化量大，而不是惯性大。
  • 忽视“一切物体”：任何条件下物体都具有惯性，与运动状态无关。

代表题精讲

代表题：2012新课标-01

题目：关于惯性，正确的说法是（多选）
A. 物体抵抗运动状态变化的性质是惯性
B. 没有力作用，物体只能处于静止状态
C. 行星在圆周轨道上保持匀速率运动的性质是惯性
D. 运动物体如果没有受到力的作用，将继续以同一速度沿同一直线运动

思路：运用惯性定义和牛顿第一定律逐项辨析。惯性是抵抗运动状态变化的性质，不受力时物体保持静止或匀速直线运动；圆周运动是变速运动，不属惯性体现。

步骤： 1. A项：“抵抗运动状态变化”正是惯性的核心内涵，正确。 2. B项：根据牛顿第一定律，物体不受力时还可以做匀速直线运动，“只能静止”错误。 3. C项：行星做匀速率圆周运动，速度方向时刻改变，运动状态变化，需要向心力维持，不是惯性；惯性是指保持原来运动状态，方向不变，错误。 4. D项：运动物体不受力时，将保持匀速直线运动，与牛顿第一定律一致，正确。 综上，正确选项为A、D。

点评/变式：此题关联课本对惯性的理解。易错项C将“匀速率”与“匀速直线运动”混淆，务必明确“运动状态”包含速度的方向。变式可考查：同一物体在地球与月球上惯性是否变化（不变，因质量不变），或卡车空载与满载时紧急制动的难易（惯性不同）。
