感应电动势

考点感应电动势权重9真题数1学科物理父主题电磁感应

考点定位

  • 父主题：电磁感应
  • 权重 weight：9
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择9
  • 难度分布：中1

知识精要

  • 感应电动势的产生：只要穿过闭合回路的磁通量发生变化，回路中就有感应电动势。动生电动势的表达式为 $E = BLv_\perp$，其中 $v_\perp$ 为切割磁感线的有效速度分量；也可由法拉第电磁感应定律 $E = n\frac{\Delta \Phi}{\Delta t}$ 计算。
  • 右手定则与楞次定律：判断感应电流方向时，切割型用右手定则（磁场穿手心、拇指指运动方向、四指指电流方向）；磁通量变化型用楞次定律（增反减同）。在双棒、多磁场问题中，要注意各电源的极性及在回路中的串并联关系。
  • 安培力的计算与方向：安培力大小 $F = BIL$，方向由左手定则判断。当磁场方向与导体棒不垂直时，需将安培力沿导轨方向和垂直导轨方向分解，常出现 $\cos\theta$ 或 $\sin\theta$ 因子，切忌想当然。
  • 双棒联动模型：两棒通过导轨和磁场构成闭合回路时，各棒的加速度、速度由受力决定，而受力又随电流变化。稳定状态常对应电流恒定、加速度为零或两棒加速度满足特定比例。列方程的核心是：对每根棒写牛顿第二定律，结合电磁感应与电路方程联立。
  • 等效电路与电动势叠加：若两棒运动产生的电动势在回路中方向相同（同为顺时针或逆时针驱动），则总电动势为两者之和；若方向相反，则为两者之差。电动势的表达式必须体现出切割磁感线的有效速度分量。

解题方法与套路

  1. 判断电流方向：先用右手定则或楞次定律确定每根导体棒产生的感应电流方向，再在回路中叠加，得出总电流的流向，从而判定选项中的电流方向是否正确。
  2. 画截面图作受力分析：将立体图转化为侧视图或截面图。标出重力、支持力、安培力。注意安培力 $F = BIL$ 的方向垂直于 $B$ 和 $I$ 所决定的平面，通常为水平方向；再将其沿斜面方向与垂直斜面方向分解，代入牛顿第二定律。
  3. 列写牛顿第二定律与电路方程：
  4. 对每一棒：$m g \sin\theta - F_A \cos\alpha = m a$（其中 $\alpha$ 为安培力与斜面的夹角，若 $B$ 竖直向上、斜面倾角 $\theta$，则安培力水平，沿斜面分量为 $BIL\cos\theta$）。
  5. 电动势：$E_1 = B_1 L v_1 \sin\phi_1$，$E_2 = B_2 L v_2 \sin\phi_2$（$\phi$ 为速度与磁场的夹角），总电动势 $E_{\text{总}} = E_1 \pm E_2$。
  6. 电流：$I = \frac{E_{\text{总}}}{R_{\text{总}}}$，明确 $R_{\text{总}}$ 为回路总电阻。
  7. 分析运动与稳定条件：从初始时刻开始分析速度、电流、安培力的变化趋势。当加速度趋于零时，速度达到最大且电流稳定；若某一阶段加速度相等，则速度始终相等，进而可比较电动势、电流等。
  8. 求解未知量与验证：利用稳定条件（$a=0$ 或已知比例）联立方程，解出电流、速度或质量比。注意代数化简，保留根号或分数形式。最后将结果逐一代入选项验证。

高频易错

  • 安培力方向及其分量写错：当磁场竖直向上、导轨倾斜时，安培力水平，沿斜面的分量为 $BIL\cos\theta$，而非 $BIL\sin\theta$。许多同学直接在安培力前面乘 $\sin\theta$ 而导致全题错误。
  • 盲目套用“加速度之比等于质量反比”：在双棒问题中，安培力与质量不成简单比例时，加速度之比需由具体方程推导。如本题中两棒加速度相等，而不是 $2:1$ 或 $1:2$。
  • 感应电动势直接写成 $E = BLv$：忽略了磁场与速度方向不垂直的情况。必须写成 $E = BLv\sin\theta$ 或 $E = BLv_\perp$。竖直向上的磁场中，沿斜面下滑的棒，有效切割速度为水平分量 $v\cos\theta$（或写成 $v\sin(90^\circ-\theta)$）。
  • 电动势与电池串并联混淆：未能正确判断两电源在回路中是串联相助还是串联相消。判断标准是回路中两电源驱动的电流方向是否一致，而非简单看速度方向。
  • 电流“趋于”条件理解偏差：“电流趋于某值”对应最终匀速状态（$a=0$），此时由平衡方程求出的电流即为稳定电流。部分考生误用初始状态或中间状态去计算。
  • 误认为感应电动势始终相等：即使两棒速度大小相等，若磁感应强度不同或切割磁感线的有效速度分量不同，电动势也不相等。

代表题精讲

2024-辽宁-09（双棒“∧”形导轨与竖直磁场）

题目：如图，两条“∧”形的光滑平行金属导轨固定在绝缘水平面上，左右两导轨面与水平面夹角均为 $30^\circ$，处于竖直向上的匀强磁场中，磁感应强度大小分别为 $2B$ 和 $B$。将有一定阻值的导体棒 $ab$、$cd$ 放置在导轨上，同时由静止释放，两棒质量分别为 $2m$ 和 $m$，长度均为 $L$。导轨足够长且电阻不计，求两棒下滑过程中正确选项（A. 回路电流方向；B. $ab$ 中电流趋于 $\frac{\sqrt{3}mg}{3BL}$；C. $ab$ 与 $cd$ 加速度大小之比；D. 两棒电动势是否始终相等）。

思路： 1. 先用右手定则判断每根棒产生的电流方向，确定回路总电流方向。 2. 将两棒分别作为研究对象，画侧视图，分析受力：重力垂直于水平面，安培力水平，沿斜面分解。 3. 写出两棒的牛顿第二定律方程，比较加速度关系。 4. 写出总电动势表达式，结合稳定条件（$a=0$）求出电流趋于值。 5. 逐个验证选项。

步骤： 1. 电流方向：磁场竖直向上。$ab$ 沿左斜面下滑，速度方向沿斜面向下（左下），右手定则知感应电流从 $b$ 流向 $a$；$cd$ 沿右斜面下滑（右下），电流从 $c$ 流向 $d$。在回路中，电流流向为 $a \to b \to c \to d \to a$，即 $abcda$，A 正确。 2. 受力与加速度：设回路电流为 $I$，总电阻为 $R$。
$ab$ 棒：$2mg\sin30^\circ - 2BIL\cos30^\circ = 2m a_{ab}$
$cd$ 棒：$mg\sin30^\circ - BIL\cos30^\circ = m a_{cd}$
两式化简得：
$a_{ab} = g\sin30^\circ - \frac{BIL\cos30^\circ}{m}$
$a_{cd} = g\sin30^\circ - \frac{BIL\cos30^\circ}{m}$
故 $a_{ab} = a_{cd}$，加速度大小之比为 $1:1$，C 错误。由于初速度为零且加速度始终相等，两棒速度大小始终相等。 3. 电动势分析：$ab$ 产生的动生电动势 $E_{ab} = 2B L v \cos30^\circ$，$cd$ 的电动势 $E_{cd} = B L v \cos30^\circ$。两棒在回路中电流方向一致，总电动势 $E = E_{ab} + E_{cd} = 3BLv\cos30^\circ$。显然 $E_{ab} \neq E_{cd}$，D 错误。 4. 稳定电流：随着速度增大，电流增大，安培力增大，加速度减小。当两棒匀速时，$a=0$。对 $ab$ 有 $2mg\sin30^\circ = 2BIL\cos30^\circ$，解得 $I = \frac{mg\tan30^\circ}{BL} = \frac{\sqrt{3}mg}{3BL}$。B 正确。

点评/变式：本题综合性强，核心陷阱在于安培力分量的角度判断和加速度关系的推导。许多同学不加推导直接认为质量比决定加速度比，导致误选 C。对于竖直磁场与倾斜导轨的组合，一定要画出截面图，明确空间关系。变式可改为导轨平放在水平面上、磁场倾斜，或者双棒垂直跨接在同一水平导轨上，考查电动势的叠加与抵消。解题逻辑链完全一致：方向→受力→加速度→速度→电动势→电流→稳定条件。
