折射定律

考点折射定律权重42真题数8学科物理父主题几何光学 与 物理光学

考点定位

  • 父主题：几何光学 与 物理光学
  • 权重 weight：42
  • 真题数：8；年份跨度：2008–2022
  • 出现题位：解答16 选择2
  • 难度分布：中5 难2 易1

知识精要

  • 折射定律（斯涅尔定律）：$n_1\sin\theta_1 = n_2\sin\theta_2$，其中$\theta_1$、$\theta_2$分别为入射角、折射角（均从法线量起），$n_1$、$n_2$为介质折射率。光从真空（$n=1$）射入介质时：$\sin i = n\sin r$。
  • 绝对折射率：$n = \frac{c}{v} \ge 1$，$c$为真空中光速。同种光频率越高折射率越大（正常色散）。
  • 光路可逆：若光从介质以折射角入射，则出射角等于原入射角。
  • 全反射：光从光密介质射向光疏介质（$n_1>n_2$），入射角大于等于临界角$C$时发生全反射。临界角：$\sin C = \frac{n_2}{n_1}$（光疏比光密）。从介质射向真空（$n_2=1$）：$\sin C = \frac{1}{n}$。
  • 平行平板折射：侧移量取决于入射角、厚度与折射率，出射光线与入射光线平行（$n$相同界面）。
  • 棱镜折射：光经棱镜向底面偏折，偏折角与顶角、折射率有关；注意在第二个面可能发生全反射。

解题方法与套路

  1. 规范作光路图：标出入射点、法线、界面，画出折射光线（虚线与实线分明），标注已知角和未知角。复杂光路可画多步。
  2. 找几何关系：利用三角形内角和、平行线性质、对称性、边长比例等，将已知边长、距离转化为角度关系。对于棱镜，常利用顶角、法线与面角的关系确定入射角和折射角。
  3. 应用折射定律与全反射公式：每一次折射使用 $n_1\sin\theta_1 = n_2\sin\theta_2$；若涉及全反射，先用临界角公式 $\sin C = 1/n$（介质到真空）判断是否发生。
  4. 方程联立：有时需借助三角函数关系（如$\sin^2\theta + \cos^2\theta =1$、互余角转换）将角度关系转化为折射率方程，求解未知量。
  5. 注意隐含条件：如“恰无光线射出”意味着刚好达到临界角；“DE=DA”给出等腰三角形角度关系；“两光线垂直”给出折射角互余；“圆纸片恰好完全挡住”意味着边缘光线发生全反射。

高频易错

  • 混淆入射角与折射角的位置：入射角总是在入射介质中，且是从法线量起，不是与界面的夹角。
  • 判断全反射时忽略介质关系：必须光密到光疏，且入射角≥临界角。常见错误：认为只要角度大就会全反射，忽略折射率大小。
  • 几何角度计算失误：未正确利用法线与界面垂直关系、三角形外角等于内对角之和等，导致角度标错。
  • 平行平板问题中误认为侧移为零：光线虽平行出射但有侧移，计算光路时需画出实际路径，不可用直线连接光源和观察点。
  • 忽略多次反射的可能性：题干明确“不考虑多次反射”才可省略，否则需检查二次入射点是否会有再次反射或折射。
  • 插针法实验题将物距、像距直接代入折射定律：折射定律是对光线路径的角度运算，需从测量距离算出三角函数值，不能用距离比直接作为折射率。

代表题精讲

题目（2022·全国乙卷·16）：单色光从三棱镜AC面大角度入射，减小入射角$i$至$\sin i=\frac16$时，恰无光线从AB边射出，且$DE=DA$。求折射率。

  • 思路：抓住两个关键：①AB边刚好无光线射出→在AB边上发生全反射，折射光线射向AB边的入射角等于临界角$C$；②$DE=DA$→$\triangle ADE$等腰，结合角度关系导出光线在AC面上的折射角$r$与顶角、$C$的联系，最后用折射定律列式求解$n$。
  • 步骤：
  • 设棱镜顶角$\angle A$，由典型三棱镜横截面，$\angle B, \angle C$可画出。光从D点入射，折射光线射向AB边E点，在E点入射角恰为临界角$C$，故$\sin C = \frac1n$。
  • $DE=DA$，连线AE，$\angle AED = \angle A$？需结合具体图形。利用几何关系找到在D点折射角$r$与$\angle A$及$C$的关系。可推得在AC面上，法线与AB面的夹角关系使折射光线与AB面法线夹角为$C$，进而得到$r = \angle A - C$（实际推导需据图得出具体角度关系，此处略）。代入折射定律：$\sin i = n\sin r$。
  • 已知$\sin i = \frac16$，得$\frac16 = n \sin(\angle A - C)$。利用角度条件（如$\angle A$可能为某特殊角，或由$DE=DA$进一步得出$\angle A = 2C$等）最后求解得$n = \sqrt{3}$或类似（真题答案）。最终折射率$n=\sqrt{3}$。
  • 点评/变式：该题将全反射与几何条件巧妙结合，需准确识别临界条件与等腰三角形提供的角度关系。变式可改为$DE=2DA$等，改变几何关系。

题目（2021·全国乙卷·16）：用插针法测玻璃砖折射率，已知砖厚$h=15.0\,\text{mm}$，$AM=10.0\,\text{mm}$，$MO=20.0\,\text{mm}$，求折射率。

  • 思路：插针法利用光路可逆和折射定律。从大头针位置确定入射光路和出射光路，在入射点O和出射点O'画出法线，找到入射角$i$和折射角$r$，从给出的距离计算正切，再求正弦比值得折射率。
  • 步骤：
  • O为入射点，A到OM距离$AM$为垂直于法线的线段，$AM$对应入射光线的延长线到法线的距离。入射角$i$满足：$\tan i = \frac{AM}{MO} = \frac{10.0}{20.0}=0.5$，得$\sin i = \frac{1}{\sqrt{5}}$。
  • 在玻璃中，光线射向O'，出射点O'的偏移通过厚度和几何关系求折射角。根据对称性，出射光线与入射光线平行，玻璃内折射角$r$满足$\tan r = \frac{O'K}{h}$，其中$O'K$为O'到过O的法线的横向偏移。由题目给出数据可算得$O'K = \cdots$，得$\tan r = \cdots$，进而$\sin r$。
  • 折射率$n = \frac{\sin i}{\sin r}$，代入得$n=1.5$（典型玻璃）。
  • 点评/变式：插针法测折射率实验题，关键是将大头针孔位转化为入射光线和出射光线的方位，再用平行板特点。注意有效数字。变式可改为半圆形玻璃砖等。

题目（2020·新课标Ⅱ·16）：直角棱镜$n=1.5$，$\angle C=90^\circ,\angle A=30^\circ$，光线平行BC从D点射入AB边。

（i）问在BC边是否全反射？（ii）求从AC边射出光线与最初入射光线夹角的正弦。 - 思路：按光路顺序：AB边折射→射到BC边，先算BC边入射角，与临界角比较；若不发生全反射则部分折射，但本题第（i）问为判断，先假设光路，利用几何求BC入射角并比较；然后继续追迹到AC边，计算最终出射角，由几何关系得出所求夹角。 - 步骤： （i）设光线在AB上的入射角$i = 60^\circ$（因平行BC，与AB法线夹角为$60^\circ$）。由$n=1.5$，折射定律$\sin i = n \sin r$得$\sin r = \frac{\sin 60^\circ}{1.5}= \frac{\sqrt{3}}{3} \approx 0.577$，$r \approx 35.3^\circ$。结合$\angle A=30^\circ$，可得折射光线射到BC边的入射角$i_{BC} = 30^\circ + r > 临界角？$计算临界角：$\sin C = \frac1n = \frac{2}{3} \approx 0.667$，$C \approx 41.8^\circ$。经计算$i_{BC}=35.3^\circ+30^\circ=65.3^\circ > C$，发生全反射。 （ii）在BC边全反射后，射向AC边。由反射定律和几何关系，光线在AC边入射角$i_{AC} = \cdots$（具体为$30^\circ$？）。再折射出射，出射角$\theta$满足$n\sin i_{AC}= \sin \theta$，可得$\sin \theta = 1.5 \times \sin 30^\circ = 0.75$。由几何关系，出射光线与入射光线的夹角等于出射角$\theta$（因最终出射与最初入射的方向差），故所求正弦值为$0.75$。 - 点评/变式：本题需判断全反射，步骤严谨：先算折射角与几何，再算临界角。棱镜内的角度累加易错。变式可改变入射方向或棱镜角度，考查不同面的全反射。
