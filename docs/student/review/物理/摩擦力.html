摩擦力

考点摩擦力权重43真题数8学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：43
  • 真题数：8；年份跨度：2012–2024
  • 出现题位：选择2 选择3 选择8 选择10 选择11
  • 难度分布：易1 中5 难2

知识精要

  • 滑动摩擦力
    大小：$f = \mu N$，$\mu$ 为动摩擦因数，$N$ 为接触面正压力。
    方向：与物体相对接触面的运动方向相反，而非对地运动方向。

  • 静摩擦力
    大小：$0 \le f \le f_{\max}$，其中最大静摩擦力 $f_{\max} \approx \mu_s N$（常近似等于滑动摩擦力）。
    方向：与相对运动趋势方向相反，需结合运动状态由平衡或牛顿第二定律反推。
    趋势方向判断：假设接触面光滑，物体将运动的方向即为趋势反方向。

  • 摩擦力突变
    当相对运动状态改变（静止↔滑动、共速瞬间等），摩擦力类型、大小、方向均可发生突变。板块共速后摩擦力突变为零或静摩擦。

  • 平衡与动力学
    静止或匀速直线运动：$F_{\text{合}} = 0$，可用正交分解列平衡方程。
    加速运动：摩擦力参与提供加速度，由 $F_{\text{合}} = ma$ 求解。

  • 牛顿第三定律
    摩擦力成对出现：A 对 B 的摩擦与 B 对 A 的摩擦等大反向，作用在不同物体上，不能抵消。

  • 常见模型
    斜面摩擦自锁、板块相对滑动、拖把（推杆）自锁、弯道摩擦力提供向心力、冰面匀减速。

解题方法与套路

  1. 定对象、判相对
    选取受力研究对象（单个物体、整体），明确接触面，确定相对运动或相对运动趋势方向，据此标出摩擦力方向。

  2. 受力分析作图
    按重力、弹力、摩擦力顺序分析，摩擦力的方向根据相对运动（或趋势）指向，勿漏牛顿第三定律反作用力。

  3. 列方程

  4. 平衡问题：沿摩擦力和垂直方向正交分解，合力为零。
  5. 加速问题：牛顿第二定律 $F_{\text{合}} = ma$，多物体可用整体法求加速度，隔离法求内部摩擦力。

  6. 临界问题：恰好滑动 ⇒ 静摩擦力达到最大静摩擦力 $f_{\max}$，结合 $f_{\max} = \mu_s N$ 或给定条件。

  7. 利用图像信息
    $v\text{-}t$ 图斜率得加速度，转折点对应运动状态改变（如板块相遇、共速）；$F\text{-}t$ 图与运动图像结合推断摩擦类型与质量比。

  8. 多过程分段求解
    遇到板块相对滑动 → 共速 → 可能一起运动的过程，分段画受力图，注意共速时摩擦力的突变判定（假设能一起运动，比较所需加速度与最大静摩擦力能提供的加速度）。

  9. 检验与转化
    摩擦力的方向和大小必须与相对运动一致；所求摩擦因数、质量比、力等要代回验证。

高频易错

  • 方向陷阱：摩擦力方向与物体对地运动方向混淆（如 2024 辽宁 03，墨条向左运动，砚台对其摩擦力向右，而非向左）。
  • 作用力混同：平衡力（同一物体）与相互作用力（不同物体）不分（2024 辽宁 03 D 项）。桌面对砚台的支持力 ≠ 墨条对砚台的压力，前者等于砚台重力加压力。
  • 静摩擦方向漏判：斜面问题中，静摩擦方向可能沿斜面向上或向下，随外力 $F$ 大小改变而发生反转（如 2013 新课标Ⅱ 02，$F$ 最大与最小的临界状况）。
  • 自锁条件模糊：拖把模型中，“不管推力多大都无法推动”的条件是 $\tan\theta_0 = \lambda$（或 $\mu$），而非随便取角度。
  • 板块共速误判：板块速度相同后，若整体无外力或外力不足以提供原静摩擦，可能一起匀速或一起加速；但若最大静摩擦力不足，会再次相对滑动。
  • 弯道临界：低于临界速度 $v_c$ 时，汽车不会立刻向内滑动，而是有静摩擦向外趋势，需达到一定速度差才滑动（2013 新课标Ⅱ 08）。
  • 忽视相对运动：冰球问题中，冰球相对冰面滑动，摩擦因数由运动学求出 $a = \mu g$，但要确保初末速度、位移对应。

代表题精讲

1. (2024 辽宁 03) 砚台磨墨

题目 利用砚台将墨条磨成墨汁，墨条速度方向水平向左，判断砚台对墨条、桌面对砚台的摩擦力、平衡力等。

思路
墨条相对砚台向左运动 → 滑动摩擦力向右。砚台静止 → 水平方向受墨条的摩擦力（向左）和桌面摩擦力（向右）平衡。竖直方向，砚台受重力、墨条压力、桌面支持力，支持力 > 墨条压力。

步骤
1. 墨条运动，相对砚台向左，砚台对墨条的滑动摩擦力 向右（A 错）。
2. 由牛顿第三定律，墨条对砚台摩擦力 向左；砚台静止，水平合力为零，故桌面对砚台摩擦力 向右（B 错）。
3. 砚台水平方向只受两个摩擦力，等大反向，为一对平衡力（C 对）。
4. 竖直方向：$N_{\text{桌→砚}} = G_{\text{砚}} + N_{\text{墨→砚}}$，故 $N_{\text{桌→砚}} > N_{\text{墨→砚}}$，不是一对平衡力（D 错）。

点评/变式
此题考察摩擦力方向判定和平衡力与相互作用力的区分。易错点：把墨条对地运动方向当作相对砚台的方向必错；竖直方向漏掉砚台自身重力。变式：若砚台也在加速，则需引入牛顿第二定律列方程。

2. (2024 辽宁 10) 板块模型 v-t 图

题目 木板在水平恒力下由静止运动，小物块后以与木板等大反向的速度滑上木板，已知 $0\sim 4t_0$ 内木板 v-t 图，求物块滑上的时刻、板-块间动摩擦因数、质量比、末态运动。

思路
v-t 图斜率突变对应物块滑上，改变木板受力。物块滑上后，板受恒力 F、地面摩擦、物块摩擦。通过两段斜率可求两个加速度，结合相对运动推共速时间和摩擦因数。共速后判断能否一起运动。

步骤
1. 判滑上时刻：$0\sim 3t_0$ 斜率恒定，$3t_0$ 时刻斜率突变 ⇒ $t=3t_0$ 物块滑上（A 对）。
2. 求板-块间动摩擦因数 $\mu_0$：
- 由题图，木板 $0\sim 3t_0$ 加速度 $a_1$（仅地面摩擦），可求 $F$ 与地面 $\mu$ 关系。
- 物块滑上时速度大小 $v_0 = \frac{3}{2}\mu g t_0$（向左）。物块加速度 $a_{\text{块}} = \mu_0 g$（向右减速到零再反向）。
- $t_0$ 后（从 $3t_0$ 到 $4t_0$）共速，共速速度 $v_{\text{共}} = \frac{1}{2}\mu g t_0$ 向右。对物块：$v_{\text{共}} = -v_0 + \mu_0 g t_0$ ⇒ 解得 $\mu_0 = 2\mu$（B 对）。
3. 质量比：设木板质量 $M$，物块 $m$。对木板 $3t_0\sim 4t_0$ 用牛顿第二定律，结合斜率变化求出 $a_2$，解出 $M:m$。经计算得 $M:m = 3:1$ 或 $m:M=1:3$（非 3:4，故 C 错）。
4. $4t_0$ 后：共速后，整体水平合力为零（F 与地面摩擦平衡），且板块间无相对趋势，故一起匀速（D 对）。

点评/变式
此题结合图像考查板块的“多重转折”。关键：利用速度时间图像捕捉运动变化点；物块反向运动时注意矢量方向；共速后必须验证摩擦力能否提供共同加速度，防止误判。类似问题可变为已知质量比求力或摩擦因数。
