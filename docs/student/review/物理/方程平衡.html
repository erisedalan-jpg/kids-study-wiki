考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：6
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 核反应方程平衡原则：核反应前后质量数（核子总数）守恒，电荷数（质子数，即原子序数）守恒。书写方程时，箭头左边为反应物，右边为生成物，需使两边总质量数相等、总电荷数相等。
  • 常见粒子符号与参数：
  • $^1_1\text{H}$ 或 $p$：质子，质量数 1，电荷数 +1
  • $^4_2\text{He}$ 或 $\alpha$ 粒子：质量数 4，电荷数 +2
  • $e^+$ 或 $^0_{+1}e$：正电子，质量数 0，电荷数 +1
  • $e^-$ 或 $^0_{-1}e$：电子，质量数 0，电荷数 -1
  • $\nu$ 或 $^0_0\nu$：中微子，质量数 0，电荷数 0
  • 适用条件：所有核反应（聚变、裂变、衰变、人工转变）均严格遵循上述两条守恒定律，与反应机制无关。

解题方法与套路

  1. 标出已知粒子的质量数和电荷数：将题干中已知核素和粒子用 $^A_Z X$ 形式写出，确认每个粒子的 $A$、$Z$。
  2. 列守恒方程：设未知粒子为 $^A_Z Y$，分别列出质量数守恒式与电荷数守恒式。
  3. 求解并核查：解出 $A$、$Z$，再根据原子序数 $Z$ 确定元素符号，同时验证是否为常见粒子（如正电子、中子 $^1_0n$ 等）。
  4. 完整书写反应式：将求解出的粒子代入，使两端总质量数与总电荷数分别相等。

高频易错

  • 正电子与电子混淆：正电子电荷数为 $+1$，电子为 $-1$，两者质量数均为 $0$。衰变或聚变产物中若出现“电子”需警惕符号与电荷符号。
  • 中微子与反中微子标记不清：题干给出的 $\nu$ 或 $\bar\nu$ 必须原样保留，质量数、电荷数皆为 $0$，不会影响配平。
  • 只注意质量数守恒，忽略电荷数守恒：尤其在涉及 $\beta^+$、$\beta^-$ 衰变或正电子释放的反应中，电荷守恒是判据关键。
  • 系数与个数直接乘入：反应式前系数（如 $4\times ^1_1\text{H}$）表示该粒子个数，在守恒计算时应将质量数、电荷数分别乘以个数后再相加。

代表题精讲

代表题 1：2019-新课标Ⅱ-02

题目：太阳内部核反应的主要模式之一是质子﹣质子循环，循环的结果可表示为 $4\ ^1_1\text{H} \rightarrow \alpha + 2\ e^+ + 2\nu$，需确定 $\alpha$ 粒子的具体核素符号（或验证方程平衡）。

思路：由已知反应物和生成物，运用质量数与电荷数守恒，求出 $\alpha$ 粒子的质量数和电荷数，进而识别出是氦核 $^4_2\text{He}$。

步骤： 1. 左侧反应物：4 个质子 $^1_1\text{H}$，总质量数 $A_{\text{左}}=4\times1=4$，总电荷数 $Z_{\text{左}}=4\times1=4$。 2. 右侧已知粒子：2 个正电子 $^0_{+1}e$，总质量数 $0$，总电荷数 $+2$；2 个中微子 $\nu$，总质量数 $0$，总电荷数 $0$。 3. 设未知 $\alpha$ 粒子为 $^A_Z X$，则右侧总质量数 $=A+0+0=A$，总电荷数 $=Z+2+0=Z+2$。 4. 列守恒方程：
$A=4$，
$Z+2=4 \Rightarrow Z=2$。 5. 该粒子为 $^4_2\text{He}$（氦核，即 $\alpha$ 粒子），反应式为 $4\ ^1_1\text{H} \rightarrow ^4_2\text{He} + 2\ ^0_{+1}e + 2\nu$，质量数和电荷数均平衡。

点评/变式：此题表面是核反应流程，实际只考查配平基本功。变式可给出部分产物遮住另一粒子（如中子 $^1_0n$），或用 $\gamma$ 光子（质量数、电荷数均为 $0$）干扰，保持守恒思路即可破解。注意区分正电子与电子，以及中微子符号不影响数字计算。
