知识精要

  • 时间：描述运动过程的长短，是过程量。在运动学中常作为已知量或待求量，与位移、速度、加速度通过运动学公式关联。
  • 反应时间：从感觉信号到动作开始所经历的时间。在起跑问题中，运动员听到枪声到开始起跑的时间间隔，这段时间内运动员静止。
  • 运动分段模型：真实运动常简化为多段直线运动的组合，常见：
  • 先匀加速（$a$ 恒定）后匀速 ($v=v_m$ 不变)；
  • 全程总位移 $s = s_1 + s_2$，运动总时间 $t_{\text{运动}} = t_1 + t_2$，总时间 $T = t_{\text{反应}} + t_{\text{运动}}$。
  • 匀变速直线运动基本公式（以初速 $v_0=0$ 的匀加速为例）： $$v = at,\quad s = \frac{1}{2}at^2,\quad v^2 = 2as,\quad s = \frac{v}{2}t$$
  • 匀速运动：$s = v t$
  • 联立技巧：在分段相等速率问题中，最大速率 $v_m$、加速时间 $t_1$、加速位移 $s_1$ 通过 $v_m = at_1$ 和 $s_1 = \frac{1}{2}at_1^2 = \frac{v_m}{2}t_1$ 关联，常设其中两个未知量列方程组。

解题方法与套路

  1. 画过程草图：标出各段的已知量、未知量，明确起止时刻和时间间隔。特别注意反应时间不计入运动时间。
  2. 拆解已知总时间：总时间 $T$ 包含反应时间 $t_{\text{反}}$ 和运动时间 $t_{\text{运}}$，其中运动时间常分为匀加速时间 $t_1$ 和匀速时间 $t_2$： $$t_{\text{运}} = T - t_{\text{反}} = t_1 + t_2$$
  3. 分段列位移方程：
  4. 匀加速段：$s_1 = \frac{v_m}{2} t_1$（或 $\frac{1}{2}at_1^2$，$v_m=at_1$）
  5. 匀速段：$s_2 = v_m t_2$
  6. 总位移：$s = s_1 + s_2$
  7. 消元求解未知量：将 $t_2$ 用 $t_{\text{运}} - t_1$ 替换，联立位移关系得到关于 $v_m$ 和 $t_1$（或 $a$）的方程。若已知总位移和总运动时间，常可解出 $v_m$ 和 $a$。
  8. 验证合理性：检查所求物理量是否符合实际（如加速度是否合理，匀速段速度是否小于瞬时极限等）。

高频易错

  • 忽略反应时间：直接用发令到撞线的总成绩作为运动时间列方程，导致加速时间和加速度计算错误。必须从总时间中扣除反应时间。
  • 位移与时间平均分段的误用：不能用总位移除以总时间求平均速度，然后直接认为等于最大速度的一半之类，除非运动是匀加速后匀速且给出特定比例，必须严格按分段位移和。
  • 符号混淆：$t_1$ 是加速时间，$t_2$ 是匀速时间，$t_{\text{运}}$ 是运动总时间，$T$ 是包含反应时间的全程耗时，列方程时容易代人错误。
  • 误用公式：匀加速段从静止开始，位移公式 $s = \frac{v_m}{2}t_1$ 只有在初速为零时成立，若起跑不是从静止启动则需注意初速；同样 $v_m = at_1$ 需确认初速为零。
  • 计算单位：时间常用秒（s），位移用米（m），速度用米/秒（m/s），加速度用 m/s²，国际单位制无须换算，但若题目给的是 km、km/h 等注意统一。

代表题精讲

题目

2010 年 11 题（新课标Ⅰ）
短跑名将博尔特在北京奥运会 100 m 比赛中，成绩为 9.69 s。假定他从发令到起跑的反应时间为 0.15 s，起跑后做匀加速运动，达到最大速率后做匀速运动。求：
(1) 博尔特在比赛中的最大速率 $v_m$ 和加速度 $a$；
(2) 在 200 m 比赛中，他的反应时间和起跑后的加速阶段与 100 m 比赛相同，但因弯道和体力影响，最大速率只达到 100 m 比赛时的 96%，求他 200 m 比赛的成绩（保留两位小数）。

思路

100 m 问题：总时间 $T=9.69\,\text{s}$，反应时间 $t_{\text{反}}=0.15\,\text{s}$，运动时间 $t_{\text{运}}=T-t_{\text{反}}$。设加速时间 $t_1$，匀速时间 $t_2$，最大速率 $v_m$，加速度 $a$。由匀加速位移公式和匀速位移公式，结合总位移 100 m，可列含 $v_m,t_1$ 的方程组。再由 $v_m=at_1$ 求 $a$。
200 m 问题：总位移 200 m，反应和加速阶段参数与 100 m 相同（即 $t_1,a$ 不变），$v_m' = 0.96 v_m$。运动时间 $t_{\text{运}}' = t_1 + t_2'$（匀速时间不同）。根据总位移列式求 $t_2'$，进而得总时间 $T' = t_{\text{反}} + t_{\text{运}}'$。

步骤

(1) 求最大速率和加速度
设加速时间为 $t_1$，匀速时间为 $t_2$，最大速率为 $v_m$。
运动时间：$t_{\text{运}} = 9.69 - 0.15 = 9.54 \,\text{s} = t_1 + t_2$。
匀加速位移：$s_1 = \frac{v_m}{2}t_1$；匀速位移：$s_2 = v_m t_2$。
总位移：$s = s_1 + s_2 = \frac{v_m}{2}t_1 + v_m t_2 = 100$。
代入 $t_2 = 9.54 - t_1$：
$$\frac{v_m}{2}t_1 + v_m(9.54 - t_1) = 100 \Rightarrow v_m\left(9.54 - \frac{t_1}{2}\right)=100 \quad\text{(1)}$$ 又加速阶段满足 $v_m = a t_1$，但方程(1)有两个未知量，需补充关系。注意条件不足？题目没有单独给出加速阶段位移或时间，但隐含了加速到最大速率后立即匀速，没有中间阶段。实际上方程(1)已经包含了所有条件。一个方程两个未知数，通常还需要平均速度的另一关系或利用 $v_m$ 与 $t_1$ 的合理性范围。实际上从物理过程看，$v_m$ 和 $t_1$ 必须满足从静止开始加速，位移 100 m 在总运动时间 9.54 s 内完成，这给定了唯一解。可将 $v_m$ 用 $a$ 和 $t_1$ 表示，但增加了一个未知数 $a$，仍然无法封闭。检查原题数据：博尔特100m世界纪录9.69秒，平均速度约10.32m/s，最大速率约12m/s左右，应该有确定解。仔细思考：运动时间9.54s，则平均速度 $\bar{v} = 100/9.54 \approx 10.48\,\text{m/s}$。对于匀加速+匀速模型，平均速度 $\bar{v} = \frac{s}{t_{\text{运}}} = \frac{\frac{v_m}{2}t_1 + v_m(t_{\text{运}}-t_1)}{t_{\text{运}}} = v_m\left(1 - \frac{t_1}{2t_{\text{运}}}\right)$。由此可得 $v_m$ 和 $t_1$ 的关系，但仍存在多解可能？实际上在相同平均速度下，$v_m$ 和 $t_1$ 是一一对应的，但必须结合 $v_m$ 为正且 $0<t_1<t_{\text{运}}$。然而无法唯一确定。是否还需利用200米的条件？但100米应该可以单独求解。仔细审原题，可能隐含加速阶段达到最大速率时所跑的距离与总距离的比例信息？题干未提供。回忆原高考题：第一问题干未给出额外条件，但可以通过对200米的分析反推？不可能。我记错了，原题100米第一问是可以直接解得唯一解的。因为从文字“起跑后做匀加速运动，达到最大速率后做匀速运动。”并没有给出加速阶段距离或时间，仅凭总位移和总运动时间，确实不能确定两个未知数。这怎么可能？除非我们还知道在100m比赛中博尔特的最大速率是有限的，但依然有无穷多组解。经过仔细回忆，原题可能给定了博尔特在100米比赛中的起跑加速阶段跑了多远？没有。查阅记忆，更准确的原题为：“短跑名将博尔特在北京奥运会上创造了100m和200m短跑项目的新世界纪录，他的成绩分别是9.69s和19.30s。假定他在100m比赛时从发令到起跑的反应时间是0.15s，起跑后做匀加速运动，达到最大速率后做匀速运动。200m比赛时，反应时间及起跑后加速阶段的加速度和加速时间与100m比赛时相同，但由于弯道和体力等因素的影响，以后的平均速率只有跑100m时最大速率的96%。求：(1)加速所用时间和达到的最大速率；(2)起跑后做匀加速运动的加速度。”这就有方向了：原题第一问是求加速时间和最大速率，但没有给200米的第一问数据，所以必须结合100米和200米两个条件联立求解加速时间和最大速率！对，第一问需要用两个比赛的总成绩和位移数据才能解出加速阶段参数。因为仅凭100米一个方程 $v_m(9.54 - t_1/2) = 100$ 无法同时解出 $v_m$ 和 $t_1$。因此第一问实际上是“求加速所用时间和达到的最大速率”，需要我们联立两个比赛的方程。

所以，题干应该是：博尔特在北京奥运会上创造了100 m和200 m短跑项目的新世界纪录，成绩分别是9.69 s和19.30 s。假定他在100 m比赛时从发令到起跑的反应时间是0.15 s，起跑后做匀加速运动，达到最大速率后做匀速运动。200 m比赛时，反应时间及起跑后加速阶段的加速度和加速时间与100 m比赛时相同，但由于弯道和体力等因素的影响，以后匀速阶段的最大速率只有跑100 m时最大速率的96%。求： (1) 加速所用时间和达到的最大速率； (2) 起跑后做匀加速运动的加速度。

这就是正确的题目。

步骤 (修正后)

(1) 对100 m过程：运动时间 $t_{\text{运1}} = 9.69 - 0.15 = 9.54 \,\text{s}$。
设加速时间为 $t_1$（待求），最大速率 $v_m$。加速段位移 $s_{11} = \frac{v_m}{2}t_1$，匀速段位移 $s_{12} = v_m(9.54 - t_1)$。
总位移：$\frac{v_m}{2}t_1 + v_m(9.54 - t_1) = 100$，即 $v_m\left(9.54 - \frac{t_1}{2}\right) = 100 \quad\text{(1)}$
对200 m过程：运动时间 $t_{\text{运2}} = 19.30 - 0.15 = 19.15 \,\text{s}$。加速时间仍为 $t_1$，加速段位移 $s_{21} = \frac{0.96v_m}{2}t_1$？注意：加速阶段加速度相同，所以达到的最大速率应为 $v_m' = a t_1$，由于 $a$ 相同、$t_1$ 相同，则 $v_m' = v_m$？但题目说“匀速阶段的最大速率只有100 m时最大速率的96%”，这暗示200米的加速阶段加速度和加速时间相同，所以加速结束时的速率应该还是 $v_m$，但随后因为弯道体力，最大速率只达到96%$v_m$ 并匀速；还是说200米的加速过程由于弯道体力，所能达到的最大速率就是96%$v_m$？仔细读：“……起跑后加速阶段的加速度和加速时间与100m比赛时相同，但由于弯道和体力等因素的影响，以后的平均速率只有跑100m时最大速率的96%。” “以后的平均速率”应指匀速阶段的速率，即最大速率是96%$v_m$。所以加速阶段加速度和加速时间相同，则加速结束时速率为 $v_m$？不，如果加速度和加速时间相同，末速率应变，那么加速结束的速率就是 $v_m$，但后面说最大速率只有96%$v_m$，意味着加速到 $v_m$ 后，可能无法维持，会降为96%$v_m$ 匀速？这样过程复杂化了。通常的模型是：200米的加速阶段参数相同（a, t1），所以加速结束达到的速率也是vm，但随后由于弯道，只能以0.96vm匀速跑完剩余距离。这样加速段位移计算不变，仍用vm？但这样加速段位移将大于实际值。这样合理吗？如果是原题，说法是：“以后的平均速率只有跑100m时最大速率的96%”，意思是匀速阶段的速率（即最大速率）为0.96vm。那么加速段的末速率仍为vm，与匀速段不同？不合理。实际上原高考题是这样表述的：“200m比赛时，反应时间及起跑后加速阶段的加速度和加速时间与100m比赛时相同，但由于弯道和体力等因素的影响，以后的平均速率只有跑100m时最大速率的96%。”这里的“以后的平均速率”其实是指匀速阶段的速度。但加速阶段如果相同，则末速率为vm，这之后就立即进入“以后”的匀速阶段，那匀速速率就是vm，并非96%
