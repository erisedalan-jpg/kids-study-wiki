正弦交流电有效值

考点定位

  • 父主题：交流电 与 变压器
  • 权重 weight：0
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 正弦交流电的有效值：让交流电和直流电通过相同阻值的电阻，在相同时间内产生的热量相等，则直流电的数值称为交流电的有效值。正弦式电流的有效值 $I = \frac{I_m}{\sqrt{2}}$，$U = \frac{U_m}{\sqrt{2}}$（仅适用于完整正弦波）。
  • 理想变压器：
  • 电压比：$\frac{U_1}{U_2} = \frac{n_1}{n_2}$（一个副线圈）。
  • 功率关系：$P_{\text{入}} = P_{\text{出}}$，即 $U_1 I_1 = U_2 I_2$。
  • 电流比：$\frac{I_1}{I_2} = \frac{n_2}{n_1}$（仅对完整正弦交流电，且副线圈为纯电阻电路无二极管时直接成立）。
  • 二极管半波整流对有效值的影响：
  • 理想二极管正向导通、反向截止，使副线圈输出变为半波正弦脉冲。
  • 半波整流后负载 $R$ 上的电压有效值 $U_{\text{负载}}$ 与副线圈两端正弦电压有效值 $U_2$ 的关系：根据焦耳热等效，半波整流后 $U_{\text{负载}} = \frac{U_2}{\sqrt{2}}$。
  • 变压器原线圈电流反映的是功率：$I_1 U_1 = \frac{U_{\text{负载}}^2}{R}$。
  • 交流电压表测量的是有效值（若无特殊说明）。

解题方法与套路

  1. 处理含二极管的交流电路：先明确二极管的作用——半波整流。副线圈电压 $u_2$ 为正弦波，经二极管后负载 $R$ 上只获得正半周（或负半周）电压。
  2. 计算功率用有效值：负载电阻 $R$ 的发热功率 $P = \frac{U_{\text{cd}}^2}{R}$，这里 $U_{\text{cd}}$ 是 $R$ 两端电压的有效值（即题目中电压表读数）。
  3. 建立变压器两端功率关系：$U_{ab} I_1 = P = \frac{U_{\text{cd}}^2}{R}$（忽略二极管损耗）。
  4. 分析电压关系注意波形差异：
  5. $U_{ab}$ 是原线圈完整正弦波有效值。
  6. 副线圈 $c、d$ 间的电压 $U_{cd}$ 是半波整流后的有效值，而副线圈两端（二极管前）的电压有效值 $U_2 = \frac{n_2}{n_1}U_{ab}$，但 $U_{cd} \neq U_2$，满足 $U_{cd} = \frac{U_2}{\sqrt{2}}$。
  7. 动态变化分析：$R$ 增大 → $P = \frac{U_{cd}^2}{R}$ 减小（$U_{cd}$ 不受 $R$ 影响，因为二极管整流后电压有效值由 $U_2$ 决定），原线圈电流 $I_1 = \frac{P}{U_{ab}}$ 减小。
  8. 二极管短路情况：短路后 $R$ 获得完整正弦波，电压有效值变为 $U_2$，功率加倍，因此原线圈电流也加倍。

高频易错

  • 误将电压比直接用于含有二极管的电路：$\frac{U_{ab}}{U_{cd}} = \frac{n_1}{n_2}$ 是错误的，因为 $U_{cd}$ 是半波电压有效值，不等于副线圈的完整正弦有效值 $U_2$。
  • 混淆有效值与最大值关系：半波整流后，电压有效值不是原来的一半，而是 $\frac{1}{\sqrt{2}}$ 倍，因为功率与电压平方成正比，半波功率是一半，故电压有效值为原来的 $\frac{1}{\sqrt{2}}$。
  • 错误认为负载变化会影响 $U_{cd}$：在理想变压器且二极管参数固定下，$U_{cd}$ 由原线圈电压和匝数比决定，与 $R$ 无关。$R$ 改变仅影响电流和功率。
  • 二极管短路后电流加倍的理解：短路使功率加倍，而非电压加倍导致电流翻倍。注意电流读数 $I_1 = \frac{P}{U_{ab}}$，功率 $P = \frac{U_{\text{负载}}^2}{R}$，从半波到全波，$U_{\text{负载}}$ 从 $\frac{U_2}{\sqrt{2}}$ 变为 $U_2$，功率变为 2 倍，故 $I_1$ 加倍。

代表题精讲

题目

（2014·新课标Ⅱ·08）一理想变压器原、副线圈匝数 $n_1$、$n_2$，原线圈接正弦交流电源，一个二极管和电阻 $R$ 串联接入副线圈。交流电压表测 $a、b$ 端和 $c、d$ 端电压分别为 $U_{ab}$ 和 $U_{cd}$。判断四个选项。

思路

无二极管时，标准变压器关系成立。加入二极管后，$R$ 获得半波正弦电压，其有效值不等于副线圈全波有效值。先根据焦耳热得出 $U_{cd}$ 与副线圈电压 $U_2$ 的关系，再利用理想变压器两端功率相等分析 $U_{ab}$、$I_1$ 等物理量的变化。

步骤

  1. 设无二极管时副线圈两端（二极管前）电压有效值为 $U_2$，则 $\frac{U_{ab}}{U_2} = \frac{n_1}{n_2}$。
  2. 经半波整流后，$R$ 上电压有效值 $U_{cd}$ 满足：一周期内仅半周通电，发热量是完整正弦波的一半，即 $\frac{U_{cd}^2}{R} = \frac{1}{2} \cdot \frac{U_2^2}{R}$，得 $U_{cd} = \frac{U_2}{\sqrt{2}}$。
  3. 因此 $\frac{U_{ab}}{U_{cd}} = \frac{U_{ab}}{U_2/\sqrt{2}} = \sqrt{2}\frac{n_1}{n_2}$，故选项 A 错误。
  4. $U_{cd}$ 仅由 $U_{ab}$ 和匝数比决定，与 $R$ 无关，选项 C 错误。
  5. 增大 $R$，负载功率 $P = \frac{U_{cd}^2}{R}$ 减小，理想变压器输入功率等于输出功率，电流表读数 $I_1 = \frac{P}{U_{ab}}$ 变小，选项 B 正确。
  6. 将二极管短路，$R$ 获得完整正弦波电压 $U_2$，电压有效值变为 $U_2 = \sqrt{2}U_{cd}$，功率 $P' = \frac{U_2^2}{R} = 2 \cdot \frac{U_{cd}^2}{R} = 2P$，故原线圈电流加倍，选项 D 正确。

点评/变式

本题核心在于理解非完整正弦波有效值的计算，以及理想变压器必须基于功率（而非简单电压比）处理含整流元件的电路。
变式思考：若在副线圈回路中串联一个电阻再与二极管、$R$ 并联，或者将二极管与 $R$ 并联，其有效值关系如何变化？解题关键仍是画出等效电路，分段分析通电时间，利用等效发热计算有效值，并结合变压器功率关系求解。
