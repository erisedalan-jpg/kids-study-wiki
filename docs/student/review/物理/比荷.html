比荷

考点比荷权重12真题数2学科物理父主题磁场 与 安培力洛伦兹力

考点定位

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：12
  • 真题数：2；年份跨度：2016–2021
  • 出现题位：选择5 选择7
  • 难度分布：中2

知识精要

  • 比荷（荷质比）：带电粒子的电荷量 $q$ 与质量 $m$ 的比值 $\dfrac{q}{m}$，单位为 $\text{C/kg}$。
  • 电场中的比荷效应：不计重力时，带电粒子在匀强电场中的加速度
    $$a = \frac{qE}{m}$$ 比荷决定相同电场下的加速度大小。电荷的正负决定加速度方向与电场方向相同或相反。类平抛运动中，偏转距离 $y = \frac12 \frac{qE}{m} t^2$，比荷绝对值越大，相同时间内偏转越大；比荷相同的粒子在相同入射速度下轨迹完全相同。
  • 磁场中的比荷效应：不计重力时，带电粒子垂直进入匀强磁场，洛伦兹力提供向心力
    $$qvB = m\frac{v^2}{r} \quad\Rightarrow\quad r = \frac{mv}{qB},\quad T = \frac{2\pi m}{qB}$$ 轨道半径与比荷成反比，周期与比荷成反比。运动时间
    $$t = \frac{\theta}{2\pi}T = \frac{\theta m}{qB}$$ （$\theta$ 为轨迹圆弧对应的圆心角，单位 rad）。
  • 适用条件：粒子速度与磁场垂直；匀强电场/磁场；忽略重力。

解题方法与套路

  1. 电场中粒子轨迹比较
  2. 写出加速度 $a_y = \frac{qE}{m}$，明确正负表示偏转方向。
  3. 水平匀速 $x = v_0 t$，各粒子 $v_0$ 相同，水平位移相同时时间 $t$ 相同。
  4. 比较 $|a_y|$，即比较比荷绝对值 $|q/m|$，判断偏转大小顺序。比荷相同的正粒子轨迹重合，负粒子偏转方向相反但形状对称。
  5. 结合选项图像，排除方向错误、弯曲程度不对的选项。
  6. 磁场中粒子与转动圆筒的时空关联
  7. 画平面图，标注直径 $MN$，入射方向与 $MN$ 的夹角，利用几何关系确定轨迹圆的圆心角 $\theta$（常用对称或弦切角关系）。
  8. 根据 $t = \frac{\theta m}{qB}$ 写出粒子运动时间；根据圆筒转过的角度写出时间 $t = \frac{\Delta\alpha}{\omega}$（注意角度统一用弧度）。
  9. 令两时间相等，解出比荷 $\frac{q}{m}$ 的表达式。
  10. 若有多解，需判断几何可能性（是否碰撞筒壁、角度范围）。
  11. 统一思路：将比荷作为联系运动学（或动力学）与电磁场力的核心参量，通过加速度或轨道半径、周期建立方程。

高频易错

  • 比荷与“荷质比”混淆：题目问“比荷”通常指电荷量比质量 $q/m$，注意不要误写为 $m/q$。
  • 正负号处理：电场中加速度方向由 $q$ 的正负和电场方向共同决定，忽略电荷正负会导致偏转方向反向。比较偏转大小时应取比荷的绝对值。
  • 磁场中周期公式记错：$T = \frac{2\pi m}{qB}$，与速度无关，但易误写成 $T=\frac{2\pi v}{qB}$ 或 $T=\frac{2\pi r}{v}$ 时忘记半径也含比荷。
  • 几何角度判断失误：磁场中粒子初末位置已知，但圆心角不一定是明显的角度，需利用弦、半径垂直关系仔细推导，常见漏解（如互补角）。
  • 时间等时性遗漏：圆筒转动问题时，粒子运动时间等于筒转过已知角度的时间，容易忘记二者同时开始同时结束这一隐含条件。

代表题精讲

代表题1（2021-全国乙-07）

题目：四个粒子 $(+q, m)$、$(+q, 2m)$ 的比荷为 $+q/m$ 和 $+q/(2m)=+0.5q/m$？待仔细看题干：$(+q, m)$，$(+2q, m)$？原题给出：“( )q m+，、( 2 )q m+，、( 3 3 )q m+，、( )q m-”，解析为$(+q, m)$，$(+2q, m)$，$(+3q, 3m)$，$(-q, m)$。比荷对应 $+q/m$，$+2q/m$，$+q/m$，$-q/m$。以相同速度射入匀强电场，电场平行y轴。判断轨迹可能正确的图像。（原题选项为图像，AD正确）

思路：四个粒子水平匀速，竖直方向匀加速，加速度大小由 $\frac{|q|E}{m}$ 决定，方向由电荷正负决定。比较比荷绝对值：粒子1、3、4的绝对值均为 $q/m$，粒子2为 $2q/m$。因此粒子1和3轨迹重合向上偏（设电场沿+y），粒子4向下偏且弯曲程度与1、3相同；粒子2向上偏且偏转量约为1、3的两倍。观察选项，应有一组重合的正偏曲线、一正偏更弯的曲线、一负偏与正偏对称的曲线。

步骤： 1. 水平方向 $x=v_0 t$，各粒 $v_0$ 同，相同 $x$ 时 $t$ 同。 2. 竖直加速度 $a = \frac{qE}{m}$。令比荷单位 $k=q/m$，则加速度：$a_1 = +kE$，$a_2 = +2kE$，$a_3 = +kE$，$a_4 = -kE$。 3. 偏转距离 $y=\frac12 a t^2$，故在相同 $t$ 下，$y_1=y_3$，$y_2=2y_1$，$y_4=-y_1$。 4. 轨迹应为抛物线，粒子1、3重合且向上弯，粒子2向上弯曲程度更大，粒子4向下弯曲且与1对称。符合该特征的为AD。

点评/变式：关键抓住“比荷绝对值相同则运动轨迹形状相同，正负决定偏转侧”。若电场方向未定，可假设方向不影响相对关系。变式：若粒子速度不同，则比较时要同时考虑加速度和时间，难度升级。

代表题2（2016-新课标Ⅱ-05）

题目：一圆筒处于磁感应强度 $B$ 的匀强磁场中，磁场平行筒轴。筒横截面如图，直径 $MN$ 两端有小孔。粒子从 $M$ 射入，速度方向与 $MN$ 成 $30^\circ$。筒以角速度 $\omega$ 顺时针绕过圆心的轴转动，当筒转过 $90^\circ$ 时，粒子恰好从 $N$ 飞出，不计重力，未与筒壁碰撞。求粒子比荷。

思路：粒子在筒内做匀速圆周运动，与筒壁无碰，必从 $M$ 到 $N$ 沿某段圆弧运动。利用入射方向与 $MN$ 成 $30^\circ$，作出圆心，确定轨迹对应圆心角。轨迹运动时间 $t = \frac{\theta m}{qB}$，同时圆筒转过 $\pi/2$，$t = \frac{\pi/2}{\omega}$，联立可解比荷。

步骤： 1. 画图：$MN$ 为直径。粒子从 $M$ 以与 $MN$ 成 $30^\circ$ 角射入。粒子速度与弦 $MN$ 的夹角为 $30^\circ$，由几何，轨迹圆的半径 $R$ 与弦 $MN$ 的夹角关系，可得两种情况：粒子可能沿优弧或劣弧从 $M$ 到 $N$。 2. 情况一（劣弧）：弦切角 $30^\circ$，圆心角 $\theta = 2 \times 30^\circ = 60^\circ = \frac{\pi}{3}$。 3. 情况二（优弧）：对应圆心角 $\theta' = 360^\circ - 60^\circ = 300^\circ = \frac{5\pi}{3}$。 4. 时间关系：$t = \frac{\theta m}{qB} = \frac{\pi/2}{\omega}$。 5. 代入 $\theta = \frac{\pi}{3}$ 得 $\frac{q}{m} = \frac{2\omega}{3B}$？重新计算：$\frac{\pi/3 \cdot m}{qB} = \frac{\pi}{2\omega} \Rightarrow \frac{q}{m} = \frac{2\omega}{3B}$。但题目选项通常为 $\frac{\omega}{B}$ 等，需核查。实际上常用解法：粒子圆轨迹周长比为 $\theta/360^\circ$，时间相等。正确结果应为 $\frac{q}{m} = \frac{\omega}{B}$ 和 $\frac{q}{m} = \frac{5\omega}{B}$？按选项，常见正确选项为 A：$\frac{\omega}{B}$。此处可能我几何简化有误，真实圆心角推导：速度与半径垂直，连接圆心与M、N，由几何可解出弦MN对应圆心角为60°时，半径R与圆筒半径r的关系，但粒子不进筒壁碰撞，轨迹圆弧的弦MN长度等于直径？不，M、N在筒壁上，轨迹圆弧的弦就是筒的直径。若轨迹半径大于筒半径，则圆心在筒外。需结合选项：根据标准答案，比荷为 $\frac{\omega}{B}$。但讲解中正确步骤为：入射速度与MN成30°，所以轨迹圆的弦MN对应的圆心角为60°或300°，因为弦切角等于圆心角的一半。但注意：弦切角是速度方向（切线）与弦的夹角，这里轨迹圆在M点的速度方向已知，MN是轨迹圆的弦，故弦切角=30°，故圆心角=60° 或 300°。时间 $t = \frac{\theta m}{qB}$，筒转过 $\pi/2$ 时间 $t=\frac{\pi}{2\omega}$。联立得 $\frac{q}{m} = \frac{2\theta \omega}{\pi B}$？不对，是 $\frac{\theta m}{qB} = \frac{\pi}{2\omega} \Rightarrow \frac{q}{m} = \frac{2\theta \omega}{\pi B}$。若 $\theta=\frac{\pi}{3}$，则 $\frac{q}{m} = \frac{2\omega}{3B}$，不美。实际题目中，磁场圆筒模型通常粒子射入射出时，运动轨迹的圆心角不仅由弦切角决定，还跟筒的半径有关。这里粒子在筒内且不与筒壁碰撞，说明轨迹半径不能大于筒半径。需重新审视：典型高考题（2016全国2）答案为 $\frac{\omega}{B}$。但几何关系更细致：M、N为直径两端，轨迹圆经过M、N，弦MN为轨迹圆的弦。速度方向与MN成30°，由圆性质，$\angle O'MN$（$O'$为轨迹圆心）满足 $90° -
