气体做功

考点气体做功权重6真题数1学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：6
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：填空13
  • 难度分布：中1

知识精要

  • 理想气体状态方程：$pV = nRT$（或 $pV = CT$，$C$ 为常数）。在 $T$-$V$ 图（或 $p$-$V$ 图、$p$-$T$ 图）中，一个点代表一个平衡态，一条线段代表一个准静态过程。
  • 气体做功：系统对外界做功 $W_{\text{外}} = \int p \, dV$（准静态过程）。
  • $V$ 增大（膨胀）：气体对外做正功（$W_{\text{外}}>0$），系统内能可能减少。
  • $V$ 减小（压缩）：气体对外做负功（外界对气体做正功，$W_{\text{外}}<0$）。
  • $V$ 不变（等容过程）：$W_{\text{外}}=0$。
  • 热力学第一定律：$\Delta U = W + Q$（外界对系统做功 $W$ 与系统吸热 $Q$ 之和等于内能增量）。常见约定：气体对外做功记为 $W'=-W$，则 $\Delta U = -W' + Q$，即 $Q = \Delta U + W'$。
  • 理想气体内能只与温度有关：$\Delta U = n C_V \Delta T$（$C_V$ 为定容摩尔热容）。$T$ 升高则 $\Delta U > 0$，反之 $\Delta U < 0$。
  • $T$-$V$ 图中的关键线：
  • 过原点的倾斜直线：由 $T \propto V$ 及 $pV = nRT$ 得 $p = \text{常数}$，即 等压过程。
  • 平行于 $V$ 轴的直线：等容过程（$V$ 不変）。
  • 平行于 $T$ 轴的直线：等温过程（$T$ 不变）。

解题方法与套路

对于 $T$-$V$、$p$-$V$、$p$-$T$ 图像与热力学第一定律的综合题，通用解法如下：

  1. 识图定过程：根据图像中线段的变化，判断是等压、等容、等温还是绝热等特殊过程，必要时利用状态方程换算出 $p$-$V$ 关系。
  2. 判做功：由体积变化直接判断气体对外做功的正负。体积增大 → 对外做正功；体积减小 → 对外做负功；体积不变 → 不做功。
  3. 判内能变化：理想气体内能仅由温度决定。从图中读出 $T$ 的变化方向，$T$ 升 → $\Delta U>0$；$T$ 降 → $\Delta U<0$。
  4. 用第一定律定热量：根据 $\Delta U = W + Q$（或 $Q = \Delta U + W_{\text{外}}$）定量或半定量判断吸、放热。当 $\Delta U$ 与 $W$（或 $W_{\text{外}}$）已知符号后，可确定 $Q$ 的正负。
  5. 特殊比例与计算：若涉及定量功、热量计算，需结合等压功 $W_{\text{外}} = p\Delta V$、等容热 $Q = nC_V\Delta T$、等压热 $Q = nC_p\Delta T$ 等。

高频易错

  • 混淆 $T$-$V$ 图与 $p$-$V$ 图：$T$-$V$ 图中过原点的直线代表等压过程，而非等温过程；等温过程在 $T$-$V$ 图中是平行于 $V$ 轴的竖直线。
  • 做功符号混乱：题目常“气体对外做功”与“外界对气体做功”换用，列第一定律 $ \Delta U = W + Q$ 时需明确 $W$ 是外界对系统做的功。习惯用 $Q = \Delta U + W_{\text{气体对外}}$ 更直接。
  • 只看体积不看温度：做功只看体积变化，内能只看温度变化，两者独立判断后再综合热学第一定律；切忌不经内能分析，直接由做功推断热量。
  • 等容不做功但温度可变化：体积不变时 $W_{\text{外}}=0$，但温度变化可引起内能变，此时 $Q = \Delta U$，吸放热直接由温度升降决定。
  • 多过程连续性判断：综合问题常涉及多段过程，必须分段分析做功、内能变化，再判断各段的吸放热情况，不可混淆。

代表题精讲

题目（2022·全国乙卷·13 改编回顾）

一定量的理想气体从状态 $a$ 经状态 $b$ 变化到状态 $c$，其过程如 $T$-$V$ 图上的两条线段所示：$a \to b$ 为过原点的倾斜直线，$b \to c$ 为平行于 $T$ 轴的竖直线（即等容过程）。则在此过程中（多选）：
A. $ab$ 过程中气体对外界做功
B. $bc$ 过程中气体对外界做功
C. $ab$ 过程中气体从外界吸热
D. $bc$ 过程中气体从外界吸热

思路

先由 $T$-$V$ 图识别两个过程的特征：$ab$ 过原点 → 等压过程；$bc$ 是等容过程。再分别分析各过程体积变化 → 判定做功；温度变化 → 判定内能变化；最后用热力学第一定律推断热量传递方向。

步骤

  • $a \to b$ 过程：
  • 图线过原点 → 等压。由图知温度降低、体积减小。
  • 体积减小 → 气体对外做负功（$W' < 0$），A 项错。
  • 温度降低 → 内能减少（$\Delta U < 0$）。
  • 由 $Q = \Delta U + W'$（$W'$ 为对外做功，符号已负）得 $Q$ 为负，即气体放热。C 项错。
  • $b \to c$ 过程：
  • 图线平行于 $T$ 轴（$V$ 不变）→ 等容过程。
  • 体积不变 → 气体对外不做功（$W'=0$），B 项错。
  • 由图知温度升高 → 内能增加（$\Delta U > 0$）。
  • 由 $Q = \Delta U$ 得 $Q > 0$，气体从外界吸热，D 项正确。

综上，正确选项为 D（原卷若为多选可能同时选 C 和 D 需视选项原设，按此分析 $ab$ 放热，$bc$ 吸热；若 C 为“ab 气体放热”则 C 也正确）。

点评/变式

  • 核心能力：从 $T$-$V$ 图像直接提取 $V$、$T$ 变化，并快速关联到等压、等容等过程。
  • 变式 1：将图像改为 $p$-$V$ 图，$a \to b$ 为水平线（等压），$b \to c$ 为垂直线（等容），则做功分析类似，但需重新判断温度变化。
  • 变式 2：增加过程 $c \to a$ 形成循环，求整个循环中气体对外做功、吸收净热量等，需结合循环面积（$p$-$V$ 图）或分段计算。
  • 应试提醒：遇到 $T$-$V$ 图，第一时间标注出特殊线（过原点等压，竖线等容），再分段列出 $V$、$T$、$W'$、$\Delta U$、$Q$ 的符号，答案一目了然。
