气体实验定律

考点气体实验定律权重5真题数1学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：5
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：填空14
  • 难度分布：中1

知识精要

  • 理想气体状态方程：一定质量的理想气体满足 $pV = nRT$ 或 $\frac{pV}{T}=C$（常数）。
  • 气体实验三定律（均为状态方程的特例）：
  • 等温变化（玻意耳定律）：$m$、$T$ 不变时，$pV = \text{常数}$；
  • 等容变化（查理定律）：$m$、$V$ 不变时，$\frac{p}{T} = \text{常数}$；
  • 等压变化（盖-吕萨克定律）：$m$、$p$ 不变时，$\frac{V}{T} = \text{常数}$。
  • 适用条件：气体质量一定且可视为理想气体；$T$ 必须用热力学温度（单位 K）；常数在不同状态下成立，需根据初末状态联立方程。
  • 压强的确定：封闭气体压强通常通过受力平衡（活塞、水银柱等）或连通器等外部条件求解。常用公式：$p = p_0 \pm \frac{mg}{S}$（竖直放置，若活塞静止）；当多活塞用刚性连接时，宜取整体为研究对象分析压强。

解题方法与套路

  1. 定对象与过程：明确哪部分一定质量的理想气体，区分初态与末态，画出状态变化示意图。
  2. 找参量：对初态、末态分别列出 $(p_1,V_1,T_1)$ 和 $(p_2,V_2,T_2)$，注意体积与几何尺寸（如活塞截面积及移动距离）的关系。
  3. 判定律：分析变化中等温、等容还是等压？若为一般过程，则直接选用理想气体状态方程 $\frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2}$。
  4. 列补充方程：涉及力学平衡时，对活塞、液柱等进行受力分析（整体法或隔离法），求解气体压强表达式，并与大气压、重力、连杆力等建立联系。
  5. 统一单位并求解：温度转换为开尔文（$T = t + 273$），其余物理量单位任意但须自洽。代入数据解方程，检验结果合理性。

高频易错

  • 温度未转换为热力学温度，直接代入摄氏温度导致比例错误。
  • 混淆气体质量不变与漏气、充气问题，后者需用总物质的量守恒或密度方程处理。
  • 压强计算遗漏大气压：例如竖直放置的活塞上表面受大气压 $p_0S$，下表面受气体压强 $pS$，列平衡式时易漏项。
  • 多活塞连接时，未考虑轻杆传递力的特点而错误独立分析单个活塞；正确做法是对整体列力平衡方程，或隔离后结合加速度关系（若匀加速则加惯性力）。
  • 体积变化与活塞移动距离的关系出错：对于截面积不同的汽缸，气体体积变化并非直接正比于单侧位移，而应考虑有效截面积差（如 $ \Delta V = d(S_{\text{大}} - S_{\text{小}})$）。
