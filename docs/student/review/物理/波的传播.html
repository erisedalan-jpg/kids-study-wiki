波的传播

考点波的传播权重6真题数1学科物理父主题机械振动 与 机械波

考点定位

  • 父主题：机械振动 与 机械波
  • 权重 weight：6
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 波的形成：介质中相邻质点间存在相互作用力，前一个质点带动后一个质点做受迫振动，振动状态由近及远传播形成机械波。
  • 波长 $\lambda$：振动相位总是相同的两个相邻质点间的距离。一个周期内波传播的距离等于一个波长。
  • 波速 $v$、频率 $f$、周期 $T$ 与波长的关系：$v = \lambda f = \frac{\lambda}{T}$。波速由介质决定，频率由波源决定。
  • 波动图像与振动图像：$y$—$x$ 图（波形图）表示某时刻各质点的位移；$y$—$t$ 图表示某质点位移随时间变化。两者结合可判断波的传播方向、质点振动方向。
  • 质点的振动方向与波传播方向的关系（同侧法/上下坡法）：
  • 同侧法：质点的振动方向与波的传播方向必须位于波形图的同一侧。
  • 沿波传播方向看，“上坡”质点向下振动，“下坡”质点向上振动。
  • 波动方程（选学但有助于解多解题）：简谐波沿 $x$ 轴正方向传播：$y = A\sin(\omega t - kx + \varphi_0)$，其中 $k = \frac{2\pi}{\lambda}$。$t$ 时刻的波形为 $y = A\sin(-kx + \varphi)$ 形式。
  • 波的空间周期性：相距为 $\Delta x$ 的两质点，其相位差 $\Delta\varphi = \frac{2\pi}{\lambda}\Delta x$。若给出两点振动状态，波长满足 $\Delta x = \left( n + \frac{\Delta\varphi}{2\pi} \right)\lambda$，其中 $n = 0,1,2,\dots$，导致波长多解。
  • 波的时间周期性：$t$ 时刻与 $t + nT$ 时刻波形重合，因此已知某些限制时也会出现周期多解。

解题方法与套路

  1. 画波形示意图：根据已知质点位置及振动方向，结合波的传播方向，画出 $t=0$ 时刻的波形草图。利用“同侧法”或“上下坡法”确定波形大致走向。
  2. 列相位关系：找出两点间距离 $\Delta x$ 与波长 $\lambda$ 的关系。根据两质点的振动状态确定它们的相位差 $\Delta\varphi$。
  3. 如一点在平衡位置某方向运动，另一点在波峰（或波谷），相位差不是唯一值，需加 $2n\pi$。
  4. 建立等式并求解：由 $\Delta x = \frac{\Delta\varphi}{2\pi}\lambda + n\lambda$ 或 $\Delta x = \left(k + \frac{\Delta\varphi}{2\pi}\right)\lambda$ 导出 $\lambda = \frac{\Delta x}{k + \frac{\Delta\varphi}{2\pi}}$（$k = 0,1,2,\dots$）。
  5. 筛选选项：将整数 $n$ 依次代入，求出所有可能的 $\lambda$，对照选项选择。注意 $n$ 从 $0$ 开始取，合理取舍。

高频易错

  • 漏掉空间周期多解：只求出 $n=0$ 的一个波长，忽略 $n=1,2,\dots$ 的其他可能值。题目问“可能等于”必须列出所有可能波长。
  • 相位差判断错误：没有正确分析两点振动状态所对应的相位。如平衡位置且向负方向振动，初相为 $\pi$（或 $-\pi$），不是 $0$。
  • 方向判断混淆：波沿 $x$ 正方向传播时，质点振动方向与传播方向的关系用错，导致相位差符号反了。
  • 公式机械套用：直接用 $\Delta x = (n+\frac{1}{4})\lambda$ 等结论而不检验适用条件，容易在复杂状态时出错。优先画图、推相位。
  • 忽略 $n$ 值的合理性：当 $n$ 取某些值时，波长会小于题设隐含条件（如小于两点距离），需注意检查。

代表题精讲

题目：简谐横波沿 $x$ 轴正方向传播，振幅为 $A$。$t=0$ 时，$x=0$ 处质元在 $y=0$ 且向 $y$ 轴负方向运动；$x=0.15\,\text{m}$ 处质元在 $y=A$ 处。求波长可能值。
选项：A. 0.60 m B. 0.20 m C. 0.12 m D. 0.086 m

思路：由两点振动状态求相位差，结合空间周期性导出波长的一般表达式，再逐一代入整数 $n$ 得出选项中可能的波长。

步骤： 1. 以 $x=0$ 处质点振动状态为参考。$t=0$ 时 $y=0$ 且向负方向运动 → 其振动相位为 $\pi$（或 $-\pi$）。
2. $x=0.15\,\text{m}$ 处质元在 $y=A$ → 处于波峰，对应相位为 $\frac{\pi}{2} + 2m\pi$（$m$ 为整数）。
3. 波沿 $x$ 正方向传播，$x$ 越大相位越落后。两点相位差 $\Delta\varphi = \varphi_{x=0} - \varphi_{x=0.15}$。取 $\varphi_0 = \pi$，$\varphi_{0.15} = \frac{\pi}{2} + 2m\pi$，则 $\Delta\varphi = \pi - \left(\frac{\pi}{2} + 2m\pi\right) = \frac{\pi}{2} - 2m\pi$。
也可理解为 $x=0.15\,\text{m}$ 处相位比 $x=0$ 落后 $\frac{\pi}{2} + 2k\pi$（令 $k = -m$），即 $\frac{2\pi}{\lambda}\cdot 0.15 = \frac{\pi}{2} + 2k\pi$。
4. 化简：$\frac{0.3\pi}{\lambda} = \frac{\pi}{2} + 2k\pi \Rightarrow \frac{0.3}{\lambda} = \frac{1}{2} + 2k = \frac{1+4k}{2}$。
5. 得 $\lambda = \frac{0.6}{1+4k}\,\text{m}$，$k = 0,1,2,\dots$
$k=0:\ \lambda = 0.60\,\text{m}$；
$k=1:\ \lambda = \frac{0.6}{5}=0.12\,\text{m}$；
$k=2:\ \lambda = \frac{0.6}{9}\approx 0.067\,\text{m}$；
之后 $\lambda$ 继续减小，无对应选项。
6. 选项中 0.60 m 和 0.12 m 符合，选 AC。

点评/变式：此题为典型的波的多解问题，核心在于“空间周期性 + 特定相位差”。若将 $x=0$ 处条件改为“向 $y$ 轴正方向运动”，则初相变为 $0$，$x=0.15\,\text{m}$ 处仍为波峰时，相位差变为 $-\frac{\pi}{2}+2k\pi$，$\lambda = \frac{0.6}{4k-1}$，$k=1,2,\dots$，答案会变化。复习中要重点训练“由两点状态反推波长”的通用逻辑，避免记死结论。
