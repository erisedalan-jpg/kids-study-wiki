液体表面张力

考点液体表面张力权重5真题数1学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：5
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：填空13
  • 难度分布：易1

知识精要

  • 液体表面张力：液体表面层分子间距较大，分子间作用力表现为引力，使液面具有收缩到表面积最小的趋势。适用条件为气液交界面，实例：小雨滴、露珠呈球形，水黾停在水面等。
  • 布朗运动：悬浮微粒（如花粉颗粒）的无规则运动。它反映的是液体分子无规则热运动的宏观表现，并非微粒自身分子的热运动。微粒越小、温度越高，布朗运动越明显。
  • 液晶的光学各向异性：液晶既具有液体的流动性，又具有晶体的光学各向异性，可被电场控制取向。彩色液晶显示器正是利用此特性实现显示。
  • 沸点与气压：液体的沸点随外界气压升高而升高，随气压降低而降低（如高原气压低，水不到100℃就沸腾）。并非由环境温度直接决定。
  • 蒸发吸热：液体蒸发时，动能较大的分子逸出液面，剩余液体分子平均动能减小，温度下降。干湿泡温度计正是利用湿纱布蒸发吸热，使湿泡示数低于干泡，且空气相对湿度越小，温差越大。

解题方法与套路

对于“下列说法正确的是”类的多选题/选项辨析，采用以下步骤： 1. 逐项审查：每个选项独立判断，标记已有知识能直接确认正误的。 2. 锁定考点：识别每个选项对应的知识点（表面张力、布朗运动、液晶、沸点与气压、蒸发吸热等），回忆该知识点的关键结论与常见错误表述。 3. 对比概念：特别注意容易混淆的对偶概念：如“布朗运动反映花粉分子热运动”（错误，反映液体分子热运动）、“高原沸点低是温度低”（错误，是气压低）。 4. 排除法+因果验证：对于有因果关系的选项（如“因为...所以...”），检查因果关系是否成立。 5. 警惕绝对化表述：如“一定”“都”等词，除非定理明确支持，否则多为错误选项。

高频易错

  • 布朗运动的描述对象：选项称“花粉分子的热运动”或“反映了微粒分子的热运动”均为错误。布朗运动的主体是“微粒”（花粉颗粒），它反映的是“液体分子”的无规则运动。
  • 表面张力与浮力的混淆：小雨滴/露珠呈球形是表面张力作用，而不是浮力或大气压力。小心将球形现象归于“分子斥力”或其它力。
  • 液晶各向异性的误用：液晶的光学各向异性是其关键特性，但注意其流动性，不要误认为所有方向物理性质相同，也不要与晶体的完全刚性混淆。
  • 沸点的影响因素：沸点取决于气压，而非环境温度。高原水“烧不开”是气压低，不是温度低。高压锅则是提高气压来提高沸点。
  • 干湿泡温度计的读数逻辑：湿泡温度低是因为水蒸发吸热，不是湿纱布保温或吸水导致升温。湿泡示数不受水温直接影响，而是蒸发降温与环境温度达到的平衡。

代表题精讲

代表题1（2014新课标Ⅱ-13）

题目：判断关于布朗运动、表面张力、液晶、沸点和干湿泡温度计的说法正误。

思路：依次判断每个选项，调动对应的知识点。 - A：考查布朗运动反映的对象。 - B：考查表面张力的宏观表现。 - C：考查液晶的特性及其应用。 - D：考查沸点与气压的关系。 - E：考查蒸发吸热原理。

步骤： 1. 审选项A：“悬浮在水中的花粉的布朗运动反映了花粉分子的热运动”。布朗运动中的花粉是微小颗粒，由大量分子组成，其无规则运动反映的是水分子（液体分子）的热运动，不是花粉自身分子的热运动。故A错误。 2. 审选项B：“空气的小雨滴呈球形是水的表面张力作用的结果”。水滴表面层分子间距较大，分子间表现引力（表面张力），有收缩趋势，在体积相同的情况下球形表面积最小，故呈球形。B正确。 3. 审选项C：“彩色液晶显示器利用了液晶的光学性质具有各向异性的特点”。液晶的光学性质（如折射率）随方向而异（各向异性），且可受电场调控，用于显示。C正确。 4. 审选项D：“高原地区水的沸点较低，这是高原地区温度较低的缘故”。水沸点随气压降低而降低，高原空气稀薄气压低，故沸点低，与温度低无关。因果关系错，D错误。 5. 审选项E：“干湿泡温度计的湿泡显示的温度低于干泡显示的温度，这是湿泡外纱布中的水蒸发吸热的结果”。湿纱布的水蒸发时吸收热量，使湿泡温度下降，低于环境温度（干泡示数）。E正确。 故正确选项为B、C、E。

点评/变式：该题覆盖热学多个基础点，为典型“散点多选”。易错点集中于因果关系（如D选项）和描述对象（如A选项）。变式训练可针对每个小知识点单独抠出错点，如：“下列说法是否正确：①布朗运动就是液体分子的热运动；②水银温度计在高原示数偏低是因为高原气温低；③液晶分子的排列是完全无序的。”通过辨析增强概念清晰度。
