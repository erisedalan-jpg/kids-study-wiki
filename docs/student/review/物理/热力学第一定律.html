热力学第一定律

考点热力学第一定律权重61真题数12学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：61
  • 真题数：12；年份跨度：2008–2023
  • 出现题位：填空13 选择1 选择3 选择8
  • 难度分布：中9 易1 难2

知识精要

  • 热力学第一定律：$\Delta U = Q + W$
  • $\Delta U$：系统内能增量（理想气体内能仅由温度决定，$\Delta U = n C_V \Delta T$）
  • $Q$：系统从外界吸收的热量（$Q>0$ 吸热，$Q<0$ 放热）
  • $W$：外界对系统做的功（$W>0$ 外界对系统做功，$W<0$ 系统对外界做功）
  • 常用变形：$Q = \Delta U - W$，对气体往往写成 $W = -p\Delta V$（准静态过程）
  • 理想气体内能：只有分子动能，无分子势能；内能只与温度有关。实际气体分子势能不能忽略，内能包含分子动能与分子势能，与体积也有关。
  • 气体做功：
  • 膨胀 → 气体对外做功 $W_{外} = -p\Delta V$ → 外界对气体做功 $W < 0$
  • 压缩 → 外界对气体做正功 $W > 0$
  • 向真空自由膨胀：气体不受外力，$W=0$
  • 体积不变：不做功
  • 理想气体状态方程：$pV = nRT$ 或 $\dfrac{pV}{T} = C$。结合 $p-V$ 图、$T-V$ 图、$p-T$ 图判断状态参量变化。
  • 热力学第二定律（用于辨析）：
  • 开尔文表述：不可能从单一热源吸热使之完全变为功而不产生其他影响
  • 克劳修斯表述：热量不能自发地从低温物体传到高温物体
  • 两类问题区别：违背第一定律是能量不守恒；违背第二定律是过程的方向性被破坏。
  • 气体压强微观解释：大量气体分子对器壁的频繁碰撞产生压强；温度越高、分子数密度越大，压强越大。完全失重时压强仍存在。

解题方法与套路

  1. 明确研究对象：一定量的理想气体（或多部分气体），判断初末状态及过程特征（等温、等压、等容、绝热、自由膨胀等）。
  2. 状态参量分析：利用理想气体状态方程 $\dfrac{pV}{T}=C$，由已知变化判断 $p、V、T$ 的变化关系。
  3. 内能变化：理想气体内能只看温度，$T$ 升高则 $\Delta U>0$，$T$ 降低则 $\Delta U<0$，等温则 $\Delta U=0$。
  4. 做功判断：看体积变化（或是否对真空膨胀）。体积增大 → $W<0$，体积减小 → $W>0$，体积不变或向真空膨胀 → $W=0$。
  5. 热量计算/吸放热判断：代入 $\Delta U = Q + W$（或 $Q = \Delta U - W$）得出 $Q$ 的正负及大小。
  6. 多部分气体与力学综合：
  7. 对活塞受力分析，列出平衡方程（注意弹簧弹力、外界大气压等）
  8. 联系各部分气体压强关系
  9. 结合几何关系确定体积变化
  10. 定律辨析题：判断是否违背热力学第一定律（能量守恒）、第二定律（方向性/单一热源/制冷等）。

高频易错

  • 符号混乱：牢记 $\Delta U = Q + W$ 中的 $W$ 是外界对系统做的功。若用气体对外做功 $W'$，则 $\Delta U = Q - W'$。
  • 理想气体体积增大内能一定减小：错误。体积膨胀可能吸热，等温膨胀内能不变；只有绝热自由膨胀或绝热膨胀时内能才减小。
  • 向真空膨胀做功：气体向真空扩散时不做功（$W=0$），而非对外做功。
  • 压强与重力：气体压强源于分子热运动碰撞，完全失重时仍存在压强，不会消失。
  • 温度与热量混淆：温度升高不一定吸热（可外界做功）；吸收热量温度不一定升高（等温膨胀吸热）。
  • 热力学第一、第二定律混淆：第一定律是能量守恒，违背表现为凭空产生能量；第二定律是过程方向性，违背表现为效率100%而无其他影响、热量自发从低温到高温等。
  • 实际气体与理想气体区别：实际气体内能包含分子势能，体积变化可能影响内能；题目未说明是理想气体时应考虑分子势能（如2018题）。

代表题精讲

2023-新课标-08

题目：绝热汽缸内用轻弹簧连接的两绝热活塞分成 f、g、h 三部分，初始温度、体积、压强相等，弹簧原长。通过电阻丝对 f 缓慢加热，停止加热并稳定后，判断说法正误。

思路：加热 f → 温度升高、压强增大 → 推动活塞压缩 h 并压缩弹簧 → 对 h 做绝热正功 → h 内能增加。稳定后弹簧处于压缩状态，由活塞平衡得 $p_f = p_g + \dfrac{F_{\text{弹}}}{S}$，故 $p_f > p_g$。结合理想气体状态方程比较 f 与 g 的温度。f 与 h 温度是否相等：加热导致 f 温度升高，h 因绝热压缩升温，但最终系统达到热平衡否？由活塞绝热、弹簧连接，f 与 h 直接无热交换，但通过活塞运动传递能量，最终可能温度不同。分析选项。

步骤： - A：h 被压缩，外界对 h 做正功，绝热 $Q=0$，由 $\Delta U = Q+W$，$\Delta U > 0$，内能增加，A 正确。 - B：稳定时对左边活塞 $p_f S = p_g S + F_{\text{弹}}$，弹簧被压缩，$F_{\text{弹}}>0$，故 $p_f > p_g$；初始体积相等，加热后 f 体积大于 g（弹簧压缩使 g 体积减小），由 $\dfrac{p_f V_f}{T_f} = \dfrac{p_g V_g}{T_g}$，因 $p_f V_f > p_g V_g$，得 $T_f > T_g$，B 错误。 - C：f 与 h 间无直接热交换且最终系统稳定，h 增加的压强源于活塞压缩而非热传导，f 温度高于初始，h 温度也高于初始，但不一定相等，且由整体体积约束及弹簧弹力，f 与 h 温度不会相等，C 错误。 - D：对右边活塞最终平衡，h 的压强与弹簧弹力及大气压（汽缸置于地面，外界大气未知），但左右活塞均绝热，平衡时左右两侧压强满足 $p_f = p_h + \cdots$？需具体受力分析。实际上活塞与汽缸绝热、无摩擦，但未提及大气压。通常这类问题中，汽缸外部环境为大气，但题干“置于水平地面上”未强调与大气相通。从解析可知 D 正确。深入：右边活塞受 h 气体压力向右，弹簧弹力向左，必须还有大气压力？假如汽缸是封闭的绝热汽缸，可能 f 左边也有大气？严谨分析：由系统整体，弹簧弹力为内力，最终 $p_h$ 与 $p_f$ 关系可由两个活塞平衡联立，结论 $p_f = p_h$。故 D 正确。

点评/变式：连接体问题“绝热+弹簧”综合了热力学第一定律、气体状态方程与受力平衡。注意分清哪部分气体经历什么过程，做功与传热路径。变式：若弹簧不是轻弹簧，或活塞有质量，则受力分析需计入重力。

2017-新课标Ⅱ-13

题目：绝热汽缸，隔板左侧为理想气体，右侧与绝热活塞之间为真空。抽开隔板，气体自发扩散至整个汽缸；待稳定后缓慢推压活塞，将气体压回原体积。判断过程内能、做功等说法。

思路：第一步：向真空扩散，无阻力，气体不对外做功 $W=0$，汽缸绝热 $Q=0$，则 $\Delta U =0$，内能不变。第二步：缓慢压缩，外界对气体做功 $W>0$，仍绝热 $Q=0$，内能增大，温度升高
