牛顿第一定律

考点牛顿第一定律权重8真题数1学科物理父主题力 与 牛顿运动定律

考点定位

  • 父主题：力 与 牛顿运动定律
  • 权重 weight：8
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 牛顿第一定律（惯性定律）：一切物体总保持匀速直线运动状态或静止状态，除非作用在它上面的力迫使它改变这种状态。
  • 惯性：物体具有保持原来匀速直线运动状态或静止状态的性质，称为惯性。
  • 惯性是物体的固有属性，一切物体在任何情况下都有惯性。
  • 惯性的唯一量度是质量，质量越大，惯性越大（即运动状态越难改变）。
  • 惯性不是力，不能说“受到惯性”或“惯性力”。
  • 力与运动的关系：力是改变物体运动状态的原因，不是维持物体运动的原因。
  • 适用条件：牛顿第一定律仅在惯性参考系中成立（高中阶段默认为地面参考系）。

解题方法与套路

  1. 抓惯性定义关键词：题目中出现“抵抗运动状态变化”“保持原来运动状态”等表述时，直接与惯性概念挂钩；确认质量是唯一决定因素，与其他运动参量（速度、加速度）均无关。
  2. 辨析力与运动：凡是认为“力是维持运动的原因”“不受力必定静止”的说法一律错误。正确表述：不受力时物体做匀速直线运动或静止；受力是改变速度（大小或方向）的原因。
  3. 甄别特例陷阱：匀速圆周运动的速度方向时刻改变，属变速运动，不符合“保持原运动状态”，因此不是惯性的表现。
  4. 多选判断法：抓住“一切物体都有惯性”“不受力则匀速直线运动或静止”两条铁律，逐项排除明显违背的选项。

高频易错

  • “不受力只能静止”：疏忽了匀速直线运动状态。牛顿第一定律包括静止和匀速直线运动两种状态，不受力时物体究竟处于哪种状态由初始条件决定。
  • “匀速圆周运动是惯性运动”：速度方向持续改变，必须有向心力作用，该运动状态一直在变，不能归为惯性。
  • 混淆惯性与惯性定律：惯性和惯性定律（牛顿第一定律）不是一个概念，正确说法：惯性定律指出，物体因惯性而保持运动状态不变。
  • 认为速度越大惯性越大：惯性仅与质量有关，与速度、是否运动、地理位置无关。

代表题精讲

2012年新课标卷·第1题（伽利略理想实验与惯性概念）

题目
关于惯性的早期讨论中，判断下列说法正确的有：
A．物体抵抗运动状态变化的性质是惯性
B．没有力作用，物体只能处于静止状态
C．行星在圆周轨道上保持匀速率运动的性质是惯性
D．运动物体如果没有受到力的作用，将继续以同一速度沿同一直线运动

思路
由惯性定义和牛顿第一定律入手，逐项检验。惯性为抵抗状态变化之性；力是改变运动的原因而非维持运动的原因；圆周运动速率虽不变，但速度方向时刻改变，并非“运动状态不变”。

步骤
1. A项：惯性即物体保持原运动状态、抵抗变化的性质，直接符合定义，正确。
2. B项：不受力时，物体可能静止也可能做匀速直线运动（取决于初态），本项说“只能静止”以偏概全，错误。
3. C项：行星在圆周轨道上运动，方向时刻改变，速度矢量在变化，需向心力维持，不符合“保持原来运动状态”，错误。
4. D项：符合牛顿第一定律——运动物体不受力将保持匀速直线运动（同一速度，沿同一直线），正确。
综上，选 A、D。

点评/变式
- 本题源自伽利略理想实验的思想，属基础概念题，但多选常因“不受力只能静止”的旧观念失分。
- 变式：若题设改为“物体保持原来速度大小不变的性质是惯性”，仍然错——惯性是保持速度矢量不变，方向改变即受外力作用。记忆要点：惯性=保持原速原向；力=改变速度的原因。
