物体做曲线运动的条件

考点物体做曲线运动的条件权重0真题数1学科物理父主题曲线运动 与 抛体

考点定位

  • 父主题：曲线运动 与 抛体
  • 权重 weight：0
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 曲线运动条件：物体所受合外力方向与速度方向不在同一直线上。合力指向轨迹凹侧，其切向分量改变速度大小，法向分量改变速度方向。
  • 电场线 vs 运动轨迹：电场线是假想曲线，反映空间场强分布，其切线方向表示该点场强方向。粒子实际运动轨迹是其速度矢量随时间累积的结果。仅当电场线为直线、粒子初速为零或初速方向沿电场线、且粒子仅受电场力时，轨迹才可能与电场线重合。
  • 功能关系：在仅受电场力作用下，电场力做正功，电势能减小，动能增大；做负功则反之。粒子由静止释放，在任意两点间满足 $E_{pM} \ge E_{pN}$（末点电势能不高于起点）。
  • 电势能高低的量度：对正电荷，电势高处电势能大；对负电荷，电势低处电势能大。但无论电荷正负，从静止释放后电场力必做正功，电势能必然降低。

解题方法与套路

  1. 逐项审视，逻辑拆解：针对多选型选择题，将每个选项视为独立判断题。先提取选项核心判断词，再与物理规律严格比对。
  2. 条件与模型对应：遇到带电粒子运动，立刻判断电场是否已知、粒子初始状态（静/动）、是否“仅受电场力”。若电场为“静电场”但分布形状“未知”，则所有关于轨迹形状（直线/曲线）、速度单调性等的确定性结论都不能成立，“可能”项优先考虑。
  3. 反例排除法：对绝对化表述（如“一定”、“必”），构造反例快速排除。如“轨迹一定与电场线重合”，可用非匀强电场中粒子做曲线运动来否定。
  4. 基本守恒与功能关系运用：对于“仅受电场力”、“由静止释放”类问题，直接锁定“电场力做正功→电势能减小→动能增加”这一逻辑链，只分析功的正负而不纠缠具体电场分布。

高频易错

  • 将电场线与轨迹等价：误认为粒子沿电场线运动是普遍情况。只有同时满足“电场线为直线、初速为零或初速沿直线、仅受电场力”三重条件才可。
  • 混淆场强方向与速度方向：曲线运动中，某点速度方向为轨迹切线方向，而该点电场力（场强）方向为电场线的切线方向，两者在轨迹弯曲时绝不相同。D选项是典型干扰项。
  • 绝对化陷阱：对“未知电场”条件缺乏敏感度，错选含“一定”的确定性结论。在信息不充分时，只有“可能”性或由能量守恒导出的必然结论（如电势能降低）才是可靠的。
  • 忽略初始条件差异：M点“静止”是关键。若无此条件，粒子电势能就可能上升（如速度足够时，克服电场力减速），而C选项“不低于”正是利用了初态动能为零保证电场力全程只能做正功或为零。

代表题精讲

题目（2019新课标Ⅱ）：一带电粒子仅在电场力作用下，自M点由静止开始运动，N为轨迹上另一点。判断选项中关于速度大小变化、轨迹与电场线关系、电势能比较以及受力方向与速度方向关系的说法。

思路：从“电场未知”、“仅受电场力”、“M点静止”三个核心条件入手。利用能量守恒判断电势能必降低；利用曲线运动的条件可判断D项的“一定平行”必错；利用电场线与轨迹的严格关系判断B项的“一定重合”必错；A项含“可能”，需寻找可能性成立的情景。

步骤： 1. 审视A项（速度大小可能先增大后减小）：若电场方向在运动中相对于粒子速度反向，粒子会先加速后减速。例如在正、负点电荷附近往复运动。结论：该情景可出现，故“可能”正确。A正确。 2. 审视B项（轨迹一定与某条电场线重合）：联想到非匀强电场，如点电荷电场，粒子若初速偏离径向，将做曲线运动，轨迹与弯曲的电场线不重合。即使电场线是弯曲的，粒子运动也必有脱离该曲线的法向加速度，条件不满足三重标准。B错误。 3. 审视C项（M点电势能不低于N点电势能）：粒子仅受电场力，从静止出发，由动能定理知电场力做正功（或零功），则电势能必定减少或不变。故 $E_{pM} \ge E_{pN}$。C正确。 4. 审视D项（N点电场力方向一定与轨迹切线平行）：曲线运动瞬间，速度沿轨迹切线方向，而合力必指向轨迹凹侧，与速度方向有夹角，绝不平行的。只能当粒子做直线运动时才共线。轨迹未必是直线，故“一定平行”错误。D错误。

点评/变式：本题是“电场+曲线运动”的综合甄别题，核心技巧在于识别条件缺失带来的不确定性。遇到此类问题，切勿过度脑补具体电场形状，应紧抓“静止→正功→电势能降”的第一性原理和“力速不共线→曲线”的动力学判据。 - 变式：若将题干中“静止”改为“以初速度 $v_0$ 运动”，则C选项中“不低于”不再一定成立，因粒子可能出现动能足够大，克服电场力做负功电势能增大的阶段。
