知识精要

理想气体状态方程描述一定质量理想气体状态参量间关系。核心公式：
$$ \frac{pV}{T} = C \quad \text{或} \quad \frac{p_1V_1}{T_1} = \frac{p_2V_2}{T_2} $$ 其中 $C=nR$，$n$ 为物质的量，$R$ 为普适气体常量。$T$ 必须使用热力学温度 $(K)$。

气体实验定律均为其特例： - 等温变化 ($T$不变)：玻意耳定律 $p_1V_1 = p_2V_2$ - 等压变化 ($p$不变)：盖-吕萨克定律 $\frac{V_1}{T_1} = \frac{V_2}{T_2}$ - 等容变化 ($V$不变)：查理定律 $\frac{p_1}{T_1} = \frac{p_2}{T_2}$

对于变质量问题，常以原有气体整体为研究对象，或利用克拉珀龙方程 $pV=nRT$ 求摩尔数。

温度是分子平均动能的标志。理想气体内能只由温度决定，若温度不变则内能不变。压强微观上取决于分子数密度和分子的平均动能（温度）。

解题方法与套路

  1. 明确研究对象：确定是哪一部分“一定质量”的理想气体。若涉及多部分气体，需分别对各部分列式，并通过几何关系、力学平衡关系建立联系。对于漏气、充气等变质量问题，常以全部原有气体为对象。
  2. 分析初末状态与过程：仔细审题，找出气体在不同阶段的 $p、V、T$ 参量。判断变化过程是等温、等压、等容还是一般变化。涉及两个部分气体时，常伴随一部分推动另一部分做等压或等容变化。
  3. 选用规律列式：根据过程特点选用气体实验定律或理想气体状态方程。若涉及热传递与内能变化，结合热力学第一定律 $\Delta U = W + Q$（注意吸放热、做正负功的符号）。
  4. 建立辅助方程：通过活塞、液柱等受力平衡求压强；通过容器几何关系求体积变化；通过力与运动关系（如弹簧形变）分析状态。
  5. 联立求解：统一单位，注意压强单位常用 $cmHg$ 或 $Pa$，温度必须换算成开尔文。

高频易错

  • 初末状态分析不准确：未正确判断“稳定后”各活塞/液柱的位置，导致体积关系错误。如 2023新课标题中，需结合弹簧弹力变化判断活塞移动方向与最终位置。
  • 研究对象混淆：在两部分气体相互牵连的系统中，机械地对某一部分直接使用理想气体状态方程，未考虑另一部分的状态变化会通过活塞或液柱影响它的压强。应先整体分析驱动过程，再隔离分析各气体。
  • 热力学第一定律符号弄错：$\Delta U = W + Q$ 中，气体体积减小（外界对气体做功）$W$ 取正，体积增大（气体对外界做功）$W$ 取负；吸热 $Q$ 取正，放热 $Q$ 取负。绝热过程 $Q=0$。
  • 忽视“缓慢”条件：题目中“缓慢加热或移动”意味着过程任意时刻均可视为平衡态，适用于理想气体状态方程，但中间过程若非等压/等容，不能混淆使用特例定律。
  • 压强分析错误：对液柱、活塞受力分析时漏掉大气压或某部分气体压强，导致初末态压强表达式出错。

代表题精讲

题目1：2023-新课标-08

一绝热汽缸内，轻弹簧连接两绝热活塞，将缸分为 $f、g、h$ 三部分理想气体。初始弹簧原长，三部分 $p、V、T$ 相同。缓慢加热 $f$ 中气体，停止并稳定后，判断各选项正误。

思路： 1. 加热 $f$ → $T_f$ 升高 → $p_f$ 增大 → 打破活塞平衡。 2. 左活塞左移压缩 $h$，右活塞右移拉伸弹簧，弹簧被压缩，弹力增大。 3. 分析活塞最终受力平衡条件，比较 $p_f$ 与 $p_g$。 4. 根据理想气体状态方程，结合体积变化，比较温度。

步骤： - A选项：活塞左移，$h$ 体积减小，绝热 $Q=0$，外界对气体做正功 $W>0$，由 $\Delta U = W + Q$ 可知 $\Delta U > 0$，$h$ 内能增加。A 正确。 - B、C选项：对左活塞平衡：$p_f S = p_g S + F_{\text{弹}}$，故 $p_f > p_g$。初始三部分体积相同，设为 $V_0$；最终 $f$ 体积 $V_f > V_0$，$g$ 体积 $V_g < V_0$。由理想气体状态方程 $\frac{p_f V_f}{T_f} = \frac{p_0 V_0}{T_0}$，$\frac{p_g V_g}{T_g} = \frac{p_0 V_0}{T_0}$。因为 $p_f V_f > p_0 V_0$，必有 $T_f > T_0$；因为 $p_g V_g$ 与 $p_0 V_0$ 关系不定，但由上述不等式联立可推得 $T_f$ 应明显高于 $T_g$，两者不等。B、C 错误。 - D选项：对整体（两活塞及弹簧）受力分析，外界大气压与气缸左端对 $h$ 压力平衡，可得 $p_h$ 必等于大气压或与 $f$ 压强存在关系。由活塞平衡详细推导可得，$f$ 与 $h$ 压强存在直接对应关系，本题中稳定后两者压强相等。D 正确。 - 答：AD

点评/变式： 此题为多部分气体与力、热综合的经典难题。关键在于 “先定性判断趋势，再定量隔离分析” 。弹簧从原长变为压缩，弹力方向是关键突破口。变式训练可换成两部分气体+弹簧，或液柱分隔两部分气体等。

题目2：2024-辽宁-11

理想变压器原副线圈匝数比 $n_1:n_2=5:1$，原线圈接峰值为 $U_m$ 的正弦交变电源。副线圈接阻值为 $R$ 的电热丝，置于绝热容器内加热理想气体，初始温度 $T_0$，吸热满足 $Q=C\Delta T$。求通电时间 $t$ 使压强变为 $2$ 倍。

思路： 1. 由变压器关系求副线圈电压有效值，进而求输出功率 $P$。 2. 气体发生等容变化，由查理定律求末态温度及 $\Delta T$。 3. 利用 $Q=C\Delta T$ 和 $Q=Pt$（电热丝产生的热量全部被气体吸收）联立求解时间 $t$。

步骤： - （1）输出功率 P： 输入电压有效值 $U_1 = \frac{U_m}{\sqrt{2}}$。 由 $\frac{U_1}{U_2} = \frac{n_1}{n_2}$ 得 $U_2 = \frac{n_2}{n_1}U_1 = \frac{1}{5} \cdot \frac{U_m}{\sqrt{2}} = \frac{U_m}{5\sqrt{2}}$。 输出功率 $P = \frac{U_2^2}{R} = \frac{U_m^2}{50R}$。 - （2）通电时间 t： 气体体积不变，由查理定律：$p_0/T_0 = 2p_0/T_2 \Rightarrow T_2 = 2T_0$。 温度变化量 $\Delta T = T_2 - T_0 = T_0$。 吸收热量 $Q = C\Delta T = CT_0$。 电热丝产热 $Q_{\text{电}} = Pt$。 由 $Q=Q_{\text{电}}$ 得 $t = \frac{Q}{P} = \frac{CT_0}{\frac{U_m^2}{50R}} = \frac{50 \, C \, T_0 \, R}{U_m^2}$。

点评/变式： 本题将交变电流、变压器与热学完美结合，但每个模块考得都不深，属于“拼盘”式综合题。分模块逐层击破是上策。注意高压输电线路上，能量守恒关系表述要清晰。可变式为等压加热求活塞移动距离等。
