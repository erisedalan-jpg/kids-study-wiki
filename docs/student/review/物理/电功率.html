电功率

考点电功率权重24真题数4学科物理父主题恒定电流

考点定位

  • 父主题：恒定电流
  • 权重 weight：24
  • 真题数：4；年份跨度：2008–2016
  • 出现题位：填空12 选择4 选择7
  • 难度分布：中2 易1 难1

知识精要

  • 电功率定义：电流在单位时间内做的功，$P = \frac{W}{t} = UI$（普遍适用）。
  • 焦耳定律与热功率：$Q = I^2 R t$，热功率 $P_{\text{热}} = I^2 R$（适用于一切电路）。纯电阻电路中，$P_{\text{热}} = P_{\text{总}} = UI = I^2 R = \frac{U^2}{R}$；非纯电阻电路中 $P_{\text{总}} = UI > I^2 R$。
  • 电源功率与输出功率：电源总功率 $P_{\text{总}} = E I$；电源内阻消耗功率 $P_r = I^2 r$；电源输出功率 $P_{\text{出}} = P_{\text{总}} - P_r = UI_{\text{外}}$（$U$ 为路端电压）。
  • 理想变压器：输入功率等于输出功率，$U_1 I_1 = U_2 I_2$（多副线圈时 $P_1 = P_2 + P_3 + \cdots$）。结合变压比 $\frac{U_1}{U_2} = \frac{n_1}{n_2}$ 和变流比 $\frac{I_1}{I_2} = \frac{n_2}{n_1}$（仅一个副线圈时成立）可求电压、电流和功率分配。
  • 电磁感应中的电功率：动生电动势 $E = Blv$（$v$ 为有效切割速度）。回路总功率 $P_{\text{总}} = E I$，克服安培力做功的功率 $P_{\text{安}} = B I l v$，在纯电阻电路中等效。部分电路功率 $P = I^2 R$ 或 $P = \frac{U^2}{R}$。

解题方法与套路

  1. 明确电路结构与用电器性质：判断是纯电阻电路还是非纯电阻电路，确定功率公式的选用（$P=UI$、$P=I^2R$、$P=U^2/R$）。
  2. 变压器类问题——功率是桥梁：解析原副线圈的电流、电压关系时，先由匝数比确定电压比，再通过功率相等 $U_1 I_1 = U_2 I_2$ 求电流，切忌死套电流与匝数成反比的公式（仅在单副线圈且空载电流不计时成立）。
  3. 电磁感应问题——能量转化定功率：明确安培力做功与电能转化的对应关系，回路中某电阻的功率常通过 $I^2 R$ 或 $P_{\text{总}} - P_{\text{内}}$ 求得；涉及恒定电流时，可结合运动学求平均速度，进而求平均功率。
  4. 含变化量的功率分析：当某物理量发生变化时，抓住功率与关键量的函数关系（如 $P \propto E^2 \propto \omega^2$、$P \propto v^2$ 等），避免凭感觉线性外推。

高频易错

  • 乱用功率公式：在电动机等非纯电阻电路中将 $P=I^2R$ 或 $P=U^2/R$ 当作总功率，忽略机械功率；纯电阻电路才三者等价。
  • 变压器电流关系误用：直接认为 $\frac{I_1}{I_2} = \frac{n_2}{n_1}$ 万能，忽略多副线圈或非理想情况，应牢记功率守恒 $U_1 I_1 = U_2 I_2 + U_3 I_3 + \cdots$。
  • 角速度、转速与功率的平方关系：由电磁感应 $E = \frac{1}{2}B\omega r^2$ 等形式，功率 $P \propto \omega^2$，误认为 $P \propto \omega$ 会致错（如法拉第圆盘）。
  • 平均功率与瞬时功率混淆：在运动过程中求功率时，注意题目所求是平均值还是瞬时值。平均值应用平均电动势或平均电流计算，不能简单用平均速度代入瞬时功率公式。
  • 变压器中电压不变误推功率不变：调节匝数或负载时，输出功率 $P_2 = \frac{U_2^2}{R}$ 随 $U_2$ 变化，输入功率随之改变，不能默认电流不变或功率恒定。

代表题精讲

题目（2016 新课标Ⅱ 第7题）

法拉第圆盘发电机：铜圆盘在竖直向上的匀强磁场 $B$ 中绕轴转动，P、Q 接触边缘和轴，外接电阻 $R$。判断电流的大小、方向及热功率与角速度的关系。

思路：将圆盘视为无数辐条，等效为导体棒旋转切割，感应电动势 $E = \frac{1}{2}B\omega r^2$（其中 $r$ 为半径）。由右手定则判断电流方向，由 $E$ 与 $\omega$ 的关系得出电流 $I = \frac{E}{R_{\text{总}}}$ 与 $\omega$ 的关系，功率 $P_{\text{热}} = I^2 R \propto \omega^2$。

步骤： 1. 圆盘旋转切割磁感线，产生的感应电动势 $E = \frac{1}{2}B r^2 \omega$（常量部分全部固定时 $E \propto \omega$）。 2. 若 $\omega$ 恒定，$E$ 恒定，$I$ 恒定，A 正确。 3. 从上往下看，顺时针转动时右手定则判定电流从边缘 P 流向轴心 Q（盘内），外电路由 a→R→b，B 正确。 4. 圆盘转动方向不变，$E$ 方向不变，电流方向不变，与角速度大小无关，C 错误。 5. 电阻 $R$ 上的热功率 $P = I^2 R = \left( \frac{E}{R+r} \right)^2 R$，$E \propto \omega$，则 $P \propto \omega^2$，角速度变为 2 倍，功率变为 4 倍，D 错误。 答案：AB

点评/变式：法拉第圆盘可等效为无数并联的棒切割，电动势公式需牢记。功率与角速度的平方关系是此类问题常设的陷阱。变式：若外电路断开，盘内是否有电流？断开时无电流，但仍有感应电动势。

题目（2012 新课标 第4题）

自耦调压变压器，总匝数 1900，原线圈 1100 匝，输入 220V。输出电压调至最大时负载功率 2.0kW。求此时 $U_2$ 和原线圈电流 $I_1$。

思路：输出电压最大时，副线圈取全部 1900 匝，利用理想变压器电压比求 $U_2$，再用功率守恒 $P_1 = P_2$ 求 $I_1$。

步骤： 1. 电压比为 $\frac{U_1}{U_2} = \frac{n_1}{n_2}$，其中 $n_1 = 1100$，$n_2 = 1900$，$U_1 = 220 \text{V}$。 2. 解得 $U_2 = \frac{n_2}{n_1} U_1 = \frac{1900}{1100} \times 220 = 380 \text{V}$。 3. 理想变压器输入功率等于输出功率：$U_1 I_1 = P_2 = 2000 \text{W}$。 4. $I_1 = \frac{P_2}{U_1} = \frac{2000}{220} \approx 9.1 \text{A}$。 答案：$U_2 \approx 380 \text{V}$，$I_1 \approx 9.1 \text{A}$（根据选项确定）。

点评/变式：自耦变压器的本质是理想变压器，分清原副线圈对应的匝数是关键。注意不能直接用电流比反比于匝数比，因为原副线圈有公共部分时电流关系复杂，但功率守恒始终有效。

题目（2011 新课标 第4题）

理想变压器原副线圈匝数比 1:2，副线圈接额定 220V、22W 的灯泡，正常发光。求原线圈电压表读数 $U$ 和电流表读数 $I$。

思路：由灯泡正常发光得副线圈电压、电流，利用变压比、功率守恒（或电流比）求原线圈的量。

步骤： 1. 灯泡正常发光：$U_2 = 220 \text{V}$，电流 $I_2 = \frac{P_{\text{额}}}{U_2} = \frac{22}{220} = 0.1 \text{A}$。 2. 由 $\frac{U_1}{U_2} = \frac{n_1}{n_2} = \frac{1}{2}$，得 $U_1 = 110 \text{V}$。 3. 方法一（功率守恒）：$U_1 I_1 = U_2 I_2 = 22 \text{W}$，得 $I_1 = \frac{22}{110} = 0.2 \text{A}$。 方法二（单副线圈电流比）：$\frac{I_1}{I_2} = \frac{n_2}{n_1} = 2$，得 $I_1 = 0.2 \text{A}$。 答案：U=110V，I=0.2A（A选项）。

点评/变式：此题是最基本的变压器应用，灯泡正常发光是突破点。注意电流比仅对单输出回路成立，此处适用。常错点：误将匝数比当作电流比，忘记反比关系；或不看单位，直接心算出错。
