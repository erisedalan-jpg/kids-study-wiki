电场力做功

考点电场力做功权重26真题数5学科物理父主题功 与 能

考点定位

  • 父主题：功 与 能
  • 权重 weight：26
  • 真题数：5；年份跨度：2018–2024
  • 出现题位：选择2 选择6 选择7 选择8
  • 难度分布：中5

知识精要

  • 电场力做功：电荷在电场中移动时，电场力做功 $W_{AB} = qU_{AB}$（与路径无关）。
  • 功能关系：电场力做的功等于电势能的减少量，即 $W_{\text{电}} = -\Delta E_p = E_{pA} - E_{pB}$。
  • 电势能判断：正电荷在电势高处电势能大，负电荷在电势低处电势能大；仅电场力作用时，电势能与动能之和守恒。
  • 匀强电场中做功：$W = qEd$，$d$ 为沿电场线方向的位移投影。
  • 电场力与轨迹：曲线运动中合力（电场力）指向轨迹凹侧；轨迹不一定与电场线重合。
  • 等势面规律：等势面密集处场强大，电场线垂直于等势面并指向电势降低的方向；在同一等势面上移动电荷，电场力做功为零。
  • 电势差与中点：匀强电场中，两点的中点电势等于两点电势的平均值；电场力做功与路径无关，因此可利用中间点分段计算。

解题方法与套路

  1. 功的正负判断：先画出电场线方向或场强方向，再标出位移矢量，由二者夹角（锐角正功、钝角负功）直接判定电场力做功的正负。
  2. 功能关系两步法：
  3. 分析是否只有电场力做功（或其它力），用动能定理列式：$W_{\text{合}} = \Delta E_k$。
  4. 电场力做功与电势能的关系：$W_{\text{电}} = E_{p\text{初}} - E_{p\text{末}}$。结合两者求解动能、电势能变化。
  5. 电势能大小比较：
  6. 明确电荷正负。
  7. 判断电势高低（沿电场线方向电势降低，等势面数值变化）。
  8. 套用 $E_p = q\varphi$：正电荷 $E_p$ 与 $\varphi$ 同向变化，负电荷反向。
  9. 匀强电场中做功计算：
  10. 确定场强大小和方向。
  11. 找出位移在场强方向的投影 $d$，用 $W = qEd$ 计算。
  12. 注意：两点间距离不等同于 $d$，需分解。
  13. 等势面问题破解：
  14. 疏密定场强大小：密处 $E$ 大，进而判断电场力 $F=qE$ 大小。
  15. 画出电场线（垂直于等势面，由高电势指向低电势）。
  16. 根据电势变化判断电场力做功和电势能变化。
  17. 粒子轨迹分析：
  18. 在仅受电场力且从静止开始运动时，粒子必从高电势向低电势（正电荷）或反（负电荷），电场力一定做正功，速度增大。但若电场方向改变或粒子有初速度，速度大小可能先增后减。

高频易错

  • 错把轨迹当电场线：只有电场线为直线、粒子初速为零或初速沿直线时，轨迹才与电场线重合；曲线运动中，轨迹切线与受力方向不平行。
  • 混淆 $d$ 与位移：在 $W=qEd$ 中，$d$ 必须是沿电场方向的投影距离，并非任意两点间距。
  • 忽略电荷正负：比较电势能时，不看电荷正负直接认为电势高处电势能大（负电荷情况恰好相反）。
  • 误判做功与动能关系：当有重力等其他力时，电场力做功正负不一定对应动能增减，必须用动能定理综合考虑。
  • 中点电势陷阱：匀强电场中，任意线段中点的电势等于两端点电势的平均值，但电场力做功不一定直接用该中点电势差计算，需关注是否沿同一路径。
  • 等势面判断场强随意：相邻等势面间电势差相等时，间距越小场强越大，但未说明“相邻等势面等势差”时不能直接由疏密推断。

代表题精讲

代表题1：2024-辽宁-06

题目：带电小球在水平匀强电场和重力场中，初速度沿虚线（合力方向）时轨迹为直线，初速度垂直于虚线时，从O点出发到等高处的过程中，动能和电势能如何变化？

思路：由“沿虚线运动为直线”推出重力和电场力的合力沿虚线。初速度垂直虚线时，粒子做类斜抛运动，回到等高点的过程中重力做功为零，只需分析电场力做功。

步骤： 1. 锁定合力方向：小球仅受重力和水平电场力，其沿虚线直线运动，说明合力沿虚线，由此判定电场力方向水平向右。 2. 分析新运动：初速度垂直虚线，即与合力垂直，物体做类平抛运动（恒力垂直于初速），轨迹为抛物线。 3. 回到等高处：重力做的总功为零（上升与下降过程对称），只有水平方向电场力持续做正功。 4. 功能关系：电场力做正功 → 电势能减小；合力做功为正（因电场力正功且重力不做功） → 动能增大。故选D（动能增大，电势能减小）。

点评/变式：本题巧妙运用“直线运动条件”反推合力方向，再结合独立作用原理（重力做功与高度差有关）解决问题。变式：若初速度既不沿虚线也不垂直虚线，轨迹如何？可分解运动处理。

代表题2：2022-全国乙-06

题目：四顶点固定两正两负等量电荷构成正方形，分析内切圆上L、N（对角线交点）和M（切点）的电场方向及移动电荷做功情况。

思路：分别利用点电荷场强叠加确定合场强方向；结合对称性与等势面判断电势关系；电场力做功看电势差。

步骤： 1. 判断L、N场强方向：N点处于两负电荷中垂线上（场强指向N）且两正电荷在N点场强也指向N，合场强由N→O；同理L点合场强由O→L。正方形对角线垂直，故L与N场强方向垂直，A正确。 2. 判断M点场强方向：底边等量异号电荷在M点产生向左场强，上方异号电荷产生向右场强，但因M靠近底边，向左场强更大，合场强向左，B正确。 3. 判断M→O做功：M、O位于正方体两等量异号电荷连线的中垂面上（等势面），电势相等，移动正电荷电场力做功为零，C错误。 4. 判断L→N做功：顺着电场线方向电势降低，即N点电势高于L点（电场线N→O→L），正电荷从L到N，电场力做正功（或负功？电势升高，正电荷电势能增大，电场力做负功），总之做功不为零，D错误。

点评/变式：本题核心是等量异号电荷连线中垂线为等势线且为零势面，等量同号电荷需具体分析。变式：若将正电荷从M移至N，利用对称性和电势叠加可求做功。

代表题3：2021-全国乙-02

题目：接地金属板上方负电荷，给出等势面（相邻等势面电势差相等），比较M和N处正试探电荷的电场力与电势能大小。

思路：依据等势面疏密判断场强，等势面密处$E$大，得电场力大小；根据电场线方向（由高压指向低压）或负电荷电场特征，电势靠近负电荷更低，正电荷在电势低处电势能小。

步骤： 1. 场强比较：图中等势面密集处场强大，观察M、N位置等势面间距，密者$F$大。 2. 电势高低：金属板接地为零电势，负电荷产生负电势，越靠近负电荷电势越低。由等势面数值标定或位置判断M、N电势高低。 3. 电势能比较：正电荷，$E_p = q\varphi$，电势大处电势能大。综合可得答案。

点评：本题陷阱在于正负电荷电势能判据，务必牢记“正高能大，负高能小”。即使无图，掌握基本原理即可举一反三。
