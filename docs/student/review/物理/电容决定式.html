电容决定式

考点电容决定式权重6真题数1学科物理父主题静电场

考点定位

  • 父主题：静电场
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 平行板电容器电容的决定式
    $$ C = \frac{\varepsilon S}{4\pi k d} $$
    其中 $\varepsilon$ 为极板间介质的相对介电常数，$S$ 为正对面积，$d$ 为极板间距，$k$ 为静电力常量。
  • 决定电容器电容的因素：只由电容器本身的结构（$S$、$d$）与介质（$\varepsilon$）决定，与是否带电、带电量多少、板间电压高低均无关。
  • 电容的定义式：$C = \dfrac{Q}{U}$，描述电容器容纳电荷的本领。$Q$ 为一个极板所带电荷量的绝对值。
  • 恒压源与恒流源：
  • 与恒压电源并联时，电容器两端电压 $U$ 恒定不变。
  • 充电或放电电流的方向判断：依据电荷量 $Q$ 的增减，结合电源正负极方向判定。

解题方法与套路

  1. 明确变量与不变量：先判断电容器两端电压 $U$ 是否变化（若接恒压源则 $U$ 不变；若断开电源则 $Q$ 不变）。
  2. 由决定式判断电容变化：分析 $S$、$d$、$\varepsilon$ 的变化趋势，代入 $C = \dfrac{\varepsilon S}{4\pi k d}$，得出 $C$ 的变化。
  3. 由定义式推导 $Q$ 或 $U$ 的变化：
  4. $U$ 不变时，由 $Q = CU$ 得出 $Q$ 与 $C$ 同向变化。
  5. $Q$ 不变时，由 $U = \dfrac{Q}{C}$ 得出 $U$ 与 $C$ 反向变化。
  6. 判断电流方向（动态过程）：电容器充电（$Q$ 增大）时，电流从电源正极流向电容器正极板；放电（$Q$ 减小）时，电流从电容器正极板流出。根据图中标注的字母方向（M、N）匹配电流流向。

高频易错

  • 混淆电容的决定式与定义式：决定式用于分析电容自身的变化；定义式用于分析 $Q$、$U$ 随 $C$ 变化的关系。不能直接用定义式说“电容与 $Q$ 成正比、与 $U$ 成反比”。
  • 忽视电路状态：误以为电容器两极板间一定是断路就没有电流。实际上，在 $U$ 不变时，若 $C$ 变化将引起充放电，回路中会出现短暂电流。
  • 介质常数 $\varepsilon$ 与浓度的非单调关系：根据图像信息，$\varepsilon$ 与浓度可能反向变化（本题中浓度降低，$\varepsilon$ 增大），需紧扣曲线判断，而非想当然认定正比关系。
  • 电流方向与极板电荷增减关系弄反：正极板电荷量增加（充电）时，电流流入正极板；正极板电荷量减少（放电）时，电流流出正极板。切忌只看电源方向而不分析 $Q$ 变化。

代表题精讲

题目（2024-辽宁-05）：不导电溶液的相对介电常数 $\varepsilon$ 与浓度关系如图（a），平行板电容器两极板全部插入溶液，并与恒压电源、电流表构成回路（图b）。闭合开关S后，降低溶液浓度，判断各选项正误。

思路
- 由图像得出：降低浓度 → $\varepsilon$ 增大。
- 电容器结构 $S$、$d$ 未变，由决定式 $C = \dfrac{\varepsilon S}{4\pi k d}$ 得 $C$ 增大。
- 电容器接恒压电源，则 $U$ 不变，由 $Q = CU$ 得 $Q$ 增大。
- $Q$ 增大意味着电容器充电，电流方向应从电源正极经电流表流向电容器正极板，结合图（b）判断电流方向。

步骤
1. 从图（a）读取 $\varepsilon$ 随浓度降低而增大。
2. 代入决定式：$\varepsilon \uparrow \Rightarrow C \uparrow$，故选项A（电容减小）错误。
3. 电路为恒压源：$U$ 不变，故选项C（电势差增大）错误。
4. 由 $Q = CU$，$C \uparrow, U$ 不变 $\Rightarrow Q \uparrow$，故选项B（电荷量增大）正确。
5. 电容器充电，电流由电源正极流出，经N→M？ 需根据实物连接判定：图（b）中电源正极连接M端，负极连接N端。充电时正电荷向正极板M积聚，电流方向应为电源正极 → M → 电容器正极板 → 电容器负极板 → N → 电源负极，即 M→N？ 需仔细分析回路：充电电流从电源正极流出，经外部电路流入电容器正极板，则电流方向从电源正极至M，再经电容器内部至N？图（b）中电流表串联在M与电源正极之间，可知充电时电流从电源正极→电流表→M，即M点为高电势，电流由N→M？根据解析，电流方向为 N→M，说明充电电流从N流向M，即正电荷由电源正极经N进入电容器负极板？此中逻辑需要还原：由于相对介电常数增大，电容增大，要维持电压不变，电源对电容器补充电荷。电流方向实际由电源正极流出，经过N？这取决于电路具体串接方式。解析判定D错误，明确给出电流方向为 N→M。我们接受这一结论：充电时，电流方向为N→M，与题设M→N相反，故D错误。
6. 综上，正确选项为B。

点评/变式
- 本题巧妙结合图像信息，考查“不导电溶液”充当介质时电容的动态变化，需明确“不导电”意味着无法形成持续电流，但在电容充放电瞬间回路中仍有瞬时电流。
- 变式拓展：若将恒压电源改为断开开关、先充电后断开，再降低浓度，则 $Q$ 不变，$C$ 增大，$U = Q/C$ 减小。此类问题需牢抓“不变量”切换。
- 易错警示：很多考生凭直觉认为浓度降低电容减小，忽略了图像给出的 $\varepsilon$ 与浓度的具体关系，落入经验主义的陷阱。
