电容决定式

考点电容决定式权重6真题数1学科物理父主题静电场

考点定位

  • 父主题：静电场
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 平行板电容器的决定式：$C = \dfrac{\varepsilon_r S}{4\pi k d}$，式中 $\varepsilon_r$ 为相对介电常数（常简记为 $\varepsilon$），$S$ 为正对面积，$d$ 为板间距离，$k$ 为静电力常量。$C$ 与 $\varepsilon_r$、$S$ 成正比，与 $d$ 成反比。
  • 电容的定义式：$C = \dfrac{Q}{U}$（适用于一切电容器），$Q$ 与极板所带电荷量，$U$ 为两极板间电势差。
  • 两类动态问题
  • 电容器始终与恒压电源连接（$U$ 不变）：$C$ 变化 → $Q=CU$ 随之变化；
  • 电容器充电后与电源断开（$Q$ 不变）：$C$ 变化 → $U=Q/C$ 随之变化。
  • 介电常数与电容的关系：同一电容器，填入不同介质，$\varepsilon_r$ 越大，$C$ 越大。本题中降低溶液浓度 → $\varepsilon_r$ 增大 → $C$ 增大。

解题方法与套路

  1. 先挖出“不变”量：看电容器是“接恒压电源”还是“断开电源”。接恒压电源 → $U$ 不变；断开电源 → $Q$ 不变。
  2. 再分析 $C$ 怎么变：根据决定式 $C = \dfrac{\varepsilon_r S}{4\pi k d}$，判断 $\varepsilon_r$（或 $S$、$d$）的变化趋势，确定 $C$ 增大还是减小。
  3. 用定义式链式推理：由 $C = \dfrac{Q}{U}$，结合不变量，导出 $Q$ 或 $U$ 的变化。
  4. 判断充/放电与电流方向：
  5. $Q$ 增大 → 对电容器充电，电流从电源正极通过外电路流入电容器正极板；
  6. $Q$ 减小 → 电容器放电，电流从电容器正极板通过外电路流回电源负极。
  7. 观察电流表（或给定电路）的接线方式，确认电流“从哪儿流到哪儿”。

高频易错

  • 混淆 $U$ 不变与 $Q$ 不变的条件：看到“恒压电源”就锁定 $U$ 不变，不能因为介质变化就想当然地认为电压也变。
  • 介质导电性误解：题目中“不导电溶液”是指溶液本身不构成电流回路，但电容器仍可通过金属极板与外部电路进行充、放电，不影响电容的决定式。
  • $\varepsilon_r$ 与浓度的关系看反：曲线给出的是 $\varepsilon_r$–浓度关系，要先看自变量（浓度）降低时函数值（$\varepsilon_r$）如何变化，不要被图像形状迷惑。
  • 电流方向记反：充电时电流从电源正极流经外电路到达正极板，放电时方向相反。结合电流表正负接线柱规定判断“M→N”还是“N→M”。

代表题精讲

题目 2024·辽宁·5
不导电溶液的相对介电常数 $\varepsilon$ 与浓度曲线如图，平行板电容器两极板全部插入该溶液，并与恒压电源、电流表等构成电路。闭合开关 S，降低溶液浓度，判断电容、电荷量、电势差及电流方向。

思路
恒压电源 → $U$ 不变；降低浓度 → 查曲线得 $\varepsilon$ 增大；由决定式得 $C$ 增大；由 $Q=CU$ 得 $Q$ 增大，故电容器充电；充电电流从电源正极经电流表流入正极板，依图示即 N→M。

步骤
1. 确定不变量：电路始终接恒压电源，两极板间电势差 $U$ 恒定。
2. 由曲线：降低浓度，溶液的 $\varepsilon$ 增大。
3. 代入决定式 $C = \dfrac{\varepsilon S}{4\pi k d}$：$\varepsilon$ 增大 → $C$ 增大。故 A 项“电容减小”错误。
4. 由 $Q = CU$：$U$ 不变，$C$ 增大 → $Q$ 增大。故 B 项正确，C 项“电势差增大”错误。
5. 电荷量 $Q$ 增大，表明电容器正在充电。充电电流从电源正极出发，经电流表流入电容器正极板。结合电路图，电流方向为 N→M，故 D 项“M→N”错误。
答案 B

点评/变式
本题属于 $U$ 不变的电容动态问题，核心是把介质变化转化为 $\varepsilon$ 的变化。若保持 $Q$ 不变（断开电源），降低浓度会使 $C$ 增大，$U=Q/C$ 将减小。注意区分并熟练掌握两类动态的逻辑链条。
