电流与匝数成反比

考点电流与匝数成反比权重6真题数1学科物理父主题交流电 与 变压器

考点定位

  • 父主题：交流电 与 变压器
  • 权重 weight：6
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 理想变压器模型：无漏磁、无铜损铁损，输入功率等于输出功率。
  • 电压关系：$ \frac{U_1}{U_2} = \frac{n_1}{n_2} $ （与匝数成正比，适用于任意线圈之间）。
  • 电流关系：$ \frac{I_1}{I_2} = \frac{n_2}{n_1} $ （与匝数成反比，适用条件：只有一个副线圈）。
  • 功率关系：$ P_1 = P_2 $，即 $ U_1 I_1 = U_2 I_2 $ （普适，用于多副线圈时求原线圈电流）。
  • 交流电表的读数：均为有效值。原、副线圈的电压与电流均指有效值，与额定值一致。

解题方法与套路

  1. 由负载确立副线圈参量：若用电器正常工作（如灯泡正常发光），则副线圈电压 $U_2$ 等于额定电压，副线圈电流 $I_2$ 可由 $ I_2 = \frac{P_{\text{额}}}{U_{\text{额}}} $ 求出。
  2. 用电压比求原线圈电压：$ U_1 = \frac{n_1}{n_2} U_2 $。
  3. 用电流比求原线圈电流（仅一个副线圈时）：$ I_1 = \frac{n_2}{n_1} I_2 $。
    若有多组副线圈，则改用功率关系：$ I_1 = \frac{P_2 + P_3 + \dots}{U_1} $。
  4. 校验功率守恒：验证 $ U_1 I_1 = U_2 I_2 $，可快速排查计算错误。

高频易错

  • 电流反比关系的适用条件：必须只有一个副线圈。出现多个副线圈时，只能用功率关系 $ U_1 I_1 = U_2 I_2 + U_3 I_3 + \dots $ 求 $ I_1 $，谨防直接套用匝数反比。
  • 匝数比前后对应：电压比 $ \frac{U_1}{U_2} = \frac{n_1}{n_2} $，电流比 $ \frac{I_1}{I_2} = \frac{n_2}{n_1} $，易写颠倒。记住“电压跟匝数同序，电流反序”。
  • 有效值的理解：交流电表读数均为有效值。铭牌额定电压220V、额定功率22W均指有效值，直接参与计算，不要误带入峰值 $ \sqrt{2} $ 关系。
  • 混淆与等效电阻：原线圈电压 $U_1$ 是加在原线圈两端的电压（电压表示数），并非恒等于输入电源电压，尤其当原线圈串有电阻或电表有内阻时需仔细分析（本题为理想情况，可直接用）。

代表题精讲

1. 2011-新课标-04

题目：如图，理想变压器原副线圈匝数比 $ n_1 : n_2 = 1 : 2 $；副线圈灯泡额定电压220V、额定功率22W。闭合开关，灯泡正常发光。用 $U$ 和 $I$ 分别表示此时原线圈电压表和电流表的读数，则正确的是（ ）
A．$U=110\text{V},\ I=0.2\text{A}$　B．$U=110\text{V},\ I=0.05\text{A}$
C．$U=110\sqrt{2}\text{V},\ I=0.2\text{A}$　D．$U=110\sqrt{2}\text{V},\ I=0.2\text{A}$

思路：灯泡正常发光 → $U_2=220\text{V}$，$ I_2=\frac{P}{U_2} $；再用电压比求 $U$，用电流反比求 $I$。

步骤：
- 副线圈电压 $U_2 = 220\text{V}$（额定值）。
- 副线圈电流 $ I_2 = \frac{P}{U_2} = \frac{22}{220} = 0.1\text{A} $。
- 由电压比：$ \frac{U}{U_2} = \frac{n_1}{n_2} = \frac12 \Rightarrow U = \frac12 \times 220 = 110\text{V}$。
- 由一个副线圈电流反比：$ \frac{I}{I_2} = \frac{n_2}{n_1} = \frac21 \Rightarrow I = 2 \times 0.1 = 0.2\text{A}$。
答案A，注意易错选项B是将电压比错误套用到电流上（$I=\frac12 I_2=0.05\text{A}$），C和D混入了峰值。

点评/变式：
- 本题直接考查理想变压器的两个基本比例关系，属于基础题。
- 若原线圈串联电阻或电表内阻，则 $U$ 不再直接由匝数比决定，需结合闭合电路欧姆定律。
- 变式：副线圈接有滑动变阻器，调节时原线圈电流如何变？由 $ I_1 = \frac{n_2}{n_1} I_2 = \frac{n_2}{n_1} \cdot \frac{U_2}{R}$，$U_2$ 恒定，则 $I_1 \propto \frac1R$，可轻松判断。
