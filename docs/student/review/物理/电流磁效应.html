电流磁效应

考点电流磁效应权重10真题数1学科物理父主题磁场 与 安培力洛伦兹力

考点定位

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：10
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：选择5
  • 难度分布：易1

知识精要

  • 磁现象与磁场：磁体周围存在磁场，磁场对放入其中的磁体或电流有力的作用。磁体上磁性最强的区域叫磁极（$N$极和$S$极），任何一个磁体都有两个磁极，不存在磁单极子。
  • 地磁场：地球本身是一个大磁体，地磁北极在地理南极附近，地磁南极在地理北极附近。指南针的$N$极指向地理北极（地磁南极），说明地球周围存在磁场。
  • 电流的磁效应（奥斯特实验）：通电导线周围存在磁场，其磁场方向可由安培定则（右手螺旋定则）判断。通电直导线的磁场会使附近的小磁针发生偏转。
  • 磁化与磁场干扰：铁块等铁磁性物质在磁场中会被磁化，从而改变周围的磁场分布，因此指南针的指向会受到附近铁块、磁体或电流的干扰。

解题方法与套路

  1. 抓基本概念：逐一审读选项，判断是否违背物理学基本规律（如“磁单极子不存在”“电流周围有磁场”）。
  2. 联系实际现象：将选项描述与熟知的实验或生活现象对照（如通电导线使磁针偏转是奥斯特实验的直接结论，地磁场使指南针定向是常识）。
  3. 区分磁场来源与相互作用：分析指南针受哪些磁场（地磁场、铁块被磁化后产生的磁场、电流产生的磁场等）的影响，若有附加磁场，指南针指向必定偏离正常地磁方向。
  4. 多选验证：对于选择题，若判断出不止一个正确说法，需确认题目是否允许多选；注意正确说法的完整性和科学性。

高频易错

  • 磁单极子误区：误以为存在单独的$N$极或$S$极，实际上磁极总是成对出现。
  • 忽视铁块的磁化效应：认为铁块没有磁性就不影响指南针，实际上铁块在地磁场或其他磁场中易被磁化，会改变周围磁场，从而干扰指南针。
  • 混淆电流磁场与地磁场的关系：认为通电导线的磁场太弱或不影响磁针，实际上直导线电流的磁场足以使附近小磁针发生明显偏转（奥斯特实验）。
  • 误判地磁场方向与指南针指向：错误理解为指南针$N$极指向地理南极，或把地磁极与地理极完全等同，未注意地磁南北极与地理南北极的相反关系。

代表题精讲

代表题 2015-新课标Ⅱ-05

题目
指南针是我国古代四大发明之一。关于指南针，下列说明正确的是
A. 指南针可以仅具有一个磁极
B. 指南针能够指向南北，说明地球具有磁场
C. 指南针的指向会受到附近铁块的干扰
D. 在指南针正上方附近沿指针方向放置一直导线，导线通电时指南针不偏转

思路
本题是磁现象基础概念的综合判断，涉及磁极特性、地磁场、磁化及电流磁效应。应根据每一条说法的物理本质逐一分析真伪，注意本题为多选题，可能有两个正确选项。

步骤
1. 分析A：自然界不存在独立的磁单极子，任何磁体都有$N$、$S$两极，故A错误。
2. 分析B：指南针在自由静止时总是一端指南、一端指北，这是因为地球本身是一个大磁体，其磁场对磁针有力的作用，所以指南针指向南北直接说明地球具有磁场，故B正确。
3. 分析C：铁块属于铁磁性材料，在地磁场或指南针自身磁场的作用下会被磁化，磁化后的铁块产生附加磁场，必然干扰指南针附近的总磁场分布，从而影响其指向，故C正确。
4. 分析D：在指南针正上方沿指针方向放置一直导线并通电，通电直导线周围会产生磁场（电流的磁效应），该磁场对指南针有力的作用，会使指南针发生偏转（奥斯特实验原理），故D错误。
综合判断：正确选项为 B、C。

点评/变式
- 此题考查了磁现象最核心的几个知识点，错选项A和D往往是考生因知识模糊而误选的。
- 变式：若将D选项中“沿指针方向”改为“垂直指针方向”再提问，通电直导线仍会产生磁场，指南针依然会偏转（只是偏转方向和程度不同），原理不变。
- 延伸：铁块干扰指南针的实质是磁化产生的附加磁场，若换成铜块、铝块等非铁磁性物质则不会产生类似干扰。
