电源效率

考点定位

  • 父主题：恒定电流
  • 权重 weight：6
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 电源效率定义：电源的效率 $\eta$ 为外电路消耗的功率（输出功率 $P_{\text{出}}$）与电源总功率 $P_{\text{总}}$ 之比。
    $$\eta = \frac{P_{\text{出}}}{P_{\text{总}}} \times 100\%$$
  • 通用表达式：对于任何电路，$P_{\text{出}} = UI$（$U$ 为路端电压，$I$ 为干路电流），$P_{\text{总}} = EI$（$E$ 为电源电动势）。由此可得
    $$\eta = \frac{UI}{EI} = \frac{U}{E}$$ 即电源效率在数值上等于路端电压与电动势的比值。这一表达式与负载是否为纯电阻无关，具有普适性。
  • 纯电阻电路中的特殊形式：若外电路为纯电阻 $R$，内阻为 $r$，则 $U = \frac{E R}{R + r}$，代入可得
    $$\eta = \frac{R}{R + r} = \frac{1}{1 + \frac{r}{R}}$$ 效率随外电阻 $R$ 的增大而增大，当 $R = r$ 时输出功率最大，但此时效率仅为 $50\%$。
  • $U$–$I$ 图像中的效率获取：在路端电压 $U$ 随电流 $I$ 变化的实验图线中，纵轴截距即为电动势 $E$。图线上任一点对应的效率 $\eta = \frac{U_{\text{点}}}{E}$，直接从坐标刻度读出对应纵坐标之比即可，无需知道内阻 $r$ 的具体数值。
  • 适用条件：$\eta = U/E$ 适用于所有电路；$\eta = R/(R+r)$ 仅适用于纯电阻电路。遇到含有电动机、电解槽等非纯电阻元件时，必须使用 $\eta = U/E$。

解题方法与套路

此类试题通常围绕“从 $U$–$I$ 图像读取效率”或“由电阻关系求效率”，通用解法如下：

  1. 明确效率的本质：无论题目给出何种场景，优先写出 $\eta = \frac{P_{\text{出}}}{P_{\text{总}}}$。
  2. 推导普适公式：利用 $P_{\text{出}} = UI$，$P_{\text{总}} = EI$，立即得到 $\eta = \frac{U}{E}$。这一步是化解图像题或复杂电路题的关键。
  3. 提取电动势 $E$：
  4. 若有 $U$–$I$ 图线，$E$ 为纵轴截距（$I=0$ 时的 $U$）。
  5. 若已知若干组 $(U,I)$ 数据，可通过闭合电路欧姆定律 $U = E - Ir$ 求解 $E$。
  6. 确定目标状态的路端电压 $U$：
  7. 对于图像题，直接从图线上读取指定点对应的纵坐标 $U_a$、$U_b$ 等。
  8. 对于纯电阻电路，可由 $U = \frac{E R}{R+r}$ 计算，或由串联分压比例关系得出。
  9. 代入比值计算：$\eta = U/E$，必要时化为百分数。多个状态逐一计算再比对。
  10. 关注隐含条件：若题述“电源输出功率最大”，则隐含 $R=r$，此时 $\eta=50\%$；但效率自身可继续随 $R$ 增大而提升，注意区分。

高频易错

  • 混淆效率与输出功率：输出功率最大时效率仅为 $50\%$，并非最大；效率最高时（$R \to \infty$，断路）输出功率趋于零。两者无单调对应关系，切忌将“功率大”等同于“效率高”。
  • 滥用电阻比公式：$\eta = R/(R+r)$ 仅适用于纯电阻电路。只要电路中出现电动机、电解池等元件，必须回到 $\eta = U/E$ 进行计算，否则必然出错。
  • 忽略纵轴刻度偏移：部分 $U$–$I$ 图像纵轴起点不为零，此时纵轴“截距”仍是电动势 $E$，但读取电压差值时需对照实际坐标刻度，不可直接用几何长度估算比值。
  • 混淆内、外电压：效率公式中分子是路端电压 $U$，不是内电压 $U_r$。有些题目给出内电压图像或内电压数据，若不注意区分就会把 $\eta$ 算成 $U_r/E$ 而丢分。
  • 图像中的效率比较：在同一 $U$–$I$ 图线上，越靠近纵轴（电流越小）的点，其路端电压越接近 $E$，效率越高；不可误认为图线上斜率变化直接对应效率变化。

代表题精讲

代表题 2010·新课标Ⅰ·06

题目：
电源效率 $\eta$ 定义为外电路电阻消耗的功率与电源总功率之比。在测电源电动势和内阻的实验中得到的 $U$–$I$ 图线如图所示，图中 $U$ 为路端电压，$I$ 为干路电流，$a$、$b$ 为图线上的两点，相应状态下电源的效率分别为 $\eta_a$、$\eta_b$。由图可知 $\eta_a$、$\eta_b$ 的值分别为（ ）
A. $\frac{3}{4}$、$\frac{1}{4}$　B. $\frac{1}{3}$、$\frac{2}{3}$　C. $\frac{1}{2}$、$\frac{1}{2}$　D. $\frac{2}{3}$、$\frac{1}{3}$
（图线特征：纵轴截距为 $E$，$a$ 点纵坐标为 $\frac{2}{3}E$，$b$ 点纵坐标为 $\frac{1}{3}E$）

思路：
直接利用效率的通用表达式 $\eta = \frac{U}{E}$。从 $U$–$I$ 图像读出 $a$、$b$ 两点对应的路端电压与电动势的比例关系，代入计算即可，无需涉及内阻或电流值。

步骤：
1. 写出效率表达式：$\eta = \frac{UI}{EI} = \frac{U}{E}$。
2. 观察 $U$–$I$ 图线，纵轴截距表示电动势 $E$。
3. 图中 $a$ 点对应的路端电压 $U_a = \frac{2}{3}E$，故 $\eta_a = \frac{U_a}{E} = \frac{2}{3}$。
4. $b$ 点对应的路端电压 $U_b = \frac{1}{3}E$，故 $\eta_b = \frac{U_b}{E} = \frac{1}{3}$。
5. 比对选项，答案为 D。

点评/变式：
- 本题核心在于认识到电源效率等于路端电压与电动势之比，这一结论直接绕开了对内阻和电流的处理，使图像题瞬间简化。
- 变式一：若图像给出 $a$、$b$ 两点电流值，求此时电源内阻消耗的功率之比，仍可借助 $\eta$ 与内外电压关系快速求解。
- 变式二：将条件改为“输出功率相等”的两点，则需结合 $U$–$I$ 图线的矩形面积关系，此时两点效率一般不相等，效率高低由对应电压高低决定。
