电表改装

考点电表改装权重10真题数2学科物理父主题实验 与 测量

考点定位

  • 父主题：实验 与 测量
  • 权重 weight：10
  • 真题数：2；年份跨度：2018–2022
  • 出现题位：选择9 选择10
  • 难度分布：中2

知识精要

  • 电流表改装成大量程电流表 将内阻为 $R_g$、满偏电流为 $I_g$ 的表头改装成量程为 $I$ 的电流表（$I>I_g$），必须在表头两端并联一个分流电阻 $R$。 由并联电压相等：$I_g R_g = (I - I_g)R$，得 $R = \dfrac{I_g}{I - I_g}R_g$。 改装后电流表内阻 $R_A = \dfrac{R_g R}{R_g + R}$。
  • 电流表改装成电压表 将同一表头改装成量程为 $U$ 的电压表，必须串联一个分压电阻 $R$。 由串联电流相等：$U = I_g(R_g + R)$，得 $R = \dfrac{U}{I_g} - R_g$。 改装后电压表内阻 $R_V = R_g + R = \dfrac{U}{I_g}$。
  • 多用电表的挡位设计 一表头可通过切换并联电阻 $R_1$ 得到电流挡（并联分流），再在电流挡基础上串联电阻 $R_2$ 得到电压挡。此时，改装后的电流挡整体视为新的“表头”（量程 $I$，内阻 $R_A$），串联分压后实现电压挡：$U = I(R_A + R_2)$。
  • 伏安法测电阻与分压接法 要求电压、电流从零开始连续调节时，控制电路应使用分压式接法，滑动变阻器一般选小阻值（如 $10\,\Omega$），以保证调节线性度和细度。

解题方法与套路

  1. 审清原表头参数：明确微安表或毫安表的量程 $I_g$、内阻 $R_g$。
  2. 确定改装目标：需改成多大的电流量程 $I$ 或电压量程 $U$。
  3. 选择改装方式：
  4. 扩大量程为电流表 → 并联分流电阻，利用 $I_gR_g = (I - I_g)R$。
  5. 扩大量程为电压表 → 串联分压电阻，利用 $U = I_g(R_g + R)$ 或改装后的满偏电流乘总电阻。
  6. 多挡位改装流程：先计算电流挡并联电阻 $R_1$，再计算改装后电流表的内阻 $R_A = \dfrac{R_gR_1}{R_g+R_1}$。将量程 $I$ 与 $R_A$ 作为新表头，根据电压挡量程 $U$，列 $U = I(R_A + R_2)$，解得 $R_2$。
  7. 读数与数据处理：注意电表改装后，表盘刻度对应的实际量程比例。计算电阻时，利用欧姆定律 $R = \dfrac{U}{I}$，注意单位换算和有效数字保留要求。

高频易错

  • 并联与串联混淆：改装电流表时，习惯性串联电阻，导致量程错误。正确：分流需并联，分压需串联。
  • 改装后的内阻计算：改装后电流表内阻不是简单的 $R_g$ 与分流电阻并联值$R_{\text{并}}$，用它计算电压挡分压电阻时，必须以 $R_{\text{并}}$ 为表头内阻，总额定电流为扩程后的 $I$，并非原 $I_g$。
  • 滑动变阻器选错：要求“电流在 $0\sim5\,\text{mA}$ 连续可调”必须选用分压接法，变阻器选小阻值。若选 $1.5\,\text{k}\Omega$ 会调节困难，且无法从零开始。
  • 读数有效数字：电表读数必须根据最小分度值估读。如量程 $3\,\text{V}$，最小分度 $0.1\,\text{V}$，需读到 $0.01\,\text{V}$；量程 $1\,\text{mA}$，最小分度 $0.02\,\text{mA}$，估读到 $0.01\,\text{mA}$ 位。
  • 电阻箱阻值取值：计算结果需符合电阻箱的实际阻值范围与步进值，并按要求保留到个位。

代表题精讲

代表题 1：2022全国乙卷·10（电表改装+伏安特性）

题目：测约 $550\,\Omega$ 电阻 $R_x$ 在 $0\sim5\,\text{mA}$ 的伏安特性。器材：电压表（$3\,\text{V}$，内阻很大），电流表 A（$1\,\text{mA}$，$300\,\Omega$），电源 $E\approx4\,\text{V}$，滑动变阻器 $R$（$10\,\Omega$ 或 $1.5\,\text{k}\Omega$），定值电阻 $R_0$（$75\,\Omega$ 或 $150\,\Omega$），开关导线。

思路： (1) 电流需从零连续调节至 $5\,\text{mA}$，控制电路必须用分压接法，滑变选 $10\,\Omega$。 (2) 电流表量程需从 $1\,\text{mA}$ 扩展到 $5\,\text{mA}$，将定值电阻 $R_0$ 与 A 并联分流。计算得 $R_0=75\,\Omega$。 (3) 设计电路：滑动变阻器分压输出接在 $R_x$ 与改装后电流表串联支路的两端（或安培表内接/外接，依内阻而定。题中电压表内阻很大，电流表内阻改装后较小，可用安培表外接或内接，按常规伏安法）。由给定器材符号连线。 (4) 读数：电压表用 $3\,\text{V}$ 量程，读数为 $2.30\,\text{V}$（示例图(b)）；改装电流表读数为 $4.20\,\text{mA}$（实际图片中可能为 $4.20\,\text{mA}$，需按分度估读），此电流为流过干路总电流，但因为电流表改装后并联，流过 $R_x$ 的电流即为总电流 $4.20\,\text{mA}$。电阻 $R = \dfrac{U}{I} = \dfrac{2.30}{4.20\times10^{-3}}\,\Omega \approx 548\,\Omega$（保留三位有效数字）。

点评/变式： 明确改装后的电流表与待测电阻串联，流过电流即为改装表的示值乘以倍率。若改装表示值指原表头偏转格数，需换算为实际电流。本题关键是从“0~5 mA 连续可调”锁定分压接法与小滑变。

代表题 2：2018新课标Ⅱ·09（组装多用电表）

题目：用微安表头（$100\,\mu\text{A}$，$900\,\Omega$），电阻箱 $R_1$、$R_2$，组装 $1\,\text{mA}$ 电流挡和 $3\,\text{V}$ 电压挡的多用电表。*为公共接线柱，a、b 分别为电流挡和电压挡接线柱。

思路： (1) 电流挡：微安表并联 $R_1$ 构成 $1\,\text{mA}$ 电流表；电压挡：在电流挡基础上串联 $R_2$ 构成 $3\,\text{V}$ 电压表。 (2) 画电路：a 接微安表与 $R_1$ 并联后的一个端点，b 接该并联组合再串联 $R_2$ 的端点，* 为公共端。 (3) 计算：$I_g R_g = (I - I_g)R_1 \Rightarrow 100 \times 900 = (1000-100)R_1$，得 $R_1 = 100\,\Omega$。改装后电流表内阻 $R_A = \frac{900 \times 100}{900+100}=90\,\Omega$。电压挡：$3\,\text{V} = 1\,\text{mA} \times (90 + R_2)$，得 $R_2 = 2910\,\Omega$。

点评/变式： 注意多挡位共用表头，电压挡是在电流挡基础上构建，不要误用微安表直接串联大电阻得到 $3\,\text{V}$（那样量程会出错）。同时注意电阻箱取值保留个位。
