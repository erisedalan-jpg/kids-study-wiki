  • 父主题：恒定电流

知识精要

  • 电路原理图：用统一规定的图形符号表示电路元件，用连线反映实际连接的电路图。画图时导线应横平竖直，尽量减少交叉；元件符号要规范；必须准确反映串、并联关系与电表测量对象。
  • 伏安法测电阻：$R_x = \frac{U_x}{I_x}$，若电流表外接则测量值偏小，内接则测量值偏大。本实验未直接使用电流表，而是通过与已知电阻 $R_0$ 串联，利用电压表分别测两端电压间接求流：$I_0 = \frac{U_1}{R_0}$，由串联 $I_x = I_0$ 得 $R_x = \frac{U_2}{I_0} = \frac{U_2}{U_1}R_0$。
  • 电压表内阻影响：电压表内阻并非无穷大，会引入分流。考虑内阻时，通过 $R_0$ 所在支路的总电流 $I = \frac{U_1}{R_0} + \frac{U_1}{r_1}$，$R_x$ 所在支路的总电流 $I = \frac{U_2}{R_x} + \frac{U_2}{r_2}$，由串联电流相等可解出真实 $R_x$。
  • 滑动变阻器接法：分压式接法（一上两下或一上一下的动端与两端形成分压）可从 $0$ 开始连续调节电压，适合要求电压从零起调或大范围调节的实验；限流式接法仅串入一部分电阻。本实验采用分压式接法，初始时应使滑动头置于输出电压最小的位置（最右端）。

解题方法与套路

  1. 定元件、理路径
    从电源正极出发，沿导线依次识别经过的开关、滑动变阻器、电阻箱、待测电阻等，分清干路与支路。电压表最后补在待测元件两端。
  2. 明测量、画框架
    确定各表测量的物理量：如电压表 $\text{V}_1$ 并联在电阻箱 $R_0$ 两端，电压表 $\text{V}_2$ 并联在 $R_x$ 两端。先串联部分、再并联部分，画出主体串联回路。
  3. 规范符号、平直布线
    滑动变阻器按分压接法画出三个接线柱：下两接线柱接电源，动端接线柱接负载。电阻箱用规定符号，一般元件用通用符号。导线避免斜线和多余交叉。
  4. 推公式、分两态
  5. 不计电压表内阻：$R_x = \frac{U_2}{U_1}R_0$（纯串联电流相等）。
  6. 计及电压表内阻：由 $\frac{U_1}{R_0}+\frac{U_1}{r_1}=\frac{U_2}{R_x}+\frac{U_2}{r_2}$ 导出 $R_x = \frac{U_2R_0r_1r_2}{U_1r_2(r_1+R_0)-U_2R_0r_1}$。

高频易错

  • 分压接法的初始安全位置：闭合开关前，分压器滑动触头应置于负载分压最小的一端（本题“最右端”），防止电压表过载。不能随意放在中点。
  • 电压表分流勿遗漏：题目明示“电压表内阻都很大”，但第（Ⅲ）问明确要求考虑内阻，必须用并联分流处理，误认为电压表完全理想会导致失分。
  • 张冠李戴：$U_1$ 与 $U_2$ 必须一一对应到 $R_0$ 和 $R_x$ 两端电压，若在实物图中读错电压表编号，表达式会写反。
  • 原理图与实物接线不一致：实物图中导线在接线柱上的实际连接方式必须原样平移为原理图的电气连接，尤其分压器的上下接线柱不能混淆。
  • 公式变形错漏：推导计及内阻的 $R_x$ 时，代数整理步骤易出错，最好先写出等式再移项，最后整体表达成 $R_x=\cdots$，避免正负号或分母遗漏项。

代表题精讲

题目（2008·全国Ⅱ·10）

利用两个内阻很大的相同量程电压表、电阻箱 $R_0$（初始值与待测电阻 $R_x\approx500\Omega$ 接近）和分压式滑动变阻器测 $R_x$。按给定实物连线，操作步骤：滑变置最右端→合开关→左移使两表明显偏转→记示数 $U_1$、$U_2$→多次测量。要求画出电路原理图、写出不计和计及电压表内阻时 $R_x$ 的表达式。

思路

根据实物连线确定电流路径：电源正极→开关→滑动变阻器（一上一下和另一固定端），分压输出端分别接 $R_0$ 和 $R_x$ 的串联组合。电压表 $\text{V}_1$ 并接在 $R_0$ 两端，$\text{V}_2$ 并接在 $R_x$ 两端。不计内阻时，串联电流 $I = U_1/R_0 = U_2/R_x$。计及内阻时，电压表相当于在 $R_0$、$R_x$ 上各并联了一个分流电阻 $r_1,r_2$，利用两支路总电流相等列式。

步骤

  1. 画原理图：先绘出电源、开关、滑动变阻器分压接法（下端两接线柱全接电源，上端一接线柱接负载）。再将电阻箱 $R_0$ 和 $R_x$ 串联后接在分压输出端与电源负极之间。最后补充电压表 $\text{V}_1$ 并联在 $R_0$ 两端、$\text{V}_2$ 并联在 $R_x$ 两端。
  2. 不计电压表内阻：
    串联电流 $I = \frac{U_1}{R_0}$，且 $R_x$ 两端电压为 $U_2$，故
    $$R_x = \frac{U_2}{I} = \frac{U_2}{U_1}R_0.$$
  3. 计及电压表内阻：
    通过 $R_0$ 所在并联部分的总电流
    $$I = \frac{U_1}{R_0} + \frac{U_1}{r_1},$$
    通过 $R_x$ 所在并联部分的总电流
    $$I = \frac{U_2}{R_x} + \frac{U_2}{r_2}.$$
    二者相等，联立
    $$\frac{U_1}{R_0} + \frac{U_1}{r_1} = \frac{U_2}{R_x} + \frac{U_2}{r_2},$$
    移项解出
    $$\frac{U_2}{R_x} = \frac{U_1}{R_0} + \frac{U_1}{r_1} - \frac{U_2}{r_2},$$
    取倒数并整理得
    $$R_x = \frac{U_2 R_0 r_1 r_2}{U_1 r_2 (r_1 + R_0) - U_2 R_0 r_1}.$$

点评/变式

该题核心在于将实物接线转换为原理图，并利用串联分压和并联分流原理建立方程。计及内阻的推导中，很多考生误用 $U_1/R_0 = U_2/R_x$ 直接修正，而忽略电压表分流路径，导致错误。
变式：若将电压表换成电流表，并已知电流表内阻，可由 $U=I_1(R_0+R_A)$ 测电压，同样可推 $R_x$。或者将电阻箱与待测电阻并联，电流表测总电流和一支路电流，依据分流关系求解，原理相通。
