电路设计

考点定位

  • 父主题：恒定电流
  • 权重 weight：11
  • 真题数：2；年份跨度：2015–2022
  • 出现题位：选择10
  • 难度分布：中2

知识精要

  • 滑动变阻器的分压接法：要求被测电阻的电压或电流从零开始连续可调，或被测电阻阻值远大于滑动变阻器最大阻值时，必须采用分压式接法。此时滑动变阻器应选阻值较小的，便于精细调节。
  • 电表改装（电流表扩程）：已知内阻 $R_g$ 的电流表，并联一个分流电阻 $R_0$ 可扩大其量程。若原量程为 $I_g$，欲改为 $I$，则 $I_g R_g = (I - I_g)R_0$。本题利用定值电阻作为分流电阻实现电流表量程扩大。
  • 电压表半偏法测内阻原理：利用待测电压表与电阻箱串联，先让电压表满偏，保持滑变器滑片不动，断开电阻箱短路开关（或接入电阻箱），调节电阻箱使电压表半偏，此时电压表内阻近似等于电阻箱阻值。其成立条件为滑动变阻器总阻值远小于电压表内阻，即保持并联支路两端电压几乎不变。
  • 误差分析（半偏法）：实际调节电阻箱使电压表半偏时，并联部分总电阻增大，分压变大，电阻箱两端电压大于电压表电压，故电阻箱阻值大于电压表真实内阻，即 $R_v' > R_v$。
  • 实验器材选择：电源电动势要略大于电压表量程；滑动变阻器阻值选择需满足分压调节细度要求；定值电阻的选取要满足改装后量程和安全要求。

解题方法与套路

  1. 审清实验目的与要求：明确是测伏安特性还是测电表内阻，关注“0~某范围连续可调”等关键字眼，直接确定分压接法。
  2. 分析待测元件与电表量程的匹配：估算最大电流、电压值，若电流表量程不足，需用已知内阻的电流表并联定值电阻扩程；若电压表量程不足可考虑改装或半偏法。
  3. 选择滑动变阻器接法及阻值：
  4. 要求电压/电流从零开始 → 分压式。
  5. 分压式优先选总阻值较小的滑动变阻器（使得负载上电压随滑片移动接近线性变化，调节方便）。
  6. 电表改装计算：根据 $I_g R_g = (I - I_g)R_0$ 快速选择合适的分流或分压电阻。
  7. 连接电路图：按“电源→开关→滑动变阻器分压端→待测支路”逐次连接，注意电表正负接线柱。
  8. 读数与数据处理：读电表示数时注意量程、最小分度及估读规则；利用伏安关系 $R_x = U_x / I_x$ 计算阻值，注意有效数字。
  9. 误差归因：半偏法类问题紧扣“电压是否严格不变”或“电流是否严格不变”进行分析，得出测量值与真实值的大小关系。

高频易错

  • 滑动变阻器接法选错：题目给出“0~5mA范围内连续可调”明确要求分压，却误画成限流式接法。
  • 分压电路中滑动变阻器阻值选取不当：选大了（如1.5 kΩ）会使负载电压难以从零开始平缓调节，应选10 Ω。
  • 改装电流表时定值电阻阻值算错：将分流电阻当成与电流表串联，或代入错误量程进行计算。正确应为并联分流，且改装后总电流等于原表满偏电流与并联电阻电流之和。
  • 半偏法误差方向混淆：测电压表内阻，认为断开 $S_2$ 后并联部分电压不变，实际上串联电阻箱后该支路总电阻增大，分到的电压变大，导致测量值偏大，错误地判断为“偏小”或“等于”。
  • 电表示数估读不准确：电压表3V量程，1分度0.1V，需估读到0.01V；电流表1mA量程，1分度0.02mA，应估读到0.002mA（或半格估读），容易少估或多估。
  • 有效数字保留错误：计算 $R_x$ 时，代入测量值后结果要求保留3位有效数字，忽略计算过程中的有效数字规则。

代表题精讲

题目（2022·全国乙卷）：探究阻值约550Ω的 $R_x$ 在0~5mA范围内的伏安特性。给出电压表（3V，内阻很大）、电流表（1mA，内阻300Ω）、电源（4V，内阻不计）、滑动变阻器（10Ω或1.5kΩ）、定值电阻（75Ω或150Ω）等。完成电路设计、仪器选择并读表计算阻值。

思路：
① 0~5mA连续可调 → 滑动变阻器分压接法，应选最大阻值小的10Ω。
② 电流表量程1mA < 5mA，需扩程。将定值电阻并联在电流表两端作为分流电阻。扩程后总电流 $I=1\text{mA} + \frac{1\text{mA} \times 300\Omega}{R_0}$，令 $I=5\text{mA}$ 得 $R_0=75\Omega$，故定值电阻选75Ω。
③ 电压表直接测 $R_x$ 两端电压，电压表内阻很大，电流表（连同并联的 $R_0$）外接，即电流表外接法。
④ 读电压表：量程3V，指针指在1.60V（估读到0.01V）。电流表：量程1mA，实际刻度0.64mA，因并联分流，流过 $R_x$ 的电流为总电流，$I_x = 0.64\text{mA} \times \frac{300+75}{75} = 3.20\text{mA}$。计算 $R_x = 1.60 / (3.20 \times10^{-3}) = 500\Omega$ （保留3位有效数字）。

步骤：
1. 确定分压接法，选滑动变阻器 $R=10\Omega$。
2. 计算扩程电阻：$R_0 = \frac{I_g R_g}{I-I_g} = \frac{1\times300}{5-1}=75\Omega$，选75Ω。
3. 画出电路：滑动变阻器下两接线柱接电源，上端与滑片接出分压电压；电压表直接并在 $R_x$ 两端；电流表与75Ω并联后再与 $R_x$ 串联。注意电表极性。
4. 读数：电压表1.60V，电流表读数0.64mA，则 $I_x = 0.64 \times \frac{375}{75}=3.20\text{mA}$。
5. 计算：$R_x = \frac{1.60}{3.20\times10^{-3}} = 500\Omega$。

点评/变式：
本题关键是将“电流范围连续可调”与“分压接法+小阻值滑变器”捆绑，将“电流表量程扩大”与“并联定值电阻”运算结合。变式可考：若电流表内阻未知，能否用此方案扩程？若滑动变阻器选1.5kΩ，调节会出现什么现象？还可将电压表量程扩大作为考点。

题目（2015·新课标Ⅱ）：利用半偏法测电压表内阻，提供待测电压表（3V，内阻约3000Ω）、电阻箱（0~99999.9Ω）、滑动变阻器（100Ω，2A）、电源（6V，内阻不计），要求补充电路并完成步骤和误差分析。

思路：
半偏法测电压表内阻，需要先让电压表满偏，保持供电部分状态不变，通过串联电阻箱分压使电压表半偏。电路设计：待测电压表与电阻箱串联，开关 $S_2$ 与电阻箱并联（用于短路/接入），然后整体与滑动变阻器分压部分并联。滑动变阻器采用分压接法以便调节电压，且其阻值（100Ω）远小于电压表内阻（~3000Ω），才能近似认为接入电阻箱后并联支路端电压不变。
误差：接入电阻箱后，并联部分总电阻增大，分压增大，电压表两端电压略低于原先满偏时的电压，导致电阻箱分压大于电压表分压，因此 $R_v' > R_v$。

步骤：
1. 补全电路：电源串接开关，滑动变阻器以分压式连接；待测电压表与电阻箱串联，开关 $S_2$ 并接在电阻箱两端；电压表与电阻箱串联支路接于滑动变阻器输出端。
2. 实验操作步骤：移动滑片使分压最小，闭合 $S_1$、$S_2$，调节滑变器使电压表满偏；保持滑变器滑片位置不变，断开 $S_2$，调节电阻箱使电压表半偏；读取电阻箱示数即为测得内阻。
3. 误差判断：测量值大于真实值，因为电压表所在支路总电阻变大，分得电压变大，导致电阻箱上电压大于满偏电压的一半。

点评/变式：
半偏法测电压表内阻的误差根源在于“并联支路电压不能绝对恒定”，减小误差的方法是使滑动变阻器总阻值远小于待测表内阻，这正是器材选择的深层逻辑。变式可考电流表半偏法测内阻，电路结构对称但误差方向相反（$R_g' < R_g$），需对比理解。
