磁场

考点磁场权重23真题数3学科物理父主题磁场 与 安培力洛伦兹力

考点定位

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：23
  • 真题数：3；年份跨度：2017–2017
  • 出现题位：选择5 选择7 选择8
  • 难度分布：难1 中2

知识精要

  • 磁场的基本性质：磁感应强度 $B$ 描述磁场强弱和方向，单位 $T$。磁场对电流和运动电荷有力的作用。
  • 安培力：通电直导线在匀强磁场中所受安培力 $F = BIL\sin\theta$，其中 $\theta$ 为电流方向与磁场方向的夹角，方向由左手定则判定。
  • 洛伦兹力：运动电荷在磁场中受力 $F = qvB\sin\theta$，$\theta$ 为速度方向与磁场方向夹角。洛伦兹力总与速度垂直，永不做功。带电粒子垂直进入匀强磁场时，做匀速圆周运动，基本方程 $qvB = m\dfrac{v^2}{r}$，可得轨道半径 $r = \dfrac{mv}{qB}$，周期 $T = \dfrac{2\pi m}{qB}$（与速度无关）。
  • 动生电动势：导体在磁场中切割磁感线时，产生的感应电动势 $E = BLv$（$B$、$L$、$v$ 两两垂直），方向由楞次定律或右手定则判断。
  • 安培力与电磁驱动的联系：通电线圈在磁场中受安培力力矩作用而转动，其连续转动需要换向（如“刮漆”方式实现电流方向的周期性变化）。

解题方法与套路

  1. 带电粒子在圆形磁场中的轨迹圆分析法
  2. 画出粒子的运动轨迹，利用出射点分布范围确定轨迹圆半径与磁场圆半径的几何关系。
  3. 常见情形：速率变化→轨迹圆半径变化→相同入射点下，出射点范围对应不同的圆心角。

  4. 由 $r = \dfrac{mv}{qB}$，速度比等于半径比，将物理量转化为几何量的比值。

  5. 线框切割磁感线的多阶段运动分析

  6. 从 $E-t$ 图像获取时间信息，结合线框边长得出匀速运动速度：$v = \dfrac{L}{t}$（$L$ 为进入或离开过程的位移）。
  7. 利用 $E=BLv$ 计算磁感应强度 $B = \dfrac{E}{Lv}$。
  8. 根据电动势的正负（对应感应电流方向），用楞次定律（“增反减同”或“来拒去留”）反推原磁场方向。

  9. 在有感应电流的时间段内，安培力 $F = BIL = B\dfrac{E}{R}L$，结合电路总电阻求解。

  10. 简易电动机（安培力驱动）的连续转动判断

  11. 核心：线圈通电后受安培力转矩而加速转动，每转过半圈后需改变电流方向或切断电流，才能持续同向转动。
  12. 处理“换向”技巧：只刮掉转轴一侧的绝缘漆（如一侧全刮，另一侧只刮下面），可让线圈每半圈通电一次，另半圈靠惯性转过。

高频易错

  • 圆形磁场中速度比问题：容易错误地将出射点对应的圆弧弦长直接当作轨迹圆直径，忽略轨迹圆的圆心不在磁场圆心上，导致几何关系错误。必须抓住入射点、出射点与两个圆心构成的几何图形。
  • $E-t$ 图像的理解：$E$ 为零的阶段不一定表示线框静止，可能是 $ab$ 和 $cd$ 边同时切割磁感线且电动势抵消（完全在匀强磁场中），务必结合线框边长和运动时间判断线框位置。
  • 楞次定律判定磁场方向：电动势的正负代表感应电流的流向（通常规定顺时针为“+”），判断原磁场方向时应严格按照“感应电流的磁场阻碍磁通量变化”的逻辑，不可凭感觉乱猜。
  • 安培力计算时忘记有效长度或有效电阻：线框切割时只有一条边产生电动势，但安培力作用在通电导线上，必须用回路总电阻求电流，再用该力臂长度计算安培力。
  • 电动机的换向原理：误以为全刮掉绝缘漆的线圈能连续转动；实际这样会使电流方向在半圈后不变，安培力方向反向，导致线圈来回摆动而无法持续转动。

代表题精讲

第1题（2017-新课标Ⅱ-05）

题目：圆形匀强磁场，P 为边界上一点。相同粒子以速率 $v_1$ 射入，出射点分布在六分之一圆周；以 $v_2$ 射入，出射点分布在三分之一圆周。求 $v_2 : v_1$。
思路：速率越大→轨迹圆半径越大→从 P 点出射的范围越大。将分布弧长对应圆心角转化为轨迹圆半径与磁场圆半径的关系，再利用半径正比于速度。
步骤：
- 设磁场圆半径为 $r$。当轨迹半径为 $R_1$ 时，最远出射点 M 对应 $\angle POM = 60^\circ$，由几何关系得 $R_1 = \dfrac{r}{2}$。
- 当轨迹半径为 $R_2$ 时，最远出射点 N 对应 $\angle PON = 120^\circ$，得 $R_2 = \dfrac{\sqrt{3}}{2}r$。
- 由 $R = \dfrac{mv}{qB}$ 知 $v \propto R$，故 $v_2 : v_1 = R_2 : R_1 = \sqrt{3} : 1$。
点评/变式：此题是典型的“旋转圆”模型，即入射速度大小固定、方向任意，轨迹圆平动变为绕入射点的转动。临界条件由轨迹圆与磁场圆相交弧长确定。变式可改为已知速度比求角度范围，或更改磁场形状（如正方形）。

第2题（2017-新课标Ⅱ-07）

题目：两条平行虚线间的匀强磁场，正方形线框 cd 边进入磁场开始计时，给出 $E-t$ 图。判断磁感应强度大小、速度、磁场方向和 $t=0.4$ ~ $0.6$ s 内的安培力。
思路：从 $E-t$ 图读出时间段，结合边长算速度和 $B$；利用电动势正负和楞次定律判磁场方向；在对应时间段用欧姆定律和安培力公式求解力。
步骤：
- 由图知：$0$~$0.2$ s 只有 cd 边切割，$E=0.01$ V，历时 $0.2$ s 进入，线框边长 $L=0.1$ m，速度 $v = L/0.2 = 0.5$ m/s。
- 由 $E = BLv$ 得 $B = E/(Lv) = 0.01/(0.1\times0.5) = 0.2$ T，排除选项 A。
- $0.2$~$0.4$ s 电动势为零→线框完全在磁场内；$0.4$~$0.6$ s 电动势为负→ ab 边切割出磁场，感应电流方向与进入时相反。结合进入时顺时针为正，用楞次定律判断原磁场方向垂直纸面向外，C 正确。
- $t=0.4$~$0.6$ s 内，$E=0.01$ V，总电阻 $R=0.005\,\Omega$，电流 $I=E/R=2$ A，安培力 $F = BIL = 0.2\times2\times0.1=0.04$ N，D 错误。
点评/变式：此题融合 $E-t$ 图像分析与电磁感应多过程，关键是不将电动势为零误解为静止，并能根据方向推断磁场。变式可改为线框从静止加速进入磁场，结合动力学与能量。

第3题（2017-新课标Ⅱ-08）

题目：自制简易电动机，线圈绕制引出转轴，永磁铁在下方，如何刮绝缘漆使线圈能连续转动。
思路：线圈转动受安培力矩驱动，每转半圈后若电流方向不变，安培力会反向阻碍转动；必须通过只在一侧刮漆实现半圈通电、半圈断电的“换向”作用。
步骤：
- 分析线圈通电：左侧导线电流向外，右侧向内，根据左手定则（磁场竖直向上），左侧受向上力，右侧向下，形成顺时针力矩。
- 转过半圈后，原左侧导线到右侧，电流方向变为向内，此时若仍有电流，安培力力矩将反向，无法继续转动。
- 正确刮漆方法：将一侧转轴（如左轴）上下绝缘漆全刮掉（始终与电路连通），另一侧转轴（如右轴）只刮下侧漆。这样每转半圈，只有半圈有电流，另半圈靠惯性转过，实现连续同向转动。选项 D 正确。
点评/变式：这是安培力驱动的经典“科挂电动机”，核心是理解“机械换向”。变式可要求设计不同刮漆方式实现反转，或分析全刮漆时线圈的运动情况（来回摆动）。
