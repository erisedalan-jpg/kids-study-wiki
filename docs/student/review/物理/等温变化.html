等温变化

考点等温变化权重46真题数5学科物理父主题热学

考点定位

  • 父主题：热学
  • 权重 weight：46
  • 真题数：5；年份跨度：2010–2019
  • 出现题位：填空13 填空14
  • 难度分布：中5

知识精要

  • 等温变化（玻意耳定律）
    一定质量的理想气体，温度保持不变时，压强与体积成反比：
    $$p_1V_1 = p_2V_2$$
    适用条件：质量一定、温度不变。

  • 适用对象
    单一气体或通过隔离法分割出的各部分气体。必须在变化前后正确选择研究对象，确保气体质量不变。

  • 压强确定——力平衡法

  • 在涉及活塞、水银柱等连接体时，通过对活塞或液柱作受力分析，列出平衡方程，求出气体压强。
  • 液柱压强：$p = p_0 \pm \rho g h$（h为液柱竖直高度，注意单位统一：mmHg、cmHg可直接用数值加和）。

  • 刚性杆连接的活塞：两侧压力差通过杆传递，利用整体或隔离平衡条件。

  • 体积关系——几何约束
    双缸、多气室系统中，通过活塞位移、液柱移动等建立气体体积变化间的几何关系，是求解的关键辅助方程。

  • 变质量问题处理
    如抽气、用气等情境，将变质量问题转化为质量不变问题：把用去的气体在某一压强下的体积换算出来，再利用玻意耳定律。常用虚拟“分装”思想：把最后剩余气与用走的气视为同一初始气体的等温膨胀。

解题方法与套路

  1. 拆分研究对象
    将多部分气体、活塞、水银柱等拆分为独立研究对象。对每一部分理想气体，明确“初态”和“末态”，标注$p, V$（温度不变时只标$p, V$）。

  2. 建立压强关系
    对活塞或液柱列力平衡方程（静止时合力为零）：

  3. 活塞：$p_{\text{气1}} S_1 + \dots = p_{\text{气2}} S_2 + \dots$。注意受力面积与气体作用面积对应。

  4. 水银柱：同一高度处压强相等，沿液柱向上向下加减$\rho g h$。

  5. 建立体积关系
    根据容器几何形状、活塞连杆刚性连接、液面升降等条件，写出各部分气体体积变化量的关系式。常见形式： $$V_1 - V_{10} = k(V_{20} - V_2)$$ 其中$k$由截面积决定。

  6. 应用玻意耳定律
    对每一部分气体列出等温变化方程： $$p_{\text{初}} V_{\text{初}} = p_{\text{末}} V_{\text{末}}$$ 若有变量，往往会联立出方程组。

  7. 联立求解并统一单位
    联立压强、体积、平衡方程求解。关键词有：“缓慢”移动意味着随时平衡、等温；“温度保持不变”直接锁定玻意耳定律；统一使用题目给定的压强单位（如cmHg、atm等）以避免换算错误。

高频易错

  • 混淆等温与等容条件
    看到温度不变直接用玻意耳定律是可行的，但如果容器体积不变（如U形管问题中部分气室），则为等容变化，压强与温度的关系改用查理定律。真题中常混搭出现，要分阶段识别。

  • 压强平衡时忽略受力面积
    用刚性杆连接的两个活塞，两端气体压力为$p_1S_1$、$p_2S_2$，列平衡时务必乘以各自的面积，不能直接认为$p_1 = p_2$。杆连接时，整体列式或分别列式要注意力传递关系。

  • 体积关系错误
    双缸问题中，两活塞移动导致的体积变化量之比等于横截面积之比。没写出准确的几何关系会使方程无法闭合。典型错误：未考虑负号，误写成$V_1 + V_2 = \text{const}$。

  • 变质量问题的处理失误
    在使用气瓶供气的情境中，直接套用$pV = \text{const}$而不注意气体质量减少。正确做法是假想将用掉的氧气“收集”到同一压强下计算体积，再与每天用量比较。

  • 液柱高度差的压强方向
    U形管中，同一水平面压强相等，由已知液面高度差折算压强。易错点：方向搞反导致$p = p_0 \pm \rho g h$符号错。

代表题精讲

题1：2019-新课标Ⅱ-14（双活塞连杆+抽气）

题目：两汽缸截面积分别为$2S$和$S$，用刚性杆连接两活塞，分隔出氢气、空气、氮气。平衡时氮气$p_0, V_0$，氢气$2V_0$，空气压强$p$。缓慢抽走全部空气，温度不变，求抽气前氢气压强及抽气后氢气压强和体积。

思路
（i）抽气前：取两活塞整体或隔离分析力平衡，得到氢气压强。
（ii）抽气后：空气消失，氢气、氮气均发生等温变化。对两活塞重新列出平衡方程（氮气与氢气压强关系），再分别对氢气、氮气用玻意耳定律，配合活塞移动导致的体积约束，解出氢气末态的$p_1, V_1$。

步骤
（i）对活塞整体（刚性杆连接，内力总和抵消）：水平方向$p_{\text{氢}} \cdot 2S + p_0 \cdot S = p \cdot 2S + p \cdot S$
解得 $p_{\text{氢}} = \frac{1}{2}(p_0 + p)$。

（ii）抽气后，设氢气压强$p_1$、体积$V_1$，氮气压强$p_2$、体积$V_2$。
活塞平衡：$p_1 \cdot 2S = p_2 \cdot S \Rightarrow p_2 = 2p_1$。
等温变化：氢气 $p_1 V_1 = p_{\text{氢}} \cdot 2V_0$；氮气 $p_2 V_2 = p_0 V_0$。
体积几何关系：因杆刚性，两活塞移动距离相等，位移$\Delta x$满足 $V_1 - 2V_0 = 2S \Delta x$，$V_0 - V_2 = S \Delta x$，消去$\Delta x$得 $V_1 - 2V_0 = 2(V_0 - V_2)$。
联立可解得$p_1 = \frac{1}{2}p_0 + \frac{1}{4}p$，$V_1 = \frac{4(p_0 + p)}{2p_0 + p} V_0$（化简后形式按真题）。

点评/变式
核心考点：刚性杆连接的双活塞系统受力分析和体积约束。变式可能将抽气改为充气或加热某一气室，需把等温与力学平衡、几何关系综合应用。

题2：2016-新课标Ⅱ-14（氧气瓶供气—变质量等效）

题目：氧气瓶容积$0.08\,\text{m}^3$，初压20 atm。实验室每天消耗1 atm氧气$0.36\,\text{m}^3$。压强降至2 atm时需重新充气，温度不变，求可供使用天数。

思路
瓶中气体质量随使用减少，不能直接对全瓶套玻意耳定律。转化思路：设末态瓶内剩余气体在2 atm下体积为$V_{\text{末}} = 0.08 \,\text{m}^3$，将其等温膨胀到1 atm时体积$V_{\text{剩}}'$；再设想整瓶初始20 atm气体等温膨胀到1 atm的体积$V_{\text{初}}'$。则使用掉的1 atm气体体积$V_{\text{用}}' = V_{\text{初}}' - V_{\text{剩}}'$，除以每日0.36 m³即得天数。

步骤
对瓶内初始全部气体（质量$m_0$）：在等温下从$(20\,\text{atm}, 0.08 \,\text{m}^3)$变为$(1\,\text{atm}, V_{\text{初}}')$，
$20 \times 0.08 = 1 \times V_{\text{初}}' \Rightarrow V_{\text{初}}' = 1.6\,\text{m}^3$。

剩余气体（质量$m$）在2 atm下占体积$0.08\,\text{m}^3$，若等温变化到1 atm，
$2 \times 0.08 = 1 \times V_{\text{剩}}' \Rightarrow V_{\text{剩}}' = 0.16\,\text{m}^3$。

可用的1 atm气体体积 $V_{\text{用}}' = 1.6 - 0.16 = 1.44 \,\text{m}^3$。
使用天数 $n = \frac{1.44}{0.36} = 4$ 天。

点评/变式
变质量问题的经典转化——虚拟膨胀法。要点是保持“可无限供气”的认定，把剩余气体也视作可抽出使用。变式可能涉及多瓶轮换供气或漏气后的重新充气计算。

题3：2013-新课标Ⅱ-14（双段气柱+活塞下推）

题目：竖直玻璃管，下部空气柱$l_1=25.0\,\text{cm}$，中间水银柱$l_2=25.0\,\text{cm}$，上部空气柱$l_3=40.0\,\text{cm}$。管下端封闭，上端开口，大气压$p_0=75.0\,\text{cmHg}$。缓慢下推活塞使下部空气柱长度变为$l_1'=20.0\,\text{cm}$，无漏气，求最后下部分气体压强和活塞下推距离。

思路
整个过程温度不变，两部分空气柱各自经历等温变化。关键是确定两部分气体初末态的压强与体积，以及水银柱平衡条件（压强关联）。活塞下推距离通过上部气柱的长度变化与下部气柱变化关联得出。

步骤
初态（未推活塞）：下部空气柱$l_1=25.0\,\text{cm}$，体积比例按长度（横截面不变）。设管内横截面积为$S$。 下部气体压强 $p_{下0} = p_0 + l_2 = 75.0 + 25.0 = 100.0 \,\text{cmHg}$。
上部气体压强 $p_{上0} = p_0 = 75.0 \,\text{cmHg}$（开口连大气），体积对应长度$l_3=40.0\,\text{cm}$。

末态（推活塞后）：下部气体长度$l_1'=20.0\,\text{cm}$，压强设为$p_{下}$；上部气体长度设为$l_3'$，压强$p_{上}$。
水银柱仍平衡：$p_{下} = p_{上} + l_2$（水银柱长不变）。
两部分等温：下部 $p_{下} \cdot l_1' = p_{下0} \cdot l_1$；上部 $p_{上} \cdot l_3' = p_{上0} \cdot l_3$。

联立：$p_{下} = \frac{p_{下0} l_1}{l_1'} = \frac{100 \times 25}{20} = 125 \,\text{cmHg}$。
于是 $p_{上} = p_{下} - l_2 = 125 - 25 = 100 \,\text{cmHg}$。
上部气体初态$75 \times 40 = 100 \times l_3' \Rightarrow l_3' = 30.0 \,\text{cm}$。

活塞下推距离 $d = (l_3 - l_3') + (l_1 - l_1') = (40 - 30) + (25 - 20) = 15.0\,\text{cm}$。

点评/变式
本题是典型的多段气柱关联问题。解题关键是正确写出各气柱的压强表达式（液柱平衡），利用等温变化求出末态长度，再由几何关系得活塞位移。变式可将活塞推向下部闭端变为抽拉，或把水银换成其他液柱，思路一致。
