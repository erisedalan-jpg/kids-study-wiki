等量异号电荷电场

考点等量异号电荷电场权重6真题数1学科物理父主题静电场

考点定位

  • 父主题：静电场
  • 权重 weight：6
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 单个等量异号点电荷系统
  • 电场线：从正电荷出发终止于负电荷，两电荷连线上电场强度方向沿连线，中垂面（线）上各点场强方向均与该面垂直且指向负电荷一侧。
  • 电势：中垂面为电势为零的等势面（无穷远处为零），正电荷一侧电势为正，负电荷一侧电势为负。沿电场线方向电势降低。
  • 场强大小：连线上中点场强最小；中垂面上由中点向远处场强逐渐减小。
  • 多电荷系统的电场叠加
  • 电场强度：矢量叠加，遵循平行四边形定则。对称性可简化合成。
  • 电势：标量叠加，代数和。
  • 电场力做功
  • $W_{AB}=qU_{AB}=q(\varphi_A-\varphi_B)$。
  • 正电荷从高电势移到低电势，电场力做正功；负电荷相反。
  • 适用条件：真空中的点电荷，$E=k\frac{Q}{r^2}$，电场、电势叠加原理成立。忽略边缘效应。

解题方法与套路

  1. 明确电荷分布与所求点位置：画出所有点电荷及关键点，标出正负。
  2. 分解系统：将复杂电荷系统拆分为若干对等量异号电荷，或逐个点电荷分析。
  3. 对称性分析：判断所求点是否在某对电荷的中垂线上、连线上或对称轴上，利用等量异号电荷中垂线是零势面且场强方向一致的性质快速得场强方向或电势。
  4. 场强叠加：对每对或每个电荷在该点产生的电场进行矢量合成，优先用对称抵消判断方向。
  5. 电势叠加与比较：对每个电荷产生的电势代数求和（标量），判断两点电势高低。
  6. 做功判断：由 $\Delta\varphi$ 及电荷正负得出做功正负，或利用等势面性质（两点在同一等势面上则移动电荷不做功）。
  7. 选项互验：电场力做功为零常与等势面关联，可通过场强方向垂直等势面进一步验证。

高频易错

  • 误用等势面：等量异号电荷的中垂面是电势为零的等势面，但仅在“该对电荷”内部成立。多对电荷系统中某些点可能恰好处于某对电荷的等势面上，需明确是哪一对。
  • 忽视距离对场强大小的贡献：对称位置的场强方向可能相同或相反，但大小不一定相等，如题中M点离两对电荷距离不同，场强不能完全抵消。
  • L、N电势高低的误判：容易仅凭对称性直觉认为对角线交点电势相等，实际L、N分别处于不同电势区域（如L靠近负电荷区，电势较低），移动正电荷做功不为零。
  • 方向垂直的误判：A选项中L和N场强方向分别沿对角线指向O，垂直关系源于正方形对角线垂直，而非等量异号电荷本身性质。不能生搬硬套“中垂线场强方向垂直”的结论。
  • 做功正负与电势升降的对应关系：正电荷从低电势到高电势，外力需做正功，电场力做负功；反之电场力做正功。选项C中从M到O，电势相等则做功为零，忌主观臆断。

代表题精讲

题目（2022全国乙卷·6）
正方形四个顶点固定两对等量异号点电荷$+q$、$-q$，L、N为两条对角线与内切圆的交点，O为内切圆圆心，M为内切圆与边的切点。判断：A. L和N电场方向是否垂直；B. M点电场方向；C. 正电荷从M到O电场力做功；D. 正电荷从L到N电场力做功。

思路
将四个电荷分为上下、左右两对等量异号电荷；抓住L、N、M、O的几何特殊性（L、N在对角线上，M在边中点，O在中心）；结合每对电荷的电场叠加和等势面性质逐项分析。

步骤
1. 构建电荷分布模型：由题意和选项暗示，可推断正方形左上、右下为$-q$，左下、右上为$+q$（或等价对称分布）。
2. A项：分析N点，处于两正电荷（左下、右上）连线的中垂线上，两正电荷在此产生的场强沿NO方向指向O；同时N位于两负电荷连线的中垂线上，两负电荷产生的场强也沿NO方向指向O，故N点合场强由N指向O。对称分析得L点合场强由O指向L。对角线相互垂直，L和N电场方向垂直。✅
3. B项：M为底边中点。底边两电荷左$+q$右$-q$，在M产生的场强均向左；上边两电荷左$-q$右$+q$，在M产生的场强均向右。M离底边近、离上边远，向左的场强大于向右的场强，合场强向左。内切圆切于M，切线竖直，向左方向确实平行于切线。✅
4. C项：观察M和O，均位于竖直方向那一对等量异号电荷（以对角线划分的另一对）的中垂面（线）上？正确判断：正方形竖直方向的一对等量异号电荷（如左上与右下，或右下与左上，或上下边上的电荷对）恰好使M和O在同一等势面上，电势相等。移动正电荷电场力做功为零。❌
5. D项：L点更靠近负电荷区域，电势低于N点（N靠近正电荷区域），正电荷从低电势到高电势，电场力做负功，不为零。❌
最终答案：AB。

点评/变式
本题的亮点在于将两对等量异号电荷组合，考察叠加思想的灵活运用。破解关键：
- 优先利用单对电荷的中垂面等势性与方向特点，再将两对合成。
- 比较电势时，可逐对电荷产生的电势代数相加，或直接用对称性判断高低。
- 变式：若将正方形顶点改为四个同号电荷、或一对等量同号与一对等量异号组合，可类比分析，注意对称性变化。
