简谐运动的表达式

考点简谐运动的表达式权重5真题数1学科物理父主题机械振动 与 机械波

考点定位

  • 父主题：机械振动 与 机械波
  • 权重 weight：5
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：解答16
  • 难度分布：中1

知识精要

  • 简谐运动表达式：$y = A\sin(\omega t + \varphi)$ 或 $y = A\cos(\omega t + \varphi)$。
    其中 $A$ 为振幅，$\omega = \dfrac{2\pi}{T} = 2\pi f$ 为角频率（圆频率），$\varphi$ 为初相。
  • 各量确定：
  • 振幅 $A$：由最大位移绝对值或结合初始位移与速度通过旋转矢量求得。
  • 周期 $T$ 与 $\omega$：利用质点从特定位置（如最大位移、平衡位置）首次到达另一位置的时间与 $T/4$ 等的关系。
  • 初相 $\varphi$：设出标准式后，代入 $t=0$ 的位移 $y_0$，得 $\sin\varphi = \dfrac{y_0}{A}$（或余弦），再结合此时速度方向（平衡位置向上/向下）确定 $\varphi$ 的唯一值。
  • 适用条件：质点做简谐运动，表达式只对单一振动质点；若涉及波，要区分波动方程与振动方程，振动方程是描述某固定质点的位移随时间变化。

解题方法与套路

  1. 审题区分振动与波动：明确所求是质点的振动方程还是波的表达式，振动方程只含时间变量 $t$。
  2. 求振幅 $A$：
  3. 若已知质点处于波峰或波谷，则振幅即位移绝对值；
  4. 若已知某时刻位移与速度方向，可结合 $A = \dfrac{|y|}{\sin(\omega t + \varphi)}$ 或旋转矢量图求。
  5. 在波动问题中，可结合空间几何与两点振动状态联动求 $A$。
  6. 求周期 $T$（或 $\omega$）：
  7. 质点从最大位移第一次回到平衡位置用时 $T/4$；
  8. 从平衡位置到最大位移用时 $T/4$；
  9. 利用不同质点（如波峰处质点与另一质点）回平衡位置的时间差，结合传播关系求出 $T$。
  10. 设振动方程并定初相 $\varphi$：
  11. 通常设为 $y = A\sin(\omega t + \varphi)$ 或 $y = A\cos(\omega t + \varphi)$；
  12. 代入 $t=0$ 的位移，解出 $\sin\varphi$，再判断 $\varphi$ 所在象限（由 $t=0$ 时速度方向定）；
  13. 若设为余弦，则 $y_0 = A\cos\varphi$，同样结合速度定 $\varphi$。
  14. 检验：将所得方程代入另一已知时刻的状态验证。

高频易错

  • 把任意位置首次回平衡位置的时间直接当 $T/4$：只有从最大位移（波峰或波谷）或平衡位置到最大位移才为 $T/4$；否则需靠方程或旋转矢量计算。
  • 忽略速度方向导致初相多解：$\sin\varphi = y_0/A$ 在 $(-\pi, \pi]$ 内通常有两解，必须根据此时质点是向平衡位置靠近还是远离来判定正负。
  • 混淆振动方程与波动方程：振动方程只有 $t$，波动方程含 $t$ 和 $x$，且波动方程中的初相需考虑坐标原点。若题目要求“质点O的位移随时间变化”，应写纯振动方程。
  • 振幅取值错误：当初始位移不是最大位移时，不能直接将初始位移当成振幅，需结合其他条件（如波长限制、另一质点状态）解出 $A$。
  • 用 $\lambda \ge 10\,\text{cm}$ 等限定条件决定波长取值：易忽略题目隐含取舍，导致多解或错解。

代表题精讲

题目（2016·新课标Ⅱ·16）

一列简谐横波沿 $x$ 轴正向传播，波长不小于 $10\,\text{cm}$。$O$ 和 $A$ 平衡位置分别在 $x=0$ 和 $x=5\,\text{cm}$。$t=0$ 时，质点 $O$ 位移 $y=4\,\text{cm}$，质点 $A$ 处于波峰；$t=\dfrac{1}{3}\,\text{s}$ 时 $O$ 第一次回到平衡位置，$t=1\,\text{s}$ 时 $A$ 第一次回到平衡位置。求：
（ⅰ）周期、波速、波长；
（ⅱ）质点 $O$ 的位移随时间变化的关系式。

思路
- 由 $A$ 最初在波峰、$1\,\text{s}$ 首次回平衡位置得 $T/4 = 1\,\text{s}$，故 $T=4\,\text{s}$。
- 由 $O$、$A$ 间距 $5\,\text{cm}$ 和 $t=0$ 时 $A$ 为波峰、$O$ 位移 $4\,\text{cm}$，结合 $\lambda\ge 10\,\text{cm}$ 可推振幅 $A_0$ 和波长 $\lambda$。利用 $O$ 在 $1/3\,\text{s}$ 回平衡位置确定其振动初相，进而得到波长与波速。
- 写出 $O$ 点的振动方程 $y_O = A\sin(\omega t + \varphi)$，代入初始条件求出 $A$ 和 $\varphi$。

步骤
1. 求周期：$A$ 从波峰（最大位移）首次回到平衡位置用时 $\dfrac{T}{4}=1\,\text{s}$，得 $T=4\,\text{s}$。
2. 求振幅与波长：设 $O$ 振动方程为 $y_O = A\sin(\omega t + \varphi)$，$t=0$ 时 $y_O = 4\,\text{cm} = A\sin\varphi$。$t=\dfrac{1}{3}\,\text{s}$ 时 $y_O=0$，得 $A\sin\left(\dfrac{2\pi}{4}\cdot\dfrac{1}{3}+\varphi\right)=0$。
解得 $\omega = \dfrac{\pi}{2}\,\text{rad/s}$，由此 $\sin\left(\dfrac{\pi}{6}+\varphi\right)=0$，$\dfrac{\pi}{6}+\varphi = k\pi$。结合初相范围与 $O$ 正向平衡位置运动（$t=0$ 时速度应为负，因向下回平衡位置），得 $\varphi = \dfrac{5\pi}{6}$。则 $\sin\varphi = \dfrac12$，故 $A = \dfrac{4\,\text{cm}}{1/2} = 8\,\text{cm}$。
$t=0$ 时 $A$ 在波峰，$O$ 与 $A$ 间距 $\Delta x = 5\,\text{cm}$，波向右传播，$O$ 相位落后 $A$。$A$ 的振动方程为 $y_A = 8\sin\left(\dfrac{\pi}{2} t + \dfrac{\pi}{2}\right)$（$t=0$ 波峰），或直接用余弦 $8\cos\left(\dfrac{\pi}{2}t\right)$。由两点相位差 $\Delta\varphi = \dfrac{2\pi\Delta x}{\lambda}$，且在 $t=0$ 时 $y_O=4\,\text{cm}$（正位移），$A$ 在正最大，故 $O$ 比 $A$ 相位落后 $\dfrac{\pi}{3}$（因为 $\sin(\pi/2 - \pi/3)=\sin(\pi/6)=1/2$，再考虑振幅得 4 cm）。这样 $\dfrac{2\pi\cdot5}{\lambda} = \dfrac{\pi}{3} + 2k\pi$，由于 $\lambda\ge10\,\text{cm}$，$5/\lambda \le 0.5$，取 $k=0$ 得 $\dfrac{10\pi}{\lambda} = \dfrac{\pi}{3}$，$\lambda = 30\,\text{cm}$。
3. 波速：$v = \dfrac{\lambda}{T} = \dfrac{30}{4}\,\text{cm/s} = 7.5\,\text{cm/s}$。
4. 振动方程：将 $T=4\,\text{s}$、$\omega=\dfrac{\pi}{2}$、$A=8\,\text{cm}$、$\varphi=\dfrac{5\pi}{6}$ 代入正弦形式，得
$$y_O = 8\sin\left(\dfrac{\pi}{2}t + \dfrac{5\pi}{6}\right)\,\text{cm}$$
或等价余弦形式 $y_O = 8\cos\left(\dfrac{\pi}{2}t + \dfrac{\pi}{3}\right)\,\text{cm}$。

点评/变式
- 本题关键两步：利用波峰质点回平衡位置时间直接得出周期；利用两点振动状态与波程差求波长时，需结合波长限制保留正确解。
- 初相确定务必结合速度方向，不能只由位移。若漏判速度方向，$\varphi$ 可能误取 $\dfrac{\pi}{6}$，导致振动方程反向。
- 变式：若波长无下限约束，可能出现多解 $\lambda = \dfrac{30}{12k+1}\,\text{cm}$，此时需由题干筛选。
