角速度与轨道半径

考点角速度与轨道半径权重6真题数1学科物理父主题曲线运动 与 抛体

考点定位

  • 父主题：曲线运动 与 抛体
  • 权重 weight：6
  • 真题数：1；年份跨度：2023–2023
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 质量不变性：在低速宏观条件下，物体的质量是固有属性，不随位置、运动状态（$v \ll c$）变化。
  • 万有引力定律：$F = G\dfrac{Mm}{r^2}$（$r$ 为物体到地心的距离）。同一物体，距地心越远，所受地球引力越小。
  • 匀速圆周运动的合力：在地面上静止时合力为零；在圆轨道上运行时，合力等于万有引力，提供向心力。
  • 天上圆周运动的动力学：$G\dfrac{Mm}{r^2} = m\omega^2 r \quad\Rightarrow\quad \omega = \sqrt{\dfrac{GM}{r^3}}$。
    轨道半径 $r$ 越大，角速度 $\omega$ 越小。
  • 地球同步卫星：轨道半径约为 $4.2 \times 10^7 \, \text{m}$（距地面约 $36000 \, \text{km}$），角速度与地球自转角速度相等，周期 $T = 24 \, \text{h}$。可用于做角速度比较的“中间参照物”。

解题方法与套路

  1. 锁定研究状态：明确物体处于“地面静止”还是“在轨匀速圆周运动”，两者受力与合力特征截然不同。
  2. 引力比较看距离：$F_{引} = G\frac{Mm}{r^2}$，$r$ 为到地心距离。$r$ 越大，引力越小。注意区分距地面高度 $h$ 与 $r = R + h$。
  3. 角速度比较三步骤：
  4. 写出角速度表达式 $\omega = \sqrt{\frac{GM}{r^3}}$；
  5. 画出不同轨道半径的相对大小；
  6. 若题目涉及地球自转角速度，立即联想到同步卫星角速度与之相等，将比较转化为 $r$ 与 $r_{同步}$ 的比较。
  7. 注意隐含参照物：同步卫星的轨道半径、角速度是高频中间量，比较空间站、地面物体、同步卫星三者时，使用“链式比较”：空间站 $\omega$ > 同步卫星 $\omega$ = 地球自转 $\omega$。

高频易错

  • 误区1：认为物体进入太空后质量减小。质量是基本属性，在低速下不变，失重不是“失质量”。
  • 误区2：引力比较直接用高度 $h$ 而忘记加地球半径 $R$。$F_1 = G\frac{Mm}{R^2}$，$F = G\frac{Mm}{(R+h)^2}$，分母增大引力必定减小，不可能“高轨道引力更大”。
  • 误区3：忘记地面上物体合力为零，而在轨道上合力等于引力，直接比较引力大小误判合力大小。
  • 误区4：混淆角速度与线速度。$\omega \propto 1/\sqrt{r^3}$，$v \propto 1/\sqrt{r}$，两者均随 $r$ 增大而减小，但比例不同。比较角速度务必用角速度公式。
  • 误区5：忽略“同步卫星角速度=地球自转角速度”这一隐藏条件，导致无法连接空间站与地球自转的比较。

代表题精讲

2023-新课标-04

题目简述：天舟六号对接空间站，运行在距地面约 $400\,\text{km}$ 轨道（小于同步卫星高度），物资做匀速圆周运动。判断后物资的质量、合力、引力、角速度与地面上时的比较。

思路：分别对四个选项涉及的物理量，应用万有引力定律、圆周运动动力学、质量属性，结合同步卫星作为角速度参照。

步骤： - A．质量：宏观低速下质量不变 → A 错误。
- B．合力：地面静止合力为零；在轨时合力为 $F_{合} = G\frac{Mm}{(R+h)^2} > 0$，因此合力比地面大 → B 错误。
- C．引力：地面引力 $F_{地} = G\frac{Mm}{R^2}$，在轨引力 $F_{轨} = G\frac{Mm}{(R+h)^2}$，分母 $R+h > R$，故 $F_{轨} < F_{地}$ → C 错误。
- D．角速度：由 $\omega = \sqrt{\frac{GM}{r^3}}$，空间站轨道半径 $r = R+h$ 小于同步卫星轨道半径 $r_{同步}$，所以 $\omega > \omega_{同步}$；又同步卫星角速度等于地球自转角速度，因此这批物资的角速度大于地球自转角速度 → D 正确。

点评/变式：本题通过天舟六号空间站情境，串联了质量不变、引力随距离变化、合力与加速度的对应，以及角速度与轨道半径的定性比较。变式训练：若比较线速度大小、向心加速度大小，同样用轨道半径链式比较：$a_n = \frac{GM}{r^2}$，$v = \sqrt{\frac{GM}{r}}$，近地轨道所有运动学量（线速度、角速度、向心加速度）均大于同步卫星，同步卫星又等于地球表面随地球自转的物体（注意：地面上随地球自转的物体不是万有引力完全提供向心力，需区分）。
