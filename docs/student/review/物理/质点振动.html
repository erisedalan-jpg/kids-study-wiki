质点振动

考点质点振动权重6真题数1学科物理父主题机械振动 与 机械波

考点定位

  • 父主题：机械振动 与 机械波
  • 权重 weight：6
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：解答15
  • 难度分布：中1

知识精要

  • 简谐运动：质点位移随时间按正弦（或余弦）规律变化 $x = A\sin(\omega t + \varphi_0)$。回复力 $F = -kx$，各物理量（位移、速度、加速度、动能、势能）均做周期性变化，周期 $T = 2\pi\sqrt{\frac{m}{k}}$，由系统本身决定。
  • 机械波：振动的传播。横波质点振动方向与波传播方向垂直，波形呈峰谷；纵波质点振动方向与传播方向共线。波速 $v = \frac{\lambda}{T} = \lambda f$，其中 $\lambda$ 由介质和波源频率共同决定，波速由介质决定。
  • 波动图像（$y$–$x$图）：某时刻各质点偏离平衡位置的位移分布，可读出波长 $\lambda$、振幅 $A$，结合传播方向用“同侧法”或“微平移法”判断各质点此刻振动方向。
  • 振动图像（$y$–$t$图）：某一质点位移随时间变化，可读出周期 $T$、振幅 $A$，直接看出任一时刻该质点的位移、运动方向及加速度方向。
  • 两图互推要点：从振动图像确定某质点在某时刻的位置和振动方向，再到波动图像中找出该质点，结合波传播方向逆推其他质点的状态或确定波形演变。

解题方法与套路

  1. 先抓共同物理量：对比所给波形图和振动图，找同一质点在两图中的对应时刻。由振动图读出该质点在此时刻的位移 $y$ 和振动方向（斜率正负）。
  2. 确定波的传播方向：在波形图中找到该质点的位置，若该质点振动方向已知，用“同侧法”（质点振动方向与波传播方向在波形图同一侧）快速判定波沿 $x$ 轴正向还是负向传播。
  3. 完整求解波参数：由波形图得 $\lambda$，由振动图得 $T$，套用 $v = \lambda/T$ 求波速。注意 $t=0$ 是否为计时起点，若不是需理清时间差对应的相位差 $\Delta\varphi = \omega \Delta t = \frac{2\pi}{T}\Delta t$。
  4. 判断任意质点某时刻状态：给定时刻 $t$，先由波传播方向和波速计算波形平移距离 $\Delta x = v\Delta t$，用“微平移法”画出新波形，直接读出各质点位移；或根据质点的振动方程 $y = A\sin(\omega t + \varphi)$ 代入该质点初相和时间求解。
  5. 多解问题规范处理：由于波动的时间周期性和空间周期性，若传播方向不确定或时间间隔与周期关系不唯一，必须写出通解 $\Delta x = n\lambda + \Delta x_0$ 或 $\Delta t = nT + \Delta t_0$，并讨论 $n$ 的取值。

高频易错

  • 混淆两图横轴：振动图横轴是时间 $t$，波动图横轴是位置 $x$。将振动图的“斜率”直接理解为质点速度大小和方向，但波动图某点斜率是 $\partial y/\partial x$，不代表质点振动快慢。
  • 质点不随波迁移：误以为质点在波传播方向上发生位移，实际上质点仅在其平衡位置附近振动，传播的只是振动形式和能量。
  • 传播方向与振动方向相互判断错误：用错“同侧法”（应使质点振动箭头与波传播箭头处于波形同一侧），或混淆“上坡下振、下坡上振”口诀的适用条件。
  • 盲目代公式忽略周期性：直接由波形图平移求时间，未考虑波速可能对应 $n\lambda + \Delta x$ 导致多解。对振动图只取一个周期内的值，忽略质点回到同一位置可能有两次方向相反的情况。
  • 相位计算初始时刻错位：题目常给 $t=0.10\text{s}$ 时的波形和某质点的振动图像，需正确书写振动方程或波动方程，将 $t=0.10\text{s}$ 作为计时起点 $t’=0$ 转换后再计算。

代表题精讲

代表题 2014-新课标Ⅱ-15

题目：图(a)为 $t=0.10\text{s}$ 时的波形图，P位于 $x=1.0\text{m}$，Q位于 $x=4.0\text{m}$；图(b)为质点Q的振动图像。判断有关说法是否正确(通常为多选题，选项涉及波速、周期、P点振动方向、某时刻位移等)。

思路：
先由Q的振动图像找到它在 $t=0.10\text{s}$ 时的位置和振动方向，再到波形图中定位 $x=4.0\text{m}$ 处，用同侧法反推波传播方向。根据波形图读波长、振动图读周期，算出波速。最后用平移法或振动方程分析P点在特定时刻的状态。

步骤：
1. 读图(b)：Q的振动图像，$t=0.10\text{s}$ 时Q的位移 $y_Q=0$，且振动方向向上（曲线斜率为正）。
2. 读图(a)：在 $t=0.10\text{s}$ 波形图中，$x=4.0\text{m}$ 处质点Q恰好处于平衡位置（位移为0），符合振动图信息。Q将要向上振动，因此波必须向左传播（沿 $x$ 轴负方向）才能使Q在下一时刻向上运动（同侧法：将波向左微平移，Q处会形成下凹，质点向上走）。
3. 求周期和波速：由图(b)直接得周期 $T=0.20\text{s}$；由图(a)得波长 $\lambda = 8.0\text{m}$，波速 $v = \frac{\lambda}{T} = \frac{8.0}{0.20} = 40\text{m/s}$。
4. 分析P点：$t=0.10\text{s}$ 时，P在 $x=1.0\text{m}$ 处，波形图显示其位移为正（处于波峰和平衡位置之间）。波向左传播，用平移法：经 $\Delta t$ 后波形向 $-x$ 平移 $\Delta x = v\Delta t$。如问 $t=0$ 时的情况，$\Delta t = -0.10\text{s}$（倒退），波向右平移 $4.0\text{m}$，可得 $t=0$ 的波形，从而读出P的位移。或由振动方程：对P，初相可从波形和位置推算，写出 $y_P = A\sin(\omega t + \varphi_P)$ 再代入时间求解。
5. 核对各选项：典型的正确选项——波速 $40\text{m/s}$，周期 $0.20\text{s}$，波沿 $x$ 轴负向传播；$t=0$ 时P位于负向最大位移（或某一具体值）等待判断。

点评/变式：
本题是波动图像与振动图像结合的经典考法，核心在于“同一质点、同一时刻”的对应。易错点是看图不细，将振动图的向上趋势误判为波向右传。变式常出现：交换P、Q角色给振动图像，或只给出部分波形和振动图求传播方向可能性（多解情况）。处理多解时，必须明确波传播的双向性和周期性，写清通解公式，再根据限制条件（如“在图中时刻之后某质点首次到达波峰”）确定 $n$ 值。
