转动切割

考点转动切割权重6真题数1学科物理父主题电磁感应

考点定位

  • 父主题：电磁感应
  • 权重 weight：6
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • 转动切割电动势：长为 $L$ 的直导体绕其一端在匀强磁场 $B$ 中以角速度 $\omega$ 垂直切割磁感线时，产生感应电动势 $$E = \frac{1}{2}B\omega L^2$$ 方向由右手定则（或正电荷所受洛伦兹力方向）判断：四指指向感应电流方向，电动势方向沿径向由低速端指向高速端。
  • 一般转动杆切割（不含端点）：若导体两端到转轴距离分别为 $r_1$、$r_2$（$r_2 > r_1$），则 $$E = \int_{r_1}^{r_2} B\omega l\,dl = \frac{1}{2}B\omega (r_2^2 - r_1^2)$$ 适用于同心导轨上的径向杆切割。
  • 等效电路：转动杆为电源，其电阻忽略时端电压等于电动势。外电路连接导轨与电阻，需判断电势高低（近轴端低、远轴端高）。
  • 功率与能量：
  • 电路中感应电流的电功率（焦耳热功率）等于安培力做功的功率： $$P_{\text{电}} = EI = I^2R = \frac{E^2}{R}$$
  • 外力驱动杆匀速转动时，外力功率 $P_{\text{外}} = P_{\text{电}} + P_{\text{摩擦}}$（若存在摩擦）。
  • 摩擦力分析：转动杆与水平导轨存在滑动摩擦，需通过力矩平衡求支点压力，再求摩擦力及摩擦功率。

解题方法与套路

  1. 确定电源与回路：明确哪段导体切割磁感线（常为径向杆），画出等效电路，标出内阻可忽略的等效电源及外电阻 $R$。
  2. 计算电动势：
  3. 若杆从转轴起：$E = \frac{1}{2}B\omega L^2$；
  4. 若杆两端距转轴 $r_1$、$r_2$：$E = \frac{1}{2}B\omega (r_2^2 - r_1^2)$ 或采用积分求平均速度 $\bar{v}=\omega\frac{r_1+r_2}{2}$，则 $E = B\bar{v}(r_2-r_1)$。
  5. 判断电流方向：右手定则（磁场穿手→拇指指运动方向→四指指感应电流方向），或利用洛伦兹力判电势高低（远轴端电势高）。
  6. 求感应电流：$I = \dfrac{E}{R_{\text{总}}}$，并指明流过电阻的方向。
  7. 受力与功率计算：
  8. 安培力：用 $F_{\text{安}} = B I L_{\text{有效}}$ 或力矩 $M = \int dM$。更简捷：安培力功率 $P_{\text{安}} = EI$。
  9. 摩擦力：先通过杆的力矩平衡求出两端支持力 $N_A,N_B$，再计算各端摩擦力 $f=\mu N$，速度$v=\omega r$，得摩擦功率 $P_{\text{摩擦}} = f_Av_A + f_Bv_B$。
  10. 外力匀速转动时，外力功率等于总阻功率：$P_{\text{外}} = P_{\text{安}} + P_{\text{摩擦}}$。

高频易错

  • 错用公式：直接将整杆长代入 $E = \frac{1}{2}B\omega L^2$，忽略杆两端都不在转轴的情况（如本题 $E \ne \frac{1}{2}B\omega r^2$）。
  • 方向判断含糊：转动切割中动生电动势方向始终沿径向由低线速度端指向高线速度端，混淆内、外轨电势高低导致电流方向反。
  • 受力分析遗漏：忘记滑动摩擦力做功，仅计算安培力功率，导致外力功率少项。
  • 支反力分配错误：对水平杆两端支反力简单视为各为 $\frac{1}{2}mg$ 而不通过力矩平衡检验，实际本题恰为各 $\frac{1}{2}mg$，但若不是均匀杆或支点不对称则需严格计算。
  • 单位与符号混乱：角速度 $\omega$ 与半径 $r$ 指数、系数 $\frac{1}{2}$ 漏乘或错乘。
