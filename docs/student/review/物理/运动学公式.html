运动学公式

考点运动学公式权重10真题数2学科物理父主题运动学

考点定位

  • 父主题：运动学
  • 权重 weight：10
  • 真题数：2；年份跨度：2015–2016
  • 出现题位：填空12 选择6
  • 难度分布：中1 难1

知识精要

  • 匀变速直线运动基本公式：
  • 速度公式：$v = v_0 + at$
  • 位移公式：$x = v_0t + \frac{1}{2}at^2$
  • 速度-位移公式：$v^2 - v_0^2 = 2ax$
  • 平均速度公式：$\overline{v} = \frac{x}{t} = \frac{v_0 + v}{2}$（仅适用于匀变速）
  • 牛顿第二定律：$F = ma$，加速度是联系力与运动的桥梁，分析运动必先求加速度。
  • 功能关系定量求解：
  • 功的公式：$W = Fs \cos\theta$
  • 动能定理：$W_{\text{合}} = \Delta E_k$（处理变力或复杂过程的首选）
  • 运动学推论：初速度为零的匀加速直线运动，通过连续相等位移所用时间比为 $1: (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : \cdots$

解题方法与套路

  1. 审题锁定研究对象：明确要求分析的是单个物体、多物体系统中的哪一部分。
  2. 受力分析求加速度：对研究对象做彻底的受力分析，利用牛顿第二定律求合力和加速度 $a$，审慎判断摩擦力类型及方向。
  3. 运动过程分段：若涉及多个运动阶段（如摩擦因数突变），以突变时刻为界拆分过程，确保各段的加速度恒定。
  4. 选择公式列方程：根据已知量（$v_0, x, t, v$）和未知量，灵活选用无时间 $t$ 的公式 $v^2 - v_0^2 = 2ax$ 或无加速度 $a$ 的公式 $x = \frac{v_0+v}{2}t$，尽量减少运算量。
  5. 联动分析与相对运动：多体问题先独立分析各物体加速度，再采用相对加速度 $a_{\text{相}} = a_A - a_B$、相对位移等概念简化追及或脱离问题。

高频易错

  • 盲目代公式：直接套用匀变速公式之前，必须确认过程中加速度 $a$ 是否恒定，遇到阻力与速度相关或过程摩擦力突变，须分段处理。
  • 力与运动的混淆：不要混淆“物体受力大小”与“物体运动快慢”。甲球质量大、受阻力大，但需通过加速度比较运动快慢，直接凭感觉判断时间极易出错。
  • 变量关联遗漏：涉及半径、质量等几何量时，注意 $m \propto r^3$，阻力与半径 $r$ 成正比，导致加速度表达式中包含与 $r$ 相关的因子，不能轻易约掉。
  • 摩擦力方向误判：传送带或板块模型中，根据相对运动或相对运动趋势判断摩擦力方向，一旦相对运动方向改变，摩擦力会突变。
  • 功的计算路径错位：计算“克服某力做功”直接用该力大小乘以对地位移即可，注意它与相对位移生热（$Q = f \cdot x_{\text{相}}$）的区别。

代表题精讲

题一：两球下落问题（2016-新课标Ⅱ-06）

题目：同材质实心球甲、乙，甲质量大于乙。在空气中由静止下落，阻力 $f = kr$（$r$为半径，与速率无关）。比较下落相同距离的物理量。 思路：比较运动时间、末速度、加速度必须通过牛顿第二定律求出加速度表达式，再对比量值大小。比较克服阻力做功用功的定义式。 步骤： 1. 由 $m \propto r^3$，得 $r \propto \sqrt[3]{m}$，阻力 $f = kr \propto m^{1/3}$。 2. 列牛顿第二定律方程：$mg - f = ma$，得加速度 $a = g - \frac{k r}{m}$。 3. 改写 $a$ 表达式：因 $\frac{r}{m} \propto \frac{1}{r^2}$，即半径越大（质量越大），$\frac{r}{m}$ 越小，故 $a_{\text{甲}} > a_{\text{乙}}$，即甲加速度大。 4. 由 $x = \frac{1}{2}at^2$ 知，相同距离下 $a$ 大则 $t$ 小，甲用时短；由 $v^2 = 2ax$ 知，$a$ 大则末速度 $v$ 大。 5. 克服阻力做功 $W_f = f \cdot x = krx$，甲半径 $r$ 大，距离 $x$ 相同，故 $W_f$ 甲大。 点评：不可单因甲受阻力大就误判加速度小，核心在比较 $r/m$，需将物理量同化为单一自变量的函数。

题二：滑坡堆积体运动（2015-新课标Ⅱ-12）

题目：倾角 $\theta=37^\circ$ 的坡上，质量均为 $m$ 的碎石堆A与石板B，动摩擦因数 $\mu_1$ 突变为 $\frac{3}{8}$，$\mu_2$ 突变为 $0.5$，2s后B上表面变光滑。已知 $l=27$m，求0~2s加速度及A在B上总时间。 思路：分时段对A、B隔离受力分析求加速度。0~2s两物均加速但不同加速度，2s后B上表面光滑，A、B相互作用改变。利用相对运动关系求脱离时间。 步骤： 1. 0~2s受力分析： 对A：$mg\sin\theta - \mu_1 mg \cos\theta = ma_A$，代入数值解得 $a_A = 3\text{m/s}^2$。 对B：$mg\sin\theta + \mu_1 mg \cos\theta - \mu_2 (2mg) \cos\theta = ma_B$，代入解得 $a_B = 1\text{m/s}^2$。 2. 0~2s运动积累： A、B对地位移：$\Delta x_A = \frac{1}{2}a_A t^2 = 6$m；$\Delta x_B = \frac{1}{2}a_B t^2 = 2$m。 A相对B位移：$\Delta x_{\text{相1}} = 4\text{m}$。 2s末速度：$v_A = 6\text{m/s}$，$v_B = 2\text{m/s}$。 3. 2s后受力突变：B上表面光滑，A受合力为 $mg\sin\theta$，$a_A' = 6\text{m/s}^2$；B受合力为 $mg\sin\theta - \mu_2 (2mg) \cos\theta$，$a_B' = -2\text{m/s}^2$（减速）。 4. 相对运动求时间：A相对B的加速度 $a_{\text{相}} = a_A' - a_B' = 8\text{m/s}^2$，初相对速度 $v_{\text{相}} = v_A - v_B = 4\text{m/s}$。还需走的相对位移 $s_{\text{相}} = l - \Delta x_{\text{相1}} = 23\text{m}$。 由 $s_{\text{相}} = v_{\text{相}} t_2 + \frac{1}{2}a_{\text{相}} t_2^2$，代入解得 $t_2 = 2\text{s}$（舍去负根）。 5. 总时间 $t = 2\text{s} + 2\text{s} = 4\text{s}$。 点评：本题是经典的多过程板块-临界问题，关键在于摩擦力突变时刻的分段处理，以及熟练运用相对运动法简化第二次脱离过程的时间计算。
