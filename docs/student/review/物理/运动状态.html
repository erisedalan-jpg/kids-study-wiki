运动状态

考点运动状态权重6真题数2学科物理父主题运动学

考点定位

  • 父主题：运动学
  • 权重 weight：6
  • 真题数：2；年份跨度：2012–2015
  • 出现题位：选择1
  • 难度分布：中1 易1

知识精要

  • 运动状态：物体的运动用速度矢量 $\vec{v}$ 描述，包含大小（速率）和方向。运动状态的改变表现为速度 $\vec{v}$ 的变化（如大小变、方向变或同时变）。
  • 惯性：物体保持原来运动状态（静止或匀速直线）的性质，牛顿第一定律（惯性定律）的核心。惯性大小唯一由质量 $m$ 决定，质量越大，惯性越大，运动状态越难改变。
  • 力与运动的关系：力是改变运动状态的原因，不是维持运动的原因。合力 $\vec{F}{\text{合}}$ 决定加速度 $\vec{a}$（$\vec{F}$），二者瞬时对应：合力为零时运动状态不变（静止或匀速直线）；合力恒定且不为零时物体做匀变速运动。 }} = m\vec{a
  • 典型应用：静电力与重力复合场中的平衡与运动，常见模型为初始静止物体受平衡力，条件突变后根据新合力方向确定运动。

解题方法与套路

  1. 审明初态：确定物体初始运动状态——是静止（$v_0=0$）还是具有某初速度 $v_0$，这是判断后续运动的基础。
  2. 受力全析：画出物体所受的全部力（重力、电场力、接触力等），注意恒力与变力，明确各力的大小和方向。若条件改变（如极板旋转），优先分析决定力大小和方向的因素是否变化（如电容器电量、间距、正对面积不变时 $E$ 不变，电场力大小不变）。
  3. 合力求解：用平行四边形定则或正交分解求合力 $\vec{F}_{\text{合}}$ 的大小和方向，是判定运动的关键。
  4. 判运动类型：
  5. $F_{\text{合}}=0$：静止或匀速直线；
  6. $F_{\text{合}}$ 恒定且 $v_0=0$：沿合力方向匀加速直线；
  7. $F_{\text{合}}$ 恒定且与 $v_0$ 同线：匀变速直线；
  8. $F_{\text{合}}$ 恒定且与 $v_0$ 有夹角：匀变速曲线。
  9. 概念辨析定选项：对于惯性、力与运动关系等概念题，紧扣“惯性是抵抗变化”“力是改变原因”“不受力时速度不变”等要点逐项排错。

高频易错

  • 误认“力是维持运动的原因”：惯性维持运动状态，力用来改变它。如“没有力物体只能静止” （2012题B）是典型错误，不受力时可匀速直线。
  • 混淆“速率不变”与“运动状态不变”：运动状态含方向，匀速圆周运动速率不变但方向时刻改变，运动状态在变，必受力，这不是惯性表现（2012题C错误）。
  • 电容器旋转问题中误判电场力：平行板绕某点旋转，若电量、间距、正对面积均不变，电场强度大小 $E$ 不变，仅方向随板旋转变化。易忽略此点而错认为电场力大小或方向改变，导致合力方向判断错误。
  • 忽视初速度对运动轨迹的影响：从静止释放（$v_0=0$）时，运动方向必与合力方向一致；若 $v_0 \neq 0$，则物体不一定沿合力方向运动，可能做曲线运动（如类平抛）。默认“力向哪就向哪动”易出错。

代表题精讲

2015-新课标Ⅱ-01

题目简述：
两平行带电金属板水平放置，板间 a 点静止释放一带电微粒恰好静止。现将两板绕过 a 点的轴逆时针转 $45^\circ$，再在 a 点静止释放相同微粒，问微粒运动情况。选项：A. 静止；B. 向左上方匀加速；C. 向正下方匀加速；D. 向左下方匀加速。

思路：
初始微粒静止 → 电场力与重力二力平衡，电场力竖直向上大小为 $mg$。极板旋转过程中电容器带电量、板间距、正对面积不变 → 电场强度大小不变 → 电场力大小仍为 $mg$，仅方向逆时针转 $45^\circ$。新状态下重力与电场力夹角 $135^\circ$，求合力方向。从静止释放，微粒沿合力方向做匀加速直线运动。

步骤：
1. 初始静止受力：重力 $G = mg$ 竖直向下，电场力 $F_0 = mg$ 竖直向上，平衡。
2. 极板旋转分析：由 $C$ 不变、$Q$ 不变、$d$ 不变、$S$ 不变，得 $E = \frac{U}{d} = \frac{Q}{Cd} = \frac{4 \pi k Q}{\varepsilon S}$ 大小不变，故电场力大小 $F = mg$ 不变，方向随板面法向逆时针转 $45^\circ$，即与竖直向上方向成 $45^\circ$ 斜向左上。
3. 旋转后合力：重力竖直向下 $mg$，电场力大小 $mg$、方向与竖直向下成 $135^\circ$ 角。由矢量合成，合力方向在两者角平分线偏下，即向左下方，大小恒定。
4. 运动判定：$v_0 = 0$，合力恒定向左下方，故微粒向左下方做匀加速直线运动。D 正确。

点评/变式：
- 核心考点：电容器动态分析（决定电场强度不变的条件）与从静止释放时运动方向判定。
- 易错：认为极板旋转后电场力方向变化导致大小也变，或忽略重力，直接判电场力方向为运动方向。
- 变式：若极板旋转后，不是静止释放而是给微粒垂直极板向下的初速度，则需比较初速度方向与合力方向，可能做匀变速曲线运动。
