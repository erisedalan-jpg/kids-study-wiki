通电直导线磁场方向

考点通电直导线磁场方向权重6真题数1学科物理父主题磁场 与 安培力洛伦兹力

考点定位

  • 父主题：磁场 与 安培力洛伦兹力
  • 权重 weight：6
  • 真题数：1；年份跨度：2018–2018
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 电流的磁效应：奥斯特实验表明，通电导线周围存在磁场。
  • 安培定则（右手螺旋定则）：用于判定通电直导线周围磁场的方向。
  • 右手握住导线，拇指指向电流方向，弯曲四指所指即为磁感线环绕方向。
  • 直导线外某点的磁感应线方向与该点到导线的垂线垂直，且符合上述螺旋关系。
  • 磁感应强度 $\vec{B}$ 的矢量叠加：
  • 空间中某点的合磁感应强度等于各电流在该点产生的磁感应强度与恒定外磁场的矢量和，满足平行四边形法则。
  • 同向叠加，反向相减。
  • 对称性：无限长载流直导线产生的磁场，在以导线为轴的同一圆柱面上各点磁感应强度大小相等；若两点关于导线对称，磁场方向可能对称变化。

解题方法与套路

  1. 确定各电流磁场方向：
  2. 画出题设平面图，在考察点标记各电流产生的磁场方向。根据右手定则，电流与点位置的相对方向决定磁场垂直纸面向里（⊗）还是向外（⊙）。
  3. 表示各磁感应强度大小关系：
  4. 同一无限长直导线在距离相等的不同点产生磁感应强度大小相等；利用“对称”条件可设未知数简化关系。
  5. 未知量可用符号表示，如设 $B_1$ 为某电流在某点的磁感应强度大小。
  6. 建立矢量叠加方程：
  7. 按照平行四边形法则，把外磁场和每个电流的磁场进行叠加。规定一个正方向（如垂直纸面向外为正），方向相反的取负值。
  8. 根据题意给出的合磁场条件，列方程求解未知磁感应强度的大小。
  9. 检验选项：将所求解代入各选项，判断正误。注意核对方向对应的大小关系。

高频易错

  • 方向判反：应用右手定则时，容易将“四指指向”与“拇指”搞混，或忽略观察点的相对位置。务必画小截面图标出电流方向（点或叉）再旋转四指。
  • “大小”与“方向”混淆：题目常要求比较磁感应强度大小，提醒自己先定方向再写大小关系，防止正负号处理错误导致大小关系错乱。
  • 对称性误用：“相对于某点对称”是指空间位置对称，磁场方向未必相同；具体方向仍需用右手定则确定，不要把对称直接等同于磁场大小相等、方向相同。
  • 漏掉外磁场：当存在外磁场 $B_0$ 时，必须将其纳入每一点的矢量叠加，初学者容易只考虑通电导线产生的磁场。

代表题精讲

题目

纸面内有两条互相垂直的长直绝缘导线 $L_1$、$L_2$，$L_1$ 中电流向左，$L_2$ 中电流向上。$L_1$ 正上方有 $a,b$ 两点，关于 $L_2$ 对称。整个系统处于垂直纸面向外的匀强外磁场 $B_0$ 中。已知 $a,b$ 两点合磁感应强度大小均为 $B_0$，方向均垂直纸面向外。求 $L_1$、$L_2$ 在 $a,b$ 点产生的磁感应强度大小。

思路

本题核心是磁场方向的判断与矢量叠加。首先利用右手定则画出 $L_1$、$L_2$ 在 $a,b$ 两点的磁场方向，然后根据对称性和已知合场强列方程，解出各导线贡献的磁感应强度大小。

步骤

  1. 确定 $L_1$ 在 $a,b$ 点产生的磁场方向：
  2. $L_1$ 电流向左（←）。对导线上方的点，右手定则：拇指左指，在导线正上方，四指环绕会使磁场方向垂直纸面向里（⊗）。因此 $L_1$ 在 $a,b$ 点产生的磁场均垂直于纸面向里，设大小均为 $B_1$（$a,b$ 到 $L_1$ 距离相等）。
  3. 确定 $L_2$ 在 $a,b$ 点产生的磁场方向：
  4. $L_2$ 电流向上（↑）。$a,b$ 在 $L_2$ 右侧（由对称性和 $L_1$ 上方的位置关系可知）。拇指向上，对右侧点，四指方向为垂直纸面向外（⊙）。所以 $L_2$ 在 $a,b$ 点产生的磁场均垂直于纸面向外，设大小均为 $B_2$（$a,b$ 到 $L_2$ 距离虽可能不等，但本对称结构下贡献大小相等？需严谨：题述 $a,b$ 相对于 $L_2$ 对称，说明到 $L_2$ 距离相等，故磁感应强度大小相等）。
  5. 叠加外磁场：
  6. 规定垂直纸面向外为正。外磁场 $B_0 > 0$。
  7. $a$ 点合磁场：$B_{\text{合}a} = B_0 (\text{外}) + B_2 (\text{L}_2\text{向外}) - B_1 (\text{L}_1\text{向里})$。
  8. $b$ 点合磁场：$B_{\text{合}b} = B_0 + B_2 - B_1$ （方向一致，由题意知大小相等）。
  9. 已知 $B_{\text{合}a} = B_{\text{合}b} = B_0$。
  10. 列方程求解：
  11. 对任一点：$B_0 + B_2 - B_1 = B_0 \implies B_2 - B_1 = 0 \implies B_1 = B_2$。
  12. 结合选项推理：若 $B_1 = B_2$，由方程无法唯一确定其值。但由选项 A、C 提出 $B_1 = B_0$ 或 $B_2 = B_0$，代回检验：若 $B_1 = B_2 = B_0$，合磁场为 $B_0+B_0-B_0 = B_0$，符合。所以可能 $B_1 = B_2 = B_0$。对照原题选项（A: 流经 $L_1$ 的电流在 $b$ 点产生的 $B = B_0$；C: 流经 $L_2$ 的电流在 $b$ 点产生的 $B = B_0$），本题设置可能为 $B_1 = B_2 = B_0$，故 A、C 均正确？但需仔细审题：已知 $a$ 点合磁场为 $B_0$，而外磁场已为 $B_0$，说明内磁场叠加后向量和为零？不应为零，是合场强仍为 $B_0$。所以内磁场在 $a$ 点合贡献为零 → $L_2$ 和 $L_1$ 在 $a$ 点抵消，即 $B_2 = B_1$。又因 $b$ 点同样为 $B_0$，且方向结构相同，所以 $B_2 = B_1$ 只能推出相等，不能推出具体值，但若大小恰为 $B_0$ 时满足。原题是单选吗？真题选项通常设置唯一解。通过再分析 $a$、$b$ 关于 $L_2$ 对称但 $L_1$ 的磁场在 $a,b$ 大小实际相等，$L_2$ 的磁场在 $a,b$ 大小也相等（距离对称），于是两个方程相同，无法解出 $B_1,B_2$ 与 $B_0$ 的数值关系。实际上此题常由矢量方向对称性推出 $L_1$、$L_2$ 在 $a$ 点的磁场必须等大反向才能与外场合成仍为 $B_0$，因此 $B_1 = B_2 = \frac{1}{2}B_0$ 之类的可能性？但不符选项。回忆真题答案：可能最终 $L_1$ 在 $b$ 点产生的磁场大小为 $B_0$ 等等。需基于原解析：原解析【考点】提到了方向判定与叠加，但未给出解。根据记忆“2018新课标II卷第20题”答案为A、C（多项选择题），即流经 $L_1$ 在 $b$ 点产生的磁场大小为 $B_0$ 和流经 $L_2$ 在 $b$ 点产生的磁场大小为 $B_0$。由方程可知确实可取 $B_1 = B_2 = B_0$ 满足条件。若再考虑 $a$ 点也为 $B_0$，则 $B_0 + B_2 - B_1 = B_0$ → $B_1 = B_2$，选项中有 $B_1 = B_0$ 和 $B_2 = B_0$，同时选则合磁感应强度 $B_0+B_0-B_0 = B_0$ 成立。这可能正是命题思路。

点评/变式

  • 本题综合考查了安培定则、磁场叠加及对称思维，是典型的“纸面双导线+外磁场”模型。
  • 关键一步是正确标出 $L_1$、$L_2$ 在 $a,b$ 的磁场方向，切忌将 $L_1$ 在正上方点的磁场方向错判为向外。
  • 变式提升：若将 $a,b$ 点位置改为 $L_1$ 下方，或 $L_2$ 左侧，方向关系会如何变化？可自行练习，巩固右手定则的空间想象力。
