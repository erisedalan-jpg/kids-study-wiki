速度的合成与分解

考点速度的合成与分解权重0真题数3学科物理父主题运动学

考点定位

  • 父主题：运动学
  • 权重 weight：0
  • 真题数：3；年份跨度：2011–2023
  • 出现题位：选择2 选择3 选择11
  • 难度分布：中3

知识精要

  • 速度的矢量性：速度是矢量，既有大小又有方向，运算遵循平行四边形定则或三角形定则。
  • 合运动与分运动的关系：
  • 等时性：各分运动与合运动同时发生、同时结束。
  • 独立性：各分运动互不影响。
  • 等效性：分运动共同效果与合运动相同。
  • 速度的合成：已知分速度求合速度，用平行四边形定则（或三角形定则）。
    若分速度 $v_1$、$v_2$ 夹角为 $\theta$，合速度大小 $v=\sqrt{v_1^2+v_2^2+2v_1v_2\cos\theta}$。
  • 速度的分解：已知合速度求分速度，按实际效果或解题需要分解，常用两种方式：
  • 按运动效果分解（如关联速度中沿绳与垂直绳方向）；
  • 正交分解（如平抛运动中水平与竖直方向；恒力作用下沿力方向与垂直力方向）。
  • 重要推论：
  • 速度分解后，某一方向上的分运动为该方向上的直线运动，可用相应直线运动规律。
  • 曲线运动中，垂直恒定外力方向的速度分量保持不变（因该方向力不做功，无加速度）；外力只改变与其共线的速度分量。
  • 典型模型：
  • 平抛运动中，任意时刻速度与水平方向夹角 $\alpha$ 满足 $\tan\alpha=\dfrac{gt}{v_0}$，位移与水平方向夹角 $\beta$ 满足 $\tan\beta=\dfrac{gt}{2v_0}$，$\tan\alpha=2\tan\beta$。
  • 小船渡河、卫星变轨等均涉及速度矢量合成。

解题方法与套路

  1. 明确合速度与分速度
    根据题意确定研究对象实际运动的速度为合速度，参与的几个运动对应的速度为分速度。常见情况：物体相对地面的运动为合运动；发动机点火给卫星附加速度时，转移轨道速度与附加速度的合成为同步轨道速度。

  2. 建立速度矢量图
    画出速度平行四边形或三角形，标出已知量（大小、方向）和未知量。注意角度关系，例如卫星变轨中转移轨道与同步轨道夹角 $30^\circ$ 是合速度与一分速度的夹角。

  3. 选择分解方向

  4. 若恒力与速度成角，将速度沿力方向和垂直力方向正交分解，垂直力方向的分速度不变。
  5. 若涉及与水平面（水面）的夹角，常常分解为水平与竖直方向，利用平抛规律。

  6. 关联速度问题中沿绳/杆方向的分速度相等。

  7. 列式求解
    应用几何关系（三角函数、正弦定理、余弦定理等）或代数关系（$v=\sqrt{v_x^2+v_y^2}$，$\tan\alpha=v_y/v_x$）计算未知量。
    例如：已知合速度 $v$、一分速度 $v_1$ 及它们夹角 $\theta$，求另一分速度 $v_2$，用 $v_2=\sqrt{v^2+v_1^2-2vv_1\cos\theta}$（当 $v$ 与 $v_1$ 为邻边时）。

  8. 讨论物理合理性
    对多解情况（如速度方向不同导致动能变化不同）做全面分析，根据条件取舍。

高频易错

  • 混淆合速度与分速度：在实际问题中误把某一分运动的速度当作合速度，例如把沿绳方向的速度当作合速度（关联速度）、把转移轨道速度当作合速度而不是分速度，导致矢量关系错误。
  • 忽视矢量角度关系：卫星变轨题中误以为附加速度大小就是两速度之差，忘记它们是矢量，夹角 $30^\circ$ 必须用余弦定理计算。
  • 速度分解时漏掉垂直分量：在恒力导致曲线运动中，只分析沿力方向速度变化，忘记垂直力方向速度不变，从而错误判断合速度会减小到零或一直减小。尤其当恒力与速度成钝角时，合速度的最小值不为零（如2011年D选项）。
  • 错用夹角：打水漂问题中，速度与水面的夹角等于速度与水平方向的夹角，有的同学误认为是与竖直方向的夹角；平抛运动中速度偏向角的正切为 $v_y/v_x$，切莫记反。
  • 数学运算失误：不小千克单位换算、数量级错误，或在余弦定理中符号弄错（减号写成加号）。

代表题精讲

题1（2023新课标·11）石子“打水漂”

题目：从距水面高 $h$ 处水平抛出石子，要使石子接触水面时速度方向与水面的夹角不大于 $\theta$，求抛出速度的最小值。不计空气阻力。
思路：石子做平抛运动，水平速度不变，竖直方向自由落体。触水时速度与水平方向夹角 $\alpha$ 不大于 $\theta$，由此建立不等式求解 $v_0$。
步骤：
1. 竖直分速度 $v_y=\sqrt{2gh}$。
2. 触水时速度方向与水平方向夹角满足 $\tan\alpha=\dfrac{v_y}{v_0}$。
3. 要求 $\alpha \le \theta$，则 $\tan\alpha \le \tan\theta$，即 $\dfrac{\sqrt{2gh}}{v_0} \le \tan\theta$。
4. 解得 $v_0 \ge \dfrac{\sqrt{2gh}}{\tan\theta}$，最小值为 $v_{0\min}=\dfrac{\sqrt{2gh}}{\tan\theta}$。
点评/变式：考查平抛运动速度分解的基本应用，关键是正确判断“与水面的夹角”即速度与水平面的夹角。变式可求此时水平位移、入射角最大时的抛出速度等。

题2（2015新课标Ⅱ·03）卫星变轨附加速度

题目：卫星在转移轨道上飞经赤道上空时速度 $v_1=1.55\times10^3\,\text{m/s}$，方向与同步轨道（环绕速度 $v=3.1\times10^3\,\text{m/s}$）夹角 $30^\circ$。发动机点火给卫星一附加速度，使之进入同步轨道。求附加速度的大小和方向。
思路：明确合速度为同步轨道速度 $v$，分速度为转移轨道速度 $v_1$ 和附加速度 $v_2$。已知合速度与一分速度的大小和夹角，用矢量三角形求另一分速度。
步骤：
1. 画矢量三角形：合速度 $v$ 与分速度 $v_1$ 夹角 $30^\circ$，$v_2$ 为待求。
2. 由余弦定理：$v_2=\sqrt{v^2+v_1^2-2vv_1\cos30^\circ}$
$=\sqrt{(3.1^2+1.55^2-2\times3.1\times1.55\times\frac{\sqrt3}{2})}\times10^3\,\text{m/s}$
$=\sqrt{9.61+2.4025-8.322}\times10^3\approx\sqrt{3.6905}\times10^3\approx1.92\times10^3\,\text{m/s}$。
3. 方向由速度三角形判定：因为 $v>v_1$，且夹角偏向东侧，附加速度方向为东偏南。对应选项B：东偏南方向，$1.9\times10^3\,\text{m/s}$。
点评/变式：本题典型体现了速度合成与分解在航天中应用，注意区分合运动与分运动。若对余弦定理不熟，可用正交分解计算 $v_2$ 的大小和方向。

题3（2011新课标·02）恒力作用下质点动能变化

题目：质点原做匀速直线运动，从某时刻起受一恒力作用。此后其动能可能怎样变化？（多选）
思路：恒力即合力，将初速度沿恒力方向和垂直恒力方向分解，垂直分量不变，平行分量在恒力作用下匀变速。根据恒力与初速度方向关系讨论合速度大小变化。
步骤：
1. 设初速度 $v_0$ 与恒力 $F$ 夹角 $\theta$，则 $v_{\parallel}=v_0\cos\theta$，$v_{\perp}=v_0\sin\theta$。
- $v_{\perp}$ 不变；$v_{\parallel}$ 在 $F$ 作用下匀变速。
2. 合速度 $v=\sqrt{v_{\parallel}^2+v_{\perp}^2}$，动能 $E_k=\frac12 mv^2$。
3. 讨论：
- 恒力与 $v_0$ 同向（$\theta=0$）：$v_{\parallel}$ 一直增大，动能一直增大（A对）。
- 恒力与 $v_0$ 反向（$\theta=\pi$）：$v_{\parallel}$ 先减到零再反向增大，动能为零时速度减为零，再增大（B对）。
- 恒力与 $v_0$ 成锐角（$\theta\in(0,\frac\pi2)$）：$v_{\parallel}$ 一直增大，动能一直增大，不会先增后减（C错）。
