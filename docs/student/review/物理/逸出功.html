逸出功

考点逸出功权重16真题数3学科物理父主题近代物理

考点定位

  • 父主题：近代物理
  • 权重 weight：16
  • 真题数：3；年份跨度：2011–2024
  • 出现题位：解答17 选择4 选择8
  • 难度分布：易1 中1 难1

知识精要

  • 逸出功 $W_0$：电子从金属表面逸出所需的最小能量，由金属材料自身性质决定，与入射光频率、强度无关。
  • 光子能量：$E = h\nu$，其中普朗克常量 $h = 6.63 \times 10^{-34}\ \text{J·s}$，$\nu$ 为频率。光强度（光子数目）只影响单位时间逸出的光电子数，不改变单个光子能量。
  • 爱因斯坦光电效应方程：$E_{k,\text{max}} = h\nu - W_0$。其中 $E_{k,\text{max}}$ 为光电子的最大初动能。
  • 当 $E_{k,\text{max}} = 0$ 时，得到截止频率 $\nu_0 = \dfrac{W_0}{h}$，截止波长 $\lambda_0 = \dfrac{c}{\nu_0} = \dfrac{hc}{W_0}$。
  • 遏止电压 $U_c$：满足 $eU_c = E_{k,\text{max}}$，因此 $U_c = \dfrac{h\nu - W_0}{e} = \dfrac{hc}{e}\left( \dfrac{1}{\lambda} - \dfrac{1}{\lambda_0} \right)$，其中 $e$ 为元电荷。
  • 波长-频率关系：$\nu = \dfrac{c}{\lambda}$，真空中光速 $c = 3.00 \times 10^8\ \text{m/s}$。

解题方法与套路

  1. 确定已知量与待求量：厘清入射光频率（或波长、光强）、逸出功（或截止频率/波长）、最大初动能（或遏止电压）之间的关系。
  2. 紧扣核心方程：凡是涉及光电效应定量计算，一律从 $E_{k,\text{max}} = h\nu - W_0$ 出发。若题目给出波长，先利用 $\nu = c/\lambda$ 转换为频率。
  3. 求逸出功或截止参量：
  4. 若已知截止频率 $\nu_0$ 或截止波长 $\lambda_0$，则 $W_0 = h\nu_0 = \dfrac{hc}{\lambda_0}$。
  5. 若已知入射频率 $\nu$ 和最大初动能 $E_{k,\text{max}}$，则 $W_0 = h\nu - E_{k,\text{max}}$。
  6. 求最大初动能或遏止电压：
  7. $E_{k,\text{max}} = h\nu - W_0$。
  8. 遏止电压 $U = \dfrac{E_{k,\text{max}}}{e}$，可展开为 $U = \dfrac{h\nu - W_0}{e} = \dfrac{hc}{e}\left( \dfrac{1}{\lambda} - \dfrac{1}{\lambda_0} \right)$。
  9. 分析光强问题：光强只改变光子数密度，从而影响单位时间逸出的光电子数（饱和光电流）。光强不改变 $\nu$、$h\nu$、$W_0$、$E_{k,\text{max}}$ 或 $U_c$。

高频易错

  • 混淆光强与光子能量：认为增大光强会增大光子能量或逸出功。实际上，光子能量仅由频率决定，逸出功是金属固有属性，二者与光强无关。
  • 计算中单位不统一：波长常以纳米（nm）给出，必须换算为米（m）再代入 $c/\lambda$。光速 $c = 3.00 \times 10^8\ \text{m/s}$，$1\ \text{nm} = 10^{-9}\ \text{m}$。
  • 遏止电压与最大初动能关系不清：遏止电压是使光电流恰好为零的反向电压，$eU_c = E_{k,\text{max}}$，与入射光强无关。
  • 误判光电效应发生条件：发生光电效应的条件是 $\nu \ge \nu_0$ 或 $\lambda \le \lambda_0$，易将波长大小关系搞反。
  • 忽略逸出功的固有性：在不同题目情境中，误以为改变入射光参数会改变逸出功，导致选项误判。

代表题精讲

1. 题目（2024-辽宁-08）：用某一频率X光照射金属表面逸出光电子，增加此X光强度，判断逸出功、光子能量、最大初动能、单位时间光电子数的变化情况。

思路

抓住光电效应中“光频率决定光子能量和最大初动能，光强度决定光电子数”的因果关系，逐一验证选项。

步骤

  • A 逸出功：金属固有属性，与光强无关，不变→错误。
  • B 光子能量：$E = h\nu$，频率
