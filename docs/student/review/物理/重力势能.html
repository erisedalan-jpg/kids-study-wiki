重力势能

考点重力势能权重10真题数1学科物理父主题万有引力 与 天体

考点定位

  • 父主题：万有引力 与 天体
  • 权重 weight：10
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 重力势能 $E_p = mgh$（$h$ 为相对零势能面的高度）。势能具有相对性，值取决于零势能面选取；但重力势能的变化 $\Delta E_p = mg\Delta h$ 具有绝对性，与零势能面无关。
  • 重力做功与重力势能变化的关系：$W_G = -\Delta E_p = mg(h_1 - h_2)$。重力做正功，重力势能减少。
  • 机械能 $E_{\text{总}} = E_k + E_p$。只有重力（或系统内弹力）做功时，机械能守恒；若有其他力做功，机械能的改变量等于其他力做的功，即 $W_{\text{其他}} = \Delta E_{\text{总}}$。
  • 从 $E_p-h$ 图像获取信息：图线斜率 $k = mg$，结合 $g$ 可求物体质量；从 $E_{\text{总}}-h$ 图像获取机械能变化情况，机械能减小则说明有阻力等非保守力做负功。

解题方法与套路

  1. 读图像，抓特殊点：看清纵、横轴，由 $E_p-h$ 过原点直线、某高度对应势能值，利用 $E_p=mgh$ 求出质量或重力；若 $E_{\text{总}}-h$ 为倾斜直线，则阻力恒定。
  2. 求动能：利用 $E_k = E_{\text{总}} - E_p$，在同一高度处两纵坐标之差即为动能。
  3. 求初速度等运动量：从 $h=0$ 处 $E_{\text{总}}$（此时 $E_p=0$，$E_k=E_{\text{总}}$）得到初动能，结合动能定理 $E_k = \frac12 mv^2$ 求速度。
  4. 分析能量转化：根据 $E_{\text{总}}$ 随高度变化求出机械能减少量，由 $|\Delta E_{\text{总}}| = |W_f| = f \cdot h$ 求阻力；由动能定理或功能关系求动能变化、速度变化。
  5. 谨防干扰：注意题干给定的重力加速度值，不可盲用 $9.8\,\text{m/s}^2$；明确零势能面的选取，计算势能变化时只看高度差。

高频易错

  • 混淆零势能面：题目规定“地面为重力势能零点”时，$E_p=mgh$ 中 $h$ 必须相对地面，不能用其他参考面。
  • 直接由 $E_{\text{总}}$ 斜率推出质量：$E_{\text{总}}-h$ 斜率反映阻力（除重力外的其他力做功），$E_p-h$ 斜率才是 $mg$。
  • 盲目认为机械能守恒：本题中 $E_{\text{总}}$ 随高度线性减小，说明空气阻力不可忽略，不能直接用初动能等于最高点重力势能。
  • 将 $E_{\text{总}}$ 与 $E_p$ 图线差值错当动能减少量：注意动能减少量是动能的初末状态差，而非某高度 $E_{\text{总}}-E_p$ 与初动能的直接比较。
  • 单位与方向：重力势能与功的单位统一为焦耳（J）；速度大小求出后切勿带负号；$g$ 取 $10\,\text{m/s}^2$ 必须按题设。

代表题精讲

题目
从地面竖直向上抛出一物体，其机械能 $E_{\text{总}}=E_k+E_p$，取地面为重力势能零点，该物体的 $E_{\text{总}}$ 和 $E_p$ 随高度 $h$ 的变化如图所示。重力加速度 $g=10\,\text{m/s}^2$。由图可知（ ）
A. 物体的质量为 $2\,\text{kg}$
B. $h=0$ 时，物体的速率为 $20\,\text{m/s}$
C. $h=2\,\text{m}$ 时，物体的动能 $E_k=40\,\text{J}$
D. 从地面至 $h=4\,\text{m}$，物体的动能减少 $100\,\text{J}$

（图中：$E_p-h$ 为过原点的倾斜直线，$h=4\,\text{m}$ 时 $E_p=80\,\text{J}$；$E_{\text{总}}-h$ 为从 $(0,\,100\,\text{J})$ 下降到 $(4\,\text{m},\,80\,\text{J})$ 的直线。）

思路
由 $E_p=mgh$ 求质量；由 $h=0$ 时的 $E_{\text{总}}$ 得初动能并求初速度；再由 $h=2\,\text{m}$ 的 $E_{\text{总}}$ 与 $E_p$ 之差求该处动能；最高点（$h=4\,\text{m}$）动能为零，初末动能差即为动能减少量。

步骤
1. 当 $h=4\,\text{m}$ 时 $E_p=80\,\text{J}$，由 $E_p=mgh$ 得 $m = \dfrac{80}{10\times4}\,\text{kg} = 2\,\text{kg}$。A 正确。
2. $h=0$ 时，$E_p=0$，$E_{\text{总}}=100\,\text{J}$，故初动能 $E_{k0}=100\,\text{J}$。由 $\dfrac12 mv^2 = 100$ 得 $v= \sqrt{\dfrac{200}{2}}\,\text{m/s}=10\,\text{m/s}$，B 错误。
3. $h=2\,\text{m}$ 时，由图像线性插值可得 $E_p=40\,\text{J}$，$E_{\text{总}}=90\,\text{J}$，因此动能 $E_k = 90-40 = 50\,\text{J}$，C 错误。
4. 到达 $h=4\,\text{m}$ 时，$E_{\text{总}}=E_p=80\,\text{J}$，动能 $E_k=0$。初动能 $100\,\text{J}$，故动能减少 $\Delta E_k = 100-0 = 100\,\text{J}$，D 正确。
答案选 AD。

点评/变式
本题巧妙利用两条能量图线呈现竖直上抛中的能量关系，考查了从图像读取数据、重力势能公式、机械能组成以及动能变化等核心知识点。图像中 $E_{\text{总}}$ 下降说明有空气阻力，且阻力恒定（斜率不变）。
变式思考：若要求空气阻力大小，可由 $W_f = \Delta E_{\text{总}} = 80-100 = -20\,\text{J}$，即克服阻力做功 $20\,\text{J}$，
