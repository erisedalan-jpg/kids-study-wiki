闭合电路欧姆定律

考点闭合电路欧姆定律权重52真题数10学科物理父主题恒定电流

考点定位

  • 父主题：恒定电流
  • 权重 weight：52
  • 真题数：10；年份跨度：2008–2022
  • 出现题位：选择3 选择4 选择5 选择6 选择8 选择10 选择11
  • 难度分布：中9 难1

知识精要

  • 闭合电路欧姆定律：闭合电路中的电流 $I$ 与电源电动势 $E$ 成正比，与内外电阻之和成反比。 $$I = \frac{E}{R + r}$$ 路端电压（电源两极间电压）： $$U = E - Ir$$ 适用条件：外电路为纯电阻电路，且 $E$、$r$ 恒定。

  • 电源的 $U$–$I$ 图像：由 $U = E - Ir$ 得，图像为一条倾斜直线。纵轴截距为电动势 $E$，斜率绝对值为内阻 $r$（注意有时纵轴起点不为零导致截距误导）。图像与横轴交点对应短路电流 $I_{short}=E/r$。

  • 闭合电路中的功率与效率：电源总功率 $P_{总}=EI$，输出功率 $P_{出}=UI$，内耗功率 $P_{内}=I^2 r$。当 $R=r$ 时输出功率最大，但效率并非最高。

  • 电磁感应中的闭合电路：感应电动势 $E$（动生：$E=Blv$ 或 $E=\tfrac{1}{2}Bl^2\omega$ 等；感生：$E = n\frac{\Delta \Phi}{\Delta t}$）充当“电源电动势”，内阻为产生感应电动势的那部分导体的电阻。电流仍满足 $I = \frac{E}{R+ r}$，安培力 $F = BIl$，焦耳热 $Q = I^2 R t$。

  • 电表改装原理：利用闭合电路欧姆定律与串并联关系。小量程电流表（表头）串联大电阻改装为电压表，并联小电阻改装为电流表。多用电表的挡位切换通过改变内部电路连接实现。

解题方法与套路

  1. 电磁感应类综合问题的“三步曲”
  2. 找电源：确定哪部分导体或回路产生感应电动势，算出 $E$（动生用 $E=Blv_{\text{有效}}$，感生用法拉第定律 $E=n\frac{\Delta \Phi}{\Delta t}$），并明确内阻 $r$。
  3. 画电路：将产生电动势的部分视为电源，其余部分看作外电路，等效成串并联关系，求出总电阻 $R_{\text{总}}$。

  4. 用定律：由闭合电路欧姆定律求电流 $I = \frac{E}{R_{\text{总}}}$，再求路端电压、安培力、电功、电热等。

  5. 测电源电动势与内阻的实验通法

  6. 公式变形法：根据实验电路写出闭合电路欧姆定律的具体形式（如 $E = U + \frac{U}{R_V \parallel R_0}r$ 或 $E = U + \frac{U}{R}r$），将其整理成线性关系 $y = kx + b$，利用图像斜率、截距求得 $E$、$r$。
  7. 图像处理：常见如 $\frac{1}{U}$–$R$ 图像，则由 $\frac{1}{U} = \frac{r}{E}\cdot\frac{1}{R} + \frac{1}{E}$ 得斜率为 $\frac{r}{E}$，截距为 $\frac{1}{E}$，进而求解。

  8. 误差分析：注意电压表分流或电流表分压对测 $E$、$r$ 的影响，可用等效电源法或图像修正法。

  9. 电磁感应图像问题（$i$–$t$、$v$–$t$ 等）

  10. 分段分析：按运动过程或磁场变化分段，每一段确定电动势和电流的大小、方向。
  11. 判断大小：由 $E = Blv$ 或 $\frac{\Delta B}{\Delta t}S$ 计算，考虑速度变化时 $v$ 可能影响安培力进而改变加速度，导致 $v$–$t$ 曲线非线性。

  12. 判断方向：用楞次定律或右手定则，注意规定的正方向，图像中正负对应方向。

  13. 多用电表改装计算

  14. 明确开关接不同位置时的电路结构，利用满偏电流和量程要求，依据欧姆定律列方程求解串联电阻或并联电阻的值。

高频易错

  • 内、外电阻不分：在电磁感应问题中，产生 $E$ 的导体本身有电阻时，该电阻就是电源内阻 $r$，代入 $I = E/(R+r)$ 时不能遗漏。计算焦耳热时，$Q = I^2 R t$ 中的 $R$ 是产生热量的那部分电阻，内外要分清。
  • 有效长度找错：安培力公式 $F = BIl$ 中的 $l$ 是导线在磁场中的有效切割长度，且在磁场内的部分才受安培力。例如对角线水平放置的正方形框，有效长度为对角线在磁场内的投影长度等。
  • 图像斜率、截距误读：在 $U$–$I$ 图像中，若纵轴起点不是 0，则纵轴截距不等于电动势，需用两点斜率求内阻。在 $\frac{1}{U}$–$R$ 等线性图像中，斜率与截距对应参数易弄反，需要将表达式严格写成 $y=kx+b$ 后对比求得。
  • 方向与正负号混淆：画 $i$–$t$ 图像时，要先规定正方向，用楞次定律逐段判定感应电流方向，注意进出场时方向相反，磁场方向交替也会导致电流方向改变。忽略方向会导致图像正负画反。
  • 动态过程中的加速度变化：在安培力参与下，速度变化会引起感应电动势、电流、安培力变化，加速度非恒定，$v$–$t$ 图斜率不断变化。误认为是匀变速将导致错选。完全进入磁场后回路中磁通量不变，没有感应电流，不受安培力，物体可能匀速。

代表题精讲

题目（2022全国乙-11）：边长为 $l=0.40\,\text{m}$ 的正方形金属框，单位长度电阻 $\lambda = 5.0\times 10^{-3}\,\Omega/\text{m}$。框上方有方向垂直于框面的匀强磁场，磁感应强度 $B(t) = 0.3 - 0.1 t\,(\text{SI})$。$t=0$ 到 $t=3.0\,\text{s}$ 内，求：(1) $t=2.0\,\text{s}$ 时金属框所受安培力大小；(2) $0$ 到 $2.0\,\text{s}$ 内金属框产生的焦耳热。

思路
由 $B(t)$ 得磁场均匀减小，产生感生电动势。正方形框总电阻 $R = 4l\lambda$。用 $E = \frac{\Delta \Phi}{\Delta t} = S\left|\frac{\Delta B}{\Delta t}\right|$ 求电动势，$S$ 为框面积 $l^2$，但题目图中框的一条对角线水平，且磁场方向垂直于框面，所以整个框均在磁场中，面积 $S = l^2$（题目中实际上感应电动势计算用了 $\frac{1}{2} l^2 \frac{\Delta B}{\Delta t}$，原因是磁场只分布在金属框对角线一侧？仔细审题：“金属框的一条对角线水平，其下方有方向垂直于金属框所在平面的匀强磁场”，所以只有框的一半面积在磁场中！对，有效面积应为 $\frac{1}{2}l^2$。这正是易错点。之后由闭合电路欧姆定律求 $I$，安培力 $F = B I L_{\text{有效}}$，有效长度 $L_{\text{有效}} = \sqrt{2} l$。焦耳热 $Q = I^2 R t$。

步骤
1. 总电阻：$R = 4l\lambda = 4\times 0.4\times 5\times 10^{-3}\,\Omega = 0.008\,\Omega$。
2. 感应电动势：磁场仅覆盖半个正方形（下方三角形区域），有效面积 $S = \frac{1}{2}l^2$，$\left|\frac{\Delta B}{\Delta t}\right| = 0.1\,\text{T/s}$，故 $E = S\frac{\Delta B}{\Delta t} = \frac{1}{2}\times 0.4^2 \times 0.1 = 0.008\,\text{V}$。
3. 电流：$I = \frac{E}{R} = \frac{0.008}{0.008} = 1\,\text{A}$，且恒定。
4. $t=2.0\,\text{s}$ 时磁感应强度 $B = 0.3 - 0.1\times 2 = 0.1\,\text{T}$。边框处于磁场中的有效切割长度 $L = \sqrt{2} l$，安培力 $F = B I L = 0.1 \times 1 \times \sqrt{2} \times 0.4 = 0.04\sqrt{2}\,\text{N}$。
5. 焦耳热：$Q = I^2 R t = 1^2 \times 0.008 \times 2.0 = 0.016\,\text{J}$。

点评/变式
误将整个正方形面积代入是典型陷阱。有效面积与有效长度都需要根据磁场区域仔细判断。此类感生电动势与安培力结合题，关键是分清“源”与“路”，以及正确几何分析。

题目（2021全国乙-10）：用图(a)电路测电动势 $E\approx 1.5\text{V}$、内阻 $r<2\Omega$。电压表量程 $1\text{V}$，内阻 $R_V=380.0\Omega$，定值电阻 $R_0=20.0\Omega$，电阻箱 $R$。完成填空：(1)为保护电压表，闭合开关前电阻箱阻值选_；(3)用 $R,R0,R_V,E,r$ 表示 $\frac{1}{U}$ 得__；(4)由 $\frac{1}{U}$–$R$ 图线求 $E,r$。

思路
(1) 保护电压表需使分压不超过量程。将 $R_0$ 与电压表并联后再与电阻箱 $R$ 串联，考虑电路闭合时的分压关系，$R$ 较大时分压多，电压表分压小，故选 $15.0\Omega$。(3) 由闭合电路欧姆定律 $E = U + \left(\frac{U}{R_V} + \frac{U}{R_0}\right)(R+r)$，化简为 $\frac{1}{U} = \frac{1}{E} + \frac{R+r}{E}\left(\frac{1}{R_V} + \frac{1}{R_0}\right)$，整理成 $\frac{1}{U} = \frac{R}{E}\left(\frac{1}{R_V}+\frac{1}{R_0}\right) + \frac{1}{E} + \frac{r}{E}\left(\frac{1}{R_V}+\frac{1}{R_0}\right)$，图像斜率与截距可求 $E,r$。

步骤
1. 保护电压表：$E\approx 1.5\,\text{V}$，若 $R$ 过小，并联部分电压可能超过 1V。粗略估算，$R_0=20\Omega$ 与 $R_V=380\Omega$ 并联电阻 $R_{\text{并}}\approx 19\Omega$，当 $R=5\Omega$ 时，总电阻约 $24\Omega$，电流约 $0.0625\text{A}$，并联部分电压约 $1.19\text{V}>1\text{V}$，不安全；$R=15\Omega$ 时并联部分电压约 $0.84\text{V}$，安全。选 $15.0\Omega$。
2. 表达式：$I_{\text{总}} = \frac{U}{R_V} + \frac{U}{R_0}$，$E = U + I_{\text{总}}(R+r)$，代入得
$$E = U + U\left(\frac{1}{R_V}+\frac{1}{R_0}\right)(R+r)$$
变形：
$$\frac{1}{U} = \frac{1}{E}\left[1 + \left(\frac{1}{R_V}+\frac{1}{R_0}\right)(R+r)\right] = \frac{R}{E}\left(\frac{1}{R_V}+\frac{1}{R_0}\right) + \frac{1}{E} + \frac{r}{E}\left(\frac{1}{R_V}+\frac{1}{R_0}\right)$$
3. 由题给图线截距 $b$ 和斜率 $k$，有 $\frac{1}{E} + \frac{r}{E}\left(\frac{1}{R_V}+\frac{1}{R_0}\right)=b$，$\frac{1}{E}\left(\frac{1}{R_V}+\frac{1}{R_0}\right)=k$。联立解得 $E = \frac{1}{k}\left(\frac{1}{R_V}+\frac{1}{R_0}\right)$，再代入求出 $r$。

点评/变式
此类实验题关键在于正确写出闭合电路的原始方程，不要遗漏电压表的分流。把非线性关系转化为直线，通过斜率和截距求解，可减小偶然误差。注意电压表内阻并非理想无穷大，测量时必须考虑其影响。

题目（2018新课标Ⅱ-05）：间距相同、方向交替的矩形匀强磁场区域，宽度均为 $l$，边长为 $l$ 的正方形金属线框匀速向左运动，线框中感应电流 $i$ 随时间变化的正确图线是？

思路
线框总有一边切割磁感线，左右两条边所处的磁场方向可能相同或相反，导致电动势叠加或抵消。根据线框运动到不同位置分段：线框进入第一个磁场区域、跨越边界时两边在不同方向磁场中、完全在反向磁场区域等。逐段求出 $E$，方向用楞次定律判定，用 $i=E/R$ 画图。

步骤
设线框电阻 $R$，速度 $v$，磁感应强度大小 $B$。
- 第一阶段：线框右侧边进入右侧第一个磁场（设向上），产生逆时针电流，取为正，$i=Blv/R$ 恒定。
- 第二阶段：右侧边进入邻接反向磁场（向下），而左侧边仍在原向上磁场中，两边产生的电动势同向叠加，$E=2Blv$，电流大小加倍，方向为顺时针（负向），故 $i=-2Blv/R$。
- 第三阶段：右侧边离开磁场区域，左侧边处于向下磁场中，$E=Blv$，电流顺时针
