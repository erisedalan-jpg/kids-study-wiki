频率关系

考点频率关系权重6真题数1学科物理父主题机械振动 与 机械波

考点定位

  • 父主题：机械振动 与 机械波
  • 权重 weight：6
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：解答15
  • 难度分布：中1

知识精要

  • 波尔频率条件：原子从高能级 $E_n$ 向低能级 $E_m$ 跃迁时，辐射光子的频率 $v$ 满足 $h v = E_n - E_m$；吸收光子时 $h v = E_n - E_m$（$n>m$）。
  • 一群处于量子数 $n$ 的激发态氢原子，向低能级跃迁时，可能发出的光谱线条数为 $N = C_n^2 = \frac{n(n-1)}{2}$。
  • 在跃迁产生的所有谱线中，频率最高（波长最短）的谱线对应能级差最大的跃迁，通常为从最高激发态直接跃迁至基态。
  • 若仅观测到三条谱线 $v_3 > v_2 > v_1$，则原子被激发到了 $n=3$ 的能级（因为 $C_3^2=3$），且频率之间存在代数和关系：$v_3 = v_2 + v_1$，这源于能级差的叠加 $E_3 - E_1 = (E_3 - E_2) + (E_2 - E_1)$。
  • 入射光（激发光）的频率 $v_0$ 必须恰好等于从基态跃迁到该激发态的能级差对应的频率，即 $h v_0 = E_n - E_1$。
  • 该部分内容虽以原子物理为载体，但与机械波的频率关系（如干涉、衍射的频率条件）有相通之处，均强调频率与能量（或波源振动）的对应，以及多频率间的线性关系。

解题方法与套路

  1. 由谱线条数反推能级
    观测到的独立光谱线数目 $N$，利用 $N = \frac{n(n-1)}{2}$ 求出氢原子被激发的最高能级量子数 $n$。常见数据：$N=1$ 对应 $n=2$；$N=3$ 对应 $n=3$；$N=6$ 对应 $n=4$。

  2. 确定最高频率谱线
    最高频率 $v_{\max}$ 一定对应从最高能级 $n$ 直接跃迁到基态 $n=1$，满足 $h v_{\max} = E_n - E_1$。

  3. 建立频率代数和关系
    通过能级图列出所有可能的跃迁，利用能级差的叠加性写出频率关系式。典型结论：最高频率等于其他各频率之和（仅当谱线从同一最高能级分步跃迁至基态时成立，如 $n=3$ 时 $v_{31}=v_{32}+v_{21}$）。

  4. 对照入射光子频率
    若用频率 $v_0$ 的光照射基态原子使之激发，则 $h v_0$ 必须等于从基态到该最高能级的能量差，即 $v_0$ 与最高发射频率 $v_{\max}$ 可能相等（若直接回到基态），也可能不等，需具体计算。

高频易错

  • 误认为“观测到几条谱线，原子就被激发到几能级”，这是错误的。能级数 $n$ 与谱线条数 $N$ 是组合关系，非一一对应。
  • 混淆吸收光频率 $v_0$ 与发射谱线频率的关系，尤其容易错误地认为 $v_0 = v_1 + v_2 + v_3$ 或直接等于某一谱线频率，忽略了吸收是从基态到单一激发态的单次跃迁。
  • 解题时忽略“仅能观测到”这一限制，意味着原子只被激发到某一确定能级，没有发生进一步电离或级联激发。
  • 套用频率相加关系时不画能级图，导致写错各频率间的加减关系。务必用能级差验证：若 $v_a = v_b + v_c$，则高能级差必须等于另外两个能级差之和。
  • 将原子跃迁的频率关系与机械波的频率关系混用，例如直接认为频率由波源决定而忽略能级结构，导致错误。

代表题精讲

题目（2010 新课标Ⅰ 高频考点）
用频率为 $v_0$ 的光照射大量处于基态的氢原子，在所发射的光谱中仅能观测到频率分别为 $v_1$、$v_2$、$v_3$ 的三条谱线，且 $v_3 > v_2 > v_1$，判断正确选项。
选项涉及 $v_0$ 与 $v_1$ 的大小、$v_3 = v_2 + v_1$ 等关系。

思路
“仅能观测到三条谱线”暗示氢原子被激发到了 $n=3$ 的能级（因为 $C_3^2=3$）。以此为基础，画出氢原子能级示意图（$n=1,2,3$），标出所有可能的跃迁及对应的频率，利用能级差的叠加性得出 $v_3$、$v_2$、$v_1$ 之间的关系，再结合入射光频率 $v_0$ 的意义进行判断。

步骤 1. 由谱线条数 $N=3$ 可知最高能级 $n=3$，跃迁路径为：
$3 \rightarrow 1$（频率 $v_3$），$3 \rightarrow 2$（频率 $v_2$），$2 \rightarrow 1$（频率 $v_1$）。
因为能级差 $E_3 - E_1 > E_3 - E_2 > E_2 - E_1$，且 $v \propto \Delta E$，所以 $v_3$ 最大，$v_2$ 次之，$v_1$ 最小，与题干一致。 2. 能级差叠加：$E_3 - E_1 = (E_3 - E_2) + (E_2 - E_1)$，两边除以 $h$ 得 $v_3 = v_2 + v_1$。故 B 选项正确。 3. 入射光频率 $v_0$ 使原子从基态跃迁到 $n=3$，所以 $h v_0 = E_3 - E_1 = h v_3$，因此 $v_0 = v_3$。显然 $v_0 > v_1$，A 选项 $v_0 < v_1$ 错误；C 项 $v_0 = v_1 + v_2 + v_3$ 错误。

点评/变式
该题核心是利用谱线数目锁定能级，再通过能级差叠加构建频率代数关系，是氢原子光谱的经典题型。要注意“仅能观测到”暗含单一最高能级，若题目改为“可能观测到三条谱线”，则最高能级可能是 $n=3$ 或更高（但只利用了其中部分跃迁），需要分类讨论。
变式训练：若用电子碰撞激发氢原子，观测到 $6$ 条谱线，求入射电子最小动能等。始终把握“谱线条数→最高能级→能级差关系”的解题链条。
