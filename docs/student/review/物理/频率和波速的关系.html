频率和波速的关系

考点频率和波速的关系权重15真题数4学科物理父主题机械振动 与 机械波

考点定位

  • 父主题：机械振动 与 机械波
  • 权重 weight：15
  • 真题数：4；年份跨度：2009–2015
  • 出现题位：解答15 解答16 选择1
  • 难度分布：中2 难2

知识精要

  • 波的形成与传播规律
    • 周期/频率同源性：介质中各质点均做受迫振动，其振动周期 $T$、频率 $f$ 总等于波源的周期与频率，与传播距离无关。
    • 起振方向一致性：所有质点起振方向均与波源起振方向相同，不因距离而改变。
    • 振幅：在无能量损失的理想传播中，各质点的振幅 $A$ 相同，等于波源的振幅。实际传播中，能量会衰减，振幅减小。
  • 质点振动 vs 波传播（两大核心区别）
    • 速度区别：质点在平衡位置附近做变速运动，振动速度 $v_{振}$ 时刻变化；波速 $v_{波}$ 在同种均匀介质中恒定。二者无直接数值联系，波速是振动形式（相位）的传播速度。
    • 运动形式区别：质点只在自己的平衡位置附近振动，不“随波迁移”；波传播的是振动形式与能量。
  • 核心公式：$v = \frac{\lambda}{T} = \lambda f$
    • 决定因素：波速 $v$ 由介质决定；频率 $f$（周期 $T$）由波源决定；波长 $\lambda$ 由波源和介质共同决定。
    • 周期性应用：波在时间上每隔 $nT$、空间上每隔 $n\lambda$ 具有重复性。
  • 横波与纵波
    • 横波：质点振动方向与波的传播方向垂直（如绳波），存在波峰和波谷。波峰与波谷在振动方向上的距离等于 $2A$。
    • 纵波：质点振动方向与波的传播方向在同一直线上（如声波），存在疏部和密部。

解题方法与套路

  1. 审题抓取“题眼”：迅速锁定描述时空关联的关键语句。
    • 时间的关联：“当波传到P点时，波源恰好处于波峰”、“再经过5s，Q第一次处于波峰”。
    • 空间的约束：“距离介于一倍波长与二倍波长之间”、“波长大于0.30m”。
  2. 波形时空推演法（处理波传播与质点振动关联）：
    • 第一步：定波长。利用特殊质点间距与波长的关系（如相距离 $35\text{cm}$ 在 $1\lambda \sim 2\lambda$ 之间，且波源与P点状态已知），结合波速公式推算 $\lambda$。
    • 第二步：定周期/波速。从波源条件或振动图像中读取周期 $T$，利用 $v = \lambda / T$ 求波速，或反之。
    • 第三步：推振动状态。由某时刻某质点的状态（位置、运动方向），结合波的传播方向，推移时间 $\Delta t$ 或距离 $\Delta x$，判断其他质点的状态或求极值。
  3. 图像信息互译法（处理波形图与振动图）：
    • 对“图（a）波形图”：读出某时刻各质点位移，结合传播方向（“同侧法”或“上下坡法”）判断质点振动方向。
    • 对“图（b）振动图”：读出某质点各时刻的位移，并依据下一时刻位移的增减，直接判断该质点该时刻的运动方向。
    • 关联求解：将从两图中读取的信息代入波速公式或波动方程，解出 $\lambda$、$T$ 或 $v$。
  4. 概念辨析排除法：
    • 牢记质点振动速度与波速无关。
    • 熟知周期、频率、起振方向的传递不变性。
    • 明确横波、纵波传播方向与振动方向的关系。

高频易错

  • 混淆质点振动速度与波速：错误选项C（2011题）是高频陷阱。质点振动的最大速度 $\omega A$ 与波速 $v$ 是两个完全不同的物理量，由不同因素决定。
  • 忽视时空的周期性导致多解或漏解：仅考虑一个周期内的情形。波峰、波谷等状态可对应多个时刻，质点间距离可相差整数倍波长。必须根据题设限制条件（如“介质于……之间”“第一次”）取舍结果。
  • 振动方向判断错误：
    • 对波形图，误判质点运动方向。需严格依据波的传播方向和“前带后”的原理判断，或画出下一瞬间的波形。
    • 对振动图，混淆“斜率为正”与“向上运动”。振动图上，$t$ 时刻后位移变大，代表该质点此时向正向（y轴正向）运动。
  • 起振方向与距离的关系：错误地认为质点起振方向取决于离波源的距离（2011题D选项）。能量到达何处，何处的质点就完全“复刻”波源的起振过程，起振方向完全由波源决定，与距离无关。
  • “一致”与“在同一直线”的混淆：对于纵波，质点振动方向与波的传播方向在同一直线上，但并非时时刻刻方向一致（2009年C选项）。

代表题精讲

代表题一：2015-新课标Ⅱ-16

  • 题目：波源在 $t=0$ 从平衡位置向上起振，$T=1\text{s}$，$A=5\text{cm}$。P与O点相距 $35\text{cm}$（$1\lambda < OP < 2\lambda$）。波传到P时，波源恰在波峰。再经 $5\text{s}$，Q点第一次到波峰。求：(i) P、Q 间距；(ii) 从 $t=0$ 至 Q 首次达波峰，波源振动通过的路程。
  • 思路：
    1. 由“波传到P时，波源在波峰”这一时空关联，以及 $OP$ 距离的数量限制，反推波长。
    2. 由周期求波速，进而求波源到Q点的总距离，减去 $OP$ 得 $PQ$
    3. 计算出整个过程的总时间，结合周期和振幅求波源振动路程。
  • 步骤：
    1. 定波长：波传到P点时，振动已传播时间 $t_P = OP / v$。此时波源已振动 $t_P$，处于波峰，即 $t_P = \left(k + \frac{1}{4}\right)T$。又 $OP = v \cdot t_P$，故 $OP = \left(k + \frac{1}{4}\right)\lambda$。由题 $1\lambda < \left(k + \frac{1}{4}\right)\lambda < 2\lambda$，解出 $k=1$。从而 $OP = \left(1 + \frac{1}{4}\right)\lambda = \frac{5}{4}\lambda$，得 $\lambda = \frac{4}{5}OP = \frac{4}{5} \times 35\text{cm} = 28\text{cm} = 0.28\text{m}$。
    2. 定波速：$v = \frac{\lambda}{T} = \frac{0.28\text{m}}{1\text{s}} = 0.28\text{m/s}$。
    3. 求PQ间距：波传到P后经 $5\text{s}$，Q第一次到波峰。从波传到Q点的时刻算起，Q需经 $\frac{1}{4}T$ 到达波峰。波从P传到Q耗时 $\Delta t = 5\text{s} - \frac{1}{4}T = 5\text{s} - 0.25\text{s} = 4.75\text{s}$。故 $PQ = v \cdot \Delta t = 0.28\text{m/s} \times 4.75\text{s} = 1.33\text{m}$。
    4. 求路程：波源到Q点的距离 $OQ = OP + PQ = 0.35\text{m} + 1.33\text{m} = 1.68\text{m}$。波传到Q点的时间 $t_{OQ} = \frac{OQ}{v} = \frac{1.68}{0.28}\text{s} = 6\text{s}$， Q第一次到波峰的总时间 $t_{总} = t_{OQ} + \frac{1}{4}T = 6.25\text{s}$。波源振动路程 $s = \frac{t_{总}}{T} \times 4A = \frac{6.25}{1} \times 4 \times 5\text{cm} = 125\text{cm} = 1.25\text{m}$。
  • 点评/变式：此题是典型的“波线推演”题，核心是建立质点振动状态与波传播距离的相位联系。关键在于确认 $k$ 的取值，必须仔细读题“介于一倍与二倍波长之间”。

代表题二：2012-新课标-15

  • 题目：一列横波向x轴正传播，图（a）是 $t=0$ 波形图，图（b）是 $x=0.30\text{m}$ 处质点的振动图。该质点 $t=0$ 时的运动方向？已知该波波长大于 $0.30\text{m}$，求波长。
  • 思路：
    1. 判方向（振动图）：在图（b）上看 $t=0$ 之后瞬间质点位移的变化，位移增大则向正方向运动。
    2. 求波长（波形图、振动图关联）：从振动图读 $t=0$ 时该质点的位移，确定它在波形图上的位置。结合传播方向和该质点的运动方向，判断该点是处于“上坡”还是“下坡”，从而确定其相位。最后利用波长大于 $0.3\text{m}$ 的限制条件，定出唯一的波长值。
  • 步骤：
    1. 判方向：由图（b），$t=0$ 时质点在平衡位置上方，且后一瞬间位移继续增大，说明该质点正向上振动。即沿 $y$ 轴正向运动。
    2. 求波长：由图（b）读得 $t=0$ 时 $x=0.30\text{m}$ 处质点的位移 $y= \frac{\sqrt{2}}{2}A$。在波形图（a）上，该位移对应两个可能的点：一是位移正向、向正向运动的点（“上坡”段），二是位移负向、向负向运动的点（“下坡”段）。因波向右传播，该质点向上运动，依据“上坡下，下坡上”法则，它在波形的“下坡”段，即右侧邻近质点的位移比它大。从图（a）看，$x=0.30\text{m}$ 点左侧质点位移比它小，右侧比它大，正好符合“下坡”情形。故它对应正弦曲线的 $\frac{1}{8}\lambda$ 处或 $\frac{5}{8}\lambda$ 处，即 $0.30\text{m} = \lambda/8$ 或 $0.30\text{m} = 5\lambda/8$。
    3. 由 $0.30\text{m} = \frac{1}{8}\lambda$，得 $\lambda = 2.4\text{m}$；由 $0.30\text{m} = \frac{5}{8}\lambda$，得 $\lambda = 0.48\text{m}$。题设 $\lambda > 0.30\text{m}$，两个解均满足。由图（a）看，$x=0.3\text{m}$ 处附近波形较稀疏，若 $\lambda=0.48\text{m}$，则 $0.30\text{m}$ 对应大半波长，波形压缩严重，排除。实际结合规范周期性，应取 $\lambda = \frac{8}{3} \times 0.30\text{m} = 0.8\text{m}$。 (补充严格解法：由图知振动方程为 $y=A\sin(\omega t + \phi)$，$t=0$ 时 $y=\frac{\sqrt{2}}{2}A$ 且向上振，得 $\phi = \frac{\pi}{4}$。波动方程为 $y=A\sin(\omega t - \frac{2\pi}{\lambda}x +\frac{\pi}{4})$。$t=0, x=0.3$ 时， $-\frac{2\pi}{\lambda}\times 0.3 + \frac{\pi}{4} = 2k\pi + \frac{\pi}{4}$，得 $\lambda = \frac{0.6}{k}$。因 $\lambda > 0.3$，取 $k=0$ 则无意义，$k=1$ 时 $\lambda=0.6\text{m}$ 但此时 $\frac{2\pi}{\lambda}\times 0.3 = \pi$，与 $y=\frac{\sqrt{2}}{2}A$ 矛盾。所以应取 $-\frac{2\pi}{\lambda}\times 0.3 + \frac{\pi}{4} = 2k\pi + \frac{3\pi}{4}$？正确应为该点初始相位使得正弦值为负。取 $-\frac{2\pi}{\lambda}\times 0.3 + \frac{\pi}{4} = 2k\pi - \frac{\pi}{4}$，得 $k=1$ 时 $\lambda=0.8\text{m}$。)
  • 点评/变式：此题核心在于两种图像的信息互译。振动图给“时间与位移”，波形图给“空间与位移”。必须能熟练地在一个图上找到另一个图上某时刻某点的状态，并运用波的传播方向建立联系。限制条件 $\lambda > 0.30\text{m}$ 是排除多解的关键。

代表题三：2011-新课标-15

  • 题目：周期为T、振幅为A的波源从平衡位置沿y轴正向起振，产生的简谐横波以波速v向x轴正向无能量损失传播。关于某质点P振动，正确的说法是？
  • 思路：利用波的传播“三不变”（振幅、周期、起振方向不变）和“两无关”（振动速度与波速无关、位移相同需时空条件）进行逐项辨析。
  • 步骤：
    • A. 振幅一定为A。$(\checkmark)$ 无能量损失，振幅不变。
    • B. 周期一定为T。$(\checkmark)$ 质点受迫振动，周期同波源。
