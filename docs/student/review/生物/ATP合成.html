ATP合成

考点ATP合成权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • ATP的结构与功能：ATP（三磷酸腺苷）是高能磷酸化合物，结构简式 $A-P\sim P\sim P$，含2个高能磷酸键。远离腺苷（$A$）的高能磷酸键断裂时释放大量能量，直接为细胞生命活动供能。
  • ATP的合成过程：
  • 条件：需要原料 $\text{ADP}$ 与 $\text{Pi}$（磷酸），以及能量来源和酶的催化。
  • 能量来源：
    • 光能：在光合作用光反应中，叶绿体利用光能，催化 $ \text{ADP} + \text{Pi} \xrightarrow{\text{酶}} \text{ATP} $。此过程属于光合磷酸化，磷酸是必需反应物。
    • 化学能：在细胞呼吸中，有机物氧化分解释放的化学能，驱动 $\text{ADP}$ 与 $\text{Pi}$ 在细胞质基质和线粒体中合成 $\text{ATP}$。
  • 场所：细胞质基质（糖酵解）、线粒体基质（柠檬酸循环）、线粒体内膜（氧化磷酸化）、叶绿体类囊体薄膜（光反应）。
  • ATP合成的核心要点（从本题提炼）：
  • 光反应中 $\text{Pi}$ 是合成 $\text{ATP}$ 的直接原料（A项正确）。
  • 叶绿素吸收光能属于物理过程，不需要酶参与；但后续的电子传递和 $\text{ATP}$ 合成需酶催化（B项正确）。
  • 细胞呼吸为一切耗能生命活动（如病毒核酸复制）提供 $\text{ATP}$（D项正确）；病毒自身无能量代谢系统，完全依赖宿主细胞呼吸产能。
  • 乳酸是无氧呼吸的终产物，其本身不分解供能；剧烈运动时所需能量直接来源于 $\text{ATP}$ 的水解，而 $\text{ATP}$ 由细胞呼吸（有氧和无氧）合成（C项错误）。

解题方法与套路

此类“叙述错误的是”题目，选项跨域光合与呼吸作用核心概念，可采用“三步核实法”： 1. 拆分选项，定位知识点：将每个选项拆分为“前提-结论”或“过程-物质”关系，快速匹配教材基础定义。
- 例：A项→光反应中$\text{ATP}$原料；B项→色素吸收光能是否需酶；C项→乳酸的作用；D项→病毒的能量来源。 2. 调用核心原理逐项判正误：
- 对合成代谢，强调“原料、能量、酶、场所”四要素。
- 对能量流动，牢记“直接能源物质永远是$\text{ATP}$”，各类中间产物（如乳酸、酒精）不能直接供能。
- 对生物类型，病毒、原核生物的特殊性（结构缺损、依附宿主）须作为检查重点。 3. 对比矛盾点，锁定错误项：将明显违背基本事实的项（如C项：乳酸分解供能）直接定为答案。若犹豫，反向审视其他选项，利用排除法确认。

高频易错

  • 错把代谢产物当直接能源：认为乳酸、酒精、糖原等物质直接提供能量。事实是，这些物质需先经转化，能量最终储存在$\text{ATP}$中才能被利用。剧烈运动时肌细胞经无氧呼吸产生乳酸，$\text{ATP}$合成仍依赖糖酵解过程，乳酸不再分解放能。
  • 混淆“吸能过程”与“催化过程”：误以为所有吸收光能的步骤都需要酶。光合色素吸收光能是物理激发，不需酶；而电子传递、二氧化碳固定等后续生化反应才需要酶催化。
  • 忽略特殊生物的代谢依存性：对病毒、寄生生物的认知局限。病毒仅含核酸和蛋白质外壳，无呼吸酶系统，其核酸复制、蛋白质合成所需$\text{ATP}$全部由宿主细胞呼吸作用提供。
  • 对“合成反应物”概念不清：混淆催化条件与反应物。$\text{ATP}$合成原料为$\text{ADP}$和$\text{Pi}$，磷酸（$\text{Pi}$）是反应物而不是催化剂或能量来源。

代表题精讲

题目：（2014-新课标Ⅱ-06）关于光合作用和呼吸作用的叙述，找出错误选项。四个选项分别涉及光反应原料、色素吸能、乳酸功能、病毒复制供能。

思路：
本题为多考点整合型选择题，核心在测试对$\text{ATP}$合成途径、吸能本质及能量直接来源的理解。采用“直击谬误”策略：直接审视C项，剧烈运动供能物质是否为乳酸，调用无氧呼吸根本目的（产$\text{ATP}$）即可判定。

步骤：
1. A项核实：光反应中，水光解产生$\text{H}^+$，$\text{ADP}+\text{Pi} \xrightarrow[\text{酶}]{\text{光能}} \text{ATP}$，磷酸是必需反应物。正确。
2. B项核实：叶绿素吸收红光、蓝紫光，属于色素分子物理特性，不需酶；之后的电子传递才需酶。正确。
3. C项辨析：人体无氧呼吸终产物是乳酸，该过程释放少量能量，一部分储存于$\text{ATP}$中。肌细胞收缩利用$\text{ATP}$水解能，乳酸堆积后需运至肝脏重新转化，并不直接分解供能。“由乳酸分解提供”混淆了能量来源。错误。
4. D项核实：病毒无细胞结构，核酸复制、蛋白质装配等耗能过程均利用宿主细胞呼吸作用产生的$\text{ATP}$。正确。
综合判断，选C。

点评/变式：
- 此题陷阱在于日常用语误导（“乳酸堆积导致肌肉酸痛”，错认为乳酸还能供能）。复习中务必建立“$\text{ATP}$—直接能源”的绝对对应关系。
- 变式预测：可能将C项改为“无氧呼吸合成$\text{ATP}$的能量来自葡萄糖分解”“骨骼肌细胞中$\text{ATP}$可由丙酮酸进一步分解产生”等，考法一致，均强调$\text{ATP}$合成途径及直接供能角色。抓住“谁消耗$\text{ATP}$、谁产生$\text{ATP}$”的逻辑主线即可应对。
