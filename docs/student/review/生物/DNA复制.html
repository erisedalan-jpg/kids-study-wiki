DNA复制

考点DNA复制权重25真题数4学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：25
  • 真题数：4；年份跨度：2014–2024
  • 出现题位：选择1 选择2 选择5
  • 难度分布：易3 中1

知识精要

  • DNA复制的时机与场所
    • 主要发生在细胞分裂间期（有丝分裂间期与减数第一次分裂前的间期）的细胞核中。
    • 真核细胞的叶绿体和线粒体（半自主性细胞器，含裸露环状DNA）中也可发生。
  • DNA复制的特点
    • 半保留复制：解旋后的两条母链分别作为模板，合成新的子链，新形成的DNA分子中一条链为旧链，一条链为新链。
    • 边解旋边复制：提高复制效率。
  • 有丝分裂中染色体与DNA的数量变化（以体细胞染色体数为 $2N$ 为例）
    • 间期（关键）：DNA完成复制，数目由 $2N \rightarrow 4N$；每个染色体形成两个姐妹染色单体，由同一个着丝点连接。
    • 前期、中期：染色体数 $2N$（形态固定、清晰，含 $2$ 个DNA），核DNA数 $4N$，染色单体数 $4N$。
    • 后期：着丝点自动分裂，姐妹染色单体分开成为独立的染色体（染色体数加倍为 $4N$），核DNA数仍为 $4N$，染色单体数降为 $0$。
    • 末期：细胞一分为二，染色体数和核DNA数恢复为 $2N$。
  • DNA与RNA的结构化学基础（易混点）
    • 基本骨架：由磷酸基团与脱氧核糖（非核糖）交替连接而成，位于双链外侧。
    • 连接键：一条链上的磷酸和脱氧核糖通过磷酸二酯键连接；两条链之间的碱基通过氢键配对（A=T, C≡G）。
    • 五碳糖差异：DNA含脱氧核糖，RNA含核糖。

解题方法与套路

  1. 明确定位分裂时期，理清“着丝点”状态 遇到涉及“染色体：DNA：染色单体”比例计算的题目，先判断时期。核心技巧在于看着丝点是否分裂：
    • 着丝点未分裂（间期G2、前期、中期）：比例为 $1:2:2$。
    • 着丝点已分裂（后期、末期）：染色单体消失，比例为 $1:1:0$。
  2. 区分“有丝分裂”与“减数分裂”的同源染色体行为
    • 有丝分裂全程存在同源染色体，但无“配对、分离”行为。
    • 试题常设陷阱，将有丝分裂后期的姐妹染色单体分开，偷换概念为减数分裂后期的“同源染色体分离”。
  3. 辨析“全能性”与“分化”的实质
    • 细胞全能性：关键指标是发育成完整个体或分化成各种类型细胞的潜能。仅分化成一两种组织器官（如卵圆细胞→肝细胞）不体现全能性。
    • 细胞分化：本质是基因的选择性表达，遗传物质（DNA）本身并未改变。
  4. 核酸检测的试剂与原理鉴别
    • DNA/RNA分布观察：甲基绿+吡罗红混合染色。盐酸改变细胞膜通透性，便于染色剂进入，同时使DNA与蛋白质分离。
    • 活细胞鉴定：活细胞的细胞膜具有选择透过性，台盼蓝等大分子染料无法进入；死细胞膜通透性改变被染成蓝色。

高频易错

  • 错将“姐妹染色单体分开”等同为“同源染色体分离”
    • 陷阱示例：果蝇体细胞有丝分裂后期，成对的同源染色体分开。正解： 有丝分裂后期分开的是姐妹染色单体，同源染色体分离仅发生在减数第一次分裂。
  • 错将“磷酸-五碳糖”的连接键记混
    • 陷阱示例：DNA单链上的磷酸和核糖通过氢键连接。正解： DNA的五碳糖是脱氧核糖，磷酸与脱氧核糖交替连接构成骨架，连接键是磷酸二酯键；碱基对之间才是氢键。
  • 误判“最终结果”为“全能性”
    • 陷阱示例：干细胞转化为肝细胞证明其具有全能性。正解： 全能性是指发育成完整个体，细胞分化为特定组织属于基因选择性表达，未体现全能性（除非发育成完整生物体）。
  • 混淆“代谢旺盛”与“死细胞”的判断依据
    • 陷阱示例：台盼蓝可将代谢旺盛的细胞染成蓝色。正解： 代谢旺盛的活细胞膜具有选择透过性，能排斥染料；死细胞膜丧失功能才会被染蓝。

代表题精讲

2024-辽宁-02（细胞增殖与分化综合辨析）

  • 题目：手术切除大鼠肝脏后，分析肝细胞增殖与卵圆细胞分化的叙述，找出错误选项。
  • 思路：运用细胞分裂、凋亡、分化及全能性概念逐项对照。注意D选项“全能性”的判断标准是“完整个体”。
  • 步骤：
    • A项：肝细胞增殖即进行有丝分裂，分裂间期必定发生DNA复制，正确。
    • B项：器官体积恢复伴随旧细胞凋亡和新细胞产生，是机体的稳态调节，正确。
    • C项：卵圆细胞分化（基因选择性表达）形成功能特化的肝细胞，正确。
    • D项：卵圆细胞仅形成新的肝细胞（一种特定组织），未形成完整的有机体或全部细胞类型，不能证明全能性，错误。故选D。
  • 点评/变式：本题是典型的“全能性”概念判断题。解题关键在于将“全能性”与“细胞分化”严格区分。任何表述只要落脚于生成特定细胞或组织而未提到“完整个体”，即可判定不体现全能性。

2021-全国乙-01（果蝇有丝分裂细节辨析）

  • 题目：分析果蝇体细胞（含8条染色体）有丝分裂的叙述，找出错误选项。
  • 思路：结合分裂时期特征，重点审查有丝分裂后期染色体行为。排除偷换“姐妹染色单体分离”与“同源染色体分离”的干扰项。
  • 步骤：
    • A项：间期DNA发生半保留复制，DNA数由8增至16，正确。
    • B项：前期染色体已完成复制，每条含2条染色单体、2个DNA，正确。
    • C项：中期染色体形态稳定、数目清晰，着丝点呈赤道板排列，是观察最佳时期，正确。
    • D项：有丝分裂后期着丝点自然分裂，姐妹染色单体分开导致染色体暂时倍增至16条。有丝分裂过程中的同源染色体并不分离，此项错误。故选D。
  • 点评/变式：“同源染色体分离”只在减数第一次分裂发生，是高考的高频陷阱词。考生只要看见“有丝分裂”和“同源染色体分离”出现在同一句，应立刻警觉并判定为错误。

2014-新课标Ⅱ-05（核酸结构基础判断）

  • 题目：关于核酸的叙述，找出错误选项。
  • 思路：紧扣DNA与RNA的化学成分差异（五碳糖种类）和化学键连接部位进行排查。
  • 步骤：
    • A项：转录由RNA聚合酶催化，将DNA信息转录至mRNA，正确。
    • B项：线粒体、叶绿体含少量DNA，可进行独立的DNA复制，正确。
    • C项：需注意DNA分子链上的五碳糖是“脱氧核糖”而非“核糖”，且一条单链中磷酸与脱氧核糖通过“磷酸二酯键”相连，不是氢键。此项表述两处错漏，错误。
    • D项：甲基绿、吡罗红混合染液可区分DNA和RNA分布，为教材实验结论，正确。故选C。
  • 点评/变式：本题杀伤力在于“磷酸和核糖”的细微表述。知识硬核考点：DNA链骨架是磷酸-脱氧核糖交替连接，碱基互补配对靠氢键；考生易在“核糖/脱氧核糖”命名和“氢键/磷酸二酯键”的位置上混淆失分。
