RNA保护

考点定位

  • 父主题：遗传与进化
  • 权重 weight：5
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • RNA 的特性与提取保护
    • RNA（核糖核酸）是基因表达过程中的关键中间分子，化学性质较 DNA 更不稳定，极易被 RNA 酶（RNase）降解。RNase 广泛存在且稳定，是提取 RNA（提取核糖核酸）时需要应对的首要问题。
    • 提取 RNA（提取核糖核酸）的关键保护措施：全程低温操作，使用 RNA 酶抑制剂（RNA 酶抑制剂），以抑制 RNase 活性，防止 RNA 降解（防止核糖核酸降解）。
    • 选材原则：优先选择细胞代谢旺盛、分裂活跃的幼嫩组织（如嫩叶）。这类组织RNA 含量高，细胞壁薄，易于破碎，便于获取高质量的 RNA。
  • 中心法则与 cDNA 的制备
    • 逆转录（反转录）：以 mRNA 为模板，在逆转录酶（反转录酶）的作用下，遵循碱基互补配对原则（A-T，U-A，G-C，C-G），合成互补 DNA（互补脱氧核糖核酸，cDNA）的过程。
    • 该过程的本质是遗传信息从 RNA（核糖核酸）流向 DNA（脱氧核糖核酸）的特殊途径，在基因工程中常用于获取真核生物不含内含子的目的基因。
  • 基因表达载体的构建
    • 目的基因不能直接导入受体细胞并表达，必须依赖运载体（如质粒）。
    • 原因在于目的基因是外源 DNA 片段，缺少在受体细胞中独立存在和表达的必需元件，至少要包括：复制原点（在受体细胞内自主复制，遗传给子代）和启动子（RNA 聚合酶识别和结合位点，驱动转录起始）。

解题方法与套路

  1. 抓取实验目的与材料特性

    • 题干若涉及从生物体中提取特定物质（RNA/蛋白质），首先分析所选材料的特性。代谢越旺盛、越幼嫩的组织，目标核酸和蛋白质含量通常越高，且细胞结构更易破碎。
    • 提取RNA 必须立即联想其“易降解”的特性，以及对应的保护剂（某酶抑制剂）作用，填写实验操作目的即可直接用“防止xx降解”的句式。

  2. 知识还原法处理过程原理

    • 看到“以 mRNA 获得 cDNA”，直接还原为“逆转录（反转录）”过程，按模板、原料、酶、原则的逻辑链作答：在逆转录酶的作用下，以 mRNA 为模板，遵循碱基互补配对原则合成 cDNA。

  3. 基因工程工具功能的反向分析

    • 问及为何不能直接将物质（如目的基因）导入，应转换为：它缺少了什么，使得它无法在细胞内独立运行？
    • 联想质粒载体的核心结构：复制原点（复制稳定性）、启动子（表达起始）、标记基因（筛选）等。将缺失的核心元件列出，即为答案要点（如无复制原点、无启动子）。

  4. 分点作答，直击关键词

    • 题目明确要求答出“两点”时，先寻找并列且最核心的原因。答题要使用专业关键词（复制原点、启动子），避免冗长描述。

高频易错

  • 概念混淆：酶与其抑制剂
    • 陷阱：提取 RNA 时，添加的是“RNA 酶抑制剂”，而非促进剂。目的是抑制 RNA 酶活性，而非直接去除 RNA 酶。写错功能正好相反。
  • 错答基因工程载体元件
    • 陷阱：将“缺少启动子”与“缺少起始密码子”混淆。启动子是DNA 上的序列，是 RNA 聚合酶结合位点；起始密码子（如 AUG）在 mRNA 上，是翻译起始的信号。基因不表达时，从 DNA 层面找原因应是缺少启动子（转录层面）。
    • 陷阱：只答出“目的基因无法复制”而未点出原因是缺少“复制原点”这一关键结构。
  • 逆转录概念理解片面
    • 陷阱：以为只有病毒有逆转录过程。在基因工程中，它是人为获取真核 cDNA（互补脱氧核糖核酸）的常规技术。回答原理时，不能遗漏“以 mRNA 为模板”这个前提。

代表题精讲

题目：（2017 新课标Ⅱ）结合几丁质酶基因工程，考查基因工程操作中 RNA 的提取与处理、通过逆转录获取目的基因和构建基因表达载体的原因。

思路： - 第（1）问，紧扣“提取RNA”和材料“嫩叶”与“老叶”的生理状态差异，以及“RNA酶抑制剂”对RNA的直接保护作用。 - 第（2）问，直接调用中心法则中“逆转录”过程的核心步骤来作答。 - 第（3）问，从目的基因 DNA 片段自身的缺陷出发，对比质粒作为运载体所具备的功能元件（复制、表达），反向推导出目的基因缺失的核心结构。

步骤： 1. 分析嫩叶 vs 老叶： - 嫩叶：细胞代谢旺盛，基因转录活跃，mRNA 含量高；细胞壁纤维化程度低，研磨时细胞更易破碎，RNA 溶出率高。因此常选用嫩叶。 2. 解释 RNA 酶抑制剂： - 细胞内外存在大量极稳定的 RNA 酶，极易导致提取出的 RNA 被迅速降解。添加 RNA 酶抑制剂能特异性地抑制 RNA 酶的活性，其目的就是防止 RNA 在提取纯化过程中被降解。 3. 阐述 cDNA 合成原理： - 原理是基于逆转录反应。具体是：在逆转录酶的催化下，以提取到的几丁质酶 mRNA 为模板，在三磷酸脱氧核苷酸（dNTP）为原料的条件下，严格按照碱基互补配对原则（A 与 T 配对，U 与 A 配对，G 与 C 配对），从 mRNA 逆向合成一条与其序列互补的 DNA 单链（互补脱氧核糖核酸，cDNA）。 4. 论证不可直接导入的原因： - 一个 DNA 片段要在受体细胞中稳定存在并表达，必须作为复制子或整合入基因组才能复制，且需启动子等启动转录。孤立的目的是基因片段： - 缺少 复制原点，在受体细胞有丝分裂时无法完成自主复制，会很快丢失。 - 缺少 启动子，受体细胞内的 RNA 聚合酶无法识别并结合到正确的位点上，因此转录过程无法起始，目的基因无法表达出相应的蛋白质。

点评/变式： - 本题代表了基因工程考查从“操作细节”到“原理分析”的递进模式。 - 第（1）问是典型的实验分析填空，核心是建立“材料特性—实验需求”的联系。变式可问“提取植物总蛋白为何不建议选用老叶”，答案思路类似：老叶蛋白质酶类复杂、次生代谢物多，易干扰提取。 - 第（3）问的“不可直接导入”变式较多，如直接问“基因表达载体的构建是基因工程的核心，原因是什么”，可迁移作答：使目的基因在受体细胞中稳定存在、表达和发挥作用，即载体提供了复制原点、启动子、标记基因等必需元件。
