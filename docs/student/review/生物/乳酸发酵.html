乳酸发酵

考点乳酸发酵权重6真题数1学科生物父主题生物技术与工程

考点定位

  • 父主题：生物技术与工程
  • 权重 weight：6
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择2
  • 难度分布：中1

知识精要

  • 无氧呼吸（乳酸发酵）概念：细胞在无氧条件下，通过酶的催化作用，将葡萄糖等有机物不彻底氧化分解，产生乳酸并释放少量能量的过程。
  • 场所：全过程在细胞质基质中进行。
  • 过程（两个阶段）：
  • 第一阶段（糖酵解）：$C_6H_{12}O_6$ 经酶催化分解为 2 分子丙酮酸（$CH_3COCOOH$），同时产生少量 [H]（NADH）并释放少量能量，生成少量 ATP。
  • 第二阶段：丙酮酸在特定酶的作用下，接受第一阶段产生的 [H] 被还原为乳酸（$C_3H_6O_3$），该阶段不产生 ATP。
  • 总反应式：$C_6H_{12}O_6 \xrightarrow{酶} 2C_3H_6O_3 + 少量能量$
  • 能量变化：1 mol 葡萄糖经乳酸发酵只释放 $196.65\ \text{kJ}$ 能量，其中 $61.08\ \text{kJ}$ 储存在 ATP 中（净生成 2 个 ATP），其余以热能形式散失。
  • 适用条件与实例：
  • 动物细胞：剧烈运动时肌细胞短暂缺氧。
  • 某些植物器官：马铃薯块茎、甜菜块根、玉米胚乳等。
  • 微生物：乳酸菌（制作酸奶、泡菜等）。
  • 与酒精发酵的区别：酒精发酵第二阶段丙酮酸先脱羧生成乙醛，再被还原为酒精和 $CO_2$；乳酸发酵无 $CO_2$ 生成，直接还原丙酮酸为乳酸。
  • 调控：氧气抑制无氧呼吸（巴斯德效应），氧气浓度升高会抑制乳酸积累。

解题方法与套路

  1. 先判断呼吸类型：根据题干给出的生物材料（如马铃薯块茎、动物细胞、乳酸菌）或产物（是否有 $CO_2$ 或酒精）确定是无氧呼吸中的乳酸发酵还是酒精发酵。
  2. 照准过程与场所：所有无氧呼吸的第一阶段均相同，都在细胞质基质中生成丙酮酸和少量 ATP；区别仅在于第二阶段不同。乳酸发酵的第二阶段是丙酮酸被 [H] 还原为乳酸，始终在细胞质基质中完成。
  3. 紧扣能量语句：无氧呼吸只在第一阶段释放能量、合成 ATP；第二阶段不产生 ATP。凡是说“丙酮酸生成过程不产能”“第二阶段产生 ATP”均错。
  4. 辨别产物表述：乳酸发酵的终产物是乳酸，无 $CO_2$ 和酒精；葡萄糖是反应物而非产物。选项中若将葡萄糖列为产物可直接排除。
  5. 分析环境因素影响：氧气浓度升高抑制无氧呼吸，减少乳酸（或酒精）积累，影响酸味/酒味产生。

高频易错

  • 误将葡萄糖当作产物：无氧呼吸的底物是葡萄糖，产物只有乳酸（或酒精+$CO_2$），不可能同时出现葡萄糖。
  • 认为丙酮酸生成阶段不放能：糖酵解（即第一阶段，产生丙酮酸）是放能过程，净生成 2 个 ATP。易错的说法如“产生丙酮酸的过程不能生成 ATP”。
  • 混淆发酵产物：把马铃薯块茎无氧呼吸产物错记为酒精+$CO_2$。记住常见特例：马铃薯块茎、甜菜块根、玉米胚乳和动物细胞一般为乳酸发酵。
  • 混淆场所：误以为乳酸发酵第二阶段在线粒体进行，实则全在细胞质基质中完成。
  • 对氧气影响的错误推断：以为提高氧气浓度能促进无氧呼吸，增加酸味。实际上氧气会抑制无氧呼吸相关酶活性，降低乳酸积累量。
  • 忽视“乳酸由丙酮酸转化”：无氧呼吸第二阶段丙酮酸在 NADH 供氢下直接还原为乳酸，不是乙酰 CoA 或乙醇的中间产物转变。

代表题精讲

2019-新课标Ⅱ-02

题目：马铃薯块茎储藏不当会出现酸味，与无氧呼吸有关。选出正确叙述。
思路：本题围绕马铃薯块茎的乳酸发酵过程，考查产物、中间转化及能量变化。需运用乳酸发酵的两阶段特征和氧气调控原理。
步骤：
- A 项说产物是乳酸和葡萄糖，葡萄糖为反应物，直接排除。
- B 项说乳酸由丙酮酸转化而来，这对应无氧呼吸第二阶段，正确。
- C 项称产生丙酮酸的过程不能生成 ATP，但糖酵解阶段确有 ATP 净生成，故错。
- D 项说升高氧气浓度增加酸味，氧气抑制无氧呼吸，会减少乳酸和酸味，错。
点评/变式：该题典型考查无氧呼吸基础知识，容易因记忆模糊而踩坑。变式可结合“马铃薯块茎无氧呼吸与酵母菌无氧呼吸的产物比较”“氧气浓度与呼吸熵（RQ）变化”等角度延伸，注意区分乳酸发酵第二阶段不产 ATP 也不产生气体，由此可判断密闭容器内气压和产物的变化。
