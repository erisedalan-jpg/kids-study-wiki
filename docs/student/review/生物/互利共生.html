互利共生

考点互利共生权重16真题数2学科生物父主题生物与环境

考点定位

  • 父主题：生物与环境
  • 权重 weight：16
  • 真题数：2；年份跨度：2009–2023
  • 出现题位：选择5 选择11
  • 难度分布：中2

知识精要

  • 互利共生：两种生物共同生活，双方相互依存，彼此有利。若分开，则双方或一方不能独立生存。
  • 核心特征：双方均获益，且常为专性依赖关系。
  • 典型实例：根瘤菌与豆科植物（根瘤菌固氮提供氮素；植物提供有机物和栖息场所）、蚂蚁与蚜虫（蚂蚁取食蜜露并保护蚜虫）。
  • 种间关系快速辨析：
  • 互利共生：双方有利，互不可缺。常见组合：固氮微生物+植物、真菌+藻类（地衣）、蚂蚁+蚜虫。
  • 竞争：争夺相同资源（食物、空间、光等），结果常表现为相互抑制或一方淘汰另一方。典型指标：一种增加则另一种减少。
  • 捕食：一种生物以另一种为食，被捕食者数量常随捕食者变动呈现周期变化。
  • 寄生：一方获利，另一方受害。寄生物常生活在宿主体内或体表，摄取宿主营养。

解题方法与套路

  1. 定义锚定法：遇到种间关系判断题，首先复述四种关系的定义，将选项行为与定义逐一比对。尤其关注“双方是否均有利且相互依存”——这是互利共生区别于寄生、捕食的核心。
  2. 资源维度分析法：涉及“同环境取食”时，必须判断二者利用的资源是否完全相同。例如，食叶与采蜜虽同期同植物，但食性生态位分化，不构成竞争。只有当生存资源（空间、食物种类等）高度重叠时，才判定为竞争。
  3. 数量动态反推法：对于实验或描述中出现的数量变化，若“一种数量增加直接导致另一种减少”，是竞争或捕食的强信号；若“同增同减”或“一荣俱荣”，则极大可能是互利共生。
  4. 实验变量拆解法：面对探究“根瘤菌固氮能力”等互利共生关系的研究型试题，需快速识别自变量（如是否接种根瘤菌、根瘤菌类型）、因变量（植物含氮量/干重）与无关变量（光照、温度等），按对照原则和单因子变量原则设计实验或分析结果。

高频易错

  • 共同出现≠竞争关系：易将“在同一植株上觅食”直接等同于竞争，忽略食性分化（叶片 vs. 花蜜）或生态位不同。只要不争夺同种核心资源，即不构成竞争。
  • 互利共生与片利共生的混淆：互利共生是双方严格获利；若一方获利而另一方无害无利，为偏利共生，高考常混入干扰项，务必紧扣“双方均获利”。
  • 体表/体内寄生与共生的边界模糊：关键看宿主是否受害。噬菌体利用细菌氨基酸为原料并增殖，导致细菌裂解死亡，是典型的寄生，而非共生。
  • 忽略数量变化的解读：看到“两种绿藻，一种增加则另一种减少”误判为捕食。捕食通常有滞后性数量波动，而竞争常表现为资源直接排斥导致的即时性消长。

代表题精讲

题目1：2009-全国Ⅱ-05

题目：以选择题形式判断种间竞争实例。选项涉及蚂蚁与蚜虫、菜粉蝶幼虫与蜜蜂、细菌与噬菌体、两种绿藻的混养现象。 思路：根据竞争定义“争夺共同资源，相互抑制”，逐项核对。 步骤： - A项：蚂蚁取食蚜虫蜜露并保护蚜虫，双方获利，为互利共生，排除。 - B项：菜粉蝶幼虫食叶，蜜蜂采蜜，资源无竞争，排除。 - C项：噬菌体寄生于细菌，利用其养料，宿主受害，为寄生，排除。 - D项：两种绿藻同处培养瓶，争夺光、无机盐等资源，且一种数量上升伴随另一种下降，直接体现竞争抑制，正确。 点评/变式：该题集中考查了种间关系辨析的核心陷阱。尤其注意B项的双重干扰：一是利用同株植物，二是昆虫间易被泛化联想。变式考法：给出“培养瓶中A增加B减少”数据，询问背后机理是资源耗竭抑制（竞争）还是直接取食（捕食），可从是否直接接触或种群变动同步性判断。

题目2：2023-新课标-11

题目：探究野生草本豆科植物根瘤菌固氮能力的实验分析。涉及从盐碱地分离根瘤菌、通过组培获得无其他菌源的试管苗，并检验其根瘤固氮活性。 思路：聚焦“探究固氮能力”的实验目的，构建“有无根瘤菌”的对照逻辑，严格控制无关变量（如原有氮源）。 步骤： 1. 明确变量与对照组：自变量为是否接种目标根瘤菌，因变量为植物体含氮量（或生长状况、含氮有机物积累量）。对照组应接种等量无菌水或灭活根瘤菌液。 2. 控制无关变量：选用组培苗可避免种子或土壤自带其他固氮菌的干扰；培养液中需配比为无氮培养基，以强迫植物完全依赖根瘤菌固氮来获取氮源，固氮能力差异才能显现。 3. 结果与结论：培养后，若接种组植物含氮量、植株干重显著高于不接种组，则证明该菌具有固氮能力。 点评/变式：此题以实验设计为壳，内核仍为互利共生。核心考点是固氮作用为植物提供可利用氮素，此乃互利的物质基础。变式可将其迁移至内生真菌提高抗逆性、菌根真菌促进磷吸收等共生模型，解题逻辑完全一致：寄主获益指标（如特定矿质元素含量、抗逆酶活性）+ 适当的无/缺条件培养 → 验证共生功能。
