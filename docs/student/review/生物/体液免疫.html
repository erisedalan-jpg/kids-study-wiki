体液免疫

知识精要

体液免疫是特异性免疫的重要组成部分，主要针对细胞外病原体（如病毒、细菌）及其毒素。

  • 核心过程

    1. 抗原呈递：病原体被抗原呈递细胞（如树突状细胞、巨噬细胞、B细胞）摄取、处理，并将抗原肽呈递在细胞表面。
    2. 辅助性T细胞活化：抗原呈递细胞将抗原信息传递给辅助性T细胞，使其活化。
    3. B细胞活化（双信号模型）
      • 第一信号：病原体直接与B细胞表面的特异性受体结合。
      • 第二信号：活化的辅助性T细胞表面的特定分子发生变化，与B细胞结合。
      • 在以上两个信号的共同作用下，B细胞开始分裂、分化。
    4. 增殖与分化
      • 活化的辅助性T细胞分泌细胞因子（如淋巴因子），促进B细胞的增殖和分化。
      • B细胞大部分分化为浆细胞，产生并分泌特异性抗体。抗体与病原体结合，形成沉淀或细胞集团，最终被吞噬细胞吞噬消化。
      • 小部分分化为记忆B细胞，在二次免疫中快速响应，引发更强烈的免疫反应。

  • 关键细胞的功能定位

    • 抗原呈递细胞：巨噬细胞（参与非特异性和特异性免疫）、树突状细胞、B细胞（属于淋巴细胞，同样能呈递抗原）。
    • 辅助性T细胞：体液免疫的中心调节细胞，既能通过表面分子接触激活B细胞，又能分泌细胞因子促进其增殖分化。它同时是联系体液免疫与细胞免疫的枢纽。
    • 浆细胞：唯一能产生抗体的细胞，不具识别抗原能力。
    • 细胞毒性T细胞：在细胞免疫中，识别并与被病原体入侵的靶细胞密切接触，使其裂解死亡。不直接清除游离的病毒，不分泌抗体。

  • 免疫类型辨析

    • 非特异性免疫：生来就有，不针对特定病原体，作用范围广，无记忆性（如吞噬细胞的吞噬作用）。是第一道和第二道防线。
    • 特异性免疫：出生后形成，针对特定病原体，具有专一性和记忆性。分为体液免疫和细胞免疫。
    • 两者关系：非特异性免疫是特异性免疫的基础。

解题方法与套路

  1. 细胞功能分类法 遇到免疫过程示意图，首先对图中细胞进行“身份判定”与“功能归类”：

    • 摄取/呈递抗原类：包括巨噬细胞、树突状细胞、B细胞。判断标准是能否“加工处理”并向辅助性T细胞呈递。
    • 调节/辅助类：辅助性T细胞。判断标准是它能同时接触呈递细胞与B细胞，并常伴有分泌物（细胞因子）。
    • 执行/效应类：浆细胞（产生抗体）、细胞毒性T细胞（攻击靶细胞）。牢记浆细胞不识别抗原，细胞毒性T细胞不分泌抗体。

  2. 免疫类型辨析法 对于判断“属于何种免疫”或“是否正确”的题，使用排除法与核心概念法：

    • 提及“抗体”、“浆细胞”、“B细胞增殖分化” → 核心是体液免疫。
    • 提及“靶细胞裂解”、“细胞毒性T细胞活化” → 核心是细胞免疫。
    • 提及“吞噬细胞吞噬”、“不针对特定病原体”、“先天具有” → 核心是非特异性免疫。
    • 关键联系点：病毒、胞内寄生菌等病原体，既引发体液免疫，也引发细胞免疫。辅助性T细胞是两个过程的共同参与者。

  3. 过程顺序排错法 对于判断免疫过程叙述的题，严格按照 “识别 → 呈递 → 活化 → 增殖分化 → 效应” 的顺序进行逻辑校验。通常，辅助性T细胞的活化是后续B细胞和细胞毒性T细胞激活的中心环节，排序题常在此处设置干扰项。

高频易错

  • 错误地将B细胞排除在抗原呈递细胞之外。B细胞属于淋巴细胞，但它也能摄取加工并呈递抗原。
  • 混淆辅助性T细胞的作用范围。误认为它只参与体液免疫。实际上，它通过分泌细胞因子等方式同时参与体液免疫和细胞免疫。
  • 混淆效应细胞的功能。
    • 错误：“浆细胞直接清除病毒”。正解：浆细胞分泌的抗体与病毒结合形成沉淀，再由吞噬细胞吞噬清除，抗体本身不直接杀死病原体。
    • 错误：“细胞毒性T细胞分泌抗体”。正解：分泌抗体的是浆细胞。
    • 错误：“细胞毒性T细胞直接清除内环境中的病毒”。正解：它裂解的是被病毒感染的靶细胞。
  • 忽视免疫调节的机制。在抗原被清除后，免疫反应会通过负反馈调节减弱，以维持内环境稳态。认为免疫细胞活化后功能会一直持续下去是错误的。
  • 混淆淋巴因子的来源与名称演变。旧教材中的“淋巴因子”在新教材中常称为“细胞因子”，由辅助性T细胞等多种细胞分泌，能促进B细胞和细胞毒性T细胞的增殖分化。

代表题精讲

代表题一：2024-辽宁-17

  • 题目：通过肝巨噬细胞活化示意图，分析病毒入侵肝脏后各免疫细胞（1~4）及物质Y的功能与相互关系，选择正确选项。
  • 思路：本题属于流程图辨析题。核心是根据箭头和细胞形态判定细胞身份，再逐项验证其功能表述。
  • 步骤
    1. 身份判定：据图，细胞1能呈递抗原，应为抗原呈递细胞。细胞2接受呈递后，既能活化细胞4（B细胞），又能活化细胞1，并能分泌物质Y，这是辅助性T细胞的典型特征。细胞4接受信号后分化为细胞3，细胞3分泌物质Y（抗体），所以细胞4是B细胞，细胞3是浆细胞，物质Y是抗体。
    2. 选项分析
      • A项：肝巨噬细胞（属于图中细胞1的一种）能无差别吞噬，属于非特异性免疫；又能处理和呈递抗原，参与特异性免疫。正确。
      • B项：细胞2（辅助性T细胞）分泌的细胞因子可以促进细胞4（B细胞）的活化；同时，它对细胞1（肝巨噬细胞等抗原呈递细胞）存在正反馈调节，也能促进其活化。正确。
      • C项：细胞3（浆细胞）分泌的物质Y是抗体。抗体不能直接清除病毒，而是与其结合。细胞4（B细胞）分化为浆细胞和记忆细胞，不能直接清除病毒。错误。
      • D项：病毒被清除后，抗原刺激消失，免疫系统会通过调节机制使活化的细胞4（活化的B细胞）等免疫细胞功能受到抑制，以维持稳态。正确。
  • 点评/变式：本类图表题的关键是准确定位“辅助性T细胞”，它是连接非特异免疫、体液免疫和细胞免疫的核心枢纽。变式考查常将体液免疫与细胞免疫过程混合在同一图中，务必厘清B细胞（体液）和细胞毒性T细胞（细胞）的活化路径。

代表题二：2023-新课标-03

  • 题目：以组合选择题形式，判断关于免疫细胞、免疫过程（体液/细胞）的5条叙述是否正确。
  • 思路：精准辨析核心概念，使用排除法。
  • 步骤
    1. 逐条验证
      • ① 免疫细胞通过表面受体识别病原体表面特定蛋白，这是免疫反应启动的基础。→ 正确。
      • ② 树突状细胞和B细胞都属于抗原呈递细胞，B细胞是淋巴细胞的一种。→ “淋巴细胞不能呈递抗原” 错误，排除A、C。
      • ③ 辅助性T细胞在体液免疫（激活B细胞）和细胞免疫（激活细胞毒性T细胞）中均发挥关键作用。→ “不参与细胞免疫” 错误，排除D。
      • ④ B细胞和T细胞在初次免疫中均可形成对应的记忆细胞，用于二次免疫应答。→ 正确。
      • ⑤ 致病细菌感染人体，其表面抗原可引起体液免疫；若其侵入宿主细胞成为胞内寄生菌，则会引起细胞免疫。→ 正确。
    2. 得出组合：因此，正确的叙述是①④⑤。答案选B。
  • 点评/变式：此类题目直接考查对核心概念的记忆与辨析。最常混淆的点是“B细胞是否是淋巴细胞/能否呈递抗原”以及“辅助性T细胞的作用范围”。复习时必须建立清晰的细胞分类树状图。
