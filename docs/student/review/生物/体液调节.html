知识精要

体液调节的核心是化学物质（主要是激素）通过体液运输作用于靶细胞，从而调节生命活动。本专题聚焦脊椎动物（尤其是人体）的激素调节及其与神经调节的协同。

1. 激素的本质与作用特点 - 本质多样性：甲状腺激素是氨基酸衍生物，胰岛素、胰高血糖素是蛋白质，性激素与醛固酮是固醇类（脂质）。 - 作用机制：激素作为信息分子，与靶细胞特异性受体结合，调节细胞代谢，作用后即被灭活。 - 运输途径：通过体液（主要是血液）运输，作用于全身，但仅对具有特定受体的靶细胞、靶器官起效。注意：激素不能通过神经纤维运输。 - 微量高效：血液中浓度极低，但生理效应显著。

2. 下丘脑-垂体-靶腺轴与分级调节 - 分级调节：下丘脑分泌促激素释放激素，促进垂体分泌相应促激素，再促进靶腺分泌激素。这是维持激素水平稳态的核心调控轴。 - 反馈调节：靶腺激素浓度升高时，会抑制下丘脑和垂体的分泌活动，使激素浓度回落，维持稳态。 - 实例：甲状腺激素调节、性激素调节。与外源注射实验结合考查：注射外源甲状腺激素，通过负反馈抑制自身促甲状腺激素分泌，导致自身甲状腺激素合成量 减少；而注射促甲状腺激素，则会直接促进自身甲状腺激素合成量 增多。

3. 神经调节与体液调节的关联 - 关系：二者紧密联系，多数内分泌腺受中枢神经系统控制。例如，交感神经兴奋可促使肾上腺髓质分泌肾上腺素。 - 区别： - 神经调节：作用途径为反射弧，反应迅速、准确、短暂。 - 体液调节：作用途径为体液运输，反应较缓慢、作用范围广泛、时间持久。 - 实例：呼吸运动的调节是神经和体液共同调节的典例。中枢和外周化学感受器可感受 $CO_2$ 浓度变化，通过神经调节呼吸肌；同时大脑皮层可对呼吸进行随意控制。

4. 内环境稳态中的其他重要激素 - 胰高血糖素：由胰岛A细胞分泌，主要作用是促进肝糖原分解为葡萄糖、促进非糖物质（如脂肪、氨基酸）转化为糖，从而升高血糖。 - 抗利尿激素（ADH）：由下丘脑合成、垂体释放，作用于肾小管和集合管，促进其对水分的重吸收，降低细胞外液渗透压。 - 醛固酮：由肾上腺皮质分泌，主要功能是促进肾小管和集合管对 $Na^+$ 的重吸收，同时促进 $K^+$ 的分泌，对维持血钠和血钾含量的平衡至关重要。

解题方法与套路

  1. 精准锁定关键词，区分调节类型：
  2. 见到“传入/传出神经”“神经中枢”“反射弧” 即判定为神经调节路径。

  3. 见到“某激素”“某化学物质”“经血液运输”“化学感受器” 即判定为体液调节路径。若两者均出现，则为神经-体液调节。

  4. 活用“下丘脑-垂体-靶腺”轴分析结果：

  5. 分级放大：凡是问“注射促某激素”导致的结果，激素合成量必 增加。

  6. 负反馈抑制：凡是问“注射外源某激素”对自身内分泌腺的影响，激素合成量必 减少。（原理：外源激素浓度升高的信号，会引发负反馈抑制下丘脑和垂体的促激素分泌，最终导致自身合成不足）。这是解答实验分析题的万能钥匙。

  7. 激素作用题的“功能模板”：

  8. 升血糖类：回答模板 = “促进…分解” + “促进…转化” 。胰高血糖素和肾上腺素均适用。
  9. 恒渗压类：$ADH$ 作用 = “促进肾小管、集合管对水的重吸收”。醛固酮作用 = “促进肾小管、集合管对 $Na^+$ 的重吸收”。

  10. 酸碱/呼吸调节：$CO_2$ 或 $H^+$ 浓度变化作用路径 = “刺激（化学）感受器” → “兴奋传至呼吸中枢” → “调节呼吸运动（加快/减慢）”。

  11. 实验设计与曲线分析：

  12. 切断/损毁实验：若切断某神经后，生理反应消失或减弱，则结论为：“该生理反应依赖于该神经传导的传入/传出功能或某感受器的作用”。例如，切断外周化学感受器传入神经后，动物对 $CO_2$ 刺激的通气反应显著削弱，则说明外周化学感受器在感受 $CO_2$ 刺激、促进呼吸运动中起关键作用。
  13. 测试-训练-再测试实验：对比前测与后测的成绩，可分析学习能力；对比两组差异，可分析能力缺陷。结果表述需从“初始能力”和“学习能力”两个角度展开。

高频易错

  1. 激素运输途径混淆：激素通过体液（主要是血液）运输至全身，绝非通过神经纤维。一旦看到选项中“激素通过神经纤维运输”，可直接判错。
  2. 反射弧完整性与中枢控制：膝跳反射的神经中枢在脊髓，即便大脑皮层受损，只要反射弧的其余部分完整，反射仍能发生，但不能被意识控制。
  3. 分级调节中“倒因为果”：外源注射甲状腺激素导致自身甲状腺激素合成减少，正确原因是通过负反馈抑制了促激素分泌，而不是“外源激素抑制了甲状腺的功能”。
  4. 下丘脑的“双重身份”：下丘脑既属于神经系统（中枢），又是内分泌器官。其分泌的抗利尿激素（ADH）和释放到血液中的催产素是由垂体后叶释放的，而非直接由下丘脑进入血液；其分泌的促激素释放激素等经门脉系统运至垂体前叶。
  5. 实验结论表述片面：如针对呼吸调节实验，在分析结论时，仅得出“中枢化学感受器是感受 $CO_2$ 的唯一途径”是错误的。因切断外周传入神经后，通气仍可随 $CO_2$ 增加，单纯根据曲线差异应严谨得出“外周化学感受器和中枢化学感受器共同参与了 $CO_2$ 引起的呼吸调节”或“外周化学感受器在此调节中起重要作用”。
  6. 规范术语书写：“靶器官”不能写成“把器官”，“醛固酮”不能写成“醛固同”，“协同/拮抗”作用对象需明确，胰高血糖素和胰岛素作用是拮抗而非协同。

代表题精讲

1. 2023-新课标-08

  • 题目：运动稳态综合题，涉及自主神经、 $CO_2$ 调节、胰高血糖素、抗利尿激素和醛固酮。
  • 思路：本题是体液调节核心概念的集合。解题关键在于准确记忆各激素的核心功能，并识别生理条件变化（运动、失水）所激发的激素响应。
  • 步骤：
  • 运动时心跳加快，是不受意识支配的内脏活动，由交感神经兴奋主导。
  • 剧烈运动产生大量 $CO_2$ ，这是一个体液调节触发神经调节的经典模型。 $CO_2$ 作为体液因子，作用于呼吸中枢，进而使呼吸运动加快。
  • 胰高血糖素升高血糖的作用，套用模板：“促进肝糖原分解为葡萄糖，促进非糖物质转化为葡萄糖”。（注意：书中强调是肝糖原，肌糖原不能直接分解为葡萄糖）。
  • 细胞外液渗透压升高，刺激下丘脑渗透压感受器，垂体后叶释放抗利尿激素，作用靶点为肾小管和集合管。
  • 醛固酮在血钠降低时分泌增加，核心功能是“促进肾小管和集合管对 $Na^+$ 的重吸收”，以维持血钠平衡。
  • 点评/变式：本题考察的是“刺激-腺体-激素-效应”的直线型逻辑。失分点往往在于书写不规范或混淆醛固酮与抗利尿激素的作用。变式可考：大量出汗后补充淡盐水比纯水更有利于维持内环境稳态的原因——既补充了水，又防止了血钠降低。

2. 2022-全国乙-08

  • 题目：甲状腺激素调节的实验分析，涉及放射性追踪与外源注射对合成量的影响。
  • 思路：本题关键在于运用“下丘脑-垂体-甲状腺”轴的反馈调节原理。实验一考查激素合成的原料；实验二考查分级调节与负反馈抑制导致的不同结果。
  • 步骤：
  • 实验一：家兔甲状腺中检测到放射性碘，因为甲状腺细胞能选择性地吸收碘，将其作为原料合成甲状腺激素。
  • 实验二分析：设丙组注射促甲状腺激素、乙组注射甲状腺激素、甲组注入生理盐水作空白对照。
  • 丙组 vs 甲组：促甲状腺激素能促进甲状腺的活动，所以丙组甲状腺激素合成量大于甲组。
  • 乙组 vs 丙组：乙组注射的外源甲状腺激素，通过负反馈抑制了下丘脑和垂体，导致内源性促甲状腺激素分泌减少，自身甲状腺激素合成量也随之减少。因此，乙组和丙组的自身甲状腺激素合成量肯定不相同，原因是二者调节机制完全不同，前者被抑制，后者被促进。
  • 点评/变式：本题核心陷阱在于“合成量”指的是内源合成量。若题目换为“血液中甲状腺激素总含量”，则乙组（外源+内源）未必低于丙组，需具体分析。务必看清设问对象。

3. 2024-辽宁-23（节选）

  • 题目：听歌跟唱与唱歌时的生命活动调节。
  • 思路：这是一道典型的神经-体液调节综合题，融合了反射类型判断、分级调节、恒压调节实验分析及对比性学习能力测验。
  • 步骤：
  • 听歌跟唱分析：声波刺激感受器产生兴奋（是电信号/神经冲动，不是“反射”）。该过程经过中枢分析，由传出神经支配效应器，由于需要对歌词、旋律进行分析，是后天学习的，应判断为条件反射。
  • 呼吸调节分析：有意识地控制呼吸，起作用的最高级中枢是大脑皮层，这体现了高级中枢对低级中枢的控制。分析 $CO_2$ 反应实验图，切断外周传入神经后，通气量仍随 $CO_2$ 升高而增多（体现中枢化学感受器作用），但反应幅度显著降低。结论应为“$CO_2$ 对肺通气量的调节作用，一部分是通过刺激外周化学感受器实现的”或“中枢和外周化学感受器共同参与了该调节，且外周起重要作用”。
  • 失歌症分析：观察图2的柱状图。与正常组相比，失歌症组“前测和后测的音乐感知准确率均更低”（感知能力缺陷）；“后测较前测的准确率提升幅度更小”（学习能力缺陷）。仅分析失歌症组自身数据，其“后测比前测准确率高，且有显著性差异”，说明“训练能提升失歌症者（一定程度）的音乐感知准确率”。
  • 点评/变式：该题核心素养是读图和实验对照。在描述实验结论时，必须有严谨的统计学思维（“显著提高/降低”），避免“略有差异”等主观描述。变式可考查不同感官的感知训练效果。
