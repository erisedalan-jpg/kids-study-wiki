光反应

考点光反应权重11真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：11
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：选择3
  • 难度分布：易1

知识精要

  • 光反应场所：叶绿体的类囊体薄膜。
  • 物质与能量变化： $$2\text{H}_2\text{O} \xrightarrow[\text{色素}]{\text{光能}} 4\text{H}^+ + \text{O}_2 + 4e^-$$ $$\text{ADP} + \text{Pi} + \text{能量} \xrightarrow[\text{}]{\text{酶}} \text{ATP}$$ $$\text{NADP}^+ + 2e^- + \text{H}^+ \xrightarrow[\text{}]{\text{酶}} \text{NADPH}$$ 核心产物是ATP和NADPH（二者合称同化力），它们将用于暗反应（碳反应）中C3的还原。
  • 光合色素的核心地位：光合色素（叶绿素a、叶绿素b、类胡萝卜素）是光反应的物质基础，负责吸收、传递和转化光能。
  • 关键联系：
  • Mg 是构成叶绿素分子的必需矿质元素。
  • 光反应的强度直接决定暗反应的强度。光反应停止（如无光或色素受损），会因ATP和NADPH断供，随即导致暗反应停止。

解题方法与套路

此类“条件变化引起光合作用强度变化”类型题，按以下步骤“顺藤摸瓜”：

  1. 锁定初始靶点：识别题干条件变化的直接作用对象。本题中“缺镁”的直接对象是“叶绿素”。
  2. 追踪第一步结果：判断该直接对象变化引起的第一次反应变化。缺镁→叶绿素合成受阻→吸收、转化光能能力下降→光反应强度必然降低（排除A、C）。
  3. 按因果关系向下推演：判断第一步结果引发的中长期效应。光反应产物（ATP、NADPH）产量降低，导致暗反应C3还原阶段原料不足→暗反应强度随之降低。
  4. 识别直接与间接效应：牢记暗反应不仅需要CO2，还严重依赖于光反应提供动力和还原剂。光反应受损，“暗反应强度不变”的情况（D选项）在生物学上违背制约逻辑。

高频易错

  • 误以为暗反应可独立维持：部分同学认为只要维持CO2供应，暗反应强度就不变。失分点在于忘记暗反应极度依赖光反应提供的ATP和[H]（NADPH）。光反应一旦减弱，同化力供应不足是其直接且唯一的结果。
  • 分不清“直接条件”与“间接条件”：镁是叶绿素的组分，缺镁直接影响的是光相关的色素，而非直接作用于暗反应酶系。错选C（光反应强度不变）是默认了“光”不变光反应就不变，忽略了色素这个吸光载体的核心作用。
  • 主观割裂两个阶段：把光反应和暗反应当成两个完全独立的生理过程。实际上二者在物质和能量上严格耦联。光反应受损必然拖垮暗反应，反之，暗反应受阻（如CO2断供）也会通过产物积累抑制光反应。

代表题精讲

题目：番茄幼苗在缺镁培养液中培养后，叶片光合作用强度下降的直接原因判断（选择题）。

思路：拆解题干关键词“缺镁”，定位到叶绿素。缺镁导致叶绿素不足，直接影响光反应中的光能吸收与转化。根据光反应与暗反应的耦联关系，推演暗反应相应变化。

步骤： 1. 知识调用：镁是叶绿素分子的核心元素。缺镁植物叶绿素合成受阻，在外部光照不变的情况下，光系统对光能的捕获效率大跌。 2. 逻辑推导： - 第一步：光能吸收减少 $\rightarrow$ 光反应强度降低（确认A错，D后半句错）。 - 第二步：光反应产物ATP和NADPH生成量减少 $\rightarrow$ 暗反应中C3还原缺乏物质和能量 $\rightarrow$ 暗反应强度随之降低（确认C错，A前半句错）。 3. 结论判定：光反应强度与暗反应强度均降低，正确答案为B。

点评/变式： - 本题陷阱：极易被“光照未变”迷惑，忽略了色素这一光能获取器的核心作用。 - 易错变式：若干旱引起气孔关闭，则直接受限的是暗反应（CO2不足）。此时长期处理下，因暗反应消耗ATP/NADPH减少，会造成二者积累，进而反馈抑制光反应，导致光反应强度也跟着下降。注意区分初始原因和继发反馈。
