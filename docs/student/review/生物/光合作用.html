知识精要

  1. 光合作用总反应式： $$ \text{CO}_2 + \text{H}_2\text{O} \xrightarrow[\text{叶绿体}]{\text{光能}} (\text{CH}_2\text{O}) + \text{O}_2 $$
  2. 光反应与暗反应（碳反应）的比较：
项目 光反应 暗反应（碳反应）
场所 叶绿体类囊体薄膜 叶绿体基质
条件 光、色素、酶 多种酶、[H]（NADPH）、ATP
物质变化 ①水的光解：$2\text{H}_2\text{O} \xrightarrow{\text{光}} 4\text{H}^+ + 4e^- + \text{O}_2$
②ATP的合成：$\text{ADP} + \text{Pi} \xrightarrow{\text{酶}} \text{ATP}$
③NADPH的合成： $\text{NADP}^+ + \text{H}^+ + 2e^- \xrightarrow{\text{酶}} \text{NADPH}$		 ①$\text{CO}_2$的固定：$\text{C5} + \text{CO}_2 \xrightarrow{\text{酶}} 2\text{C3}$
②C3的还原：$2\text{C3} \xrightarrow[\text{酶}]{\text{ATP, [H]}} 2(\text{CH}_2\text{O}) + \text{C5}$
能量变化 光能 → ATP和NADPH中的活跃化学能 ATP和NADPH中的活跃化学能 → 有机物中稳定的化学能
关键产物 $\text{O}_2$, $\text{ATP}$, $\text{NADPH}$（[H]） $(\text{CH}_2\text{O})$, $\text{ADP}$, $\text{Pi}$, $\text{NADP}^+$
  1. 光呼吸：在光下，$\text{C5}$与$\text{O}_2$结合生成$\text{C2}$，随后在叶绿体、过氧化物酶体、线粒体中完成，消耗$\text{ATP}$和$\text{NADPH}$，释放已固定的$\text{CO}_2$的过程。在$\text{CO}_2/\text{O}_2$比值低时发生，是光合作用效率的重要限制因素。
  2. 净光合速率与总光合速率：
    • 总（真正）光合速率 = 净光合速率 + 呼吸速率。
    • 净光合速率的表观指标：$\text{CO}_2$吸收量、$\text{O}_2$释放量、有机物积累量。
  3. 干旱植物特殊$\text{CO}_2$固定方式（如景天科植物CAM途径）：晚上气孔开放，吸收$\text{CO}_2$并以苹果酸形式储存于液泡；白天气孔关闭，苹果酸脱羧释放$\text{CO}_2$进入卡尔文循环，以减少蒸腾作用失水。

解题方法与套路

  1. 过程流程图解法：遇到复杂生理过程（如光呼吸、光合-呼吸耦合），立刻在草稿纸上画出关键物质（$\text{C5}$, $\text{C3}$, $\text{C2}$, 葡萄糖）和场所（叶绿体、线粒体）的流程图，标注条件和能量变化，使直观化。
  2. 净/总光合速率曲线“三点分析法”：
    • 零点（与x轴交点）：光合速率 = 呼吸速率。
    • 负值区：光合速率 < 呼吸速率。
    • 正值及饱和区：光合速率 > 呼吸速率，分析限制因素时看曲线趋势，水平段限制因素为横坐标以外的因子（如光强、$\text{CO}_2$浓度），上升段限制因素为横坐标因子。
  3. 密闭容器气体变化“供-需”模型：分析容器内$\text{CO}_2$或$\text{O}_2$变化，紧扣“光合作用消耗/产生”与“呼吸作用产生/消耗”的差值。当$\text{CO}_2$浓度稳定时，光合速率 = 呼吸速率。
  4. 实验设计题“三要素”法：
    • 自变量：精准描述处理方式（如干旱 vs 正常）。
    • 因变量：明确检测指标（如液泡pH）。
    • 控制变量：强调“生长状态相同”“随机均分”“相同且适宜”等，确保对照。
  5. 细胞器功能定位法：分析某过程发生的场所时，采用排除定位。上清液能将葡萄糖彻底分解，说明同时含细胞质基质（糖酵解场所）和线粒体（有氧呼吸后两个阶段场所）。

高频易错

  • 混淆“光反应”与“有氧呼吸”阶段：光反应产生ATP和NADPH，场所是类囊体薄膜；有氧呼吸三个阶段都能产生ATP，前两个阶段产生NADH。
  • 误判限制因素：曲线水平阶段，限制因素不是横坐标变量；多条曲线在高$\text{CO}_2$浓度下合并，说明此时$\text{CO}_2$不再是限制因素，光强是主要限制因素。
  • 漏答ATP产生场所：有光照时，叶肉细胞产生ATP的场所应考虑：细胞质基质、线粒体、叶绿体类囊体薄膜。
  • 气孔开闭原因与结果混淆：干旱地区植物气孔白天关闭，主要目的是减少蒸腾作用失水，而非防止呼吸作用消耗。
  • “乳酸分解供能”谬误：人体剧烈运动产生的乳酸，须经血液运输到肝脏转化为葡萄糖或丙酮酸再氧化分解供能，乳酸本身不能直接分解供能。
  • 对离体细胞器的功能判断绝对化：叶绿体双层膜破裂，只要类囊体膜结构完整，加光照和适宜条件，仍可进行光反应释放$\text{O}_2$。

代表题精讲

2024-辽宁-21

  • 题目：围绕光呼吸过程图（叶绿体与线粒体），考查过程名称、场所、$\text{CO}_2$来源，并结合转基因植株的净光合速率柱状图，分析差异原因及产量优势。
  • 思路： （1）根据图1物质转化，反应①为$\text{C5} + \text{CO}_2 \rightarrow \text{C3}$，即$\text{CO}_2$的固定。 （2）以葡萄糖为底物的有氧呼吸，葡萄糖在第一阶段细胞质基质中分解产生NADH，丙酮酸进入线粒体基质彻底分解产生大量NADH。注意区分与光合作用NADPH的场所。 （3）植物光合作用碳来源有三：外界环境、呼吸作用释放、光呼吸释放。分析净光合速率图时，7—10时，光照增强，WT净光合速率可能因光呼吸强而受限，而转基因株系因导入改变光呼吸的基因，光呼吸被抑制或改变，使得净光合速率升高。 （4）株系1在相同条件下，单位叶面积有机物积累（净光合速率）最多，故产量可能更具优势。
  • 步骤：
    1. （1） 由反应物$\text{CO}_2$和$\text{C5}$，生成物$\text{C3}$，直接判为“$\text{CO}_2$的固定”。
    2. （2） 回忆有氧呼吸全过程，排出“细胞质基质”和“线粒体基质”。
    3. （3） $\text{CO}_2$来源除题干暗示的“外界环境”外，由图1可知光呼吸释放$\text{CO}_2$，由呼吸作用定义知细胞呼吸释放$\text{CO}_2$。差异原因为“转基因株系1和2可能因光呼吸被抑制，在7-10时光照增强时，减少了有机物消耗，净光合速率较WT更高”。
    4. （4） 结合图2、图3，株系1在两个测定时段净光合速率均最高，由此得出判断依据。
  • 点评/变式：本题将光呼吸与转基因育种结合，对获取信息能力要求高。常见变式：给出$\text{CO}_2$补偿点、饱和点数据表，分析不同植物光合特性；或结合$^{14}\text{C}$同位素示踪，追踪光合产物路径。

2022-全国乙-02

  • 题目：某正常生长植物于适宜且恒定的密闭容器中，容器内$\text{CO}_2$初期降低，之后保持相对稳定。分析原因。
  • 思路：运用密闭容器气体变化模型。初期植株正常，光合作用吸收$\text{CO}_2$量大于呼吸作用释放$\text{CO}_2$量，导致容器内$\text{CO}_2$总量下降。随着$\text{CO}_2$浓度下降，光合速率会受限制而降低，呼吸速率相对稳定。待两者速率相等时，容器内$\text{CO}_2$浓度达到动态平衡，不再改变。
  • 步骤：
    1. 审题： 条件为“生长正常”“适宜且恒定温光”“密闭”，观测对象是“容器内$\text{CO}_2$”。
    2. 建模： 容器$\text{CO}_2$浓度净变化= 光合消耗 - 呼吸释放。
    3. 分析： 初期浓度下降→净变化为负→光合消耗 > 呼吸释放，即光合速率 > 呼吸速率。后期浓度稳定→净变化为零→光合消耗 = 呼吸释放，即光合速率 = 呼吸速率。
    4. 判断： 直接匹配D选项描述。
  • 点评/变式：本题是最经典的“密闭小室”问题变式。常设陷阱是将“$\text{CO}_2$浓度稳定”曲解为“光合速率达到顶峰（饱和）”。速率饱和由外部因子决定，而密闭容器中速率稳定是内外供需达平衡，并非光合酶被$\text{CO}_2$饱和。

2023-新课标-02

  • 题目：判断一组农业生产措施与原理匹配的正确性，涉及低温储存、春化、风干、光周期、合理密植、间作。
  • 思路：逐一用植物生理学原理辨析。春化（②）是低温诱导成花，光周期（④）是光暗时长影响开花，二者均与开花有关。风干（③）降低种子自由水含量，减弱呼吸消耗；合理密植（⑤）则是通过优化光照和通风，增大光合总面积，而非直接降低消耗。间作（⑥）利用不同作物高矮搭配，提高光能利用率，促进光合作用。
  • 步骤：
    1. 找核心： 牢记各措施最直接、最主要的目的。
    2. 逐项精算：
      • ②④：均与诱导开花有关（√），A前半句对。
      • ③：风干降低呼吸消耗（√）；⑤：合理密植促进光合作用（×），故B错误。
      • ②：春化是促开花，非促光合（×），C错误。
      • ①：低温储存减弱呼吸（√）；③：风干减弱呼吸（√）；④：光周期目的在开花，非减弱呼吸（×），D错误。
    3. 定论： 只有A选项的关联是全部合理的。
  • 点评/变式：这类题考查广度，要求准确记忆各措施的原理归属，不混淆“促进光合”与“抑制呼吸”的措施。常见干扰项是将“适时灌溉”等同于“通风降温”。
