光呼吸

考点光呼吸权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：解答21
  • 难度分布：中1

知识精要

  • 光呼吸的本质：在光照、$CO_2$ 浓度低而 $O_2$ 浓度高的条件下，Rubisco 催化 $C_5$ 与 $O_2$ 结合，生成 $C_2$ 化合物（磷酸乙醇酸），随后在叶绿体、过氧化物酶体和线粒体中代谢，最终释放 $CO_2$ 的过程。
  • 发生条件与场所：
  • 诱发因素：$CO_2/O_2$ 比值降低（气孔关闭、强光耗竭 $CO_2$ 等）。
  • 涉及细胞器：叶绿体 → 过氧化物酶体 → 线粒体。
  • 物质与能量变化：
  • 底物：已同化的碳（$C_5$ 被氧化）。
  • 产物：$CO_2$、$NH_3$ 等，并消耗 ATP 和还原力。
  • 光呼吸整体不产生可利用的能量，反而消耗同化碳与能量。
  • 与有氧呼吸的本质区别：
  • 有氧呼吸以葡萄糖等为底物，主要在线粒体进行，释放能量合成大量 ATP；光呼吸底物为光合中间产物，无能量收益，且涉及多细胞器协作。
  • 光呼吸的生理影响：降低表观量子效率，减少净光合产物，是作物产量的潜在限制因素。

解题方法与套路

  1. 区分底物与过程：看清题目中“C₅与 O₂ 反应”还是“葡萄糖为底物的氧化分解”，准确对应光呼吸与有氧呼吸。
  2. 定位细胞器功能：分析流程图时，抓住各细胞器特有的反应——叶绿体（碳固定与光呼吸起始）、过氧化物酶体（氧化分解）、线粒体（释放 CO₂），结合光合作用知识确定步骤名称。
  3. 分析曲线与净光合速率：
  4. 明确 $CO_2$ 来源：大气 $CO_2$、光呼吸释放的 $CO_2$、呼吸作用（暗呼吸）释放的 $CO_2$。
  5. 净光合速率 = 总光合速率 - 呼吸速率（包括光呼吸与暗呼吸）。当未知呼吸速率时，无法仅用净光合速率计算总光合速率。
  6. 转基因产量优势推导：从净光合速率差异切入——光呼吸被抑制或改造后，净光合速率提高，有机物积累增多，是产量提升的依据。

高频易错

  • 误将光呼吸等同于暗呼吸（有氧呼吸）：光呼吸消耗 ATP，不产生可利用能量，且底物不是葡萄糖而是 $C_5$ 氧化生成的 $C_2$ 化合物。
  • 场所混淆：有氧呼吸产生 NADH 的场所是细胞质基质（糖酵解）和线粒体基质（丙酮酸氧化脱羧、三羧酸循环）；光呼吸不在这两处产生 NADH，反而消耗还原力。
  • 净光合速率与总光合速率计算：图 3 若只给出净光合速率而无总呼吸速率（光呼吸+暗呼吸）数据，则无法计算总光合速率，不可只用“净光合+暗呼吸”简单叠加，需注意题干是否提供全呼吸速率。
  • 光呼吸 $CO_2$ 来源的理解：光呼吸释放的 $CO_2$ 是植物光合作用自源的 $CO_2$，可重新被固定，不是从外界吸收。
  • 忽略光呼吸对产量影响的整体性：抑制光呼吸可提高净碳固定，但完全消除可能削弱光保护，在强光等胁迫下反而不利；答题时通常按题目导向，以提升净光合速率为增产依据。

代表题精讲

题目

（2024 辽宁卷 21）光下叶绿体中 $C_5$ 与 $CO_2$ 反应形成 $C_3$；当 $CO_2/O_2$ 比值低时，$C_5$ 与 $O_2$ 反应形成 $C_2$，经叶绿体、过氧化物酶体和线粒体完成光呼吸。给出图 1 的代谢过程，以及野生型(WT)与两个转基因株系 1 和 2 的净光合速率变化曲线（图 2、图 3）。回答反应名称、有氧呼吸产生 NADH 的场所、$CO_2$ 来源、7—10 时净光合速率差异原因、能否计算总光合速率及理由、株系 1 产量优势的依据。

思路

首先，根据卡尔文循环和光呼吸入门知识，识别反应①为 $CO_2$ 固定。其次，区分有氧呼吸各阶段与相应场所：细胞质基质（糖酵解）和线粒体基质（丙酮酸脱羧、三羧酸循环）均产 NADH。第三，分析光合作用 $CO_2$ 来源：外界吸收 + 呼吸作用（有氧呼吸）释放 + 光呼吸释放。接着，解读净光合速率曲线：7—10 时光照增强，株系 1、2 因光呼吸被改造，$CO_2$ 损失减少且能量浪费降低，净光合速率高于 WT。对于总光合速率，图 3 仅给净光合速率而无整个呼吸消耗数据，故无法计算。最后，产量优势从一整天净光合速率更高（有机物积累更多）得出。

步骤

  1. （1）反应①是 CO₂的固定。
  2. （2）有氧呼吸产生 NADH 的场所：细胞质基质、线粒体基质。
  3. （3）① 植物光合作用 $CO_2$ 来源除了外界环境，还可来自 光呼吸 和 呼吸作用（有氧呼吸）。
    ② 7—10 时株系差异原因：随着光照增强，光呼吸可能加剧，而 WT 正常进行较强的光呼吸，消耗较多已固定碳和能量；转入改变光呼吸基因的株系 1、2 光呼吸被削弱，减少碳和能量的浪费，净光合速率逐步高于 WT。
    ③ 不能计算出株系 1 的总光合速率，理由：总光合速率=净光合速率+呼吸速率，图 3 只给出净光合速率，未提供光呼吸和暗呼吸的总呼吸消耗数据。
  4. （4）株系 1 产量优势的依据：在测定时间段内，株系 1 的净光合速率始终显著高于 WT，且下午时段仍维持较高水平，说明全天有机物积累量更多，因此产量可能更具优势。

点评/变式

本题典型考查光呼吸与光合作用、呼吸作用的整合分析，重在过程区分和信息提取。变式可要求设计实验探究提高 $CO_2/O_2$ 比值对光呼吸的影响，或根据代谢简图补充中间产物，或计算某一时段碳固定量与光呼吸消耗量的关系。核心始终是：Rubisco 的双重功能、光呼吸多细胞器协作、净光合速率与呼吸的定量关系。
