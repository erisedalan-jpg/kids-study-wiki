免疫

考点免疫权重0真题数3学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：0
  • 真题数：3；年份跨度：2020–2024
  • 出现题位：选择1 选择3 选择12
  • 难度分布：中2 易1

知识精要

  • 抗原 (Antigen)：能引起机体产生特异性免疫的物质。化学本质通常是蛋白质等大分子。新冠病毒的蛋白质、肺炎双球菌的蛋白质等均可作为抗原。
  • 抗原呈递细胞 (APC)：
    • 作用：摄取、加工、处理抗原，并将抗原肽段呈递给辅助性T细胞。
    • 过程：
      1. 胞吞：依赖细胞膜的流动性，需要膜蛋白的识别参与，消耗能量。运输方式为胞吞，非被动运输。
      2. 加工处理：内吞形成的囊泡与溶酶体融合，利用溶酶体中的水解酶将抗原降解为肽段。
      3. 呈递：抗原肽段在内质网和高尔基体等细胞器的参与下，与MHCⅡ类分子结合，最终通过囊泡转运至细胞膜表面。
  • 免疫系统功能异常：
    • 自身免疫病：免疫系统“敌我不分”，将自身物质当作外来异物攻击。实例：类风湿性关节炎、系统性红斑狼疮。
    • 过敏反应：针对过敏原产生的异常免疫应答。实例：接触花粉、毛屑、海鲜引起的鼻炎、荨麻疹等。
    • 免疫缺陷病：免疫功能不足或缺陷。实例：艾滋病（获得性免疫缺陷综合征）。
  • 病毒与原核生物的结构比较：
    • 新冠病毒 (SARS-CoV-2)：无细胞结构，主要由蛋白质外壳和一种单链RNA (遗传物质) 组成。无核糖体，必须利用宿主细胞的核糖体合成自身蛋白质。
    • 肺炎双球菌：有细胞结构，属于原核生物。遗传物质是DNA，有唯一细胞器核糖体。

解题方法与套路

  1. 锁定研究对象类型：精准判断题干或选项中涉及的是病毒、原核生物还是真核细胞，这是解题的出发点。
  2. 结构与功能一一对应：
    • 病毒：无细胞结构、无核糖体 → 无法独立合成蛋白质。
    • 胞吞/胞吐：直接对应细胞膜的流动性和能量消耗，常与“被动运输”、“载体蛋白”等混淆，要警惕。
  3. 过程一致性分析：
    • 在分析APC呈递抗原或分泌蛋白合成运输的题目时，紧扣生物膜系统的结构与功能联系（内质网→高尔基体→囊泡→细胞膜），注意其联系方式是间接的（通过囊泡），而非结构上的直接连接。
  4. 辨析免疫异常类型：关键词映射法。
    • “攻击自身结构” → 自身免疫病。
    • “接触外界物质（过敏原）引发” → 过敏反应。
    • “免疫功能低下或缺失” → 免疫缺陷病。
    • 特别注意：抗维生素D佝偻病、白化病等是遗传病，不属于免疫病。

高频易错

  • 病毒蛋白质的合成场所：错误认为病毒可以利用自身结构合成蛋白质。正确：病毒无核糖体，必须在宿主细胞的核糖体上合成。
  • 胞吞过程中的膜蛋白作用：错误认为胞吞只与膜流动性有关，与膜蛋白无关。正确：胞吞需要细胞膜上的受体蛋白进行识别，依赖膜蛋白。
  • 抗原的化学本质：错误地认为只有蛋白质可作为抗原。正确：蛋白质是主要抗原，但某些多糖、脂类等也可能成为抗原。
  • 遗传物质与核苷酸的混淆：错误地比较RNA和DNA的核苷酸种类。正确：新冠病毒的遗传物质是RNA，含四种核糖核苷酸；肺炎双球菌的遗传物质是DNA，含四种脱氧核糖核苷酸。两者含有的核苷酸完全不同。
  • 免疫功能异常类型的混淆：
    • 将“遗传病”误判为自身免疫病（如抗维生素D佝偻病）。
    • 将“过敏反应”误判为自身免疫病。关键是看攻击对象是自身还是外来非致病性物质。

代表题精讲

代表题1 (2024·辽宁卷·12)

  • 题目：以APC摄取、加工处理和呈递抗原的过程示意图为情境，判断关于该过程及相关结构的叙述正误。
  • 思路：本题核心是考查胞吞、胞内运输和细胞器分工的知识。解题关键是将图示过程与已学的分泌蛋白合成运输、溶酶体功能、生物膜系统等知识进行类比和联系。
  • 步骤：
    1. A项分析：“摄取抗原的过程依赖细胞膜的流动性，与膜蛋白无关”。摄取抗原是胞吞作用，依赖膜的流动性进行形变包裹，但首先需要膜蛋白识别抗原，触发胞吞。故“与膜蛋白无关”错误。
    2. B项分析：“直接加工处理抗原的细胞器有①②③”。图中显示抗原被内吞后，首先与含有水解酶的溶酶体（③）融合并被降解。之后，抗原肽段进入内质网等结构进行后续加工。内质网（①）、高尔基体（②）是参与后续呈递的，不是直接加工处理外源性抗原的第一步。主要的直接加工处理细胞器是溶酶体。此说法不准确。
    3. C项分析：“抗原加工处理过程体现了生物膜系统结构上的直接联系”。内质网、高尔基体、囊泡、细胞膜之间的物质运输是通过囊泡的形成、转移和融合完成的，这体现了生物膜系统的间接联系，而非结构上的直接连接。故错误。
    4. D项分析：“抗原肽段与MHCⅡ类分子结合后，可通过囊泡呈递到细胞表面”。MHCⅡ类分子在细胞内与加工后的抗原肽段结合，形成的复合物通过高尔基体发出的囊泡运输并与细胞膜融合，从而被呈递到细胞表面。此项描述正确，符合示意图流程。
  • 点评/变式：本题综合性较强，将《分子与细胞》中细胞结构和物质运输的知识与《稳态与调节》中的免疫知识深度融合。备考时需建立“结构决定功能”的跨章节知识观。变式：可用相同示意图考查分泌抗体的浆细胞或分泌淋巴因子的T细胞的相关过程。

代表题2 (2020·新课标Ⅱ卷·1)

  • 题目：比较新冠病毒与肺炎双球菌的结构、跨膜运输、遗传物质和免疫原性。
  • 思路：这是一道典型的病原体比较题，解题关键在于明确细菌是原核生物，有细胞结构；病毒无细胞结构，生命活动必须依赖宿主细胞。
  • 步骤：
    1. A项分析：“新冠病毒进入宿主细胞的跨膜运输方式属于被动运输”。病毒大分子或颗粒进入细胞的方式是胞吞，此过程需要消耗能量，属于主动运输范畴，不是被动运输。错误。
    2. B项分析：“新冠病毒与肺炎双球菌均可利用自身的核糖体进行蛋白质合成”。新冠病毒没有核糖体，只能“借用”宿主细胞的核糖体。肺炎双球菌作为原核生物，有核糖体。故错误。
    3. C项分析：“新冠病毒与肺炎双球菌二者遗传物质所含有的核苷酸是相同的”。新冠病毒的遗传物质是RNA，其基本单位是核糖核苷酸；肺炎双球菌的遗传物质是DNA，其基本单位是脱氧核糖核苷酸。二者核苷酸的五碳糖不同，种类完全不同。错误。
    4. D项分析：“新冠病毒或肺炎双球菌的某些蛋白质可作为抗原引起机体免疫反应”。两者都有蛋白质，这些主体结构成分均为大分子，进入机体后能被免疫系统识别为“非己”物质，即抗原，可引发免疫反应。正确。
  • 点评/变式：本题精准命中了“病毒与细胞生物的区别”这一高频考点。失分点常在于忽略病毒无细胞器、混淆胞吞与被动运输的区别。备考中要系统梳理病毒、原核生物、真核生物的比较表，特别是繁殖方式、遗传物质和蛋白质合成场所。
