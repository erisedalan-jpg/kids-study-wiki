免疫系统

考点免疫系统权重6真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：6
  • 真题数：1；年份跨度：2013–2013
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 免疫细胞分类
  • 免疫细胞：泛指所有参与免疫应答或与免疫应答有关的细胞，包括淋巴细胞、吞噬细胞、树突状细胞等。
  • 淋巴细胞：特指特异性免疫的核心细胞，仅包括T细胞和B细胞；吞噬细胞（如巨噬细胞、中性粒细胞）不属于淋巴细胞。
  • 免疫细胞分布
  • T细胞和B细胞成熟后经血液循环和淋巴循环分布于血液、淋巴液及外周免疫器官。
  • 抗体分泌方式
  • 抗体（本质是蛋白质）由浆细胞通过胞吐作用分泌，依赖细胞膜的流动性，需消耗能量。
  • 概念辨析
  • 免疫细胞 ⊃ 淋巴细胞，吞噬细胞⊆免疫细胞，但吞噬细胞⊈淋巴细胞。
  • 浆细胞是B淋巴细胞接受抗原刺激后增殖分化形成的终末效应细胞，能大量分泌抗体。

解题方法与套路

  1. 严格区分概念间的包涵关系：用集合图梳理“免疫细胞—淋巴细胞—T细胞/B细胞”以及“免疫细胞—吞噬细胞”的关系。
  2. 抓住关键特征词：看到“淋巴细胞”立即反应只含T、B两种；看到“免疫细胞”则思考更广的范围（含吞噬细胞等）。
  3. 关联细胞产地与运输路径：联系免疫细胞的成熟场所（胸腺、骨髓）与淋巴—血液回流，判断细胞分布。
  4. 联系分泌物特性与分泌方式：明确抗体的化学本质为分泌蛋白，故浆细胞以胞吐方式排泌；胞吐是跨膜运输的一种，常见于大分子或颗粒物质的释放。

高频易错

  • 误认为吞噬细胞属于淋巴细胞：吞噬细胞具有非特异性吞噬功能，归属免疫细胞大类，但不入淋巴细胞之列。题干常以“淋巴细胞包括B细胞、T细胞和吞噬细胞”设置陷阱。
  • 混淆T细胞、B细胞只存在于淋巴液：实则T、B细胞可随血液循环及淋巴循环流动，血液和淋巴液中均有分布。
  • 对抗体分泌机制记忆模糊：部分考生以为是主动运输或自由扩散，实则抗体为生物大分子，须经高尔基体包装，以胞吐形式分泌至胞外。
  • 忽略“免疫细胞”一词的广度：只要参与免疫作用的细胞均可称为免疫细胞，吞噬细胞、淋巴细胞、树突状细胞等均属此范畴。

代表题精讲

题目：2013·新课标Ⅱ·04——关于免疫细胞的叙述，选出错误的选项。
思路：逐项对照免疫细胞的核心定义与分布知识。重点核查“淋巴细胞”是否被偷换了范围。
步骤
- A项：称“淋巴细胞包括B细胞、T细胞和吞噬细胞”。结合知识，淋巴细胞仅含T、B两种，吞噬细胞不属于淋巴细胞，故此项错误。
- B项：血液和淋巴液中都含有T细胞和B细胞。T、B细胞经循环系统再分布，描述正确。
- C项：吞噬细胞和B细胞都属于免疫细胞。二者均直接参与免疫过程，属于免疫细胞，正确。
- D项：浆细胞通过胞吐作用分泌抗体。抗体为分泌蛋白，胞吐排出，正确。
- 结论：错误项为A。
点评/变式：此题是免疫细胞分类的典型“同义替换”干扰题。变式常将“淋巴细胞”替换为“白细胞”、“吞噬细胞”替换为“中性粒细胞”等，核心仍是辨析细胞归属。应对策略：牢记淋巴细胞的严格定义，并构建免疫细胞家族拓扑图。
