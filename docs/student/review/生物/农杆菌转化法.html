农杆菌转化法

考点农杆菌转化法权重8真题数1学科生物父主题生物技术与工程

考点定位

  • 父主题：生物技术与工程
  • 权重 weight：8
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • 基因文库
  • 基因组文库：包含某种生物 全部 基因；构建时将全部 DNA 随机切割成片段与载体连接后导入受体菌。
  • cDNA 文库：以 mRNA 为模板逆转录获得，只包含 部分（已表达）基因，不含内含子等非编码序列。
  • 农杆菌转化法
  • 原理：利用 农杆菌 Ti 质粒 上的 T-DNA 可将外源基因 转移并整合到植物细胞染色体 DNA 中。
  • 步骤：目的基因插入 Ti 质粒 T-DNA 区 → 导入农杆菌 → 农杆菌感染植物 体细胞（外植体）→ 组织培养得到再生植株。
  • 适用范围：主要用于 双子叶植物 和裸子植物，单子叶植物较难。
  • 目的基因的检测与鉴定
  • 分子水平：检测转基因植株的 表达产物（蛋白质），如抗原-抗体杂交。
  • 个体生物学水平：直接观察目标 性状（如耐旱性）是否改变。
  • 转基因植株整合位置的遗传推断
  • 二倍体转基因植株自交，若耐旱基因插入 同源染色体的一条上，相当于一个 杂合 的等位位点，遵循分离定律，自交后代显性：隐性 = 3:1（设耐旱为显性且独立整合不影响育性）。
  • 若插入 同源染色体的两条上，则该植株为耐旱基因纯合，自交后代全部耐旱。

解题方法与套路

  1. 明确文库类型：看到“基因组文库”想到全部基因、含非编码区；“cDNA 文库”想到逆转录、部分基因、无内含子。
  2. 目的基因获取与导入：先构建文库，通过 分子探针或特异性引物 筛选目的基因 → 选择合适方法导入受体（农杆菌转化法主要用于植物，适合双子叶）。填空中注意根据受体植物是否耐旱选择靶标——通常将目的基因转入 性状较差 的个体。
  3. 表达与检测的逻辑链：基因工程操作流程：获取基因→构建表达载体→导入受体→检测与鉴定。检测表达是否成功需先检测 表达产物（蛋白质），再于 个体水平 检测目标性状。
  4. 遗传推断法：对于“是否整合到染色体”及“整合在同源染色体的一条/两条”的判断，可将转基因植株视为 单基因位点 的杂合/纯合体，利用自交/测交子代的 性状分离比 反推。

高频易错

  • 混淆基因组文库与 cDNA 文库：误以为二者都包含全部基因；cDNA 文库来自逆转录，只代表 某一时期/组织表达的基因。
  • 目的基因导入与检测的对应关系：将“正确表达”直接等同于个体水平检测；应先答检测 表达产物，再答检测 植株性状。
  • 农杆菌转化法的适用对象：错以为可用于所有植物；实际操作中对单子叶植物效率低。
  • 遗传比推断整合位置：看到 3:1 即以为在常染色体上独立遗传，但需具体答出整合在 同源染色体的一条上（即单拷贝杂合插入），若答成“两条上”则产生全耐旱后代。

代表题精讲

题目 2014-新课标Ⅱ-12

（1）基因组文库与 cDNA 文库的基因组成比较；（2）从文库中获得耐旱基因的方法；（3）农杆菌转化法将基因导入植物乙体细胞后，检测表达和耐旱性；（4）转基因自交后代 3:1 推断整合位置。

思路
以基因工程流程为主线：基因获取（文库）→ 导入方法（农杆菌）→ 表达检测（蛋白质与性状）→ 遗传验证（自交分离比推断整合情况）。

步骤 - (1)(2) 基因组文库含 全部 基因，cDNA 文库含 部分 基因；从基因组文库中经 筛选（杂交） 获得目的基因。 - (3) 因植物乙耐旱性低，故将基因通过农杆菌转化法导入 植物乙 的体细胞；正确表达需检测 表达产物，再于田间检测 耐旱性。 - (4) 二倍体自交子代耐旱：不耐旱 = 3:1，符合单基因杂合的分离比，说明基因整合到 同源染色体的一条上。

点评/变式
本题将基因工程与遗传规律结合，是经典综合性考查。易错点在于检测层次必须从分子产物到个体表型。若后代全为耐旱，则基因整合在 同源染色体的两条上；若后代比例不符合单基因分离比，则可能 多拷贝插入或发生位置效应。变式可结合电泳、PCR 检测基因存在但无表达的情况，进一步考查“表达”与“存在”的区别。
