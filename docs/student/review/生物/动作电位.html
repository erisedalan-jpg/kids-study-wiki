动作电位

考点动作电位权重10真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：10
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 静息电位：神经细胞未受刺激时膜内外的电位差，表现为外正内负。主要由细胞内外 $K^+$ 浓度差决定，$K^+$ 通过钾漏通道外流，接近 $K^+$ 的平衡电位。静息电位大小与细胞外 $K^+$ 浓度密切相关，与细胞外 $Na^+$ 浓度基本无关。
  • 动作电位：细胞受适宜刺激后，膜两侧发生的一次快速、可逆的电位倒转和恢复过程。包括：
  • 去极化：电压门控 $Na^+$ 通道开放，$Na^+$ 大量内流，膜内电位升高（负值减小并倒转为正）。
  • 复极化：$Na^+$ 通道失活，电压门控 $K^+$ 通道开放，$K^+$ 外流，恢复外正内负。
  • 动作电位峰值：主要取决于细胞内外 $Na^+$ 的浓度梯度。细胞外 $Na^+$ 浓度降低 → 内流驱动力减弱 → 动作电位峰值降低；细胞外 $Na^+$ 浓度升高 → 峰值升高（有限度）。动作电位具有“全或无”特性，但峰值可在一定范围内随 $Na^+$ 浓度差变化。
  • 适用条件：讨论静息电位与 $Na^+$ 变化无关时，需保持 $K^+$ 浓度等其他条件不变；动作电位的产生要求刺激达到阈电位。

解题方法与套路

  1. 审题抓变量：明确题干改变的是细胞外液（溶液S）中哪种离子浓度（本题为降低 $Na^+$），并确认其他离子浓度是否同步变动。
  2. 对应电位机制：
  3. 若变量是 $K^+$ 浓度，影响静息电位（外正内负的差值）：细胞外 $K^+$ 升高 → 静息电位绝对值减小；细胞外 $K^+$ 降低 → 静息电位绝对值增大。
  4. 若变量是 $Na^+$ 浓度，主要影响动作电位峰值（高度）：细胞外 $Na^+$ 降低 → 动作电位峰值降低；细胞外 $Na^+$ 升高 → 峰值升高。
  5. 排除干扰：分清所问是静息电位还是动作电位，选项中可能同时出现两者的错误描述，根据机制快速排除。
  6. 结合“全或无”理解：$Na^+$ 浓度变化不影响是否产生动作电位（仍可达阈电位产生），但影响峰值的幅度。

高频易错

  • 混淆离子职责：误以为细胞外 $Na^+$ 浓度变化会影响静息电位。静息阶段膜对 $K^+$ 通透性高，对 $Na^+$ 通透性极低，故静息电位主要由 $K^+$ 平衡电位决定。
  • 绝对化记忆“全或无”：认为动作电位幅度绝对不变。实际上，“全或无”指刺激强度在阈电位以上时，动作电位一旦触发便以固定模式产生，但峰值大小受膜两侧离子浓度梯度影响。
  • 忽略隐含条件：题目中“适当降低溶液S的 $Na^+$”，维持了 $K^+$ 浓度不变，如果未明确其他离子恒定，需默认为单一变量，避免过度联想。
  • 相近数字干扰：选项中静息电位“不变”是关键词，若粗看易选“增大”或“减小”。

代表题精讲

2010·新课标卷·05

题目：将神经细胞置于相当于细胞外液的溶液S中，测静息电位。给予适宜刺激，记录动作电位。适当降低溶液S的 $Na^+$ 浓度，测量该细胞的静息电位和动作电位，观察到的现象是（ ）
A．静息电位值减小　B．静息电位值增大　C．动作电位峰值升高　D．动作电位峰值降低

思路：先区分静息电位与动作电位的离子基础——静息电位看 $K^+$，动作电位峰值看 $Na^+$。题中只降低了 $Na^+$ 浓度， $K^+$ 浓度不变，因此静息电位不受影响。动作电位去极化时 $Na^+$ 内流的驱动力下降，进入细胞的 $Na^+$ 量减少，峰值必然降低。

步骤： 1. 分析静息电位：主要由 $K^+$ 外流导致，与 $Na^+$ 无关。降低溶液S中 $Na^+$，$K^+$ 浓度不变，所以静息电位值不变。排除A、B。 2. 分析动作电位：峰值的形成依赖 $Na^+$ 快速内流。降低细胞外 $Na^+$ 浓度，使得膜内外 $Na^+$ 浓度差减小，内流动力减弱，$Na^+$ 平衡电位绝对值减小，导致动作电位峰值降低。确认选D。 3. 最终确定：动作电位峰值降低，静息电位不变，D正确。

点评/变式：本题直击核心概念鉴别，是电位类选择题的典型考法。变式可改为“适当增加溶液S中 $K^+$ 浓度”或同时改变两种离子，需谨记：细胞外 $K^+$ 升高 → 静息电位绝对值减小（更接近阈电位，兴奋性可能升高）；细胞外 $Na^+$ 升高 → 动作电位峰值升高。组合变化时逐一分析即可。
