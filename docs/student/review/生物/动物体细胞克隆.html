动物体细胞克隆

知识精要

  • 动物体细胞核移植原理：动物体细胞核移植是将动物一个体细胞的细胞核，移入一个已去掉细胞核的卵母细胞中，使其重组并发育成一个新的胚胎，最终发育为与供体细胞核遗传物质基本相同的个体。该技术证明了已分化的动物体细胞核具有全能性。
  • 基本流程
  • 供体细胞准备：从供体动物获取体细胞进行培养。
  • 受体细胞准备：获取卵母细胞，培养至减数第二次分裂中期（MⅡ期），用显微操作方法去除细胞核。
  • 核移植与重组：将供体体细胞核注入/融合到去核卵母细胞中。
  • 重组细胞激活与培养：通过物理或化学方法刺激重组细胞分裂发育。
  • 胚胎移植：将早期胚胎移植到代孕（受体）母体子宫内，完成妊娠并产下克隆动物。
  • 遗传物质来源
  • 克隆动物的细胞核遗传物质来自供体动物。
  • 细胞质遗传物质（线粒体DNA） 主要来自受体卵母细胞。
  • 因此，克隆动物与供体动物的性状不完全相同，会受到卵母细胞细胞质基因的影响。
  • 供体细胞的选材要求
  • 供体细胞传代次数不宜过多。多次传代后，细胞中遗传物质（或DNA/染色体）的稳定性会降低，可能积累突变，影响克隆成功率与克隆动物健康。
  • 供体细胞性染色体组成：克隆哺乳动物（二倍体）的供体可以是雌性或雄性，因此正常细胞核中性染色体组成为 XX或XY。

解题方法与套路

  1. 流程识别与名词定位
    见到核移植流程简图，首先识别“去除细胞核”“细胞核移植”“重组细胞”“胚胎移植”等关键步骤的名称。尤其牢记：去核发生在MⅡ期卵母细胞，去核工具/方法是显微操作仪/显微操作，将早期胚胎移入代孕母体叫胚胎移植。
  2. “不完全相同”问题答题模板
    如果问及克隆动物与供体动物性状差异的原因，题干指向“从遗传物质角度”，标准答法是：受体卵母细胞的细胞质中含有遗传物质（线粒体DNA），会对克隆动物的性状产生影响。切忌只回答说“环境因素”，必须扣住题干限定的角度。
  3. 传代次数与稳定性关系
    若题目出现“经多次传代后”或“培养代数多”的信息，需要答出遗传物质（或染色体、DNA）稳定性降低，这通常涉及供体细胞的选择注意点。
  4. 结论/意义类问题终极答案
    但凡克隆动物（如“多莉”羊）成功获得，其核心结论都是：证明已分化的动物体细胞的细胞核具有全能性。看到“证明”“说明”等词，直接定位此结论。

高频易错

  • 去核时期混淆：误答成“去核时卵母细胞培养到受精后”或“MⅠ期”。核移植去核必须在MⅡ期，此时细胞核（极体与纺锤体）位置便于显微操作去除。
  • 去核方法表述不准：将该操作写成“显微注射”“手术”“离心”等，规范的专有名词是显微操作（去核）。
  • 遗传物质来源分析片面：只答“环境因素导致性状差异”，未抓住题目给定的限制——“从遗传物质的角度”。必须点出细胞质DNA（线粒体DNA） 的影响。
  • “全能性”的主体对象错误：写成“证明了克隆动物的细胞具有全能性”或“动物细胞具有全能性”。标准表述是已分化体细胞的细胞核具有全能性，强调“体细胞”“已分化”“去核卵母细胞重编程”。
  • 性染色体的漏答：供体可能为雄性（XY）或雌性（XX），只答一种则因考虑不全面而失分。

代表题精讲

代表题1：2016-新课标Ⅱ-12

题目
题干给出核移植克隆哺乳动物流程简图，设问涵盖去核处理、胚胎移植、供体细胞传代问题、性状差异的遗传原因，以及成功克隆的证明结论。

思路
严格按照动物细胞核移植全流程对应图中的每一步：
- A是供体细胞核，含二倍体染色体数目，性染色体可能为XX或XY。
- 过程①为去核，核心回答时期（MⅡ期）与操作手法（显微操作）。
- 过程②为将早期胚胎送入代孕母体，即胚胎移植。
- 多次传代后供体细胞稳定性下降，原因是“遗传物质稳定性降低”。
- 性状不完全相同从细胞质遗传角度切入（细胞质DNA影响）。
- 克隆成功的科学意义紧扣“已分化体细胞核的全能性”结论。

步骤
1. 第（1）问填性染色体组成：“XX或XY”；填去核方法：“显微操作”；填过程②的名称：“胚胎移植”。
2. 第（2）问填多次传代后的稳定性降低对象：“遗传物质”（或DNA）。
3. 第（3）问从遗传物质角度回答性状差异原因：“卵母细胞的细胞质中含遗传物质（线粒体DNA），影响克隆动物性状”。
4. 第（4）问直接写出最终结论：“动物已分化体细胞的细胞核具有全能性”。

点评/变式
该题为典型流程填空题与原因分析题，完整覆盖体细胞核移植重难点。变式常设置为：
- 将“显微操作”改成“显微注射”“电融合”等的混淆。
- 突变某种去核时期，判断是否正确。
- 对性状差异设问时，隐去“遗传物质角度”，可能引发环境或表观遗传错误应答，需注意审题限定。答题时必须严格对应题目给出的角度作答。
