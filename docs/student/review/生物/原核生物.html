总览数学物理化学生物

原核生物

考点原核生物权重13真题数2学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：13
  • 真题数：2；年份跨度：2013–2020
  • 出现题位：选择3
  • 难度分布：中1 易1

知识精要

  • 原核生物结构：无核膜包被的细胞核，仅有拟核（裸露DNA集中区域）；除核糖体外无其他细胞器（无线粒体、叶绿体等），细胞壁主要成分为肽聚糖（支原体除外）。
  • 遗传物质与基因表达：遗传物质为DNA；基因主要在拟核及质粒上；转录与翻译能同时同地进行；相关酶由拟核中基因编码。
  • 代谢特点：无线粒体的好氧细菌（如肺炎双球菌、醋酸杆菌）质膜上含有与有氧呼吸相关的酶，能进行有氧呼吸；部分为厌氧菌（如破伤风芽孢杆菌、乳酸菌），只能进行无氧呼吸。
  • 与病毒的根本区别：病毒无细胞结构，无独立代谢能力，必须寄生在活细胞内，利用宿主细胞核糖体合成蛋白质；遗传物质是DNA或RNA，核苷酸种类与原核生物可能不同（DNA含脱氧核糖，RNA含核糖，碱基类型有差异）。
  • 免疫与抗原：原核生物及病毒的某些蛋白质可作为抗原，引发机体的特异性免疫反应。

解题方法与套路

  1. 明确生物类型：先判断题目中生物是原核生物、真核生物还是病毒。
  2. 比照结构特征：看是否具有核膜、膜性细胞器、核糖体、染色体、细胞壁成分等；原核细胞仅有核糖体，病毒无任何细胞器。
  3. 联想代谢与遗传：有氧呼吸不一定需要线粒体，关键看是否有有氧呼吸酶；酶和蛋白质编码对应拟核或细胞核或宿主；遗传物质确定后，核酸种类及核苷酸组成便确定。
  4. 注意特例：破伤风芽孢杆菌为严格厌氧菌，有氧环境抑制其生长；支原体无细胞壁等特殊情形快速排除。
  5. 结合免疫学知识：判断是否能作为抗原、引起哪种免疫反应。

高频易错

  • 误以为无线粒体就不能进行有氧呼吸：好氧细菌质膜上有有氧呼吸酶，能进行有氧呼吸。
  • 混淆病毒与原核生物：病毒没有细胞结构，不含核糖体，蛋白质合成必须依赖宿主。
  • 遗传物质与核苷酸种类判断失误：细胞生物的遗传物质均为DNA，病毒的遗传物质为DNA或RNA，二者核苷酸种类不完全相同；DNA病毒与原核生物的核苷酸种类可以相同。
  • 对微生物氧需求类型记忆错误：破伤风芽孢杆菌是厌氧菌，有氧条件下受抑制；肺炎双球菌是好氧菌。
  • 忽略酶的编码来源：细菌中与呼吸等生命活动相关的酶均由拟核中的基因编码，而非质粒独立承担主要生命活动调控。

代表题精讲

代表题1：2020-新课标Ⅱ-03

题目：关于新冠病毒与肺炎双球菌的叙述，判断选项正误。

思路：先明确新冠病毒是RNA病毒，无细胞结构；肺炎双球菌是原核生物，遗传物质为DNA。选项涉及胞吞进入、核糖体利用、核苷酸种类及抗原作用，需逐项利用病毒和原核生物的典型特征判断。

步骤： 1. 新冠病毒进入宿主细胞的方式是胞吞？膜融合型病毒多为胞吞，此处需要记忆或推理；依解析，该选项错误。 2. 分析蛋白质合成的场所：新冠病毒无核糖体，必须利用宿主细胞的核糖体，故选项表述“新冠病毒无核糖体”基础上若说可利用自身核糖体则错，解析指明B错误。 3. 比较核苷酸种类：新冠病毒遗传物质是RNA，肺炎双球菌遗传物质是DNA，两者核酸种类不同，核苷酸种类不同（核糖核苷酸与脱氧核苷酸的区别），C错误。 4. 免疫抗原性：病毒与细菌的蛋白质均可作为抗原，D正确。

点评/变式：本题集中考查病毒与原核生物的辨析。变式可把肺炎双球菌替换为大肠杆菌或酵母菌，增加判断线粒体、有氧呼吸、细胞壁成分等维度，但逻辑一致：先定类型，再审结构功能。

代表题2：2013-新课标Ⅱ-03

题目：与微生物呼吸有关的叙述，选择错误项。

思路：列举的四种微生物覆盖好氧细菌、厌氧细菌与兼性厌氧真菌。需用原核生物的结构与呼吸类型知识逐项分析。

步骤： 1. 肺炎双球菌无线粒体但含好氧呼吸酶，能进行有氧呼吸，A正确。 2. 细菌呼吸有关的酶由拟核中基因编码，该性状不由质粒单独决定，B正确。 3. 破伤风芽孢杆菌是专性厌氧菌，有氧环境抑制其生长，C错误，为题目所求。 4. 酵母菌有氧呼吸产物为CO₂和H₂O，无氧呼吸产物为酒精和CO₂，D正确。

点评/变式：易错点在破伤风杆菌的氧需求类型及肺炎双球菌无线粒体但有氧呼吸的常考命题。变式可将肺炎双球菌换成蓝藻（光合作用无叶绿体）、硝化细菌（化能合成作用），再次强化结构决定代谢类型的例外性。
