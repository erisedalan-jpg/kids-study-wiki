反义基因

考点反义基因权重6真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：6
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：选择7
  • 难度分布：易1

知识精要

  • 反义基因：能与目标基因（正义基因）的 mRNA 互补配对的 DNA 片段。将其转入生物体后，可转录产生反义 RNA，与目标 mRNA 形成双链，从而阻断翻译过程，抑制目标基因的表达。
  • 作用机理：
    $\text{反义基因} \xrightarrow{\text{转录}} \text{反义 RNA} \xrightarrow{\text{碱基互补配对}} \text{目标 mRNA} \xrightarrow{\text{抑制}} \text{翻译受阻}$
    最终导致相应蛋白质合成减少或缺失。
  • 适用条件：常用于基因功能研究（基因敲低）及作物性状改良。反义基因只抑制特定目标基因，不影响其他基因表达。
  • 乙烯与果实成熟：乙烯是植物激素，能促进果实成熟。果实中乙烯含量越高，成熟越早。

解题方法与套路

  1. 厘清基因关系：明确材料中哪些是内源功能基因（如 X 基因、Y 基因），哪些是外源反义基因（反义 X、反义 Y）。反义基因本身不编码功能蛋白，只起抑制作用。
  2. 蛋白检测推断抑制效果：若某组果实中未检测到 X 蛋白，说明反义 X 基因成功抑制了 X 基因表达；同理推断 Y 基因。
  3. 对照数据找差异：以非转基因植株（A 组）为对照，比较乙烯释放量，判断各基因对乙烯合成的作用：
  4. 乙烯释放量降低 → 相关基因被抑制 → 该基因可能促进乙烯合成。
  5. 乙烯释放量无变化或变化小 → 该基因对乙烯影响小。
  6. 关联生理指标与性状：乙烯含量高 → 成熟早、不耐储存；乙烯含量低 → 成熟晚、耐储存。结合数据回答成熟时间和储存时间问题。
  7. 填写作答基因组成：问“与乙烯含量有关的基因”时，应列出该组细胞内所有可能参与乙烯调控的基因（包括功能基因和反义基因），注意反义基因虽不直接产乙烯，但影响相关功能基因表达，故应列入。

高频易错

  • 误把反义基因当功能基因：填写基因组成时遗漏反义基因，如 B 组除 X、Y 基因外还应写反义 X 基因，忽略即丢分。
  • 蛋白检测结果与乙烯数据脱节：题目先给蛋白检测结果，再给乙烯数据，需将两者结合，不能单用一组信息。如 C 组既无 Y 蛋白又无乙烯释放，说明 Y 基因促进乙烯合成且被完全抑制。
  • 乙烯释放量为零不代表无相关基因：C 组乙烯释放量始终为零，是因反义 Y 基因抑制了 Y 基因，细胞内仍有 X 基因和反义 Y 基因，只说“无 Y 基因”错误。
  • 储存时间判断：错误认为成熟早的果实耐储存，实际上乙烯释放量高的果实衰老快，不耐储存。B 组乙烯低，35 天采摘后储存时间更长。
  • 对照分析不全面：三组比较时忽略时间点差异，如 35d 后 A 组乙烯下降而 B、C 组仍较低，需结合基因抑制持续时间解释。

代表题精讲

【代表题】2015-新课标Ⅱ-07

题目
以非转基因植株（A 组）、反义 X 基因植株（B 组）、反义 Y 基因植株（C 组）为材料，检测不同天数果实的乙烯释放量，并结合蛋白检测结果，回答：（1）各组果实中与乙烯含量有关的基因；（2）成熟最早组及原因、35 天采摘后储存时间更长的组。

思路
从反义基因抑制原理出发，蛋白质检测结果证明抑制成功；对照乙烯数据，推导基因功能及对成熟、储存的影响。

步骤
1. 分析蛋白检测结果：B 组无 X 蛋白 → 反义 X 基因抑制 X 基因表达；C 组无 Y 蛋白 → 反义 Y 基因抑制 Y 基因表达。A 组正常表达 X、Y。
2. 结合乙烯数据分析基因作用：
- A 组乙烯释放量在 35d 后出现并较高 → X、Y 基因均正常表达，乙烯合成正常，果实正常成熟。
- B 组乙烯释放量明显低于 A 组 → X 基因被抑制导致乙烯合成减少，说明 X 基因促进乙烯合成。
- C 组整个过程中乙烯释放量始终为 0 → Y 基因被完全抑制，说明 Y 基因是乙烯合成的关键基因，可能起主要作用。
3. 作答基因组成（填所有与乙烯有关的基因，含反义基因）：
- A 组：X 基因和 Y 基因。
- B 组：X 基因、Y 基因和反义 X 基因。
- C 组：……（虽题未直接要求填全，但按推理应含 X 基因、Y 基因和反义 Y 基因）。
4. 推果实成熟与储存：乙烯高成熟早 → A 组成熟最早；35 天采摘后，B 组乙烯低、衰老慢 → 储存时间更长。

点评/变式
- 该题核心在于反义基因抑制专一性与植物激素作用。易错点已在高频易错中强调。
- 变式：若反义 X 基因和反义 Y 基因同时转入，推测乙烯释放量变化及成熟表型；或改换其他激素（如脱落酸）结合基因敲低实验，解题思路一致：先明确抑制关系，再关联生理数据。
