反馈调节

考点反馈调节权重11真题数2学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：11
  • 真题数：2；年份跨度：2009–2022
  • 出现题位：选择2 选择8
  • 难度分布：中1 易1

知识精要

  • 反馈调节定义：在一个系统中，系统本身工作的效果，反过来又作为信息调节该系统的工作。
  • 负反馈：反馈结果抑制最初变化。是维持稳态的核心机制。
    • 结果：使系统维持相对稳定。
    • 实例：甲状腺激素分泌调节（血液中 $T_3/T_4$ 升高，抑制下丘脑和垂体分泌 $TRH$ 及 $TSH$）；血钙调节（降钙素与甲状旁腺素互为拮抗，维持血钙稳态）。
  • 正反馈：反馈结果促进与加强最初变化。
    • 结果：使系统偏离稳态，加速生理过程。
    • 实例：排尿反射、分娩过程、血液凝固。
  • 分级调节与反馈调节的区别：
    • 分级调节：下丘脑 $\rightarrow$ 垂体 $\rightarrow$ 靶腺（纵向控制）。
    • 反馈调节：靶腺激素浓度升高 $\rightarrow$ 抑制下丘脑和垂体（反向抑制）。注意，靶腺激素只对下丘脑和垂体进行负反馈，并非对自身。

解题方法与套路

  1. 判断调节类型：抓取关键词“抑制”、“维持稳定”、“保持相对恒定”通常属于负反馈；出现“加速”、“增强”、“进一步”通常属于正反馈。
  2. 分析激素分泌轴（下丘脑-垂体-靶腺）：
    • 注射靶腺激素（如甲状腺激素）$\rightarrow$ 负反馈抑制增强 $\rightarrow$ 内源 $TSH$ 及靶腺激素合成减少。
    • 注射促激素（如促甲状腺激素）$\rightarrow$ 直接促进靶腺分泌 $\rightarrow$ 靶腺激素合成增多。
    • 注射生理盐水作为空白对照，代表基础分泌量。
  3. 放射性同位素示踪应用：看到“放射性碘” $\rightarrow$ 甲状腺会主动摄取碘元素用于合成甲状腺激素 $\rightarrow$ 题干常考查甲状腺的功能特性。

高频易错

  • 混淆调节方向：误以为注射外源甲状腺激素会促进自身甲状腺合成激素。正确理解：外源激素增多启动负反馈，抑制垂体分泌 $TSH$，导致自身甲状腺合成量下降（乙组<甲组）。
  • 忽略“腺体”与“激素”的来源差异：乙组注射甲状腺激素，激素本身来自外界，但题目问的是“甲状腺的合成量”，即腺体的功能。乙组自身甲状腺合成被抑制，丙组自身甲状腺受 $TSH$ 刺激合成增强，二者不相同。
  • 误判反馈的靶器官：靶腺激素的负反馈作用对象是下丘脑和垂体，不直接通过负反馈抑制自身腺体细胞对原料的摄取。
  • 只记结论，忽略现实复杂性：2009 全国卷真题“降钙素由甲状腺 C 细胞分泌”，易先入为主记成“甲状旁腺分泌降钙素”导致判断错误。血钙调节是双重激素拮抗调节的经典范例。

代表题精讲

2022-全国乙-08

  • 题目：研究甲状腺激素合成机制，实验一注射放射性碘检测甲状腺放射性；实验二对甲乙丙三组家兔分别注射生理盐水、甲状腺激素、促甲状腺激素，检测血中甲状腺激素含量。
  • 思路： （1）考查甲状腺的功能（选择性摄取碘）。 （2）考查分级调节与负反馈。注意审题：比较“丙组与甲组”、“乙组与丙组”的合成量，而非血液总含量。
  • 步骤：
    • (1) 甲状腺具有吸收碘用以合成甲状腺激素的功能，故放射性会聚集于甲状腺。
    • (2)
      • 甲组注射生理盐水为对照，甲状腺正常合成。
      • 丙组注射促甲状腺激素（$TSH$），促进甲状腺合成分泌，故丙组合成量大于甲组。
      • 乙组注射甲状腺激素，通过负反馈抑制垂体分泌 $TSH$，导致自身甲状腺合成减少。丙组受外源 $TSH$ 刺激合成增多。由于两组的调节机制相反，合成量增减方向不同，故不相同。
  • 点评/变式：这是一道经典的“反直觉”考题。核心陷阱在于混淆了“血液中甲状腺激素总量”与“自身合成量”。注射外源激素后，总量虽升高，但内源合成被摧毁。备考时务必界定清楚研究对象是激素浓度还是分泌速率/合成速率。

2009-全国Ⅱ-02

  • 题目：阐述甲状旁腺素与甲状腺 C 细胞分泌的降钙素在血钙调节中的作用，判断关于血钙叙述的错误选项。
  • 思路：判定该过程为负反馈调节。血钙下降 $\rightarrow$ 甲状旁腺素增多 $\rightarrow$ 血钙上升；血钙上升 $\rightarrow$ 降钙素增多 $\rightarrow$ 血钙下降。
  • 步骤：
    • 提取题干信息：甲状旁腺素使血钙升，降钙素使血钙降。
    • 二者作用相拮抗，共同维持血钙稳态。当血钙浓度偏离正常值时，会引发相应的激素调节使血钙回归正常，这种抑制作用属于典型的负反馈。
    • 错误选项中常包含：误将血钙调节变更为正反馈，或混淆甲状旁腺与甲状腺 C 细胞的分泌产物。
  • 点评/变式：破题关键是对“血钙上升/下降”引发的后续效应进行箭头推导。只要推导出激素效应最终逆转了初始变化，即可确认为负反馈。注意区分“甲状腺 C 细胞”与“甲状旁腺”两个解剖位置相邻但功能不同的结构。
