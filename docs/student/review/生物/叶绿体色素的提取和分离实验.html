叶绿体色素的提取和分离实验

考点叶绿体色素的提取和分离实验权重6真题数1学科生物父主题实验

考点定位

  • 父主题：实验
  • 权重 weight：6
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 提取原理：叶绿体色素为脂溶性物质，能溶解于无水乙醇、丙酮等有机溶剂。常用无水乙醇提取色素。
  • 分离原理：纸层析法。不同色素在层析液（如石油醚∶丙酮∶苯混合液）中溶解度不同，溶解度高的随层析液在滤纸条上扩散快，反之则慢，从而实现分离。
  • 实验关键试剂与材料
  • 无水乙醇：溶解、提取色素。
  • 石英砂（$\ce{SiO2}$）：研磨充分，破坏细胞结构。
  • 碳酸钙（$\ce{CaCO3}$）：防止研磨时液泡内有机酸破坏叶绿素。
  • 层析液：分离色素，不可没及滤液细线。
  • 四种色素与滤纸条分布（自上而下）
    | 色素 | 颜色 | 溶解度 | 扩散速度 |
    |---|---|---|---|
    | 胡萝卜素 | 橙黄色 | 最高 | 最快 |
    | 叶黄素 | 黄色 | 较高 | 较快 |
    | 叶绿素 a | 蓝绿色 | 较低 | 较慢 |
    | 叶绿素 b | 黄绿色 | 最低 | 最慢 |
  • 色素吸收光谱
  • 叶绿素 a 和叶绿素 b：主要吸收红光和蓝紫光。
  • 胡萝卜素和叶黄素：主要吸收蓝紫光。
  • 所有光合色素均不吸收红外光和紫外光，仅吸收可见光中的特定波段。
  • 影响叶绿素合成的因素
  • 光：光是叶绿素合成的必要条件。黑暗下幼苗因无法合成叶绿素，原有类胡萝卜素颜色显现而呈黄色。
  • 矿质元素：镁（$\ce{Mg}$）是叶绿素的必需组成元素，根从土壤中吸收；氮（$\ce{N}$）等也参与构成。

解题方法与套路

  1. 提取与分离试剂不混淆：提取用有机溶剂（无水乙醇），分离用层析液。遇“用层析液提取色素”等说法直接判错。
  2. 色素分布顺序判定：记住“胡黄 a b”自上而下，溶解度、扩散速度与位置正相关。可联系“胡萝卜素跑最快，叶绿素 b 最慢”口诀。
  3. 吸收光谱定性判断：题干中出现“红外光”“紫外光”参与光合作用必错。正确表述为“红光和蓝紫光”。
  4. 实验操作正误辨析：
  5. 滤液细线触及层析液→色素溶于层析液，实验失败。
  6. 未加 $\ce{CaCO3}$ →叶绿素被破坏，色素带窄、颜色浅或缺失。
  7. 未加 $\ce{SiO2}$ →研磨不充分，色素提取量少。
  8. 滤液细线画得过粗→色素分离起点不均匀，色素带重叠。
  9. 针对现象的解释推理：如秋天叶片变黄——低温下叶绿素分解，类胡萝卜素稳定，故显示黄色；黑暗下黄化苗——缺少光照致叶绿素无法合成。

高频易错

  • 红外光、紫外光用于光合作用（❌）。色素只吸收可见光波段，植物无法利用红外和紫外光。2016 年全国卷Ⅱ 此题 C 选项即为此陷阱。
  • 色素在层析液中溶解度与扩散距离混淆：扩散距离长→溶解度高，而非相反。部分同学会误以为跑得快的溶解度低。
  • 黑暗中叶片变黄原因误判：误认为是类胡萝卜素大量合成，实际是叶绿素合成受阻，而类胡萝卜素一直存在且较稳定，所以呈现黄色。
  • 提取与分离试剂记反：提取需破细胞并溶解色素，用无水乙醇；分离需根据溶解度差异展开，用层析液。互用则无效果。
  • 研磨时不加 $\ce{CaCO3}$ 导致类胡萝卜素被破坏（错误）。$\ce{CaCO3}$ 保护的是叶绿素，类胡萝卜素相对稳定。
  • 滤纸条上最宽的色素带：通常为叶绿素 a（蓝绿色），不少同学错记成叶黄素或胡萝卜素。

代表题精讲

2016·新课标Ⅱ·04

题目（改编简述）：下列关于高等植物叶绿体中色素的叙述，错误选项为哪一项？四个选项分别涉及色素溶于有机溶剂、镁的来源、吸收光谱、黑暗下幼苗变黄原因。

思路：本题综合考察色素提取原理、矿质吸收、光合有效辐射及叶绿素合成条件。需逐项调用核心知识判定，尤其关注绝对化表述及光谱常识。

步骤
1. A 选项：色素能够溶解在有机溶剂乙醇中。提取实验正是利用此原理，用无水乙醇溶解色素 → 正确。
2. B 选项：构成叶绿素的镁可由根从土壤吸收。植物必需矿质元素的主要吸收器官为根，镁以 $\ce{Mg^{2+}}$ 形式被根系吸收后运输到地上部分参与叶绿素合成 → 正确。
3. C 选项：红外光和紫外光可被叶绿体色素吸收用于光合作用。已知光合色素只吸收可见光，尤其红光和蓝紫光，红外与紫外不被吸收 → 错误，即为答案。
4. D 选项：黑暗中幼苗叶片呈黄色是叶绿素合成受阻所致。光为叶绿素合成必要条件，黑暗下无法合成叶绿素，类胡萝卜素原有的颜色显现出来，呈黄色 → 正确。

点评/变式
- 点评：该题以“错误”设问，C 项极易因“红外紫外有能量可能被利用”的生活经验而误选，实则严格遵循教材色素吸收光谱。
- 变式预测：可改为考察“提取色素时加 $\ce{CaCO3}$ 的作用”“纸层析后色素带颜色及位置”等，需灵活迁移实验原理和色素特性。牢记：提取——溶解；分离——溶解度差异；可见光吸收——不含红外紫外；黄化——缺光阻叶绿素合成。
