呼吸作用

考点呼吸作用权重0真题数6学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：0
  • 真题数：6；年份跨度：2014–2022
  • 出现题位：选择1 选择2 选择6 选择7 选择9
  • 难度分布：易2 中4

知识精要

  • 有氧呼吸
  • 场所：细胞质基质（第一阶段）、线粒体基质（第二阶段）、线粒体内膜（第三阶段）。
  • 总反应式：$C_6H_{12}O_6 + 6H_2O + 6O_2 \xrightarrow{酶} 6CO_2 + 12H_2O + 能量$。
  • 能量变化：1 mol 葡萄糖彻底氧化分解共释放 2870 kJ 能量，其中 977.28 kJ 储存在 ATP 中，其余以热能散失。三个阶段均能产生 ATP，第三阶段产 ATP 最多。
  • ATP 的产生场所：细胞质基质、线粒体基质、线粒体内膜。
  • 无氧呼吸
  • 场所：细胞质基质。
  • 两种类型：
    • 产酒精：$C_6H_{12}O_6 \xrightarrow{酶} 2C_2H_5OH + 2CO_2 + 少量能量$（如酵母菌、多数植物器官）。
    • 产乳酸：$C_6H_{12}O_6 \xrightarrow{酶} 2C_3H_6O_3 + 少量能量$（如动物细胞、乳酸菌、马铃薯块茎、甜菜块根、玉米胚）。
  • 能量特点：第一阶段与有氧呼吸第一阶段完全相同，仅第一阶段释放少量能量。
  • 光合作用与呼吸作用的关系
  • 表观光合速率（净光合速率）= 真正光合速率（总光合速率）− 呼吸速率。
  • 补偿点：光合速率等于呼吸速率时，植物与外界无气体交换，密闭容器内 $CO_2$ 浓度保持相对稳定。
  • 白天有光时，叶肉细胞产生 ATP 的场所：细胞质基质、线粒体（基质与内膜）、叶绿体类囊体薄膜。
  • 呼吸作用的影响因素
  • 温度：影响呼吸酶活性，进而影响呼吸速率。
  • $O_2$ 浓度：有氧呼吸必需；低氧时无氧呼吸受抑制，高氧时有氧呼吸增强（对无氧呼吸有抑制作用）。
  • $CO_2$ 浓度：过高会抑制呼吸作用。
  • 含水量：种子的呼吸速率随含水量升高而升高。

解题方法与套路

  1. 密闭容器气体变化分析：植物在密闭容器中，初期光合速率大于呼吸速率 → $CO_2$ 浓度下降；随后达到补偿点 → 光合速率等于呼吸速率 → $CO_2$ 浓度保持相对稳定。注意区分“表观光合”与“真正光合”，密闭容器内测得的 $CO_2$ 变化反映的是净光合速率。
  2. 表格/实验数据的自变量-因变量分析法
  3. 找自变量（表格列标题或实验处理条件，如温度、气体种类、光照距离）。
  4. 找因变量（实验测得的数值，如离子吸收量、颜色变化）。
  5. 比较相同自变量下不同组别的因变量差异，结合呼吸作用原理（主动运输消耗 ATP，ATP 来自细胞呼吸）得出有氧/温度与吸收速率的关系。
  6. 实验设计题的规范作答模板
  7. 取材、分组（随机均分为实验组和对照组）。
  8. 控制变量（实验组施加干旱处理，对照组正常条件，其余条件相同且适宜）。
  9. 检测指标（如测定夜晚液泡 pH）。
  10. 预期结果（实验组 pH 低于对照组，说明干旱诱导苹果酸积累，验证特殊 $CO_2$ 固定方式）。
  11. ATP 产生场所的判断口诀：动物无光合，植物分光暗。白天有光：细胞质基质 + 线粒体 + 叶绿体（类囊体薄膜）；夜晚无光：细胞质基质 + 线粒体。
  12. 特殊代谢途径的适应意义推理：干旱环境 → 气孔白天关闭减少蒸腾失水，晚上打开吸收 $CO_2$ 并储存为苹果酸 → 白天利用储存的 $CO_2$ 进行光合作用 → 既保水又保证光合正常进行。

高频易错

  • 光合速率与呼吸速率的比较：密闭容器中 $CO_2$ 降低表示“光合 > 呼吸”，不是“光合升高”或“呼吸降低”；稳定时“光合 = 呼吸”，而非呼吸速率保持稳定、光合降低。
  • “光合作用所需的 $CO_2$ 来源”遗漏细胞呼吸：干旱植物白天气孔关闭时，光合作用所需 $CO_2$ 不仅来自苹果酸脱羧，还包括细胞呼吸释放的 $CO_2$。
  • 剧烈运动时能量的直接来源：人体在剧烈运动时肌细胞可进行无氧呼吸产生乳酸，但 乳酸分解产生的能量并不直接供生理活动使用——乳酸需经肝脏重新转化为葡萄糖、再经有氧呼吸供能；直接能源始终是 ATP。真题曾在此处设误。
  • 主动运输与呼吸作用的关系：离子吸收是主动运输，需要 ATP 供能；ATP 来自细胞呼吸，因此氧气浓度（有氧/氮气）和温度（影响酶活性）均影响离子的主动吸收。误选“氮气中吸收不消耗 ATP”是典型错误。
  • ATP产生场所的遗漏：白天有光时，叶肉细胞进行光合作用（光反应在类囊体薄膜上产生 ATP）和呼吸作用（细胞质基质、线粒体均能产生 ATP），三个场所缺一不可；夜晚只进行呼吸作用。
  • 光合色素吸收光能是否需要酶：叶绿素吸收光能是物理过程，无需酶参与；但光反应中 ATP 的合成（将光能转化为化学能）需要 ATP 合成酶催化。两个概念不能混淆。

代表题精讲

2022-全国乙-02

题目：将生长正常的小麦置于密闭容器，适宜恒定温光下培养，初期 $CO_2$ 含量降低，之后保持相对稳定。实验现象解释正确的是（　　） 思路：密闭容器即与外无气体交换；容器中 $CO_2$ 下降表明植物光合作用消耗 $CO_2$ 的速率大于自身呼吸产生 $CO_2$ 的速率（真正光合 > 呼吸）；后续 $CO_2$ 稳定，说明光合速率与呼吸速率相等，达到补偿点，不再净吸收 $CO_2$。整个过程温度、光照恒定，不应推理为光合/呼吸速率自发升高或降低。 步骤 1. 排除 A：初期 $CO_2$ 降低是因为光合速率本身就大于呼吸速率，并非光合速率“逐渐升高”。 2. 排除 B：题干条件是“适宜且恒定”，无依据判断“光合速率和呼吸速率均降低”。 3. 排除 C：若初期“呼吸速率大于光合速率”，则 $CO_2$ 应升高而非降低，与题干矛盾。 4. 确认 D：初期光合速率大于呼吸速率 → 容器 $CO_2$ 降低；随着 $CO_2$ 浓度降低，光合速率受 $CO_2$ 限制而下降，最终与呼吸速率达到平衡，$CO_2$ 相对稳定。符合逻辑。 点评：光合-呼吸动态平衡是高频考点。抓住核心——密闭容器中气体变化直接反映“净光合”的正负与零点，培养条件的“恒定”已排除了环境变量引发的速率变化，唯一可变的是容器内 $CO_2$ 浓度本身作为暗反应的限制因子。变式练习：若改为光照强度逐渐增强，则对应光合速率逐渐升高的情境，A 选项可能正确。

2021-全国乙-07

题目：干旱地区植物甲晚上气孔开放吸收 $CO_2$ 并以苹果酸储存于液泡，白天气孔关闭，苹果酸脱羧释放 $CO_2$ 供光合作用。 （1）白天叶肉细胞产生 ATP 的场所有_。光合作用所需 $CO2$ 来源于苹果酸脱羧和__。 （2）气孔白天关闭、晚上打开的适应意义：既防止_，又保证_正常进行。 （3）请以 pH 为检测指标，设计实验验证该植物在干旱环境中的特殊 $CO_2$ 固定方式。 思路 - （1）抓住“白天”→ 有光 → 同时进行光合与呼吸 → 产 ATP 场所三者合一；“光合作用所需 $CO_2$”来源包括外源（气孔吸收）与内源（细胞呼吸），白天特殊代谢途径中另有苹果酸脱羧这一来源。 - （2）干旱的核心矛盾是保水与吸 $CO_2$ 的冲突；晚上温度低、蒸腾弱，打开气孔吸收 $CO_2$ 并储存，白天关闭气孔则减少蒸腾失水，同时可利用储存碳源维持光合作用。 - （3）验证实验需设对照组（正常环境）与实验组（干旱环境），检测储存于液泡的苹果酸引起的 pH 变化（苹果酸积累使液泡 pH 下降）。按照规范模板书写实验思路和预期结果。 步骤 - （1）细胞质基质、线粒体（线粒体基质和线粒体内膜）、叶绿体类囊体薄膜；细胞呼吸（或呼吸作用）释放的 $CO_2$。 - （2）蒸腾作用过强导致水分散失过多；光合作用。 - （3）实验思路：取生长状态相同的植物甲若干株随机均分为 A、B 两组；A 组在湿度适宜的正常环境中培养，B 组在干旱环境中培养，其他条件相同且适宜。一段时间后，分别检测两组植株夜晚同一时间液泡中的 pH，并求平均值。预期结果：A 组 pH 平均值高于 B 组（B 组因干旱诱导积累更多苹果酸，pH 显著较低）。 点评：此类题目考查光合、呼吸、蒸腾的协调与特殊代谢的进化适应。设计实验时务必注意：对照设置在于有无干旱胁迫，检测时机必须统一在“夜晚”以反映苹果酸的积累，检测指标（pH）需要明确取自液泡。变式：若将检测指标改为“黎明前叶片中有机酸（苹果酸）含量”，则预期结果相同——干旱组有机酸含量高于正常组。
