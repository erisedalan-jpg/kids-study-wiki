噬菌体

考点噬菌体权重12真题数2学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：12
  • 真题数：2；年份跨度：2017–2018
  • 出现题位：选择2 选择5
  • 难度分布：易1 中1

知识精要

  • 病毒核心特征：无细胞结构，由核酸（DNA或RNA）和蛋白质外壳构成；必须专一性寄生在活细胞内，利用宿主细胞的核糖体、原料、能量和酶系统完成增殖。
  • 噬菌体代表——T₂噬菌体：
  • 核酸类型：DNA病毒（双链DNA）。
  • 宿主：专门寄生大肠杆菌（不能寄生肺炎双球菌等其他细菌）。
  • 增殖过程：吸附→注入（仅DNA进入）→合成（模板：噬菌体DNA；原料、酶、能量：全部来自宿主）→组装→释放。
  • 其他常考病毒：
  • 烟草花叶病毒：RNA病毒，可从中提取到RNA。
  • HIV（人类免疫缺陷病毒）：RNA病毒，逆转录增殖，引起艾滋病（获得性免疫缺陷综合征）。
  • 同位素标记实验：
  • $^{32}\text{P}$标记DNA（因P是DNA特有组成元素，蛋白质一般不含P）；$^{35}\text{S}$标记蛋白质外壳（因S存在于蛋白质中，DNA不含S）。
  • 只能先用含同位素的培养基培养宿主细胞，再用标记后宿主细胞培养噬菌体，不能直接用培养基培养噬菌体。

解题方法与套路

  1. 先定类型后判宿主：看到“病毒”，立即区分是DNA病毒（如T₂噬菌体、噬菌体类多数）还是RNA病毒（如烟草花叶病毒、HIV、流感病毒）。同时回忆其专一宿主，如T₂噬菌体→大肠杆菌，HIV→T淋巴细胞。
  2. 代谢判断看场所：凡涉及“在病毒体内/颗粒内合成蛋白质/RNA/mRNA/进行代谢”等，一律判错。病毒自身无核糖体等细胞器，不能独立合成任何大分子。
  3. 标记实验抓“来源”：子代噬菌体的核酸原料来自宿主细胞吸收的物质（培养基中的同位素需先进入宿主，再进入子代DNA）。因此，$^{32}\text{P}$标记的培养基最终可使子代噬菌体核酸带标记，而蛋白质外壳的原料也来自宿主，$^{35}\text{S}$标记的蛋白质外壳不会传给子代DNA。
  4. 选项对比找矛盾：当选项中出现“可感染肺炎双球菌”“在肺炎双球菌中复制”等与常见宿主（大肠杆菌）不符的描述，即与专一性矛盾，迅速判定为错误。

高频易错

  • 混淆宿主：T₂噬菌体只能侵染大肠杆菌，不能在肺炎双球菌、酵母菌或其他真核细胞中增殖。
  • 合成场所错位：误认为“病毒可以在自身颗粒内利用自身物质合成mRNA和蛋白质”，实际上病毒所有合成活动均发生在宿主细胞内部，利用了宿主的核糖体和原料。
  • 核酸类型张冠李戴：错将HIV（RNA病毒）与T₂噬菌体（DNA病毒）的核酸类型和增殖过程等同。HIV通过逆转录整合，T₂噬菌体直接DNA复制转录。
  • 标记方法错误：误以为可直接用含$^{32}\text{P}$的培养基培养噬菌体进行标记，实际上必须通过培养宿主细胞再转接噬菌体的间接标记法。
  • 烟草花叶病毒成分误判：虽含RNA，但不能反推它含有DNA，或认为它属于DNA病毒。

代表题精讲

【代表题】2018-新课标Ⅱ-05

题目：判断下列关于病毒叙述中的错误选项（涉及烟草花叶病毒、T₂噬菌体、HIV）。 思路：逐一调用三种病毒的核心属性：核酸类型、宿主特异性与致病性，搜寻描述与事实不符的选项。 步骤： 1. 烟草花叶病毒是RNA病毒，RNA可从病毒颗粒中提取 → A正确。 2. T₂噬菌体是专性寄生于大肠杆菌的DNA病毒，肺炎双球菌细胞表面无对应受体，不能吸附更不会裂解 → B错误。 3. HIV攻击人体T淋巴细胞，导致免疫缺陷综合征（艾滋病） → C正确。 点评/变式：此题陷阱在于“噬菌体可感染一切细菌”的错误观念。变式常考查“噬菌体与HIV的核酸类型是否相同”“两者增殖是否需要逆转录”，核心就是先判类型再说过程。

【代表题】2017-新课标Ⅱ-02

题目：结合T₂噬菌体侵染大肠杆菌实验，判断关于该噬菌体叙述正确的选项。 思路：回忆噬菌体结构（DNA+蛋白质外壳）和增殖全过程，并复盘同位素标记实验的设计逻辑。 步骤： 1. A项称可在肺炎双球菌中复制 → 专一宿主是大肠杆菌，无法增殖 → 错误。 2. B项称病毒颗粒内可合成mRNA和蛋白质 → 颗粒内无核糖体、无能量代谢，合成过程在宿主细胞内 → 错误。 3. C项，$^{32}\text{P}$经宿主摄取，可出现在子代噬菌体的核酸（DNA）中 → 原料来自宿主吸收的磷酸盐，合成时进入DNA链，符合实验事实 → 正确。 4. D项，HIV核酸为RNA（逆转录增殖），T₂噬菌体核酸为DNA（直接复制转录增殖） → 类型与过程均不同 → 错误。 点评/变式：代表题集中考查专一寄生与病毒合成原料来源。复习变式可深挖：“若用$^{35}\text{S}$标记噬菌体侵染未标记大肠杆菌，子代哪里出放射性？”答：仅亲代蛋白质外壳带有，子代无。此即“DNA是遗传物质”实验的关键逻辑。
