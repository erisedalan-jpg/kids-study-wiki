噬菌体侵染实验

考点噬菌体侵染实验权重12真题数2学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：12
  • 真题数：2；年份跨度：2013–2017
  • 出现题位：选择3 选择5
  • 难度分布：易2

知识精要

  • 实验材料：T2噬菌体（仅由蛋白质外壳和内部的DNA分子组成）与大肠杆菌。噬菌体具有严格的宿主专一性，只能侵染大肠杆菌，不能侵染其他细菌（如肺炎双球菌）。
  • 实验方法：放射性同位素标记法。用 $^{35}S$ 标记噬菌体的蛋白质外壳（因为S仅存在于蛋白质中），用 $^{32}P$ 标记噬菌体的DNA（因为P几乎仅存在于DNA中）。
  • 核心设计思路：设法将DNA和蛋白质分开，单独地、直接地观察它们在遗传中的作用，遵循单一变量原则和对照原则。
  • 关键步骤与现象分析：
    • 侵染与吸附：噬菌体先吸附在大肠杆菌表面，仅将DNA注入细菌细胞内，蛋白质外壳留在外面。
    • 搅拌与离心：
      • 搅拌：使吸附在细菌表面的噬菌体蛋白质外壳脱落。
      • 离心：让比重较大的细菌（含被注入的DNA）沉淀到管底（沉淀物），而比重较轻的噬菌体蛋白质外壳及未吸附的噬菌体则悬浮在上清液中。
    • 放射性检测：
      • $^{35}S$ 标记组：放射性主要出现在上清液中，沉淀物放射性很低。
      • $^{32}P$ 标记组：放射性主要出现在沉淀物中，上清液放射性很低。
  • 实验结论：DNA是遗传物质，蛋白质不是遗传物质。这有力地证明了DNA在亲代与子代之间具有连续性，能够指导蛋白质的合成。

解题方法与套路

  1. 明确实验目的与结论的对应关系：熟记证明DNA是遗传物质的经典实验只有两个——肺炎双球菌转化实验和T2噬菌体侵染细菌实验。排除其他实验如孟德尔、摩尔根的实验，它们分别证明了基因的分离/自由组合定律和基因位于染色体上。
  2. 把握实验材料的专一性：解题时若出现“T2噬菌体侵染肺炎双球菌”等说法，立即判断为错误，因为其宿主只能是大肠杆菌。
  3. 紧扣实验设计的核心思想：看到“设法分离DNA和蛋白质”或“单独直接观察”的表述，应立刻联想到这两个实验。
  4. 精准分析同位素标记去向：
    • 程序性判断标记组别：看到 $^{35}S$，锁定蛋白质；看到 $^{32}P$，锁定DNA。
    • 分步推导：注入细菌内部的是DNA，留在外部的是蛋白质外壳。离心后，细菌在沉淀物，外壳在上清液。
    • 得出放射性分布：标记外壳的 $^{35}S$ 主要在上清液；标记DNA的 $^{32}P$ 主要在沉淀物。
    • 若出现沉淀物中也有少量 $^{35}S$ 或上清液中也出现少量 $^{32}P$，通常归因于搅拌不充分（外壳未完全脱落）或培养时间过短/过长（部分子代噬菌体释放）导致的，这属异常现象，不改变实验的核心结论。

高频易错

  • 错将T2噬菌体的宿主混为肺炎双球菌：需强化记忆，T2噬菌体是专门寄生在大肠杆菌体内的病毒，不能在肺炎双球菌中复制。
  • 混淆经典实验的研究成果：
    • 孟德尔 → 基因的分离定律和自由组合定律。
    • 摩尔根 → 基因位于染色体上（伴性遗传）。
    • 格里菲思/艾弗里 → 肺炎双球菌转化实验，证明DNA是遗传物质。
    • 赫尔希和蔡斯 → T2噬菌体侵染实验，进一步确证DNA是遗传物质。
    • 威尔金斯和富兰克林的DNA X光衍射实验 → 为DNA双螺旋结构模型的建立提供了重要数据，但并未直接证明DNA是遗传物质。
  • 对“上清液”和“沉淀物”的成分理解不清：误以为离心后所有病毒成分都在一起。需明确，放射性分布的关键在于被标记物质是进入了细菌内部（沉淀）还是留在了外部（上清）。
  • 对上清液或沉淀物出现微量异常放射性的原因误判： $^{32}P$ 标记组上清液放射性偏高，常因培养时间过长，子代噬菌体将细菌裂解释放； $^{35}S$ 标记组沉淀物放射性偏高，常因搅拌不充分，带标记外壳仍黏附在细菌表面。

代表题精讲

代表题一（2017-新课标Ⅱ-03）

  • 题目：T2噬菌体侵染大肠杆菌并证明DNA是遗传物质，判断实验材料及操作的正误。
  • 思路：本题综合考察噬菌体侵染实验的全过程。解题关键是牢记T2噬菌体的专一宿主是大肠杆菌。
  • 步骤：A选项指出T2噬菌体可在肺炎双球菌中复制和增殖。根据知识，T2噬菌体只能寄生在大肠杆菌内，它是一种细菌病毒，具有严格的宿主特异性，不能跨物种侵染肺炎双球菌。故A项直接判断为错误。
  • 点评/变式：此题是基础判断题，直接考查寄生专一性。变式可设置为：“用放射性同位素标记的噬菌体去侵染无放射性的肺炎双球菌”，能得出同样结论吗？不能，因为噬菌体根本不会侵染肺炎双球菌。

代表题二（2013-新课标Ⅱ-05）

  • 题目：在生命科学史中，选出能证明“DNA是遗传物质”的实验组合。
  • 思路：此题属于经典实验的成果辨析，需将每个选项的实验结论与核心结论“DNA是遗传物质”进行精准匹配。
  • 步骤：
    1. 逐一分析每个实验的核心成果： ① 孟德尔实验 → 发现遗传因子（基因）的分离、自由组合规律。 ② 摩尔根实验 → 证明基因在染色体上呈线性排列。 ③ 肺炎双球菌转化实验 → 通过体内、体外转化，证明了DNA(转化因子)是遗传物质。 ④ T2噬菌体侵染实验 → 通过同位素示踪，确证DNA是遗传物质，蛋白质不是。 ⑤ DNA的X光衍射实验 → 为搭建DNA双螺旋结构模型提供物理数据，并未证明遗传物质是哪一种。
    2. 组合判断：只有③和④实验的结论直接且唯一指向“DNA是遗传物质”。
  • 点评/变式：本题的易错点是容易将③④与②⑤混淆。需明确证明“基因在染色体上”与证明“DNA是遗传物质”是遗传学史上两个紧密关联但结论不同的里程碑。变式问法：“为DNA双螺旋结构模型构建提供启示的实验是？”答：⑤。
