固氮作用

考点固氮作用权重7真题数1学科生物父主题生物与环境

考点定位

  • 父主题：生物与环境
  • 权重 weight：7
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：选择3
  • 难度分布：中1

知识精要

  • 生物固氮：指固氮微生物将大气中的 $N_2$ 还原成 $NH_3$ 的过程。固氮微生物包括共生固氮微生物（如根瘤菌）和自生固氮微生物（如圆褐固氮菌）。
  • 根瘤菌与豆科植物的共生关系
  • 根瘤菌侵入豆科植物根毛 → 形成根瘤。
  • 根瘤菌通过固氮酶将 $N_2$ 转化为含氮化合物，供给植物；植物通过光合作用提供有机物给根瘤菌。
  • 固氮酶对氧气极其敏感，需要在低氧条件下才能发挥活性。
  • 根瘤内的微环境：豆科植物产生豆血红蛋白，可结合并调节根瘤内部 $O_2$ 浓度，维持低氧环境，既满足根瘤菌呼吸产能，又保护固氮酶。
  • 影响根瘤菌固氮效率的因素
  • 氧气浓度：根瘤内低氧利于固氮，过高氧气抑制固氮酶活性。
  • 土壤含水量：长期淹水导致根系缺氧，呼吸受抑，能量供应不足 → 固氮量下降。
  • 氮素水平：土壤中化合氮丰富时，植物会减少对根瘤菌的依赖，甚至抑制根瘤形成和固氮。
  • 光照与光合作用：光合作用强 → 有机物供应充足 → 固氮效率高。
  • 根瘤菌的生活习性
  • 在土壤中可独立存活（自生状态），但不具有固氮能力；只有侵入豆科植物形成根瘤后，在共生条件下才表现固氮活性。
  • 大豆植株生长所需氮素：一部分来自根瘤菌固氮，一部分来自土壤中的氮（如铵盐、硝酸盐等），并非全部依赖根瘤菌。

解题方法与套路

  1. 辨别共生菌的生活阶段：遇到“离开植物能否存活”“能否固氮”类选项，先看是否混淆了“存活”与“固氮”。根瘤菌能独立存活于土壤中，但不能固氮；固氮活性仅在共生时出现。
  2. 分析环境因素对固氮的影响：重点关注与呼吸、氧气、能量供应相关的条件。
  3. 淹水、板结 → 根际缺氧 → 有氧呼吸受阻 → ATP 减少 → 固氮量降低。
  4. 干旱可能影响植物光合作用，间接导致有机物减少、固氮下降。
  5. 氮素来源辨析：涉及“某植物所需氮素均来自根瘤菌”的选项，一般为错。绝大多数植物会同时吸收土壤中已有的化合氮，尤其在幼苗期和衰老期。
  6. 概念精准定位：
  7. 固氮作用 ≠ 氨化作用（有机氮转化为 $NH_3$）≠ 硝化作用（$NH_3$ → $NO_3^-$）。
  8. 选项中出现混用术语时，直接排除。

高频易错

  • 误区：“根瘤菌离开植物根系不能存活” → 错误。根瘤菌可在土壤中腐生生存，只是没有固氮能力。
  • 误区：“土壤淹水有利于固氮” → 错误。淹水导致根部缺氧，细胞呼吸减弱，ATP 供应不足，固氮量反而减少（固氮过程耗能大）。
  • 误区：“大豆生长所需氮全部来自根瘤菌” → 错误。大豆还可从土壤吸收含氮离子，早期幼苗阶段主要靠土壤氮。
  • 误区：认为所有细菌固氮都需要与植物共生 → 自生固氮菌如圆褐固氮菌，能独立固氮。
  • 混淆根瘤菌与硝化细菌、反硝化细菌：根瘤菌是将 $N_2$ 固定为 $NH_3$；硝化细菌将 $NH_3$ 氧化为 $NO_3^-$；反硝化细菌将 $NO_3^-$ 还原为 $N_2$，正好相反。

代表题精讲

题目

（2008·全国Ⅱ，3）下列对根瘤菌的叙述，正确的是（　　） A．根瘤菌在植物根外也能固氮 B．根瘤菌离开植物根系不能存活 C．土壤淹水时，根瘤菌固氮量减少 D．大豆植株生长所需的氮都来自根瘤菌

思路 本题考查根瘤菌的共生固氮特性及环境因素的影响。逐项分析： - A：固氮需在根瘤内微氧环境，根外（无根瘤结构）不能固氮。 - B：根瘤菌可独立存活，但无固氮功能。 - C：淹水造成缺氧，呼吸受抑，能量少，固氮量下降，符合原理。 - D：大豆氮源有土壤化合氮和共生固氮两部分，并非“都来自”根瘤菌。

步骤 1. 依据“固氮酶需低氧且共生时才表达” → A 错。 2. 依据“根瘤菌腐生阶段可存活但不固氮” → B 错。 3. 依据“淹水→根部缺氧→呼吸减弱→ATP减少→固氮下降” → C 正确。 4. 依据“植物可吸收土壤氮肥” → D 错误。

点评/变式 - 关键：区分“能否存活”与“能否固氮”，以及环境胁迫通过呼吸途径影响共生固氮。 - 变式：若将“淹水”改为“土壤板结”或“长期阴雨”，同理因氧气不足导致固氮量下降。若改为“适当松土”则有利于固氮。 - 延伸：根瘤呈粉红色是由于豆血红蛋白的存在，其作用类似血红蛋白，调节氧分压保护固氮酶。
