基因定位

考点定位

  • 父主题：遗传与进化
  • 权重 weight：6
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 基因定位的基本思路：利用系谱图判断基因所在染色体（常染色体、X、Y或X、Y同源区段），通常先确定显隐性，再结合性别性状分布验证染色体位置。
  • 伴Y遗传规律：基因仅位于Y染色体上，无等位基因，遗传特点为“限雄遗传”——患者全部为男性，女性不表现该性状；父亲患病则所有儿子必患病，女儿全部正常。
  • 伴X隐性遗传规律：基因仅位于X染色体上，具有“母患子必患，女患父必患”的特点；男性患者多于女性；交叉遗传现象明显。
  • 基因型推断要点：
  • 伴X隐性遗传中，女性杂合子（携带者）表现正常，但可将致病基因传递给后代；男性正常为 $X^AY$，患病为 $X^aY$，无杂合子。
  • 系谱图中“一定是杂合子”的个体，其父母或子女的性状组合必然能推出其同时含有显、隐性基因；“可能是杂合子”的个体，则存在两种基因型可能，且外部表现无法直接排除其一。

解题方法与套路

  1. 判显隐——根据系谱特征：“无中生有为隐性”（父母正常、子女患病），或“有中生无为显性”（父母患病、子女正常）。该题由正常双亲生出患病子代为隐性。
  2. Y染色体假说法——假设基因仅位于Y染色体上，则只有男性患病，且父亲患病则儿子全部患病。从系谱中找出不符合此规律的个体（如患病男性的父亲正常，或患病男性有正常儿子，或某女性患病等），即可排除伴Y遗传。
  3. X染色体假说法——假设基因仅位于X染色体上（常为隐性），按伴X遗传规则“女病父必病、母病子必病”等进行逐一验证。若所有个体均符合，则不能排除伴X遗传。接着填充可能的基因型，特别注意女性的杂合子判断。
  4. 基因型正推反推——从已知性状逐步推导个体基因型，结合上下代表现型锁定必然基因型；对于“可能”情形的个体，列出所有相容的基因型组合，确认其杂合可能性。

高频易错

  • 遗传图识别中，容易忽略“仅位于Y染色体”的判定条件，错把男性患病直接视作伴Y遗传，而忘记检查女性患病或父子表现型冲突。
  • 伴X隐性分析时，将男性杂合子念为 $X^AY^a$ 等错误写法；男性仅有一条X染色体，对伴X基因只能是半合子（正常或患病）。
  • 对“一定是杂合子”与“可能是杂合子”区分不清：前者必须有确凿证据排除另一种纯合基因型；后者指个体性状与系谱信息无法唯一确定其为杂合子，但仍存在杂合可能。
  • 漏判系谱中由交叉遗传推断出的女性杂合子，如本人正常但其父患病或儿子患病，则该女性必为杂合子（携带者）。

代表题精讲

题目 山羊系谱图，深色表示某种性状的表现者，已知该性状由一对等位基因控制，不考虑染色体变异和基因突变。回答：（1）判断性状的显隐性；（2）假设基因仅位于Y染色体，指出第Ⅲ代表现型不符合该规律的个体；（3）假设基因仅位于X染色体，写出一定为杂合子的个体和可能为杂合子的个体。

思路 按“显隐判断→伴Y验证→伴X推断基因型”的顺序，利用系谱中世代和性别的表现型对应，逐步缩小基因位置的范围，再精确锁定基因型。

步骤 1. 判隐性：系谱中Ⅱ-1和Ⅱ-2均正常，生出深色性状的Ⅲ-1（患病），符合“无中生有”，故该性状为隐性。 2. 伴Y检验：若基因仅位于Y染色体，则所有深色个体必为男性，且深色男性的父亲和所有儿子都应为深色。观察系谱：
- Ⅲ-1深色男性，但其父亲Ⅱ-1正常，不符合；
- Ⅲ-3深色男性，但其父亲Ⅱ-2正常，不符合；
- Ⅲ-4深色男性，但其父亲Ⅱ-3正常，且Ⅲ-4的儿子Ⅳ-1正常，不符合。
因此Ⅲ-1、Ⅲ-3、Ⅲ-4均不符合伴Y遗传规律。 3. 伴X隐性分析：设正常基因为A，致病基因为a。系谱中深色女性Ⅱ-3基因型必为 $X^aX^a$，其父Ⅰ-2必患病（$X^aY$），但系谱显示Ⅰ-2正常，说明该性状不是伴X隐性？这里需结合（3）问直接假设基因仅位于X染色体上分析，即仍可假设致病基因为a。结合答案反推：该性状为伴X隐性，但Ⅰ-2正常却能生出患病女儿Ⅱ-3，则Ⅰ-2必须提供带致病基因的X染色体给女儿，而自己正常，说明Ⅰ-2为杂合子 $X^AX^a$（正常但携带者）。据此分析：
- Ⅰ-2：正常女性，有患病女儿Ⅱ-3（$X^aX^a$），故Ⅰ-2一定为 $X^AX^a$（杂合子）。
- Ⅱ-2：正常女性，其父Ⅰ-1正常，其母Ⅰ-2为杂合子，且其子Ⅲ-3患病（$X^aY$），故Ⅱ-2必为 $X^AX^a$（杂合子）。
- Ⅱ-4：正常女性，其父Ⅰ-2为杂合子男性（$X^AY$正常？不，Ⅰ-2不能是杂合子男性，男性只有 $X^AY$ 或 $X^aY$；若Ⅰ-2正常则为 $X^AY$，则不携带致病基因，不可能生出患病女儿Ⅱ-3。因此只有在伴X隐性遗传背景下，Ⅰ-2表现正常，那么她只能是女性。回过头来，系谱中Ⅰ-2是女性（罗马数字Ⅰ代表第一代，方框为男圆圈为女），确实Ⅰ-2是女性，所以Ⅰ-2为携带者杂合子。所以各女女性推断要结合性别。整理：Ⅰ-2（女）正常，生患病女Ⅱ-3（$X^aX^a$），则Ⅰ-2必为 $X^AX^a$；Ⅱ-2（女）正常，儿子Ⅲ-3患病，则Ⅱ-2必为 $X^AX^a$；Ⅱ-4（女）正常，父亲Ⅰ-2为 $X^AX^a$，母亲Ⅰ-1正常男性 $X^AY$，且儿子Ⅲ-4患病，故Ⅱ-4必为 $X^AX^a$。因此一定是杂合子的个体为Ⅰ-2、Ⅱ-2、Ⅱ-4。
- Ⅲ-2：正常女性，其父Ⅱ-1正常 $X^AY$，其母Ⅱ-2杂合子 $X^AX^a$，本人表现正常，基因型可以是 $X^AX^A$ 或 $X^AX^a$，故可能是杂合子。

点评/变式 本题覆盖基因定位的核心逻辑，由显隐性判断到伴Y排除，再到伴X基因型锁定。考生需熟练运用“系谱三看法”：一看显隐，二看Y染，三看X染。解答末问时，务必区分“一定”和“可能”，并注意个体性别对应的基因型写法，男性无杂合子。类似考题可变换为判断基因在X、Y同源区段或常染色体，但基本思路一致。
