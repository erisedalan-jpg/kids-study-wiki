基因工程载体

考点基因工程载体权重2真题数1学科生物父主题生物技术与工程

考点定位

  • 父主题：生物技术与工程
  • 权重 weight：2
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • 基因工程载体（运载体）
  • 作用：携带外源目的基因进入受体细胞，并在其中复制、表达。
  • 常见类型：质粒、λ噬菌体的衍生物、动植物病毒等。
  • 作为运载体必备条件：
    1. 具有一个至多个限制酶切割位点，供外源DNA插入；
    2. 具有标记基因（如抗生素抗性基因），便于筛选重组DNA分子；
    3. 能在宿主细胞中自我复制，或整合到染色体DNA上同步复制；
    4. 对受体细胞无害，且易从宿主细胞中分离。
  • 限制酶切割产生的末端类型：黏性末端和平末端。
  • 黏性末端：限制酶在识别序列的对称轴两侧进行切割，产生互补的单链突出末端，如EcoRⅠ切割产生5'-AATT-3'黏性末端。
  • 平末端：限制酶在识别序列的对称轴处进行切割，产生无突出的平齐末端。
  • DNA连接酶
  • E.coli DNA连接酶：只能连接双链DNA片段互补的黏性末端，不能连接平末端。
  • T4 DNA连接酶：既能连接黏性末端，又能连接平末端（平末端连接效率较低）。
  • 目的基因与载体相连的要求：目的基因片段和载体必须具有相同的末端（均为相同的黏性末端或均为平末端）。切割目的基因的另一限制酶必须能够产生与载体切割末端相同的末端（如同裂酶或同尾酶）。
  • 将目的基因导入受体细胞
  • 常采用质粒作为载体，转化大肠杆菌。
  • 未处理的大肠杆菌吸收外源DNA的能力极弱，需用$CaCl_2$处理细胞，使其成为易于吸收外源DNA的感受态细胞。
  • 其他相关技术
  • 反转录：以mRNA为模板，在反转录酶作用下合成互补DNA（cDNA）。
  • 体外大量扩增（获得大量反转录产物）常采用PCR（聚合酶链式反应）技术。

解题方法与套路

  1. 载体填空类题目：看到“除质粒外还有哪些运载体”，直接填“噬菌体”和“动植物病毒”。注意教材表述顺序，质粒最常用，噬菌体和动植物病毒也是常用载体。
  2. 末端类型书写：明确区分“黏性末端”与“平末端”。“黏”字常容易写错，注意偏旁。不要写成“粘性末端”。
  3. 限制酶的切割要求：当题目问可用另一种限制酶切割目的基因时，必须答出“切割产生的末端与载体切割产生的末端相同”。关键词是“末端相同”，而不是酶相同。
  4. DNA连接酶类型：区分来源和功能。E.coli DNA连接酶只能连黏性末端，T4 DNA连接酶二者皆可。若题目要求填两类，常用“E．coli DNA连接酶”和“T4 DNA连接酶”，注意大小写和点号。
  5. 反转录和PCR组合：看见“体外获得大量反转录产物”，自动联想PCR技术。模板为mRNA，产物为cDNA（互补DNA）。
  6. 转化受体细胞：问“为什么不能直接用未处理的大肠杆菌”，答出“未处理的大肠杆菌吸收质粒（外源DNA）的能力极弱”，重点在于“吸收能力极弱”或“不是感受态”。若要问处理方法，则答“CaCl₂处理”。

高频易错

  • 末端类型写错别字：“黏性末端”误写为“粘性末端”或“连性末端”。“平末端”误写为“平滑末端”。考试以教材为准。
  • E.coli DNA连接酶名称书写不规范：遗漏点号（E.coli），或把“E”写成小写“e”，或把“coli”写成“Coli”。应正确书写为“E．coli DNA连接酶”（或E.coli）。
  • 两种DNA连接酶功能混淆：容易记错E.coli DNA连接酶可连平末端。准确记忆：只有T4 DNA连接酶可连平末端。
  • 限制酶切割特点回答不准确：题目要求答出“另一种限制酶的特点”，有的考生只答“识别不同序列”而忽略“产生相同末端”。必须扣住“末端相同”。
  • 反转录模板和产物颠倒：易把模板答成DNA，产物答成mRNA。反转录方向是mRNA → cDNA（DNA）。PCR扩增的是DNA。
  • 未处理大肠杆菌不能做受体细胞的原因：只答“不能吸收”过于模糊，需要答出“吸收能力极弱”或“不能吸收外源DNA”，以呼应教材上“感受态细胞”概念。

代表题精讲

题目（2012年新课标卷, T12 节选）
根据基因工程的有关知识填空：限制酶切割DNA产生的片段末端类型有哪些；为使运载体与目的基因相连，另一种限制酶必须具有的特点；两种DNA连接酶的名称；反转录的模板、产物以及体外大量获取产物的技术；基因工程中除质粒外的两种运载体；不能直接用未处理的大肠杆菌作为受体细胞的原因。

思路
本题全部为基础填空，需准确回忆教材核心概念：①末端类型——黏性末端和平末端；②载体与目的基因连接要求末端一致，因此另一种限制酶切割产生的末端必须与EcoRⅠ切割产生的相同；③DNA连接酶——E．coli DNA连接酶和T4 DNA连接酶；④反转录体系——模板为mRNA（或RNA），产物为cDNA（或DNA），大量扩增用PCR技术；⑤其他载体——噬菌体、动植物病毒；⑥感受态细胞——未经处理的大肠杆菌吸收外源DNA的能力极弱。

步骤
1. 末端类型：直接填写“黏性末端”和“平末端”，注意“黏”字写法。
2. 另一种限制酶的特点：关键点是切割产生的DNA片段末端与EcoRⅠ切割产生的末端相同，答“切割产生的末端相同”即可满分。
3. DNA连接酶：写出两种来源不同的DNA连接酶——“E．coli DNA连接酶”和“T4 DNA连接酶”，字母大小写和点号不可错。
4. 反转录和扩增：模板——mRNA（或RNA）；产物——cDNA（或DNA）；大量获取的技术——PCR。这三个空要对应准确，顺序不可颠倒。
5. 其他运载体：在质粒之外补充“噬菌体”“动植物病毒”，二者均为教材列举，顺序不拘。
6. 受体细胞处理原因：答“未处理的大肠杆菌吸收质粒（外源DNA）的能力极弱”，点出“吸收能力极弱”这一核心，或“未形成感受态”亦可。

点评/变式
本题几乎涵盖了基因工程工具和基本步骤的填空易考点。备考时需将所有工具（限制酶、DNA连接酶、载体）连同其特性、典型实例背诵准确。变式问法：“检测目的基因是否导入受体细胞”常用DNA分子杂交技术；“初步筛选重组质粒”可用含抗生素的培养基，依靠标记基因。要能做到一空多题熟练迁移。
