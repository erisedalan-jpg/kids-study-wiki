知识精要

  • 常染色体基因来源推理：个体的等位基因一个来自父方，一个来自母方。若父母均为杂合子（如 $Aa$），则无法确定父母传给子代的显性基因具体来自祖父还是祖母（或外祖父还是外祖母），因为父母产生配子时等位基因随机分离。
  • 伴 X 染色体基因来源推理：
  • 男性：$X$ 染色体一定来自母亲，$Y$ 染色体一定来自父亲。
  • 女性：一条 $X$ 来自父亲，一条 $X$ 来自母亲。
  • 关键链条：父亲的 $X$ 必来自祖母（因祖父传给父亲的是 $Y$）；母亲的 $X$ 可来自外祖父或外祖母，无法唯一确定。
  • 适用条件：不考虑基因突变和染色体变异，仅依据遗传规律。

解题方法与套路

  1. 明确基因位置：先判断基因位于常染色体还是 $X$ 染色体，按题目要求或已知信息确定。
  2. 标出关键个体的基因型：根据表现型或题目假设，写出女孩、父母、祖辈的基因型（注意考虑可能存在的杂合情况）。
  3. 从子代到亲代逐级追溯：
  4. 若为常染色体：指出该女孩的一个显性基因来自父亲，另一个来自母亲；由于父母均为 $A_$（可能杂合），无法进一步区分来自哪个祖辈。
  5. 若为 $X$ 染色体：
    • 女孩的其中一个 $X^A$ 来自父亲 $\to$ 父亲的 $X^A$ 一定来自祖母（父亲的 $Y$ 来自祖父）。
    • 女孩的另一个 $X^A$ 来自母亲 $\to$ 母亲的 $X^A$ 可能来自外祖父，也可能来自外祖母，无法确定。
  6. 规范表述：用“必然来自”“无法确定”等术语，并简要给出判断依据。

高频易错

  • 混淆传递路径：误以为常染色体遗传中，父亲传给女儿的 $A$ 一定来自祖父——实际上也可能来自祖母，因为父亲的 $A$ 可以是其父母任一方遗传的。
  • 伴 X 遗传中父亲 X 的来源记反：认为父亲的 $X$ 来自祖父，正确应是：父亲（$X^AY$）的 $X^A$ 只能来自母亲（祖母），$Y$ 来自父亲（祖父）。
  • 外祖父与外祖母混淆：题目问“另一个 $X^A$ 来自外祖父还是外祖母”，容易不假思索写外祖母，实际上女孩母亲的 $X^A$ 既可来自外祖父（外祖父的 $X$ 全部传给女儿），也可来自外祖母（若外祖母为 $X^AX^a$），无法唯一确定。
  • 忽略条件限定：题目假设“女孩基因型为 $X^AX^A$ 或 $AA$”，其中 $AA$ 可能来自父母双方的 $A$，不可默认全来自一方。

代表题精讲

【代表题】2015-新课标Ⅱ-10

题目：某女孩基因型为 $X^AX^A$ 或 $AA$，祖辈四人的基因型分别为：祖父 $X^AY$ 或 $Aa$，祖母 $X^AX^a$ 或 $Aa$，外祖父 $X^AY$ 或 $Aa$，外祖母 $X^AX^a$ 或 $Aa$。不考虑变异，回答： （1）若基因在常染色体上，能否确定女孩的 2 个 $A$ 来自祖辈中的哪两人？为什么？ （2）若基因在 $X$ 染色体上，判断女孩的一个 $X^A$ 必然来自哪位祖辈，以及能否确定另一个 $X^A$ 的来源。

思路： - 第（1）问：常染色体遗传，女孩 $AA$ 的两个 $A$ 分别来自父亲和母亲。再由祖辈均为 $Aa$，推知父亲（$AA$ 或 $Aa$）的 $A$ 可能来自祖父或祖母，无法确定；母亲的 $A$ 同理无法确定。 - 第（2）问：$X$ 染色体遗传，女孩 $X^AX^A$ 的两个 $X^A$，一个来自父亲，一个来自母亲。父亲基因型为 $X^AY$，其 $X^A$ 一定来自祖母（因父亲从祖父获得 $Y$）。母亲基因型为 $X^AX^a$，其 $X^A$ 可能来自外祖父（外祖父的 $X^A$ 必然传给女儿）或外祖母（若外祖母提供 $X^A$），故无法确定。

步骤： 1. 第（1）问： - 女孩 $AA$ $\to$ 一个 $A$ 来自父亲，一个来自母亲。 - 祖辈均为 $Aa$ $\to$ 父亲可能为 $AA$ 或 $Aa$，他的 $A$ 基因可能是其父亲（祖父）的 $A$ 或母亲（祖母）的 $A$。 - 同理，母亲的 $A$ 也无法追溯至外祖父或外祖母中的特定一人。 - 因此：不能确定，理由如上。 2. 第（2）问： - 女孩 $X^AX^A$ $\to$ 其一 $X^A$ 来自父亲，其二来自母亲。 - 父亲 $X^AY$：$X^A$ 只能来自祖母（祖父给父亲的是 $Y$） $\to$ 女孩的这一 $X^A$ 必然来自祖母。 - 母亲 $X^AX^a$：母亲的 $X^A$ 可以来自外祖父（外祖父 $X^AY$ 一定传 $X^A$ 给女儿），也可以来自外祖母（外祖母 $X^AX^a$ 可能传 $X^A$） $\to$ 无法确定女孩另一个 $X^A$ 是来自外祖父还是外祖母。

点评/变式： - 本题核心考点是常染色体传递的“不确定性”与伴 X 传递中“男性 $X$ 定源于母”的确定性。解题时画出遗传关系简图，用箭头标注基因流向，不易出错。 - 变式：若祖母为 $X^aX^a$（隐性纯合），父亲为男性患者，则女孩从父亲获得的 $X$ 必然为祖母的 $X^a$，而非 $X^A$。灵活运用“父亲 XY 的 X 必来自祖母”这一铁律是解题关键。
