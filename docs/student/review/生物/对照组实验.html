对照组实验

考点对照组实验权重6真题数1学科生物父主题实验

考点定位

  • 父主题：实验
  • 权重 weight：6
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：选择7
  • 难度分布：易1

知识精要

  • 对照组实验原理：通过设置对照组（不做处理或做空白处理）排除无关变量干扰，确保实验结果由自变量引起。对照组是其他实验组的参照基线。
  • 基因与性状关系：基因通过控制蛋白质合成直接或间接影响性状。反义基因转录出的mRNA与靶基因mRNA互补配对，抑制翻译过程，从而特异性沉默靶基因。
  • 乙烯的生理功能：乙烯是植物激素，主要作用是促进果实成熟、器官脱落和衰老。乙烯释放量与果实成熟度呈正相关。
  • 实验变量分析：
  • 自变量：是否转入反义基因及反义基因的种类（A组无，B组反义X，C组反义Y）。
  • 因变量：乙烯释放量（反映乙烯含量和果实成熟度）。
  • 无关变量：植株生长条件、果实发育阶段、检测时间等需保持一致。
  • 结果推知基因功能：C组反义Y基因后乙烯释放量为0，说明Y基因是乙烯合成所必需的；B组反义X基因后乙烯释放量降低但未消失，说明X基因促进乙烯合成但不是唯一必需基因。A组含有正常X、Y基因，乙烯含量正常。

解题方法与套路

  1. 锁定对照组，明确参照标准
    找出哪一组是不做处理（或空载、野生型）的对照组，其结果为自然状态下的本底值。本题A组为非转基因植株，即为对照组。
  2. 比较实验组与对照组的差异，确定变量效应
    若实验组某指标低于对照组，说明被抑制的基因对该指标有正向作用；若等于零，则该基因可能是该过程的必需基因。B组乙烯降低但仍释放，X基因促进乙烯合成；C组乙烯为零，Y基因对乙烯合成为必需。
  3. 结合生物学背景知识进行逻辑推理
    将数据变化联系到激素功能：乙烯促进成熟，则含量高的A组成熟最早；乙烯含量低的果实耐储存，故B组储存时间长。
  4. 注意反义基因本身的存在
    转基因植株基因组中存在反义基因序列，因此描述“与乙烯含量有关的基因”时，需包括转入的反义基因。B组中既有原本的X基因、Y基因，还有外源的反义X基因（它通过转录反义RNA抑制X基因表达，但不产生功能蛋白）。

高频易错

  • 忽视反义基因作为“基因”的存在：题目问“B组果实中与乙烯含量有关的基因”，考生易只答X基因和Y基因，漏掉反义X基因。反义基因虽不编码功能蛋白，但它是转入的DNA片段，能通过表达调控影响乙烯含量，属于相关基因。
  • 混淆“抑制表达”与“基因缺失”：反义X基因并未敲除X基因，只是抑制X基因表达。B组果实仍含有正常的X基因，只是其表达被干扰，乙烯产量下降但未归零。
  • 不清楚乙烯含量与储存时间关系：乙烯含量越低，果实成熟越慢，采后常温储存时间越长。误以为35 d时B组乙烯低于A组，但未意识到此时A组已开始衰老，B组耐储。
  • 对照组判断错误：若将C组（乙烯为0）误认为对照组，会导致所有结论反向。只有A组是未转基因的自然状态，才是唯一对照组。

代表题精讲

题目：2015·新课标Ⅱ·7。为研究番茄X、Y基因对果实成熟的影响，用非转基因（A组）、反义X基因（B组）、反义Y基因（C组）植株进行实验，检测不同天数果实乙烯释放量（表略）。回答：（1）推测各组与乙烯含量有关的基因；（2）哪组成熟最早，原因；35 d采摘A、B组，常温储存时间较长的组。

思路：先确定对照组A，其数据反映正常成熟过程；再分析B、C与A的差异。C组乙烯始终为0，说明Y基因被抑制后乙烯完全无法合成，Y基因为必需基因。B组乙烯降低，X基因被抑制影响乙烯合成但未阻断，X基因为促进基因。反义基因本身是外源基因，也要计入相关基因。成熟早晚看乙烯峰值高低，储存看成熟度低。

步骤： 1. 读表，A组乙烯在35 d达峰值后下降，表明果实成熟；B组乙烯量始终低于A；C组始终为0。 2. （1）A组为正常植株，具有X、Y基因，故与乙烯含量有关的基因为X基因和Y基因。B组除X、Y外还转入反义X基因，它抑制X表达但不产生蛋白，仍属于相关基因，答案为X基因、Y基因和反义X基因。 3. （2）A组乙烯含量最高，乙烯促进果实成熟，故A组成熟最早。35 d时B组乙烯远低于A，成熟度低，常温下储存时间更长，答案为B组。

点评/变式：本题核心是理解反义基因技术中“基因”的定义包含转入的反义序列，以及通过比较实验组与对照组推断基因功能。变式：若增加“反义X+反义Y”双转基因组，乙烯释放量预测为0，可推知X和Y在乙烯合成途径中均为必需基因且Y不可替代；若给反义基因植株施加外源乙烯，成熟加快，可验证乙烯功能。
