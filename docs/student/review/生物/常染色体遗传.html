常染色体遗传

考点常染色体遗传权重11真题数2学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：11
  • 真题数：2；年份跨度：2015–2024
  • 出现题位：解答20 选择10
  • 难度分布：中2

知识精要

  • 常染色体遗传的核心特征：基因位于常染色体上（非同源区段），在体细胞中成对存在（分别来自父方和母方），传递时遵循孟德尔分离定律，与性别无关。
  • 等位基因来源追踪原则：一个个体的常染色体上的每一对等位基因，一个必然来自父亲，一个必然来自母亲。但来自父亲的这个等位基因可能是祖父的也可能是祖母的（两者等概率）；来自母亲的等位基因同样可能是外祖父或外祖母的。因此，仅凭常染色体基因型，通常无法确定某个显性基因具体来自哪一位祖辈（除非有特殊标记如 STR 多态性分型可区分，但就来源判断而言，概率上是不确定的）。
  • 短串联重复序列（STR）的遗传特点：位于常染色体上的 STR 就像一对等位基因，具有同源染色体，可通过父母双方传递，传递规律同常染色体基因。计算某个特定 STR 等位基因传递给后代的概率时，按等位基因随机分离计算：亲本具有某等位基因，传给子代的概率为 $1/2$；若涉及多代，需将每代的传递概率相乘。
  • 与 X 染色体遗传的对比：X 染色体非同源区段上的基因/STR，在男性个体中呈半合子状态，父亲的 X 染色体必定传给女儿，且父亲的 X 染色体必定来自祖母。因此，追踪 X 染色体上特定基因来源时具有确定性（来自父亲的 X 必定源自祖母），而常染色体上则无此确定性，这是关键的区分点。

解题方法与套路

  1. 明确基因位置：首先判断题目研究的基因是在常染色体上还是性染色体上。若为常染色体，按“每对等位基因分别来自父方、母方，且父/母方基因随机来源于上一代”处理；若为X染色体，须注意交叉遗传特点（父亲→女儿，母亲→儿子/女儿等）。
  2. 拆解传递路径：将需要追踪的个体到目标祖辈的传递过程分解为多个步骤（如Ⅲ-1←Ⅱ-1←Ⅰ代，或Ⅱ-4 直接对Ⅰ代等）。每一步的传递概率：常染色体等位基因传递率为 $1/2$，X 染色体上父亲传递给女儿为 $1$（必传），母亲传递给子女为 $1/2$（随机给一条X）。
  3. 连乘概率：若需求“两个人都得到同一个体的同一个基因”，需将各自的获取概率相乘，同时注意两个人可能共享相同的传递路径（如Ⅲ-1 和Ⅱ-1 都从Ⅰ代获取），分别计算再乘。
  4. 利用排除法或确定性判断：对于能否确定来源的问题型，常染色体遗传一般回答“不能”，原因在于祖辈的等位基因父母双方均可提供；X染色体遗传中父亲提供的X来源唯一（祖母），可确定；母亲提供的X来源不确定（外祖父或外祖母）。
  5. STR多态性题目的特殊处理：把每个 STR 看作一个“基因座位”，按基因传递规律计算相同STR片段传递的概率，本质与等位基因传递概率计算一致。

高频易错

  • 混淆常染色体与性染色体遗传规律：将常染色体上的基因错误地套用“父亲的基因必来自祖母”之类的规则，导致判断错误。
  • 概率相乘时遗漏中间个体的基因型可能性：如求Ⅲ-1 与Ⅱ-1 得到同一个 D18S51 的概率时，误以为直接是 $1/2\times1/2=1/4$，忽略了Ⅱ-1 的基因型也是经过随机传递的，必须将Ⅱ-1 得到该基因的概率（$1/2$）也乘进去，正确答案才是 $1/2\times1/2\times1/2=1/8$。
  • 将“来自同一个体”等同于“来自同一来源”：同一个 STR 片段可能在家族中多位成员携带，计算时必须区分是“同一个体（如Ⅰ代某一人）”还是“任意一个祖辈”，通常需要乘上目标具体个体的概率。
  • 误以为常染色体显性基因能确定祖辈来源：在“某女孩为 AA”之类的题目中，认为一个A必然来自祖父或祖母，另一个必然来自外祖父或外祖母，实际上由于父母双方均可能是杂合子，其提供的A有可能来自祖父或祖母（或外祖父或外祖母），无法具体指定到哪一个人，这是常染色体遗传的根本限制。
  • 计算 X 染色体上传递概率时，忽视母亲传给女儿是随机给一条X：母亲有两条X，传给女儿的特定一条X的概率是 $1/2$（除非有特征可识别），易错为直接必传。
