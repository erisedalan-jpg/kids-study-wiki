底物浓度

考点底物浓度权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 底物浓度对酶促反应速率的影响
  • 在酶量一定、酶活性正常的条件下，底物浓度较低时，反应速率随底物浓度增加而快速升高（近似一级反应）。
  • 随着底物浓度逐渐增大，反应速率增幅减缓，最终趋于恒定，达到最大反应速率 $v_{\text{max}}$（零级反应），此时酶分子被底物饱和。
  • 影响曲线特征的关键因素
  • 酶浓度：当底物过量时，反应速率与酶浓度成正比。
  • 酶活性：温度、pH 等条件改变酶活性时，$v_{\text{max}}$ 会相应改变；若酶完全失活，则无论底物浓度如何，反应速率均为 0，产物总量不再增加。
  • 适用前提：上述关系仅在酶未变性失活时成立。酶一旦失活，即使添加底物，亦无法引发反应。

解题方法与套路

  1. 明确酶促反应体系的状态
    审题时先判断酶是否仍具有活性（通过温度、pH 等条件）。若酶已失活，则底物浓度的改变不再影响产物生成。
  2. 区分“反应速率”与“产物总量”
  3. 在连续监测实验中，若酶不失活，适当增加底物可提高反应速率，可能使产物总量增加；
  4. 若酶已完全失活，反应立即停止，此时增加底物无法改变产物总量（如题中 60℃ 处理组）。
  5. 分析坐标曲线时的关键步骤
  6. 观察各曲线平台期的高低：正常情况下平台高度反映最终产物总量，由底物总量或酶活性决定。
  7. 当曲线出现早期停止上升（如 C 组在 t₂ 后不变），应推断酶失活，进而判断后续操作（加底物）无效。
  8. 牢记饱和效应：在酶活性正常且底物不足时，增加底物能提升速率；若底物已饱和，则速率不再随底物浓度升高而加快，但经过足够时间，产物总量会接近初始底物总量。

高频易错

  • 误认为增加底物总能使产物增加
    若酶高温变性失活，反应早已终止，补充底物无法“激活”反应，产物总量保持不变。
  • 混淆底物浓度与酶浓度/活性的影响
    题目常以温度实验为背景，考生容易忽略酶已失活这一隐含条件，直接套用“增加底物→提高速率”的结论而失分。
  • 未看清问题问的是“速率”还是“总量”
    有时增加底物虽对瞬时反应速率无影响（酶饱和），但产物总量可能随底物量增加而增大；需具体分析酶是否仍具备催化能力。
  • 忽略酶的化学本质与特性
    题目中常附带考查酶的化学本质（蛋白质或 RNA）及特性（高效性、专一性、作用条件温和等），注意与底物浓度无关，但仍需准确记忆。

代表题精讲

题目（2016·新课标Ⅱ·7 节选）

研究温度对酶活性的影响，设置 A（20℃）、B（40℃）、C（60℃）三组，测定不同反应时间的产物浓度。结果如图（略）。
（3）在时间 t₂ 时，向 C 组反应体系中增加 2 倍量的底物，其他条件不变，则在 t₃ 时，C 组产物总量如何变化？说明原因。

思路
- 先根据曲线推断 C 组在 t₂ 时酶的状态：由结果可知 C 组产物浓度在 t₂ 后不再增加，表明 60℃ 条件下酶已完全失活。
- 再分析增加底物的影响：酶已失去催化功能，化学反应无法继续进行，故产物总量必然不变。

步骤
1. 从坐标曲线确认 C 组在 t₂ 时刻进入平台期，不再生成产物 → 酶失活。
2. 结合酶的特性：高温使酶空间结构破坏，活性丧失且不可恢复。
3. 推理：失活的酶不能再催化底物转化，此时即使增加底物，反应也不会重启，因此 t₃ 时产物总量与 t₂ 时相同。
4. 规范作答：“不变，原因是 60℃ 条件下 t₂ 时酶已失活，即使增加底物，反应产物总量也不会增加”。

点评/变式
- 本题陷阱在于用温度实验考查底物浓度的影响，核心是判断酶是否仍具备活性。
- 变式延伸：若将 C 组改为低温处理（如 0℃）且酶活性受抑制但未变性，增加底物能否提高速率？答案取决于是否恢复适宜温度——低温仅抑制活性，酶未失活，一旦升温，增加底物可提高反应速率；但如果保持低温，受活性限制，速率增幅可能有限。
- 备考启示：面对“改变底物浓度”的提问，第一时间锁定酶是否正常工作，再结合饱和规律答题。
