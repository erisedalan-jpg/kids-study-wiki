性状分离比变式

考点性状分离比变式权重5真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：5
  • 真题数：1；年份跨度：2023–2023
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 核心本质：$9:6:1$ 是孟德尔经典两对相对性状杂交实验 $9:3:3:1$ 分离比的变式，其遗传基础仍是两对独立遗传的非等位基因。
  • 产生机制：属于“积加效应”或称“显性基因累加效应”。只有双显性基因（A_B_）同时存在时表现为一种性状（高秆），存在单显性基因（A_bb或 aaB_）表现为另一种性状（矮秆），双隐性基因（aabb）表现为第三种性状（极矮秆）。
  • 基因型-表型对应关系（以本题为例）：
    • 高秆：A_B_（共 $9$ 份，含1份纯合AABB）。
    • 矮秆：A_bb 和 aaB_（共 $6$ 份，含2份纯合AAbb、aaBB）。
    • 极矮秆：aabb（共 $1$ 份）。
  • 数学本质：表型比例为 $9: (3+3) : 1$，即双显:单显:双隐。

解题方法与套路

  • 步骤一：识别“变式”并还原母体比例 若题目给出的子代表型比例可换算成分母为 $16$（即总份数为 $16$）的比例，立即将其与 $9:3:3:1$ 进行对照。如 $9:6:1$ 意味着中间两组 $3$ 和 $3$ 合并，提示两对基因独立遗传。

  • 步骤二：反推基因型与表型对应关系 根据合并比例确定显隐性关系。在 $9:6:1$ 中，$16$ 份中单独的 $1$ 份必为隐性纯合（aabb），$9$ 份必为双显性（A_B_），剩余的 $6$ 份则为单显性（A_bb、aaB_）。

  • 步骤三：验证亲本与F1基因型 逆向推导亲本：若F1为双杂合（AaBb），则亲本通常为表现型相同的单显纯合子（aaBB × AAbb），这样才能保证F1同时含有A和B显性基因。

  • 步骤四：精准计算特定群体中的比例 注意分母的变化。计算“高秆中纯合子比例”时，分母是高秆总数（9），分子是高秆纯合子（AABB，1），结果为 $\frac{1}{9}$；计算“矮秆中纯合子比例”时，分母是矮秆总数（6），分子是矮秆纯合子（AAbb和aaBB，共2），结果为 $\frac{1}{3}$。这是高频失分点。

高频易错

  • 混淆比例分母：这是最常见错误。求“某表型中”的纯合/杂合比例，分母必须换成该表型个体总数，绝不能默认使用 $16$ 作分母。
    • 错例：F2矮秆中纯合子比例为 $\frac{2}{16}=\frac{1}{8}$。
    • 正解：F2矮秆中纯合子比例为 $\frac{2}{6}=\frac{1}{3}$。
  • 基因型统计错漏：计算矮秆基因型时，容易遗漏。单显性状包含A_bb和aaB_两类，每一类各有2种基因型（如A_bb包含AAbb、Aabb），合计 $2+2=4$ 种，不是 $2$ 种。
  • 审题不清致推理反向：题目要求选“错误”项时，常因前面选项信息正确、推导顺利而误把“错误”当作“正确”项选择。务必在审题时圈画“错误的”等关键限定词。

代表题精讲

2023·新课标·05

题目：某小组让2个矮秆突变体（亲本）杂交，F1全为高秆，F2中高秆:矮秆:极矮秆=9:6:1。用A、B表示显性基因，相关推测错误的是（ ）

思路： 1. 判模型：$9:6:1$ 总和为 $16$，是 $9:3:3:1$ 的变式，表明两对等位基因位于非同源染色体上，遵循自由组合定律。 2. 定对应：$9$份（A_B_）为高秆，$1$份（aabb）为极矮秆，中间 $6$份（A_bb、aaB_）为矮秆。 3. 推亲本：F1为AaBb（高秆）自交得F2，说明双亲矮秆应为纯合单显类型，即aaBB和AAbb。 4. 算比率：逐项计算F2各表型内纯合子比例，重点区分分母基数。

步骤： - 选项A（亲本与F1基因型）：根据 $9:6:1$ 反推，双亲必为AAbb和aaBB，F1必为AaBb。推测正确。 - 选项B（F2矮秆基因型种类）：矮秆即A_bb和aaB_。A_bb有AAbb、Aabb；aaB_有aaBB、aaBb。合计4种。推测正确。 - 选项C（极端表型基因型）：根据9:6:1定义，A_B_为高秆，故AABB为高秆；aabb为极矮秆。推测正确。 - 选项D（特定群体纯合子比例计算）： - F2矮秆共占总体的 $\frac{6}{16}$，其中纯合子为AAbb和aaBB，占总体的 $\frac{2}{16}$。所以，矮秆中纯合子比例 $= \frac{2/16}{6/16} = \frac{1}{3}$。原选项说 $1/2$，错误。 - F2高秆共占总体的 $\frac{9}{16}$，其中纯合子AABB占总体的 $\frac{1}{16}$。所以，高秆中纯合子比例 $= \frac{1/16}{9/16} = \frac{1}{9}$。原选项说 $1/16$，错误。 - 结论：D项两处计算均错，故D为错误选项。

点评/变式： - 核心点评：本题全面考查基因互作中“积加效应”的比例分析，特别是对“在某种表型个体中”进行概率计算的严谨性。选项D是极其经典的设误点，直接使用总体比例来代替特定群体比例。 - 变式拓展：基因互作还有多种变式，如 $9:7$（双显为一种性状，其余合并为另一种）、$9:3:4$（隐性上位）、$12:3:1$（显性上位）、$15:1$（重叠作用）等。解所有变式题的核心思想完全一致：先确定比例总和是否为 $16$ 或 $16$ 的倍数，再对标准 $9:3:3:1$ 进行合理合并与拆分，最后确定基因型与表型的映射关系。
