抗利尿激素

考点抗利尿激素权重0真题数3学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：0
  • 真题数：3；年份跨度：2012–2024
  • 出现题位：选择3 选择4 选择11
  • 难度分布：易3

知识精要

  • 抗利尿激素（ADH）：由下丘脑视上核和室旁核的神经细胞合成，经下丘脑–垂体束运输至垂体后叶（神经垂体）贮存并释放入血。
  • 生理作用：增强肾小管（近曲小管后的各段）和集合管对水的通透性，促进水的重吸收，使尿量减少，血浆渗透压降低，体液容量恢复。
  • 分泌调节：
  • 主要刺激：血浆渗透压（尤其是晶体渗透压）升高 → 下丘脑渗透压感受器兴奋 → ADH分泌增加。
  • 血容量减少（如大失血）→ 心房容积感受器传入冲动减少 → 刺激ADH分泌。
  • 其他因素：动脉血压下降、疼痛、焦虑、剧烈运动等可促进分泌；酒精抑制分泌。
  • 相关激素对比：
  • 醛固酮：由肾上腺皮质球状带分泌，受肾素–血管紧张素–醛固酮系统（RAAS） 及血K⁺、血Na⁺浓度调节，促进肾远曲小管和集合管保Na⁺排K⁺，同时促进水的被动重吸收。其分泌也受下丘脑–垂体–肾上腺皮质轴调控（ACTH促进）。
  • 甲状腺激素/性激素等属于轴调控，肾上腺皮质此轴不直接主控醛固酮的应急分泌，但长期调节有关。
  • 水平衡综合调节：失水过多（如长时间未饮水）→ 血浆渗透压↑ → 渗透压感受器兴奋 → 下丘脑（渴觉中枢）→ 产生渴觉，主动饮水；同时下丘脑神经细胞合成ADH↑ → 垂体后叶释放ADH↑ → 肾重吸收水↑ → 尿量↓ → 渗透压回落。此调节为负反馈。
  • 利尿剂治疗机制：部分利尿剂（如袢利尿剂、噻嗪类）抑制Na⁺/Cl⁻重吸收，减少水的被动重吸收，产生利尿作用；临床可用于水肿性疾病。用药时常需关注电解质和饮食配合。

解题方法与套路

  1. 抓准“变化方向”：题干涉及脱水、水肿或激素水平变化时，先确定血浆渗透压是升高还是降低，再推断ADH、醛固酮的预期变化（渗透压↑ → ADH↑，渗透压↓ → ADH↓）。注意抗利尿激素变化是原因还是结果。
  2. 区分激素作用的结果：抗利尿激素升高 → 水重吸收↑ → 尿量↓、血浆渗透压↓（稀释体液）；醛固酮升高 → 保Na⁺排K⁺ ↑ → 水被动重吸收↑ → 尿量↓、血容量↑。切忌误判为ADH升高导致渗透压升高（那是不足或抵抗的结果，生理性反馈前因是渗透压升高）。
  3. 辨析调节轴的归属：肾上腺皮质各层激素调节轴不同——糖皮质激素受下丘脑–垂体–肾上腺皮质轴，性激素也属此轴；醛固酮主要依赖RAAS和血钾，但题干提及“下丘脑–垂体–肾上腺皮质轴”调控可能在广义上包括，如急性应激时ACTH少量促进分泌，必须结合题目选项判断。常考题设置迷惑选项，根据真题语境谨慎选择。
  4. 联系临床与生活化情景：如“利尿剂治疗+低盐饮食”逻辑：利尿剂排水利尿，阻止水肿；低盐饮食减少钠摄入，防止水钠潴留，两者协同。分析此种组合方案的合理性。
  5. 选择题排除法：找明显违背生理原理的选项，比如脱水时血浆渗透压降低、重吸收减弱等；再处理模棱两可的轴调控项，结合教材定论。

高频易错

  • 错把抗利尿激素作用结果当原因：题目常设“抗利尿激素升高使细胞外液渗透压升高”这类陷阱。实际上，ADH分泌增加是渗透压升高的结果，它的作用是让渗透压回降，所以ADH升高会使渗透压降低。
  • 混淆醛固酮的调节轴：部分考生认为醛固酮不受下丘脑–垂体调控，但其实在应激状态下，ACTH可促进其分泌，题目表述“可受下丘脑–垂体–肾上腺皮质轴调控”要结合教材判断。真题中类似选项可能设置为正确。
  • 忽略利尿剂治疗时的饮食建议：使用利尿剂增加排尿时，若继续高盐饮食，容易抵消药效，加重钠水潴留，所以应保持低盐饮食。误选“高盐”或“无需控盐”的选项。
  • 水平衡调节中各结构作用混淆：感受器（下丘脑渗透压感受器）→ 效应器（垂体释放激素、大脑皮层产生渴觉）→ 靶器官（肾小管集合管）。脱水时下丘脑渗透压感受器受刺激增强，并非减弱。
  • 只记ADH促进保水，不记其对渗透压的影响：单纯记“保水”而忘记保水后渗透压下降，导致错误判断渗透压走向。

代表题精讲

代表题1：2024-辽宁-11

题目：梅尼埃病伴内耳淋巴水肿，检测血清抗利尿激素和醛固酮浓度均高于正常，临床上用利尿剂治疗。问错误叙述：A.内耳听觉感受细胞生存的内环境稳态失衡影响听力；B.发作期抗利尿激素水平升高使细胞外液渗透压升高；C.醛固酮的分泌可受下丘脑–垂体–肾上腺皮质轴调控；D.急性发作期使用利尿剂治疗同时应保持低盐饮食。
思路：需逐项判断正误。内耳淋巴液属于内环境，稳态失衡自然影响听觉感受器。抗利尿激素升高促进水重吸收，应使细胞外液渗透压降低，B项因果倒置、结论错误，故为答案。醛固酮调节中确有部分ACTH调控，C项表述“可受”通常是正确的。利尿剂促排水利尿，配合低盐饮食防钠水潴留，D项合理。
步骤：①A判断：内耳听觉感受细胞（耳蜗毛细胞）生活在淋巴液（内环境）中，水肿导致稳态失衡，影响听力，正确。②B判断：抗利尿激素分泌增加 → 肾重吸收水↑ → 血液稀释 → 细胞外液渗透压下降。题干中急性发作组抗利尿激素浓度升高24.93 vs 19.83，引发渗透压下降，而非升高，故B错。③C判断：肾上腺皮质分泌醛固酮受多重调节，下丘脑–垂体–肾上腺皮质轴（CRH-ACTH）对其有允许作用，表述正确。④D判断：利尿剂利尿消退水肿，低盐饮食可减少体内钠水量，协同治疗，正确。故选B。
点评/变式：此题为多表型病例分析，注意抗利尿激素升高与渗透压变化间的逻辑关系，是高频失分点。变式可考醛固酮增多症、尿崩症等。

代表题2：2019-新课标Ⅱ-04

题目：当人体失水过多时，不会发生的生理变化是
A．血浆渗透压升高
B．产生渴感
C．血液中的抗利尿激素含量升高
D．肾小管对水的重吸收降低
思路：失水过多时，体液减少、渗透压升高，会引发一系列保水反应。找不会发生的一项，即与保水反应相悖的选项。
步骤：①确定失水后果：细胞外液丧失水分 → 血浆渗透压升高（A成立）。②渗透压升高刺激下丘脑渗透压感受器，传到大脑皮层产生渴觉（B成立）。③同样刺激使下丘脑合成、垂体释放抗利尿激素增加（C成立）。④抗利尿激素增加作用于肾小管和集合管，增强对水的重吸收，使尿量减少，而非降低重吸收，因此D项不会发生，且是错误说法，选D。
点评/变式：简单的水平衡调节正反判断，抓住保水机制链条的终末效应。变式可改为“失水过多时直接导致的生理反应”，需注意“不会发生”与“会发生”的转换。

代表题3：2012-新课标-03

题目：哺乳动物因长时间未饮水导致机体脱水时，会发生的生理现象是
A．血浆渗透压降低
B．抗利尿激素分泌增加
C．下丘脑渗透压感受器受到的刺激减弱
D．肾小管和集合管对水的重吸收作用减弱
思路：脱水时各项保水调节被启动，找出符合实际生理变化的选项。
步骤：①脱水 → 体液减少，血浆渗透压升高，A降低错误。②渗透压升高刺激下丘脑渗透压感受器，使其兴奋增强，传入信号增多，C“刺激减弱”错误。③感受器兴奋导致下丘脑合成ADH增加，垂体释放入血，B抗利尿激素分泌增加正确。④ADH增加使肾小管、集合管对水通透性加大，重吸收普遍增强，D“重吸收作用减弱”错误。因此正确选项为B。
点评/变式：此题几乎全面考查脱水后的生理链，若混淆ADH作用结果极易误选。变式可与低钠血症或水利尿情况对比出题。
