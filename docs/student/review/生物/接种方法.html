接种方法

  • 父主题：生物技术与工程

  • 出现题位：选择11

知识精要

  1. 微生物接种的核心目的：将微生物分散成单个细胞，使其在固体培养基表面繁殖形成由单个细胞产生的菌落，从而获得纯培养物。
  2. 常用接种方法：
    • 平板划线法：通过接种环在琼脂固体培养基表面连续划线的操作，将聚集的菌种逐步稀释分散到培养基的表面。最终可在末端获得单个菌落。适用于分离纯种，但不能用于计数。
    • 稀释涂布平板法：将菌液进行一系列梯度稀释后，取一定量稀释菌液涂布到固体培养基表面，培养后各菌落由单个细菌繁殖而来。既能分离纯种，也能用于微生物计数。
    • 涂布法（或称均匀涂布法）：用涂布器将菌液均匀涂抹于整个平板表面，经培养后可观察到细菌均匀生长、布满平板。常用于观察菌体特征或进行药敏试验（如本题所述），不用于分离单个菌落。
  3. 药敏试验原理：
    • 含有抗生素的纸片置于已接种待测菌的平板上培养，若该菌对抗生素敏感，则抗生素在纸片周围扩散形成的浓度会抑制细菌生长，形成透明圈（抑菌圈）。
    • 若为耐药菌，则不会出现透明圈，或透明圈内仍有耐药性突变的菌落生长。
    • 透明圈的大小直接反映了该菌对相应抗生素的敏感性程度（透明圈越大，敏感性越强）。临床应选择产生最大透明圈的抗生素进行治疗。

解题方法与套路

  1. 根据实验目的筛选接种方法：
    • 目的为“获取菌落”或“分离纯化”：答案首选平板划线法或稀释涂布平板法。两者均可，需结合上下文确认唯一答案或择一作答。
    • 目的为“均匀生长”或“布满平板”：答案必须是涂布法（或稀释涂布的后续涂布操作）。注意区分“分离菌落用的平板划线/稀释涂布”与“用于铺满平板观察现象的涂布”。
  2. 药敏试验（透明圈）因果对应法：
    • 有透明圈 → 细菌被抑制 → 该抗生素有效（敏感）。
    • 无透明圈 → 细菌未被抑制 → 该抗生素无效（不敏感）。
    • 透明圈大或小 → 抑菌强度高或低 → 敏感性的强弱。
    • 透明圈内有菌落（排除污染） → 突变菌株不受该抗生素抑制 → 耐药菌。
  3. 最优选择推断：
    • 在临床应用中，应选择抑菌圈最大（即最敏感）的抗生素，以达到最佳抗菌效果。

高频易错

  1. 概念混淆：平板划线 vs. 涂布法：
    • 失分点：题目要求“均匀生长、布满平板”，误填“平板划线法”或“稀释涂布平板法”。
    • 避坑：“均匀生长、布满平板”描述的是菌落连成一片的无缝生长状态，必须使用涂布法。平板划线得到的是分散的、阶梯分布的蘑菇状菌落，“稀释涂布法”虽然操作叫“涂布”，但其名称本身强调的是“稀释”以获得单菌落，而本题第二空直接指向使菌液均匀铺满的纯“涂布”操作。
  2. 混淆“不敏感”与“耐药”：
    • 失分点：看到无透明圈，直接填“耐药”。
    • 避坑：
      • 无透明圈 → 细菌正常生长，说明抗生素对该菌无效，应填不敏感。
      • 透明圈中出现单个菌落 → 大部分菌被抑制，少数突变者存活繁殖，这叫耐药菌。
    • 结论：“不敏感”针对的是菌种整体特性；“耐药”针对的是群体中出现的极少数突变个体。
  3. 选错最优抗生素：
    • 失分点：错误认为出现耐药菌就放弃选择，或错选其他抗生素。
    • 避坑：只要该致病菌对某个抗生素（如A）没有产生耐药且透明圈最大，即敏感性最强，它就是临床上的最佳选择。

代表题精讲

题目（2013-新课标Ⅱ-11）：临床试用抗生素前做细菌耐药实验，从病人样本获取致病菌，检测不同抗生素敏感性。

思路：本题涵盖微生物接种的两个不同阶段操作和药敏试验的结果与分析。第一步是根据“获取菌落”提示选用两种常规分离法；第二步是根据“均匀生长、布满平板”提示选用涂布法；第三步是依据抑菌圈的有无、大小及圈内异常菌落，对应解释毒敏、耐药及强弱。

步骤： 1. 第一问填空：为从样本中获取单一致病菌菌落，需分离菌种，常规方法填“平板划线”法或“稀释涂布平板”法。 2. 第二问填空：取单菌落稀释后，为使其铺满平板、均匀生长，必须用“涂布法”接种。 3. 第三问填空： * 含A滤纸片周围出现透明圈，说明生长被抑制，致病菌对抗生素A“敏感”；含B无透明圈，说明致病菌对抗生素B“不敏感”。 * 含C的透明圈小于含A的，说明抑菌能力较弱，即“该致病菌对C的敏感性较A的弱”。 * 含D的透明圈中出现一个菌落，且排除杂菌污染，说明该菌株是突变产生的不受抗生素D抑制的“耐药菌”。 4. 第四问填空：A的透明圈最大且无耐药菌株，为达到最佳抗菌效果，应选择抗生素“A”。

点评/变式：该题为微生物接种与应用的经典考法。务必牢记：“平板划线/稀释涂布”用于求分离，“涂布法”用于铺平板。在进行结果比对时，透明圈大小的比较对象是严格的，必须使用题干限定的比较句式，如“较……的弱”。若变式为“经培养后平板未出现菌落”的成因分析，应联想到接种环过热烫死菌种、培养基选配错误或抗生素浓度过高等因素。
