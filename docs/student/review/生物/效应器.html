效应器

考点效应器权重1真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：1
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 效应器的定义：传出神经末梢和它所支配的肌肉或腺体。它是反射弧的最后一个环节。
  • 反射弧的完整结构：感受器→传入神经→神经中枢→传出神经→效应器。兴奋由传出神经传至效应器，引起肌肉收缩或腺体分泌。
  • 条件反射与效应器：条件反射（如“望梅止渴”）的建立需要大脑皮层参与，但效应器仍然是具体的肌肉或腺体（如唾液腺），反射弧的“传出→效应器”通路不变。
  • 信号转化形式：兴奋在完整反射弧中传导时，会发生“电信号→化学信号→电信号”的转化。其中，化学信号出现在突触处（神经递质释放），效应器突触后膜接受递质后产生电反应或直接导致分泌。
  • 效应器的种类：常见效应器有骨骼肌、平滑肌、心肌、各种外分泌腺（如唾液腺、汗腺）以及某些内分泌腺。

解题方法与套路

  1. 判断反射弧各环节：严格按照“感受器→传入神经→中枢→传出神经→效应器”对应。凡是题干描述“支配××肌肉/腺体”或“引起××分泌/收缩”的结构，多为效应器或传出神经末梢。
  2. 效应器归属验证：看到“唾液腺”“肱二头肌”等，务必联想到它仅仅是效应器的一部分，高中答题中若仅出现腺体/肌肉名称，常视为效应器的简化说法，但若选项表述为“效应器就是指××腺体”，需要警惕是否缺少“传出神经末梢”。
  3. 分析“信号转化”选项：只要反射弧中包含突触，就一定有“电→化学→电”转化。因此看见此类选项，通常正确，除非题干强调只有电信号。
  4. 条件/非条件反射识别：有大脑皮层参与的一般是条件反射，其效应器与对应的非条件反射效应器相同（如同是唾液腺），但要能区分刺激来源是直接非条件刺激还是无关信号，避免混淆。

高频易错

  • 效应器概念被“腰斩”：误认为效应器只指肌肉或腺体，忽略传出神经末梢。严谨定义应为传出神经末梢+所支配的肌肉或腺体。
  • “直接刺激”陷阱：题中“色泽直接刺激神经中枢”之类表述是经典错误，色泽是光刺激，必须经过眼（感受器）、视神经（传入神经）才能到达中枢，不存在“直接”。
  • 大脑皮层作用泛化：条件反射需要大脑皮层，但并不是所有反射都需要大脑皮层。若将“所有反射都需要大脑皮层”视为正确，就会掉坑。非条件反射的神经中枢在脊髓或脑干，但仍可受大脑皮层调节。
  • 信号转化位置混淆：有部分考生以为“电-化学-电”仅在效应器处发生，实际上只要存在突触，无论是中枢内突触还是神经-肌肉接头，均发生此转化。
  • 效应器与感受器不分：效应器是传出神经末梢，而感受器是传入神经末梢，两者功能截然相反，结构上也不同。

代表题精讲

题目（2012·新课标）当人看见酸梅时唾液分泌会大量增加。对此现象的分析，错误的是哪项？
选项涉及大脑皮层参与、效应器是否为唾液腺、色泽直接刺激神经中枢、信号转化等。

思路
本题通过“望梅止渴”这一经典条件反射，综合考察反射弧结构、效应器定位、条件反射中枢以及兴奋传导的化学信号转化。需逐项辨析生物学原理，尤其关注描述中是否存在绝对化或跨越必要环节的表达。

步骤
1. 判断反射类型：看见酸梅→唾液分泌，是后天形成的条件反射，必须有大脑皮层参与，A项正确。
2. 定位效应器：唾液腺接受副交感神经等传出纤维的支配，分泌唾液。在高中层面，可以说该反射的效应器是唾液腺，B项正确。
3. 检查C项：“酸梅色泽直接刺激神经中枢引起唾液分泌”——色泽是光线，首先作用于视网膜上的感光细胞（感受器），产生神经冲动经视神经传到大脑皮层视觉中枢，再通过相关联络核团至唾液分泌中枢，最后经传出神经到达唾液腺。程序绝非“直接”，C项错误。
4. 验证D项：“电-化学-电”信号的转化：反射弧中任何两个神经元之间以及神经-腺体接头处都有突触，兴奋传递必涉及电信号（神经冲动）→化学信号（神经递质释放）→电信号（突触后电位）或直接引发分泌，因此D项正确。
综上，选C。

点评/变式
本题失分常因囿于“效应器就是肌肉或腺体”的片面认识，而命题中B项未强调传出神经末梢，仍在课标内被视为正确表述，但考生需知完整定义。
变式：若将“看见酸梅”改为“吃到酸梅”，则为非条件反射，神经中枢主要在延髓（唾液分泌中枢），不需大脑皮层参与，但效应器仍是唾液腺，信号转化依然存在。通过此类对比训练，可牢固掌握反射弧核心概念，避免因刺激性质改变而张冠李戴。
