无机盐补充

考点无机盐补充权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择9
  • 难度分布：易1

知识精要

  • 无机盐的存在形式：大多数以离子形式存在于细胞中，少数参与构成复杂化合物（如骨骼中的钙盐、血红蛋白中的 $Fe^{2+}$、叶绿素中的 $Mg^{2+}$）。
  • 无机盐的生理功能：
  • 维持细胞和生物体的正常生命活动（如 $Ca^{2+}$ 可调节肌肉收缩，血钙过低会引发抽搐）。
  • 参与维持内环境的渗透压平衡（血浆渗透压主要与 $Na^+$、$Cl^-$ 有关）。
  • 参与维持酸碱平衡（如血浆中 $H_2CO_3/NaHCO_3$ 缓冲对）、维持神经肌肉兴奋性等。
  • 水盐调节的失盐情境：人在剧烈运动、高温环境中大量排汗，汗液为低渗液，主要丢失水分和 $Na^+$、$K^+$ 等无机盐离子。大量出汗后若只补水不补盐，细胞外液渗透压会下降，水向细胞内转移，严重时可引发水中毒，无法维持内环境稳态。因此，补水的同时需要补充电解质（无机盐），以恢复渗透压平衡及正常的生理机能。

解题方法与套路

  1. 识别“失盐”情境：题干中出现“大量出汗”“剧烈运动”“腹泻”“呕吐”等关键信息时，应联想到机体丢失的无机盐（主要为钠盐、钾盐）需随水一并补充。
  2. 分析内环境稳态调节对象：明确题目考查的是水平衡（口渴、抗利尿激素）还是无机盐平衡（醛固酮调节 $Na^+$、$K^+$ 重吸收），或其综合（水盐调节）。剧烈运动后大量出汗属于水、盐同时丢失，答案通常要求同时补充。
  3. 规范填空用词：涉及需要补充的物质，应答“无机盐”“电解质”或具体离子（$Na^+$），忌答“盐水”等非专业术语。若题目考查激素，应准确匹配胰岛A细胞→胰高血糖素，肾上腺皮质→醛固酮等。
  4. 结合具体生理功能作答：若题目要求写出功能，如胰高血糖素的作用，按“促进……、抑制……”的规范句式，覆盖促进糖原分解、促进非糖物质转化、升高血糖等关键得分点。

高频易错

  • 只补水不补盐：考生容易受“出汗失水”的单一思维影响，忽略汗液中同时含有无机盐，导致错失“补充电解质（无机盐）”的得分点。
  • 混淆激素与组织的作用：如将升高血糖的激素答为“肾上腺素”而非题目情境指向的“胰高血糖素”（题干提示胰岛A细胞）。需根据题干给出的特定细胞进行二次确认。
  • 术语随意替换：将“无机盐/电解质”填写为“盐”“盐水”可能因不够规范而失分。将“非糖物质转化为葡萄糖”简写为“非糖物质转化”可能导致漏点，应明确转化对象。
  • 忽略题干指引的得分点数：如“答出2点即可”，需确保答案包含两个独立的得分关键词或短句，避免重复表述导致丢点。

代表题精讲

题目：2020-新课标Ⅱ-09（原题概要）
（1）剧烈奔跑时肌细胞会出现_，导致肌肉酸痛感。
（2）较长时间剧烈运动时，胰岛A细胞分泌加强，分泌_，该激素具有_等生理功能，使血糖升高。
（3）大量出汗后，为维持内环境相对稳定，饮水同时应适当补充一些_。

思路：该题以剧烈运动为情境，串联无氧呼吸产物、血糖调节激素与水盐平衡调节。第（1）问从“肌肉酸痛”推断乳酸积累，根源是无氧呼吸。第（2）问由“胰岛A细胞”锁定胰高血糖素，功能按升高血糖的途径陈述。第（3）问抓住大量出汗使水盐同时流失，单补水会破坏渗透压，故需补充电解质。

步骤：
1. 第（1）空：肌肉酸痛→无氧呼吸产生乳酸积累→答“无氧呼吸”。
2. 第（2）空第一处：胰岛A细胞→分泌胰高血糖素→答“胰高血糖素”。
3. 第（2）空第二处：功能→促进肝糖原分解；促进非糖物质转化为葡萄糖→按“至少2点”规范列出。
4. 第（3）空：汗液含水和无机盐→为维持渗透压等内环境稳态→在饮水时补充“电解质（无机盐）”。

点评/变式：本题为一道基础填空题，精准考查了考生对代谢途径、激素调节以及水盐平衡的综合理解。容易失分点为第（3）空，须牢记大量出汗后必须“水盐同补”。变式可联系腹泻、呕吐等失盐情境，同样需补充口服补液盐或电解质溶液；还可能联合考查抗利尿激素、醛固酮在水盐重吸收中的协同调节。
