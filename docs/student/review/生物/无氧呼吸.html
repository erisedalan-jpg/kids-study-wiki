无氧呼吸

考点无氧呼吸权重33真题数4学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：33
  • 真题数：4；年份跨度：2009–2020
  • 出现题位：选择1 选择2 选择3 选择9
  • 难度分布：易3 中1

知识精要

  • 场所：无氧呼吸全过程均在细胞质基质中进行。这是与原核细胞（无线粒体）仍能进行呼吸作用的关键联系。
  • 过程（两阶段）：
    • 第一阶段（糖酵解）：$C_6H_{12}O_6$（葡萄糖）$\xrightarrow{酶}$ 2 $C_3H_4O_3$（丙酮酸） + 4 $[H]$ + 少量能量。此阶段与有氧呼吸第一阶段完全相同。
    • 第二阶段：丙酮酸在不同酶催化下，被第一阶段产生的 $[H]$ 还原，生成不同的终产物。
      • 产生乳酸：$C_3H_4O_3$（丙酮酸）$\xrightarrow{酶}$ $C_3H_6O_3$（乳酸）。常见实例：动物肌细胞无氧呼吸、马铃薯块茎、甜菜块根、玉米胚、乳酸菌。
      • 产生酒精和二氧化碳：$C_3H_4O_3$（丙酮酸）$\xrightarrow{酶}$ $C_2H_5OH$（酒精） + $CO_2$。常见实例：酵母菌、大多数植物细胞。
  • 能量转化：无氧呼吸只在第一阶段释放少量能量，生成少量ATP。第二阶段不产生ATP。葡萄糖中未释放的能量主要储存在乳酸或酒精中。
  • 本质与意义：有机物的不彻底氧化分解，为生命活动在缺氧条件下提供应急能量。
  • 光合与呼吸关系：叶肉细胞在任何活细胞状态下（包括光照下）都持续进行呼吸作用。光照下，光合速率远大于呼吸速率时，呼吸产生的$CO_2$被光合作用直接利用，不易察觉，但呼吸从未停止。

解题方法与套路

  1. 产物与生物关联法 判断某生物无氧呼吸产物时，应立刻调用记忆表格：
    • 产物只有乳酸→动物肌细胞、乳酸菌、马铃薯块茎、甜菜块根。
    • 产物为酒精与 $CO_2$→酵母菌、绝大多数植物组织。
    • 特例排查：马铃薯块茎产乳酸，不产酒精，储存出现酸味即源于乳酸积累，而非酒精。
  2. 能量与ATP产生阶段判定 面对无氧呼吸过程与ATP关系的问题，应立即反应：ATP仅在葡萄糖→丙酮酸阶段（第一阶段）生成。分析选项时，看到“丙酮酸→乳酸/酒精阶段生成ATP”或“无氧呼吸不产生ATP”即可判定为错误。
  3. 微生物/原核生物呼吸分析策略
    • 牢记结构差异：原核生物（肺炎双球菌、破伤风杆菌等）无线粒体。
    • 功能不受结构限制：有需氧型原核生物，细胞质基质和细胞膜上有与有氧呼吸相关的酶系，可进行有氧呼吸；亦有厌氧型。
    • 解题关键：破除“无线粒体无法进行有氧呼吸”的惯性思维。酶的合成受细胞核或拟核中基因的控制。
  4. 光合与呼吸关系辨析 凡是宣称“光照下植物只进行光合作用不进行呼吸作用”、“光合产物即呼吸底物时呼吸会停止”等切断二者独立性的说法，均为错误选项。判断题可直接依据“呼吸作用在所有活细胞中时刻进行”作为根本判断原则。

高频易错

  • 产物张冠李戴：误将所有植物细胞的无氧呼吸产物都记作酒精和$CO_2$，忽视马铃薯块茎、玉米胚等产乳酸的特例。或混淆不同生物的产物，如认为酵母菌无氧呼吸产乳酸。
  • 能量生成阶段误解：误认为无氧呼吸第二阶段（丙酮酸→乳酸/酒精）可生成ATP，或在涉及无氧呼吸全过程时，表述为“无氧呼吸全过程均能释放少量能量生成ATP”。务必牢记第二阶段不产能。
  • 原核生物与无线粒体的混淆：思维定式，将“无线粒体”与“不能进行有氧呼吸”划等号。对于“无线粒体即进行无氧呼吸”的描述，除非题干已明确其为厌氧菌，否则需警惕其存在有氧呼吸的可能。
  • 在“活细胞是否呼吸”问题上犯错：坚信特化细胞（如人体硬骨组织细胞）、在特定环境中的细胞（如光照下的叶肉细胞）不进行呼吸作用或呼吸作用会暂停。根治方法是反复强化核心概念：呼吸作用为任何活细胞时刻必需的自我更新与供能活动。

代表题精讲

题目：（2020-新课标Ⅱ-09节选）剧烈奔跑运动时肌细胞会出现______，这一呼吸方式会导致肌肉有酸痛感。 - 思路：本题直接将生活现象“肌肉酸痛”与细胞代谢类型挂钩。解题线索是识别“酸痛”的生化成因。 - 步骤：剧烈运动导致肌细胞供氧不足，启动无氧呼吸补充能量。动物肌细胞无氧呼吸的终产物是乳酸，乳酸大量积累会引起肌肉酸痛。故填空处为“无氧呼吸”。 - 点评/变式：直接考察无氧呼吸的应用。若命题引向产酒精的植物组织，现象描述可能变为“水淹导致植物根部变黑腐烂，伴随酒味”，即须判断为酒精发酵。

题目：（2019-新课标Ⅱ-02）下列关于马铃薯块茎细胞无氧呼吸的叙述，正确的是（ ） - 思路：严格依据植物无氧呼吸产物特例与分阶段能量梳理进行选项排除。 - 步骤： - A项：马铃薯块茎无氧呼吸的终产物是乳酸，不是葡萄糖（葡萄糖是底物，已被分解）。错误。 - B项：无氧呼吸第一阶段葡萄糖分解为丙酮酸，第二阶段丙酮酸被 $[H]$ 还原为乳酸。正确。 - C项：无氧呼吸第一阶段（产生丙酮酸的过程）会释放少量能量，生成ATP。错误。 - D项：氧气浓度升高会抑制无氧呼吸酶的活性，乳酸的生成量将减少，酸味不会增加。错误。 - 点评/变式：本题集中考查无氧呼吸产物、过程与调控。注意，储存环境缺氧是块茎启动无氧呼吸产生乳酸的前提。若将马铃薯块茎换成苹果果实或水稻根，反应式及产物便切换为酒精和$CO_2$，易错点即在此处。

题目：（2013-新课标Ⅱ-03）下列与微生物呼吸有关的叙述，错误的是（ ） - 思路：本题涉及不同微生物呼吸类型的对比，应用“结构-功能”分离和对典型微生物习性的记忆解题。 - 步骤： - A项：肺炎双球菌为原核生物，无线粒体，但它是需氧菌，含有氧呼吸酶系，可进行有氧呼吸。正确。 - B项：细菌为原核生物，其呼吸作用酶的合成由拟核中的基因编码调控。正确。 - C项：破伤风芽孢杆菌为严格的厌氧菌，有氧环境会抑制其生命活动。选项中“适宜生活在有氧环境”与之完全相反。错误。 - D项：酵母菌为兼性厌氧型真菌，有氧呼吸产$CO_2$和$H_2O$，无氧呼吸产酒精和$CO_2$，二者产物不同。正确。 - 点评/变式：核心陷阱在于对原核生物呼吸方式的机械判断。必须明确，“无线粒体”$\neq$“只能无氧呼吸”。本题需记忆几种经典微生物的呼吸类型，如醋酸杆菌（需氧）、乳酸菌（专性厌氧、产乳酸）、酵母菌（兼性厌氧）等。
