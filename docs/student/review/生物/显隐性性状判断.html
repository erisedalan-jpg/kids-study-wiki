显隐性性状判断

考点显隐性性状判断权重5真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：5
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 显隐性性状的定义：具有一对相对性状的两纯合亲本杂交（或一方显性纯合、一方隐性纯合），$F_1$ 表现出的性状为显性性状，$F_1$ 未表现出的性状为隐性性状。这就是“定义法”判断显隐性的核心。
  • 适用条件：
  • 亲本必须为具有相对性状的纯合子（至少控制该性状的一对基因是纯合的）。若亲本不确定纯合，需通过多对杂交组合反向验证。
  • 子代数量足够多，且无致死、基因互作等异常现象。
  • 常染色体遗传与伴性遗传均可使用定义法，但若正反交结果不一致，则暗示伴性遗传，此时需另行分析。
  • 延伸判定法：
  • 性状分离法：同一亲本自交（或相同基因型个体间杂交），后代出现性状分离，则分离出的新性状为隐性，亲本的性状为显性。比例接近 $3:1$ 时家长本为杂合子。
  • 口诀：“无中生有为隐性”（双亲正常，子代出现患者，则该病为隐性遗传病）；“有中生无为显性”（双亲患病，子代出现正常，则该病为显性遗传病）。用于遗传系谱图分析。
  • 两对及多对性状：若两对基因独立遗传，显隐性可分别判断，互不干扰。如题中，根据有毛白肉A（$\text{DDff}$）与无毛黄肉C（$\text{ddFF}$）杂交，子代全部表现为有毛黄肉，即可同时判断出有毛对无毛为显性，黄肉对白肉为显性。

解题方法与套路

  1. 寻找关键杂交组合 – 优先寻找“相对性状杂交，后代只表现一种性状”的组合，即双亲分别为两种相对性状，子代无性状分离。直接得出结论：子代表现出来的即为显性。
  2. 若无典型显性组合，则利用自交或相同性状杂交 – 观察子代是否出现与亲本不同的性状（性状分离）。分离出来的新性状为隐性，亲本为显性杂合子。例如“无毛黄肉B自交后代出现无毛白肉”，说明白肉为隐性，黄肉为显性，且B为杂合子（$\text{ddFf}$）。
  3. 确定基因型框架 – 先用显隐性定出“空格”：显性性状个体可能为纯合或杂合（用 $_$ 表示未知基因），隐性性状个体一定为隐性纯合。如题中，有毛为显性用 $\text{D}_$，无毛为隐性用 $\text{dd}$；黄肉为显性用 $\text{F}_$，白肉为隐性用 $\text{ff}$。
  4. 子代逆推亲本基因型 – 根据子代的表现型及比例，反向拆分配子来源。常用分离比为突破口：若子代出现 $1:1$ 分离，则亲本一方杂合、一方隐性纯合（测交类型）；若子代全为同一性状，则亲本至少一方为显性纯合；若出现 $3:1$，则双亲均为杂合。
  5. 逐对分析，组合求解 – 两对或多对独立遗传的性状，先按单对分析，再将结果组合。最后写出遗传图解（注意符号：$\times$、$P$、配子、子代基因型与表现型、比例）。

高频易错

  • 误把“多数性状”当显性：不能凭种群中出现频率高低直接判断显隐性，必须以杂交实验获得的子代表现为准。
  • 忽视亲本纯合的必要条件：定义法要求亲本是纯合子。若杂交亲本中有杂合子，$F_1$ 可能同时出现双亲性状，此时不能直接判定显隐性，需结合其他组合。
  • 混淆基因型书写：显性个体未确认纯合时，应使用通配符“$_$”保持可能性，如 $\text{D}_\text{ff}$，不可直接写成 $\text{DDff}$ 或 $\text{Ddff}$，除非已有可靠证据。
  • 不验证独立遗传条件：题干若说明“独立遗传”，才可应用自由组合定律的 $9:3:3:1$ 及其变形。若未说明，需通过测交比例是否 $1:1:1:1$ 来验证。
  • 遗传图解不规范：漏写表现型、比例，或未用箭头等符号连接各代，导致扣分。杂交符号“$\times$”不能省略，自交符号“$\otimes$”与杂交不同。
  • 自交后代比例计算忽略隐性纯合子：如 $\text{ddFf}$ 自交，只考虑果肉颜色，后代 $\frac{3}{4}$ 黄肉、$\frac{1}{4}$ 白肉，但果皮始终无毛（$\text{dd}$），因此表现型为“无毛黄肉:无毛白肉=$3:1$”，而非“有毛黄肉”等。

代表题精讲

代表题：2016·新课标Ⅱ-10（综合杂交实验推断显隐性与基因型）

题目简述：某种植物果皮有毛/无毛（D/d）、果肉黄/白（F/f）独立遗传。利用有毛白肉A、无毛黄肉B、无毛黄肉C三基因型不同个体进行三组实验：实验1 A×B；实验2 B×C；实验3 A×C。给定子代表现（题干原始有表格，需自行推断），要求确定显隐性、写出各株基因型、推演后代比例及遗传图解。

思路： - 抓住实验3（A有毛白肉 × C无毛黄肉）→ 子代全为有毛黄肉，显性立刻判定。 - 从隐性性状（无毛、白肉）入手确定必为纯合隐性 $\text{dd}$、$\text{ff}$，逐步推导其他基因型。 - 利用实验2 B×C 子代全为无毛黄肉，且C为无毛黄肉无性状分离，推测C的果肉基因型为 $\text{FF}$（纯合）。 - 由实验1 A×B 子代出现白肉（$\text{ff}$）但不出现无毛，推测B的果肉基因为杂合 $\text{Ff}$。 - 基因型全部确定后，按要求书写遗传图解并计算比例。

步骤： 1. 判断显隐性：根据实验3，一方有毛白肉，另一方无毛黄肉，两者为双相对性状差异的纯合子（后续基因型可验证），子代全为有毛黄肉 → 有毛对无毛为显性，黄肉对白肉为显性。 2. 确定隐性纯合片段：无毛为隐性，基因型 $\text{dd}$；白肉为隐性，基因型 $\text{ff}$。故A为有毛白肉 → 必含 $\text{D}_$ 和 $\text{ff}$；C为无毛黄肉 → 必含 $\text{dd}$ 和 $\text{F}_$；B为无毛黄肉 → 必含 $\text{dd}$ 和 $\text{F}_$。 3. 推导C的基因型：实验3中子代全为有毛黄肉，无性状分离，说明A和C均在各自显性性状上为纯合，否则可能分离。结合A白肉一定是 $\text{ff}$，那么黄肉必须由C提供 $\text{F}$，且不出现白肉，说明C的黄肉是纯合 $\text{FF}$。有毛来自A，子代有毛且无无毛出现，要求C不能提供d？C是无毛 $\text{dd}$，子代从A得D，从C得d，组成 $\text{Dd}$，全为有毛，成立。所以C＝$\text{ddFF}$，A＝$\text{DDff}$（因有毛不能杂合，否则实验3可能出现无毛）。 4. 推导B的基因型：B为无毛黄肉 $\text{ddF}_$。实验1 A（$\text{DDff}$）× B（$\text{ddF}_$）子代出现有毛白肉 $\text{Ddff}$ 和有毛黄肉 $\text{DdFf}$，题干描述有性状分离（原始数据有白肉出现），说明B是杂合子 $\text{Ff}$，所以B＝$\text{ddFf}$。 5. 验证实验2：B $\text{ddFf}$ × C $\text{ddFF}$ → 子代全部无毛，果肉基因型 $\text{FF}$ 或 $\text{Ff}$，均黄肉，比例符合全部无毛黄肉。 6. 计算（3）～（5）： - （3）B自交：$\text{ddFf}$ × $\text{ddFf}$ → 果皮全无毛，果肉 $3/4$黄肉($1\text{FF}+2\text{Ff}$)、$1/4$白肉($1\text{ff}$) → 无毛黄肉:无毛白肉 $= 3:1$。 - （4）实验3子代基因型为 $\text{DdFf}$（全有毛黄肉），自交 $ \text{DdFf} \times \text{DdFf} $，两对独立，$F_2$ 表现型比例典型 $9:3:3:1$：9有毛黄肉，3有毛白肉，3无毛黄肉，1无毛白肉。 - （5）实验2子代无毛黄肉：基因型为 $\text{ddFF}$ 和 $\text{ddFf}$。 7. （6）书写实验一遗传图解： - 亲本：有毛白肉A $\text{DDff}$ $\times$ 无毛黄肉B $\text{ddFf}$ - 配子：A→$\text{Df}$；B→$\text{dF}$、$\text{df}$ - 子代：$\text{DdFf}$（有毛黄肉）、$\text{Ddff}$（有毛白肉），比例 $1:1$ - 规范表达：包含 $P$、配子、$F_1$、表现型及比例，箭头或下行。

点评/变式： - 该题是“定义法”判断显隐性的经典应用，考查学生通过子代表现逆推基因型的能力。关键是锁住显隐性组合（实验3）一举突破。 - 变式训练：可将实验顺序打乱，或补充其他杂交组，如“有毛黄肉自交后代出现无毛白肉”，则改用性状分离法确定显隐性。 - 注意遗传图解的完整性，尤其是多对性状时配子不要遗漏，比例标注清晰。
