最适浓度

考点最适浓度权重6真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：6
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 最适浓度：在生长素等植物激素的作用中，使生理效应（如弯曲角度$\alpha$、生长长度等）达到最大值所对应的浓度。
  • 作用双重性：生长素的生理效应与浓度并非单调关系。在低于最适浓度时，效应随浓度升高而增强；达到最适浓度时效应最强；超过最适浓度后，效应随浓度升高而减弱。
  • 效应等同原理：基于双重性，除最适浓度外，任何一个特定的生理效应（小于最大值）都对应着两个不同的浓度，一个位于最适浓度的左侧（低浓度），一个位于最适浓度的右侧（高浓度）。
  • 浓度曲线拐点：效应-浓度关系曲线呈钟形或倒“U”形，最适浓度即曲线的顶点。曲线的上升段和下降段可以有同一效应水平的两点。

解题方法与套路

  1. 识别曲线类型：首先判断题目所给的生理效应与浓度关系是否为典型的钟形曲线，确认其存在一个效应峰值（最适浓度）。
  2. 一效应双浓度判定：若题中指出某一非最大效应来自未知浓度，应立刻反应出该效应可对应A、B两个浓度，一个在最适浓度左侧，一个在右侧。
  3. 稀释实验设计思维：这是鉴别A、B浓度的核心方法。
  4. 原理：将未知浓度溶液稀释后，测量生理效应的变化方向。
  5. 若稀释后效应减弱（稀释后效应值 < 原效应值）：原溶液处于最适浓度左侧的上升段。因浓度降低，效应沿曲线向左下方移动，故效应减小。
  6. 若稀释后效应增强（稀释后效应值 > 原效应值）：原溶液处于最适浓度右侧的下降段。因浓度降低趋近最适浓度，效应沿曲线向左上方移动，故效应增大。
  7. 结论表述范式：预测并比较稀释前后效应值（如$\alpha_1$与$\alpha_2$）的大小，得出确切结论——“若……，则原溶液为A浓度；若……，则原溶液为B浓度”。

高频易错

  • 混淆单一性与双重性：误认为生理效应总是随浓度升高而单调递增或递减，看到同一效应值便断定浓度相同。须牢记生长素等物质存在“最适浓度”。
  • 稀释结果的逻辑颠倒：在根据稀释后效应大小推断原浓度位置时，最容易出错。要牢记：稀释能使高于最适浓度的溶液效应增大（因其向最适浓度靠近），使低于最适浓度的溶液效应减小（因其远离最适浓度）。
  • 忽略最适浓度的唯一性：错误地将效应大小的变化趋势等同于浓度的唯一性。除最大效应值外，任何小于最大值的效应值都对应两种可能浓度，必须通过附加实验（如稀释）来区分。

代表题精讲

题目：(2010·新课标) 通过实验获得茎段弯曲角度$\alpha$与生长素浓度的钟形曲线。现测得一未知浓度溶液产生弯曲角度$\alpha_1$，从曲线上查得对应的低浓度A和高浓度B。为确定真实浓度，将其稀释至原浓度的80%后测得弯曲角度$\alpha_2$。请预测$\alpha_2$与$\alpha_1$的比较结果并给出相应结论。 思路：本题核心考查生长素作用双重性中“同效应双浓度”的鉴别。解题关键在于利用稀释后生理效应（弯曲角度）的变化方向，反推原浓度在效应曲线上所处的位置。 步骤： 1. 分析可知，$\alpha_1$为非最大值，故原溶液可能是左侧上升段的A浓度，也可能是右侧下降段的B浓度。 2. 分情况讨论稀释结果： - 若原溶液为低浓度A，稀释后浓度变得更低，效应减弱，弯曲角度变小，表现为$\alpha_2 < \alpha_1$。 - 若原溶液为高浓度B，稀释后浓度降低并向最适浓度靠拢，效应增强，弯曲角度变大，表现为$\alpha_2 > \alpha_1$。 3. 据此写出完全对应的结论：若$\alpha_2$小于$\alpha_1$，则该溶液的生长素浓度为A；若$\alpha_2$大于$\alpha_1$，则该溶液的生长素浓度为B。 点评/变式：本题是“最适浓度”考点的经典模型。解题逻辑可概括为“稀释以定向”。变式训练中，可将“弯曲角度”换为“胚芽鞘伸长长度”“生根数量”等指标，或将植物激素换为作用具有最适浓度的酶、调节物质等，但“稀释效应判定法”的思维内核完全一致。牢牢把握“稀释后效应增大，则原液为高浓度；稀释后效应减小，则原液为低浓度”这一核心规律，是应对此类题目的不二法门。
