核酸

考点核酸权重14真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：14
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：选择2
  • 难度分布：中1

知识精要

  • 核酸的结构层次：元素组成 C、H、O、N、P → 核苷酸（磷酸+五碳糖+含氮碱基）→ 多核苷酸链。
  • DNA 与 RNA 比较：
  • DNA：脱氧核糖，碱基 A/T/C/G，通常双链结构，是主要的遗传物质。
  • RNA：核糖，碱基 A/U/C/G，通常单链，参与蛋白质合成，少数病毒（如 HIV）以 RNA 为遗传物质。
  • 遗传物质的类型：
  • 细胞生物：同时含有 DNA 和 RNA，但遗传物质是 DNA。
  • 病毒：只含一种核酸，DNA 病毒（如 T2 噬菌体）以 DNA 为遗传物质；RNA 病毒（如 HIV）以 RNA 为遗传物质。
  • T2 噬菌体增殖过程：吸附 → 注入 DNA → 利用宿主细胞原料合成子代 DNA 和蛋白质 → 组装 → 释放。
  • 关键：合成子代噬菌体所需原料（核苷酸、氨基酸）全部来自宿主细胞，唯一起指令作用的是噬菌体 DNA。
  • 同位素标记法：$^{32}{\rm P}$ 标记 DNA（因 DNA 含磷），$^{35}{\rm S}$ 标记蛋白质（因蛋白质含硫）。宿主摄取培养基中的 $^{32}{\rm P}$ 后，子代噬菌体核酸中可检测到放射性。

解题方法与套路

  1. 审清生物类别：先判断题目对象是细胞生物还是病毒；若为病毒，进一步判断是 DNA 病毒还是 RNA 病毒。
  2. 抓准物质联系：病毒增殖时，核酸模板由病毒提供，合成原料（核苷酸、氨基酸等）全部从宿主获取。
  3. 匹配标记元素定位：分析放射性元素标记了哪种物质（DNA/蛋白质），追踪该物质出现的场所（子代病毒、细菌沉淀、上清液等）。
  4. 类比迁移谨慎：不同病毒的核酸类型、增殖过程不同，不能将 T2 噬菌体的结论直接套用到其他病毒（如 HIV）上。

高频易错

  • 病毒宿主专一性混淆：T2 噬菌体专门寄生在大肠杆菌，不能在其他细菌（如肺炎双球菌）中增殖。
  • 忽略合成场所：病毒不具有独立代谢能力，mRNA 和蛋白质只能在宿主细胞内合成，病毒颗粒内不会进行转录或翻译。
  • 核酸类型误判：HIV 是 RNA 病毒，其遗传物质为 RNA，增殖涉及逆转录；T2 噬菌体是 DNA 病毒，无逆转录过程。两者核酸类型和增殖过程均不同。
  • 原料来源记忆不清：容易错误认为子代噬菌体的核酸原料由亲代带入，实际上全部来自培养基（经宿主摄取）。

代表题精讲

题目 2017·新课标Ⅱ·02

在证明 DNA 是遗传物质的过程中，T2 噬菌体侵染大肠杆菌的实验发挥了重要作用。判断下列关于 T2 噬菌体叙述的正误。

思路
结合噬菌体专一宿主、增殖条件、物质合成原料及场所、核酸类型与标记元素去向逐项分析。

步骤
- A 项：T2 噬菌体只能寄生在大肠杆菌，在肺炎双球菌中不能复制增殖。错误。
- B 项：T2 噬菌体没有细胞结构，单独存在时不能合成 mRNA 和蛋白质，这些过程必须在宿主细胞内完成。错误。
- C 项：$^{32}{\rm P}$ 标记的培养基中，宿主摄取含 $^{32}{\rm P}$ 的磷酸盐合成自身核苷酸等，噬菌体侵入后利用宿主原料合成子代 DNA，因此 $^{32}{\rm P}$ 可出现在 T2 噬菌体的核酸中。正确。
- D 项：人体免疫缺陷病毒 (HIV) 的核酸是 RNA，增殖需逆转录；T2 噬菌体核酸是 DNA，直接利用宿主细胞合成。二者核酸类型和增殖过程均不同。错误。

点评/变式
本题以经典实验为载体，考查病毒的物质组成、专一寄生、增殖过程以及核酸特性。错误选项设计极具迷惑性，常误认为病毒可独立代谢或任意更换宿主。变式可延伸至“用 $^{35}{\rm S}$ 标记蛋白质，放射性主要出现在上清液”等实验分析，强化对标记元素跟踪的理解。
