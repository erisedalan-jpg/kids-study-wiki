植物体细胞杂交

考点植物体细胞杂交权重7真题数1学科生物父主题生物技术与工程

考点定位

  • 父主题：生物技术与工程
  • 权重 weight：7
  • 真题数：1；年份跨度：2013–2013
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • 概念：植物体细胞杂交是将不同种植物的体细胞（原生质体）诱导融合，经组织培养获得杂种植物，克服远缘杂交不亲和障碍，实现核质基因重组。
  • 操作流程：
    去壁（纤维素酶+果胶酶 → 原生质体） → 诱导融合（物理：电激、离心；化学：PEG） → 形成杂种细胞 → 脱分化形成愈伤组织 → 再分化成植株。
  • 多倍体判定：杂种植株一般含双亲染色体组，为异源多倍体。多倍体定义：由受精卵发育而来，体细胞含三个或三个以上染色体组。
  • 可育性原因：杂种植株因双亲染色体融合但通常能正常联会，而在有性杂交中异源染色体往往不能正常联会，导致减数分裂紊乱，配子不育。
  • 人工种子：以组织培养获得的胚状体、不定芽、顶芽、腋芽等为繁殖体，包裹人工种皮（人工薄膜）制成。
  • 应用：培育兼具双亲优良性状的药用植物、农作物新种质。

解题方法与套路

  1. 识记填空题流程：按照“酶解法去壁 → 原生质体 → 融合 → 愈伤组织 → 再分化”顺序匹配题干，注意酶的种类（纤维素酶、果胶酶）、融合方法及相应名词。
  2. 多倍体与可育性判断：抓住“由受精卵发育”“染色体组数≥3”回答多倍体定义；分析杂种植株可育的依据：亲本染色体经诱导融合后同源染色体能正常配对，而有性杂交因亲缘关系远常致联会紊乱。
  3. 人工种子材料选择：联想植物组织培养中能发育成完整植株的结构（胚状体、芽等），避免答出“种子”或“合子”，因为这些是自然有性生殖产物。
  4. 因果解释题：建立“现象—机制—结果”链条，如“不育 → 减数分裂时染色体不能正常联会 → 无法形成正常配子”的对应关系。

高频易错

  • 去壁酶选混：易错添加蛋白酶或溶菌酶，必须明确植物细胞壁成分是纤维素和果胶，对应酶是纤维素酶和果胶酶。
  • 多倍体定义失误：多倍体强调“由受精卵发育”和“三个或三个以上染色体组”，单独说“染色体组多”不得分；注意与单倍体区分。
  • 杂种植株可育原因表述含糊：仅答“染色体加倍”不够，需明确前者有性杂交后代染色体联会异常，体细胞杂交后代染色体能正常联会。
  • 人工种子材料错答：误写“种子”“受精卵”“合子”，实际应来自植物组织培养的不定器官或胚状体。
  • 流程词序混淆：脱分化形成愈伤组织在再分化之前，部分考生颠倒顺序。

代表题精讲

题目（2013新课标Ⅱ·12）：考查同时含两种有效成分的新型药用植物培育，涉及去壁、融合、组织培养、多倍体概念、可育性原因、人工种子等。

思路
分（1）填写技术流程关键词，（2）解释多倍体定义及杂种植株可育因果，（3）列举人工种子繁殖材料。

步骤
- （1）取叶片，用纤维素酶和果胶酶去壁获原生质体；化学诱导融合；形成愈伤组织；再分化成植株；此培养技术即植物体细胞杂交技术。
- （2）多倍体是由受精卵发育，体细胞含三个或三个以上染色体组。有性杂交后代不育：减数分裂时染色体联会异常；体细胞杂种可育：因其细胞内染色体能正常联会。
- （3）经植物组织培养得到胚状体、顶芽、不定芽、腋芽等材料用人工薄膜包装得人工种子。

点评/变式
该题为基础填空+原因阐释，考生需精准记忆术语并理解减数分裂联会机制。变式可能将“有性杂交不育”换成“体细胞杂交可育的优势”或要求比较原生质体融合与受精作用的区别，均需紧扣“联会是否正常”这一核心得分点。
