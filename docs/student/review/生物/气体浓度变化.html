气体浓度变化

考点气体浓度变化权重5真题数1学科生物父主题实验

考点定位

  • 父主题：实验
  • 权重 weight：5
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 密闭容器中气体变化的本质：植物在光照下同时进行光合作用与呼吸作用，容器内 $CO_2$ 浓度的变化取决于净光合速率（$P_n = P_g - R$，其中 $P_g$ 为总光合速率，$R$ 为呼吸速率）。
  • 三种基本关系：
  • $P_g > R \implies P_n > 0 \implies$ 植物从外界吸收 $CO_2$，容器内 $CO_2$ 浓度下降。
  • $P_g = R \implies P_n = 0 \implies$ 光合吸收的 $CO_2$ 等于呼吸释放的 $CO_2$，浓度保持稳定（达到 $CO_2$ 补偿点）。
  • $P_g < R \implies P_n < 0 \implies$ 呼吸释放 $CO_2$ 多于光合消耗，浓度上升。
  • 恒定适宜条件下的动态变化：在温度、光照恒定且适宜时，呼吸速率基本不变；但密闭容器中 $CO_2$ 浓度变化会反馈调节光合速率。初期 $CO_2$ 浓度较高，$P_g$ 较高，$P_g > R$，$CO_2$ 降低；随后 $CO_2$ 降低使 $P_g$ 逐渐减小，直至 $P_g = R$ 时达到动态平衡。
  • $CO_2$ 补偿点：密闭条件下，当光合速率降至与呼吸速率相等时的 $CO_2$ 浓度，此时净光合为零，浓度不再变化。

解题方法与套路

  1. 锁定对象与条件：明确装置（密闭/开放）、植物状态（正常/胁迫）、环境（光照/黑暗、恒温/变温），判断是仅呼吸还是光合与呼吸共存。
  2. 抓气体浓度变化趋势：
  3. 浓度降低 → 净吸收 > 0 → 光合 > 呼吸（光下）。
  4. 浓度升高 → 净释放 > 0 → 光合 < 呼吸或仅有呼吸。
  5. 浓度不变 → 净交换为 0 → 光合 = 呼吸（或既不消耗也不产生）。
  6. 分析速率动态：密闭容器中，因原料（$CO_2$）消耗或产物（$O_2$）积累，光合速率往往会受反馈调节而变化，不可默认光合速率始终不变。
  7. 对比选项排除干扰：重点辨析“速率绝对值变化”与“相对大小关系”，结合趋势排除与曲线方向矛盾的选项。

高频易错

  • 混淆“速率降低”与“小于呼吸”：初期 $CO_2$ 降低只能说明光合速率大于呼吸速率，不能倒推光合速率本身在升高。密闭环境 $CO_2$ 下降反而会导致光合速率逐渐下降。
  • 忽视密闭环境的反馈调节：误以为温度、光照恒定则光合速率始终不变，从而错选 B 或认为 $P_g$ 一直无限大于 $R$。
  • 错误理解“保持相对稳定”：认为稳定时呼吸停止或光合单独变化，实际是光合速率下降到与呼吸速率相等，达到 $CO_2$ 补偿点。
  • 曲线方向与速率大小颠倒：看到 $CO_2$ 下降就认为呼吸速率大于光合速率（这是 $CO_2$ 上升的条件），本质是对净光合方向理解反向。

代表题精讲

题目

（2022 全国乙卷 2）将生长正常的小麦放在密闭容器中，在适宜且恒定的温度和光照下培养，容器内 $CO_2$ 含量初期逐渐降低，之后保持相对稳定。下列解释合理的是（　　） A. 初期光合速率逐渐升高，之后光合速率等于呼吸速率 B. 初期光合速率和呼吸速率均降低，之后呼吸速率保持稳定 C. 初期呼吸速率大于光合速率，之后呼吸速率等于光合速率 D. 初期光合速率大于呼吸速率，之后光合速率等于呼吸速率

思路

  • 关键词：密闭、恒温、适宜光照、$CO_2$ 先降后稳。
  • 明确 $CO_2$ 降低 $\Rightarrow$ 净光合 $>0$ $\Rightarrow$ 光合速率 $>$ 呼吸速率。
  • 后期稳定 $\Rightarrow$ 净光合 $=0$ $\Rightarrow$ 光合速率 $=$ 呼吸速率。
  • 密闭环境中 $CO_2$ 下降会使光合速率受限而降低，最终在补偿点达到平衡。

步骤

  1. 初期 $CO_2$ 浓度逐渐降低，说明容器内 $CO_2$ 被净吸收，故光合速率大于呼吸速率，直接排除 C（C 会导致 $CO_2$ 上升）。
  2. 温度、光照恒定，呼吸速率基本不变；$CO_2$ 降低会限制光合速率，使其下降而非升高，故 A 错。
  3. 光合速率初期下降（而非升高），但始终大于呼吸，直至两者相等；选项 B 说两者均降低且之后呼吸才稳定，不合逻辑。
  4. 选项 D 准确描述了相对大小关系：初期光合 $>$ 呼吸，之后二者相等，与 $CO_2$ 先降后稳完全吻合。

点评/变式

  • 核心陷阱：本题极易错选 A，误以为 $CO_2$ 降低是由于光合速率不断升高。实则在密闭容器中，植物消耗 $CO_2$ 的同时也在降低光合速率，只是仍高于呼吸。
  • 变式延伸：若将容器改为 $O_2$ 含量监测，初期 $O_2$ 逐渐升高，后保持相对稳定，则同样对应光合大于呼吸，后达到平衡。若置于黑暗条件下，则只有呼吸，$CO_2$ 持续升高。考生应熟练运用“净速率方向决定浓度变化”这一准则。
