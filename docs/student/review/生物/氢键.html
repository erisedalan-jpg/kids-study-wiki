氢键

考点定位

  • 父主题：分子与细胞
  • 权重 weight：0
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 蛋白质的结构层次
    • 一级结构：氨基酸的排列顺序（肽链）。
    • 二级结构：局部肽链借助氢键盘曲、折叠形成 $\alpha$ 螺旋或 $\beta$ 折叠。
    • 三级结构：在二级结构基础上进一步盘曲折叠，形成具有特定空间构象的整体结构，维系力量包括氢键、疏水作用、离子键等。
    • 四级结构：多条肽链（亚基）通过非共价键结合。
  • 氢键在蛋白质中的作用
    • 并非维持蛋白质空间结构的唯一力量，但对维持二级结构至关重要。
    • 贡献于蛋白质特定形状（如球形结构）的形成，使之具有功能性空间构象。
  • 钙调蛋白与钙离子
    • 钙调蛋白本质是蛋白质，基本组成单位为氨基酸，合成场所为核糖体。
    • $Ca^{2+}$ 不是蛋白质的结构组分，而是作为一种信号分子，与特定蛋白质结合后可引起后者构象改变，从而调控其活性。

解题方法与套路

对于涉及蛋白质、离子结合与结构变化的复合型选择题，可遵循以下步骤： 1. 锁定物质本质：首先确认题干所述物质的化学本质（如蛋白质、核酸等），据此调取其基本单位、合成场所等固定知识点。 2. 辨析组成与作用：严格区分“作为基本组成单位的物质”与“起调节作用的离子或小分子”。矿物质离子（如 $Ca^{2+}$）不是生物大分子的单体。 3. 拆解结构成因：分析空间结构的形成原因，常考知识网包括： - 特定结构（如球形、折叠）的形成与氢键、疏水作用等有关。 - 结合配体（如离子、辅酶）可能改变分子构象，但不改变其一级结构。 4. 使用排除法验证：将选项逐一与教材核心概念比对，优先排除在基本单位、合成场所等硬性知识点上犯错的选项。

高频易错

  • 错认离子为组成单位：题目常将结合离子（如 $Ca^{2+}$、$Mg^{2+}$）与蛋白质、核酸的基本组成单位（氨基酸、核苷酸）并列，诱使考生混淆“功能性结合”与“结构性组成”。
  • 狭隘理解氢键作用：误认为氢键只存在于 $DNA$ 双螺旋或水分子中。需牢记氢键是蛋白质二级结构形成的主要作用力，广泛参与所有生物大分子高级结构的维持。
  • 忽略构象变化的可能：受“结构决定功能”的固化思维影响，易认为功能蛋白的结构是绝对固定的。实际上，许多蛋白质在行使功能时，通过与配体结合，其空间结构会发生可逆的动态变化。

代表题精讲

题目：2024-辽宁-01 题干略。（考查钙调蛋白的结构、组成与离子结合）

思路： 本题为叙述错误类选择题，核心在于辨析“钙调蛋白”这种蛋白质的分子属性。解题时必须抓住其蛋白质本质，并以此反驳涉及基本组成单位、合成场所及结构变化的错误描述。

步骤： 1. 分析选项 A：钙调蛋白是蛋白质，所有蛋白质的合成场所均为核糖体。该叙述正确。 2. 分析选项 B：$Ca^{2+}$ 是一种无机离子，由题干可知其作为“感受器”结合的对象，而非构成该蛋白的结构单元。蛋白质的基本组成单位恒定为氨基酸。该叙述混淆了调控离子与结构单元，故错误。 3. 分析选项 C：蛋白质的球形结构属于高级空间构象。肽链在折叠、盘曲形成此特定形状的过程中，氢键是关键的维系力量。该叙述正确。 4. 分析选项 D：蛋白质与特定离子或小分子结合后，常诱导其构象发生改变（例如载体蛋白、通道蛋白、受体蛋白），这是其行使功能的基础。钙调蛋白结合 $Ca^{2+}$ 后空间结构可能变化，合乎逻辑且为教材间接支持。该叙述正确。

点评/变式： 本题的典型陷阱在于选项 B 和 C。许多考生能判断 B 是错的，但会犹豫 C 或 D。必须深植一个观念：蛋白质的任何折叠（从 $\alpha$ 螺旋到复杂的球形结构）都离不开氢键的参与。变式题可能将钙调蛋白更换为血红蛋白、载体蛋白等，考查 $Fe^{2+}$ 或底物结合引起的变构效应，核心逻辑完全相同：蛋白质的根本属性不变，离子结合常引发构象变化。
