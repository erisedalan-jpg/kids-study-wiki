水存在形式

考点水存在形式权重5真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：5
  • 真题数：1；年份跨度：2018–2018
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 水在细胞中的存在形式：自由水（以游离形式存在，流动性强，参与代谢反应、物质运输等）与结合水（与蛋白质、多糖等物质结合，构成细胞结构成分）。
  • 自由水与结合水比值越大，细胞代谢越旺盛，但抗逆性（如抗旱、抗寒）越弱；比值越小，代谢速率减缓，抗逆性增强。
  • 细胞呼吸（主要是 $C_6H_{12}O_6 + 6O_2 + 6H_2O \xrightarrow{\text{酶}} 6CO_2 + 12H_2O + \text{能量}$）属于细胞内重要的代谢过程，其强度与水含量直接相关。自由水是细胞呼吸的介质和反应物，含水量降低会抑制呼吸酶活性、限制气体交换。
  • 种子风干过程主要减少自由水，结合水比例相对上升。此时种子进入休眠，有机物消耗显著降低，微生物也因缺水难以繁殖。

解题方法与套路

  1. 明确情境核心：读题时圈定“风干前后”等处理，迅速对接“自由水减少、结合水比例增大”这一本质变化。
  2. 建立含水量与代谢的关系链：自由水 → 代谢强度（尤其细胞呼吸）→ 有机物消耗速率 → 种子活力/休眠 → 抗逆性。凡是认为风干后呼吸强度仍高的选项，一定违背这条关系链。
  3. 善用排除法定位“说法错误”：题目若问“错误的是”，优先筛选与水分变化引起的代谢逻辑相悖的表述（如代谢强度高、消耗快等）；其余选项通常为正确陈述，可反向验证。
  4. 警惕微生物生长条件干扰：种子风干后水分极少，限制微生物繁殖所需的自由水，选项若涉及微生物不易繁殖，一般是正确推断。

高频易错

  • 混淆自由水和结合水的功能：误认为结合水也直接参与代谢，导致判断代谢强度时出错。实际上结合水是结构水，不参与化学反应。
  • 误以为风干后细胞呼吸强度不变或升高：风干导致自由水锐减，酶活性降低，呼吸强度必然下降，而非升高。
  • 错误解读比值变化：风干后结合水与自由水的比值增大，即分子变大、分母变小，但有些学生将比值增大等同于自由水增多，造成反向选择。
  • 忽视种子休眠的生态意义：误认为风干后种子有机物消耗加速，其实消耗减慢正是利于长期贮藏的适应。

代表题精讲

题目（2018·新课标Ⅱ·4）：有些作物的种子入库前需要经过风干处理。与风干前相比，下列说法错误的是？选项：A. 风干种子中有机物的消耗减慢；B. 风干种子上微生物不易生长繁殖；C. 风干种子中细胞呼吸作用的强度高；D. 风干种子中结合水与自由水的比值大。

思路：先抓“风干”造成自由水显著减少这一核心事实，然后逐一审视选项，找出与自由水减少引发的代谢降低规律相矛盾的那个。

步骤： 1. 风干降低自由水含量→细胞呼吸相关的酶活性受抑，呼吸强度降低→有机物消耗减慢，故A对，C错（呼吸作用强度应为低，不是高）。 2. 微生物繁殖需要大量自由水，风干缺水环境不利其生长，B对。 3. 风干后自由水减少而结合水基本不变，结合水/自由水比值增大，D对。 4. 本题要求选“错误”，所以选C。

点评/变式：此类题抓住“水与代谢正相关”的核心，几乎所有变式（如干旱胁迫、种子上霜冻、干种子萌发吸水）都可归结为“自由水增→代谢升，自由水减→代谢降”。注意区分“结合水/自由水比值”与“自由水/结合水比值”，命题常在此设陷阱。变式训练可尝试：将风干种子与浸泡后的种子对比，问呼吸速率、有机物变化、抗寒性等。
