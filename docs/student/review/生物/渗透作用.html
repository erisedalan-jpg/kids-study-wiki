渗透作用

考点渗透作用权重20真题数3学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：20
  • 真题数：3；年份跨度：2011–2020
  • 出现题位：选择1 选择4 选择5
  • 难度分布：中2 易1

知识精要

  • 渗透作用定义：水分子（或其他溶剂分子）透过半透膜，从低浓度溶液向高浓度溶液的扩散。
  • 发生条件：
    • 具有半透膜。
    • 半透膜两侧的溶液存在浓度差（物质的量浓度差）。
  • 渗透方向：由低渗（低浓度、高水势）$\rightarrow$ 高渗（高浓度、低水势）。水分子从水相对多的一侧流向水相对少的一侧。
  • 动物细胞与植物细胞的比较：
    • 动物细胞：细胞膜相当于半透膜。当外界溶液浓度 $<$ 细胞质浓度时，细胞吸水膨胀甚至涨破；当外界溶液浓度 $>$ 细胞质浓度时，细胞失水皱缩；当内外浓度相等时，水分进出动态平衡。
    • 植物细胞：原生质层（细胞膜、液泡膜及二者之间的细胞质）具有选择透过性，相当于半透膜。细胞壁为全透性。当外界溶液浓度 $>$ 细胞液浓度时，细胞失水，发生质壁分离；当外界溶液浓度 $<$ 细胞液浓度时，细胞吸水，发生质壁分离复原。
  • 核心解题原理：
    • 水分移动看“物质的量浓度”。
    • 物质的量浓度 $\approx \frac{\text{质量浓度}}{\text{相对分子质量}}$。
    • 在同一质量浓度下，溶质的相对分子质量越大，其物质的量浓度越低。
    • 渗透压高低由单位体积内溶质微粒数决定，即由物质的量浓度决定。

解题方法与套路

  1. 第一步：明确半透膜与两侧溶液。区分到底是物理的半透膜还是生物膜（细胞膜、原生质层），并锁定膜两侧参与渗透的液体。
  2. 第二步：比较“物质的量浓度”。题干若给出“质量浓度”，且溶质分子量不同，必须通过“质量浓度 / 相对分子质量”估算物质的量浓度高低。切勿被质量浓度数字迷惑。
  3. 第三步：判断水的净流动与细胞形态变化。
    • 一旦明确哪侧溶液物质的量浓度高，水便更多地流向该侧。
    • 植物细胞关键判据：若细胞失水，原生质层与细胞壁分离（质壁分离）；若吸水至膨胀，由于存在细胞壁，细胞体积略增但通常不会涨破；若水进出动态平衡（净吸水量为零），宏观溶液浓度不变。
  4. 第四步：辨析实验条件与补充试剂影响：
    • 完全营养液浸泡：细胞处在等渗或相对高渗环境中，吸足了无机盐等溶质，细胞液浓度可能有所升高，导致吸水能力暂时改变。
    • 蒸馏水浸泡：细胞吸水，体积略胀，细胞液浓度被稀释降低。
    • 题干强调“在此期间没有溶质交换”，即溶质分子不能跨膜进出，此时只存在单纯的水分子移动。
  5. 第五步：结合特殊材料特征：哺乳动物成熟红细胞无细胞核和具膜细胞器，离心或低渗处理后易获得纯净的细胞膜；成熟植物细胞有大液泡，便于观察质壁分离。

高频易错

  • 混淆“质量浓度”与“物质的量浓度”：这是本题型最大陷阱。题目经常故意给出等质量浓度的两种糖溶液（如甲糖相对分子质量为乙糖的 2 倍），此时甲糖溶液的质量浓度虽相等，但由于分子量大，其物质的量浓度反而更低，水势更高。错误的直觉会导致弄反水的渗透方向。
  • 误将“浓度升高”单纯归因于溶质增加：若实验过程无溶质交换，溶液浓度升高只能是因为水分渗出到细胞中，导致溶剂（水）减少。错误选项常暗示细胞失水导致外界浓度升高，要理清逻辑。
  • 对“质壁分离”条件认知模糊：
    • 只有当外界溶液浓度（物质的量浓度）大于细胞液浓度时，细胞失水才发生质壁分离。
    • 若溶液浓度降低，只说明细胞排出了少量水甚至细胞吸水，不一定发生质壁分离，有可能是植物细胞从质壁分离状态复原，或者仅仅是正常细胞的微弱吸水。
  • 动植物细胞吸水结果混淆：植物细胞有细胞壁保护，吸水不会涨破；动物细胞无细胞壁，在蒸馏水中会吸水涨破。人红细胞没有液泡，错误选项常编造“液泡胀破”来考察动物细胞结构认知。
  • 忽视被动运输（自由扩散）的本质：水分子进出细胞是顺着相对含量梯度，属于被动运输（自由扩散或协助扩散），不消耗能量，绝非主动运输。一旦在水分跨膜运输类填空题中填“主动运输”即得零分。

代表题精讲

代表题一：2020-新课标Ⅱ-05

题目：取某植物成熟叶片，打孔获得叶圆片分别放入质量浓度相同的甲糖溶液（相对分子质量约为乙糖的 2 倍）和乙糖溶液中。平衡时甲组溶液浓度升高，期间无溶质交换。据此判断错误的是： A. 甲组叶细胞吸收了甲糖溶液中的水使甲糖溶液浓度升高 B. 若测得乙糖溶液浓度不变，则乙组叶细胞的净吸水量为零 C. 若测得乙糖溶液浓度降低，则乙组叶肉细胞可能发生了质壁分离 D. 若测得乙糖溶液浓度升高，则叶细胞的净吸水量乙组大于甲组

思路： - 核心条件：等质量浓度，但甲糖分子量大 → 物质的量浓度为甲糖 $<$ 乙糖。 - 宏观现象：甲糖溶液浓度升高，由于无溶质交换，一定是水分从外界进入了叶细胞，溶剂变少，溶质浓度被动上升。 - 选项辨析围绕水的流向与浓度变化的对应关系。

步骤： 1. 审清浓度单位类型：g/mL 代表质量浓度。甲相对分子质量≈2倍的乙 → 物质的量浓度：甲糖 $<$ 乙糖。 2. 分析甲组现象：甲糖溶液浓度升高，说明叶细胞大量吸水（甲溶液水势相对叶细胞更低？这里注意：实际上非原生质体状况；按题干现象反推即可），即甲组叶细胞处于高渗液，水从低浓度溶液流向了高浓度细胞。 3. 验证选项： - A：解释了“浓度升高”是因为失溶剂，无误，正确命题。 - B：若乙糖溶液浓度不变，即无净水分移动，正确。 - C：若乙糖溶液浓度降低，即水从叶细胞流向了外界（外界溶液变稀）。叶细胞失水，如果外界浓度过高，可发生质壁分离，描述“可能”严谨，正确。 - D：若乙糖溶液浓度升高，也是指外界水进入细胞。比较吸水量：D 项信誓旦旦乙组吸水大于甲组？题干已暗示甲组外界溶液浓度已经升高，即甲组吸水极多。而乙组若升高，到底谁多，取决于各自内外浓度差，不能简单位置论断“乙大于甲”。因此 D 项错误。 4. 选定错误项：D。

点评/变式：此题核心是拆解“等质量浓度异分子量糖类”的陷阱。变式训练时，可将乙糖改为同浓度的 NaCl 或蔗糖，进一步考察物质的量浓度换算。

代表题二：2011-新课标-04

题目：紫色洋葱外表皮分为两组，甲组先在完全营养液浸泡，乙组在蒸馏水浸泡，随后均置于 0.3 g/mL 蔗糖溶液中处理，一段时间后水分不再减少。比较甲乙两组细胞水分渗出量的大小及运输方式。

思路： - 区分预处理对不同组别细胞液浓度的改变。 - 渗透失水量取决于细胞液浓度与外界蔗糖溶液浓度之间的差距大小。 - 水分运输方式固定为被动运输，直接用此排除含“主动运输”的选项。

步骤： 1. 判断细胞状态： - 甲组（完全营养液）：吸收了无机盐，细胞液浓度相对较高（初始水势较低）。 - 乙组（蒸馏水）：细胞吸水膨胀，细胞液浓度被稀释变低（初始水势较高）。 2. 分析失水量：当统一放入高浓度蔗糖液（0.3g/mL）时，水从水势高处流向低处。 - 乙组细胞液更稀，与外界蔗糖溶液的浓度差更大，水渗出量也比甲组更多。 - 甲组细胞液自身浓度高，与外界蔗糖的差距相对较小，渗透失水少。 3. 判断运输方式：水分子进出细胞属于被动运输（自由扩散或协助扩散）。 4. 综合：渗出量甲组 $<$ 乙组，方式为被动运输。

点评/变式：本题与上体联动，渗透出发点无一例外都是比较溶质微粒数。变式中，若将“完全营养液”改为高浓度 KNO₃ 溶液，题目会结合“质壁分离自动复原”来出题。
