渗透压

考点渗透压权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 渗透压：溶液中溶质微粒对水的吸引力。溶质微粒越多，渗透压越高。水分子从低渗透压区域（低浓度）向高渗透压区域（高浓度）运动。
  • 植物细胞渗透作用的结构基础：原生质层（细胞膜、液泡膜及两层膜之间的细胞质）具有选择透过性，相当于半透膜；细胞液与外界溶液存在浓度差。
  • 质壁分离：外界溶液渗透压 > 细胞液渗透压时，细胞失水，原生质体体积缩小，与细胞壁分离。质壁分离复原：外界溶液渗透压 < 细胞液渗透压时，细胞吸水，原生质体体积恢复。
  • 自动复原：当溶质分子可被细胞选择性吸收时，细胞吸收溶质后，细胞液渗透压升高，即使外界仍有溶质，细胞也可吸水而发生自动复原（如题中物质A）。
  • 原生质体与细胞体积：原生质体指除去细胞壁的植物细胞部分。细胞壁全透性，伸缩性小，原生质体伸缩性大，因此质壁分离时细胞体积基本不变，原生质体体积明显缩小。

解题方法与套路

  1. 读坐标曲线：纵坐标为“原生质体相对体积”，体积减小代表失水质壁分离，体积增大代表吸水质壁分离复原。横坐标为时间，根据变化趋势分段分析。
  2. 判断渗透压对比：细胞吸水 → 细胞液渗透压 > 外界溶液渗透压；细胞失水 → 外界溶液渗透压 > 细胞液渗透压。注意“渗透压”比较是指溶液对水的吸引能力，即“浓度高者渗透压大”。
  3. 区分结构：原生质体体积变化 ≠ 细胞体积变化。由于细胞壁几乎不伸缩，细胞失水时细胞体积变化极小，而原生质体显著收缩。
  4. 分析溶质运动：若曲线出现先下降后上升（自动复原），说明溶质能够进入细胞，使细胞液浓度增大，重新吸水。不能认为物质“未进入”。
  5. 液泡与细胞质基质：液泡内液体（细胞液）与细胞质基质之间也存在渗透压差，但在质壁分离与复原宏观分析中，通常比较细胞液与外界溶液。注意题目是否要求比较液泡与细胞质基质的渗透压。

高频易错

  • 原生质体体积缩小，误认为细胞体积同样变化：细胞壁伸缩性极小，质壁分离时细胞体积基本不变，原生质体缩小是主要体现。
  • 看到溶质进入导致复原，误认为浓度没有变化：从曲线自动复原可知物质A可通过细胞膜，选项“0～4h内物质A没有通过细胞膜进入细胞内”是典型错误。
  • 渗透压与浓度的术语混淆：外界渗透压高 → 外界溶液浓度相对高，细胞失水。选项“物质A溶液的渗透压小于细胞液的渗透压”在吸水阶段才成立，失水阶段则相反。
  • 误判液泡渗透压与细胞质基质渗透压的关系：正常活细胞中，细胞质基质与液泡液间存在渗透平衡，失水时液泡液浓缩渗透压升高，可能导致短时差异，但常见考题只作细胞液与外界比较，此处该选项“0～1h内液泡中液体的渗透压大于细胞质基质的渗透压”无法从题干信息推出，且通常水分通过原生质层进出液泡是经细胞质基质，无需单独比较。
  • 忽视细胞壁全透性：物质A可以自由通过细胞壁，限制进入的主要是细胞膜和原生质层。

代表题精讲

题目：2017-新课标Ⅱ-04

将植物成熟细胞放入物质A溶液中，原生质体体积变化趋势为先下降(0～1h)，后上升(2～4h)。判断下列叙述正误。 A. 0～4h内物质A没有通过细胞膜进入细胞内 B. 0～1h内细胞体积与原生质体体积的变化量相等 C. 2～3h内物质A溶液的渗透压小于细胞液的渗透压 D. 0～1h内液泡中液体的渗透压大于细胞质基质的渗透压

思路

分析曲线走势：原生质体相对体积先降后升，说明先发生质壁分离，后自动复原。由此得出0～1h时外界渗透压 > 细胞液渗透压，细胞失水；2～3h时细胞液渗透压 > 外界渗透压，细胞吸水。自动复原说明物质A被吸收进入细胞，提高了细胞液渗透压。

步骤

  1. 排查A：因发生了自动复原，物质A已进入细胞，故A错误。
  2. 排查B：0～1h细胞失水，原生质体缩小，但细胞壁伸缩性小，细胞体积几乎不变，变化量不等，B错误。
  3. 排查C：2～3h原生质体体积增大，细胞吸水，所以细胞液渗透压高于外界溶液，即物质A溶液渗透压小于细胞液渗透压，C正确。
  4. 排查D：0～1h失水，液泡中液体因失水而渗透压升高，但细胞质基质与液泡液之间渗透平衡复杂，题干无信息支持该比较，且水分子跨原生质层进出液泡主要通过渗透压差，此处说法不成立，D错误。

点评/变式

本题核心考点是渗透作用引起的质壁分离与复原，结合曲线分析能力。考生易错在B项，忽略细胞壁特性导致原生质体与细胞体积变化不一致；A项需通过自动复原反推溶质进入；C项要求准确理解渗透压的比较对象。变式可改变物质种类（如甘油、KNO₃等可被吸收的溶质）或给出不同浓度梯度，考查同样原理。陷阱常设在“渗透压大于/小于”的比较对象和结构差异上。
