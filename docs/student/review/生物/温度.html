温度

考点定位

  • 父主题：生物与环境
  • 权重 weight：0
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 温度与水中溶氧量的关系：水温升高，气体溶解度下降，水中氧气含量随之降低。
  • 变温动物（如寒温带湖泊动物）的代谢速率随环境温度升高而增强，耗氧量增加。
  • 血红蛋白的适应：在低氧或高代谢需求下，动物可通过增加红细胞中血红蛋白含量来提高血液载氧能力，属于生理性适应。
  • 该调节方向为：水温升高 → 水中溶解氧减少、机体代谢增强 → 需要更多氧气 → 血红蛋白含量代偿性上升。

解题方法与套路

  1. 识别自变量与因变量链条：先看环境因子（水温）如何影响直接因变量（水中溶氧）；再看生物本身因变量（代谢强度、血红蛋白含量）如何响应。
  2. 抓住“适应”主线：生物在不利环境中往往通过代偿机制维持内稳态，顺着“条件变化→压力增大→补偿性调节”的箭头推理。
  3. 排除干扰选项：若曲线单纯下降，说明随水温升高血红蛋白减少，这与“需要更多氧气”矛盾；先升后降或先降后升通常对应双重因素的转折，此处无充足证据支持。

高频易错

  • 误以为水温升高直接导致血红蛋白变性或下降，选下降曲线（乙）。未考虑机体代偿性增强。
  • 忽略题干提供的“水中氧含量随水温升高而下降”这一条件，未将其与代谢需求结合，导致逻辑断链。
  • 误选先升后降的曲线（丙），主观认为过高温会抑制血红蛋白合成，但题干限定“一定温度范围内”，未触及温度伤害极限。

代表题精讲

题目（2010新课标-04）：已知水中氧含量随水温升高而下降。生活在寒温带湖泊中的某动物，其血红蛋白含量与水温有关。判断能正确表示一定温度范围内血红蛋白含量随水温变化趋势的曲线。（甲：上升；乙：下降；丙：先升后降；丁：先降后升）

思路：水温升高造成双重效应：①水中溶氧减少，动物的氧气来源受限；②变温动物代谢率随温度上升而提高，耗氧增加。为保障组织供氧，应增加血红蛋白含量以提升载氧能力。因此血红蛋白含量应随水温升高而单调升高，对应上升曲线。

步骤： 1. 提取关键信息：“水中氧含量随水温的升高而下降”。 2. 分析该动物：寒温带湖泊动物（通常为变温动物），水温升高 → 代谢增强。 3. 综合：氧气供应减少，而需求增加，需通过提高血红蛋白含量来补偿。 4. 确定趋势：血红蛋白含量随水温升高而增加，选上升曲线甲。

点评/变式：本题本质考查生物对环境温度变化的响应与生理适应。变式可设计为：给出不同温度下动物的呼吸频率、红细胞比容等数据，要求推断适应方向。解题核心始终是理清“环境变化→理化因子改变→生物需求变化→适应性调节”的因果链。
