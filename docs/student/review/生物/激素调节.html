激素调节

  • 父主题：稳态与调节

  • 真题数：3；年份跨度：2009–2021
  • 出现题位：选择2 选择3 选择9
  • 难度分布：中2 易1

知识精要

激素调节是动物稳态维持的核心机制，相关要点如下：

  • 激素的本质与作用：激素是内分泌腺（或内分泌细胞）分泌的微量、高效化学信息分子。其既不组成细胞结构，不提供能量，也不具催化活性。作用为传递信息、调节生命活动，作用后被灭活。
  • 调节方式：反馈调节——如甲状腺激素分泌的分级调节与负反馈；血钙调节中甲状旁腺素与降钙素的相互拮抗以维持稳态。
  • 激素作用的特点：
  • 微量和高效
  • 通过体液（主要是血液）运输——内分泌腺无导管，激素直接进入体液。
  • 作用于靶器官、靶细胞——激素与靶细胞的特异性受体结合，引发细胞响应。
  • 高中核心激素归纳

解题方法与套路

  1. 快速定位内分泌源头：根据题干信息（如腺体名称、细胞类型、生理效应），反推激素名称。尤其注意垂体的“促”字类激素、胰岛A/B细胞的血糖调节激素及甲状腺激素。
  2. 明晰运输途径：激素运输方式固定为通过体液（血液）运输，直接填“体液”几乎全覆盖。
  3. 梳理“激素—靶细胞—响应”逻辑链：
  4. 先确定激素，再锁定靶器官/靶细胞（常为激素特异性作用场所，如胰高血糖素-肝细胞，肾上腺素-心肌/肝细胞）。
  5. 靶细胞的响应是具体生理效应（如“促进肝糖原分解使血糖升高”“心率加快”），而非再次分泌激素（除非是垂体促激素作用于靶腺体）。
  6. 辨析激素本质：判断正误题中，牢记激素不是能源物质、不是催化剂、不是细胞结构。可据此直接排除“高能化合物”“催化活性”“作为细胞组分”等错误说法。
  7. 分析反馈与拮抗：遇到“血钙浓度”“血糖”等调节，立即联想负反馈与拮抗模型。某一物质浓度变化→调节激素分泌→反向作用恢复稳态，其中两个拮抗激素往往来自不同腺体，共同维持指标稳定。

高频易错

  • 错把激素当能源或酶：肾上腺素使心率加快是调节作用，不说明它是“高能化合物”；胰高血糖素促进分解是调节信号，不说明它有“催化活性”；胰岛素调节代谢，不“作为细胞结构组分”。
  • 混淆靶器官与最终效应器官：填写响应时，垂体促激素（如促甲状腺激素）的靶器官是甲状腺，其响应是“促进甲状腺分泌甲状腺激素”，而非“提高细胞代谢速率”（那是甲状腺激素的效应）。肾上腺素靶细胞可包含心肌细胞（对应心率效应）和肝细胞（对应升血糖效应）。
  • 忽视激素的灭活机制：误以为激素持续起作用。正确理解是激素一经靶细胞接受并起作用后就被灭活，体内需持续产生以维持含量动态平衡。
  • 混淆相似概念：甲状腺激素由甲状腺分泌，而非垂体。生长激素由垂体分泌。促激素释放激素由下丘脑分泌，促激素由垂体分泌。调节题目时常需精准定位到具体腺体。
  • 反馈调节对象判断失误：负反馈中，靶腺体(如甲状腺)产生的激素(甲状腺激素)反过来抑制的是下丘脑和垂体，而非直接抑制靶腺体自身。

代表题精讲

题目：2021全国乙卷表格填空题，要求围绕细胞间信息交流，完成内分泌腺/细胞、激素、靶器官/细胞及响应的对应关系。 思路：依据表格已给信息碎片，利用激素调节的特定对应关系，逆向或正向推导空缺内容。 步骤： 1. 胰岛素对应关系：由“胰岛B细胞”与“促进肝糖原合成”，直接填激素“(1)胰岛素”。 2. 促甲状腺激素对应关系：由“垂体”与“靶器官甲状腺”，结合垂体分泌的、作用于甲状腺的激素，填“(2)促甲状腺激素”。 3. 运输方式：激素运输栏目的通性，填“(3)体液”。 4. 肾上腺素靶器官：由“肾上腺分泌”与“心率加快”响应，反推靶器官为“(4)心脏（或心肌细胞）”。 5. 垂体—甲状腺—响应：由“垂体分泌促甲状腺激素”作用于“甲状腺”，推出靶细胞响应为“(5)促进甲状腺分泌甲状腺激素”。（注意是腺体分泌激素，而非全身代谢效应）。 点评/变式：本题考查激素调节的系统性，关键在于区分各级激素作用的直接靶点与最终效应。变式训练可把血糖、体温调节等类似模式挖空，强化“源头→激素→靶点→直接响应”的逻辑链训练。

题目：2018新课标Ⅱ卷选择题，判断关于人体内激素的正确叙述。 思路：逐一审查选项，利用激素“微量、高效、传递信息、不供能不催化非结构”的本质属性进行甄别。 步骤： - A ×：肾上腺素使心率加快，体现信息传递与调节，并不说明激素本身含高能量。 - B ×：胰高血糖素升血糖是信号调节，肝糖原分解靠酶，激素无催化活性。 - C ×：胰岛素加速糖原合成是调节代谢，绝不作为细胞结构组分。 - D √：青春期，性激素由性腺分泌，经体液运输，与靶细胞受体结合，促进机体发育，完全符合激素作用特点。 点评/变式：此题为典型的概念辨析题，陷阱多设置于将激素的作用（调节）与其本质（信息分子）混淆，并嫁接能源物质、酶、结构物质的功能于其上。应试时，只要牢记激素的唯一角色是“化学信使”，即可快速排除错误选项。
