激素运输

考点激素运输权重6真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：6
  • 真题数：1；年份跨度：2011–2011
  • 出现题位：选择5
  • 难度分布：易1

知识精要

  • 激素运输的基本方式：激素由内分泌腺（或内分泌细胞）分泌后，直接进入血液（或组织液、淋巴等体液），随体液（血液循环） 运输到全身各处。
  • 激素的作用特点：激素在体液中含量极低，但具有高效的生物活性。激素随体液到达全身，但仅能识别并结合特定靶细胞或靶器官表面或内部的受体，即作用具有特异性。
  • 神经调节与体液调节的核心区别：
  • 传递媒介：神经调节依靠电信号（神经纤维上传导）和化学信号（突触间传递）；体液调节的核心媒介是随血液循环运输的化学物质（如激素）。
  • 运输通道：神经冲动沿反射弧（神经纤维） 传导；激素通过血管等体液循环系统运输。
  • 作用范围：神经调节作用范围较局限、精准；体液调节作用范围较广泛。
  • 反射弧是神经调节的结构基础：一个完整的反射活动必须经过感受器、传入神经、神经中枢、传出神经和效应器五个环节。内脏神经属于传出神经的一部分。在任何涉及“反射”的调节过程中，均依赖完整反射弧。

解题方法与套路

针对判断“神经/体液/神经-体液”调节类型的考题，可采用以下通用“三步排查法”： 1. 结构基础辨析：若题干明确提到“反射弧”（含“传入/传出神经”“内脏神经支配”等）参与，则必定包含神经调节。此步骤是判断有神经调节的最高优先级。 2. 运输途径辨析：识别信号分子的运输通道。 - 若物质是“激素”，其运输途径必定是体液（血液循环）。凡出现“通过神经纤维运输激素/神经递质到靶器官”的选项，均为错误。 - 若物质是“神经递质”，它仅在突触间隙（组织液）中扩散，但产生和释放它的前提是神经冲动的传导。 3. 效应过程辨析：若过程由“某种刺激 → 内分泌腺 → 分泌激素 → 体液运输 → 靶器官反应”，且不含完整反射弧（或只有作为条件反射的启动环节），则为单纯的体液调节。若既有反射弧的参与，最终又有激素经由体液运输发挥作用，则该过程为典型的神经-体液调节。

高频易错

  • 致命错误：混淆神经调节与体液调节的运输载体。决不可认为“激素可以沿神经纤维运输”或“神经递质可以随血液循环远距离运输”。
  • 概念误解：误将“内脏神经支配内分泌腺”的活动，等同于“激素通过神经运输”。“内脏神经”只是传出信号指令，告知内分泌腺释放激素，激素释放入血后的漫长旅程全然不经过神经纤维。
  • 靶向作用与运输途径混淆：激素虽通过体液运输到全身，但只作用于具有特定受体的靶器官。选项若将“运输”和“作用”的逻辑故意颠倒，极易导致误判（如本题C选项，将体液运输说成靶向神经运输）。
  • 混用调节类型：无法区分“单纯体液调节”与“神经-体液调节”。含有“反射”“神经支配”的激素分泌活动，属于神经-体液调节，仅答“体液调节”属于不完全概括，但在具体辨析选择题时，更需关注各环节的具体表述是否错误。

代表题精讲

代表题：2011-新课标-05

  • 题目：人在恐惧、紧张时，内脏神经支配肾上腺髓质释放肾上腺素，该激素使心率加快。选出错误叙述。
  • 思路：本题要求选出“错误”选项，需通过“调节类型”、“运输方式”、“靶器官”和“结构基础”四个维度逐一核查选项。题干中“内脏神经支配”和“激素使心率加快”是两个关键点。
  • 步骤：
  • 审题抓关键：“内脏神经支配”对应神经调节；“肾上腺髓质释放肾上腺素”至“心率加快”对应激素发挥作用，即体液调节。整体属神经-体液调节。
  • 选项A核查（靶器官）：激素（肾上腺素）作用于心脏，心脏即为该激素的靶器官。A选项表述无误。
  • 选项B核查（调节类型）：有神经指令、有血液中激素的终末效应，包含神经与体液（激素）两种方式。B选项表述无误。
  • 选项C核查（运输途径）：此为高频错点。肾上腺素作为激素，由肾上腺分泌后必须进入血液运输到心脏，绝无可能通过神经纤维内部进行运输。C选项表述违反科学事实，为本题答案。
  • 选项D核查（结构基础）：反射弧是神经调节的结构基础，本题含神经调节环节（内脏神经传出），故存在反射弧结构。D选项表述无误。
  • 点评/变式： 本题无情揭露了一个极深的误区：“神经支配内分泌腺分泌激素”不等于“激素沿神经运输”。生理路径是：神经末梢释放指令 → 腺体分泌激素入血（体液）→ 循环系统运输 → 靶器官。变式考查中，常将“神经递质”与“激素”运输方式互换作为干扰项，务必分清递质在局部（突触间隙），激素在全身（血液）。
