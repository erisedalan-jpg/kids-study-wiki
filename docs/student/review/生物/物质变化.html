物质变化

考点物质变化权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：选择7
  • 难度分布：易1

知识精要

  • 光合作用物质变化
  • 光反应：$H_2O \rightarrow O_2 + NADPH + ATP$（场所在类囊体薄膜）
  • 暗反应（碳反应）：$CO_2$固定（$C_5 + CO_2 \rightarrow 2C_3$），$C_3$还原（$C_3 \xrightarrow{ATP,NADPH} C_5 + (CH_2O)$）（场所为叶绿体基质）
  • 有氧呼吸物质变化
  • 第一阶段：$C_6H_{12}O_6 \rightarrow 2C_3H_4O_3$（丙酮酸）$+4[H] +$少量ATP（细胞质基质）
  • 第二阶段：$2C_3H_4O_3 + 6H_2O \rightarrow 6CO_2 + 20[H] +$少量ATP（线粒体基质）
  • 第三阶段：$24[H] + 6O_2 \rightarrow 12H_2O +$大量ATP（线粒体内膜）
  • 关键物质比较
  • 光合作用$[H]$是$NADPH$（还原型辅酶Ⅱ）；呼吸作用$[H]$是$NADH$（还原型辅酶Ⅰ）
  • 光合作用ATP只用于暗反应，呼吸作用ATP用于各项生命活动
  • $C_3,C_5$变化规律：$C_5+CO_2 \rightarrow 2C_3$，光照强度或$CO_2$浓度骤变时，$C_3$与$C_5$含量变化相反

解题方法与套路

  1. 识别图解部位：先根据$[H]$、ATP的来源和去向区分光合作用的光反应（产生$O_2,NADPH,ATP$）与暗反应（消耗$CO_2,ATP,NADPH$，产生有机物）；再根据葡萄糖→丙酮酸、$O_2$消耗、$H_2O$生成等标志判断有氧呼吸各阶段。
  2. 确定字母/编号含义：
  3. 常见物质代号：光合作用中A常为$O_2$，B为$C_3$，C为$C_5$，D为$NADPH$或ATP；呼吸作用中E常为丙酮酸。
  4. 过程编号：①光反应，②暗反应$C_3$还原，③呼吸第一阶段，④呼吸第二阶段，⑤呼吸第三阶段。
  5. 分析ATP和$[H]$的来龙去脉：标记哪些过程产生ATP（光反应、呼吸三个阶段），哪些过程消耗ATP（暗反应、主动运输等），特别注意光合作用ATP仅用于碳反应。
  6. 突破条件骤变类问题：突然停止$CO_2$供应→$C_3$减少、$C_5$积累、ATP和$NADPH$利用受阻而积累；突然停止光照→$C_3$积累、$C_5$减少、ATP和$NADPH$缺乏。
  7. 同位素示踪：$H_2^{18}O$光解产生$^{18}O_2$；有氧呼吸第二阶段$C_3H_4O_3+H_2^{18}O \rightarrow C^{18}O_2$；标记$^{14}CO_2$则暗反应中依次出现$C_3$、$C_5$和有机物。

高频易错

  • 混淆两类$[H]$：光合作用$[H]$为$NADPH$，呼吸作用$[H]$为$NADH$；两者不能混用，它们在不同场所发挥作用。
  • ATP产生场所记错：有氧呼吸三个阶段均能产生ATP，但数量差异大；光合作用只有光反应产生ATP，暗反应不产生ATP。
  • $C_3$与$C_5$含量变化弄反：光照减弱时，$C_3$↑、$C_5$↓；$CO_2$供应不足时，$C_3$↓、$C_5$↑。记忆口诀“光多五少三多，碳多三多五少”常出错。
  • 误认为暗反应只在暗处进行：暗反应虽不直接需光，但需要光反应提供ATP和NADPH，因此长期无光暗反应也会停止。
  • 呼吸作用底物≠只有葡萄糖：蛋白质、脂肪等需通过不同途径进入呼吸作用（如乙酰辅酶A等），但高考示意图一般从葡萄糖开始。
  • 光合作用产生$O_2$只来自$H_2O$：光反应$2H_2O \rightarrow O_2+4[H]$，氧气中的氧全部来自水分子，并非来自$CO_2$。

代表题精讲

题目
某植物叶肉细胞光合作用和呼吸作用过程示意图中，字母A～D表示物质，数字①～④表示过程，请回答：（1）写出A、B、C、D的名称；（2）产生ATP的过程有哪些？（3）倘若突然停止$CO_2$供应，短时间内$C_3$和$C_5$的含量变化分别是？

思路
首先根据产生$O_2$和$[H]$、ATP的区域锁定光反应（A为$O_2$，①为光反应），随后暗反应中消耗$CO_2$和产物$C_3$（B）、$C_5$（C）再生；再从葡萄糖分解为丙酮酸（D）进入线粒体确定呼吸阶段，最后联系条件变化分析中间产物波动。

步骤
1. 由光反应水光解$2H_2O \rightarrow O_2+4[H]+ATP$确定A为$O_2$，过程①为光反应，产生的$[H]$和ATP用于暗反应。 2. 暗反应中$CO_2$与$C_5$（C）结合生成$C_3$（B），故B是$C_3$，C是$C_5$；过程②为$C_3$的还原。 3. 有氧呼吸第一阶段葡萄糖分解为丙酮酸，故D为丙酮酸（$C_3H_4O_3$）；过程③为呼吸第一阶段。 4. 产生ATP的过程：光反应①、有氧呼吸第一阶段③、第二阶段、第三阶段均可产生ATP（注意若示意图未标明全部呼吸阶段，则按图示答）。 5. 突然停止$CO_2$供应，$CO_2$固定停止，$C_5$消耗减少而积累，$C_3$生成停止但其还原仍消耗$C_3$，故$C_3$减少，$C_5$增加。

点评/变式
此类示意图题的本质是考查光合与呼吸过程的物质转化逻辑。变式可改变光照强度、标记同位素位置等，核心仍是抓住“光反应供氢供能、碳反应耗氢耗能”“呼吸三阶段递进氧化”。建议自己绘制空白图解，反复填写物质名称和$[H]$、ATP数量，以强化记忆网络。
