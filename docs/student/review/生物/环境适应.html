  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 环境适应是指生物在形态结构、生理功能和生活习性等方面与所处环境相协调的现象，是自然选择的结果。高考常以植物对光照强度、温度、水分等因素的适应为载体。
  • 阳生植物与阴生植物叶片的适应特征
    | 比较项目 | 阳生叶（树冠上层） | 阴生叶（树冠下层） |
    |----------|-------------------|-------------------|
    | 叶片厚度 | 较厚，角质层发达 | 较薄，角质层薄或无 |
    | 叶肉细胞层 | 栅栏组织发达，多层紧密 | 海绵组织发达，栅栏组织单层稀疏 |
    | 叶绿体 | 数目多，体积小，类囊体垛叠少 | 数目少，体积大，类囊体垛叠多 |
    | 叶绿素a/b值 | 较高，利于吸收强光 | 较低，叶绿素b相对含量高，吸收弱光能力强 |
    | 呼吸速率 | 高（线粒体数目多，酶活性高） | 低 |
    | 光补偿点 | 高 | 低 |
    | 光饱和点 | 高 | 低 |
    | 最大净光合速率 | 高 | 低 |
  • 净光合速率 = 总光合速率 - 呼吸速率。曲线与纵轴交点（光照强度为0）的绝对值代表呼吸速率；曲线与横轴交点代表光补偿点（光合=呼吸）；曲线最高点对应的光照强度为光饱和点。
  • 光合色素提取与分离：提取用无水乙醇（或95%乙醇+碳酸钙/二氧化硅保护），分离用层析液（石油醚:丙酮:苯混合液）。叶绿素a和b主要吸收红光和蓝紫光，吸收峰不同。

解题方法与套路

  1. 曲线分析“三看”法
    （1）看起点：光照强度为零时，净光合速率负值的绝对值 = 呼吸速率。
    （2）看转折：曲线上升达到平稳或下降的拐点，对应光饱和点；与横轴交点对应光补偿点。
    （3）看趋势和差异：不同曲线（如A、B叶）在同一光照下的净光合速率高低、饱和点高低，反映对光环境的适应差异。
  2. 限制因素推断
  3. 若光合速率随光照增强不再升高，限制因素可能是CO₂浓度、酶活性等。
  4. 若净光合速率下降而胞间CO₂浓度升高 → 非气孔因素限制（如光合酶活性受抑、叶绿体结构受损），此时CO₂利用减少导致积累。
  5. 若净光合速率下降且胞间CO₂浓度也下降 → 气孔导度降低引起CO₂供应不足（气孔因素）。
  6. 实验类题目
  7. 色素提取：研磨时加SiO₂（研磨充分）、CaCO₃（防止叶绿素破坏），用无水乙醇溶解色素。
  8. 变量分析与对照设计：定性判断叶绿素a/b比可通过观察滤纸条上色素带宽度比值。

高频易错

  • ❌ 呼吸速率判断错误：将光照为零时净光合速率值（负值）的绝对值视为呼吸速率正确，但误认为两曲线目测比较即可，忽略零点数值精准读数。
  • ❌ 胞间CO₂浓度变化归因单一：认为光合下降必然由气孔关闭引起。当测得胞间CO₂浓度升高时，反而说明“非气孔限制”，常见原因如高温抑酶、强光破坏光合系统、光合产物积累反馈抑制等。
  • ❌ 光补偿点与光饱和点混淆：光补偿点是净光合速率为零的光照强度，光饱和点是净光合速率达到最大时的最低光照强度。阴生叶饱和点低，补偿点也低；阳生叶两者均高。
  • ❌ 提取与分离试剂错用：提取叶绿素用无水乙醇，分离色素用层析液；碳酸钙防破坏，二氧化硅助研磨。色素分离原理是溶解度不同，不是分子大小。
  • ❌ 总光合速率与净光合速率误算：总光合速率 = 净光合速率 + 呼吸速率，在光照下从曲线直接读出的是净光合速率，不能直接代表真光合强度。

代表题精讲

题目（2018·新课标Ⅱ，8题）

为研究树冠上下层叶片光合特性，取A（上层）、B（下层）两种叶片测定净光合速率随光照强度的变化曲线（图略）。回答问题：（1）比较A、B叶片呼吸速率的大小；（2）光照强度达一定数值后A净光合速率下降，而胞间CO₂浓度较高，分析原因；（3）提取叶绿素常用的有机溶剂。

思路

（1）呼吸速率应从曲线光照强度为0时对应纵坐标的绝对值比较；图中A的负值更大，呼吸速率更高。（2）净光合下降但胞间CO₂高，排除气孔关闭，应从光合作用暗反应利用CO₂能力下降角度解释。（3）记忆知识。

步骤

  • （1）光照为0时，净光合速率代表呼吸速率（氧消耗/CO₂释放）。由图可见A叶片纵轴截距更负，呼吸速率大于B。原因是阳生叶呼吸酶活性高，线粒体多，提供更多能量支持生长。
  • （2）光照过强时，A叶片净光合下降，说明光合作用总能力降低（光抑制）；但胞间CO₂浓度高，表明CO₂没有减少，而是利用受阻。原因：强光下叶绿体类囊体受损或暗反应相关酶活性受抑制，导致固定CO₂的速率变慢，CO₂在细胞间隙积累。
  • （3）常用有机溶剂：无水乙醇（或体积分数95%的乙醇，可加入少量碳酸钙防破坏）。

点评/变式

本题典型体现“环境适应”中植物叶片结构-功能相统一。常考变式：①将A、B叶片置于不同光强下测定光合参数，分析阴生/阳生植物特征；②结合气孔导度、胞间CO₂浓度变化综合分析光合“午休”现象的调节机制；③提取色素后，滤纸条上两条叶片色带宽度差异，推测叶绿素a/b比大小与光环境的关系。
