琼脂糖凝胶电泳

考点琼脂糖凝胶电泳权重6真题数1学科生物父主题生物技术与工程

考点定位

  • 父主题：生物技术与工程
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择7
  • 难度分布：中1

知识精要

  • 原理：琼脂糖凝胶具有分子筛效应和电泳效应。DNA分子在碱性缓冲液中带负电荷，在电场中由负极向正极移动。
  • 迁移率影响因素：
  • 凝胶浓度：浓度越大，凝胶孔径越小，有效分离的DNA片段越小。低浓度凝胶（0.3%~0.5%）适合分离大片段DNA（20 kb以上），高浓度凝胶（1.5%~3.0%）适合分离小片段DNA（0.1~3 kb）。
  • DNA分子大小：分子越大，在凝胶中迁移阻力越大，迁移速率越慢；分子越小，迁移越快。
  • DNA构型：对于质粒DNA，相同分子量下超螺旋（共价闭合环状）迁移最快，线性次之，开环最慢。
  • 电场强度：低电压时迁移率与电压成正比，但电压过高会导致条带扩散并降低大片段分辨率。
  • 凝胶制备关键点：称取琼脂糖 → 加热溶解于电泳缓冲液（如TAE或TBE）→ 冷却至60 ℃左右加入核酸染料（如EB、GelRed）→ 倒入插好梳子的制胶槽凝固。
  • 缓冲液：常用TAE（适合大片段，缓冲容量较低，电泳时间不宜太长）和TBE（适合小片段，缓冲容量高，长时间电泳稳定）。缓冲液维持pH并传导电流。
  • 指示剂：上样缓冲液中含溴酚蓝（在0.5×TBE中约迁移相当于300 bp线性双链DNA）和二甲苯青（约迁移相当于4 kb），可指示电泳进程。
  • 结果鉴定：电泳后紫外灯下观察荧光条带，通过与DNA分子量标准（Marker）比对判断PCR产物大小及特异性。

解题方法与套路

  1. 审题抓关键信息：分清实验目的（鉴定PCR产物、分离不同片段、检测基因型等），找出涉及变量（凝胶浓度、电压、缓冲液种类、上样量等）。
  2. 匹配凝胶浓度与DNA片段大小：给出的DNA片段大小决定适宜凝胶浓度范围，题目中若出现“分离5 kb和10 kb片段却使用2%凝胶”即为错误。
  3. 注意缓冲液与染料使用条件：TAE与TBE不可混淆，染料需在冷却后加入避免高温破坏，上样缓冲液的作用是增加密度和显色。
  4. 迁移规律正确推理：小片段在前，大片段在后；超螺旋质粒比线性质粒更快。
  5. 排除绝对化表述：如“所有DNA在琼脂糖凝胶中都带正电荷”“电压越高分辨率越高”等典型错误说法。

高频易错

  • 凝胶浓度选择僵化：误认为一种浓度可分离所有片段大小。实际必须根据待分离片段大小调整浓度。
  • 忽视DNA构型影响：误以为分子量相同的超螺旋、线性和开环DNA迁移速率相同，忽略构型差异。
  • 缓冲液使用错误：用水代替缓冲液或混淆TAE与TBE用途。
  • 染料加入时机：在琼脂糖未溶解或温度过高时加入核酸染料，导致染料降解或挥发污染。
  • 电压与分辨率关系颠倒：认为电压越高条带越清晰，实际高电压产生热量，使带扩散，降低大片段分辨率。
  • 终产物判断偏差：PCR产物若出现非特异性条带或引物二聚体，在电泳中容易被误判为目标条带；忽略阳性、阴性对照的重要性。
  • 上样缓冲液成分误解：误以为溴酚蓝等染料能与DNA结合发荧光，实际它们是肉眼可见指示剂，核酸染料才与DNA结合发出荧光。

代表题精讲

[代表题] 2024-辽宁-07

题目：关于采用琼脂糖凝胶电泳鉴定PCR产物的实验，下列叙述正确的是
选项A：琼脂糖凝胶浓度的选择需考虑待分离DNA片段的大小。

思路：本题考察琼脂糖凝胶电泳的核心原理及操作要点。需要结合凝胶浓度与DNA片段大小的对应关系、电泳条件等基础知识，逐项分析选项叙述是否符合实验实际。

步骤： - 审阅选项A：琼脂糖凝胶的分子筛效应由其浓度决定，浓度越高，凝胶孔径越小，适合分离的小片段DNA范围越窄。因此，选择凝胶浓度时必须以待分离DNA片段的大小为依据，比如分离500 bp产物常用1.2%~1.5%凝胶，而分离5 kb以上片段宜用0.5%~0.7%凝胶。该叙述科学、正确。 - （其他选项常规错误类型举例，如：使用高电压有利于提高所有片段的分辨率；上样缓冲液中的溴酚蓝与DNA结合发出荧光；电泳时DNA由正极向负极移动等。本题答案为A。）

点评/变式： - 本题直接考查对凝胶电泳基本知识点的记忆和理解，是典型“条件-结果”搭配判断题。 - 变式1：给出PCR产物大小和给定的凝胶浓度，判断是否可以有效分离。 - 变式2：给出电泳图谱，要求学生根据条带迁移距离反推凝胶浓度是否合适。 - 复习时要将“片段大小-凝胶浓度”对照表内化，同时注意与聚丙烯酰胺凝胶电泳（测序胶，用于分离小片段或单链DNA）鉴别，防止混淆。
