生态金字塔

考点生态金字塔权重7真题数1学科生物父主题生物与环境

考点定位

  • 父主题：生物与环境
  • 权重 weight：7
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 生态金字塔：将生态系统各营养级的能量、生物量或个体数量按营养级顺序由低到高排列的图形结构。
  • 三种类型：
  • 能量金字塔：以各营养级所含总能量（单位：$kJ/(m^2·a)$ 等）为尺度。能量沿食物链逐级递减，传递效率通常为 $10\%\sim20\%$，故能量金字塔在任何生态系统中永远呈正金字塔形（下宽上窄），不可倒置。
  • 生物量金字塔：以各营养级现有有机物质总量（干重，$g/m^2$ 等）为尺度。多数陆地生态系统中为正金字塔形，但在浮游植物→浮游动物的水生生态系统中，可能呈现倒金字塔形（因浮游植物个体小、繁殖快、现存生物量暂时较低）。
  • 数量金字塔：以各营养级生物个体数目（个）为尺度。其形状取决于生产者与消费者个体大小差异：生产者个体小而多（如牧草），则呈正金字塔形；生产者个体大而少（如一棵乔木），可能呈倒金字塔形（一棵树上可栖息大量昆虫）。
  • 适用条件：金字塔类型不同，倒置可能性不同；能量金字塔从不倒置，数量金字塔和生物量金字塔可出现倒置。

解题方法与套路

  1. 锁定金字塔类型：仔细审题，明确考查的是数量金字塔、生物量金字塔还是能量金字塔，注意关键词“生物个体的数量”“生物量”“能量”。
  2. 判断生产者与消费者个体大小关系：如果考查的是数量金字塔，比较第一营养级（生产者）与第二营养级（初级消费者）的个体大小和单位面积数量。生产者个体远小于消费者，通常为正金字塔；生产者个体远大于消费者，且一棵植物上可生活多个消费者，则可能为倒金字塔。
  3. 排除能量金字塔干扰：不论情境如何，能量金字塔一定为正金字塔，若题目混入“能量”字眼，可直接排除倒置选项。
  4. 结合典型实例记忆：夏季草原牧草（多而小）→羊（少而大）为正金字塔形；森林乔木（一棵树大而少）→昆虫（多而小）为倒金字塔形。水生生态系统的生物量金字塔常倒置。
  5. 读选项逻辑：题目常考两种生态系统的数量金字塔形状对比，先单独判断，再组合选择。

高频易错

  • 混淆金字塔类型：误以为所有生态金字塔都可倒置，或误以为数量金字塔永远是正金字塔形。记住能量金字塔永不倒置，数量和生物量金字塔在一定条件下可倒置。
  • 忽略生产者个体大小：分析数量金字塔时，不关注第一营养级的单位个体大小，只凭“草原”“森林”等词随意判断。草类个体小、数量极多，乔木个体大、数量相对较少，这一差异决定金字塔的正倒。
  • 混淆森林生态系统的营养级：误认为森林生态系统中第一营养级（乔木）数量一定很多，实际上按个体数量计，一株乔木是一个个体，其数量远小于其上的昆虫。因而森林的数量金字塔常呈倒置。
  • 将生物量金字塔与数量金字塔记反：水生生态系统中生物量金字塔经常倒置（浮游植物现存量低于浮游动物），而数量金字塔通常正置（浮游植物个体数量远多于浮游动物）。需区别记忆。

代表题精讲

代表题：2019-新课标Ⅱ-06

题目：如果食物链上各营养级均以生物个体的数量来表示，并以食物链起点的生物个体数作底层来绘制数量金字塔，则只有两个营养级的夏季草原生态系统（第一营养级牧草，第二营养级羊）和森林生态系统（第一营养级乔木，第二营养级昆虫）数量金字塔的形状最可能是
A．前者为金字塔形，后者为倒金字塔形
B．前者为倒金字塔形，后者为金字塔形
C．前者为金字塔形，后者为金字塔形
D．前者为倒金字塔形，后者为倒金字塔形

思路：本题明确考查“数量金字塔”，并给出两个具体生态系统的生产者与消费者。草原第一营养级牧草个体极小、数量极大，第二营养级羊个体大、数量少 → 正金字塔形；森林第一营养级乔木个体极大、数量少（一棵树即一个个体），第二营养级昆虫个体小、数量多 → 倒金字塔形。两者组合直接选A。

步骤：
1. 确认金字塔类型：数量金字塔。
2. 分析草原：牧草（无数棵小草）→ 数量多；羊→ 数量少 → 下宽上窄，正金字塔形。
3. 分析森林：乔木（一株大树）→ 数量极少（底层窄）；昆虫（大量）→ 数量多（上层宽）→ 下窄上宽，倒金字塔形。
4. 组合：前者正，后者倒，对应A项。

点评/变式：
- 点评：此题关键不在记忆，而在抓住“个体数量”和“生产者个体大小”的直观对比。只要区分开两种生态系统，答案一目了然。能量金字塔是强干扰，但题干已明确“数量”，需保持警惕。
- 变式：若将“数量金字塔”改为“生物量金字塔”，夏季草原仍为正金字塔，但森林（乔木生物量极大，昆虫生物量较少）多为正金字塔形；若改为水生浮游植物→浮游动物的生物量金字塔，则可能呈现倒置。进一步可结合能量流动和物质循环综合设问，务必辨清金字塔的尺度单位。
