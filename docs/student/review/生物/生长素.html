总览数学物理化学生物

生长素

考点生长素权重18真题数3学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：18
  • 真题数：3；年份跨度：2019–2024
  • 出现题位：填空13 选择7
  • 难度分布：中2 易1

知识精要

  • 生长素的合成与运输：主要在芽、幼叶等分生组织合成；运输方式为极性运输（从形态学上端向形态学下端运输），受重力、单侧光等影响可发生横向运输。
  • 生长素的生理作用：具有两重性——低浓度促进生长，高浓度抑制生长（根、芽、茎最适浓度不同，根最敏感）。促进细胞伸长、细胞分裂（细胞核分裂）、诱导维管组织分化等。
  • 细胞分裂素与生长素的协同：在细胞分裂中，生长素促进细胞核分裂，细胞分裂素促进细胞质分裂，二者共同调控细胞周期中 G₁→S、G₂→M 的转换。
  • 环境信号调控：光信号受体包括光敏色素（感受红光/远红光）等；其他环境因素如温度（春化作用）、重力等通过影响激素分布调节生长。
  • 实验设计原理：琼脂块可收集、转移生长素；云母片/玻璃片阻断运输；通过弯曲角度（α角）半定量反映生长素浓度差异。

解题方法与套路

  1. 生长素浓度与生长关系的判断
    理清“含量”与“促进/抑制”的对应：高浓度抑制时，常伴随生长减缓、根长缩短等表型。结合图表数据直接比较浓度和长度变化。
  2. 激素间协同与拮抗的分析
    细胞分裂素与生长素分工明确，看清实验检测指标（如基因表达量、蛋白活性），推断激素含量或功能变化对结果的影响。
  3. 运输阻断与收集实验的分析
    云母片插入方向决定阻断类型（横向/纵向）；琼脂块位置决定收集的生长素来源。比较不同处理组弯曲角度，可逆推生长素分布与合成量。
  4. 基因表达量与激素含量的转化
    合成酶基因表达↑ → 激素含量↑；水解酶基因表达↑ → 激素含量↓。切勿直接将基因表达量等同于激素含量，需综合合成与降解的净效应。
  5. 环境因素类填空
    光受体答“光敏色素”（高等植物主答此）；环境因素答“温度、重力、水分”等常规项，避免超纲词汇。

高频易错

  • 基因表达量 ≠ 激素含量：如砷处理6h时细胞分裂素合成酶基因表达远高于水解酶基因，净效应是含量增加，而非减少（易误选A）。
  • 生长素高浓度抑制不意味着直接导致吸收能力下降：抑制根生长会间接降低吸水吸肥能力，但若题目问砷的直接毒害机制，主要在于激素平衡紊乱。
  • 细胞分裂中生长素的作用模糊：易混淆生长素主要促进细胞核分裂，细胞分裂素主要促进细胞质分裂，填空需精准。
  • α角形成描述不完整：仅写“生长素促进生长”不给全分，需点明“琼脂块中生长素进入左侧，左侧浓度高于右侧，导致左侧生长快于右侧，形成弯曲角度”。
  • 极性运输方向用词不准：只能是“形态学上端→形态学下端”，不能简写“从上到下”。
  • 琼脂块收集实验的推理疏漏：乙组左右琼脂块浓度基本相同但小于甲组总量，说明云母片阻断了尖端内生长素的横向再分配，但总合成量不变，导致两侧均分后单侧浓度低于甲组未分离的量。

代表题精讲

【代表题1】2024·辽宁·13

题目
研究砷抑制拟南芥根生长机制，通过图1（细胞分裂素合成酶与水解酶基因表达）、图2（根长）、图3（生长素含量）数据，选择错误推测。

思路
根据基因表达量的相对高低推断激素含量的净变化；联系生长素的两重性，判断浓度—生长的对应关系；基于LOG2基因表达变化推测其蛋白功能。

步骤
- A项：图1显示合成酶基因表达远高于水解酶基因，故细胞分裂素含量应增加而非减少 → A错误，即符合题意。
- B项：图2、3显示砷处理组生长素含量高于对照，但根长显著缩短，符合生长素高浓度抑制生长 → B正确。
- C项：砷处理延长使LOG2基因表达减少，提示该基因产物可能减轻毒害；增强其活性可缓解抑制作用 → C正确。
- D项：根长抑制使吸收面积减小，间接导致水分和矿质吸收能力下降 → D正确。
选A。

点评/变式
变式可设问：若用外源细胞分裂素处理砷胁迫根，预测根长度变化。需知过高的细胞分裂素也可能打破激素平衡，不一定恢复生长。

【代表题2】2023·新课标·07

题目
考查细胞周期的物质准备、生长素与细胞分裂素在细胞分裂中的分工、光信号受体及环境因素。

思路
基础知识直接填空，注意术语准确性和并列项的完整性。

步骤
（1）分裂间期的物质准备：DNA分子复制和有关蛋白质的合成。
（2）生长素主要促进细胞核的分裂；细胞分裂素主要促进细胞质的分裂。
（3）光受体答“光敏色素”即可得分（其他如隐花色素、向光素亦正确但非必备）；环境因素答“温度、重力”（或“水分”“氧气”等中的两个）。

点评/变式
本题体现“长句表述”得分点：如（2）中务必点明“核”“质”之分，写成“促进细胞分裂”不得分。复习时需将教材黑体字原话精准记忆。

【代表题3】2019·新课标Ⅱ·07

题目
胚芽鞘顶端用云母片隔开与否，琼脂块收集生长素后测量弯曲角度，解释原因。

思路
明确极性运输与横向运输的阻断效应，根据弯曲角度反推生长素浓度差异。

步骤
（1）极性运输方向：从形态学上端到形态学下端。
（2）α角成因：琼脂块中生长素扩散进入胚芽鞘切段左侧，左侧浓度高于右侧，左侧生长快于右侧，向右弯曲。
（3）乙组左右琼脂块α角相近且小于甲组：云母片完全阻断了尖端内生长素向一侧的横向再分配，左右两侧收集的生长素含量基本相同；未阻隔的甲组全部生长素聚集于一侧，浓度更高，故角度更大。

点评/变式
若将云母片改为插入一半，则左右仍会有差异，可设计新题。弯曲角度大小与生长素浓度关系并非线性，但在一定范围为正相关，试题默认这一条件。
