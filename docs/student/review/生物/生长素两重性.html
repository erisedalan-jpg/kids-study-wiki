生长素两重性

考点生长素两重性权重6真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：6
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 生长素作用特性——两重性
  • 核心定义：生长素在低浓度时促进生长，在高浓度时抑制生长，甚至杀死植物。
  • 最适浓度：存在一个促进效果最强的浓度（如图中使弯曲角度 $\alpha$ 达到最大的浓度），低于或高于此浓度，促进效果均减弱。
  • 相同效果：一个低浓度和一个高浓度的生长素溶液，可以因均不等于最适浓度而产生完全相同的生理效应（如本题中产生相同的弯曲角度$\alpha$）。
  • 浓度-效应曲线：典型的“钟形”或“倒钟形”曲线，以最适浓度为界，左侧为促进作用递增区间，右侧为促进作用递减（或转入抑制）区间。

解题方法与套路

  1. 确认效应指标：明确题意中衡量生长素作用效果的指标（如本题的弯曲角度 $\alpha$），将其与“促进/抑制”定性或定量对应。
  2. 识别曲线类型：看到“相同效应值对应两个不同浓度”的现象，立即关联生长素作用的两重性（或“双重性”）。生成 $\alpha$ 的曲线具有峰值，峰值两侧必然存在效应相同而浓度不同的点。
  3. 设计区分实验（浓度稀释法）：当遇到未知浓度（已知效应值为 $\alpha_1$）且需在对应的A（低浓度）、B（高浓度）中区分时，采用稀释法：
  4. 原理：适度稀释后，若原液为低浓度A，作用效果减弱；若原液为高浓度B且仍处于促进效应上升段（稀释后向最适浓度靠近），作用效果增强。
  5. 操作：将待测液稀释一定倍数(如80%)，再次测量效应值 $\alpha_2$。
  6. 推断结论：
    • 若 $\alpha_2 < \alpha_1$，稀释后效应下降 → 原液为较低浓度A。
    • 若 $\alpha_2 > \alpha_1$，稀释后效应上升 → 原液为较高浓度B。

高频易错

  • 死记“低促高抑”：部分题目背景（如本题茎段弯曲）涉及的浓度范围可能全程都表现为“促进” ，仅是比较哪个浓度促进效果更强。只要出现“两重性”或相同效应对应两个浓度，即可运用此特性解题，不必硬套“抑制”字眼。
  • 混淆浓度方向与效应变化：在稀释法判断中，误以为稀释只会导致效应下降。必须紧扣曲线：若原液处于最适浓度右侧（高浓度侧），向左侧稀释会增强效应。
  • 逻辑推理不严密：写结论时，必须将 $\alpha_2$ 与 $\alpha_1$ 的大小关系和对应的浓度类型（A或B）完全匹配，二者互为充要条件，不可颠倒。

代表题精讲

题目（2010-新课标）简述：从黄化苗切取茎段纵切，浸没在不同浓度生长素溶液中，茎段半边茎向切面侧弯曲生长形成弯曲角度$\alpha$（图甲），$\alpha$与生长素浓度关系如图乙。 （1）解释“在两个不同浓度下$\alpha$相同”的原因。 （2）未知浓度溶液测得$\alpha_1$，对应图乙中低浓度A、高浓度B。将溶液稀释至80%再测，得$\alpha_2$。预测结果并得出结论。

思路 题（1）与题（2）紧密围绕生长素作用两重性的核心曲线特征：存在最适浓度产生最大效应，两侧可有效应相同的对称点。题（2）利用稀释改变浓度，根据效应值变化与曲线走向的关系反推原浓度位置。

步骤 1. （1）原因分析： - 生长素的作用具有双重性。 - 图乙显示存在一个最适生长素浓度，使$\alpha$最大。 - 在低于或高于该最适浓度时，均可产生小于最大值的相同$\alpha$。 2. （2）操作预测与结论： - 将待测液稀释为原浓度的80%后测量 $\alpha_2$。 - 情况一：若原液为低浓度A，稀释使其浓度更低，作用效果减弱 → 预测结果：$\alpha_2 < \alpha_1$。 → 得出结论：该溶液的生长素浓度为A。 - 情况二：若原液为高浓度B（且假设B稀释后仍在促进效应上升段），稀释使其向最适浓度靠近，作用效果增强 → 预测结果：$\alpha_2 > \alpha_1$。 → 得出结论：该溶液的生长素浓度为B。

点评/变式 本题是生长素两重性在实验分析中的经典应用，图像信息与原理紧密结合。解题的关键在于将“角度相同”抽象为“效应相同”，进而调用两重性曲线模型。浓度稀释判定法可推广至所有具有“钟形”剂量-效应曲线的生化调节类题目。注意：在高浓度B侧，务必默认稀释后的浓度依然在促进效果随浓度降低而升高的区段，否则若稀释后进入另一侧的低效区间，结论将失效，但高考答题通常以标准模型为准。
