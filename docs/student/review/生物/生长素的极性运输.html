生长素的极性运输

考点生长素的极性运输权重1真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：1
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 生长素的合成部位：主要在幼嫩的芽、叶和发育中的种子等具有分生能力的组织，胚芽鞘尖端是典型的合成部位。
  • 极性运输（纵向运输）
  • 方向：只能从形态学上端向形态学下端运输，不可逆转。
  • 实质：主动运输，需要载体蛋白并消耗 ATP，可由呼吸抑制剂阻断。
  • 常见实验证据：将含生长素的茎段正放（形态学上端在上）时，生长素可向形态学下端输出；倒置后则不能。
  • 非极性运输：在成熟组织中通过韧皮部进行，方向与形态学无关，可双向。
  • 横向运输：发生在胚芽鞘尖端等幼嫩部位，由单侧光、重力等单向刺激引起（如从向光侧→背光侧），分布不均触发向性运动。
  • 生长素作用的基本模式：尖端合成 → 极性运输到伸长区 → 调节生长；不均匀分布导致弯曲生长。

解题方法与套路

  1. 定位合成与接收：先找出能合成生长素的部位（通常为尖端、芽等），以及需要生长素才发生弯曲或生长的下部区域。
  2. 判明形态学方向：对于植株地上部分，远离地面的方向为形态学上端，近地端为形态学下端。切段接入时，须判定其放置方向。
  3. 追踪运输路径：生长素从合成处输出，必须沿形态学上端→下端的路径进入下端，方能发挥作用。若接入的切段被倒置，则形态学上端朝向下方，生长素无法运输到下部。
  4. 叠加横向运输：若存在单侧光、重力等刺激，还要分析尖端内横向运输造成的分布差异，但前提是能正常进行极性运输。
  5. 对照选项排除：常见干扰项会混淆“能否合成”与“能否运输”，抓住“合成部位正常但运输方向被阻断”这一关键逻辑。

高频易错

  • 将合成能力等同于运输能力：尖端都能合成生长素，但如果接入切段被倒置，极性运输被阻断，下部照样得不到生长素。
  • 忽略形态学上、下端的判断：把切段的正放、倒放理解为简单的空间位置颠倒，而忘记对茎而言形态学上端始终是原本靠近顶芽的一端。
  • 混淆横向运输与极性运输的方向性：单侧光只影响尖端内部的横向运输，不影响纵向极性运输的方向，极性运输不为光所改变。
  • 误认琼脂块实验与植物组织相同：琼脂块中的生长素是扩散，没有极性；而植物组织切段中的运输才具有严格极性，不能任意类推。

代表题精讲

2012·新课标·05

题目
取生长一致的燕麦胚芽鞘，切除 a、b 两组尖端下方一段，再从 c、d 两组对应位置切取等长切段，按图中方式接入 a、b（a′组接入正常方向切段，b′组接入倒置切段），单侧光照射后 a′组向光弯曲生长，b′组无弯曲生长。问原因。

思路
弯曲生长要求尖端合成的生长素能经极性运输到达下方伸长区，并由横向运输造成两侧分布不均。a′组切段正向放置，极性运输正常；b′组切段倒置，形态学上端在下，生长素无法运输到基部，导致无弯曲。c、d 组本身都能合成生长素，差异在于接入方向。

步骤
1. 明确弯曲条件：尖端合成生长素 → 极性运输至下部 → 在单侧光作用下横向运输导致背光侧多于向光侧 → 背光侧生长快 → 向光弯曲。
2. 分析 a′组：切段接入时形态学上端在上，极性运输通畅，尖端合成的生长素能运至基部，故能弯曲。
3. 分析 b′组：切段接入时形态学上端在下（倒置），极性运输方向被迫由下向上，无法将生长素运送至胚芽鞘下部；尖端合成能力正常但运输被阻断，因此不发生弯曲。
4. 对照选项，C 项“c 组尖端能运输，d 组不能”为错误（二者在本组内均可运输），正确答案为 D：“a′组尖端的生长素能向胚芽鞘基部运输，b′组尖端的生长素不能”。

点评/变式
该题是验证极性运输的经典实验模型。变式可换用含生长素的琼脂块放置于切段顶端，此时琼脂块无极性，扩散不受方向限制，切段正放倒放都可能有生长素运出，结论需重新分析。重点始终放在活组织的主动极性运输上，注意区分扩散与主动运输。
