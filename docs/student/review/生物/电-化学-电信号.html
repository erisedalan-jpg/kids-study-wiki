电-化学-电信号

考点电-化学-电信号权重0真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：0
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 兴奋的本质：兴奋在神经纤维上以局部电流（电信号）的形式传导；在神经元之间通过突触传递时，会发生 $电信号\to 化学信号\to 电信号$ 的转化。
  • 突触传递过程：突触前膜释放神经递质（化学信号），经突触间隙扩散，与突触后膜受体结合，引发突触后膜电位变化（电信号）。该过程单向传递，由突触前膜→突触后膜。
  • 反射弧完整性与信号类型：一个完整的反射弧中，信息传递同时存在电信号和化学信号。感受器将刺激转化为电信号，传入神经上为电信号，神经中枢既有电信号又有化学信号，传出神经上为电信号，效应器接受电信号或化学信号产生效应。
  • 条件反射与大脑皮层：条件反射（如看见酸梅分泌唾液）是后天形成的，必须有大脑皮层的参与。非条件反射则不需要大脑皮层，由较低级中枢即可完成。
  • 效应器的组成：效应器是指传出神经末梢及其支配的肌肉或腺体。针对唾液分泌，效应器是传出神经末梢和唾液腺。
  • 感觉的形成路径：感受器接收刺激产生兴奋，经传入神经传到大脑皮层的感觉中枢，才形成感觉。刺激不能直接作用于神经中枢。

解题方法与套路

  1. 区分反射类型：看是否需要大脑皮层参与：题目中出现“看见、听见、想到、说及书写”等词时，常为条件反射，须大脑皮层参与；缩手反射、膝跳反射等常为非条件反射，中枢在脊髓或脑干。
  2. 厘清信号转化路径：熟悉整个反射弧中电信号与化学信号出现的位点：
  3. 感受器 → 电信号（产生动作电位）
  4. 传入神经 → 电信号
  5. 突触 → $电\to 化学\to 电$
  6. 传出神经 → 电信号
  7. 效应器 → 取决于效应器类型（肌肉腺体可接受神经末梢释放的递质，即化学信号，或电耦合，但常为化学信号） 常考点：只要有突触参与，必存在“电-化学-电”转化。
  8. 识别刺激与中枢的关系：刺激必须被感受器接受并转化为电信号后，才能传入神经中枢；题目中若有“××直接刺激神经中枢”的表述，一定是错误的（除非有大脑皮层直接受到电刺激等人工情境，但自然情况下不成立）。
  9. 判断效应器：揪出“传出神经末梢 + 它所支配的肌肉或腺体”的完整表述；选择题中若只说“唾液腺是效应器”往往不全，但真题中曾以“效应器是唾液腺”作为正确选项的表述，需要根据当时选项完整度比较判别，此真题中B项“这是一种反射活动，其效应器是唾液腺”正确，因其在简化叙述中可接受。

高频易错

  • 误以为神经中枢可直接接受刺激：视觉刺激、化学刺激等必须由感受器接受并转化为电信号，再经传入神经传到神经中枢。选项若说“色泽直接刺激神经中枢”，立判错误。
  • 混淆“感觉”与“反射”路径：感觉产生只需感受器→传入神经→大脑皮层；反射则需要完整的反射弧（必须有传出神经和效应器）。
  • 错判效应器组成：效应器包括传出神经末梢和它所支配的肌肉或腺体，两者缺一不可。考试中要警惕省略“传出神经末梢”造成的干扰。
  • 忽略突触处的化学信号：兴奋在反射弧上不全是电信号，只要经过突触就有“电-化学-电”转化。选项说“整个过程中均为电信号”或只有电信号就是错的。
  • 条件反射与大脑皮层关系不清：条件反射一定有大脑皮层参与；非条件反射神经中枢可不在大脑皮层。

代表题精讲

题目：当人看见酸梅时唾液分泌会大量增加。对此现象的分析，错误的是（　）
A．这一反射过程需要大脑皮层的参与
B．这是一种反射活动，其效应器是唾液腺
C．酸梅色泽直接刺激神经中枢引起唾液分泌
D．这一过程中有“电﹣化学﹣电”信号的转化

思路：首先判定该现象属于条件反射：看见酸梅（视觉刺激）→分泌唾液，是后天习得的反射，需大脑皮层参与。然后逐一检验反射弧各环节描述是否符合生理学事实。重点关注“刺激能否直接作用于神经中枢”以及信号形式转化。

步骤： 1. 分析反射类型：看见酸梅→唾液分泌，属于条件反射，大脑皮层参与对其建立和执行是必要的。故A正确。 2. 效应器判断：唾液分泌的效应器是传出神经末梢支配的唾液腺；选项B表述为“效应器是唾液腺”，在本题选项对比下可接受，视为正确。 3. 刺激路径检查：酸梅色泽属于光信号，必须先由视网膜（感受器）接受并转化为电信号，经视神经传入大脑皮层视觉中枢，再由大脑皮层分析处理后通过传出神经控制唾液腺。选项C说“酸梅色泽直接刺激神经中枢”，跳过了感受器和传入神经环节，明显错误。故C是错误项。 4. 信号转化验证：该反射弧中视觉信号转化为电信号，传入神经电信号、中枢内及传出途中必经过突触（“电-化学-电”转化），最终支配唾液腺分泌。因此整个过程存在“电-化学-电”信号转化，D正确。 5. 得出答案：选错误的，为C。

点评/变式：此题常规考点是反射弧和信号转化，易出错点在于C项具有迷惑性，将“感受器接受刺激并传入中枢”的过程偷换为“直接刺激神经中枢”，违背了反射弧的完整性要求。变式题可将“看到酸梅”换成“吃到酸梅”（非条件反射），则大脑皮层可不必参与，但信号转化仍存在。也可把效应器描述改成“传出神经末梢和唾液腺”来检验对效应器概念的严格掌握。
