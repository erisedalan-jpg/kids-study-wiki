病毒特性

考点病毒特性权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2009–2009
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 病毒基本特性：无细胞结构，仅由核酸（DNA 或 RNA）和蛋白质外壳构成，部分病毒具有包膜。病毒不能独立代谢，必须在活的宿主细胞内专性寄生，以复制方式增殖（吸附→注入→核酸复制与蛋白质合成→组装→释放）。
  • 抗原性与抗原决定簇：病毒的蛋白质外壳或包膜糖蛋白上存在抗原决定簇，即抗原分子表面能与抗体或淋巴细胞受体特异性结合的特定化学基团。抗原决定簇决定了抗原的特异性，是免疫系统识别病毒的分子基础。
  • 免疫接种原理：疫苗通过刺激机体产生针对特定抗原的记忆细胞和抗体，形成特异性免疫。若疫苗预防的病原体与另一病原体拥有相同的抗原决定簇，机体产生的抗体或效应 T 细胞便能交叉识别并清除另一种病原体，这称为交叉保护。
  • 适用条件：接种 A 疫苗能预防 B 病的前提是 A 与 B 具有共同（相同或高度相似）的抗原决定簇，而非取决于侵染部位、致病机理或传播途径是否相同。

解题方法与套路

  1. 审清免疫学逻辑：题目涉及“接种 X 疫苗→预防 Y 病”时，立即锁定考查的是抗原与抗体的特异性结合，或效应 T 细胞对相同抗原呈递细胞的识别。
  2. 抓核心条件：若要实现交叉免疫保护，必须满足 Y 病原体与 X 疫苗所模拟的病原体具有相同的抗原决定簇。这是抗体或 TCR（T 细胞受体）精准识别的分子来源。
  3. 排除干扰选项：快速排除侵染部位、致病机理、传播途径等与免疫识别特异性无直接因果关系的选项。记忆口诀：“免疫交叉靠抗原，部位机理勿来沾。”
  4. 印证选项：确认正确答案中的“抗原决定簇”与题干“免疫接种”本质挂钩——因为疫苗本质就是抗原或其成分。

高频易错

  • 混淆侵染部位与抗原特异性：误以为只要两种病毒侵染同一组织（如呼吸道上皮），接种一种疫苗即可预防另一种。免疫系统识别的是分子而非部位。
  • 以为致病机理相同即可交叉免疫：如均引起肺炎或细胞因子风暴，但若表面抗原决定簇不同，已有抗体无法结合新病毒，无法阻止感染。
  • 忽视“抗原决定簇”概念的理解：对抗原特异性的分子基础记忆模糊，将免疫应答的启动错误归于整个病原体结构，而免疫识别依赖的是抗原表位（决定簇）。记忆不牢易失分。

代表题精讲

题目：为防止甲型 H1N1 病毒在人群中的传播，有人建议接种人流感疫苗，接种人流感疫苗能够预防甲型 H1N1 流感的条件之一是：甲型 H1N1 病毒和人流感病毒具有相同的

思路：明确核心概念——免疫接种的本质是利用抗原刺激机体产生特异性抗体和记忆细胞。交叉保护能力取决于抗体能否结合新病毒的抗原，即抗原决定簇是否相同。

步骤： - 找出题干的关键动作：“接种人流感疫苗”预防“甲型 H1N1”。 - 联系知识：疫苗预防的基础是抗原-抗体特异性识别。抗体由原疫苗的抗原决定簇诱导产生，只能识别相同或高度相似的抗原决定簇。 - 排查选项：A. 侵染部位——同为呼吸道感染，但不同病毒可侵染相同部位而抗原完全不同；B. 致病机理——机理相同不代表抗原分子相同；C. 抗原决定簇——直接决定抗体能否结合；D. 传播途径——飞沫传播也非免疫识别依据。 - 因此锁定 C 选项。

点评/变式：本题为经典“抗原交叉保护”题型，难度中等。易错选 A，因为学生会从生活直觉出发，认为都感染呼吸道就打同类疫苗。变式可延伸至禽流感与人流感病毒之间的抗原转换和基因重配，若新病毒表面抗原发生大变异（抗原转变），则原有疫苗失效。务必牢记：免疫交叉保护只认“抗原决定簇”这一把钥匙。
