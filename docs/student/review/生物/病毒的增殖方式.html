病毒的增殖方式

考点病毒的增殖方式权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2008–2008
  • 出现题位：选择4
  • 难度分布：易1

知识精要

  • 病毒的核心属性：非细胞形态生物，无完整细胞结构，仅由核酸（DNA或RNA）与蛋白质衣壳构成，部分种类具囊膜（源自宿主细胞膜）。专性活细胞内寄生，自身无代谢酶系与核糖体，完全依赖宿主细胞的能量、原料与酶系统完成增殖。
  • 增殖过程：吸附→注入核酸→脱壳→生物合成（利用宿主原料与场所复制核酸、合成蛋白质）→装配→释放。任何环节脱离宿主即中止。
  • 培养条件：必须用活体组织或活细胞培养，如鸡胚、敏感细胞系。经高温灭菌的无生命培养基上病毒完全失活，不可能出现菌斑或增殖现象。
  • 人类免疫缺陷病毒（HIV）：一种RNA囊膜病毒，主要侵染辅助性T细胞，导致后天获得性免疫缺陷综合征（AIDS）。其逆转录过程是抗病毒药物的关键靶点。

解题方法与套路

针对“病毒结构与增殖”类判断题，遵循以下通用步骤迅速锁定答案： 1. 判定寄生性：只要选项暗示病毒能在无活细胞的人工培养基、高温灭菌物或脱离宿主独立增殖，直接判定为错误。 2. 核对结构层次：明确核酸位置——无囊膜病毒核酸在衣壳内，有囊膜病毒核酸在核心，紧贴囊膜内层的是基质蛋白而非核酸。混淆核酸与囊膜/衣壳外置关系的选项必错。 3. 关联病因：涉及病毒引起的疾病名称必须严格对应，如HIV对应“获得性免疫缺陷综合征”（艾滋病），而非其他免疫病名称。 4. 绝对词排除：选项中若出现“可以不依赖”“所有”“任何”等绝对化表述，与病毒专性活细胞寄生的特性相悖，大概率错误。 5. 备选验证：若四个选项中有三个明确违背病毒核心知识，直接选剩余一项以节省时间，再用病毒定义反向确认。

高频易错

  • 陷阱1：培养基误区
    学生易受“细菌/真菌可在培养基上生长”的思维定势影响，误认为病毒也可在灭菌人工培养基上增殖。必须牢记：病毒为专性活细胞寄生，无活细胞即无增殖，培养基仅提供营养而无宿主代谢，病毒无法独立合成。
  • 陷阱2：囊膜结构错位
    流感病毒等囊膜病毒，核酸位于内部核心，并非在“囊膜上”或“衣壳外”。真题选项常故意将核酸定位至囊膜外部，利用考生对病毒微观结构的模糊认知设错。
  • 陷阱3：独立增殖误解
    “烟草花叶病毒可以不依赖宿主细胞而增殖”等表述极具迷惑性。部分考生可能认为某些病毒较“原始”可独立生存，忽略病毒均属非细胞形态、必须借助宿主复制这一绝对前提。
  • 陷阱4：高温灭菌所致假象
    高温灭菌能杀死微生物，但不能使病毒“变异”为可直接利用培养基的形态，题干中“经高温灭菌的培养基”是干扰信息，核心考点仍是病毒培养必须依赖活宿主。

代表题精讲

题目

（2008·全国Ⅱ·04，6分）下列关于病毒的叙述，正确的是（　　）
A．烟草花叶病毒可以不依赖宿主细胞而增殖
B．流感病毒的核酸位于衣壳外面的囊膜上
C．肠道病毒可在经高温灭菌的培养基上生长增殖
D．人类免疫缺陷病毒感染可导致获得性免疫缺陷综合症

思路

本题四个选项分别针对病毒增殖依赖性、结构组成、培养方式与致病性设问。解题关键在于严格调用“病毒为专性活细胞寄生”“核酸定位于核心而非囊膜”“病毒须活细胞培养”等核心知识，依次排除三项错误，锁定正确项。

步骤

  1. 分析A项：所有病毒均无独立代谢系统，必须依赖宿主细胞辅以原料、酶与能量才能增殖。烟草花叶病毒也不例外，故“可以不依赖”明显错误。
  2. 分析B项：流感病毒具囊膜，结构自外至内为囊膜→基质蛋白→核心，核酸位于核心内，而非囊膜上。“衣壳外面的囊膜上”与事实相悖。
  3. 分析C项：高温灭菌仅杀灭培养基中的微生物，无法提供病毒复制必需的活细胞核糖体、酶系统等。病毒在无活细胞的培养基上根本不能增殖，表述错误。
  4. 分析D项：人类免疫缺陷病毒即HIV，主要攻击辅助性T淋巴细胞，导致机体免疫功能严重缺陷，引发获得性免疫缺陷综合症（艾滋病），因果关系与疾病名称完全正确。
    综上，正确选项为D。

点评/变式

本题以病毒的基础概念为核心，通过多个经典易错点组合，精准考查考生对病毒“专性寄生”本质的理解。失分常见于B项的囊膜-核酸位置关系及C项的培养基培养假定。
变式拓展：可将选项变为“流感病毒核酸存在于核心，与RNA聚合酶一起包装”“HIV在体外可用鸡胚大量培养”“高温处理后的病毒立即丧失感染性但可在培养基增殖”等，本质仍脱离不了“活细胞寄生”与“结构定位”。应对所有变式，紧扣“无活细胞不增殖”、明确核酸位置，即可准确破题。
