病毒结构

考点病毒结构权重22真题数4学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：22
  • 真题数：4；年份跨度：2008–2020
  • 出现题位：选择1 选择2 选择3 选择4
  • 难度分布：易3 中1

知识精要

  • 病毒的结构：无细胞结构，仅由核酸（DNA 或 RNA）和蛋白质衣壳构成；某些病毒外面还包被一层囊膜（含脂质和糖蛋白）。遗传物质只有一种：DNA 或 RNA，不会同时含有两者。
  • 病毒的增殖：专性活细胞内寄生，必须依赖宿主细胞的物质和能量代谢系统进行增殖。增殖过程一般包括吸附→注入核酸→生物合成（利用宿主核糖体、酶等）→组装→释放。病毒自身没有核糖体，不能独立合成蛋白质。
  • 病毒进入宿主细胞的方式：大分子颗粒一般通过胞吞（膜泡运输）进入细胞，消耗能量，不属于被动运输。
  • 病毒的培养：不可在无细胞的培养基（如高温灭菌的培养基）上生长，只能利用活体组织或活细胞培养。
  • 遗传物质的核苷酸种类：DNA 病毒含脱氧核糖核苷酸，RNA 病毒含核糖核苷酸；核苷酸种类不同，不能混为一谈。
  • 抗原属性：病毒的蛋白质（如衣壳蛋白、囊膜蛋白）和细菌的蛋白质均可作为抗原，被机体免疫系统识别，引发特异性免疫反应。
  • 相关疾病归类：
  • 病毒感染：艾滋病（由 HIV 感染引起，导致获得性免疫缺陷综合征）、流感、新冠肺炎、肠道病毒感染等。
  • 自身免疫病：免疫系统攻击自身组织，如类风湿性关节炎、系统性红斑狼疮，与病毒直接结构无关，但可能由感染诱发。
  • 过敏反应：接触过敏原引起的过度免疫应答，如动物毛屑接触性鼻炎。
  • 遗传病：基因突变引起，如抗维生素 D 佝偻病。

解题方法与套路

  1. 判断是否为细胞生物：病毒无细胞结构，不属原核或真核生物；选项中出现“病毒有核糖体”“病毒在培养基上增殖”，可直接判定为错误。
  2. 遗传物质判定：明确题目中病毒的遗传物质类型（DNA 或 RNA），再对比核苷酸种类。若题目同时涉及细菌，要区分：细菌为细胞生物，遗传物质是 DNA，含脱氧核糖核苷酸；病毒的核苷酸种类由其遗传物质类型决定。
  3. 跨膜运输方式判定：病毒或大分子颗粒进入细胞一般为胞吞，需要能量，不属于被动运输（自由扩散、协助扩散）。
  4. 抗原与免疫病区分：
  5. 病毒或病原生物的蛋白质 → 作为抗原引发正常免疫反应。
  6. 选项涉及“自身免疫病” → 关键词“攻击自身物质”，常见实例：类风湿性关节炎。
  7. 艾滋病 → 免疫缺陷病，病原体是 HIV。
  8. 过敏反应 → 因人而异，常见过敏原如花粉、毛屑。
  9. 排除法快速解题：读完所有选项，先排除明显知识性错误（如病毒有核糖体、病毒独立代谢、遗传物质核苷酸相同），再细读剩余选项。

高频易错

  • 病毒与细菌混淆：误认为病毒有细胞结构，可利用自身核糖体合成蛋白质。病毒只能借宿主核糖体完成翻译。
  • 遗传物质核苷酸混同：认为“都是核酸所以核苷酸相同”，忽视核糖和脱氧核糖的差异。
  • 病毒进入细胞方式错误：将胞吞当作被动运输（不需能量），或误选主动运输、自由扩散。
  • 病毒培养误区：以为病毒可在琼脂培养基上生长，忽视其专性寄生特征。病毒分离需用活细胞或鸡胚。
  • 免疫疾病归类混淆：艾滋病、自身免疫病、过敏反应、遗传病概念界限不清。尤其注意“获得性免疫缺陷综合症”指的是艾滋病，病因是 HIV 感染。
  • 病毒结构位置错误：例如认为流感病毒的核酸位于囊膜上，实则核酸在内层核心，囊膜为外部包被。

代表题精讲

代表题 1：2020-新课标Ⅱ-01

题目
新冠病毒（SARS‑CoV‑2，含单链 RNA）和肺炎双球菌均可引起肺炎，关于二者结构的相关叙述，选出正确选项。

思路
逐项辨析：A 为物质跨膜运输方式判定；B 考查蛋白质合成场所（核糖体归属）；C 考查遗传物质类型与核苷酸种类对应关系；D 考查抗原属性与免疫识别。

步骤
1. A 项：新冠病毒进入宿主细胞是胞吞，需要消耗能量，胞吞属于膜泡运输，非被动运输（自由扩散或协助扩散），故 A 错误。
2. B 项：新冠病毒无细胞结构，没有核糖体；肺炎双球菌是原核生物，自身有核糖体。病毒利用宿主细胞的核糖体进行蛋白质合成，B 错误。
3. C 项：新冠病毒遗传物质是 RNA，核苷酸为核糖核苷酸；肺炎双球菌遗传物质是 DNA，核苷酸为脱氧核糖核苷酸，两者核苷酸不同，C 错误。
4. D 项：病毒的表面蛋白和细菌的蛋白质均可作为抗原被机体免疫系统识别，D 正确。
结论：D。

点评/变式
本题考查病毒与细菌的结构差异及免疫学基本概念，是高频考点组合。注意变式可能将“肺炎双球菌”换成“大肠杆菌”或“HIV”，答题思路不变。关键抓住病毒无细胞结构、胞吞耗能、遗传物质核苷酸类型等核心点。

代表题 2：2020-新课标Ⅱ-02

题目
给出四个疾病选项，识别属于自身免疫病的一项。

思路
抓住自身免疫病的定义——“免疫系统将自身物质当作外来异物攻击”，并记住常见实例。排除法对比：艾滋病是免疫缺陷，过敏性鼻炎是过敏反应，抗维生素 D 佝偻病是遗传病。

步骤
1. 艾滋病：由 HIV 感染引起，攻击 T 细胞导致免疫缺陷，属获得性免疫缺陷综合征，非自身免疫病。
2. 类风湿性关节炎：免疫系统攻击关节滑膜，典型自身免疫病，符合定义。
3. 动物毛屑接触性鼻炎：接触过敏原引起的过敏反应，非攻击自身物质。
4. 抗维生素 D 佝偻病：基因突变引起的遗传病，钙磷代谢异常，与免疫攻击无关。
结论：B（类风湿性关节炎）。

点评/变式
本题虽未直接考查病毒结构，但属于病毒专题的免疫关联考点。容易混淆的是艾滋病和自身免疫病，需要从病因和免疫机制区分：艾滋病由病毒感染造成免疫缺陷，而自身免疫病是免疫系统“敌我不分”。备考时可将病毒引起的疾病（如艾滋病、流感、COVID‑19）与自身免疫病归类对比记忆。
