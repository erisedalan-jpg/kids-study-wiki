病毒致癌因子

考点病毒致癌因子权重5真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：5
  • 真题数：1；年份跨度：2015–2015
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 致癌因子的分类：环境中的致癌因子可分为物理致癌因子（如紫外线、电离辐射）、化学致癌因子（如亚硝胺、黄曲霉素）和病毒致癌因子三类。
  • 病毒致癌因子的本质：某些病毒含有癌基因（如 $src$ 基因）或能激活宿主细胞中的原癌基因，其遗传物质可在感染后整合到宿主基因组中，导致细胞发生癌变。
  • 代表实例：Rous 肉瘤病毒（一种逆转录病毒）是最早被证实的病毒致癌因子，能够诱发禽类肉瘤，其携带的 $src$ 基因编码一种酪氨酸激酶，持续激活细胞增殖信号通路。虽然该病毒主要导致禽类肿瘤，但其致癌机理与人类多种病毒诱发的癌症（如 HPV 致宫颈癌、EB 病毒致鼻咽癌）高度相似，属于公认的致瘤因子。
  • 病毒致癌的适用条件：只有部分病毒具有致癌能力，并非所有病毒都是致癌因子。癌变的发生通常是原癌基因激活与抑癌基因失活多步骤累积的结果，病毒感染只是其中一种启动或促进因素。

解题方法与套路

  1. 锁定题眼，匹配知识块：当题干或选项中涉及“Rous 肉瘤病毒”“病毒致癌因子”时，立即调取“病毒致癌因子实例与机理”相关内容，识别“Rous 肉瘤病毒是致瘤因子”这一课本结论。
  2. 选项排查法：对于复合型选择题，逐项对接教材考点：
  3. 若涉及“抗体进入细胞”，联系抗体只能在细胞外液中发挥作用（体液免疫），不能进入宿主细胞；
  4. 若涉及“溶菌酶机理”，明确其化学本质是蛋白质，通过水解细菌细胞壁起作用，与抗体结合病毒形成沉淀或中和的机制完全不同；
  5. 若涉及HIV浓度与T细胞数量，联系HIV攻击T细胞导致其数量下降，病毒载量与病情严重程度正相关。
  6. “本质”干扰项识别：选项中将两个机制不同的过程描述为“相同”，或故意用“不是”“无关”等绝对化表述偷换公认的科学结论，往往是错误选项的典型特征。见到此类表述需提高警惕，主动回顾教材原话予以反驳。

高频易错

  • 易混淆“病毒致癌因子”与“非致癌病毒”：误认为所有病毒都能致癌，或把 Rous 肉瘤病毒误认为不是致癌因子。牢记课本明确将其列为病毒致癌因子的经典例证。
  • 对 Rous 肉瘤病毒宿主范围的误解：认为该病毒仅感染禽类，便推断其“与人的细胞癌变无关”。实际上，高考对其考查的核心是它作为“致癌因子”的研究价值及普遍原理，并非要求人类患病的直接相关性，但选项若否定其致瘤因子属性即为错。
  • 抗体进入细胞的陷阱：部分同学混淆细胞免疫与体液免疫的作用场所，错误以为抗体可进入靶细胞消灭胞内病原体。实际上，胞内病原体需由效应T细胞使靶细胞裂解后，再由抗体等清除。
  • 不加区分地等同杀菌机制：抗体抵抗病毒依靠特异性结合（凝集/中和），溶菌酶杀灭细菌依靠酶解细胞壁肽聚糖，两者机制截然不同，命题常在此处设“相同”陷阱。

代表题精讲

题目：2015 年新课标Ⅱ卷第5题——关于病原体的叙述，选出正确选项。主要涉及结核杆菌的消除、抗病毒机制对比、Rous 肉瘤病毒是否致癌以及 HIV 感染的相关说法。

思路

本题是一道病原体与免疫、癌变的综合题。需要调用免疫调节（体液免疫与细胞免疫）、免疫物质的作用机制、病毒致癌因子实例以及艾滋病致病机理四个板块的知识。对于含“病毒致癌因子”考点的选项 C，直接判断其表述是否违背教材结论即可；其他选项则需仔细辨析免疫过程的内在逻辑。

步骤

  1. 分析选项 A：结核杆菌属于胞内寄生菌，当它寄生在细胞内时，抗体无法进入细胞；消灭胞内病原体依赖于细胞免疫（效应 T 细胞裂解靶细胞）后，体液免疫和吞噬细胞再发挥作用。故 A 错误。
  2. 分析选项 B：抗体与病毒特异性结合后会形成沉淀或使病毒失去侵染能力，最后由吞噬细胞处理；溶菌酶则是通过水解细菌细胞壁中的肽聚糖来杀灭细菌。两者机制完全不同，不能等同。故 B 错误。
  3. 分析选项 C：Rous 肉瘤病毒是课本中明确列出的病毒致癌因子，属于致瘤因子，它的致癌机理在人类的癌症研究中具有普遍意义。选项说“不是致瘤因子，与人的细胞癌变无关”完全违背事实。故 C 错误。
  4. 分析选项 D：HIV 侵入人体后，会特异性攻击 T 细胞，随病毒大量增殖，T 细胞数量持续下降，当 T 细胞数量极低时，免疫功能几乎完全丧失，各种症状由此显现。因此，人感染 HIV 后的症状严重程度确实与病毒浓度和 T 细胞数量密切相关。故 D 正确。

点评/变式

  • 点评：本题通过一个选项直接考查了“病毒致癌因子”的基础记忆，同时串联了免疫学中的多个易混点，综合性强。找准 C 项的教材出处是快速得分的关键。
  • 变式 1：可将 C 项改为“Rous 肉瘤病毒感染会导致宿主细胞中的原癌基因或抑癌基因发生突变”来考查致癌机理。
  • 变式 2：将“Rous 肉瘤病毒”替换为“EB 病毒”“人乳头瘤病毒（HPV）”等教材常见病毒致癌因子实例，应能同理判断其是否为致癌因子及与人类癌症的关系。
