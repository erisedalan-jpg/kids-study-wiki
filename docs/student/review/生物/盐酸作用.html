盐酸作用

考点定位

  • 父主题：分子与细胞
  • 权重 weight：5
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：选择3
  • 难度分布：易1

知识精要

水是细胞中含量最多的化合物，在生命活动中承担核心角色。其存在形式分为自由水和结合水两大类，二者功能、理化性质及比例共同调控细胞代谢与抗逆性，是高考生物的高频考点。

  • 水的存在形式与比较

    • 结合水：与细胞内蛋白质、多糖等亲水性物质紧密结合，失去流动性与溶解性。它是细胞结构的重要组成成分，赋予细胞一定形状与韧性。
    • 自由水：以游离状态存在，具有流动性。它能溶解多种物质，是细胞内良好的溶剂和反应介质，直接参与水解、光合作用光反应、有氧呼吸第二阶段等生化反应，并承担营养物质与代谢废物的运输任务。

  • 自由水/结合水比值与代谢的关系

    • 在一定范围内，自由水与结合水的比值越高，细胞的代谢活动越旺盛，是种子萌发、幼嫩组织生长等活跃生命活动的基础。
    • 反之，比值降低时，代谢速率减缓，但细胞抗逆性（如抗旱、抗寒能力）增强，例如越冬植物体内结合水比例会上升。

  • 水代谢的生理功能

    • 维持植物形态：植物通过根系渗透吸水，使液泡充盈，产生膨压，支撑幼嫩组织，维持其固有姿态。
    • 参与细胞呼吸：在有氧呼吸中，水既是反应物（第二阶段，丙酮酸与水反应生成 $CO_2$ 和 $[H]$），也是生成物（第三阶段，$[H]$ 与 $O_2$ 结合生成大量水），并非只产生不消耗。

解题方法与套路

处理“水的存在形式与生理作用”辨析题，可遵循以下通用解题路径，快速锁定错误选项：

  1. 明确设问方向，圈出否定词：先看清题目要求选择“正确”还是“错误”的选项，避免低级失误。
  2. 快速划分水的类型：审视选项是考查“自由水”还是“结合水”，联想对应功能。结合水→结构成分；自由水→溶剂、反应物、运输、介质。
  3. 关联具体生理过程：对于涉及代谢过程的选项（如光合、呼吸、运输），需精准回忆该过程中水是作为反应物、生成物还是仅作介质。
    • 呼吸作用：牢记有氧呼吸第二阶段消耗水，第三阶段生成水。这是命题人设置干扰项的“重灾区”。
    • 光合作用：光反应需水作为电子供体，消耗水；暗反应（卡尔文循环）生成水。
  4. 运用“比值”原理进行趋势判断：遇到涉及代谢速率或抗逆性的选项，直接套用结论：“自由水/结合水”比值升高→代谢旺盛；比值降低→抗逆性增强。

高频易错

  • 混淆有氧呼吸中的水代谢阶段：错误地认为细胞有氧呼吸全过程只生成水而不消耗水。这是最经典的思维漏洞，准确记忆应为“第二阶段反应物，第三阶段生成物”。
  • 混淆结合水与自由水的生理功能：错误地将结合水归为良好溶剂或反应介质，其核心功能仅是构成细胞结构。
  • 忽略水的物理支撑作用：不理解植物坚挺的生理基础，将“吸收水分”与“维持姿态”割裂，实则液泡内水分充盈产生的膨压直接支撑植物体。
  • 比值与生理状态的错配：错误地将低比值（结合水占比高）与代谢旺盛挂钩，或将高比值与抗逆性强挂钩，必须明确二者呈负相关。

代表题精讲

题目：（2021·全国乙卷）判断“细胞的有氧呼吸过程不消耗水但能产生水”叙述的正误。

思路 本题考察有氧呼吸三个阶段的物质变化细节。题干明确要求筛选“错误”选项，核心陷阱设在有氧呼吸的水代谢归属上。需调取有氧呼吸阶段模型，分别核验水在反应物和生成物中的出现位置。

步骤 1. 定位知识原型：回顾有氧呼吸全过程。 - 第一阶段（细胞质基质）：葡萄糖分解为丙酮酸和少量 $[H]$，无水参与。 - 第二阶段（线粒体基质）：丙酮酸与水彻底分解为 $CO_2$ 和大量 $[H]$。此处水作为反应物被消耗。 - 第三阶段（线粒体内膜）：前两阶段产生的 $[H]$ 与 $O_2$ 结合形成水。此处水作为生成物被释放。 2. 比对选项表述：选项称“不消耗水但能产生水”。 3. 判定逻辑冲突：该表述直接与第二阶段“消耗水”的科学事实相悖，属于以偏概全，因此该表述错误。

点评/变式 该题错误率高，源于学生对呼吸作用过程的记忆停留在总反应式（$C_6H_{12}O_6 + 6H_2O + 6O_2 \rightarrow 6CO_2 + 12H_2O$），误认为反应式中的水仅用于标注，忽视了其作为核心反应物的实质。
变式思考：若将选项改写为“光合作用全过程只消耗水不产生水”，同样错误。因光反应消耗水，而暗反应 $C_3$ 的还原过程会生成水。复习务必细化到各阶段物质变化，精准辨析反应物与生成物。
