神经递质

考点神经递质权重13真题数2学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：13
  • 真题数：2；年份跨度：2016–2022
  • 出现题位：选择3 选择8
  • 难度分布：中2

知识精要

  • 神经递质：神经元之间或神经元与效应细胞间传递信息的化学物质，贮存在突触小泡内。
  • 突触传递过程：兴奋传到轴突末梢→突触前膜去极化→电压门控$Ca^{2+}$通道开放→$Ca^{2+}$内流→突触小泡向突触前膜移动、融合→以胞吐方式释放神经递质至突触间隙→递质扩散与突触后膜上的特异性受体结合→引发突触后膜电位变化（兴奋或抑制）→递质迅速被降解酶（如乙酰胆碱酯酶）降解或由突触前膜回收，终止信号。
  • 兴奋性递质与抑制性递质：如乙酰胆碱（兴奋性）、多巴胺（多为抑制性或调节性）、一氧化氮（特殊气体递质）等。同一递质在不同突触可因受体类型不同而产生兴奋或抑制效应。
  • 调节与疾病：兴奋传递过度可致肌肉痉挛、癫痫等；传递不足可致肌肉松弛、抑郁等。治疗策略：通过药物影响递质的释放、与受体结合、降解或回收等环节，增强或减弱传递。

解题方法与套路

  1. 明确异常状态：题干常给出“兴奋传递过度”或“传递不足”的病理情境，弄清需增强还是减弱突触传递。
  2. 拆解干预环节：分析选项措施作用于哪一环节——递质释放量、受体的数量/活性、递质降解/回收速度等。
  3. 推断传递强度变化：
  4. 促进释放、抑制降解、增加受体数量/亲和力 → 传递增强。
  5. 抑制释放、阻断受体、促进降解 → 传递减弱。
  6. 匹配治疗目标：对照题意选择能缓解症状的措施。注意递质性质（兴奋/抑制），若题干未标明，按常见情形（如神经-肌接头处为兴奋性）处理。
  7. 图示题延伸：对示意图题，先识别突触前膜、突触间隙、突触后膜、递质、受体、降解酶等，再根据箭头和物质归属解答合成、释放、去向及失活相关问题。

高频易错

  • 混淆递质性质：以为所有递质都是兴奋性的，忽略抑制性递质的存在。抑制性递质降解受阻会导致突触后膜持续抑制，而非兴奋。
  • 错选“抑制酶活性”：题目给兴奋过度时，考生常误以为抑制降解酶可减少递质，实则使递质堆积、兴奋加强。治疗肌肉痉挛应选减弱传递的措施。
  • 忽略受体数量的动态影响：认为增加受体与症状无关，实际增加受体等同于增强传递。
  • 胞吐方式的描述不准：易答成“胞吞”或“主动运输”“自由扩散”，神经递质释放是胞吐，需消耗能量，依赖$Ca^{2+}$内流。
  • 概念混淆：将“降解酶”与“回收”的作用混为一谈。乙酰胆碱失活主要靠降解，有些递质（如去甲肾上腺素）以回收为主。
  • 忽视循环利用：乙酰胆碱合成时，其降解产物（如胆碱）可被突触前膜回收再利用，易在图示题填错物质。

代表题精讲

题目 （2022-全国乙-03）运动神经元与骨骼肌间的兴奋传递过度引起肌肉痉挛，给予下列哪种治疗方法合理？
思路 骨骼肌收缩取决于运动神经元释放兴奋性递质（乙酰胆碱）的强度。治疗需减弱过度传递。分析各选项对突触传递强度的影响。
步骤
- A：加快递质释放 → 突触间隙递质浓度↑ → 与受体结合↑ → 兴奋传递增强，加重痉挛。不合理。
- B：阻止递质与受体结合 → 信号传递受阻 → 传递减弱，缓解痉挛。合理。
- C：抑制降解酶 → 递质持续存在，结合时间延长 → 传递增强，加重病情。不合理。
- D：增加突触后膜受体 → 结合机会↑ → 传递增强，不合理。
选B。
点评/变式 此类题本质考查“兴奋传递的影响因素”。若题干改为“传递不足导致肌肉松弛”，则应选增强传递的措施（如促进释放、抑制降解等）。注意区分传递过度的“治疗”是削弱，而非增强。

题目 （2016-新课标Ⅱ-08）图示乙酰胆碱合成与释放。回答：（1）合成时能循环利用的物质；除乙酰胆碱外，多巴胺和一氧化氮能否作神经递质。（2）兴奋传到末梢时，突触小泡内的递质经何种方式释放到何处。（3）若D酶失活，突触后神经元会表现为何。
思路 识图：A-C为乙酰胆碱，C由突触间隙回收至突触前膜再参与合成，故C可循环。常见递质包括多巴胺、一氧化氮等。胞吐是递质释放的典型方式。D酶位于突触后膜，可能为乙酰胆碱酯酶，失活则递质持续作用。
步骤
- (1) 填“C”；填“能”。
- (2) 填“胞吐”；“突触间隙”。
- (3) 乙酰胆碱为兴奋性递质，降解受阻 → 持续激活突触后膜 → 填“持续兴奋”。
点评/变式 图示题关键在箭头方向与物质变化。递质种类容易漏填“一氧化氮”这类非经典递质。D酶失活后果需结合递质性质判断，若为抑制性递质则答“持续抑制”。复习时应注意神经递质释放、作用、失活过程的统一模型。
