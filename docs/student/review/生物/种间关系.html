知识精要

  • 种间关系：指不同物种种群之间的相互作用，是群落结构的基础。
  • 主要类型及特点：
    • 互利共生：两种生物共同生活，相互依存，彼此有利。如根瘤菌与豆科植物。
    • 捕食：一种生物以另一种生物为食，被捕食者与捕食者数量常表现出周期性波动。
    • 寄生：一种生物（寄主）从另一种生物（宿主）的体液、组织或已消化物质中获取营养，并对宿主造成危害。如病毒与宿主。
    • 竞争：两种或多种生物共同利用相同且有限的资源和空间，相互抑制。其结果常表现为“你死我活”或“此消彼长”。
  • 能量流动与种间关系：食物链上营养级一般不超过 4-5 个，原因是生态系统的能量流动具有单向流动、逐级递减的特点（传递效率约为 $10\% \sim 20\%$），无法维持更高营养级生物生存。
  • 生态系统的稳定性：
    • 抵抗力稳定性：生态系统抵抗外界干扰并使自身结构与功能保持原状的能力。
    • 恢复力稳定性：生态系统在受到外界干扰后恢复原状的能力。
    • 一般而言，营养结构越复杂，抵抗力稳定性越高，恢复力稳定性越低。
  • 生态工程原理：
    • 协调原理：生物与环境、生物与生物的协调与适应。
    • 自生原理：通过有效选择生物组分，利用生物之间的相互作用，实现系统的自组织、自我优化和自我维持。

解题方法与套路

  1. 判断种间关系类型法：
    • 锁定生物对象：明确题目描述的是哪几种生物。
    • 分析相互作用：是“同生共死/一方受益，一方无害” → 互利共生；是“一方吃另一方/数量上‘先增先减为被捕食，后增后减为捕食者’” → 捕食；是“一方获益，一方受害/寄生在体表或体内” → 寄生；是“争夺同种资源/你消我长” → 竞争。特别注意区分“竞争”与“捕食”：竞争不直接以对方为食，而是争夺资源。
  2. 食物网构建与分析法：
    • 全物种罗列：写出所有生产者、消费者。
    • 定向连线：根据题干营养关系，从食物（被食者）指向取食者（捕食者），用箭头连接，构成食物网。
    • 多级影响推理：当某物种数量变化时，根据食物网沿箭头方向推导：一种生物数量减少，其天敌因食物减少而减少，其食物因天敌减少而增加。注意分析连锁反应和可能的间接影响（如通过“恐惧效应”改变其他生物行为）。
  3. “恐惧生态学”问题三步破解法：
    • 理解概念：明确“威慑”与“恐惧”指大型肉食动物通过非直接捕食的行为驱赶或改变被捕食者分布，从而影响低营养级。
    • 分离效应：将大型动物引入的影响分为：① 对被捕食者的直接捕食；② 对被捕食者的驱赶（使其离开最优觅食地）；③ 对中层捕食者的捕食或驱赶（改变其对更低营养级的捕食压力）。
    • 指向解题：根据题目设问，选择上述效应中的一点或多点，用以解释“竞争反转”、“农作物破坏减轻”等现象。

高频易错

  • 混淆“竞争”与“捕食”：两种生物若因取食同一资源导致数量负相关，是竞争。若一种生物因另一种生物数量增加而减少，且两者有直接吃与被吃关系，是捕食。判断关键看相互作用是“夺资源”还是“吃身体”。
  • 误判“寄生”与“捕食”：寄生生物通常比宿主小得多，短期内不直接杀死宿主，而是长期依附获利；捕食者则通常快速杀死猎物。病毒、细菌噬菌体与其宿主都是典型的寄生关系。
  • 忽略种间关系的间接影响：分析物种数量变化时，只考虑单向捕食，忽略食物网中的多级连带效应和行为层面的影响（如恐惧导致的觅食时间减少）。
  • 稳定性概念张冠李戴：在填空或判断时，将“干扰后恢复原状”的能力错误表述为“抵抗力稳定性”，其应为“恢复力稳定性”。
  • 对“协调原理”理解偏差：生态工程的协调不仅指生物与环境的协调，也包括生物组分之间（种间关系）的协调。单一种植不因地制宜就是违背此原理的常见例子。

代表题精讲

题目1：2024-辽宁-05 - 思路：本题考察利用种间关系及生态工程原理分析实际问题的能力。需结合弗兰克氏菌与沙棘的互利共生关系及筛选修复树种的生态学原则进行逐项判断。 - 步骤： 1. 确定关系：由“形成根瘤…共生固氮”判断两者为互利共生。 2. 分析选项A：题干提及沙棘“增强旱、寒适应性”，因此可作为西北干旱区修复树种，A项正确。 3. 分析选项B：矿区废弃地条件恶劣，选择抗逆性强（耐旱、寒）的沙棘，是考虑了其与环境的适应性，这恰恰遵循了生态工程的协调原理，故B项叙述错误。 4. 分析选项C：共生固氮改良土壤，为其他树种创造生长条件，体现了改良环境、促进群落演替的作用，C项正确。 5. 分析选项D：研究弗兰克氏菌遗传多样性，旨在筛选高效或抗逆菌株，以增强共生体系修复力，符合应用逻辑，D项正确。 - 点评/变式：此题“描述正确选错误项”，关键在于精确理解生态工程“协调”原理的内涵——“生物与环境、生物与生物”的相互适应。沙棘适应矿区即是协调。变式易错点是将弗兰克氏菌与其宿主判定为寄生关系。

题目2：2018-新课标Ⅱ-09 - 思路：本题为新概念应用题，核心是理解并运用“恐惧生态学”（非直接捕食的威慑与驱赶作用）来解释生态现象。需要从该视角出发，重新解读物种间相互作用。 - 步骤： 1. 第（1）问填空：考查能量流动的特性。营养级不多，直接填“能量沿食物链流动时是逐级递减的”。 2. 第（2）问推测：关键词是“不是由于直接捕食”，必须调用“恐惧与威慑”知识。 - 角度一：顶级肉食动物驱赶了植食性动物甲，使其逃离最优生境，数量减少，从而让乙在竞争中反转崛起。 - 角度二：顶级肉食动物驱赶或捕食了该食物网中的肉食性动物（乙的天敌），导致乙的天敌压力减小，乙数量增加，从而逆转了竞争。 3. 第（3）问推测：分析野猪破坏减轻，同样从捕食和恐惧双重角度。 - 直接捕食：大型肉食动物直接捕食了部分野猪。 - 行为威慑：大型肉食动物的存在，使野猪因恐惧而躲避，不敢或减少进入农田觅食。 - 点评/变式：“恐惧生态学”的实质是非消费性效应。标准答案的要点常来自对捕食和驱赶两种效能的拆分组合。答题时不论问“几点原因”，都需优先考虑这两种效能，并将其精准对应到题目具体的生物名称上。

题目3：2012-新课标-10 - 思路：本题通过“鹿角效应”假说，考察信息获取与实验设计能力。分析思路为理解假说内涵→设计变量（角的有无）→控制无关变量→选取合理观测指标。 - 步骤： 1. 提炼假说：“形态相同的食草动物群体能迷惑捕食者”。 2. 选择实验对象与变量：为检验该假说，模拟情境中的“形态”是关键变量。可选用有无“鹿角”的模型作为变量。一组是形态相同的无角模型群，另一组是形态相同的雄鹿角模型群。 3. 控制干扰：所有样本（假鹿）的总面积、高度、数量等应相同，排布随机，以排除这些因素的干扰。 4. 确定观测指标：记录一定时间内，捕食者（如狼）对不同形态模型群的攻击次数或捕食成功率。 5. 预测结果：若假说成立，形态单一的群体（如都是无角）应该受到更少的攻击。 - 点评/变式：此题立意较高，从行为生态学角度考察种间关系（捕食）的适应性策略。设计实验的关键在于精准定义自变量（形态是否一致），并将因变量量化（捕食者的选择频率）。这是一个典型的“验证假说”类实验设计模板。
