种间竞争

考点种间竞争权重5真题数1学科生物父主题生物与环境

考点定位

  • 父主题：生物与环境
  • 权重 weight：5
  • 真题数：1；年份跨度：2021–2021
  • 出现题位：选择8
  • 难度分布：中1

知识精要

  • 种间竞争：两种或两种以上生物相互争夺有限的资源和空间。
  • 竞争排斥原理（高斯假说）：在一个稳定的环境中，两个或两个以上受资源限制且具有相同资源利用方式的物种，不能长期共存在一起。
  • 竞争结果
  • 排斥：资源利用生态位高度重叠 → 一方存活，另一方被淘汰或死亡。
  • 共存：生态位分化（资源利用方式出现差异） → 长期共存。
  • 生态位分化：竞争物种在资源利用的时间、空间（部位）、食物大小、取食方式等方面发生分化，从而降低竞争强度。
  • 实验验证关键条件
  • 所选物种应形态和习性上很接近（或具有相同资源利用方式）。
  • 需在资源有限的环境中混合培养。
  • 竞争排斥的标志：一方存活，另一方死亡。

解题方法与套路

  1. 紧扣题干定义答题
    若题目直接给出“竞争排斥原理”的定义，则答案必须严格匹配定义的限制条件。如实验选材要求“具有相同资源利用方式”，环境资源必须“有限”。
  2. 从实验目的倒推实验现象
    明确“验证竞争排斥原理”的目的 → 结果必然是竞争排斥的典型表现（一方死亡），而不是相互抑制或共存。
  3. 生态位分化的具体化作答
    分析共存原因时，从题干已提示的一个维度（如取食种子大小）发散到同类型具体维度：取食部位、取食时间、取食高度、取食方式等。只需答出合理的一点即可。
  4. 结论归纳紧扣材料
    结论需概括整道题的研究与实验，对比竞争排斥和竞争共存的条件，用简洁语言点明核心：相同资源利用方式 → 竞争排斥，不同资源利用方式 → 竞争共存。

高频易错

  • 把“有限”写成“无限”：错误认为验证排斥需充足资源让一方充分发挥优势，实际上只有资源受限才会产生排斥，无限资源下可能无明显竞争。
  • 排斥结果表述不明确：只答“相互抑制”或“竞争”是不够的，需明确为一方存活、另一方死亡（或消失）。
  • 生态位分化答题空泛：只写“生态位不同”不符合题目要求的具体“取食角度”，必须落实到具体维度如“取食时间不同”“取食部位不同”。
  • 选材原则脱离定义：忽略题干定义中“具有相同资源利用方式的物种”，而随意写“两个不同物种”，导致失分。
  • 混淆竞争排斥与竞争共存的条件：错误认为有竞争就不能共存，忽略生态位分化可实现共存。

代表题精讲

题目（2021全国乙卷8）
在自然界中，竞争是一个非常普遍的现象。（1）为验证竞争排斥原理，选用双小核草履虫和大草履虫为材料。选择动物遵循的原则是_。需要将两种草履虫放在资源__的环境中混合培养。当实验出现__的结果时即可证实竞争排斥原理。（2）共存在同一棵树上的两种雀科鸟，经进化后分别取食大小不同的种子而共存，还可因取食的__不同而共存。（3）根据上述实验和研究，关于种间竞争的结果可得出结论是_。

思路
（1）直接引用题干对竞争排斥原理的描述：“具有相同资源利用方式的物种不能长期共存在一起” → 选材需具有相同资源利用方式或形态习性接近；资源环境必须有限，否则无法验证排斥；排斥结果应为一方死亡。
（2）取食维度分化，仿照“种子大小”例举具体且合理的角度，如取食部位、取食时间。
（3）综合实验（竞争排斥）和研究（共存）得出对比性结论：资源利用方式相同则排斥，不同则共存。

步骤
- （1）第一空：依据定义 → “形态和习性上很接近（或具有相同的资源利用方式）”。第二空：环境条件需限制资源 → “有限的”。第三空：预期验证排斥的结果 → “一方（双小核草履虫）存活，另一方（大草履虫）死亡”。
- （2）在取食角度下，除大小还可从时间、空间等答 → “部位、时间等（合理即可）”。
- （3）归纳题干信息：排斥对应“相同资源利用方式的物种竞争排斥”，共存对应“不同资源利用方式的物种竞争共存” → “有相同资源利用方式的物种竞争排斥，有不同资源利用方式的物种竞争共存”。

点评/变式
本题以经典实验和生态实例为载体，考查对竞争排斥原理的理解和迁移应用。变式可要求设计实验验证竞争排斥，或解释自然群落中竞争物种共存的其他机制（如空间异质性、干扰等）。解题核心是始终抓住“资源利用方式是否重叠”这一关键。
