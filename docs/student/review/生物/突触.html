突触

考点突触权重10真题数2学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：10
  • 真题数：2；年份跨度：2012–2022
  • 出现题位：选择3 选择8
  • 难度分布：中1 易1

知识精要

  • 突触结构：由突触前膜（轴突末端膨大而成的突触小体膜）、突触间隙（组织液）和突触后膜（下一神经元的树突膜或细胞体膜）组成。
  • 兴奋传递过程：兴奋传至突触前膜→突触小泡与突触前膜融合，以胞吐方式释放神经递质→递质通过突触间隙扩散至突触后膜→与特异性受体结合→引起下一神经元兴奋或抑制。神经递质发挥作用后，被降解酶水解或被突触前膜回收，以避免持续作用。
  • 传递特点：单向传递（递质只能由突触前膜释放作用于突触后膜）；信号转换：电信号→化学信号→电信号；存在突触延搁。
  • 功能调节：兴奋传递的强度受递质释放量、受体数量、递质降解速率等因素影响。临床上可通过调控突触传递治疗疾病：减弱传递可阻止递质与受体结合（如题中治疗肌肉痉挛），增强传递则加快释放、增加受体或抑制降解酶活性。
  • 与反射弧关系：突触是反射弧中神经元之间或神经元与效应器之间的连接结构。传入神经元的胞体在神经节；反射弧中神经中枢是最复杂部分，低级中枢受大脑皮层高级中枢调控（如屏住呼吸）。

解题方法与套路

  1. 判别传递方向与功能：先明确所给情境是兴奋传递增强还是减弱。肌肉痉挛代表传递过度，需减弱；抑制性疾病则可能需增强。
  2. 定位药物靶点：分析选项或题干中的药物作用环节——递质释放（胞吐）、递质与受体结合、递质降解（酶活性）、受体数量或敏感性。每一环节的改变会直接影响突触后膜电位变化。
  3. 逻辑推理效果：增强传递的操作（加快释放、抑制降解、增加受体）会导致兴奋加剧；减弱传递的操作（阻止结合、促进降解、减少受体）则抑制兴奋。对照题干目的选择符合项。
  4. 结构填空题：记忆突触小体对应轴突末端，突触后膜常见位置为树突或细胞体（视具体突触而定，如脊髓前角运动神经元胞体形成突触后膜）。反射弧各环节命名遵循“感受器→传入神经→神经中枢→传出神经→效应器”的固定顺序。
  5. 排除法验证：将复杂选项逐一代入模型，结合基础知识排除明显违背单向传递或功能逻辑的选项。

高频易错

  • 肌肉痉挛治疗方向混淆：误以为增加神经递质释放或受体数量能“补充不足”，忽视痉挛本质是传递过度。痉挛时需抑制传递，而非增强。
  • 忽视递质降解酶的作用：判断药物抑制降解酶活性时，易误认为此操作能终止信号，实则导致递质堆积，持续兴奋突触后膜。
  • 突触后膜位置记忆模糊：将神经元②的突触后膜误判为树突（常见错误），需根据题意或图像判断。本题中需明确神经元①轴突末梢与神经元②细胞体形成突触。
  • 反射弧组成部分混淆：如将神经中枢误认为传入神经，或将效应器当作传出神经。牢记传入神经连感受器、传出神经连效应器，神经中枢位于脑或脊髓。
  • 大脑皮层调控的遗漏：屏住呼吸等高级意识活动必须由大脑皮层参与，低级中枢脑干仅调解基本节律。此类题目易忽略高级中枢的调控功能。

代表题精讲

代表题一

题目（2022-全国乙-03）：运动神经元与骨骼肌间的兴奋传递过度引起肌肉痉挛，问合理的治疗方法。 思路：肌肉痉挛是兴奋传递过度所致，治疗必须减弱传递。逐一分析各药物对突触传递强度的影响。
步骤： 1. 选项A：加快递质释放→突触间隙递质增多→与受体结合增强→兴奋加剧（不选）。 2. 选项B：阻止递质与受体结合→无法引发突触后膜电位变化→传递阻断→减弱兴奋，可缓解痉挛（正确）。 3. 选项C：抑制降解酶→递质不被分解，持续作用→兴奋延长或增强（不选）。 4. 选项D：增加受体数量→更多递质结合→兴奋增强（不选）。
点评/变式：药物调控突触传递为高频考点。变式可考查“患者出现肌无力，需增强传递”，此时应选加快释放或增加受体的方案。核心原则：先确定兴奋目标是增强还是减弱，再对应操作。

代表题二

题目（2012-新课标-08）：肺牵张反射示意图，填空反射弧各环节及突触结构。 思路：反射弧结构需按兴奋传导路径推断；突触细节需结合神经元形态确认。 步骤： 1. 反射弧：由肺中感受器兴奋，沿传入神经（b）进入脑干（a，神经中枢），再经传出神经（c）至呼吸肌（d，效应器）。故a是神经中枢，b是传入神经，c是传出神经，d是效应器。 2. 屏住呼吸是有意识控制，必须受大脑皮层调控。 3. 突触：神经元①的轴突末端膨大形成突触小体；图（b）显示突触后膜位于神经元②的胞体上，故填“轴突”“细胞体”。
点评/变式：本题强调反射弧与突触的结构定位。常见变式：交换神经元类型，如突触后膜位于树突（需根据题图）；或考查“切断传入神经，反射是否完成”。解题核心：紧扣冲动传导路径，注意轴突末端形成的结构，以及后膜所在位置。
