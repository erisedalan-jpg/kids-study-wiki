糖蛋白

考点糖蛋白权重11真题数2学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：11
  • 真题数：2；年份跨度：2014–2014
  • 出现题位：选择1 选择3
  • 难度分布：易2

知识精要

  • 化学本质与分布：糖蛋白是细胞膜表面的蛋白质与寡糖链共价结合的复合物，糖链位于细胞膜外侧，构成细胞外被（糖萼）。
  • 核心功能：
  • 细胞识别与通讯：糖蛋白的特异性寡糖链作为分子标签，介导细胞间的识别与信号传递。
  • 细胞黏着：在动物细胞中，膜表面糖蛋白（如钙黏蛋白、整合素等）通过糖链介导细胞间的连接与黏附，维持组织结构。
  • 物质运输与受体：部分糖蛋白可作为载体或受体，参与跨膜物质运输及信号转导分子。
  • 跨膜拓扑要求：糖蛋白的糖链修饰仅发生于内质网和高尔基体腔面，因此成熟糖蛋白的糖链必须暴露于质膜外侧（或囊泡内腔），这是判断膜蛋白内外侧朝向的依据。
  • 癌细胞特征关联：癌细胞表面糖蛋白异常或减少，导致细胞间黏着性下降，易发生扩散转移。

解题方法与套路

  1. 选项直选法——锁定关键词“细胞间黏着性”与“识别” ：涉及动物细胞间连接、黏附、信息交流功能的直接指向，多半考查糖蛋白。见到“动物细胞间的黏着性”等描述，可直接与糖蛋白建立联系。
  2. 对比排除法——区分植物特有结构：遇到植物细胞的特殊结构（如胞间连丝、蔗糖合成能力）时，需与动物细胞的功能进行区分。胞间连丝是细胞质通道，主要成分是内质网、连丝微管等，非糖蛋白主导的识别黏附。
  3. 功能定位排除法：若题干涉及内环境物质交换（如组织液回流）、ATP能量代谢等，此类过程虽依赖膜蛋白，但核心考点往往不在糖蛋白的特异性识别与黏着功能，而在物质跨膜运输机制或能量转化。
  4. “动物/植物”差异排查：题目若同时提及动植物细胞功能比较，动物细胞特有的黏着机制（依赖糖蛋白）和植物细胞特有的营养合成（如蔗糖）是重要辨析点。

高频易错

  • 混淆植物胞间连丝与动物黏着机制：胞间连丝是植物细胞间物质运输和信息传递的通道蛋白结构，而动物细胞间的黏着主要依赖细胞膜上的糖蛋白。二者功能有相似但物质基础截然不同，不可混用。
  • 误认为所有物质运输均依赖糖蛋白：细胞物质输入输出是一大类生理过程，糖蛋白主要介导识别依赖性的运输或信号转导，普通气体、小分子、离子的扩散或一般载体运输并不一定需要糖蛋白的识别功能。
  • 代谢合成产物与膜蛋白功能混淆：哺乳动物能合成乳糖，但不能合成蔗糖；植物能合成蔗糖。此类代谢差异与糖蛋白的结构功能无关，属于酶系统差异，易在综合题中错选。
  • 内环境稳态与糖蛋白脱离：组织液生成与回流依赖于毛细血管壁通透性、血浆胶体渗透压与静水压差等物理和屏障因素，主要考查内环境循环的理化因素，不直接考查糖蛋白的黏附功能。

代表题精讲

题目（2014-新课标Ⅱ-01）：关于细胞的叙述，错误的是（ D ） A．植物细胞的胞间连丝具有物质运输的作用
B．动物细胞间的黏着性与细胞膜上的糖蛋白有关
C．ATP水解释放的能量可用于细胞内的吸能反应
D．哺乳动物的细胞可以合成蔗糖，也可以合成乳糖

思路：逐项排查四个选项的生物学事实正确性。A考查植物细胞特有结构功能，B考查动物细胞膜成分功能，C考查ATP能量耦联，D考查动物糖代谢能力。锁定不符合事实的选项。

步骤： 1. A选项：胞间连丝是贯穿植物细胞壁的细胞质通道，实现共质体运输，正确。 2. B选项：细胞外被的糖蛋白含有特异性糖链，介导细胞识别与黏着，动物细胞黏着依赖于此，正确。 3. C选项：ATP水解直接供能，是胞内吸能反应（如合成代谢、主动运输）的能量来源，正确。 4. D选项：哺乳动物肝细胞可利用半乳糖合成乳糖，但缺乏蔗糖合成酶系，不能合成蔗糖。蔗糖主要在植物细胞合成。此说法错误。

点评/变式：本题为典型的正误判断型，常将不同模块的基础知识点混合。D选项易混淆单糖、二糖的动植物来源。变式可考查“癌细胞易转移的原因”，此时应联系B选项——癌细胞膜表面糖蛋白减少，黏着性降低。

题目（2014-新课标Ⅱ-03）：关于正常情况下组织液生成与回流的叙述，错误的是（ A ） A．生成与回流的组织液中氧气的含量相等
B．组织液不断生成与回流，并保持动态平衡
C．血浆中的有些物质经毛细血管动脉端进入组织液
D．组织液中的有些物质经毛细血管静脉端进入血液

思路：梳理组织液生成与回流的压力机制和物质交换梯度。生成端发生在毛细血管动脉端，回流端发生于静脉端及淋巴管，此过程伴随着氧气及代谢废物的浓度变化。

步骤： 1. A选项：动脉端血液富氧，依压力滤过生成的组织液含氧量高；组织细胞不断消耗氧气，使生成侧与回流入静脉端的组织液间存在氧分压差，氧气含量不可能相等。A明显错误。 2. B选项：稳态下，组织液的生成量与回流量（含淋巴回流）保持动态平衡，防止水肿，正确。 3. C选项：血浆中的氧气、水分、小分子营养物质、激素等可经毛细血管动脉端进入组织液，正确。 4. D选项：组织细胞产生的二氧化碳、尿素等代谢废物可经毛细血管静脉端及淋巴管回收，正确。

点评/变式：该题虽归属内环境考点，但易跟细胞膜载体与糖蛋白功能混淆。A选项揭示物质跨毛细血管壁交换过程中浓度梯度驱动的非均一性。变式可问及“构成组织液渗透压的主要成分”或“组织液回流受阻的病理（如水肿）”，均依赖对稳态物质回流机制的理解，不涉及糖蛋白的识别黏连。
