考点定位

  • 父主题：遗传与进化
  • 权重 weight：6
  • 真题数：1；年份跨度：2017–2017
  • 出现题位：选择10
  • 难度分布：中1

知识精要

  • 系谱图：用标准符号绘制，表示家族中各成员性状表现及亲缘关系。常染色体遗传与性染色体遗传符号一致，但需注明性别（□男、○女）和患病（■●或填充）。
  • 伴X隐性遗传的核心规律：
  • 患病男性（$X^aY$）远多于女性，男性只要携带致病基因即患病。
  • 女性患者（$X^aX^a$）的儿子一定患病；患病男性的母亲和女儿一定是携带者（$X^AX^a$）或患者。
  • 交叉遗传：致病基因常表现为“外公→女儿→外孙”的传递模式。
  • 基因频率与基因型频率（伴性遗传）：
  • 男性只有一条X染色体，男性群体中 致病基因频率 = 男性患病率。
  • 在满足群体平衡（随机婚配、无突变、无选择等）且 男女致病基因频率相等 的假设下，女性群体的基因频率与男性相同。
  • 女性群体中各基因型频率满足哈代-温伯格定律：$p^2 + 2pq + q^2 = 1$，其中$q$为致病基因频率，$p$为正常基因频率。女性携带者比例 = $2pq$，女性患者比例 = $q^2$。
  • 概率计算要点：
  • 必须先根据亲代与子代表现型确定个体可能的基因型及其概率。
  • 非血友病夫妇生出非双胞胎女儿，大女儿已生患病男孩，可反推大女儿基因型，进而推断小女儿基因型概率（在无额外信息时，需考虑条件概率）。
  • 计算子代患病概率时，注意区分男孩患病概率与患病男孩概率：伴X隐性遗传中，母亲为携带者时，儿子患病概率为 $\frac{1}{2}$，女儿患病概率为0（父亲正常）。

解题方法与套路

  1. 系谱图绘制
  2. 从题干提取亲代、子代成员及其性状。
  3. 按世代自上而下，同代从左到右排列，用婚姻线和亲子连线连接。

  4. 已知患病者填充或标记，未知性别未出生个体用“?”或菱形表示，题干特殊要求（如用“□”表示未知孩子）须遵从。

  5. 基因型推断与概率计算

  6. 先定性后定量：根据表现型和遗传方式确定“必然基因型”与“可能基因型”。
  7. 反推与正推结合：利用患病后代逆推亲代基因型（如大女儿生出患病男孩，则大女儿必为携带者）。
  8. 条件概率转化：大女儿和小女儿为同卵双胞胎？非双胞胎，则基因型独立。由大女儿表现型（正常）且生患病男孩，可知大女儿为 $X^AX^a$；而其父母均正常，父亲 $X^AY$，母亲必为 $X^AX^a$。小女儿表现正常，其基因型可能为 $X^AX^A$ 或 $X^AX^a$，概率各 $\frac{1}{2}$？需注意：母亲为携带者，父亲正常，女儿必然从父亲获得正常基因 $X^A$，从母亲获得 $X^A$ 或 $X^a$ 各 $\frac{1}{2}$，因此女儿为携带者的概率为 $\frac{1}{2}$。

  9. 概率拆分：问“生出血友病男孩的概率”，分解为“孩子是男孩且患病”。若小女儿是携带者（概率 $\frac{1}{2}$），则与正常男子（$X^AY$）婚配，儿子患病概率为 $\frac{1}{2}$（儿子从母亲获得$X^a$），故最终概率 = $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。若问“携带者女孩概率”，女孩必从父亲获得 $X^A$，为携带者需从母亲获 $X^a$，概率为携带者母亲概率 $\frac{1}{2}$ 乘以传给女儿 $X^a$ 概率 $\frac{1}{2}$，再乘以生女儿概率 $\frac{1}{2}$？错。若已明确是女孩，则不乘性别概率。题干“生出血友病基因携带者女孩的概率”意为所生孩子是女孩且为携带者，需乘生女孩概率 $\frac{1}{2}$。若两女儿基因型相同，则小女儿一定为携带者，此时携带者女孩概率 = $\frac{1}{2}$（携带者概率1 × 生女概率 $\frac{1}{2}$）？实际上如果小女儿基因型已知为携带者，生女且携带者的概率：女儿从父亲得 $X^A$，从母亲得 $X^a$ 的概率是 $\frac{1}{2}$，而孩子是女儿的概率为 $\frac{1}{2}$，所以概率 = $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。仔细审题。

  10. 伴性基因频率计算

  11. 利用男性患病比例直接得到致病基因频率（$q =$ 男性发病率）。
  12. 默认男女基因频率相等，女性携带者比例 = $2q(1-q)$。
  13. 注意：群体平衡时，男性患者比例即为 $q$，女性患者比例为 $q^2$。此处男性群体中血友病患者的比例为1%，即 $q=0.01$，女性携带者比例 = $2 \times 0.01 \times 0.99 = 0.0198 = 1.98\%$。

高频易错

  • 混淆“男孩患病”与“患病男孩”：伴X遗传中两者计算路径不同，尤其当亲本基因型不确定时，必须分别乘以性别概率或条件概率。
  • 伴X遗传下小女儿基因型概率的确定：父母正常，父亲 $X^AY$，母亲 $X^AX^a$，小女儿正常，基因型为 $X^AX^A$ 或 $X^AX^a$，概率并非简单的 $\frac{1}{3}$ 和 $\frac{2}{3}$。女儿必从父亲获得 $X^A$，从母亲获得 $X^A$ 或 $X^a$ 的概率各 $\frac{1}{2}$，因此携带者概率为 $\frac{1}{2}$。常染色体隐性杂合子自交，正常后代表现型中杂合子概率才是 $\frac{2}{3}$，此处不要混淆。
  • 条件信息利用不充分：题干中“假如这两个女儿基因型相同”，暗示小女儿基因型与大女儿相同（即 $X^AX^a$），此时概率计算需直接用确定基因型，不再考虑 $\frac{1}{2}$ 的概率前提。
  • 基因频率计算特殊规则：伴X遗传在男女群体中达到平衡时，男性基因频率可直接由男性表型频率得出，女性群体则符合 $p^2, 2pq, q^2$，但计算时务必分清 $q$ 的含义及适用群体。切不可将男性患病率直接代入女性患病率。
  • 系谱图绘制不规范：未按世代排列、未标明个体序号或关系、患病与正常混淆、未用标准图形或遗漏已怀孕个体表示。

代表题精讲

题目：人血友病是伴X隐性遗传病。一对非血友病夫妇生出两个非双胞胎女儿。大女儿与正常男子结婚生出血友病男孩。小女儿与正常男子结婚并已怀孕。回答：（1）画系谱图；（2）小女儿生出患血友病男孩的概率；若两女儿基因型相同，小女儿生出血友病基因携带者女孩的概率；（3）男性群体血友病比例1%，求致病基因频率及女性携带者比例。

思路：根据伴X隐性遗传特点，从患病男孩反推大女儿必为携带者，进而确定外祖父母（即题干中的那对非血友病夫妇）基因型：父亲 $X^AY$，母亲 $X^AX^a$。由此推知小女儿基因型及概率。第（3）问利用男性表型频率等于基因频率，再转换到女性群体计算携带者比例。

步骤： 1. 绘制系谱图：
第一代：□正常男、○正常女（夫妇）。
第二代：两个女儿，○正常大女儿、○正常小女儿。大女儿与□正常男婚配后，生出一■患病男孩（第三代的第一个孩子）。小女儿下方连□?表示未出生孩子。标注血亲关系。 2. 计算小女儿后代概率：
已知大女儿生出患病男孩，故大女儿基因型为 $X^AX^a$。小女儿表型正常，其父亲提供 $X^A$，母亲提供 $X^A$ 或 $X^a$ 的概率各 $\frac{1}{2}$，所以小女儿为 $X^AX^a$ 的概率 = $\frac{1}{2}$。
- 生出患血友病男孩：需小女儿为携带者（$\frac{1}{2}$）× 生男孩概率（$\frac{1}{2}$）× 男孩患病概率（$\frac{1}{2}$）= $\frac{1}{8}$。
- 若两女儿基因型相同，则小女儿也为 $X^AX^a$。生出血友病基因携带者女孩：生女孩概率 $\frac{1}{2}$ × 女儿从母亲获得 $X^a$ 概率 $\frac{1}{2}$ = $\frac{1}{4}$。 3. 基因频率计算：
男性群体中血友病患者比例 = 1%，即男性致病基因频率 $q = 0.01$。假设男女基因频率相等，则女性群体中致病基因频率也为 0.01，正常基因频率 $p = 0.99$。女性携带者比例 = $2pq = 2 \times 0.01 \times 0.99 = 0.0198 = 1.98\%$。

点评/变式：此题全面考查伴X隐性遗传的系谱分析、条件概率拆解以及基因频率的性别差异。易错点在于小女儿基因型概率的推导以及“携带者女孩”是否乘以性别系数。变式可联系X显性遗传或常染色体遗传的频率计算，对比哈代-温伯格定律的适用场景。
