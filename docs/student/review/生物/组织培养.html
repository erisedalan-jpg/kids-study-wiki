组织培养

  • 父主题：生物技术与工程
  • 权重 weight：0
  • 真题数：1；年份跨度：2016–2016
  • 出现题位：选择1
  • 难度分布：中1

知识精要

  • 植物组织培养原理：基于植物细胞的全能性，即已分化的植物细胞含有本物种全套遗传信息，在适宜条件下可发育成完整植株。需离体培养、无菌操作、适宜激素配比（生长素与细胞分裂素）等。
  • 全能性表达条件：①离体（外植体）；②严格无菌；③培养基提供水、无机盐、有机物及激素；④适宜温度等环境。
  • 植物组织培养过程：外植体 → 脱分化（形成愈伤组织）→ 再分化（根、芽）→ 完整植株。脱分化丧失原有分化状态，再分化重新分化形成器官。
  • 实例：叶肉细胞经组织培养可获得新植株，体现了细胞的全能性。花粉（单倍体细胞）经组织培养得到单倍体植株，也是全能性的体现。
  • 动物细胞核全能性：动物已分化细胞的细胞核经移植到去核卵母细胞中，可发育成个体，证明动物细胞核具有全能性（如克隆羊多利）。但分化动物细胞的全能性受限，通常不直接培养成个体。
  • 细胞分化：基因选择性表达的结果，分化细胞仍具有全套基因，只是表达情况不同。造血干细胞是已分化的多能干细胞，可分化为各种血细胞，不是“未经分化”的细胞。
  • 有丝分裂的意义：将亲代细胞复制的染色体精确均分到两个子细胞，保持亲子代遗传性状的稳定，对生物性状的遗传有重要贡献。

解题方法与套路

  1. 判断细胞全能性的表现：关键看一个细胞（或离体组织）最终发育成完整生物个体（或完整的器官系统）。组织培养成完整植株体现全能性；动物克隆中核移植成功体现细胞核全能性。
  2. 辨析细胞的分化程度：
  3. 胚胎干细胞：未分化或低分化；
  4. 成体干细胞（如造血干细胞）：已分化，具有特定分化方向；
  5. 体细胞（如叶肉细胞）：高度分化。
  6. 有丝分裂与遗传稳定性：有丝分裂过程中DNA复制后精确均分，子代细胞遗传物质相同，这是保持遗传性状的基础。若无变异，有丝分裂不改变遗传组成。
  7. 区分“基因选择性表达”与“基因丢失”：细胞分化时遗传物质不丢失，只是不同基因开启或关闭。植物的组织培养复原完整植株正是基于分化细胞仍保留全套基因。
  8. 组织培养应用的判断：选项中出现“组织培养”“快速繁殖”“脱毒苗”“花粉培养”等，一般体现全能性。但要注意是否强调离体、无菌条件等，若违背这些条件则不能实现。

高频易错

  • 混淆造血干细胞的分化状态：许多考生误认为造血干细胞是“未经分化的细胞”，实际上它是多能干细胞，已经分化，只是分化程度较低，能继续分化为多种血细胞。
  • 误将有丝分裂与遗传改变联系：有丝分裂产生的是与亲代细胞相同的子细胞，在无突变时不会改变遗传性状，因此对性状遗传有贡献是“维持”而非“改变”。错误选项中可能出现“有丝分裂导致性状分离”之类的陷阱。
  • 全能性概念的扩大化：并非所有细胞都直接表现全能性，动物体细胞需借助核移植技术才能证明其细胞核的全能性；植物体细胞则常通过组织培养直接体现全能性。若选项中说法为“动物任何细胞都能培养成新个体”则是错误的。
  • 组织培养条件缺失：认为组织培养只需植入土壤即可，忽略了严格无菌、适宜培养基与激素配比等必要条件。考试中若出现“将叶片直接插入土壤长成植株”属于扦插，不属于组织培养的全能性体现。
  • 细胞分化与基因丢失混淆：错误地认为分化的细胞丢失了某些基因，才导致功能差异。正解是分化细胞保留了全部基因，只是选择性表达不同。

代表题精讲

2016-新课标Ⅱ-01（细胞的生命历程综合）

题目：下列叙述错误的是
A．细胞的有丝分裂对生物性状的遗传有贡献
B．哺乳动物的造血干细胞是未经分化的细胞
C．细胞分化是细胞内基因选择性表达的结果
D．通过组织培养可将植物叶肉细胞培育成新的植株

思路
逐一分析选项，调用细胞分化、细胞全能性、有丝分裂等核心概念。重点认定造血干细胞已分化；有丝分裂保持遗传稳定；植物组织培养基于全能性。

步骤
1. 选项A：有丝分裂可将亲代细胞的染色体精确平均分配到两个子细胞，保证子代含与亲代相同的遗传物质，若无突变，性状得以稳定传递，因此对性状遗传有贡献，A正确。
2. 选项B：造血干细胞是存在于骨髓中的多能干细胞，能分化为红细胞、白细胞、血小板等，属于已分化的细胞（只是分化潜能较大），并非未分化细胞，故B错误。
3. 选项C：细胞分化的实质就是基因的选择性表达，同一生物的不同细胞中，表达的基因种类不同，导致形态、结构和功能差异，C正确。
4. 选项D：植物叶肉细胞是高度分化的体细胞，但含有本物种全套基因，经离体培养、给予合适条件可脱分化、再分化形成完整植株，这体现了植物细胞的全能性，D正确。
5. 题干要求选错误的，综上错误选项为B。

点评/变式
本题将细胞分裂、分化、全能性等多个核心概念串联，典型陷阱是误认为干细胞就是未分化的。备考提醒：干细胞按分化能力分全能、多能、单能等，其中造血干细胞为多能干细胞，已分化。变式练习可考查“花粉离体培养获得单倍体植株”体现全能性，或追问“植物组织培养过程中脱分化的实质”等。抓住“已分化细胞是否恢复全能性、需什么条件”是突破此类题的关键。
