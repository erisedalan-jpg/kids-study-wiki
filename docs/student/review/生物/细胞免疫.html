细胞免疫

考点细胞免疫权重14真题数2学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：14
  • 真题数：2；年份跨度：2014–2023
  • 出现题位：选择3 选择8
  • 难度分布：中2

知识精要

  • 免疫细胞：执行免疫功能的细胞，来自骨髓造血干细胞，包括淋巴细胞、树突状细胞、巨噬细胞等。
  • 识别机制：免疫细胞表面的受体可识别病原体表面的特定蛋白质等物质，区分“自己”与“非己”。
  • 抗原呈递细胞（APC）：$ \text{B细胞} $、树突状细胞、巨噬细胞等均可摄取、加工、处理抗原，并将抗原信息呈递给辅助性T细胞。注意：B细胞属于淋巴细胞。
  • 细胞免疫核心过程：靶细胞（被病原体侵染）膜表面的某些分子发生变化，被细胞毒性T细胞（效应T细胞）识别。细胞毒性T细胞与靶细胞特异性结合，使其裂解死亡，释放病原体。
  • 辅助性T细胞：在体液免疫中，其表面的特定分子发生变化并与B细胞结合，同时分泌细胞因子促进B细胞增殖分化为浆细胞和记忆B细胞；在细胞免疫中，也参与细胞毒性T细胞的活化。
  • 记忆细胞：体液免疫产生记忆B细胞，细胞免疫产生记忆T细胞。二次免疫反应更快、更强。
  • 免疫类型关系：某些致病细菌（胞内寄生菌等）感染人体，既可引发体液免疫，也可引发细胞免疫。
  • 效应T细胞（现称细胞毒性T细胞）的作用：识别并裂解被病原体入侵的靶细胞。
  • 细胞因子：主要由T细胞产生（旧称淋巴因子），作用于B细胞，促进其增殖分化。

解题方法与套路

  1. 精准辨析免疫细胞与物质功能
    • 遇到“免疫细胞受体识别”叙述，抓住所有免疫细胞均需依靠表面受体识别信号分子或病原体这一共性。
    • 涉及“淋巴细胞能否呈递抗原”，需特别注意B细胞是一种淋巴细胞，且属于专职抗原呈递细胞。
  2. 区分两种特异性免疫的过程与联系
    • 判断某免疫过程属于体液免疫还是细胞免疫，关键看最终效应机制：依赖抗体清除胞外病原体为体液免疫；依赖效应T细胞裂解靶细胞为细胞免疫。
    • 定位辅助性T细胞的作用时，默记其“两头管”——既辅助B细胞（体液免疫），又辅助初始T细胞活化为效应T细胞（细胞免疫）。选项中“仅参与体液免疫”必错。
  3. 厘清记忆细胞的来源
    • 记忆B细胞来源于B细胞增殖分化（体液免疫过程）。
    • 记忆T细胞来源于细胞毒性T细胞增殖分化（细胞免疫过程）。
    • 若题目将某种记忆细胞张冠李戴给另一种免疫过程，直接判定为错误。
  4. 实验与材料题分析技巧
    • 分析免疫功效实验（如草药对免疫影响）：先定位自变量（不同处理组）与因变量（吞噬能力、T细胞含量、抗体水平等）的对应关系。
    • 见到吞噬能力提升，关联非特异性免疫；见到T细胞含量或抗体量变化，关联特异性免疫及对应过程。
    • 对于教材标准答案式的填空（如效应T细胞作用），严格对照课本人教版黑体字原话作答。

高频易错

  • 混淆B细胞的分类：误认为“淋巴细胞不能呈递抗原”。正确知识是：B细胞是淋巴细胞的主要类型之一，能处理和呈递抗原，尤其在再次免疫应答中作用关键。
  • 误判辅助性T细胞的功能范围：错误地认为辅助性T细胞仅参与体液免疫过程。必须牢记：辅助性T细胞既参与体液免疫的激活，也是细胞毒性T细胞活化所必需的。
  • 记忆细胞归属不清：在判断或填写“细胞免疫产生的记忆细胞”时误写“记忆B细胞”。需形成条件反射：体液免疫→记忆B细胞；细胞免疫→记忆T细胞。
  • 效应T细胞作用对象混淆：将效应T细胞的作用描述为“直接杀死病原体”。正确的是：效应T细胞是与被病原体入侵的宿主细胞（靶细胞）密切接触，导致靶细胞裂解死亡，而非直接攻击游离病原体。
  • 淋巴因子与细胞因子的名词更替：旧教材称为淋巴因子，新教材统一为细胞因子。答题时需注意所处语境，防止新旧名称混用失分。

代表题精讲

代表题一：2023-新课标-03

  • 题目：判断关于免疫细胞与过程的五个叙述组合，选出正确选项。
  • 思路：逐条推敲每个叙述，利用免疫细胞识别、抗原呈递、辅助性T细胞功能、记忆细胞来源等核心知识点排除错误项。
  • 步骤：
    1. 审析①：“免疫细胞表面的受体可识别细菌、病毒……”。免疫应答始于识别，受体识别是基础，①正确。
    2. 审析②：“树突状细胞能够处理和呈递抗原，淋巴细胞不能呈递抗原”。B细胞（淋巴细胞的一种）是典型的抗原呈递细胞，②错误。
    3. 审析③：“辅助性T细胞参与体液免疫……而不参与细胞免疫”。辅助性T细胞在两个免疫过程中均发挥关键启动/辅助作用，③错误。
    4. 审析④：“体液免疫可产生记忆B细胞，细胞免疫可产生记忆T细胞”。两种特异性免疫均产生对应的记忆细胞以维持长期免疫力，④正确。
    5. 审析⑤：“某些致病细菌……既可引发体液免疫又可引发细胞免疫”。胞内寄生菌等是经典例子，⑤正确。
    6. 综上，正确的是①④⑤，匹配B选项。
  • 点评/变式：本题通过多项组合的形式，集中考查了特异性免疫中极易混淆的核心概念。特别是“淋巴细胞不能呈递抗原”和“辅助性T细胞不参与细胞免疫”，是历届考生最频繁掉入的陷阱。这类题目需具备“概念纠错”的敏感性，复习时需将B细胞、树突状细胞、巨噬细胞并列为APC家族，并强化辅助性T细胞的枢纽地位。

代表题二：2014-新课标Ⅱ-08

  • 题目：以探究草药提高小鼠免疫功能为背景，填空回答非特异性免疫特点、效应T细胞作用及体液免疫因子与细胞关系。
  • 思路：第一部分由实验数据概括非特异性免疫要点；第二部分由T细胞含量变化引出细胞免疫，精确作答教材效应T细胞功能定义；第三部分依循体液免疫中“T细胞→细胞因子→B细胞→抗体”这一核心轴线填空。
  • 步骤：
    1. （1）非特异性免疫特点：实验提及吞噬细胞吞噬能力增强，其特点应从“先天性”“无特异性”角度作答：机体生来就有，不针对某一特定病原体，而是对多种病原体都有一定的防御作用。
    2. （2）效应T细胞作用：题干延伸至特异性免疫中的细胞免疫，效应T细胞的作用核心是其对靶细胞的攻击方式：识别并与被病原体入侵的宿主细胞密切接触，使之裂解死亡。
    3. （3）免疫因子与细胞：依序回忆体液免疫流程。T细胞分泌的物质在彼时语境下为“淋巴因子”（现代教材称细胞因子）；其作用的接受者为“B细胞”；B细胞最终增殖分化为“浆细胞”，分泌“抗体”。
  • 点评/变式：本题完美融合了实验分析结论与教材固有概念填空。难点在于：需要将实验组的对比结果（吞噬能力关键点、T细胞含量）迅速映射到“非特异性免疫”与“特异性免疫”的大框架中。对效应T细胞作用的描述必须高度规范，一字不差；对“T细胞-淋巴因子-B细胞-抗体”这条路径的考查，揭示选择性填空往往环环相扣，任一环节生疏便全局被卡，复习时应将体液免疫和细胞免疫的全流程精确到每一个短语。
