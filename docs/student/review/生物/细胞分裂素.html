细胞分裂素

考点细胞分裂素权重12真题数3学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：12
  • 真题数：3；年份跨度：2012–2024
  • 出现题位：填空13 选择7 选择11
  • 难度分布：中1 易2

知识精要

  • 核心定义：细胞分裂素是一类促进细胞质分裂的植物激素，化学本质多为腺嘌呤衍生物，主要在根尖合成，经木质部由下向上运输。
  • 功能要点：
  • 细胞分裂协同：与生长素共同调控细胞增殖，生长素促进细胞核分裂，细胞分裂素促进细胞质分裂。
  • 组织培养应用：诱导芽分化，调节其与生长素的比例可控制器官发生方向（比例高促芽，比例低促根）。
  • 延缓衰老：抑制蛋白质与叶绿素分解，维持叶片生理活性。
  • 对抗顶端优势：促进侧芽萌发，打破顶端抑制。
  • 合成与调控：细胞分裂素合成酶（如LOG2蛋白）催化合成，水解酶介导降解；两者活性平衡决定其含量。环境胁迫（如重金属砷）可通过改变基因表达影响该平衡。
  • 人工类似物：6-苄基腺嘌呤（6-BA）是常用细胞分裂素类植物生长调节剂，在MS培养基中用于诱导丛芽再生。

解题方法与套路

  1. 图表逻辑推理法（针对实验数据题）
    🔹 第一步：拆解图表要素——明确坐标轴代表哪两种基因（合成酶基因、水解酶基因）的相对表达量，确定时间点分组。
    🔹 第二步：净效应判读——若合成酶表达量高于水解酶，则激素净合成 > 净降解，激素总量上升；反之则下降。不可只看单一指标。
    🔹 第三步：跨图关联——将激素含量变化与表型（如根长、芽数）或另一激素（如生长素）数据关联，导出因果关系。

  2. 精准填空/简答法（针对基础知识题）
    🔹 记忆口诀：“核生质裂”（生长素促细胞核分裂，细胞分裂素促细胞质分裂）。
    🔹 教材原话还原：间期物质准备 “DNA分子复制和有关蛋白质的合成”。
    🔹 环境因素扩展：光受体必答“光敏色素”，环境因素多选“温度”“重力”。

  3. 实验设计速析法（针对培养基类试题）
    🔹 看表头：确认自变量是激素组合（如6-BA与IAA浓度），因变量是外植体再生比率和丛芽平均数。
    🔹 比趋势：对比不同浓度下因变量变化，找到促进或抑制的阈值。
    🔹 归类必备：6-BA、激动素属细胞分裂素类，IAA、NAA属生长素类，切勿混淆。

高频易错

  • 断章取义推断激素含量：看到水解酶表达降低，就断定激素含量减少，忽略合成酶表达同时显著更高。务必计算净效应：合成酶高且水解酶低 → 含量增加。
  • 生长素与细胞分裂素在分裂中角色互换：错误答“生长素促细胞质分裂”。设立防错检查点：细胞核是司令部，生长素驱动核内活动；细胞质是执行层，细胞分裂素驱动胞质分离。
  • 6-BA归类误判：由于实验常与IAA同时出现，误将6-BA也归为生长素类。牢记：6-BA化学结构模拟细胞分裂素，功能上诱导芽形成，属于细胞分裂素类似物。
  • 忽略激素双重作用：高浓度生长素会抑制根伸长（如砷处理组生长素含量高但根短），解题时不能单向认为生长素都促进生长，应力抓题干数据给出的实际反应。

2024-辽宁-13 砷胁迫与细胞分裂素含量分析

题目：
通过检测砷酸盐处理拟南芥根中细胞分裂素合成酶/水解酶基因表达量、生长素含量和根长，选择错误推测。

思路：
本题核心为“基因表达 → 激素含量 → 生理效应”的串联推理。逐个选项核查逻辑链条是否与图表数据一致。

步骤：
- 分析A：图1显示6h时，细胞分裂素合成酶基因表达量极高，水解酶基因表达量极低，说明合成远大于分解，细胞分裂素净含量应增加。A选项称含量减少，直接与数据矛盾，故A错误。
- 验证B：图2、3表明砷处理组生长素含量高于对照，但根长显著变短，符合“高生长素抑制根生长”的双重作用。合理。
- 验证C：图1中LOG2基因表达随时间下降，LOG2蛋白是合成所需，增强其活性可弥补砷造成的损失，理论可行。合理。
- 验证D：根是吸水吸盐主力器官，抑制其生长必定削弱吸收功能。合理。

点评/变式：
此题骨子里考的是“数据不被表象欺骗”。变式常将砷换为干旱，细胞分裂素换为脱落酸，方法不变：盯准合成与分解两条线，求净变化。

2023-新课标-07 细胞分裂的激素分工与环境调控

题目：
（1）细胞分裂间期的物质准备内容；（2）生长素和细胞分裂素在促进细胞分裂时的具体作用分工；（3）接受光信号的受体及其他环境因素举例。

思路：
纯主干知识再现。扫一遍教材下关键短语，针对（2）需要严格区隔两者动词后的宾语。

步骤：
- （1）答：DNA分子复制和有关蛋白质的合成。不能漏掉“有关”二字，不能把间期准备等同于整个间期所有事件。
- （2）答：生长素的主要作用是促进细胞核的分裂，细胞分裂素的主要作用是促进细胞质的分裂。顺序不能颠倒。
- （3）受体答：光敏色素（或向光素）。环境因素答：温度、重力（或水分）。开放采分，但需是教材常驻点。

点评/变式：
看似散装填空，实为激素协同作用的底层切片。变式可能问赤霉素与脱落酸在种子萌发中的抗衡，答题思路同样：一词定位关键原料。

2012-新课标-11 6-BA分类与组织培养基础

题目：
给定6-BA和IAA不同浓度组合对菊花外植体再生丛芽影响的结果表，要求填写培养基无机盐元素类别及6-BA的激素归类。

思路：
此题在2012年考查基础识记，直接对应教材元素分类概念和植物生长调节剂谱系。

步骤：
- 元素类：大量元素与微量元素。这是基于植物需求量，记忆“大量九种”或口诀即可调用。
- 6-BA归类：题中讲明6-BA与IAA相比，IAA是生长素，6-BA在促进丛芽中起细胞分裂素样作用，必须答出“细胞分裂素类”。不能因为还有别的激素就混乱。
