细胞吸水与失水

考点细胞吸水与失水权重5真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：5
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 渗透作用：水分子（或其他溶剂分子）通过半透膜从低浓度溶液向高浓度溶液扩散。
  • 发生条件：①有半透膜；②膜两侧溶液存在物质的量浓度差（渗透压差）。
  • 植物细胞渗透系统：原生质层（细胞膜+液泡膜+细胞质）相当于半透膜，细胞液与外界溶液通过原生质层进行渗透。细胞壁为全透性，起支撑保护作用。
  • 质壁分离与复原：
  • 当细胞液渗透压 < 外界溶液渗透压，细胞失水，原生质层与细胞壁分离（质壁分离）。
  • 当细胞液渗透压 > 外界溶液渗透压，细胞吸水，质壁分离复原（若已分离）。
  • 渗透压比较：渗透压取决于单位体积溶液中溶质微粒数，即 $\Pi = iCRT$（$i$ 为等渗系数，$C$ 为物质的量浓度）。对于相同质量浓度的非电解质溶液，相对分子质量越小，物质的量浓度越大，渗透压越高。
  • 溶液浓度变化与水分移动（无溶质交换时）：
  • 外界溶液浓度升高 → 溶液体积减小 → 细胞吸水（细胞从溶液吸收水分）。
  • 外界溶液浓度降低 → 溶液体积增大 → 细胞失水。
  • 外界溶液浓度不变 → 水分进出达动态平衡，细胞净吸水量为零。

解题方法与套路

  1. 明确半透膜与可透物质：确认水分可自由通过，溶质是否可通过半透膜。常见实验情景中，蔗糖、糖类等一般假定为不能通过原生质层。
  2. 统一比较尺度：题干若给出质量浓度（如 g/mL），必须结合溶质相对分子质量转化为物质的量浓度或直接比较渗透压。牢记：相同质量浓度下，分子量小的溶质溶液渗透压高。
  3. 根据平衡后浓度变化推断水流方向：
  4. 溶液浓度 升高 → 水从溶液流向细胞（细胞吸水）。
  5. 溶液浓度 降低 → 水从细胞流向溶液（细胞失水）。
  6. 溶液浓度 不变 → 水分净移动为零。
  7. 判断细胞状态：结合细胞吸水/失水方向，判断其是否发生质壁分离或吸水膨胀。细胞失水到一定程度可出现质壁分离；细胞持续吸水可使质壁分离复原。
  8. 比较不同组别吸水量：仅凭两组都吸水（或都失水）不能直接得出具体吸水量大小，需进一步比较各自的渗透压差及平衡状态。

高频易错

  • 混淆质量浓度与物质的量浓度：误以为质量浓度相同则渗透压相同，忽视分子量差异。如本题中甲糖相对分子质量约为乙糖 2 倍，导致两者的物质的量浓度相差约 2 倍，渗透压显著不同。
  • 错误归因溶液浓度变化：在无溶质交换时，溶液浓度升高是水分减少所致，并非溶质增多；浓度降低则是水分增加。部分考生误认为溶质进出改变了浓度。
  • 忽略“无溶质交换”条件：若溶质也能透过半透膜，则水分移动和最终平衡需同时考虑水势和溶质扩散，分析思路完全不同。务必紧扣题目给出的限制。
  • 混淆细胞吸水量与溶液浓度变化的程度：选项 D 类陷阱——认为两组都吸水时，某一组的净吸水量一定更大，而未考虑初始渗透势差及平衡时内外浓度关系，可能无法比较。
  • 质壁分离概念模糊：细胞失水不一定立刻发生质壁分离，但持续失水通常导致原生质体收缩，与细胞壁分离。只要细胞失水，即可推断可能发生质壁分离。

代表题精讲

题目（2020·新课标Ⅱ·05）
将成熟植物叶片圆片分别放入质量浓度相同的甲糖溶液和乙糖溶液中（甲糖相对分子质量约为乙糖的2倍），全程叶细胞与溶液无溶质交换。平衡后测得甲糖溶液浓度升高。判断下列说法错误选项。

思路
- 关键：甲、乙初始质量浓度相同，但分子量甲≈2×乙 → 甲糖溶液物质的量浓度（渗透压）约为乙糖溶液的 1/2。
- 甲组溶液浓度升高 → 溶液失水 → 甲组叶细胞吸水，说明细胞液渗透压 > 甲糖溶液渗透压。
- 乙糖溶液初始渗透压较高，未知细胞液渗透压与乙糖溶液的关系，需依据浓度变化分情况讨论。

步骤
1. 分析 A 项：甲组溶液浓度升高是因叶细胞吸收了溶液中的水，导致溶液体积减小、浓度增大，A 正确。
2. B 项：若乙糖溶液浓度不变，水分进出平衡，净吸水量为零，B 正确。
3. C 项：若乙糖溶液浓度降低，则乙组细胞失水（水进入溶液），肉细胞失水可发生质壁分离，C 正确。
4. D 项：若乙糖溶液浓度升高，说明乙组细胞也吸水。但两组细胞吸水量的多少取决于各自细胞内外浓度差及平衡状态，无法由单一浓度变化直接推出乙组净吸水量大于甲组，D 错误。

点评/变式
- 本题易错点为 D，核心是理解吸水量的比较必须依赖渗透压差值的变化量，而非仅凭是否吸水。
- 变式思考：若将“质量浓度相同”改为“物质的量浓度相同”，则甲、乙初始渗透压相同，此时若甲糖溶液浓度升高而乙不变或降低，则可更清晰地判断渗透关系，解题思路应转换到膜对溶质的选择性透过上。
