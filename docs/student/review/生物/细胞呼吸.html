知识精要

细胞呼吸是细胞内有机物氧化分解、释放能量的过程，是一切活细胞每时每刻都在进行的生命活动。

核心过程 - 有氧呼吸：主要场所为线粒体。分三阶段：第一阶段葡萄糖在细胞质基质中酵解为丙酮酸和少量 $[H]$, 释放少量能量；第二阶段丙酮酸和水在线粒体基质中彻底分解为 $CO_2$ 和大量 $[H]$, 释放少量能量；第三阶段前两阶段产生的 $[H]$ 与 $O_2$ 在线粒体内膜上结合生成 $H_2O$, 释放大量能量。总反应式：$C_6H_{12}O_6 + 6H_2O + 6O_2 \xrightarrow{酶} 6CO_2 + 12H_2O + \text{能量}$。 - 无氧呼吸：全过程在细胞质基质中进行。第一阶段与有氧呼吸相同；第二阶段丙酮酸在不同酶催化下生成酒精和 $CO_2$（如酵母菌、大多数植物）或乳酸（如动物细胞、乳酸菌、马铃薯块茎等），不释放能量。

关键物质与能量变化 - 水：自由水含量影响代谢速率；结合水含量与抗逆性正相关。风干处理降低自由水，使结合水/自由水比值增大，呼吸强度减弱。 - 能量：细胞呼吸释放的能量大部分以热能形式散失，少部分储存在 ATP 中。

重要微生物呼吸类型 - 酵母菌：兼性厌氧型。有氧时进行有氧呼吸，产物为 $CO_2$ 和 $H_2O$；无氧时进行无氧呼吸，产物为酒精和 $CO_2$。 - 醋酸杆菌：好氧型原核生物，无线粒体，利用乙醇在有氧条件下生成醋酸。 - 破伤风芽孢杆菌：严格厌氧型，在有氧环境中代谢受抑制。 - 肺炎双球菌：好氧型原核生物，无线粒体但含有氧呼吸酶，可进行有氧呼吸。

农业生产应用原理 - 低温/低氧/干燥：通过抑制呼吸作用相关酶的活性或降低底物浓度来降低细胞呼吸强度，减少有机物消耗。 - 中耕松土/排涝：增加土壤氧气含量，促进根系有氧呼吸。 - 合理密植/间作套种：主要通过改善通风和光照条件，增大光合作用面积与效率。

解题方法与套路

1. 辨析“细胞呼吸”概念正误的通用步骤 - 第一步：判断生物学事实。确认对象是否为“活细胞”，活细胞必进行呼吸作用（如“叶肉细胞在光下不呼吸”必错）。 - 第二步：定位场所与酶。明确呼吸作用全过程需酶的催化。原核生物无线粒体，但相关酶可能分布在细胞质或细胞膜上，因此它们也能进行有氧呼吸。 - 第三步：区分类别与产物。对有氧呼吸和多种无氧呼吸类型，采用“角色-条件-产物”三步定位法：角色（如酵母菌、动物、植物器官）→ 条件（氧浓度）→ 产物（水、酒精、乳酸或 $CO_2$）。 - 第四步：跨选择题选项排除法。遵循：排除绝对化错误表述→ 排除逻辑矛盾（如“降低消耗”与“维持高强度呼吸”的矛盾）→ 比对事实细节（如微生物需氧/厌氧性）。

2. 分析“生产措施”作用原理的解题模型 - 第一步：拆解核心处理。将措施拆解为处理对象（种子/果实/植株）和核心操作（低温/风干/密植/间作）。 - 第二步：定位主要代谢。区别该操作主要直接影响光合作用还是呼吸作用，或兼而有之。如密植、间作主要影响光能的捕获和气体的交换（光合与呼吸的双重影响）；低温储藏主破的是呼吸消耗。 - 第三步：联动环境因子。将温度、水、氧气与关键代谢过程对应： - $\text{低温} \rightarrow \text{酶活性降} \rightarrow \text{呼吸速率降}$。 - $\text{风干} \rightarrow \text{自由水降} \rightarrow \text{代谢降} + \text{微生物抑制}$。 - $\text{淹水} \rightarrow \text{氧气降} \rightarrow \text{无氧呼吸增强/有氧呼吸被抑}$。

3. 图表/实验数据分析的“三步定位法” - 第一步：识坐标、明变量。从题干的干重-时间图中，区分“总干重”（如种子+胚乳）和“部分干重”（如仅胚乳）代表的意义。 - 第二步：计算变化值。总干重下降量=呼吸消耗量。通过计算单位时间干重下降的最大值定位呼吸速率最大的时段。 - 第三步：关联生物学原理。将数据拐点与萌发过程生理变化关联。如种子萌发初期，胚乳干重下降速率加快对应呼吸速率上升。

高频易错

  • 陷阱1：光合与呼吸的存在性混淆。误认为绿色植物在光照下只进行光合作用不进行呼吸作用。所有活细胞不论光照与否，生命全程都在进行细胞呼吸。
  • 陷阱2：原核生物呼吸场所的误判。认为“无线粒体就不能进行有氧呼吸”。肺炎双球菌、醋酸杆菌等好氧型原核生物，虽没有线粒体，但细胞质和细胞膜上含有与有氧呼吸相关的酶，能进行有氧呼吸。
  • 陷阱3：厌氧菌对氧气的耐受误判。将厌氧菌理解为“在无氧下生活”，而忽视其在有氧条件下代谢会受抑制甚至死亡。破伤风芽孢杆菌在有氧环境中生存受阻，是伤口包扎需透气的理论基础。
  • 陷阱4：细胞呼吸产物与对应菌群错配。混淆不同生物的无氧呼吸产物。需牢记特例：动物细胞、乳酸菌的产物仅为乳酸；酵母菌、大多数植物为酒精和二氧化碳。
  • 陷阱5：单一思维分析复杂农业措施。错误地将所有措施都归因于降低呼吸作用。应明确：低温储藏旨在降呼吸；风干既降自身呼吸又防微生物滋生；合理密植和间作主要是为了提高光能利用率；春化、光周期处理主要调节的是生长发育和开花，并非直接以呼吸作用或光合作用为主要目的。

代表题精讲

代表题一：2023-新课标-02

  • 题目：关于生产、生活中多种措施及目的的组合判断选择题。
  • 思路：应用“解题模型2”，对6项措施逐一进行主次功能解析。①低温贮藏→降呼吸；②春化处理→促发育开花；③风干贮藏→降呼吸与抑菌；④光周期处理→控开花时间；⑤合理密植→增光合效率；⑥间作种植→增光合效率。解题核心是区分措施的直接主要目标与附带影响。
  • 步骤：
    1. 归类分析：将措施分为两类储备。呼吸调节类：①③。发育/光合调节类：②④⑤⑥。
    2. 逐项验证：
      • A选项：②利用低温促花，④利用昼夜长短控花，均与“开花”相关，表述无误。
      • B/D选项：均将⑤⑥等归于降呼吸/促光合，正确判断需准确定性⑤⑥的核心目的并非降呼吸，而是提高光能利用率及光合作用强度。
      • C选项：⑤⑥目的定性为促进光合作用，合理。但②目的是促发育，并非光合作用。该选项因混杂了②而错误。
    3. 结论：A选项准确关联了措施与生物学现象的根本关系。
  • 点评/变式：本题的特点是选项为多措施组合判断，需要考生剥离措施的单一核心功能。务必明确：措施的主要目的直接影响判断。易错点是习惯将所有为“节约有机物”的措施都归因于呼吸作用。变式训练可关注：储藏种子/果实采用“低氧”而非“无氧”的原因，无氧会增强无氧呼吸产生酒精导致霉烂。

代表题二：2018-新课标Ⅱ-04

  • 题目：判断关于种子风干处理前后的各项描述中哪一项是错误的。
  • 思路：运用“知识精要”中水与代谢的关系。风干=种子失去大量自由水→代谢强度大幅度下降→呼吸作用减弱、有机物消耗减慢、微生物不易繁殖；同时结合水/自由水比值增大。
  • 步骤：
    1. 定核心推论：降低自由水含量 → 细胞呼吸强度降低。
    2. 选项扫描：A项“消耗减慢”、B项“不易生长”、D项“比值大”均与“代谢减弱”的逻辑完全吻合。
    3. 定位矛盾：C项“风干种子中细胞呼吸作用的强度高”，与核心推论直接抵触。风干使代谢减弱，呼吸强度必然降低而非升高。
  • 点评/变式：本题考点极其集中，唯一切入点就是自由水含量。错误选项故意设计为与常识相反的描述，以考察对“自由水/结合水比值决定代谢强度”这一原理的绝对掌握。变式可延伸到“种子萌发”与“干燥储藏”互为逆过程，萌发时呼吸强度最初上升的基础正是自由水含量增加。

代表题三：2016-新课标Ⅱ-11

  • 题目：填空题，依托苹果醋生产工艺，考察酵母菌呼吸代谢的场所、产物、检测及醋酸杆菌的发酵条件。
  • 思路：运用“解题模型1”之“角色-条件-产物”分析流程。酵母菌有氧呼吸产能多，增殖快；无氧呼吸产酒精，场所为细胞质基质，可用酸性重铬酸钾检测。醋酸杆菌是好氧菌，产物醋酸生成需有氧，最适温度高于酵母菌酒精发酵。
  • 步骤：
    1. 第一阶段——酵母菌：图中所示①为无氧呼吸第二阶段，产物乙醇（用重铬酸钾检测呈灰绿色），全程在细胞质基质进行。过程③是有氧呼吸，在线粒体进行。因有氧呼吸产能多，故有氧条件下酵母菌增殖更快。
    2. 第二阶段——醋酸杆菌：乙醇变醋酸需醋酸杆菌，其属好氧型，因此需有氧条件。醋酸杆菌为原核生物，不含线粒体。酒精发酵的最适温度（约18-25℃）通常低于醋酸发酵（约30-35℃）。
    3. 知识整合：模板化记忆“菌名-真/原核-呼吸方式-核心产物-发酵条件”。
  • 点评/变式：本题高度综合，将代谢类型、真原核细胞结构、发酵工程细节串联。此类题型的陷阱常在于混淆同一生物在不同条件下的产物（例：酵母菌有氧无氧产物的差异），或混淆不同工程菌的呼吸方式与工艺条件。变式可联系传统果酒制作中“先通气后密封”的原理。
