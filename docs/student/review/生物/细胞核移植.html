细胞核移植

考点细胞核移植权重7真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：7
  • 真题数：1；年份跨度：2018–2018
  • 出现题位：填空12
  • 难度分布：中1

知识精要

  • 细胞核移植：将供体细胞的细胞核移入受体去核卵母细胞，构建重组细胞，经激活和胚胎培养后获得完整个体的技术。其原理是动物体细胞的细胞核具有全能性，去核卵母细胞的细胞质能重编程供体核。
  • 关键操作：
  • 受体细胞：去核的减数第二次分裂中期卵母细胞（去除染色体的中期Ⅱ卵母细胞），具有促进核全能性表达的物质。
  • 供核细胞：已导入目的基因的体细胞（如本题中可产生绿色荧光的皮肤细胞）或其他供体细胞。
  • 基本流程：供体细胞培养 → 受体卵母细胞去核 → 显微注射/电融合将细胞核移入去核卵母细胞 → 激活重组细胞 → 体外培养至早期胚胎 → 胚胎移植入代孕母体子宫。
  • 应用：克隆动物（如获得含有融合基因的转基因克隆牛）；加速良种繁育；生产药用蛋白等。本题中通过核移植获得含 GFP 融合基因的克隆牛，实现目的基因在各种组织中的稳定表达。

解题方法与套路

  1. 识别核移植语境：题干中出现“将…细胞的移入牛的中”“获得含有…的克隆个体”“体外培养、胚胎移植”等描述，往往要求填写“细胞核”和“去核卵母细胞”。
  2. 填词策略：
  3. 若前文描述的是“能产生绿色荧光（或其他标记）的细胞”，则移入的应为该细胞的细胞核（而非整个细胞或荧光蛋白）。
  4. 受体空位应填去核卵母细胞，不能遗漏“去核”二字，避免写作“卵细胞”“受精卵”或“未去核卵母细胞”。
  5. 联系过程完整性：核移植后通常需体外培养获得早期胚胎，再进行胚胎移植，这一流程常与基因工程串联考查，填空时注意上下文呼应。
  6. 基因工程结合核移植：当目的基因先导入体细胞，再通过核移植产生克隆动物时，鉴定目的基因应取核 DNA为模板，因为基因整合在染色体上，随细胞核传递。

高频易错

  • 受体细胞的错误填写：写成“去核的卵细胞”“去核受精卵”或漏写“去核”仅写“卵母细胞”。实际上必须是“去核卵母细胞”（常用减数第二次分裂中期的卵母细胞）。
  • 混淆核移植与胚胎分割：胚胎分割是分割同一个早期胚胎获得同卵多胎，不涉及去核操作；核移植依赖供体细胞核，重编程发育，切勿混用术语。
  • 未理解核的全能性：误将绿色荧光细胞的“荧光蛋白”“mRNA”等填入移入物空位，忽视性状由细胞核基因控制，移入必须为细胞核。
  • PCR 鉴定时模板选择错误：检测目的基因是否在组织中存在，应使用核 DNA（全基因组）而非 mRNA（检测表达）或总蛋白，因为核 DNA 可显示基因整合，且不易降解。

代表题精讲

题目
2018 年新课标Ⅱ卷第 12 题以 GFP 融合基因为切入点，构建真核表达载体 P1，导入牛皮肤细胞并筛选出可产生绿色荧光的细胞。欲获得含融合基因甲的克隆牛，需将此类细胞的__移入牛的____中，经体外培养、胚胎移植等。同时要求回答限制酶选择、表达过程、PCR 鉴定模板等问题。

思路
先从基因工程部分确认载体构建和表达检测，再迁移到动物克隆技术。第（3）问抓住“克隆牛”和“将…细胞的…移入…”判断为体细胞核移植，结合克隆动物的核心操作即可作答；第（4）问从检测基因存在角度选择最稳定的核 DNA。

步骤
（1）据图分析，要使融合基因甲完整插入载体并保证方向正确，须用两种黏性末端不同的限制酶 E1 和 E4 切割，从而保证甲的完整性与正确连接。
（2）在皮肤细胞中观察到绿色荧光，表明 L1 基因已正常进行转录和翻译（表达为融合蛋白）。
（3）核移植：将能产生绿色荧光的细胞的细胞核移入牛的去核卵母细胞中，重组细胞经激活和培养形成早期胚胎，再进行胚胎移植，即可获得含甲的克隆牛。
（4）检测甲是否存在于各组织细胞，应取该牛不同组织细胞中的核 DNA 为模板进行 PCR，因为融合基因整合在染色体 DNA 上，随细胞分裂稳定传递。

点评/变式
本题综合基因工程与核移植，易错点集中在“去核”二字的遗漏和 PCR 模板的选择。变式可变化标记基因，或将核移植受体换为去核的受精卵（错误选项），需牢记克隆动物的受体必定是去核卵母细胞。理解核移植实质：供体核提供全套遗传信息，受体卵母细胞质提供重编程环境，由此可实现体细胞克隆。
