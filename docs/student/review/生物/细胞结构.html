总览数学物理化学生物

细胞结构

考点细胞结构权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 内质网：真核细胞内由膜围成的管状、泡状或扁平囊状结构，是细胞内脂质合成的主要场所，同时参与分泌蛋白的加工、运输。
  • 细胞核：遗传信息库，细胞代谢和遗传的控制中心；主要进行DNA 复制和转录合成 RNA。
  • 蛋白质合成场所是核糖体，不是内质网，也不是细胞核（线粒体和叶绿体含核糖体可合成部分蛋白质，但本题不涉及）。
  • 知识点网络：内质网 → 脂质；细胞核 → RNA（转录）；核糖体 → 蛋白质；线粒体/叶绿体 → 少量 DNA 和 RNA 等。

解题方法与套路

  1. 逐一对应法：根据选项中的物质，快速提取合该物质的主要细胞结构。
  2. 脂质 → 内质网；
  3. 蛋白质 → 核糖体；
  4. RNA → 转录主要在细胞核，线粒体、叶绿体也有，但考题常指细胞核；
  5. DNA → 复制主要在细胞核，线粒体、叶绿体也有。
  6. 排除干扰项：优先排除绝对错误项（如“内质网合成蛋白质”“蛋白质在细胞核合成”等），再比较细微差异。
  7. 审清问题限定：“内质网和细胞核中能够合成的物质”指分别合成，注意不要混淆各结构的主导功能，不考虑少数例外（如内质网上附着的核糖体合成的蛋白质算作核糖体功能，不算内质网合成）。

高频易错

  • “内质网合成蛋白质”：蛋白质由核糖体合成，内质网参与加工和运输，容易记混。
  • “细胞核内合成蛋白质”：真核细胞核内无核糖体，不能合成蛋白质。
  • “RNA 只能由细胞核合成”：线粒体、叶绿体中也可转录，但题目未涉及时可视为细胞核，不可无限制扩大。
  • 选项包含并列情况：题目要求“内质网”和“细胞核”都能合成，如果其中一个不符合，整个选项错误，不能只看一半。

代表题精讲

题目（2019·新课标Ⅱ·1）：在真核细胞的内质网和细胞核中能够合成的物质分别是（ ）
A. 脂质、RNA B. 氨基酸、蛋白质 C. RNA、DNA D. DNA、蛋白质

  • 思路：分别回忆内质网和细胞核的主导合成功能，逐项验证。
  • 步骤：
  • 内质网：主要合成脂质，也是蛋白质加工的场所，但不直接合成蛋白质；因此若选项说内质网合成RNA、DNA、氨基酸或蛋白质，可直接排除。
  • 细胞核：DNA复制和RNA转录的场所，所以能合成DNA和RNA；但常见考题强调细胞核转录合成RNA。
  • 对照选项：A项“脂质”对“RNA”，与实际吻合；B项“氨基酸”不是内质网合成，“蛋白质”细胞核不合成；C项“RNA”内质网不合成；D项“DNA”内质网不合成，“蛋白质”细胞核不合成。故选A。
  • 点评：本题属于典型“场所—产物”对应题，难度低，重在熟练掌握各细胞结构的核心功能。
    变式：若改为“内质网和高尔基体中都能进行的生理活动”，可考查加工蛋白质等功能；若问“细胞核中不能发生的”，可能考查蛋白质合成。
