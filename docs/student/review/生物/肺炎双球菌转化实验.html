肺炎双球菌转化实验

考点肺炎双球菌转化实验权重8真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：8
  • 真题数：1；年份跨度：2013–2013
  • 出现题位：选择5
  • 难度分布：易1

知识精要

  • 核心问题：探究生物的遗传物质究竟是蛋白质还是DNA。
  • 肺炎双球菌类型：
    • S型（光滑型）：有多糖类荚膜，有毒性，菌落表面光滑。
    • R型（粗糙型）：无荚膜，无毒性，菌落表面粗糙。
  • 格里菲斯体内转化实验：
    • 过程：
      1. 注射R型活菌 → 小鼠存活；
      2. 注射S型活菌 → 小鼠死亡；
      3. 注射加热杀死的S型菌 → 小鼠存活；
      4. 注射R型活菌 + 加热杀死的S型菌 → 小鼠死亡，分离出活的S型菌。
    • 结论：加热杀死的S型菌中存在“转化因子”，能使R型菌转化为S型菌。该实验未证明遗传物质是DNA。
  • 艾弗里体外转化实验：
    • 设计思路：设法将S型菌的各组分（DNA、蛋白质、多糖等）分开，单独、直接地研究它们的作用。
    • 过程：分别用DNA酶、蛋白酶、RNA酶处理S型菌的细胞提取物，再与R型菌混合培养。
    • 结果与结论：只有用DNA酶处理后，R型菌不能转化为S型菌。证明了DNA才是使R型菌产生稳定遗传变化的物质（即DNA是遗传物质）。
  • 关键关联实验：T2噬菌体侵染大肠杆菌实验（共同结论：DNA是遗传物质）。
  • 非遗传物质证明实验：孟德尔杂交实验（提出遗传规律）、摩尔根果蝇实验（证实基因在染色体上）、DNA的X光衍射实验（为DNA双螺旋结构模型提供依据）。

解题方法与套路

  1. 区分“现象/结论”与“本质证明”：
  2. 遇到设问为“证明DNA是遗传物质的实验”，直接锁定肺炎双球菌转化实验（艾弗里）和T2噬菌体侵染实验。格里菲斯实验只是发现转化现象，未证明转化因子本质。
  3. 排除已知的“假说/假说验证”实验：
  4. 孟德尔、摩尔根的实验分别揭示了遗传的基本规律和基因的位置关系，均在DNA被确认为遗传物质之前或独立进行，不直接涉及遗传物质化学本质的鉴定。
  5. 排除结构解析类实验：
  6. DNA的X光衍射实验和DNA双螺旋模型的构建，揭示了DNA的空间结构，而非证明其是遗传物质。
  7. 三字经口诀辅助判断：
  8. “肺（废）炎，噬菌（亲），DNA是核心”：看到题目问证明DNA是遗传物质，圈定这两类实验。

高频易错

  • 混淆格里菲斯与艾弗里的结论：错误选项常把“格里菲斯证明DNA是遗传物质”混入。务必记清，格里菲斯只提出了“转化因子”的假说，艾弗里通过体外转化实验才真正完成化学本质的证明。
  • 过度解读“转化因子”：加热杀死的S型菌让R型菌转化的本质是基因重组，但此考点常设陷阱，误认为该实验直接分离出了DNA。
  • 混淆实验目的：将“证明DNA是遗传物质”与“发现基因规律/基因位置/推导双螺旋结构”的实验混为一谈。

代表题精讲

题目（2013·新课标Ⅱ·05）： 判断哪些实验直接证明了DNA是遗传物质。选项涉及：①孟德尔杂交实验；②摩尔根果蝇杂交实验；③肺炎双球菌转化实验；④ T2噬菌体侵染实验；⑤ DNA的X光衍射实验。

思路： 本题为典型的实验目的匹配题。解题核心在于严格区分各经典遗传学实验的历史贡献，直接锁定以分离提纯化学成分并各自验证功能为思路的实验。

步骤： 1. 选项筛选：逐一审视每个实验的核心价值。 - ① 孟德尔：提出遗传因子假说和两大定律。不直接证明DNA为遗传物质。 - ② 摩尔根：利用果蝇眼色伴性遗传，证明基因在染色体上。不直接证明物质为DNA。 - ③ 肺炎双球菌转化实验（特指艾弗里完整实验）：分离蛋白质和DNA，证明DNA是遗传物质。符合题意。 - ④ T2噬菌体侵染实验：利用同位素标记，直接证明DNA进入细菌并指导蛋白质外壳的合成，DNA是遗传物质。符合题意。 - ⑤ DNA的X光衍射实验：提供了DNA结构的物理参数，推动了结构解析。不符题意。 2. 结论判定：③和④正确，即选项C为正确答案。

点评/变式 - 点评：本题零难度，丢分极可能是混淆了艾弗里实验的结论或记忆了格里菲斯实验的错误表述。此类题目的核心解题资产就是一张“经典实验贡献清单”。 - 变式：若题目改为“为DNA双螺旋结构模型构建提供依据的实验”，答案则应选⑤；若改为“证明基因在染色体上的实验”，则应选②。务必形成条件反射。
