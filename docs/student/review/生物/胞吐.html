总览数学物理化学生物

胞吐

考点胞吐权重12真题数2学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：12
  • 真题数：2；年份跨度：2015–2016
  • 出现题位：选择3 选择8
  • 难度分布：中1 易1

知识精要

  • 胞吐（胞吐作用）：细胞内大分子物质（如蛋白质、多肽、神经递质等）被包裹在囊泡中，囊泡移向细胞膜并与之融合，将内容物释放到细胞外的过程。属于主动运输，需消耗细胞代谢产生的能量（ATP），依赖于细胞膜的流动性。
  • 结构基础：高尔基体“出芽”形成分泌泡，或突触小体中的突触小泡，通过马达蛋白沿细胞骨架运输，最终囊泡膜与细胞膜融合。
  • 实例：浆细胞分泌抗体；胰腺腺泡细胞分泌消化酶；突触前膜释放神经递质（如乙酰胆碱、多巴胺、去甲肾上腺素等）；内分泌细胞分泌蛋白质类激素。
  • 与胞吞对比：方向相反，均为大分子颗粒或液体跨膜运输方式，都涉及膜的变形与融合，体现了细胞膜的流动性。神经递质中一氧化氮（NO）等气体分子可直接自由扩散，无需胞吐。
  • 不属于胞吐的过程：mRNA通过核孔从细胞核到细胞质，属于核孔复合体介导的主动转运，不涉及膜融合，不属于胞吐。

解题方法与套路

  1. 抓关键特征：判断是否描述为“囊泡与细胞膜融合后释放物质”。凡涉及“分泌到细胞外”“释放到突触间隙”“胞外”等词，且物质是大分子或包裹在囊泡中的神经递质，均为胞吐。
  2. 牢记典型非胞吐实例：mRNA出核（核孔）、脂溶性小分子（如NO、CO₂）直接扩散、离子通道或载体介导的跨膜运输均非胞吐。
  3. 排除法：在选择题中，识别非膜融合的运输方式，如核孔运输、自由扩散、协助扩散、主动运输（载体蛋白），即可快速排除。
  4. 图文结合题：若示意图中出现突触小泡与细胞膜融合，直接判断为胞吐；若问物质循环利用，注意图中箭头回指。
  5. 生理效应推理：神经递质释放后若不能被酶分解，则持续作用于后膜，根据递质类型判断兴奋或抑制。乙酰胆碱为兴奋性递质，失活受阻导致后神经元持续兴奋。

高频易错

  • 误以为所有神经递质都通过胞吐释放：一氧化氮（NO）是气体分子，可自由扩散，不属于胞吐。
  • 将mRNA通过核孔出核误认为胞吐：核孔不涉及膜融合，属于核质转运，不属于胞吐。
  • 混淆“跨膜运输”与“胞吐是否属于跨膜”：胞吐是大分子物质跨过细胞膜的运输方式，属于广义的跨膜运输，但不是通过载体蛋白或直接穿膜。
  • 忽视条件“胞吐需能量”：若题目强调“不消耗ATP”的释放，则不是胞吐。所有胞吐均需ATP。
  • 混淆合成与释放过程：在乙酰胆碱合成图示中，E可能是胆碱被再利用，C是乙酸？题中“能循环利用的物质是C（填‘A’‘C’或‘E’）”，注意区分A-C整体代表乙酰胆碱，C为其中一部分（胆碱），考生易忽视图示标注而错选。
  • 静息与动作电位判断：D酶（乙酰胆碱酯酶）失活后乙酰胆碱不能被水解，持续作用于受体，导致突触后膜持续兴奋（Na⁺内流不断），而非抑制。

代表题精讲

代表题一：2016-新课标Ⅱ-08

题目：图示乙酰胆碱（A-C）合成与释放，回答：（1）能循环利用的物质是（填A、C或E）；除乙酰胆碱外，多巴胺和一氧化氮作为神经递质。（2）兴奋传到神经末梢时，A-C通过方式释放到。（3）若D酶失活，突触后神经元会表现为持续___。

思路：根据合成图找出回收箭头指向的物质为C（胆碱），知晓常见神经递质种类；突触小泡释放递质为胞吐到突触间隙；D酶（乙酰胆碱酯酶）分解递质，失活则递质持续作用，兴奋型递质导致持续兴奋。

步骤： 1. 读图：E进入合成A-C，释放后降解成A和C，C被重新摄入，故循环利用的是C。 2. 背记：多巴胺是单胺类递质（胞吐），一氧化氮是气体（自由扩散），但均属于神经递质，故填“能”。 3. 运输方式：神经递质在突触小泡中通过胞吐释放，填“胞吐”；释放到“突触间隙”。 4. D酶失活→乙酰胆碱积累→持续结合受体→突触后膜持续Na⁺内流，表现为持续“兴奋”。

点评/变式：本题综合突触结构与功能、物质循环、胞吐概念。变式可问“若抑制囊泡与膜融合，则递质释放受何影响？”答案应为阻断胞吐，无法释放。

代表题二：2015-新课标Ⅱ-03

题目：下列不属于胞吐作用的是：A.浆细胞分泌抗体；B.mRNA从细胞核到细胞质；C.分泌蛋白从胰腺腺泡细胞到胞外；D.突触小泡释放神经递质。

思路：根据胞吐定义（囊泡与膜融合释放）逐一判断。A、C、D均有分泌泡/突触小泡与细胞膜融合，B是核孔运输，不涉及膜融合。

步骤： 1. A项：抗体是蛋白质，由浆细胞产生后包裹在囊泡中，经胞吐分泌，属于胞吐。 2. B项：mRNA通过核孔复合体出核，无膜融合，不属于胞吐。 3. C项：分泌蛋白如胰蛋白酶等由腺泡细胞粗面内质网→高尔基体→分泌泡→胞吐，属于胞吐。 4. D项：突触小泡内含神经递质，兴奋时与突触前膜融合释放，属于胞吐。 5. 故选B。

点评/变式：常考“不属于胞吐”需熟记特殊实例（如核孔、自由扩散的气体递质）。可能扩展为判断哪些属于胞吞？如白细胞吞噬细菌、变形虫摄食等。牢牢掌握“膜融合包裹”这一核心。
