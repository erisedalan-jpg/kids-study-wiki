能量代谢

考点能量代谢权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2014–2014
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • ATP的合成：光反应中，ADP与磷酸（Pi）在ATP合酶催化下合成ATP，磷酸是必需反应物。
  • 光合色素吸收光能：叶绿素等色素分子捕获光能是物理过程，不消耗酶；酶作用于后续电子传递、水光解及ATP合成。
  • 细胞呼吸与能量供应：生命活动的直接能源是ATP。有氧呼吸、无氧呼吸第一阶段（糖酵解）均能产生ATP。无氧呼吸过程不产生额外ATP，产物（乳酸或酒精）不直接供能。
  • 剧烈运动时的能量代谢：肌肉细胞通过有氧呼吸与无氧呼吸（产生乳酸）补充ATP，乳酸是葡萄糖不完全氧化的终产物，其分解不直接提供运动所需的能量。
  • 病毒的能量来源：病毒没有独立的代谢系统，核酸复制、蛋白质合成等生命活动完全依赖宿主细胞呼吸作用产生的ATP。

解题方法与套路

  1. 逐项排查法：面对“正确/错误”叙述题，将每个选项与所学核心概念做精确比对，警惕偷换概念。
  2. 锁定常考易混点：优先核对“光反应是否需要酶”“无氧呼吸产物是否供能”“病毒是否自主供能”等经典设错角度。
  3. 直接能源ATP原则：一切耗能生命活动所需能量必须由ATP直接提供，任何其他物质（乳酸、葡萄糖、脂肪）均不可绕过ATP直接供能。
  4. 区分“过程”与“结果”：比如，色素吸收光能（物理）≠光化学反应（需酶），无氧呼吸产生ATP（第一阶段）≠乳酸释放能量供肌肉收缩。

高频易错

  • 乳酸供能陷阱：易误认为剧烈运动时，肌肉细胞利用乳酸无氧呼吸继续供能，实际上乳酸是糖酵解终产物，其积累后需经乳酸穿梭或彻底氧化，过程不直接生成ATP，运动时的直接能量仍来自ATP。
  • 光合作用与酶：混淆“吸收光能”与“光反应全过程”，前者无需酶，后者（水光解、ATP合成）必须酶催化。
  • 病毒代谢归属：易忽略病毒专性寄生的特性，误认为病毒在宿主细胞内可利用自身酶系统产生能量，实则所有能量和物质均取自宿主。
  • 磷酸的角色：光反应中ATP来源于ADP和Pi，若未能将“磷酸”与Pi联系，可能错判A选项。

代表题精讲

题目（2014-新课标Ⅱ-06）

题目：关于光合作用和呼吸作用的叙述，错误的是（ ）
A．磷酸是光反应中合成ATP所需的反应物
B．光合作用中叶绿素吸收光能不需要酶的参与
C．人体在剧烈运动时所需要的能量由乳酸分解提供
D．病毒核酸的复制需要宿主细胞的呼吸作用提供能量

思路：本题要求找出错误叙述，需逐项调用光合作用与呼吸作用的关键原理。重点排查：ATP合成原料、色素吸收光能的机制、无氧呼吸与直接能源的关系、病毒能量来源。

步骤： - A项：光反应合成ATP的反应式为 $ADP + Pi \xrightarrow{\text{光、酶}} ATP$，磷酸（Pi）是底物，正确。
- B项：叶绿素的捕光属于色素分子的光物理响应，不经过酶催化；后续电子传递和水的光解则有酶参与，正确。
- C项：人体剧烈运动时ATP消耗剧增，主要由有氧呼吸和糖酵解补充，糖酵解产物乳酸并不直接供能，乳酸需在恢复期氧化或糖异生，其分解无法直接为肌肉收缩提供ATP，该叙述错误，即本题答案。
- D项：病毒无细胞结构，核酸复制等过程须在宿主细胞内完成，依赖宿主呼吸作用提供的ATP，正确。

点评/变式：C项是典型混淆“无氧呼吸产能”与“产物可利用”的陷阱。变式可改为：“人体在剧烈运动时所需能量来自无氧呼吸过程中释放的能量”——同样错误，因无氧呼吸仅在第一步释放少量ATP，后续不产能。复习时牢记“直接能源唯一原则”：任何生命活动有能量需求，立即链接ATP。若题干变更为找出正确叙述，需举一反三关注B、D这类易被忽略但正确的表述。
