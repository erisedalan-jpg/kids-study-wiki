脂肪

考点脂肪权重0真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：0
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择3
  • 难度分布：易1

知识精要

  • 脂肪的组成与功能
  • 组成元素：仅含 $C, H, O$。与糖类相比，脂肪的 $H$ 含量高，$O$ 含量低。
  • 基本单位：甘油和脂肪酸。
  • 主要功能：细胞内良好的储能物质；保温、缓冲和减压，保护内脏器官。
  • 脂肪的检测原理
  • 试剂：苏丹Ⅲ染液或苏丹Ⅳ染液。
  • 条件与现象：制作临时装片用显微镜观察。苏丹Ⅲ将脂肪染成橘黄色，苏丹Ⅳ染成红色。
  • 关键操作要点：需用体积分数为 $50\%$ 的酒精溶液洗去浮色，避免多余的染料干扰对细胞内部脂肪滴的观察。
  • 观察材料的选取原则（由真题提炼的核心考法）
  • 质壁分离观察材料：必须选择活的成熟植物细胞，最好含有易观察的中央大液泡（无色的细胞也可选用，但含色素更佳）。最理想的材料是紫色洋葱鳞片叶外表皮。
  • RNA 分布观察材料：常用人的口腔上皮细胞或动物组织细胞进行涂片，染色剂为吡罗红甲基绿混合染液。
  • 脂肪检测观察材料：优先选择富含脂肪且便于徒手切成薄片的植物种子。最经典的材料是花生子叶（需切片）。

解题方法与套路

  1. 审清叠加实验要求 面对“在特定仪器下同时观察多个对象”的题目，先拆解每个实验目标对材料的独立要求，再寻找能同时满足所有条件的材料组合选项。
  2. 匹配“最佳材料”标准
  3. 涉及“质壁分离”→ 找活的、有大液泡的植物细胞。见到“紫色洋葱”通常是首选。
  4. 涉及“脂肪鉴定”→ 找富含脂肪的植物子叶或种子。见到“花生子叶”通常是首选。
  5. 选项横向比对排除法
  6. 先排除无法用于观察目标结构之一的材料组合。如水稻胚乳主要含淀粉（可鉴定糖类），不适合观察脂肪，可直接排除包含它的选项。
  7. 注意题干陷阱：“普通显微镜下观察 RNA”需用甲基绿吡罗红染色，其操作流程与脂肪鉴定的切片流程完全不同，很难在同一临时装片下同时观察到。需回归题意，识别出题者意图是选一组含实验所需材料的组合，而非要求在同一个材料上完成所有实验。

高频易错

  • 忽视材料化学组成：误认为水稻胚乳富含脂肪。水稻胚乳细胞主要储存淀粉，花生子叶才富含脂肪。
  • 质壁分离材料混淆：错选无大液泡/无色的植物材料或未成熟组织。首选材料必须是液泡带颜色的成熟植物细胞（如紫色洋葱外表皮），便于在普通光学显微镜下直接观察原生质层与细胞壁的分离。
  • 试剂与颜色反应张冠李戴：混淆苏丹Ⅲ与苏丹Ⅳ的显色反应颜色，或误以为用显微镜观察脂肪滴时无需去浮色。不洗去浮色会造成视野背景一片红/黄。
  • 不区分“检测实验”与“染色后观察”：绝大多数的化学试剂检测（如检测还原糖、蛋白质）是不需要显微镜的，只有检测细胞中的脂肪滴和观察线粒体/DNA/RNA/染色体等定位实验才必须用显微镜。

代表题精讲

题目：2010-新课标-03（2010）

若要在普通显微镜下观察到质壁分离、RNA 和脂肪，下列四组材料中应选择的一组是 A. 水稻胚乳和花生子叶 B. 天竺葵叶和水稻胚乳 C. 紫色洋葱和花生子叶 D. 天竺葵叶和紫色洋葱

思路： 该题为典型的“一题多考点”实验材料选择题。题干要求在显微镜下观察三个独立项目：质壁分离、RNA、脂肪。首先需明确这三个实验各自的最佳材料：质壁分离最佳为紫色洋葱外表皮；脂肪最佳为花生子叶；RNA 观察通常是独立制片，本题提供的选项中须有能完成该观察的材料，但考虑到所有选项均为植物组织，且真题解析逻辑认为该组合目的是选出分别能完成实验的材料组合。解题关键在于找出能覆盖前两项必需材料的选项，并排除不合要求的组合。

步骤： 1. 锁定“质壁分离”材料：观察质壁分离必须用活的、有大液泡的植物细胞。选项中，紫色洋葱鳞片叶外表皮细胞是完美的材料。故含有“紫色洋葱”的 C、D 两项进入待选。 2. 锁定“脂肪”材料：检测脂肪需用富含脂肪的植物种子制作切片。花生子叶富含脂肪，是标准材料。选项 C 含有花生子叶，选项 D 无。 3. 排除干扰项：水稻胚乳主要成分为淀粉，不适合鉴定脂肪，排除 A、B。天竺葵叶虽为植物，但其叶肉细胞主要用于光合作用实验或质壁分离观察，作为脂肪鉴定材料不典型。D 项无法完成对脂肪的有效观察。 4. 综合确认：C 项提供了“紫色洋葱”（完成质壁分离观察）和“花生子叶”（完成脂肪检测），且这两类材料经适当处理亦可满足 RNA 分布观察的试验要求（本题语境下理解为覆盖观察目标）。故 C 项成立。

点评/变式： 此类题目需警惕“一组材料”的含义。命题常将不同实验的最佳观察对象进行组合，考生必须死记特定实验与特定材料的固定搭配。变式提问可能改为“在下列材料中可以同时观察到质壁分离和脂肪的是”，若选项中出现“洋葱鳞片叶”，需注意只有外表皮适合观察质壁分离，洋葱内表皮无色且不易直接观察，但可通过染色或层析观察核酸；而观察脂肪，最好选子叶。
