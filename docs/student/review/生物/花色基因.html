花色基因

考点花色基因权重5真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：5
  • 真题数：1；年份跨度：2010–2010
  • 出现题位：选择6
  • 难度分布：中1

知识精要

  • 基因突变：DNA分子中发生碱基对的替换、增添或缺失，从而引起基因结构的改变。突变结果产生新等位基因，根本差异在于基因的碱基序列。
  • DNA组成与多样性：所有个体的基因均由A、T、C、G四种碱基组成，碱基种类不变；DNA的多样性源于碱基的数量与排列顺序千变万化。
  • 真假突变鉴别：确认是否发生基因突变，不能依赖碱基组成（总是A/T/C/G）、细胞DNA总量（一般不变）或RNA含量（反映表达水平），必须直接比较目标基因的DNA序列。
  • 适用条件：适用于推测植株颜色等性状突然变异是否为基因突变导致的遗传物质改变。

解题方法与套路

  1. 锁定核心概念：看到“突变”“推测是否为基因突变”，立刻关联基因突变的定义——碱基序列的改变（替换、增添、缺失）。
  2. 排除“组成/总量”干扰项：明确基因突变不改变碱基种类（都是A、T、C、G），也不改变整个细胞的DNA含量（单个碱基变化微乎其微）。RNA含量受多因素影响，与序列无法直接回答“是否突变”。
  3. 直接命中DNA序列：要检测突变，最终须比较基因的碱基排列顺序（DNA序列）。
  4. 答题口诀：突变异表型，根源查序列；组成和含量，统统不可信。

高频易错

  • 误选A（碱基组成）：认为突变会改变碱基种类，实际上所有DNA均由A、T、C、G四种组成，突变只是排列方式变化。
  • 误选C（DNA含量）：基因突变是基因内部几个碱基的改变，不引起细胞内DNA总量的明显变化；而染色体变异则可能改变DNA含量。
  • 误选D（RNA含量）：RNA含量反映基因表达量，不能直接揭示基因结构是否改变；表型变化可能是表达调节所致，与序列突变不直接划等号。
  • 忽视“确定该推测是否正确”的问法：题目要求验证“花色突变是否由基因突变引起”，必须从本质——基因序列结构入手。

代表题精讲

题目：白花豌豆园中出现一株红花豌豆，推测是花色基因突变导致。为验证推测，应检测和比较红花与白花植株中的（ ）
A．花色基因的碱基组成　　B．花色基因的DNA序列　　C．细胞的DNA含量　　D．细胞的RNA含量

思路：基因突变的本质是DNA序列改变。要证实突变发生，必须找出序列差异。其他选项均不能直接反映序列变化。

步骤： - 步骤①：明确“基因突变”定义——碱基对替换、增添或缺失→基因结构（碱基序列）改变。 - 步骤②：分析各选项本质。A：所有基因碱基组成都是A、T、C、G，不变。C：突变不改变DNA分子总数。D：RNA含量与基因表达水平相关，不能证明序列突变。B：DNA序列直接比较，可发现单个碱基差异。 - 步骤③：确定最佳方案为测序比较，故选B。

点评/变式：本题是典型的“概念辨析+操作选择”模式。变式可改为：如何鉴定某种抗药性细菌是否因基因突变产生？同样思路，必须比较敏感型与抗药型菌株相关基因的碱基序列，而非检测蛋白质或RNA含量。核心一句话：查序列，不查含量与种类。
