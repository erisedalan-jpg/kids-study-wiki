蛋白质合成

考点蛋白质合成权重6真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：6
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择2
  • 难度分布：易1

知识精要

  • 蛋白质合成的核心场所：核糖体（附着在内质网上或游离于细胞质基质中）。
  • 合成过程：
  • 转录：细胞核中，以 DNA 的一条链为模板合成 mRNA（通过碱基互补配对：A–U、T–A、C–G、G–C）。
  • 翻译：核糖体上，mRNA 上的密码子与 tRNA 上的反密码子配对，按 mRNA 的遗传信息将氨基酸连接为多肽链。
  • 分泌蛋白与胞内蛋白的合成途径：
  • 胞内蛋白：游离核糖体合成，直接在细胞质中发挥作用。
  • 分泌蛋白：附着在内质网上的核糖体合成→内质网腔加工→高尔基体进一步修饰、分类、包装→囊泡运输→细胞膜外排。
  • 蛋白质结构与功能多样性：氨基酸的种类、数目、排列顺序及肽链的空间结构决定其功能。抗体、酶、某些激素（如胰岛素）均为蛋白质，执行免疫功能、催化功能、调节功能等。

解题方法与套路

  1. 审清设问归属：看到“合成”“分泌”“核糖体”等词，立即链接蛋白质合成场所、过程；若涉及免疫球蛋白（抗体），想其化学本质是蛋白质，合成与分泌需经核糖体→内质网→高尔基体路径。
  2. 选项正误辨析法：
  3. 若考具体疾病，先判断其机制：自身免疫病是免疫系统攻击自身组织，通常有特定的自身抗体（蛋白质）参与；过敏反应由过敏原引发，不攻击自身；免疫缺陷病是免疫系统功能低下。
  4. 结合蛋白质知识：抗体是浆细胞合成并分泌的蛋白质，需要核糖体、内质网、高尔基体参与。
  5. 概念对比：将易混概念放一起对比，如自身免疫病 vs 过敏反应 vs 免疫缺陷病，抓住“攻击对象是否为自身”这一关键。
  6. 遗传病辨析：凡遗传物质改变引起的疾病，一般与蛋白质合成路径是否异常无关，而是基因缺陷导致某种蛋白质不能正常合成或功能异常（如抗维生素 D 佝偻病是 X 染色体上基因突变导致肾小管对磷吸收障碍）。

高频易错

  • 混淆核糖体的存在形式：认为所有蛋白质都由附着核糖体合成。实际上，胞内蛋白由游离核糖体合成，分泌蛋白、膜蛋白由附着核糖体合成。
  • 误将自身免疫病与过敏反应等同：自身免疫病是攻击自身正常细胞/组织，过敏反应是防御过于强烈但针对非致病抗原（如花粉），目标为非自身。
  • 不清楚疾病类型归属：艾滋病是获得性免疫缺陷综合征（免疫缺陷病），类风湿性关节炎、系统性红斑狼疮为自身免疫病，动物毛屑接触性鼻炎为过敏反应，抗维生素 D 佝偻病为单基因遗传病。
  • 忽略蛋白质合成与疾病的内在联系：抗体本质是蛋白质，自身免疫病发生时，浆细胞合成抗体错误地识别自身蛋白质为抗原，此过程中抗体合成依然遵循蛋白质合成的普遍规律。

代表题精讲

代表题 2020-新课标Ⅱ-02

题目：判断哪一项属于自身免疫病，选项为：A.艾滋病 B.类风湿性关节炎 C.动物毛屑接触性鼻炎 D.抗维生素D佝偻病。

思路：此题表面考疾病分类，深层可联系蛋白质合成。自身免疫病的发生是由于免疫系统产生的抗体（蛋白质）或效应 T 细胞攻击自身组织。抗体的化学本质是免疫球蛋白，其合成途径与分泌蛋白相同。审题时先回忆自身免疫病的定义，再逐项辨析。类风湿性关节炎是由自身抗体攻击关节滑膜引起，属于自身免疫病；艾滋病是 HIV 破坏 T 细胞导致的免疫缺陷；动物毛屑接触性鼻炎是过敏反应；抗维生素 D 佝偻病是遗传病。

步骤： 1. 锁定核心概念：自身免疫病——免疫系统“敌我不分”，将自身物质当作外来异物攻击。 2. 分析 A 项：艾滋病是免疫缺陷病，由 HIV 攻击 T 细胞造成免疫功能丧失，不是攻击自身。 3. 分析 B 项：类风湿性关节炎，体内产生针对关节滑膜自身组织的抗体，导致关节炎症，属于自身免疫病，正确。 4. 分析 C 项：动物毛屑接触性鼻炎，是对外界毛屑（过敏原）产生的过敏反应，不是针对自身。 5. 分析 D 项：抗维生素 D 佝偻病，是 X 染色体显性基因缺陷导致肾小管对磷的重吸收障碍，属遗传病，与免疫无关。 6. 确认 B 正确。

点评/变式：本题可从蛋白质功能角度深化理解：类风湿性关节炎的自身抗体属于蛋白质，其合成场所是核糖体，加工运输依赖内质网和高尔基体。若变式设问“上述疾病中有几种患者体内会产生针对自身组织蛋白的抗体”，则应选自身免疫病。注意抗体产生是体液免疫的一部分，所有抗体合成均为核糖体翻译、内质网高尔基体加工这一经典途径。复习时可将自身免疫病与蛋白质合成、分泌路径结合，形成知识网络。
