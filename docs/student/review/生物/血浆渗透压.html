血浆渗透压

考点血浆渗透压权重6真题数2学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：6
  • 真题数：2；年份跨度：2012–2019
  • 出现题位：选择3 选择4
  • 难度分布：易2

知识精要

  • 血浆渗透压：主要由无机盐（尤其$Na^+$、$Cl^-$）和蛋白质（血浆蛋白）维持。渗透压升高时，细胞内液外流，细胞皱缩。
  • 感受器与调节中枢：下丘脑渗透压感受器感受细胞外液渗透压变化，将信号传至下丘脑（调节中枢），进而控制垂体释放抗利尿激素（ADH）。
  • 抗利尿激素（ADH）：由下丘脑视上核和室旁核合成，经垂体后叶释放。作用：促进肾小管和集合管对水的重吸收，使尿液浓缩、尿量减少。
  • 水平衡调节路径： 饮水不足/失水过多/食物过咸 → 细胞外液渗透压升高 → 下丘脑渗透压感受器兴奋 → 下丘脑合成、垂体释放 ADH 增加 → 肾小管、集合管重吸收水增加 → 尿量减少。 同时大脑皮层产生渴觉，主动饮水。
  • 适用条件：哺乳动物/人体脱水、失水时，渗透压升高引发的系列调节；反之，饮水过多，ADH减少，尿量增多。

解题方法与套路

  1. 锁定自变量：明确题干是“失水过多”“脱水”还是“饮水过多”，判断渗透压是升高还是降低。
  2. 梳理调节链：从渗透压变化→感受器→ADH→肾小管/集合管→尿量，按序推导每个环节的变化方向。
  3. 排除干扰项：注意 “不会发生”“正确”“错误” 等关键词。失水时 “血浆渗透压降低” 或 “ADH 分泌减少” 等反向叙述为直接排除项。
  4. 抓准感受器与刺激的关系：渗透压升高 ⇒ 感受器刺激增强；渗透压降低 ⇒ 刺激减弱。
  5. 关联排尿量：ADH 多则水重吸收多 → 尿少且浓缩；ADH 少则尿多而稀。

高频易错

  • 混淆渗透压变化方向：脱水 / 失水时，血浆渗透压必升高，非降低。
  • 错误关联感受器刺激：渗透压升高，感受器兴奋增强而非减弱。
  • 误判抗利尿激素来源：ADH 由下丘脑合成、垂体后叶释放，并非垂体直接合成。
  • 忽略负反馈细节：补充水分后渗透压回降，ADH 分泌减少，易错选为 ADH 持续升高。
  • 漏看题干否定词：“不会发生”“错误的是”，直接导致选反。

代表题精讲

题目（2019·新课标Ⅱ·4）

当人体失水过多时，不会发生的生理变化是
A．血浆渗透压升高 B．肾小管对水的重吸收增强 C．抗利尿激素分泌增多 D．尿量明显增加

思路：先确定失水过多时渗透压升高，再推导后续调节方向，最后找出与之矛盾的选项。
步骤：
- 失水过多 → 细胞外液渗透压升高，A 会发生。
- 渗透压升高 → ADH 分泌增多，C 会发生。
- ADH 增多 → 肾小管和集合管对水重吸收增强 → 尿量减少，故 B 会发生，D 不会发生。
点评/变式：D 项尿量增加是典型反向干扰。变式可改为饮水过多场景，此时血浆渗透压降低、ADH 减少、尿量增加，思路对称。

题目（2012·新课标·3）

哺乳动物因长时间未饮水导致机体脱水时，会发生的生理现象是
A．血浆渗透压降低 B．抗利尿激素分泌增加 C．下丘脑渗透压感受器受到的刺激减弱 D．肾小管和集合管对水的重吸收作用减弱

思路：脱水等同于失水，渗透压升高，沿着 “升高-刺激增强-ADH 增加-重吸收增强” 主线选择。
步骤：
- 脱水 → 细胞外液渗透压升高，A 错。
- 渗透压升高 → 下丘脑渗透压感受器兴奋增强，C 错。
- 兴奋增强 → ADH 分泌增加，B 正确。
- ADH 增加 → 肾小管、集合管对水重吸收增强，D 错。
点评/变式：几乎所有选项都与标准调节链的某一环节反向设置，只需严格按“升高→增强→增加→增强”推导即可。若题干改为“大量饮水后”，调节链完全反转，正确选项应为 ADH 减少、重吸收减弱等。
