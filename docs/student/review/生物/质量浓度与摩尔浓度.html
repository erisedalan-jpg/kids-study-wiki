质量浓度与摩尔浓度

考点质量浓度与摩尔浓度权重6真题数1学科生物父主题实验

考点定位

  • 父主题：实验
  • 权重 weight：6
  • 真题数：1；年份跨度：2020–2020
  • 出现题位：选择5
  • 难度分布：中1

知识精要

  • 质量浓度：单位体积溶液中所含溶质的质量，常用单位 $\text{g/mL}$ 或 $\text{g/L}$。
  • 摩尔浓度（物质的量浓度）：单位体积溶液中所含溶质的物质的量，单位 $\text{mol/L}$。
    与质量浓度的换算关系：$c = \frac{\rho}{M}$，其中 $c$ 为摩尔浓度，$\rho$ 为质量浓度，$M$ 为溶质的摩尔质量（相对分子质量的数值）。
  • 渗透压：决定水分跨半透膜净移动方向的是溶液的渗透浓度，即溶质质点的总浓度。对于非电解质稀溶液，渗透压取决于摩尔浓度（实际为渗透浓度）。质量浓度相同的不同溶质，摩尔浓度与摩尔质量成反比。
  • 植物细胞渗透吸水/失水：
  • 当细胞液渗透压 > 外界溶液渗透压时，细胞吸水（表现为溶液浓度升高）；反之细胞失水，发生质壁分离。
  • 水分净移动量为零时，外界溶液浓度不变，细胞液与外界溶液等渗。

解题方法与套路

  1. 识别浓度类型：题干给出的“浓度”单位是 $\text{g/mL}$ 等质量浓度形式，不可直接用于比较渗透压。
  2. 统一到渗透相关量：将质量浓度转换为摩尔浓度（或比较渗透压大小），用公式 $c = \rho / M$，由相对分子质量推断摩尔浓度高低。质量浓度相等时，相对分子质量越大，摩尔浓度越小，渗透压越低。
  3. 根据溶液浓度变化推断水移动方向：
  4. 溶液浓度升高 → 水从溶液进入细胞（细胞吸水）；
  5. 溶液浓度不变 → 水净移动为零；
  6. 溶液浓度降低 → 水从细胞进入溶液（细胞失水，可能出现质壁分离）。
  7. 选项逐项排查：紧扣“质量浓度”“摩尔浓度”差异及水移动方向，排除概念混淆带来的错误选项。

高频易错

  • 直接以为“浓度相同”渗透压就相同：题干常以质量浓度相等作为初始条件，但渗透相关的是摩尔浓度（或渗透浓度），忽略摩尔质量差异必错。
  • 混淆溶液浓度升高与降低的方向：溶液浓度升高意味着溶剂减少，而非溶质增多（题干强调无溶质交换），方向判断反向会导致整个推理错误。
  • 在比较吸水量时忽略渗透压差：当两组细胞都吸水时，初始摩尔浓度较低的一侧外界溶液与细胞液的渗透压差更大，单位时间内净吸水量更大，不能因为都吸水就默认吸水量相同或反了。

代表题精讲

题目：2020·新课标Ⅱ·05（6分）取某植物成熟叶片，用打孔器获取叶圆片，等分成两份，分别放入浓度（单位为 $\text{g/mL}$）相同的甲糖溶液和乙糖溶液中，得到甲、乙两个实验组（甲糖的相对分子质量约为乙糖的2倍）。水分交换达到平衡时，检测甲、乙两组的溶液浓度，发现甲组中甲糖溶液浓度升高。在此期间叶细胞和溶液之间没有溶质交换。据此判断下列说法错误的是（　）
选项略。

思路
- 初始质量浓度相等，甲糖相对分子质量是乙糖的2倍，则甲糖溶液的摩尔浓度 $c_{\text{甲}} = \frac{\rho}{M_{\text{甲}}}$，乙糖 $c_{\text{乙}} = \frac{\rho}{M_{\text{乙}}}$，因 $M_{\text{甲}} \approx 2M_{\text{乙}}$，所以 $c_{\text{甲}} \approx \frac{1}{2}c_{\text{乙}}$。渗透压甲 < 乙。
- 甲组溶液浓度升高 → 溶液变浓，水减少 → 水从甲糖溶液进入叶细胞，说明细胞液渗透压 > 甲糖溶液渗透压。
- 由此推导乙组各种可能情况下的水分移动，并判断哪个选项错误。

步骤
1. 换算摩尔浓度并比较渗透压：甲糖摩尔浓度低，乙糖摩尔浓度高；渗透压 $\Pi_{\text{甲}}<\Pi_{\text{乙}}$。
2. 根据甲组现象建立不等式：细胞液渗透压 > 甲糖溶液渗透压，记为 $\Pi_{\text{细胞}} > \Pi_{\text{甲}}$。
3. 对选项A判断：甲组叶细胞吸水使甲糖溶液浓度升高——符合推导，A正确。
4. 选项B判断：若乙糖溶液浓度不变，则净吸水量为零，说明细胞液与乙糖溶液等渗（$\Pi_{\text{细胞}} = \Pi_{\text{乙}}$）。由 $\Pi_{\text{细胞}} > \Pi_{\text{甲}}$ 和 $\Pi_{\text{甲}}<\Pi_{\text{乙}}$ 该情况可能成立，B正确。
5. 选项C判断：若乙糖溶液浓度降低，说明水从细胞进入乙糖溶液（细胞失水），可能发生质壁分离——符合推理，C正确。
6. 选项D判断：若乙糖溶液浓度升高，说明乙组叶细胞吸水。此时甲、乙均吸水，但甲糖溶液渗透压更低，与细胞液的浓度差更大，推动力更强，在同等条件下甲组吸水量应更大，所以“乙组大于甲组”错误，选D。

点评/变式
- 本题核心陷阱：用质量浓度相等“伪装”成等渗，实则渗透压由摩尔浓度决定。
- 变式训练：若将溶液改为相同摩尔浓度，但溶质相对分子质量不同，则渗透压相等，水移动仅取决于细胞液与外界溶液摩尔浓度差。若再改变条件允许溶质交换，则需进一步分析溶质跨膜运输对渗透压的动态影响。
