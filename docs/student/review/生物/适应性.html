知识精要

  • 适应性：指生物的形态结构、生理功能、行为方式等与环境条件相适合的现象，是长期自然选择的结果。
  • 实质：环境通过选择保存有利变异，种群基因频率定向改变，形成适应的性状。
  • 常见层次：
  • 形态结构适应：如仙人掌叶退化成刺减少蒸腾。
  • 生理功能适应：如高原动物血红蛋白浓度较高以提高运氧能力。
  • 行为适应：如鸟类的迁徙、动物的冬眠。
  • 本题涉及的适应机制：
  • 自变量（水温升高）→ 因变量（水中溶氧量下降）→ 动物体通过 增加血红蛋白含量 弥补氧供应不足，表现为上升趋势曲线。
  • 这属于 生理补偿性适应，维持内环境稳态。

解题方法与套路

  1. 明确双变量关系：先分清题目中给的直接变量（水温）和间接后果（溶氧下降），再结合生物体生理响应，确定最终观察指标（血红蛋白含量）的变化方向。
  2. 抓“适应”的关键指向：遇到“一定温度范围内某动物血液中血红蛋白含量随水温变化”，立刻联想 环境氧含量下降→生物需增强摄氧/运氧能力→血红蛋白升高 这一补偿逻辑。
  3. 排除迷惑选项：若曲线先升后降或先降后平，需判断是否超出生物适应范围。在题目所述的适宜温度范围内，适应性调节一般呈单调变化。
  4. 图像定位：识别横纵坐标，看清多条曲线趋势（甲上升、乙先升后降、丙下降、丁不变），结合原理锁定正确答案。

高频易错

  • 误解适应方向：以为水温升高使代谢加快导致血红蛋白消耗增多而含量下降，误选下降曲线。实际动物会主动合成更多血红蛋白以应对低氧，含量应上升。
  • 忽视“溶氧随水温升高而下降”的隐含条件：未将水温→溶氧→机体适应串成因果链，仅看水温一个变量而错选。
  • 混淆长期进化适应与短期生理调节：本题为生理调节层面的快速适应，但仍体现生物对环境的适应能力，易误以为适应性只能由遗传变异体现。
  • 未注意坐标原点和趋势：以为血红蛋白含量是从零开始急剧上升，实际有基础值，缓慢上升属于正常适应曲线，避免误判。

代表题精讲

2010 新课标-04

题目：水中氧含量随水温升高而下降。生活在寒温带湖泊中的某动物，其血液血红蛋白含量与其生活的水温有关。下图（甲乙丙丁四条曲线：甲逐渐上升，乙先升后降，丙逐渐下降，丁保持不变）中能正确表示一定温度范围内该动物血红蛋白含量随水温变化趋势的曲线是（　　）
A．甲　B．乙　C．丙　D．丁

思路：搭建因果链——水温↑ → 水中溶氧↓ → 动物摄氧困难 → 机体适应反应：合成更多血红蛋白以增强氧的运输能力。因此血红蛋白含量应随水温升高而 逐渐增加。观察四条曲线，只有甲符合上升趋势。

步骤： 1. 解析题干给定信息：水温越高，水中氧含量越低。 2. 推理适应性反应：低氧环境会刺激动物产生更多血红蛋白，提高血液运氧效率，这是典型的生理适应。 3. 确定曲线趋势：随水温升高，自变量增大，血红蛋白含量作为因变量应增大，曲线呈上升趋势。 4. 匹配选项：甲上升，符合；乙最终下降，不符合；丙整体下降，不符合；丁不变，不符合。选 A（甲）。

点评/变式：本题表面考曲线判断，实质考“生物对环境适应的具体表现”。变式训练可改为给出不同海拔（氧分压不同）或不同温度下的红细胞数目曲线，解法相同：低氧→红细胞/血红蛋白增多。核心是抓住“环境限制因素→生物补偿调节”的逻辑。
