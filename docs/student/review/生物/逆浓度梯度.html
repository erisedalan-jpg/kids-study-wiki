逆浓度梯度

考点逆浓度梯度权重5真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：5
  • 真题数：1；年份跨度：2019–2019
  • 出现题位：选择3
  • 难度分布：中1

知识精要

  • 被动运输与主动运输的本质区别：被动运输（自由扩散、协助扩散）顺浓度梯度进行，不消耗细胞代谢能；主动运输逆浓度梯度进行，需载体蛋白并消耗能量（通常由ATP水解提供）。
  • 主动运输的核心特征：
  • 逆浓度梯度：从低浓度侧运往高浓度侧。
  • 需要载体蛋白（如H⁺-ATPase等泵蛋白），载体具有特异性。
  • 需要消耗能量，直接能量来源一般为ATP水解，少数可借助光能或离子电化学梯度（此时光能并不是直接驱动载体构象改变，而是通过影响ATP合成或信号途径间接供能）。
  • H⁺-ATPase类载体：兼具载体与ATP水解酶活性，水解ATP的同时将H⁺逆浓度梯度跨膜转运，是植物细胞、线粒体、叶绿体等膜上的重要主动运输系统。
  • 对照实验分析思路：通过抑制ATP水解（加抑制剂）来阻断能量供应，若运输过程停止，则可判定该运输需ATP供能，属于主动运输；若蓝光引起的效应被抑制剂阻断，说明蓝光的作用需通过ATP水解来实现，而非直接供能。

解题方法与套路

  1. 锁定运输方向与浓度关系：分析题干中细胞内外pH、H⁺浓度等信息，明确离子运输是顺浓度还是逆浓度。如细胞内pH高于细胞外→细胞外H⁺浓度高，细胞内H⁺浓度低，H⁺外流属逆浓度梯度。
  2. 判断能量来源：主动运输的直接能量通常是ATP水解；若题干中出现光、抑制剂等，需分清能量供应链——光可能通过促进ATP合成间接驱动，而非直接作为能量货币。
  3. 对照实验结果推理：
  4. 实验组1（蓝光照射）→ 结果pH明显降低 → H⁺外流增加。
  5. 实验组2（加ATP水解抑制剂 + 蓝光）→ 结果pH不变 → 运输被阻断 → 证明该运输依赖ATP水解供能。
  6. 由此推断：蓝光的作用是激活或促进ATP水解，而不是直接为H⁺转运供能。
  7. 排除错误选项技巧：选项中若出现“直接提供”“自由扩散通过膜”等说法，需用对照实验结论和膜通透原理一一验证。主动运输蛋白通常不允许离子自由扩散通过。

高频易错

  • 混淆能量直接来源：误认为蓝光可直接作为主动运输的能量来源。实际上，光能需先转化成ATP中的化学能，再由ATP水解驱动载体。选项C“可由蓝光直接提供”正是典型陷阱。
  • 忽略自由扩散的限制：H⁺带电荷，不易通过磷脂双分子层自由扩散，即使存在浓度梯度，也需要通道或载体。选项D指出H⁺不能自由扩散进入细胞，常被误判为错误，但实际正确。
  • 不会区分“主动运输被阻断”与“载体失活”：抑制剂抑制的是ATP水解，并非直接破坏载体蛋白，但会导致主动运输停止。需明确能量供应与载体功能之间的关系。
  • 忽视细胞内外pH与H⁺浓度的换算：pH越小，H⁺浓度越高。细胞内pH高于细胞外→胞内H⁺浓度低，胞外高，因此H⁺转运到胞外为逆浓度梯度。

代表题精讲

题目：2019年新课标Ⅱ卷第3题，关于H⁺-ATPase的实验推测不合理选项的判断。

思路： - 提取关键信息：H⁺-ATPase有ATP水解酶活性，逆浓度梯度运H⁺；细胞悬液细胞内pH高于细胞外；暗中pH不变；蓝光照射后pH明显降低；加入ATP水解抑制剂+蓝光，pH不变。 - 逐项验证：A、B、D均与实验信息和主动运输原理一致；C项“蓝光直接提供能量”与抑制剂实验结果矛盾（若蓝光直接供能，抑制剂不应阻断），故不合理。

步骤： 1. 根据“细胞内pH高于细胞外”推出胞外H⁺浓度高，H⁺外流为逆浓度梯度。 2. 蓝光使溶液pH降低，说明H⁺外流增强，且该过程被ATP水解抑制剂阻断，证明运输需要ATP水解，而非光能直接驱动。 3. 判断各选项： - A：质膜定位+蓝光引起外流 → 正确。 - B：蓝光通过H⁺-ATPase导致逆浓度运输 → 正确。 - C：逆浓度转运所需能量由蓝光直接提供 → 与抑制剂阻断事实矛盾，错误。 - D：H⁺不能自由扩散进入细胞 → 正确（电荷、无通道时需载体）。 4. 选不合理项C。

点评/变式： 该题综合考查主动运输与实验分析能力。易错点在于把蓝光的作用等同于直接能源。类似考法可变为：将抑制剂换为呼吸抑制剂或ATP合成酶抑制剂，原理相同。注意区分类题中光能、电能、化学能的转化路径。
