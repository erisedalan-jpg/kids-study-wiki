遗传信息翻译

考点遗传信息翻译权重1真题数1学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：1
  • 真题数：1；年份跨度：2012–2012
  • 出现题位：选择1
  • 难度分布：易1

知识精要

  • 翻译的概念：以 mRNA 为模板，以 tRNA 为运载工具，在核糖体上按照 mRNA 的密码子顺序合成具有一定氨基酸序列的蛋白质的过程。
  • 翻译的场所、模板与原料：
  • 场所：核糖体（由 rRNA 和蛋白质组成）。
  • 模板：mRNA（其碱基序列直接决定蛋白质的氨基酸序列）。
  • 原料：氨基酸（由 tRNA 搬运）。
  • 密码子与反密码子：
  • 密码子：mRNA 上决定一个氨基酸的 3 个相邻碱基，共有 64 种，其中 61 种编码氨基酸，3 种为终止密码子。
  • 反密码子：tRNA 上能与密码子互补配对的 3 个碱基，tRNA 有 61 种。
  • 密码子的特性：专一性（一种密码子只决定一种氨基酸）、通用性（所有生物共用一套密码子）。
  • 蛋白质结构多样性的原因：
  • 直接原因：mRNA 的碱基序列不同 → 氨基酸的种类、数目、排列顺序不同 + 肽链的空间结构千变万化。
  • 根本原因：DNA 的碱基序列不同（或基因的选择性表达导致转录出的 mRNA 不同）。
  • 细胞分化与翻译的关系：同一物种的不同细胞含有相同的 DNA，但由于基因的选择性表达，转录出的 mRNA 不同，翻译出的蛋白质不同，细胞功能出现差异。翻译过程中，tRNA 种类、核糖体成分、密码子与氨基酸的对应关系在所有体细胞中都是一致的。

解题方法与套路

  1. 明确设问对象：判断题目问的是蛋白质多样性的“直接原因”还是“根本原因”。
  2. 关键词含“直接原因”“mRNA”等，一般选 mRNA 碱基序列不同。
  3. 关键词含“根本原因”“基因”“DNA”等，选 DNA 碱基序列不同或基因选择性表达。
  4. 排除不变因素：在同一个体不同细胞中，以下因素通常相同，不能作为差异的原因：
  5. tRNA 的种类和结构
  6. 核糖体的化学成分（rRNA + 蛋白质）
  7. 密码子与氨基酸的对应关系（密码子表具有通用性）
  8. 抓住翻译的核心逻辑：蛋白质的氨基酸排列顺序完全由 mRNA 上的密码子排列顺序决定，因此两个蛋白质的氨基酸顺序不同，必然是由于翻译它们的 mRNA 碱基序列不同。
  9. 结合细胞分化：若题干提到“同一物种的两类细胞”，指向基因的选择性表达 → 转录产生的 mRNA 不同 → 翻译产物不同。
  10. 谨慎辨析选项：遇到“tRNA 种类不同”“核糖体成分不同”“同一密码子决定不同氨基酸”等表述，可立即判断为错误，因为这与生物学基本事实相悖。

高频易错

  • 混淆直接原因与根本原因：题目问“氨基酸排列顺序不同”，是蛋白质的差异，其直接模板是 mRNA，故选 mRNA 不同；若追问“为什么 mRNA 不同”，则答基因的选择性表达（DNA 相同，但表达情况不同）。误选 DNA 不同会失分。
  • 误认为不同细胞中 tRNA 种类不同：tRNA 有 61 种，所有体细胞共享同一套 tRNA，不会因细胞种类而改变。
  • 误认为核糖体成分不同：原核与真核的核糖体有差异，但同一物种的体细胞中核糖体都由 rRNA 和相同的蛋白质组成。
  • 误以为同一密码子可以决定多种氨基酸：密码子具有专一性，一种密码子只对应一种氨基酸，这是翻译精确性的基础。
  • 忽视“同一物种”的大前提：同一物种的细胞遗传物质相同，因此蛋白质差异只能源于表达层面的调控，而不是基因本身不同。
  • 对中心法则顺序理解不清：DNA → mRNA → 蛋白质，要看清题目是在哪一层次提问。

代表题精讲

题目：同一物种的两类细胞各产生一种分泌蛋白，组成这两种蛋白质的各种氨基酸含量相同，但排列顺序不同。其原因是参与这两种蛋白质合成的（　　）
A．tRNA种类不同
B．mRNA碱基序列不同
C．核糖体成分不同
D．同一密码子所决定的氨基酸不同

思路：抓住“氨基酸含量相同，排列顺序不同”这一关键，可知蛋白质的空间结构或一级结构有异，但不涉及氨基酸种类差异。从中心法则可知，氨基酸排列顺序由 mRNA 上密码子顺序决定。两类细胞属于同一物种，基因组相同，因此差异出在转录后的 mRNA 上。继而排除翻译装置（tRNA、核糖体）和密码子表差异。

步骤：
1. 分析已知：同一物种两类细胞，分泌蛋白 A 与 B 氨基酸组成（种类及每种含量）相同，但排列顺序不同 → 蛋白质不同。
2. 回忆决定氨基酸排列顺序的直接模板：mRNA 的碱基序列（密码子）。
3. 排除其他可能：
- tRNA：负责识别并转运氨基酸，所有细胞 tRNA 种类一致，不决定顺序。
- 核糖体：仅提供场所，成分不变。
- 密码子表：通用且专一，同一密码子不会决定不同氨基酸。
4. 最终确定 B 选项。

点评/变式：
- 此题考查点在于“蛋白质差异的直接模板”。同一物种的不同细胞，DNA 相同，蛋白质不同的直接原因一定是 mRNA 不同。
- 变式训练：若题干改为“根本原因”，则答案应选“基因的选择性表达”或“DNA 中基因转录的情况不同”。
- 解题时要树立“不变的”与“变化”的对照思维：在同一生物体内，tRNA、核糖体、密码子表是“通用装置”，而 mRNA 是“特异性信息分子”。这样能迅速排除干扰项。
