遗传物质

考点遗传物质权重16真题数3学科生物父主题遗传与进化

考点定位

  • 父主题：遗传与进化
  • 权重 weight：16
  • 真题数：3；年份跨度：2016–2020
  • 出现题位：选择2 选择3 选择5
  • 难度分布：中1 易2

知识精要

  • 遗传物质的本质：绝大多数生物的遗传物质是DNA；少数病毒（如新冠病毒、烟草花叶病毒、HIV）的遗传物质是RNA。
  • 病毒结构特点：无细胞结构，无核糖体，必须寄生在活细胞内。主要由核酸和蛋白质外壳构成。
  • 病毒核酸种类：一种病毒只含一种核酸（DNA或RNA），因此病毒体内核苷酸只有4种（脱氧核糖核苷酸或核糖核苷酸）。细胞生物同时含有DNA和RNA，体内共有8种核苷酸。
  • 病毒入侵与繁殖：动物病毒通常通过胞吞（膜融合）进入宿主细胞；进入后利用宿主细胞的核糖体等结构合成自身蛋白质，复制核酸并组装子代病毒。
  • DNA解旋的生理意义：DNA双链解开是DNA复制和转录的必要前提。复制需解旋酶打开双链，转录需RNA聚合酶解开局部双链。若DNA双链不能解开，则复制和转录均受阻。
  • 细胞周期与DNA复制：DNA复制发生在分裂间期（S期）。复制受阻会导致细胞停滞在间期，不能进入分裂期，而非阻断在分裂中期。癌细胞增殖依赖旺盛的DNA复制，阻碍DNA解旋可抑制其增殖。
  • 免疫与抗原：病毒或细菌的蛋白质可作为抗原，引发机体免疫反应。自身免疫病是免疫系统将自身物质当作外来异物攻击所致（如类风湿性关节炎）。

解题方法与套路

  1. 区分病毒与细胞生物的核酸种类：看准题目信息是病毒还是细菌（原核）、真核细胞。病毒核酸单一，核苷酸4种；细胞生物含DNA和RNA，核苷酸8种。
  2. 辨析病毒增殖过程：病毒进入宿主细胞的方式（注意动物病毒多为胞吞，噬菌体为注入核酸），蛋白质合成场所（宿主核糖体），原料来源均来自宿主。
  3. 识记常见病毒核酸类型：DNA病毒如T2噬菌体；RNA病毒如新冠病毒、烟草花叶病毒、HIV、流感病毒等。T2噬菌体专门侵染大肠杆菌，不能侵染肺炎双球菌。
  4. 针对“抑制DNA解旋”类题目：抓住“解旋是复制和转录的共同条件”这一核心，推理影响：①DNA复制受阻；②转录受阻；③分裂间期进程被阻断（而非分裂中期）；④对增殖活跃的癌细胞抑制作用更明显。
  5. 辨析免疫类型：自身免疫病是免疫系统攻击自身组织；过敏反应是针对外来无害物质（如花粉、海鲜）；免疫缺陷是免疫功能低下或缺失（如艾滋病）。

高频易错

  • 病毒入侵方式：新冠病毒通过胞吞进入细胞，易错认为是直接将RNA注入（如噬菌体方式）。
  • 病毒蛋白质合成场所：病毒无核糖体，必须利用宿主细胞核糖体，考生易误认为病毒自身含有核糖体。
  • 噬菌体寄主特异性：T2噬菌体只侵染大肠杆菌，不可误认为它能侵染肺炎双球菌。
  • 核苷酸种类计算：细胞生物含两种核酸，核苷酸8种；病毒只含一种核酸，核苷酸4种。切忌混淆。
  • DNA解旋抑制剂的作用时期：该类物质阻断的是间期的复制和转录，而细胞周期阻断在间期（或G1/S期），不是分裂中期。分裂中线粒体、染色单体分离等过程不直接依赖DNA解旋。
  • 抑制增殖与“中期”：抑制剂阻断DNA复制，使细胞无法通过G1/S检查点，从而阻止细胞进入分裂期，癌细胞的无限增殖因而被抑制。

代表题精讲

代表题1：2020-新课标Ⅱ-03

题目：下列关于新冠病毒和肺炎双球菌的叙述，正确的是（　　）……（正确项：某些蛋白质可作为抗原引起机体免疫反应）

思路：对比病毒的寄生特性与原核生物的核酸组成，逐一分析选项中的生物学事实。

步骤： 1. A项：新冠病毒（有包膜的RNA病毒）通过胞吞进入宿主细胞——符合事实，但选项原文错误描述为其他方式（真题未显示但解析指出A错误），判断其错误。 2. B项：病毒无核糖体，只能利用宿主细胞核糖体合成蛋白质——错误。 3. C项：新冠病毒遗传物质为RNA，含核糖核苷酸；肺炎双球菌遗传物质为DNA，含脱氧核糖核苷酸，两者含有的核苷酸种类不同——正确（但选项错误认为相同，故C错）。 4. D项：新冠病毒和肺炎双球菌的蛋白质可作为抗原引起免疫反应——正确。 结论选D。

点评/变式：此类题常将病毒与原核生物放在一起考查结构、代谢、遗传物质的差异。注意病毒只含一种核酸，原核生物含两种核酸。抗原性物质不限于蛋白质，某些多糖、脂类也可作为抗原，但教材常见例为蛋白质。变式可考查病毒侵入宿主的具体过程或免疫应答的类型。

代表题2：2018-新课标Ⅱ-05

题目：下列关于病毒的叙述，错误的是（　　）

思路：结合不同病毒（烟草花叶病毒、T2噬菌体、HIV）的经典生物学事实，找出与事实不符的选项。

步骤： - A：烟草花叶病毒是RNA病毒，可以提取到RNA——正确。 - B：T2噬菌体特异侵染大肠杆菌，不能感染肺炎双球菌并使其裂解——错误。 - C：HIV攻击T细胞，可引起获得性免疫缺陷综合征（AIDS）——正确。 故错误选项为B。

点评/变式：牢记经典实验材料：烟草花叶病毒证明RNA是遗传物质；T2噬菌体侵染大肠杆菌实验证明DNA是遗传物质；HIV属逆转录病毒。易错点在于记混噬菌体的宿主。变式可追问T2噬菌体遗传物质是什么，或HIV的逆转录过程。

代表题3：2016-新课标Ⅱ-02

题目：某种物质可插入DNA双链碱基对之间，使双链不能解开。在正常细胞培养液中加入该物质，叙述错误的是（　　）

思路：从“DNA双链不能解开”这一核心限制出发，推理对DNA复制、转录及细胞周期的影响。

步骤： 1. 双链不解开→DNA复制所需模板无法形成→DNA复制障碍（A正确）。 2. 双链不解开→转录时RNA聚合酶无法沿模板移动→转录障碍（B正确）。 3. DNA复制受阻于间期，细胞周期阻断在间期（G1/S期），而不会到达分裂中期——该物质不能将细胞阻断在分裂中期（C错误）。 4. 癌细胞增殖需要频繁进行DNA复制，抑制DNA解旋可抑制其增殖（D正确）。 答案选C。

点评/变式：核心点是“解旋与复制、转录的关系”，以及“间期与分裂期的区分”。许多同学误解“阻断在分裂中期”，实际中期染色体排列、分离等不直接依赖DNA解旋。变式可联系化疗药物作用的分子机制，或将其与基因表达、细胞凋亡结合。
