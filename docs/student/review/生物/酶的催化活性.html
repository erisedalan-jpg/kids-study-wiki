酶的催化活性

考点酶的催化活性权重7真题数1学科生物父主题分子与细胞

考点定位

  • 父主题：分子与细胞
  • 权重 weight：7
  • 真题数：1；年份跨度：2022–2022
  • 出现题位：选择4
  • 难度分布：中1

知识精要

  • 酶的化学本质：绝大多数酶是蛋白质，少数是核糖核酸酶（RNA），即RNA也具有催化功能（核酶）。
  • 酶的催化活性条件：酶的活性受温度、pH、金属离子等影响。不同酶所需最适条件不同。本题中RNA组分的催化活性表现为依赖高浓度 $Mg^{2+}$，而蛋白质组分在该体系中无催化活性。
  • 实验变量分析：实验设计必须贯彻单一变量原则与对照原则。本题自变量为“酶组分种类”与“$Mg^{2+}$浓度”，因变量为“产物有无”，底物为无关变量。第①组为阳性对照组。
  • 结果与结论的对应：有产物生成 → 该条件下对应组分有催化活性；无产物生成 → 该条件下对应组分无催化活性。

解题方法与套路

  1. 锁定实验目的与变量
    通读题干，明确“探究什么”，找出自变量（通常为表格中改变的条件：组分、离子浓度）和因变量（产物有无/反应速率等），识别无关变量（底物等）及对照组（全齐条件组①）。
  2. 逐组转化信息
    将表格中的“+”“-”转化为文字条件：哪一组包含哪些组分、处于哪种离子浓度、是否产生产物。
  3. 运用单一变量对比法
  4. 比较只有 $Mg^{2+}$ 浓度不同而其它组分相同的实验组（如②与④：均有底物+RNA组分；③与⑤：均有底物+蛋白质组分），得出单一离子浓度影响某一组分活性的结论。
  5. 比较只有酶组分不同而 $Mg^{2+}$ 浓度相同的实验组，得出某一浓度下哪种组分有活性。
  6. 逐项选项对照
    将选项描述的条件与实验组的实际产物有无一一比对，注意绝对化字眼（“必须”“只”“随……升高而升高”等），若无充分数据支持则排除。

高频易错

  • 忽视全组分正常条件下的结果：看到第④组高 $Mg^{2+}$ 有产物，就误认为“酶P必须在高浓度 $Mg^{2+}$ 才有活性”，忽略了第①组低 $Mg^{2+}$ 条件下全酶（RNA+蛋白质）也有产物，说明全酶在低浓度下已有活性。
  • 将全酶的活性归于蛋白质：受“酶通常是蛋白质”定势影响，误认为蛋白质组分必然有催化功能。而本题①②③对比可知蛋白质组分单独存在（不论RNA有无、不论 $Mg^{2+}$浓度）均无产物生成，催化活性来自RNA组分。
  • 混淆对照组中辅助因子的作用：误以为 $Mg^{2+}$ 是激活蛋白质组分的，但对比③和⑤，不同 $Mg^{2+}$ 浓度下蛋白质组分均无产物，说明蛋白质组分无活性，与 $Mg^{2+}$ 浓度无关。
  • 错用“随浓度升高活性升高”结论：表格只设定了两个浓度点，无法得出连续变化趋势，这类线性描述选项若无多梯度数据支撑通常为误。

代表题精讲

题目（2022·全国乙卷·4）
探究由RNA和蛋白质组成的酶P不同组分的催化条件，5组实验依次控制底物、RNA组分、蛋白质组分、低/高浓度 $Mg^{2+}$ 的有无，记录产物情况，判断正确结论。

思路
先定位实验类型为“组分-离子浓度”双因素实验。明确变量后，将产物有无直接对应为“该条件对应组分是否有催化活性”。再利用单一变量配对比较：②与④对比得RNA组分需高 $Mg^{2+}$；③与⑤对比得蛋白质组分在任何 $Mg^{2+}$ 浓度下均无催化活性。最后结合①全酶在低 $Mg^{2+}$ 有活性，可否定绝对化结论。

步骤
- 提取变量：自变量为组分组合（RNA±、蛋白质±）和 $Mg^{2+}$ 浓度（低/高），因变量为产物。无关变量底物均存在。
- 配对分析：
- 组②（RNA+，蛋白-，低 $Mg^{2+}$）无产物，组④（RNA+，蛋白-，高 $Mg^{2+}$）有产物 → 高 $Mg^{2+}$ 下RNA组分有催化活性。
- 组③（RNA-，蛋白+，低 $Mg^{2+}$）无产物，组⑤（RNA-，蛋白+，高 $Mg^{2+}$）无产物 → 蛋白组分在任何条件下均无活性。
- 组①全酶（RNA+，蛋白+，低 $Mg^{2+}$）有产物 → 全酶在低 $Mg^{2+}$ 即具活性。
- 选项验证：
- A：“必须”与①矛盾，错。
- B、D：蛋白质组分无催化活性，错。
- C：“高浓度 $Mg^{2+}$ 下RNA组分有催化活性”与②④对比一致，正确。

点评/变式
本题核心在于打破“酶都是蛋白质”的刻板印象，并且考查从双因素表格中剥离因果关系的能力。常见变式：提供其他金属离子浓度梯度或pH梯度，结合不同酶组分，仍用单一变量配对法求解。注意当题干给出多种条件组合时，切莫跳过阳性对照组（全齐组）直接下结论；同时对“一定需要”“随……升高而升高”等绝/趋势性描述需谨慎求证是否有完整数据支撑。
