醛固酮

考点醛固酮权重6真题数1学科生物父主题稳态与调节

考点定位

  • 父主题：稳态与调节
  • 权重 weight：6
  • 真题数：1；年份跨度：2024–2024
  • 出现题位：选择11
  • 难度分布：易1

知识精要

  • 醛固酮
  • 化学本质：固醇类（盐皮质激素），由肾上腺皮质球状带分泌。
  • 生理作用：促进肾远曲小管和集合管对 $Na^+$ 的重吸收，同时促进 $K^+$ 的分泌（简称“保钠排钾”）。$Na^+$ 重吸收使水跟随被动重吸收，导致细胞外液增多、血压升高。
  • 分泌调节：
    1. 肾素-血管紧张素-醛固酮系统（RAAS）：循环血量减少、血压下降 → 肾球旁细胞分泌肾素 → 血管紧张素原 → 血管紧张素Ⅰ →（肺中转化酶）→ 血管紧张素Ⅱ → 刺激肾上腺皮质分泌醛固酮。
    2. 血 $Na^+$ 浓度降低或血 $K^+$ 浓度升高可直接促进分泌。
    3. 下丘脑-垂体-肾上腺皮质轴释放的促肾上腺皮质激素（ACTH）也可在一定程度上促进分泌（高中阶段认可其受该轴调节）。
  • 抗利尿激素（ADH）
  • 来源：下丘脑视上核、室旁核的神经内分泌细胞合成，经神经垂体释放入血。
  • 作用：增加肾远曲小管和集合管对水的通透性，促进水重吸收，减少尿量，使细胞外液渗透压降低。
  • 内耳听觉感受细胞（毛细胞）生活在内淋巴液中，内淋巴离子成分独特（高 $K^+$ 低 $Na^+$），维持内淋巴电位和离子稳态是正常听力的基础。内淋巴水肿即内环境稳态失衡，会影响听觉转换。

解题方法与套路

  1. 读表析数据：对比实验组与对照组数值的升降，快速判断激素分泌变化方向。
  2. 激素功能归因：调用核心激素（抗利尿激素、醛固酮等）的生理作用，推断该变化引发的连锁生理效应（如渗透压升降、离子浓度变化、尿量等）。
  3. 检验调节途径：对选项中涉及的调节轴（如下丘脑-垂体-肾上腺皮质轴）进行判断，结合教材知识确认是否正确。
  4. 综合治疗原理：根据病理状态（如淋巴水肿、水钠潴留）和药物作用（利尿剂排水），选择合理的辅助措施（如限盐），利用激素功能进行反向推理。

高频易错

  • 抗利尿激素的作用后果：ADH增多 → 水重吸收增强 → 尿量减少、血浆渗透压 下降，而非上升。易错选“使细胞外液渗透压升高”。
  • 醛固酮的调节途径：虽主要受RAAS和血$Na^+$/$K^+$调控，但高中阶段需知道肾上腺皮质分泌的激素（包括醛固酮）受下丘脑-垂体-肾上腺皮质轴的调控，因此“醛固酮的分泌可受该轴调控”为正确叙述，考生常因此条模糊而选错。
  • 利尿剂与饮食的配合：利尿剂促进排 $Na^+$ 排水，若高盐饮食会抵消药效、加重水钠潴留，故应低盐饮食，而非无需控盐或高盐。

代表题精讲

题目（2024·辽宁·11） 梅尼埃病患者急性发作期血清抗利尿激素和醛固酮水平均高于正常，临床上常用利尿剂治疗。根据实验结果和激素功能，选出错误叙述。

思路
逐项利用抗利尿激素、醛固酮的生理作用及调节知识，分析表格数据，结合内环境稳态与临床治疗原则判断正误。

步骤
- A项：听觉感受细胞生存于内淋巴液，淋巴水肿即为内环境成分和压力改变，稳态破坏必然影响听力 → 正确。 - B项：抗利尿激素促进肾小管和集合管重吸收水，使细胞外液渗透压降低，而非升高；发作期ADH升高导致渗透压下降 → 错误，符合题意。 - C项：醛固酮作为肾上腺皮质激素，其分泌受下丘脑-垂体-肾上腺皮质轴的调控（ACTH可促进其释放），此说法在高中范围内为正确 → 正确。 - D项：利尿剂排水；醛固酮已升高的患者水钠潴留明显，若高盐饮食会加重水肿，因此应保持低盐饮食 → 正确。 - 综上，错误的是B。

点评/变式
本题通过临床实例综合考查两种激素的比较。核心易混点在于抗利尿激素使渗透压下降（常被误认为升高），而醛固酮导致水钠潴留（渗透压可因等渗性水位增而变动不大，但通过容量调整血压）。变式可能将两种激素与相关离子浓度（血$Na^+$、血$K^+$）联动设问，需紧扣“保钠排钾”与“排水降渗”的功能区别。
