限制酶

考点限制酶权重17真题数3学科生物父主题生物技术与工程

考点定位

  • 父主题：生物技术与工程
  • 权重 weight：17
  • 真题数：3；年份跨度：2012–2021
  • 出现题位：填空12
  • 难度分布：中3

知识精要

  • 限制酶的来源与作用：主要从原核生物中分离，能识别双链 DNA 分子的特定核苷酸序列，并在特定位点切割磷酸二酯键。
  • 切割末端类型：
    • 黏性末端：错位切割，产生单链突出的末端，如 $Eco$RⅠ、$Pst$Ⅰ。两条链的断裂位置不在同一点。
    • 平末端：沿对称轴切割，产生无单链突出的齐平末端，如 $Sma$Ⅰ、$Eco$RⅤ。
  • DNA 连接酶：恢复被限制酶切开的磷酸二酯键，连接具有相同末端（黏性末端或平末端）的 DNA 片段。
    • $E.coli$ DNA 连接酶：只能连接互补配对的黏性末端，修复效率高。
    • T4 DNA 连接酶：既能连接黏性末端，也能连接平末端，但连接平末端效率较低。
  • 基因工程载体（如质粒）的必备条件：
    • 复制原点：保证载体在宿主细胞内能够自我复制，使目的基因得以扩增。
    • 多克隆位点/限制酶切位点：含有一至多个限制酶切位点，便于外源 DNA 插入，且这些位点最好位于标记基因之外。
    • 标记基因：如抗生素抗性基因，作用是筛选和鉴定含有载体或重组 DNA 的宿主细胞。
    • 启动子：位于目的基因首端的一段特殊 DNA 序列，是 RNA 聚合酶识别与结合的位点，能驱动基因的转录。
  • 筛选方法：利用抗生素抗性基因，在含有相应抗生素的培养基中培养宿主细胞，能存活的细胞即为成功导入含标记基因载体的细胞。

解题方法与套路

  1. 判断切割末端类型：

    • 观察限制酶识别序列上的切割箭头。若两条链的切割点直接对齐，产生齐平的末端，为平末端（如 $Sma$Ⅰ、$Eco$RⅤ）。
    • 若两条链的切割点错开，产生单链突出的 DNA 片段，为黏性末端（如 $Eco$RⅠ、$Pst$Ⅰ）。

  2. 匹配 DNA 连接酶类型：

    • 题干要求使用 $E.coli$ DNA 连接酶时，只能选择产生黏性末端的酶切割的片段进行连接。
    • 题干要求使用 T4 DNA 连接酶时，所有产生黏性末端或平末端的酶切割的片段均可连接。

  3. 设计双酶切方案：

    • 核心目的：防止载体与目的基因的自身环化及反向连接。
    • 选酶策略：选择两种产生不同黏性末端的限制酶，分别切割目的基因两侧与载体多克隆位点上的相应序列，确保目的基因能按预定方向与载体正确连接，并保持目的基因与载体结构的完整。

  4. 解析基因结构功能：

    • 明确基因表达（转录、翻译）的产物（如荧光蛋白）是检测的指标。
    • 区分 PCR 鉴定（检测细胞核中的DNA）与 RNA 鉴定（检测特定细胞中提取的 mRNA）的对象。
    • 掌握启动子、标记基因、复制原点等元件在基因表达、筛选、复制中的核心功能。

高频易错

  • 误判酶切末端：混淆 $Sma$Ⅰ 产生的平末端与 $Eco$RⅠ 产生的黏性末端。解题时务必核对图示中切割点的位置是否交错。
  • 混淆两种 DNA 连接酶的功能：认为 $E.coli$ DNA 连接酶也能连接平末端。谨记其只能连接互补配对的黏性末端，连接平末端是 T4 DNA 连接酶的专属能力。
  • 混淆 PCR 与分子杂交检测的对象：问“在不同组织细胞中是否存在目的基因”，应提取基因组 DNA（总 DNA）做 PCR 鉴定；问“目的基因在特定组织细胞中是否表达”，应提取 mRNA 或检测蛋白质产物（如下例中的荧光蛋白）。
  • 混淆启动子的功能与位置：将启动子功能错误描述为“起始翻译”或“起始 DNA 复制”。其准确功能是“RNA 聚合酶识别和结合，驱动转录”，位于基因上游。
  • 载体元件功能记忆模糊：将“复制原点”的作用写成“翻译”或“表达”；将“标记基因”的作用仅写成“筛选”，未写出具体的“在含抗生素培养基中培养，存活者即为阳性克隆”的逻辑过程。

代表题精讲

题目 (2021-全国乙-12)

用 DNA 重组技术创造生物产品，图示 4 种限制酶的切割位点。回答了关于 DNA 连接酶连接效率与末端类型的关系、质粒载体元件功能及筛选方法、启动子定义等问题。

思路 此题系统考查了基因工程核心工具酶及载体功能。解题核心是根据箭头位置判断末端类型，再匹配连接酶特性。载体元件的功能需结合实践流程准确阐述。

步骤 1. 末端判断与连接酶匹配：观察图，$Eco$RⅠ、$Pst$Ⅰ 切割位点交错，产生黏性末端；$Sma$Ⅰ、$Eco$RⅤ 剪切点对齐，产生平末端。因此，$E.coli$ DNA 连接酶仅能连接前两者产生的片段；T4 DNA 连接酶能连接所有四种酶产生的片段。 2. 明确关键化学键：DNA 连接酶连接的是脱氧核糖与磷酸基团之间的 $3',5'$-磷酸二酯键。 3. 解析载体条件：复制原点 → 自我复制；多克隆位点 → 一至多个限制酶切位点；标记基因筛选方法 → 用含相应抗生素的培养基培养，能存活的即为含该质粒的宿主细胞。 4. 定义启动子：启动子是 RNA 聚合酶识别、结合的 DNA 序列，功能是驱动（启动）基因的转录。

点评/变式 此题是基因工程基础概念的集合考查。高频失分点在于：(1) 对两种连接酶连接特性的混淆；(2) 对标记基因筛选方法的表述不完整，缺少“用相应抗生素培养”这一具体操作；(3) 将启动子的功能错答为“起始翻译”或“表达”。变式训练可替换图示，考查不同限制酶切后产物的连接可能性。

题目 (2018-新课标Ⅱ-12)

某团队将 L1 基因与 GFP 基因融合构建真核表达载体 P1，图示了载体结构和四种产生不同黏性末端的限制酶 E1~E4 的位点。问题涉及双酶切选择、基因表达验证、体细胞核移植及 PCR 鉴定取材。

思路 此题考查“双酶切”这一高阶技术思维。解题关键在于，选择两种酶切位点，使目的基因插入载体时，既能保持自身完整不被切碎，又能确保与载体正确连接。

步骤 1. 分析双酶切选择：切割目的基因甲（L1-GFP）时，若用 E2 或 E3，会分别切断 L1 和 GFP 基因，破坏甲的完整性。因此，必须选择切割甲两侧载体序列的酶，即 E1 和 E4。这样既能完整切下甲，又能在载体多克隆位点（MCS）上产生两个不同黏性末端，保证甲定向且正确地与载体连接，避免自身环化。 2. 解读表达现象：观察到绿色荧光，说明 GFP 基因已成功表达出蛋白质。基因表达包括 转录（合成 mRNA）和 翻译（合成蛋白质）两个关键过程。 3. 推断细胞工程流程：要使克隆牛获得产生绿色荧光的性状，需将已导入载体 P1 的供体细胞的细胞核，移入去核的卵母细胞中。 4. 确定 PCR 鉴定取材：要检测甲是否存在于克隆牛的不同组织中，实质是检测其基因组中是否含有甲的 DNA 序列。因此，应提取各组织细胞的总 DNA (核 DNA) 作为 PCR 模板。若提取 mRNA，则只能检测在特定组织中是否发生转录，与题意“是否存在”不符。

点评/变式 核心失分点在于“双酶切”的目的选择：考生易只想到“防止自身环化”，而忽略“保持目的基因完整”这一前提。另外，PCR 检测“存在”与“表达”所需提取的核酸类型（DNA vs RNA）极易混淆。变式可改为让考生根据目的基因上的酶切位点图，自行选择特定的两种酶，并说明不能选择其他酶的理由。
