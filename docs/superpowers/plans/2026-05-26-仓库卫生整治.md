# 仓库卫生整治 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把根目录 6 个被 git 跟踪的一次性中间产物移出跟踪并归到已忽略目录，加固 .gitignore 防复发，给出 working/ 本地清理清单。

**Architecture:** 纯 git + 文件移动操作，无代码逻辑改动。验证靠 `git ls-files` / `git status` / 探针文件观察，而非单元测试。一次提交完成「移出跟踪 + 新增忽略规则」，缩小与 Obsidian Git 30 分钟自动备份的竞态窗口。

**Tech Stack:** git、bash（Windows 下 Unix 路径风格）。

> **关于提交**：本仓库 Obsidian Git 每 30 分钟自动 `vault backup` 提交全部改动。本计划在 Task 4 做一次**专门提交**（`chore: 仓库卫生整治`），让 `git rm --cached` 成为可读的一笔历史，而非淹没在 `vault backup: N files` 里。若用户偏好交给 vault backup，可跳过 Task 4 的 commit，仅完成暂存。

**Spec:** `docs/superpowers/specs/2026-05-26-仓库卫生整治-design.md`

### Task 3: 加固 .gitignore

**Files:**
- Modify: `.gitignore`（在「# 编辑器临时」段之后插入新段）

- [ ] **Step 1: 在 .gitignore 中插入根目录锚定忽略规则**

在 `.gitignore` 的「# 编辑器临时」段（`*~` 行）之后、空行处，插入：
```gitignore

# 根目录一次性诊断/临时产物（防 vault backup 误吞；前导 / 仅锚定根目录，不影响子目录脚本）
/_*.txt
/_*.py
/_*.json
/*_todo.*
/_tmp_*
```

- [ ] **Step 2: 验证新规则忽略根目录探针文件**

Run:
```bash
touch _probe.txt _probe.py _scratch_todo.json
git status --porcelain _probe.txt _probe.py _scratch_todo.json
```
Expected: **空输出**（三个探针均被忽略，不出现在 status 中）。

- [ ] **Step 3: 验证子目录脚本未被误伤**

Run:
```bash
git check-ignore 00-元/scripts/_utils.py 00-元/scripts/_exam_utils.py; echo "exit=$?"
```
Expected: 无文件被列出，`exit=1`（check-ignore 无匹配时返回 1）——确认子目录下划线脚本不被忽略。

- [ ] **Step 4: 清理探针文件**

Run:
```bash
rm -f _probe.txt _probe.py _scratch_todo.json
```
Expected: 无输出。

将根目录 6 个一次性诊断/待办文件移出 git 跟踪并归到 docs/superpowers/working/，
新增根锚定忽略规则防 vault backup 再吞同类文件。

Expected: 提交成功，显示 7 项改动（1 modified + 6 deleted）。

- [ ] **Step 3: 验收——根目录无散落文件被跟踪**
