# 设计稿：教材覆盖重设计（试点·小学数学）

- 日期：2026-05-22
- 状态：设计待评审
- 范围：试点 = 小学数学（一上→六下，12 册，现有 81 词条 001-081）；机制对六科（语文/数学/英语/物理/化学/生物）通用

## 1. 背景与目标

本知识库定位是给两个孩子（现 3、5 岁）的「学前→高中」共建 wiki，参考 Karpathy LLM Wiki（原子化文章 + 双向链接组网 + 增量积累）。此前为「高考真题分支」积累了大量初高中词条，导致**学段倒挂**：实测全库 高中 4718 / 初中 1487 / 小学 459 / 学前 131，70% 是高中，而孩子真实所处的低学段最薄。

本次回归核心诉求，**抛开考生分支**，从小学一年级起重新设计。目标三条：

1. **有效性梳理**：体检现有词条，剔除/修正不合规、骨架、断链、错引项。
2. **教材对照扩容**：以教材为权威，确保教材内容**完整**落为知识词条（不再以真题考点为锚）。
3. **纵向成长链**：沿教材概念主线（strand）为词条加「前置→延伸」链，让同一概念从小一到高三连续可走，一条词条陪孩子长大。

不在本设计内：组织轴重构（保留学科本位，不改主题/好奇心漫游为主轴）、学前阶段、考生权重/真题分支。

## 2. 范围

- **试点**：小学数学一段（一上→六下）。跑通「抽检→有效性梳理→覆盖扩容→纵向链接→验收」全流程。
- **推广边界**：机制（工具 + 工作流）对六科全学段通用；推广顺序待试点验收后另定（默认逐科或逐段，不在本稿展开）。
- **不含科目**：科学/道法/史地/政治等当前 0 词条学科不在六科范围内，本轮不建。

## 3. 权威与基准

- **完整性基准 = 102 篇学习路径**（`00-元/学习路径/<学段>/<学科>/`）。每册已含「单元构成」表（章节+教材页+重点+难度）、「重点知识点全单」、「与本 wiki 词条覆盖」对照。
- **教材仅作抽检校验**：不建教材 PDF 全量目录抽取管线。抽样若干册，用 pdf/markitdown 抽教材目录，比对学习路径是否忠实于教材；确认无系统性遗漏后，路径即为权威基准。
- 教材引用源：`00-元/教材索引.md`（人教/统编/PEP 版本映射 + 本地 PDF 路径）。

## 4. 纵向骨架（strand 定义）

以人教小学数学四大领域为概念主线：

1. **数与代数**：数的认识 → 数的运算 → 常见的量 → 式与方程（雏形）→ 比和比例 → 探索规律
2. **图形与几何**：图形的认识（立体先于平面，遵教材序）→ 测量 → 图形的运动 → 图形与位置
3. **统计与概率**：数据收集与整理 → 统计图表 → 可能性
4. **综合与实践**

每条词条归入一条 strand 并标序位；沿 strand 加：
- **前置**（向下溯源）：本概念依赖的更早概念（如 乘法 ← 加法）
- **延伸**（向上生长）：本概念长成的后续概念（如 加法 → 乘法 → 乘方）

strand 与序位、前后位用一份 `strand_map_数学小学.yaml` 显式声明，供链注入脚本读取。

## 5. 模板调整

- **去 🧒3-6 层**：小学词条不再要求「## 🧒 给 3-6 岁（共读版）」段。
  - 新词条模板（小学变体）正文两层：`## 📚 给 6-12 岁（自读版）` + `## 🎓 给 12+（进阶版）`。
  - **存量 81 词条清理**：删除现有 🧒3-6 整段（仅该段；`📖 相关绘本`/`🗣️ 家长讲解话术` 暂留，对 6 岁亲子仍有用）。
- 纵向链落位 `## 🔗 相关词条` 段，结构化为「前置 / 延伸」两子项（规范化 wikilink `[[NNN-裸名|显示]]`）。
- 其余 frontmatter 7 字段、序号前缀、bare-name alias、出处教材链等红线不变。

## 6. 工作流（五阶段）

### Phase 0 — 抽检对照教材
- 抽 3/12 册（建议 一上 / 三下 / 六上，覆盖低中高难度）。
- 用 pdf/markitdown skill 抽教材 PDF 目录与黑体知识点，比对学习路径「单元构成/知识点全单」。
- 产出抽检报告：路径忠实 → 定为基准；发现系统性漏 → 记修正规则并回补路径。
- 路由：Opus/Sonnet（字符级判断），不走 v4-pro。

### Phase 1 — 有效性梳理（体检 81 词条）
- 自动检查：`stats.py` / `analyze_links.py`（断链·无入链）/ `fix_wikilinks.py --dry` / `fix_latex_delim.py --dry` / alias 检查。
- 内容校验（新增 `audit_entries.py`）：
  - frontmatter 7 字段齐、aliases 首位为 bare-name、序号前缀存在
  - 正文层存在性（📚 + 🎓 必有；🧒 应已清）、非空骨架（每层非 `🚧`/非占位、≥ 阈值字数）
  - 教材引用：📑出处「教材」行 PDF 路径真实存在 + 含具体章节
  - wikilink 已规范化（无裸 `[[X]]`）、数学公式用 `$`/`$$` 定界符
- 产出：每词条有效性记分卡 + 不合规清单（分「自动可修」/「需人工」）。

### Phase 2 — 覆盖矩阵（gap 识别）
- 新增 `coverage_matrix.py`：解析某学科段全部学习路径，抽「重点知识点全单」+「单元构成·重点」为期望知识点清单；alias-aware（复用 `fix_wikilinks.collect_targets()`）映射到现有词条。
- 产出覆盖矩阵：`册 → 知识点 → [已覆盖词条 | GAP]`，及缺口知识点清单。

### Phase 3 — 扩容生成（补缺口）
- 缺口知识点走 `gen_atom_skeleton.py`（v4-pro 批量），按小学两层模板生成，带：教材 PDF 引用（查教材索引）+ 学期序号前缀 + bare-name alias。
- 生成后跑 `fix_wikilinks.py --apply` / `fix_latex_delim.py --apply`。
- 路由：批量生成 v4-pro + 50% 自检；数学不涉古文/敏感。

### Phase 4 — 纵向链接
- 编写 `strand_map_数学小学.yaml`（词条 stem → strand + 序位 + 前置[] + 延伸[]）。
- 新增 `gen_ladder_links.py`：按 map 向 `🔗 相关词条` 段注入「前置/延伸」规范化链；**双向保证**（延伸目标自动回填指回的前置），顺带消「无入链」。

### Phase 5 — 验收
- 重跑 `stats.py --write`、`analyze_links.py`：断链↓、无入链↓、本段覆盖 = 100%（vs 学习路径基准）。
- 更新 CLAUDE.md 进度与本设计落地备注。

## 7. 新增工具规格（皆可复用六科）

| 脚本 | 输入 | 输出 | 复用现有 |
|---|---|---|---|
| `audit_entries.py` | 学科段词条 | 有效性记分卡 + 不合规清单 | `_utils` / `read_frontmatter` |
| `coverage_matrix.py` | 学习路径 docs | 覆盖矩阵 + 缺口清单 | `fix_wikilinks.collect_targets` |
| `gen_ladder_links.py` | strand_map YAML | 注入前置/延伸链 + 双向回填 | `fix_wikilinks` 规范化 |

均放 `00-元/scripts/`，配 `tests/`，遵现有 `setup_utf8()`/`REPO_ROOT` 约定，CLI 带 `--dry`/`--apply`。

## 8. 多模型路由

- 抽检、有效性梳理、字符级判断：Opus / Sonnet
- 批量补条：DeepSeek v4-pro + 50% 自检
- 古文/敏感：本试点（数学）不涉

## 9. 验收标准

1. 抽检 3 册路径忠实度结论明确（基准可信 或 修正规则已记）。
2. 81 词条有效性记分卡全绿（自动可修项已 apply；需人工项清单留存）。
3. 覆盖矩阵显示小学数学段对学习路径基准 100% 覆盖（缺口已补）。
4. `analyze_links`：本段断链、无入链显著下降；纵向「前置/延伸」链双向连通。
5. 三个新脚本单测通过，纳入 `pytest 00-元/scripts/tests/` 基线。

## 10. 风险与开放点

- **基准非穷尽**：学习路径是策展清单，抽检若发现其漏教材细节，需决定是「回补路径再扩容」还是「接受策展范围」。Phase 0 结论驱动。
- **🧒 清理副作用**：删段需精确匹配 `## 🧒 给 3-6 岁（共读版）` 到下一 `##` 前，避免误删。先 `--dry` 全量预览。
- **strand 归属歧义**：少数词条跨 strand（如「方位」属几何也涉数感），map 里允许多归属，链按主 strand。
- **绘本/话术去留**：本稿暂留，若后续判定低龄味过重再议。

## 11. 不做（YAGNI）

- 不建教材 PDF 目录抽取管线（Phase 0 仅人工抽检）。
- 不动真题分支 / 权重 / 学生 HTML。
- 不重构组织轴、不建 0 词条学科、不碰学前。
- 不在本稿定六科推广顺序。
