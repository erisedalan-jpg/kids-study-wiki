# 学科整理 SOP（可复用：数学 → 物化生等全科）

- 日期：2026-05-23
- 来源：数学全学段整理（小学→高中）沉淀；工具均已通用（接 `--dir`/`--grade`/`--paths`）
- 目的：把「教材梳理 → 去重 → 纵向贯通 → 纵向覆盖 → 元数据 → 总览 → 体检」整套流程标准化，可逐科逐段套用

## 0. 总原则

1. **先测后定**：每阶段先跑诊断出真实数字，再决定动作。数学多次"一测就发现缺口/不合规多是伪命题"（别名不匹配、格式误报、考点固有特征），盲目批改会做错工。
2. **区分词条类型**：教材概念词条 vs 真题派生考点词条。后者（`考点精讲`/`高考真题命中`/`高频易错点` 标记）豁免「教材必引」「裸链规范化」红线——它们是考点非教材节，行文引用细碎概念属知识前沿，非缺陷。
3. **不盲目膨胀**：考点行文里的前沿/变体引用（多为一次性、或现有概念的啰嗦变体）**不新建词条**。新建只针对"被反复引用且确无对应"的真缺口。
4. **破坏性操作先 dry-run + 全库影响评估 + git 可回滚**：删词条/改名/全库链接重定向前必看影响面（含真题/索引/学习路径的外部引用）。

## 1. 阶段流水线（逐科逐段）

### Phase 0 抽检对照教材（可选，新科首次）
- 抽 3 册，用 `fitz` 抽教材 PDF 目录文本，比对学习路径「单元构成」是否忠实。
- 数学结论：路径高度忠实 → 以学习路径为完整性基准，不建 PDF 全量抽取管线。物化生可沿用此假设，抽检 1-2 册确认即可。

### Phase 1 有效性梳理
```bash
python 00-元/scripts/audit_entries.py --dir <科> --grade <小学|初中|高中>
```
- 产出记分卡。**先看不合规类型分布**，再分批修：
  - 自动可修：`fix_wikilinks.py --apply` / `fix_latex_delim.py --apply` / `fix_stale_links.py --apply`
  - 教材引用缺失：教材概念词条按学习路径单元映射补（查 `00-元/教材索引.md`）；考点词条豁免（audit 已自动）
  - 🧒 层（仅小学有）：`strip_kid_layer.py --dir <科> --grade 小学 --apply`
- ⚠️ **审计误报教训（数学踩过 4 个，audit 已修，物化生应已免疫）**：
  - `- 教材：`（无粗体）/ `- 本地教材：`（前缀）/ `## 📑 出处`（精简标题）均合法
  - `准备课《X》`/`第三册`/书名号《》 算有效章节
  - 块式 `aliases:\n  - x` 与带引号 `["x"]` 的 bare-name 首位合法
  - 正则 `\s*$` 会贪婪吃换行 → 用 `[ \t]*`

### Phase 2 覆盖矩阵（教材完整性）
```bash
python 00-元/scripts/coverage_matrix.py --paths 00-元/学习路径/<学段>/<科> --dir <科>
```
- 缺口**多为别名不匹配伪缺口**（路径术语 ≠ 词条规范名）。人工校：
  - 伪缺口 → 给现有词条补 alias（仿 `working/backfill_*_aliases.py`，按"目标名特征子串"唯一匹配 + 加 alias），再 `fix_wikilinks.py --apply`
  - 真缺口（确无对应）→ 少量新建（末尾追加编号 + 学段标注，零 renumber）

### Phase 3 去重合并
诊断近重复（归一去「的/图象图像/空格/连字符」后同名）：
```bash
python docs/superpowers/working/dedup_plan.py    # 改 dir 后跑；出 dedup_plan.md + dedup_map.json
```
- 规范件 = 入链最多者。**三批策略**（按 dup 与规范件字数差）：
  - 非富内容（规范≥dup）+ 措辞冗余（差<250）：快合并（保规范件内容）
  - 互补内容（差≥250）：`merge_dups.py --append-body`，重复件正文并入规范件「🔁 合并补充」段，不丢内容
- 引擎 `merge_dups.py`：alias 并入 + 学段取并 + **全库链接重定向（含真题/索引/学习路径）** + 删除。务必 dry-run 看影响面。

### Phase 4 纵向链贯通
- 跨学段主干：手写 `strand_map_<科>.yaml`（声明 `延伸`，前置自动回填）。锚点 stem 用 `ls <科>/ | grep` 精确定位。
- 学段内递进：`gen_strand_from_paths.py`（改 dir/路径）从学习路径概念顺序自动派生链，并入 strand_map。
- 注入：`gen_ladder_links.py --map strand_map_<科>.yaml --dir <科> --apply`（合并模式，保留既有相关词条 + 幂等）。

### Phase 5 纵向总览视图
```bash
python docs/superpowers/working/gen_strand_overview.py --write   # 改 dir/输出名
```
- 出 `索引/<科>纵向总览.md`：按域 Mermaid `graph LR` + 可点击节点（Obsidian 阅读模式）。

### Phase 6 元数据卫生
```bash
python docs/superpowers/working/fix_metadata.py --apply   # 改 dir
```
- 主题按域关键词推断填（抽样校准确率）；alias 首位 bare 重排；状态缺省。
- 英文术语缺失 → v4-pro 批量：`gen_english_terms.py --apply`（翻译=生成任务，走 DeepSeek v4-pro）。

### Phase 7 体检验收
- 重跑 `audit_entries.py`（各段合规率）+ `coverage_matrix.py`（缺口）+ `analyze_links.py`（断链/无入链）+ `stats.py --write`。
- **判定**：考点豁免后，剩余应主要是 英文术语 + 极少真缺陷。若仍大量"裸链/教材"不合规，先确认是否考点固有特征（频次分布：大量一次性引用 = 前沿，非缺陷）。

## 2. 各科注意点

- **物化生**：仅 **初中 + 高中**（无学前/小学，**不需 strip_kid_layer**）。初中两层（📚6-12 + 🎓12+），高中单层（🎓 考点精讲）。`audit` grade-aware 已适配。
- **教材路径**（`00-元/教材索引.md`）：物理/化学/生物 初中`人教版-人民教育出版社/{七八九}年级/`、高中人教版各册；化学初中仅九年级。
- **考点占比高**：物化生高中同样真题派生考点多，`is_kaodian` 豁免同样适用（实测高中不合规已仅 77-103，非数学修前的 852）。
- **去重/纵向**：物化生尚未做（strand 覆盖近 0，dedup 未扫）——是推广主要工作量。

## 5. 推广建议顺序

1. 每科先跑 **Phase 1 体检 + Phase 3 去重诊断 + Phase 2 覆盖**（只读，出数字）→ 评估工作量
2. 按"低风险高收益"序：元数据(Phase6) → 去重(Phase3) → 纵向(Phase4-5) → 教材引用补(Phase1 尾)
3. 英文术语统一最后走 v4-pro 批量（跨科一次性）
4. 每科一段一提交，保持可回滚；改名/删除类先 dry-run
