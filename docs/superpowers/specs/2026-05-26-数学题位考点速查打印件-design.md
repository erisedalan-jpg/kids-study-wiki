# 吉林数学高考题位考点速查打印件 — 设计

> 日期：2026-05-26 ｜ 状态：已确认，待实现
> 背景：为数学 / 吉林 / 高考冲刺，按**高考题位**（选择第1题、第2题…填空、解答各题）逐题位统计高频考点并整合，输出**便于打印、线下携带**的速查件（打印优化单 HTML → 浏览器 Ctrl+P 存 PDF）。

## 目标

把 `真题/吉林-数学/*.md`（741 题，frontmatter 带 题型/题号/考点/年份/卷别/文理/难度）按**三段卷型 × 逐题位**聚合考点频次，整合并归一后，为每个题位的高频考点配「核心公式 / 方法 / 易错点」，生成一个 A4 打印优化的单 HTML。

非目标：不改真题源 md；不做在线交互/答题；不覆盖英语或其他学科；不做自动 PDF 渲染（用浏览器打印）。

## 卷型三段模型（实测确定）

吉林数学卷型换过代，题位含义随结构变，故分三段、各按自身结构统计：

| 段 | 年份 | 卷型 | 结构（题型:题号范围） | 文理 |
|---|---|---|---|---|
| **旧结构** | 2008–2022 | 全国/新课标/全国乙 | 选择 1–12（每5分）· 填空 13–16 · 解答 17–22/23 | 文理分卷 → **按理科统计**（与吉林理科冲刺一致；文卷略） |
| **过渡** | 2023 | 新课标Ⅱ | 选择 1–12（8单选+4多选）· 填空 13–16 · 解答 17–22 | 不分文理 |
| **最新** | 2024+ | 新课标Ⅱ（新结构）| 选择 1–11（8单选+3多选）· 填空 12–14 · 解答 15–19 | 不分文理 |

- **题位 key** = (段, 题型, 题号)。单选/多选由题号落区间派生（如最新段选择 1–8 单选、9–11 多选），无需额外字段。
- 「最新」段是当前高考（2025/26）对应结构；后续年份（2025…）入库后归入此段，结构假定稳定。样本现仅 2024 一套——**薄样本如实标注**（标「样本=1，规律参考」），随真题累积自动变厚。
- 旧结构样本充足（理科每题位 40+ 题），题位规律统计有效（实测：选择2≈复数运算、选择11≈离心率/双曲线、选择12≈抽象函数/数形结合）。

## 架构（4 组件 + 数据流）

```
真题/吉林-数学/*.md ──(题型+题号+考点+年份+文理)──► [1] 题位聚合（自动）
                                                      │
[2] normalize_考点_数学.yaml（原始名→规范名）──────────┤ 归一、合并同义、去重、排频
                                                      │
[3] lexicon_blueprint_数学.yaml（规范考点→公式/方法/易错/词条）┤ 高频考点挂内容
                                                      ▼
                              [4] gen_exam_blueprint.py ──► docs/student/数学题位速查.html
                                   三段 × 逐题位 × 整合考点          （A4 打印 CSS，Ctrl+P→PDF）
```

### [1] 题位聚合（gen_exam_blueprint.py 内，纯函数）
- 复用 `_utils.read_frontmatter` / 现有 `_exam_utils` 解析 frontmatter。
- 按上表把每题归入 (段, 题型, 题号)；旧结构只取 `文理=理`。
- 每题位收集其全部题的 `考点[]`，经 [2] 归一后用 `Counter` 排频。
- 输出中间结构：`{段: {(题型,题号): {样本数, 难度倾向, 考点频次:[(规范名,次数)...]}}}`。
- **难度倾向** = 该题位 `难度` 字段的众数（易/中/难，并列取偏难者）。

### [2] 考点归一表 `00-元/scripts/normalize_考点_数学.yaml`
- 形如 `复数的运算: 复数运算` / `复数运算: 复数运算` / `复数的几何意义: 复数的几何意义`。
- 构建方式：脚本带 `--dump-考点` 模式，扫全部真题输出「去重原始考点 + 出现次数」清单 → 人工/Opus 归并填表。
- 未在表中的考点：规范名 = 自身（pass-through），不丢数据。

### [3] 考点速查库 `00-元/scripts/lexicon_blueprint_数学.yaml`（人工策展，Opus 亲写）
- 键 = 规范考点名；值：
  ```yaml
  复数运算:
    公式: ["$z=a+bi$，$\\bar z=a-bi$", "$|z|=\\sqrt{a^2+b^2}$", "$\\frac{1}{i}=-i$"]
    方法: ["分母实数化：分子分母同乘共轭", "几何意义：复数↔向量/点"]
    易错: ["$i^2=-1$ 漏负号", "共轭只变虚部符号"]
    词条: "061-方程"   # 可选，链回加权词条 stem（HTML 里加锚链）
  ```
- 红线遵循：公式一律 Obsidian/KaTeX 定界符 `$...$` / `$$...$$`（不用 `\(\)`）；数学内容 Opus 亲写、不交 v4-pro。
- 覆盖优先级：先写各题位**高频考点**（频次靠前、覆盖该题位即可），低频长尾不强求。库可增量长大。

### [4] 生成器 `00-元/scripts/gen_exam_blueprint.py`
- CLI：`--apply`（写盘）/ `--dump-考点`（导归一表种子）/ 默认 dry-run 打印各段题位统计。
- 输出 `docs/student/数学题位速查.html`（depth 0，复用 `vendor/katex/` 渲染公式、`vendor/style.css` 基础样式；打印 CSS 内联在 `<head>`）。riding 进现有 `pack_student_zip.py` 包。
- 页面结构：
  - 顶部：标题 + 卷型三段说明 + 「样本薄」提示图例。
  - 三段各一区块，`@media print` 段间 `page-break-before`。
  - 段内按题位顺序（选择1…N、填空、解答）；每题位卡片：
    - 标题：`选择2 · 样本N · 难度倾向(易/中/难)` + 单选/多选标记。
    - **整合考点频次条**：`复数运算 ×12 ｜ 共轭复数 ×7 ｜ …`（按频次降序）。
    - 「高频展开」判定：不设硬频次阈值——**速查库覆盖到的考点即展开**公式/方法/易错块，库未覆盖的仅列名+频次（库的覆盖范围即隐式高频门槛，由 P2/P3 决定写哪些）。
    - 考点若有 `词条` 字段 → 锚链到 `atoms/{stem}.html`（HTML 可点；打印显词条号）。
- 打印优化：A4、可读字号、避免卡片跨页断裂（`break-inside: avoid`）、黑白友好（频次/难度用底纹非纯色）。

## 分期实施

- **P1 — 跑通管线，出骨架打印件**：组件[1][2][4]（[2] 先脚本 dump 种子 + 人工粗归并）+ 生成器输出**只含考点频次**的三段题位 HTML，可 Ctrl+P 成 PDF。验收：HTML 渲染、三段齐、所有题位有频次、打印分页正常。
- **P2 — 选择题速查库**：组件[3] 写选择题各题位高频考点的 公式/方法/易错；生成器合并展开块。验收：选择题题位高频考点均有内容块、公式 KaTeX 正常渲染。
- **P3 — 扩展**：库扩到填空/解答题位；后续年份（2025+）入「最新」段；归一表补长尾。

## 测试

- **unittest**（`00-元/scripts/tests/test_gen_exam_blueprint.py`）：用 fixture frontmatter 验
  - 三段分段正确（年份→段映射边界：2022→旧、2023→过渡、2024→最新）；
  - 旧结构只计理科；
  - 题位分组 (题型,题号) 正确；
  - 归一表应用（同义合并后频次相加）；
  - 频次降序。
- 生成器输出结构断言：三段标题存在、题位卡片含频次、库考点含公式块、`break-inside:avoid` 等打印 CSS 注入。
- **打印验收**（人工）：浏览器打开 → Ctrl+P 预览 A4 → 分页/卡片不断裂/公式渲染正常。

## 风险

- **最新段样本薄（2024 仅 1 套）**：题位规律偶然性大 → 页面如实标「样本=N」，规律以旧结构为主、最新段作结构对齐参照；随真题累积变实。
- **考点名长尾噪声**：归一表覆盖不全则频次散 → pass-through 不丢数据；高频项优先归并即可，长尾不影响题位主规律。
- **速查库写作量**：选择题约 11 题位 × 数个高频考点，P2 量可控；填空/解答留 P3。错一个公式坑娃 → Opus 亲写 + KaTeX 定界符红线 + 打印验收时人眼校公式。
- **卷型再换代**：若未来高考结构再变，加新段即可（三段模型可扩 N 段）。
