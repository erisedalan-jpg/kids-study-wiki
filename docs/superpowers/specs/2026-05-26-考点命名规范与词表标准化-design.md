# 考点命名规范与词表标准化（保守）— 设计

> 日期：2026-05-26 ｜ 状态：已确认，待实现
> 背景：真题 `考点` frontmatter 词表脏（922 个不同 tag，大量纯写法变体：交集/交集及其运算/集合的交集运算、三角函数的图象与性质/…图像与性质、复数的运算/复数运算…）。这是全真题管线的中枢词表（→反链→weight→吉林冲刺索引/HTML/题位脑图），需从源头规范，而非仅显示层补救。

## 目标

1. 立**考点命名规范**（规则 + canonical 清单），防词表再脏。
2. 源头**只归并纯写法变体**（保留有意义粒度），改写 741 真题 `考点` 字段。
3. 温和重算下游（反链/weight/索引/HTML/脑图），验证 weight 漂移极小且合理。

非目标：**不做语义级合并**（复数乘法/除法保留）；不改 `考点` 之外的 frontmatter；不重构真题管线脚本逻辑；不在本期完成题位脑图的父主题分组（X 完成后另接）。

## 血缘（为何保守 + 必须重算）

```
真题 考点[] ──exam_index──► 反链回填 学科/<考点>词条（按 alias 匹配概念词条）
                              ├──► compute_weight：反链得分 → weight（吉林反链×5…）
                              ├──► 高频考点索引 + 题型×考点交叉表
                              └──► gen_html 学生站考点显示 + 高频榜；gen_exam_blueprint 题位脑图
```

- 改考点名 → 改 alias 匹配 → 改反链 → 改 weight。**只并变体**时，变体多半本就匹配同一概念（或都不匹配），故 weight 漂移应接近 0；少数漂移来自「变体合并后匹配上了概念词条」——这属**修正**而非破坏，但须人工确认。

## 命名规范（6 条，写入 `00-元/考点命名规则.md`）

1. **去冗余「的」连接词**：`函数的奇偶性→函数奇偶性`、`导数的几何意义→导数几何意义`、`椭圆的标准方程→椭圆标准方程`。（去掉不改义的结构助词「的」。）
2. **操作词归一**：表"对某对象做运算/求解"的尾缀统一为「运算」；`交集`/`交集及其运算`/`集合交集`/`集合的交集`/`集合的交集运算`→`交集运算`；`并集`/`并集运算`→`并集运算`；`集合的运算`→`集合运算`。
3. **「图象」统一**（课标用字，不用「图像」）：`三角函数的图像与性质`/`三角函数图象与性质`/`三角函数的图象与性质`→`三角函数图象与性质`。
4. **去题型/赘尾**：`问题`/`判断`/`与应用`/`及应用`/`的解法`等不改义尾缀去除；`命题的真假判断`/`命题的真假判断与应用`→`命题真假判断`；`绝对值不等式的解法`→`绝对值不等式`。
5. **不并语义不同项**（保留真粒度）：`复数乘法`≠`复数除法`≠`复数运算`；`正弦定理`≠`余弦定理`；`线面平行`≠`线面垂直`——均**保留**，不得合并。
6. **受控词表**：维护 canonical 考点清单；新真题录入考点须从清单选；确需新词走评审加入清单（沿用项目"红线"风格，记入命名规则文档）。

> 判定"纯变体"的硬标准：两 tag 去掉「的/及其/运算/计算/问题/判断/应用/解法」等结构性词与图象/图像异写后**字面同义**，即为变体可并；否则保留。映射表逐条须人工确认满足此标准。

## 架构（4 组件）

```
[规范] 00-元/考点命名规则.md（6 条规则 + canonical 清单 + 维护流程）
[映射] 00-元/scripts/canonical_考点_数学.yaml（变体原名 → canonical 规范名；仅纯变体）
[迁移] 00-元/scripts/normalize_kaodian_source.py
         读 canonical 映射 → 改写 真题/吉林-数学/*.md frontmatter 考点[]（备份/dry-run/diff/--apply）
[重算] 按序跑：exam_index（反链+索引）→ compute_weight（weight）→ gen_html → gen_exam_blueprint
         对比 weight 漂移、考点碎片数下降
```

### [映射] `canonical_考点_数学.yaml`
- `原变体名: 规范名`，仅收纯写法变体（满足上方硬标准）。规范名本身也列（指向自己）以明确 canonical。
- 构建：`gen_exam_blueprint.py --dump-考点`（按名排序已有）→ 人工/Opus 按 6 条规则聚类填表 → 逐条确认同义。
- 不在表中的考点：保持原样（pass-through），不动。

### [迁移] `normalize_kaodian_source.py`
- 复用 `_utils.read_frontmatter` 仅定位/解析，但**改写须精确替换 frontmatter 内 `考点:` 行**（保留其余字段与正文不动）。
- CLI：默认 dry-run 输出**将改动的文件 + 考点前后 diff**；`--apply` 写盘。
- 安全：仅当 git 工作树干净时允许 `--apply`（基线可回退）；只改 `考点` 字段；逐文件 in-place，保留 frontmatter 其余行原样（含数组写法 `[a, b]`）。
- 幂等：已是规范名的不再改；重复跑无副作用。
- 范围：本期仅 `真题/吉林-数学/`（其余省/科同法后续，规则通用）。

### [重算] 下游链（迁移后按序执行 + 验证）
1. `exam_index`（吉林-数学）：重建反链/高频考点/交叉表；检查并清理因改名产生的孤儿 `学科/<旧考点名>.md` 反链文件（若有）。
2. `compute_weight --apply`：重算 weight；**对比迁移前后 weight 漂移**（导出前后 weight 表 diff，漂移应集中在极少数变体修正项、幅度小）。
3. `gen_html --apply` / `gen_exam_blueprint --apply`：刷新 HTML 与脑图。

## 安全与回退

- 迁移前确认 `git status` 干净（本次设计/计划文档可先提交）；迁移 + 重算各自独立提交，便于按步回退。
- `normalize_kaodian_source.py --apply` 前必跑 dry-run，人工过 diff。
- weight 漂移若超出预期（如大批词条 weight 跳变），停止并排查映射表是否误并了语义不同项。

## 验证标准

- `--dump-考点` 不同考点数显著下降（922 → 预期数百内），集合/三角图象/复数运算等簇收敛为单一规范名。
- 迁移仅改 `考点` 行：随机抽查若干真题，frontmatter 其余字段与正文 byte 级不变。
- weight 漂移：迁移前后 weight 表 diff，变动词条数少、幅度小，且每处变动可解释（变体合并后匹配/不匹配概念词条）。
- 单测回归全过；exam_index/compute_weight 无报错。
- 命名规则文档含可执行的"如何加新考点"流程。

## 与题位脑图的衔接

X 完成后，`gen_exam_blueprint` 的 `考点` 已是干净规范名，子项不再碎、同义不再跨父组重复。届时回到脑图，完成/简化「考点→父主题」分组（group_考点_数学.yaml 改作用在 canonical 词表上，条目大减），即得高质量树。

## 风险

- **误并语义项** → weight/反链错乱：映射表逐条人工确认满足"纯变体硬标准"；保守优先，拿不准的不并。
- **孤儿反链文件**：改名后旧 `学科/<考点>.md` 反链段可能残留；重算步骤含清理检查。
- **frontmatter 改写破坏格式**：迁移脚本精确替换 `考点:` 单行、保留数组写法与其余行；dry-run diff 把关；wikilinks/LaTeX 红线不涉（只动 frontmatter 标签）。
- **范围蔓延**：本期限吉林-数学；其余省科沿用同规则、同脚本，后续单独跑。
