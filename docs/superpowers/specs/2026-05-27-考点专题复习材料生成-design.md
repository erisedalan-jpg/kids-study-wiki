# 考点专题复习材料生成 · 设计

> 基于已标准化的树状考点 tag（父主题→考点），为每个考点聚合其全部真题并整合知识，产出**考生复习用**的考点专题材料。数学先行，逐步扩散到物/化/生四科。

## 目标

把现有「树状 tag + 真题 + 概念词条 + 权重」沉淀为**以考点为纲的深度复习单元**：每个考点一页，含定位、知识精要、解题方法、高频易错、代表题精讲、全部真题清单、关联。考生按考点（沿父主题树）系统复习。

## 非目标

- 不改学习词条（`学科/`）的三层共读结构；复习材料独立成树。
- 不做英语（长训非考点学习，排除，与冲刺索引口径一致）。
- 不替换现有真题 md 的「摘要/关联考点/解析图」；本设计在其上叠加文本语料与考点专题层。

## 既有事实（约束与可复用资产）

- 真题 md（`真题/{省}-{科}/`）frontmatter 已含归一后 canonical `考点` 字段、`难度`、`题型`、`题号`、`年份`、`PDF`、`PDF页码`；正文已有 `## 摘要`（一行）、`## 关联考点`（wikilinks）、`## 答案与解析`（解析图）。
- 解析卷 PDF（`素材/真题/...`，169 份）**含可抽取文本层**（已验证）；真题 frontmatter `PDF` + `PDF页码` 指向之。
- 树状分组 `group_考点_<科>.yaml`（数学15/物理17/化学15/生物6 父主题，覆盖 ~100%）。
- canonical 词表 `canonical_考点_<科>.yaml`；真题考点已全归一、残留近义簇为 0。
- 概念词条反链（`exam_index` 的「高考真题命中」段，alias-aware）；权重 `compute_weight`；题位脑图 `gen_exam_blueprint`（吉林，题型×题号→父主题→考点 树）。
- 多模型路由（`docs/superpowers/plans/2026-05-12-multi-model-workflow-v3.md`）：批量生成走 DeepSeek v4-pro + 50% 自检；公式/敏感/字符级审查走 Opus。

## 架构：三层流水线

```
① 真题文本语料层（基础设施、可复用）
   真题 md(考点tags + PDF/PDF页码) + 解析卷PDF
     ──[extract_exam_text.py]──> 真题 md 新增「## 题干文本」「## 解析文本」

② 考点专题生成层
   group_考点_<科>.yaml(树) + 真题文本语料 + 概念词条
     ──[gen_kaodian_review.py]──> 复习/<科>/<考点>.md
     ──[validate_review.py 体检门]──> 通过才进后处理

③ 消费层
   复习/*.md ──[gen_html.py 扩展]──> docs/student/ 复习页（链 blueprint/词条/真题）
```

**为何「真题文本语料」独立成层**：它是可复用基础设施（站内搜索、错题本、未来特性均受益），且让②退化为**纯文本批量生成** → 可路由 DeepSeek v4-pro 跑全考点×四科，成本可控。

## 数据单元：`复习/<科>/<考点>.md`

### frontmatter
```yaml
title: <考点>          # canonical 考点名
考点: <考点>
父主题: <父主题>        # 取自 group_考点_<科>.yaml
学科: <科>
weight: <int>          # 取自概念词条 weight（如有对应词条），否则真题频次
真题数: <int>
高频题位: [选择5, 解答18, ...]   # 取自真题 (题型,题号)
状态: 草稿 | 已校对
```

### 正文区块（区块来源标注：现有数据=零 LLM，LLM=需生成）
1. **## 考点定位**（现有数据）— 父主题路径、weight·真题频次、出现题位（脑图树）、难度分布、年份跨度。
2. **## 知识精要**（LLM）— 考纲级核心：定义/公式/定理/适用条件，从该考点全部真题解析 + 概念词条整合。
3. **## 解题方法与套路**（LLM）— 跨该考点真题归纳的通法步骤。
4. **## 高频易错**（LLM）— 该考点真题中的典型陷阱/失分点。
5. **## 代表题精讲**（LLM）— 选 2–3 道**近年优先**，逐题：题干文本 + 思路 + 步骤 + 点评/变式。
6. **## 全部真题清单**（现有数据）— 该考点所有真题：`[[真题|显示]]` + 年份 + 难度 + 摘要。
7. **## 关联**（现有数据 + LLM 轻判）— 概念词条 `[[链接]]`、同父主题邻近考点、易混考点。

## 关键映射（均为可确定计算）

| 映射 | 来源 |
|---|---|
| 考点 → 真题 | 真题 frontmatter `考点`（已全归一 canonical）直接反查 |
| 考点 → 父主题 | `group_考点_<科>.yaml` |
| 考点 → 题位 | 真题 `(题型, 题号)` |
| 考点 → 概念词条 | `fix_wikilinks.collect_targets()` alias 查找（考点名常为词条 alias） |
| 专题覆盖集 | group 表中**有 ≥1 真题命中**的全部 canonical 考点（无真题的考点跳过） |
| 代表题选取 | 该考点真题按 `年份` 降序，取前 2–3（同年取难度高者/解析全者） |

## 新增工具（沿用现有工具箱风格：增量/幂等/dry-run/`--province --subject` 参数化/体检门）

### `extract_exam_text.py`
- 输入：`--province --subject`（默认 吉林/数学）。
- 对每道真题：按 `PDF` + `PDF页码` 打开解析卷 PDF，抽该页文本，用**题号正则 + 题面图锚点**切出本题题干与解析段。
- 输出：写真题 md 新增 `## 题干文本` / `## 解析文本`（幂等：已存在则跳过或 `--force` 覆盖）。
- 切分失败回退：整页文本入 `## 解析文本` 并打 `录入状态: 文本待人工切分` 标记。
- dry-run 打印抽取统计 + 失败清单。

### `gen_kaodian_review.py`
- 输入：`--province --subject`，可选 `--考点 <名>` 单点、`--limit N`。
- 对覆盖集每个考点：聚合（真题文本语料 + 难度/年份/题位 + 概念词条摘要）→ 组 prompt → 批量交 DeepSeek v4-pro（含 50% 自检）→ 写 `复习/<科>/<考点>.md`。
- 增量幂等：已存在且 `状态: 已校对` 跳过；`草稿` 可 `--regen` 重生。
- 生成后自动 hook `fix_wikilinks --apply`（wikilinks 规范化红线）。

### `validate_review.py`（⭐体检门，仿 `validate_gen.py`）
- 拦：缺区块/缺 frontmatter 字段、代码围栏残留、提示模板吐出、**公式非 Obsidian 定界符**（`\(\)\[\]` 字面）、wikilinks 未规范化、代表题数 0。
- 不过不准进后处理（renumber 类无关，复习 md 不加序号前缀，是独立树）。

### `gen_html.py` 扩展
- 识别 `复习/` 树，渲染考点专题页；从题位脑图、概念词条、真题页交叉链接到对应复习页。

## 生成路由与红线

- 批量文本生成 → DeepSeek v4-pro + 50% 自检（小批量亦可）。
- **公式必须 Obsidian 定界符** `$...$` / `$$...$$`（CLAUDE.md 红线；DeepSeek 惯吐 LaTeX `\(\)\[\]`）；生成后 `fix_latex_delim.py --apply`（按 manifest 限范围）。
- **wikilinks 规范化**：生成 hook + 手编后 `fix_wikilinks.py --apply`。
- 数学/物理公式密集考点：体检门拦脏公式；必要时升级 Opus 重写该考点，或对代表题用视觉读 `*.a.png` 校正（C 方案，留计划阶段决定阈值）。

## 分期（已确认）

- **P0 — 真题文本语料（数学）**：实现 `extract_exam_text.py`，跑吉林+北京+湖南数学全部真题，产出 `## 题干文本`/`## 解析文本`。**先验证数学公式 PDF 抽取质量**（最大技术风险点）；统计切分成功率，调正则/锚点。
- **P1 — 数学考点专题闭环**：实现 `gen_kaodian_review.py` + `validate_review.py`，生成数学全考点专题 `复习/数学/`；扩 `gen_html.py`；抽样校对 + 公式/链接修复。跑通端到端试点。
- **P2 — 扩科**：物理 → 化学 → 生物，各跑 P0 文本语料 + P1 专题生成（工具已参数化，复用）。物化生公式（物理尤甚）抽取质量单独验证。

## 主要风险与缓解

| 风险 | 缓解 |
|---|---|
| PDF 公式抽取脏（数学/物理最甚） | 清洗 + `fix_latex_delim` 定界符修复 + 体检门拦 + 必要时 Opus/视觉校正 |
| PDF 多题分页切分不准 | 题号正则 + 题面图锚点定位；失败回退整页 + `文本待人工切分` 标记 |
| 生成体量大（全考点×四科） | 增量幂等 + 分期 + DeepSeek 批量；按 weight 降序先跑高频考点便于早校对 |
| 考点 ≠ 概念词条 1:1 | 复习 md 独立成树；缺口考点也建专题，`## 关联` 段链已有词条/邻近考点 |
| 真题文本语料污染原 md | 仅追加新区块，不动既有 frontmatter/摘要/关联考点/解析图；dry-run 过 diff |

- **占位扫描**：无 TBD；各工具职责/输入输出/幂等策略明确；区块来源（现有数据 vs LLM）逐条标注。
- **一致性**：三层流水线与工具一一对应；`--province --subject` 参数化、体检门、增量幂等、公式/wikilinks 红线与现有真题管线口径一致；分期 P0→P1→P2 与「数学先行→四科」一致。
- **歧义**：「全考点」明确为 group 表中有 ≥1 真题命中的 canonical 考点；「代表题近年优先」明确为按年份降序取 2–3。
- **范围**：聚焦考点专题复习材料一条主线；不含错题本/搜索等下游（仅指出语料可复用）。
