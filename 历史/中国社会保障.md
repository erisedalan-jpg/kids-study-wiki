# 中国社会保障

> **一句话**：中国社会保障是自古以来国家通过赋税、仓储、慈善等手段，为百姓提供基本生活保障的制度。
> **English**: China’s social security is a historical system through which the state has provided basic living guarantees to the people by means of taxation, granaries, and charity.

## 🎓 给 12+（进阶版）

中国社会保障的历史脉络，贯穿于国家赋税征收与基层治理的互动之中。从先秦的“荒政”思想、汉代的“常平仓”，到隋唐义仓、宋代的居养院与安济坊，再到明清的养济院与保甲赈恤，历朝历代都在探索如何在灾荒、贫困和养老中维持社会稳定。这些举措与赋税制度紧密相连——国家通过田赋、丁税等收入建立仓储，再由县乡里甲等基层组织负责具体发放，体现了“取之于民、用之于民”的传统治理逻辑。相比西方近代福利制度，中国古代社会保障更强调家族互助与政府救济相结合，其资金来源、实施主体与基层行政体系深度绑定，是理解“大一统”国家治理的重要窗口。

## 🗣️ 家长讲解话术

- 孩子可能问 **“古代没有社保卡，他们怎么领救济？”** → 可以解释为：古代没有统一的社保卡，但官府会通过保甲制度核对户口，由里长、甲首根据名册发给米粮，就像现在社区发物资一样。
- **共读小活动**：用积木或纸条搭建一个简易的“义仓”模型，模拟灾年开仓放粮的过程，5分钟内可完成。
