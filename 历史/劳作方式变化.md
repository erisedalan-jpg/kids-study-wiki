# 劳作方式变化

> **一句话**：劳作方式的变化，就是人从用手和简单工具干活，慢慢变成用机器和电脑干活的过程。
> **English**: Changes in labor practices refer to how humans have shifted from working with simple tools to working with machines and computers over time.

## 🎓 给 12+（进阶版）

劳作方式变化是指人类在获取生活资料、进行社会生产过程中，所使用的劳动手段、组织形式及人机关系的结构性演变。核心是从依赖人力与手工工具，转向利用畜力、水力、蒸汽、电力，再到自动化与智能化系统。历史脉络大致为：采集狩猎 → 原始农业 → 传统农耕与手工工匠 → 工厂制的机器大生产 → 流水线与电气化 → 信息时代的弹性生产与平台劳动。每一次重大变化，都对应着生产工具（如[[生产工具]]）的革新和能源动力的跃迁，并深刻重塑社会分工、家庭结构与人对自然的控制力。理解这条线索，有助于串联[[工业革命]]、[[农耕文明]]与[[信息技术革命]]等词条的深层逻辑。

## 🗣️ 家长讲解话术

- 孩子可能问 **"为什么以前的人不用机器？"** → 可以从“电和发动机还没被发明出来”切入，说明每一代人都只能用手头最好的工具，机器不是一开始就有的。
- **共读小活动**：用家里的积木或文具，模拟“手工抄书”与“用印章盖章”的区别。让孩子分别体验一笔一画写十个字，与用橡皮章快速盖十个印，感受工具对劳作速度和身体劳累的影响，整个过程不超过5分钟。
