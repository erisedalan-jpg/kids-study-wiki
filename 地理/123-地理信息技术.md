# 地理信息技术

> **一句话**：用计算机眼睛和地图工具，帮我们看清城市、森林、天气的变化，比如找走丢的小狗或预测火山喷发。
> **English**: A set of tools that uses computers to capture, store, analyze, and display geographic data about the Earth.

---

## 🎓 给 12+（进阶版）

**地理信息技术**是对地理空间数据进行采集、管理、分析和表达的技术总称，核心技术包括**遥感（RS）**、**地理信息系统（GIS）**和**全球卫星导航系统（GNSS，如 GPS）**。在自然灾害监测中，遥感可以从高空或太空获取灾区的图像，帮助识别洪水淹没范围、森林火点或地震形变；GIS 将房屋、道路、人口等图层与灾区影像叠合，快速做出风险评估与救援路径规划；GNSS 则提供精准的定位信息，用于测绘滑坡位移、确定受灾点坐标。三者协同，构成“眼睛—大脑—神经系统”式的防灾减灾技术体系。

## 🌐 中英对照

### 词汇

| 中文 | English | 词性 | 例句 |
|------|---------|------|------|
| 遥感 | Remote Sensing (RS) | 名词 | 遥感图像可以显示森林火灾的燃烧范围。 |
| 地理信息系统 | Geographic Information System (GIS) | 名词 | GIS 能叠加河流与居民地图层，分析洪水风险。 |
| 全球卫星导航系统 | Global Navigation Satellite System (GNSS) | 名词 | GNSS 帮助救援队准确抵达倒塌建筑的位置。 |
| 灾害评估 | Disaster Assessment | 名词 | 灾后评估需要结合遥感与实地调查。 |

## 🗣️ 家长讲解话术

- 孩子可能问 **“卫星怎么看到我家被水淹了？”** → 可以解释卫星在高空拍照片，就像你用无人机拍照，只不过卫星飞得更高，还能分辨水体和陆地，水会反射不同颜色的光。
- **共读小活动**：用手机地图 App 打开卫星视图，找到自己家附近的公园或学校，放大看屋顶、操场和树木，然后想一想如果发生洪水，哪些地方会先被淹没，在地图上画圈标记。
