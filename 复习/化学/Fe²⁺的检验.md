## 知识精要
- **Fe²⁺的检验方法**
  1. **铁氰化钾法**：向待测液中滴加 $K_3[Fe(CN)_6]$（铁氰化钾）溶液，若产生**特征蓝色沉淀**（滕氏蓝），则含有 $Fe^{2+}$。  
     $$3Fe^{2+} + 2[Fe(CN)_6]^{3-} = Fe_3[Fe(CN)_6]_2 \downarrow$$
     *特点*：灵敏度高、选择性好，特定干扰较少，是中学阶段检验 $Fe^{2+}$ 的最优先推荐方法。
  2. **碱液法**：向待测液中加入 $NaOH$ 溶液，先生成**白色沉淀** $Fe(OH)_2$，迅速变为灰绿色，最后变为红褐色 $Fe(OH)_3$。  
     $$Fe^{2+} + 2OH^- = Fe(OH)_2 \downarrow$$
     $$4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3$$
     *缺点*：白色沉淀存在时间极短，观察困难，易受 $Fe^{3+}$ 等其他阳离子颜色干扰。
  3. **酸性高锰酸钾法**：向待测液中滴加酸性 $KMnO_4$ 溶液，若紫色褪去，说明存在还原性物质（如 $Fe^{2+}$）。  
     $$5Fe^{2+} + MnO_4^- + 8H^+ = 5Fe^{3+} + Mn^{2+} + 4H_2O$$
     *注意*：需确保溶液中无 $Cl^-$、$Br^-$、$I^-$、$SO_3^{2-}$ 等还原性干扰离子，否则会误判。
  4. **硫氰化钾—氯水法（间接法）**：先加 $KSCN$ 溶液，无现象；再加氯水（或 $H_2O_2$），溶液变为血红色，则原溶液含 $Fe^{2+}$。
- **适用条件与干扰**
  - 铁氰化钾法不易受 $Cl^-$、$Br^-$、$NO_3^-$ 等干扰，是检验 $Fe^{2+}$ 的最稳妥试剂。
  - 检验多种阳离子共存时，应优先使用特征反应，排除颜色类似离子的干扰（如 $Fe^{3+}$ 不会与 $K_3[Fe(CN)_6]$ 产生蓝色沉淀，但会使 $KSCN$ 变红）。

## 解题方法与套路
1. **明确检验目标**：判定溶液中的 $Fe^{2+}$，而非 $Fe^{3+}$ 或总铁。
2. **选项试剂适应性分析**：根据题干提供的试剂/方法，结合溶液中已知共存离子，判断是否满足检验条件。
   - 若存在 $Br^-$、$I^-$ 等还原性离子，不可使用酸性 $KMnO_4$ 等氧化性试剂直接检验 $Fe^{2+}$。
   - 若溶液酸性较强，$Fe^{2+}$ 不易被空气氧化，碱液法效果差，首选铁氰化钾。
3. **检验逻辑链**：
   - 取样 → 加检验试剂 → 特征现象 → 结论（有/无 $Fe^{2+}$）。
   - 特征现象表述要准确：铁氰化钾——“蓝色沉淀”（滕氏蓝）；碱液法——“白色沉淀迅速变灰绿，最后变红褐色”。
4. **审题避坑**：注意题干中“实验方法或试剂使用是否合理”，要兼顾反应原理、干扰条件、操作顺序，不能只看最终现象有无。

## 高频易错
- **混淆检验试剂**：$Fe^{2+}$ 用**铁氰化钾** $K_3[Fe(CN)_6]$，$Fe^{3+}$ 用**亚铁氰化钾** $K_4[Fe(CN)_6]$（生成普鲁士蓝），二者检验对象恰好相反，记反则全错。
- **忽略共存离子干扰**：在 $NaBr$、$KI$ 等溶液中检验 $Fe^{2+}$，若选用酸性 $KMnO_4$，$Br^-$、$I^-$ 同样能使其褪色，导致误判。
- **碱液法观察时机错误**：$Fe(OH)_2$ 白色沉淀极易被氧化，若操作过慢或振荡过多，直接看到灰绿色或红褐色，误以为不含 $Fe^{2+}$。
- **$Fe^{2+}$ 与 $Fe^{3+}$ 同时存在时的检验顺序**：应先检验 $Fe^{2+}$（如用铁氰化钾），再用 $KSCN$ 检验 $Fe^{3+}$；若先用氧化剂将 $Fe^{2+}$ 氧化再检验总铁，则无法区分原溶液是否含 $Fe^{2+}$。

## 代表题精讲
### **题目** （2024辽宁卷，8A）
检验 $NaBr$ 溶液中是否含有 $Fe^{2+}$，选用 $K_3[Fe(CN)_6]$ 溶液。判断该实验方法/试剂使用是否合理。

### **思路**
$NaBr$ 溶液中含 $Na^+$、$Br^-$，可能存在 $Fe^{2+}$。检验 $Fe^{2+}$ 的最佳特征试剂是铁氰化钾，$Br^-$ 不与 $K_3[Fe(CN)_6]$ 反应，无干扰。因此试剂选择合理。

### **步骤**
1. 用洁净胶头滴管取少量待测 $NaBr$ 溶液于试管中。
2. 向其中滴加 $2\sim3$ 滴 $K_3[Fe(CN)_6]$ 溶液，轻轻振荡。
3. 若产生**蓝色沉淀**，则证明原溶液中含有 $Fe^{2+}$；若无明显变化，则无 $Fe^{2+}$。
4. 结论：该方法原理正确，无共存离子干扰，操作可行，试剂使用合理。

### **点评/变式**
- **点评**：本题从实验评价角度考查 $Fe^{2+}$ 检验，核心是抓住“$Fe^{2+}$ + 铁氰化钾 → 滕氏蓝”的特征反应，并分析实际溶液环境。$Br^-$ 虽是还原性离子，但不与铁氰化钾反应，不干扰检验，这是易错点。
- **变式**：若将试剂改为酸性 $KMnO_4$ 溶液，则**不合理**，因为 $Br^-$ 也能被 $MnO_4^-$ 氧化为 $Br_2$，紫色褪去不能证明 $Fe^{2+}$ 存在。若将溶液换为 $FeCl_3$ 与 $FeCl_2$ 混合液，检验 $Fe^{2+}$ 仍可用 $K_3[Fe(CN)_6]$，$Fe^{3+}$ 不产生蓝色沉淀，互不干扰。
