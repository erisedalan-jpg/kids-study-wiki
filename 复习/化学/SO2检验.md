## 知识精要
- **SO₂的制备原理**
  - 实验室常用强酸制弱酸原理：亚硫酸钠（$Na_{2}SO_{3}$）与较浓的强酸（如70% $H_{2}SO_{4}$）反应。
  - 核心方程式：$Na_{2}SO_{3} + H_{2}SO_{4}(浓) = Na_{2}SO_{4} + SO_{2}↑ + H_{2}O$。
  - 发生装置为“固+液→气”型，仪器名称为蒸馏烧瓶（不能写圆底烧瓶，因其便于滴加液体）。

- **SO₂的四大核心性质**
  - **酸性氧化物通性**：能使湿润石蕊试纸变红，能与碱反应（尾气吸收）。
  - **强还原性**：能被多种氧化剂氧化。
    - 与酸性高锰酸钾反应：$5SO_{2} + 2MnO_{4}^{-} + 2H_{2}O = 2Mn^{2+} + 5SO_{4}^{2-} + 4H^{+}$（现象：紫红色褪去）。
    - 与卤素单质（$X_{2}$）反应：$SO_{2} + X_{2} + 2H_{2}O = H_{2}SO_{4} + 2HX$。
    - 与$Fe^{3+}$反应：$SO_{2} + 2Fe^{3+} + 2H_{2}O = 2Fe^{2+} + SO_{4}^{2-} + 4H^{+}$（现象：棕黄色变浅绿）。
  - **弱氧化性**：遇更强还原剂（如$H_{2}S$或$S^{2-}$）发生归中反应。
    - 反应：$SO_{2} + 2H_{2}S = 3S↓ + 2H_{2}O$（现象：产生淡黄色浑浊）。
  - **漂白性**
    - **作用对象**：品红溶液、鲜花（但不能漂白酸碱指示剂，如石蕊变红但不褪色）。
    - **特征**：与品红化合成无色不稳定物质，**加热恢复原色**。此特性用于区分$SO_{2}$与$Cl_{2}$漂白。

- **尾气处理**
  - 必须防止$SO_{2}$逸散污染空气。
  - 常用强碱溶液吸收，如$NaOH$溶液：$2NaOH + SO_{2} = Na_{2}SO_{3} + H_{2}O$。

## 解题方法与套路
1. **仪器定名与反应书写（送分题策略）**
   - 涉及滴加浓酸且有侧管的圆底烧瓶，一律写“蒸馏烧瓶”。
   - 酸式盐与强酸反应的配平，按复分解规律，强酸制弱酸或高沸点酸制低沸点酸，注意气体符号。

2. **现象描述与性质判定的捆绑解证法**
   - **看见高锰酸钾褪色→锁定还原性**：直接默写生疏方程式，注意酸性条件下$MnO_{4}^{-}$还原产物为无色$Mn^{2+}$。
   - **看见淡黄色沉淀（硫单质）→锁定氧化性**：同时展现+4价硫能得电子生成0价硫。

3. **可逆性探究的答题模板**
   - 操作：利用分液漏斗活塞控制停止通$SO_{2}$，对褪色后的品红溶液直接加热。
   - 现象：溶液由无色恢复为红色。 
   - 关键词：闭合活塞、停止通气、酒精灯加热、恢复原色。缺一不可。

4. **尾气吸收液的选择**
   - $SO_{2}$、$Cl_{2}$、$HCl$、$NO_{2}$等酸性或有毒气体，见尾气处理，优先且首选填写“$NaOH$溶液”。

## 高频易错
- **仪器命名写错字**：“蒸馏烧瓶” 易错写成 “蒸馏烧平”、“圆底烧瓶” 或 “分液漏斗+烧瓶组合”。
- **方程式“酸性”条件遗漏**：书写 $MnO_{4}^{-}$ 与 $SO_{2}$ 反应时，必须补全 $H^{+}$ 参与反应生成水，否则电荷和质量均不守恒。
- **漂白与酸碱性混淆**
  - 误区：认为$SO_{2}$像$Cl_{2}$一样能使石蕊先变红后褪色。
  - 正解：$SO_{2}$只能使石蕊变红，**不能使其褪色**；只有品红等特定有机物能体现其可逆漂白性。
- **尾气处理漏写浓度**：仅写“$NaOH$”易丢分，需写全“$NaOH$溶液”。工业上也用氨水等，但最稳妥是写碱液。

## 代表题精讲
**题目**：2010新课标卷实验题（节选），涉及$SO_{2}$制备与多性质验证。
**思路**：
- 通过A装置（$Na_{2}SO_{3} +$浓硫酸）制气，B、C、D依次检验还原性、氧化性与漂白性。
**步骤**：
1. **仪器与制备**：A中仪器为蒸馏烧瓶，方程式为复分解反应生成$SO_{2}$。
2. **现象与性质推断（B→C）**
   - 观察B（酸性高锰酸钾）：现象写“紫红色褪去”，性质填“还原性”，并配平离子方程式。
   - 观察C（硫化钠溶液）：现象写“产生淡黄色浑浊”，性质填写“氧化性”。
3. **操作与现象设计（D装置品红验证）**
   - 需回答：通入$SO_{2}$品红褪色，接着关闭玻璃旋塞，点燃酒精灯加热，溶液由无色恢复红色。
4. **尾气处理**：尾气含毒$SO_{2}$，必须填“$NaOH$溶液”吸收。
**点评/变式**：
- 本题是$SO_{2}$性质考查的母题模型，将“变色”现象与“氧化/还原因果”深度捆绑。
- **变式**：若将高锰酸钾换成溴水或氯化铁溶液，现象对应变成橙黄色褪色或棕黄色变浅绿，性质仍填“还原性”，这说明只要涉及化合价升高，核心逻辑不变。
