## 知识精要
- **CO₂ 与碳酸盐的反应**  
  - 向碳酸盐溶液中通入 CO₂，生成碳酸氢盐：  
    $\text{Na}_2\text{CO}_3 + \text{CO}_2 + \text{H}_2\text{O} \longrightarrow 2\text{NaHCO}_3$  
    $\text{CaCO}_3 + \text{CO}_2 + \text{H}_2\text{O} \longrightarrow \text{Ca(HCO}_3)_2$（沉淀溶解）
  - 上述反应的逆过程（加热或加碱）可使碳酸氢盐重新转化为碳酸盐沉淀。
- **溶解度差异与结晶析出**  
  - 相同温度下，$\text{NaHCO}_3$ 的溶解度小于 $\text{Na}_2\text{CO}_3$。  
  - 向饱和 $\text{Na}_2\text{CO}_3$ 溶液中通入 CO₂，因生成溶解度更小的 $\text{NaHCO}_3$ 且溶剂水被消耗，会析出 $\text{NaHCO}_3$ 晶体。这是侯氏制碱法的原理基础。
- **碳酸钠与酸的分步反应**  
  - $\text{Na}_2\text{CO}_3$ 与盐酸反应分两步：  
    $\text{CO}_3^{2-} + \text{H}^+ \longrightarrow \text{HCO}_3^-$（优先）  
    $\text{HCO}_3^- + \text{H}^+ \longrightarrow \text{CO}_2\uparrow + \text{H}_2\text{O}$（后发生）  
  - 只有当 $\text{Na}_2\text{CO}_3$ 完全转化为 $\text{NaHCO}_3$ 后，继续加酸才会放出 CO₂。
- **NaHCO₃ 与 Na₂CO₃ 的盐酸反应放气量比较**  
  - 等质量时：$\text{NaHCO}_3$（摩尔质量 $84\ \text{g·mol}^{-1}$）放出的 CO₂ 多于 $\text{Na}_2\text{CO}_3$（$106\ \text{g·mol}^{-1}$），因为单位质量含碳量更高。
  - 等物质的量时：两者放出的 CO₂ 物质的量相等。

## 解题方法与套路
1. **判断离子反应能否发生**  
   - 看有无难溶、难电离或挥发性物质生成。$\text{Ca(HCO}_3)_2$ 与 $\text{NaHCO}_3$ 混合无沉淀、气体或弱电解质生成，不反应。
2. **碳酸盐与酸反应产物的定量判断**  
   - 明确“逐滴加入”与“一次加入”的区别。逐滴加酸时，酸先与 $\text{CO}_3^{2-}$ 反应生成 $\text{HCO}_3^-$，若酸量不足，无 CO₂ 产生。
3. **等质量/等物质的量与气体体积计算**  
   - 先换算为物质的量 $n = \dfrac{m}{M}$，再根据碳原子守恒得出 $n(\text{CO}_2)$，最后比较体积。
4. **通 CO₂ 析晶问题**  
   - 抓住反应消耗水、生成溶解度更小的物质两个关键点，结合饱和溶液析晶条件分析。反应方程式是核心依据。

## 高频易错
- **忽视反应分步，误认为加少量酸即放 CO₂**  
  向 $\text{Na}_2\text{CO}_3$ 中逐滴加入等物质的量的 HCl 时，只发生 $\text{CO}_3^{2-} \rightarrow \text{HCO}_3^-$，无气泡，考生常误以为会放出 1:2 的 CO₂。
- **错把 Ca(HCO₃)₂ 与 NaHCO₃ 的混合当成 Ca²⁺ 与 CO₃²⁻ 的直接混合**  
  两种溶液均大量存在 $\text{HCO}_3^-$，电离出的 $\text{CO}_3^{2-}$ 极少，无法达到 $\text{CaCO}_3$ 的 $K_\text{sp}$，无沉淀生成。
- **等质量比较时直接用化学计量数判断气体体积**  
  必须考虑摩尔质量的差异。$\text{NaHCO}_3$ 的 $M$ 较小，等质量时物质的量大，放出的 CO₂ 更多。
- **忽略结晶析出的双重原因**  
  误以为仅因生成 $\text{NaHCO}_3$ 就析出，忽略反应消耗水使溶剂减少、且同温下 $\text{NaHCO}_3$ 溶解度本身较小，二者共同导致析晶。

## 代表题精讲
**题目**  
（2009·全国Ⅱ·3）下列叙述中正确的是  
A. 向含有 CaCO₃ 沉淀的水中通入 CO₂ 至沉淀恰好溶解，再向溶液中加入 NaHCO₃ 饱和溶液，又有 CaCO₃ 沉淀生成  
B. 向 Na₂CO₃ 溶液中逐滴加入等物质的量的稀盐酸，生成的 CO₂ 与原 Na₂CO₃ 的物质的量之比为 1∶2  
C. 等质量的 NaHCO₃ 和 Na₂CO₃ 分别与足量盐酸反应，在同温同压下，生成的 CO₂ 体积相同  
D. 向 Na₂CO₃ 饱和溶液中通入 CO₂，有 NaHCO₃ 结晶析出  

**思路**  
逐一分析每个选项的反应实质，抓住离子反应发生的条件、分步反应的定量关系、混合物质量与气体体积的换算，以及饱和溶液变化规律。

**步骤**  
- **A 选项**：CaCO₃ 通入 CO₂ 转化为可溶的 Ca(HCO₃)₂，溶液含 Ca²⁺ 和 HCO₃⁻。加入 NaHCO₃ 饱和溶液，仅增加 HCO₃⁻ 和 Na⁺，不能生成 CaCO₃ 沉淀（无大量 CO₃²⁻，也不满足复分解条件）。故 A 错。  
- **B 选项**：$n(\text{Na}_2\text{CO}_3) : n(\text{HCl}) = 1:1$，发生反应 $\text{Na}_2\text{CO}_3 + \text{HCl} = \text{NaHCO}_3 + \text{NaCl}$，无 CO₂ 生成。只有当 $n(\text{HCl}) \ge 2n(\text{Na}_2\text{CO}_3)$ 时才会放气。故 B 错。  
- **C 选项**：设质量均为 $m$，则 $n(\text{NaHCO}_3) = \dfrac{m}{84}$，$n(\text{Na}_2\text{CO}_3) = \dfrac{m}{106}$。由碳守恒，放出 CO₂ 的物质的量分别为 $\dfrac{m}{84}$ 和 $\dfrac{m}{106}$，显然前者更多，同温同压下体积不等。故 C 错。  
- **D 选项**：饱和 Na₂CO₃ 溶液中通入 CO₂：$\text{Na}_2\text{CO}_3 + \text{CO}_2 + \text{H}_2\text{O} = 2\text{NaHCO}_3$。反应消耗水，且生成的 NaHCO₃ 溶解度小于 Na₂CO₃，故 NaHCO₃ 因过饱和而结晶析出。D 正确。  

**点评/变式**  
本题考查 CO₂ 参与的碳酸盐、碳酸氢盐转化，覆盖复分解条件、分步反应、守恒计算及溶解度原理，综合性较强。变式可设计为：向饱和 NaHCO₃ 溶液中通入 CO₂ 是否有晶体析出？答案是否定的（反应方向相反），进一步强化对平衡和溶解度的理解。
