## 知识精要
- **定义**：催化剂是能改变化学反应速率，而本身的质量和化学性质在反应前后保持不变的物质。
- **作用本质**：通过改变反应路径，**降低反应的活化能**，使更多普通分子成为活化分子，从而大幅提高反应速率。
- **能量图像特征**：催化反应路径的活化能峰低于无催化路径；但反应热（$\Delta H$）不变，即催化剂不改变反应的始终态。
- **与平衡的关系**：
  - 催化剂**同等程度地改变正、逆反应速率**，因此只能缩短达到平衡的时间，**不能使化学平衡发生移动**。
  - 催化剂的加入**不改变**平衡常数 $K$、平衡转化率、平衡产率。
- **选择性**：一种催化剂往往只对特定的反应或某一类反应有催化作用。在平行反应或连串反应中，可通过选择合适催化剂提高目标产物比例。
- **催化剂的判据**：
  - 反应中先消耗、后生成，总质量与化学组成不变的物质是催化剂。
  - 若某物质在总反应中未出现，但参与了具体基元反应并循环再生，则其为催化剂。
  - 反应物直接转化而来的中间产物不是催化剂，反应物本身更不应错误归为催化剂（如雾霾中 $\text{NH}_3$ 是反应物，不是催化剂）。

## 解题方法与套路
1. **催化剂、中间产物的区分法**
   - 写出分步反应：找出第一步消耗、后面又重新生成的物质，即为催化剂；只在中间步骤生成又被消耗的物质为中间产物。
   - 观察总反应方程式：催化剂不进入总反应计量式，中间产物也不进入，但催化剂是外加组分，中间产物是反应自身衍生的。
2. **催化剂对速率与平衡的影响题**
   - 一看速率：加入催化剂后，正、逆速率同时增大，$v$–$t$ 图像上正逆速率均突跃后趋于相等，平衡点时间缩短。
   - 二看平衡量：浓度–时间图像中，加催化剂只改变斜率，不改变平衡浓度平台高度。
   - 涉及转化率、产率、平衡常数的选项，只要题干明确“加催化剂”，这些量均不变。
3. **活化能与能量图像题**
   - 区分有无催化剂的能量曲线：峰值较低者为催化路径。
   - 计算活化能降低值：用无催化剂活化能减去有催化剂活化能。
   - 无论催化与否，$\Delta H = E_{\text{正活化}} - E_{\text{逆活化}}$ 值相同。
4. **催化剂与选择性、温度的关系**
   - 选择性计算：目标产物速率（或产量）除以总转化速率（或总转化量）。
   - 注意温度对催化剂活性的影响：催化剂有一定活性温度范围，过高可能失活。

## 高频易错
- **把反应物当催化剂**：如 $\text{NH}_3$ 参与生成铵盐，是反应物而非催化剂；判断时应看物质是否在反应中被消耗且不再生成。
- **认为催化剂只加速正反应**：催化剂同等加速正逆反应，若原平衡态加入催化剂，正逆速率仍相等，只是数值都变大，平衡不移动。
- **误以为催化剂能提高平衡产率/转化率**：催化剂不改变平衡点，只能缩短到达平衡的时间，若题目表述为“提高平衡转化率”则一定是错误选项。
- **混淆催化剂与中间产物**：先消耗后生成且总反应中不出现的为催化剂；先生成后消耗的为中间产物。
- **认为催化剂不参与反应**：催化剂参与反应改变了路径，只是最后又恢复原状，质量与化学组成不变，所以可以说“参与了反应”。
- **过量使用催化剂导致平衡移动**：催化剂过多不会改变平衡，但如果是固体催化剂增加表面积，可加快速率，但依然不改变平衡。

## 代表题精讲
### 代表题一：2024·辽宁·10
**题目**：异山梨醇由生物质制备，150℃时制备过程及物质浓度随时间变化如图，15h后异山梨醇浓度不再变化。判断错误说法（选项涉及速率、平衡常数、平均速率、催化剂对平衡转化率的影响）。

**思路**：这是一道典型的多步反应浓度–时间图像题，需结合平衡建立时刻、浓度变化量、催化剂对限度的影响进行判断。核心是利用“催化剂不改变平衡转化率”直接排除D选项的错误可能性，同时精确读取图像数据验证A、B、C。

**步骤**：
1. 审A项“3h时反应②正逆速率相等”：图像显示3h后异山梨醇浓度仍继续增大，直到15h才不变，说明3h时反应②未达平衡，正逆速率不等，故A错误，为答案。
2. 审B项“平衡常数：①>②”：15h后所有物质浓度不变，此时山梨醇转化完全，1,4-失水山梨醇仍有剩余，说明反应①进行更彻底，平衡常数①>②，B正确。
3. 审C项“0~3h平均速率(异山梨醇)”：从图读取0~3h异山梨醇浓度增加0.042 mol/kg，速率为 $0.042/3 = 0.014\ \text{mol}\cdot \text{kg}^{-1}\cdot\text{h}^{-1}$，C正确。
4. 审D项“反应②加入催化剂不改变其平衡转化率”：催化剂只改变速率，不改变平衡转化率，D正确。可见选A。

**点评/变式**：本题将多步连续反应与催化剂基础概念结合。D选项是催化剂性质的直接考查，属于必拿分点。A项关键在于看清平衡时间，不为图像中间时刻所迷惑。变式训练可改为判断“若添加选择性催化剂提高反应②速率，能否提高异山梨醇平衡产率？”——不能，平衡产率只由平衡常数和起始浓度决定。

### 代表题二：2018·新课标Ⅱ·2
**题目**：雾霾形成与氮氧化物、二氧化硫、氨有关（图示）。判断叙述错误的是（选项包含分散剂、雾霾成分、$\text{NH}_3$是否为催化剂、与氮肥关系）。

**思路**：通过雾霾形成示意图，结合催化剂定义进行判断。陷阱在于将参与生成颗粒物的反应物误认为催化剂。

**步骤**：
1. A项：雾和霾均分散在空气中，分散剂相同，正确。
2. B项：由图示可知无机颗粒物含硝酸铵、硫酸铵，正确。
3. C项：图中$\text{NH}_3$与硝酸、硫酸反应生成铵盐而消耗，并非先消耗后生成，故为反应物而不是催化剂，C错误。
4. D项：过量施用氮肥会释放$\text{NH}_3$，促进无机颗粒物生成，加剧雾霾，正确。因此选C。

**点评/变式**：此题从环境问题切入，实则考查催化剂定义。记住：“反应中先消后生、最终不耗”是催化剂的特征。可将类似逻辑迁移到大气化学或工业催化循环中，如$\text{NO}$在臭氧层破坏中作催化剂，因其消耗又再生。
