## 知识精要

- **锌及其化合物**
  - **闪锌矿 (ZnS)**：难溶于水，可与氧气在高温下焙烧反应：$2ZnS + 3O_2 \xrightarrow{\Delta} 2ZnO + 2SO_2$。
  - **氧化锌 (ZnO)**：两性氧化物，既可溶于强酸 ($ZnO + 2H^+ = Zn^{2+} + H_2O$)，也可溶于强碱。
  - **硫酸锌 (ZnSO₄)**：易溶于水。其溶液可通过电解得到单质锌：$2ZnSO_4 + 2H_2O \xrightarrow{电解} 2Zn + O_2 \uparrow + 2H_2SO_4$。
  - **金属锌**：活泼金属，常见化合价为 +2价。

- **杂质元素及其化合物去除原理**
  - **PbS、CdS、FeS**：硫化物杂质。焙烧时转化为对应氧化物，酸浸时与硫酸反应生成硫酸盐进入溶液。
  - **除杂顺序与方法**：
    - **调节pH法**：向含 $Zn^{2+}$、$Fe^{3+}$ 等离子的溶液中加 ZnO 或 ZnCO₃ 等物质，消耗 $H^+$，促进 $Fe^{3+}$ 水解生成 $Fe(OH)_3$ 沉淀从而除去。此方法的优势是不引入新杂质。
    - **置换法**：向滤液中加入比目标金属活泼的金属单质（通常为锌粉），可将活泼性较差的金属离子（如 $Cd^{2+}$、$Pb^{2+}$）从其盐溶液中置换出来，过滤除去。反应为：$Zn + Cd^{2+} = Zn^{2+} + Cd$、$Zn + Pb^{2+} = Zn^{2+} + Pb$。
  - **SiO₂**：酸性氧化物，不溶于硫酸，在焙烧后的酸浸环节直接作为滤渣除去。

- **硫酸盐溶解性规律**：$PbSO_4$ 微溶于水，$CaSO_4$ 微溶，$BaSO_4$ 难溶。绝大多数硫酸盐易溶。

## 解题方法与套路

1. **流程目的先行**：明确最终要提纯的目标元素及其化合物（本题为提取单质锌），在整个流程分析中，紧盯“目标元素走向”与“杂质分离路径”。
2. **预处理与转化分析**：
   - 初始“焙烧”通常把难溶硫化物转化为易与酸反应的氧化物，并观察有无废气（如 $SO_2$）产生，需考虑尾气处理。
   - “酸浸”环节遵循“强制弱”的复分解反应规律，明确哪些物质溶解进入溶液，哪些不反应成为滤渣（如 $SiO_2$、$PbSO_4$ 等）。
3. **核心提纯步骤拆解**：
   - 对于杂质阳离子，常采用“调 pH 值水解沉淀”除去 $Fe^{3+}$，再通过“加活泼金属置换”除去 $Cd^{2+}$、$Pb^{2+}$ 等。
   - 调 pH 所用试剂应选择对应目标金属的氧化物、碳酸盐或氢氧化物，严格遵循“不引入新杂质”原则。
4. **终端产品获取**：从净化后的含目标离子的盐溶液中，通过“电解”等方法直接制取高纯度的金属单质，需准确书写电解总反应方程式，注意放电顺序和溶液环境。

## 高频易错

- **硫化物直接加酸错误**：SiO₂ 难溶于酸，可通过酸浸过滤除去，但 ZnS 等硫化物常温下难与稀硫酸直接反应，必须通过焙烧转化为氧化物后再酸浸溶解。这是工艺流程题的高频前置陷阱。
- **试剂选择引入新杂质**：除去 $Fe^{3+}$ 时，若使用 NaOH、NH₃·H₂O 等碱直接调 pH，会引入 $Na^+$、$NH_4^+$ 且易导致目标离子 $Zn^{2+}$ 共沉淀。必须选用 ZnO、ZnCO₃ 或 Zn(OH)₂ 等含目标元素的物质。
- **除杂顺序混乱**：置换法除杂（加锌粉除 $Cd^{2+}$、$Pb^{2+}$）必须放在置换沉淀法（调 pH 除 $Fe^{3+}$）之后。因为 $Fe^{3+}$ 也可与 Zn 发生氧化还原反应，若顺序颠倒，会消耗大量锌粉，增加成本并可能引入新的铁离子干扰。
- **电解方程式误写**：电解 $ZnSO_4$ 溶液时，阳极若为惰性电极，放电的是水中的 $OH^-$，产生 $O_2$ 和 $H^+$，产物总伴有硫酸生成。单纯只写“$Zn^{2+}+2e^- = Zn$”只是阴极反应式，并非完整的总化学方程式。

## 代表题精讲

**题目**：2018-新课标Ⅱ-08 闪锌矿（ZnS，含 SiO₂、FeS、CdS、PbS）制备金属锌的流程分析。

**思路**：本题为经典的物质制备与分离提纯工艺流程题。解题核心是“元素追踪法”，依据硫化物焙烧→酸浸→调 pH 水解沉淀→置换→电解的主线，逐一分析目标物 Zn 的迁移路径与杂质 Si、Fe、Cd、Pb 的分离节点。

**步骤**：
1. **焙烧**：硫化物与 $O_2$ 高温反应，生成对应金属氧化物（ZnO、Fe₂O₃、CdO、PbO）和 $SO_2$，SiO₂ 不反应。
2. **酸浸**：加入稀硫酸后，金属氧化物溶解为相应的硫酸盐（$ZnSO_4$、$Fe_2(SO_4)_3$、$CdSO_4$、$PbSO_4$ 微溶析出），SiO₂ 不反应。故此步滤渣①主要为未溶的 SiO₂ 和生成的 PbSO₄，滤液含 $Zn^{2+}$、$Fe^{3+}$、$Cd^{2+}$。
3. **除铁**：向含 $Fe^{3+}$ 的酸性滤液中加入 ZnO 调节 pH，促进 $Fe^{3+} + 3H_2O \rightleftharpoons Fe(OH)_3 + 3H^+$ 水解平衡正向移动，使其沉淀为 $Fe(OH)_3$ 过滤除去。ZnO 在此既作反应物又调 pH，不引入新杂质。
4. **除镉**：向除铁后的含 $Zn^{2+}$、$Cd^{2+}$ 滤液中加入锌粉，依据金属活动性 $Zn > Cd$，发生置换反应 $Zn + Cd^{2+} = Zn^{2+} + Cd$，滤渣③为析出的海绵状镉及过量锌粉。
5. **电解**：净化后的 $ZnSO_4$ 溶液电解总反应为 $2ZnSO_4 + 2H_2O \xrightarrow{电解} 2Zn + O_2 \uparrow + 2H_2SO_4$，阴极析出锌。

**点评/变式**：本题完整呈现了湿法冶锌的经典工艺逻辑。失分点往往集中于：未能识别 PbSO₄ 的微溶特性而将其与可溶杂质混淆，导致滤渣成分判断失误。“除铁”与“除镉”步骤顺序的因果逻辑分析是简答题的考察要害。将此流程类比迁移，同样的逻辑也适用于从辉铜矿（Cu₂S）炼铜、或从菱锌矿（ZnCO₃）炼锌的工艺分析，核心均是围绕主元素浸出、惰性杂质过滤、活性杂质分步沉淀或置换的提纯思路。
