## 知识精要
- **元素在周期表中的位置**
  - 原子序数＝核电荷数＝质子数＝原子核外电子数。
  - 主族元素所在的周期序数＝电子层数；主族序数＝最外层电子数。
  - 常见“位—构—性”关系：原子结构决定元素在周期表中的位置，结构相似导致化学性质相似。
- **半径比较规则**
  - 同周期（短周期）从左到右，原子半径依次减小（稀有气体除外）。
  - 同主族从上到下，原子半径依次增大。
  - 简单离子半径比较：先看电子层数，再看核电荷数。电子层结构相同的离子，核电荷越大，半径越小。
- **电离能与电负性**
  - 第一电离能：气态基态原子失去一个电子变成气态 $+1$ 价离子所需的最低能量。大体趋势：同周期从左到右增大，同主族从上到下减小。注意ⅡA、ⅤA族因全满/半满稳定结构反常偏大。
  - 电负性：原子吸引键合电子的能力。周期表中右上方最大（F 为 4.0），常用于判断化合价与化学键类型。
- **非金属性与金属性**
  - 非金属性越强，最高价氧化物对应水化物酸性越强，氢化物稳定性越强；金属性越强，最高价氧化物对应水化物碱性越强。
  - 气态氢化物热稳定性：同周期从左到右增强，同主族从下到上增强。
- **化学键与 $8$ 电子结构**
  - 判断原子是否达到 $8$ 电子稳定结构（$H$ 为 $2$ 电子）：原子的最外层电子数 $+$ 共用电子对数 $+$ 从阳离子失去/阴离子得到的电子数 $= 8$。
- **常见分子空间构型与杂化方式**
  - VSEPR 模型与中心原子杂化对应：价层电子对数 $2$ 对应 $sp$，$3$ 对应 $sp^2$，$4$ 对应 $sp^3$。
  - 典型构型：$sp^3$ 可形成三角锥形（如 $NH_3$）、V 形（如 $H_2O$）；$sp^2$ 可形成平面三角形。
- **晶体类型与性质**
  - 分子晶体：通过范德华力/氢键结合，熔沸点较低（如 $O_3$、$H_2O$）。
  - 离子晶体：阴阳离子通过离子键结合，熔沸点较高（如 $Na_2O$）。
  - 晶胞中微粒数目、配位数、密度计算：$ \rho = \dfrac{ZM}{N_A a^3} $。

## 解题方法与套路
1. **先推元素**
   - 从题干提取关键信息：
     - 原子序数关系（依次增大，和、差等）。
     - 化学环境（能形成几个共价键、常见化合价、配位键判断；形成分子的空间构型）。
     - 特征物质与性质（如红棕色气体 $NO_2$、强酸对应氧化物水化物、常温下单质状态；与水/甲醇反应的单质等）。
     - 电子排布与周期数、族序数的关系。
   - 常用突破口：$H$（1 个共价键）、$B$（可形成 3 个共价键，常有缺电子结构）、$N$（3 个共价键，对应 $NH_3$ 等）、$O$（2 个共价键）、$Na$（+1 阳离子）、$Al$（ⅢA，周期数=族序数时可反推）、$Cl$（最外层 7 电子，总电子数 17 等）。
2. **代入元素验证**
   - 将推断的元素代入已知条件（原子序数之和、位置关系、化合价之和等）验算，确保逻辑自洽。
3. **应用规律逐项判断选项**
   - 键型：非金属之间多为共价键；活泼金属与非金属之间为离子键。晶体的性质反推键型。
   - 性质递变：根据周期表位置比较半径、非金属性/金属性、氢化物稳定性、最高价氧化物水化物的酸碱性。
   - 特殊结构：计算 $8$ 电子稳定结构时，中心原子如 $B$ 往往最外层电子仅有 $6$ 个（$BF_3$ 典型）。
   - 最高化合价规律：主族元素最高正价 $=$ 族序数（$O$、$F$ 除外）。
4. **解构晶胞与分子几何**
   - 利用化合价、配位数反向推导化学式。
   - 运用 VSEPR 判断杂化与空间构型，注意孤电子对对键角的影响。
   - 结合几何和摩尔质量进行密度、参数计算。

## 高频易错
- **忽视 $H$ 的 $2$ 电子稳定结构**：将 $H$ 满足 $2$ 电子当作错误判断。
- **$B$、$Be$ 等缺电子原子常不满足 $8$ 电子**：如题目中 $BF_3$，B 周围只有 6 个电子。请务必画结构或数电子对检验。
- **最高价氧化物水化物酸碱性混淆**：非金属性越强，**最高价含氧酸**酸性越强，但低价含氧酸不一定遵循此规律（如 $HClO$ 为弱酸）。必须判准化合价。
- **“氧化物对应的水化物”≠“最高价氧化物对应的水化物”**：前者含各种价态，后者专指最高价。选项中未写“最高价”时极易以偏概全，需警惕。
- **原子与离子半径对比逻辑错误**：电子层结构相同（如 $N^{3-}、O^{2-}、Na^+、Al^{3+}$），核电荷越大半径越小；电子层不同时，层数多则半径大在先。
- **非金属性与氢化物稳定性的对应**：非金属性越强，其简单气态氢化物越稳定，而非酸性越强（如 $HF$ 极稳定却是弱酸）。
- **忽视配位键的存在**：题干中若出现形式上的 4 个共价键，但原子只有 3 个价电子，很可能生成配位键（如 $NH_4^+$ 或 $B$ 的配合物），此仍属于共价键范畴。
- **元素推断中的价态矛盾**：常见陷阱——同周期 $W$ 与 $X$ 最高正价之和为 8，推理时需注意 $O、F$ 无最高正价，$N$ 最高正价为 +5，$Al$ 为 +3 等。
- **第一电离能异常顺序**：$Be > B$，$N > O$，$Mg > Al$，$P > S$ 等，因全满或半满稳定，历年高频设误。

## 代表题精讲
### **题目 1**（2020-新课标Ⅱ-07）
- **题目**：短周期主族元素组成的储氢化合物中，$W$、$X$、$Y$、$Z$ 原子序数依次增大，总和为 24。给出结构图，判断错误选项。
- **思路**：由结构反推元素——1 个共价键的 $W$ 极可能为 $H$，+1 价阳离子 $Z$ 为 $Na$。$X$ 成 4 个共价键（含 1 个配位键）为 $B$，$Y$ 成 3 个共价键为 $N$。代入总和 $1+5+7+11=24$ 验证成功。
- **步骤**：
  1. 推元素：$WH$、$XB$、$YN$、$ZNa$。
  2. A 项：非金属间为共价键 → 正确。
  3. B 项：$Na$ 与水/甲醇反应均放氢 → 正确。
  4. C 项：$N$ 最高价氧化物水化物为 $HNO_3$，强酸 → 正确。
  5. D 项：$BF_3$ 中 $B$ 最外层电子 $3+3=6$，不满足 8 电子 → 错误。
- **点评/变式**：缺电子结构是高频考点。$B$、$Be$ 的卤化物通常不满足 8 电子。变式训练：若 $X$ 为 $Al$ 则成键形式不同，常见的 $AlCl_3$ 也缺电子，易形成二聚体。

### **题目 2**（2019-新课标Ⅱ-03）
- **题目**：周期表片段，$W$ 在第二周期，$X、Y、Z$ 在第三周期。$W$ 与 $X$ 最高化合价之和为 8，判断错误选项。
- **思路**：利用“最高化合价 + 位置限定”唯一确定元素。$W$ 第二周期，设最外层电子 $x$，则 $X$ 第三周期，最外层电子 $x-2$。根据 $x+(x-2)=8$，得 $x=5$。因此 $W$ 为 $N$，$X$ 为 $Al$，$Y$ 为 $Si$，$Z$ 为 $P$。
- **步骤**：
  1. 推元素：$W(N)$、$X(Al)$、$Y(Si)$、$Z(P)$。
  2. A 项：$N$（二周期）半径 < $Al$（三周期）→ 正确。
  3. B 项：$Si$ 常温常压为固态 → 正确。
  4. C 项：非金属性 $P< N$，所以氢化物稳定性 $PH_3< NH_3$，即 $Z< W$ → 正确。
  5. D 项：$Al$ 最高价氧化物水化物 $Al(OH)_3$ 为两性氢氧化物，非强碱 → 错误。
- **点评/变式**：利用元素位置与化合价代数关系反推元素是课标卷经典模式。务必分清“金属性→碱性”“两性氢氧化物”辨析。常见的陷阱：$Mg(OH)_2$ 为中强碱、$Al(OH)_3$ 两性。

### **题目 3**（2018-新课标Ⅱ-04）
- **题目**：$W、X、Y、Z$ 原子序数依次增大的短周期元素，$W$ 与 $X$ 生成红棕色刺激性气体；$Y$ 周期数是族序数 3 倍；$Z$ 最外层电子数等于 $W$ 总电子数。
- **思路**：红棕色刺激性气体为 $NO_2$，推得 $W(N)、X(O)$。$Y$ 周期数=3×族序数，且原子序数 $> O$，故 $Y(Na)$。$Z$ 最外层电子 $= N$ 总电子数 $=7$，$Z$ 为 $Cl$。
- **步骤**：
  1. 推元素：$W(N)、X(O)、Y(Na)、Z(Cl)$。
  2. A 项：$O$ 与 $N$ 可生成多种氧化物，与 $Na$ 有 $Na_2O、Na_2O_2$，与 $Cl$ 有多种氧化物 → 正确。
  3. B 项：$Na_2O_2$ 含离子键与 $O-O$ 非极性共价键 → 错误（说“只含有离子键”不成立）。
  4. C 项：$N^{3-}$、$O^{2-}$、$Na^+$ 为 28 电子，$Cl^-$ 为 288 结构，电子层不同 → 错误。
  5. D 项：$N$ 的氧化物对应水化物如 $HNO_2$ 为弱酸 → 错误。
- **点评/变式**：本题综合考查了性质、结构、化学键。B 项涉及氧化物中化学键类型的判断，除 $Na_2O$ 外还有过氧化钠。D 项再次提醒“氧化物对应水化物”≠“最高价氧化物”。
