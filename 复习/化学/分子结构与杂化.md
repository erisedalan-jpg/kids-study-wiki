## 知识精要
- **杂化轨道理论核心**：
    - 杂化是原子轨道在成键过程中重新组合形成新轨道的过程，用于解释分子空间构型。
    - 杂化轨道数 $n =$ 中心原子孤电子对数 $+$ 中心原子 $\sigma$ 键个数。
    - $n=2$ 为 $sp$ 杂化（直线形，$180^\circ$）；$n=3$ 为 $sp^2$ 杂化（平面三角形，$120^\circ$）；$n=4$ 为 $sp^3$ 杂化（正四面体，$109.5^\circ$）。当 $n=4$ 且存在孤电子对时，分子构型变为三角锥形或 $V$ 形。
- **价层电子对互斥理论 (VSEPR)**：
    - 计算中心原子价层电子对数 = $\frac{\text{中心原子价电子数} + \text{配位原子提供的电子数} \pm \text{离子电荷数}}{2}$。
    - 多中心含氧酸，通常氢原子与氧原子结合，该氧原子作为羟基连接中心原子。
    - 酸根离子构型的判断同样基于 VSEPR，需考虑电荷对价电子的影响。
- **等电子体原理**：原子总数相同、价电子总数相同的粒子，具有相似的化学键特征和空间结构。
- **第一电离能变化规律**：同周期从左向右呈增大趋势（注意 $\rm IIA$ 与 $\rm VA$ 族反常半满全满）；同主族从上到下减小。
- **配位键**：成键原子一方提供孤电子对，另一方提供空轨道所形成的共价键。

## 解题方法与套路
1. **元素推断是前提**：
    根据原子结构特征（周期数、未成对电子数、价电子排布、最外层/内层电子关系、次外层电子数等），结合原子序数递增，逐步锁定元素。需要熟练记忆1-36号元素对应的电子排布式。
2. **杂化方式与空间构型判断三步法**：
    - **第一步**：确定中心原子，计算其价层电子对数。
    - **第二步**：核对孤电子对数，由价层电子对数直接得出杂化类型。
    - **第三步**：由实际成键数与孤对电子数推断分子或离子的空间构型。
3. **化学键类型与分子极性判断**：
    - **极性键与非极性键**：同种原子之间为非极性键，不同种原子之间为极性键。
    - **分子极性**：空间结构完全对称（正四面体、平面三角形、直线形同配体）的多原子分子一般为非极性分子。
    - “既含极性键又含非极性键”的物质，结构上通常存在同种原子的直接相连（如过氧键 $-O-O-$、肼中的 $N-N$ 单键）。
4. **晶体结构分析与计算**：
    - **均摊法**确定晶胞内粒子数目，进而推断离子所带电荷或化学式。
    - 基于电荷守恒判断离子内部存在的化学键类型（离子键、共价键、配位键）。

## 高频易错
- **电负性与第一电离能定义混淆**：第一电离能测量的是气态基态原子失去第一个电子的能力，氮原子 $2p^3$ 半充满稳定，其第一电离能比同周期紧邻的氧原子高。
- **杂化类型与空间构型割裂判断**：误以为 $sp^3$ 杂化都是正四面体形。只要含孤电子对，分子的实际几何构型会发生畸变（如氨气的三角锥形）。
- **书写轨道示意图遗漏细节**：容易忽略基态原子电子排布遵循的洪特规则（能量最低原理、泡利不相容原理），以及离子的价电子排布与原子排布的差异。对于 $d$ 区元素，常需考虑 $3d$ 和 $4s$ 轨道能量的相对高低。
- **“价层电子对数”计算忽略离子电荷**：对阴离子，需加上电荷数；对阳离子，需减去电荷数。漏算会导致杂化方式与构型判断完全错误。
- **化学键类型判断遗漏配位键**：当中心原子形成共价键数目超过其基态未成对电子数，或形成复杂离子时（如 $[Cu(NH_3)_4]^{2+}$），极易漏答配位键。注意配位键属于共价键。

## 代表题精讲
### **题目**：2014-新课标Ⅱ-12 (元素推断综合)
通过核外电子排布特征，推断出短周期加第四周期的五种元素。并根据元素及其化合物性质，考查第一电离能、杂化方式、分子极性、晶体结构及化学键种类。

**思路**：
此题核心是利用原子结构特征突破元素推断。
- “核外电子总数与周期数相同”确定 **a** 为氢 ($\rm H$)。
- “价电子层未成对电子有3个，且位于前四周期的b”可以是第二周期的氮 ($\rm N$) 或第三周期的磷 ($\rm P$)。
- “c的最外层电子数为内层电子数的3倍”说明c只有两个电子层，核外电子排布为2、6，确定 **c** 为氧 ($\rm O$)。结合原子序数递增，反推 **b** 为氮。
- “d与c同族”，下一周期为硫，确定 **d** 为硫 ($\rm S$)。
- “e最外层1个电子，次外层18个电子”，说明排满 $3s^23p^63d^{10}$，确定 **e** 为铜 ($\rm Cu$)。

**步骤**：
1. **第一电离能比较**：同周期 $I_1$ 大小关系：$\rm N > O$。同主族 $I_1$ 大小关系：$\rm O > S$。故氮、氧、硫中第一电离能最大的是 $\rm N$。
2. **价层轨道示意图**：铜为29号元素，基态原子电子排布式 $[Ar] 3d^{10}4s^1$。失去一个电子形成 $\rm Cu^+$，电子排布为 $[Ar] 3d^{10}$，价层仅 $3d$ 轨道全满。
3. **杂化方式与分子结构**：a为氢元素，与其他元素形成二元化合物。分子呈三角锥形，中心原子需采取 $sp^3$ 杂化且有1个孤电子对，典型分子是 $\rm NH_3$ (氨)。既含极性键又含非极性键的二元化合物，常见分子为 $\rm H_2O_2$ (过氧化氢，存在 $O-O$ 非极性键)和 $\rm N_2H_4$ (肼，存在 $N-N$ 非极性键)。
4. **含氧酸结构推断**：中心原子价层电子对数为3 ($sp^2$ 杂化)，一般形成双键。常见酸为 $\rm HNO_3$ (硝酸) 和 $\rm HNO_2$ (亚硝酸)。酸根呈三角锥形，中心原子为 $sp^3$ 杂化，有一个孤电子对，价层电子对数为4。可知是 $\rm SO_3^{2-}$，对应的酸是 $\rm H_2SO_3$ (亚硫酸)。
5. **晶体与配合物结构分析**：
    - 观察 $\rm Cu$ 与 $\rm O$ 的晶胞结构图1，使用均摊法，该晶胞中氧原子在顶点和面心，数目为 $8\times \frac{1}{8} + 6\times \frac{1}{2} = 4$。铜原子都在体内，数目为4。两者个数比为 $1:1$，化学式为 $\rm CuO$，可知氧元素为 $-2$ 价，则铜离子 $e$ 的电荷数为 **+2**。（注意：题目标准答案为+1，但按图1计算结果是+2，此处严格按解析推断逻辑）
    - 五种元素形成 $1:1$ 型离子化合物。阴离子呈四面体结构，常见为 $\rm SO_4^{2-}$ (硫酸根)。阳离子为 $\rm Cu^{2+}$ 与 $\rm NH_3$ 形成的呈轴向狭长八面体结构的铜氨配离子，其内界 $\rm [Cu(NH_3)_4(H_2O)_2]^{2+}$ 中存在铜氧、铜氮间的**配位键**和配体内部的**共价键**。加热时，由于热稳定性，首先失去的是结合力较弱的小分子配体 $\rm H_2O$。

**点评/变式**：
本题以元素周期表为载体，横向覆盖了电离能、分子构型理论、晶体密度计算以及配合物理论。此类题目解题的关键在于第一问的元素推断绝不能出错。对于分子构型，要熟练记忆价层电子对数的计算公式。在离子化合物中寻找化学键类型时，需重点关注是否有配合物内界形成，这是检验考生是否具有“配位键”意识的常见考法。
