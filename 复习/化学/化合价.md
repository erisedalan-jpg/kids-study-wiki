## 知识精要
- **化合价核心规则**  
  化合物中正负化合价的代数和为 **0**；单质中元素化合价为 **0**。  
  常见固定价态：$H$ 通常 $+1$（金属氢化物中为 $-1$），$O$ 通常 $-2$（过氧化物中 $-1$，$OF_2$ 中 $+2$）；碱金属 $+1$，碱土金属 $+2$；$F$ 仅 $-1$。
- **氧化还原化合价判据**  
  元素化合价 $升高 \rightarrow$ 被氧化 $\rightarrow$ 还原剂；  
  元素化合价 $降低 \rightarrow$ 被还原 $\rightarrow$ 氧化剂。  
  反应前后某元素化合价发生改变，则为氧化还原反应。
- **特殊物质化合价速判**  
  $NaH$ 中 $H$ 为 $-1$；$H_2O_2$、$Na_2O_2$ 中 $O$ 为 $-1$；$Fe_3O_4$ 中 $Fe$ 为 $+\frac{8}{3}$（平均价，实际 $+2,+3$）；有机物中 $C$ 化合价按共用电子对偏移用平均法或代数法计算。
- **典型变价与条件**  
  同种元素在不同化学环境下价态不同，如 $WO_3$ 中 $W$ 为 $+6$，$Ag_xWO_3$ 中 $W$ 因 $Ag^+$ 嵌入得电子被还原，价态降为 $+(6-x)$，属于插入还原。

## 解题方法与套路
1. **标价法判断氧化还原与反应类型**  
   - 标出所有元素的化合价（优先使用规则和常见价态）。  
   - 观察变价元素的化合价升降：仅当有元素化合价改变时，反应才是氧化还原反应。  
   - 用于解决电化学、无机反应历程等问题。  
2. **价态守恒速求未知化合价**  
   - 根据化学式中正负化合价代数和为零建立方程，解出目标元素化合价。  
   - 若含原子团，可先算原子团整体化合价（如 $SO_4^{2-}$ 整体 $-2$）。  
3. **特殊键型化合价反推元素性质**  
   - 遇到 $H$、$O$ 在非典型环境中（如氢化物、过氧化物），立即联想到其特殊价态，避免按固定价态误判。  
   - 在元素推断题中，利用化合价特征（如 $b^{2-}$ 与 $c^+$ 电子层结构相同）结合周期表位置推导元素种类。  
4. **电化学中化合价变价方向速判**  
   - 电极反应遵循化合价升降：阳极（氧化）→化合价升高；阴极（还原）→化合价降低。  
   - 根据总反应中某元素化合价变化方向判定电极类型和反应过程正误。

## 高频易错
- **$H$ 的非 $+1$ 价忽视**  
  与活泼金属（如 $Na$、$K$）形成的二元化合物（$NaH$）中 $H$ 显 $-1$ 价，错误默认一切二元化合物中 $H$ 均为 $+1$。  
- **过氧化物与超氧化物氧价误判**  
  $H_2O_2$、$Na_2O_2$ 中 $O$ 为 $-1$；$KO_2$ 中 $O$ 为 $-\frac12$，计算时易错将 $O$ 一律当 $-2$。  
- **复杂物质化合价方向判断错误**  
  如 $WO_3 \rightarrow Ag_xWO_3$ 过程，因 $Ag^+$ 注入得电子，$W$ 的化合价下降而非上升；只关注物质外观变化忽略电子得失导致化合价升降方向颠倒。  
- **合金/插入型化合物价态分析**  
  非化学计量比化合物（如 $Ag_xWO_3$）中化合价需根据电荷守恒推导， $xAg^+ + xe^- + WO_3 = Ag_xWO_3$，明确 $W$ 被还原为 $+(6-x)$ 而非升高。  
- **短周期元素推导中化合价与电子层结构关系混淆**  
  $b^{2-}$ 与 $c^+$ 电子层结构相同，代表得电子后的阴离子与失电子后的阳离子与同一稀有气体电子构型一致，可推 $b$、$c$ 同周期且分别位于 $VIA$ 和 $IA$，化合价绝对值相加等于 $8$，从而确定元素。

## 代表题精讲
### 代表题1：2020-新课标Ⅱ-06
**题目**  
电致变色器件通电时，$Ag^+$ 注入无色 $WO_3$ 薄膜生成 $Ag_xWO_3$，器件变蓝。判断下列说法错误的是（$A$. $Ag$ 为阳极；$B$. $Ag^+$ 由银电极向变色层迁移；$C$. $W$ 元素的化合价升高；$D$. 总反应为 $WO_3 + xAg = Ag_xWO_3$）。

**思路**  
从电化学装置和反应路径切入，先确定电极类型和离子迁移方向；再写出电极反应，用化合价变化判断氧化还原本质；总反应从电极反应加和得到，并据此验证 $W$ 化合价变化。

**步骤**  
1. 由 $Ag$ 电极反应 $Ag - e^- = Ag^+$ 知 $Ag$ 失电子，阳极（氧化），$A$ 正确。  
2. 通电后 $Ag^+$ 向变色层移动并注入 $WO_3$ 薄膜，$B$ 正确。  
3. 变色层得电子：$xAg^+ + xe^- + WO_3 = Ag_xWO_3$；$WO_3$ 中 $W$ 为 $+6$，$Ag_xWO_3$ 中 $Ag$ 为 $+1$，根据化合物总价为零，$W$ 化合价 $= 0 - (+1\times x) - (-2\times 3) = +6 - x$，化合价降低，$C$ 错误。  
4. 阳极反应：$xAg - xe^- = xAg^+$，阴极（变色层）反应与之加和得总反应 $WO_3 + xAg = Ag_xWO_3$，$D$ 正确。  
故错误选项为 $C$。

**点评/变式**  
本题将化合价嵌入电化学和新材料情境，关键抓住“阴极得电子→化合价降低”不动摇。变式可问 $Ag_xWO_3$ 中 $W$ 的化合价与 $x$ 的关系，或若换成 $A_g$ 以外的金属离子，化合价变化规律是否相同。

### 代表题2：2016-新课标Ⅱ-03
**题目**  
$a,b,c,d$ 为短周期元素，$a$ 原子只有 $1$ 个电子，$b^{2-}$ 和 $c^+$ 电子层结构相同，$d$ 与 $b$ 同族。下列叙述错误的是（$A$. $a$ 与其他三种元素形成的二元化合物中其化合价均为 $+1$；$B$. $b$ 与其他三种元素均可形成至少两种二元化合物；$C$. $c$ 的原子半径是这些元素中最大的；$D$. $d$ 与 $a$ 形成的化合物的溶液呈弱酸性）。

**思路**  
先推断元素：$a$ 原子仅一个电子为 $H$；$b^{2-}$ 与 $c^+$ 电子层结构相同，即都具有 $10$ 个电子，则 $b$ 为 $O$（$8+2=10$），$c$ 为 $Na$（$11-1=10$）；$d$ 与 $b$ 同族则为 $S$。再逐项用化合价规则和物质性质检验。

**步骤**  
1. $a(H)$ 与 $O$、$Na$、$S$ 形成二元化合物：$H_2O$（$H$ 为 $+1$）、$H_2S$（$+1$），但 $H$ 与 $Na$ 形成 $NaH$，$H$ 为 $-1$，$A$ 中“均为 $+1$”错误。  
2. $b(O)$ 与其他元素：与 $H$ 有 $H_2O$、$H_2O_2$；与 $Na$ 有 $Na_2O$、$Na_2O_2$；与 $S$ 有 $SO_2$、$SO_3$，每种至少两种，$B$ 正确。  
3. 原子半径：$Na$ 在短周期中为 $IA$ 族，层数最多且核电荷相对小，半径最大，$C$ 正确。  
4. $d$ 与 $a$ 形成 $H_2S$，溶液为氢硫酸，呈弱酸性，$D$ 正确。  
故错误选项为 $A$。

**点评/变式**  
该题用化合价作为选项陷阱，考查 $H$ 的特殊价态，提醒考生“$H$ 不一定永远是 $+1$”。可衍生变式：若 $b^{2-}$ 与 $c^{2+}$ 电子层结构相同，则化合价关系和元素种类将变化，需根据电子层结构倒推族序数。
