## 知识精要
- **电子式**：表示原子最外层电子及离子、共价分子中原子间成键情况的式子。  
  - 简单阳离子（如$\ce{Na+}$）直接用离子符号表示，不需加方括号和电子。  
  - 阴离子和复杂离子（如$\ce{[ \overset{\cdot\cdot}{\underset{\cdot\cdot}{O}} \! : \! \overset{\cdot\cdot}{\underset{\cdot\cdot}{O}} ]^{2-}}$、$\ce{[ \overset{\cdot\cdot}{\underset{\cdot\cdot}{Cl}} :]^{-}}$）**必须加方括号并标电荷**。  
  - 过氧化物（如$\ce{Na2O2}$）中氧氧间以**一对共用电子对**形成过氧根$\ce{O2^{2-}}$。  
- **原子（离子）结构示意图**：小圈内写核电荷数，弧线表示电子层，弧线上数字表示该层电子数。  
  - 原子：质子数 = 电子数；离子：阳离子电子数 < 质子数，阴离子电子数 > 质子数。  
  - 常见排布：$\ce{Cl}$为$\ce{(+17) 2, 8, 7}$；$\ce{Cl-}$为$\ce{(+17) 2, 8, 8}$。  
- **核组成符号**：${}^A_Z \mathrm{X}$，$Z$为质子数，$A$为质量数，中子数$N = A - Z$。同位素质子数相同、中子数不同。  
- **气体摩尔体积**：标准状况（$0\ ^\circ\mathrm{C}$，$101\ \mathrm{kPa}$）下，$V_\mathrm{m} \approx 22.4\ \mathrm{L\cdot mol^{-1}}$，**仅适用于气体**。  
- **混合物计算**：常借用**平均化学式**、**守恒法**（碳原子守恒等）；若题目未给定物质的量比，结论一般不成立，除非通过条件确定唯一比例。  

## 解题方法与套路
1. **快速判断选项考查的用语类型**（电子式 / 结构示意图 / 核素符号 / 气体体积 / 混合物计算）。  
2. **电子式正误检查要点**：  
   - 离子化合物：阴离子是否加方括号并标电荷？  
   - 过氧根$\ce{O2^{2-}}$内部是否为$\ce{O-O}$单键（一对共用电子）？  
   - 最外层电子数是否满足8电子稳定结构（$\ce{H}$为2电子）？  
3. **结构示意图正误检查要点**：  
   - 核内质子数是否正确？核外电子总数是否与离子电荷匹配？  
   - 电子层排布是否符合“2, 8, 18……”规律？  
4. **核素符号正误检查要点**：  
   - 质子数$Z$由元素种类决定（如氮必为7）。  
   - 中子数$N$可不同，注意同位素的存在。  
5. **气体体积计算**：  
   - 前提必须是**标准状况**且该物质在标况下为**气体**。  
   - 若是求生成气体体积，确认所给物质的计算依据（质量/物质的量），必要时用平均化学式或极值法。  
6. **混合物结论判定**：  
   - 若选项未给出混合物比例或不能推出唯一比例，则“完全燃烧生成一定体积$\ce{CO2}$”等结论一般不合理，可判错。  

## 高频易错
- **$\ce{Na2O2}$电子式**：常误写为$\ce{Na+ [:\overset{\cdot\cdot}{\underset{\cdot\cdot}{O}}:]^{2-} Na+}$（氧间无共用电子），正确应体现过氧根中的共价单键。  
- **$\ce{Cl-}$结构示意图**：易与$\ce{Cl}$原子混淆，将最外层电子数写成7（实际应为8）。  
- **中子数与质子数**：误认为同种元素的中子数一定等于质子数。例如$\ce{^{14}N}$中子数7，$\ce{^{15}N}$中子数8。  
- **气体摩尔体积适用条件**：忽视“标准状况”或误把液体、固体的体积代入$22.4\ \mathrm{L\cdot mol^{-1}}$。注意选项B中$\ce{CO2}$虽为气体，但反应物的量需要混合物的平均组成才能计算，若未说明比例则无法推出固定体积。  
- **混合物计算默认1:1**：选项B只有乙醇与丙醇按物质的量1:1混合时结论才成立，无此前提即错误。  

## 代表题精讲
### **题目**  
（2010全国新课标）判断下列表达的正误：  
A．$\ce{Na2O2}$的电子式  
B．$106\ \mathrm{g}$的乙醇和丙醇混合液完全燃烧生成的$\ce{CO2}$为$112\ \mathrm{L}$（标准状况）  
C．在氮原子中，质子数为7而中子数不一定为7  
D．$\ce{Cl-}$的结构示意图  

### **思路**  
- A项：回忆$\ce{Na2O2}$是离子化合物，由$\ce{Na+}$和过氧根$\ce{O2^{2-}}$构成，$\ce{O2^{2-}}$中氧原子间以一对共用电子成键，需正确书写。  
- B项：乙醇$\ce{C2H6O}$与丙醇$\ce{C3H8O}$，不论以何比例混合，$106\ \mathrm{g}$混合物完全燃烧生成$\ce{CO2}$的体积是否恒为$112\ \mathrm{L}$？需要计算平均化学式，看是否唯一确定。  
- C项：明确氮的原子序数=质子数=7，中子数依赖于同位素，可举例说明。  
- D项：$\ce{Cl-}$比$\ce{Cl}$多一个电子，核外电子排布为2,8,8，与核电荷数17匹配。  

### **步骤**  
1. **A项**：$\ce{Na2O2}$的电子式正确写法为$\ce{Na+ [:\overset{\cdot\cdot}{\underset{\cdot\cdot}{O}} : \overset{\cdot\cdot}{\underset{\cdot\cdot}{O}} :]^{2-} Na+}$，如果选项画成$\ce{Na+ [:\overset{\cdot\cdot}{\underset{\cdot\cdot}{O}}:]^{2-} Na+}$（氧间无共用电子）则为错误。此处原题未直接展示选项具体图，但根据常见陷阱，该选项错误。  
2. **B项**：设乙醇物质的量$x\ \mathrm{mol}$（$M=46\ \mathrm{g\cdot mol^{-1}}$），丙醇$y\ \mathrm{mol}$（$M=60\ \mathrm{g\cdot mol^{-1}}$）。总质量$46x + 60y = 106$。完全燃烧生成$\ce{CO2}$的物质的量由碳原子守恒为$2x + 3y$，体积$V = 22.4(2x+3y)\ \mathrm{L}$。若要$V=112\ \mathrm{L}$，则$2x+3y=5$。联立$46x+60y=106$，解得$x=1, y=1$。因此只有$1:1$混合时成立，选项未说明比例，故错误。  
3. **C项**：氮元素有$\ce{^{14}N}$（质子数7，中子数7）和$\ce{^{15}N}$（质子数7，中子数8）等同位素，故质子数必为7，但中子数不一定为7。正确。  
4. **D项**：$\ce{Cl-}$质子数为17，电子数为18，结构示意图应为$(+17) 2, 8, 8$。若选项画成$(+17) 2, 8, 7$则是氯原子，错误。  

### **点评/变式**  
- 本题以化学用语为主线，融合基本概念与计算，要求考生**精确记忆常见物质的微观表达，并具备敏锐的条件审视能力**。  
- B项的陷阱在于“混合液”未给定比例，通过列方程可发现唯一解，但选项缺少条件，属于“不全则错”的典型考法。  
- 变式训练：  
  - 写出$\ce{H2O2}$的电子式，并与$\ce{Na2O2}$比较；  
  - 将B项改为“$106\ \mathrm{g}$乙醇与丙醇按物质的量$1:1$混合，完全燃烧生成$\ce{CO2}$标况下体积为$112\ \mathrm{L}$”，此时是否正确？（正确）  
  - 判断$22.4\ \mathrm{L}$ $\ce{Cl2}$在非标况下物质的量是否为$1\ \mathrm{mol}$。
