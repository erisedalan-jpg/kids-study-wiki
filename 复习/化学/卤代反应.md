## 知识精要
- **定义**：有机物分子中的原子或原子团被卤素原子取代的反应称为卤代反应。
- **烷烃卤代**：烷烃与卤素单质（如 $Cl_2$、$Br_2$）在光照（或加热）条件下发生取代反应，生成卤代烃和卤化氢。例如：
  $$CH_4 + Cl_2 \xrightarrow{\text{光}} CH_3Cl + HCl$$
  反应可继续进行，生成多卤代物：
  $$CH_3Cl + Cl_2 \xrightarrow{\text{光}} CH_2Cl_2 + HCl$$
  $$CH_2Cl_2 + Cl_2 \xrightarrow{\text{光}} CHCl_3 + HCl$$
  $$CHCl_3 + Cl_2 \xrightarrow{\text{光}} CCl_4 + HCl$$
- **反应条件**：光照或加热，两者均为提供自由基引发所需的能量。常温无光时不反应。
- **反应历程**：自由基取代。经历链引发、链增长、链终止三个阶段。光照使卤素分子均裂产生自由基：
  $$Cl_2 \xrightarrow{\text{光}} 2Cl\cdot$$
- **产物特点**：甲烷的卤代产物常温下 $CH_3Cl$ 为气体，$CH_2Cl_2$、$CHCl_3$、$CCl_4$ 为液体（不可燃）。生成物为混合物，一般得不到纯净的一卤代物。
- **实验现象**（甲烷与氯气光照）：黄绿色逐渐变浅；试管内壁出现油状液滴；试管内水面上升（因生成 $HCl$ 易溶于水，且反应后气体体积减小）；有少量白雾（$HCl$ 与水蒸气形成酸雾）。

## 解题方法与套路
1. **判断反应类型**：抓住“光照条件下烷烃与卤素单质反应”即为取代反应，非加成或氧化。
2. **分析装置与现象**：
   - 若装置密闭，光照后气体体积变化：体积减小通常因生成易溶于水的 $HCl$ 及气体总物质的量减少。
   - 液滴或油状物：多卤代产物（$CH_2Cl_2$、$CHCl_3$、$CCl_4$）的液膜。
   - 颜色变化：卤素单质消耗，颜色消退。
3. **书写方程式与产物判断**：明确连续取代，生成多种取代产物，卤代产物中卤原子数不同导致状态差异。
4. **条件控制答题**：无光照不反应；注意溴蒸气取代反应类似但条件可能略有差异（如加热）。
5. **实验安全与尾气处理**：有机卤代物及 $HCl$ 的酸性尾气需用碱液吸收，注意防倒吸。

## 高频易错
- **混淆反应类型**：甲烷与氯气光照是**取代**而非加成，许多考生误写加成反应。
- **忽略产物状态**：误认为所有氯代甲烷都是气体，实则只有一氯甲烷是气体，其余是油状液体。
- **忽略体积变化原因**：只记得生成 $HCl$ 溶于水使压强减小，却忽略反应本身气体分子数变化（如 $CH_4+Cl_2 \to CH_3Cl+HCl$，气体分子数 $1+1 \to 1+1$ 不变；但若生成多卤代物，如 $CH_2Cl_2$ 为液体，气体分子数可能减小）。
- **反应条件书写模糊**：光照必须明确写出，箭头或等号上标明“光”或“$h\nu$”，不可省略。
- **误判反应程度**：认为反应停留在一氯代阶段，实际产物为混合物，导致答题时错误书写单一方程式。
- **缺少尾气分析**：忽略 $HCl$ 气体逸出造成污染，实验设计未考虑吸收装置导致失分。

## 代表题精讲
**题目**：实验室中用如图所示的装置进行甲烷与氯气在光照下反应的实验。（装置为密闭量筒或试管中充入 $CH_4$ 和 $Cl_2$ 的混合气体，倒置于饱和食盐水或水槽中，光照）

**思路**：该题考查甲烷氯代反应的条件、现象、反应类型和产物状态。需结合自由基取代机理，解释管壁油状液滴、水位上升、气体颜色变浅等现象。

**步骤**：
1. 气体为黄绿色（$Cl_2$ 的颜色），光照后颜色逐渐褪去，证明 $Cl_2$ 被消耗。
2. 反应生成 $HCl$，极易溶于水，导致试管内气压下降，液面上升。
3. 生成 $CH_3Cl$（气态）、$CH_2Cl_2$、$CHCl_3$、$CCl_4$（液态），其中有液态产物附着在管壁，形成油状液滴。
4. 白雾是 $HCl$ 与水蒸气结合形成的盐酸酸雾。
5. 反应属于取代反应，每取代一个 $H$ 消耗一个 $Cl_2$ 分子并生成一个 $HCl$ 分子。

**点评/变式**：本题为典型实验现象分析，难度较低但细节极易失分。变式考查常要求写出多步取代的化学方程式，或比较不同卤素（$F_2$、$Br_2$）反应的异同。注意 $F_2$ 与甲烷反应过于剧烈会爆炸，溴代需加热条件。解答时紧扣自由基机理、条件与产物状态，确保逐条有据。
