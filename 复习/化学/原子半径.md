## 知识精要
- **原子半径的定义**：通常指共价半径、金属半径或范德华半径，用于衡量原子的大小。
- **影响原子半径的主要因素**
  - 电子层数：层数越多，电子云离核越远，半径越大。
  - 核电荷数：电子层数相同时，核电荷数越大，原子核对最外层电子的吸引力越强，半径越小。
  - 电子间排斥：当电子层结构相同（如等电子离子）时，核电荷数越大，半径越小；同种元素的阴离子半径 > 原子半径 > 阳离子半径。
- **周期性变化规律**
  - 同周期（稀有气体除外）：从左到右，核电荷数递增，原子半径逐渐**减小**。
  - 同主族：从上到下，电子层数增加，原子半径逐渐**增大**。
  - 稀有气体原子半径比同周期卤素大，采用范德华半径比较。
- **微粒半径比较通则**（“三步法”）
  1. 先看电子层数：层数多者半径大。
  2. 层数相同时看核电荷数：核电荷数大者半径小。
  3. 若电子层数和核电荷数都相同（如$ \text{O}^{2-} $与$ \text{F}^- $、$ \text{Na}^+ $与$ \text{Mg}^{2+} $），再看核外电子数，电子数多者半径更大（但此条已隐含在离子比较中，注意$ r(\text{S}^{2-}) > r(\text{Cl}^-) > r(\text{K}^+) > r(\text{Ca}^{2+}) $等）。

## 解题方法与套路
1. **先推断元素种类与位置**  
   从题干给出的原子结构（如“只有1个电子”）、离子电荷与电子层结构相同、族关系等，快速确定元素符号及在周期表中的坐标。  
   例如：短周期中“$ b^{2-} $与$ c^+ $电子层结构相同”，立即锁定$ b $为第二周期ⅥA、$ c $为第三周期ⅠA，避免盲目猜测。
2. **画出简易位置关系图**  
   将推断出的元素在周期表草图中标出，直观展示同周期、同主族关系。
3. **比较原子半径时套用“层数—核电荷数”规则**  
   若需比较$ c $、$ b $、$ d $的原子半径，先看层数：$ c $、$ d $同处第三周期，层数>第二周期的$ b $；同周期$ c $（ⅠA）在$ d $（ⅥA）左侧，故$ r(c) > r(d) > r(b) $。氢原子半径极小，一般不做比较的重点。
4. **选项验证时结合物质组成与性质**  
   半径比较正确只是其中一个选项，还需检查化合价、二元化合物种类、水溶液酸碱性等，确保推断无误。

## 高频易错
- **推断离子所对应元素时出现跳跃**  
  误以为$ b^{2-} $与$ c^+ $电子层结构相同，就一定是$ \text{O}^{2-} $和$ \text{Na}^+ $，其实也可能是$ \text{S}^{2-} $和$ \text{K}^+ $，但题干限定短周期，$ \text{K} $不在短周期，故优先考虑$ \text{O} $和$ \text{Na} $。要养成验证周期的习惯。
- **氢元素的特殊化合价**  
  氢与非金属形成共价化合物时显$ +1 $价，但与活泼金属（如$ \text{Na} $）形成的离子型氢化物（$ \text{NaH} $）中，氢为$ -1 $价。本题A项若忽略这一点，极易错判。
- **原子半径比较中的定势错误**  
  看到$ a $（H）原子只有一个电子，就误以为半径最小，不过此处未涉及与其他原子半径的直接比较，但需警惕所有原子中H的原子半径并非最小（比H小的有He等）。在选项中判断“c的原子半径最大”时，必须确认所有元素，不能只看离子。
- **电子层结构相同≠原子半径相同**  
  $ b^{2-} $与$ c^+ $电子层结构相同（均为$ 2,8 $），但$ r(c > b) $，因为$ c $核电荷数大于$ b $，这是常见失分点。

## 代表题精讲
### **2016-新课标Ⅱ-03**
**题目**  
短周期元素a、b、c、d，a原子只有1个电子，$ b^{2-} $与$ c^+ $电子层结构相同，d与b同族。判断关于这四种元素叙述错误的选项。

**思路**  
由a原子只有1个电子，知a为氢（H）。$ b^{2-} $与$ c^+ $电子层结构相同且为短周期元素，只能推断b为氧（O），c为钠（Na），它们具有Ne原子（$ 2,8 $）电子构型。d与b同族，b是ⅥA族，d为硫（S）。  
然后逐项分析：A项关注H的化合价特殊性（NaH中H为$ -1 $）；B项考查O与H、Na、S形成二元化合物的多样性；C项比较原子半径，由位置关系可快速判断；D项验证H₂S的弱酸性。

**步骤**  
1. **元素推断**  
   - a：原子只有1个电子 → H（ⅠA，第一周期）。  
   - b、c：$ b^{2-} $与$ c^+ $电子层结构相同，且均短周期 → b为第二周期ⅥA的O，$ c^+ $为第三周期ⅠA的Na$^{+}$，离子结构均为$ 2,8 $。  
   - d：与b同族（ⅥA）且短周期 → d为S（第三周期）。  

2. **选项辨析**  
   - **A**：H与O形成$ \text{H}_2\text{O} $、$ \text{H}_2\text{O}_2 $，H显$ +1 $；H与S形成$ \text{H}_2\text{S} $，H显$ +1 $；但与Na形成NaH时，H得电子显$ -1 $价。故“化合价均为+1”错误，A错。  
   - **B**：O与H可形成$ \text{H}_2\text{O} $、$ \text{H}_2\text{O}_2 $；O与Na可形成$ \text{Na}_2\text{O} $、$ \text{Na}_2\text{O}_2 $；O与S可形成$ \text{SO}_2 $、$ \text{SO}_3 $，均至少两种，B正确。  
   - **C**：原子半径比较，Na有三层电子，半径远超二层的O和H；Na与S同周期，Na在左，半径大于S。所以Na原子半径最大，C正确。  
   - **D**：d与a形成$ \text{H}_2\text{S} $，其水溶液氢硫酸为弱酸，D正确。  
   错误项为A。

**点评/变式**  
本题以简单的结构信息考查元素推断、原子半径比较以及化合物性质，属于基础但易入坑的经典题型。  
- **易错警示**：必须牢记氢与活泼金属形成的氢化物中H为$ -1 $价，这是判断化合价“一律为+1”时的致命陷阱。  
- **拓展变式**：若将“d与b同族”改为“d与c同周期且最外层电子数为b的一半”，则d可能为Al或Si，需重新推断。解题逻辑不变：先准确定位元素，再调用半径比较规则和物质性质验证。  
- **半径比较口诀**：“层多径大，层同序大径小”，熟练运用可快速攻破周期表类选择题。
