## 知识精要
- **原子构成与微粒关系**  
  原子序数 $Z$ = 核电荷数 = 核外电子数（原子中）。短周期元素为 1～18 号，电子排布遵循构造原理。  
- **电子排布与结构表示**  
  最外层电子数决定元素的化学性质；次外层电子数可用于推断。8 电子稳定判据：分子中各原子最外层电子数（共用电子对均计入）达到 8（H 为 2），缺电子原子如 B 在 $BF_3$ 中为 6 电子结构。  
- **元素周期表结构关系**  
  周期序数 = 电子层数；主族族序数 = 最外层电子数。  
  特例：$Y$ 的周期数是族序数的 3 倍 → 第三周期第 ⅠA 族（Na）。  
- **成键特征与化合价**  
  非金属原子间形成共价键，金属与非金属间通常形成离子键（但 $Na_2O_2$ 等含共价键）。  
  最高正价 = 最外层电子数（O、F 除外），最低负价 = 最外层电子数 - 8。  
  常见成键数：H（1）、B（3，可形成配位键达 4）、C（4）、N（3）、O（2）、F（1）等。  
- **元素化合物的特殊性质（推断题突破口）**  
  - 红棕色有刺激性气味气体：$NO_2$（N 与 O 元素）  
  - 熔点最高的氧化物：$MgO$（W 与 Y 形成的 M，通常由 $MgO$ 推断）  
  - 单质能与水及醇反应生成氢气：碱金属 Na 等。  
  - 最高价氧化物水化物为强酸：$HNO_3$、$H_2SO_4$、$HClO_4$ 等。  

## 解题方法与套路
1. **锁定突破口**  
   从题干中提取元素特征：特殊性质（颜色、状态、气味、反应）、周期数与族序数关系、原子序数之和、电子层结构等。  
2. **建立假设验证**  
   如给定原子序数之和，列出可能元素，结合形成的化合物结构（共价键数、离子电荷）尝试匹配。  
3. **逐项验证选项**  
   推断出元素后，逐一判断选项：  
   - 化学键类型：同种非金属间非极性键，不同非金属间极性键；铵盐、含氧酸盐等含离子键和共价键。  
   - 化合物种类：O、N 等可有多种价态，形成多种二元化合物。  
   - 微粒半径比较：同周期从左到右半径减小，同主族从上到下半径增大；简单离子电子层结构相同时，核电荷数大者半径小。  
   - 最高价氧化物水化物酸性：非金属性越强，最高价含氧酸酸性越强；注意低价含氧酸未必是强酸（如 $HNO_2$ 弱酸）。  
4. **回代入题**  
   检验原子序数递增、所有条件均满足，防止遗漏细节（如短周期主族限定）。  

## 高频易错
- **8电子稳定结构的误判**  
  如 $BF_3$ 中 B 最外层 3 个电子参与形成 3 对共用电子，总数为 6，未达 8 电子；常见缺电子原子：Be、B、Al 等。  
- **离子化合物中是否只含离子键**  
  $Na_2O_2$ 含 $O-O$ 非极性共价键，$NH_4Cl$、$NaOH$ 等均含共价键。  
- **最高价氧化物水化物酸性与低价含氧酸混淆**  
  如 N 的含氧酸 $HNO_3$ 强酸，$HNO_2$ 弱酸；题目常考最高价态对应的酸性。  
- **电子层结构相同的离子判断**  
  $N^{3-}$、$O^{2-}$、$Na^+$ 等电子层结构相同，但 $Cl^-$ 比 $Na^+$ 多一电子层，结构不同。  
- **原子半径比较不看状态**  
  比较半径必须先看电子层数，层多半径大；同层时核电荷数越大半径越小。顺序可能为 $Na > N > O$ 等，而非理所当然。  

## 代表题精讲
### 题一：2020-新课标Ⅱ-07
**题目** 短周期主族元素 W、X、Y、Z 组成化合物（结构如图），原子序数依次增大且总和为 24。Z 形成 +1 价阳离子，X 形成 4 个共价键，W 形成 1 个共价键，Y 形成 3 个共价键。判断叙述错误的是。

**思路** 由 Z 为 +1 价阳离子且原子序数最大，推 Z 为 Na（短周期）。X 成 4 个键，可能为 C 或 B（B 可形成 3 个正常共价键后接受配位键达 4）。结合原子序数和为 24：设 W 为 H（1），Y 为 N（7），X 为 B（5），Z 为 Na（11），总和 1+5+7+11=24 吻合。验证结构：W（H）与 X（B）等均以共价键结合；Y（N）最高价氧化物的水化物 $HNO_3$ 为强酸；Na 与水、甲醇均反应产生 $H_2$。$BF_3$ 中 B 最外层电子数 3+3=6，不满足 8 电子。

**步骤**  
1. 确定元素：Z 是 Na；W 成 1 键 → H；X 成 4 键可能为 B（因 C 此时与 N 等序数不符）；余下 Y 为 N。  
2. 选项 A：共价键结合，正确。  
3. 选项 B：Na 与水、甲醇反应, 正确。  
4. 选项 C：$HNO_3$ 强酸，正确。  
5. 选项 D：计算 $BF_3$ 中 B 电子数 6，错误。故选 D。  

**点评/变式** 利用“成键数”和“原子序数和”协同推断是关键。注意 B 的缺电子本质，常成为 8 电子判据的陷阱。

### 题二：2018-新课标Ⅱ-04
**题目** W、X、Y、Z 为原子序数依次增大的短周期元素。W 与 X 生成红棕色刺激性气味气体；Y 周期数是族序数 3 倍；Z 最外层电子数等于 W 电子总数。判断叙述正确。

**思路** 红棕色刺激性气味气体是 $NO_2$，故 W 为 N，X 为 O。Y 周期数是族序数 3 倍，第三周期第 ⅠA 族为 Na。Z 最外层电子数 = W 电子总数 = 7（N 为 2+5），则 Z 为 Cl（第三周期，最外层 7 电子）。  

**步骤**  
1. 推断：W=N，X=O，Y=Na，Z=Cl。  
2. 选项 A：X（O）与其他三种元素：与 N 形成 NO、$NO_2$、$N_2O_5$ 等，与 Na 形成 $Na_2O$、$Na_2O_2$，与 Cl 形成 $ClO_2$、$Cl_2O_7$ 等，均两种或以上，正确。  
3. 选项 B：Y（Na）与 O 形成的 $Na_2O_2$ 含共价键，错误。  
4. 选项 C：简单离子 $N^{3-}$、$O^{2-}$、$Na^+$ 电子层结构相同，但 $Cl^-$ 多一电子层，不完全相同，错误。  
5. 选项 D：W 的氧化物水化物 $HNO_2$ 为弱酸，错误。故选 A。  

**点评/变式** 特征气体为推断核心。掌握“同一元素可形成多种二元化合物”是高频考点。易错点在于离子键与共价键并存、含氧酸强弱辨析。
