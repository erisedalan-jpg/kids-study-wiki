## 知识精要
- **杂化轨道理论**：原子在成键时，能量相近的原子轨道重新组合成一组能量相等、成分相同的新轨道（杂化轨道），使成键能力增强。常见杂化类型：
  - $sp$ 杂化：直线形，键角 $180^\circ$，有 $2$ 个 $\sigma$ 键（或 $\sigma$ 键与孤电子对之和为 $2$）。
  - $sp^2$ 杂化：平面三角形，键角 $120^\circ$，有 $3$ 个 $\sigma$ 键（或 $\sigma$ 键与孤电子对之和为 $3$）。
  - $sp^3$ 杂化：四面体形，键角约 $109.5^\circ$，有 $4$ 个 $\sigma$ 键（或 $\sigma$ 键与孤电子对之和为 $4$）。
- **判断杂化方式的核心方法**：对中心原子，使用**价层电子对互斥理论（VSEPR）**，计算价层电子对数 $n$：
  $$n = \frac{\text{中心原子的价电子数} + \text{配位原子提供的单电子数} \pm \text{电荷调节}}{2}$$
  配位原子为H或卤素时各提供1个单电子，O/S作配体时不提供。然后：
  - $n=2 \rightarrow sp$，$n=3 \rightarrow sp^2$，$n=4 \rightarrow sp^3$。
  - 也可通过 $\sigma$ 键数 $+$ 孤电子对数 $= n$ 直接得出。
- **杂化与分子空间构型**：注意孤电子对对键角的影响（挤压键角），并区别电子对构型和分子形状（如$sp^3$中有$\ce{NH3}$为三角锥形，$\ce{H2O}$为V形）。
- **第一电离能**：同周期从左到右总体增大，但ⅡA（$ns^2$全满）> ⅢA，ⅤA（$np^3$半满）> ⅥA。
- **未成对电子数**：依据基态原子的电子排布，画出轨道表示式判断。
- **氢键**：X–H…Y 形式，X、Y通常为N、O、F等电负性大、半径小的原子，常见 N–H…O、O–H…O 等。

## 解题方法与套路
1. **杂化类型快速判断**  
   - 给定分子或离子，先确定中心原子，画出结构简式或路易斯结构。
   - 计数中心原子的 $\sigma$ 键数目和孤电子对数，核对总数。
   - 总数 $=2 \Rightarrow sp$； $=3 \Rightarrow sp^2$； $=4 \Rightarrow sp^3$。  
   - 对于有机物中的C原子：若形成4个单键 $\rightarrow sp^3$；双键碳 $\rightarrow sp^2$；三键碳 $\rightarrow sp$。对于B常形成3个 $\sigma$ 键无孤电子 $\rightarrow sp^2$，但有配位键时可能成 $sp^3$。N原子依结构判断。

2. **未成对电子数比较**  
   - 写出基态电子排布（1s 2s 2p…），对于p区元素注意洪特规则。B：$2s^2 2p^1$，未成对1；C：$2s^2 2p^2$，2个；N：$2s^2 2p^3$，3个；O：$2s^2 2p^4$，2个。据此快速排序。

3. **第一电离能排序**  
   - 同周期趋势：从左到右递增，但要记住ⅡA、ⅤA的特殊稳定性，比较相邻元素时特别注意C、N、O的顺序：C < O < N（或有时考虑C < O < N）。涉及同族比较时，从上到下减小。

4. **氢键识别**  
   - 检查分子中是否存在与电负性原子相连的H（如N–H、O–H、F–H），且附近有其他分子或同一分子内的孤电子对受体（N、O、F）。晶体结构图中见到虚线连接H与O/N，通常为氢键。

5. **综合选择策略**  
   - 逐一审查选项，用排除法。先判断化学基础事实（如第一电离能顺序、未成对电子数），再分析结构相关选项（杂化、氢键）。不确定时结合图形与文字信息进行逻辑推理。

## 高频易错
- **杂化只看键数忽略孤电子对**：误以为 \(\ce{NH3}\) 中N形成3个键就为 $sp^2$，实际有1对孤电子，应为 $sp^3$。同样，$\ce{H2O}$ 为 $sp^3$，不是$sp^2$。
- **B的杂化误判**：通常B可形成3个共价键为 $sp^2$，但若形成4个 $\sigma$ 键（如与4个O原子成键）且无孤电子，则为 $sp^3$，不要思维定式。
- **第一电离能比较忽略特殊稳定性**：直接按C<N<O或C<O<N记忆常错。正确顺序是C < O < N。常考题：第二周期C、N、O的第一电离能比较，务必突出N的$p^3$半满。
- **未成对电子数只记原子序数**：O的电子排布为 $2s^2 2p^4$，p轨道有2个未成对电子，不是4个，与C相同。题目中B<C=O<N易错记成O多于C。
- **氢键判据遗漏**：只看到N–H，未寻找相邻的O或N作为受体，或者未注意到N–H…O的作用。微观结构中须学会识别氢键供体和受体。

## 代表题精讲
**题目**（2023新课标卷）给定一种可吸附甲醇的材料晶体部分结构，化学式为 $[\ce{C(NH2)3}][\ce{B(OCH3)4}]$，其中 $[\ce{C(NH2)3}]^+$ 为平面结构。判断选项正误。

**思路**  
结合给出的平面结构信息，推断 $[\ce{C(NH2)3}]^+$ 中C和N的杂化方式为 $sp^2$。观察 $[\ce{B(OCH3)4}]^-$，B接4个O形成4个 $\sigma$ 键，无孤电子，B为 $sp^3$ 杂化；O连B和C各1个 $\sigma$ 键，还有2对孤电子，故O为 $sp^3$ 杂化。由此可判定杂化类型。再根据第二周期元素性质比较第一电离能和未成对电子数，结合结构图寻找N–H…O氢键。

**步骤**
1. **判断氢键**（选项A）：分析 $[\ce{C(NH2)3}]^+$ 中含有–NH$_2$，其H可与四配位硼酸根中的O形成N–H…O氢键。从晶体结构图中能观察到相应短距离接触，故存在氢键，A正确。
2. **比较第一电离能**（选项B）：C、N、O同周期，第一电离能总体趋势增大，但N的$2p^3$半满稳定，实际顺序为 $\ce{C} (1086\ \mathrm{kJ \cdot mol^{-1}}) < \ce{O} (1314) < \ce{N} (1402)$，所以C<N<O错误，B错。
3. **比较未成对电子数**（选项C）：B基态为$1s^2 2s^2 2p^1$，有1个未成对电子；C为$1s^2 2s^2 2p^2$，2个；O为$1s^2 2s^2 2p^4$，2个；N为$1s^2 2s^2 2p^3$，3个。所以数量为 B(1) < C(2) = O(2) < N(3)，选项C称“B<C<O<N”不正确，C错。
4. **分析杂化类型**（选项D）：
   - 已知 $[\ce{C(NH2)3}]^+$ 为平面结构，中心C形成3个 $\sigma$ 键，无孤电子，C为 $sp^2$；每个N也形成3个 $\sigma$ 键（连C和两个H），无孤电子，也为 $sp^2$。
   - $[\ce{B(OCH3)4}]^-$ 中B形成4个B–O $\sigma$ 键，无孤电子，为 $sp^3$ 杂化。
   - 该离子中O原子连接两个原子（一个B，一个C），配有2对孤电子，价层电子对数 $=2+2=4$，因此O为 $sp^3$。
   可见晶体中B为 $sp^3$，N为 $sp^2$，O为 $sp^3$，杂化类型不完全相同，D错。
5. 综上，只有A正确。

**点评/变式**  
该题综合考查结构化学多个核心概念，一大难点是灵活判断杂化：不要仅凭“B通常$sp^2$”的经验，需根据配位数和孤电子对理性分析。变式训练：给出 $[\ce{NH4}][\ce{BF4}]$ 或类似离子液体，判断其中N、B、F的杂化方式，并比较第一电离能与未成对电子，巩固VSEPR应用和周期律。
