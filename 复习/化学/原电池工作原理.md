## 知识精要
1.  **定义与本质**：原电池是将**化学能转化为电能**的装置，其本质是基于**自发的氧化还原反应**。
    - 负极：发生**氧化反应**，失去电子。
    - 正极：发生**还原反应**，得到电子。
2.  **电极判断**：通常，**较活泼金属**作负极，但需结合具体电解质环境判断。如本题中 $Mg$ 比 $Ag$ 活泼，且能与电解质海水反应，故作负极。
3.  **电极反应式书写**：
    - **负极**：$Mg - 2e^- = Mg^{2+}$（自身放电）。
    - **正极**：**氧化剂**在正极表面得电子。本题中，正极材料 $AgCl$ 是难溶物，在电极反应式中**不拆开**书写，即：$2AgCl + 2e^- = 2Ag + 2Cl^-$。
    - **副反应**：活泼金属负极可与电解质溶液中的水直接发生氧化还原反应，如：$Mg + 2H_2O = Mg(OH)_2 \downarrow + H_2 \uparrow$。
4.  **离子迁移**：
    - **阴离子** ($Cl^-$、$SO_4^{2-}$等) 向**负极**迁移。
    - **阳离子** ($K^+$、$Na^+$等) 向**正极**迁移。
    - 巧记：异性相吸，正正负负（正离子去正极，负离子去负极）。

## 解题方法与套路
1.  **审题定两极**：快速识别题干中的电池体系，根据金属活泼性、元素化合价升降，明确电池的**负极（还原剂）** 与**正极（氧化剂）**。
2.  **书写半反应**：
    - 先写负极反应式，遵循“价态守恒、电荷守恒、原子守恒”。
    - 再依据氧化剂，并结合电解质环境，写出正极反应式。
    - **特别关注**：电极材料、氧化物、难溶盐等在书写离子方程式时**保留化学式**。
3.  **判定离子行为**：根据“**阴离子移向负极，阳离子移向正极**”判断溶液中离子的迁移方向。
4.  **排查干扰选项**：
    - 检查有无**副反应**（如本题中镁与水反应）。
    - 检查电子守恒、电荷守恒有无错误。
    - 检查物质拆分形态（是否忽略难溶物）。

## 高频易错
- **陷阱1：忽视电极材料的溶解性与存在形式。** 切忌见到 $Ag^+$ 就写 $Ag^+ + e^- = Ag$，本题中正极材料是难溶的 **$AgCl$ 固体**，不能拆成离子形式书写。
- **陷阱2：混淆离子迁移方向。** 误以为负离子（$Cl^-$）向正极移动。应牢记：负极发生氧化反应产生阳离子，为保持溶液电中性，阴离子向负极区域迁移。
- **陷阱3：遗漏竞争反应（副反应）。** 只分析电化学过程，忽略了活泼金属（如 $Mg$、$Al$、$Na$）本身能与电解质溶液（水、酸）发生直接的化学置换反应，导致放电效率下降。
- **陷阱4：电极正负与阴阳极的术语混用。** 在原电池中，输出电子的永远是**负极**（对内电路称阳极）。

## 代表题精讲
**题目**：以海水为电解质的 $Mg-AgCl$ 水激活电池，判断叙述错误的是。

**思路**：
先定性分析电池，$Mg$ 比 $Ag$ 活泼，肯定作负极，那 $AgCl$ 就作正极。然后检查各个选项：A、B 直接考电极反应式的书写，关键在于反应物是否拆分正确。C 考离子迁移，是基本规则。D 提醒我们思考活泼金属有没有副反应。

**步骤**：
1.  **分析负极**：镁失去电子，$Mg - 2e^- = Mg^{2+}$。**A 项叙述正确。**
2.  **分析正极**：氧化剂是难溶的氯化银，得电子被还原为单质银，同时释放出氯离子进入溶液。反应式为 $2AgCl + 2e^- = 2Ag + 2Cl^-$，**而非** $Ag^+ + e^- = Ag$。**B 项将 $AgCl$ 错写为 $Ag^+$，叙述错误，即为答案。**
3.  **分析离子迁移**：放电时，正极不断产生阴离子 $Cl^-$，浓度增高，同时负极阳离子增多，阴离子会由正极区向负极区迁移。**C 项叙述正确。**
4.  **排查副反应**：金属镁化学性质活泼，常温下即可与水反应，生成氢氧化镁和氢气：$Mg + 2H_2O = Mg(OH)_2 \downarrow + H_2 \uparrow$。这会造成负极材料的额外损耗。**D 项叙述正确。**

**点评/变式**
- **核心教训**：解答此类题的最大障碍是习惯性思维，自动将正极材料当成离子形式。务必看清题目所给物质。
- **变式**：若将此电池的电解质换为 $NaOH$ 溶液，并且负极材料换为 $Al$，则负极反应式变为 $Al - 3e^- + 4OH^- = [Al(OH)_4]^-$。若问及正极，依然是 $AgCl + e^- = Ag + Cl^-$。可见，书写电极反应式，必须紧密结合电极材料和电解质环境。
