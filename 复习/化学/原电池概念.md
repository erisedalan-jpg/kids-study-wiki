## 知识精要
- **根本判据**：只有自发进行的**氧化还原反应**才能设计成化学电源。自发反应一定是 $\Delta G \lt 0$ 的反应。
- **总反应辨识**：原电池的总反应是氧化反应与还原反应之和。根据装置图中不同半电池，能写出自发的总离子方程式。
- **正/负极判断**：
    - **负极**：较活泼金属，发生**氧化**反应，电子流出。
    - **正极**：较不活泼金属（或导电非金属），发生**还原**反应，电子流入。
- **电极方程式书写**：
    - 先写“负氧正还”的主体物质变化。
    - 再根据电解质环境（酸性、碱性、熔融盐、非水溶剂等）补充 $H^+$ 或 $OH^-$ 等，使电荷守恒。
    - 最后用原子守恒配平（常需补水）。
    - 示例（如真题场景）：$Cd+2Ag^+ = 2Ag+Cd^{2+}$，负极：$Cd-2e^- = Cd^{2+}$，正极：$2Ag^+ + 2e^- = 2Ag$。
- **离子移动方向**：
    - 在外电路，电子从负极移向正极。
    - 在内电路（电解质溶液），阳离子移向正极，阴离子移向负极。
- **析氢与吸氧腐蚀规律**：当正极材料比氢气活泼时，正极自身得电子（析出金属），不发生析氢反应。（真题中 Cd 比 Co 活泼，故装置 I 中并不析出氢气，而是直接发生金属离子的还原）。

## 解题方法与套路
1. **判断氧化还原方向**：读题后，快速标出所有装置中涉及的元素化合价，确定“氧化剂”和“还原剂”，依据金属活动性顺序或非金属强弱，写出自发进行的离子方程式。总反应总是强还原剂制取弱还原剂。
2. **匹配电极与总反应**：
   - 负极区的反应物一定是总反应中的还原剂，产物是氧化产物。
   - 正极区的反应物一定是总反应中的氧化剂，产物是还原产物。
3. **拆写、检查电极方程式**：
   - **步骤**：标化合价变价 → 写主体得失电子数 → 添介质离子（水溶液中避免出现 $O^{2-}$ 等）使电荷守恒 → 补水或其他分子使原子守恒。
   - **检查原则**：两电极方程式相加必须恰好等于总离子方程式（电子抵消，介质及水若出现也必须消除）。
4. **设计原电池验证**：若要求判断给定反应能否自发，可设计双液原电池。自发的反应设计为放电过程；非自发的，接上外电源后即为电解池。

## 高频易错
- **错误判断自发性**：本题极易错选非自发反应选项。题干装置通常给出多个原电池，它们自身都是自发的。若所给离子方程式在给定的装置方向上是非自发的（即实际装置发生的是该反应的逆向），则该方程式错误。必须严格对照装置标注的电极材料。
- **混淆电极符号与电极产物**：直接将电极材料当作反应物或产物。负极材料可能参与反应（如 $Cd$ 溶解为 $Cd^{2+}$），也可能只作惰性载体。要依据总反应确定实际失电子物质。
- **无视“析氢/析金属”的条件**：错误认为正极一定有气体产生。当负极比氢气活泼但正极存在比氢气更不活泼的金属离子（如 $Co^{2+}$）时，优先析出金属单质（$Co$），而非 $H_2$。本质是比较正极区各氧化剂（$H^+$ 与 $Co^{2+}$）的氧化性强弱。
- **离子方程式中物质拆分疏漏**：将难溶金属（如 $Ag$、$Co$、$Cd$）错误拆成离子形式书写；或将可溶强电解质（如 $Cd^{2+}$）误写成化学式。
- **电荷不守恒**：书写电极反应时常漏写电子数或离子电荷数，导致加和时电子不抵消。

## 代表题精讲
**题目**：（2010 全国新课标）根据右图（两原电池装置串联/独立比对，电极分别涉及 $Ag$、$Cd$、$Co$），判断下列离子方程式中错误的是哪个。给定选项涉及 $Ag/Cd^{2+}$、$Co^{2+}/Cd$ 体系等。

**思路**：
本题核心是依据装置图，分别写出两套装置中发生的自发的总反应，然后与四个选项逐一比对。装置 I 给了 $Ag$ 和 $Cd$ 电极，装置 II 给了 $Co$ 和 $Cd$ 电极，已知 $Cd$ 比 $Co$ 活泼。
1.  先判断装置 I：$Cd$ 更活泼，为负极，负极溶解生成 $Cd^{2+}$；正极 $Ag^+$ 得电子析出 $Ag$。装置 I 的总反应为 $Cd + 2Ag^+ = Cd^{2+} + 2Ag$。
2.  再判断装置 II：$Cd$ 仍更活泼，为负极，负极溶解生成 $Cd^{2+}$；正极 $Co^{2+}$ 得电子生成 $Co$（单质钴为固体）。装置 II 的总反应为 $Cd + Co^{2+} = Cd^{2+} + Co$。
3.  看选项判断自发性。原电池的自发方向是强还原剂制弱还原剂。若选项给出的离子方程式方向与上述两个自发反应相反，则该反应在该条件下非自发，为错误选项。

**步骤**：
1.  **分析装置 I**：负极 $Cd - 2e^- = Cd^{2+}$，正极 $2Ag^+ + 2e^- = 2Ag$。总反应：$Cd(s) + 2Ag^+(aq) = Cd^{2+}(aq) + 2Ag(s)$。该反应正向自发。
2.  **分析装置 II**：负极 $Cd - 2e^- = Cd^{2+}$，正极 $Co^{2+} + 2e^- = Co(s)$。总反应：$Cd(s) + Co^{2+}(aq) = Cd^{2+}(aq) + Co(s)$。该反应正向自发。
3.  **对照选项确定错误项**：选项 A 给出的反应为 $2Ag(s) + Cd^{2+}(aq) = 2Ag^+(aq) + Cd(s)$，这恰好是装置 I 正向自发的总反应的反方向，为非自发反应。如果将 $Ag$ 作负极、$Cd$ 作正极，装置不可能产生电流。因此该方程式是错误的。

**点评/变式**：
- **点评**：此题考查了“设计原电池”与“判断反应自发性”的底层逻辑：原电池反应一定是氧化还原自发反应。任何违背了电极提供者自发能力的方程式，即使配平正确也是错误的。需要结合装置给定的电极材料判断实际发生的是哪一方向的反应。
- **变式训练**：题干若变更为给出 $Ag、Cu、Fe$ 三种金属片段和对应的离子，要求书写所有可能构成的原电池的总反应方程式，并判别给定半反应的错误之处。解题核心不变：抓住“两金属电极，活泼的做负极，自发的总反应固定唯一”这一规律。
