## 知识精要
- **反应机理**：描述化学反应经历的基元步骤，显示旧键断裂与新键形成的具体过程。常通过循环图（催化循环）呈现，包含反应物、产物、催化剂、中间体及过渡态。
- **催化剂特征**：参与反应改变路径，但本身在反应前后质量和化学性质不变；在循环图中表现为“进→出→再生回原点”。
- **中间体**：反应过程中生成、随后又被消耗的物种（非反应物/产物，不出现在总反应中）。循环图中除起点（催化剂）外，其余循环节点一般为中间体。
- **总反应方程式的推导**：将循环框图中的物质进行物料守恒加和，消去中间体和催化剂，得到净反应。从净反应可快速判断反应物消耗与产物生成。
- **元素成键数目变化**：根据中心原子在循环中不同物种的结构（配位数、化学键种类）推断成键数目是否变化。如 $\ce{Fe(CO)5}$ 中 Fe 的成键数为 $5$，$\ce{Fe(CO)4}$ 中为 $4$ 等。
- **配位催化与能源/环境关联**：过渡金属配合物催化可将小分子（$\ce{CO, H2O}$ 等）转化为清洁能源（$\ce{H2}$）或转化温室气体，注意区分“消耗温室气体 $\ce{CO2}$”还是“产生 $\ce{CO2}$”。

## 解题方法与套路
1. **锁定循环起点与催化剂**：识别图形中起始和最终相同的物种（如 $\ce{Fe(CO)5}$），该物种即为催化剂。
2. **顺着箭头逐一写出各步转化**：将图中标注的每一步反应物与生成物标记完整（注意 $\ce{OH-、H2O、H+}$ 等小分子的进出）。
3. **写出总反应**：将分步反应相加，消去中间体和催化剂，得到净反应方程式。如本题总反应为 $\ce{CO + H2O = CO2 + H2}$。
4. **以总反应为基准判断选项**：
   - 被消耗的才是反应物，被生成的才是产物。
   - 参与循环但不出现在总反应中的是催化剂或中间体。
   - 若问“消耗 $\ce{CO2}$”，必须看总反应中 $\ce{CO2}$ 在反应物一侧还是生成物一侧。
5. **分析成键数目变化**：对比循环中同一元素不同物种的配位数或结构，凡配位键、共价键总数改变，则成键数目发生变化。

## 高频易错
- **混淆消耗与产生**：误将“反应中出现了某物质”等同于“该物质被消耗”。必须看总反应还是在某步作为生成物？本题错误选项 C 即因总反应产生 $\ce{CO2}$，而非消耗 $\ce{CO2}$。
- **忽略催化循环的闭合性**：催化剂最后必须再生，误将某步消耗催化剂当作催化剂被消耗殆尽。
- **漏看循环中的小分子/离子**：如 $\ce{OH-、H2O、H+}$ 在图中的进出，容易漏加，导致总反应推导错误。
- **成键数目判断随意**：仅凭猜测而不对比具体结构。必须根据各物种明确写出的形式判断配位数和共价键，如 $\ce{Fe(CO)5}$ 与 $\ce{Fe(CO)4}$、$\ce{Fe(CO)4H2}$ 等。
- **循环图中方向看反**：箭头指向是生成方向，逆箭头误判为反应步骤。

## 代表题精讲
### **题目**  
（2020 新课标Ⅱ卷）文献报道 $\ce{Fe(CO)5}$ 催化某反应的一种反应机理如图所示。下列叙述错误的是  
A．$\ce{OH-}$ 参与了该催化循环  
B．该反应可产生清洁燃料 $\ce{H2}$  
C．该反应可消耗温室气体 $\ce{CO2}$  
D．该催化循环中 $\ce{Fe}$ 的成键数目发生变化  

### **思路**  
先解读机理图，写出各步转化，导出总反应。再根据总反应判断消耗/生成何种气体，以及 $\ce{OH-}$ 是否参与循环、$\ce{Fe}$ 成键数目是否变化。

### **步骤**  
1. 从机理图推导循环步骤（由题干解析给出）：  
   $\ce{Fe(CO)5 -> Fe(CO)4COOH- -> Fe(CO)4H- + CO2 -> Fe(CO)4(HOH)H- -> Fe(CO)4(H)2 + OH- -> Fe(CO)4H2 -> Fe(CO)4 + H2 -> Fe(CO)5}$  
2. 将各步加和，消去中间物种和催化剂，得总反应：$\ce{CO + H2O = CO2 + H2}$。  
3. 依据总反应判断：  
   - $\ce{OH-}$ 出现在循环中，多步涉及，A 正确。  
   - 产物有 $\ce{H2}$，为清洁燃料，B 正确。  
   - $\ce{CO2}$ 在产物一侧，反应产生 $\ce{CO2}$，并非消耗，C 错误。  
   - $\ce{Fe}$ 在循环里先后形成 $\ce{Fe(CO)5}$、$\ce{Fe(CO)4COOH-}$、$\ce{Fe(CO)4H-}$、$\ce{Fe(CO)4(HOH)H-}$、$\ce{Fe(CO)4(H)2}$、$\ce{Fe(CO)4H2}$、$\ce{Fe(CO)4}$，配位数及成键形式变化，成键数目改变，D 正确。  
4. 选错误叙述为 C。

### **点评/变式**  
本题核心：从复杂催化机理图中抓出净反应，进而避开各种“参与”“生成”的文字陷阱。循环图中只要某物种最终未净消耗，则不能称“该反应消耗它”，除非指明在某基元步骤中。  
**变式预测**：可能出现不同催化剂（如 $\ce{Ru}$、$\ce{Co}$ 配合物）催化水煤气变换反应或 $\ce{CO2}$ 加氢的机理图，要求判断总反应、催化剂、中间体、成键变化，还可能结合能量变化图考查决速步与活化能。保持方法不变：先推导净反应，再作答。
