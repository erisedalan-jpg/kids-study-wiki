## 知识精要
1. **取代反应**
   - 定义：有机物分子里的某些原子或原子团被其他原子或原子团所替代的反应。
   - 特点：有上有下、饱和结构偏好、不改变分子整体的不饱和度。碳骨架一般不断裂。
   - 常见类属：卤代（烷烃光卤代、苯的同系物卤代）、硝化、磺化、酯化、水解（卤代烃水解、酯水解）、醇分子间脱水成醚等。
2. **加成反应**
   - 定义：有机物分子中不饱和碳原子与其他原子或原子团直接结合生成新化合物的反应。
   - 特点：只上不下、通常发生在不饱和键（C=C、C≡C、C=O、苯环加氢等）上，产物不饱和度降低。
   - 常见类属：烯/炔与H₂、X₂、HX、H₂O的加成，醛/酮与H₂、HCN的加成，苯环加氢。
3. **消去反应**
   - 定义：有机物分子中脱去一个小分子（如水、卤化氢等），生成不饱和化合物的反应。
   - 特点：只下不上、分子内形成不饱和键（C=C或C≡C）。
   - 条件提示：醇的消去（浓硫酸、加热）、卤代烃的消去（强碱醇溶液、加热）。
4. **氧化反应与还原反应（有机视角）**
   - 氧化：加氧去氢（如醇→醛→酸，烯烃被KMnO₄氧化）。
   - 还原：加氢去氧（如醛/酮加氢还原成醇，硝基苯被还原成苯胺）。
5. **快速判断法**
   - 看碳原子化学键变化：双键消失或单键变双键可能是加成或消去；官能团互换不变键数常为取代。
   - 看反应物特征：反应物全部转化为产物且无小分子脱落（加成）；产物中出现两种以上物质（取代）；生成不饱和键（消去）。

## 解题方法与套路
1. **题干信息抓特征法**
   - 瞄准关键条件：如“与饱和碳酸氢钠不反应”→无-COOH；“能发生银镜反应”→有-CHO或HCOO-。这些条件限定了官能团，进而排除或锁定反应类型。
   - 利用已知信息：题干中给出的“已知反应”揭示了特定官能团的转化规律（如酰胺化、成环反应），必须将其与熟悉的取代、加成等基本类型对应。
2. **结构对比还原法（强用于有机推断流程图）**
   - 锁定目标：对比相邻两种物质（如A→B）的碳骨架和官能团变化。
   - 逐原子核对：哪里的化学键变了？碳原子数增减？是否引入杂原子？
   - 映射反应：引入两个基团且无不饱和键变化→取代；双键打开→加成；形成双键且有H₂O等脱去→消去；醛基变羧基→氧化。
3. **无机反应类型排除（选择/辨析题）**
   - 四大基本反应类型（化合、分解、置换、复分解）与有机反应类型辨析时，务必紧扣“有机物分子中的键变化”。
   - 反应若记不清，从断键和成键方式反推：断了一个单键、形成了一个单键且两边连的原子/基团互换，必为取代。

## 高频易错
1. **酯化反应类型的误解**
   - 陷阱：酯化反应中羧酸脱羟基、醇脱氢，生成酯和水，断键在C-O和O-H，实质是取代反应，极易误判为中和或其他类型。
   - **牢记**：酸和醇的酯化本质上属于取代反应。
2. **硝化、磺化等“化的归属**
   - 苯环上引入硝基(-NO₂)、磺酸基(-SO₃H)的过程，苯环上H被替换，属于取代反应。
3. **加成与化合的混淆**
   - 乙烯使溴水褪色（生成1，2-二溴乙烷），虽然反应物变成单一产物，但因发生在有机物的不饱和键上，属于**加成反应**，不能单纯称之为化合反应。
4. **水解反应的双重身份**
   - 卤代烃、酯、酰胺、多肽等的水解，断裂C-X、C-O等异裂，产物分为两类，本质上都是**取代反应**。
5. **“不能与碳酸氢钠反应”的陷阱**
   - 此结论仅证明无-COOH，化合物仍可能含酚羟基、醇羟基等，可发生酯化（取代）、氧化等反应，不能直接排除所有反应活性位点。

## 代表题精讲
### **题目**1：2022-全国乙-12节选
某药物中间体合成路线中，已知化合物F不能与饱和碳酸氢钠溶液反应产生二氧化碳。分析A→B、B→C、E→F、F→G的反应类型。
**思路**
1. 审题干限定：“F不能与NaHCO₃反应”→F不含羧基(-COOH)，E→F的反应必不是生成-COOH的氧化反应，而只能是官能团的保护、取代或消除后重建。
2. 运用结构对比法：逐对分解流程图中的结构片段（虽无图形，按经验类推），重点排查酰胺键、氨基、氰基及羟基保护基的生成与转化。
3. 定类型：有机合成以取代反应为核心骨架构建方式，涉及官能团转化多数是取代（如酰氯化、成酰胺、水解）。若有双键或环的生成/打开才可能是加成或消去。

**步骤**
1. A→B常为引入保护基或活化基团，比如酰氯与胺反应生成酰胺，旧键断裂、新键生成，属于**取代反应**。
2. B→C若有氰基引入或增长碳链，通常是卤代烃与NaCN的取代，为**取代反应**。
3. 由题意“F不能与NaHCO₃反应”，推测若其前体含酯基或氰基，E→F发生了水解却未生成酸，那只能是氰基部分水解成酰胺基(取代)或酯基醇解(取代)，均属**取代反应**。
4. F→G生成最终产物，若涉及开环或还原氰基，可能为加成或还原，但在合成尾端常为脱保护基的**取代反应**。

**点评/变式**
此题的题眼在于用“不能与饱和碳酸氢钠反应”预先排除了羧酸，反证了全部转化均不涉及将非羧酸基团氧化成羧基。应考时遇到此类“已知”条件，必须将其作为结构特征锁定范围，然后在取代、加成、消去三足鼎立中，根据原子经济性和产物结构平稳推定为主的取代反应。

### **题目**2：2011-新课标-03
下列反应属于取代反应的是：
①CH₃CH=CH₂+Br₂ → CH₃CHBrCH₂Br
②CH₃CH₂OH → CH₂=CH₂+H₂O
③CH₃COOH+CH₃CH₂OH → CH₃COOCH₂CH₃+H₂O
④C₆H₆+HNO₃ → C₆H₅NO₂+H₂O

**思路**
逐一辨析四道反应的化学键与官能团变化，按定义直接归类。有机反应中分子间脱除小分子生成新化合物的多半是取代。

**步骤**
1. 反应①：丙烯C=C双键打开，两端各加一个溴原子，分子式由C₃H₆变C₃H₆Br₂，不饱和度降低一位，仅加入原子未脱去，是**加成反应**。
2. 反应②：乙醇分子内脱去一分子水，生成了C=C双键，属于**消去反应**。
3. 反应③：羧酸(-COOH)脱-OH、醇脱-H，结合生成酯和水，酸与醇通过脱小分子交换了官能团，断键在C-O和O-H，属**取代反应（酯化）**。
4. 反应④：苯环上一个H被-NO₂替代，产物仍是环状结构，不饱和度不变，是典型的**取代反应（硝化）**。
  综上，③④为取代反应。

**点评/变式**
本题属反应类型直接定性，失分点在于把①②误判。记牢口诀：双键打开是加成，分子内脱水是消去，酯化硝化皆是取代。变式可把反应条件更模糊化，或与给定的未见过信息反应比对归类，本质不变。
