## 知识精要
- **可逆反应**：在同一条件下，既能向正反应方向进行，又能向逆反应方向进行的反应。  
- **可逆反应的本质特征**：  
  - 同条件：正、逆反应在完全相同的外部条件（温度、压强等）下同时进行。  
  - 双向性：反应混合物中反应物和生成物始终共存，反应无法进行到底。  
  - 动态平衡：达到平衡时 $v_{\text{正}} = v_{\text{逆}} \neq 0$，各组分浓度保持恒定。  
- **与“不可逆反应”的区别**：  
  - 不可逆反应一般指单向趋于完成（如沉淀、气体逸出、水生成等使离子浓度显著降低），或正逆反应条件不同（如电解与电池放电）。  
  - 大多数化学反应均有一定可逆性，但高中阶段常通过“反应物是否大量剩余”“能否在同一体系共存”来判断。  
- **可逆反应的常见实例**：  
  - $\ce{Fe^3+ + 3SCN- <=> Fe(SCN)3}$（血红色溶液，检定 $\ce{Fe^3+}$ 常用）  
  - $\ce{2SO2 + O2 <=>[催化剂][\Delta] 2SO3}$、$\ce{N2 + 3H2 <=> 2NH3}$  
  - $\ce{Cl2 + H2O <=> HCl + HClO}$  
- **证明可逆反应的方法**：  
  设计实验证实反应物不能完全转化。如在某一反应物过量时，另一反应物经充分反应后仍有剩余；或产物与反应物在相同条件下共存。  

## 解题方法与套路
1. **鉴别实验能否证明可逆性**  
   - 关键看是否满足“同条件共存”。选项中若设计“反应物恰好完全反应”或“某物质过量使反应物耗尽”，则不能直接证明可逆。  
   - 典型陷阱：$\ce{Fe^3+ + I-}$ 体系，若 $\ce{KI}$ 过量，$\ce{Fe^3+}$ 仍被检出，不可简单得出“可逆”，因为有可能是反应未达平衡或动力学滞留，需进一步验证平衡移动或设计半量反应。

2. **判断结论表述的正误**  
   - 结论中若出现“该反应为可逆反应”，须回溯实验现象是否证实反应物和产物在终态中同时存在且反应未进行到底。  
   - 同时排除试剂过量、副反应、环境条件不一致等因素干扰。

3. **结合控制变量思想**  
   - 证明可逆性常采用“限制一种反应物的量，检测其是否剩余”的方式。例如：$n(\ce{Fe^3+}) : n(\ce{I-}) = 1:1$ 少量反应，检测 $\ce{Fe^3+}$ 或 $\ce{I2}$ 的存在。  
   - 若反应物以极稀浓度共存，有时还需辅助其他平衡反应联合推理。

4. **关注隐含平衡的表述**  
   - 氯水性质中 $\ce{Cl2}$ 与 $\ce{H2O}$ 存在平衡，涉及次氯酸的漂白、杀菌等，解释现象时常从平衡移动角度切入。

## 高频易错
- **混淆“反应未完全”与“可逆反应”**  
  反应未完全可能是速率不足、条件不充分或副反应消耗，不一定是同一条件下的双向可逆反应。必须根据正逆反应条件是否一致判别。  
- **对照实验缺失**  
  仅凭一种配比下检出了剩余反应物，就结论“可逆”，忽略可能正好是反应物过量导致，属于逻辑不严密。  
- **忽略反应条件变化**  
  如电解、高温分解产物在常温下不再反应，这不属于可逆反应范畴（条件不同）。  
- **沉淀转化与可逆性的混淆**  
  利用 $K_{sp}$ 大小比较导出的沉淀转化是单向宏观过程，不能简单等同于可逆反应，尽管溶液中存在固-液溶解平衡，但不是通常考查的可逆反应。  
- **文字游戏**：选项结论中“能说明”“证明了”“可得出”的强度不同，审题不准导致失分。

## 代表题精讲
### 【代表题】2022-全国乙-04（实验操作、现象与结论）
**题目**  
给出四个独立的实验方案，每个方案包含操作、现象及结论，要求选出结论正确的选项。其中C选项涉及可逆反应条件的考查：  
- A. $\ce{NaBr}$ 溶液滴加过量氯水，再加淀粉 $\ce{KI}$ 溶液，先变橙色后变蓝，结论氧化性 $\ce{Cl2 > Br2 > I2}$。  
- B. 蔗糖溶液稀硫酸水浴加热，加新制 $\ce{Cu(OH)2}$ 悬浊液，无砖红色沉淀，结论蔗糖未水解。  
- C. $\ce{KI}$ 溶液与少量 $\ce{FeCl3}$ 溶液反应后，滴加 $\ce{KSCN}$ 溶液，溶液变红，结论 $\ce{Fe^3+}$ 与 $\ce{I-}$ 的反应为可逆反应。  
- D. $\ce{AgNO3}$ 溶液先加 $\ce{NaCl}$ 生白色沉淀，再加 $\ce{KI}$ 沉淀变黄，结论 $K_{sp}(\ce{AgCl}) > K_{sp}(\ce{AgI})$。

**思路**  
- 本题逐项判断实验设计能否支撑结论。  
- 判断的关键在于试剂用量是否受控、干扰是否排除、现象与结论之间有否必然逻辑联系。  
- C选项直接关联“可逆反应”的证明：$\ce{2Fe^3+ + 2I- -> 2Fe^2+ + I2}$，若反应完全且 $\ce{Fe^3+}$ 少量，则 $\ce{Fe^3+}$ 应完全消耗，加 $\ce{KSCN}$ 不应显红色。显红说明 $\ce{Fe^3+}$ 有剩余，在 $\ce{KI}$ 过量的条件下，至少说明反应未进行到底，体系存在平衡状态，从而支持该反应为可逆反应。

**步骤**  
1. **分析A**：过量氯水会把 $\ce{KI}$ 直接氧化，$\ce{Br2}$ 与 $\ce{I-}$ 的反应被掩盖，无法比较 $\ce{Br2}$ 与 $\ce{I2}$ 的氧化性顺序。结论不成立。  
2. **分析B**：稀硫酸作催化剂，水浴加热后必须加 $\ce{NaOH}$ 中和酸并使环境呈碱性，才能与 $\ce{Cu(OH)2}$ 检验葡萄糖，无砖红色沉淀可能因为酸性环境破坏了检验条件，不能得出未水解的结论。  
3. **分析C**：$\ce{KI}$ 溶液为过量，少量 $\ce{FeCl3}$ 本应完全转化。若反应为彻底的不可逆反应，则溶液中无 $\ce{Fe^3+}$，加入 $\ce{KSCN}$ 不会变红。现象变红，表明 $\ce{Fe^3+}$ 未完全消耗，反应物与产物在同一条件下共存，故反应存在可逆性（或存在平衡）。因此该结论正确。  
4. **分析D**：$\ce{AgNO3}$ 先加 $\ce{NaCl}$ 生成 $\ce{AgCl}$ 沉淀，未消耗完的 $\ce{Ag+}$ 直接与后续 $\ce{KI}$ 反应生成 $\ce{AgI}$，并非沉淀 $\ce{AgCl}$ 转化为 $\ce{AgI}$，不能比较 $K_{sp}$ 大小。结论错误。  
综合，正确选项（结论成立）为C。

**点评/变式**  
- 本题通过实验设计巧妙考查了可逆反应概念的实验验证，是高考区分度的着力点。  
- 变式训练：若改为“取少量反应后的溶液，加淀粉溶液变蓝，说明生成 $\ce{I2}$，但能否证明反应为可逆？”不能，仅证明正反应发生，未涉及逆反应。需结合“反应物离子仍可检出”双项证据才能推向可逆。  
- 常
