## 知识精要
- **守恒法的核心思想**：在任何化学过程中（化学变化、溶解、稀释、热分解等），某些物理量保持恒定不变。它是定量计算的基本依据，常用来绕过繁琐的中间过程，快速求解。
- **常考守恒类型**
  - **质量守恒**：反应前后或过程前后总质量不变。在热重分析、混合物反应中用于计算某组分的质量、质量分数、失重率。
  - **原子（元素）守恒**：任一元素的原子种类和数目在变化前后不变。常用于推断未知物化学式、判断产物、配平方程式。
  - **电荷守恒**：电解质溶液中阳离子所带正电荷总数等于阴离子所带负电荷总数。用于比较离子浓度、推断离子组成。
  - **电子守恒（化合价升降守恒）**：氧化还原反应中，氧化剂得电子总数等于还原剂失电子总数。用于计算氧化剂 / 还原剂的量、产物中元素的化合价。
- **适用条件**：
  - 过程明确，能列出反应式或变化关系时优先使用。
  - 若整体过程复杂，可直接对始态与终态列守恒关系（如元素守恒、电子守恒），不一定要写出每一步方程式。
  - 热重曲线类题中，利用每一平台对应的恒定质量（质量守恒）分析失去的小分子组成及数目。

## 解题方法与套路
1. **锁定守恒对象**
   读题时明确所求量所涉及的守恒类型：涉及质量 → 质量守恒；求化学式 → 原子守恒；涉及氧化还原 → 电子守恒；溶液中离子浓度比较 → 电荷守恒。
2. **搭建守恒框架**
   列出反应或过程的始态和终态，找出其中不变的量。如热重曲线题：原始总质量 = 某温度残留固体质量 + 逸出气体总质量。
3. **联立已知数据**
   将题目给的数据（相对分子质量、原子序数、失重百分率、物质的量等）代入守恒关系，建立代数方程。
4. **结合元素推断突破**
   对于物质推断题，先用原子守恒、电子总数奇偶性等微观信息确定元素，再用质量守恒确定化学式中的结晶水个数或分子组成。
5. **验证与作答**
   计算出的数据代入选项或设问中验证是否合理，再确定最终答案。注意单位、物质的状态以及题目特殊要求（如无刺激性气体逸出等）。

## 高频易错
- **忽视中间产物的干扰**：有些热分解过程并非一步完成，若仅看初、终态列质量守恒，可能忽略了特定温度段失去的具体组分。应依据每个平台对应的失重，逐步分析。
- **元素推断时忽视原子序数与价态限制**：如短周期元素原子序数之和为 21，需要同时满足电子总数奇偶性、常温存在状态、化合物中常见化合价等条件，漏掉任一条件会导致推断错误。
- **错把固体残留的质量当作某单一物质**：很多热重分析中固体残留物是混合物，不能直接当作某一固定化学式，只能通过元素守恒或结晶水数去匹配。
- **混用守恒类型**：如把电子守恒用于非氧化还原反应；在非电解质溶液中滥用电荷守恒；把质量守恒与质量分数混淆。
- **忽略化学式中前驱体组成与失去分子的对应**：如化合物 $\ce{(NH4)2B4O7 · 4H2O}$ 中，失去的 $\ce{H2O}$ 既可能包括结晶水，也可能来自铵根的分解，要根据温度和无刺激性气体等条件判断。

## 代表题精讲
**题目**（2022·全国乙卷·5）  
化合物 $(\ce{YW4})_2\ce{X2Z8·W2Z}$ 可用于电讯器材、高级玻璃的制造。$\ce{W}$、$\ce{X}$、$\ce{Y}$、$\ce{Z}$ 为短周期元素，原子序数依次增加，且加和为 $21$。$\ce{YZ2}$ 分子的总电子数为奇数，常温下为气体。该化合物的热重曲线如图所示，在 $200^\circ \text{C}$ 以下热分解时无刺激性气体逸出。下列叙述正确的是（选项涉及单质状态、最高价含氧酸酸性、失重阶段失去 $\ce{W2Z}$ 数目、化学式判断）。

**思路**  
1. 先利用元素信息推断 $\ce{W, X, Y, Z}$。  
2. 再根据热重曲线和守恒法判断各阶段失去的物质及数目，最后评估选项正误。

**步骤**  
- **元素推断**：  
  设原子序数 $a(\ce{W}) < b(\ce{X}) < c(\ce{Y}) < d(\ce{Z})$，总和 $a+b+c+d=21$。  
  $\ce{YZ2}$ 常温为气体，总电子数为奇数。常见短周期气体氧化物中，$\ce{NO2}$（电子数 $7+2\times8=23$）符合条件，故 $\ce{Y}$ 为 $\ce{N}$（$c=7$），$\ce{Z}$ 为 $\ce{O}$（$d=8$）。  
  则 $a+b=21-7-8=6$，且 $a<b<7$，可能组合 $a=1, b=5$（$\ce{H}$ 和 $\ce{B}$）或 $a=2, b=4$（$\ce{He}$ 和 $\ce{Be}$）。$\ce{He}$ 几乎不形成化合物，故 $\ce{W}$ 为 $\ce{H}$，$\ce{X}$ 为 $\ce{B}$。

- **化学式重构**：  
  $\ce{(YW4)2X2Z8·W2Z}$ 即 $\ce{(NH4)2B2O8·H2O}$。考虑 $\ce{B}$ 常见化合价 $+3$，需保证阴离子电荷平衡，实际矿物中应写为 $\ce{(NH4)2B4O7·4H2O}$（四硼酸铵），题中形式可能为简化或实际存在的另一种写法，但不影响失重计算，只需利用元素种类与热重数据。

- **热重守恒分析**：  
  初始总质量为 $m_0$，$200^\circ \text{C}$ 以下无刺激性气体，说明失去的只是水分子 $\ce{H2O}$（即 $\ce{W2Z}$），不会分解出 $\ce{NH3}$ 等刺激性气体。  
  图中第一阶段（约 $100$–$200^\circ \text{C}$）失重率对应失去 $4$ 个 $\ce{H2O}$ 分子（相对分子质量 $4\times18=72$），与初始总质量比例匹配，可计算出每失去 $1$ 个 $\ce{H2O}$ 的失重百分数。据此可确定该阶段失去的 $\ce{W2Z}$ 数目为 $4$。

- **选项辨析**：  
  A．$\ce{W}$（$\ce{H2}$）为气体，$\ce{X}$（$\ce{B}$）单质为固体，$\ce{Y}$（$\ce{N2}$）和 $\ce{Z}$（$\ce{O2}$）为气体，并非全是气体 → 错。  
  B．最高价氧化物对应水化物酸性：$\ce{HNO3}$（强酸）$>$ $\ce{H3BO3}$（极弱酸），即 $Y>X$，选项说 $Y<X$ → 错。  
  C．$100$–$200^\circ \text{C}$ 阶段热分解失去 $4$ 个 $\ce{W2Z}$（$\ce{H2O}$） → 由守恒法计算正确。  
  D．化学式不可能是 $\ce{NH4HCO3·H2O}$，组成、原子比均不匹配 → 错。

**点评 / 变式**  
本题将短周期元素推断与热重曲线定量计算巧妙结合，突出质量守恒和原子守恒在复杂体系中的应用。核心在于：先依据原子序数和分子电子数奇偶性锁定元素，再通过热分解“无刺激性气体”限定了失去的组分仅为水，最后利用失重率定量判断结晶水数目。变式训练可尝试给出不同未知物，通过热重曲线各段失重率反推化学式中结晶水或分解产物比例，始终抓住“每一温度平台对应一个固定组成”的守恒思想。
