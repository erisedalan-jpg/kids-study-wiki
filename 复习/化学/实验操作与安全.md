## 知识精要
- **实验安全核心原则**
    - **防爆炸**：可燃性气体（如 $H_2$、$CO$）加热或点燃前必须验纯；用保护气（$N_2$、稀有气体）排尽装置内空气，形成无氧环境。
    - **防污染**：有毒有害尾气（$Cl_2$、$SO_2$、$CO$）必须用溶液吸收或点燃处理；反应遗漏产物可能污染环境。
    - **防倒吸**：加热制备并收集气体时，实验结束必须先移出导管再熄灭酒精灯；涉及易溶气体吸收时，使用倒置漏斗或安全瓶。
    - **防暴沸**：液体加热时加入沸石或碎瓷片，防止液体剧烈跳动。
    - **防堵塞**：加热固体物质时，试管口略向下倾斜，防止冷凝水倒流炸裂；高温下易堵塞导管口的反应需注意（如硫蒸气）。
- **气密性检查**：形成密闭体系，用微热法（导管末端伸入水中，手捂产生气泡，松开形成稳定水柱）或注水法（关闭活塞，长颈漏斗注水形成液面差不变）。
- **保护气的多重作用**
    1. **排尽空气**：实验前通入，驱赶装置内的 $O_2$、$CO_2$、水蒸气，防止反应物或产物被氧化、水解或干扰检验。
    2. **载气**：实验中持续通入，将生成的气体全部赶入后续检验或吸收装置，确保测定准确。
    3. **防止倒吸与氧化**：实验结束继续通保护气至冷却，平衡气压避免倒吸；防止外界空气进入使高温产物重新被氧化。
- **实验操作顺序模板**
    - 连接仪器 → 检查气密性 → 加入药品 → 通保护气排空气 → 加热进行反应 → 撤去热源 → 继续通保护气至冷却 → 拆除装置。
- **常见意外处理**
    - 酸/碱溅到皮肤：大量水冲洗，再涂稀 $NaHCO_3$ 溶液或硼酸。
    - 酒精灯失火：用湿布或沙土盖灭。
    - 误食重金属盐：服用牛奶、蛋清解毒。

## 解题方法与套路
1. **明确实验目的与装置结构**  
   划分装置区段（发生→除杂→干燥→主反应→检验/收集→尾气处理），弄清每部分仪器的作用，分析可能导致的安全问题。
2. **保护气作用答题模板**  
   按“**实验前排尽空气，防止××被氧化/××干扰；实验中将××气体全部驱赶至××；实验后继续通，平衡压强防止倒吸，同时防止××进入氧化产物**”分点作答，避免遗漏。
3. **防倒吸操作连锁分析**  
   - 加热制气+排水法收集：④先移导管后熄灯。  
   - 加热制气+液体吸收尾气：吸收装置前加安全瓶，或使用倒置漏斗刚接触液面；实验结束时先撤热源，继续通保护气。  
   - 有硬质玻璃管加热+后续溶液吸收：实验结束时继续通保护气至冷却，一来防倒吸，二来防空气氧化。
4. **气密性检查方法选择**  
   根据装置特点应用：若有长颈漏斗或分液漏斗，优先注水法；若全密闭，微热法更简便。描述时注明操作、现象、结论。
5. **实验评价与改进思路**  
   从**安全性**（是否需防爆、防倒吸、尾气处理）、**准确性**（是否排尽干扰气体、产物是否完全收集）、**简便性**（仪器是否复杂）、**环保性**（有无有害排放）四个维度评判。

## 高频易错
- **保护气目的答不全面**：只写“排空气”，漏写“作为载气导尽生成气体”和“防止外界空气回流”。  
- **实验操作顺序颠倒**：先加热后再通保护气，导致爆炸或产物被氧化。  
- **结束操作“先熄灯后撤导管”**：造成装置内压强降低，液体倒吸进热试管引起炸裂。  
- **忽略空气中 $CO_2$ 和 $H_2O$ 的干扰**：在检验分解产物 $CO_2$ 或水蒸气时，未先排除装置内空气中原有的 $CO_2$、$H_2O$，或未干燥气体导致误判。  
- **尾气直接排空**：$CO$、$Cl_2$ 等有毒气体没有设置点燃或吸收装置，造成污染和中毒风险。  
- **防堵塞误解**：将防倒吸装置（安全瓶）错答成防堵塞；或将棉花团防固体粉末进入导管的作用写成防倒吸。  
- **加热装置选择错误**：超过 $100^\circ C$ 仍用水浴加热；直接加热易分解的物质未用间接加热。

## 代表题精讲
**题目**：2018-新课标Ⅱ-10（节选）——三草酸合铁酸钾（$K_3[Fe(C_2O_4)_3]\cdot 3H_2O$）热分解实验，装置图给出。回答通入氮气的目的。

**思路**：本实验探究分解产物，热分解可能产生含 $CO$、$CO_2$ 等还原性气体，产物中的 $FeC_2O_4$ 等易被空气中氧气氧化。通入 $N_2$ 应从实验前、中、后三个阶段分析作用，对照保护气的完整答题模板进行整合。

**步骤**  
1. **实验前排尽空气**：先通一段时间 $N_2$，将硬质玻璃管及后续装置中的 $O_2$、$CO_2$ 和 $H_2O$ 排出。防止空气中 $O_2$ 将分解生成的 $FeC_2O_4$（或 $Fe^{2+}$ 化合物）氧化；防止空气中 $CO_2$ 对分解产生 $CO_2$ 的检验造成干扰。  
2. **实验中作为载气**：持续通 $N_2$，使 $K_3[Fe(C_2O_4)_3]\cdot 3H_2O$ 分解产生的所有气体被缓慢稳定地吹入后续的检验装置（如澄清石灰水检验 $CO_2$、浓硫酸干燥、$CuO$ 检验 $CO$ 等），确保气体被充分吸收反应，提高测定准确性。  
3. **实验结束防倒吸与防氧化**：反应结束停止加热后，继续通 $N_2$ 直至装置冷却至室温。一方面平衡气压，防止末端吸收液因装置冷却而倒吸入热试管；另一方面，隔绝外界空气，防止空气中 $O_2$ 在高温残留物未冷却时将其重新氧化。

**点评/变式**  
本题是“保护气作用”的标杆考法，考生须养成 **“三位一体”** 的回答习惯：排干扰 → 运产物 → 保安全。  
常见变式：  
- **氢气还原氧化铜实验**中用 $H_2$ 作保护气和还原剂，除上述作用外还强调“先通 $H_2$ 排空气防爆炸，结束先停加热后通 $H_2$ 至冷却防氧化”。  
- **测定有机化合物的组成**时，用 $O_2$ 氧化样品，用 $N_2$ 将燃烧后全部产物（$CO_2$、$H_2O$）驱赶进入吸收管，回答要点同样为排尽空气、驱赶产物。  
- **若用排水法收集气体**，实验结束除继续通保护气外，还需强调“先移出导管，后熄灭酒精灯”，以防倒吸。复习时应将变式融合训练，灵活套用模板。
