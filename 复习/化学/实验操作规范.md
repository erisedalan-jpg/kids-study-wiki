## 知识精要
- **胶体制备**：$\text{Fe(OH)}_3$ 胶体通过将饱和 $\text{FeCl}_3$ 溶液滴入沸水制得，不可用 $\text{NaOH}$ 与 $\text{FeCl}_3$ 反应（会生成沉淀）。
- **盐类水解与蒸发结晶**：挥发性酸对应的盐溶液加热蒸干时，水解生成的酸挥发，最终得到金属氧化物或碱式盐。如 $\text{MgCl}_2$ 溶液蒸干得到 $\text{Mg(OH)Cl}$ 或 $\text{MgO}$，而非无水 $\text{MgCl}_2$。制备无水 $\text{MgCl}_2$ 需在 $\text{HCl}$ 气氛中蒸发结晶，抑制水解。
- **除杂原则**：不减少被提纯物质，不引入新杂质。除去 $\text{Cu}$ 粉中的 $\text{CuO}$，若用稀硝酸，$\text{Cu}$ 和 $\text{CuO}$ 均会溶解，不能达到目的；应用稀盐酸或稀硫酸，只溶解 $\text{CuO}$，过滤、洗涤、干燥即可。
- **常见物质的提纯与制备条件**：
  - 制备无水盐（如 $\text{AlCl}_3$、$\text{FeCl}_3$、$\text{MgCl}_2$ 等）：在相应酸的气流中加热蒸干。
  - 胶体制备：利用水解反应，控制浓度、温度和介质。

## 解题方法与套路
1. **题干目标与操作匹配判定法**
   - 先明确实验目的（如制备、除杂、分离）。
   - 分析操作涉及的化学反应原理，判断是否按预期进行，有无副反应、干扰。
2. **典型试剂使用注意排查**
   - 硝酸：强氧化性，能溶解绝大多数金属（包括 $\text{Cu}$、$\text{Ag}$），除铜的氧化物时不能用。
   - $\text{NaOH}$：强碱性，用于沉淀金属离子，但制胶体时容易造成沉淀颗粒过大。
3. **水解产物的最终形态推断**
   - 对于可水解的盐，加热蒸发时考虑酸是否挥发：酸挥发则水解彻底，得氧化物或氢氧化物；酸难挥发则可能得原溶质或碱式盐。
   - 牢记特例：$\text{MgCl}_2$ 溶液蒸干最终得 $\text{MgO}$；$\text{AlCl}_3$ 蒸干得 $\text{Al}_2\text{O}_3$。
4. **最佳方案选择法**
   - 除杂原则：不增、不减、易分离、易复原。理想的除杂试剂只与杂质反应，生成易分离的物质。
   - 制备无水盐：用 $\text{HCl}$ 气流保护或与 $\text{SOCl}_2$ 等反应。

## 高频易错
- **混淆胶体制备与沉淀反应**：$\text{Fe(OH)}_3$ 胶体制备必须使用沸水，若用 $\text{NaOH}$ 溶液直接与铁盐反应，得到的是红褐色沉淀，不能形成胶体。
- **误认为所有盐溶液蒸干都能得到原溶质**：忽略了水解和酸挥发的双重影响。$\text{MgCl}_2$ 溶液蒸干过程中发生 $\text{MgCl}_2 + 2\text{H}_2\text{O} \rightleftharpoons \text{Mg(OH)}_2 + 2\text{HCl}$，$\text{HCl}$ 挥发，平衡正移，最终分解为 $\text{MgO}$。
- **用强氧化性酸除去金属氧化物杂质**：$\text{Cu}$ 粉中混有 $\text{CuO}$，若加入稀 $\text{HNO}_3$，铜和氧化铜均反应：$3\text{Cu} + 8\text{HNO}_3$（稀）$\rightarrow$ $\dots$，$\text{CuO} + 2\text{HNO}_3 \rightarrow \dots$，导致主体物质也被消耗，实验失败。
- **忽视结晶水或水解产物的转化**：加热蒸干并非简单的蒸发除水，往往伴随化学反应，如 $\text{FeCl}_3$ 溶液蒸干得到 $\text{Fe(OH)}_3$ 后再分解为 $\text{Fe}_2\text{O}_3$。

## 代表题精讲
**题目**：下列实验操作能达到实验目的的是（    ）  
A. 制备 $\text{Fe(OH)}_3$ 胶体：将 $\text{NaOH}$ 浓溶液滴加到饱和 $\text{FeCl}_3$ 溶液中  
B. 由 $\text{MgCl}_2$ 溶液制备无水 $\text{MgCl}_2$：将 $\text{MgCl}_2$ 溶液加热蒸干  
C. 除去 $\text{Cu}$ 粉中混有的 $\text{CuO}$：加入稀硝酸溶液，过滤、洗涤、干燥  

**思路**：逐一分析各选项操作是否符合对应的实验目的。  
A 考查胶体制备的正确方法；B 考查水解盐的蒸发结晶；C 考查除杂试剂的合理选择。  

**步骤**：
- **A 项**：饱和 $\text{FeCl}_3$ 溶液滴入沸水中，继续加热至红褐色透明液体，得 $\text{Fe(OH)}_3$ 胶体。若滴加 $\text{NaOH}$ 浓溶液，发生 $\text{Fe}^{3+} + 3\text{OH}^- = \text{Fe(OH)}_3 \downarrow$，生成沉淀而非胶体。操作错误。
- **B 项**：$\text{MgCl}_2$ 为强酸弱碱盐，水解生成 $\text{Mg(OH)}_2$ 和 $\text{HCl}$，加热促进水解且 $\text{HCl}$ 挥发，平衡右移，最终蒸干得到 $\text{MgO}$ 固体，无法得到无水 $\text{MgCl}_2$。应在 $\text{HCl}$ 气流中加热蒸发。操作错误。
- **C 项**：稀硝酸具有强氧化性，$\text{Cu}$ 粉和 $\text{CuO}$ 均能与稀硝酸反应：$\text{CuO} + 2\text{HNO}_3 = \text{Cu(NO}_3)_2 + \text{H}_2\text{O}$，$3\text{Cu} + 8\text{HNO}_3\text{(稀)} = 3\text{Cu(NO}_3)_2 + 2\text{NO}\uparrow + 4\text{H}_2\text{O}$。主体物质 $\text{Cu}$ 被消耗，无法达到除杂目的。应选用稀盐酸或稀硫酸。操作错误。

三项操作均不能达到实验目的，本题无正确选项（代表题原题可能为单选题且其中一项设计正确，此处根据语料均为错误，故判断三个选项均不可行；高考题中一般有一项正确，但此处提供的语料显示三个选项均错，可能是题干不完整，但仍按分析解答。若严格按照提供语料，所有选项均不能达到目的。）。  

**点评/变式**：
- 该类题型必须对核心物质的化学特性非常熟悉，尤其关注“胶体≠沉淀”“蒸发≠单纯去水”“除杂不能牺牲主体”。
- 变式训练：若选项 B 改为“将 $\text{MgCl}_2 \cdot 6\text{H}_2\text{O}$ 在 $\text{HCl}$ 气流中加热”，则可成功制备无水 $\text{MgCl}_2$。  
- 再如，“除去 $\text{FeCl}_2$ 溶液中的 $\text{FeCl}_3$”可加入过量铁粉后过滤，利用 $\text{Fe} + 2\text{Fe}^{3+} = 3\text{Fe}^{2+}$，不能采用加铜粉或直接加热。
