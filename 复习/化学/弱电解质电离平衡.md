## 知识精要
- 弱电解质电离平衡：电离过程吸热，符合“越热越电离”；稀释促进电离，电离度增大，但离子浓度不一定增大。电离平衡常数 $K_a$（或 $K_b$）只与温度有关，与浓度无关。
- 一元弱酸（碱）中：$c(\mathrm{H}^+)=\sqrt{K_a\cdot c}$ 近似成立（$c/K_a\geq 400$），稀释时 $c(\mathrm{H}^+)$ 减小，$n(\mathrm{H}^+)$ 增大。
- 多元弱酸分步电离，酸性主要由第一步决定，第二步电离极弱，如 $ \mathrm{H_2S} $ 溶液中 $c(\mathrm{H}^+) \gg c(\mathrm{HS}^-)\gg c(\mathrm{S}^{2-})$。
- 盐类水解：谁弱谁水解，越弱越水解。对应弱酸酸性越弱，其强碱盐溶液碱性越强。如酸性：$ \mathrm{CH_3COOH > H_2CO_3 > HClO > HCO_3^-}$，则等浓度时碱性：$ \mathrm{CH_3COONa < NaHCO_3 < NaClO < Na_2CO_3}$。
- 溶液中三大守恒：
  - 电荷守恒：阳离子所带正电荷总数 = 阴离子所带负电荷总数。
  - 物料守恒（元素质量守恒）：某一组分的起始浓度等于其各种存在形式平衡浓度之和。
  - 质子守恒：酸失去的质子数 = 碱得到的质子数（可由电荷守恒与物料守恒联立推导）。

## 解题方法与套路
1. **判强弱，定主次**：根据题目信息判断溶质是强电解质还是弱电解质，确定电离或水解是溶液酸碱性的主导因素。
2. **写方程，理微粒**：写出溶液中所有电离、水解方程式，理清存在的分子和离子种类，特别注意多元弱酸的酸式根。
3. **抓守恒，列关系**：
   - 单一溶液：直接用电荷守恒、物料守恒、质子守恒判断选项。
   - 混合溶液：先考虑是否反应，确定溶质，再写守恒式。混合比例不确定时，选择与比例无关的守恒式（如电荷守恒）。
4. **弱酸（碱）稀释“三变三不变”**：电离程度、$n(\mathrm{H}^+)$、$n(\mathrm{OH}^-)$ 增大；温度不变则 $K_w$、$K_a$（$K_b$）、$c(\mathrm{H}^+)\cdot c(\mathrm{OH}^-)$ 不变；$c(\mathrm{H}^+)$（酸性）或 $c(\mathrm{OH}^-)$（碱性）减小，但变化幅度小于强酸（碱）。
5. **比大小，用规律**：
   - 比较盐溶液碱（酸）性：对应酸越弱，水解程度越大，pH越高（或越低）。
   - 比较等pH弱酸盐浓度：酸性越弱的对应盐浓度越小（因为水解程度大）。
   - 比较各种粒子浓度：先判断酸碱性，再结合水解、电离程度相对大小。
6. **极值验证法**：对于混合溶液任意比例问题，可取极限点（如仅一种溶质）带入选项快速排除。

## 高频易错
- **二元弱酸电离误区**：误认为 $c(\mathrm{H}^+)$ 与第一步电离产生的酸式根浓度相等，忽略了第二步电离消耗酸式根且产生很少的 $\mathrm{H}^+$，正确关系为 $c(\mathrm{H}^+) \gg c(\mathrm{HA}^-)$（$\mathrm{H_2A}$ 溶液中）。
- **稀释规律记反**：弱酸稀释时 $c(\mathrm{H}^+)$ 减小但不会成比例减小，pH增大小于1；误将 $a=b+1$ 套用于弱碱稀释，忽视电离度增大带来的缓冲效应。
- **守恒式残缺**：书写电荷守恒时遗漏多价离子，如 $\mathrm{H_2C_2O_4}$ 与 $\mathrm{NaOH}$ 混合，电荷守恒应为 $c(\mathrm{Na}^+) + c(\mathrm{H}^+) = c(\mathrm{OH}^-) + c(\mathrm{HC_2O_4^-}) + 2c(\mathrm{C_2O_4^{2-}})$，漏乘系数是典型失分点。
- **混淆 $K_a$ 与浓度**：认为稀释时平衡常数增大，实际上 $K_a$ 仅受温度影响，稀释时不变。
- **跨级水解比较**：比较等pH的 $\mathrm{CH_3COONa}$、$\mathrm{NaHCO_3}$、$\mathrm{NaClO}$ 的 $c(\mathrm{Na}^+)$ 时，忽视 $\mathrm{NaHCO_3}$ 中 $\mathrm{HCO_3^-}$ 水解程度小于 $\mathrm{CO_3^{2-}}$ 水解，且 $\mathrm{HCO_3^-}$ 还能微弱电离，应厘清酸性顺序：$\mathrm{CH_3COOH > H_2CO_3 > HClO > HCO_3^-}$，等pH时浓度排序与酸性顺序相反。

## 代表题精讲
### 代表题1：2014·新课标Ⅱ·05
**题目**：判断离子浓度关系式正误。涉及 $\mathrm{H_2S}$ 溶液中离子浓度关系、氨水稀释后pH变化、$\mathrm{H_2C_2O_4}$ 与$\mathrm{NaOH}$任意比例混合的电荷守恒、等pH钠盐溶液 $c(\mathrm{Na}^+)$ 比较。

**思路**：
- A项：$\mathrm{H_2S}$ 为二元弱酸，第一步电离为主，$c(\mathrm{H}^+) \gg c(\mathrm{HS}^-)$，不相等。
- B项：氨水为弱碱，稀释10倍，因电离平衡正向移动，pH减小不足1，故 $a < b+1$。
- C项：根据电荷守恒，混合溶液中阳离子只有 $\mathrm{Na}^+、\mathrm{H}^+$，阴离子有 $\mathrm{OH}^-、\mathrm{HC_2O_4^-}、\mathrm{C_2O_4^{2-}}$，正确式子应包含 $2c(\mathrm{C_2O_4^{2-}})$，选项漏项。
- D项：等pH即 $c(\mathrm{OH}^-)$ 相同，水解程度 $\mathrm{ClO^- > HCO_3^- > CH_3COO^-}$，故所需盐浓度 $\mathrm{CH_3COONa > NaHCO_3 > NaClO}$，即 $c(\mathrm{Na}^+)$ 排序正确。

**步骤**：
1. 针对每个选项，先判断溶液性质（单一/混合，强/弱）。
2. 对A、C选项直接用电离特征和电荷守恒公式比对。
3. 对B选项调用弱碱稀释pH变化规律。
4. 对D选项调用“越弱越水解”判断盐浓度大小与pH关系。

**点评/变式**：本题集成度高，一道题考查了弱电解质电离、稀释、三大守恒和水解大小比较。解题关键在于熟练记忆守恒式规范写法，以及厘清酸（碱）性强弱与水解程度的关系。变式训练：将D项改为“pH相同的NaOH与氨水稀释相同倍数后的pH比较”等。

### 代表题2：2011·新课标·04
**题目**：将0.1mol·L⁻¹HF溶液加水不断稀释，判断始终增大的量。

**思路**：HF是弱酸，稀释促进电离，$n(\mathrm{H}^+)$、$n(\mathrm{F}^-)$、电离度均增大；温度不变，$K_a(\mathrm{HF})$ 不变；加入水使溶液体积增大为主导，$c(\mathrm{H}^+)$、$c(\mathrm{F}^-)$ 均减小。题目选项中可能给出的表达式有：$\frac{c(\mathrm{H}^+)}{c(\mathrm{HF})}$、$\frac{c(\mathrm{F}^-)}{c(\mathrm{HF})}$、$\frac{K_a}{c(\mathrm{H}^+)}$ 等。其中 $\frac{c(\mathrm{H}^+)}{c(\mathrm{HF})} = \frac{K_a}{c(\mathrm{F}^-)}$，稀释时 $c(\mathrm{F}^-)$ 减小，则该比值增大；$\frac{c(\mathrm{F}^-)}{c(\mathrm{HF})}$ 同样增大；或者从“越稀越电离”直接得电离度 $\alpha$ 增大，$\frac{\alpha}{1-\alpha}$ 增大。

**步骤**：
1. 确定溶液体系：弱酸HF $ \rightleftharpoons $ H⁺ + F⁻。
2. 稀释时平衡右移，分子、分母变化趋势分析：$c(\mathrm{HF})$ 因稀释和电离双减少，下降更快；$c(\mathrm{H}^+)$ 和 $c(\mathrm{F}^-)$ 虽减小，但相对于HF的比例上升。
3. 利用 $K_a = \frac{c(\mathrm{H}^+)\cdot c(\mathrm{F}^-)}{c(\mathrm{HF})}$ 不变，导出待判断表达式的单调性。
4. 排除 $K_a$ 和 $c(\mathrm{H}^+)$ 等明显减小或不变量。

**点评/变式**：此题易错选 $c(\mathrm{H}^+)$ 或 $K_a$。需牢记稀释时离子浓度的变化是“总量增，浓度减”。可外延至强酸稀释：粒子浓度均反比减小，比值不变。

### 代表题3：2009·全国Ⅱ·05
**题目**：等浓度的醋酸、苯酚、苯酚钠、碳酸、碳酸钠、碳酸氢钠溶液，pH由小到大排列。

**思路**：首先将溶液按酸、盐分类。酸溶液pH<7，盐溶液一般pH>7（强碱弱酸盐）。酸性：醋酸 > 碳酸 > 苯酚；苯酚钠、碳酸钠、碳酸氢钠水解呈碱性，对应酸性越弱，水解程度越大，碱性越强。酸性：苯酚 < 碳酸 < 碳酸氢根？实际上对应酸：苯酚 $K_a\approx 10^{-10}$，碳酸 $K_{a1}=4.3\times10^{-7}$，$K_{a2}=5.6\times10^{-11}$。故酸性：碳酸 > 苯酚 > 碳酸氢钠（对应酸为 $\mathrm{HCO_3^-}$）。因此碱性：碳酸钠 > 苯酚钠 > 碳酸氢钠（等浓度时）。所以pH从小到大：醋酸 < 碳酸 < 苯酚 < 碳酸氢钠 < 苯酚钠 < 碳酸钠。

**步骤**：
1. 分成两组：①④为酸，其余为盐。
2. 根据 $K_a$ 或常识比较酸强弱：$\mathrm{CH_3COOH > H_2CO_3 > C_6H_5OH}$，得出pH顺序①<④<②。
3. 盐溶液水解呈碱性，判断对应酸：苯酚钠→苯酚，碳酸钠→碳酸氢根（或碳酸第二步），碳酸氢钠→碳酸。特别注意碳酸氢钠对应酸为 $\mathrm{H_2CO_3}$，但 $\mathrm{HCO_3^-}$ 水解大于电离，呈弱碱性；苯酚酸性弱于碳酸，故苯酚钠碱性>碳酸氢钠；碳酸钠对应酸为 $\mathrm{HCO_3^-}$，更弱，碱性最强。
4. 整合排序得：①<④<②<⑥<③<⑤。

**点评/变式**：本题核心是建立“酸性强弱—对应盐水解程度”的映射。易错点在于碳酸氢钠的位置，需明确比较对象是水解产生的碱性，且注意 $\mathrm{NaHCO_3}$ 溶液碱性弱于 $\mathrm{Na_2CO_3}$ 和苯酚钠。变式：改为等pH时比较浓度，则顺序完全相反。
