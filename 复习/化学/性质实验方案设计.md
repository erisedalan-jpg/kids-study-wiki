## 知识精要
- 常见离子检验方法
  - $\mathrm{Fe^{2+}}$：与 $\mathrm{K_3[Fe(CN)_6]}$ 生成蓝色沉淀（特征检验）；先加 $\mathrm{KSCN}$ 无现象，再加氯水变红（需排除 $\mathrm{Fe^{3+}}$ 干扰）。
  - $\mathrm{Fe^{3+}}$：遇 $\mathrm{KSCN}$ 溶液显红色（配合物 $[\mathrm{Fe(SCN)}]^{2+}$）；遇苯酚显紫色。
  - $\mathrm{I_2}$：在 $\mathrm{CCl_4}$ 或苯中显紫色，可用萃取验证 $\mathrm{I^-}$ 被氧化生成 $\mathrm{I_2}$。
- 氧化还原反应方向与限度
  - 反应 $\mathrm{2Fe^{3+} + 2I^- \rightleftharpoons 2Fe^{2+} + I_2}$ 为可逆反应。通过检验反应后溶液中既有 $\mathrm{Fe^{3+}}$ 剩余又有 $\mathrm{Fe^{2+}}$ 生成，可证明反应不能进行到底。
  - 较强氧化剂/还原剂可改变反应方向：$\mathrm{Cl_2}$ 可氧化 $\mathrm{Fe^{2+}}$ 为 $\mathrm{Fe^{3+}}$；$\mathrm{H_2O_2}$ 在酸性条件下氧化 $\mathrm{Fe^{2+}}$。
- 实验干扰排除与条件控制
  - 易被空气中 $\mathrm{O_2}$ 氧化的试剂（如 $\mathrm{Fe^{2+}}$ 溶液），配制时需加少量对应还原性固体（铁粉）防止氧化。
  - 检验空气敏感的反应时，可用煤油覆盖液面隔离空气，排除溶解氧的干扰。

## 解题方法与套路
1. **审题抓目的**：先明确实验要验证的性质（如氧化性/还原性、离子检验、可逆反应）。
2. **分析试剂作用**：
   - 加入铁屑、煤油等——目的是保护或隔绝空气，防止干扰。
   - 加入氯水、$\mathrm{H_2O_2}$——提供氧化剂，探究氧化过程。
   - 加入 $\mathrm{KSCN}$、$\mathrm{K_3[Fe(CN)_6]}$——特征检验特定离子。
3. **依据现象逐级推理**：
   - 溶液变红→存在 $\mathrm{Fe^{3+}}$（$\mathrm{KSCN}$ 特征反应）。
   - 蓝色沉淀→存在 $\mathrm{Fe^{2+}}$（$\mathrm{K_3[Fe(CN)_6]}$ 特征反应）。
   - $\mathrm{CCl_4}$ 层呈紫色→生成了 $\mathrm{I_2}$。
4. **破解实验严谨性设问**：
   - 指出原方案的不足（如未排除 $\mathrm{O_2}$ 氧化 $\mathrm{Fe^{2+}}$）。
   - 说明改进措施的科学原理（覆盖煤油、液面下操作）。
5. **解释后续异常现象**：
   - 涉及催化分解（$\mathrm{Fe^{3+}}$ 催化 $\mathrm{H_2O_2}$）、平衡移动（水解平衡，放热促进水解生成沉淀）。

## 高频易错
- $\mathrm{Fe^{2+}}$ 检验直接用 $\mathrm{KSCN}$ 和氯水，但忽视原溶液中可能存在 $\mathrm{Fe^{3+}}$ 的干扰，未设计对照。
- 写离子方程式时漏掉介质条件：如酸性介质下 $\mathrm{H_2O_2}$ 氧化 $\mathrm{Fe^{2+}}$ 需要 $\mathrm{H^+}$ 参与（产物为 $\mathrm{Fe^{3+} + H_2O}$），漏写氢离子或水。
- 对可逆反应的证明逻辑不清：须同时检出反应物（$\mathrm{Fe^{3+}}$）剩余和生成物（$\mathrm{Fe^{2+}}$、$\mathrm{I_2}$）出现，方可下结论。
- 隔离空气操作名称和原理混淆：液封常用苯、煤油等密度比水小且不与水混溶的有机物，原理是隔绝 $\mathrm{O_2}$，防止氧化。
- 红褐色沉淀成因漏掉平衡移动：“放热促进水解”需明确指向 $\mathrm{Fe^{3+} + 3H_2O \rightleftharpoons Fe(OH)_3 + 3H^+}$，升温平衡正向移动。

## 代表题精讲
### 代表题：2016-新课标Ⅱ-10
**题目**：探究 $\mathrm{Fe^{2+}}$、$\mathrm{Fe^{3+}}$ 性质，包括防氧化措施、氯水氧化实验、煤油作用、可逆反应证明、酸性 $\mathrm{H_2O_2}$ 氧化与后续气泡及沉淀解释。

**思路**：本实验以 $\mathrm{Fe^{2+}/\ Fe^{3+}}$ 的氧化还原及检验为主线，考查实验设计细节：防氧化、空气隔绝、离子检验组合证明可逆反应、催化及水解平衡。

**步骤**  
- （1）配制 $\mathrm{FeCl_2}$ 溶液时加铁屑：利用 $\mathrm{Fe + 2Fe^{3+} = 3Fe^{2+}}$ 防止 $\mathrm{Fe^{2+}}$ 被空气氧化为 $\mathrm{Fe^{3+}}$。  
- （2）氯水氧化 $\mathrm{Fe^{2+}}$：离子方程式 $\mathrm{2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-}$，$\mathrm{KSCN}$ 检验生成的 $\mathrm{Fe^{3+}}$。  
- （3）煤油封液改进实验严谨性：煤油密度小于水，浮于液面，隔绝空气，防止空气中的 $\mathrm{O_2}$ 将 $\mathrm{Fe^{2+}}$ 氧化，确保变红仅由氯水氧化引起。  
- （4）证明 $\mathrm{Fe^{3+}}$ 与 $\mathrm{I^-}$ 反应为可逆反应：  
   - 试管① $\mathrm{CCl_4}$ 层紫色 → 生成 $\mathrm{I_2}$；  
   - 试管②蓝色沉淀 → 有 $\mathrm{Fe^{2+}}$（$\mathrm{K_3[Fe(CN)_6]}$ 特征）；  
   - 试管③溶液变红 → 有 $\mathrm{Fe^{3+}}$ 剩余；  
   既有反应物剩余又有生成物，证明反应 $\mathrm{2Fe^{3+} + 2I^- \rightleftharpoons 2Fe^{2+} + I_2}$ 可逆。  
- （5）酸性 $\mathrm{H_2O_2}$ 氧化 $\mathrm{Fe^{2+}}$：$\mathrm{2Fe^{2+} + H_2O_2 + 2H^+ = 2Fe^{3+} + 2H_2O}$。随后气泡（$\mathrm{O_2}$）是因 $\mathrm{Fe^{3+}}$ 催化 $\mathrm{H_2O_2}$ 分解：$\mathrm{2H_2O_2 \xrightarrow{Fe^{3+}} 2H_2O + O_2\uparrow}$。红褐色沉淀 $\mathrm{Fe(OH)_3}$ 是因为分解反应放热，促进 $\mathrm{Fe^{3+}}$ 的水解平衡 $\mathrm{Fe^{3+} + 3H_2O \rightleftharpoons Fe(OH)_3 + 3H^+}$ 正向移动。

**点评/变式**  
- 本题是典型的“实验探究链”：从试剂配制（防氧化）→单一性质检验→装置优化（煤油隔绝）→多个检验组合推断反应限度→条件改变引发新反应及副反应解释，覆盖核心素养：变化观念、证据推理、科学探究。  
- 变式延伸：若将 $\mathrm{KSCN}$ 和 $\mathrm{K_3[Fe(CN)_6]}$ 互换检验场景，需注意二者专一性；若将煤油换为苯，原理相同。平衡移动解释注意构建“速率/平衡+热效应”的因果链，高考高频考法。
