## 知识精要
- 晶胞是晶体结构的最小重复单元，晶胞参数包括 $a,b,c,\alpha,\beta,\gamma$，立方晶系中 $a=b=c$。
- 原子分数坐标：以晶胞参数为单位长度，晶胞内原子位置表示为 $(x,y,z)$，取值范围 $0 \le x,y,z < 1$。
- 利用“均摊法”确定化学式：顶点1/8，棱上1/4，面上1/2，体内1。
- 密度公式：  
  $$\rho = \frac{ZM}{N_A V}$$  
  其中 $Z$ 为晶胞内化学式数目，$M$ 为化学式摩尔质量（$g \cdot mol^{-1}$），$N_A$ 为阿伏伽德罗常数，$V$ 为晶胞体积（$cm^3$）。  
  晶胞体积 $V$ 可由晶胞参数计算，如立方晶系 $V=a^3$。  
  由该公式可反推未知组成比例或晶胞参数。
- 投影图：从某个方向（如 c 轴方向）的投影反映原子在底面（ab面）的相对位置，通常给出分数坐标的 $x,y$ 值，$z$ 需结合文字条件和晶胞对称性推断。

## 解题方法与套路
1. **确定晶胞内各原子的个数**：  
   - 审题时精准解读“共同占据底面位置”“比例依次为 $x$ 和 $1-x$”等条件，区分等效原子与协同占据。  
   - 利用均摊法计算各个位置上的原子总数（包括共占位按比例算有效个数）。  
2. **书写化学式及摩尔质量表达式**：  
   - 由各原子个数比写出化学式，若含有未知参数 $x$，则化学式和摩尔质量 $M$ 均表示为 $x$ 的函数。  
3. **代入密度公式列方程**：  
   - 根据给出的密度 $\rho$ 和晶胞参数计算体积 $V$（注意单位换算，长度用 cm）。  
   - 将化学式数目 $Z$（通常为 1）、$M(x)$、$N_A$、$V$ 代入 $\rho = \frac{ZM}{N_A V}$，得到 $\rho$ 关于 $x$ 的表达式或方程。  
   - 若题干要求直接写表达式，则整理出 $\rho = f(x)$；若求 $x$ 值，则解方程。  
4. **推导原子分数坐标**：  
   - 读取已有坐标（如原子1），结合对称性（底面、体心、面心等）与投影图判断其余原子的位置。  
   - 注意坐标的参照是晶胞的顶点，原点可自己设定，但通常晶胞图已暗示坐标原点在某一顶角（如左下后角）。  
   - 上下底面、棱上、体内原子的 $z$ 坐标分别是 $0$、中间分数、$1$ 等，配合投影图上的相对位置写出 $(x,y,z)$。

## 高频易错
- 均摊法忽略共占位条件：若底面被两种离子按比例占据，不能直接算成各1/2，应按比例计算各自有效个数（如 $F^-$ 有效个数为底面的贡献 $\times x$）。
- 体积单位混乱：密度公式要求 $V$ 单位为 $cm^3$，晶胞参数常用 $\text{pm}$ 或 $\mathring A$，必须换算：$1 \text{ pm} = 10^{-10} \text{ cm}$，$1 \mathring A = 10^{-8} \text{ cm}$。
- 摩尔质量计算错误：化学式中含 $x$ 时，$M$ 必须代入每个原子的摩尔质量并保留 $x$，未正确合并同类项导致表达式复杂或错误。
- 原子分数坐标的 $z$ 值推断错误：底面原子 $z=0$ 或 $z=1$（取决于原点位置和原子层位置），盲目将底面一律标为 $z=0$ 而不看是否属于同一底面。
- 晶胞内含化学式数目 $Z$ 直接设为 1 而未核对：在特别比例占据情况下，化学式可能是 $Z>1$，需要根据均摊后的原子总数与化学式中原子数比对确定 $Z$。本题中 $Z=1$，但部分变式可能改变。

## 代表题精讲
### 2019-新课标Ⅱ-11（4）
**题目**  
一种四方超导化合物的晶胞如图，Sm 和 As 的投影如图。$F^-$ 和 $O^{2-}$ 共同占据晶胞的上下底面位置，比例依次为 $x$ 和 $1-x$。求该化合物的化学式，并写出密度 $\rho$ 与晶胞参数的关系表达式（用含 $x$ 的式子表示）；给出原子 2 和 3 的分数坐标。

**思路**  
利用均摊法计算各原子个数，根据比例写出化学式，再代入密度公式推导 $\rho$ 的表达式。由给出的原子 1 坐标和投影图推出 2、3 的坐标。

**步骤**  
1. **算原子个数**  
   - Sm：图 2 中 Sm 位于晶胞顶点和上下底面中心？由投影看出 Sm 在底面处于棱上和面心？根据题干投影位置图可读出 Sm 为 2 个（通常四方晶胞中 Sm 在顶点和体心？实际解析：Sm 位于晶胞顶点和体心时，均摊得 2 个 Sm，本题 Sm 原子个数为 2）。  
   - As：类似地，As 位于晶胞面上或棱上，最终得 2 个 As。  
   - Fe：Fe 位于另一个亚层，均摊得 2 个 Fe。  
   - $F^-$ 和 $O^{2-}$：共同占据上下底面（两个面，每个面一个位置，共 2 个位置），每个位置由 $F$ 和 $O$ 按比例占，所以 $F$ 有效个数 $2x$，$O$ 有效个数 $2(1-x)$。  
   综上，原子比 Sm:Fe:As:O:F = 2:2:2:2(1-x):2x = 1:1:1:(1-x):x，化学式为 $SmFeAsO_{1-x}F_x$。  

2. **密度表达式**  
   晶胞含 1 个化学式，摩尔质量 $M = [150.4 + 55.8 + 74.9 + 16.0(1-x) + 19.0x] \text{ g}\cdot \text{mol}^{-1} = [281.1 + 3.0x] \text{ g}\cdot \text{mol}^{-1}$ (Sm取150.4近似值，真实需参照试卷给定原子量，此处按解析给出表达式)。  
   设晶胞参数为 $a \text{ pm}$ 和 $c \text{ pm}$，体积 $V = a^2 c \times 10^{-30} \text{ cm}^3$。  
   密度 $\rho = \frac{1 \times M}{N_A V} = \frac{281.1 + 3.0x}{N_A a^2 c \times 10^{-30}} \text{ g}\cdot \text{cm}^{-3}$。  
   （实际本题只要求写出表达式，最终答案整理为 $\rho = \frac{2[281.1+3.0x]}{N_A a^2 c \times 10^{-30}}$？检查：结合均摊，化学式为 $SmFeAsO_{1-x}F_x$，按原子个数比为 2:2:2:2(1-x):2x，约简为 $Z=1$ 的化学式，所以摩尔质量对应的是 $SmFeAsO_{1-x}F_x$，即 $M=281.1+3.0x$。按该结果填入得 $\rho = \frac{281.1+3.0x}{N_A a^2 c \times 10^{-30}}$。根据当年正确答案常带系数，因为实际质量是1个晶胞的质量除以晶胞体积。晶胞含1个$SmFeAsO_{1-x}F_x$，故公式正确。最终表达式允许保留原子量符号，通常作答为 $\rho = \frac{2[150+56+75+16(1-x)+19x]}{N_A a^2 c \times 10^{-30}}$ 或化简形式。标准答案给出的是 $\rho = \frac{2[281+3x]}{N_A a^2 c \times 10^{-30}}$ 但 Sm 原子量按 150 算，自己核对时注意原子量可按题给。这里展示通用关系。）

3. **分数坐标**  
   原子 1 的坐标为 $(1/2, 1/2, 1/2)$ （题中给出）。  
   由投影图知原子 2 在底面且与原子 1 投影位置相同，即 $x=1/2, y=1/2$，因为底面 $z=0$，所以原子 2：$(1/2, 1/2, 0)$。  
   原子 3 位于 c 轴方向的棱中点，投影在原点，即 $x=0, y=0$，且高度为 $\frac12 c$ 对应坐标 $z=1/2$，得 $(0, 0, 1/2)$。

**点评/变式**  
本题综合性强，将化学式推断、密度计算与分数坐标集于一体。关键在于正确处理共占位离子的有效数目，并以参数 $x$ 保持函数关系。分数坐标从投影图和已有坐标出发，利用高度信息即能快速写出。变式训练可要求由密度值反算 $x$，或给出不同比例占据时推导密度公式。
