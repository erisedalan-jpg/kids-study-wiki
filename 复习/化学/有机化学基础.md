## 知识精要
- **取代反应**：有机物分子里的某些原子或原子团被其他原子或原子团所替代的反应。  
  通式：$R\!-\!A + B \rightarrow R\!-\!B + A$ （或 $R\!-\!A + B\!-\!C \rightarrow R\!-\!B + A\!-\!C$）  
  特征：**“有上有下”**，产物一般为两种化合物，反应前后碳骨架不饱和程度通常不变。
- **常见取代反应**：
  - 烷烃的卤代：$CH_4 + Cl_2 \xrightarrow{光照} CH_3Cl + HCl$
  - 苯及其同系物的卤代、硝化、磺化：  
    $C_6H_6 + Br_2 \xrightarrow{FeBr_3} C_6H_5Br + HBr$  
    $C_6H_6 + HNO_3 \xrightarrow{浓硫酸/△} C_6H_5NO_2 + H_2O$
  - 醇与氢卤酸的取代：$C_2H_5OH + HBr \xrightarrow{△} C_2H_5Br + H_2O$
  - 酯化反应：$CH_3COOH + C_2H_5OH \underset{△}{\stackrel{浓H_2SO_4}{\rightleftharpoons}} CH_3COOC_2H_5 + H_2O$ （酸脱羟基醇脱氢）
  - 酯的水解、卤代烃的水解等。
- **易混淆反应类型区分**：
  - **加成反应**：不饱和键断裂，两端直接加上原子或原子团，产物唯一（一种化合物）。例：$CH_2\!=\!CH_2 + Br_2 \rightarrow CH_2Br\!-\!CH_2Br$
  - **消去反应**：从分子内脱去小分子（$H_2O$、$HX$等），生成不饱和键。例：$C_2H_5OH \xrightarrow{浓H_2SO_4/170℃} CH_2\!=\!CH_2\uparrow + H_2O$

## 解题方法与套路
1. **定类型，抓特征**：通览反应式，从“断键位置”和“产物组成”快速判断。
   - 若反应物都含不饱和键（如烯、炔、醛、酮、苯环勉强算），且产物只有一种分子——大概率**加成**。
   - 若产物有不止一种分子，且反应物有一种饱和分子 + 一种单质或化合物，发生原子/基团交换——**取代**。
   - 若从饱和分子中脱去小分子，生成不饱和键——**消去**。
2. **典型反应条件速判**：
   - “光照”“$FeX_3$”“浓硫酸/△（酯化或硝化）”“$NaOH$水溶液/△（卤代烃水解）” → 常为取代。
   - “$Ni/△$ 与 $H_2$”“$Br_2/CCl_4$”“$HX$”“催化剂、加热、加压”且不饱和键消失 → 常为加成。
   - “浓硫酸/170℃（醇）”“$NaOH$醇溶液/△（卤代烃）” → 消去。
3. **逐项排查法**：对于选择题，按序号依次用①②③④判断，用排除法快速锁定答案。特别注意酯化反应容易误判为非取代，其本质为酸脱羟基醇脱氢的取代。

## 高频易错
- **酯化反应不是消去也不是脱水缩合**：教材定义酯化属于取代反应，许多同学因看到生成水而误以为消去，务必牢记酯化机理是取代。
- **苯的硝化、磺化都是取代**：苯环上氢原子被 $-NO_2$、$-SO_3H$ 代替，符合取代定义。
- **烯烃与溴水或溴的四氯化碳溶液**：是加成，因双键断裂加上两个溴原子，产物唯一，不是取代。
- **误判“体积变化”或“分子数变化”**：取代反应产物分子数不一定增多（如酯化反应：2分子→2分子），不能以分子数作为绝对标准。
- **注意“反应条件”诱导**：如 $CH_3CH_2OH$ 与浓硫酸共热，140℃生成乙醚是取代（分子间脱水），170℃生成乙烯是消去，条件不同反应类型截然不同。

## 代表题精讲
**题目**：（2011新课标）判断下列反应属于取代反应的是：  
① $CH_3CH\!=\!CH_2 + Br_2 \rightarrow CH_3CHBrCH_2Br$  
② $CH_3CH_2OH \rightarrow CH_2\!=\!CH_2 + H_2O$  
③ $CH_3COOH + CH_3CH_2OH \rightarrow CH_3COOCH_2CH_3 + H_2O$  
④ $C_6H_6 + HNO_3 \rightarrow C_6H_5NO_2 + H_2O$

**思路**：熟记取代、加成、消去的定义与典型代表，逐项分析断键方式和产物种类。①为烯烃与溴反应，双键打开加溴，产物唯一→加成；②为醇脱去水生成烯烃→消去；③为酸与醇生成酯和水，属于酯化反应→取代；④为苯环上氢被硝基替代→取代。因此③④正确。

**步骤**：
1. 分析①：反应物丙烯含碳碳双键，与 $Br_2$ 反应后双键打开，两个溴原子分别加到两个碳上，只生成一种产物，无小分子副产物→ **加成反应**，排除。
2. 分析②：乙醇在浓硫酸、170℃下分子内脱去一分子水，生成乙烯，碳骨架从不饱和键无到有→ **消去反应**，排除。
3. 分析③：乙酸与乙醇反应，乙酸中羧基的 $-OH$ 被乙醇的 $-OC_2H_5$ 替代，生成酯和水，原子团发生交换→ **取代反应（酯化）**，入选。
4. 分析④：苯与硝酸在浓硫酸催化下，苯环上一个 $-H$ 被 $-NO_2$ 替代，生成硝基苯和水→ **取代反应（硝化）**，入选。
5. 综合：属于取代反应的是③④。

**点评/变式**：
- 本题为经典的反应类型判断题，核心在于准确记忆四大基本反应类型（取代、加成、消去、聚合）的定义及代表物。
- 变式：可将反应条件做变形，如给出 $CH_4 + Cl_2 \xrightarrow{光照}$（取代），$CH_2\!=\!CH_2 + H_2O \xrightarrow{催化剂}$（加成），$CH_3CH_2Br + NaOH \xrightarrow{乙醇/△}$（消去），反复训练“条件—类型”对应关系。
- 强化：酯化反应和水解反应互为可逆，均属取代；卤代烃在 $NaOH$ 水溶液中水解是取代，在 $NaOH$ 醇溶液中消去是消去，对比记忆更牢固。
