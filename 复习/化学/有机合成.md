## 知识精要  
- **有机合成核心任务**：构建碳骨架（碳链增长/缩短/成环）与官能团转化（引入、消除、保护和变换）。  
- **常见碳骨架构建反应**  
  - 碳链增长：羟醛缩合、格氏试剂与羰基化合物加成、烷基化（氰化物取代、炔化物烷基化）、Diels‑Alder 反应等。  
  - 碳链缩短：烯烃、炔烃氧化断键，脱羧反应等。  
  - 成环：狄尔斯‑阿尔德反应、分子内酯化/缩合等。  
- **官能团转化总结表**（精选真题高频转化）  

| 目标转化 | 常用试剂与条件 | 反应类型 |
|----------|----------------|----------|
| **醇 → 醛/酮** | 氧化：$KMnO_4/H^+$（控制条件）、$CrO_3$/吡啶、催化氧化$O_2/Cu$ | 氧化反应 |
| **醇 → 羧酸** | 强氧化：$KMnO_4/H^+$、$K_2Cr_2O_7/H^+$、$HNO_3$ | 氧化反应 |
| **醛/酮 → 醇** | $NaBH_4$、$LiAlH_4$、催化加氢($H_2/Ni$)、与格氏试剂加成后水解 | 还原/加成 |
| **卤代烃 → 醇** | $NaOH$水溶液加热（水解） | 取代反应 |
| **卤代烃 → 烯烃** | $NaOH$醇溶液加热（消去） | 消去反应 |
| **醇 → 卤代烃** | $HX$、$PX_3$、$SOCl_2$ | 取代反应 |
| **烯烃 → 卤代烃** | $HX$、$X_2$（加成）；$NBS$/光照（烯丙位溴代） | 加成/取代 |
| **羧酸 → 酯** | 醇 + 浓$H_2SO_4$，加热（酯化） | 酯化反应 |
| **酯 → 羧酸 + 醇** | 酸或碱催化下水解 | 水解反应 |
| **芳香烃侧链氧化** | $KMnO_4/H^+$加热 → 苯甲酸（与苯环相连的碳上有$H$即可氧化） | 氧化反应 |
| **硝基 → 氨基** | $Fe/HCl$、催化加氢($H_2/Pd$) | 还原反应 |
| **氨基 → 酰胺** | 酰氯或酸酐 | 缩合反应 |

- **保护基原理**：多官能团分子中，某一官能团在所需反应条件下不稳定时，先将其转化为惰性基团，事后再复原。例如：羟基可先成醚或酯保护，羰基可成缩醛/缩酮保护。  
- **逆合成分析（合成子法）**：从目标分子推出前体，断开化学键识别合成子，匹配等价试剂，直到简单易得的起始原料。  
- **反应条件与现象**  
  - 酯化反应：浓硫酸催化，可逆，加热回流，常需分水器；  
  - 卤代烃水解/消去：碱的水溶液（加热）→醇，碱的醇溶液（加热）→烯烃；  
  - 侧链氧化：酸性高锰酸钾加热，苯甲酸析出冷却过滤得晶体；  
  - 格氏试剂反应：无水无氧，醚作溶剂，加成后需酸水解。  
- **高分子合成**  
  - 加聚反应：含不饱和键单体（烯、炔等）通过加成聚合；  
  - 缩聚反应：含两个或多个官能团单体脱水或脱小分子（酯化、酰胺化、酚醛缩合），如聚酯（PPG）、聚碳酸酯（PC）、环氧树脂。

## 解题方法与套路  
1. **有机推断“三看一利用”**  
   - 看分子式变化：比较相邻物质分子式差值，推断反应类型（加/减 $H_2O$、$HCl$、氧化得失氧等）。  
   - 看特征条件：光照（烷基卤代）、$NaOH/醇$（消去）、$O_2/Cu$（催化氧化）、$LiAlH_4$（还原）、浓硫酸加热（消去/酯化）等。  
   - 看结构信息：核磁共振氢谱峰数目→氢种类，对称性；IR吸收峰→官能团。  
   - 利用已知信息反应：题目所给信息方程式（如格氏试剂加成、D‑A反应、醛缩合）必须作为模板套用到流程中。  

2. **合成路线设计四步法**  
   - 步骤一：对比原料和目标分子的碳骨架变化，确定碳链增长或缩短方式，画出碳骨架构建顺序。  
   - 步骤二：找出官能团差异（种类、位置、数目），设计转化顺序，必要时加入保护基。  
   - 步骤三：选择每一步的试剂和条件，注意反应的选择性和兼容性。  
   - 步骤四：从头到尾检查条件是否冲突（如碱性步骤后不能直接加酸性试剂酸化且未中和等）。  

3. **同分异构体书写策略**  
   - 限定条件型：先确定官能团，然后取代基位置异构，最后碳链异构，并检查顺反异构、对映异构。  
   - 核磁共振氢谱型：峰面积比→氢原子数目比，峰数→对称性。先从对称结构入手。  

4. **实验制备类题目答题模板**  
   - 仪器名称：三颈烧瓶、球形冷凝管、分液漏斗等。  
   - 操作目的：回流、控温、趁热过滤（防止产品析出损失）、冰水浴冷却（降低溶解度析晶）、洗涤（冷水洗除杂质、乙醇洗除有机物）。  
   - 纯度计算：滴定数据→物质的量→纯度，注意容量瓶取样比例换算。  
   - 产率计算：实际产量÷理论产量×100%，注意限速试剂判断。  

5. **有机合成路线图填充套路**  
   - 先确定前后物质的结构片段，利用条件反推中间体结构。  
   - 遇信息反应：将原料结构按信息反应式对应位置嫁接，写出产物。  
   - 缺步骤推断：对比反应前后官能团变化，补写常见转化。

## 高频易错  
- **反应条件混淆**：$NaOH$水溶液/醇溶液功能不同，前者水解（-OH取代），后者消去（生成不饱和键）。  
- **官能团位置选择性忽略**：甲苯侧链氧化无论侧链多长，只要有α‑H均氧化为苯甲酸；但若与苯环相连的碳上无氢（如叔丁基苯）则不被氧化。  
- **酯化反应可逆，醇和羧酸均可能过量**，写方程式勿忘“浓$H_2SO_4$、加热”和可逆符号。  
- **格氏试剂制备与反应条件**：必须在无水无氧中，否则与 $H_2O$ 反应失效；加成后需 $H^+/H_2O$ 水解得醇。  
- **保护基决策失误**：例如先氧化侧链甲基为羧基，后想还原醛基，此时羧基也会被还原，必须提前保护羧基。常见遗忘保护。  
- **同分异构体数目遗漏**：苯环上的位置异构（邻、间、对）、取代基异构（丙基与异丙基）及顺反异构体均要全面考虑。  
- **合成路线设计顺序不合理**：先引入某基团导致后续反应选择性降低，如先硝化再溴代定位矛盾。  
- **实验操作描述笼统**：如“洗涤”未指明用冷水、热水还是有机溶剂；“干燥”方法不具体（晾干、烘干、用干燥剂）。  
- **纯度计算忽略取样比例**：如配成 $100\,\mathrm{mL}$ 取 $25\,\mathrm{mL}$ 滴定，计算时须乘倍数。  
- **有机反应方程式中漏写副产物**：取代、消去、酯化常附带 $H_2O$、$HX$ 等小分子，配平需完整。

## 代表题精讲  
### **2024-辽宁-19 特戈拉赞合成**  
**题目简述**：以构建特戈拉赞（化合物 K）的合成路线为背景，路线中涉及苯环取代、杂环构建、多步官能团转化等。  
**思路**：根据路线框图中分子式及结构片段变化，结合信息反应条件，逆向推导或正向填充中间体；关键步骤如硝化、还原、酰化、环合等，需利用题目提供的特殊反应（如缩合环化）推断结构。  
**步骤**：  
1. 对比各步分子式和已知片段，补填中间体 A ~ J 的结构简式。  
2. 识别反应类型：硝化（混酸）、还原（$Fe/HCl$）、酰胺化（酰氯）、缩合成环等。  
3. 写出由某关键中间体到 K 的反应方程式，注意条件和小分子。  
4. 同分异构体书写：依限定条件（含某种基团、氢谱特征）逐一列出。  
**点评**：本题融合芳香族化学和杂环合成，重点考察逆推能力和信息迁移。变式训练可强化环合反应机理的理解。  

### **2023-新课标-09 二苯乙二酮制备**  
**题目简述**：实验室由安息香氧化制备二苯乙二酮，给出反应式、物质性质表及实验流程，涉及装置选择、操作目的分析和纯度计算。  
**思路**：根据氧化反应原理和溶解度表格，解释操作步骤并计算产率或纯度；注意氧化剂 $FeCl_3$ 和冰乙酸的作用，产品分离提纯措施。  
**步骤**：  
1. 结合熔点、溶解性，理解步骤①中加热溶解的目的，以及用水和冰乙酸的混合溶剂原因（增加溶解度）。  
2. 反应结束后，根据产品难溶于水，易溶于乙醇、苯、乙酸的性质，解释后处理方法（如过滤、水洗、重结晶）。  
3. 纯度或产率计算：利用反应计量关系，确定限速试剂，理论产量=(实际量/摩尔质量)×产物摩尔质量；产率=实际产品÷理论产量×100%。  
4. 回答装置图中冷凝管、温度计位置等常见仪器问题。  
**点评**：此类实验制备题突出物质分离提纯与条件控制；失分点常在产率计算时忽略摩尔比或操作目的回答不准确。变式可练习苯甲酸制备、乙酸乙酯制备等类似流程。  

### **2020-新课标Ⅱ-09 苯甲酸制备与纯度测定**  
**题目简述**：甲苯经 $KMnO_4$ 氧化、亚硫酸氢钠还原过量氧化剂、酸化析出苯甲酸，通过过滤、洗涤、干燥得粗品，再以 $KOH$ 滴定测纯度。  
**思路**：氧化阶段结束后，饱和 $NaHSO_3$ 去掉残余氧化剂（归中反应），酸化使苯甲酸钠变苯甲酸沉淀；纯度用中和滴定，注意取样换算。  
**步骤**：  
1. 解释步骤 (2) 中趁热过滤的目的：去除 $MnO_2$ 沉淀，防止苯甲酸钠冷却析出损失。  
2. 酸化析出完全后，冷水洗涤减少溶解损失；沸水浴干燥是利用苯甲酸升华性质？实际上控制温度，使水分蒸发。  
3. 纯度计算：$n(KOH)=0.01000\,\mathrm{mol\cdot L^{-1}}\times 0.02150\,\mathrm{L}=2.15\times10^{-4}\,\mathrm{mol}$  
   $\to$ 消耗 $KOH$ 的物质的量等于苯甲酸的物质的量（取样部分）。  
   粗产品溶解于 $100\,\mathrm{mL}$ 容量瓶，取 $25.00\,\mathrm{mL}$，所以样品苯甲酸总量为 $n_{\text{总}}=4\times2.15\times10^{-4}=8.60\times10^{-4}\,\mathrm{mol}$  
   $m_{\text{纯}}=8.60\times10^{-4}\times122\,\mathrm{g/mol}\approx0.105\,\mathrm{g}$  
   粗产品称量 $0.122\,\mathrm{g}$，纯度 $= 0.105/0.122\times100\%\approx86.1\%$。  
4. 讨论操作失误对纯度影响：如滴定管未润洗导致体积偏大，纯度偏高。  
**点评**：此题完美结合有机合成实验和定量分析，常考趁热过滤、洗涤溶剂选择、滴定计算及误差分析。变式可拓展为其他有机酸制备与含量测定。
