## 知识精要
有机合成推断是高考有机化学的核心拉分板块，考查从原料出发经官能团转化、碳骨架构建得到目标分子的逻辑链推理。考纲核心知识如下：

- **官能团特征反应与鉴别条件**
  - 羧基：与饱和$NaHCO_3$溶液反应放出$CO_2$；遇紫色石蕊变红。
  - 酚羟基：与$FeCl_3$溶液显紫色；与溴水产生白色沉淀。
  - 醛基：发生银镜反应或与新制$Cu(OH)_2$悬浊液加热产生砖红色沉淀。
  - 碳碳双键/三键：使溴水或酸性$KMnO_4$溶液褪色。
  - 卤代烃：$NaOH$水溶液加热发生水解（取代），$NaOH$醇溶液加热发生消去。
  - 醇羟基：与$Na$反应放出$H_2$；在浓硫酸加热下发生消去（生成烯烃）或分子间脱水（生成醚）；与羧酸发生酯化。
  - 酯基：酸性或碱性条件下水解；碱性水解生成羧酸盐和醇。
- **反应类型与断键成键规律**
  - 取代：烷基苯侧链卤代（光照）、苯环上卤代（$FeX_3$催化）、酯化、水解、醇与$HX$反应等。
  - 加成：$H_2/Ni$与不饱和键（烯、炔、醛、酮、苯环）加成；$HX$、$X_2$、$H_2O$与不饱和键加成（遵循马氏规则，硼氢化-氧化反马氏）。
  - 消去：醇消去（浓$H_2SO_4$，$170^\circ C$）、卤代烃消去（$NaOH/醇$，加热）生成不饱和键。
  - 氧化：醇氧化成醛/酮（$O_2/Cu$、$Ag$）、醛氧化成羧酸（银氨溶液、新制$Cu(OH)_2$、酸性$KMnO_4$）、烯烃氧化断键（臭氧氧化、酸性$KMnO_4$）。
  - 还原：硝基还原为氨基（$Fe/HCl$、$H_2$/催化剂）、羰基还原为羟基。
- **不饱和度与分子式推断**
  - 不饱和度$\Omega = \frac{2C+2+N-H-X}{2}$（$X$为卤素）。一个苯环$\Omega=4$，一个双键$\Omega=1$，一个三键$\Omega=2$。
  - 由分子式变化推断反应类型：加氢去氧则$\Omega$减小；去水消去则$\Omega$增大且$H$、$O$原子数减少。
- **题给信息（陌生反应）的迁移应用**
  - 常见的成环反应、格氏试剂增长碳链、羰基α-H取代、醛酮与羟胺/肼缩合、Claisen酯缩合、酰胺化等。
  - 必须模仿信息中断键位置和产物结构规律，应用到新底物上。
- **同分异构体的书写**
  - 限定条件：分子式相同、含特定官能团种类或数目、等效氢等。
  - 方法：先算不饱和度，确定碳骨架异构，再安排官能团位置，注意对称性和立体异构（若要求）。

## 解题方法与套路
1. **画出起点与终点，抓特征差异**  
   将原料和目标分子对比，找出碳原子数变化、官能团增减、不饱和度差异。起点与终点碳骨架增减是逆合成的关键线索。
2. **标注题给条件，逐段推理**  
   沿合成路线逐一标注试剂/条件，立即联想可能发生的反应类型。例如：“$NaOH/H_2O$，加热” = 卤代烃水解或酯水解；“浓$H_2SO_4$，$\Delta$” = 酯化或醇消去；“$O_2$/催化剂，$\Delta$” = 醇氧化或烯烃环氧化等。
3. **借助“已知”性质锁定特征结构**  
   如“与$NaHCO_3$反应放出$CO_2$” → 含-COOH；“不能与$NaHCO_3$反应” → 排除羧基；“可发生银镜反应” → 含醛基或甲酸酯结构；“遇$FeCl_3$显色” → 含酚羟基。用此类信息排除或确定候选结构。
4. **利用分子式缺口推断中间体**  
   结合步骤的原子变化：$+H_2$ → 加成或硝基还原；$-H_2O$ → 消去或酯化；$+O$ → 氧化；$+Br$ → 加成或取代。将相邻两物的分子式相减，得到“净变化”分子式（如$H_2O$、$HBr$、$O$），推断反应类型。
5. **借鉴题中陌生反应，套用模板**  
   复杂步骤中给出的新反应（如Michael加成、酰胺缩合、还原胺化等），必须在推断时完全模仿。先分析信息反应断键成键部位、催化剂、溶剂，然后在新底物中找到对应官能团进行“复制粘贴”。
6. **逆向与正向结合，验证完整性**  
   遇到多步路线，可从目标物逆推，同时从原料正推，在某个中间体处“会师”。验证每步反应条件和官能团兼容性（如酸性条件下是否破坏其他基团）。
7. **同分异构体策略**  
   先算不饱和度 $\Omega$，分析限制条件（如能发生银镜反应→含醛基），然后写出所有碳骨架，移动官能团位置，最后补充芳香环异构、顺反异构等。注意“核磁共振氢谱峰面积比”可锁定等效氢种类的数目。

## 高频易错
- **反应条件混淆**  
  - $NaOH$水溶液/加热 → 水解取代；$NaOH$醇溶液/加热 → 消去。  
  - 浓硫酸/加热 → 醇消去需控制$170^\circ C$，$140^\circ C$生成醚；醇与酸酯化加热一般$120^\circ C$左右。  
  - 氧化伯醇用$O_2/Cu,\Delta$得醛；用酸性$KMnO_4$或$K_2Cr_2O_7$直接得羧酸。
- **官能团保护遗漏**  
  合成中先氧化再保护，或设计保护基（如保护醛基为缩醛），但题目路线中可能未明确标注，需结合后续条件判断。忽略保护与去保护是推断时卡壳的常见原因。
- **选择性反应判断失误**  
  多个官能团共存时，某一试剂可能优先与某一基团反应，如$NaBH_4$还原醛酮但不还原酯基；$H_2/Ni$可还原碳碳双键、醛基、硝基，通常不还原酯基和羧基（特殊条件除外）。
- **碳骨架重排忽略**  
  某些重排反应（如频哪醇重排、Beckmann重排）会在题给信息中出现，若不严格模仿断键/成键位置，极易推断出错误骨架。
- **信息特征利用不全**  
  如“F不能与饱和$NaHCO_3$溶液反应产生$CO_2$”，只说明无-COOH，不能排除酚羟基、磺酸基等其他酸性基团，进一步分析需结合其他数据。忽略这一点会导致误判。
- **不饱和度计算错误**  
  氮原子贡献+1（$-\frac{N}{2}$应实际上算作+1价），卤素等同取代氢，计算时卤素按-X，式下 $C+1-\frac{H+X}{2}+\frac{N}{2}$。计算错误导致骨架假设偏离。
- **同分异构体数目统计疏漏**  
  苯环上取代基位置异构（邻间对）、侧链异构、顺反异构、手性碳异构（若要求）易遗漏。限定含氧官能团种类时，羧基与酯基、醇羟基与醚键常可互变。

## 代表题精讲
### **2023-新课标-11（莫西赛利合成推断）**
**题目**简述：以某芳香化合物A为起始原料，经多步反应合成莫西赛利(K)。合成路线涉及硝化、还原、酰胺化、醚化等转化。需要推测A的名称及若干中间体的结构简式，并完成反应类型、官能团名称、手性碳等设问。

**思路**：利用终产物K的碳骨架和题中“莫西赛利”结构特点（脑血管药物，含芳香醚、酰胺、手性中心）逆推。识别路线中出现的特征条件：混酸（硝化）、$Fe/HCl$（硝基还原为氨基）、与酰氯反应（酰胺化）、$NaBH_4$（选择性还原羰基）、碳酸钾/卤代烷（醚化）。结合分子式推测A为最简单的芳香烃衍生物。

**步骤**：
- 第一步，从K逆向断开酰胺键，得到羧酸衍生物片段和胺片段。根据题给流程中最后一步酰胺化由某中间体与另一片段缩合，锁定上一级中间体分别为J（酰氯或酸酐）与相应的胺。  
- 第二步，由胺片段的碳原子数和不饱和度，结合芳香区质子信号，推出含苯环且带氨基、醚键的结构。其前体含硝基，对应硝化产物。  
- 第三步，继续逆推至A，通过硝化条件可确定A为苯酚或甲氧基苯等。根据分子式及后续引入的取代基位置，判断A应具有一个可硝化的芳环且未带吸电子基团影响定位。最终确定A为苯酚（或对应的结构名称）。  
- 正验证：苯酚经威廉姆森醚化引入乙基保护，再硝化进入对位，还原、酰胺化、去保护、再反应得到K。

**点评/变式**：本题集中考查了**芳香族化合物的定位效应、保护基策略与官能团转化顺序**。常见变式：将保护基改为苄基或硅醚；酰胺化试剂换成酸酐；或者增加手性合成步骤，需判断手性碳的构型（R/S）。复习时应习惯从后往前拆解复杂活性分子。
