## 知识精要
- 有机物结构推断常用方法：
  - 分子式+不饱和度 → 可能官能团与骨架
  - 核磁共振氢谱（$^1\text{H-NMR}$）：峰组数=化学环境不同的氢原子种类；峰面积比=各类氢原子个数比
  - 化学性质：如遇 $\text{FeCl}_3$ 显色→酚羟基；与 $\text{NaOH}$ 反应→羧基、酚羟基、酯基等；与 $\text{Na}$ 反应→醇羟基、酚羟基、羧基等
- 苯环上等效氢种类：
  - 单取代苯环：3种氢（邻、间、对），峰面积比2:2:1
  - 对位二取代（两个不同取代基）：苯环上2种氢，峰面积比2:2（或1:1）
  - 邻位或间位二取代通常多于2种氢
- 常见反应类型：
  - 取代反应：卤代、酯化、醚化、酚与酰氯或卤代烃等
  - 加成反应：$\ce{C=C}$、$\ce{C=O}$ 等
  - 氧化/还原反应
- 同分异构体书写策略：
  - 先定官能团与不饱和键，再排碳骨架，后移官能团位置
  - 结合核磁氢谱峰组数与面积比确定等效氢分布，反推对称性

## 解题方法与套路
1. **拆解信息，确定关键碎片**：从分子式、明显特征峰（如单峰→高度对称基团，如 $\ce{-O-}$ 或 $\ce{-CH2-}$ 对称环境）、化学计量反应（1 mol 与 $\text{NaOH}$、$\text{Na}$ 反应量）推断含氧官能团种类与个数。
2. **苯环取代模式判断**：“苯环上仅有两种氢”常对应**对位二取代**或具有高度对称性的多取代（如均三取代等），优先考虑对位。
3. **沿合成路线正向或逆向推理**：
   - 对比原料与产物分子式变化，结合反应条件（如 $\ce{SOCl2}$ 常将醇羟基转为氯原子）判断反应类型与中间体结构。
   - 正确书写化学方程式：注明反应条件，有机物写结构简式，无机物写化学式，配平。
4. **确定最终产物分子式**：数清 $\ce{C、H、O、N}$ 等原子个数，注意环状结构或支链，必要时用不饱和度验证。
5. **限定条件同分异构体枚举**：
   - “遇 $\text{FeCl}_3$ 显色”→有酚羟基；$\text{1 mol L}$ 与 $\text{2 mol Na}_2\text{CO}_3$ 反应→含一个酚羟基和一个羧基（或两个酚羟基位于强吸电子环境下，需结合其他条件判断，但通常酚与 $\text{Na}_2\text{CO}_3$ 只生成 $\text{NaHCO}_3$，1 mol 酚羟基消耗 $\text{0.5 mol Na}_2\text{CO}_3$，若消耗 $\text{2 mol}$ 则暗示有 $\text{COOH}$ 或特殊结构），需紧扣化学计量。
   - 根据芳香环上取代基数目与位置，组合出所有可能，再利用等效氢峰面积比筛选。

## 高频易错
- **核磁峰面积比直接当作氢个数**：如 $6:1:1$ 对应两个 $\ce{-CH3}$（等效）+ 一个 $\ce{-CH}$ + 一个 $\ce{-OH}$ 等，忽视隐含的对称性会导致结构错误。
- **苯环上氢种类与取代位置的误判**：对位二取代（两取代基不同）苯环上只有1组峰（4个氢等价吗？不，对位苯环上剩余4个氢处于两种环境：邻位两个等价，间位两个等价，所以两组峰，面积比2:2），若信息说“仅有两种氢”且峰面积比通常为2:2（或1:1），易误判为邻位或间位。
- **酚与 $\text{NaOH}$、$\text{Na}$、$\text{Na}_2\text{CO}_3$ 反应的计量关系**：
  - $\text{1 mol}$ 酚羟基消耗 $\text{1 mol NaOH}$，与 $\text{Na}$ 产生 $\text{0.5 mol H}_2$（即 $\text{1 mol}$ 羟基消耗 $\text{1 mol Na}$）。
  - 酚不与 $\text{NaHCO}_3$ 反应，但与 $\text{Na}_2\text{CO}_3$ 反应生成 $\text{NaHCO}_3$，$\text{1 mol}$ 酚羟基消耗 $\text{0.5 mol Na}_2\text{CO}_3$。本题 $\text{1 mol D}$ 可与 $\text{2 mol Na}$ 反应，说明 $\text{D}$ 含两个活泼氢（如一个酚羟基 $\text{-OH}$ 和一个醇羟基 $\text{-OH}$），而只与 $\text{1 mol NaOH}$ 反应，说明其中只有酚羟基呈酸性反应。混淆会导致 $\text{D}$ 结构推错。
- **同分异构体数目遗漏或重复**：书写时缺乏系统性，如固定一个取代基，移动另一个，未注意对称性导致重复计数。限定核磁氢谱峰面积比时，易忽略对称结构的多种可能。

## 代表题精讲
**题目**（2017新课标Ⅱ卷12，节选合成G路线及问题）  
合成路线涉及 A($\ce{C2H4O}$)→B($\ce{C3H8O}$)→C···→G，已知信息：A 的核磁单峰；B 核磁三组峰 $6:1:1$；D 苯环两种氢，$\ce{1 mol D}$ 与 $\ce{1 mol NaOH}$ 或 $\ce{2 mol Na}$ 反应。需推结构，完成方程、反应类型、分子式及同分异构体等问题。

**思路**  
从特征谱学与性质切入确定 A、B、D，再利用合成路线推 C、E、F、G，最后解同分异构体。

**步骤**  
1. **推断 A**：分子式 $\ce{C2H4O}$，不饱和度 1，核磁单峰说明所有氢等价→只能是具有对称结构的环氧化合物（环氧乙烷），结构简式：$\ce{CH2-CH2}$ 成环（可用键线式表示）。
2. **推断 B**：分子式 $\ce{C3H8O}$（饱和一元醇或醚），核磁三组峰面积比 $6:1:1$→含两个等效甲基和一个 $\ce{CH}$ 及一个活泼氢，结构为 $\ce{CH3-CHOH-CH3}$，名称 2-丙醇。
3. **推断 D**：苯环上仅两种氢→对位二取代。$\ce{1 mol D}$ 与 $\ce{1 mol NaOH}$ 反应→含酚羟基；$\ce{1 mol D}$ 与 $\ce{2 mol Na}$ 反应→含两个活泼氢（酚羟基+醇羟基），且两个氧原子对应 $\ce{-OH}$ 和 $\ce{-CH2OH}$，故 D 为对羟基苯甲醇 $\ce{HO-Ph-CH2OH}$。
4. **合成路线推导**：A 与 B 在酸催化下环氧开环生成醚醇 C（$\ce{HO-CH2-CH2-O-CH(CH3)2}$）。C 与 D 在催化剂下脱水成醚生成 E（二醚结构）。E 在 $\ce{SOCl2}$ 作用下醇羟基被氯取代生成 F（卤代），反应类型为取代反应。F 与胺类发生取代（或缩合）得 G。
5. **G 的分子式**：计数碳、氢、氮、氧原子，得 $\ce{C18H31NO4}$。
6. **同分异构体 L**（$\ce{D}$ 的异构）：$\ce{C7H8O2}$，遇 $\ce{FeCl3}$ 显色→含酚羟基；$\ce{1 mol L}$ 与 $\ce{2 mol Na2CO3}$ 反应→含两个酚羟基（$\ce{1 mol}$ 酚羟基消耗 $\ce{0.5 mol Na2CO3}$，或含羧基，但这里与 $\ce{Na2CO3}$ 反应计量结合分子式，应为苯二酚类）。苯环三取代（两个 $\ce{-OH}$，一个 $\ce{-CH3}$），且核磁氢谱四组峰，峰面积比 $3:2:2:1$→一个甲基（3H），两个等价芳氢（2H+2H），一个酚羟基氢（1H），对应对称结构：两个 $\ce{-OH}$ 互相对位，甲基位于其间位或邻位？分析可得两种结构满足峰面积要求：2,4-二羟基-1-甲基苯和 3,5-二羟基-1-甲基苯（即间苯二酚类甲基衍生物），写出对应结构简式。

**点评/变式**  
有机推断核心在于抓住“结构限定条件”，谱学与化学性质双线验证。苯环上等效氢种类直接限定取代方式。同分异构体组合时先定骨架后定位置，结合对称性与等效氢筛选，是必考题型。类似题可变换官能团（如羧基、醛基）与谱图信息，解题逻辑不变。
