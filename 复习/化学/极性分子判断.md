## 知识精要
- **极性键与极性分子**  
  极性键：不同原子间共用电子对偏移，键有偶极矩，如 $H-Cl$。  
  极性分子：整个分子正负电荷中心不重合，分子偶极矩 $\mu \neq 0$。  

- **判断核心依据**  
  分子极性 = 键的极性 + 空间构型对称性。  
  - 若分子内所有化学键均为非极性键（同种原子），则一定为非极性分子（如 $O_2$、$P_4$）。  
  - 若含极性键，需看空间构型：  
    - 完全对称→非极性分子：$CO_2$（直线形）、$BF_3$（平面三角形）、$CH_4$（正四面体）、$SF_6$（正八面体）。  
    - 不对称→极性分子：$H_2O$（V形）、$NH_3$（三角锥形）、$SO_2$（V形）。  

- **常见分子极性速记**  
  - 极性分子：$H_2O$、$NH_3$、$H_2O_2$、$CH_3Cl$、$HCl$、$SO_2$、$H_2S$、$NF_3$、$O_3$（V形）。  
  - 非极性分子：$CO_2$、$CS_2$、$CCl_4$、$BF_3$、$PCl_5$、$SF_6$、$C_6H_6$、$CH_4$。  

- **适用条件**  
  基于价层电子对互斥（VSEPR）模型确定构型，结合电负性差异；适用于共价型分子，不适用离子晶体判断。

## 解题方法与套路
1. **先看原子种类**  
   若分子中所有原子均相同，直接判定为非极性分子（如 $P_4$、$S_8$）。  
2. **再查中心原子杂化与孤电子对**  
   用 VSEPR 计算中心原子价层电子对数，确定空间构型：  
   - 杂化轨道类型：$sp$ → 直线形；$sp^2$ → 平面三角形（或 V 形）；$sp^3$ → 四面体形（或三角锥形、V 形）。  
   - 孤电子对导致构型不对称，极易产生极性。  
3. **判断空间对称性**  
   - 所有相同共价键矢量合是否为零。  
   - 若分子内正、负电荷中心可重合，则为非极性分子。  
4. **特例反查**  
   如 $O_3$ 虽由同种原子组成，但中心氧有孤对，构型 V 形且电荷分布不均，为极性分子。需注意“同原子不一定非极性”的例外。

## 高频易错
- **误用“有极性键就是极性分子”**  
  $CO_2$ 有极性键但直线对称，为非极性分子；$CCl_4$ 键极性但完全对称，非极性。  
- **忽略孤电子对效应**  
  $NH_3$ 与 $NF_3$ 均为三角锥形，键矩和孤对电子矩同向叠加，极性更强。$BF_3$ 无孤对，平面三角形，非极性。  
- **把结构相似的分子直接类比**  
  $CH_4$ 非极性，但 $CH_3Cl$ 为极性；$CCl_4$ 非极性，但 $CHCl_3$ 为极性。取代基对称性被破坏则产生极性。  
- **错判“顺反异构”的极性**  
  顺式-二氯乙烯空间不对称，为极性分子；反式-二氯乙烯高度对称（平面，偶极矩矢量抵消），为非极性分子。  
- **混淆“键的极性”与“分子极性”的考查**  
  题目常设置“含有极性键的非极性分子”选项，需通过构型综合判断。

## 代表题精讲
### **题目** 2023·新课标·06（节选）  
以 $Fe^{2+}$ 配合物为催化中心将 $NH_2OH$ 与 $NH_3$ 转化为肼的反应历程中，涉及若干含氮分子。下列分子极性判断或相关描述错误的是（ ）  
A. $NH_3$ 是极性分子，空间构型为三角锥形  
B. $NH_2OH$ 是极性分子，分子中 N—O 键为极性键  
C. $NH_2NH_2$ 中 N 原子均为 $sp^3$ 杂化，分子为非极性分子  
D. 反应过程中 $Fe^{2+}$ 的配位数未发生变化  

#### **思路**  
先提取关键分子 $NH_3$、$NH_2OH$、$NH_2NH_2$，运用分子极性判断套路：分析中心原子杂化、空间构型、取代基对称性。肼的构型需要类比 $H_2O_2$ 而非乙烷，注意旋转与偶极矩。

#### **步骤**  
1. $NH_3$：N 采取 $sp^3$ 不等性杂化，有 1 对孤电子对，三角锥形，键矩与孤对电子矩无法抵消 → 极性分子。A 正确。  
2. $NH_2OH$：羟胺，N 与 O 均为 $sp^3$ 杂化，N—O 键因电负性（O > N）为极性键，分子整体因 N 上孤对及 O—H 弯曲结构不对称 → 极性分子。B 正确。  
3. $NH_2NH_2$：肼，每个 N 为 $sp^3$ 杂化，有一对孤对电子，两 N 通过 σ 键连接并可绕键旋转。类似 $H_2O_2$，其优势构象为邻位交叉，两个孤对电子与 N—H 键的偶极矩不能完全抵消，因此 **肼是极性分子**（$\mu \approx 1.85~D$）。C 项说“非极性分子”，错误。  
4. D 项涉及配合物，需结合历程示意图判断，配位数可能因底物配位与离去而变化，题中常设为不变，错误选项通常是 C。  

#### **点评/变式**  
本题以肼合成新情境为载体，实际考查 VSEPR 与分子极性判断的核心素养。易错点在于误以为肼类似乙烷而对称非极性，忽略了 N 上的孤对电子与扭转构象产生的偶极矩。  
**变式**：比较 $C_2H_6$（非极性）与 $N_2H_4$（极性）的差异；或判断羟胺是否为极性分子；将 $NH_2OH$ 与 $H_2O_2$ 类比均能加深对称性与孤对电子影响的理解。
