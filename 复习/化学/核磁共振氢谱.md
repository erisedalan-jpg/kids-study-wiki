## 知识精要
- **核磁共振氢谱（¹H NMR）核心信息**  
  ① **吸收峰组数** = 分子中不同化学环境的氢原子**种类数**（等效氢只有一组峰）。  
  ② **峰面积（积分高度）之比** = 不同种类氢原子**数目之比**（最简整数比）。结合分子式或氢原子总数可推算出每组氢的绝对个数。  
  ③ **单峰/单一吸收峰**：分子高度对称，所有氢化学环境完全相同（如环戊烷、环氧乙烷、对苯二取代物中某些情况）。  

- **常见结构对应的谱特征**  
  - **高度对称的烃**：如环戊烷 $ \ce{C5H10} $（$70$），仅一种氢，单峰。  
  - **环氧乙烷** $ \ce{C2H4O} $：两个亚甲基等价，单峰。  
  - **2‑丙醇**：三组峰，峰面积比 $6:1:1$（两个甲基的 $6$ 个H、次甲基 $1$ 个H、羟基 $1$ 个H）。  
  - **苯环含两种不同化学环境氢**：对位二取代苯的苯环上可能呈两组对称的峰（面积比依取代基而定）。  

- **综合推断必结合信息**  
  分子式、官能团反应、不饱和度、对称性、其他谱学数据（如质谱、红外）。核磁共振氢谱给出的是**氢的等价性及个数比**，是推断有机物结构的核心依据之一。

## 解题方法与套路
1. **读谱抓关键**  
   - 数清峰组数 → 确定几种不同化学环境的氢原子。  
   - 列出各峰面积比 → 氢原子个数最简比。  
2. **结合分子式求氢原子总数**  
   - 由分子式得到总氢数，将比例倍乘使和为总氢数，得各组氢绝对数目。  
3. **推断结构片段**  
   - 根据化学性质（如与Na、NaOH、$\ce{FeCl3}$等反应）确定官能团种类与数目。  
   - 利用不饱和度、碳骨架信息限定可能结构。  
   - 结合氢谱的峰组数与峰面积比，排布官能团位置、取代基位置，满足对称性要求。  
4. **验证与书写**  
   - 检查各氢原子是否确实等价（对称性分析），确认无遗漏。  
   - 书写结构简式，完成推断填空。

## 高频易错
- **错把比例当绝对个数**：必须结合分子式或总氢数换算，否则直接用于书写结构会出错。  
- **忽略分子的对称性**：苯环上“两种不同化学环境的氢”可能是对位取代导致左右对称，误以为有四种氢。  
- **混淆单峰与无吸收**：单峰是只有一类氢，不是没有氢信号；如环氧乙烷四个氢全部等价，只出一个单峰。  
- **官能团活泼氢归属错误**：–OH、–NH₂等活泼氢在核磁共振氢谱中可出现独立峰（如2‑丙醇中OH给出独立峰），易忽略或错误计数。  
- **同分异构体计数时漏项**：根据核磁共振氢谱的峰面积比排列取代基时，未考虑位置异构的对称性可能产生重复结构导致漏数或多算。

## 代表题精讲
### **题目1**（2017·新课标Ⅱ·12）  
已知 $ \ce{C2H4O} $（A）核磁共振氢谱为单峰，B的核磁共振氢谱三组峰，峰面积比 $6:1:1$；D的苯环上仅有两种不同化学环境的氢，且 $1\;\text{mol}$ D 可与 $1\;\text{mol}$ NaOH 或 $2\;\text{mol}$ Na 反应。推断整条合成路线中各物质结构。

- **思路**  
  由A单峰+分子式 $\ce{C2H4O}$ → 高度对称的环氧化物（环氧乙烷）；B三组峰 $6:1:1$ 且后续转化中产生2‑丙醇结构，确证B为2‑丙醇。D含酚羟基（与 $ \ce{FeCl3} $ 显色）和醇羟基（与Na反应）→ 苯环二取代，两种氢 → 对位取代。结合反应条件推导E、F、G。

- **步骤**  
  1. A：不饱和度 $1$，只有一种氢，必为三元环醚 $\ce{CH2\bond{1}CH2\bond{1}O}$。  
  2. B：三组峰 $6:1:1$，示有 $6$ 个等价甲基氢+ $1$ 个次甲基氢+ $1$ 个羟氢，结构 $\ce{(CH3)2CHOH}$。  
  3. D：$\ce{C6H?O?}$ 与酚羟基显色，$1\;\text{mol}$ 消耗 $1\;\text{mol}$ NaOH → 一个酚羟基；消耗 $2\;\text{mol}$ Na → 另一个为醇羟基；苯环两种氢 → 对位二取代，故D为对羟基苯甲醇。  
  4. 依题设反应推出E、F、G结构，并完成L的同分异构体书写。

- **点评/变式**  
  本题核磁共振氢谱信息贯穿起始物与中间体的推断，重点考查**从峰组数和面积比反推近似对称结构**的能力。变式：若单峰分子式为 $\ce{C3H6O}$（丙酮？不对，丙酮有两组峰；环丙醇？），则需结合不饱和度，可能为环丙醇（三种氢），单峰不符合，应为 $\ce{CH3OCH2CH3}$ 但有两类氢……此时要联想高度对称环氧丙烷？可采用相同逻辑排除。

### **题目2**（2015·新课标Ⅱ·13）  
烃A相对分子质量 $70$，核磁共振氢谱仅一种化学环境的氢；B为单氯代烃；C分子式 $\ce{C5H8}$；E、F为相差 $14$ 的同系物，F为福尔马林溶质。合成可降解聚酯PPG。

- **思路**  
  A相对分子质量 $70$，只一种氢 → 环戊烷（$\ce{C5H10}=70$，所有氢等价）。B为单氯代环戊烷。后续经消去、氧化开环等得到戊二酸丙二醇酯型聚合物的单体。

- **步骤**  
  1. A的氢谱单峰+$M=70$ → 高对称环烷烃 $\ce{C5H10}$，即环戊烷。  
  2. A氯化得单氯代物B，再消去HCl得环戊烯（C，$\ce{C5H8}$）。  
  3. C氧化开环得戊二醛（F为甲醛，E为乙醛？实际E、F为同系物差$14$，F即甲醛，E则为乙醛，二者与环戊烯反应？参照原题信息）→ 最终合成聚戊二酸丙二醇酯。  
  4. 利用核磁共振氢谱确证中间体结构正确性。

- **点评/变式**  
  本题起点是烃A的**唯一氢环境和相对分子质量**联合限制，提示考生必须掌握常见对称烃的分子量和结构。类似推理可迁移至：$M=84$ 只一种氢 → 环己烷；$M=56$ 只一种氢 → 环丁烷，但要核查不饱和度，烯烃若对称也可有一种氢（如2,3-二甲基-2-丁烯 $\ce{C6H12}$，但分子量 $84$）。举一反三，熟记典型对称结构，快速破题。
