## 知识精要
- **气态氢化物热稳定性**：指氢化物受热分解的难易程度，热稳定性越高，越难分解。
- 判断依据：元素的**非金属性越强**，其气态氢化物热稳定性**越强**。
- 元素非金属性递变规律：
  - 同周期（从左→右）：非金属性逐渐增强 → 氢化物稳定性逐渐增强，如 $ \text{SiH}_4 < \text{PH}_3 < \text{H}_2\text{S} < \text{HCl} $。
  - 同主族（从上→下）：非金属性逐渐减弱 → 氢化物稳定性逐渐减弱，如 $ \text{HF} > \text{HCl} > \text{HBr} > \text{HI} $；$ \text{NH}_3 > \text{PH}_3 > \text{AsH}_3 $。
- 典例：$ \text{NH}_3 $（N 非金属性强）稳定性远大于 $ \text{PH}_3 $（P 非金属性弱），$ \text{H}_2\text{O} $ 稳定性大于 $ \text{H}_2\text{S} $。
- 联系：最高价氧化物对应水化物的酸碱性与非金属性/金属性直接相关，金属性越强，碱性越强；非金属性越强，最高价含氧酸酸性越强。

## 解题方法与套路
1. **元素推断优先**：利用题目中的原子结构特点、化合价关系、周期表位置等条件，快速锁定元素种类。如短周期主族元素，最高正价=最外层电子数（O、F除外），最高正价与最低负价绝对值之和常为8。
2. **构建位—构—性关系图**：画出元素在周期表中的相对位置，明确其所在周期和主族，建立“位置→结构→性质”的推导链条。
3. **氢化物稳定性比较两步走**：
   - 先看是否为同一周期或同一主族；
   - 利用元素非金属性强弱直接得出氢化物稳定性顺序：非金属性越强，氢化物越稳定。涉及 N、P、As 等常见变价元素时，牢记 $ \text{NH}_3 $ 很稳定。
4. **全维度验证选项**：逐项检查原子半径（同周期左大右小，同主族上小下大）、单质状态、氢化物稳定性、最高价氧化物水化物的酸碱性等，用两个以上规律交叉验证，避免粗心错判。

## 高频易错
- **混淆“氢化物稳定性”与“氢化物酸性”**：$ \text{HF} $ 最稳定，但为弱酸；$ \text{HI} $ 很不稳定，反而是强酸。稳定性由共价键键能及非金属性决定，与酸性强弱无关。
- **短周期特殊元素忽略**：O、F 无最高正价，通常不参与最高化合价之和计算；O、F 的氢化物 $ \text{H}_2\text{O} $ 和 $ \text{HF} $ 稳定性极强。
- **元素推断中化合价陷阱**：如 W 与 X 最高化合价之和为 8，常误以为 W、X 最外层电子数直接相加为 8，需注意 X 在最外层电子数可能为 x-2 等相对位置关系。
- **最高价氧化物水化物酸碱性混淆**：铝是金属，但其氧化物 $ \text{Al}_2\text{O}_3 $ 和氢氧化物 $ \text{Al(OH)}_3 $ 为两性，不是强碱。此类“伪强碱”在选项中出现频率高，必须警惕。

## 代表题精讲
**题目**：2019 新课标Ⅱ 第 3 题——给出周期表部分片段，短周期主族元素 W、X、Y、Z，W 与 X 最高化合价之和为 8，判断说法错误选项。

**思路**：先根据 W 位于第二周期、X、Y、Z 位于第三周期，设 W 最外层电子数为 x，X 最外层电子数由其左边位置的 W 推导：W 在 X 的上一行且偏右，故 X 最外层电子数为 x-2。利用最高价=最外层电子数（主族），列方程 x + (x-2)=8，解得 x=5，W 为 N。则 X 为 Al，Y 为 Si，Z 为 P。然后逐一验证选项。

**步骤**：
- 推断元素：由周期表片段，W 第二周期，X 第三周期且位于 W 的左下位置 → X 最外层电子数 = W 最外层电子数 −2；W 位于 VA 族，为 N；X 为 Al，Y 为 Si，Z 为 P。
- A 选项：原子半径，N 位于第二周期，Al 第三周期，电子层越多半径越大，故 N<Al，正确。
- C 选项：气态氢化物热稳定性 $ \text{PH}_3 $（Z）与 $ \text{NH}_3 $（W）比较。N 的非金属性远强于 P，所以稳定性 $ \text{NH}_3 > \text{PH}_3 $，即 Z（$ \text{PH}_3 $）< W（$ \text{NH}_3 $），正确。
- D 选项：X 的最高价氧化物水化物为 $ \text{Al(OH)}_3 $，属于两性氢氧化物，不是强碱，错误。答案选 D。

**点评/变式**：此题将氢化物稳定性嵌入元素推断与多性质比较中，属于典型的“位—构—性”综合题。即使 C 选项正确，也需完整推断所有元素，否则可能误以为 Z 的非金属性更强而失分。变式可改为给出氢化物稳定性相对强弱反向推断元素位置，或与最高价含氧酸酸性比较结合，解题核心仍是紧扣非金属性递变规律。
