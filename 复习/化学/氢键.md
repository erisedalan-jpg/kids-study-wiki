## 知识精要
- **氢键的定义**：与电负性大、半径小的原子 $X$（$\ce{N,O,F}$）以共价键结合的氢原子 $H$，与另一个电负性大、半径小的原子 $Y$（$\ce{N,O,F}$）的孤对电子之间产生的静电吸引和部分共价键性质的相互作用，表示为 $\ce{X-H\bond{...}Y}$。
- **形成条件**：分子中必须存在 $\ce{N-H}$、$\ce{O-H}$ 或 $\ce{H-F}$ 等强极性键；另一个分子或同一分子其他部位必须有含孤对电子的 $\ce{N}$、$\ce{O}$、$\ce{F}$ 原子。
- **特征**：氢键比化学键弱，比范德华力强；有方向性和饱和性（$H$ 与 $Y$ 的对位结构）；分子间氢键使物质沸点、溶解度升高（如水、$\ce{HF}$、$\ce{NH3}$ 反常）；分子内氢键常使沸点降低、溶解度减小；对超分子自组装和晶体堆积起关键作用。
- **表示方法**：$\ce{X-H\bond{...}Y}$，如图中虚线所示，如 $\ce{(NH4+) N-H\bond{...}Cl}$、$\ce{(H3O+) O-H\bond{...}N}$。
- **对性质的影响**：使熔点、沸点、汽化热、溶解度出现反常升高；维持生物分子（蛋白质、DNA）空间构型；超分子体系（如环糊精包合）中的重要识别驱动力之一。

## 解题方法与套路
1. **识“氢”探“孤”法**：先确认分子（或离子）中是否存在 $\ce{N-H}$、$\ce{O-H}$、$\ce{F-H}$ 共价键；再查找同一分子内或相邻分子间是否存在有孤对电子的 $\ce{N}$、$\ce{O}$、$\ce{F}$ 原子，且空间距离合适，则可形成氢键。
2. **图示与表示式互推法**：根据晶胞或分子结构图，虚线通常代表氢键，从电负性原子 $X$（带 $H$）指向孤对电子供体 $Y$。书写为 $[\ce{X-H\bond{...}Y}]$，并标明供体和受体的化学环境来源，如 $\ce{(NH4+)N-H\bond{...}Cl-}$。
3. **性质推断法**：若题目问及熔沸点异常、溶解性较大、第一电离能反常（如 $\ce{N}$ 的 $E_1$ 异常因为 $\ce{2p^3}$ 半满）、杂化类型和空间构型等，可先分析氢键作用，再结合电子排布半满全满稳定规律作答。
4. **排除干扰项**：注意分子内氢键与分子间氢键的不同影响；注意氢键不是化学键，不改变原子的价层电子对数计算。在超分子体系中，氢键仅是作用力之一，判断包合作用的驱动力要综合考虑极性、范德华力等。

## 高频易错
- **误将氢键当成化学键**：计算σ键数目、杂化类型、价层电子对数时，氢键不计入σ键总数，不改变中心原子杂化。
- **氢键供受体判断错误**：如 $\ce{(NH4+)}$ 中 $N-H$ 是供体，$\ce{Cl-}$ 离子（有孤对电子）是受体，书写顺序不可颠倒，箭头指向电子供体（孤对电子一方）。
- **第一电离能与电子亲和能异常**：$\ce{N}$ 原子的 $2p$ 半充满稳定，电离能比 $\ce{O}$ 高，电子亲和能出现负异常，答题时常忽视半满全满效应。
- **混淆杂化与氢键的存在**：平面结构的离子（如 $\ce{[C(NH2)3]+}$）碳和氮均为 $sp^2$ 杂化，但氢键的存在与否不直接由杂化决定，需结合结构图中原子间距和虚线标识。
- **未成对电子数排序错误**：$\ce{N}$ 的 $2p^3$ 有三个未成对电子，$\ce{O}$、$\ce{C}$ 为两个，$\ce{B}$ 为1个，不能凭臆断排序。
- **超分子包合作用的绝对化**：“均可”“全部”等表述往往是错误项，如环六糊精空腔极性较小，优先包合非极性或极性匹配的分子，并非所有非极性分子均可包合。

## 代表题精讲
### 代表题1：2023-新课标-03
**题目**：材料含 $\ce{[C(NH2)3]+}$ 和 $\ce{[B(OCH3)4]-}$，结构图中显示存在 $\ce{N-H\bond{...}O}$ 氢键。判断说法正误（氢键、第一电离能、未成对电子、杂化）。

**思路**：先观察图中虚线段连接 $\ce{H}$ 原子与 $\ce{O}$ 原子，确认氢键；利用半满规则比较 $C,N,O$ 第一电离能；写出基态电子排布推断未成对电子数；分析离子中中心原子的价层电子对和空间构型确定杂化。

**步骤**：
1. 找到 $\ce{[C(NH2)3]+}$ 中的 $\ce{-NH2}$ 氢与 $\ce{[B(OCH3)4]-}$ 中的氧之间虚线，即为 $\ce{N-H\bond{...}O}$ 氢键，A正确。
2. 第一电离能顺序：$\ce{C < O < N}$（因 $N$ 的 $2p^3$ 半满稳定），B错误。
3. 基态未成对电子数：$\ce{B}$（$1$）、$\ce{C}$（$2$）、$\ce{O}$（$2$）、$\ce{N}$（$3$），故 $\ce{B < C = O < N}$，C错误。
4. $\ce{[C(NH2)3]+}$ 为平面结构，$C$ 和 $N$ 均为 $sp^2$ 杂化；$\ce{[B(OCH3)4]-}$ 中 $B$ 与四 $O$ 成键，无孤对，$sp^3$ 杂化；$\ce{O}$ 有2孤对与2成键，也为 $sp^3$ 杂化。杂化不完全相同，D错误。

**点评/变式**：此题综合性强，氢键识别与周期表性质结合。注意区分氢键供体和受体。变式训练：可变换阴离子，要求书写新的氢键表示式，或判断含氢键的晶体性质。

### 代表题2：2017-新课标Ⅱ-11
**题目**：给定五氮阴离子盐 $\ce{R}$，其中含 $\ce{H3O+}$、$\ce{NH4+}$、$\ce{N5-}$。要求书写电子排布图、解释电子亲和能趋势及 $\ce{N}$ 异常、分析阳离子异同、指出 $\sigma$ 键数目和 $\Pi^5_6$、写氢键表示式。

**思路**：利用原子结构知识解决(1)(2)；对比 $\ce{H3O+}$ 与 $\ce{NH4+}$ 的中心原子杂化（均为 $sp^3$）、价层电子对数（均为4）、共价键类型（均为 $\sigma$ 键），区别在于立体结构（三角锥形与正四面体）；从结构图数 $\sigma$ 键，根据大π键定义得出 $\Pi^5_6$；氢键表示按供体-受体格式。

**步骤**：
1. 氮 $2s^22p^3$，价层排布图为：$\boxed{↑↓}$ $\boxed{↑}$ $\boxed{↑}$ $\boxed{↑}$ （2s、2p 轨道）。
2. 同周期从左到右核电荷增大，半径减小，故结合电子放热增大；$N$ 的 $2p$ 半满稳定，不易再加电子，$E_1$ 异常小。
3. ① 阳离子相同：A(中心原子 $sp^3$ 杂化)、B(价层电子对数均为4)、D(均为σ共价键)；不同：C(立体构型：$\ce{H3O+}$ 三角锥，$\ce{NH4+}$ 正四面体)。② $\ce{N5-}$ 为 $\ce{V}$ 形五原子链，σ键总数为5 (两两间均为σ键)；参与大π键的原子数5，电子数计算：每个氮提供1个p电子，加上负电荷1，共6电子，故大π键为 $\Pi^5_6$。③图(b)虚线：$\ce{(NH4+)N-H\bond{...}Cl}$、(另一条) $\ce{(H3O+)O-H\bond{...}N}$ (指向 $\ce{N5-}$ 中的 $\ce{N}$)。

**点评/变式**：本题将氢键与原子结构、分子结构综合。注意氢键表示法要求准确标明物种来源。变式：可给出复杂阴离子，要求写出全部氢键表示式。

### 代表题3：2024-辽宁-09
**题目**：环六糊精具有空腔，腔内极性小，可包合某些分子。判断选项：是否属于寡糖、非极性分子均可被包合、甲氧基对位暴露、可用萃取分离。

**思路**：从有机化学知识，环六糊精是低聚糖(寡糖)；空腔极性小，倾向包合非极性或匹配极性的客体，但并非所有非极性分子均可，需考虑尺寸等；图2显示甲氧基对位空间取向暴露于环境中；萃取法适合溶解度差异分离，环六糊精和氯代苯甲醚极性不同可采用。

**步骤**：
1. 环六糊精是葡萄糖缩合物，水解得多个葡萄糖，属于寡糖，A正确。
2. “非极性分子均可被包合”过于绝对，与空腔尺寸、形状匹配相关，B错误。
3. 图2中甲氧基的对位（即苯环另一侧）朝向外部反应环境，C正确。
4. 环六糊精与氯代苯甲醚可通过调节溶剂极性的萃取法分离，D正确。

**点评/变式**：题目融入超分子化学概念，考查氢键以及空腔极性引导的分子识别。易错点在于“均可”绝对化表达。变式：给出不同客体的包合常数，分析氢键和疏水作用贡献。
