## 知识精要
- **物理性质**：无色、有刺激性气味的气体；密度比空气小（$ \rho_{\text{NH}_3} < \rho_{\text{空气}} $）；极易溶于水（1 体积水约溶解 700 体积氨气）；易液化，液氨气化时吸收大量热，可作制冷剂。
- **喷泉实验原理**：氨气在水中溶解度极大，少量水进入烧瓶后溶解大量氨，使瓶内气压急剧降低，外界大气压将水压入烧瓶形成喷泉。成功关键：气密性好、气体干燥、烧瓶内部尽量充满气体。
- **化学性质**  
  1. **与水反应**：$ \mathrm{NH_3 + H_2O \rightleftharpoons NH_3 \cdot H_2O \rightleftharpoons NH_4^+ + OH^-} $，水溶液称氨水，呈弱碱性。氨水中含微粒：$ \mathrm{NH_3,\ NH_3 \cdot H_2O,\ NH_4^+,\ OH^-,\ H^+} $（极少量）和水分子。  
  2. **与酸反应**：遇挥发性酸（浓盐酸、浓硝酸）产生白烟，如 $ \mathrm{NH_3 + HCl = NH_4Cl} $。也可与硫酸等不挥发性酸反应制铵盐。  
  3. **还原性（催化氧化）**：$ \mathrm{4NH_3 + 5O_2 \xrightarrow[\Delta]{Pt/\text{催化剂}} 4NO + 6H_2O} $（工业制硝酸的基础）。氨气在纯氧中可燃烧：$ \mathrm{4NH_3 + 3O_2 \xrightarrow{点燃} 2N_2 + 6H_2O} $。  
  4. **与盐溶液反应**：通入某些盐溶液会生成沉淀（利用碱性），如 $ \mathrm{Al^{3+} + 3NH_3 \cdot H_2O = Al(OH)_3 \downarrow + 3NH_4^+} $。注意氨水为弱碱，不能溶解两性氢氧化物。
- **实验室制法**  
  - 原理：$ \mathrm{2NH_4Cl + Ca(OH)_2 \xrightarrow{\Delta} CaCl_2 + 2NH_3 \uparrow + 2H_2O} $。  
  - 装置：固固加热型（试管口略向下倾斜）。  
  - 收集：向下排空气法（导管口塞棉花防止对流）。  
  - 验满：湿润的红色石蕊试纸变蓝，或蘸浓盐酸的玻璃棒靠近产生白烟。  
  - 干燥：用碱石灰（不能使用 $ \mathrm{P_2O_5} $ 或浓硫酸等酸性干燥剂，也不能用无水 $ \mathrm{CaCl_2} $，因会形成 $ \mathrm{CaCl_2 \cdot 8NH_3} $）。
- **铵盐性质**：均易溶于水；受热易分解（不一定都生成氨气，如 $ \mathrm{NH_4NO_3} $ 在不同温度下产物不同）；与碱共热都会放出氨气，据此可检验铵根。

## 解题方法与套路
1. **氨气“白烟”判断型**：若题中出现“产生白烟”，立即锁定氨气与挥发性酸（HCl、HNO₃等）相遇生成铵盐固体小颗粒；若与不挥发性酸反应则无明显白烟，仅是化合。
2. **喷泉实验分析型**：看到“喷泉”先检查是否易溶气体（NH₃、HCl等）；分析压差形成原因；若需计算烧瓶内溶液浓度，抓住原气体物质的量 $ n $ 和最终溶液体积等于原来气体充满的体积（若充满，则浓度 $ c = \dfrac{1}{V_{\mathrm{m}}} \ \mathrm{mol/L} $，标况下约 $ 0.045 \ \mathrm{mol/L} $，与气体种类无关，仅要求气体充满且完全溶解且溶质不挥发）。
3. **氨水成分与反应计算**：明确溶质以 $ \mathrm{NH_3} $ 计；氨水中存在平衡，计算浓度时注意是弱碱，电离方程式用可逆号；与酸反应时按 $ \mathrm{NH_3} $ 总量计。
4. **制备与净化流程型**：按“发生→干燥→收集→验满→尾气处理”顺序分析；干燥剂只能选择碱石灰（或生石灰、NaOH固体）；尾气用水或酸吸收，注意防倒吸（如倒置漏斗）。
5. **氧化还原方程式书写**：氨气中氮元素化合价 -3，可被氧化成 $ \mathrm{N_2} $（0 价）、$ \mathrm{NO} $（+2 价）等。根据氧化剂强弱判断产物，配平先根据电子守恒，再质量守恒。
6. **实验探究/鉴别型**：鉴别铵根离子——取样品加浓碱加热，湿润红色石蕊试纸变蓝；氨气鉴别——特征刺激性气味、试纸变蓝、白烟。

## 高频易错
- **氨气与酸反应现象混淆**：浓盐酸、浓硝酸挥发，接触氨气产生白烟；稀酸或不挥发性酸不产生白烟，只是中和反应生成铵盐溶液。
- **干燥剂选择错误**：误用无水氯化钙、浓硫酸或 $ \mathrm{P_2O_5} $，因均与氨气反应。牢记只能用碱性或中性干燥剂如碱石灰、CaO、NaOH。
- **氨水中溶质的认知偏差**：氨水中溶质通常视为氨气（$ \mathrm{NH_3} $），但计算溶质质量分数时，$ \mathrm{NH_3} $ 溶于水部分生成 $ \mathrm{NH_3 \cdot H_2O} $，很多题目仍以 $ \mathrm{NH_3} $ 作为溶质计算；书写离子方程式时，弱碱氨水写成 $ \mathrm{NH_3 \cdot H_2O} $ 形式，不能拆。
- **喷泉实验物质的量浓度计算误区**：若气体未充满整瓶（混入空气），则溶液最终占满烧瓶的体积不等于气体原有体积，此时浓度需按实际溶解气体量和最终溶液体积计算，容易直接用 $ 1/22.4 $。
- **铵盐分解规律**：铵盐受热都分解，但不一定生成氨气。例如 $ \mathrm{NH_4NO_3} $ 受热可能发生 $ \mathrm{NH_4NO_3 \xrightarrow{\Delta} N_2O + 2H_2O} $ 或爆炸反应；$ \mathrm{(NH_4)_2SO_4} $ 强热生成 $ \mathrm{NH_3} $ 和硫酸，硫酸不挥发会进一步反应等。需根据氧化性酸根具体分析。
- **尾气处理防倒吸**：氨气极易溶于水，直接插入水中会倒吸，必须采用倒置漏斗、安全瓶等措施。
- **检验氨气的试纸选择**：用湿润的红色石蕊试纸，不能直接用蓝色石蕊试纸或 pH 试纸。

### 【代表题 1】氨气的喷泉实验与浓度计算
**题目**  
同温同压下，用一支容积为 $ V \ \mathrm{L} $ 的烧瓶，通过向下排空气法收集满氨气，完成喷泉实验（假设水充满整个烧瓶且溶质不扩散损失）。计算最终烧瓶内溶液的物质的量浓度（气体摩尔体积用 $ V_{\mathrm{m}} \ \mathrm{L\cdot mol^{-1}} $ 表示）。

**思路**  
喷泉实验后溶液充满烧瓶，体积为 $ V \ \mathrm{L} $，而溶质来自原充满的氨气。求出氨气物质的量 $ n = \dfrac{V}{V_{\mathrm{m}}} $，再除以最终溶液体积 $ V $，即可得 $ c $。

**步骤**  
1. 由理想气体状态可知，充满时氨气物质的量 $ n(\mathrm{NH_3}) = \dfrac{V}{V_{\mathrm{m}}} \ \mathrm{mol} $。  
2. 喷泉结束后，氨气全部溶解，溶液体积为 $ V \ \mathrm{L} $。  
3. 溶液物质的量浓度 $$ c = \frac{n}{V} = \frac{V/V_{\mathrm{m}}}{V} = \frac{1}{V_{\mathrm{m}}} \ \mathrm{mol \cdot L^{-1}} $$。  
4. 若为标准状况，$ V_{\mathrm{m}} \approx 22.4 \ \mathrm{L\cdot mol^{-1}} $，则 $ c \approx 0.045 \ \mathrm{mol\cdot L^{-1}} $。

**点评/变式**  
- 此题暴露常见陷阱：溶液体积若因导管内水预先进入而造成烧瓶内未完全充满溶液，则溶液体积小于 $ V $，需按实际体积计算。  
- 变式：若烧瓶内原本混有少量空气，喷泉后溶液仅占据部分体积，则溶质仍为原有氨气的量，浓度下降。解题时气体物质的量仍按 $ pV = nRT $ 计算，但务必以初始氨气分压对应的物质的量为准。

### 【代表题 2】氨气还原性与催化氧化推断
**题目**  
已知 A 是气体单质，B 是无色有刺激性气味气体，C 为红棕色气体。A 与 B 在一定条件下反应生成 C 和水，且 B 能使湿润红色石蕊试纸变蓝。写出有关反应的化学方程式，并回答 B 参加催化氧化的条件和方程式。

**思路**  
B 能使石蕊变蓝→B 为碱性气体，有刺激性气味，极易溶于水→氨气（$ \mathrm{NH_3} $）。A 为气体单质，与 $ \mathrm{NH_3} $ 反应生成红棕色气体 C 和水，则 A 应具有氧化性，常见为 $ \mathrm{O_2} $，红棕色气体为 $ \mathrm{NO_2} $。该过程为 $ \mathrm{NH_3} $ 的催化氧化：先生成 $ \mathrm{NO} $，再被 $ \mathrm{O_2} $ 氧化为 $ \mathrm{NO_2} $。

**步骤**  
1. 定性推断：B 是 $ \mathrm{NH_3} $；C 红棕色为 $ \mathrm{NO_2} $；A 气体单质氧化剂为 $ \mathrm{O_2} $。  
2. 氨气催化氧化：$ \mathrm{4NH_3 + 5O_2 \xrightarrow[\Delta]{Pt/\text{催化剂}} 4NO + 6H_2O} $（条件：催化剂（铂网或氧化铁铬），加热）。  
3. NO 进一步氧化：$ \mathrm{2NO + O_2 = 2NO_2} $，总反应可写为 $ \mathrm{4NH_3 + 7O_2 \longrightarrow 4NO_2 + 6H_2O} $（条件不同可一步写出，但工业通常两步）。  
4. 按要求书写：B 参加催化氧化即为 $ \mathrm{4NH_3 + 5O_2 \xrightarrow[\Delta]{催化剂} 4NO + 6H_2O} $。

**点评/变式**  
- 易错点在于将氨气燃烧方程式与催化氧化混淆。纯氧中点燃生成 $ \mathrm{N_2} $，而有催化剂时控制氧化生成 $ \mathrm{NO} $。  
- 变式：若未知 C 为红棕色，可改为 C 在空气中变红棕色，则为 $ \mathrm{NO} $ 遇氧生成 $ \mathrm{NO_2} $。解题务必注意反应条件和产物差异。
