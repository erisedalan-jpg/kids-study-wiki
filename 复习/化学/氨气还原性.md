## 知识精要
- **核心反应**：氨气中氮元素为最低价（－3），具有还原性。与氧化铜反应体现氨的还原性：  
  $2NH_3 + 3CuO \xrightarrow{\Delta} N_2 + 3Cu + 3H_2O$  
  该反应是典型的氧化还原实验，常与氨的制备、干燥、产物检验联合考查。
- **常见还原性反应归纳**：  
  ① 催化氧化制硝酸：$4NH_3 + 5O_2 \xrightarrow{催化剂/\Delta} 4NO + 6H_2O$  
  ② 与氯气：$2NH_3 + 3Cl_2 = N_2 + 6HCl$（或生成$NH_4Cl$白烟）  
  ③ 还原金属氧化物（如$CuO$、$Fe_2O_3$）：$NH_3$被氧化为$N_2$，金属氧化物被还原为单质。
- **实验装置原理**：  
  ① $NH_3$制备（$Ca(OH)_2$与$NH_4Cl$固体加热）→ 碱石灰干燥 → 通入灼热$CuO$反应管 → 产物$Cu$留在管内，$N_2$和未反应$NH_3$、水蒸气导出 → 吸收$NH_3$（常用稀硫酸或水，注意防倒吸）→ 排水集气法收集$N_2$（$N_2$不溶于水）。
- **判定依据**：反应中$NH_3$中氮化合价升高，被氧化，氨气作还原剂。

## 解题方法与套路
1. **原理确定**：依据题干信息写出氧化还原方程式，标出化合价变化，明确氧化剂（$CuO$→$Cu$，铜降2）与还原剂（$NH_3$→$N_2$，氮升3），据此配平。
2. **装置剖析**：  
   - 气体发生装置：固固加热型（制$NH_3$）。  
   - 干燥装置：使用碱石灰或生石灰（不可用浓硫酸、无水$CaCl_2$，因$CaCl_2$会与$NH_3$形成络合物）。  
   - 主反应装置：硬质玻璃管中盛放氧化铜，管口有湿润的红色石蕊试纸或水吸收装置。  
   - 尾气处理：$NH_3$极易溶于水，必须防倒吸（倒置漏斗、干燥管或四氯化碳隔离水）。  
   - 产物检验：$N_2$用排水法收集，验证$Cu$为紫红色固体。
3. **定量计算**：利用差量法或氧化还原电子守恒。如固体质量减少为$CuO$失氧量，失氧量同时与$NH_3$失电子相关。
4. **现象描述模板**：黑色固体逐渐变为紫红色，管口有无色液体冷凝，湿润红色石蕊试纸接触尾气变蓝等。

## 高频易错
- **干燥剂误选**：误用氯化钙干燥氨气（会生成$CaCl_2·8NH_3$），必选碱石灰。
- **尾气未防倒吸或吸收不完全**：氨气极易溶于水，直接插入水中会引起倒吸。若用稀硫酸吸收需加防倒吸装置，且不能直接排入空气（污染、损失）。
- **产物检验遗漏**：若题目要求验证产物$H_2O$，需在$CuO$管后加无水硫酸铜装置（加入碱石灰干燥管之前，防止从吸收液中带出水）。
- **气体纯度与爆炸**：氨气与空气混合受热可能爆炸，实验前需排尽装置内空气（可利用产生的$NH_3$排尽）。
- **氮元素去向易错**：氨气还原氧化铜产物是$N_2$，而非$NO$或$NO_2$，除非催化剂条件。此处氧化铜氧化能力下只得到$N_2$。
- **电子守恒比例误算**：1 mol $NH_3$失3 mol电子，1 mol $CuO$得2 mol电子，故$n(NH_3):n(CuO)=2:3$。

## 代表题精讲
**题目**：已知氨可与灼热的氧化铜反应生成氮气和金属铜，利用图示装置（典型：氨气发生器→碱石灰干燥管→灼热氧化铜管→防倒吸吸收装置→排水集气）实现该反应，回答相关问题。

**思路**：先用固体加热法制取$NH_3$，干燥后与$CuO$在高温下反应，用稀硫酸吸收尾气并防倒吸，最后用排水法收集$N_2$。围绕各仪器作用、连接顺序、反应方程式及现象展开。

**步骤**  
1. 连接装置：A（发生）→B（干燥）→C（$CuO$反应管）→D（防倒吸吸收）→E（排水收集）。  
2. 先通氨气排尽空气，再加热C处，黑色$CuO$逐渐变为紫红色。  
3. 停止加热后继续通氨气至冷却，防止灼热铜被氧化。  
4. 用湿润红色石蕊试纸靠近尾气管口检验未反应的$NH_3$是否吸收完全。

**点评/变式**  
本题是氨气还原性的经典实验综合题。常变式：① 加装无水硫酸铜检验水（在C与D之间加干燥管）；② 若无防倒吸装置，让你指出错误并画出正确装置（可用倒扣漏斗或干燥管）；③ 给定固体减少质量，求$CuO$纯度或$NH_3$消耗量。记住核心是氧化还原电子守恒和$NH_3$的干燥、吸收要点。
