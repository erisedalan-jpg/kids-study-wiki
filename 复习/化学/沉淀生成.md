## 知识精要
- **沉淀生成条件**：离子积 $Q_c > K_{sp}$ 时，溶液过饱和，生成沉淀。
- **常见沉淀反应**：
  - $S_2O_3^{2-} + 2H^+ \rightarrow S\downarrow + SO_2\uparrow + H_2O$（酸中自身歧化，产生硫乳浊）
  - $Ba^{2+} + SO_4^{2-} \rightarrow BaSO_4\downarrow$（不溶于强酸）
  - $Ba^{2+} + SO_3^{2-} \rightarrow BaSO_3\downarrow$（溶于强酸，放出 $SO_2$）
  - $Ba^{2+} + CO_3^{2-} \rightarrow BaCO_3\downarrow$（溶于强酸，放出 $CO_2$）
- **实验干扰**：过量盐酸可溶解部分难溶盐（$BaSO_3$、$BaCO_3$），而 $BaSO_4$ 不溶；$Na_2S_2O_3$ 遇盐酸析硫和放出刺激性气体，现象覆盖性强，会遮蔽 $SO_3^{2-}$、$CO_3^{2-}$ 等离子的特征反应。
- **离子推断原则**：确定的离子必须有**唯一**且**不被覆盖**的现象证据；现象被主要反应完全覆盖的离子只能判为“不能确定”。

## 解题方法与套路
1. **翻译操作→反应**：读到“溶于水得无色透明溶液”，推出无难溶物、无不共存离子（氧化还原、双水解等）。
2. **标注关键试剂**：过量稀盐酸、$BaCl_2$ 溶液，预判可溶解哪些沉淀（盐酸溶解碳酸盐、亚硫酸盐），不可溶解哪些（$BaSO_4$）。
3. **现象锁定必含物质**：溶液变浑＋刺激性气体 → $S_2O_3^{2-}$ 存在（自身歧化，无需其他氧化剂）；离心后清液加 $BaCl_2$ 产生沉淀 → 上清液含 $SO_4^{2-}$ → 原样中必有 $SO_4^{2-}$（或 $HSO_4^-$）。
4. **排除表面干扰**：$Na_2S_2O_3$ 酸反应同样放出 $SO_2$，因此不能通过是否闻到 $SO_2$ 判断 $SO_3^{2-}$ 存在；$CO_2$ 无色无味，更易被掩盖。
5. **给出确定结论**：必含物质列确定性证据；不能确定的物质指出“现象被覆盖，无法排除”。

## 高频易错
- **误判 $SO_3^{2-}$ 存在**：见到“刺激性气体放出”便认为一定含 $Na_2SO_3$，忽略 $Na_2S_2O_3$ 遇酸也产生 $SO_2$。
- **忽略盐酸的“过量”与溶沉作用**：步骤③加 $BaCl_2$ 是在过量盐酸环境中，$BaSO_3$ 与 $BaCO_3$ 会被酸溶解，只有 $BaSO_4$ 能生成沉淀；若错以为沉淀是 $BaSO_3$ 或 $BaCO_3$，就会倒退推断出 $SO_3^{2-}$ 或 $CO_3^{2-}$ 必然存在。
- **沉淀颜色与量的无意识**：硫单质析出为淡黄色浑浊，$BaSO_4$ 为白色沉淀，在文字描述中常忽略区分，导致对步骤②沉淀判读不清。
- **漏用离心分离信息**：离心分离后所得“上层清液”意味着硫沉淀已被分离，后续加 $BaCl_2$ 的沉淀只能来自溶液中的阴离子，不可与之前的硫沉淀混淆。

## 代表题精讲
### 代表题 2022-全国乙-03
**题目**：某白色粉末可能含 $Na_2SO_4$、$Na_2SO_3$、$Na_2S_2O_3$、$Na_2CO_3$。实验：①溶于水得无色透明液；②加过量稀盐酸，溶液变浑浊，有刺激性气体逸出，离心分离；③取上层清液滴加 $BaCl_2$ 溶液，有沉淀生成。确定一定存在的物质。

**思路**：此题核心是**现象归属的排他性**。浑浊+刺激性气体直接锁定 $Na_2S_2O_3$；过量盐酸保证后续 $SO_4^{2-}$ 检验不受 $SO_3^{2-}$、$CO_3^{2-}$ 干扰；$BaSO_4$ 在强酸性中不溶，证明原样含 $SO_4^{2-}$。$SO_3^{2-}$、$CO_3^{2-}$ 的特征现象被 $S_2O_3^{2-}$ 反应的 $SO_2$ 和浑浊完全覆盖，不能确定是否存在。

**步骤**：
1. 步骤①：全溶说明无互相反应导致的不溶物（如 $S_2O_3^{2-}$ 与 $H^+$ 尚无酸环境），推断样品中离子可共存。
2. 步骤②：$S_2O_3^{2-} + 2H^+ \longrightarrow S\downarrow + SO_2\uparrow + H_2O$，溶液变浑为硫单质，刺激性气体为 $SO_2$。**必定含有 $Na_2S_2O_3$。**
3. 步骤③：过量盐酸使 $SO_3^{2-}$、$CO_3^{2-}$ 分别转为 $SO_2$、$CO_2$ 逸出，溶液中仅残留 $SO_4^{2-}$（若原样含 $Na_2SO_4$）和可能过量酸根；加入 $BaCl_2$ 生成不溶于酸的白色沉淀 $BaSO_4$。**必定含有 $Na_2SO_4$。**
4. $Na_2SO_3$ 与酸反应也产生 $SO_2$，$Na_2CO_3$ 与酸产生 $CO_2$，均被 $S_2O_3^{2-}$ 的反应现象掩盖，无独立证据，属于**不能确定**。
5. 结论：确定为 $Na_2SO_4$、$Na_2S_2O_3$，即选项 A。

**点评/变式**：该题完美示范了“覆盖效应”下的离子推断。变式常改用稀硫酸替代盐酸，此时加 $BaCl_2$ 时 $BaSO_4$ 沉淀会有 $SO_4^{2-}$ 源自酸本身的干扰，出题方向转为通过质量变化或气体定量分析来推断。考生必须敏锐区分：检验 $SO_4^{2-}$ 加 $Ba^{2+}$ 前必须确保溶液为强酸性且无其它可形成钡盐沉淀的阴离子，最稳妥的酸化试剂通常为**稀盐酸**。
