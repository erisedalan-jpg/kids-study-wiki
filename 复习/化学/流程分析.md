## 知识精要
- **工艺流程主线**：预处理→核心反应→除杂→分离提纯→产品。常见操作：粉碎（增大接触面积）、焙烧（改变结构或价态）、酸/碱浸（溶解目标组分）、过滤、蒸发浓缩、冷却结晶、萃取、蒸馏等。
- **除杂原则**：不引入新杂质，尽量不损耗主产品，易于分离。过量试剂需在后续步骤中除去（如酸浸后调pH沉淀，或通过生成气体、沉淀除去）。
- **氧化还原除杂**：利用变价离子不同价态的沉淀能力差异。如 $Fe^{2+}$ 易溶，氧化为 $Fe^{3+}$ 后可在较低 pH 下水解沉淀为 $Fe(OH)_3$ 除去。常用氧化剂：$H_2O_2$、$MnO_4^-$、$Cl_2$ 等。须注意氧化剂的还原产物是否造成新杂质（如 $KMnO_4$ 在中性或弱碱性介质中还原为 $MnO_2$，可过滤除去）。
- **沉淀控制**：通过调节 pH 使金属离子分步沉淀（ $K_{sp}$ 计算），可用 $M(OH)_n$ 沉淀或硫化物沉淀。 $pH$ 过低沉淀不完全，过高可能使主元素溶解或两性氢氧化物溶解。
- **置换除杂**：活泼金属置换较不活泼金属离子，如 $Zn$ 置换 $Ni^{2+}$、$Cu^{2+}$。要求置换剂不引入更难除去的杂质，且过量的置换剂可通过过滤或酸溶除去。
- **纯度检验**：取最后一次洗涤液或滤液，检测杂质离子（如 $Ni^{2+}$ 可用丁二酮肟显色或沉淀法）。
- **真题背景（氧化锌纯化）**：工业级氧化锌含 $Fe^{2+}$, $Mn^{2+}$, $Ni^{2+}$，用稀硫酸溶解后，加 $KMnO_4$ 氧化 $Fe^{2+}$、$Mn^{2+}$，生成易沉淀的 $Fe^{3+}$ 和 $MnO_2$ ，调 pH 使二者沉淀过滤除去； $Ni^{2+}$ 不能被 $KMnO_4$ 氧化，用锌粉置换为金属镍过滤除去，最终获得纯净 $Zn^{2+}$ 溶液（进一步转化为 $ZnO$）。

## 解题方法与套路
1. **读题抓关键**：明确原料成分、目标产物、杂质种类，特别注意题干提示信息（如“Ni(II)不能被氧化”“还原产物是MnO₂”），覆盖了氧化剂选择、沉淀成分等核心。
2. **拆解流程模块**：将流程分段：
   - 酸/碱浸：将固体转化为离子进入溶液，写离子方程式（注意氧化物、难溶物的书写）。
   - 氧化环节：书写氧化还原离子方程式，配平注意电荷守恒、介质条件。注意量：过量氧化剂需考虑。
   - 调pH沉淀：依据 $K_{sp}$ 或已知信息判断沉淀 pH 范围，回答滤渣成分。
   - 置换/化学除杂：判断置换反应能否发生（金属活动性顺序），写出方程式。
   - 分离操作：过滤、洗涤、蒸发、煅烧等，注意操作目的与规范术语。
3. **书写方程式技巧**：除非题目指定，流程图中的反应一般写离子方程式。氧化还原反应配平用“化合价升降法”或“离子电子法”，注意介质（酸性用 $H^+$ 和 $H_2O$，碱性用 $OH^-$ 和 $H_2O$）。如：$5Fe^{2+} + MnO_4^- + 8H^+ = 5Fe^{3+} + Mn^{2+} + 4H_2O$（酸性），本题中性条件生成 $MnO_2$：$3Fe^{2+} + MnO_4^- + 4H^+ = 3Fe^{3+} + MnO_2 \downarrow + 2H_2O$ 或从电荷守恒配平。
4. **问答呼应**：题目常问“某试剂作用”“滤渣成分”“操作目的”，答案需紧扣元素去向与原理。如：加 $KMnO_4$ 目的是将 $Fe^{2+}$ 氧化为 $Fe^{3+}$，将 $Mn^{2+}$ 氧化为 $MnO_2$ 沉淀；调 pH 是为了使 $Fe^{3+}$ 水解沉淀完全；加 $Zn$ 粉是置换 $Ni^{2+}$ 等。
5. **计算与检验**：涉及 $K_{sp}$ 计算离子沉淀完全的 pH 时，代入离子浓度 $1\times10^{-5} mol/L$ 判据；检验杂质是否除净用“取最后一次洗涤液少许，滴加……，若……则……”。

## 高频易错
- **忽略氧化剂还原产物与介质的关系**：$KMnO_4$ 在酸性下的还原产物是 $Mn^{2+}$，在中性或弱碱性下是 $MnO_2$，题目已明确提示时必须严格遵照，否则方程式错误且后续除杂分析出错。
- **调 pH 除铁忽略 $Fe^{3+}$ 已生成，仍写“氧化除 $Fe^{2+}$ ”**：流程中如果在调 pH 前已加入氧化剂，则铁元素已转为 $Fe^{3+}$，调 pH 是为沉淀 $Fe(OH)_3$；若答“氧化亚铁”则混淆步骤。
- **滤渣成分漏写或错写**：常见错误是杂质沉淀写不全。本题氧化并调 pH 后滤渣至少含 $MnO_2$ 和 $Fe(OH)_3$，可能有过量 $KMnO_4$ 生成的 $MnO_2$；忽视过量高锰酸钾自身的转化。
- **置换法引入新杂质**：若用比 Zn 活泼的金属置换 Ni，则会引入更难除去的金属离子。需选择主产品金属本身（如 Zn）或易除去的金属。
- **pH 范围选择不当**：未考虑 $Zn^{2+}$ 开始沉淀的 pH，若 pH 过高会导致目标产物 $Zn^{2+}$ 也沉淀损失。需掌握 $Zn(OH)_2$ 沉淀的 pH 范围。
- **流程中操作术语不规范**：如“蒸发结晶”与“蒸发浓缩、冷却结晶”适用对象混淆；过滤后沉淀需要洗涤，洗涤的目的是除去表面可溶性杂质，答题要具体指明洗去何种离子。
- **检验离子未强调“取样”**：检验杂质离子是否除尽，必须描述取样操作（取少量最后一次洗涤液/滤液于试管中），否则不得分。

## 代表题精讲
### **题目**（2013·新课标Ⅱ·9）
纯化含 $Fe^{2+}$、$Mn^{2+}$、$Ni^{2+}$ 杂质的工业级氧化锌。流程：工业级 $ZnO$ 加稀硫酸酸浸→加入 $KMnO_4$ 溶液并控制 pH→过滤（滤渣Ⅰ）→滤液中加入锌粉→过滤（滤渣Ⅱ）→滤液经系列处理得纯净 $ZnO$。提示：$Ni^{2+}$ 不能被 $KMnO_4$ 氧化；$KMnO_4$ 的还原产物是 $MnO_2$。

常见设问：
(1) 酸浸时发生的主要离子方程式。
(2) 加入 $KMnO_4$ 的作用及发生反应的离子方程式。
(3) 滤渣Ⅰ的主要成分。
(4) 加入锌粉的目的和反应的离子方程式。
(5) 如何检验滤液中 $Ni^{2+}$ 已除尽？

### **思路**
流程核心是“氧化沉淀除铁锰，置换除镍”。根据提示，$KMnO_4$ 还原产物为 $MnO_2$ 固体，本身可滤除；$Fe^{2+}$ 被氧化为 $Fe^{3+}$，通过调 pH 水解为 $Fe(OH)_3$ 沉淀。$Mn^{2+}$ 被氧化为 $MnO_2$ 沉淀。硫酸提供的酸性条件使氧化物溶解，氧化还原配平时注意介质酸性不足时需补 $H^+$ 或直接用离子电荷守恒配平（实际酸浸后溶液呈酸性，可认为有 $H^+$ 环境）。所有方程式均为离子方程式，体现实际参与反应的微粒。

### **步骤**
**(1) 酸浸方程式**：$ZnO$ 和杂质氧化物 $FeO$、$MnO$、$NiO$ 分别与 $H^+$ 反应。
$$ZnO + 2H^+ = Zn^{2+} + H_2O$$
$$FeO + 2H^+ = Fe^{2+} + H_2O$$
$$MnO + 2H^+ = Mn^{2+} + H_2O$$
$$NiO + 2H^+ = Ni^{2+} + H_2O$$

**(2) $KMnO_4$ 的作用与方程式**：氧化 $Fe^{2+}$ 和 $Mn^{2+}$，自身被还原为 $MnO_2$。酸性环境：
$$MnO_4^- + 3Fe^{2+} + 4H^+ = MnO_2 \downarrow + 3Fe^{3+} + 2H_2O$$
$$2MnO_4^- + 3Mn^{2+} + 2H_2O = 5MnO_2 \downarrow + 4H^+$$
（第二式特点：反应生成 $H^+$，因此实际调 pH 需加碱或缓冲物）

**(3) 滤渣Ⅰ成分**：调 pH 至 $Fe^{3+}$ 完全水解沉淀的 pH（约 3～4），此时 $Fe(OH)_3$ 和 $MnO_2$ 共同析出，还可能夹带少量过量的 $MnO_2$ 来自未反应的 $KMnO_4$。滤渣Ⅰ主要成分为 $Fe(OH)_3$ 和 $MnO_2$。

**(4) 锌粉作用**：利用 Zn 的金属性比 Ni 强，置换除去 $Ni^{2+}$：
$$Zn + Ni^{2+} = Zn^{2+} + Ni$$
滤渣Ⅱ主要为过量的 Zn 粉和被置换出的 Ni 单质。

**(5) 检验 $Ni^{2+}$ 除尽**：取少量最后滤液于试管中，滴加丁二酮肟溶液（或继续加锌粉/其他特征试剂），若无鲜红色沉淀（或不出现特征颜色变化），则表明 $Ni^{2+}$ 已除尽。答题模板：取样→加试剂→描述现象→结论。

### **点评/变式**
此题属于典型的“变价沉淀+置换”除杂流程，核心突破口是题干提示的“不能氧化”和“还原产物”。答题时抓住三条线：主产品 $Zn^{2+}$ 的走向；杂质元素形态的转化（$Fe^{2+}→Fe^{3+}→Fe(OH)_3↓$；$Mn^{2+}→MnO_2↓$；$Ni^{2+}→Ni↓$）；试剂的引入与去除（$KMnO_4$ 变为 $MnO_2$ 滤除，过量 $Zn$ 粉过滤回收）。变式：若杂质含 $Cu^{2+}$，可直接用锌粉置换；若允许用 $H_2O_2$ 替代 $KMnO_4$，则氧化后无固体还原产物，需注意调 pH 沉淀后滤渣仅为 $Fe(OH)_3$，锰需另除。
