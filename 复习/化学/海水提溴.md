## 知识精要
- 海水提溴的原料：通常为海水淡化后的**浓海水**（富含Br⁻）。
- 主要方法：**空气吹出法**。
  - **氧化**：用Cl₂将浓海水中的Br⁻氧化为Br₂：
    $$2\text{Br}^- + \text{Cl}_2 \longrightarrow \text{Br}_2 + 2\text{Cl}^-$$
  - **吹出**：利用热空气将Br₂吹出（利用了溴**易挥发**的物理性质）。
  - **吸收**：用纯碱（Na₂CO₃）溶液吸收Br₂，防止污染，并实现富集：
    $$3\text{Br}_2 + 3\text{Na}_2\text{CO}_3 \xrightarrow{\text{H}_2\text{O}} 5\text{NaBr} + \text{NaBrO}_3 + 3\text{CO}_2 \uparrow$$
    或另一种常见吸收产物（含NaHCO₃）：
    $$3\text{Br}_2 + 6\text{Na}_2\text{CO}_3 + 3\text{H}_2\text{O} \longrightarrow 5\text{NaBr} + \text{NaBrO}_3 + 6\text{NaHCO}_3$$
  - **酸化释溴**：加酸（H₂SO₄）使Br⁻与BrO₃⁻发生归中反应，重新获得高浓度Br₂：
    $$5\text{Br}^- + \text{BrO}_3^- + 6\text{H}^+ \longrightarrow 3\text{Br}_2 + 3\text{H}_2\text{O}$$
- 关联考点：海水综合利用还可提取**镁**（熟石灰沉淀、盐酸转化、电解熔融氯化镁）、**钾**等，属于绿色化学与流程优化问题。

## 解题方法与套路
1. **分析流程主线**：明确原料→预处理→核心反应→分离提纯→目标产物的每一环节，标注进出物质名称与状态。
2. **用守恒思想配平陌生反应**：如歧化或归中反应，利用化合价升降相等、物料守恒（Br原子数守恒、电荷守恒）进行配平。
3. **性质决定操作**：联系物质的特性（如Br₂挥发性、Cl₂氧化性强于Br₂、Br₂在水中溶解度小但易溶于有机溶剂等）解释吹出、吸收、萃取等操作。
4. **评价改进方向**：工艺评价题从**提高产率**（循环利用、避免副反应）、**产物纯度**（减少杂质引入）、**经济环保**（原料廉价、减少有毒排放、能量消耗低）等角度选择可行措施。

## 高频易错
- **混淆氧化顺序**：Cl₂能从Br⁻中置换出Br₂，但若通入过量Cl₂，可能进一步把Br₂氧化为BrO₃⁻或其他高价态，必须根据题意判断用量。
- **纯碱吸收方程式配平错误**：忽略CO₃²⁻在酸性介质中生成CO₂，若反应环境明确为纯碱溶液且生成NaHCO₃时，则产物不同；必须结合题目给出的反应环境进行配平。
- **操作目的模糊**：空气吹出为**富集溴**，不是直接得到产品；碱吸收后经酸化才制得纯净溴单质。
- **淡化方法混淆**：混凝法可除去悬浮物、胶体，但**不能除掉可溶性盐（NaCl等）**，无法获得淡水，淡化需蒸馏、反渗透等方法。

## 代表题精讲
### 2014-新课标Ⅱ-11
**题目**简述：题干要求判断海水淡化与浓海水资源化工艺中的可行措施，并涉及空气吹出法提溴时用纯碱吸收的化学反应配平及相关计算。（注：原真题为填空题）

**思路**：第（1）问利用海水综合利用及化学常识排除明显错误选项（混凝法不能淡化海水）；第（2）问给出反应物Br₂、Na₂CO₃、H₂O，产物NaBr、NaBrO₃、NaHCO₃，要求配平，需用化合价升降与原子守恒。

**步骤**：
1. 分析小题（1）：混凝法只能除去水中悬浮物和胶体，无法去除溶解的盐分，故①不可行；提高产品质量、优化品种、改进提取工艺均属于可行的改进方向，故填②③④。
2. 对于反应：
   $$\dots\text{Br}_2 + \dots\text{Na}_2\text{CO}_3 + \dots\text{H}_2\text{O} \longrightarrow \dots\text{NaBr} + \dots\text{NaBrO}_3 + \dots\text{NaHCO}_3$$
   - 标注化合价：Br₂中Br为0价；NaBr中Br为-1价，NaBrO₃中Br为+5价。Br₂发生歧化。
   - 根据电子守恒：生成1个BrO₃⁻（+5）失去5个电子，配平需5个Br⁻得5个电子，故Br₂→5Br⁻+1BrO₃⁻，即**3个Br₂**参加歧化生成5个NaBr和1个NaBrO₃。
   - 定关键系数：NaBr系数5，NaBrO₃系数1，则Br₂系数3。
   - 根据钠原子守恒：右边Na⁺共5+1=6个，左边需3个Na₂CO₃提供；碳原子守恒：3个C全部转化为3个CO₂？但题干写NaHCO₃，说明还有部分CO₃²⁻转化为HCO₃⁻。则3个Na₂CO₃中共有3个C，若全进入NaHCO₃，则NaHCO₃系数应为3，此时Na⁺为5+1+3=9个，左边Na⁺仅有6个，矛盾。因此反应实际上是：Br₂+Na₂CO₃+H₂O → NaBr+NaBrO₃+NaHCO₃+CO₂？但题干未给出CO₂。实际给出的反应式应为：Br₂+Na₂CO₃+H₂O → NaBr+NaBrO₃+NaHCO₃（H元素守恒？若产物无CO₂，则C全部在NaHCO₃，需3个Na₂CO₃给出3个C，则NaHCO₃系数3，Na⁺总数=5+1+3=9，Na₂CO₃提供6个Na⁺，缺3Na⁺？矛盾，说明题目可能另有括号注明或原题式不完整。）根据常见资料，纯碱吸收Br₂反应为：3Br₂+3Na₂CO₃ → 5NaBr+NaBrO₃+3CO₂；若为含H₂O生成NaHCO₃，通常写成3Br₂+6Na₂CO₃+3H₂O → 5NaBr+NaBrO₃+6NaHCO₃。原题所给“碱吸收溴的主要反应 Br₂+Na₂CO₃+H₂O → NaBr+NaBrO₃+NaHCO₃”可能意在让配平并标出缺失的物质（可能生成CO₂）。解答时根据电荷与原子守恒配平为：3Br₂+6Na₂CO₃+3H₂O = 5NaBr+NaBrO₃+6NaHCO₃。若给出的是无CO₂产物，则不必深究，按给定物质配平即可：3Br₂+3Na₂CO₃+H₂O = NaBr+NaBrO₃+NaHCO₃（系数仍按守恒调整，但钠数会不对，审题需结合题目具体要求）。

**点评/变式**：海水提溴中纯碱吸收环节是高频方程式考点，配平关键是抓住Br₂歧化为Br⁻和BrO₃⁻的电子转移，碳元素去向常忽略而失分。变题可能提供“步骤图”或“工艺流程图”，要求补充试剂、书写分离方法（如“蒸馏”）。答题时牢记：**氧化用Cl₂，吹出靠挥发，吸收用Na₂CO₃，酸化得精溴**。
