## 知识精要
- **海水淡化核心原理**：海水淡化的本质是实现水分子与溶解盐离子的物理分离，不涉及化学转化。工业主流方法有蒸馏法（利用沸点差异）、电渗析法（电场驱动离子通过选择性交换膜）与反渗透法（加压克服自然渗透压使水分子透过半透膜）。
- **溶解平衡与沉淀转化**：浓海水提镁的化学基础是沉淀溶解平衡。利用石灰乳（ $Ca(OH)_2$ 微溶，提供廉价碱源）将 $Mg^{2+}$ 转化为溶解度更低的 $Mg(OH)_2$ 沉淀，实现 $Mg^{2+}$ 的富集。核心反应：$Mg^{2+} + 2OH^- \rightleftharpoons Mg(OH)_2 \downarrow$。
- **氧化还原与富集**：溴离子富集依赖氧化还原反应。氯气氧化性比溴强，可将 $Br^-$ 氧化为游离态的 $Br_2$（$Cl_2 + 2Br^- = 2Cl^- + Br_2$）。后续用纯碱（$Na_2CO_3$）吸收，利用 $Br_2$ 在碱性条件下的歧化反应（$3Br_2 + 3CO_3^{2-} = 5Br^- + BrO_3^- + 3CO_2 \uparrow$），实现溴的逆向富集与形态转化，最后再酸化得高浓度溴单质。
- **除杂与提纯**：粗盐（$NaCl$）的精制须遵循“不增、不减、易分、顺序”原则，用化学沉淀法依次去除 $SO_4^{2-}$（加 $BaCl_2$）、$Mg^{2+}$（加 $NaOH$）、$Ca^{2+}$（加 $Na_2CO_3$），过滤后调节 $pH$ 除过量碱。

## 解题方法与套路
- **流程目的分析法**：先锁定原料（浓海水）和目标产物（淡水、钾、溴、镁等），用箭头串联“原料→除杂/富集→转化→分离→精制→产物”。遇到评价“做法是否可行”的选项，必须紧扣“是否实现有效分离”和“是否引入新杂质”两个核心逻辑。
- **试剂选择口诀**：“水”淡须蒸或膜，“镁”沉必选碱（石灰乳），“溴”吹先氧化（$Cl_2$），“钾”钠析晶瞧（溶解度随温度变化差异）。
- **分离操作规范表述**：
    - **沉淀生成**：“向溶液中加入稍过量的沉淀剂，搅拌、静置……”强调“稍过量”以保证目标离子沉淀完全。
    - **固液分离**：“过滤”，滤渣如是沉淀则需“洗涤”去除表面吸附的可溶性杂质离子（如 $Na^+$、$Cl^-$），检验是否洗净的方法：取最后一次洗涤液少量于试管，滴加某试剂，若无某现象则已洗净。
    - **获取晶体**：若溶质溶解度随温度变化大，用“蒸发浓缩→冷却结晶→过滤”；若溶解度受温度影响小，或想获取热稳定性高的溶质，用“蒸发结晶→趁热过滤”。
- **氧化还原产物的书写**：涉及 $Br_2$ 与碱反应，必须在碱性介质下分析其歧化产物，配平氧原子时优先考虑 $H_2O$ 或 $CO_2$（取决于用纯碱还是烧碱）。

## 高频易错
- **混淆净水与淡化**：混凝法是沉淀水中的胶体及悬浮颗粒物，无法除去溶解的 $Na^+$、$Cl^-$，故不能淡化海水。一旦选项将混凝法与获取淡水关联，直接判错。
- **错选石灰水替代石灰乳**：$Ca(OH)_2$ 溶解度极小，石灰水浓度太低，导致生成 $Mg(OH)_2$ 量极少且难以过滤分离，工业生产中必须用悬浊状的石灰乳。
- **沉淀顺序的逻辑错误**：在粗盐精制中，除 $Ca^{2+}$ 常用 $Na_2CO_3$。若 $BaCl_2$ 加在 $Na_2CO_3$ 之后，则过量的 $Ba^{2+}$ 无法在后续步骤中被 $CO_3^{2-}$ 沉淀除去，会引入新的重金属离子杂质。故 $Na_2CO_3$ 必须添加在 $BaCl_2$ 之后。
- **循环利用的经济性忽视**：$Br_2$ 吸收液酸化后生成的 $NaCl$ 溶液等，只要不含有害杂质，通常可循环至前端的氯气氧化步骤或海水淡化入水口，这属于“优化工艺”的得分表述，答题时不可遗漏。
- **洗涤液选用失当**：洗涤沉淀误用蒸馏水常导致胶体或微溶沉淀发生胶溶或部分溶解损失，有时需采用该溶质的饱和溶液或有机溶剂进行淋洗。

## 代表题精讲
### **题目**：2014-新课标Ⅱ-11 海水淡化与资源化流程

**题目简述**
以海水淡化为基础，评价工艺改进的可行性；设计“空气吹出法”提溴的氧化、碱吸收与酸化过程；利用沉淀法从浓海水中提镁，讨论试剂选取、沉淀提纯及母液中氯化钠晶体的分离方法。

**思路**
第（1）问需分清物理分离与化学沉淀的界限；第（2）问结合氯溴置换及溴元素的碱性歧化规律，推导反应方程式；第（3）（4）问则建立在沉淀溶解平衡及晶体析出方法的工业逻辑之上。

**步骤**
1.  **评价工艺设想**：
    - 选项①：混凝法去除悬浮物，不能去盐分，不能获取淡水→错误。
    - 选项②③④：提升质量、优化品种、改进提工艺均属于节能减排、提高原料利用率和效益的正向优化→正确。故填(2)(3)(4)。
2.  **溴的吸收与转化**：
    - 氧化：用氯气将浓海水中的 $Br^-$ 氧化为 $Br_2$，化学方程式为 $Cl_2 + 2Br^- = 2Cl^- + Br_2$。
    - 碱吸收：$Br_2$ 通入纯碱溶液，发生自身氧化还原，生成 $NaBr$、$NaBrO_3$ 并有 $CO_2$ 放出，且生成物中溴元素化合价有 $-1$ 价和 $+5$ 价，利用电子得失守恒和质量守恒配平得：$3Br_2 + 3CO_3^{2-} = 5Br^- + BrO_3^- + 3CO_2 \uparrow$。
    - 解析已给出反应：$3Br_2+6Na_2CO_3+3H_2O = 5NaBr+NaBrO_3+6NaHCO_3$，或写成离子方程式。最后酸化时，溶液中的 $H^+$ 浓度增大，$Br^-$ 和 $BrO_3^-$ 发生归中反应，重新生成高浓度的 $Br_2$ 单质。
3.  **镁的沉淀与提纯**：
    - 试剂选择：选用石灰乳而非石灰水。原理是 $Mg^{2+}$ 与碱反应生成 $Mg(OH)_2$ 沉淀。
    - 提纯操作：将粗 $Mg(OH)_2$ 溶于盐酸得 $MgCl_2$ 溶液，经蒸发浓缩、冷却结晶（或直接浓缩析出）即可得到较纯净的氯化镁晶体，除去不溶性杂质。
4.  **氯化钠晶体的获取**：
    - 分离出 $Mg(OH)_2$ 后的滤液，主要成分是 $NaCl$ 和未反应完的 $Ca^{2+}$ 等离子。氯化钠溶解度随温度升高变化极小，适合采用蒸发溶剂、浓缩析出氯化钠固体的方法，具体操作为：**蒸发结晶，趁热过滤**。

**点评/变式**
本题是典型的海水综合利用框图题前身，直接考核对化工逻辑的判断力。“空气吹出法”是卤素单质提取的经典模型，核心是“氧化→吹出→吸收→再氧化”的富集循环，考生必须灵敏意识到溴元素在碱性条件下一定会发生歧化，且纯碱参与时碳元素转化为碳酸氢盐或二氧化碳。遇到将沉淀洗涤、重结晶除杂与获取母液中残留溶质的操作组合题时，要记住基本原则：**除杂要“过量慎选”，洗涤要“少量多次”，析晶看“曲线形状”**。
