## 知识精要
- **天然水中溶解气体**：主要为 $O_2$、$CO_2$，少量 $N_2$ 及痕量稀有气体等。这部分知识在流程题的背景分析中常见，需记住主要成分。
- **混凝剂**：能破坏水中胶态杂质及悬浮物的稳定性，使其聚集成较大矾花而沉降的化学药剂。
  - **常见无机混凝剂**：明矾（化学式 $KAl(SO_4)_2·12H_2O$，有效成分为 $Al_2(SO_4)_3$）、硫酸铝、硫酸亚铁、硫酸铁、聚合氯化铝（$PAC$）、聚合硫酸铁等。
  - **净水原理**（核心）：混凝剂溶于水后，其中的 $Al^{3+}$ 或 $Fe^{3+}$（或 $Fe^{2+}$ 氧化后）发生水解，生成 $Al(OH)_3$ 或 $Fe(OH)_3$ 胶体。胶体具有巨大表面积，吸附水中悬浮颗粒物及部分胶态杂质，并中和其电荷，使胶粒脱稳聚沉，经沉降、过滤后除去。
  - **胶体可表示为**：$Al(OH)_3$（胶体）、$Fe(OH)_3$（胶体），不可加↓；原理切忌误写成“杀菌消毒”。
- **水的净化与软化区别**：
  - **净化**：除去水中悬浮杂质、胶体、部分溶解性有机物等，混凝、沉降、过滤、消毒等操作属净化范畴（不能降低水中 $Ca^{2+}、Mg^{2+}$ 总量）。
  - **软化**：降低或除去水中的 $Ca^{2+}、Mg^{2+}$，方法有加热煮沸法、药剂法（石灰-纯碱法）、离子交换法等。软化后水的总硬度降低。
- **硬度计算**（复习为主）：
  - 定义：$1°$ 硬度相当于每升水中含 $10mg CaO$，或相当量的 $MgO$（$7.1mg$）。
  - 换算关系：$$硬度(°) = \frac{m(CaO)+m(MgO)相当量}{10\,mg/L}$$ 将 $c(Ca^{2+})$ 和 $c(Mg^{2+})$ 分别换算成 $CaO$ 的质量浓度：
    $$\rho(CaO) = c(Ca^{2+})\times M(CaO)\quad \rho(MgO)相当于 = c(Mg^{2+})\times M(CaO) \times \frac{1}{1}$$
    或直接用：每升水中 $Ca^{2+}$ 与 $Mg^{2+}$ 的毫摩尔数之和乘 $CaO$ 的摩尔质量（$56\ g/mol$）即得 $CaO$ 毫克数，再除以 $10$ 得硬度。
    高度简洁公式：$$硬度(°) = 5.6 \times [c(Ca^{2+})+c(Mg^{2+})]\,(mmol/L)$$

## 解题方法与套路
1. **气体溶解性类填空**：联想空气主要成分及水中溶解度——$O_2$ 支持水生生物，$CO_2$ 来自大气及水中生物呼吸，优先填写 $O_2$、$CO_2$（少量 $N_2$ 亦可）。
2. **混凝剂选择与原理书写**：
   - 填名称：首选“明矾、硫酸铝”或“硫酸亚铁、硫酸铁”（写物质名称而非化学式，注意专业名称，如“明矾”“聚合氯化铝”）。若题干允许，写出两种即可。
   - 原理描述万能模板：“（混凝剂中） $Al^{3+}$（或 $Fe^{2+}/Fe^{3+}$） 水解生成 $Al(OH)_3$（或 $Fe(OH)_3$）胶体，该胶体能吸附水中的悬浮杂质并使之沉降。”
   - 注意：若用 $Fe^{2+}$，需涉及氧化为 $Fe^{3+}$ 再水解，但答题时可直接写有效成分水解成胶体。
3. **净化 vs 软化区分题**：回答要点——“水的净化是用混凝、沉降、过滤等方法除去悬浮物和部分杂质；水的软化是降低或除去 $Ca^{2+}、Mg^{2+}$。” 强调净化不降低硬度。
4. **硬度计算题三步走**：
   - ① 计算 $Ca^{2+}$、$Mg^{2+}$ 的物质的量浓度对应的 $CaO$ 质量浓度：$m_{CaO}/L = c(Ca^{2+})\times 56\,g/mol$，$m_{CaO}'/L = c(Mg^{2+})\times 56\,g/mol$（注意 $Mg^{2+}$ 亦可视为相当的 $CaO$）。
   - ② 合并总 $CaO$ 质量（mg/L）：以 $mg$ 为单位求和。
   - ③ 除以 $10$ 即得硬度（°）。或者直接用公式：$硬度(°) = 5.6 \times (1.2 + 0.6) = 10.08° \approx 10.1°$。

## 高频易错
- **净水原理错写成杀菌消毒**：明矾等混凝剂仅能凝聚悬浮物，不能杀死细菌病毒；消毒采用 $Cl_2$、$ClO_2$ 等。考试中常因思维定势混为一谈而失分。
- **胶体表述不规范**：仅写“生成 $Al(OH)_3$ 沉淀”或漏写“胶体”二字，导致原理严重扣分。必须点出“水解生成胶体，吸附…”。
- **混凝剂名称写错**：题目要求填物质名称却写成化学式（如写 $KAl(SO_4)_2·12H_2O$ 或 $Al_2(SO_4)_3$），或写俗名错别字（“明矾”写成“明钒”）。
- **软化与净化混淆**：说“净化能降低硬度”，或软化方法写成加明矾，概念不清。务必区分：净化→去杂（悬浮物）；软化→去 $Ca^{2+}、Mg^{2+}$。
- **硬度计算单位换算失误**：未将浓度转化为质量，或将 $CaO$ 摩尔质量记错，或忽略 $Mg^{2+}$ 的相当量直接相加减。必须统一换算为 $CaO$ 的 $mg/L$ 后用 $10 mg/°$ 除。
- **遗漏溶解气体**：天然水溶解气体只填 $O_2$ 而漏 $CO_2$，或误写 $N_2$ 为主（虽含氮气但不是主要溶解气体，因 $N_2$ 溶解度远小于 $CO_2$ 和 $O_2$），最好按教材结论：$O_2$、$CO_2$。

## 代表题精讲
### **题目**  
2010 新课标卷化学与技术选做题，考查天然水中的溶解气体、混凝剂及净水原理、水的净化与软化区别、基于 $Ca^{2+}/Mg^{2+}$ 浓度的硬度计算。

**思路**  
(1) 从自然界水与大气交换及水生生物呼吸作用入手。  
(2) 回忆教材中常用混凝剂名称及 $Al^{3+}$ 或 $Fe^{3+}$ 水解生成胶体的原理。  
(3) 准确表述净化与软化的不同目的和手段。  
(4) 利用硬度定义，将物质的量浓度转换为 $CaO$ 质量浓度后求和再除以 $10$。

**步骤**  
(1) **天然水中溶解气体**：氧气（$O_2$）、二氧化碳（$CO_2$）。  
(2) **混凝剂名称**：明矾、硫酸铝（或硫酸亚铁、硫酸铁等，任写两种）。  
   **净水原理**：混凝剂中的 $Al^{3+}$（或 $Fe^{3+}$）水解生成 $Al(OH)_3$（或 $Fe(OH)_3$）胶体，该胶体具有很强的吸附能力，能吸附水中的悬浮颗粒物，使其凝聚成为较大的矾花而沉降，达到净水效果。  
(3) **水的净化与软化区别**：水的净化是通过混凝、沉降、过滤等方法除去水中的悬浮物及部分杂质，而水的软化是降低或除去水中的 $Ca^{2+}、Mg^{2+}$；净化不能改变水的硬度，软化可降低硬度。  
(4) **硬度计算**：  
   已知 $c(Ca^{2+}) = 1.2 \times 10^{-3}\ mol/L$，$c(Mg^{2+}) = 6 \times 10^{-4}\ mol/L$。  
   $Ca^{2+}$ 相当于 $CaO$ 质量浓度：$1.2 \times 10^{-3}\ mol/L \times 56\ g/mol = 0.0672\ g/L = 67.2\ mg/L$。  
   $Mg^{2+}$ 相当于 $CaO$ 质量浓度：$6 \times 10^{-4}\ mol/L \times 56\ g/mol = 0.0336\ g/L = 33.6\ mg/L$。  
   总 $CaO$ 质量浓度为 $67.2 + 33.6 = 100.8\ mg/L$。  
   硬度为 $100.8\ mg/L ÷ 10\ mg/L·° = 10.08° ≈ 10.1°$。  
   或直接公式：$硬度 = 5.6 \times (1.2 + 0.6) = 10.08°$。

**点评/变式**  
- 该题将水的处理技术拼接考查，小题间相对独立，但概念易混淆。混凝剂原理的规范表达是阅卷踩分点，务必出现“水解”“胶体”“吸附凝聚沉降”。  
- 硬度计算实质是浓度换算，牢记 $CaO$ 摩尔质量 $56\ g/mol$，并注意 $Mg^{2+}$ 也需按 $CaO$ 等量折算，防止直接加浓度数值。  
- 变式可能将净水与硬水软化流程综合成流程图，要求选择试剂或写操作名称；或给出 $HCO_3^-$ 离子浓度，求暂时硬度等，均可用同一思路解决。
