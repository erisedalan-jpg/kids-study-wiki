## 知识精要
- **沉淀溶解平衡**：在一定温度下，难溶电解质固体与溶液中离子之间建立的动态平衡。例如 $M(OH)_2(s) \rightleftharpoons M^{2+}(aq) + 2OH^-(aq)$。
- **溶度积常数 ($K_{sp}$)**：沉淀溶解平衡的平衡常数，只与**温度**有关，与离子浓度无关。表达式为各离子平衡浓度以化学计量数为指数的乘积。
  - 通式：$A_mB_n(s) \rightleftharpoons mA^{n+}(aq) + nB^{m-}(aq)$，$K_{sp}=[A^{n+}]^m[B^{m-}]^n$。
  - 本题型：$M(OH)_2$ 的 $K_{sp}=[M^{2+}][OH^-]^2=a$。
- **溶度积规则**（判断沉淀生成与溶解）：
  - $Q_c > K_{sp}$：溶液过饱和，析出沉淀。
  - $Q_c = K_{sp}$：饱和溶液，达平衡。
  - $Q_c < K_{sp}$：溶液不饱和，无沉淀析出或沉淀溶解。
- **pH 与 $K_{sp}$ 的耦合计算**（25 ℃）：
  - $pH + pOH = 14$，$pOH = -\lg[OH^-]$。
  - 已知离子浓度求 $[OH^-]$ 或 $[H^+]$，代入 $K_{sp}$ 表达式解出。

## 解题方法与套路
1. **写平衡，列表达式**：根据难溶电解质的组成写出溶解平衡及 $K_{sp}$ 表达式，重点核对离子浓度的指数（化学计量数）。
2. **代数据，定未知浓度**：将题目给出的离子浓度或其他条件代入 $K_{sp}$ 表达式，列出方程。
3. **算 $[OH^-]$（或 $[H^+]$）**：解方程求出 $[OH^-]$，注意根号运算：若 $[OH^-]^2 = \frac{a}{b}$，则 $[OH^-] = \sqrt{\frac{a}{b}}$。
4. **转 $pH$**：利用 $pOH = -\lg[OH^-]$ 及 $pH = 14 - pOH$（25 ℃）得到 $pH$。涉及对数公式：
   $$-\lg\sqrt{\frac{a}{b}} = \frac{1}{2}\lg\frac{b}{a} = -\frac{1}{2}\lg\frac{a}{b}$$
   最终 $pH = 14 + \frac{1}{2}\lg\frac{a}{b}$（或等价形式）。
5. **验温度**：所有 $K_w=10^{-14}$ 的换算仅适用于常温（25 ℃）下，若题目指明其他温度需使用对应 $K_w$。

## 高频易错
- **指数遗漏或错位**：写 $K_{sp}$ 时忘记给 $[OH^-]$ 加指数 $2$（如 $M(OH)_2$ 写为 $K_{sp}=[M^{2+}][OH^-]$），导致后续全错。
- **平衡浓度与溶解度的混淆**：题目中给出的 $c(M^{2+})$ 是人为调整后的浓度，并非纯水中溶解产生的离子浓度，此时 $[OH^-] \neq 2c(M^{2+})$，必须通过 $K_{sp}$ 重新计算。
- **对数运算失误**：
  - $\lg\sqrt{x} = \frac{1}{2}\lg x$，常忘记系数 $\frac{1}{2}$。
  - $-\lg\frac{a}{b} = \lg\frac{b}{a}$，符号变化易错。
  - $pH = 14 + \frac{1}{2}\lg\frac{a}{b}$ 中，根号内的 $a/b$ 顺序与对数前正负号相对应，切忌死记硬背。
- **温度条件忽略**：直接用 $pH + pOH = 14$ 而未确认温度是否为 25 ℃，非 25 ℃ 时应根据题目所给 $K_w$ 换算。

## 代表题精讲
**题目**：室温下，$M(OH)_2(s) \rightleftharpoons M^{2+}(aq) + 2OH^-(aq)$ 的 $K_{sp}=a$，当 $c(M^{2+}) = b \ \text{mol} \cdot L^{-1}$ 时，溶液的 $pH$ 是多少？

**思路**：已知 $K_{sp}$ 表达式直接关联 $[M^{2+}]$ 和 $[OH^-]$，代入 $[M^{2+}]=b$ 求出 $[OH^-]$，再换算成 $pH$。

**步骤**：
1. 沉淀溶解平衡：$M(OH)_2(s) \rightleftharpoons M^{2+} + 2OH^-$，$K_{sp} = [M^{2+}][OH^-]^2 = a$。
2. 代入 $[M^{2+}] = b$：$b \cdot [OH^-]^2 = a \ \Rightarrow \ [OH^-]^2 = \dfrac{a}{b}$。
3. 求 $[OH^-]$：$[OH^-] = \sqrt{\dfrac{a}{b}}$。
4. 计算 $pOH$：$pOH = -\lg[OH^-] = -\lg\sqrt{\dfrac{a}{b}} = -\dfrac{1}{2}\lg\dfrac{a}{b} = \dfrac{1}{2}\lg\dfrac{b}{a}$。
5. 室温下求 $pH$：$pH = 14 - pOH = 14 - \dfrac{1}{2}\lg\dfrac{b}{a} = 14 + \dfrac{1}{2}\lg\dfrac{a}{b}$。对照选项，即为 $14 + \lg\left(\sqrt{\dfrac{a}{b}}\right)$ 对应的形式。

**点评/变式**：
- 此题核心在于区分“题目给定浓度”与“由 $K_{sp}$ 导出的浓度”，千万不能认为 $[OH^-]=2b$。
- 变式1：将 $M(OH)_2$ 换成 $Fe(OH)_3$，注意 $K_{sp}=[Fe^{3+}][OH^-]^3$，计算时会出现立方根和对数系数 $\frac{1}{3}$。
- 变式2：已知溶液的 $pH$ 和 $K_{sp}$，反求某金属离子的最大允许浓度（用于沉淀完全或开始沉淀的判断），解题步骤反向操作即可。
