## 知识精要
- **定义与本质**：物料守恒（质量守恒）是指在电解质溶液中，某一特定元素的原始加入形态的总浓度，等于该元素在溶液中各种存在形态的平衡浓度之和。溶液体积变化时，守恒的是“物质的量”，浓度关系须乘以体积比。
- **核心公式形态**（以一元弱酸HA为例）：
    - 若加入$c_0$的HA：$c(\text{HA}) + c(\text{A}^-) = c_0$
    - 若加入$c_0$的NaA：$c(\text{HA}) + c(\text{A}^-) = c_0$，$c(\text{Na}^+) = c_0$
    - 多元弱酸/盐需考虑各形态系数：如$H_{n}A$体系，$c(\text{原始浓度}) = \sum [\text{各型体含A}]$。
- **用于沉淀溶解平衡**：难溶盐$MA$饱和溶液中，$M^+$不水解，则所有含$A$物种（$A^-$、$HA$等）总浓度等于溶解产生的$M^+$浓度。即$c(M^+)=c(A^-)+c(HA)$。若形成多种配合物，相应累加。
- **图像依据**：分布系数$\delta(x)$表示某形态占总浓度的分数，$\sum \delta_i = 1$。由图像交点可求$K_{a}$（$\delta$相等时pH=pKa），并可反推物料守恒关系。

## 解题方法与套路
1. **锁定“守恒原子”和原始来源**：读题找到不发生变化的中心原子（如弱酸根$A$、金属离子$M$等），确定该原子最初以什么形式加入（盐、难溶电解质、通入气体等）。
2. **列出所有含该原子的形态**：包括未电离的分子、各级电离离子、水解产物、沉淀形式、配合物等。例如二元弱酸$H_2A$的形态有$H_2A$、$HA^-$、$A^{2-}$。
3. **建立等量关系**：原始总浓度 = 各形态平衡浓度之和。若涉及两溶液混合，需乘以体积分数 $\frac{V_1}{V_1+V_2}$。
4. **结合其他守恒或平衡常数化简**：
   - 利用已知浓度、pH、分布系数计算单一形态浓度。
   - 用$K_{sp}$关联$c(M^+)$与$c(A^-)$，代入物料守恒消元。
   - 在图像题中，读出关键点（交点、起点）的$\delta$或浓度，代入守恒式检验或推导。
5. **快速判断正误**：选择题中可先写出守恒式，将选项变形与守恒式比对，或通过“守恒总量必须等于初始投料”快速排除缺项、多系数错误。

## 高频易错
- **遗漏水解产物**：如$Na_2CO_3$溶液，物料守恒中不仅有$CO_3^{2-}$，更有$HCO_3^-$、$H_2CO_3$。忽略质子化物种是头号失分点。
- **系数搞错**：$Na_2S$中$c(Na^+)=2[c(S^{2-})+c(HS^-)+c(H_2S)]$，系数的2极容易漏写。
- **混淆物料守恒与电荷守恒**：物料守恒只看某种原子，与电荷无关；电荷守恒是正负电荷总量相等。二者联立可导出质子守恒，但不能直接用物料守恒替代电荷守恒。
- **不能识别“隐藏”的物料守恒**：沉淀溶解平衡中，$M^+$无水解，而$A^-$有水解，题目给出$c(M^+)$与$c(H^+)$关系时，必须立刻反应出$c(M^+)=c(A^-)+c(HA)$这条核心守恒式。
- **图像题中错看曲线上点对应的形态**：分布系数图横坐标为pH，不同曲线代表不同形态。必须看准交点对应的$\delta$值，有时需要由$\delta$反推某形态浓度，切记总浓度可能并非恒定1。

## 代表题精讲

**题目**（2021全国乙-7）HA为一元弱酸，难溶盐MA的饱和溶液中$c(M^+)$随$c(H^+)$变化，$M^+$不发生水解。实验得$c^2(M^+)-c(H^+)$为线性关系（实线所示）。分析该线性关系的理论依据。
**思路**：由MA沉淀溶解平衡$M^+$、$A^-$，再利用弱酸$HA$的电离平衡和物料守恒，导出$c(M^+)$与$c(H^+)$的函数表达式，验证线性。
**步骤**：
1. 写出溶解平衡与$K_{sp}$：$MA(s) \rightleftharpoons M^+ + A^-$，$K_{sp}=c(M^+) \cdot c(A^-)$。
2. $A^-$水解产生$HA$，物料守恒为 $c(M^+) = c(A^-) + c(HA)$。
3. 由$HA$电离平衡：$K_a = \frac{c(H^+) \cdot c(A^-)}{c(HA)}$，得出 $c(HA) = \frac{c(H^+) \cdot c(A^-)}{K_a}$。
4. 代入物料守恒：$c(M^+) = c(A^-) + \frac{c(H^+) \cdot c(A^-)}{K_a} = c(A^-) \left(1+\frac{c(H^+)}{K_a}\right)$。
5. 用$K_{sp}$消去$c(A^-) = \frac{K_{sp}}{c(M^+)}$，得 $c(M^+) = \frac{K_{sp}}{c(M^+)} \left(1+\frac{c(H^+)}{K_a}\right)$，整理得 $c^2(M^+) = K_{sp} + \frac{K_{sp}}{K_a} c(H^+)$。
6. 故$c^2(M^+)$与$c(H^+)$呈线性关系，斜率为$\frac{K_{sp}}{K_a}$，截距为$K_{sp}$。验证了题目所述线性。
**点评/变式**：此题巧用物料守恒将沉淀溶解平衡与弱酸电离结合，容易因未列出$c(M^+)=c(A^-)+c(HA)$而卡住。变式可将一元弱酸换为二元弱酸，物料守恒项增加，斜率与$K_{a1},K_{a2}$相关。

**题目**（2017新课标Ⅱ-6）改变0.1mol·L⁻¹二元弱酸$H_2A$溶液的pH，溶液中$H_2A$、$HA^-$、$A^{2-}$的物质的量分数$\delta(x)$随pH变化如图所示。判断下列叙述错误的选项。
**思路**：运用分布系数总和为1验证物料守恒；由交点pH求$K_{a1},K_{a2}$；利用给定总浓度和$\delta$计算某形态浓度。
**步骤**：
1. 物料守恒检验：总浓度0.1mol·L⁻¹，则$c(H_2A)+c(HA^-)+c(A^{2-}) = 0.1$，$\delta_{H_2A}+\delta_{HA^-}+\delta_{A^{2-}}=1$。图线上任意pH三点纵坐标和必为1，可判断选项关于物料守恒描述的误正。
2. 求$K_{a1}$：当$c(H_2A)=c(HA^-)$即两曲线交点处，pH=p$K_{a1}$，由交点读出；同理$HA^-$与$A^{2-}$曲线交点对应p$K_{a2}$。
3. 已知总浓度和某点$\delta$求具体浓度：如pH=某一值时，$\delta_{A^{2-}} \approx 0.xx$，则$c(A^{2-}) = 0.1 \times \delta$。选项中常错用“pH=…时$c(HA^-)$大于…”类，需结合$\delta$精确判断。
4. 典型错误选项往往违背物料守恒，如“溶液中$c(H_2A)+c(HA^-)=0.1$”，漏掉$A^{2-}$，即可判定错误。
**点评/变式**：分布系数图是物料守恒的直观体现，任何漏项或者系数错误都可迅速由$\delta$之和≠1识别。变式可改为混合溶液，如加入NaOH部分中和的$H_2A$体系，依然可用物料守恒$(c(Na^+)+c(H^+)$关系结合守恒列式判断。
