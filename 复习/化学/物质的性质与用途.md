## 知识精要
- 物质的性质决定其用途，熟记常见无机物的物理性质、化学性质及其对应的典型应用。
- 去油污：碳酸钠溶液因水解呈碱性（$CO_3^{2-}+H_2O \rightleftharpoons HCO_3^- + OH^-$），能促进油脂水解而被除去；也可用热的纯碱溶液增强效果。
- 消毒漂白：漂白粉的有效成分为 $Ca(ClO)_2$，使用时接触空气中的 $CO_2$ 与水，生成具有强氧化性的 $HClO$，从而杀菌消毒：  
  $$Ca(ClO)_2 + CO_2 + H_2O = CaCO_3\downarrow + 2HClO$$
- 中和胃酸：胃酸主要成分为盐酸，常用弱碱性的 $Al(OH)_3$ 或 $NaHCO_3$ 等中和。$Al(OH)_3$ 不产生气体，更为理想：  
  $$Al(OH)_3 + 3HCl = AlCl_3 + 3H_2O$$
- 医学造影：胃肠 X 射线造影需用不溶于水和酸的硫酸钡（$BaSO_4$）作“钡餐”；而 $BaCO_3$ 虽不溶于水，但可溶于胃酸，生成剧毒的 $Ba^{2+}$，因此绝对禁用：  
  $$BaCO_3 + 2HCl = BaCl_2 + CO_2\uparrow + H_2O$$
- 相关重要物质用途扩展：
  - $NaHCO_3$：食品膨松剂、胃酸中和剂、灭火剂。
  - $FeCl_3$：净水剂（水解生成 $Fe(OH)_3$ 胶体吸附杂质）。
  - $KAl(SO_4)_2 \cdot 12H_2O$（明矾）：净水、食品膨松剂。
  - $ClO_2$、$O_3$：饮用水消毒，无二次污染。
  - $SiO_2$：光导纤维；$HF$：刻蚀玻璃。
  - $Na_2O_2$：供氧剂（与 $CO_2$、$H_2O$ 反应生成 $O_2$）。

## 解题方法与套路
1. **审明“正确”或“错误”**：看清题干是要求选“正确”还是“错误”的说法，避免因惯性失分。  
2. **逐一对应“用途→性质”**：对每个选项，快速写出该用途所依赖的化学性质，并判断该性质是否真实、环境条件是否满足。  
3. **警惕相似物质的混淆**：重点区分 $BaSO_4$（不溶于酸，无毒）与 $BaCO_3$（溶于酸，产生有毒 $Ba^{2+}$）；区分 $Ca(ClO)_2$（消毒）与 $CaCl_2$（无漂白性）等。  
4. **考虑反应条件与副产物**：用途往往建立在特定条件下（如水中、空气中、胃酸中），并伴随副产物；若副产物有毒性或违背用途原则，则该应用错误。  
5. **结合生活常识与课本表述**：化学与生活类题目常来源于教材正文、科学探究或资料卡片，平时需注意积累并准确记忆。

## 高频易错
- **钡餐选用 $BaCO_3$**：许多学生只记住“钡盐不溶于水”而忽视胃酸的作用，误以为 $BaCO_3$ 也可作钡餐。必须明确 $BaSO_4$ 既不溶于水也不溶于酸，是唯一安全的钡餐成分。  
- **漂白粉消毒原理误解**：误认为 $Ca(ClO)_2$ 直接消毒，而实际上是由 $Ca(ClO)_2$ 与 $CO_2$、$H_2O$ 反应生成的 $HClO$ 起强氧化性杀菌作用。未指明 $HClO$ 或忽略反应条件都会导致失分。  
- **碳酸钠去污原理不清**：易混淆为“碳酸钠与油脂反应”或“溶解作用”。正确原理是水解呈碱性促进油脂水解（皂化反应），同时也是表面活性物质可起一定乳化作用。  
- **氢氧化铝中和胃酸的优点**：有的学生认为 $NaHCO_3$ 更好，忽略其产生 $CO_2$ 可能引起胃胀、胃穿孔的危险。氢氧化铝作为弱碱，中和过程温和且不产生气体，更适用于胃酸过多人群。  
- **其他易混点**：$SiO_2$ 用于制作光导纤维而非太阳能电池（太阳能电池用晶体硅）；$HF$ 能刻蚀玻璃，因其与 $SiO_2$ 反应，而其他酸不能；$FeCl_3$ 净水利用其水解生成胶体的吸附性，不是直接杀菌。

## 代表题精讲
**题目**（2018·新课标Ⅱ·1）  
化学与生活密切相关，下列说法错误的是  
A. 碳酸钠可用于去除餐具的油污  
B. 漂白粉可用于生活用水的消毒  
C. 氢氧化铝可用于中和过多胃酸  
D. 碳酸钡可用于胃肠 X 射线造影检查  

**思路**  
这是一道典型的“性质与用途匹配”判断题，需要逐项分析每个用途背后所依据的化学性质，并判断该性质是否真实、安全。错误选项往往隐藏着对物质化学性质的错误认知（如忽略了特定环境下的反应）。

**步骤**  
1. 选项 A：碳酸钠溶液因水解显碱性，碱性条件下油脂水解生成甘油和脂肪酸盐，可去除油污。该用途正确。  
2. 选项 B：漂白粉的主要成分 $CaCl_2$ 和 $Ca(ClO)_2$，有效成分为 $Ca(ClO)_2$。遇 $CO_2$ 和水生成 $HClO$，$HClO$ 具有强氧化性，能杀菌消毒。该用途正确。  
3. 选项 C：氢氧化铝 $Al(OH)_3$ 是难溶于水的两性氢氧化物，能与胃酸中的盐酸发生中和反应，降低胃液酸性，且不产生气体，安全可靠。该用途正确。  
4. 选项 D：碳酸钡 $BaCO_3$ 虽不溶于水，但可溶于胃酸（盐酸），生成有毒的氯化钡，$Ba^{2+}$ 为重金属离子会引起中毒。而胃部造影所需的是既不溶于水也不溶于酸的硫酸钡 $BaSO_4$。该用途错误。  
故答案为 D。

**点评/变式**  
- 此题以最常见的生活应用为情境，考查学生“性质→用途”的推演能力。错误选项 D 是经典陷阱，反复出现在各类考试中。  
- 变式设问：若将 D 改为“硫酸钡可用于胃肠 X 射线造影检查”——说法正确。若将 C 改为“碳酸氢钠可用于中和过多胃酸”——说法虽部分正确（能中和），但 $NaHCO_3$ 产生的 $CO_2$ 可能导致胃穿孔，故医学上慎用。这种“相对正确”的辨析在选择题中需根据题意判断。  
- 延伸记忆：常考的不溶性抗酸药还有氢氧化镁 $Mg(OH)_2$，同样不产生 $CO_2$；而三硅酸镁 $Mg_2Si_3O_8 \cdot nH_2O$ 能与酸反应同时保护胃黏膜。平时应多关联课本出现的药物成分及其原理。
