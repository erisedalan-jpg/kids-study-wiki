## 知识精要
- **反应物与生成物判断**：随反应进行物质的量减少的为反应物，增加的为生成物。
- **化学计量数的确定**：各物质的变化量之比等于化学方程式中对应物质的化学计量数之比（变化量 $\Delta n$ 取绝对值）。  
  $\Delta n(\text{A}) : \Delta n(\text{B}) : \Delta n(\text{C}) = a : b : c$
- **化学反应速率**：$v = \dfrac{\Delta c}{\Delta t} = \dfrac{\Delta n}{V \cdot \Delta t}$，单位通常为 $\text{mol}\!\cdot\!\text{L}^{-1}\!\cdot\!\text{min}^{-1}$ 或 $\text{mol}\!\cdot\!\text{L}^{-1}\!\cdot\!\text{s}^{-1}$。同一反应各物质速率之比等于化学计量数之比。
- **转化率**：$\alpha = \dfrac{\text{该物质的变化量}}{\text{该物质的起始量}} \times 100\%$。
- **化学平衡状态的标志**：各组分物质的量（浓度）不再随时间改变。

## 解题方法与套路
1. **读表识变**：观察表格数据，找出随时间进行物质的量不再变化的时刻（平衡点），并区分反应物与生成物。
2. **计算变化量**：选取从起始到平衡（或某一段反应完全进行）的数据，计算各物质物质的量的变化量 $\Delta n$。注意必须取同一时间段的差值。
3. **确定计量数**：将各物质的 $\Delta n$ 化为最简整数比，即得化学方程式的化学计量数。可逆反应写“$\rightleftharpoons$”，若题目表明完全反应则写“$=$”。
4. **求速率与转化率**：代入 $V$（容器体积）和 $\Delta t$ 求速率；用起始量和变化量求转化率。
5. **验证与延伸**：利用平衡数据验证方程式是否正确，或根据问题要求计算某时刻的瞬时速率（需用相邻数据近似）。

## 高频易错
- **忽略体积**：直接用物质的量变化代替浓度变化计算速率，忘记除以体积 $V$。
- **时间段选取错误**：计算速率时没有用对应时间段的变化量，或误用累计时间。
- **变化量比值未化简**：直接将变化量当作计量数，未化成最简整数比导致方程式错误。
- **反应物/生成物混淆**：未注意减少的是反应物、增加的是生成物，将计量数写反。
- **有效数据选择**：反应可能未达到平衡或数据有波动，必须选取浓度（物质的量）不再变化的稳定区间作为平衡状态。
- **单位换算出错**：时间单位（min / s）、体积单位（L / mL）必须一致。

## 代表题精讲
**题目**（2009·全国Ⅱ·9）  
在 2 L 密闭容器中，X 与 Y 反应生成 Z，测得不同时间各物质的量如表所示，请据此分析反应并完成相关计算。  

| t/min | X/mol | Y/mol | Z/mol |
|-------|-------|-------|-------|
| 0     | 1.00  | 1.00  | 0.00  |
| 1     | 0.90  | 0.80  | 0.20  |
| 3     | 0.75  | 0.50  | 0.50  |
| 5     | 0.65  | 0.30  | 0.70  |
| 9     | 0.55  | 0.10  | 0.90  |
| 10    | 0.55  | 0.10  | 0.90  |
| 14    | 0.55  | 0.10  | 0.90  |

**思路**  
从表格看到 X、Y 的物质的量随时间减少，Z 增加，X、Y 为反应物，Z 为生成物。9 min 后各物质量不变，说明已达平衡。取起始（0 min）与平衡（9 min）数据计算变化量。

**步骤**  
1. 变化量：$\Delta n(\text{X}) = 1.00 - 0.55 = 0.45\ \text{mol}$  
   $\Delta n(\text{Y}) = 1.00 - 0.10 = 0.90\ \text{mol}$  
   $\Delta n(\text{Z}) = 0.90 - 0.00 = 0.90\ \text{mol}$  
2. 化为最简整数比：$\Delta n(\text{X}):\Delta n(\text{Y}):\Delta n(\text{Z}) = 0.45:0.90:0.90 = 1:2:2$  
   化学方程式：$\text{X} + 2\text{Y} \rightleftharpoons 2\text{Z}$（因达到平衡，用可逆号）  
3. 若计算 0~1 min 内 X 的反应速率：$v(\text{X}) = \dfrac{1.00-0.90}{2 \times 1} = 0.05\ \text{mol}\!\cdot\!\text{L}^{-1}\!\cdot\!\text{min}^{-1}$  
   或用计量数关系求 $v(\text{Y})$、$v(\text{Z})$。  
4. X 的平衡转化率：$\alpha(\text{X}) = \dfrac{0.45}{1.00} \times 100\% = 45\%$  

**点评/变式**  
本题以表格形式考查“三段式”基础，关键在于选准起、止状态。变式可要求计算不同时间段的平均速率，或比较达到平衡的时间；也可将数据绘成曲线图考查读图能力。无论形式如何，核心都是变化量求算与计量数关系。
