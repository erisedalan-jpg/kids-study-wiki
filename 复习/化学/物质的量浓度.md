## 知识精要
- **定义**：溶质B的物质的量除以溶液的体积，符号 $c_B$，单位 $\mathrm{mol \cdot L^{-1}}$。  
  $$c_B = \frac{n_B}{V_{溶液}}$$
- **核心极限**：$V_{溶液}$ 是溶液总体积（不是溶剂体积），单位常用升（L）。溶液分成若干等份后，每一份的浓度不变，但溶质的物质的量与体积成正比。
- **稀释定律**：稀释前后溶质的物质的量不变。  
  $$c_1V_1 = c_2V_2$$
- **离子浓度关系**：  
  强电解质溶液中 $c(\text{离子}) = (\text{化学式中该离子个数}) \times c(\text{溶质})$。  
  如 $c(\mathrm{Cl^-}) = 2c(\mathrm{BaCl_2})$。
- **守恒思想（高频计算工具）**：  
  - **物料守恒**：溶液中某元素的总物质的量等于各来源贡献之和。  
    $$n(\mathrm{Cl^-}) = 2n(\mathrm{BaCl_2}) + n(\mathrm{KCl})$$
  - **电荷守恒**：阳离子所带正电荷总量 = 阴离子所带负电荷总量。  
  - **沉淀反应计量**：$n(\mathrm{Ba^{2+}}) = n(\mathrm{SO_4^{2-}})$，$n(\mathrm{Ag^+}) = n(\mathrm{Cl^-})$。
- **pH与浓度换算**（25℃）：  
  $$c(\mathrm{H^+}) = 10^{-\mathrm{pH}},\quad c(\mathrm{OH^-}) = 10^{-(14-\mathrm{pH})}$$
  混合后需先求剩余 $c(\mathrm{H^+})$ 或 $c(\mathrm{OH^-})$，再除以总体积反推原浓度。

## 解题方法与套路
1. **拆解体积与份数**：看清原溶液体积、分成几份、取哪一份用。每份体积 = 原体积 ÷ 份数，单位转化为 L。  
2. **写离子反应找计量关系**：明确“完全沉淀”对应的等量关系，如 $n(\mathrm{Ba^{2+}}) = a\ \mathrm{mol}$，$n(\mathrm{Cl^-}) = b\ \mathrm{mol}$。  
3. **建物料守恒方程**：用已知离子的物质的量表达未知离子。如 $n(\mathrm{Cl^-}) = 2n(\mathrm{Ba^{2+}}) + n(\mathrm{K^+})$，解出 $n(\mathrm{K^+})$。  
4. **求浓度**：$c = \dfrac{n}{V_{该份溶液}}$。注意 $V$ 是取用的一份溶液的体积，不是原总体积。  
5. **酸碱混合求原浓度**：  
   - 由 pH 得到过量离子的 $c$；  
   - 设原浓度为 $c_0$，根据体积比列出剩余物质的量表达式；  
   - 用剩余物质的量 ÷ 混合总体积 = 已知的过量离子浓度，解 $c_0$。  
6. **检验代数式**：答案常为含 $a,b$ 的表达式，计算后与选项比对。

## 高频易错
- **体积陷阱**：忘记将原溶液的分份倍数计入。如“500mL 分成5等份”→取一份 $V=0.1\ \mathrm{L}$。直接用 0.5 L 计算浓度会错选 0.2 $(b-2a)$ 之类的干扰项。  
- **离子来源漏项**：$n(\mathrm{Cl^-})$ 既来自 $\mathrm{BaCl_2}$ 又来自 $\mathrm{KCl}$，必须写成 $b = 2a + n(\mathrm{K^+})$，误写成 $b - a$ 导致错选 C。  
- **酸碱混合不除以总体积**：直接用 $n(\mathrm{OH^-})_{\text{剩}}$ 等于 0.01 求解，漏掉除以混合后总体积（$(3+2)V$），会得到 $c = 0.01\ \mathrm{mol \cdot L^{-1}}$ 错选 A。  
- **单位忽略**：pH 计算中 $c(\mathrm{OH^-})$ 的单位是 $\mathrm{mol \cdot L^{-1}}$，余下的物质的量必须对应混合后的总体积，不能忽略体积的倍数 $V$。

## 代表题精讲
### 1. 2010 全国新课标·04
**题目**：含 $\mathrm{BaCl_2}$ 和 $\mathrm{KCl}$ 的混合溶液 500 mL，分成 5 等份。一份加入 $a$ mol $\mathrm{Na_2SO_4}$，恰好使 $\mathrm{Ba^{2+}}$ 完全沉淀；另一份加入 $b$ mol $\mathrm{AgNO_3}$，恰好使 $\mathrm{Cl^-}$ 完全沉淀。求原混合溶液中 $c(\mathrm{K^+})$。  
**思路**：每份体积为 $\frac{500}{5}=100\ \mathrm{mL}=0.1\ \mathrm{L}$。由沉淀反应得 $n(\mathrm{Ba^{2+}})=a$，$n(\mathrm{Cl^-})=b$。根据氯离子物料守恒求出每份中 $n(\mathrm{K^+})$，再除以 0.1 L 得浓度。  
**步骤**：  
1. 每份溶液体积 $V_1 = 0.1\ \mathrm{L}$。  
2. $n(\mathrm{Ba^{2+}}) = n(\mathrm{Na_2SO_4}) = a\ \mathrm{mol}$。  
3. $n(\mathrm{Cl^-}) = n(\mathrm{AgNO_3}) = b\ \mathrm{mol}$。  
4. 由 $\mathrm{Cl^-}$ 来源：$n(\mathrm{Cl^-}) = 2n(\mathrm{Ba^{2+}}) + n(\mathrm{K^+})$，得 $b = 2a + n(\mathrm{K^+})$。  
5. $n(\mathrm{K^+}) = b - 2a\ \mathrm{mol}$。  
6. $c(\mathrm{K^+}) = \frac{n(\mathrm{K^+})}{V_1} = \frac{b-2a}{0.1} = 10(b-2a)\ \mathrm{mol \cdot L^{-1}}$。  
**点评**：典型的“离子守恒+体积等分”考题。变式可将 $\mathrm{Na_2SO_4}$ 换成 $\mathrm{H_2SO_4}$，或改变份数，核心都是先求一份中离子的物质的量，再求浓度。

### 2. 2008 全国Ⅱ·04
**题目**：物质的量浓度相同的 $\mathrm{NaOH}$ 和 $\mathrm{HCl}$ 溶液，以 3:2 体积比混合，所得溶液 pH=12。求原溶液的物质的量浓度。  
**思路**：pH=12 → $c(\mathrm{OH^-})_{\text{剩}} = 0.01\ \mathrm{mol \cdot L^{-1}}$，碱过量。设原浓度为 $c$，根据体积比计算剩余 $\mathrm{OH^-}$ 浓度，解出 $c$。  
**步骤**：  
1. 常温下，$\mathrm{pH}=12 \Rightarrow c(\mathrm{H^+})=10^{-12}$，$c(\mathrm{OH^-}) = 10^{-2} = 0.01\ \mathrm{mol \cdot L^{-1}}$。  
2. 设原浓度均为 $c\ \mathrm{mol \cdot L^{-1}}$，取体积 $3V$、$2V$，混合后总体积约为 $5V$。  
3. $n(\mathrm{OH^-})_{\text{总}} = 3cV$，$n(\mathrm{H^+}) = 2cV$，反应后剩余 $n(\mathrm{OH^-}) = 3cV - 2cV = cV$。  
4. $c(\mathrm{OH^-})_{\text{剩}} = \frac{cV}{5V} = \frac{c}{5} = 0.01$。  
5. 解得 $c = 0.05\ \mathrm{mol \cdot L^{-1}}$。  
**点评**：抓住“过量的碱”是解题关键，易错点在于忘记除以总体积 $5V$。变式可改为求混合后 pH，或改为弱酸/弱碱，同样用过量物质浓度列式。
