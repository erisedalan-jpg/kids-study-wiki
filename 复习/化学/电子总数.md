## 知识精要
- **电子总数**：微粒（原子、分子、离子）所含电子总数 = 各组成原子序数之和 − 微粒所带电荷数（阳离子减电荷值，阴离子加电荷值）。
  - 例：$_{11}Na^+$ 电子数 = $11 - 1 = 10$；$_{17}Cl^-$ 电子数 = $17 + 1 = 18$；$_{8}O^{2-}$ 电子数 = $8 + 2 = 10$。
- **等电子体**：电子总数相同的微粒。前20号元素常考等电子体系列：
  - **2电子**：$He$、$Li^+$、$H^-$。
  - **10电子**：$Ne$、$HF$、$H_2O$、$NH_3$、$CH_4$、$Na^+$、$Mg^{2+}$、$Al^{3+}$、$OH^-$、$F^-$、$O^{2-}$、$NH_4^+$ 等。
  - **14电子**：$N_2$、$CO$、$C_2H_2$、$HCN$ 等。其中 $CO$ 为碳的低价氧化物，与 $N_2$ 互为典型等电子体。
  - **18电子**：$Ar$、$HCl$、$H_2S$、$PH_3$、$SiH_4$、$H_2O_2$、$K^+$、$Ca^{2+}$、$Cl^-$、$S^{2-}$、$HS^-$ 等。
- **位置与价态规律**：同族元素往往具有相似的化合价和等电子关系（如 $C$ 与 $Si$，$N$ 与 $P$）。前20号元素中，短周期元素与对应的长周期同族元素易组合推断。
- **低价氧化物**：某元素在有多种价态时，呈现较低价态的氧化物。常见如 $C$ 的低价氧化物为 $CO$（+2价），$Fe$ 的低价氧化物为 $FeO$（+2价）。

## 解题方法与套路
1. **锁定等电子关系**：从题干中直接给出电子总数相等的微粒对入手，与熟记的10/14/18电子库匹配。  
   - 常见突破口：若“某低价氧化物与某单质分子电子总数相等”，优先想到 $CO$ 与 $N_2$（均14电子），锁定 $Q$ 为 $C$、$X$ 为 $N$。
2. **利用同族关系外推**：由已知元素和“同族”条件确定另一元素。如 $R$ 与 $Q$ 同族，且为前20号元素，则 $R$ 可能为 $Si$（$C$ 同族）。
3. **离子与稀有气体原子等电子**：若“离子与 $Ar$ 原子的电子总数相等”，则该离子必为18电子离子。前20号常见18电子离子：$K^+$、$Ca^{2+}$、$Cl^-$、$S^{2-}$。  
   - 结合原子序数大小、离子符号进行筛选。
4. **验证“不同族”等条**：用给出的“不同族”限制条件排除矛盾，最终确认元素组合。
5. **全局检验**：将推断元素带回各条件，检查电子总数、族关系、原子序数等是否吻合。

## 高频易错
- **低价氧化物判错**：若 $Q$ 为 $C$，其低价氧化物为 $CO$（电子数 $6+8=14$），切勿误选 $CO_2$（$6+8\times2=22$电子）。
- **离子电子数计算**：$Na^+$ 电子数是 $11-1=10$ 而非 $11$；$Cl^-$ 是 $17+1=18$ 而非 $17$。方向颠倒会导致全盘推断错误。
- **$Ar$ 电子总数**：$Ar$ 为18号元素，电子数 = 18。易与 $Ne$（10）混淆。
- **原子团等电子体忽略**：$OH^-$（10e⁻）、$NH_4^+$（10e⁻）、$H_3O^+$（10e⁻）等也常见，忽视会导致漏解。
- **族别判断失误**：$N$ 与 $K$ 不同族，但 $K$ 与 $Ca$ 相邻易混淆。务必根据周期表位置严谨区分主族和周期数。

## 代表题精讲
### **题目**（2008·全国Ⅱ·10节选）
$Q$、$R$、$X$、$Y$、$Z$ 为前20号元素中的五种，$Q$ 的低价氧化物与 $X$ 单质分子的电子总数相等，$R$ 与 $Q$ 同族，$X$、$Y$ 与 $Z$ 不同族，$Y$ 和 $Z$ 的离子与 $Ar$ 原子的电子总数相等。试推断五种元素。

**思路**  
从“电子总数相等”作为突破口，调用常见等电子体记忆库，先锁定 $Q$ 和 $X$，再利用同族关系推 $R$，最后借助18电子离子和族限制推出 $Y$、$Z$。

**步骤**  
1. $Q$ 的低价氧化物电子总数 = $X$ 单质分子的电子总数。常见14电子组：$CO$ 与 $N_2$。  
   - $CO$ 电子数 = $6 + 8 = 14$；$N_2$ 电子数 = $7 \times 2 = 14$。  
   - 故 $Q$ 为碳 $C$（低价氧化物 $CO$），$X$ 为氮 $N$（单质 $N_2$）。  
2. $R$ 与 $Q$（$C$）同族，前20号内为 $Si$（第ⅣA族）。  
3. $Y$ 和 $Z$ 的离子与 $Ar$ 原子电子总数相等，$Ar$ 为18号 $18e^-$。  
   - 可能的18电子离子：$K^+$（19−1=18）、$Ca^{2+}$（20−2=18）、$Cl^-$（17+1=18）、$S^{2-}$（16+2=18）。  
4. 限制条件：$X$（$N$）与 $Z$ 不同族，$Y$ 与 $Z$ 不同族。  
   - 若 $Z=K$（ⅠA族），$X=N$（ⅤA族）不同族，符合。  
   - 若 $Y=Cl$（ⅦA族），$Z=K$（ⅠA族）不同族，符合。且 $K^+$、$Cl^-$ 同为18电子。  
   - 其他组合如 $Ca^{2+}$ 与 $Cl^-$ 也可，需综合原子序数信息（题目可能存在后续设问，此处以典型解举例）。  
5. 故一组合理推断：$Q=C$，$R=Si$，$X=N$，$Y=Cl$，$Z=K$。  

**点评/变式**  
- 本题的“题眼”是等电子体 $CO$ 与 $N_2$，务必熟记14电子微粒组。  
- 变式可能给出 $Q$ 的氧化物与 $X$ 的氢化物等电子，如 $CO_2$ 与 $N_2O$（22电子），应与14电子区分。  
- 注意 $Ar$ 与 $Ne$ 的电子数混淆，若条件换为“与 $Ne$ 电子总数相等”，则对应10电子微粒。
