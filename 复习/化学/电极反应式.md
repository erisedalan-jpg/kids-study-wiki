## 知识精要
- **电极反应式书写原则**：负极发生氧化反应（失电子），正极发生还原反应（得电子）；必须满足质量守恒、电荷守恒，且介质中的离子可参与反应。
- **常见电池反应设定**：以海水（含 $Cl^-$ 、$Na^+$ 等）为电解质溶液时，电极产物可能与水或溶解物质发生后续反应。
- **难溶物电极写法**：正极材料为 $AgCl$ 等难溶盐时，电极反应式中应直接写 $AgCl$ 而非 $Ag^+$ ，对应关系为 $AgCl + e^- \rightarrow Ag + Cl^-$（因 $AgCl$ 溶解度极小，溶液中 $Ag^+$ 浓度极低）。
- **离子迁移方向**：原电池中，阴离子向负极移动，阳离子向正极移动。
- **副反应**：活泼金属（如 $Mg$ ）在以水为溶剂的电解液中可直接与水发生置换反应：$Mg + 2H_2O = Mg(OH)_2 + H_2 \uparrow$。

## 解题方法与套路
1. **确定两极与反应类型**：根据金属活泼性（或氧化性/还原性）判断负极（活泼金属）和正极（氧化剂材料）。负极失电子，正极得电子。
2. **书写电极反应式**：
   - 负极：金属单质直接写为 $M - ne^- = M^{n+}$（注意电荷守恒）。
   - 正极：若正极材料为可溶盐（如 $Ag^+$），写 $Ag^+ + e^- = Ag$；若为难溶盐（如 $AgCl$），写 $AgCl + e^- = Ag + Cl^-$，切勿拆分出离子。
3. **分析离子移动**：记住“负负正正”——负极带正电荷过剩吸引阴离子，阴离子向负极移动；阳离子向正极移动。
4. **检查副反应**：极度活泼金属（如 $Mg$、$Al$ 等）在水溶液中电极过程可能伴随与水直接反应，需结合题干条件判断是否存在副反应及其对电极反应的干扰。
5. **选项综合**：将每个选项放入完整电池模型验证，注意“错误的是”之类的逆向选择要求。

## 高频易错
- **误拆难溶盐**：看到 $AgCl$ 直接认为正极反应为 $Ag^+ + e^- = Ag$，忽略 $AgCl$ 难溶、溶液中 $Ag^+$ 浓度极低而不能持续反应的真实过程。
- **离子迁移方向记反**：误认为阴离子向正极移动，或阳离子向负极移动。需牢记原电池内部是阴离子流向负极，阳离子流向正极。
- **忽略活泼金属与水的副反应**：以为金属在电解质溶液中只发生电极反应，未考虑 $Mg$、$Al$ 等可直接被水氧化，导致错误判断负极副反应不存在或错误评价电池性能。
- **电荷守恒失误**：电极反应式只配平原子，忘记用电子配平电荷，尤其在结合 $Cl^-$ 等离子的正极反应中易漏写或错写电荷。

## 代表题精讲
**题目**（2016-新课标Ⅱ-05）  
$Mg–AgCl$ 电池以海水为电解质溶液，判断叙述错误选项。  
选项：A. 负极 $Mg-2e^-=Mg^{2+}$；B. 正极 $Ag^++e^-=Ag$；C. $Cl^-$ 由正极向负极迁移；D. 负极副反应 $Mg+2H_2O=Mg(OH)_2+H_2↑$。

**思路**  
先定位电池两极：活泼 $Mg$ 作负极，$AgCl$ 作正极。海水为电解液提供 $Cl^-$、$Na^+$、$H_2O$ 等。负极 $Mg$ 失去电子。正极 $AgCl$ 得电子还原为 $Ag$ ，同时释放 $Cl^-$。阴离子在电场作用下将向负极迁移。$Mg$ 的活泼性足够强，可与水发生副反应。据此检查各选项。

**步骤**  
1. 负极：$Mg$ 失电子生成 $Mg^{2+}$，A 项 $Mg-2e^-=Mg^{2+}$ 正确。  
2. 正极：$AgCl$ 难溶，反应式为 $AgCl+e^-=Ag+Cl^-$。若按 B 项写成 $Ag^++e^-=Ag$，相当于认为溶解的 $Ag^+$ 反应，但海水中 $Ag^+$ 浓度极低，实际反应物是固体 $AgCl$，故 B 错误。  
3. 离子迁移：原电池工作时，阴离子向负极移动。正极反应产生 $Cl^-$，所以 $Cl^-$ 由正极区向负极迁移，C 项描述“由正极向负极迁移”正确。  
4. 副反应：$Mg$ 是活泼金属，在海水（含水）中可直接与水反应：$Mg+2H_2O=Mg(OH)_2+H_2↑$，D 正确。

**点评/变式**  
本题核心陷阱在于正极反应式必须根据电极材料实际存在形式书写，不可想当然地拆开难溶盐。类似情形常出现在 $AgCl$、$AgBr$、$PbSO_4$ 等材料作电极时。备考时应熟练记忆：凡题目给出难溶盐作电极，书写反应式时必须保留难溶盐整体，释放相应阴离子，不可拆为简单离子。同时牢记原电池内部“阴离→负极，阳离→正极”以及活泼金属在水系电解液中的副反应可能性。
