## 知识精要
- **电离常数（$K_a$）**：对一元弱酸 $ \mathrm{HA} \rightleftharpoons \mathrm{H^+} + \mathrm{A^-} $，其电离常数 $ K_a = \frac{[\mathrm{H^+}][\mathrm{A^-}]}{[\mathrm{HA}]} $，式中各浓度为平衡时的物质的量浓度。
- **$K_a$ 的物理意义**：表示弱酸电离程度的大小。$K_a$ 越大，酸性越强；$K_a$ 只受温度影响，与浓度无关。
- **分布分数（$\delta$）与 $K_a$ 的关系**：对于一元弱酸体系，定义 $ \delta(\mathrm{HA}) = \frac{[\mathrm{HA}]}{c_{\text{总}}} $，$ \delta(\mathrm{A^-}) = \frac{[\mathrm{A^-}]}{c_{\text{总}}} $。当 $ \delta(\mathrm{HA}) = \delta(\mathrm{A^-}) $，即 $[\mathrm{HA}] = [\mathrm{A^-}]$ 时，代入 $K_a$ 表达式可得 $K_a = [\mathrm{H^+}]$，即 $ \mathrm{pH} = \mathrm{p}K_a $。
- **图像判据**：$\delta$–$\mathrm{pH}$ 分布曲线中，酸型体（如 $\mathrm{HA}$）和碱型体（如 $\mathrm{A^-}$）曲线交点的横坐标即为 $\mathrm{p}K_a$。

## 解题方法与套路
1. **定位曲线**：看清图中代表酸型体与碱型体的曲线（通常标示 $\delta(\mathrm{HA})$、$\delta(\mathrm{A^-})$）。
2. **找交点**：直接读取两曲线交点所对应的 $\mathrm{pH}$ 数值。
3. **计算 $K_a$**：由 $ \mathrm{p}K_a = \mathrm{pH}$ 得 $ K_a = 10^{-\mathrm{pH}} $，结果按科学记数法或数量级表示。
4. **推广**：对于多元弱酸（如 $\mathrm{H_2A}$），$\delta(\mathrm{H_2A})$ 与 $\delta(\mathrm{HA^-})$ 交点对应 $K_{a1}$；$\delta(\mathrm{HA^-})$ 与 $\delta(\mathrm{A^{2-}})$ 交点对应 $K_{a2}$。弱碱的分布曲线同理，交点 $\mathrm{pOH} = \mathrm{p}K_b$。

## 高频易错
- **混淆坐标**：误将分布分数当作浓度，找交点时需明确纵坐标是 $\delta$，交点仅表示两物种浓度相等，并非溶液 pH 等于 7 或滴定终点。
- **读数不准**：坐标轴分度较密时，易读错 $\mathrm{pH}$ 值（如将 7.5 读为 7.4），须看清最小刻度。
- **忽略对数关系**：直接写出 $ \mathrm{p}K_a = 10^{-7.5} $ 之类的式子，混淆 $ \mathrm{p}K_a $ 与 $K_a$ 的定义。正确应为 $K_a = 10^{-7.5}$。
- **错判曲线**：当图像给出多种组分（如同时存在 $\mathrm{H_2A}$、$\mathrm{HA^-}$、$\mathrm{A^{2-}}$），需认清每一级电离对应的酸型与碱型，切勿张冠李戴。
- **数量级表达失误**：$10^{-7.5}$ 介于 $10^{-8}$ 和 $10^{-7}$ 之间，常错写为 $10^{-7}$ 或 $10^{-8}$，可用 $ \sqrt{10}\times 10^{-8} \approx 3.2\times 10^{-8} $ 估算验证。

## 代表题精讲
**题目** （2020·新课标Ⅱ·8节选）次氯酸（$\mathrm{HClO}$）为一元弱酸，其电离平衡体系中各成分的组成分数 $\delta$ （$\delta(\mathrm{HClO})$、$\delta(\mathrm{ClO^-})$）与 $\mathrm{pH}$ 的关系如图所示。求 $\mathrm{HClO}$ 的电离常数 $K_a$ 值。

**思路**  
图像给出 $\mathrm{HClO}$ 和 $\mathrm{ClO^-}$ 的分布曲线，两线交点处 $[\mathrm{HClO}] = [\mathrm{ClO^-}]$。根据电离常数表达式，此时 $K_a = [\mathrm{H^+}]$，交点对应的 $\mathrm{pH}$ 即 $\mathrm{p}K_a$，进而可得 $K_a$。

**步骤**  
1. 在分布曲线图中找到 $\delta(\mathrm{HClO})$ 与 $\delta(\mathrm{ClO^-})$ 的交点。  
2. 读取交点横坐标 $\mathrm{pH} \approx 7.5$。  
3. 由 $\mathrm{p}K_a = 7.5$ 得 $K_a = 10^{-7.5}$，可保留此形式，或转化为 $3.2 \times 10^{-8}$。

**点评/变式**  
&mdash; 该方法源自分布分数与电离平衡的定量关系，其本质是“缓冲溶液等组分比”的特殊情况，也是中和滴定半中和点的原理基础。  
&mdash; 若考题图像中同时给出 $\mathrm{H_2CO_3}$ 各级分布，则第一、第二级电离常数分别对应 $\mathrm{H_2CO_3}$/$\mathrm{HCO_3^-}$ 交点与 $\mathrm{HCO_3^-}$/$\mathrm{CO_3^{2-}}$ 交点。  
&mdash; 注意坐标若为 $\mathrm{pH}$ 与 $\lg\frac{[\mathrm{A^-}]}{[\mathrm{HA}]}$ 的图像，直线与横轴交点同样表示 $[\mathrm{HA}]=[\mathrm{A^-}]$，原理一致。
