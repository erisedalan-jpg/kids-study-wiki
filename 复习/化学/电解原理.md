## 知识精要
- **电解池基本概念**
  - **电解池**：将电能转化为化学能的装置。
  - **构成条件**：外接直流电源、两个电极（阴、阳极）、电解质溶液（或熔融电解质）、形成闭合回路。
  - **电极判断**：
    - **阳极**：与电源**正极**相连，发生**氧化**反应。
    - **阴极**：与电源**负极**相连，发生**还原**反应。
  - **电子流向**：电源负极 $\to$ 阴极；阳极 $\to$ 电源正极。（电子不下水）
  - **离子流向**：阳离子移向**阴极**；阴离子移向**阳极**。

- **放电顺序**（在惰性电极，如石墨、铂的条件下）
  - **阳极（阴离子或活性电极失电子）**：
    活性电极（除Au、Pt外的金属） $>$ $S^{2-}$ $>$ $I^-$ $>$ $Br^-$ $>$ $Cl^-$ $>$ $OH^-$ $>$ 含氧酸根（如$SO_4^{2-}$） $>$ $F^-$。
    *特例：若阳极为活泼金属（Cu、Ag等），阳极自身优先氧化溶解。*
  - **阴极（阳离子得电子）**：
    $Ag^+$ $>$ $Fe^{3+}$ $>$ $Cu^{2+}$ $>$ $H^+$（酸） $>$ $Pb^{2+}$ $>$ $Sn^{2+}$ $>$ $Fe^{2+}$ $>$ $Zn^{2+}$ $>$ $H^+$（水） $>$ $Al^{3+}$ $>$ $Mg^{2+}$ $>$ $Na^{+}$ $>$ $Ca^{2+}$ $>$ $K^{+}$。
    *注意：水溶液中，位于氢之后的金属阳离子先于$H^+$放电；活泼金属阳离子（如$Na^+$）在水溶液中不放电，由水电离的$H^+$放电。*

- **电极反应式的书写**
  - **判电极、定离子**：先确定阴阳极，再根据放电顺序确定参与反应的离子。
  - **配电荷、配原子**：
    - 酸性环境：利用$H^+$和$H_2O$配平。
    - 碱性环境：利用$OH^-$和$H_2O$配平。
    - 熔融状态：直接根据离子化合价变化配平。
  - **电解水型**（如电解$Na_2SO_4$、$H_2SO_4$、$NaOH$溶液）：
    - 阳极：$2H_2O - 4e^- = O_2 \uparrow + 4H^+$ 
    - 阴极：$4H_2O + 4e^- = 2H_2 \uparrow + 4OH^-$ 
  - **电解电解质型**：
    - 如电解$CuCl_2$溶液：阳极 $2Cl^- - 2e^- = Cl_2 \uparrow$，阴极 $Cu^{2+} + 2e^- = Cu$。
  - **放氧生酸型/放氢生碱型**：阳极产物是$O_2$通常伴随$H^+$生成；阴极产物是$H_2$通常伴随$OH^-$生成。

- **电极产物的判断与现象**
  - **气体体积**：串联电路中电子守恒。电解水时，$V_{H_2}$（阴极）:$V_{O_2}$（阳极）=$2:1$。
  - **酸碱性变化**：
    - pH试纸或石蕊试纸湿润后置于电极口检验。
    - 阴极附近因产生$OH^-$，pH升高，遇酚酞变红或使石蕊变蓝。
    - 阳极附近因产生$H^+$（或消耗$OH^-$），pH降低，遇石蕊变红。若有$Cl_2$生成，湿润的淀粉-KI试纸变蓝。

## 解题方法与套路
1. **辨析池子**：首先明确装置是原电池还是电解池。有外接直流电源的为电解池，无电源但能自发氧化还原的为原电池。
2. **确定电极**：根据电源正负极确定阳、阴极。注意题目中的信息提示，如“待加工工件”“铝制品表面氧化”（阳极氧化），即该工件必须作**阳极**。
3. **分析介质与离子**：列出电解质溶液（或熔融液）中所有的阳离子和阴离子。
4. **排序放电**：依据阳极、阴极放电顺序，排除不参与反应的惰性离子，确定在阳极失电子的微粒和在阴极得电子的微粒。特别注意**阳极金属是否为活性电极**。
5. **书写半反应**：根据确定的放电微粒书写电极反应式，并利用介质环境（$H^+$或$OH^-$）配平电荷与原子。
6. **关联现象与计算**：
   - 观察气体颜色、气味、体积比。
   - 分析溶液pH变化及电极区颜色变化。
   - 结合电子守恒计算各电极产物的物质的量或质量。

## 高频易错
- **活性阳极被忽视**：当阳极为Fe、Cu、Ag等非惰性金属时，金属电极优先失去电子溶解，而不是溶液中的阴离子放电。例如2024辽宁卷“脱氯”中Cu屑的溶解及CuCl的生成均基于Cu单质失去电子变为$Cu^+$。
- **放电顺序记混**：混淆阴阳极放电顺序。务必牢记阳极是阴离子或金属失电子，阴极是阳离子得电子。水溶液中$Cl^-$在阳极放电生成$Cl_2$，而$SO_4^{2-}$等含氧酸根不放电，是水放电生成$O_2$。
- **酸碱环境误判**：电解水时，阳极产生$O_2$并导致局部$H^+$富集，使石蕊变红；阴极产生$H_2$并导致局部$OH^-$富集，使石蕊变蓝。考生常把阴阳极对应的酸碱性搞反。
- **电化学原理与工艺流程割裂**：在工业流程题中，无法将“通电”“极板析出物”“化合价仅某元素改变”等信息迅速翻译成电解池模型，导致无法推导出关键化学反应。如看到“仅有Cu价态改变”应立刻想到Cu单质失电子被氧化。
- **电解方程式产物忽略反应环境**：书写总反应方程式时，若阴阳极产物（如$Cl_2$与$NaOH$）会发生后续反应，不能简单相加，需考虑溶液中的二次反应。

## 代表题精讲

### 代表题一：2024-辽宁-13
- **题目**：某工厂利用铜屑脱除锌浸出液中的Cl⁻并制备Zn。流程涉及“浸铜”和“脱氯”，脱氯步骤仅Cu元素化合价发生改变。分析选项正误。
- **思路**：
  1. 明确“浸铜”是将Cu单质在酸性条件下用$H_2O_2$氧化为$Cu^{2+}$。
  2. 理解“脱氯”步骤利用“仅Cu价态改变”这一条件，推导出发生归中反应生成CuCl沉淀。
  3. 判断电化学装置：制备Zn应是电解$Zn^{2+}$，$Zn^{2+}$在阴极得电子生成Zn，阳极应发生氧化反应。
- **步骤**：
  - **审题**：题干指明“仅Cu元素化合价发生改变”，意味着Zn元素、Cl元素化合价不变。
  - **分析A项**：工业流程需控制原料用量。“浸铜”必须确保Cu全部溶解，若加足量$H_2O_2$可保证此步彻底。A正确。
  - **分析B项**：$Cu$与$H^+$不反应，应在酸性条件下被$H_2O_2$氧化。正确离子方程式：$Cu + H_2O_2 + 2H^+ = Cu^{2+} + 2H_2O$。原选项方程式还原产物写成了$H_2$而非水，原子不守恒且违背氧化还原规律。B错误。
  - **分析C项**：在脱氯液中存在$Cu^{2+}$、$Zn^{2+}$及$Cl^-$。若仅Cu价态改变，只能是$Cu^{2+}$与未反应的Cu单质发生归中反应，生成+1价的CuCl沉淀。反应为 $Cu + Cu^{2+} + 2Cl^- = 2CuCl \downarrow$。该反应实现了除Cl⁻。C正确。
  - **分析D项**：净化后主要含$Zn^{2+}$，电解精炼或制备Zn，$Zn^{2+}$应在阴极得电子生成Zn单质，阳极是粗锌或惰性电极失电子，不可能在阳极得到Zn。D错误。
- **点评/变式**：本题将氧化还原归中反应隐藏于电化学背景中，核心陷阱在于B项离子方程式的书写，必须遵守氧化还原守恒（化合价升降相同）和原子守恒。变式可考察若阳极是粗锌，阳极泥的成分。

### 代表题二：2017-新课标Ⅱ-05
- **题目**：用电解氧化法在铝制品表面形成致密氧化膜，电解质为$H_2SO_4-H_2C_2O_4$混合溶液，判断错误的叙述。
- **思路**：
  1. 目的：在铝制品表面生成$Al_2O_3$氧化膜。此为“阳极氧化”工艺。
  2. 模型构建：待加工器件必须连接电源正极作阳极，使其发生氧化反应。
  3. 阴阳极判定：铝制品为阳极（失电子），导电挂具或不锈钢等作阴极，溶液中的$H^+$在阴极得电子。
- **步骤**：
  - **分析A项**：“待加工铝质工件为阳极”是为了让铝表面失去电子，进而被氧化生成氧化膜。A正确。
  - **分析B项**：由于$H_2SO_4$提供酸性环境，阴极是溶液中的阳离子放电。根据放电顺序，$H^+$放电能力强，阴极反应为 $2H^+ + 2e^- = H_2 \uparrow$，B正确。
  - **分析C项**：阳极是Al，发生氧化反应。因表面生成致密氧化膜，反应原理是Al与溶液中的氧结合（由水提供）：$2Al + 3H_2O - 6e^- = Al_2O_3 + 6H^+$。不是简单Al变成$Al^{3+}$溶解，否则无法成膜。选项若说阳极反应仅是$Al - 3e^- = Al^{3+}$则是错误的。
  - **分析D项**：若用稀硫酸代替混合酸，硫酸阳极产物只有$O_2$（由$OH^-$放电生成），无法控制成膜环境；且草酸起到络合、缓冲或导电等辅助成膜作用以提高膜层质量。故不可简单替换。D正确。
- **点评/变式**：此类题需明确“氧化膜”必须是阳极原位生长。若阳极为活泼金属且生成的不是致密钝化膜，则可能发生溶解。本题重点辨析阳极是失电子溶解掉入溶液，还是失电子表面生成固态氧化物膜。
