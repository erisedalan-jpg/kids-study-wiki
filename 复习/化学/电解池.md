## 知识精要
- **定义**：电解池是将电能转化为化学能的装置。其核心构成包括外接直流电源、两个电极（活性或惰性）和电解质溶液（或熔融电解质）。
- **反应类型**：电解过程是非自发的氧化还原反应。与外接电源正极相连的是阳极，发生**氧化**反应；与外接电源负极相连的是阴极，发生**还原**反应。
- **电极判断**：
  - **阳极**：连接电源正极，吸引阴离子，发生氧化反应。若阳极为活性电极（如Ag、Fe、Cu），则优先放电溶解。
  - **阴极**：连接电源负极，吸引阳离子，发生还原反应。惰性电极只起导电作用。
- **离子移动方向口诀**：电解池中“阴阳相吸”，即阳离子移向阴极，阴离子移向阳极。特别注意与“可充电电池”的原电池模式区分：原电池是“正正负负”（阳离子移向正极）。
- **电极反应式书写规则**：
  1. 根据元素价态变化确定产物和得失电子数。
  2. 含氧酸盐或氧化物参与反应时，需根据环境（酸性/碱性/熔融盐）添加 $H^+$、$OH^-$、$H_2O$、$CO_3^{2-}$ 等使电荷与原子守恒。
  3. 书写充电过程的电极反应时，直接反转放电产物，不可生搬硬套“阴极还原”规则。充电时，接电源正极的为阳极（发生氧化），接电源负极的为阴极（发生还原）。

## 解题方法与套路
1. **一判装置，二判电极**：首步通过题设“通电”、“电解”、“充电”等关键词或外接电源示意图，断定装置为电解池。阳极连正极，阴极连负极。
2. **三判离子移动**：依据“阴阳相吸”规律，写出溶液中具体的阴、阳离子，标出移动方向，为判断电极反应物做好准备。
3. **四析放电，定价态变化**：
   - 判断阳极是活性电极放电溶解，还是溶液中的阴离子放电。
   - 判断阴极是 $H^+$ 还是金属阳离子放电。
   - **关键**：根据核心元素化合价的升降，准确判定是氧化（升价）还是还原（降价）。
4. **五查环境，配平反应**：分析电解质环境或电极材料（如 $WO_3$、$Na_2CO_3$、$Ni_2O_3$ 等固态氧化物），利用 $H^+$、$OH^-$、$CO_3^{2-}$ 等粒子确保电极反应式的电荷与原子守恒。
5. **六推总反应**：合并两个半反应，消去电子及中间粒子，验证总反应式是否与题意相符。

## 高频易错
- **电极类型混淆**：将电解池和原电池的电极名称、离子移动方向记反。电解池是“阴阳相吸”；原电池是“正正负负”。面对“二次电池”时，务必看清题问是“放电”还是“充电”。
- **化合价分析粗心**：对复杂物质（如 $Ag_xWO_3$、$Ni_2O_3$）中元素化合价的推算错误，导致氧化/还原判断定性失误。$Ag_xWO_3$ 中 $W$ 的化合价为 $+(6-x)$，发生还原反应。
- **电极反应式书写环境错误**：
  - **碱性环境**（如铁镍蓄电池）：产物是氢氧化物，用 $OH^-$ 和 $H_2O$ 配平，不能出现 $H^+$。
  - **熔融盐/固态电极**：反应物或产物可能为难溶氧化物，不要随意拆分成离子。
- **充电电极反应书写错误**：误以为“阴极一定得电子”。二次电池充电时，阴极发生的电极反应（如 $Fe(OH)_2 + 2e^- = Fe + 2OH^-$）实为还原，但该电极反应通过逆向书写来得更准确。切勿生硬套用“正极/阳极”规则，应从总反应倒推各电极的氧化/还原行为。

## 代表题精讲
**题目（2020-新课标Ⅱ-06）**：电致变色器件通电时，$Ag^+$ 注入无色 $WO_3$ 薄膜生成 $Ag_xWO_3$ 呈蓝色。判断叙述错误项。
- **思路**：该装置特点为通电后发生颜色变化，属于电能驱动化学反应的电解池。需找到化合价变化的元素，分析其在阴阳极的反应原理。
- **步骤**：
  1. 通电，且 $Ag$ 电极变为 $Ag^+$，发生氧化反应（$Ag - e^- = Ag^+$），故 $Ag$ 为阳极，A 正确。
  2. 电解池中，阳离子 $Ag^+$ 向阴极（$WO_3$ 变色层）迁移，B 正确。
  3. $WO_3$ 中 $W$ 为 +6 价，生成的 $Ag_xWO_3$ 中 $Ag$ 为 +1 价，由化合价代数和为 0 推得 $W$ 为 $+(6-x)$ 价，化合价降低，发生还原反应，C 错误。
  4. 合并阳极（氧化）与阴极（$xAg^+ + WO_3 + xe^- = Ag_xWO_3$）反应，得总反应 $WO_3 + xAg = Ag_xWO_3$，D 正确。
- **点评**：此题核心陷阱在于化合价的微观变化。看见“注入”不能想当然认为是物理掺杂，要理解为 $Ag^+$ 得电子后嵌入晶格，必然伴随 $W$ 的被迫降价以维持电荷守恒。

**题目（2018-新课标Ⅱ-06）**：关于“可呼吸” $Na-CO_2$ 二次电池（总反应：$3CO_2+4Na⇌2Na_2CO_3+C$）的判断错误项。
- **思路**：作为二次电池，需分解放电与充电两个互为可逆的过程进行分析。放电是原电池，充电是电解池。
- **步骤**：
  1. 放电时，$Na$ 失电子为负极，碳纳米管镍网得电子为正极。阴离子 $ClO_4^-$ 向负极移动，A 正确。
  2. 由总反应知，放电正极吸收 $CO_2$ 生成 $Na_2CO_3$ 和 $C$；充电时反应逆向，释放 $CO_2$，B 正确。
  3. 放电正极，$CO_2$ 得电子，在碳酸盐环境中生成 $CO_3^{2-}$ 和 $C$，电极反应为 $3CO_2 + 4e^- = 2CO_3^{2-} + C$，C 正确。
  4. 充电时，原放电负极（现在变为阴极）反应是 $Na^+$ 得电子沉积为 $Na$（$Na^+ + e^- = Na$），现在接电源负极，应为阴极。原正极（现在变为阳极）发生 $2CO_3^{2-} + C - 4e^- = 3CO_2$。D 项将充电阴极反应误写为“正极反应”，且反应环境与产物不匹配，故 D 错误。
- **点评**：此题区分度高，需全面掌握二次电池的“原电池放电”与“电解池充电”两种模式下的电极判断与反应书写。“呼吸”是现象，本质是充放电循环中的气体消耗与释放。

**题目（2011-新课标-05）**：铁镍蓄电池（$Fe+Ni_2O_3+3H_2O=Fe(OH)_2+2Ni(OH)_2$）的判断错误项。
- **思路**：根据总反应，元素化合价 $Fe: 0 \rightarrow +2$（氧化），$Ni: +3 \rightarrow +2$（还原）。结合产物为氢氧化物，判定为碱性电解液。
- **步骤**：
  1. 放电时，$Fe$ 氧化为负极，$Ni_2O_3$ 还原为正极，结合碱性环境给出半反应，A、B 正确。
  2. 充电时，阴极反应为放电负极的逆过程：$Fe(OH)_2 + 2e^- = Fe + 2OH^-$。此过程生成大量 $OH^-$，阴极附近碱性增强，C 错误。
  3. 充电阳极反应为放电正极的逆过程：$2Ni(OH)_2 + 2OH^- - 2e^- = Ni_2O_3 + 3H_2O$，D 正确。
- **点评**：此题为典型的消耗极性电解液的蓄电池。判断电解质酸碱性是破题关键。充电时离子浓度变化容易误判，可通过写出具体的半反应来确认 $OH^-$ 是反应物还是生成物。
