## 知识精要
- **碳酸盐与碳酸氢盐的相互转化**
  - 正盐 → 酸式盐：向碳酸盐溶液中通入过量 $CO_2$ 或滴加少量酸。
    $$CO_3^{2-} + CO_2 + H_2O \rightleftharpoons 2HCO_3^-$$
    （注：该反应消耗水，$NaHCO_3$ 溶解度显著低于 $Na_2CO_3$，饱和 $Na_2CO_3$ 溶液中通入 $CO_2$ 会析出 $NaHCO_3$ 结晶——侯氏制碱法关键原理）
  - 酸式盐 → 正盐：加热分解（固态 $NaHCO_3$）或加碱溶液。
    $$2NaHCO_3 \xrightarrow{\Delta} Na_2CO_3 + CO_2↑ + H_2O$$
    $$HCO_3^- + OH^- \rightleftharpoons CO_3^{2-} + H_2O$$

- **与酸反应定量关系**
  - $Na_2CO_3$ 与强酸逐滴反应分两步：
    $$CO_3^{2-} + H^+ \rightleftharpoons HCO_3^- \quad (立即)$$
    $$HCO_3^- + H^+ \rightleftharpoons CO_2↑ + H_2O \quad (后发生)$$
    逐滴加入等物质的量 $HCl$ 时，只发生第一步，无气泡。
  - $NaHCO_3$ 遇酸直接放出 $CO_2$：
    $$HCO_3^- + H^+ \rightleftharpoons CO_2↑ + H_2O$$
    等质量时，$NaHCO_3$ 产生 $CO_2$ 多（$NaHCO_3$ 摩尔质量 84 g·mol⁻¹，$Na_2CO_3$ 106 g·mol⁻¹，相同质量 $n(NaHCO_3) > n(Na_2CO_3)$）。

- **溶解性差异**
  - $Na_2CO_3$ 易溶；$NaHCO_3$ 溶解度较小（此性质常用于沉淀分离）。
  - $CaCO_3$ 难溶，遇 $CO_2$ 水溶液生成可溶 $Ca(HCO_3)_2$：
    $$CaCO_3 + CO_2 + H_2O \rightleftharpoons Ca(HCO_3)_2$$
  - $Ca(HCO_3)_2$ 只存在于溶液中，与 $NaHCO_3$ 溶液不反应（无 $CaCO_3$ 沉淀生成，二者混合不发生复分解）。

## 解题方法与套路
1. **逐项排除法**：定性推断各步产物是否合理，特别注意分步反应顺序、反应物比例与现象的匹配。
2. **定量计算验证法**：对于涉及质量、物质的量、气体体积的选项，写出关系式，通过摩尔质量或化学计量数计算比较。
3. **溶解度与结晶析出判断题**：若涉及饱和溶液通 $CO_2$ 或加盐，优先考虑产物的相对溶解度，以及反应是否消耗溶剂（水），从而使溶质过饱和析出。
4. **离子反应本质分析法**：拆开溶液中的主要离子，判断能否反应生成沉淀、气体或弱电解质，尤其区分“能反应”与“能共存”。

## 高频易错
- **向 $CaCO_3$ 溶解后的清液加 $NaHCO_3$**：误认为会复分解产生 $CaCO_3$ 沉淀，实则 $Ca(HCO_3)_2$ 与 $NaHCO_3$ 无有效离子结合，不能生成沉淀。
- **$Na_2CO_3$ 中逐滴加酸的气体体积比**：混淆“等物质的量”时只生成 $NaHCO_3$，错误套用 $1:2$ 思想。必须牢记分步反应，第一步不放 $CO_2$。
- **等质量 $NaHCO_3$ 与 $Na_2CO_3$ 产 $CO_2$ 体积**：凭主观认为都产生 $CO_2$ 且质量相等就相同，忽略摩尔质量差异。比较 $CO_2$ 体积须基于物质的量之比。
- **通 $CO_2$ 于 $Na_2CO_3$ 饱和溶液**：忽略反应消耗水且 $NaHCO_3$ 溶解度较小，未能判断出结晶析出，或认为仍为澄清溶液。
- **$Ca(HCO_3)_2$ 的不稳定性**：常温下加入 $NaHCO_3$ 不分解，若加热则析出 $CaCO_3$，但题目未加热，不能混淆条件。

## 代表题精讲
**题目**：2009年全国Ⅱ卷第3题，判断关于碳酸盐与碳酸氢盐转化的正确叙述。

**思路**：逐项分析反应实质，结合定量关系、溶解度和结晶条件，找出唯一正确项。

**步骤**：
- **A 项**：$CaCO_3$ 沉淀通 $CO_2$ 生成可溶 $Ca(HCO_3)_2$，沉淀恰好溶解；再加 $NaHCO_3$ 饱和溶液，溶液中 $Ca^{2+}$ 以 $Ca(HCO_3)_2$ 存在，加入 $NaHCO_3$ 并未提供 $CO_3^{2-}$（非碱性环境无法使 $HCO_3^-$ 转化为 $CO_3^{2-}$），不能生成 $CaCO_3$ 沉淀。该项错误。
- **B 项**：等物质的量 $HCl$ 逐滴加入 $Na_2CO_3$ 溶液，先发生 $CO_3^{2-} + H^+ \rightarrow HCO_3^-$，$HCl$ 耗尽时仅生成 $NaHCO_3$，无 $CO_2$ 放出，比例为 $0:1$。该项错误。
- **C 项**：设质量均为 $m$，$n(NaHCO_3)=m/84$，$n(Na_2CO_3)=m/106$。与足量盐酸反应时，碳原子均全部进入 $CO_2$，故生成 $CO_2$ 的物质的量之比为 $106:84$ 的倒数，即 $106/84 \neq 1$，体积不相同。该项错误。
- **D 项**：饱和 $Na_2CO_3$ 溶液通 $CO_2$ 发生 $Na_2CO_3 + CO_2 + H_2O \rightarrow 2NaHCO_3$。反应消耗水，$NaHCO_3$ 溶解度较小，且生成质量更大，故 $NaHCO_3$ 过饱和析出结晶。该项正确。

**点评/变式**：本题统摄碳酸盐与酸式盐转化的核心知识，覆盖沉淀溶解、分步定量、溶解度驱动结晶等综合思维。变式训练可关注：“向 $Ca(HCO_3)_2$ 溶液中加 $NaOH$ 溶液”生成 $CaCO_3$ 沉淀（适量时 $Ca^{2+} + 2HCO_3^- + 2OH^- \rightarrow CaCO_3↓ + CO_3^{2-} + 2H_2O$）；“等浓度 $Na_2CO_3$ 和 $NaHCO_3$ 混合液加酸逐滴”的气泡产生顺序等，强化分步反应与量比关系。
