## 知识精要
- **离子导体**：依靠离子迁移导电的物质，在电化学装置中充当电解质，必须隔绝电子导电。常见有电解质溶液、熔融盐和固体电解质（如快离子导体）。
- **固体电解质（快离子导体）**：只允许特定离子（如Na⁺）在晶格中迁移，电子绝缘，兼具隔膜与电解质功能。典型代表：钠-β″-氧化铝陶瓷管。
- **ZEBRA电池（钠-氯化镍电池）**：以金属钠为负极活性物质，多孔Ni/NiCl₂为正极，钠离子导体陶瓷管为电解质。
  - 总反应：$2\text{Na} + \text{NiCl}_2 \xrightleftharpoons[\text{充电}]{\text{放电}} 2\text{NaCl} + \text{Ni}$
  - 放电时（原电池）：
    - 负极（Na）：$\text{Na} - e^- = \text{Na}^+$
    - 正极（NiCl₂）：$\text{NiCl}_2 + 2e^- = \text{Ni} + 2\text{Cl}^-$，随后 $2\text{Na}^+ + 2\text{Cl}^- = 2\text{NaCl}$（沉积在正极多孔Ni中）
    - 离子移动：Na⁺经离子导体向正极迁移，电子经外电路流向正极。
  - 充电时（电解池）：
    - 阴极（原负极）：$\text{Na}^+ + e^- = \text{Na}$
    - 阳极（原正极）：$\text{Ni} + 2\text{Cl}^- - 2e^- = \text{NiCl}_2$
    - 离子移动：Na⁺经离子导体向阴极（原负极）迁移。
- **适用条件**：分析离子导体时，必须明确其传导离子种类及迁移方向，严格区分电子/离子导电路径。

## 解题方法与套路
1. **明确装置工作状态**：先判断是放电（原电池）还是充电（电解池），电极极性相反，离子迁移方向不同。
2. **识别离子导体及传导离子**：从题干直接获取，如“钠离子导体”→传导Na⁺，其他离子和电子不能通过。
3. **书写电极反应**：依据活性物质得失电子能力。活泼金属作负极放电；充电时阳极发生氧化反应。正极反应需注意生成物是否与传导离子结合。
4. **确定离子移动方向**：放电时阳离子向正极移动，阴离子向负极移动（离子导体内若只允许阳离子通过，则只有阳离子移动）；充电时阳离子向阴极移动。可结合“外电路电子从负极流向正极，内电路离子补偿电荷”来理解。
5. **关联电极质量与电解质变化**：放电负极溶解质量减小，正极生成固态盐质量增加；固体电解质本身不消耗。

## 高频易错
- **混淆离子移动方向**：充电时Na⁺应从阳极（原正极）移向阴极（原负极），而非相反。典型错项：“充电时钠离子导体中Na⁺由负极移向正极”。
- **误以为离子导体可以传导电子**：陶瓷管是电子绝缘的，电子只能走外电路，若选项中暗示电子通过电解质则错误。
- **忽视离子选择透过性**：如钠离子导体中Cl⁻、Ni²⁺等不能迁移，若说“Cl⁻通过陶瓷管”即错。
- **错误书写正极反应**：不可将正极反应写为生成$\text{Cl}_2$的形式，因为Na⁺存在下立即结合为NaCl：$\text{NiCl}_2 + 2\text{Na}^+ + 2e^- = \text{Ni} + 2\text{NaCl}$ 或分步写但实质一致。
- **误判电极**：若以为NiCl₂是负极，未比较钠和Ni的活性差异。钠极活泼，必为负极。

## 代表题精讲
**题目**：“ZEBRA”蓄电池结构如图，电极材料多孔Ni/NiCl₂和金属钠由钠离子导体陶瓷管相隔。已知选项为：  
A．放电时，金属钠电极作负极  
B．充电时，钠离子导体中Na⁺由负极移向正极  
C．放电时，负极反应为 $\text{Na} - e^- = \text{Na}^+$  
D．放电时，Na⁺向正极移动  
问题：叙述错误的是哪一项？

**思路**：该电池放电时是原电池，Na失电子为负极，A、C正确；阳离子Na⁺向正极移动，D正确。充电时，电池变为电解池，原负极变为阴极，原正极变为阳极，Na⁺应由阳极（原正极）通过离子导体移向阴极（原负极），即向负极移动，选项B说“由负极移向正极”与正确方向相反。

**步骤**：
1. 放电分析：Na比NiCl₂中的Ni活泼，Na失电子作负极，A正确；电极反应Na－e⁻=Na⁺，C正确。
2. 放电时离子迁移：阳离子Na⁺向正极移动以维持电荷平衡，D正确。
3. 充电分析：外接电源，原正极接电源正极变阳极，原负极接电源负极变阴极。钠离子导体中Na⁺向阴极（原负极）移动。B叙述为由负极移向正极，刚好反向，故B错误，选B。

**点评/变式**  
本题透过离子导体考查电化学核心规律：迁移离子种类和方向由电极反应决定。相似变式可将钠离子导体换为质子交换膜（H⁺导体）或氧离子导体（固体氧化物燃料电池），分析方法一致：先判断充放电状态，确定电极极性和反应，再分析传导离子移动方向。牢记根本规律——原电池中阳离子移向正极，电解池中阳离子移向阴极，即可避免方向错误。
