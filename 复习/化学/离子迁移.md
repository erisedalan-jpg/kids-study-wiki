## 知识精要
- **离子迁移**：电池（原电池/电解池）内部，电解质中阴、阳离子在电场作用下的定向移动，用于传递电荷、完成电极反应。
- **基本规律**：
  - **原电池（放电）**：阳离子移向正极（阴极），阴离子移向负极（阳极）。
  - **电解池（充电/电解）**：阳离子移向阴极，阴离子移向阳极。
  - 口诀：正正负负（正离子→正极，负离子→负极）仅适用于原电池；电解池相反。
- **离子迁移与电极反应的关联**：
  - 迁移的离子可直接参加电极反应（如 $Ag^+$、$Zn^{2+}$、$Li^+$ 得/失电子）或维持溶液电中性。
  - 嵌入反应中，离子迁移至电极体相，导致元素化合价呈非整数或平均值（如 $Ag_xWO_3$ 中 $W$ 的化合价）。
- **离子交换膜**：选择性允许特定离子通过（质子膜、阴/阳离子交换膜），改变离子迁移路径，常用于区分电极室。
- **适用条件**：水溶液、有机电解液、熔融盐、固态电解质体系；能量转化装置（燃料电池、蓄电池、电解池、电致变色器件）。

## 解题方法与套路
1. **判断装置类型**  
   - 有外接电源 → 电解池；无外接电源、能自发反应 → 原电池。  
   - 注意“充电”过程为电解池，“放电”过程为原电池。
2. **确定电极与电极反应**  
   - 原电池：负极氧化（失电子），正极还原（得电子）。  
   - 电解池：阳极氧化（接电源正极），阴极还原（接电源负极）。  
   - 结合物质化合价变化写出半反应，注意介质参与（$H^+$、$OH^-$、$H_2O$ 等）。
3. **分析电解质中离子种类与迁移方向**  
   - 列出溶液中所有可自由移动的离子（电解质电离、电极反应产生的离子）。  
   - 依据“异性相吸”：阳离子移向阴极/正极，阴离子移向阳极/负极。  
   - 若存在离子交换膜，需判断膜允许通过的离子种类，再确定迁移路径。
4. **综合解答选项**  
   - 验证离子迁移方向是否与电极属性、电场方向一致。  
   - 计算化合价时，利用总反应或电极反应中电子守恒，列式求解平均化合价或嵌入系数。
   - 注意新型概念（如空穴 $h^+$）：可视为带正电的载流子，其移动方向与电子相反，用于驱动氧化反应。

## 高频易错
- **原电池与电解池离子迁移方向混淆**：充电时阳离子移向阴极，阴离子移向阳极；放电时正好相反。切忌死记“正离子移向正极”而不区分装置。
- **忽略溶液中隐蔽离子**：酸性介质中存在 $H^+$，碱性存在 $OH^-$，有时它们优先放电，影响主要离子的迁移分析。
- **离子交换膜选择性判断失误**：若为阳膜只有阳离子能通过，阴离子不能随意跨膜；若为质子膜只允许 $H^+$ 通过。
- **平均化合价陷阱**：如 $Ag_xWO_3$ 中 $W$ 化合价为 $+(6-x)$，相对于 $WO_3$ 中 $+6$ 价是降低而非升高；不能仅凭加合物的形式判断化合价变化。
- **概念混淆：电子流动 vs 离子迁移**：电子沿外电路移动（负极→正极或阳极→阴极），溶液中无电子自由移动，只能靠离子导电。题干若说“电子通过溶液”必错。
- **对“空穴 $h^+$”错误理解**：空穴相当于正电荷，在光照下产生并参与阳极氧化反应，其“移动”不能简单等同于阳离子迁移，需认清空穴消耗与离子生成的关系。

### 2023-新课标-04
**题目** 以 $V_2O_5$ 和 $Zn$ 为电极、$Zn(CF_3SO_3)_2$ 水溶液为电解质的电池，放电时示意图如下（图略）。分析放电过程中离子迁移等情况。  

**思路**  
该装置为无外接电源的原电池，$Zn$ 活泼性强，作负极；$V_2O_5$ 作正极。放电时负极氧化产生 $Zn^{2+}$，正极 $V_2O_5$ 得到电子并与 $Zn^{2+}$ 结合生成锌嵌入化合物。离子迁移需维持溶液电中性。

**步骤**  
1. 判断电极：$Zn$（负极） → $Zn - 2e^- = Zn^{2+}$；$V_2O_5$（正极） → $V_2O_5 + x Zn^{2+} + 2x e^- = Zn_x V_2O_5$。  
2. 离子迁移：负极区 $Zn^{2+}$ 浓度升高，正极区 $Zn^{2+}$ 被消耗，$Zn^{2+}$ 从负极区经溶液向正极区迁移。  
3. 阴离子迁移：$CF_3SO_3^-$ 不参加电极反应，为平衡负极区多余正电荷，将向负极迁移。  
4. 结论：主要阳离子 $Zn^{2+}$ 移向正极（$V_2O_5$ 电极）。

**点评/变式**  
考查原电池中离子迁移的“宏观表象”。变式可改为充电过程（电解池）时 $Zn^{2+}$ 移回负极；或加装阳离子交换膜限制 $CF_3SO_3^-$ 迁移，分析迁移离子种类变化。

光照充电为电解池：阳极发生 $Li_2O_2$ 氧化生成 $Li^+$ 和 $O_2$，阴极 $Li^+$ 还原为 $Li$。电解质中 $Li^+$ 从阳极区产生并向阴极迁移，空穴在阳极消耗。分析选项时，结合电解池离子迁移方向及反应物、产物判断。

1. 确定装置：充电时外电路有光生电动势，为电解池。
