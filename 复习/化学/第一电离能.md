## 知识精要

- **定义**：气态电中性基态原子失去一个电子转化为气态基态正离子所需要的**最低能量**，符号 $I_1$，单位 $\text{kJ}\cdot \text{mol}^{-1}$。
- **同周期递变规律**：从左到右，第一电离能整体呈**增大**趋势。  
  **异常**：第ⅡA族（$ns^2$全满）和第ⅤA族（$ns^2np^3$半满）的第一电离能高于同周期相邻元素。例：第一电离能 $\text{C}<\text{O}<\text{N}$。
- **同主族递变规律**：从上到下，原子半径增大，第一电离能**减小**。例：$\text{O}>\text{S}>\text{Se}$，$\text{K}<\text{Na}$。
- **影响因素**：原子半径（主要）、有效核电荷、电子排布（全满、半满较稳定）。

## 解题方法与套路

1. **判断位置，定向比较**  
   - 同周期：画简图，标出元素位置，顺着原子序数增大方向遵循递增规律，但需跳过ⅡA、ⅤA处的**凸起**。  
   - 同主族：直接按从上到下递减作答。
2. **出现ⅡA、ⅤA，先排查“反常”**  
   - 若相邻元素为 $\text{Be}$ 与 $\text{B}$、$\text{N}$ 与 $\text{O}$、$\text{Mg}$ 与 $\text{Al}$、$\text{P}$ 与 $\text{S}$ 等，第一电离能较高者为ⅡA/ⅤA族。  
   - 排序时，先将ⅡA、ⅤA置于相邻右侧元素之前，再结合整体趋势。
3. **推断题中，先定元素，再依规律排列**  
   - 根据电子排布、价层电子、离子电荷确定具体元素符号，再调用规律比较。
4. **表述规范**：直接用“元素符号+>”或“元素符号+<”连接，或描述“最小”“最大”。

## 高频易错

- **盲目记“C<N<O”**  
  实际：$\text{N}$ 的 $2p^3$ 半满稳定，$I_1$ 比 $\text{O}$ 大，正确顺序为 $\text{C}<\text{O}<\text{N}$。
- **忽略ⅡA、ⅤA凸起**  
  见 $\text{B}$、$\text{Al}$ 或 $\text{O}$、$\text{S}$ 就直接相邻排序，导致位置颠倒。
- **混淆同周期与同主族规律**  
  同周期递增，同主族递减，审题不清极易用反。
- **不理解“第一电离能最小”与金属性的关系**  
  最活泼的金属（如碱金属、碱土金属）通常第一电离能最小；题意中最小的往往是原子半径最大、金属性最强的元素，如 $\text{K}$。
- **主观认为非金属性强则第一电离能一定高**  
  $\text{N}$ 的非金属性弱于 $\text{O}$，但 $I_1(\text{N}) > I_1(\text{O})$，半满稳定起关键作用。

## 代表题精讲

### 2023-新课标-03  
**题目**：可吸附甲醇的晶体中含 $\text{C, N, O, B}$，判断关于第一电离能比较的正误：基态原子的第一电离能 $\text{C}<\text{N}<\text{O}$。  
**思路**：同周期元素 $\text{C, N, O}$，需应用ⅡA、ⅤA凸起规律，$\text{N}$ 为ⅤA，$I_1$ 比 $\text{O}$ 大。  
**步骤**  
1. 定位：$\text{C, N, O}$ 均为第二周期，从左到右原子序数递增。  
2. 趋势：正常情况下递增，但 $\text{N}$ 的 $2p^3$ 半满稳定，第一电离能大于 $\text{O}$。  
3. 排序：$I_1(\text{C}) < I_1(\text{O}) < I_1(\text{N})$，故 $\text{C}<\text{N}<\text{O}$ 错误。  
**点评/变式**：该选项为经典陷阱。遇到 $\text{C, N, O}$ 或 $\text{P, S}$ 等组合，立即标记半满效应。变式：比较 $\text{Be, B, C}$，则 $I_1(\text{B})$ 较低，$\text{Be}$ 因全满而凸起，顺序 $\text{B}<\text{C}<\text{Be}$。

### 2013-新课标Ⅱ-12  
**题目**：前四周期原子序数依次增大的元素 $\text{A, B, C, D}$，$\text{A}$ 和 $\text{B}$ 价层未成对电子各1个，$\text{A}^-$ 与 $\text{B}^+$ 电子数相差8；$\text{C, D}$ 与 $\text{B}$ 同周期，价层未成对电子数分别为4和2，且原子序数差2。回答：四种元素中第一电离能最小的是？  
**思路**：推断出具体元素，最易失电子的元素第一电离能最小。  
**步骤**  
1. $\text{A}^-$ 与 $\text{B}^+$ 电子数相差8且价层各一个未成对电子：$\text{A}$ 可能为 $\text{F}$（$2s^22p^5$，得到一个电子成 $\text{F}^-$），$\text{B}$ 为 $\text{K}$（$4s^1$，失去一个电子成 $\text{K}^+$）。$\text{F}^-$ 电子数 $10$，$\text{K}^+$ 电子数 $18$，差8，符合。  
2. $\text{C, D}$ 与 $\text{B}$（$\text{K}$）同周期（第四周期），$\text{C}$ 未成对电子数4，可能为 $\text{Fe}$（$3d^64s^2$，未成对4个），$\text{D}$ 未成对电子数2，且序数差2，$\text{D}$ 为 $\text{Ni}$（$3d^84s^2$，未成对2个）。  
3. 四种元素 $\text{F, K, Fe, Ni}$，$\text{K}$ 为碱金属，原子半径最大，金属性最强，最容易失去电子，第一电离能最小。  
**点评/变式**：先推断元素再运用周期规律。抓牢“第一电离能最小”与元素金属性最强的对应关系。若问电负性最大，则为 $\text{F}$。

### 2012-新课标-12  
**题目**：比较 $\text{O, S, Se}$ 原子的第一电离能由大到小的顺序。  
**思路**：ⅥA族从上到下，原子半径增大，失去电子越来越容易，第一电离能递减。  
**步骤**  
1. 定位：$\text{O, S, Se}$ 为同主族（ⅥA），自上而下依次为第二、三、四周期。  
2. 规律：同主族从上到下，原子半径增大，核对外层电子引力减弱，第一电离能减小。  
3. 排序：$\text{O} > \text{S} > \text{Se}$。  
**点评/变式**：单纯同主族比较直接使用递减规律即可，无需考虑半满影响。注意 $\text{O}$ 因原子半径小，有特殊性（如第二周期某些异常），但在同族比较中不影响大趋势。变式：比较 $\text{N, P, As}$，同理 $ \text{N}>\text{P}>\text{As}$。
