## 知识精要
- **等效平衡**：在一定条件（恒温恒容或恒温恒压）下，对同一可逆反应，不同起始投料方式达到平衡时，各组分百分含量（体积分数、物质的量分数）完全相同的状态。
- **核心判据——“一边倒”成比例**：
  将各组分的起始物质的量全部按化学计量数折算至同一边（通常折算至反应物一侧）。若折算后的对应物质的物质的量之比相等。
  - 恒温恒压：任意可逆反应，成比例即为等效平衡。
  - 恒温恒容且反应前后气体体积不变（$\Delta n_g = 0$）：成比例即为等效平衡。
  - 恒温恒容且反应前后气体体积变化（$\Delta n_g \neq 0$）：必须“一边倒”后完全相等（全等平衡）才是等效平衡。
- **等效平衡的结果**：达到等效平衡时，各组分的百分含量相同；各组分的绝对物质的量不一定相等（若恒温恒压，物质的量成比例；若恒温恒容且$\Delta n_g=0$，物质的量成比例；若恒温恒容且$\Delta n_g\neq0$，全等平衡时物质的量完全相同）。
- **本考点涉及的反应**：$CO_2(g) + H_2(g) \rightleftharpoons CO(g) + H_2O(g)$，反应前后气体分子数不变（$\Delta n_g = 0$）。在恒温恒压下属于仅需“成比例”即可等效。

## 解题方法与套路
1. **判断反应特征**：首先确认反应前后气体分子数（或体积）是否变化。如本题$\Delta n_g = 0$，恒温恒压与恒温恒容等效条件放宽。
2. **极端假设（一边倒）**：将各实验的起始加入物全部按方程式化学计量数折算到同一侧（通常折算为反应物）。注意折算时与被折算物在同一侧的起始量要叠加。
3. **比较折算结果**：看折算后各组对应物质的量是否成比例或相等。关注总物质的量（或各组分绝对量）的相对大小。
4. **得出平衡结论**：等效平衡的组别，所求组分（如$n(CO)$）大小相同；非等效组别，按折算后反应物总量多少排序（恒温恒压或$\Delta n_g=0$衡容时，总量越大平衡时产物绝对量也越大）。
5. **答题检查**：切忌直接根据单一物质起始量的大小下结论，必须考虑平衡移动和等效关系。

## 高频易错
- 乱用“一边倒”成比例条件：恒温恒容且气体分子数变化的反应，要求完全相等而非仅成比例，误当成比例作答。
- 忽略反应前后气体体积差：对$\Delta n_g = 0$的反应仍谨小慎微地去考虑恒容/恒压的区别，其实等效条件一致（均为成比例）。
- 直接比较某组分起始量判断平衡量：如本题若不转化，看到丙起始$n(CO)=a$，极易误以为平衡时$n(CO)$很大，实际丙全转化后与甲完全等效。
- 转化方向选择错误：一边倒时必须始终沿方程式正方向或逆方向统一折算，不得部分正、部分逆。本题解析把丙、丁的$CO$和$H_2O$全部转化为$CO_2$和$H_2$，做到一致。
- 混淆恒压条件下总物质的量与平衡产物量的关系：成比例等效时，平衡产物绝对量与起始投入总量成正比，但投料比例不同时不具可比性，需全转化后对比。

## 代表题精讲
**题目**（2008·全国Ⅱ·8）在相同温度和压强下，反应$CO_2(g) + H_2(g) \rightleftharpoons CO(g) + H_2O(g)$，四组实验起始物质的量见下表。达到平衡后，$n(CO)$的大小顺序是（　　）
|  | $CO_2$ | $H_2$ | $CO$ | $H_2O$ |
|--|-------|-------|------|--------|
|甲| $a$ | $a$ | 0 | 0 |
|乙| $2a$ | $a$ | 0 | 0 |
|丙| 0 | 0 | $a$ | $a$ |
|丁| $a$ | 0 | $a$ | $a$ |
A．乙=丁＞丙=甲　B．乙＞丁＞甲＞丙　C．丁＞乙＞丙=甲　D．丁＞丙＞乙＞甲

**思路**：该反应气体体积不变，恒温恒压下等效平衡只要求“一边倒”后物质的量成比例。将丙、丁中的产物全部转化为反应物，再与甲、乙比较折算后的起始量，量相等的组别平衡后$n(CO)$相同，量大的组别平衡后$n(CO)$更大。

**步骤**
1. 判断反应特点：$CO_2 + H_2 \rightleftharpoons CO + H_2O$，$\Delta n_g = 0$，恒温恒压属于成比例即等效。
2. 对丙进行极端假设转化：将$a\text{ mol }CO$、$a\text{ mol }H_2O$全部反应生成$a\text{ mol }CO_2$和$a\text{ mol }H_2$，折算后丙起始相当于$(a, a, 0, 0)$，与甲完全相同。
3. 对丁进行极端假设转化：$a\text{ mol }CO$、$a\text{ mol }H_2O$全部生成$a\text{ mol }CO_2$和$a\text{ mol }H_2$，加上原有的$a\text{ mol }CO_2$，共$2a\text{ mol }CO_2$，$H_2$为$a\text{ mol}$，折算后丁起始相当于$(2a, a, 0, 0)$，与乙完全相同。
4. 对比四组：甲与丙等效，乙与丁等效。起始量乙（丁）大于甲（丙），平衡时$n(CO)$自然是乙=丁＞甲=丙。
5. 对应选项A。

**点评/变式**  
- 评析：经典等效平衡题，使用“一边倒”将多组不同投料统一转换为同侧起始量，化繁为简。本题恒压且有$\Delta n_g=0$，等效条件宽容，只需注意转化完全性。  
- 变式：若改为恒温恒容，因$\Delta n_g=0$，等效条件不变，答案依然相同。若将反应换成$N_2 + 3H_2 \rightleftharpoons 2NH_3$（$\Delta n_g \neq 0$）且恒温恒容，则需“一边倒”后完全相等才等效，此时甲、丙转化后均为$a$、$a$（看作反应物），等效；乙、丁转化后不等效，平衡量需建立三段式求解，题目难度升级。
