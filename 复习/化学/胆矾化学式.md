## 知识精要
- 胆矾是五水合硫酸铜的俗称，化学式为 $CuSO_4\cdot 5H_2O$，属于结晶水合物，蓝色晶体。
- 结晶水合物中“·”前后分别写无水盐与结晶水分子数，命名时用“X水合XX”或俗名。
- 硫酸铜晶体受热易逐步失水：$CuSO_4\cdot 5H_2O \stackrel{Δ}{→} CuSO_4 + 5H_2O↑$，颜色由蓝变白。
- 胆矾是湿法冶铜的起始原料：$Fe + CuSO_4 = Cu + FeSO_4$，该反应属于置换反应，铁将铜离子还原为金属铜。
- 从溶液中获得结晶水合物的常用方法是蒸发浓缩、降温结晶（或趁热过滤），过滤洗涤干燥。

## 解题方法与套路
1. **审读文献信息**：用现代化学术语等价转换古文中描述的物质与操作。例如“苦泉”→含硫酸铜溶液，“熬之则成胆矾”→蒸发结晶得胆矾，“烹胆矾则成铜”→加热分解或铁釜置换得铜。  
2. **区分俗名与化学式**：胆矾、绿矾、明矾、芒硝等俗名必须与对应的化学式准确匹配，尤其注意是否带结晶水及结晶水数目。  
3. **判断物质转化类型**：铁与硫酸铜溶液反应为置换；加热胆矾失水为分解；溶液析出晶体为结晶或浓缩。  
4. **关注结晶水合物相关考点**：  
   - 化学式书写：$CuSO_4\cdot 5H_2O$，不可少写点号及水数。  
   - 制备/提纯：蒸发浓缩、冷却结晶、过滤。  
   - 定量计算：结晶水合物相对分子质量、与无水物的质量差值。  
5. **逐项验证选项**：将每个选项与题目信息、化学原理对照，快速排除不合理选项。

## 高频易错
- **混淆无水物与结晶水合物**：直接写胆矾为 $CuSO_4$ 漏掉 $\cdot 5H_2O$。  
- **把蒸发浓缩与蒸发至干混淆**：胆矾的制备要求加热蒸发浓缩后降温结晶，若蒸干会发生脱水分解。  
- **对“熬”“烹”等古语误读**：可能错误认为“烹胆矾则成铜”是直接加热分解胆矾生成铜（实际需要还原剂铁），或将“熬胆矾铁釜”误解为物理变化。  
- **置换反应范围的判定**：铁与硫酸铜溶液反应是置换，但高温下 $H_2$ 还原 $CuO$ 等也属置换，需灵活判断。  
- **结晶水合物书写习惯**：中间的点“·”不能省略，且写在中间偏下。

## 代表题精讲
**题目**（2020新课标Ⅱ第1题）  
《梦溪笔谈》记载：“苦泉…熬之则成胆矾，烹胆矾则成铜。熬胆矾铁釜，久之亦化为铜”。判断叙述正误。

**思路**  
先翻译古文得出物质与操作：苦泉含硫酸铜→蒸发结晶得胆矾（$CuSO_4\cdot 5H_2O$）；胆矾放入铁锅加热（铁与硫酸铜接触）发生置换生成铜，铁锅被腐蚀。然后结合选项逐一辨析。

**步骤**  
- A选项：胆矾化学式 $CuSO_4$ ——错误，应为 $CuSO_4\cdot 5H_2O$。  
- B选项：胆矾可作为湿法冶铜原料——正确，胆矾溶于水得硫酸铜液，加铁置换得铜。  
- C选项：“熬之则成胆矾”是浓缩结晶过程——正确，蒸去水分析出晶体。  
- D选项：“熬胆矾铁釜，久之亦化为铜”是发生了置换反应——正确，$Fe + CuSO_4 = Cu + FeSO_4$。

答案选A。

**点评/变式**  
本题以古籍为背景考查物质俗称与化学式、基本分离方法和反应类型，看似新颖，实则核心为基础知识。变式可考查：胆矾失水产物与现象、胆矾相对分子质量计算、从苦泉制备胆矾的实验流程（如蒸发浓缩、冷却结晶、过滤）。复习时需将常见结晶水合物一一对应，并熟悉从溶液中获取晶体的常用方法及适用条件。
