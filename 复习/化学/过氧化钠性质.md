## 知识精要
- **过氧化钠的物理性质**：淡黄色固体，有强吸湿性。
- **核心化学性质**：
  - 与水反应：$2Na_2O_2 + 2H_2O \rightarrow 4NaOH + O_2\uparrow$（既作氧化剂又作还原剂）。
  - 与二氧化碳反应：$2Na_2O_2 + 2CO_2 \rightarrow 2Na_2CO_3 + O_2$（常作供氧剂）。
  - **在空气中久置的变化路径**：$Na_2O_2$ 先与空气中的水蒸气作用生成 $NaOH$ 和 $O_2$，$NaOH$ 再吸收 $CO_2$ 生成 $Na_2CO_3$，最终白色固体为 $Na_2CO_3$。现象：淡黄色固体逐渐变为白色粉末。
- **稳定性**：$Na_2O_2$ 在通常受热条件下不易分解为 $Na_2O$ 和 $O_2$；$Na_2O$ 在空气中加热会进一步氧化为 $Na_2O_2$。
- **与物质的量相关的计算关系**：$2Na_2O_2 \sim O_2 \sim 2CO_2$（吸收 $CO_2$ 放出 $O_2$ 的量比），常与气体体积变化、混合物成分推断结合考查。

## 解题方法与套路
1. **抓颜色与状态变化，反推反应路径**  
   见到淡黄色变白色不溶物，立刻联想 $Na_2O_2$ 在空气中转化为 $Na_2CO_3$，而非分解为 $Na_2O$。
2. **氧化还原与非氧化还原反应的区分**  
   $Na_2O_2$ 中氧为-1价，与水或 $CO_2$ 的反应均是自身的歧化反应，产物中氧分别为-2价（$NaOH$、$Na_2CO_3$）和0价（$O_2$）。书写方程式时氧元素守恒是检查关键。
3. **熟悉常见物质在空气中变质规律**  
   碱性氧化物（如 $CaO$）→氢氧化物→碳酸盐；$Na_2O_2$ 同理最终得到碳酸盐。遇到有类似颜色变化的物质（如 $K_2O_2$），原理一致。
4. **离子方程式和化学方程式的正误判断题通用策略**  
   - 看是否符合事实（反应是否发生、产物是否正确）。
   - 看条件（如是否需要水浴、通电、催化剂）。
   - 看配平（质量守恒、电荷守恒）。
   - 重点关注“不能正确表达”的要求，避免因惯性思维错选。

## 高频易错
- **错误认定 $Na_2O_2$ 直接分解**：选项 $2Na_2O_2 \xrightarrow{放置} 2Na_2O + O_2\uparrow$ 是典型陷阱，实际上常温在空气中 $Na_2O_2$ 不分解，而是与 $CO_2$、水蒸气反应。
- **混淆 $Na_2O$ 与 $Na_2O_2$ 的转化关系**：$Na_2O$ 加热氧化能生成 $Na_2O_2$，但逆过程不通过热分解实现。
- **忽略颜色描述掩盖的真实反应**：看到“淡黄色变为白色”易误以为是发生了分解或风化，而忽略与空气中成分的多步反应。
- **单选题忽视“不能正确表达”的否定词**：考试时容易选出自己熟悉且正确的方程式，导致丢分。本题要求选“不能正确表达”的选项。
- **对沉淀转化原理记忆模糊**：$Mg(OH)_2$ 悬浊液与 $FeCl_3$ 反应生成 $Fe(OH)_3$ 红褐色沉淀，体现溶解度 $Fe(OH)_3 < Mg(OH)_2$，该反应属实且方程式正确。不能误判为错。

## 代表题精讲
### 代表题1：2019年新课标Ⅱ卷第5题
**题目**  
判断化学方程式中不能正确表达反应颜色变化的一项：  
A. $Zn$ 与 $CuSO_4$ 溶液反应蓝色消失（$Zn+CuSO_4═Cu+ZnSO_4$）  
B. 澄清石灰水久置出现白色固体（$Ca(OH)_2+CO_2═CaCO_3↓+H_2O$）  
C. $Na_2O_2$ 在空气中放置淡黄色变白色（$2Na_2O_2═2Na_2O+O_2↑$）  
D. $Mg(OH)_2$ 悬浊液与 $FeCl_3$ 溶液作用出现红褐色（$3Mg(OH)_2+2FeCl_3═2Fe(OH)_3+3MgCl_2$）  

**思路**  
本题以颜色变化为载体，考查反应原理的正误。必须逐个选项验证反应能否真实发生，特别关注C项中 $Na_2O_2$ 的变化本质。

**步骤**  
1. A项：锌置换铜，$Cu^{2+}$ 蓝色消失，固体析出红色铜，方程式正确。  
2. B项：$Ca(OH)_2$ 吸收空气中 $CO_2$ 生成难溶的 $CaCO_3$ 白色沉淀，方程式正确。  
3. C项：$Na_2O_2$ 在空气中先与水气生成 $NaOH$ 和 $O_2$，再与 $CO_2$ 反应生成 $Na_2CO_3$ 白色固体，不是直接分解为 $Na_2O$，方程式违背化学事实。  
4. D项：$Mg(OH)_2$ 溶解度大于 $Fe(OH)_3$，可转化为红褐色的 $Fe(OH)_3$ 沉淀，方程式正确。  
结论：C错误，为答案。

**点评/变式**  
- 考查“不能正确表达”时须审题冷静。  
- 变式：可问“$Na_2O_2$ 在空气中长时间放置后生成物的成分”，答主成分为 $Na_2CO_3$，可能含有少量 $NaOH$。也可联系供氧剂原理，问潜艇中 $Na_2O_2$ 吸收 $CO_2$ 的反应。  
- 牢记：$Na_2O_2$ 暴露在空气中最后的归宿是**碳酸钠**，不是氧化钠也不是硝酸钠。
