## 知识精要
- **酸碱中和本质**：$ \mathrm{H^+ + OH^- \rightleftharpoons H_2O} $，强酸强碱之间完全电离，反应实质是 $ \mathrm{H^+} $ 与 $ \mathrm{OH^-} $ 按物质的量 1∶1 结合。
- **pH 与浓度的关系**：$ \mathrm{pH = -\lg c(H^+)} $，$ \mathrm{pOH = -\lg c(OH^-)} $，常温下 $ \mathrm{pH + pOH = 14} $。若溶液 $ \mathrm{pH}=12 $，则 $ \mathrm{c(H^+)=10^{-12}\,mol/L} $，$ \mathrm{c(OH^-)=10^{-2}\,mol/L} $。
- **混合后酸碱过量的判断**：先分别求出 $ n(\mathrm{H^+}) $ 和 $ n(\mathrm{OH^-}) $，比较大小。若 $ n(\mathrm{OH^-}) > n(\mathrm{H^+}) $，则碱过量，剩余 $ \mathrm{c(OH^-)} = \dfrac{n(\mathrm{OH^-}) - n(\mathrm{H^+})}{V_{\text{总}}} $；若酸过量，则用 $ \mathrm{c(H^+)} $ 计算。
- **物质的量浓度计算通式**：$ c = \dfrac{n}{V} $，混合过程中 $ n $ 守恒，$ V_{\text{总}} $ 为混和后总体积（忽略体积变化时直接相加）。

## 解题方法与套路
1. **判过量**：由混合后 $ \mathrm{pH}=12>7 $ 可知碱过量，溶液显碱性，需用 $ \mathrm{c(OH^-)} $ 表征。
2. **设未知**：设原溶液物质的量浓度为 $ c\,\mathrm{mol/L} $，$ \mathrm{NaOH} $ 体积为 $ 3V $，$ \mathrm{HCl} $ 体积为 $ 2V $。
3. **算剩余**：  
   $ n(\mathrm{OH^-})_{\text{始}} = c \times 3V $，$ n(\mathrm{H^+})_{\text{始}} = c \times 2V $，  
   剩余 $ n(\mathrm{OH^-}) = 3cV - 2cV = cV $，  
   总体积 $ V_{\text{总}} = 3V + 2V = 5V $。
4. **列等式**：  
   $ \mathrm{c(OH^-)}_{\text{余}} = \dfrac{cV}{5V} = \dfrac{c}{5} $。  
   由 $ \mathrm{pH}=12 \Rightarrow \mathrm{c(OH^-)}=0.01\,\mathrm{mol/L} $，有 $ \dfrac{c}{5}=0.01 $，解得 $ c=0.05\,\mathrm{mol/L} $。
5. **验选项**：对照选项，$ 0.05\,\mathrm{mol/L} $ 对应 C 项。

## 高频易错
- **未判过量直接用 $ \mathrm{pH} $ 反推浓度**：看到 $ \mathrm{pH}=12 $ 就误以为 $ \mathrm{c(H^+)}=10^{-12}\,\mathrm{mol/L} $，再用反应掉的 $ \mathrm{H^+} $ 列式，导致错误。必须先明确过量离子。
- **体积叠加遗漏**：计算剩余离子浓度时，忘记反应后溶液总体积已变为两溶液体积之和，仍用某单一原体积做分母。
- **$ \mathrm{pH} $ 与 $ \mathrm{pOH} $ 换算混乱**：给 $ \mathrm{pH}=12 $ 时，$ \mathrm{c(OH^-)} $ 应为 $ 10^{-2}\,\mathrm{mol/L} $，而非 $ 10^{-12} $。常温下牢记 $ \mathrm{pH + pOH = 14} $。
- **单位忽视**：$ \mathrm{pH}=12 $ 对应 $ 0.01\,\mathrm{mol/L} $，代入时直接写 $ 10^{-12} $ 会导致结果差 $ 10^{10} $ 倍。

## 代表题精讲
### **题目**
物质的量浓度相同的 $ \mathrm{NaOH} $ 和 $ \mathrm{HCl} $ 溶液以 3∶2 体积比相混合，所得溶液的 $ \mathrm{pH}=12 $。则原溶液的物质的量浓度为（ ）  
A．0.01 mol·L⁻¹　B．0.017 mol·L⁻¹　C．0.05 mol·L⁻¹　D．0.50 mol·L⁻¹

**思路**  
$ \mathrm{pH}=12 $ 说明混合后碱过量，先转换为 $ \mathrm{c(OH^-)}=0.01\,\mathrm{mol/L} $。设原浓度为 $ c $，体积用比值代替，计算剩余 $ \mathrm{OH^-} $ 的量和总体积，建立方程求解 $ c $。

**步骤**  
设原溶液浓度为 $ c\,\mathrm{mol/L} $，取 $ \mathrm{NaOH} $ 体积 $ 3V $，$ \mathrm{HCl} $ 体积 $ 2V $。  
$ n(\mathrm{NaOH}) = 3cV $，$ n(\mathrm{HCl}) = 2cV $。  
发生中和 $ \mathrm{NaOH + HCl = NaCl + H_2O} $，碱剩余：  
$ n(\mathrm{OH^-})_{\text{余}} = 3cV - 2cV = cV $。  
混合后总体积 $ V_{\text{总}} = 5V $，  
$ \mathrm{c(OH^-)}_{\text{余}} = \dfrac{cV}{5V} = \dfrac{c}{5} $。  
已知 $ \mathrm{pH}=12 \Rightarrow \mathrm{pOH}=2 \Rightarrow \mathrm{c(OH^-)}=0.01\,\mathrm{mol/L} $，  
所以 $ \dfrac{c}{5} = 0.01 $，解得 $ c = 0.05\,\mathrm{mol/L} $，选 C。

**点评/变式**  
本题用“体积比”代替具体体积，巧妙消去 $ V $，是酸碱中和计算中的经典模式。  
- **变式 1**：同浓度 $ \mathrm{H_2SO_4} $ 与 $ \mathrm{NaOH} $ 混合，需注意二元酸提供 $ 2 $ 倍 $ \mathrm{H^+} $。  
- **变式 2**：已知混合后 $ \mathrm{pH}=2 $（酸过量），思路对称，改用剩余 $ \mathrm{c(H^+)} $ 列式。  
- **变式 3**：由已知浓度反推体积比，只需将 $ c $ 视为已知，设体积比 $ x:y $ 列方程。  
核心口诀：**判过量→算余量→加总体→定浓度**。
