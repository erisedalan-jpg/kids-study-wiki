## 知识精要
- **醛基检验原理**
  醛基（$—CHO$）具有强还原性，可被弱氧化剂氧化，常用两种反应：
  - **银镜反应**：$RCHO + 2[Ag(NH_3)_2]OH \xrightarrow{\Delta} RCOONH_4 + 2Ag\downarrow + 3NH_3 + H_2O$，水浴加热，试管内壁出现光亮的银镜。
  - **与新制 $Cu(OH)_2$ 悬浊液反应**：$RCHO + 2Cu(OH)_2 + NaOH \xrightarrow{\Delta} RCOONa + Cu_2O\downarrow + 3H_2O$，直接加热，产生砖红色 ($Cu_2O$) 沉淀。
- **适用对象**
  含醛基的有机物：醛类、甲酸、甲酸盐、甲酸酯、葡萄糖、麦芽糖等。酮糖（如果糖）在碱性条件下可异构化为醛糖，因此也能发生上述反应。
- **关键条件**
  - 反应必须在**强碱性环境** ($pH>11$) 中进行，通常使用过量 $NaOH$ 溶液。
  - 新制 $Cu(OH)_2$ 悬浊液需将 $NaOH$ 与少量 $CuSO_4$ 混合制得，确保 $NaOH$ 过量。
  - 两反应均需**加热**（银镜反应需水浴，新制 $Cu(OH)_2$ 反应直接加热至沸腾）。
- **糖类水解产物的检验**
  - 蔗糖、淀粉等在酸催化下水解生成还原性糖（葡萄糖）。
  - 检验水解液中的醛基前，**必须先用 $NaOH$ 溶液中和催化剂酸**，使溶液呈碱性，否则酸会消耗 $Cu(OH)_2$ 或破坏银氨溶液，导致实验失败。

## 解题方法与套路
1. **判断是否含醛基**  
   先看物质结构：是否含有 $—CHO$ 或属于能产生醛基的结构（缩醛、多糖等间接水解需注意）。含有 $—COOCH_3$ 等酯基的一般不直接反应，但甲酸酯可反应。
2. **书写反应方程式**  
   银镜反应用 $[Ag(NH_3)_2]OH$ 氧化，注意产物为羧酸铵盐；与新制 $Cu(OH)_2$ 反应时，醛被氧化为羧酸钠，氢氧化铜被还原为 $Cu_2O$。两种反应均需标注加热条件和碱性环境。
3. **设计检验方案**  
   - 若为简单醛类：直接加入新制 $Cu(OH)_2$ 或银氨溶液，加热观察现象。
   - 若为糖类水解液：先加稀酸水解，冷却后用 $NaOH$ 中和至碱性，再加入新制 $Cu(OH)_2$ 或银氨溶液，加热。
   - 若要判断水解程度：需取两份水解液，一份直接检验是否含醛基（判断是否部分水解），另一份中和后再检验（判断是否完全水解），并结合碘水等检验淀粉是否存在。
4. **实验操作与现象的匹配**  
   - 银镜反应：“光亮的银镜”说明成功；无明显现象或出现黑色沉淀（$Ag$ 疏松）可能是试管不干净或加热方式不当。
   - 新制 $Cu(OH)_2$ 反应：“砖红色沉淀”为阳性；若出现蓝色絮状沉淀溶解、溶液变绛蓝色而未加热即判定，属错误。

## 高频易错
- **忽视中和步骤**：蔗糖、淀粉水解时使用了稀 $H_2SO_4$ 作催化剂，水解液呈酸性，若不先用 $NaOH$ 中和至碱性，直接加入新制 $Cu(OH)_2$，$Cu(OH)_2$ 优先与酸中和，不出现砖红色沉淀，会误认为“未水解”或“无醛基”。（对应真题典型陷阱）
- **碱的用量不足**：新制 $Cu(OH)_2$ 时 $NaOH$ 未过量，导致 $Cu(OH)_2$ 量少或环境碱性不够，加热无法生成 $Cu_2O$。
- **加热条件错误**：银镜反应不能直接用酒精灯加热，须水浴加热；新制 $Cu(OH)_2$ 反应若未加热到沸腾，反应缓慢或不明显。
- **混淆酮糖性质**：果糖是酮糖，但在碱性条件下可烯醇化异构为醛糖，因此也能发生银镜反应和与新制 $Cu(OH)_2$ 的反应，不能说“酮糖不能发生这些反应”。
- **忽视还原性干扰**：某些物质（如 $Na_2SO_3$、$H_2S$ 等）也能还原银氨溶液，需结合其他特征反应判断是否为醛基。

## 代表题精讲
**题目**（2022全国乙卷第4题B选项）  
向蔗糖溶液中滴加稀硫酸，水浴加热，加入新制的 $Cu(OH)_2$ 悬浊液，无砖红色沉淀，结论：蔗糖未发生水解。判断该操作和结论是否正确。

**思路**  
蔗糖在稀硫酸催化下水浴加热，水解生成葡萄糖和果糖，两种产物均具有还原性，应与新制 $Cu(OH)_2$ 反应生成砖红色 $Cu_2O$。实验未观察到砖红色沉淀，并不能直接得出“未水解”，需要分析操作是否满足醛基检验的必备条件——强碱性环境。

**步骤**  
1. 蔗糖水解后，溶液中存在催化剂 $H_2SO_4$，体系呈强酸性。
2. 接下来直接加入新制 $Cu(OH)_2$ 悬浊液（含 $NaOH$ 过量），$Cu(OH)_2$ 会优先与 $H_2SO_4$ 发生中和反应：$Cu(OH)_2 + H_2SO_4 = CuSO_4 + 2H_2O$，悬浊液被破坏，无法提供氧化 $—CHO$ 所需的碱性 $Cu(OH)_2$。
3. 即便有少量 $Cu(OH)_2$ 剩余，由于酸未被中和完全，加热仍不利于醛基氧化。因此无砖红色沉淀只说明操作错误，不能证明蔗糖未水解。
4. 正确操作：水解后应冷却，加入 $NaOH$ 溶液至溶液呈碱性，再滴加新制 $Cu(OH)_2$ 悬浊液，加热煮沸，观察现象。

**点评/变式**  
这一陷阱在高考中反复出现，本质是考查“醛基检验的必备条件（碱性＋加热）”。变式常出现在淀粉水解程度的检验、纤维素水解等实验中。答题时，只要看到“酸催化水解后直接加新制 $Cu(OH)_2$ 或银氨溶液”的描述，应立即判断为错误操作，结论不可靠。此外，若题干改为“先加 $NaOH$ 中和，再加新制 $Cu(OH)_2$，加热后出现砖红色沉淀”，即可证明水解生成了还原性糖。
