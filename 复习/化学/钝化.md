## 知识精要
- **钝化定义**：常温下，某些金属（主要是 **Fe、Al**）在 **浓硫酸、浓硝酸** 中表面迅速生成一层**致密的氧化物薄膜**，阻止内部金属与酸进一步反应的现象。
- **本质**：属于**化学变化**。强氧化性酸将金属表层氧化为对应的氧化物（如 $Al_{2}O_{3}、Fe_{3}O_{4}$ 等），不是生成盐，也不是不反应。
- **条件与范围**
  - 金属：常见于 **Fe、Al**（Cr、Ni 等也会钝化）。
  - 试剂：必须是**强氧化性酸**——**浓 $HNO_{3}$、浓 $H_{2}SO_{4}$**（冷的更好）；稀酸（稀 $HNO_{3}$、稀 $H_{2}SO_{4}$）不会钝化，反而剧烈反应生成气体。
  - 温度：**常温/冷的浓酸**才钝化；加热会破坏氧化膜，发生剧烈氧化还原反应（生成 $NO_{2}、SO_{2}$ 等）。
- **实验现象**：金属表面无明显气泡，**无红棕色气体**（$NO_{2}$）或无色刺激性气体（$SO_{2}$）产生，溶液无明显颜色变化。不要描述为“不反应”。
- **应用**：常温下可用**铁制或铝制容器**储运浓硫酸、浓硝酸。

## 解题方法与套路
1. **锁定试剂与条件**：见到金属（尤其 Fe、Al）与硫酸、硝酸的组合，立刻抓取关键词——“浓”、“稀”、“常温”、“加热”。只要出现“常温/室温/冷的 **浓** $H_{2}SO_{4}$ 或浓 $HNO_{3}$”，立即联想钝化。
2. **区分反应状态**  
   - 钝化 ≠ 不反应：选项若说“Al 与浓硝酸不反应”一定错，钝化是反应后迅速停止。
   - 钝化 ≠ 生成气体：预测现象若写“产生红棕色气体（$NO_{2}$）”“气泡”等，必与实际不符。
3. **预判实验现象**：砂纸打磨过的铝条、铁片放入冷的浓硝酸/浓硫酸中 → **无明显现象**（表面可能变暗），而非产生刺激性气体或沉淀。
4. **结论正误判断**：选项结论若为“金属与浓酸不反应”“说明该酸无强氧化性”等，属错误。若为“金属发生钝化”“表面形成致密氧化膜”等，属正确。

## 高频易错
- **把钝化当作“不反应”**：铁/铝在常温浓硝酸中“几乎无明显现象”是钝化，化学反应已经发生，生成了致密氧化膜。
- **混淆稀酸与浓酸的作用**：一看见 Al 与硝酸就填钝化，但若试剂是**稀硝酸**则会剧烈反应生成 $NO$、$Al(NO_{3})_{3}$，不是钝化。
- **忽略温度限制**：题干写“加热”的条件下，浓硝酸/浓硫酸与铁、铝会持续剧烈反应，生成 $NO_{2}$ 或 $SO_{2}$，**不能答钝化**。
- **误判砂纸打磨后的现象**：用砂纸打磨仅去除了原始氧化膜，放入浓氧化性酸中会**重新钝化**，现象仍是“无明显变化”，不能预测产生红棕色气体。
- **电极问题中的干扰**：原电池里遇到浓硝酸，Al 或 Fe 可能因钝化而作正极，不是常规的活泼金属失电子。不要把钝化导致的现象当成普通反应。

## 代表题精讲
**题目**（2015 新课标Ⅱ 第7题 B 项）  
用图示装置进行实验：将①中物质滴入②中，预测②中的现象与实际是否相符。其中 B 项为：①浓硝酸，②用砂纸打磨过的铝条，预测现象：产生红棕色气体。

**思路**  
抓住“浓硝酸 + 常温 + 铝条（打磨）”，立即调用钝化原理，预测现象为无明显变化，而非气体生成。

**步骤**  
1. 判断试剂：①是浓 $HNO_{3}$，②是铝条。说明是金属与浓氧化性酸接触。  
2. 分析条件：题图未加热，默认常温。铝条经砂纸打磨除去了原始氧化膜，但遇浓 $HNO_{3}$ 瞬间被氧化生成新的致密 $Al_{2}O_{3}$ 膜，即钝化。  
3. 推断现象：钝化使反应迅速终止，内部铝不再与酸接触，因此不会持续生成 $NO_{2}$ 红棕色气体，实际现象应为**无明显变化**或金属表面略变暗。  
4. 对比预测：原预测“产生红棕色气体”与钝化的实际现象不符，因此该项错误。

**点评/变式**  
本题高频错误是简单地认为打磨除去了氧化膜，铝就直接与浓硝酸反应生成气体，完全忽略再钝化机制。变式可考：将浓硝酸换为稀硝酸，则预测产生无色气体（$NO$），现象相符；或加热条件下浓硝酸与铝条，才会产生红棕色气体，此时钝化被破坏。

**题目**（2023 新课标 第5题相关选项）  
根据实验操作及现象，判断结论是否正确，其中一组常见组合为：操作——常温将铝片放入浓硝酸中；现象——无明显现象；结论——铝与浓硝酸不反应。

**思路**  
这类题直接考查“钝化是化学变化”的核心认知，现象正确，结论错误。需识别出“无明显现象”对应的真实原因。

**步骤**  
1. 操作分析：常温、铝片、浓硝酸，符合钝化条件。  
2. 现象认可：“无明显现象”本身确实是与钝化相符的客观事实。  
3. 结论评价：“不反应”这一结论错在否认化学变化的发生。正确结论应为：常温下铝遇浓硝酸发生钝化，表面形成了致密氧化膜。  
4. 判断结果：该选项结论错误。

**点评/变式**  
本题陷阱在于将正确的现象表述与错误的因果解释混合。考生需牢记：钝化是反应（化学变化），表面膜是氧化物，结论中绝不能出现“不反应”。变式可能改为“铝在浓硫酸中钝化，说明浓硫酸无强氧化性”同样错误，钝化恰恰利用了浓硫酸的强氧化性。
