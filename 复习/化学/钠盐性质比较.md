## 知识精要
- $\text{Na}_2\text{CO}_3$（纯碱、苏打）与 $\text{NaHCO}_3$（小苏打）核心性质对比：
  - 水溶性：同温下 $S(\text{Na}_2\text{CO}_3) > S(\text{NaHCO}_3)$。向饱和 $\text{Na}_2\text{CO}_3$ 溶液通入 $\text{CO}_2$ 会析出 $\text{NaHCO}_3$ 晶体：$\text{Na}_2\text{CO}_3 + \text{CO}_2 + \text{H}_2\text{O} = 2\text{NaHCO}_3\downarrow$
  - 热稳定性：$\text{Na}_2\text{CO}_3$ 稳定不分解；$\text{NaHCO}_3$ 受热易分解：$2\text{NaHCO}_3 \xrightarrow{\Delta} \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$
  - 与盐酸反应：
    - $\text{Na}_2\text{CO}_3$ 分步进行：$\text{CO}_3^{2-} + \text{H}^+ = \text{HCO}_3^-$，$\text{HCO}_3^- + \text{H}^+ = \text{H}_2\text{O} + \text{CO}_2\uparrow$。当 $n(\text{HCl}) = n(\text{Na}_2\text{CO}_3)$ 时仅生成 $\text{NaHCO}_3$，无 $\text{CO}_2$ 气体
    - $\text{NaHCO}_3$ 快速放气：$\text{HCO}_3^- + \text{H}^+ = \text{H}_2\text{O} + \text{CO}_2\uparrow$
  - 与碱反应：$\text{NaHCO}_3 + \text{NaOH} = \text{Na}_2\text{CO}_3 + \text{H}_2\text{O}$；$\text{Na}_2\text{CO}_3$ 与 $\text{NaOH}$ 不反应
  - 与钙盐/钡盐：$\text{Na}_2\text{CO}_3$ 生成 $\text{CaCO}_3\downarrow$、$\text{BaCO}_3\downarrow$；$\text{NaHCO}_3$ 一般不生成沉淀（除非遇 $\text{Ca(OH)}_2$ 等）
  - 碳酸钙的转化：$\text{CaCO}_3 + \text{CO}_2 + \text{H}_2\text{O} = \text{Ca(HCO}_3)_2$（沉淀溶解），$\text{Ca(HCO}_3)_2$ 与 $\text{NaHCO}_3$ 不反应，与 $\text{Na}_2\text{CO}_3$ 反应：$\text{Ca(HCO}_3)_2 + \text{Na}_2\text{CO}_3 = \text{CaCO}_3\downarrow + 2\text{NaHCO}_3$
- 定量关系：等质量时 $n(\text{NaHCO}_3) = \frac{m}{84}$、$n(\text{Na}_2\text{CO}_3) = \frac{m}{106}$，与足量盐酸反应生成的 $\text{CO}_2$ 体积（同温同压）之比为 $\frac{m}{84} : \frac{m}{106} = 53:42$，不相等。

## 解题方法与套路
1. **锁定关键反应**：根据试剂组合快速写出离子方程式，注意 $\text{Na}_2\text{CO}_3$ 遇酸的分步特征（逐滴加入、等物质的量均为考点）。
2. **溶解决定性判断**：$\text{NaHCO}_3$ 相对 $\text{Na}_2\text{CO}_3$ 溶解度较小，饱和碳酸钠与 $\text{CO}_2$ 反应消耗水并生成 $\text{NaHCO}_3$，常作为结晶析出的标志模型。
3. **复杂沉淀转化分析**：明确“$\text{CaCO}_3 \rightleftharpoons \text{Ca(HCO}_3)_2$”可逆，$\text{Ca(HCO}_3)_2$ 遇 $\text{CO}_3^{2-}$ 沉淀、遇 $\text{HCO}_3^-$ 不沉淀。
4. **定量比大小**：等质量气体体积比→转化为物质的量比；等物质的量反应→按方程式计量判断产物有无。
5. **逐滴与滴加顺序陷阱**：$\text{Na}_2\text{CO}_3$ 滴入盐酸（酸过量）立即有气泡；盐酸逐滴滴入 $\text{Na}_2\text{CO}_3$（碳酸钠过量）则分步，当 $n(\text{H}^+) \le n(\text{CO}_3^{2-})$ 时无气体。

## 高频易错
- **误以为 $\text{Ca(HCO}_3)_2$ 与 $\text{NaHCO}_3$ 会复分解沉淀**：两者均含 $\text{HCO}_3^-$，无法结合 $\text{Ca}^{2+}$ 生成 $\text{CaCO}_3$，必须补充 $\text{OH}^-$ 或 $\text{CO}_3^{2-}$。
- **将等物质的量的 $\text{Na}_2\text{CO}_3$ 与 $\text{HCl}$ 反应直接写成放出 $\text{CO}_2$**：第一步仅生成 $\text{NaHCO}_3$，气体量为零，比值应为 $0:2=0$，而非 $1:2$。
- **质量与物质的量混淆**：比体积（同温同压）比的是物质的量，等质量时 $n = \frac{m}{M}$，摩尔质量不同导致 $n$ 不同，$\text{NaHCO}_3$（84）与 $\text{Na}_2\text{CO}_3$（106）不可想当然认为体积相等。
- **忽视 $\text{NaHCO}_3$ 溶解度较小的事实**：饱和 $\text{Na}_2\text{CO}_3$ 通 $\text{CO}_2$ 后水减少、产物 $\text{NaHCO}_3$ 溶解度更低，双重作用易结晶，不是任意浓度都能析出，题干强调“饱和”“结晶析出”正确。

## 代表题精讲
**题目** （2009·全国Ⅱ卷3题改编）：判断下列叙述正误。  
A. 向含 $\text{CaCO}_3$ 沉淀的水中通入 $\text{CO}_2$ 至沉淀恰好溶解，再加入 $\text{NaHCO}_3$ 饱和溶液，又有 $\text{CaCO}_3$ 沉淀生成。  
B. 向 $\text{Na}_2\text{CO}_3$ 溶液中逐滴加入等物质的量的稀盐酸，生成的 $\text{CO}_2$ 与原 $\text{Na}_2\text{CO}_3$ 的物质的量之比为 $1:2$。  
C. 等质量的 $\text{NaHCO}_3$ 和 $\text{Na}_2\text{CO}_3$ 分别与足量盐酸反应，在同温同压下，生成的 $\text{CO}_2$ 体积相同。  
D. 向 $\text{Na}_2\text{CO}_3$ 饱和溶液中通入 $\text{CO}_2$，有 $\text{NaHCO}_3$ 结晶析出。

**思路**  
本题覆盖碳酸盐的溶解平衡、分步反应计量、溶解度差异及质量与气体体积换算。需逐项调用反应原理和定量关系进行反驳或验证。

**步骤**  
- A项：$\text{CaCO}_3 + \text{CO}_2 + \text{H}_2\text{O} = \text{Ca(HCO}_3)_2$，得到 $\text{Ca}^{2+}$ 以 $\text{Ca(HCO}_3)_2$ 存在。加 $\text{NaHCO}_3$ 饱和溶液引入 $\text{Na}^+$ 和 $\text{HCO}_3^-$，无 $\text{OH}^-$ 或 $\text{CO}_3^{2-}$，不能使 $\text{Ca}^{2+}$ 沉淀。**错误**。  
- B项：$\text{Na}_2\text{CO}_3 + \text{HCl} = \text{NaHCO}_3 + \text{NaCl}$，$n(\text{HCl}) = n(\text{Na}_2\text{CO}_3)$ 时恰好生成 $\text{NaHCO}_3$，无 $\text{CO}_2$，体积比应为 $0$。**错误**。  
- C项：设质量均为 $m$，$n(\text{NaHCO}_3) = \frac{m}{84}$，$n(\text{Na}_2\text{CO}_3) = \frac{m}{106}$，根据碳守恒生成 $\text{CO}_2$ 的物质的量不同，同温同压体积不同。**错误**。  
- D项：饱和 $\text{Na}_2\text{CO}_3$ 溶液中通入 $\text{CO}_2$：$\text{Na}_2\text{CO}_3 + \text{CO}_2 + \text{H}_2\text{O} = 2\text{NaHCO}_3$，消耗水，且相同温度下 $\text{NaHCO}_3$ 溶解度小于 $\text{Na}_2\text{CO}_3$，故有 $\text{NaHCO}_3$ 结晶析出。**正确**。

**点评/变式**  
这道经典选择题系统考查了碳酸盐的“酸-盐-气体-沉淀”四重转化。易错点在“分步反应无气体”和“同质量气体体积不等”。变式可改为：“向饱和 $\text{NaHCO}_3$ 溶液中通入 $\text{CO}_2$ 是否析出晶体？”（不反应且不饱和降低，无析出）“等物质的量的两种盐与足量盐酸反应，耗酸量、产气量比较？”（耗酸 $\text{Na}_2\text{CO}_3$ 是 $\text{NaHCO}_3$ 两倍，产气量相同）。务必牢记溶解度差异和分步计量。
