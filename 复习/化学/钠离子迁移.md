## 知识精要
- **钠离子导体的作用**：在钠基电池（如ZEBRA蓄电池）中，钠离子导体（陶瓷管）是固体电解质，仅允许 $Na^+$ 通过，阴离子和溶剂不能透过。放电时 $Na^+$ 从负极移向正极，充电时从正极移向阴极（即放电时的负极），实现“摇椅式”迁移。
- **电极判断**：
  - 原电池（放电）：根据金属活动性，活泼金属钠必定为**负极**，发生氧化反应 $Na - e^- = Na^+$；相对不活泼的 $Ni/NiCl_2$ 电极为正极，发生还原反应 $NiCl_2 + 2e^- = Ni + 2Cl^-$（在钠离子导体中，正极反应常合并为 $NiCl_2 + 2Na^+ + 2e^- = Ni + 2NaCl$）。
  - 电解池（充电）：与电源负极相连的一极为**阴极**，$Na^+$ 在此得电子还原；与电源正极相连的一极为**阳极**，$Ni$ 在此失电子氧化。
- **总反应式**：放电时 $2Na + NiCl_2 \rightleftharpoons 2NaCl + Ni$，充电逆过程。适用条件：工作温度使 $Na$ 和 $NaCl$ 处于液态，陶瓷管提供 $Na^+$ 导通绝缘。
- **离子迁移方向规则**（必考）：
  - 放电：阳离子→正极，阴离子→负极（口诀“正带正电吸阳离子”或“正正负负”：阳离子去正极，阴离子去负极）。
  - 充电：阳离子→阴极（“阴极还原得电子，吸引阳离子”），阴离子→阳极。对钠离子电池，充放电时 $Na^+$ 移动方向相反。

## 解题方法与套路
1. **标化合价、判氧化还原**：写出总反应，找出变价元素。放电自发的方向为原电池，其中化合价升高的物质在负极发生氧化反应。
2. **确定电极名称**：
   - 放电：活泼金属（如 $Na$、$Li$）作**负极**，正极材料接受电子。
   - 充电：外接电源，原负极变成**阴极**，原正极变成**阳极**。
3. **分析离子移动**：给定膜或导体允许的离子种类。放电时阳离子向正极移动；充电时阳离子向阴极（即原负极）移动。可用“阳向正（放）”、“阳向阴（充）”快速判断。
4. **验证选项**：电极反应式关注电子得失与守恒，离子迁移方向与电极对应，总反应注意条件与可逆符号。

## 高频易错
- **颠倒充放电的电极名称**：放电时钠是负极，充电时该极变为阴极，大量同学误认为充电时钠电极仍是“负极”并标错离子移动方向。
- **阳离子迁移方向混乱**：误记“阳离子移向阴极”用于放电，导致放电时认为 $Na^+$ 移向钠电极（负极）。记住放电时正极带正电吸引阴离子？实则正极带正电是因电势高，但阳离子在溶液中移向正极（外电路电子流入正极，需要阳离子去中和电荷）。可用放电“正正”（阳离子去正极），充电“阳向阴”区分。
- **错判负极反应**：见到“钠失电子”便认为发生在正极，或混淆 $Na-e^-=Na^+$ 的位置。牢记活泼金属在放电时必为负极。
- **忽视电解质类型**：钠离子导体只导 $Na^+$，正极反应不能写成 $Cl^-$ 参与，只能写成 $Na^+$ 参与的形式，否则会误解离子迁移。

## 代表题精讲
**题目** （2013·新课标Ⅱ·5，改编） “ZEBRA”蓄电池的结构如图所示，电极材料多孔 $Ni/NiCl_2$ 和金属钠之间由钠离子导体制作的陶瓷管相隔。下列关于该电池的叙述错误的是（ ）
A. 电池总反应为 $2Na + NiCl_2 \rightleftharpoons 2NaCl + Ni$  
B. 放电时，金属钠是正极，电极反应为 $Na - e^- = Na^+$  
C. 充电时，钠离子通过陶瓷管向钠电极迁移  
D. 放电时，钠离子通过陶瓷管向 $Ni/NiCl_2$ 电极迁移  

**思路**  
先由总反应判断放电时的氧化还原，确定正负极。金属钠化合价升高，必为负极；Ni 化合价降低，$Ni/NiCl_2$ 电极为正极。再根据充放电与离子迁移规律，放电时 $Na^+$（阳离子）移向正极，充电时 $Na^+$ 移向阴极（即钠电极）。逐项比对即可找出错误选项。

**步骤**  
1. **写出放电反应**：$2Na + NiCl_2 = 2NaCl + Ni$，$Na$ 失电子，$Ni^{2+}$ 得电子。  
2. **电极确定**：放电时 $Na$ 为**负极**，$Ni/NiCl_2$ 为**正极**。选项 B 称“金属钠是正极”，与事实矛盾，错误。  
3. **离子移动**：陶瓷管为钠离子导体，只导 $Na^+$。放电时 $Na^+$ 从钠电极（负极）穿过陶瓷管移向 $Ni/NiCl_2$ 电极（正极），D 正确。充电时为电解池，钠电极接电源负极成为**阴极**，$Na^+$ 移向阴极（钠电极），C 正确。总反应式 A 也正确。  
4. **结论**：叙述错误的是 B。

**点评/变式**  
本题关键陷阱在看似简单的“电极名称”上，许多考生因惯性思维认为钠永远作负极而忽略题目选项故意将“负极”写成“正极”。变式训练可改问离子迁移方向或充电时的电极反应式，例如：“充电时阳极反应是什么？”应能推导出 $Ni + 2Cl^- - 2e^- = NiCl_2$（或结合钠离子导体写为 $Ni + 2NaCl - 2e^- = NiCl_2 + 2Na^+$）。遇到含固体电解质（如钠离子导体、锂离子导体）的题目，始终抓住两点：① 离子传导种类限制；② 充放电电极名称反转后离子移动方向随之反转。
