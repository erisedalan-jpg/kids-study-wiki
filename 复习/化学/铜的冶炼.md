## 知识精要
- **铜的存在与常见矿石**：黄铜矿($\mathrm{CuFeS_2}$)、辉铜矿($\mathrm{Cu_2S}$)、孔雀石($\mathrm{Cu_2(OH)_2CO_3}$)等。冶炼方法因矿石类型而异。
- **火法炼铜**（硫化矿）：
  1. 造锍熔炼：$$2\mathrm{CuFeS_2} + \mathrm{O_2} \xrightarrow{\Delta} \mathrm{Cu_2S} + 2\mathrm{FeS} + \mathrm{SO_2}$$ 得到冰铜（$\mathrm{Cu_2S}$ 与 $\mathrm{FeS}$ 熔体）。
  2. 吹炼：加入石英，先氧化 $\mathrm{FeS}$ 造渣：$2\mathrm{FeS} + 3\mathrm{O_2} \xrightarrow{\Delta} 2\mathrm{FeO} + 2\mathrm{SO_2}$，$\mathrm{FeO} + \mathrm{SiO_2} \xrightarrow{\Delta} \mathrm{FeSiO_3}$（渣）。再氧化 $\mathrm{Cu_2S}$ 得粗铜：$2\mathrm{Cu_2S} + 3\mathrm{O_2} \xrightarrow{\Delta} 2\mathrm{Cu_2O} + 2\mathrm{SO_2}$，$$2\mathrm{Cu_2O} + \mathrm{Cu_2S} \xrightarrow{\Delta} 6\mathrm{Cu} + \mathrm{SO_2} \uparrow$$
  3. 电解精炼：阳极粗铜溶解，阴极纯铜析出，粗铜中活泼金属（$\mathrm{Zn, Fe, Ni}$ 等）留在溶液，不活泼金属（$\mathrm{Ag, Au}$ 等）形成阳极泥。
- **湿法炼铜**（氧化矿/低品位矿）：
  - 酸浸：$\mathrm{CuO} + \mathrm{H_2SO_4} = \mathrm{CuSO_4} + \mathrm{H_2O}$
  - 置换：$\mathrm{Fe} + \mathrm{CuSO_4} = \mathrm{FeSO_4} + \mathrm{Cu}$（铁屑廉价）
  - 亦可用萃取‑电积法。
- **细菌冶金**（生物湿法，常用于低品位硫化矿及包裹金解离）：
  - 利用氧化亚铁硫杆菌等，在有氧、酸性条件下将不溶性硫化物转化为可溶性硫酸盐：
    $$4\mathrm{FeS} + 9\mathrm{O_2} + 2\mathrm{H_2SO_4} \xrightarrow{\text{细菌}} 2\mathrm{Fe_2(SO_4)_3} + 2\mathrm{H_2O}$$
    在黄铜矿中：$4\mathrm{CuFeS_2} + 17\mathrm{O_2} + 2\mathrm{H_2SO_4} \xrightarrow{\text{细菌}} 4\mathrm{CuSO_4} + 2\mathrm{Fe_2(SO_4)_3} + 2\mathrm{H_2O}$
  - 对于难处理金矿，**细菌氧化**破坏含金硫化物包裹层，使金暴露，再进行氰化浸金。
- **氰化提金原理**（联系真题）：$4\mathrm{Au} + 8\mathrm{NaCN} + \mathrm{O_2} + 2\mathrm{H_2O} = 4\mathrm{Na[Au(CN)_2]} + 4\mathrm{NaOH}$，再用锌置换：$2\mathrm{[Au(CN)_2]^-} + \mathrm{Zn} = 2\mathrm{Au} + \mathrm{[Zn(CN)_4]^{2-}}$。

## 解题方法与套路
1. **通读题头，明确原料成分与最终产品**。如真题原料为载金硫化矿粉（$\mathrm{Au}$ 被 $\mathrm{FeS, FeAsS}$ 包裹），产品为金。
2. **划分阶段，理清流程主线**：预处理（细菌氧化）→ 浸出（氰化）→ 提纯（置换/电积）。各阶段功能：氧化破坏包裹→ 溶解金→ 还原得单质金。
3. **书写陌生方程式**：抓住元素价态变化（$\mathrm{S^{2-} \rightarrow S^{6+}}$、$\mathrm{Fe^{2+} \rightarrow Fe^{3+}}$、$\mathrm{As^{3-} \rightarrow As^{5+}}$），依据电子守恒、电荷守恒、原子守恒配平，酸性环境可用 $\mathrm{H^+}$ 或 $\mathrm{H_2SO_4}$ 配电荷，氧的来源为 $\mathrm{O_2}$。
4. **分析条件控制**：
   - 温度：细菌活性适温 25–40 ℃，过高会致死；
   - pH：细菌氧化需酸性（pH 1.5–2.5），氰化浸金需碱性（pH 10–11）防止 $\mathrm{HCN}$ 逸出；
   - 通气：供氧以保障氧化作用和金溶解。
5. **绿色化学视角**：尾液含氰化物需氧化破坏（漂白粉等），滤液中的 $\mathrm{Fe^{3+}}$、$\mathrm{AsO_4^{3-}}$ 需回收或无害化处理。

## 高频易错
- **冰铜成分误解**：冰铜不是纯 $\mathrm{Cu_2S}$，而是含 $\mathrm{Cu_2S}$ 和 $\mathrm{FeS}$ 的混合熔体，后续吹炼先除铁后得铜。
- **湿法炼铜置换剂选择**：不能用 $\mathrm{Na, K}$ 等活泼金属，因与水剧烈反应且成本高；常用 $\mathrm{Fe}$。
- **细菌氧化产物**：硫化物彻底氧化为硫酸盐（$\mathrm{SO_4^{2-}}$），不是单质 $\mathrm{S}$ 或 $\mathrm{SO_2}$；砷被氧化成砷酸（$\mathrm{H_3AsO_4}$）或砷酸盐，而非 $\mathrm{As_2O_3}$。
- **细菌冶金条件**：误以为细菌直接“消化”矿石；实际是细菌催化 $\mathrm{Fe^{2+}}$ 氧化为 $\mathrm{Fe^{3+}}$，后者作为强氧化剂攻击硫化物，细菌从中获取能量。
- **难处理金矿的直接浸出**：若不经过氧化预处理，金被致密硫化物包裹，氰化物溶液无法接触金，浸出率极低——这是真题的核心陷阱。
- **砷的处理**：含砷硫化物氧化后，砷以砷酸根进入溶液，不能随意排放，需用石灰沉淀成砷酸钙等处置。

## 代表题精讲
**代表题：2024·辽宁·16**

**题目简述**：以细菌冶金技术处理载金硫化矿粉（细粒 $\mathrm{Au}$ 被 $\mathrm{FeS}$、$\mathrm{FeAsS}$ 包裹）的工艺流程为载体，考查提高金浸出率及冶炼金的物质转化、条件和原理。

**思路**：
细菌氧化阶段破坏包裹层，使金粒暴露；随后氰化浸出金形成络合物；再用锌置换得单质金。核心是书写细菌氧化
