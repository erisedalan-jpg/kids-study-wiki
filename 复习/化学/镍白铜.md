## 知识精要
- 合金的熔点通常低于其任一组分纯金属的熔点，原因是合金中各组分原子大小不同，排列不规则，原子间作用力减弱，加热时更易破坏有序结构。
- $\ce{Ni}$ 属于中等活泼金属，常温下在空气、水中稳定，可溶于稀硝酸等强氧化性酸：$\ce{3Ni + 8HNO3(稀) -> 3Ni(NO3)2 + 2NO ^ + 4H2O}$，钝化于浓硝酸。
- $\ce{Ni^2+}$ 可与 $\ce{NH3\cdot H2O}$ 先形成 $\ce{Ni(OH)2}$ 绿色沉淀，氨水过量时沉淀溶解，生成蓝色 $\ce{[Ni(NH3)6]^{2+}}$ 配离子。该配离子在配位平衡、电镀液中常见。
- 电镀时，待镀金属作阴极，镀层金属作阳极（或可溶性阳极），含镀层金属离子的溶液作电镀液。阴极得电子，阳极失电子，溶液中离子浓度保持基本稳定，可实现均匀镀层。
- 合金抗腐蚀性常优于组分金属，镍白铜因形成致密氧化膜及电化学性质改变而耐蚀，常用于铸币、仿银饰品。

## 解题方法与套路
1. **合金性质判断**  
   - 见到“合金的熔点/硬度”问题，依据组分原子半径差异导致的晶格畸变，得出“熔点低、硬度大”的规律。
   - 原电池腐蚀情境中，若合金某一组分被选择性腐蚀（如脱锌），要先明确更活泼金属发生氧化反应。
2. **过渡金属配位反应推理**  
   - 金属离子加氨水（或 $\ce{NaOH}$），先写沉淀反应，再根据“沉淀是否溶于过量试剂”判断是否生成配离子。
   - 配离子颜色为高频考点：牢记 $\ce{[Ni(NH3)6]^{2+}}$ 蓝色、$\ce{[Cu(NH3)4]^{2+}}$ 深蓝、$\ce{[Ag(NH3)2]+}$ 无色。
3. **电镀与电解计算**  
   - 确定阴阳极和电极反应；阳极若为可溶性金属（如镍阳极），失电子进入溶液，补充阴极消耗的离子。
   - 串联电路中各电极转移电子数相等，计算镀层质量用 $m = \frac{MIt}{nF}$（$I$ 电流，$t$ 时间，$n$ 电子数，$F = 96500\,\mathrm{C\cdot mol^{-1}}$）。
4. **信息型工艺流程题**  
   - 圈出原料和目标产物，分析每一步所加试剂的作用（酸浸、碱浸、配合、置换等）。
   - 关注价态变化，运用守恒书写陌生氧化还原方程式。注意调 $\mathrm{pH}$ 除杂时 $K_{sp}$ 的计算。

## 高频易错
- 合金熔点判断：误以为合金熔点高于纯金属；应注意答题时写明“合金内部原子排列不如纯金属规整，金属键减弱”。
- 镍氨配离子：错写为沉淀 $\ce{Ni(OH)2}$ 或不标电荷，如写成 $\ce{[Ni(NH3)6]}$ 而漏掉 $\ce{^{2+}}$；错记颜色为绿色（绿色是 $\ce{Ni(OH)2}$）。
- 电镀时电极材料选择：误将镀件作阳极；电极反应书写时未注意溶液酸碱性对产物影响。
- 计算电子转移时，$\ce{Ni}$ 的化合价混淆：单质 $\ce{Ni}$ 变为 $\ce{Ni^{2+}}$ 失去 $2e^{-}$，写半反应时对应。
- 陌生流程中忽视过量氨水的双重作用：先中和酸，再使 $\ce{Ni^{2+}}$ 转化为配离子进入溶液，与 $\ce{Fe^{3+}}$ 等形成氢氧化物沉淀分离。

## 代表题精讲
**代表题** 2016 年新课标 Ⅱ 卷第 12 题（部分）

**题目**  
东晋《华阳国志·南中志》记载云南镍白铜。镍白铜是铜镍合金，曾用于造币和仿银饰品。题目以镍白铜为背景，围绕合金性质、镍化合物的配合反应、电镀等展开设问，如：①镍白铜的熔点比纯组分____（填“高”或“低”），原因是什么；②$\ce{Ni^{2+}}$ 与过量氨水作用的实验现象和离子方程式；③以镍白铜废料回收镍，设计电镀方案并书写电极反应式等。

**思路**  
从合金通性开始，明确合金熔点低的原因；利用配位化学知识解释 $\ce{Ni^{2+}}$ 与氨水的反应，注意“先沉淀后溶解”的渐变过程；电镀部分要判断阴阳极，阳极用粗镍，阴极为镀件，通过控制条件实现镍的纯化与镀层。

**步骤**  
1. **合金熔点**：镍白铜为铜镍合金，原子半径差异导致晶格畸变，金属键减弱，故熔点低于纯铜或纯镍。答案：“低”；原因：“合金中原子种类不同、排列不规则，原子间金属键较纯金属弱，加热时易被破坏”。  
2. **配合物形成**：向含 $\ce{Ni^{2+}}$ 的溶液中逐滴加入氨水，先生成 $\ce{Ni(OH)2}$ 绿色沉淀，离子方程式：$\ce{Ni^{2+} + 2NH3\cdot H2O -> Ni(OH)2 v + 2NH4+}$；继续滴加氨水，沉淀溶解变为蓝色溶液，形成 $\ce{[Ni(NH3)6]^{2+}}$，离子方程式：$\ce{Ni(OH)2 + 6NH3\cdot H2O -> [Ni(NH3)6]^{2+} + 2OH- + 6H2O}$ （或写作 $\ce{Ni(OH)2 + 4NH3 + 2NH4+ -> [Ni(NH3)6]^{2+} + 2H2O}$，根据情景配平）。  
3. **电镀回收**：若以粗镍为阳极，纯镍片为阴极，$\ce{NiSO4}$ 溶液为电解液。阳极反应：$\ce{Ni - 2e- -> Ni^{2+}}$（粗镍中杂质落入阳极泥）；阴极反应：$\ce{Ni^{2+} + 2e- -> Ni}$。溶液中 $\ce{Ni^{2+}}$ 浓度基本不变，达到提纯和电镀双重目的。计算镀层质量时利用 $Q = It$、$n(e^{-}) = \frac{Q}{F}$，$m = \frac{M}{2} \times n(e^{-})$。

**点评/变式**  
该题将传统文化素材与电化学、配位化学巧妙融合，考查合金本质、配合物转化及电镀应用，是典型的结构–性质–应用串联题。易错点在于配离子颜色的表述和沉淀溶解方程式的配平。变式常见：以废镍催化剂（含 $\ce{Ni}$、$\ce{Al}$、$\ce{Fe}$ 等）为原料制备 $\ce{NiSO4\cdot xH2O}$ 的工艺流程题，亦用氨水配合除杂，其原理相通。
