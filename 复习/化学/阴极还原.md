## 知识精要
- **阴极反应本质**：电解池中与电源负极相连的电极，**电子流入**，发生**还原反应**（得电子）。
- **常见阴极反应书写模板**  
  ① 溶液中阳离子放电（惰性电极）：$M^{n+} + ne^- = M$（较不活泼金属）。  
  ② 若阳离子为活泼金属（如 $Na^+$、$Mg^{2+}$、$Al^{3+}$），实际是水电离出的 $H^+$ 放电：  
  $$2H_2O + 2e^- = H_2\uparrow + 2OH^- \quad (\text{或 } 2H^+ + 2e^- = H_2\uparrow)$$  
  ③ 当溶液中含有氧化性较强的阳离子（如 $Ag^+$、$Cu^{2+}$、$Fe^{3+}$）时，优先于 $H^+$ 放电。  
- **阴极放电顺序**（惰性电极）：  
  $$Ag^+ > Fe^{3+} > Cu^{2+} > H^+ (\text{酸}) > Pb^{2+} > Fe^{2+} > Zn^{2+} > H^+(\text{水}) > Al^{3+} > Mg^{2+} > Na^+$$
  其中 $H^+(\text{水})$ 代表水电离出的氢离子。  
- **适用条件**：① 惰性电极（石墨、铂等）——电极本身不参与反应；② 电解质为水溶液时，需考虑 $H_2O$ 的放电。  

## 解题方法与套路
1. **确定电解池两极**：外接电源正极→阳极；负极→阴极。电子从阴极流出，溶液中阳离子移向阴极。  
2. **识别溶液中的离子**：列出阳离子（含水电离的 $H^+$）和阴离子（含 $OH^-$）。  
3. **判断阴极放电顺序**：按氧化性顺序，最先放电的阳离子在阴极得电子。  
4. **书写阴极反应式**：  
   - 若放电的是水中的 $H^+$，用 $2H_2O + 2e^- = H_2\uparrow + 2OH^-$，并标注产物状态。  
   - 注意后续反应：阴极生成的 $OH^-$ 可能与 $Mg^{2+}$、$Al^{3+}$ 等生成沉淀。  
5. **结合题目情境分析**：如海水电解中，$Mg(OH)_2$ 沉淀覆盖管道可防生物附着；阳极产生的 $Cl_2$ 可杀菌。  

## 高频易错
- **混淆阴阳极**：阴极得电子，阳极失电子；阴极与电源负极相连，阳极与正极相连。  
- **阳离子放电顺序记错**：误以为 $Na^+$、$Mg^{2+}$ 等活泼金属阳离子能在水溶液中得电子，而实际是 $H^+$ 放电。  
- **忽视水的放电**：水溶液中无高氧化性阳离子时，阴极必定是 $H_2O$ 得电子生成 $H_2$ 和 $OH^-$，不可直接写成 $H^+ + e^-$ 而忽略水的电离平衡。  
- **忽略后续反应**：误以为阴极产物只有 $H_2$ 和 $OH^-$，未考虑 $OH^-$ 与 $Mg^{2+}$ 结合成 $Mg(OH)_2$ 沉淀，导致对实验现象（如阴极区沉淀、pH 升高等）判断错误。  
- **书写不规范**：电极反应式未配平电荷和质量，漏写 $e^-$ 或气体/沉淀符号。阴离子放电产物如 $Cl_2$ 写成 $Cl^-$。  

## 代表题精讲
### 2021-全国乙-06 电解海水防生物附着
**题目**  
沿海电厂以海水为冷却水，排水管道中生物附着影响排放。在管道口设置一对惰性电极，通入一定电流进行电解。下列关于该过程的说法错误的是？  
A. 阳极生成氯气，可用于杀菌  
B. 阴极发生还原反应，生成氢气  
C. 阴极附近 pH 升高，生成的 $Mg(OH)_2$ 覆盖管道表面  
D. 电解总反应为 $2NaCl + 2H_2O \xrightarrow{\text{电解}} 2NaOH + H_2\uparrow + Cl_2\uparrow$

**思路**  
电解海水（主要含 $Na^+$、$Mg^{2+}$、$Cl^-$ 等），惰性电极不参与反应。阳极阴离子放电：$Cl^-$ 失去电子生成 $Cl_2$；阴极阳离子放电：$Mg^{2+}$、$Na^+$ 均不放电，由 $H_2O$ 得电子生成 $H_2$ 和 $OH^-$。$OH^-$ 与 $Mg^{2+}$ 结合生成 $Mg(OH)_2$ 沉淀。阳极产物 $Cl_2$ 与水反应生成 $HClO$ 杀菌。总反应需写出实际发生的反应，由于生成 $Mg(OH)_2$ 沉淀，电解质中的 $Na^+$ 不参与最终产物。

**步骤**  
1. **确定两极**：阴极与电源负极相连，阳极与正极相连。  
2. **阳极反应**：$2Cl^- - 2e^- = Cl_2\uparrow$  
3. **阴极反应**：水溶液中 $Na^+$、$Mg^{2+}$ 不放电，$2H_2O + 2e^- = H_2\uparrow + 2OH^-$  
4. **阴极区后续反应**：$Mg^{2+} + 2OH^- = Mg(OH)_2\downarrow$，故阴极附近 pH 升高，产生白色沉淀覆盖管壁，阻碍生物附着。  
5. **阳极区**：$Cl_2 + H_2O = HCl + HClO$，$HClO$ 具有强氧化性，可杀菌。  
6. **总反应**：$Mg^{2+} + 2Cl^- + 2H_2O \xrightarrow{\text{电解}} Mg(OH)_2\downarrow + H_2\uparrow + Cl_2\uparrow$  
7. **选项判断**：D 选项将总反应写成生成 $NaOH$，忽略了海水中 $Mg^{2+}$ 的存在，错误。正确选项为 D。

**点评/变式**  
- 本题核心是阴极还原反应及后续沉淀生成，考查电解基本原理和海水的实际成分。  
- 常见变式：若用铁作阳极，铁会失电子生成 $Fe^{2+}$，阳极反应变为 $Fe - 2e^- = Fe^{2+}$，阴极仍为析氢，产物 $Fe(OH)_2$ 被氧化为 $Fe(OH)_3$，形成絮状物吸附杂质，可用于污水处理（电絮凝法）。  
- 注意：电解水溶液，无论电解质是否参与放电，阴极析出 $H_2$ 的同时必然生成 $OH^-$，使阴极区呈碱性，这是解决电化学与物质转化结合题的关键“题眼”。
