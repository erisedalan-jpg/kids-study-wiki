## 知识精要
- **离子迁移方向判断依据**  
  原电池中，阴离子（如 $\mathrm{Cl}^-$、$\mathrm{SO_4^{2-}}$）向负极移动，阳离子（如 $\mathrm{K}^+$、$\mathrm{Na}^+$）向正极移动。  
  电解池中，阴离子向阳极移动，阳离子向阴极移动。  
  本质原因：带负电的电子从负极流出，负极积累正电荷，吸引电解质中阴离子以维持电荷守恒；正极获得电子，积累负电荷，吸引阳离子。
- **原电池电极反应书写规则**  
  - 负极失电子发生氧化反应，正极得电子发生还原反应。  
  - 电极反应必须匹配电解质环境：  
    - 水溶液中难溶物（如 $\mathrm{AgCl}$）不拆写成离子形式，直接以化学式参与反应。  
    - 碱性环境用 $\mathrm{OH}^-$ 或 $\mathrm{H}_2\mathrm{O}$ 配平，酸性环境用 $\mathrm{H}^+$ 和 $\mathrm{H}_2\mathrm{O}$。  
  - 注意活泼金属在电解质中可能发生的自放电副反应（如 $\mathrm{Mg}$ 在海水中的析氢腐蚀）。
- **离子迁移与电流/电子流动的关系**  
  外电路：电子从负极经导线流向正极。  
  电解质内部：无电子流动，依靠离子的定向迁移形成电流。电流方向全程统一：正电荷移动方向。

## 解题方法与套路
1. **确定正负极**  
   根据总反应或电极材料的活泼性：较活泼金属作负极（失电子），较不活泼物质作正极（得电子）。
2. **书写电极反应式**  
   - 标明氧化态变化（负极：$R \rightarrow R^{n+} + n\mathrm{e}^-$；正极：$Ox + n\mathrm{e}^- \rightarrow Red$）。  
   - 结合电解质中实际存在的物种配平电荷与原子守恒。注意难溶物、弱电解质、配合物的存在形式。
3. **判断离子迁移方向**  
   牢记口诀：“原电池阳正阴负”（阳离子向正极，阴离子向负极）。电解池倒置口诀：“阳氧阴还，离子反向”（阳离子向阴极，阴离子向阳极）。  
   也可从电子得失区正负极后，推知内电路离子迁移以保持电中性。
4. **校验特殊条件**  
   - 水溶液电池中，活泼金属是否直接与水反应产生 $\mathrm{H}_2$？  
   - 是否存在可溶性气体（如 $\mathrm{O}_2$、$\mathrm{Cl}_2$）参与反应？  
   - 给定电池是否为二次电池？确定离子迁移时须分清放电与充电过程。

## 高频易错
- **阴/阳离子迁移方向混淆**  
  误以为阴离子移向正极（被“异性相吸”误导），正确的原电池内部，正极积累电子带负电，吸引阳离子，排斥阴离子；负极带正电，吸引阴离子。
- **电极反应拆分错误**  
  难溶物如 $\mathrm{AgCl}$ 写成 $\mathrm{Ag}^+ + \mathrm{e}^- \rightarrow \mathrm{Ag}$，忽略其以固态形式存在于电极上，应写为 $\mathrm{AgCl} + \mathrm{e}^- \rightarrow \mathrm{Ag} + \mathrm{Cl}^-$。类似地，碱性介质中 $\mathrm{O}_2$ 的还原不可直接生成 $\mathrm{H}^+$。
- **忽略副反应**  
  活泼金属（如 $\mathrm{Mg}$、$\mathrm{Al}$）在酸性或中性海水电解质中会与水发生置换析氢反应，不能随意认为负极只发生电极反应。实际电池放电时可能同时发生腐蚀反应，判断产物或电极消耗量时须注意。
- **熔融盐或固体电解质体系离子迁移差异**  
  在 $\mathrm{Li}$ 离子电池等体系中迁移离子是 $\mathrm{Li}^+$，阴离子不迁移；迁移方向仍为原电池中阳离子向正极，阴离子（若可迁移）向负极。不结合具体情境盲目套用易错。

## 代表题精讲
### **题目**・2016 新课标Ⅱ 第5题  
$\mathrm{Mg–AgCl}$ 电池以海水为电解质溶液，下列说法错误的是（　　）  
A．负极反应：$\mathrm{Mg} - 2\mathrm{e}^- = \mathrm{Mg}^{2+}$  
B．正极反应：$\mathrm{Ag}^+ + \mathrm{e}^- = \mathrm{Ag}$  
C．放电时 $\mathrm{Cl}^-$ 由正极向负极迁移  
D．负极可能发生 $\mathrm{Mg} + 2\mathrm{H}_2\mathrm{O} = \mathrm{Mg(OH)}_2 + \mathrm{H}_2 \uparrow$

**思路**  
先判明正负极材料：$\mathrm{Mg}$ 为活泼金属，作负极；$\mathrm{AgCl}$ 为氧化剂，作正极。书写电极反应必须匹配海水环境。再运用原电池离子迁移规则判断 $\mathrm{Cl}^-$ 移动方向，同时注意 $\mathrm{Mg}$ 与水的化学活性。

**步骤**  
1. 确定电池总反应：$\mathrm{Mg} + 2\mathrm{AgCl} = \mathrm{Mg}^{2+} + 2\mathrm{Ag} + 2\mathrm{Cl}^-$ 。  
2. 分电极式：  
   - 负极：$\mathrm{Mg} - 2\mathrm{e}^- = \mathrm{Mg}^{2+}$（正确，A项无误）。  
   - 正极：$\mathrm{AgCl}$ 得电子被还原为 $\mathrm{Ag}$，释放 $\mathrm{Cl}^-$：$2\mathrm{AgCl} + 2\mathrm{e}^- = 2\mathrm{Ag} + 2\mathrm{Cl}^-$，而非 $\mathrm{Ag}^+ + \mathrm{e}^- = \mathrm{Ag}$（B项错误）。  
3. 迁移方向：原电池内电路中，阴离子向负极迁移。$\mathrm{Cl}^-$ 在正极区产生，为了使电解质保持电中性，$\mathrm{Cl}^-$ 向负极迁移（C项正确）。  
4. 副反应：海水呈弱碱性或近中性，$\mathrm{Mg}$ 活泼性很强，可与水反应生成 $\mathrm{Mg(OH)}_2$ 和 $\mathrm{H}_2$，导致负极腐蚀（D项正确）。  
故错误选项为 B。

**点评/变式**  
本题典型陷阱在于正极反应式的书写，许多考生一见“银”直接写 $\mathrm{Ag}^+$ 还原，忽略材料给出的是难溶氯化银。  
变式训练：将电解质换成熔融 $\mathrm{AgCl}$ 或使用 $\mathrm{Ag}_2\mathrm{O}$ 正极时书写电极式。再结合离子交换膜电池，判断膜允许哪类离子通过及其迁移方向，如通过阴离子交换膜则 $\mathrm{Cl}^-$ 从正极区移向负极区，与本题自然迁移吻合。关键仍在于：**无论何种膜，原电池中阴离子整体趋势是移向负极**。
