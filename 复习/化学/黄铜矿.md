## 知识精要
- 黄铜矿主要成分为 $\mathrm{CuFeS_{2}}$，其中 $\mathrm{Cu}$ 为 $+2$ 价、$\mathrm{Fe}$ 为 $+2$ 价、$\mathrm{S}$ 为 $-2$ 价。
- 火法炼铜核心流程：反射炉熔炼（造锍）→ 转炉吹炼 → 电解精炼。
- 反射炉中关键反应：
  - 黄铜矿与氧气在高温 ($1000\,^{\circ}\mathrm{C}$)下生成 $\mathrm{Cu_{2}S}$、$\mathrm{FeS}$，部分 $\mathrm{FeS}$ 进一步氧化为 $\mathrm{FeO}$。
  - 主要化学方程式：
    $$2\mathrm{CuFeS_{2}}+\mathrm{O_{2}}\xrightarrow{\triangle}\mathrm{Cu_{2}S}+2\mathrm{FeS}+\mathrm{SO_{2}}$$
    $$2\mathrm{FeS}+3\mathrm{O_{2}}\xrightarrow{\triangle}2\mathrm{FeO}+2\mathrm{SO_{2}}$$
  - 石英砂 ($\mathrm{SiO_{2}}$) 作为造渣剂：$\mathrm{FeO+SiO_{2}\xrightarrow{\triangle}FeSiO_{3}}$（形成炉渣除去）。
- 后续吹炼：$\mathrm{Cu_{2}S}$ 被氧化成粗铜：
  $$2\mathrm{Cu_{2}S}+3\mathrm{O_{2}}\xrightarrow{\triangle}2\mathrm{Cu_{2}O}+2\mathrm{SO_{2}}$$
  $$2\mathrm{Cu_{2}O}+\mathrm{Cu_{2}S}\xrightarrow{\triangle}6\mathrm{Cu}+\mathrm{SO_{2}}$$
- 电解精炼：粗铜作阳极，纯铜作阴极，$\mathrm{CuSO_{4}}$-$ \mathrm{H_{2}SO_{4}}$ 溶液作电解液。

## 解题方法与套路
1. **流程题的一般解题步骤**  
   - 明确原料成分与目标产物。  
   - 逐段分析操作（熔炼、造渣、氧化还原等），写出核心反应方程式。  
   - 结合反应原理（氧化还原、化合价变化、造渣反应）推断产物与副产物。  
2. **黄铜矿火法炼铜反应方程式的书写方法**  
   - 先确定中心元素变价：$\mathrm{Cu}$ 从 $+2$ → $+1$（$\mathrm{Cu_{2}S}$），$\mathrm{Fe}$ 从 $+2$ → $+2$（$\mathrm{FeS}$中不变价）或 → $+2$（$\mathrm{FeO}$），$\mathrm{S}$ 从 $-2$ → $+4$（$\mathrm{SO_{2}}$）。  
   - 根据原子守恒和电子守恒配平。高温下 $\mathrm{FeS}$ 可被过量空气氧化为 $\mathrm{FeO}$。  
3. **石英砂作用的分析套路**  
   - 石英砂 $\mathrm{SiO_{2}}$ 是酸性氧化物，能与碱性氧化物 $\mathrm{FeO}$ 反应形成炉渣，符合“酸性除碱性杂质”原理。  
4. **答题模板**  
   - 现象描述：“黑色熔融物”“炉渣分层”等。  
   - 方程式书写：注意反应条件（高温/加热），配平，气体符号。

## 高频易错
- **产物价态判断错误**：直接将 $\mathrm{CuFeS_{2}}$ 中的 $\mathrm{Cu}$ 还原为 $\mathrm{Cu}$ 单质，忽略反射炉中主要得到的是 $\mathrm{Cu_{2}S}$（冰铜），单质铜要在后续转炉中才得到。  
- **氧化顺序错误**：$\mathrm{FeS}$ 比 $\mathrm{Cu_{2}S}$ 更易被氧化，但反射炉中控制氧气量仅使部分 $\mathrm{FeS}$ 转化为 $\mathrm{FeO}$，若氧气过量会使 $\mathrm{Cu_{2}S}$ 也氧化损失。  
- **忽略造渣反应**：未能写出 $\mathrm{FeO+SiO_{2}}$ 的反应，导致对石英砂的作用解释不完整。  
- **配平失误**：$\mathrm{FeS}$ 氧化生成 $\mathrm{FeO}$ 和 $\mathrm{SO_{2}}$ 的方程式容易写错，正确为 $2\mathrm{FeS}+3\mathrm{O_{2}}=2\mathrm{FeO}+2\mathrm{SO_{2}}$，而非 $\mathrm{FeS+O_{2}=FeO+SO_{2}}$（电子得失不守恒）。  
- **混淆流程各阶段**：将反射炉反应和转炉反应混淆，错把粗铜生成提前到反射炉阶段。  
- **热化学语言不规范**：高温反应未写“$\xrightarrow{\triangle}$”或“高温”，条件缺失。

## 代表题精讲
**题目**（2012·新课标·11）  
黄铜矿（主要成分 $\mathrm{CuFeS_{2}}$）炼制精铜的流程，反射炉中将铜精矿砂和石英砂混合加热到 $1000\,^{\circ}\mathrm{C}$ 左右，黄铜矿与空气反应生成 $\mathrm{Cu}$ 和 $\mathrm{Fe}$ 的低价硫化物，且部分 $\mathrm{Fe}$ 的硫化物转变为 $\mathrm{Fe}$ 的低价氧化物。写出该过程中两个主要反应的化学方程式。

**思路**  
由题意，生成低价硫化物即 $\mathrm{Cu_{2}S}$ 和 $\mathrm{FeS}$；低价氧化物即 $\mathrm{FeO}$。需书写 $\mathrm{CuFeS_{2}}$ 与 $\mathrm{O_{2}}$ 反应生成 $\mathrm{Cu_{2}S}$、$\mathrm{FeS}$、$\mathrm{SO_{2}}$ 的方程式，以及 $\mathrm{FeS}$ 氧化为 $\mathrm{FeO}$ 和 $\mathrm{SO_{2}}$ 的方程式。

**步骤**  
1. 确定第一反应的反应物与主要产物：$\mathrm{CuFeS_{2}+O_{2}\to Cu_{2}S+FeS+SO_{2}}$。  
2. 配平：利用化合价升降守恒。$\mathrm{Cu: +2\to +1}$ 降低 $1$，$\mathrm{S}$ 部分由 $-2\to +4$ 升高 $6$。1个 $\mathrm{CuFeS_{2}}$ 含 $2$ 个 $\mathrm{S}$，若生成 $1$ 个 $\mathrm{SO_{2}}$，则升高 $6$；$\mathrm{Cu}$ 降低 $2\times 1=2$，故整体升高 $4$？须调整系数。更简便的原子守恒法：设生成 $x\mathrm{Cu_{2}S}$，$y\mathrm{FeS}$，$z\mathrm{SO_{2}}$。由 $\mathrm{Cu}$ 守恒 $2x=1$ 得 $x=1/2$；由 $\mathrm{Fe}$ 守恒 $y=1$；由 $\mathrm{S}$ 守恒 $y+z=2$，得 $z=1$；再由 $\mathrm{O}$ 守恒得 $\mathrm{O_{2}}$ 系数为 $1/2$。整体乘 $2$ 得整数：$2\mathrm{CuFeS_{2}}+5\mathrm{O_{2}}\to \mathrm{Cu_{2}S}+2\mathrm{FeS}+4\mathrm{SO_{2}}$？等，注意氧原子数量！重新正确推导：假设产物 $\mathrm{Cu_{2}S}$、$\mathrm{FeS}$、$\mathrm{SO_{2}}$，硫源来自 $\mathrm{CuFeS_{2}}$。按 $\mathrm{CuFeS_{2}}=1\ \mathrm{mol}$，有 $1\ \mathrm{mol}\ \mathrm{Cu}$，$1\ \mathrm{mol}\ \mathrm{Fe}$，$2\ \mathrm{mol}\ \mathrm{S}$。生成 $0.5\ \mathrm{mol}\ \mathrm{Cu_{2}S}$ 固定 $1\ \mathrm{mol}\ \mathrm{Cu}$、$0.5\ \mathrm{mol}\ \mathrm{S}$；还剩 $1.5\ \mathrm{mol}\ \mathrm{S}$ 和 $1\ \mathrm{mol}\ \mathrm{Fe}$，其中 $1\ \mathrm{mol}\ \mathrm{S}$ 与 $\mathrm{Fe}$ 生成 $\mathrm{FeS}$，剩余 $0.5\ \mathrm{mol}\ \mathrm{S}$ 生成 $0.5\ \mathrm{mol}\ \mathrm{SO_{2}}$。氧原子需 $0.5\times 2=1\ \mathrm{mol}\ \mathrm{O}$，即 $0.5\ \mathrm{mol}\ \mathrm{O_{2}}$。所以方程式：$1\mathrm{CuFeS_{2}}+0.5\mathrm{O_{2}}\to 0.5\mathrm{Cu_{2}S}+1\mathrm{FeS}+0.5\mathrm{SO_{2}}$，乘 $2$ 得 $2\mathrm{CuFeS_{2}}+\mathrm{O_{2}}\xrightarrow{\triangle}\mathrm{Cu_{2}S}+2\mathrm{FeS}+\mathrm{SO_{2}}$。  
3. 确定第二反应：$\mathrm{FeS}$ 氧化为 $\mathrm{FeO}$ 和 $\mathrm{SO_{2}}$。配平：$2\mathrm{FeS}+3\mathrm{O_{2}}\xrightarrow{\triangle}2\mathrm{FeO}+2\mathrm{SO_{2}}$。  
4. 答案即为上述两个化学方程式。

**点评/变式**  
- 此题考查化工流程中根据信息书写陌生方程式的能力，核心是守恒思想的运用——原子守恒、电子守恒。  
- 变式：若将石英砂的作用一并设问，则需补充造渣反应 $\mathrm{FeO+SiO_{2}\xrightarrow{\triangle}FeSiO_{3}}$；若追问转炉中粗铜的生成，则需书写 $\mathrm{Cu_{2}S}$ 被氧化及后续反应。  
- 强调：反射炉产物为“冰铜” ($\mathrm{Cu_{2}S}{\cdot}\mathrm{FeS}$ 融合物)，而非单质铜，这是区分流程各阶段的关键。
