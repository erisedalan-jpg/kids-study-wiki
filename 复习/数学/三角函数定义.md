## 知识精要
- **任意角三角函数的定义**  
  在平面直角坐标系中，设角 $\theta$ 的终边上任意一点 $P(x,y)$（原点除外），  
  $r = |OP| = \sqrt{x^{2}+y^{2}} > 0$，则  
  $$\sin\theta = \frac{y}{r},\quad \cos\theta = \frac{x}{r},\quad \tan\theta = \frac{y}{x}\;(x\neq0)$$
  注：$\cot\theta = \frac{x}{y}$，$\sec\theta = \frac{r}{x}$，$\csc\theta = \frac{r}{y}$。
- **终边相同的角与象限符号**  
  终边相同的角三角函数值相等（$2k\pi+\theta$，$k\in\mathbb{Z}$）。  
  三角函数在各象限的符号由 $x$、$y$ 的符号决定（记忆口诀：“一全正，二正弦，三正切，四余弦”）。
- **终边落在直线上的处理**  
  终边在直线 $y = kx$ 上时，点 $P$ 可取 $(t, kt)\,(t\neq0)$，此时 $r = |t|\sqrt{1+k^{2}}$，  
  求值时常因平方或比值运算消去参数 $t$ 和绝对值，无需讨论象限。
- **同角基本关系与倍角公式（常结合考查）**  
  $\sin^{2}\theta + \cos^{2}\theta = 1$，$\tan\theta = \dfrac{\sin\theta}{\cos\theta}$。  
  $\cos2\theta = \cos^{2}\theta - \sin^{2}\theta = 2\cos^{2}\theta - 1 = 1 - 2\sin^{2}\theta = \dfrac{1-\tan^{2}\theta}{1+\tan^{2}\theta}$。

## 解题方法与套路
1. **已知终边位置求值**  
   - 在终边上取一易于计算的点 $P(x,y)$（常设 $x$ 为方便值，再算出 $y$），求出 $r = \sqrt{x^{2}+y^{2}}$。  
   - 直接代入定义式得 $\sin\theta,\cos\theta,\tan\theta$ 等，注意讨论符号或利用平方消去符号。
2. **终边在直线上的统一处理**  
   - 设点 $P(t, kt)$，则 $r = |t|\sqrt{1+k^{2}}$。  
   - 若求 $\sin^{2}\theta,\cos^{2}\theta,\cos2\theta$ 等偶次式，可直接代入消去 $t$ 和绝对值；若求一次式且未给 $t$ 符号，通常需分象限讨论。
3. **切化弦或直接代 $\tan\theta$ 求 $\sin2\theta,\cos2\theta$**  
   - 已知 $\tan\theta = k$，可用万能公式：$\cos2\theta = \frac{1-k^{2}}{1+k^{2}}$，$\sin2\theta = \frac{2k}{1+k^{2}}$。  
   - 这类技巧可绕过求 $\sin\theta,\cos\theta$ 的符号烦恼。

## 高频易错
- **忽视终边所在象限**：终边在直线 $y = kx$（$k\neq0$）上占据两个象限，若求 $\sin\theta,\cos\theta$ 等一次式而未指定 $\theta$ 的象限，需分两类讨论取正负。
- **错用 $r$**：$r$ 必须取正数 $\sqrt{x^{2}+y^{2}}$，误写成 $x^{2}+y^{2}$ 或 $|x|$ 导致错误。
- **倍角公式符号错乱**：$\cos2\theta$ 的符号由 $2\theta$ 终边位置决定，不能凭 $\theta$ 的象限草率判断，直接使用 $\frac{1-\tan^{2}\theta}{1+\tan^{2}\theta}$ 可避免此类错误。
- **混淆角的终边与直线**：终边是射线，起点在原点；直线是无限延伸的，要确保取的点在终边（射线）上，而非整条直线。

## 代表题精讲
**题目**（2011·全国新课标理5）  
已知角 $\theta$ 的顶点与原点重合，始边与 $x$ 轴正半轴重合，终边在直线 $y = 2x$ 上，则 $\cos2\theta =$  
A. $-\dfrac{4}{5}$　B. $-\dfrac{3}{5}$　C. $\dfrac{3}{5}$　D. $\dfrac{4}{5}$

**思路**  
终边在直线 $y=2x$ 上，可取终边上一点 $(t,2t)$ 表示三角函数，然后利用倍角公式 $\cos2\theta = \cos^{2}\theta - \sin^{2}\theta$ 或直接由 $\tan\theta = 2$ 用 $\cos2\theta = \frac{1-\tan^{2}\theta}{1+\tan^{2}\theta}$ 求解。由于求的是 $\cos2\theta$，其表达式中含平方或偶次，$t$ 和绝对值均可消去，故不用区分象限。

**步骤**  
**法一（定义法）**  
设终边上一点 $P(t,2t)$（$t \neq 0$），则  
$r = \sqrt{t^{2} + (2t)^{2}} = \sqrt{5t^{2}} = |t|\sqrt{5}$。  
$\cos\theta = \dfrac{x}{r} = \dfrac{t}{|t|\sqrt{5}},\quad \sin\theta = \dfrac{y}{r} = \dfrac{2t}{|t|\sqrt{5}}$。  
$\cos2\theta = \cos^{2}\theta - \sin^{2}\theta = \dfrac{t^{2}}{5t^{2}} - \dfrac{4t^{2}}{5t^{2}} = \dfrac{-3t^{2}}{5t^{2}} = -\dfrac{3}{5}$。  

**法二（$\tan\theta$ 直接公式）**  
$\tan\theta = \dfrac{y}{x} = \dfrac{2t}{t} = 2$。  
$\cos2\theta = \dfrac{1 - \tan^{2}\theta}{1 + \tan^{2}\theta} = \dfrac{1 - 4}{1 + 4} = -\dfrac{3}{5}$。  
故选 B。

**点评与变式**  
- 此题用万能公式最简，免去了定义法中 $|t|$ 的干扰。  
- 若终边在直线 $y = -2x$ 上，同理 $\tan\theta = -2$，则 $\cos2\theta = \dfrac{1 - 4}{1 + 4} = -\dfrac{3}{5}$，结果相同，可见 $\cos2\theta$ 仅与 $\tan^{2}\theta$ 有关。  
- 若问 $\sin2\theta$：当 $\tan\theta=2$ 时，$\sin2\theta = \dfrac{2\tan\theta}{1+\tan^{2}\theta} = \dfrac{4}{5}$；需注意 $\sin2\theta$ 符号由象限决定，若 $\theta$ 在第一象限，$\sin2\theta$ 为正；若在第三象限，$2\theta$ 可能在第一或第二象限，但由公式直接得正数，与平方类似自动保持符号一致性（此处 $\sin2\theta$ 的符号实际依赖于 $\tan\theta$，当 $\tan\theta>0$ 时 $\sin2\theta>0$，无需额外讨论）。
