## 知识精要
1.  **同角三角函数基本关系**：核心平方关系 $\sin^2\alpha + \cos^2\alpha = 1$；商数关系 $\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$（适用条件：$\cos\alpha \neq 0$）。常用于“知一求二”。
2.  **两角和与差公式**：
    -   正弦：$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$
    -   余弦：$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$
    适用条件：$\alpha, \beta$ 为任意角。需熟练逆用，如将 $\sin\alpha\cos\beta + \cos\alpha\sin\beta$ 整体看作 $\sin(\alpha+\beta)$。
3.  **二倍角公式**：
    -   正弦：$\sin 2\alpha = 2\sin\alpha\cos\alpha$
    -   余弦：$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$
    适用条件：$\alpha$ 为任意角。关键在于根据问题结构，灵活选择余弦二倍角公式的三种形式进行升幂或降幂。
4.  **辅助角公式**：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi = \frac{b}{a}$。用于将表达式化为单一正弦函数，从而分析周期、单调性与最值。
5.  **角度范围与符号判断**：三角函数求值必须优先根据给定角所在象限，确定正弦、余弦、正切的符号。这是避免增解、错解的核心前提。

## 解题方法与套路
1.  **第一步：锁定角范围，定符号**。拿到求值题，第一反应不是代公式，而是先明确角所在的象限或区间，据此判定待求三角函数值的正负。这是贯穿所有真题的保分底线。
2.  **第二步：挖掘隐含条件，构方程**。利用题设等式，通过两边平方、与 $\sin^2\alpha+\cos^2\alpha=1$ 联立等方法，构造关于待求值（或其组合）的方程。例如，将 $\sin\alpha+\cos\beta=1$ 类条件两边平方，可产生交叉项，为使用和角公式创造条件。
3.  **第三步：活用公式，整体代换**。对于结构明显且目标的角与已知角有倍数、和差关系的，直接使用公式变形。二倍角公式常用于统一角度或函数名；两角和差公式及其逆用，则用于将“散装”的三角函数组合包装成整体，简化运算。
4.  **第四步：模型化与验证**。求单调区间、最值等问题，先用辅助角公式化为 $y=A\sin(\omega x+\varphi)+k$ 的标准模型。求解后，务必将答案（如参数 $a$ 的取值范围）与第一步中确定的范围综合取交集，完成最终验证。

## 高频易错
-   **忽略符号判定**：看到 $\sin^2\alpha$ 开方得到 $\sin\alpha$ 时，忘记由 $\alpha$ 所在象限判定正负，导致答案多解或错选符号。如 $\alpha \in (0,\frac{\pi}{2})$，则 $\sin\alpha>0, \cos\alpha>0$ 是硬性约束。
-   **平方运算产生增根**：对等式两边平方是构造方程利器，但会引入原式不满足的增根。平方后求出的结果，必须代回已知条件（特别是含有正负关系的条件，如 $\cos\alpha+\sin\beta=0$）进行检验。
-   **公式应用机械，混淆条件**：使用二倍角公式时，不注意所求角与已知角倍数关系的对应。例如，由 $2\sin 2\alpha$ 化简时，错误地写成 $2(2\sin\alpha\cos\alpha)$。辅助角公式中，把 $\varphi$ 所在象限记错，导致单调区间求反。
-   **定义域遗忘**：求单调区间、最值时，只套用标准正弦函数的性质，而忘记题目中给定的 $x$ 或 $a$ 的原始范围，导致最终区间取值放大或缩小。

## 代表题精讲
**题目**（2019-理-10）：已知 $\alpha \in (0,\frac{\pi}{2})$，$2\sin 2\alpha = \cos 2\alpha + 1$，求 $\sin\alpha$ 的值。
-   **思路**：目标是 $\sin\alpha$，已知条件同时含 $\sin 2\alpha$ 和 $\cos 2\alpha$，首先用二倍角公式统一为 $\alpha$ 的正余弦，再利用 $\alpha$ 范围确定符号，最后联立 $\sin^2\alpha+\cos^2\alpha=1$ 求解。
-   **步骤**：
    1.  二倍角公式展开：$2(2\sin\alpha\cos\alpha) = (1-2\sin^2\alpha) + 1$，即 $4\sin\alpha\cos\alpha = 2 - 2\sin^2\alpha$。
    2.  由 $\alpha \in (0,\frac{\pi}{2})$ 知 $\cos\alpha>0$，但我们不解 $\cos\alpha$，而是将上式化为 $4\sin\alpha\cos\alpha = 2(1-\sin^2\alpha) = 2\cos^2\alpha$。
    3.  两边约去 $2\cos\alpha$（$\cos\alpha>0$，安全），得 $2\sin\alpha = \cos\alpha$。
    4.  将 $\cos\alpha = 2\sin\alpha$ 代入 $\sin^2\alpha+\cos^2\alpha=1$，得 $\sin^2\alpha + (2\sin\alpha)^2 = 5\sin^2\alpha = 1$。
    5.  解得 $\sin\alpha = \frac{\sqrt{5}}{5}$（因 $\alpha$ 在第一象限，舍去负值）。
-   **点评/变式**：本题核心是余弦二倍角“三选一”的灵活性，选择 $1-2\sin^2\alpha$ 能直接产生 $\cos^2\alpha$，为约分创造条件。若错用 $\cos2\alpha=2\cos^2\alpha-1$ 会得到不同路径，但最终均需利用平方关系。变式训练：条件改为 $\alpha \in (-\frac{\pi}{2},0)$，求 $\tan\alpha$。

**题目**（2018-文-10）：若 $f(x)=\cos x-\sin x$ 在 $[0,a]$ 上是减函数，求 $a$ 的最大值。
-   **思路**：研究三角函数单调性，第一步先用辅助角公式化简，转化为标准正弦或余弦模型。然后求出该函数的所有单调递减区间，最后再与给定区间 $[0,a]$ 匹配，求 $a$ 的界限。
-   **步骤**：
    1.  辅助角化简：$f(x)=\cos x-\sin x = -\sin x + \cos x = -\sqrt{2}\sin(x - \frac{\pi}{4})$。
    2.  求 $f(x)$ 减区间等价于求 $g(x)=\sin(x-\frac{\pi}{4})$ 的增区间（因为前面有负号）。
    3.  令 $-\frac{\pi}{2}+2k\pi \le x-\frac{\pi}{4} \le \frac{\pi}{2}+2k\pi, k\in Z$，解得 $-\frac{\pi}{4}+2k\pi \le x \le \frac{3\pi}{4}+2k\pi$。
    4.  取 $k=0$，得一个包含原点的减区间 $[-\frac{\pi}{4}, \frac{3\pi}{4}]$。
    5.  已知 $f(x)$ 在 $[0,a]$ 上递减，则 $[0,a]$ 必须是上述区间的子区间，故 $a \le \frac{3\pi}{4}$。$a$ 的最大值为 $\frac{3\pi}{4}$。
-   **点评/变式**：符号是易错点。$f(x)$ 前有负号，求单调性时要反转。最终答案必须结合题目给定的下限 $x\ge0$，不可直接写出单个区间的端点。变式：改为求 $f(x)$ 在 $[0, \pi]$ 上的减区间。

**题目**（2018-理-15）：已知 $\sin\alpha+\cos\beta=1$，$\cos\alpha+\sin\beta=0$，求 $\sin(\alpha+\beta)$。
-   **思路**：目标是整体 $\sin(\alpha+\beta)$，其展开式为 $\sin\alpha\cos\beta+\cos\alpha\sin\beta$。观察已知两式，将其两边平方，产生的交叉项恰好就是目标展开式，相加即可求解。
-   **步骤**：
    1.  $①$ 式平方：$(\sin\alpha+\cos\beta)^2 = \sin^2\alpha + 2\sin\alpha\cos\beta + \cos^2\beta = 1$。
    2.  $②$ 式平方：$(\cos\alpha+\sin\beta)^2 = \cos^2\alpha + 2\cos\alpha\sin\beta + \sin^2\beta = 0$。
    3.  $①+②$ 得：$(\sin^2\alpha+\cos^2\alpha) + (\sin^2\beta+\cos^2\beta) + 2(\sin\alpha\cos\beta+\cos\alpha\sin\beta) = 1$。
    4.  利用同角关系及和角公式得：$1 + 1 + 2\sin(\alpha+\beta) = 1$。
    5.  整理得 $2\sin(\alpha+\beta) = -1$，故 $\sin(\alpha+\beta) = -\frac{1}{2}$。
-   **点评/变式**：本题巧用“平方和”技巧构造出积化和差结构，避免了分别求 $\alpha, \beta$ 的复杂过程。这是处理“对称式”条件求整体值的经典方法。注意，此处因无需单独求角，故未用到 $\sin\beta, \cos\alpha$ 等值的逐个符号判断，直接消元得出整体值，是应试的高阶视角。
