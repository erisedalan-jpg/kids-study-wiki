## 知识精要
- **三角形中位线定理**：连接三角形两边中点的线段叫做三角形的中位线。三角形的中位线平行于第三边，且等于第三边的一半。
  - 如图 $D,E$ 分别为 $\triangle ABC$ 边 $AB,AC$ 的中点 $\implies DE \parallel BC$ 且 $DE = \frac{1}{2}BC$。
  - 常用于证明平行关系、线段倍分关系，是构造平行四边形的基础。
- **平行四边形的判定与性质**（核心工具）：
  - 判定：一组对边平行且相等 $\iff$ 平行四边形；两组对边分别平行 $\iff$ 平行四边形。
  - 性质：对边平行且相等，对角相等，对角线互相平分。
- **圆中相关定理**（外接圆背景）：
  - 同圆或等圆中，相等的圆周角所对的弧相等，相等的弧所对的弦相等。
  - 平行弦所夹的弧相等：若弦 $CF \parallel AB$，则 $\widehat{AF}=\widehat{BC}$，从而 $AF=BC$。
  - 圆周角定理：同弧所对的圆周角相等。
- **相似三角形的判定**：
  - 两角对应相等的两个三角形相似（AA）。
  - 常用于圆中通过弧找等角。

## 解题方法与套路
1. **捕捉中点，连出中位线**：看到三角形两边中点，立即连接得到中位线，得出 $DE \parallel BC$ 及 $AD=DB$ 等结论。
2. **利用平行条件构造平行四边形**：题设中出现 $CF \parallel AB$，结合中位线得到的平行，可推出四边形 $BDFC$ 为平行四边形（两组对边分别平行）。由此转化边的关系：$CF \parallel BD$ 且 $CF=BD$，结合 $D$ 为中点得 $CF \parallel AD$ 且 $CF=AD$，进一步得 $ADCF$ 为平行四边形。
3. **借助圆的性质将边等转化为弧等**：由平行四边形性质得 $AF=CD$，欲证 $CD=BC$，只需证 $AF=BC$。在圆中，由平行弦 $CF \parallel AB$ 可得 $\widehat{AF}=\widehat{BC}$，从而 $AF=BC$，传递得证。
4. **证相似“先找角后找边”**：在圆背景下优先找相等角。
   - 等弧对等角：由 $\widehat{AF}=\widehat{BC}$ 得 $\angle BDC = \angle GBD$（或精确定位对应角）。
   - 平行线内错角/同位角：结合中位线平行、平行四边形对边平行转化角相等。
   - 使用公共角：如 $\angle DBC$ 为公共角或相等角。
   - 由两组角等判定 $\triangle BCD \sim \triangle GBD$。

## 高频易错
- **误用中位线定理**：只写了 $D,E$ 是中点，却忘了明确“在 $\triangle ABC$ 中”，导致结论无据。注意中位线定理必须在同一三角形中使用。
- **平行四边形判定条件混淆**：证明 $BDFC$ 是平行四边形时，需明确“$DF \parallel BC$（中位线），$CF \parallel AB$（已知）”，两组对边分别平行，不能单凭感觉。
- **圆中角对应混乱**：证明相似时找角易出错。必须严格从等弧 $\widehat{AF}=\widehat{BC}$ 出发，看清弧所对的圆周角是哪些，如 $\angle BDC$ 对 $\widehat{BC}$，$\angle GBD$ 对 $\widehat{GD}$？需仔细标图，避免误把弦切角或非对应角当作相等。
- **忽视三点共线或平行带来的“隐藏中点”**：$D$ 是 $AB$ 中点，证得 $CF \parallel AD$ 且 $CF=AD$ 才得 $\square ADCF$ 为平行四边形，缺一不可。尤其要证明 $CF=BD$ 后再用 $BD=AD$ 传递。
- **证明相似时直接写对应边成比例**：在圆中往往先找角等更简便，直接用比例会陷入复杂计算或需引入其他定理，增加失分风险。

## 代表题精讲
**题目** （2012年全国卷文22/理22，10分）  
如图，$D,E$ 分别为 $\triangle ABC$ 边 $AB,AC$ 的中点，直线 $DE$ 交 $\triangle ABC$ 的外接圆于 $F,G$ 两点，$CF \parallel AB$。证明：（1）$CD=BC$；（2）$\triangle BCD \sim \triangle GBD$。

> 注：文科与理科题目完全相同，以下合并讲解。

**思路**  
（1）看到中点立即用中位线得 $DF \parallel BC$。由 $CF \parallel AB$ 构造平行四边形 $BDFC$，得 $CF=BD$，再用 $D$ 是中点推出 $CF=AD$，结合 $CF \parallel AD$ 得 $\square ADCF$ 为平行四边形，从而 $AF=CD$。在圆中由 $CF \parallel AB$ 得 $\widehat{AF}=\widehat{BC}$，弦 $AF=BC$，等量代换即得 $CD=BC$。  
（2）由（1）的结论和圆的性质挖掘角等：$\widehat{BC}=\widehat{AF}$ 得 $\angle BDC=\angle GBF$？需结合图形找准 $\triangle BCD$ 与 $\triangle GBD$ 的对应角。可证 $\angle BCD = \angle GBD$ 和 $\angle DBC = \angle DGB$，用 AA 判定相似。

**步骤**  
**(1) 证明 $CD=BC$**  
- $\because D,E$ 分别为 $AB,AC$ 中点，$\therefore DE \parallel BC$，即 $DF \parallel BC$。  
- 又 $\because CF \parallel AB$，$\therefore$ 四边形 $BDFC$ 为平行四边形（两组对边分别平行）。  
- $\therefore CF = BD$，且 $CF \parallel BD$。  
- $\because D$ 为 $AB$ 中点，$\therefore AD = BD$。  
- $\therefore CF = AD$，且 $CF \parallel AD$，$\therefore$ 四边形 $ADCF$ 为平行四边形。  
- $\therefore AF = CD$。  
- 在圆中，$\because CF \parallel AB$，$\therefore \widehat{AF} = \widehat{BC}$（平行弦所夹弧相等）。  
- $\therefore AF = BC$。  
- 从而 $CD = BC$。  

**(2) 证明 $\triangle BCD \sim \triangle GBD$**  
- 由 (1) 知 $\widehat{AF} = \widehat{BC}$，$\therefore \angle BDF = \angle BGF$？需精确匹配：观察 $\triangle BCD$ 和 $\triangle GBD$ 的公共边 $BD$。  
- $\because \widehat{AF} = \widehat{BC}$，$\therefore \angle BDC = \angle GBF$（等弧所对圆周角），也就是 $\angle BDC = \angle GBD$。  
- 又 $\because DF \parallel BC$，$\therefore \angle FDB = \angle DBC$。而 $\angle FDB$ 与 $\angle FGB$ 同对 $\widehat{FB}$，$\therefore \angle FDB = \angle FGB$，即 $\angle DBC = \angle DGB$。  
- 在 $\triangle BCD$ 与 $\triangle GBD$ 中，  
  $\angle BDC = \angle GBD$，  
  $\angle DBC = \angle DGB$，  
  $\therefore \triangle BCD \sim \triangle GBD$（AA）。

**点评/变式**  
- 本题的核心链：中点→中位线→平行四边形→边等；平行弦→等弧→等弦；等弦/等弧→等角→相似。是三角形、四边形、圆三大模块的综合应用。  
- 证明相似时，务必明确每一组等角来自哪个定理。常见误写：把 $\angle BDC$ 和 $\angle GBD$ 的位置对应错。画图时可将两个三角形用不同颜色标出，避免对错边角。  
- **变式训练**：若题中 $CF \parallel AB$ 改为 $CF$ 平分 $\angle ACB$，其他条件不变，求证 $CD$ 仍是 $\triangle ABC$ 外接圆的切线（或其他结论）。可强化圆幂与平行的结合。  
- **考场策略**：第（1）问的边等常为第（2）问相似提供等边带来的等角，所以（1）的结论要善用。证明书写要条理清晰，每一步标注定理依据，可减少非智力失分。
