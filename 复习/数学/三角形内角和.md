## 知识精要

**三角形内角和定理**  
在 $\triangle ABC$ 中，有  
$$A+B+C=\pi$$  
由此可得常用变形：  
- $C = \pi - (A+B)$，$\dfrac{A+B}{2} = \dfrac{\pi}{2} - \dfrac{C}{2}$  
- $\sin C = \sin(A+B)$，$\cos C = -\cos(A+B)$，$\sin\dfrac{C}{2} = \cos\dfrac{A+B}{2}$

**正弦定理（解三角形的边角互化工具）**  
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$  
可实现边化角（$a=2R\sin A$ 等）或角化边（$\sin A = \frac{a}{2R}$ 等），用于条件等式向单一类型转化。

**余弦定理（边角互化与方程工具）**  
$$a^2 = b^2 + c^2 - 2bc\cos A$$  
其变形 $\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$ 常用于将角的余弦转化为边的关系。

**两角差的正弦公式（恒等变换基础）**  
$$\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$$  
在交叉结构 $\sin C\sin(A-B)$ 等式中，展开后可与正弦、余弦定理联动。

## 解题方法与套路

1. **利用内角和消元或产生关系**  
   当条件中含多个角时，先用 $C = \pi - (A+B)$ 消去一个角，或利用诱导公式将不同角的正余弦统一到较少的内角上，降低未知数个数。

2. **条件等式的结构识别与展开**  
   遇到 $\sin X \sin(Y-Z)$ 型结构，优先用两角差的正弦公式展开，使角度分离，为边角互化做准备。

3. **边角互化的时机选择**  
   - 若目标是求角，优先“化边为角”，用正弦定理将边表示成角的正弦，结合三角恒等变换求解。  
   - 若目标是证明边的关系（如 $2a^2 = b^2 + c^2$），则在得到 $\cos A$、$\cos B$ 等表达式后，直接代入余弦定理，将角的余弦转化为边。

4. **利用角的范围排除增解**  
   由内角和及题设限定各角的区间（多为 $(0,\pi)$），结合三角函数值相等推角的关系时，需注意：  
   - 若 $\sin\alpha = \sin\beta$ 且 $\alpha,\beta \in (0,\pi)$，则 $\alpha = \beta$ 或 $\alpha + \beta = \pi$；  
   - 再结合内角和等条件舍去矛盾情形。

## 高频易错

- **错误使用诱导公式符号**  
  如误写 $\sin C = \sin(A+B)$ 的符号，或 $\cos(\pi - \alpha) = -\cos\alpha$ 遗漏负号，导致后续推导全反。

- **展开 $\sin X\sin(Y-Z)$ 时漏乘或符号混乱**  
  $\sin(X)\sin(Y-Z) = \sin X(\sin Y\cos Z - \cos Y\sin Z)$，易错为 $\sin X\sin Y - \sin X\sin Z$ 或漏掉 $\cos$ 因子。

- **由 $\sin\alpha = \sin\beta$ 推角关系漏掉互补情形**  
  在 $(0,\pi)$ 内，$\sin\alpha = \sin\beta$ 除了 $\alpha = \beta$，还有 $\alpha = \pi - \beta$，仅靠“显然不相等”缺少严谨推理会扣分，需结合已知条件或取值范围明确排除。

- **正弦定理化边为角时遗漏公因子 $2R$**  
  将 $a\cos B$ 等混合形式化角时，$a = 2R\sin A$，代换后 $2R$ 通常会被约去，但若计算过程中将其误作 $a = \sin A$ 直接代入，会导致比例错误。

- **余弦定理代入后化简粗心**  
  交叉项 $-\frac12(a^2+c^2-b^2)$ 等系数和符号极易写错，建议明确写出 $\cos A = \frac{b^2+c^2-a^2}{2bc}$ 再逐项代入，等式两边系数化整再化简。

## 代表题精讲

### 代表题1：2022-文-17 **(1)**

**题目**  
在 $\triangle ABC$ 中，内角 $A,B,C$ 对边为 $a,b,c$，已知  
$$\sin C \sin(A-B) = \sin B \sin(C-A)$$  
若 $A = 2B$，求 $C$。

**思路**  
将 $A=2B$ 代入已知等式，用内角和表示出所有角的关系，借助 $\sin$ 值相等及角度范围确定 $C$。

**步骤**  
1. 将 $A=2B$ 代入等式：  
   $\sin C \sin(2B-B) = \sin B \sin(C-2B)$  
   即 $\sin C \sin B = \sin B \sin(C-2B)$。  
2. 因为 $0<B<\pi$，$\sin B \neq 0$，两边同除 $\sin B$ 得：  
   $\sin C = \sin(C-2B)$。  
3. $0<C<\pi$，且 $C-2B = C-A$，范围也在 $(0,\pi)$。由 $\sin \alpha = \sin \beta$ 得：  
   (i) $C = C-2B$（不可能，否则 $B=0$）；  
   (ii) $C + (C-2B) = \pi$，即 $2C - 2B = \pi$，得 $C = B + \frac{\pi}{2}$。  
4. 结合 $A=2B$ 与 $A+B+C=\pi$ 消元：  
   $2B + B + \left(B+\frac{\pi}{2}\right) = \pi$  
   $\Rightarrow 4B = \frac{\pi}{2} \Rightarrow B = \frac{\pi}{8}$。  
5. 于是 $C = B + \frac{\pi}{2} = \frac{\pi}{8}+\frac{\pi}{2} = \frac{5\pi}{8}$。

**点评/变式**  
充分体现了三角形内角和与诱导关系的联合应用。若改为求 $A$ 或 $B$，思路相同；若将“$A=2B$”换为“$A,B$ 等差”，则需设 $B = A-d, C = A+d$ 再用内角和。

### 代表题1：2022-文-17 **(2)**

**题目**  
在上述三角形中，条件同 (1)，证明：$2a^2 = b^2 + c^2$。

**思路**  
将条件等式两边展开（两角差正弦），化出含 $\cos$ 的边角混合结构，再利用正弦定理、余弦定理转化为纯边的关系并化简。

**步骤**  
1. 展开条件：  
   $\sin C (\sin A\cos B - \cos A\sin B) = \sin B (\sin C\cos A - \cos C\sin A)$  
   整理得：  
   $\sin C\sin A\cos B - \sin C\cos A\sin B = \sin B\sin C\cos A - \sin B\cos C\sin A$  
2. 移项合并（将含 $\cos A$ 项移到一边）：  
   $\sin C\sin A\cos B = \sin C\cos A\sin B + \sin B\sin C\cos A - \sin B\cos C\sin A$  
   注意到右端有两项 $\sin B\sin C\cos A$，即 $2\sin B\sin C\cos A$，于是：  
   $\sin C\sin A\cos B = 2\sin B\sin C\cos A - \sin B\cos C\sin A$  
3. 用正弦定理将所有正弦代换成边（约去 $2R$）：  
   $\sin A \to a$，$\sin B \to b$，$\sin C \to c$，得：  
   $c \cdot a \cdot \cos B = 2 b \cdot c \cdot \cos A - b \cdot \cos C \cdot a$  
4. 两边同除以 $abc$（非零），得：  
   $\frac{\cos B}{b} = \frac{2\cos A}{a} - \frac{\cos C}{c}$  
5. 代入余弦定理：  
   $\cos B = \frac{a^2+c^2-b^2}{2ac}$，$\cos A = \frac{b^2+c^2-a^2}{2bc}$，$\cos C = \frac{a^2+b^2-c^2}{2ab}$  
6. 分别代入，化简：  
   $\frac{1}{b}\cdot\frac{a^2+c^2-b^2}{2ac} = \frac{2}{a}\cdot\frac{b^2+c^2-a^2}{2bc} - \frac{1}{c}\cdot\frac{a^2+b^2-c^2}{2ab}$  
   通分化简（乘 $2abc$）可得：  
   $a(a^2+c^2-b^2) = 2c(b^2+c^2-a^2) - b(a^2+b^2-c^2)$  
   展开并整理同类项，最终化简为 $2a^2 = b^2 + c^2$。

**点评/变式**  
本题核心是“边角互化+余弦定理代入”的经典路径。注意移项合并时避免丢失因子，尤其是 $\sin B\sin C\cos A$ 出现两次需合并。若条件变为积化和差形式，也可同样展开处理。
