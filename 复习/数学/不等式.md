## 知识精要
不等式是高考数学的核心考点，主要考查不等式的性质、证明、解法及综合应用。

- **不等式的基本性质**：对称性、传递性、可加性、可乘性（注意符号）、同向可加性、同向正数可乘性、乘方与开方性质。
- **常见不等式模型**：
    - 一元二次不等式：$ax^2+bx+c>0(<0)$ 的解集依赖判别式 $\Delta$ 和开口方向。
    - 绝对值不等式：$|f(x)|<a \Leftrightarrow -a<f(x)<a$；$|f(x)|>a \Leftrightarrow f(x)<-a$ 或 $f(x)>a$（$a>0$）。
    - 高次不等式与分式不等式：数轴穿根法，注意奇穿偶不穿、分母不为零。
    - 指数与对数不等式：化为同底函数，利用单调性（当 $a>1$ 时单调增；$0<a<1$ 时单调减），务必注意定义域（真数 $>0$）。
- **线性规划**：求目标函数 $z=ax+by$ 在可行域（线性约束条件围成）内的最值。通常在可行域顶点处取得最值。
- **不等式证明常用方法**：
    - **比较法**：作差法（与0比）、作商法（与1比，要求正数）。
    - **综合法**：由因导果，利用基本不等式 $a+b \ge 2\sqrt{ab} (a,b>0)$ 等。
    - **分析法**：执果索因，寻找成立的充分条件。
    - **构造函数法**：通过求导研究函数单调性证明不等式。这是压轴题核心方法。例如证明 $x > \sin x$ ($x>0$)，可构造函数 $F(x)=x-\sin x$。
- **含参不等式恒成立/存在性问题**：
    - **分离参数法**：$a \ge f(x)$ 恒成立 $\Leftrightarrow$ $a \ge f(x)_{max}$；$a \le f(x)$ 恒成立 $\Leftrightarrow$ $a \le f(x)_{min}$。
    - **分类讨论法**：对参数进行讨论，结合函数单调性、极值/最值求解。

## 解题方法与套路
跨真题归纳通用解法步骤：

1.  **不等式解集的求解步骤**：
    - 标准化：化为右侧为0的形式（如 $f(x)>0$）。
    - 因式分解：将左侧分解为一次因式或不可约二次因式的乘积。
    - 求根：令各因式为0，求出所有根。
    - 数轴穿根：在数轴上标出根，从右上角开始，依次穿过各根（重根按奇偶处理）。
    - 检验端点和分母：注意区间开闭。

2.  **线性规划求目标函数最值步骤**：
    - 设出约束条件并画出可行域（确定各直线）。
    - 改写目标函数为斜截式：$y = \frac{a}{b}x - \frac{z}{b}$。
    - 平移直线：寻找使直线在 $y$ 轴截距取得最大或最小的可行域顶点。
    - 代入顶点坐标计算目标函数值，比较得出最值。

3.  **构造函数法证明不等式（用导数）步骤**：
    - 移项构造：将要证不等式化为 $F(x)>0$ 或 $F(x)<0$ 的形式。
    - 求导分析：求 $F'(x)$，判断 $F(x)$ 在给定区间上的单调性。
    - 端点效应：计算区间端点处的函数值（或极限），结合单调性完成证明。
    - 若一次函数无法判断，可进行二阶求导或分离参数后再构造函数。

4.  **比较实数大小的步骤**：
    - 若底数或形式涉及函数，可考虑构造函数，利用单调性比较。
    - 若数值特征明显，可采用“0,1二分法”或特殊值法（注意适用范围）。
    - 对数比较：同底用单调性；同真数可利用图像或换底公式；既不同底也不同真数常找中间值0或1。

## 高频易错
真题暴露的典型陷阱与失分点：

- **忽视定义域与限制条件**：在解对数不等式、分式不等式时，必须先满足真数>0、分母≠0。在进行不等式乘法时，忽略乘数的正负号。
- **分类讨论不完整**：含参数的二次不等式、指数对数不等式，当底数含参时未对参数范围进行分类讨论导致漏解。极大值、极小值点问题，对参数划分区间不严密。
- **构造函数法求导失误**：复合函数求导法则不熟，导致导函数错误，最终无法判断单调性。
- **线性规划可行域与目标函数斜率判断错误**：未将目标函数化为斜截式，凭感觉判断截距导致结果相反。忽视边界虚实（取等条件）。
- **不等式性质误用**：随意使用“同向不等式相减、相除”。忽略了均值不等式等号成立的条件（“一正、二定、三相等”）。
- **穿根法的奇偶混淆**：偶次重根处错误地“穿过去”，导致解集区间错误。

## 代表题精讲

**题目**：（2023·新课标Ⅱ·22）
（1）证明：当 $0<x<1$ 时， $x-x^2 < \sin x < x$；
（2）已知函数 $f(x)=\cos x - \ln(1-ax^2)$，若 $x=0$ 是 $f(x)$ 的极大值点，求 $a$ 的取值范围。
- **思路**：
    （1）构造两个函数 $F(x)=x-\sin x$ 与 $G(x)=\sin x - x + x^2$，利用导数求其单调性，由 $F(x)>0$ 且 $G(x)>0$，证得双不等式。
    （2）$f(x)$ 为偶函数，故只需在 $x>0$ 时讨论。对 $f(x)$ 求导后，利用（1）的结论进行放缩，转化为二次函数类问题，并取不同 $a$ 的极值情况分析，确定使 $x=0$ 成为极大值点（即先增后减）的 $a$ 的范围。
- **步骤**：
    （1）设 $F(x)=x-\sin x$，$x\in (0,1)$。则 $F'(x)=1-\cos x$。因 $0<x<1$，$\cos x <1$，故 $F'(x)>0$，$F(x)$ 在 $(0,1)$ 递增。所以 $F(x)>F(0)=0$，即 $x>\sin x$。再设 $G(x)=\sin x - x + x^2$，$x\in (0,1)$。$G'(x)=\cos x -1 +2x$。设 $H(x)=G'(x)$，则 $H'(x)=-\sin x +2>0$，$G'(x)$ 递增，$G'(x)>G'(0)=0$。故 $G(x)$ 递增，$G(x)>G(0)=0$，即 $\sin x > x-x^2$。综上，$x-x^2 < \sin x < x$ 成立。
    （2）易见 $f(x)$ 定义域由 $1-ax^2>0$ 决定，且为偶函数。只需考虑 $x\ge 0$ 情况。$f'(x)=-\sin x + \frac{2ax}{1-ax^2} = -x + x + \dots$。
    期望 $x=0$ 为极大值点，应在 $x=0$ 右边附近 $f'(x)<0$。由（1）知 $-\sin x > -x$。
    故 $f'(x) > -x + \frac{2ax}{1-ax^2} = x(\frac{2a}{1-ax^2} -1)$。
    令 $g(x)=\frac{2a}{1-ax^2} -1$。当 $a \le 2$ 时，存在某右侧区间使 $f'(x)>0$，$f(x)$ 递增，不是极大值；当 $a>2$ 时，在0右侧 $f'(x)<0$，递减，符合 $x=0$ 是极大值点。由对称性及偶函数可知，$a$ 的取值范围是 $(2, +\infty)$。
- **点评/变式**：
    本题是函数、不等式与导数综合的压轴题。标准套路是利用导数研究函数性质证明不等式，并以此为“引理”解决更复杂的参数范围问题，即“先探路后证明”或“放缩法”。解题的关键在于第一问的结论是第二问的阶梯，这种“搭桥铺路”式的命题模式非常经典。考生务必掌握构造函数和利用已知不等式进行有效放缩的技巧。变式训练：尝试证明 $(0<x<1)$ 时 $\frac{2x}{2+x} < \ln(1+x) < \frac{x}{\sqrt{1+x}}$，并以此求解相关问题。

**题目**：（2018·文·23）
设函数 $f(x)=5-|x+a|-|x-2|$。
（题目虽不完整，但保留核心考点：绝对值函数的化简与最值。补充完整：求 $f(x)$ 的最大值。）
- **思路**：直接利用绝对值的三角不等式性质 $|a|+|b| \ge |a \pm b|$ 处理，或采用“零点分段法”去绝对值化为分段函数，再结合图像求最大值。
- **步骤**：
    法一（不等式性质）：
    $f(x) = 5 - (|x+a|+|x-2|)$。
    由 $|x+a|+|x-2| \ge |(x+a)-(x-2)| = |a+2|$，
    当且仅当 $(x+a)(x-2) \le 0$ 时取等。
    故 $f(x) \le 5 - |a+2|$，最大值为 $5-|a+2|$。
    法二（零点分段法）：
    零点为 $x=-a$ 和 $x=2$。
    当 $-a<2$ 时，分段讨论并画出图像，发现最大值在 $[-a,2]$ 区间取得，为常数 $5-|-a-2|$。
    同理当 $-a \ge 2$ 时，最大值在 $[2,-a]$ 取得，为常数。
    综合可得最大值为 $5-|a+2|$。
- **点评/变式**：
    处理含多个绝对值的函数，首选绝对值的三角不等式 $|a|+|b| \ge |a \pm b|$，可实现快速求解最值，但必须确认取等条件的自变量的存在性。零点分段法是通法，任何绝对值问题都可转化为分段函数解决，但计算相对繁杂。本题作为选考题，体现了不等式工具在函数最值问题中的强大威力。升级题设：若 $f(x) \ge 2$ 的解集为 $\emptyset$，求 $a$ 的范围，同样可用此性质转化为参数的不等式。
