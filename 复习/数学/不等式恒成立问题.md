## 知识精要
- **恒成立问题本质**：寻求参数范围，使得某不等式在指定区间上“永远成立”。
- **常用转化方向**：
  - 直接构造含参函数 $g(x)$，转化为求 $g(x)$ 的最值，令 $g(x)_{\min} > 0$（或 $g(x)_{\max} < 0$）。
  - 分离参数：若可化为 $a > h(x)$ 恒成立，则 $a > h(x)_{\max}$；若 $a < h(x)$ 恒成立，则 $a < h(x)_{\min}$。
- **导数工具的必用条件**：
  - 函数在给定区间上可导。
  - 利用导数研究单调性、极值与最值。
- **端点效应与临界点**：当不等式在区间端点处取等号（如本题 $f(1)=0$），往往可推出参数的必要条件，进而结合单调性讨论充分性。
- **隐零点与设而不求**：当导函数的零点不可解时，可设零点 $x_0$，利用 $g'(x_0)=0$ 消去参数或超越项，完成最值估算。
- **洛必达法则的辅助**：分离参数后若求 $h(x)$ 的极限为 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 型，可借助洛必达法则求极限值，作为参数范围的临界值（解答中需用“由洛必达法则可得”并指明条件满足）。

## 解题方法与套路
1. **定义域先行**：涉及对数 $\ln x$ 时，定义域为 $(0,+\infty)$，复合函数要注意内层定义域。所有讨论必须在定义域内进行。
2. **构造函数并求导**：
   - 若是含参讨论型，直接令 $F(x,\!a)$，求 $F'(x)$，整理成可分析符号的形式。
   - 若分离参数型，变形为 $a > (\text{或} <) h(x)$，对 $h(x)$ 求导研究其单调性与最值（或上/下确界）。
3. **讨论核心点**：
   - 找出使导数为零的驻点（可能含参数），分情况讨论该点是否在区间内。
   - 若导函数符号不易判断，可进行二阶求导或局部因式分解。
   - 注意临界情形：区间端点函数值、导数值、极值点的函数极限。
4. **端点优先检查**：当 $x \to a^+$ 或 $x \to +\infty$ 时，检查函数值是否满足不等式的“取等”条件，这常给出参数的必要范围。
5. **重述结论**：根据最值与参数关系，写出参数的最终取值范围（用区间或集合表示），并确认等号能否取得。

## 高频易错
- **忽略定义域**：直接对 $\ln x$ 求导而未强调 $x>0$，或在区间 $(1,+\infty)$ 上讨论时，错写为 $[1,+\infty)$。
- **端点 $f(1)=0$ 的误用**：
  - 已知 $f(1)=0$，要使 $x>1$ 时 $f(x)>0$，不能直接等价于 $f'(x)>0$（仅是充分非必要条件，还需考虑导数变号）。
  - 易漏掉 $f'(1)$ 必须非负的必要条件：由 $f(x)>0=f(1)$，若 $f'(1)<0$，则在 $1$ 右侧附近函数值会小于 $0$，导致矛盾。这一“端点效应”是缩小讨论范围的关键。
- **参数分离时不讨论分母符号**：变形 $a < \frac{(x+1)\ln x}{x-1}$ 时，需确认分母在 $x>1$ 时恒正，否则不等式方向会反转。
- **分离后函数的最值不可达**：如 $h(x) > a$ 恒成立，而 $h(x)_{\min}$ 在开区间取不到，只能用下确界或极限来描述，此时等号是否可取需要判定极限情形。
- **忽略二阶导或多次求导后的符号切换**：当 $f'(x)$ 难以直观判断，需求 $f''(x)$，但易在求导运算中出错（特别是乘积和对数的导数）。
- **解题步骤跳跃**：直接由 $f''(x)$ 符号下结论，未明确说明一阶导单调性及根的存在性，导致逻辑链断裂被扣分。

## 代表题精讲
### 代表题1：2016-文-20（Ⅰ）——切线方程
**题目**  
已知 $f(x)=(x+1)\ln x-a(x-1)$，当 $a=4$ 时，求曲线 $y=f(x)$ 在 $(1, f(1))$ 处的切线方程。

**思路**  
切线方程的关键要素是切点坐标与切线斜率。其中切点横坐标 $x_0=1$，纵坐标由原函数直接计算，斜率由导数在 $x=1$ 处的值确定。代入 $a=4$，按部就班计算，注意定义域 $x>0$。

**步骤**  
1. 当 $a=4$ 时，$f(x)=(x+1)\ln x -4(x-1)$，定义域 $x>0$。  
2. 计算 $f(1)$：$f(1)=(1+1)\ln1 -4\times0 =0$。切点为 $(1,0)$。  
3. 求导：$f'(x)=\ln x + \frac{x+1}{x} -4 = \ln x + 1 + \frac{1}{x} -4 = \ln x + \frac{1}{x} -3$。  
4. 切线斜率 $k=f'(1)=\ln 1 + 1 -3 = -2$。  
5. 切线方程：$y-0 = -2(x-1)$，即 $y = -2x+2$。

**点评/变式**  
切线问题属于基础得分项，务必保证运算准确。注意 $\frac{d}{dx}[(x+1)\ln x] = \ln x + \frac{x+1}{x}$。若题目改为过原点的切线，则需要设切点并解方程，难度会提升一档。

### 代表题2：2016-文-20（Ⅱ）——恒成立求参数范围
**题目**  
若当 $x\in(1,+\infty)$ 时 $f(x)>0$ 恒成立，求 $a$ 的取值范围。

**思路**  
观察 $f(1)=0$，问题转化为：在 $x>1$ 时函数值保持为正。可采用分离参数法或直接讨论法。分离参数：由 $f(x)>0$ 得 $a < \frac{(x+1)\ln x}{x-1}$（分母正），令 $h(x)=\frac{(x+1)\ln x}{x-1}$，求 $h(x)$ 在 $x>1$ 时的下确界。直接讨论法则利用 $f'(x)$，结合 $f(1)=0$ 去推参数的必要条件 $f'(1)\ge0$，再分类证明。

**步骤（分离参数法）**  
1. 当 $x>1$ 时，$x-1>0$，$f(x)>0 \iff a < \frac{(x+1)\ln x}{x-1}$。  
   令 $h(x)=\frac{(x+1)\ln x}{x-1}$，定义域 $(1,+\infty)$。  
2. 求导 $h'(x)$：  
   $h'(x)=\frac{[( \ln x + 1 + \frac{1}{x})(x-1) - (x+1)\ln x]}{(x-1)^2}$  
   化简分子：  
   $N(x)=(x-1)\ln x + x - 1 + \frac{(x-1)}{x} - (x+1)\ln x = -2\ln x + x - 1 + 1 - \frac{1}{x} = x - \frac{1}{x} - 2\ln x$。  
   所以 $h'(x)=\frac{x - \frac{1}{x} - 2\ln x}{(x-1)^2}$。  
3. 再令 $\varphi(x)=x - \frac{1}{x} - 2\ln x$，$x>1$。  
   $\varphi'(x)=1+\frac{1}{x^2}-\frac{2}{x}=\frac{x^2+1-2x}{x^2}=\frac{(x-1)^2}{x^2}>0$，  
   故 $\varphi(x)$ 在 $(1,+\infty)$ 单调递增，$\varphi(x)>\varphi(1)=0$。  
4. 因此 $h'(x)>0$，$h(x)$ 在 $(1,+\infty)$ 单调递增。  
5. $h(x)$ 的下确界为 $\lim_{x\to1^+} h(x)$（因为单调增且取不到 $x=1$）。  
   使用洛必达法则或等价变形：  
   $\lim_{x\to1^+}\frac{(x+1)\ln x}{x-1} \xlongequal{\frac{0}{0}} \lim_{x\to1^+}\frac{\ln x + 1 + \frac{1}{x}}{1}=2$。  
   故 $h(x)>2$。  
6. 要使 $a < h(x)$ 恒成立，需 $a \le 2$。等号可取：当 $a=2$ 时，$f(x)=(x+1)\ln x -2(x-1)$，可以证明 $f(x)>0$（可用前述端点效应+导数证明）。  
   综上，$a$ 的取值范围为 $(-\infty, 2]$。

**点评/变式**  
- 分离参数后遇到函数单调递增且上/下确界通过洛必达求得，是恒成立问题的经典套路。务必注明洛必达法则条件已满足，且讨论等号能否取得。  
- 变式：若把 $(1,+\infty)$ 换成 $(0,+\infty)$，则需分段讨论 $x$ 的正负对不等式方向的影响，难度大幅提升。端点效应法的核心是“特殊点显化必要条件”，可快速缩小参数范围，再证明充分性，同样高效。
