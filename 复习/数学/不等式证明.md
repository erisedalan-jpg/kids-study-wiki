## 知识精要
不等式证明是高考数学的重要考点，常出现在压轴题位置，分值高、区分度大。

- **比较法**：作差比较 $a-b \geq 0$；作商比较（要求均为正数）$\frac{a}{b} \geq 1$。
- **综合法**：从已知条件或基本不等式出发，逐步推导。
- **分析法**：从结论出发寻找充分条件，即“执果索因”。
- **基本不等式链**：若 $a, b > 0$，则 $\frac{2}{\frac{1}{a}+\frac{1}{b}} \leq \sqrt{ab} \leq \frac{a+b}{2} \leq \sqrt{\frac{a^2+b^2}{2}}$。
- **均值不等式**：若 $a, b > 0$，则 $a+b \geq 2\sqrt{ab}$；三元形式 $a+b+c \geq 3\sqrt[3]{abc}$。
- **柯西不等式**：$(a^2+b^2)(c^2+d^2) \geq (ac+bd)^2$，向量形式 $|\vec{a} \cdot \vec{b}| \leq |\vec{a}||\vec{b}|$。
- **绝对值不等式**：$||a|-|b|| \leq |a \pm b| \leq |a|+|b|$。
- **导数工具**：构造函数，利用单调性求最值证明不等式。需注意定义域，特别是含 $\ln x$ 时要求 $x>0$。

## 解题方法与套路
1. **作差构造法**  
   将欲证不等式化为 $F(x) \geq 0$ 形式，构造函数求导，分析单调性求最小值。若直接作差求导复杂，可先等价变形。
2. **放缩法**  
   利用已知不等式（如均值、切线放缩、$\ln x \leq x-1$、$e^x \geq x+1$ 等）对复杂表达式进行适度放大或缩小，转化为易证不等式。需控制放缩尺度。
3. **换元与消元**  
   对于多元条件不等式，利用已知等式消去一元或多变量，转化为单变量函数问题；或利用齐次特征令比值换元统一变量。
4. **绝对值证明套路**  
   优先利用平方法去掉绝对值（要求两边非负）；若不能，利用绝对值三角不等式或分类讨论去绝对值号。
5. **充要条件证法**  
   必须分别证明充分性与必要性。熟练运用分析法倒推（$\Leftarrow$ 寻找成立条件）与综合法正写（$\Rightarrow$ 由条件导出结论）。
6. **对称换元与对偶式**  
   对于轮换对称或含形如 $\frac{a^2}{b}$ 的结构，常配上 $b$ 使用均值不等式消除分母，如 $\frac{a^2}{b}+b \geq 2a$。

## 高频易错
- **忽略“正数”条件**：在应用均值不等式或柯西不等式放缩时，必须严格验证字母范围是否均为正数。
- **极值点偏移混淆**：利用导数证双变量不等式时，务必确认 $x_1, x_2$ 的对应关系与区间位置，不可随意套用对称构造法。
- **对数单身狗，指数找朋友**：含 $\ln x$ 或 $e^x$ 的不等式，构造函数时常分离它们，避免求导后复杂化。如 $\ln x$ 一般不与多项式相乘除。
- **放缩失度**：放缩后若得到 $f(x) \leq$ 某个常数，必须验证等号能否取到；若不能取到，放缩过度导致证明失败。
- **区间的开闭与定义域**：利用导数求单调性，书写区间时注意 $(, )$ 与 $[, ]$ 的区别；若定义域为 $(0, +\infty)$，切线放缩时需确认切点在定义域内。

## 代表题精讲
### 代表题1：2020-理-21
- **题目**：已知 $f(x)=\sin 2x \sin^2 x$，证明 $|f(x)| \leq \frac{3\sqrt{3}}{8}$，且证明连乘积不等式。
- **思路**：利用倍角公式及积化和差化简，转化为三次函数求导求最值；连乘部分通过对数化积累求和结合放缩。
- **步骤**：  
  1. $f(x)=2\sin x \cos x \cdot \sin^2 x = 2\sin^3 x \cos x$。  
  2. 为去除根号或绝对值，可考虑平方：$[f(x)]^2 = 4\sin^6 x \cos^2 x = 4\sin^6 x(1-\sin^2 x)$。  
  3. 令 $t=\sin^2 x \in [0, 1]$，则 $y=4t^3(1-t)=4(t^3-t^4)$，求导得 $y'=4(3t^2-4t^3)=4t^2(3-4t)$。  
  4. 在 $t=\frac{3}{4}$ 时取得最大值，代回得 $y_{\max}=\frac{27}{64}$，故 $|f(x)| \leq \sqrt{\frac{27}{64}} = \frac{3\sqrt{3}}{8}$。
- **点评/变式**：三角函数不等式常化为二次或三次函数求最值，或者利用三角函数有界性放缩。注意绝对值符号需结合对称性处理。

### 代表题2：2017-文-23
- **题目**：已知 $a, b > 0$ 且 $a^3+b^3=2$，证明 $(a+b)(a^5+b^5) \geq 4$ 及 $a+b \leq 2$。
- **思路**：第一问柯西不等式一步到位；第二问利用立方和公式消元，结合均值不等式构造关于 $a+b$ 的不等式。
- **步骤**：  
  (1) 由柯西不等式：$(a+b)(a^5+b^5) \geq (a^3+b^3)^2 = 2^2 = 4$。  
  (2) 由 $a^3+b^3=(a+b)(a^2-ab+b^2)=2$，且 $a^2-ab+b^2 = (a+b)^2-3ab$。  
  设 $s=a+b, p=ab$。则 $s(s^2-3p)=2$。  
  由均值 $\sqrt{ab} \leq \frac{a+b}{2}$ 得 $p \leq \frac{s^2}{4}$。  
  代入得 $2 = s^3 - 3sp \geq s^3 - 3s \cdot \frac{s^2}{4} = \frac{1}{4}s^3$，即 $s^3 \leq 8$，故 $s \leq 2$。
- **点评/变式**：已知高次和求一次和的范围，典型套路是“降次”结合均值不等式，利用 $ab$ 与 $a+b$ 的等量关系消元是关键。

### 代表题3：2011-文-21
- **题目**：已知 $f(x)=\frac{\ln x}{x+1}+\frac{1}{x}$，证明当 $x>0$ 且 $x \neq 1$ 时，$f(x) > \frac{\ln x}{x-1}$。
- **思路**：作差转化为分式结构，以 $x-1$ 与 $x+1$ 为节点，构造 $h(x)=\ln x - \frac{2(x-1)}{x+1}$ 或其变体，利用导数及经典不等式 $\ln x \leq x-1$ 或切线放缩证明。
- **步骤**：  
  1. 要证 $\frac{\ln x}{x+1}+\frac{1}{x} > \frac{\ln x}{x-1}$，通分移项即证 $\frac{1}{x} > \frac{2\ln x}{x^2-1}$。  
  2. 当 $x>1$ 时，$x^2-1>0$，即证 $\ln x < \frac{x^2-1}{2x} = \frac{1}{2}(x-\frac{1}{x})$。  
  3. 构造函数 $F(x)=\ln x - \frac{x}{2} + \frac{1}{2x}$，$F(1)=0$，求导得 $F'(x)= -\frac{(x-1)^2}{2x^2} \leq 0$，故 $F(x)$ 单调递减，$x>1$ 时 $F(x)<0$ 得证。  
  4. 同理可证 $0<x<1$ 情形。
- **点评/变式**：对数不等式变形核心常为 $\ln x$ 与有理函数的比较。注意 $x$ 与 $1$ 的大小关系影响分母符号，需分类讨论。
