## 知识精要
- **两角和与差的正弦公式**
  $$\sin(\alpha \pm \beta)=\sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$
- **两角和与差的余弦公式**
  $$\cos(\alpha \pm \beta)=\cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$
  （注意余弦公式符号：“同名异号”）
- **两角和与差的正切公式**
  $$\tan(\alpha \pm \beta)=\frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta} \quad(\alpha,\beta,\alpha\pm\beta \neq k\pi+\frac{\pi}{2})$$
- **辅助角公式（合一变形）**
  $$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$$
  其中 $\tan\varphi=\frac{b}{a}$，$\varphi$ 所在象限由 $a,b$ 符号决定；也可化为余弦形式。
- **正弦型函数的单调性**
  对于 $y=A\sin(\omega x+\varphi)$（$A>0,\omega>0$），将 $\omega x+\varphi$ 视为整体代入 $y=\sin t$ 的单调区间：
  - 增区间：$-\frac{\pi}{2}+2k\pi \le \omega x+\varphi \le \frac{\pi}{2}+2k\pi$
  - 减区间：$\frac{\pi}{2}+2k\pi \le \omega x+\varphi \le \frac{3\pi}{2}+2k\pi$
  若 $A<0$，需先化为正，或根据复合函数单调性反向求解。
- **适用条件**：角度为任意实数；公式适用于化简、求值、研究三角函数性质（单调性、最值、周期等）。

## 解题方法与套路
1. **化简优先**  
   见到含 $\sin$、$\cos$ 的线性组合（如 $\cos x - \sin x$），立即用辅助角公式合并为 $A\sin(x+\varphi)$ 或 $A\cos(x+\varphi)$ 形式。  
   *例*：$\cos x - \sin x = -\sin(x-\frac{\pi}{4})$ 或 $\sqrt{2}\cos(x+\frac{\pi}{4})$。
2. **整体代换求单调区间**  
   令 $t = \omega x+\varphi$，由 $y=\sin t$（或$\cos t$）的单调区间反解 $x$ 的范围，再结合给定区间限制求出参数的最大（小）值。
3. **角度变换与拆角技巧**  
   对于形如 $\sin(x+2\varphi)-2\sin\varphi\cos(x+\varphi)$ 的式子，将 $x+2\varphi$ 拆成 $(x+\varphi)+\varphi$，利用两角和的正弦公式展开，往往可以抵消并简化。
4. **区间包含问题处理**  
   若已知 $f(x)$ 在区间 $I$ 上是单调的，需使 $I$ 是求得的单调区间的子集，由此建立关于参数的不等式，得出参数的取值范围或最值。
5. **最值问题直接利用正弦、余弦的有界性**  
   化简后若得到 $\sin(x-\varphi)$ 等形式，由 $-1 \le \sin \le 1$ 直接得到最大（小）值，无需讨论更多细节。

## 高频易错
- **辅助角公式的符号与相位**  
  如 $\cos x-\sin x = \sqrt{2}\cos(x+\frac{\pi}{4})$，但若写成 $-\sin(x-\frac{\pi}{4})$，负号会导致单调性反转。必须先明确 $A$ 的符号，再套用正弦的单调区间（通常要求 $A>0$）。
- **正、余弦公式符号混淆**  
  $\cos(\alpha+\beta)=\cos\alpha\cos\beta - \sin\alpha\sin\beta$，$\cos(\alpha-\beta)=\cos\alpha\cos\beta + \sin\alpha\sin\beta$，与正弦公式的符号容易记错。应对方法：记住“余余正正，符号相反”。
- **单调区间端点开闭與参数限制**  
  如求 $a$ 的最大值，当单调区间包含 $0$ 且另一端为 $\frac{3\pi}{4}$ 时，$a$ 可以取到 $\frac{3\pi}{4}$（闭区间），但题中若给开区间要注意。另如 $[-a,a]$ 包含原点情形，对称区间的限制要同时满足左、右两个端点，取交集的最苛刻值。
- **忽略公式的适用条件**  
  用正切公式时必须保证分母不为零且各角、和差角不在 $\frac{\pi}{2}+k\pi$ 上。
- **盲目展开而不会构造“同名角”**  
  如 $\sin(x+2\varphi)-2\sin\varphi\cos(x+\varphi)$，若直接将所有项全展开反而复杂，正确做法是看出 $x+2\varphi = (x+\varphi)+\varphi$。

## 代表题精讲
### **题目**（2018·文·10）  
若 $f(x)=\cos x - \sin x$ 在 $[0,a]$ 上是减函数，求 $a$ 的最大值。

**思路**  
先利用辅助角公式将 $f(x)$ 化为单一正弦或余弦形式，并保证 $A>0$ 或先处理负号，再套入正弦（或余弦）的标准减区间，结合区间 $[0,a]$ 是减区间子集的条件求 $a$ 的最大值。

**步骤**  
$f(x)=\cos x-\sin x = -\sin(x-\frac{\pi}{4})$。  
令 $g(x)= \sin(x-\frac{\pi}{4})$，则 $f(x)=-g(x)$。  
$f(x)$ 单调递减 $\Leftrightarrow$ $g(x)$ 单调递增。  
$g(x)$ 的增区间：$-\frac{\pi}{2}+2k\pi \le x-\frac{\pi}{4} \le \frac{\pi}{2}+2k\pi \Rightarrow -\frac{\pi}{4}+2k\pi \le x \le \frac{3\pi}{4}+2k\pi$。  
取 $k=0$，得到包含 $0$ 的 $f(x)$ 的减区间为 $[-\frac{\pi}{4},\, \frac{3\pi}{4}]$。  
因为 $f(x)$ 在 $[0,a]$ 上减，所以 $[0,a] \subseteq [-\frac{\pi}{4},\, \frac{3\pi}{4}]$，于是 $a \le \frac{3\pi}{4}$。  
故 $a$ 的最大值为 $\frac{3\pi}{4}$。

**点评/变式**  
解题关键是看清负号对单调性的影响。若直接化为 $f(x)=\sqrt{2}\cos(x+\frac{\pi}{4})$，则 $\cos$ 的减区间为 $x+\frac{\pi}{4}\in[2k\pi,\,\pi+2k\pi]$，同样得 $x\in[-\frac{\pi}{4}+2k\pi,\,\frac{3\pi}{4}+2k\pi]$，殊途同归。变式：若区间改为 $[-a,a]$，则需同时满足 $-a \ge -\frac{\pi}{4}$ 和 $a \le \frac{3\pi}{4}$，取交集得 $a \le \frac{\pi}{4}$，这就是同卷理科第10题的结论，注意对称区间与不对称区间的细微差别。

### **题目**（2018·理·10）  
若 $f(x)=\cos x - \sin x$ 在 $[-a,a]$ 上是减函数，求 $a$ 的最大值。

**思路**  
化简后得出减区间，再使对称区间 $[-a,a]$ 完全落在该减区间内。

**步骤**  
同上得 $f(x)$ 的一个减区间为 $[-\frac{\pi}{4},\, \frac{3\pi}{4}]$。  
要使 $[-a,a] \subseteq [-\frac{\pi}{4},\, \frac{3\pi}{4}]$，必须满足：  
$\begin{cases}
-a \ge -\frac{\pi}{4} \\
a \le \frac{3\pi}{4}
\end{cases} \Rightarrow a \le \frac{\pi}{4}$ 且 $a \le \frac{3\pi}{4}$，所以 $a \le \frac{\pi}{4}$。  
因此 $a$ 的最大值为 $\frac{\pi}{4}$。

**点评/变式**  
与文科题对比，仅区间条件从 $[0,a]$ 变为 $[-a,a]$，答案从 $\frac{3\pi}{4}$ 变成 $\frac{\pi}{4}$，原因是增加了左端点的约束。此类选择题常设计成“姊妹题”，提醒我们审题时注意区间形式。

### **题目**（2014·文·14）  
函数 $f(x)=\sin(x+\varphi)-2\sin\varphi\cos x$ 的最大值为______。

**思路**  
直接展开第一项并合并同类项，可以凑出两角差的正弦公式大幅简化。

**步骤**  
$f(x)=\sin x\cos\varphi+\cos x\sin\varphi - 2\sin\varphi\cos x$  
$=\sin x\cos\varphi - \sin\varphi\cos x$  
$=\sin(x-\varphi)$。  
由正弦的有界性，最大值为 $1$。

**点评/变式**  
此题表面含参 $\varphi$，但化简后参数消失，最大值恒定。关键在于灵活运用两角和的正弦公式，不要盲目将第二项用二倍角或其他公式复杂化。同类题如：$f(x)=\sin(x+2\varphi)-2\sin\varphi\cos(x+\varphi)$，将 $x+2\varphi$ 视为 $(x+\varphi)+\varphi$，同理可得最大值为 $1$。这就是构造角、拆角的典型应用。
