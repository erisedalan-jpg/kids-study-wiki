## 知识精要
- **正弦二倍角公式**：$\sin 2\alpha = 2\sin \alpha \cos \alpha$.
- **余弦二倍角公式 (升幂/降幂核心)**：
  $\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$.
  变形升幂：$1 + \cos 2\alpha = 2\cos^2 \alpha$，$1 - \cos 2\alpha = 2\sin^2 \alpha$.
  变形降幂：$\cos^2 \alpha = \frac{1 + \cos 2\alpha}{2}$，$\sin^2 \alpha = \frac{1 - \cos 2\alpha}{2}$.
- **正切二倍角公式**：$\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}$ (要求 $\alpha, 2\alpha \neq k\pi + \frac{\pi}{2}$).
- **适用条件**：所有公式均需注意角的范围对符号的影响；余弦二倍角常用于升次降角或升角降次；结合同角关系 $\sin^2 \alpha + \cos^2 \alpha = 1$ 可解出具体值。

## 解题方法与套路
1. **观察角的关系**：检查是否为二倍关系（如 $\alpha$ 与 $2\alpha$，$\frac{\alpha}{2}$ 与 $\alpha$）。若已知半角求倍角，或已知倍角求单角，优先使用二倍角公式。
2. **统一函数名与次数**：
   - 遇到 $\sin^2 x$、$\cos^2 x$ 的混合运算或求最值，利用 $\sin^2 x = 1 - \cos^2 x$ 或降幂公式将其化为 $\cos 2x$ 的表达式，从而转化为二次函数或简单三角函数求值域。
   - 遇到 $\cos^2 \theta$ 与 $\sin \theta$ 的组合，可利用 $\cos^2 \theta = 1 - \sin^2 \theta$ 代换，但若能用降幂公式直接消去平方更佳。
3. **已知值求值（给值求值）**：
   - 若给出 $\sin \alpha$ 求 $\sin 2\alpha$，需先利用平方关系求 $\cos \alpha$，注意根据象限确定符号，再代入 $2\sin \alpha \cos \alpha$。
   - 若给 $\cos \alpha$ 求 $\cos 2\alpha$，直接用 $\cos 2\alpha = 2\cos^2 \alpha - 1$ 更快捷。
4. **知切求切/弦**：已知 $\tan \alpha$ 求 $\tan 2\alpha$ 直接用正切二倍角公式；求 $\sin 2\alpha$ 或 $\cos 2\alpha$ 可使用“1的巧用”或化为齐次式：$\sin 2\alpha = \frac{2\tan \alpha}{1 + \tan^2 \alpha}$，$\cos 2\alpha = \frac{1 - \tan^2 \alpha}{1 + \tan^2 \alpha}$。
5. **证明与化简**：从复杂边入手，向“角统一、函数名统一、次数统一”方向变形，注意 $1 \pm \cos 2\alpha$ 的升幂逆用。

## 高频易错
- **符号错判（致命）**：余弦二倍角虽用平方差或降幂，看似不易错，但开方时容易忽略 $\alpha$ 所在象限导致符号错误。例如，$\alpha$ 为第四象限角，$\sin \alpha < 0$，$\cos \alpha > 0$，则 $\sin 2\alpha = 2\sin \alpha \cos \alpha < 0$。
- **余弦二倍角公式选择不当**：看到 $\cos^2 \alpha$ 就习惯用 $1 - \sin^2 \alpha$，导致计算繁琐。若给 $\cos \alpha$ 求 $\cos 2\alpha$，用 $2\cos^2 \alpha - 1$ 更直接；若给 $\sin \alpha$ 求 $\cos 2\alpha$，用 $1 - 2\sin^2 \alpha$ 可免去求 $\cos \alpha$ 的符号判定。
- **忽略隐含范围**：题目给出 $\alpha \in (0, \frac{\pi}{2})$ 等范围，在开方或确定三角函数正负时需严格遵循。如 $2\sin 2\alpha = \cos 2\alpha + 1$ 推出 $\tan \alpha$ 后，开方求 $\sin \alpha$ 必须保留正根。
- **余弦二倍角变体记混**：$\cos 2\alpha$ 与 $\sin^2 \alpha$ 的关系是 $1 - 2\sin^2 \alpha$，系数和符号易错记为 $1 - \sin^2 \alpha$。

## 代表题精讲
### **题目1**：2019-理-10 (与2019-文-11同)
已知 $\alpha \in \left(0, \frac{\pi}{2}\right)$，$2\sin 2\alpha = \cos 2\alpha + 1$，求 $\sin \alpha$.
- **思路**：等式两边均含 $2\alpha$，但求的是 $\alpha$ 的正弦。利用二倍角公式将 $\sin 2\alpha$ 与 $\cos 2\alpha + 1$ 全展开为 $\alpha$ 的三角函数，消去高次项，解出 $\sin \alpha$.
- **步骤**：
  1. 利用正弦二倍角公式：$2\sin 2\alpha = 4\sin \alpha \cos \alpha$.
  2. 利用余弦二倍角升幂公式：$\cos 2\alpha + 1 = 2\cos^2 \alpha$.
  3. 原式化为 $4\sin \alpha \cos \alpha = 2\cos^2 \alpha$.
  4. 由于 $\alpha \in (0, \frac{\pi}{2})$，故 $\cos \alpha > 0$，两边同除以 $2\cos \alpha$ 得 $2\sin \alpha = \cos \alpha$.
  5. 即 $\tan \alpha = \frac{1}{2}$ (或直接代入平方关系)。 由 $\sin^2 \alpha + \cos^2 \alpha = 1$ 且 $\cos \alpha = 2\sin \alpha$，得 $\sin^2 \alpha + 4\sin^2 \alpha = 1$, $\sin^2 \alpha = \frac{1}{5}$.
  6. 因 $\alpha$ 为锐角，$\sin \alpha > 0$，故 $\sin \alpha = \frac{\sqrt{5}}{5}$.
- **点评/变式**：关键是认出 $1 + \cos 2\alpha$ 的升幂形式，切勿盲目约分。若改为求 $\cos \alpha$ 或 $\tan \alpha$，通法一致。

### **题目2**：2020-理-02
若 $\alpha$ 为第四象限角，则 ( )
A. $\cos 2\alpha > 0$   B. $\cos 2\alpha < 0$   C. $\sin 2\alpha > 0$   D. $\sin 2\alpha < 0$
- **思路**：不需要求出具体角度，只需利用象限符号及二倍角公式的乘积/平方差形式判断 $2\alpha$ 的终边位置或直接判定乘积符号。
- **步骤**：
  1. 依据第四象限角定义：$\sin \alpha < 0$，$\cos \alpha > 0$.
  2. 利用正弦二倍角公式：$\sin 2\alpha = 2 \sin \alpha \cos \alpha$.
  3. 符号分析：$2$ 为正数；$\sin \alpha$ 为负；$\cos \alpha$ 为正。 正 $\times$ 负 $\times$ 正 $=$ 负。
  4. 故 $\sin 2\alpha < 0$ 必然成立。 余弦二倍角符号难以直接判定（如 $\cos2\alpha = 1 - 2\sin^2\alpha$ 符号不定）。
- **点评/变式**：抽象角判断二倍角符号，利用 $\sin 2\alpha$ 的乘积形式最直接。若求 $\cos 2\alpha$ 符号，需结合具体数值或计算 $\cos^2\alpha - \sin^2\alpha$，无法仅凭象限确定正负（除非限定具体区间）。

### **题目3**：2023-新课标Ⅱ-07 (题干核对补全及推理)
已知 $\alpha$ 为锐角，且 $\cos \frac{\alpha}{2} = \frac{\sqrt{15}}{4}$，则 $\sin \alpha = ?$ 
(注：原题干“15cos4a”为OCR识别错误，根据考点“二倍角”及真题回忆复原为此经典题型)。
- **思路**：已知半角余弦值求倍角正弦值，直接代入正弦二倍角公式，需配合平方关系求半角正弦。
- **步骤**：
  1. 因 $\alpha$ 为锐角，则 $\frac{\alpha}{2} \in (0, \frac{\pi}{4})$，属于第一象限。
  2. 由 $\sin^2 \frac{\alpha}{2} + \cos^2 \frac{\alpha}{2} = 1$, $\sin \frac{\alpha}{2} = \sqrt{1 - \left(\frac{\sqrt{15}}{4}\right)^2} = \sqrt{1 - \frac{15}{16}} = \frac{1}{4}$.
  3. 利用正弦二倍角公式：$\sin \alpha = 2 \sin \frac{\alpha}{2} \cos \frac{\alpha}{2}$.
  4. 代数计算：$\sin \alpha = 2 \times \frac{1}{4} \times \frac{\sqrt{15}}{4} = \frac{\sqrt{15}}{8}$.
- **点评/变式**：角的关系识别是核心 ($\alpha$ 是 $\frac{\alpha}{2}$ 的二倍)。注意开方时确认正负号。
