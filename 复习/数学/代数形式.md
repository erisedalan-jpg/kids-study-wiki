## 知识精要
- 复数的代数形式：$z=a+bi\;(a,b\in\mathbb{R})$，$a$ 为实部，$b$ 为虚部。
- 复数相等：$a+bi=c+di\Leftrightarrow a=c$ 且 $b=d$（$a,b,c,d\in\mathbb{R}$）。
- 共轭复数：$z=a+bi$ 的共轭 $\overline{z}=a-bi$，满足 $z\cdot\overline{z}=a^2+b^2$。
- 四则运算：  
  加减：$(a+bi)\pm(c+di)=(a\pm c)+(b\pm d)i$。  
  乘法：$(a+bi)(c+di)=(ac-bd)+(ad+bc)i$。  
  除法：$\dfrac{a+bi}{c+di}=\dfrac{(a+bi)(c-di)}{(c+di)(c-di)}=\dfrac{ac+bd}{c^2+d^2}+\dfrac{bc-ad}{c^2+d^2}i\;(c+di\neq0)$。  
  本质：分母实数化，即分子分母同乘分母的共轭复数。
- 虚数单位 $i$ 的幂周期性：$i^4=1$，$i^{4k+r}=i^r$，特别地 $i^1=i,\ i^2=-1,\ i^3=-i,\ i^4=1$。

## 解题方法与套路
1. **识别运算类型**：判断题目是加减、乘法还是除法。
2. **除法的标准化步骤**：  
   ① 将分子分母写成代数形式；  
   ② 分子分母同乘分母的共轭复数；  
   ③ 分母利用 $(c+di)(c-di)=c^2+d^2$ 化为实数；  
   ④ 分子展开、合并同类项，利用 $i^2=-1$ 化简；  
   ⑤ 将结果写成 $a+bi$（或 $a+bi$ 的最简分数形式）。
3. **乘法的快速处理**：直接按多项式乘法展开，合并时牢记 $i^2=-1$。
4. **混合运算**：先乘除、后加减，遇除法优先分母实数化。

## 高频易错
- **分母漏乘或部分乘**：分子分母必须同乘分母的共轭复数，尤其分子未完全分配。
- **$i^2$ 符号错误**：展开过程中将 $i^2$ 误写成 $1$ 或忘记变号。
- **结果形式不规范**：最终答案未分离实部、虚部，或虚部未写成带 $i$ 的形式；分数未化到最简。
- **共轭概念混淆**：分母实数化时错误地乘了分子或分母本身的共轭，而不是分母的共轭。
- **运算跳步导致失误**：直接套公式时代错符号（如除法结果虚部分子 $bc-ad$ 顺序反）。

## 代表题精讲
**题目** (2018·全国卷理科)  
化简 $\frac{1+2i}{1-2i}$。  
选项：A．$i$　B．$-\frac{3}{5}$　C．$-\frac{4}{5}$　D．$-\frac{3}{5}+\frac{4}{5}i$

**思路**  
分母为 $1-2i$，其共轭复数为 $1+2i$。分子分母同乘 $1+2i$，利用平方差公式将分母化为实数，分子按完全平方公式展开，最后化为 $a+bi$ 形式。

**步骤**  
1. 写出原式：$\frac{1+2i}{1-2i}$。
2. 分子分母同乘分母的共轭复数 $(1+2i)$：  
   $$\frac{(1+2i)(1+2i)}{(1-2i)(1+2i)} = \frac{(1+2i)^2}{1^2 - (2i)^2}$$
3. 分母化简：$1 - 4i^2 = 1 - 4(-1) = 1+4 = 5$。
4. 分子展开：$(1+2i)^2 = 1^2 + 2\cdot 1\cdot 2i + (2i)^2 = 1 + 4i + 4i^2$。  
   代入 $i^2 = -1$ 得 $1 + 4i - 4 = -3 + 4i$。
5. 原式 $= \frac{-3+4i}{5} = -\frac{3}{5} + \frac{4}{5}i$。  
   对应选项 D。

**点评/变式**  
该题直接考查复数除法的分母实数化，是基础但必考运算。若题目变为 $\frac{2-i}{1+i}$，同样策略：分子分母同乘 $(1-i)$，分母变成 $1^2+1^2=2$，分子 $(2-i)(1-i)=2-2i-i+i^2=2-3i-1=1-3i$，结果为 $\frac{1}{2}-\frac{3}{2}i$。关键始终是：**共轭对象选分母的、每一步严格检查 $i^2=-1$、最后分离实虚部。**
