## 知识精要
- **余切定义**：$\cot \alpha = \dfrac{\cos \alpha}{\sin \alpha}$（$\sin\alpha \neq 0$）；常写为 $\cot \alpha = \dfrac{1}{\tan \alpha}$（$\tan\alpha \neq 0$）。
- **平方关系**：$1 + \cot^2 \alpha = \csc^2 \alpha = \dfrac{1}{\sin^2 \alpha}$，由此可得 $\sin^2 \alpha = \dfrac{1}{1+\cot^2 \alpha}$。
- **核心恒等式**：$\sin^2 \alpha + \cos^2 \alpha = 1$。
- **三角形内角限制**：在 $\triangle ABC$ 中，$0 < A < \pi$，必有 $\sin A > 0$。若 $\cot A < 0$，则 $\cos A$ 与 $\sin A$ 异号，结合 $\sin A>0$，得 $\cos A<0$，即 $A$ 为钝角。

## 解题方法与套路
1. **化切为弦**：由 $\cot A = k$，写出 $\cos A = k \sin A$。
2. **联立平方和**：将上式代入 $\sin^2 A + \cos^2 A = 1$，消元得到只含 $\sin A$（或 $\cos A$）的方程，求出 $\sin^2 A$ 或 $\cos^2 A$。
3. **开方定号**：根据角所在范围及已知 $\cot A$ 的符号，确定 $\sin A$ 或 $\cos A$ 的最终符号，尤其注意三角形中 $\sin A>0$，$\cot A$ 的符号直接决定 $\cos A$ 的符号。
4. **可选路径**：利用 $1+\cot^2 A = \frac{1}{\sin^2 A}$ 先求 $\sin^2 A$，再通过 $\cos^2 A = 1-\sin^2 A$ 得 $|\cos A|$，最后依据象限（三角形内角性质）判号。

## 高频易错
- **疏忽三角形内角范围为 $(0,\pi)$**：不知 $\sin A$ 恒正，直接由 $\cot A < 0$ 得出 $\cos A$ 可能为正的错误结论。
- **开方时漏掉负号**：由 $\cos^2 A$ 开方得 $\pm |\cos A|$，不结合 $\cot A$ 的符号筛选，导致误选正值。
- **误用倒数关系**：将 $\cot A$ 当作 $\tan A$ 处理，分子分母颠倒；或在已知 $\cot A$ 时忘记 $\cot A = \frac{1}{\tan A}$，计算失误。
- **符号判定时机错误**：先求出 $\cos A$ 的绝对值，再用三角形内角排除钝角可能性，但因忽视 $\cot$ 符号而保留锐角结果。

## 代表题精讲
**题目**  
已知 $\triangle ABC$ 中，$\cot A = -\dfrac{12}{5}$，则 $\cos A =$（选项略）

**思路**  
化余切为余弦与正弦的比，联立 $\sin^2 A + \cos^2 A = 1$ 求 $\cos A$。由于 $A$ 是三角形内角，$\sin A>0$，结合 $\cot A<0$ 判 $\cos A$ 为负，从开方后的两解中选取负值。

**步骤**  

由 $\cot A = \dfrac{\cos A}{\sin A} = -\dfrac{12}{5}$，得  
$$\cos A = -\frac{12}{5} \sin A.$$

代入 $\sin^2 A + \cos^2 A = 1$：  
$$\sin^2 A + \left( -\frac{12}{5}\sin A \right)^2 = 1,$$  
$$\sin^2 A + \frac{144}{25}\sin^2 A = 1,$$  
$$\frac{169}{25}\sin^2 A = 1,$$  
$$\sin^2 A = \frac{25}{169}.$$

因为 $A \in (0, \pi)$，$\sin A > 0$，故  
$$\sin A = \frac{5}{13}.$$

于是  
$$\cos A = -\frac{12}{5} \times \frac{5}{13} = -\frac{12}{13}.$$

经检验，$\cos A < 0$ 符合 $\cot A < 0$ 且 $\sin A>0$ 的条件，故答案为 $-\dfrac{12}{13}$。

**点评/变式**  
- 本题直接考查余切定义与同角平方关系的联合运用，属于基础必得分题。关键在于开方后根据三角形内角性质果断取正 $\sin A$，再反推 $\cos A$。  
- **变式1**：若已知 $\tan A = -\dfrac{12}{5}$，求 $\cos A$。可用 $\tan A = \dfrac{\sin A}{\cos A}$，类似联立，注意 $\tan A<0$ 时 $\sin A$ 与 $\cos A$ 异号，三角形内 $\sin A>0$，故 $\cos A<0$，结果相同。  
- **变式2**：已知 $\cot A = \dfrac{12}{5}$ 且 $A$ 为第三象限角，求 $\cos A$。此时 $\sin A<0$，$\cos A<0$，开方需判双负，锻炼对符号的全面把握。
