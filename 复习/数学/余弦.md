## 知识精要
- 任意角 $\alpha$ 的余弦定义为 $\cos\alpha = \frac{x}{r}$，其中 $P(x,y)$ 是角 $\alpha$ 终边上一点，$r=\sqrt{x^2+y^2}$。在三角形中，$\cos A$ 反映角 $A$ 的邻边与斜边之比（直角三角形）或由余弦定理联系三边：$\cos A = \frac{b^2+c^2-a^2}{2bc}$。
- 同角三角函数基本关系：
  1. 平方关系：$\sin^2\alpha + \cos^2\alpha = 1$；
  2. 商数关系：$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$；
  3. 倒数关系：$\cot\alpha = \frac{1}{\tan\alpha} = \frac{\cos\alpha}{\sin\alpha}$。
- 已知某三角函数值求其他三角函数值时，必须根据角的范围确定所求三角函数的符号。三角形内角 $A\in (0,\pi)$，$\sin A>0$ 恒成立，$\cos A$、$\tan A$、$\cot A$ 的符号由角 $A$ 是锐角还是钝角决定：
  - 若 $A$ 为锐角 $(0,\frac{\pi}{2})$，则 $\cos A>0$，$\tan A>0$，$\cot A>0$；
  - 若 $A$ 为钝角 $(\frac{\pi}{2},\pi)$，则 $\cos A<0$，$\tan A<0$，$\cot A<0$。

## 解题方法与套路
已知 $\cot A$ 求 $\cos A$（或在 $\triangle ABC$ 中由一个三角函数值求另一个）的通用步骤：
1. **化切为弦**：利用 $\cot A = \frac{\cos A}{\sin A}$，将已知的 $\cot A$ 表示为 $\cos A$ 与 $\sin A$ 的比，从而得到 $\cos A = k \sin A$（$k$ 为已知常数）。
2. **联立平方关系**：将上一步关系式代入 $\sin^2 A + \cos^2 A = 1$，消元得到关于 $\sin A$（或 $\cos A$）的一元二次方程。
3. **求解并定号**：解出平方根，得到 $\cos A$ 的绝对值。由角的范围（三角形内角、已知 $\cot A$ 的符号）判定 $A$ 是锐角还是钝角，从而确定 $\cos A$ 的符号，舍去增根。
4. **化简检验**：代入检验是否满足原条件，确保 $\sin A$ 与 $\cos A$ 的比值与已知 $\cot A$ 一致。

**拓展**：若已知 $\sin A$、$\cos A$、$\tan A$ 中任一，求其余时均可用“联立方程组”或“构造直角三角形并定号”两种思路。

## 高频易错
- **漏判角的范围**：仅由 $\sin^2+\cos^2=1$ 解得正负两个值，未结合三角形内角或已知函数值的符号进行取舍。三角形中 $\sin A>0$，但 $\cos A$、$\tan A$、$\cot A$ 可正可负，务必看已知值的正负。
- **忽略 $\cot A$ 分母不为零**：$\cot A = \frac{\cos A}{\sin A}$，必须保证 $\sin A \neq 0$。在 $\triangle ABC$ 中 $A\in(0,\pi)$，$\sin A\neq 0$ 自动满足。
- **符号误判**：例如 $\cot A<0$，说明 $A$ 必为钝角，则 $\cos A<0$；若错误地取正，则全题失分。
- **粗心代入错误**：将 $\cot A$ 的值直接当作 $\cos A$ 或 $\tan A$ 使用，导致关系混乱。
- **结果未化简**：求出的 $\cos A$ 应化为最简分数或有理数形式。

## 代表题精讲
**题目**（2009 全国卷·文·04）在 $\triangle ABC$ 中，已知 $\cot A = -\frac{12}{5}$，则 $\cos A =$（ ）
A. $\frac{5}{13}$　B. $\frac{12}{13}$　C. $-\frac{5}{13}$　D. $-\frac{12}{13}$

**思路**
由 $\cot A$ 建立 $\cos A$ 与 $\sin A$ 的关系，联立 $\sin^2 A + \cos^2 A = 1$，解出 $\cos A$；利用 $\cot A<0$ 判定 $A$ 为钝角，决定 $\cos A$ 的符号，选择负值选项。

**步骤**
1. 化切为弦：$\cot A = \frac{\cos A}{\sin A} = -\frac{12}{5}$，得 $\cos A = -\frac{12}{5}\sin A$。
2. 联立平方关系：代入 $\sin^2 A + \cos^2 A = 1$，得  
   $\sin^2 A + \frac{144}{25}\sin^2 A = 1 \Rightarrow \frac{169}{25}\sin^2 A = 1$，
   解得 $\sin^2 A = \frac{25}{169}$，$\sin A = \frac{5}{13}$（三角形中 $\sin A>0$）。
3. 求 $\cos A$ 并定号：$\cos A = -\frac{12}{5} \times \frac{5}{13} = -\frac{12}{13}$。
   由 $\cot A<0$ 可知 $A$ 为钝角，$\cos A$ 应为负，与所得一致，故选 **D**。

**点评/变式**
- 本题核心是“知一切求余弦”。关键在于利用同角平方关系建立方程，用已知的 $\cot A$ 作为桥梁。
- **变式1**：条件改为“$\tan A = -\frac{12}{5}$”，则 $\cos A = -\frac{5}{13}$，同理可得。
- **变式2**：条件改为“$\cos A = -\frac{12}{13}$，求 $\cot A$”，回代关系式即得 $\cot A = -\frac{12}{5}$，注意符号照应。
- 三角形背景下的符号判断是高频考点：若 $\cot A>0$，则 $A$ 为锐角，$\cos A>0$，取值改变为 $\frac{12}{13}$。务必看清正负。
