## 知识精要
- **余弦函数**：$y=\cos x$，定义域 $\mathbb{R}$，值域 $[-1,1]$，最小正周期 $T=2\pi$。
- **图象特征**：余弦曲线可看作正弦曲线向左平移 $\frac{\pi}{2}$ 得到，即 $\cos x = \sin\left(x+\frac{\pi}{2}\right)$。在 $[0,2\pi]$ 上，最高点 $(0,1)$，$(\pi,-1)$，最低点 $(\pi,-1)$（注：$(2\pi,1)$），与 $x$ 轴交点 $\frac{\pi}{2}$，$\frac{3\pi}{2}$。
- **最值**：$y=\cos x$ 在 $x=2k\pi$ 时取最大值 $1$，在 $x=\pi+2k\pi$ 时取最小值 $-1$，$k\in\mathbb{Z}$。
- **图象变换与交点**：动直线 $x=a$ 与 $y=\sin x$、$y=\cos x$ 分别交于 $M(a,\sin a)$、$N(a,\cos a)$，两点竖距 $|MN| = |\sin a - \cos a|$。利用辅助角公式可化为 $\sqrt{2}\left|\sin\left(a-\frac{\pi}{4}\right)\right| \in [0,\sqrt{2}]$。

## 解题方法与套路
1. **化归为单一三角函数**：若题目涉及 $\sin x$ 与 $\cos x$ 的线性组合，优先使用辅助角公式 $a\sin x+b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，将问题转化为单一正弦（或余弦）型函数的最值考查。
2. **竖距最大值的求法**：动直线与两函数图象相交所得竖距，构造差值函数 $h(x)=|f(x)-g(x)|$，利用三角恒等变形求该函数的最大值。
3. **数形结合**：在确定表达式后，可结合正弦（余弦）的有界性 $|\sin\theta|\le 1$ 直接得到最值及对应的 $x$ 取值。
4. **通用步骤**：
   - 写出交点纵坐标差（带绝对值）的表达式；
   - 利用三角公式合并为正弦型函数；
   - 根据正弦函数绝对值的有界性写出最大值，并求取等条件（即 $x$ 满足的方程）。

## 高频易错
- **忽略绝对值**：竖距本质是距离，即纵坐标差的绝对值。若直接求 $f(x)-g(x)$ 的最值而不加绝对值，会得到 $[-\sqrt{2},\sqrt{2}]$，导致最大值误判。
- **辅助角计算马虎**：$\sin x - \cos x = \sqrt{2}\sin\left(x-\frac{\pi}{4}\right)$ 而非 $\sqrt{2}\sin\left(x+\frac{\pi}{4}\right)$，相位角易错。可代入特殊点验证。
- **周期误判**：求 $|\sin(x-\frac{\pi}{4})|$ 的最大值时，注意绝对值正弦的周期变为 $\pi$，但不影响最大值仍为 $1$。
- **选项干扰**：看到 $\sqrt{2}$ 与 $2$ 时，易将正弦型系数 $\sqrt{2}$ 误当作最大值 $2$ 而选错。

## 代表题精讲
### 2008-理-08
**题目** 动直线 $x=a$ 与函数 $f(x)=\sin x$ 和 $g(x)=\cos x$ 的图象分别交于 $M,N$ 两点，求 $|MN|$ 的最大值。

**思路** 写出两点纵坐标差的绝对值，化为 $| \sin a - \cos a |$，用辅助角公式合并，利用正弦函数绝对值不超过 $1$ 求最大值。

**步骤**  
1. 由交点得 $M(a,\sin a)$，$N(a,\cos a)$，则 $|MN| = |\sin a - \cos a|$。  
2. 提取 $\sqrt{2}$：$\sin a - \cos a = \sqrt{2} \left( \frac{\sqrt{2}}{2}\sin a - \frac{\sqrt{2}}{2}\cos a \right) = \sqrt{2}\sin\left(a - \frac{\pi}{4}\right)$。  
3. 所以 $|MN| = \sqrt{2} \left| \sin\left(a - \frac{\pi}{4}\right) \right|$。  
4. 因 $\left| \sin\left(a - \frac{\pi}{4}\right) \right| \le 1$，故 $|MN| \le \sqrt{2}$，当 $a - \frac{\pi}{4} = \frac{\pi}{2} + k\pi$ 即 $a = \frac{3\pi}{4} + k\pi$ 时取等号。  
最大值为 $\sqrt{2}$。

**点评/变式** 本题本质是考查余弦、正弦函数图象关系及辅助角公式。变式：若改为 $f(x)=\cos x$，$g(x)=\cos(x+\theta)$，则竖距为 $|\cos x - \cos(x+\theta)|$，可用和差化积求解，最值同样与参数相关。
