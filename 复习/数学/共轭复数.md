## 知识精要
- 共轭复数定义：若 $z=a+bi\ (a,b\in\mathbf{R})$，则其共轭复数为 $\bar{z}=a-bi$ ．实部不变，虚部变为相反数．特别地，实数 $a$ 的共轭为自身，纯虚数 $bi$ 的共轭为 $-bi$．
- 复数相等的充要条件：$a+bi=c+di\Leftrightarrow a=c,\ b=d$ （$a,b,c,d\in\mathbf{R}$）．这是将复数条件转化为实数方程组的基本依据．
- 共轭复数的常用性质：
  - $\overline{z_1\pm z_2}=\bar{z_1}\pm\bar{z_2}$，$\overline{z_1\cdot z_2}=\bar{z_1}\cdot\bar{z_2}$，$\overline{\left(\dfrac{z_1}{z_2}\right)}=\dfrac{\bar{z_1}}{\bar{z_2}}\ (z_2\neq0)$．
  - $z+\bar{z}=2a$ （实部两倍），$z-\bar{z}=2bi$ （虚部两倍乘以 i）．
  - $z\cdot\bar{z}=|z|^2=a^2+b^2$，据此可快速求模及与模相关的运算．
- 复数在复平面内的对应点：$z=a+bi$ 对应点 $(a,b)$；$\bar{z}=a-bi$ 对应点 $(a,-b)$，两点关于实轴对称．
- 复数的四则运算：除法运算分子分母同乘分母的共轭复数以化为 $a+bi$ 形式．

## 解题方法与套路
1. **设复标准型代入**：当条件中同时出现 $z$ 与 $\bar{z}$ 且不易直接化简时，设 $z=a+bi\ (a,b\in\mathbf{R})$，则 $\bar{z}=a-bi$．代入条件，利用复数相等的充要条件列出关于 $a,b$ 的方程组，解得实部与虚部．此法普适性强，几乎覆盖所有方程型问题．
2. **利用共轭性质整体代换**：如 $z+\bar{z}$，$z-\bar{z}$，$z\cdot\bar{z}$ 可直接用 $a,b$ 或 $|z|^2$ 表示．遇到 $f(z,\bar{z})=c+di$ 时，将左侧整体转化为实部、虚部表达式，一步到位得到方程组．
3. **先化简再求共轭**：对于已知 $z$ 表达式（乘法、除法）求 $\bar{z}$ 的题，先将 $z$ 化为 $a+bi$ 形式，再取共轭．特别注意 $i^2=-1$ 及分母实数化技巧．
4. **复平面信息问题**：将共轭复数显式写出实、虚部，直接对应点坐标；若涉及象限判断，只需看实部、虚部的符号．
5. **参数问题**：若含参数 $a,b$，并给出含 $z,\bar{z}$ 的等式，代入标准化为 $A+Bi=0$，利用复数为零的充要条件（实部虚部均为0）列方程组求解．

## 高频易错
- 共轭复数定义不清：$\bar{z}$ 只改变虚部符号，实部不变．常见错误：将实部符号也改变，或忘记变号，或误认为 $\overline{a+bi}=a+bi$ 对所有复数成立．
- 忽略 $a,b\in\mathbf{R}$ 的前提：在设 $z=a+bi$ 时，只有当 $a,b$ 为实数时，$\bar{z}=a-bi$ 才成立；如果题目涉及参数且未指明实虚部为实数，必须先明确前提．
- 复数相等转化时漏掉虚部或系数：如 $a+bi=0$ 意味着 $a=0$ 且 $b=0$，而非仅实部为零．含 $i$ 的项易在合并时丢失系数，导致解错 $a,b$．
- 复平面坐标与点对应错误：$z=a+bi$ 对应 $(a,b)$，$\bar{z}=a-bi$ 对应 $(a,-b)$，常有人混淆横纵坐标或符号．
- 计算失误：除法运算未乘分母共轭复数，或 $i^2$ 计算成 $1$，或在提取公因式时符号出错．
- 性质误用：$\overline{z_1+z_2}=\bar{z_1}+\bar{z_2}$ 正确，但 $\overline{z^n}=(\bar{z})^n$ 仅当 $n$ 为整数时成立；非标准复合函数共轭不可直接交换．

## 代表题精讲

**题目** 已知 $z=1-2i$，且 $z + a\bar{z} + b = 0$，其中 $a,b$ 为实数，求 $a,b$ 的值．
**思路** 由共轭定义写出 $\bar{z}=1+2i$，代入等式，左侧整理为实部加虚部形式，利用实部、虚部均为零列方程组．
**步骤**
1. $z=1-2i$，则 $\bar{z}=1+2i$．
2. 代入：$(1-2i) + a(1+2i) + b = 0$，整理得 $(1+a+b) + (-2+2a)i = 0$．
3. 由复数相等，实部与虚部分别为零：$\begin{cases} 1+a+b=0 \\ -2+2a=0 \end{cases}$．
4. 解得 $a=1$，代入第一式得 $b=-2$．
**点评** 此类题关键在于将 $\bar{z}$ 正确写出，合并同类项后利用复数相等转方程组．可出变式：条件改为 $z\bar{z}+a z+b=0$，则需用到模的性质 $\bar{z}z=|z|^2$．

**题目** 设 $2(z+\bar{z}) + 3(z-\bar{z}) = 4+6i$，求复数 $z$．
**思路** 设 $z=a+bi$ 直接算 $z+\bar{z}=2a$，$z-\bar{z}=2bi$，代入后与右边 $4+6i$ 比较实、虚部得 $a,b$．
**步骤**
1. 设 $z=a+bi\ (a,b\in\mathbf{R})$，则 $\bar{z}=a-bi$．
2. 计算 $z+\bar{z}=2a$，$z-\bar{z}=2bi$．
3. 原式 $2(2a) + 3(2bi) = 4a + 6bi$．
4. 于是 $4a+6bi=4+6i$，由复数相等得 $4a=4$，$6b=6$，解得 $a=1$，$b=1$．
5. 故 $z=1+i$．
**点评** 将含 $z,\bar{z}$ 的线性组合直接转化为 $a,b$ 的线性式，避免繁琐带入．变式：若条件为 $(z+\bar{z})+i(z-\bar{z})=c+di$，同样可快速求解．

**题目** 设 $z=i(2+i)$，求 $\bar{z}$．
**思路** 先进行乘法运算化简 $z$，再根据共轭定义写出 $\bar{z}$．
**步骤**
1. $z = i(2+i) = 2i + i^2 = -1 + 2i$．
2. $\bar{z} = \overline{-1+2i} = -1 - 2i$．
**点评** 本题为基础计算型，关键在于 $i^2=-1$ 不犯错，共轭只改变虚部符号．可拓展为求 $z$ 的模 $|z|=\sqrt{(-1)^2+2^2}=\sqrt5$，或点 $(-1,2)$ 所在象限．
