## 知识精要
- **双曲线的标准方程与基本量**：焦点在 $x$ 轴上的双曲线标准方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（$a>0,b>0$），其中 $c^2 = a^2 + b^2$，离心率 $e = \frac{c}{a} > 1$。
- **顶点与实轴**：双曲线左、右顶点为 $A_1(-a,0)$、$A_2(a,0)$，实轴长 $|A_1A_2| = 2a$。
- **离心率的几何意义**：$e$ 刻画双曲线开口大小，$e$ 越大，渐近线斜率绝对值 $\frac{b}{a}$ 越大。
- **几何条件的坐标转化**：将题中几何关系（角、线段相等、特殊图形）在坐标系下翻译为点的坐标或线段长度的代数表达式。顶角 $120^\circ$ 的等腰三角形一般可借助三角函数或向量得出相关点的坐标。
- **代入法求参数关系**：通过将关键点的坐标代入曲线方程，得到关于 $a,b$ 的方程，进而求得 $e$。

## 解题方法与套路
1. **建立坐标系或明确已有坐标系**：通常圆锥曲线题目已给标准方程，可直接利用其顶点、焦点坐标。
2. **转化几何条件为坐标或长度等式**：  
   - 等腰三角形：找出腰和底，写出等量关系。  
   - 顶角 $120^\circ$：已知两腰及其夹角，可用余弦定理求底边，或利用旋转/三角函数求出第三点坐标。本例中利用 $MA=2a$，$\angle MAB=120^\circ$，将 $M$ 的坐标表示为 $(-2a, \sqrt{3}a)$（注意角度方向与符号）。  
3. **代入曲线方程**：将求得的点坐标代入双曲线方程，化简得到 $a$ 与 $b$ 的关系。  
4. **利用 $c^2 = a^2 + b^2$ 消元**：用 $a$ 和 $b$ 表示 $c$，进而求出离心率 $e = \frac{c}{a} = \sqrt{1 + \frac{b^2}{a^2}}$。  
5. **检验合理性**：确认求得的 $e$ 符合双曲线条件，并注意题目有无限制（如点 $M$ 是否合理）。

## 高频易错
- **角度与坐标符号**：判断点 $M$ 所在的象限（左支还是右支），直接影响坐标正负。如 $M$ 在左支，$x$ 坐标应为负，$y$ 坐标由 $\sin 120^\circ$ 决定正负。若符号错则方程错误。
- **腰的确认**：题中“$\triangle ABM$ 为等腰三角形，顶角为 $120^\circ$”需明确哪两边为腰。本题默认 $AB$ 为底边（因 $A,B$ 为固定顶点，$MA=MB$ 也成立？但解析取 $MA=AB=2a$，需依据题意判断）。若误认为 $MA=MB$，则会得到不同方程导致错解。
- **线段长度坐标化**：$A(-a,0), B(a,0)$，则 $AB=2a$。点 $M$ 到 $A$ 的距离公式易算错，直接用几何关系表示坐标更高效。
- **离心率公式混淆**：椭圆 $e = \frac{c}{a} < 1$，双曲线 $e = \frac{c}{a} > 1$，勿记反。且双曲线中 $c^2 = a^2 + b^2$，椭圆为 $a^2 = b^2 + c^2$。
- **运算失误**：代入方程后分式化简，未及时约分可能导致关系复杂化。

## 代表题精讲
### 代表题：2015-理-11
**题目**：已知 $A,B$ 为双曲线 $E$ 的左、右顶点，点 $M$ 在 $E$ 上，$\triangle ABM$ 为等腰三角形，顶角为 $120^\circ$，求 $E$ 的离心率。

**思路**：  
由双曲线对称性及条件，设 $E: \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，则 $A(-a,0), B(a,0)$。由等腰三角形及顶角 $120^\circ$，确定腰为 $MA$ 和 $AB$（或 $MB$ 和 $AB$，选其一，结果对称），通过角度关系算出 $M$ 点坐标，代入双曲线方程得出 $a,b$ 关系，进而求 $e$。

**步骤**：  
1. 设双曲线标准方程为 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，顶点 $A(-a,0), B(a,0)$，则 $|AB|=2a$。  
2. 由 $\triangle ABM$ 为等腰三角形，顶角 $120^\circ$，不妨令 $|MA|=|AB|=2a$，$\angle MAB = 120^\circ$。  
3. 由 $A(-a,0)$ 出发，向 $AB$ 逆时针（或顺时针，但保证点在左支）旋转 $120^\circ$ 并取长度 $2a$，可得 $M$ 坐标：$x_M = -a + 2a \cos 120^\circ = -a - a = -2a$，$y_M = 0 + 2a \sin 120^\circ = \sqrt{3}a$。故 $M(-2a, \sqrt{3}a)$。  
4. 将 $M$ 代入双曲线方程：$\frac{(-2a)^2}{a^2} - \frac{(\sqrt{3}a)^2}{b^2} = 1$，得 $4 - \frac{3a^2}{b^2} = 1$，整理得 $\frac{3a^2}{b^2} = 3 \Rightarrow a^2 = b^2$，即 $a = b$。  
5. 计算 $c = \sqrt{a^2 + b^2} = \sqrt{2a^2} = \sqrt{2}a$，故离心率 $e = \frac{c}{a} = \sqrt{2}$。

**点评/变式**：  
本题的关键在于**几何条件→坐标**的转化。顶角与腰长确定后，利用三角函数或向量可直接写出目标点坐标。避免联立距离方程。若变顶角大小，或变为等腰但不知哪边为腰的情形，要注意分类讨论。例如：若条件改为 $\triangle ABM$ 是正三角形且 $M$ 在双曲线上，则可求 $e$；若 $M$ 在右支，则 $x$ 坐标取正，结果相同，双曲线左、右对称不影响离心率。本题答案为 $\sqrt{2}$，对应选项 D。
