## 知识精要
- **异面直线所成角**：定义在 $\left(0,\frac{\pi}{2}\right]$，设两直线方向向量分别为 $\vec{a},\vec{b}$，则 $\cos\theta = \frac{|\vec{a}\cdot\vec{b}|}{|\vec{a}||\vec{b}|}$（取绝对值保证角为锐角或直角）。
- **坐标法求角前提**：图形中存在两两垂直的棱或可作出三条两两垂直的直线作为坐标轴，常选顶点、中心、中点等对称点作原点。正棱锥、正棱柱、长方体（含正方体）优先考虑建系。
- **建系要点**：将几何图形放置于空间直角坐标系中，写出所有关键点坐标，再转化为向量坐标。若图形没有天然垂直，可适当平移或利用对称性构造坐标系。
- **向量运算**：设 $\vec{a}=(x_1,y_1,z_1), \vec{b}=(x_2,y_2,z_2)$，内积 $\vec{a}\cdot\vec{b}=x_1x_2+y_1y_2+z_1z_2$，模长 $|\vec{a}|=\sqrt{x_1^2+y_1^2+z_1^2}$。

## 解题方法与套路
1. **审图画轴**：分析几何体的对称特征，确定三条两两垂直的方向为 $x,y,z$ 轴，一般让底面落在 $xOy$ 平面内，高沿 $z$ 轴。正棱锥常以底面中心为原点。
2. **写点坐标**：根据棱长或给定线段长度，写出各顶点坐标。底面上的点直接由平面几何可得，顶点的第三坐标由高确定。中点用中点公式 $M\left(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2},\frac{z_1+z_2}{2}\right)$。
3. **求方向向量**：计算所需的两条异面直线的方向向量，通常通过终点坐标减起点坐标得到。
4. **用夹角公式**：代入 $\cos\theta = \frac{|\vec{a}\cdot\vec{b}|}{|\vec{a}||\vec{b}|}$，算出余弦值即为异面直线所成角的余弦。注意结果的绝对值。
5. **验证与选择**：若选项中有理数，注意代数化简，结果通常为 $\frac{\sqrt{3}}{3},\frac{\sqrt{6}}{3}$ 等同类型。

## 高频易错
- **坐标系建立不合理**：未保证轴两两垂直，导致运算复杂或错误。务必明确哪个方向与哪个方向垂直，必要时可利用正方体或长方体辅助建系。
- **坐标计算错误**：底面上点的正负号混淆，忽略题目中“棱长相等”等条件，将长度不加处理直接带入，正四棱锥顶点坐标 $S(0,0,h)$ 中高 $h$ 需由侧棱长与底面对角线半长用勾股定理求出：$h = \sqrt{l^2 - (\frac{\sqrt{2}}{2}a)^2}$。
- **向量坐标写反或误减**：方向向量需对应同一条直线，切忌交叉相减；中点坐标符号也要细心。
- **忽略绝对值**：直接用 $\vec{a}\cdot\vec{b}/(|\vec{a}||\vec{b}|)$ 可能得出负值，但异面直线所成角取锐角或直角，必须加绝对值。
- **混淆异面直线夹角与线面角、二面角公式**：记清每个公式中向量的选取以及是否取绝对值或正负变换。

## 代表题精讲
### **题目**（2008·全国卷理·10）
已知正四棱锥 $S-ABCD$ 的侧棱长与底面边长都相等，$E$ 是 $SB$ 的中点，求异面直线 $AE$ 与 $SD$ 所成角的余弦值。

**思路**：正四棱锥底面是正方形，侧棱相等且等于边长，可建系利用坐标法。将底面中心设为原点，对角线方向为 $x,y$ 轴，高为 $z$ 轴，写出各点坐标，求出 $\overrightarrow{AE}$ 和 $\overrightarrow{SD}$，再用夹角公式。

**步骤**：
1. **建系**：设正四棱锥 $S-ABCD$ 底面中心为坐标原点 $O$，$AC$ 在 $x$ 轴上，$BD$ 在 $y$ 轴上，$SO$ 沿 $z$ 轴。令底面边长为 $2$（方便计算），则侧棱长也为 $2$。
2. **求坐标**：
   - 底面正方形对角线半长 $OA=\sqrt{2}$，高 $h=SO=\sqrt{SA^2 - OA^2} = \sqrt{2^2 - (\sqrt{2})^2} = \sqrt{2}$。
   - 因此 $A(1,-1,0)$，$B(1,1,0)$，$C(-1,1,0)$，$D(-1,-1,0)$，$S(0,0,\sqrt{2})$。
   - $E$ 为 $SB$ 中点：$E\left(\frac{1+0}{2},\frac{1+0}{2},\frac{0+\sqrt{2}}{2}\right) = \left(\frac{1}{2},\frac{1}{2},\frac{\sqrt{2}}{2}\right)$。
3. **求向量**：
   - $\overrightarrow{AE} = \left(\frac{1}{2}-1, \frac{1}{2}-(-1), \frac{\sqrt{2}}{2}-0\right) = \left(-\frac{1}{2}, \frac{3}{2}, \frac{\sqrt{2}}{2}\right)$。
   - $\overrightarrow{SD} = \left(-1-0, -1-0, 0-\sqrt{2}\right) = \left(-1, -1, -\sqrt{2}\right)$。
4. **计算**：
   - 内积：$\overrightarrow{AE}\cdot\overrightarrow{SD} = \left(-\frac{1}{2}\right)(-1) + \frac{3}{2}(-1) + \frac{\sqrt{2}}{2}(-\sqrt{2}) = \frac{1}{2} - \frac{3}{2} - 1 = -2$。
   - 模长：$|\overrightarrow{AE}| = \sqrt{\left(-\frac{1}{2}\right)^2 + \left(\frac{3}{2}\right)^2 + \left(\frac{\sqrt{2}}{2}\right)^2} = \sqrt{\frac{1}{4}+\frac{9}{4}+\frac{2}{4}} = \sqrt{3}$；
     $|\overrightarrow{SD}| = \sqrt{(-1)^2+(-1)^2+(-\sqrt{2})^2} = \sqrt{1+1+2} = 2$。
   - 夹角的余弦绝对值：$\cos\theta = \frac{|-2|}{\sqrt{3} \times 2} = \frac{2}{2\sqrt{3}} = \frac{\sqrt{3}}{3}$。

**点评/变式**：此题通过对称建系将几何问题转化为代数运算，关键是用好正四棱锥的几何性质确定坐标。变式：若求 $AE$ 与平面 $SCD$ 所成角，则先求 $\overrightarrow{AE}$ 与平面法向量夹角正弦；若$E$为任意分点，用定比分点公式即可。
