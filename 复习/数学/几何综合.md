## 知识精要
- **等腰三角形的性质**：$AB=AC$，底边上的高 $AD$ 平分顶角 $\angle BAC$ 并垂直平分底边 $BC$。
- **切线长定理**：从圆外一点引圆的两条切线，它们的切线长相等。由此可得 $AE=AF$，$BE=?$ 等。
- **弦切角定理**：弦切角等于它所夹的弧所对的圆周角。可用于导角证明平行。
- **垂径定理**：垂直于弦的直径平分弦，且平分弦所对的两条弧。在本题中，$AD \perp BC$，且 $O$ 在 $AD$ 上时，$M,N$ 关于 $AD$ 对称。
- **切割线定理**：从圆外一点引圆的切线和割线，切线长是这点到割线与圆交点的两条线段长的比例中项。（若涉及计算常需配合使用）
- **四点共圆的判定与性质**：圆内接四边形对角互补，外角等于内对角，可用于角度转化。
- **相似三角形判定**：平行导致相似（$EF\parallel BC \Rightarrow \triangle AEF \sim \triangle ABC$），或由等角推相似，用于计算线段比及面积比。
- **面积计算**：四边形 $EBCF$ 为梯形（由 $EF\parallel BC$），面积 $S=\frac{1}{2}(EF+BC)\cdot h$，其中 $h$ 为梯形的高，可从等腰三角形和圆的性质导出。

## 解题方法与套路
1. **证平行**：
   - 思路一：利用弦切角与圆周角转化。连接 $OE,OF$，由切线得 $OE \perp AB$，$OF \perp AC$，结合 $O$ 在 $AD$ 上，可证 $\angle AEF = \angle B$，得同位角相等。
   - 思路二：利用切线长定理 $AE=AF$，结合等腰 $\triangle ABC$ 得 $\frac{AE}{AB}=\frac{AF}{AC}$，从而直接由比例线段得 $EF\parallel BC$（更简洁）。
2. **涉及圆半径与等腰高的计算**：
   - 设圆半径为 $r$，巧妙利用条件“$AG=r$”结合垂径定理表达 $AD$、$OD$ 等。
   - 利用 $AE$ 与 $MN$ 的长度，通过射影定理或勾股定理在 $\triangle AEO$ 等直角三角形中建立方程，求出半径及关键线段长。
3. **求面积的一般流程**：
   - 利用相似比 $\frac{AE}{AB}$ 求 $EF$ 与 $BC$ 的长。
   - 利用已知条件和圆的性质求梯形的高（通常等于 $AD-AG-?$ $+$ 弦心距等组合）。
   - 代入梯形面积公式。注意先算所需要的所有线段长，再最后求面积，确保计算准确。

## 高频易错
- **误认为 $O$ 在 $AD$ 上就推出 $M,N$ 是 $BC$ 与圆的切点**：$M,N$ 只是交点，不一定相切，直接用切线的性质会出错。
- **切线长定理乱用在对 $BC$ 上**：仅当直线与圆相切时才可用，本题 $BC$ 与圆相交于 $M,N$，不可对 $B,C$ 直接用切线长定理。
- **忽略等腰三角形的对称性**：由于 $AB=AC$ 且 $AD$ 是底边的高，整个图形关于 $AD$ 对称，$E$ 和 $F$、$M$ 和 $N$ 都是对称点，可简化计算。若没有利用对称，会增加计算量。
- **计算梯形面积时高判断错误**：梯形 $EBCF$ 的高不一定等于 $AD$ 减去某段；需明确它是两平行线 $EF$ 与 $BC$ 间的垂线段长度，可能在 $AD$ 上对应的一段。
- **混淆相似比与面积比**：$\triangle AEF \sim \triangle ABC$ 的面积比 $= (\frac{AE}{AB})^2$，不要直接当成长度比。

## 代表题精讲
### 代表题1：2015年理数第22题
**题目**：如图，$O$ 为等腰三角形 $ABC$ 内一点，$\odot O$ 与底边 $BC$ 交于 $M,N$ 两点，与底边上的高 $AD$ 交于点 $G$，且与 $AB,AC$ 分别相切于 $E,F$ 两点。  
(1) 求证：$EF\parallel BC$；  
(2) 若 $AG$ 等于 $\odot O$ 的半径，且 $AE=MN=2\sqrt{3}$，求四边形 $EBCF$ 的面积。

**思路**：
(1) 由 $AB,AC$ 是切线可得 $AE=AF$，结合等腰 $\triangle ABC$ 和比例线段，利用“若一条直线截三角形两边所得的对应线段成比例，则该直线平行于第三边”即得证。
(2) 利用对称性设半径 $r$，由 $AG=r$ 得 $O,G$ 位置关系；结合弦 $MN$ 的长度与垂径定理求出弦心距，进而求得半径 $r$ 及 $AD$ 等；再通过相似求出 $EF,BC$ 和高，计算梯形面积。

**步骤**：
1. (1) 证明：
   $\because AB,AC$ 与 $\odot O$ 相切于 $E,F$，由切线长定理得 $AE=AF$。
   又 $\because \triangle ABC$ 是等腰三角形，$AD \perp BC$，且 $AB=AC$，
   $\therefore \frac{AE}{AB} = \frac{AF}{AC}$。  
   在 $\triangle ABC$ 中，$\because \frac{AE}{AB} = \frac{AF}{AC}$，且 $E,F$ 分别在 $AB,AC$ 上，  
   $\therefore EF \parallel BC$。得证。

2. (2) 连接 $OE,OM,OA$，设 $\odot O$ 半径为 $r$，则 $OE=OM=r$，由条件 $AG=r$。  
   $\because AD \perp BC$ 且 $M,N$ 为弦与 $BC$ 交点，由对称性可知 $O$ 在 $AD$ 上，  
   令弦心距 $OD = d$，则 $AD$ 上 $G$ 在 $A$ 与 $O$ 之间。  
   在 $\text{Rt}\triangle AEO$ 中，$AE=2\sqrt{3}$，$OE=r$，由勾股定理：$AO = \sqrt{AE^2 - OE^2} = \sqrt{(2\sqrt{3})^2 - r^2} = \sqrt{12 - r^2}$。  
   又 $AG=r$，点 $G$ 在 $AO$ 上，则 $OG = AO - AG = \sqrt{12 - r^2} - r$。  
   但 $OG$ 亦是点 $O$ 到直径方向上的问题？注意 $G$ 是圆与 $AD$ 的交点，故 $OG = r$。为什么？因为 $G$ 在圆上！重新审题：$AD$ 与 $\odot O$ 交于点 $G$，即 $G$ 是圆上一点，所以 $OG = r$。  
   故 $OG = r$。于是有 $\sqrt{12 - r^2} - r = r$，即 $\sqrt{12 - r^2} = 2r$，  
   平方得 $12 - r^2 = 4r^2 \Rightarrow 5r^2 = 12 \Rightarrow r^2 = \frac{12}{5}$，  
   $r = \frac{2\sqrt{15}}{5}$。  
   此时 $AO = 2r = \frac{4\sqrt{15}}{5}$，$AE$ 已知。  
   在 $\text{Rt}\triangle AEO$ 中，还可求 $OE$ 等。  
   另外，弦 $MN = 2\sqrt{3}$，由垂径定理 $MD = \frac{1}{2}MN = \sqrt{3}$。  
   在 $\text{Rt}\triangle OMD$ 中，$OD = \sqrt{r^2 - MD^2} = \sqrt{\frac{12}{5} - 3} = \sqrt{\frac{12}{5} - \frac{15}{5}} = \sqrt{-\frac{3}{5}}$？这就出现矛盾，表明 $MN$ 长度与条件 $AE=MN$ 可能导致 $OD$ 为虚数，需要检查题设。实际上原高考题是“$AE=MN=2\sqrt{3}$”吗？可能我记错了。原题是（2015全国2卷）AE=MN=4/3? 查证：原题是“若AG等于圆O的半径，且AE=MN=2√3?” 其实原题是AE=MN=2√3，但这样算出OD平方为负，所以必须修正。正确的应该是 “AE = MN = 2√3” 对应某个特定的图形，其实我计算有误：$r^2=12/5$，$MD=√3$，$MD^2=3$，而$12/5=2.4$，确实小于3，所以无解。说明题给数据应是其他值。检索记忆：2015年全国卷2理数22题(几何证明选讲)：(2)若AG等于⊙O的半径，且AE=MN=2√3，求四边形EBCF的面积。标准答案给出AE=MN=2√3，r=√3？实际解法中，他们先设半径r，由AG=r，得AO=2r，在Rt△AEO中，AE²+EO²=AO², 即 (2√3)² + r² = (2r)² ⇒ 12 + r² = 4r² ⇒ 3r²=12 ⇒ r=2。所以r=2。这样MD=MN/2=√3，在Rt△OMD中，OD=√(r²-MD²)=√(4-3)=1。没问题！我前面错在勾股定理写反了：应该是AO² = AE² + EO²，而不是AE² - EO²。因为切线垂直于半径，所以OE⊥AB，∠AEO=90°，AO是斜边。正确。

   修正：
   连接 $OE$，则 $OE \perp AB$。  
   在 $\text{Rt}\triangle AEO$ 中，$AE = 2\sqrt{3}$，$OE = r$，$AO = AG + GO = r + r = 2r$。  
   由勾股定理：$AE^2 + OE^2 = AO^2$，即 $(2\sqrt{3})^2 + r^2 = (2r)^2$。  
   $12 + r^2 = 4r^2 \Rightarrow 3r^2 = 12 \Rightarrow r = 2$。  
   于是 $AO = 4$。  
   由垂径定理，$M,N$ 关于 $AD$ 对称，$D$ 为 $MN$ 中点，$MD = \frac{1}{2}MN = \sqrt{3}$。  
   在 $\text{Rt}\triangle OMD$ 中，$OD = \sqrt{r^2 - MD^2} = \sqrt{4 - 3} = 1$。  
   因此 $AD = AO + OD = 4 + 1 = 5$。  
   又 $AB$ 是切线，$AE \perp OE$，由 $\triangle AOE \sim \triangle ABD$（或直接用三角函数），  
   由 $OE \perp AB$，$AD \perp BC$，得 $\angle BAD$ 共用，可证 $\text{Rt}\triangle AOE \sim \text{Rt}\triangle ABD$。  
   相似比：$\frac{AO}{AB} = \frac{AE}{AD} \Rightarrow AB = \frac{AO \cdot AD}{AE} = \frac{4 \times 5}{2\sqrt{3}} = \frac{10}{\sqrt{3}} = \frac{10\sqrt{3}}{3}$。  
   再由 $EF \parallel BC$，$\triangle AEF \sim \triangle ABC$，相似比 $\frac{AE}{AB} = \frac{2\sqrt{3}}{\frac{10\sqrt{3}}{3}} = \frac{3}{5}$。  
   则 $EF = \frac{3}{5}BC$。  
   又 $BC = 2BD$，在 $\text{Rt}\triangle ABD$ 中，$BD = \sqrt{AB^2 - AD^2} = \sqrt{\left(\frac{10\sqrt{3}}{3}\right)^2 - 5^2} = \sqrt{\frac{300}{9} - 25} = \sqrt{\frac{300-225}{9}} = \sqrt{\frac{75}{9}} = \frac{5\sqrt{3}}{3}$。  
   所以 $BC = 2BD = \frac{10\sqrt{3}}{3}$，  
   $EF = \frac{3}{5} \times \frac{10\sqrt{3}}{3} = 2\sqrt{3}$。  
   梯形 $EBCF$ 的高即为两平行线间距离，等于 $AD$ 上对应线段长：由 $EF \parallel BC$，高 $h = AD - (AO - r?)$ 更简单：$h$ 为点 $E$ 到 $BC$ 的距离，由于对称，$h$ 等于 $AD$ 减去 $A$ 到 $EF$ 的距离。在相似三角形中，$A$ 到 $EF$ 的高 $h_{A-EF} = \frac{3}{5} AD = 3$。故 $h = AD - h_{A-EF} = 5-3=2$。  
   梯形面积 $S = \frac{1}{2}(EF + BC) \times h = \frac{1}{2}\left(2\sqrt{3} + \frac{10\sqrt{3}}{3}\right) \times 2 = \left(\frac{6\sqrt{3}+10\sqrt{3}}{3}\right) = \frac{16\sqrt{3}}{3}$。

**点评/变式**：本题融汇切线、垂径、相似、勾股等核心几何知识，属于圆的综合证明与计算。突破口是(1)利用切线长定理与比例判定平行，(2)抓住$AG=r$沟通$AO=2r$和勾股关系求出半径，继而用相似传递长度。易错点在于混淆$AO$与$AG$的关系，须明确$G$在圆上，$OG=r$。变式训练中，可更改条件如“$AG=2r$”或“$MN$不过圆心”等，训练方程构建能力。
