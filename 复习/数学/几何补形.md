## 知识精要
- **几何补形**：将非标准几何体（棱台、斜棱柱、不规则多面体等）通过延长棱、添加截面等方式还原为标准几何体（锥体、正棱柱等），借助标准体的性质化难为易。
- **正棱台补锥**：正三棱台 $ABC-A_1B_1C_1$ 的上、下底面为正三角形且中心对齐，侧棱延长后必交于一点 $P$，补成正三棱锥 $P-ABC$。此时台体与锥体存在比例关系：相似比 $k = \frac{\text{上底边长}}{\text{下底边长}}$，体积比 $k^3$，对应高之比 $k$。
- **体积与高**：正三棱锥 $P-ABC$ 的体积 $V_{\text{锥}} = \frac{V_{\text{台}}}{1-k^3}$。求得锥高后，线面角可直接在锥体直角三角形中解决。
- **线面角定义**：斜线与其在平面内的射影所成的锐角。求法：作垂线构造直角三角形，用正切或正弦求解。关键量：斜线段在平面的射影长及垂线段（高）。

## 解题方法与套路
1. **识别可补形特征**  
   台体（正/一般棱台、圆台）、斜柱体、缺顶锥等，考虑用补形还原为锥或正柱。优先观察侧棱延长是否共点。
2. **定相似比 $k$**  
   对正棱台/圆台，$k = \frac{\text{上底线段长}}{\text{下底对应线段长}}$（边长、半径、高等）。如本题：$k = \frac{A_1B_1}{AB} = \frac{2}{6} = \frac13$。
3. **体积转化求锥高**  
   已知台体体积 $V_{\text{台}}$，由 $V_{\text{台}} = V_{\text{大锥}} - V_{\text{小锥}} = V_{\text{大锥}}(1-k^3)$ 得 $V_{\text{大锥}} = \frac{V_{\text{台}}}{1-k^3}$。再由锥体体积 $V = \frac13 S_{\text{底}} h_{\text{锥}}$ 解出 $h_{\text{锥}}$。
4. **转回线面角**  
   线面角在锥顶与底面垂足、底面射影构成的直角三角形中。正切 = $\frac{\text{锥高}}{\text{斜足到底面中心距离}}$。（台体中的 $A_1A$ 与平面 $ABC$ 所成角，即 $PA$ 与平面 $ABC$ 所成角，两者相等）
5. **验算**  
   检查相似比方向，避免上下底混淆导致体积倍数出错。

## 高频易错
- **相似比用反**：将 $k$ 取为 $\frac{\text{下底}}{\text{上底}}$，导致 $V_{\text{大锥}} = \frac{V_{\text{台}}}{k^3-1}$ 误算。牢记补形后大锥比小锥，$k$ 小于1时体积关系才正常。
- **台体体积公式误记**：正三棱台体积不是简单的 $\frac13 h (S_1 + \sqrt{S_1S_2}+S_2)$，需正确使用该公式或补形处理。
- **线面角找错**：将 $A_1A$ 与底面所成角误认为 $\angle A_1AM$（$M$ 为底面任意点），实际上垂足应为 $A$ 在底面射影，且因台体正三棱台，$A_1$ 在底面的射影在 $AD$ 延长线上（$D$ 为 $BC$ 中点），必须正确作出高线。
- **锥体内的比例混淆**：补形后，$PA_1:PA = k$，$P$ 到上、下底面距离之比也为 $k$。台高 $h = h_{\text{大锥}} - h_{\text{小锥}} = h_{\text{大锥}}(1-k)$，切勿错用为 $h=h_{\text{大锥}}(1-k^3)$。
- **数值计算**：面积、高、体积涉及根号运算时，谨防简单有理化失误，如 $\frac{4\sqrt3}{3}$ 的平方等。

## 代表题精讲
### 代表题1：2024·新课标Ⅱ 第7题
**题目**  
正三棱台 $ABC-A_1B_1C_1$ 体积为 $\frac{52}{3}$，$AB=6$，$A_1B_1=2$，求 $A_1A$ 与平面 $ABC$ 所成角的正切值。

**思路**  
补形法：将正三棱台侧棱延长交于一点 $P$，补成正三棱锥 $P-ABC$。此时所求线面角即 $PA$ 与底面 $ABC$ 所成角，且由体积比求出大锥高，再结合底面中心到顶点的距离求出正切值。

**步骤**  
1. 底面正三角形 $ABC$ 边长 $6$，面积 $S = \frac{\sqrt3}{4} \times 6^2 = 9\sqrt3$。  
2. 相似比 $k = \frac{A_1B_1}{AB} = \frac23?$ 这里注意：$A_1B_1=2$，$AB=6$，所以 $k = \frac{2}{6} = \frac13$。  
3. 大锥体积 $V_{P-ABC} = \frac{V_{\text{台}}}{1 - k^3} = \frac{\frac{52}{3}}{1 - (\frac13)^3} = \frac{\frac{52}{3}}{1 - \frac{1}{27}} = \frac{\frac{52}{3}}{\frac{26}{27}} = \frac{52}{3} \times \frac{27}{26} = 18$。  
4. 设正三棱锥高为 $H$，则 $\frac13 S H = 18 \Rightarrow \frac13 \times 9\sqrt3 \times H = 18 \Rightarrow H = \frac{18 \times 3}{9\sqrt3} = 2\sqrt3$。  
5. 正三角形 $ABC$ 中心为 $O$，则 $AO = \frac{\sqrt3}{3} \times 6 = 2\sqrt3$。  
6. 在 $\mathrm{Rt}\triangle POA$ 中，$\angle PAO$ 即为所求线面角，$\tan \angle PAO = \frac{H}{AO} = \frac{2\sqrt3}{2\sqrt3} = 1$。  
对应选项 B。

**点评/变式**  
- 补形法避免了直接计算台高和射影的繁琐几何构造，利用体积比直接得到锥高，化台为锥是关键。  
- 变式：若台体为一般三棱台、或已知线面角反求体积，同样优先补形寻找比例关系。  
- 注意：非正棱台补锥后，底面积与高仍可通过相似比解决，但底边不一定正对中心，此时仍需回到传统射影法求角，但体积转化同样有效。
