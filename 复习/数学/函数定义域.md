## 知识精要
- **函数定义域**：自变量 $x$ 的取值范围，是研究函数一切性质的前提。
  - 常见限制：分母不为零；偶次根号下被开方数非负；对数真数大于零、底数大于零且不等于 $1$；零次幂底数不为零等。
  - 复合函数 $y=f(g(x))$ 的定义域：由 $g(x)$ 的定义域与 $f(u)$ 对 $u$ 的要求取交集得到。
  - 实际应用或几何问题还需考虑实际意义。
- **函数值域**：函数值的集合，由定义域和对应关系共同决定。常见函数的值域：
  - $y=x$：$\mathbb{R}$
  - $y=\lg x$：$\mathbb{R}$
  - $y=a^x$（$a>0,a\neq1$）：$(0,+\infty)$
  - $y=\frac{1}{\sqrt{x}}$：$(0,+\infty)$
  - $y=10^{\lg x}$：化简为 $y=x$，但隐含定义域 $(0,+\infty)$，故值域为 $(0,+\infty)$。
- **函数的奇偶性**：
  - 定义域必须关于原点对称，否则既不是奇函数也不是偶函数。
  - 奇函数：$\forall x\in D,\ f(-x)=-f(x)$，图像关于原点对称。
  - 偶函数：$\forall x\in D,\ f(-x)=f(x)$，图像关于 $y$ 轴对称。
- **函数的单调性**：
  - 单调区间是定义域的子集。
  - 四则运算对单调性的影响：增 + 增 = 增；减 + 减 = 减；正数倍单调性不变；增函数的倒数在其同号区间内为减函数等。
  - 具体函数如 $y=x^3$ 在 $\mathbb{R}$ 上递增；$y=\frac{1}{x^3}$ 在 $(0,+\infty)$ 和 $(-\infty,0)$ 上分别递减。

## 解题方法与套路
1. **求函数定义域的基本步骤**  
   （1）列出全部约束条件（分母、根号、对数等）。  
   （2）解不等式（组）得到交集。  
   （3）用区间或集合表示，并检查是否关于原点对称（若后续要判断奇偶性）。

2. **判断函数奇偶性的通用流程**  
   （1）先求定义域，若不关于原点对称 → 非奇非偶，结束。  
   （2）若对称，计算 $f(-x)$，与 $f(x)$ 比较：  
       - $f(-x)=f(x)$ → 偶函数；  
       - $f(-x)=-f(x)$ → 奇函数；  
       - 均不成立 → 非奇非偶。  
   （3）对于含参或分段函数，可结合图像或特殊值辅助否定。

3. **利用单调性性质快速判断复合函数单调性**  
   - 若 $y=f(u)$ 与 $u=g(x)$ 单调性相同，则 $y=f(g(x))$ 递增；相反则递减（同增异减）。  
   - 利用基本初等函数的单调性及四则运算：如 $x^3$ 增，$\frac{1}{x^3}$ 在 $(0,+\infty)$ 减，则 $x^3 - \frac{1}{x^3}$ 为增函数（增 − 减 = 增 + 增 = 增）。

4. **求值域的方法**  
   - 先明确定义域。  
   - 利用基本函数值域、图像、单调性、换元法或反解法。  
   - 注意等价变形是否改变定义域（如 $y=10^{\lg x}$ 化简为 $y=x$ 时定义域缩小）。

## 高频易错
- **忽略隐含定义域**：如 $f(x)=x^3-\frac{1}{x^3}$ 中分式要求 $x\neq0$；$y=10^{\lg x}$ 中真数 $x>0$，若直接化简成 $y=x$ 会误认为定义域为 $\mathbb{R}$。
- **奇偶性判断的第一步缺失**：不先看定义域是否关于原点对称就直接用 $-x$ 代入，导致在原点不对称的函数上错误地套用结论。
- **单调性“整体递增”与“分别在区间上递增”混淆**：如 $y=\frac{1}{x^3}$ 在 $(0,+\infty)$ 和 $(-\infty,0)$ 上分别递减，但不能说在定义域上单调递减（因跨区间不连续）。本题 $f(x)=x^3-\frac{1}{x^3}$ 在 $(0,+\infty)$ 递增，也在 $(-\infty,0)$ 递增，仍为正确选项。
- **定义域与值域“相同”的理解偏差**：指集合相等，而非形式类似。如 $y=\lg x$ 定义域 $(0,+\infty)$、值域 $\mathbb{R}$，并不相同；$y=\frac{1}{\sqrt{x}}$ 定义域和值域都是 $(0,+\infty)$。
- **审题失误**：选项中出现“奇函数且在(0,+∞)递增”等组合描述时，需逐一验证两个性质是否同时成立，避免只判对一半就选。

## 代表题精讲
### 代表题一：2020-文-10
**题目**：已知 $f(x)=x^3-\frac{1}{x^3}$，判断其奇偶性及在 $(0,+\infty)$ 上的单调性。

**思路**：  
定义域含分式且为奇次幂，需关注 $x\neq0$。先求定义域并检查对称性，再用定义判断奇偶性。对于单调性，分别考虑 $x^3$ 的单调性与 $-\frac{1}{x^3}$ 的单调性，利用增函数减减函数仍为增函数的原则。

**步骤**：  
1. 定义域：由 $\frac{1}{x^3}$ 要求 $x\neq0$，得 $D=(-\infty,0)\cup(0,+\infty)$，关于原点对称。  
2. 奇偶性：$f(-x)=(-x)^3-\frac{1}{(-x)^3}=-x^3+\frac{1}{x^3}=-(x^3-\frac{1}{x^3})=-f(x)$，故为奇函数。  
3. 单调性：当 $x\in(0,+\infty)$ 时，$y=x^3$ 递增；$y=\frac{1}{x^3}$ 递减，因此 $-\frac{1}{x^3}$ 递增。两个增函数相加仍为增函数，所以 $f(x)$ 在 $(0,+\infty)$ 上单调递增。  
4. 综合选A。

**点评/变式**：  
本题为函数性质的基础综合，提醒我们奇偶性必须结合定义域对称性；利用简单函数的单调性及四则运算可快速判断复杂函数的单调性。变式：若改为 $f(x)=x^3+\frac{1}{x^3}$，单调性如何变化？仍为奇函数，但 $x^3$ 增、$\frac{1}{x^3}$ 减，减法变成加法后不再保证单调性统一，需用导数或单调性定义重新判断。

### 代表题二：2016-文-10
**题目**：函数 $y=10^{\lg x}$ 的定义域和值域均为 $(0,+\infty)$，下列哪个函数与之相同？  
选项：A. $y=x$　B. $y=\lg x$　C. $y=2^x$　D. $y=\frac{1}{\sqrt{x}}$

**思路**：  
依次求各选项的定义域与值域，与 $(0,+\infty)$ 进行比较，注意定义域受解析式自然约束，值域由对应关系决定。

**步骤**：  
1. A：$y=x$，定义域 $\mathbb{R}$，值域 $\mathbb{R}$，不符。  
2. B：$y=\lg x$，定义域 $(0,+\infty)$，值域 $\mathbb{R}$，不符。  
3. C：$y=2^x$，定义域 $\mathbb{R}$，值域 $(0,+\infty)$，不符。  
4. D：$y=\frac{1}{\sqrt{x}}$，要求 $x>0$，定义域 $(0,+\infty)$；当 $x>0$ 时 $\sqrt{x}>0$，其倒数仍大于 $0$，且可取得一切正实数，故值域 $(0,+\infty)$，符合要求。  
5. 正确选项为D。

**点评/变式**：  
本题陷阱在于 $y=10^{\lg x}$ 易化简为 $y=x$ 而忽略真数 $x>0$ 的隐含条件，导致定义域误判。解题时必须保持原式约束。变式：求 $y=\sqrt{\lg x}$ 的定义域与值域，应满足 $x>0$ 且 $\lg x\geq0$ 即 $x\geq1$，定义域 $[1,+\infty)$，值域 $[0,+\infty)$，与本题进行对比，体会“相同”的含义。
