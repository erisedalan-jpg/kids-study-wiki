## 知识精要
1. **极值与极值点**  
   设函数 $y=f(x)$ 在点 $x_0$ 的某邻域有定义，若对该邻域内任意 $x \neq x_0$，恒有 $f(x) < f(x_0)$，则称 $f(x_0)$ 为极大值，$x_0$ 为极大值点；若恒有 $f(x) > f(x_0)$，则称 $f(x_0)$ 为极小值，$x_0$ 为极小值点。极值是局部概念，最值是全局概念。

2. **可导函数极值的必要条件**  
   若函数 $f(x)$ 在 $x_0$ 处可导且取得极值，则 $f'(x_0)=0$。使 $f'(x)=0$ 的点称为驻点。极值点必为驻点或不可导点，反之不真。

3. **充分条件（判别法）**  
   - **第一充分条件**：在 $x_0$ 去心邻域内 $f'(x)$ 左正右负 ⇒ 极大值；左负右正 ⇒ 极小值；两侧同号 ⇒ 不是极值。  
   - **第二充分条件**：$f'(x_0)=0$ 且 $f''(x_0) \neq 0$，若 $f''(x_0)<0$ 则为极大值，$f''(x_0)>0$ 则为极小值。

4. **求极值的一般步骤**  
   ① 确定定义域；② 求导函数 $f'(x)$；③ 求驻点及不可导点；④ 用极值充分条件逐点判断；⑤ 将极值点代入原函数得极值。

5. **含参函数极值问题的核心思路**  
   对含参导数的零点、符号进行有序的分类讨论，通常以参数对导数零点的存在性、大小及两侧符号的影响为划分标准，结合极值定义列不等式求解。

## 解题方法与套路
1. **极值计算标准流程**  
   - 写出定义域 → 求导 → 通分因式分解 → 解方程 $f'(x)=0$ → 列表考察单调性 → 得出结论。  
   - 对指、对、幂混合函数，优先将导数整理为可判断符号的形式。

2. **证明极值点唯一性的套路**  
   - 目标转化为证明导函数 $f'(x)$ 在定义域内有唯一变号零点。  
   - 先判断 $f'(x)$ 的单调性（求二阶导分析）；  
   - 根据端点极限或特殊点函数值，用零点存在定理锁定唯一零点 $x_0$；  
   - 验证 $x_0$ 两侧 $f'(x)$ 异号，即得唯一极值点。

3. **含参求极值范围类问题的破题策略**  
   - 求出驻点（一般含参数表达式）；  
   - 写出极值关于参数的表达式 $g(a)$；  
   - 根据题意建立不等式 $g(a) < 0$ 或 $g(a) > 0$；  
   - 结合参数的自然限制（如使驻点有意义）及分类条件求解参数范围。

4. **如何避开讨论失分**  
   - 参数每取一个范围，必须明确导数的零点是否存在、有几个、大小顺序如何。  
   - 画数轴或思维导图梳理分类标准，防止漏掉“等于”的临界情形。

## 高频易错
1. **忘记定义域**  
   含对数 $\ln x$ 时未限定 $x>0$，导致驻点或极值点不在定义域内仍错误保留。

2. **不验证两侧符号变化**  
   仅由 $f'(x_0)=0$ 立即断定极值，忽略 $f'(x_0)$ 不变号的情形（如 $y=x^3$ 在 $x=0$ 处无极值）。

3. **混淆极值与最值**  
   极值点是区间内部的局部最值点，区间端点有可能成为最值但不一定是极值；求参数范围时误将极值条件代成最值条件。

4. **极值表达式代入错误**  
   求出极值点 $x=x_0$ 后忘记代回原函数 $f(x)$，而错将 $x_0$ 或导数表达式作为极值。

5. **含参讨论遗漏临界值**  
   如导数为 $f'(x)=e^x - a$，当 $a \leq 0$ 时 $f'(x)>0$ 恒成立，无极值点；若跳过 $a \leq 0$ 的情况直接设驻点 $\ln a$，将导致丢解或错解。

6. **抽象极值点的不等式求解**  
   在利用零点存在定理得到极值点 $x_0$ 满足的方程后，未能整体代换化简极值表达式，强行解近似根导致失分。

## 代表题精讲
### **题目1** （2024·新课标Ⅱ·16）
已知函数 $f(x) = e^x - ax - a^3$．  
（1）当 $a=1$ 时，求曲线 $y=f(x)$ 在点 $(1,f(1))$ 处的切线方程；  
（2）若 $f(x)$ 有极小值，且极小值小于 $0$，求 $a$ 的取值范围．

**思路**  
（1）求导得斜率，用点斜式（或直线一般式）写出切线。  
（2）极小值存在 ⇒ 导数有变号零点。先对 $a$ 分类确定是否存在极值点，求出极值表达式，利用极小值 $<0$ 建立不等式解出 $a$ 范围。

**步骤**  
**（1）** 当 $a=1$ 时，$f(x)=e^x - x -1$．  
导数为 $f'(x)=e^x - 1$，$f'(1)=e - 1$．切点坐标 $(1,e - 2)$．  
切线方程：$y - (e-2) = (e-1)(x-1)$，化为一般式：$(e-1)x - y - 1 =0$．  
**（2）** $f'(x)=e^x - a$．  
- 当 $a \leq 0$ 时，$f'(x)>0$ 恒成立，$f(x)$ 单调递增，无极小值，舍去．  
- 当 $a > 0$ 时，令 $f'(x)=0$，得唯一驻点 $x = \ln a$．  
  当 $x < \ln a$ 时 $f'(x) < 0$，当 $x > \ln a$ 时 $f'(x) > 0$，  
  因此 $f(x)$ 在 $x=\ln a$ 处取得极小值．  
  极小值 $f(\ln a) = a - a\ln a - a^3$．  
  由题设有 $a - a\ln a - a^3 < 0$，结合 $a>0$，两边同除以 $a$ 得  
  $1 - \ln a - a^2 < 0$，即 $\ln a + a^2 > 1$．  
  记 $g(a) = \ln a + a^2$，$a>0$，$g(a)$ 单调递增，且 $g(1)=1$．  
  故不等式解集为 $a > 1$．  
综上，$a$ 的取值范围是 $(1, +\infty)$．

**点评/变式**  
本题型为“由极值性质求参数范围”的典型题。分类讨论的第一步至关重要：导数零点参数 $a$ 必须与零比较。变式常把极小值条件改为极大值，或极值点与某点比较，解法本质均为“含参不等式”。

### **题目2** （2019·全国卷文·21（1））
已知函数 $f(x) = (x-1)\ln x - x - 1$．  
证明：$f(x)$ 存在唯一的极值点．

**思路**  
要证唯一极值点，等价于证明导函数 $f'(x)$ 在定义域内有唯一零点，且异号。本题用二阶导判定 $f'(x)$ 单调，再用零点定理锁定唯一零点。

**步骤**  
函数定义域为 $(0, +\infty)$．  
求导：$f'(x) = \ln x + \frac{x-1}{x} - 1 = \ln x - \frac{1}{x}$．  
再求二阶导：$f''(x) = \frac{1}{x} + \frac{1}{x^2} > 0$ 在 $(0,+\infty)$ 恒成立，  
故 $f'(x)$ 在 $(0,+\infty)$ 上单调递增．  
取点考察：$f'(1) = -1 < 0$，$f'(2) = \ln 2 - \frac{1}{2} > 0$（因 $\ln 2 > \frac{1}{2}$）．  
由零点存在定理和单调性，$f'(x)$ 在 $(1,2)$ 内存在唯一零点，记作 $x_0$．  
当 $0 < x < x_0$ 时，$f'(x) < f'(x_0) = 0$；当 $x > x_0$ 时，$f'(x) > 0$．  
所以 $f(x)$ 在 $x_0$ 处取得极小值，该极值点唯一．

**点评/变式**  
证明“极值点唯一”的关键在于转化到导数的零点唯一。二阶导判定单调性、特值验证零点存在性是组合必背套路。若变为证明“存在唯一的极大值点”，只需将导数的符号变化反述。
