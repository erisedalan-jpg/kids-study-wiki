## 知识精要
- **导数的几何意义**：函数 $y=f(x)$ 在 $x=x_0$ 处的导数 $f'(x_0)$ 表示曲线在点 $(x_0,f(x_0))$ 处切线的斜率。
- **切线方程**：若切点 $(x_0, f(x_0))$ 已知，则切线方程为 $y - f(x_0) = f'(x_0)(x - x_0)$。若切点未知，设切点坐标后利用条件求参。
- **极值的求解**：  
  1. 求导函数 $f'(x)$；  
  2. 解 $f'(x)=0$，得到可能的极值点；  
  3. 判断 $f'(x)$ 在每个根左右的符号：左正右负为极大值点，左负右正为极小值点；  
  4. 极值为 $f(x_0)$（不可导点需单独验证，真题中均为可导情形）。
- **两直线位置关系与斜率**：直线 $y=k_1x+b_1$ 与 $y=k_2x+b_2$ 垂直 $\iff k_1k_2=-1$；平行 $\iff k_1=k_2$ 且 $b_1 \neq b_2$。  
- **切线在坐标轴上的截距**：切线方程 $y=kx+b$，在 $x$ 轴上的截距即令 $y=0$ 解得的 $x=-\dfrac{b}{k}$（$k\neq 0$）；在 $y$ 轴上的截距为 $b$。

## 解题方法与套路
1. **求切线斜率**：求出导函数 $f'(x)$，代入切点横坐标 $x_0$，得斜率 $k=f'(x_0)$。复合函数求导注意链式法则，如 $(e^{ax})' = ae^{ax}$。
2. **设切点建方程**：若切点未知或需用切点表示相关量，设切点为 $(x_0,f(x_0))$，写出切线方程 $y-f(x_0)=f'(x_0)(x-x_0)$，再根据题设条件（如斜率正负、与某直线垂直、截距范围等）建立关于 $x_0$ 的方程或函数。
3. **条件转化**：垂直条件直接转化为 $k_1k_2=-1$ 求参；斜率负数条件转化为 $f'(x_0)<0$，解出自变量 $x_0$ 的范围。
4. **求截距的范围**：将截距表示为切点横坐标的函数（如 $x$ 轴截距 $d(x_0)=x_0-\dfrac{f(x_0)}{f'(x_0)}$），再在题设限定的 $x_0$ 范围内，利用导数求该函数的值域（最值问题）。
5. **求解极值**：按“求导→求驻点→判单调→得极值”四步走。复杂函数的极值需正确运用求导法则（乘积、商、复合）和符号判断表。

## 高频易错
- **求导公式混淆**：例如 $f(x)=x^2 e^{-x}$ 的导数，需用乘法的求导法则：$f'=2x e^{-x}+x^2 e^{-x}(-1)$，不可遗漏复合部分的内导。
- **混淆极值点与导数为零的点**：$f'(x_0)=0$ 只是可导函数取得极值的必要条件；必须验证左右符号改变，否则可能只是驻点。如 $f(x)=x^3$ 在 $x=0$ 处导数为 $0$ 但无极值。
- **切线问题忽略定义域**：切点横坐标必须让原函数和导函数有意义，同时若切线斜率以负数等条件限定了 $x_0$ 的范围，讨论截距时必须在该范围内进行。
- **截距概念不清**：截距不是距离，可为负数。在 $x$ 轴上的截距是直线与 $x$ 轴交点的横坐标，故 $y=0$ 解出 $x$ 即可，不要带绝对值。
- **垂直条件不规范使用**：一般直线方程化为斜截式后，斜率相乘为 $-1$；若给出 $x+2y+1=0$，其斜率为 $-\dfrac{1}{2}$，不要直接取系数比而忽略符号。
- **默认切线斜率存在**：若题干未说明，需考虑斜率不存在的情形。但导数类问题通常隐含可导，若遇折点需单独验证。（本考点真题暂未涉及）

## 代表题精讲
### **题目** (2013-文-21): 已知 $f(x)=x^2e^{-x}$，求极值；当切线斜率为负时，求切线在 $x$ 轴上截距的取值范围。
**思路**：第（Ⅰ）问按极值标准流程：求导→因式分解找驻点→分段判符号→下结论。第（Ⅱ）问先用导数几何意义写出斜率 $k=f'(x_0)$，由 $k<0$ 解出切点横坐标范围；再写出切线方程并令 $y=0$ 求 $x$ 轴截距的表达式；将该截距视为关于 $x_0$ 的函数，在已得范围上求值域。  
**步骤**：  
（Ⅰ）  
$f'(x)=2xe^{-x} - x^2 e^{-x} = e^{-x}(2x - x^2)$，令 $f'(x)=0$，得 $x=0$ 或 $x=2$。  
列表：$x\in(-\infty,0)$ 时 $f'<0$，递减；$(0,2)$ 时 $f'>0$，递增；$(2,+\infty)$ 时 $f'<0$，递减。  
故极小值 $f(0)=0$，极大值 $f(2)=\dfrac{4}{e^2}$。  

（Ⅱ）  
设切点 $(x_0, x_0^2 e^{-x_0})$，则斜率 $k=f'(x_0)=e^{-x_0}(2x_0 - x_0^2)$。  
令 $k<0$，即 $2x_0 - x_0^2<0$（因 $e^{-x_0}>0$），解得 $x_0<0$ 或 $x_0>2$。  
切线方程：$y - x_0^2 e^{-x_0} = k(x - x_0)$。  
令 $y=0$，得 $x$ 轴截距 $d = x_0 - \dfrac{x_0^2 e^{-x_0}}{k} = x_0 - \dfrac{x_0^2 e^{-x_0}}{e^{-x_0}(2x_0 - x_0^2)} = x_0 - \dfrac{x_0^2}{2x_0 - x_0^2} = x_0 + \dfrac{x_0}{x_0 - 2}$。  
化简得 $d = \dfrac{x_0^2 - 2x_0 + x_0}{x_0 - 2} = \dfrac{x_0(x_0 - 1)}{x_0 - 2}$。  
构造 $g(x) = \dfrac{x(x-1)}{x-2}$，定义域为 $(-\infty,0) \cup (2,+\infty)$，求其值域。  
$g'(x)=\dfrac{x^2 - 4x + 2}{(x-2)^2}$，由 $g'(x)=0$ 得 $x=2\pm\sqrt{2}$。  
结合定义域，$x=2-\sqrt{2}<0$ 是极小值点；$x=2+\sqrt{2}>2$ 是极小值点（注意两侧单调性）。  
计算极限和极值：  
当 $x\to -\infty$，$g(x)\to +\infty$；$g(2-\sqrt{2}) = 3+2\sqrt{2}$；当 $x\to 0$（左）时，$g(x)\to 0$。故 $x<0$ 时值域 $[3+2\sqrt{2}, +\infty)$。  
当 $x\to 2^+$，$g(x)\to +\infty$；$g(2+\sqrt{2}) = 3-2\sqrt{2}$ 为负；当 $x\to +\infty$，$g(x)\to +\infty$。故 $x>2$ 时值域 $[3-2\sqrt{2}, +\infty)$。  
因此截距的取值范围是 $[3-2\sqrt{2}, +\infty)$。  
**点评/变式**：本题综合了极值与切线截距，核心是把截距转化为切点横坐标的函数，再借助导数求值域。若将截距改为“$y$ 轴截距”或“切线在两轴截距之和”等，方法完全一致；注意函数化简和定义域限制的来源。

### **题目** (2008-理-14): 曲线 $y=e^{ax}$ 在点 $(0,1)$ 处的切线与直线 $x+2y+1=0$ 垂直，求 $a$。  
**思路**：直接求导得切线斜率，利用点斜式写出切线方程，由垂直关系建立斜率等式求解。  
**步骤**：  
$y' = ae^{ax}$，在 $x=0$ 处斜率 $k = ae^{0} = a$。  
切线方程为 $y-1 = a(x-0)$，即 $ax - y + 1 = 0$，其斜率为 $a$。  
已知直线 $x+2y+1=0$ 可化为 $y = -\dfrac{1}{2}x - \dfrac{1}{2}$，斜率为 $-\dfrac{1}{2}$。  
由垂直条件：$a \cdot \left(-\dfrac{1}{2}\right) = -1$，解得 $a = 2$。  
**点评/变式**：属于基础送分题，考查导数几何意义与直线位置关系。变式可改为“平行”则 $a=-\dfrac{1}{2}$，或把点改为其它横坐标，只需正确计算导数值即可。
