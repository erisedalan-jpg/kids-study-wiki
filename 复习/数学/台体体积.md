## 知识精要
1. **台体体积公式**：对于上、下底面面积分别为 $S_1$、$S_2$，高为 $h$ 的台体，其体积为  
   $$V = \frac{1}{3}h \left( S_1 + S_2 + \sqrt{S_1 S_2} \right)$$  
   适用条件：棱台、圆台统一公式，关键是把上下底面积和高算准。
2. **正三棱台的结构特征**：  
   - 上、下底面是相似的正三角形，对应边平行，中心连线与底面垂直。  
   - 侧棱相等，侧面是全等的等腰梯形。  
   - 高 $h$ 是上、下底面中心间的距离，也是进一步计算线面角的桥梁。
3. **线面角定义**：斜线与它在平面内的射影所夹的锐角。若侧棱与底面所成角为 $\theta$，则 $\tan\theta = \dfrac{\text{棱台高（或棱锥高）}}{\text{侧棱在底面内的投影长}}$。

## 解题方法与套路
1. **直接法（用台体公式）**  
   - 步骤①：由底面形状计算上、下底面积 $S_1$、$S_2$。正三角形面积 $S=\frac{\sqrt{3}}{4}a^2$。  
   - 步骤②：将 $V$、$S_1$、$S_2$ 代入台体体积公式，解出高 $h$。  
   - 步骤③：在正棱台的下底面上，找到上底顶点（或上底中心）的投影点，利用平面几何计算投影与侧棱端点构成的线段长。  
   - 步骤④：在由高 $h$ 和投影长组成的直角三角形中，利用 $\tan\theta = \frac{h}{\text{投影长}}$ 求出线面角的正切值。
2. **补形法（还原为棱锥）**  
   - 步骤①：将正三棱台补成正三棱锥 $P-ABC$（延长侧棱交于一点）。  
   - 步骤②：由上下底边长之比得到相似比，推出小棱锥与大棱锥的体积比或高之比。  
   - 步骤③：利用“台体体积 = 大棱锥体积 $-$ 小棱锥体积”求出大棱锥的高（即原棱锥的高）。  
   - 步骤④：直接在补出的正三棱锥中计算侧棱与底面的线面角，正切值 $\tan\theta = \frac{\text{锥高}}{\text{底面外接圆半径}}$（若侧棱投影正好是底面外接圆半径）。此即原台体侧棱与底面所成角。

## 高频易错
- **台体体积公式错记**：漏乘 $\frac13$ 或忘掉 $\sqrt{S_1 S_2}$ 项，把“$S_1+S_2+\sqrt{S_1S_2}$”记成“$S_1+S_2$”或“$\frac{S_1+S_2}{2}$”。  
- **线面角定位错误**：误把侧面与底面的夹角当成侧棱与底面的夹角。侧棱的线面角要用棱与它在底面上的射影构成的角，而不是侧面上的斜高。  
- **投影点找不准**：正三棱台顶点在底面的投影不在底面顶点，而在底面三角形中心与顶点连线的某个分点上。作辅助线时应从侧棱上端点向底面作垂线，垂足位置可由相似形确定。  
- **面积计算陷阱**：正三角形面积公式 $\frac{\sqrt{3}}{4}a^2$ 中的 $\frac{\sqrt{3}}{4}$ 容易与 $\frac12 ab\sin C$ 混淆，导致算错。  
- **数值计算粗心**：体积或高为分数时化简不彻底，比如本该约分成 $\frac{4\sqrt{3}}{3}$，却保留了复杂根式形式，影响后续求正切的准确性。

## 代表题精讲
**题目**（2024·新课标Ⅱ卷·7）：已知正三棱台 $ABC-A_1B_1C_1$ 的体积为 $\frac{52}{3}$，$AB=6$，$A_1B_1=2$，则 $A_1A$ 与平面 $ABC$ 所成角的正切值为？  
**思路**：先求上下底面积，代入台体体积公式求高，再找侧棱在底面上的投影长度，最后在直角三角形中求正切。亦可补形为正三棱锥整体求解。

**步骤（直接法）**  
1. 计算面积：  
   $S_{\triangle ABC} = \frac{\sqrt{3}}{4}\times 6^2 = 9\sqrt{3}$，  
   $S_{\triangle A_1B_1C_1} = \frac{\sqrt{3}}{4}\times 2^2 = \sqrt{3}$。  
2. 由 $V = \frac{1}{3}h\big(9\sqrt{3} + \sqrt{3} + \sqrt{9\sqrt{3}\cdot\sqrt{3}}\big) = \frac{1}{3}h(9\sqrt{3}+\sqrt{3}+3\sqrt{3}) = \frac{1}{3}h\cdot 13\sqrt{3} = \frac{13\sqrt{3}}{3}h$。  
   又已知 $V = \frac{52}{3}$，故 $\frac{13\sqrt{3}}{3}h = \frac{52}{3}$，解得 $h = \frac{4\sqrt{3}}{3}$。  
3. 如图，取 $BC$、$B_1C_1$ 的中点 $D$、$D_1$，则 $AD = 3\sqrt{3}$，$A_1D_1 = \sqrt{3}$。  
   从 $A_1$ 向底面 $ABC$ 作垂线，垂足 $M$ 在 $AD$ 上。设 $AM = x$，由相似关系或投影差量可推出 $AM = AD - A_1D_1 = 3\sqrt{3} - \sqrt{3} = 2\sqrt{3}$（需注意这里实际为底面中心到顶点的距离之差，因结构对称，侧棱 $A_1A$ 在底面投影即为 $AM$ 的长度）。  
4. 在 $\text{Rt}\triangle A_1AM$ 中，$A_1M = h = \frac{4\sqrt{3}}{3}$，$AM = 2\sqrt{3}$，  
   $\tan\angle A_1AM = \dfrac{A_1M}{AM} = \dfrac{\frac{4\sqrt{3}}{3}}{2\sqrt{3}} = \frac{2}{3}$？此处严谨验算：$2\sqrt{3} = \frac{6\sqrt{3}}{3}$，比值为 $\frac{4\sqrt{3}}{3} \div \frac{6\sqrt{3}}{3} = \frac{4}{6} = \frac{2}{3}$。但真题解析得到 $1$，说明投影长算法另有说法。实际上 $A_1$ 的投影并非恰好在 $AD$ 上且 $AM$ 不等于 $AD-A_1D_1$。正确做法：正三棱台侧面投影应对应底面中心到顶点距离之差的一半？重温解析：分别过 $A_1$、$D_1$ 作底面垂线，设 $AM=x$，由对称性 $A_1$ 到底面中心 $O$ 的水平距离差，以及利用相似，可列式得到 $AM=\frac{4\sqrt{3}}{3}$，然后 $\tan =1$。由于直接法涉及复杂平面几何，补形法更清晰。补形：将三棱台补成正三棱锥 $P-ABC$。由 $A_1B_1:AB=2:6=1:3$，得小棱锥与大棱锥体积比 $1:27$，台体占 $26$ 份，$V_{\text{台}}=\frac{52}{3}$，故大棱锥体积 $V_{P-ABC}=18$，又大棱锥高满足 $V=\frac{1}{3}H\cdot 9\sqrt{3}=18 \Rightarrow H=2\sqrt{3}$。侧棱 $PA$ 与底面夹角 $\theta$ 满足 $\tan\theta = \frac{H}{OA}$，其中 $OA$ 为底面外接圆半径，正三角形边长 $6$ 时 $OA=\frac{6}{\sqrt{3}}=2\sqrt{3}$，故 $\tan\theta=1$。

**点评**：台体线面角问题优先考虑补形法，能直接利用锥体的简洁几何关系，避免复杂的投影推算。若用台体体积公式直接求高，则务必理清顶点投影与底面中心、边中点间的几何关系，防止投影长度计算失误。  
**变式**：若将该正三棱台改为圆台，已知上、下底半径和体积，求母线或侧棱（此处为圆台无侧棱，可求母线与底面夹角），则同理用补形法或直接法，投影关系更简单（投影即为半径差）。
