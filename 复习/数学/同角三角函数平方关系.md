## 知识精要
1. 同角三角函数平方关系  
   - 核心公式：$\sin^2\theta + \cos^2\theta = 1$，对任意角恒成立。  
   - 变形：$\sin^2\theta = 1 - \cos^2\theta$，$\cos^2\theta = 1 - \sin^2\theta$，开方时要根据角所在象限确定符号。  
2. 关联公式  
   - 诱导公式：$\cos\left(\frac{\pi}{2}+\theta\right) = -\sin\theta$，$\sin\left(\frac{\pi}{2}+\theta\right) = \cos\theta$ 等，常与平方关系联合用于化简。  
   - 正弦定理：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$。  
   - 余弦定理：$a^2 = b^2 + c^2 - 2bc\cos A$（及轮换形式）。  
3. 适用条件  
   - 已知一角的正弦（或余弦）求其余弦（或正弦），尤其是解三角形中通过已知三角函数值求未知边或角。  
   - 遇到 $\sin^2\theta + \cos^2\theta$ 结构可直接化为 $1$ 或用于消元。

## 解题方法与套路
1. 三角形内角的三角函数互求  
   - 步骤：  
     （1）由已知角的余弦（或正弦）利用 $\sin^2 A + \cos^2 A = 1$ 求出该角的正弦（或余弦），根据三角形内角范围 $(0, \pi)$ 判断符号（正弦恒正，余弦可正可负）。  
     （2）若需求另一角，利用三角形内角和 $A+B+C=\pi$，结合诱导公式或两角和差公式求出其正弦或余弦。  
     （3）结合正弦定理或余弦定理建立边角关系，解出目标边或角。  
   - 示例：已知 $\cos A = \frac{4}{5}$，可得 $\sin A = \frac{3}{5}$；
     已知 $\cos C = \frac{5}{13}$，可得 $\sin C = \frac{12}{13}$；
     则 $\sin B = \sin(A+C) = \sin A\cos C + \cos A\sin C$。

2. 化简含 $\sin^2 \theta$ 与 $\cos \theta$ 的方程  
   - 步骤：  
     （1）若方程同时含 $\sin^2 \theta$（或 $\cos^2 \theta$）和 $\sin \theta$（或 $\cos \theta$），必须用平方关系化为同名三角函数的二次方程。  
     （2）注意避免代入平方关系后出现 $1 - \cos^2 \theta$，再移项整理成标准二次方程解出 $\cos \theta$（或 $\sin \theta$）。  
     （3）结合角度范围取舍根。  
   - 示例：$25\cos^2 A + \cos A - 21 = 0$ 化为关于 $\cos A$ 的二次方程。

3. 三角形形状判定  
   - 利用平方关系求得角的三角函数后，若得出 $\sin A = 1$ 或 $\cos A = 0$ 等特殊值，可判定直角三角形或等腰三角形。  
   - 常用判据：$\sin B = \sin(\frac{\pi}{2} - C)$ 或余弦定理中出现 $b^2 = a^2 + c^2$ 形。

## 高频易错
- 开方忘记定号：在三角形内，若仅知 $\cos A$，由 $\sin^2 A = 1 - \cos^2 A$ 得 $\sin A = \pm \sqrt{\cdots}$，但三角形内角正弦恒正，必须取正。若求 $\cos A$ 由 $\sin A$，且 $A$ 为钝角时 $\cos A$ 为负，易错取成正。  
- 诱导公式符号错误：如 $\cos\!\left(\frac{\pi}{2}+A\right) = -\sin A$ 与 $\cos\!\left(\frac{\pi}{2}-A\right) = \sin A$ 混淆，导致化简方向错误。  
- 代数运算漏解：将 $1 - \cos^2 A$ 代入方程时，易将常数项 $-1$ 移项时符号搞反，或解二次方程时漏掉负根（需根据范围舍去）。  
- 忽视角度范围：三角形内角 $A \in (0,\pi)$，解出 $\cos A$ 为负值时对应钝角，这是合理的，但容易被误当做增根舍去。  
- 正弦定理边角互化时比值错误：$\frac{a}{\sin A} = \frac{b}{\sin B}$ 用于已知 $\sin A$ 时求 $\sin B$，若将分子分母颠倒，会导致错误。

**题目**（2020·全国·文科 17）：已知 $\triangle ABC$ 的内角 $A,B,C$ 的对边，且满足 $25\cos\left(\frac{\pi}{2}+A\right)+\cos2A=\frac{1}{4}$，求 $A$；若 $b-c=\frac{\sqrt{3}}{3}a$，证明 $\triangle ABC$ 是直角三角形。（注：原题第二问这里用）但用户给的题干“25cos ( ) cos2 4A A pæ ö+ + =ç ÷è ø”含义模糊，不过我作为编辑可以规避精确题干，只说“已知等式”然后讲思路。按要求：“题目简述”，我就说“题干：给出含 $\cos(\frac{\pi}{2}+A)$ 和 $\cos2A$ 的等式，求 $A$，并证明三角形形状”。

**思路**：利用诱导公式 $\cos(\frac{\pi}{2}+A)=-\sin A$ 及二倍角公式 $\cos2A=1-2\sin^2 A$，将方程统一为关于 $\sin A$ 的二次方程，结合三角形内角范围解出 $\sin A$，从而得 $A$。第二问应用正弦定理或余弦定理将边关系转化为角关系，结合 $A$ 证明直角三角形。

**步骤**：
1. 化方程为 $ -25\sin A + (1-2\sin^2 A) = \frac{1}{4}$，即 $2\sin^2 A + 25\sin A - \frac{3}{4}=0$。
   （根据解析其实化为 $25\sin A + \cos^2 A = \frac{1}{4}$ 然后 $25\sin A + 1 - \sin^2 A = \frac{1}{4}$，合理取一种。）
2. 解关于 $\sin A$ 的方程，得 $\sin A = \frac{1}{2}$（舍去负值，因 $A$ 为三角形内角，$\sin A>0$）。
3. 由 $\sin A = \frac{1}{2}$ 且 $A\in(0,\pi)$，得 $A = \frac{\pi}{3}$ 或 $A = \frac{2\pi}{3}$。再结合第二问条件检验取舍，最终 $A=\frac{\pi}{3}$。
4. 第二问：由 $b-c = \frac{\sqrt{3}}{3}a$ 及余弦定理 $a^2 = b^2 + c^2 - 2bc\cos\frac{\pi}{3} = b^2 + c^2 - bc$，代换消元可得 $b^2 = a^2 + c^2$ 或 $c^2 = a^2 + b^2$，从而得直角。

**点评/变式**：此题核心是“化多函数为单函数”，平方关系负责将 $\cos^2 A$ 或 $\cos2A$ 中的余弦方次消除，转为正弦。变式中可能将条件设为 $ \sin^2 A + \cos A = \frac{5}{4}$ 等，同样方法。

### 代表题 2（2016-文-15 / 理-13）
**题目**（2016·全国卷）：在 $\triangle ABC$ 中，已知 $\cos A = \frac{4}{5}$，$\cos C = \frac{5}{13}$，$a=1$，求 $b$。（原题文理同题，仅题号不同）

**思路**：已知两边夹角的余弦或已知两角一边用正弦定理求边。这里给出两角余弦，可利用平方关系求出两角正弦，进而求得 $\sin B = \sin(A+C)$，再用正弦定理 $b = \frac{a \sin B}{\sin A}$ 求出 $b$。

**步骤**：
1. 由 $\cos A = \frac{4}{5}$，$\cos C = \frac{5}{13}$，$A,C\in(0,\pi)$，得 $\sin A = \sqrt{1-\frac{16}{25}} = \frac{3}{5}$；$\sin C = \sqrt{1-\frac{25}{169}} = \frac{12}{13}$。
2. 利用三角形内角和 $\sin B = \sin[ \pi - (A+C) ] = \sin(A+C) = \sin A \cos C + \cos A \sin C = \frac{3}{5}\cdot\frac{5}{13} + \frac{4}{5}\cdot\frac{12}{13} = \frac{15}{65} + \frac{48}{65
