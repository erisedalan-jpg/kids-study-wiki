## 知识精要
- **向量加法**：三角形法则（首尾顺次相接）与平行四边形法则（共起点对角线）；满足交换律 $\vec{a}+\vec{b}=\vec{b}+\vec{a}$ 与结合律 $(\vec{a}+\vec{b})+\vec{c}=\vec{a}+(\vec{b}+\vec{c})$.
- **向量减法**：三角形法则，共起点时，连接终点指向**被减向量**；$\overrightarrow{AB} - \overrightarrow{AC} = \overrightarrow{CB}$.
- **几何意义**：平面图形中任意边、对角线等均可通过选定基底的加减组合唯一表示；封闭图形中首尾相接的向量和为零向量.
- **数量积**：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$，坐标运算 $\vec{a}\cdot\vec{b}=x_1x_2+y_1y_2$；垂直时 $\vec{a}\cdot\vec{b}=0$.
- **基向量法**：选取两个不共线且模与夹角已知（常用垂直）的向量作为基底，平面内任一向量可写成 $\lambda \vec{e}_1 + \mu \vec{e}_2$，然后用基底运算.

## 解题方法与套路
1. **选定基底**：优先取有公共起点、模长已知、夹角确定（矩形/正方形中常为垂直）的两个向量，如 $\overrightarrow{AB},\overrightarrow{AD}$.
2. **向量表示（核心用加减法）**：
   - 利用加法：$\overrightarrow{目标} = \overrightarrow{已知首尾相接的若干向量之和}$；
   - 利用减法：共起点向量相减，得“终点连，指向被减”；
   - 利用数乘：中点、分点条件化为基底的组合系数.
3. **展开计算**：
   - 代入数量积表达式，按分配律展开；
   - 利用基底模长平方（如 $|\overrightarrow{AB}|^2$）和基底间点积（垂直时为 $0$）化简；
   - 必要时建系，将向量坐标化，用坐标运算验证.
4. **检查几何条件**：确认边的关系、点的位置未被误用（如中点系数 $\frac12$ 的方向）.

## 高频易错
- **减法方向反**：$\overrightarrow{AB} - \overrightarrow{AC}$ 得到的是 $\overrightarrow{CB}$，而非 $\overrightarrow{BC}$；口诀“连终点，指被减”.
- **中点向量误写**：$E$ 为 $CD$ 中点时，$\overrightarrow{DE} = \frac12 \overrightarrow{DC}$，方向不能写反为 $\overrightarrow{EC}$.
- **基底选取不当**：未利用垂直、模长等已知条件，导致数量积展开项过多或无法化简.
- **展开漏项或符号错**：$(\vec{a}+\vec{b})\cdot(\vec{c}+\vec{d})$ 展开时丢交叉项，或去括号未变号.
- **混淆向量与常数**：垂直时 $\vec{a}\cdot\vec{b}=0$，但展开中不能遗忘该项，也不能将“零向量”与数字 $0$ 等同直接忽略向量的线性组合.

## 代表题精讲
**题目**（2013 理 13）  
已知正方形 $ABCD$ 的边长为 $2$，$E$ 为 $CD$ 的中点，则 $\overrightarrow{AE}\cdot\overrightarrow{BD}=$ ______.

**思路**  
正方形中 $AB \perp AD$，模长均为 $2$，可选用 $\overrightarrow{AB}, \overrightarrow{AD}$ 为基底。将 $\overrightarrow{AE}$ 与 $\overrightarrow{BD}$ 用基底加减表示，再算数量积，利用垂直使交叉项消失.

**步骤**  
1. 设基底 $\overrightarrow{AB} = \vec{a},\ \overrightarrow{AD} = \vec{b}$，则 $|\vec{a}|=|\vec{b}|=2,\ \vec{a}\cdot\vec{b}=0$.
2. 表示 $\overrightarrow{AE}$：$E$ 为 $CD$ 中点，$\overrightarrow{DE} = \frac12\overrightarrow{DC} = \frac12\vec{a}$，  
   $\overrightarrow{AE} = \overrightarrow{AD} + \overrightarrow{DE} = \vec{b} + \frac12\vec{a}$.
3. 表示 $\overrightarrow{BD}$：共起点 $B$、$D$，用减法 $\overrightarrow{BD} = \overrightarrow{AD} - \overrightarrow{AB} = \vec{b} - \vec{a}$.
4. 计算数量积：  
   $\overrightarrow{AE}\cdot\overrightarrow{BD} = \left(\vec{b} + \frac12\vec{a}\right)\cdot\left(\vec{b} - \vec{a}\right)$  
   $= \vec{b}\cdot\vec{b} - \vec{b}\cdot\vec{a} + \frac12\vec{a}\cdot\vec{b} - \frac12\vec{a}\cdot\vec{a}$  
   $= |\vec{b}|^2 - 0 + 0 - \frac12|\vec{a}|^2 = 2^2 - \frac12\cdot 2^2 = 4 - 2 = 2$.
5. 得 $\overrightarrow{AE}\cdot\overrightarrow{BD}=2$.

**点评/变式**  
本题是“基底加减+垂直”的典型考法，核心在于用减法准确写出对角线向量。若正方形换成边长 $a$ 的正方形，结果为 $\frac12 a^2$；换成矩形且邻边长为 $a,b$，则结果依赖于边长和夹角，需保留交叉项。也可建系：$A(0,0), B(2,0), D(0,2), C(2,2), E(1,2)$，得 $\overrightarrow{AE}=(1,2),\ \overrightarrow{BD}=(-2,2)$，点积 $1\cdot(-2)+2\cdot2=2$，作为验算.
