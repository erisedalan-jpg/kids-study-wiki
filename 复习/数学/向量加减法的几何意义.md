## 知识精要
- **向量加法的几何意义**：三角形法则（首尾相连，和向量由起点指向终点）与平行四边形法则（共起点，和向量为对角线）。  
  坐标表示：若 $\vec{a}=(x_1,y_1)$，$\vec{b}=(x_2,y_2)$，则 $\vec{a}+\vec{b}=(x_1+x_2,y_1+y_2)$。  
- **向量减法的几何意义**：$\vec{a}-\vec{b}$ 表示以 $\vec{b}$ 的终点指向 $\vec{a}$ 的终点的向量（共起点时）；等于“被减向量加上减向量的相反向量”。  
  坐标表示：$\vec{a}-\vec{b}=(x_1-x_2,y_1-y_2)$。  
- **数量积**：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$；坐标 $\vec{a}\cdot\vec{b}=x_1x_2+y_1y_2$。  
- **向量垂直的充要条件**：$\vec{a}\perp\vec{b}\Leftrightarrow \vec{a}\cdot\vec{b}=0$。  
- **向量线性运算的基本策略**：在几何图形中，选取一组不共线、模长和夹角已知的基向量（如矩形的邻边、正方形中相邻垂直的边），将待求向量用基向量线性表示，再算数量积。

## 解题方法与套路
1. **选好基向量**：一般选图形中互相垂直且长度已知的两个边所在向量作为基向量（例如正方形中 $\vec{AB}$ 与 $\vec{AD}$）。  
2. **分解目标向量**：利用向量加减法几何意义，将所求表达式中的向量写成基向量的线性组合。  
   - 如中点 $E$ 的 $\vec{AE} = \vec{AD} + \frac12\vec{DC}$ 或 $\vec{AB} + \frac12\vec{AD}$ 等（依基向量选择）。  
3. **展开数量积**：将分解后的向量点乘按分配律展开。  
4. **利用已知条件化简**：  
   - 基向量模长已知，代入 $|\vec{a}|^2$；  
   - 若基向量互相垂直，则数量积为 $0$；  
   - 平行向量间点乘转化为模长乘积。  
5. **得出数值结果**。

## 高频易错
- **基向量选择混乱**：没用统一的一组基向量表示所有相关向量，导致表达式不一致，计算错误。  
- **加减法方向搞反**：$\vec{AB} - \vec{AD} = \vec{DB}$，而不是 $\vec{BD}$；减法必须牢记“共起点，指被减”。  
- **中点向量的表示错误**：如正方形 $ABCD$ 中，$E$ 为 $CD$ 中点，误写为 $\frac12(\vec{AD}+\vec{AC})$ 等情况，应直接利用平行四边形或三角形法则。  
- **漏掉垂直条件**：未利用正方形或矩形邻边垂直带来的点积为零的性质，导致冗余运算或结果错误。  
- **运算符号和顺序**：展开点乘时忽略向量方向，符号写反；尤其在减法组合时更易出错。

## 代表题精讲
### **题目**：正方形 $ABCD$ 边长为 $2$，$E$ 为 $CD$ 中点，求 $\vec{AE}\cdot\vec{BD}$。

**思路**：选取 $\vec{AB}$ 和 $\vec{AD}$ 为基向量，将 $\vec{AE}$ 与 $\vec{BD}$ 用它们表示，展开数量积，并用模长和垂直关系求值。

**步骤**：  
1. 设基向量 $\vec{a}=\vec{AB}$，$\vec{b}=\vec{AD}$，则 $|\vec{a}|=|\vec{b}|=2$，且 $\vec{a}\cdot\vec{b}=0$。  
2. 表达 $\vec{AE}$：从 $A$ 经 $D$ 到 $E$，$E$ 为 $CD$ 中点，因此 $\vec{AE}=\vec{AD}+\frac12\vec{DC}$。又 $\vec{DC}=\vec{AB}=\vec{a}$，所以 $\vec{AE}= \vec{b} + \frac12\vec{a}$。  
3. 表达 $\vec{BD}$：$\vec{BD}=\vec{AD}-\vec{AB}=\vec{b}-\vec{a}$。  
4. 计算数量积：  
   $$ \vec{AE}\cdot\vec{BD} = \left(\vec{b}+\frac12\vec{a}\right)\cdot(\vec{b}-\vec{a}) = \vec{b}\cdot\vec{b} - \vec{b}\cdot\vec{a} + \frac12\vec{a}\cdot\vec{b} - \frac12\vec{a}\cdot\vec{a} $$  
   $$ = |\vec{b}|^2 - 0 + 0 - \frac12|\vec{a}|^2 = 4 - \frac12\times4 = 2。 $$  
5. 故原式值为 $2$。

**点评/变式**：  
- 该题核心在于利用基向量分解，利用垂直和模长条件约化。  
- 若改为一般矩形或平行四边形，则需知道邻边夹角及模长，仍可用同样步骤，但垂直带来的点积为零不再适用，需用 $|\vec{a}||\vec{b}|\cos\theta$。  
- 也可建坐标系，将 $A(0,0),B(2,0),C(2,2),D(0,2),E(1,2)$，用坐标运算，殊途同归。但掌握向量基底的几何意义更有一般性。
