## 知识精要
- **异面直线所成角**：过空间任一点分别作两条异面直线的平行线，这两条相交直线所成的不大于 $ \frac{\pi}{2} $ 的角（即锐角或直角）叫做异面直线所成的角，范围 $ (0,\frac{\pi}{2}] $。
- **平移法求角**：利用平行关系（三角形的中位线、平行四边形的对边、棱柱/棱锥的棱等）将其中一条或两条异面直线平移到同一平面内，构成三角形，再用余弦定理或解直角三角形求得该角的余弦值，最后根据范围确定角的大小。
- **向量法求角**：
  - 设异面直线 $l_1, l_2$ 的方向向量分别为 $\vec{a},\vec{b}$，则 $\cos \langle \vec{a},\vec{b}\rangle = \frac{\vec{a}\cdot \vec{b}}{|\vec{a}||\vec{b}|}$。
  - 异面直线所成角 $\theta$ 满足 $\cos \theta = |\cos \langle \vec{a},\vec{b}\rangle|$，$ \theta \in \left(0,\frac{\pi}{2}\right] $。这里取绝对值是因为直线夹角只取锐角或直角。
- **正方体（正四棱柱）**：棱长相等，所有面为全等的正方形，体对角线与棱、面对角线均有固定夹角。建系时可选取顶点为原点，三条两两垂直的棱所在直线为坐标轴，便于向量运算。

## 解题方法与套路
1. **平移法（几何法）**
   - **观察结构**：分析两条异面直线所在的位置，优先利用正方体、长方体、正棱柱等几何体的对称性。
   - **选点平移**：通常将其中一条直线平移至与另一条直线“头碰头”或构成明显可解的三角形。常用平移方式：
     - 利用三角形中位线：连接中点时，中位线平行于第三边。
     - 利用平行四边形：对边平行且相等。
     - 在正方体中，平移常用面对角线、体对角线的平行关系。
   - **解三角形**：连接辅助线构成三角形，标出已知边长（如正方体棱长设为1），通过勾股定理、余弦定理计算所求角。
   - **下结论**：根据计算结果，若求得余弦值，查特殊角得角度。

2. **向量法（坐标法）**
   - **建系设点**：选择空间直角坐标系，通常以某一顶点为原点，三条棱为坐标轴，设棱长为1（或 $a$），写出各点坐标。
   - **确定方向向量**：求出两条异面直线所在方向上的向量，如 $\vec{PB}$ 和 $\vec{AD_1}$，注意箭头方向不影响夹角大小。
   - **计算夹角余弦**：利用 $\cos \theta = \frac{|\vec{v_1}\cdot \vec{v_2}|}{|\vec{v_1}||\vec{v_2}|}$ 求得 $\theta$ 的余弦值，得到 $\theta$。
   - **选法原则**：图形规则（如正方体、正棱柱、墙角模型）、建系后点坐标易求时用向量法；能快速平移得到特殊三角形时用平移法。

## 高频易错
- **忽略角的范围，忘记取绝对值**：向量夹角范围是 $[0,\pi]$，但异面直线所成角范围是 $(0,\frac{\pi}{2}]$。直接求 $\cos\langle \vec{a},\vec{b}\rangle$ 可能为负，必须取绝对值 $|\cos\langle \vec{a},\vec{b}\rangle|$ 才能对应直线夹角。
- **平移后端点没对准，构不成三角形**：做平移时，必须保证平移后的两条直线相交于一点，否则得到的是两条平行（或异面）的线，无法直接求角。要确保“过一点作两条异面直线的平行线，这两条相交直线所成角”这一要求。
- **求角时误用补角**：解三角形时求出的角可能是两条相交直线的夹角，如果这个角大于 $\frac{\pi}{2}$，需取其补角作为异面直线所成的角（如算出 $\cos \alpha = -\frac12$，则夹角为 $\frac{\pi}{3}$，而非 $\frac{2\pi}{3}$）。
- **建系时坐标写错**：正方体顶点坐标易混淆，务必按“右手系”或固定顺序写出，如 $A(0,0,0), B(1,0,0), D(0,1,0), A_1(0,0,1)$ 等，正方体通常棱长设为1，注意相对位置。

## 代表题精讲
### 代表题 2021-文-10
**题目** 在正方体 $ABCD-A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 的中点，则直线 $PB$ 与 $AD_1$ 所成的角为  
A. $\frac{\pi}{2}$  B. $\frac{\pi}{3}$  C. $\frac{\pi}{4}$  D. $\frac{\pi}{6}$

**思路**  
正方体棱长未知，可设棱长为 $1$（或 $2$）。有两种代表性解法：  
- **平移法**：注意到 $AD_1 // BC_1$，将 $AD_1$ 平移到 $BC_1$，则问题转化为求 $PB$ 与 $BC_1$ 的夹角。连接 $PC_1$，在 $\triangle PBC_1$ 中计算三边长度，再用余弦定理求 $\angle PBC_1$。  
- **向量法**：以 $D$ 为原点建立空间直角坐标系，写出 $P$、$B$、$A$、$D_1$ 的坐标，得到方向向量 $\vec{PB}$ 与 $\vec{AD_1}$，利用夹角公式求解。

**步骤（平移法）**
1. 如图，正方体 $ABCD-A_1B_1C_1D_1$，$AD_1 // BC_1$，因此 $PB$ 与 $AD_1$ 的夹角等于 $PB$ 与 $BC_1$ 的夹角 $\angle PBC_1$。
2. 设正方体棱长为 $2$（便于中点坐标化为整数），则 $BB_1=2$，$B_1D_1=2\sqrt{2}$，$B_1P=\frac{1}{2}B_1D_1=\sqrt{2}$。
    - $PB = \sqrt{BB_1^2 + B_1P^2} = \sqrt{2^2 + (\sqrt{2})^2} = \sqrt{6}$.
    - $BC_1$ 是正方形的面对角线，$BC_1 = 2\sqrt{2}$.
    - $PC_1 = \sqrt{2}$（因为 $P$ 为 $B_1D_1$ 中点，$B_1C_1=2$，$P$ 到 $C_1$ 连线也可由勾股定理：在底面上，$B_1C_1=2$，$B_1P=\sqrt{2}$，$\angle PB_1C_1=45^\circ$，用余弦定理 $PC_1^2=(\sqrt{2})^2+2^2-2\cdot \sqrt{2}\cdot 2\cdot \frac{\sqrt{2}}{2}=2+4-4=2$，故 $PC_1=\sqrt{2}$。但注意，$B,C_1$之间没有面，需要的是 $\triangle PBC_1$ 的三边，我们其实求 $PB$、$BC_1$、$PC_1$。
3. 在 $\triangle PBC_1$ 中，用余弦定理求 $\angle PBC_1$：
   $$ \cos\angle PBC_1 = \frac{PB^2 + BC_1^2 - PC_1^2}{2\cdot PB\cdot BC_1} = \frac{6 + 8 - 2}{2\cdot \sqrt{6}\cdot 2\sqrt{2}} = \frac{12}{4\sqrt{12}} = \frac{12}{4\cdot 2\sqrt{3}} = \frac{12}{8\sqrt{3}} = \frac{\sqrt{3}}{2}. $$
   因此 $\angle PBC_1 = \frac{\pi}{6}$？不对，$\cos = \frac{\sqrt{3}}{2}$ 对应 $30^\circ$ 即 $\frac{\pi}{6}$。但是题目中 $PB$ 与 $AD_1$ 所成角等于 $\angle PBC_1$，答案是 $\frac{\pi}{6}$？需要核对：若 $\cos = \frac{\sqrt{3}}{2}$，则角为 $\frac{\pi}{6}$。但有没有可能大于 $90^\circ$ 取补角？这里余弦为正，角为锐角，没问题。可是真实答案是？根据记忆，这道2021全国甲卷文数第10题，答案应该是 $\frac{\pi}{3}$ 或者 $\frac{\pi}{6}$？让我们重新计算，防止错误。设棱长 $1$：$BB_1=1$，$B_1P=\frac{\sqrt{2}}{2}$，$PB=\sqrt{1+\frac12}=\sqrt{\frac32}=\frac{\sqrt{6}}{2}$。$BC_1=\sqrt{2}$。$PC_1$：在 $\triangle PB_1C_1$，$B_1P=\frac{\sqrt{2}}{2}$，$B_1C_1=1$，$\angle PB_1C_1=45^\circ$，$PC_1^2 = (\frac{\sqrt{2}}{2})^2+1^2-2\cdot\frac{\sqrt{2}}{2}\cdot 1\cdot\frac{\sqrt{2}}{2} = \frac12+1-1=\frac12$，所以 $PC_1=\frac{\sqrt{2}}{2}$。然后 $\cos\angle PBC_1 = \frac{ (\frac{\sqrt{6}}{2})^2 + (\sqrt{2})^2 - (\frac{\sqrt{2}}{2})^2 }{2\cdot \frac{\sqrt{6}}{2}\cdot \sqrt{2}} = \frac{ \frac{6}{4} + 2 - \frac{2}{4} }{ 2\cdot \frac{\sqrt{12}}{2} } = \frac{ \frac{3}{2} + 2 - \frac12 }{ \sqrt{12} } = \frac{3}{ \sqrt{12} } = \frac{3}{2\sqrt{3}} = \frac{\sqrt{3}}{2}$，$ \angle PBC_1 = \frac{\pi}{6}$。啊？那应该是 $\frac{\pi}{6}$。但很多网上回忆答案是 $\frac{\pi}{6}$，选项中有。那么就是D。等一下，题目中 $PB$ 与 $AD_1$ 的夹角，$AD_1$ 平移为 $BC_1$，平移正确。所以角为 $\frac{\pi}{6}$。但是有的解析做向量法也可能得出答案。确认无误，答案为 D $\frac{\pi}{6}$。但是如果是 $\frac{\pi}{3}$，余弦值是 $\frac12$，计算不符。所以代表题答案是 D。

那我们改写步骤为棱长1或2。设棱长为2方便计算：$BB_1=2$，$B_1D_1=2\sqrt{2}$，$B_1P=\sqrt{2}$，$PB=\sqrt{4+2}=\sqrt{6}$，$BC_1=2\sqrt{2}$，$PC_1$：$\triangle PB_1C_1$，$B_1P=\sqrt{2}$，$B_1C_1=2$，$\angle PB_1C_1=45^\circ$，$PC_1^2=2+4-2\cdot\sqrt{2}\cdot 2\cdot\frac{\sqrt{2}}{2}=6-4=2$，$PC_1=\sqrt{2}$，余弦：$(6+8-2)/(2*\sqrt{6}*2\sqrt{2}) = 12/(4\sqrt{12}) = 12/(8\sqrt{3}) = 3/(2\sqrt{3}) = \sqrt{3}/2$。答案 $\frac{\pi}{6}$。对了。

向量法：以D为原点，DA, DC, DD1为x,y,z轴，设棱长2，A(2,0,0), D1(0,0,2)，则 $\vec{AD_1}=(-2,0,2)$。B(2,2,0)，C1(0,2,2)，B1(2,2,2)，D1(0,0,2)，P为B1D1中点：B1(2,2,2)，D1(0,0,2)，P(1,1,2)。则 $\vec{PB} = B - P = (2-1, 2-1, 0-2) = (1,1,-2)$。计算 $\vec{AD_1} \cdot \vec{PB} = (-2)*1 + 0*1 + 2*(-2) = -2-4=-6$。模长 $|\vec{AD_1}| = \sqrt{4+0+4}=\sqrt{8}=2\sqrt{2}$，$|\vec{PB}|=\sqrt{1+1+4}=\sqrt{6}$。$\cos \theta = \frac{|\vec{AD_1}\cdot \vec{PB}|}{|\vec{AD_1}||\vec{PB}|} = \frac{6}{2\sqrt{2}\cdot \sqrt{6}} = \frac{6}{2\sqrt{12}} = \frac{6}{4\sqrt{3}} = \frac{\sqrt{3}}{2}$，得 $\theta = \frac{\pi}{6}$。完美。

所以代表题精讲里可以同时讲两种解法，然后点评。

**点评/变式**  
此题平移法关键在于将 $AD_1$ 平移至与 $PB$ 共顶点的 $BC_1$，利用正方体中面对角线平行的特性。建立空间直角坐标系时，设棱长为 $2$ 可避免分数运算。  
**变式1**：若 $P$ 为 $B_1C_1$ 中点，求 $PB$ 与 $AD_1$ 所成角（用同样方法可得余弦为 $\frac{\sqrt{10}}{5}$）。  
**变式2**：若求 $PB$ 与 $D_1C$ 所成角，可利用平移 $D_1C$ 至 $A_1B$，在 $\triangle PBA_1$ 中求解。
