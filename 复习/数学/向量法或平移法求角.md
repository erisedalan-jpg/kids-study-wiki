## 知识精要
- **异面直线所成角**：过空间任意一点，分别作两条异面直线的平行线，这两条相交直线所成的锐角或直角即为异面直线所成的角。范围：$(0,\frac{\pi}{2}]$。
- **平移法**：利用平行四边形的对边平行且相等、三角形的中位线等性质，将其中一条直线平移至与另一条直线相交的位置，构造出平面三角形求解。
- **向量法**：设空间向量 $\vec{a}$ 与 $\vec{b}$ 的方向分别与异面直线 $l_1$ 与 $l_2$ 平行，则 $l_1$ 与 $l_2$ 所成角 $\theta$ 满足：
  $$\cos\theta = |\cos\langle \vec{a}, \vec{b} \rangle| = \frac{|\vec{a} \cdot \vec{b}|}{|\vec{a}||\vec{b}|}$$
- **坐标运算**：在规则几何体（如正方体）中，优先建立空间直角坐标系，利用坐标法求向量夹角。

## 解题方法与套路
1. **选系与设点**：利用正方体、长方体或含垂直关系的几何体，以一点为原点、三条两两垂直的棱为坐标轴建立空间直角坐标系。设出棱长（通常设为单位1），标出相关各点的坐标。
2. **写向量并求方向向量**：直接写出目标直线所在段落的起点与终点坐标，计算对应的方向向量。
3. **套用夹角公式**：计算两方向向量点积的绝对值与模长，代入公式
   $$\cos\theta = \frac{|\vec{u} \cdot \vec{v}|}{|\vec{u}| |\vec{v}|}$$
   求出 $\cos\theta$。
4. **定角**：根据 $\cos\theta$ 的值确定角 $\theta$ （通常为 $\frac{\pi}{6}$、$\frac{\pi}{4}$、$\frac{\pi}{3}$ 等特殊角）。注意异面直线所成角取锐角或直角。

## 高频易错
- **向量夹角与异面直线夹角混淆**：向量夹角公式算出的是 $[0, \pi]$ 间的值，而异面直线所成角必须是锐角或直角。必须对点积结果取绝对值，否则可能得到钝角的余弦值。
- **坐标计算失误**：在标点坐标时，对空间位置（特别是中点、$n$ 等分点）的 $z$ 坐标换算错误。需严格按照坐标定义进行推导。
- **方向向量选错**：找错对应直线的方向向量，例如将 $PB$ 误写成 $BP$ 虽不影响方向，但起点终点坐标相减时出现符号错误导致向量错误。
- **余弦值反查角度错误**：例如 $\cos\theta = \frac{\sqrt{3}}{2}$ 对应的角应为 $\frac{\pi}{6}$ 而非 $\frac{\pi}{3}$，务必记熟特殊角的三角函数值。

## 代表题精讲
### 2021-文-10
**题目**：在正方体 $ABCD-A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 的中点，求直线 $PB$ 与 $AD_1$ 所成的角。选项：A. $\frac{\pi}{2}$ B. $\frac{\pi}{3}$ C. $\frac{\pi}{4}$ D. $\frac{\pi}{6}$

**思路**：利用正方体的优良垂直与平行结构，采用向量坐标法。以 $D$ 为原点建立空间直角坐标系，设棱长为 $2$，标出点 $D$、$A$、$B$、$P$、$D_1$ 的坐标，分别求出 $PB$ 和 $AD_1$ 的方向向量，代入异面直线夹角公式求解。

**步骤**：
1. 建系：设正方体棱长为 $2$。以 $D$ 为原点，$DA$、$DC$、$DD_1$ 所在直线分别为 $x$、$y$、$z$ 轴，建立空间直角坐标系。
2. 标点：各点坐标为 $A(2,0,0)$，$B(2,2,0)$，$D_1(0,0,2)$。$B_1(2,2,2)$，$P$ 为 $B_1D_1$ 中点，故 $P(1,1,2)$。
3. 求方向向量：
   $\overrightarrow{PB} = B - P = (2-1, 2-1, 0-2) = (1, 1, -2)$；
   $\overrightarrow{AD_1} = D_1 - A = (0-2, 0-0, 2-0) = (-2, 0, 2)$。
4. 套公式：
   $\overrightarrow{PB} \cdot \overrightarrow{AD_1} = 1\times(-2) + 1\times0 + (-2)\times2 = -6$。
   $|\overrightarrow{PB}| = \sqrt{1^2+1^2+(-2)^2} = \sqrt{6}$。
   $|\overrightarrow{AD_1}| = \sqrt{(-2)^2+0^2+2^2} = \sqrt{8} = 2\sqrt{2}$。
   $\cos\theta = \frac{|-6|}{\sqrt{6} \times 2\sqrt{2}} = \frac{6}{2\sqrt{12}} = \frac{3}{2\sqrt{3}} = \frac{\sqrt{3}}{2}$。
5. 定角：$\cos\theta = \frac{\sqrt{3}}{2}$ 且 $\theta \in (0, \frac{\pi}{2}]$，所以 $\theta = \frac{\pi}{6}$。故选 D。

**点评/变式**：本题建系设棱长为 $2$ 直接规避了中点产生的分数坐标，计算更简洁。遇到正方体或长方体中的异面直线求角，向量法通常是首选。若采用平移法，可连接 $A_1B$，发现 $A_1B \parallel D_1C$，将 $AD_1$ 平移至 $BC_1$ 或连接 $D_1C$，同样可在 $\triangle D_1PB$ 或 $\triangle PBC_1$ 中利用余弦定理求解，但计算量可能略大。
