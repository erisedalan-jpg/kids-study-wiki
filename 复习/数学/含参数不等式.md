## 知识精要

1. **绝对值不等式的核心思想**  
   含绝对值的不等式 $|f(x)| \gtrless g(x)$ 本质上是分段函数的表达，必须通过“**零点分段**”去掉绝对值符号，转化为若干不等式组求解。零点即为使绝对值内部表达式等于 $0$ 的 $x$ 值。

2. **零点分段法操作要点**  
   对于形如 $|x-a|$ 的绝对值，零点为 $x=a$。以零点为界将数轴分段：
   - 当 $x \geq a$ 时，$|x-a| = x-a$；
   - 当 $x < a$（或 $x \le a$，依据不等式等号归属而定）时，$|x-a| = -(x-a)=a-x$。  
   每一段上将原不等式化为无绝对值的一次或二次不等式，并**与分段区间取交集**作为该段解集，最终各段解集的并集即为原不等式解集。

3. **含参数不等式的逆向求参**  
   已知含参绝对值不等式的解集求参数，通常利用解集的端点与参数的关系建立方程。关键是分段求解过程中必须严格保持**参数与自变量的相对大小关系**，结合解集形式反推参数值。若某段不等式组无解（集合为空），则排除该段对应参数情况。

4. **适用条件与核心公式**
   - $|x-a|$ 的几何意义：数轴上点 $x$ 到点 $a$ 的距离。
   - $|x-a| > c\ (c>0) \iff x > a+c$ 或 $x < a-c$；
   - $|x-a| < c\ (c>0) \iff a-c < x < a+c$。  
   但当绝对值与一次项混合时（如 $|x-a| + 3x \le 0$），几何意义不便直接使用，必须使用分段讨论。

## 解题方法与套路

1. **定零点，分区间**  
   令绝对值内部表达式 $=0$，解出零点 $x_0$。以 $x_0$ 将全体实数分为 $(-\infty, x_0)$ 和 $[x_0, +\infty)$（等号可任意归入一侧，但需保证不重不漏）。

2. **分段去绝对值，化为一元不等式（组）**  
   在每个区间上，依据 $x$ 与 $x_0$ 的大小关系写出 $|x-a|$ 的等价表达式，将原不等式转化为不含绝对值的不等式，并与该区间的约束条件联立，形成不等式组：
   $$
   \begin{cases}
   x \geq a \\
   \text{化简后的不等式}
   \end{cases}
   \quad \text{和} \quad
   \begin{cases}
   x < a \\
   \text{化简后的不等式}
   \end{cases}
   $$

3. **求解不等式组，整合结果**  
   分别解出每个不等式组。注意不等式组的解是该组内所有不等式的交集。将各组的解集取并集，即得原不等式的解集。

4. **已知解集求参数：利用端点对应**  
   若题目给出最终解集为 $\{x \mid x \le x_0\}$（或单侧区间），则：
   - 分段讨论后某一侧区间可能无解（矛盾），应从另一侧得到解集；
   - 将得到的解集形式（如 $x \le -\dfrac{a}{2}$）与已知解集端点对比，建立方程 $-\dfrac{a}{2} = -1$，解出参数，并**检验是否符合前提条件**（如 $a>0$）。

## 高频易错

- **忽略分段区间与不等式解的取交**  
  分段去掉绝对值后解出的 $x$ 范围，必须与该段的定义区间取交集。例如在 $x \ge a$ 段解得 $x \le \dfrac{a}{4}$，若 $a > 0$ 则交集为空，不能直接写 $x \le \dfrac{a}{4}$。

- **绝对值等号归属混乱**  
  零点处函数值为 $0$，等号可放在任意一侧，但不能两边都不放或两边都放（重复）。通常采用“右侧取等，左侧不取”：$x \ge a$ 和 $x < a$，保证不重不漏。归属不影响最终解集，但影响书写规范。

- **忽略参数的正负与大小关系**  
  参数 $a>0$ 等条件在分段求解时必须参与不等式的等价变形，例如判断 $\dfrac{a}{4}$ 与 $a$ 的大小，否则可能导致错误地保留空集。切记在参数背景下全程关注参数的取值范围。

- **直接套用几何意义导致错误**  
  $|x-a|+3x \le 0$ 不是标准的两边绝对值或纯绝对值不等式，不能直接用“距离”公式求解，必须老老实实分段讨论。

- **解集端点代入不检验**  
  由端点相等求出参数值后，必须代回原不等式验证解集是否完全一致，避免增根。

## 代表题精讲

### 代表题：2011·理·24

**题目**：设函数 $f(x)=|x-a|+3x$，其中 $a>0$。  
（Ⅰ）当 $a=1$ 时，求不等式 $f(x) \ge 3x+2$ 的解集；  
（Ⅱ）若不等式 $f(x) \le 0$ 的解集为 $\{x \mid x \le -1\}$，求 $a$ 的值。

**思路**：  
（Ⅰ）代入 $a=1$ 化简得 $|x-1| \ge 2$，直接利用绝对值几何意义或两边平方求解。  
（Ⅱ）由 $f(x) \le 0$ 得 $|x-a|+3x \le 0$。零点为 $x=a$，分 $x \ge a$ 和 $x < a$ 两段去绝对值，每种情况解出 $x$ 的范围并取交集。最后利用已知解集为 $x \le -1$ 建立等量关系求 $a$，并验证 $a>0$ 是否符合。

**步骤**：  
**（Ⅰ）** 当 $a=1$ 时，$f(x) = |x-1|+3x$，不等式 $f(x) \ge 3x+2$ 化为：
$$
|x-1|+3x \ge 3x+2 \implies |x-1| \ge 2.
$$
由绝对值不等式得 $x-1 \ge 2$ 或 $x-1 \le -2$，解得 $x \ge 3$ 或 $x \le -1$。  
$\therefore$ 解集为 $\{x \mid x \ge 3 \text{ 或 } x \le -1\}$。

**（Ⅱ）** 由 $f(x) \le 0$ 得：
$$
|x-a| + 3x \le 0.
$$
**分段讨论**：

- **当 $x \ge a$ 时**，$|x-a| = x-a$，原不等式化为：
  $$
  x-a + 3x \le 0 \implies 4x \le a \implies x \le \frac{a}{4}.
  $$
  此时需同时满足 $x \ge a$ 和 $x \le \dfrac{a}{4}$。因为 $a>0$ 时 $a > \dfrac{a}{4}$，所以不存在 $x$ 同时满足两者，故此段解集为 $\varnothing$。

- **当 $x < a$ 时**，$|x-a| = a-x$，原不等式化为：
  $$
  a-x + 3x \le 0 \implies 2x \le -a \implies x \le -\frac{a}{2}.
  $$
  还需满足 $x < a$。由于 $a>0$，$-\dfrac{a}{2} < 0 < a$，故 $x \le -\dfrac{a}{2}$ 已隐含 $x < a$。此段解集为 $x \le -\dfrac{a}{2}$。

综合两段，原不等式 $f(x) \le 0$ 的解集为 $\{x \mid x \le -\dfrac{a}{2}\}$。  
已知解集为 $\{x \mid x \le -1\}$，故有：
$$
-\frac{a}{2} = -1 \implies a = 2.
$$
$a=2>0$，符合题意。

**点评/变式**：  
本题（Ⅱ）的“陷阱”在于 $x \ge a$ 这一支得到空集。很多考生会不加验证直接写出 $x \le \dfrac{a}{4}$ 作为潜在解集，从而无法得出唯一参数。解题的关键在于严格求解**不等式组**，并始终不忘比较参数与分段端点的相对大小。  
**变式训练**：若将条件改为 $f(x) \le 0$ 的解集为 $\{x \mid -3 \le x \le -1\}$，则不可能成立，因为绝对值加一次函数形成的解集必然是单侧射线。你能分析原因吗？
