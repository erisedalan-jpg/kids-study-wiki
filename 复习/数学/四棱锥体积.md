## 知识精要
- **四棱锥的体积公式**：$V = \frac{1}{3} S h$，其中 $S$ 为底面四边形面积，$h$ 为顶点到底面的高。
- **底面四边形面积**：一般四边形 $ABCD$ 对角线 $AC,BD$ 夹角为 $\alpha$，则 $S = \frac{1}{2} AC \cdot BD \cdot \sin \alpha$。当 $\alpha = 90^\circ$ 且对角线长最大时，面积最大；圆内接四边形中，对角线均为直径且垂直时（即正方形），面积最大为 $2r^2$（$r$ 为外接圆半径）。
- **球的截面性质**：球心到截面距离 $h$、截面圆半径 $r$、球半径 $R$ 满足 $r^2 + h^2 = R^2$。若四棱锥顶点在球心、底面顶点在球面上，则高 $h$ 即为球心到底面距离，底面外接圆半径即为截面圆半径。
- **均值不等式求最值**：对于正数 $a,b,c$，有 $\frac{a+b+c}{3} \ge \sqrt[3]{abc}$，当 $a=b=c$ 时取等号，常需拆项配系数使用。
- **线面垂直的应用**：证明直线垂直于平面，得到几何体内的高（如点到平面的距离），是构建体积计算的关键。

## 解题方法与套路
1. **直接公式法**：明确四棱锥的底面和顶点，分别求出底面积 $S$ 和高 $h$，代入 $V = \frac{1}{3} S h$。适用于底面形状规则、高易求的问题。
2. **函数最值法（体积最大化）**：
   - 设定变量（如高 $h$ 或底面半径 $r$），利用几何约束（如球截面关系 $r^2+h^2=R^2$）建立联系。
   - 将体积 $V$ 表示为单一变量的函数，例如 $V = \frac{2}{3}(R^2 - h^2)h$。
   - 使用**均值不等式**或**导数**求最值：用均值不等式时需拆项凑定值，如 $V^2 = \frac{4}{9}(R^2-h^2)^2 h^2$，设 $a = \frac{R^2-h^2}{2}, b = \frac{R^2-h^2}{2}, c = h^2$，利用 $\frac{a+b+c}{3} \ge \sqrt[3]{abc}$；用导数则直接求导令 $V'=0$，注意检验取等条件。
   - 得出最值对应的变量值，进而求出高或其他所求量。
3. **等体积法（转移顶点）**：当原顶点到底面的高不易求时，可更换顶点或底面，利用体积不变转化计算。
4. **线面垂直定高法**：若棱锥的高不是直观给出的，需先通过证明线面垂直（判定定理：直线垂直于平面内两条相交直线）来确定高，再求长度。

## 高频易错
- **搞混球心、截面圆心与高的关系**：球的内接四棱锥若顶点在球心，则高 $h$ 是球心到底面的距离，满足 $h^2 + r^2 = R^2$，易误作 $r = R$。
- **面积公式遗漏系数**：四边形面积用对角线夹角时漏写 $\frac{1}{2}$ 或 $\sin \alpha$；圆内接四边形最大面积直接当成 $\pi r^2$ 或 $r^2$，正确为 $2r^2$。
- **均值不等式配凑不当**：在 $V = \frac{2}{3} r^2 h$ 中，直接对 $r^2$ 和 $h$ 使用均值，忽略 $r^2$ 需拆分为 $\frac{r^2}{2} + \frac{r^2}{2}$ 才能与 $h^2$ 构成和为定值，导致取等条件错误。
- **取等条件未验证或忽略**：使用不等式求最值必须说明何时取等（如正方形条件、$r^2/2 = h^2$ 等），漏写会失分。
- **高不是直观棱**：如长方体中的四棱锥，高往往是点到侧面的距离，需要先证明该连线垂直于侧面，不能想当然拿侧棱当高。

## 代表题精讲
### 【代表题1】2022年理科第9题（文科第12题）
**题目**：已知球 $O$ 的半径为 $1$，四棱锥的顶点为 $O$，底面的四个顶点均在球 $O$ 的球面上，则当该四棱锥的体积最大时，其高为多少？（选项略）

**思路**：
四棱锥的顶点为球心 $O$，高 $h$ 即 $O$ 到底面的距离。由球的截面性质得底面外接圆半径 $r$ 满足 $r^2 + h^2 = 1$。要使体积最大，在固定 $r$ 时底面四边形面积应取最大。圆内接四边形最大面积为 $2r^2$（当为正方形时取到）。于是 $V = \frac{1}{3} \cdot 2r^2 \cdot h = \frac{2}{3} r^2 h$，且 $r^2 = 1 - h^2$。问题化为求 $f(h) = \frac{2}{3}(1-h^2)h$ 在 $(0,1)$ 上的最大值。

**步骤**：
1. 设四棱锥高为 $h$，底面四边形所在小圆半径为 $r$，则由球截面得 $r^2 + h^2 = 1$。
2. 底面四边形面积 $S \le 2r^2$（取等时为正方形）。故体积 $V = \frac{1}{3} S h \le \frac{2}{3} r^2 h = \frac{2}{3} (1-h^2)h$。
3. 求最值。考虑 $V^2 = \frac{4}{9} (1-h^2)^2 h^2$。令 $a = \frac{1-h^2}{2}, b = \frac{1-h^2}{2}, c = h^2$，由均值不等式：
   $$\frac{a+b+c}{3} = \frac{(1-h^2) + h^2}{3} = \frac{1}{3} \ge \sqrt[3]{abc} = \sqrt[3]{\frac{(1-h^2)^2 h^2}{4}}$$
   从而 $(1-h^2)^2 h^2 \le \frac{4}{27}$，$V^2 \le \frac{4}{9} \cdot \frac{4}{27} = \frac{16}{243}$，即 $V \le \frac{4\sqrt{3}}{27}$。
4. 取等条件：$\frac{1-h^2}{2} = h^2$，解得 $h^2 = \frac{1}{3}$，即 $h = \frac{\sqrt{3}}{3}$。此时体积最大。
5. 选项 C 为 $\frac{\sqrt{3}}{3}$。

**点评/变式**：
本题关键是“先固定高，最大化底面积”的策略，以及利用圆内接四边形性质得出 $S_{\text{max}}=2r^2$。均值不等式配凑 $r^2$ 需拆为两个 $\frac{r^2}{2}$ 是常见手段。**变式**：若球半径变为 $R$，高为 $\frac{\sqrt{3}}{3}R$ 时体积最大；若改为三棱锥（顶点在球心，底面三角形内接于圆）则底面积最大为 $\frac{3\sqrt{3}}{4}r^2$，方法类似。

### 【代表题2】2019年文科第17题
**题目**：长方体 $ABCD-A_1B_1C_1D_1$ 底面是正方形，点 $E$ 在棱 $AA_1$ 上，$BE \perp EC_1$。
(1) 证明 $BE \perp$平面 $EB_1C_1$；
(2) 若 $AE=A_1E$，$AB=3$，求四棱锥 $E-BB_1C_1C$ 的体积。

**思路**：
(1) 利用长方体性质得 $B_1C_1 \perp$ 平面 $AA_1B_1B$，推出 $B_1C_1 \perp BE$；结合已知 $BE \perp EC_1$，及 $B_1C_1 \cap EC_1 = C_1$，可证 $BE \perp$ 平面 $EB_1C_1$。
(2) 设侧棱 $AA_1 = 2a$，则 $AE = a$。由 $BE \perp EC_1$ 可建立勾股关系求 $a$。取 $BB_1$ 中点 $F$，证 $EF \perp$ 平面 $BB_1C_1C$，则四棱锥高为 $EF$。底面 $BB_1C_1C$ 为矩形，面积易求，代入体积公式。

**步骤**：
1. 证明：
   - 长方体 $ABCD-A_1B_1C_1D_1$ 中，$B_1C_1 \perp$ 平面 $AA_1B_1B$，而 $BE \subset$ 平面 $AA_1B_1B$，故 $B_1C_1 \perp BE$。
   - 已知 $BE \perp EC_1$，且 $EC_1 \subset$ 平面 $EB_1C_1$，$B_1C_1 \subset$ 平面 $EB_1C_1$，$EC_1 \cap B_1C_1 = C_1$。
   - 由线面垂直判定定理得 $BE \perp$ 平面 $EB_1C_1$。
2. 求体积：
   - 设 $AA_1 = 2a$，由 $AE = A_1E$ 得 $AE = a$。底面正方形边长 $AB=3$，则 $BE = \sqrt{3^2 + a^2}$，$EC_1 = \sqrt{3^2 + 3^2 + a^2} = \sqrt{18 + a^2}$，$BC_1 = \sqrt{3^2 + (2a)^2} = \sqrt{9+4a^2}$。
   - 由 $BE \perp EC_1$（由(1)知 $BE \perp$ 平面 $EB_1C_1$，$EC_1$ 在该平面内）得 $BE^2 + EC_1^2 = BC_1^2$，即 $(9+a^2) + (18+a^2) = 9+4a^2$，解得 $a^2=9$，$a=3$（负值舍去）。故 $AA_1 = 6$。
   - 取 $BB_1$ 中点 $F$，连接 $EF$。易证 $EF \parallel AB$ 且 $EF=AB=3$，又 $AB \perp$ 平面 $BB_1C_1C$，故 $EF \perp$ 平面 $BB_1C_1C$。四棱锥 $E-BB_1C_1C$ 的高 $h = EF = 3$。
   - 底面矩形 $BB_1C_1C$ 中，$BB_1=6$，$BC=3$，面积 $S = 6 \times 3 = 18$。
   - 体积 $V = \frac{1}{3} S h = \frac{1}{3} \times 18 \times 3 = 18$。
