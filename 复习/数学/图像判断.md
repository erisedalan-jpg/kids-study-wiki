## 知识精要
- 圆周运动代数化：圆心在原点、半径为 $R$ 的圆周上的质点，可用参数方程 $\begin{cases} x = R\cos\theta \\ y = R\sin\theta \end{cases}$ 或 $\begin{cases} x = R\sin\theta \\ y = R\cos\theta \end{cases}$ 描述，其中 $\theta$ 为以弧度表示的旋转角。
- 角速度 $\omega$：匀速圆周运动中，$\theta = \theta_0 + \omega t$（逆时针为正），$t$ 为时间。
- 点到坐标轴的距离：点 $P(x,y)$ 到 $x$ 轴距离为 $d = |y|$，到 $y$ 轴距离为 $d = |x|$，必须取绝对值以确保非负。
- 绝对值三角函数图象：$y = A|\sin(\omega t + \varphi)|$ 或 $y = A|\cos(\omega t + \varphi)|$ 的周期是原始三角函数的 $\frac{1}{2}$，振幅为 $|A|$，图象翻折后整体位于 $x$ 轴上方。

## 解题方法与套路
1. **建立运动模型**：将实际情境转化为参数方程或函数关系，明确圆心、半径、角速度等关键量。
2. **写出角度函数**：利用角速度公式 $\theta(t) = \theta_0 + \omega t$，注意 $\theta_0$ 由初始位置坐标确定。
3. **表达目标变量**：所求量（如距离、坐标分量）用角度或时间表示，尤其注意距离需加绝对值。
4. **分析函数图象特征**：从解析式得出周期、振幅、单调区间、零点和特殊点值（如 $t=0$ 初值），排除干扰选项，选出符合规律的图象。

## 高频易错
- **漏掉距离的绝对值**：直接取 $y$ 值而不是 $|y|$ 作为距离，导致函数值域、周期、图象形状错误。
- **初始角度求解错误**：由坐标 $P_0(x_0, y_0)$ 利用 $x_0 = R\cos\theta_0, y_0 = R\sin\theta_0$ 求 $\theta_0$ 时，未结合象限确定正确符号或错误使用弧度值。
- **周期计算失误**：混淆 $\sin$ 与 $|\sin|$ 的周期，误认为绝对值正弦的周期仍为 $2\pi$，实际为 $\pi$。
- **忽略角速度单位**：角速度默认以弧度/单位时间给出，若试题隐含角度制，需转换，否则角度函数不匹配。

## 代表题精讲
### **题目**  
质点 $P$ 在半径为 $2$ 的圆周上逆时针运动，初始位置为 $P_0(\sqrt{2}, -\sqrt{2})$，角速度为 $1$。点 $P$ 到 $x$ 轴的距离 $d$ 关于时间 $t$ 的函数图象大致为选项之一。  

### **思路**  
建立圆周运动的参数方程，确定角度 $\theta$ 与时间 $t$ 的关系；写出 $y$ 坐标，则距离 $d = |y|$；分析 $d(t)$ 的性质并与选项图象比对。

### **步骤**  
1. 设圆心在原点，半径为 $R=2$，点 $P$ 坐标 $(x,y)$ 满足 $x=2\cos\theta,\; y=2\sin\theta$。  
2. 由角速度 $\omega = 1$，得 $\theta(t) = \theta_0 + t$。  
3. $t=0$ 时，$2\cos\theta_0 = \sqrt{2} \Rightarrow \cos\theta_0 = \frac{\sqrt{2}}{2}$，$2\sin\theta_0 = -\sqrt{2} \Rightarrow \sin\theta_0 = -\frac{\sqrt{2}}{2}$，结合第四象限得 $\theta_0 = -\dfrac{\pi}{4}$，故 $\theta(t) = t - \dfrac{\pi}{4}$。  
4. 到 $x$ 轴距离 $d = |y| = \left|2\sin\left(t - \frac{\pi}{4}\right)\right| = 2\left|\sin\left(t - \frac{\pi}{4}\right)\right|$。  
5. 函数特征：周期 $T = \dfrac{2\pi}{1} \div 2 = \pi$，非负，最大值为 $2$，最小值为 $0$；$t=0$ 时 $d = 2\left|-\frac{\sqrt{2}}{2}\right| = \sqrt{2}$；$t = \frac{\pi}{4}$ 时 $d = 0$；$t = \frac{3\pi}{4}$ 时 $d = 2$。图象为从 $(\!0,\sqrt{2}\!)$ 下降至 $(\!\frac{\pi}{4},0\!)$ 再上升至 $(\!\frac{3\pi}{4},2\!)$ 的波浪线。  
6. 对照选项，选取符合该走势的图象。

### **点评/变式**  
本题关键在将距离转化为 $|2\sin(t - \frac{\pi}{4})|$，排除未取绝对值或初值错误的干扰项。验证特殊点（如零点、峰值点）可快速淘汰错误图象。  
**变式**：若求点 $P$ 到 $y$ 轴距离 $d'$，则 $d' = |x| = 2\left|\cos\left(t - \frac{\pi}{4}\right)\right|$，图象类似但相位偏移。也可改为求质点纵坐标 $y$ 本身（不取绝对值），则周期为 $2\pi$ 且含负值区，图象形状迥异，应注意审题。
