## 知识精要
- **圆的参数方程标准式**：以 $C(a, b)$ 为圆心、$r$ 为半径的圆的标准参数方程为：
  $$\begin{cases} x = a + r\cos\theta \\ y = b + r\sin\theta \end{cases} (\theta\text{为参数})$$
  其中 $\theta$ 的几何意义是旋转角（即圆心角），取值范围一般为 $[0, 2\pi)$。
- **参数方程与普通方程互化**：
  - 化普通方程：移项凑出 $\cos^2\theta + \sin^2\theta = 1$ 消去 $\theta$，得到 $(x-a)^2 + (y-b)^2 = r^2$。
  - 化参数方程：将圆的标准方程 $(x-a)^2 + (y-b)^2 = r^2$ 变形为 $(\frac{x-a}{r})^2 + (\frac{y-b}{r})^2 = 1$，令 $\frac{x-a}{r} = \cos\theta, \frac{y-b}{r} = \sin\theta$ 即可。
- **极坐标与参数方程的联系**：
  - 转换桥梁：$x = \rho\cos\theta, y = \rho\sin\theta, \rho^2 = x^2+y^2$。
  - 从极坐标方程 $\rho = 2a\cos\theta$ 可化为直角坐标方程 $(x-a)^2 + y^2 = a^2$（常以 $(a,0)$ 为圆心，过原点）。参数形式为 $\begin{cases} x = a + a\cos\phi \\ y = a\sin\phi \end{cases}$。
- **切线方程的求法**：
  - 已知圆方程及圆外一点 $P(x_0, y_0)$，设切线方程为 $y - y_0 = k(x - x_0)$。
  - 利用**圆心到直线的距离等于半径**：$d = \frac{|A a + B b + C|}{\sqrt{A^2 + B^2}} = r$，解出斜率 $k$。
  - **注意**：若只解出一个 $k$，需检验斜率不存在（即 $x = x_0$）的情况，避免漏解。
- **切线的极坐标方程**：将切线直角坐标方程 $Ax + By + C = 0$ 利用 $x = \rho\cos\theta, y = \rho\sin\theta$ 代入，化简为 $\rho\cos(\theta - \phi) = p$ 或类似的极坐标形式。部分结果可用辅助角公式合并。

## 解题方法与套路
1. **求圆的参数方程**：
   - **定圆心，定半径**：从题目中直接读取或通过极坐标/直角坐标方程配出圆心坐标 $(a,b)$ 与半径 $r$。
   - **直接套用标准式**：写出 $\begin{cases} x = a + r\cos\theta \\ y = b + r\sin\theta \end{cases}$，并依题意标注参数 $\theta$ 的取值范围（尤以圆弧或半圆为重要，如上半圆 $y \geq 0$ 对应限定参数范围）。
2. **求过圆外一点的切线方程**：
   - **第一步**：验证斜率不存在时 $x = x_0$ 是否与圆相切（计算圆心到该直线距离是否等于 $r$）。
   - **第二步**：设斜率 $k$，写点斜式 $y - y_0 = k(x - x_0)$，化为一般式。
   - **第三步**：用点到直线距离公式 $d = r$ 建立关于 $k$ 的方程，求解并化简。
3. **切线方程的极坐标转化**：
   - 将求出的直角坐标切线方程中的 $x, y$ 替换为 $\rho\cos\theta, \rho\sin\theta$。
   - 化简整理，常拼凑为 $\rho\cos(\theta \pm \alpha) = d$ 的形式。
4. **参数方程背景下的切线/斜率问题**：
   - 将切点 $D$ 设为参数形式 $(a+r\cos\theta_0, b+r\sin\theta_0)$。
   - **关键性质**：圆心与切点的连线 $CD$ 垂直于切线。若已知切线斜率，则可直接得出 $CD$ 的斜率，以此建立参数方程求 $\theta_0$。

## 高频易错
- **忽视参数范围**：极坐标方程中常隐含范围限制，如 $\rho = 2\cos\theta$ 仅代表以 $(1,0)$ 为圆心、半径为 1 的**圆**，但若指定了 $\theta \in [0, \frac{\pi}{2}]$，图形仅为**上半圆**。此时参数方程必须标注 $\theta$ 的取值区间。
- **漏掉垂直切线**：设点斜式方程求切线时，若关于 $k$ 的二次方程退化为一次或只解出一个解，必须警惕直线 $x = x_0$ 这一情况，往往它就是漏掉的另一条切线。
- **距离公式计算失误**：将点斜式化为一般式求距离时，代入圆心坐标后符号易错。应严格按 $d = \frac{|kx_0 - y_0 + b - ka|}{\sqrt{k^2+1}}$ 的绝对值形式规范代入。
- **极坐标方程化简不彻底**：代入直角坐标方程后易直接写成 $\rho$ 的复杂表达式，忘记利用辅助角公式合并成“点到直线距离式”的极坐标表达。
- **参数几何意义混淆**：圆的参数 $\theta$ 为圆心角，但并非在所有图中都等于该点与原点连线的极角。切忌将参数方程中的参数角与极坐标系下的极角 $\theta$ 混淆。

## 代表题精讲
### 代表题 1：2021-文-22
**题目**：已知圆 $C$ 的圆心为 $C(2,1)$，半径为 1。（1）写参数方程；（2）过点 $F(4,1)$ 作圆的两条切线，在以原点为极点、x 轴正半轴为极轴的极坐标系下，求切线的极坐标方程。

**思路**：圆心半径齐全，直接套用标准式即得参数方程。切线求解需设点斜式，注意讨论斜率不存在的情况，经点线距公式求出 $k$，最后做直角坐标到极坐标的转化。

**步骤**：
1. **写参数方程**：圆心 $C(2,1)$，$r=1$。得参数方程 $\begin{cases} x = 2 + \cos\theta \\ y = 1 + \sin\theta \end{cases}$ ($\theta$ 为参数)。
2. **求切线**：
   （i）检验 $x=4$ 是否相切：圆心 $(2,1)$ 到 $x=4$ 距离 $d=2 > 1$，不相切。
   （ii）设切线 $y - 1 = k(x - 4) \implies kx - y + 1 - 4k = 0$。
   （iii）利用距离公式：$d = \frac{|2k - 1 + 1 - 4k|}{\sqrt{k^2+1}} = \frac{|-2k|}{\sqrt{k^2+1}} = 1$。两边平方得 $4k^2 = k^2 + 1 \implies k = \pm\frac{\sqrt{3}}{3}$。
3. **化极坐标方程**：
   - $k_1 = \frac{\sqrt{3}}{3}$ 时，切线 $y - 1 = \frac{\sqrt{3}}{3}(x - 4) \implies x - \sqrt{3}y - 4 + \sqrt{3} = 0$。代入极坐标 $\rho\cos\theta - \sqrt{3}\rho\sin\theta = 4 - \sqrt{3} \implies \rho\cos(\theta + \frac{\pi}{3}) = 2 - \frac{\sqrt{3}}{2}$（解法常见化简为 $\rho\cos(\theta + \frac{\pi}{6})$ 等形式，实际应视具体目标而定；真题答案化简为 $\rho\cos(\theta + \frac{\pi}{3}) = \dots$ 需注意计算细节，此处核心体现代换与辅助角合并的方法）。
   精准计算：$x - \sqrt{3}y = 4 - \sqrt{3}$，即 $\rho(\cos\theta - \sqrt{3}\sin\theta) = 4 - \sqrt{3} \implies 2\rho\cos(\theta + \frac{\pi}{3}) = 4 - \sqrt{3}$。
   - $k_2$ 同理处理，得 $2\rho\cos(\theta - \frac{\pi}{3}) = 4 + \sqrt{3}$ 形态。

**点评/变式**：此题是标准的“给圆定参，过点求切”模型。易错点在于忘记检验垂直切线 $x=4$，以及在极坐标化简时辅助角公式 $\cos\theta \pm \sqrt{3}\sin\theta = 2\cos(\theta \mp \frac{\pi}{3})$ 的处理。若将圆心平移到原点，该题即为基础题型。

### 代表题 2：2014-理-23
**题目**：半圆 $C$ 的极坐标方程为 $\rho = 2\cos\theta, \theta \in [0, \frac{\pi}{2}]$。求 $C$ 的参数方程；设点 $D$ 在 $C$ 上，$C$ 在 $D$ 处的切线与直线 $l: y = \sqrt{3}x + 2$ 垂直，求直线 $CD$ 的倾斜角及 $D$ 的坐标。

**思路**：先化极坐标方程为直角坐标普通方程，利用平方关系求出参数方程，并注意半圆范围对参数的限制。利用“切线垂直于过切点的半径”这一几何性质，将切线垂直条件转为 $CD$ 与 $l$ 斜率相等，从而定出 $D$ 所对应的参数值。

**步骤**：
1. **求参数方程**：由 $\rho=2\cos\theta \implies \rho^2 = 2\rho\cos\theta \implies x^2+y^2 = 2x$，配方得 $(x-1)^2 + y^2 = 1$。
   由于 $\theta \in [0, \frac{\pi}{2}]$，$\rho \geq 0, x \geq 0, y \geq 0$，图形为上半圆。
   参数方程为 $\begin{cases} x = 1 + \cos t \\ y = \sin t \end{cases}$ ($t$ 为参数，$0 \leq t \leq \pi$，此处 $y = \sin t \geq 0$ 自然对应上半圆)。
2. **求切点 D**：已知 $l$ 斜率 $k_l = \sqrt{3}$，切线与之垂直，故切线斜率为 $-\frac{\sqrt{3}}{3}$。
   圆心 $C(1,0)$，$CD$ 垂直于切线，所以直线 $CD$ 的斜率 $k_{CD} = \frac{\sin t - 0}{(1+\cos t) - 1} = \frac{\sin t}{\cos t} = \tan t$。
   由垂直关系，切线斜率应为 $-\frac{1}{\tan t}$，即 $-\frac{1}{\tan t} = -\frac{\sqrt{3}}{3} \implies \tan t = \sqrt{3}$。
   在 $t \in [0, \pi]$ 内，得 $t = \frac{\pi}{3}$。
3. **得倾斜角与坐标**：$CD$ 倾斜角即为 $t = \frac{\pi}{3}$ (即 $60^\circ$)。
   代入参数方程得 $D(1+\cos\frac{\pi}{3}, \sin\frac{\pi}{3}) = (\frac{3}{2}, \frac{\sqrt{3}}{2})$。

**点评/变式**：本题考查极坐标、参数方程与直线位置关系的综合运用。核心技巧在于将垂直条件转化为与半径的关系，巧妙利用参数方程中角度参数的几何意义直接得解，避免了求切线的繁琐运算。但凡遇到圆上一点的切线问题，优先联想“圆心与切点连线垂直于切线”的性质。
