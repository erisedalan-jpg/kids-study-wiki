## 知识精要

- **圆的标准方程**：$(x-a)^2+(y-b)^2=r^2$，圆心 $(a,b)$，半径 $r$。求圆方程的核心就是**定圆心、定半径**两件事。
- **圆的一般方程**：$x^2+y^2+Dx+Ey+F=0$（$D^2+E^2-4F>0$），圆心 $\left(-\dfrac{D}{2},-\dfrac{E}{2}\right)$，半径 $r=\dfrac{1}{2}\sqrt{D^2+E^2-4F}$。
- **直线与圆的位置关系**：比较圆心到直线距离 $d$ 与半径 $r$：$d<r$ 相交，$d=r$ 相切，$d>r$ 相离。**相交弦长** $|AB|=2\sqrt{r^2-d^2}$（弦心距、半径、半弦长构成直角三角形）。
- **圆与圆位置关系**：圆心距 $d$ 与 $|r_1-r_2|$、$r_1+r_2$ 比较；两圆方程相减得**公共弦所在直线方程**。
- **抛物线相关定值**：$y^2=2px$ 焦点 $\left(\dfrac{p}{2},0\right)$，准线 $x=-\dfrac{p}{2}$；$x^2=2py$ 焦点 $\left(0,\dfrac{p}{2}\right)$，准线 $y=-\dfrac{p}{2}$。焦点弦 $|AB|=x_1+x_2+p$（横轴型）。由定义，抛物线上点到焦点距离 = 到准线距离。
- **极坐标下的圆**：圆心在极轴上、过极点、半径 $\dfrac{a}{2}$ 的圆，极坐标方程为 $\rho=a\cos\theta$；圆心在 $\dfrac{\pi}{2}$ 方向则为 $\rho=a\sin\theta$。
- **切线与切点**：圆 / 圆锥曲线的切线问题，常用"圆心到切线距离 = 半径"或对曲线求导得切线斜率。

## 解题方法与套路

1. **待定圆方程**：① 几何条件明显（已知圆心或圆心在某直线上）用标准式，先定圆心再算半径；② 已知三点用一般式，代入解 $D,E,F$。
2. **过两点且与定直线相切的圆**：① 圆心在两点连线的中垂线上；② 半径 = 圆心到切线距离 = 圆心到两点距离；③ 列方程组解圆心坐标与半径。
3. **抛物线焦点弦定半径**：求"过弦 $AB$ 两端且与准线相切的圆"——圆心是弦 $AB$ 中点（因弦为直径时半径 = 半弦长，且中点到准线距离 = 半焦点弦 = 半弦长，恰相切），半径 = $\dfrac{1}{2}|AB|$。
4. **几何法求离心率（圆 + 圆锥曲线）**：① 按对称性精确作图；② 利用"以 $OF$ 为直径的圆"等几何性质（直径所对圆周角为直角）写出交点坐标；③ 把交点代入另一圆 / 曲线方程，得到 $a,b,c$ 关系，求 $e$。
5. **切线长与面积最值**：设动点坐标（在已知圆上参数化），用导数求两切线及切点弦 $AB$ 方程，联立曲线求 $|AB|$ 和点到 $AB$ 的距离，面积表示成参数的函数，用二次函数 / 求导求最值。
6. **参数方程与极坐标互化**：消参化普通方程（三角参数用 $\sin^2+\cos^2=1$）；普通方程经 $x=\rho\cos\theta,\ y=\rho\sin\theta,\ x^2+y^2=\rho^2$ 化极坐标。

## 高频易错

- **一般方程忘记验证 $D^2+E^2-4F>0$**：否则不表示圆（可能是点或空集）。
- **弦长公式张冠李戴**：$|AB|=2\sqrt{r^2-d^2}$ 中 $d$ 是圆心到直线距离，不是到端点距离。
- **抛物线焦点 / 准线参数 $p$ 与 $\dfrac{p}{2}$ 混淆**：$y^2=2px$ 焦点为 $\left(\dfrac{p}{2},0\right)$，不是 $(p,0)$。
- **"与准线相切的圆"未抓住半径 = 半弦长这一几何关系**，盲目设一般式导致计算繁琐。
- **几何法求离心率漏验范围**：双曲线 $e>1$，椭圆 $0<e<1$，解出后须取舍。
- **极坐标方程符号**：$\rho=a\cos\theta$（极轴方向）与 $\rho=a\sin\theta$（$\dfrac{\pi}{2}$ 方向）方向写反。
- **参数方程化普通方程后丢失变量范围**：参数有界时普通方程应注明 $x,y$ 取值范围。

## 代表题精讲

**代表题一（2018·理·19，过焦点弦两端且与准线相切的圆）**

**题目**：抛物线 $C:y^2=4x$ 焦点为 $F$，过 $F$ 且斜率 $k>0$ 的直线 $l$ 交 $C$ 于 $A,B$，$|AB|=8$。求 $l$ 的方程，及过 $A,B$ 且与 $C$ 的准线相切的圆的方程。

**思路**：用焦点弦公式 $|AB|=x_1+x_2+p$ 定 $k$；圆以 $AB$ 为直径（半径 = 半弦长，圆心 = $AB$ 中点），圆心到准线距离恰等于半径即满足相切。

**步骤**：
1. $C:y^2=4x$ 中 $2p=4$，$p=2$，焦点 $F(1,0)$，准线 $x=-1$。设 $l:y=k(x-1)$。
2. 代入抛物线：$k^2x^2-(2k^2+4)x+k^2=0$，$x_1+x_2=\dfrac{2k^2+4}{k^2}$。
3. 焦点弦 $|AB|=x_1+x_2+p=\dfrac{2k^2+4}{k^2}+2=8$，解得 $k^2=1$，又 $k>0$ 故 $k=1$，$l:y=x-1$。
4. 此时 $x_1+x_2=6$，中点 $M$ 横坐标 $3$，由 $y=x-1$ 得 $M(3,2)$。
5. 圆以 $AB$ 为直径，半径 $r=\dfrac{1}{2}|AB|=4$；中点 $M$ 到准线 $x=-1$ 的距离 $=3-(-1)=4=r$，故与准线相切。
6. 圆方程：$(x-3)^2+(y-2)^2=16$。

**点评**：抓住"焦点弦中点到准线距离 = 半弦长"是本题的几何灵魂，避免了联立求 $A,B$ 坐标的繁琐。变式：若 $k<0$ 同理得对称的另一解；若改为"与 $y$ 轴相切"，则半径改为中点到 $y$ 轴距离。

**代表题二（2019·文·12 / 理·11，圆的对称性求双曲线离心率）**

**题目**：双曲线 $C:\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$ 右焦点 $F$，$O$ 为原点。以 $OF$ 为直径的圆与圆 $x^2+y^2=a^2$ 交于 $P,Q$，若 $|PQ|=|OF|$，求 $e$（答案 $\sqrt{2}$，选 A）。

**思路**：两圆交点关于 $x$ 轴对称，$PQ\perp x$ 轴；由 $|PQ|=|OF|=c$ 定出 $P$ 坐标，代入 $x^2+y^2=a^2$ 得 $a,c$ 关系。

**步骤**：
1. 设 $PQ$ 与 $x$ 轴交于 $A$，由对称性 $PQ\perp x$ 轴。$|PQ|=|OF|=c$，故 $|PA|=\dfrac{c}{2}$。
2. $PA$ 是以 $OF$ 为直径的圆的半径，半径为 $\dfrac{c}{2}$，故 $A$ 是该圆圆心，$|OA|=\dfrac{c}{2}$，即 $P\left(\dfrac{c}{2},\dfrac{c}{2}\right)$。
3. $P$ 在圆 $x^2+y^2=a^2$ 上：$\dfrac{c^2}{4}+\dfrac{c^2}{4}=a^2$，即 $\dfrac{c^2}{2}=a^2$，$\dfrac{c^2}{a^2}=2$，$e=\sqrt{2}$，选 A。

**点评**：以线段为直径的圆，直径所对圆周角为直角，是几何法定坐标的常用桥梁。验证 $e=\sqrt{2}>1$ 符合双曲线。变式：把内圆改为 $x^2+y^2=b^2$，仅最后代入方程不同。

**代表题三（2021·理·21，圆上动点引抛物线切线求三角形面积最大值）**

**题目**：抛物线 $C:x^2=2py\ (p>0)$ 焦点 $F$ 与圆 $M:x^2+(y+4)^2=1$ 上点距离最小值为 $4$。求 $p$；$P$ 在 $M$ 上，$PA,PB$ 为 $C$ 的两条切线，$A,B$ 为切点，求 $\triangle PAB$ 面积的最大值。

**思路**：圆外一点到圆上点的最近距离 = 该点到圆心距离 $-$ 半径，定 $p$；设 $P$ 在圆上参数化，由导数写切点弦 $AB$ 方程，面积表为 $P$ 纵坐标的函数求最值。

**步骤**：
1. $F\left(0,\dfrac{p}{2}\right)$，$M$ 圆心 $(0,-4)$、半径 $1$。$F$ 到圆上点最小距离 $=|FM|-1=\left(\dfrac{p}{2}+4\right)-1=4$，解得 $p=2$，故 $C:x^2=4y$。
2. 设切点 $A(x_1,y_1),B(x_2,y_2)$，$P(x_0,y_0)$。由 $y=\dfrac{x^2}{4}$，$y'=\dfrac{x}{2}$，切线 $PA:y=\dfrac{x_1}{2}(x-x_1)+y_1$。由两切线均过 $P$，得切点弦 $AB$ 方程 $x_0x=2(y+y_0)$。
3. 联立 $AB$ 与 $x^2=4y$，得 $|AB|$ 与点 $P$ 到 $AB$ 距离，面积 $S=\dfrac{1}{2}|AB|\cdot d$ 整理为关于 $y_0$ 的函数。
4. $P$ 在圆 $M$ 上故 $y_0\in[-5,-3]$，$S(y_0)=(x_0^2-4y_0)^{3/2}/2$，其中 $x_0^2=1-(y_0+4)^2$；代入得 $S$ 关于 $y_0$ 在 $[-5,-3]$ 上的表达式，求导（或单调性）得 $y_0=-5$ 时面积最大，最大值为 $20\sqrt{5}$。

**点评**：本题综合"圆外点最近距离 + 切点弦（极线）方程 + 闭区间最值"。切点弦方程 $x_0x=2(y+y_0)$ 是抛物线切线问题的利器。变式：改圆为椭圆约束，方法框架不变，仅参数范围与代入方程不同。
