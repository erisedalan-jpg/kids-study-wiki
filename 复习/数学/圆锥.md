## 知识精要
- **圆锥的定义**：以直角三角形的一条直角边所在直线为旋转轴，其余两边旋转形成的面所围成的旋转体。轴截面为等腰三角形。
- **核心公式**：
  - 侧面积：$S_{\text{侧}} = \pi r l$（$r$ 底面半径，$l$ 母线长）
  - 全面积：$S_{\text{全}} = \pi r (r + l)$
  - 体积：$V = \frac{1}{3} \pi r^2 h$（$h$ 为高）
- **球与圆锥的结合**：
  - 若圆锥顶点和底面圆周均在球面上，则圆锥内接于球。
  - 轴截面中，球的大圆与圆锥的轴截面等腰三角形外接，球心在圆锥的高所在直线上。
  - 设球半径为 $R$，圆锥底面半径为 $r$，球心到圆锥底面的距离为 $d$（$|d| < R$），则 $R^2 = r^2 + d^2$。
- **本题特有情形**：两个圆锥有公共底面，且顶点和底面圆周都在同一球面上。此时两个圆锥的顶点关于底面所在平面对称，球心必在公共底面的垂线上，两圆锥的高分别为 $R + d$ 和 $R - d$（或 $|R - d|$，需讨论球心与底面的相对位置）。

## 解题方法与套路
1. **画轴截面**：将空间问题平面化，画出过球心且垂直于公共底面的截面，得到球的大圆和内接的两个等腰三角形（共底边，顶点分居两侧）。
2. **设元建立方程**：
   - 设球的半径为 $R$，公共底面半径为 $r$，球心到公共底面的距离为 $d$（可取正值，结合图形判断球心位置）。
   - 利用勾股关系：$R^2 = r^2 + d^2$。
3. **利用已知面积比**：根据“圆锥底面面积是这个球面面积的 $\frac{3}{16}$”列出方程：
   $$\frac{\pi r^2}{4\pi R^2} = \frac{3}{16} \quad \Rightarrow \quad \frac{r^2}{R^2} = \frac{3}{4}$$
4. **求 $d$**：联立 $r^2 = \frac{3}{4}R^2$ 与 $r^2 + d^2 = R^2$，得 $d^2 = \frac{1}{4}R^2$，即 $d = \frac{1}{2}R$（$d > 0$）。
5. **定两圆锥的高**：球心在公共底面一侧时，两高为 $h_1 = R + d = \frac{3}{2}R$，$h_2 = R - d = \frac{1}{2}R$；若球心在公共底面上，则 $d=0$，两高相等，与面积比矛盾；若底面在球心上方，对称可知结果相同。
6. **计算体积比**：两圆锥底面相同，体积比等于高之比：
   $$\frac{V_{\text{小}}}{V_{\text{大}}} = \frac{h_{\text{小}}}{h_{\text{大}}} = \frac{\frac{1}{2}R}{\frac{3}{2}R} = \frac{1}{3}$$
   故比值为 $\frac{1}{3}$（或回答较小与较大者之比为 $1:3$）。

## 高频易错
- **漏掉球心位置讨论**：直接默认球心在公共底面上（$d=0$），导致无法满足题目条件，或错误认为两圆锥等高。实际由已知面积比可唯一确定 $d \neq 0$，但仍需注意分类意识。
- **面积公式记错**：球的表面积公式 $S = 4\pi R^2$，容易误写为 $\pi R^2$ 或 $2\pi R^2$；圆锥底面积为 $\pi r^2$，切勿混淆。
- **体积比直接代错高**：$h_1$ 与 $h_2$ 一为 $R+d$，一为 $|R-d|$，计算时忽略绝对值，可能将较小体积的高写成 $d-R$（当 $d>R$ 时无意义）。
- **几何关系理解偏差**：两个圆锥顶点和底面圆周都在同一球面上，球心不一定在公共底面内，正确理解是公共底面为球的一个小圆，球心在过圆心且垂直于该小圆面的直线上。

## 代表题精讲
### 代表题 2011-文-16
**题目**：已知两个圆锥有公共底面，且两个圆锥的顶点和底面的圆周都在同一个球面上。若圆锥底面面积是这个球面面积的 $\frac{3}{16}$，则这两个圆锥中，体积较小者的体积与体积较大者的体积的比值为______。

**思路**：抓住公共底面即球的一个小圆，利用面积比得到半径平方比，借助轴截面中球心到小圆的距离建立两圆锥高的表达式，最后体积比转化为高之比。

**步骤**：
1. 画轴截面图：球心 $O$，球半径 $R$；公共底面圆心 $O_1$，半径 $r$；$O$ 到 $O_1$ 的距离 $d$（$O$ 在 $O_1$ 上方）。过 $O$ 的直径两端点 $A$、$B$ 为两圆锥顶点，$O_1$ 在 $AB$ 上，则 $AO_1 = R+d$，$BO_1 = R-d$。
2. 由底面面积与球面积关系：$\frac{\pi r^2}{4\pi R^2} = \frac{3}{16} \Rightarrow r^2 = \frac{3}{4}R^2$。
3. 在 $\triangle OO_1C$（$C$ 为底面圆周上一点）中，$OC = R$，$O_1C = r$，有 $R^2 = r^2 + d^2$，代入得 $d^2 = \frac{1}{4}R^2$，取 $d = \frac{1}{2}R$。
4. 两圆锥的高：$h_1 = R + d = \frac{3}{2}R$（大），$h_2 = R - d = \frac{1}{2}R$（小）。
5. 体积比：$\frac{V_{\text{小}}}{V_{\text{大}}} = \frac{\frac{1}{3}\pi r^2 h_2}{\frac{1}{3}\pi r^2 h_1} = \frac{h_2}{h_1} = \frac{1}{3}$。

**点评/变式**：本题核心是用平面截球，将立体几何降维到圆与弦的关系。若题干改为“底面圆周恰好是球的一个大圆”，则 $d=0$，两圆锥母线均为 $R$，体积比变为 $1:1$，但此时底面面积与球面积之比为 $\frac{\pi R^2}{4\pi R^2} = \frac{1}{4}$，非 $\frac{3}{16}$。可见题中比值 $\frac{3}{16}$ 是精心设计，确保 $d \neq 0$ 且产生确定的比例。考试时可快速检验：由 $\frac{r^2}{R^2} = \frac{3}{4}$ 联想 $3-4-5$ 三角形，常见模型 $r=\frac{\sqrt{3}}{2}R, d=\frac{1}{2}R$。
