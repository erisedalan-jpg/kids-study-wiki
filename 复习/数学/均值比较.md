## 知识精要

- **样本平均数**：对于样本数据 $x_1, x_2, \dots, x_n$，  
  $$\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i$$

- **样本方差**：刻画样本数据离散程度的指标，高考范围采用分母为 $n$ 的定义  
  $$s^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2 = \frac{1}{n}\left(\sum_{i=1}^{n}x_i^2\right) - \bar{x}^2$$

- **两样本均值比较（固定阈值法）**：  
  设有两个独立样本，容量相等为 $n$，样本均值分别为 $\bar{x}$、$\bar{y}$，样本方差分别为 $s_1^2$、$s_2^2$。  
  为判断“新指标均值是否显著高于旧指标均值”，若满足  
  $$\bar{y} - \bar{x} \ge 2\sqrt{\frac{s_1^2 + s_2^2}{n}}$$  
  则认为有**显著提高**；否则不认为有显著提高。  

  **适用条件**：两个独立样本、样本容量相等、指标近似服从正态分布或样本量不太小时，题目会直接给出判断准则，只需准确代入计算。该准则本质是两总体均值差异的简化检验，结合了方差差异的度量。

- 注意：此处的比较通常是**右侧检验**（新设备指标是否提高），阈值由 $2\sqrt{\frac{s_1^2+s_2^2}{n}}$ 给定。

## 解题方法与套路

1. **读题识别**：看到“检验新设备指标有无显著提高”“根据规则判断是否认为有显著提高”和给出的形如 $\bar{y}-\bar{x} \ge k\sqrt{\frac{s_1^2+s_2^2}{n}}$ 的条件，即为均值比较类计算题。

2. **准确计算样本均值**：  
   分别列出两组数据，利用 $\bar{x} = \frac{\sum x_i}{n}$ 精确求出 $\bar{x}$ 和 $\bar{y}$。数据多位小数时，可先求和再除以 $n$，保留合适的精度（通常保留一位或两位小数即可）。

3. **准确计算样本方差**：  
   优先使用简化公式 $s^2 = \frac{1}{n}\sum x_i^2 - \bar{x}^2$，避免逐个作差累积误差。先计算每个数据的平方和，再减去均值平方乘以 $n$ 的部分。注意分母为 $n$，不是 $n-1$。

4. **代入阈值条件**：  
   将求得的 $\bar{x}$、$\bar{y}$、$s_1^2$、$s_2^2$ 与 $n$（本题常为 $10$）代入右端表达式，计算 $2\sqrt{\frac{s_1^2+s_2^2}{n}}$，得到阈值。

5. **做差比较并下结论**：  
   计算 $\bar{y} - \bar{x}$，与阈值比较：
   - 若 $\bar{y} - \bar{x} \ge \text{阈值}$，则“有显著提高”；
   - 否则“无显著提高”。
   结论要完整，回扣题目问题。

6. **检查计算**：方差、均值的运算容易出错，可利用“数据对称性质”或回代验证。

## 高频易错

- **方差分母用错**：高考计算样本方差时明确要求分母为 $n$（不是 $n-1$），直接用 $\frac{1}{n}\sum (x_i - \bar{x})^2$。  
- **平方和计算疏忽**：手算 $\sum x_i^2$ 时易漏平方或加错，建议两两核对，数值较整齐时可先观察。  
- **混淆两个样本的均值和方差**：计算时代错数据，导致 $s_1^2$ 与 $s_2^2$ 颠倒。  
- **未开方或多乘平方**：阈值表达式中根号下是方差和除以 $n$，外面乘 $2$，计算时可能忘了开平方根，或者把根号只分配给部分项。  
- **比较方向误判**：题目要求“有无提高”，必须计算 $\bar{y}-\bar{x}$（新减旧），不是绝对值。若新均值反而低，差值为负，自然不满足 $\ge$，不能误取绝对值比较。  
- **结果表述不规范**：“有显著提高”与“无显著提高”需按题设原话写，勿自创“显著性好”等术语。
