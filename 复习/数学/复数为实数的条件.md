## 知识精要
- **复数的标准形式**：$z=a+bi\;(a,b\in\mathbb R)$，其中 $a$ 为实部，$b$ 为虚部。  
- **复数为实数的充要条件**：$b=0$（虚部为零）。  
  更一般地，对于任意复数表达式，先通过代数运算将其化为 $a+bi$ 的形式，再令虚部为零即可。  
- **常用运算性质**（$i^2=-1$）：  
  $$(a+bi)^2=a^2-b^2+2abi$$  
  $$(a+bi)^3=a^3+3a^2bi-3ab^2-b^3i=(a^3-3ab^2)+(3a^2b-b^3)i$$  
  $$(a+bi)^n\;(n\in\mathbb N^*)$$ 可使用二项式定理展开，注意 $i$ 的幂次周期：$i^2=-1,\;i^3=-i,\;i^4=1\ldots$  
- **适用条件**：题目中给定的 $a,b$ 均为实数，若附加 $b\neq0$ 说明虚部非零，在解方程时应排除 $b=0$ 的无效解。

## 解题方法与套路
1. **化为标准形**：将题给复数表达式通过乘法展开、合并同类项，整理成 $A+Bi$（$A,B\in\mathbb R$）的形式。  
2. **提取虚部**：明确写出虚部 $B$（通常是含参数的表达式）。  
3. **令虚部为零**：由复数为实数 $\Leftrightarrow B=0$ 列出方程。  
4. **解方程得参数关系**：结合题目附加条件（如 $b\neq0$）合理化简方程，避免丢失或增解。  
5. **验证与对应选项**：将结果化为最简关系式，对照选项选出正确答案。

## 高频易错
- **忘记 $i^2=-1$ 导致实部、虚部符号错误**：展开 $(a+bi)^3$ 时，中间项 $3a(bi)^2=3a\cdot b^2i^2=-3ab^2$，容易遗漏负号而错误地将其计入虚部。  
- **虚部提取不完整**：展开时需严格区分实部和含 $i$ 的虚部，将所有含 $i$ 的项合并后再提取系数，不可将部分实数项误当作虚部。  
- **忽略附加条件 $b\neq0$**：由 $3a^2b-b^3=0$ 得 $b(3a^2-b^2)=0$，若不排除 $b=0$ 会得到 $b=0$ 或 $b^2=3a^2$，但 $b=0$ 与已知矛盾，必须舍去。  
- **将 “复数为实数” 与 “复数为纯虚数” 混淆**：纯虚数要求实部为零且虚部不为零，实数只要虚部为零，不应记混。

## 代表题精讲
**题目** （2008·理·02）  
设 $a,b\in\mathbb R$ 且 $b\neq0$，若复数 $(a+bi)^3$ 是实数，则（ ）  
A. $b^2=3a^2$　B. $a^2=3b^2$　C. $b^2=9a^2$　D. $a^2=9b^2$

**思路**  
直接将 $(a+bi)^3$ 展开为 $A+Bi$ 的形式，利用它是实数得到虚部 $B=0$，代入 $b\neq0$ 解出 $a,b$ 的关系。  

**步骤**  
1. 展开：  
   $$(a+bi)^3 = a^3 + 3a^2(bi) + 3a(bi)^2 + (bi)^3$$  
   化简：$=a^3+3a^2bi -3ab^2 -b^3i = (a^3-3ab^2)+(3a^2b-b^3)i$。  
2. 由复数为实数，令虚部为零：  
   $$3a^2b - b^3 = 0 \;\Rightarrow\; b(3a^2 - b^2)=0$$  
3. 因为 $b\neq0$，所以 $3a^2 - b^2=0$，即 $b^2 = 3a^2$。  
4. 对应选项，选 A。

**点评/变式**  
- 本题直接考查复数为实数的充要条件和二项式展开，属于基础题，务必算准系数。  
- 变式：若 $(a+bi)^3$ 为纯虚数，则需实部为零且虚部非零，即 $a^3-3ab^2=0$ 且 $3a^2b-b^3\neq0$，结合 $b\neq0$ 可推出 $a=0$ 或 $a^2=3b^2$。  
- 高次幂问题同样可先化成三角形式 $r(\cos\theta+i\sin\theta)$ 利用棣莫弗定理处理，但低次展开亦足够快速。
