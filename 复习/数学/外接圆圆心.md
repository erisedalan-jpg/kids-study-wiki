## 知识精要
- **三角形的外接圆**：经过三角形三个顶点的圆，其圆心 O 称为外心。
- **外心的性质**：
  - 外心到三角形三个顶点的距离相等，该距离即为外接圆半径 $R$。
  - 外心是三角形三条边的垂直平分线的交点。
  - 锐角三角形外心在三角形内部；直角三角形外心在斜边中点上；钝角三角形外心在三角形外部。
- **坐标法求外心**：
  - 设圆心坐标 $O(x_0,y_0)$，由 $|OA| = |OB| = |OC|$ 建立方程组，解出 $x_0,y_0$。
  - 也可求出任意两条边的垂直平分线方程，其交点即为外心。
- **距离公式**：点 $P(x_1,y_1)$ 到原点 $(0,0)$ 的距离 $d = \sqrt{x_1^2+y_1^2}$。

## 解题方法与套路
1. **设圆心坐标**：设外接圆圆心为 $O(a,b)$。
2. **列距离相等方程**：利用 $|OA|^2=|OB|^2$ 和 $|OB|^2=|OC|^2$（或 $|OA|^2=|OC|^2$）得到两个关于 $a,b$ 的方程，消去平方项简化为二元一次方程组。
3. **解出圆心坐标**：联立解出 $a,b$，得到外心。
4. **计算所求量**：根据问题（如到原点的距离）代入距离公式计算，注意结果的化简。
5. **特殊情形优先判断**：若三角形为直角三角形，外心可直接写为斜边中点，从而简化计算。

## 高频易错
- **坐标代入平方出错**：列方程时，将两点坐标差的平方和算错，尤其是负号和根式的平方。
- **忽视直角三角形的简便解法**：拿到三点坐标未先判断是否构成直角三角形，硬用一般方程求解，增加计算量和出错可能。
- **解方程组时消元失误**：两个二次方程相减得到一次方程时，符号或系数易出错，建议分步检查。
- **距离求平方后忘记开方**：最终问题是求距离，解出 $a,b$ 后直接当成距离，忘记计算 $\sqrt{a^2+b^2}$。
- **选项干扰**：选择题中，开方后未与选项匹配，或因近似值混淆精确值。

## 代表题精讲
**题目**（2015·全国Ⅰ卷文7）：已知三点 $A(1,0), B(0,\sqrt{3}), C(2,\sqrt{3})$，则 $\triangle ABC$ 外接圆的圆心到原点的距离为  
A. $\dfrac{5}{3}$　B. $\dfrac{\sqrt{21}}{3}$　C. $\dfrac{2\sqrt{5}}{3}$　D. $\dfrac{4}{3}$

**思路**  
观察三点坐标，$A(1,0)$ 与 $B,C$ 无明显直角特征，可直接设外心坐标 $O(a,b)$，由 $|OA|=|OB|$ 和 $|OB|=|OC|$ 列方程组求解。

**步骤**  
1. 设外心 $O(a,b)$，由 $|OA|^2 = |OB|^2$ 得：  
   $$(a-1)^2 + (b-0)^2 = (a-0)^2 + (b-\sqrt{3})^2$$
   展开化简：  
   $$a^2-2a+1+b^2 = a^2+b^2-2\sqrt{3}b+3$$  
   消去 $a^2+b^2$，得 $-2a+1 = -2\sqrt{3}b+3$  
   整理：$-2a + 2\sqrt{3}b = 2$，即 $a - \sqrt{3}b = -1$　……①
2. 由 $|OB|^2 = |OC|^2$ 得：  
   $$(a-0)^2+(b-\sqrt{3})^2 = (a-2)^2+(b-\sqrt{3})^2$$  
   两边消去相同的 $(b-\sqrt{3})^2$，得：  
   $$a^2 = (a-2)^2 \Rightarrow a^2 = a^2 -4a +4$$  
   解得 $4a=4$，即 $a=1$。
3. 代入①：$1 - \sqrt{3}b = -1$，得 $\sqrt{3}b=2$，$b = \dfrac{2}{\sqrt{3}} = \dfrac{2\sqrt{3}}{3}$。  
   所以外心 $O\left(1, \dfrac{2\sqrt{3}}{3}\right)$。
4. 外心到原点的距离 $d = \sqrt{1^2 + \left(\dfrac{2\sqrt{3}}{3}\right)^2} = \sqrt{1 + \dfrac{12}{9}} = \sqrt{1+\dfrac{4}{3}} = \sqrt{\dfrac{7}{3}} = \dfrac{\sqrt{21}}{3}$。  
   对应选项 B。

**点评/变式**  
- 本题方程②因 $B,C$ 纵坐标相同，消去纵坐标差后得到 $a^2=(a-2)^2$，计算极其简单。这是命题人有意设置的简化点，应敏锐捕捉。
- 若三点无纵坐标相等的优势，则需完整解二元一次线性方程组，计算量稍大但步骤不变。
- **变式训练**：已知 $\triangle ABC$ 顶点 $A(0,2), B(2,0), C(-1,0)$，求其外接圆圆心到原点距离。（提示：先判断形状，$AB$ 斜率 $-1$，$AC$ 斜率？计算发现是直角三角形，外心为斜边中点，避免复杂方程）。
