## 知识精要
- 向量的数量积（内积）：$a\cdot b = |a||b|\cos\theta$，其中$\theta$为非零向量$a,b$的夹角，$\theta\in[0,\pi]$。
- 夹角公式（由数量积变形）：$\cos\theta = \dfrac{a\cdot b}{|a||b|}$，常用于求角或构建方程。
- 向量的模及其平方性质：
  $|a|^2 = a\cdot a$；
  $|a\pm b|^2 = (a\pm b)\cdot(a\pm b) = |a|^2 \pm 2a\cdot b + |b|^2$。
- 将模的条件两边平方，配合夹角公式，即可把几何度量问题转化为代数方程求解。

## 解题方法与套路
1. **读题标已知**：明确给定向量的模、夹角、数量积或模的和差条件。
2. **目标模平方法**：对所求或已知的模表达式（如$|2a-b|$）两边同时平方，展开为$|a|^2, |b|^2$及$a\cdot b$的组合。
3. **数量积切入**：若已知夹角$\theta$，代入$a\cdot b = |a||b|\cos\theta$，统一变量。
4. **建方程求解**：将已知模的数值代入，转化为关于未知模的方程（通常为二次方程），解得正值即为所求模长。
5. **检验舍根**：模长必须非负，若方程有两根，只保留非负根（注意根是否符合夹角范围隐含的约束）。

## 高频易错
- 忽略所有参与数量积的向量必须非零，即使用夹角公式前确认$|a|\neq0, |b|\neq0$。
- 模长方程求解时，开方漏写正负号；但模长本身为非负数，答数只取非负值。
- 展开$|ma\pm nb|^2$时漏乘交叉项系数：$(ma\pm nb)^2 = m^2|a|^2 \pm 2mn\,a\cdot b + n^2|b|^2$。
- 夹角为钝角时$\cos\theta<0$，代入$a\cdot b$为负值，计算时符号易错。
- 把夹角公式误记成$\sin\theta$或$\tan\theta$的分式。

## 代表题精讲
### 题目1（2012-理-13）
**题目**：已知非零向量$a,b$的夹角为$45^\circ$，$|a|=1$，且$|2a-b|^2 = 13-6\sqrt{2}$，求$|b|$。

**思路**：条件给出模的平方，直接展开配方，利用夹角牵入数量积，转化为关于$|b|$的二次方程。

**步骤**：
1. 设$|b| = x\ (x>0)$，由夹角得 $a\cdot b = |a||b|\cos45^\circ = 1\cdot x\cdot\frac{\sqrt{2}}{2} = \frac{\sqrt{2}}{2}x$。
2. 将$|2a-b|^2$展开：
   $$|2a-b|^2 = 4|a|^2 - 4a\cdot b + |b|^2 = 4\cdot1 - 4\cdot\frac{\sqrt{2}}{2}x + x^2 = 4 - 2\sqrt{2}x + x^2.$$
3. 代入已知值：$x^2 - 2\sqrt{2}x + 4 = 13 - 6\sqrt{2}$。
4. 整理成标准二次方程：$x^2 - 2\sqrt{2}x - 9 + 6\sqrt{2} = 0$。
5. 判别式 $\Delta = (-2\sqrt{2})^2 - 4\times1\times(-9+6\sqrt{2}) = 8 + 36 - 24\sqrt{2} = 44 - 24\sqrt{2}$。
   注意到 $44-24\sqrt{2} = (6-2\sqrt{2})^2$。
6. 求根：$x = \frac{2\sqrt{2} \pm (6-2\sqrt{2})}{2}$，
   正根 $x = \frac{2\sqrt{2}+6-2\sqrt{2}}{2} = 3$，负根舍去。
故 $|b|=3$。

**点评/变式**：本题核心是“给模的平方，列方程”。若条件改为$|2a+b|$、$|a-2b|$等，展开结构类似，留意交叉项符号。凡涉及单一向量模未知，均可通过构造二次方程求解。
