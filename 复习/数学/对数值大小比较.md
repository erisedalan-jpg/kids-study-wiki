## 知识精要
- **对数函数的单调性**  
  对于 $y=\log_a x \,(a>0,a\neq 1)$：当 $a>1$ 时，在 $(0,+\infty)$ 上单调递增；当 $0<a<1$ 时，在 $(0,+\infty)$ 上单调递减。比较同底对数可直接利用单调性。

- **对数恒等式与变形**  
  $\log_a(xy)=\log_a x + \log_a y$，$\log_a \dfrac{x}{y}=\log_a x - \log_a y$，$\log_a b^n = n\log_a b$，$\log_a b = \dfrac{\log_c b}{\log_c a}$（换底公式）。通过变形可将不同底的对数转化为同底或建立与特殊值的关系。

- **特殊中间值 $0$ 与 $1$**  
  $\log_a 1 = 0$；$\log_a a = 1$。任何底大于 $1$ 时，真数大于 $1$ 则对数大于 $0$，真数小于 $1$ 则对数小于 $0$；底在 $(0,1)$ 时相反。比较不同底对数时，常借助 $0$ 和 $1$ 进行分界。

- **作差/作商比较法**  
  对于同号的对数值，可作差与 $0$ 比较，或作商与 $1$ 比较，结合因式符号或单调性得出结论。

- **指数与对数互化**  
  $a = \log_b c \iff b^a = c$，必要时可将对数式转化为指数式，借助指数函数的性质比较大小。

## 解题方法与套路
比较对数值大小的通用步骤：

1. **观察底数与真数，判断能否直接利用单调性**  
   若底数相同，直接由单调性比较真数大小；若真数相同，可由换底公式 $\log_a x = \dfrac{1}{\log_x a}$ 转化为比较倒数，再利用单调性；若底数和真数均不同，进入下一步。

2. **借助 $0$ 或 $1$ 进行划分**  
   确定各对数值与 $0$、$1$ 的大小关系，将多个对数分成大于 $1$、$(0,1)$、小于 $0$ 等区间，往往可以快速排出顺序。例如 $\log_a b > 1 \iff (a>1\text{ 且 }b>a)$ 或 $(0<a<1\text{ 且 }0<b<a)$。

3. **化为同底或同真数**  
   通过换底公式或对数运算法则，将式子变形成底数（或真数）相同的形式，再利用单调性或作差、作商比较。

4. **作差或作商及因式分析**  
   若仍难直接判断，对两个对数作差（或作商），利用对数性质合并，结合已知变量的范围判断正负。

5. **遇变量真数时注意定义域和符号**  
   真数中含有变量 $x$ 时，必须先确定其取值范围（保证对数有意义），再比较同底对数或通过作差判断大小。

## 高频易错
- **忽视底数对单调性的影响**  
  只记住“增函数”而忘记讨论 $0<a<1$ 时的减函数情形，导致大小反向。

- **误用中间值 $1$ 的判断条件**  
  容易记错：$\log_a b > 1$ 不一定等价于 $b>1$，必须结合底数 $a$ 与 $1$ 的大小关系共同判断。

- **换底公式使用不当**  
  换底后忽略底数变化导致的单调性反转，如 $\log_a b = \dfrac{1}{\log_b a}$，比较 $\log_3 2$ 与 $\log_5 2$ 时不能直接比较 $2$ 的大小。

- **忽略真数的限制条件**  
  含有变量的对数比较时，忘记先求定义域，导致错误。如 $x\in(e^{-1},1)$ 时未判断 $\ln x$ 的符号就盲目作差。

- **作差时符号判断失误**  
  提取公因式后，未结合变量范围确定每一部分的符号，导致大小结论错误。

## 代表题精讲
### 1. 2013-理-08
**题目**  
设 $a=\log_3 6$，$b=\log_5 10$，$c=\log_7 14$，比较 $a,b,c$ 的大小。

**思路**  
三个对数的底数和真数均不同，但真数都是底数的两倍，可分离出 $\log_a 2$ 的形式：  
$a=1+\log_3 2$，$b=1+\log_5 2$，$c=1+\log_7 2$。  
只需比较 $\log_3 2,\log_5 2,\log_7 2$。它们真数相同、底数不同，利用换底公式 $\log_x 2 = \dfrac{1}{\log_2 x}$，由 $\log_2 x$ 的单调性可知 $\log_2 7 > \log_2 5 > \log_2 3 > 0$，从而 $\log_3 2 > \log_5 2 > \log_7 2$。

**步骤**
1. 化简：$a=\log_3(3\times2)=1+\log_3 2$，$b=1+\log_5 2$，$c=1+\log_7 2$。
2. 因为 $y=\log_2 x$ 在 $(0,+\infty)$ 上单调递增，所以 $\log_2 7 > \log_2 5 > \log_2 3$。
3. 取倒数得 $\dfrac{1}{\log_2 3} > \dfrac{1}{\log_2 5} > \dfrac{1}{\log_2 7}$，即 $\log_3 2 > \log_5 2 > \log_7 2$。
4. 各加 $1$ 可得 $a > b > c$。

**点评/变式**  
该题核心是“连环同真数”结构的识别。变式：比较 $\log_2 3$、$\log_3 4$、$\log_4 5$ 等，可考虑与 $1$ 的差或换底后作商。

### 2. 2009-理-07
**题目**  
设 $a=\log_3 \pi$，$b=\log_2 \sqrt{3}$，$c=\log_3 \sqrt{2}$，比较 $a,b,c$ 的大小。

**思路**  
$a$ 的底和真数均大于 $1$，可先与 $1$ 比较；$b$ 和 $c$ 真数为根式，可化为 $\frac12 \log_2 3$ 和 $\frac12 \log_3 2$。通过分界点 $1$ 和中间值 $\frac12$ 划分区间即可排序。

**步骤**
1. $a=\log_3 \pi$，因为 $\pi > 3$，所以 $a > 1$。
2. $b=\log_2 \sqrt{3} = \frac12 \log_2 3$，由于 $\log_2 3 > \log_2 2 = 1$，故 $b > \frac12$；且 $\log_2 3 < \log_2 4 = 2$，所以 $b < 1$，即 $b \in (0.5, 1)$。
3. $c=\log_3 \sqrt{2} = \frac12 \log_3 2$，因为 $\log_3 2 < \log_3 3 = 1$，故 $c < \frac12$。
4. 综上 $a > 1 > b > \frac12 > c$，即 $a > b > c$。

**点评/变式**  
用 $1$ 和 $\frac12$ 双重中间值巧妙分段。若出现底数不确定的情况（如 $a \in (0,1)$），需反向讨论，切不可直接套用此题结论。

### 3. 2008-理-04
**题目**  
若 $x \in (e^{-1}, 1)$，$a = \ln x$，$b = 2\ln x$，$c = \ln^3 x$，比较 $a,b,c$ 的大小。

**思路**  
先确定 $a$ 的范围，再作差比较 $b$ 与 $a$、$c$ 与 $a$ 的关系，利用因式分解和符号判断。

**步骤**
1. 当 $x \in (e^{-1}, 1)$ 时，$\ln x$ 单调递增，所以 $a = \ln x \in (-1, 0)$。
2. $b - a = 2\ln x - \ln x = \ln x = a < 0$，因此 $b < a$。
3. $a - c = \ln x - \ln^3 x = \ln x(1 - \ln^2 x) = a (1 - a^2)$。  
   由 $a \in (-1,0)$ 得 $a < 0$，$a^2 \in (0,1)$，因此 $1-a^2 > 0$，于是 $a(1-a^2) < 0$，即 $a < c$。
4. 结合得 $b < a < c$。

**点评/变式**  
解决含变量的对数比较问题时，“先定范围后作差”是基本策略。该题陷阱在于 $b$ 和 $c$ 看似接近，实则需要精细判断。变式：若 $x \in (1, e)$，$a,b,c$ 的大小关系将变为 $c < a < b$，建议自行验证，强化对符号区间的敏感度。
