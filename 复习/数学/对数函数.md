## 知识精要
- **定义**：函数 $y = \log_a x \ (a>0,\ a\neq1)$ 叫做对数函数，$x>0$。
- **图象与性质**：
  - 定义域 $(0, +\infty)$，值域 $R$，过定点 $(1,0)$。
  - 当 $a>1$ 时，在 $(0,+\infty)$ 上单调递增；当 $0<a<1$ 时，单调递减。
  - $y=\log_a x$ 与 $y=a^x$ 互为反函数，图象关于直线 $y=x$ 对称。
- **运算性质**（$M>0, N>0$）：
  $$\log_a(MN)=\log_a M+\log_a N, \quad \log_a\frac{M}{N}=\log_a M-\log_a N, \quad \log_a M^n=n\log_a M$$
  换底公式：$\log_a b=\frac{\log_c b}{\log_c a}$，特别地 $\log_a b=\frac{1}{\log_b a}$。
- **导数**：$(\ln x)'=\frac{1}{x}$，$(\log_a x)'=\frac{1}{x\ln a}$。
- **常见对数不等式**：
  - $\ln x \le x-1 \ (x>0)$，等号在 $x=1$ 时成立。
  - $\ln x \ge 1-\frac{1}{x}$，$\frac{x-1}{x} \le \ln x \le x-1$ 等变形。
  - 对于 $\ln(y-x+1)$ 的正负，转化为比较真数与 $1$ 的大小。
- **指数与对数混合问题**：若 $a^x \cdot b^y$ 形式复杂，常取对数或构造函数利用单调性。

## 解题方法与套路
1. **比较对数大小**：
   - 同底利用单调性；不同底化为同底（换底公式）。
   - 借助中间值 $0$ 和 $1$（如 $\log_a 1=0, \log_a a=1$）。
   - 作差或作商比较，结合对数运算及真数范围。
2. **指对不等式与构造单调函数**：
   - 将不等式变形为 $f(x) < f(y)$ 的形式，分析 $f(t)$ 的单调性得出 $x$ 与 $y$ 的大小关系。
   - 常构造 $f(t)=a^t + b^t$ 或差组合，利用指数、对数函数的增减性判断整体单调性。
3. **数形结合解方程与不等式**：
   - 方程 $\log_a x = kx+b$ 或含指数、对数的方程，转化为图象交点。
   - 画图时抓住定点、渐近线、单调趋势，注意参数对图象的影响。
   - 分段函数结合图象求参数范围，尤其是对称关系得出乘积或和的范围。
4. **对数函数的切线问题**：
   - 设切点 $(x_0, \ln x_0 + C)$，求导得切线斜率 $k=\frac{1}{x_0}$。
   - 写出切线方程 $y = \frac{1}{x_0}x + \ln x_0 + C - 1$。
   - 若一条直线公切两曲线，联立斜率与截距相等，解方程组。
   - 注意不同曲线切点不同，设多个切点，构建等量关系。

## 高频易错
- **忽视定义域**：对数真数必须大于 $0$，如 $\ln(y-x+1)$ 需要 $y-x+1>0$，忽视会导致取不到或无意义。
- **忽略底数对单调性的影响**：没有分 $a>1$ 和 $0<a<1$ 讨论，直接套用单调性致错。
- **对数与指数相互转化时方向错误**：$\log_a x < y$ 当 $a>1$ 时等价于 $0<x<a^y$；当 $0<a<1$ 时等价于 $x>a^y$。
- **错误使用中间值**：在比较对数大小时，若对数可能为负，与 $0$ 比较易忽略符号。如 $x\in(e^{-1},1)$ 时 $\ln x \in (-1,0)$，这时 $\ln^3 x$ 的绝对值更小，容易误判大小。
- **抽象函数单调性构造失误**：如 $2^x$ 增，$-3^{-x}=-(\frac{1}{3})^x$，因 $(\frac{1}{3})^x$ 减，所以 $-3^{-x}$ 增，整体 $f(t)=2^t-3^{-t}$ 增。若错误判断某部分单调性，会导致整个推理错误。
- **公切线问题中忽略切点不同**：一条直线切两条曲线时，切点一般不同，误认为同一切点会导致漏解或错解；设两个切点分别刻画是标准方法。

## 代表题精讲
### **2020 年全国卷文科第12题 / 理科第11题**
**题目**：若 $2^x - 2^y < 3^{-x} - 3^{-y}$，则（  ）  
A. $\ln(y-x+1) > 0$　　B. $\ln(y-x+1) < 0$　　C. $\ln|x-y| > 0$　　D. $\ln|x-y| < 0$

**思路**：将原不等式移项构造同一函数形式，利用函数单调性得出 $x$ 与 $y$ 的大小关系，然后逐项判断各选项中真数与 $1$ 的大小关系，从而得出对数值的正负。

**步骤**：
1. 由 $2^x-2^y < 3^{-x}-3^{-y}$，移项得 $2^x - 3^{-x} < 2^y - 3^{-y}$。
2. 令 $f(t) = 2^t - 3^{-t}$。因为 $y=2^t$ 在 $R$ 上单调递增，$y=3^{-t} = \left(\frac{1}{3}\right)^t$ 在 $R$ 上单调递减，所以 $-3^{-t}$ 单调递增。故 $f(t)$ 是 $R$ 上的增函数。
3. 由 $f(x) < f(y)$ 且 $f(t)$ 递增，推出 $x < y$。
4. 于是 $y-x > 0$，$y-x+1 > 1$，故 $\ln(y-x+1) > 0$，A正确，B错误。  
   对于 C、D：$x-y$ 的正负不确定，绝对值与 $1$ 的大小未知，无法确定 $\ln|x-y|$ 的符号，均错误。

**点评/变式**：本题核心是通过等价变形构造单调函数，这是处理指对混合不等式的常用技巧。变式：若不等式改为 $2^x + 3^{-x} < 2^y + 3^{-y}$，亦可构造 $g(t)=2^t+3^{-t}$，其导数 $g'(t)=2^t\ln2 - 3^{-t}\ln3$ 在 $R$ 上先负后正，不能直接得出单调性，需要分段讨论，难度增大。另外，判断对数符号时，务必注意真数必须大于0且比较与1的大小。

### **2016 年全国卷理科第16题**
**题目**：若直线 $y = kx + b$ 是曲线 $y = \ln x + 2$ 的切线，也是曲线 $y = \ln(x+1)$ 的切线，则 $b =$ ______.

**思路**：设出两个切点，利用导数求出切线斜率及方程，由同一直线得斜率和截距分别相等，建立方程组求解 $b$。

**步骤**：
1. 设直线与 $y = \ln x + 2$ 的切点为 $(x_1, \ln x_1 + 2)$，由 $y' = \frac{1}{x}$ 得切线斜率 $k = \frac{1}{x_1}$，切线方程为  
   $$y = \frac{1}{x_1}x + \ln x_1 + 1.$$
2. 设直线与 $y = \ln(x+1)$ 的切点为 $(x_2, \ln(x_2+1))$，由 $y' = \frac{1}{x+1}$ 得斜率 $k = \frac{1}{x_2+1}$，切线方程为  
   $$y = \frac{1}{x_2+1}x + \ln(x_2+1) - \frac{x_2}{x_2+1}.$$
3. 比较两切线方程得方程组：
   $$\begin{cases}
   \frac{1}{x_1} = \frac{1}{x_2+1}, \\
   \ln x_1 + 1 = \ln(x_2+1) - \frac{x_2}{x_2+1}.
   \end{cases}$$
4. 由第一式得 $x_2+1 = x_1$，代入第二式：  
   $\ln x_1 + 1 = \ln x_1 - \frac{x_1-1}{x_1}$ ⇒ $1 = -\frac{x_1-1}{x_1}$ ⇒ $x_1 = \frac{1}{2}$.
5. 回代得 $k = 2$，$b = \ln x_1 + 1 = \ln\frac{1}{2} + 1 = 1 - \ln 2$.

**点评/变式**：公切线问题抓住“切点不同、斜率和截距分别相等”这一核心。常见变式是求公切线方程或参数满足的条件。若两曲线分别为相互平移的 $\ln x + A$ 与 $\ln(x+a)$，可以灵活利用 $x_1 = x_2 + a$ 简化计算。
