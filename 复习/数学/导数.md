## 知识精要
- **导数定义与几何意义**
  - 函数 $y=f(x)$ 在 $x=x_0$ 处的导数 $f'(x_0)$ 是曲线在点 $(x_0, f(x_0))$ 处切线的斜率。
  - 切线方程：$y - f(x_0) = f'(x_0)(x - x_0)$。
  - $f'(x_0)$ 存在是可导的前提，$f'(x_0)=0$ 是 $x_0$ 为极值点的 **必要不充分条件**。
- **基本初等函数导数公式（必须熟练）**
  - $(x^n)' = nx^{n-1}$； $(\sin x)' = \cos x$； $(\cos x)' = -\sin x$； $(a^x)' = a^x \ln a$； $(\text{e}^x)' = \text{e}^x$； $(\ln x)' = \frac{1}{x}$。
- **导数运算与复合函数求导**
  - 四则运算法则：$[f(x) \pm g(x)]' = f'(x) \pm g'(x)$； $[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)$； $\left[ \frac{f(x)}{g(x)} \right]' = \frac{f'(x)g(x)-f(x)g'(x)}{g^2(x)} (g(x) \neq 0)$。
  - 链式法则（复合函数）：$y = f(g(x))$，则 $y' = f'(g(x)) \cdot g'(x)$。
- **导数与单调性、极值、最值**
  - **单调性**：在区间 $I$ 上，$f'(x) > 0 \Rightarrow f(x)$ 单调递增；$f'(x) < 0 \Rightarrow f(x)$ 单调递减。（注意等号仅在孤立点成立）
  - **极值判断**：$x_0$ 两侧 $f'(x)$ 变号是极值点存在的充分条件。左正右负极大，左负右正极小。务必检查定义域。
  - **闭区间最值**：比较所有极值点与区间端点处的函数值，取最大/最小者。
- **三次函数特性**
  - $f(x)=ax^3+bx^2+cx+d(a \neq 0)$ 的导数为二次函数，根的个数（判别式 $\Delta$）决定极值点个数。
  - 三次函数的图像关于唯一拐点（即二阶导数为零的点）成中心对称。对称中心横坐标为 $x = -\frac{b}{3a}$。
- **函数零点问题**
  - 判断零点个数常结合单调性、极值符号与零点存在定理。若在区间 $[m,n]$ 上单调且 $f(m)f(n)<0$，则区间内有唯一零点。

## 解题方法与套路
1.  **利用导数研究函数单调性的标准步骤**
    - 确定定义域（至关重要，尤其是含 $\ln x$、$\frac{1}{x}$ 等）。
    - 求导并化简（通分、因式分解，目标是能轻易判断符号）。
    - 解导函数方程，找到临界点，划分区间列表。
    - 各区间的导数符号 $\rightarrow$ 函数的增减性。（若含参数，需分类讨论）
2.  **求函数极值/最值的规范流程**
    - 求定义域，求导。
    - 令 $f'(x)=0$，解出所有根（驻点）及不可导点。
    - 列表（或画导函数符号图），确认极值点和极值。
    - 闭区间最值：将驻点、不可导点、端点值代入原函数比较。
3.  **导数证明不等式的核心——构造函数**
    - **移项构造**：欲证 $g(x) > h(x)$，构造 $F(x) = g(x) - h(x)$，即证 $F(x)_{\text{min}} > 0$。
    - **双函数构造**：若无法直接求最值，可构造 $F(x)、G(x)$ 分别研究单调性并借助中间量放缩。
    - **隐零点代换**：当导函数零点无法直接求解时，设隐零点 $x_0$，利用导函数方程代换掉超越部分，化简原函数。此为证明复杂不等式或求最值的核心技巧。
4.  **求解参数范围的通法**
    - **变量分离**：将参数 $a$ 分离到不等式一边，如 $a \ge g(x)$，则需求 $g(x)_{\max}$。此法优先尝试，但要注意保号与极限。
    - **分类讨论**：当不易分离参数时，直接对含参函数求导，根据极值点、定义域等划分参数区间，逐个讨论单调性，确保满足题意（如 $f(x) \ge 0$ 恒成立）。
    - **轨迹与几何意义**：将方程根问题转化为两函数图像交点问题（2022理16），通过切线斜率等几何意义确定参数边界，本质是导数几何意义的灵活运用。
5.  **切线与公切线问题的两步走**
    - **单一切线**：先求切点（或设切点），再求斜率，最后写出方程。切点是解题核心。
    - **公切线**：设出两条曲线的各自切点 $(x_1,f(x_1))$、$(x_2,g(x_2))$，利用“斜率相等”且“截距相等”（或切线重合）建立方程组求解。注意区分“切点相同”和“切线相同”。

## 高频易错
- **混淆极值的充要条件**：$f'(x_0)=0$ 是 $x_0$ 为极值点的必要不充分条件！必须检验 $x_0$ 两侧导数是否变号（如2024真题选项B的反例，$f'(0)=0$ 但两侧同号，非极值点）。
- **忽视函数的定义域**：研究对数、分母含变量等类型的函数时，第一步必须写出定义域。讨论单调性、区间必须基于定义域（如2019真题需在 $(0,1)$ 和 $(1,\infty)$ 上分别讨论）。
- **含参讨论漏解、乱序**：参数导致导函数零点大小不确定时，必须按逻辑顺序分类（如 $a<0, a=0, 0<a<1, a>1$），不重不漏。画函数图像时务必区分 $0<a<1$ 与 $a>1$ 的差异。
- **运算失误**：
  - 复合函数 $(a^x)'$ 误记为 $x a^{x-1}$，正确的是 $a^x \ln a$。
  - 常见分式、根式求导后符号遗忘。三角函数求导正负号混淆。
- **误用零点存在定理**：定理要求函数在闭区间内“连续”且端点值“异号”。若函数不连续（有渐近线），即使两端点异号也不能直接断言有零点。
- **“切线相同”不等于“切点相同”**：一条直线可以是两条曲线的公切线，但切点可能在不同位置（2019真题即曲线 $y=\ln x$ 与 $y=e^x$ 在不同点的同一直线公切线）。
- **证明不等式时忽视取等条件**：若放缩链条中某步等号无法取得，即便最终不等式不等号正确，从逻辑上也可能扣分。必须检查每一步等号成立条件是否能同时满足。
