## 知识精要
- **平均数（均值）**
  - **定义**：一组数据 $x_1, x_2, \dots, x_n$ 的平均数 $\bar{x} = \frac{1}{n}(x_1 + x_2 + \dots + x_n)$。
  - **加权平均数**：若数据 $x_i$ 出现的频数为 $f_i$，则 $\bar{x} = \frac{\sum x_i f_i}{\sum f_i}$。
  - **频率分布表求平均**：用各组的组中值乘以对应频率求和，即 $\bar{x} \approx \sum (组中值 \times 频率)$。组中值一般为区间两端点的算术平均数。
- **中位数**
  - 一组数据按大小排序后，处于中间位置的数（奇数个）或中间两数的平均数（偶数个）。
  - 去极端值（最高/最低）不影响中位数。
- **方差与标准差**
  - **方差**：$s^2 = \frac{1}{n}\sum_{i=1}^n (x_i - \bar{x})^2$。
  - **标准差**：$s = \sqrt{s^2}$。
  - 去掉极端值通常会使方差变小；极差（最大值减最小值）必定变小。
- **概率的统计估计**
  - 用频率估计概率：$P(A) \approx \frac{事件A出现的频数}{总试验次数}$。

## 解题方法与套路
1. **茎叶图读数与特征计算**：
   - 先准确列出所有数据，注意茎和叶的还原（保留原始小数位数）。
   - 求中位数时，将数据排序后取中间位置；偶数个数据需取中间两数的平均值。
   - 求平均数时，先求和再除以总数，注意进位与小数运算。
2. **频率分布表（或频数分布表）的计算**：
   - **估值计算**：用“组中值×频数”求和，再除以总数得到平均数的估计值。
   - **方差估值**：根据组中值 $\hat{x}_i$ 和平均数估计值 $\bar{x}$，利用 $s^2 \approx \frac{\sum (\hat{x}_i - \bar{x})^2 \times 频数}{总数}$，标准差为其算术平方根。注意题目中可能给出近似根号值辅助计算。
3. **数字特征的变化规律判断**：
   - 去掉对称的极端值（最高、最低）后，“中位数”通常保持不变，可作为快速判断的特征。
   - 去掉极端值，平均数可能变化（除非原数据对称），方差通常减小，极差必减小或不变。
   - 可用特殊值法（构造具体数据）代入验证，提高解题速度。
4. **结论推断与比较**：
   - 比较平均值时，可通过观察数据的集中趋势（如茎叶分布）定性判断。
   - 比较分散程度（波动大小）可通过茎叶图观察“叶片”的疏密程度，越密集表示方差越小，越分散表示方差越大。

## 高频易错
- **中位数计算陷阱**：偶数个数据时，必须取中间两个数的平均数，不能直接取中间位置的某个数。
- **概率估计粗心**：计数比值时，需明确“大于”或“不小于”的边界值是否包含在内，避免多计或少计。概率值永远在 $[0,1]$ 之间。
- **茎叶图细节**：茎叶图的茎和叶单位可能不同，读取数据后一定要写成带量纲的真实数据，避免将“8 | 1”误解为 81 而非 8.1。
- **平均数估算误区**：在频率分布表中，无法得到精确的平均数，只能用组中值代替，且组中值的计算为区间两端点之和的一半。

## 代表题精讲
### 2022-文-04
**题目**：给出甲、乙两位同学16周体育运动时长的茎叶图，判断关于中位数、平均数、概率的四个结论中哪一个是错误的。
**思路**：直接利用茎叶图还原数据，逐一验算选项。
**步骤**：
1. **审数据**：从茎叶图读出甲、乙各16个数据。
2. **验A（中位数）**：将甲的16个数据排序，第8、9位为 $7.3$ 和 $7.5$。偶数个，中位数为 $\frac{7.3 + 7.5}{2} = 7.4$。A正确。
3. **验B（平均数）**：累加乙的16个数据求其和。计算得和为 $136.1$，平均数为 $\frac{136.1}{16} \approx 8.506 > 8$。B正确。
4. **验C/D（概率估计）**：用频率估计概率。甲大于8的数据有6个（$8.1, 8.2, 8.2, 8.3, 8.5, 9.1$），概率为 $\frac{6}{16}=0.375<0.4$。C错误。乙大于8的数据有13个，概率为 $\frac{13}{16}=0.8125>0.6$，D正确。
**点评**：此为茎叶图与数字特征结合的综合题。核心是细心还原数据，并准确利用定义式计算，特别注意偶数个数据的中位数求法。

### 2019-文-19
**题目**：根据100个企业产值增长率的频数分布表，估计不同范围的企业比例，并求平均数和标准差的估计值。
**思路**：比例直接用频数除以总数；平均值用各组组中值加权平均；标准差利用方差公式开方，并利用题目提供的根号近似值。
**步骤**：
1. **求比例**：不低于40%即 $[0.40,0.60)$ 与 $[0.60,0.80)$ 的企业数为 $14+7=21$，比例为 $21\%$。产值负增长即 $[-0.20,0)$ 的企业数为 $2$，比例为 $2\%$。
2. **求平均数**：计算各组组中值并加权。
   - $[-0.20,0)$：组中值 $-0.1$，频数 $2$。
   - $[0,0.20)$：组中值 $0.1$，频数 $24$。
   - $[0.20,0.40)$：组中值 $0.3$，频数 $53$。
   - $[0.40,0.60)$：组中值 $0.5$，频数 $14$。
   - $[0.60,0.80)$：组中值 $0.7$，频数 $7$。
   平均数 $\bar{x} = \frac{(-0.1)\times2 + 0.1\times24 + 0.3\times53 + 0.5\times14 + 0.7\times7}{100} = \frac{30}{100}=0.3$。
3. **求标准差**：计算方差。
   $s^2 = \frac{1}{100}[2\times(-0.1-0.3)^2 + 24\times(0.1-0.3)^2 + 53\times(0.3-0.3)^2 + 14\times(0.5-0.3)^2 + 7\times(0.7-0.3)^2] = 0.0296$
   标准差 $s = \sqrt{0.0296} = \sqrt{\frac{296}{10000}} = \frac{\sqrt{74 \times 4}}{100} = \frac{2\sqrt{74}}{100}$，利用 $\sqrt{74} \approx 8.602$，得 $s \approx 0.17$。
**点评**：分组数据求数字特征，必须用组中值代替真实值进行计算。注意运算的精确度，并合理利用题目所给的无理数近似值进行最终化简。

### 2019-理-05
**题目**：9位评委打分，去掉一个最高分和一个最低分后，7个有效评分与9个原始评分相比，哪个数字特征不变。
**思路**：利用数字特征的特性或快速构造一个特殊数列进行排除。
**步骤**：
1. 设9个评分从小到大为 $x_1 \le x_2 \le ... \le x_9$。
2. 去除 $x_1$ 和 $x_9$ 后，中间的数据位置不变，原中位数为 $x_5$，新中位数仍为 $x_5$。故中位数不变。
3. 排除法：去掉极端值，总分变化，故平均数通常变化；数据波动变小，故方差通常变小；最大值和最小值去掉了，极差 $x_9 - x_1$ 必然变小或不变。
**点评**：去极端值处理是比赛中常用策略，其“抗干扰性”决定了中位数是稳健的特征数，而平均数、方差、极差对极端值敏感。
