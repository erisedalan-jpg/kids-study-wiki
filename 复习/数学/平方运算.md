## 知识精要
- **核心公式**：同角三角函数基本关系 $\sin^2\theta+\cos^2\theta=1$；两角和的正弦公式 $\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$。
- **平方运算的适用情境**：已知两个关于 $\sin\alpha,\cos\beta,\cos\alpha,\sin\beta$ 的线性方程，目标是求 $\sin(\alpha\pm\beta)$ 或 $\cos(\alpha\pm\beta)$ 的值。通过两边平方，可将正弦、余弦交叉项显式化，同时利用 $\sin^2+\cos^2=1$ 消去平方项。
- **定理本质**：平方是构造出 $\sin\alpha\cos\beta\pm\cos\alpha\sin\beta$ 结构的桥梁，其背后依托两角和差公式的逆用。对于形如 $A\sin\alpha + B\cos\beta = C$ 的式子平方，会自然出现 $\sin^2\alpha$ 和 $\cos^2\beta$，与其他平方式子组合后可化为 $2+2\sin(\alpha+\beta)$ 等形式。

## 解题方法与套路
1. **识别可平方的结构**：题干给出两个方程，分别含有 $\sin\alpha$ 与 $\cos\beta$、$\cos\alpha$ 与 $\sin\beta$ 的线性组合，且目标多为 $\sin(\alpha\pm\beta)$ 或 $\cos(\alpha\pm\beta)$。
2. **分别平方**：将已知的两个等式各自左右两边平方，展开左边完全平方式。此时会出现 $\sin^2\alpha,\cos^2\beta$ 等项和交叉项 $2\sin\alpha\cos\beta$ 或 $2\cos\alpha\sin\beta$。
3. **合理相加或相减**：将两个展开后的平方等式相加（或相减），利用 $\sin^2\alpha+\cos^2\alpha=1$ 和 $\sin^2\beta+\cos^2\beta=1$ 合并常数，交叉项组合成两角和差的正弦或余弦公式。
4. **解出目标值**：化简所得的等式，得到关于 $\sin(\alpha+\beta)$ 等目标的简单方程，直接求解。若需要 $\cos(\alpha+\beta)$，可考虑平方相减或结合其他条件。
5. **必要时检验**：平方运算属于等价变形吗？是，两边平方在同号时可能会增根，但本题中结果唯一，无需排除。若有根号或开方，需警惕符号。

## 高频易错
- **漏写交叉项系数**：两边平方时忘记写二倍交叉项，如将 $(\sin\alpha+\cos\beta)^2$ 写成 $\sin^2\alpha+\cos^2\beta$，导致无法凑出 $\sin(\alpha+\beta)$。
- **误用平方和公式**：误以为 $\sin^2\alpha+\cos^2\beta=1$，应注意角相同才能用平方和关系，不同角需与另一个平方等式合并才能产生常数。
- **相加相减选择错误**：若目标含 $\sin(\alpha+\beta)$，应选择两式相加；若求 $\sin(\alpha-\beta)$ 或 $\cos(\alpha+\beta)$，则可能需要调整符号或相减。不加分辨直接相加可能得到无用的表达式。
- **忘记常数项叠加**：$\sin^2\alpha+\cos^2\alpha=1$，$\sin^2\beta+\cos^2\beta=1$，两个1相加得2，如果只记一个1则导致常数项错误，最终结果差之千里。
- **结果未约简**：解出 $2\sin(\alpha+\beta)=-1$ 后需化为 $\sin(\alpha+\beta)=-\dfrac{1}{2}$，部分同学会忘记除以2。

## 代表题精讲
**题目**：（2018·全国卷理15）已知 $\sin\alpha+\cos\beta=1$，$\cos\alpha+\sin\beta=0$，求 $\sin(\alpha+\beta)$．

**思路**  
两个条件分别含有 $\sin\alpha+\cos\beta$ 和 $\cos\alpha+\sin\beta$，而目标是 $\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta$。把已知等式两边平方后相加，恰好能产生 $\sin^2\alpha+\cos^2\alpha$、$\sin^2\beta+\cos^2\beta$ 以及交叉项和。利用平方和为1合并常数，交叉项组合即得目标。

**步骤**  
1. 将 $\sin\alpha+\cos\beta=1$ 两边平方：  
   $(\sin\alpha+\cos\beta)^2 = 1^2$  
   $\Rightarrow \sin^2\alpha + 2\sin\alpha\cos\beta + \cos^2\beta = 1$  ①  
2. 将 $\cos\alpha+\sin\beta=0$ 两边平方：  
   $(\cos\alpha+\sin\beta)^2 = 0^2$  
   $\Rightarrow \cos^2\alpha + 2\cos\alpha\sin\beta + \sin^2\beta = 0$  ②  
3. ① + ② 得：  
   $(\sin^2\alpha+\cos^2\alpha) + (\sin^2\beta+\cos^2\beta) + 2(\sin\alpha\cos\beta + \cos\alpha\sin\beta) = 1+0$  
   $\Rightarrow 1 + 1 + 2\sin(\alpha+\beta) = 1$  
   $\Rightarrow 2 + 2\sin(\alpha+\beta) = 1$  
4. 解出 $\sin(\alpha+\beta)$：  
   $2\sin(\alpha+\beta) = -1$  
   $\sin(\alpha+\beta) = -\dfrac{1}{2}$  

**点评/变式**  
本题核心是“平方相加构造两角和”，属于三角求值中的经典套路。若题目改为求 $\cos(\alpha+\beta)$，可考虑将两式相减：① − ② 得到 $\sin^2\alpha-\cos^2\alpha+\cos^2\beta-\sin^2\beta + 2(\sin\alpha\cos\beta-\cos\alpha\sin\beta)=1$，利用倍角公式可化出 $\cos2\alpha$ 等，或者将原式移项后平方相减并配合 $\sin^2+\cos^2=1$ 凑出 $\cos(\alpha+\beta)$ 的表达式。变式训练：已知 $\sin\alpha+\cos\beta=\frac{1}{2}$，$\cos\alpha-\sin\beta=\frac{\sqrt{3}}{2}$，求 $\sin(\alpha-\beta)$ 的值。解题关键仍是平方后适当相加或相减，构造出 $\sin\alpha\cos\beta-\cos\alpha\sin\beta$。
