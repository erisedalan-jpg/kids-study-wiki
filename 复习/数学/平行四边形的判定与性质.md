## 知识精要
- **三角形中位线定理**：三角形的中位线平行于第三边，且等于第三边的一半。
- **平行四边形的判定**（常考）：
  1. 两组对边分别平行的四边形是平行四边形。
  2. 一组对边平行且相等的四边形是平行四边形。
  3. 对角线互相平分的四边形是平行四边形。
- **平行四边形的性质**：
  1. 对边平行且相等。
  2. 对角相等，邻角互补。
  3. 对角线互相平分。
- **平行线性质**：两直线平行，同位角相等；内错角相等；同旁内角互补；夹在平行线间的平行线段相等。
- **圆的性质**：等弧对等弦；同弧所对圆周角相等；圆内接四边形对角互补等（本题利用平行弦所夹弧相等）。
- **相似三角形的判定**：两角对应相等的两三角形相似。

## 解题方法与套路
1. **证明线段相等**：若线段不在可直接关联的图形中，可尝试通过构造平行四边形“搬运”线段。  
   - 利用已知平行与中点，先判定一个四边形是平行四边形，得到对边相等。  
   - 再判定另一四边形为平行四边形，将目标线段转化为另一已知或易证的相等线段。
2. **利用中位线构造平行**：看到中点，优先连接构成中位线，获得平行及线段比例关系，为下一步构造平行四边形提供一组平行边。
3. **证明三角形相似**：在有圆的背景中，充分利用弧、弦、圆周角的关系找出两组对应角相等。
   - 平行弦 ⇒ 等弧 ⇒ 等圆周角。
   - 同弧所对的圆周角相等。
   - 公共角或对顶角。
4. **整体思路**：复杂图形先分解，找到平行四边形“桥梁”，将分散的条件集中。

## 高频易错
- **判定平行四边形的条件缺失**：用“一组对边平行且相等”时，必须是同一组对边，切忌误用为“一组对边平行，另一组对边相等”，后者不一定是平行四边形（可能是等腰梯形）。
- **误用中位线性质**：三角形的中位线平行于第三边且等于其一半，但不可直接得出中位线与三角形另两边相等；本题中用到中位线只是得到 $DE \parallel BC$。
- **圆中平行弦的结论模糊**：$CF \parallel AB$ 推不出 $AF = BC$ 的直接全等，需结合圆的平行弦性质得出 $\widehat{AF} = \widehat{BC}$，进而得弦 $AF = BC$。跳跃推导易扣分。
- **证明相似时漏找公共角**：$\triangle BCD$ 与 $\triangle GBD$ 有公共角 $\angle D$，容易被忽略；写完等弧所得的等角后，一定要确认还差哪个角，公共角/对顶角通常是很关键的一步。

## 代表题精讲
**题目**  
如图，$D$，$E$ 分别为 $\triangle ABC$ 边 $AB$，$AC$ 的中点，直线 $DE$ 交 $\triangle ABC$ 的外接圆于 $F$，$G$ 两点，若 $CF \parallel AB$，证明：  
（1）$CD = BC$；  
（2）$\triangle BCD \sim \triangle GBD$．  

**思路**  
（1）由中位线得 $DE \parallel BC$；结合 $CF \parallel AB$，先后判定四边形 $BDFC$ 和 $ADCF$ 为平行四边形，利用对边相等将 $CD$ 转化为 $AF$，再利用平行弦所夹弧相等得到 $AF = BC$。  
（2）由 $CF \parallel AB$ 得等弧 $\widehat{AF}=\widehat{BC}$，推得 $\angle DBC = \angle DGB$；又 $\angle BDC = \angle GDB$ 为公共角，即可证相似。

**步骤**  
（1）  
* 由 $D$、$E$ 为中点 $\Rightarrow DE \parallel BC$（中位线定理）．  
* 已知 $CF \parallel AB$，又 $DF \parallel BC$，故四边形 $BDFC$ 为平行四边形 $\Rightarrow CF \parallel BD$ 且 $CF = BD$．  
* 又 $AD = DB$，故 $CF \parallel AD$ 且 $CF = AD$，得四边形 $ADCF$ 为平行四边形 $\Rightarrow CD = AF$．  
* 在圆中，由 $CF \parallel AB \Rightarrow \widehat{AF} = \widehat{BC} \Rightarrow AF = BC$，从而 $CD = BC$．  

（2）  
* 由 $\widehat{AF} = \widehat{BC}$ 知 $\angle ACF = \angle BAC$（等弧所对圆周角），但更方便的是由平行弦得等弧推得 $\angle FBC = \angle BFC$ 等。本题直接用：由 $CF \parallel AB$ 有 $\widehat{AF} = \widehat{BC}$，从而 $\angle AGB = \angle BDC$？更直接：因 $\widehat{AF} = \widehat{BC}$，所以 $\angle DBC = \angle DGB$（同弧或等弧所对圆周角相等）。  
* 在 $\triangle BCD$ 与 $\triangle GBD$ 中，$\angle BDC = \angle GDB$（公共角），$\angle DBC = \angle DGB$，因此 $\triangle BCD \sim \triangle GBD$（AA）．

**点评/变式**  
- “先平四后等弧”是平面几何中证线段相等的经典链条。  
- 变式：若条件改为 $CF$ 为切线或改变平行关系，仍可利用平行四边形转移线段。  
- 证相似时不要忽略公共角，圆中线段的平行关系最终转化为角相等是常态。
