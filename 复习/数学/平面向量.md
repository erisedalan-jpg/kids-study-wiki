## 知识精要
- **向量概念**：既有大小又有方向的量。零向量 $\vec{0}$ 模长为 $0$，方向任意；单位向量模长为 $1$。
- **线性运算**：
  - 加法/减法：三角形法则或平行四边形法则。
  - 数乘：$\lambda \vec{a}$，$|\lambda \vec{a}| = |\lambda| |\vec{a}|$，方向由 $\lambda$ 正负决定。
- **坐标表示**：若 $\vec{a} = (x_1, y_1)$，$\vec{b} = (x_2, y_2)$，则
  - $\vec{a} + \vec{b} = (x_1 + x_2, y_1 + y_2)$，$\lambda \vec{a} = (\lambda x_1, \lambda y_1)$。
- **共线（平行）条件**：
  - 几何形式：$\vec{a} \parallel \vec{b} \ (\vec{b} \neq \vec{0}) \iff \vec{a} = \lambda \vec{b}$（存在唯一实数 $\lambda$）。
  - 坐标形式：$x_1 y_2 - x_2 y_1 = 0$（交叉相乘相等）。注意零向量与任意向量平行。
- **垂直条件**：
  - $\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0$。
  - 坐标形式：$x_1 x_2 + y_1 y_2 = 0$。
- **数量积（点乘）**：
  - 定义：$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos \theta$，其中 $\theta$ 为夹角。
  - 坐标运算：$\vec{a} \cdot \vec{b} = x_1 x_2 + y_1 y_2$。
  - 模长：$|\vec{a}| = \sqrt{x_1^2 + y_1^2}$。
  - 夹角：$\cos \theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}| |\vec{b}|}$。
- **三点共线**：$A,B,C$ 共线 $\iff \overrightarrow{AB} = \lambda \overrightarrow{AC}$。
- **向量位置关系应用**：平行常用于解未知坐标或参数，垂直常用于解参数 $k$ 或证明直角。

## 解题方法与套路
1. **坐标化策略**：题目给出坐标或易于建系时，将所有条件转化为坐标运算，利用方程求解。
   - 平行：$x_1 y_2 - x_2 y_1 = 0$。
   - 垂直：$x_1 x_2 + y_1 y_2 = 0$。
   - 求夹角：直接代入 $\cos \theta = \frac{x_1 x_2 + y_1 y_2}{\sqrt{x_1^2 + y_1^2} \cdot \sqrt{x_2^2 + y_2^2}}$。
2. **共线定理套用**：当向量以 $\vec{a}$、$\vec{b}$ 为基底且不共线时，设出系数建立方程组。
   - 若 $\vec{m} = \lambda \vec{n}$，且 $\vec{m}, \vec{n}$ 用基底表示，利用基底线性无关性，比较对应系数求出参数（如 2015 理 13）。
3. **垂直关系的直接展开**：遇到形如 “$k\vec{a} - \vec{b}$ 与 $\vec{a}$ 垂直”，直接点乘为零：$(k\vec{a} - \vec{b}) \cdot \vec{a} = 0$，结合 $\vec{a}\cdot\vec{a}=|\vec{a}|^2$ 与已知长度和夹角求解。
   - 注意单位向量的模为 $1$。
4. **求夹角四步法**：①求向量的坐标或模长与数量积；②算 $\vec{a}\cdot\vec{b}$；③算 $|\vec{a}|,|\vec{b}|$；④代入余弦公式。

## 高频易错
- **平行坐标公式符号错**：$x_1 y_2 - x_2 y_1 = 0$ 易错记成 $x_1 x_2 - y_1 y_2 = 0$ 或忘记负号。务必记忆“交叉乘、相减为零”。
- **忽略零向量**：平行条件 $\vec{a} = \lambda \vec{b}$ 要求 $\vec{b} \neq \vec{0}$。若题目中向量可能为零向量需单独讨论；但高考范围内通常为非零向量。
- **垂直与平行的公式混淆**：垂直是坐标对应乘积和为 $0$，平行是交叉积差为 $0$。
- **共线定理设错系数**：$\lambda \vec{a} + \vec{b}$ 与 $\vec{a} + 2\vec{b}$ 平行，误写为 $\lambda \vec{a} + \vec{b} = \vec{a} + 2\vec{b}$。需引入参数 $t$ 如 $\lambda \vec{a} + \vec{b} = t(\vec{a} + 2\vec{b})$。
- **数量积计算忽略夹角**：用定义式计算 $\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta$ 时，夹角易用错，特别是单位向量夹角若为特殊角 $45^\circ$，其 $\cos 45^\circ = \frac{\sqrt{2}}{2}$。
- **模长计算错误**：求 $|\vec{a}|$ 时忘记开平方；向量模长非负，去根号时注意。
- **夹角余弦结果忘化简**：需化到最简分数或带根号形式。

## 代表题精讲
### 代表题 1：2021-文-13
**题目**：已知向量 $\vec{a}=(2,5)$，$\vec{b}=(\lambda,4)$，若 $\vec{a} \parallel \vec{b}$，则 $\lambda=$ ______。

**思路**：向量平行坐标条件直接列方程。

**步骤**：
由 $\vec{a} \parallel \vec{b}$ 得 $2 \times 4 - 5 \times \lambda = 0$，即 $8 - 5\lambda = 0$，解得 $\lambda = \frac{8}{5}$。

**点评/变式**：极简基础题，考场必须秒杀。注意交叉相乘时从左到右 $x_1y_2$ 与 $x_2y_1$ 勿颠倒。若变式为垂直：$(2,5)\perp(\lambda,4) \Rightarrow 2\lambda+20=0$。

### 代表题 2：2020-理-13
**题目**：已知单位向量 $\vec{a}$，$\vec{b}$ 的夹角为 $45^\circ$，$k\vec{a} - \vec{b}$ 与 $\vec{a}$ 垂直，求实数 $k$。

**思路**：借助垂直的充要条件展开，利用单位长度和已知夹角算数量积。

**步骤**：
1. 单位向量：$|\vec{a}|=|\vec{b}|=1$，数量积 $\vec{a}\cdot\vec{b}=1\times 1\times \cos 45^\circ = \frac{\sqrt{2}}{2}$。
2. 垂直条件：$(k\vec{a} - \vec{b}) \cdot \vec{a} = 0$。
3. 展开：$k(\vec{a}\cdot\vec{a}) - \vec{b}\cdot\vec{a} = 0$，即 $k|\vec{a}|^2 - \vec{a}\cdot\vec{b} = 0$。
4. 代入数据：$k\times 1 - \frac{\sqrt{2}}{2} = 0$，得 $k = \frac{\sqrt{2}}{2}$。

**点评/变式**：典型向量垂直与数量积运算的结合。若条件改为 “$k\vec{a}+\vec{b}$ 与 $\vec{b}$ 垂直”，则列 $(k\vec{a}+\vec{b})\cdot\vec{b}=0 \Rightarrow k\vec{a}\cdot\vec{b} + |\vec{b}|^2 = 0$。注意单位向量模长为 $1$ 这个隐含条件。

### 代表题 3：2016-文-13
**题目**：已知向量 $\vec{a}=(m,4)$，$\vec{b}=(3,-2)$，且 $\vec{a} \parallel \vec{b}$，求 $m$。

**思路**：直接应用向量平行坐标公式。

**步骤**：
由 $\vec{a} \parallel \vec{b}$ 得 $m\times(-2) - 4\times 3 = 0$，即 $-2m - 12 = 0$，解得 $m = -6$。

**点评/变式**：同样套路，符号易错点：$-2m=12 \Rightarrow m=-6$。若已知 $\vec{a}$ 与 $\vec{b}$ 同向或反向则需额外判断系数符号，本题只问平行则无此要求。还可考延伸：若此时 $|\vec{a}|=2\sqrt{13}$，求 $m$ 正负。本题用 $m=-6$，模长为 $\sqrt{36+16}=\sqrt{52}=2\sqrt{13}$，吻合。
