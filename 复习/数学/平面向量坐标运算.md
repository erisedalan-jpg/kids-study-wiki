## 知识精要
- **线性运算坐标化**
  - 加减法：若 $\vec{a}=(x_1, y_1)$，$\vec{b}=(x_2, y_2)$，则 $\vec{a} \pm \vec{b} = (x_1 \pm x_2, y_1 \pm y_2)$。
  - 数乘：$\lambda \vec{a} = (\lambda x_1, \lambda y_1)$。
- **数量积坐标化（用于求角、证垂直）**
  - 公式：$\vec{a} \cdot \vec{b} = x_1x_2 + y_1y_2$
  - 模长：$|\vec{a}| = \sqrt{x_1^2 + y_1^2}$
  - 垂直条件：$\vec{a} \perp \vec{b} \iff \vec{a} \cdot \vec{b} = 0 \iff x_1x_2 + y_1y_2 = 0$。
- **共线（平行）坐标条件（用于证平行、求参）**
  - 若 $\vec{a} \parallel \vec{b} (\vec{b} \neq \vec{0})$，则存在实数 $\lambda$ 使得 $\vec{a} = \lambda \vec{b}$。
  - 坐标表示：$x_1y_2 - x_2y_1 = 0$。注意分母非零时的比例关系。

## 解题方法与套路
1. **翻译几何条件**：将题目中的垂直、共线、长度、夹角及向量间线性关系（如 $\vec{PQ}=9\vec{QF}$）准确转化为对应向量的坐标方程。
2. **引入参数与坐标关联**：
   - 涉及圆锥曲线动点时，常利用曲线方程设出动点坐标（如抛物线 $(\frac{y^2}{2p}, y)$），用参数表达相关向量。
   - 目标向量尽量用已知点或已有参数表示，实现“统一变量”。
3. **构建关系式求参**：
   - 利用转化的坐标方程组，解出关键坐标或参数（如 $m, \lambda$）。
   - 对于最值问题，通过代入消元将目标量表达为单变量函数（如分式），利用基本不等式或判别式求最值。
4. **规范公式运算**：
   - 求模长先求差坐标再代入公式；数量积直接按 $x_1x_2 + y_1y_2$ 计算；多用垂直坐标条件快速列方程。

## 高频易错
- **坐标运算顺序错**：求 $|\vec{a}-\vec{b}|$ 时，易误算为 $|\vec{a}| - |\vec{b}|$。必须严格执行先求差坐标 $(-1, 1)$，再套用模长公式 $\sqrt{(-1)^2+1^2}$。
- **数量积公式混淆**：误用垂直或数量积公式，如将 $\vec{a}\cdot\vec{b}$ 误算为 $(x_1y_2, x_2y_1)$ 或 $x_1x_2 - y_1y_2$。
- **垂直条件用错**：混淆 $(\vec{a} + \vec{b}) \perp \vec{b}$ 与 $\vec{a} \perp \vec{b}$ 的方程，应先准确求出 $\vec{a} + \vec{b}$ 的坐标，再与 $\vec{b}$ 点乘为零。
- **共线公式记反或分母条件忽略**：将 $x_1y_2 - x_2y_1 = 0$ 错记为 $x_1x_2 - y_1y_2=0$；直接用分式时忽略分母为零的情况。
- **参数对应分量混淆**：在向量线性关系中（如 $\vec{PQ}=9\vec{QF}$），将 $x$ 分量关系与 $y$ 分量关系列错，导致错误方程组。

## 代表题精讲
### 1. 2019-文-03：向量模长计算
**题目**：已知 $\vec{a}=(2,3), \vec{b}=(3,2)$，求 $|\vec{a}-\vec{b}|$。
**思路**：直接利用向量减法坐标公式，再代入模长公式。
**步骤**：
- 计算差向量：$\vec{a} - \vec{b} = (2-3, 3-2) = (-1, 1)$。
- 计算模长：$|\vec{a}-\vec{b}| = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$。
**点评/变式**：这是最基础的坐标运算题，失分点往往在于跳步，仅当 $|\vec{a}|$ 与 $|\vec{b}|$ 共线同向时才相等。变式训练：求 $|2\vec{a}+3\vec{b}|$。

### 2. 2016-理-03：向量垂直求参
**题目**：已知 $\vec{a}=(1,m), \vec{b}=(3,-2)$，且 $(\vec{a}+\vec{b})\perp\vec{b}$，求 $m$。
**思路**：先正确计算和向量坐标，再利用垂直的充要条件（数量积为零）建立关于 $m$ 的方程并求解。
**步骤**：
- 求和向量：$\vec{a}+\vec{b} = (1+3, m-2) = (4, m-2)$。
- 由 $(\vec{a}+\vec{b})\perp\vec{b}$，得 $(\vec{a}+\vec{b})\cdot\vec{b} = 0$。
- 代入坐标：$4\times3 + (m-2)\times(-2) = 0$。
- 解方程：$12 - 2m + 4 = 0 \implies 16 - 2m = 0 \implies m = 8$。
**点评/变式**：关键在于求对和向量及应用垂直的坐标公式 $x_1x_2+y_1y_2=0$。变式：若改为 $(\vec{a}+\vec{b})\parallel\vec{b}$，则用 $4\times(-2) - 3\times(m-2)=0$ 求解。

### 3. 2021-文-20（节选）：向量关系下求斜率最值
**题目**：抛物线 $C: y^2=4x$ 的焦点 $F(1,0)$，点 $P$ 在 $C$ 上，点 $Q$ 满足 $\vec{PQ}=9\vec{QF}$，求 $OQ$ 斜率 $k$ 的最大值。
**思路**：利用抛物线方程合理设点 $P$ 坐标，将向量等式转化为坐标方程组，解出 $Q$ 点坐标，从而将斜率 $k$ 表达为 $P$ 点坐标参数的函数，最后利用基本不等式求最值。
**步骤**：
- 设点：令 $P(\frac{y_0^2}{4}, y_0)$，$Q(x_Q, y_Q)$。
- 表达向量：$\vec{PQ} = (x_Q - \frac{y_0^2}{4}, y_Q - y_0)$；$\vec{QF} = (1 - x_Q, -y_Q)$。
- 代入关系：由 $\vec{PQ} = 9\vec{QF}$，建立方程组：
$$\begin{cases} x_Q - \frac{y_0^2}{4} = 9(1 - x_Q) \\ y_Q - y_0 = 9(-y_Q) \end{cases}$$
- 解出 $Q$ 坐标：由第二式得 $10y_Q = y_0 \implies y_Q = \frac{y_0}{10}$；由第一式得 $10x_Q = \frac{y_0^2}{4} + 9 \implies x_Q = \frac{1}{10}(\frac{y_0^2}{4} + 9)$。
- 求斜率表达式：直线 $OQ$ 斜率 $k = \frac{y_Q}{x_Q} = \frac{\frac{y_0}{10}}{\frac{1}{10}(\frac{y_0^2}{4} + 9)} = \frac{y_0}{\frac{y_0^2}{4} + 9}$。
- 求 $k$ 的最大值：当 $y_0=0$ 时 $k=0$，不是最大；当 $y_0>0$ 时，$k = \frac{1}{\frac{y_0}{4} + \frac{9}{y_0}} \le \frac{1}{2\sqrt{\frac{y_0}{4}\cdot\frac{9}{y_0}}} = \frac{1}{2\times\frac{3}{2}} = \frac{1}{3}$。当且仅当 $\frac{y_0}{4}=\frac{9}{y_0}$ 即 $y_0=6$ 时等号成立。同理 $y_0<0$ 时，斜率最大值为 $\frac{1}{3}$。
**点评/变式**：此题将向量坐标运算与解析几何最值完美结合。关键是会利用曲线方程合理设参以简化运算，以及最后分式最值（常数分离、基本不等式）的处理技巧。这是解答压轴题的必备方法。
