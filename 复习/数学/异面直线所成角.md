## 知识精要
- **异面直线所成的角**：过空间任意一点，分别作两条异面直线的平行线，这两条相交直线所成的锐角或直角，即为异面直线所成的角。范围是 $(0,\frac{\pi}{2}]$。
- **核心方法**：
  1. **平移法**：利用中位线、平行四边形等，将其中一条或两条直线平移到同一平面内，构成相交直线，再解三角形求角。
  2. **向量法**：建立空间直角坐标系，求出两条异面直线的方向向量 $\vec{a},\vec{b}$，利用 $\cos\theta = |\cos\langle\vec{a},\vec{b}\rangle| = \frac{|\vec{a}\cdot\vec{b}|}{|\vec{a}||\vec{b}|}$ 求解，注意 $\theta\in(0,\frac{\pi}{2}]$，故余弦值必须取绝对值。
- **适用条件**：求角问题多以正方体、长方体、正棱柱、正棱锥为背景。平移法在图形规则时快捷；向量法在垂直关系明显、易于建系时通用性强。
- **必备公式**：余弦定理 $c^2=a^2+b^2-2ab\cos C$，向量坐标运算，线段长度公式。

## 解题方法与套路
1. **平移构造三角形法**  
   - 观察图形，利用已知平行关系（如正方形对边、中位线、平行六面体棱）平移一条直线，使其与另一条直线相交。  
   - 连线构造出包含该相交角的三角形（常为直角三角形或一般三角形）。  
   - 利用勾股定理、三角函数定义或余弦定理，直接求出角或角的三角函数值。  
   - 若求出的角为钝角，取其余角作为异面直线所成角；若用余弦定理得出负值，取其绝对值对应的锐角。

2. **空间向量坐标法**  
   - 找到三条两两垂直的棱，以交点为原点建立空间直角坐标系。  
   - 写出直线上各点坐标，求得两异面直线的方向向量。  
   - 用向量夹角余弦公式计算 $\cos\langle\vec{a},\vec{b}\rangle =\frac{\vec{a}\cdot\vec{b}}{|\vec{a}||\vec{b}|}$，再取绝对值，即 $\cos\theta = |\cos\langle\vec{a},\vec{b}\rangle|$。  
   - 若题目要求正切值等，先由余弦求正弦 $\sin\theta=\sqrt{1-\cos^2\theta}$，再求 $\tan\theta=\frac{\sin\theta}{\cos\theta}$。

3. **补形技巧**  
   将原几何体补成更规则的几何体（如直三棱柱补成直四棱柱），使异面直线变为可平移相交的直线，简化平移过程。

## 高频易错
- **角度范围混乱**：异面直线所成角的范围是 $(0,\frac{\pi}{2}]$，但平移后两相交直线所成角可能是锐角或钝角。若算出钝角，必须取其补角；使用余弦定理时，若 $\cos$ 为负，应取其绝对值对应的锐角。  
- **向量法忘记取绝对值**：直接用 $\cos\langle\vec{a},\vec{b}\rangle$ 而未加绝对值，当两向量夹角为钝角时导致错误。  
- **建系坐标求错**：正方体、长方体棱长赋值不一致；中点、端点坐标计算失误；忽略不同坐标轴方向导致的符号错误。  
- **平移后三角形误判**：构造的三角形不一定是直角三角形，盲目使用勾股定理；需先判断形状再选用解三角形方法。  
- **正切值求解遗漏分母有理化**，或误将邻边比对边。  
- **忽略隐含垂直关系**：如正方体对角线中线面垂直、线线垂直，导致无法简化计算。

## 代表题精讲
### **题目1**（2021年全国卷文/理）  
在正方体 $ABCD-A_1B_1C_1D_1$ 中，$P$ 为 $B_1D_1$ 的中点，求直线 $PB$ 与 $AD_1$ 所成的角。

**思路**  
$AD_1 \parallel BC_1$，将所求角转化为 $PB$ 与 $BC_1$ 的夹角，即 $\angle PBC_1$。连接 $PC_1$，证明 $PC_1 \perp PB$，从而在 $\text{Rt}\triangle PBC_1$ 中用正弦或边长比求角。

**步骤**  
1. 连接 $BC_1, PC_1, PB$，由 $AD_1\parallel BC_1$ 知 $\angle PBC_1$ 或其补角为所求。  
2. 设正方体棱长为2，则 $BC_1=2\sqrt{2}$，$PC_1=\frac{1}{2}B_1D_1=\sqrt{2}$。  
3. 由 $BB_1\perp$ 平面 $A_1B_1C_1D_1$ 知 $BB_1\perp PC_1$，又 $PC_1\perp B_1D_1$，故 $PC_1\perp$ 平面 $PBB_1$，从而 $PC_1\perp PB$。  
4. 在 $\text{Rt}\triangle PBC_1$ 中，$\sin \angle PBC_1 = \frac{PC_1}{BC_1}=\frac{\sqrt{2}}{2\sqrt{2}}=\frac{1}{2}$，得 $\angle PBC_1=\frac{\pi}{6}$，即异面直线所成角为 $\frac{\pi}{6}$。

**点评/变式**  
平移是处理正方体中异面直线所成角的首选。关键在利用已知平行线将分散线段集中，再通过线面垂直证出直角三角形简化计算。若 $P$ 变为 $B_1D_1$ 上动点，角度变化亦可转化为函数最值问题。

### **题目2**（2018年全国卷文）  
在正方体 $ABCD-A_1B_1C_1D_1$ 中，$E$ 为棱 $CC_1$ 的中点，求异面直线 $AE$ 与 $CD$ 所成角的正切值。

**思路**  
正方体棱垂直，易于建系。以 $D$ 为原点，$\overrightarrow{DA},\overrightarrow{DC},\overrightarrow{DD_1}$ 为 $x,y,z$ 轴正方向建立空间直角坐标系，写出 $A,E,D,C$ 的坐标，求方向向量 $\overrightarrow{AE}$ 与 $\overrightarrow{CD}$，利用向量夹角公式求余弦，再转化为正切。

**步骤**  
1. 设棱长为2，得 $A(2,0,0), E(0,2,1), C(0,2,0), D(0,0,0)$。  
2. $\overrightarrow{AE}=(-2,2,1)$，$\overrightarrow{CD}=(0,-2,0)$。  
3. $\cos\theta = \frac{|\overrightarrow{AE}\cdot\overrightarrow{CD}|}{|\overrightarrow{AE}||\overrightarrow{CD}|} = \frac{|0-4+0|}{\sqrt{(-2)^2+2^2+1^2}\cdot\sqrt{0^2+(-2)^2+0^2}} = \frac{4}{3\cdot 2} = \frac{2}{3}$。  
4. $\sin\theta = \sqrt{1-\left(\frac{2}{3}\right)^2}=\frac{\sqrt{5}}{3}$，$\tan\theta = \frac{\sin\theta}{\cos\theta}=\frac{\sqrt{5}}{2}$。

**点评/变式**  
建系法对于规则几何体非常有效，无需繁琐的平移构造。注意异面直线所成角向量的余弦取绝对值。变式中若求 $AE$ 与 $D_1C_1$ 所成角，同样可用向量法，注意方向向量的选取。两种方法结合可确保准确率。
