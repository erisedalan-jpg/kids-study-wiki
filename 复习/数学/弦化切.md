## 知识精要
- **弦化切的核心变换**：已知 $\tan\alpha$、$\tan\beta$ 的和与积，可求 $\sin(\alpha+\beta)$、$\cos(\alpha+\beta)$、$\tan(\alpha+\beta)$，无需单独求出 $\alpha$、$\beta$。
- **基本公式**：  
  $$\tan(\alpha+\beta)=\frac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta}$$  
  同角关系：$\sin\theta=\frac{\tan\theta}{\pm\sqrt{1+\tan^2\theta}}$，$\cos\theta=\frac{1}{\pm\sqrt{1+\tan^2\theta}}$，符号由 $\theta$ 所在象限决定。  
- **和角展开的弦切联动**：  
  $$\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta=\cos\alpha\cos\beta(\tan\alpha+\tan\beta)$$  
  $$\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta=\cos\alpha\cos\beta(1-\tan\alpha\tan\beta)$$  
  平方关系：$\sin^2(\alpha+\beta)+\cos^2(\alpha+\beta)=1$。
- **适用条件**：已知 $\tan\alpha\pm\tan\beta$ 与 $\tan\alpha\tan\beta$（或可构造韦达定理的形式），且能通过角范围确定 $\cos\alpha\cos\beta$ 的符号。

## 解题方法与套路
1. **正切和角先行**：遇到 $\tan\alpha+\tan\beta$ 与 $\tan\alpha\tan\beta$，立刻写出 $\tan(\alpha+\beta)=\frac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta}$，得到整体角的正切值。
2. **设公因子连乘**：设 $C=\cos\alpha\cos\beta$，则  
   $\sin(\alpha+\beta)=C(\tan\alpha+\tan\beta)$，  
   $\cos(\alpha+\beta)=C(1-\tan\alpha\tan\beta)$。  
   将已知代入，消去 $\tan$ 得到关于 $C$ 的表达式。
3. **利用平方关系定 $C$**：由 $\sin^2(\alpha+\beta)+\cos^2(\alpha+\beta)=1$ 建立方程，解出 $C^2$，再根据 $\alpha,\beta$ 所在象限的余弦符号确定 $C$ 的正负。
4. **回代求目标值**：将 $C$ 代入 $\sin(\alpha+\beta)$ 或 $\cos(\alpha+\beta)$ 的表达式，得到最终结果。若需要 $\sin$，直接用 $\sin(\alpha+\beta)=C(\tan\alpha+\tan\beta)$ 即可。

## 高频易错
- **忽略角度象限对弦符号的影响**：已知 $\tan$ 值可正可负，但通过 $\alpha$、$\beta$ 的具体象限可确定 $\cos\alpha\cos\beta$ 的符号，绝不能直接开方取正。
- **混淆 $\tan(\alpha+\beta)$ 与 $\sin(\alpha+\beta)$ 的符号**：$\tan(\alpha+\beta)$ 为负不代表 $\sin(\alpha+\beta)$ 一定为负，必须结合 $\alpha+\beta$ 的范围综合判断，或者通过 $C$ 的符号一并定出弦的符号。
- **直接使用 $\sin\theta=\tan\theta/\sqrt{1+\tan^2\theta}$ 时漏掉 $\pm$**：当 $\theta$ 的象限未确定时，该公式自带正负号，需额外分析。
- **韦达定理求正切两根后直接求弦**：若试图先求 $\tan\alpha$、$\tan\beta$ 再展开 $\sin(\alpha+\beta)$，过程繁琐且容易引入二次根式运算错误；整体“弦化切”更为高效。

## 代表题精讲
### 代表题：2024-新课标Ⅱ-13
**题目**：已知 $\alpha$ 为第一象限角，$\beta$ 为第三象限角，$\tan\alpha+\tan\beta=4$，$\tan\alpha\tan\beta=\sqrt{2}+1$，求 $\sin(\alpha+\beta)$。

**思路**：不单独求 $\alpha,\beta$。利用整体代入，先得到 $\tan(\alpha+\beta)$，再通过“公因子 $C=\cos\alpha\cos\beta$”搭桥，用平方关系求出 $C$ 并定号，最终得到 $\sin(\alpha+\beta)$。

**步骤**：  
1. 计算 $\tan(\alpha+\beta)=\frac{4}{1-(\sqrt{2}+1)}=\frac{4}{-\sqrt{2}}=-2\sqrt{2}$。  
2. 设 $C=\cos\alpha\cos\beta$，则 $\sin(\alpha+\beta)=C(\tan\alpha+\tan\beta)=4C$，$\cos(\alpha+\beta)=C(1-\tan\alpha\tan\beta)=-\sqrt{2}C$。  
3. 代入平方恒等式：$(4C)^2+(-\sqrt{2}C)^2=1 \Rightarrow 16C^2+2C^2=18C^2=1 \Rightarrow C^2=\frac{1}{18}$。  
4. 定号：$\alpha$ 在第一象限 $\Rightarrow\cos\alpha>0$；$\beta$ 在第三象限 $\Rightarrow\cos\beta<0$，故 $C=\cos\alpha\cos\beta<0$，取 $C=-\frac{1}{3\sqrt{2}}=-\frac{\sqrt{2}}{6}$。  
5. 计算目标：$\sin(\alpha+\beta)=4C=4\times\left(-\frac{\sqrt{2}}{6}\right)=-\frac{2\sqrt{2}}{3}$。

**点评/变式**：本题巧妙避开了直接求 $\tan\alpha,\tan\beta$ 的繁琐步骤，考查“弦化切”的整体代换思想。若题目改为求 $\cos(\alpha+\beta)$ 或 $\tan(\alpha+\beta)$，第一步即可得出正切值；若改为已知 $\sin(\alpha+\beta)$ 求正切之和与积，同样可逆向使用公因子法。注意，任何时候都必须养成“象限定号”的警觉，这是区分答案唯一性的关键。
