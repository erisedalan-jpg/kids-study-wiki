## 知识精要
1. **抛物线定义**：平面内到一个定点 $F$（焦点）和一条定直线 $l$（准线，$F otin l$）距离相等的点的轨迹。
   - 表达式：$|PF| = d(P, l)$
   - 焦点 $F$ 到准线 $l$ 的距离为焦准距，记作 $p$ ($p>0$)。

2. **标准方程与几何性质（以焦点在 $x$ 轴正半轴为例）**：
   - 方程：$y^2 = 2px \ (p>0)$
   - 焦点：$F(\frac{p}{2}, 0)$；准线：$x = -\frac{p}{2}$
   - 真题中出现的高频特例 $y^2 = 4x$：此时 $2p = 4$，即 $p = 2$。
     - 焦点：$F(1, 0)$；准线：$x = -1$；焦点到准线距离为 $p = 2$。
   - 通径：过焦点垂直对称轴的弦，长度为 $2p$。对 $y^2=4x$，通径长为 $4$。

3. **焦点弦（定义延伸）**：
   - 设 $AB$ 是过焦点 $F$ 的弦，$A(x_1, y_1)$，$B(x_2, y_2)$。
   - 焦半径：$|AF| = x_1 + \frac{p}{2}$，$|BF| = x_2 + \frac{p}{2}$。
   - 弦长公式：$|AB| = |AF| + |BF| = x_1 + x_2 + p$。
   - 以参数角 $\theta$（倾斜角）表示的弦长公式：$|AB| = \frac{2p}{\sin^2\theta}$（适用于标准位置开口向右的抛物线）。

4. **定义的转化桥梁作用**：抛物线上的点到焦点的距离与到准线的距离可等量转化。这是解决最值、存在性、相切等综合问题的核心利器。

## 解题方法与套路
1. **回归定义，化曲为直**：
   遇到涉及抛物线上动点到焦点（或准线）距离的问题，优先利用定义将折线段和转化为直线段。如将 $|PF|$ 转化为点 $P$ 到准线的距离，进而与垂足、切点产生几何关联（如 2024 年真题及 2018 年圆的构造）。

2. **焦点弦的两种处理策略**：
   - **坐标法（设而不求）**：设过焦点 $F$ 的直线为 $y = k(x - 1)$($y^2=4x$ 为例)，联立抛物线消元，利用韦达定理得出 $x_1+x_2$ 及 $x_1x_2$ 的值，代入 $|AB| = x_1 + x_2 + p$ 求参。
   - **倾斜角法（二级结论）**：若已知弦长求斜率或倾斜角，直接使用 $|AB| = \frac{2p}{\sin^2\theta}$ 可极大简化运算。

3. **几何法辅助求解**：
   遇到与切线、垂足、相切圆相关的综合题，先根据定义转化距离，再利用平面几何性质（如：圆心距与半径的关系、中位线、垂直平分线）确定圆心轨迹或半径，减少纯代数运算的复杂度。

4. **设点设线的技巧**：
   - 若点在抛物线上，可设动点 $P(\frac{y_0^2}{2p}, y_0)$ 或 $P(2pt^2, 2pt)$，利用参数减少变量个数。
   - 凡过焦点 $(1,0)$ 的直线，设成 $x = my + 1$ 可避免讨论斜率是否存在的失分风险，且在 $y^2 = 4x$ 中联立可直接得到 $y_1+y_2$ 及 $y_1y_2$。

5. **轨迹与定点定值**：
   利用定义直接判断动点轨迹为抛物线，避免列式平移化简。对于相切问题，紧扣圆心到准线距离等于半径这一条件。

## 高频易错
- **混淆标准方程与焦点、准线的对应关系**：开口方向不同，方程中 $p$ 的符号和准线的位置极易写反。务必牢记 $y^2 = 4x$ 焦点是 $F(1,0)$ 而非 $F(2,0)$，准线是 $x=-1$。
- **定义应用失误**：距离转化时漏掉方向或搞错添项。点 $(x_0, y_0)$ 在 $y^2 = 2px$ 上时，到焦点距离为 $x_0 + \frac{p}{2}$；到准线距离为 $x_0 - (-\frac{p}{2}) = x_0 + \frac{p}{2}$。若点坐标含负值，切忌直接套用线段表象长度。
- **焦点弦公式适用范围**：弦长公式 $|AB| = x_1 + x_2 + p$ 仅适用于过焦点的弦。非焦点弦不可使用。公式 $|AB| = \frac{2p}{\sin^2\theta}$ 仅对标准形式的抛物线（顶点在原点、开口向右）过焦点的弦直接有效，若倾斜角变化或被题型改编，需重新推导。
- **半径的几何关系复杂化**：利用准线为切线求圆方程时，半径是圆心到准线的距离，同时也是到点 $A, B$ 的距离。考生常因未结合抛物线定义确定圆心坐标的隐含条件，导致计算繁琐或解错。
- **计算过失丢分**：
  - 联立方程时漏算 $\Delta$ 的验证，虽然求斜率 $k$ 时多为正，但必须写判断步骤。
  - 焦点弦的横坐标 $x_1, x_2$ 可能为 $1 \pm \sqrt{2}$ 等形式，求 $|AB|$ 时易因去绝对值的符号错误导致算错距离。

## 代表题精讲
### 代表题 1：2024-新课标Ⅱ-10（多选题）
**题目**：抛物线 $C: y^2 = 4x$ 准线为 $l$，$P$ 为 $C$ 上动点。过 $P$ 作圆 $A: (x+4)^2 + y^2 = 1$ 的切线，切点为 $Q$；过 $P$ 作 $l$ 的垂线，垂足为 $B$。判断 $l$ 与圆 $A$ 的位置关系等选项。
**思路**：直接求圆心 $A(-4, 0)$ 到准线 $x = -1$ 的距离，与圆 $A$ 半径 $r=1$ 比较。利用抛物线定义，将 $|PB|$ 转化为 $|PF|$，再结合切线长定理、圆外一点到圆的切线长公式来研究 $|PQ|$ 与 $|PB|$ 的等量关系。
**步骤**：
1. 由 $y^2 = 4x$ 得准线 $l: x = -1$，焦点 $F(1, 0)$。
2. 圆 $A$ 的圆心为 $(-4, 0)$，半径 $r = 1$。圆心到准线 $l$ 的距离 $d = |-4 - (-1)| = 3$。由于 $3 > 1$，$l$ 与圆 $A$ **相离**。由此排除相切选项。
3. 设 $P(x_0, y_0)$，由抛物线定义，$|PB|$ 等于 $P$ 到准线 $l$ 的距离 $x_0 + 1$。
4. $P$ 到焦点 $F$ 的距离 $|PF|$ 也等于 $x_0 + 1$。故 $|PB| = |PF|$。
5. 在 $Rt\triangle PAQ$ 中，切线长 $|PQ| = \sqrt{|PA|^2 - r^2} = \sqrt{|PA|^2 - 1}$。
6. 结合几何或代数代换，可探讨 $|PQ|$ 与 $|PB|$ 的大小关系是否恒定，或何时取等。
**点评/变式**：本题将抛物线定义与圆的切线长融合，核心枢纽是 $|PB| = |PF|$。凡是遇到动点向准线作垂线，必须条件反射般在脑中建立与焦点的连线，常用此等量代换破解线段最值或恒等式。

### 代表题 2：2022-理科-05（2022 文科-06）
**题目**：设 $F$ 为 $y^2 = 4x$ 的焦点，点 $A$ 在 $C$ 上，点 $B(3, 0)$，$|AF| = |BF|$，求 $|AB|$。
**思路**：直接计算 $|BF|$ 得出 $|AF|$ 长度，再利用抛物线定义将 $|AF|$ 转化为点 $A$ 到准线 $x=-1$ 的距离，倒推出点 $A$ 的横坐标。进一步求出 $A$ 点坐标，最后利用两点间距离公式求 $|AB|$。
**步骤**：
1. 由 $y^2 = 4x$ 知焦点 $F(1, 0)$，准线 $x = -1$。
2. $B(3, 0)$，故 $|BF| = |3 - 1| = 2$。由 $|AF| = |BF|$ 得 $|AF| = 2$。
3. 设 $A(x_0, y_0)$，由抛物线定义，$|AF|$ 等于 $A$ 到准线距离，即 $x_0 - (-1) = x_0 + 1 = 2$。
4. 解得 $x_0 = 1$。代入 $y^2 = 4 \times 1 = 4$，得 $y_0 = \pm 2$。不妨取 $A(1, 2)$ 或 $A(1, -2)$。
5. 计算 $|AB| = \sqrt{(1 - 3)^2 + (\pm 2 - 0)^2} = \sqrt{(-2)^2 + 4} = \sqrt{8} = 2\sqrt{2}$。
**点评/变式**：此类题为“单点挂靠型”基础题，切勿动用大运算量设线联立。一切围绕 $|AF|$ 等于“横坐标加半焦准距”展开。若本题 $B$ 点坐标换到准线上或改为焦点弦条件，仍需回归到“通过距离反求横坐标”的思路。
