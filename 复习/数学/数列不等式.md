## 知识精要
- **等差数列与等比数列的转化**  
  若 $a_1, 3a_2, 9a_3$ 成等差数列，则 $2 \times (3a_2) = a_1 + 9a_3$。将等比通项 $a_n = a_1 q^{n-1}$ 代入可解公比 $q$。
- **等比数列前 $n$ 项和**  
  $a_1=1, q \neq 1$ 时，$S_n = \frac{a_1(1-q^n)}{1-q}$。本题 $q=\frac13$，得 $S_n = \frac32\left(1-\frac1{3^n}\right)$。
- **错位相减法求 $\{n \cdot q^n\}$ 型前 $n$ 项和**  
  对 $T_n = \sum_{k=1}^n k \cdot q^k$（或类似形式），乘公比 $q$ 后错位相减，利用等比数列求和化简。  
  公式原型：  
  $$T_n = \sum_{k=1}^n k x^{k} \quad (x \neq 1) \;\Longrightarrow\; T_n = \frac{x - (n+1)x^{n+1} + n x^{n+2}}{(1-x)^2}$$
  本题 $b_n = \frac{n}{3^n}$，对应 $x=\frac13$，用标准步骤可解。
- **数列不等式的证明**  
  求出 $S_n$ 与 $T_n$ 的解析式后，常用作差法或放缩法比较大小。若作差结果恒负（正），则不等式得证。无需过度放缩时，直接化简更可靠。

## 解题方法与套路
1. **通项优先，方程求参**  
   根据等差（等比）条件列出关于首项、公差的方程，解出基本量，写出通项公式。
2. **识别差比结构，固定错位相减步骤**  
   - 写出 $T_n$ 展开式；  
   - 两边同乘公比 $q$（本题为 $\frac13$）得到 $qT_n$ 的展开式；  
   - 两式相减（通常用 $T_n - qT_n$），中间项呈现等比数列；  
   - 对中间等比部分求和，再整理出 $T_n$ 的封闭形式。  
   **公式化记忆**：$\{n \cdot q^{n-1}\}$ 求和结果为 $\frac{1 - (n+1)q^n + n q^{n+1}}{(1-q)^2}$，可代入验证。
3. **证明不等式：先化简，再作差**  
   将 $S_n$ 和 $T_n$ 写成最简分式，将欲证不等式移项化为 $T_n - \frac{S_n}{2} < 0$，代入计算结果，判定符号。若结果为 $- \frac{n}{2\cdot 3^n}$ 等形式，直接得结论。

## 高频易错
- **等差条件列式错位**：$a_1, 3a_2, 9a_3$ 成等差，是 $2 \cdot (3a_2) = a_1 + 9a_3$，勿漏乘系数 $3$ 或 $9$。
- **等比求和公式记混**：$S_n = \frac{a_1(1-q^n)}{1-q}$，分母是 $1-q$；注意 $q^n$ 指数与项数对应。
- **错位相减时项数匹配错误**：乘 $q$ 后，$qT_n$ 最后一项指数为 $n+1$；相减时中间对齐的项数为 $n-1$ 项，极易多算或少算。
- **错位相减后整理符号出错**：$T_n - qT_n$ 右侧首项是 $T_n$ 的首项，末项是 $-qT_n$ 的末项；合并时分数通分、提取公因式要步步心算验证。
- **不等式证明未彻底化简**：求出 $T_n$ 后直接代入 $T_n < \frac{S_n}{2}$，若不提取公因式或通分，易看不出恒负（恒正），导致“伪证”或未完成证明。

## 代表题精讲
### 代表题：2021-文-19
**题目**  
已知 $\{a_n\}$ 是首项为 $1$ 的等比数列，$b_n = \frac{n a_n}{3}$，且 $a_1, 3a_2, 9a_3$ 成等差数列。  
（1）求 $\{a_n\}$ 和 $\{b_n\}$ 的通项公式；  
（2）记 $S_n, T_n$ 分别为 $\{a_n\}$ 和 $\{b_n\}$ 的前 $n$ 项和，证明：$T_n < \frac{S_n}{2}$。

**思路**  
（1）由等差数列条件建立公比 $q$ 的方程；解出 $q$ 得 $a_n$，再代入 $b_n$。  
（2）分别用等比求和与错位相减法求 $S_n$ 与 $T_n$，作差证明不等式。

**步骤**  
**（1）** 设公比为 $q$，则 $a_n = q^{n-1}$。  
由 $a_1, 3a_2, 9a_3$ 成等差：$2 \cdot 3a_2 = a_1 + 9a_3$  
$\Rightarrow 6q = 1 + 9q^2 \;\Longrightarrow\; 9q^2 - 6q + 1 = 0 \;\Longrightarrow\; (3q-1)^2 = 0$  
得 $q = \frac13$，故 $a_n = \left(\frac13\right)^{n-1}$，  
$b_n = \frac{n a_n}{3} = \frac{n}{3} \cdot \left(\frac13\right)^{n-1} = \frac{n}{3^n}$。

**（2）** $\{a_n\}$ 前 $n$ 项和：  
$$S_n = \frac{1 \cdot \left(1 - \frac1{3^n}\right)}{1 - \frac13} = \frac32\left(1 - \frac1{3^n}\right)$$
$\{b_n\}$ 前 $n$ 项和 $T_n$：  
$T_n = \frac1{3} + \frac2{3^2} + \frac3{3^3} + \cdots + \frac{n}{3^n}$  
乘 $\frac13$：$\frac13 T_n = \frac1{3^2} + \frac2{3^3} + \cdots + \frac{n-1}{3^n} + \frac{n}{3^{n+1}}$  
相减：$\frac23 T_n = \frac1{3} + \frac1{3^2} + \cdots + \frac1{3^n} - \frac{n}{3^{n+1}}$  
中间等比求和：$\frac{\frac13(1-\frac1{3^n})}{1-\frac13} = \frac12\left(1-\frac1{3^n}\right)$  
故 $\frac23 T_n = \frac12\left(1-\frac1{3^n}\right) - \frac{n}{3^{n+1}}$  
$\Rightarrow T_n = \frac34\left(1-\frac1{3^n}\right) - \frac{n}{2 \cdot 3^n}$  
比较 $T_n$ 与 $\frac{S_n}{2} = \frac34\left(1-\frac1{3^n}\right)$：  
$T_n - \frac{S_n}{2} = -\frac{n}{2 \cdot 3^n} < 0$ 恒成立，  
所以 $T_n < \frac{S_n}{2}$，得证。

**点评/变式**  
- 本题核心是错位相减法，步骤固定，计算量可控；不等式证明退化为作差直接得符号，难度较低。  
- 变式1：若 $b_n = n \cdot a_n$，则求和时乘公比 $q$；证明可能需放缩。  
- 变式2：改为证明 $T_n > \frac{S_n}{4}$ 等形式，可训练放缩或函数单调性视角，避免过度依赖直接作差。
