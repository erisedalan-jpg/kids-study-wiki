## 知识精要
- **数列单调性的定义**：若对任意 $n \in \mathbb{N}^*$，有 $a_{n+1} > a_n$（或 $a_{n+1} \ge a_n$），则称 $\{a_n\}$ 为递增数列；$a_{n+1} < a_n$（或 $a_{n+1} \le a_n$）为递减数列。
- **判定方法**：
  1. **作差法**：$a_{n+1} - a_n$ 的符号决定单调性。
  2. **作商法**（正项数列）：$\frac{a_{n+1}}{a_n}$ 与 $1$ 的关系决定单调性。
  3. **函数法**：若通项 $a_n = f(n)$，则 $f(x)$ 在 $[1,+\infty)$ 上的单调性决定数列单调性；对递推数列 $a_{n+1} = f(a_n)$，可借助 $f(x)$ 的单调性与不动点分析。
- **连分数数列的单调性**（本考点核心）：
  设 $a_k \in \mathbb{N}^*$，数列 $\{b_n\}$ 定义为连分数渐近序列：
  $$b_1 = 1+\frac{1}{a_1},\; b_2 = 1+\frac{1}{a_1+\frac{1}{a_2}},\; b_3 = 1+\frac{1}{a_1+\frac{1}{a_2+\frac{1}{a_3}}},\; \dots$$
  则 $\{b_n\}$ 具有严格的奇偶交叉单调性：
  - **奇数项递减**：$b_1 > b_3 > b_5 > \dots$
  - **偶数项递增**：$b_2 < b_4 < b_6 < \dots$
  - **任意偶数项小于任意奇数项**：对 $\forall m,n \in \mathbb{N}^*$，有 $b_{2m} < b_{2n-1}$。

  此性质源于正项连分数的截断性质：每增加一层，奇数层逼近值单调递减，偶数层逼近值单调递增，且整体交错。

## 解题方法与套路
1. **识别连分数结构**：题目中出现形如 $1+\frac{1}{a_1+\frac{1}{a_2+\dots}}$ 的嵌套分式，立即联想到渐近分数序列 $\{b_n\}$。
2. **参数正化**：确认 $a_k > 0$（本题 $a_k \in \mathbb{N}^* \Rightarrow a_k \ge 1$），这是放缩与倒数保持不等号方向的前提。
3. **局部比较建立基础不等式**：
   由 $a_1 < a_1 + \frac{1}{a_2}$（分母更大），得 $\frac{1}{a_1} > \frac{1}{a_1+\frac{1}{a_2}}$，从而 $b_1 > b_2$。
   类似地，可逐层推得 $b_2 < b_3$，$b_3 > b_4$ … 依此确定奇偶单调方向。
4. **归纳/递推获得整体单调性**：
   设第 $n$ 层连分数值为 $c_n$，则有 $b_n = 1 + \frac{1}{a_1 + c_{n-1}}$。通过 $c_n$ 的奇偶单调性反推 $b_n$ 的单调性，或直接记忆“奇数项递减，偶数项递增，偶数项<奇数项”的口诀。
5. **选项比大小**：
   - 同奇偶项比较：用单调性直接判大小（奇数项递减，偶数项递增）。
   - 奇偶异项比较：一律有偶数项小于奇数项，无需计算中间项。

## 高频易错
- **忽略 $a_k$ 的正整数条件**：若 $a_k$ 可以为 $0$ 或负值，则不等式方向可能反转。务必在解题第一步圈出 $a_k \in \mathbb{N}^*$，确保分母为正且放缩安全。
- **奇偶单调性混淆**：死记“奇减偶增，偶小奇大”。常见错选 A（$b_1 < b_5$）或 C（$b_6 < b_2$），本质是把奇数项当成递增，或把偶数项当成递减。
- **直接通分计算**：对于项数较多的 $b_6$、$b_8$ 等，暴力通分展开计算量极大且易错，必须用结构性质比大小。
- **不等号传递失误**：在多层嵌套倒数时，每取一次倒数不等号反向，两次反向则恢复，操作层数记混容易导致结论相反。建议用具体数字（如 $a_k=1$）代入验算理清方向。

## 代表题精讲
### **题目**（2022 全国甲卷·理 4）
嫦娥二号卫星绕日周期与地球绕日周期的比值用到数列 $\{b_n\}$：$b_1 = 1+\frac{1}{a_1}$，$b_2 = 1+\frac{1}{a_1+\frac{1}{a_2}}$，$b_3 = 1+\frac{1}{a_1+\frac{1}{a_2+\frac{1}{a_3}}}$，$\dots$，其中 $a_k \in \mathbb{N}^*$。判断正确选项：
A. $b_1 < b_5$   B. $b_3 < b_8$   C. $b_6 < b_2$   D. $b_4 < b_7$

**思路**：此题 $a_k \ge 1$，$\{b_n\}$ 为正项数列且具有连分数渐近结构。不直接计算通项，而是利用正数倒数反向不等式的性质，比较相邻项大小，归纳出“奇数项递减，偶数项递增，偶数恒小于奇数”的结论，再逐项对照选项。

**步骤**：
1. 由 $a_1, a_2 \in \mathbb{N}^*$ 知 $a_1 < a_1 + \frac{1}{a_2}$，取倒数得 $\frac{1}{a_1} > \frac{1}{a_1+\frac{1}{a_2}}$，从而 $b_1 = 1+\frac{1}{a_1} > 1+\frac{1}{a_1+\frac{1}{a_2}} = b_2$，即 $b_1 > b_2$。
2. 同理，比较 $b_2$ 与 $b_3$：注意到 $a_1+\frac{1}{a_2} < a_1+\frac{1}{a_2+\frac{1}{a_3}}$，再次取倒数并加 1，得 $b_2 < b_3$。依此类推，可得两条单调链：
   - 奇数项：$b_1 > b_3 > b_5 > b_7 > \cdots$
   - 偶数项：$b_2 < b_4 < b_6 < b_8 < \cdots$
3. 进一步可证任意偶数项均小于任意奇数项（连分数收敛性），因此整体排序为：
   $$b_2 < b_4 < b_6 < b_8 < \cdots < b_7 < b_5 < b_3 < b_1.$$
4. 检验选项：
   - A：$b_1$ 与 $b_5$ 同属奇数项，奇数递减 $\Rightarrow b_1 > b_5$，A 错。
   - B：$b_3$ 为奇数项，$b_8$ 为偶数项，奇数大于偶数 $\Rightarrow b_3 > b_8$，B 错。
   - C：$b_6$ 与 $b_2$ 同属偶数项，偶数递增 $\Rightarrow b_6 > b_2$，C 错。
   - D：$b_4$ 为偶数项，$b_7$ 为奇数项，偶数小于奇数 $\Rightarrow b_4 < b_7$，D 正确。

**点评/变式**：本题以科技情境包装，本质是连分数数列的单调性比较。解题关键在于将复杂嵌套分式理解成一层层“加倒数”操作，利用正整数带来的严格不等式关系，导出奇偶交叉的单调结论。若条件改为 $a_k \in \mathbb{R}^+$ 且不一定大于等于 1，结论仍成立（只需各项为正）。变式训练时可请学生自行推导 $b_n$ 与 $b_{n+2}$ 的大小关系，并证明“偶数项均小于奇数项”。
