## 知识精要
- **递推公式**：给出数列两项或多项之间的关系式，如 $a_{n+1}=f(a_n)$ 或含 $S_n$ 的关系。
- **$a_n$ 与 $S_n$ 的基本关系**：
  $$a_n = \begin{cases} S_1, & n=1 \\ S_n - S_{n-1}, & n\ge 2 \end{cases}$$
  常用于消去 $a_n$ 或 $S_n$，得到仅含 $S_n$ 或仅含 $a_n$ 的递推。
- **常见递推模型与构造方法**：
  1. **$a_{n+1}=pa_n+q$**（$p\neq1$，$q\neq0$）：构造等比，设 $a_{n+1}+\lambda=p(a_n+\lambda)$，解得 $\lambda=\frac{q}{p-1}$。
  2. **$a_{n+1}=a_n+f(n)$**（累加法）：$a_n=a_1+\sum_{k=1}^{n-1}f(k)$。
  3. **$a_{n+1}=f(n)a_n$**（累乘法）：$a_n=a_1\prod_{k=1}^{n-1}f(k)$。
  4. **$a_{n+1}=\frac{pa_n}{qa_n+r}$**（倒数型）：取倒数化为 $\frac{1}{a_{n+1}}$ 的线性关系。
  5. **$a_{n+1}+(-1)^n a_n = f(n)$**（含 $(-1)^n$ 奇偶交替）：一般分奇偶项列式，通过消元或并项转化为隔项递推，再进行分组求和。
  6. **周期递推**：若 $a_{n+T}=a_n$ 恒成立，则数列为周期数列，可通过计算前几项发现周期。
- **等比/等差数列的定义**：证明数列 $\{b_n\}$ 为等差或等比，需得出 $b_{n+1}-b_n=d$ 或 $\frac{b_{n+1}}{b_n}=q$（常数），且注意首项非零（等比）。
- **适用条件注意**：所有利用 $a_n=S_n-S_{n-1}$ 的变形必须注意 $n\ge2$；构造新数列时需验证首项是否符合构造形式。

## 解题方法与套路
1. **$S_n$ 与 $a_n$ 的互化**  
   已知 $S_n$ 与 $a_n$ 的等式，考虑利用 $a_{n+1}=S_{n+1}-S_n$（或 $a_n=S_n-S_{n-1}$）消元，得到纯相邻项或纯 $S_n$ 的递推，再往等差或等比转化。
2. **构造辅助数列**  
   对于非标准型递推，通过取倒数、因式分解、两边同加（乘）常数、同除以某式等手段，构造出 $\left\{\frac{1}{a_n}\right\}$、$\{a_{n+1}-2a_n\}$ 等能判定等差/等比的新数列。
3. **累加 / 累乘法**  
   遇到 $a_{n+1}-a_n = f(n)$ 可累加；$\frac{a_{n+1}}{a_n}=f(n)$ 可累乘。当 $f(n)$ 为可求和或可化简的数列时直接计算。
4. **奇偶分拆与分组处理**  
   递推式中含有 $(-1)^n$ 或奇偶项关系不同时，分别对 $n$ 取奇数和偶数列出等式，通过加减消元得到关于 $a_{2k-1}$ 和 $a_{2k}$ 的独立递推；求和时按两项或四项一组整理，转化为若干个可求和的片段。
5. **周期识别与验证**  
   若递推式不易直接解出通项，可计算前几项（如 $a_1,a_2,a_3,\dots$）观察是否有重复，确定周期 $T$ 后，所求任意项均可通过模 $T$ 转化为前几项之一。
6. **错位相减预备**  
   由递推求出通项后（如 $a_n = n\cdot 2^{2n-1}$ 型），求和时注意等差数列乘等比数列的结构，采用错位相减法。

## 高频易错
- **忽略 $n\ge2$ 条件**：利用 $a_n=S_n-S_{n-1}$ 构造等差或等比时，必须注明 $n\ge2$，且需单独验证 $n=1$ 时首项是否满足所得通项公式。
- **倒数变形时忘记约束**：等式两边同除以 $S_{n+1}S_n$ 或 $a_na_{n+1}$ 前，应确保这些项不为零，否则可能漏解或产生增根。
- **奇偶分组时项数混淆**：含 $(-1)^n$ 的递推求和，前 $60$ 项分组容易算错组数；建议先写出相邻两式推得的规律，再按规律的周期（如每 $4$ 项一个片段）计算总数。
- **周期数列起点推算错误**：递推方向为正向给出 $a_8$ 反求 $a_1$ 时，需正确逆向迭代或正向从 $a_1$ 试推找周期，极容易多算或少算一项导致余数对应错误。
- **构造新数列时首项计算错误**：构造出 $\left\{\frac1{S_n}\right\}$ 为首项 $-1$、公差 $-1$，忘记 $S_1=a_1=-1$，直接当做正数导致符号错误。
- **累加时项数出错**：累加法求和从 $a_1$ 加到 $a_n$，中间有 $n-1$ 个等式，求和上限为 $n-1$，代入 $f(n)$ 时常见标号偏移。

## 代表题精讲
### 1. 2015 理 16
**题目**：数列 $\{a_n\}$ 前 $n$ 项和 $S_n$，$a_1=-1$，$a_{n+1}=S_{n+1}S_n$，求 $S_n$。  
**思路**：题目给出 $a_{n+1}$ 与 $S_{n+1},S_n$ 的关系，自然想到利用 $a_{n+1}=S_{n+1}-S_n$ 消去 $a_{n+1}$，得到关于 $S_n$ 的递推，再变形构造等差数列。  
**步骤**：  
由 $a_{n+1}=S_{n+1}-S_n$ 及已知得 $S_{n+1}-S_n = S_{n+1}S_n$。两边同除以 $S_{n+1}S_n$（$S_n\neq0$ 由递推及首项保证），得 $\frac{1}{S_n} - \frac{1}{S_{n+1}} = 1$，即 $\frac{1}{S_{n+1}} - \frac{1}{S_n} = -1$。又 $\frac{1}{S_1}=\frac{1}{a_1} = -1$，故数列 $\left\{\frac{1}{S_n}\right\}$ 是首项 $-1$、公差 $-1$ 的等差数列。于是 $\frac{1}{S_n} = -1 + (n-1)(-1) = -n$，得 $S_n = -\frac{1}{n}$。  
**点评与变式**：核心是 $a_n$ 与 $S_n$ 的转化，并构造倒数等差数列。变式可能让求 $a_n$，只需再结合 $a_n=S_n-S_{n-1}\,(n\ge2)$。易错：忘考虑 $S_n$ 是否为零、遗漏 $n=1$ 验证。

### 2. 2014 文 16
**题目**：数列 $\{a_n\}$ 满足 $a_{n+1}=\frac{1}{1-a_n}$，$a_8=2$，求 $a_1$。  
**思路**：递推式为分式形式，直接求通项较复杂，但结构简洁，尝试迭代计算几项观察周期规律，再用周期反推。  
**步骤**：  
由 $a_8=2$，令 $n=7$ 得 $a_8=\frac{1}{1-a_7} \Rightarrow 2=\frac{1}{1-a_7} \Rightarrow a_7=\frac12$。  
令 $n=6$：$a_7=\frac{1}{1-a_6} \Rightarrow \frac12=\frac{1}{1-a_6} \Rightarrow a_6=-1$。  
令 $n=5$：$a_6=\frac{1}{1-a_5} \Rightarrow -1=\frac{1}{1-a_5} \Rightarrow a_5=2$。
