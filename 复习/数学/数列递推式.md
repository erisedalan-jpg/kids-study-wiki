## 知识精要
- **数列递推式**：由初始项及相邻项的关系式确定数列各项。常见类型包括：
  - 一阶递推 $a_{n+1}=f(n)a_n+g(n)$：可用累加、累乘或构造等差/等比数列。
  - 含前 $n$ 项和 $S_n$ 的递推：利用 $a_n = \begin{cases} S_1, & n=1 \\ S_n - S_{n-1}, & n \geq 2 \end{cases}$ 化为纯 $a_n$ 或 $S_n$ 的递推。
  - 含 $(-1)^n$ 的递推：区分奇偶项，分组消元或并项。
  - 分式递推 $a_{n+1}=\frac{1}{1-a_n}$ 型：通常具有周期性，周期为 $T=2,3,4$ 等。
- **核心方法**：
  - 构造等差/等比辅助数列（如设 $b_n=a_{n+1}-2a_n$ 或 $b_n=S_n-3^n$）。
  - 同除、取倒数等变形，化为 $\frac{1}{S_{n+1}}-\frac{1}{S_n}=d$ 等差结构。
  - 分组求和、并项求和、错位相减法、累加（乘）法。

## 解题方法与套路
1. **消 $S_n$ 或 $a_n$**：若递推式中同时出现 $a_n$ 与 $S_n$，优先用 $a_{n+1}=S_{n+1}-S_n$（$n\geq 2$）替换，得到单一数列的递推，并注意 $n=1$ 的验证。
2. **构造辅助数列**：形如 $a_{n+1}=pa_n+q$ 可通过待定系数变为 $a_{n+1}+\lambda = p(a_n+\lambda)$；形如 $a_{n+1}=a_n+f(n)$ 直接累加；形如 $a_{n+1}=g(n)a_n$ 累乘；含 $S_n$ 与积 的递推常用取倒数或除以积化为等差数列。
3. **奇偶分类与并项**：递推式中出现 $(-1)^n$ 时，对 $n$ 分奇偶写出两式，相加减消去交替项，或将连续几项组合成定值，用于求和。
4. **周期规律寻找**：对分式迭代或给定的递推，从初始项顺推/逆推几项，发现周期 $T$ 后直接由 $a_n = a_{n \bmod T}$ 求特定项或分组求和。
5. **数列求和**：错位相减法用于 $\{ n \cdot q^n \}$ 型；分组求和用于周期数列或奇偶项规律不同；并项求和用于相邻项和为定值或简单式子。

## 高频易错
- 使用 $a_n=S_n-S_{n-1}$ 时忽略 $n\geq 2$，未单独检验 $n=1$，导致初始项不匹配。
- 构造辅助数列时系数配凑错误，如 $a_{n+1}-2a_n = 2(a_n-2a_{n-1})$ 中比例不统一。
- 处理 $(-1)^n$ 递推时，奇数项和偶数项递推式搞反，求和时分组项数计算错误。
- 错位相减时对齐错位、漏乘公比或漏掉最后一项，以及未讨论公比 $q=1$ 的特殊情况。
- 取倒数时未考虑分母为零（如 $S_n=0$）的可能性，导致漏解或变形不合法。
- 周期数列逆推求项时自大到小递推关系写错，导致循环节错误。

### 2015-理-16
**题目**：数列 $\{a_n\}$ 满足 $a_1=-1$，$a_{n+1}=S_{n+1}S_n$，求 $S_n$。
**思路**：递推式含 $a_{n+1}$, $S_{n+1}$, $S_n$，利用 $a_{n+1}=S_{n+1}-S_n$ 消去 $a_{n+1}$，得 $S_{n+1}-S_n=S_{n+1}S_n$。因 $S_n\neq 0$，两边同除以 $S_{n+1}S_n$ 构造等差数列。
**步骤**：
1. 由定义 $S_{n+1}-S_n=a_{n+1}$，代入条件得 $S_{n+1}-S_n=S_{n+1}S_n$。
2. 显然 $S_n \neq 0$，两边同除 $S_{n+1}S_n$：$\frac{1}{S_n} - \frac{1}{S_{n+1}} = 1$，即 $\frac{1}{S_{n+1}} - \frac{1}{S_n} = -1$。
3. 数列 $\{\frac{1}{S_n}\}$ 是首项 $\frac{1}{S_1}=\frac{1}{a_1}=-1$，公差 $-1$ 的等差数列。
4. 所以 $\frac{1}{S_n} = -1 + (n-1)(-1) = -n$，得 $S_n = -\frac{1}{n}$。

**点评/变式**：关键是转化出 $\frac{1}{S_{n+1}}-\frac{1}{S_n}$ 的形式。类似 $a_{n+1}=S_nS_{n+2}$ 可结合 $a_{n+1}=S_{n+1}-S_n$，$a_{n+2}=S_{n+2}-S_{n+1}$ 处理。
