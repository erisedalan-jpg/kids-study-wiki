## 知识精要
**数据分析**是运用统计图表和数字特征对数据进行描述、推断，进而作出决策的统计分支。高考主要考查从图表中读取信息、计算数字特征及解读数据意义的能力。

- **常用统计图表**
    - **柱形图（条形图）**：用宽度相同的条形的高度或长短表示数据变动趋势，适合比较不同类别或时间点的数值。
    - **频率分布直方图**：以面积表示频率，用于展示连续型数据的分布。
    - **茎叶图**：保留原始数据，便于观察分布、集中趋势和计算中位数等数字特征。中间为“茎”，两侧为“叶”。
- **核心数字特征**
    - **中位数**：将数据从小到大排序后，位于中间位置的数。偶数个数据时，通常取中间两数的平均数。
    - **众数**：出现次数最多的数据。
    - **平均数**：$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$。
    - **方差与标准差**：衡量数据的离散程度。方差 $s^2 = \frac{1}{n}\sum_{i=1}^{n} (x_i - \bar{x})^2$。
- **统计推断**
    - **用样本估计总体**：样本的数字特征（中位数、平均数等）是总体特征的近似。
    - **相关性**：两个变量间若一个变大另一个也变大，称正相关；若一个变大另一个变小，称负相关。
    - **事件概率的估计**：$P = \frac{\text{频数}}{\text{样本容量}}$。

## 解题方法与套路
1. **图表信息提取**  
   明确图表的横轴、纵轴含义（例如年份与排放量、评分与人次）。对柱形图，关注柱高所代表的数值及其变化趋势；对茎叶图，注意数据排列方式和重复次数。
2. **数字特征的快速计算**  
   - **茎叶图中位数**：将所有“叶”按茎分组展开成升序排列，数出总个数，若为奇数则取正中间值；若为偶数则取中间两个数的平均。  
   - **概率估计**：统计满足条件的个体数目，除以样本总数。频率直方图中，概率对应矩形面积。
3. **趋势与相关性判定**  
   随着时间推移，柱高持续上升为正相关，持续下降为负相关。注意局部波动（如先升后降）与整体趋势的区别。
4. **评价与决策**  
   结合图表和数据特征（如平均水平、稳定性）给出合理结论。可比较集中程度、离散程度、高低水平等。

## 高频易错
- **混淆正相关与负相关**：看到数值逐年下降，错误判断为正相关。正相关要求同向变化，下降趋势应为负相关。
- **中位数确定不准确**：茎叶图中忘记将数据从小到大排序，直接取中间叶子；或当数据个数为偶数时，未取两数的平均。
- **概率估计用错分母**：将“高于90分的概率”误算为用所有可能评分等级，而非总人数；或忽略“估计”二字，以为必须精确。
- **趋势概括不严谨**：忽视某些年份的异常波动，导致整体趋势判断错误（如2004-2006年排放上升，2006年以后下降，不能简单说“一直减少”）。
- **单位或刻度忽略**：柱形图纵轴单位、茎叶图的“茎”代表数量级未注意，导致数据读错。

## 代表题精讲
### 1. 2015-理-03 柱形图趋势判断
**题目**  
给出一幅2004-2013年我国二氧化硫年排放量柱形图，判断四个结论中哪个不正确，涉及减排效果最显著的年份、治理显现成效的年份、排放趋势及相关性。

**思路**  
逐项对照柱形图：A项看相邻两年下降幅度最大的年份；B项分析排放量开始减少的转折点；C项验证2006年后的整体方向；D项辨别2006年后排放量与年份是正相关还是负相关。

**步骤**  
- 阅读图表：横轴为年份，纵轴为排放量（万吨）。2004-2006年柱高上升，2007年后基本下降，2008年较2007年降幅最明显。  
- A：2007至2008年落差最大，效果最显著 → 正确。  
- B：2007年排放量开始下降，说明治理显现成效 → 正确。  
- C：2006年后柱高逐年降低 → 呈减少趋势 → 正确。  
- D：2006年后排放量下降，则排放量与年份一个降一个增，为负相关，而非正相关 → 错误。  
故选D。

**点评/变式**  
读图时注意区分“逐年比较”与“整体趋势”，正相关要求学生明确两个变量的变化方向一致。变式可能给出折线图或双柱形图，考查相关性、极值点、变化率等。

### 2. 2014-文-19 茎叶图与评价
**题目**  
给出50位市民对甲、乙两部门评分的茎叶图，求：（Ⅰ）两部门评分中位数的估计值；（Ⅱ）评分高于90的概率的估计；（Ⅲ）根据茎叶图分析市民对两部门的评价。

**思路**  
（Ⅰ）将两部门的茎叶数据分别按顺序列出，找到第25和26个数据的值并取平均；（Ⅱ）分别统计两部门评分大于90的个数，除以50；（Ⅲ）结合中位数、分布形状、集中程度、高分数量等进行对比。

**步骤**  
- （Ⅰ）整理甲部门茎叶数据，排序后第25、26位分别为75,75 → 中位数75。乙部门第25、26位分别为66,68 → 中位数 $\frac{66+68}{2} = 67$。  
- （Ⅱ）甲部门评分高于90的频数：茎9叶为5,8 → 2个，茎10叶为0 → 1个，共3个，概率估计 $P = \frac{3}{50} = 0.06$。乙部门高于90的频数：茎9叶为6,7,8,9 → 4个，茎10叶1,2,3,4,5,6,7,8,9 → 9个，共13个，概率 $P = \frac{13}{50} = 0.26$。  
- （Ⅲ）评价：甲部门评分的中位数更高，数据多集中在70-80分段，说明市民对甲评价较好且较一致；乙部门评分中位数低，分布较分散，但高于90的高分比例较大，说明有部分市民极其满意，但整体评价差异大。

**点评/变式**  
茎叶图中的中位数计算必须先还原全部数据并排序，不可疏忽。评价类问题需从集中趋势（中位数/平均数）和离散程度（方差/极差）及极端值多角度回答。变式可让计算平均数或方差，再比较两部门。
