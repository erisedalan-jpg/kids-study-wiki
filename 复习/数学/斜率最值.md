## 知识精要
1.  **抛物线的标准方程与几何意义**：对于抛物线 $y^2 = 2px (p>0)$，焦点 $F(\frac{p}{2}, 0)$，准线 $x = -\frac{p}{2}$。焦点到准线的距离即为 $p$。
2.  **向量条件的坐标转化**：共线或线段比例关系（如 $\overrightarrow{PQ} = \lambda \overrightarrow{QF}$）是建立点坐标之间等量关系的关键桥梁。需熟练进行向量的坐标运算，将几何关系代数化。
3.  **斜率最值的求解路径**：解析几何中的最值问题，核心是将目标量（如斜率 $k$）表示为某个变量的函数。常用的函数模型有：
    -   **二次分式型**：如 $k = \frac{y}{x}$，通过消元转化为 $f(t) = \frac{t}{at^2+b}$ 型，分子分母同除以 $t$（或使用判别式法），换元后利用基本不等式求最值。本题即为此模型。
    -   **其它函数模型**：包括二次函数、对勾函数等。

## 解题方法与套路
**通用解法：变量引参→方程转化→函数建模→最值求解**

1.  **设点引参，减少变量**：根据点在抛物线上，引入单参数表示动点坐标。如设 $P(\frac{y_0^2}{4}, y_0)$，既满足曲线方程，又减少变量。
2.  **转化条件，建立联系**：分析题目条件（如向量关系 $\overrightarrow{PQ}=9\overrightarrow{QF}$），明确各点坐标间的线性关系。利用向量相等，列出方程组，用参数表示出目标点 $Q$ 的坐标 $(x_Q, y_Q)$。
3.  **联立方程，表示目标**：直接写出目标量的表达式。对于斜率 $k_{OQ} = \frac{y_Q}{x_Q}$，将上一步求得的坐标代入，转化为只含单一参数 $y_0$ 的函数表达式。
4.  **求最值，注意取等条件**：对得出的分式函数（常为 $\frac{y_0}{a y_0^2 + b}$ 型）求最值。基本步骤为：
    -   对 $y_0=0$ 的情况单独讨论。
    -   当 $y_0 \neq 0$ 时，分子分母同除以 $y_0$，分母转化为关于 $y_0 + \frac{c}{y_0}$ 的表达式。
    -   灵活运用基本不等式（或对勾函数单调性）求解，必须验证并注明取等条件。

## 高频易错
1.  **参数 $p$ 的误读**：混淆 “焦点到准线的距离 $p$” 与 “焦点到原点的距离 $\frac{p}{2}$”，导致抛物线方程求错，满盘皆输。务必牢记 $p$ 的几何意义。
2.  **向量坐标运算的符号错误**：在进行 $\overrightarrow{PQ} = \lambda \overrightarrow{QF}$ 这类向量运算时，极易写错点的对应坐标。如将 $\overrightarrow{PQ}$ 错误计算为 $(x_Q - x_P, y_Q - y_P)$ 或是顺序颠倒。应严格使用“终点坐标减起点坐标”。
3.  **忽略定义域或变量讨论**：在求分式函数最值时，机械地分子分母同除以 $y_0$，却忽略了 $y_0 = 0$ 的情况。尽管本题中 $y_0=0$ 时斜率为 0 不是最大值，但这是严谨性的体现，若不讨论可能扣步骤分。
4.  **取等条件与点的存在性脱节**：用基本不等式求最值时，算出了最值却未写出此时参数 $y_0$ 的具体值，或该值导致点 $P$ 不存在或不在抛物线上。必须验证取等条件与已知条件是否兼容。

## 代表题精讲
**题目**：已知抛物线 $C: y^2=2px(p>0)$ 的焦点 $F$ 到准线的距离为 2。（1）求 $C$ 的方程；（2）原点为 $O$，点 $P$ 在 $C$ 上，点 $Q$ 满足 $\overrightarrow{PQ}=9\overrightarrow{QF}$，求直线 $OQ$ 斜率的最大值。
**思路**：第（2）问核心是构建 $k_{OQ}$ 关于单变量的函数。设出动点 $P$ 的坐标，以参数 $y_0$ 表示。利用向量关系解出 $Q$ 坐标，从而将 $k_{OQ}$ 表示为 $y_0$ 的函数，最后用基本不等式求该函数的最大值。
**步骤**：
1.  **求解抛物线方程**：由焦点到准线距离 $p=2$，直接得方程 $y^2=4x$。
2.  **设点与转化向量关系**：设 $P(\frac{y_0^2}{4}, y_0)$，$Q(x_Q, y_Q)$，已知 $F(1,0)$。由 $\overrightarrow{PQ}=9\overrightarrow{QF}$ 得：$(x_Q - \frac{y_0^2}{4}, y_Q - y_0) = 9(1 - x_Q, 0 - y_Q)$。
3.  **解出 $Q$ 点坐标**：由方程组：
    $$
    \begin{cases}
    x_Q - \frac{y_0^2}{4} = 9(1 - x_Q) \\
    y_Q - y_0 = 9(0 - y_Q)
    \end{cases}
    $$
    解得 $x_Q = \frac{9 + \frac{y_0^2}{4}}{10}$，$y_Q = \frac{y_0}{10}$。
4.  **建立斜率函数模型**：直线 $OQ$ 的斜率 $k = \frac{y_Q}{x_Q} = \frac{\frac{y_0}{10}}{\frac{36 + y_0^2}{40}} = \frac{y_0}{\frac{36 + y_0^2}{4}} = \frac{4y_0}{y_0^2 + 36}$。
5.  **分情况讨论并求最值**：
    -   当 $y_0 = 0$ 时，$k = 0$；
    -   当 $y_0 > 0$ 时，$k = \frac{4}{y_0 + \frac{36}{y_0}} \le \frac{4}{2\sqrt{y_0 \cdot \frac{36}{y_0}}} = \frac{4}{12} = \frac{1}{3}$，取等当 $y_0 = 6$；
    -   当 $y_0 < 0$ 时，由对称性 $k < 0$；
    综上，斜率最大值为 $\frac{1}{3}$。
**点评/变式**：此题是“动点+向量关系+斜率最值”的经典范式。关键在于利用向量关系作为纽带，将目标斜率与已知曲线上的动点坐标统一起来。**变式**：若将向量条件改为“点 $Q$ 在线段 $PF$ 上，且 $|PQ|:|QF|=9:1$”，或改为求 $k_{PQ}$ 的最值，解法内核不变，仍为设参消元建立函数模型。
