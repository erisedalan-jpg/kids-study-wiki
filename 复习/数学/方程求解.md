## 知识精要
- 方程求解的核心：根据题设条件，利用代数、几何中的等量关系建立关于未知数的方程（组），通过消元、化简求得未知数，并代回验证。
- 等比数列相关公式：通项 $a_n = a_1 q^{n-1}$，前 $n$ 项和 $S_n = \frac{a_1(1-q^n)}{1-q}\ (q \neq 1)$。若 $q=1$ 则 $S_n = na_1$。
- 等差数列相关公式：通项 $a_n = a_1 + (n-1)d$，前 $n$ 项和 $S_n = \frac{n(a_1+a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$。
- 解析几何参数方程：抛物线 $y^2=2px$ 焦点坐标 $(\frac{p}{2},0)$；椭圆 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$ 焦点坐标 $(\pm c,0)$，其中 $c^2 = a^2 - b^2$。
- 适用条件：等比数列 $q \neq 0$；使用求和公式需注意 $q \neq 1$；椭圆中 $a > b > 0$，$p > 0$ 等。

## 解题方法与套路
1. **确定未知量与方程类型**：分清待求量（如首项、公比、公差、参数 $p$ 等），联想与之相关的定义公式或几何性质。
2. **构造方程（组）**：利用题目给出的和、差、特定项关系、焦点相同等条件直接翻译成等式。等比数列优先考虑首项 $a_1$ 与公比 $q$；等差数列优先考虑首项 $a_1$ 与公差 $d$；圆锥曲线用标准方程中的参数。
3. **化简与求解**：
   - 等比数列：一般通过两式相除消去 $a_1$，得到关于 $q$ 的方程，解出 $q$，再代回求 $a_1$。注意变形时 $a_1 \neq 0$。
   - 等差数列：通常是一次方程，直接代入化简求 $d$。
   - 解析几何：根据焦点或半轴关系建立关于 $p$ 的二次方程，可用因式分解或检验排除法。
4. **检验解的合理性**：代回原条件验证，尤其是等比数列公比 $q=1$ 是否为增根；参数的合法范围（如 $p>0$，$q \neq 0$ 等）。

## 高频易错
- **等比数列忽视 $q=1$ 的情况**：使用求和公式 $\frac{a_1(1-q^n)}{1-q}$ 时，须先排除或检验 $q=1$，否则分母为零导致错误。
- **方程列错**：混淆等差数列与等比数列的通项、求和公式；将 $a_2 - a_5$ 误写成 $a_2 + a_5$；焦点坐标中 $p$ 与 $c$ 的对应关系搞反（抛物线焦点 $(\frac{p}{2},0)$，椭圆中 $c^2 = a^2 - b^2$ 而不是 $a^2 + b^2$）。
- **计算失误**：解方程组时变形不严谨（如两边约去含未知量的因式，忽略该因式可能为零）；公比 $q$ 求出后忘记求 $a_1$ 或 $a_6$。
- **单位与定义域**：实际问题中项数、环数等为正整数，解出的值须符合实际意义；等比数列公比 $q=0$ 舍去。
- **符号错误**：已知 $a_1 = -2$ 时，代入通项需注意符号，如 $a_2 = -2 + d$ 等。

## 代表题精讲
### 代表题1：2022年文科第10题（等比数列求指定项）
**题目**：等比数列 $\{a_n\}$ 的前3项和为168，$a_2 - a_5 = 42$，求 $a_6$。

**思路**：设首项 $a_1$ 和公比 $q\ (q \neq 0)$。由 $q=1$ 时 $a_2-a_5=0$ 排除 $q=1$。根据前3项和及 $a_2-a_5$ 列出方程组，消元求 $q$，再得 $a_1$，最后用通项求 $a_6$。

**步骤**：
1. 设公比为 $q$，$q \neq 0$。若 $q=1$，则 $a_2 = a_5$，给出 $a_2 - a_5 = 0 \neq 42$，故 $q \neq 1$。
2. 由条件得：
   $$S_3 = \frac{a_1(1-q^3)}{1-q} = 168 \quad\text{①}$$
   $$a_2 - a_5 = a_1 q - a_1 q^4 = a_1 q(1 - q^3) = 42 \quad\text{②}$$
3. ①式除以②式（$a_1 \neq 0, 1-q^3 \neq 0$）：
   $$\frac{S_3}{a_2 - a_5} = \frac{ \frac{a_1(1-q^3)}{1-q} }{ a_1 q(1-q^3) } = \frac{1}{q(1-q)} = \frac{168}{42} = 4$$
   得 $q(1-q) = \frac{1}{4}$，即 $4q^2 - 4q + 1 = 0$，解得 $q = \frac{1}{2}$。
4. 将 $q = \frac{1}{2}$ 代入②：$a_1 \cdot \frac{1}{2} \left(1 - \frac{1}{8}\right) = 42$，求得 $a_1 = 96$。
5. 计算 $a_6 = a_1 q^5 = 96 \times \left(\frac{1}{2}\right)^5 = 3$。

**点评/变式**：本题关键在于通过比值消去 $a_1$ 获得关于 $q$ 的方程，简化运算。若能直接观察出 $S_3 = a_1 + a_2 + a_3$ 与 $a_2-a_5$ 的形式，也可用 $a_1(1+q+q^2)=168$ 与 $a_1 q(1-q^3)=42$ 联立。变式：若将条件改为“前3项和”与“$a_3-a_6$”，方法相同，注意分解 $1-q^3=(1-q)(1+q+q^2)$。

### 代表题2：2020年文科第14题（等差数列求和）
**题目**：记 $S_n$ 为等差数列 $\{a_n\}$ 的前 $n$ 项和。已知 $a_1 = -2$，$a_2 + a_6 = 2$，求 $S_{10}$。

**思路**：设公差 $d$，利用等差数列通项将 $a_2 + a_6$ 转化为关于 $d$ 的一次方程，解出 $d$，再代入前 $n$ 项和公式求 $S_{10}$。

**步骤**：
1. 设公差为 $d$，则 $a_2 = a_1 + d = -2 + d$，$a_6 = a_1 + 5d = -2 + 5d$。
2. 由 $a_2 + a_6 = 2$ 得：$(-2+d) + (-2+5d) = 2$，即 $6d - 4 = 2$，解得 $d = 1$。
3. 利用求和公式：
   $$S_{10} = 10a_1 + \frac{10 \times 9}{2}d = 10 \times (-2) + 45 \times 1 = -20 + 45 = 25.$$

**点评/变式**：本题为一次方程，计算量小。易错点在于下标推算错误：$a_6 = a_1+5d$，而非加6d。类似题常通过给定两项和求公差，注意符号处理。变式：改为等比数列，给定 $a_2+a_6$ 的等式，则需解高次方程或整体代换。
