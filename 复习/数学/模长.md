## 知识精要
- **复数模长定义**：复数 $z = a + bi$（$a, b \in \mathbb{R}$，$i$ 为虚数单位）的模长 $|z|$ 表示复平面上对应点 $Z(a,b)$ 到原点的距离。
- **计算公式**：$$|z| = |a+bi| = \sqrt{a^2 + b^2}$$
- **本质联系**：$|z| = \sqrt{z \cdot \overline{z}}$，其中 $\overline{z}=a-bi$ 为共轭复数。
- **适用条件**：对任意复数 $a+bi$ 直接适用，实数可视为虚部为零的特殊复数。

## 解题方法与套路
1. **识别形式**：将复数化为标准代数形式 $a+bi$，若题干给出运算形如 $z = c + di$（$c,d$ 可能含负号或运算），先整理实部与虚部。
2. **提取实虚**：准确读出实部 $a$ 与虚部 $b$（含符号），特别注意虚部是 $i$ 的系数，不包含 $i$。
3. **代入公式**：直接计算 $|z| = \sqrt{a^2 + b^2}$，注意平方运算会消除符号，最终结果为非负实数。
4. **化简结果**：若平方和为完全平方数则开尽，否则保留根号或化为最简根式。

## 高频易错
- 忘记模长公式中的平方再开方，误写成 $|z| = a + b$ 或 $|z| = \sqrt{a+b}$。
- 忽略虚部的符号：$|a-bi| = \sqrt{a^2+(-b)^2} = \sqrt{a^2+b^2}$，模长与虚部符号无关，但计算时必须用原系数平方。
- 将模长与共轭复数混淆：模长是实数，共轭是复数；求 $|z|$ 不能写成 $a-bi$。
- 根式化简不规范：例如 $\sqrt{2}$ 保留即可，不用近似，若题目为选择题要核对选项的根号形式。

## 代表题精讲
**题目**（2024·新课标Ⅱ·1）已知 $z = -1 - i$，则 $|z| =$  
A. $0$　B. $1$　C. $\sqrt{2}$　D. $2$

**思路**  
复数已给出标准代数形式，实部 $a=-1$，虚部 $b=-1$，直接使用模长公式 $\sqrt{a^2+b^2}$ 求值。

**步骤**  
由 $z=-1-i$，得 $a=-1, b=-1$。  
$|z| = \sqrt{(-1)^2 + (-1)^2} = \sqrt{1+1} = \sqrt{2}$。  
对应选项 C。

**点评/变式**  
- 此题属于复数模长最基础的直接计算，属于送分题，必须秒杀。  
- 注意符号陷阱：即使写成 $z = -1 - i$，平方后符号消失，模长恒为正实数。  
- 变式：若 $z = 2 - i$，则 $|z| = \sqrt{5}$；若 $z = \frac{1}{1+i}$，先化简为 $\frac{1-i}{2} = \frac12 - \frac12 i$，再求模长为 $\frac{\sqrt{2}}{2}$，核心步骤仍是先化为 $a+bi$ 形式。
