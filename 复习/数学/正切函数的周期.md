## 知识精要
- **正切型函数的周期**：函数 $y = \tan(\omega x + \varphi)$（$\omega > 0$）的最小正周期为 $T = \frac{\pi}{\omega}$。注意分母是 $\omega$，不是 $2\omega$，这是正切与正弦/余弦周期公式的根本区别。
- **图像平移规律**：$y = \tan(\omega x + \varphi)$ 向右平移 $a$ 个单位后，解析式变为 $y = \tan\big[\omega(x - a) + \varphi\big] = \tan(\omega x - \omega a + \varphi)$（左加右减，且 $\omega$ 要乘进平移量）。
- **两正切型函数图像重合的充要条件**：若 $y = \tan(\omega x + \varphi_1)$ 与 $y = \tan(\omega x + \varphi_2)$ 的图像重合（$\omega$ 相同），则 $\varphi_1 - \varphi_2 = k\pi$，$k \in \mathbb{Z}$。本质是相差整数个周期，因为 $\tan\theta$ 的周期是 $\pi$，相位差为 $\pi$ 的整数倍时图像完全一致。

## 解题方法与套路
1. **写出平移后的解析式**  
   根据“左加右减”将平移量代入，注意将系数 $\omega$ 提出，得到形如 $\tan(\omega x + \text{新常数})$ 的表达式。
2. **利用图像重合建立等式**  
   令平移后的函数与目标函数相等，由正切函数的周期性得到一般关系：  
   $\tan(\omega x + \alpha) = \tan(\omega x + \beta) \quad \Rightarrow \quad \alpha = \beta + k\pi\ (k \in \mathbb{Z})$。  
   注意是 $k\pi$，不是 $2k\pi$。
3. **解出参数并讨论整数 $k$**  
   从等式中解出所求参数（常为 $\omega$）关于 $k$ 的表达式，结合题目给定的范围（如 $\omega > 0$）和“最小值”等要求，确定 $k$ 的取值，得到最终答案。
4. **（通用思维）正切类问题优先考虑周期性和相位差的周期性，少用诱导公式强行变换，直接比较相位最高效。**

## 高频易错
- **平移方向反用**：向右平移是 $x$ 减去平移量，误写成 $x + \text{平移量}$ 会导致全盘皆输。
- **周期记错**：正切周期是 $\frac{\pi}{\omega}$，在重合条件中错误地加上 $2k\pi$ 而不是 $k\pi$。
- **漏乘系数**：平移时只将 $x$ 加减，忘记乘 $\omega$，如 $y=\tan(\omega x + \varphi)$ 向右平移 $a$ 单位，错写成 $\tan(\omega x + \varphi - a)$，正确应为 $\tan(\omega x - \omega a + \varphi)$。
- **整数 $k$ 的取值粗心**：求出 $\omega = f(k)$ 后，盲目取 $k=0$，忽略 $\omega>0$ 或“最小正值”可能对应 $k=1$ 或 $k=-1$ 等情况，需结合不等式精细判断。
- **误用正弦型重合条件**：正弦/余弦图像重合需相差 $2k\pi$，与正切的 $k\pi$ 混用，是失分重灾区。

## 代表题精讲
**题目**（2009全国文·9）  
将函数 $y = \tan\left(\omega x + \frac{\pi}{4}\right)$（$\omega > 0$）的图像向右平移 $\frac{\pi}{6}$ 个单位长度后，与函数 $y = \tan\left(\omega x + \frac{\pi}{6}\right)$ 的图像重合，求 $\omega$ 的最小值。

**思路**  
先由平移规则写出新函数解析式，再利用正切函数图像重合的充要条件（相位相差 $k\pi$）建立等式，解出 $\omega$ 关于整数 $k$ 的表达式，结合 $\omega>0$ 求最小正值。

**步骤**  
1. 写出平移后的函数：  
   $y = \tan\left[\omega\left(x - \frac{\pi}{6}\right) + \frac{\pi}{4}\right] = \tan\left(\omega x - \frac{\omega\pi}{6} + \frac{\pi}{4}\right)$。  
2. 令其与目标函数重合：  
   $\tan\left(\omega x - \frac{\omega\pi}{6} + \frac{\pi}{4}\right) = \tan\left(\omega x + \frac{\pi}{6}\right)$。  
   由正切图像重合条件得：  
   $-\frac{\omega\pi}{6} + \frac{\pi}{4} = \frac{\pi}{6} + k\pi$，$k \in \mathbb{Z}$。  
3. 化简等式：  
   $-\frac{\omega\pi}{6} = \frac{\pi}{6} - \frac{\pi}{4} + k\pi = -\frac{\pi}{12} + k\pi$，  
   两边乘 $-\frac{6}{\pi}$：$\omega = \frac{1}{2} - 6k$。  
4. 求 $\omega>0$ 的最小值：  
   当 $k=0$ 时，$\omega = \frac{1}{2} > 0$；$k$ 取负整数会使 $\omega$ 更大，取正整数 $\omega$ 为负。故最小值为 $\frac{1}{2}$。  

**点评/变式**  
- **点评**：本题紧扣正切周期 $T=\pi/\omega$，图像重合本质是相位差为 $\pi$ 的整数倍，无需考虑定义域限制。易错点在于将 $k\pi$ 写成 $2k\pi$，或平移时漏乘 $\omega$。  
- **变式**：若将题中“向右平移 $\frac{\pi}{6}$”改为“向左平移 $\frac{\pi}{6}$”，则等式变为 $\frac{\omega\pi}{6} + \frac{\pi}{4} = \frac{\pi}{6} + k\pi$，可得 $\omega = 6k - \frac{1}{2}$，$\omega>0$ 的最小值为 $k=1$ 时的 $\frac{11}{2}$。  
- **延伸**：若目标函数改为 $y = \tan\left(2\omega x + \frac{\pi}{6}\right)$（$\omega$ 不同），则无法仅用相位差表达，需考虑周期变化，一般不直接命制此类题。
