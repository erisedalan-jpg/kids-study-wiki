## 知识精要
- **正弦函数的图象**：$y=\sin x$ 的图象是一条波浪线，定义域 $\mathbb{R}$，值域 $[-1,1]$，以 $2\pi$ 为最小正周期，是奇函数，关于原点对称。
- **五点作图法**：取 $x=0,\frac{\pi}{2},\pi,\frac{3\pi}{2},2\pi$，对应 $y=0,1,0,-1,0$，可快速描出基本波形。
- **与余弦函数的关系**：$\cos x = \sin\!\left(x+\frac{\pi}{2}\right)$，两图象形状相同，仅相位差 $\frac{\pi}{2}$。$y=\sin x$ 与 $y=\cos x$ 的图象交点满足 $\sin x = \cos x$，即 $x=\frac{\pi}{4}+k\pi$。
- **两函数图象竖直距离**：对同一 $x=a$，函数 $f(x)$ 与 $g(x)$ 的图象上两点 $M(a,f(a))$、$N(a,g(a))$，其距离 $|MN|=|f(a)-g(a)|$。
- **辅助角公式**：$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x+\varphi)$，其中 $\tan\varphi=\frac{b}{a}$。由此 $|\sin x - \cos x| = \sqrt{2}\left|\sin\!\left(x-\frac{\pi}{4}\right)\right|$，最大值为 $\sqrt{2}$。此公式是处理正弦、余弦线性组合的核心工具。

## 解题方法与套路
1. **化距离为函数差**：动直线 $x=a$ 与两函数图象交点间的竖直距离，就是两函数值之差的绝对值，即 $d(a)=|f(a)-g(a)|$。
2. **统一函数名**：遇到 $\sin x$ 与 $\cos x$ 的差或和，优先用辅助角公式合并为单一正弦（或余弦）型函数，如 $A\sin(x+\varphi)$。
3. **求最值**：对于 $|A\sin(x+\varphi)|$，最大值即为 $|A|$（若 $A>0$ 则直接取 $A$），利用正弦的有界性 $|\sin\theta|\le 1$。
4. **关注定义域**：若题目给出 $a$ 的取值范围，需在区间上求极值；若无限制，则直接取全局最大。

## 高频易错
- **忘记绝对值**：两点距离是非负的，构造差函数时必须加绝对值 $|f(x)-g(x)|$，否则可能只求差的最大值而漏掉最小值导致错误。
- **辅助角计算失误**：$\sin x - \cos x = \sqrt{2}\sin\!\left(x-\frac{\pi}{4}\right)$，而非 $\sqrt{2}\sin\!\left(x+\frac{\pi}{4}\right)$，注意符号与辅助角 $\varphi$ 的象限。可代入特殊点检验。
- **混淆横纵距离**：动直线 $x=a$ 给出的两点 $M,N$ 横坐标相同，距离为纵坐标之差，不是横坐标之差，也不是两点间欧氏距离。
- **忽略选项特征**：当选项中出现 $\sqrt{2}$、$2$ 等值，应联想到 $\sin x \pm \cos x$ 的振幅为 $\sqrt{2}$，直接锁定答案，避免复杂计算。

## 代表题精讲
**题目**（2008 全国卷理 8）：动直线 $x=a$ 与 $f(x)=\sin x$ 和 $g(x)=\cos x$ 的图象分别交于 $M,N$ 两点，求 $|MN|$ 的最大值。  
**思路**：同一直线 $x=a$ 与两函数交点的距离即 $|\sin a - \cos a|$，化为 $A\sin(a+\varphi)$ 的形式求最值。  
**步骤**：
1. 由题意，$M(a,\sin a)$，$N(a,\cos a)$，故 $|MN| = |\sin a - \cos a|$。
2. 利用辅助角公式：$\sin a - \cos a = \sqrt{2}\sin\!\left(a - \frac{\pi}{4}\right)$。
3. 所以 $|MN| = \sqrt{2}\left|\sin\!\left(a - \frac{\pi}{4}\right)\right|$。
4. 正弦函数绝对值最大为 $1$，因此 $|MN|_{\max} = \sqrt{2}$，对应选项 B。

**点评/变式**：本题本质是求同一自变量下两正弦型函数的差的最值，属基础题。变式可改为垂直于 $y$ 轴的交点距离、或求 $|\sin x + \sqrt{3}\cos x|$ 的最大值（合并后振幅为 $2$）、或限制 $a$ 在某个区间求最大值，只需结合单调性分析即可。
