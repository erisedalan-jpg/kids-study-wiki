## 知识精要
- 正方体体积公式：若棱长为 $a$，则体积 $V = a^3$。
- 正方体的体对角线长：$l = \sqrt{a^2 + a^2 + a^2} = \sqrt{3}a$。
- 正方体的外接球：正方体八个顶点均落在球面上，球心与正方体中心重合，外接球的直径 $2R$ 等于正方体的体对角线长，即 $2R = \sqrt{3}a$，外接球半径 $R = \frac{\sqrt{3}}{2}a$。
- 球的表面积公式：$S = 4\pi R^2$。

## 解题方法与套路
1. 已知正方体体积，直接由 $V = a^3$ 反解棱长 $a = \sqrt[3]{V}$。
2. 联想正方体与球的位置关系：顶点同在球面上 $\rightarrow$ 球为正方体的外接球。
3. 建立棱长 $a$ 与外接球半径 $R$ 的关系：$2R = \sqrt{3}a$，即 $R = \frac{\sqrt{3}}{2}a$。
4. 将 $R$ 代入球的表面积公式 $S = 4\pi R^2$ 计算，注意化简结果保留 $\pi$（高考选择题常见设置）。
5. 若问题改为内切球（$2R = a$）或与各棱相切的球（$2R = \sqrt{2}a$），对应半径关系随之切换，切忌混淆。

## 高频易错
- 体对角线公式记错：误记为 $\sqrt{2}a$（面对角线）或 $\sqrt{a^2 + a^2}$ 导致外接球半径算错。
- 半径与直径不分：体对角线长等于外接球的直径 $2R$，而非半径 $R$，计算表面积时忘记除以 $2$。
- 体积为 $8$ 时，棱长开立方易错算为 $a=2\sqrt{2}$，正确值为 $a=2$。
- 球的表面积系数 $4\pi R^2$ 与体积公式 $\frac{4}{3}\pi R^3$ 混淆。

## 代表题精讲
**题目**：体积为 $8$ 的正方体的顶点都在同一球面上，则该球面的表面积为____。（2016·全国卷·文）

**思路**：由正方体体积求棱长，由棱长得体对角线，体对角线即外接球直径，再求球半径代入表面积公式。

**步骤**：
正方体体积 $V = a^3 = 8$，解得棱长 $a = 2$。
体对角线长 $l = \sqrt{3}a = 2\sqrt{3}$。
因顶点均在同一球面上，该球为正方体的外接球，其直径 $2R = l = 2\sqrt{3}$，得半径 $R = \sqrt{3}$。
球的表面积 $S = 4\pi R^2 = 4\pi \times (\sqrt{3})^2 = 12\pi$。

**点评/变式**：
- 本题为核心套路题，关键点在于正方体结构特征的迁移。外接球、内切球、棱切球三者对应半径公式务必精准记忆。
- 变式：若原题改为“体积为 $8$ 的正方体的各面都与同一个球相切”，则该球为内切球，直径 $2R = a$，半径 $R = 1$，表面积 $S = 4\pi$；若改为“球与正方体的各条棱都相切”，则直径 $2R = \sqrt{2}a$，半径 $R = \sqrt{2}$，表面积 $S = 8\pi$。对比训练可强化空间想象与公式切换能力。
