## 知识精要
- 正方体的截面图形由截平面与正方体各面的交线围成，常见截面形状有三角形、四边形、五边形、六边形。
- 正方体被一个平面截去一部分后，剩余几何体的三视图可用来反推截面位置与被截部分形状。
- 正方体体积 $V = a^3$；三棱锥体积 $V_{\text{锥}} = \frac{1}{3} S_{\text{底}} h$。当截平面切过同一顶点处的三条棱时，截去的部分是一个底面为等腰直角三角形、高为棱长的三棱锥，其体积为 $\frac{1}{6}a^3$。
- 利用“长对正、高平齐、宽相等”原则，由三视图中的实线对角线可确定截面在各个面上的投影，从而定位截交线。

## 解题方法与套路
1. **定几何体**：明确原始几何体为正方体，并设棱长为 $1$ 或 $a$。
2. **读三视图**：抓住视图中出现的斜线（实线），这些斜线是截平面与对应侧面的交线在视图面上的投影。根据“长对正、高平齐、宽相等”推断截面的空间位置。
3. **还原截面**：结合三个视图中的对角线方向与位置，确定截平面切过了哪些棱、交点位置。常见的截角问题中，对角线端点与顶点重合，截平面切去一个三棱锥。
4. **求体积比**：计算截去部分的体积与剩余部分体积，然后求比值。通常截去部分是规则的三棱锥，可直接套用锥体体积公式。
5. **验证**：可将剩余部分体积与正方体体积相减，确保体积和等于正方体总体积，检验计算无误。

## 高频易错
- **视图中对角线的虚实辨析**：截交线在可见面上画实线，在不可见面画虚线。本题中三个视图中均为实线，说明截面与各投影面均可见，截去部分必为正方体的一个角，不可误判为内部孔洞。
- **体积比的对象弄反**：题目问“截去部分体积与剩余部分体积的比值”，切忌将剩余部分当成截去部分。可先求截去部分占整体的比例，再得比值。
- **棱锥高与底面的对应错误**：截去的三棱锥如果以截平面为底面计算体积相对复杂，应以原正方体的面为底面，棱为高，直接使用 $\frac{1}{3}\times(\frac{1}{2}a^2)\times a = \frac{a^3}{6}$。
- **忽略单位或设值不一般化**：解答时设棱长为 $1$ 或 $a$，比值与具体长度无关，但体积表达式需保持一致性，避免计算错误。

## 代表题精讲
**题目**  
一个正方体被一个平面截去一部分后，剩余部分的三视图均为正方形且内部含有一条由顶点引出的对角线（实线），求截去部分体积与剩余部分体积的比值。

**思路**  
由三视图三个正方形内均有对角实线可知，截平面切过了正方体的一个顶点，且与从该顶点出发的三条棱相交于另一侧面的顶点，截去的是一个底面为等腰直角三角形的三棱锥。通过计算该三棱锥体积与正方体体积，可得到所求比值。

**步骤**  
1. 设正方体棱长为 $a$，则正方体体积 $V_{\text{正}} = a^3$。  
2. 由三视图判断被截几何体：正视图、侧视图、俯视图中对角线均连接了正方形的两个相对顶点，且交于同一角，说明截平面经过正方体同一顶点发出的三条棱的端点，切去一个三棱锥。  
3. 该三棱锥的三条侧棱两两垂直，长度均为 $a$，可取其中一条棱为高，底面为两条互相垂直的棱构成的直角三角形。  
4. 计算三棱锥体积：底面积 $S = \frac{1}{2} a^2$，高 $h = a$，则 $V_{\text{截}} = \frac{1}{3} \times \frac{1}{2} a^2 \times a = \frac{a^3}{6}$。  
5. 剩余部分体积 $V_{\text{剩}} = V_{\text{正}} - V_{\text{截}} = a^3 - \frac{a^3}{6} = \frac{5a^3}{6}$。  
6. 所求比值 $V_{\text{截}} : V_{\text{剩}} = \frac{a^3}{6} : \frac{5a^3}{6} = 1:5$，即比值为 $\frac{1}{5}$。

**点评/变式**  
此题属于“三视图还原几何体”与“正方体截角”的综合，核心在于识图与体积公式的简单应用。变式可改为“已知一个正方体被一平面截去一角，剩余几何体的表面积与原正方体表面积之比”，此时需计算截面的面积（正三角形），训练视图还原后的几何体表面构成分析能力。
