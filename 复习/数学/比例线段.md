## 知识精要
- **平行线分线段成比例**：三条平行线截两条直线，所得对应线段成比例。这是建立比例式的基础。
- **相似三角形的性质**：对应角相等、对应边成比例；对应高的比等于相似比。在测量问题中常通过构造相似三角形将不可测的高度转化为水平距离的比。
- **基本测量模型**：利用两组垂直于水平面的标杆与视线构成相似三角形，通过两次观测的水平距离差（表目距的差）消去未知的水平距离，从而求得高度。关键关系：设岛高 $h$，表高 $t$，表距 $s$，前表目距 $a$，后表目距 $b$，则  
  $$h = t\left(1 + \frac{d}{a}\right) = t\left(1 + \frac{d + s}{b}\right)$$  
  消去 $d$ 得  
  $$h = \frac{t \cdot s}{b - a} + t$$

## 解题方法与套路
1. **还原几何图形**：根据题意画出水平线 $AC$ 以及垂直于 $AC$ 的标杆 $DE, FG$ 和被测物 $AB$，标出已知量（表高、表距、表目距）。
2. **确定相似三角形**：利用“视线—标杆顶端—目标顶端”共线，由 $AB \parallel DE \parallel FG$ 得到 $\triangle ABH \sim \triangle DEH$ 和 $\triangle ABC \sim \triangle FGC$。
3. **设未知量列比例式**：引入岛高 $h$ 和岛到前表水平距离 $d$，写出两组比例式：  
   $$\frac{h}{t} = \frac{d + a}{a}, \quad \frac{h}{t} = \frac{d + s + b}{b}$$
4. **联立消元**：从两式中消去 $d$，代入 $b-a = \Delta$（表目距的差）化简，得到 $h$ 的表达式。
5. **匹配选项**：整理成选项形式，确认常数项符号，选出正确答案。

## 高频易错
- **线段对应错位**：误把 $BH$ 写成 $d$ 而忽略 $EH$，或把 $BC$ 写成 $d+s$ 而漏掉 $GC$。务必根据人眼在标杆远离岛一侧的特点，准确写出 $BH = d + EH$、$BC = d + EG + GC$。
- **混淆表距与表目距**：表距 $EG$ 是两标杆间的水平距离；表目距 $EH, GC$ 是标杆到观测点的水平距离，两者功能不同，不可互换。
- **代数化简失误**：用 $b-a$ 代换时符号易错，合并项时需小心，确保最终得到 $h = \frac{t \cdot s}{\Delta} + t$，而非 $h = \frac{t \cdot s}{\Delta} - t$ 等形式。
- **忽视相似条件**：必须确认视线共线（$A,D,H$ 和 $A,F,C$）且标杆与目标均垂直于水平面，才能使用相似三角形，否则比例关系不成立。

## 代表题精讲
**题目**（2021·全国卷·理9）魏晋时刘徽《海岛算经》测海岛高：如图，$E,H,G$ 在水平线 $AC$ 上，$DE$ 与 $FG$ 是等高的“表高”，$EG$ 为“表距”，$GC$ 与 $EH$ 为“表目距”，其差称为“表目距的差”，则海岛高 $AB$ 的表达式为。  

**思路**：利用两次视线 $A-D-H$ 与 $A-F-C$ 构造两组相似三角形，分别建立岛高与水平距离的比例关系，再通过表目距的差消去未知距离，直接得到岛高公式。  

**步骤**  
1. **设元与标图**：设岛高 $AB = h$，表高 $DE = FG = t$，表距 $EG = s$，前表目距 $EH = a$，后表目距 $GC = b$，表目距的差 $\Delta = b - a$。令岛底 $B$ 到前表 $E$ 的距离 $BE = d$。由测量方式知 $H$ 在 $E$ 远离岛的一侧，$C$ 在 $G$ 远离岛的一侧，故  
   $BH = d + a$，$BC = d + s + b$。  
2. **列相似比例**：由 $AB \parallel DE \parallel FG$ 得  
   $$\triangle ABH \sim \triangle DEH \;\Rightarrow\; \frac{h}{t} = \frac{d + a}{a},$$  
   $$\triangle ABC \sim \triangle FGC \;\Rightarrow\; \frac{h}{t} = \frac{d + s + b}{b}.$$  
3. **消去 $d$**：由第一式得 $d = a\left(\frac{h}{t} - 1\right)$，代入第二式：
   $$\frac{h}{t} = \frac{a\left(\frac{h}{t} - 1\right) + s + b}{b}.$$  
   两边乘 $b$ 并展开：  
   $$b \cdot \frac{h}{t} = a \cdot \frac{h}{t} - a + s + b.$$  
   移项合并含 $\frac{h}{t}$ 的项：  
   $$(b - a)\frac{h}{t} = s + (b - a).$$  
4. **求解 $h$**：将 $b - a = \Delta$ 代入，得  
   $$\Delta \cdot \frac{h}{t} = s + \Delta \;\Rightarrow\; \frac{h}{t} = \frac{s}{\Delta} + 1 \;\Rightarrow\; h = \frac{t \cdot s}{\Delta} + t.$$  
   即海岛高 $=$ 表高 $\times$ 表距 $\div$ 表目距的差 $+$ 表高，对应选项 **A**。  

**点评/变式** 本题的关键在于准确写出 $BH$ 和 $BC$ 的表达式，消元时直接使用已知差 $\Delta$ 可使运算简洁。若将观测点移至标杆同侧或改变标杆高度，则相似三角形的对应边会发生变化，但整体消元思路不变。掌握这一推导方法，即可应对各类比例线段测量问题。
