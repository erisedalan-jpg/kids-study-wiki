## 知识精要

由 $a_{m+n}=a_m a_n$ 且 $a_1=2$，可推导 $\{a_n\}$ 为**等比数列**。

- 令 $m=1$：$a_{n+1}=a_n\cdot a_1=2a_n$，故 $\dfrac{a_{n+1}}{a_n}=2$，公比 $q=2$。
- 通项公式：$a_n = a_1 q^{\,n-1} = 2^n$。
- 前 $n$ 项和公式： $S_n = \dfrac{a_1(1-q^n)}{1-q} = 2^{n+1}-2 \quad (q\neq1)$。

**一般地**，等比数列 $\{a_n\}$ 中，若 $m+n=p+q$，则 $a_m a_n = a_p a_q$。此处条件升级为任意两项下标加法对应项的乘法，揭示**指数函数特征**：形如 $a_n = c\cdot q^{\,n}$ 可满足 $a_{m+n}=a_m a_n$（只需 $c^2 = c\cdot q$，验证可得 $c=q$ 或 $c=0$ 等特例）。

## 解题方法与套路

1. **由递推关系求通项**  
   若给出 $a_{m+n}=a_m a_n$，优先**赋值**（如令 $m=1$）转化为 $a_{n+1}=k a_n$，并检查首项得到等比数列。

2. **判定等比后直接写通项**  
   利用 $a_n = a_1 q^{n-1}$ 得到项的表达式，避免逐项推导。

3. **有限段求和的处理**  
   - 和 $a_{k+1}+a_{k+2}+\cdots+a_{N}$ 可用 $S_N - S_k$ 计算。
   - 或直接利用等比数列求和公式计算部分和：首项 $a_{k+1}$，公比 $q$，项数 $N-k$。
   - 将条件方程化为指数等式，利用同底数幂相等解出下标。

4. **指数方程的求解**  
   写入形如 $2^A - 2^B = 2^M - 2^N$，往往对应指数相等。注意检验**唯一性**。

## 高频易错

- **忽视项数计算**：从 $k+1$ 到 $N$ 共有 $N-k$ 项，而非 $N-k-1$ 或 $N-k+1$。
- **求和公式记混**：等比数列前 $n$ 项和分母为 $1-q$，注意首项和公比的幂次。$S_n = \dfrac{a_1(1-q^n)}{1-q}$ 而非 $q^n-1$ 直接倒置。
- **误用等差数列公式**：遇到和式先确认是等差还是等比，不可盲目套用。
- **指数运算出错**：$2^{k+1}+2^{k+2}+\cdots+2^{10} = 2^{k+1}(2^{10-k}-1)$ 时，括号内指数易算错。
- **忽略 $q=1$ 的讨论**：虽然本题公比为2，但养成习惯检查 $q=1$ 时公式退化为 $S_n = n a_1$，确保不失分。

## 代表题精讲

### 2020-理-06 等比定义与求和逆向求参

**题目**  
数列 $\{a_n\}$ 满足 $a_1=2$，$a_{m+n}=a_m a_n$。若 $a_{k+1}+a_{k+2}+\cdots+a_{10}=2^{11}-2^{5}$，求 $k$ 的值。

**思路**  
由乘积条件得等比，写出通项 $a_n=2^n$，将左边和式表示为 $S_{10}-S_k$ 或直接等比求和，化简为 $2^{11}-2^{k+1}$，与右边 $2^{11}-2^5$ 对比得出 $k$。

**步骤**  

1. 求通项：令 $m=1$，有 $a_{n+1}=a_n\cdot a_1 = 2a_n$，所以 $\{a_n\}$ 是首项 $2$、公比 $2$ 的等比数列，  
   因此 $a_n = 2\cdot 2^{\,n-1}=2^n$。

2. 计算部分和：  
   $$a_{k+1}+a_{k+2}+\cdots+a_{10} = S_{10} - S_k$$  
   前 $n$ 项和 $S_n = \dfrac{2(1-2^n)}{1-2}=2^{n+1}-2$。  
   则 $S_{10}=2^{11}-2$，$S_k=2^{k+1}-2$，  
   两者相减得 $(2^{11}-2)-(2^{k+1}-2) = 2^{11}-2^{k+1}$。

3. 建立等式并求解：  
   由题意 $2^{11}-2^{k+1}=2^{11}-2^{5}$，  
   所以 $2^{k+1}=2^5$，可得 $k+1=5$，即 $k=4$。

**点评**  
本题将**等比定义隐藏于抽象等式**，考查赋值意识与整体代换。求和时活用 $S_N-S_k$ 可避免复杂项数运算。  

**变式**  
若条件改为 $a_{k+1}+a_{k+2}+\cdots+a_{15}=2^{16}-2^{7}$，则 $2^{16}-2^{k+1}=2^{16}-2^{7}$ 推出 $k=6$（假设仍为同一数列）。  
进一步可设 $a_1=3$、$a_{m+n}=a_m a_n$，则公比为 $3$，和式变为 $3$ 的幂，方法完全相同。
