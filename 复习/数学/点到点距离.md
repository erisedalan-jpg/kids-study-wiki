## 知识精要
- **平面上两点距离公式**：点 $P_1(x_1,y_1)$，$P_2(x_2,y_2)$，则  
  $$|P_1P_2| = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$$
  本质是勾股定理的坐标化，可推广到空间（加上 $z$ 方向差的平方）。
- **适用条件**：已知两点坐标的直接度量；无论两点位置如何，公式均成立。
- **公式变形与联系**：  
  - 向量视角：若 $\overrightarrow{P_1P_2} = (a,b)$，则 $|P_1P_2| = \sqrt{a^2+b^2}$。  
  - 与中点、定比分点结合求距离：先求点坐标，再代入公式。  
  - 距离的平方常用于避免根号运算。
- **常见关联考点**：外接圆圆心（外心）的求法——三角形任意两边垂直平分线的交点；重心、垂心等特殊点的坐标公式。

## 解题方法与套路
1. **直接代公式**：当两点坐标明确给出时，准确代入 $x_1,y_1,x_2,y_2$，注意减法的顺序不影响平方结果，但建议保持统一格式。  
2. **间接求点**：若所求距离的一端点为未知（如圆心、重心等），先利用几何特征或代数条件求出该点坐标。  
   - 外心：求出两条边的中垂线方程，联立解交点，即为圆心坐标。  
   - 重心：三顶点坐标平均 $(\frac{x_A+x_B+x_C}{3}, \frac{y_A+y_B+y_C}{3})$。  
   - 垂心、内心等依题目条件选用。  
3. **几何特征的简化**：观察已知点的对称性、特殊关系（如三点共线、构成直角三角形等），优先利用图形性质减少计算。例如直角三角形外心为斜边中点。  
4. **整体平方处理**：若最终结果需保留根号或比较大小，可先求距离的平方，再做判断，避免开方带来的复杂运算。

## 高频易错
- **忘记开方**：得出 $(x_1-x_2)^2+(y_1-y_2)^2$ 后误认为是距离，未取平方根，尤其在紧张时容易漏掉根号。  
- **混淆中点坐标与距离公式**：两点距离需平方和开方；中点坐标为算数平均 $( \frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$，不可混用。  
- **垂直平分线求解错误**：在求外心时，中垂线的斜率是边斜率的负倒数，若边长斜率不存在（垂直 $x$ 轴）需单独处理，否则导致方程错误。  
- **坐标代入错误**：横纵坐标代反（如将 $(x_1,y_1)$ 的 $y_1$ 当成 $x$）或符号抄错，属于低级失误。  
- **根号下算术错误**：如 $\sqrt{1+\frac{4}{3}}$ 误算为 $\sqrt{\frac{5}{3}}$ 等。加强平方和通分训练。

## 代表题精讲
### 题目1（2015·全国卷·文）
已知三点 $A(1,0)$，$B(0,\sqrt{3})$，$C(2,\sqrt{3})$，则 $\triangle ABC$ 外接圆的圆心到原点的距离为（　）  
A. $\dfrac{5}{3}$　B. $\dfrac{\sqrt{21}}{3}$　C. $\dfrac{2\sqrt{5}}{3}$　D. $\dfrac{4}{3}$

**思路**  
所求为目标点 $O'$（外接圆圆心）到原点 $(0,0)$ 的距离。必须先求出 $O'$ 坐标。外心是三角形三边垂直平分线的交点，选取两条边（如 $AB$ 和 $BC$）求中垂线方程并联立。

**步骤**  
1. **求边 $AB$ 的中垂线**：  
   - $A(1,0), B(0,\sqrt{3})$，中点 $D(\frac{1+0}{2}, \frac{0+\sqrt{3}}{2}) = (\frac12, \frac{\sqrt{3}}{2})$。  
   - $k_{AB} = \frac{\sqrt{3}-0}{0-1} = -\sqrt{3}$，故中垂线斜率 $k_1 = \frac{1}{\sqrt{3}}$。  
   - 方程：$y - \frac{\sqrt{3}}{2} = \frac{1}{\sqrt{3}}(x - \frac12)$，化简得 $y = \frac{1}{\sqrt{3}}x + \frac{\sqrt{3}}{3}$。  

2. **求边 $BC$ 的中垂线**：  
   - $B(0,\sqrt{3}), C(2,\sqrt{3})$，中点 $E(1, \sqrt{3})$。  
   - $BC$ 平行 $x$ 轴（$k=0$），故中垂线斜率不存在，为竖直线 $x=1$。  

3. **联立求解 $O'$**：  
   代入 $x=1$ 到 $AB$ 中垂线方程：$y = \frac{1}{\sqrt{3}}\times 1 + \frac{\sqrt{3}}{3} = \frac{2\sqrt{3}}{3}$。  
   所以圆心 $O'(1, \frac{2\sqrt{3}}{3})$。

4. **求原点 $(0,0)$ 到 $O'$ 的距离**：  
   $$d = \sqrt{(1-0)^2 + \left(\frac{2\sqrt{3}}{3} - 0\right)^2} = \sqrt{1 + \frac{4\times 3}{9}} = \sqrt{1 + \frac{4}{3}} = \sqrt{\frac{7}{3}} = \frac{\sqrt{21}}{3}.$$  
   对应选项 **B**。

**点评/变式**  
- 本题核心是距离公式的间接应用：先求外心（几何计算），再用点到点距离公式。外心求法利用中垂线，其中 $BC$ 水平使其中垂线为竖直，极大简化运算。若三边均倾斜，则需解二元一次方程组，计算量略增。  
- **变式训练**：将 $B(0,\sqrt{3})$ 改为 $B(0,2)$，圆心的 $x$ 坐标仍为 1，$y$ 坐标变化，再求距离；或改为求重心到原点距离（直接代入重心坐标平均，距离为 $\frac{\sqrt{?}}{?}$），体会不同特殊点求法的区别。
