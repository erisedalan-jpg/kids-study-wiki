## 知识精要
- **点到直线距离公式**：点 $P(x_0, y_0)$ 到直线 $l: Ax + By + C = 0$（$A,B$ 不同时为 0）的距离为
  $$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$
- **直线方程标准化**：使用公式前必须将直线方程化为一般式 $Ax+By+C=0$。对于斜截式 $y=kx+b$，应化为 $kx - y + b =0$。
- **圆中的联系**：圆的圆心 $(a,b)$ 到直线的距离 $d$ 与半径 $r$ 共同控制直线与圆的位置关系：$d<r$ 相交，$d=r$ 相切，$d>r$ 相离。弦长公式为 $2\sqrt{r^2-d^2}$。
- **平行线间距离**可转化为一条直线上任一点到另一直线的距离。
- **椭圆/双曲线焦点/渐近线**的相关距离问题，常结合其标准方程与几何性质，最终归结为点到直线的计算。

## 解题方法与套路
1. **标准化直线方程**：拿到直线方程的第一步，统一整理成 $Ax+By+C=0$ 形式，明确 $A,B,C$ 的值，避免因斜率、截距形式直接代入公式导致符号错误。
2. **确定目标点坐标**：找准“动点”或“定点”。定点直接代入；动点通常通过几何关系（如点在圆/圆锥曲线上、对称关系、参数方程）设出坐标，最后代入距离公式构建方程。
3. **联立几何条件与距离公式**：
   - 遇到距离为已知值，直接列等式 $d=$ 已知值，去绝对值符号时注意多解情况。
   - 遇到面积条件，优先用弦长公式与距离表示面积，再代入距离公式求解参数。
4. **切线问题转化**：处理过定点的圆/曲线的切线问题，设出直线点斜式方程后，利用“圆心到切线距离 = 半径”或判别式法建立关于斜率 $k$ 的方程，求解后注意检验斜率不存在的情况。
5. **最值/范围问题**：对于距离相关的最值，通常先写出距离表达式（可能含参），再结合函数性质、几何意义（如三点共线、反函数对称性）或基本不等式求解。

## 高频易错
- **直线形式不规范**：将 $y=kx+b$ 代入公式时分子误写为 $|kx_0 + b - y_0|$ 而非 $|kx_0 - y_0 + b|$，或分母遗漏 $\sqrt{k^2+1}$ 的符号。牢记先化为一般式。
- **忽略斜率不存在的直线**：设直线方程为 $y-y_0 = k(x-x_0)$ 时，默认了斜率存在，会漏掉垂直于 $x$ 轴的直线。解题时必须单独检验此情况，如代表题中用 $m$ 表示斜率的倒数则可不讨论。
- **含参距离忘加绝对值**：公式分子为绝对值，丢掉则默认值非负，导致遗漏负数解（如求参数 $m$ 时）。
- **混淆圆/椭圆中的几何量**：求弦长时误用 $d$ 与 $r$ 的关系；求椭圆/双曲线的焦点到直线距离时，焦点坐标 $(±c,0)$ 中的 $c$ 与方程中 $a^2,b^2$ 关系混淆。
- **对称问题转化错误**：如两互为反函数的图像上点的最短距离问题，误以为是两曲线差的最小值，而应转化为其中一条曲线上点到 $y=x$ 距离的最值问题。

## 代表题精讲
### 1. 2023-新课标Ⅱ-05
**题目**：椭圆 $C: \frac{x^2}{3} + y^2 = 1$，左右焦点 $F_1, F_2$，直线 $y=x+m$ 与 $C$ 交于 $A,B$ 两点，若 $\triangle F_1AB$ 面积是 $\triangle F_2AB$ 面积的 2 倍，求 $m$。
**思路**：两个三角形同底 $AB$，面积比即转化为高之比，也就是左、右焦点到直线 $y=x+m$ 的距离之比。联立面积比与距离公式可解。
**步骤**：
1. 由椭圆方程得 $c = \sqrt{3-1} = \sqrt{2}$，焦点坐标 $F_1(-\sqrt{2}, 0), F_2(\sqrt{2}, 0)$。
2. $\triangle F_1AB$ 与 $\triangle F_2AB$ 共用底边 $AB$，其面积比为 2，等价于点 $F_1, F_2$ 到直线 $x - y + m = 0$ 的距离之比 $d_1:d_2 = 2:1$。
3. 写出距离公式：$d_1 = \frac{|-\sqrt{2} + m|}{\sqrt{2}}, d_2 = \frac{|\sqrt{2} + m|}{\sqrt{2}}$。
4. 由 $\frac{d_1}{d_2} = 2$ 得 $\frac{|m-\sqrt{2}|}{|m+\sqrt{2}|} = 2$。因为直线与椭圆相交需保证 $\Delta > 0$，结合选项检验，解绝对值方程得 $m = -\frac{2}{3}$ 或 $m = -3\sqrt{2}$（舍去）。
**点评/变式**：核心是将面积比转化为点到直线的距离比，避免了求解弦长 $|AB|$ 的繁琐计算。注意 $F_1, F_2$ 在直线的同侧还是异侧，决定了绝对值内表达式去绝对值后的符号，这里直接利用比例关系平方或用几何意义可简化。

### 2. 2023-新课标Ⅱ-15
**题目**：直线 $l: x - my + 1 = 0$ 与圆 $C: (x-1)^2 + y^2 = 4$ 交于 $A,B$ 两点，写出满足 $\triangle ABC$ 面积为 $\frac{8}{5}$ 的 $m$ 的一个值。
**思路**：题中 $C$ 为圆心，$\triangle ABC$ 是等腰三角形，面积可用弦长和圆心到直线的距离表示。先由面积求出 $d$ 的值，再代入点到直线距离公式求 $m$。
**步骤**：
1. 圆心 $C(1,0)$，半径 $r=2$。
2. 设圆心到直线 $l$ 的距离为 $d = \frac{|1 \times 1 - 0 \times m + 1|}{\sqrt{1^2 + (-m)^2}} = \frac{2}{\sqrt{1+m^2}}$。
3. 弦长 $|AB| = 2\sqrt{r^2 - d^2} = 2\sqrt{4-d^2}$。
4. 三角形面积 $S = \frac{1}{2}|AB| \cdot d = d \cdot \sqrt{4-d^2} = \frac{8}{5}$。
5. 解得 $d^2 = \frac{4}{5}$ 或 $\frac{16}{5}$（后者大于 4，舍去），故 $\frac{2}{\sqrt{1+m^2}} = \frac{2}{\sqrt{5}}$，得 $1+m^2=5$，即 $m = \pm 2$（或 $\pm \frac{1}{2}$）。
**点评/变式**：此题开放答案，体现“直线方程设为 $x-my+1=0$”的巧妙之处：它天然包含斜率不存在（$m=0$）的情况。这类通过距离和面积构建方程的问题，务必检验距离 $d$ 是否小于 $2$。

### 3. 2021-文-14
**题目**：双曲线 $\frac{x^2}{4} - \frac{y^2}{5} = 1$ 的右焦点到直线 $x + 2y - 8 = 0$ 的距离为____。
**思路**：直接计算焦点坐标，再代入点到直线的距离公式。注意双曲线焦点所在轴和基本量的关系。
**步骤**：
1. 由双曲线标准方程知 $a^2=4, b^2=5$，则 $c = \sqrt{a^2+b^2} = \sqrt{9} = 3$。
2. 右焦点坐标为 $(3,0)$。
3. 直线方程为 $x+2y-8=0$。
4. 距离 $d = \frac{|3 + 2 \times 0 - 8|}{\sqrt{1^2 + 2^2}} = \frac{5}{\sqrt{5}} = \sqrt{5}$。
**点评/变式**：基础保分题，完全考查公式记忆与基本量计算。牢记椭圆/双曲线中 $a,b,c$ 的关系，区分焦点在何轴。
