## 知识精要
- **抛物线焦点坐标**：对于标准方程 $y^2 = 2px\ (p>0)$，焦点为 $F\left(\frac p2,0\right)$；$y^2 = -2px\ (p>0)$ 焦点为 $\left(-\frac p2,0\right)$；$x^2 = 2py\ (p>0)$ 焦点为 $\left(0,\frac p2\right)$；$x^2 = -2py\ (p>0)$ 焦点为 $\left(0,-\frac p2\right)$。  
- **椭圆焦点坐标**：对于椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\ (a>b>0)$，焦点在 $x$ 轴上，$c = \sqrt{a^2 - b^2}$，焦点为 $(\pm c,0)$；若焦点在 $y$ 轴上（$\frac{y^2}{a^2}+\frac{x^2}{b^2}=1$），焦点为 $(0,\pm c)$，其中 $c = \sqrt{a^2 - b^2}$。  
- **共焦点条件**：若两曲线共用同一焦点，则该点坐标满足两曲线的焦点公式，可建立关于待定参数的方程。注意区分长轴所在轴，正确计算 $c$。

## 解题方法与套路
1. **先定型再定量**：将所给方程化为标准形式，明确曲线类型及开口（或长轴）方向。  
2. **写出焦点坐标**：利用标准方程的参数（$p$ 或 $a,b$）表示出焦点坐标，注意 $p>0$，$a>b>0$ 等隐含条件。  
3. **建立方程**：根据“公共焦点”或焦点重合条件，令对应坐标相等（如焦点在 $x$ 轴上，则横坐标相等，纵坐标为 $0$）。  
4. **解方程求参数**：消元或直接解方程，注意舍去不合题意的增根（如负值、零值）。  
5. **检验与巧解**：遇到选择题时，可代入选项检验焦点坐标是否一致，利用排除法快速求解。

## 高频易错
- **椭圆 $a,b$ 大小判断错误**：焦点总是在长轴上，若分母大的项对应 $a^2$；若分母大小与 $x^2,y^2$ 关系不清，易把 $c^2 = a^2 - b^2$ 弄反。  
- **抛物线焦点位置符号错误**：一次项决定对称轴，系数正负决定开口，焦点在轴上且与开口同向，计算 $\frac p2$ 时注意正负号。  
- **忽略参数范围**：如 $p>0$，得到 $p=0$ 时应舍去；椭圆 $a>b>0$，若解得 $p$ 使 $a\le b$ 需检验。  
- **混淆不同曲线的 $c$ 含义**：椭圆 $c$ 是半焦距，抛物线中并没有 $c$；公共焦点时不能直接将椭圆 $c$ 与抛物线 $\frac p2$ 做无关联的比较，需建立相等关系。  
- **解方程时平方导致增根**：如 $\frac p2 = \sqrt{2p}$ 两边平方可能引入 $p=0$，需代回验证。

## 代表题精讲
**题目**（2019 全国Ⅱ理 8）若抛物线 $y^2 = 2px\ (p>0)$ 的焦点是椭圆 $\frac{x^2}{3p} + \frac{y^2}{p} = 1$ 的一个焦点，则 $p =$  
A. $2$　　 B. $3$　　 C. $4$　　 D. $8$

**思路**  
分别写出抛物线和椭圆的焦点坐标，利用焦点相同建立关于 $p$ 的方程。注意椭圆方程中分母 $3p$ 与 $p$ 的大小关系，判断焦点所在轴并计算 $c$。亦可代入选项快速排除。

**步骤**  
1. 由抛物线 $y^2 = 2px\ (p>0)$，焦点为 $F\left(\frac p2, 0\right)$。  
2. 椭圆方程 $\frac{x^2}{3p} + \frac{y^2}{p} = 1$，因为 $3p > p > 0$，故焦点在 $x$ 轴上，$a^2 = 3p$，$b^2 = p$，则 $c = \sqrt{a^2 - b^2} = \sqrt{3p - p} = \sqrt{2p}$，焦点为 $(\pm \sqrt{2p}, 0)$。  
3. 由题设，抛物线的焦点就是椭圆的某一个焦点，由于都在 $x$ 轴正半轴或负半轴？注意 $\frac p2 > 0$，而椭圆焦点为 $(\pm \sqrt{2p}, 0)$，正半轴焦点为 $(\sqrt{2p}, 0)$，所以：  
   $$ \frac p2 = \sqrt{2p} $$  
4. 两边平方得 $\frac{p^2}{4} = 2p \implies p^2 = 8p \implies p(p-8)=0$。  
   结合 $p>0$，得 $p=8$。  
5. 检验：$p=8$ 时，抛物线焦点 $(4,0)$，椭圆 $a^2=24,\ b^2=8,\ c=\sqrt{16}=4$，焦点 $(\pm 4,0)$，符合。故选 **D**。

**点评/变式**  
- 本题本质是两曲线的基本量计算与相等关系构建，难度较低。若疏忽椭圆焦点位置判断，误认为焦点在 $y$ 轴，会得到 $c = \sqrt{p - 3p}$ 无解或错解。  
- 变式思考：若改为抛物线与椭圆有公共焦点且焦点在 $y$ 轴，可将椭圆方程调整为 $\frac{x^2}{p} + \frac{y^2}{3p} = 1$，再与 $x^2 = 2py$ 组合求解。亦可将椭圆换成双曲线，注意 $c = \sqrt{a^2 + b^2}$，方法完全一致。  
- 小题巧解：当 $p=2$ 时，抛物线焦点 $(1,0)$，椭圆焦点 $(\pm \sqrt4,0)=(\pm2,0)$，不重合，排除 A；类似可快速排除 B、C，直接选 D。
