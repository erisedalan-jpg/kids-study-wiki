## 知识精要

特殊值法是选择 / 填空题的"提速利器"：把一般问题中的参数、变量取具体的特殊值（或特殊位置、特殊函数），用得到的具体结论去**排除错误选项**或**反推参数**。它牺牲了严密性（特殊值满足不代表一般成立），但在客观题中极为高效。常用三种形态：

- **特值排除（排除法）**：对"判断哪个结论 / 函数正确"的选择题，对每个选项代入恰当的特殊值，只要某选项被一个反例否定即排除。常用反例对子：$a=2,b=-1$（满足 $a>b$ 但 $|a|<|b|$）、$a-b=1$（使 $\ln(a-b)=0$）等。
- **特值定参（必要条件法）**：对"$f(x)$ 满足某恒成立性质（如偶函数、恒过定点）求参数"的题，取一个特殊自变量代入得到关于参数的方程，先解出**候选参数**（必要条件），客观题可直接选，解答题须再验证充分性。
- **特殊函数 / 特殊图形法**：动点取特殊位置、一般三角形取等边、一般数列取常数列等，把抽象关系具体化。

关键依据：常用基本函数的单调性——指数 $y=3^x$ 递增、幂函数 $y=x^3$ 递增、对数 $y=\ln x$ 在 $(0,+\infty)$ 递增；偶函数定义 $f(-x)=f(x)$、奇函数 $f(-x)=-f(x)$。

## 解题方法与套路

1. **判断恒成立 / 选正确结论**：逐选项找反例。优先选取"边界值""使某式为 $0$ 或符号翻转"的特殊值（如令 $a-b=1$ 使对数为 $0$、取负数测试绝对值），一击排除。
2. **反例构造的次序**：先用一个简单正值组合试，若不能区分再换"一正一负""含 $0$""含 $1$"等极端组合，目标是让错误选项最快暴露矛盾。
3. **由性质定参（偶 / 奇 / 对称）**：取自变量的一对相反数，利用 $f(1)=f(-1)$（偶）或 $f(1)=-f(-1)$（奇）列方程解参数；解完务必**回代验证**定义域对称且性质真成立（必要 → 充分）。
4. **识图选函数**：观察图象的特殊点（过原点否、$x=1$ 处取值正负、是否过某定点）和趋势（奇偶、单调、有界），代入候选解析式逐一比对，矛盾即排除。
5. **数列 / 一般量比较**：先按定义代入边界特值（如各项取允许范围的端点）缩小可能，再结合放缩或单调性确认。

## 高频易错

- **把"必要"当"充分"**：特殊值满足只说明"必须如此"，反向不一定成立。解答题用特值定出参数后**必须验证**；客观题虽可直接用，但要警惕命题人设的"假根"。
- **特殊值取得太特殊导致选项无法区分**：取的值恰好让多个选项都成立时要换值，不能据此下结论。
- **忽略定义域对称性**：判断奇偶函数时，定出参数后未检验定义域是否关于原点对称，导致结论错误。
- **绝对值 / 偶次方掩盖符号**：取值时若全取正数，可能漏掉负值反例（如 $|a|>|b|$ 类命题需用负数检验）。
- **指数 / 幂 / 对数单调性方向记反**：如误认为 $3^a<3^b$ 当 $a>b$，导致排除判断出错。

## 代表题精讲

**代表题一（2023·新课标Ⅱ·04，偶函数求参数）**

**题目**：若 $f(x)=\left(\dfrac{2x-1}{2x+1}+a\right)\ln(\,\cdots\,)$ 形式的函数（含参数 $a$）为偶函数，求 $a$（答案 $a=0$，选 B）。

**思路**：偶函数对一切定义域内 $x$ 满足 $f(-x)=f(x)$，取特殊值 $x=1$ 得 $f(1)=f(-1)$，列方程解出候选 $a$，再回代验证。

**步骤**：
1. 由偶函数性质，取 $x=1$：$f(1)=f(-1)$。
2. 代入解析式得关于 $a$ 的方程，整理（利用 $\ln 3+\ln\dfrac13=0$ 类对消）解得 $a=0$。
3. 验证：当 $a=0$ 时，定义域为 $\left\{x\mid x>\dfrac12\text{ 或 }x<-\dfrac12\right\}$，关于原点对称；且 $f(-x)=f(x)$ 恒成立，确为偶函数，选 B。

**点评**：偶函数题"取一对相反特值定参 + 回代验证"是标准两步。验证不可省，因为 $f(1)=f(-1)$ 只是必要条件。变式：换成奇函数则用 $f(1)=-f(-1)$，或用 $f(0)=0$（若 $0$ 在定义域内）。

**代表题二（2019·理·06，特值法判断不等式）**

**题目**：若 $a>b$，判断下列哪项一定成立：A. $\ln(a-b)>0$；B. $3^a<3^b$；C. $a^3-b^3>0$；D. $|a|>|b|$。（答案 C）

**思路**：对 A、B、D 各找一个反例排除，对 C 用幂函数单调性确认。

**步骤**：
1. **排 A**：取 $a=2,b=1$，$a>b$ 但 $\ln(a-b)=\ln1=0\not>0$，A 错。
2. **排 B**：$y=3^x$ 递增，$a>b\Rightarrow3^a>3^b$，与 B 矛盾，B 错。
3. **排 D**：取 $a=1,b=-2$，$a>b$ 但 $|a|=1<|b|=2$，D 错。
4. **定 C**：幂函数 $y=x^3$ 在 $\mathbb{R}$ 上递增，$a>b\Rightarrow a^3>b^3$，即 $a^3-b^3>0$，C 恒成立，选 C。

**点评**：本题是"特值排除 + 单调性确认"的经典组合。反例的妙处在于专挑使式子取 $0$（A）或符号翻转（D）的值。变式：将选项换为 $\dfrac1a<\dfrac1b$ 等，需用 $a,b$ 异号的反例破解。

**代表题三（2022·文·08，特值识别函数图象）**

**题目**：给出区间 $[-3,3]$ 上某函数的大致图象，从 A. $\dfrac{x^3-2x}{x^2+1}$、B. $\dfrac{x^2-2x}{x^2+1}$、C. $\dfrac{2x\cos x}{x^2+1}$、D. $\dfrac{2\sin x}{x^2+1}$ 中选出对应函数（答案 A）。

**思路**：用特殊点函数值和奇偶性逐项排除。

**步骤**：
1. **排 B**：设 $g(x)=\dfrac{x^2-2x}{x^2+1}$，$g(1)=\dfrac{1-2}{2}=-\dfrac12\neq0$，而图象在 $x=1$ 处过零点附近，与图象不符（且 B 非奇非偶），排除。
2. **排 C**：$h(x)=\dfrac{2x\cos x}{x^2+1}$，当 $x\in\left(0,\dfrac{\pi}{2}\right)$ 时 $\cos x>0$、$x>0$，故 $h(x)>0$；但目标图象在该区间为负，排除 C。
3. **排 D**：$\dfrac{2\sin x}{x^2+1}$ 在原点附近增长形态与图象不符（峰值位置 / 符号不匹配），排除。
4. 余 A：$\dfrac{x^3-2x}{x^2+1}$ 为奇函数，图象关于原点对称，特殊点取值与趋势均吻合，选 A。

**点评**：识图题先看奇偶（对称性）和特殊点（$x=0,1$ 处取值正负），再看趋势。变式：把待选函数换成含 $\tan$ 或绝对值的形式，仍以特值 + 奇偶 + 渐近趋势三招排除。
