## 知识精要
- 球的定义：空间中到定点（球心）距离等于定长（半径 $R$）的点的集合。
- 球心到截面的距离 $d$、截面圆半径 $r$ 与球半径 $R$ 满足：$R^2 = r^2 + d^2$。
- 圆锥的顶点与底面圆周均在球面上 $\Leftrightarrow$ 球心在圆锥轴线上；轴截面是球的大圆或小圆内的内接三角形。
- 两圆锥共底面且顶点均在同一个球面上：公共底面为球的一个截面圆，两圆锥顶点关于截面所在平面分居两侧（或同侧），它们的高分别为 $R+d$ 与 $R-d$（$d$ 为球心到截面距离），高的和为 $2R$。

## 解题方法与套路
1. **化立体为平面**：画出组合体的轴截面，转化为球截面圆内接等腰三角形（或两个三角形）问题。
2. **设元建方程**：设球半径 $R$，底面圆半径 $r$，球心到公共底面的距离 $d$，由 $R^2=r^2+d^2$ 建立关系。
3. **利用题设面积或长度比**：将面积条件转化为 $r$ 与 $R$ 的方程，求出 $d$ 关于 $R$ 的表达式。
4. **求高度比**：两圆锥高分别为 $h_1=R+d$，$h_2=R-d$（或反过来），直接代入求比值。
5. **注意多解检验**：当条件对称时，比值常有倒数两种可能，注意题目问的是“小与大”还是“大与小”，避免比例反置。

## 高频易错
- **误认球心在底面上**：当两圆锥共底面且都在球内时，往往下意识认为球心在公共底面内，错得 $d=0$。
- **面积条件转化错误**：球面积公式 $S_{\text{球}}=4\pi R^2$，圆面积 $S_{\text{底}}=\pi r^2$；比值代入时易遗漏系数。
- **忽略绝对值导致高算错**：两圆锥的高表示为 $|d \pm R|$，若直接取 $d-R$ 为负，会导致高为负值。实际高应为 $R \pm d$（设 $d\ge 0$）。
- **比例顺序颠倒**：题目要求“体积较小者的高与体积较大者的高的比值”，注意较小高的表达式是 $R-d$，较大高是 $R+d$，比值即 $\dfrac{R-d}{R+d}$，勿写反。

## 代表题精讲
**题目**（2011 全国新课标 文-16） 已知两个圆锥有公共底面，且两个圆锥的顶点和底面的圆周都在同一个球面上。若圆锥底面面积是这个球面面积的 $\dfrac{3}{16}$，则这两个圆锥中，体积较小者的高与体积较大者的高的比值为________。

**思路**  
球心必在公共底面的垂线上，利用轴截面将其转化为平面圆内问题。由底面与球面的面积比求得底面半径与球半径的关系，进而确定球心到底面的距离，两圆锥高即 $R\pm d$，较小者与较大者之比即可求出。

**步骤**
1. 设球半径为 $R$，公共底面圆的半径为 $r$，球心 $O$ 到公共底面的距离为 $d$（$d\ge 0$），则有  
   $$R^2 = r^2 + d^2.$$
2. 由圆锥底面面积是球面面积的 $\dfrac{3}{16}$ 得  
   $$\pi r^2 = \frac{3}{16} \cdot 4\pi R^2 \quad\Rightarrow\quad r^2 = \frac{3}{4} R^2.$$
3. 代入 $R^2 = r^2 + d^2$：  
   $$R^2 = \frac{3}{4}R^2 + d^2 \quad\Rightarrow\quad d^2 = \frac{1}{4}R^2 \quad\Rightarrow\quad d = \frac{R}{2}.$$
4. 两圆锥的高分别为 $h_1 = R + d = \frac{3}{2}R$，$h_2 = R - d = \frac{1}{2}R$。  
   体积较小者的高为 $h_2$，较大者的高为 $h_1$，故所求比值为  
   $$\frac{h_2}{h_1} = \frac{\frac{R}{2}}{\frac{3R}{2}} = \frac{1}{3}.$$

**点评/变式**  
- 关键是把组合体的对称性转化为 $R,d,r$ 的几何关系，进而用代数比值得出结果。  
- 变式：若两圆锥的高之比为 $1:2$，求底面面积与球面面积的比（反向运用 $R$ 与 $d$ 关系）。  
- 注意题目问的是“较小者高与较大者高的比”，若将高认作 $d\pm R$ 易错，应先定 $d\le R$，保证高的非负性。
