## 知识精要
1. 球的截面性质：用一个平面去截球，若截面不经过球心，则截面圆圆心 $O_1$ 与球心 $O$ 的连线垂直于截面，且球心到截面的距离 $d$、截面圆半径 $r$ 和球半径 $R$ 满足 $$d = \sqrt{R^2 - r^2}$$
2. 等边三角形（正三角形）的边长 $a$ 与面积 $S$ 的关系：$$S = \frac{\sqrt{3}}{4}a^2$$ 其外接圆半径 $r = \frac{\sqrt{3}}{3}a$，内切圆半径也常用，但本题用外接圆。
3. 球的表面积公式：$S_{\text{球}} = 4\pi R^2$，由此可解出球半径 $R$。
4. 适用条件：已知球面上若干点构成的平面图形形状与度量，求球心到该平面的距离，本质是球的截面问题。当平面图形为三角形且已知面积，可先求边长及外接圆半径，再结合球半径使用垂径定理。

## 解题方法与套路
1. **由平面图形性质求截面圆半径**：若截面图形是三角形且顶点在球面上，则该截面圆就是三角形的外接圆。根据已知条件（如面积、边长、角度等）求出三角形边长，再计算出外接圆半径 $r$。
2. **由球的度量求球半径**：利用球的表面积或体积公式求出球半径 $R$。
3. **应用球的截面垂径定理**：代公式 $d = \sqrt{R^2 - r^2}$ 求出球心到截面的距离 $d$，并注意 $d \ge 0$。
4. **检验合理性**：必须确保 $R \ge r$，否则无法构成几何体，这是隐含条件。

## 高频易错
- **混淆三角形外接圆半径与边长的关系**：等边三角形外接圆半径 $r = \frac{\sqrt{3}}{3}a$，而误记为 $r = \frac{\sqrt{3}}{2}a$（那个是边长与新构成直角三角形的边的关系）或 $r = \frac{\sqrt{3}}{6}a$（内切圆半径）。
- **球的表面积公式记忆错误**：$S = 4\pi R^2$ 记成 $S = \pi R^2$（圆的面积）或 $S = 4\pi R^3$ 等。
- **计算平方根时忘记开方**：求出 $d^2$ 后直接作为答案，或开方时漏掉正根。
- **将距离误认为等于球半径减去某长度**，直接做减法，而正确关系是 $d = \sqrt{R^2 - r^2}$。

## 代表题精讲
**题目** 已知 $\triangle ABC$ 是面积为 $\frac{9\sqrt{3}}{4}$ 的等边三角形，顶点都在球 $O$ 的球面上。若球 $O$ 的表面积为 $16\pi$，则 $O$ 到平面 $ABC$ 的距离为（ ）  
A. $\sqrt{3}$   B. $\frac{3}{2}$   C. $1$   D. $\frac{\sqrt{3}}{2}$

**思路**  
$\triangle ABC$ 是截面圆的内接等边三角形，其外接圆半径 $r$ 即为截面圆半径。由面积求边长 $a$，再求 $r$。由球的表面积求出球半径 $R$。最后用公式 $d = \sqrt{R^2 - r^2}$ 得到距离。

**步骤**  
1. 设等边三角形边长为 $a$，面积 $S = \frac{\sqrt{3}}{4}a^2 = \frac{9\sqrt{3}}{4}$，解得 $a^2 = 9$，故 $a = 3$。  
2. 等边三角形的外接圆半径 $r = \frac{\sqrt{3}}{3}a = \frac{\sqrt{3}}{3} \times 3 = \sqrt{3}$。  
3. 球 $O$ 的表面积 $S_{\text{球}} = 4\pi R^2 = 16\pi$，得 $R^2 = 4$，即 $R = 2$。  
4. 球心到平面 $ABC$ 的距离 $d = \sqrt{R^2 - r^2} = \sqrt{4 - 3} = 1$。对应选项 C。

**点评/变式**  
本题是球截面性质的直接应用，难度不大，但易错点在于计算外接圆半径。变式可将等边三角形换为直角三角形（其外接圆半径等于斜边的一半）或已知一般三角形边长用正弦定理求外接圆半径；也可将条件“表面积”改为“体积”，公式变为 $V = \frac{4}{3}\pi R^3$，再解出 $R$。
