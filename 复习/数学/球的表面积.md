## 知识精要
球的表面积是立体几何与外接问题的核心考点，集中于一个基本公式和几个关键几何模型。

1. **基本公式**：
   - 球的表面积：$S = 4\pi R^2$
   - 球的体积：$V = \frac{4}{3}\pi R^3$（在求解半径 $R$ 时经常作为中间步骤）
2. **球的截面性质**（关键模型）：
   - 平面截球面得到圆，球心 $O$ 到截面圆的距离 $d$、球的半径 $R$、截面圆半径 $r$ 三者满足勾股关系：$R^2 = r^2 + d^2$。
   - 当 $d=0$ 时，截面为大圆；$d=R$ 时，截面退化为点。此题关系是沟通球与体内点、线、面的核心桥梁。
3. **常见空间几何体的外接球模型**：
   - **长方体（含正方体）**：体对角线长为外接球直径 $2R = \sqrt{\text{长}^2+\text{宽}^2+\text{高}^2}$。
   - **正棱柱/直棱柱**：外接球心为上、下底面外心连线的中点。$R^2 = \left(\frac{h}{2}\right)^2 + r_{\text{底面}}^2$。
   - **正棱锥**：外接球心在高线上。可利用轴截面图形，通过勾股定理列方程求 $R$。
   - 能补形为长方体的四面体，优先补形求解。

## 解题方法与套路
求解球的表面积，本质是求解球的半径 $R$。牢固掌握以下两类基本途径：

1. **直接求半径 $R$**：
   - **已知表面积/体积**：直接用公式 $S = 4\pi R^2$ 或 $V = \frac{4}{3}\pi R^3$ 反解出 $R$。注意开方运算的准确性。
   - **利用截面圆关系**：根据题意找出截面圆半径 $r$ 和球心到截面距离 $d$，代入核心关系式 $R^2 = r^2 + d^2$。
     - 例如，已知球心到截面ABC的距离，需求解截面圆圆心（对于三角形即外心）的半径 $r$。
2. **构建几何体外接球模型求 $R$**：
   - **找球心位置**：这是解题的关键。对于规则几何体，球心必在几何体的重心或对称中心。
     - 长方体、正方体：球心为体对角线交点。
     - 一般直棱柱：球心为上、下底面外接圆圆心连线的中点。
     - 正棱锥：球心在顶点与底面外接圆圆心所连的高线上。
   - **构造特征三角形**：画出几何体，找到包含球心 $O$、底面外接圆圆心 $O_1$、几何体一个顶点（如棱柱底面上的一个顶点）在内的直角三角形。
   - **列勾股定理方程**：在此直角三角形中，三边分别为：球半径 $R$、底面外接圆半径 $r$、球心到底面的距离（通常是高的一半或与高相关）。
     - 对于直三棱柱：$R^2 = \left(\frac{h}{2}\right)^2 + r_{\text{底面}}^2$。
     - 对于底面为正三角形的几何体，底面外接圆半径 $r = \frac{\sqrt{3}}{3}a$（$a$为边长）。
3. **动态最值问题**：抓住“点C位于垂直于面AOB的直径端点时，三棱锥 $O-ABC$ 体积最大”这类题设，直接建立体积与 $R$ 的函数关系，解出 $R$。

## 高频易错
1. **混淆直径与半径**：公式 $S = 4\pi R^2$ 中的是半径 $R$，题设常给“对角线长”、“体对角线是直径”，务必先求半径 $R$ 再代入计算，避免将直径当作半径直接平方。
2. **截面圆性质理解错误**：搞不清“球心到截面距离 $d$”、“截面圆半径 $r$”、“球的半径 $R$”的几何关系，错误地认为 $R = r + d$。正解是直角三角形勾股关系：$R^2 = r^2 + d^2$。
3. **外接球模型应用混乱**：
   - **底面外接圆半径求错**：等边三角形的外接圆半径 $r = \frac{\sqrt{3}}{3}a$，而不是高或内切圆半径。
   - **球心位置找错**：对于侧棱垂直于底面的三棱柱，球心是上下底面中心连线的中点，而非底面中心。计算时遗漏“侧棱长的一半”这个关键边。
4. **体积最值中的位置误判**：在求解“三棱锥体积最大值”时，不能准确判断动点的最优位置是垂直于底面的直径端点，导致无法入手。
5. **计算粗心**：在解方程 $R^2 = \text{常数}$ 后，忘记最后目标是求表面积 $4\pi R^2$，或者在代入时漏乘系数 $4\pi$。

## 代表题精讲
### 代表题1：2020-文-11（理-10）
**题目**：面积为 $\frac{9\sqrt{3}}{4}$ 的等边三角形ABC顶点在球面上，球表面积 $16\pi$，求 $O$ 到平面ABC的距离。

**思路**：点面距离 $d$ 是勾股关系 $R^2 = r^2 + d^2$ 中的一条直角边。我们已知球表面积可求 $R$，已知等边三角形面积可求边长进而求其外接圆半径 $r$，最后解出 $d$。

**步骤**：
1. **由球表面积求半径**：$4\pi R^2 = 16\pi \implies R^2 = 4 \implies R = 2$。
2. **由三角形面积求外接圆半径**：设等边三角形边长为 $a$，其面积 $S = \frac{\sqrt{3}}{4}a^2 = \frac{9\sqrt{3}}{4} \implies a^2 = 9 \implies a = 3$。等边三角形外接圆半径 $r = \frac{\sqrt{3}}{3}a = \sqrt{3}$。
3. **利用勾股关系求距离**：球心 $O$ 到截面ABC的距离 $d$ 满足 $R^2 = r^2 + d^2$，代入得 $2^2 = (\sqrt{3})^2 + d^2 \implies d^2 = 1 \implies d = 1$。
4. 答案选C。

**点评/变式**：此题是截面性质的标准应用。截面圆是三角形ABC的外接圆，其半径 $r$ 是连接空间问题与平面图形的关键中间量。
> **变式**：若已知的是距离 $d$ 和球的表面积，求三角形的面积，步骤完全逆向。

### 代表题2：2017-文-15
**题目**：长宽高为3，2，1的长方体的顶点在球面上，求球的表面积。

**思路**：长方体所有顶点到其中心距离相等，该中心即为外接球心，体对角线即为外接球直径。

**步骤**：
1. **求体对角线长**：$\text{体对角线} = \sqrt{3^2 + 2^2 + 1^2} = \sqrt{14}$。
2. **确定球半径**：球直径 $2R = \sqrt{14}$，故半径 $R = \frac{\sqrt{14}}{2}$。
3. **求表面积**：$S = 4\pi R^2 = 4\pi \times \left(\frac{\sqrt{14}}{2}\right)^2 = 4\pi \times \frac{14}{4} = 14\pi$。

**点评/变式**：此题为“墙角模型”的外接球，可推广到所有可补形为长方体的四面体。关键是牢记长方体与外接球的关系：$ (2R)^2 = \text{长}^2 + \text{宽}^2 + \text{高}^2 $，直接跳过了找球心的步骤，大幅简化运算。若为正方体，则 $2R = \sqrt{3}a$。
