## 知识精要
- **圆的标准方程**：$(x-a)^2+(y-b)^2=r^2$，圆心 $(a,b)$，半径 $r$。
- **直线方程的形式**：一般式 $Ax+By+C=0$；参数式 $\begin{cases} x=x_0+t\cos\theta \\ y=y_0+t\sin\theta \end{cases}$，其中 $t$ 为参数，$\theta$ 为倾斜角，斜率 $k=\tan\theta$。
- **直线与圆相交的充要条件**：圆心到直线的距离 $d<r$。
- **弦长公式**：设圆心到直线的距离为 $d$，半径为 $r$，则相交弦长 $|AB| = 2\sqrt{r^2 - d^2}$。
- **联立方程与韦达定理**：将直线方程代入圆方程消元得一元二次方程 $ax^2+bx+c=0$ ($a\neq0$)，交点 $A(x_1,y_1), B(x_2,y_2)$，则 $x_1+x_2=-\dfrac{b}{a}, x_1x_2=\dfrac{c}{a}$，再由直线关系得 $y_1,y_2$ 的和与积。适用条件：$\Delta>0$。
- **垂直条件的坐标转化**：若 $OA \perp OB$（$O$ 为原点），则 $\overrightarrow{OA} \cdot \overrightarrow{OB}=0$，即 $x_1x_2 + y_1y_2 = 0$。
- **极坐标与直角坐标互化**：$\rho^2 = x^2+y^2$，$x=\rho\cos\theta$，$y=\rho\sin\theta$。

## 解题方法与套路
1. **求圆的方程**：通常利用标准式确定圆心和半径，或用一般式 $x^2+y^2+Dx+Ey+F=0$ 待定系数求解（如借由曲线与坐标轴交点）。
2. **求弦长或由弦长求参数**：
   - 将直线方程化为一般式，写出圆心坐标和半径；
   - 计算圆心到直线的距离 $d = \dfrac{|A x_0 + B y_0 + C|}{\sqrt{A^2+B^2}}$；
   - 套用弦长公式 $|AB| = 2\sqrt{r^2 - d^2}$，建立关于所求参数（如斜率 $k$）的方程并求解。
3. **利用垂直关系建立方程**：
   - 设交点坐标 $A(x_1,y_1), B(x_2,y_2)$，联立直线与圆的方程，消元得到一元二次方程；
   - 写出韦达定理的表达式，利用直线方程将 $y_1,y_2$ 用 $x_1,x_2$ 表示，代入 $x_1x_2 + y_1y_2 = 0$ 得到关于参数的方程；
   - 注意验证 $\Delta>0$ 保证两交点存在。
4. **参数方程的处理**：
   - 已知直线参数方程 $\begin{cases} x = x_0 + t \cos\theta \\ y = y_0 + t \sin\theta \end{cases}$ 时，可通过消去 $t$ 得到普通方程 $y-y_0 = \tan\theta (x-x_0)$（需讨论 $\cos\theta=0$ 的情况，此时直线垂直于 $x$ 轴）。
5. **极坐标方程化归**：直接将 $x=\rho\cos\theta, y=\rho\sin\theta$ 代入圆的直角坐标方程，化简即得极坐标方程。

## 高频易错
- **忽视斜率不存在的情形**：由参数方程写普通方程时，当 $\cos\theta=0$（即 $\theta=\frac{\pi}{2}$）时，直线方程为 $x=x_0$，斜率不存在，需单独讨论。涉及弦长问题时，有时题目默认斜率存在，但仍需警惕。
- **弦长公式记忆混淆**：错误记为 $|AB| = \sqrt{r^2 - d^2}$ 或 $|AB| = 2(r-d)$，务必明确 $2\sqrt{r^2-d^2}$ 是半弦长 $\times2$。
- **点到直线距离公式符号遗漏**：代入圆心坐标时，注意 $C$ 项的正负，分母一定是$\sqrt{A^2+B^2}$。
- **忽略判别式 $\Delta>0$**：在使用韦达定理建立方程解决含参问题时，往往直接求值而忘记检验直线与圆是否确实相交，可能导致增根。
- **极坐标方程化简差错**：代入后漏项，例如 $x^2+y^2$ 用 $\rho^2$ 替换，一次项 $x$ 用 $\rho\cos\theta$ 替换时系数错误。
- **几何条件转化不准确**：$OA\perp OB$ 误写为 $x_1+x_2+y_1+y_2=0$ 或 $k_{OA}\cdot k_{OB}=1$ 等，正确为 $x_1x_2+y_1y_2=0$。

## 代表题精讲
### **题目**（2016-文-23）
在直角坐标系 $xOy$ 中，圆 $C: (x+6)^2+y^2=25$。
（Ⅰ）以原点为极点、$x$ 轴正半轴为极轴建立极坐标系，求 $C$ 的极坐标方程；
（Ⅱ）直线 $l$ 的参数方程为 $\begin{cases} x=t\cos\alpha \\ y=t\sin\alpha \end{cases}$（$t$ 为参数），$l$ 与 $C$ 交于 $A,B$ 两点，$|AB|=\sqrt{10}$，求 $l$ 的斜率。

**思路**：
（Ⅰ）利用极坐标互化公式直接代入标准方程。
（Ⅱ）由参数方程写普通方程 $y=kx$（$k=\tan\alpha$），利用弦长公式：圆心到直线距离 $d=\dfrac{| -6k|}{\sqrt{k^2+1}}$，半径 $r=5$，由 $|AB|=2\sqrt{r^2-d^2}=\sqrt{10}$ 解出 $k$。

**步骤**：
（Ⅰ）圆方程为 $(x+6)^2+y^2=25$，即 $x^2+y^2+12x+11=0$。代入 $x^2+y^2=\rho^2$，$x=\rho\cos\theta$，得极坐标方程：$\rho^2+12\rho\cos\theta+11=0$。
（Ⅱ）由参数方程消去 $t$，得 $y = x\tan\alpha$，即 $l: kx - y = 0$（$k=\tan\alpha$）。圆 $C$ 的圆心 $(-6,0)$，半径 $r=5$。圆心到 $l$ 的距离 $d = \dfrac{|-6k - 0|}{\sqrt{k^2+1}} = \dfrac{6|k|}{\sqrt{k^2+1}}$。
由弦长公式 $|AB| = 2\sqrt{r^2-d^2} = 2\sqrt{25 - \dfrac{36k^2}{k^2+1}} = \sqrt{10}$。
两边平方：$4\left(25 - \dfrac{36k^2}{k^2+1}\right)=10$，即 $25 - \dfrac{36k^2}{k^2+1} = \dfrac{5}{2}$，解得 $\dfrac{36k^2}{k^2+1} = \dfrac{45}{2}$，化简得 $72k^2 = 45(k^2+1)$，即 $27k^2=45$，$k^2=\dfrac{5}{3}$，故 $k = \pm\dfrac{\sqrt{15}}{3}$。
直线 $l$ 的斜率为 $\pm\dfrac{\sqrt{15}}{3}$。

**点评/变式**：
由极坐标方程可直接看出圆心和半径吗？这里得到的 $\rho^2+12\rho\cos\theta+11=0$ 对应圆。参数方程化为普通方程时注意，若 $\alpha=\frac{\pi}{2}$ 则 $x=0$，此时 $l$ 为 $y$ 轴，验证弦长满足吗？可检验排除。本题是典型的“弦长反求斜率”问题，关键在距离公式与弦长公式联立。变式：若已知弦长为某值，求直线纵截距，方法与本题同理。

### **题目**（2011-文-20）
在平面直角坐标系 $xOy$ 中，曲线 $y=x^2-6x+1$ 与坐标轴的交点都在圆 $C$ 上。
（Ⅰ）求圆 $C$ 的方程；
（Ⅱ）若圆 $C$ 与直线 $x-y+a=0$ 交于 $A,B$ 两点，且 $OA\perp OB$，求 $a$ 的值。

**思路**：
（Ⅰ）求出曲线与坐标轴的三个交点，由圆过这三点求方程。法一利用几何性质：圆心在两点中垂线上；法二设一般式解方程组。
（Ⅱ）设交点坐标，联立直线与圆方程，消 $y$ 保留 $x$，用韦达定理表达 $x_1x_2$ 与 $x_1+x_2$，再用直线关系写出 $y_1y_2$，代入垂直条件 $x_1x_2+y_1y_2=0$，解出 $a$，最后验证 $\Delta>0$。

**步骤**：
（Ⅰ）曲线与坐标轴交点：令 $x=0$ 得 $(0,1)$；令 $y=0$，解 $x^2-6x+1=0$ 得 $x=3\pm2\sqrt{2}$，即 $(3+2\sqrt{2},0)$ 和 $(3-2\sqrt{2},0)$。三点确定圆。法一：由坐标特征知圆心在 $x=3$ 上，设圆心 $(3,t)$，由 $|CO|=|CA|$（$O$为$(0,1)$，$A$为$(3+2\sqrt{2},0)$）得 $(3-0)^2+(t-1)^2 = (2\sqrt{2})^2+(t-0)^2$，解得 $t=1$。半径为 $\sqrt{3^2+0^2}=3$，圆 $C$: $(x-3)^2+(y-1)^2=9$。
（Ⅱ）设 $A(x_1,y_1), B(x_2,y_2)$。由 $x-y+a=0$ 得 $y=x+a$，代入圆方程：$(x-3)^2+(x+a-1)^2=9$，整理得 $2x^2 + 2(a-4)x + a^2-2a+1=0$。
$\Delta = 4(a-4)^2 - 8(a^2-2a+1) > 0$，化简得 $-4a^2-16a+56>0$（以备检验）。
由韦达定理：$x_1+x_2 = 4-a$，$x_1x_2 = \dfrac{a^2-2a+1}{2}$。
则 $y_1 = x_1+a$，$y_2=x_2+a$，故 $y_1y_2 = (x_1+a)(x_2+a) = x_1x_2 + a(x_1+x_2) + a^2$。
代入垂直条件 $x_1x_2 + y_1y_2 = 0$：
$x_1x_2 + [x_1x_2 + a(x_1+x_2) + a^2] = 2x_1x_2 + a(x_1+x_2) + a^2 = 0$。
将和与积代入：$2\cdot\dfrac{a^2-2a+1}{2} + a(4-a) + a^2 = (a^2-2a+1) + 4a - a^2 + a^2 = a^2 + 2a + 1 = 0$。
得 $(a+1)^2=0$，故 $a=-1$。
检验：当 $a=-1$ 时，$\Delta$ 表达式值为正，符合题意，所以 $a=-1$。

**点评/变式**：
求圆方程时，要根据交点坐标特征灵活选择方法，如本题用中垂线交点和待定系数法均可。第二问是典型的“垂直弦”问题，核心是设而不求、韦达转化。若将直线换成参数式或给定斜率，方法类似。注意检验 $\Delta>0$ 是防止产生非交点的失分关键。变式：当条件变为 $|AB|$ 为定值时，则使用弦长公式；若改为 $OA$、$OB$ 斜率之和为定值，则化为 $y_1/x_1 + y_2/x_2$ 的韦达形式。
