## 知识精要

1. **到角公式**  
   直线 $l_1$ 到 $l_2$ 的角 $\theta$ 满足  
   $$\tan\theta = \frac{k_2 - k_1}{1 + k_2 k_1}\quad (1 + k_1 k_2 \neq 0)$$  
   若 $1 + k_1 k_2 = 0$，则 $l_1 \perp l_2$，到角 $\theta=90^\circ$。  
   到角是有方向的角，与直线的排列顺序有关；而**夹角**公式  
   $$\tan\alpha = \left| \frac{k_2 - k_1}{1 + k_2 k_1} \right|$$  
   给出的是锐角（或直角）。

2. **等腰三角形的等角性质**  
   等腰三角形底边所在直线与两腰所在直线的夹角相等。若两腰不平行，底边与两腰所成的两个底角大小相等，利用到角公式可建立方程。

3. **直线关于点、直线对称的常见结论**  
   - 点 $P(a,b)$ 关于直线 $Ax+By+C=0$ 的对称点 $(x_0,y_0)$ 满足：  
     中点在对称轴上，连线与对称轴垂直。  
   - 直线关于点的对称：转化为点的对称。  
   - 直线关于直线的对称：可先求交点，再取已知直线上一点，求其对称点，由两点确定对称直线；亦可利用角平分线性质（所求直线与原直线关于对称轴成等角）。  
   - 到角公式可直接用于处理“角平分线”“等角线”问题。

## 解题方法与套路

1. **识图并提取几何性质**  
   遇到等腰三角形、角平分线、对称等条件，优先转化为“等角”关系。例如：底边与两腰夹角相等，角平分线与两边夹角相等，对称轴与两对称直线夹角相等。

2. **设出未知直线方程**  
   若已知所求直线上一点（如原点），直接设 $y=kx$（注意斜率不存在时单独讨论）。若不知点，可根据条件设一般式或点斜式。

3. **建立到角（或夹角）等式**  
   对于“等角”条件，若已知两条直线的相对位置，可用有方向的到角公式：  
   $l_3$ 到 $l_1$ 的角 = $l_2$ 到 $l_3$ 的角。  
   若不能确定方向，用夹角公式但要结合图形排除多余解。

4. **解方程求参数并检验**  
   求出的斜率需代入原设检查是否满足几何限制（如题目中“原点在底边上”可排除使原点不在底边线段上的增根）。注意剔除使分母为零的解。

5. **数形结合验证**  
   必要时画草图，观察直线间相对位置，确保解的合理性。

## 高频易错

- **混淆到角与夹角**：用 $|\,\cdot\,|$ 会丢失方向信息，可能产生两个解，其中一个是底边的高（或角平分线），需要根据“底边”还是“高”进行区分。
- **忽略斜率不存在的情况**：设 $y=kx$ 时，必须单独验证 $x=0$ 是否满足题设（此类题中若原点在两腰交点和其它位置可快速判断）。
- **没有检验解的几何合理性**：解出的 $k$ 可能使得底边与腰交于原点的同一侧，导致原点不在底边“线段”上，仅在其延长线上。务必结合交点坐标确认。
- **到角公式分母为零的处理**：若 $1+k_1k_2=0$，仍可直接用垂直关系或分类讨论。
- **计算失误**：交叉相乘时漏乘、移项出错，建议解出后代入原到角方程两边验证。

## 代表题精讲

### **题目**（2008·理·11 改编）  
等腰三角形两腰所在直线 $l_1:x+y-2=0$，$l_2:x-7y-4=0$，原点在底边上，求底边所在直线的斜率。

### **思路**  
设底边 $l_3:y=kx$（过原点）。利用等腰三角形底边与两腰夹角相等，即有方向的角：$l_3$ 到 $l_1$ 的角等于 $l_2$ 到 $l_3$ 的角。用“到角公式”列出关于 $k$ 的方程，解出 $k$，再舍弃几何上不成立的增根。

### **步骤**  
1. 求已知斜率：$k_1=-1$，$k_2=\frac{1}{7}$。  
2. 写出到角关系：  
   $$\frac{k_1 - k}{1 + k_1 k} = \frac{k - k_2}{1 + k k_2}$$  
   即  
   $$\frac{-1 - k}{1 - k} = \frac{k - \frac{1}{7}}{1 + \frac{k}{7}}$$  
3. 化简右端：  
   $$\frac{k - \frac{1}{7}}{1 + \frac{k}{7}} = \frac{\frac{7k-1}{7}}{\frac{7+k}{7}} = \frac{7k-1}{7+k}$$  
   等式化为  
   $$\frac{-(k+1)}{1-k} = \frac{7k-1}{7+k}$$  
4. 交叉相乘：  
   $$-(k+1)(7+k) = (1-k)(7k-1)$$  
   展开：  
   $$-(k^2+8k+7) = (1-k)(7k-1) = 7k-1 -7k^2 +k = -7k^2+8k-1$$  
   移项：  
   $$-k^2 -8k -7 = -7k^2+8k-1$$  
   $$6k^2 -16k -6 = 0 \implies 3k^2 -8k -3 = 0$$  
5. 解二次方程：  
   $(3k+1)(k-3)=0 \implies k=3$ 或 $k=-\frac{1}{3}$。  
6. 检验：当 $k=-\frac{1}{3}$ 时，求得底边与两腰的交点，原点在线段的延长线上（或原点不在两交点之间），与“原点在底边上”矛盾；$k=3$ 满足。  
   （快速判定：分别求 $l_1$、$l_2$ 与 $y=3x$ 和 $y=-\frac{1}{3}x$ 的交点，看原点是否在两点之间。$y=3x$ 与 $l_1$ 交于 $(\frac{1}{2},\frac{3}{2})$，与 $l_2$ 交于 $(-\frac{1}{5},-\frac{3}{5})$，原点在两点之间；$y=-\frac{1}{3}x$ 的两交点横坐标同号，原点在线段外。）

### **点评 / 变式**  
- 本题核心是将几何条件“等腰三角形”转化为“底边与两腰的夹角相等”，直接用有方向的到角公式列方程，避免了繁杂的距离计算。  
- 如果题目改为“求底边上的高所在直线”，则高是两腰的**角平分线**，可用夹角公式取锐角平分线，或求两腰交点，再用夹角公式求平分线斜率。  
- 变式：两条直线 $l_1$、$l_2$ 相交，求过某定点且与 $l_1$、$l_2$ 成等角的直线方程，需分“内角平分线”和“外角平分线”讨论，可结合到角公式并注意方向。
