## 知识精要
- **直线的倾斜角**：直线向上方向与 $x$ 轴正方向所成的最小正角，记为 $\alpha$，$\alpha \in [0,\pi)$。
- **直线的斜率**：倾斜角 $\alpha \neq \frac{\pi}{2}$ 时，斜率 $k = \tan\alpha$。当直线方程为 $y = kx + b$ 时，$k$ 即为该直线的斜率。
- **斜率与倾斜角的关系**：由直线方程可直接读出斜率，进而得到倾斜角的正切值：
  $$\tan\alpha = k.$$
- **同角三角函数基本关系**：
  $$\sin^2\alpha + \cos^2\alpha = 1,\quad \tan\alpha = \frac{\sin\alpha}{\cos\alpha},\quad 1 + \tan^2\alpha = \frac{1}{\cos^2\alpha}.$$
- **二倍角公式（余弦）**：
  $$\cos 2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha = \cos^2\alpha - \sin^2\alpha.$$
- **适用条件**：直线斜率存在（倾斜角不为 $\frac{\pi}{2}$）；角度 $\theta$ 的终边落在该直线上时，$\theta$ 与倾斜角 $\alpha$ 的关系为 $\theta = \alpha$ 或 $\theta = \alpha + \pi$，但正切值不变。

## 解题方法与套路
1. **由直线方程求斜率与正切值**  
   从直线方程 $y = kx$（或 $y = kx + b$）中直接读出斜率 $k$，则 $\tan\theta = k$。  
2. **利用“1的代换”求 $\cos^2\theta$**  
   由 $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$，得  
   $\cos^2\theta = \dfrac{1}{1 + \tan^2\theta}$。  
   （注：此公式不涉及象限，直接得到平方值，安全高效。）  
3. **代入二倍角公式计算 $\cos 2\theta$**  
   $\cos 2\theta = 2\cos^2\theta - 1$，将上一步的 $\cos^2\theta$ 代入即可。  
4. **（选通法）构造直角三角形**  
   由 $\tan\theta = 2$，不妨设角 $\theta$ 终边上一点 $(1,2)$，可求斜边 $\sqrt{5}$，得 $\cos\theta = \pm \frac{1}{\sqrt{5}}$，平方后代入二倍角公式，结果一致。注意平方后符号消失，无需讨论象限。

## 高频易错
- **混淆倾斜角与直线的夹角**：直线 $y = 2x$ 的倾斜角 $\alpha$ 满足 $\tan\alpha = 2$，而非 $\alpha = 2$。  
- **忽略斜率不存在的情况**：本题直线为 $y = 2x$，斜率存在，但复习时需注意倾斜角为 $\frac{\pi}{2}$ 时斜率无定义，相关公式失效。  
- **三角函数符号判断失误**：终边在直线 $y = 2x$ 上，角 $\theta$ 可在第一或第三象限，$\cos\theta$ 有正负。但所求为 $\cos 2\theta$，只依赖 $\cos^2\theta$，故可直接使用 $1 + \tan^2\theta = \frac{1}{\cos^2\theta}$ 避开符号讨论。若错误地强行判断象限而忽略平方，可能得错解。  
- **公式记忆串用**：二倍角公式 $\cos 2\theta = 1 - 2\sin^2\theta$ 与 $\cos 2\theta = 2\cos^2\theta - 1$ 混淆，或与正弦二倍角混淆，导致代入错误。  
- **计算粗心**：由 $\tan\theta = 2$ 求 $\cos^2\theta$ 时，分母计算为 $1+2^2=5$，易误算成 $1+2=3$。

## 代表题精讲
**题目**（2011·全国卷文数第7题）  
已知角 $\theta$ 的顶点与原点重合，始边与 $x$ 轴的正半轴重合，终边在直线 $y = 2x$ 上，则 $\cos 2\theta =$（ ）

**思路**  
直线上终边确定后，斜率即 $\tan\theta$，通过同角关系求出 $\cos^2\theta$，代入二倍角公式即得 $\cos 2\theta$。回避讨论 $\theta$ 的象限。

**步骤**  
1. 由终边在直线 $y = 2x$ 上，得斜率 $k = 2$，故 $\tan\theta = 2$。  
2. 依据 $1 + \tan^2\theta = \dfrac{1}{\cos^2\theta}$，得  
   $\cos^2\theta = \dfrac{1}{1 + 2^2} = \dfrac{1}{5}$。  
3. 由二倍角公式 $\cos 2\theta = 2\cos^2\theta - 1$，  
   $\cos 2\theta = 2 \times \dfrac{1}{5} - 1 = -\dfrac{3}{5}$。  
4. 对应选项为 $-\dfrac{3}{5}$。

**点评/变式**  
该题是解析几何中斜率概念与三角恒等变换的经典结合，难度中等，但属于必会基础题。  
- **变式方向一**：将直线改为 $y = \sqrt{3}x$，此时 $\tan\theta = \sqrt{3}$，倾斜角为特殊角，可先求出 $\theta = \frac{\pi}{3}$ 或 $\frac{4\pi}{3}$，再求 $\cos 2\theta$，但直接使用公式依然更快捷。  
- **变式方向二**：求 $\sin 2\theta$ 或 $\tan 2\theta$，需额外注意符号：若终边所在象限不确定，$\sin 2\theta$ 或 $\tan 2\theta$ 可能有两解，此时需结合倾斜角范围或点的坐标符号进一步限定。  
- **通法优势**：利用 $\cos^2\theta = \frac{1}{1+\tan^2\theta}$ 求余弦平方，是处理“已知正切求余弦二倍角”的最优套路，省去开方和符号判断，大幅降低错误率。
