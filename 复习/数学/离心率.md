## 知识精要
- **离心率定义**：
    - 椭圆与双曲线中，$e = \frac{c}{a}$，其中 $c$ 为半焦距，$a$ 为长半轴（实半轴）长。
    - 范围：椭圆 $e \in (0, 1)$；双曲线 $e \in (1, +\infty)$；抛物线 $e=1$。
- **基本关系**：务必区分椭圆与双曲线的参数关系。
    - 椭圆：$a^2 = b^2 + c^2$，焦点在长轴上。
    - 双曲线：$c^2 = a^2 + b^2$，焦点在实轴上。
- **渐近线（双曲线）**：
    - 焦点在 $x$ 轴：$y = \pm \frac{b}{a} x$。
    - 焦点在 $y$ 轴：$y = \pm \frac{a}{b} x$。
    - 渐近线斜率与离心率关系：若渐近线斜率为 $k = \frac{b}{a}$，则 $e = \frac{c}{a} = \sqrt{1+ \left( \frac{b}{a} \right)^2} = \sqrt{1 + k^2}$。
- **通径（焦径）**：
    - 过焦点且垂直于焦点所在对称轴的弦。半通径长 $l = \frac{b^2}{a}$。
    - 椭圆/双曲线的通径端点坐标：$x$ 轴上的焦点 $F(\pm c, 0)$，则 $y = \pm \frac{b^2}{a}$。
- **圆锥曲线定义**：
    - 椭圆第一定义：$|PF_1| + |PF_2| = 2a$。
    - 双曲线第一定义：$\left| |PF_1| - |PF_2| \right| = 2a$。
    - 椭圆与双曲线的第二定义（选填可用）：动点到焦点距离与到对应准线距离之比为定值 $e$。

## 解题方法与套路
1.  **直接法求 $e$**：已知 $a, b, c$ 中任意两个的等量关系，直接联立 $a,b,c$ 基本关系消元，解出 $e = \frac{c}{a}$。
    - 如题干给出渐近线斜率 $k$，双曲线直接套 $e = \sqrt{1+k^2}$。
    - 椭圆题给出 $a,c$ 线性关系可直接得出 $e$。

2.  **几何法构造 $a,c$ 齐次式**：这是高考最高频的题型，尤其涉及焦点三角形、圆与圆锥曲线交点。
    - **步骤**：
        - **画图**：据题意精准画出图形，标出已知长度、角度。
        - **找几何关系**：利用等腰三角形、直角三角形（勾股定理）、正弦/余弦定理、圆的对称性与半径相等、切线的垂直关系等。
        - **翻译成边**：将几何条件转化为仅含 $a,b,c$ 的线段长度表达式。常用切入点：
            - 椭圆上点 $P$ 满足 $PF_1 \perp PF_2$，则 $|PF_1|^2 + |PF_2|^2 = |F_1F_2|^2 = 4c^2$，且 $|PF_1|+|PF_2| = 2a$。
            - 焦点三角形已知角度，可用正弦定理或构造过点作坐标轴的垂线求出点坐标。
        - **代入/消元**：将点的坐标代入圆锥曲线方程，结合定义，消去 $b$，得到仅含 $a,c$ 的齐次方程，两边同除 $a^2$ 或 $a^4$ 等，解出 $e$。

3.  **通径公式使用**：题干出现“过焦点且垂直长/实轴的弦”，立即写出弦长 $ = 2 \cdot \frac{b^2}{a}$，直接得等式求解。

4.  **轨迹交点法**：求点坐标时，若该点同时在两线上（如同时在圆与圆锥曲线上），可联立方程或利用圆的几何性质求坐标，代入曲线方程。

## 高频易错
- **混淆 $a,b,c$ 关系**：
    - 双曲线计算中误用 $a^2+b^2=c^2$ 为 $a^2=b^2+c^2$。
    - 一看到 $PF_1 \perp PF_2$ 就默认 $|PF_1|^2+|PF_2|^2=4c^2$，但在双曲线中需注意到底是在焦点三角形用余弦定理，还是结合定义导出 $|PF_1|\cdot|PF_2|$ 的值。

- **忽略分类讨论**：
    - 双曲线问题常需判断交点 $M,N$ 位于双曲线的同一支还是两支，不同情况得出的夹角或线段关系不同（如真题 2022 理-11）。仅做出一种情况会漏解，现多选题趋势更需警惕。
    - 椭圆对称轴方向未定时，需分焦点在 $x$ 轴或 $y$ 轴讨论。

- **渐近线斜率与 $e$ 的关系错乱**：
    - 双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2}=1$ 的渐近线斜率为 $\pm \frac{b}{a}$，才对应 $e=\sqrt{1+\left(\frac{b}{a}\right)^2}$。若渐近线斜率为 $\pm \frac{a}{b}$，则 $e=\sqrt{1+\left(\frac{a}{b}\right)^2}$，不能死记。

- **点坐标直接代入方程的运算错误**：
    - 将形如 $(c, \sqrt{3}c)$ 的点代入 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 或双曲线方程后，不会灵活利用 $b^2 = a^2 - c^2$ 或 $c^2-a^2$ 消元，导致式子冗长算错。

- **忽略离心率范围限制**：
    - 求得 $e$ 的两个值，未根据椭圆 $0<e<1$、双曲线 $e>1$ 进行取舍。

## 代表题精讲
### **题目**（2022-理-11）
双曲线 $C$ 焦点 $F_1, F_2$，以实轴为直径作圆 $D$。过 $F_1$ 作 $D$ 的切线与 $C$ 交于 $M,N$，$\cos \angle F_1 N F_2 = \frac{3}{5}$，求离心率 $e$。

**思路**
画图，圆心 $O$，半径 $a$。切线 $F_1 M N$，切点 $G$，故 $OG \perp MN$。本题关键在于将已知角 $\angle F_1 N F_2$（余弦为 $\frac{3}{5}$）置于 $\triangle F_1 N F_2$ 中，用正弦定理或余弦定理结合双曲线定义求出边长关系。由于 $M,N$ 为交点，需分点在同一支或两支讨论。

**步骤**
1. **几何关联**：连接 $OG$ 则 $OG \perp F_1 N$。在 $Rt\triangle OG F_1$ 中，$|OG|=a, |OF_1|=c, |F_1 G|=b$。
2. **设角**：设 $\angle F_1 N F_2 = \theta$，则 $\cos \theta = \frac{3}{5}$，故 $\sin \theta = \frac{4}{5}$。
3. **分类讨论**：
    - **情况一**：$M,N$ 在左支，$N$ 为左支上点。在 $\triangle F_1 N F_2$ 中，由正弦定理：$\frac{|F_1 F_2|}{\sin \theta} = \frac{|NF_2|}{\sin \angle NF_1F_2} = \frac{|NF_1|}{\sin \angle NF_2F_1}$。结合双曲线定义 $|NF_2| - |NF_1| = 2a$。由 $OG \parallel NF_2$ 等几何关系导出 $ \angle NF_1F_2$ 正余弦。
    - **解析结论**：经运算可得 $|NF_1| = 3b/2 - a$ 等关系，代入定义式最终化简得关系式 $2b=3a$ 或 $a=2b$。由 $e = \frac{c}{a} = \frac{\sqrt{a^2+b^2}}{a} = \sqrt{1+\left(\frac{b}{a}\right)^2}$，当 $2b=3a$ 时 $e=\frac{\sqrt{13}}{2}$；当 $a=2b$ 时 $e=\frac{\sqrt{5}}{2}$。
    - **情况二**：$M,N$ 各在左右支，同样利用定义和三角关系，可验证结果与上述合并情况无异。

**点评/变式**
- **核心难点**：几何条件（切线、定角）与圆锥曲线定义的无缝衔接，辅以三角计算。
- **变式训练**：将“切线”条件换成“过焦点作 $60^\circ$ 的直线”，余弦值换成其他值，思路类似：以焦点三角形为突破口，联立定义与正余弦定理。

### **题目**（2020-理-19 / 文-19）
椭圆 $C_1: \frac{x^2}{a^2} + \frac{y^2}{b^2}=1$ 与抛物线 $C_2$ 共焦点 $F$，过 $F$ 垂直于 $x$ 轴的弦分别为 $AB, CD$，且 $|CD| = \frac{4}{3}|AB|$。（1）求 $C_1$ 的离心率。

**思路**
由共焦点可知 $C_2$ 方程可设为 $y^2=4cx$。通径长可直接用公式表达，竖直线交抛物线弦长也是通径，由此建立等量关系直接求 $e$。

**步骤**
1. **设方程**：$C_1$ 焦点 $F(c,0)$，$C_2$ 为 $y^2=4cx$。
2. **算弦长**：
    - $|AB|$ 是椭圆通径，长 $=\frac{2b^2}{a}$。
    - $|CD|$ 是抛物线过焦点的弦，将 $x=c$ 代入 $y^2=4cx$ 得 $y=\pm 2c$，长 $=4c$。
3. **建等式**：由 $|CD| = \frac{4}{3}|AB|$ 得 $4c = \frac{4}{3} \cdot \frac{2b^2}{a}$，化简 $c = \frac{2b^2}{3a}$。
4. **化简求 $e$**：代入椭圆 $b^2 = a^2 - c^2$：$3ac = 2(a^2-c^2)$，同除 $a^2$：$3e = 2(1-e^2)$。
整理得 $2e^2 + 3e - 2 = 0$，即 $(2e-1)(e+2)=0$。因 $e>0$，故 $e = \frac{1}{2}$。

**点评/变式**
- **容易错点**：抛物线通径误记为 $\frac{a}{b}$ 等形式，一定要熟记抛物线 $y^2=2px$ 的通径为 $2p$，本题 $p=2c$ 故通径为 $4c$。
- **拓展**：若抛物线开口方向变为上下，同理只用通径建等式即可。
