## 知识精要
- **平面的基本性质**  
  公理1：若直线上的两点在平面内，则直线在平面内。  
  公理2：不共线的三点确定一个平面。  
  公理3：若两个不重合的平面有一个公共点，则它们存在过该点的一条公共直线。  
  推论：两两相交且不过同一点的三条直线必在同一平面内。
- **空间直线、平面的位置关系**  
  线线关系：相交、平行、异面（不相交也不平行）。  
  线面关系：直线在平面内、直线与平面平行、直线与平面相交（含垂直）。  
  面面关系：平行、相交（含垂直）。
- **平行与垂直的判定与性质**  
  线面垂直判定：一条直线垂直于平面内两条相交直线，则该直线垂直于平面。  
  线面垂直性质：若直线垂直平面，则垂直于平面内所有直线。  
  面面垂直判定：一个平面过另一个平面的垂线，则两面垂直。  
  面面平行判定：一个平面内的两条相交直线分别平行于另一个平面。
- **空间向量与坐标法**  
  建立空间直角坐标系，利用点坐标和法向量解决位置关系与夹角问题。  
  两平面垂直 $\Leftrightarrow$ 法向量数量积为零。  
  两平面平行 $\Leftrightarrow$ 法向量平行（成比例）。
- **几何体的结构与度量**  
  正方体、长方体、正四棱锥、正三棱柱等的基本性质（棱长、对角线、面的形状）。  
  面积与体积公式：$V_{锥}=\frac{1}{3}Sh$, $V_{柱}=Sh$, $S_{球}=4\pi R^2$, $V_{球}=\frac{4}{3}\pi R^3$。  
  球的截面性质：球心与截面圆圆心连线垂直于截面；两截面圆公共弦的中垂线关联球心与两圆心，矩形的对角线相等。

## 解题方法与套路
1. **直观判断与性质推证法**  
   - 遇正方体、长方体等典型模型，优先考虑已知的结构性质（如体对角线垂直面、面对角线垂直等）。  
   - 证明垂直：通常利用线面垂直判定，寻找两条相交直线均与目标线垂直，尤其善用正方形对角线、等腰三角形三线合一等。  
   - 证明平行：利用中位线、平行四边形、传递性等。

2. **空间向量坐标法（万能解法）**  
   - 步骤：选原点 → 建系（尽量使坐标简单） → 设棱长 → 写出相关点坐标 → 求平面法向量 → 通过法向量关系判断位置关系或计算角。  
   - 判断面面垂直：法向量内积为0；面面平行：法向量共线。  
   - 求线面角、二面角：利用方向向量与法向量的夹角公式，注意角度的锐钝与绝对值。

3. **折叠与展开问题**  
   - 折叠前后不变性：平面内的长度、角度不变；折痕两侧的平面图形保真。垂直关系可能延续（折痕处的垂直关系）。  
   - 证明垂直：折叠后，若折前某线段垂直于折痕，则折后其与折痕所在直线的垂直关系保持，进而可推导线面垂直。

4. **球与截面的处理**  
   - 抓住球心到截面圆的距离、截面圆半径、球半径的垂径定理关系：$d^2+r^2=R^2$。  
   - 多截面关联时，将球心、两圆心、公共弦中点构成矩形或直角三角形，利用平几关系求圆心距。

5. **新定义与信息题**  
   - 冷静读题，提取几何体特征（对称性、顶点在正方体表面等），转化为常规的平面或立体几何计算。  
   - 半正多面体等，常用正方体为外框，通过俯视或对称性建立方程求解棱长。

## 高频易错
- **混淆判定条件**：线面垂直判定必须是垂直于面内“两条相交直线”，只垂直于两条平行直线无法断定。  
- **异面直线的误解**：“两条直线不相交则平行”错误，空间中还有异面情形。  
- **三点确定平面的条件遗漏**：经过空间中任意三点不一定确定唯一平面，当三点共线时有无数个平面。  
- **向量法计算粗心**：求法向量时方程组列错或计算失误导致误判；判断垂直/平行时忽略数量积为零的符号精确性；求二面角未区分锐角或钝角导致符号错误。  
- **折叠问题中不变性与变化混淆**：折叠后某些垂直关系消失，判断时未分析折痕是否保持垂直，导致错误推导线面关系。  
- **球截面问题中矩形误用**：两截面圆的圆心距常错误等于球心到公共弦距离，实际上应为矩形的对角线（$\sqrt{2^2-1^2}=\sqrt{3}$，圆心距等于$\sqrt{3}$，不是1之类的）。  
- **类比推理不严谨**：将平面平行四边形的性质类比到平行六面体时，需确保条件充分且必要，不能仅形式上仿写。

## 代表题精讲
### **题目**  2022年全国卷文科第9题（理第7题）
在正方体 $ABCD-A_1B_1C_1D_1$ 中，$E,F$ 分别为 $AB,BC$ 的中点，判断所给选项中的面面关系。

**思路**  
直观发现 $EF\parallel AC$，又 $AC\perp BD$ 且 $DD_1\perp\text{底面}$，可证 $EF\perp\text{平面}BDD_1$，得到面面垂直直接选出A。其余选项可用坐标法验证排除。

**步骤**  
1. 连接 $AC,BD$。在正方形 $ABCD$ 中，$AC\perp BD$。  
2. 由 $E,F$ 为中点，得 $EF\parallel AC$，故 $EF\perp BD$。  
3. 正方体中 $DD_1\perp\text{平面}ABCD$，$EF\subset\text{底面}$，故 $DD_1\perp EF$。  
4. $BD\cap DD_1=D$，则 $EF\perp\text{平面}BDD_1$。又 $EF\subset\text{平面}B_1EF$，得面 $B_1EF\perp\text{面}BDD_1$，A正确。  
5. 对B、C、D，可建系 $D(0,0,0), A(2,0,0), B(2,2,0), D_1(0,0,2)$，求出各面法向量验证（过程略）。

**点评/变式**  
正方体模型是重要载体，利用“面对角线垂直”“体对角线与面对角线关系”等结论可快速破题。坐标法适用于所有选项的彻底排查，但优先观察典型垂直结构可节省时间。变式：将中点改为三等分点，或考察线面角、二面角，方法相通。

### **题目**  2020年全国卷理科第16题
设有四个命题 $p_1$:两两相交且不过同一点的三条直线必在同一平面内；$p_2$:过空间中任意三点有且仅有一个平面；$p_3$:若空间两条直线不相交，则这两条直线平行；$p_4$:若直线 $l\subset\alpha$，直线 $m\perp\alpha$，则 $m\perp l$。判断复合命题的真假（找出所有真命题的序号）。

**思路**  
逐一判定简单命题的真假，再用复合命题逻辑真值表计算。

**步骤**  
1. **$p_1$ 真**：设 $l_1\cap l_2=A$ 确定平面 $\alpha$，$l_3$ 与 $l_1,l_2$ 分别交于另两点 $B,C$，则 $B,C\in\alpha$，故 $l_3\subset\alpha$。  
2. **$p_2$ 假**：当三点共线时，过这三点的平面有无数个。  
3. **$p_3$ 假**：空间直线不相交可能平行也可能异面。  
4. **$p_4$ 真**：线面垂直的性质，垂直于平面的直线垂直于平面内任意直线。  
5. 评价复合命题：① $p_1\lor p_4$ 真；② $p_1\lor p_2$ 真（但题干为 $p_1p_2\land$？原题符号 $p_1p_2\land$ 是 $p_1\land p_2$，假）；③ $¬p_2\lor p_3$ 真（$¬p_2$ 真，故或真）；④ $¬p_3\lor ¬p_4$ 真（$¬p_3$ 真）。所以真命题序号为①③④。

**点评/变式**  
本题表面考逻辑，实则考查立体几何公理与公理的适用条件，是“陷阱题”。典型失分点：忽视公理2“不共线”条件，混淆异面与平行概念。备考中需精准记忆每个定理的前提。变式：给出推理填空或改编为截面问题，不变的是对基础概念的严格考查。
