## 知识精要
- **等差中项核心性质**：在等差数列 $\{a_n\}$ 中，若 $m+n=p+q$（$m,n,p,q\in \mathbb{N}^*$），则 $a_m + a_n = a_p + a_q$。
  特别地，当 $m+n=2k$ 时，有 $a_m + a_n = 2a_k$，即 $a_k$ 为 $a_m$ 与 $a_n$ 的等差中项。
- **前 $n$ 项和与等差中项的转化**：对于等差数列的前 $n$ 项和 $S_n$，若 $n$ 为奇数，设 $n=2k-1$，则
  $$S_{2k-1} = \frac{(2k-1)(a_1+a_{2k-1})}{2} = (2k-1)a_k.$$
  这是等差中项性质在求和中的直接应用，将“和”转化为“中间项”的倍数，大幅简化运算。
- **适用条件**：数列必须是等差数列（或已知条件可推出该性质）。常配合下标和相等使用，无需解出首项与公差。

## 解题方法与套路
1. **识别下标关系**：观察所求式子与已知条件中项的下标，寻找和为常数的配对。  
   - 如题中出现 $a_5$ 与 $a_3$，涉及 $S_9$ 和 $S_5$，立刻联想到 $9=2\times5-1$，$5=2\times3-1$。  
2. **化“和”为“项”**：利用 $S_{2k-1} = (2k-1)a_k$，将前若干项和直接替换为中间项的倍数。  
   - $S_9 = 9a_5$，$S_5 = 5a_3$。  
3. **代入已知等量关系**：将已知的项间关系（如 $a_5=5a_3$）代入转化后的表达式，直接得出比值等结果。  
4. **检验下标边界**：确保项的下标为正整数，且奇数下标对应奇数和形式，避免错用公式。

## 高频易错
- **混淆中项对应关系**：误认为 $S_n$ 总能写成 $n\cdot a_{\frac{n}{2}}$ 或 $n\cdot a_{\frac{n+1}{2}}$。  
  → 只有 $n$ 为奇数时，中项才唯一且为 $a_{\frac{n+1}{2}}$（如 $S_9$ 的中项是 $a_5$，因为 $\frac{9+1}{2}=5$）。  
- **下标计算偏移**：将 $S_5$ 误写成 $5a_2$ 或 $5a_4$。  
  → 记牢公式：$S_{2m-1} = (2m-1)a_m$，令 $2m-1=5$，则 $m=3$，所以中项为 $a_3$。  
- **性质使用条件忽略**：将等差中项性质直接用于非等差数列，或随便推广到等比数列。  
  → 等比数列有类似的外项积等于中间项平方的性质，而非和相等。  
- **比值计算丢分母**：在最后一步 $\frac{S_9}{S_5} = \frac{9a_5}{5a_3}$ 时，忘记同时代入 $a_5=5a_3$，或约分时误将系数约错。  
  → 严格代入：$\frac{9\times5a_3}{5a_3}=9$，系数 5 会约掉。

## 代表题精讲
### **题目**（2009-理-14）
设等差数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $a_5=5a_3$，则 $\displaystyle\frac{S_9}{S_5}=$ ______。

**思路**  
目标求 $S_9$ 与 $S_5$ 的比值，避免直接设首项和公差列方程组。注意到 $9=2\times5-1$，$5=2\times3-1$，均为奇数，可借助等差中项性质将 $S_9$、$S_5$ 分别转化为 $9a_5$ 和 $5a_3$，从而直接利用已知条件 $a_5=5a_3$ 求解。

**步骤**  
1. 利用奇数项和的等差中项形式：  
   $S_9 = 9a_5$（因为 $9=2\times5-1$，中项为 $a_5$），  
   $S_5 = 5a_3$（因为 $5=2\times3-1$，中项为 $a_3$）。  
2. 写出比值并代入已知等式：  
   $\displaystyle\frac{S_9}{S_5} = \frac{9a_5}{5a_3}$。  
3. 将 $a_5 = 5a_3$ 代入：  
   $\displaystyle\frac{9a_5}{5a_3} = \frac{9\times5a_3}{5a_3} = 9$。  
4. 故结果为 $9$。

**点评/变式**  
此题是等差中项性质在求和比值的直接应用，关键一步在于识别下标 $9$ 与 $5$、$5$ 与 $3$ 的关联。  
**变式1**：条件改为 $a_3+a_7=10$，求 $S_9$。则利用 $a_3+a_7=2a_5$ 得 $a_5=5$，从而 $S_9=9a_5=45$。  
**变式2**：求 $\frac{a_5}{a_3}$ 已知时，也可反求 $\frac{S_{11}}{S_7}$ 等，遵循相同套路：$S_{11}=11a_6$，但 $a_6$ 与已知项关系需通过公差或中项链推导，注意不要机械套用，需先观察下标和是否与已知项建立联系。
