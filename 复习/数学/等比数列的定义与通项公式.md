## 知识精要
- **等比数列定义**：从第 2 项起，每一项与前一项的比等于同一个常数（公比 $q \neq 0$），即 $\dfrac{a_{n+1}}{a_n}=q$（$n \in \mathbb{N}^*$），且 $a_1 \neq 0$。
- **通项公式**：$a_n = a_1 q^{n-1}$。推导方法：累乘法。
- **等比中项**：若 $a, G, b$ 成等比数列，则 $G^2 = ab$（$ab>0$）。
- **构造等比模型**：  
  对于 $a_{n+1} = p a_n + q$（$p \neq 0,1$，$q \neq 0$），可引入待定常数 $\lambda$，  
  令 $a_{n+1} + \lambda = p(a_n + \lambda)$，解得 $\lambda = \dfrac{q}{p-1}$。  
  新数列 $\{a_n + \lambda\}$ 是以 $a_1+\lambda$ 为首项、$p$ 为公比的等比数列。  
  特别地，若 $p=1$，则 $\{a_n\}$ 为等差数列。
- **等比数列求和公式**（$q \neq 1$）：$S_n = \dfrac{a_1(1-q^n)}{1-q}$。

## 解题方法与套路
1. **判定或证明等比数列**  
   - 定义法：证明 $\dfrac{a_{n+1}}{a_n}=常数$，且首项 $\neq 0$。  
   - 通项构造法：对于 $a_{n+1}=p a_n + q$，采用待定系数法化为 $a_{n+1}+\lambda = p(a_n+\lambda)$，得到等比数列。

2. **求通项公式的通用步骤**  
   (1) 由递推关系确定 $\lambda$；  
   (2) 写出新等比数列 $\{a_n+\lambda\}$ 的通项；  
   (3) 反解出 $a_n$ 的通项。  
   例题中：$a_{n+1}=3a_n+1 \Rightarrow \lambda=\frac{1}{2}$，得 $a_n+\frac12$ 以 3 为公比等比。

3. **求和不等式的证明**  
   - 目标：证明 $\sum \frac{1}{a_k} < C$。  
   - 常见手段：放缩为等比数列求和。通常保持方向一致（如将分母“适当放大”使分式变小，或分母“适当缩小”使分式变大，并确保形成等比）。  
   - 本题放缩：$\frac{1}{a_n} = \frac{2}{3^n - 1} \le \frac{1}{3^{n-1}}$（或更精细的放缩），再整体求和利用等比求和公式。

4. **书写规范**  
   - 证明等比时需注明首项非零且公比常数；  
   - 放缩环节要指明放大或缩小的依据，检验方向与不等号一致；  
   - 求和时注意项数为 $n$，求和公式指数对应正确。

## 高频易错
- **常数 $\lambda$ 计算错误**：$a_{n+1}=p a_n + q$ 中，$\lambda = \frac{q}{p-1}$（分母是 $p-1$，不是 $1-p$）。错例：把 $\lambda$ 当成 $q/(1-p)$。  
- **忽视首项检验**：仅推得 $a_{n+1}+\lambda = p(a_n+\lambda)$，未指明 $a_1+\lambda \neq 0$，导致扣逻辑分。  
- **构造对象混淆**：最终求 $\{a_n\}$ 通项时忘记减去 $\lambda$，直接写出新数列通项当作原数列。  
- **等比求和时项数出错**：$\sum_{k=1}^n r^{k-1} = \frac{1-r^n}{1-r}$，误写成 $n+1$ 项。  
- **放缩方向反了**：欲证 $\sum \frac{1}{a_k} < C$，把 $\frac{1}{a_n}$ 放大（即分母缩小），得到更大的和，无法证明原不等式。正确应保证放缩后每一项 $\ge$ 原项或严格大小关系可传递。本题常规做法是放缩为等比数列后求和，需确保放缩后每一项不小于原分式吗？注意：欲证 $S < C$，应找上界，即 $S \le T < C$，$T$ 放缩后各项应 $\ge$ 原项，但求和后 $< C$。典型错：把 $\frac{1}{a_n}$ 缩小了，得到更小的和，并不能推出原和小于某值。  
- **忽略 $n$ 的起始值**：放缩应从 $n=1$ 或 $n=2$ 开始，需保证每一步均成立。

## 代表题精讲
**题目**（2014 全国·理 17）  
数列 $\{a_n\}$ 满足 $a_1=1$，$a_{n+1}=3a_n+1$。  
（Ⅰ）证明 $\{a_n+\frac12\}$ 是等比数列，并求 $\{a_n\}$ 的通项公式；  
（Ⅱ）证明 $\frac1{a_1}+\frac1{a_2}+\cdots+\frac1{a_n} < \frac32$。

**思路**  
（Ⅰ）递推形如 $a_{n+1}=3a_n+1$，用待定系数法构造等比。由 $a_{n+1}+\lambda = 3(a_n+\lambda)$，解得 $\lambda = \frac12$。  
（Ⅱ）求出 $a_n = \frac{3^n-1}{2}$，则 $\frac1{a_n} = \frac{2}{3^n-1}$。为证和小于 $\frac32$，可放缩为等比数列求和。注意到 $\frac{2}{3^n-1} \le \frac{1}{3^{n-1}}$（$n\ge 1$），累加后用等比求和公式即得。

**步骤**  
（Ⅰ）  
设 $a_{n+1}+\lambda = 3(a_n+\lambda)$，展开得 $a_{n+1}=3a_n+2\lambda$。  
与 $a_{n+1}=3a_n+1$ 对比，得 $2\lambda=1 \Rightarrow \lambda=\frac12$。  
于是 $a_{n+1}+\frac12 = 3\left(a_n+\frac12\right)$，且 $a_1+\frac12 = \frac32 \neq 0$。  
故 $\{a_n+\frac12\}$ 是首项为 $\frac32$，公比为 $3$ 的等比数列。  
通项：$a_n+\frac12 = \frac32 \cdot 3^{n-1} = \frac{3^n}{2}$，  
所以 $a_n = \frac{3^n - 1}{2}$。

（Ⅱ）  
由 (Ⅰ) 知 $a_n = \frac{3^n-1}{2}$，则 $\frac1{a_n} = \frac{2}{3^n-1}$。  
当 $n \ge 1$ 时，$3^n-1 \ge 2\cdot 3^{n-1}$（可简单放缩：$3^n-1 = 3\cdot 3^{n-1}-1 \ge 2\cdot 3^{n-1}$，对于 $n=1$ 也成立），  
因此 $\frac{2}{3^n-1} \le \frac{2}{2\cdot 3^{n-1}} = \frac{1}{3^{n-1}}$。  
于是  
$$
\sum_{k=1}^n \frac1{a_k} \le 1 + \frac13 + \frac1{3^2} + \cdots + \frac1{3^{n-1}} = \frac{1-\frac1{3^n}}{1-\frac13} = \frac32\left(1-\frac1{3^n}\right) < \frac32.
$$
不等式得证。

**点评/变式**  
- 本题是“一次线性递推”构造等比数列求通项的典型范例，务必熟练掌握待定系数法。  
- 放缩技巧：将分式放大为等比数列的通项，利用求和公式得到常数界。注意验证放缩从 $n=1$ 起成立，若 $n=1$ 不成立，可单独验证后从 $n\ge2$ 放缩再合并。  
- **变式**：若递推改为 $a_{n+1}=3a_n+2$，则 $\lambda=1$，等比对象为 $\{a_n+1\}$。  
- **拓展**：若证 $\sum \frac1{a_k} >$ 某个值，则需缩小分母，构造更大的等比（或裂项）进行求和。
