## 知识精要
- **终边相同的角**：所有与角 $\alpha$ 终边相同的角，可表示为 $\theta = \alpha + 2k\pi\ (k\in\mathbb{Z})$。若角 $\theta$ 的终边在直线 $y=kx$ 上，则 $\tan\theta = k$，但需明确角可位于两个不同象限（$\theta$ 与 $\pi+\theta$ 终边均在该直线上）。
- **任意角三角函数定义**：设角 $\theta$ 终边上一点 $P(x,y)$，$|OP|=r=\sqrt{x^2+y^2}$，则 $\sin\theta=\dfrac{y}{r}$，$\cos\theta=\dfrac{x}{r}$，$\tan\theta=\dfrac{y}{x}$（$x\neq0$）。
- **同角商数关系**：$\tan\theta = \dfrac{\sin\theta}{\cos\theta}$。
- **二倍角公式**：$\cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta = \dfrac{1-\tan^2\theta}{1+\tan^2\theta}$。特别地，用 $\tan\theta$ 表达的“万能公式”在此类题型中可直接使用。
- **适用条件**：已知角终边直线斜率时，可设 $\tan\theta$，代入 $\cos2\theta$ 的含切表达式快速求值。

## 解题方法与套路
1. **化斜率为正切**：由终边所在直线 $y=kx$，直接得到 $\tan\theta = k$。注意直线过原点、不含截距，斜率即角的正切。
2. **选用二倍角公式**：已知 $\tan\theta$ 求 $\cos2\theta$，优先使用 $\cos2\theta = \dfrac{1-\tan^2\theta}{1+\tan^2\theta}$，避免求 $\sin\theta,\cos\theta$ 的符号讨论。
3. **代值化简**：将斜率 $k$ 代入上述公式，化简即得结果。
4. **符号检验（可选）**：若使用 $\sin\theta,\cos\theta$ 求解，需根据终边所在象限确定符号，但利用正切表达式可自动包含符号。

## 高频易错
- **混淆终边与直线**：终边在直线 $y=2x$ 上包含两个互为反向延长线的射线，对应 $\tan\theta = 2$ 恒成立，但 $\theta$ 的象限不确定，直接用 $\sin\theta,\cos\theta$ 时有正负取舍风险。
- **误判直线倾斜角**：错误地将直线倾斜角直接等同于 $\theta$ 的一个值，而忽略角 $\theta$ 可能相差 $\pi$ 的整数倍，导致周期理解偏差。
- **公式使用不当**：用 $\cos2\theta = 2\cos^2\theta - 1$ 时，需先求 $\cos^2\theta$，由 $\tan\theta$ 得 $\cos^2\theta = \dfrac{1}{1+\tan^2\theta}$，容易在代换时漏掉系数或平方。
- **数值计算粗心**：代入 $k=2$ 时，$\cos2\theta = \dfrac{1-4}{1+4} = -\dfrac{3}{5}$，有考生可能错误计算为 $\dfrac{1-2}{1+2}$ 等形式。

## 代表题精讲
**题目**（2011 理 05）：已知角 $\theta$ 的顶点与原点重合，始边与 $x$ 轴正半轴重合，终边在直线 $y=2x$ 上，求 $\cos2\theta$。

**思路**：由终边在直线上得 $\tan\theta = 2$，直接代入二倍角的万能公式 $\cos2\theta = \dfrac{1-\tan^2\theta}{1+\tan^2\theta}$ 即得。

**步骤**：
1. 由终边所在直线 $y=2x$ 得 $\tan\theta = 2$。
2. 代入公式：$\cos2\theta = \dfrac{1-\tan^2\theta}{1+\tan^2\theta} = \dfrac{1-2^2}{1+2^2} = \dfrac{1-4}{1+4} = -\dfrac{3}{5}$。

**点评/变式**：此题直击“终边在直线上”与“正切值”的等价关系，无需讨论象限，切入点是万能公式的熟练运用。变式可问 $\sin2\theta$ 或 $\tan2\theta$，同样用正切表达，如 $\tan2\theta = \dfrac{2\tan\theta}{1-\tan^2\theta}$；也可将直线改为 $y = -3x$，方法完全一致。
