## 知识精要
- **用样本估计总体**
  - **平均数估计**：总体均值的无偏估计为样本均值 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n}x_i$；总体总量的估计为 $\hat{T} = N \cdot \bar{x}$（$N$ 为总体单元数）。
  - **相关系数**：变量 $x$ 与 $y$ 的样本线性相关程度用 Pearson 相关系数度量：
    $$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2} \sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}$$
    $|r| \le 1$，$r>0$ 正相关，$r<0$ 负相关，$|r|$ 越接近 $1$，线性关系越强。
  - **抽样方法适用条件**：简单随机抽样适用于总体差异不大；若总体内部差异显著（如各地块植物覆盖面积差异很大），应采用分层抽样，按差异特征分层，以提高样本代表性。

- **频率估计概率**
  - 在大量重复试验或统计中，事件 $A$ 的概率可用其频率的加权平均来估计：$P(A) \approx \frac{\sum (\text{频数} \times \text{频率})}{\text{总频数}}$。
  - 平均正点率等指标是加权平均数，而非简单算术平均。

- **统计图表的识读**
  - 柱形图（条形图）反映数量随时间的变化，通过柱高比较增减趋势。
  - 正相关：一个变量增加，另一个变量也增加（散点呈上升趋势）；负相关：一个变量增加，另一个变量减少。与年份的“正相关”指随时间推移数值上升。

## 解题方法与套路
1. **总量估计问题**（如2020理18(1)）  
   步骤：计算样本均值 $\bar{y} = \frac{1}{n}\sum y_i$ → 总体总量估计值 = 总体单元数 × 样本均值。

2. **相关系数计算**（如2020理18(2)）  
   步骤：识别或计算 $\sum(x_i-\bar{x})^2$、$\sum(y_i-\bar{y})^2$、$\sum(x_i-\bar{x})(y_i-\bar{y})$ → 代入公式 $r = \frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sqrt{\sum(x_i-\bar{x})^2 \cdot \sum(y_i-\bar{y})^2}}$ → 算出数值并按要求精确度取值。

3. **优化抽样方法**（如2020理18(3)）  
   步骤：指出原抽样方法的局限（如简单随机抽样忽略层内差异） → 提出改进方法（分层抽样） → 说明理由：各层差异大，分层抽样使各层都有代表，降低估计误差。

4. **频率加权估计概率**（如2019文14/理13）  
   步骤：计算各部分的“正点次数”：车次数 × 正点率 → 求和得总正点次数 → 总车次数求和 → 平均正点率 = 总正点次数 ÷ 总车次数。注意：结果保留两位小数或题目要求。

5. **统计图表结论判断题**（如2015理03）  
   步骤：逐项看图验证 → 关注“逐年比较”“趋势”“相关性”措辞 → 正相关意味着指标随年份增加而增加，若指标下降则为负相关。

## 高频易错
- **混淆相关方向**：把“逐年减少”说成“正相关”。实际年份增大、排放量下降，应为“负相关”。
- **相关系数符号遗漏**：计算中分子项 $\sum(x_i-\bar{x})(y_i-\bar{y})$ 的正负决定 $r$ 符号，切勿只取绝对值。
- **简单随机抽样万能论**：当总体各单元差异明显时仍用简单随机抽样，导致样本代表性差；应改用分层抽样。
- **频率估计概率的精确性误认**：用样本频率估计概率得到的是**估计值**，不是精确值；题目常要求填写估计值，忽视“约”“估计”易失分。
- **加权与简单平均混淆**：多个不同基数的率求总平均时，必须用加权平均（权数为车次或其他频数），直接算术平均会导致错误。
- **图表顺序误读**：柱形图横轴通常是时间，务必看清年份顺序，不要将早期的数字与晚期比较时错误连接趋势。

## 代表题精讲
### **题目1** （2020全国卷理18）  
**题目**：某地区200个地块用简单随机抽样抽20个样区，得到植物覆盖面积$x_i$和野生动物数量$y_i$。已知 $\sum x_i = 160$, $\sum y_i = 1200$, $\sum(x_i-\bar{x})^2 = 80$, $\sum(y_i-\bar{y})^2 = 9000$, $\sum(x_i-\bar{x})(y_i-\bar{y}) = 800$。  
(1) 求该地区这种野生动物数量的估计值（等于样区平均数×地块数）；  
(2) 求样本相关系数（精确到0.01）；  
(3) 各地块植物覆盖面积差异很大，为提高代表性，给出更合理抽样方法并说明理由。  

**思路**：(1) 样区动物数量平均数 $\bar{y}=1200/20=60$，总量估计为 $200\times60$。  
(2) 已给三个平方和及乘积和，直接代入公式求 $r$，注意 $\sqrt{2}\approx1.414$ 可简化。  
(3) 差异大→分层抽样，按植物覆盖面积分层，各层独立抽样。

**步骤**：  
(1) $\bar{y}=\frac{1200}{20}=60$，估计总数 $=200 \times 60 = 12000$。  
(2) $r = \frac{800}{\sqrt{80 \times 9000}} = \frac{800}{\sqrt{720000}} = \frac{800}{600\sqrt{2}} = \frac{4}{3\sqrt{2}} = \frac{2\sqrt{2}}{3} \approx \frac{2\times1.414}{3} \approx 0.943$，精确到0.01得 $0.94$。  
(3) 采用分层抽样。将200个地块按植物覆盖面积大小分成若干层，每层按比例抽取样本；这样各层均有代表，可减少由于覆盖面积差异引起的抽样误差，使野生动物数量的估计更准确。

**点评/变式**：总量估计关键在于正确使用“平均数×总体单位数”。相关系数计算中给定了中间结果，直接代入；若没有给定，需自己求均值再算离差。分层抽样的表述要明确分层依据和操作。

### **题目2** （2019全国卷文14/理13）  
**题目**：经停某站的高铁列车，10个车次正点率0.97，20个车次正点率0.98，10个车次正点率0.99，求该站所有车次平均正点率的估计值。  

**思路**：本质上是一个加权平均问题：正点率估计值 = 总正点列数 ÷ 总列数。

**步骤**：  
总正点列数 ≈ $10\times0.97 + 20\times0.98 + 10\times0.99 = 9.7 + 19.6 + 9.9 = 39.2$，总车次 $=40$，平均正点率估计值 $= 39.2 / 40 = 0.98$。

**点评/变式**：此题虽短，但体现出“频率稳定于概率”的统计思想，且强调加权。若误用 $(0.97+0.98+0.99)/3 = 0.98$ 得巧合正确，但遇见不同权数时会出错，必须养成计算加权平均的习惯。变式可改变各组车次数，仍按总正点数除以总车次处理。
