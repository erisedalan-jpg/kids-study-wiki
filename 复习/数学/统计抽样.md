## 知识精要
- **样本平均数**：设有 $n$ 个数据 $x_1, x_2, \dots, x_n$，则样本平均数 $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$。对二维样本 $(x_i,y_i)$，同理可得 $\bar{y}$。
- **样本相关系数**：描述两个变量间线性相关程度的量。
  $$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$
  等价计算式（适于直接利用给定和式）：
  $$r = \frac{\sum x_i y_i - n\bar{x}\bar{y}}{\sqrt{\left(\sum x_i^2 - n\bar{x}^2\right)\left(\sum y_i^2 - n\bar{y}^2\right)}}$$
  $|r| \le 1$；$|r|$ 越接近 $1$，线性相关越强。
- **比例估计（回归过原点）**：若已知两变量近似成正比 $y = kx$，可利用样本回归过原点的思想，用平均值或总和之比估计比例系数：$\hat{k} = \frac{\bar{y}}{\bar{x}} = \frac{\sum y_i}{\sum x_i}$。已知总体 $X$ 总和 $T_x$，总体 $Y$ 总量的估计值为 $\hat{T}_y = \hat{k} \cdot T_x$。

## 解题方法与套路
1. **求样本平均数**：直接利用定义式 $\bar{x} = \frac{1}{n}\sum x_i$，$\bar{y} = \frac{1}{n}\sum y_i$。若题目已给出总和，直接除以 $n$。
2. **求样本相关系数**：
   - 优先识别题目给出的和式 $\sum x_i^2$、$\sum y_i^2$、$\sum x_i y_i$ 等，直接代入变形公式。
   - 若未全部直接给出，先算出 $\bar{x},\bar{y}$，再计算 $\sum(x_i-\bar{x})^2$ 等。
   - 计算时保留足够中间精度，最后按要求“精确到 0.01”四舍五入。
3. **比例关系下的总体估计**：
   - 根据“$y$ 与 $x$ 近似成正比”，利用样本求出比例系数 $\hat{k} = \frac{\bar{y}}{\bar{x}}$ 或 $\frac{\sum y_i}{\sum x_i}$（两者等价）。
   - 用 $\hat{k} \times$（总体 $x$ 总和） 即得总体 $y$ 总量的估计值。
   - 注意单位，不重复换算。

## 高频易错
- **相关系数公式用错**：漏掉分母的根号，或混淆 $\sum x_i^2$ 与 $(\sum x_i)^2$。必须分清：$\sum (x_i - \bar{x})^2 = \sum x_i^2 - \frac{1}{n}(\sum x_i)^2$。
- **计算精度丢失**：求 $r$ 时分步计算导致舍入误差累积，最后结果偏差。应尽量使用给定和式直接算分子、分母，最后一步再开方相除。
- **比例系数估计混乱**：第三问中比例系数可用 $\frac{\sum y_i}{\sum x_i}$ 直接得到，但有人误用 $\frac{\sum (y_i/x_i)}{n}$ 或回归系数等。题干明确“近似成正比”且没有截距，应使用过原点的比值。
- **精确度遗漏**：题目明确“精确到 0.01”，结果未四舍五入或保留位数不对。
- **数据抄错**：表格数据与计算和式之间抄错行；误将 $0.038$ 等当作 $\sum x_i^2$ 或 $\sum x_i y_i$，须对照题干说明。

## 代表题精讲
**题目**（2022-文-19）：给出10棵树木的根部横截面积 $x_i$ 与材积量 $y_i$，以及 $\sum x_i=0.6$，$\sum y_i=3.9$，$\sum x_i^2=0.038$，$\sum y_i^2=1.6158$，$\sum x_i y_i=0.2474$。（1）估计平均根部横截面积与平均材积量；（2）求样本相关系数（精确到 0.01）；（3）已知林区所有树木根部横截面积总和 $186\,\text{m}^2$，材积量与根部横截面积近似成正比，估计总材积量。

**思路**：（1）直接用样本均值公式；（2）代入相关系数的和式变形公式计算；（3）利用比例关系：比例系数 $\hat{k} = \bar{y}/\bar{x}$，总材积量 $=\hat{k} \times 186$。

**步骤**：
（1）$\bar{x} = \frac{0.6}{10} = 0.06\,(\text{m}^2)$，$\bar{y} = \frac{3.9}{10} = 0.39\,(\text{m}^3)$。
（2）计算所需中间量：
$n\bar{x}\bar{y} = 10 \times 0.06 \times 0.39 = 0.234$；
分子：$\sum x_i y_i - n\bar{x}\bar{y} = 0.2474 - 0.234 = 0.0134$；
分母第一项：$\sum x_i^2 - n\bar{x}^2 = 0.038 - 10\times(0.06)^2 = 0.038 - 0.036 = 0.002$；
分母第二项：$\sum y_i^2 - n\bar{y}^2 = 1.6158 - 10\times(0.39)^2 = 1.6158 - 1.521 = 0.0948$；
$r = \frac{0.0134}{\sqrt{0.002 \times 0.0948}} = \frac{0.0134}{\sqrt{0.0001896}} \approx \frac{0.0134}{0.01377} \approx 0.973 \approx 0.97$。
（3）由正比关系，$\hat{k} = \frac{\bar{y}}{\bar{x}} = \frac{0.39}{0.06} = 6.5$，
总材积量估计值 $= 6.5 \times 186 = 1209\,(\text{m}^3)$。

**点评/变式**：本题是统计抽样结合一元线性比例估计的典型题。相关系数虽与回归直线相关，但这里只考计算不考方程。第三问抓住“近似成正比”“总和已知”，用平均值之比是最快方法，也可用综合样本总量之比 $\frac{3.9}{0.6}=6.5$，结果一致。变式可能将正比改为一般线性回归 $y = a + bx$，则需先求出回归方程，再代入总体 $x$ 总和进行估计。
