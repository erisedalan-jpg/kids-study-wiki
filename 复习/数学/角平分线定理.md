## 知识精要
**三角形内角平分线定理**：在 $\triangle ABC$ 中，若 $AD$ 平分 $\angle BAC$ 且交 $BC$ 于 $D$，则  
$$
\frac{BD}{DC} = \frac{AB}{AC}.
$$  
即角平分线将对边分成的两段与邻边成比例。  
- 证明思路：过 $C$ 作 $AD$ 的平行线交 $BA$ 延长线于 $E$，利用平行线分线段成比例及等腰三角形性质。  
- 适用条件：已知角平分线，求边之比；或已知边之比，证角平分线；常与正弦定理、余弦定理结合解三角形。  
- 变形：$BD = \frac{AB}{AB+AC}\cdot BC$，$DC = \frac{AC}{AB+AC}\cdot BC$；在 $\triangle ABD$ 和 $\triangle ACD$ 中，由正弦定理可得 $\frac{\sin \angle BAD}{\sin \angle B} = \frac{BD}{AB}$ 等关系，结合平分角可导出角的关系。

## 解题方法与套路
1. **识别关键条件**：题设出现“角平分线”并给出分线段长度或比例，立即联想内角平分线定理，将角平分转化为边比例 $\frac{BD}{DC} = \frac{AB}{AC}$。  
2. **设比例系数**：若已知 $BD:DC=m:n$，则设 $AB=mk$，$AC=nk$，再结合其他条件求解 $k$ 或角度。  
3. **联用正弦定理**：目标为求角的正弦值之比或角度时，先由角平分线定理得边比，再在 $\triangle ABC$ 中用正弦定理 $\frac{AB}{\sin C} = \frac{AC}{\sin B}$，得 $\frac{\sin B}{\sin C} = \frac{AC}{AB}$，与边比挂钩。  
4. **联用余弦定理**：若已知一边一角或求边长，利用边比设出两边长，配合夹角用余弦定理列方程。  
5. **整体步骤**：平移角度关系→转化边比→设出边长→解三角形（正弦/余弦）→回代求目标量。

## 高频易错
- **误用顶点顺序**：角平分线分对边所得两线段必须与邻边对应正确，即 $\frac{BD}{DC} = \frac{AB}{AC}$，不可颠倒为 $\frac{BD}{DC} = \frac{AC}{AB}$。  
- **忽略比例系数单位**：由比例设边长时，必须引入相同的比例系数 $k$，避免直接令 $AB=BD$ 等错误。  
- **角平分线长公式混淆**：内角平分线长 $AD^2 = AB\cdot AC - BD\cdot DC$ 非必考，若题目未要求切勿盲目代入，优先用比例定理。  
- **正弦定理对应错误**：由 $\frac{AB}{\sin C} = \frac{AC}{\sin B}$ 得到的是 $\frac{\sin B}{\sin C} = \frac{AC}{AB}$，而非 $\frac{AB}{AC}$，需与角平分线定理的边比配合时注意取倒数。  
- **忘记角度关系**：$AD$ 平分 $\angle A$，则 $\angle BAD = \angle CAD = \frac{1}{2}\angle A$，在解三角形时可直接使用。

## 代表题精讲
### 代表题：2015年高考文科数学全国卷 第17题  
**题目**：在 $\triangle ABC$ 中，$D$ 是 $BC$ 上的点，$AD$ 平分 $\angle BAC$，$BD=2DC$。  
（Ⅰ）求 $\frac{\sin B}{\sin C}$；  
（Ⅱ）若 $\angle BAC = 60^\circ$，求 $\angle B$。

**思路**：  
（Ⅰ）由 $AD$ 平分角和 $BD=2DC$，根据内角平分线定理得 $AB:AC = BD:DC = 2:1$，即 $AB=2AC$。再在 $\triangle ABC$ 中用正弦定理将边比转化为角的正弦比：$\frac{AB}{\sin C} = \frac{AC}{\sin B}$，变形即可求出 $\frac{\sin B}{\sin C}$。  
（Ⅱ）已知 $\angle A=60^\circ$，且 $\frac{\sin B}{\sin C} = \frac{1}{2}$（由（Ⅰ）结果），又 $\sin C = \sin(180^\circ - A - B) = \sin(120^\circ - B)$，代入得关于 $B$ 的方程，结合三角形内角和及角度范围解出 $B$。

**步骤**：  
（Ⅰ）  
1. 因为 $AD$ 平分 $\angle BAC$，由内角平分线定理得 $\frac{AB}{AC} = \frac{BD}{DC}$。  
2. 已知 $BD=2DC$，所以 $\frac{AB}{AC} = 2$，即 $AB = 2AC$。  
3. 在 $\triangle ABC$ 中由正弦定理 $\frac{AB}{\sin C} = \frac{AC}{\sin B}$。  
4. 代入 $AB=2AC$ 得 $\frac{2AC}{\sin C} = \frac{AC}{\sin B}$，消去 $AC$ 得 $\frac{2}{\sin C} = \frac{1}{\sin B}$。  
5. 所以 $\frac{\sin B}{\sin C} = \frac{1}{2}$。  

（Ⅱ）  
1. 由（Ⅰ）知 $\sin B = \frac{1}{2} \sin C$。  
2. 在 $\triangle ABC$ 中，$A+B+C=180^\circ$，又 $\angle A = 60^\circ$，所以 $C = 120^\circ - B$。  
3. 则 $\sin C = \sin(120^\circ - B) = \sin 120^\circ \cos B - \cos 120^\circ \sin B = \frac{\sqrt{3}}{2}\cos B + \frac{1}{2}\sin B$。  
4. 代入 $\sin B = \frac{1}{2} \left( \frac{\sqrt{3}}{2}\cos B + \frac{1}{2}\sin B \right)$，即 $\sin B = \frac{\sqrt{3}}{4}\cos B + \frac{1}{4}\sin B$。  
5. 移项得 $\frac{3}{4}\sin B = \frac{\sqrt{3}}{4}\cos B$，两边乘4得 $3\sin B = \sqrt{3}\cos B$，所以 $\tan B = \frac{\sqrt{3}}{3}$。  
6. 因为 $B$ 是三角形内角，且由 $\tan B = \frac{\sqrt{3}}{3}$ 得 $B = 30^\circ$（$0^\circ < B < 120^\circ$）。  

**点评/变式**：  
- 本题完美展示了角平分线定理与正弦定理的“接力”：先用角平分线定理得边比，再用正弦定理将边比转化为角的正弦比，是经典套路。  
- 第二问中构建关于 $B$ 的方程时，利用 $A+B+C=\pi$ 消去 $C$，是解三角形的基本操作，注意两角和差的正弦公式不要记错。  
- 变式：若将条件改为 $AD$ 平分 $\angle BAC$ 且 $\frac{\sin B}{\sin C}=k$，则可反推 $BD:DC$；若加入边长数据，则可求三角形面积等，核心均是先确立边比关系。
