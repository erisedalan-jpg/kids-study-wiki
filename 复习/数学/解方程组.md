## 知识精要
- **方程组定义**：由两个或两个以上方程构成的组合，用以求解多个未知数。在高考中，绝大部分方程组可通过**消元**化为一元方程求解。
- **核心方法**——消元：  
  $$ \begin{cases} 方程1 \\ 方程2 \end{cases} \xrightarrow{\text{代入消元 or 加减消元}} \quad \text{一元方程} $$
- **等差数列基本量方程组**：等差数列 $\{a_n\}$ 的核心量为 $a_1$（首项）与 $d$（公差）。当题目给出若干项的关系时，由通项 $a_n = a_1 + (n-1)d$ 和求和 $S_n = na_1 + \dfrac{n(n-1)}{2}d$ 建立关于 $a_1,d$ 的线性方程组，解出 $a_1,d$ 即可求出该数列的任意项或和。
- **适用条件**：数列明确为等差数列（或等比数列同理，用 $a_1,q$ 建立方程组）。

## 解题方法与套路
1. **识别基本量**：对等差数列，设出首项 $a_1$、公差 $d$。
2. **翻译条件列式**：将题干中的项与和用 $a_1,d$ 表示，得到方程（组）。如 $a_3 + a_4 = (a_1+2d)+(a_1+3d) = 2a_1+5d$。
3. **解方程组求基本量**：优先使用**加减消元**快速求出 $a_1$ 和 $d$。若系数较繁，可用代入消元。
4. **代入目标求值**：将解得的 $a_1,d$ 代入所求的通项或求和公式计算。
5. **验根**（高分习惯）：将 $a_1,d$ 代回原条件验证是否满足，防止符号或计算错误。

## 高频易错
- **消元时符号错误**：尤其是两式相减时，忘记“减负变加”，导致 $d$ 算反。
- **通项脚标代错**：$a_n = a_1 + (n-1)d$ 中括号内为 $n-1$，将 $a_3$ 误写为 $a_1+3d$。
- **求和公式误用**：$S_n = na_1 + \dfrac{n(n-1)}{2}d$，系数 $\dfrac{n(n-1)}{2}$ 易算错，如忘记除以 2 或 $n$ 取错。
- **只解一半**：解出 $a_1,d$ 后过于兴奋，忘记代入所求的 $S_{10}$ 或 $a_n$ 即匆忙写答案，导致“功亏一篑”。
- **误判次数**：如果方程两边不在同一数量级，盲目消元会变复杂，应先化简单个方程。

- **方程组定义**：由两个或两个以上方程构成的组合，用以求解多个未知数。高考中绝大部分方程组可通过**消元**化为一元方程求解，核心是减少未知数个数。
- **基本解法**：
  - **代入消元法**：从某一方程中解出一个未知数，代入其余方程。
  - **加减消元法**：方程间相加或相减，抵消某项，直接得到另一未知数的值。
- **等差数列基本量方程模型**：等差数列 $\{a_n\}$ 完全由首项 $a_1$ 与公差 $d$ 确定。通项公式 $a_n=a_1+(n-1)d$，求和公式 $S_n=na_1+\dfrac{n(n-1)}{2}d$。当题目给出关于某些项或和的独立条件时，可把条件“翻译”为只含 $a_1,d$ 的方程，联立求解即可打通全题。
- **消元策略**：等差数列方程通常为二元一次方程组，优先用**加减消元**，直接加/减消去 $a_1$ 求 $d$，或消 $d$ 求 $a_1$，效率最高。

## 解题方法与套路
1. **设基本量**：对等差数列，明确写出“设首项为 $a_1$，公差为 $d$”。
2. **翻译条件**：将题给关系式写成含 $a_1,d$ 的方程。
   - 出现 $a_n$ 时，代入 $a_n = a_1+(n-1)d$。
   - 出现 $S_n$ 时，代入求和公式，或利用与 $a_n$ 的关系简化。
3. **整理方程组**：去括号，合并同类项，统一为 $Aa_1+Bd=C$ 的标准形式。
4. **选择消元法求解**：
   - 若 $a_1$ 系数成比例，用加减消元求出 $d$ 再回代；
   - 若 $d$ 系数成比例，同理先求 $a_1$。
5. **代入目标计算**：将求出的 $a_1,d$ 代入题目要求的表达式（如 $S_{10}$，某具体项等）。
6. **检验**：把解得的 $a_1,d$ 反代回原条件，快速心算验证，确保答案正确。

## 高频易错
- **项数脚标示错**：$a_n = a_1 + (n-1)d$ 中，$n-1$ 易误为 $n$，列方程时一步错全盘输。
- **加减消元符号出错**：两式相减时，被减式的每一项都要变号，尤其常数项和 $d$ 系数容易错漏。
- **求和公式系数混淆**：$S_n = na_1 + \frac{n(n-1)}{2}d$，遗忘分母 $2$ 或将 $\frac{n(n-1)}{2}$ 误算成 $n^2$ 等，导致 $S_{10}$ 计算错误。
- **模型误用**：如未判断数列类型就乱用等差/等比公式；本题虽明确为等差，但也提醒必须看清定义再建模。
- **结果未化简**：求得 $a_1,d$ 后直接写原方程组的解，却忘了最终求 $S_{10}$，造成答非所问的失分。
