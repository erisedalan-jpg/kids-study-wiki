## 知识精要
- **定义**：若一个多面体的所有顶点都在同一球面上，则称该球为多面体的外接球。
- **长方体外接球的定理**：长方体的体对角线长等于其外接球的直径。这是由长方体与球心的对称性决定的——球心即长方体体对角线的中点。
- **核心公式**（设长方体长、宽、高分别为 $a, b, c$）：
  1. 体对角线长：$d = \sqrt{a^2 + b^2 + c^2}$  
  2. 外接球半径：$R = \dfrac{d}{2} = \dfrac{\sqrt{a^2 + b^2 + c^2}}{2}$  
  3. 外接球表面积：$S = 4\pi R^2$  
  4. 外接球体积：$V = \dfrac{4}{3}\pi R^3$
- **适用条件**：题干明确为“长方体的顶点都在一个球面上”或“长方体的外接球”，即可直接代入。特殊的，正方体是长方体的特例（$a=b=c$），公式同样适用。

## 解题方法与套路
1. **识别模型**：判断几何体是否为长方体（含正方体），是否提及所有顶点在同一个球面上。
2. **提取棱长**：从题干中准确找出长、宽、高的值或比例，若有参数先保留符号运算。
3. **计算体对角线**：代入 $d = \sqrt{a^2+b^2+c^2}$，注意平方和的开方不要遗漏。
4. **求半径**：$R = \dfrac{d}{2}$，务必区分直径与半径。
5. **求目标量**：根据所求量（表面积 $S=4\pi R^2$ 或体积 $V=\frac{4}{3}\pi R^3$）直接计算。若给出的是倍数关系，可先整体平方或立方再乘系数，减少中间开方次数，提高准确率。
   - 技巧：求表面积时可先算 $R^2 = \dfrac{a^2+b^2+c^2}{4}$，则 $S = \pi (a^2+b^2+c^2)$，跳过开方直接得出答案。

## 高频易错
- **直径与半径混淆**：体对角线等于直径，不是半径。求表面积或体积时忘记除以2，导致结果错误。
- **开方、平方误用**：计算 $R^2$ 时直接将 $\dfrac{\sqrt{a^2+b^2+c^2}}{2}$ 写成 $\dfrac{a^2+b^2+c^2}{2}$，漏掉分母的平方。
- **表面积与体积公式误记**：表面积是 $4\pi R^2$（系数4），体积是 $\frac{4}{3}\pi R^3$，二者容易写串。
- **棱长代入错误**：遇到诸如 $2a$ 的长时，平方项应计算为 $(2a)^2 = 4a^2$，而不是 $2a^2$。
- **特殊图形混淆**：对正方体误用对角线等于棱长的 $\sqrt{2}$ 倍等平面结论；必须使用体对角线（$\sqrt{3}a$ 倍棱长）。

## 代表题精讲
**题目**（2010全国卷文7）：设长方体的长、宽、高分别为 $2a, a, a$，其顶点都在一个球面上，则该球的表面积为（ ）

**思路**  
长方体的外接球直径即为体对角线。先求体对角线长，得到半径，再代入球的表面积公式。直接套用结论 $S = \pi(a^2+b^2+c^2)$ 最为快捷。

**步骤**  
1. 记长 $l=2a$，宽 $w=a$，高 $h=a$。  
2. 体对角线平方：$d^2 = l^2 + w^2 + h^2 = (2a)^2 + a^2 + a^2 = 4a^2 + a^2 + a^2 = 6a^2$。  
3. 由 $R^2 = \dfrac{d^2}{4} = \dfrac{6a^2}{4} = \dfrac{3}{2}a^2$。  
4. 表面积：$S = 4\pi R^2 = 4\pi \cdot \dfrac{3}{2}a^2 = 6\pi a^2$。  
   （或用简化公式 $S = \pi d^2 = \pi \cdot 6a^2 = 6\pi a^2$）

**点评**  
此题纯考长方体外接球的直接公式套用，属于低档基础题，需保证绝对正确。注意长是 $2a$ 而非 $a$，这是很多考生易看错的点。变式：若改为正方体（长宽高等长），或给出表面积反求棱长，解法完全同源，务必形成条件反射——看到长方体顶点共球，立即联想体对角线即直径。
