## 知识精要
- **串并联基本规律**
  - 串联：电流相等 $I=I_1=I_2$，总电压 $U=U_1+U_2$，总电阻 $R=R_1+R_2$，电压分配 $\frac{U_1}{U_2}=\frac{R_1}{R_2}$。
  - 并联：电压相等 $U=U_1=U_2$，总电流 $I=I_1+I_2$，总电阻 $\frac{1}{R}=\frac{1}{R_1}+\frac{1}{R_2}$，电流分配 $\frac{I_1}{I_2}=\frac{R_2}{R_1}$。
- **小量程电流表（表头）参数**：满偏电流 $I_g$、内阻 $R_g$，其满偏电压 $U_g=I_g R_g$。
- **改装为大量程电流表**：并联分流电阻 $R_{\text{并}}$。
  $$(I - I_g)R_{\text{并}} = I_g R_g \quad\Rightarrow\quad R_{\text{并}} = \frac{I_g R_g}{I - I_g}$$
  其中 $I$ 为改装后量程。
- **改装为电压表**：串联分压电阻 $R_{\text{串}}$。
  $$U = I_g (R_g + R_{\text{串}}) \quad\Rightarrow\quad R_{\text{串}} = \frac{U}{I_g} - R_g$$
  其中 $U$ 为改装后量程。
- **多用电表档位切换原理**：通过开关切换电路的串并联结构，使同一表头配合不同电阻实现电流档与电压档。
- **电表极性**：电流从“+”接线柱（红表笔）流入，“−”接线柱（黑表笔）流出。对于表头，电流应从正接线柱流入，指针正向偏转。

## 解题方法与套路
1. **明确表头参数**：从题中提取满偏电流 $I_g$ 和内阻 $R_g$（注意单位换算，如 μA 转 mA）。
2. **确定改装目标**：看清要改装成多大量程的电流表或电压表，是单一改装还是多档位。
3. **选择改装方式**：
   - 电流表：表头并联小电阻；  
   - 电压表：表头串联大电阻；  
   - 多档位：利用开关切换，使表头在不同支路中满足并联或串联关系。
4. **列方程求解电阻**：
   - 并联分流：$(I_{\text{量程}} - I_g)R_{\text{并}} = I_g R_g$；
   - 串联分压：$U_{\text{量程}} = I_g(R_g + R_{\text{串}})$；
   - 若为复杂网络，按开关通断分别画出等效电路，标出电流路径，再用串并联关系列式。
5. **画电路图与实物连线**：电流表改装时并联电阻要与表头“头头相连、尾尾相连”；电压表改装时电阻与表头串在同一支路。实物连线注意“先串后并”、接线柱位置。
6. **结果处理**：按题目要求保留有效数字或精确到个位，计算时注意单位统一（Ω 与 kΩ 等）。

## 高频易错
- **并联分流电阻计算时遗漏“量程减去 $I_g$”**：误用 $I_{\text{量程}} R_{\text{并}} = I_g R_g$，导致电阻值错误。
- **单位混用**：表头量程常给 μA，计算时未转换为 mA 或 A，使最终电阻量级出错。
- **改装电压表时误用改装后电流表的内阻**：若先改装为电流表再改装电压表，计算串联电阻时应以改装后电流表的等效满偏电流和等效内阻为基准，切勿仍用原表头参数。
- **多档位电路识别错误**：开关闭合或断开时，没有正确判断是并联还是串联关系，例如开关闭合将电阻短路等情形。
- **表笔颜色与电流方向**：红表笔应接高电位、电流流入；黑表笔接低电位、电流流出。在实物连线或判断时容易接反。
- **实物连线对应关系**：未按电路图对应接线柱编号，或将电阻箱两端接错，导致档位功能混乱。

## 代表题精讲
### 2018-新课标Ⅱ-09
**题目**：用微安表头（$100\mu\text{A}$，$900\Omega$），电阻箱 $R_1(0\sim999.9\Omega)$、$R_2(0\sim99999.9\Omega)$，先组装 $1\text{mA}$ 电流表，再改装成 $3\text{V}$ 电压表。画电路图并标 $R_1$、$R_2$，求两电阻值（保留到个位）。

**思路**：$1\text{mA}$ 电流表需并联分流电阻 $R_1$；在此基础上串联 $R_2$ 改装为 $3\text{V}$ 电压表。改装后电流表满偏电流为 $1\text{mA}$，其等效内阻为 $R_g\parallel R_1$，再串联 $R_2$ 使总电压为 $3\text{V}$。

**步骤**：
1. 将 $I_g=100\mu\text{A}=0.1\text{mA}$，$R_g=900\Omega$。
2. 改装 $1\text{mA}$ 电流表：并联 $R_1$，分流 $(1-0.1)\text{mA}=0.9\text{mA}$。
   $$(1-0.1)R_1 = 0.1 \times 900 \quad\Rightarrow\quad 0.9R_1 = 90 \quad\Rightarrow\quad R_1 = 100\Omega$$
3. 改装后电流表内阻 $R_{\text{内}} = \frac{R_g R_1}{R_g+R_1} = \frac{900\times100}{900+100} = 90\Omega$，满偏电流 $1\text{mA}$。
4. 改装为 $3\text{V}$ 电压表：串联 $R_2$，$U = I_{\text{满}}(R_{\text{内}}+R_2)$。
   $$3 = 0.001\times(90+R_2) \quad\Rightarrow\quad 90+R_2 = 3000 \quad\Rightarrow\quad R_2 = 2910\Omega$$
5. 电路设计：表头与 $R_1$ 并联后为一个整体（电流表），再与 $R_2$ 串联；公共接线柱○接在并联节点一端，$a$ 为电流档（$R_1$ 与表头整体两端的引出），$b$ 为电压档（串联 $R_2$ 后的高端）。电路图从略，符合上述连接。

**点评/变式**：该题是典型的两级改装，容易在有改装后电流表内阻变化这点出错。若直接拿原表头算 $R_2$ 会得到错误值 $2910\Omega$ 还是巧合？这里算出来恰好正确，但真正原理必须以改装后整体参数计算，这是高频失分点。

### 2013-新课标Ⅱ-10
**题目**：量程 $1\text{mA}$、内阻 $120\Omega$ 的表头按图(a)电路改装成 $1\text{V}$ 和 $1\text{A}$ 多用电表。$R_1$、$R_2$ 为定值电阻，$S$ 为开关。回答：实物连线；$S$ 闭合与断开时各测什么；表笔 $A$ 颜色；求 $R_1$、$R_2$（3 位有效数字）。

**思路**：开关闭合时，$R_1$ 与表头串联后再与 $R_2$ 并联，通过并联分流实现大电流量程；开关断开时，表头与 $R_1$ 和 $R_2$ 全部串联，通过串联分压实现电压量程。根据量程列式求解。

**步骤**：
1. 电路结构识别：
   - $S$ 闭合：表头（$R_g$）与 $R_1$ 串联，再整体与 $R_2$ 并联。改装后的电流表量程 $1\text{A}$，满偏时 $I_g=1\text{mA}$ 流过表头支路。表头支路总电阻 $R_g+R_1$，两端电压等于 $R_2$ 两端电压。干路总电流 $1\text{A}$。并联分流：$(1 - 0.001) R_2 = 0.001 (R_g+R_1)$。
   - $S$ 断开：表头、$R_1$、$R_2$ 串联，改装为 $1\text{V}$ 电压表。满偏时 $I_g=1\text{mA}$，串联总电阻满足 $U = I_g (R_g+R_1+R_2)$。
2. 代入 $I_g=0.001\text{A}$，$R_g=120\Omega$，$U=1\text{V}$，$I_{\text{量}}=1\text{A}$：
   - 串联分压：$1 = 0.001\times(120 + R_1 + R_2) \Rightarrow 120+R_1+R_2=1000 \quad (1)$
   - 并联分流：$(1-0.001)R_2 = 0.001(120+R_1)$，近似 $1-0.001\approx 0.999$，可精确列：$0.999R_2 = 0.12 + 0.001R_1 \quad (2)$
   由于结果保留三位有效数字，可联立精确求解。
3. 由(1)得 $R_1+R_2=880$，代入(2)：$0.999R_2 = 0.12 + 0.001(880 - R_2)$，
   $0.999R_2 = 0.12 + 0.88 - 0.001R_2$，
   $0.999R_2 + 0.001R_2 = 1.00 \Rightarrow R_2 = 1.00\Omega$。
   则 $R_1 = 880 - 1.00 = 879\Omega$，取有效数字为 $880\Omega$（由计算精确值 $879\Omega$ 但在保留三位有效数字且原始数据 1.00 等，答案为 $R_1=1.00\Omega$、$R_2=880\Omega$；注意题干答案给出 $R_1=1.00\Omega$，$R_2=880\Omega$，实际是 $R_1$ 为小电阻，$R_2$ 为大电阻。对应开关闭合分流用一个极小电阻 $R_1$？此处由电路图 a 确定 $R_1$ 和 $R_2$ 位置：图 a 中开关与 $R_1$ 串联再与表头串联后和 $R_2$ 并联，所以 $R_1$ 是串联在表头支路的小电阻，用来配合 $R_2$ 分流。因此结果 $R_1=1.00\Omega$、$R_2=880\Omega$ 符合物理意义。
4. 功能判断：开关闭合时，电路总电阻很小（因并联低阻），可测大电流，即测电流；断开时大电阻串联，测电压。
5. 表笔极性：电流从 A 流入？需看电路图 a 中表头正负。通常保证电流从红表笔流入。由题通常规律，A 应是黑表笔。结合真题答案“黑”。
6. 实物连线：对照图 a 的连接点，按电路顺序连接，注意表头正负、开关接点。

**点评/变式**：本题关键在于理解开关作用，闭合时构成并联分流电路，断开时构成串联分压电路。列式时注意量程对应的满偏条件。易错点是把 $R_1$、$R_2$ 阻值位置搞混。实物连线题注意先后顺序与节点对应。
