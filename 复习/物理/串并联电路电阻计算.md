## 知识精要

- **串联电路电阻**  
  总电阻等于各部分电阻之和：  
  $$R_{\text{串}} = R_1 + R_2 + \cdots + R_n$$

- **并联电路电阻**  
  总电阻的倒数等于各支路电阻倒数之和：  
  $$\frac{1}{R_{\text{并}}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}$$  
  两个电阻并联的常用表达式：  
  $$R_{\text{并}} = \frac{R_1 R_2}{R_1 + R_2}$$

- **混联电路**  
  先判断电阻间的串、并联关系，再用等效替代法逐级简化，最终算出总电阻。

- **闭合电路欧姆定律**  
  $$E = U_{\text{外}} + Ir$$  
  其中电源电动势 $E$ 和内阻 $r$ 可由 $U$–$I$ 图线得到：  
  - 纵轴截距为 $E$  
  - 斜率的绝对值为 $r = \left|\frac{\Delta U}{\Delta I}\right|$

- **路端电压、总电流与外电阻的关系**  
  $$U_{\text{外}} = IR_{\text{外}}$$  
  结合 $I = \frac{E - U_{\text{外}}}{r}$ 可推出：  
  $$R_{\text{外}} = \frac{U_{\text{外}}}{I} = \frac{U_{\text{外}} r}{E - U_{\text{外}}}$$

## 解题方法与套路

涉及电源和电阻网络的电路匹配问题，通用步骤：

1. **读图求电源参数**  
   从给出的 $U$–$I$ 图线直接获取：电动势 $E = U_{\text{截}}$，内阻 $r = \left|\frac{\Delta U}{\Delta I}\right|$。注意单位是否统一（如 V、A、Ω）。

2. **由路端电压求总电流**  
   利用闭合电路欧姆定律 $E = U + Ir$，已知 $U$（路端电压）时解出：  
   $$I = \frac{E - U}{r}$$

3. **计算外电路总电阻**  
   外电路的总电阻：  
   $$R_{\text{外}} = \frac{U}{I}$$

4. **反推电阻连接方式**  
   将所得 $R_{\text{外}}$ 与给定单个电阻值比较，通过串并联组合公式（乘积/加和、倒数关系等）验算选项中每一组连接方式的等效电阻，找出符合 $R_{\text{外}}$ 的方案。若为选择题，可直接排除不符项；若为计算题，则需写出可能的拓扑。

## 高频易错

- **混淆电动势与路端电压**  
  不能直接用路端电压 $U$ 除以内阻 $r$ 计算电流，必须用 $I = (E-U)/r$。

- **$U$–$I$ 图线斜率误读**  
  斜率 $\frac{\Delta U}{\Delta I}$ 是负值，内阻取其绝对值。若坐标轴起点非零，应取直线两点的差值计算，避免直接用某一点的坐标比求斜率。

- **并联电阻计算错误**  
  并联公式是倒数关系，两个电阻并联常见错误为 $R_{\text{并}} = \frac{R_1R_2}{R_1+R_2}$，但超过两个电阻时学生容易直接相乘相加，必须坚持“倒数和再倒数”的流程。

- **混联结构识别不清**  
  未准确判断电阻之间的节点连接关系，导致等效电阻算错。遇到等势点可以用抹去或合并法简化电路。

- **单位不统一**  
  内阻与电阻单位通常为 Ω，电压为 V，电流为 A，计算前后注意换算（如 mV 与 V），避免数量级错误。

## 代表题精讲

### 2009·全国Ⅱ·04

**题目**  
某电源的 $U$–$I$ 图线如图所示，由图可得电动势 $E = 6.0\ \text{V}$，内阻 $r = 0.5\ \Omega$。用此电源与三个阻值均为 $3\ \Omega$ 的电阻连接成电路，测得路端电压为 $4.8\ \text{V}$。则三个电阻的可能连接方式是下列选项中的哪一个？（选项为四组由三个 $3\ \Omega$ 电阻构成的不同混联电路图）

**思路**  
由路端电压和电源参数求出总电流，进而求出外电路所需的总电阻；再逐一计算选项中各电路的等效电阻，与计算值 $2\ \Omega$ 吻合者即为正确答案。

**步骤**  

1. 算总电流  
   $$I = \frac{E - U}{r} = \frac{6.0 - 4.8}{0.5} = \frac{1.2}{0.5} = 2.4\ \text{A}$$

2. 算外电路总电阻  
   $$R_{\text{外}} = \frac{U}{I} = \frac{4.8}{2.4} = 2.0\ \Omega$$

3. 分析电阻组合  
   三个 $3\ \Omega$ 电阻所有可能的等效电阻值：
   - 三个串联：$3+3+3 = 9\ \Omega$
   - 三个并联：$\frac{3}{3} = 1\ \Omega$
   - 两串一并：先串联两个得 $6\ \Omega$，再与第三个并联  
     $$R = \frac{6 \times 3}{6 + 3} = 2\ \Omega$$
   - 两并一串：先并联两个得 $1.5\ \Omega$，再串联第三个  
     $$R = 1.5 + 3 = 4.5\ \Omega$$

   只有“两个串联后与第三个并联”的组合得到 $2\ \Omega$，与计算结果一致。

4. 结论  
   该电路为两个 $3\ \Omega$ 电阻串联后，再与第三个 $3\ \Omega$ 电阻并联。

**点评与变式**  
- 本题将恒定电流中的两大核心考点——闭合电路欧姆定律和电阻串并联结合，通过 $U$–$I$ 图线同时考查学生读图与计算能力。  
- 若题目改为“路端电压增大为 5.4 V”，则总电流 $I = (6-5.4)/0.5 = 1.2\ \text{A}$，外电阻 $R_{\text{外}} = 5.4/1.2 = 4.5\ \Omega$，对应“两个并联再串联一个”的连接方式。  
- 复习时可自行变换电源参数和电阻值，练习不同组合的快速等效电阻计算，做到在考场上无需逐个复杂推导，直接套用两电阻并联的乘积/加和公式快速排除错误选项。
