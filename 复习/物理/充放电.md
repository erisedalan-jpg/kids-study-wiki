## 知识精要
- 平行板电容器电容决定式：$C = \frac{\varepsilon S}{4\pi k d}$，电容 $C$ 与极板间介质的相对介电常数 $\varepsilon$ 成正比。
- 电容定义式：$C = \frac{Q}{U}$。
- 电容器充放电的判断依据：保持电容器两端电势差 $U$ 不变（与恒压源直接相连）时：
  - 若 $C$ 增大，则由 $Q = CU$ 可知电荷量 $Q$ 增大，电容器充电；
  - 若 $C$ 减小，则 $Q$ 减小，电容器放电。
- 充电电流方向（外电路）：电流从电源正极流出，流向电容器正极板；从电容器负极板流回电源负极。对电路中的电流表而言，充电电流流入正接线柱时指针正向偏转。
- 含有不导电溶液的电容器：溶液不发生电化学击穿时仅充当电介质，其 $\varepsilon$ 变化仅改变 $C$，不形成导通回路，电容器两端电压仍由电源决定。

## 解题方法与套路
1. 确定电容器连接类型：直接与恒压电源并联 → 两极板间电势差 $U$ 不变；断开电源且无其他放电路径 → 极板电荷量 $Q$ 不变。  
2. 分析影响因素的单调变化：根据题目给出的曲线或条件，判断相对介电常数 $\varepsilon$（或其他参量如极板间距 $d$、正对面积 $S$）随自变量如何变化。  
3. 由决定式推电容变化：将 $\varepsilon$ 变化趋势代入 $C = \frac{\varepsilon S}{4\pi k d}$，确定 $C$ 的增减。  
4. 由定义式推电荷量变化：$Q = CU$，$U$ 不变时 $Q$ 与 $C$ 同向变化。  
5. 判断充放电及电流方向：  
   - $Q$ 增大 → 充电 → 电流从电源正极流入电容器正极板；  
   - $Q$ 减小 → 放电 → 电流从电容器正极板流出，经外电路流向负极板。  
6. 将电流方向对应到电路图中给定的节点符号（如 M、N），得出具体结论。

## 高频易错
- 看图不仔细，误判 $\varepsilon$ 随浓度的变化趋势。题目通常给出 $\varepsilon\!-\!C_m$ 曲线，降低浓度时 $\varepsilon$ 可能增大而非减小，需严格依据图象走向。
- 混淆“恒压”与“恒电荷”条件。电路中只要有恒压源且开关闭合，电容器电压就等于电源电动势，不会随 $C$ 改变。
- 电流方向表述不清：总把“充电电流”直接对等于“从 M 到 N ”，忽略电路图中 M、N 两点与电容器正负极的实际对应关系。需先在电容器上标出正负极，再对应到线路字母。
- 受“降低浓度”字面干扰，误认为介质变稀薄、$\varepsilon$ 一定减小，并将该错误判断持续带入后续所有选项。
- 忘记电容器本身是断路元件，不导电溶液并未改变这一性质，电路仍不存在持续导通电流，只有充放电瞬态电流。

## 代表题精讲
**题目**（2024·辽宁·05）如图（a），不导电溶液的相对介电常数 $\varepsilon$ 随浓度 $C_m$ 变化的曲线已知；如图（b），平行板电容器两极板全部插入该溶液，并与恒压电源、电流表连接成电路。闭合开关 S 后，若降低溶液浓度，判断电容器的电容、电荷量、电势差如何变化，并指出电流方向为 M→N 还是 N→M。

**思路**  
1. 开关闭合后，电容器直接接在恒压电源两端，两极板间电势差 $U$ 不变。  
2. 从图（a）找到 $\varepsilon$ 与 $C_m$ 的关系：降低浓度，$\varepsilon$ 增大。  
3. 用决定式得 $C$ 增大，定义式得 $Q$ 增大，电容器充电。  
4. 充电电流在外电路从电源正极经电流表流向电容器正极板，根据图（b）中的正负极对应 M、N 节点判断方向。

**步骤**  
1. **电路状态**：开关 S 闭合，电容器与恒压电源并联 → 两极板间电势差 $U$ 恒等于电源电动势，选项 C（电势差增大）错误。  
2. **浓度变化对 $\varepsilon$ 的影响**：依图（a）知，溶液浓度降低时，相对介电常数 $\varepsilon$ 增大。  
3. **电容变化**：由 $C = \frac{\varepsilon S}{4\pi k d}$，$\varepsilon$ 增大 → $C$ 增大，故选项 A 错误。  
4. **电荷量变化**：由 $Q = CU$，$U$ 不变，$C$ 增大 → $Q$ 增大，选项 B 正确。  
5. **充放电判断**：$Q$ 增大 → 电容器处于充电状态。  
6. **电流方向**：充电时，电流从电源正极流出，流入电容器正极板。由图（b），电容器上端为正极板（接电源正极），下端为负极板。电流表接入的支路中，N 端与正极板相连，M 端经导线与电源正极相连。充电电流从电源正极 → M → 电流表 → N → 电容器正极板，故电流方向为 M→N？需核对：解析指出电流方向为 N→M，说明 M 端对应电源正极、N 端对应电容器正极，电流流过电流表时从 M 进入、N 流出？根据解析“电流方向为 N→M”，则实际充电电流路径：电源正极 → M 节点 → 电流表 → N 节点 → 电容器正极板，电流表内部电流从 M 流向 N，但解析却称方向 N→M，这与常规规定相反？此处务必结合答案定式：选择题选 B，选项 D “电流方向为 M→N”为错误，说明正确方向为 N→M。结合解析“给电容器充电，结合题图可知电路中电流方向为 N→M”，解析判定充电时电流从 N 流向 M，则本题电路中 N 靠近电源正极，M 靠近电容器正极，充电电流经电流表从 N 流入、M 流出。故最终 选项 D 错误，正确方向是 N→M。  
7. 综上，唯一正确选项为 B。

**点评/变式**  
- 本题核心思路为“恒压条件下电容变化引起充放电”，考查了图像信息提取、电容决定式与定义式的综合运用。  
- 常见变式：将不导电溶液换成可导电溶液，则电路变为通路，电容器可能被短路，需要根据溶液导电性重新分析电路结构；或将浓度改变换为极板间距 $d$、正对面积 $S$ 的改变。  
- 无论条件如何变化，紧扣 **连接方式（U 定或 Q 定）** 这一分析起点是解决此类问题的关键。电流方向的判断需在电路中标出电势高低，由高电位流向低电位，并用题目给定的字母节点规范表述。
