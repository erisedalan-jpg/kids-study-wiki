## 知识精要
- **光的干涉（双缝干涉）**
  - 相邻亮（暗）条纹间距公式：$$\Delta x = \frac{L}{d}\lambda$$
    其中 $d$ 为双缝间距，$L$ 为双缝到屏的距离（缝屏距），$\lambda$ 为光在真空（或空气）中的波长。
  - 影响 $\Delta x$ 的因素：$\lambda$ 越大、$d$ 越小、$L$ 越大，条纹间距越大。光源到双缝的距离不影响 $\Delta x$。
  - 适用条件：相干光源（频率相同、相位差恒定、振动方向一致），双缝实验满足分波前干涉。
- **光的折射与反射**
  - 折射定律（斯涅尔定律）：$$n_1 \sin i = n_2 \sin \gamma$$
    （从介质1进入介质2，$i$ 为入射角，$\gamma$ 为折射角，$n_1,n_2$ 为绝对折射率）。若光从介质射入真空（或空气），$n_{介}\sin i = \sin \gamma$（空气折射率近似为1）。
  - 绝对折射率 $n = \dfrac{c}{v}$，$c$ 为真空光速，$v$ 为介质中光速。
  - 反射定律：反射角等于入射角，反射光线与入射光线、法线在同一平面内。
  - 光路可逆性。
- **物理光学与几何光学结合问题**
  - 涉及镜面反射时，可作光源关于反射面的对称点（虚光源），将反射光线转化为直线传播，简化光路。
  - 利用几何关系（三角形边角关系、平行线、角度互余等）建立入射角、折射角之间的数量关系，再代入折射定律求解。

## 解题方法与套路
1. **双缝干涉条纹间距调节问题**
   - 直接列出公式 $\Delta x = \frac{L}{d}\lambda$，逐项分析选项中改变哪个物理量如何影响 $\Delta x$。
   - 注意波长与颜色对应关系：红 > 橙 > 黄 > 绿 > 蓝 > 紫，波长越长，条纹间距越大。
   - 警惕无关因素：光源与双缝的距离仅影响光强，不影响条纹间距。
2. **几何光学折射率求解问题（含反射）**
   - 第一步：明确光路中哪些是折射，哪些是反射。对于反光材料（镜面），作点光源关于反射面的对称点，画出反射光对应的入射光线路径。
   - 第二步：在界面处标出入射角 $i$ 和折射角 $\gamma$，注意角度是光线与法线的夹角。
   - 第三步：用折射定律列方程。若有多个折射点，分别列出。
   - 第四步：挖掘题目给出的角度关系（如两光线垂直意味着角度和为90°）以及几何 长度关系（如正方向边长、高度等），求出角度或角度的三角函数值。
   - 第五步：联立方程求解折射率 $n$。常用技巧：当 $i$ 较小时可近似，但本题多为严格的三角函数代数运算，需能熟练进行正弦余弦转换。

## 高频易错
- **双缝干涉**：误认为光源到双缝的距离会影响条纹间距，从而错选E。公式 $\Delta x = \frac{L}{d}\lambda$ 中 $L$ 是双缝到屏的距离，与光源位置无关。
- **颜色与波长**：记不清红、蓝光波长谁大，导致选反。红色波长大于绿色，蓝色波长小于绿色。
- **折射问题中角度找错**：将光线与界面的夹角当作入射角或折射角，忘记应是光线与**法线**的夹角。
- **反射路径处理不当**：没想到利用对称点将反射光线“拉直”，导致光路复杂、角度关系混乱。
- **几何关系遗漏**：题目中“两束光线相互垂直”这类互余关系未转换成方程，或未正确标出哪两个角互余。例如 $γ_1+γ_2=90°$ 可能被错写为入射角互余。
- **折射定律中 $n$ 的位置**：分不清 $n\sin i = 1\cdot \sin γ$ 还是 $\sin i = n\sin γ$。统一方法：介质中的角度正弦乘介质折射率 = 真空（或空气）中角度正弦，即 $n_{介}\sin\theta_{介} = \sin\theta_{空}$。

## 代表题精讲
### **题目1** （2017·新课标Ⅱ·15）双缝干涉条纹间距的调节
**题目**：用绿色激光做双缝干涉实验，若要增大相邻亮条纹间距，下列哪些方法可行？（多选：红/蓝激光；减小双缝间距；屏远离双缝；光源远离双缝）

**思路**：直接运用公式 $\Delta x = \frac{L}{d}\lambda$，分析每个操作对 $\Delta x$ 的影响。增大波长（绿→红）、减小 $d$、增大 $L$ 均可增大间距；改变光源与双缝距离无效。

**步骤**：
- 绿光波长为 $\lambda_0$，红光波长大于绿光，蓝光波长小于绿光。
- A．改用红光 → λ 增大 → Δx 增大，正确。
- B．改用蓝光 → λ 减小 → Δx 减小，错误。
- C．减小 $d$ → Δx 增大，正确。
- D．屏幕远离 → $L$ 增大 → Δx 增大，正确。
- E．光源远离 → 不影响 $d$、$L$、$\lambda$，错误。

**点评/变式**：本题为高频考点，常以选择题出现。需牢记公式中的 $L$ 是双缝到屏距离，而非光源到双缝距离。变式可问“若要减小条纹间距”，或结合白光干涉、薄膜干涉等对比考查。

### **题目2** （2017·新课标Ⅱ·16）含有反射面的折射率计算
**题目**：一桶状容器高 $2l$，底边长 $l$ 的正方形，装满透明液体。右侧内壁为反光材料，其余吸光。左下角有一点光源，从液面 $D$ 点（右上角）出射的两条光线（一条直接折射，另一条经右侧壁反射后折射）相互垂直，求液体折射率。

**思路**：作光路图，标出入射角 $i_1,i_2$ 和折射角 $γ_1,γ_2$。利用反射的对称特性，将光源关于反射面的对称点 $C$ 作出，连接 $CD$ 得反射光线对应的入射光线。根据几何关系求出入射角的正弦（边长关系），利用 $γ_1+γ_2=90°$ 和折射定律联立解出 $n$。

**步骤**：
1. 建立坐标系或几何图形：左下角点光源 $S$，右上角 $D$。容器高 $2l$，宽 $l$。右侧壁为反射面。
2. 作 $S$ 关于右侧壁的对称点 $C$，则从 $C$ 到 $D$ 的直线即为反射光线对应的虚直线，与右壁交于 $E$，$SE$ 为入射光线。
3. 直接光束：从 $S$ 到 $D$ 的直线。入射角 $i_1$ 是 $SD$ 与法线（竖直线）的夹角，由几何得 $\sin i_1 = \frac{l}{\sqrt{(2l)^2+l^2}} = \frac{1}{\sqrt{5}}$。
   折射角 $γ_1$ 对应出射空气。
4. 反射光束：实际光路 $S→E→D$，$ED$ 的延长线过 $C$。$C$ 点坐标为 （$2l$,0），$D$ 点坐标为（$l$, $2l$）（若以左下角为原点）。计算 $CD$ 连线的水平与竖直投影：水平距离 $2l - l = l$，竖直距离 $2l - 0 = 2l$。因此该光线从介质射向空气的入射角 $i_2$ 满足 $\sin i_2 = \frac{l}{\sqrt{l^2+(2l)^2}} = \frac{1}{\sqrt{5}}$。（巧合相等）
5. 折射定律：
   $$n\sin i_1 = \sin γ_1$$
   $$n\sin i_2 = \sin γ_2$$
6. 由题意：两出射光线垂直 → $γ_1 + γ_2 = 90°$ → $\sin γ_2 = \cos γ_1$。
7. 代入 $\sin i_1=\sin i_2=\frac{1}{\sqrt{5}}$，有：
   $$\sin γ_1 = n\cdot\frac{1}{\sqrt{5}}, \quad \sin γ_2 = n\cdot\frac{1}{\sqrt{5}}$$
   又 $\sin^2 γ_1 + \cos^2 γ_1 = 1$，即 $\sin^2 γ_1 + \sin^2 γ_2 = 1$。
   得：$\left(\frac{n}{\sqrt{5}}\right)^2 + \left(\frac{n}{\sqrt{5}}\right)^2 = 1$ → $\frac{2n^2}{5}=1$ → $n^2 = \frac{5}{2}$ → $n=\frac{\sqrt{10}}{2} \approx 1.58$。

**点评/变式**：此题为典型的反射+折射综合题，核心技巧是作对称点将反射光路拉直。需注意不能忽略几何运算细节，两个入射角恰好相等是本题的特殊简化。变式可更换点光源位置、改变反光壁位置，或改为求光在液体中的传播时间等，但基本方法不变。
