## 知识精要
- **光强的微观本质**：单色光的光强 $I$ 由光子数密度和光子能量共同决定，$I = N \cdot h\nu$，其中 $N$ 为单位时间垂直照射到单位面积上的光子数。  
- **光子能量**：$\varepsilon = h\nu$，仅由光的频率 $\nu$ 决定，与光强无关。  
- **金属的逸出功**：$W_0$ 是金属的固有属性，只与金属种类和表面状态有关，与入射光的频率、强度均无关。  
- **爱因斯坦光电效应方程**：$E_{km} = h\nu - W_0$。光电子最大初动能仅取决于入射光频率和金属逸出功，与光强无关。  
- **光强变化的核心影响**（在能够发生光电效应，即 $\nu>\nu_c$ 的前提下）：  
  - 饱和光电流 $I_s$ 与光强成正比：光强越大，单位时间照射到金属表面的光子数越多，单位时间逸出的光电子数越多，饱和光电流越大。  
  - 遏止电压 $U_c$ 和截止频率 $\nu_c$ 均不随光强变化。

## 解题方法与套路
- **步骤一 锁定“变”与“不变”**：题目若仅改变“光强”而不改变“频率”，立刻确定三个不变量——光子能量、逸出功、最大初动能。  
- **步骤二 判断光子数效应**：光强增大，必然导致单位时间打在金属表面的光子数 $N$ 变大，进而单位时间逸出的光电子数增多，饱和光电流增大。  
- **步骤三 辨析干扰项**：凡是涉及“初动能”“遏止电压”“光子能量”随光强增大的选项均为错误；“逸出功随光强变化”是陷阱，逸出功只与金属有关。  
- **步骤四 综合方程**：必要时写出 $E_{km}=h\nu-W_0$，并说明等式右边与光强无关，给判断提供定量依据。

## 高频易错
- 误认为光强增大时**光子能量变大**：光子能量 $h\nu$ 只由频率决定，光强只影响光子数目。  
- **逸出功与入射光混淆**：逸出功是金属的固有特征量，不能由增大光强来改变；题中常见的“逸出功增大”为强烈干扰项。  
- **最大初动能误随光强增大**：$E_{km}=h\nu-W_0$ 无光强项，只有频率和逸出功起作用。  
- 忽略“能够发生光电效应”这一前提条件：若光频率小于截止频率，无论光强多大都无法产生光电子；但在已发生光电效应的前提下，光强才决定饱和光电流的大小。  
- 混淆**饱和光电流**与**瞬时电流**：饱和光电流取决于单位时间逸出光电子总数，与光强成正比；而光电流的瞬时值还与所加电压有关。

## 代表题精讲
### 代表题一（2024·辽宁·08）
**题目**：用某一频率 X 光照射金属表面，逸出了光电子。仅增加此 X 光的强度，判断逸出功、光子能量、最大初动能及单位时间逸出光电子数的变化。

**思路**：题目只改变光强，频率固定。抓住“三不变”（逸出功、光子能量、最大初动能）与“一变”（光子数增多导致光电子数增多），逐项排除。

**步骤**：  
1. 逸出功为金属固有属性，与入射光强无关 → A 错误。  
2. 光子能量 $\varepsilon = h\nu$，频率不变则光子能量不变 → B 正确。  
3. 由 $E_{km}=h\nu-W_0$，右侧不含光强，最大初动能不变 → C 错误。  
4. 光强增大，单位时间到达金属表面的光子数 $N$ 增多，逸出光电子数随之增多 → D 正确。

**点评/变式**：该题几乎覆盖了光强在光电效应中的全部核心结论，属于典型考法。  
**变式**：若在实验中保持频率不变，增大光强，光电流随电压变化的曲线将如何变化？饱和光电流增大，遏止电压不变，曲线形状整体上移但顶点右移量不变。

### 代表题二（基于考纲经典设问）
**题目**：研究光电效应的实验中，用同一频率的单色光照射阴极，增大光强。简述饱和光电流如何变化，并说明理由。

**思路**：光电效应中，一个光电子对应一个被吸收的光子（在 $\nu > \nu_c$ 前提下）。光强增大意味着光子数密度增大，被吸收的光子数增多，单位时间逸出的光电子数增多。

**步骤**：  
1. 单色光频率不变，每个光子能量固定。  
2. 增大光强 $I$ 意味着单位时间照射的光子总数 $N$ 增大。  
3. 阴极在单位时间内吸收的光子数增加，激发出的光电子数 $n$ 成正比增多。  
4. 当正向电压达到使所有逸出光电子均被阳极收集时，饱和光电流 $I_s = n e$ 与 $n$ 成正比，因此 $I_s$ 随光强增大而线性增大。  
5. 结论：饱和光电流随光强增大而增大，且成正比关系。

**点评/变式**：该命题将光强与宏观可测量（饱和光电流）直接联系，是实验题与选择题的高频方向。若将“增大光强”改为“换用频率更高但光强相同的单色光”，则饱和光电流不一定增大，因单个光子能量虽然更高，但光子数可能减少，需结合实验曲线的定量分析。
