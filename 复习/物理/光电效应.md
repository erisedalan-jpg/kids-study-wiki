## 知识精要
- **光电效应**：金属在光的照射下发射电子的现象，发射出的电子称为光电子。
- **实验规律**：
  1. 每种金属都存在一个**截止频率（极限频率）$\nu_c$**，入射光频率低于此值，无论光强多大，都不发生光电效应。
  2. 光电子的**最大初动能**$E_k$随入射光频率$\nu$线性增大，与入射光**强度无关**。
  3. 光电效应具有**瞬时性**（$\lt 10^{-9}\,\text{s}$）。
  4. 当入射光频率$\nu \gt \nu_c$时，**饱和光电流**与入射光强成正比（反映了单位时间内逸出的光电子数）。
- **光子说与方程**：
  光子能量：$\varepsilon = h\nu$（$h$为普朗克常量，$\nu$为频率）。
  爱因斯坦光电效应方程：$E_k = h\nu - W_0$。
  其中 $W_0$ 为金属的**逸出功**，$W_0 = h\nu_c$（$\nu_c$为截止频率）。
  $E_k$可用反向遏止电压$U_c$测量：$E_k = eU_c$。
- **光的强度**：在频率不变时，光强与单位时间照射到单位面积上的**光子数**成正比。光强增大，光子数增多，逸出的光电子数增多，但单个光电子最大初动能不变。

## 解题方法与套路
1. **概念辨析题**：抓住“三个只与”：
   - 逸出功$W_0$只与金属材料有关。
   - 光子能量$\varepsilon$只与光的频率$\nu$有关。
   - 最大初动能$E_k$只与入射光频率$\nu$和金属$W_0$有关。
   光强（频率一定时）只影响光子数和光电子数，不改变$E_k$。
2. **定量计算题**：以方程 $E_k = h\nu - W_0$ 为核心。
   - 已知最大初动能和频率（或波长），求逸出功或截止频率：$W_0 = h\nu - E_k$，$\nu_c = \dfrac{W_0}{h}$。
   - 已知遏止电压$U_c$，先求$E_k = eU_c$，再代入方程。
   - 已知光速$c$与波长$\lambda$，换频率：$\nu = \dfrac{c}{\lambda}$（注意波长单位换算：$1\,\text{nm} = 10^{-9}\,\text{m}$）。
3. **典型陷阱应对**：题干中出现“增加光强”“频率不变”时，立即锁定光子数增多、$E_k$不变；出现“频率增大”时，锁定$E_k$增大，再结合光强变化判断光子数变化。

## 高频易错
- **强度越大，光子能量越大？** 错！光子能量只由频率决定，光强在频率一定时只代表光子数多少。
- **光强增大，最大初动能增大？** 错！最大初动能只与频率有关，与光强无关。
- **金属逸出功随入射光频率变化？** 错！逸出功是金属自身的固有属性，不随入射光变化。
- **混淆遏止电压与入射光频率**：遏止电压反映的是最大初动能，与光强无关。若不加分析直接套用$U_c \propto \nu$的错误关系会失分。
- **单位换算失误**：波长常以纳米（$\text{nm}$）给出，计算频率时必须换成米（$\times 10^{-9}$），普朗克常量常为$6.63\times10^{-34}\,\text{J}\cdot \text{s}$，极易因数量级算错而丢分。

## 代表题精讲
### 代表题1：2024-辽宁-08
**题目**：用某一频率的X光照射金属表面逸出光电子，增加此X光的强度，则（　）  
A. 金属逸出功增大 B. X光的光子能量不变 C. 逸出的光电子最大初动能增大 D. 单位时间逸出的光电子数增多

**思路**：抓住核心条件——**频率不变，强度增加**。光子能量看频率，逸出功看金属，最大初动能看频率和逸出功，光电子数看光子数（强度）。

**步骤**：
- 入射光频率未变，由$\varepsilon = h\nu$知光子能量不变，故B正确。
- 金属逸出功是自身固有属性，与光照无关，故A错误。
- 由$E_k = h\nu - W_0$，$\nu$不变、$W_0$不变，$E_k$不变，故C错误。
- 增加光强意味着单位时间照射到金属表面的光子数增多，单位时间逸出的光电子数增多，故D正确。

**点评/变式**：本题考查对光电效应规律的基本理解，属于基础辨析题。**变式**：若把“增加强度”改为“增大频率，强度不变”，则光子能量增大，$E_k$增大，但由于光强不变，光子数可能减少（因每个光子能量大了），单位时间逸出电子数一般减少。

### 代表题2：2018-新课标Ⅱ-04
**题目**：用波长为$300\,\text{nm}$的光照射锌板，电子逸出时的最大初动能为$1.28\times10^{-19}\,\text{J}$，已知$h=6.63\times10^{-34}\,\text{J}\cdot \text{s}$，$c=3.00\times10^8\,\text{m/s}$，求能使锌产生光电效应的单色光的最低频率。

**思路**：最低频率即截止频率$\nu_c$。需先由光电效应方程求出锌的逸出功$W_0$，再由$W_0 = h\nu_c$求$\nu_c$。

**步骤**：
- 波长换算：$\lambda = 300\,\text{nm} = 3.00\times10^{-7}\,\text{m}$。
- 求入射光频率：$\nu = \dfrac{c}{\lambda} = \dfrac{3.00\times10^8}{3.00\times10^{-7}} = 1.00\times10^{15}\,\text{Hz}$。
- 根据爱因斯坦方程求逸出功：$W_0 = h\nu - E_k = (6.63\times10^{-34} \times 1.00\times10^{15}) - 1.28\times10^{-19} = 6.63\times10^{-19} - 1.28\times10^{-19} = 5.35\times10^{-19}\,\text{J}$。
- 求截止频率：$\nu_c = \dfrac{W_0}{h} = \dfrac{5.35\times10^{-19}}{6.63\times10^{-34}} \approx 8.07\times10^{14}\,\text{Hz}$。
选项合理近似为$8\times10^{14}\,\text{Hz}$，选B。

**点评/变式**：本题是$E_k = h\nu - W_0$与$W_0 = h\nu_c$的典型应用。失分点主要集中在$\lambda$单位忘记换算、指数运算错误。**变式**：若给出遏止电压$U_c$，则先通过$E_k = eU_c$得到最大初动能，其余步骤完全一致。
