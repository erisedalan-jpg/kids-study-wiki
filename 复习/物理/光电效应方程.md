## 知识精要
- **光子能量**：$E=h\nu=h\frac{c}{\lambda}$，其中 $h$ 为普朗克常量（$6.63\times10^{-34}\,\text{J·s}$），$c$ 为真空中光速（$3.00\times10^{8}\,\text{m/s}$）。
- **爱因斯坦光电效应方程**：$E_k = h\nu - W_0$ 或 $E_k = h\frac{c}{\lambda} - W_0$，$E_k$ 为光电子的最大初动能。
- **逸出功**：$W_0 = h\nu_0 = h\frac{c}{\lambda_0}$，$\nu_0$ 为截止频率（极限频率），$\lambda_0$ 为截止波长（红限波长）。仅当入射光频率 $\nu > \nu_0$（或 $\lambda < \lambda_0$）时才能发生光电效应。
- **遏止电压**：$eU_c = E_k$，其中 $e$ 为元电荷，$U_c$ 为遏止电压。最大初动能等于电场力对光电子所做的功。
- **适用条件**：单个光子与单个电子相互作用；光子能量必须大于金属逸出功；与光强无关（光强影响饱和光电流）。

## 解题方法与套路
1. **明确已知量与所求量**：提取题目中的波长 $\lambda$、频率 $\nu$、最大初动能 $E_k$、截止频率/波长、遏止电压等。
2. **选择核心方程**：
   - 涉及最大初动能与入射光频率/波长：$E_k = h\nu - W_0$。
   - 涉及逸出功与截止频率/波长：$W_0 = h\nu_0 = h\frac{c}{\lambda_0}$。
   - 涉及遏止电压：$eU_c = E_k$。
3. **统一单位**：波长通常换算为米（$\text{nm}\to\text{m}$，$1\,\text{nm}=10^{-9}\,\text{m}$）；能量单位用焦耳（$\text{J}$）或电子伏特（$\text{eV}$，$1\,\text{eV}=1.6\times10^{-19}\,\text{J}$）；频率单位为 $\text{Hz}$。
4. **联立代数运算**：将已知数据代入方程，注意指数运算与有效数字，解出未知量。
5. **验证结果合理性**：检查求得频率/波长是否满足发生光电效应的条件。

## 高频易错
- **混淆波长与频率**：忘记用 $c=\lambda\nu$ 进行转换，或直接用波长套用频率公式。
- **单位不统一**：未将纳米转换为米，直接与光速（$\text{m/s}$）运算导致数量级错误。
- **误用最大初动能与频率的正比关系**：最大初动能与频率是 **线性关系** $E_k = h\nu - W_0$，并非正比，图线不过原点。
- **遏止电压方向与符号**：牢记 $eU_c = E_k$ 中的 $U_c$ 为绝对值，遏止电压对应光电子恰被反向电场截止。
- **计算指数失误**：普朗克常量、光速、波长数值均含 $10$ 的幂次，运算时易因指数加减出错，建议分步处理系数与幂指数。

## 代表题精讲
### **题目1**（2018-新课标Ⅱ-04）
**简述**：波长为 $300\,\text{nm}$ 的光照射锌板，电子最大初动能为 $1.28\times10^{-19}\,\text{J}$，求能使锌产生光电效应的单色光最低频率。  
**思路**：最低频率即截止频率 $\nu_0$。先由光电效应方程求逸出功 $W_0$，再由 $W_0=h\nu_0$ 求 $\nu_0$。  
**步骤**：  
1. 将波长换算为米：$\lambda = 300\,\text{nm}=3.00\times10^{-7}\,\text{m}$。  
2. 由 $E_k = h\frac{c}{\lambda} - W_0$，得 $W_0 = h\frac{c}{\lambda} - E_k$。  
   计算 $h\frac{c}{\lambda} = \frac{6.63\times10^{-34} \times 3.00\times10^{8}}{3.00\times10^{-7}} = 6.63\times10^{-19}\,\text{J}$。  
   则 $W_0 = 6.63\times10^{-19} - 1.28\times10^{-19} = 5.35\times10^{-19}\,\text{J}$。  
3. 由 $W_0 = h\nu_0$ 得 $\nu_0 = \frac{W_0}{h} = \frac{5.35\times10^{-19}}{6.63\times10^{-34}} \approx 8.07\times10^{14}\,\text{Hz}$。  
   最接近选项为 $8\times10^{14}\,\text{Hz}$。  
**点评/变式**：本题属于直接套用公式的基础题，核心是 $\frac{hc}{\lambda}$ 的计算与指数处理。变式可改为已知逸出功和入射波长，求遏止电压，只需多一步 $eU_c=E_k$。

### **题目2**（2011-新课标-17）
**简述**：某金属截止频率对应的波长为 $\lambda_0$，求金属逸出功；用波长为 $\lambda$（$\lambda<\lambda_0$）的光照射，求遏止电压。（用 $e$、$c$、$h$ 和 $\lambda_0$、$\lambda$ 表示）  
**思路**：先用截止波长表示逸出功 $W_0 = h\frac{c}{\lambda_0}$；再由光电效应方程与 $eU_c=E_k$ 求遏止电压的表达式。  
**步骤**：  
1. 逸出功：$W_0 = h\nu_0 = h\frac{c}{\lambda_0}$。  
2. 波长为 $\lambda$ 的光子能量 $E = h\frac{c}{\lambda}$。最大初动能 $E_k = h\frac{c}{\lambda} - h\frac{c}{\lambda_0}$。  
3. 由 $eU_c = E_k$，得遏止电压 $U_c = \frac{E_k}{e} = \frac{hc}{e}\left(\frac{1}{\lambda} - \frac{1}{\lambda_0}\right)$。  
**点评/变式**：该类符号推导题强调物理表达式的规范书写。注意 $\lambda<\lambda_0$ 的条件保证括号内为正值。常考变形：给出遏止电压与波长关系图像，通过斜率与截距求 $h$ 和 $\lambda_0$。
