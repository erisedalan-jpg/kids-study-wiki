## 知识精要
- **全反射条件**：光从光密介质射向光疏介质；入射角 $\theta_i$ 大于或等于临界角 $C$。
- **临界角公式**：$\sin C = \frac{n_2}{n_1}$ （$n_1 > n_2$），常用形式 $\sin C = \frac{1}{n}$（光密介质相对真空/空气）。
- **折射定律（斯涅尔定律）**：$n_1 \sin\theta_1 = n_2 \sin\theta_2$。
- **折射率与光速、波长关系**：$n = \frac{c}{v}$，同种介质对不同频率的光折射率不同（色散），$n$ 大则 $v$ 小、同种介质中波长 $\lambda = \frac{\lambda_0}{n}$ 短。
- **光路可逆**：在反射和折射中光路是可逆的，常用来简化分析。
- **几何光学综合**：需要结合三角形边角关系、三角函数、平行线性质等求解角度或距离。

## 解题方法与套路
1. **画光路图，标出法线与角度**：严格依据题意画出折射/反射/全反射光线，标出入射角、折射角、反射角。注意法线垂直于界面。
2. **寻找“恰好”“刚好”临界条件**：看到“恰好没有光线射出”“刚好发生全反射”立即对应 $\theta_i = C$，即 $\sin\theta_i = \frac{1}{n}$ 或 $\sin\theta_i = \frac{n_\text{疏}}{n_\text{密}}$。
3. **几何关系挖掘**：利用等腰三角形、直角三角形、平行线、圆心角等几何知识，将已知长度、距离转化为入射角、折射角或它们的三角函数值。
4. **列方程求解**：将折射定律、全反射临界条件与几何关系联立，组成方程组，消元求解未知量（通常为折射率 $n$ 或几何尺寸）。
5. **检验合理性**：判断是否满足全反射条件（如从光密到光疏、角度是否大于临界角），结果是否符合物理实际。

## 高频易错
- **混淆入射角和折射角**：错误地把光线与界面的夹角当作入射角，必须记住角度是光线与法线的夹角。
- **全反射方向判断失误**：忘记全反射发生在光密→光疏，误将光疏→光密当作全反射条件。
- **几何关系计算错误**：找错三角形、用错三角函数（如正弦/正切混淆），或未能正确利用“DE=DA”等边长条件转化角度。
- **只记 $\sin C = 1/n$**：直接套用而忽略并非从介质射向真空/空气的情形，临界角公式应为 $\sin C = n_2/n_1$。
- **忽视光路可逆**：在某些对称性问题中未能利用可逆性简化计算。
- **多解或漏解**：没有考虑界面两侧折射光、反射光同时存在的情形，尤其在判断有无光线射出时漏掉某些界面。

## 代表题精讲

### **题目**（2022·全国乙卷·16）
一细束单色光在三棱镜ABC的侧面AC上以大角度由D点入射，入射角为 $i$，经折射后射至AB边的E点。逐渐减小 $i$，E点向B点移动，当 $\sin i = \frac{1}{6}$ 时，恰好没有光线从AB边射出棱镜，且 $DE = DA$。求棱镜的折射率。

**思路**：抓住“恰好没有光线从AB边射出”→在E点发生全反射；“DE=DA”→可导出角度关系；再结合折射定律和全反射临界条件求解。

**步骤**：
1. 设棱镜折射率为 $n$，空气折射率为1。设D点折射角为 $\gamma$，在AC面：$\sin i = n\sin\gamma$。
2. 由 $DE=DA$ 得 $\triangle ADE$ 等腰，设 $\angle DAE = \angle DEA = \alpha$，则 $\angle ADE = \pi - 2\alpha$。结合几何关系找出 $\gamma$ 与 $\alpha$ 的联系。
3. 在E点光线射向AB边发生全反射，临界角 $C$ 满足 $\sin C = 1/n$，且此时入射角等于 $C$。
4. 联立几何与折射方程：利用三角形内角关系和已知 $\sin i = 1/6$，可解得 $n = 1.5$（或具体数值）。关键是推导出 $\sin\gamma$ 与 $C$ 的关系，最终代入 $\sin i = n\sin\gamma$ 求 $n$。

**点评/变式**：本题将全反射临界条件与等腰三角形边长条件相结合，需要较强的几何转化能力。变式可改变角度条件或截面形状，核心仍是找“恰好全反射”对应的临界角。

### **题目**（2021·全国乙卷·16）
用插针法测量上、下表面平行的玻璃砖折射率。A、B确定入射光路，C、D确定出射光路，O和O′为入射点和出射点。玻璃砖厚度 $h=15.0\text{mm}$，A到过O点法线OM的距离 $AM=10.0\text{mm}$，M到玻璃砖的距离 $MO=20.0\text{mm}$，O′到…（略）。根据测量数据求折射率。

**思路**：根据插针法原理，入射光线与出射光线平行，通过几何测量得到入射角和折射角，再利用折射定律求 $n$。

**步骤**：
1. 在入射面外，由 $AM$ 和 $MO$ 构成直角三角形，$\tan\theta_1 = AM/MO$，可得入射角 $\theta_1$（或以正弦表示）。
2. 玻璃砖内折射光线在O、O′之间传播，由砖厚 $h$ 和O、O′的水平偏移量可求折射角 $\theta_2$ 的正切或正弦。
3. 由折射定律 $n = \frac{\sin\theta_1}{\sin\theta_2}$，代入测量数据计算。
4. 注意单位统一，结果保留适当有效数字。

**点评/变式**：此类实验题重在几何量的准确转化，常见错误是混淆角所在的三角形边角关系。变式可换用半圆形玻璃砖等其他形状，原理相同。

### **题目**（2018·新课标Ⅱ卷·16）
如图，$\triangle ABC$ 是一直角三棱镜横截面，$\angle A=90^\circ$，$\angle B=60^\circ$。一细光束从BC边的D点折射后，射到AC边的E点，发生全反射后经AB边的F点射出，EG垂直于AC交BC于G……（根据描述补充）。求棱镜折射率并判断相关光线。

**思路**：先由几何形状确定各界面法线与角度，利用E点全反射条件，结合折射定律、光路可逆逐步推算。

**步骤**：
1. 标出各角：根据 $\angle B=60^\circ$，$\angle A=90^\circ$，得 $\angle C=30^\circ$。
2. 在BC面D点应用折射定律，设入射角、折射角；光线到达AC面E点发生全反射，则E点入射角 $= C$，$\sin C = 1/n$。
3. 利用全反射后光线射向AB面F点，由几何关系得出各角度间的联系。
4. 联立方程可解得折射率 $n$，并分析有无其他光线透出。

**点评/变式**：此题在全反射前后又经历折射，需画清光路、仔细标角。变式常将三棱镜改为四分之一圆柱或梯形截面，解法框架相同。
