## 知识精要
- 电场力做功与电势能变化：$W_{AB} = E_{pA} - E_{pB} = qU_{AB}$。正电荷电势能减小，电场力做正功。
- 匀强电场中电势分布特征：沿任意直线，电势均匀变化。任意两点连线的中点电势等于两点电势的平均值：$\varphi_M = \frac{\varphi_A + \varphi_C}{2}$（$M$ 为 $AC$ 中点）。
- 推论：若 $M$、$N$ 分别为 $a$–$c$、$b$–$d$ 的中点，则 $U_{MN} = \frac{1}{2}(U_{ab} + U_{cd})$? 需谨慎。正确关系：$\varphi_M = \frac{\varphi_a+\varphi_c}{2}$，$\varphi_N = \frac{\varphi_b+\varphi_d}{2}$，故 $U_{MN} = \varphi_M - \varphi_N = \frac{1}{2}[(\varphi_a-\varphi_b) + (\varphi_c-\varphi_d)] = \frac{U_{ab}+U_{cd}}{2}$。由此可得 $W_{MN} = qU_{MN} = \frac{W_{ab}+W_{cd}}{2}$。
- 匀强电场场强与电势差关系：$E = \frac{U}{d}$，$d$ 必须是沿电场线方向的距离。仅靠任意两点距离无法直接确定场强大小。

## 解题方法与套路
1. **识别中点条件**：题目给出中点，立刻联想到匀强电场中“中点电势等于两端点电势的平均值”。
2. **转化已知做功为电势差**：由 $W = qU$，将电势能变化量转化为两点间电势差，注意正负号（正电荷 $W$ 为正表示 $U>0$，沿着电场力方向电势降低）。
3. **应用中点电势关系列式**：设未知电势（或直接表达 $U_{MN}$），利用 $\varphi_M = \frac{\varphi_a+\varphi_c}{2}$，$\varphi_N = \frac{\varphi_b+\varphi_d}{2}$，求出目标电势差 $U_{MN} = \frac{U_{ab}+U_{cd}}{2}$。
4. **检验场强相关选项**：看到直接由 $E = W/(qL)$ 的表述，务必检查 $L$ 是否沿场强方向；若不明确，选项一般错误。场强方向判定需要等势面信息，仅凭一对点做功不能唯一确定场强方向。
5. **匀强电场中平行四边形/任意四边形中点**：可将图形置于坐标系中，利用电势与位置坐标的线性关系 $\varphi = Ex + Fy + G$，中点坐标对应函数值求平均，快速验证做功关系。

## 高频易错
- **误判场强方向**：由 $a \to b$ 电场力做功只能给出 $a$、$b$ 电势高低，不能推断场强方向与 $ab$ 连线平行。场强方向可能沿任意方向，只要 $a$、$b$ 在电场方向上的投影距离合适。
- **错用场强公式**：认为 $E = \frac{W}{qL}$ 普遍成立，忽略公式 $E = \frac{U}{d}$ 中 $d$ 是沿场强方向的有效距离。题中所给 $L$ 若非 $c$、$d$ 沿场强方向距离，则该表达式错误。
- **忽略电荷符号**：题干指定 $q>0$ 时较简单；若电荷符号不定，需分析不同电荷下做功与电势能变化的符号关系。
- **电势能“减小”理解偏差**：电势能减小 $W_1$ 意味着电场力做功 $W_1$（正功），即 $W_{ab} = W_1$，$U_{ab} = W_1/q$。

## 代表题精讲
### 代表题：2018-新课标Ⅱ-08
**题目**：$a$、$b$、$c$、$d$ 四点处于与平面平行的匀强电场中，$M$ 为 $a$、$c$ 连线中点，$N$ 为 $b$、$d$ 连线中点。正电荷 $q$ 从 $a$ 到 $b$ 电势能减小 $W_1$，从 $c$ 到 $d$ 电势能减小 $W_2$。判断：
- A．场强方向一定与 $a$、$b$ 连线平行
- B．粒子从 $M$ 到 $N$，电场力做功一定为 $\frac{W_1+W_2}{2}$
- C．若 $c$、$d$ 间距为 $L$，则场强大小一定为 $\frac{W_2}{qL}$

**思路**：利用匀强电场中电势线性分布特性，构建中点电势关系，再将功转化为电势差进行运算。

**步骤**：
1. 由正电荷电势能减少知 $W_{ab}=W_1$，$W_{cd}=W_2$，故 $U_{ab}=W_1/q$，$U_{cd}=W_2/q$。
2. $M$ 为 $ac$ 中点 $\Rightarrow$ $\varphi_M = (\varphi_a+\varphi_c)/2$；$N$ 为 $bd$ 中点 $\Rightarrow$ $\varphi_N = (\varphi_b+\varphi_d)/2$。
3. $U_{MN}=\varphi_M-\varphi_N = \frac{1}{2}[(\varphi_a-\varphi_b)+(\varphi_c-\varphi_d)] = \frac{1}{2}(U_{ab}+U_{cd})$。
4. 故 $W_{MN}=qU_{MN}=\frac{W_1+W_2}{2}$，B 对。
5. A 错：$a$、$b$ 连线方向不一定是场强方向，做功仅反映沿场强方向投影的移动。
6. C 错：$L$ 若不沿场强方向，不能直接用 $E=\frac{U_{cd}}{L}=\frac{W_2}{qL}$，缺少有效距离条件。

**点评/变式**：本题核心是“匀强电场中两点连线中点电势等于两端电势平均值”，任意四边形中连接对边中点得到的线段，其两端电势差等于另外两组对边电势差的平均值。变式可改为已知某三点电势，求第四点或中点电势，或结合几何图形求电场强度方向。
