## 知识精要
- **曲线运动条件与力向判断**：质点做曲线运动时，所受合外力（或加速度）必指向轨迹弯曲的内侧（凹侧），速度方向沿轨迹该点的切线方向。  
- **速率变化与夹角关系**：合外力与速度的夹角 $\theta$ 决定速率增减——$0^\circ \le \theta < 90^\circ$ 时速率增大；$\theta = 90^\circ$ 时速率为极值；$90^\circ < \theta \le 180^\circ$ 时速率减小。速率递减等价于合力与速度成钝角。  
- **电场力方向规定**：电场强度 $\vec{E}$ 的方向规定为正电荷所受电场力 $\vec{F}$ 的方向。负电荷受力 $\vec{F} = q\vec{E}$（$q<0$），因此 $\vec{F}$ 与 $\vec{E}$ 反向。  
- **切线方向**：轨迹上某点的切线方向代表质点在该点的瞬时速度方向，是判断力与运动方向关系的基准。

## 解题方法与套路
1. **定速度方向**：在题目给定的点（如b点）沿轨迹切线画出速度 $\vec{v}$ 的方向，用虚线或箭头标出质点运动指向。  
2. **定合力凹侧**：根据轨迹弯曲形状，标出凹侧，合外力 $\vec{F}_合$ 必指向这一侧。  
3. **夹角定增减**：由题干“速率递减”得出 $\vec{F}_合$ 与 $\vec{v}$ 夹角为钝角（$>90^\circ$）；若“速率递增”则为锐角。由此将力的指向从“大致在凹侧”进一步约束为“在凹侧且偏向速度反向一侧”。  
4. **电荷转场强**：  
   - 正电荷：$\vec{E}$ 与 $\vec{F}_合$ 同向；  
   - 负电荷：$\vec{E}$ 与 $\vec{F}_合$ 反向。  
5. **选项匹配**：在示意图中将上述确定的 $\vec{E}$ 方向范围与各选项矢量比对，指向吻合者即为正确选项。  

## 高频易错
- **忘记电荷符号翻转**：直接把合外力方向当作电场强度方向，负电荷时必须反向。  
- **凹侧方向看反**：轨迹弯曲内侧判断失误，导致合力指向完全错误。  
- **速率增减与夹角关系记混**：误以为速率减小对应锐角，速率增大对应钝角。  
- **切线画不准**：速度方向偏离真实切线，造成后续夹角判断全错。  
- **忽视“只受电场力”条件**：若题目中有多力，需先作力的合成或分解，不能直接将电场力视为合外力。

## 代表题精讲
**题目**（2011新课标·07）：一带负电荷的质点仅在电场力作用下，沿曲线 $abc$ 从 $a$ 运动到 $c$，速率递减。虚线为 $b$ 点切线，问 $b$ 点电场强度 $\vec{E}$ 的方向可能正确的图示。  

**思路**：抓住“负电荷→$\vec{E}$ 与电场力 $\vec{F}$ 反向”“曲线运动→$\vec{F}$ 指向凹侧”“速率递减→$\vec{F}$ 与速度 $\vec{v}$ 成钝角”三层约束，从力学关系中反推出 $\vec{E}$ 的方向范围。  

**步骤**  
1. 在 $b$ 点沿切线（虚线）画出速度 $\vec{v}$ 的方向（质点从 $a$ 到 $c$ 的运动指向）。  
2. 观察轨迹弯曲，确定凹侧。$\vec{F}$ 必须指向凹侧，且因速率递减，$\vec{F}$ 与 $\vec{v}$ 夹角 $>90^\circ$，故 $\vec{F}$ 指向凹侧并偏向速度的后方。  
3. 质点带负电，$\vec{E} = \vec{F}/q$ 且 $q<0$，所以 $\vec{E}$ 与 $\vec{F}$ 反向。于是 $\vec{E}$ 应指向轨迹的凸侧，同时与速度 $\vec{v}$ 的夹角为锐角（$<90^\circ$）。  
4. 将四个选项示意图逐一检验：凡 $\vec{E}$ 指向凹侧或与 $\vec{v}$ 成钝角的选项均错误，仅 $\vec{E}$ 指向凸侧偏后且与速度成锐角的选项符合。正确选项为 D。  

**点评/变式**  
- 本题将曲线运动、功与速率变化、电场方向三个基础知识点串联，错选多因忽略负电荷导致的 $\vec{E}$ 与 $\vec{F}$ 反向。  
- 变式：若质点带正电且速率递增，则 $\vec{E}$ 与 $\vec{F}$ 同向指向凹侧且与速度成锐角；若只受重力，则加速度恒为 $\vec{g}$ 竖直向下，同样用凹侧和夹角约束判断轨迹形态。核心思路均为“定凹侧→定合力夹角→定场力方向”。
