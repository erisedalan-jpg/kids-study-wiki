## 知识精要
- **核心模型**：实际刹车过程包含反应时间（匀速）→ 制动系统响应（过渡阶段，通常忽略或简化）→ 稳定制动（匀减速直至停下）。若题干简化为“立即刹车”且稳定减速，则模型为初速 $v_0$、末速 $0$ 的匀减速直线运动。
- **基本公式**（匀减速至停止，$a>0$ 表示加速度大小）：
  - 速度：$v = v_0 - a t$
  - 位移：$x = v_0 t - \frac{1}{2}a t^2$
  - 消时公式：$v^2 = v_0^2 - 2a x$
  - 停止时间：$t_0 = \frac{v_0}{a}$，停止距离：$x_{\text{停}} = \frac{v_0^2}{2a}$
- **适用条件**：以上匀变速公式仅在 $t \le t_0$ 时适用；若 $t > t_0$，汽车已停止，速度恒为 $0$，位移等于 $x_{\text{停}}$，**不可**直接套用原始运动学公式。
- **多过程衔接**：先画运动示意图，标出各阶段初末状态。反应时间内的匀速位移 $x_{\text{反}} = v_0 t_{\text{反}}$，制动距离再加安全距离判断是否碰撞。

## 解题方法与套路
1. **判停是关键**：处理给定时间位移问题，先假设汽车未停止，解出 $v_0$、$a$，再算出停止时间 $t_0$，检验题目给定时间内汽车是否已停。若给定时刻超过 $t_0$，须分段计算或用逆向思维（末速为零的反向匀加速）。
2. **巧用平均速度**：匀变速直线运动中 $\bar{v}=\frac{v_0+v}{2}=\frac{x}{t}$，尤其适合已知连续相等时间位移或处理“第 $n$ 秒内位移”的问题，可建立中间时刻瞬时速度关系。
3. **逆向转换法**：末速为零的匀减速过程，可逆向视为初速为零的匀加速，位移公式简化为 $x = \frac{1}{2}a t^2$，计算更少出错。
4. **图像辅助**：画 $v\text{-}t$ 图，图线下面积代表位移，斜率代表加速度。复杂多过程问题中，图像能直观反映停止时刻与位移关系。
5. **刹车“陷阱”标准流程**：
   - 第一步：设匀减速运动的初速度 $v_0$、加速度大小 $a$。
   - 第二步：根据某段时间位移列出方程（注意时间范围要小于 $t_0$，若不确定则设未知数）。
   - 第三步：求出的 $v_0$、$a$ 必须满足 $t_0=\frac{v_0}{a}$ 使位移数据自洽，排除矛盾解。
   - 第四步：再计算所求量（总位移、某段时间位移等）。

## 高频易错
- **未判断物体是否先停下**：直接套用 $x = v_0 t - \frac{1}{2}a t^2$ 计算给出的“第 $4\ \text{s}$ 内”位移，可能会得到加速度多解，甚至误认为一直在运动。必须验证汽车是在哪一时刻停止的。
- **对“第 $n$ 秒内”理解不当**：“第 $4\ \text{s}$ 内”指从第 $3\ \text{s}$ 末到第 $4\ \text{s}$ 末这 $1\ \text{s}$ 的位移。若汽车在第 $3.5\ \text{s}$ 停止，则“第 $4\ \text{s}$ 内”实际运动时间不足 $1\ \text{s}$。
- **混淆位移与路程**：本题为单向直线运动，位移大小等于路程，但使用公式时若反向加速必须特别留意方向。
- **多过程衔接丢失初始条件**：把反应时间结束时的速度误当作零，错误重置计时起点。牢记制动过程的初速度等于反应时间的末速度。
- **符号体系混乱**：匀减速运动中加速度方向与速度方向相反。建议在计算中用加速度大小 $a$（正值）列式 $v = v_0 - a t$，避免代入负值导致运算错误。

## 代表题精讲
**题目**：2019·新课标Ⅱ·12  
一质量 $m=2000\ \text{kg}$ 的汽车在平直公路上匀速行驶，司机突然发现前方 $100\ \text{m}$ 处有警示牌立即刹车。阻力随时间变化简化为图线：$0\sim t_1$ 为反应时间 $t_1=0.8\ \text{s}$（阻力忽略，汽车匀速）。$t_1\sim t_2$ 为刹车系统启动时间 $t_2=1.3\ \text{s}$。$t_2$ 时刻后刹车系统稳定工作至停止。已知从 $t_2$ 时刻开始，汽车第 $1\ \text{s}$ 内的位移为 $24\ \text{m}$，第 $4\ \text{s}$ 内的位移为 $1\ \text{m}$。

**思路**：  
关键在 $t_2$ 后为匀减速直线运动，初速 $v_2$、加速度大小 $a$。给定时间间隔的位移隐含停止时刻信息。设 $t_2=0$ 为新计时起点，用匀变速推论列式，判断汽车是否在第 $4\ \text{s}$ 前已停止，求出 $v_2$ 与 $a$，最后根据全过程求司机发现警示牌时的初速度及是否撞上。

**步骤**：  
1. 设从 $t_2$ 时刻起汽车初速度为 $v_2$，加速度大小为 $a$（$a>0$）。  
2. 第 $1\ \text{s}$ 内位移 $24\ \text{m}$：若第 $1\ \text{s}$ 内未停止，有 $x_1 = v_2 \times 1 - \frac{1}{2}a \times 1^2 = 24$ ①  
3. 判断第 $4\ \text{s}$ 内运动情况。假设汽车在第 $4\ \text{s}$ 内已停止，设停止时刻为 $n$ 秒（$3 < n \le 4$），则第 $4\ \text{s}$ 内位移仅为 $3\sim n$ 秒的位移。用逆向思维，从停止时刻反向看做初速为零的匀加速，第 $4\ \text{s}$ 内位移等于最后 $(n-3)$ 秒的位移。  
   但更严谨方法是：先假设 $4\ \text{s}$ 末未停止，由匀变速规律，相邻相等时间位移差 $\Delta x = -aT^2$，若 $4\ \text{s}$ 内一直运动，则第 $4\ \text{s}$ 内位移 $x_4$ 与 $x_1$ 满足 $x_4 = x_1 - 3a$。代入 $x_4=1\ \text{m}$，得 $1 = 24 - 3a \Rightarrow a = \frac{23}{3} \approx 7.67\ \text{m/s}^2$。再代回①得 $v_2 = 24 + 0.5a = 24 + \frac{23}{6} \approx 27.83\ \text{m/s}$，停止时间 $t_0 = v_2/a \approx 3.63\ \text{s} < 4\ \text{s}$，这与假设“$4\ \text{s}$ 内一直运动”矛盾。故汽车在第 $4\ \text{s}$ 内已停止。  
4. 正确列式：设汽车在 $t_2$ 之后运动总时间为 $T$ 秒停下。逆向看，第 $1\ \text{s}$ 内位移为 $24\ \text{m}$，它在逆向中是最后 $1\ \text{s}$ 内的位移；第 $4\ \text{s}$ 内位移为 $1\ \text{m}$，它在逆向中对应从停止往前数第 $4\ \text{s}$ 内（即 $3\sim 4\ \text{s}$ 区间）的位移。由逆向初速为零的匀加速：  
   连续相等时间位移比 $x_Ⅰ:x_Ⅱ:x_Ⅲ:x_Ⅳ… = 1:3:5:7…$  
   已知正向第 $1\ \text{s}$ 内（逆向最后 $1\ \text{s}$）为 $24\ \text{m}$，则该比值对应 $1$ 份？不是，需考虑停止时间 $T$ 可能不是整数。  
   改用公式：$v_2 - aT = 0$。  
   正向最后 $1\ \text{s}$ 位移即逆向第 $1\ \text{s}$：$\frac{1}{2}a \times 1^2 = \frac{a}{2}$。但这与 $24\ \text{m}$ 不直接相等，因为题目中“第 $1\ \text{s}$ 内”不一定就是最后 $1\ \text{s}$，可能停止时刻在第 $1\ \text{s}$ 之后。  
   重新严谨分析：由第 $1\ \text{s}$ 内位移 $24\ \text{m}$ 知汽车在第 $1\ \text{s}$ 内未停止；第 $4\ \text{s}$ 内位移 $1\ \text{m}$ 表示汽车在 $3\sim 4\ \text{s}$ 之间某时刻停止。设从 $t_2$ 起经过 $t$ 秒停止，$3 < t \le 4$。  
   正向：$x_1 = v_2 \times 1 - \frac{1}{2}a \times 1^2 = 24$。  
   第 $4\ \text{s}$ 内位移 $= $ 从 $3\ \text{s}$ 到 $t$ 的位移：$x_{3\to t} = [v_2 \times 3 - \frac{1}{2}a \times 3^2] - [v_2 t - \frac{1}{2}a t^2]?$ 这么算复杂。用末速为零求逆向位移更方便：  
   逆向初速为零，运动总时间 $T = t$。则正向第 $1\ \text{s}$ 内位移对应逆向最后 $1\ \text{s}$ 位移，只要 $t>1$ 成立。逆向最后 $1\ \text{s}$ 位移：$x_{\text{逆1}} = \frac{1}{2}a ( T^2 - (T-1)^2 ) = \frac{1}{2}a(2T-1) = 24$。  
   正向第 $4\ \text{s}$ 内位移，即逆向来看，是从起始（停止时刻）往前数第 $4\ \text{s}$ 内的位移（若 $t\le 4$，则第 $4\ \text{s}$ 内只有 $t-3$ 秒的运动）。逆向第 $1\ \text{s}$ 位移 $x_{Ⅰ}$，第 $2\ \text{s}$ 位移 $x_{Ⅱ}=3x_{Ⅰ}$，但仅限于 $t\ge 4$。题目中 $3<t\le4$，逆向第 $4\ \text{s}$ 不完整。  
   实际逆向总时间 $T$ 小于 $4\ \text{s}$，逆向第 $4\ \text{s}$ 内其实只运动了最后 $(T-3)$ 秒这段时间。逆向在最后 $(T-3)$ 秒内的位移等于 $\frac{1}{2}a (T-3)^2$（因为初速为零）。它对应正向第 $4\ \text{s}$ 内位移 $1\ \text{m}$。  
   而正向第 $1\ \text{s}$ 内位移为逆向从 $T$ 到 $T-1$ 的位移：$24 = \frac{1}{2}a[T^2 - (T-1)^2] = \frac{1}{2}a(2T-1)$。  
   正向第 $4\ \text{s}$ 内位移 $1 = \frac{1}{2}a (T-3)^2$ （因为 $T\le4$，$T-3 > 0$）。  
   两式联立：$a(2T-1) = 48$，$a(T-3)^2 = 2$。  
   相除：$\frac{a(2T-1)}{a(T-3)^2} = \frac{48}{2} \Rightarrow \frac{2T-1}{(T-3)^2} = 24$。  
   展开：$2T-1 = 24(T^2 -6T +9) = 24T^2 -144T + 216$  
   $\Rightarrow 24T^2 -146T + 217 = 0$。  
   解得 $T = \frac{146 \pm \sqrt{146^2 - 4 \times 24 \times 217}}{2 \times 24} = \frac{146 \pm \sqrt{21316 - 20832}}{48} = \frac{146 \pm 22}{48}$，$T_1 = 3.5\ \text{s}$，$T_2 = \frac{124}{48} \approx 2.58\ \text{s}$（舍去，因 $3 < T \le 4$）。取 $T = 3.5\ \text{s}$。  
   则 $a = \frac{2}{(T-3)^2} = \frac{2}{0.5^2} = 8\ \text{m/s}^2$。  
   $v_2 = aT = 8 \times 3.5 = 28\ \text{m/s}$。  
5. 全过程：$0\sim t_1$ 反应时间匀速，初速度 $v_0 = v_2 = 28\ \text{m/s}$（本题假设启动时间内速度变化可以忽略，题干暗示刹车系统稳定后从 $t_2$ 开始匀减速，且 $t_1\sim t_2$ 内阻力变化但未给出具体运动，通常题目会要求求出 $t_2$ 时刻速度即为反应时间结束时的速度，若需考虑启动阶段，可按图线计算）。本题后续还会求汽车运动总时间，并判断是否撞上 $100\ \text{m}$ 处警示牌（通常列位移求和比较即可）。

**点评/变式**：  
此题完美展现“刹车陷阱”的经典命题——通过“第 $4\ \text{s}$ 内位移”制造物体提前停止的隐藏条件。解题必须跳出“全过程匀变速”的思维定式，先判断再代入。逆向思维将复杂分段计算变为初速为零的匀加速，大幅简化方程。变式训练：可将本题改为已知最后 $1\ \text{s}$ 位移和全部制动时间，反求初速度；或增加反应时间、安全距离判断是否相撞，强化多过程分析能力。
