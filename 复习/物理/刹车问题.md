## 知识精要
- **刹车问题的本质**：实际汽车刹车过程并非理想的匀减速直线运动，但系统稳定工作后通常可视为**匀减速直线运动直至停止**。核心模型为末速度为零的匀变速直线运动。
- **“刹车陷阱”**：物体做匀减速运动，速度减为零后即静止，不会反向加速。计算某段时间内的位移时，必须先判断物体在该时间段内是否已停止，即求**刹车时间** $t_0 = \frac{v_0}{a}$（或结合速度公式 $v = v_0 + at$ 令 $v=0$）。
- **反应时间与启动时间**：从发现情况到刹车系统生效存在时间差。反应时间内汽车匀速行驶；启动时间内制动力逐渐增大（变减速），通常题目会给出简化模型或分阶段处理。
- **匀变速直线运动基本公式**（以初速度 $v_0$ 方向为正，加速度 $a$ 通常为负值）：
  - 速度公式：$v = v_0 + at$
  - 位移公式：$x = v_0 t + \frac{1}{2}at^2$
  - 速度-位移关系：$v^2 - v_0^2 = 2ax$
  - 平均速度：$\bar{v} = \frac{x}{t} = \frac{v_0+v}{2}$（仅匀变速适用）
- **逐差法推论**：匀变速直线运动中，连续相等时间 $T$ 内的位移差 $\Delta x = aT^2$。可推广为 $x_m - x_n = (m-n)aT^2$，用于求加速度。

## 解题方法与套路
1. **画过程草图，明确阶段**：将运动分为“匀速反应阶段→变减速启动阶段→匀减速刹车阶段”。标出已知量、未知量，特别关注题目给出的“从某时刻起第几秒内的位移”这类条件。
2. **优先判断刹车时间**：对于末速度为零的匀减速阶段，先设加速度大小为 $a$，利用 $v_0$（或该阶段初速度）求出理论上停止所需时间 $t_{停}$。若题目给出 $n$ 秒内的位移，必须比较 $n$ 与 $t_{停}$ 的关系，确认物体在该秒内是否已停。
3. **灵活选用运动学公式**：
   - 涉及位移与时间时，若已知初速度或末速度，优先使用平均速度公式 $x = \frac{v_0+v}{2}t$，可避免二次方程。
   - 已知两段相等时间内的位移时，使用 $\Delta x = aT^2$ 快速求加速度，但必须保证两段时间内物体均在做完整的匀变速运动（未停止）。
4. **逆向思维**：末速度为零的匀减速直线运动，可逆向看作初速度为零的匀加速直线运动，按比例关系简化计算（如初速为零的连续相等时间内位移比 $1:3:5:\cdots$）。
5. **检验物理合理性**：算出结果后，验证是否符合题意：加速度方向是否与运动方向相反，减速时间是否超过刹车时间而出现反向运动等。

## 高频易错
- **死套公式，忽视停止**：直接对整段时间（如第 $4\textrm{s}$ 内）套用位移公式或推论，未判断汽车是否已停止，导致计算出错。务必先算刹车总时间。
- **混淆“第 $n$ 秒内”与“前 $n$ 秒内”**：前者是 $1\textrm{s}$ 内的位移，后者是 $n\textrm{s}$ 内的位移。条件“第 $4\textrm{s}$ 内的位移为 $1\textrm{m}$”指第 $4$ 个 $1\textrm{s}$ 内的位移，不是前 $4$ 秒的总位移。
- **误用“相邻相等时间位移差”公式**：当 $x_4$ 对应的 $1\textrm{s}$ 内物体并非全程在运动（中途停止），则 $x_4 - x_1 = 3aT^2$ 不再成立，必须先判断。
- **反应时间内仍按减速处理**：反应时间内驾驶员未采取制动，汽车保持原速匀速运动，此段位移为 $x = v_0 t_{反}$。
- **符号混乱**：未统一规定正方向，导致加速度 $a$ 的正负与位移、速度符号矛盾。建议以初速度方向为正，加速度取负值，所得位移均大于零。

## 代表题精讲
### 2019-新课标Ⅱ-12
**题目**：一质量为 $m=2000\textrm{kg}$ 的汽车在平直公路匀速行驶，司机发现前方 $100\textrm{m}$ 处警示牌立即刹车。阻力随时间变化如图，$0\sim t_1=0.8\textrm{s}$ 为反应时间（匀速）；$t_1\sim t_2=1.3\textrm{s}$ 为启动时间；$t_2$ 起刹车系统稳定匀减速至停止。从 $t_2$ 时刻开始，汽车第 $1\textrm{s}$ 内的位移为 $24\textrm{m}$，第 $4\textrm{s}$ 内的位移为 $1\textrm{m}$。求汽车在 $t_2$ 时刻的速度大小及此后刹车加速度大小，并判断是否撞上警示牌。

**思路**：从 $t_2$ 时刻开始为匀减速直线运动，已知第 $1\textrm{s}$ 内和第 $4\textrm{s}$ 内的位移，需注意“第 $4\textrm{s}$ 内”可能汽车已停止。可先假设均未停止，用逐差法求加速度，再验证停止时间；若矛盾则说明第 $4\textrm{s}$ 内已停下，改用末速为零处理。

**步骤**：
1. **规定正方向**：以汽车行驶方向为正，设 $t_2$ 时刻初速为 $v_0$，加速度大小为 $a$（$a>0$），实际加速度为 $-a$。
2. **采用假设检验**：
   - 若第 $4\textrm{s}$ 内汽车仍在运动，由 $\Delta x = aT^2$：$x_1 - x_4 = 3aT^2$，其中 $T=1\textrm{s}$，得 $24\textrm{m} - 1\textrm{m} = 3a \times 1^2 \Rightarrow a \approx 7.67\textrm{m/s}^2$。
   - 那么刹车时间 $t_停 = \frac{v_0}{a}$。由第 $1\textrm{s}$ 内位移 $x_1 = v_0 \times 1 - \frac{1}{2}a \times 1^2 = 24 \Rightarrow v_0 - 0.5a = 24$。代入 $a$ 解得 $v_0 \approx 27.84\textrm{m/s}$，$t_停 \approx 3.63\textrm{s}$。这意味着 $3\sim 4\textrm{s}$ 内汽车已停止，$x_4=0$，与已知 $1\textrm{m}$ 矛盾。因此假设不成立，汽车在第 $4\textrm{s}$ 内已停止。
3. **正确求解**：设 $t_2$ 后汽车运动总时间为 $t_总$，则 $3\textrm{s} < t_总 \le 4\textrm{s}$。第 $4\textrm{s}$ 内位移为停止前最后的运动：若 $t_总 = 3 + \Delta t$（$0 < \Delta t \le 1$），则 $x_4$ 为最后 $\Delta t$ 时间内的位移，逆向看作初速为零的加速：$x_4 = \frac{1}{2}a(\Delta t)^2 = 1\textrm{m}$。第 $1\textrm{s}$ 内位移 $x_1 = \frac{v_0 + (v_0 - a \cdot 1)}{2} \times 1 = v_0 - 0.5a = 24\textrm{m}$。又 $v_0 = a t_总 = a(3 + \Delta t)$。联立：
   - $a(3+\Delta t) - 0.5a = 24 \Rightarrow a(2.5 + \Delta t) = 24$
   - $\frac{1}{2}a(\Delta t)^2 = 1 \Rightarrow a (\Delta t)^2 = 2$
   - 两式相除消去 $a$：$\frac{2.5 + \Delta t}{(\Delta t)^2} = 12$，整理得 $12(\Delta t)^2 - \Delta t - 2.5 = 0$。
   - 解得 $\Delta t = 0.5\textrm{s}$（负值舍去）。则 $t_总 = 3.5\textrm{s}$，$a = \frac{2}{(\Delta t)^2} = 8\textrm{m/s}^2$，$v_0 = a t_总 = 28\textrm{m/s}$。
4. **判断是否撞上**：全程位移需分段计算。
   - 反应阶段位移 $x_{反} = v_{匀速} \cdot t_1$，需知原匀速速度。由 $t_1\sim t_2$ 启动阶段题未给定量，可结合图像（原题图线为阻力从0线性增至恒值）求此段位移（通常用动量定理或平均阻力近似，但本题核心是后段，原题要求可能仅后段求 $v_0,a$，并给出前段条件求总位移），此处从略。假设已得总位移 $< 100\textrm{m}$ 则未撞上。

**点评/变式**：本题巧妙利用第 $4\textrm{s}$ 内位移为 $1\textrm{m}$ 而非零，排除了全程匀速减速的假设，要求考生具备“刹车陷阱”的意识与检验能力。变式训练：可改为已知最后 $1\textrm{s}$ 内位移或停止前位移，直接利用逆向思维列式。同时注意连接反应阶段与稳定刹车阶段的初速度关系。
