## 知识精要
- **力的合成定义**：求几个力的合力的过程叫作力的合成。合力是几个力的共同作用效果的等效力。
- **平行四边形定则**：两个力合成时，以表示这两个力的线段为邻边作平行四边形，这两个邻边之间的对角线就代表合力的大小和方向。该定则是矢量合成的普适法则。
- **合力范围**：对于互成角度 $\theta$ 的两个共点力 $F_1$、$F_2$，其合力 $F$ 满足 $|F_1 - F_2| \le F \le F_1 + F_2$。
- **平衡条件**：物体处于静止或匀速直线运动状态时，所受合外力为零。二力平衡必等大、反向、共线。
- **核心推论**：当两分力大小相等且夹角 $> 90^\circ$ 时，合力小于分力；当夹角 $< 90^\circ$ 时，合力大于分力。夹角为 $135^\circ$ 时，两等大力合成的合力方向在角平分线上。

## 解题方法与套路
1. **受力分析与状态判定**：先明确研究对象初始时刻的受力情况，判断其所处状态（平衡/不平衡）。若平衡，则列出合外力为零的方程。
2. **识别恒力与变力**：区分系统中哪些力的大小和方向在条件变化前后保持不变。例如，本题中微粒重力 $mg$ 大小方向均不变；极板旋转前后，电场强度大小不变，仅方向随极板共同旋转。
3. **确定力的新方向与夹角**：根据题干描述，准确画出变化后各力的方向，并计算力与力之间的夹角。如极板旋转 $45^\circ$，则电场力方向也随之旋转 $45^\circ$。
4. **应用平行四边形定则求合力**：以变化后的两力为邻边作平行四边形，根据几何关系（如力的等大性、特定夹角）直接确定合力方向与大小。
5. **根据合力判断运动性质**：
   - 若初速度为零，合力恒定，则物体沿合力方向做匀加速直线运动。
   - 若初速度不为零，则需分析合力与速度的夹角，判断是直线还是曲线运动。

## 高频易错
- **误认为电场力方向随板转动后，与重力的夹角是 $45^\circ$**：实际上，原电场力竖直向上，逆时针旋转 $45^\circ$ 后，与竖直向下的重力夹角为 $180^\circ - 45^\circ = 135^\circ$。必须准确计算新的夹角。
- **凭直觉误判运动方向为“向左”或“向下”的纯分力方向**：合力是矢量和，方向必在两分力夹角之间。等大的重力和电场力成 $135^\circ$，合力方向在其角平分线上，即与竖直方向夹角为 $67.5^\circ$ 的左下方，而非纯水平或纯竖直方向。
- **静止释放点的位置误解**：题干中微粒从“两板中间a点”释放，极板绕a点旋转，该点空间位置未变，微粒初速度为零，这是匀加速直线运动的初始条件。
- **错误套用平衡条件**：极板旋转后，力的大小虽未变，但方向不再共线反向，平衡被打破，不能继续按静止状态分析。

## 代表题精讲
### **2015-新课标Ⅱ-01** 极板旋转后带电微粒的运动

**【题目】**
两平行带电金属板水平放置，板间a点从静止释放一带电微粒，恰好静止。现将两板绕过a点的轴（垂直于纸面）逆时针旋转 $45^\circ$，再由a点从静止释放同样的微粒，判断其运动状态。

**【思路】**
初始静止 $\rightarrow$ 二力平衡 ($mg$ 竖直向下，$F_{电}$ 竖直向上)。极板旋转 $45^\circ$ $\rightarrow$ 电场力 $F_{电}$ 大小不变，方向逆时针转 $45^\circ$。对微粒施加静止释放条件，求重力和新电场力的合力方向，即可知运动情况。

**【步骤】**
1. **初态平衡分析**：微粒静止，有 $F_{电} = mg$，方向竖直向上。
2. **变化后受力重画**：将两板绕a点逆时针旋转 $45^\circ$，板间电场强度 $E$ 的大小不变，方向始终垂直于板面，故也逆时针旋转 $45^\circ$。电场力 $F_{电}'$ 大小仍为 $mg$，方向偏移竖直向上 $45^\circ$ 角。重力 $mg$ 保持不变，竖直向下。
3. **计算合力**：此时重力与电场力大小相等，均为 $mg$。两力方向夹角为 $180^\circ - 45^\circ = 135^\circ$。利用平行四边形定则，合力大小 $F = \sqrt{(mg)^2 + (mg)^2 + 2(mg)(mg)\cos 135^\circ}$。方向指向左下方，且在两力角平分线上。
4. **判断运动**：微粒从静止释放，初速度为零，受恒定合力作用，将沿合力方向即左下方做匀加速直线运动。

**【点评/变式】**
本题核心是力的合成思想在复合场中的应用，无需计算具体场强和电荷量，仅通过力的矢量性即可解题。
- **变式1**：若极板旋转角度为 $90^\circ$，则电场力水平，两力等大垂直，合力大小为 $\sqrt{2}mg$，方向为左下 $45^\circ$。
- **变式2**：若旋转后微粒不是静止释放，而是具有某一初速度，则需比较初速度方向与合力方向是否共线，以判断是匀变速直线运动还是匀变速曲线运动（类抛体运动）。本题静止释放是特例，确保了直线运动。
