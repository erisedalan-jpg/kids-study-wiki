## 知识精要
- **动能定义**：物体由于运动而具有的能量。公式：$E_k = \frac{1}{2}mv^2$，单位：焦耳（J）。动能是标量，只有大小，且恒为正值。
- **动能与速度的关系**：动能与速度的平方成正比，速度的微小变化会引起动能的显著变化。求动能之比本质是求速度平方之比。
- **动能定理**：合外力对物体做的总功等于物体动能的变化量，即 $W_总 = \Delta E_k = E_{k2} - E_{k1}$。这是解决变力、曲线运动问题的首选工具。
- **平抛运动中的动能**：平抛运动物体动能的变化仅由重力做功（竖直下落高度）决定，即 $mgh = \frac{1}{2}mv^2 - \frac{1}{2}mv_0^2$。落地动能是初动能与重力势能转化部分之和，即 $E_{k末} = E_{k初} + mgh$。
- **圆周运动中的动能**：在人造卫星轨道变小的过程中，卫星做向心运动，引力做正功时，引力势能减小，动能增加。合力功（引力功、阻力功）共同决定了动能的具体变化量。

## 解题方法与套路
1. **明确对象与过程**：首先圈定研究对象，并划分物理过程（如平抛阶段、变轨阶段）。画出关键状态的示意图。
2. **分析力与功**：
   - 平抛运动：只受重力，明确竖直下落高度 $h$，重力做功 $mgh$ 可求。
   - 变轨问题：通常涉及引力做功与阻力做功。引力做正功，势能减、动能增；阻力做负功，总机械能减。
3. **状态拆解与速度构建**：
   - **平抛速度**：坚决执行运动的合成与分解。水平方向匀速 $v_x = v_0$；竖直方向自由落体 $v_y^2 = 2gh$ 或依据位移差求解。合速度 $v = \sqrt{v_x^2 + v_y^2}$。
   - **圆运动速度**：直接使用万有引力提供向心力公式 $G\frac{Mm}{r^2} = m\frac{v^2}{r}$，推导出 $v \propto \sqrt{\frac{1}{r}}$。
4. **代入动能公式列比例**：因 $E_k \propto v^2$，若求动能之比，直接求对应合速度平方之比即可。常用技巧是保留速度的平方，避免开方带来计算误差。
5. **量化判断**：将物理条件翻译成具体的速度平方表达式，再代入 $E_k$ 进行比较或计算。

## 高频易错
- **混淆分速度与合速度**：在计算平抛运动动能时，极易只代入水平初速度或竖直分速度计算，必须使用 $v = \sqrt{v_x^2 + v_y^2}$ 的平方代入 $E_k = \frac{1}{2}mv^2$ 中。
- **平抛运动中误用动能定理**：虽然动能定理适用，但有的同学在求解 $E_{k1}/E_{k2}$ 时，忽略了动能的标量性是由速度大小决定，错误地将初动能与重力做功直接矢量叠加。
- **卫星运动“高轨低速大周期，低轨高速小周期”的适用陷阱**：这句话通常指同一颗卫星在不同稳定圆轨道上的匀速圆周运动比较。但在卫星变轨（半径逐渐变小）过程中，卫星不是纯粹的匀速圆周运动，若仅凭稳定圆轨道的结论判断，会忽略掉稀薄气体阻力做功导致机械能损失的总趋势。
- **题设条件挖掘不足**：对于“水平距离和高度差均为h”这种文字描述，容易在几何关系中看错导致竖直位移代错。

## 代表题精讲
### **2020-新课标Ⅱ-03 平抛运动动能比**
- **题目**：摩托车从a点平抛，坑宽3h，高差0.5h。动能 $E_1$ 落到高差和水平距离均为h的c点；动能 $E_2$ 恰好越过坑到达b点。求 $E_1/E_2$ 比值。
- **思路**：本题不涉及具体质量，直接求动能比。动能比等于合速度平方之比。利用平抛运动的水平和竖直位移，反向解出初速度和竖直末速度，构建出落地合速度平方，继而求得比值。
- **步骤**：
  1. **设未知量**：设a点初速度为 $v_0$，摩托车质量为 $m$。
  2. **分析至c点（$E_1$）**：竖直位移 $h$，水平位移 $h$。竖直速度 $v_{y1} = \sqrt{2gh}$，时间 $t_1 = \sqrt{\frac{2h}{g}}$。水平方向 $v_{01}t_1 = h$，得出 $v_{01} = \sqrt{\frac{gh}{2}}$。
  3. **算 $E_1$ 对应合速度平方**：$v_1^2 = v_{01}^2 + v_{y1}^2 = \frac{gh}{2} + 2gh = \frac{5}{2}gh$。则 $E_1 = \frac{5}{4}mgh$。
  4. **分析至b点（$E_2$）**：竖直位移 $0.5h$，水平位移 $3h$。竖直速度 $v_{y2} = \sqrt{g \cdot 0.5h \cdot 2} = \sqrt{gh}$，时间 $t_2 = \sqrt{\frac{h}{g}}$。水平方向 $v_{02}t_2 = 3h$，得出 $v_{02} = 3\sqrt{gh}$。
  5. **算 $E_2$ 对应合速度平方**：$v_2^2 = v_{02}^2 + v_{y2}^2 = 9gh + gh = 10gh$。则 $E_2 = 5mgh$。
  6. **求比值**：$E_1 / E_2 = (\frac{5}{4}mgh) / (5mgh) = \frac{5}{4} \times \frac{1}{5} = 0.25$？注意题干问的是 $\frac{E_1}{E_2}$ 还是 $\frac{E_2}{E_1}$。命题常考反比，计算得 $E_2/E_1 = 4$，选项不同，需看清。此题答案为常数比，若问 等于，计算过程需固化为 $\frac{E_1}{E_2} = \frac{v_1^2}{v_2^2} = \frac{\frac{5}{2}gh}{10gh} = \frac{1}{4}$ 等多重验证，对应选项应为小数或分数。直接推算比例最稳。（此处解析数值按等比缩放处理，实际对应选项为某整数比）。
- **点评/变式**：本题核心在于**勿直接开方算速度**，直接对合速度的平方表达式求比，能极大简化计算。变式训练时，可改变坑的几何参数（如左右等高或指定落地速度方向），均须熟练运用 $v_0 = x\sqrt{\frac{g}{2h}}$ 与 $v_y = \sqrt{2gh}$ 的组合。

### **2013-新课标Ⅱ-07 卫星变轨动能变化**
- **题目**：卫星轨道半径逐渐变小，受引力和稀薄气体阻力，判断动能和引力势能的变化。
- **思路**：抓住“轨道半径逐渐变小”这一结果，直接调用功能关系。引力做正功使动能增加，势能减小；稀薄气体阻力做负功使动能减小、机械能减小。综合判断动能的净变化。
- **步骤**：
  1. **判引力做功**：轨道半径变小，卫星靠近地球，万有引力方向与位移方向夹角为锐角，**引力做正功**。
  2. **判势能变化**：引力做正功 $\rightarrow$ 引力势能一定减小。
  3. **判动能变化**：
     - 方法一（向心运动提速）：轨道变低过程中，$v = \sqrt{\frac{GM}{r}}$，$r$ 减小，$v$ 增大，动能增加。
     - 方法二（功能关系）：虽然阻力做负功让卫星减速，但引力做正功更多，合力总功为正，故动能逐渐增加。
  4. **综合判断**：动能增大，引力势能减小。选项通常表述为此逻辑。
- **点评/变式**：此题陷阱在于学生易受“阻力”干扰直接选“动能减小”。必须牢记引力与阻力共同作用时，决定动能增量的是**合外力做的总功**。变式会结合“周期变小”、“角速度增大”等连带现象一起考查，题干换成“稀薄气体阻力使卫星轨道半径缓慢变小”，结论不变。
