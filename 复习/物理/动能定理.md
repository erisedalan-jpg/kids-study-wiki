## 知识精要
- **动能定理内容**：合外力对物体所做的功等于物体动能的变化，即 $W_{\text{合}} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$。
- **功的计算**：$W = F l \cos\theta$（恒力），变力做功常通过动能定理间接求解；重力做功 $W_G = mgh$（与路径无关），电场力做功 $W_e = qU$，摩擦力做功 $W_f = -f l$（与路径有关）。
- **适用条件**：直线运动、曲线运动，恒力、变力，单个过程或多个过程均适用；全程列式时注意各力做功的代数和。
- **正负功意义**：正功使动能增加，负功使动能减少。能量转化角度：重力做正功，重力势能减少；电场力做正功，电势能减少；克服摩擦力做功转化为内能。
- **多过程与全程法**：若各力做功可分段表达，优先全程列方程 $W_1 + W_2 + \cdots = E_{k\text{末}} - E_{k\text{初}}$，可避免中间状态的速度计算。
- **功能关系深化**：动能定理是功能关系的核心，常与能量守恒、动量定理、圆周运动向心力公式等结合考查。

## 解题方法与套路
1. **确定研究对象和过程**：明确单个物体（或系统）的初、末状态，选取从初到末的运动过程。过程选取以“包含所求未知量且已知条件充分”为原则。
2. **受力与做功分析**：画出受力示意图，理清每个力在全过程中的做功情况。注意恒力直接 $F l \cos\theta$，变力考虑用动能定理反求功。
3. **列出动能定理方程**：$W_{\text{合}} = \frac{1}{2}mv_{\text{末}}^2 - \frac{1}{2}mv_{\text{初}}^2$，其中 $W_{\text{合}}$ 为所有力做功的代数和（正功带正号，负功带负号）。
4. **结合辅助方程**：
   - 涉及圆周运动：在特殊位置用向心力公式 $F_{\text{合}} = m\frac{v^2}{r}$。
   - 涉及电场：电势差与电场力做功关系 $W_{AB} = qU_{AB}$；匀强电场中 $W = qEd$。
   - 涉及弹簧：弹簧弹力做功等于弹性势能减少量，$W_{\text{弹}} = E_{p1} - E_{p2}$。
   - 涉及图像：$W-x$ 图面积代表功；$F-t$ 图可结合动量定理求速度，再代入动能定理。
5. **解方程并检验**：代入数据时注意单位统一，检查结果是否符合物理情景（如速度方向、能量转化方向）。

## 高频易错
- **功的正负误判**：当力与位移夹角为钝角时做负功，书写动能定理时易将负功写成正号导致计算错误。
- **变力做功与恒力混淆**：如弹簧弹力为变力，不能用 $W = Fs$ 直接计算，须用动能定理或弹性势能变化求解。
- **初末状态动能遗漏**：物体由静止开始则初动能为0；末状态若速度为零，则末动能为0，不能遗漏。
- **摩擦力做功的路径依赖**：多过程问题中，摩擦力在各段均做负功，总功等于摩擦力大小乘总路程（而非位移），易错用位移替代路程。
- **动能定理与动能分量错误**：动能是标量，不能分解。若将速度分解代入 $\frac{1}{2}mv^2$ 时，必须用合速度。
- **忽略隐含的功**：如“缓慢移动”隐含动能不变；电场、重力场中易漏掉电场力或重力的功；圆弧轨道支持力不做功，但若存在摩擦力则须计入。
- **能量转化方向反推错误**：动能增大时电势能或重力势能减小，反之亦然，但结合功的正负分析时易颠倒。

## 代表题精讲
### 2024-辽宁-06
**题目**：在水平匀强电场中，带电小球仅在重力和电场力作用下于竖直面内运动。若初速度沿虚线则轨迹为直线，若初速度垂直于虚线，则从O点出发运动到与O点等高处过程中，动能和电势能如何变化？

**思路**：根据“初速度沿虚线轨迹为直线”得出合力方向沿虚线，进而判断电场强度方向。当初速度垂直虚线时，小球做类斜抛运动，回到等高处重力做功为零，只需分析电场力做功，利用动能定理即可判断动能变化及电势能变化。

**步骤**：
1. 由初速度沿虚线轨迹为直线，说明电场力与重力的合力方向沿虚线。又电场水平，故合力斜向下，电场强度必须水平向右才能与重力合成指向虚线方向。
2. 若初速度垂直虚线，从O点出发到等高处，重力做功为零；电场力方向向右，与运动方向的水平分量同向，电场力做正功。
3. 根据动能定理：$W_{\text{电}} = \Delta E_k > 0$，动能增大；电场力做正功，电势能减小，故选D。

**点评/变式**：本题陷阱在于忽略重力，误认为只受电场力。解题关键是“直线运动条件”→合力沿直线，从而确定电场方向。变式：若初速度方向沿虚线反向，则小球可能做直线减速；垂直于虚线斜向上射出，则最高点等高处仍为电场力做正功。

### 2024-辽宁-12
**题目**：水平桌面上A、B两物块夹着压缩弹簧，同时释放后A做平抛运动，B滑行一段距离停止。已知A的平抛射程、下落高度、B的滑行距离及质量，求脱离弹簧时A、B的速度、桌面动摩擦因数及弹簧释放的弹性势能。

**思路**：A做平抛运动，由高度和射程可求脱离弹簧时的速度$v_A$；B做匀减速直线运动，用动能定理结合滑行距离可求$v_B$和动摩擦因数μ；再对A、B和弹簧系统，由能量守恒或动能定理（弹簧弹力做功等于弹性势能释放）求出$\Delta E_p$。

**步骤**：
1. A飞出后平抛：$h = \frac{1}{2}gt^2$，$x_A = v_A t$，得$v_A = x_A \sqrt{\frac{g}{2h}} = 0.4 \times \sqrt{\frac{10}{1.6}} = 1\,\text{m/s}$。
2. B脱离弹簧后滑行：仅摩擦力做功，由动能定理 $-\mu m_B g x_B = 0 - \frac{1}{2}m_B v_B^2$；同时系统动量守恒（释放过程合外力为零）：$0 = m_A v_A - m_B v_B$（因A向左，B向右，取A方向为正），代入质量相等得$v_B = v_A = 1\,\text{m/s}$。
3. 将$v_B$代入动能定理得 $\mu = \frac{v_B^2}{2g x_B} = \frac{1^2}{2 \times 10 \times 0.25} = 0.2$。
4. 弹簧释放的弹性势能转化为A、B的动能及B滑行至脱离前可能已有摩擦生热？注意：释放瞬间弹簧恢复原长时A已离开桌面，B虽有摩擦但位移极短可忽略？题干“同时释放，弹簧恢复原长时A恰好飞出”应理解为弹簧原长时A刚脱离桌面，过程中B受摩擦力但位移为压缩量$\Delta x$，严格来说弹性势能等于A、B获得的动能加上B克服摩擦力做的功在恢复原长过程中的部分。但通常题目简化：弹簧弹力对A、B做功之和等于弹性势能减少，而B所受摩擦力在弹开过程中做功为$-\mu m_B g \Delta x$，需计入。由能量守恒：$E_p = \frac{1}{2}m_A v_A^2 + \frac{1}{2}m_B v_B^2 + \mu m_B g \Delta x = 0.5 \times 0.1 \times 1^2 \times 2 + 0.2 \times 0.1 \times 10 \times 0.1 = 0.12\,\text{J}$。

**点评/变式**：易错点：直接用动能定理对B从释放到停止列全程方程时，注意弹力做功与摩擦力做功并存，分开选取过程更清晰。变式：若A、B质量不等，需用动量守恒求速度比，再结合动能定理。

### 2023-新课标-02
**题目**：无风时，雨滴以恒定速率v竖直下落高度h，克服空气阻力做功为多少？

**思路**：匀速下落，动能不变，重力做正功，空气阻力做负功。由动能定理：$W_G + W_f = \Delta E_k = 0$，所以$W_f = -mgh$，克服空气阻力做功为$mgh$。

**步骤**：
1. 雨滴匀速下落，初末动能均为$\frac{1}{2}mv^2$，变化量为0。
2. 重力做功 $W_G = mgh$（正功）；设空气阻力做功为 $W_f$（负功）。
3. 动能定理：$mgh + W_f = 0 \Rightarrow W_f = -mgh$，故克服空气阻力做功 $|W_f| = mgh$，选B。

**点评/变式**：此题易误选C，认为动能不变但重力做功转化为内能，用 $mgh - \frac{1}{2}mv^2$ 的错误。重申：动能定理中的末动能与初动能都是$\frac{1}{2}mv^2$，与高度h无关。变式：若雨滴加速下落，则空气阻力做功小于mgh。
