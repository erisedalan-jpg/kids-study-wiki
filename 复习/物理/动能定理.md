## 知识精要
动能定理描述合力做功与物体动能变化之间的定量关系。

- **表达式**：$W_{\text{合}} = \Delta E_k = \frac{1}{2}mv_t^2 - \frac{1}{2}mv_0^2$
  - $W_{\text{合}}$ 为所有外力做功的代数和（包括重力、电场力、摩擦力等）。
  - 功是标量，求和时直接带上正负号代数相加。
- **适用条件**：既适用于直线运动，也适用于曲线运动；既适用于恒力，也适用于变力（变力做功问题中，动能定理往往是最优解法）。
- **功能关系延伸**：
  - 重力做功等于重力势能的减少量：$W_G = -\Delta E_p$。
  - 电场力做功等于电势能的减少量：$W_{\text{电}} = -\Delta E_{\text{电}}$。
  - 除重力和系统内弹簧弹力外，其他力做功的代数和等于机械能的变化量。
- **核心要点**：动能是状态量，对应某一时刻或某一位置；功是过程量，对应某一段位移或过程。

## 解题方法与套路
1. **明确对象与过程**：选定单个物体或系统为研究对象，确定始、末状态对应的位置并标出速度（$v_0, v_t$），画出位移轨迹。
2. **受力与做功分析**：
   - 全面分析研究对象在运动过程中受到的各个力（恒力、变力、电场力等）。
   - 判断各力做功正负：力与位移夹角小于 $90^\circ$ 做正功，大于 $90^\circ$ 做负功，等于 $90^\circ$ 不做功。
   - 写出合外力做的总功 $W_{\text{合}} = W_1 + W_2 + \dots$。
3. **状态参量提取**：写出初动能 $E_{k0}$ 和末动能 $E_{kt}$。
4. **列方程求解**：利用 $W_{\text{合}} = \frac{1}{2}mv_t^2 - \frac{1}{2}mv_0^2$ 求解未知量。
5. **多过程分段或全程法**：
   - **分段法**：按运动性质或受力变化将全程分为几个阶段，逐段应用动能定理。
   - **全程法**：对全过程整体应用动能定理（注意：全程中某些变力做功与路径有关时需分段，如滑动摩擦力做功与路径总长度有关）。
6. **电场与重力场综合**：分析是否考虑重力；若合力为恒力，可将合力等效为“等效重力”，简化运动分析。

## 高频易错
- **功的正负号处理不当**：计算总功时，摩擦力做负功或克服某个力做功，代数求和时极易丢负号。如克服摩擦力做功 $W$，则摩擦力做的功为 $-W$。
- **混淆动能定理与动量定理**：动能定理处理的是“力在空间上的积累（功）”；动量定理处理的是“力在时间上的积累（冲量）”；遇到涉及时间或速度方向的动量变化问题时，切忌错用公式。
- **对“动能不变”的误解**：匀速圆周运动或匀速直线运动的物体动能不变，但合力不一定为零。匀速圆周运动合力提供向心力，动能定理中合外力做功为零，但物体受到合力不为零。
- **忽略初末状态分析**：对 “从静止释放” “落地反弹” 等过程，未能准确写出始末动能表达式，特别是反弹至最高点时末动能通常为零。
- **变力做功陷阱**：对于方向变化的摩擦力或大小随位移变化的变力，直接当作恒力计算做功是错误的。曲线运动中，若力的方向始终与速度方向相反（如空气阻力），其功为 $-f \times \text{路径长度}$。
- **系统与单体混淆**：应用动能定理时，若研究对象是系统，需要考虑系统内各物体的动能变化之和，且要注意系统内力的功是否可以相互抵消。在连接体或碰撞问题中，应先明确单体还是整体列式。

## 代表题精讲
### 代表题 1：2024-辽宁-06
**题目**：小球在水平匀强电场与重力场中，初速沿某虚线做直线运动；初速垂直虚线则运动至等高处时，判断动能与电势能变化。

**思路**：
直线运动条件决定合力方向，确定电场方向。比较电场力做功正负及重力做功，由动能定理判动能变化。

**步骤**：
1. 由“初速度沿虚线轨迹为直线”推得小球受合力方向沿虚线。
2. 合力由重力和水平电场力合成，故电场力方向水平向右。
3. 初速度垂直虚线斜向上抛出，从 $O$ 返至等高点的过程中，重力做功 $W_G = 0$。
4. 运动轨迹分析：水平方向向右偏移，电场力方向与水平位移同向，电场力做正功 $W_{\text{电}} > 0$。
5. 由动能定理 $W_{\text{电}} + W_G = \Delta E_k$，得 $\Delta E_k > 0$，动能增大。
6. 电场力做正功，电势能减小。

**点评与变式**：
抓住“恒定合力方向与速度共线为直线运动”这一核心条件。若合力为斜向，物体做类斜抛或类平抛运动，可利用动能定理快速判断能量转换，免去复杂的轨迹计算。

### 代表题 2：2024-辽宁-12
**题目**：压缩弹簧释放推动 A、B 两物块，A 平抛落地，B 在桌面滑行停止。求脱离弹簧速度、动摩擦因数及弹性势能。

**思路**：
A 出桌面后平抛，竖直下落求时间，水平位移求初速 $v_A$。B 脱离后匀减速，用动能定理求 $\mu$ 和 $v_B$。再由系统能量守恒求弹簧弹性势能。

**步骤**：
1. **A脱离速度**：平抛竖直位移 $h = 0.8\,\text{m}$，由 $h = \frac{1}{2}gt^2$ 得下落时间 $t = 0.4\,\text{s}$。水平射程 $x_A = 0.4\,\text{m}$，故
   $$v_A = \frac{x_A}{t} = 1\,\text{m/s}.$$
2. **动摩擦因数**：对 B 滑行过程用动能定理，$- \mu m g x_B = 0 - \frac{1}{2} m v_B^2$。同时，弹簧释放瞬间系统动量守恒（时间极短，桌面外力远小于内弹力）：
   $$ 0 = m_A v_A - m_B v_B \implies v_A = v_B = 1\,\text{m/s}.$$
   代入动摩擦因数表达式：
   $$\mu \times 0.1 \times 10 \times 0.25 = \frac{1}{2} \times 0.1 \times 1^2 \implies \mu = 0.2.$$
3. **弹性势能**：由能量守恒，弹簧弹性势能完全转化为 A、B 动能及内能：
   $$E_p = \frac{1}{2} m_A v_A^2 + \frac{1}{2} m_B v_B^2 = 2 \times \frac{1}{2} \times 0.1 \times 1^2 = 0.12\,\text{J}.$$
   （注意：脱离瞬间尚未产生摩擦热，故只分配动能。）

**点评与变式**：
若桌面表面粗糙且弹簧与物块栓接，分离前后需考虑是否有弹性势能残留。本题关键在结合动量守恒与动能定理求解瞬时速度。

### 代表题 3：2023-新课标-02
**题目**：雨滴在地面附近以恒定速率竖直下落，求下落某段高度克服空气阻力做的功。

**思路**：
匀速下落说明合力为零，重力与阻力大小相等。利用动能定理 ($\Delta E_k = 0$) 计算总功，从而直接得到克服空气阻力的功。

**步骤**：
1. 明确过程：雨滴下落高度 $h$，初末速度均为 $v$，动能不变 $\Delta E_k = 0$。
2. 受力做功：重力做功 $W_G = mgh > 0$；空气阻力做负功 $W_f < 0$。
3. 列动能定理：
   $$mgh + W_f = 0 \implies W_f = -mgh.$$
4. 克服空气阻力做功即阻力做功的绝对值：
   $$W_{\text{克}} = mgh.$$

**点评与变式**：
动能不变并不意味着不受力或不耗能，本题中重力势能完全转化为内能。切忌误用机械能守恒定律直接写出 $\frac{1}{2}mv^2$ 项。
