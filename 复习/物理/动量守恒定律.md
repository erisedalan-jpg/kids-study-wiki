## 知识精要
动量守恒定律是自然界最重要、最普遍的守恒定律之一，研究对象为系统。
- **适用条件**：系统不受外力或所受外力的矢量和为零；系统内力远大于外力（如碰撞、爆炸）；系统在某一方向上不受外力或该方向外力矢量和为零，则该方向动量守恒。
- **表达式**：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$ 或 $p_{初} = p_{末}$。
- **碰撞类型与特征**：
  - **弹性碰撞**：动量守恒 + 动能守恒。如钢球碰撞、弹簧连接的分离过程（弹性势能完全释放）。
  - **完全非弹性碰撞**：动量守恒 + 动能损失最大。碰后物体共速，如“粘在一起”、“滑块陷入木板”。
  - **非弹性碰撞**：动量守恒 + 动能有损失。如一般碰撞、弹簧未到原长即分离。
- **核心关系链**：
  - 动量守恒常与能量守恒（动能定理、机械能守恒、功能关系）联用。摩擦生热 $Q = \mu m g \cdot x_{相对}$。
  - 弹簧模型是经典载体：弹簧压缩最短或拉伸最长时，连接体共速，系统动能损失最大，转化为弹性势能；弹簧恢复原长时，弹性势能全部释放，系统动能最大，可类比弹性碰撞。

## 解题方法与套路
1. **明确系统与过程**：选定研究对象（哪些物体构成系统），分析受力，判断动量是否守恒（外力之和是否为零）。
2. **抓住临界状态**：
   - 物体间碰撞瞬间：内力远大于外力，动量近似守恒。
   - 滑块与木板共速、A与B共速、弹簧形变量最大/原长——均为动量守恒方程列出的关键节点。
3. **方程组合**：
   - **动量守恒方程**：选定正方向，写出初、末态总动量。
   - **能量方程**：动能定理（$-\mu m g x = \frac{1}{2}mv^2 - \frac{1}{2}mv_0^2$）或能量守恒（$\Delta E_k = \Delta E_p + Q$）。
4. **多过程解题**：将复杂运动分解为“碰撞过程”、“弹簧作用过程”、“匀减速直线运动过程”、“平抛过程”，逐个单独列方程，通过联系速度衔接。
5. **速度关联**：轻弹簧连接体分离瞬间，速度不关联；但接触类或共速类过程，须列出速度相等关系。
6. **相对运动**：涉及是否追上、能否再次碰撞的判断，先求分离后各自速度，再用运动学公式比较位移或直接比较速度。

## 高频易错
- **守恒条件混淆**：有摩擦或弹簧弹力作用时，系统动量可能仍守恒（地面光滑时），但机械能不守恒。
- **惯性系选择**：动量守恒定律必须在同一惯性参考系中应用，所有速度必须相对同一参考系（通常为地面）。
- **矢量方向的疏忽**：碰撞前后速度方向可能反向，列方程时必须注意正负号，未标出方向的应先假定方向，由计算结果判断实际方向。
- **完全非弹性碰撞的误判**：“粘在一起”必定共速，动能损失最大；但弹簧连接体共速时，弹性势能储存能量，分离后动量守恒但动能可再次变化，不能直接套用完全非弹性碰撞机械能损失公式。
- **多体转化遗漏**：弹簧连接两物块时，弹性势能是系统的，计算释放的弹性势能 $E_p$ 时，不能只算一个物体的动能，应核算 $E_p = \frac{1}{2}m_1 v_1^2 + \frac{1}{2}m_2 v_2^2 - \frac{1}{2}(m_1+m_2)v_{共}^2$。
- **追及条件分析错误**：判断能否追上，临界条件不是两者速度相等，而是当后者速度恰好等于前者时，后者的位移是否超过前者，或反弹速度大小比较。

## 代表题精讲
### **题目**：2024-辽宁-12
高度 $h=0.8\text{m}$ 的水平桌面上，两个相同物块 A、B 间夹一压缩量 $\Delta x=0.1\text{m}$ 的轻弹簧，同时静止释放。弹簧恢复原长时 A 从桌面左端平抛，射程 $x_A=0.4\text{m}$；B 滑行 $x_B=0.25\text{m}$ 后停止。质量 $m_A=m_B=0.1\text{kg}$，$g=10\text{m/s}^2$。
（1）求脱离弹簧时速度 $v_A$ 和 $v_B$；
（2）求动摩擦因数 $\mu$；
（3）求弹簧释放的弹性势能 $E_p$。

**思路**：过程清晰，遵循“平抛求速度→动能定理求$\mu$→系统能量守恒求$E_p$”的链条。

**步骤**：
1. **求 $v_A$**：A 做平抛运动，$h = \frac{1}{2}gt^2 \Rightarrow t = \sqrt{\frac{2 \times 0.8}{10}} = 0.4\text{s}$；水平方向 $x_A = v_A t \Rightarrow v_A = \frac{0.4}{0.4} = 1\text{m/s}$。
2. **求 $v_B$**：弹簧恢复原长时，A、B 系统动量守恒（弹簧为系统内力）：$0 = m_A v_A - m_B v_B \Rightarrow v_B = v_A = 1\text{m/s}$。
3. **求 $\mu$**：对 B 脱离弹簧后的滑行用动能定理，$-\mu m_B g x_B = 0 - \frac{1}{2}m_B v_B^2$。代入解得 $\mu = \frac{v_B^2}{2g x_B} = \frac{1^2}{2 \times 10 \times 0.25} = 0.2$。
4. **求 $E_p$**：弹簧释放过程能量守恒，$E_p = \frac{1}{2}m_A v_A^2 + \frac{1}{2}m_B v_B^2 = \frac{1}{2} \times 0.1 \times 1^2 \times 2 = 0.1\text{J}$。（原卷答案 $0.12\text{J}$ 含克服桌面段摩擦，按题意“释放弹性势能”为转化为动能部分加上摩擦耗散：$E_p = \frac{1}{2}m_A v_A^2 + \frac{1}{2}m_B v_B^2 + \mu m_B g x_B = 0.1 + 0.05 = 0.15\text{J}$，题干答案 $0.12\text{J}$ 待确认计算细节，此处按标准解法给出框架）
**点评**：弹簧双物块平抛模型，重点考察动量守恒与能量守恒的分段使用。平抛与匀减速运动独立处理，最后用能量统合。

### **题目**：2022-全国乙-12
物块A在光滑水平面上连弹簧静止，B向A运动，$t=0$ 接触弹簧，$t=2t_0$ 分离，已知 $0\sim t_0$ 内A移动 $0.36v_0 t_0$。分离后A冲上粗糙斜面再滑下，与B再次碰撞，A二次上滑最高点相同。$\sin\theta=0.6$，求弹簧最大弹性势能、最大压缩量和斜面动摩擦因数。

**思路**：$v-t$ 图像挖掘信息，弹簧两临界（共速与分离）抓取方程，结合人船模型位移关系求最大压缩量。

**步骤**：
1. **求B质量**：$t_0$ 时共速 $v = \frac{1.2 m_B}{m+m_B}v_0$，由图像 $v = v_0$；代入得 $m_B = 5m$。
2. **最大弹性势能**：$E_{p, max} = \frac{1}{2} \cdot 5m \cdot (1.2v_0)^2 - \frac{1}{2} \cdot 6m \cdot v_0^2 = 0.6 m v_0^2$。
3. **最大压缩量 $l_{max}$**：弹簧压缩过程等效“人船模型”，A与B相对位移即为压缩量。$m_A v_A + m_B v_B = (m_A+m_B)v_{共}$，设A位移 $s_A$，B位移 $s_B$，系统 $m s_A + 5m s_B = 0$（以共速位置为参考），且 $s_B - s_A = l_{max}$。利用 $0 \sim t_0$ 内 $s_A = 0.36 v_0 t_0$，可解得 $l_{max} = 0.768 v_0 t_0$。
4. **求动摩擦因数 $\mu$**：A与B分离时弹性碰撞，分离速度 $v_A = 2v_0$，$v_B = \frac{2}{5}v_0$。A 上滑再下滑全过程，回到平面速度 $v_A' < v_A$。由 A 与 B 再次碰撞后 A 达同一高度，可推知碰后 A 的速度与第一次碰后速度相同。由全程动量能量守恒联立，解得 $\mu = 0.45$。
**点评**：图像信息提取与弹簧碰撞模型的深度结合，弹簧压缩量通过相对位移积分或人船模型求解，斜面问题结合多次碰撞复原条件，综合性强。

### **题目**：2021-全国乙-01
光滑水平地面上，小车内有轻弹簧连接滑块，滑块与车厢底板有摩擦。撤去推力时滑块有相对滑动，问系统动量和机械能守恒性。

**思路**：直接根据守恒条件判断。

**步骤**：
1. **动量守恒**：以小车、弹簧、滑块为系统，地面光滑无外力，撤去推力后动量守恒。
2. **机械能不守恒**：“滑块有相对滑动”“底板有摩擦”说明系统内摩擦力做功，机械能不守恒。
**选 B**。
**点评**：易错题。牢记动量守恒看外力，机械能守恒看除重力弹力外其他力做功。内部摩擦耗散机械能但不影响动量守恒。
