## 知识精要
- **匀变速直线运动基本公式**  
  速度公式：$v = v_0 + at$  
  位移公式：$x = v_0t + \frac{1}{2}at^2$  
  速度—位移公式：$v^2 - v_0^2 = 2ax$  
  平均速度：$\bar{v} = \frac{v_0+v}{2}$（仅匀变速适用）  
  适用条件：加速度恒定、直线运动。

- **多段运动处理原则**  
  将全程按运动性质（加速、匀速、减速）分段；段与段之间的衔接点物理量（如速度、位置）相同。

- **关键关联**  
  总时间 $t_{\text{总}}=$ 各段时间之和；总位移 $x_{\text{总}}=$ 各段位移之和。  
  反应时间不计入运动时间，仅影响总用时。

- **图像辅助**  
  $v-t$ 图中斜率表加速度，面积表位移，可直观建立方程。

## 解题方法与套路
1. **画运动示意图**  
   在草稿上画出物体运动的轨迹，标明各段的运动性质（匀加速、匀速等）、已知量和待求量。
2. **分段与衔接**  
   将运动分成纯运动阶段，连接点的速度就是下一阶段的初速度，这个速度往往是解决问题的桥梁。
3. **建立时间与位移方程**  
   利用“总位移＝各段位移之和”与“总运动时间＝各段运动时间之和”列方程。涉及反应时间时，明确区分实际运动时间与比赛成绩。
4. **设元技巧**  
   优先设可关联多段的物理量（如最大速度 $v_m$、加速时间 $t_1$）。利用匀变速平均速度公式减少未知数。
5. **解方程组**  
   代入消元，求解关键量后再回代求加速度、位移等。
6. **结果检验**  
   验算所得速度、时间是否符合物理情景（如 $v_m>0$，加速时间在总时间内）。

## 高频易错
- **忘记扣除反应时间**  
  题干给出的“成绩”包含反应时间，真正的运动时间 $=$ 成绩 $-$ 反应时间。  
  典型失误：直接用9.69 s作为100 m的运动时间，导致全盘错误。
- **匀速段速度写错**  
  第二问（如200 m）中，若题目给定后续只能以最大速率的若干百分比运动，则匀速速度变为 $k\cdot v_m$，不能仍用 $v_m$。  
  典型失误：200 m 问题中匀速段仍使用 $v_m$ 而忘记乘以 $96\%$。
- **加速段位移公式误用**  
  许多考生将加速段位移误写为 $x_1 = v_m t_1$，漏掉 $\frac{1}{2}$ 因子。必须用 $x_1 = \frac{1}{2}v_m t_1$ 或 $x_1 = \frac{1}{2}at_1^2$。
- **单位与有效数字**  
  结果要求保留两位小数时，中间计算应多保留一位，避免舍入误差。
- **忽视加速距离相等条件**  
  若题目明确“加速阶段的加速度和加速距离均与100 m比赛相同”，则加速时间 $t_1$ 与最大速度 $v_m$ 均不变，可直接利用这一相等关系建立方程，勿重复设元。

## 代表题精讲
### 代表题1：2010·新课标Ⅰ·11
**题目**  
博尔特在北京奥运会上100 m和200 m成绩分别为9.69 s和19.30 s。在100 m比赛中，反应时间0.15 s，起跑后匀加速至最大速率，此后匀速跑完全程。200 m比赛时，反应时间相同，加速阶段的加速度和加速距离与100 m比赛相同，此后仅能以最大速率的96%匀速跑。求：(1)加速所用时间及最大速率；(2)起跑后匀加速的加速度。（结果保留两位小数）

**思路**  
确定两个项目的运动时间（扣除反应时间），利用“总位移＝加速段位移＋匀速段位移”建立方程组。100 m给出一个方程，200 m给出另一个方程，两式联立可解加速时间和最大速率，再通过 $a=v_m/t_1$ 求加速度。

**步骤**  
1. **计算各项目纯运动时间**  
   100 m：$t_{100}=9.69-0.15=9.54\;\text{s}$  
   200 m：$t_{200}=19.30-0.15=19.15\;\text{s}$

2. **设未知量并列100 m方程**  
   设加速时间 $t$，最大速率 $v$。  
   加速段位移：$x_1 = \frac{1}{2}v t$  
   匀速段位移：$x_2 = v(9.54-t)$  
   总位移方程：  
   $$\frac{1}{2}vt + v(9.54-t) = 100$$  
   化简得：  
   $$v(9.54 - \frac{t}{2}) = 100 \quad (1)$$

3. **列200 m方程**  
   加速条件与100 m相同，故加速段位移仍为 $\frac{1}{2}vt$，加速时间仍为 $t$，最大速率仍为 $v$。  
   匀速段速率变为 $0.96v$，匀速时间 $19.15-t$。  
   总位移方程：  
   $$\frac{1}{2}vt + 0.96v(19.15-t) = 200 \quad (2)$$

4. **联立求解**  
   由(1)得：$v = \dfrac{100}{9.54 - \frac{t}{2}}$  
   代入(2)：  
   $$\frac{100}{9.54-\frac{t}{2}}\left[\frac{t}{2} + 0.96(19.15-t)\right] = 200$$  
   两边乘 $9.54-\frac{t}{2}$，整理：  
   $$100\left(\frac{t}{2} + 18.384 - 0.96t\right) = 200\left(9.54 - \frac{t}{2}\right)$$  
   $$50t + 1838.4 - 96t = 1908 - 100t$$  
   $$-46t + 1838.4 = 1908 - 100t$$  
   $$54t = 69.6 \quad \Rightarrow \quad t = 1.29\;\text{s}$$  
   代入(1)：  
   $$v = \frac{100}{9.54 - 1.29/2} = \frac{100}{8.895} \approx 11.24\;\text{m/s}$$

5. **求加速度**  
   $$a = \frac{v}{t} = \frac{11.24}{1.29} \approx 8.71\;\text{m/s}^2$$

**点评**  
本题核心在于利用两个运动过程的衔接点——加速时间与最大速率相同，通过总位移建立方程组。易错点是忘记扣除反应时间，以及200 m匀速段速率未乘 $96\%$。匀加速段位移用 $\frac{1}{2}vt$ 表达可减少未知数个数，是常用简化技巧。计算结果保留两位小数时，中间步骤保留更多有效数字即可。
