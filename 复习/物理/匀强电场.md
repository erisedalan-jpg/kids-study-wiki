## 知识精要
- **匀强电场基本性质**  
  电场强度 $E$ 处处大小相等、方向相同，电场线为等间距平行线。  
  沿场强方向电势均匀降落，关系式为 $E = \frac{U}{d}$（$d$ 为沿场强方向的投影距离）。  
  电场力做功与电势差的关系：$W_{AB} = qU_{AB} = q(\varphi_A - \varphi_B)$，且 $W_{AB} = -\Delta E_p$（正电荷沿电场线方向移动，电势能减小）。

- **电势的叠加与中点电势**  
  在匀强电场中，任意直线上电势均匀变化，故线段中点电势等于两端点电势之和的一半：  
  $\varphi_M = \frac{\varphi_A + \varphi_C}{2}$（$M$ 为 $AC$ 中点）。  
  此结论可推广为：沿同一直线上等间距点间电势差相等。

- **匀强电场中的“平行等长”规律**  
  若 $AB \parallel CD$ 且 $|AB| = |CD|$，则 $U_{AB} = U_{CD}$（电势差仅与沿场强方向的投影长度有关）。  
  由此可推知：平行四边形两对角线中点重合，则四个顶点间存在特定电势关系。

## 解题方法与套路
1. **明确做功与电势差的关系**  
   从题干给出的电势能变化量 $\Delta E_p$，利用 $W = -\Delta E_p$（或 $W = \Delta E_{p减}$）求得电场力做正功值 $W$，再由 $U = \frac{W}{q}$ 求出对应两点间的电势差。

2. **利用中点电势公式简化问题**  
   匀强电场中两点连线中点电势 $\varphi_{\text{中}} = \frac{\varphi_1 + \varphi_2}{2}$，可直接用于计算该点与其他点间的电势差，避免复杂的几何投影。  
   对于任意四边形，可连接对角线，利用中点电势建立电势关系。

3. **判断场强方向与大小**  
   - 匀强电场方向不一定与任意两点的连线平行，只有该连线为等势线时垂直或沿电势降落最快的方向时才可能平行。  
   - 场强大小必须用 $E = \frac{U}{d}$ 计算，$d$ 必须是沿电场方向的距离（通过投影或几何关系求得），不可直接代入两点直线距离 $L$。

4. **等分法与辅助线**  
   已知某两点间电势差时，可将该线段等分，标出各等分点的电势；再连接电势相同的点画出等势线，由等势线与电场线垂直确定场强方向，由等势线间距求场强大小。

## 高频易错
- **错把任意距离当 $d$**  
  $E = \frac{U}{d}$ 中的 $d$ 必须是两点连线在电场方向上的投影长度，而非任意给定距离 $L$。仅当两点连线平行于电场方向时，$d = L$。

- **混淆电势能与电场力做功的正负**  
  电势能减小 $W$，说明电场力做正功 $W$（$W_{电} = -\Delta E_p = W$），勿将正负号弄反导致电势差计算错误。

- **误认为场强方向必沿某两点连线**  
  匀强电场方向不依赖于任意两点的连线，只取决于等势面的垂直方向。仅当该两点电势差与距离的比值恰好等于最大场强时才可能指示方向。

- **中点电势公式滥用**  
  中点电势等于两端点电势平均值，仅对匀强电场中同一直线上的点严格成立；在其他电场（如点电荷电场）中不成立。

- **忽略 $W_1=W_2$ 的特殊几何暗示**  
  当 $W_1=W_2$ 时，可推出 $U_{ab}=U_{cd}$，结合匀强电场平行等长性质可得 $U_{ac}=U_{bd}$，进而导出相关两点间电势差关系；忽略该条件易漏选正确选项。

## 代表题精讲
### 代表题：2018-新课标Ⅱ-08（多选）
**题目**  
同一平面内 $a$、$b$、$c$、$d$ 四点处于匀强电场中，电场方向与此平面平行。$M$ 为 $a$、$c$ 中点，$N$ 为 $b$、$d$ 中点。电荷量为 $q$（$q>0$）的粒子从 $a$ 移到 $b$，电势能减小 $W_1$；从 $c$ 移到 $d$，电势能减小 $W_2$。下列选项正确的是：  
A. 场强方向一定与 $ab$ 连线平行  
B. 若粒子从 $M$ 移到 $N$，电场力做功一定为 $\frac{W_1+W_2}{2}$  
C. 若 $cd$ 间距离为 $L$，则场强大小一定为 $\frac{W_2}{qL}$  
D. 若 $W_1=W_2$，则 $a$、$M$ 间电势差一定等于 $b$、$N$ 间电势差

**思路**  
粒子在匀强电场中移动，电势能减少量等于电场力做的正功：$W=qU$。  
由中点电势公式：$\varphi_M=\frac{\varphi_a+\varphi_c}{2}$，$\varphi_N=\frac{\varphi_b+\varphi_d}{2}$，再求 $M$ 到 $N$ 的功。  
场强 $E=\frac{U}{d}$ 必须用沿场强方向的投影距离；场强方向取决于等势面而不是任意两点连线。  
$W_1=W_2$ 导出 $U_{ab}=U_{cd}$，结合匀强电场平行等长关系可推出 $U_{ac}=U_{bd}$，进而得到 $U_{aM}=U_{bN}$。

**步骤**  
1. **求 $ab$ 间电势差**：由 $W_1 = qU_{ab}$，得 $U_{ab} = \frac{W_1}{q}$；同理 $U_{cd} = \frac{W_2}{q}$。  
2. **分析 A 选项**：场强方向由等势面决定，不一定与 $ab$ 连线平行，A 错误。  
3. **分析 B 选项**：  
   $\varphi_M = \frac{\varphi_a+\varphi_c}{2}$，$\varphi_N = \frac{\varphi_b+\varphi_d}{2}$  
   $U_{MN} = \varphi_M - \varphi_N = \frac{1}{2} [(\varphi_a-\varphi_b) + (\varphi_c-\varphi_d)] = \frac{U_{ab}+U_{cd}}{2}$  
   则 $W_{MN} = qU_{MN} = q \cdot \frac{U_{ab}+U_{cd}}{2} = \frac{W_1+W_2}{2}$，B 正确。  
4. **分析 C 选项**：  
   $W_2 = qU_{cd}$，但 $U_{cd} = E \cdot d$（$d$ 为 $cd$ 在电场方向上的投影长度），当 $cd$ 不沿电场方向时 $d < L$，故 $E = \frac{W_2}{qL}$ 不一定成立，C 错误。  
5. **分析 D 选项**：  
   若 $W_1 = W_2$，则 $U_{ab} = U_{cd}$，即 $\varphi_a - \varphi_b = \varphi_c - \varphi_d$，移项得 $\varphi_a - \varphi_c = \varphi_b - \varphi_d$，即 $U_{ac} = U_{bd}$。  
   $M$ 为 $ac$ 中点，$N$ 为 $bd$ 中点，故 $U_{aM} = \frac{U_{ac}}{2}$，$U_{bN} = \frac{U_{bd}}{2}$，因此 $U_{aM} = U_{bN}$，D 正确。  
   正确选项为 B、D。

**点评/变式**  
- 本题核心是匀强电场中电势差计算的线性叠加，中点电势公式是破局关键。  
- 易错点集中在场强公式中 $d$ 的几何意义与方向判断，切忌想当然代入两点直线距离。  
- 变式：可将矩形、平行四边形等特殊几何图形引入，结合 $W_1=W_2$ 条件求某点的电势或场强大小，训练等分法画等势线与确定场强方向。
