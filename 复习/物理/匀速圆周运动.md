## 知识精要
- **匀速圆周运动条件**：物体所受合外力全部提供向心力，即 $F_合 = F_n$，且 $F_n$ 大小恒定、方向始终指向圆心并与速度垂直。  
- **向心力公式**：$F_n = m\dfrac{v^2}{r} = m\omega^2 r = m\dfrac{4\pi^2}{T^2}r = m\omega v = m\cdot 4\pi^2 n^2 r$。向心力是按效果命名的力，不是性质力。
- **天体匀速圆周运动**：万有引力提供向心力   
  $$G\dfrac{Mm}{r^2} = m\dfrac{v^2}{r} = m\omega^2 r = m\dfrac{4\pi^2}{T^2}r$$  
  轨道半径 $r$ 越大，线速度 $v$、角速度 $\omega$、向心加速度 $a_n$ 越小，周期 $T$ 越大（“越高越慢”）。地面物体静止时合力为零，所受引力 $F_引 = \dfrac{GMm}{R^2}$，支持力与引力的合力为零；在轨飞船所受引力即为合力。
- **带电粒子在匀强磁场中的匀速圆周运动**：洛伦兹力提供向心力 $qvB = m\dfrac{v^2}{r}$，得  
  $$r = \dfrac{mv}{qB},\quad T = \dfrac{2\pi m}{qB}$$  
  $T$ 与 $v$、$r$ 无关。解题核心是定圆心、求半径、画轨迹，利用几何关系找出半径与已知长度的联系。
- **辐向电场中的圆周运动**：若电场强度 $E \propto \dfrac{1}{r}$ 且方向指向圆心，则带电粒子可在某些特定半径处靠电场力提供向心力做匀速圆周运动：$qE = q\dfrac{k}{r} = m\dfrac{v^2}{r}$。若粒子不做圆周运动，径向上的电场力做功，动能必变化。

## 解题方法与套路
1. **明确运动类型**：匀速圆周运动→合外力=向心力；非匀速圆周运动或一般曲线运动→径向合力不为 $m\dfrac{v^2}{r}$，或有切向力做功。
2. **受力分析，指向圆心列向心力方程**：将力按径矢方向投影，写出 $F_向 = m\dfrac{v^2}{r} = m\omega^2 r$。  
   - 天体：$G\dfrac{Mm}{r^2} = m\omega^2 r$。  
   - 磁场：$qvB = m\dfrac{v^2}{r}$。  
   - 辐向电场：$qE(r) = m\dfrac{v^2}{r}$。
3. **几何关系求半径**（尤其磁场问题）：  
   - 若已知出射点区域占圆周的比例，画出临界轨迹，利用弦切角、圆心角、半径关系。  
   - 轨迹圆半径 $R$ 与磁场圆半径 $r_0$ 的关系常通过三角函数或勾股定理给出，如 $R = r_0\tan\dfrac{\theta}{2}$ 等。
4. **对比不同轨道或不同粒子**：利用向心力方程导出 $v\propto r$（磁场）、$\omega\propto r^{-3/2}$（天体）等比例关系，直接通过半径之比求速度或角速度之比。
5. **判断动能变化**（辐向电场等）：若粒子沿径向移动，电场力（或径向分力）做正/负功→动能变化。结合轨迹凹凸判断径向速度分量变化。

## 高频易错
- **质量不变性**：在宏观低速下，物体质量不随位置、运动状态改变。太空物资质量等于地面质量，失重是“视重”为零。
- **引力与合力混淆**：地面静止物体合力为零，所受地球引力并不为零；在轨做匀速圆周运动的物体，合力等于引力，但因其轨道半径 $r>R$，引力比地面时小，合力也比地面时（零除外？实际上地面合力为零，在轨合力不为零）概念易错。  
- **角速度比较的对象错误**：地球自转角速度等于同步卫星的角速度，近地轨道飞船的角速度大于同步卫星角速度。
- **辐向电场中非圆周轨迹的功能关系**：电场力沿径向，若粒子的轨迹半径不断变化，径向位移必导致电场力做功，动能会改变。不可随意套用匀速圆周运动的结论。
- **带电粒子在磁场中的半径与速度的正比关系误用**：$r=\frac{mv}{qB}$，仅当 $B$ 不变时 $v \propto r$，若遇不同磁场区需重新分析。误判临界角时，常把磁场边界弦对应的圆心角当作轨迹圆的圆心角。  
- **几何关系定错**：六分之一圆周对应的圆心角是 $60^\circ$，三分之一圆周是 $120^\circ$。画图时务必分清是磁场圆上的弧还是轨迹圆。

## 代表题精讲
### 2023-新课标-04  
**题目**：天舟六号携带物资进入距地面约 $400\,\text{km}$ 轨道（低于同步卫星轨道），与空间站对接后近似做匀速圆周运动，判断各选项。  
**思路**：质量不可变；引力用 $F = \dfrac{GMm}{r^2}$ 比较；合力在地面为零、在太空不为零；角速度用 $\omega = \sqrt{\dfrac{GM}{r^3}}$ 与同步卫星（$\omega = \omega_{\text{地球自转}}$）比较。  
**步骤**：  
- A：低速宏观质量不变→A错。  
- B、C：设轨道半径 $r = R+h$，物资所受引力 $F_1 = \dfrac{GMm}{r^2}$；地面引力 $F_0 = \dfrac{GMm}{R^2}$。因 $r>R$，$F_1 < F_0$→C错。地面物体合力为零，在轨合力=$F_1\neq 0$，比地面合力大（地面为0）→B错。  
- D：由 $G\dfrac{Mm}{r^2}=m\omega^2 r \Rightarrow \omega = \sqrt{\dfrac{GM}{r^3}}$，$r < r_{\text{同步}}$，故 $\omega > \omega_{\text{同步}} = \omega_{\text{自转}}$→D对。  
**点评/变式**：对比地面与太空状态，要牢记质量不变、“重力”实为引力分力（或引力本身）。同步卫星的角速度是重要参照。变式可考：求线速度大小关系、周期长短等。

### 2022-全国乙-08  
**题目**：同轴半圆柱形极板间电场强度 $E \propto \dfrac{1}{r}$ 且指向圆心。粒子1、2做半径 $r_1$、$r_2$ 的匀速圆周运动；粒子3从 $r_2$ 射入、$r_1$ 射出；粒子4从 $r_1$ 射入、$r_2$ 射出。判断动能关系。  
**思路**：匀速圆周运动粒子满足 $qE = m\dfrac{v^2}{r}$；非圆周轨迹通过功能关系和曲率半径分析动能变化。  
**步骤**：  
- 设 $E = \dfrac{k}{r}$，对粒子1：$q\dfrac{k}{r_1}=m\dfrac{v_1^2}{r_1} \Rightarrow \frac12 mv_1^2 = \frac12 qk$；同理粒子2动能 $\frac12 mv_2^2 = \frac12 qk$。所以粒子1、2做匀速圆周运动时动能相等，与半径无关→C错。  
- 粒子3从大半径 $r_2$ 到小半径 $r_1$，初始若要做半径为 $r_2$ 的圆周运动需动能 $\frac12 qk$，但轨迹向内偏折，表明在 $r_2$ 处径向合力大于所需向心力，即实际速度小于圆周运动速度，故入射动能小于 $\frac12 qk$；随着向圆心靠近，电场力做正功（力指向圆心，位移向内），动能增加，所以出射动能大于入射动能→A错。  
- 粒子4从小半径 $r_1$ 到大半径 $r_2$，轨迹向外偏，初始所需向心力大于电场力，速度大于同位置圆周运动速度，入射动能大于 $\frac12 qk$；径向外移时电场力做负功，动能减小，出射动能小于入射动能→B对。  
- 粒子1动能 = $\frac12 qk$，粒子3入射动能小于 $\frac12 qk$→D对。  
**点评/变式**：辐向电场中“匀速圆周运动动能与半径无关”是关键结论（来源于 $E\propto 1/r$）。判断非圆周运动动能变化可用“向心供需”比较：若实际径向力 > 所需向心力，物体会向圆心偏折，当前速率小于圆周速率；功能关系辅助。

### 2017-新课标Ⅱ-05  
**题目**：圆形匀强磁场区域半径为 $r$，粒子以速率 $v_1$ 射入时出射点分布在六分之一圆周；以 $v_2$ 射入时出射点分布在三分之一圆周，求 $v_2:v_1$。  
**思路**：出射点分布对应最远出射点的弦对磁场圆心张角，由几何关系找出轨迹圆半径 $R$ 与磁场圆半径 $r$ 的关系，再用 $v \propto R$ 求比。  
**步骤**：  
- 速率 $v_1$ 时，出射点占 $1/6$ 圆周→最远点与 $P$ 点对磁场圆心张角 $\angle POM = 60^\circ$。此时轨迹圆半径 $R_1$：直径 $2R_1$ 与弦 $PM$ 满足 $R_1 = \dfrac{r}{2}$（轨迹弦切角关系：$\sin30^\circ = \dfrac{r/2}{R_1}$? 正确推导：由几何，$P$ 为入射点，沿径向射入，轨迹圆心在过 $P$ 的垂线上，出射点 $M$，磁场圆心 $O$，轨迹圆心 $O_1$，$\triangle OO_1M$ 中 $OO_1=R_1$，$OM=r$，$\angle O_1OM=30^\circ$，得 $R_1 = \dfrac{r}{2}$。）。  
- 速率 $v_2$ 时，出射点占 $1/3$ 圆周→ $\angle PON = 120^\circ$。类似得 $R_2 = r\tan 60^\circ/2$? 通过标准解析 $R_2 = \dfrac{\sqrt{3}}{2}r$。  
- 由 $qvB=m\dfrac{v^2}{R} \Rightarrow v = \dfrac{qBR}{m} \propto R$，所以 $v_2 : v_1 = R_2 : R_1 = \sqrt{3} : 1$。  
**点评/变式**：核心是准确画出临界轨迹并利用磁场圆和轨迹圆的半径、圆心角关系。若出射点占比改为“某弦长”等，同理转化为几何约束。比例题目中无需具体求 $R$ 的数值，可用三角函数直接写出比例。
