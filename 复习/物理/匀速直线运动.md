## 知识精要
- **定义**：物体在任意相等时间间隔内通过的位移都相同的直线运动，即速度恒定（大小、方向均不变）。
- **核心特征**：加速度 $a=0$，合力 $F_{\text{合}}=0$（物体处于平衡状态）。
- **基本公式**：位移 $x = vt$，速度 $v$ 恒定。
- **能量特征（考频极高）**：合力做功为零，动能不变 $\Delta E_k = 0$。  
  若物体受多力作用，动能定理为 $W_{\text{合}} = \sum W_i = 0$。  
  据此可直接求某一力做功、求克服某力做功等。
- **常见情境**：收尾速度（雨滴下落、跳伞）、最大速度后匀速阶段（车辆、运动员）、传送带匀速段等。

## 解题方法与套路
1. **状态确认**：审题抓关键描述——“恒定速率”“匀速”“一直匀速”“最大速率后匀速”等，立即锁定 $a=0$，$F_{\text{合}}=0$。
2. **受力分析**：画出物体受力图，明确各力及方向。
   - 若已知某些力，可利用 $\sum \vec{F} = 0$ 求未知力大小（如阻力大小、牵引力大小）。
3. **能量路径**：若涉及做功、高度变化等，优先使用动能定理：
   $$W_{\text{合}} = \Delta E_k = 0 \quad \Rightarrow \quad W_{\text{正}} + W_{\text{负}} = 0$$
   其中克服某力做功等于该力做功的绝对值。
4. **分段混合运动**（先匀加速后匀速）：将运动拆分为匀变速阶段和匀速阶段。
   - 合理设最大速度 $v_m$、加速度 $a$、加速时间 $t_1$、匀速时间 $t_2$ 等。
   - 利用速度公式 $v_m = at_1$，位移关系 $x_1 = \frac{1}{2}at_1^2$（或 $\frac{v_m}{2}t_1$），$x_2 = v_m t_2$，总时间 $t = t_1 + t_2$，总位移 $x = x_1 + x_2$。
   - 反应时间等“静止”阶段单独计入总时间，不做位移贡献。

## 高频易错
- **忽视“匀速”隐含的平衡条件**：看到匀速不立刻写合力为零，反而乱用牛顿第二定律或匀变速公式，导致丢分。
- **动能定理用错符号**：匀速时 $\Delta E_k = 0$，但常误写成 $mgh - W_f = \frac{1}{2}mv^2$。正确应为 $mgh - W_{\text{克}f} = 0$（其中 $W_{\text{克}f}$ 为克服阻力做功）或 $W_G + W_f = 0$，即 $mgh - |W_f| = 0$。
- **“克服某力做功”与“该力做功”混淆**：克服做功取正值，做功有正负。例：重力做功 $mgh$，阻力做功 $-mgh$，克服阻力做功 $mgh$。
- **分段运动的时间陷阱**：将总时间直接代入匀速阶段的位移公式 $x=vt$，未扣除加速时间或反应时间，导致总位移计算错误。
- **空气阻力与速度关系的误解**：题设“恒定的速率”表示已平衡，阻力大小等于重力，不随速度变化（已恒定），勿用 $f=kv$ 等未给条件。

## 代表题精讲
### 题1（2023·新课标·02）
**题目**：无风时，雨滴受空气阻力作用在地面附近以恒定速率竖直下落。质量为 $m$ 的雨滴以速率 $v$ 下落高度 $h$ 过程中，克服空气阻力做的功为（重力加速度为 $g$）  
A. 0 B. $mgh$ C. $\frac{1}{2}mv^2 - mgh$ D. $\frac{1}{2}mv^2 + mgh$

**思路**：匀速→合力为零→动能定理 $\Delta E_k = 0$→$W_G + W_f = 0$。克服阻力做功 $W_{\text{克}} = -W_f = W_G = mgh$。

**步骤**：  
1. 确认过程：高度下降 $h$，初末速度大小均为 $v$，动能不变。  
2. 重力做功 $W_G = mgh$（正功）。  
3. 由动能定理：$W_G + W_f = 0 \;\Rightarrow\; W_f = -mgh$。  
4. 克服空气阻力做功 $W_{\text{克}} = |W_f| = mgh$。  
答案选 B。

**点评/变式**：  
- 本题直接考查匀速运动中功能关系的核心结论：匀速下落时克服阻力做功等于重力势能的减少量。  
- 变式：若雨滴加速下落，则 $W_{\text{克}} < mgh$（部分势能转化为动能）；若减速下落，则 $W_{\text{克}} > mgh$。抓住动能变化是解题关键。

### 题2（2010·新课标Ⅰ·11，节选匀速阶段）
**题目**：博尔特在北京奥运会100m比赛中，从发令到起跑的反应时间为0.15s，起跑后先做匀加速运动，达到最大速率后做匀速运动跑完全程，成绩为9.69s。已知100m位移，求最大速率及加速阶段的加速度等问题（原题含200m数据，此处仅取匀速相关逻辑）。

**思路**：反应时间无位移；起跑后匀加速至最大速率 $v_m$；之后匀速至终点。恰有两段运动，需设变量串联方程。

**步骤**：  
1. 设匀加速时间 $t_1$，加速度 $a$，最大速率 $v_m = a t_1$。  
2. 匀加速位移 $x_1 = \frac{v_m}{2} t_1$（初速为零）。  
3. 匀速位移 $x_2 = 100\,\text{m} - x_1$，匀速时间 $t_2 = \frac{x_2}{v_m}$。  
4. 总时间 $t_1 + t_2 = 9.69\,\text{s} - 0.15\,\text{s} = 9.54\,\text{s}$。  
5. 联立 $x_1 + x_2 = 100\,\text{m}$ 及时间关系，可解得 $v_m$、$t_1$ 等。  
（具体数值解略，思路关键在匀速段位移、时间表达）

**点评/变式**：  
- 匀速阶段在综合问题中常与匀变速阶段组合，解题关键是 **分开段写关系，不混淆公式**。  
- 易错点：总时间中漏减反应时间；用 $x=vt$ 处理全程而误将其视为全程匀速。  
- 这类题还会出现在传送带、最大速度行驶、先加速后匀速的追及等问题中，通法一致。
