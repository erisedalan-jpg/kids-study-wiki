## 知识精要
- **定义**：放射性元素的原子核有半数发生衰变所需的时间，叫作半衰期，符号 $T_{1/2}$ 或 $\tau$。它反映的是大量原子核衰变的统计快慢。
- **公式**：剩余质量 $m = m_0\left(\frac{1}{2}\right)^{\frac{t}{T}}$ 或剩余原子核数 $N = N_0\left(\frac{1}{2}\right)^{\frac{t}{T}}$，其中 $t$ 为经历的时间，$T$ 为半衰期。
- **适用条件与理解**：
  - 半衰期是对**大量原子核**的统计规律，对单个或少数几个原子核无意义。
  - 半衰期由原子核**内部自身因素**决定，与原子所处的物理状态（如温度、压强）和化学状态（单质或化合物）无关。
  - 不同的放射性元素半衰期不同，衰变过程质量数守恒、电荷数守恒，且满足动量守恒。
- **从图像读半衰期**：在 $m-t$ 或 $N-t$ 图像中，质量（或数量）变为原来**一半**所经历的时间为半衰期。注意坐标起点与比例，根据“任意两个时刻质量之比为 $1/2$ 时，时间间隔即为一个半衰期”进行推算。

## 解题方法与套路
1. **公式直接应用**  
   已知初始量 $m_0$ 和半衰期 $T$，求经过时间 $t$ 后的剩余量或求时间，直接套用 $m = m_0\left(\frac{1}{2}\right)^{t/T}$。求解指数时可取对数。
2. **图像读取半衰期**  
   - 步骤：在图像中找出质量（或数量）从任意值 $m_a$ 减少到 $m_a/2$ 所对应的两个时刻，其时间差即为一个半衰期。  
   - 技巧：若图像坐标不是从 $m_0$ 开始，直接找某点变为其一半的两个时刻更方便，避免原点干扰。  
3. **衰变中的动量与动能关系**  
   静止的核发生衰变时系统总动量为零，因此衰变产物（如 $\alpha$ 粒子和反冲核）的动量**大小相等、方向相反**。动能与质量成反比：$E_k = \frac{p^2}{2m}$，质量大的动能小。可据此判断动能之比或速度之比。
4. **质量亏损与衰变能的判断**  
   衰变中产物质量之和小于原核质量，差值为质量亏损，对应释放能量 $E = \Delta m c^2$。衰变方程遵循质量数、电荷数守恒。半衰期不因是否发生一次衰变而改变，更不等于单次衰变所需时间。

## 高频易错
- **误把半衰期当成一个原子核衰变所需时间**：半衰期是大量核的统计概念，一个核何时衰变是随机的，不能说“一个铀核的半衰期是放出 $\alpha$ 粒子所经历的时间”。
- **混淆图像中的“一半”**：不注意图中纵坐标的起点是否为初始值。如图线显示的是比值 $m/m_0$，从 $2/3$ 降到 $1/3$ 才是衰变一半，对应的横坐标差才是半衰期，而非直接从 $1/2$ 找起。
- **错误认为外界条件能改变半衰期**：温度、压强、化学反应不能改变放射性元素的半衰期。这是原子核本身属性。
- **动量与动能关系混乱**：衰变产物动量大小相等，但动能与质量成反比，不能认为二者动能相等，更不能直接用动能守恒。
- **忽略质量亏损或误认为质量数亏损**：质量亏损是指静质量亏损，而质量数（核子总数）是守恒的。衰变后新核与粒子质量之和**小于**衰变前质量，但质量数之和相等。

## 代表题精讲
### 代表题1：2021·全国乙·04（半衰期图像问题）
- **题目简述**：放射性核素 ${}^{113}\mathrm{In}$ 由 ${}^{113}\mathrm{Sn}$ 衰变产生。已知初始质量为 $m_0$ 的 ${}^{113}\mathrm{Sn}$ 经过时间 $t$ 后剩余质量为 $m$，给出 $\frac{m}{m_0}-t$ 图线，求其半衰期。选项为四个天数。
- **思路**：从图线上任取一点，找到该点质量变为一半所对应的时间差，即为一个半衰期。注意图线纵坐标是比值，直接从图上读取。
- **步骤**：
  1. 观察图线，当 $\frac{m}{m_0} = \frac{2}{3}$ 时，对应时刻 $t_1 = 67.3\ \mathrm{d}$。
  2. 当质量剩下一半，即 $\frac{m}{m_0} = \frac{1}{3}$ 时，对应时刻 $t_2 = 182.4\ \mathrm{d}$。
  3. 根据半衰期定义，$\frac{m}{m_0}$ 从 $\frac{2}{3}$ 降到 $\frac{1}{3}$ 恰好经历质量减半的过程，故半衰期 $T = t_2 - t_1 = 115.1\ \mathrm{d}$。
  4. 对照选项，选 C。
- **点评/变式**：此题重点考查从图像中提取半衰期的能力。陷阱在于并非直接从 $1/2$ 开始寻找，需找到任意两个成二分之一关系的点。变式：若纵坐标为质量（非比值），且初始量未知，仍可找任意点减半求时间差。熟练应用“半衰期与起始时刻无关”的特性。

### 代表题2：2017·新课标Ⅱ·02（α衰变中的物理量判断）
- **题目简述**：静止铀核 ${}^{238}_{92}\mathrm{U}$ 放出 $\alpha$ 粒子衰变成钍核 ${}^{234}_{90}\mathrm{Th}$，衰变方程已知。从下列说法中选出正确选项（原题选项：A. 衰变后钍核的动能等于 $\alpha$ 粒子的动能；B. 衰变后钍核的动量大小等于 $\alpha$ 粒子的动量大小；C. 铀核的半衰期等于其放出一个 $\alpha$ 粒子所经历的时间；D. 衰变后 $\alpha$ 粒子与钍核的质量之和等于衰变前铀核的质量）。
- **思路**：本题综合考查动量守恒、动能分配、半衰期概念和质量亏损。抓住“静止衰变”这一条件，利用系统总动量为零分析动量与动能关系；依据半衰期统计性判断 C 项；依据质量亏损判断 D 项。
- **步骤**：
  1. **动量分析**：衰变前铀核静止，总动量为零。衰变后 $\alpha$ 粒子和钍核组成的系统动量仍守恒为零，所以二者动量大小相等、方向相反。选项 B 正确。
  2. **动能分析**：由 $E_k = \frac{p^2}{2m}$，动量大小相等，则动能与质量成反比。钍核质量约为 $\alpha$ 粒子的 $\frac{234}{4} = 58.5$ 倍，故 $\alpha$ 粒子动能远大于钍核动能，选项 A 错误。
  3. **半衰期概念辨析**：半衰期是大量原子核衰变的统计规律，不表示一个特定核放出一个粒子所需的时间，且单个核衰变时刻随机。选项 C 错误。
  4. **质量亏损**：衰变时释放能量，存在质量亏损，产物静质量之和小于原核质量，选项 D 错误。正确选项只有 B。
- **点评/变式**：该题属于近代物理典型小题，一题多点，精准打击易错概念。复习时务必理解“静止衰变，动量等大反向；动能按质量反比分配”。对于半衰期，牢记“统计规律”四个字。变式可改为给出质量数，求动能之比或速度之比，亦可结合磁场中轨迹半径判断。
