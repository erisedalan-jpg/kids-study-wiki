## 知识精要

- **液体压强基本规律**：深度为 $h$ 的液柱产生的压强为 $p_{\text{液}}=\rho g h$。同种静止液体中，同一水平面上各点的压强相等（连通器原理）。
- **气体压强的确定**：通常选取与气体接触的液面或活塞为研究对象，利用受力平衡或液面高度差关系求出气体压强。常见表达式：
  $$p = p_0 \pm \rho g \Delta h$$
  其中 $p_0$ 为大气压强，$\Delta h$ 为液面高度差，“$+$”用于液面低于参考面，“$-$”用于液面高于参考面。在水银问题中常用 $\mathrm{cmHg}$ 单位，此时 $p = p_0 \pm h$（$h$ 以 $\mathrm{cm}$ 计）。
- **理想气体实验定律（等温变化）**：一定质量的理想气体，温度不变时，
  $$p_1 V_1 = p_2 V_2$$
  对于横截面积 $S$ 不变的玻璃管或气缸，体积可用空气柱长度 $l$ 代替：$p_1 l_1 = p_2 l_2$。
- **多段气体与多过程问题**：每一段封入气体均可视为独立的研究对象，应用等温变化规律。若涉及液柱移动、注入或放出液体，需结合几何关系确定初、末态气柱长度，并注意各气体压强之间的联系。

## 解题方法与套路

1. **确定研究对象**：明确哪一部分气体为“一定质量的理想气体”，通常为某段被封住的空气柱。
2. **画情景示意图**：画出初态和末态的液面位置、管长、空气柱长度等，标出已知量和未知量。
3. **写压强表达式**：
   - 根据液面高度差或力平衡，写出气体压强与大气压强、液柱高度差的关系式。
   - 注意连通器原理：同一水平面的压强相等，可列方程连接不同管或不同部分。
   - 遇到开口向下且液柱较高时，需判断是否出现真空，若产生真空，则管内压强由剩余液柱高度决定（如 $p = \rho g x$）。
4. **推空气柱长度**：由几何关系得出初、末态气体的体积或气柱长度。对于高热度题型，长度往往通过总长减去液柱长度得到。
5. **应用玻意耳定律**：$p_1 l_1 = p_2 l_2$（横截面积不变时），列方程求解。
6. **多过程依次处理**：有多个操作（放水银、注水银、转动等）时，分段分析，上一过程的末态即为下一过程的初态，逐步求解。
7. **检查与单位**：确保所有量单位统一（常用 $\mathrm{cmHg}$ 和 $\mathrm{cm}$），解的合理性（如长度不能为负，不能超过管长）。

## 高频易错

- **压强正负号搞反**：液面比参考面高还是低决定压强是加还是减，不能死记公式，要依据“越深压强越大”的原理判断。
- **忘记大气压的作用**：开口管或与大气连通的液面，其表面压强为 $p_0$；完全封闭并且有真空的区域压强为零。
- **连通器的隐含条件**：底部连通的几根管中，同一水平面压强相等，这是建立各管气体压强关系的关键，但常被忽略。
- **真空条件误判**：当管开口向下且水银柱较长时，部分水银可能流出，封闭端出现真空，此时管内气体压强等于剩余水银柱产生的压强，而非 $p_0-\rho g h$。
- **几何关系错误**：空气柱长度变化等于液柱长度变化之和或差，但学生常常弄错谁增加、谁减少。尤其在注入或放出水银时，务必画图辅助分析。
- **对象混淆**：若系统中有多段气体，各自独立满足玻意耳定律，但不能将不同部分的气体混为一谈。压强间的联系必须通过液柱或活塞的平衡建立。
- **误用气态方程**：此类问题往往明确“缓慢”“温度保持不变”，须用玻意耳定律；若题目明确温度变化，则需用理想气体状态方程 $\frac{pV}{T}=C$，不可乱套。

## 代表题精讲

### **题目**（2021全国乙·14）
玻璃装置中竖直管 A、B 上端封闭、C 开口，三管下部连通。A 管长 $l_1=13.5\ \mathrm{cm}$，B 管长 $l_2=32\ \mathrm{cm}$。从 C 管缓慢注入水银，直至 B、C 两管水银柱高度差 $h=5\ \mathrm{cm}$。已知 $p_0=75\ \mathrm{cmHg}$，求此时 A、B 两管内水银柱的高度差。

**思路**：三个管底部连通，底部压强相等。设初始 A、B 内气体均为大气压强 $p_0$，体积对应原管长。注入水银后，B 与 C 高度差 $5\ \mathrm{cm}$，说明 B 内气体压强 $p_B = p_0 + 5$。对 B 内气体用等温变化求出其空气柱长度，从而得到 B 管内水银柱长度，进而求出底部压强。再利用底部压强相等，得到 A 管底部压强，写出 A 内气体压强表达式，对 A 内气体用等温变化求出空气柱长，最终得 A、B 水银柱高度差。

**步骤**：
1. 设管的横截面积为 $S$，初态：A、B 内气柱长分别为 $l_1=13.5\ \mathrm{cm}$，$l_2=32\ \mathrm{cm}$，压强均为 $p_0=75\ \mathrm{cmHg}$。
2. 末态：B 与 C 管水银面高度差 $h=5\ \mathrm{cm}$，C 开口，故 B 内气体压强 $p_B = p_0 + h = 80\ \mathrm{cmHg}$。
3. 对 B 内气体：$p_0 l_2 = p_B l_{B\text{气}}'\ \Rightarrow\ 75\times32 = 80\times l_{B\text{气}}'$，得 $l_{B\text{气}}'=30\ \mathrm{cm}$。
4. B 管总长 $32\ \mathrm{cm}$，所以 B 中水银柱长 $\Delta L_B = 2\ \mathrm{cm}$。
5. 底部压强 $p_{\text{底}} = p_B + \rho g \Delta L_B$，以 $\mathrm{cmHg}$ 为单位：$p_{\text{底}} = 80 + 2 = 82\ \mathrm{cmHg}$。
6. 设 A 中水银柱长 $x$，则 A 内气柱长为 $l_{A\text{气}}' = l_1 - x = 13.5 - x$。A 内气体压强 $p_A = p_{\text{底}} - x$（因为 A 内气柱上方压强加 $x$ 高度的水银等于底部压强）。
7. 对 A 内气体：$p_0 l_1 = p_A l_{A\text{气}}'$，即 $75\times13.5 = (82 - x)(13.5 - x)$。
8. 整理得 $x^2 - 95.5x + 94.5 = 0$，解得 $x=1\ \mathrm{cm}$（另一解 $94.5\ \mathrm{cm}$ 不符舍去）。
9. A、B 水银柱高度差：$x - \Delta L_B = 1 - 2 = -1\ \mathrm{cm}$，绝对值 $1\ \mathrm{cm}$。

**点评/变式**：本题关键是利用底部连通器压强相等，以及通过等温变化求出气柱长度再推液柱长度。注意 C 管开口，B 管上端封闭，底部压强由 B 管条件求得，再反推 A。类似变式可改为两管连通、注入液体等，均需抓住同一水平面压强相等的核心关系。

### **题目**（2015新课标Ⅱ·14）
U 形管竖直放置，A 侧上端封闭，B 侧上端与大气相通，下端开关 K 关闭。初始 A 侧气柱长 $l=10.0\ \mathrm{cm}$，B 侧水银面比 A 侧高 $h=3.0\ \mathrm{cm}$。打开 K 放出部分水银，至两侧水银面高度差为 $h_1=10.0\ \mathrm{cm}$ 时关闭 K。大气压 $p_0=75.0\ \mathrm{cmHg}$。（ⅰ）求放出水银后 A 侧空气柱长度；（ⅱ）再向 B 侧注入水银，使两侧水银面达到同一高度，求注入的水银在管内的长度。

**思路**：初始状态利用高度差求 A 内压强。放出水银过程，A 内气体等温膨胀，末态高度差已知，可求压强，再用玻意耳定律求气柱长度。第二步注入水银使液面相平，此时 A、B 液面等高，A 内压强变为 $p_0$，用等温变化求出新气柱长，结合几何关系求注入的水银长度。

**步骤**：
（ⅰ）
1. 初态：A 内气柱长 $l_1=10.0\ \mathrm{cm}$，压强 $p_1 = p_0 - h = 75.0 - 3.0 = 72.0\ \mathrm{cmHg}$（A 侧液面高于 B 侧）。
2. 放出水银后末态：两侧高度差 $h_1=10.0\ \mathrm{cm}$，此时仍是 B 侧高于 A 侧（因放出水银后 B 侧下降更多），故 $p_2 = p_0 - h_1 = 65.0\ \mathrm{cmHg}$。
3. 等温变化：$p_1 l_1 = p_2 l_2$，得 $72.0\times 10.0 = 65.0 \times l_2$，$l_2 \approx 11.08\ \mathrm{cm}$。
（ⅱ）
4. 注入水银使液面相平，则末态 A 内压强 $p_3 = p_0 = 75.0\ \mathrm{cmHg}$，气柱长 $l_3$ 满足 $p_1 l_1 = p_3 l_3$，得 $72.0\times 10.0 = 75.0\times l_3$，$l_3 = 9.6\ \mathrm{cm}$。
5. 几何分析：设 U 形管横截面积均匀。初始（放出水银后）A 气柱长 $l_2=11.08\ \mathrm{cm}$，B 侧比 A 侧液面高 $h_1=10.0\ \mathrm{cm}$。注入水银使液面相平，气柱缩短 $l_2 - l_3 = 1.48\ \mathrm{cm}$，这导致 A 侧液面上升 $1.48\ \mathrm{cm}$（因为气柱底端即水银面）。要想相平，B 侧需注入的水银不仅要补足原来比 A 侧高的 $10.0\ \mathrm{cm}$，还要补充因 A 侧液面上升而需要多注入的部分。
   设注入水银在管内的长度为 $\Delta L$。注入后，A 侧液面上升 $\Delta h_A = l_2 - l_3 = 1.48\ \mathrm{cm}$。B 侧与 A 侧最终相平，则 B 侧液面相对于放出水银后的位置上升了 $\Delta h_B = h_1 + \Delta h_A = 10.0 + 1.48 = 11.48\ \mathrm{cm}$。注入水银所占长度即为两侧液面变化量之和（因为液体体积守恒）：$\Delta L = \Delta h_A + \Delta h_B = 1.48 + 11.48 = 12.96\ \mathrm{cm} \approx 13.0\ \mathrm{cm}$。也可直接计算 $\Delta L = h_1 + 2(l_2 - l_3)$。

**点评/变式**：该题典型地综合了压强平衡与等温变化，并涉及液面移动的几何关系。易错点在于第二步求注入水银长度时只加高度差 $h_1$，而忘记 A 侧液面上升也需额外补充水银。通用方法：分别找出两侧液面的高度变化量，注入总长度等于两侧变化量之和。变式可能为抽出部分水银、或一侧管径不同，需转换体积关系。

### **题目**（2011新课标·14）
细长玻璃管上端开口、下端封闭，下部水银柱 $l_1=66\ \mathrm{cm}$，中间封有空气柱 $l_2=6.6\ \mathrm{cm}$，上部水银柱 $l_3=44\ \mathrm{cm}$，水银面恰与管口平齐。大气压 $p_0=76\ \mathrm{cmHg}$。将玻璃管绕底端缓慢转动一周，求在开口向下和转回到原来位置时管中空气柱的长度。

**思路**：开口向上初态的压强由上部水银柱求得。转至开口向下时，由于管内水银总长度达 $110\ \mathrm{cm}$，管口向下会导致水银流出，封闭端可能出现真空。需判断剩余水银柱长度，根据平衡条件求出空气柱压强（等于剩余水银柱高 $\times\rho g$）。随后应用玻意耳定律，并注意几何约束。转回原位置时，再次分析压强变化，列式求解。

**步骤**：
1. 初态开口向上：空气柱压强 $p_1 = p_0 + l_3 = 76 + 44 = 120\ \mathrm{cmHg}$，气柱长 $l_2=6.6\ \mathrm{cm}$。
2. 开口向下时：设管口处剩余水银柱长度为 $x$（即原上部水银流出一部分后剩下的），则管内空气柱压强 $p_2 = x\ \mathrm{cmHg}$（因为封闭端可能出现真空，管内气体压强即等于剩余水银产生的压强；同时管口处水银面与大气接触，满足 $p_2 + x = p_0$？不对，需谨慎：开口向下，管口处水银面为大气压 $p_0$，设管内气体压强 $p_2$，剩余水银柱高 $x$，根据连通器：管口处 $p_0 = p_2 + x$，这样 $p_2 = p_0 - x$。但答案是按真空处理的，因为水银总长 $L=l_1+l_3=110\ \mathrm{cm} > 76\ \mathrm{cm}$，转动后上部水银不可能全部保留，必有部分流出且形成真空，此时空气柱压强由剩余在下端
