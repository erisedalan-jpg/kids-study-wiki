## 知识精要

1. **带电粒子在匀强磁场中的基本运动**
   质量为 $m$、电荷量为 $q$ 的粒子以速度 $v$ 垂直射入磁感应强度为 $B$ 的匀强磁场，只受洛伦兹力作用，做匀速圆周运动。

2. **核心公式**
   - 洛伦兹力提供向心力：$qvB = m\frac{v^{2}}{r}$
   - 轨道半径：$r = \frac{mv}{qB}$
   - 周期（与速度无关）：$T = \frac{2\pi r}{v} = \frac{2\pi m}{qB}$
   - 角速度：$\omega = \frac{2\pi}{T} = \frac{qB}{m}$
   - 向心加速度：$a = \frac{qvB}{m}$ 或 $a = \frac{v^{2}}{r} = \omega^{2}r$

3. **适用条件**
   - 粒子速度方向与磁场方向垂直（$v \perp B$）
   - 忽略重力影响（洛伦兹力远大于重力等其他力）

4. **比例关系（$v$ 相同，$m,q$ 不变时）**
   - $r \propto \frac{1}{B}$
   - $a \propto B$
   - $T \propto \frac{1}{B}$
   - $\omega \propto B$

## 解题方法与套路

1. **确定不变量的思维起点**
   题目出现“速率相同”的同一带电粒子，立即锁定不变量：$v$、$m$、$q$。
   变量仅来自不同区域的磁感应强度 $B$。

2. **建立公式比例链**
   将所求物理量（$r$、$a$、$T$、$\omega$）用题目中的不变量和变量表达，写出正反比关系：
   - $r = \frac{mv}{qB} \implies r \propto \frac{1}{B}$
   - $a = \frac{qvB}{m} \implies a \propto B$
   - $T = \frac{2\pi m}{qB} \implies T \propto \frac{1}{B}$
   - $\omega = \frac{qB}{m} \implies \omega \propto B$

3. **套用比例快速对照**
   设基准区域参数（如Ⅰ区 $B_Ⅰ = kB$，Ⅱ区 $B_Ⅱ = B$），将各物理量的倍数关系逐项写出，直接匹配选项。

4. **排除陷阱选项**
   特别注意方向性：$T$ 与 $\omega$ 互为倒数，若 $B$ 变为 $k$ 倍，周期变为 $1/k$ 倍而非 $k$ 倍；加速度、角速度与 $B$ 成正比。

## 高频易错

- **周期与速度/半径关联性误判**
  中学阶段常见错误：从 $T=\frac{2\pi r}{v}$ 看，认为 $r$ 变了周期就变。实际上 $r$ 与 $v$ 同步变化，当 $v$ 不变、$B$ 改变时，$r$ 变但 $v$ 不变，则 $T$ 可由 $T=\frac{2\pi m}{qB}$ 直接判断，与速度无关。

- **比例颠倒**
  未明确Ⅰ、Ⅱ区 $B$ 大小关系，直接主观推测。题干“Ⅰ中的磁感应强度是Ⅱ中的k倍”，应严格赋值：$B_Ⅰ = kB$，$B_Ⅱ = B$。很多考生将 $k$ 倍关系弄反，导致全题错误。

- **混淆角速度与周期的倒数关系**
  周期与角速度互为倒数，当 $B$ 变为 $k$ 倍时，$\omega$ 变为 $k$ 倍，$T$ 变为 $1/k$ 倍。部分考生会错误地认为周期也变为 $k$ 倍。

- **加速度表达式混乱**
  加速度既可用 $a=\frac{qvB}{m}$，也可用 $a=\frac{v^2}{r}$。若用后者且错误地认为 $r$ 不变或代入错误比例，则会得出相反的结论。最稳妥的方法是用 $a \propto B$ 直接判断。

## 代表题精讲

### 代表题1：2015-新课标Ⅱ-06

**题目**：两个匀强磁场区域Ⅰ和Ⅱ，Ⅰ中的磁感应强度是Ⅱ中的 $k$ 倍。两个速率相同的电子分别在两磁场区域做圆周运动。与Ⅰ中运动的电子相比，Ⅱ中的电子（ ）  
A. 运动轨迹的半径是Ⅰ中的 $k$ 倍  
B. 加速度的大小是Ⅰ中的 $k$ 倍  
C. 做圆周运动的周期是Ⅰ中的 $k$ 倍  
D. 做圆周运动的角速度是Ⅰ中的 $k$ 倍  

**思路**：  
电子速率 $v$ 相同，质量 $m$、电荷量 $e$ 均保持不变。设Ⅱ区磁感应强度为 $B$，则Ⅰ区为 $kB$。写出半径、加速度、周期、角速度的表达式，比较Ⅱ区与Ⅰ区物理量的比值。

**步骤**：  
1. 半径：$r = \frac{mv}{eB}$，则 $r_Ⅰ = \frac{mv}{ekB}$，$r_Ⅱ = \frac{mv}{eB}$，$\frac{r_Ⅱ}{r_Ⅰ} = k$，即Ⅱ中半径是Ⅰ中的 $k$ 倍。A正确。
2. 加速度：$a = \frac{evB}{m}$，$a_Ⅰ = \frac{ev \cdot kB}{m}$，$a_Ⅱ = \frac{evB}{m}$，$\frac{a_Ⅱ}{a_Ⅰ} = \frac{1}{k}$，即Ⅱ中加速度是Ⅰ中的 $\frac{1}{k}$ 倍。B错误。
3. 周期：$T = \frac{2\pi m}{eB}$，$T_Ⅰ = \frac{2\pi m}{ekB}$，$T_Ⅱ = \frac{2\pi m}{eB}$，$\frac{T_Ⅱ}{T_Ⅰ} = k$，即Ⅱ中周期是Ⅰ中的 $k$ 倍。C正确。
4. 角速度：$\omega = \frac{eB}{m}$，$\omega_Ⅰ = \frac{ekB}{m}$，$\omega_Ⅱ = \frac{eB}{m}$，$\frac{\omega_Ⅱ}{\omega_Ⅰ} = \frac{1}{k}$，即Ⅱ中角速度是Ⅰ中的 $\frac{1}{k}$ 倍。D错误。

**答案**：AC

**点评/变式**  
- 本题核心是抓住“相同速率”同一粒子，直接利用与 $B$ 的比例关系得出结论。  
- 变式训练：若将“速率相同”改为“动量大小相同”或“动能相同”，则比例关系会发生变化，需重新推导。例如动能相同，$v \propto \frac{1}{\sqrt{m}}$（若 $m$ 可变），此时周期仍与速度无关，但半径表达式要调整。务必强化不变量意识。
