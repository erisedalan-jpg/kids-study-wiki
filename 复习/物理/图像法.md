## 知识精要
- **图像法的核心**：将物理量间的非线性关系通过坐标变换转为线性关系（“化曲为直”），利用图线的斜率、截距等几何特征求解物理量。
- **通用步骤**：
  1. 导出所研究的两个物理量间的函数关系 $y = f(x)$；
  2. 通过代数变形写成 $Y = kX + b$ 的形式，其中 $Y$、$X$ 只含测量数据，$k$、$b$ 含待求量；
  3. 确定纵轴 $Y$、横轴 $X$，描点作图；
  4. 在拟合直线上取两较远点计算斜率 $k$，延长图线读取截距 $b$（注意单位与起点）；
  5. 代入 $k$、$b$ 表达式解出待求物理量。
- **典型应用——伏阻法测电源 $E$、$r$**（电压表内阻 $R_V$、并联定值电阻 $R_0$ 扩大测量范围）：  
  闭合电路欧姆定律
  $$E = U + \left( \frac{U}{R_V} + \frac{U}{R_0} \right)(R + r)$$
  变形得
  $$\frac{1}{U} = \frac{1}{E} \left( 1 + \frac{r}{R_{\text{并}}} \right) + \frac{1}{E R_{\text{并}}} \cdot R$$
  其中 $R_{\text{并}} = \dfrac{R_V R_0}{R_V + R_0}$，图线 $\dfrac{1}{U} - R$ 为直线。  
  斜率 $k = \dfrac{1}{E R_{\text{并}}}$，截距 $b = \dfrac{1}{E} \left( 1 + \dfrac{r}{R_{\text{并}}} \right)$，联立解得
  $$E = \frac{1}{k R_{\text{并}}}, \quad r = \frac{b}{k} - R_{\text{并}}$$
- **适用条件**：两轴均为线性坐标；所用数据点应均匀分布在拟合直线两侧；计算斜率时不得使用原始实验数据点代入公式直接求平均，必须从图线上取值。

## 解题方法与套路
1. **写原始方程**：根据电路结构，由闭合电路欧姆定律或部分电路欧姆定律列出 $E$ 与测量量 $U$、$I$（或 $R$）的关系式。注意电表内阻影响不可忽略时，应按实际电流路径写。
2. **线性化变形**：把方程整理为 $\displaystyle \frac{1}{U} = A \cdot R + B$ 或 $\displaystyle \frac{1}{I} = A \cdot R + B$ 等形式，明确斜率和截距中包含的已知量（如 $R_V$、$R_0$）与待求量（$E$、$r$）。
3. **保护措施判据**：闭合开关前电阻箱应处于**阻值最大**位置，以减小电流、保护电压表（防止超量程）。
4. **图像信息读取**：
   - 看清坐标起点（是否从零开始），截距 $b$ 直接读取纵轴交点的值；
   - 斜率 $k = \dfrac{\Delta Y}{\Delta X}$，选取点应标注在拟合直线上，不能直接用原始数据点且两取点距离尽量远；
   - 单位换算：电阻常用 $\Omega$ 或 $k\Omega$，电压用 $V$ 或 $mV$，计算时统一为国际单位。
5. **联立求解**：把 $k$、$b$ 的表达式联立，解出 $E$、$r$。注意有效数字与题目给的数据匹配。

## 高频易错
- **保护电阻阻值选小**：为防止电压表超量程，闭合开关前电阻箱 $R$ 必须取较大值，若错选小阻值，回路电流大，电压表分压可能超过量程损坏表头。
- **$\frac{1}{U}$ 表达式漏项或错并**：电压表与定值电阻 $R_0$ 并联时，总电流 $I = U/R_V + U/R_0$，易漏掉任一分支；若 $R_0$ 与电压表串联扩程，则 $I = U/R_V$，路端电压变成 $U_V + U_{R0}$，两种情况不可混淆。
- **斜率和截距代反**：变形后直线常为 $y = kx + b$，将 $y$ 对应于 $\frac{1}{U}$，$x$ 对应于 $R$，计算 $E$、$r$ 时代入关系易倒置。
- **图像坐标非齐次**：如图线纵轴起点不为零，截距 $b$ 不能用直接目视读取值代入零点的纵坐标，应由延长线在纵轴上的交点确定（线性坐标下读取原始坐标值）。
- **忘记等效并联电阻**：当电压表和定值电阻并联时，流过它们的总电流由并联总电阻 $R_{\text{并}} = R_V R_0/(R_V+R_0)$ 决定，若仍用 $R_V$ 或 $R_0$ 单独计算会出错。
- **有效数字错误**：$E$ 和 $r$ 的最终结果应与题目所给测量值的最小位数保持一致或合理保留，避免多写或少写。
