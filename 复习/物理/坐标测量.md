## 知识精要
- **平抛运动正交分解**
  水平方向：匀速直线 $x = v_0 t$；竖直方向：自由落体 $y = \frac{1}{2}gt^2$（通常取抛出点为原点，向下为 $y$ 轴正方向）。
- **相等时间间隔的获取**
  轨迹上水平位移相等的两点间，所用时间相等。若在坐标纸上 $x_{2}-x_{1}=x_{3}-x_{2}$，则小球由 $P_1\to P_2$ 与 $P_2\to P_3$ 的时间 $T$ 相等。
- **竖直方向的匀变速规律**
  连续相等时间内的竖直分位移差恒定：$\Delta y = y_3-2y_2+y_1 = gT^{2}$。由此可求时间 $T$。
- **坐标测量与单位换算**
  从坐标纸读取格数，乘以每格代表的实际长度得到位移值（注意单位统一为国际单位）。
- **抛出点坐标的反推**
  由 $v_{0}=\frac{\Delta x}{T}$ 得到初速度；由中间时刻的竖直分速度 $v_{y}=\frac{y_3-y_1}{2T}$ 可得该点运动时间 $t=\frac{v_{y}}{g}$；再由 $x_0=x - v_0 t,\ y_0=y - \frac{1}{2}gt^{2}$ 求出抛出点坐标。

## 解题方法与套路
1. **建系读点**  
   在给出的坐标纸上，根据网格线读出 $P_{1}、P_{2}、P_{3}$ 三点的坐标 $(x_i,\ y_i)$。注意纵坐标方向及每格代表的实际长度 $L$，将格数乘 $L$ 换算成米。
2. **确认时间相等**  
   验证 $x_{2}-x_{1}=x_{3}-x_{2}$，从而判断 $P_{1}\to P_{2}$ 和 $P_{2}\to P_{3}$ 的时间间隔相等，设为 $T$。
3. **计算时间间隔 $T$**  
   计算相邻两段的竖直位移 $h_{12}=|y_{2}-y_{1}|$，$h_{23}=|y_{3}-y_{2}|$，由 $\Delta h = h_{23}-h_{12}=gT^{2}$ 求得 $T=\sqrt{\frac{\Delta h}{g}}$。若数据明显不满足整数格差，可用 $\Delta h = y_{3}-2y_{2}+y_{1}$ 直接计算。
4. **求水平初速度 $v_0$**  
   由水平位移 $\Delta x = |x_{2}-x_{1}| = v_0 T$，得 $v_0 = \frac{\Delta x}{T}$。
5. **求抛出点（可选）**  
   - 计算 $P_2$ 点的竖直分速度：$v_{2y} = \frac{h_{12}+h_{23}}{2T}$（中间时刻速度）。  
   - 小球从抛出到 $P_2$ 的时间 $t_2 = \frac{v_{2y}}{g}$。  
   - 抛出点坐标：$x_0 = x_2 - v_0 t_2$，$y_0 = y_2 - \frac{1}{2}g t_2^{2}$（注意坐标轴正负方向的规定）。
6. **涉及机械能损失时**  
   由下滑高度 $H$ 得理论速度 $v_{\text{理}}=\sqrt{2gH}$，实际初速 $v_0$，相对损失 $= \frac{E_1-E_2}{E_1} = \frac{v_{\text{理}}^2 - v_0^2}{v_{\text{理}}^2}\times 100\%$。

## 高频易错
- **坐标读数方向错误**  
  题目中 $y$ 轴可能向下为正，也可能向上为正。读数时务必先根据轨迹弯曲方向判定坐标系正方向，避免符号混乱。竖直位移须用绝对值相减。
- **未换算单位**  
  坐标纸的每小格边长 $0.10\,\text{m}$ 等，直接按格数乘长度，但常有学生忘记乘 $0.10$ 而直接保留格数代入公式，导致数量级错误。
- **将 $P_1$ 误作抛出点**  
  除非题中明确或通过位移比例 $1:3:5$ 验证，否则 $P_1$ 不是抛出点。直接用 $y_1=\frac{1}{2}gt^2$ 求时间会出错。必须用位移差 $\Delta y=gT^2$ 处理。
- **时间间隔 $T$ 的计算**  
  错误地用 $h_{12}= \frac{1}{2}gT^2$ 或 $h_{23} - h_{12} = gT^2$ 中的 $h$ 误取某一整段位移。务必明确 $\Delta h$ 是连续相等时间内的位移差（第二个位移减第一个位移）。
- **有效数字和根号保留**  
  题目要求“保留两位小数”或“可用根号表示”时务必遵行，如 $T=0.20\,\text{s}$ 不能写成 $0.2\,\text{s}$。

## 代表题精讲
### **题目**（2009·全国Ⅱ·10）
某同学做“研究平抛运动”实验，坐标纸每小格边长 $L=0.10\,\text{m}$，轨迹上三个点 $P_1、P_2、P_3$，$P_1$ 与 $P_2$、$P_2$ 与 $P_3$ 的水平距离相等。部分坐标纸如图，可读出格数。完成以下问题（结果保留两位小数或根号）：
(1) 读取 $|y_1-y_2|$、$|y_1-y_3|$、$|x_1-x_2|$；
(2) 求小球从 $P_1$ 到 $P_2$ 的时间和小球的水平速度；
(3) 已知小球下滑高度 $0.50\,\text{m}$，求下滑到抛出过程机械能的相对损失。

### **思路**
从坐标纸格数读取水平和竖直位移，利用水平位移相等得到等时性，由竖直位移差求时间间隔 $T$，进而求 $v_0$；第三问由理想平抛初速与实际初速比较求机械能损失。

### **步骤**
1. **读数**（设 $y$ 向下为正，$P_1$ 在最上方）  
   由格数得：$|y_1-y_2| = 6\times0.10 = 0.60\,\text{m}$；  
   $|y_1-y_3| = 16\times0.10 = 1.60\,\text{m}$；  
   则 $|y_2-y_3| = 1.60 - 0.60 = 1.00\,\text{m}$。  
   $|x_1-x_2| = 6\times0.10 = 0.60\,\text{m}$。
2. **求时间 $T$**  
   竖直方向连续相等时间内的位移差  
   $\Delta y = |y_2-y_3| - |y_1-y_2| = 1.00 - 0.60 = 0.40\,\text{m}$。  
   由 $\Delta y = gT^{2}$，取 $g=10\,\text{m/s}^{2}$，得 $T = \sqrt{0.40/10}=0.20\,\text{s}$。
3. **求水平速度 $v_0$**  
   $v_0 = \frac{|x_1-x_2|}{T} = \frac{0.60}{0.20} = 3.0\,\text{m/s}$。
4. **机械能损失**  
   下滑高度 $H=0.50\,\text{m}$，若机械能守恒，抛出速度 $v_{\text{理}} = \sqrt{2gH} = \sqrt{10}\,\text{m/s} \approx 3.16\,\text{m/s}$。  
   实际 $v_0 = 3.0\,\text{m/s}$，  
   相对损失 $= \frac{E_1-E_2}{E_1} = \frac{\frac12 m v_{\text{理}}^2 - \frac12 m v_0^2}{\frac12 m v_{\text{理}}^2} = 1 - \frac{3.0^2}{10} = 0.10 = 10\%$。

### **点评/变式**
- 本题核心是利用 **逐差法** 求时间间隔，不能将第一段竖直位移直接视作自由落体。
- 读数时若坐标纸原点不在抛出点，只须用相对距离，不影响 $T$ 和 $v_0$
