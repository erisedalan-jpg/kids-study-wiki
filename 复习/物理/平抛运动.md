## 知识精要
- **定义与条件**：物体以一定的初速度沿水平方向抛出，仅受重力作用的运动。  
- **基本规律**  
  水平方向：匀速直线运动，$x = v_0 t$。  
  竖直方向：自由落体运动，$v_y = gt$，$y = \frac{1}{2}gt^2$。  
- **合运动**  
  合速度 $v = \sqrt{v_0^2 + v_y^2}$，方向 $\tan \theta = \dfrac{v_y}{v_0}$。  
  合位移 $s = \sqrt{x^2 + y^2}$，方向 $\tan \alpha = \dfrac{y}{x}$。  
- **轨迹方程**：$y = \dfrac{g}{2v_0^2}x^2$（抛物线）。  
- **飞行时间**：由下落高度 $h$ 唯一决定，$t = \sqrt{\frac{2h}{g}}$，与水平初速度无关。  
- **速度偏向角与位移偏向角关系**：$\tan \theta = 2\tan \alpha$。  
- **能量特征**：只有重力做功，机械能守恒。$mgh + \frac12 mv_0^2 = \frac12 mv^2$。  
- **常见关联模型**  
  - 与弹簧结合：弹性势能转化为动能，随后物体平抛，注意分离时弹簧是否完全恢复原长。  
  - 与圆周运动结合：物体从圆轨道滑出后做平抛，关键为脱离点速度方向（若恰好到最高点，速度水平）。  
  - 与动量守恒结合：碰撞后物体获得初速度进入平抛，动量守恒求速度。  
- **临界夹角问题**：落地速度与水平面夹角 $\theta$ 满足 $\tan \theta = \dfrac{\sqrt{2gh}}{v_0}$。若要求 $\theta \le \theta_0$，则 $v_0 \ge \dfrac{\sqrt{2gh}}{\tan \theta_0}$。

## 解题方法与套路
1. **建立坐标系，分解运动**：以抛出点为原点，水平方向为 $x$ 轴，竖直向下为正方向。分别列出 $x = v_0t$、$y = \frac12 gt^2$、$v_y = gt$。  
2. **确定关键物理量**：若已知下落高度 $h$，先由 $t = \sqrt{2h/g}$ 求时间；已知水平位移 $x$ 即可求 $v_0$。  
3. **处理速度方向约束**：利用 $\tan \theta = v_y / v_0$，将角度条件转化为竖直分速度与水平分速度的关系，再结合高度求 $v_y$。  
4. **能量转化与守恒**：在同一平抛过程中，若已知初机械能或末动能，优先使用机械能守恒。结合弹簧、摩擦等因素时，用能量守恒或动能定理求初速度。  
5. **多过程衔接**：前一段运动（圆周、直线加速等）的末速度是平抛的初速度，分析衔接点速度大小和方向。  
6. **求位移或速度比**：分别对两个平抛过程写出水平位移表达式 $x = v_0\sqrt{2h/g}$，动能 $E_k \propto v_0^2$，建立比例求解。  
7. **解临界极值**：联系题干几何约束（如恰好越过坑、角度不超过某值），列出临界方程，解出最小初速度或最大射程。

## 高频易错
- **混淆两个角**：速度偏向角 $\theta$ 与位移偏向角 $\alpha$，错误使用 $\tan \theta = y/x$ 等。务必牢记 $\tan \theta = v_y/v_0$。  
- **平抛时间公式漏掉或错用**：时间 $t = \sqrt{2h/g}$，常见错误为 $t = h/v_0$ 或 $t = \sqrt{h/g}$。  
- **机械能守恒与动能定理混用**：平抛中重力势能减少量转化为动能增量，列式时注意初末状态。  
- **弹簧弹性势能分配不当**：轻弹簧恢复原长时，若两端连接物体，弹性势能转化为两个物体的动能之和，而非单个物体。  
- **斜抛与平抛混淆**：从圆轨道脱离后，若脱离点不是最高点，速度不水平，此后做斜抛运动，不能直接套用平抛公式。  
- **临界条件理解偏差**：“速度方向与水面的夹角不大于 $\theta$”是指速度与水平面夹角 $\le \theta$，而非与水面法线或其他。  
- **坑或台阶的高度差方向**：注意抛出点与落点的高度关系，$y$ 是竖直下落高度，若落点高于抛出点则不能单纯用自由落体公式。

### 1. 2024-辽宁-12（弹簧关联，平抛与动能定理）
**题目**：桌面高 $h=0.8\text{m}$，物块 A、B 质量均为 $0.1\text{kg}$，中间夹一压缩量 $\Delta x=0.1\text{m}$ 的轻弹簧。释放后 A 水平飞出，射程 $x_A=0.4\text{m}$；B 滑行 $x_B=0.25\text{m}$ 停止。求脱离弹簧时 $v_A$、$v_B$；动摩擦因数 $\mu$；弹簧释放的弹性势能 $E_p$。  

**思路**：A 做平抛运动，由高度和射程反求初速度；B 在桌面上匀减速，用动能定理关联 $\mu$；弹性势能等于 A、B 脱离时的总动能。  

**步骤**：  
- 对 A 平抛：下落高度 $h$，$t = \sqrt{\frac{2h}{g}} = \sqrt{\frac{1.6}{10}} = 0.4\text{s}$。水平射程 $x_A = v_A t$，则 $v_A = 0.4/0.4 = 1\text{m/s}$。  
- 弹簧与 A、B 不栓接，脱离时二者速度大小相等？题目未明，但系统动量守恒可证 $v_A=v_B=1\text{m/s}$。对 B：动能定理 $-\mu m g x_B = 0 - \frac12 m v_B^2$，代入得 $\mu = \frac{v_B^2}{2g x_B} = \frac{1}{2\times 10\times 0.25} = 0.2$。  
- 弹簧释放的弹性势能 $E_p = \frac12 m v_A^2 + \frac12 m v_B^2 = 2\times\frac12\times0.1\times1^2 = 0.12\text{J}$。  

**点评/变式**：此题型将平抛与能量、摩擦力等直线运动结合。注意弹簧连接问题时，弹性势能转化为系统动能，若两物块质量不等需用动量守恒分配速度。平抛部分求初速度是常规操作，但需警惕桌面高度与平抛下落高度的关系。

### 2. 2023-新课标-11（“打水漂”临界夹角）
**题目**：要使石子接触水面时速度方向与水面的夹角不大于 $\theta$，从高度 $h$ 处水平抛出，求抛出速度的最小值。  

**思路**：石子平抛，触水面瞬间竖直分速度由高度决定；由夹角限制确定水平分速度的下限。  

**步骤**：  
- 设抛出初速度 $v_0$，触水时竖直分速度 $v_y = \sqrt{2gh}$。  
- 速度与水面夹角 $\alpha$ 满足 $\tan \alpha = \dfrac{v_y}{v_0} \le \tan \theta$。  
- 因此 $v_0 \ge \dfrac{v_y}{\tan\theta} = \dfrac{\sqrt{2gh}}{\tan\theta}$，最小值为 $\dfrac{\sqrt{2gh}}{\tan\theta}$。  

**点评/变式**：本题陷阱在于“速度方向与水面夹角”即速度与水平方向夹角，很多学生误认为是与竖直方向夹角。极值条件转换为正切不等式即可。变式可改为速度方向与水面夹角等于某值求射程，或给定初速度求撞击角度。
