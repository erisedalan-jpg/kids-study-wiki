## 知识精要
- **开普勒第三定律**：所有绕同一中心天体运行的行星，其轨道半长轴 $a$ 的立方与公转周期 $T$ 的平方之比为一个常量，即  
  $$\frac{a^3}{T^2} = k$$  
  其中 $k$ 只与中心天体的质量有关，对绕同一中心天体运行的天体均相同。
- **圆轨道近似**：在中学物理中，行星轨道常视为圆轨道，轨道半径 $r$ 等于半长轴。由万有引力提供向心力可得  
  $$\frac{GMm}{r^2} = m\frac{4\pi^2}{T^2}r \quad\Rightarrow\quad \frac{r^3}{T^2} = \frac{GM}{4\pi^2}$$  
  即 $r^3 \propto T^2$ 或 $T \propto r^{3/2}$。
- **对数形式**：对 $r^3/T^2 = k$ (或 $T^2 \propto r^3$) 两边取对数：  
  $$3\lg r - 2\lg T = \text{常量} \quad\text{或}\quad 2\lg T = 3\lg r + \text{常量}$$  
  变形可得 $\lg T = \frac{3}{2}\lg r + \text{常量}$ 或 $\lg r = \frac{2}{3}\lg T + \text{常量}$，在对数坐标系中是一条直线，斜率反映幂指数关系。
- **适用条件**：必须针对同一中心天体的不同环绕星体；若中心天体不同，$k$ 值不同，不可直接套用。

## 解题方法与套路
1. **明确对象与中心天体**：判断题目中涉及的星体是否绕同一中心天体运行，确认适用开普勒第三定律。
2. **写出比例关系**：用 $r^3/T^2 = k$ 或 $T^2 \propto r^3$ 表达规律；若涉及图像，确定横、纵坐标的物理量。
3. **线性化处理**：若题目给出对数坐标或非正比图像，对两边取对数转化为线性关系：  
   若 $y^m = C x^n$，则 $\lg y = \frac{n}{m}\lg x + \frac{\lg C}{m}$，利用斜率 $\frac{n}{m}$ 和截距判断。
4. **分析斜率与截距的物理意义**：在 $\lg T \sim \lg r$ 图中，斜率为 $3/2$；在 $\lg r \sim \lg T$ 图中，斜率为 $2/3$。截距与中心天体质量和标准化常数有关。
5. **结合图象特征作答**：比照选项中直线的斜率、位置是否符合推导出的表达式，排除干扰项。

## 高频易错
- **对数坐标斜率混淆**：常见 $\lg T$ 为横轴、$\lg r$ 为纵轴时斜率应为 $2/3$，若误记为 $3/2$ 会选错。  
  推导方法：由 $T^2 \propto r^3$ 得 $r \propto T^{2/3}$，取对数 $\lg r = \frac{2}{3}\lg T + \text{常量}$。
- **忽略对数底数**：物理中 $\lg$ 常用以10为底，但只要横纵坐标统一取相同底数，斜率关系不变。
- **标准化变量理解偏差**：题目常引入 $T_0$、$r_0$ 作归一化，如 $T/T_0$ 和 $r/r_0$，此时仍有 $(r/r_0)^3 / (T/T_0)^2 = 1$，对数图像斜率依然为 $2/3$（纵轴 $\lg(r/r_0)$，横轴 $\lg(T/T_0)$）。
- **错用比例常数**：$k=GM/(4\pi^2)$ 只对同一中心天体成立。若中心天体改变（如比较地球绕日和月球绕地），不能直接由开普勒第三定律得出比例。
- **把椭圆半长轴与圆周半径等同混淆**：圆轨道时半径就是半长轴，但若题目明显给出椭圆轨道，需严格使用半长轴 $a$ 代替 $r$。

## 代表题精讲
### **题目**（2010·新课标Ⅰ·07）  
太阳系中的8大行星的轨道均可近似看成圆轨道。下列4幅图是用来描述这些行星运动所遵从的某一规律的图像。图中坐标系的横轴是 $\lg(T/T_0)$，纵轴是 $\lg(R/R_0)$，$T$ 和 $R$ 分别是行星绕太阳运行的周期和圆轨道半径，$T_0$ 和 $R_0$ 分别是水星绕太阳运行的周期和半径。选出正确的图像。

**思路**：所有行星绕同一太阳运行，满足开普勒第三定律 $R^3/T^2 = \text{常量}$。设水星常量相同，有 $R^3/T^2 = R_0^3/T_0^2$，变形为 $(R/R_0)^3 = (T/T_0)^2$。对两边取常用对数得 $3\lg(R/R_0) = 2\lg(T/T_0)$，即 $\lg(R/R_0) = \frac{2}{3}\lg(T/T_0)$。因此图像为过原点的直线，斜率 $k=\frac{2}{3}$。只需在四幅图中找出匹配这一特征的直线即可。

**步骤**：
1. 建立规律：由 $\frac{R^3}{T^2} = \frac{R_0^3}{T_0^2} \Rightarrow \left(\frac{R}{R_0}\right)^3 = \left(\frac{T}{T_0}\right)^2$。
2. 取对数：$\lg\left(\frac{R}{R_0}\right)^3 = \lg\left(\frac{T}{T_0}\right)^2 \Rightarrow 3\lg\frac{R}{R_0} = 2\lg\frac{T}{T_0}$。
3. 整理为纵轴关于横轴的函数：$\lg\frac{R}{R_0} = \frac{2}{3}\lg\frac{T}{T_0}$。
4. 分析图像特征：该关系表示一条通过原点、斜率为 $\frac{2}{3}$ 的直线。
5. 对照选项：选择斜率为正、值为 $\frac{2}{3}$ 且过原点的直线对应的图。

**点评/变式**：本题将开普勒第三定律与对数图像结合，核心是认清 $R^3/T^2$ 为常数的比值形式，并正确进行对数运算。常见变式有：
- 横纵坐标互换时（$\lg R$ 为横轴、$\lg T$ 为纵轴），斜率变为 $3/2$。
- 从万有引力定律出发给出不同中心天体的 $k$ 值，比较截距大小。
- 推广到椭圆轨道：只要使用半长轴 $a$ 与周期 $T$，对数图像斜率不变。
