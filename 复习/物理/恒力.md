## 知识精要
- **恒力**：大小和方向均保持不变的力。质点受到恒力作用时，产生的加速度恒定（$a=F/m$），物体做匀变速运动，轨迹可以是直线（$v_0$与$F$共线）或曲线（$v_0$与$F$不共线，如类平抛）。
- **初始条件**：质点从匀速直线运动状态开始受恒力，说明此前合力为零；该恒力即为质点此后所受的合力。
- **动能变化与合力做功**：动能定理 $W_合 = \Delta E_k$，恒力做功的正负和大小直接决定动能增减。
- **恒力方向与初速度方向的关系决定动能变化情况**：
  - **同向（夹角$0^\circ$）**：恒力做正功，物体做匀加速直线运动，动能一直增大。
  - **反向（夹角$180^\circ$）**：恒力先做负功后做正功，物体先匀减速到零再反向匀加速，动能先减小至零再增大。
  - **成锐角（$0^\circ<\theta<90^\circ$）**：恒力与初速度不共线，物体做曲线运动。将速度分解到沿力方向和垂直力方向，沿力方向分速度增加，垂直力方向分速度不变，合速度一直增大，动能一直增大。
  - **成钝角（$90^\circ<\theta<180^\circ$）**：物体做曲线运动。沿力方向分速度先减小至零再反向增大，垂直力方向分速度不变，合速度先减小后增大。当沿力方向分速度减为零时，合速度等于垂直方向分速度（不为零），动能达到一个非零的最小值，而后再增大。

## 解题方法与套路
分析恒力作用下物体动能变化的通用步骤：
1. **明确恒力即为合力**，找出恒力方向与初速度方向的夹角$\theta$。
2. **按夹角分类讨论**：
   - 若 $\theta = 0^\circ$：恒力一直做正功 $\Rightarrow$ 动能一直增大。
   - 若 $\theta = 180^\circ$：恒力先做负功后做正功 $\Rightarrow$ 动能先减至零再增大。
   - 若 $0^\circ < \theta < 90^\circ$：将速度沿力方向和垂直力方向分解，沿力方向分速度增大，垂直方向分速度不变 $\Rightarrow$ 合速度一直增大，动能一直增大。
   - 若 $90^\circ < \theta < 180^\circ$：沿力方向分速度先减至零再反向增大，垂直方向分速度不变 $\Rightarrow$ 合速度先减后增，动能先减至某一非零最小值再增大。
3. **快速判断技巧**：恒力方向若与初速度方向成钝角，则动能一定出现先减小后增大的过程，且最小值一定大于零（因为垂直方向的分速度始终存在）。

## 高频易错
- **混淆锐角与钝角的影响**：误以为只要恒力与速度方向不共线，动能就会先减小后增大。实际上，锐角情况下动能一直增大，只有钝角时才会出现先减小。
- **认为速度可以减到零**：物体在恒力作用下做曲线运动（成钝角）时，垂直于恒力方向的分速度始终不变且不为零，因此合速度绝不会减到零，动能的最小值也不为零。只有直线减速运动（反向）速度才会减到零。
- **错误类比“先增大后减小”选项**：恒力方向固定，合力做功不可能出现“先正后负”的自动反转（除非力本身方向变化），所以不可能出现动能先增大到某一最大值再减小的情形（对应C选项错误）。
- **受力分析不到位**：没有意识到质点“从匀速直线运动”开始受恒力，意味着该恒力就是唯一的合力，不需要再考虑其他力（如摩擦力、重力等）。

## 代表题精讲
**题目**  
质点开始时做匀速直线运动，从某时刻起受到一恒力作用。此后，该质点的动能可能（　　）  
A．一直增大  
B．先逐渐减小至零，再逐渐增大  
C．先逐渐增大至某一最大值，再逐渐减小  
D．先逐渐减小至某一非零的最小值，再逐渐增大  

**思路**  
恒力即为合力，质点做匀变速运动。根据恒力方向与初速度方向的夹角，分同向、反向、成锐角、成钝角四种情况，用速度分解法或动能定理判断动能变化。

**步骤**  
1. 设初速度为$v_0$，恒力为$F$，二者夹角为$\theta$。  
2. 若 $\theta = 0^\circ$（同向）：$F$做正功，$v$一直增大 $\Rightarrow E_k$ 一直增大，A正确。  
3. 若 $\theta = 180^\circ$（反向）：物体匀减速至零后反向匀加速，$v$先减到零再增大 $\Rightarrow E_k$ 先减至零再增大，B正确。  
4. 若 $0^\circ < \theta < 90^\circ$：将$v_0$分解为$v_\parallel = v_0 \cos\theta$（沿力方向）和$v_\perp = v_0 \sin\theta$（垂直力方向）。$v_\perp$不变，$v_\parallel$一直增大，合速度$v = \sqrt{v_\parallel^2 + v_\perp^2}$一直增大，动能一直增大。  
5. 若 $90^\circ < \theta < 180^\circ$：此时$\cos\theta < 0$，$v_\parallel$先减至零再反向增大，$v_\perp$不变。合速度先减小后增大，最小值出现在$v_\parallel = 0$时，$v_{\min} = v_\perp > 0$，所以动能先减至一个非零最小值再增大，D正确。C所述的“先增大后减小”在任何夹角下均不可能发生。  
6. 综上，选项A、B、D正确。

**点评/变式**  
本题是运用运动合成与分解处理恒力曲线运动的经典题目。核心要点是“垂直恒力方向的分速度不变”，由此确定合速度的极小值必大于零。变式可考查：若恒力是重力，物体从水平面斜向上抛出，其动能变化是否符合D项描述？答案为符合（斜上抛物体达最高点时速度水平分量不为零，动能最小但不为零）。还可联系“合力做功等于动能变化”这一功能关系进行多角度验证，强化对恒力作用下运动规律的整体把握。
