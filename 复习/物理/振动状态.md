## 知识精要
- **振动状态**：指质点在振动中的位移 $y$、速度 $v_y$（方向）和加速度等。在机械波中，质点的振动状态由其所在波形中的位置决定。
- **波传播与振动方向的关系**（横波）：
  - 沿波传播方向看，“上坡”（位移随 $x$ 增大而增大）的质点向下振动；“下坡”（位移随 $x$ 增大而减小）的质点向上振动。
  - 或利用同侧法：质点的振动方向与波的传播方向在波形的同侧。
- **波动方程**（简谐横波，沿 $x$ 正传）：$y = A\sin(\omega t - kx + \phi_0)$，其中 $k = \frac{2\pi}{\lambda}$。
  - $t=0$ 时，$y = A\sin(-kx + \phi_0)$。根据质点的 $y$ 和 $v_y$ 方向可定初相 $\phi_0$。
- **空间周期性**：波形每隔 $\lambda$ 重复。已知两质点的振动状态与平衡位置间距 $\Delta x$，可列关系式 $\Delta x = \Delta x_0 + n\lambda$ 或 $\Delta x = \left(n + \frac{1}{4}\right)\lambda$ 等，$n$ 取整数，从而得到多解。

## 解题方法与套路
1. **定波形零点**：根据某质点的振动方向与波传播方向，确定它在波形中的位置（上坡零点/下坡零点、波峰/波谷等）。
2. **画示意图**：面向 $x$ 正方向画出符合该质点状态的最简波形（至少画出包含另一质点位置的一个周期）。
3. **找几何关系**：在图上标示两质点的平衡位置，结合波形对称性，得出间距 $\Delta x$ 与波长 $\lambda$ 的等式，并补入周期性项 $n\lambda$（$n=0,1,2,\ldots$）。
4. **列式求解**：由 $k\Delta x = \Delta \varphi$ 或直接由间距关系得出 $\lambda$ 通式，代入选项逐一验证。

## 高频易错
- **振动方向与波形斜率不匹配**：$x=0$ 处 $y=0$ 且向下运动，易错判为下坡零点，导致关系变成 $\Delta x = \frac{3}{4}\lambda + n\lambda$ 而错选B、D。
- **忽视多解性**：只取 $n=0$ 的最小波长解，漏掉 $n=1,2,\ldots$ 对应的其他可能波长（如 $0.12\,\text{m}$）。
- **初相代入失误**：由 $y=0$ 且 $v_y<0$ 设 $\phi_0=0$，得到向上振动，导致后续全错；正确应为 $\phi_0 = \pi$（或 $y=A\sin kx$ 形式的 $t=0$ 波形）。
- **直接将间距等同于相位差**：忘记波沿正向传播时，相位沿 $x$ 减小，$\Delta \varphi = -k\Delta x + \phi_0$，符号易错。
