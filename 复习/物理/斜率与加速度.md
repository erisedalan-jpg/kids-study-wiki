## 知识精要
- **$v-t$ 图象的物理意义**  
  - 纵坐标：瞬时速度 $v$（正负表示方向，在竖直方向问题中常以向下为正）  
  - 斜率 $k = \frac{\Delta v}{\Delta t}$：**加速度** $a$，斜率恒定则加速度恒定，斜率变化则加速度变化  
  - 图线与 $t$ 轴围成的面积：**位移**大小（仅大小，无方向积分时为路程的引申）  
  - 纵截距：初速度 $v_0$  
- **牛顿第二定律的矢量性**  
  $F_{\text{合}} = ma$，在竖直方向：$mg - f = ma$ 或 $mg + f = ma$（视正方向及阻力方向而定）  
  可得阻力 $f = m(g - a)$ 或 $f = m(a - g)$，由此判断阻力随加速度的变化  
- **平均加速度与瞬时加速度**  
  - 平均加速度 $\bar{a} = \frac{\Delta v}{\Delta t}$，对应割线斜率  
  - 瞬时加速度 $a = \frac{dv}{dt}$，对应切线斜率  
- **运动时间与位移的关系**  
  在抛体类问题中，落地时刻的纵坐标对应雪道几何约束；运动时间越长，往往水平位移也越大（需结合姿态对水平速度的影响）

## 解题方法与套路
1. **明确定义，看轴识理**  
   看清横轴（$t$）、纵轴（$v$）及其单位，确认正方向。曲线上的点、斜率、面积各对应什么物理量。  
2. **斜率比较定加速度**  
   同一横坐标（同一时刻）看切线倾斜程度；不同曲线同一纵坐标（相同速度）看各自切线斜率；全程平均加速度看始末点连线的斜率。  
3. **面积比较定位移**  
   图线与 $t$ 轴围成的面积表示位移的大小，可直接比较同一时间内的位移或全程总位移，得出竖直方向位移的大小关系。  
4. **受力分析搭桥**  
   由加速度 $a$ 结合牛顿第二定律列式，将运动学信息转化为力（如阻力）的比较。注意阻力方向：若加速度 $a < g$，则阻力向上，大小为 $f = m(g-a)$。  
5. **多维推断（水平方向）**  
   竖直信息可间接推断水平情况：落地时间越长，在保持或增大水平速度的情况下，水平位移越大（需结合题设“姿态影响速度与距离”）。  
6. **多过程或多曲线对比**  
   先分别独立分析每条图线对应的过程，再逐一对比位移、加速度、受力等，注意选项往往要求选出“一定”或“可能”的结论。

## 高频易错
- **错把斜率当速度**：斜率是加速度，切线陡峭程度表示速度变化快慢，不是速度大小  
- **面积理解有误**：$v-t$ 图象面积是位移，不是路程；若速度有正有负，面积代数和才是位移  
- **忽略正方向设定**：竖直速度图象中，建立正方向后，加速度方向通过斜率的正负判断，不要想当然认为 $a=g$  
- **阻力方向判断草率**：当 $a<g$ 时，阻力方向与重力方向相反；当 $a>g$ 时，阻力方向与重力方向相同，需根据具体加速度值判断，切忌直接套用 $a=g$  
- **平均加速度与瞬时加速度混淆**：比较“过程中的平均阻力”需用全程平均加速度，比较“某速度时的阻力”需用该点切线斜率对应的瞬时加速度  
- **漏用题设递进信息**：例如“姿态影响下落速度和滑翔距离”暗示水平方向可能有差异，要结合已得出的竖直结论综合推理水平位移关系

## 代表题精讲
**题目**（2019·新课标Ⅱ卷·19）  
跳台滑雪中，运动员从同一跳台起跳，两次不同姿态下的竖直方向速度 $v-t$ 图象如图（b）所示，$t_1$、$t_2$ 分别对应两次落在倾斜雪道上的时刻。据此判断关于两次滑翔的正确说法。

**思路**  
从 $v-t$ 图象切入：先比较两次竖直位移（面积）、竖直加速度（斜率），再利用牛顿第二定律将加速度差异转化为阻力差异，最后结合落地时间推断水平位移。

**步骤**  
1. **比较竖直位移**：图线下方至 $t$ 轴面积，第二次（$0\sim t_2$）明显大于第一次（$0\sim t_1$），故第二次竖直位移更大。  
2. **比较加速度**：任意相同时刻，实线（第一次）切线的斜率绝对值大于虚线（第二次），说明第一次竖直加速度 $a_1$ 的绝对值大于第二次 $a_2$（或斜率更陡）；全程平均加速度也是第一次更大。  
3. **借助牛顿第二定律比阻力**：取向下为正，$mg - f = ma \Rightarrow f = m(g-a)$。因 $a_2 < a_1$，故 $f_2 > f_1$，即第二次在竖直方向上所受平均阻力更大；某速度 $v_1$ 时，由切线斜率知 $a_{v_1,2} < a_{v_1,1}$，则 $f_{v_1,2} > f_{v_1,1}$。  
4. **推断水平位移**：第二次落地时刻 $t_2 > t_1$，运动时间更长，且姿态调整利于滑翔距离，因此第二次水平位移更大。

**点评/变式**  
- 本题典型地将图象斜率、面积与牛顿运动定律、多过程对比相结合，是“斜率→加速度→力”链条的经典考查。  
- 变式方向：将纵轴改为 $v_x$ 或 $v_y$ 单独分析，或给出 $a-t$ 图象反推 $v-t$；也可结合动量和动能定理，进一步考查某段时间内的冲量、做功比较。解题核心不变——**图象特征 $\to$ 运动参量 $\to$ 受力分析**。
