## 知识精要
- **波的周期与频率**：介质中各质点的振动都是受迫振动，振动周期 $T$ 和频率 $f$ 必然等于波源的周期与频率。波在不同介质中传播时，周期/频率保持不变。
- **波速公式**：$v = \frac{\lambda}{T} = \lambda f$。波速 $v$ 由介质的性质决定，与质点的振动速度无关。
- **波的传播方向与质点振动方向的关系**：
    - **横波**：质点振动方向垂直于波的传播方向。利用“同侧法”、“上下坡法”或“微平移法”可由传播方向判振动方向，反之亦然。
    - **纵波**：质点振动方向与波的传播方向在同一直线上。
- **振动图象与波动图象的关联**：
    - **振动图线（$y-t$）**：描述单个质点在不同时刻的位移，直接反映周期 $T$、振幅 $A$ 及质点在某一时刻的运动趋势。
    - **波动图线（$y-x$）**：描述不同质点在相同时刻的位移，直接反映波长 $\lambda$、振幅 $A$ 及波的传播方向。
    - **互推关键**：必须依据波形图、传播方向和某质点的振动图象（或某时刻的振动状态），先确定该质点在波形图上的位置和该时刻的振动方向。
- **波源起振方向**：介质中所有质点的起振方向均与波源的起振方向相同。
- **振动的初相位**：求解简谐振动表达式 $y = A\sin(\omega t + \varphi_0)$ 的关键。常利用 $t=0$ 时刻质点的位移和接下来运动方向（速度正负）来确定 $\varphi_0$。
- **波峰与波谷的距离**：在横波的传播方向上，相邻波峰与波谷的平衡位置距离是 $\frac{\lambda}{2}$；在振动方向上，波峰到波谷的距离等于 $2A$。

## 解题方法与套路
1.  **确定周期 $T$**：
    -   优先从振动图象直接读周期。
    -   若给定时间间隔 $\Delta t$ 内质点完成了若干次特殊状态（如“回到平衡位置”、“到达波峰”）的变化，则分析 $\Delta t$ 与 $T$ 的关系：$\Delta t = nT + \frac{1}{4}T$ 或 $\frac{3}{4}T$ 等。
    -   注意区分是“第一次”还是“第n次”到达某位置。
2.  **求解波长 $\lambda$ 与波速 $v$**：
    -   利用公式 $v = \frac{\lambda}{T}$。
    -   若给定两质点间距 $\Delta x$ 及二者振动状态的特定关系（同相、反相、一个在波峰一个在平衡位置等），结合波长限制条件（如“波长不小于…”、“距离介于n倍波长之间”），建立方程 $\Delta x = n\lambda + x_0$ 求解 $\lambda$。
    -   也可先通过波传播的距离 $\Delta x$ 与时间 $\Delta t$ 求波速：$v = \frac{\Delta x}{\Delta t}$。
3.  **写出振动方程 $y = A\sin(\omega t + \varphi_0)$**：
    -   振幅 $A$ 由题给或图象读取。
    -   角频率 $\omega = \frac{2\pi}{T}$。
    -   **求初相 $\varphi_0$**：代入 $t=0$ 时的位移 $y_0$，得到 $\sin\varphi_0 = \frac{y_0}{A}$，再结合 $t=0$ 时刻质点的振动方向（速度正负），确定 $\varphi_0$ 的象限和具体值。常用舍去不符合运动趋势的解。
4.  **计算质点的路程**：
    -   **时间与周期的整数倍**：若 $\Delta t = nT + \frac{1}{2}T$，则路程 $s = 4nA + 2A$（无论从哪开始，半个周期必走 $2A$）。
    -   **从特殊位置开始**：若从平衡位置或最大位移处开始，历时 $\Delta t = nT + \frac{1}{4}T$，则路程 $s = 4nA + A$。
    -   **一般情况**：需具体分析始末位置及振动方向，不能简单使用 $4A$ 的倍数。

## 高频易错
-   **混淆质点振动速度与波的传播速度**：波在同一均匀介质中匀速传播；质点在平衡位置附近做变速简谐振动，两者毫无直接数值关系。
-   **误判纵波的“一致”**：纵波中，介质质点的振动方向与波的传播方向在同一直线上，但同一时刻，各质点的振动方向可能与传播方向相同也可能相反，不能说“一定一致”。
-   **振动方向判断失误**：从“$y-t$”图象看质点的运动趋势，要看下一时刻位移的变化；从“$y-x$”图象判断，则必须结合波的传播方向。孤立看图，极易反向。
-   **波的多解性问题**：由质点间距或时间间隔求波长或周期时，若不根据题目隐含的约束条件（如“距离不足一个波长”、“第一次到达”、“波长大于某值”）舍去多余解，会导致错误。
-   **初相位求解错误**：仅用 $y_0$ 定 $\varphi_0$ 会出现两个可能值，必须结合速度方向（$y-t$ 图 $t=0$ 处的斜率正负）才能唯一确定。忘记验证速度方向是高频失分点。
-   **质点路程计算陷阱**：直接使用 $s = \frac{\Delta t}{T} \times 4A$ 是严重的概念错误，只有从平衡位置或最大位移处开始计时，历时 $\frac{T}{4}$ 的整数倍时才成立。一般情况需画振动过程草图辅助计算。

## 代表题精讲
### 代表题一：2016-新课标Ⅱ-16
-   **题目**：简谐横波沿x轴正向传播，波长 $\lambda \ge 10\text{cm}$，$x_O=0$，$x_A=5\text{cm}$。$t=0$时，$y_O=4\text{cm}$，质点A在波峰；$t=\frac{1}{3}\text{s}$时，O第一次回平衡位置；$t=1\text{s}$时，A第一次回平衡位置。求周期、波速、波长及O点振动方程。
-   **思路**：
    1.  利用质点A由波峰首次回平衡位置的时间求周期。
    2.  判断 $t=0$ 时O点的振动方向，结合O、A两点的位移和位置关系，在波长限制下求出波长。
    3.  由周期和波长求波速。
    4.  根据振幅、周期及 $t=0$ 时O点的位移和振动方向，确定O点的振动方程。
-   **步骤**：
    1.  **求周期 $T$**：质点A在 $t=0$ 时处于波峰，$t=1\text{s}$ 时第一次回到平衡位置，历时为 $\frac{T}{4}$。有 $\frac{T}{4}=1\text{s}$，得 $T=4\text{s}$。
    2.  **求波长 $\lambda$ 和波速 $v$**：
        -   由O点状态：$t=0$ 时，$y_O=4\text{cm}$（最大位移为波峰或波谷？待定）。$t=\frac{1}{3}\text{s}$ 时首次回平衡位置，推知 $t=0$ 时O点正向平衡位置运动。因O点此时位移为正，故其振动方向向下（沿y轴负向）。可判O点不在波峰。
        -   已知 $t=0$ 时A点 ($x=5\text{cm}$) 在波峰。波沿x轴正向传播，经时间 $\Delta t$，A点的状态（波峰）可看作在更早时间 $\Delta t$ 前由左侧某点传来。O点比A点振动的相位要落后。因此，$t=0$ 时的波峰应位于O点左侧。
        -   设定波形：O点位移为 $y=4\text{cm}$ 且向下运动，O点右侧 $\Delta x = 5\text{cm}$ 的A点为波峰。在波的图象上，满足此关系的两质点距离可能是 $\frac{\lambda}{4}$ 或 $\frac{3\lambda}{4}$ 等。
        -   由 $\Delta x = n\lambda + \frac{\lambda}{4}$ 或 $n\lambda + \frac{3\lambda}{4}$ 等分析。常见情况，平衡位置在O、A间的质点要从O沿正向移动 $\frac{\lambda}{4}$ 才能到平衡位置再向上至波峰。设 $\Delta x = 5\text{cm} = n\lambda + x_0$。结合O向下运动，A为波峰，可判断 $x_0 = \frac{\lambda}{4}$ 不合理，应为 $\frac{3\lambda}{4}$ 或 $\frac{\lambda}{2}$ 加偏移。正确推导：O向下振动，经一段时间到平衡位置，说明O在波峰与平衡位置之间。A是波峰。满足条件的最近距离是A为波峰，O在波峰右侧且向下运动，波形显示O在A右侧 $\frac{1}{4}\lambda$ 处。或者，O在A左侧更远处。结合 $\lambda \ge 10\text{cm}$，$\Delta x = 5\text{cm} < \lambda$。因此O、A间距离必定对应 $\frac{\lambda}{4}$。所以 $\frac{\lambda}{4} = 5\text{cm}$，$\lambda = 20\text{cm}$。波速 $v = \frac{\lambda}{T} = \frac{0.2}{4} = 0.05\text{m/s}$。
    3.  **求振动方程 $y_O(t)$**：
        -   设 $y = A\sin(\omega t + \varphi_0)$。由题意，质点振动在位移等于4cm时为特殊位置，O点 $t=0$ 时 $y_O=4\text{cm}$ 且向下运动。若O点振幅是4cm，则此时在正向最大位移处，速度应为0，与“向下运动”矛盾。故振幅 $A > 4\text{cm}$。仔细观察：“质点O的位移为y=4cm，质点A处于波峰位置”，未给出振幅。由A在波峰，O在平衡位置之上并向下运动，可推断波形在O、A间。设波峰位移为 $A$，则A点位移为 $A$。O在波峰的左侧，$\frac{\lambda}{4}$对应相位差 $\frac{\pi}{2}$。解出 $A=8\text{cm}$。
        -   角频率 $\omega = \frac{2\pi}{T} = \frac{\pi}{2} \text{rad/s}$。
        -   $t=0$ 时，$y_O = 4\text{cm}$ 且向下运动。由 $y = A\sin(\varphi_0)$，有 $4 = 8\sin(\varphi_0)$，得 $\varphi_0 = \frac{\pi}{6}$ 或 $\frac{5\pi}{6}$。因为速度向下（$v<0$），所以 $\cos\varphi_0 < 0$，取 $\varphi_0 = \frac{5\pi}{6}$。
        -   质元O振动方程为 $y=8\sin(\frac{\pi}{2}t + \frac{5\pi}{6}) \text{cm}$。
-   **点评/变式**：本题难点在于由两点状态及时间信息，推出完整的波形，尤其是振幅的确定容易被忽略。波的多解性被题设条件“波长不小于10cm”唯一确定。求振动方程时，须严格检验速度方向以固定初相。

### 代表题二：2015-新课标Ⅱ-16
-   **题目**：波源在原点，$P$ 点距 $O$ 为 $35\text{cm}$（介于一倍与二倍波长间）。$t=0$ 时波源从平衡位置向上起振，$T=1\text{s}$，$A=5\text{cm}$。波传到 $P$ 时，波源恰在波峰；再经 $5\text{s}$，$Q$ 点首次到波峰。求 $PQ$ 距离和波源在指定时间内通过的路程。
-   **思路**：
    1.  由 $OP$ 的距离和所处波长倍数范围，结合此时波源的状态，确定波长 $\lambda$。
    2.  确定波速 $v$。由波传播时间求 $P$ 点起振时刻。
    3.  分析“再经 $5\text{s}$，$Q$ 首次到波峰”，建立时间关系求得 $Q$ 点起振时刻或其位置，从而得到 $PQ$ 间距。
    4.  计算波源的路程，需准确找出起止时间，并由其初始位置确定路程算法。
-   **步骤**：
    1.  **求波长 $\lambda$**：$OP=35\text{cm}$。波从 $O$ 传到 $P$ 的时间 $t_{OP}$，此段时间波源振动了 $t_{OP}$。波源 $t=0$ 时在平衡位置向上，在 $t_{OP}$ 时在波峰，故 $t_{OP} = nT + \frac{1}{4}T$。传播距离 $OP = v t_{OP} = n\lambda + \frac{\lambda}{4}$。已知 $OP$ 在 $\lambda$ 与 $2\lambda$ 之间，故 $n=1$。有 $\lambda + \frac{\lambda}{4} = 35\text{cm}$，得 $\lambda = 28\text{cm} = 0.28\text{m}$。波速 $v = \frac{\lambda}{T} = 0.28\text{m/s}$。
    2.  **分析Q点**：波到达P点后，再经 $5\text{s}$，平衡位置在 $Q$ 的质点首次到达波峰。这 $5\text{s}$ 包含两部分：波从P传到Q的时间 $t_{PQ}$，和Q点起振后首次到波峰的时间 $\frac{T}{4} = 0.25\text{s}$。所以 $t_{PQ} + 0.25 = 5\text{s}$，得 $t_{PQ} = 4.75\text{s}$。
    3.  **求PQ距离**：$PQ = v \cdot t_{PQ} = 0.28 \times 4.75 = 1.33\text{m} = 133\text{cm}$。
    4.  **求波源路程**：波源振动时间从 $t=0$ 到 Q首次到波峰的时刻 $t_{总}$。$t_{总} = t_{OP} + 5\text{s}$。$t_{OP} = \frac{OP}{v} = \frac{0.35}{0.28} = 1.25\text{s} = 1\frac{1}{4}T$。$t_{总}= 1.25 + 5 = 6.25\text{s} = 6\frac{1}{4}T$。
        波源自平衡位置起振，其路程 $s = (6 \times 4A) + A = 25A$。$A=5\text{cm}$，故 $s = 25 \times 5 = 125\text{cm}$。
-   **点评/变式**：明确“波源起振方向”是介质中所有质点起振方向的标杆。“首次到达波峰”的 $\frac{T}{4}$ 计时法仅对从平衡
