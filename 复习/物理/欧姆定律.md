## 知识精要
- **欧姆定律**：纯电阻电路中，导体电流 $I$ 与两端电压 $U$ 成正比，与电阻 $R$ 成反比，即 $I = \frac{U}{R}$。变体：$U = IR$、$R = \frac{U}{I}$。适用于金属导体、电解液，**不适用于**气体导电、半导体器件等非线性元件。
- **电阻定律**：$R = \rho \frac{l}{S}$，电阻由材料（电阻率 $\rho$）、长度 $l$、横截面积 $S$ 决定。
- **串并联核心规律**：串联 $I$ 处处相等，$U$ 分压，$R_{\text{总}}=R_1+R_2$；并联 $U$ 处处相等，$I$ 分流，$\frac{1}{R_{\text{总}}}=\frac{1}{R_1}+\frac{1}{R_2}$。
- **电表改装**：
  - **改装电流表**：微安表 $G$（量程 $I_g$，内阻 $R_g$）并联小电阻 $R$ 分流。$R = \frac{I_g R_g}{I - I_g}$。
  - **改装电压表**：微安表 $G$ 串联大电阻 $R$ 分压。$R = \frac{U}{I_g} - R_g$。
- **闭合电路欧姆定律**：$I = \frac{E}{R + r}$ （$E$ 电源电动势，$r$ 内阻，$R$ 外电路总电阻）。路端电压 $U = E - Ir$。
- **滑动变阻器接法**：
  - **限流式**：调节范围 $\frac{E}{R_x+R} \sim \frac{E}{R_x}$，简单但范围受限。
  - **分压式**：调节范围 $0 \sim E$，适合“电压从零连续可调”或负载电阻 $R_x$ 远大于变阻器 $R$ 时使用。**必用分压条件**：要求“电压/电流从0开始调节”；$R_x \gg R$；限流接法最小电流超过电表量程。
- **等效替代法与电桥法**：当调节电阻箱使两路电流/电压相等时，可用已知电阻替代待测电阻。电桥平衡时，中间支路无电流，对臂电阻乘积相等。
- **伏安法测电阻误差**：电流表内接法 $R_{\text{测}} > R_{\text{真}}$（大电阻适用）；电流表外接法 $R_{\text{测}} < R_{\text{真}}$（小电阻适用）。

## 解题方法与套路
1. **电路设计“两步走”** ：
   - 审题抓核心：明确电源电动势 $E$、待测元件额定电流/电压、各电表量程与内阻。
   - 定结构：
     - 控制部分：若要求“从0连续可调”或滑动变阻器全值远小于负载电阻，**必选分压式**；否则可选限流式。
     - 测量部分：根据待测电阻约 $\sqrt{R_A R_V}$ 判内接/外接；若需扩大量程，优先并联（扩流）或串联（扩压）定值电阻。
2. **电表读数“分度法”** ：
   - 先确定分度值 $d$，再读格数 $n$。
   - 0~3V量程：估读到0.01V；0~0.6A量程：估读到0.01A。遵循“十分之一估读”原则，估读值应在最小分度的下一位。
3. **数据处理的“线性化”思维**：
   - 遇图像题，写出函数关系式（如 $U = f(t)$），与标准 $y=kx+b$ 对照，斜率 $k$ 常对应所求物理量（如灵敏度 $|\frac{\Delta U}{\Delta t}|$）。
4. **等效替换法测电阻**：
   - 搭建桥式电路或替代回路，调节电阻箱使电表示数不变/电桥平衡。
   - 利用“替换前后电路状态相同”直接得出 $R_x = R_{\text{箱}}$ 或利用电桥平衡方程 $R_x R_3 = R_0 R_4$ 求解。

## 高频易错
- **分压or限流混淆**：一旦题干要求“电流/电压从0开始变化”或“多测几组数据”，必须用分压接法；限流接法无法调到0。
- **电表改装计算丢内阻**：改装电流表时，并联电阻 $R = \frac{I_g R_g}{I - I_g}$，**分母是差量**，计算时 $I_g$、$R_g$ 不能遗漏或单位不统一（如mA与A混用）。
- **有效数字保留**：由题中器材精度或表格数据定有效数字位数；计算 $R_x$ 时，$U/I$ 结果的有效数字与原始测量数据最少位数保持一致。
- **电桥平衡条件误判**：在调节中使“接通S2前后微安表示数不变”，意味着B、D两点电势相等，说明 $R_1/R_3 = R_2/R_4$，切勿记成电流为零或电压为零。
- **滑动变阻器初始位置**：分压接法实验前滑片应置于**输出电压为零的一端**（常为滑片靠近电源负极侧或与负载并联部分的最短端），以保护电表。

## 代表题精讲
**题目1**：2022-全国乙-10
- **思路**：要求测 $R_x$（约550Ω）0~5mA伏安特性。电源4V，电流表内阻300Ω量程1mA，需改装扩大量程至5mA。调压要求0~5mA连续可调，必用分压接法。
- **步骤**：
  1. 扩程计算：$I_gR_g = (I-I_g)R_0$，$1\text{mA} \times 300\Omega = (5-1)\text{mA} \times R_0$，得 $R_0=75\Omega$。
  2. 滑变选择：分压式优先选**小阻值**变阻器，调整精细，故选“$10\Omega$”。
  3. 连线电路：电源正极接滑动变阻器全电阻两端，滑片一端引出分压。待测电阻 $R_x$ 与电流表、定值电阻混联（表头与 $R_0$ 并联后再与 $R_x$ 串联），电压表测 $R_x$ 并联部分总电压。
  4. 读数计算：电压表量程3V，估读得2.30V；电流表量程1mA，估读0.84mA。因扩程5倍，$R_x$ 上真实电流 $I=5 \times 0.84\text{mA}=4.20\text{mA}$。则 $R_x = \frac{U}{I} = \frac{2.30}{4.20 \times 10^{-3}} = 548\Omega$。
- **点评/变式**：此题核心是“改装与分压相结合”。注意：电压表测量的是 $R_x$ 两端电压，并非表头两端；电流表读数须按比例还原为实际电流。若改为内接法，电流正确但电压偏大，测得的 $R_x$ 偏大。

**题目2**：2019-新课标Ⅱ-10
- **思路**：恒流源电路，借助定值电阻 $R_0$ 两端电压保持恒定电流。 $U_{R_0} = I R_0$，调节滑变维持 $V_1$ 示数为该值即可保证二极管电流恒定。
- **步骤**：
  1. $U_1 = 50.0\mu\text{A} \times 100\Omega = 5.00\text{mV}$。
  2. 由图(b)知温度升高，$U_{\text{二极管}}$ 减小。二极管正向电阻 $R_D = \frac{U_D}{I}$ 随温升而**变小**。总电压 $E$ 恒定，$R_0$ 两端电压 $U_{R_0}$ 增大，$V_1$ 示数**增大**。为使 $V_1$ 回到5.00mV，应增大 $R$ 接入阻值（分压变大），滑片向B端移动。
  3. 灵敏度 $k = |\frac{\Delta U}{\Delta t}|$，取图线上易读两点 $ (0^\circ\text{C},0.44\text{V})$ 及 $(80^\circ\text{C},0.22\text{V})$，得 $k = \frac{0.44-0.22}{80} = 2.75 \times 10^{-3} \text{V/}^\circ\text{C}$，保留2位有效数字为 $2.8 \times 10^{-3}$。
- **点评/变式**：本题将欧姆定律用于传感器。关键步骤：①从曲线读点算斜率；②明确“恒流”条件由反馈调整滑变实现。若误认为电源直接供电，会错判 $V_1$ 变化。

**题目3**：2018-新课标Ⅱ-09
- **思路**：利用串并联进行多用电表改装。电流挡需并联小电阻分流，电压挡需串联大电阻分压。
- **步骤**：
  1. 封装内部：微安表头（$I_g=100\mu\text{A}, R_g=900\Omega$）与 $R_1$ 并联组成量程1mA电流表。
  2. 计算 $R_1$：并联支路电压相等，$I_g R_g = (1\text{mA} - 100\mu\text{A}) R_1$。解得 $R_1 = \frac{100\mu\text{A} \times 900\Omega}{900\mu\text{A}} = 100\Omega$。
  3. 成电压表：电流挡基础上串联 $R_2$ 即成3V电压表。电流计满偏时，$R_2$ 两端电压 $U_{R2} = 3 - I_g R_g = 3 - 0.1\text{mA} \times 900\Omega$ 需更正。正确为：电流挡满偏电流1mA，$U = I_\text{满}(R_{\text{并}} + R_2)$，其中 $R_{\text{并}} = \frac{900 \times 100}{900+100}=90\Omega$。得 $R_2 = \frac{3\text{V}}{1\text{mA}} - 90\Omega = 2910\Omega$。
- **点评/变式**：解题时注意区分“原表头”与“改装后表头”。$R_2$ 应串联在整个电流挡总成之后。若直接在微安表上串联 $R_2$ 计算则会出错。此类题是标准套路，牢记扩流用并联小电阻，扩压用串联大电阻。
