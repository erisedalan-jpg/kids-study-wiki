## 知识精要
- **波长$\lambda$**  
  振动相位相同的相邻两质点间的距离，或波在一个周期内传播的距离。  
  公式：$$v = \lambda f = \frac{\lambda}{T} \quad\Rightarrow\quad \lambda = vT = \frac{v}{f}$$  
  其中$v$为波速（由介质决定），$f$（或$T$）为频率（周期），由波源决定，与介质无关。  
- **波传播的特性**  
  介质中各质点均做受迫振动：振幅、周期（频率）、起振方向均与波源相同（无能量损失时）。质点振动速度是变化的，与波速$v$无关。  
- **横波与纵波**  
  横波：质点振动方向与波传播方向垂直；纵波：质点振动方向与波传播方向在同一直线上（但不一定始终同向）。  
- **波的干涉**  
  两列频率相同、振动方向相同、相位差恒定的波叠加。  
  若两波源同相，则波程差$\Delta r$满足：  
  $\Delta r = k\lambda \;(k=0,1,2,\dots)$ → 振动加强；  
  $\Delta r = (2k+1)\frac{\lambda}{2}$ → 振动减弱。  
- **双缝干涉条纹间距**  
  $$\Delta x = \frac{l}{d}\lambda$$  
  $l$：双缝到屏的距离；$d$：双缝间距；$\Delta x$：相邻亮纹（或暗纹）中心间距。  
  测波长时，若第1条暗纹到第$n$条暗纹的距离为$\Delta x_n$，则$\Delta x = \frac{\Delta x_n}{n-1}$。  
- **波长与空间相位关系**  
  波源与某质点相距$x$，则质点振动与波源的时间差$\Delta t = \frac{x}{v}$。质点振动相位落后波源$\Delta\varphi = \frac{2\pi}{\lambda}x$。  
  若$x = k\lambda$，同相；$x = (2k+1)\frac{\lambda}{2}$，反相。

## 解题方法与套路
1. **应用$v = \lambda f$求波长或波速**  
   已知其中两个量求第三个，或由介质变化推断波速与波长变化（频率不变）。  
2. **双缝干涉测波长**  
   - 由$\Delta x = \frac{l}{d}\lambda$列式；  
   - 测量$n$条条纹总间距$\Delta x_n$，求$\Delta x = \frac{\Delta x_n}{n-1}$，代入计算$\lambda$；  
   - 改变$\Delta x$的方法：减小$l$、增大$d$、减小$\lambda$。  
3. **由振动源状态和空间距离求波长**  
   - 用波源振动时间$t = \frac{x}{v}$与周期$T$的关系：$t = nT + \Delta t$；  
   - 结合波的起振方向、波峰波谷位置，推出$\frac{x}{\lambda}$的整数及小数部分，解出波长。  
4. **判断干涉加强/减弱**  
   - 计算两波源到考察点的波程差$\Delta r$；  
   - 明确两波源振动是否同相（起振方向是否相同）；  
   - 同相时：$\Delta r = k\lambda$加强，半波长奇数倍减弱；反相时结论相反。  
5. **由质点振动方向反推波长或波形**  
   - 利用“同侧法”或“微平移法”确定波的传播方向与质点振动方向关系；  
   - 根据时刻及位置信息列出波长满足的方程，结合限定条件（如波长范围）求解。

## 高频易错
- **质点振动速度$\,\neq\,$波速**  
  波速由介质决定且恒定，质点振动速度随时间简谐变化，两者不能混淆。  
- **起振方向一律与波源起振方向相同**  
  无论质点离波源多远，起振方向只由波源起始方向决定，与距离无关。  
- **双缝干涉中条纹数与间距的关系**  
  增加目镜中条纹个数，意味着相邻条纹间距$\Delta x$变小，应减小双缝到屏距离、增大双缝间距或减小波长；切勿反向操作。  
- **暗纹间距的间隔数计数错误**  
  第1条暗纹到第$n$条暗纹之间有$n-1$个$\Delta x$，计算$\lambda$时务必除以$(n-1)$，而非$n$。  
- **忽略波源相位判断干涉**  
  若两波源振动反相（一个从平衡位置向上，另一个向下），加强/减弱条件与同相时恰恰相反。  
- **距离与波长相位的整数关系误判**  
  当波源在平衡位置向上振动时，相距$2.5\lambda$的质点并非总是向上，而是落后$2.5$周期，恰好处在平衡位置向下振动的反相状态。要结合时间延迟或相位差仔细判断。

## 代表题精讲
### 2023-新课标-01  
**题目**：船上的人和水下潜水员都能听见轮船鸣笛声，声波在空气和水中传播时波速、波长、周期、频率的关系。  
**思路**：声波频率由声源决定，在不同介质中不变；波速由介质性质决定，水中波速大于空气；由$\lambda = v/f$可推知波长变化。  
**步骤**：  
1. 鸣笛声的频率$f$固定，周期$T=1/f$不变。  
2. 波速$v_{\text{水}} > v_{\text{空气}}$。  
3. 由$\lambda = v/f$得，水中波长大于空气中波长。  
4. 故波速和波长均不同，A正确。  
**点评/变式**：波从一种介质进入另一种介质时，频率（周期）是“不变的桥梁”。常考光进入不同介质时的类似判断。

### 2022-全国乙-15  
**题目**：两个同相点波源$S_1$、$S_2$，周期0.8s，振幅相等，波速5m/s。求波长；点$P$到两波源距离均为10m，判断该点振动加强还是减弱；当$S_1$在平衡位置向上运动时，$P$点振动方向。  
**思路**：波长$\lambda = vT$；两波源同相，波程差为零则加强；由$P$点到波源的距离反推相位关系。  
**步骤**：  
1. $\lambda = vT = 5 \times 0.8 = 4\,\text{m}$。  
2. $\Delta r = |S_1P - S_2P| = 0$，因两波源同相，$\Delta r = 0 = 0 \cdot \lambda$，满足加强条件，故振动加强。  
3. $S_1P = 10\,\text{m} = 2.5\lambda$。$S_1$振动传到$P$用时$t = \frac{10}{5} = 2\,\text{s} = 2.5T$，$P$点振动比$S_1$落后2.5个周期，即反相。$S_1$向上时，$P$向下运动。  
**点评/变式**：若两波源反相，则波程差为零时为减弱点。距离为半波长奇数倍时质点振动反相，是判断波上质点状态的关键。

### 2024-辽宁-04  
**题目**：自制双缝干涉装置（纸板上窄缝加头发丝形成双缝），绿光照双缝，墙面上呈现干涉条纹。要使相邻亮纹中心间距变小的方法。  
**思路**：双缝干涉条纹间距公式$\Delta x = \dfrac{l}{d}\lambda$，其中$l$是缝到墙距离，$d$是双缝间距，$\lambda$是波长。  
**步骤**：  
1. 相邻亮纹间距$\Delta x \propto \frac{l}{d}\lambda$。  
2. 使$\Delta x$变小：减小$l$（将墙面移近双缝）、增大$d$（可理解为头发丝直径使双缝间距变化）、减小$\lambda$（改用波长更短的紫光或蓝光）。具体选项依据实际情况选择即可。  
**点评/变式**：无论实验装置如何变，核心公式不变。注意实际操作中“窄缝中央沿缝方向固定头发丝”形成的是等效双缝，改变头发丝粗细或波长均影响条纹间距。
