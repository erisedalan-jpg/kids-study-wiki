## 知识精要
- **焦耳定律**：电流通过导体产生的热量 $Q = I^{2}Rt$，适用于任何电路。
  - $I$ 为通过导体的电流（单位 A），$R$ 为导体电阻（单位 $\Omega$），$t$ 为通电时间（单位 s）。
  - 纯电阻电路中，电能全部转化为内能：$Q = W = UIt = \frac{U^{2}}{R}t$。
  - 非纯电阻电路中，$Q < W$，必须用 $Q = I^{2}Rt$ 计算电热。
- **电磁感应中的焦耳热**：
  - 若感应电流恒定，可直接用 $Q = I^{2}Rt$ 或 $Q = EIt$（纯电阻回路）。
  - 若电流变化，需用能量守恒或积分（如 $Q = \int I^{2}R\,dt$），在高中阶段常结合动能定理、能量守恒求解。
- **电阻计算**：均匀导线电阻 $R = \rho \frac{L}{S}$ 或 $R = \lambda L_{\text{总}}$，其中 $\lambda$ 为单位长度电阻，$L_{\text{总}}$ 为导线总长度。

## 解题方法与套路
1. **回路电阻识别**：看清是整个回路电阻还是部分电阻，当导线粗细均匀时，回路总电阻 $R = \lambda \times \text{导线总长度}$（注意串并联关系）。  
2. **电流判定**：  
   - 若题设中 $B$ 均匀变化或导体匀速运动，感应电动势 $E$ 恒定，感应电流 $I = E/R$ 恒定，焦耳热直接使用 $Q = I^{2}Rt$。  
   - 若电流变化，则先计算电热与其它能量的关系，常用能量守恒（如导体棒克服安培力做功等于回路焦耳热）。  
3. **时间区间核实**：焦耳热计算时间 $t$ 必须与题目要求的区间一致，防止误用全程或部分时间。  
4. **直接代入**：$Q = I^{2}Rt$，注意单位统一（国际单位制）。

## 高频易错
- **电功与电热混淆**：在电磁感应综合题中，若外电路有电动机等非纯电阻元件，$Q$ 不能用 $UIt$ 代替，必须用 $I^{2}Rt$。  
- **电阻计算遗漏**：导线单位长度电阻需乘以实际长度，方框类要算总周长，不能只算单边。  
- **有效物理量错误**：  
  - 计算感应电动势时，面积应为磁场穿过的有效面积（如磁场只覆盖部分回路，要用实际磁通变化的面积）。  
  - 计算安培力时，有效长度为磁场中载流导体的“两端点连线”在垂直于 $B$ 方向的投影长度。  
- **时间范围看错**：题中可能有多阶段，焦耳热阶段对应电流持续的时间。  
- **单位换算**：如题中长度用 $m$，单位长度电阻用 $\Omega/m$，最终电热的单位 $J$，注意幂次。

## 代表题精讲

**题目**  
（2022·全国乙卷·11）正方形金属框边长 $l = 0.40\,\text{m}$，导线单位长度电阻 $\lambda = 5.0 \times 10^{-3}\,\Omega/\text{m}$，框通过一顶点用细绳悬挂，一条对角线水平，下半部分有垂直于框面的匀强磁场。磁感应强度 $B(t) = 0.3 - 0.1t$ (SI)。求：  
(1) $t=2.0\,\text{s}$ 时金属框所受安培力的大小；  
(2) $t=0$ 到 $t=2.0\,\text{s}$ 内金属框产生的焦耳热。

**思路**  
1. 求出回路总电阻 $R = \lambda \cdot 4l$。  
2. 由磁场变化率求感应电动势：磁场仅存在于框的下半部分（半个正方形），磁通量变化面积应为 $\frac{1}{2}l^{2}$，$E = \frac{\Delta \Phi}{\Delta t} = \frac{\Delta B}{\Delta t} \cdot \frac{1}{2}l^{2}$。  
3. 得到电流 $I = E/R$，因 $\frac{\Delta B}{\Delta t}$ 恒定，$I$ 恒定。  
4. (1) 安培力：$t=2\,\text{s}$ 时 $B_{2} = 0.3 - 0.1 \times 2 = 0.1\,\text{T}$，磁场中导线为框下半部的两直角边，其等效长度为对角线 $L = \sqrt{2}l$，安培力 $F = B_{2} I L$。  
5. (2) 焦耳热：恒定电流下 $Q = I^{2} R \cdot t$，时间 $t = 2.0\,\text{s}$。

**步骤**  
总电阻：$R = 4l \cdot \lambda = 4 \times 0.4 \times 5.0 \times 10^{-3} = 0.008\,\Omega$。  
感应电动势：$\frac{\Delta B}{\Delta t} = 0.1\,\text{T/s}$，有效面积 $S = \frac{1}{2}l^{2} = 0.08\,\text{m}^{2}$，  
$E = 0.1 \times 0.08 = 0.008\,\text{V}$。  
电流：$I = \frac{E}{R} = \frac{0.008}{0.008} = 1\,\text{A}$。  

(1) $t=2\,\text{s}$ 时 $B=0.1\,\text{T}$，等效长度 $L = \sqrt{2} \times 0.4 = 0.4\sqrt{2}\,\text{m}$，安培力  
$F = BIL = 0.1 \times 1 \times 0.4\sqrt{2} = 0.04\sqrt{2}\,\text{N}$。  

(2) 焦耳热 $Q = I^{2} R t = 1^{2} \times 0.008 \times 2.0 = 0.016\,\text{J}$。

**点评/变式**  
- 本题核心是焦耳定律在电磁感应背景下的直接应用。只要回路电流恒定，求焦耳热就化归为纯电路问题。  
- 易错点在于误把整个正方形面积代入电动势计算（实际只是一半在磁场中），以及安培力计算时把边长当作有效长度。  
- 变式：若磁场覆盖整个框面，且 $B$ 非线性变化，电流将不再恒定，此时不能用 $Q=I^{2}Rt$ 直接求全程电热，而需考虑 $Q$ 与克服安培力做功的关系或利用有效电流（交流电）。
