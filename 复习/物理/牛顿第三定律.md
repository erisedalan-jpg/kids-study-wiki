## 知识精要
- **牛顿第三定律**：两个物体之间的作用力 $F$ 与反作用力 $F'$ 总是大小相等、方向相反，作用在同一条直线上，且分别作用在两个不同的物体上。表达式：$F = -F'$。
- **相互作用力与平衡力的区别**：
  - 相互作用力：等大、反向、共线，但作用在不同物体上，性质相同，同时产生、同时消失。
  - 平衡力：等大、反向、共线，作用在**同一物体**上，性质可不同，一个力消失另一个可仍然存在。
- **摩擦力方向判定**：滑动摩擦力方向与物体相对运动方向相反；静摩擦力方向与物体相对运动趋势方向相反。牛顿第三定律常用于由已知摩擦力推知反作用力方向。

## 解题方法与套路
1. **明确研究对象与状态**：先确定各物体是静止还是运动，有无相对滑动。
2. **摩擦力方向两步走**：
   - 找相对运动（趋势）方向：墨条相对砚台向左运动 → 砚台对墨条摩擦力向右。
   - 牛三反推：墨条对砚台摩擦力必等大反向，即向左。
3. **平衡力判断**：对处于静止的物体（如砚台）受力分析，列出水平、竖直方向平衡方程，检验各力是否作用在同一物体。
4. **区分“一对平衡力”与“一对相互作用力”**：看受力物体是否相同，相同则是平衡力候选；再看施力物体与力的性质，性质不同则一定不是相互作用力。
5. **竖直方向叠加关系**：桌面对砚台的支持力 = 砚台重力 + 墨条对砚台的压力，切忌漏掉墨条施加的额外压力。

## 高频易错
- **摩擦力方向“想当然”**：以为墨条向左运动，受到摩擦力也向左（实则向右），忘记摩擦力与相对运动方向相反。
- **盲目套用牛三而忽略研究对象**：把“砚台对桌面”与“桌面对砚台”误判为一对平衡力，实际是相互作用力。
- **混淆平衡力与相互作用力**：看到大小相等、方向相反就选平衡力，忽略必须“同一物体”这一核心条件。
- **竖直方向漏力**：分析砚台竖直方向时，只考虑重力与支持力，没有加上墨条对砚台的压力，导致错判支持力大小关系。
- **忘记“静止”状态也能有静摩擦力**：砚台静止，但受墨条摩擦力作用，桌面必须提供反向的静摩擦力来平衡。

## 代表题精讲
### 代表题1：2024·辽宁卷·03
**题目**  
利用砚台将墨条磨成墨汁，墨条速度方向水平向左。判断关于摩擦力和平衡力的说法中哪一项正确。

**思路**  
先由墨条相对砚台的运动方向确定砚台对墨条的摩擦力方向，再利用牛顿第三定律得到墨条对砚台的摩擦力方向。对砚台进行受力分析（静止），判断水平方向二力平衡、竖直方向支持力与压力的大小关系，并严格区分平衡力与相互作用力。

**步骤**  
1. 墨条向左运动，相对砚台向左滑动 → 砚台对墨条的摩擦力方向向右（滑动摩擦力与相对运动方向相反）。A选项错误。  
2. 根据牛顿第三定律，墨条对砚台的摩擦力方向向左。砚台静止，水平方向必须受力平衡 → 桌面对砚台的摩擦力方向向右。B选项错误。  
3. 砚台水平方向只受“墨条对它的摩擦力（向左）”和“桌面对它的摩擦力（向右）”，二力等大、反向、共线且作用在同一物体上，是一对平衡力。C选项正确。  
4. 竖直方向：桌面对砚台的支持力 $F_N$ = 砚台重力 $G$ + 墨条对砚台的压力 $F_压$。因此 $F_N > F_压$，且这两个力作用在同一物体上，但大小不等，不是平衡力。D选项错误。

**点评/变式**  
本题核心是牛顿第三定律与平衡力的区分。若将“墨条速度方向水平向左”改为“砚台被向右匀速拖动（墨条相对砚台静止）”，则需重新判断摩擦力方向及平衡关系，注意相对运动（趋势）的变化。再变式：问“桌面对砚台的摩擦力与砚台对桌面的摩擦力”关系，则必为相互作用力。
