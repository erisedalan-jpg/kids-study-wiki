## 知识精要
- **电动势（E）**：电源内部非静电力移送单位正电荷所做的功，表征电源将其他形式能转化为电能的本领。数值上等于电源未接入电路时两极间的电压。
- **闭合电路欧姆定律**：$E = U + I r$（$U$为路端电压，$I$为干路电流，$r$为内阻）。外电路为纯电阻时，$I = \frac{E}{R+r}$。
- **路端电压与外电流的关系**：$U = E - I r$，$U\!-\!I$图象是一条倾斜直线。纵轴截距等于电动势$E$，横轴截距等于短路电流$I_0 = \frac{E}{r}$，图线斜率的绝对值等于内阻$r = \left| \frac{\Delta U}{\Delta I} \right|$。
- **电源的功率与效率**：
  总功率 $P_总 = E I$，输出功率 $P_出 = U I$，内耗功率 $P_内 = I^2 r$。
  电源效率 $\eta = \frac{P_出}{P_总} = \frac{U}{E}$（普遍适用）；纯电阻电路也满足 $\eta = \frac{R}{R+r}$。
- **电桥平衡与电源电动势**：惠斯通电桥平衡时，桥臂电阻满足 $\frac{R_1}{R_2} = \frac{R_3}{R_4}$，此时桥两端电势相等，检流计示数为零。平衡条件与电动势大小无关，但需要电源提供稳定电压，且调节分压可改变电桥灵敏度。

## 解题方法与套路
1. **$U\!-\!I$图象信息的提取**  
   - 首先明确横轴、纵轴的物理量，注意坐标原点是否为（0,0）。  
   - 纵轴截距即为电动势$E$；若横轴起点为零，横轴截距即为短路电流$I_0$；若起点不为零，需通过延长图线读取或计算。  
   - 求内阻时，在直线上取两点，由$r = \left| \frac{\Delta U}{\Delta I} \right|$计算；也可用$r = \frac{E}{I_0}$（仅当截距准确时适用）。  
   - 求任一工作点的路端电压$U$和干路电流$I$，可进一步计算输出功率、效率等。

2. **电源效率的快速求解**  
   - 优先使用$\eta = \frac{U}{E}$，直接从图象或已知条件读出该状态下的路端电压与电动势，即可求比值。  
   - 若外电路为纯电阻，且已知内外电阻关系，也可用$\eta = \frac{R}{R+r}$，但图象法用电压比更直接，不易出错。

3. **电桥法测电阻的思维流程**  
   - 搭建电桥：电源、滑动变阻器（分压或限流）、已知电阻（电阻箱）、待测电阻、桥路灵敏电表。  
   - 调平衡：调节桥臂比例，直至接通桥路开关前后电表示数不变，说明桥两端电势相等，流过电表的电流为零。  
   - 列式求解：根据电势相等建立比例关系。若进行元件对调后再次平衡，列两个方程联立，可消去比例臂电阻等中间量，准确求得待测电阻。  
   - 提高精度：适当增大电源电动势或调节分压，使平衡接近时电表偏转灵敏；多次测量取平均；使用电阻箱时注意最大阻值的选取。

## 高频易错
- **$U\!-\!I$图象横轴起点不明确**：很多图线横轴并非从零开始，误将某点的横坐标直接当作短路电流会导致内阻、电动势计算错误。务必找纵轴截距和斜率。
- **效率公式混淆**：经常有考生错记为$\eta = \frac{I}{E}$、$\eta = \frac{R}{r}$或$\eta = \frac{U}{I}$。必须牢记$\eta = \frac{U}{E}$，它既适用于纯电阻也适用于非纯电阻电路。
- **电桥平衡判断的理解偏差**：“接通$S_2$前后微安表示数不变”反映的是桥两端电势相等，并非直接表示电阻箱阻值等于待测电阻。必须依据平衡方程求解，若只做一次平衡就代入相等，必然错误。
- **分压电路的操作不规范**：闭合电源开关前，分压器滑片应置于使输出电压为零的一端（通常为与电源负极端相接的一端）。若误按限流接法将滑片置于阻值最大端，会导致微安表上承受较大电压而被损坏。
- **读数与有效数字**：电阻箱读数要符合仪器精度要求，计算最终结果时注意题目对保留位数的要求（如“保留到个位”），不可随意省略或添加小数部分。
