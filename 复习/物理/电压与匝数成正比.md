## 知识精要
- **理想变压器模型**
  - 无漏磁（磁通量全部约束在铁芯内）、无铜损（线圈电阻不计）、铁芯无涡流与磁滞损耗。
  - 原、副线圈中每匝线圈的磁通量变化率相同，因此感应电动势与匝数成正比。
- **核心关系式**
  - 电压与匝数关系：$$\frac{U_1}{U_2} = \frac{n_1}{n_2}$$
    其中 $U_1$、$U_2$ 为原、副线圈两端电压有效值（或瞬时值），$n_1$、$n_2$ 为对应的匝数。
  - 功率守恒：理想变压器输入功率等于输出功率，$P_1 = P_2$。
  - 电流关系（仅一个副线圈时）：$$\frac{I_1}{I_2} = \frac{n_2}{n_1}$$
    多个副线圈时，电流关系须由 $U_1 I_1 = U_2 I_2 + U_3 I_3 + \dots$ 导出，不可直接套用匝数反比。
- **适用条件**
  - 只对理想变压器成立。
  - 电压有效值（或瞬时值）与匝数成正比，频率保持不变。
  - 各物理量均为交流电的有效值（或瞬时值对应），不可直接用于直流。

## 解题方法与套路
1. **明确工作状态**  
   从题干中找出“灯泡正常发光”“额定电压”“额定功率”等信息，确定副线圈电压和电流的有效值（或最大值）。
2. **列电压比方程**  
   利用 $\frac{U_1}{U_2} = \frac{n_1}{n_2}$，代入已知匝数比和一侧电压，求另一侧电压。
3. **求电流**  
   - 若只有一个副线圈，可直接用 $\frac{I_1}{I_2} = \frac{n_2}{n_1}$ 或 $I_1 = \frac{P_2}{U_1}$。
   - 若涉及功率，先由 $P_2 = U_2 I_2$（或 $P_2 = \frac{U_2^2}{R}$）算副线圈电流，再用功率守恒求原线圈电流。
4. **注意单位的统一与有效值**  
   交流电压表、电流表读数为有效值，题目中如无特别说明，电压、电流均指有效值。

## 高频易错
- **混淆电压比与电流比的正反比关系**  
  电压比与匝数比成正比，电流比（仅一个副线圈时）与匝数比成反比。记错方向会直接丢分。
- **在多副线圈时盲目套用电流反比公式**  
  多副线圈的电流关系须用功率方程求解，匝数反比不再成立。
- **忽视“正常发光”隐含条件**  
  “灯泡正常发光”隐含灯泡两端电压等于其额定电压，消耗功率等于额定功率，必须立刻转化为副线圈的已知量。
- **将峰值当成有效值代入**  
  遇到 $220\,\mathrm{V}$ 等常见值时，需确认是有效值还是最大值，本题中铭牌参数均为有效值。
- **不注意理想变压器的功率制约**  
  输出功率决定于负载，输入功率随之调整，不能随意假设原线圈电流，必须由副线圈功率反推。

## 代表题精讲
### 代表题：2011·新课标·04
**题目**  
一理想变压器原副线圈匝数比 $1:2$，副线圈接有额定电压 $220\,\mathrm{V}$、额定功率 $22\,\mathrm{W}$ 的灯泡。闭合开关，灯泡正常发光。电压表和电流表分别接在原线圈侧，求电表读数 $U$ 和 $I$。

**思路**  
灯泡正常发光 → 副线圈电压 $U_2=220\,\mathrm{V}$，电流 $I_2 = \frac{P_{\text{额}}}{U_{\text{额}}} = 0.1\,\mathrm{A}$。  
由电压与匝数成正比求原线圈电压 $U_1$，再由电流与匝数成反比或功率守恒求原线圈电流 $I_1$。

**步骤**  
1. 确定匝数比：$n_1:n_2 = 1:2$，故 $U_1:U_2 = 1:2$。  
2. 求原线圈电压：$U_1 = \frac{n_1}{n_2} U_2 = \frac{1}{2} \times 220\,\mathrm{V} = 110\,\mathrm{V}$。  
3. 求副线圈电流：$I_2 = \frac{P_2}{U_2} = \frac{22}{220}\,\mathrm{A} = 0.1\,\mathrm{A}$。  
4. 求原线圈电流：对于单副线圈，$\frac{I_1}{I_2} = \frac{n_2}{n_1} = 2$，  
   $I_1 = 2I_2 = 0.2\,\mathrm{A}$（也可用 $I_1 = \frac{P_2}{U_1} = \frac{22}{110}\,\mathrm{A} = 0.2\,\mathrm{A}$ 验证）。  
5. 读数：$U = 110\,\mathrm{V}$，$I = 0.2\,\mathrm{A}$，对应选项 **A**。

**点评/变式**  
- 本题是变压器最基础的题型，紧扣“电压与匝数成正比”，同时兼顾单副线圈的电流反比关系。  
- **变式1**：若原线圈电压不变，副线圈多接入一个相同灯泡并联，电流表读数如何变化？  
  副线圈负载功率加倍，原线圈电流随之加倍。电压关系不受影响，原线圈电压仍由匝数比和电源决定。  
- **变式2**：若匝数比改为 $2:1$，灯泡还能正常发光吗？  
  此时 $U_2 = \frac{1}{2}U_1$，若原线圈输入 $220\,\mathrm{V}$，副线圈仅 $110\,\mathrm{V}$，灯泡不能正常发光，需调整匝数比或用升压变压器。  
- 注意：交流电表读数为有效值，在纯电阻负载下计算简便，但若负载含电感、电容，功率因数会影响功率和电流关系，高考通常限定纯电阻负载。
