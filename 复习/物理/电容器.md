## 知识精要
- **电容定义式**：$C = \frac{Q}{U}$（$Q$为任一极板所带电荷量的绝对值，$U$为两极板间电势差）。
- **平行板电容器电容决定式**：$C = \frac{\varepsilon S}{4\pi k d}$，其中$\varepsilon$为极板间电介质的相对介电常数，$S$为正对面积，$d$为极板间距，$k$为静电力常量。**适用条件**：平行板电容器且忽略边缘效应。
- **匀强电场场强与电势差关系**：平行板电容器极板间电场可视为匀强电场，场强 $E = \frac{U}{d}$。
- **带电粒子在平行板电容器中的受力与平衡**：电场力 $F = qE = q\frac{U}{d}$，方向由粒子的电性及极板电势高低决定。与重力、阻力等共力作用下的匀速运动，满足合力为零。
- **电容器充放电**：与恒压电源连接时$U$不变，$Q = CU$；断开电源后$Q$不变，$U = \frac{Q}{C}$。充电时电流从电源正极流向电容器正极板，放电时电流从电容器正极板流出。

## 解题方法与套路
1. **电容器动态分析“两步走”**
   - **第一步**：明确不变量——题干中“与恒压电源连接”则$U$不变；“充电后断开电源”则$Q$不变。
   - **第二步**：由决定式 $C = \frac{\varepsilon S}{4\pi k d}$ 判断$C$的变化（看$\varepsilon$、$S$、$d$如何变），再由定义式 $C = \frac{Q}{U}$ 结合不变量推导$Q$或$U$的变化。若涉及$E$，可联立 $E = \frac{U}{d}$ 或导出式 $E = \frac{4\pi k Q}{\varepsilon S}$ 快速分析。

2. **电容器有关电路中的电流方向判定**
   - 以电容器正极板（接电源正极的极板）为参考：$Q$增大（充电）时，电流从电源正极→正极板→介质→负极板→电源负极；$Q$减小（放电）时，电流从正极板流出经外电路回到负极板。直接由$Q$的增减判断即可，无需纠结溶液是否导电（若极板直接与电源构成回路，溶液不导电不影响电容器充电）。

3. **带电粒子在电容器中的多过程平衡问题**
   - **画受力示意图**：标出重力、电场力、阻力（若有，其方向必与速度方向相反）等。
   - **按过程列平衡方程**：每个匀速过程合力为零。注意电场力 $F = qE = q\frac{U}{d}$，电压$U$改变或极性反向后，电场力大小和方向同步变化。
   - **联立求解**：利用阻力与速率成正比（$f=kv$）等条件，将不同过程的方程相比或加减，求得未知速度大小和方向。

## 高频易错
1. **$\varepsilon$变化方向的误判**：题目给出$\varepsilon$与某物理量（如浓度）的关系曲线时，务必看清横纵坐标含义及曲线走势。如“降低浓度”需对应曲线上浓度减小的方向得出$\varepsilon$是增大还是减小，切忌凭感觉判断。
2. **“溶液不导电”不等于电路断路**：电容器极板通过导线与电源直接相连，即便极板间介质不导电，电容器仍可正常充电，电流表所在回路会有瞬间或持续充电电流，不可当成断路处理。
3. **电流方向描述混淆节点符号**：电路图中标有$M$、$N$等节点，问电流方向时需结合电容器正在充电还是放电，准确判断电流流过某导线或电流表的方向，注意电子移动方向与电流方向相反。
4. **多过程问题中阻力方向易错**：空气阻力永远与相对运动方向相反，匀速上升时阻力向下，匀速下降时阻力向上。列方程时若阻力方向写反，会导致后续推导全错。
5. **电压反向后电场力处理不当**：电压变为$-U$表示极板极性对调，电场力大小与电压为$U$时相等但方向相反。切忌误认为电场力变为负值就“变小”或直接套用原方向方程。

## 代表题精讲
### **代表题1**：2024-辽宁-05
**题目**：不导电溶液相对介电常数$\varepsilon$与浓度$C_m$的关系曲线已知。平行板电容器两极板全插入溶液，与恒压电源、电流表等构成回路。闭合开关，降低溶液浓度，判断电容、电荷量、电势差及电流方向的变化。

**思路**：电容器始终与恒压电源相连→电压$U$不变。解读$\varepsilon$–$C_m$曲线，找出“降低浓度”对应的$\varepsilon$变化趋势。由决定式分析$C$的变化，再由$Q=CU$得出$Q$变化，最后根据$Q$增加还是减少确定充放电及电流方向。

**步骤**：
1. 由图(a)可知：浓度降低→$\varepsilon$增大。
2. 根据 $C = \frac{\varepsilon S}{4\pi k d}$，$\varepsilon$增大→$C$增大。选项A错误。
3. 电源恒压→两极板电势差$U$不变，选项C错误。
4. 由$Q = CU$，$C$增大→$Q$增大，电容器充电，选项B正确。
5. 充电时，正电荷定向移动方向为$N→M$（电流方向$N→M$），而选项D说$M→N$，错误。注意题图(b)中电流表连接方向。

**点评/变式**：本题核心考点是“电压不变时电容变化导致电荷量变化”，结合图像信息与电路方向判断，是典型的选择题组合形式。变式可改为“若溶液浓度增大，则电流方向如何”，或换成“断开电源后改变浓度”分析$U$的变化，强化不变量意识。

### **代表题2**：2008-全国Ⅱ-06
**题目**：平行板电容器水平放置，极板间有一电荷量不变的油滴，空气阻力与速率成正比。电压为零时匀速下降速率为$v$；电压为$U$时匀速上升速率也为$v$。求电压为$-U$时油滴匀速运动的速度大小和方向。

**思路**：油滴带电量不变、阻力 $f=kv$。三个匀速过程分别受力平衡：电压为零时仅有重力与阻力；电压为$U$时加入向上的电场力；电压为$-U$时电场力向下。通过方程联立求出电场力与重力的关系，再对第三过程列式求解速度。

**步骤**：
1. 设油滴质量$m$，带电量$q$，阻力比例系数$k$，电场力$F = q\frac{U}{d}$。
2. 电压为零，匀速下降：$mg = kv$。  (1)
3. 电压为$U$，匀速上升（向上为正方向，阻力向下）：$F - mg - kv = 0$ (上升速度$v$，阻力$kv$向下)，即$F = mg + kv$。结合(1)得$F = 2kv$。 (2)
4. 电压为$-U$，电场力向下大小仍为$F$。设向下匀速速率为$v'$，阻力向上：$mg + F - kv' = 0$。代入(1)(2)：$kv + 2kv = kv'$ ⇒ $v' = 3v$，方向向下。
5. 对应选项C。

**点评/变式**：本题重在过程分析和阻力方向的正确使用。可变形为：“若电压为$U$时匀速下降，电压为$-U$时如何”，或结合电容器动态变化（如改变极板间距问油滴运动状态），强化多过程方程联立和能力迁移。
