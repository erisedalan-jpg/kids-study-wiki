## 知识精要
- **电磁感应现象**：闭合回路磁通量变化产生感应电动势。发现者：法拉第。
- **法拉第电磁感应定律**：感应电动势大小 $E = n \dfrac{\Delta \Phi}{\Delta t}$，$n$为匝数；对于导体切割磁感线，$E = Blv$（$B$、$l$、$v$两两垂直，$l$为有效切割长度）。
- **楞次定律**：感应电流的磁场总要阻碍引起感应电流的磁通量变化。用来判断感应电流方向（或电动势方向），常用于结合右手定则。
- **动生电动势与感生电动势**：动生 $E = Blv$（平动）、$E = \frac12 B\omega l^2$ 或 $E = \frac12 B\omega (r_2^2 - r_1^2)$（转动）；感生 $E = n S \dfrac{\Delta B}{\Delta t}$（有效面积$S$为磁场中线圈面积）。
- **电磁感应中的电路**：产生感应电动势的部分等效为电源，其内阻为导体自身电阻，其余部分为外电路。回路总电阻需结合串并联计算。闭合电路欧姆定律 $I = \dfrac{E}{R_\text{总}}$。
- **安培力**：通电导体在磁场中受安培力 $F = BIl$，方向由左手定则判定，常作为阻力改变导体运动状态。
- **电磁感应与能量**：克服安培力做功等于回路产生的总焦耳热，$W_\text{克安} = Q_\text{总}$。若导体匀速运动，外力做功全部转化为焦耳热；若有其他力做功，用动能定理或能量守恒。
- **理想变压器**：$\dfrac{U_1}{U_2} = \dfrac{n_1}{n_2}$，$\dfrac{I_1}{I_2} = \dfrac{n_2}{n_1}$（一个副线圈），$P_\text{入} = P_\text{出}$。输入电压有效值 $U = \dfrac{U_m}{\sqrt{2}}$。

## 解题方法与套路
1. **判断感应电动势类型与方向**：先明确磁通量变化原因（$B$变、$S$变、切割），用楞次定律或右手定则判定电动势方向，在等效电路中标注电源正负极。
2. **定量计算电动势**：感生用 $E = n \dfrac{\Delta \Phi}{\Delta t}$，切割用 $E = Blv$（注意$l$为有效切割长度，且取垂直分量）。对于转动切割，用平均速度或直接积分（牢记结论）。
3. **构建等效电路**：将产生电动势的导体看作内阻为$r$的电源，其余部分为外电路，画出串并联关系，求总电阻、总电流，再分配到各支路。
4. **安培力与动力学分析**：由$I$求安培力 $F_A = BIl$（注意有效长度），方向用左手定则。结合牛顿第二定律、平衡条件或动量定理（如 $Bq l = m\Delta v$，其中 $q = \dfrac{\Delta \Phi}{R_\text{总}}$）。
5. **能量角度求解热量或功率**：克服安培力做功等于总焦耳热 $Q_\text{总}$。对于纯电阻电路，焦耳热按电阻比例分配，$Q_i = \dfrac{R_i}{R_\text{总}} Q_\text{总}$。
6. **图像问题处理**：看清横纵坐标，找特殊时刻（进入、出磁场等边界条件），分析电动势、电流、安培力与速度、位移的关系，注意函数单调性及方向正负。

## 高频易错
- **有效长度误判**：切割模型中 $E=Blv$ 的 $l$ 为垂直于速度方向的导线两端连线在垂直磁场平面内的投影长度，不是导线实际长度。磁场变化时 $S$ 取有磁场区域内的线圈面积。
- **方向判断混乱**：区分“阻碍磁通量变化”与“阻碍相对运动”；右手定则、左手定则、安培定则易混淆。画等效电路需标明电动势方向。
- **电路串并联错误**：双棒或多边框进入磁场时，电源可能为多个，需判断是串联还是并联；外电路结构随运动改变，电阻重新分配。
- **变压器中的峰值与有效值**：原线圈接余弦交流电时，输入电压有效值为 $U = U_m/\sqrt2$，直接用峰值代入变压器公式会出错。变压器输出功率计算要用有效值。
- **热量分配忘记内阻**：当电源有内阻（如金属框本身电阻）时，回路总焦耳热包括内阻和外电阻产热，如果问某外电阻热量，需按比例分配。
- **忽略过程分析直接套公式**：导体进出磁场过程往往不是全程匀变速，安培力随速度变化，导致加速度变化，图像题需分析速度变化趋势，不可直接假定线性。
- **能量守恒遗漏机械能变化**：感应电路产生焦耳热，能量来源可能是动能减少或者重力势能等，需完整列出能量方程，不要漏掉摩擦力做功等其他因素。
- **动量定理应用丢条件**：利用 $Bq l = m\Delta v$ 时，应确保回路总电阻恒定、过程从开始进入至完全穿出或特定阶段，且电荷量 $q = \dfrac{\Delta\Phi}{R_\text{总}}$ 只适用于某段过程。

## 代表题精讲
### 2024-辽宁-11
**题目**：理想变压器匝数比 $n_1:n_2 = 5:1$，原线圈接峰值 $U_m$ 的正弦交流电，副线圈接电阻 $R$ 的电热丝加热理想气体。气体吸收热量 $Q = C\Delta T$，初温 $T_0$，求（1）变压器输出功率 $P$；（2）压强变为2倍所需的通电时间 $t$。

**思路**：由峰值得原线圈电压有效值，由匝数比得副线圈电压有效值；副线圈为纯电阻，$P = U_2^2/R$。气体等容变化，压强与温度成正比，温度变化量与吸收热量相关，热量等于输出功率乘时间。

**步骤**：
1. 原线圈电压有效值 $U_1 = \dfrac{U_m}{\sqrt{2}}$。
2. 由 $\dfrac{U_1}{U_2} = \dfrac{n_1}{n_2}$ 得 $U_2 = \dfrac{n_2}{n_1}U_1 = \dfrac{1}{5} \cdot \dfrac{U_m}{\sqrt{2}} = \dfrac{U_m}{5\sqrt{2}}$。
3. 变压器的输出功率等于 $R$ 的热功率：$P = \dfrac{U_2^2}{R} = \dfrac{U_m^2}{50R}$。
4. 气体等容变化，$\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$，压强变为2倍则 $T_2 = 2T_0$，$\Delta T = T_2 - T_0 = T_0$。
5. 气体吸收热量 $Q = C\Delta T = C T_0$，且 $Q = P t$，故 $t = \dfrac{C T_0}{P} = \dfrac{50C T_0 R}{U_m^2}$。

**点评/变式**：本题综合变压器与热学，易错点在于电压有效值与峰值混淆。类似题可将电热丝换成电动机或给电容器充电，注意输出功率公式适用条件。

### 2023-新课标-13
**题目**：正方形金属框边长 $L$、质量 $m$、每边电阻 $R_0$，以初速度向右穿过宽 $2L$ 的匀强磁场。完全穿出后速度恰好减半。求（1）初速度大小；（2）若框置于导轨上，上、下边框与导轨始终接触良好，导轨左端连电阻 $R_1 = 2R_0$，以相同初速度进入磁场，求 $R_1$ 产生的热量。

**思路**：（1）利用动量定理：安培力冲量等于动量变化，而安培力冲量与通过截面的电荷量相关；穿过过程电荷量 $q = \dfrac{\Delta\Phi}{R_\text{总}}$，可求出初速度。（2）分析等效电路：金属框右边切割磁感线时为电源，内阻为一条边的电阻 $R_0$，外电路为左边电阻和 $R_1$ 的并联等；注意金属框运动过程中电路结构变化，最终动能全部转化为内能，由能量分配求 $R_1$ 热量。

**步骤**：
1. （1）进入与穿出过程磁通量变化量均为 $BL^2$，穿过整个区域总电荷量 $q = \dfrac{2BL^2}{4R_0} = \dfrac{BL^2}{2R_0}$。
2. 动量定理：$-B\bar I L \Delta t = -B q L = mv/2 - mv_0$，即 $-B q L = -\dfrac12 m v_0$，解得 $v_0 = \dfrac{2BqL}{m} = \dfrac{2B^2 L^3}{2mR_0} = \dfrac{B^2 L^3}{mR_0}$（结合原题数据可验算）。
3. （2）金属框右边切割，等效电源电动势 $E = BLv$，内阻 $r = R_0$；外电路为左边电阻 $R_0$ 与 $R_1$ 并联再与上、下边框电阻串联：上、下边框视为导线（接触良好），外总电阻 $R_\text{外} = \dfrac{R_0 \cdot 2R_0}{R_0 + 2R_0} = \dfrac{2}{3}R_0$，回路总电阻 $R_\text{总} = R_0 + \dfrac{2}{3}R_0 = \dfrac{5}{3}R_0$。
4. 全过程最终金属框静止，总动能全部转化为回路总焦耳热 $Q_\text{总} = \dfrac12 m v_0^2$。
5. 热量按电阻比例分配：$R_1$ 与左边电阻 $R_0$ 并联，通过 $R_1$ 的电流恒为 $R_0$ 的 $1/2$，因此 $R_1$ 的热量 $Q_{R1} = \dfrac{2R_0}{R_0 + 2R_0} \times \dfrac{R_\text{外}}{R_\text{总}} Q_\text{总} = \dfrac{2}{3} \times \dfrac{2/3}{5/3} Q_\text{总} = \dfrac{4}{15} Q_\text{总}$，代入得 $Q_{R1} = \dfrac{4}{15} \cdot \dfrac12 m \left( \dfrac{B^2 L^3}{m R_0} \right)^2$。

**点评/变式**：动量定理在电磁感应中常用于连接电荷量与速度变化，需注意过程选取。电路结构随运动变化，此类轨道滑动问题可变为双杆切割，分配热量时注意电流比例。

### 2022-全国乙-11
**题目**：边长 $l = 0.40\text{ m}$ 的正方形金属框，每边电阻线密度 $\lambda = 5.0\times10^{-3}\ \Omega/\text{m}$，用细绳悬挂，一条对角线水平，下方有垂直框面的匀强磁场，$B = 0.3 - 0.1t\ (\text{SI})$。求（1）$t = 2.0\text{ s}$ 时框所受安培力大小；（2）$0\sim 2.0\text{ s}$ 内框产生的焦耳热。

**思路**：感生电动势由磁场变化引起，金属框在磁场中的有效面积是下方三角形区域，面积 $S = \frac12 l^2$；总电阻 $R = 4l \lambda$。由法拉第定律求电动势和电流，进而求安培力。安培力需注意有效长度是处于磁场中的导体在垂直磁场方向投影，这里处于磁场中的两边各长为 $l$，等效长度为通过三角形斜边的有效长度，但安培力直接对处在磁场中的两段导线求和；该框下方两直角边受安培力，方向相同且大小相等。

**步骤**：
1. 线框总电阻 $R = 4l \lambda = 4 \times 0.4 \times 5\times10^{-3} = 8\times10^{-3}\ \Omega$。
2. 框架在磁场中的面积为等腰直角三角形，$S = \frac12 l^2 = 0.08\ \text{m}^2$，磁通量变化率 $\dfrac{\Delta B}{\Delta t} = -0.1\ \text{T/s}$，电动势 $E = \left| \dfrac{\Delta B}{\Delta t} \right| S = 0.1 \times 0.08 = 8\times10^{-3}\ \text{V}$。
3. 电流 $I = \dfrac{E}{R} = 1\ \text{A}$。
4. $t=2.0\text{ s}$ 时 $B = 0.3 - 0.1\times 2 = 0.1\ \text{T}$。处在磁场中的两条直角边长度均为 $l$ 且互相垂直，它们受安培力大小均为 $F_1 = BIl$，方向垂直于各自导线指向斜上方，合力 $F_A = \sqrt{2} BIl = \sqrt{2} \times 0.1 \times 1 \times 0.4 = 0.04\sqrt{2}\ \text{N}$。
5. 焦耳热 $Q = I^2 R t = 1^2 \times 0.008 \times 2 = 0.016\ \text{J}$。

**点评/变式**：易错点：有效面积取整个正方形，错用 $l^2$；安培力合成时忽略方向。类似可考察圆形线圈部分在变化磁场中，注意等效面积和有效长度。
