## 知识精要
- **核心物理量图像关系**：电磁感应中的图像问题常涉及 $B\!-\!t$、$\Phi\!-\!t$、$E\!-\!t$、$i\!-\!t$ 等，关键建立 **运动过程→磁通量变化→电动势/电流** 的因果链。
- **感应电动势大小**：
  - 平动切割：$E = BLv$（$L$ 为有效切割长度，$B$、$L$、$v$ 两两垂直）。
  - 在交替磁场中，两边同时切割时电动势可能叠加或抵消，总电动势为各有效边电动势的代数和（同向相加，反向相减）。
- **感应电流大小**：$i = \frac{E}{R}$（闭合电路欧姆定律），$R$ 为回路总电阻。
- **感应电流方向**：楞次定律（增反减同）或右手定则（用于单边切割）。在图像上常规定正方向，电流正负由线圈回路方向与磁场方向共同确定。
- **适用条件**：匀强磁场、导体匀速运动、回路电阻不变、忽略其他电磁影响。

## 解题方法与套路
1. **分阶段：** 按关键位置（边界、中点等）将线框运动全程分段，每段内有效切割情况不变。
2. **判大小：** 对每一段分析切割磁感线的有效边的条数、各边所处磁场的方向与磁感应强度，计算每边的 $E_i = BLv$，叠加得到总电动势 $E_\text{总}$，再由 $i = E_\text{总}/R$ 得电流大小。
3. **定方向：** 用楞次定律（看穿过回路的磁通量增减）或右手定则判断每一段的感应电流方向，与正方向对比得 $i$ 的正负。
4. **抓转折：** 找出 $i=0$ 的时刻（磁通量不变或总电动势为零）、$i$ 发生突变的位置，对应图像中的断续与拐点。
5. **绘图像：** 综合以上信息，画出分段恒定的 $i\!-\!t$ 图线或按规律变化的曲线，对比选项选择符合的图线。

## 高频易错
- **有效边遗漏或重复**：线框左右两边同时切割不同磁场时，只算单边电动势，或错误认为两边总抵消。
- **方向叠加弄反**：两边所在磁场方向相反时，两电动势是同向串联还是反向串联？必须用楞次定律或磁通量变化严格判断，不能凭直觉。
- **零电流段失察**：当整个线框完全处于同一匀强磁场中匀速运动时，磁通量不变，感应电流为零，图像中必有一段 $i=0$ 的区间，不可忽略。
- **正负号与选项不一致**：擅自规定正方向而不参考题目图像，导致自己判断的“正”与选项中的“正”错位。应优先根据题目描述的初始状态或图像原点匹配正方向。
- **时间比例算错**：线框边长与磁场宽度相等时，跨越边界产生电流的时间与零电流时间之比为 $1:1$，若线框边长 $l$，磁场宽 $l$，一个周期为 $2l/v$，各段时长需准确对应。

## 代表题精讲
### **题目**（2018·新课标Ⅱ卷）
在同一水平面内的两根平行长导轨间，有宽度均为 $l$、磁感应强度大小相等且方向交替向上向下的依次相邻矩形匀强磁场区域。一边长为 $l$ 的正方形金属线框在导轨上向左匀速运动。线框中感应电流 $i$ 随时间变化的正确图线可能是（    ）

**思路**  
线框边长等于磁场区域宽度，运动过程分为两类状态：① 线框完全处于某一匀强磁场中，磁通量不变，无感应电流；② 线框跨越相邻磁场的边界，左右两边分别在方向相反的磁场中切割磁感线。先判断产生电流时电动势大小和方向，再分析其持续时间和变化规律。

**步骤**  
1. **设物理量**：磁感应强度大小 $B$，线框匀速速度 $v$，总电阻 $R$。  
2. **划分阶段**：以线框左边到达某边界为计时起点，运动 $l/v$ 时间内，框内一直存在向上和向下两部分磁场；接着再经 $l/v$ 时间，整个框完全进入下一均匀磁场，磁通量恒定。  
3. **求跨越边界的电流**：  
   - 跨越时，左边与右边所处磁场方向相反，两有效边切割产生的感应电动势大小均为 $BLv$，且它们的方向在回路中为 **同向串联**（可由楞次定律验证：穿过回路的磁通量在增大或减小，感生电动势阻碍变化，两边的电动势推动电流朝同一方向）。  
   - 总电动势 $E = 2BLv$，电流大小 $i = \frac{2BLv}{R}$，方向恒定。  
4. **完全在区内时**：磁通量不变，$E=0$，$i=0$。  
5. **进入下一边界**：电流大小仍为 $i = \frac{2BLv}{R}$，但方向与上一段跨越时相反，形成反向矩形脉冲。  
6. **画图**：得到一个等宽的正、零、负、零交替的方波，占空比 $50\%$。对照选项，选出具有此特征的图线。

**点评/变式**  
- 本题的陷阱在于将“两边都切割”误认为电动势抵消，从而选错。必须通过磁通量变化或等效电路分析两电动势的连接关系。  
- 常见变式：磁场宽度与线框边长不等，或线框形状变化（如矩形框长宽不同），导致电流为零的时段变化或出现梯形波。解题核心仍是分段分析有效切割与磁通量变化率。
