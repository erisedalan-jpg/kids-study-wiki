## 知识精要
- **电表选择三原则**
  - **安全性**：电表量程必须大于电路中可能出现的最大电压或电流；对小灯泡等元件，取额定值作为下限，同时兼顾电表不致烧毁。
  - **准确性**：在安全前提下，电表读数应尽量靠近满偏的 $\frac{1}{3}\sim\frac{2}{3}$ 以上，以减小相对误差。若量程过大导致指针偏角过小，需考虑改装或换表。
  - **方便性**：滑动变阻器、电阻箱等调节器件应能平滑调节，尽量使被测量在较大范围内变化。
- **电流表的内接与外接**（针对伏安法测电阻或伏安特性）
  - **内接法**（电流表在电压表内）：$R_{测}=\frac{U}{I}=R_x+R_A$，测量值偏大，适用于 $R_x \gg R_A$，即“大内偏大”。
  - **外接法**（电流表在电压表外）：$R_{测}=\frac{U}{I}=\frac{R_xR_V}{R_x+R_V}$，测量值偏小，适用于 $R_x \ll R_V$，即“小外偏小”。
  - 若已知电流表内阻 $R_A$，接入电路后可对测量结果进行修正。
- **电表的非常规使用与改装**
  - 已知内阻的电流表可串联定值电阻改装为电压表，量程 $U = I_g(R_g+R)$。
  - 已知内阻的电压表可并联定值电阻改装为电流表。
  - 此类替代可解决量程不匹配或缺少某种电表的问题，核心是 **“用两表测一表”** 或 **“一表两用”**。
- **滑动变阻器的接法选择**
  - **限流接法**：简单节能，适合 $R_x$ 与 $R$ 相差不大的情况，调节范围较小。
  - **分压接法**：电压调节范围 $0\sim E$，适合要求电压从零开始、多组数据、小阻值控制大阻值等场合，功耗较大。
  - **选择依据**：要求电压从零开始变化、滑动变阻器阻值远小于待测电阻、限流接法无法安全控制，必选分压。

## 解题方法与套路
1. **锁定实验目的与器材**  
   明确是测电阻、描绘伏安特性曲线、还是改装电表。列出所给电表（量程、内阻是否已知）、定值电阻、滑动变阻器、电源等。
2. **画出初步电路框架**  
   确定供电部分（分压或限流）和测量部分（电表与被测元件的串并联关系）。若要求电压从零开始，直接采用分压式。
3. **量程匹配与安全核算**  
   - 找出待测元件的额定值（$U_{\text{额}},I_{\text{额}}$）。  
   - 检查电表量程是否满足：最大工作电压/电流 $\le$ 量程，同时指针偏转不宜过小。  
   - 若量程不合且无法更换，考虑改装：给电流表串、并电阻改用途。
4. **选择电流表内外接**  
   - 若电压表、电流表内阻已知或可估算，比较 $\sqrt{R_AR_V}$ 与 $R_x$ 近似大小。  
   - 已知电流表内阻且希望精确，可采用内接并修正；已知电压表内阻可用外接。  
   - 当只有两只电流表（无电压表）时，可将内阻已知的电流表与定值电阻串联当电压表，此时另一电流表常作外接（测总电流），通过支路电流差值得到待测电流。
5. **实物连线**  
   - 先串后并，分清正负接线柱，电流从正进负出。  
   - 分压电路中，滑动变阻器下方两端接电源，上方一端与下方一端接负载。  
   - 开关闭合前，分压电路滑片置于使负载电压为零的一端，限流电路滑片置于阻值最大端。
6. **列式与数据处理**  
   利用欧姆定律和基尔霍夫定律写出 $U,I$ 表达式，特别注意电表内阻的存在对测量值的影响，必要时进行修正。

## 高频易错
- **只看量程，忽略内阻信息**：题目给出电表内阻往往是暗示需要改装或进行误差修正，不可将其视为理想电表直接计算。
- **内外接选择随意**：不估算 $R_x$ 与 $\sqrt{R_AR_V}$ 的关系，导致系统误差方向判断错误，在要求精确测量的实验中失分。
- **改装电表时量程与安全界限混淆**：如用电流表串联电阻改装成电压表后，原电流表的满偏电流 $I_g$ 仍是安全上限，必须保证工作时流过电流表的电流 $\le I_g$，同时改装后的量程覆盖待测电压。
- **滑动变阻器接法生搬硬套**：部分考生见小灯泡就选分压，但若题目已限定器材且无电压从零开始的要求，限流可能更简洁。关键是看清题干要求：“描绘伏安特性曲线”通常必须分压，因为需要多组数据且包含零电压点。
- **实物连线错误**：分压电路中把滑动变阻器当成串联限流连接；电流表、电压表正负接线柱接反；开关未控制整个电路；导线交叉凌乱。  
- **表达式写混**：在双电流表电路中，计算待测电流时直接用某表读数而忘记减掉并联支路电流，或电压计算未计入定值电阻分压。

## 代表题精讲
### **题目**（2020·新课标Ⅱ·10）
研究小灯泡 $L\,(3.6\text{V},0.30\text{A})$ 的伏安特性。器材：电流表 $\text{A}_1$（量程 $200\,\text{mA}$，内阻 $R_{g1}=10.0\,\Omega$），电流表 $\text{A}_2$（量程 $500\,\text{mA}$，内阻 $R_{g2}=1.0\,\Omega$），定值电阻 $R_0=10.0\,\Omega$，滑动变阻器 $R_1$（$10\,\Omega$），电源 $E\approx4.5\text{V}$ 内阻不计，开关、导线。电路原理如图（a）。
（1）根据图（a）完成实物连线。
（2）若 $\text{A}_1,\text{A}_2$ 读数分别为 $I_1,I_2$，用 $I_1,I_2,R_{g1},R_0$ 表示灯泡端电压 $U=$______，流过灯泡的电流 $I=$______。为保证灯泡安全，$I_1$ 不得超过______$\text{mA}$。

### **思路**
- 解读电路：$\text{A}_1$ 与 $R_0$ 串联后作为“电压表”与灯泡并联；$\text{A}_2$ 串联在干路，测量灯泡与该“电压表”支路的总电流。此为外接法改版，可消除电压表分流引起的系统误差。
- 由小灯泡额定值可知，端电压最大 $3.6\text{V}$，$\text{A}_1$ 满偏时两端电压 $200\text{mA}\times(10+10)\Omega=4.0\text{V}>3.6\text{V}$，量程与安全均满足。干路电流最大约 $0.30\text{A}+0.2\text{A}=0.50\text{A}$，恰在 $\text{A}_2$ 量程内，选择合理。
- 表达式推导：$U=I_1(R_{g1}+R_0)$，灯泡电流 $I=I_2-I_1$。灯泡电压若达 $3.6\text{V}$，则 $I_{1\text{max}}= \frac{3.6}{10+10}=0.18\text{A}=180\text{mA}$，不能超过 $200\text{mA}$ 满偏，故安全上限为 $180\text{mA}$。

### **步骤**
1. **实物连线**：按照图（a）先连接供电回路（电源、开关、滑动变阻器分压接法），再从滑动变阻器的滑动端与下端引出电压到负载。然后将 $\text{A}_2$ 串联在干路，之后灯泡与“$\text{A}_1+R_0$”支路并联。注意 $\text{A}_1$ 的正接线柱接 $R_0$ 后接回灯泡上端，使电流从正接线柱流入。
2. **表达式填空**：由电路结构立即写出  
   $$U = I_1(R_{g1}+R_0),\quad I = I_2 - I_1.$$
3. **安全限额**：由 $U_{\text{额}}=3.6\,\text{V}=I_1(10+10)$，解得  
   $$I_{1\text{max}}= \frac{3.6}{20}=0.18\,\text{A}=180\,\text{mA}.$$  
   填空 $180$。

### **点评/变式**
- 本题以双电流表代替传统“电压表+电流表”，考查对电表功能灵活转换的理解。连接实物时，很多考生不习惯将电流表当电压表使用，错把 $\text{A}_1$ 并联在灯泡两端而不串联 $R_0$，导致改装失效。
- 变式：若将 $\text{A}_1$ 与 $R_0$ 组合改为电压表，但量程要求 $5\text{V}$，可求需串联电阻 $R_x=\frac{U}{I_g}-R_{g1}$。此类改装思想是实验改编题的常客。
- 本题还隐含了系统误差分析：若将 $\text{A}_2$ 直接串联在灯泡支路（内接），则 $\text{A}_1$ 支路分流引入误差；现采用外接通过计算消除。应试时要紧扣电路结构，写出正确 $U,I$ 表达式，切勿漏减 $I_1$。
