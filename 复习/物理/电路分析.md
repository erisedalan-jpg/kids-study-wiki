## 知识精要

- **欧姆定律**：部分电路 $I = \frac{U}{R}$，闭合电路 $I = \frac{E}{R + r}$。适用于纯电阻电路，金属导体与电解液。
- **电阻定律**：$R = \rho \frac{l}{S}$，串联 $R = R_1 + R_2 + \cdots$，并联 $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots$。
- **电功与电热**：$W = UIt$（普适），焦耳热 $Q = I^2Rt$（普适）。纯电阻中 $W = Q = \frac{U^2}{R}t$。
- **电容器充放电**：$i$、$u_C$、$q$ 均按指数规律变化，时间常数 $\tau = RC$。充电完毕时 $u_C = E$，$i = 0$；放电时 $u_C$ 从 $E$ 衰减至 $0$。$i-t$ 曲线与坐标轴所围面积等于该过程中流过某截面的电荷量 $\Delta q$。
- **电磁感应中的电路**：
  - 动生电动势 $E = BLv$（$B$、$L$、$v$ 两两垂直）；感生电动势 $E = n\frac{\Delta \Phi}{\Delta t}$。
  - 内电路与外电路：切割或磁通变化的导体为电源，其余为外电路；电流方向（内电路由低电势到高电势）。
  - 电荷量：$q = \overline{I}\Delta t = \frac{\Delta \Phi}{R_\text{总}}$（仅与磁通变化量和总电阻有关，与时间无关）。
  - 能量关系：克服安培力做功等于回路产生的总焦耳热 $W_\text{安} = Q$，结合动能定理求解速度、热量分配。
- **多用电表**：红表笔接正接线柱，测电压时红表笔接高电势点（电池正极），电流“红进黑出”。

## 解题方法与套路

1. **识别电路结构与元件角色**：
   - 电容器充放电：明确开关位置，确定回路中电阻与电容的串并联，分析暂态过程中 $i$、$u_C$ 的方向和变化趋势。
   - 电磁感应电路：将产生感应电动势的部分视为电源，画出等效电路图，标明内阻 $r$、外电阻连接关系。
2. **应用基本定律列方程**：
   - 稳恒电路：用闭合电路欧姆定律 $I = \frac{E}{R + r}$，结合串并联求电流、电压分配。
   - 电磁感应电路：$E = BLv$ 或 $E = \frac{\Delta \Phi}{\Delta t}$，结合牛顿第二定律、动能定理。
3. **巧用图像与面积**：
   - 电容器充放电 $i-t$ 图中面积代表电荷量 $q = \int i \, dt$。
   - 电磁感应中 $i-t$ 图、$F-t$ 图的形状由 $v$、$B$、切割长度 $l$ 的变化规律决定，遵循“增反减同”、“阻碍相对运动”。
4. **热量与电荷量计算**：
   - 电荷量优先用 $q = \frac{\Delta \Phi}{R_\text{总}}$，避免复杂积分。
   - 回路总焦耳热 $Q$ 等于克服安培力做的功，或由能量守恒求解；定值电阻上的热量按电阻比例分配：$Q_R = \frac{R}{R_\text{总}} Q$。
5. **多用电表使用规范**：
   - 测电压、电流时红表笔接高电势或电流流入端；测电阻需断路、调零。

## 高频易错

- **电容器充放电电流方向混淆**：充电时电流从电源正极流向电容正极板，放电时电流从电容正极板流出；灯泡亮度取决于功率 $P = i^2R$ 或 $P = \frac{u^2}{R}$，放电瞬间电流最大随后减小至零，灯泡应迅速变亮后逐渐熄灭。
- **电磁感应中电源判定错误**：切割的导体才是电源，两侧导轨或外接电阻是外电路。计算热量的电阻对象必须分清内、外，尤其注意题目问的是“电阻 $R_1$ 产生的热量”还是“总热量”。
- **电荷量与平均电流关系滥用**：$q = It$ 只适用于恒定电流，暂态过程中必须用 $q = \frac{\Delta \Phi}{R_\text{总}}$ 或面积法，不可随意代入瞬时电流。
- **$i-t$ 图像分析遗漏关键阶段**：线框进出磁场的过程要分段讨论切割的有效长度和感应电流方向。正方形线框沿对角线方向运动时，切割的有效长度随时间线性变化还是分段线性，需结合几何关系仔细推导。
- **电压表、电流表的内阻忽略条件**：理想情形下忽略，但题目中若给出电阻值，则需纳入串联、并联分析。

## 代表题精讲

### **题目** 2023-新课标-09（电容器充放电实验）
**思路**：分析电路（单刀双掷：1端充电、2端放电），运用 $RC$ 暂态规律和 $i-t$ 图面积的物理意义。
**步骤**：
1. （1）红表笔测电压应接高电势点，即电池正极。
2. （2）开关接2，电容器放电。初始电压 $u_C = E$，放电瞬间 $i_\text{max} = \frac{E}{R_\text{灯}}$，灯泡迅速变亮；随后 $u_C$ 指数衰减，电流减小，灯泡逐渐熄灭。选 C。
3. （3）充电：$R$ 越大，最大电流 $I_0 = E/R$ 越小，充电时间常数 $\tau = RC$ 越大，充电越慢。实线最大值较小，对应电阻 $R_2$（$R_2 > R_1$）。$i-t$ 面积等于电荷量 $q = CU$，即该次充电完成后电容器上的电荷量。
**点评/变式**：常考 $i-t$、$u_C\!-\!t$、$q\!-\!t$ 图像对比；放电时电阻变化对图像的影响与充电类似（时间常数变）。$q-t$ 图面积含义要区分。

### **题目** 2023-新课标-13（电磁感应综合）
**思路**：框进、出磁场均有感应电流，利用动量定理结合电荷量公式求初速度；加导轨后框上、下边与导轨构成回路，分段用能量守恒求 $R_1$ 热量。
**步骤**：
1. （1）设初速 $v_0$，末速 $\frac{v_0}{2}$。全过程中总电荷量 $q = \frac{2BL^2}{4R_0}$（进出各一次磁通变化）。由动量定理：$-B\overline{I}L \cdot \Delta t = -BLq = m\frac{v_0}{2} - mv_0$，解得 $v_0 = \frac{B^2 L^3}{m R_0}$（按原题数据精确结果应为 $v_0 = \frac{B^2 L^3}{mR_0}$，原解为 $\frac{320 B L}{m R}$ 等含混，此处依逻辑推导）。
2. （2）等效电路：框上、下边两条支路，每条边电阻 $R_0$，外接 $R_1 = 2R_0$，框进入、离开磁场过程中切割产生电动势。框完全进入后无感应电流，匀速。全过程框动能减少转化为回路焦耳热。总焦耳热 $Q_\text{总} = \frac{1}{2}mv_0^2 - \frac{1}{2}m\left(\frac{v_0}{2}\right)^2 = \frac{3}{8}mv_0^2$。再按电阻比例分配：等效内阻 $r = \frac{R_0}{2}$（两边并联），外阻 $R_1 = 2R_0$，总电阻 $R_\text{总} = \frac{5}{2}R_0$。$R_1$ 上热量 $Q_{R1} = \frac{R_1}{R_\text{总}} Q_\text{总} = \frac{2R_0}{\frac{5}{2}R_0} \cdot \frac{3}{8}mv_0^2 = \frac{3}{10}mv_0^2$，代入 $v_0$ 可得最终表达式。
**点评/变式**：核心是“框+导轨”的等效电路处理，并联内阻易错；$R_1$ 热量只占总热的一部分，不可直接用 $I^2R_1t$ 因电流变化，比例法最简。

### **题目** 2008-全国Ⅱ-08（$i-t$ 图像选择）
**思路**：导线框沿对角线方向匀速平移，切割磁感线的有效长度随时间变化，分段分析电流大小和方向。
**步骤**：
1. 设框向右上方移动，从磁场左边界进入至完全进入：有效切割长度逐渐增大至 $l$ 再减至 $0$？注意移动方向沿 $ab$（对角线），框的边长恒为 $l$。进入时等效切割的两个边，因磁场边界与边长平行？题中“虚线框对角线ba与导线框一条边垂直”，移动方向沿 $ab$。根据对称性，切割产生的电动势大小随位置呈分段线性变化。进入过程：有效切割长度从 $0$ 线性增加至最大值后线性减小到 $0$，方向逆时针（正）。框完全在磁场内移动，磁通不变，$i=0$。离开过程：有效切割长度先增后减，方向顺时针（负）。
2. 对比选项，电流大小变化为先正三角波，后零，再负三角波。C 选项与此吻合。
**点评/变式**：判断 $i-t$ 图形关键：分段；有效长度 $l_\text{效}$ 计算常用几何关系；注意方向正负规定。变式可将移动方向变为水平、矩形框进入非矩形磁场等。
