## 知识精要
- **等压变化**：一定质量的理想气体，在压强不变时，体积与热力学温度成正比，即**盖‑吕萨克定律**：
  $$\frac{V_1}{T_1} = \frac{V_2}{T_2} \quad (p \text{恒定}, m \text{不变})$$
  推论：$V \propto T$，在 $V–T$ 图中为过原点的倾斜直线。
- **适用条件**：理想气体、质量一定、压强恒定。判定“压强不变”是解题关键。
  - 常见等压模型：气缸活塞系统在**缓慢加热且活塞可自由滑动**（无摩擦）、活塞受力平衡不变、外界大气压恒定、重力恒定等场合，气体压强保持不变。
  - 若活塞面积变化（粗细筒）且有细杆连接，需对双活塞整体受力分析，结合平衡条件判定压强。
- **理想气体状态方程**：$\frac{pV}{T} = C$，当 $p$ 不变时退化为盖‑吕萨克定律。
- **热力学第一定律**：$\Delta U = Q + W$，对准静态等压过程，气体对外做功 $W = -p\,\Delta V$（外界对气体做功 $W = -p\Delta V$），吸收热量 $Q = \Delta U + p\Delta V$。常结合 $V–T$ 关系求温度及内能/热量。

## 解题方法与套路
1. **确定研究对象与状态**：选封闭气体为研究对象，明确初、末状态的 $p、V、T$ 中哪些已知，哪些可由力学平衡求得。
2. **判断是否等压**：
   - 分析活塞或液柱受力。若加热过程中活塞缓慢移动，摩擦不计，且外界大气压、重力等恒力不变，则气体压强不变。
   - 多活塞/变面积情况：对活塞组（含连接杆）整体列力平衡方程，导出气体压强表达式，判断其是否恒定。
3. **选择规律列方程**：
   - 等压变化直接用 $\frac{V_1}{T_1} = \frac{V_2}{T_2}$，体积用活塞截面积与高度乘积表示（$V = S h$）。
   - 若需能量分析，结合热力学第一定律：$\Delta U = Q + W$，$W = -p \Delta V$ 或外界对气体做功 $W_{\text{外}} = -p\Delta V$。
4. **求解并讨论**：统一单位（热力学温度用 K），验证结果物理合理性，注意活塞是否触底、是否越过卡口等约束。

## 高频易错
- **误判压强不变**：认为“缓慢加热”就一定是等压，忽略了活塞被卡口挡住或面积变化导致压强必然改变。必须通过受力分析确认。
- **体积表达错误**：气缸有粗细不同圆筒时，体积需分段计算，注意活塞移动时气体体积变化与各段横截面积的对应关系。
- **温度单位未转换**：盖‑吕萨克定律中 $T$ 必须用开尔文温标（$T = t + 273$），否则比例关系错误。
- **忽略卡口/约束条件**：活塞运动到限制位置后，若继续加热，过程不再等压，需重新分析。
- **做功符号混乱**：热力学第一定律常用 $\Delta U = Q + W$，此时外界对气体做功 $W$ 取正；气体膨胀对外做功 $W$ 取负。计算等压膨胀时常用 $W = -p\Delta V$。

## 代表题精讲
### **2022-全国乙-14**
**题目**：竖直放置的汽缸由粗细两圆柱筒组成，活塞Ⅰ、Ⅱ用轻质细杆连接，两活塞间封闭一定质量理想气体。初始两活塞静止，温度为 $T_0$。缓慢加热气体，已知大气压、活塞质量与截面积。求关联物理量。

**思路**：双活塞细杆连接，系统整体受力平衡以确定气体压强 $p$。因外界大气压、活塞重力均为定值，$p$ 恒定，属等压变化。对气体用 $\frac{V}{T} = C$，体积用两段圆柱的截面积与对应高度表达，联解未知量。

**步骤**：
1. 取两活塞与细杆整体为对象，列平衡方程求气体压强 $p$（$p$ 由大气压、活塞重力、面积等决定且不变）。
2. 写出初态体积 $V_1 = S_1 h_{10} + S_2 h_{20}$，末态体积 $V_2$ 用位移量与截面积表示。
3. 代入 $\frac{V_1}{T_0} = \frac{V_2}{T_2}$ 求末温 $T_2$ 或位移量。
4. 若涉及热量/内能，再用 $\Delta U = Q - p\Delta V$（注意符号制）。

**点评/变式**：连接体活塞问题关键是整体受力判定等压，面积不同不影响压强恒定。若细杆换为弹簧，压强可能变化，不再是等压过程。

### **2018-新课标Ⅱ-14**
**题目**：竖直开口汽缸，卡口 a、b 间距 $h$，a 距缸底 $H$，活塞质量 $m$、面积 $S$，下方密封理想气体，初始活塞在 a 处静止，上下方压强均为 $p_0$、温度 $T_0$。缓慢加热至活塞刚达 b 处。求此时气体温度及气体内能增加量（已知内能 $U = kT$）。

**思路**：活塞未离开 a 与刚离开 a 之间的初始阶段，气体等容升温升压；当压力足以支撑活塞时，活塞开始上升至 b，过程受力平衡不变，气体作等压膨胀。因此分两段：等容升温至活塞启动，再等压膨胀到 b。最终求总温升与能量。

**步骤**：
1. 判断开始运动临界：气体压强 $p_1S = mg + p_0S$，得 $p_1 = p_0 + \frac{mg}{S}$。
2. 等容阶段（a 处）：$\frac{p_0}{T_0} = \frac{p_1}{T_1}$，求出 $T_1$。
3. 等压阶段（活塞运动到 b）：体积从 $V_1 = S H$ 增加到 $V_2 = S(H+h)$，用 $\frac{V_1}{T_1} = \frac{V_2}{T_2}$，得 $T_2 = \frac{V_2}{V_1} T_1 = \frac{H+h}{H} T_1$。
4. 全过程内能增量 $\Delta U = k(T_2 - T_0)$；若需求吸收热量，用 $Q = \Delta U + p_1 S h$。

**点评/变式**：这是“等容+等压”的典型多过程问题。注意活塞运动限制在卡口间，一旦到达 b 后若继续加热，过程将变为等容升压，规律须切换。内能用线性关系 $U=kT$ 是理想气体特征，可直接与温度变化关联。
