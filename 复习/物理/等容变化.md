## 知识精要
- **查理定律（等容变化）**：一定质量的理想气体，在体积保持不变的条件下，压强 $p$ 与热力学温度 $T$ 成正比。  
  $$ \frac{p}{T} = \text{常量} \quad\text{或}\quad \frac{p_1}{T_1} = \frac{p_2}{T_2} $$
  适用条件：理想气体、质量恒定、体积不变。使用热力学温标 $T/\mathrm{K} = t/^\circ\mathrm{C} + 273$。
- **关联知识要点**  
  - 气体压强微观解释：单位时间内气体分子对单位面积器壁的碰撞力；温度升高，分子平均动能增大，体积不变时单位时间碰撞次数增加，压强增大。  
  - 压强计算：液柱压强 $p = \rho g h$，$1\ \mathrm{mmHg} \approx 133\ \mathrm{Pa}$；活塞受力平衡条件 $p_{\text{下}}S = p_{\text{上}}S + mg$（竖直放置，忽略摩擦）。
- **真题考点溯源**  
  - 2018·新课标Ⅱ：加热下方气体 → 先等容升压直到顶起活塞，后等压膨胀。  
  - 2012·新课标：阀门打开前后 $B$ 内等温，最终 $C$ 内气体等容升温，引起液柱高度差变化。

## 解题方法与套路
1. **定对象**：明确哪一部分“一定质量的理想气体”发生等容变化（常为封闭在固定容器或暂未移动活塞下方的气体）。  
2. **析状态**：分别写出初、末状态参量 $(p_1, V, T_1)$、$(p_2, V, T_2)$，注意 $V$ 不变；压强要从受力平衡或液柱差求得。  
3. **列方程**：直接套查理定律 $\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$，或与等压、等温方程联立。  
4. **求解**：统一单位（尤其是压强单位和热力学温度），解出所求的温度、压强或高度差。  
5. **综合过程的分段策略**（如2018题）：  
   - 阶段Ⅰ（等容）：气体升温升压，活塞未动，体积保持为初始值 $HS$；  
   - 阶段Ⅱ（等压）：压强达到临界值后活塞匀速上升，体积增大；  
   - 分段时利用临界条件 $p_{\text{下}}S = p_0S + mg$ 连接两个过程。

## 高频易错
- **温度代换错误**：将摄氏温度 $t$ 直接代入 $\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$，必须换算成开尔文温度 $T = t + 273$（高中近似取 $273$）。  
- **体积不变的误判**：研究对象的气体体积看似“容器固定”，但若有活塞移动过程，开始阶段体积可能不变，误判会导致全程用等容公式。  
- **压强计算遗漏力**：竖直活塞未考虑重力产生的附加压强；液柱压强计算忽略了大气压或连通器关系，如 $p = p_0 \pm \rho g \Delta h$ 符号取反。  
- **单位混乱**：mmHg、cmHg、Pa 混用，导致比例式失效。查理定律要求压强采用相同单位，比例相消即可，无需强制国际单位，但需前后一致。  
- **混淆气体定律**：将等容变化误写成 $pV =$ 常量，或等压变化写成 $\dfrac{p}{T} =$ 常量，记混公式。

## 代表题精讲

### 【代表题1】2012·新课标
**题目简述**  
玻璃泡 $A$（真空）、$B$、$C$ 由U形管与细管连接，$0^\circ\mathrm{C}$ 时阀门S关闭，$B$ 容积是 $A$ 的 $3$ 倍，U形管左低右高 $60\ \mathrm{mmHg}$。打开阀门S系统稳定后左右液面相平；再将右侧水槽加热到一定温度使得左右液面高度差恢复为 $60\ \mathrm{mmHg}$（左高右低）。求 $C$ 内初态压强及加热后水温。

**思路**  
（1）打开阀门S前后 $B$ 内气体等温膨胀，由玻意耳定律求 $B$ 内初、末态压强，再根据 $C$ 与 $B$ 通过液柱连通求 $C$ 初压强。  
（2）加热时 $C$ 中气体体积不变（玻璃泡容积固定），做等容变化，初、末态压强可由液柱差求得，代入查理定律解末温。

**步骤**  
1. 设 $A$ 容积 $V_0$，则 $B$ 容积 $3V_0$，$C$ 容积设为 $V_C$。初态：$B$ 气体体积 $V_{B1} = 3V_0$，压强 $p_{B1}$；$C$ 气体压强 $p_C$。由U形管液面差 $60\ \mathrm{mmHg}$ 知 $p_{B1} = p_C - 60\ \mathrm{mmHg}$（左低右高，即右侧 $C$ 压强比左侧高 $60\ \mathrm{mmHg}$）。
2. 打开S后，$A$、$B$ 连通总体积 $V_{B2} = V_0 + 3V_0 = 4V_0$，末态压强 $p_{B2}$。稳定后U形管液面相平，表明 $p_{B2} = p_C$（等压）。$B$ 内气体等温：$p_{B1}\cdot 3V_0 = p_{B2}\cdot 4V_0$，得 $3p_{B1} = 4p_C$。又 $p_{B1} = p_C - 60$，联立解得 $p_C = 180\ \mathrm{mmHg}$。
3. 加热时 $C$ 内气体等容：$V_C$ 不变，初态温度 $T_1 = 273\ \mathrm{K}$，压强 $p_1 = p_C = 180\ \mathrm{mmHg}$；加热后末态压强 $p_2$：U形管左高右低 $60\ \mathrm{mmHg}$，即 $p_2 = p_{B2} + 60$，而 $B$ 仍在 $0^\circ\mathrm{C}$，因 $A$、$B$ 总体积、温度与打开S后相同，$p_{B2}$ 仍为 $p_C = 180\ \mathrm{mmHg}$（注意此时 $B$ 部分与 $A$ 连通，但温度未变，状态与刚打开S后全系统稳定时相同，压强仍为 $180\ \mathrm{mmHg}$）。所以 $p_2 = 180 + 60 = 240\ \mathrm{mmHg}$。
4. 查理定律：$\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$ → $\dfrac{180}{273} = \dfrac{240}{T_2}$，解得 $T_2 = 364\ \mathrm{K}$，即 $t_2 = 91^\circ\mathrm{C}$。

**点评/变式**  
- 核心陷阱：$B$ 内气体在加热前后经历的过程不同——打开S为等温膨胀，加热时为 $C$ 等容，$B$ 的状态未变（温度保持 $0^\circ\mathrm{C}$），不能误对 $B$ 用等容公式。  
- 变式训练：若将 $B$ 也加热，或初始 $A$ 未抽真空，则需对多个气体对象分别列状态方程，利用液柱高度关系联立求解。

### 【代表题2】2018·新课标Ⅱ  
**题目简述**  
竖直放置的汽缸上端开口，内有卡口 $a$、$b$，$a$ 距底高 $H$，$ab$ 间距 $h$。活塞绝热，质量 $m$，面积 $S$，不计摩擦与厚度。初态活塞静置于 $a$ 处，上下方气体压强均为 $p_0$、温度均为 $T_0$。今用电热丝缓慢加热下方气体，直到活塞刚好到达卡口 $b$。求此时气体的温度。

**思路**  
加热过程分两阶段：  
- 阶段Ⅰ：下方气体等容升温，活塞未离开 $a$，$V = HS$，当压强增大到 $p_1$ 满足 $(p_1 - p_0)S = mg$ 时，活塞开始上移。  
- 阶段Ⅱ：活塞从 $a$ 到 $b$，气体压强恒为 $p_1$，等压膨胀，体积由 $HS$ 变为 $(H+h)S$。  
分别用查理定律和盖‑吕萨克定律求解。

**步骤**  
1. 研究下方一定质量理想气体。初态：$p_0$，$T_0$，$V_0 = HS$。  
2. 临界点（刚离 $a$）：气体仍为体积 $HS$，设此时温度 $T_1$，压强 $p_1 = p_0 + \dfrac{mg}{S}$（由活塞平衡）。  
3. 等容阶段应用查理定律：$\dfrac{p_0}{T_0} = \dfrac{p_1}{T_1}$ → $T_1 = \dfrac{p_1}{p_0}T_0 = \left(1 + \dfrac{mg}{p_0S}\right)T_0$。  
4. 活塞上升阶段为等压过程，压强 $p_1$，温度从 $T_1$ 升至 $T_2$，体积从 $HS$ 变为 $(H+h)S$。盖‑吕萨克定律：$\dfrac{V_0}{T_1} = \dfrac{V_2}{T_2}$ → $\dfrac{H}{T_1} = \dfrac{H+h}{T_2}$，得 $T_2 = \dfrac{H+h}{H} T_1 = \dfrac{H+h}{H} \left(1 + \dfrac{mg}{p_0S}\right) T_0$。

**点评/变式**  
- 关键考点：等容变化的适用条件——体积不变，不局限于“容器固定”的字面描述，活塞受约束未移动时亦是等容。  
- 临界状态的识别：从“静置在卡口”到“刚好离开”，需要力学平衡条件来确定启动压强，这是连接两个子过程的桥梁。  
- 变式：若卡口 $a$ 和 $b$ 位置调换（初始活塞在上方），或汽缸横放，或改为漏气、弹簧连接等，等容规律依然适用，但受力分析会变化。
