## 知识精要
- **胡克定律**：在弹性限度内，弹簧的弹力大小 $F$ 与弹簧的形变量 $x$ 成正比，即  
  $$F = kx$$
  - $k$：劲度系数（刚度系数），单位 $\text{N/m}$，由弹簧自身结构（材料、长度、圈数、横截面积）决定。
  - $x$：弹簧的**形变量**，$x = |l - l_0|$，$l$ 为弹簧实际长度，$l_0$ 为原长（自由长度）。
  - 定律成立条件：弹性限度内；适用于拉伸与压缩。
- **弹力方向**：与使弹簧发生形变的外力方向相反，始终指向恢复原长的方向。
- **弹簧的等效劲度系数**（由真题引申）：
  - **分段弹簧**：若原长为 $l_0$、劲度系数为 $k$ 的弹簧，截取原长的 $\frac{1}{n}$，则截得部分劲度系数变为 $nk$；同样圈数的弹簧，总长度（圈数）越大，劲度系数越小，即 $k \propto \frac{1}{l_0}$。
  - **弹簧串联**（等力）：两根劲度系数分别为 $k_1$、$k_2$ 的弹簧串联，等效劲度系数 $k$ 满足 $\frac{1}{k} = \frac{1}{k_1} + \frac{1}{k_2}$。
  - **弹簧并联**（等形变）：$k = k_1 + k_2$。
- **实验探究**：利用平衡条件 $F = mg = k(x - x_0)$，通过测量不同圈数弹簧的形变量，得出 $k$ 与圈数 $n$（或长度）的关系。

## 解题方法与套路
1. **明确研究对象与原长**：确定弹簧在情景中是否处于原长状态，标出原长 $l_0$ 的位置，区分“长度”和“形变量”。
2. **受力分析列平衡方程**：在弹簧连接体匀速或静止时，利用二力平衡或牛顿第二定律，建立外力和弹力的等式。
3. **正确书写胡克定律表达式**：  
   - 压缩时：$F = k(l_0 - l)$；  
   - 拉伸时：$F = k(l - l_0)$；  
   务必保证 $x$ 为正值，$F$ 为弹力大小。
4. **联立方程求解未知量**：遇到两个不同外力作用下的不同长度，可设原长 $l_0$ 和 $k$ 为未知数，列出方程组消元求解。
5. **处理变圈数/变长度弹簧**：将整根弹簧按圈数等分，视作多段相同小弹簧串联，利用 $k \propto \frac{1}{n}$ 得出局部弹簧的劲度系数，再根据受力相等计算局部形变。
6. **实验数据处理**：若有测量数据，计算形变量 $x = x_{加载} - x_0$，利用 $k = \frac{mg}{x}$ 计算不同圈数对应的 $k$，作图或计算 $k-n$ 关系，验证 $k \propto \frac{1}{n}$。

## 高频易错
- **将弹簧长度直接当作形变量代入公式**：这是最高频错误。必须牢记 $F=kx$ 中的 $x$ 永远是 $|l - l_0|$。
- **混淆“压缩”与“拉伸”的符号**：方程中不画蛇添足加入负号，统一用绝对值 $F = k \cdot |l - l_0|$ 计算大小，方向单独判断。
- **原长 $l_0$ 错误设定**：在拉力变压力的问题中，原长 $l_0$ 在中间，$l_1 < l_0 < l_2$，易列错式子。
- **劲度系数与长度反比的误区**：认为“弹簧越长，$k$ 越大”是错误的。同材料同粗细的弹簧，自由长度越长，劲度系数越小。如半根弹簧的 $k$ 是整根的 2 倍。
- **单位换算与重力加速度取值遗忘**：实验题中质量通常以克给出，需转为千克；$g$ 取题给值（如 $9.80\ \text{m/s}^2$），不可随意取 $10$。
- **实验题中把“指针位置”直接当形变量**：指针位置 $x$ 和 $x_0$ 的差值才是形变量，若 $P_0$ 指 0，则各指针位置差即为该段弹簧的伸长量，需注意对应圈数。

## 代表题精讲

### 代表题1：2010-新课标Ⅰ-02
**题目**  
一根轻质弹簧一端固定，用大小为 $F_1$ 的力压弹簧的另一端，平衡时长度为 $l_1$；改用大小为 $F_2$ 的力拉弹簧，平衡时长度为 $l_2$。拉伸或压缩均在弹性限度内，求弹簧的劲度系数。

**思路**  
压缩和拉伸时弹力大小分别等于 $F_1$、$F_2$。设原长为 $l_0$，压缩时形变量 $x_1 = l_0 - l_1$，拉伸时形变量 $x_2 = l_2 - l_0$。由胡克定律列出两个方程，联立消去未知的原长 $l_0$，即可求出 $k$。

**步骤**  
1. 设弹簧原长为 $l_0$，劲度系数为 $k$。  
2. 压弹簧：$F_1 = k(l_0 - l_1)$  …①  
3. 拉弹簧：$F_2 = k(l_2 - l_0)$  …②  
4. ①+② 得：$F_1 + F_2 = k(l_2 - l_1)$，  
   故 $k = \dfrac{F_1 + F_2}{l_2 - l_1}$。

**点评/变式**  
- 这类题的核心陷阱就是直接用长度列式：错误式子如 $F_1 = k l_1$、$F_2 = k l_2$ 务必避免。  
- 若题目给出的不是压和拉，而是两个不同的拉力且给出对应长度与拉力差值，同样设原长列方程组。  
- 变式：已知 $k$ 和 $l_0$，求某一长度下的弹力，则需先判断形变方向再计算。

### 代表题2：2014-新课标Ⅱ-10
**题目**  
探究弹簧劲度系数 $k$ 与圈数 $n$ 的关系。均匀长弹簧竖直悬挂，总圈数 $60$，$P_0$ 至 $P_6$ 共 $7$ 个指针，位置分别为距悬点 $0,10,20,\dots,60$ 圈。挂 $0.100\ \text{kg}$ 砝码前后，读取各指针位置 $x_0$、$x$。部分测量及计算结果已列出，要求完善表格，并得出 $k$ 与 $n$ 的关系（$g=9.80\ \text{m/s}^2$）。

**思路**  
弹簧各相邻指针之间的部分可视为 10 圈的一段小弹簧。$P_0$ 位置为 0 且固定，则 $P_i$ 的位移 $x - x_0$ 即为从悬点至该指针的那段弹簧（共 $n_i$ 圈）的总伸长量。由该段的弹力等于砝码重力 $mg$，可计算该段弹簧的等效劲度系数 $k_i = \dfrac{mg}{x_i - x_{0i}}$。理论表明，对同材质同粗细的弹簧，其劲度系数与圈数成反比，即 $k = \dfrac{C}{n}$，据此可验证 $k \propto \dfrac{1}{n}$ 或 $k \cdot n = \text{常数}$。

**步骤**  
1. 计算形变量：对于每个指针 $i$，$\Delta x_i = x_i - x_{0i}$（单位 m）。  
2. 计算弹力：挂砝码后，每段（从 0 到 $n_i$ 圈）弹簧的拉力均为 $F = mg = 0.100 \times 9.80 = 0.980\ \text{N}$。  
3. 计算各段等效劲度系数：$k_i = \dfrac{F}{\Delta x_i}$，单位 $\text{N/m}$。  
4. 分析数据：随着 $n$ 增大（圈数增多），$k$ 减小。若以 $\dfrac{1}{n}$ 为横轴、$k$ 为纵轴作图，应为过原点的直线，即 $k \propto \dfrac{1}{n}$。  
5. 得出结论：弹簧的劲度系数与圈数成反比（或与弹簧长度成反比）。

**点评/变式**  
- 此实验本质是弹簧串联性质的验证。整根弹簧可看作 6 段相同小弹簧（每段 10 圈）串联而成，每一小段的劲度系数 $k_{\text{小}} = 6 k_{\text{整}}$。不同圈数下测得的 $k$ 恰好对应不同段数串联的等效劲度系数。  
- 易错点：将单个指针的绝对位置当作形变量；或忘记把圈数 $n$ 换算成长度（若给出每圈间距）。  
- 变式：若已知自由长度和总圈数，可用类似方法求出任意圈数区间的劲度系数，进而预测特定载荷下的伸长量。
