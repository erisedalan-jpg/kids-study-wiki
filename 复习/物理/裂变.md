## 知识精要
- **裂变定义**：重核（质量数通常大于 $200$）被中子轰击后，分裂成两个中等质量数的核，并同时放出 $2\sim3$ 个中子与巨大能量的核反应过程。
- **必备特征**：
  - 反应物一侧必须包含 **一个重核 + 一个中子**（如 $^{235}_{\;92}\text{U} + ^1_0\text{n}$）。
  - 生成物为 **两个中等质量核（$A$ 在 $90\sim140$ 左右）+ 若干个中子**。
  - 电荷数 $Z$ 与质量数 $A$ 守恒。
- **典型方程**（真题对应）：
  $$^{235}_{\;92}\text{U} + ^1_0\text{n} \to ^{140}_{\;54}\text{Xe} + ^{94}_{38}\text{Sr} + 2^1_0\text{n}$$
  （也可为 $^{141}_{\;56}\text{Ba} + ^{92}_{36}\text{Kr} + 3^1_0\text{n}$ 等）
- **链式反应与临界体积**：裂变产生的中子继续引发其他铀核裂变，形成链式反应。只有当铀块体积大于 **临界体积** 时，链式反应才能持续。
- **与其他核反应的区分**：
  - **α衰变**：自发放出 $^4_2\text{He}$，质量数减 $4$，电荷数减 $2$。
  - **β衰变**：放出电子 $^{\;0}_{-1}\text{e}$，质量数不变，电荷数加 $1$（通常为 $\beta^-$）。
  - **聚变**：两个轻核（如 $^2_1\text{H} + ^3_1\text{H}$）结合成较重核，放出中子与能量。
  - **人工转变**：用高能粒子（$^4_2\text{He}$、$^1_1\text{H}$、$^1_0\text{n}$ 等）轰击原子核产生新核，常见于早期核反应发现史。

## 解题方法与套路
**核反应类型判断通用步骤（对应真题分类选择）**：
1.  **看反应物数目与身份**：
    - 若反应物只有 **一个** 核素 $\to$ **衰变**（α或β）。
    - 若反应物有 **两个** 轻核（$A \le 4$） $\to$ 优先考虑 **聚变**。
    - 若反应物为 **一个重核 + 一个中子**（且生成物有多个中子）$\to$ 必定是 **裂变**。
    - 其余两个反应物均有核且无中子的情况 $\to$ **人工转变**。
2.  **看生成物粒子**：
    - 生成 $^4_2\text{He}$ 且反应物只有一个核 $\to$ **α衰变**。
    - 生成 $^{\;0}_{-1}\text{e}$ 且反应物只有一个核 $\to$ **β衰变**（注意 $Z$ 增加 $1$）。
    - 生成多个 $^1_0\text{n}$ 且伴有能量释放 $\to$ **裂变** 或 **聚变**。
3.  **守恒检验**：快速核对质量数 $A$ 总和、电荷数 $Z$ 总和左右相等，排除违背守恒的错误选项。

**考场速断口诀**：“单核变——衰变；轻轻合——聚变；重中裂——裂变；其余核碰核——人工转变。”

## 高频易错
1.  **将β衰变误判为裂变**：β衰变反应物只有一个核，生成物有 $^{\;0}_{-1}\text{e}$，且质量数不变；裂变需中子引发，质量数被拆分。
2.  **忽略裂变方程中的中子**：书写或判断时，必须检查反应物和生成物两侧是否都有 **中子 $^1_0\text{n}$**。漏写中子会导致质量数不守恒或错归为人工转变。
3.  **α衰变与人工转变混淆**：方程左边仅有重核且生成 $^4_2\text{He}$ 为α衰变；若左边有靶核与 $^4_2\text{He}$ 等轰击粒子，则属人工转变（例如卢瑟福发现质子实验 $^{14}_{\;7}\text{N}+^4_2\text{He} \to ^{17}_{\;8}\text{O}+^1_1\text{H}$）。
4.  **聚变条件不清**：聚变反应物必须为轻核（氢同位素为主），不是所有“合二为一”都是聚变。重核俘获中子再分裂不属于聚变。
5.  **链式反应临界体积**：考题常以判断形式出现，临界体积是维持链式反应的最小体积，小于临界体积中子逃逸过多，反应不能自持。

## 代表题精讲
### 代表题：2016·新课标Ⅱ·17
**题目**：判断下列核过程方程的类型（α衰变、β衰变、裂变、聚变），将正确答案标号填入相应位置。
- A. $^{14}_{\;6}\text{C} \to ^{14}_{\;7}\text{N} + ^{\;0}_{-1}\text{e}$
- B. $^{32}_{15}\text{P} \to ^{32}_{16}\text{S} + ^{\;0}_{-1}\text{e}$
- C. $^{238}_{\;92}\text{U} \to ^{234}_{\;90}\text{Th} + ^4_2\text{He}$
- D. $^{14}_{\;7}\text{N} + ^4_2\text{He} \to ^{17}_{\;8}\text{O} + ^1_1\text{H}$
- E. $^{235}_{\;92}\text{U} + ^1_0\text{n} \to ^{140}_{\;54}\text{Xe} + ^{94}_{38}\text{Sr} + 2^1_0\text{n}$
- F. $^2_1\text{H} + ^3_1\text{H} \to ^4_2\text{He} + ^1_0\text{n}$
- 属于α衰变的是____，属于β衰变的是____，属于裂变的是____，属于聚变的是____。

**思路**：
- 单核自发变化的 A、B、C 优先考虑衰变。放出电子为β衰变，放出α粒子为α衰变。
- D 两侧均由核加粒子构成，无中子引发且非轻核结合，属人工转变（虽非本题要求类别，但需排除）。
- E 为重核 + 中子 → 中等核 + 中子，典型裂变。
- F 为轻核氘+氚 → 氦+中子，典型聚变。

**步骤**：
1. **分析 C**：$^{238}_{\;92}\text{U}$ 只有单个核在左，右有 $^{234}_{\;90}\text{Th} + ^4_2\text{He}$，质量数减 $4$，电荷数减 $2$，为 $\alpha$ 衰变。$\to$ 答案 **C**。
2. **分析 A 与 B**：均单个核向左，生成 $^{\;0}_{-1}\text{e}$，质量数不变，电荷数增 $1$，为 $\beta$ 衰变。$\to$ 答案 **A、B**。
3. **分析 E**：左边 $^{235}_{\;92}\text{U} + ^1_0\text{n}$（重核+中子），右边中等核 $^{140}_{\;54}\text{Xe}$、$^{94}_{38}\text{Sr}$ 及 $2^1_0\text{n}$，完全符合裂变。$\to$ 答案 **E**。
4. **分析 F**：左边 $^2_1\text{H} + ^3_1\text{H}$（两个轻核），右边 $^4_2\text{He} + ^1_0\text{n}$，轻核聚合成较重核，为聚变。$\to$ 答案 **F**。
5. D 方程属于人工转变，不在本题归类选项中，直接跳过。

**点评/变式**：
- 此类题的致命失分点是 **β衰变的正负电性** 和 **裂变的中子遗漏**。务必检查生成物有无 $^{\;0}_{-1}\text{e}$ 且质量数不降，裂变方程左右是否均有 $^1_0\text{n}$。
- **变式**：若给出 $^{235}_{\;92}\text{U} + ^1_0\text{n} \to ^{141}_{\;56}\text{Ba} + ^{92}_{36}\text{Kr} + 3^1_0\text{n}$，仍判为裂变；把 F 换成 $^1_1\text{H} + ^1_1\text{H} \to ^2_1\text{H} + ^0_1\text{e}$（太阳内部质子-质子链反应第一步）亦是聚变。
- 牢记裂变与聚变均为质量亏损释放能量，但反应物结构和机制截然不同，利用“重中裂、轻轻聚”口诀可快速锁定。
