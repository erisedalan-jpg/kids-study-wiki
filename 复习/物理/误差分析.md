## 知识精要
- **误差分类**  
  1. **系统误差**：仪器不完善（如零刻度不准、电表内阻）、原理不完善（如忽略摩擦、认定支路电压不变）、条件不满足等导致；测量值总是偏大或偏小，可采取校准、修正公式、改进方法等措施减小。  
  2. **偶然误差**：读数、环境波动等随机因素导致；可通过多次测量取平均值、提高测量精度来减小。
- **螺旋测微器与零误差**  
  螺旋测微器精度通常 $0.01\,\text{mm}$，读数 = 固定刻度（mm）+ 可动刻度（×0.01 mm）– 零误差。零误差是系统误差，未对齐时需记录初始示数，测量结果要扣除。
- **单摆测重力加速度的误差**  
  公式 $g = \frac{4\pi^2 L}{T^2}$，摆长 $L = l_{\text{线}} + \frac{d}{2}$（$d$ 为摆球直径），周期用累积法：$T = \frac{t}{n}$，其中 $n$ 为全振动次数。摆角应在小角度（$<5^\circ$）内。角度盘固定位置若偏上，则指示值小于实际摆角；周期计数若从第 $1$ 次到第 $61$ 次经过最低点，全振动次数为 $n = 30$。
- **伏安法测电阻的内接与外接**  
  - 电流表内接：$R_{\text{测}} = \frac{U}{I} = R_x + R_A$，测量值偏大，适合 $R_x \gg R_A$，通常 $R_x > \sqrt{R_A R_V}$ 时选用。  
  - 电流表外接：$R_{\text{测}} = \frac{U}{I} = \frac{R_x R_V}{R_x + R_V}$，测量值偏小，适合 $R_x \ll R_V$，通常 $R_x < \sqrt{R_A R_V}$ 时选用。
- **半偏法测电表内阻的系统误差**  
  测量电压表内阻时，先满偏，再串电阻箱调至半偏，认为电阻箱读数即电压表内阻。实际支路总电阻增大，分压增大，电阻箱分得的电压大于一半，导致 $R_V' > R_V$。
- **电学实验中的比例法与误差表达式**  
  用两只电压表测电阻（如图），不计电压表内阻：$R_x = \frac{U_2}{U_1} R_0$；考虑电压表内阻 $r_1$、$r_2$：  
  $$R_x = \frac{U_2 R_0 r_1 r_2}{U_1 r_2(R_0+r_1) - U_2 R_0 r_1}$$
- **其他经典误差**  
  - 验证机械能守恒：摩擦、空气阻力、长度测量不准、打点计时器不稳定等。  
  - 验证动量守恒：速度测量（纸带点迹、光电门）不准，相对误差公式 $\left| \frac{\text{碰撞前总动量}-\text{碰撞后总动量}}{\text{碰撞前总动量}} \right| \times 100\%$。  
  - 测电源电动势与内阻：电压表分流、电阻箱不准、图线法处理数据可减小偶然误差。

## 解题方法与套路
1. **识别误差类型**  
   看题干要求判断仪器校准误差、原理不完善还是操作偶然误差，并确定测量值是偏大还是偏小。
2. **螺旋测微器零误差处理**  
   - 先读初态（零刻度未对齐时的示数）记为 $d_0$（可为正或负）。  
   - 再读夹持物体后的示数 $d$。  
   - 物体直径 $D = d - d_0$。
3. **单摆周期与摆角判定**  
   - 摆长 $L$ = 摆线长度 + 摆球半径，注意单位统一。  
   - 累积法求周期：总时间 $t$，从平衡位置开始计时，第 $1$ 次经过到第 $N$ 次经过，全振动次数 $n = \frac{N-1}{2}$，周期 $T = \frac{t}{n}$。  
   - 角度盘位置导致的系统误差：角度盘固定点上移，指针指示的角度偏小；若固定点下移，指示角度偏大。
4. **伏安法内外接选择与误差判断**  
   - 比较 $R_x$ 与 $\sqrt{R_A R_V}$：$R_x$ 较大用内接，较小用外接。  
   - 判断测量值偏大还是偏小：内接测量值 = $R_x + R_A$；外接测量值 = $\frac{R_x R_V}{R_x+R_V}$。
5. **半偏法测电压表内阻误差分析**  
   - 始终明确滑片位置不变，但支路电阻增大，干路电流减小，滑动变阻器分压变化，导致支路电压变大。故电阻箱分压 $> \frac{1}{2}U_{\text{满}}$，所以 $R_V' > R_V$。若滑片位于分压电路的零端（即支路被短路）则无此误差。
6. **相对误差计算及允许范围判定**  
   - 写出动量（或其他量）的理论表达式，代入测量值计算相对误差。  
   - 相对误差 $\delta = \left| \frac{\text{理论值} - \text{测量值}}{\text{理论值}} \right| \times 100\%$，比较 $\delta$ 与允许值。

## 高频易错
- **螺旋测微器未调零**：直接读数未扣除零误差，导致系统误差。  
- **单摆周期计数错误**：将“第1次到第N次经过最低点”的振动次数误算为 $N-1$ 或 $N$，正确全振动次数为 $(N-1)/2$。  
- **角度盘位置误判**：固定在 O 点上方时，摆线与竖直方向的实际夹角大于指示值，误以为摆角较小，引入误差。  
- **内、外接法选择混淆**：死记“大内偏大，小外偏小”但不知比较对象（与 $\sqrt{R_A R_V}$ 比较），误选接法造成错误。  
- **半偏法分析错误**：认为断开 S₂ 前后滑动变阻器滑片左侧电压不变，不能识别支路电压升高的系统误差，错判 $R_V' < R_V$。  
- **电学实验表达式中漏掉内阻**：用两电压表测电阻时，题目要求考虑电压表内阻，但仍按理想情况写出 $R_x = \frac{U_2}{U_1} R_0$，丢分。  
- **相对误差分母用错**：有些题目要求用碰撞前总动量作分母，误用碰撞后或平均值。  
- **单位换算疏忽**：遮光片宽度 $1.00\,\text{cm}$ 与时间 $3.500\,\text{ms}$，计算速度时未统一单位，导致数量级错误。

## 代表题精讲
### 1. 2023·新课标·10
**题目**：用单摆测重力加速度，螺旋测微器初态未对齐（图a），后夹摆球（图b），求直径。角度盘固定在O点上方，判断指示5°时实际摆角大小。摆线长81.50cm，求摆长；从第1次到第61次经过最低点用时54.60s，求周期和重力加速度。

**思路**：螺旋测微器读数扣除零误差；角度盘上移使交点偏离球心，几何关系判定实际摆角更大；摆长加半径；全振动次数 $n = (61-1)/2 = 30$，周期 $T = t/n$。

**步骤**  
（1）读取图(a)零误差：示数为 $0.020\,\text{mm}$（举例），图(b)示数为 $20.000\,\text{mm}$，则摆球直径 $d = 20.000 - 0.020 = 19.980\,\text{mm}$。  
（2）角度盘固定在O点上方，指针指示摆角时，真实摆角为指针和悬挂点连线与竖直方向的夹角，大于角度盘所指示的5°。  
（3）摆长 $L = 81.50\,\text{cm} + \frac{1.9980}{2}\,\text{cm} \approx 82.50\,\text{cm}$。全振动次数 $n = 30$，周期 $T = \frac{54.60}{30} = 1.820\,\text{s}$，由 $g = \frac{4\pi^2 L}{T^2}$ 计算即可。

**点评/变式**：零误差是高频考点，务必先读初态。周期计数可直接套公式 $n = (N-1)/2$，从平衡位置开始计时最可靠。角度盘固定位置偏差属几何关系分析，若下移则指示角偏大。注意最终 $g$ 可能要求保留三位有效数字。

### 2. 2021·全国乙·10
**题目**：测电池电动势与内阻（$E\approx1.5V$，$r<2\Omega$），电压表量程1V、内阻 $R_V=380.0\Omega$，定值电阻 $R_0=20.0\Omega$，电阻箱。要求保护电压表选择初始阻值、推导 $\frac{1}{U}$ 表达式、作 $\frac{1}{U}-R$ 图线处理数据。

**思路**：闭合开关前电阻箱应取较大值以限制电流，防电压表超量程。根据电路结构，写出闭合电路欧姆定律，求出 $\frac{1}{U}$ 与 $R$ 的关系，整理成线性形式，借图线斜率与截距求 $E,r$。

**步骤**  
（1）保护电压表，电阻箱接入阻值应较大，选 $15.0\Omega$（5.0Ω较小可能导致电压表超量程）。  
（3）电路：电压表与 $R_0$ 并联后再与电阻箱 $R$ 串联，然后接电源。总外电阻：并联部分 $R_{\text{并}} = \frac{R_V R_0}{R_V+R_0}$，干路电流 $I = \frac{E}{R + R_{\text{并}} + r}$。电压表读数 $U = I \cdot R_{\text{并}}$，从而 
$$\frac{1}{U} = \frac{R + R_{\text{并}} + r}{E R_{\text{并}}} = \frac{1}{E R_{\text{并}}} R + \frac{R_{\text{并}}+r}{E R_{\text{并}}}$$  
（4）由 $\frac{1}{U}-R$ 图线，斜率为 $k = \frac{1}{E R_{\text{并}}}$，截距 $b = \frac{R_{\text{并}}+r}{E R_{\text{并}}}$，可解 $E$ 和 $r$。

**点评/变式**：本题关键是把电压表视为能显示自身电压的电阻，并联阻值预先算出。保护电路思想贯穿始终：选择电阻箱阻值、图线法减少偶然误差。若将 $R_0$ 换成已知内阻的电流表，思想类似。

### 3. 2015·新课标Ⅱ·10
**题目**：用半偏法测电压表内阻（量程3V，内阻约3000Ω），提供电阻箱、滑动变阻器、电源等。设计电路，写出步骤，并分析测量值与真实值的大小关系及理由。

**思路**：滑动变阻器采用分压接法，待测电压表与电阻箱串联。先闭合两开关调滑片至满偏，保持滑片不动，断开$S_2$调节电阻箱至半偏。由于支路电阻增大，分压变大，电阻箱电压大于一半，故测量值偏大。

**步骤**  
（1）电路图：滑动变阻器作为分压器，下面两个接线柱接电源，上面一个与滑片相连，分出可调电压，电压表与电阻箱串联后接在分压输出端，开关 $S_2$ 并联在电阻箱两端。  
（2）操作：移动滑片使输出分压最小 → 闭合 $S_1$、$S_2$ → 调滑片使电压表满偏 → 保持滑片不动 → 断开 $S_2$ → 调电阻箱使电压表半偏 → 电阻箱读数即 $R_V'$。  
（3）结果：$R_V' > R_V$。理由：断开 $S_2$ 后，支路总电阻变大，分压大于满偏电压，当电压表半偏时，电阻箱分担的电压大于满偏电压的一半，故阻值大于真实内阻。

**点评/变式**：半偏法系统误差属于必考难点。若测电流表内阻，也类似。改进方法：使用高阻值滑动变阻器（或用电源与定值电阻限流）接近恒流源，可减小误差。注意实验条件表述要准确，“保持滑片位置不变”是核心。
