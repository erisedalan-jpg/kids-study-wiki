## 知识精要
运动学核心是描述物体位置变化快慢及变化规律的物理分支，高考侧重匀变速直线运动与牛顿运动定律的联动分析。
- 匀变速直线运动基本公式（$v_0$为初速度，$a$为加速度，$t$为时间，$x$为位移，$v$为末速度）：
  $$v = v_0 + a t, \quad x = v_0 t + \frac{1}{2}a t^2, \quad v^2 - v_0^2 = 2 a x, \quad x = \frac{v_0+v}{2}t$$
- 平均速度公式：$\bar{v} = \frac{x}{t}$；匀变速直线运动中，某段时间中间时刻的瞬时速度等于该段时间的平均速度：$v_{t/2} = \bar{v}$。
- 牛顿第二定律：$F_{\text{合}} = m a$，要求受力分析准确（通常结合重力、弹力、摩擦力、安培力等），合力方向决定加速度方向。
- 摩擦力（动摩擦）：$f = \mu N$，方向与相对运动方向相反；静摩擦力随外力变化，有最大值。
- 安培力：通电导体垂直磁场时 $F_{\text{安}} = BIL$，方向由左手定则判断；感应电流 $I = \frac{BLv}{R}$（单棒切割），由此可得 $F_{\text{安}} = \frac{B^2 L^2 v}{R}$，常见于电磁感应综合题中的运动和受力分析。
- 运动图像：$x-t$、$v-t$、$a-t$ 图，以及从图像提取斜率、截距、面积对应物理量。$v-t$ 图斜率是加速度，面积是位移；$I-t$ 图像（感应电流）间接反映速度变化，常用于分析电磁驱动或制动问题。
- 实验测量加速度：光电门测速 $v = \frac{d}{\Delta t}$（$d$为挡光宽度），利用 $v^2 - v_0^2 = 2a x$ 或 $v=v_0+at$ 求加速度；也可通过 $v-t$ 图拟合斜率得到。

## 解题方法与套路
1. **对象与过程拆分**：划分运动阶段（如进入磁场前、磁场中、出磁场后），对每个阶段选定研究对象，明确初末速度、加速度、位移和时间关系，尤其关注临界态（如“恰好”“刚好”“匀速”等条件）。  
2. **受力与运动双向分析**：由运动状态反推合力（例如匀速$\Rightarrow$合力为零；匀加速$\Rightarrow$合力恒定且方向与加速度同向）。用牛顿第二定律列式时，优先沿加速度方向建立坐标系，分解力。  
3. **多物体联动（绳连接体）**：整体法与隔离法灵活切换。绳拉直且无质量，则两端物体加速度大小相等；利用整体法求共同加速度，隔离法求绳的拉力或相互作用力。  
4. **电磁感应中的运动分析**：先计算感应电动势 $E=BLv$ 或 $E=\frac{\Delta \Phi}{\Delta t}$，再求感应电流 $I$ 和安培力 $F = BIL$，将安培力代入牛顿第二定律，得到含速度 $v$ 的动力学方程。常出现 $F_{\text{合}} = mg\sin\theta - \frac{B^2 L^2 v}{R}$ 等形式，令 $a=0$ 可求匀速速度。  
5. **实验题：平均速度与瞬时速度关系**：用挡光片宽度除遮光时间得平均速度，若要获得更接近瞬时速度的值，应该减小挡光片宽度；利用多个不同位置的平均速度数据，通过公式法（$v^2 = v_0^2 + 2 a x$）或图像法（$v^2-x$ 图为直线）求加速度。  
6. **最小加速度与追及问题**：冰球减速运动，运动员加速运动，建立两者位移-时间关系，利用到达条件建立等式（如冰球到达挡板时运动员至少到达小旗），求出加速度的最小值。

## 高频易错
- **摩擦力方向判断失误**：运动物体所受摩擦力方向与相对运动方向相反，不是简单与速度方向相反。在斜面导体框与金属棒相互运动时，需要明确两者相对运动趋势，列隔离方程时容易搞错正负号。  
- **“匀速运动一段时间后开始加速”的临界点理解模糊**：当外力（如重力分力）与阻力（如安培力、摩擦力）平衡时匀速；一旦某一条件改变（如EF边离开磁场，安培力消失），合力不再为零而加速。  
- **电磁感应中安培力做功与速度关系混淆**：安培力 $F \propto v$，但不是恒力，匀变速假设不成立；只有在“匀速”或给定电流等特殊条件下才可作为恒力处理。  
- **连接体加速度关系直接套用$mg/(M+m)$**：若滑轮无摩擦但绳质量不计，两端物体加速度大小相等，但要考虑两个物体受力方向可能不同。绳拉着小球下落测量加速度时，不能忽略绳被张紧时两者加速度相同，但若小球质量不同，对整体应用牛顿第二定律时要注意方向规定。  
- **平均速度代替瞬时速度的条件不清**：光电门实验中，挡光时间内的平均速度可近似等于通过光电门时的瞬时速度，前提是挡光片宽度足够窄且通过过程可视为匀速。考题中常设置宽度变化来判断误差来源。  
- **图像题误读纵轴物理量**：题目给出$I-t$图，若不注意$I$的方向变化或零值点对应的运动状态，容易错选。

## 代表题精讲
### **题目**（2021-全国乙-12）  
光滑斜面倾角 $\alpha$（$\sin\alpha=0.6$），顶端 U 型导体框质量 $M=0.06\,\text{kg}$，电阻不计。金属棒 CD 质量待求，电阻 $R=3\,\Omega$，长度 $L=0.6\,\text{m}$，与框构成矩形回路；初始 CD 与 EF 相距 $s_0=0.4\,\text{m}$。同时静止下滑，CD 下滑 $s_1=\frac{3}{16}\,\text{m}$ 后进入垂直于斜面的匀强磁场 $B=1\,\text{T}$，在磁场中匀速运动；CD 离开磁场瞬间，EF 边恰好进入磁场，并匀速一段后开始加速。求：  
（1）金属棒在磁场中所受安培力大小；  
（2）金属棒质量及金属棒与导体框间动摩擦因数。

**思路**  
分阶段分析两物体的运动。第一阶段（进入磁场前）：两者一起匀加速，可用整体法求加速度及进入磁场时的速度。第二阶段（CD在磁场中匀速）：CD受力平衡，安培力 $F_{\text{安}} = \frac{B^2 L^2 v}{R}$，同时框仍在磁场外加速，二者有相对运动趋势，产生摩擦力。第三阶段（CD出磁场、EF边进磁场）：由位移关系可推出金属棒与框的相对位移，利用匀速条件与牛顿第二定律隔离列方程，最终解出质量 $m$ 和动摩擦因数 $\mu$。

**步骤**  
1. 整体下滑到CD进入磁场：由 $\alpha$ 知 $\sin\alpha=0.6$，重力沿斜面分力加速度 $a_0 = g\sin\alpha = 6\,\text{m/s}^2$。因此进入磁场时速度 $v_0 = \sqrt{2 a_0 s_1} = \sqrt{2\times 6 \times \frac{3}{16}} = 1.5\,\text{m/s}$。  
2. CD在磁场匀速，安培力与 CD 沿斜面方向合力平衡。CD 切割产生电动势 $E=BLv_0$，电流 $I = \frac{BLv_0}{R}$，安培力 $F_{\text{安}} = BIL = \frac{B^2 L^2 v_0}{R} = \frac{1^2 \times 0.6^2 \times 1.5}{3}=0.18\,\text{N}$。此为第（1）问答案。  
3. CD匀速时，对金属棒写平衡方程（沿斜面向下为正）：重力的分力 $m g \sin\alpha$，向上受到摩擦力 $f$、安培力 $F_{\text{安}}$。即 $m g \sin\alpha = f + F_{\text{安}}$。反之，对导体框：沿斜面受重力分力 $M g \sin\alpha$ 和金属棒给的摩擦力 $f$（反向），因框仅在摩擦力作用下运动（无其他阻力），其加速度 $a_{\text{框}} = \frac{M g \sin\alpha + f}{M}$。  
4. CD在磁场中匀速运动的时间 $t = \frac{L}{v_0} = \frac{0.6}{1.5}=0.4\,\text{s}$。这段时间内框的位移 $s_2 = v_0 t + \frac{1}{2} a_{\text{框}} t^2$。已知CD进入磁场前框前移了$s_1$，CD长 $L=0.6\,\text{m}$，且CD离开磁场时框的EF边恰进入磁场，说明从初始到EF边进磁场，框移动总距离为 $s_0 + L$（初始间隙+金属棒长度），由此可列出位移方程：$s_1 + s_2 = s_0 + L$。代入数值求解 $a_{\text{框}}$，再代回牛顿方程可得 $f$ 和 $m$。  
5. 计算得 $m=0.02\,\text{kg}$，动摩擦因数 $\mu = \frac{f}{m g \cos\alpha}$，其中 $\cos\alpha=0.8$，解得 $\mu = 0.375$。

**点评/变式**  
该题将匀变速运动、平衡条件、安培力、摩擦力综合于多物体系统中，关键是把运动阶段的时间关联与位移关联理清。常见变式：更换磁场方向、存在初始速度、另一根棒也切割等，需坚持“受力定运动、运动找位移、位移搭桥梁”的思路。

### **题目**（2020-新课标Ⅱ-09）  
用跨过定滑轮的细绳连接小球A和B，静止释放后测小球B的加速度。实验装置及数据（略），要求根据纸带或给定信息求当地重力加速度。

**思路**  
在忽略滑轮摩擦且绳无质量前提下，A、B加速度大小相等。由整体法：总受力为 $(m_B - m_A) g$（视B下落），总质量 $m_A+m_B$，得加速度 $a = \frac{m_B - m_A}{m_B + m_A} g$。实验通过测加速度再反推重力加速度或验证关系。

**步骤**  
1. 设B质量大于A，释放后B竖直向下、A竖直向上匀加速。  
2. 整体法列式：$(m_B - m_A) g = (m_B + m_A) a$。  
3. 若已知两小球质量、测得 $a$，则 $g = \frac{m_B + m_A}{m_B - m_A} a$。  
4. 实验测量 $a$ 可通过打点计时器纸带逐差法或光电门测速度再算斜率得到，注意减少摩擦与滑轮质量影响。

**点评/变式**  
此模型若绳子绕过动滑轮或斜面连接，加速度约束关系会改变，需重新用隔离法找加速度关联。考试中容易忘记两个物体加速度大小相等而直接对单物体写 $mg = ma$ 导致错误。

### **题目**（2019-新课标Ⅱ-08）  
平行金属导轨倾斜放置，区域 ab-cd 有垂直导轨平面的匀强磁场。两根相同导体棒 PQ、MN 先后从同一位置静止释放，PQ 进入磁场时加速度恰好为零。从PQ进入磁场开始计时，到MN离开磁场区域为止，流过PQ的电流随时间变化的图象可能正确的是哪个选项？

**思路**  
PQ以速度 $v_0$ 进磁场时 $mg\sin\theta = \frac{B^2 L^2 v_0}{R}$ 而匀速。MN稍后从同一位置释放，进入磁场前做同样匀加速，进入时速度也是 $v_0$，则进入瞬间安培力等于重力分力，也加速度为零。因PQ仍在磁场中，两棒均在磁场内且等速，回路总电动势为零，电流消失。当PQ出磁场后，只剩MN切割产生电流，反向。据此描出 $I-t$ 图轮廓。

**步骤**  
1. 分析关键时间点：PQ刚入磁场电流为 $I_0 = \frac{BLv_0}{R}$，方向设正。  
2. PQ匀速，MN匀加速直至进入磁场，此间回路中只有PQ切割，电流恒定。  
3. MN进入磁场瞬间速度也为 $v_0$，两棒等速且同向，感应电动势抵消，回路电流突变为零并持续到PQ出磁场。  
4. PQ出磁场，MN仍在磁场中，电流反向，大小仍为 $I_0$；MN匀速直至离开磁场，电流归零。最终图像选用“正恒定—突降至零—反向恒定—归零”的阶梯状。

**点评/变式**  
此类双棒问题核心是相对速度和回路电动势叠加。变式考查：若导轨间距不同或电阻不等，电流变化会更复杂，但仍可按时间轴划分阶段，逐一确定等效电动势。
