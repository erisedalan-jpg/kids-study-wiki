## 知识精要
- **追及与相遇的本质**：两物体在同一时刻到达同一位置（位移相等）。分析时关注速度关系与位移关系。
- **核心方程**  
  - 位移关系：$x_{\text{前}} + x_0 = x_{\text{后}}$（$x_0$ 为初始间距，前物在前、后物在后）  
  - 速度关系：追及过程中若后物速度小于前物，间距增大；后物速度大于前物，间距减小。**速度相等**是间距出现极值（最远/最近）的临界条件。
- **$v-t$ 图象中的关键量**  
  - 图线与 $t$ 轴围成的**面积**表示位移。  
  - **交点**（速度相等）对应距离极值时刻；**位移相等**对应面积之差等于初始间距。  
  - 图象斜率表示加速度：$a = \frac{\Delta v}{\Delta t}$。
- **相互作用型追及**：若仅两物体间存在相互作用力，由牛顿第三定律知 $F$ 等大反向，则加速度与质量成反比：$\frac{a_1}{a_2} = \frac{m_2}{m_1}$（光滑或忽略其他外力时）。

## 解题方法与套路
1. **审题与建图**  
   明确两物体的初始位置关系（谁前谁后、间距 $d$），画出运动草图或直接利用题给的 $v-t$ 图象。
2. **抓住关键节点**  
   - 速度相等的时刻 $t_0$：此时若未相遇，则距离为最值。  
   - 位移相等的时刻 $t_1$：对应相遇时刻，由 $v-t$ 图象中面积差等于初始间距或面积相等得出。
3. **利用图象面积、斜率解题**  
   - 追及问题优先用 $v-t$ 图象：位移 = 面积；相遇条件 = 面积关系。  
   - 涉及加速度的用斜率；涉及力与运动的用牛顿第二定律结合加速度比。
4. **列方程求解**  
   - 若求时间或位移，直接对面积关系列一次方程。  
   - 若求质量比、力等物理量，先由图象斜率求加速度，再与牛顿定律结合。
5. **检验结果的合理性**  
   相遇次数是否符合实际（如已追上后是否会再次拉开），所求时间是否在图象定义域内。

## 高频易错
- **混淆速度相等与位移相等**：速度相等时间距最远或最近，不一定相遇；相遇必须位移相等（或面积满足关系）。  
- **无视初始间距**：两物体不从同一位置出发时，直接比较面积大小会误判相遇时刻，必须加上初始位移差。  
- **误认图象交点就是相遇点**：$v-t$ 图象中曲线交点仅表示该时刻速度相同，不代表位移相同。  
- **相互作用力分析不完整**：仅在两物体间有相互作用时，合外力为 $0$（或系统所受合力为 $0$），可用动量守恒；若仅知相互作用力，切勿错误引入外力。  
- **加减速方向混淆**：减速运动的位移仍在增加，直到速度减为零后反向时才可能减小，处理匀减速时注意停止时间。

## 代表题精讲
### 代表题一：2009-全国Ⅱ-02（利用 $v-t$ 图象分析相互作用追及与质量比）
**题目**  
两物体甲和乙在同一直线上运动，$0\sim0.4\,\text{s}$ 内的 $v-t$ 图象如图所示。若仅在两物体之间存在相互作用，且已知图中 $t_1$ 时刻两物体速度相同（均为 $1\,\text{m/s}$），乙的初速度为 $4\,\text{m/s}$，在 $t=0.4\,\text{s}$ 时乙的速度恰好减为零。求甲、乙的质量比及 $t_1$ 的值。

**思路**  
本题为相互作用力下的追及过程。只需从图象斜率获取加速度大小，再利用牛顿第二、三定律即可得质量比；$t_1$ 由乙的匀减速运动规律求出。追及中的速度相等时刻为已知临界条件。

**步骤**  
1. **求乙的加速度**：乙从 $v_{\text{乙0}}=4\,\text{m/s}$ 匀减速到 $0$ 历时 $0.4\,\text{s}$，加速度  
   $$a_{\text{乙}} = \frac{0-4}{0.4}\,\text{m/s}^2 = -10\,\text{m/s}^2$$（大小为 $10\,\text{m/s}^2$）。  
2. **求时间 $t_1$**：乙在 $t_1$ 时刻速度 $v=1\,\text{m/s}$，由 $v = v_{\text{乙0}} + a_{\text{乙}}t_1$，  
   $$1 = 4 - 10 t_1 \quad\Rightarrow\quad t_1 = 0.30\,\text{s}.$$  
3. **求甲的加速度**：甲从静止匀加速，$t_1$ 时刻速度也为 $1\,\text{m/s}$，故  
   $$a_{\text{甲}} = \frac{1-0}{0.30}\,\text{m/s}^2 = \frac{10}{3}\,\text{m/s}^2.$$  
4. **求质量比**：两物体仅受彼此间的相互作用力，由牛顿第三定律力大小相等，因此加速度与质量成反比：  
   $$\frac{a_{\text{甲}}}{a_{\text{乙}}} = \frac{m_{\text{乙}}}{m_{\text{甲}}} \quad\Rightarrow\quad \frac{m_{\text{甲}}}{m_{\text{乙}}} = \frac{a_{\text{乙}}}{a_{\text{甲}}} = \frac{10}{\frac{10}{3}} = 3.$$  
   即甲、乙质量比为 $3:1$。

**点评/变式**  
- 本题看似求质量比，实则完全依托于追及过程中速度相等的临界信息。$v-t$ 图象的斜率直接给出加速度，而速度相等的时刻往往是解题的突破口。  
- 变式：若给出初始间距，要求判断 $t_1$ 时刻两物体是否相遇或相距最值，则需比较面积差。例如：若甲在乙后方 $d$，$t_1$ 时刻两物体速度相等，此时面积差为某值，可求最远距离或相遇条件。
