## 知识精要
- **匀变速直线运动的判别**：在匀变速直线运动中，若物体在连续相等时间间隔 $T$ 内的位移分别为 $x_1,\,x_2,\,x_3\cdots$，则任意相邻两段位移之差为恒量，即 $\Delta x = x_{n}-x_{n-1}=aT^2$。若实验数据中相邻位移差在误差范围内近似相等，则可判定物体做匀变速直线运动。
- **逐差法求加速度的基本原理**：利用 $\Delta x = aT^2$，对多段位移数据可分段相减、取平均以减小偶然误差。常用处理方式：把连续偶数段位移等分两组（例如6段），则加速度
  $$a = \frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T^2}$$
  若为4段，则 $a = \dfrac{(x_3+x_4)-(x_1+x_2)}{4T^2}$。奇数段时常舍弃最短的一段或采用相邻差值求平均。
- **瞬时速度的测量**：匀变速直线运动中，某段时间内中间时刻的瞬时速度等于该段平均速度，即
  $$v_{t/2} = \overline{v} = \frac{x}{t}$$
  常用来求纸带或雷达数据中某点的速度。
- **适用条件**：物体做匀变速直线运动（加速度恒定），等时间间隔 $T$ 已知。实验数据需满足“位移”为连续相等时间内的位移，不能直接用位置坐标代入。

## 解题方法与套路
1. **算位移，判性质**  
   从表格或纸带读取位置坐标 $x_i$，计算相邻相等时间 $T$ 内的位移：$s_1=x_1-x_0$，$s_2=x_2-x_1$，$\cdots$。求出相邻位移之差 $\Delta s_i = s_{i+1}-s_i$。若 $\Delta s_i$ 近似常数，说明物体做匀变速直线运动（常为匀加速），此为运用逐差法的前提。
2. **求瞬时速度**  
   某点（或某位置）的速度用其前后相邻时间段内的平均速度代替。如第 $n$ 个时间间隔末的速度可用 $v_n = \dfrac{x_{n+1}-x_{n-1}}{2T}$，或者 “0到2T”内的平均速度。注意找准对应的时间中点。
3. **加速度的求解**  
   - **基本逐差法**：若有连续6段位移 $x_1\sim x_6$，直接套公式 $a=\dfrac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T^2}$。
   - **通用均值法**：依次计算 $\Delta x_i = s_{i+1}-s_i$，再求平均值 $\overline{\Delta x}$，由 $a = \dfrac{\overline{\Delta x}}{T^2}$ 得到结果。两种方法本质等价。
   - **注意事项**：代入的位移必须是相同时间间隔内的位移，不能拿位置坐标直接相减后除以时间的平方。
4. **有效数字与单位**  
   按题目要求保留有效数字（如保留2位有效数字），注意单位统一为国际单位制（m, s, m/s²）。

## 高频易错
- **误把位置坐标当位移**：将表格中的 $x$ 值直接代入 $\Delta x = aT^2$ 或速度公式，忘记先求各段时间内的位移 $s_i = x_i - x_{i-1}$。
- **时间间隔 $T$ 算错**：题目若给出“每隔1 s测一次”，则 $T=1\,\text{s}$；若用逐差法公式计算加速度时，分母的 $9T^2$、$4T^2$ 中的 $T$ 不可平方遗漏。
- **平均速度对应时刻判断错误**：用 $\frac{x_2-x_0}{2T}$ 求速度时，这是 $t_1$ 时刻的瞬时速度，而非 $t_0$ 或 $t_2$。题目中“当 $x=507\,\text{m}$ 时”其实是第一段结束时刻，对应 $0\sim2\,\text{s}$ 的中间时刻 $t=1\,\text{s}$，故 $v=\frac{1094-0}{2}=547\,\text{m/s}$。
- **加速度公式混用**：未判断物体是否做匀变速就使用逐差法；或数据段数为奇数时直接套用偶数段公式导致错位。
- **有效数字与单位不匹配**：结果不带单位，或没按要求保留2位有效数字（如把79写成79.0）。
- **忽略“保留2位有效数字”**：计算平均值时需四舍五入至相应位数，如79.4保留2位为79。

## 代表题精讲
### 代表题：2022-全国乙-09
**题目** 雷达每隔1 s测量飞行器位置 $x$，数据如表，判断飞行器近似做匀加速直线运动，求 $x=507\,\text{m}$ 时的速度和整个过程的加速度（保留2位有效数字）。

| $t$/s | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|-------|---|---|---|---|---|---|---| 
| $x$/m | 0 |507|1094|1759|2505|3329|4233|

**思路**  
先求连续1 s内的位移及其差值，以确认匀加速；利用平均速度求第1 s末的速度；用6段位移的逐差法求加速度。

**步骤**  
1. 计算相邻1 s内的位移：  
   $s_1 = 507-0 = 507\,\text{m}$，  
   $s_2 = 1094-507 = 587\,\text{m}$，  
   $s_3 = 1759-1094 = 665\,\text{m}$，  
   $s_4 = 2505-1759 = 746\,\text{m}$，  
   $s_5 = 3329-2505 = 824\,\text{m}$，  
   $s_6 = 4233-3329 = 904\,\text{m}$。  
2. 相邻位移之差：  
   $\Delta s_1 = 587-507=80\,\text{m}$，  
   $\Delta s_2 = 665-587=78\,\text{m}$，  
   $\Delta s_3 = 746-665=81\,\text{m}$，  
   $\Delta s_4 = 824-746=78\,\text{m}$，  
   $\Delta s_5 = 904-824=80\,\text{m}$。  
   这些差值在80 m附近，近似相等，故飞行器近似做匀加速直线运动。
3. 求 $x=507\,\text{m}$ 时飞行器的速度：此位置对应 $t=1\,\text{s}$ 时刻，为0～2 s的中间时刻。  
   $$v = \frac{x_2 - x_0}{2T} = \frac{1094 - 0}{2 \times 1} = 547\,\text{m/s}.$$
4. 求加速度：采用逐差法，$T=1\,\text{s}$。  
   $$a = \frac{(s_4+s_5+s_6)-(s_1+s_2+s_3)}{9T^2} = \frac{(746+824+904)-(507+587+665)}{9\times 1^2} = \frac{2474-1759}{9} \approx \frac{715}{9} \approx 79.44\,\text{m/s}^2.$$
   保留2位有效数字，得 $a \approx 79\,\text{m/s}^2$。

**点评/变式**  
本题将打点计时器模型迁移至雷达测距情境，核心方法不变。关键陷阱：$x$ 是位置，不是位移；第（2）问中的速度对应 $t=1\,\text{s}$，而非0 s或2 s；逐差法分母勿忘 $9T^2$。变式练习：若表格给出奇数组数据（如5段），可舍弃第一段或最后一段，再用逐差法；或直接求相邻差的平均值求加速度。
