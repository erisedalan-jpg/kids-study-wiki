## 知识精要
- **光电效应与截止频率**  
  金属中的电子吸收光子能量后逸出，所需的最小能量为逸出功 $W_0$。恰好能发生光电效应的入射光频率称为截止频率 $\nu_0$，对应的波长 $\lambda_0 = \frac{c}{\nu_0}$。逸出功公式：  
  $$W_0 = h\nu_0 = h\frac{c}{\lambda_0}$$  
  式中 $h$ 为普朗克常量，$c$ 为真空光速。

- **爱因斯坦光电效应方程**  
  光子能量 $h\nu$ 一部分用于克服逸出功 $W_0$，剩余部分转化为光电子的最大初动能 $E_{km}$：  
  $$E_{km} = h\nu - W_0 \quad (\nu \ge \nu_0)$$

- **遏止电压 $U_c$**  
  在光电管两端施加反向电压，当光电流恰好为零时，电场力做功等于最大初动能：  
  $$eU_c = E_{km}$$  
  从而得到遏止电压表达式：  
  $$U_c = \frac{h\nu - W_0}{e} = \frac{hc}{e}\left(\frac{1}{\lambda} - \frac{1}{\lambda_0}\right)$$  
  注意：$U_c$ 仅与入射光频率（或波长）和金属的逸出功有关，与入射光强度无关。

## 解题方法与套路
1. **明确已知量与所求量**  
   从题目中找出金属的截止波长 $\lambda_0$（或截止频率 $\nu_0$）、入射光波长 $\lambda$（或频率 $\nu$）、电子电量 $e$、光速 $c$、普朗克常量 $h$ 等。
2. **先求逸出功**  
   若题目未直接给出 $W_0$，利用 $W_0 = \frac{hc}{\lambda_0}$ 或 $W_0 = h\nu_0$ 计算。
3. **写出光电效应方程**  
   根据 $E_{km} = h\frac{c}{\lambda} - W_0$（或 $h\nu - W_0$）求最大初动能。
4. **联系遏止电压**  
   利用 $eU_c = E_{km}$ 解得 $U_c = \frac{E_{km}}{e}$，代入整理成题目要求的表达式。
5. **化简结果**  
   必要时将表达式统一用已知物理量表示（如 $U_c = \frac{hc}{e}(\frac{1}{\lambda} - \frac{1}{\lambda_0})$），并注意单位。

## 高频易错
- **混淆截止频率与入射光频率**  
  截止频率（或截止波长）是金属自身的属性，与入射光无关。计算逸出功时必须使用截止频率对应的 $\lambda_0$，而非入射波长 $\lambda$。
- **误用 $E_{km} = \frac{1}{2}mv^2$ 与 $eU_c$ 的关系**  
  遏止电压对应的电场力做功 $eU_c$ 等于最大初动能，不是光子的全部能量，注意不要写成 $eU_c = h\nu$。
- **波长与频率的换算错误**  
  牢记 $c = \lambda \nu$，从波长推导遏止电压时，正确代入 $\nu = \frac{c}{\lambda}$，避免分子分母颠倒。
- **忽略条件 $\lambda < \lambda_0$**  
  只有入射光波长小于截止波长（频率大于截止频率）时，才会发生光电效应，从而有遏止电压，否则无光电子逸出。
- **表达式书写不规范**  
  部分题目要求用给定字母表示结果，注意答案中不得出现未定义的符号，且需化为最简形式。

## 代表题精讲
### **题目**（2011·新课标·17）  
某金属的截止频率对应波长为 $\lambda_0$，其逸出功为______；若用波长为 $\lambda$（$\lambda < \lambda_0$）的单色光照射，则该金属的遏止电压为______。（已知电子电量 $e$、真空光速 $c$、普朗克常量 $h$）

**思路**  
第一空直接由逸出功与截止波长的关系得出；第二空利用光电效应方程求出最大初动能，再通过 $eU_c = E_{km}$ 求遏止电压。

**步骤**  
1. 逸出功 $W_0 = h\nu_0 = h\frac{c}{\lambda_0}$，所以第一空填 $\frac{hc}{\lambda_0}$。  
2. 入射光光子的能量 $E = h\nu = h\frac{c}{\lambda}$。  
3. 由光电效应方程得最大初动能：$E_{km} = h\frac{c}{\lambda} - \frac{hc}{\lambda_0}$。  
4. 根据遏止电压关系：$eU_c = E_{km}$，解得  
   $$U_c = \frac{hc}{e}\left(\frac{1}{\lambda} - \frac{1}{\lambda_0}\right)$$  
   第二空即为该表达式。

**点评/变式**  
- 本题直接考查爱因斯坦光电效应方程的两大核心结论，是基础中的基础，必须熟练掌握波长-频率转换与最大初动能的表示。  
- **变式1：** 若给出遏止电压与入射光频率的关系曲线（$U_c$–$\nu$ 图），则图线与横轴交点为截止频率 $\nu_0$，斜率 $k = \frac{h}{e}$，可由此求普朗克常量或逸出功。  
- **变式2：** 当入射光频率变为原来的 2 倍时，遏止电压并不简单地加倍，需由 $U_c = \frac{h}{e}\nu - \frac{W_0}{e}$ 分析，注意截距的影响。
