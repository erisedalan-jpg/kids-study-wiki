## 知识精要
- **阻力与速度成正比**：$f = kv$，$k$ 为比例系数（正值），方向始终与速度方向相反。
- **平衡条件**：物体做匀速直线运动时合力为零，$\sum \vec{F}=0$，常表现为 $mg = kv$ 或电场力、重力、阻力三力平衡。
- **电场力**：平行板电容器极板间匀强电场 $E=\frac{U}{d}$，带电油滴受电场力 $F=qE$，方向取决于电荷正负与电压极性。
- **多过程分析**：同一物体在不同电压下达到新的平衡速度，核心是分别列出平衡方程，利用已知匀速时的阻力与对应外力关系联立求解。

## 解题方法与套路
1. **确定研究对象和状态**：明确油滴（或物体）在各阶段的运动状态（如“匀速下降”“匀速上升”），每种匀速对应一个受力平衡方程。
2. **画受力分析图**：标出重力（$mg$，竖直向下）、电场力（$F=qE$，根据极板电压和电荷正负定方向）、阻力（$f=kv$，与速度方向相反）。
3. **列平衡条件**：沿竖直方向建立坐标系，向上为正或向下为正，统正负号。例如向下为正时，匀速下降阻力与速度相反（向上），方程 $mg - kv = 0$。
4. **代换已知关系**：用 $mg=kv$ 或类似关系消去 $k$ 或 $mg$，用电压变化推出电场力大小 $F$，再代入新状态方程，求待求速度。
5. **注意方向判断**：新电压下，电场力方向可能反向，物体可能开始反向运动，阻力方向随之改变。可用假设法（假设匀速向上/向下）列式，若解得速度为正值则假设正确，为负值则反向。

## 高频易错
- **阻力方向写反**：阻力与速度方向相反，匀速上升时阻力向下，匀速下降时阻力向上。列平衡方程时切勿直接套用 $f=kv$ 而忽视符号。
- **电压符号与电场力方向**：电压正负反映极板电势高低，决定电场方向。带电油滴所受电场力方向需根据电荷正负判定，不可仅凭电压符号。
- **忽略重力**：题目中油滴在无电压时匀速下降，表明重力不可忽略；部分考生直接认为 $F=kv$ 而漏掉重力项。
- **混淆“速度大小”与“速度”**：题目问速度的大小与方向，只求出大小 $3v$ 却未正确判断方向会失分。
- **错误使用非平衡状态方程**：题目中“经一段时间后”匀速，表明已达平衡，若误用 $F-mg=ma$ 会引入加速度。
- **默认 $q$ 与极板电压极性**：若不明确油滴带电性质，可设电场力大小为 $F$，通过平衡方程先确定 $F$ 与 $mg$ 关系，避免符号混淆。

## 代表题精讲
**题目**（2008·全国Ⅱ）一平行板电容器两极板水平放置，两极间有一带电量不变的小油滴，阻力大小与其速率成正比。电压为零时油滴以速率 $v$ 匀速下降；电压为 $U$ 时，油滴以速率 $v$ 匀速上升。若电压改为 $-U$，求油滴匀速运动的速度大小和方向。

**思路**  
本题核心是通过两次匀速平衡建立关系：先由电压为零得 $mg = kv$；再由电压为 $U$ 时匀速上升得电场力与重力、阻力平衡，求出电场力大小；最后电压反向后电场力方向改变，设油滴向下匀速列平衡方程求解速度。

**步骤**  
1. 电压为零，匀速下降：重力向下，阻力向上，有 $mg = kv$，得 $k = \frac{mg}{v}$。
2. 电压为 $U$ 时，设电场力大小为 $F$，因匀速上升，速度向上，阻力向下，电场力向上，平衡方程：$F = mg + kv$。代入 $mg = kv$，得 $F = 2mg$。
3. 电压为 $-U$ 时，电场力大小仍为 $F = 2mg$，方向向下。假设油滴向下匀速，速度设为 $v'$，阻力向上，重力向下，电场力向下，平衡方程：$mg + F = kv'$，代入 $F=2mg$、$k=\frac{mg}{v}$，得 $v' = 3v$，方向向下。若假设向上匀速，则阻力向下，$F$向下，合力不能为零，故假设不成立。

**点评/变式**  
本题巧妙结合电场与阻力特性，关键在于不明确带电正负时统一用力的大小表示，利用已知状态逐步消元。变式：若阻力与速度平方成正比，处理方法类似，但需注意平衡条件变为 $mg = kv^2$ 等形式。
