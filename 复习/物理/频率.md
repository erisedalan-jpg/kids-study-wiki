## 知识精要
- **频率与周期**：单位时间内完成全振动的次数叫频率，符号 $f$，单位 Hz。周期 $T$ 是完成一次全振动的时间，二者互为倒数：$T=\frac{1}{f}$。频率和周期均由**波源（振源）**决定，与传播介质无关。
- **机械波中的频率**：波速 $v$、波长 $\lambda$、频率 $f$ 满足 $v=\lambda f$。同一列波从一种介质进入另一种介质时，频率（周期）**不变**，波速改变，波长随之改变。
- **光子频率**：光子能量 $E=h\nu$（$\nu$ 即频率，普朗克常量 $h=6.63\times10^{-34}\,\text{J}\cdot \text{s}$）。光的颜色由频率决定。
- **光电效应**：爱因斯坦光电效应方程 $E_{\text{k}}=h\nu - W_0$，其中 $W_0$ 为金属的逸出功。极限频率（截止频率）$\nu_0 = \frac{W_0}{h}$，入射光频率必须大于 $\nu_0$ 才能发生光电效应。
- **适用条件**：频率由波源决定在机械波、电磁波以及物质波问题中普遍成立；光子能量公式适用于所有电磁辐射；光电效应方程适用于光子与金属电子的相互作用，且一个电子一次只吸收一个光子。

## 解题方法与套路
1. **判断频率是否变化**：看到波在不同介质中传播，直接锁定频率不变、周期不变，波速和波长成比例变化。利用 $v=\lambda f$ 分析波速与波长的变化关系。
2. **波速公式求波长或频率**：已知波速和波长求频率 $f=\frac{v}{\lambda}$；已知频率和波速求波长 $\lambda=\frac{v}{f}$。注意所有物理量需用国际单位。
3. **光子能量与频率的换算**：题目给出能量（J 或 eV）求频率，用 $\nu = \frac{E}{h}$。若能量以 eV 给出，先换算为焦耳：$1\,\text{eV}=1.6\times10^{-19}\,\text{J}$。
4. **光电效应求极限频率**：根据爱因斯坦光电效应方程，先由最大初动能和入射光频率（或波长）求出逸出功 $W_0 = h\nu - E_{\text{k}}$，再由 $W_0 = h\nu_0$ 得出 $\nu_0$。若给出波长，需先通过 $\nu = \frac{c}{\lambda}$ 求得频率。
5. **不同介质中波长比**：同一种声波（或光波）频率不变，由 $f=\frac{v_1}{\lambda_1}=\frac{v_2}{\lambda_2}$ 可直接得出波长比 $\frac{\lambda_2}{\lambda_1}=\frac{v_2}{v_1}$。

## 高频易错
- **混淆频率的决定因素**：误认为波速改变时频率也会改变。牢记频率由波源决定，波速由介质决定。
- **单位换算失误**：波长单位常用 nm（$1\,\text{nm}=10^{-9}\,\text{m}$），频率常用 Hz，能量常用 eV 与 J 混用。光子能量公式中必须使用 J 与 $h$ 相乘，$1\,\text{eV}=1.6\times10^{-19}\,\text{J}$ 要熟练转换。
- **忘记逸出功对应的极限频率**：在光电效应问题中，容易跳过 $W_0$ 直接认为所有光都能打出电子。需明确 $\nu \ge \nu_0$ 是发生光电效应的前提，$\nu_0 = \frac{W_0}{h}$。
- **周期与频率关系颠倒**：有的学生误记 $T=f$。应熟练 $T=\frac{1}{f}$，在波速公式中常使用 $f$ 而非 $T$。
- **波速公式乱代**：机械波波速不由 $c$ 决定，声波在空气和钢铁中波速不同，不要代入光速。

## 代表题精讲
### **题目** 2023-新课标-01  
船上的人和水下的潜水员都能听见轮船的鸣笛声。声波在空气中和水中传播时的（ ）  
A. 波速和波长均不同  B. 频率和波速均不同  C. 波长和周期均不同  D. 周期和频率均不同

**思路**  
抓住“频率由振源决定”，声音从同一振源发出，在空气和水中周期和频率相同。波速在两种介质中明显不同，由 $v=\lambda f$ 可知波长随之不同。

**步骤**  
- 声波周期 $T$ 与频率 $f$ 均由发声体振动决定，故 $T_{\text{空气}}=T_{\text{水}}$，$f_{\text{空气}}=f_{\text{水}}$。  
- 声速在空气（约 340 m/s）和水中（约 1500 m/s）不同，波速改变。  
- 由 $v = \lambda f$，$f$ 不变而 $v$ 变大时，$\lambda$ 也变大，故波长也不同。  
- 因此波速和波长均不同，选项 A 正确。

**点评/变式**  
此题属于基础题，重在区别波的决定因素：频率由波源决定，波速由介质决定。类似问题常见于光从空气进入水，或绳波由细绳传入粗绳，均遵循频率不变、波速与波长改变。

### **题目** 2023-新课标-03  
铯原子基态的两个超精细能级之间跃迁发射的光子具有稳定的频率，铯原子钟利用的两能级能量差量级为 $10^{-5}\,\text{eV}$，跃迁发射的光子的频率量级为（已知 $h=6.63\times10^{-34}\,\text{J}\cdot \text{s}$，$e=1.60\times10^{-19}\,\text{C}$）（ ）  
A. $10^3\,\text{Hz}$  B. $10^6\,\text{Hz}$  C. $10^9\,\text{Hz}$  D. $10^{12}\,\text{Hz}$

**思路**  
利用光子能量公式 $E=h\nu$，将能量差转换为焦耳，估算频率量级。

**步骤**  
- 能级差能量：$\Delta E = 10^{-5}\,\text{eV} = 10^{-5} \times 1.6\times10^{-19}\,\text{J} = 1.6\times10^{-24}\,\text{J}$。  
- 由 $\Delta E = h\nu$ 得频率：  
  $$\nu = \frac{\Delta E}{h} = \frac{1.6\times10^{-24}}{6.63\times10^{-34}}\,\text{Hz} \approx 2.4\times10^9\,\text{Hz}$$
- 频率量级约为 $10^9\,\text{Hz}$，故选项 C 正确。

**点评/变式**  
注意 eV 与 J 的换算，以及量级估算中有效数字不必过于精确。若能量差给出为 $10^{-4}\,\text{eV}$ 或 $10^{-6}\,\text{eV}$，相应频率量级会变化，可举一反三。

### **题目** 2018-新课标Ⅱ-04  
用波长为 $300\,\text{nm}$ 的光照射锌板，电子逸出的最大初动能为 $1.28\times10^{-19}\,\text{J}$，已知普朗克常量 $h=6.63\times10^{-34}\,\text{J}\cdot \text{s}$，光速 $c=3.00\times10^8\,\text{m/s}$。能使锌产生光电效应的单色光的最低频率约为（ ）
A. $1\times10^{14}\,\text{Hz}$  B. $8\times10^{14}\,\text{Hz}$  C. $2\times10^{15}\,\text{Hz}$  D. $8\times10^{15}\,\text{Hz}$

**思路**  
先由波长求出入射光频率，再利用光电效应方程求出逸出功 $W_0$，最后由 $W_0 = h\nu_0$ 算出极限频率。

**步骤**  
- 入射光频率：$\nu = \dfrac{c}{\lambda} = \dfrac{3.00\times10^8}{300\times10^{-9}} = 1.00\times10^{15}\,\text{Hz}$。  
- 光子能量：$h\nu = 6.63\times10^{-34} \times 1.00\times10^{15} = 6.63\times10^{-19}\,\text{J}$。  
- 根据光电效应方程 $E_{\text{k}} = h\nu - W_0$，得逸出功：  
  $$W_0 = h\nu - E_{\text{k}} = 6.63\times10^{-19} - 1.28\times10^{-19} = 5.35\times10^{-19}\,\text{J}$$
- 极限频率：$\nu_0 = \dfrac{W_0}{h} = \dfrac{5.35\times10^{-19}}{6.63\times10^{-34}} \approx 8.07\times10^{14}\,\text{Hz}$，与选项 B 一致。

**点评/变式**  
关键步骤是先求出入射光子能量，减掉最大初动能得到逸出功。若题目给出极限频率要求最大初动能，只需逆向计算。单位统一到位，波长记得转换为米。
