## 知识精要
- **水在细胞中的存在形式**
  细胞内水分为**自由水**（游离态，流动）与**结合水**（与蛋白质、多糖等结合，属结构组分）。生命活动所需的主要是自由水。
- **自由水/结合水比值与代谢速率**  
  自由水比例 $f$ 越高，代谢越旺盛（如萌发种子）；比值越低，代谢越缓慢，抗逆性增强（如休眠种子）。种子风干时主要散失自由水，结合水相对稳定，故**结合水/自由水比值增大**。
- **细胞呼吸与物质消耗**  
  呼吸强度正比于自由水含量。水分充足→呼吸速率高→有机物消耗快；缺水→呼吸被抑制→有机物消耗慢。
- **水分与微生物繁殖**  
  微生物生长需一定水分活度。风干种子含水量极低，微生物代谢受抑，不易生长繁殖。
- **综合关系**  
  风干处理使自由水含量↓ → 呼吸强度↓ → 有机物消耗↓，同时微生物繁殖受抑；细胞内结合水/自由水比值↑。

## 解题方法与套路
1. **明确处理条件**  
   审题抓关键词：“风干”导致种子含水量下降，且主要是自由水丢失。
2. **推演代谢变化**  
   自由水减少 → 细胞呼吸受抑制 → 呼吸强度降低 → 有机物消耗减慢。
3. **分析微生物角度**  
   缺水环境 → 微生物生长繁殖受限制。
4. **判断比值方向**  
   自由水下降、结合水基本不变 → 结合水/自由水比值上升。
5. **辨错选项特征**  
   - 将“强度低”说成“强度高”  
   - 将“比值大”说成“比值小”  
   - 将“消耗慢”说成“消耗快”或“不变”  
   - 忽略水分对微生物的限制

## 高频易错
- 误认为风干后水分全失，细胞呼吸完全停止（实际仍有极微弱呼吸）。
- 混淆“结合水/自由水”比值的变化方向，错选比值减小的表述。
- 忽略自由水与结合水的功能差异，将有机物的消耗快慢归因于“种子是否死亡”。
- 不理解微生物繁殖需水，误判风干不影响微生物生长。
- 将“有机物消耗减慢”与“不再消耗”混淆。

## 代表题精讲
### **题目** 2018·新课标Ⅱ·第4题  
风干种子与风干前相比，说法错误的是哪项？选项内容涉及有机物消耗、微生物繁殖、呼吸强度、结合水/自由水比值。

**思路**  
题干要求选“错误”，应正向推断风干后各指标变化，再找与推论相悖的选项。核心是自由水含量降低对代谢的抑制。

**步骤**  
1. 确定变化起点：风干→种子含水量（自由水）显著下降。  
2. 有机物消耗：呼吸强度下降 → 有机物分解减慢，A项正确。  
3. 微生物繁殖：缺水 → 微生物生理活动受阻，不易繁殖，B项正确。  
4. 呼吸强度：自由水不足 → 酶促反应速率低 → 细胞呼吸强度降低，故C项“呼吸作用的强度高”错误。  
5. 水分比值：自由水减少，结合水几乎不变 → 结合水/自由水比值增大，D项正确。  
6. 错误选项为C。

**点评/变式**  
此题以种子储存为背景，考查水与代谢的关系，易错点是比值方向判断和呼吸强度定性。变式可改为：“风干利于种子保存的原因是什么？”答案要点：自由水少，呼吸弱，有机物消耗少，且不易霉变。
