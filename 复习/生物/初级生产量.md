## 知识精要
- **初级生产量（GP）**：生态系统中生产者通过光合作用或化能合成作用固定的太阳能总量或合成的有机物总量。  
  公式：$GP = NP + R$，其中 $NP$ 为净初级生产量，$R$ 为生产者自身呼吸消耗的能量。
- **净初级生产量（NP）**：初级生产量扣除生产者自身呼吸消耗后剩余的部分，即用于生产者生长、发育、繁殖及流向其他营养级的有机物量。
- **能量去向**：$GP$ 中的 $R$ 以热能散失；$NP$ 可流向初级消费者、分解者，或以枯枝落叶等形式暂时未被利用（积累在土壤中）。
- **黑白瓶法测总初级生产量**（以溶氧量为指标）：
  - 初始水样 $O_2$ 含量记为 $A$；
  - 不透光瓶只有呼吸耗氧，$n$ 小时后 $O_2$ 含量 $B$，则呼吸消耗量 $= A - B$；
  - 透光瓶光合与呼吸同时进行，$n$ 小时后 $O_2$ 含量 $C$，则净光合产氧量 $= C - A$；
  - 总初级生产量对应产氧量 $= (C - A) + (A - B) = C - B$。
- **适用条件**：黑白瓶法要求瓶内生产者呼吸速率相同且只有生产者，常用于水生生态系统。

## 解题方法与套路
1. **区分“总”与“净”**：见到“固定的太阳能”“制造的有机物总量”→总初级生产量；见到“积累的有机物”“剩余的能量”→净初级生产量。牢记 $GP = NP + R$。
2. **理清能量流图**：  
   - 看清方框/箭头代表的是能量、生物量还是 $O_2$ 变化；  
   - 箭头“呼吸”对应 $R$，去往分解者、消费者或“未利用”的箭头均源于 $NP$。
3. **黑白瓶法解题三步走**：  
   - 明确 $A$（初始值）、$B$（不透光瓶终值）、$C$（透光瓶终值）的含义；  
   - 呼吸消耗量 $= A - B$（必为正值）；净产氧量 $= C - A$；总产氧量 $= C - B$；  
   - 根据问题将氧气量换算为有机物量，并注意公式变形。
4. **比例计算**：若给出 $NP$ 的分配比例（如流向分解者占 36%），直接计算即可，但要先确认基数是否为 $NP$，而非 $GP$。

## 高频易错
- **混淆 $GP$ 与太阳入射能**：$GP$ 是已经固定的能量，远小于照射到生态系统的太阳能，不可等同。
- **把呼吸消耗当作“未被利用的能量”**：呼吸消耗已散失，不属于$NP$的一部分，当然不构成“未被利用”。
- **黑白瓶实验中指标混淆**：  
  - $C - A$ 是净初级生产量对应的产氧量，不是总初级生产量；  
  - 不透光瓶直接给出呼吸耗氧量，不能用 $B - A$（应为 $A - B$）。
- **忽视实验前提**：“生产者呼吸相同且瓶中只有生产者”，若条件不满足，不可直接用上述公式。
- **图解题抓不准基量**：如“$E_3$ 占净初级生产量的 36%”，这里的 $E_3$ 是来自 $NP$ 的去向之一（如流入分解者），若误认为 $E_3$ 本身就是 $NP$ 则会认为数值矛盾。

## 代表题精讲
### **题目**：2024 辽宁-16（能量流动示意图）  
**题目简述**：图示红松人工林能量流动，初级生产量沿碎屑食物链流动比例大，枯枝落叶和倒木被分解后剩余部分积累于土壤。给出注记“植物固定的太阳能为初级生产量，包括净初级生产量和自身呼吸消耗的能量”，选项涉及 $E$、$E_2$、$E_3$ 的判断。  
**思路**：明确图中 $E$ 为总初级生产量，$E_2$ 为呼吸消耗 $R$，$E_3$ 为流向分解者的能量（或土壤积累）。根据定义辨析各选项。  
**步骤**：  
1. $E$ 是“植物固定的太阳能”，即总初级生产量 $GP$，不是照射到生态系统的全部太阳能→A 错。  
2. $E_2$ 指向呼吸消耗，属于散失的热能，并非“未被利用的能量”→B 错。  
3. 图可显示 $E_3$ 属于净初级生产量的一部分（去往枯枝落叶/分解者），若标注比例为 36%，则 C 说“$E_3$ 占净初级生产量的 36%”正确。  
**点评/变式**：能量流图题需要紧扣注记，先定位 $GP$、$R$、$NP$，再匹配各去向。变式题会在箭头加数值求传递效率或未利用比例。

### **题目**：2019 新课标Ⅱ-09（黑白瓶法测总初级生产量）  
**题目简述**：  
（1）森林生态系统中生产者能量来源及流向。  
（2）黑白瓶法：三等份水样，初始氧量 $A$；不透光瓶（甲）终值 $B$；透光瓶（乙）终值 $C$，且条件为生产者呼吸相同且瓶中只有生产者。回答 $C$ 与 $A$ 的差值及总初级生产量表达式。  
**思路**：  
（1）基础记忆；  
（2）利用公式 $NP$ 产氧 $= C-A$，总产氧 $= C-B$。  
**步骤**：  
1. （1）太阳能；初级消费者、分解者。  
2. （2）$C-A$ 表示净初级生产量对应的产氧量（或净光合作用产氧量）。  
   总初级生产量对应的产氧量 $= (C-A) + (A-B) = C-B$。  
**点评/变式**：黑白瓶法核心在于区分“净”与“总”，并坚持用初始值 $A$ 做参照。变式可要求将氧气量换算为有机物量（乘以系数），或加入异养生物时修正公式，务必看清前提条件。
