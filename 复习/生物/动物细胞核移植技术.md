## 知识精要
- **核心概念**：动物细胞核移植技术是指将一个动物细胞的细胞核，移入一个已经去掉细胞核的卵母细胞中，使其重组并发育成一个新的胚胎，这个胚胎最终发育成与供核个体遗传背景基本相同的动物个体（克隆动物）。
- **技术流程**：供体细胞培养（注意传代次数）→ 从供体细胞中取出细胞核 → 将处于减数第二次分裂中期（MⅡ期）的卵母细胞去核（显微操作法）→ 将供体核注入去核卵母细胞 → 重组细胞 → 激活并培育成早期胚胎 → 胚胎移植到代孕母体子宫 → 诞生克隆动物。
- **原理与实质**：动物体细胞核的全能性。已分化的动物体细胞细胞核含有保持该物种全套遗传信息所需的全部基因，在去核卵母细胞质的调控下，可恢复全能性。
- **性染色体组成**：克隆动物为二倍体，正常有性生殖物种的供体细胞中性染色体组成可为 $XX$ 或 $XY$，取决于供体的性别。
- **遗传特点**：
  - 克隆动物绝大部分遗传物质来自供体细胞的细胞核，核基因与供体动物基本相同。
  - 卵母细胞的细胞质中含有少量DNA（线粒体DNA），会对克隆动物的某些性状产生影响，因此克隆动物与供体动物性状可能不完全相同。
  - 供体细胞经多次传代后，细胞内遗传物质的稳定性会降低，可能积累突变，选材时需关注传代次数。

## 解题方法与套路
1. **识图与流程填空**：看清每一步箭头的指向，明确“去核→重组→胚胎培养→胚胎移植”的顺序；去核时卵母细胞通常培养至MⅡ期，去核常用显微操作法；②往往对应胚胎移植。
2. **性染色体组成推测**：由题干“二倍体哺乳动物”“正常细胞核”可推断供体细胞中性染色体为 $XX$ 或 $XY$，只要答出这两种可能即可得全分，不要漏掉一种。
3. **“传代次数”类问题**：出现传代次数，直接关联“遗传物质稳定性降低”或“细胞衰老、突变累积”，答案模板为“经过多次传代后，供体细胞中遗传物质的稳定性会降低”。
4. **性状差异原因分析**：当问及从遗传物质角度分析克隆动物与供体性状不完全相同时，必须抓住两点：①核基因几乎完全相同，但质基因不同；②卵母细胞的细胞质中的遗传物质会对性状产生影响（或答：细胞质基因来自去核卵母细胞，与供体不同）。
5. **结论类填空**：题干以“证明了……”结尾时，结合克隆多莉背景，规范作答为“动物已分化体细胞的细胞核具有全能性”，注意是“细胞核的全能性”，不要泛写细胞全能性。

## 高频易错
- **性染色体漏写一种**：看到“二倍体哺乳动物”直接写$XX$，忽略雄性供体情况（$XY$），痛失1分。正确答法：$XX$ 或 $XY$。
- **去核时期与手段混淆**：去核一般在卵母细胞培养到MⅡ期时进行，方法为显微操作法，不可写成“离心法”或“化学处理”。
- **细胞核全能性表述错误**：不能写“证明了动物体细胞具有全能性”，克隆动物的成功只能证明**已分化体细胞的细胞核**具有全能性。高考极容易在此处设空。
- **忽略质基因影响**：分析性状差异时，只答核基因原因，未提及卵母细胞质中的遗传物质（如线粒体DNA）的影响，导致失分。
- **传代次数作用相反**：误以为传代越多越好，实质上多次传代导致供体细胞遗传物质稳定性降低，应选择传代次数少的细胞。

## 代表题精讲
**题目**：2016·新课标Ⅱ·12 题——以流程图考查核移植获取克隆哺乳动物，含填空与简答。

**思路**：本题流程为核供体细胞→供体核→去核卵母细胞→重组细胞→早期胚胎→代孕母体→克隆动物。第(1)问前两空由二倍体推性染色体组成和去核方法；第(2)问围绕供体细胞传代；第(3)问从细胞质基因解释性状差异；第(4)问延续教材结论。

**步骤**：
1. 第(1)空：因流程图显示A为正常体细胞核，该动物为二倍体哺乳动物，故性染色体组成可能为 $XX$ 或 $XY$。
2. 过程①去核常在卵母细胞培养到MⅡ期再用显微操作去除，故填“显微操作”。
3. 过程②将早期胚胎移入代孕母体子宫，为“胚胎移植”。
4. 多次传代导致供体细胞遗传物质稳定性下降，因此(2)题为“遗传物质（或DNA）”。
5. 克隆动物与供体性状不完全相同的遗传原因：卵母细胞的细胞质中含有遗传物质（如线粒体DNA），其控制的性状可能与供体不同，故填空为“卵母细胞的细胞质中的遗传物质会对克隆动物的性状产生影响”。
6. 多莉羊成功证明了“动物已分化体细胞的细胞核具有全能性”。

**点评/变式**：该题典型在于将技术流程、性染色体知识、传代稳定性、质基因影响和全能性结论融入一个主题。变式可改为“若供体细胞来自雌性，则性染色体填什么？”——只能写 $XX$。或追问“重组细胞再生的个体与供体核供体完全一致吗？”——不完全一致，因为质基因来自卵母细胞。答题务必精准区分“细胞全能性”与“细胞核全能性”。
