## 知识精要
- **叶绿体（光合作用）**
  - 光反应场所：**类囊体薄膜**（含光合色素和酶），进行水的光解（$H_2O \rightarrow O_2 + [H]$）和ATP合成。
  - 暗反应场所：**叶绿体基质**（含多种酶），进行$CO_2$的固定和C3的还原，消耗[H]和ATP。
- **线粒体（有氧呼吸）**
  - 第二阶段场所：**线粒体基质**，丙酮酸和水反应生成$CO_2$、[H]和少量ATP。
  - 第三阶段场所：**线粒体内膜**，前两阶段产生的[H]与$O_2$结合生成$H_2O$，释放大量ATP。
- **细胞质基质**
  - 有氧呼吸第一阶段（糖酵解）场所。
  - 无氧呼吸全过程场所。
- **原核细胞**
  - 没有线粒体和叶绿体，部分原核生物可在**细胞质膜**或**细胞质**进行光合作用或有氧呼吸。

## 解题方法与套路
1. **识别场所法**：看过程发生的结构。
   - 若出现水的光解、氧气释放、吸收光能，必为**类囊体薄膜**。
   - 若出现$CO_2$的固定、C3还原、无光也能进行，必为**叶绿体基质**。
   - 若出现$O_2$参与生成$H_2O$并大量产能，场所一定在**线粒体内膜**。
   - 若出现葡萄糖分解为丙酮酸、产生少量[H]和ATP，则一定在**细胞质基质**。
2. **物质追踪法**：依流程图中的关键物质推断场所。
   - 看到[H]和$O_2$结合生成水 → 线粒体内膜。
   - 看到[H]和ATP用于C3还原 → 叶绿体基质。
   - 看到葡萄糖 → 细胞质基质（起始）。
3. **过程名称填空后匹配场所**：先将图中过程标注完整（如“光反应”“暗反应”“有氧呼吸第二阶段”等），再逐一写出对应的具体结构，避免张冠李戴。

## 高频易错
- **光反应场所误答为“叶绿体基质”**：因不区分光反应和暗反应位置，实则基质为暗反应场所。
- **有氧呼吸第三阶段误答为“线粒体基质”**：记混第二阶段（基质）和第三阶段（内膜）的场所，可用“水在内膜生成”帮助记忆。
- **无氧呼吸场所只写“线粒体”**：无氧呼吸全程在**细胞质基质**，与线粒体无关。
- **忽略场所名称的精准性**：如写成“叶绿体”“线粒体”不具体，必须细化到“类囊体薄膜”“基质”“内膜”；但原核生物可笼统写“细胞质膜”。
- **不同过程共用一个场所时混淆对应关系**：暗反应（叶绿体基质）和呼吸某些阶段易串，牢牢抓住是否用到$CO_2$、光照。

## 代表题精讲
**题目** 2017-新课标Ⅱ-07（改编）  
如图是某植物叶肉细胞光合作用和呼吸作用的示意图，图中A～E代表相关过程，①～④代表物质。请结合图示回答各过程发生的场所。

**思路**  
分析方框所示过程的核心反应，由反应物、产物及特点倒推场所：
- 光合部分：看水光解和ATP产生 → 光反应；看$CO_2$到糖的变化 → 暗反应。
- 呼吸部分：葡萄糖到丙酮酸 → 第一阶段；丙酮酸到$CO_2$和[H] → 第二阶段；[H]与$O_2$生成$H_2O$ → 第三阶段。

**步骤**
1. **A（光反应）**：分解水产生$O_2$和[H]，形成ATP → 场所：类囊体薄膜。  
2. **B（暗反应）**：消耗ATP和[H]，固定$CO_2$ → 场所：叶绿体基质。  
3. **C（有氧呼吸第一阶段）**：葡萄糖分解为丙酮酸和[H] → 场所：细胞质基质。  
4. **D（有氧呼吸第二阶段）**：丙酮酸和$H_2O$反应生成$CO_2$和大量[H] → 场所：线粒体基质。  
5. **E（有氧呼吸第三阶段）**：[H]与$O_2$结合生成$H_2O$，释放大量ATP → 场所：线粒体内膜。  
   若图示涉及无氧呼吸，则对应阶段全部在细胞质基质，无后续进入线粒体的步骤。

**点评/变式**  
常以概念图、生理过程联系图形式出现。解题关键是紧抓每种物质变化的“核心反应”与发生这些反应必须依赖的结构。变式可能将场所填表或直接将字母对应结构进行连线，警惕名称规范（如“线粒体内膜”不能简写为“线粒体”）。
