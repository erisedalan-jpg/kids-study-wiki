## 知识精要
- **基因频率**：在一个种群基因库中，某个基因占全部等位基因数的比率。  
  公式：$基因频率 = \frac{该基因的数目}{该基因及其等位基因的总数} \times 100\%$
- **基因型频率**：某种基因型的个体数占群体中全部个体数的比率。
- **遗传平衡定律（哈代-温伯格定律）**：在满足种群足够大、随机交配、无突变、无迁移、无自然选择的理想条件下，基因频率和基因型频率在世代相传中保持不变。  
  若一对等位基因 $A$ 和 $a$ 的频率分别为 $p$、$q$（$p+q=1$），则基因型频率为：  
  $$p^2(AA) + 2pq(Aa) + q^2(aa) = 1$$
- **伴性遗传的基因频率**：  
  - 男性性染色体组成为 XY，仅一条 X 染色体，男性中某伴 X 基因的频率等于相应基因型频率。  
  - 若致病基因为 $X^h$（隐性），正常基因为 $X^H$，在男性群体中，患者比例即为 $X^h$ 频率。例如患者比例 1%，则 $X^h$ 频率 $= 0.01$。  
  - 女性两条 X 染色体，女性携带者（$X^H X^h$）频率可用遗传平衡公式计算：$2pq$，其中 $p$ 为正常基因频率，$q$ 为致病基因频率。
- **适用条件**：种群足够大、随机交配、无突变、无自然选择、无迁移。男性群体与女性群体基因频率相等时，可用同一频率计算不同性别的基因型频率。

## 解题方法与套路
1. **判断遗传方式并确定基因位置**：根据题干信息（如伴 X 隐性、伴 X 显性等）确定基因位于性染色体还是常染色体。  
2. **分开性别计算基因频率**：  
   - 对于伴 X 遗传，男性基因型频率直接反映基因频率（因为男性只有一条 X 染色体）。  
   - 女性基因型频率按遗传平衡定律计算：$p^2(AA):2pq(Aa):q^2(aa)$。  
3. **灵活转换基因频率与基因型频率**：  
   - 已知男性患病比例 → 即为男性中致病基因频率 $q$。  
   - 若男女基因频率相同，则女性基因频率也为 $q$，利用 $p=1-q$ 计算正常基因频率。  
   - 女性携带者比例 $= 2pq$，女性患者比例 $= q^2$。  
4. **家系概率计算**：对伴性遗传，先确定亲本基因型及产生配子的概率，用分离定律逐代推导，注意性别影响。  
5. **画系谱图**：按题干描述标准化作图，标明各成员性别、表现型、世代关系，并注明未出生个体。

## 高频易错
- **混淆男性与女性的基因型频率和基因频率**：在伴 X 遗传中，男性患者比例即致病基因频率，不能套用 $q^2$；女性才需平方或乘积计算。  
- **忽略“男女基因频率相等”这一条件**：计算女性携带者或患者比例时，必须明确致病基因频率同男性一样，否则无法计算。  
- **将女性携带者概率算成 $q^2$ 或 $p^2$**：携带者是杂合子 $2pq$，而非纯合子。  
- **遗传平衡定律滥用**：题干需明确或暗示群体处于平衡状态（如“基因频率和基因型频率保持不变”），否则不可用 $p^2、2pq、q^2$ 公式。  
- **家系概率计算中忽略“基因型相同”的特殊限定**：如“两个女儿基因型相同”，则条件概率范围缩小，需在此条件下重新计算子代患病概率。

## 代表题精讲
**题目**（2017-新课标Ⅱ-10）：  
一对非血友病夫妇生出两个非双胞胎女儿。大女儿与非血友病男子结婚生出一个患血友病男孩。小女儿与非血友病男子结婚并已怀孕。  
（1）画系谱图表示该家系血友病患病情况。  
（2）小女儿生出患血友病男孩的概率；若两个女儿基因型相同，小女儿生出血友病基因携带者女孩的概率。  
（3）在一个遗传平衡群体中，男性血友病患者比例为 1%，男性群体和女性群体致病基因频率相等。求男性群体中致病基因频率和女性群体中携带者的比例。

**思路**：  
血友病为伴 X 隐性遗传病。先由“非血友病夫妇生出的女儿与非血友病男子结婚生患病男孩”逆推大女儿必为携带者（$X^H X^h$），进而推断他们的母亲也为携带者，父亲正常（$X^H Y$）。小女儿可能为 $X^H X^H$ 或 $X^H X^h$，概率各 1/2。根据小女儿与正常男子（$X^H Y$）婚配，计算相应子代患病概率。群体部分直接利用男性患者比例得出致病基因频率，再利用平衡定律求女性携带者频率。

**步骤**：  
1. **画系谱图**：  
   - 第一代：父方 □正常，母方 ○正常（实为携带者）。  
   - 第二代：大女儿 ○正常（携带者），大女婿 □正常；小女儿 ○正常，小女婿 □正常。  
   - 第三代：大女儿的儿子 ■患者；小女儿腹中胎儿用 ◇“？”表示。  
   （具体画法略，需按遗传病系谱图规范绘制）  

2. **家系概率计算**：  
   - 推断基因型：由大女儿生出患病男孩（$X^h Y$），男孩的 $X^h$ 必来自母亲，故大女儿为 $X^H X^h$。因其父母均非患者，母亲必为携带者 $X^H X^h$，父亲为 $X^H Y$。  
   - 小女儿：母亲 $X^H X^h$，父亲 $X^H Y$，则小女儿基因型为 $X^H X^H$ 概率 1/2，$X^H X^h$ 概率 1/2。  
   - 小女儿与正常男子（$X^H Y$）婚配：  
     - 若小女儿为 $X^H X^H$，后代全部正常。  
     - 若小女儿为 $X^H X^h$，后代中男孩患病概率为 1/2（得到 $X^h$），女孩患病概率 0，携带者女孩概率 1/2。  
   - 故小女儿生出患血友病男孩的概率为：$P(小女儿为 X^H X^h) \times P(生男孩且患病) = \frac{1}{2} \times \frac{1}{4} = \frac{1}{8}$。  
   - 假如两个女儿基因型相同，则小女儿必为 $X^H X^h$（大女儿已知为 $X^H X^h$），此时生出血友病基因携带者女孩的概率：生女孩概率 1/2，且女孩基因型为 $X^H X^h$ 的概率为 1/2（母亲提供 $X^h$，父亲提供 $X^H$），所以概率为 $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。  

3. **群体基因频率计算**：  
   - 男性患者比例 1% → 男性中 $X^h$ 基因频率 = 0.01。  
   - 因为男性群体和女性群体致病基因频率相等，故女性中 $X^h$ 频率 $q = 0.01$，正常基因频率 $p = 0.99$。  
   - 女性携带者（$X^H X^h$）的比例为 $2pq = 2 \times 0.99 \times 0.01 = 0.0198 = 1.98\%$。  

**点评/变式**：  
本题综合了伴性遗传家系分析、概率计算和群体遗传学基本公式。核心陷阱在于（2）的第二问“两个女儿基因型相同”，此时必须将小女儿锁定为携带者，从而子代概率变化。群体部分易错点在于直接将男性患者比例作为 $q^2$ 计算女性携带者，要牢记男性半合子特性。变式可考色盲、抗维生素 D 佝偻病（伴 X 显性）等，或给出女性中基因型频率反推男性患病率，解题原理一致。
