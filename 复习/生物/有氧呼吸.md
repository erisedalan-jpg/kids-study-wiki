## 知识精要
- **有氧呼吸的定义**：细胞在氧的参与下，通过酶的催化作用，把葡萄糖等有机物彻底氧化分解，产生二氧化碳和水，释放大量能量，合成ATP的过程。
- **总反应式**：
  $$\mathrm{C_6H_{12}O_6 + 6H_2O + 6O_2 \xrightarrow{酶} 6CO_2 + 12H_2O + 能量}$$
  注意：能量中大部分以热能形式散失，少部分储存在ATP中。
- **阶段与场所**（真核生物）：
  1. 糖酵解（第一阶段）：细胞质基质，葡萄糖 $\rightarrow$ 丙酮酸 + 少量 $\mathrm{NADH}$ + 少量ATP。不需氧。
  2. 丙酮酸氧化脱羧和柠檬酸循环（第二阶段）：线粒体基质，丙酮酸 + 水 $\rightarrow$ $\mathrm{CO_2}$ + 大量 $\mathrm{NADH}$、$\mathrm{FADH_2}$ + 少量ATP。需氧间接参与。
  3. 氧化磷酸化（第三阶段）：线粒体内膜，前两阶段产生的 $\mathrm{NADH}$、$\mathrm{FADH_2}$ 通过电子传递链将电子传递给 $\mathrm{O_2}$，驱动ATP合酶合成大量ATP，产生水。
- **有氧呼吸产生 $\mathrm{NADH}$ 的场所**：细胞质基质（糖酵解）、线粒体基质（柠檬酸循环）。
- **能量转化效率**：1分子葡萄糖彻底氧化分解，最多可合成约 $30\sim32$ 个 ATP（真核生物）。
- **与无氧呼吸的主要区别**：
  - 有氧呼吸：彻底氧化分解，产物 $\mathrm{CO_2}$、$\mathrm{H_2O}$，释放能量多。
  - 无氧呼吸：不彻底氧化分解，产物为乳酸或酒精和 $\mathrm{CO_2}$，释放能量少，仅第一阶段产生少量ATP。
- **与光呼吸的关系**：光呼吸消耗 $\mathrm{O_2}$ 并释放已固定的碳，消耗能量，部分过程发生在线粒体和过氧化物酶体中；有氧呼吸则是主要的供能过程。
- **微生物与有氧呼吸**：
  - 好氧细菌（如肺炎双球菌）无线粒体，但细胞膜和细胞质中含有有氧呼吸的酶，能进行有氧呼吸。
  - 厌氧菌（如破伤风芽孢杆菌）只在无氧条件下生长，有氧时受抑制。
  - 酵母菌是兼性厌氧型，有氧时进行有氧呼吸，无氧时产酒精和 $\mathrm{CO_2}$。
- **细胞呼吸的普遍性**：所有活细胞时刻都进行呼吸作用，即使在光照下，叶肉细胞也同时进行光合作用和呼吸作用。

## 解题方法与套路
1. **判断呼吸方式**：
   - 看产物：有氧气消耗或产生水，一般为有氧呼吸；产生酒精或乳酸则为无氧呼吸。
   - 看场所：顺藤摸瓜找线粒体、细胞质基质相关过程。
   - 注意原核生物无粒体，但酶定位在细胞膜或细胞质。
2. **分析“O₂浓度影响吸收速率”模型**（常用于主动运输题目）：
   - 确定运输方式：若吸收速率与O₂浓度在一定范围内正相关，说明需要细胞呼吸供能 → 主动运输。
   - 找平台期原因：O₂浓度大于某值后速率不再增加 → 载体蛋白数量饱和或细胞呼吸已达最大速率。
   - 由最大吸收速率反推呼吸速率：最大吸收速率越大，主动运输需能量越多，消耗的O₂越多，呼吸速率越强。
3. **综合光合与呼吸的“净光合”题型**：
   - 记住关系式：总光合速率 = 净光合速率 + 呼吸速率。
   - CO₂来源：外界环境、呼吸作用（包括光呼吸和暗呼吸）。
   - 数据推导注意：若未给出呼吸速率，不能直接由净光合得出总光合。
4. **离体细胞器功能研究**（差速离心法）：
   - 等渗、pH适宜的缓冲液是维持细胞器结构和功能的前提。
   - 混合组分判断：上清液中含细胞质基质、线粒体时，能彻底分解葡萄糖（完成有氧呼吸）。
   - 叶绿体双层膜破裂，仅破坏叶绿体膜，类囊体膜不受影响，依然可进行光反应放氧。
5. **曲线与图表信息提取**：
   - 识图：横纵坐标、特殊点（a点、最大点）、趋势。
   - 多株系比较：关注相同条件下差异及随时间变化的原因（如转入了与光呼吸相关的基因，减弱了光呼吸，提高了净光合）。

## 高频易错
- **误区1：认为光照下叶肉细胞只进行光合作用不进行呼吸。**
  - 纠正：呼吸作用是生命活动的基础，所有活细胞时刻进行，光下也进行。
- **误区2：认为无线粒体的生物不能进行有氧呼吸。**
  - 纠正：好氧型原核生物（如肺炎双球菌）无线粒体，但具有有氧呼吸相关的酶，可在细胞膜和细胞质中进行有氧呼吸。
- **误区3：认为有氧呼吸产生 $\mathrm{NADH}$ 的场所只有线粒体。**
  - 纠正：糖酵解在细胞质基质中产生 $\mathrm{NADH}$，柠檬酸循环在线粒体基质中产生 $\mathrm{NADH}$ 和 $\mathrm{FADH_2}$。
- **误区4：分析主动运输速率与O₂浓度关系时，把“主动运输能量全部来自于有氧呼吸”绝对化。**
  - 纠正：O₂浓度影响有氧呼吸，主动运输由细胞呼吸（有氧呼吸和无氧呼吸）提供能量；但在O₂浓度极低时仍可能有吸收（无氧呼吸供能）。不过，常见题目中O₂浓度与吸收速率的正相关关系可作为主动运输的判断依据。
- **误区5：把“载体饱和”理解为“呼吸速率饱和”。**
  - 纠正：O₂浓度大于a时速率不再增加，主因是载体数量有限，而非呼吸供能不足（此时呼吸可能仍有富余）。
- **误区6：混淆光呼吸与暗呼吸。**
  - 纠正：光呼吸消耗O₂、释放CO₂且消耗能量，过程涉及叶绿体、过氧化物酶体、线粒体；而通常所指的呼吸作用（暗呼吸）主要在线粒体中进行，提供能量。
- **误区7：总光合速率计算不看条件。**
  - 纠正：必须同时获得净光合速率和呼吸速率才能计算总光合速率，仅凭净光合数据无法推出。

## 代表题精讲
### **题目**（2024·辽宁·21 节选）
在光下叶绿体中 $\mathrm{C_5}$ 与 $\mathrm{CO_2}$ 反应生成 $\mathrm{C_3}$；当 $\mathrm{CO_2/O_2}$ 比值低时，$\mathrm{C_5}$ 也与 $\mathrm{O_2}$ 反应生成 $\mathrm{C_2}$ 等，进而启动光呼吸，部分过程涉及叶绿体、线粒体。背景给出转基因株系净光合速率曲线。（1）反应①是二氧化碳的固定；（2）以葡萄糖为底物的有氧呼吸产生 $\mathrm{NADH}$ 的场所是细胞质基质和线粒体基质；（3）光合作用 $\mathrm{CO_2}$ 还可来自呼吸作用和光呼吸；7—10时株系1和2净光合速率差异原因是：随光照增强，转基因株系光呼吸减弱，固定碳释放减少；（4）据图3 数据不能计算总光合速率，因未知呼吸速率；选择株系1种植产量优势的判断依据是净光合速率更高。

**思路**  
- 紧扣“有氧呼吸产 $\mathrm{NADH}$ 的场所”考查过程记忆，注意糖酵解在细胞质基质，柠檬酸循环在线粒体基质。
- 结合光合作用与光呼吸、呼吸作用，厘清 $\mathrm{CO_2}$ 来源；对比曲线找差异原因：转基因后光呼吸强度降低，净光合升高。
- 明确总光合 = 净光合 + 呼吸，缺少呼吸不可求。

**步骤**  
1. 答（1）：$\mathrm{C_5}+\mathrm{CO_2}\rightarrow 2\mathrm{C_3}$ 是二氧化碳的固定。  
2. 答（2）：回忆有氧呼吸全过程的三个阶段，$\mathrm{NADH}$ 生成在细胞质基质（糖酵解）和线粒体基质（柠檬酸循环）。  
3. 答（3）：$\mathrm{CO_2}$ 来源：环境、光呼吸、呼吸作用（暗呼吸）。7—10时光照增强，光呼吸被抑制的株系净光合速率更快提升。  
4. 答（4）：图3只有净光合数据，无呼吸数据，故不能求总光合；选择株系1因净光合速率高，光呼吸弱，有机物积累多，产量高。

**点评/变式**  
- 此题跨模块融合光合、光呼吸、有氧呼吸，考查核心概念精准记忆和综合分析。变式可问“若给株系补充O₂，对净光合有何影响”等，进一步考察光呼吸。

### **题目**（2022·全国乙·7）
图示作物甲和乙的根细胞吸收 $\mathrm{NO_3^-}$ 速率与 $\mathrm{O_2}$ 浓度的关系，要求判断运输方式、解释平台期原因、比较最大吸收速率时的呼吸速率并提出促进措施。

**思路**  
- 主动运输依赖呼吸供能 → 在一定范围内，$\mathrm{O_2}$ 浓度上升呼吸增强，吸收速率增加，由此判断为主动运输。  
- 吸收速率不再增加时，受限因素往往是载体蛋白数量，而非能量供应。  
- 最大吸收速率越大，所需能量越多，耗 $\mathrm{O_2}$ 越多，暗示呼吸速率更高。  
- 生产上采取疏松土壤等措施提高 $\mathrm{O_2}$ 供应，促进根细胞有氧呼吸。

**步骤**  
1. 答（1）：$\mathrm{O_2}$ 浓度小于 a 时，吸收速率与 $\mathrm{O_2}$ 浓度呈正相关，说明主动运输需呼吸供能，故为主动运输。  
2. 答（2）：$\mathrm{O_2}$ 浓度大于 a 后速率不再增加，因为主动运输所需载体蛋白数量已达到饱和。  
3. 答（3）：据图，甲的最大吸收速率大于乙，主动运输对能量需求更大，因此甲根细胞的呼吸速率大于乙。  
4. 答（4）：定期松土，提高土壤含氧量，增强根系有氧呼吸，促进吸收。

**点评/变式**  
- 经典“吸收速率—$\mathrm{O_2}$ 浓度”模型，常考主动运输与呼吸的联系。变式可改为不同离子或温度干扰，训练学生迁移与建模能力。

### **题目**（2021·全国乙·4）
关于神经兴奋传导和传递的叙述，选错误项。

**思路**  
- 选项中 A：兴奋传到突触前膜，引起 $\mathrm{Na^+}$ 外流说法错误；应为 $\mathrm{Na^+}$ 内流形成动作电位上升支。  
- 本题虽表面考查神经调节，但涉及离子浓度的维持和主动运输，与有氧呼吸供能间接相关：静息电位维持靠 $\mathrm{Na^+}$-$\mathrm{K^+}$ 泵主动运输，突触前膜释放递质也需要能量，均依赖细胞呼吸。

**步骤**  
1. 分析 A：兴奋传至突触前膜，电压门控 $\mathrm{Na^+}$ 通道开放，$\mathrm{Na^+}$ 顺浓度内流，产生动作电位，并非外流。A错。  
2. B：突触前神经元兴奋，突触前膜释放神经递质（如乙酰胆碱），正确。  
3. C：乙酰胆碱在突触间隙扩散，结合突触后膜受体，正确。  
4. D：乙酰胆碱结合受体后，引起突触后膜电位变化（离子通道开放），正确。故错误项是 A。

**点评/变式**  
- 有氧呼吸在此处的隐性关联点：神经活动耗能大，离子梯度的重建（如 $\mathrm{Na^+}$-$\mathrm{K^+}$ 泵）依赖 ATP。备考时可串联细胞呼吸的供能角色。变式可改为“若抑制有氧呼吸，神经传导会如何变化？”强化知识迁移。
