## 知识精要
- **概率基础公式**：某事件发生概率 $P = \frac{该事件发生的情况数}{所有等可能情况总数}$。独立事件同时发生概率为各自概率的乘积（乘法定理）；互斥事件至少一个发生概率为各自概率之和（加法定理）。
- **基因的分离与自由组合规律**：位于非同源染色体上的非等位基因遗传遵循自由组合定律，分析时先逐对等位基因按分离定律计算，再进行组合。位于同源染色体上的非等位基因遗传遵循连锁互换定律，需结合交换率分析。
- **常染色体遗传传递概率**：亲子代间，亲本某条特定常染色体传给指定子代的概率为 $\frac{1}{2}$。此染色体在子代中继续向孙代传递时，每代传递概率仍为 $\frac{1}{2}$，累乘计算。
- **X染色体遗传传递概率**：在XY型性别决定中，X染色体传递受性别限制。男性的X染色体必来自母亲，且只传给女儿（传给女儿概率为 $1$，传给儿子概率为 $0$）；女性两条X染色体在减数分裂时随机分配，某条特定X染色体传给子代（不论子代性别）的概率为 $\frac{1}{2}$。
- **基因互作与表型概率计算**：当性状受多对独立分配的基因控制时，可依据基因互作关系（如互补效应、积加效应、隐性上位等）确定基因型与表型对应关系，利用自由组合定律框架和乘法原理计算特定表型比例。

## 解题方法与套路
1. **明确基因定位与遗传方式**：审题后迅速确定控制性状的基因位于常染色体还是性染色体上，位于非同源染色体还是同源染色体上，由此判断遵循自由组合还是连锁互换定律，并厘清 X/Y 染色体传递的性别限制。
2. **化繁为简，逐对分析**：涉及多对等位基因时，坚持“先分离、后组合”的思路。逐对计算配子类型及概率、子代基因型及概率，最后依据基因互作关系，将各对基因型概率组合转化为表型概率。
3. **构建概率乘积链**：对于连续世代传递特定染色体片段或基因组合的题目，将每一代（或每一步配子传递）视为独立事件，画出传递路径，列出各步概率，利用乘法定理求解最终概率。
4. **逆向推理与纯合体鉴定**：根据子代表型及比例逆向推知亲本基因型，或通过设计特定测交或自交方案鉴定个体基因型。选择与待测个体杂交的亲本时，应能使不同假设下的子代表型存在明确、稳定的区分（通常用隐性纯合子或能激发特定性状互作的纯合子）。

## 高频易错
- **混淆“特定等位基因”与“同源染色体上特定基因座”的概率计算**：计算得到亲本特定染色体（如“来自同一个个体的同一个 STR”）的概率，不等同于获得某个等位基因的概率。题目往往要求追踪染色体片段而非等位基因本身，谨慎区分“同源染色体一条”与“该条染色体的特定一个拷贝”。
- **忽略 X 染色体传递的性别限制**：X 染色体经男性传递时，不会传给儿子；从男性传向孙代时，其路径必然“男性→女儿→孙辈”。遗漏性别限制会导致传递概率误算为普通的 $\frac{1}{2}$ 相乘。
- **多对等位基因与亲本无中生有比例分配出错**：计算亲本产生配子以及子代基因型比例时，未严格遵循乘法原理逐对展开，仅凭记忆“9:3:3:1”变式机械套用，在非标准杂交组合或非对称父母本基因型时易出错。
- **纯合体鉴定时子代表型区分度不足**：设计杂交方案时，所选亲本与待测个体杂交的子代在不同假设下表型可能重合，无法唯一判定待测基因型。确保所选亲本使所有可能的子代表型具有排他性。

## 代表题精讲
**题目**：（2024·辽宁）家系中常染色体 STR（D18S51）与 X 染色体 STR（DXS10134）的传递概率分析。
**思路**：明确 D18S51 位于常染色体，按每代 $\frac{1}{2}$ 概率传递计算；DXS10134 位于 X 染色体非同源区段，男性个体该 STR 必来自母亲且只传给女儿。分别构建从 I 代到 III 代沿特定亲属链的染色体片段传递路径，用乘法原理累乘各步概率。
**步骤**：
- 选项 A：III-1 与 II-1 得到 I 代同一个体同一 D18S51。II-1 从 I 代获得目标片段的概率为 $\frac{1}{2}$，III-1 从 II-1 获得该片段的概率为 $\frac{1}{2}$，两步独立，概率为 $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$，而非 $\frac{1}{2}$，A 错。
- 选项 B：III-1 与 II-1 得到同一 DXS10134。II-1（男性）从 I 代获得目标 X 染色体片段概率为 $\frac{1}{2}$。III-1 的 X 染色体来自母亲 II-2，与 II-1 无关，无法由 II-1 传递，概率为 $0$，总分概率 $0$，B 错。
- 选项 C：III-1 与 II-4 得到同一 D18S51。II-4 从 I 代获得目标的概率为 $\frac{1}{2}$；III-1 的该常染色体来自父亲 II-3，II-3 与 II-4 为夫妻，II-3 传递该片段给 III-1 的概率为 $\frac{1}{2}$。II-3、II-4 各自获得 I 代同一片段为独立事件，总概率需考虑两者均从 I 代得到同一片段且传递给子代，计算应为 $\frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$，C 错。
- 选项 D：III-1 与 II-4 得到同一 DXS10134。II-4 为男性，DXS10134 仅来自 I 代母亲，且其 X 染色体只能传给女儿。III-1 为男性，X 染色体完全来自母亲 II-3，与 II-4 无 X 染色体的父系传递路径，因此概率恒为 $0$，D 对。
**点评/变式**：链式传递概率计算题的关键在于厘清每一代染色体的单向传递路径，尤其注意性染色体在男女性别间的“断点”。变式可变为计算姑侄、表亲等旁系血亲间共享特定染色体片段的概率，方法不变。

**题目**：（2022·全国乙）植物花色受 A/a、B/b 两对独立基因控制，A_B_紫色，A_bb 红色，aa_ _白色。紫花 AaBb 与红花杂合体 Aabb 杂交、白花纯合体鉴定。
**思路**：第一问为特定组合测交变形，直接分枝法或棋盘格列出配子与合子，依据基因互作规则统计表型。第二问要求一次杂交区分两种白花纯合体（aabb 或 aaBB），杂交伙伴需满足与这两种基因型杂交后代表型截然不同，且能唯一指向待测基因型。
**步骤**：
- （1）AaBb × Aabb：Aa × Aa → 子代 A_ 概率 $\frac{3}{4}$，aa 概率 $\frac{1}{4}$；Bb × bb → 子代 Bb 概率 $\frac{1}{2}$，bb 概率 $\frac{1}{2}$。组合得：A_Bb（紫色）概率 $\frac{3}{4} \times \frac{1}{2} = \frac{3}{8}$；A_bb（红色）概率 $\frac{3}{4} \times \frac{1}{2} = \frac{3}{8}$；aa_ _（白色）概率 $\frac{1}{4} \times 1 = \frac{1}{4} = \frac{2}{8}$。故白:红:紫 = 2:3:3。红花植株基因型 AAbb、Aabb。白花植株（aaBb、aabb）中纯合体 aabb 占 $\frac{1}{2}$。
- （2）待测白花纯合体甲或为 aabb，或为 aaBB。选用纯合红花 AAbb 杂交：若甲为 aabb，子代全为 Aabb（红花）；若甲为 aaBB，子代全为 AaBb（紫花）。子代红、紫分明，可唯一判定。
**点评/变式**：基因互作背景下的自由组合题，第一步求表型比例务必以乘法原理逐对基因计算，建立在对基因互作表型的精确转化上。鉴定纯合体时，杂交伙伴的选择应保证所有可能基因型对应的表型结果形成“完全区分”，常选与待测基因型上下位关系明确的纯合子。变式可调整互作关系，如改用隐性上位或积加效应，思路一致。
