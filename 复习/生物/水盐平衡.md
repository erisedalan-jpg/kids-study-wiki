## 知识精要
- **水平衡的调节中枢**：下丘脑。  
  - **渗透压感受器**位于下丘脑。  
  - **渴觉中枢**位于大脑皮层。  
- **调节激素**：抗利尿激素（ADH）。  
  - **合成与分泌**：下丘脑的神经内分泌细胞合成，由垂体后叶释放。  
  - **作用**：促进肾小管和集合管对水分的重吸收，减少尿量。  
  - **分泌调节**：  
    - 细胞外液渗透压升高 → 抗利尿激素分泌增多。  
    - 细胞外液渗透压降低 → 抗利尿激素分泌减少。  
- **调节过程（失水过多时）**：  
  - 失水 → 细胞外液渗透压升高 → 下丘脑渗透压感受器兴奋 → 垂体后叶释放抗利尿激素增加 → 肾小管、集合管对水重吸收增强 → 尿量减少；同时大脑皮层产生渴觉 → 主动饮水，补充水分。  
- **关键变化方向**：  
  - 失水时：血浆渗透压**升高**，抗利尿激素分泌**增多**，尿量**减少**，渴觉**产生**。  
  - 饮水过多时：渗透压降低，抗利尿激素减少，尿量增多。

## 解题方法与套路
1. **锁定刺激信号**：判断机体失水还是饮水过多，确定渗透压变化方向（升高或降低）。  
2. **调用核心通路**：渗透压变化 → 下丘脑感受 → 抗利尿激素分泌量改变 → 肾小管、集合管重吸收水的变化 → 尿量变化，同时注意渴觉有无。  
3. **选择/判断两步走**：  
   - 先确定“应激”方向，推理出各项生理反应应如何变化。  
   - 再根据题干设问（“发生”或“不会发生”）筛选正确或错误选项。  
4. **警惕干扰项**：  
   - 区分感受器（下丘脑）与渴觉中枢（大脑皮层）。  
   - 区分抗利尿激素的合成（下丘脑）与释放（垂体）。  

## 高频易错
- **渗透压升高还是降低判断反了**：失水时渗透压升高，不是下降。  
- **抗利尿激素的分泌方向弄错**：渗透压升高促进分泌，不是抑制；失水时常误选“抗利尿激素分泌减少”。  
- **渴觉产生部位混淆**：渴觉产生于大脑皮层，不是下丘脑；下丘脑只是渗透压感受器。  
- **肾小管重吸收变化反向**：抗利尿激素增加 → 重吸收水增强，尿量减少；误记为重吸收减弱。  
- **激素来源记错**：抗利尿激素是由下丘脑合成、垂体释放，单一答“垂体分泌”常失分。

## 代表题精讲
**题目**（2019·新课标Ⅱ·4）当人体失水过多时，不会发生的生理变化是  
A. 血浆渗透压升高  
B. 抗利尿激素分泌减少  
C. 大脑皮层产生渴觉  
D. 肾小管重吸收水增多  

**思路**  
人体失水过多时，细胞外液渗透压升高，触发一系列调节以保水、补水。不会发生的变化应与该调节方向相反。

**步骤**  
1. 失水 → 细胞外液渗透压升高 → A 会发生。  
2. 渗透压升高兴奋下丘脑渗透压感受器 → 垂体释放抗利尿激素增多 → B “分泌减少”不会发生。  
3. 抗利尿激素增多作用于肾小管、集合管 → 对水重吸收增强 → D 会发生。  
4. 大脑皮层产生渴觉，促使主动饮水 → C 会发生。  
因此不会发生的变化是 B。

**点评/变式**  
该题考查水盐平衡的核心调节路径，几乎每年都会以不同形式出现。常见变式是将“失水过多”换成“饮水过多”或“大量出汗后只补充水”，需逆推调节方向。解题关键：**抓住渗透压变化，顺推抗利尿激素和肾小管活动的方向，并牢记渴觉形成部位。**
