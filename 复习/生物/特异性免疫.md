## 知识精要
- **免疫系统的组成**：免疫系统包括免疫器官（如骨髓、胸腺）、免疫细胞（吞噬细胞、淋巴细胞等）和免疫活性物质（抗体、细胞因子、溶菌酶等）。
- **非特异性免疫与特异性免疫**
  - 非特异性免疫：生来就有，不针对某一特定病原体，对多种病原体都有防御作用，范围广，反应快，包括皮肤黏膜的屏障作用、吞噬细胞的吞噬作用、体液中的杀菌物质等。
  - 特异性免疫：出生后与病原体斗争形成，针对特定抗原，具有专一性，包括体液免疫和细胞免疫。
- **特异性免疫的过程**
  - **体液免疫**（主要针对细胞外病原体或游离的抗原）：
    1. 抗原呈递细胞（APC，如树突状细胞、巨噬细胞、B细胞）摄取、处理抗原，并将抗原肽—MHC复合物呈递在细胞表面。
    2. 抗原呈递细胞将抗原呈递给辅助性T细胞（Th），同时B细胞可通过表面受体直接识别抗原（第一信号）。
    3. 辅助性T细胞被激活后，表面特定分子发生变化并与B细胞结合（第二信号），同时分泌细胞因子。
    4. B细胞在抗原刺激和细胞因子作用下增殖分化，大部分分化为浆细胞，浆细胞产生并分泌抗体（免疫球蛋白），抗体与抗原特异性结合，形成沉淀或细胞集团，最终被吞噬细胞吞噬清除；小部分分化为记忆B细胞，长期存活，当同种抗原再次入侵时迅速增殖分化。
  - **细胞免疫**（主要针对胞内寄生病原体、肿瘤细胞、移植器官等）：
    1. 被病原体侵染的靶细胞（或癌细胞等）可将抗原肽—MHCⅠ类分子呈递于细胞表面。
    2. 细胞毒性T细胞（Tc）识别靶细胞上的抗原肽—MHCⅠ复合物，并被辅助性T细胞释放的细胞因子激活。
    3. 活化的细胞毒性T细胞（效应T细胞）与靶细胞密切接触，释放穿孔素和颗粒酶等，使靶细胞裂解死亡，暴露出的病原体被抗体结合或被吞噬细胞清除。
    4. 记忆T细胞在再次遇到相同抗原时迅速增殖分化为效应T细胞。
  - **两类免疫的关系**：体液免疫中的辅助性T细胞在细胞免疫中也起关键作用（分泌细胞因子）；细胞免疫裂解靶细胞后释放的抗原可引发体液免疫；两者相辅相成。
- **免疫细胞的功能**
  - 吞噬细胞（如巨噬细胞）：参与非特异性免疫（直接吞噬、消化病原体）和特异性免疫（作为抗原呈递细胞呈递抗原）。
  - 辅助性T细胞：识别抗原肽—MHCⅡ复合物，分泌细胞因子，辅助B细胞和细胞毒性T细胞的活化、增殖和分化。
  - 细胞毒性T细胞（效应T细胞）：识别并裂解靶细胞。
  - B细胞：呈递抗原、分化为浆细胞产生抗体。
  - 浆细胞：分泌抗体。
  - 记忆细胞：长期存在，二次免疫时快速应答。
- **二次免疫的特点**：反应快、强度强，抗体浓度高，可在大量病原体入侵前及时清除。
- **免疫功能实验分析**：淋巴细胞（包括T细胞和B细胞）是特异性免疫的核心；抗体产生依赖于完整的体液免疫路径；T细胞含量可反映细胞免疫水平。

## 解题方法与套路
1. **锁定免疫过程类型**：
   - 题干涉及“抗体”“浆细胞”“B细胞”“细胞因子”“辅助性T细胞”等→重点考虑体液免疫。
   - 题干涉及“靶细胞裂解”“细胞毒性T细胞”“效应T细胞”等→重点考虑细胞免疫。
   - 有细胞因子参与常涉及两种免疫的桥梁——辅助性T细胞。
2. **分清“识别”与“清除”**：
   - 识别：特异性识别抗原依赖于B细胞、T细胞表面的受体，效应T细胞识别靶细胞表面的抗原肽-MHC复合物；吞噬细胞可非特异性识别“非己”成分，MHC分子参与呈递。
   - 清除：抗体与抗原特异性结合后由吞噬细胞最终清除；细胞免疫通过效应T细胞使靶细胞裂解，暴露的病原体再由体液免疫和吞噬细胞清除。需要明确：效应T细胞不能直接清除游离的病毒，浆细胞不能直接吞噬病毒，抗体不能直接清除胞内病原体。
3. **把握免疫细胞的功能术语**：
   - 吞噬细胞：摄取、处理、呈递抗原，吞噬消化。
   - 辅助性T细胞：分泌细胞因子，辅助B细胞和细胞毒性T细胞活化。
   - 细胞毒性T细胞：识别并裂解靶细胞（注意：不是产生抗体，不是吞噬）。
   - 浆细胞：分泌抗体，本身不能识别抗原。
   - 记忆细胞：增殖分化，不直接产生抗体或裂解靶细胞。
4. **实验设计题审题关键**：
   - 若切除某种细胞（如淋巴细胞）后功能丧失，回输该细胞后功能恢复，可说明该细胞是必需的。
   - 检测淋巴细胞含量、抗体浓度、吞噬率等指标，需与对照组比较，区分增强的是非特异性免疫还是特异性免疫。
   - 回答“特点”时，必须使用教材规范性语言：非特异性免疫是“生来就有，不针对特定病原体，对多种病原体都有一定的防御作用”，特异性免疫特性为“后天获得，针对特定抗原”。

## 高频易错
- **混淆效应T细胞与浆细胞的功能**：效应T细胞的作用是识别并裂解被感染的靶细胞，浆细胞产生抗体；二者不可混淆。错误选项常描述“效应T细胞清除内环境中的病毒”或“浆细胞直接吞噬病原体”。
- **模糊“直接清除”的含义**：病毒被清除最终依赖吞噬细胞，抗体本身不能直接“清除”，只是标记和凝集，需由吞噬细胞完成；效应T细胞裂解靶细胞后释放的病原体仍需体液免疫和吞噬细胞处理。注意题干中出现“直接清除内环境中的病毒”的选项往往错误。
- **非特异性与特异性免疫的特点记串**：非特异性免疫是先天、无特异性；特异性免疫是后天、有特异性。描述特点时不能张冠李戴。
- **T细胞的作用范围不清**：T细胞既参与细胞免疫（细胞毒性T细胞），也参与体液免疫（辅助性T细胞）。题干问T细胞的功能时，需要兼顾。
- **忽略活化与抑制的调节**：免疫反应后，活化的免疫细胞功能会受到抑制性调节（如调节性T细胞或凋亡），以维持稳态。如题干图中活化的细胞4（可能指细胞毒性T细胞或辅助T细胞）在病毒清除后功能受抑制是正确的稳态调节。
- **记忆细胞不能直接产生抗体或直接裂解靶细胞**：记忆B细胞受抗原刺激后增殖分化为浆细胞产生抗体，记忆T细胞增殖分化为效应T细胞，它们都不是直接产生效应。

## 代表题精讲
### **题目** 2024-辽宁-17（部分示意图题）
题干简述：图示病毒入侵肝脏时肝巨噬细胞活化引起免疫反应，涉及多种细胞和物质（细胞1、2、3、4，物质Y等）。选择正确叙述。

**思路**：从选项反推，调用特异性免疫过程中各细胞功能，结合图解（虽未提供，可根据选项描述推断细胞角色）。肝巨噬细胞即吞噬细胞，可呈递抗原，参与非特异性吞噬和特异性呈递。细胞1可能在辅助T和B细胞间，细胞2为辅助T细胞，细胞3可能为浆细胞（分泌物质Y为抗体），细胞4可能为效应T细胞或记忆T细胞？选项B说“细胞2既可以促进细胞4的活化，又可以促进细胞1的活化”，暗示细胞2为辅助性T细胞，细胞4为细胞毒性T细胞，细胞1为B细胞，合理。选项C：“细胞3分泌物质Y和细胞4均可直接清除内环境中的病毒”——细胞3为浆细胞分泌抗体，抗体不能直接清除病毒，细胞4为效应T细胞作用于靶细胞，不直接清除游离病毒，故C错。选项D：“病毒被清除后，活化的细胞4的功能将受到抑制”，考查免疫稳态，正确。结合选项A：肝巨噬细胞既能参与非特异性免疫（吞噬）也能参与特异性免疫（呈递抗原），正确。故答案ABD。

**步骤**：
1. 确认肝巨噬细胞的功能：吞噬、抗原呈递，符合A。
2. 推断细胞2（辅助T细胞）通过细胞因子促进B细胞（细胞1）和细胞毒性T细胞（细胞4）活化，B正确。
3. 物质Y应为抗体，细胞3为浆细胞，抗体不能直接清除病毒，细胞4的效应T细胞只裂解靶细胞，不能直接清除内环境病毒，C错误。
4. 免疫功能有负反馈调节，病原体清除后活化细胞4受抑制，D正确。

**点评/变式**：本题通过示意图综合考查体液免疫和细胞免疫的协调，需准确掌握抗体与效应T细胞的作用对象和方式。易错点在于混淆“识别”与“清除”以及“直接清除”的内涵。变式训练中常将“细胞4”改为记忆细胞，考察记忆细胞不能直接作用。

### **题目** 2014-新课标Ⅱ-08（实验探究+过程填空）
题干简述：探究复方草药对细菌性乳腺炎疗效与免疫功能增强的关系，设模型小鼠分组，检测吞噬细胞吞噬能力、T细胞含量等。填空回答非特异性免疫特点、效应T细胞作用、T细胞产生的因子及体液免疫过程。

**思路**：第（1）问直接考查非特异性免疫的特点，应调用教材原文。第（2）问根据“T细胞含量增高”和“细胞免疫”填效应T细胞的作用——识别并与靶细胞密切接触使其裂解死亡。第（3）问串联体液免疫：T细胞产生淋巴因子（现在教材称“细胞因子”），作用于B细胞增殖分化为浆细胞，浆细胞产生抗体。遵循从真题提供的解析找标准答案。

**步骤**：
1. （1）非特异性免疫特点：机体生来就有，不针对某一特定病原体，而是对多种病原体都有一定的预防作用。
2. （2）效应T细胞的作用：识别并与被病原体入侵的宿主细胞密切接触，使之裂解死亡。
3. （3）T细胞可产生淋巴因子（细胞因子），受到抗原刺激的B细胞可在该因子作用下增殖分化为浆细胞，浆细胞产生抗体。

**点评/变式**：此题是典型的实验背景下的过程描述填空，经常将新的情境与经典知识结合。必须牢记特异性免疫中各种细胞的作用名称。注意不同教材版本表述差异，但核心不变。答题时必须用短语填空，如“淋巴因子”或“细胞因子”，可通用。实验结论推断中，比较各组数据要区分“显著高于”“极显著高于”等词，答题时概括成“增强了非特异性免疫功能”等。

### **题目** 2010-新课标-07（淋巴细胞与抗体产生）
题干简述：用大鼠进行淋巴细胞转移实验。A组去淋巴细胞后丧失产抗体能力；将B组淋巴细胞转给A组后，A组恢复产抗体能力。回答：实验说明什么细胞是免疫反应所需？

**思路**：实验通过“去除-回输”策略，证明淋巴细胞是产生抗体的必要条件。因为淋巴细胞包括B细胞和T细胞等，体液免疫中B细胞分化为浆细胞产生抗体，离不开辅助性T细胞，所以淋巴细胞是免疫反应所需的细胞。填空答案直接为“淋巴细胞”。

**步骤**：
1. 实验自变量为是否有淋巴细胞，因变量为能否产生抗体。
2. 去掉淋巴细胞后抗体产生能力丧失，回输后恢复，表明淋巴细胞是免疫功能（产生抗体）所必需的细胞。
3. 此实验说明了淋巴细胞是免疫反应所需的细胞，不能细分至T或B，因题干未区分。

**点评/变式**：此类实验设计思想常用于证明某器官或细胞的功能。变式可能进一步探究特异性免疫类型：若仅去除B细胞，则可能影响体液免疫等。答题要紧扣实验结论，不可过度推断。
