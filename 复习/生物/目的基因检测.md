## 知识精要
- **基因文库**
  - 基因组文库：包含某一生物 **全部** DNA 片段（含外显子、内含子、非编码区）。理论上覆盖所有基因。
  - cDNA 文库：以 mRNA 为模板逆转录而来，只包含 **部分** 基因（已表达的外显子），无内含子和启动子。
- **目的基因的获取**
  - 从基因组文库或 cDNA 文库中通过 **标记探针** 筛选目的基因。
- **目的基因导入受体细胞后的检测**（三个层次）
  - DNA 水平检测：是否导入目的基因——DNA 分子杂交（Southern blot）或 PCR。
  - 转录水平检测：是否转录出 mRNA——分子杂交（Northern blot）或 RT-PCR。
  - 翻译水平检测：是否表达出蛋白质——抗原-抗体杂交（检测 **表达产物**）。
  - 个体水平检测：是否表现出目标性状——进行 **田间试验** 或表型观察（如耐旱性、抗虫性等）。
- **转基因植株的遗传分析**
  - 若外源基因整合到 **同源染色体的一条上**，相当于杂合子（$Aa$），自交子代性状分离比符合孟德尔分离定律（一般为 $3:1$）。
  - 若整合到 **同源染色体的两条上**（纯合状态），自交子代全为耐旱（不分离）。

## 解题方法与套路
1. **区分两种基因文库类题目**
   - 凡涉及“所有基因”、“包括非编码序列” → 基因组文库。
   - 凡涉及“mRNA 逆转录”、“无内含子”、“部分基因” → cDNA 文库。
   - 填空时直接默写：基因组文库含 **全部** 基因，cDNA 文库含 **部分** 基因。
2. **目的基因检测层次答题法**
   - 看清设问是哪一层次：
     - 问“是否成功导入” → 答检测目的基因（DNA）。
     - 问“是否正确表达” → 先答检测 **表达产物（蛋白质）**，再答检测 **个体性状**（如耐旱性）。
     - 题目常先填“表达产物”，再填“耐旱性”（或其他具体性状）。
3. **转基因整合位置的遗传推理**
   - 二倍体自交子代 $3:1$ 分离 → 目的基因整合在 **同源染色体的一条上**（杂合）。
   - 自交全为耐旱（无分离） → 整合在 **同源染色体的两条上**（纯合）。
   - 若问测交后代比例，杂合时为 $1:1$。
4. **流程类填空**
   - 建文库 → **筛选** 目的基因 → 导入农杆菌 → 转化受体细胞 → 再生植株 → **检测表达产物** → **田间试验**。

## 高频易错
- **混淆文库类型**  
  许多考生死记“cDNA 文库是部分基因”，但忘记其来源是 mRNA，不含启动子、内含子；而基因组文库含有全部遗传信息。
- **“正确表达”的检测对象错位**  
  题目要求填“检测此再生植株中该基因的 ______”，若只填“mRNA”或“目的基因”不完整，正确表达必须检测翻译产物——**蛋白质**，最后才是个体水平性状。
- **遗传比例与整合位置对应混乱**  
  $3:1$（或 $1:2:1$）对应于一条同源染色体上插入（杂合），并非两条。看到 $3:1$ 直接默写“同源染色体的一条上”。
- **选项用词偏差**  
  “表达产物”不要写作“基因产物”或“性状”，需精准采分。

## 代表题精讲
**题目**：2014 年新课标 II 卷第 12 题，以耐旱基因从植物甲转入植物乙为背景，考查基因文库、目的基因筛选、表达检测及遗传分析。（原题 4 小问）

**思路**：   
（1）直接考查两种文库的基因覆盖度定义。  
（2）考查从文库中获取目的基因的操作——筛选。  
（3）考查目的基因表达检测的层次：先翻译产物，后个体性状。  
（4）根据自交后代比例推断整合位置，运用分离定律。

**步骤**：  
- （1）基因组文库含生物 **全部** 基因；cDNA 文库含 **部分** 基因。  
- （2）建立基因组文库后，用探针从中 **筛选** 耐旱基因。  
- （3）基因表达成功与否，先检测 **表达产物**（蛋白质），若阳性，再在田间检测 **耐旱性**（个体性状）。  
- （4）耐旱基因若整合到 **同源染色体的一条上**，相当于杂合（$Aa$），自交后代耐旱与不耐旱比例为 $3:1$；若整合到两条上则为纯合，不会出现不耐旱子代。故填“同源染色体的一条上”。

**点评/变式**：  
该题是基因工程“获取—导入—检测—遗传”全链条的经典考法。变式常改为检测方法选择题：如问“要检测耐旱基因是否转录出 mRNA，应用什么技术？”应回答分子杂交（Northern blot）或 RT-PCR。务必分层记忆：DNA 水平、RNA 水平、蛋白质水平、个体水平的一一对应，避免混淆。遗传部分可能改为给出子代比例，反推亲代整合拷贝数或位置。
