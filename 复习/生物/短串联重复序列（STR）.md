## 知识精要
- **短串联重复序列（STR）**：由 $2\text{–}6$ 个碱基作为核心重复单位串联而成的 DNA 序列，广泛分布于真核生物基因组中。核心序列重复次数的个体差异形成高度多态性，常用于遗传图谱构建、亲缘鉴定和法医学个体识别。
- **常染色体 STR 的遗传规律**：
  - 常染色体上的 STR 位于同源染色体上，每个个体含有两个等位基因，分别来自父方和母方。
  - 亲代传递配子时，同源染色体分离，每个配子获得其中一个等位基因的概率为 $\frac{1}{2}$。
  - 子代获得亲代某一特定等位基因的概率为 $\frac{1}{2}$（不考虑突变）。
- **性染色体 STR 的遗传规律**（以 X 染色体非同源区段为例）：
  - X 染色体上的 STR 在 Y 染色体上无对应等位基因。
  - 父亲的 X 染色体一定传给女儿，不会传给儿子；母亲的 X 染色体以 $\frac{1}{2}$ 的概率传给儿子或女儿。
  - 计算特定 X-STR 传递概率时，必须区分个体性别和传递路径。
- **从共同祖先获得同一等位基因的概率计算**：
  - 逐代计算每个传递环节的概率，再利用 **乘法定理** 将各环节概率连乘。
  - 若存在多种可能的传递路径，需用 **加法定理** 求和（本题不涉及）。

## 解题方法与套路
1. **明确标记位置与遗传方式**  
   先确定 STR 所在染色体类型（常染色体 / X 染色体非同源区段），推断该标记的传递规律。
2. **画出简化家系图并标注世代与性别**  
   根据题干描述还原亲缘关系，标出需要比较的个体（如“Ⅲ-1 与 Ⅱ-1”“Ⅲ-1 与 Ⅱ-4”），以及共同祖先（Ⅰ代个体）。
3. **分解传递路径**  
   将目标个体得到祖先某一特定等位基因的过程拆分为若干独立步骤：
   - 祖先传给二代个体的概率；
   - 二代个体传给三代个体的概率；
   每个步骤对应一次减数分裂和配子结合过程。
4. **分别计算概率并连乘**  
   对每一步应用分离定律和性别决定特点计算概率，最后将所有步骤的概率连乘得到最终答案。
5. **选项对比验证**  
   计算每个选项的值，注意区别常染色体 STR 与 X-STR 因遗传方式不同导致的概率差异，并结合“概率为 0”的可能性（如无法从指定祖先获得该等位基因）。

## 高频易错
- **混淆常染色体与 X 染色体的传递方式**  
  误将 X 染色体 STR 当做常染色体处理，忽略父亲 X 只能传给女儿、不能传给儿子的特点，导致概率算错。
- **未正确识别比较对象和共同祖先**  
  选项中常出现对比不同个体（如Ⅲ-1 与Ⅱ-1 或Ⅱ-4）得自同一祖先的概率，若未厘清共同祖先和对应的传递路径，容易张冠李戴。
- **概率相乘时遗漏步骤**  
  如从Ⅰ代到Ⅲ代需经过两个世代传递，每一步均为 $\frac{1}{2}$ 时，正确结果应为 $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$，但常有学生误算为 $\frac{1}{2}$ 或 $\frac{1}{8}$。
- **忽略“同一个体同一等位基因”的含义**  
  题干要求的是得到 **同一个体的同一条染色体上的同一个 STR 等位基因**，而非仅仅得到相同基因型，计算时需限定特定的那条染色体。
- **对 X-STR 概率为 0 的判断不敏感**  
  某些性别组合下，个体无法从指定祖先获得 X 染色体（如孙子与奶奶的 X 染色体传递需经父亲，父亲传给儿子的不再是奶奶的 X 染色体），此时概率为 0，常被错算为非零。

## 代表题精讲
### 【代表题】2024-辽宁-20
**题目**  
某家系中三代人的常染色体 STR（D18S51）和 X 染色体 STR（DXS10134，Y 染色体上无对应序列）的传递情况如图所示（图略），不考虑突变。下列叙述正确的是哪一项？  
A. Ⅲ-1 与Ⅱ-1 得到Ⅰ代同一个体的同一个 D18S51 的概率为 $\frac{1}{2}$  
B. Ⅲ-1 与Ⅱ-1 得到Ⅰ代同一个体的同一个 DXS10134 的概率为 $\frac{3}{4}$  
C. Ⅲ-1 与Ⅱ-4 得到Ⅰ代同一个体的同一个 D18S51 的概率为 $\frac{1}{4}$  
D. Ⅲ-1 与Ⅱ-4 得到Ⅰ代同一个体的同一个 DXS10134 的概率为 0  

**思路**  
根据家系关系判断：Ⅱ-1、Ⅱ-2、Ⅱ-3、Ⅱ-4 均为Ⅰ代夫妇的子女；Ⅲ-1 是Ⅱ-3 的后代。分别计算各选项中的两种 STR 从Ⅰ代某一特定个体传递至后代的概率，注意常染色体和 X 染色体的遗传规律差异。

**步骤**  
- **选项 A**：D18S51 位于常染色体。Ⅱ-1 得到Ⅰ代某个体的特定等位基因概率为 $\frac{1}{2}$，Ⅲ-1 要通过父亲Ⅱ-3 从Ⅰ代得到该等位基因的概率为 $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$。所以Ⅲ-1 与Ⅱ-1 得到同一 I 代个体同一 D18S51 的概率为 $\frac{1}{2} \times \frac{1}{4} = \frac{1}{8}$，A 错误。  
- **选项 B**：DXS10134 位于 X 染色体非同源区段。Ⅱ-1（女性）得到Ⅰ代某个体的特定 X 等位基因概率为 $\frac{1}{2}$；Ⅲ-1 若为男性（从家系推断），其 X 染色体来自母亲（Ⅱ-?），但此处考虑来自Ⅰ代的相同 X 染色体：需分析Ⅱ-1 和Ⅲ-1 得到同一 I 代个体同一 X 染色体的概率。根据解析，Ⅱ-1 和Ⅱ-2 获得同一 I 代个体同一 DXS10134 概率为 $\frac{1}{2}$，Ⅲ-1 获得来自Ⅱ-1 那个特定等位基因的概率为 $\frac{1}{2}$，故最终 $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$，B 错误。  
- **选项 C**：同样 D18S51 在常染色体。Ⅱ-4 获得 I 代某个体的特定等位基因概率 $\frac{1}{2}$，Ⅲ-1 通过父亲Ⅱ-3 获得同一等位基因的概率为 $\frac{1}{4}$，概率乘积 $\frac{1}{2} \times \frac{1}{4} = \frac{1}{8}$，C 错误。  
- **选项 D**：DXS10134 位于 X 染色体。Ⅱ-4 若为男性，其 X 染色体一定来自母亲（Ⅰ代女性），不可能来自父亲。Ⅲ-1 若为男性，其 X 染色体来自母亲，而母亲（Ⅱ-? ）的 X 染色体一条来自Ⅰ代女性、一条来自Ⅰ代男性。要Ⅲ-1 与Ⅱ-4 得到同一 I 代个体的同一 X 染色体，需经父系传递一致，但男性传给儿子的不是 X 染色体，故无法成立；若Ⅱ-4 和Ⅲ-1 均为男性，二者从同一 I 代得到相同 X-STR 的概率为 0。解析指出概率为 0，D 正确。

**点评/变式**  
本题核心在于区分常染色体 STR 与 X-STR 的遗传特点，以及正确拆解概率计算环节。易错点在于忽略性别对 X 染色体传递的限制，以致误判 D 项。变式训练：可将其中的个体性别或比较对象改变，比如问“Ⅲ-1 与Ⅱ-2 得到Ⅰ代同一个体的同一 X-STR 的概率”，需重新梳理传递路径和性别，巩固乘法定理的应用。
