## 知识精要
- **碳源定义**：凡可被微生物利用、为细胞提供碳架或用于合成代谢产物的含碳物质均称为碳源。
- **主要作用**：构成微生物细胞物质（如糖类、脂质、蛋白质等）及代谢产物；对异养微生物而言，碳源往往兼作能源。
- **常见碳源**：糖类（葡萄糖、蔗糖、淀粉等）、有机酸、醇类、油脂、烃类及工农业废液（如制糖废液）等。
- **碳源利用条件**：微生物能否利用某种碳源取决于其是否具备相应的分解酶系（如淀粉酶、纤维素酶等）和转运系统。不能利用的碳源即使丰富也无法被同化。
- **最适碳源的区分**：
  - **最适生长碳源**：使菌体生物量（如细胞干重）最大的碳源。
  - **最适产物碳源**：使目标产物（如化合物 S）产量最大的碳源。二者可能不同。
- **培养基的灭菌**：玻璃器皿常用干热灭菌（如 160~170 ℃，1~2 h）或高压蒸汽灭菌（121 ℃，103.4 kPa，15~30 min）。
- **培养基成分**：除碳源外，还需氮源、无机盐、水，部分需添加生长因子。

## 解题方法与套路
1. **表格数据解读**  
   - 比较不同碳源条件下的“细胞干重”列，值最大者对应**最适生长碳源**。  
   - 比较“产物产量”（如 S 产量）列，值最大者对应**最适生产碳源**。  
   - 若某碳源对应的细胞干重或产量极低（如 0 或接近 0），说明菌株难以或不能利用该碳源。
2. **不能利用碳源的原因分析**  
   - 答题框架：该微生物**缺乏分解该碳源所需的关键酶**（如“缺乏淀粉酶”），因此不能将复杂碳源水解为可利用的小分子，导致无法生长。
3. **探究最适碳源浓度的实验设计**  
   - **步骤模板**：  
     ① 以该碳源溶液（如制糖废液）为唯一碳源，配制**一系列不同浓度梯度**的培养基。  
     ② 接种等量菌株 C，在**其他条件相同且适宜**的条件下培养一段时间。  
     ③ 测定并比较各浓度下目标产物的产量（或菌体生物量，视实验目的而定）。  
     ④ **最高产量对应的浓度即为最适碳源浓度**。
4. **“废液利用”意义的简答套路**  
   - 常从**环保**（减少污染排放）、**经济**（降低生产成本、废物资源化）或**可持续发展**（循环利用）等角度任选一点作答。

## 高频易错
- 混淆“最适生长碳源”与“最适产物碳源”，错把细胞干重最大值对应的碳源直接当作最佳产物的碳源。务必看清问题指向。
- 解释不能利用淀粉等大分子碳源时，仅答“不能分解淀粉”而遗漏“缺乏淀粉酶”这一直接原因，导致表述不严谨而扣分。
- 设计最适浓度实验时，**漏掉“浓度梯度”或“唯一碳源”**，或未强调“测定并比较产量/生物量”，导致实验方案不完整。
- 答营养物质时漏掉“水”或“无机盐”，误认为生长只需碳源和氮源。
- 灭菌方法混用：玻璃器皿常用干热灭菌和高压蒸汽灭菌，**不能用灼烧灭菌（常用于接种工具）**，勿混淆。

## 代表题精讲
**题目**：2022·全国乙卷·11  
某小组比较不同碳源对菌株 C 生长及产物 S 产量的影响，结果如表（葡萄糖、淀粉、制糖废液，分别给出细胞干重和 S 产量）。设置问题链：灭菌方法、最适碳源判断、不能利用淀粉的原因、确定最适碳源浓度的实验思路、废液利用的意义。

**思路**  
本题全面考查微生物培养中碳源选择与实验分析能力。需结合表格数据对比分析，调用微生物营养与代谢基础，并设计梯度浓度实验。

**步骤**  
1. **灭菌方法**：微生物实验室中玻璃器皿常用高压蒸汽灭菌、干热灭菌。  
2. **最适碳源分析**：  
   - 由表可知细胞干重：葡萄糖 3.12 g/L 最大 → **最适生长碳源为葡萄糖**。  
   - S 产量：制糖废液 0.18 g/L 最大 → **生产 S 的最适碳源为制糖废液**。  
   - 培养基还需提供氮源、无机盐和水等。  
3. **淀粉不能利用的原因**：菌株 C 细胞中缺少**淀粉酶**，无法将淀粉分解为可利用的小分子糖。  
4. **最适碳源浓度实验思路**：以制糖废液为唯一碳源，配制一系列浓度梯度的培养基，分别接种等量菌株 C，在相同且适宜条件下培养，测定并比较 S 产量，产量最高的浓度即为最适。  
5. **意义**：废物利用可减少环境污染、降低生产成本、实现资源循环利用等（答出一点即可）。

**点评/变式**  
本题是典型的“表格→结论→分析→设计”递进式考题。易错点在于最适碳源的双重判断和酶缺失原因表述。变式训练中，若碳源为乳糖、纤维素等，解释不能利用的原因同样遵循“缺乏相应水解酶”的模式；实验设计可迁移至探究最适氮源浓度、最适 pH 等，关键在于配制梯度、单一变量控制及结果检测指标的明确。
