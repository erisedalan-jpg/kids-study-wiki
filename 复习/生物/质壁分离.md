## 知识精要
- **渗透作用基础（质壁分离原理）**
  - **渗透作用**：水分子（或其他溶剂分子）通过半透膜的扩散。
  - **发生条件**：①具有半透膜；②膜两侧存在浓度差（此处浓度指**摩尔浓度**，即单位体积内溶质分子数）。
  - **植物细胞渗透模型**
    - **原生质层**（细胞膜、液泡膜及两层膜间的细胞质）相当于**半透膜**。
    - **细胞液**（液泡内液体）、**细胞质基质**与**外界溶液**共同构成渗透系统。
    - 当外界溶液渗透压>细胞液渗透压：细胞失水，原生质层与细胞壁分离（**质壁分离**）。
    - 当外界溶液渗透压<细胞液渗透压：细胞吸水（膨胀），若此前分离，则原生质层恢复（**质壁分离复原**）。
    - 平衡时：水分**双向移动速率相等**，表现为宏观静止。
- **物质跨膜运输方式**
  - **水分子**：主要通过**被动运输**（自由扩散和协助扩散/水通道蛋白）跨越生物膜。
  - **溶质**：主动运输/被动运输，取决于具体物质；只有细胞可吸收的特定溶质才可能进入，引发质壁分离后的自动复原。
- **实验观察条件**
  - **材料选取**：必须有**中央大液泡**的成熟植物细胞，且最好带颜色（如紫色洋葱鳞片叶外表皮），便于观察。
  - **显微镜**：使用**普通光学显微镜**低倍镜即可观察到质壁分离过程。

## 解题方法与套路
1.  **确定分析对象与渗透系统**
    - 识别半透膜部分（原生质层/细胞膜），明确膜两侧溶液（细胞液/外界溶液）是什么。
2.  **比较渗透压（核心：摩尔浓度，非质量浓度）**
    - 提取题干给出或隐含的溶质浓度信息。
    - **关键辨析**：题干若给“相同质量浓度”（如g/mL），需换算或类比：$渗透压 ∝ 摩尔浓度 = \frac{质量浓度}{相对分子质量}$。质量浓度相等时，溶质相对分子质量越大，摩尔浓度越低，渗透压越小；反之，渗透压越大。
3.  **判断细胞状态（吸水/失水/平衡）**
    - **外界溶液渗透压 > 细胞液渗透压**：细胞失水，液泡缩小，原生质体体积减小→发生质壁分离。
    - **外界溶液渗透压 < 细胞液渗透压**：细胞吸水，原生质体体积增大→质壁分离复原。
    - **外界溶液渗透压 = 细胞液渗透压**：水分进出平衡，细胞形态与体积维持动态稳定。
4.  **分析曲线/数据的关键拐点**
    - 体积不再减小：内外渗透压达到平衡。
    - 体积减小后能自发增大：表明发生了**溶质跨膜运输进入细胞**，导致细胞液渗透压升高，细胞自动吸水复原。
    - 平衡时溶液浓度变化：可逆向推理植物细胞吸/失水量。
5.  **检验“细胞->溶液”与“溶液->细胞”两向对推**
    - 若细胞吸水，则外界溶液溶质总量不变、水减少→溶液浓度升高（即题干现象：“甲组溶液浓度升高”能反推细胞吸水）。

## 高频易错
- **浓度比较混淆“质量浓度”与“摩尔浓度”**
  - 致死陷阱：见题干“浓度（单位g/mL）相同”就想当然认为渗透压相同。需立刻警觉：**质量浓度相同 ≠ 摩尔浓度相同**。相对分子质量大者，摩尔浓度低，渗透压小。
- **平衡状态误判为完全停止**
  - 达平衡时，水分仍在进出，只是**双向速率相等**，宏观体积不变。
- **忽略“溶质有无跨膜”的可能**
  - 看到曲线先降后升，就是典型的溶质逐渐内流（主动运输/协助扩散）的信号。不能误以为整个过程只有水在移动。
- **原生质体与细胞体积变化不分**
  - 失水时，**原生质体体积变化量 > 细胞体积变化量**，因为有细胞壁，细胞伸缩性远小于原生质层。
- **对“液泡中液体”与“细胞质基质”的渗透压大小关系判断混乱**
  - 水分移动方向总是：**低渗→高渗**。只要细胞失水，说明水从液泡外流，则**液泡液渗透压 < 细胞质基质渗透压**（初期可能是外界溶液最高，水流向外）。

## 代表题精讲
### 2020-新课标Ⅱ-05
- **题目**：取同植物等量叶圆片，放入同质量浓度（g/mL）的甲糖液与乙糖液，甲糖相对分子质量约为乙糖的2倍。水分平衡时，测得甲组溶液浓度升高。整个过程无溶质交换。判断错误选项。
- **思路**
  1. 由结论反推动态：甲组溶液浓度升高 + 无溶质交换 → 水从细胞外流入溶液？不对，是先由溶液流入细胞；题中溶液浓度升高是静态结果；动态过程：由于质量浓度相同，甲糖分子量大 → 摩尔浓度低 → 渗透压低 → 细胞先吸水（细胞液变稀）或？。等等，外界渗透压低：水从外界进入细胞，水少了溶液浓度就升高。这正好印证甲组细胞吸水。
  2. 推断细胞内外初始渗透压：甲液渗透压（低） < 细胞液渗透压 → 细胞吸水。
  3. 按此逻辑逐一审查选项：
     - A：细胞从甲糖液吸水使其浓度升高，对。
     - B：若乙液浓度不变，即溶液失/得水为零 → 细胞净吸/失水为零，对。
     - C：若乙液浓度降低 → 乙液增加了水 → 细胞失水 → 可能质壁分离，对。
     - D：若乙液浓度升高，即细胞吸水。甲、乙两组均吸水。因初始甲摩尔浓度更低（渗透压更小），甲组吸水量应大于乙组。选项说“乙组大于甲组”明显错误，选D。
- **步骤**
  1. **换算浓度**：同质量浓度，$M_{甲}>M_{乙} \Rightarrow$ 摩尔浓度 $c_{甲}<c_{乙}$；甲液渗透压 < 乙液渗透压。
  2. **推甲组过程**：由结果“甲液浓度升高”+“无溶质交换” → 水从甲液进入细胞 → 甲液摩尔浓度低于细胞液。
  3. **逐项比对**：D项将净吸水量大小对比说反→为我所求之错项。
- **点评/变式**
  本题最核心就是“同等质量浓度 ≠ 同等摩尔浓度”陷阱。《复习》中凡见等质量浓度的不同相对分子质量溶质，立刻先比较摩尔浓度以定渗透方向。本选项结合“溶液浓度升降”来考你们逆推吸水还是失水，一旦基础概念清了，反倒简单。

### 2017-新课标Ⅱ-04
- **题目**：成熟植物细胞在A溶液中，原生质体体积先降（0~1h）后升（2~4h）。判断正确选项。
- **思路**
  - 0~1h体积减小：外界渗透压 > 内部，细胞失水质壁分离。
  - 2~4h体积增大：内部渗透压升高，发生自动复原 → A溶质可进入细胞。
  - 用排除法排查选项：细胞体积≠原生质体体积、液泡液 vs 细胞质基质渗透压关系要动态看。
- **步骤**
  1. **0~1h阶段**：细胞失水 → 液泡液中水流出→液泡液渗透压 < 细胞质基质渗透压（失水初期是外界>细胞质>液泡）。选项D错误。
  2. **体积变化量对比**：细胞壁伸缩性小 → 原生质体缩小远大于整个细胞缩小。选项B错误。
  3. **溶质运输判断**：0~1h可能已有A进入（只是外渗透压主导失水），复原阶段更是证明A已内流→选项A说“0-4h均未进入”错误。
  4. **渗透压比较（2~3h）**：此时复原中，细胞吸水，则外界溶液渗透压低于细胞液渗透压。选项C叙述“物质A溶液的渗透压小于细胞液的渗透压”正确。
- **点评/变式**
  本题典型质壁分离曲线解读。此题表明：发现曲线能自动回升，必因溶质可缓慢内流。考试还会结合“$\ce{KNO3}$、尿素、乙二醇”等可通过膜的物质来出题，平时牢记。
