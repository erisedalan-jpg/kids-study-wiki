## 知识精要
- 透明圈法原理：底物（如含氮有机物W）使固体培养基不透明，产降解酶的菌落周围因底物被分解而形成透明圈。
- 选择培养基设计：分离降解特定有机物的微生物时，以该有机物作为唯一碳源或氮源（依其元素组成），不能利用者被抑制。
- 透明圈的解读：
  - 有透明圈 → 该菌落能降解底物。
  - 无透明圈 → 不能降解，或降解产物不改变不透明性。
  - 透明圈直径 ≈ 降解能力 + 酶扩散速率。在等量加样、相同培养条件下，透明圈越大，降解能力通常越强。
- 对照实验设置：比较酶活力时，需设缓冲液空白对照（排除溶剂对底物的影响），保证加样量、酶浓度相同，测量透明圈直径。
- 固氮菌鉴别：无氮源培养基上能生长 → 可利用空气中 $N_2$ 作为氮源。

## 解题方法与套路
1. 选菌思路：若分离降解X的菌，氮源/碳源仅设为X → 用选择培养基培养 → 能在其上生长的菌可能利用X → 再通过透明圈的有无确认降解。
2. 透明圈选择题判断：
   - 优先选菌落周围出现透明圈的菌落进行纯化。
   - 比较两菌降解能力：在底物浓度、培养时间一致时，透明圈直径大者降解能力强（需注意菌落大小可能影响，通常选透明圈与菌落直径比值大的）。
3. 比较酶活性的实验设计：
   - 用含底物的固体培养基。
   - 等量、相同浓度的酶液（或溶液）滴加于培养基表面（如定点加样）。
   - 必设空白对照组：等量缓冲液（或灭活酶液）。
   - 培养后，观察并测量透明圈直径。
   - 结论：无透明圈 → 缓冲液不能降解；透明圈直径相近 → 两种酶降解能力相当；有明显大小差异 → 大者降解能力强。
4. 验证是否固氮：用无氮源培养基，接种待测菌，培养观察能否生长。能生长 → 有固氮能力；不能 → 无固氮能力。

## 高频易错
- 混淆“能生长”与“能降解”：在含W的选择培养基上生长只能说明该菌能利用W作为氮源（或碳源）生存，但不能直接证明它能将W分解为不透明的消失产物；只有出现透明圈才直接证明降解。
- 不重视空白对照：比较酶E与天然酶时，不设置缓冲液对照就缺乏基线，无法确认透明圈是否由酶引起，可能被扣分。
- 透明圈大小比较条件不一致：培养时间、温度、加样量、酶浓度、底物浓度不同都会影响结果，题目中未说明相同时需默认为相同，若题目设置陷阱需注意分析。
- 误认为透明圈直径等于降解能力：实际还与酶的扩散性、稳定性有关，但高中阶段一般简化为正相关。
- 固氮测试中仍加入含氮化合物：设计无氮源培养基时不能添加蛋白胨、铵盐、硝酸盐等，否则无法判断。

## 代表题精讲
**题目**：2019新课标Ⅱ第11题（15分），围绕从土壤筛选能降解含氮有机物W的细菌，设问选择培养基氮源、菌落选择依据、设计固氮能力实验、比较酶E与天然酶降解能力实验。

**思路**：
- (1) 要筛选降解W的菌，应让W成为目标菌必需而其他菌难利用的营养，因W含氮，设为唯一氮源。
- (2) 图示甲、乙菌落，乙菌落周围出现透明圈 → 乙能降解W，选乙。
- (3) 验证能否利用空气氮气，用无氮源培养基，观察能否生长。
- (4) 比较两种酶，需设置缓冲液对照；无透明圈证明缓冲液不能降解W；A、B透明圈直径相近说明两者降解能力相近。

**步骤**：
1. 分析(1)：分离目的菌需限制氮源种类，培养基中加入W作为唯一氮源，只有降解W的菌能利用其氮元素生存。
2. 分析(2)：观察平板上菌落形态，甲菌落周围培养基仍不透明，乙菌落周围出现透明圈，说明乙产生的酶扩散并降解了W，因此选择乙菌落纯化。
3. 分析(3)：核心是排除其他氮源。实验思路：将甲、乙菌分别接种于无氮源（如无氮基本培养基）的固体平板，适宜条件培养。预期结果及结论：若某菌能生长，则说明其能固定空气中的氮气；若不能生长，则不能。
4. 分析(4)：①三处需均滴加等量液体，C处应为缓冲液，构成空白对照组。②一段时间后观察。C无透明圈→缓冲液不能降解W。若A、B透明圈直径大小相近→酶E与天然酶降解W能力相近。若差异显著，可进一步判断强弱。

**点评/变式**：
- 透明圈法是微生物筛选的经典考点，常结合选择培养基、酶活性比较出题。
- 变式：将底物改为淀粉（遇碘变蓝，透明圈变无色圈）、纤维素（刚果红染色，透明圈不显色）、蛋白质等。本质相同：产酶菌落周围因底物被分解而出现与背景不同的圈，圈大小反映酶活力或菌株降解能力。
- 设计实验比较两种微生物的降解能力，注意等量接种、相同培养时间、测量透明圈直径（或透明圈直径与菌落直径比值）。
