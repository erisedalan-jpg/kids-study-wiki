## 知识精要

**遗传图解的规范书写**：自上而下依次写出 P（亲本）→ 配子 → F₁（子一代）→ 配子 → F₂（子二代），每代标注**基因型 + 表现型**，并在亲本下方注明性别符号（♀×♂）与杂交（×）、自交（⊗）符号。

**书写五要素**（缺一扣分）：
1. 亲本基因型与表现型完整，性别明确；
2. 配子要单独列出（一个亲本可能产生多种配子，需全部写出并用「↘↙」连线指向下代）；
3. F₁/F₂ 写出全部基因型及对应表现型；
4. 表现型比例（如灰体长翅∶残翅 = 9∶3∶3∶1）写在末行；
5. 文字说明杂交方式（杂交/自交/测交）。

**伴性遗传**：X（或 Z）染色体上的基因随性染色体传递。X 染色体隐性遗传：写基因型须带性染色体，如 $X^A X^a$、$X^a Y$；雄果蝇半合子只有一个等位基因。

**性别决定方式**：果蝇/人类为 XY 型（♀ 为 XX、♂ 为 XY）；鸟类、家禽、蛾蝶为 ZW 型（♀ 为 ZW、♂ 为 ZZ）。**ZW 型中雌性是异型**，性状由父本贡献的 Z 决定子代雄性、母本的 Z/W 决定其表现，分析时性别与基因要绑定。

**自由组合下的比例计算**：常染色体与性染色体上的两对基因独立遗传，可**分开按基因座算概率再相乘**（乘法原理），最后合并得四种表现型之比。

## 解题方法与套路

1. **先定遗传方式**：判断显隐性、基因位于常染色体还是性染色体（X/Z）。隐性性状在雌雄中比例差异、与性别关联是判定伴性的关键。
2. **写出亲本基因型**：纯合/杂合按题意定，伴性基因必须带性染色体符号。
3. **拆配子**：每个亲本按基因座分别产生配子，常染色体基因与性染色体基因组合写全。
4. **组合子代并定表现型**：用棋盘法或分别计算各基因座概率。性染色体基因要把性别一并算入（如 $X^A X^a$、$X^A Y$ 分属雌雄）。
5. **分而治之算比例**：两对独立基因分别求比（如常染色体 B/b 得 长∶残=3∶1，X 染色体 A/a 结合性别求灰∶黄），再用乘法原理相乘得最终四性状比。
6. **设计杂交求目标个体**：若一次杂交得不到目标基因型，需让 F₁ 与亲本回交/测交（如再与隐性亲本杂交）以获得目标，并用规范遗传图解表示全过程。

## 高频易错

- **配子漏写或不写**：遗传图解必须显式列出配子，省略直接失分。
- **伴性基因不带性染色体**：写成 A/a 而非 $X^A/X^a$，或雄性写成两个等位基因（应为半合子 $X^a Y$）。
- **ZW 型与 XY 型混淆**：家禽豁眼题误用 XY 型分析，雌雄异型方向弄反（ZW 型雌性为异配 ZW）。
- **表现型与性别脱节**：算 X/Z 染色体性状时忘记把性别一起统计，导致雌雄比例算错。
- **比例未用乘法原理**：把两对独立基因混在一起列棋盘易出错，应分座求概率再相乘。
- **目标个体一步到位的误判**：误以为单次杂交即可得目标黄体雌果蝇，实则需 F₁ 再与黄体雄果蝇杂交。
- **表现型描述不全**：只写基因型不写表现型，或末行漏写比例。

## 代表题精讲

### 【代表题】2021-全国乙-10

**题目**：果蝇灰体（显）对黄体（隐）由 X 染色体上 A/a 控制；长翅（显）对残翅（隐）由常染色体 B/b 控制。（1）用灰体纯合雌果蝇与黄体雄果蝇为材料，设计杂交获得黄体雌果蝇（要求用遗传图解表示）。（2）黄体残翅雌果蝇 × 灰体长翅雄果蝇（$X^A Y BB$）得 F₁，F₁ 相互交配得 F₂，求 F₂ 中灰体长翅∶灰体残翅∶黄体长翅∶黄体残翅之比，及 F₂ 中灰体长翅雌蝇出现的概率。

**思路**：第（1）问需两步杂交（一次得不到黄体雌）；第（2）问把 X 染色体 A/a 与常染色体 B/b 分别算，再乘法合并。

**步骤（1）**：
- P：$X^A X^A$（灰体雌）× $X^a Y$（黄体雄）；配子 $X^A$ 与 $X^a$、$Y$。
- F₁：$X^A X^a$（灰体雌）、$X^A Y$（灰体雄），无黄体雌。
- 再杂交：取 F₁ 灰体雌 $X^A X^a$ × 亲本黄体雄 $X^a Y$；配子 $X^A$、$X^a$ 与 $X^a$、$Y$。
- 子代：$X^A X^a$（灰雌）、$X^a X^a$（黄雌，即目标）、$X^A Y$（灰雄）、$X^a Y$（黄雄）。即得黄体雌果蝇 $X^a X^a$。

**步骤（2）**：
- 亲本：黄残雌 $X^a X^a bb$ × 灰长雄 $X^A Y BB$。F₁：常染色体 $Bb$（全长翅）；X 染色体 $X^A X^a$（灰雌）、$X^a Y$（黄雄）。
- F₁ 互交：B/b 这对 $Bb×Bb$ → 长∶残 = 3∶1。
- X 染色体 $X^A X^a × X^a Y$ → 后代 $X^A X^a$(灰雌)∶$X^a X^a$(黄雌)∶$X^A Y$(灰雄)∶$X^a Y$(黄雄) = 1∶1∶1∶1，即灰∶黄 = 1∶1。
- 合并表现型比：灰长∶灰残∶黄长∶黄残 = (1×3)∶(1×1)∶(1×3)∶(1×1) = **3∶1∶3∶1**。
- 灰体长翅雌蝇概率：灰雌 = $X^A X^a$ 占全部的 1/4；长翅 = 3/4；相乘 = $\dfrac{1}{4}\times\dfrac{3}{4}=\dfrac{3}{16}$。

**点评/变式**：本题示范「伴性 + 常染色体」分座计算的标准套路，乘法原理是关键。第（1）问强调遗传图解须含两步杂交、完整配子与表现型。变式：若把灰/黄改到常染色体、长/残改到 X 染色体，分析框架不变，只是性别与哪对基因绑定互换。

### 【代表题】2018-新课标Ⅱ-10

**题目**：某家禽豁眼与正常眼为一对相对性状，豁眼雌禽产蛋能力强。性别决定方式与鸡相同（ZW 型），豁眼由 Z 染色体上的隐性基因 a 控制。要求据此分析相关杂交并书写遗传图解。

**思路**：ZW 型中 ♀ 为 ZW（异型）、♂ 为 ZZ。隐性基因在 Z 上，雌禽只有一条 Z，故基因型决定即表现（半合子）。设计杂交获得高比例豁眼雌禽时，要让母本贡献的 Z 与父本的 Z 合理搭配。

**步骤**：
- 明确基因型记法：豁眼雌 $Z^a W$、正常眼雌 $Z^A W$；豁眼雄 $Z^a Z^a$、正常眼雄 $Z^A Z^a$ 或 $Z^A Z^A$。
- 雌禽性状由其唯一的 Z 决定：$Z^a W$ 即豁眼雌、$Z^A W$ 即正常眼雌。
- 欲后代雌禽全为豁眼（产蛋强），让父本为豁眼纯合 $Z^a Z^a$ × 任意雌：父本只给 $Z^a$，女儿得父本 $Z^a$ + 母本 W = $Z^a W$，全豁眼雌。
- 规范图解：P $Z^a Z^a$（豁眼雄）× $Z^A W$（正常眼雌）；配子 $Z^a$ 与 $Z^A$、W；子代 $Z^A Z^a$（正常眼雄）、$Z^a W$（豁眼雌），即雌性全豁眼。

**点评/变式**：ZW 型分析的核心是「雌性异型、性状随父本 Z 传给女儿」，与 XY 型方向相反，最易因套用 XY 型而出错。变式：判断 F₁ 中豁眼∶正常眼比例、或反向选育（要正常眼雌禽）时父本应取的基因型。
