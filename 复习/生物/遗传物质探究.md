## 知识精要
- **肺炎双球菌转化实验**
  - 格里菲思体内转化实验：证明加热杀死的S型菌含有“转化因子”，使R型活菌转化为S型菌（仅证明存在，未证明是DNA）。
  - 艾弗里体外转化实验：分别用蛋白酶、RNA酶、酯酶、DNA酶处理S型菌提取物，**只有DNA酶处理组丧失转化能力**。直接证明 **DNA 是遗传物质**，蛋白质、多糖等不是。
  - 核心设计思想：**设法将 DNA 与蛋白质等其他成分分开，单独地、直接地观察它们的作用**。
- **T2 噬菌体侵染大肠杆菌实验**
  - 赫尔希和蔡斯利用放射性同位素标记法：
    - $^{35}S$ 标记噬菌体蛋白质外壳：上清液放射性高，沉淀放射性低（蛋白质外壳未进入细菌）。
    - $^{32}P$ 标记噬菌体 DNA：沉淀放射性高，上清液放射性低（DNA 注入细菌）。
  - 子代噬菌体检测到 $^{32}P$，未检测到 $^{35}S$。
  - 结论：**DNA 是遗传物质**。该实验完美印证了“DNA 是遗传物质，蛋白质不是”。
- **易混淆实验对照**
  - 孟德尔豌豆杂交实验 → 提出基因分离/自由组合定律（未涉及遗传物质化学本质）。
  - 摩尔根果蝇杂交实验 → 证明基因在染色体上（未涉及 DNA 直接证明）。
  - DNA X 射线衍射实验 → 为沃森、克里克构建 DNA 双螺旋模型提供衍射图谱数据（属于结构探究，非遗传物质证明）。

## 解题方法与套路
1. **关键条件锁定法**：审题时圈定“证明 **DNA 是遗传物质**”这一核心诉求，而非“基因定位”或“DNA 结构”。
2. **实验设计原理回溯**：
   - 若选项出现“肺炎双球菌转化实验”，需区分是格里菲思（只推断存在转化因子）还是艾弗里（直接证明 DNA 是转化因子）。考题通常笼统指代整个转化实验体系，无误即可选。
   - 若选项出现“噬菌体侵染实验”，结合“同位素标记”、“分离蛋白质与 DNA”特征直接判定正确。
3. **排除法应用**：
   - 看到“孟德尔”、“摩尔根” → 直接排除（属于遗传学规律发现或染色体定位）。
   - 看到“X 射线衍射”、“DNA 双螺旋” → 直接排除（属于物理化学结构解析）。
4. **组合选项验证**：将筛选出的正确实验序号（③④）与选项匹配，快速筛选 C 项。

## 高频易错
- **格里菲思与艾弗里张冠李戴**：格里菲思的体内转化实验**未证明** DNA 是遗传物质，只发现了“转化因子”。只有艾弗里体外转化实验才鉴定出该因子是 DNA。选择题若混入“格里菲思证明 DNA 是遗传物质”的描述为错。
- **摩尔根实验属性混淆**：摩尔根证明了 **基因在染色体上**，这是对孟德尔遗传定律的细胞学解释补充，**并未直接触及 DNA 是遗传物质的化学证明**。切勿因“果蝇”联想到遗传学就误选。
- **“蛋白质外壳”标记的放射性误判**：$^{35}S$ 标记的噬菌体侵染时，**蛋白质外壳并不进入细菌细胞**，因此沉淀物（主要是细菌）放射性极低。若搅拌不充分导致部分外壳附着，会使沉淀物出现少量 $^{35}S$，但这属于操作误差，不影响实验最终结论。
- **DNA 衍射实验的归属**：DNA 的 X 射线衍射实验提供了物理结构证据，助力了双螺旋模型建立，但它不解决“谁是遗传物质”的生物学功能证明问题。

## 代表题精讲
**题目** （2013·新课标Ⅱ·5）判断哪组实验证明了 DNA 是遗传物质：①孟德尔豌豆杂交 ②摩尔根果蝇杂交 ③肺炎双球菌转化实验 ④T2噬菌体侵染实验 ⑤DNA X 射线衍射实验。

**思路**
紧扣题干“证明 DNA 是遗传物质”这一化学本质鉴定任务。梳理每个历史实验的核心贡献，快速剔除仅涉及遗传规律、基因定位、物质结构的实验，保留直接鉴定 DNA 为遗传物质的经典组别。

**步骤**
1. 排查①：孟德尔实验发现了分离与自由组合定律，研究对象是“遗传因子”，未涉及 DNA 提取与鉴定。排除。
2. 排查②：摩尔根将白眼基因定位在 X 染色体上，提出“基因在染色体上”假说，同样未解析遗传物质的化学身份。排除。
3. 锁定③：肺炎双球菌转化实验（尤其是艾弗里体外转化）使用酶解法去除了蛋白质与 DNA 的作用，化学上证实转化因子就是 DNA。符合题意。
4. 锁定④：T2 噬菌体侵染实验用 $^{35}S$ 和 $^{32}P$ 分开追踪蛋白质与 DNA，证明注入细菌并完成复制遗传的是 DNA 而非蛋白质。符合题意。
5. 排查⑤：X 射线衍射仅提供 DNA 空间构象参数，用于构建双螺旋模型，不涉及功能证明。排除。
6. 有效配对为③④，对应选项 C。

**点评/变式**
本题属于识记级送分题，但高度浓缩了遗传学史考点。变式训练时需警惕“肺炎双球菌的格里菲思实验证明了...”这种半截子选项，格里菲思止步于“存在转化因子”，唯有完整的转化实验体系或特指艾弗里才可判定为直接证明。
