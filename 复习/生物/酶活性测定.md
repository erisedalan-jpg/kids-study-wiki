## 知识精要
- **酶活性定义**：酶催化特定化学反应的能力，通常用单位时间内底物减少量或产物生成量表示，国际单位为 katal（mol/s），实验中常以相对活性或比活力（单位蛋白质的活性）比较。
- **酶活性测定要点**：需在最适温度、最适 pH 及底物饱和条件下测定初始反应速率；显色法、荧光法、电化学法等均遵循产物生成或底物消耗的线性响应区间；需同步设置空白对照（失活酶或不含酶的体系）排除非酶促背景。
- **基因与酶活性的关系**：基因通过转录、翻译决定酶的一级结构。突变若导致开放阅读框内提前出现终止密码子（PTC），翻译产物多肽链长度变短，空间结构破坏，酶活性丧失或降低。点突变、插入、缺失均可造成此类后果，启动子区或剪接位点突变也可影响酶量或活性。
- **遗传分析中的酶活性**：隐性突变纯合子通常酶活极低或丧失；野生型纯合子酶活最高；杂合子因存在一个正常拷贝，酶活常介于中间，可借此辅助显隐性判断。转基因互补实验（将正常基因转入突变体）可恢复表型和酶活，用于基因功能验证。
- **同源基因**：序列高度相似、功能相关的不同基因座基因（非等位基因），可能编码同工酶。本题 A1 与 A2 为非等位同源基因，分别突变形成持绿表型，属于异源基因冗余控制相同性状。

## 解题方法与套路
1. **理清遗传关系，确定显隐性**  
   - 将突变体与野生型杂交，若 F₁ 全部表现为野生型表型，则突变性状由隐性基因控制（显性突变时 F₁ 常表现突变性状或中间型）。由此推断突变基因型（如纯合 ml）及功能缺失性质。
2. **分析核酸序列差异，推断突变类型与后果**  
   - 比对模板链，若出现碱基缺失、插入、替换，计算开放阅读框变化，重点判断是否形成提前终止密码子（UAA、UAG、UGA），并估算翻译产物长度变化（变短/变化有限）。若模板链某段缺失非 3 的整数倍碱基，常导致移码并在下游出现终止子，肽链严重缩短。
3. **解读酶活性测定数据**  
   - 根据柱形图或表格，酶活性高者为野生型（功能正常），酶活性极低或检测不到者为突变纯合子；注意可能存在的补偿效应（如不同基因编码同工酶时，单突变体残留部分活性）。若出现三个样本，活性呈现“高一中—低”，可能对应野生型、杂合子、突变纯合子（本题为纯合比较，无杂合子，故活性最高的为野生型）。
4. **验证基因功能的实验设计**  
   - 转基因互补实验：将目标野生型基因转入突变体，若恢复正常表型和酶活，则证明该基因控制该性状。需选择纯合突变个体为受体，以野生型基因表达载体进行转化。
5. **整合分子与表型数据得出结论**  
   - 将序列分析的突变类型、蛋白质结构预测与酶活性检测、表型观察相互印证，形成完整的“基因—酶—性状”逻辑链。

## 高频易错
- **碱基数目缺失与移码判断失误**：缺失 3 的倍数个碱基可能不造成移码，仅移除对应氨基酸，肽链长度几乎不变；缺失非 3 倍数则必然移码，提前遇到终止密码子，肽链显著缩短。考生需严格计算缺失碱基数。
- **显隐性与表型对应出错**：若野生型与突变体杂交后代全部为突变性状，才为显性突变；本题中出现“熟黄 × 持绿→全部熟黄”，则持绿为隐性，熟黄为显性，不能反推。
- **同源基因与等位基因混淆**：A1 与 A2 是非等位的同源基因，位于不同基因座，不属于等位基因；单基因突变即可造成表型，不可视为同一基因的不同等位形式。
- **酶活性测定对照设置**：考生填空或分析时易忽略检测体系中的阴性对照，错误地将非特异性信号当作酶活，或未考虑相同蛋白上样量的必要性（需结合比活力概念）。
- **提前终止密码子与蛋白长度**：提前终止必然导致产物变短，但若突变发生位置极靠近原始终止密码子，长度变化微小，易被忽略；需明确排序前后差异。
- **转基因互补受体选择**：验证 A1 基因功能，应将野生型 A1 基因转入“持绿”突变体 ml 中，而非转入野生型或其他突变体，否则无法得出正确结论。

## 代表题精讲
**题目**（2024·辽宁·24）  
小麦野生型成熟期正常枯黄（熟黄），突变纯合子 ml 与 m2 均表现为叶片保持绿色时间延长（持绿），分别由 a1、a2 隐性突变引起。A1 与 A2 为非等位同源基因。  
（1）推断显隐性并设计转基因互补实验验证 A1 功能。  
（2）根据模板链信息（图 1）判断 a1 与 a2 的突变类型及对蛋白质的影响；根据酶活性检测结果（图 2）识别野生型对应的株系。

**思路**  
（1）熟黄与持绿杂交，若子代全部熟黄，则熟黄为显性，持绿为隐性。功能验证需将 A1 基因转入持绿突变体 ml，若植株恢复熟黄表型，则证明 A1 控制熟黄。  
（2）从图 1 模板链缺失情况判断 a1 为缺失某段碱基（非 3 倍数），造成移码并提前出现终止密码子；a2 为单碱基替换产生无义突变（提前终止）。两种突变均使 mRNA 提前出现终止密码子，翻译出的肽链长度变短，空间结构改变，酶活性丧失。图 2 酶活性最高者为野生型。

**步骤**  
1. 第一空：F₁ 表型应为“熟黄”（野生型亲本表型），说明突变型对野生型为隐性。  
2. 第二空：将 A1 基因转入“持绿”（答题时填写“持绿”）个体，若植株表现熟黄，可验证该基因控制叶片衰老过程。  
3. 据图 1：比较 a1 与野生型模板链，发现 a1 缺失若干碱基（非 3 整数倍），发生“碱基缺失”；a2 发生单个碱基的改变（如 C→T 等），为“碱基替换”。两者均使 mRNA 上出现提前的终止密码子。  
4. 第三、四空：合成的 mRNA 都提前出现了“终止密码子”，翻译出的多肽链长度变“短”。  
5. 酶活性数据：由柱状图可知，有一个株系的酶活性显著高于另两个，应为野生型；根据序列号或标注选择“相应数字”（如“①”或“1”），填写该号。  
6. 结论串联：a1 缺失突变和 a2 无义突变均导致 A 酶失活，不能正常降解叶绿素等，叶片持绿。

**点评/变式**  
本题将遗传规律、分子突变类型、蛋白质结构和酶活性测定融为一体，代表了“基因—酶—性状”经典分析范式。解题关键在：  
- 熟练运用显隐性杂交实验判断依据；  
- 准确区别碱基缺失、插入与替换，尤其关注是否引发移码；  
- 明确提前终止密码子一定导致肽链变短，进而使酶失活；  
- 酶活柱状图中最高值即为野生型。  
变式训练可延伸到温度敏感型突变、同工酶补偿、启动子突变导致酶量降低等情况，结合酶动力学参数（$K_m$、$V_{max}$）变化进行综合分析。
