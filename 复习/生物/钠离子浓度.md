## 知识精要
- **静息电位**：神经纤维未受刺激时膜内外电位表现为外正内负，主要由 $K^+$ 外流维持，其大小主要取决于膜内外 $K^+$ 浓度差，几乎不受细胞外 $Na^+$ 浓度影响。
- **动作电位**：神经纤维受刺激时产生的一次快速、可逆的电位变化，表现为外负内正，峰值由 $Na^+$ 内流决定，主要由膜内外 $Na^+$ 浓度差驱动。细胞外 $Na^+$ 浓度降低 → 膜内外 $Na^+$ 浓度差减小 → 刺激时 $Na^+$ 内流量减少 → 动作电位峰值降低；反之升高。
- **适用条件**：分析实验处理（如改变细胞外液 $Na^+$ 或 $K^+$ 浓度）对神经细胞电位的影响时，必须明确：
  - 改变 $K^+$ 浓度 → 影响静息电位；
  - 改变 $Na^+$ 浓度 → 影响动作电位峰值，不影响静息电位。

## 解题方法与套路
1. **审题定位**：明确题目改变的是何种离子浓度，区分是 $Na^+$ 还是 $K^+$，留意是“细胞外液”还是“细胞内液”的浓度变化。
2. **知识点挂钩**：快速回忆静息电位和动作电位的离子基础：
   - $K^+$ 平衡电位决定静息电位；
   - $Na^+$ 内流幅度决定动作电位峰值。
3. **逻辑推演**：改变某离子浓度 → 影响该离子的跨膜扩散驱动力（即该离子平衡电位）→ 对应静息电位或动作电位峰值的变化。若被改变的离子与某电位无关，则该电位不变。
4. **排除干扰**：题目常设置“静息电位也会变”的干扰选项，须坚定地根据离子专一性排除。

## 高频易错
- **混淆钾钠影响**：错以为降低细胞外 $Na^+$ 会使静息电位减小或增大。实际上静息电位受 $K^+$ 浓度差支配，$Na^+$ 浓度变化不影响静息电位。
- **方向判断错误**：降低细胞外 $Na^+$ 时，误以为动作电位峰值升高。须记住：外液 $Na^+$ 越低，$Na^+$ 内流驱动力越小，峰值越低。
- **忽视“相当于细胞外液”的条件**：实验溶液 S 模拟细胞外液，改变其成分等同于改变细胞外液相应离子浓度，考生易将此与细胞内液变化混淆。

## 代表题精讲
**题目**：2010-新课标-05（简化）  
将神经细胞置于相当于细胞外液的溶液 S 中，测得静息电位。给予适宜刺激产生动作电位。适当降低溶液 S 中 $Na^+$ 浓度，再次测量，则（ ）  
A. 静息电位值减小  
B. 静息电位值增大  
C. 动作电位峰值升高  
D. 动作电位峰值降低

**思路**  
抓住核心知识：静息电位与 $K^+$ 相关，动作电位峰值与 $Na^+$ 相关。降低细胞外 $Na^+$ 浓度，$Na^+$ 电化学驱动力减小，内流减少，动作电位峰值降低；$K^+$ 浓度未变，静息电位不受影响。

**步骤**  
1. 分析处理对象：降低溶液 S 的 $Na^+$ 浓度，即降低细胞外 $Na^+$ 浓度。  
2. 静息电位判断：静息电位主要取决于细胞内外 $K^+$ 浓度差，处理未改变 $K^+$ 浓度，故静息电位不变。排除 A、B。  
3. 动作电位判断：动作电位峰值由 $Na^+$ 内流决定。细胞外 $Na^+$ 浓度降低 → 膜内外 $Na^+$ 浓度差减小 → 受刺激时 $Na^+$ 内流驱动力下降 → 内流 $Na^+$ 量减少 → 动作电位峰值降低。故选 D。

**点评/变式**  
本题是典型的直接概念应用题。若将“降低溶液 S 的 $Na^+$”换成“降低溶液 S 的 $K^+$”，则静息电位绝对值减小（或静息电位向去极化方向变化），动作电位峰值基本不变。务必养成“离子-电位”一一对应的思维习惯，避免轻率判断。
