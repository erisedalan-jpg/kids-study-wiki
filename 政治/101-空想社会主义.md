# 空想社会主义

> **一句话**：空想社会主义是很多人梦想建立一个没有贫穷和压迫的美好社会，但因为不知道具体怎么实现，所以叫“空想”。
> **English**: Utopian socialism is a theory that imagines an ideal society without exploitation, but lacks a scientific path to achieve it.

## 🎓 给 12+（进阶版）

空想社会主义是科学社会主义的思想来源之一。代表人物有法国的圣西门、傅立叶和英国的欧文。他们深刻批判了资本主义的弊病，对未来社会提出了许多天才设想，如图书馆式的组织、消灭城乡对立、人人劳动等。但由于当时资本主义矛盾还未充分暴露，他们未能发现社会发展的客观规律，不了解阶级斗争是推动阶级社会发展的直接动力，也没有认识到无产阶级的历史使命，因而寄希望于统治者和资本家的良心发现，使得这些美好构想沦为“空想”。马克思、恩格斯创立了**唯物史观**和**剩余价值学说**，揭示了人类社会发展的一般规律和资本主义运行的特殊规律，才使社会主义从空想变为科学。关联词条：[[科学社会主义]]、[[唯物史观与剩余价值学说]]、[[资本主义基本矛盾]]。

## 🗣️ 家长讲解话术

- 孩子可能问 **“为什么叫‘空想’，不叫‘梦想’？”** → 可以这样解释：因为空想社会主义者只是想象了一个理想世界的蓝图，就像画了一幅漂亮的画，但他们没有找到搭梯子的方法，不知道依靠谁、通过什么步骤才能真的把画变成现实。马克思他们找到了“搭梯子”的方法，所以才能变成科学。
- **共读小活动**：拿出纸和笔，让孩子画一个“最完美的社区”，然后一起讨论“这个社区要怎么才能从纸上变成真的？需要哪些人帮忙？需要什么规则？” 引导孩子理解：美好的愿望还需要实际的方法才能实现。
