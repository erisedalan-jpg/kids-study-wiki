# 社会主义核心价值观（政治）

> **一句话**：社会主义核心价值观是中国人共同追求的好品质，像一座灯塔，告诉我们国家、社会和自己该怎样做才更好。
> **English**: The Core Socialist Values are shared ideals that guide how our country, society, and each person should act for a better life.

---

## 🎓 给 12+（进阶版）

社会主义核心价值观是社会主义核心价值体系的内核，集中体现当代中国精神，凝结全体人民共同的价值追求。其基本内容包括：**国家层面**倡导富强、民主、文明、和谐；**社会层面**倡导自由、平等、公正、法治；**公民个人层面**倡导爱国、敬业、诚信、友善。三者有机统一，国家价值目标是社会与个人价值实现的前提，社会价值取向是联结国家与个人的纽带，个人价值准则是基础。在《哲学与文化》中，它与文化自信、意识形态领导权、培育担当民族复兴大任的时代新人等密切相关，是凝魂聚气、强基固本的基础工程。

## 🗣️ 家长讲解话术

- 孩子可能问 **“为什么要把这些词记下来？”** → 可以告诉他：这些词就像我们家的家规或班级的班规，是我们所有人一起约定要努力做到的方向，让我们的国家、社会和我们自己都变得更好。
- **共读小活动**：准备12张卡片，分别写上12个核心价值观的词。请孩子从中选出他认为今天自己做得最好和最有待加强的一个词，并说一说理由。活动可在晚饭后5分钟内完成，用纸和笔即可。
