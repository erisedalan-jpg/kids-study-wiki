# 人类命运共同体（政治）

> **一句话**：人类命运共同体是说，全世界的人就像坐在同一条大船上，要一起划船、互相帮助，才能让大家都安全、都过上好日子。
> **English**: The Community with a Shared Future for Mankind means that all people in the world are like passengers on the same big boat — we need to row together and help each other so that everyone can be safe and live well.

## 🎓 给 12+（进阶版）

**形式化定义**：人类命运共同体是新时代中国外交的核心主张，倡导各国在追求本国利益时兼顾他国合理关切，在谋求自身发展中促进共同发展，建设持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界。这一理念强调各国相互依存、利益交融、安危与共，要求摒弃零和博弈与强权政治，遵循共商共建共享的全球治理观。

**关联词条**：与[[多边主义]]互为支撑，区别于单边主义；与[[全球治理]]密切相关，为全球治理提供价值导向；在实践上常与[[一带一路]]倡议相衔接，体现为具体的合作平台与发展方案。

## 🗣️ 家长讲解话术

- 孩子可能问 **"人类命运共同体是不是要所有国家合并成一个国家？"** → 回答方向：不是的，每个国家的主权和独立都受到尊重，只是各国在像保护环境、防止疾病传播这些事上像邻居一样合作，而不是合并。
- **共读小活动**：拿出一张世界地图或地球仪，找出其中3个不同的大洲，让孩子说出每个地方人们共同面临的一个问题（如气候变化、森林减少），讨论合作解决的办法。用时约5分钟，材料用家中地图或打印即可。
