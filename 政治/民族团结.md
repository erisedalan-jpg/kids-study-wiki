# 民族团结

> **一句话**：民族团结就是不同民族的人像一家人，互相尊重、互相帮助，一起把国家建设得更好。
> **English**: Ethnic unity means different ethnic groups treat each other like family, respecting and helping one another to build a stronger nation together.

## 📚 给 6-12 岁（自读版）

你所在的班级里可能有不同星座、不同爱好的小朋友，大家互相学习对方的优点，不排挤任何人，这就是班级团结。我们国家有 56 个民族，就像 56 朵不同颜色的花。每个民族都有自己独特的语言、节日和美食，比如傣族的泼水节、蒙古族的那达慕大会。大家彼此欣赏习惯、友好相处，国家才会更温暖、更有力量。民族团结就是大家一起做一朵漂亮的“大花束”。

## 🎓 给 12+（进阶版）

民族团结是指各民族在政治、经济、文化、社会生活中一律平等，相互尊重、相互包容、相互帮助，共同维护国家统一和社会稳定。它建立在《宪法》“中华人民共和国各民族一律平等”的基础上，是处理民族关系的基本准则。筑牢民族团结，需要增强“中华民族共同体意识”，推动各民族交往交流交融，同时反对大民族主义和地方民族主义。在政治学框架中，它常与[[民族区域自治制度]]、[[国家安全]]等概念联动，是多民族国家长治久安的重要基石。

## 🗣️ 家长讲解话术

- 孩子可能问 **“为什么我们国家要有这么多民族？”** → 可以告诉孩子，不同民族就像不同的颜色，只有一种颜色会很单调，各种颜色在一起才能画出最美的图画。每个民族都有自己了不起的创造，大家互相学习，生活才更精彩。
- **共读小活动**：找一张中国地图，带孩子用不同颜色的贴纸贴在部分民族聚居的区域，一边贴一边聊那个民族的一个有趣节日或食物，5 分钟左右即可。
