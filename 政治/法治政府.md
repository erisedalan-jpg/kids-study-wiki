# 法治政府

> **一句话**：法治政府就是像遵守游戏规则一样，政府做事也要按法律来，不能随便乱管。
> **English**: A law‑based government acts according to the law, like everyone following the same game rules.

## 🎓 给 12+（进阶版）

法治政府是全面依法治国的主体工程，指政府在行使权力、履行职责过程中坚持法治原则，严格依法行政。其基本要求包括：职能科学、权责法定、执法严明、公开公正、智能高效、廉洁诚信。政府的权力由法律授予，行使权力必须遵守法定程序，接受监督。它与「法治国家」「法治社会」一体建设：法治国家是目标，法治政府是关键，法治社会是基础。建设法治政府需要把政府活动全面纳入法治轨道，用法治给行政权力定规矩、划界限，使政府不越位、不缺位，做到法定职责必须为、法无授权不可为。

## 🗣️ 家长讲解话术

- 孩子可能问 **“为什么政府也要听法律的？”** → 法律是大家一起定的规则，政府带头遵守，社会才会更公平、更有序。
- **共读小活动**：拿出一份简单的“家庭规则”清单，和孩子一起讨论“家长需不需要也遵守这些规则”，引到“所有人都要守规矩，管大家的人更要守规矩”。
