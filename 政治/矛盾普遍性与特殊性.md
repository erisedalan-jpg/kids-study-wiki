# 矛盾普遍性与特殊性

> **一句话**：所有事物里都有矛盾，但每个事物的矛盾又和别人不一样，就像每个人都会遇到困难，但每个人的困难都不同。
> **English**: Every thing contains contradiction, but the contradiction in each thing is unique—like everyone faces troubles, but each person’s troubles are different.

---
## 🎓 给 12+（进阶版）

矛盾的普遍性（或绝对性）指矛盾存在于一切事物的发展过程中，每一事物的发展过程中存在着自始至终的矛盾运动，即“事事有矛盾，时时有矛盾”。矛盾的特殊性（或相对性）指矛盾着的事物及其每一个侧面各有其特点，具体表现为不同事物的矛盾各有特点，同一事物在发展的不同过程和阶段上的矛盾各有特点，以及同一矛盾的两个方面也各有其特点。二者是共性与个性的关系：普遍性寓于特殊性之中，并通过特殊性表现出来；特殊性也离不开普遍性，在一定条件下可以相互转化。  
这一原理要求我们在认识事物时，必须坚持具体问题具体分析，既要看到矛盾的普遍性，又要把握矛盾的特殊性。

## 🗣️ 家长讲解话术

- 孩子可能问 **“矛盾不是吵架吗？为什么说哪儿都有矛盾？”** → 这里的矛盾不是人际冲突，而是事物内部对立统一的两个方面，比如吸引与排斥、成功与失败、遗传与变异。可以用“电池有正极和负极”来辅助理解。
- **共读小活动**：找一件家里常见的物品（如手机），和孩子一起列出它内部存在的对立又统一的两个方面（如：便捷 vs.依赖，通话 vs.辐射，蓄电 vs.耗电），讨论哪个特点使这个手机区别于其他手机，从而体会普遍性与特殊性。
