# 三角函数的图像与性质

> **一句话**：正弦、余弦、正切函数的图像形状、周期性、奇偶性、单调性、最值与对称性的统称，是研究周期现象与求解三角问题的核心工具。
> **English**: The collective shapes, periodicity, parity, monotonicity, extrema, and symmetry of sine, cosine, and tangent functions, serving as the core tool for studying periodic phenomena and solving trigonometric problems.

## 🎓 考点精讲

**核心定义**：正弦函数 $y = \sin x\ (x\in\mathbb{R})$，余弦函数 $y = \cos x\ (x\in\mathbb{R})$，正切函数 $y = \tan x\ (x \neq \frac{\pi}{2}+k\pi, k\in\mathbb{Z})$。它们的图像分别称为正弦曲线、余弦曲线和正切曲线。
**基本性质**：
- 周期性：$y=\sin x, \cos x$ 的最小正周期 $T=2\pi$；$y=\tan x$ 的周期 $T=\pi$。
- 奇偶性：$\sin x, \tan x$ 为奇函数；$\cos x$ 为偶函数。
- 单调区间（在一个周期内）：$\sin x$ 在 $[-\frac{\pi}{2}+2k\pi, \frac{\pi}{2}+2k\pi]$ 递增；$\cos x$ 在 $[(2k-1)\pi, 2k\pi]$ 递增；$\tan x$ 在 $(-\frac{\pi}{2}+k\pi, \frac{\pi}{2}+k\pi)$ 递增。
- 最值：$\sin x, \cos x$ 最大值为 1，最小值为 -1；$\tan x$ 无最值。
- 对称性：$\sin x$ 对称中心 $(k\pi,0)$，对称轴 $x=\frac{\pi}{2}+k\pi$；$\cos x$ 对称中心 $(\frac{\pi}{2}+k\pi,0)$，对称轴 $x=k\pi$；$\tan x$ 对称中心 $(\frac{k\pi}{2},0)$，无对称轴。

**关键方法**：用“五点法”绘制一个周期内的图像；已知 $y=A\sin(\omega x+\varphi)+B$ 图像求解析式时，由最值差求 $|A|$，由周期 $T=\frac{2\pi}{|\omega|}$ 求 $\omega$，利用关键点坐标求 $\varphi$；处理单调性、对称性、最值时，将 $\omega x+\varphi$ 视为整体代入相应性质条件，解出 $x$ 的范围。

**典型应用**：高考常在选填题中直接考查正弦型函数的图像识别、单调区间、对称轴或对称中心，或在解答题中先通过三角恒等变换化为 $A\sin(\omega x+\varphi)+k$ 形式，再讨论性质。例如，给出 $f(x)=2\sin(2x+\frac{\pi}{3})+1$ 的图像，求其在 $[\frac{\pi}{6},\frac{2\pi}{3}]$ 上的单调递增区间，需解不等式 $-\frac{\pi}{2}+2k\pi \leq 2x+\frac{\pi}{3} \leq \frac{\pi}{2}+2k\pi$ 并与给定区间求交。

## ⚠️ 高频易错点

- 忘记正切函数的定义域 $x \neq \frac{\pi}{2}+k\pi$，导致单调性判定或取值错误。
- 写单调区间时遗漏“$k\in\mathbb{Z}$”，或将正弦、余弦的递增区间相互混淆。
- 图像变换时混淆相位变换（平移）与周期变换（伸缩）的顺序：若将 $y=\sin x$ 先压缩为 $y=\sin 2x$ 再向右平移 $\frac{\pi}{6}$，实际是对 $x$ 替换，平移量应为 $\frac{\pi}{12}$（即由 $\sin[2(x-\frac{\pi}{12})]$ 得出），而非直接平移 $\frac{\pi}{6}$。
- 由 $y=A\sin(\omega x+\varphi)$ 求对称轴时，错误地令 $\omega x+\varphi = k\pi$（应为 $\omega x+\varphi = \frac{\pi}{2}+k\pi$）导致解答出错。

## 🎓 考点精讲

三角函数图象与性质的核心是掌握正弦、余弦、正切三类标准函数的“图像—性质”双向转化。

- **定义与基本图像**  
  正弦函数 $y = \sin x$, $x \in \mathbb{R}$，图像是波浪形正弦曲线，定义域 $\mathbb{R}$，值域 $[-1,1]$。  
  余弦函数 $y = \cos x$ 图像可由 $y = \sin x$ 向左平移 $\frac{\pi}{2}$ 得到，值域同为 $[-1,1]$。  
  正切函数 $y = \tan x = \frac{\sin x}{\cos x}$，定义域 $\{x \mid x \neq k\pi + \frac{\pi}{2}, k\in\mathbb{Z}\}$，值域 $\mathbb{R}$，图像在每个区间内递增且有无穷多条渐近线。

- **核心性质**  
  周期：$\sin x, \cos x$ 的最小正周期 $T=2\pi$；$\tan x$ 的最小正周期 $T=\pi$。一般形式 $y = A\sin(\omega x + \varphi) + B$ 的最小正周期 $T = \frac{2\pi}{|\omega|}$（余弦同理），$\tan(\omega x + \varphi)$ 的周期 $T = \frac{\pi}{|\omega|}$。  
  对称性：$\sin x$ 是奇函数，关于 $(k\pi,0)$ 中心对称，关于直线 $x = k\pi + \frac{\pi}{2}$ 轴对称；$\cos x$ 是偶函数，关于 $(k\pi+\frac{\pi}{2},0)$ 中心对称，关于 $x=k\pi$ 轴对称；$\tan x$ 是奇函数，关于 $(\frac{k\pi}{2},0)$ 中心对称，无对称轴。  
  单调性：$\sin x$ 在 $[-\frac{\pi}{2}+2k\pi, \frac{\pi}{2}+2k\pi]$ 增，$[\frac{\pi}{2}+2k\pi, \frac{3\pi}{2}+2k\pi]$ 减；$\cos x$ 在 $[-\pi+2k\pi, 2k\pi]$ 增，$[2k\pi, \pi+2k\pi]$ 减；$\tan x$ 在每个区间 $(-\frac{\pi}{2}+k\pi, \frac{\pi}{2}+k\pi)$ 内单调递增。最值：$\sin x, \cos x$ 最大值为 $1$，最小值为 $-1$，在各自对应点取得。

- **关键方法与典型考查**  
  1. **作图与变形**：通过“五点法”画出 $y = A\sin(\omega x + \varphi)$ 的简图，并能从图像反求解析式。高考常给出部分图像或文字条件，求 $A,\omega,\varphi$。  
  2. **三角函数的单调区间、对称轴与对称中心**：解 $\omega x + \varphi$ 整体的不等式或等式，转化为原始函数性质求解。  
  3. **三角函数的取值范围与最值**：化为 $y = A\sin z + B$ 或 $y = a(\sin x)^2 + b\sin x + c$ 二次型，结合换元与有界性求最值，常用于解三角形或导数中的边界问题。  
  4. **利用性质比较大小、解方程与不等式**：如在给定区间上依据单调性比较 $\sin\alpha$ 与 $\sin\beta$ 的大小，或解 $\sin x > \frac{1}{2}$ 型区间解集。

## ⚠️ 高频易错点

- **周期公式混淆**：忘记加绝对值 $T = \frac{2\pi}{|\omega|}$，或以角度制直接代入弧度制周期公式。
- ** $\varphi$ 的求解忽略符号与范围**：在由图像求 $y = A\sin(\omega x + \varphi)$ 时，当选择了错误的五点对应点，会导致 $\varphi$ 值偏差；未注意通常取 $|\varphi| \leq \pi$ 的限制。
- **正切型函数定义域漏写**：$y = \tan(\omega x + \varphi)$ 的定义域必须使 $\omega x + \varphi \neq \frac{\pi}{2} + k\pi$，学生常漏写整体集合表达，或忽略 $k\in\mathbb{Z}$。
- **复合区间单调性分析失误**：求 $y = A\sin(\omega x + \varphi)$ 的单调增区间时，未考虑 $A$ 的正负以及 $\omega$ 的符号，错误地直接套用 $\sin x$ 的单调区间，而忽略复合函数“同增异减”的规则。

## 🔁 合并补充：原《三角函数的图象与性质》

## 🎓 考点精讲

- **定义/原理**  
  基本三角函数包括 $y = \sin x$，$y = \cos x$，$y = \tan x$。  
  - **正弦函数** $y = \sin x$：定义域 $\mathbb{R}$，值域 $[-1, 1]$，最小正周期 $T = 2\pi$，奇函数，在 $[-\frac{\pi}{2} + 2k\pi, \frac{\pi}{2} + 2k\pi]$ 上单调递增，在 $[\frac{\pi}{2} + 2k\pi, \frac{3\pi}{2} + 2k\pi]$ 上单调递减，对称中心 $(k\pi, 0)$，对称轴 $x = \frac{\pi}{2} + k\pi$ ($k \in \mathbb{Z}$)。  
  - **余弦函数** $y = \cos x$：定义域 $\mathbb{R}$，值域 $[-1, 1]$，$T = 2\pi$，偶函数，在 $[-\pi + 2k\pi, 2k\pi]$ 上递增，在 $[2k\pi, \pi + 2k\pi]$ 上递减，对称中心 $(\frac{\pi}{2} + k\pi, 0)$，对称轴 $x = k\pi$。  
  - **正切函数** $y = \tan x$：定义域 $\{x \mid x \neq \frac{\pi}{2} + k\pi\}$，值域 $\mathbb{R}$，$T = \pi$，奇函数，在每个区间 $(-\frac{\pi}{2} + k\pi, \frac{\pi}{2} + k\pi)$ 内单调递增，对称中心 $(\frac{k\pi}{2}, 0)$，无对称轴。  
  一般正弦型函数 $y = A\sin(\omega x + \varphi) + b$ 的图象可由 $y = \sin x$ 通过平移、伸缩变换得到：周期 $T = \frac{2\pi}{|\omega|}$，频率 $f = \frac{1}{T}$，相位 $\omega x + \varphi$，初相 $\varphi$。

- **关键方法**  
  1. **五点法作图**：对 $y = A\sin(\omega x + \varphi)$ 的一个周期，取使相位等于 $0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}, 2\pi$ 的五个 $x$ 值，计算对应 $y$ 值，描点绘制光滑曲线。  
  2. **求单调区间**：将 $\omega x + \varphi$ 看作整体，代入 $y = \sin z$ 或 $y = \cos z$ 的单调区间解出 $x$。当 $\omega < 0$ 时，需先利用诱导公式化为正系数。  
  3. **求值域与最值**：结合定义域、图象及三角函数的有界性；对于 $y = a\sin x + b\cos x$，可化为 $\sqrt{a^2 + b^2}\sin(x + \varphi)$ 处理。  
  4. **判断周期与对称性**：直接由解析式读出系数，利用公式 $T = \frac{2\pi}{|\omega|}$；对称轴或对称中心通过令 $\omega x + \varphi = k\pi + \frac{\pi}{2}$（对称轴）或 $\omega x + \varphi = k\pi$（对称中心）求解。

- **典型应用**  
  高考中常考查：  
  - 根据部分图象求解析式 $y = A\sin(\omega x + \varphi) + b$，需从图象中提取最值（得 $A, b$）、周期（得 $\omega$）和特征点代入求 $\varphi$。  
  - 结合图象比较三角函数值大小、解三角不等式（如 $\sin x > \frac{1}{2}$），一般画出单位圆或图象，在指定区间内确定解集。  
  - 与导数、解三角形、参数问题结合，如讨论 $f(x) = \sin x + \cos x + a$ 在 $[0, \pi]$ 上的零点个数，需画出图象或利用辅助角公式化为正弦型函数分析。

## ⚠️ 高频易错点

- **忽视正切函数定义域**：解 $y = \tan(\omega x + \varphi)$ 相关问题时，丢失 $ \omega x + \varphi \neq \frac{\pi}{2} + k\pi$ 的限制，导致答案区间包含无定义点。  
- **单调区间写法错误**：对 $y = A\sin(\omega x + \varphi)$（$\omega < 0$）直接套用公式而不先恒等变形，得到的单调性与实际相反；或将多个单调增区间用“并集”连接（应写“每个区间上单调增”，不可用 $\cup$ 连接）。  
- **周期判断混淆**：忘记加绝对值导致周期错误，如 $y = \sin\left(-2x + \frac{\pi}{3}\right)$ 的周期误写为 $-\pi$，正确应为 $T = \frac{2\pi}{|-2|} = \pi$。  
- **复合函数性质讨论不当**：讨论 $y = \sin(\cos x)$ 的值域或单调性时，未考虑内层函数值域对整体性质的制约，直接套用正弦性质出错。
