# 核酸的结构与功能

> **一句话**：核酸是由核苷酸聚合而成的生物大分子，通过碱基序列储存和传递遗传信息，分为 DNA 和 RNA 两大类。
> **English**: Nucleic acids are polymers of nucleotides that store and transmit genetic information through base sequences, classified mainly into DNA and RNA.

## 🎓 考点精讲

**定义/原理**  
核酸的基本单位是核苷酸，每个核苷酸由一分子磷酸、一分子五碳糖和一分子含氮碱基组成。DNA（脱氧核糖核酸）的五碳糖是脱氧核糖，含 A、T、C、G 四种碱基，通常由反向平行的两条脱氧核苷酸链通过碱基互补配对（A=T，C≡G）形成双螺旋结构，链间以氢键维持；RNA（核糖核酸）的五碳糖是核糖，含 A、U、C、G，多为单链。  
功能上，DNA 是主要的遗传物质，其碱基序列携带遗传信息；RNA 在基因表达中发挥关键作用——mRNA 传递遗传信息，tRNA 转运氨基酸，rRNA 参与核糖体构成。核酸的结构与功能高度适应：双螺旋的稳定性适合遗传信息的长期储存，RNA 单链的灵活性使其能参与多种功能。

**关键方法**  
对于碱基比例与数量计算类问题，核心依据是双链 DNA 中碱基互补配对原则：A = T，C = G；任意两个不互补的碱基之和占全部碱基的 50%，即嘌呤数 = 嘧啶数。解题步骤：先明确是 DNA 还是 RNA（看 T 和 U），再分清是双链还是单链，随后利用总数关系和比例关系建立方程求解。另一种常见题型是依据核酸结构推断生物类型，如病毒核酸中若出现 T 则为 DNA 病毒，若出现 U 则为 RNA 病毒。

**典型应用**  
高考中常见设问：“某 DNA 分子共有 1000 个碱基对，其中胞嘧啶 300 个，问该分子中腺嘌呤有多少个？”——由 C = 300 → G = 300，总碱基 2000，所以 A + T = 2000 - 600 = 1400，则 A = 700。另一种情境是结合 DNA 半保留复制的计算，如“含 15N 的 DNA 在 14N 中复制 n 次，含 15N 的分子数及链数”，需同时应用核酸结构与复制机制。

## ⚠️ 高频易错点

- 混淆 DNA 与 RNA 的碱基与五碳糖：DNA 含 T、脱氧核糖，RNA 含 U、核糖；看到 U 就判定为 RNA。
- 碱基比例计算时误把单链比例当作双链比例，或忽略“互补碱基之和在双链中占 50%”的结论。
- 认为所有 RNA 都是单链——事实上 tRNA 和某些 RNA 病毒存在局部双链区，存在碱基配对。
- 混淆核酸的初步水解与彻底水解产物：初步水解得到核苷酸，彻底水解得到磷酸、五碳糖、含氮碱基。

## 🎓 考点精讲

### 一、核苷酸——核酸的基本组成单位

每个核苷酸由三部分组成：一分子**磷酸**、一分子**五碳糖**、一分子**含氮碱基**。
- DNA 的五碳糖为**脱氧核糖**，RNA 的五碳糖为**核糖**。
- 碱基分为嘌呤（A 腺嘌呤、G 鸟嘌呤）和嘧啶（C 胞嘧啶、T 胸腺嘧啶 / U 尿嘧啶）。DNA 特有 T，RNA 特有 U。

### 二、DNA 双螺旋结构（核心考点）

由沃森和克里克提出，要点如下：
1. **两条链反向平行**：一条链 5′→3′，另一条 3′→5′。
2. **外侧骨架**：磷酸与脱氧核糖交替连接，形成基本骨架。
3. **内侧碱基互补配对**：A 与 T 通过两个氢键配对，G 与 C 通过三个氢键配对。
4. **空间结构**：向右盘旋成双螺旋，G-C 含量越高，DNA 越稳定。

### 三、RNA 的结构与分类

RNA 通常为**单链**，局部可折叠形成双链区（也遵循 A-U、G-C 配对）。
- **mRNA**（信使 RNA）：携带遗传信息，作为翻译模板。
- **tRNA**（转运 RNA）：一端携带氨基酸，另一端有反密码子，识别密码子。
- **rRNA**（核糖体 RNA）：与蛋白质构成核糖体，催化肽键形成（核酶功能）。

### 四、核酸的功能

DNA 是**遗传信息的储存者**，通过半保留复制传递；RNA 参与**基因表达**（转录与翻译），某些病毒以 RNA 为遗传物质。

### 高考典型设问与解题方法

**设问 1：结构辨识题**——给出某核苷酸或核酸片段示意图，判断属于 DNA 或 RNA。
- **关键**：看五碳糖（是否脱氧）、看碱基（有无 T 或 U）。

**设问 2：碱基计算题**——已知双链 DNA 中某碱基比例，求另一碱基或单链中的比例。
- **核心公式**（查伽夫法则）：
  - 双链 DNA 中：A = T，G = C；A + G = T + C = 50%（嘌呤 = 嘧啶）。
  - 某碱基在双链中的比例 = 其在两条单链中比例的平均值。
- **解题步骤**：先由互补关系确定各碱基的整体数量关系，再结合单链比例需求反推。

**设问 3：结构稳定性比较**——比较不同 DNA 分子的热稳定性。
- **判定依据**：G-C 碱基对越多（三氢键），DNA 越稳定，解旋所需温度越高。

## ⚠️ 高频易错点

- **混淆单链与双链的碱基计算规则**：单链中 A 不一定等于 T、G 不一定等于 C，只有双链中才严格成立。若题目给出单链比例求另一条链，必须用互补关系推导，不能直接套用 AT/GC 相等。
- **误将 RNA 的 U 用于 DNA 结构描述**：DNA 中不含尿嘧啶（U），RNA 中不含胸腺嘧啶（T）；写核酸结构或碱基配对时必须区分清楚。
- **混淆核苷酸与核酸的组成层次**：核苷酸是单体（含磷酸+五碳糖+碱基），核酸是多聚体。题目问“某物质含有 C、H、O、N、P 且为遗传物质”时，指向核酸而非单纯核苷酸。
- **误认为 RNA 全是单链无配对**：tRNA 和 rRNA 均有局部双链区，存在碱基配对（A-U、G-C），该配对也可用于 RNA 结构稳定性分析。
